    机构的基本元素¶

    这一页要建立本课程的概念骨架。 骨架只有四个词：

    1
    构件 ──用──> 运动副 ──连成──> 运动链 ──固定一个构件──> 机构

    后面所有内容（自由度、传动、连杆设计）都挂在这条链上。 每个新名词都要能放进这条链的某个位置 ✓

    这一页的主线

    四个概念是层层递进的关系，不是并列的四个知识点：

    层 概念 一句话
    1 构件 一个独立的运动单元
    2 运动副 两个构件之间的连接方式
    3 运动链 用运动副连起来的一串构件
    4 机构 运动链里固定一个构件（机架）

    看懂这张表，就懂了本页的全部结构 ✓

    一、构件：什么是「一个运动单元」¶

    1.1 定义¶

    构件（Machine element / Link）：机器中每一个独立的运动单元体。

    关键在「独立运动」四个字 —— 判断两个零件是不是同一个构件， 问一句话就行：它们之间有没有相对运动？

    情况 是几个构件
    两零件用螺栓刚性连接，彼此不能动 同一个构件 ✓
    两零件之间有转轴，能相对转动 两个构件 ✓

    1.2 构件 vs 零件（最容易混的一对词）¶

    构件不等于零件 —— 这是本课程第一个高频错误

    零件（Part） 构件（Link / Machine element）
    定义 独立制造的单元 独立运动的单元
    判断依据 能不能单独加工出来 有没有相对运动
    数量关系 一个构件可以由多个零件组成 ✓ —
    例子 螺栓、螺母、轴套、连杆体、连杆盖 一根完整的连杆（含体+盖+螺栓+轴瓦）

    为什么必须分清：机构分析关心的是「谁相对谁能动」， 所以用构件计数，不用零件计数 ⚠

    数错构件会导致自由度算错 —— 这是后面自由度计算错误的头号原因。

    1.3 一个典型例子：连杆有几个零件、几个构件¶

    课件的例子是连杆组件。它由以下零件组成：

    零件 作用
    连杆体 主体
    连杆盖 配合体，与体合成封闭孔
    螺钉、螺母、垫圈 把盖紧固体
    轴套 减少磨损
    轴瓦 承载面

    这些零件是几个构件？答案是 1 个 —— 因为螺钉拧紧后， 盖与体之间没有相对运动，整体作为一个运动单元 ✓

    这说明：这个连杆组件虽然由 5 类零件构成， 但在机构简图里只画一条线（一个构件）。

    1.4 构件的分类（按运动性质）¶

    课件没细分，但机构分析里这个分类很实用：

    类型 特点 例子
    机架（Frame） 固定不动（或作为参考系） 机床床身、机器人底座
    原动件（Driver） 接受外部驱动、主动运动 电机带动的曲柄
    从动件（Follower） 被带动的构件 连杆、滑块
    连杆（Coupler） 既不固定也不直接接驱动的中间构件 四杆机构的连杆

    注意：同一个构件在不同分析中可能换角色。 把底座固定时它是机架；反过来研究底座相对臂的运动时， 臂就成了「机架」。机架是相对的 ⚠

    二、运动副：两个构件之间怎么连¶

    2.1 定义¶

    运动副（Kinematic pair）：两个构件之间直接接触、 且能保持一定相对运动的连接。

    这个定义有三个要素，缺一不可：

    要素 说明 反例
    直接接触 必须接触 用绳子隔空拉 → 不是运动副
    有相对运动 能相对动 焊死 → 变成一个构件，不是运动副 ✗
    运动受约束 相对运动是有限的、确定的 自由漂浮 → 无约束限制

    第三个要素最关键：运动副的本质是「约束」 —— 它限制了构件之间本来可能的相对运动 ✓ 这句话是下一节「自由度与约束」的伏笔。

    2.2 运动副的两种分类法¶

    分类法一：按接触形式分（最重要）

    低副（Lower pair） 高副（Higher pair）
    接触形式 面接触 点或线接触
    例子 转动副、移动副 齿轮啮合、凸轮与从动件
    引入的约束数 2 1
    承载能力 大（接触面积大）✓ 小（接触应力大）
    磨损 小、均匀 大（应力集中）⚠
    加工 容易 较难
    能否传递复杂运动 较难 容易（凸轮可任意轮廓）✓

    为什么低副约束数是 2、高副是 1 —— 这是后续自由度公式的关键， 下面「三、约束与自由度」会给出完整解释。

    分类法二：按相对运动形式分

    类型 相对运动 保留的自由度
    转动副（Revolute pair） 绕一根轴旋转 1（转角）
    移动副（Prismatic pair） 沿一个方向平移 1（位移）
    螺旋副（Helical pair） 转动与移动按固定比例耦合 1（转角，位移随之确定）
    球面副（Spherical pair） 绕一点任意转动 3（两个转角 + 自转）

    注意：上表里的自由度是「这个副允许几个独立运动」， 和「这个副约束几个」是互补关系（下面讲） ✓

    三、约束与自由度：连接带来的限制¶

    这一段是理解自由度公式的唯一途径，必须看懂。

    3.1 先看一个构件独立时能做什么¶

    在平面里，一个构件的位置需要几个数才能确定？

    需要确定的量 数量
    位置：\(x\) 坐标 1
    位置：\(y\) 坐标 1
    姿态：转角 \(\theta\) 1
    合计 3 ✓

    所以「平面内一个自由构件有 3 个自由度」。

    在空间里呢？位置 3 个 + 姿态 3 个 = 6 个自由度 ✓

    这两个数字（平面 3、空间 6）必须记住 —— 所有自由度公式都是从它们出发的。

    3.2 连接后自由度减少¶

    当两个构件用运动副连接，它们之间的某些相对运动被限制住了。 被限制掉的数量就是「约束数」。

    \[(\text{剩余自由度}) = (\text{原来的自由度}) - (\text{约束数})\]

    平面内的具体账目：

    运动副 原先可动 被限制掉 剩余可动
    转动副 3 2（不能沿 \(x\)、\(y\) 平移） 1（只能转）
    移动副 3 2（不能转、不能垂直移动） 1（只能沿一个方向移）
    平面高副 3 1（只限制了垂直方向） 2（可沿轮廓滚动+滑动）

    这张表解释了「为什么低副约束 2、高副约束 1」 ✓ 因为低副是面接触，面接触同时限制了两个方向； 高副是点/线接触，只限制一个方向。

    把这个关系记成一句话

    接触形式 限制的方向数 引入约束
    面接触（低副） 一个面能挡住两个方向的移动 2
    点/线接触（高副） 一个点只挡住一个方向 1

    平面自由度公式里的 \(-2P_L - P_H\) 就是这么来的 —— 每个低副减 2，每个高副减 1 ✓

    四、运动链：构件的连接网络¶

    4.1 定义¶

    运动链（Kinematic chain）：用运动副把两个以上构件连接起来的系统。

    关键词是「系统」 —— 运动链看的是整体连接关系， 而不是单个构件或单个副 ✓

    4.2 开链与闭链（必须分清）¶

    开链（Open chain） 闭链（Closed chain）
    特征 首尾不相连 首尾相连，形成环路
    例子 串联机械臂 四杆机构、平行四边形机构
    末端自由度 各关节自由度累加 受闭环约束、不能简单累加 ⚠
    刚度 低（误差累积） 高
    工作空间 大（各关节独立）✓ 小（受闭环限制）

    五、机构：运动链 + 机架¶

    5.1 定义¶

    机构（Mechanism）：当运动链中有一个构件被固定为机架时， 整个系统就称为机构。

    关键理解：机构 = 运动链 + 指定机架 ✓

    为什么必须指定机架：因为「谁在动」是相对的。 不指定参考系，「这个构件动几个方向」这句话没有意义 ⚠

    5.2 同一个运动链可以变成不同机构¶

    这是本页最有意思的一点：把运动链里的不同构件固定， 会得到运动特性完全不同的机构。

    以四杆链为例：

    固定哪个构件 得到的机构 特点
    最短杆的相邻杆 曲柄摇杆机构 一个构件整转、另一个摆动
    最短杆本身 双曲柄机构 两个构件都能整转
    最短杆的对面杆 双摇杆机构 只能摆动

    所以「结构」和「运动」是两件事： - 结构（哪些构件、哪些运动副、怎么连）决定可能是什么 - 固定谁当机架决定实际是哪一个机构 ⚠

    这个事实的工程意义：设计时可以用同一个机构样板， 通过改变固定件获得不同的运动输出 ✓

    判断下列运动副的类型（低副 / 高副），并说出它引入几个约束： (a) 门与门框之间的合页 (b) 两个齿轮啮合 © 抽屉与柜体 (d) 滚珠在滚道上滚动

    判断下列系统是开链还是闭链，并说明它的自由度该「累加」还是「用公式」： (a) 六轴串联机械臂 (b) 汽车转向的梯形机构 © 挖掘机的工作装置 (d) 并联平台（六条支链）

    思路

    看首尾是否相连形成环路。

    解答
    系统 是否成环 类型 自由度算法

    八、自测¶

    Q1 一个零件由 3 个子零件焊接成一个刚性整体， 它与另一个同样焊接的零件用一个转动副相连。 问：这里涉及几个零件、几个构件、几个运动副？

    提示

    先分子零件数，再问「哪些之间没有相对运动」。

    解答
    问题 答案 理由
    零件数 6 \(3 + 3\)
    构件数 2 每个焊接体内部无相对运动，各算 1 个

    Q3 为什么「同一个运动链固定不同构件会得到不同机构」？ 请举一个具体例子说明。

    提示

    想「谁在动是相对于谁说的」。

    解答

    原因是「运动是相对的」 —— 「某个构件转了几圈」这句话，必须指明相对于谁。 固定不同的构件，就等于选了不同的参考系， 于是各构件的「运动表现」随之改变 ✓

    具体例子：四杆运动链（4 构件、4 转动副）

    固定的构件 得到的机构 运动表现
    最短杆的相邻杆 曲柄摇杆机构 一杆整转、一杆摆动
    最短杆 双曲柄机构 两杆都能整转
    最短杆的对面杆 双摇杆机构 两杆都只能摆动

    同一个物理实体，只因为你把哪个件焊死在底座上， 就成了三种不同的机构 ⚠

    工程价值：这给了设计者一个省钱的办法 —— 同一个机构样板（同一套零件、同一套加工工序） 可以派生出多种运动方案 ✓

    Q4 下面这段话对不对？为什么？ 「因为运动副限制了构件间的相对运动， 所以运动副越多，机构的自由度就越小。」

    提示

    想一个反例：增加运动副的同时还能增加什么？ 想想「运动链里加一个构件」时会怎样。

    解答

    这句话只对了一半，必须补上一个前提 ⚠

    正确的表述： 「如果构件数不变，那么增加运动副确实会减少自由度。」

    为什么必须补前提：因为在机构里增加一个运动副， 通常要同时增加构件。而每个新增构件自身带来 3 个自由度（平面）：

    同时发生的事 对自由度的影响
    新增 1 个构件 \(+3\)
    新增 1 个低副（连到已有构件上） \(-2\)
    净效果 \(+1\) ✓

    所以「增加一个构件和一个低副」反而让自由度增加了 1 —— 这正是开链机械臂的设计原理： 每个关节加一个连杆，总自由度增加 1 ✓

    反例总结：

    情形 构件数 运动副数 自由度
    一个自由构件 1 0 3
    加一个构件 + 一个转动副 2 1 4
    再加一个 3 2 5

    自由度在增加，而不是减少 ⚠

    # 开链：每加一个构件和一个转动副，自由度净增 1
print("%-8s %-8s %-8s %s" % ("构件数", "低副数", "自由构件", "总自由度"))
print("-" * 44)
for n_link in range(1, 6):
    n_pair = n_link - 1                 # 串成一条链
    # 平面开链：每个自由构件 3 个自由度，每个低副减 2
    # 但最左那个构件也作为参考（不算自由度），这里统一按
    # 「自由构件数 × 3 - 约束数 × 2」的口径演示趋势
    dof = 3 * n_link - 2 * n_pair
    print("%-8d %-8d %-8d %d" % (n_link, n_pair, n_link, dof))
print()
print("趋势：每步净增 3 - 2 = 1，自由度随构件数增加而增加")

    小结¶

    要记住的 为什么
    构件 = 独立运动单元，零件 = 独立制造单元 一个构件可由多个零件组成，别数错
    判断是否同一构件：有没有相对运动 这是唯一可靠的判据
    运动副三要素：直接接触、有相对运动、运动受确定约束 缺一就不是运动副
    低副 = 面接触、约束 2；高副 = 点线接触、约束 1 决定自由度公式里乘 2 还是乘 1
    平面自由构件 3 个自由度，空间 6 个 所有公式的起点
    约束数 = 基准自由度 − 允许自由度数 平面基准 3、空间基准 6
    开链：自由度可累加；闭链：必须用公式 闭环会产生额外约束方程
    机构 = 运动链 + 机架 不指定参考系，「谁在动」无意义
    固定不同构件 → 不同机构 运动是相对的；同一套零件可派生多方案
    增加运动副不一定减少自由度 若同时增加构件：净效果是 \(+3-2=+1\)

    下一页：自由度与约束 —— 把这一页的「构件贡献自由度、运动副减少自由度」 写成一个能直接套用的公式，并学会对任意机构算出自由度。
