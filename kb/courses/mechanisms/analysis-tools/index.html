    机构分析工具¶

    这一页是第 1 章的最后一页，它回答一个问题：拿到一个机构，具体该怎么做分析？

    前面几页把概念一个个拆开讲完了：构件、运动副、运动链、机构、自由度、常用传动、 平面连杆。但真要动手分析一个真实的机械装置时，这些概念要怎么串成一条 可执行的动作？

    本课程课件在章末给出的答案是：先画机构简图，再用工具把运动算出来

    看起来差不多 实际差别 后果
    看实物数零件 机构分析数的是构件（运动单元） 自由度算大一截 ⚠
    凭印象画一张示意图 简图必须用标准运动副符号、按比例 运动副类型判错，公式代错 ⚠
    用工具拖一拖，看着能动 工具也要先给对输入模型 输入错了，工具给不出对答案 ⚠
    画完图就交差 还要做数值验证（轨迹、传动角） 图上看着没问题，实际够不到 ⚠

    这一页的核心问题

    工具能替你算什么，不能替你算什么？

    一句话回答：工具替你算，不替你判断

    所以本页的顺序是：

    1. 先讲简图怎么画（这是判断，只有人能做）；
    2. 再讲工具怎么算（这是计算，机器比人快）；
    3. 最后用四件最小工具、几个完整例子， 把「判断 + 计算」串成一条能反复使用的工作流

    本页面对的现实约束很明确：不是所有环境都能装专业机构分析软件。 因此本页的重点不是「介绍某款工具」，而是 用几十行代码把工具的核心能力自己实现出来 ✓

    一、为什么需要工具，而不是只用纸笔¶

    1.1 手算能撑到多复杂¶

    先明确一件事：手算不是不行，手算能用的范围其实比想象的宽。

    课件里出现的四杆机构、曲柄滑块机构，用手算完全做得下来：

    机构 手算难度 为什么
    四杆机构自由度 极低 数出 \(l = 4\)、\(P_L = 4\)、\(P_H = 0\)，代一次公式
    曲柄滑块机构自由度 极低 同样是 \(l = 4\)、\(P_L = 4\)
    四杆机构的某几个位置 低 每个位置解一次三角形
    四杆机构的传动角 中 每个位置要算两条线的夹角

    但手算的能力边界在哪里？ 不在公式复杂度上，而在数量上。 机构一复杂，量的增长是爆炸式的：

    • 杆件数一多（多杆）：每多一个独立回路，就要多联立一组三角方程；
    • 出现多环（闭链套闭链）：每个环都要单独解，解出来的角还要代入下一个环；
    • 出现高副（凸轮、齿轮）：接触点的位置本身就要先求出来，才能算夹角；
    • 一旦要整周分析：曲柄转一整圈要算几百个位置，纸笔根本不现实

    1.2 一个量化的对比：回路数决定手算负担¶

    「独立回路」是这里唯一需要的计数概念：

    平面低副机构的独立回路数 = \(P_L - (l - 1)\)

    其中 \(l\) 是构件总数（含机架），\(P_L\) 是低副个数。 这条式子的意思是：机构里有几个「独立可解的三角形」。

    为什么每个回路要解两个方程：一个回路要定下两条未知杆的方向， 方向由两个坐标分量决定，所以每个回路要联立 2 个方程。

    把这条式子代进去，负担就一目了然了。 取五种常见机构，逐个手算：

    四杆机构：\(l = 4\)、\(P_L = 4\)，代入得

    \[k = P_L - (l - 1) = 4 - (4 - 1) = 4 - 3 = 1\]

    回路数 1，待联立的方程数 \(2k = 2\)。正好是「解一个三角形」的量

    曲柄滑块机构：\(l = 4\)、\(P_L = 4\)（三个转动副 + 一个移动副，都算低副），代入得

    \[k = 4 - 3 = 1, \qquad 2k = 2\]

    回路数还是 1 —— 移动副不额外增加回路，只是把「转一个角」换成「移一段距离」

    平面五杆机构：\(l = 5\)、\(P_L = 5\)，代入得

    \[k = 5 - (5 - 1) = 5 - 4 = 1, \qquad 2k = 2\]

    这里有个容易误判的点：五杆比四杆多一根杆，回路数却还是 1。 原因是多出来的那根杆同时也带来了一个低副， \((l - 1)\) 和 \(P_L\) 同步加 1，差值不变

    六杆机构（Watt 型）：\(l = 6\)、\(P_L = 7\)，代入得

    \[k = 7 - (6 - 1) = 7 - 5 = 2, \qquad 2k = 4\]

    八杆机构：\(l = 8\)、\(P_L = 10\)，代入得

    \[k = 10 - (8 - 1) = 10 - 7 = 3, \qquad 2k = 6\]

    把五次手算的结果摆在一起，就是一张手算对照表：

    机构 \(l\) \(P_L\) 独立回路数 \(k\) 待联立方程数 \(2k\) 手算感受
    四杆机构 4 4 1 2 解一个三角形，纸笔够用 ✓
    曲柄滑块机构 4 4 1 2 同上，只是移副换转副 ✓
    平面五杆机构 5 5 1 2 和四杆一样，别被杆数骗了
    六杆机构（Watt 型） 6 7 2 4 要按环顺序解，开始容易错 ⚠
    八杆机构 8 10 3 6 三环顺序求解，手算不现实 ⚠

    注意最后一行：八杆机构只比四杆多了 4 根杆， 但手算负担从「2 个方程解一次」变成「3 环顺序求解 6 个方程」， 而且第 2 环的输入是第 1 环的输出， 任何一个环节的符号选错（对应另一种装配方式），整条链全错

    这说明什么：手算的困难不在单个方程的难度上， 而在方程之间的依赖关系上。四杆和五杆都只有一个回路， 它们的手算量其实是同一个量级； 真正的门槛出现在第三个回路之后 —— 从那里开始，每一步都要拿上一步的解往下代， 误差和符号错误会沿着回路链一路放大

    1.3 工具真正的价值：四件事¶

    课件在章末要求用工具做的事，其实正好就是工具的四项核心价值：

    工具能做的四件事 对应的工程问题 手算能做到吗
    快速画机构简图 这个机构到底由几根杆、几个副组成 可以，但反复修改时很慢
    自动算自由度 需要几个驱动；会不会卡死 可以，但要手数复合铰链/虚约束 ⚠
    算关键点的运动轨迹 工作端能走到哪里，轨迹是什么形状 算几个点可以，整周不行 ⚠
    看干涉 运动过程中杆件会不会撞在一起 基本做不到 ⚠

    1.4 哪类问题适合手算、哪类必须用工具¶

    这是本页第一张「判据表」，它决定了你拿到一个问题后先掏纸笔还是先开工具：

    问题类型 手算 工具 理由
    数构件、数运动副 必须手算 ✓ 辅助 判断「哪些零件是一个构件」只有人能定
    自由度计算 必须手算 ✓ 可复核 复合铰链、虚约束要先人工排查 ⚠
    四杆机构几个指定位置 可以 更快 每个位置解一次三角形
    六杆以上机构位置分析 做不到 ⚠ 必须 ✓ 多环顺序求解，手算易错
    整周轨迹（几百个位置） 做不到 ⚠ 必须 ✓ 纯数量问题
    干涉检查 / 工作空间边界 做不到 ⚠ 必须 ✓ 需要遍历全部位形
    传动角随曲柄角的变化曲线 只能取几个点 必须 ✓ 需要密集采样找最小值
    考试中的概念推导 必须手算 ✓ 工具不参与 考的是理解，不是算力

    最容易走偏的一步：跳过手算直接上工具

    很多人的第一反应是「有工具了，谁还手算」。

    但上面这张表里，凡是要「判断」的地方，工具都帮不上忙：

    • 哪些零件刚性连接在一起、该合并成一个构件 —— 工具不知道
    • 某个连接是转动副还是移动副 —— 工具不知道
    • 这个机构该固定哪一个构件当作机架 —— 工具更不知道

    这些判断做错了，工具会非常认真地算出一个错误答案， 而且它的界面看上去毫无异常

    正确的心态：工具是计算器，不是裁判。 它只负责算得快，不负责任务判断对错。

    2.2 什么是「机构简图」¶

    机构简图（kinematic diagram）：把真实机械装置抽象成 线条 + 运动副符号的平面图形。

    抽象掉什么、保留什么，是简图的全部要点：

    实物里有的东西 简图里怎么处理 为什么

    螺栓、键、销、轴套、挡圈 丢掉（它们不产生相对运动） 属于同一构件内部
    一个构件的真实形状 一条线 ✓ 刚体只需知道两个端点位置
    转动副的轴承、轴销 一个小圆圈 ✓ 只需知道转轴中心
    移动副的导轨与滑块 一个滑块符号 ✓ 只需知道移动方向
    固定的机架 打斜线 ✓ 明确谁是「不动」的那一个

    直接看实物数 会数成什么 后果

    2.4 画简图的规范步骤（本节最实用的部分）¶

    下面这六步是从「拿到实物或图纸」到「算出自由度」的标准流程。 每一步都不能跳：

    步 做什么 最常见的错法
    1 分清固定件（机架）与运动件 把电机外壳当运动件，机架少算 ⚠
    2 把刚性连接在一起的零件合并成一个构件 按零件数当构件数 ⚠
    3 用线条代表构件，长度按比例 线条随手画，运动关系失真
    4 用标准符号标注运动副 转动副不画圆圈、移动副不画滑块
    5 标出机架（打斜线） 不标机架，读者不知道谁固定
    6 数 \(l\)、\(P_L\)、\(P_H\)，代公式算 \(F\) 复合铰链、虚约束漏算 ⚠

    第 4 步需要的标准符号只有三个（平面机构够用了）：

    运动副类型 简图符号 接触方式 约束数（平面）
    转动副（回转副） 一个小圆圈 面接触 2（低副）
    移动副（滑动副） 一个矩形滑块 + 导轨线 面接触 2（低副）
    高副（齿轮副、凸轮副） 画出接触处的轮廓，点上一点 点/线接触 1（高副）

    读图对照六步法：

    图上的东西 对应六步的哪一步 数出来的值

    四个小圆圈 \(A\)、\(B\)、\(C\)、\(D\) 第 4 步：标准符号标副 符号数 = \(P_L = 4\)

    2.5 第 2 步详解：零件清单 → 构件清单（手算示范）¶

    第 2 步（合并刚接件）是六步里最容易出错的一步，值得单独把它算一遍。

    手算的做法就是列两张表： 左边一张零件明细表（照实物或图纸抄）， 右边一张构件清单（把刚接的零件并到一起）。 合并的依据只有一条问句：

    这两个零件之间，有没有相对运动？ 没有 → 属于同一个构件；有 → 分属两个构件

    下面按这条问句，把一台曲柄摇杆式送料装置的零件逐个归位：

    零件 数量 归属构件 判据（为什么这样归）
    底板 1 机架 装在地面上，整个装置的不动件 ✓
    电动机外壳 1 机架 螺栓固定在底板上，与底板无相对运动 ✓
    曲柄 1 曲柄 装在电机轴上，与机架构成转动副 ✓
    连杆体 1 连杆 两端分别铰接曲柄与摇杆 ✓
    连杆盖 1 连杆 与连杆体合抱成一个封闭孔，拧紧后无相对运动 ✓
    连杆螺栓 2 连杆 拧紧后与连杆体无相对运动 ✓
    连杆轴瓦 2 连杆 压装在连杆孔内，不产生相对运动 ✓
    摇杆 1 摇杆 一端铰接连杆，一端铰接机架 ✓
    摇杆销轴 1 摇杆 与摇杆焊接成一体 ✓
    工作台 1 摇杆 与摇杆螺栓固定，随之一起摆动 ✓
    轴用挡圈 4 不计入 标准件，只做轴向定位，不影响运动分析

    数一数零件：\(1 + 1 + 1 + 1 + 1 + 2 + 2 + 1 + 1 + 1 + 4 = 16\) 件。

    数一数构件：机架、曲柄、连杆、摇杆 —— 一共 4 个。

    \[16 \text{ 个零件} \;\longrightarrow\; 4 \text{ 个构件}\]

    这就是简图的第一层威力：它把一张 16 行的零件明细表， 压缩成了一张能直接代公式的图 —— 图上只画 4 条线

    再往下推一步：既然简图上有 4 条线，那 \(l = 4\)； 4 条线的端点两两铰接，形成 \(A\)、\(B\)、\(C\)、\(D\) 四个转动副， 其中 \(A\)、\(D\) 接机架，所以 \(P_L = 4\)、\(P_H = 0\)。代入自由度公式：

    \[F = 3(l - 1) - 2P_L - P_H = 3 \times (4 - 1) - 2 \times 4 - 0 = 9 - 8 = 1\]

    这说明什么：从「16 个零件」到「\(F = 1\)」， 中间只经过了一次归并和一次代公式。 把 16 直接当作 \(l\) 代进去会得到

    \[F = 3 \times 15 - 2 \times 16 - 0 = 45 - 32 = 13\]

    凭空多出 12 个自由度，结论会荒谬到「这台装置需要 13 个电机」 所以第 2 步做错的代价，是全盘皆错。

    哪些零件该「不计入」，这条线不能随便划

    上面那张表里，轴用挡圈被标成「不计入」。这不是因为它小， 而是因为它不改变相对运动：它只限制轴向窜动， 而机构的运动分析只关心平面内的相对转动与移动

    但划这条线要小心，下面两类零件不能随手归进「不计入」：

    • 滚子、滚珠：它们会引入局部自由度。 该处要单独扣除 1 个自由度，直接忽略会让 \(F\) 偏大
    • 弹簧、阻尼器：它们不限制运动，但会施加力。 做运动分析可以不计构件，做力分析时必须算进去 ⚠

    判断口径：只问「它是否影响相对运动」， 不要问「它重要不重要」—— 重要性是另一回事

    2.6 简图的一致性自检：三个必须对上的数¶

    真实项目中，简图画完之后还要做一次自检： 图上有几根线、几个符号，和准备代进公式的参数对得上吗？

    自检只有三句问话，画完简图就照着走一遍：

    自检项 怎么查 对不上的含义
    线条数 是否等于 \(l\) 数图上画了几条线 有构件被漏画或重复画 ⚠
    运动副符号数 是否等于 \(P_L + P_H\) 数图上画了几个圆圈、几个滑块、几个高副接触点 有副被漏标或类型判错 ⚠
    有没有孤立构件 每条线两端是否都接着运动副 有构件悬空，说明简图画错了 ⚠

    再补一句最容易漏的检查：

    同一个位置上，是不是挂了 3 个或更多构件？ 是 → 这里就是一个复合铰链，必须按 \(k - 1\) 个数转动副 ⚠

    手算示范：拿上面那个四杆机构走一遍。

    第一句：线条数 = 4，\(l = 4\)，对上

    第二句：图上 4 个小圆圈，\(P_L + P_H = 4 + 0 = 4\)，对上

    第三句：\(A\) 接机架与曲柄、\(B\) 接曲柄与连杆、\(C\) 接连杆与摇杆、 \(D\) 接摇杆与机架 —— 四条线两端全部接着副，没有孤立构件

    第四句：在每个铰点处数一数挂着的构件数：

    铰点 挂着的构件 个数 是不是复合铰链
    \(A\) 机架、曲柄 2 否
    \(B\) 曲柄、连杆 2 否
    \(C\) 连杆、摇杆 2 否
    \(D\) 摇杆、机架 2 否

    四处都是 2 个构件，没有复合铰链，所以 \(P_L = 1 + 1 + 1 + 1 = 4\)

    代公式收尾：

    \[F = 3(l - 1) - 2P_L - P_H = 3 \times 3 - 2 \times 4 - 0 = 1\]

    结论：需要 1 个原动件，机构才有确定运动

    这说明什么：这张四行的自检表，其实就是前面「六步法」第 6 步的展开。 它看起来像走过场，但第 4 句那句追问，是整页最容易丢分的地方 —— 复合铰链和虚约束都是在这一步被发现的，一旦漏掉， 后面所有的位置分析、轨迹、传动角都会建立在一个错误的 \(l\)、\(P_L\) 上

    下一节开始处理「算出来之后怎么用」——也就是运动轨迹。

    三、运动轨迹分析¶

    3.1 什么是轨迹¶

    轨迹：机构中某一点在运动过程中走过的曲线。

    要算轨迹，需要三个东西：

    需要的 说明
    一个驱动变量 比如曲柄转角 \(\theta_2\)，从 \(0^\circ\) 转到 \(360^\circ\)
    一套位置分析 给定 \(\theta_2\)，算出机构里所有点的位置
    一个取样步长 比如每 \(1^\circ\) 取一个点，一共取 361 个点

    注意这里的关键词是「点」：轨迹从来不是一条抽象的线， 它是一串坐标。算轨迹就是循环地算位置，把坐标存进列表

    3.2 为什么轨迹这么重要¶

    课件把「分析关键构件的运动轨迹」列进了每一道作业， 原因就是轨迹能直接回答三个工程问题：

    想知道的 轨迹怎么回答
    会不会干涉？ 轨迹曲线如果扫过机架或其他杆件的区域，就会撞 ⚠
    能不能满足工艺要求？ 工艺要求常写成「某点走一条近似的直线/圆弧」，直接拿轨迹比对 ✓
    工作空间有多大？ 轨迹的包围盒（能走到的范围）就是工作空间的估计 ✓

    3.3 两种轨迹的对比：简单的和复杂的¶

    同一个四杆机构里，不同点的轨迹复杂度差别极大：

    取哪一点 由谁决定 轨迹形状
    曲柄外端 \(B\) 只由曲柄长度和 \(\theta_2\) 决定 一个圆（半径为曲柄长）
    连杆上一点（如中点 \(M\)） 由五个杆长 + 装配方式共同决定 复杂封闭曲线 ✓

    「一个圆」好理解，因为曲柄是绕固定点的整周转动，端点到转轴的距离恒定不变。 「复杂曲线」正是连杆机构的价值所在：

    连杆机构能实现复杂运动，靠的就是连杆上某一点的轨迹是复杂曲线。 想要什么形状的轨迹，就去设计合适的杆长组合

    3.4 轨迹为什么要用余弦定理一步步推¶

    位置分析的思路（一句话）：给定 \(\theta_2\) 后点 \(B\) 就定了， 剩下的是一个已知三边的三角形 \(BCD\)（\(BD\) 的长度可算）， 用余弦定理求两次角，就能定出 \(C\) 的位置

    把它拆成不跳步的五步。 机构参数取

    符号 含义 数值
    \(a\) 曲柄长 \(AB\) 25 mm
    \(b\) 连杆长 \(BC\) 70 mm
    \(c\) 摇杆长 \(CD\) 60 mm
    \(d\) 机架长 \(AD\) 90 mm
    \(\theta_2\) 曲柄转角（驱动量） 待定

    约定：\(A\) 放在原点 \((0, 0)\)，\(D\) 放在 \((d, 0) = (90, 0)\)，机架沿 \(x\) 轴水平放。

    第 1 步：由驱动量定出 \(B\)。

    曲柄绕固定点 \(A\) 做整周转动，所以 \(B\) 一定落在以 \(A\) 为圆心、\(a\) 为半径的圆上：

    \[B = (a \cos \theta_2, \; a \sin \theta_2)\]

    这一步只用到了曲柄自己，跟其它三根杆完全无关

    第 2 步：算 \(BD\) 的长度。

    \[r = \lvert BD \rvert = \sqrt{(d - a \cos\theta_2)^2 + (0 - a \sin\theta_2)^2}\]

    把平方项展开：

    \[r^2 = d^2 - 2ad\cos\theta_2 + a^2\cos^2\theta_2 + a^2\sin^2\theta_2\]

    利用 \(\cos^2\theta_2 + \sin^2\theta_2 = 1\)：

    \[r^2 = a^2 + d^2 - 2ad \cos\theta_2\]

    为什么这个结果好记：它就是余弦定理 —— 三角形 \(ABD\) 中， 已知两边 \(a\)、\(d\) 和它们的夹角 \(\theta_2\)，求对边 \(r\)

    第 3 步：在三角形 \(BCD\) 里用余弦定理。

    三角形 \(BCD\) 的三边此时全部已知：\(BC = b\)，\(CD = c\)，\(BD = r\)。 要求的是 \(BC\) 与 \(BD\) 的夹角 \(\varphi\)：

    \[\cos \varphi = \frac{r^2 + b^2 - c^2}{2rb}\]

    为什么分母是 \(2rb\)：\(\varphi\) 的两条邻边是 \(BD = r\) 和 \(BC = b\)， 与 \(\varphi\) 相对的边是 \(CD = c\)，套余弦定理的标准形式 \(a^2 = b^2 + c^2 - 2bc\cos A\) 即可

    能不能解出来，看这一条：\(\lvert \cos\varphi \rvert \gt 1\) 时无解， 物理含义是这个位置根本装配不起来 —— 三根杆的长度凑不成一个三角形。

    第 4 步：把角叠加到方位角上，定出 \(C\)。

    先求 \(\vec{BD}\) 的方位角：

    \[\delta = \operatorname{atan2}(-a\sin\theta_2, \; d - a\cos\theta_2)\]

    \(BC\) 的方位角就是在这个基准上加或减 \(\varphi\)。取加号：

    \[\gamma = \delta + \varphi\]
    \[C = (a\cos\theta_2 + b\cos\gamma, \; a\sin\theta_2 + b\sin\gamma)\]

    为什么有两个解：\(\gamma = \delta + \varphi\) 与 \(\gamma = \delta - \varphi\) 都满足三边条件，它们对应两种装配方式 —— \(C\) 在 \(BD\) 的上方或下方。

    这是机构分析里最容易被忽略的一个岔口：同一个杆长组合、 同一个 \(\theta_2\)，可以有两种完全不同的位形。 分析时必须先确定装配方式并全程一致， 中途换解会让轨迹跳成另一条曲线

    第 5 步：求两个杆的方向角。

    \[\theta_3 = \angle(\vec{BC}), \qquad \theta_4 = \angle(\vec{DC})\]

    到此，位置分析完成：给定一个 \(\theta_2\)，就得到机构全部位形

    手算例题：取 \(\theta_2 = 0^\circ\) 走一遍。

    第 1 步：\(B = (25\cos 0^\circ, 25\sin 0^\circ) = (25, 0)\)

    第 2 步：\(r^2 = 25^2 + 90^2 - 2 \times 25 \times 90 \times \cos 0^\circ = 625 + 8100 - 4500 = 4225\)，所以 \(r = \sqrt{4225} = 65\) mm

    第 3 步：\(\cos\varphi = \dfrac{65^2 + 70^2 - 60^2}{2 \times 65 \times 70} = \dfrac{4225 + 4900 - 3600}{9100} = \dfrac{5525}{9100} \approx 0.60714\)

    \(\varphi = \arccos(0.60714) \approx 52.6168^\circ\)

    第 4 步：\(B\) 与 \(D\) 都在机架线上，\(\delta = \operatorname{atan2}(0, 65) = 0^\circ\)， 所以 \(\gamma = 0^\circ + 52.6168^\circ = 52.6168^\circ\)

    \(C = (25 + 70\cos 52.6168^\circ, \; 0 + 70\sin 52.6168^\circ) \approx (25 + 42.5000, \; 0 + 55.6215) = (67.5000, \; 55.6215)\)

    第 5 步：\(\theta_3 = 52.6168^\circ\)， \(\theta_4 = \operatorname{atan2}(55.6215, \; 67.5000 - 90) = \operatorname{atan2}(55.6215, \; -22.5000) \approx 112.0243^\circ\)

    核对：\(\lvert BC \rvert = \sqrt{(67.5-25)^2 + (55.6215-0)^2} = 70.0000\)， \(\lvert CD \rvert = \sqrt{(67.5-90)^2 + (55.6215-0)^2} = 60.0000\)

    这说明什么：整个位置分析里只用了一次余弦定理， 其余都是加减和坐标变换。四杆机构之所以能手算， 根本原因就是它的独立回路只有 1 个（见 §1.2）， 永远只需要解一个三角形 ✓

    3.5 为什么轨迹是复杂曲线，以及怎么判断干涉¶

    先回答第一个问题：为什么曲柄端走圆、连杆上的点走复杂曲线？

    看 \(B\) 的坐标公式：\(B = (a\cos\theta_2, a\sin\theta_2)\)。 两个分量分别是 \(\theta_2\) 的余弦和正弦，平方和为常数 \(a^2\)：

    \[x_B^2 + y_B^2 = a^2\cos^2\theta_2 + a^2\sin^2\theta_2 = a^2\]

    所以 \(B\) 一定落在半径为 \(a\) 的圆上。关键是：\(B\) 的表达式中 只有 \(\theta_2\) 一个变量，\(a\) 和 \(d\) 以外的杆长根本没出现

    再看连杆上任意一点 \(P\)。用参数 \(t\) 定位它在连杆上的位置：

    \[P = B + t(C - B), \qquad t = 0 \to B, \quad t = 1 \to C, \quad t = 0.5 \to \text{中点}\]

    把 \(B\) 和 \(C\) 的表达式代进去：

    \[P_x = a\cos\theta_2 + t\,b\cos\gamma, \qquad P_y = a\sin\theta_2 + t\,b\sin\gamma\]

    而 \(\gamma = \delta + \varphi\)，其中

    \[\delta = \operatorname{atan2}(-a\sin\theta_2, \, d - a\cos\theta_2), \qquad \cos\varphi = \frac{r^2 + b^2 - c^2}{2rb}\]

    注意 \(\delta\) 和 \(\varphi\) 里都含有 \(\theta_2\)，而且 \(\varphi\) 里还含 \(b\)、\(c\)。

    这就是复杂曲线的来源：\(P\) 的两个坐标里， 每一项都是 \(\theta_2\) 的复合函数 —— 一个反三角函数套着一个含 \(\theta_2\) 的分式，再取正弦或余弦。 这种表达式没有 \(\sin\theta\)、\(\cos\theta\) 那样的简单周期性， 所以画出来的封闭曲线既不是圆、也不是椭圆、也不是直线 ⚠

    下面这张图把上面这套推导画成了动画式的示意： 曲柄（最左边那条线）绕固定中心整周转， 通过连杆拖动滑块沿导轨往复移动， 虚点线画出的就是连杆中点走过的那条复杂封闭曲线：

    读图要抓住三件事，它们正好对应上面的公式：

    图上的东西 对应的式子 几何含义
    曲柄端点绕「曲柄中心」画的圆 \(B = (a\cos\theta_2,\ a\sin\theta_2)\) 只含 \(\theta_2\)，所以是标准圆 ✓
    连杆那条线，两端各一个铰点 \(P = B + t(C - B)\) 连杆上任何点都在这条线上
    滑块沿下方导轨往复 \(C\) 的坐标随 \(\theta_2\) 变 移动副把转动变成了直线移动 ⚠
    那条虚点线围成的环 \(P\) 的坐标含 \(\arcsin\)、\(\arccos\) 复合项 既不是圆也不是直线 ⚠

    「转动变成往复移动」的直观解释： 曲柄端点 \(B\) 在圆上跑，滑块被导轨约束成只能沿一条直线动， 两者被一根长度固定的连杆连着 —— 于是圆上的运动被「投影」到直线上，出来就是往复移动 ✓

    再回答第二个问题：怎么从轨迹判断干涉？

    干涉（杆件在运动中撞在一起）是简图上看不出来的， 但用轨迹可以查。判据分三层，从最粗到最细：

    层次 怎么判断 能发现什么 代价
    包围盒 算轨迹在 \(x\)、\(y\) 上的极值范围 工作端能不能够到工作区 ✓ 两个数就行
    与机架比 轨迹是否穿过机架线段所在的区域 工作端撞底板 ⚠ 一次比较
    与其它杆比 采样位置上，连杆线段与摇杆线段是否相交 杆与杆相撞 ⚠ 每个位置都要判

    第三层「两线段是否相交」的手算判据（考试也可能问到）：

    给定连杆线段 \(BC\) 与摇杆线段 \(CD\)，它们共用一个端点 \(C\)， 所以不需要做完整的线段相交测试 —— 只要检查 除了 \(C\) 之外，\(BC\) 上有没有别的点落在 \(CD\) 上。

    而 \(BC\) 上除 \(C\) 外的点是 \(B + t(C - B)\)，\(t \in [0, 1)\)。 它落在 \(CD\) 上，等价于 \(\theta_3\) 与 \(\theta_4\) 满足

    \[\theta_3 \equiv \theta_4 \pmod{180^\circ}\]

    也就是「连杆与摇杆共线」 —— 这正是 §4.6 要讲的死点位置 ✓

    这说明什么：轨迹分析和传动角分析不是两件独立的事。 从轨迹看是「两个线段撞了」，从传动角看是「\(\mu = 0\)」， 从机构的运动看是「推不动了」—— 同一件事的三种说法 ✓

    4.1 现实约束¶

    先说清楚一件事：不是所有环境都能装专业机构分析软件。 有的场合不能联网、不能买授权、不允许在机器上装额外的东西。

    但机构分析的核心计算，用几十行代码就能做 ✓ 这一节给出的四个工具，覆盖了课件要求你做的全部计算：

    4.2 工具 1：算自由度（含复合铰链与虚约束排查）¶

    工具 1 要解决的是自由度公式里最容易出错的两个地方：

    出错的根源 正确做法
    复合铰链：同一处连接了 \(k \ge 3\) 个构件 该处算 \(k - 1\) 个转动副 ✓
    虚约束：不起独立限制作用的重复约束 先把引入虚约束的副或链去掉，再数 ✓

    为什么复合铰链是 \(k-1\) 个转动副： \(k\) 个构件在同一处铰接，它们两两之间可以相对转动， 但把 \(k\) 个构件连成一个「铰链束」只需要 \(k-1\) 次连接， 每连接一次构成一个转动副 ✓

    为什么虚约束要先去掉再数：虚约束是重复的、不起独立限制作用的约束。 它不减少机构的实际运动能力，但公式会老老实实把它算进去， 于是 \(F\) 被算小 —— 极端情况会被算成 \(0\) ⚠

    下面把八种常见机构逐个手算一遍，和 §2.6 的自检表对照着看：

    # 机构 \(l\) \(P_L\) \(P_H\) \(F = 3(l-1) - 2P_L - P_H\) 驱动数
    ① 铰链四杆机构 4 4 0 \(3 \times 3 - 8 - 0 = 1\) 1 ✓
    ② 曲柄滑块机构 4 4 0 \(3 \times 3 - 8 - 0 = 1\) 1 ✓
    ③ 凸轮 + 尖顶从动件 3 2 1 \(3 \times 2 - 4 - 1 = 1\) 1 ✓
    ④ 齿轮机构（两轮 + 机架） 3 2 1 \(3 \times 2 - 4 - 1 = 1\) 1 ✓
    ⑤ 平面五杆机构 5 5 0 \(3 \times 4 - 10 - 0 = 2\) 2 ✓
    ⑥ 含复合铰链的六杆机构 6 7 0 \(3 \times 5 - 14 - 0 = 1\) 1 ✓
    ⑦ 含虚约束的机构（去约束后） 4 4 0 \(3 \times 3 - 8 - 0 = 1\) 1 ✓
    ⑧ 错法对照：⑥ 的复合铰链没拆开 6 6 0 \(3 \times 5 - 12 - 0 = 3\) 会误判成 3 ⚠

    逐行说明这张表怎么来的：

    ③ 凸轮 + 尖顶从动件：\(l = 3\)（凸轮、从动件、机架）， 凸轮与机架一个转动副、从动件与机架一个移动副，共 \(P_L = 2\)； 凸轮与从动件之间是点接触，算 \(P_H = 1\)。代入：

    \[F = 3 \times (3 - 1) - 2 \times 2 - 1 = 6 - 4 - 1 = 1\]

    ④ 齿轮机构：结构与 ③ 完全同构 —— 两个齿轮 + 机架， 两个转动副（\(P_L = 2\)）、一对轮齿啮合（\(P_H = 1\)），所以 \(F\) 同样是 1 ✓

    ⑤ 平面五杆机构：\(F = 2\)，意味着它需要两个驱动。 这是五杆与四杆最本质的差别，也是它常被用作两自由度机构（比如机械臂的平面部分）的原因 ✓

    ⑥ 含复合铰链的六杆机构：某铰点处挂着 3 个构件。 按 \(k = 3\) 处理，该处贡献 \(3 - 1 = 2\) 个转动副， 比「当作 1 个副」多出 1 个，所以 \(P_L = 6 + 1 = 7\)。代入：

    \[F = 3 \times (6 - 1) - 2 \times 7 - 0 = 15 - 14 = 1\]

    ⑦ 含虚约束的机构：这个例子最值得单独说。 不排查虚约束时，\(l = 5\)、\(P_L = 6\)：

    \[F = 3 \times (5 - 1) - 2 \times 6 = 12 - 12 = 0\]

    \(F = 0\)！按公式读，它是一个刚性结构，根本不能动 ⚠

    但把引入虚约束的那一部分（1 个构件、2 个低副）去掉之后：

    \[F = 3 \times (4 - 1) - 2 \times 4 = 9 - 8 = 1\]

    同一个机构，两种数法差了 1 个自由度。 如果不做排查，一个本来能动的机构会被直接判死 ⚠

    ⑧ 错法对照：把 ⑥ 的复合铰链照字面「只算 1 个副」， \(P_L\) 就少算 1，\(F\) 从 1 跳到 3：

    对比 复合铰链怎么处理 \(P_L\) \(F\) 后果
    ⑥ 正确 拆开：3 个构件 → 2 个转动副 7 1 配 1 个驱动 ✓
    ⑧ 错误 不拆：该处只算 1 个副 6 3 以为要配 3 个驱动 ⚠

    差了 2 个驱动。真按 ⑧ 去装，机构会被过约束卡死 ⚠

    这说明什么：自由度公式本身只有一项， 但喂给它的 \(l\)、\(P_L\)、\(P_H\) 才是关键。 复合铰链让 \(P_L\) 偏小、虚约束让 \(P_L\) 偏大， 一个把 \(F\) 抬高，一个把 \(F\) 压低 —— 两者方向相反，但都会让你得出错误结论 ✓

    再往下推一步：\(F\) 定下来之后，驱动数就定了。

    \[n_{\text{drive}} = F\]

    理由是：每个原动件提供 1 个独立的运动输入， 要确定机构的位置，独立输入数必须正好等于自由度数 ✓

    • \(F = 1\) → 装 1 个电机。装 2 个会互相打架，机构卡死 ⚠
    • \(F = 2\) → 必须装 2 个。只装 1 个，机构还有 1 个自由度没被约束， 各个构件的位置不确定，会乱动 ⚠
    • \(F = 0\) → 不是机构，是刚性结构，装多少个都动不了 ⚠

    自由度与驱动数这条链，是本页的主线

    简图 → 数 \(l\)、\(P_L\)、\(P_H\) → 算 \(F\) → 定驱动数

    这四步里，前两步是判断，第三步是算术，第四步是工程决策。 后面的位置分析、轨迹、传动角，都建立在「驱动数已经定对」的前提上 ✓

    所以拿到任何机构，先把这条链走完再动手算别的 ✓

    怎么用手算结果回答工程问题：

    • 想知道「需要几个电机」→ 直接看 \(F\) 这一格；
    • 想知道「为什么装了电机却卡死」→ 对比 ⑥ 和 ⑧ 两行， 看 \(P_L\) 差在哪里 ✓

    r"""平面机构自由度：F = 3(l-1) - 2*P_L - P_H。"""

def report(name, n_links, low_pairs, high_pairs, k_at_joint=None,
           virtual=None, p_drive=1):
    r"""打印一个机构的自由度分析。

    k_at_joint  复合铰链处挂着的构件数（此时 low_pairs 只算了 1 个副）
    virtual     按虚约束去掉的 (构件数, 低副数)（此时填未去掉时的数）
    """

    if k_at_joint is not None:
        low = low - 1 + (k_at_joint - 1)      # 把复合铰链拆开
        note += "（拆开 1 处复合铰链：%d 个构件 → %d 个副）" % (
            k_at_joint, k_at_joint - 1)
    if virtual is not None:
        dl, dp = virtual

    print("  F = 3*(%d-1) - 2*%d - %d = %d" % (l, low, high_pairs, F))

    elif p_drive == F:

def solve_fourbar(theta2_deg):
    r"""给定曲柄转角，返回 (连杆角, 摇杆角, BD 长度, C 点)。"""
    t2 = math.radians(theta2_deg)
    bx, by = a * math.cos(t2), a * math.sin(t2)
    r = math.hypot(d - bx, -by)                # 余弦定理：r^2 = a^2 + d^2 - 2ad cos
    cos_phi = (r * r + b * b - c * c) / (2.0 * r * b)
    if abs(cos_phi) > 1.0:
        return None                            # 三角形凑不起来：装配失败
    phi = math.acos(max(-1.0, min(1.0, cos_phi)))
    gamma = math.atan2(-by, d - bx) + phi
    cx, cy = bx + b * math.cos(gamma), by + b * math.sin(gamma)
    th3 = math.degrees(math.atan2(cy - by, cx - bx)) % 360.0
    th4 = math.degrees(math.atan2(cy, cx - d)) % 360.0
    return th3, th4, r, (cx, cy)

    但这个包围盒偏小。 因为只取了 \(45^\circ\) 一个步长， 峰和谷很可能落在两个采样点之间。把步长加密到每 \(1^\circ\) 一个点 （共 361 个位置），包围盒变成：

    方向 最小值 最大值 尺寸 与 \(45^\circ\) 步长相比
    \(x\) 6.2895 48.4371 42.1476 mm 大了 2.4564 mm ⚠
    \(y\) 2.8381 40.0664 37.2283 mm 大了 1.5908 mm ⚠

    差值就是采样太稀漏掉的峰 ⚠

    这是一条必须记住的规矩：报包围盒时， 必须说明采样步长。步长粗了报出来的工作空间是偏小的， 会让人误以为方案不可行 ✓

    为什么这个尺寸值得单独报：它是工作空间的直接估计。 如果工艺要求是「工作端在 \(x\) 方向移动 60 mm」， 看一眼 42.15 就知道不用算下去，这个杆长组合做不到 ✓

    这正是轨迹分析最大的工程价值：在造出实物之前就否掉不可行的方案。

    轨迹闭不闭合，也是一条自检： \(\theta_2 = 0^\circ\) 与 \(\theta_2 = 360^\circ\) 两点必须重合， 因为机构转满一圈回到原位。

    手算表首行 \(M = (46.2500, \; 27.8107)\)， 末行 \(M = (46.2500, \; 27.8107)\) —— 完全相同 ✓

    如果首末不重合，只有两种可能：采样区间没取满 \(360^\circ\)， 或者位置分析里漏了把角度归一化 ⚠

    对照曲柄外端 \(B\)：\(B\) 到固定铰点 \(A\) 的距离恒等于 \(a = 25\) mm， 所以 \(B\) 的轨迹就是一个半径 25 mm 的圆； 而连杆中点走出的是一条复杂封闭曲线 —— 两者完全不同 ✓

    4.6 工具 4：算传动角，找最小传动角与死点¶

    传动角是什么：机构运转时，连杆与从动件（摇杆）之间所夹的锐角， 通常记为 \(\mu\)。

    它的物理意义很直接：

    传动角 \(\mu\) 的大小 说明 后果
    接近 \(90^\circ\) 力的方向几乎垂直于从动件 同样的力产生最大力矩 ✓
    越来越小 力的方向越来越「顺着」杆件 有效力矩变小，效率低 ⚠
    等于 \(0^\circ\) 力完全顺着杆件，无法推动摇杆 死点，机构卡住 ⚠

    标准做法：曲柄转一整圈，找出 \(\mu\) 的最小值， 再对照设计准则判断能不能用。

    但转一整圈是机器的活，人只要抓关键位置。 下面推清楚「最小值出现在哪」。

    第一步：传动角是三角形 \(BCD\) 的一个内角。

    铰点 \(C\) 处连着三样东西：连杆 \(CB\)、摇杆 \(CD\)、以及它们之间的夹角。 由余弦定理，这个角完全由三边长决定：

    \[\cos\angle BCD = \frac{b^2 + c^2 - \lvert BD \rvert^2}{2bc}\]

    分母 \(2bc\) 是常数（\(b = 70\)、\(c = 60\) 都固定），所以 \(\cos\angle BCD\) 与 \(\lvert BD \rvert\) 是反向关系： \(\lvert BD \rvert\) 越大，\(\cos\angle BCD\) 越小，\(\angle BCD\) 越大 ✓

    第二步：\(\lvert BD \rvert\) 在什么位置取极值。

    由 §3.4 已推出的 \(r^2 = a^2 + d^2 - 2ad\cos\theta_2\)， \(r\) 只随 \(\cos\theta_2\) 变化：

    \(\theta_2\) \(\cos\theta_2\) \(r^2 = a^2 + d^2 - 2ad\cos\theta_2\) \(r = \lvert BD \rvert\)
    \(0^\circ\) \(+1\) \(625 + 8100 - 4500 = 4225\) \(d - a = 65\)（最小）
    \(90^\circ\) \(0\) \(625 + 8100 = 8725\) \(\sqrt{8725} \approx 93.41\)
    \(180^\circ\) \(-1\) \(625 + 8100 + 4500 = 13225\) \(d + a = 115\)（最大）

    所以 \(\lvert BD \rvert\) 的最大值 \(d + a = 115\) 出现在 \(\theta_2 = 180^\circ\) （曲柄与机架外共线），最小值 \(d - a = 65\) 出现在 \(\theta_2 = 0^\circ\) （曲柄与机架内共线）✓

    第三步：\(\angle BCD\) 最大 → 传动角（锐角）最小。

    传动角取锐角：\(\mu = \min(\angle BCD, \; 180^\circ - \angle BCD)\)。 所以 \(\angle BCD\) 最大时，\(\mu\) 最小 ✓

    第四步：手算 \(\theta_2 = 180^\circ\) 那一点。

    \(\theta_2 = 180^\circ\) 时 \(B = (-25, 0)\)，\(D = (90, 0)\)，两点都在机架线上，

    \[r = d + a = 90 + 25 = 115 \text{ mm}\]
    \[\cos\angle BCD = \frac{b^2 + c^2 - r^2}{2bc} = \frac{4900 + 3600 - 13225}{2 \times 70 \times 60} = \frac{-4725}{8400} = -0.5625\]
    \[\angle BCD = \arccos(-0.5625) \approx 124.2289^\circ\]
    \[\mu_{\min} = 180^\circ - 124.2289^\circ \approx 55.7711^\circ\]

    第五步：与准则比较。

    \[55.7711^\circ \gt 40^\circ \quad \Rightarrow \quad \text{传力性能可接受} \; ✓\]

    第六步：检查有没有死点。

    死点要求 \(\mu = 0\)，也就是连杆与摇杆共线，即

    \[\lvert BD \rvert = b + c = 130 \quad \text{或} \quad \lvert BD \rvert = \lvert b - c \rvert = 10\]

    而本机构的 \(\lvert BD \rvert\) 只能在 \(65\) 到 \(115\) 之间（见第二步那张表），

    \[65 \gt 10 \quad \text{且} \quad 115 \lt 130\]

    两个值都取不到，所以没有死点

    把整圈的关键位置列成一张手算对照表，不用扫描也能看全：

    \(\theta_2\) \(\lvert BD \rvert\) / mm \(\angle BCD\) 传动角 \(\mu\) 该位置的意义
    \(0^\circ\) 65.0000 59.4075° 59.4075° 内共线，\(\lvert BD \rvert\) 最小
    \(60^\circ\) 80.4674 76.0502° 76.0502° 一般位置
    \(90^\circ\) 93.4077 91.5350° 88.4650° \(\lvert BD \rvert\) 接近中值
    \(180^\circ\) 115.0000 124.2289° 55.7711° 外共线，\(\mu\) 取最小值 ⚠
    \(270^\circ\) 93.4077 91.5350° 88.4650° 与 \(90^\circ\) 关于机架镜像
    \(272.9^\circ\) ≈93.35 90.0182° 89.9818° \(\mu\) 取最大值（\(\angle BCD\) 最接近 \(90^\circ\)）

    这张表里有三个数要记住：\(\mu_{\min} = 55.7711^\circ\)（在 \(180^\circ\)）、 \(\mu_{\max} = 89.9818^\circ\)（在 \(272.9^\circ\)，不正好是 \(270^\circ\)）、 以及摇杆摆角 \(49.2751^\circ\)（从 \(\theta_4\) 的 \(104.3406^\circ\) 到 \(153.6157^\circ\)）。

    最小传动角是设计准则，不是「算出来看看」的参考值

    课件与设计手册对传动角有明确要求， 最常引用的下限是 \(40^\circ\)

    原因：传动角越小，同样大小的力能产生的力矩越小， 而且杆件与铰链上的反力会急剧增大，磨损加剧

    所以工具 4 的正确用法是：

    1. 先算出 \(\mu_{\min}\)；
    2. 再与准则比较；
    3. 不满足就回去改杆长，而不是「先用着」

    注意「刚好够」也不算够：本例算出的 \(\mu_{\min} = 55.77^\circ\) 离下限有 \(15^\circ\) 余量，属于安全的设计； 但如果算出 \(41^\circ\)，实际制造误差、装配偏差一叠加就会掉到下限以下 设计上通常要求留出至少 \(5^\circ \sim 10^\circ\) 的余量

    一个必须记住的对照关系（后面例题会用到）：

    传动角 发生在什么位置 说明
    \(\mu_{\min}\) 曲柄与机架共线的两个位置之一 设计工况，用来校核 ✓
    \(\mu = 0^\circ\) 连杆与摇杆共线 死点，机构失去传力能力 ⚠

    这说明什么：传动角分析不需要扫描整圈。 只要抓住「\(\lvert BD \rvert\) 的两个极端位置」， 就抓到了 \(\mu\) 的最小值 —— 两个手算点代替 3600 个机器点 这背后的依据是第三步那条单调关系： \(\lvert BD \rvert \uparrow \Rightarrow \angle BCD \uparrow \Rightarrow \mu \downarrow\)， 单调就只需要看端点

    4.7 完整流程演示：从简图数值到工程结论¶

    这一节把 §2 的简图和 §4 的分析串成一条线， 走一遍「读简图 → 算自由度 → 定驱动数 → 判能否用 → 下结论」：

    阶段 做什么 输入 输出 谁来做
    ① 读简图 数线条、数副符号 简图 \(l\)、\(P_L\)、\(P_H\) 人 ⚠
    ② 算自由度 代公式 \(l\)、\(P_L\)、\(P_H\) \(F\) 算术
    ③ 定驱动数 取 \(n = F\) \(F\) 电机个数 人判断
    ④ 位置分析 解三角形，扫满一圈 杆长、\(\theta_2\) 各点坐标 算术
    ⑤ 判可达性 看有没有装配失败 位置分析结果 曲柄能否整周转 人判断
    ⑥ 下结论 对照工艺要求 摆角、包围盒、\(\mu_{\min}\) 方案可行 / 要改 人 ⚠

    手工走一遍这个四杆机构（\(a=25\)、\(b=70\)、\(c=60\)、\(d=90\)）：

    ① 读简图：4 条线 → \(l = 4\)； 4 个小圆圈（\(A\)、\(B\)、\(C\)、\(D\)）→ \(P_L = 4\)； 没有高副 → \(P_H = 0\)； 四个铰点各挂 2 个构件，无复合铰链；无虚约束

    ② 算自由度：

    \[F = 3 \times (4 - 1) - 2 \times 4 - 0 = 9 - 8 = 1\]

    ③ 定驱动数：\(F = 1 \gt 0\)，

    \[n_{\text{drive}} = F = 1\]

    装 1 个电机即可；多装会过约束卡死，少装则运动不确定

    ④ 位置分析：把 \(\theta_2\) 从 \(0^\circ\) 扫到 \(360^\circ\)， 每一步解一次 §3.4 那五步。需要检查的是有没有解不出来的位置。

    判断依据：\(\theta_2 = 0^\circ\) 时 \(\lvert BD \rvert\) 最小为 \(65\)， \(\theta_2 = 180^\circ\) 时最大为 \(115\)。 三角形 \(BCD\) 能解出，要求三边长满足三角不等式：

    \[\lvert b - c \rvert \le \lvert BD \rvert \le b + c \qquad \Longrightarrow \qquad 10 \le \lvert BD \rvert \le 130\]

    本例的 \(\lvert BD \rvert \in [65, 115]\)，完全落在 \([10, 130]\) 内， 所以整圈 360 个位置全部有解 ✓

    这里顺便得到一个更强的结论：\(\lvert BD \rvert\) 能取到的最小值 \(65\) 大于 \(\lvert b - c \rvert = 10\)，最大值 \(115\) 小于 \(b + c = 130\)， 说明连杆与摇杆永远不可能共线 → 曲柄能整周转动， 机构属于曲柄摇杆机构 ✓

    ⑤ 判可达性：装配失败的位置数 = 0， 曲柄可以从 \(0^\circ\) 转到 \(360^\circ\) 全程有解 ✓

    ⑥ 下结论：摇杆摆角范围 \(104.3406^\circ \sim 153.6157^\circ\)， 摆角 \(49.2751^\circ\) —— 适合作摆动输出的场合 ✓

    把这段手算推导整理成一张结论表：

    结论编号 结论 依据
    ① 自由度为 1 \(F = 3(4-1) - 2 \times 4 = 1\)
    ② 配 1 个驱动 驱动数 = \(F\)
    ③ 曲柄整周可达 \([65, 115] \subset [10, 130]\)
    ④ 是曲柄摇杆机构 曲柄能整周转，摇杆只摆动
    ⑤ 摇杆输出约 49.3° 往复摆动 \(\theta_4\) 极值之差
    ⑥ 传力性能可接受 \(\mu_{\min} = 55.77^\circ \gt 40^\circ\)

    反过来，如果第 ④ 步出现解不出来的位置，结论就要整个改掉： 杆长组合不满足曲柄存在条件，曲柄无法整周转动，方案不可行 ⚠

    这张流程的价值：它把前面几页分散的概念 —— 构件、运动副、自由度、位置分析 —— 压成了一条任何人拿到机构都能照着走的路线 ✓

    4.8 用轨迹回答一个真实的工程问题：近似直线¶

    工程问题：设计一个机构，让工作端在某个行程里近似走直线 （很多送料、导向机构都要这个功能）。用四杆机构行不行？ 连杆上哪一点最合适？

    判据的量化：不能只说「看着挺直」。定义一个数：

    在一段连续采样里，取首末两点的连线作为弦， 所有点里离弦最大的距离记为 \(\Delta\)，弦长记为 \(L\)， 则相对直线度 \(= \Delta / L\)。这个值越小越直。

    这个判据的好处：它把「直不直」变成一个可以直接比较的数， 还能设阈值（比如要求优于 \(0.5\%\)）✓

    怎么算 \(\Delta\)：设弦的两端是 \((x_1, y_1)\) 与 \((x_2, y_2)\)， 测点 \((x, y)\) 到弦的垂直距离用叉积除以弦长：

    \[\Delta = \max_i \frac{\bigl\lvert (x_2 - x_1)(y_1 - y_i) - (x_1 - x_i)(y_2 - y_1) \bigr\rvert}{L}\]

    为什么要取最大值：直线度看的是最差的那一点， 不是平均值 —— 工件在中间某一处偏出去，就是不合格 ⚠

    在不同 \(t\) 上取点，分别算最优段。 窗口取连续 61 个采样点 （对应曲柄转 \(60^\circ\)），只保留弦长大于 \(20\) mm 的段：

    参数 \(t\) 起点曲柄角 终点曲柄角 最大偏离 \(\Delta\) / mm 相对直线度
    0.00（\(B\) 点） 211° 271° 3.3494 13.3975%
    0.25 295° 355° 2.0905 8.2986%
    0.50（中点） 298° 358° 0.8380 3.2897%
    0.62 300° 360° 0.2216 0.8631%
    0.75 276° 336° 0.1000 0.4151%
    0.88 259° 319° 0.2382 1.1869%
    1.00（\(C\) 点） 129° 189° 0.8433 4.2062%
    1.25 54° 114° 0.2162 1.0226%
    1.50 69° 129° 0.1683 0.6704%
    1.62 103° 163° 0.1127 0.4499%
    1.75 90° 150° 0.0428 0.1608% ✓
    1.88 90° 150° 0.2187 0.8159%
    2.00 89° 149° 0.4377 1.6168%

    从这张表读出的三件事：

    1. 最优取点是 \(t = 1.75\)，对应曲柄行程 \(90^\circ \to 150^\circ\)（共 \(60^\circ\)）；
    2. 最大偏离 \(0.0428\) mm，弦长 \(26.6312\) mm， 相对直线度 \(0.1608\%\)，优于 \(0.5\%\) 的判据要求 ✓
    3. 取点选错代价极大：直接用中点（\(t = 0.50\)）时， 最优段的相对直线度是 \(3.2897\%\)， 比 \(t = 1.75\) 的结果差约 20 倍 ⚠

    为什么 \(t = 1.75\) 是个「连杆外延点」也合理： \(t \gt 1\) 表示这个点不在 \(B\) 与 \(C\) 之间，而是从 \(B\) 越过 \(C\) 再延长 \(0.75 b\)。 连杆机构里这种外延点（常叫连杆曲线的取值点）恰恰是专门用来 「凑」想要的轨迹形状的 —— 这也是直线导引机构的基本手法 ✓

    这说明什么：四杆机构可以做出近似直线段， 但必须精心挑选连杆上的取点。 选错点（比如想当然地用中点），直线度会差一个数量级以上。 而这个问题靠肉眼看图是绝对看不出来的 —— 图的纵向尺度被压缩后，\(0.04\) mm 和 \(0.84\) mm 看起来一样直 ⚠ 这正是「轨迹分析必须算，不能只看」的根本原因 ✓

    把「工程要求」翻译成「判据」，是分析的第一步

    这一段最值得学的不是算式，而是那个判据的定义。

    工程师说「要近似直线」，机器听不懂。你必须把它翻译成：

    工程语言 可计算的判据
    走得直不直 相对直线度 \(\Delta / L\)，要求小于某个阈值 ✓
    行程有多长 弦长 \(L\) ✓
    覆盖多宽的区间 起止曲柄角之差 ✓

    翻译这一步只有人能做，翻译对了，后面的计算才有用武之地 ✓

    再补一句：判据必须带数值阈值。 「近似直线」不是判据，「相对直线度优于 \(0.5\%\)」才是 ✓

    5.3 工作流的「回路」性质：不合格就回去改¶

    注意流程图最后那个回头箭头。这是机构设计最重要的性质：

    分析不是一次过的，而是反复迭代的。

    迭代原因 改什么 怎么看
    传动角太小 加长摇杆或缩短连杆 工具 4 的 \(\mu_{\min}\) ✓
    轨迹不满足工艺 换连杆上的取点 \(t\)，或改杆长 工具 3 的轨迹 ✓
    工作空间不够 改杆长（尤其曲柄和机架） 工具 3 的包围盒 ✓
    装不上驱动 检查自由度与驱动数是否匹配 工具 1 的报告 ✓

    每一次迭代的成本很低（改几个数、跑一遍代码）， 这正是用代码做分析的最大优势： 试二十种杆长组合只要几秒，而做二十个实物样机是不可能的 ✓

    这是本页最想强调的一句话，单独用一段说清楚：

    工具只加速计算，判断对不对还是靠人。 ⚠

    具体到每一步：

    概念 工具代替不了什么
    构件 哪些零件该合并成一个构件，工具不知道 ⚠

    七、用工具容易犯的三个错¶

    7.1 错法一：直接把 CAD 图当简图用¶

    表现：把三维装配图打开，对着屏幕上的零件数构件； 或者把 CAD 里的零件清单直接当作构件清单。

    为什么错：CAD 图是零件级的，简图是构件级的。 两者之间差着「合并刚接件」这一步 ⚠

    CAD 里看到的 简图里应该是 差多少
    底板、电机外壳、4 个地脚螺栓 1 个机架 少 5 个
    连杆体、连杆盖、2 螺栓、2 轴瓦 1 个连杆 少 5 个
    摇杆、销轴、工作台 1 个摇杆 少 2 个

    后果：构件数 \(l\) 从 4 变成 16 以上， 自由度算出来大得离谱， 于是你会得出「这个机构需要十几个电机」的荒谬结论 ⚠

    7.2 错法二：相信工具算出的自由度而不检查¶

    表现：输入一串数字，工具输出 \(F = 3\)，就直接写进报告。

    为什么错：工具只做算术，不做判断。 它不知道你数进去的那个「1 个转动副」其实是个挂了三根杆的复合铰链 ⚠

    必须自己检查的三件事：

    检查项 怎么查 不查的后果
    复合铰链 逐个铰点问「这里挂了几个构件」 \(F\) 偏大 ⚠
    虚约束 问「这个约束有独立限制作用吗」 \(F\) 偏小甚至为 0 ⚠
    局部自由度 问「有没有滚子、滚珠这类不影响整体运动的部件」 \(F\) 偏大 ⚠

    一个可靠的判断信号：如果算出的 \(F\) 与你的直觉严重不符 （比如一个明显能动的四杆机构算出 \(F = 0\)）， 不要怀疑直觉，先回去重数 ✓

    7.3 错法三：只画图不做数值验证¶

    表现：简图画得很漂亮，运动看着也顺畅，就交差了。

    为什么错：图纸上的「看着没问题」和数值上的「真的没问题」是两回事 ⚠ 平面图看不出下面这些：

    杆件在中途撞在一起（干涉） 工具 3 的轨迹是否穿过其他构件 ✓

    三个错看起来不一样，根子却是同一个：

    错法 共同点

    典型例题¶

    例题 1：含复合铰链的机构，自由度是多少¶

    一个六杆机构，简图上数出 \(l = 6\)，各铰点挂着的构件数是： \(A\) 处 2 个、\(B\) 处 2 个、\(C\) 处 4 个、\(D\) 处 2 个、\(E\) 处 2 个。 全是转动副，没有高副。求 \(F\)，并说明该配几个驱动。

    思路

    关键是 \(C\) 处那个数字 4：它已经说明这是一处复合铰链 ⚠

    千万不要把「数出来的铰点个数 5」当作 \(P_L\)。 正确做法是逐个铰点套用那条规则：

    \(k\) 个构件在同一处以转动副相连 → 该处有 \(k - 1\) 个转动副

    把每个铰点贡献的副数加起来，才是 \(P_L\) ✓

    解答

    第一步：逐个铰点拆出转动副个数。

    铰点 挂着几个构件 该处的转动副个数
    \(A\) 2 1
    \(B\) 2 1
    \(C\) 4 3 ⚠
    \(D\) 2 1
    \(E\) 2 1
    合计 —— \(P_L = 7\)

    第二步：代公式。

    \[F = 3(l-1) - 2P_L - P_H = 3 \times 5 - 2 \times 7 - 0 = 15 - 14 = 1\]

    第三步：确定驱动数。

    \(F = 1 \gt 0\)，机构能动；应配 1 个原动件，运动才确定 ✓

    错法对照：如果把 \(C\) 处只算 1 个副， \(P_L\) 就变成 5，算出 \(F = 15 - 10 = 5\) ⚠

    这个错误值比正确值 大了 4，会让你以为要多装 4 个电机。 真装了，机构会被过约束卡死。

    第四步：改用「铰点数」的错误数法对照一遍。

    如果不逐个铰点套规则，而是把「图上数出 5 个铰点」直接当作 \(P_L\)：

    \[F_{\text{错}} = 3 \times 5 - 2 \times 5 - 0 = 15 - 10 = 5\]
    数法 \(P_L\) \(F\) 该配几个驱动 后果
    正确：逐个铰点算 \(k - 1\) 7 1 1 个 ✓ 运动确定
    错误：把铰点数当 \(P_L\) 5 5 ⚠ 会以为要 5 个 过约束卡死 ⚠

    差出来的 4 个自由度，全部来自 \(C\) 处那一个复合铰链： 该处挂了 4 个构件，正确算法给 \(4 - 1 = 3\) 个副， 错误算法只给 1 个，正好少 2 个副， 而每个低副约束 2 个自由度，\(2 \times 2 = 4\) ✓

    这说明什么：复合铰链的误差是成倍放大的， 因为它同时影响 \(P_L\) 和 \(F\) 两个量， 而且放大倍数正好是「每个低副约束的自由度数」= 2 ⚠

    例题 2：手算一个位置，再用代码核对¶

    四杆机构，杆长 \(a = 25\)、\(b = 70\)、\(c = 60\)、\(d = 90\)（mm）， 机架 \(AD\) 水平放置。求曲柄角 \(\theta_2 = 90^\circ\) 时的连杆角 \(\theta_3\)、摇杆角 \(\theta_4\)。

    思路

    分三步走，每一步都只用一个三角形：

    1. 由 \(\theta_2\) 定出点 \(B\) 的坐标（曲柄是绕 \(A\) 的圆周运动）；
    2. 三角形 \(BCD\) 的三边都已知（\(\lvert BD \rvert\) 用两点距离算）， 用余弦定理求角 \(\angle CBD\)；
    3. 把 \(\angle CBD\) 叠加到向量 \(\vec{BD}\) 的方位角上， 就得到 \(BC\) 的方向，从 \(B\) 走 \(b\) 就到 \(C\) ✓

    最后一定要用「\(\lvert BC \rvert\) 应等于 \(b\)、\(\lvert CD \rvert\) 应等于 \(c\)」核对一遍 ✓

    解答

    第一步：点 \(B\) 的坐标。

    \[B = (a\cos 90^\circ,\ a\sin 90^\circ) = (0,\ 25)\]

    第二步：求 \(\lvert BD \rvert\)。

    \[\vec{BD} = (90 - 0,\ 0 - 25) = (90,\ -25)\]
    \[\lvert BD \rvert = \sqrt{90^2 + (-25)^2} = \sqrt{8100 + 625} = \sqrt{8725} \approx 93.4077\ \text{mm}\]

    第三步：余弦定理求 \(\angle CBD\)。

    \[\cos \angle CBD = \frac{\lvert BD \rvert^2 + b^2 - c^2}{2 \lvert BD \rvert b} = \frac{8725 + 4900 - 3600}{2 \times 93.4077 \times 70} \approx 0.7666\]
    \[\angle CBD = \arccos(0.7666) \approx 39.9497^\circ\]

    第四步：求 \(BC\) 的方位角并定出 \(C\)。

    \(\vec{BD}\) 的方位角 \(= \arctan_2(-25,\ 90) \approx -15.5241^\circ\)， 所以 \(BC\) 的方位角 \(= -15.5241^\circ + 39.9497^\circ = 24.4256^\circ\)。

    \[C = (0 + 70\cos 24.4256^\circ,\ 25 + 70\sin 24.4256^\circ) \approx (63.7349,\ 53.9458)\]

    第五步：求两个角。

    \[\theta_3 = \angle(\vec{BC}) = 24.4256^\circ\]
    \[\theta_4 = \arctan_2(53.9458,\ 63.7349 - 90) = \arctan_2(53.9458,\ -26.2651) \approx 115.9605^\circ\]

    第六步：核对。

    核对量 实算 应为
    \(\lvert BC \rvert\) 70.000000 70.0 ✓
    \(\lvert CD \rvert\) 60.000000 60.0 ✓

    下面把整个手算过程再走一遍，并顺手完成核对：

    第一步：点 \(B\) 的坐标。 \(\theta_2 = 90^\circ\) 时

    \[B = (25\cos 90^\circ, \; 25\sin 90^\circ) = (0, \; 25)\]

    第二步：求 \(\lvert BD \rvert\)。

    \[\vec{BD} = (90 - 0, \; 0 - 25) = (90, \; -25)\]
    \[\lvert BD \rvert = \sqrt{90^2 + (-25)^2} = \sqrt{8100 + 625} = \sqrt{8725} \approx 93.4077 \text{ mm}\]

    第三步：余弦定理求 \(\angle CBD\)。

    \[\cos\angle CBD = \frac{r^2 + b^2 - c^2}{2rb} = \frac{8725 + 4900 - 3600}{2 \times 93.4077 \times 70} \approx 0.766608\]
    \[\angle CBD \approx 39.9497^\circ\]

    第四步：求 \(BC\) 的方位角并定出 \(C\)。

    \(\vec{BD}\) 的方位角 \(\delta = \operatorname{atan2}(-25, \; 90) \approx -15.5241^\circ\)，所以

    \[\gamma = -15.5241^\circ + 39.9497^\circ = 24.4256^\circ\]
    \[C = (70\cos 24.4256^\circ, \; 25 + 70\sin 24.4256^\circ) \approx (63.7349, \; 53.9458)\]

    第五步：求两个杆的方向角。

    \[\theta_3 = 24.4256^\circ\]
    \[\theta_4 = \operatorname{atan2}(53.9458, \; 63.7349 - 90) = \operatorname{atan2}(53.9458, \; -26.2651) \approx 115.9605^\circ\]

    第六步：核对。

    核对量 实算 应为 结论
    \(\lvert BC \rvert\) 70.000000 70.0 相符 ✓
    \(\lvert CD \rvert\) 60.000000 60.0 相符 ✓

    这六步与 §4.2b 表里 \(\theta_2 = 90^\circ\) 那一行完全对上 （\(\theta_3 = 24.4256^\circ\)、\(\theta_4 = 115.9605^\circ\)）， 说明整条位置分析链是自洽的 ✓

    这说明什么：手算和迭代计算给出的数必须一致。 不一致时，先怀疑自己手算时用的装配方式（\(\gamma = \delta + \varphi\) 还是 \(\gamma = \delta - \varphi\)）与计算时用的一致不一致 ⚠ 这是位置分析最常见的错源。

    例题 3：手算最小传动角，再用整周扫描核对¶

    同一个机构（\(a = 25\)、\(b = 70\)、\(c = 60\)、\(d = 90\)）。 已知最小传动角出现在曲柄与机架共线的位置，用手算求出它，再用整周扫描核对。

    思路

    传动角是连杆与摇杆之间的锐角，它是三角形 \(BCD\) 的一个内角。

    由余弦定理，\(\angle BCD\) 完全由三边长 \(b\)、\(c\)、\(\lvert BD \rvert\) 决定：

    \[\cos \angle BCD = \frac{b^2 + c^2 - \lvert BD \rvert^2}{2bc}\]

    所以传动角随 \(\lvert BD \rvert\) 单调变化：

    • \(\lvert BD \rvert\) 最长时（曲柄与机架外共线，即 \(\theta_2 = 180^\circ\)）→ 夹角最大；
    • 夹角越大，取锐角后的传动角越小 ⚠

    因此只需手算 \(\theta_2 = 180^\circ\) 这一个位置，就找到了最小值 ✓

    解答

    第一步：求这个位置的 \(\lvert BD \rvert\)。

    \(\theta_2 = 180^\circ\) 时，\(B = (-25,\ 0)\)，与 \(D = (90, 0)\) 都在机架线上：

    \[\lvert BD \rvert = d + a = 90 + 25 = 115\ \text{mm}\]

    第二步：余弦定理求铰点 \(C\) 处的夹角。

    \[\cos \angle BCD = \frac{b^2 + c^2 - \lvert BD \rvert^2}{2bc} = \frac{4900 + 3600 - 13225}{2 \times 70 \times 60} = \frac{-4725}{8400} = -0.5625\]
    \[\angle BCD = \arccos(-0.5625) \approx 124.2289^\circ\]

    第三步：取锐角作为传动角。

    \[\mu = 180^\circ - 124.2289^\circ \approx 55.7711^\circ\]

    结论：\(\mu_{\min} \approx 55.77^\circ\)， 大于常用的 \(40^\circ\) 下限，传力性能可接受

    另外，\(\mu = 0\) 需要连杆与摇杆共线（即 \(\lvert BD \rvert = b + c = 130\) 或 \(\lvert BD \rvert = \lvert b - c \rvert = 10\)）， 而本机构的 \(\lvert BD \rvert\) 只在 \(65\) 到 \(115\) 之间， 取不到这两个值，所以没有死点

    下面把「整周扫描」这一步的结论列出来做核对。 扫描步长取 \(0.01^\circ\)，共 36000 个位置：

    扫描项 结果 与手算比较
    最小传动角 55.7711° 与手算 完全相同 ✓
    出现位置 曲柄角 180.0° 正是曲柄与机架外共线的位置 ✓
    铰点 \(C\) 处夹角范围 59.4075° ~ 124.2289° 上界就是手算的 124.2289° ✓
    传动角范围 55.7711° ~ 89.9818° 下界就是手算的 \(\mu_{\min}\) ✓
    死点数 0 个 与「取不到 10 和 130」的判断一致 ✓

    手算给出的 55.7711° 与扫描给出的最小值一模一样， 而且最小值出现的位置也正是手算选定的那个共线位置 —— 说明「传动角随 \(\lvert BD \rvert\) 单调变化」这条推理是成立的

    这说明什么：如果手算选的不是共线位置（比如随便取 \(\theta_2 = 90^\circ\)）， 算出来的 \(\mu\) 是 \(88.4650^\circ\)，比真值大了三十多度， 会得出「传动角余量很大」的错误结论 关键位置的选取本身，就是手算的核心技能。

    自测¶

    Q1 判断对错并说明理由：

    （a）画机构简图时，应该按零件个数画线条。 （b）机构简图上的线条长度可以随手画，只要形状像就行。 （c）只要把机构输入工具，工具算出来的自由度一定正确。

    答案

    （a）错

    简图上的线条代表构件，不是零件。 刚性连接在一起、彼此没有相对运动的零件要合并成一个构件。 上文的例子是：16 个零件 → 4 个构件。

    按零件数画，构件数会大好几倍，自由度算出来完全错

    （b）错

    简图要按比例画。原因：简图是用来做位置分析的， 杆长比例错了，算出来的轨迹、传动角、工作空间全错。

    这里的「按比例」不是要求画得多漂亮， 而是要求图上各条线的长度之比等于实际杆长之比

    （c）错

    工具只做算术，不做判断。它算的是你喂给它的模型：

    • 有没有复合铰链没拆开 —— 工具不知道
    • 有没有虚约束没去掉 —— 工具不知道
    • 有没有局部自由度（滚子之类）—— 工具不知道

    输入模型错了，工具会又快又准地给出错误答案

    Q2 一个四杆机构，\(a = 25\)、\(b = 70\)、\(c = 60\)、\(d = 90\)（mm）。 请说明：

    （a）\(F\) 是多少，需要几个驱动； （b）如果想让工作端沿 \(x\) 方向行程达到 \(60\) mm（取连杆中点），这个方案行不行； （c）如果不行，你打算先改哪个杆长，为什么。

    提示

    （a）数 \(l\)、\(P_L\)、\(P_H\) 后直接套公式。 （b）用工具 3 算包围盒，用 \(x\) 方向的宽度与 \(60\) mm 比较。 （c）想一想曲柄转角整周变化时，谁的贡献让连杆中点沿 \(x\) 方向来回移动。

    答案

    （a）自由度与驱动数。

    \(l = 4\)（3 个活动构件 + 机架），\(P_L = 4\)（\(A\)、\(B\)、\(C\)、\(D\)），\(P_H = 0\)：

    \[F = 3(4-1) - 2 \times 4 - 0 = 9 - 8 = 1\]

    \(F = 1 \gt 0\)，机构能动；应配 1 个原动件

    （b）行程够不够。

    用位置分析扫一圈算包围盒，\(x\) 方向的宽度是 42.1803 mm（见例题 4）。

    \[42.1803 \lt 60\]

    不够，差约 \(17.82\) mm，方案不可行

    （c）先改哪个杆长，为什么。

    优先加长曲柄 \(a\)

    理由：连杆中点的 \(x\) 坐标里，点 \(B\) 的贡献是 \(a\cos\theta_2\)， 它随 \(\theta_2\) 整周变化，直接贡献 \(2a\) 的 \(x\) 方向摆幅。

    所以 \(a\) 从 \(25\) 增到约 \(34\) 时，\(x\) 方向能多出约 \(18\) mm， 正好补上缺口。

    但要注意两点：

    1. 加长 \(a\) 会同时改变传动角 ⚠ —— 必须回到工具 4 复核 \(\mu_{\min}\) 是否仍在 \(40^\circ\) 以上；
    2. 加长 \(a\) 后要重新检查是否仍满足曲柄存在条件 （\(a\) 是最短杆时，还要看 \(a + d\) 与 \(b + c\) 的关系）。

    这正是 §5.3 讲的迭代：改一个参数，就要把整条工作流重走一遍

    Q4 用工具算出的轨迹「看着很直」，为什么还不能直接说满足工艺要求？ 请写出你至少要报告的三个数。

    答案

    为什么不能凭「看着很直」下结论：

    1. 看图没有尺度 ⚠ —— 图上 1 mm 的偏差和 10 mm 的偏差看起来差不多， 而工程上两者是完全不同的结论；
    2. 不知道判据的阈值 ⚠ —— 工艺要求通常写成「直线度优于 \(0.5\%\)」 这类量化指标，必须换算成数才能比；
    3. 不知道适用区间 ⚠ —— 「直」只在一段行程里成立， 必须说清这一段对应曲柄的哪一段角度 ✓

    至少要报告的三个数（对应 §4.8 的判据）：

    要报告的数 它回答什么 本页例子里的值
    相对直线度 \(\Delta / L\) 到底有多直 \(0.1608\%\)（要求优于 \(0.5\%\)）✓
    弦长 \(L\) 这一段行程有多长 \(26.6312\) mm
    起止曲柄角 这一段对应哪段驱动区间 \(90^\circ\) 到 \(150^\circ\)

    再加一个责任性的数字：取点参数 \(t\)（这里是 \(1.75\)）。

    因为同一条连杆上，不同 \(t\) 的直线度差别极大 —— 本例中 \(t = 0.5\)（中点）的最优段相对直线度是 \(3.2897\%\)， 比 \(t = 1.75\) 差了约 83 倍

    当曲柄在 \(90^\circ \sim 150^\circ\) 之间转动时， 连杆上 \(t = 1.75\) 处的点走出一段长 \(26.63\) mm、 相对直线度 \(0.16\%\) 的近似直线

    这样一句话，别人可以照着复现，也可以拿去和工艺要求比

    小结¶

    这一页的主线只有一条：简图 → 自由度 → 驱动数。 先把这条链走对，位置分析、轨迹、传动角才有意义。

    要记住的 为什么
    工具替你算，不替你判断 构件怎么合并、副是什么类型、机架是谁，工具都不知道 ⚠
    手算适合简单机构 四杆、曲柄滑块只要解一个三角形
    机构一复杂（多杆、多环、含高副）手算量剧增 回路数每加 1，就多联立 2 个三角方程，还要顺序求解 ⚠
    五杆机构的手算量和四杆一样 \(l\) 与 \(P_L\) 同步加 1，回路数不变 ✓
    手算的难点在方程之间的依赖，不在单个方程 第三环之后误差会沿回路链放大 ⚠
    工具的四大价值：画简图、算自由度、算轨迹、看干涉 分别对应四类工程问题 ✓
    机构简图 = 线 + 运动副符号 只保留「刚性距离」与「可相对运动」两件事
    为什么必须先画简图 实物有厚度、倒角、无关零件，直接看实物数构件一定错 ⚠
    画简图六步：分固定件 → 并刚接件 → 画线 → 标符号 → 标机架 → 数并代公式 第 2 步与第 6 步最容易错
    合并刚接件的唯一问句：这两个零件之间有相对运动吗 没有就属于同一个构件 ✓
    标准符号只有三个：转动副画小圆圈、移动副画滑块、高副画接触轮廓 记住这三个就不会判错类型 ✓
    零件数 ≠ 构件数 上文的例子里是 16 个零件 → 4 个构件
    简图自检四句问话 线条数 = \(l\)？符号数 = \(P_L+P_H\)？有没有孤立构件？有没有挂 3 个构件的铰点？⚠
    位置分析只需解一个三角形 因为四杆机构的独立回路只有 1 个 ✓
    位置分析必须验证 用「每根杆的两点距离应等于名义杆长」核对 ✓
    位置分析只有三个数真正要算对：\(r\)、\(\varphi\)、\(\delta\) 其余都是加减与取正弦余弦
    同一 \(\theta_2\) 有两个装配解 \(\gamma = \delta \pm \varphi\)；中途换解会让轨迹跳成另一条曲线 ⚠
    轨迹是「一串坐标」，不是一条抽象的线 算轨迹就是循环算位置
    曲柄端走圆，连杆上的点走复杂曲线 \(B\) 的坐标只含 \(\theta_2\)，\(P\) 的坐标含反三角复合项 ✓
    轨迹一定要报包围盒，并说明采样步长 步长粗了报出的工作空间偏小 ⚠
    轨迹首末必须重合 \(\theta_2\) 转满 \(360^\circ\) 回到原位，不重合说明漏了角度归一化 ⚠
    干涉的量化判据是 \(\theta_3 \equiv \theta_4 \pmod{180^\circ}\) 也就是连杆与摇杆共线，与死点是同一件事 ✓
    四条最小工具：算自由度、位置分析、算轨迹、算传动角 覆盖课件要求的全部计算动作 ✓
    复合铰链：\(k\) 个构件 → \(k-1\) 个转动副 同一处挂 3 个以上构件就要拆
    虚约束：先去掉重复约束再数 不去掉会让 \(F\) 偏小甚至算成 0 ⚠
    \(F\) 定下来，驱动数就是 \(F\) \(F=1\) 装 1 个；\(F=2\) 必须装 2 个；\(F=0\) 装几个都不动 ⚠
    传动角取锐角；\(\mu = 0\) 就是死点 死点出现在连杆与摇杆共线的位置
    \(\mu_{\min}\) 只需要手算共线的两个位置 因为 \(\angle BCD\) 随 \(\lvert BD \rvert\) 单调，单调只需看端点 ✓
    最小传动角要和 \(40^\circ\) 这类准则比较，不是算着看 不满足就回去改杆长，而不是先用着 ⚠
    设计上要留 \(5^\circ \sim 10^\circ\) 余量 「刚好够」会被制造误差吃掉 ⚠
    近似直线的判据是相对直线度 \(\Delta / L\) 「看着很直」不是判据，带阈值的数才是 ✓
    连杆取点 \(t\) 是设计轨迹的关键旋钮 本例 \(t=1.75\) 比中点 \(t=0.5\) 的直线度好约 20 倍 ⚠
    工作流：实物 → 简图 → 数 l、P_L、P_H → 算 F → 定驱动数 → 位置分析 → 验证工艺 这是本章最有价值的归纳 ✓
    工作流是迭代的：不满足就回去改杆长 试二十种杆长组合只要几秒，做二十个样机不可能 ✓
    工具只分四类：通用数值计算环境、机构专用仿真工具、多体动力学工具、通用 CAD 先判断「我需要哪一类」
    通用 CAD 不做运动学自动求解 它擅长装配与干涉检查，不擅长自动算自由度 ⚠
    不管用什么工具，构件、运动副、自由度必须先掌握 工具只加速计算，判断对不对还是靠人 ✓
    三个错：拿 CAD 图当简图、相信工具算的自由度、只画图不验证 共同点是把「看到的」当成「该数的」⚠
    CAD 是零件级的，简图是构件级的 两者之间差着「合并刚接件」这一步
    结果与直觉严重不符时，先回去重数 \(F\) 偏大通常是漏了复合铰链，\(F\) 偏小通常是没去虚约束 ⚠
