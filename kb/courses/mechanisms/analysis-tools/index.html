    机构分析工具¶

    这一页是第 1 章的最后一页，它回答一个问题：拿到一个机构，具体该怎么做分析？

    前面几页把概念一个个拆开讲完了：构件、运动副、运动链、机构、自由度、常用传动、 平面连杆。但真要动手分析一个真实的机械装置时，这些概念要怎么串成一条 可执行的动作？

    本课程课件在章末给出的答案是：先画机构简图，再用工具把运动算出来 ✓

    看起来差不多 实际差别 后果
    看实物数零件 机构分析数的是构件（运动单元） 自由度算大一截 ⚠
    凭印象画一张示意图 简图必须用标准运动副符号、按比例 运动副类型判错，公式代错 ⚠
    用工具拖一拖，看着能动 工具也要先给对输入模型 输入错了，工具给不出对答案 ⚠
    画完图就交差 还要做数值验证（轨迹、传动角） 图上看着没问题，实际够不到 ⚠

    这一页的核心问题

    工具能替你算什么，不能替你算什么？

    一句话回答：工具替你算，不替你判断 ✓

    所以本页的顺序是：

    1. 先讲简图怎么画（这是判断，只有人能做）；
    2. 再讲工具怎么算（这是计算，机器比人快）；
    3. 最后用四件最小工具、几个完整例子， 把「判断 + 计算」串成一条能反复使用的工作流 ✓

    本页面对的现实约束很明确：不是所有环境都能装专业机构分析软件。 因此本页的重点不是「介绍某款工具」，而是 用几十行代码把工具的核心能力自己实现出来 ✓

    一、为什么需要工具，而不是只用纸笔¶

    1.1 手算能撑到多复杂¶

    先明确一件事：手算不是不行，手算能用的范围其实比想象的宽。

    课件里出现的四杆机构、曲柄滑块机构，用手算完全做得下来：

    机构 手算难度 为什么
    四杆机构自由度 极低 数出 \(l = 4\)、\(P_L = 4\)、\(P_H = 0\)，代一次公式
    曲柄滑块机构自由度 极低 同样是 \(l = 4\)、\(P_L = 4\)
    四杆机构的某几个位置 低 每个位置解一次三角形
    四杆机构的传动角 中 每个位置要算两条线的夹角

    但手算的能力边界在哪里？ 不在公式复杂度上，而在数量上。 机构一复杂，量的增长是爆炸式的：

    • 杆件数一多（多杆）：每多一个独立回路，就要多联立一组三角方程；
    • 出现多环（闭链套闭链）：每个环都要单独解，解出来的角还要代入下一个环；
    • 出现高副（凸轮、齿轮）：接触点的位置本身就要先求出来，才能算夹角；
    • 一旦要整周分析：曲柄转一整圈要算几百个位置，纸笔根本不现实 ⚠

    1.2 一个量化的对比：回路数决定手算负担¶

    「独立回路」是这里唯一需要的计数概念：

    平面低副机构的独立回路数 = \(P_L - (l - 1)\)

    其中 \(l\) 是构件总数（含机架），\(P_L\) 是低副个数。 这条式子的意思是：机构里有几个「独立可解的三角形」。

    为什么每个回路要解两个方程：一个回路要定下两条未知杆的方向， 方向由两个坐标分量决定，所以每个回路要联立 2 个方程。

    1.3 工具真正的价值：四件事¶

    课件在章末要求用工具做的事，其实正好就是工具的四项核心价值：

    工具能做的四件事 对应的工程问题 手算能做到吗
    快速画机构简图 这个机构到底由几根杆、几个副组成 可以，但反复修改时很慢
    自动算自由度 需要几个驱动；会不会卡死 可以，但要手数复合铰链/虚约束 ⚠
    算关键点的运动轨迹 工作端能走到哪里，轨迹是什么形状 算几个点可以，整周不行 ⚠
    看干涉 运动过程中杆件会不会撞在一起 基本做不到 ⚠

    1.4 哪类问题适合手算、哪类必须用工具¶

    这是本页第一张「判据表」，它决定了你拿到一个问题后先掏纸笔还是先开工具：

    问题类型 手算 工具 理由
    数构件、数运动副 必须手算 ✓ 辅助 判断「哪些零件是一个构件」只有人能定
    自由度计算 必须手算 ✓ 可复核 复合铰链、虚约束要先人工排查 ⚠
    四杆机构几个指定位置 可以 更快 每个位置解一次三角形
    六杆以上机构位置分析 做不到 ⚠ 必须 ✓ 多环顺序求解，手算易错
    整周轨迹（几百个位置） 做不到 ⚠ 必须 ✓ 纯数量问题
    干涉检查 / 工作空间边界 做不到 ⚠ 必须 ✓ 需要遍历全部位形
    传动角随曲柄角的变化曲线 只能取几个点 必须 ✓ 需要密集采样找最小值
    考试中的概念推导 必须手算 ✓ 工具不参与 考的是理解，不是算力

    最容易走偏的一步：跳过手算直接上工具

    很多人的第一反应是「有工具了，谁还手算」。

    但上面这张表里，凡是要「判断」的地方，工具都帮不上忙：

    • 哪些零件刚性连接在一起、该合并成一个构件 —— 工具不知道 ⚠
    • 某个连接是转动副还是移动副 —— 工具不知道 ⚠
    • 这个机构该固定哪一个构件当作机架 —— 工具更不知道 ⚠

    这些判断做错了，工具会非常认真地算出一个错误答案， 而且它的界面看上去毫无异常 ✓

    正确的心态：工具是计算器，不是裁判。 它只负责算得快，不负责任务判断对错。

    2.2 什么是「机构简图」¶

    机构简图（kinematic diagram）：把真实机械装置抽象成 线条 + 运动副符号的平面图形。

    抽象掉什么、保留什么，是简图的全部要点：

    实物里有的东西 简图里怎么处理 为什么
    杆的厚度、倒角、油孔 全部丢掉 与运动无关
    螺栓、键、销、轴套、挡圈 丢掉（它们不产生相对运动） 属于同一构件内部
    一个构件的真实形状 一条线 ✓ 刚体只需知道两个端点位置
    转动副的轴承、轴销 一个小圆圈 ✓ 只需知道转轴中心
    移动副的导轨与滑块 一个滑块符号 ✓ 只需知道移动方向
    固定的机架 打斜线 ✓ 明确谁是「不动」的那一个

    一句话总结抽象规则：

    简图保留的只有两件事 —— 哪些点之间是刚性距离不变（构件）， 哪些点之间可以相对转或相对移（运动副）。

    三、运动轨迹分析¶

    3.1 什么是轨迹¶

    轨迹：机构中某一点在运动过程中走过的曲线。

    要算轨迹，需要三个东西：

    需要的 说明
    一个驱动变量 比如曲柄转角 \(\theta_2\)，从 \(0^\circ\) 转到 \(360^\circ\)
    一套位置分析 给定 \(\theta_2\)，算出机构里所有点的位置
    一个取样步长 比如每 \(1^\circ\) 取一个点，一共取 361 个点

    注意这里的关键词是「点」：轨迹从来不是一条抽象的线， 它是一串坐标。算轨迹就是循环地算位置，把坐标存进列表 ✓

    3.2 为什么轨迹这么重要¶

    课件把「分析关键构件的运动轨迹」列进了每一道作业， 原因就是轨迹能直接回答三个工程问题：

    想知道的 轨迹怎么回答
    会不会干涉？ 轨迹曲线如果扫过机架或其他杆件的区域，就会撞 ⚠
    能不能满足工艺要求？ 工艺要求常写成「某点走一条近似的直线/圆弧」，直接拿轨迹比对 ✓
    工作空间有多大？ 轨迹的包围盒（能走到的范围）就是工作空间的估计 ✓

    3.3 两种轨迹的对比：简单的和复杂的¶

    同一个四杆机构里，不同点的轨迹复杂度差别极大：

    取哪一点 由谁决定 轨迹形状
    曲柄外端 \(B\) 只由曲柄长度和 \(\theta_2\) 决定 一个圆（半径为曲柄长）
    连杆上一点（如中点 \(M\)） 由五个杆长 + 装配方式共同决定 复杂封闭曲线 ✓

    「一个圆」好理解，因为曲柄是绕固定点的整周转动，端点到转轴的距离恒定不变。 「复杂曲线」正是连杆机构的价值所在：

    连杆机构能实现复杂运动，靠的就是连杆上某一点的轨迹是复杂曲线。 想要什么形状的轨迹，就去设计合适的杆长组合 ✓

    import math

# 四杆机构（单位统一用 mm）
a, b, c, d = 25.0, 70.0, 60.0, 90.0      # 曲柄、连杆、摇杆、机架
XB, YB = 0.0, 0.0                        # 固定铰点 B（机架左端，这里当作原点）
XD, YD = d, 0.0                          # 固定铰点 D（机架右端）


def solve_position(theta2_deg):
    r"""给定曲柄转角，返回 (连杆角, 摇杆角, 点B, 点C)。

    原理：点 B 由曲柄决定；三角形 BCD 三边已知（BD 可算），
          用余弦定理求角，再叠加 BD 的方位角。
    """
    t2 = math.radians(theta2_deg)
    bx = XB + a * math.cos(t2)
    by = YB + a * math.sin(t2)

    dx, dy = XD - bx, YD - by             # 向量 BD
    r = math.hypot(dx, dy)                # BD 的长度

    # 三角形 BCD：边 r=BD、b=BC、c=CD，求 BC 与 BD 的夹角 phi
    cos_phi = (r * r + b * b - c * c) / (2.0 * r * b)
    if abs(cos_phi) > 1.0:                # 三角形解不出来：装配失败
        return None
    phi = math.acos(max(-1.0, min(1.0, cos_phi)))
    delta = math.atan2(dy, dx)            # BD 的方位角
    gamma = delta + phi                   # BC 的方位角（取上面那种装配）

    cx = bx + b * math.cos(gamma)
    cy = by + b * math.sin(gamma)

    theta3 = math.degrees(math.atan2(cy - by, cx - bx)) % 360.0
    theta4 = math.degrees(math.atan2(cy - YD, cx - XD)) % 360.0
    return theta3, theta4, (bx, by), (cx, cy)

    def solve_dof(n_links, low_pairs, high_pairs):
    r"""平面机构自由度：F = 3(l-1) - 2*P_L - P_H。

    n_links    构件总数（含机架）
    low_pairs  低副个数（转动副 + 移动副）
    high_pairs 高副个数（齿轮副、凸轮副等点/线接触副）
    """
    return 3 * (n_links - 1) - 2 * low_pairs - high_pairs


def pairs_at_one_joint(k):
    r"""k 个构件在同一处以转动副相连时，该处的转动副个数 = k - 1。"""
    return k - 1


def report(name, n_links, low_pairs, high_pairs,
           k_at_joint=None, virtual=None, p_drive=1):
    r"""打印一个机构的自由度分析报告。

    k_at_joint  该机构有一处复合铰链时，传入那里挂着的构件数；
                此时 low_pairs 应填「把该铰点只数成 1 个副」得到的数
    virtual     按虚约束去掉的部分 (去掉的构件数, 去掉的低副数)；
                此时 n_links / low_pairs 应填**未去掉时**的数
    p_drive     实际打算配的原动件个数
    """
    l, low = n_links, low_pairs
    note = ""
    if k_at_joint is not None:
        low = low - 1 + pairs_at_one_joint(k_at_joint)      # 把复合铰链拆开
        note += "（拆开 1 处复合铰链：%d 个构件 → %d 个转动副）" % (
            k_at_joint, pairs_at_one_joint(k_at_joint))
    if virtual is not None:
        dl, dp = virtual
        l -= dl
        low -= dp
        note += "（按虚约束去掉 %d 个构件、%d 个低副）" % (dl, dp)

    F = solve_dof(l, low, high_pairs)
    print("%s" % name)
    if virtual is not None:
        print("  未去虚约束时：F = %d" % solve_dof(n_links, low_pairs, high_pairs))
    print("  处理后：l = %d，P_L = %d，P_H = %d %s" % (l, low, high_pairs, note))
    print("  F = 3*(%d-1) - 2*%d - %d = %d" % (l, low, high_pairs, F))
    if F <= 0:
        print("  → 这不是机构（刚性结构），不能动 ⚠")
    elif p_drive == F:
        print("  → 应配 %d 个原动件，运动确定 ✓" % F)
    else:
        print("  → 配 %d 个原动件，与 F = %d 不符，运动不确定 ⚠" % (p_drive, F))
    print()
    return F

a, b, c, d = 25.0, 70.0, 60.0, 90.0


def solve_fourbar(theta2_deg, a=a, b=b, c=c, d=d, upper=True):
    r"""四杆机构位置分析。

    机架 A-D 水平放置，A 在原点，D 在 (d, 0)；
    曲柄 A-B 长 a，连杆 B-C 长 b，摇杆 D-C 长 c。

    返回 (theta3, theta4, A_, B, C)，角度单位「度」，长度单位与输入一致。
    三角形的两个解对应两种装配方式，用 upper 选择其中一种。
    """
    t2 = math.radians(theta2_deg)
    Ax, Ay = 0.0, 0.0
    Dx, Dy = d, 0.0
    Bx = Ax + a * math.cos(t2)
    By = Ay + a * math.sin(t2)

    dx, dy = Dx - Bx, Dy - By
    r = math.hypot(dx, dy)                       # BD 长度

    cos_phi = (r * r + b * b - c * c) / (2.0 * r * b)
    if abs(cos_phi) > 1.0:
        return None                              # 解不出三角形：该位置不存在
    phi = math.acos(max(-1.0, min(1.0, cos_phi)))
    gamma = math.atan2(dy, dx) + (phi if upper else -phi)
    Cx = Bx + b * math.cos(gamma)
    Cy = By + b * math.sin(gamma)

    theta3 = math.degrees(math.atan2(Cy - By, Cx - Bx)) % 360.0
    theta4 = math.degrees(math.atan2(Cy - Dy, Cx - Dx)) % 360.0
    return theta3, theta4, (Ax, Ay), (Bx, By), (Cx, Cy)

    4.6 工具 4：算传动角，找最小传动角与死点¶

    传动角是什么：机构运转时，连杆与从动件（摇杆）之间所夹的锐角， 通常记为 \(\mu\)。

    它的物理意义很直接：

    传动角 \(\mu\) 的大小 说明 后果
    接近 \(90^\circ\) 力的方向几乎垂直于从动件 同样的力产生最大力矩 ✓
    越来越小 力的方向越来越「顺着」杆件 有效力矩变小，效率低 ⚠
    等于 \(0^\circ\) 力完全顺着杆件，无法推动摇杆 死点，机构卡住 ⚠

    标准做法：曲柄转一整圈，找出 \(\mu\) 的最小值， 再对照设计准则判断能不能用。

def straightness(seg):
    r"""返回 (最大偏离弦的距离, 弦长)。"""

    七、用工具容易犯的三个错¶

    7.1 错法一：直接把 CAD 图当简图用¶

    表现：把三维装配图打开，对着屏幕上的零件数构件； 或者把 CAD 里的零件清单直接当作构件清单。

    为什么错：CAD 图是零件级的，简图是构件级的。 两者之间差着「合并刚接件」这一步 ⚠

    CAD 里看到的 简图里应该是 差多少
    底板、电机外壳、4 个地脚螺栓 1 个机架 少 5 个
    连杆体、连杆盖、2 螺栓、2 轴瓦 1 个连杆 少 5 个
    摇杆、销轴、工作台 1 个摇杆 少 2 个

    后果：构件数 \(l\) 从 4 变成 16 以上， 自由度算出来大得离谱， 于是你会得出「这个机构需要十几个电机」的荒谬结论 ⚠

    7.2 错法二：相信工具算出的自由度而不检查¶

    表现：输入一串数字，工具输出 \(F = 3\)，就直接写进报告。

    为什么错：工具只做算术，不做判断。 它不知道你数进去的那个「1 个转动副」其实是个挂了三根杆的复合铰链 ⚠

    必须自己检查的三件事：

    检查项 怎么查 不查的后果
    复合铰链 逐个铰点问「这里挂了几个构件」 \(F\) 偏大 ⚠
    虚约束 问「这个约束有独立限制作用吗」 \(F\) 偏小甚至为 0 ⚠
    局部自由度 问「有没有滚子、滚珠这类不影响整体运动的部件」 \(F\) 偏大 ⚠

    一个可靠的判断信号：如果算出的 \(F\) 与你的直觉严重不符 （比如一个明显能动的四杆机构算出 \(F = 0\)）， 不要怀疑直觉，先回去重数 ✓

    7.3 错法三：只画图不做数值验证¶

    表现：简图画得很漂亮，运动看着也顺畅，就交差了。

    为什么错：图纸上的「看着没问题」和数值上的「真的没问题」是两回事 ⚠ 平面图看不出下面这些：

    图纸上看不出来的 用哪个工具查

    杆件在中途撞在一起（干涉） 工具 3 的轨迹是否穿过其他构件 ✓

    例题 2：手算一个位置，再用代码核对¶

    四杆机构，杆长 \(a = 25\)、\(b = 70\)、\(c = 60\)、\(d = 90\)（mm）， 机架 \(AD\) 水平放置。求曲柄角 \(\theta_2 = 90^\circ\) 时的连杆角 \(\theta_3\)、摇杆角 \(\theta_4\)。

    思路

    分三步走，每一步都只用一个三角形：

    1. 由 \(\theta_2\) 定出点 \(B\) 的坐标（曲柄是绕 \(A\) 的圆周运动）；
    2. 三角形 \(BCD\) 的三边都已知（\(\lvert BD \rvert\) 用两点距离算）， 用余弦定理求角 \(\angle CBD\)；
    3. 把 \(\angle CBD\) 叠加到向量 \(\vec{BD}\) 的方位角上， 就得到 \(BC\) 的方向，从 \(B\) 走 \(b\) 就到 \(C\) ✓

    最后一定要用「\(\lvert BC \rvert\) 应等于 \(b\)、\(\lvert CD \rvert\) 应等于 \(c\)」核对一遍 ✓

    解答

    第一步：点 \(B\) 的坐标。

    \[B = (a\cos 90^\circ,\ a\sin 90^\circ) = (0,\ 25)\]

    第二步：求 \(\lvert BD \rvert\)。

    \[\vec{BD} = (90 - 0,\ 0 - 25) = (90,\ -25)\]
    \[\lvert BD \rvert = \sqrt{90^2 + (-25)^2} = \sqrt{8100 + 625} = \sqrt{8725} \approx 93.4077\ \text{mm}\]

    第三步：余弦定理求 \(\angle CBD\)。

    \[\cos \angle CBD = \frac{\lvert BD \rvert^2 + b^2 - c^2}{2 \lvert BD \rvert b} = \frac{8725 + 4900 - 3600}{2 \times 93.4077 \times 70} \approx 0.7666\]

    例题 3：手算最小传动角，再用代码核对¶

    同一个机构（\(a = 25\)、\(b = 70\)、\(c = 60\)、\(d = 90\)）。 已知最小传动角出现在曲柄与机架共线的位置，用手算求出它，再用整周扫描核对。

    思路

    传动角是连杆与摇杆之间的锐角，它是三角形 \(BCD\) 的一个内角。

    由余弦定理，\(\angle BCD\) 完全由三边长 \(b\)、\(c\)、\(\lvert BD \rvert\) 决定：

    \[\cos \angle BCD = \frac{b^2 + c^2 - \lvert BD \rvert^2}{2bc}\]

    所以传动角随 \(\lvert BD \rvert\) 单调变化：

    • \(\lvert BD \rvert\) 最长时（曲柄与机架外共线，即 \(\theta_2 = 180^\circ\)）→ 夹角最大；
    • 夹角越大，取锐角后的传动角越小 ⚠

    因此只需手算 \(\theta_2 = 180^\circ\) 这一个位置，就找到了最小值 ✓

    解答

    第一步：求这个位置的 \(\lvert BD \rvert\)。

    \(\theta_2 = 180^\circ\) 时，\(B = (-25,\ 0)\)，与 \(D = (90, 0)\) 都在机架线上：

    \[\lvert BD \rvert = d + a = 90 + 25 = 115\ \text{mm}\]

    第二步：余弦定理求铰点 \(C\) 处的夹角。

    \[\cos \angle BCD = \frac{b^2 + c^2 - \lvert BD \rvert^2}{2bc} = \frac{4900 + 3600 - 13225}{2 \times 70 \times 60} = \frac{-4725}{8400} = -0.5625\]
    \[\angle BCD = \arccos(-0.5625) \approx 124.2289^\circ\]

    第三步：取锐角作为传动角。

    \[\mu = 180^\circ - 124.2289^\circ \approx 55.7711^\circ\]

    Q1 判断对错并说明理由：

    （a）画机构简图时，应该按零件个数画线条。 （b）机构简图上的线条长度可以随手画，只要形状像就行。 （c）只要把机构输入工具，工具算出来的自由度一定正确。

    答案

    （a）错 ⚠

    简图上的线条代表构件，不是零件。 刚性连接在一起、彼此没有相对运动的零件要合并成一个构件。 上文的例子是：16 个零件 → 4 个构件。

    按零件数画，构件数会大好几倍，自由度算出来完全错 ⚠

    （b）错 ⚠

    简图要按比例画。原因：简图是用来做位置分析的， 杆长比例错了，算出来的轨迹、传动角、工作空间全错。

    这里的「按比例」不是要求画得多漂亮， 而是要求图上各条线的长度之比等于实际杆长之比 ✓

    （c）错 ⚠

    工具只做算术，不做判断。它算的是你喂给它的模型：

    • 有没有复合铰链没拆开 —— 工具不知道 ⚠
    • 有没有虚约束没去掉 —— 工具不知道 ⚠
    • 有没有局部自由度（滚子之类）—— 工具不知道 ⚠

    输入模型错了，工具会又快又准地给出错误答案 ✓

    Q2 一个四杆机构，\(a = 25\)、\(b = 70\)、\(c = 60\)、\(d = 90\)（mm）。 请说明：

    （a）\(F\) 是多少，需要几个驱动； （b）如果想让工作端沿 \(x\) 方向行程达到 \(60\) mm（取连杆中点），这个方案行不行； （c）如果不行，你打算先改哪个杆长，为什么。

    提示

    （a）数 \(l\)、\(P_L\)、\(P_H\) 后直接套公式。 （b）用工具 3 算包围盒，用 \(x\) 方向的宽度与 \(60\) mm 比较。 （c）想一想曲柄转角整周变化时，谁的贡献让连杆中点沿 \(x\) 方向来回移动。

    答案

    （a）自由度与驱动数。

    \(l = 4\)（3 个活动构件 + 机架），\(P_L = 4\)（\(A\)、\(B\)、\(C\)、\(D\)），\(P_H = 0\)：

    \[F = 3(4-1) - 2 \times 4 - 0 = 9 - 8 = 1\]

    \(F = 1 \gt 0\)，机构能动；应配 1 个原动件 ✓

    （b）行程够不够。

    用位置分析扫一圈算包围盒，\(x\) 方向的宽度是 42.1803 mm（见例题 4）。

    \[42.1803 \lt 60\]

    不够，差约 \(17.82\) mm，方案不可行 ⚠

    （c）先改哪个杆长，为什么。

    优先加长曲柄 \(a\) ✓

    理由：连杆中点的 \(x\) 坐标里，点 \(B\) 的贡献是 \(a\cos\theta_2\)， 它随 \(\theta_2\) 整周变化，直接贡献 \(2a\) 的 \(x\) 方向摆幅。

    1. 加长 \(a\) 会同时改变传动角 ⚠ —— 必须回到工具 4 复核 \(\mu_{\min}\) 是否仍在 \(40^\circ\) 以上；

    小结¶

    要记住的 为什么
    工具替你算，不替你判断 构件怎么合并、副是什么类型、机架是谁，工具都不知道 ⚠
    手算适合简单机构 四杆、曲柄滑块只要解一个三角形
    机构一复杂（多杆、多环、含高副）手算量剧增 回路数每加 1，就多联立 2 个三角方程，还要顺序求解 ⚠
    工具的四大价值：画简图、算自由度、算轨迹、看干涉 分别对应四类工程问题 ✓
    机构简图 = 线 + 运动副符号 只保留「刚性距离」与「可相对运动」两件事
    为什么必须先画简图 实物有厚度、倒角、无关零件，直接看实物数构件一定错 ⚠
    画简图六步：分固定件 → 并刚接件 → 画线 → 标符号 → 标机架 → 数并代公式 第 2 步与第 6 步最容易错
    标准符号只有三个：转动副画小圆圈、移动副画滑块、高副画接触轮廓 记住这三个就不会判错类型 ✓
    零件数 ≠ 构件数 上文的例子里是 16 个零件 → 4 个构件
    轨迹是「一串坐标」，不是一条抽象的线 算轨迹就是循环算位置
    为什么轨迹重要：干涉、工艺要求、工作空间 三个问题都能直接用轨迹回答 ✓
    轨迹一定要报包围盒 包围盒就是工作空间的估计
    曲柄端走圆，连杆上的点走复杂曲线 「复杂曲线」正是连杆机构能实现复杂运动的原因 ✓
    四条最小工具：算自由度、位置分析、算轨迹、算传动角 覆盖课件要求的全部计算动作 ✓
    复合铰链：\(k\) 个构件 → \(k-1\) 个转动副 同一处挂 3 个以上构件就要拆
    虚约束：先去掉重复约束再数 不去掉会让 \(F\) 偏小甚至算成 0 ⚠
    位置分析必须验证 用「每根杆的两点距离应等于名义杆长」核对 ✓
    传动角取锐角；\(\mu = 0\) 就是死点 死点出现在连杆与摇杆共线的位置
    最小传动角要和 \(40^\circ\) 这类准则比较，不是算着看 不满足就回去改杆长，而不是先用着 ⚠
    工作流：实物 → 简图 → 数 l、P_L、P_H → 算 F → 定驱动数 → 位置分析 → 验证工艺 这是本章最有价值的归纳 ✓
    工作流是迭代的：不满足就回去改杆长 用代码试二十种方案只要几秒 ✓
    工具只分四类：通用数值计算环境、机构专用仿真工具、多体动力学工具、通用 CAD 先判断「我需要哪一类」
    通用 CAD 不做运动学自动求解 它擅长装配与干涉检查，不擅长自动算自由度 ⚠
    不管用什么工具，构件、运动副、自由度必须先掌握 工具只加速计算，判断对不对还是靠人 ✓
    三个错：拿 CAD 图当简图、相信工具算的自由度、只画图不验证 共同点是把「看到的」当成「该数的」⚠
    CAD 是零件级的，简图是构件级的 两者之间差着「合并刚接件」这一步
    结果与直觉严重不符时，先回去重数 \(F\) 偏大通常是漏了复合铰链，\(F\) 偏小通常是没去虚约束 ⚠
