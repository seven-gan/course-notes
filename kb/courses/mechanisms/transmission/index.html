    这一页回答一个问题：从动力源到工作端，中间那一段到底该怎么连？

    动力源（电机、内燃机）给出的运动很单调：转速高、扭矩小、一直朝一个方向转。 而工作端想要的东西往往完全相反：转速低、扭矩大、还要来回直线走。 这两端「对不上」，中间就必须有一个东西把运动翻译一遍 —— 这个翻译器就叫传动机构（Transmission mechanism）。

    本页依据本课程课件 1.4 节，把课件列出的几类传动机构逐个讲清： 它们靠什么原理工作、传动比怎么算、各自擅长什么、又有什么硬伤。

    先看一组容易混的东西，它们外观相似，选错代价很大：

    看起来差不多 实际差别 后果
    皮带 与 同步带 一个是摩擦传动，一个是齿形啮合 前者会打滑，传动比不准 ⚠
    链传动 与 带传动 一个是啮合，一个是摩擦 链能保准确传动比，带不能 ✓
    齿轮 与 凸轮 齿轮传的是转动，凸轮规定的是运动规律 用错就等于少了一件功能
    凸轮 与 连杆 凸轮靠轮廓形状，连杆靠转动副串接 前者磨损快，后者承载大

    这一页的主线

    整页在回答同一件事：「要改变的是什么？」

    要改变的 找谁
    转速、扭矩 带、链、齿轮（有传动比）
    运动形式（转 → 往复、转 → 摆动） 凸轮、连杆、齿轮齿条
    位置 / 运动规律的形状 凸轮（唯一能任意指定）

    看清需求属于哪一类，选型就不会错

    一、为什么需要传动机构¶

    1.1 动力源与工作端天然不匹配¶

    电机（或任何动力源）和负载之间，几乎总有三处不匹配：

    不匹配的地方 动力源一侧 工作端一侧
    转速 高（常见每分钟上千转） 低（每分钟几十转甚至几转）
    扭矩 小 大
    运动形式 连续旋转 常常是往复、间歇、摆动
    位置关系 就在电机轴上 可能在别处，甚至几米外

    如果直接把负载装在电机轴上会怎样：电机转得太快，带不动， 一通电就堵转发热烧毁。所以中间必须有传动机构。

    1.2 传动机构能改变的四件事¶

    本课程课件把传动机构的作用概括为四点，这四点是本页的骨架：

    改变什么 含义 谁来做
    改变转速 输入快、输出慢（或反过来） 带、链、齿轮
    改变扭矩 转速降下来，扭矩就升上去 有传动比的所有传动
    改变运动形式 转动变往复、转动变摆动 凸轮、连杆、齿轮齿条
    改变位置 把运动送到远处的另一个地方 带、链、绳索

    「改变扭矩」不是凭空多出来的力

    传动机构不产生能量，它只是把「转速」换成「扭矩」—— 这一点在本页推导扭矩与转速成反比时会看得非常清楚。

    课件 1.1 节就点明了这个结论：简单机械并不会产生能量，只能改变它

    工程含义：想用减速的方式把扭矩放大 10 倍， 输出的转速就必然只剩原来的十分之一。两头都要，做不到

    1.3 需求 → 用什么传动¶

    下面这张表是本页的选型总纲，后面的每一节都在为它给出理由：

    工作端需求 推荐传动 一点理由
    只要减速，允许有点不准 带传动 便宜、能缓冲、能过载保护
    转速必须严格同步 同步带 / 链 / 齿轮 啮合传动，不打滑
    低速大扭矩 多级齿轮（齿系） 各级传动比相乘，容易做大

    2.1 结构元素：让机器「立得住、连得牢、不漏油」¶

    结构元素不改变转速，也不换运动形式，它们的任务是让整台机器成为一个整体。 但没有它们，任何传动都装不起来，所以必须先认一遍：

    紧固件（Fasteners） 把几个零件固定成一个不能相对动的整体 螺栓、螺母、螺钉、垫圈
    键、花键、开口销（Keys / Splines / Cotton pins） 阻止轮与轴之间相对转动，专门传递扭矩 齿轮、带轮装在轴上

    轴承就是转动副在实物上的实现方式

    概念层 名称

    实物零件 轴承（滑动轴承 / 滚动轴承）

    所以数运动副时数的是有几处相对转动， 而不是数装了几个轴承 —— 二者不能混淆 ⚠

    三、带传动（Belt）¶

    3.1 工作原理：靠摩擦力¶

    带传动的结构极简单，就是三个东西：

    1
    主动带轮（小）─── 皮带 ─── 从动带轮（大）

    动力是这样传过去的：

    1. 动力源把主动带轮转起来；
    2. 张紧的皮带被带轮「抓住」，靠轮与带之间的摩擦力被拽着走；
    3. 皮带跑起来后，又用摩擦力去拽从动带轮；
    4. 从动带轮就跟着转了。

    关键在「摩擦力」三个字 —— 皮带没有被卡死在轮上， 它只是被压紧后的摩擦带着走。这个特点既是它最大的优点，也是它最致命的缺点。

    3.2 传动比公式：从「带速处处相等」推出来¶

    先用符号把要用的量定义清楚：

    符号 含义 单位
    \(D_1\) 主动轮直径 mm
    \(D_2\) 从动轮直径 mm
    \(n_1\) 主动轮转速 r/min（转每分）
    \(n_2\) 从动轮转速 r/min
    \(v\) 皮带线速度 m/s
    \(i\) 传动比 无量纲

    第一步：写出带轮边缘的线速度。

    带轮转一圈，轮缘上一点走过的路程就是轮子的周长 \(\pi D\)（\(D\) 单位 mm，所以周长是 \(\pi D\) mm）。 每分钟转 \(n\) 圈，所以每分钟走过 \(\pi D n\) mm。 换成「每秒多少米」要除以 60，再除以 1000：

    \[v = \frac{\pi D n}{60 \times 1000} = \frac{\pi D n}{60000}\]

    这里的 60000 就是 \(60 \times 1000\)，把「每分钟」换成「每秒钟」、「毫米」换成「米」。

    第二步：用「皮带不打滑时，皮带上各点速度相同」。

    皮带是一条连续的带子，它自己在运动，速度是 \(v\)。 在理想（不滑动）的情况下，皮带在主动轮处的速度、在从动轮处的速度必然相同 —— 因为它是同一根带子，不能一边跑得快一边跑得慢。

    所以两个带轮的轮缘速度都等于 \(v\)：

    \[\frac{\pi D_1 n_1}{60000} = \frac{\pi D_2 n_2}{60000}\]

    第三步：两边约掉公共因子。

    两边同乘 \(\frac{60000}{\pi}\)（这是一个非零常数，约掉不影响等式）：

    \[D_1 n_1 = D_2 n_2\]

    第四步：把转速挪到一边、直径挪到另一边。

    两边同除以 \(n_2 D_1\)（前提是它们都不为零，实际工作中恒成立）：

    \[\frac{n_1}{n_2} = \frac{D_2}{D_1}\]

    这就是传动比的定义式：

    \[\boxed{\;i = \frac{n_1}{n_2} = \frac{D_2}{D_1}\;}\]

    从动轮越大，转得越慢。 大轮直径是小轮的两倍，输出转速就只剩一半 —— 这就是「减速」。 反过来说，减速比 = 直径比，想要多大的减速比，就把两个轮子的直径做成那么大。

    这个公式成立有个前提：不打滑

    上面第二步用的是「皮带速度处处相同」。 而皮带靠摩擦传动，一旦载荷太大，皮带就会在轮上打滑， 这时皮带速度并不等于轮缘速度，整个推导的前提就崩了

    所以 \(i = D_2 / D_1\) 是理想传动比， 实际的转速比会因为打滑而偏离这个值。详见 3.5 节。

    3.3 优点：过载保护、缓冲吸振、适合远距离¶

    优点 为什么
    过载保护 ✓ 载荷突然变大时皮带先打滑，把多余能量耗掉，电机和机器都不会被拧坏
    缓冲吸振 ✓ 皮带是弹性体，能吸收冲击和振动，传动平稳、噪声小
    适合远距离 ✓ 中间用几米长的皮带就能把动力送过去，两个轮子不必挨着
    结构简单、便宜 ✓ 不需要精密加工和润滑，维修换一根带子就行
    噪声小 ✓ 摩擦传动不像啮合那样产生周期性冲击

    「过载保护」是带传动最独特的能力 —— 后面要讲的链、齿轮、凸轮全都没有这个能力，它们一旦过载就断齿或拉断。

    3.4 缺点：打滑导致传动比不准确¶

    缺点 为什么
    打滑 → 传动比不准确 ⚠ 摩擦传动的固有特性，输出转速随载荷浮动，无法严格同步
    需要张紧 ⚠ 不张紧就没有摩擦力，皮带会空转；用久了皮带会松弛，需要张紧轮
    传动比不能太大 单级一般不超过 7 左右，否则小轮包角太小，打滑更严重
    寿命短 皮带会磨损、老化、拉长
    不能传很大扭矩 摩擦力有上限，重载下必须用多根带并联

    「传动比不准确」到底有多严重

    不是「差一点点没关系」，而是会累积成系统性误差。

    举例：一根定位用的传送带，如果皮带打滑 2%， 那么从动轮每转 50 圈，就少转了整整 1 圈。 需要精确位置的地方（如机械臂关节、数控机床进给） 就完全没法用普通带传动 ✗

    解决办法是换同步带（见 3.5 节），而不是把皮带拉得更紧

    3.5 三个变体：普通带、V 带、同步带¶

    变体 靠什么传力 特点
    普通平带 平面摩擦 最简单，摩擦力小，容易打滑
    V 带（三角带） 楔形槽里的两侧面摩擦 楔形效应把摩擦放大，能传更大扭矩 ✓
    同步带（齿形带） 带齿与轮齿啮合 不打滑，传动比准确 ✓ 但失去过载保护

    V 带为什么能增大摩擦：皮带嵌在轮子的 V 形槽里， 张紧力在两侧斜面上被分解，把带子压向槽壁的力远大于初张紧力。 同样的张紧力，V 带能产生的摩擦力是平带的数倍 —— 这就是「楔形效应」，和楔块、斜面的省力道理是同一个。

    同步带是本页第一个重要的「例外」： 课件明确指出「同步带：带齿与轮齿的相互啮合传动」。 它外形像皮带，但原理已经变成啮合了， 所以它同时具备「带传动能远距离」和「啮合传动传动比准确」两个优点

    代价是：一旦过载，齿会被剪坏，而不是打滑 —— 保护能力没了

    3.7 逐级推导：为什么 \(n_2 = n_1 / i\)¶

    带传动的公式短短几行，但每一步都有依据，拆开看一遍就不会记反。 设主动轮直径 \(D_1\)、转速 \(n_1\)，从动轮直径 \(D_2\)、转速 \(n_2\)。

    第 1 步：写出主动轮边缘的线速度。 轮子边缘一点绕圆心转一周走过的距离是周长 \(\pi D_1\)， 每秒转的圈数是 \(n_1/60\)，所以边缘线速度

    \[v_1 = \pi D_1 \frac{n_1}{60}\]

    依据：圆周运动里 \(v = \omega r\)，把 \(\omega\) 换成每分钟转数。

    第 2 步：写出从动轮边缘的线速度。

    \[v_2 = \pi D_2 \frac{n_2}{60}\]

    第 3 步：用「不打滑」把两式连起来。 带是柔性体、靠摩擦贴着轮面走，只要不滑动， 带上每一点的线速度处处相等，所以 \(v_1 = v_2\)：

    \[\pi D_1 \frac{n_1}{60} = \pi D_2 \frac{n_2}{60}\]

    第 4 步：约掉两边公共因子。 \(\pi\) 和 \(60\) 都在两边，直接消掉：

    \[D_1 n_1 = D_2 n_2\]

    这条式子说明：轮子直径与转速成反比，大轮转得慢，小轮转得快。

    第 5 步：定义传动比。 习惯上把「从动轮齿数（或直径）比主动轮」定义为传动比：

    \[i = \frac{D_2}{D_1}\]

    第 6 步：把 \(i\) 代回第 4 步。 由 \(D_2 = i D_1\) 代入 \(D_1 n_1 = D_2 n_2\)：

    \[D_1 n_1 = i D_1 n_2 \;\Longrightarrow\; n_1 = i\, n_2 \;\Longrightarrow\; n_2 = \frac{n_1}{i}\]

    \(i > 1\) 时 \(n_2 < n_1\)，是从动轮变慢，叫减速传动； \(i < 1\) 时反而变快，叫增速传动。整条推导只用到两个事实： 「周长等于 \(\pi D\)」和「不打滑时线速度相等」——没有任何别的假设。

    记反 i 的方向是最高频的失分点

    传动比 \(i\) 的分子必须是从动轮参数，分母必须是主动轮参数。 若把 \(i\) 写成 \(D_1/D_2\) 并仍用 \(n_2 = n_1/i\)，得到的数恰好是正确答案的倒数， 转速会翻成错误的数量级。记法：先问一句「从动轮比主动轮大还是小」， 大就 \(i>1\) 减速，再由 \(n_2 = n_1/i\) 得出变慢，方向自检就通过了

    3.8 打滑带来的误差：手算对照表¶

    打滑是摩擦传动的固有现象，用滑差率 \(\varepsilon\) 描述它：

    \[\varepsilon = \frac{n_{1,\text{理想}} - n_{1,\text{实际}}}{n_{1,\text{理想}}}\]

    也就是从动轮少转的比例。取主动轮 \(n_1 = 1440\) r/min， 轮径比 \(D_2/D_1 = 3.000\)，则理想传动比 \(i = 3.000\)、 理想输出转速 \(n_2 = 1440 / 3.000 = 480.00\) r/min。 打滑后输出转速按 \(n_2^{\text{实}} = \dfrac{n_1}{i}(1-\varepsilon)\) 下降， 下表全部由手算填出：

    传动类型 滑差 \(\varepsilon\) 手算式 实际 \(n_2\)/(r/min) 与理想之差 主动轮转 50 圈后少转
    同步带（啮合） 0 \(480.00 \times 1.00\) 480.00 0.00 0.000 圈
    V 带 1% \(480.00 \times 0.99\) 475.20 −4.80 0.167 圈
    V 带 2% \(480.00 \times 0.98\) 470.40 −9.60 0.333 圈
    V 带 5% \(480.00 \times 0.95\) 456.00 −24.00 0.833 圈

    「少转圈数」一栏的算法：主动轮转 50 圈时从动轮本该转 \(50/i = 50/3 = 16.667\) 圈， 实际少了 \(\varepsilon\) 倍，即 \(16.667 \times 0.05 = 0.833\) 圈。

    同步带滑差为 0，传动比严格准确； 摩擦传动的误差随转数线性累积，而且无法自愈 —— 转得越久偏得越多，所以分度、同步、定位这类场合一律不能用普通摩擦带。

    四、链传动（Chain）¶

    4.1 工作原理：靠啮合，不是摩擦¶

    链传动的结构是三个东西：

    1
    主动链轮 ─── 链条（一节一节的刚性链节）─── 从动链轮

    动力是这样传过去的：

    1. 动力源带动主动链轮转；
    2. 链轮的轮齿卡进链条的链节孔里，把链条「推」着走；
    3. 链条另一头的链节又卡进从动链轮的齿槽，把它拽着转。

    和带传动的根本差别：链条的链节与轮齿之间是形状咬合， 不是靠压紧后的摩擦。所以链条跑多快，轮子就必须转多快，不存在「打滑」这回事。 课件对此的表述是：「链轮轮齿与链节的啮合传递运动和动力」。

    4.2 传动比公式¶

    链传动的传动比由齿数决定，而不是由直径决定：

    \[\boxed{\;i = \frac{n_1}{n_2} = \frac{z_2}{z_1}\;}\]

    其中 \(z_1\) 是主动链轮的齿数，\(z_2\) 是从动链轮的齿数，\(n_1\)、\(n_2\) 是两轮转速。

    推导思路和带传动完全一样： 链条每走动「一个链节的距离」，主动链轮就转过一个齿， 从动链轮也转过一个齿（因为链节是刚性的，两边必须一一对应）。 所以单位时间里，两边转过的齿数必然相同：

    \[z_1 n_1 = z_2 n_2\]

    两边同除以 \(n_2 z_1\) 就得到 \(i = z_2 / z_1\)。

    所以链传动的「平均传动比」是严格准确的 ✓ —— 只要齿数定了，平均转速比就精确等于齿数比，与载荷、磨损都无关。

    4.3 优点与缺点¶

    优点 为什么
    传动比准确 ✓ 啮合传动，不像带那样打滑
    能传大扭矩 ✓ 链节是金属的，强度远高于皮带
    适合远距离 ✓ 中间用长链条，和皮带一样可以拉开距离
    效率高 啮合损失小，一般可到 95% 以上
    不怕高温油污 不像橡胶皮带那样怕油怕热
    缺点 为什么
    冲击噪声大 ⚠ 链节与轮齿进入啮合时是「撞上去」的，有周期性冲击
    必须润滑 ⚠ 不润滑会迅速磨损拉长，进而跳齿
    瞬时速度不均匀 ⚠ 链条绕在链轮上呈多边形，见 4.4 节
    不能过载保护 过载直接断链，没有缓冲
    需要张紧 链条用久会拉长，要张紧或去节

    「传动比准确」指的是平均值，不是每一瞬间

    这一点极容易被读错：

    说法 对不对
    链传动平均传动比准确 ✓ 对，\(i = z_2/z_1\) 精确成立
    链传动瞬时传动比恒定 ✗ 错，它有小幅周期性波动 ⚠

    原因是链条不是圆的，它绕在链轮上是一个正多边形（4.4 节会算）。 所以严格说，链传动是「平均准确，瞬时略抖」

    4.4 为什么会有「多边形效应」¶

    链条由刚性链节铰接而成，绕到链轮上时， 各个链节首尾相连成一条折线，正好贴在链轮的内接正多边形上。

    设链轮齿数为 \(z\)，那么正多边形每条边对应的圆心角是：

    \[\theta = \frac{360°}{z}\]

    链条沿着这个多边形走，它的瞬时速度等于链节铰链点速度在多边形边方向上的投影。 铰链点在圆周上运动，速度方向沿切线， 所以瞬时速度 \(v\) 与平均速度 \(v_m\) 的关系是：

    \[v = v_m \cos\beta\]

    其中 \(\beta\) 是「铰链位置角」，它在 \(-\theta/2\) 到 \(+\theta/2\) 之间来回摆动。 最慢的一刻出现在 \(\beta = \pm\theta/2\) 处，即

    \[v_{\min} = v_m \cos\!\left(\frac{180°}{z}\right)\]

    波动幅度就是 \(1 - \cos(180°/z)\)。 齿数 \(z\) 越大，这个角度越小，\(\cos\) 越接近 1，速度就越平稳 —— 这就是为什么链传动要用较多齿数的链轮。

    4.5 逐级推导：链传动的传动比与扭矩、功率¶

    链传动与带传动结论形式相同，但依据完全不同：链是啮合，不是摩擦。

    第 1 步：写出「齿数相等地走过」。 链轮每转过一个齿，就有一节链条被啮入又啮出。 主动链轮转一圈送出的链节数是 \(z_1\)，从动链轮转一圈收进的链节数是 \(z_2\)。 链条是刚性的、节距处处相同，送出的链节数必须等于收进的链节数，所以

    \[z_1 n_1 = z_2 n_2\]

    第 2 步：定义传动比。

    \[i = \frac{z_2}{z_1}\]

    第 3 步：解出输出转速。 由第 1 步 \(n_2 = \dfrac{z_1 n_1}{z_2} = \dfrac{n_1}{i}\)， 与带传动的 \(n_2 = n_1/i\) 形式完全一样。

    第 4 步：看扭矩。 忽略损失时输入功率与输出功率相等。 用 \(P = T\omega\)（\(T\) 为扭矩、\(\omega\) 为角速度）写出两端：

    \[T_1 \omega_1 = T_2 \omega_2\]

    把 \(\omega_2 = \omega_1 / i\) 代入：

    \[T_1 \omega_1 = T_2 \frac{\omega_1}{i} \;\Longrightarrow\; T_1 = \frac{T_2}{i} \;\Longrightarrow\; T_2 = i\, T_1\]

    第 5 步：验证功率不变。 输出端功率 \(P_2 = T_2 \omega_2 = (i T_1)\left(\dfrac{\omega_1}{i}\right) = T_1 \omega_1 = P_1\)。 \(i\) 在相乘时恰好被约掉 —— 这就是「传动比只搬运转速和扭矩， 不搬运功率」的算式来源。

    减速比 \(i\) 越大，转速降得越多、扭矩放得越大， 而功率一动不动。所以想「用减速器白赚功率」是不可能的， 传动机构只是把功率换一种形态（低转速大扭矩）交出来。

    一句话记住三条关系

    传动比 \(i\) 同时管三件事，方向如下：

    量 关系 减速（\(i>1\)）时的走向
    转速 \(n\) \(n_2 = n_1/i\) 变小 ↓
    扭矩 \(T\) \(T_2 = i\,T_1\) 变大 ↑
    功率 \(P\) \(P_2 = P_1\) 不变 →

    转速、扭矩反比，功率守恒。三者一起记，就不会出现 「转速降了扭矩也降」这种自相矛盾的答案

    五、齿轮传动（Gear / Gear train）¶

    5.1 工作原理：啮合，齿数决定传动比¶

    齿轮传动是两个带齿的轮子直接咬在一起：

    1
    主动齿轮 z1 ── 轮齿互相咬合 ── 从动齿轮 z2

    动力是这样传过去的：主动轮的齿顶住从动轮的齿，一个齿一个齿地推过去。 和链传动同属啮合传动，所以同样不打滑、传动比准确。

    传动比由齿数决定：

    \[\boxed{\;i = \frac{n_1}{n_2} = \frac{z_2}{z_1}\;}\]

    其中 \(z_1\) 是主动轮齿数，\(z_2\) 是从动轮齿数，\(n_1\) 是主动轮转速，\(n_2\) 是从动轮转速。

    推导思路和链传动一模一样：一对啮合的齿轮，在接触处齿必须一一对应， 主动轮转过一个齿，从动轮就得让过一个齿。所以单位时间两边转过的齿数相等：

    \[z_1 n_1 = z_2 n_2\]

    两边同除以 \(n_2 z_1\)（\(z_1\)、\(n_2\) 在实际工作中都不为零）就得到上式

    看图：左边小轮 \(z_1 = 20\)，右边大轮 \(z_2 = 60\)，所以 \(i = 60/20 = 3\)。 图上没有画扭矩，但可以想见：大轮转得慢，换来的正是扭矩变大 —— 小轮转 3 圈，大轮才转 1 圈，可大轮轴上能憋住的力矩却是小轮的 3 倍。 把这张图和前面带、链的推导连起来看，会发现三者的转速关系形式完全一致， 区别只在「靠什么保证不打滑」：带靠摩擦、链靠链节、齿轮靠齿面。

    5.2 关键点：齿轮是「高副」¶

    这是本页必须链接回上一页的地方。

    齿轮啮合的地方是一个齿面顶住另一个齿面， 接触处是一条线（理论上），面积为零级别。按运动副的分类：

    接触方式 副的类型 平面内的约束数
    转动副 面接触 低副 2
    齿轮啮合 线接触 高副 ✓ 1
    凸轮与从动件 点/线接触 高副 ✓ 1

    为什么这件事重要：在算自由度时， 齿轮啮合要记作 \(P_H = 1\)，而不是两个低副

    上一页讲高副低代时给过一个规律：高副（\(P_H=1\)）恰好可以替换掉「一个低副 + 一个构件」， 而自由度保持不变。齿轮机构正好是这条规律最常出现的场合 —— 一对齿轮（2 个构件 + 1 个高副）和一个「三杆两低副」结构在自由度上是等价的。

    为什么齿轮必须做成高副

    低副是面接触，约束多（2 个），转动副就是这样。 但齿轮必须同时做两件事：一边传递转动，一边约束两轮的转速比。

    如果做成面接触的低副，两个轮子就被锁死了，根本转不动。 做成高副（只约束 1 个方向），两个轮子才能各自绕自己的轴转， 而转速比由齿数这个纯几何量保证

    所以「高副」不是缺点，而是齿轮能工作的必要条件。

    5.3 常见类型¶

    课件 1.4 节列出的齿轮类型有：正齿轮、内齿轮、齿轮齿条、直齿锥齿轮、蜗轮蜗杆。 此外还给了齿轮的两个关键几何量：

    几何量 含义 关系
    模数 \(m\) 表示齿轮大小的基准量 齿距 \(p = \pi m\)
    齿数 \(z\) 轮上有几个齿 分度圆周长 \(= \pi d = p z = \pi m z\)

    由「分度圆周长」这一条能直接推出分度圆直径公式： 两边同除以 \(\pi\) 得

    \[d = m z\]

    模数 \(m\) 相同的一对齿轮才能啮合（因为齿距 \(p = \pi m\) 必须一致）✓ 模数越大，齿越大、轮越大、能传的扭矩也越大。

    类型 一句话特点
    正齿轮（直齿圆柱齿轮） 最常见的类型，齿与轴平行，制造简单，但有冲击噪声
    内齿轮 齿开在圆环内侧，两轮转向相同（外啮合是反向的）
    齿轮齿条 把转动变成直线移动，是换运动形式最常用的办法之一
    直齿锥齿轮 用在两根相交轴之间，常见是 90° 交角
    蜗轮蜗杆 两轴垂直交错，单级就能得到很大的减速比，且能自锁

    同一对齿轮的转向关系要记清：外啮合（两轮在外面咬）转向相反； 内啮合转向相同。每加一级外啮合，转向就反一次

    5.4 齿系（Gear train）：多级传动比是各级之积¶

    齿系就是把多个齿轮串成一串，前一级的从动轮变成后一级的主动轮：

    1
2
    轮1(主动) ──啮合── 轮2 ─┬─ 同一个轴 ─┐ 轮3(主动) ──啮合── 轮4(从动)
                        └────────────┘

    推导思路（这是本页最重要的推导之一）：

    设这一串里有 \(k\) 级，各级的传动比是 \(i_1, i_2, \dots, i_k\)。 按定义，传动比等于「输出转速比」的倒数那一侧：

    \[i_1 = \frac{n_1}{n_2},\quad i_2 = \frac{n_2}{n_3},\quad \dots,\quad i_k = \frac{n_k}{n_{k+1}}\]

    第一步：把这一串比例连乘。

    \[i_1 \cdot i_2 \cdots i_k = \frac{n_1}{n_2} \cdot \frac{n_2}{n_3} \cdots \frac{n_k}{n_{k+1}}\]

    第二步：右边的分子分母开始成对约掉 —— 第一个分式的分母 \(n_2\) 和第二个分式的分子 \(n_2\) 是同一个量，约掉； 依次类推，只有最开头的 \(n_1\) 和最末尾的 \(n_{k+1}\) 留了下来：

    \[i_1 i_2 \cdots i_k = \frac{n_1}{n_{k+1}} = i_{\text{总}}\]

    结论：

    \[\boxed{\;i_{\text{总}} = i_1 \cdot i_2 \cdots i_k\;}\]

    多级传动比是各级相乘，不是相加。 每一级的减速比是 4，串两级就是 \(4 \times 4 = 16\) 倍减速，而不是 8 倍

    再用齿数写一遍（因为每级 \(i = z_{\text{从}}/z_{\text{主}}\)）：

    \[i_{\text{总}} = \frac{z_2}{z_1} \cdot \frac{z_4}{z_3} \cdots\]

    多级传动比最容易错的地方：乘还是加

    说法 对不对
    两级减速比各为 4，总减速比 \(= 4 \times 4 = 16\) ✓ 对
    两级减速比各为 4，总减速比 \(= 4 + 4 = 8\) ✗ 错 ⚠

    为什么直觉容易错：会误以为「两级各减速 4 倍，加起来就是减慢了 8 倍」。 但减速是乘性的：第一级把 1000 r/min 变成 250 r/min， 第二级再在 250 的基础上除以 4 变成 62.5 r/min —— 是连续地除，所以是相乘。

    一句话记法：传动比是比值的比，比值链式传递就要连乘

    5.5 优点与缺点¶

    优点 为什么
    传动比准确 ✓ 啮合传动，不打滑
    结构紧凑 ✓ 一对齿轮就能实现较大减速比，占地很小
    效率高 ✓ 一般单级 96% 以上，远高于蜗杆
    能传很大功率 ✓ 齿面接触强度高，可做到千瓦到兆瓦级
    寿命长 金属齿面，比皮带耐用
    传动比范围大 多级串联可做到几百甚至上千
    缺点 为什么
    制造精度要求高 ⚠ 齿形、中心距都要精确，否则噪声大、磨损快
    无过载保护 ⚠ 过载直接断齿，不像皮带能打滑
    不适宜远距离 两轮必须挨着，中间传不过去
    需要润滑和密封 齿轮箱必须保证油不泄漏
    有噪声和振动 齿的周期性啮入啮出会产生噪声

    六、凸轮与从动件（Cam and follower）¶

    6.1 工作原理：靠轮廓形状决定运动规律¶

    凸轮机构由两个基本件组成：

    零件 作用
    凸轮（Cam） 一个轮廓形状被精心设计的转动（或移动）件
    从动件（Follower） 始终贴着凸轮轮廓的零件，被轮廓推着动

    动力是这样传过去的：

    1. 凸轮转动（或移动）；
    2. 从动件在弹簧或重力作用下始终压紧凸轮的工作轮廓；
    3. 凸轮轮廓高低起伏，从动件就被顶起来、再落下去；
    4. 于是从动件的位移完全由轮廓形状决定。

    注意「接触」这一层：凸轮与从动件之间是高副（点接触或线接触）， 这一点和齿轮一样，算自由度时记 \(P_H = 1\)

    6.2 最大价值：能实现任意指定的运动规律¶

    这是凸轮机构独一无二的地方，也是它至今不可替代的原因。

    先说别的传动能做到什么：

    传动 输入输出关系
    带 / 链 / 齿轮 只能做到「转速成固定比例」这一种关系
    连杆 只能做到「由杆长决定的那几种有限关系」
    凸轮 能实现任意指定的运动规律 ✓

    为什么凸轮能做到任意：因为从动件的位移 \(s\) 与凸轮转角 \(\varphi\) 之间的关系 \(s = f(\varphi)\) 是直接把轮廓画出来得到的。 想要什么样的 \(s(\varphi)\) 曲线，就把轮廓的径向距离按这条曲线做出来：

    \[s(\varphi) = \rho(\varphi) - \rho_0\]

    其中 \(\rho(\varphi)\) 是凸轮在转角 \(\varphi\) 处的向径（从转动中心到轮廓的距离）， \(\rho_0\) 是基圆半径（轮廓上离中心最近处的向径）。

    凸轮转一个角度，从动件就上升一段，上升多少等于「向径减去基圆半径」。 所以想指定运动规律，就等于指定向径随转角的变化

    这才是凸轮真正的本事：它把「运动规律设计」变成了「轮廓曲线设计」。 内燃机要按严格的「吸气-压缩-做功-排气」时序开关气门，只有凸轮能做到。

    6.3 从动件的三种形式¶

    形式 形状 优点 缺点
    尖底从动件 底是一个尖点 能贴合任意复杂轮廓，结构最简单 磨损极快 ⚠，尖点接触应力巨大
    滚子从动件 底是一个可自转的滚子 摩擦磨损小 ✓，可传较大载荷 滚子有局部自由度，结构略复杂
    平底从动件 底是一个平面 接触应力小、润滑好、不易磨损 只能配凸形轮廓，凹轮廓会卡住 ⚠

    6.4 与自由度的联系：滚子带来「局部自由度」¶

    上一页讲过「局部自由度」这个概念。滚子从动件就是它最经典的实例：

    1
2
    从动件的整体上下运动  ← 真正在工作
滚子绕自身轴的转动    ← 局部自由度，不影响整体运动

    为什么滚子自转是局部自由度： 滚子自转只是让它自己在凸轮表面滚动，从而把滑动摩擦变成滚动摩擦。 但滚子转多少圈，完全不改变从动件的位移 —— 它不参与「机构要完成什么运动」这件事。

    在算自由度时怎么处理：局部自由度应当预先扣除， 否则算出来的 \(F\) 会偏小

    上一页的结论可以直接用：如果忘了扣掉滚子这个局部自由度， 算出来的 \(F\) 会比真实值小 1。

    滚子从动件是「故意的局部自由度」

    普通机构里的局部自由度往往是设计疏忽， 但滚子从动件里的滚子是主动加上去的 —— 目的就是把滑动摩擦换成滚动摩擦，大幅降低磨损

    问题 答案
    滚子自转影响从动件位移吗？ 不影响 ✗
    那它为什么要存在？ 为了减摩 ✓
    算自由度时怎么处理？ 先扣掉它 ⚠

    所以「局部自由度」不总是坏事 ——它是可以刻意设计进来的。

    6.5 缺点¶

    缺点 为什么
    高副，易磨损 ⚠ 点/线接触，接触应力大；尖底从动件尤其严重
    轮廓加工难 要做出精确的非圆曲线，工艺成本高
    从动件行程有限 向径变化范围受凸轮尺寸限制
    需要压紧装置 必须用弹簧或重力保证从动件始终贴住轮廓，否则会「飞脱」
    高速时冲击大 从动件有惯性，转速太高会脱开轮廓或撞出噪声

    6.6 偏心圆凸轮：从轮廓形状算出从动件位移¶

    下面用偏心圆凸轮（一个简单的圆，但转动中心不在圆心）来算从动件位移。 设凸轮的圆心与转动中心相距 \(e\)（偏距），凸轮半径为 \(R\)。

    凸轮转过角 \(\varphi\) 时，从转动中心到轮廓的向径 \(\rho(\varphi)\) 可以用余弦定理求出：

    \[\rho(\varphi) = e\cos\varphi + \sqrt{R^2 - e^2\sin^2\varphi}\]

    符号定义：\(e\) 是偏距（mm），\(R\) 是凸轮半径（mm），\(\varphi\) 是凸轮转角（弧度）。 根号里 \(R^2 - e^2\sin^2\varphi\) 在 \(e \lt R\) 时恒为正，所以向径总是有实数解。

    6.7 逐级推导：偏心圆凸轮的向径公式¶

    向径公式看起来有点吓人，其实只用了一次余弦定理。

    第 1 步：画三角形。 三个顶点分别是：转动中心 \(O\)、凸轮几何中心 \(C\)、轮廓上的接触点 \(P\)。 已知 \(OC = e\)（偏距）、\(CP = R\)（半径），要求的 \(OP\) 就是向径 \(\rho\)。

    第 2 步：确定夹角。 当凸轮转过 \(\varphi\) 时， 从 \(O\) 看 \(C\) 的方向与从 \(C\) 看 \(P\) 的方向之间的夹角…… 用 \(\angle OCP\) 记为 \(\gamma\)。由几何关系 \(\gamma = 180° - \varphi\)， 于是 \(\cos\gamma = -\cos\varphi\)。

    第 3 步：写余弦定理。 在三角形 \(OCP\) 中，对边 \(OP\) 所对的角是 \(\gamma\)：

    \[\rho^2 = e^2 + R^2 - 2eR\cos\gamma = e^2 + R^2 + 2eR\cos\varphi\]

    第 4 步：化成课件的形式。 把上式两边配方。注意

    \[(e\cos\varphi + \rho)^2 = e^2\cos^2\varphi + 2e\rho\cos\varphi + \rho^2\]

    这条式子暂时用不上，改从 \(\rho^2 - 2e\rho\cos\varphi + e^2\cos^2\varphi = R^2 - e^2\sin^2\varphi\) 入手 （把第 3 步的 \(e^2\) 拆成 \(e^2\cos^2\varphi + e^2\sin^2\varphi\) 再移项）。左边正好是一个完全平方：

    \[(\rho - e\cos\varphi)^2 = R^2 - e^2\sin^2\varphi\]

    第 5 步：开方取正根。 向径是长度，取正号：

    \[\rho(\varphi) = e\cos\varphi + \sqrt{R^2 - e^2\sin^2\varphi}\]

    第 6 步：从动件位移。

    \[s(\varphi) = \rho(\varphi) - \rho_{\min},\qquad \rho_{\min} = R - e\]

    \(\rho_{\min}\) 出现在 \(\varphi = 180°\) 处（\(\cos180° = -1\)，且根号取 \(R\)）， 此时 \(\rho = -e + R = R - e\)

    凸轮给从动件的位移完全由 \(\rho(\varphi)\) 决定。 想让从动件走什么规律，就把轮廓做成对应的向径函数 —— 这是凸轮唯一不可替代的能力，齿轮、带、链都做不到。

    七、皮带 / 绳索 / 链条：三种柔性传动¶

    课件把这三者写在一起：「皮带(Belt)、绳索(Cable/Chain)」， 它们的共同点是 —— 都是柔性件，可以弯、可以绕、可以把动力送到远处。

    7.1 绳索：只能承受拉力¶

    绳索（Cable） 的工作原理很朴素：拉。

    • 绳索只能承受拉力，不能受压（一压就弯了）、不能受弯（会散股）。
    • 所以绳索传动必须是封闭回路或配重回路： 一头拉，另一头的负载就被拽动。

    典型用途：起重机、电梯、卷扬机、索道。

    绳索的特点 说明
    承载能力 只能拉 ⚠，受力方向单一
    传动比 无固定传动比（滑轮组只改变力与绳速的关系）
    距离 很远 ✓，几百米都可以
    精度 差（有弹性伸长、打滑、摆动）
    优点 极轻、极远、成本低
    缺点 不能反向传动、不能精确定位

    八、简单机械（Simple machine）¶

    8.1 它们是最古老的传动，但至今还在用¶

    课件回顾了历史上被列出的五种（后来是六种）简单机械：

    简单机械 英文 一句话作用

    轮轴 Wheel & axle 大轮转一圈，轴上绕的绳收一圈
    滑轮 Pulley 改变力的方向，或成倍减小所需的力
    斜面 Inclined plane 用长距离换取小推力

    课件还提到，斜面、楔块、螺杆这三者本质上是同一个原理的不同外形： 楔块 = 移动的斜面；螺杆 = 卷在圆柱上的斜面

    8.2 机械优势（Mechanical Advantage）¶

    机械优势回答的问题：用很小的力，能撬起多大的重物？

    定义（理想机械优势 IMA）：

    \[IMA = \frac{F_{\text{输出}}}{F_{\text{输入}}} = \frac{d_{\text{输入}}}{d_{\text{输出}}}\]

    符号定义：\(F_{\text{输入}}\) 是你施加的力，\(F_{\text{输出}}\) 是机器克服的载荷； \(d_{\text{输入}}\) 是你施力点移动的距离，\(d_{\text{输出}}\) 是载荷移动的距离。

    推导思路：机器不产生能量（课件明确说了这一点），所以理想情况下 「输入做的功 = 输出做的功」，也就是

    \[F_{\text{输入}} \cdot d_{\text{输入}} = F_{\text{输出}} \cdot d_{\text{输出}}\]

    两边同除以 \(F_{\text{输入}} d_{\text{输出}}\)（两者均不为零），就得到

    \[IMA = \frac{F_{\text{输出}}}{F_{\text{输入}}} = \frac{d_{\text{输入}}}{d_{\text{输出}}}\]

    你在长距离上使小力，机器就在短距离上出大力。 力放大的倍数，正好等于你多走的距离倍数 —— 代价是速度变慢

    课件在斜面的例子里把这个结论写成了数字： 假设 \(R = 18\) cm、\(P = 1/8\) cm，要提升 \(1500\) kg， 则 \(F\) 处所需力是 \(1.6579\) kg —— 并且「提升的重量的移动速度比 F 处施加的力慢得多」。 这就是「省力必然费距离」的直接体现。

    8.3 各种简单机械的机械优势公式¶

    简单机械 机械优势公式 符号含义
    杠杆 \(IMA = \dfrac{l_{\text{输入}}}{l_{\text{输出}}}\) \(l\) 为力臂长度
    轮轴 \(IMA = \dfrac{R_{\text{轮}}}{R_{\text{轴}}}\) \(R\) 为半径
    滑轮（n 段绳） \(IMA = n\) \(n\) 为承担载荷的绳段数
    斜面 \(IMA = \dfrac{L}{h} = \dfrac{1}{\sin\alpha}\) \(L\) 斜面长，\(h\) 高，\(\alpha\) 倾角
    楔块 \(IMA = \dfrac{L}{t}\) \(L\) 楔长，\(t\) 楔厚
    螺钉 \(IMA = \dfrac{2\pi r}{p}\) \(r\) 手柄半径，\(p\) 螺距

    斜面公式的推导思路（课件 1.1 节点明了斜面的机械优势）：

    一个倾角为 \(\alpha\) 的斜面，沿斜面推上去的长度是 \(L\)，竖直抬起的高度是 \(h\)。 由直角三角形，\(h = L\sin\alpha\)，所以

    \[IMA = \frac{L}{h} = \frac{L}{L\sin\alpha} = \frac{1}{\sin\alpha}\]

    斜面越平缓（\(\alpha\) 越小），\(\sin\alpha\) 越小，机械优势越大 但代价是你要沿着斜面走更长的路。

    螺钉为什么那么省力：螺距 \(p\) 很小，手柄转一圈手柄端点走了 \(2\pi r\) 那么远， 而螺钉只前进 \(p\) 那么多。所以 \(IMA = 2\pi r / p\) 往往能达到几十甚至上百

    8.5 逐级推导：机械优势为什么是「力臂之比」¶

    机械优势（Mechanical Advantage, MA）的定义是输出力与输入力之比：

    \[MA = \frac{F_{\text{out}}}{F_{\text{in}}}\]

    第 1 步：从「功守恒」出发。 理想机械（无摩擦、无自重）不创造能量，所以 「输入功 = 输出功」：

    \[F_{\text{in}} s_{\text{in}} = F_{\text{out}} s_{\text{out}}\]

    其中 \(s_{\text{in}}\)、\(s_{\text{out}}\) 分别是输入端和输出端走过的距离。

    第 2 步：解出力之比。

    \[\frac{F_{\text{out}}}{F_{\text{in}}} = \frac{s_{\text{in}}}{s_{\text{out}}}\]

    第 3 步：读出结论。 机械优势等于输入位移比输出位移。 换句话说：想放大多少力，就得让输入端多走多少路 —— 这就是「省力必然费距离」的算式来源，和前面传动里 「降转速必然升扭矩、功率不变」是同一条原理的两种写法。

    第 4 步：应用到杠杆。 杠杆绕支点转一个小角 \(\Delta\theta\)， 两端走过的弧长分别是 \(s_{\text{in}} = l_{\text{in}}\Delta\theta\)、 \(s_{\text{out}} = l_{\text{out}}\Delta\theta\)，代入第 2 步：

    \[MA = \frac{l_{\text{in}}\Delta\theta}{l_{\text{out}}\Delta\theta} = \frac{l_{\text{in}}}{l_{\text{out}}}\]

    \(\Delta\theta\) 被约掉 —— 所以机械优势只跟力臂长度有关，与转过多少角度无关

    第 5 步：应用到斜面。 沿长 \(L\) 的斜面把物体推上高度 \(h\)， 输入位移是 \(L\)（沿斜面走），输出位移是 \(h\)（竖直抬高）。 由几何关系 \(h = L\sin\alpha\)（\(\alpha\) 为倾角）：

    \[MA = \frac{L}{h} = \frac{L}{L\sin\alpha} = \frac{1}{\sin\alpha}\]

    第 6 步：应用到滑轮组。 用 \(n\) 段绳承担载荷时， 载荷上升 \(d\)，每段绳都要缩短 \(d\)，共需拉出 \(nd\) 的绳长。 即 \(s_{\text{out}} = d\)、\(s_{\text{in}} = nd\)，于是

    \[MA = \frac{nd}{d} = n\]

    三种简单机械的公式形式完全不同， 但全部来自同一条 \(F_{\text{in}}s_{\text{in}} = F_{\text{out}}s_{\text{out}}\)。 记住这条，考试时即使忘了某个公式，也能按「位移怎么变」现场推出来。

    机械优势不是越大越好

    \(MA\) 越大，同样的输入力能顶起越重的载荷， 但输出端的速度也同比例变慢，或者要拉的绳/推的行程同比例变长。 实际机器的 \(MA\) 还受摩擦、自重、绳索与滑轮的磨损拖累， 真实的省力倍数总是小于理想值 \(MA\)。 若看到某方案标称 \(MA\) 极大，先怀疑两件事： 输出行程是否被压缩到不可用，以及是否把摩擦损失算漏了

    九、连杆（Linkage）¶

    9.1 工作原理：用转动副把多个刚体连起来¶

    连杆机构是把几根刚性杆件用转动副（铰链）首尾相接， 再固定其中一根（机架），其余杆件就能按确定的规律运动。

    课件 1.5 节说得很清楚：铰链四连杆机构是有四个杆件通过铰链连接而成的传动机构。

    核心特征：连杆机构里用到的运动副全部是转动副（或移动副）， 也就是低副 —— 面接触

    9.2 优点：低副、承载大、耐磨损¶

    优点 为什么
    低副（面接触） ✓ 接触面积大，压强小，不像高副那样容易磨损
    承载能力大 ✓ 面接触能承受很大的力，适合重型机械
    耐磨损、寿命长 ✓ 压强小、磨损慢，维护简单
    制造容易 ✓ 转动副就是一个圆孔配一根圆柱销，加工精度要求比齿轮齿廓低
    能实现多种运动形式 ✓ 转动 → 往复、转动 → 摆动、转动 → 复杂轨迹

    为什么「低副」这件事被反复强调 —— 把它和齿轮、凸轮放在一起看就清楚了：

    机构 运动副类型 接触方式 承载与磨损
    连杆 低副 ✓ 面接触 承载大、磨损慢 ✓
    齿轮 高副 线接触 承载中等、需润滑
    凸轮 高副 ⚠ 点/线接触 承载小、磨损快 ⚠

    一句话结论：要承载大、要耐用，就选连杆；要传动比准，就选齿轮

    十一、传动比计算的两个易错点¶

    11.1 易错点一：多级传动要比比相乘，不是相加¶

    这个坑在第五节已经推过，这里再强调一次它错在哪、怎么自查。

    错法：把各级传动比加起来当总传动比。 对法：连乘。

    \[i_{\text{总}} = i_1 \cdot i_2 \cdots i_k \quad \text{（不是 } i_1 + i_2 + \cdots + i_k \text{）}\]

    自查办法（非常好用）：算完之后，用齿数直接验算一遍。

    \[i_{\text{总}} = \frac{z_2}{z_1} \cdot \frac{z_4}{z_3} \cdot \frac{z_6}{z_5}\]

    如果中间轴上的齿轮是同一个轮（既是从动轮又是主动轮，\(z_2 = z_3\)）， 那它应该在乘积里被约掉：

    \[i_{\text{总}} = \frac{z_2}{z_1} \cdot \frac{z_4}{z_2} = \frac{z_4}{z_1}\]

    如果输入轴和输出轴之间只传递扭矩、不换速，中间那个惰轮（idler）不影响总传动比 它只改变转向（每过一个外啮合惰轮，转向反一次）。

    所以有一个极好用的验算：把总传动比写成「所有从动轮齿数之积 ÷ 所有主动轮齿数之积」：

    \[i_{\text{总}} = \frac{\prod z_{\text{从}}}{\prod z_{\text{主}}}\]

    如果分母里的某个齿数在分子里也出现了，说明它是惰轮，约掉它不影响结果

    11.2 易错点二：扭矩与转速成反比¶

    这是传动里最基本的守恒关系，也是最容易被忘掉的一条。

    推导思路：理想情况下（忽略摩擦损失），传动机构不产生也不消耗能量， 所以输入功率等于输出功率。功率的定义是

    \[P = T \omega\]

    符号定义：\(P\) 是功率（W），\(T\) 是扭矩（N·m），\(\omega\) 是角速度（rad/s）。

    第一步：输入端和输出端的功率相等。

    \[T_1 \omega_1 = T_2 \omega_2\]

    第二步：角速度与转速成正比（\(\omega = 2\pi n / 60\)）， 两边的 \(2\pi/60\) 是同一个常数，约掉后用转速代替角速度：

    \[T_1 n_1 = T_2 n_2\]

    第三步：把 \(n_1/n_2 = i\) 代进去：

    \[\boxed{\;\frac{T_2}{T_1} = \frac{n_1}{n_2} = i\;}\]

    传动比 \(i\) 是「转速减小的倍数」，同时是「扭矩放大的倍数」

    传动比 \(i\) 输出转速 输出扭矩
    \(i = 4\) 变成 \(1/4\) 变成 4 倍 ✓
    \(i = 10\) 变成 \(1/10\) 变成 10 倍 ✓
    \(i = 1\) 不变 不变
    \(i = 0.5\)（增速） 变成 2 倍 变成一半 ⚠

    「减速」永远等价于「增扭」—— 这是选择题的高频考点

    看到「减速」两个字，就要立刻反应出「扭矩变大了」，反过来也一样：

    说法 对不对
    减速箱既能降低转速，又能增大扭矩 ✓ 对，同一件事的两面
    减速箱能把转速降低，但扭矩不变 ✗ 错 ⚠
    想同时要高速和大扭矩，装个减速箱就行 ✗ 错 ⚠ 二者此消彼长

    公式 \(T_1 n_1 = T_2 n_2\) 会自动替你把关： 只要记住它是「乘积守恒」，任何一边想多拿，另一边就必须少给 ✓

    注意它的前提是「忽略损失」。考虑效率 \(\eta\) 之后应当是

    \[T_1 n_1 \eta = T_2 n_2\]

    也就是说，实际输出的扭矩比理想值小一个 \(\eta\) 倍（11.3 节会算）。

    11.3 各级效率相乘：总效率也是连乘¶

    传动过程中的摩擦会吃掉一部分功率。设单级效率为 \(\eta\)（\(0 \lt \eta \lt 1\)）， \(k\) 级串联之后：

    \[\eta_{\text{总}} = \eta_1 \cdot \eta_2 \cdots \eta_k\]

    推导思路：第一级的输出功率是 \(P_1 \eta_1\)， 它又是第二级的输入，第二级的输出是 \((P_1 \eta_1)\eta_2 = P_1 \eta_1 \eta_2\)， 依次下去，第 \(k\) 级输出 \(P_1 \eta_1 \eta_2 \cdots \eta_k\)。除以输入就得到上式

    这条规律的重要推论：级数越多，总效率越低， 而且降得很快。例如每级 \(\eta = 0.97\)：

    级数 总效率
    1 0.970
    2 0.941
    3 0.913
    5 0.859
    10 0.738

    所以「多级串联」是有代价的： 虽然能得到很大的传动比，但每加一级就损失一份功率

    for i_k, eta_k in stages:
        i_total *= i_k
        eta_total *= eta_k

    P_out = T_real * w_out
    print("%-6d %-9.3f %-12.3f %-13.2f %-13.2f %-11.4f %.2f"
          % (k, round(i_total, 3), round(n_out, 3), round(T_ideal, 2),
             round(T_real, 2), round(eta_total, 4), round(P_out, 2)))

    很多人选型只看「传动比」和「距离」， 结果在偶尔会卡死的机器上装了齿轮箱 —— 一旦卡死，断齿，整台机器停产

    手动千斤顶 不会（人自己控力） 螺杆 ✓

    一句话：「可能堵转」的场合优先用带传动

    12.3 判据的优先级：四个问题按顺序问¶

    12.1 的决策流程可以用四个按优先级排列的问题来描述， 后面的问题只有在前面都不成立时才需要问：

    顺序 问什么 若「是」选谁 为什么它排在这一位
    1 传动比必须准确吗？ 齿轮 / 同步带 / 链 / 蜗杆 精度是硬指标，不满足则方案直接作废
    2 需要过载保护吗？ 带传动 只有摩擦带能靠打滑当保险丝
    3 需要复杂运动规律吗？ 凸轮 只有凸轮能把规律做成轮廓
    4 要大承载、便宜、耐用吗？ 连杆 低副面接触，承载大、耐磨损、成本低

    为什么是这个顺序：第 1 问若答「是」，后面三问根本不用问 —— 因为只有啮合类才准，带传动已被排除，它自然也就失去了过载保护这个优点。 反过来，若第 1 问答「否」，才轮到第 2 问：既然允许不准， 那不如用带传动顺带拿到「打滑保命」的好处。 这四问是一条链，不能跳着问、也不能并列问 ✓

    典型场合手算对照表（按上面的顺序逐行判断）：

    场合 准确？ 过载保护？ 复杂规律？ 大承载？ 距离 大速比？ 手推结论
    数控机床进给轴 是 — — — 近 否 问 1 命中且距离近 → 齿轮
    物料传送带 否 是 — — 远 否 问 1 否、问 2 命中 → 带传动
    内燃机配气 否 否 是 — 近 否 前两问皆否、问 3 命中 → 凸轮
    冲压机主传动 否 否 否 是 近 否 前三问皆否、问 4 命中 → 连杆
    自行车后轮驱动 是 — — — 中 否 问 1 命中，距离不算远 → 齿轮或链
    起重卷扬 是 — — — 远 是 问 1 命中、要大速比 → 蜗杆或多级齿轮

    同一份需求表，只要按顺序问四句，答案就唯一了。 注意「物料传送带」和「起重卷扬」都被问到第 2 问附近， 但前者答「不需要准确」而后者答「需要准确」， 结论就从带传动分岔到蜗杆 —— 第 1 问的答案决定了后面全部走向。

    把这四问当成并列清单是最常见的选型错误

    四个问题不是并列的评分项，而是有优先级的分支。 如果把它们当成「哪条满足得多就选哪个」， 就会出现「物料传送带既想要过载保护、又想要耐用， 于是选了连杆」这种荒唐结论 —— 连杆根本不提供过载保护，也不适合远距离。 正确做法：严格按 1→2→3→4 顺序问， 一旦某一问答「是」就停止提问、直接选型

    十三、典型例题¶

    例题 1：单级带传动的输出转速¶

    一台电机输出转速 \(n_1 = 1450\) r/min，主动带轮直径 \(D_1 = 80\) mm， 从动带轮直径 \(D_2 = 240\) mm，忽略打滑。求传动比与从动轮转速。

    思路

    直接用带传动的传动比公式 \(i = D_2/D_1\)， 再用 \(n_2 = n_1 / i\)。注意两个直径单位一致就行，比值无量纲。

    解答

    第一步：写公式并代入。

    \[i = \frac{D_2}{D_1} = \frac{240}{80} = 3\]

    第二步：求输出转速。

    \[n_2 = \frac{n_1}{i} = \frac{1450}{3} \approx 483.33\ \text{r/min}\]

    第三步：验算（用 \(D_1 n_1 = D_2 n_2\)）。

    \[D_1 n_1 = 80 \times 1450 = 116000\]
    \[D_2 n_2 = 240 \times 483.33 \approx 116000\]

    两边相等 ✓ 计算无误。

    结论：传动比 \(i = 3\)，从动轮转速约 483.33 r/min， 从动轮转得比主动轮慢 3 倍。

    追问：如果从动轮半径太大装不下，还有什么办法？ 答：改成多级传动（两级 \(i = 3\) 可以用 \(\sqrt{3} \approx 1.732\) 分配）， 或者改用链传动/齿轮传动。带传动单级传动比不宜超过 7，主要受打滑限制

    例题 2：两级齿轮系的总传动比¶

    一个两级齿轮减速箱：第一级 \(z_1 = 20\)、\(z_2 = 60\)； 第二级 \(z_3 = 18\)、\(z_4 = 72\)。输入转速 \(n_1 = 1440\) r/min。求总传动比与输出转速。

    思路

    重点在「相乘不相加」。分别算两级传动比，再连乘。 最后用「各级转速连续去除」验算一遍。

    解答

    第一步：算第一级传动比。

    \[i_1 = \frac{z_2}{z_1} = \frac{60}{20} = 3\]

    第二步：算第二级传动比。

    \[i_2 = \frac{z_4}{z_3} = \frac{72}{18} = 4\]

    第三步：连乘求总传动比。

    \[i_{\text{总}} = i_1 \times i_2 = 3 \times 4 = 12\]

    错误对照：如果误加成 \(3 + 4 = 7\)，结果会差近一倍

    第四步：求输出转速。

    \[n_{\text{出}} = \frac{n_1}{i_{\text{总}}} = \frac{1440}{12} = 120\ \text{r/min}\]

    第五步：逐级验算。

    经过 转速
    输入轴 \(1440\) r/min
    过第一级（\(i_1 = 3\)） \(1440 / 3 = 480\) r/min
    过第二级（\(i_2 = 4\)） \(480 / 4 = 120\) r/min

    与第四步一致

    结论：总传动比 \(i_{\text{总}} = 12\)，输出转速 120 r/min。

    顺带一问：如果忽略损失，输出扭矩是多少（设输入扭矩 \(T_1 = 8\) N·m）？

    \[T_{\text{出}} = T_1 \cdot i_{\text{总}} = 8 \times 12 = 96\ \text{N·m}\]

    减速 12 倍 = 增扭 12 倍

    例题 3：链传动的齿数与瞬时速度波动¶

    一链传动：主动链轮 \(z_1 = 19\)，从动链轮 \(z_2 = 57\)， 主动轮转速 \(n_1 = 900\) r/min。 求传动比、从动轮转速，并算出瞬时速度的波动幅度。

    思路

    传动比用 \(i = z_2/z_1\)。 波动幅度用 4.4 节的结论：\(1 - \cos(180°/z)\)， 这里的齿数取小链轮（\(z_1\)，因为小轮的多边形效应更明显）。

    解答

    第一步：传动比。

    \[i = \frac{z_2}{z_1} = \frac{57}{19} = 3\]

    第二步：从动轮转速（平均）。

    \[n_2 = \frac{n_1}{i} = \frac{900}{3} = 300\ \text{r/min}\]

    第三步：瞬时速度波动。

    小链轮 \(z_1 = 19\)，半角为

    \[\frac{180°}{19} \approx 9.474°\]

    波动幅度为

    \[1 - \cos(9.474°) = 1 - 0.98636 \approx 0.01364\]

    换算成百分比约 1.36%。

    第四步：解释为什么用 \(z_1\) 而不是 \(z_2\)。

    链轮 齿数 半角 波动幅度
    小链轮 19 9.474° 1.364%
    大链轮 57 3.158° 0.152%

    波动由齿数少的那一侧决定 —— 因为 \(180°/z\) 里 \(z\) 在分母， \(z\) 越小角度越大、\(\cos\) 越小、波动越大

    结论：\(i = 3\)、\(n_2 = 300\) r/min、 瞬时速度波动约 1.36%（由小链轮决定）。

    工程含义：这就是「链传动平均准确、瞬时略抖」的具体数字 要更平稳，就把小链轮的齿数选大一些（但会增加尺寸）。

    例题 4：凸轮从动件的位移¶

    一个偏心圆凸轮，凸轮半径 \(R = 30\) mm，偏距 \(e = 6\) mm。 求凸轮转过 \(0°\)、\(60°\)、\(120°\)、\(180°\) 时从动件的向径与位移。 并说明「要改成简谐运动规律该怎么做」。

    思路

    向径用 6.6 节给的余弦公式： \(\rho = e\cos\varphi + \sqrt{R^2 - e^2\sin^2\varphi}\)。 位移 \(s = \rho - \rho_{\min}\)，其中 \(\rho_{\min} = R - e\)。 最后一问要用「轮廓即规律」这条认识来回答。

    解答

    第一步：先算最低点（基圆半径）。

    \[\rho_{\min} = R - e = 30 - 6 = 24\ \text{mm}\]

    第二步：逐角度代入。

    取 \(\varphi = 0°\)： \(\sin 0° = 0\)，\(\cos 0° = 1\)，所以

    \[\rho = 6 \times 1 + \sqrt{30^2 - 0} = 6 + 30 = 36\ \text{mm},\quad s = 36 - 24 = 12\ \text{mm}\]

    取 \(\varphi = 60°\)： \(\sin 60° = 0.8660\)，\(\cos 60° = 0.5\)，

    \[\rho = 6 \times 0.5 + \sqrt{900 - 36 \times 0.75} = 3 + \sqrt{873} \approx 3 + 29.546 = 32.546\ \text{mm}\]
    \[s = 32.546 - 24 = 8.546\ \text{mm}\]

    取 \(\varphi = 120°\)： \(\sin 120° = 0.8660\)，\(\cos 120° = -0.5\)，

    \[\rho = -3 + \sqrt{873} \approx 26.546\ \text{mm},\quad s \approx 2.546\ \text{mm}\]

    取 \(\varphi = 180°\)： \(\sin 180° = 0\)，\(\cos 180° = -1\)，

    \[\rho = -6 + 30 = 24\ \text{mm},\quad s = 0\ \text{mm}\]

    第三步：汇总成表。

    转角 \(\varphi\) 向径 \(\rho\) / mm 位移 \(s\) / mm
    \(0°\) 36.000 12.000
    \(60°\) 32.546 8.546
    \(120°\) 26.546 2.546
    \(180°\) 24.000 0.000

    观察：凸轮转半圈（\(180°\)），从动件从最高 12 mm 降到 0 mm， 走的是一条光滑的非线性曲线 —— 这条曲线的形状完全由轮廓决定

    第四步：怎么改成简谐运动规律。

    简谐运动规律是

    \[s(\varphi) = \frac{h}{2}\left(1 - \cos\frac{2\pi\varphi}{\Phi}\right)\]

    要让从动件按它走，只需要照着这条曲线重新做轮廓： 把凸轮在转角 \(\varphi\) 处的向径改成

    \[\rho(\varphi) = \rho_{\min} + s(\varphi)\]

    也就是「先把想要的运动规律画出来，再把轮廓做成这个形状」。

    这就是凸轮最大的价值：其他传动都做不到这一点 —— 带、链、齿轮只能给出固定比例的转速关系，连杆只能给出杆长决定的那几种关系

    结论：位移依次为 12.000、8.546、2.546、0.000 mm； 要换规律，就按新规律重新设计轮廓的向径。

    十四、自测¶

    Q1 一个单级带传动，主动轮直径 120 mm，转速 960 r/min， 从动轮直径 360 mm，忽略打滑。传动比是多少？从动轮转速是多少？ 如果用同步带替代普通 V 带，输出转速会变还是不变？为什么？

    答案

    传动比：

    \[i = \frac{D_2}{D_1} = \frac{360}{120} = 3\]

    从动轮转速：

    \[n_2 = \frac{n_1}{i} = \frac{960}{3} = 320\ \text{r/min}\]

    换同步带后：会变大一点。

    原因：普通 V 带靠摩擦，会打滑，实际输出转速低于 320 r/min； 同步带靠齿形啮合，不打滑，输出转速严格等于 320 r/min

    所以「会变」——变的是实际值，理想值 320 只是普通 V 带达不到的上限

    Q2 判断对错并说明理由： （a）齿轮传动和凸轮传动都属于高副。 （b）带传动的传动比是准确的。 （c）多级齿轮传动的总传动比等于各级传动比之和。

    答案

    （a）对 ✓ 齿轮是齿面线接触、凸轮与从动件是点/线接触， 两者都是点或线接触，按定义都是高副，算自由度时记 \(P_H = 1\)。

    （b）错 ⚠ 带传动靠摩擦，载荷一大就打滑， 传动比会随载荷浮动，不准确。 只有同步带（齿形带，靠啮合）才准确。

    （c）错 ⚠ 应该是相乘：

    \[i_{\text{总}} = i_1 \cdot i_2 \cdots i_k\]

    因为每一级都是在前一级输出的转速上再除一次，是链式传递， 数学上表现为比值连乘（中间轴的转速会被约掉）。

    Q3 一个两级减速箱，总传动比 \(i_{\text{总}} = 20\)， 输入转速 \(n_1 = 1200\) r/min，输入功率 \(P_1 = 2\) kW。 忽略损失，求输出转速与输出扭矩。

    提示

    先用 \(n_{\text{出}} = n_1 / i_{\text{总}}\) 求转速， 再用 \(T_1 n_1 = T_2 n_2\)（或功率守恒 \(P = T\omega\)）求扭矩。 用功率算更直接：\(\omega = 2\pi n/60\)，\(T = P/\omega\)。

    答案

    第一步：输出转速。

    \[n_2 = \frac{n_1}{i_{\text{总}}} = \frac{1200}{20} = 60\ \text{r/min}\]

    第二步：把输入转速换成角速度，求输入扭矩。

    \[\omega_1 = \frac{2\pi n_1}{60} = \frac{2\pi \times 1200}{60} = 40\pi \approx 125.664\ \text{rad/s}\]
    \[T_1 = \frac{P_1}{\omega_1} = \frac{2000}{125.664} \approx 15.915\ \text{N·m}\]

    第三步：用 \(T_1 n_1 = T_2 n_2\) 求输出扭矩。

    \[T_2 = T_1 \cdot \frac{n_1}{n_2} = T_1 \cdot i_{\text{总}} = 15.915 \times 20 \approx 318.31\ \text{N·m}\]

    第四步：验算（输出功率应仍为 2 kW）。

    \[\omega_2 = \frac{2\pi \times 60}{60} = 2\pi \approx 6.283\ \text{rad/s}\]
    \[P_2 = T_2 \omega_2 = 318.31 \times 6.283 \approx 2000\ \text{W}\]

    与输入功率一致

    结论：输出转速 60 r/min，输出扭矩约 318.31 N·m。

    要点：减速 20 倍就是增扭 20 倍 如果考虑效率 \(\eta\)（比如三级齿轮 \(\eta_{\text{总}} = 0.91\)）， 实际输出扭矩只有 \(318.31 \times 0.91 \approx 289.66\) N·m

    Q4 某设备需要：把电机转速降到 1/60，输出轴离电机 2 米远， 且万一工作端卡死必须保护电机不被烧毁。应该选什么传动？说明理由， 并说明为什么其他几种不合适。

    提示

    把三个需求逐条对照第十二节的判据表： 「传动比」和「距离」决定候选范围，「过载保护」做最终筛选。

    解答

    第一步：拆出三个需求。

    需求 含义
    减速 1/60，精度要求不高 需要大传动比，但不要求严格准确
    距离 2 米 必须用柔性传动
    卡死时保护电机 必须能过载保护

    第二步：先按「距离」筛。

    距离 2 米 → 齿轮、凸轮、连杆全部排除（它们必须挨着装）✗ 只剩带、链、绳索。

    第三步：再按「过载保护」筛。

    候选 能否过载保护 结论
    带传动 能（打滑） ✓ 符合
    链传动 不能（断链） ✗
    绳索 不能（拉断） ✗

    第四步：按「大传动比」核对。

    单级带传动比一般不超过 7， 所以 \(1/60\) 要用多级带传动（\(i_{\text{总}} = i_1 i_2 \cdots\)）： 例如三级各 \(i \approx 3.91\)，因为

    \[3.91^3 \approx 59.8 \approx 60\]

    或者用「两级带传动 + 一级齿轮」的组合。

    第五步：给出答案。

    推荐：多级带传动（例如三级串联）。

    理由：只有带传动能在远距离下提供机械过载保护。 一旦工作端卡死，皮带打滑，电机空转但不会烧毁

    其他方案为什么不合适：

    方案 不合适的原因
    齿轮 远距离传不过去；过载断齿 ⚠
    链 远距离可以，但过载断链 ✗
    同步带 远距离可以，但齿形啮合过载会剪齿，无保护 ✗
    绳索 远距离可以，但只能单向拉、无保护 ✗
    凸轮 距离太远，且承载小、磨损快 ✗
    连杆 距离太远 ✗

    延伸思考：如果后来发现「精度也必须保证」， 那这个需求就自相矛盾了 —— 精度（要啮合）和保护（要打滑）在机械上不可兼得， 此时只能靠电气保护（如电流检测 + 变频器限矩）来补足

    小结¶

    要记住的 为什么
    传动机构改变四件事：转速、扭矩、运动形式、位置 这是它存在的全部理由
    结构元素只管支撑连接密封，不传运动 机架、轴、联轴器、轴承、紧固件、键、密封件
    传动类机械元件共六类 简单机械、齿轮/齿系、凸轮、皮带、绳索/链条、连杆
    带传动靠摩擦力 所以会打滑 → 传动比不准确 ⚠，但有过载保护 ✓
    带传动 \(i = D_2/D_1\)，由「皮带速度处处相同」推出 \(D_1 n_1 = D_2 n_2\) 是它的核心等式
    同步带是啮合，不打滑，传动比准确 但失去了过载保护 ⚠
    链传动靠啮合，\(i = z_2/z_1\)，平均准确 瞬时速度有多边形效应造成的波动 ⚠
    齿轮啮合是「高副」 线接触，算自由度时记 \(P_H = 1\) ✓
    齿轮 \(i = z_2/z_1\)；分度圆 \(d = mz\)；齿距 \(p = \pi m\) 模数相同才能啮合
    多级传动比是各级之积 \(i_{\text{总}} = i_1 i_2 \cdots\)（不是相加）⚠
    扭矩与转速成反比 \(T_1 n_1 = T_2 n_2\) → 减速就是增扭 ✓
    \(n_2 = n_1/i\)、\(T_2 = i\,T_1\)、\(P_2 = P_1\) 三条一起记 传动比只搬转速和扭矩，不搬运功率
    功率不变的算式来源 \(P_2 = (iT_1)(\omega_1/i) = T_1\omega_1 = P_1\)，\(i\) 被约掉 ✓
    总效率也是各级相乘，级数越多越低 \(0.97^{10} \approx 0.738\) ⚠
    凸轮能实现任意指定的运动规律 这是它不可替代的唯一价值 ✓
    凸轮是高副，易磨损；轮廓加工难 尖底从动件尤其严重 ⚠
    滚子从动件里的滚子有局部自由度 目的是减摩；算自由度时要先扣掉 ✓
    绳索只能承受拉力 所以无固定传动比、不能反向传动
    简单机械的机械优势 \(IMA = d_{\text{输入}}/d_{\text{输出}}\) 由「机器不产生能量」推出：省力必然费距离
    连杆用低副（面接触） 承载大、耐磨损、便宜，但传动比不固定 ✓
    「传动比准确」与「过载保护」不可兼得 六种传动里只有带能保护，而它恰恰不准确
    选型先问四个问题：准不准、要不要保护、规律复杂吗、承载大吗 见第十二节决策流程
