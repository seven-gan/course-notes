    2.1 运动空间与工作空间¶

    这一页回答一个设计机器时最先被问到的问题：这台机械臂能摸到哪儿？

    这个问题看起来像是一句玩笑，其实是机械臂设计的第一道门槛。 你的任务是要在某个位置拧一颗螺丝、浇一道焊缝、放一个工件， 如果机械臂根本够不到那个位置，那么后面的轨迹规划、力控制、 视觉伺服写得再漂亮都没有用 —— 因为物理上它就到不了。

    「能摸到哪儿」的那个区域，就是本页要讲的工作空间。

    这一页的核心问题

    一句话主线：

    工作空间 = 末端参考点所有能到达位置的集合， 它的形状由「杆长 + 关节限位 + 关节类型」三件事共同决定。

    本页的推理顺序是：先定义工作空间 → 说明它为什么常常是环状/球壳状 （中间有空洞）→ 逐条分析三个影响因素 → 指出空洞位置不是随便定的，而是被逆解的分界（奇异位形）切出来的。

    看完这一页，你应该能拿到一台机械臂的杆长和关节限位， 凭心算说出它能够到哪个范围、哪一圈是空的、把哪个关节放开最有价值。

    一、先分清几个容易混的说法¶

    在正式定义之前，先把一组看起来差不多、实际上完全不同的说法摆在一起。 本页后面所有的讨论，都建立在这几张表划出的分界上。

    说法 说的是什么 单位是什么 记住它的关键
    关节空间 关节变量本身（转角、位移）构成的集合 角度（度）或长度（毫米） 有几个关节就是几维
    工作空间 末端参考点能达到的位置集合 长度（毫米） 是物理空间里的一个区域
    任务空间 任务关心的是末端位姿（位置 + 姿态） 位置 + 角度 比工作空间多管三根姿态轴
    可达工作空间 至少存在一个逆解的位置 长度（毫米） 要求最松，通常指的是它
    灵巧工作空间 能用任意姿态到达的位置 长度（毫米） 是可达工作空间的子集
    奇异位形 雅可比矩阵降秩的那些构型 关节变量 逆解的分界、工作空间的边界

    读表的方法：从上往下读，要求的条件越来越严。 从「有一个逆解」到「任意姿态都有逆解」，这就是可达工作空间 收缩成灵巧工作空间的过程

    一个实用的判断：装上夹具、拿上工具之后，真正能干活的区域 比工作空间还要再小一圈。所以设计时不能把工件放在工作空间的最边缘 —— 边缘上的位置就算勉强能到，末端姿态也往往是扭曲的，装不上去。

    二、什么是工作空间¶

    2.1 定义¶

    把机械臂所有关节都装成电机（或者气缸 / 丝杠）， 每个关节都能在自己的运动范围内连续变化。 在这些关节变量的任意一种组合下，末端参考点都会落到物理空间里的某一个点上。

    把所有这样的点收集起来，得到的位置集合就叫做工作空间（workspace）。

    用符号写清楚。设机械臂有 \(n\) 个关节，单个关节的运动范围是闭区间：

    \[q_i \in [q_i^{\min},\, q_i^{\max}], \qquad i = 1, 2, \dots, n\]

    所有关节变量拼成一个 \(n\) 维向量，叫作关节向量：

    \[q = (q_1, q_2, \dots, q_n)\]

    正运动学把它映射成末端参考点的三维位置：

    \[p = f(q)\]

    于是工作空间就是像集：

    \[\mathcal{W} = \{\, f(q) \; : \; q_i \in [q_i^{\min}, q_i^{\max}], \; i = 1, \dots, n \,\}\]

    \(\mathcal{W}\) 是那个「能摸到哪儿」的区域， 右边说的是「把关节区间里所有的 \(q\) 都试一遍，把结果 \(p\) 全收集起来」。 所以工作空间只跟几何有关（杆多长、关节能转多少）， 跟你用多大的电机、控制算法写得怎么样都没有关系

    三个符号再明确一遍：

    符号 是什么 单位 / 范围 一句话解释
    \(n\) 关节个数 正整数 也就是机械臂的自由度数
    \(q\) 关节向量 \(n\) 维 一组具体的关节取值，叫一个构型
    \(f\) 正运动学 映射 「给关节角度，求末端位置」
    \(\mathcal{W}\) 工作空间 空间中的点集 末端参考点能达到的所有位置

    注意「末端参考点」这个词。工作空间描述的是一个点能到哪儿， 不是一个物体能覆盖多大范围。习惯上把参考点取在工具安装法兰的中心， 或者末端关节轴的交点上。约定不同，算出来的工作空间形状会有出入 —— 所以比较两台机械臂的工作空间时，要先确认参考点取在哪里

    参考点取错，比较就全错了

    同样一台六轴机械臂，把参考点取在腕部中心和取在指尖， 得到的可达半径可以差出一两百毫米。

    更麻烦的是：取在指尖时，参考点还随工具朝向摆动， 工作空间会变成一个「带毛边」的鼓包； 取在腕心时，工作空间是一张光滑的曲面。

    本页后面的所有讨论，参考点一律取在末端杆的端点， 这样 \(r\) 才好用一个简单的余弦定理写出来。

    2.2 可达工作空间与灵巧工作空间¶

    课件把「运动空间」和「工作空间」放在一起讲，其实说的是同一件事的两种严格程度：

    名称 严格定义 量的是 直观说法
    可达工作空间 至少有一个关节构型能使参考点到达 位置 手腕伸到极限也摸得到
    灵巧工作空间 参考点落在该处时，末端仍能取到任意姿态 位置 + 姿态 不但够得着，还能转着圈拧
    全姿态工作空间 上述两种的另一种叫法 位置 + 姿态 有的教材用这个词
    可达工作空间 灵巧工作空间
    装夹工件能不能放在这里 能，但姿态可能要迁就 能，姿态随便挑
    大小关系 大 小，是前者的子集
    边界处会发生什么 逆解数目减少到只剩一个 已经出界
    适合的工序 单纯搬运、放到指定位置 拧螺丝、贴面打磨、插装

    两者的关系一句话概括：

    \[\mathcal{W}_{\text{灵巧}} \subseteq \mathcal{W}_{\text{可达}}\]

    为什么灵巧空间一定更小：因为「能到」只要求 \(f(q) = p\) 有解， 而「还能取任意姿态」要求 \(f(q) = p\) 且姿态部分也有解。 多了一组约束，能被满足的 \(p\) 只会变少，不会变多

    末端有三根腕关节（常见于六轴工业机械臂）时， 腕关节只改变姿态而不改变参考点位置，所以： 如果参考点取在腕心，可达工作空间与灵巧工作空间就是同一个区域 —— 腕关节转多少都不动参考点，姿态自然是想取什么就取什么

    反过来说，要让灵巧空间小于可达空间，就得看前三个「臂关节」： 臂关节的杆长与限位决定了参考点能落在哪儿， 腕关节的限位决定了在那儿能摆出多少种姿态。 本页关心的是位置，所以后面的计算都只看臂关节。

    三、串联机器人的工作空间为什么是环状的¶

    3.1 从最熟悉的二杆臂推起¶

    先看最简单的情形：两根杆、两个转动关节，都在同一个平面里。 这种机构在上一页已经分析过它的运动，这里只关心端点的距离。

    设第一根杆长 \(L_1\)，第二根杆长 \(L_2\)， 两个关节的转角分别是 \(\theta_1\) 和 \(\theta_2\)， \(\theta_2\) 从 \(0\) 量起（\(0\) 表示两根杆拉直）。 把第二根杆投影到「沿第一根杆方向」和「垂直第一根杆方向」两个分量上：

    沿第一根杆方向的分量是 \(L_1 + L_2 \cos\theta_2\)， 垂直方向的分量是 \(L_2 \sin\theta_2\)。

    端点距离基座的长度 \(r\) 就是这两个分量的勾股和：

    \[r^2 = \bigl(L_1 + L_2\cos\theta_2\bigr)^2 + \bigl(L_2\sin\theta_2\bigr)^2\]

    把右边的平方展开。第一项：

    \[\bigl(L_1 + L_2\cos\theta_2\bigr)^2 = L_1^2 + 2L_1L_2\cos\theta_2 + L_2^2\cos^2\theta_2\]

    第二项：

    \[\bigl(L_2\sin\theta_2\bigr)^2 = L_2^2\sin^2\theta_2\]

    两项相加：

    \[r^2 = L_1^2 + 2L_1L_2\cos\theta_2 + L_2^2\cos^2\theta_2 + L_2^2\sin^2\theta_2\]

    为什么能合并：因为余弦平方与正弦平方之和恒等于 1， 这是三角恒等式 \(\sin^2\theta + \cos^2\theta = 1\)，与 \(\theta\) 取什么值无关。 于是：

    \[r^2 = L_1^2 + L_2^2 + 2L_1L_2\cos\theta_2\]

    两边开平方（\(r\) 是长度，取非负根）：

    \[r = \sqrt{\,L_1^2 + L_2^2 + 2L_1L_2\cos\theta_2\,}\]

    这个式子说明什么：\(\theta_1\) 完全消失了。 也就是说，转动第一根杆只是让整条臂整体转一圈，端点画出一个圆， 圆的半径只由 \(\theta_2\) 决定。 所以臂的「能伸多远」和「朝哪个方向」是两件独立的事。

    再往下想一步：\(\cos\theta_2\) 在 \(\theta_2\) 变化时单调变化， 所以 \(r\) 的取值范围就是 \(\cos\theta_2\) 的取值范围决定的。 \(\cos\theta_2\) 的取值范围是 \([-1, 1]\)（在 \(\theta_2 = 180°\) 和 \(\theta_2 = 0\) 处取到）， 代进去得到 \(r\) 的两个端点：

    情形 此时 \(\cos\theta_2\) 得到的 \(r\) 臂的样子
    完全伸直 \(+1\) \(\sqrt{L_1^2 + L_2^2 + 2L_1L_2} = L_1 + L_2\) 两根杆连成一条直线
    完全折回 \(-1\) \(\sqrt{L_1^2 + L_2^2 - 2L_1L_2} = \lvert L_1 - L_2 \rvert\) 第二根杆叠回第一根杆上

    中间那一步用了完全平方公式 \(a^2 + b^2 \pm 2ab = (a \pm b)^2\)， 再开方时用了 \(\sqrt{(L_1+L_2)^2} = L_1 + L_2\)（杆长都是正数，绝对值可以直接去）。

    于是得到一个很重要的结论，它正是「空洞」的来源：

    \[r \in [\, \lvert L_1 - L_2 \rvert,\; L_1 + L_2 \,]\]

    半径小于 \(\lvert L_1 - L_2 \rvert\) 的地方，怎么动也到不了。

    3.2 二杆臂的可达区域逐点算出来¶

    为了看清楚上面那个区间到底意味着什么，把杆长取成两个整数： \(L_1 = 120\) 毫米、\(L_2 = 180\) 毫米（这是某台小型机械臂的比例）。 两端分别是：

    \[r_{\max} = 120 + 180 = 300 \text{ 毫米}, \qquad r_{\min} = \lvert 180 - 120 \rvert = 60 \text{ 毫米}\]

    下面把 \(\theta_2\) 从 \(0\) 每隔 15 度取一个值，逐个代入 \(r = \sqrt{120^2 + 180^2 + 2 \times 120 \times 180 \times \cos\theta_2}\)， 把结果列成表。手算示范第一行： \(\cos 0 = 1\)，所以根号里是 \(14400 + 32400 + 43200 = 90000\)， 开方得 \(300.00\)。第二行：\(\cos 15° = 0.965926\)， 根号里是 \(14400 + 32400 + 43200 \times 0.965926 = 88528\)， 开方得 \(297.54\)。

    为什么会这样，不用求导也能看明白：想想你的手臂。 把肘部微弯一点点，手就往里收一点点； 但如果你已经把手完全收到肩膀前，再想往里收， 手就会大幅度地朝肩膀方向扑过来。这正是余弦函数在 \(0\) 和 \(180\) 附近 变化率不同的表现 —— 同样的角度增量，\(\cos\) 在两端附近变得慢， 而在 \(90\) 度附近变得快。等等，这里要小心 ⚠ \(\cos\) 在 \(90\) 度附近变得最快，可我们上面看到的却是 \(\theta_2\) 接近 \(180\) 度时 \(r\) 掉得最快 —— 两者不矛盾， 因为 \(r\) 还经过了开方这一步。 根号函数在自变量小的时候变化率大（导数趋于无穷）， 把「\(\cos\) 变化最快的位置」和「根号最陡的位置」叠在一起， 就表现为最后段掉得最快。结论只要记住一句： \(r\) 随 \(\theta_2\) 的收缩，在收回到折叠位姿的最后一段最剧烈。

    接下来是最关键的一步推理：

    固定基座，让第一个关节 \(\theta_1\) 转一整圈。 此时上述每一个 \(r\) 都会画出一个圆：

    • \(r = 300\) 画出最外圈，半径 300；
    • \(r = 60\) 画出最内圈，半径 60；
    • 中间的 11 个 \(r\) 画出 11 个同心圆。

    把这些圆全部填满（作为实心圆盘收集起来）， 得到的是一个圆环：外半径 300、内半径 60。

    圆环中心那个半径 60 的圆盘，一个点都到不了。

    这就是空洞。它不是画图时忘了画，而是机构本身的结构性事实： 要想让端点落到离基座只有 30 毫米的地方， 你必须让第二根杆（180 毫米）绕回第一根杆（120 毫米）里面去， 让两者折叠后的长度只剩 30 —— 可折叠后的最短长度是 \(\lvert 180 - 120 \rvert = 60\)， 做不到了 ⚠

    如果两根杆一样长（\(L_1 = L_2\)），那么 \(r_{\min} = 0\)， 两个同心圆之间没有任何空隙，工作空间是一个实心圆盘， 中心也能到达（两杆完全重合叠在一起）。 可见「有没有空洞」完全由两根杆的长度差决定。

    3.3 从平面圆环到立体球壳¶

    上面是平面机构，端点被限制在同一张纸面上，所以工作空间是圆环。 真实的串联机械臂不是平的：它的第一个关节把整条臂在水平面里转一圈。

    把平面圆环绕基座的竖直轴旋转一周，圆环就扫出一个球壳。 这个球壳的内半径就是平面上的 \(r_{\min}\)，外半径就是 \(r_{\max}\)。

    所以对三连杆的串联机械臂（上臂、前臂、加上末端一小段）， 如果三个关节都是转动副，各杆长 \(L_1\)、\(L_2\)、\(L_3\)， 工作空间是球壳状的区域，内半径与外半径各是多少， 取决于这三个长度怎么组合。最容易看明白的是全伸直与全折回两种极端构型。

    「球壳」只是一种极粗略的说法

    严格地说，机械臂的工作空间不是一个标准球壳。 它的真实形状更像一个球壳与一堆圆环叠加出来的鼓包：

    • 杆长极不相等（比如 400、300、100 毫米）时，中段的壁厚会发生剧烈变化 —— 因为折叠构型随时可能因为某个关节到达限位而「断掉」；
    • 关节限位通常不是对称的（例如肘关节只能 0 到 140 度，不能反向）， 这会把球壳切掉一大块，切出一个锥形缺口；
    • 一旦机构里含有移动副（例如立柱可以上下伸缩）， 工作空间会从球壳变成球壳与圆柱的叠加。

    考试里说「球壳」一般指主要形状， 但你要能说出它和标准球壳在哪里不一样 —— 这一页第五节就是专门讲这件事的。

    import numpy as np

# 三个转动关节的臂，各杆长（单位：毫米）
L1, L2, L3 = 400.0, 300.0, 100.0
Lw = L1 + L2 + L3          # 完全伸直时的最大半径

# 关节限位（度）：肩、肘、腕
q1_lo, q1_hi = -170.0, 170.0
q2_lo, q2_hi = -110.0, 110.0
q3_lo, q3_hi = -150.0, 150.0

# 末端参考点到基座的距离：把三根杆依次投影到极轴方向再取模长
def reach(a1, a2, a3):
    c2, c3 = np.cos(np.radians(a2)), np.cos(np.radians(a3))
    return np.sqrt(L1**2 + L2**2 + L3**2
                   + 2 * L1 * L2 * c2
                   + 2 * L2 * L3 * c3
                   + 2 * L1 * L3 * np.cos(np.radians(a2 + a3)))

# 随机采样 20 万组关节角
rng = np.random.default_rng(42)
N = 200000
a1 = rng.uniform(q1_lo, q1_hi, N)
a2 = rng.uniform(q2_lo, q2_hi, N)
a3 = rng.uniform(q3_lo, q3_hi, N)
r = reach(a1, a2, a3)

print("总臂长 Lw =", Lw, "毫米")
print("可达半径：min =", r.min().round(1),
      " max =", r.max().round(1),
      " 平均 =", r.mean().round(1))
print("落在 r < 400 毫米的比例 =", (100 * (r < 400).mean()).round(3), "%")
print("落在 r >= 700 毫米的比例 =", (100 * (r >= 700).mean()).round(3), "%")

    读这段输出要抓住两件事：

    第一，min = 310.0，不是 0。 20 万组采样里最小的到达距离是 310 毫米， 说明半径 310 以内一个点都到不了，空洞是真实存在的 ✓

    第二，用采样找到的 310 不等于理论上算出来的 100。 为什么？因为这是一次随机采样，落在极值附近的构型很稀少 —— 要让 \(\theta_2\) 恰好取到限位的一端，同时 \(\theta_3\) 也取到把前臂折回来的那一端， 这样的组合在 20 万次随机抽样里几乎抽不到。 换句话说，采样得到的 min 是「有多密」的估计，不是理论最小值 ⚠

    理论上那个填不满的球有多大：只让肘关节折到底， 把最长的杆（400 毫米）与末端的 100 毫米折叠到同一侧， 就能把参考点拉到离基座 300 毫米的地方；再多用上 300 毫米那根杆， 就能拉到 100 毫米。所以空洞半径是 100 毫米。

    注意这个 100 不是随便来的：它等于 \(L_1 - L_2 - L_3 = 400 - 300 - 100\)， 也就是「最长的杆减去其余两根之和」。这个量正是 3.1 节 \(\lvert L_1 - L_2 \rvert\) 在三个杆上的推广 ✓

    关于 4.735% 这个数：它说的是「随机采样关节角时， 有多大概率端点落在半径 400 以内」。超过 95% 的构型端点都落在 400 之外， 说明这台臂的绝大部分位形都伸得比较开。 设计工位时要注意：机械臂在「收缩」状态下能提供的操作空间其实很有限。

    四、影响工作空间的三个因素¶

    课件把串联机器人工作空间的影响因素归为三条。下面逐条讲， 每条都配一个能量化的判断方法。

    为什么只有三条：因为 \(p = f(q)\) 这个映射里， 真正能调的只有这些 —— \(f\) 由杆件之间的相对位置决定（也就是各连杆长度）， \(q\) 的取值范围由关节机构决定（也就是关节的运动范围）， 而 \(f\) 对 \(q\) 的依赖形式由关节是转还是移决定（也就是关节类型）。 除此之外没有第四个自由度可以调 ✓

    4.1 因素一：各连杆的长度¶

    先看最直接的量：最大伸展半径。

    把 \(n\) 根杆全部拉直排成一条线，末端参考点到基座的距离就是：

    \[r_{\max} = L_1 + L_2 + \cdots + L_n\]

    怎么读：\(\sum L_i\) 就是「机械臂最长能伸多远」， 这是所有设计指标的起点。注意它只跟杆长有关，跟关节限位无关 —— 因为「拉直」这个姿态本身并不需要很大的关节转角 ✓

    再看空洞半径。 三杆的推广形式是：

    \[r_{\min} = L_{\max} - \bigl(\text{其余各杆之和}\bigr) = \max_i L_i - \Bigl(\sum_j L_j - \max_i L_i\Bigr) = 2\max_i L_i - \sum_j L_j\]

    如果最长的那根杆比其余所有杆加起来还长， 那么折叠后最短也还有一段伸在外面，空洞半径是这个差额； 如果最长的那根杆没有其余各杆加起来长， 那么折叠后长度可以是 0，空洞消失，工作空间从球壳退化成一个实心球

    边界情况必须点明：当 \(L_{\max} = \sum_{j \ne \max} L_j\) 时， \(r_{\min} = 0\)，空洞半径恰好是 0，球壳的「内球面」缩成一个点。 这是空洞从有到无的分界。

    做一个数量上的比较：把 800 毫米的总长在两杆臂上做两种分配。

    分配方案 \(L_1\)（毫米） \(L_2\)（毫米） \(r_{\max}\)（毫米） \(r_{\min}\)（毫米） 工作空间形状
    平均 400 400 800 0 实心圆盘，无空洞
    悬殊 700 100 800 600 极窄的圆环，中间大洞
    中等 500 300 800 200 中等宽度的圆环

    这张表说明一件很容易被忽略的事： 总长相同，工作空间的形状可以完全不一样。

    具体到「可用面积」，差别更惊人。平面圆环的面积是 \(\pi (r_{\max}^2 - r_{\min}^2)\)，代入第 1 行和第 2 行：

    • 平均分配：\(\pi (800^2 - 0^2) = 2.011 \times 10^6\) 平方毫米；
    • 悬殊分配：\(\pi (800^2 - 600^2) = 8.80 \times 10^5\) 平方毫米。

    后者只剩前者的 43.7%。同样的材料、同样的总长， 只因为杆长分配不同，可用面积就少了一半多

    这背后的物理直觉：把杆做得长短悬殊， 等于让机械臂「折叠时缩得很厉害」—— 可缩得很厉害也意味着「伸开时有一段结构是多余的」。

    实际怎么选：如果工件是围绕基座一圈摆放（例如环形装配线）， 就希望工作空间是一圈较窄的环，此时把杆做得长短悬殊反而合适， 因为它能把工作空间精确地箍在工件所在的那一圈上， 同时避免机械臂伸到环形工位的中心去撞别的设备。 反过来，如果工位是一大片平面，就要把两根杆做得尽量等长。

    再看「哪根杆长最值钱」。 总长固定时，多出来的 1 毫米长度 如果加在最长的那根杆上，它在 \(r_{\max}\) 和 \(r_{\min}\) 上同时起作用， 一起往外推；如果加在最短的那根杆上， 它会同时把 \(r_{\min}\) 往回拉、把 \(r_{\max}\) 往外推， 两种效果都对扩大可用区域有利。

    一个能省很多试错时间的问题

    选机械臂时，除了「最大臂展」，一定要再问一句：

    「最小臂展（也就是空洞半径）是多少？」

    如果工件必须放在离基座很近的地方， 一台臂展 800 毫米、最小臂展 600 毫米的机械臂， 在这个工位上的实际能力相当于一台臂展只有 200 毫米的小机器。

    粗糙但够用的经验做法：把总长的三分之一到四分之一当作 需要重点核对的「近端禁区」尺寸。

    4.2 因素二：关节的运动范围（限位）¶

    杆长决定的是球壳的内外半径，而关节限位决定的是球壳保留了多少。

    先看第一关节的限位。 第一关节通常绕竖直轴转动， 它的限位直接决定了工作空间的张角。

    第一关节限位 工作空间的形状 还剩下的比例 典型场合
    \(360°\) 无限制 完整的回转体 100% 少数带滑环的专用设备
    \(\pm 170°\) 缺一个 \(20°\) 楔形 约 94% 常见工业六轴臂
    \(\pm 90°\) 只剩半个 50% 部分协作臂、需要避免绕线的场合
    \(\pm 45°\) 只剩四分之一 25% 受限安装空间

    为什么第一关节总会有个楔形缺口：因为电缆、气管要从基座穿到末端去。 如果第一关节能无限转，线缆会被绞断。所以实际产品都会限制它的转角， 把「走线」留在缺口那一段。那 20 度的楔形缺口，就是给线缆留的

    再看第二、第三关节的限位，这两个才是最难分析的。 它们限制的不是张角，而是半径： 因为「伸到 \(r_{\max}\)」这个姿态要求相关关节到达 \(0\) 度（伸直）， 「收到 \(r_{\min}\)」这个姿态要求相关关节到达接近 \(180\) 度（折回）。 如果限位把这两个极端角度切掉了，实际 \(r\) 的变化区间就会向内缩。

    4.3 因素三：关节类型（转动副与移动副）¶

    前两节里所有关节都是转动副（记作 R）。一旦机构里出现移动副（记作 P）， 工作空间的形状会换一种几何体。

    关节类型 它给末端加上的运动 在笛卡尔空间里的贡献 位置与 \(\theta\) 的关系
    转动副 R 绕轴转动 一段圆弧 三角函数，非线性
    移动副 P 沿轴直线平移 一段直线 直接相加，线性

    移动副的关键优点：它对末端位置的贡献是直接相加的， 不经过三角函数。所以移动关节的限位只会把工作空间切掉一块， 不会像转动关节那样「产生」一个空洞 —— 因为转动关节的「折回」才能把可及半径收小， 而移动关节的行程用尽只是停在原地

    移动副的代价：它的结构通常更占地方、更怕侧向力， 而且要密封、要防尘。所以工业机械臂里， 移动关节多出现在龙门、直角坐标、升降立柱这类构型上。

    课件给出的五种基础构型，正好覆盖了从「全 P」到「全 R」的整条谱：

    构型 关节串 工作空间的主要形状 特性
    直角坐标 / 龙门 P P P 长方体 位置与关节值一一对应，控制最直白
    柱坐标 R P P 空心圆柱（一个环带） 结构紧凑，上下料方便
    极坐标 / 球坐标 R R P 球壳 能覆盖较远距离，姿态受限制
    横向关节臂 R R R（水平排布） 横置的扁球壳 + 缺口 竖直方向薄，平面内大
    纵向关节臂 R R R（竖直排布） 球壳 最像人的手臂

def reach_rot(a1, a2, a3):
    return np.sqrt(
        L1**2 + L2**2 + L3**2
        + 2 * L1 * L2 * np.cos(np.radians(a2))
        + 2 * L2 * L3 * np.cos(np.radians(a3))
        + 2 * L1 * L3 * np.cos(np.radians(a2 + a3)))

        + 2 * s2 * L3 * np.cos(np.radians(a3))

    五、工作空间边界与奇异位形¶

    5.1 边界是「逆解的分界」¶

    工作空间的边界有一个很干脆的刻画：边界上逆解的数目会减少。

    • 在内部一点：通常有多个逆解（左手 / 右手、肘上 / 肘下、腕翻 / 腕不翻）；
    • 在边界上：几个解合流成同一个，解的重数下降；
    • 在外面：无解。

    为什么边界上逆解会合流：以上面那个二杆臂为例。 在半径 \(r\)（满足 \(60 \lt r \lt 300\)）处， \(\cos\theta_2 = (r^2 - L_1^2 - L_2^2) / (2L_1L_2)\) 落在 \((-1, 1)\) 之间， 所以 \(\theta_2\) 有两个解（\(\pm\theta_2\)）， 对应「肘在上」和「肘在下」两种位形，是关于两基座连线镜像的两条腿。

    到了 \(r = 300\)，\(\cos\theta_2 = 1\)， 两个解在 \(\theta_2 = 0\) 处合并成一个 —— 就是完全伸直那一种。 到了 \(r = 60\)，\(\cos\theta_2 = -1\)，两个解在 \(\theta_2 = 180°\) 处合并。

    所以边界就是「两个解合成一个」的地方，而在这些地方，雅可比矩阵降秩。 这些位形就叫奇异位形。

    5.2 奇异位形为什么是边界¶

    用最直白的说法：奇异位形就是机械臂「使不上劲」的那些构型。

    想想完全伸直的手臂：这时候你的手伸得最远， 可是你没法再把手往外推了 —— 就算再用力， 手也只是原地不动，力量全部顺着骨头压过去了， 一点也没变成向外的位移。

    数学上，这表现为雅可比矩阵不满秩： 关节角的小变化方向里，存在某些方向能让末端动， 也存在某些方向无论怎么动关节，末端就是不动。 末端完全动不了的那些方向，恰好指向工作空间的外边

    关键推论：奇异位形不在工作空间的内部，而在它的边界上。 所以：

    \[\text{工作空间的边界} \subseteq \{\text{奇异位形对应的末端位置}\}\]

    反过来的方向不成立 边界点一定是奇异位形对应的位置， 但有些奇异位形（例如腕部的六个轴共面）对应的位置 可能落在工作空间的内部，它只是让某些姿态取不到， 并没有让整个点都够不到。

    5.3 关节限位边界与奇异位形边界的区别¶

    这一条特别容易混，单独拎出来讲。

    边界的种类 由什么造成 边界处的逆解数目 边界处的雅可比 外侧是什么
    奇异位形边界 机构构型本身退化 两个解合流 降秩 无解
    关节限位边界 某个关节撞到限位挡块 仍是多解，只是有一解失效 一般不降秩 换一个解就能到

    两者在几何上的表现完全不同：

    • 奇异位形边界是一条光滑的曲面，因为它由方程的实根合流条件决定；
    • 关节限位边界是一张折面，在「两个关节同时到限位」处出现尖角。

    怎么区分：拿到一个边界点， 数一下该点处有效的逆解个数，并算一下雅可比的行列式。

    • 逆解数减少、行列式趋于 0 → 奇异位形边界；
    • 逆解数没变、行列式正常 → 只是限位切出来的边界。

    为什么一定要分清：因为两者的可用性完全不同。

    • 限位边界其实没什么大问题：机械臂在那里还能正常出力， 只是有个关节不能继续转了。甚至可以「换一个解」绕过去。
    • 奇异位形边界要躲着工作：在它附近， 要往某个方向移动末端需要无穷大的关节速度 （因为雅可比降秩，求逆时会出现除以 0）。

    越靠近奇异位形，关节速度越失控

    在奇异位形附近，末端做同样的匀速直线运动， 所需的关节速度会急剧上升并趋向无穷。

    实际后果是：电机突然被要求高速转动、抖动、 甚至触发过流保护而停机。

    所以工作空间靠近边界的那一圈，通常要留一段安全余量， 不能把常用工位正好压在边界上。 「理论够得着」和「实际能稳定干活」是两件事

    5.4 用图看清「关节范围决定可达区域」¶

    前面所有的讨论都落在「转角到不了，就有一块区域去不成」这一点上。 曲柄滑块机构是这个问题最直观的例子： 曲柄整圈转动，滑块却被限制在一条直线上往复 —— 能走的那一段直线，正是由曲柄长度决定的「可达区域」； 直线以外的所有位置，就是它的「空洞」。

    看图上的三个部分：左边那个圈是曲柄中心， 虚线画的是曲柄端点转一圈走过的整圆 —— 这一圈上的每一个点曲柄端点都能到。 右边那个带阴影的方块是滑块， 中间的粗线是连杆。

    从这张图要看出两件事：

    第一，能到和不能到是截然分开的。 曲柄端点能走满整个圆；滑块却只能沿水平导轨走一段。 同样是「机构上的一个点」，可达区域的大小差了一整个量级。 机构里每个点都有自己的可达区域，工作空间是其中一个特定点的。

    第二，形状是被约束逼出来的。 滑块为什么只能走直线？因为导轨给了它一个约束 （只允许一个方向的平移）。曲柄为什么能转整圈？因为它只有一个转动约束。 所以「可达区域长什么样」这个问题，本质上是问 「这个点身上背了几条约束、约束是什么形式」 —— 这正是第三节里关节类型影响工作空间形状的同一个道理。 四杆机构的工作空间形状由「哪一根是机架、哪一根被驱动」决定；串联机器人的工作空间形状同理，由「哪几个关节是转动、哪几个是移动」决定。

    把图代进工作空间的语境：如果把末端参考点取在曲柄端点上， 那么它的工作空间就是图上那个完整的圆； 如果取在滑块上，工作空间就是那段直线。 同一台机构，参考点换一下，工作空间从二维的圆变成一维的线段 —— 这再次说明 2.1 节里那句「要先确认参考点取在哪里」不是废话

    六、典型例题¶

    例题 1：二杆臂的工作空间内径与外径¶

    题目：某平面二杆机械臂的两根杆长分别是 \(L_1 = 150\) 毫米、 \(L_2 = 250\) 毫米，两个关节都是转动副，关节限位足够大（都能转满所需角度）。 求它以末端为参考点的工作空间的内半径、外半径， 并说明中间有没有空洞。

    思路

    先写出发达半径公式 \(r = \sqrt{L_1^2 + L_2^2 + 2L_1L_2\cos\theta_2}\)， 再让 \(\cos\theta_2\) 分别取 \(+1\) 与 \(-1\) 得到两个极端值。

    注意 \(\cos\theta_2\) 取 \(-1\) 对应的不是「0」而是 \(L_2 - L_1\) 的绝对值， 因为两根杆不一样长，折叠后还有一段露在外面。

    解答

    第一步：写出可达半径。

    第二根杆相对第一根杆的转角记作 \(\theta_2\)（\(0\) 表示拉直），

    \[r = \sqrt{L_1^2 + L_2^2 + 2L_1L_2\cos\theta_2}\]

    中间这步展开在正文 3.1 节做过：先把 \((L_1 + L_2\cos\theta_2)^2 + (L_2\sin\theta_2)^2\) 展开， 再用 \(\cos^2\theta_2 + \sin^2\theta_2 = 1\) 合并。

    第二步：取两个极端。

    因为 \(\cos\theta_2\) 的取值范围是闭区间 \([-1, 1]\)， 所以 \(r\) 的取值范围就是这个区间两端代进去的值。

    \(\cos\theta_2 = +1\)（拉直）：

    \[r_{\max} = \sqrt{150^2 + 250^2 + 2 \times 150 \times 250} = \sqrt{22500 + 62500 + 75000} = \sqrt{160000} = 400 \text{ 毫米}\]

    \(\cos\theta_2 = -1\)（折回）：

    \[r_{\min} = \sqrt{150^2 + 250^2 - 2 \times 150 \times 250} = \sqrt{22500 + 62500 - 75000} = \sqrt{10000} = 100 \text{ 毫米}\]

    第三步：判断有无空洞。

    注意用的是 \(\sqrt{(L_2-L_1)^2} = L_2 - L_1 = 250 - 150 = 100\)， 因为 \(L_2 \gt L_1\)，绝对值可以直接去。

    \(r_{\min} = 100\) 毫米 \(\gt 0\)，所以有空洞： 半径 100 毫米以内的圆盘一个点都到不了。

    第四步：回答。

    工作空间是一个圆环：外半径 400 毫米、内半径 100 毫米， 中间有半径 100 毫米的空洞。 空洞半径恰好等于两根杆的长度差。

    例题 2：三杆臂的空洞半径¶

    题目：某串联机械臂的三个臂关节都是转动副， 杆长分别是 \(L_1 = 500\) 毫米、\(L_2 = 300\) 毫米、\(L_3 = 200\) 毫米。 求「完全伸直」与「完全折回」两种极端构型下的末端半径， 并写出空洞半径的一般公式。

    思路

    三根杆全伸直就是直接相加；全折回则是「最长的杆减掉其余各杆之和」。 先判断最长的杆是否比其余各杆之和长 —— 如果是，空洞存在；如果不是，空洞消失。

    解答

    第一步：完全伸直。

    三根杆排成一条直线，末端半径是三者之和：

    \[r_{\max} = L_1 + L_2 + L_3 = 500 + 300 + 200 = 1000 \text{ 毫米}\]

    第二步：完全折回。

    要让末端尽量靠近基座，得让尽可能多的杆反向折回来抵消。 把最长的 \(L_1\) 当作「主杆」， 让 \(L_2\) 和 \(L_3\) 都折到与它相反的方向：

    \[r_{\min} = L_1 - L_2 - L_3 = 500 - 300 - 200 = 0 \text{ 毫米}\]

    第三步：解释 0 的含义。

    \(r_{\min} = 0\) 说明空洞消失。 当 \(500 = 300 + 200\) 时， 其余两根杆加起来恰好等于最长的杆， 折叠后末端可以被拉到与基座重合的位置。

    因此这不是球壳，而是实心球： 半径从 0 到 1000 毫米的整个球体都能到达。

    （严格地说，\(r = 0\) 只在恰好折叠到位的那一个构型上取到， 如果考虑机构自碰撞，实际能到的最近距离会略微大于 0。）

    第四步：一般公式。

    推广到 \(n\) 根杆，记最长的那根为 \(L_{\max}\)：

    \[r_{\min} = \max\Bigl(0,\; L_{\max} - \sum_{j \ne \max} L_j\Bigr)\]

    外面套一个 \(\max(0, \cdot)\) 是因为半径不能为负 —— 当其余各杆之和超过最长杆时，物理上「最近就是 0」， 不可能出现负半径。

    这个公式说明什么： 有没有空洞，只取决于最长的那根杆是不是比其余各杆加起来还长。 和总长、和杆的排列顺序都无关。

    例题 3：关节限位把外半径切掉了多少¶

    题目：一台二杆机械臂的杆长是 \(L_1 = 500\) 毫米、\(L_2 = 420\) 毫米。 设计时出于机构自碰撞的考虑，把肘关节的转角限制为 \(20° \le \theta_2 \le 150°\)（\(\theta_2 = 0\) 表示拉直）。 求实际能达到的最大半径与最小半径， 并与理论值比较，算出外半径损失了百分之几。

    思路

    理论极值要求 \(\theta_2\) 取到 \(0\) 和 \(180\)， 但限位区间是 \([20, 150]\)，两个端点都没到。 所以直接把 \(20\) 和 \(150\) 代进半径公式，得到的就是实际极值。

    解答

    第一步：算理论极值。

    \(\cos\theta_2 = 1\) 时（\(\theta_2 = 0\)）：

    \[r_{\max}^{\text{理}} = \sqrt{500^2 + 420^2 + 2\times 500 \times 420 \times 1} = \sqrt{250000 + 176400 + 420000} = \sqrt{846400} = 920 \text{ 毫米}\]

    \(\cos\theta_2 = -1\) 时（\(\theta_2 = 180\)）：

    \[r_{\min}^{\text{理}} = \sqrt{250000 + 176400 - 420000} = \sqrt{6400} = 80 \text{ 毫米}\]

    第二步：算实际极值。

    限位区间是 \([20°, 150°]\)，两个端点代进去。

    \(\theta_2 = 20°\)，\(\cos 20° = 0.939693\)：

    \[r_{\max} = \sqrt{250000 + 176400 + 420000 \times 0.939693} = \sqrt{250000 + 176400 + 394671} = \sqrt{821071} \approx 906.13 \text{ 毫米}\]

    \(\theta_2 = 150°\)，\(\cos 150° = -0.866025\)：

    \[r_{\min} = \sqrt{250000 + 176400 - 420000 \times 0.866025} = \sqrt{250000 + 176400 - 363731} = \sqrt{62669} \approx 250.34 \text{ 毫米}\]

    第三步：算损失。

    外半径损失：

    \[\frac{920 - 906.13}{920} = \frac{13.87}{920} \approx 1.5\%\]

    内半径变化：从理论的 80 毫米变成实际的 250.34 毫米， 空洞半径变大了 3 倍多。

    第四步：回答与解读。

    外半径只损失 1.5%，几乎可以忽略 —— 因为 \(\cos\theta_2\) 在 \(0\) 附近变化极慢， 从 \(0\) 转到 \(20\) 度，\(\cos\) 只从 \(1.000000\) 掉到 \(0.939693\)。

    但内半径从 80 毫米涨到 250.34 毫米，空洞扩大了。 原因是 \(\cos\) 在 \(180\) 度附近同样变得慢， 所以从 \(180\) 收到 \(150\)，半径也没能收到底。

    这个结果告诉我们： 肘关节的外侧限位（限制伸展的那一侧）对工作空间影响很小， 可以放心收紧； 而内侧限位（限制折叠的那一侧）代价很大， 每收一度都要仔细权衡

    例题 4：移动副对工作空间的贡献¶

    题目：一台机械臂的前三段是「转动 — 移动 — 转动」， 第一根杆 \(L_1 = 200\) 毫米固定不动， 第二段是一个行程 \(s\) 从 \(0\) 到 \(400\) 毫米的移动副， 第三段 \(L_3 = 200\) 毫米仍然是转动副。 在 \(s = 0\)、\(s = 200\)、\(s = 400\) 毫米三种行程下， 分别求末端能达到的最大半径（取第三段与第二段共线）。

    思路

    移动副的贡献是直接相加，不经过三角函数。 三段共线时，末端半径就是三段长度的简单和； 只是第二段的长度 \(s\) 是可变的。

    解答

    第一步：写出可达半径。

    三段共线时没有角度偏差，半径就是三段长度之和：

    \[r = L_1 + s + L_3\]

    注意这一步为什么这么简单： 因为移动副的位移 \(s\) 是按直线累加的， 不像转动副那样要乘 \(\cos\) 或者 \(\sin\)。 这正是 4.3 节表格里说的「移动副的贡献是线性的」

    第二步：三个行程分别代入。

    行程 \(s\)（毫米） 计算式 \(r\)（毫米）
    0 \(200 + 0 + 200\) 400
    200 \(200 + 200 + 200\) 600
    400 \(200 + 400 + 200\) 800

    第三步：再看最小半径。

    要让末端靠近基座，把第三段折回来对准第一段。 \(s\) 最小时（\(s = 0\)），

    \[r_{\min} = \lvert L_1 - L_3 \rvert = \lvert 200 - 200 \rvert = 0\]

    移动副缩到 0 之后，这根臂退化成了两杆臂， 而且两根杆等长，所以最近能到基座本身。

    \(s\) 最大时（\(s = 400\)），

    \[r_{\min} = 200 - 0 - 200 = 0\]

    等等，这里要小心：\(s = 400\) 时第二段是伸开的， 要让它「不贡献半径」是不可能的 —— 它占了实实在在的 400 毫米。 正确的算法是把第三段折回来抵消第一段，第二段照算：

    \[r_{\min} = s + \lvert L_1 - L_3 \rvert = 400 + 0 = 400 \text{ 毫米}\]

    这就是移动副的代价：行程用得越多， 机械臂的最近可达距离也跟着变大， 因为那段伸出去的长度没法折叠掉

    第四步：回答与比较。

    三种行程下，工作空间的近端边界分别是 0、0、400 毫米， 远端边界分别是 400、600、800 毫米。

    和纯转动副的三杆臂比较： 同等总长时，转动副的三杆臂把近端压得更近 （可用折叠的方式把伸出去的长度抵消掉）， 而带移动副的构型近端下限被行程撑住， 灵活性反而不如纯转动副。

    所以 4.3 节的两面都要说全： 移动副能让机械臂缩得更短（相对于固定杆长的转动臂）， 但它的行程一旦用掉，就没法再折叠回来， 近端边界会随行程一起水涨船高。

    七、自测¶

    Q1 「可达工作空间」和「灵巧工作空间」，哪个更大？ 两者的大小关系是怎么来的？

    解答

    可达工作空间更大，灵巧工作空间是它的一部分。

    关系式是 \(\mathcal{W}_{\text{灵巧}} \subseteq \mathcal{W}_{\text{可达}}\)。

    为什么：「可达」只要求 \(f(q) = p\) 有解（能到达这个位置）； 「灵巧」在此之上还要求该处的姿态可以任意取。 多了一组约束，满足条件的位置只会变少。

    顺带记一个特例：如果参考点取在腕心（三个腕关节轴的交点）， 那么腕关节怎么转都不改变参考点位置， 此时可达空间与灵巧空间重合。

    Q2 二杆臂 \(L_1 = 200\) 毫米、\(L_2 = 200\) 毫米， 工作空间中间有空洞吗？如果把 \(L_2\) 改成 300 毫米呢？

    解答

    相等时没有空洞。 \(r_{\min} = \lvert 200 - 200 \rvert = 0\)， 最小可达半径是 0，两根杆可以完全叠在一起， 中心那个点也能到达，工作空间是实心圆盘。

    改成 300 毫米后有空洞。 \(r_{\min} = \lvert 200 - 300 \rvert = 100\) 毫米， 半径 100 毫米以内走不到，空洞出现了。

    外半径两种情况都是 400 和 500 毫米（\(200+200\) 与 \(200+300\)）。

    关键判据：空洞半径 \(= \lvert L_1 - L_2 \rvert\)， 两根杆等长时空洞消失，这是最省机构的做法。

    Q3 有人为了增大机械臂的工作空间，把三个关节的运动范围 都调到最大。这么做对吗？请指出至少两个问题。

    解答

    方向没错，但代价被忽略了。把三个问题都列出来：

    问题一：机构自碰撞。 关节转到极端角度时， 两根杆可能会撞在一起。所以实际产品的限位常常是 为了避开自碰撞而设的，不是想放开就能放开。

    问题二：工作空间边界处精度和刚度都很差。 关节接近限位时，臂处于近似奇异或极限的位形， 末端刚度低、误差被放大，末端定位精度会明显下降。

    问题三：驱动能力不一定跟得上。 关节限位的另一面是「速度和力矩在这个范围内能保证」。 放开限位之后，电机在边界的转速与力矩可能不达标。

    补充一点：如果只是为了让末端到得更远， 先问一句「到底是远端不够还是近端不够」。 4.2 节的表说明肘关节的内侧限位才是对可用面积影响最大的那个， 盲目全部放开可能根本没解决真正的问题。

    Q4 一台机械臂的理论工作空间内外半径分别是 200 毫米和 900 毫米。有人把它安装在一个直径 300 毫米的圆形料仓旁边， 让机械臂从料仓里取件。这样布置有没有问题？

    解答

    有问题：空洞会盖住料仓。

    第一步：算空洞覆盖范围。

    空洞半径是 200 毫米，也就是所有离基座小于 200 毫米的位置都到不了。

    第二步：算料仓的范围。

    料仓直径 300 毫米，半径 150 毫米。 如果料仓中心离基座的距离是 \(D\)， 那么料仓上离基座最近的那个点距基座 \(D - 150\) 毫米。

    第三步：比较。

    只要 \(D - 150 \lt 200\)，也就是 \(D \lt 350\) 毫米， 料仓靠近基座的那一部分就落在空洞里，机械臂够不到。

    把料仓放到 \(D = 350\) 毫米处，也只是恰好够到最内侧的那一点； 再想往里取件就不行了。

    第四步：正确做法。

    • 把料仓往外挪，使 \(D \gt 350\) 毫米，留一段安全余量；
    • 或者改用最小臂展更小的构型 （比如例题 4 里带移动副的那种）；
    • 或者干脆改用料仓自带的送料机构，把工件送到工作空间里。

    这道题要建立的直觉： 最大臂展决定「能伸多远」，但它完全不告诉你「近处能不能干」。 选型时必须同时核对最小臂展。

    八、小结¶

    要记住的 为什么
    工作空间 \(= \{f(q) : q_i \in [q_i^{\min}, q_i^{\max}]\}\) 定义式，一切结论的出发点
    可达工作空间 \(\supseteq\) 灵巧工作空间 后者多一组姿态约束，只会更小
    参考点取在哪里决定工作空间是什么 取在腕心时腕关节不影响位置，取在指尖时会
    \(r_{\max} = \sum L_i\) 完全伸直；只看最大臂展看不出杆长分配与关节类型的影响
    \(r_{\min} = \max(0,\, L_{\max} - \sum_{j \ne \max} L_j)\) 完全折回；正值才意味着有空洞
    二杆臂：\(r = \sqrt{L_1^2 + L_2^2 + 2L_1L_2\cos\theta_2}\) 余弦定理推导，\(\theta_1\) 在式子里消失
    两杆等长 ⇒ 无空洞 空洞半径 \(= \lvert L_1 - L_2 \rvert\)，等长时为 0
    串联臂工作空间常是球壳而非实心球 关节限位使臂无法「折叠到中心」
    因素一：连杆长度 ⇒ 决定内外半径 管「壁有多厚」
    因素二：关节运动范围 ⇒ 决定球壳保留多少 管「壁还剩多少」；肘关节内侧限位代价最大
    因素三：关节类型 ⇒ 决定几何体种类 R 走弧线、P 走直线；P-R-P 比 R-R-R 的最近可达距离小得多
    工作空间边界上逆解数目减少 两个解合流是边界的判据
    奇异位形在边界上，边界附近速度失控 雅可比降秩，求逆时除以 0
    奇异位形边界光滑、限位边界带尖角 前者由方程实根合流产生，后者由两个关节同时撞限位产生
    「理论够得着」不等于「实际能干活」 还要留自碰撞余量与精度余量
    要避开的坑 会怎么错
    以为工作空间是个实心球 中间那个空洞是真的到不了，不是画图问题
    只看最大臂展就下选型结论 杆长分配和关节类型都不影响最大臂展，但强烈影响可用区域
    把常用工位压在理论边界上 边界附近关节速度趋于无穷，抖动、过流
    以为放开所有限位就能增大工作空间 自碰撞、刚度、驱动能力三重限制
    把「可达」当成「能用任意姿态」 可达空间外圈的那一圈姿态往往很受限
    忘了参考点要取在哪里 换参考点，工作空间的形状和尺寸都会变
