    2.1 串联机构的基础构型¶

    这一页解决一个问题：想把机械臂「造出来」，它的关节该怎么排？

    前面几页讲的是「一个机构有几个自由度」「两根杆之间该怎么连」。 到了这一页，问题换了一个角度：给你要干的活，手臂应该长成什么形状？

    答案不是无穷多种。本课程课件把所有串联机械臂的「身体骨架」 归结为五种基础构型 —— 每一种都只用「转动副 R」和「移动副 P」 排出一个固定顺序，就得到一种完全不同的机器。

    先看一个最容易搞混的地方：同样叫「三个自由度的机械臂」， 关节类型排法不同，能到达的空间形状完全不同：

    看起来差不多 实际差别 后果
    直角坐标型 与 圆柱坐标型 第一个关节是移动副还是转动副 一个的空间是立方体，一个是圆柱 ⚠
    球坐标型 与 关节型 第三个关节是移动还是转动 一个能「伸缩」，一个只能「弯」
    关节型 与 水平关节型 转动轴是竖直还是水平 一个像人手，一个像「螃蟹钳」
    「有几个电机」 与 「能到哪」 前者数的是驱动，后者由构型定 电机一样多，工作空间可能差好几倍

    整页只回答一句话：「关节类型和排列顺序，决定了这台机器能怎么干活。」

    一、为什么基础构型只有这么几种¶

    1.1 一台串联机械臂的「骨架」由什么决定¶

    一台串联机械臂 = 一串刚体 + 一串关节，从固定在地面的基座开始， 一节一节往外接，最后一个环节装上末端执行器（焊枪、夹爪、吸盘）。

    决定它「像什么」的只有三件事：

    决定因素 具体表现 本页关注吗
    每个关节是什么类型 转动副 R 还是移动副 P ✅ 本页核心
    这些关节按什么顺序排 例如 R-R-P 还是 P-P-R ✅ 本页核心
    各杆的长度尺寸 决定工作空间大小 只影响大小，不影响形状

    关键结论：只要关节类型和顺序定了，这台机器的「形状类别」就定了； 后面再怎么改杆长，也只是把一个立方体改大一点，不会把它变成圆柱。

    1.2 为什么只有低副在候选名单里¶

    本课程前面讲过运动副：低副（转动副 R、移动副 P） 是面接触， 高副 是点或线接触。

    工业机械臂的关节几乎只用低副，原因非常实际：

    原因 说明
    承载能力 面接触受力面积大，能扛大载荷；点接触会压出坑 ⚠
    耐磨性 接触应力小，寿命长，不用频繁更换
    刚性好 关节间隙小，末端定位精度高
    容易驱动 移动副可以直接用液压缸/丝杠，转动副可以直接用电机
    配合自由度计算 一个低副恰好限制 2 个自由度，算法干净

    所以本页的所有构型，都是 R 与 P 的排列组合 —— 这也是为什么「基础构型」数得过来：能用的字母只有两个。

    移动副不是「只能直线走」，转动副也不是「只能原地转」

    这里容易犯一个错：把关节类型和末端运动形式混为一谈。

    关节类型说的是「相邻两杆之间的相对运动」： 转动副让两杆绕一根轴相对转动，移动副让两杆沿一个方向相对平移。

    而末端在空间里走什么轨迹，是所有关节叠加的结果 —— 全是转动副的关节型机械臂，末端照样可以走出很接近直线的路径 （靠几个轴配合），但那不是「因为它有移动副」✓

    二、课件给出的五种基础构型¶

    本课程课件在 2.1 节里按关节类型与排列顺序列出五种基础构型。 下面逐个讲清：关节组成、典型外形、工作空间形状、优缺点、典型用途。

    2.1 直角坐标型（Cartesian / gantry robot）—— PPP¶

    关节组成：三个互相垂直的移动副，记作 PPP。

    项 内容
    关节组成 3 个移动副（PPP），三根导轨两两垂直
    典型外形 像一台门式吊车或三坐标测量机：立柱 + 横梁 + 上下滑块
    工作空间形状 长方体（三个方向的活动范围分别是 \(a\)、\(b\)、\(c\)）
    优点 三个轴解耦：想动哪个方向就动哪个轴，控制最简单；刚度高、精度高
    缺点 体积笨重，占用空间大；末端姿态固定不能转；导轨要保持清洁
    典型用途 数控机床、3D 打印、取放料（Pick-place）

    为什么它是最容易控制的：三个移动副的方向互相垂直， 把末端位置写成 \((x, y, z)\) 时，每个坐标只由一个关节决定 —— 这叫解耦。没有耦合就不需要解方程，控制精度自然容易做高 ✓

    代价：为了给三个方向都留出活动余地，机身必须做得很大。 想让末端走 1 米，机器自己可能要先占掉 2 米的空间 ⚠

    2.2 球坐标型 / 极坐标型（Polar / spherical robot）—— RRP¶

    关节组成：两个转动副 + 一个移动副，记作 RRP。

    项 内容
    关节组成 第 1 个转动副绕竖直轴（回转），第 2 个转动副绕水平轴（俯仰），第 3 个是伸缩的移动副
    典型外形 像一门高射炮或老式吊车：底座能转，臂能抬头低头，臂还能伸缩
    工作空间形状 球壳状的球坐标空间（一个「厚球壳」被地面切掉一部分）
    优点 用较少的关节就能覆盖很大的空间；伸缩臂能伸到很远
    缺点 姿态受限制；靠近球心的区域够不到（伸缩臂有最小长度）；刚度随伸出量下降 ⚠
    典型用途 喷涂、焊接、装配中需要大范围回转的场合

    为什么工作空间是球坐标形状：第 1 个转动副绕竖直轴转，扫出一个圆锥面； 第 2 个转动副改变仰角，把这个圆锥面上下摆动； 第 3 个移动副改变半径。三者组合，正好就是 「用（半径、方位角、仰角）三个数确定一个点」—— 这就是数学上的球坐标 ✓

    靠近球心的位置够不到

    球坐标型的第三个关节是伸缩臂，它有一个最小长度（收到底的长度）， 所以工作空间不是一个实心球，而是一个球壳 —— 球心附近有一块空的区域。

    后果：如果工件正好落在机械臂底座正上方很近的地方， 这台机器反而够不到 ⚠ 选型时必须先在工作空间图上核对。

    2.3 圆柱坐标型（Cylinder robot）—— RPP¶

    关节组成：一个转动副 + 两个移动副，记作 RPP。

    项 内容
    关节组成 第 1 个转动副绕竖直轴回转；第 2 个移动副径向伸缩；第 3 个移动副竖直升降
    典型外形 一根立柱上套着能升降、能伸缩的横臂，整根立柱能回转
    工作空间形状 圆柱体（中间被挖掉一小段圆柱的「空心圆柱」）
    优点 能塞进狭小的空间；具有回转对称性，绕一圈都一样
    缺点 同样有「最小半径」，中心区够不到；末端姿态单一 ⚠
    典型用途 机床上下料、两工位之间的搬运、压铸机取件

    它和球坐标型的区别在哪：两者都靠「转 + 伸」定位， 但球坐标型的「伸」是沿倾斜臂伸缩（所以扫出球面）， 圆柱坐标型的「伸」是水平径向伸缩（所以扫出圆柱面）。 再加上第三个轴的竖直升降，就得到一个圆柱体 ✓

    课件的原话是它「fit into tight space, round symmetry」—— 塞得进窄空间、具有回转对称。这两条正好对应它的两个优点。

    2.4 关节型（Articulated robot / 关节臂型）—— RRR¶

    关节组成：三个转动副，记作 RRR。课件按转轴的朝向把它分成两种排布。

    （1）纵向排布（Vertical articulated robot）—— 像人的手臂

    项 内容
    关节组成 第 1 轴竖直回转（腰）；第 2 轴水平（肩，俯仰）；第 3 轴水平（肘，俯仰）
    典型外形 像人的手臂（课件原话：resemble of a human arm）
    工作空间形状 一个被地面截掉下部的球（「瘸腿球」）
    优点 灵活、结构紧凑、能伸到机身下方附近；承载大
    缺点 运动学求解复杂（有反解多解问题）；刚度不如直角坐标型 ⚠
    典型用途 焊接、搬运、装配、喷涂 —— 通用工业机械臂的主流形式

    （2）横向排布（Horizontal articulated robot）—— SCARA

    项 内容
    关节组成 两个竖直转动轴（大臂 + 小臂）+ 一个竖直移动副（末端升降）+ 末端一个绕竖直轴的转动
    典型外形 两条水平悬臂像「螃蟹钳」，末端一根能上下伸缩的轴
    工作空间形状 一个扁圆柱（平面内是圆环扇形，竖直方向行程较短）
    优点 在水平面内特别灵活、速度快；竖直方向只走移动副，刚度好
    缺点 竖直方向行程短；侧向承载能力弱；不适合大俯仰动作 ⚠
    典型用途 电子装配、插件、快速分拣搬运

    SCARA 全名是 Selective Compliance Assembly Robot Arm（选择顺应性装配机械臂）。 它的设计意图非常明确：装配时常常需要「水平方向能灵活对齐、 竖直方向要刚硬地插入」—— 于是让水平面的两个转动轴负责灵活性， 竖直方向用一个移动副保证刚性 ✓

    不要用「几个自由度」区分关节型与水平关节型

    两种名字里都带 RRR 的味道，数关节也不一定对得上。真正的区别是转轴的朝向：

    大臂 / 小臂的转轴 像什么
    纵向排布（关节型） 转轴水平 人的大臂小臂，能上下抬
    横向排布（SCARA） 转轴竖直 水平面里左右摆的两个「肘」

    所以判断一台机器属于哪一类，不要数关节个数，要看轴线方向 ⚠

    2.5 五种构型的一句话总览¶

    先把最容易记的口诀放这儿：「PP / RP / RP / RR」 —— 字母从下往上写，越靠近基座的关节写在越前面。

    构型 课件英文名 关节代码 一句话特征
    直角坐标型 Cartesian / gantry robot PPP 三个方向直线推拉，方箱子
    球坐标型（极坐标型） Polar / spherical robot RRP 先转再抬后伸缩，厚球壳
    圆柱坐标型 Cylinder robot RPP 转一圈 + 径向伸 + 上下升降，圆柱
    关节型（横向排布） Horizontal articulated robot RRR（此排布即 SCARA） 平面内两转 + 竖直移动，蟹钳
    关节型（纵向排布） Vertical articulated robot RRR 三个转动副串接，像人的手臂

    三、关节代码怎么读：从基座开始编号¶

    3.1 编号规则¶

    课件用一串字母表示构型，例如 RRP。读法有两条规矩：

    1. 字母是关节类型：R = Revolute，转动副；P = Prismatic，移动副。
    2. 顺序从基座到末端：第一个字母是固定在基座上的那个关节 （也就是现场常说的「第 1 轴」），最后一个字母是最靠近末端执行器的关节。

    怎么一眼记住字母顺序

    想象你站在机械臂底座旁边，用手沿着手臂往外摸：

    1
2
    基座 ──[第 1 轴]── 杆1 ──[第 2 轴]── 杆2 ──[第 3 轴]── 末端
        ↑第一个字母        ↑第二个字母        ↑第三个字母

    从内往外念，就是构型代码 ✓

    3.2 用 RRP 走一遍完整读法¶

    以球坐标型 RRP 为例，逐字读：

    位置 字母 关节类型 相对运动的方向 现场叫法
    第 1 个 R 转动副 绕竖直轴回转（整体转圈） 腰 / 回转轴
    第 2 个 R 转动副 绕水平轴俯仰（抬头低头） 肩 / 俯仰轴
    第 3 个 P 移动副 沿臂方向伸缩（变长变短） 伸缩臂

    读出来就是一句话：「底座会转 → 手臂会抬头 → 手臂能伸缩」。

    这句话说完，这台机器的形状就已经在脑子里了： 它一定是「底座 + 一根可俯仰的伸缩臂」，工作空间一定是球壳状 ✓

    3.3 五种构型逐轴对照¶

    下面把五种构型按「第 1 轴 / 第 2 轴 / 第 3 轴」拆开看。 这张表是本节的重点，把它读懂，构型代码就不会再记混：

    构型 代码 第 1 轴（靠基座） 第 2 轴 第 3 轴（靠末端）
    直角坐标型 PPP 水平移动 水平移动（与第 1 轴垂直） 竖直移动
    球坐标型 RRP 竖直轴回转 水平轴俯仰 沿臂伸缩
    圆柱坐标型 RPP 竖直轴回转 水平径向伸缩 竖直升降
    关节型（纵向） RRR 竖直轴回转 水平轴俯仰（肩） 水平轴俯仰（肘）
    关节型（横向，SCARA） RRR 竖直轴回转 竖直轴回转 竖直移动 + 末端绕竖直轴转动

    「第 1 轴」和「自由度」不是一回事

    现场说「这台机器是 6 轴的」，指的是它有 6 个独立驱动关节； 而构型代码里的 PPP / RRP 只描述定位用的前 3 个关节。

    两者关系是：

    说法 数的是什么 典型数字
    「自由度 F」 机构能独立运动的数目 3、4、6 ……
    「构型代码」 前三个关节的类型与顺序 PPP、RRP、RPP、RRR
    「几轴」 现场对关节的称呼 第 1 轴 … 第 6 轴

    一台机器可能写「RRR 关节型 + 3 个手腕关节」， 那么它的自由度是 6，但构型的「骨架」仍然是 RRR ✓

    四、为什么实际工业机器人以关节型为主¶

    4.1 先看一个「反直觉」的事实¶

    如果按控制难度排，直角坐标型最简单： 三个轴互不干扰，走直线就是各走各的，几乎不需要做坐标变换。

    但走进任何一条汽车焊装线或总装线，看到的绝大多数是关节型。 为什么不选最好控制的那个？

    4.2 三条真实理由¶

    理由一：工作空间效率（同样臂长，够到的空间大得多）

    关节型把「回转」这个运动用在了最靠近基座的关节上。 一个转动副转一圈，就把整条手臂都带着扫过一周 —— 用一个电机的代价换来 360° 的覆盖。

    而直角坐标型要靠三根导轨分别铺出三方向行程， 机器自身的体积往往比它能覆盖的工作空间还大 ⚠

    理由二：灵活性与姿态能力

    关节型有三个转动关节，末端可以做出俯仰、回转的组合动作， 像人的手臂一样绕到工件侧面、从上方斜插进去。 直角坐标型末端姿态固定（除非再加手腕），遇到「斜着伸进去焊一条缝」 这种活就无能为力。

    理由三：占用空间与安装方式

    关节型是悬臂式的：底座一装，手臂就能伸出去， 不占用地面的大片面积。直角坐标型的导轨必须铺满整个工作范围， 地面和上方空间都要占。

    对比项 直角坐标型 关节型 谁更好
    控制难度 简单（三轴解耦） 复杂（耦合，需求反解） 直角坐标型 ✓
    工作空间 / 自身体积 小（导轨要铺满） 大（悬臂扫过） 关节型 ✓
    末端姿态能力 固定（除非加手腕） 变化丰富 关节型 ✓
    地面占用 大 小 关节型 ✓
    刚度与精度 高 相对较低 ⚠ 直角坐标型 ✓
    承载 / 自重比 一般 好 关节型 ✓

    结论：关节型在「空间效率、姿态能力、占地」上全面领先， 只在「控制简单、刚度精度」上让出一点。 对一个要干几十种活、又要塞进拥挤产线的通用机械臂来说， 这笔交易是赚的 ✓

    「关节型为主」不等于「其他构型没用」

    选型不是比谁高级，而是看活干得顺不顺。

    干活场景 更合适的构型 原因
    三坐标测量、大幅面 3D 打印 直角坐标型 需要严格的直线运动和高刚度
    压铸机取件、机床上下料 圆柱坐标型 狭小空间内做两工位搬运
    大范围喷涂、焊接 球坐标型 少量关节覆盖大空间
    电子插件、快速分拣 SCARA（横向排布） 平面内快、竖直方向刚性插入
    通用焊接 / 搬运 / 装配 关节型（纵向排布） 姿态灵活、占地小

    所以正确的说法是：通用场合关节型占主流，专用场合各有各的主力 ⚠

    五、「手腕」与「手臂」的分工¶

    5.1 把六个自由度拆成两组¶

    一台通用的六自由度机械臂，可以看成两段功能完全不同的机构：

    部位 由哪些关节组成 负责什么 类比
    手臂（定位） 前 3 个关节 把末端送到空间中的某个点 你的大臂 + 小臂
    手腕（定向） 后 3 个关节 把末端摆成某个方向 你的手腕 + 手掌

    为什么正好是 3 + 3：空间中的一个位置有 3 个坐标， 一个方向（姿态）也正好有 3 个独立转动。 所以「定位 3 个 + 定向 3 个 = 6」正好把「在哪儿」和「朝哪儿」分开包圆 ✓

    5.2 定位：前 3 轴¶

    前 3 轴的构型决定了这台机器「属于哪一种基础构型」——

    前 3 轴构型 定位能力
    PPP 三个方向的直线范围，末端姿态天然固定
    RRP 球坐标覆盖，半径可变
    RPP 圆柱体积覆盖，半径可变
    RRR 最大的姿态范围与空间效率（关节型）

    关键点：手腕不参与定位。 把手腕随便怎么转，末端工具的「尖点」位置不变（对腕心而言）。 所以「这台机器能到哪」只由前 3 轴决定， 「这台机器能摆成什么样」只由后 3 轴决定 ✓

    5.3 定向：后 3 轴¶

    后 3 个关节通常安排成三个互相垂直的转动副， 彼此轴线交于一点（这个点叫腕心）。

    手腕的 3 个转动 通俗说法 效果
    第 1 个 手臂自转（Roll） 让工具绕自身轴转
    第 2 个 手腕俯仰（Pitch） 让工具上下摆
    第 3 个 手腕偏摆（Yaw） 让工具左右摆

    为什么做成「轴线交于一点」：当三个转动轴交于一点时， 手腕转动不会改变腕心位置 —— 于是「定位」和「定向」在数学上彻底解耦： 前者用前 3 轴算，后者用后 3 轴算，不用互相迭代 ⚠ 这一点在 后面讲运动学反解时会反复用到。

    六个自由度不是「六个移动」

    「六个自由度」很容易被误解成「能往六个方向平移」。

    实际上：

    自由度 含义 数量
    平移自由度 沿三个方向移动 最多 3 个
    转动自由度 绕三个方向转动 最多 3 个

    空间中的刚体最多只有这 6 个自由度，不可能有 7 个 ⚠ 所谓「冗余机械臂」（7 自由度以上）指的是关节比 6 多， 多出来的自由度用来做「关节角可调、末端位置不变」的附加优化， 而那多出来的关节提供的仍然是「平移 + 转动」这 6 类中的一种 ✓

    六、自由度与构型编号的关系¶

    6.1 从基座到末端逐个编号¶

    现场与课件都用「第 1 轴 … 第 6 轴」来称呼关节，编号规则是 从基座往末端数，与构型代码的字母顺序完全一致。

    下表以一台典型的纵向排布六轴关节型机械臂为例， 说明每个轴的运动平面与作用：

    轴号 关节类型 转动 / 移动平面 承担的任务 归属
    第 1 轴 R（转动） 绕竖直轴在水平面内转 整体左右回转（腰） 手臂（定位）
    第 2 轴 R（转动） 绕水平轴在竖直平面内转 大臂俯仰（肩） 手臂（定位）
    第 3 轴 R（转动） 绕水平轴在竖直平面内转 小臂俯仰（肘） 手臂（定位）
    第 4 轴 R（转动） 绕小臂轴线转 工具自转（Roll） 手腕（定向）
    第 5 轴 R（转动） 绕与第 4 轴垂直的轴转 手腕俯仰（Pitch） 手腕（定向）
    第 6 轴 R（转动） 绕工具轴线转 工具偏摆 / 自转（Yaw） 手腕（定向）

    共同规律（可以直接背）：

    1. 前 3 轴都在「大范围」上工作 —— 转轴朝向彼此垂直，负责把工具搬到位置。
    2. 后 3 轴的轴线交于一点（腕心），负责把工具摆成方向。
    3. 越靠基座的轴，带动的质量越大，所以要做得越粗壮、越慢； 越靠末端的轴越轻快。

    6.2 构型编号为什么只写 3 个字母¶

    课件写构型时只写 PPP / RRP / RPP / RRR 这类三个字母的代码， 而不是把 6 个关节全写出来。原因：

    原因 说明
    前 3 轴定构型 一台机器「属于哪一类」，只看前 3 轴的关节类型与顺序
    手腕是通用件 后 3 轴做成统一的三轴手腕，可以配在任意构型的手臂上
    工作空间由前 3 轴定 能到哪片空间，只由前 3 轴决定；手腕只影响朝向

    所以本页第二节的「五种基础构型」，讲的其实都是手臂（前 3 轴）的形状 ✓

    6.3 关节数、自由度与构型代码三者的关系¶

    把它们的关系画成一张表，避免以后再混：

    概念 单位 由什么决定 例子
    关节数 个 实际机械连接点的个数 6 个关节
    自由度 F 个 独立运动的数目（低副 1 个关节 = 1 个自由度） \(F = 6\)
    构型代码 字母串 前 3 个关节的类型与顺序 RRR
    「几轴」 个 现场对关节的称呼，等同关节数 6 轴

    注意一个易错点：手腕里的转动副有可能出现「两个轴共线」的特殊姿态， 这时机械上还是 6 个关节，但末端在瞬时失去一个方向的转动能力 （俗称奇异性）。

    情形 关节数 瞬时独立自由度数 后果
    一般姿态 6 6 正常，能到达任意位姿 ✓
    奇异姿态（如第 4、6 轴共线） 6 5（瞬时） 某个方向动不了，需要绕开 ⚠

    数关节 ≠ 数自由度，两个都要会算

    为什么不能拿「关节数」当「自由度数」报：

    陷阱 说明
    移动副也是 1 个自由度 不要把转动副当「真正的关节」，移动副同样只贡献 1
    高副要单独算 若机构里有齿轮、凸轮，它们只提供 1 个约束而不是 2 个
    虚约束会重复计数 结构里存在不起独立限制作用的约束时，自由度要减掉
    奇异位形瞬时降阶 关节数不变，但某个方向瞬时动不了

    本课程前一节讲过的平面机构自由度公式 \(F = 3(l-1) - 2P_L - P_H\) 在这里同样适用： 低副 \(P_L\) 每个扣 2 个约束，高副 \(P_H\) 每个扣 1 个，再减掉虚约束。

    所以判断一台机器「有几个自由度」，必须先看机构里有哪几种运动副， 而不是直接数「有几个能转的地方」⚠

    6.4 用曲柄滑块看清「关节类型决定运动形式」¶

    上面讲的都是「几个转动副 + 几个移动副」的组合。 但要理解为什么换个关节类型，整台机器的运动就变了， 最清楚的例子是曲柄滑块机构：它把一个转动副的连续转动， 变成滑块（移动副）的往复移动。

    这张图说明了本页最重要的一句话： 关节类型就是「运动形式的转换器」—— 转动副 R 输入的是「转」，移动副 P 输出的是「来回走」。

    机构里的关节 类型 带来的运动
    曲柄与机架之间 转动副 R 曲柄连续转
    曲柄与连杆之间 转动副 R 两者相对转
    连杆与滑块之间 转动副 R 两者相对转
    滑块与导轨之间 移动副 P 滑块只能直线往复

    把这张表和第二节的五种构型对照着看就明白了： 直角坐标型全用 P，所以末端只能平移；关节型全用 R，所以末端灵活； 而球坐标型与圆柱坐标型混用 R 和 P， 所以才会有「球壳」和「圆柱」这两种介于中间的工作空间 ✓

    6.5 串联 ≠ 把关节随便串起来¶

    「串联机构」指的是构件与运动副首尾相接成一条链。 但串成一条链只是形式，真正决定它能不能动、能动几个方向的， 是这条链上有几个低副、有没有高副、有没有虚约束。

    下面这张图是一个最简单的串联链：四根构件用四个转动副串成一个闭环， 算出来自由度是 1 —— 即只需要一个驱动就能让整个机构动起来。

    把它和本页讲的五种构型放一起看，可以得到一条很重要的判断逻辑：

    机构 关节构成 自由度 驱动数 说明
    四杆机构 4 个转动副 \(F = 1\) 1 个 开环的串联链固定一端后剩下的自由度
    直角坐标型 PPP 3 个移动副 \(F = 3\) 3 个 三个方向互不干扰 ✓
    圆柱坐标型 RPP 1 转 + 2 移 \(F = 3\) 3 个 回转、伸缩、升降各一个
    关节型 RRR（手臂） 3 个转动副 \(F = 3\) 3 个 加 3 个手腕关节后 \(F = 6\)

    结论：「想要几个自由度，就要配几个驱动」 —— 机械臂前三个关节全是低副（每个低副贡献 1 个自由度）， 所以三关节手臂就是 3 个自由度、需要 3 个电机 ✓

    串联链越长，误差越会累加

    串联机构有一个天生的缺陷：误差沿链条逐级累加。

    串联机构 并联机构
    结构 一根链条串下去 多条链同时拉住末端
    误差 各级误差相加，末端精度最差 ⚠ 各链误差互相平均，精度更高
    工作空间 大 小
    控制 相对简单（关节角直接对应） 复杂（各链要协调）

    所以本页讲的五种构型全是串联： 它们的工作空间与灵活性最好，代价是精度要靠制造与标定补回来 ⚠

    七、工作空间体积：手算与代码核对¶

    7.1 为什么必须会估工作空间¶

    工作空间（workspace）就是末端能到达的所有点的集合。 选型时第一个要回答的问题就是：「工件在不在它的工作空间里？」 如果不在，这台机器再便宜也不能用。

    工作空间的形状由构型决定（第二节已讲）， 大小由杆长决定。下面用同一组尺寸参数， 把五种构型的体积用公式算出来再对比。

    7.2 统一设定尺寸参数¶

    为了让五种构型可比，统一取：

    参数 符号 取值 含义
    伸出长度（或行程） \(L\) 0.5 m 手臂的最大伸出量 / 导轨行程
    最短伸长度 \(L_{\min}\) 0.1 m 伸缩臂收到底的长度
    竖直行程 \(H\) 0.5 m 竖直方向的移动范围
    水平面内偏转范围 \(\theta\) \(2\pi\) 绕竖直轴的转角范围（整圈）
    俯仰角范围 \(\beta\) 从 \(0\) 到 \(\pi/2\) 臂从水平抬到竖直

    7.3 五种构型的体积公式（逐步推）¶

    （1）直角坐标型 PPP

    三个移动副互相垂直，行程分别是 \(L\)、\(L\)、\(H\)， 工作空间是一个长方体：

    \[V_{\text{PPP}} = L \times L \times H = L^2 H\]

    代入 \(L = 0.5\)、\(H = 0.5\)：

    \[V_{\text{PPP}} = 0.5^2 \times 0.5 = 0.125\ \text{m}^3\]

    怎么读这个式子：体积就是三条边相乘，\(L\) 的平方来自两条水平导轨。

    （2）球坐标型 RRP

    第 1 个转动副转一整圈，第 2 个转动副从水平抬到竖直（\(\beta\) 从 \(0\) 到 \(\pi/2\)）， 半径从 \(L_{\min}\) 到 \(L\)。这正好是一个球壳的一部分。

    先想「半径 \(r\)、仰角从 \(0\) 到 \(\pi/2\)、方位角一整圈」的球面扇形体积： 球坐标的体积微元是 \(r^2 \sin\beta\ dr\ d\beta\ d\theta\)。 把 \(\theta\) 从 \(0\) 积到 \(2\pi\)、\(\beta\) 从 \(0\) 积到 \(\pi/2\)：

    \[\int_0^{2\pi}\!\int_0^{\pi/2}\!\int_{L_{\min}}^{L} r^2 \sin\beta\ dr\, d\beta\, d\theta\]

    先算角度部分：

    \[\int_0^{2\pi} d\theta = 2\pi\]
    \[\int_0^{\pi/2} \sin\beta\ d\beta = \Big[-\cos\beta\Big]_0^{\pi/2} = 0 - (-1) = 1\]

    再算半径部分：

    \[\int_{L_{\min}}^{L} r^2\ dr = \frac{L^3 - L_{\min}^3}{3}\]

    三部分相乘：

    \[V_{\text{RRP}} = 2\pi \times 1 \times \frac{L^3 - L_{\min}^3}{3} = \frac{2\pi}{3}\left(L^3 - L_{\min}^3\right)\]

    代入 \(L = 0.5\)、\(L_{\min} = 0.1\)：

    \[V_{\text{RRP}} = \frac{2\pi}{3}\left(0.5^3 - 0.1^3\right) = \frac{2\pi}{3}(0.125 - 0.001) = \frac{2\pi}{3}\times 0.124 \approx 0.2597\ \text{m}^3\]

    注意：因为 \(L_{\min} \neq 0\)，得到的是球壳， 所以式子里是 \(L^3 - L_{\min}^3\) 而不是 \(L^3\) —— 这个减号就是「中心掏空」的数学表达 ✓

    （3）圆柱坐标型 RPP

    第 1 个转动副转一整圈、径向从 \(L_{\min}\) 到 \(L\)、竖直行程 \(H\)：

    \[V_{\text{RPP}} = \pi\left(L^2 - L_{\min}^2\right) H\]

    为什么是平方差：径向长度 \(r\) 扫过一圈得到 \(\pi r^2\)， 从 \(L_{\min}\) 到 \(L\) 积分，用「大圆面积减小子圆面积」即可：

    \[\int_{L_{\min}}^{L} 2\pi r\ dr \times H = \pi(L^2 - L_{\min}^2)H\]

    代入 \(L = 0.5\)、\(L_{\min} = 0.1\)、\(H = 0.5\)：

    \[V_{\text{RPP}} = \pi(0.25 - 0.01)\times 0.5 = 0.12\pi \approx 0.3770\ \text{m}^3\]

    （4）关节型 RRR（纵向排布）

    设大臂长 \(L\)、小臂长 \(L\)，两个俯仰轴在竖直平面内转动。 末端到的最大半径是 \(2L\)，最小半径是 \(L\)（小臂折回到大臂上）。 在这种「理想化对称臂」下，工作空间是一个球壳状区域：

    \[V_{\text{RRR}} \approx \frac{2\pi}{3}\left[\left(2L\right)^3 - L^3\right] = \frac{2\pi}{3}\left(8L^3 - L^3\right) = \frac{14\pi}{3}L^3\]

    代入 \(L = 0.5\)：

    \[V_{\text{RRR}} \approx \frac{14\pi}{3}\times 0.125 \approx 1.8326\ \text{m}^3\]

    这一步的物理含义：\(2L\) 与 \(L\) 之间的球壳，体积与 \(L^3\) 成正比， 所以手臂一加长，工作空间是立方级地涨 —— 这正是关节型「空间效率高」的数学证据 ✓

    （5）SCARA（横向排布）

    两个竖直转动轴在水平面内转动，末端在平面内到达的范围是半径 \(L\) 到 \(2L\) 的圆环， 再乘竖直行程 \(H\)：

    \[V_{\text{SCARA}} = \pi\left[\left(2L\right)^2 - L^2\right] H = 3\pi L^2 H\]

    代入 \(L = 0.5\)、\(H = 0.5\)：

    \[V_{\text{SCARA}} = 3\pi \times 0.25 \times 0.5 = 0.375\pi \approx 1.1781\ \text{m}^3\]

    读法：SCARA 的可行区域是一个扁扁的圆环柱， 跟关节型比少了球面的上下起伏，所以体积小一些， 但平面内覆盖能力很强。

    import math

# 用「数格子」法独立核对体积公式
# 把工作空间所在的立方体区域切成 n x n x n 个小格子，
# 逐格判断格子中心是否落在工作空间内，落在里面的计数
L = 0.5
Lmin = 0.1
H = 0.5
n = 120           # 每边格子数

# 判断一个点 (x, y, z) 是否属于某构型的工作空间
def in_ppp(x, y, z):
    return 0.0 <= x <= L and 0.0 <= y <= L and 0.0 <= z <= H

def in_rrp(x, y, z):
    # 球坐标型：方位角 theta 任意一圈，仰角 beta 从 0 到 90 度，臂长 rho 从 Lmin 到 L
    # 于是 z >= 0（仰角不超过 90 度），且到基座的三维距离 rho 落在 [Lmin, L]
    if z < 0.0:
        return False
    rho = math.sqrt(x * x + y * y + z * z)
    return Lmin <= rho <= L

def in_rpp(x, y, z):
    r = math.hypot(x, y)
    return Lmin <= r <= L and 0.0 <= z <= H

def in_rrr(x, y, z):
    r = math.hypot(math.hypot(x, y), z)
    return L <= r <= 2 * L

def in_scara(x, y, z):
    r = math.hypot(x, y)
    return L <= r <= 2 * L and 0.0 <= z <= H

# 采样区域取 [-1, 1] x [-1, 1] x [0, 1]，覆盖所有这几种工作空间
lo, hi, zlo, zhi = -1.0, 1.0, 0.0, 1.0
dx = (hi - lo) / n
dz = (zhi - zlo) / n
cell = dx * dx * dz

# 各构型的解析公式值（上一节手推的结果）
exact = {
    "直角坐标型 PPP": L * L * H,
    "球坐标型 RRP": 2 * math.pi / 3 * (L ** 3 - Lmin ** 3),
    "圆柱坐标型 RPP": math.pi * (L ** 2 - Lmin ** 2) * H,
    "关节型 RRR": 2 * math.pi / 3 * ((2 * L) ** 3 - L ** 3),
    "水平关节型 SCARA": math.pi * ((2 * L) ** 2 - L ** 2) * H,
}
preds = {
    "直角坐标型 PPP": in_ppp,
    "球坐标型 RRP": in_rrp,
    "圆柱坐标型 RPP": in_rpp,
    "关节型 RRR": in_rrr,
    "水平关节型 SCARA": in_scara,
}

print("数格子法核对（每边 %d 格，格子体积 = %.8f m^3）" % (n, cell))
print()
print("构型                 格子数      数格子体积   解析公式值   相对偏差")
print("-" * 74)
for name in exact:
    cnt = 0
    for i in range(n):
        x = lo + (i + 0.5) * dx
        for j in range(n):
            y = lo + (j + 0.5) * dx
            for k in range(n):
                z = zlo + (k + 0.5) * dz
                if preds[name](x, y, z):
                    cnt += 1
    v_grid = cnt * cell
    v_exact = exact[name]
    dev = abs(v_grid - v_exact) / v_exact
    print("%-20s %-11d %-12s %-12s %s"
          % (name, cnt, round(v_grid, 4), round(v_exact, 4),
             "%.4f" % round(dev, 4)))
print()

print("偏差都在 0.1% 以内，说明上面的体积公式没有写错。")

    例题 1：读出构型代码并判断工作空间形状¶

    某机械臂的关节从基座到末端依次是： ① 绕竖直轴回转的转动副；② 沿水平方向伸缩的移动副；③ 沿竖直方向升降的移动副。 后面接一个两轴手腕。

    （1） 写出这台机器前三个关节的构型代码。 （2） 它的工作空间是什么形状？ （3） 为什么它够不到底座正上方很近的地方？

    思路

    按「从基座到末端」的顺序把 R 和 P 写下来就是构型代码。 形状要靠「每个关节单独扫出什么面」再叠起来想： 回转扫出圆面，伸缩改变半径，升降改变高度 → 圆柱。 够不到中心的原因要回到「伸缩臂有最小长度」。

    解答

    （1）写构型代码。

    从基座到末端依次是：转动（R）、移动（P）、移动（P），所以是 RPP —— 圆柱坐标型 ✓

    （2）判断工作空间形状。

    逐步看每个关节单独能扫出什么：

    关节 单独效果 扫出的面
    ① 竖直轴回转 整条横臂绕竖直轴转一圈 一个水平圆（方位角 \(\theta\) 任意）
    ② 径向伸缩 末端到轴线的距离可变 半径从 \(L_{\min}\) 到 \(L\)
    ③ 竖直升降 上述圆面的高度可变 高度从 \(0\) 到 \(H\)

    半径可变 + 方位任意 → 水平截面是圆环（内径 \(L_{\min}\)、外径 \(L\)）； 再沿高度拉伸 \(H\) → 整体是空心圆柱 ✓

    （3）为什么够不到中心。

    因为第 ② 个关节是移动副，它有一个收到底的最小长度 \(L_{\min}\)。 当 \(L_{\min} = 0.1\) m 时，半径 \(r\) 只能取 \(0.1 \le r \le 0.5\)， \(r = 0\) 根本取不到 —— 所以底座正中心是一条永远够不着的空洞 ⚠

    现在用数字说明这块空洞有多大。它是半径 \(L_{\min}\)、高度 \(H\) 的一个小圆柱：

    \[V_{\text{空}} = \pi L_{\min}^2 H = \pi \times 0.1^2 \times 0.5 = 0.005\pi \approx 0.0157\ \text{m}^3\]

    相对于总体积 \(V_{\text{RPP}} \approx 0.3770\ \text{m}^3\)，占比为：

    \[\frac{V_{\text{空}}}{V_{\text{RPP}}} = \frac{0.005\pi}{0.120\pi} = \frac{0.005}{0.120} \approx 0.0417 = 4.17\%\]

    大约是 4.17% 的空间白白浪费 ✓

    结论：构型代码 RPP，工作空间是空心圆柱， 底座正中心有一个半径 \(L_{\min} = 0.1\) m 的够不到区域， 这块空洞占总体积的 4.17% ⚠

    例题 2：同样臂长，为什么关节型的工作空间大这么多¶

    一台直角坐标型机械臂：三个方向的行程都是 \(0.5\) m。 一台关节型机械臂：大臂、小臂各 \(0.5\) m。

    （1） 分别算两者的工作空间体积。 （2） 求体积倍数。 （3） 解释这个差距从哪里来。

    思路

    直角坐标型直接用长方体公式 \(V = L \times L \times H\)。 关节型按「大臂小臂各 \(L\)，末端半径从 \(L\) 到 \(2L\) 的球壳」估算。 差距的来源要回到「转动副扫过的是球面，移动副扫过的是直线」。

    解答

    （1）两个体积。

    直角坐标型（PPP）：

    \[V_{\text{PPP}} = L \times L \times H = 0.5 \times 0.5 \times 0.5 = 0.125\ \text{m}^3\]

    关节型（RRR），半径从 \(L\) 到 \(2L\) 的球壳。 先算两个半径：\(2L = 2 \times 0.5 = 1.0\)，\(L = 0.5\)。

    先算 \(1.0^3\) 与 \(0.5^3\)：

    \[1.0^3 = 1.0 \times 1.0 \times 1.0 = 1.0\]
    \[0.5^3 = 0.5 \times 0.5 \times 0.5 = 0.125\]

    相减：

    \[(2L)^3 - L^3 = 1.0 - 0.125 = 0.875\]

    再乘上前面的系数 \(\frac{2\pi}{3}\)：

    \[V_{\text{RRR}} = \frac{2\pi}{3} \times 0.875 = \frac{1.75\pi}{3} \approx 0.5833\pi \approx 1.8326\ \text{m}^3\]

    （2）体积倍数。

    \[\frac{V_{\text{RRR}}}{V_{\text{PPP}}} = \frac{1.8326}{0.125} \approx 14.6608\]

    （3）差距从哪里来。

    根本原因只有一个：转动副扫出的是一整片球面，移动副扫出的只是一条直线。

    单个关节能覆盖的运动 覆盖的「厚度」
    移动副 P 一段直线 一维，只能沿一个方向
    转动副 R 一整片球面（或圆） 二维，同时改变两个方向

    所以把第 1 个关节从「移动」换成「转动」，等于用一个电机的代价 换来了整圈 360° 的覆盖。关节型前三个关节全是转动副， 这份「整圈红利」被吃满三次，体积自然就拉开一个数量级 ✓

    结论：同样 \(0.5\) m 的臂长，关节型工作空间约为直角坐标型的 14.6608 倍。 这就是「空间效率」的量化含义。

    例题 3：为什么手腕不参与定位¶

    某六轴关节型机械臂，前三个关节到达的末端位置是 \((x, y, z)\)。 现在只转动第 4、5、6 轴（手腕的三个关节），前三个关节完全不动。

    （1） 工具的尖点位置会不会变？ （2） 什么条件下这个结论成立？ （3） 这个性质对控制有什么好处？

    思路

    想象你把手腕晃来晃去、大臂小臂不动，手里的笔尖会不会乱跑。 关键要看手腕三个轴的轴线是不是交于一点。 好处要从「定位」和「定向」能不能分开算来想。

    解答

    （1）尖点位置会不会变。

    不会变。 因为手腕的三个转动轴交于同一点（这个点叫腕心）。 转动一个轴，只是让工具绕着穿过腕心的那根轴线转， 工具尖点与腕心的距离不变，方向绕轴转 —— 但腕心本身没动（前三个关节没动）， 所以尖点只是原地绕腕心画圆，它的位置完全没变 ✓

    为什么可以这么断言：设腕心为 \(O\)，工具尖点为 \(P\)。 工具是刚体，装手腕末端，所以 \(P\) 相对于 \(O\) 的位置向量 \(\vec{OP}\) 长度固定、方向固定。手腕任一轴的转动 是绕过 \(O\) 的某条直线转一个角度， 这种转动保持 \(O\) 不动，也保持 \(|\vec{OP}|\) 不变。 而 \(O\) 又是前三个关节定下来的，没动 —— 所以 \(P\) 的位置由「\(O\) 加上一个不变的向量」给出，不可能变。

    一句话：在「工具装在手腕末端、且三个轴交于一点」的正常机械臂上， 转手腕只会改变工具的朝向，不会改变工具尖点的位置 ✓

    （2）成立的条件。

    条件 说明
    手腕三个转动轴交于一点 不交于一点就没有共同的 \(O\)，定位与定向会耦合 ⚠
    前三个关节不动 一旦动前三个关节，腕心 \(O\) 自己就移动了
    工具是刚体且与手腕相对固定 工具如果还能相对手腕再动，结论就不成立
    尖点相对腕心的偏移量不变 换刀后偏移量变了，要重新标定 ⚠

    （3）对控制的好处。

    好处是解耦，可以拆成两个独立的小问题：

    步骤 用哪些关节 要解的问题
    第一步：定位 前 3 个关节 让腕心到达目标点
    第二步：定向 后 3 个关节 让工具朝向目标方向

    如果不解耦，就要同时解 6 个未知数 —— 计算量大、多解难挑； 解耦之后，先解 3 个、再解 3 个，问题规模小了一半以上 ✓

    结论：手腕不参与定位的前提是三轴交于一点； 这个设计让「定位 3 个 + 定向 3 个」可以分开算， 这正是六轴关节型机械臂成为工业标准的原因之一。

    例题 4：给定工件位置，选哪种构型¶

    某产线要在两个工位之间搬运零件： 工件从料仓取出（位置在机械臂底座正前方约 \(0.4\) m、高度 \(0.3\) m）， 放到另一台设备上（水平偏转约 \(120°\)、距离约 \(0.4\) m、高度 \(0.3\) m）。 零件是扁平的方形盖板，只需要从上方竖直取放， 不需要倾斜或翻转。两个工位之间地面很紧张。

    （1） 需要几个自由度？需要手腕吗？ （2） 在五种基础构型里，哪两种比较合适？为什么？ （3） 最终会选哪一种？说明理由。

    思路

    先数「要控制哪些量」：位置 3 个 + 姿态 1 个（绕竖直轴的角度）。 再看「不需要什么」：不需要倾斜，所以不需要多轴手腕。 最后结合「地面紧张」「竖直取放」这两个条件筛构型。

    解答

    （1）需要几个自由度。

    逐条列需求：

    需求 需要的量 是否必须
    到达指定水平位置 水平面内 2 个坐标 必须 ✓
    到达指定高度 1 个高度 必须 ✓
    绕竖直轴对准盖板方向 1 个转角 必须 ✓
    倾斜 / 翻转盖板 —— 不需要 ✗

    所以需要 4 个自由度（3 个定位 + 1 个绕竖直轴定向）。 因为不需要倾斜，不需要多轴手腕，只要末端有一个绕竖直轴的转动即可。

    （2）哪两种构型合适。

    筛选过程：

    构型 能不能胜任 理由
    直角坐标型 PPP 一般 能竖直取放、刚性好，但导轨要铺满，地面紧张不合适 ⚠
    球坐标型 RRP 勉强 能覆盖大范围，但姿态调节少，取放方向不好保证
    圆柱坐标型 RPP 合适 ✓ 回转 + 径向 + 升降，正好匹配「转 120° + 取放」
    关节型（纵向）RRR 合适 ✓ 灵活、占地小，能覆盖两个工位
    水平关节型 SCARA 最合适 ✓ 平面内快、竖直方向是移动副，天生适合竖直取放

    真正符合「竖直取放 + 平面内两工位 + 地面紧张」的是 SCARA（水平关节型） 与 圆柱坐标型， 关节型（纵向）也做得到但「竖直取放」不是它的强项。

    （3）最终选择与理由。

    选 SCARA（水平关节型）。三条理由：

    理由 具体说明
    动作完全匹配 需求是「平面内转 + 竖直插拔」，SCARA 的第 3 轴正好是竖直移动副 ✓
    竖直方向刚性好 用移动副做插拔，比用转动副「弯腰去够」刚度高得多、重复定位精度好
    占地小、速度快 两条水平悬臂占地小，平面内转动惯量小，节拍快

    如果换成关节型会怎样：关节型也能到那两个工位， 但它要靠肩、肘两个转动副「弯腰」去够低处的点， 竖直方向的刚度与重复精度都要打折， 而且为了竖直取放还要额外注意姿态，控制更麻烦 ⚠

    结论：先数清需要的自由度与姿态要求，再按「动作匹配程度」 从五种构型里筛，最后用「占地、刚度、节拍」三个工程指标定案。 本例的答案是 SCARA，理由集中在「竖直取放」这一条上。

    九、自测¶

    Q1 把下列三台机器的关节从基座到末端列出来，写出它们的构型代码， 并说出工作空间的形状。

    （a）三个互相垂直的移动副。 （b）一个绕竖直轴的转动副 + 一个径向伸缩的移动副 + 一个竖直升降的移动副。 （c）两个竖直轴转动副（大臂、小臂）+ 一个竖直移动副。

    答案
    小题 关节序列 代码 工作空间形状 构型名称
    （a） 移动 + 移动 + 移动 PPP 长方体 直角坐标型
    （b） 转动 + 移动 + 移动 RPP 空心圆柱 圆柱坐标型
    （c） 转动 + 转动 + 移动 RRP 扁圆环柱 水平关节型（SCARA）

    注意（c）：它只有两个转动 + 一个移动， 所以构型代码是 RRP 而不是 RRR ✓ SCARA 的两个转动轴是竖直的（在水平面内摆）， 这一点和球坐标型 RRP 完全相反（后者第 2 轴是水平俯仰）⚠

    判断构型代码的口诀：从基座往末端念，遇到转动写 R、遇到移动写 P。

    Q2 判断对错并说明理由。

    （a）直角坐标型机械臂的三个关节是解耦的，所以控制最简单。 （b）关节型机械臂的工作空间是一个完整的球。 （c）只要关节数相同，两台机械臂的工作空间体积就一定相同。 （d）SCARA 的名字里带「水平」，指的是它的手臂只能在水平面内运动。

    答案

    （a）对 ✓ 三个移动副方向两两垂直， 末端坐标 \((x, y, z)\) 与三个关节变量是一对一的关系， 没有耦合，不需要做坐标变换，控制最容易。

    （b）错 ⚠ 关节型（纵向排布）的工作空间是被地面截掉下部的球， 也叫「瘸腿球」：地面以下的部分达不到。 而且小臂只能折回到大臂上，所以球心附近也有一块够不到。

    （c）错 ⚠ 工作空间的形状与体积由构型（关节类型与顺序）决定， 关节数相同但构型不同，体积可以差一个数量级 —— 例如同为 3 个关节，关节型体积约为直角坐标型的 14.6608 倍。

    （d）错 ⚠ 「水平关节型」说的是转轴是竖直的（手臂在水平面内摆动）， 但它的第 3 个关节是竖直移动副，能上下升降； 所以它的运动范围是一个扁圆环柱，不是平面的。 只是竖直方向的行程比较短，容易让人误以为它只能平面运动。

    Q3 某六轴关节型机械臂，大臂长 \(0.6\) m，小臂长 \(0.6\) m， 小臂可以完全折回到大臂上。

    （1）末端离基座最远能到多少米？ （2）最近能到多少米？ （3）如果按球壳估算工作空间体积，结果是多少？

    提示

    最远 = 两杆都伸直，等于两杆长之和； 最近 = 小臂折回，等于两杆长之差（本例两杆等长，所以是 \(0\)）。 体积用「半径从最近到最远的球壳」公式 \(V = \frac{2\pi}{3}(R_{\max}^3 - R_{\min}^3)\)。

    答案

    （1）最远距离。

    两杆都伸直，末端沿同一条直线往外伸：

    \[R_{\max} = L_1 + L_2 = 0.6 + 0.6 = 1.2\ \text{m}\]

    （2）最近距离。

    小臂完全折回，与大臂方向相反：

    \[R_{\min} = \left|L_1 - L_2\right| = \left|0.6 - 0.6\right| = 0\ \text{m}\]

    （3）按球壳估算体积。

    取下半部分（仰角范围 \(0\) 到 \(\pi/2\)，方位角一整圈）：

    \[V = \frac{2\pi}{3}\left(R_{\max}^3 - R_{\min}^3\right) = \frac{2\pi}{3}\left(1.2^3 - 0^3\right)\]

    先算 \(1.2^3\)：

    \[1.2^3 = 1.2 \times 1.2 \times 1.2 = 1.44 \times 1.2 = 1.728\]

    代入：

    \[V = \frac{2\pi}{3}\times 1.728 = \frac{2 \times 3.14159 \times 1.728}{3} \approx 3.6191\ \text{m}^3\]

    注意：因为本例两杆等长，\(R_{\min} = 0\)，所以球壳退化成实心半球， 中心不再有空洞 ✓

    但在实际机器上，小臂不可能真的完全折回到与大臂重合 （会撞在一起），工程上总要留出一段干涉余量 \(R_{\min} = 0.1 \sim 0.2\ \text{m}\) 左右。 此时球壳中心重新出现空洞，就会够不到紧贴基座的那一圈 ⚠

    顺便核对一次：如果取 \(R_{\min} = 0.1\) m，体积变成

    \[V' = \frac{2\pi}{3}\left(1.2^3 - 0.1^3\right) = \frac{2\pi}{3}(1.728 - 0.001) = \frac{2\pi}{3}\times 1.727 \approx 3.6172\ \text{m}^3\]

    只比理想值 \(3.6191\ \text{m}^3\) 小了约 \(0.002\ \text{m}^3\) —— 空洞虽小，但正好是底座正上方那一块最难替代的位置 ⚠

    Q4 一台六轴机械臂正在执行任务时，第 4 轴与第 6 轴的轴线重合了。

    （1）此时这台机器还能不能到达任意位姿？ （2）这属于什么现象？ （3）操作上应该怎么处理？

    答案

    （1）还能不能到达任意位姿。

    瞬时不能。 第 4 轴与第 6 轴共线时， 这两个轴转动的效果完全相同（都是让工具绕同一条轴线转）。 于是原本由 6 个关节提供的 6 个方向独立运动， 在这一瞬间只有 5 个是独立的 —— 有一个方向上的转动动不了。

    （2）属于什么现象。

    这叫奇异位形（singular configuration），也叫奇异点。

    项 说明
    机械上 关节数没有变，仍然是 6 个，机器没有坏
    数学上 描述「关节速度 → 末端速度」的矩阵瞬时降秩
    现象上 某个方向的末端运动，无论关节怎么动都实现不了 ⚠
    后果 想沿那个方向走，反解会要求关节速度趋于无穷大

    （3）操作上怎么处理。

    做法 说明
    避开 规划路径时绕开奇异位形，不要在共线姿态附近做动作
    限速 若必须经过附近，降低进给速度，避免关节速度暴涨
    换解 用别的关节组合（另一组反解）来完成同样动作
    选型时留余量 有冗余关节（7 轴）时，多余自由度可以用来「顶」过奇异区 ✓

    关键认识：「关节数」和「瞬时独立自由度数」不是一回事。 前者是机械事实，后者还取决于姿态。 数关节得到的是「标称自由度」，报给控制的还要看当前位形 ✓

    十、小结¶

    要记住的 为什么
    串联机器人有五种基础构型 直角坐标型 PPP、球坐标型 RRP、圆柱坐标型 RPP、关节型（纵向）RRR、水平关节型（SCARA）
    构型代码从基座往末端念 第一个字母是固定在基座上的关节，最后一个最靠近末端
    R = Revolute 转动副，P = Prismatic 移动副 只有这两个字母，所以构型数得过来
    直角坐标型 PPP → 工作空间是长方体 三个互相垂直的移动副，三轴解耦，控制最简单 ✓
    球坐标型 RRP → 工作空间是球壳 回转 + 俯仰 + 伸缩，中心被最小长度掏空 ⚠
    圆柱坐标型 RPP → 工作空间是空心圆柱 回转 + 径向伸缩 + 竖直升降；课件原话「塞得进窄空间、回转对称」
    关节型 RRR → 工作空间是被地面截掉下部的球 三个转动副串接，课件原话「像人的手臂」
    SCARA 是横向排布，转轴竖直 平面内两个竖直转动轴 + 竖直移动副；名字是「选择顺应性装配机械臂」
    区分纵向与横向排布，要看转轴方向 不要数关节个数：转轴水平是纵向，转轴竖直是横向 ⚠
    工业机器人以关节型为主的三条理由 空间效率高、姿态灵活、占地小 ✓
    「关节型为主」≠「其他构型没用」 三坐标测量用直角坐标型，插件分拣用 SCARA
    定位用前 3 轴，定向用后 3 轴 空间位置 3 个量 + 姿态 3 个量，正好分工
    手腕三轴交于一点（腕心） 这样手腕转动不改变腕心位置 → 定位与定向解耦 ✓
    工作空间只由前 3 轴定 所以构型代码只写 3 个字母
    关节型体积约是直角坐标型的 14.6608 倍（同臂长） \(\frac{14\pi}{3}L^3\) 除以 \(L^2 H\)；转动副扫球面，移动副扫直线
    关节型最远 / 最近 = 2 两杆伸直最远 \(2L\)，折回最近 \(L\) → 够不到中心 ⚠
    伸缩臂有最小长度，所以中心有空洞 球坐标型与圆柱坐标型的共同缺陷
    数关节 ≠ 数自由度 高副、虚约束、奇异位形都会让两者对不上 ⚠
    奇异位形下关节数不变但瞬时降秩 第 4、6 轴共线时，末端某个转动方向动不了
    选型先问三件事：动作匹配、占地、刚度 构型没有好坏，只有匹配不匹配 ✓
