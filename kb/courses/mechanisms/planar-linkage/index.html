    平面连杆机构¶

    这一页要回答的问题是：把四根杆用铰链连成一个闭环，再固定其中一根，会得到什么？

    答案只有有限的几种，而且由四根杆的长度关系唯一决定：

    看起来差不多 实际差别 后果
    四根杆的长度稍有不同 整转副的个数不同（可能是 1 个或 0 个） 机构可能变成双曲柄、曲柄摇杆或双摇杆 ⚠
    都是「四杆闭环」 固定哪一根当机架 同一个运动链派生三种不同机构 ✓
    都「能转」 传动角大小不同 传动角太小会卡死，或效率极低 ⚠

    所以本页的主线是一条判定链：长度关系 → 有没有整转副 → 固定哪一根 → 得到什么机构。

    这一页的核心问题

    平面连杆机构的所有结论，都挂在三个量上：

    量 它在问什么 本页哪一节回答
    长度之和 最短杆与最长杆之和，是否不超过另外两杆之和 第三节
    传动角 力的方向与受力点运动方向的夹角是否够小 第六节
    极位夹角 两个极限位置对应的工作行程与返回行程是否相等 第五节

    三个量各管一件事，不能互相替代： 长度条件合格不代表传动角合格，传动角合格也不代表急回特性满足要求

    一、什么是平面连杆机构¶

    1.1 定义¶

    平面连杆机构（Planar linkage）：由若干刚性构件用低副连接而成、 并且所有构件都在同一平面内（或若干相互平行的平面内）运动的机构。

    定义里的三个关键词，每一个都要落到实处：

    关键词 含义 为什么重要
    刚性构件 本身受力不变形的杆件（一个独立的运动单元） 只有不变形，「一根杆」才能当成一个参数来算
    低副 面接触的运动副：转动副（铰链）与移动副（导轨） 低副的约束数是 2，直接决定自由度
    同一平面内 所有构件的运动都平行于同一个平面 平面问题里一个自由构件只有 3 个自由度（不是 6 个）

    「低副」是连杆机构最本质的标签。 转动副和移动副都是面接触： 圆柱销配圆孔、滑块配导轨，靠的是两个面互相贴住，而不是点顶住点、线顶住线。

    低副与高副的区别，决定了整章的分类方式

    运动副 接触方式 约束数 典型例子
    低副 面接触 2 转动副（铰链）、移动副（导轨）
    高副 点接触或线接触 1 齿轮齿廓、凸轮轮廓

    「连杆机构里只有低副」这句话有三个推论：

    1. 接触面积大 → 压强小 → 能承受很大的载荷
    2. 磨损慢 → 寿命长、维护简单
    3. 每个低副消耗 2 个自由度 → 自由度公式里写 \(2P_L\)

    反过来看凸轮：凸轮与从动件是高副，点线接触，所以磨损快、承载小 —— 这正是「凸轮能实现任意运动规律，却扛不住大力」的原因

    1.2 优势：为什么工程上大量使用连杆机构¶

    优势 为什么成立 工程后果
    全部是低副 面接触，压强小 承载能力大、耐磨损 ✓
    能承受很大载荷 面接触的压强远小于点、线接触 冲床、压力机的主传动大量用连杆 ✓
    能实现多种运动转换 转动 → 摆动、转动 → 往复移动、转动 → 复杂轨迹 一种机构形式覆盖多种需求 ✓
    结构简单、可靠 主要零件就是杆、销、孔 不易出故障，维护简单
    制造容易、成本低 转动副就是一个圆孔配一根圆柱销 加工精度要求低于齿轮齿廓

    「能实现多种运动转换」值得单独看一眼。同一套四杆机构，只改变输出端取在哪里， 就能拿到完全不同的运动形式：

    输入运动 输出取在 输出运动形式 典型机械
    转动（曲柄） 另一个连架杆 往复摆动 缝纫机踏板、雨刮器
    转动（曲柄） 滑块 往复移动 内燃机、压缩机
    转动（曲柄） 连杆上的某个点 复杂封闭轨迹 步行机器人的腿

    1.3 缺点：三条必须记住的限制¶

    缺点 具体表现 怎么应对
    只能近似实现给定运动规律 ⚠ 杆长一确定，输出运动就被锁定，无法任意指定 对运动规律要求严格时改用凸轮
    存在死点位置 从动件传动角为 0 时，驱动力再大也推不动它 加飞轮靠惯性冲过去，或干脆利用它自锁
    惯性力难以平衡 构件做变速运动，质量分布不平衡 高速场合加配重，或改用其他机构

    「近似」这两个字要理解到位：它不是指连杆机构的输出不准确， 而是指你无法先任意指定一条输出运动规律，再让连杆去精确实现它。 连杆能实现的，只有由杆长决定的、有限的那几种运动关系

    把三种机构放在一起比，这条限制就很清楚了：

    想实现的效果 连杆机构 凸轮机构 齿轮机构
    任意指定的输出运动规律 ✗ 做不到 ✓ 能做到 ✗ 只能定传动比
    输出按固定传动比恒速转动 ✗ ✗ ✓
    输出做往复摆动 ✓ 由杆长决定 ✓ ✗
    输出走复杂封闭轨迹 ✓ 靠连杆点 ✗ ✗
    承载大、耐磨损 ✓ 低副面接触 ✗ 高副磨损快 中等

    一句话选型：要承载大又耐用选连杆，要任意运动规律选凸轮， 要传动比准确选齿轮

    1.4 手算自由度：三个机构各算一遍¶

    为什么第一件事是算自由度：不管机构长得多复杂，先确认它到底有几个自由度、 需要几个驱动。这一页涉及的四杆机构和曲柄滑块机构，自由度都是 1， 所以都只需要一个电机

    自由度的公式来自上一页的收支账，这里直接调用：

    \[F = 3(l - 1) - 2P_L - P_H\]

    \(l\) 是构件总数（含机架），\(P_L\) 是低副个数，\(P_H\) 是高副个数； \((l-1)\) 表示「除去机架以外，需要确定位置的构件数」； 每个自由构件提供 3 个自由度，每个低副扣掉 2 个，每个高副扣掉 1 个

    算例 A：铰链四杆机构。 构件总数 \(l = 4\)（三根活动杆 + 机架）， 四个转动副都是低副，所以 \(P_L = 4\)、\(P_H = 0\)。代入：

    \[F = 3 \times (4 - 1) - 2 \times 4 - 0 = 9 - 8 - 0 = 1\]

    算例 B：对心曲柄滑块机构。 构件总数还是 \(l = 4\) （曲柄、连杆、滑块、机架），运动副是 3 个转动副 + 1 个移动副， 移动副同样是低副，所以 \(P_L = 4\)、\(P_H = 0\)：

    \[F = 3 \times (4 - 1) - 2 \times 4 - 0 = 9 - 8 - 0 = 1\]

    算例 C：偏心曲柄滑块机构。 偏心只是把导轨中线平移了一个距离， 构件数和运动副数一个都没变，所以

    \[F = 3 \times (4 - 1) - 2 \times 4 - 0 = 1\]

    三个算例的结果对照：

    机构 构件数 \(l\) 低副 \(P_L\) 高副 \(P_H\) \(3(l-1)\) \(-2P_L\) \(F\)
    铰链四杆机构 4 4 0 9 8 1
    对心曲柄滑块机构 4 4 0 9 8 1
    偏心曲柄滑块机构 4 4 0 9 8 1

    这三行数字完全一样，不是巧合 —— 它们本来就是一个四构件运动链，只是把其中一个转动副换成了移动副 （连架杆从「绕机架摆动」变成「沿导轨滑动」）， 或者把移动副的导轨中线挪了个位置。约束的数目没变，自由度自然也没变

    由此得到两条很实用的结论：

    • 自由度是 1，意味着一个电机就能确定全部位形 所以后面所有讨论「给定曲柄转角 \(\theta\)，求滑块位置 \(s\)」的问题， 都是唯一确定的 —— 这正是第 2.5 节与第 4 节能逐项写出位置公式的前提 ✓
    • 自由度是 1 也意味着驱动放错位置就会出问题：把电机装在摇杆上， 它照样能带动整条链，但一旦走到某个位置传不动了， 整条链就会被「顶死」—— 这就是第七节的死点

    算自由度时的两个高频错点

    1. 机架要算进构件总数 \(l\)，但公式里用的是 \((l-1)\)， 因为机架的位置是已知的，不需要再去确定
    2. 移动副是低副，不是高副 ⚠ 它同样是面接触， 提供的约束数是 2，在公式里老老实实记进 \(P_L\)。 把移动副当成高副去算，会算出 \(F = 2\) 这种明显不对的结果 ✗

    2.5 位置分析：给定曲柄转角，求连杆与摇杆的方位¶

    问题：曲柄 AB 转到角度 \(\theta\) 时，连杆 BC 的方位角是多少？摇杆 CD 摆到哪个角度？

    解法：两圆交点法。 把机构想成两个圆：

    1. 曲柄先把 B 点送到 \((a\cos\theta,\ a\sin\theta)\)
    2. C 点必须同时满足两个距离条件：\(|BC| = b\)、\(|CD| = c\)
    3. 也就是说，C 在以 B 为圆心、\(b\) 为半径的圆上， 同时又在以 D 为圆心、\(c\) 为半径的圆上
    4. 两圆的交点就是 C 的两个可能位置 —— 对应两种装配方式（术语叫两个「分支」）

    逐步推导（不跳步）：

    第 1 步：写出 B 的坐标。 设 A 为原点，机架 AD 沿 \(x\) 轴，则 \(D = (d, 0)\)， B 点在以 A 为圆心、\(a\) 为半径的圆上：

    \[B = (a\cos\theta,\ a\sin\theta)\]

    第 2 步：算 B 到 D 的距离 \(L\)。 用两点距离公式：

    \[L = |BD| = \sqrt{(d - a\cos\theta)^2 + (a\sin\theta)^2}\]

    第 3 步：在三角形 BCD 里用余弦定理。 设从 C 向直线 BD 作垂线，垂足为 F，记 \(T = |BF|\)、\(h = |CF|\)（图中 \(h\) 就是 C 到 BD 的垂直距离）。 因为 A 与 F 之间没有别的约束，可以列出两个勾股关系：

    \[b^2 = T^2 + h^2\]
    \[c^2 = (L - T)^2 + h^2\]

    第 4 步：两式相减，消掉未知的 \(h\)。 用第一式减第二式：

    \[b^2 - c^2 = T^2 - (L - T)^2\]

    第 5 步：把右边展开。 展开平方项：

    \[b^2 - c^2 = T^2 - (L^2 - 2LT + T^2) = T^2 - L^2 + 2LT - T^2 = 2LT - L^2\]

    第 6 步：解出 \(T\)。

    \[T = \frac{b^2 - c^2 + L^2}{2L}\]

    第 7 步：解出 \(h\)。 代回勾股关系：

    \[h = \sqrt{b^2 - T^2}\]

    第 8 步：写出 C 的坐标。 记从 B 指向 D 的单位向量为 \(\mathbf{u} = (D - B)/L\)，把 \(\mathbf{u}\) 逆时针旋转 90° 得到法向量 \(\mathbf{n} = (-u_y,\ u_x)\)，则

    \[C = B + T\mathbf{u} \pm h\mathbf{n}\]

    \(\pm\) 对应两个分支：取正号是一种装配方式，取负号是另一种。 同一条曲柄转角下，这个机构确实存在两种位形，工程上必须指定用哪一种 ✓

    什么时候无解 —— 装配不上的角度

    第 7 步要开平方，要求 \(b^2 - T^2 \ge 0\)。 等价的说法是：两个圆要相交，即

    \[|b - c| \le L \le b + c\]

    如果某个曲柄转角下 \(L\) 超出这个范围，就说明这个机构在该角度装不上 这在判断「某杆能不能整周转动」时非常有用： 能让 \(L\) 在整个 0°～360° 里都满足不等式，那根杆才能整周转动

    下面把这套计算用手算做一遍（四个连杆长度单位统一取 mm）， 取 \(a = AB = 40\)、\(b = BC = 120\)、\(c = CD = 90\)、\(d = AD = 140\)， 曲柄角 \(\theta\) 从 0° 起每隔 45° 算一次。

    先算 \(\theta = 0°\)： 此时 \(B = (40,\, 0)\)，所以

    \[|BD| = \sqrt{(140 - 40)^2 + 0^2} = 100.000\]

    代入第 6 步的 \(T\)：

    \[T = \frac{b^2 - c^2 + |BD|^2}{2|BD|} = \frac{120^2 - 90^2 + 100^2}{2 \times 100} = \frac{14400 - 8100 + 10000}{200} = \frac{16300}{200} = 81.500\]

    代入第 7 步的 \(h\)：

    \[h = \sqrt{b^2 - T^2} = \sqrt{120^2 - 81.5^2} = \sqrt{14400 - 6642.25} = \sqrt{7757.75} = 88.078\]

    第 8 步的 \(C\) 点坐标：从 \(B = (40,0)\) 指向 \(D = (140,0)\) 的方向是 \(\mathbf{u} = (1, 0)\)，其法向量 \(\mathbf{n} = (0, 1)\)，取正号分支：

    \[C = B + T\mathbf{u} + h\mathbf{n} = (40 + 81.5,\ 0 + 88.078) = (121.500,\ 88.078)\]

    接着算连杆角与摇杆角（都是与 \(x\) 轴正向的夹角）：

    \[\psi = \arctan\frac{C_y - B_y}{C_x - B_x} = \arctan\frac{88.078}{81.500} = 47.221°\]
    \[\varphi = \arctan\frac{C_y}{C_x - d} = \arctan\frac{88.078}{-18.500} = 101.862°\]

    （分母为负、分子为正，所以答案在第二象限）

    其余各角度的算法完全一样，把 \(\theta\) 换掉重算上面五步即可。 把结果列成表：

    曲柄角 \(\theta\) / ° \(\|BD\|\) 连杆铰点 \(C\) 坐标 连杆角 \(\psi\) / ° 摇杆角 \(\varphi\) / °

    三、曲柄存在的条件（格拉斯霍夫判据）¶

    在往下读之前，先看清楚判据到底在判什么。 它只回答三个问题：

    判据回答的 判据不回答的
    至少存在一个整转副 ✓ 哪一根杆能整周转动 ✗
    最短杆两端的两个转动副就是整转副 ✓ 其它转动副是不是整转副 ✗
    — 整个机构是哪种类型 ✗

    「得到哪种机构」还要再叠加一个信息：固定哪一根杆当机架。 把这两个信息合起来，就只有四种组合 —— 下面一个一个说清楚为什么。

    组合 判据 机架取哪一根 得到什么机构 为什么
    ① 成立 与最短杆相邻的杆 曲柄摇杆机构 最短杆是连架杆，它两端都是整转副 → 它是曲柄；另一根连架杆只能摆动 → 摇杆 ✓
    ② 成立 最短杆本身 双曲柄机构 两根连架杆都跟最短杆相邻，接机架处都是整转副 → 两根都能整周转 ✓
    ③ 成立 最短杆的对面杆 双摇杆机构 两根连架杆接机架的转动副都不是整转副 → 都只能摆动 ⚠
    ④ 不成立 无论固定哪一根 双摇杆机构 一个整转副都没有，没有杆能转满一圈 ⚠

    为什么组合④「无论固定哪一根」都是双摇杆： 由格拉斯霍夫判据，\(s + l \gt p + q\) 时根本不存在整转副 —— 这不是「某一根不能转」的问题，而是整条运动链里任何转动副都不能整周相对转动。 机架只是把某一根杆相对固定住，改变不了「连杆与摇杆都装不上」这个事实

    怎么用这张表：拿到四根杆的长度和「哪一根当机架」，按顺序问两个问题 —— 判据成立吗？最短杆在哪？ 答案直接落在这四行里

    3.1 判据的符号约定¶

    这一节的起点是课件给出的一个定理名与一组符号。 课件在本节列出的内容是葛氏定理（Grashof's theorem），并定义了三个长度：

    符号 含义
    \(s\) 最短杆的长度（shortest bar）
    \(l\) 最长杆的长度（longest bar）
    \(p,\ q\) 两根中间长度的杆（intermediate bar）

    下面判据的具体内容、推导与三种结果，课件没有抽出可复制的文字， 按教材通用表述补全 —— 凡属补全的部分都标「补充」。 上一页「机构的基本元素」已经列出过三种结果的对应关系， 本节把它补上判据本身和推导。

    3.2 判据的内容「补充」¶

    葛氏判据（补充）：四杆机构中存在整转副的充要条件是

    \[s + l \le p + q\]

    最短杆与最长杆的长度之和，不大于另外两根杆的长度之和

    「整转副」的定义：两个构件能绕着这个转动副相对转满一圈（相对转角能取遍 \(0°\sim360°\)） 的转动副。反过来说，如果一个转动副两边的构件互相卡着，最多只能摆一个角度范围， 那它就是摆动副，不是整转副

    判据保证的是「存在」，不是「每根杆都能整周转」

    这是本节最容易理解错的一句话。\(s + l \le p + q\) 成立时，我们得到的是：

    判据成立时，能确定的 判据成立时，不能确定的
    至少存在一个整转副 ✓ 哪一根杆能整周转动 ✗
    最短杆两端的两个转动副就是整转副 ✓ 其它转动副是不是整转副 ✗
    — 整个机构是哪种类型 ✗

    「得到哪种机构」还要再叠加一个信息：固定哪一根杆当机架。 这就是 3.4 节那张表要说的事

    3.3 判据为什么是「和」而不是别的 —— 逐步推导「补充」¶

    推导的目标：说明「最短杆能整周转动」到底要求什么， 以及为什么最后会归结成一条两边之和的比较。

    第 1 步：把问题说成一个「三角形存在性」问题。

    设最短杆是 \(AB = a\)，它的相邻杆 \(AD = d\) 是机架，\(BC = b\) 是连杆，\(CD = c\)。 （这里用 \(a\) 代替判据里的 \(s\)，是为了和 2.5 节的代号一致。）

    \(AB\) 能整周转动的意思是：曲柄角 \(\theta\) 从 0° 涨到 360° 的过程中， B 点能走完整个圆，同时连杆 \(BC\) 与摇杆 \(CD\) 都装得上。

    B 点一旦确定，C 点就要由「到 B 的距离是 \(b\)、到 D 的距离是 \(c\)」这两个条件定出来。 这正是一个三角形的存在性问题：三角形 BCD 的三边是 \(b\)、\(c\)、\(|BD|\)。

    三角形存在的条件（三角形不等式）：任意两边之和大于第三边、任意两边之差小于第三边， 所以

    \[|b - c| \le |BD| \le b + c\]

    第 2 步：算清 \(|BD|\) 能取哪些值。

    B 点在以 A 为圆心、半径 \(a\) 的圆上跑，D 点固定在离 A 为 \(d\) 的地方（\(AD\) 是机架）。 一个固定的点到一个圆的圆周上任意一点的距离，取值范围是

    \[|BD| \in [\,|d - a|,\ d + a\,]\]

    怎么读这两端：B 转到「与 D 同一侧、离 D 最近」的位置时 \(|BD|\) 取到最短 \(|d - a|\)； B 转到「与 D 相背、离 D 最远」的位置时 \(|BD|\) 取到最长 \(d + a\) 中间的值也都能取到，因为 B 在圆上是连续地跑的

    第 3 步：要求「对一切 \(\theta\) 都成立」。

    曲柄整周转动，意味着每一个 \(\theta\) 都要装得上， 所以第 1 步那个不等式必须对 \(|BD|\) 的全部可能取值都成立。 因为 \(b\)、\(c\) 是常数，最苛刻的情形就落在 \(|BD|\) 的两端：

    \[|b - c| \le |BD|_{\min} = |d - a|\]
    \[|BD|_{\max} = d + a \le b + c\]

    第 4 步：把绝对值拆开。

    第一式 \(|b - c| \le d - a\)（因为把 \(AB\) 当最短杆，有 \(d \ge a\)，右边是正的）可以拆成两个不等式：

    \[b - c \le d - a \quad \Longrightarrow \quad a + b \le c + d\]
    \[c - b \le d - a \quad \Longrightarrow \quad a + c \le b + d\]

    第二式本身就是一个：

    \[a + d \le b + c\]

    第 5 步：合起来看这三个不等式的含义。

    \[a + b \le c + d, \qquad a + c \le b + d, \qquad a + d \le b + c\]

    三个式子的左边都含 \(a\)，右边是另外两杆之和。把它们统一写成一句话：

    \[a + \max(b, c, d) \le \text{（其余两杆之和）}\]

    左边就是「最短杆 + 最长杆」（因为 \(a\) 是最短杆，\(\max(b,c,d)\) 就是最长杆 \(l\)）， 右边就是「另外两杆之和」 —— 这正是 \(s + l \le p + q\)

    第 6 步：反过来看，判据里的最短杆一定要做连架杆吗？

    不一定 —— 判据本身只描述了四个长度之间的一个不等式关系，没说哪根杆在哪。 但只要先认定一根最短杆，上面的推导就说明了： 以最短杆的相邻杆为机架时，最短杆能整周转动 ⟺ 判据成立

    补充说明：判据的完整证明要按四种长度排列情形分别讨论， 上式是最基本的一种（最短杆做连架杆）。 本页只需用到这条结论：判据成立 → 最短杆可以整周转动

    def classify_four_bar(a, b, c, d):
    """a=AB、b=BC、c=CD、d=AD(机架)。返回判据中间量与机构类型。"""
    lens = {"AB": a, "BC": b, "CD": c, "AD": d}
    order = sorted(lens, key=lambda k: lens[k])
    s, l, p, q = order[0], order[3], order[1], order[2]
    sum_sl = lens[s] + lens[l]
    sum_pq = lens[p] + lens[q]
    ok = sum_sl <= sum_pq
    adj = {"AB": ("AD", "BC"), "BC": ("AB", "CD"),
           "CD": ("BC", "AD"), "AD": ("CD", "AB")}
    if not ok:
        kind = "双摇杆（无整转副）"
    elif s == "AD":
        kind = "双曲柄（机架本身最短）"
    elif "AD" in adj[s]:
        kind = "曲柄摇杆（机架与最短杆相邻）"
    else:
        kind = "双摇杆（机架是最短杆的对面杆）"
    return s, l, sum_sl, sum_pq, ok, kind

    3.7 判据为什么是「和」而不是别的 —— 逐步推导¶

    推导的目标：说明「最短杆能整周转动」到底要求什么， 以及为什么最后会归结成一条两边之和的比较。

    第 1 步：把问题说成一个「三角形存在性」问题。

    设最短杆是 \(AB = a\)，它的相邻杆 \(AD = d\) 是机架，\(BC = b\) 是连杆，\(CD = c\)。 （这里用 \(a\) 代替判据里的 \(s\)，是为了和 2.5 节的代号一致。）

    \(AB\) 能整周转动的意思是：曲柄角 \(\theta\) 从 0° 涨到 360° 的过程中， B 点能走完整个圆，同时连杆 \(BC\) 与摇杆 \(CD\) 都装得上。

    B 点一旦确定，C 点就要由「到 B 的距离是 \(b\)、到 D 的距离是 \(c\)」这两个条件定出来。 这正是一个三角形的存在性问题：三角形 BCD 的三边是 \(b\)、\(c\)、\(|BD|\)。

    第 2 步：写上三角形存在条件。

    三角形三边满足「任意两边之和大于第三边、两边之差小于第三边」，即

    \[|b - c| \le |BD| \le b + c\]

    第 3 步：算清 \(|BD|\) 能取哪些值。 B 点在以 A 为圆心、半径 \(a\) 的圆上跑，D 点固定在离 A 为 \(d\) 的地方。 由三角不等式（或者说「两点距离介于和与差之间」），\(|BD|\) 的取值范围是

    \[d - a \le |BD| \le d + a\]

    第 4 步：把两个条件拼起来。 要求对任意 \(\theta\) 都能装配上，就必须让 \([\,d-a,\ d+a\,]\) 整个落在 \([\,|b-c|,\ b+c\,]\) 里面。于是得到两个不等式：

    \[d + a \le b + c \qquad\text{（上界）}\]
    \[d - a \ge |b - c| \qquad\text{（下界）}\]

    第 5 步：处理下界的绝对值。 \(d - a \ge |b-c|\) 等价于两条同时成立：

    \[d - a \ge b - c \;\Longrightarrow\; a + c \le b + d\]
    \[d - a \ge c - b \;\Longrightarrow\; a + b \le c + d\]

    （另一边的 \(a - d \ge |b-c|\) 不可能，因为 \(a\) 是最短杆，\(a \le d\)。）

    第 6 步：把三条不等式摆在一起，找出共同点。

    来源 不等式
    上界 \(d + a \le b + c\) \(a + d \le b + c\)
    下界第一支 \(a + c \le b + d\)
    下界第二支 \(a + b \le c + d\)

    三条不等式的左边都含 \(a\)（最短杆），右边都是另外两根杆之和。 把它们写成「最短杆 + 某一根 ≤ 其余两根之和」的统一形式， 最强（最难满足）的那一条就是 \(a + d \le b + c\)， 其中 \(d\) 是除 \(a\) 之外最长的杆。令 \(s = a\)、\(l = d\)、另两根为 \(p\)、\(q\)，就得到

    \[\boxed{s + l \le p + q}\]

    这就是格拉斯霍夫判据

    第 7 步：反过来看，判据里的最短杆一定要做连架杆吗？

    不一定 —— 判据本身只描述了四个长度之间的一个不等式关系，没说哪根杆在哪。 但只要先认定一根最短杆，上面的推导就说明了： 以最短杆的相邻杆为机架时，最短杆能整周转动 ⟺ 判据成立

    判据的形式是「和」而不是「差」或者「乘积」， 根本原因是它来自三角形不等式 —— 而三角形不等式说的就是「两边之和大于第三边」。 所以判据的物理含义可以一句话概括：

    一句话记住判据的来源

    杆长条件其实就是「最短杆 + 最长杆」与「另外两根之和」比大小 之所以是「和」比「和」，是因为它由三角形不等式推出来的 —— 上下界两边一起卡，最后只剩这一条最强的不等式

    补充说明：判据的完整证明要按四种长度排列情形分别讨论， 上面推的是最基本的一种（最短杆做连架杆）

    把 2.5 与 3.6 两节的结论合起来看，得到一条后面反复要用的判据： 位置的求法只有两种 —— 两圆交点法（求交点坐标）和余弦定理法（只算边长与夹角）。 两条完全独立的路径给出同一个答案，就说明公式没有推错。

    顺手做一个手算核对（这也是考试里最常见的题型）。 取 \(a = 40\)、\(b = 120\)、\(c = 90\)、\(d = 140\)（单位 mm），\(\theta = 30°\)：

    第 1 步：求 B 点坐标。

    \[B = (40\cos 30°,\ 40\sin 30°) = (34.641,\ 20.000)\]

    第 2 步：求 \(|BD|\)。 D 固定在 \((140,\ 0)\)：

    \[|BD| = \sqrt{(140 - 34.641)^2 + (0 - 20.000)^2} = \sqrt{105.359^2 + 20^2} = \sqrt{11100.5 + 400} \approx 107.240\]

    第 3 步：在三角形 BCD 里求 \(\angle BCD\)。 三边已知，用余弦定理：

    \[\cos\angle BCD = \frac{b^2 + c^2 - |BD|^2}{2bc} = \frac{14400 + 8100 - 11500.4}{21600} = \frac{10999.6}{21600} \approx 0.50924\]
    \[\angle BCD = \arccos 0.50924 \approx 59.39°\]

    第 4 步：与 3.6 节的输出对照 —— 那里两条独立路径给出 \(59.387087°\)， 手算到小数点后两位也是 \(59.39°\)，完全对得上

    只要三边已知，一个三角形的角就能用余弦定理直接算出来， 根本不需要去求交点坐标。后面算传动角、算极位夹角， 用的全都是这一条 —— 「能算边长就别算坐标」是这一章最省时间的做法

    4.3 滑块位移公式的推导（对心，\(e = 0\)）「逐步不跳步」¶

    先定义符号（单位统一）：

    符号 含义 取值范围
    \(r\) 曲柄长度（\(AB\)） \(r \gt 0\)
    \(l\) 连杆长度（\(BC\)） \(l \gt r\)（否则机构不能整周转动）

    \(s\) 滑块位移：滑块销心 C 到原点 A 的距离 \(l - r \le s \le l + r\)

    推导思路就一句话：把两段长度分别投影到导轨方向上，再相加。 下面把每一步都写出来。

    第 1 步：写出 B 点的坐标（曲柄的投影）。

    设 A 为原点、导轨沿 \(x\) 轴正方向。曲柄长 \(r\)、转角 \(\theta\)，所以

    \[B = (r\cos\theta,\ r\sin\theta)\]

    这一步的几何含义：\(r\cos\theta\) 是曲柄沿导轨方向的投影， \(r\sin\theta\) 是曲柄垂直于导轨方向的投影

    第 2 步：写出 C 点的位置约束。

    滑块销心 C 在导轨上（对心时导轨就是 \(x\) 轴），所以 \(C = (s,\ 0)\)； 连杆长 \(l\) 固定，所以 B、C 两点的距离必须等于 \(l\)：

    \[(s - r\cos\theta)^2 + (0 - r\sin\theta)^2 = l^2\]

    第 3 步：解出 \(s\)。

    把第二项写成 \(r^2\sin^2\theta\)：

    \[(s - r\cos\theta)^2 + r^2\sin^2\theta = l^2\]

    把 \(r^2\sin^2\theta\) 移到右边：

    \[(s - r\cos\theta)^2 = l^2 - r^2\sin^2\theta\]

    第 4 步：开平方，并说明为什么根号里一定为正。

    因为 \(l \gt r\)，而 \(|\sin\theta| \le 1\)，所以对任何 \(\theta\) 都有

    \[l^2 - r^2\sin^2\theta \ge l^2 - r^2 \gt 0\]

    根号里恒为正，说明对心曲柄滑块机构里曲柄一定能整周转动 ✓ （注意：条件就是 \(l \gt r\) —— 连杆必须比曲柄长。）

    开平方得

    \[s - r\cos\theta = \pm\sqrt{l^2 - r^2\sin^2\theta}\]

    取哪个符号：C 在 B 的前方（远离曲柄那一侧）是正常装配， 所以取正号

    第 5 步：得到最终公式。

    \[s = r\cos\theta + \sqrt{l^2 - r^2\sin^2\theta}\]

    前一项是曲柄沿导轨的投影，后一项是连杆沿导轨的投影， 两者相加就是滑块销心到 A 的距离

    第 6 步：验算两个极端位置。

    \(\theta = 0°\) 时 \(\cos 0° = 1\)、\(\sin 0° = 0\)，代入得

    \[s = r \times 1 + \sqrt{l^2 - 0} = r + l\]

    \(\theta = 180°\) 时 \(\cos 180° = -1\)、\(\sin 180° = 0\)，代入得

    \[s = -r + \sqrt{l^2 - 0} = l - r\]

    行程 \(H\)：最远减最近

    \[H = (r + l) - (l - r) = 2r\]

    对心曲柄滑块的行程恰好等于曲柄长度的两倍 —— 这是一条非常常用的经验结论

    4.4 推广到偏心（\(e \ne 0\)）¶

    偏心时导轨中线不再过 A，而是距 A 垂直距离 \(e\)。 把导轨中线取在 \(y = e\)，则滑块销心 \(C = (s,\ e)\)。

    B 的坐标不变（曲柄还是绕 A 转）：\(B = (r\cos\theta,\ r\sin\theta)\)。

    第 1 步：写距离条件。 B、C 距离为 \(l\)：

    \[(s - r\cos\theta)^2 + (e - r\sin\theta)^2 = l^2\]

    第 2 步：解出 \(s\)。 移项：

    \[(s - r\cos\theta)^2 = l^2 - (e - r\sin\theta)^2 = l^2 - (r\sin\theta - e)^2\]

    第 3 步：开平方取正号。

    \[s = r\cos\theta + \sqrt{l^2 - (r\sin\theta - e)^2}\]

    这就是偏心曲柄滑块的位移公式

    图上把这个过程画出来了：曲柄转一圈、连杆跟着摆，滑块就在导轨上来回走一趟 —— 这张图正是上面那条公式的几何含义

    把 \(e = 0\) 代进去，它就退化回对心公式 —— 说明这个式子是更一般的写法

    第 4 步：偏心时曲柄还能整周转动吗？

    要求根号里对一切 \(\theta\) 都非负。\(r\sin\theta\) 在 \([-r,\ r]\) 之间变化， 所以 \(r\sin\theta - e\) 在 \([-r - e,\ r - e]\) 之间变化，它的绝对值最大是 \(r + e\)。 因此偏心曲柄滑块能整周转动的条件是

    \[r + e \le l\]

    曲柄长度加上偏心距不能超过连杆长度 ✓ 偏心距越大，对连杆长度的要求越严

    4.5 手算对照：给定转角，一步步算出滑块位置¶

    手算才是考试里真正要用的方式。 取 \(r = 50\) mm、\(l = 150\) mm， 把 \(\theta\) 取成 \(0°\)、\(90°\)、\(180°\) 三个位置算到底：

    \(\theta = 0°\)：\(\cos 0° = 1\)、\(\sin 0° = 0\)，代入公式

    \[s = 50 \times 1 + \sqrt{150^2 - 50^2 \times 0} = 50 + 150 = 200\ \text{mm}\]

    \(\theta = 90°\)：\(\cos 90° = 0\)、\(\sin 90° = 1\)，先算根号里

    \[150^2 - 50^2 \times 1 = 22500 - 2500 = 20000\]
    \[\sqrt{20000} \approx 141.421\ \text{mm}\]

    所以

    \[s = 50 \times 0 + 141.421 = 141.421\ \text{mm}\]

    \(\theta = 180°\)：\(\cos 180° = -1\)、\(\sin 180° = 0\)，代入得

    \[s = -50 + 150 = 100\ \text{mm}\]

    三个位置合起来看：\(s\) 从 100 变到 200，行程

    \[H = 200 - 100 = 100\ \text{mm} = 2r\]

    4.7 偏心距的工程意义：一个参数调节急回¶

    偏心距为什么要存在：它制造不对称。把 \(e\) 从 0 加到 30， 行程 \(H\) 与两个极位之间的夹角 \(\theta_0\) 会同时变化， 再由 \(\theta_0\) 得到行程速比系数 \(K\)（\(K\) 的确切定义在第五节）：

    \(e\) 行程 \(H\) / mm 极位夹角 \(\theta_0\) \(K\) 结论
    0.0 100.0000 0.0000° 1.0000 完全对称，没有急回
    10.0 100.2511 2.8730° 1.0324 开始有急回，但很弱
    20.0 101.0179 5.7980° 1.0666 急回变明显
    30.0 102.3433 8.8310° 1.1032 急回更明显，但行程偏离 \(2r\) 也更多 ⚠

    这张表给出了一个重要的设计权衡： 偏心距越大，急回特性越强，但行程偏离 \(2r\) 也越多、滑块的侧向力也越大 所以偏心距不是「越大越好」，而是按需要的 \(K\) 值反算出来的一个具体尺寸

    回到本节的起点：曲柄滑块机构虽然只有 4 个构件，但通过偏心距这一个参数， 就能在「对称、无急回」与「不对称、有急回」之间连续调节

    五、急回特性与行程速比系数¶

    5.1 现象：工作行程慢、返回行程快¶

    很多机器要求「去的时候慢，回来的时候快」。 例如牛头刨床： 刀具切削时走得很慢（要保证加工质量与刀具寿命）， 空回时快速退回（这段不切削，越快越省时间）

    把这件事抽象到机构上：从动件有两个极限位置， 从动件从一个极限走到另一个极限，叫一个行程； 再走回来，是另一个行程。

    术语 含义
    极位 从动件能到达的极限位置（例如摇杆摆到最左、最右）
    工作行程 从动件从一个极位走到另一个极位的过程
    返回行程（空回） 从动件从另一个极位走回来的过程
    急回特性 返回行程比工作行程快这一现象 ✓

    5.2 极位出现在哪里 —— 曲柄与连杆共线¶

    这是本节的关键结论：对曲柄摇杆机构，摇杆摆到极限位置时， 曲柄与连杆正好连成一条直线（共线）。

    为什么：摇杆 CD 的位置由 \(|AC|\) 决定（\(A\) 是曲柄固定铰、\(C\) 是摇杆与连杆的铰点）。 \(|AC|\) 能取到多大，取决于曲柄与连杆怎么折：

    • \(|AC|\) 最大 → 曲柄与连杆拉直（向外伸长），此时 \(|AC| = a + b\)
    • \(|AC|\) 最小 → 曲柄与连杆重叠（折回自己身上），此时 \(|AC| = |b - a|\)

    摇杆摆到极限，就是要 \(|AC|\) 取到最大或最小，所以曲柄与连杆必然共线

    5.3 极位夹角与行程速比系数 \(K\) 的定义¶

    极位夹角 \(\theta_0\) 的定义：摇杆处于两个极位时， 曲柄所对应的两个位置之间所夹的锐角。

    符号与范围：\(0° \le \theta_0 \lt 180°\)。 \(\theta_0 = 0\) 表示两个极位曲柄正好相隔 180°，机构完全对称，没有急回

    行程速比系数 \(K\) 的定义：工作行程时间与返回行程时间之比的反面， 也就是「快的那个行程比慢的那个行程快多少倍」。

    因为曲柄匀速转动，时间可以换成曲柄转过的角度： 转过角度大 → 花的时间多 → 走得慢。所以

    \[K = \frac{\text{慢行程的曲柄转角}}{\text{快行程的曲柄转角}} = \frac{180° + \theta_0}{180° - \theta_0}\]

    怎么读这个公式：

    • 分子 \(180° + \theta_0\) 是慢行程（从动件走得慢）对应的曲柄转角， 它比半圈多一点，所以花的时间长
    • 分母 \(180° - \theta_0\) 是快行程对应的曲柄转角，比半圈少一点， 所以花的时间短
    • \(\theta_0 = 0\) 时 \(K = 180/180 = 1\)，两个行程一样快，没有急回
    • \(\theta_0\) 越大，分子越大、分母越小，\(K\) 越大，急回越明显

    反解公式（设计时更常用）：从 \(K\) 反算需要的 \(\theta_0\)。

    \[K(180° - \theta_0) = 180° + \theta_0\]
    \[180°K - K\theta_0 = 180° + \theta_0\]
    \[180°K - 180° = \theta_0 + K\theta_0 = \theta_0(1 + K)\]
    \[\theta_0 = 180° \cdot \frac{K - 1}{K + 1}\]

    给定要求的 \(K\)，极位夹角就唯一确定了 ✓ 例如要求 \(K = 2\)，则 \(\theta_0 = 180° \times \frac{1}{3} = 60°\) —— 这是牛头刨床一类机器的常见取值。

    急回特性不是「免费」的

    \(K\) 越大，从动件的加速度在换向处越大，惯性力越难平衡：

    \(K\) 范围 典型场合 代价
    \(1.0 \sim 1.1\) 一般对称机构，不需要急回 无
    \(1.1 \sim 1.5\) 常见刨削、送料机构 换向冲击可接受 ✓
    \(1.5 \sim 2.0\) 牛头刨床、插床 换向冲击明显，需要加强结构 ⚠
    \(\gt 2.0\) 很少用 冲击过大，寿命与噪声都成问题 ⚠

    所以设计时一般把 \(K\) 控制在 1.5～2 以内， 并且把急回特性和传动角要求放在一起权衡 —— 这两条要求常常是互相冲突的（下一节会看到具体的数）

    5.4 手算：从几何尺寸算 \(\theta_0\) 与 \(K\)¶

    这一段做两件事：由四杆长度手算出 \(\theta_0\) 与 \(K\)； 以及验证「\(K\) 与 \(\theta_0\) 的互换公式」在两个方向上都能对上

    第 1 步：确定两个极位对应的 \(|AC|\)。 由 5.2 节的结论，极位出现在曲柄与连杆共线处，此时 \(A\)、\(B\)、\(C\) 三点共线，所以 \(|AC|\) 只可能取两个值：

    \[|AC|_1 = a + b \quad(\text{拉直}), \qquad |AC|_2 = |b - a| \quad(\text{重叠})\]

    第 2 步：在三角形 \(ACD\) 里用余弦定理求曲柄角。 三角形 \(ACD\) 的三边是 \(|AC|\)、\(c = CD\)、\(d = AD\)， 要求的是边 \(|AC|\) 与 \(d\) 的夹角 \(\beta\)（也就是曲柄角）：

    \[\cos\beta = \frac{d^2 + |AC|^2 - c^2}{2\,d\,|AC|}\]

    第 3 步：代入数。 取 \(a = 40\)、\(b = 120\)、\(c = 90\)、\(d = 100\)， 两个极位是 \(|AC|_1 = 160\) 与 \(|AC|_2 = 80\)。

    先算 \(|AC| = 160\) 那个极位， 分子是 \(100^2 + 160^2 - 90^2 = 10000 + 25600 - 8100 = 27500\)， 分母是 \(2 \times 100 \times 160 = 32000\)：

    \[\cos\beta_1 = \frac{27500}{32000} = 0.859375 \;\Longrightarrow\; \beta_1 = 30.753520°\]

    再算 \(|AC| = 80\) 那个极位， 分子是 \(100^2 + 80^2 - 90^2 = 10000 + 6400 - 8100 = 8300\)， 分母是 \(2 \times 100 \times 80 = 16000\)：

    \[\cos\beta_2 = \frac{8300}{16000} = 0.518750 \;\Longrightarrow\; \beta_2 = 58.751559°\]

    第 4 步：两个曲柄角之差就是极位夹角。

    \[\theta_0 = |\beta_2 - \beta_1| = |58.751559° - 30.753520°| = 27.998039° \approx 28.00°\]

    第 5 步：由定义式算 \(K\)。 代入 5.3 节的定义式：

    \[K = \frac{180° + \theta_0}{180° - \theta_0} = \frac{180 + 27.998039}{180 - 27.998039} = \frac{207.998039}{152.001961} = 1.368390 \approx 1.3684\]

    这就是「返回行程比工作行程快约 1.37 倍」的来历

    第 6 步：反向核对，确认两个公式互为逆运算。 把 \(K = 1.368390\) 代进反解式：

    \[\theta_0 = 180° \times \frac{K - 1}{K + 1} = 180° \times \frac{0.368390}{2.368390} = 180° \times 0.155545 = 27.998039°\]

    结果与第 4 步的几何值完全一致 —— 两个公式确实是互逆的

    这张表怎么用：要求 \(K = 1.5\)，就把极位夹角设计成 36°； 要求 \(K = 2\)，就设计成 60° 注意表的走向：\(K\) 越大急回越明显，\(K\) 从 1.5 涨到 3.0， \(\theta_0\) 要从 36° 一路加到 90° —— 而极位夹角越大， 机构占用的空间和不对称性也越强

    六、压力角与传动角¶

    6.1 压力角 \(\alpha\) 的定义¶

    压力角（Pressure angle）\(\alpha\)：在从动件上，驱动力 \(F\) 的方向 与受力点速度 \(v\) 的方向之间的夹角。

    符号与范围：\(0° \le \alpha \le 90°\)。

    为什么要关心这个角：不是所有的驱动力都做了有用的功。 把 \(F\) 沿两个方向分解：

    • 沿速度方向的分量 \(F_t = F\cos\alpha\) → 这个分量推动从动件运动，是有用的 有效分力
    • 垂直于速度方向的分量 \(F_n = F\sin\alpha\) → 这个分量不推动运动， 只把从动件往轴承上压，是有害的 法向分力

    所以 \(\alpha\) 越小越好 —— \(\cos\alpha\) 越大，同样的驱动力能产生更大的有效分力

    6.2 传动角 \(\gamma\) 的定义¶

    传动角（Transmission angle）\(\gamma\)：压力角的余角

    \[\gamma = 90° - \alpha\]

    在四杆机构里，传动角就是连杆与从动件（摇杆）之间的夹角 这一条要记住，因为设计时直接量的是这个角，比去画力的方向方便得多。

    符号与范围：\(0° \le \gamma \le 90°\)（取锐角那一侧）。

    传动角的判据方向不能搞反

    越大越好还是越小越好 为什么
    压力角 \(\alpha\) 越小越好 ✓ \(\alpha\) 小时有效分力 \(F\cos\alpha\) 大 ⚠ 反了
    传动角 \(\gamma\) 越大越好 ✓ \(\gamma = 90° - \alpha\)，\(\gamma\) 大等价于 \(\alpha\) 小

    记住一条就够：有效分力是 \(F\cos\alpha\)，所以 \(\alpha\) 越小越省力、\(\gamma\) 越大越省力

    6.3 先把「省力」算成一个具体的数¶

    两个极端情形：\(\gamma = 90°\)（\(\alpha = 0°\)）时驱动力一点不浪费； \(\gamma = 0°\)（\(\alpha = 90°\)）时有效分力为零，驱动力再大也推不动 —— 这就是死点。

    但只写出「\(\alpha\) 越小越好」还不够 —— 下面必须把省力的程度算成一个具体的数。

    第 1 步：定义有效分力。 设驱动力大小为 \(F\)、压力角为 \(\alpha\)。 把 \(F\) 沿两个方向正交分解，其中沿从动件速度方向的那一份叫有效分力：

    \[F_t = F\cos\alpha\]

    第 2 步：把「省力」写成比例。 有效分力占全部驱动力的比例就是

    \[\eta = \frac{F_t}{F} = \cos\alpha = \cos(90° - \gamma) = \sin\gamma\]

    第 3 步：代入几个具体的角算一遍。 这一步不能省，因为它能把「越大越好」变成可以比较的数：

    传动角 \(\gamma\) 压力角 \(\alpha\) 有效分力 \(F_t\) 占驱动力的比例 实际含义
    \(90°\) \(0°\) \(1.000\,F\) \(100.0\%\) 理想状态，推力一点不浪费 ✓
    \(60°\) \(30°\) \(0.866\,F\) \(86.6\%\) 很轻快，浪费约七分之一
    \(50°\) \(40°\) \(0.766\,F\) \(76.6\%\) 浪费将近四分之一
    \(40°\) \(50°\) \(0.643\,F\) \(64.3\%\) 工程底线，浪费超过三分之一 ⚠
    \(30°\) \(60°\) \(0.500\,F\) \(50.0\%\) 一半推力白费，通常不可接受 ✗
    \(10°\) \(80°\) \(0.174\,F\) \(17.4\%\) 几乎推不动 ✗
    \(0°\) \(90°\) \(0.000\,F\) \(0.0\%\) 死点，无论 \(F\) 多大都没用 ✗

    第 4 步：看「差 20° 到底差多少」。 \(\gamma = 40°\) 到 \(\gamma = 60°\)，角度只差 20°， 但有效分力从 \(0.643F\) 涨到 \(0.866F\)，相对提升

    \[\frac{0.866 - 0.643}{0.643} \times 100\% \approx 34.7\%\]

    同样的电机、同样的负载， 只把传动角从 40° 提到 60°，推力就宽裕了三成多。 反过来说，\(\gamma\) 掉到 40° 附近时， 为了让机构动起来，电机扭矩必须额外放大 \(\frac{1}{0.643} \approx 1.56\) 倍 ⚠

    第 5 步：求「传动角为多少时彻底推不动」。 由 \(\eta = \sin\gamma\)，要让 \(\eta = 0\) 只能是

    \[\sin\gamma = 0 \;\Longrightarrow\; \gamma = 0°\]

    它就是死点的判据 —— 见第七节

    6.4 两个极端情形与传动角的变化规律¶

    情形 \(\alpha\) \(\gamma\) 有效分力 发生了什么
    最理想 \(0°\) \(90°\) \(1.000\,F\) 驱动力全部沿速度方向，一点不浪费 ✓
    较常见 \(30°\) \(60°\) \(0.866\,F\) 日常设计的舒服区间 ✓
    下限 \(50°\) \(40°\) \(0.643\,F\) 再小就不经济了，这是工程底线 ⚠
    最糟糕 \(90°\) \(0°\) \(0.000\,F\) 有效分力为零，驱动力再大也推不动 → 死点 ⚠

    从「最理想」到「最糟糕」是一条连续的变化过程。 上表已经把这条曲线的关键点列全了，下面只需要补一句几何上的直觉：

    传动角为什么会在一个循环里变来变去：四杆机构里 \(\gamma\) 就是连杆与摇杆之间的夹角， 而这个夹角完全由三角形 BCD 的形状决定； B 点绕着 A 转一圈，\(|BD|\) 就一直在变， 三角形时而「鼓」时而「扁」，\(\gamma\) 自然也跟着变 要判断一个设计好不好，就看它最「扁」的那一刻。

    6.5 为什么设计要限制最小传动角¶

    工程上不能只看平均值，必须看最坏情况。 传动角在一圈里是变化的， 决定机构能不能可靠工作的，是 \(\gamma\) 的最小值。

    应用类型 常用 \(\gamma_{\min}\) 下限 理由
    一般动力传动（大功率、重载） \(\gamma_{\min} \ge 40°\) 传力要可靠 ✓
    高速轻载 \(\gamma_{\min} \ge 50°\) 高速时冲击更敏感 ⚠
    低速轻载、仪器仪表 可放宽到 \(30°\) 左右 载荷小，传力不是主要矛盾

    为什么定 40°：\(\gamma = 40°\) 对应 \(\alpha = 50°\)， 此时有效分力 \(F\cos 50° \approx 0.64F\) —— 大约三分之一的驱动力被浪费掉。 再小下去，浪费的比例会迅速上升（\(\gamma = 30°\) 时只剩 \(0.5F\)）

    下面把「传动角」和「急回」放在同一张表里看，会看到一个真实的权衡。 取曲柄摇杆机构 \(a = 40\)（曲柄）、\(b = 120\)（连杆）、\(c = 90\)（摇杆）， 只改机架长度 \(d\)，用前面学过的两条公式分别手算 \(\gamma_{\min}\) 与 \(K\)：

    机架 \(d\) 极位夹角 \(\theta_0\) \(K\) \(\gamma_{\min}\) 结论
    100 28.00° 1.3684 28.96° 急回明显，但传动角不合格 ✗
    110 21.01° 1.2644 35.43° 急回中等，传动角仍不足 ✗
    120 14.76° 1.1787 41.81° 刚刚越过 40° 这条线 ✓
    130 8.83° 1.1032 48.19° 传动角宽裕，但急回很弱
    140 2.86° 1.0323 54.64° 传动角最好，几乎没有急回

    这张表怎么手算出来的：以 \(d = 140\) 这一行为例。 极位出现在曲柄与连杆共线处，此时 \(AC\) 取最大 \(a + b = 160\) 或最小 \(|b - a| = 80\)。 先在三角形 ACD 里用余弦定理求曲柄角，再在最「扁」的位形上量传动角：

    • 曲柄与机架重合（\(\theta = 0°\)）时 \(|BD| = d - a = 100\) 取到最小值， 三角形 BCD 最扁，所以 \(\gamma\) 在这里最小；
    • 把三边 \(|BD| = 100\)、\(b = 120\)、\(c = 90\) 代进余弦定理，
    \[\cos\gamma = \frac{120^2 + 90^2 - 100^2}{2 \times 120 \times 90} = \frac{14400 + 8100 - 10000}{21600} = \frac{12500}{21600} \approx 0.5787\]
    \[\gamma_{\min} = \arccos 0.5787 \approx 54.64°\]

    正好和上表对得上 ✓ 其它各行用同样的两步就能算出来。

    这张表告诉我们两件必须同时记住的事：

    1. 急回特性和传动角是互相冲突的 \(d\) 从 140 减到 100，\(K\) 从 1.03 涨到 1.37（急回变好）， 但 \(\gamma_{\min}\) 从 54.64° 掉到 28.96°（受力变差）。 要急回就得牺牲传动角
    2. 两条判据的「合格线」是不同性质的： \(\gamma_{\min} \ge 40°\) 是必须满足的可靠工作底线（不满足会卡死或效率极低）； \(K\) 是按工艺需要选的性能指标（不同机器要求不同）。 所以设计的一般顺序是：先满足 \(\gamma_{\min} \ge 40°\)，再在此前提下尽量争取大的 \(K\)

    这就是为什么 \(d = 120\) 那一行最有参考价值： 它的 \(\gamma_{\min} = 41.81°\) 刚好过线，\(K = 1.1787\) 也还有一点急回 —— 一个「两条判据都勉强达标」的折中方案

    七、死点位置¶

    7.1 定义¶

    死点位置（Dead point / toggle position）：从动件的传动角为 0 （也就是压力角为 90°）时，机构所处的位置。

    在死点位置会发生什么：传动角 \(\gamma = 0°\) 意味着 有效分力 \(F\cos\alpha = F\cos 90° = 0\) —— 驱动力再大，也不能使从动件运动 → 机构卡住 ✗

    从几何上怎么认出来： 上一节说传动角是「连杆与从动件的夹角」， 所以传动角为 0 就是连杆与从动件连成一条直线。 于是判据变成一句很好用的话：

    从动件的铰链点、连杆的两个铰点三点共线时，就是死点位置

    7.2 一个必须分清的关键点：死点与「有没有曲柄」是两回事¶

    这是本节最容易搞混的地方。死点要看「谁在主动」：

    谁主动 从动件是谁 会不会出现死点
    曲柄主动 摇杆 不会出现死点 ✓（整圈里 \(\gamma \gt 0\)）
    摇杆主动 曲柄 会出现死点 ⚠（曲柄与连杆共线时）

    为什么曲柄主动时不会出现死点：3.3 节已经说明， 只要判据成立，曲柄就能整周转动，\(|BD|\) 始终在 \([|b-c|,\ b+c]\) 内部， 三角形 BCD 永远不会退化成一条线，\(\gamma\) 恒大于 0 ✓ （这正是上一节手算出的 \(\gamma_{\min} = 54.64°\) 而不是 0 的原因）

    为什么摇杆主动时会出现死点：反过来，摇杆摆动到极限位置时， 曲柄与连杆恰好共线 —— 此时以曲柄为从动件看，它的传动角就是 0

    import math

def four_bar_position(a, b, c, d, theta_deg, branch=+1):
    t = math.radians(theta_deg)
    Bx, By = a*math.cos(t), a*math.sin(t)
    BD = math.hypot(d - Bx, -By)
    if BD > b + c or BD < abs(b - c):
        return None
    T = (b*b - c*c + BD*BD) / (2*BD)
    h = math.sqrt(max(0.0, b*b - T*T))
    ux, uy = (d - Bx)/BD, -By/BD
    return Bx, By, Bx + T*ux - branch*h*uy, By + T*uy + branch*h*ux, BD

def fold_acute(ang):
    return min(ang, 180.0 - ang)

def both_angles(a, b, c, d, theta_deg, branch=+1):
    """返回 (γ_摇杆, γ_曲柄)：分别以摇杆 CD、曲柄 AB 为从动件时的传动角。"""
    r = four_bar_position(a, b, c, d, theta_deg, branch)
    if r is None:
        return None
    Bx, By, Cx, Cy, _ = r
    v1x, v1y = Bx - Cx, By - Cy
    v2x, v2y = d - Cx, -Cy
    n1, n2 = math.hypot(v1x, v1y), math.hypot(v2x, v2y)
    gC = fold_acute(math.degrees(math.acos(
        max(-1.0, min(1.0, (v1x*v2x + v1y*v2y)/(n1*n2))))))
    w1x, w1y = -Bx, -By
    w2x, w2y = Cx - Bx, Cy - By
    m1, m2 = math.hypot(w1x, w1y), math.hypot(w2x, w2y)
    gB = fold_acute(math.degrees(math.acos(
        max(-1.0, min(1.0, (w1x*w2x + w1y*w2y)/(m1*m2))))))
    return gC, gB

    机构 死点在哪里 说明
    缝纫机踏板机构 踏板踩到上下极限位置 踏板是主动件（人脚驱动），曲柄是从动件 → 会出现死点 ⚠
    飞机起落架 放下到位时三点共线 落架到位瞬间 \(\gamma = 0\)，正好自锁，不用液压长时间承力 ✓
    夹具/夹钳 夹紧到位时 夹紧力再大也退不回去，可靠夹持 ✓
    内燃机 活塞在上、下止点 活塞是主动件吗？不是 —— 靠飞轮惯性越过 ⚠

    缝纫机踏板是最典型的「死点麻烦」： 人脚踩踏板（摇杆）是主动件，通过连杆带动曲柄（大轮）转。 如果踏板正好停在上极限或下极限位置，脚再用力也转不动大轮 —— 实际做法是在大轮上装飞轮，靠它的惯性冲过死点

    7.4 两种态度：要避免的，要利用的¶

    死点不是「缺点」，而是「中性的物理事实」—— 工程师在两种场合对它有完全相反的态度

    场合 怎么做 为什么
    要避免死点 加飞轮，利用惯性冲过死点 ✓ 机构必须连续运转时，不能卡住；飞轮储存的动能帮它越过
    要避免死点（另一种办法） 加装多组机构错开相位 一组在死点时，另一组不在死点，可以互相带动
    要利用死点 起落架自锁、夹具夹紧不松脱 ✓ 死点时机构反向不可驱动 —— 这正是最可靠的自锁

    「要利用死点」这件事值得多想一步： 死点的本质是传动角为 0，正反两个方向都推不动。 所以只要把工作状态设计在死点附近，机构就变成了一把「单向锁」—— 外界的力再大也推不动它，可以省掉一套锁紧装置

    飞轮能帮上忙，但不是万能的

    做法 适用情形 局限
    加飞轮 连续运转、转速较高的机器 低速时不灵（惯性小）；频繁启动停的机器也不适用 ⚠
    错开相位 多缸/多组机构 结构复杂，成本上升
    设计成不经过死点 从动件工作区间避开死点 会限制行程范围 ⚠
    利用自锁 起落架、夹具 只在需要保持位置、不需要反向运动时可用

    选哪种办法，取决于「机器是连续转还是偶尔动」： 连续转 → 用飞轮；偶尔动但要锁住 → 就用死点自锁

    import math

def classify(a, b, c, d):
    """第一、二层：返回 (判据是否成立, 机构类型)。a=AB、b=BC、c=CD、d=AD。"""
    lens = {"AB": a, "BC": b, "CD": c, "AD": d}
    order = sorted(lens, key=lambda k: lens[k])
    s, l, p, q = order[0], order[3], order[1], order[2]
    ok = lens[s] + lens[l] <= lens[p] + lens[q]
    adj = {"AB": ("AD", "BC"), "BC": ("AB", "CD"),
           "CD": ("BC", "AD"), "AD": ("CD", "AB")}
    if not ok:
        return False, "双摇杆（无整转副）"
    if s == "AD":
        return True, "双曲柄"
    if "AD" in adj[s]:
        return True, "曲柄摇杆"
    return True, "双摇杆"

def perf(a, b, c, d):
    """第三层：以曲柄为主动件，算 γ_min 与 K；返回 (γ_min, θ0, K)。"""
    def beta(AC):
        cosv = (d*d + AC*AC - c*c) / (2*d*AC)
        return math.degrees(math.acos(max(-1.0, min(1.0, cosv))))
    theta0 = abs(beta(a + b) - beta(abs(b - a)))
    K = (180.0 + theta0) / (180.0 - theta0)
    gmin = 1e9
    for i in range(1440):
        t = math.radians(i*0.25)
        Bx, By = a*math.cos(t), a*math.sin(t)
        BD = math.hypot(d - Bx, -By)
        if BD > b + c or BD < abs(b - c):
            return None, None, None
        g = math.degrees(math.acos(max(-1.0, min(1.0, (b*b + c*c - BD*BD)/(2*b*c)))))
        gmin = min(gmin, min(g, 180.0 - g))
    return gmin, theta0, K

    例题 1：判断四杆机构的类型¶

    一个铰链四杆机构，四根杆的长度分别是 \(AB = 20\) mm（最短）、\(BC = 70\) mm、\(CD = 60\) mm、\(AD = 75\) mm， 且 \(AD\) 是机架。判断机构类型，并说明 \(AB\) 能不能整周转动。

    思路

    按流程图走。先取最短杆 \(s\) 与最长杆 \(l\)， 把它们之和与中间两根杆之和比较；再判断「最短杆与机架的位置关系」。

    解答

    第 1 步：排出四个长度，找最短杆与最长杆。

    \[20 \lt 60 \lt 70 \lt 75\]

    所以 \(s = 20\)（就是 \(AB\)）、\(l = 75\)（就是 \(AD\)）， 两根中间杆是 \(p = 60\)、\(q = 70\)。

    第 2 步：代入判据。

    \[s + l = 20 + 75 = 95\]
    \[p + q = 60 + 70 = 130\]

    比较：\(95 \le 130\) —— 判据成立 说明机构里存在整转副，最短杆 \(AB\) 的两端都是整转副。

    第 3 步：看机架与最短杆的位置关系。

    最短杆是 \(AB\)，机架是 \(AD\) —— 在四杆闭环 \(A \to B \to C \to D \to A\) 里， \(AB\) 与 \(AD\) 共用铰链 A，所以 \(AD\) 是最短杆的相邻杆

    第 4 步：查表得类型。

    条件 结果
    判据成立 + 固定最短杆的相邻杆 曲柄摇杆机构 ✓

    所以这是一个曲柄摇杆机构：\(AB\) 是曲柄（整周转动），\(CD\) 是摇杆（摆动）。

    第 5 步：用位置条件独立核对「\(AB\) 能整周转」。

    \(AB\) 整周转动要求两圆始终相交，即对一切 \(\theta\) 都有

    \[|b - c| \le |BD| \le b + c\]

    而 \(B\) 点绕 \(A\) 转时 \(|BD|\) 的取值范围是

    \[|d - a| = 75 - 20 = 55 \quad \text{到} \quad d + a = 75 + 20 = 95\]

    \(b + c = 70 + 60 = 130\)，\(|b - c| = 10\)。 因为 \(55 \ge 10\) 且 \(95 \le 130\)，不等式在整个圈上都成立 两条独立路径的结论一致：\(AB\) 能整周转动

    结论：该机构是曲柄摇杆机构，\(AB\) 是曲柄（整周转动）， \(CD\) 是摇杆；连杆是 \(BC\)，机架是 \(AD\)

    例题 2：给定曲柄转角，求连杆与摇杆的方位¶

    四杆机构 \(a = 40\) mm、\(b = 120\) mm、\(c = 90\) mm、\(d = 140\) mm （\(a\) 是曲柄 \(AB\)，\(b\) 是连杆 \(BC\)，\(c\) 是摇杆 \(CD\)，\(d\) 是机架 \(AD\)）。 曲柄转到 \(\theta = 0°\)（\(AB\) 与机架 \(AD\) 重合方向）时， 求 \(C\) 点坐标、摇杆角 \(\varphi\)，以及此时的传动角 \(\gamma\)。

    思路

    按 2.5 节的两圆交点法做，只取「\(C\) 在 \(BD\) 上方」那个分支。 三步：定 B → 算 \(|BD|\) → 在三角形 \(BCD\) 里解 \(C\)。

    解答

    第 1 步：定出 B 点。

    \[B = (a\cos 0°,\ a\sin 0°) = (40 \times 1,\ 40 \times 0) = (40,\ 0)\]

    第 2 步：算 \(|BD|\)。 \(D = (d, 0) = (140, 0)\)，所以

    \[|BD| = \sqrt{(140 - 40)^2 + (0 - 0)^2} = 100\]

    第 3 步：算垂足位置 \(T\) 与高 \(h\)。

    \[T = \frac{b^2 - c^2 + |BD|^2}{2|BD|} = \frac{120^2 - 90^2 + 100^2}{2 \times 100}\]

    分子逐项算：\(120^2 = 14400\)，\(90^2 = 8100\)，\(100^2 = 10000\)，所以

    \[T = \frac{14400 - 8100 + 10000}{200} = \frac{16300}{200} = 81.5\]
    \[h = \sqrt{b^2 - T^2} = \sqrt{14400 - 81.5^2} = \sqrt{14400 - 6642.25} = \sqrt{7757.75}\]
    \[h = 88.0781\]

    第 4 步：写出 C 点坐标。

    单位向量 \(\mathbf{u} = (D - B)/|BD| = (100/100,\ 0) = (1,\ 0)\)， 法向量 \(\mathbf{n} = (-u_y,\ u_x) = (0,\ 1)\)。 取「\(C\) 在 \(BD\) 上方」的分支（\(+h\)）：

    \[C = B + T\mathbf{u} + h\mathbf{n} = (40 + 81.5,\ 0 + 88.0781) = (121.5000,\ 88.0781)\]

    第 5 步：求摇杆角 \(\varphi\)（从 \(D\) 指向 \(C\) 的方位角）。

    \[\varphi = \operatorname{atan2}(C_y - D_y,\ C_x - D_x) = \operatorname{atan2}(88.0781 - 0,\ 121.5 - 140)\]
    \[= \operatorname{atan2}(88.0781,\ -18.5) = 101.8620°\]

    \(\varphi\) 落在第二象限（\(x\) 分量是负的、\(y\) 分量是正的）， 说明摇杆此时朝左上方向伸出

    第 6 步：验算两条边长必须是 \(b\) 与 \(c\)。

    \[|BC| = \sqrt{(40 - 121.5)^2 + (0 - 88.0781)^2} = \sqrt{6642.25 + 7757.75} = \sqrt{14400} = 120.0000\]
    \[|CD| = \sqrt{(140 - 121.5)^2 + (0 - 88.0781)^2} = \sqrt{342.25 + 7757.75} = \sqrt{8100} = 90.0000\]

    分别等于 \(b = 120\)、\(c = 90\) ✓ 位置解正确。

    第 7 步：算传动角 \(\gamma\)。

    \[\overrightarrow{CB} = B - C = (-81.5,\ -88.0781)\]
    \[\overrightarrow{CD} = D - C = (18.5,\ -88.0781)\]

    点积：

    \[\overrightarrow{CB} \cdot \overrightarrow{CD} = (-81.5)(18.5) + (-88.0781)(-88.0781)\]
    \[= -1507.75 + 7757.75 = 6250\]

    代入公式（也可以直接用三角形 BCD 的余弦定理，结果相同）：

    \[\gamma = \arccos\frac{\overrightarrow{CB} \cdot \overrightarrow{CD}}{|CB|\,|CD|} = \arccos\frac{6250}{120 \times 90} = \arccos\frac{6250}{10800}\]
    \[\gamma = \arccos 0.5787037 = 54.6406°\]

    结论：\(C = (121.5000,\ 88.0781)\)，\(\varphi = 101.8620°\)， \(\gamma = 54.6406°\) —— 远大于 \(40°\)，受力合格

    例题 3：曲柄滑块的滑块位移与行程¶

    对心曲柄滑块机构，曲柄长 \(r = 50\) mm，连杆长 \(l = 150\) mm。 求曲柄角 \(\theta = 60°\) 时的滑块位移 \(s\)，以及这个机构的行程 \(H\)。

    思路

    对心时用公式 \(s = r\cos\theta + \sqrt{l^2 - r^2\sin^2\theta}\)。 行程用两个极端位置之差。注意先确认 \(l \gt r\)（本例 \(150 \gt 50\) ✓）。

    解答

    第 1 步：先确认能整周转动。 对心时条件是 \(l \gt r\)：

    \[l = 150 \gt r = 50 \quad ✓\]

    所以曲柄能整周转动，公式适用。

    第 2 步：算 \(r\cos 60°\) 与 \(r\sin 60°\)。

    \[\cos 60° = 0.5, \qquad \sin 60° = \frac{\sqrt{3}}{2} \approx 0.8660254\]
    \[r\cos 60° = 50 \times 0.5 = 25\]
    \[r\sin 60° = 50 \times 0.8660254 = 43.301270\]

    第 3 步：算根号里的量。

    \[l^2 - r^2\sin^2\theta = 150^2 - 43.301270^2 = 22500 - 1875 = 20625\]

    注意 \(1875\) 是怎么来的：\(43.301270^2 = 1875.0000\)， 也可以写成 \(r^2\sin^2 60° = 50^2 \times (3/4) = 2500 \times 0.75 = 1875\)

    第 4 步：开平方。

    \[\sqrt{20625} = 143.6141\]

    第 5 步：相加得 \(s\)。

    \[s = r\cos\theta + \sqrt{l^2 - r^2\sin^2\theta} = 25 + 143.6141 = 168.6141 \text{ mm}\]

    第 6 步：算行程 \(H = 2r\)。

    \[H = 2r = 2 \times 50 = 100 \text{ mm}\]

    再用两个极端位置验算一遍：

    \[\theta = 0°: \quad s = 50 \times 1 + \sqrt{22500 - 0} = 50 + 150 = 200\]
    \[\theta = 180°: \quad s = 50 \times (-1) + \sqrt{22500 - 0} = -50 + 150 = 100\]
    \[H = 200 - 100 = 100 \text{ mm} \quad ✓\]

    两种算法结果一致

    结论：\(\theta = 60°\) 时滑块位移 \(s = 168.6141\) mm； 机构行程 \(H = 100\) mm，恰好等于曲柄长度的两倍

    例题 4：由几何尺寸算行程速比系数 K¶

    四杆机构 \(a = 40\) mm（曲柄）、\(b = 120\) mm（连杆）、 \(c = 90\) mm（摇杆）、\(d = 100\) mm（机架）。 求极位夹角 \(\theta_0\) 与行程速比系数 \(K\)。

    思路

    两个极位都在「曲柄与连杆共线」时出现，此时 \(|AC|\) 分别是 \(a+b\) 与 \(|b-a|\)。 对每个 \(|AC|\)，在三角形 \(ACD\) 里用余弦定理求出对应的曲柄角，两者之差就是 \(\theta_0\)。

    解答

    第 1 步：算两个极位对应的 \(|AC|\)。

    \(|AC|\) 最大（曲柄与连杆拉直）：\(|AC| = a + b = 40 + 120 = 160\)

    \(|AC|\) 最小（曲柄与连杆重叠）：\(|AC| = b - a = 120 - 40 = 80\)

    第 2 步：在三角形 \(ACD\) 里用余弦定理，求第一种情况对应的曲柄角。

    三角形 \(ACD\) 的三边是 \(|AC| = 160\)、\(|CD| = c = 90\)、\(|AD| = d = 100\)。 要求的是 \(\angle CAD\)（记作 \(\beta_1\)），它由余弦定理给出：

    \[\cos\beta_1 = \frac{d^2 + |AC|^2 - c^2}{2\,d\,|AC|} = \frac{100^2 + 160^2 - 90^2}{2 \times 100 \times 160}\]

    分子逐项算：\(100^2 = 10000\)，\(160^2 = 25600\)，\(90^2 = 8100\)，所以

    \[\cos\beta_1 = \frac{10000 + 25600 - 8100}{32000} = \frac{27500}{32000} = 0.859375\]
    \[\beta_1 = \arccos 0.859375 = 30.753520°\]

    第 3 步：同样算第二种情况。

    \[\cos\beta_2 = \frac{100^2 + 80^2 - 90^2}{2 \times 100 \times 80} = \frac{10000 + 6400 - 8100}{16000} = \frac{8300}{16000} = 0.518750\]
    \[\beta_2 = \arccos 0.518750 = 58.751559°\]

    第 4 步：求极位夹角 \(\theta_0\)。

    两个极位在四边形两侧，所以曲柄角之差要加 \(180°\) 之后再取锐角， 等效成直接取两个 \(\beta\) 之差：

    \[\theta_0 = |\beta_2 - \beta_1| = |58.751559° - 30.753520°| = 27.998039° \approx 28.00°\]

    第 5 步：代入 \(K\) 的定义式。

    \[K = \frac{180° + \theta_0}{180° - \theta_0} = \frac{180 + 27.998039}{180 - 27.998039} = \frac{207.998039}{152.001961}\]
    \[K = 1.368390 \approx 1.3684\]

    第 6 步：说明 \(K\) 的物理意义。

    行程 曲柄转角 相对快慢
    工作行程（慢） \(208.00°\) 慢 ✓
    返回行程（快） \(152.00°\) 快 ✓
    比值 \(K\) \(208.00 \div 152.00\) \(1.3684\) ✓

    曲柄匀速转，所以转角大 = 耗时长 = 慢。 返回行程只用了约 152° 的转角，比工作行程的 208° 少 56°， 所以空回时比工作时快 \(1.368\) 倍

    结论：\(\theta_0 = 28.00°\)，\(K = 1.3684\)， 机构有明显的急回特性 但要注意：本页第六节那张表显示，这个尺寸的 \(\gamma_{\min}\) 只有 \(28.96°\)， 低于 \(40°\) 的底线 —— 所以这台机器虽然急回好，受力却不可靠

    Q1 四杆机构 \(a = 30\) mm、\(b = 100\) mm、\(c = 70\) mm、\(d = 80\) mm， \(AD\) 是机架。它是哪种机构？\(AB\) 能整周转动吗？ （提示：先算 \(s+l\) 与 \(p+q\)。）

    提示

    四根杆排序为 \(30 \lt 70 \lt 80 \lt 100\)。 先比较 \(s + l\) 与两根中间杆之和，再看最短杆与机架 AD 的位置关系。

    解答

    第 1 步：排序。

    \[30 \lt 70 \lt 80 \lt 100\]

    \(s = 30\)（即 \(AB\)）、\(l = 100\)（即 \(BC\)）、\(p = 70\)、\(q = 80\)。

    第 2 步：代判据。

    \[s + l = 30 + 100 = 130, \qquad p + q = 70 + 80 = 150\]

    \(130 \le 150\) —— 判据成立 ✓ 存在整转副。

    第 3 步：看机架位置。 最短杆是 \(AB\)，机架是 \(AD\)，两者共用铰链 \(A\)， 所以 \(AD\) 是最短杆的相邻杆 → 曲柄摇杆机构

    第 4 步：核对 \(AB\) 能整周转。

    \[|d - a| = 80 - 30 = 50, \qquad d + a = 80 + 30 = 110\]
    \[|b - c| = 100 - 70 = 30, \qquad b + c = 100 + 70 = 170\]

    \(50 \ge 30\) 且 \(110 \le 170\) ✓ 对一切曲柄角两圆都相交， \(AB\) 能整周转动

    第 5 步（顺带算一下性能）。

    \[\gamma_{\min} = 27.66° \quad (\text{出现在} |BD| = 50 \text{时})\]

    \(27.66° \lt 40°\) —— 传动角不合格 所以这台机构的类型没问题，但传力不可靠，实际设计中要调整尺寸

    Q2 对心曲柄滑块机构，\(r = 40\) mm、\(l = 120\) mm。 求 \(\theta = 90°\) 时的滑块位移，并说明这个机构的行程是多少。

    提示

    \(\cos 90° = 0\)、\(\sin 90° = 1\)，代入会简化很多。 行程用 \(H = 2r\)，但要用两个极端位置验算一遍。

    解答

    第 1 步：确认能整周转。 \(l = 120 \gt r = 40\)

    第 2 步：代入公式。

    \[s = r\cos\theta + \sqrt{l^2 - r^2\sin^2\theta}\]

    \(\theta = 90°\) 时 \(\cos 90° = 0\)、\(\sin 90° = 1\)，所以

    \[s = 40 \times 0 + \sqrt{120^2 - 40^2 \times 1} = 0 + \sqrt{14400 - 1600} = \sqrt{12800}\]
    \[s = 113.1371 \text{ mm}\]

    第 3 步：算行程。

    \[H = 2r = 2 \times 40 = 80 \text{ mm}\]

    第 4 步：用两个极端位置验算。

    \[\theta = 0°: \quad s = 40 + 120 = 160\]
    \[\theta = 180°: \quad s = -40 + 120 = 80\]
    \[H = 160 - 80 = 80 \text{ mm} \quad ✓\]

    第 5 步：一个值得注意的观察。

    \(\theta = 90°\) 时 \(s = 113.1371\)，它不是两个极端位置的中间值：

    \[\frac{160 + 80}{2} = 120 \ne 113.1371\]

    所以滑块的位移曲线不是关于 \(\theta\) 对称的正弦曲线， 而是 «快出慢回» 或 «慢出快回» 非线性变化 这也是曲柄滑块机构运动分析必须用解析公式而不能简单用正弦代替的原因 ✓

    结论：\(\theta = 90°\) 时 \(s = 113.1371\) mm；行程 \(H = 80\) mm

    Q3 为什么说「平面连杆机构只能近似实现给定的运动规律」， 而凸轮机构能精确实现？这个差别来自哪一点？

    提示

    想两件事：连杆机构的输出运动是由什么决定的？ 凸轮的输出运动又是由什么决定的？两者可控的自由度不同。

    解答

    答：差别来自「可调的参数个数」不同。

    连杆机构 凸轮机构
    输出由什么决定 杆的长度（4 杆只有 4 个尺寸可调） 凸轮的轮廓形状（每一点都能独立指定）
    可调参数个数 有限（约 3 个独立长度 + 装配方案） 连续无穷多（轮廓上每一个角度都能定一个位移）
    输出运动规律 只能是由杆长决定的有限几种 ⚠ 任意指定 ✓

    关键在这句话：凸轮的轮廓每一个转角位置都能对应一个你想要的位移， 所以能精确实现任意规律； 而连杆机构的杆长一旦定下来，输出就被几何约束锁死了， 你只能在有限的几种规律里挑

    为什么工程上还是大量用连杆：

    对比项 连杆 凸轮
    运动规律精确度 只能近似 ✗ 精确 ✓
    运动副类型 低副（面接触） ✓ 高副（点线接触）✗
    承载能力 大 ✓ 小 ⚠
    耐磨损 磨损慢 ✓ 磨损快 ⚠
    制造难度 圆孔配销，容易 ✓ 轮廓加工要求高

    所以选型的判据是： 要运动规律精确 → 凸轮；要承载大、耐用、便宜 → 连杆

    补一句容易被忽略的话：虽然连杆机构不能精确实现给定的运动规律， 但它能实现别的机构做不到的东西 —— 连杆上某一点的复杂封闭轨迹（第 2.6 节算过）： 凸轮只能给出从动件的往复位移，给不出一条复杂的封闭曲线 这正是步行机器人用连杆造腿的原因

    Q4 死点位置是「缺点」还是「优点」？ 分别举一个「要避免」和「要利用」的例子，并说明各自的实现手段。

    提示

    死点的本质是传动角为 0。想一件事：这个状态下机构「反向可驱动吗」？ 从这个性质出发，分别想「连续运转的机器」和「需要保持位置的机构」。

    解答

    答：死点本身是中性的物理事实，是缺点还是优点，看场合。

    死点的本质：从动件传动角 \(\gamma = 0\)（压力角 \(\alpha = 90°\)）， 有效分力 \(F\cos 90° = 0\) —— 正反两个方向都推不动

    场合 怎么做 为什么这样做有效
    要避免（机器必须连续转） 加飞轮，靠惯性冲过死点 ✓ 飞轮储的动能在死点处补上驱动力，把机构带过去
    要避免（另一种） 多组机构错开相位 一组在死点时另一组不在，互相带动 ⚠
    要利用（需要保持位置） 起落架自锁、夹具夹紧不松脱 ✓ 死点时反向不可驱动 —— 外部力再大也顶不动，等于一把免费的锁

    两个具体例子：

    例子 属于哪一种 说明
    缝纫机踏板 要避免 ⚠ 脚踩踏板（摇杆）是主动件、大轮（曲柄）是从动件，踩到极限位置就卡住 → 装飞轮越过
    飞机起落架 要利用 ✓ 放下到位时三点共线，\(\gamma = 0\) → 自锁，不需要液压长期承力
    夹具/夹钳 要利用 ✓ 夹紧到位即自锁，夹紧力再大也退不回去

    从「谁主动」怎么看会不会有死点：

    主动件 从动件 会不会死点
    曲柄 摇杆 不会 ✓（整圈 \(\gamma \gt 0\)，如本页算出的最小值 54.64°）
    摇杆 曲柄 会 ⚠（曲柄与连杆共线时）

    所以判断一个机构有没有死点，第一步是问「谁是主动件」 缝纫机踏板的主动件是踏板（摇杆），所以有死点； 内燃机的主动件是燃气推活塞，靠飞轮越过上下止点

    小结¶

    要记住的 为什么
    平面连杆机构 = 刚性构件 + 低副 + 同一平面 三个条件各决定一件事：可计算的杆、承载大、平面自由度公式
    低副是面接触，约束数为 2 这是「承载大、耐磨损」和「公式里写 \(-2P_L\)」的共同原因 ✓
    四杆机构：4 构件、4 转动副，\(F = 1\) 一个电机就够 —— 最简真正的机构
    机架 / 连杆 / 连架杆 / 曲柄 / 摇杆 五个名称要分清，后面所有结论都用它们
    曲柄与摇杆的区别只有「整」 能不能转满一圈 ✓
    三种类型 = 同一运动链固定不同构件 运动是相对的，固定谁决定得到什么
    葛氏判据 \(s + l \le p + q\) 存在整转副的充要条件 ✓
    判据成立只说明「存在」整转副 还要叠加「固定哪一根」才知道机构类型 ⚠
    等号成立（\(s+l = p+q\)）仍满足判据 但机构是临界机构，某位置四杆共线，运动可能不确定 ⚠
    位置分析用两圆交点法 圆心 B、D，半径 \(b\)、\(c\)；两交点 = 两种装配分支
    \(\lvert b-c \rvert \le \lvert BD \rvert \le b+c\) 是装配条件 不满足就装不上；全程满足 = 那根杆能整周转 ✓
    滑块位移 \(s = r\cos\theta + \sqrt{l^2 - r^2\sin^2\theta}\) 前项曲柄投影 + 后项连杆投影 ✓
    对心曲柄滑块行程 \(H = 2r\) 只在对心时精确；偏心后略大 ⚠
    偏心曲柄滑块整转条件 \(r + e \le l\) 偏心距越大，连杆要求越长
    偏心距制造不对称 → 产生急回 \(e = 0\) 时 \(K = 1\)，\(e\) 越大 \(K\) 越大 ✓
    极位 = 曲柄与连杆共线 此时 \(\lvert AC \rvert\) 取最大 \(a+b\) 或最小 \(\lvert b-a \rvert\) ✓
    \(K = (180° + \theta_0)/(180° - \theta_0)\) 慢行程转角比快行程转角 ✓
    \(\theta_0 = 180° \cdot (K-1)/(K+1)\) 设计时由 \(K\) 反求极位夹角 ✓
    压力角 \(\alpha\) 越小越好 有效分力是 \(F\cos\alpha\) ⚠
    传动角 \(\gamma = 90° - \alpha\)，越大越好 四杆里它就是连杆与从动件的夹角 ✓
    一般要求 \(\gamma_{\min} \ge 40°\) 否则传力不可靠、可能卡死 ⚠
    死点 = 从动件传动角为 0 驱动力再大也推不动 ✓
    死点要不要避免，看「谁主动」 曲柄主动不出现；摇杆主动会出现 ⚠
    死点两种态度：飞轮冲过 / 利用自锁 连续转用飞轮；要锁住就用它 ✓
    急回与传动角互相冲突 要大的 \(K\) 就得牺牲 \(\gamma_{\min}\)，必须权衡 ⚠
    三层判据：长度 → 机架 → 性能 任一层不过关，设计就不能用 ✓

    本页的推导链，一共七步，每一步都能自己复现：

    第几步 推什么 依据
    1 自由度 \(F = 3(l-1) - 2P_L - P_H\) 构件自由度数减去副的约束数 ✓
    2 装配条件 \(\lvert b-c \rvert \le \lvert BD \rvert \le b+c\) 三角形 BCD 存在 ✓
    3 格拉斯霍夫判据 \(s + l \le p + q\) 由 \(d-a \le \lvert BD \rvert \le d+a\) 与装配条件联立 ✓
    4 四种组合得到什么机构 判据 + 固定哪一根当机架 ✓
    5 滑块位移 \(s = r\cos\theta + \sqrt{l^2 - r^2\sin^2\theta}\) B、C 距离恒为 \(l\)，再开平方取正号 ✓
    6 有效分力 \(F_t = F\cos\alpha = F\sin\gamma\) 把驱动力沿速度方向正交分解 ✓
    7 死点：\(\gamma = 0° \Rightarrow F_t = 0\) 第 6 步式子取零 ✓
