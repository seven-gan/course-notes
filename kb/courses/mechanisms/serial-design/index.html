    一、设计剖析在讲什么：从「分析」到「综合」¶

    1.1 两件事的差别¶

    本课程前面已经建立了分析的工具箱：

    工具 回答的问题 方向
    自由度公式 这个机构能动几个独立方向 分析
    D-H 参数与齐次变换 关节角给定时，末端在哪 分析（正解）
    逆运动学 末端要到某处，关节角该是多少 分析（反解）
    工作空间 这台机器够得到哪些点 分析

    而设计剖析问的是反过来的问题：

    设计问题 具体内容
    需要几个关节 任务要控制位置 3 个量 + 姿态 3 个量，够不够用
    关节怎么排 用转动副还是移动副，轴朝哪个方向
    传动怎么配 电机放哪、减速器用哪种、传动比取多大
    精度怎么保 误差怎么一路传到最后那个点上

    关键认识：分析有唯一答案，设计没有。 给定位形，正解算出来是一个数；但要「设计一台能拧钥匙的机器」， 可以有无数种做法，区别只在哪种更省、更准、更耐用 ✓

    这就是为什么本课程在这一节改用案例来讲 —— 设计的思想只藏在具体案例的取舍里，没有公式能直接写出「你该选方案 B」。

    1.2 设计剖析为什么必须看「关节以下」的东西¶

    一个只学过运动学的人容易有一个错觉： 机械臂就是几个连杆串起来，关节能转就行。

    但真正拆开一台工业机械臂，会发现关节里塞满了别的东西。 本课程课件在这个案例里给出的是剖面/爆炸图，而不是简图 —— 原因正在于此：

    只看简图会漏掉 真实机构里必须处理
    电机装在哪、多大 电机体积与发热，决定了关节外壳尺寸
    转动怎么传到关节 需要减速器、齿轮、同步带中的某一种
    关节怎么承受弯矩 需要轴承、支撑结构与刚性外壳
    线缆怎么走 内部走线孔、滑环或柔性弯折区
    重力怎么平衡 配重块、弹簧或储能元件

    所以「机构设计剖析」这四个字，剖析的不只是运动副，而是整个关节总成

    这也是本页要反复强调的一件事：机构设计不是画简图，是把运动学要求落成一个能造出来的实体。

    看清这张图的关键：A 和 D 都固定在机架上，所以整条链是一个闭环。

    现在把它和串联开链并排比一比：

    对比项 单环机构（四杆） 串联开链（机械臂）
    链的形状 闭环（首尾都连在机架上） 开链（只有基座固定，末端自由）
    构件数 \(l\) 4 \(n+1\)（\(n\) 个关节）
    低副数 \(P_L\) 4 \(n\)
    用平面公式 \(F = 3(l-1) - 2P_L\) \(3\times 3 - 2\times 4 = 1\) —（平面公式不直接适用）
    自由度 恰好 1 等于关节数
    驱动方式 只需 1 个电机 几乎每个关节都要驱动
    末端能否到达任意位姿 不能，末端只能沿一条固定轨迹走 能（6 自由度时）

    为什么串联开链的自由度就等于关节数： 开链里每个关节都是独立的低副，每加一个关节就给末端多一个独立运动， 不像闭环里那样会被机架「锁」掉一个自由度。 所以 \(n\) 个关节的开链，自由度就是 \(n\)， 这也正是为什么想要 6 个自由度就要做 6 个关节的臂

    但代价在第 5 行：四杆机构一个电机就能驱动整条链（曲柄一转，摆杆按固定规律摆动）； 机械臂要让末端去任意位姿，6 个关节就得配 6 套驱动 + 6 套减速器。 于是「怎么把这些驱动塞进细长的臂里」就成了设计的主要矛盾

    1 个自由度不是「只能画一条线」

    四杆机构的自由度是 1，指的是独立输入只有 1 个（曲柄转角）， 并不是说它的构件只能沿一条线走。

    说法 含义
    自由度 = 1 只要给定 1 个输入（曲柄角），整条链上所有构件的位置都唯一确定
    末端轨迹 连杆上不同的点，画出的轨迹完全不同（有近似直线的、有近似圆弧的）

    所以它「能画什么」取决于你在连杆上取哪个点， 但永远只有一个输入 —— 这两件事不要混 ⚠

    1.4 数关节之前先数「同一处有几个副」¶

    上面说「开链的自由度等于关节数」，这句话在关节彼此分开时成立。 但机构设计里还有一个更容易数错的坑：多个构件挤在同一处铰接。

    看图里那一处多杆共用的大铰点：四个构件全都套在同一个销轴上。 如果按「一个地方算一个转动副」来数，就会少数两个副， 自由度公式算出来的结果就全错了 ✗

    正确的数法：设同一处铰接的构件数是 \(m\)，那么这一处对应的转动副数是

    \[P = m - 1\]

    图上是 \(m = 4\)，所以 \(P = 3\)

    这个坑为什么和本页有关： 机械臂设计里，腕部三轴相交的三条轴线在几何上交于一点， 看起来也像「一个地方」。 但它们是三个互相垂直的转动副，轴线方向不同， 不属于复合铰链。 这正好和图上那种「同轴多构件铰接」形成对照，不要混淆

    情形 几何特征 该算几个副
    复合铰链 \(m\) 个构件共用一根销轴（轴线重合） \(m-1\) 个 ✓
    腕部三轴相交 三条轴交于一点但方向各不相同 就是 3 个独立转动副 ✓

    一句话：「交于一点」和「共轴」是两回事。 前者的轴方向不同，各算一个副；后者的轴重合，要合并计数

    2.2 腰部：为什么第一个关节要用大轴承和大齿轮¶

    先从最底下看起。整机照片旁边那张基座剖面图里， 最显眼的是一个巨大的滚动轴承和一对大齿轮。

    为什么腰部要做得这么粗壮，道理可以一层层推：

    层次 原因
    承载 第 1 轴要扛住整条手臂 + 末端负载的全部重量，还要扛倾覆力矩
    惯量 手臂伸直时，负载到第 1 轴轴线的距离最大，产生的力矩也最大
    精度 第 1 轴转一个小角度，末端会画出很长的弧，误差被放大
    驱动 同样的角加速度，转动惯量越大需要的扭矩越大

    算一笔账：设手臂全伸时末端到腰部轴线的水平距离是 \(r\)， 末端负载质量是 \(m\)，那么重力对第 1 轴轴线产生的倾覆力矩是

    \[\tau_g = m g r\]

    代入 \(m = 5\ \text{kg}\)、\(r = 1.0\ \text{m}\)、\(g = 9.81\ \text{m/s}^2\)：

    \[\tau_g = 5 \times 9.81 \times 1.0 = 49.05\ \text{N}\cdot\text{m}\]

    这个力矩不是第 1 轴的驱动力矩（它是绕水平轴的倾覆力矩）， 但它会变成第 1 轴轴承上的径向载荷， 所以轴承必须选得够大、跨距必须够宽 ⚠

    这就是设计剖析的第一条经验： 越靠基座的关节，承载越大、做得越粗；越靠末端的关节，越轻巧。

    课件里这台机器「大臂粗、小臂细、手腕更细」的体态， 不是审美选择，而是受力决定的

    2.3 传动链：动力是怎么「翻山越岭」到手腕的¶

    案例一最值得看的是第 2、3 张爆炸图。把它们读懂，就懂了机械臂设计的一半。

    问题在哪：机械臂的关节不在一条直线上， 可电机是一个个的圆柱体，装不进细长的手臂里。 于是有两种思路：

    思路 做法 后果
    就近驱动 每个关节旁边直接装电机 + 减速器 关节处体积大、重量大；越靠末端越吃亏 ⚠
    远端驱动 + 传动链 电机放在靠基座处，通过齿轮/同步带/连杆把动力「送」到关节 关节可以做得很细，但传动链长、刚度与回差要仔细处理

    案例一选的是第二种。 在爆炸图里能看到：几组电机与齿轮并排布置在肩部附近， 然后通过一串齿轮把转动逐级传到小臂与手腕。

    这么做的好处非常直接：

    好处 为什么重要
    减轻末端重量 越靠末端的质量，对前面所有关节的惯量贡献越大
    缩小关节体积 手腕可以做得很细，能伸进工件内部
    便于散热 电机集中在臂根，可以共用散热空间
    便于维护 电机是可换件，坏了好拆

    为什么「减轻末端重量」这么关键：设末端增加的质量是 \(\Delta m\)， 它到第 \(i\) 个关节轴线的距离是 \(r_i\)， 那么这个质量对第 \(i\) 个关节转动惯量的贡献是

    \[\Delta J_i = \Delta m\, r_i^{\,2}\]

    注意这里是平方。把 \(1\ \text{kg}\) 从离轴线 \(0.1\ \text{m}\) 处挪到 \(1.0\ \text{m}\) 处， 惯量贡献从 \(1 \times 0.01 = 0.01\) 变成 \(1 \times 1.0 = 1.0\)，放大 100 倍

    这就解释了一个反直觉的事实： 为了给末端减掉 1 kg，工程师愿意在臂根多加 5 kg 的电机和配重。

    2.4 腕部：三轴相交为什么是经典设计¶

    案例一的机器属于腕部三轴相交于一点的构型。这一点在本课程前面讲过， 这里从设计的角度再看一遍它到底解决了什么问题。

    设腕部三个关节的角速度是 \(\dot\theta_4\)、\(\dot\theta_5\)、\(\dot\theta_6\)， 腕心到工具尖点的向量是 \(\mathbf{p}_{\text{tool}}\)。 如果三轴相交于腕心，那么这三个关节转动时， 工具尖点绕腕心的距离不变，只有方向在变。

    于是位置与姿态可以分开算：

    步骤 用哪些关节 目标
    第一步：定位 第 1、2、3 关节 把腕心送到目标点
    第二步：定向 第 4、5、6 关节 把工具转向目标姿态

    为什么这个「分开」可以节省很多计算： 如果不交于一点，工具尖点的位置会随着腕部转动而改变， 位置方程里就同时含有前三个和后三个关节角， 6 个未知数必须联立求解；交于一点之后，前 3 个方程只含前 3 个未知数， 可以先解完再用结果去解后 3 个

    本课程课件明确指出：满足「三个相邻关节轴相交于一点」这一条件时， 六自由度机器人的逆解可以写成封闭解（解析表达式）， 而不相交的构型往往只能靠数值迭代 —— 而迭代比解析慢得多。 所以「腕部三轴相交」不是美学，是一条能在设计阶段就把计算量降下来的结构性决策

a2, a3 = 0.425, 0.392     # 大臂、小臂长度 / m
d1 = 0.089                # 腰高 / m
L_tool = 0.150            # 工具尖点到腕心的距离 / m


def wrist_center(q):
    """前三个关节决定的腕心位置（三轴相交时，它与 q4/q5/q6 无关）。"""
    s2, c2 = np.sin(q[1]), np.cos(q[1])
    s23, c23 = np.sin(q[1] + q[2]), np.cos(q[1] + q[2])
    r = a2 * c2 + a3 * c23
    z = a2 * s2 + a3 * s23 + d1
    return np.array([r * np.cos(q[0]), r * np.sin(q[0]), z])


def tool_point(q, bias):
    """末端工具尖点位置。

    bias = 0  ：三轴相交。工具尖点只绕腕心转动，到腕心的距离恒为 L_tool。
    bias > 0  ：腕轴偏置。除了绕腕心转，还多出一个随腕姿态变化的平移，
                这个平移就是「腕心跑动」带来的位置漂移。
    """
    w = wrist_center(q)
    ang = q[0] + q[3]            # 工具在水平面内的指向
    tip = w + L_tool * np.array([np.cos(ang), np.sin(ang), 0.0])
    if bias > 0:
        # 偏置引入的额外交付：随腕部转角变化的水平平移
        tip = tip + bias * np.array([np.sin(q[3]),
                                     (1.0 - np.cos(q[3])), 0.0])
    return tip

    三、案例二：一体化关节驱动的机械臂¶

    3.1 案例的定位：把「关节」当成一个整件¶

    案例一代表的是「传动链铺满整条臂」的思路。 案例二代表的是另一条路：把电机、减速器、编码器、驱动器全部塞进关节壳里， 做成一个可以直接拧螺栓装到连杆上的独立模块。

    课件在案例二里连出三页，分别对应三种不同形态的一体化关节产品：

    课件的子页 关节里的核心内容
    子页 1 高集成电机 + RV 减速器：结构紧凑，传动比大
    子页 2 一体化电机（伺服电机 + 一体化驱动器）；减速器用行星减速器、谐波减速器
    子页 3 同一套一体化关节思路的多种形态（多臂、复合底盘等）

    注意：这里出现了三种减速器的名字 —— RV 减速器、行星减速器、谐波减速器。 它们是本页必须讲清的一个知识点，下面单独展开。

    3.2 三种减速器：为什么关节里非要有减速器¶

    先问一个更基础的问题：为什么关节里一定要装减速器？直接把电机接到关节上不行吗？

    不行，而且不行得很彻底。 原因集中在三条：

    原因 具体表现
    扭矩不够 直接驱动要产生足够大的关节扭矩，电机必须做得极大极重 ⚠
    惯量不匹配 电机转速高、扭矩小，与关节「低转速、大扭矩」的需求正好相反
    精度与分辨率 编码器装在电机侧，想分辨 \(0.001°\) 的关节角，电机侧要分辨到极高的角度

    减速器的核心作用就是用转速换扭矩。设减速比为 \(N\)（\(N \gt 1\)），

    \[\tau_{\text{out}} = N \eta \tau_{\text{in}}, \qquad \omega_{\text{out}} = \frac{\omega_{\text{in}}}{N}\]

    其中 \(\tau_{\text{in}}\) 是电机输出扭矩，\(\omega_{\text{in}}\) 是电机转速， \(\eta\) 是减速器的机械效率（\(0 \lt \eta \le 1\)）。

    怎么读这两个式子：扭矩被放大 \(N\) 倍（再打一个效率折扣）， 转速被缩小 \(N\) 倍，功率基本守恒（\(\tau\omega\) 在效率内保持不变）。

    还有一条更漂亮的性质：负载归算到电机侧的惯量，要除以 \(N^2\)：

    \[J_{\text{load}\to\text{motor}} = \frac{J_{\text{load}}}{N^2 \eta}\]

    为什么这条重要：电机要驱动的等效惯量越小，响应越快、越容易控制。 \(N = 100\) 时，负载惯量归算到电机侧只有原来的 \(1/10000\) —— 这一个平方，就是关节能做得又轻又快的数学原因

    现在再看三种减速器的差别：

    减速器 原理要点 典型传动比量级 特点
    行星减速器 太阳轮 + 多个行星轮 + 内齿圈 较小（约 3 ～ 10 每级） 结构紧凑、效率高；单级比不大，常多级串联
    谐波减速器 柔轮靠波发生器强迫变形，与刚轮少齿差啮合 较大（约 50 ～ 160） 单级比大、体积小、回差小；柔轮疲劳与刚度是弱项 ⚠
    RV 减速器 摆线针轮 + 渐开线行星轮的两级复合 大（约 30 ～ 200） 刚度高、承载大、抗冲击；体积重量较大，常用于基座关节

    课件原文的点睛之笔是：「高集成电机 + RV 减速器：结构紧凑，传动比大」。 这一句把一体化关节的动机说透了 —— 大传动比让电机可以做小， 小型化让整机重量集中到基座附近，整机的惯量与体积都受益

    这三种减速器虽然结构差别很大，但对外表现出的规律是一样的： 都是用转速换扭矩，都遵循上面那两条关系式。 下面这张图用一对最简单的齿轮把这条规律画出来 —— 看懂了齿轮，就看懂了减速器的全部本质：

    图上最值得记住的一句话是底下那行注： 「转速降到 ⅓，扭矩升到 3 倍，传递功率不变」。 这就是整页反复出现的那条守恒关系 —— 减速器不给机器增加功率，它只是把功率换个形式（用转速换扭矩）

    为什么对机械臂特别关键：机械臂最需要的恰恰是大扭矩、低转速。 关节要扛住几十到几百牛米的负载力矩，而转速只需要几十转每分钟。 齿轮副、谐波、RV 三种减速器，本质都在做同一件事： 把这台高速小扭矩的电机，改造成一台低速大扭矩的「伪电机」

    3.3 一体化关节给机构设计带来什么¶

    把关节做成模块，对整机设计的影响是连锁的：

    影响 说明
    设计变成拼装 选定关节模块后，连杆只需按接口尺寸设计，开发周期大幅缩短
    关节可互换 同一个模块可以做肩关节，也可以做腕关节（只看扭矩够不够）
    中空走线 模块通常带中央通孔，线缆可以从关节内部穿过去，不必绕在外面
    体积集中 关节本身较粗，但省掉了整条臂上的传动链

    「中空走线」这一点特别值得记住： 线缆如果绕在关节外部，关节一转线缆就会被反复弯折、拉扯， 寿命很短，而且容易被工件刮伤。把它从关节中心穿过去之后， 关节转动不会改变线缆路径，这是协作臂外观干净的根本原因

    一体化关节不是「把所有零件堆在一起」

    常见的误解是：一体化关节就是把电机、减速器、驱动器随便塞进一个壳子里。

    真正的一体化关节必须同时解决这几件事，缺一件就不能用：

    必须解决 否则会怎样
    同轴度与轴承支撑 输出法兰晃动，末端精度完全丧失 ⚠
    中央走线通道 线缆只能外露，寿命与外观都差
    编码器安装位置 关节侧没有绝对角反馈，断电后要重新回零
    热传导路径 电机与驱动器热量散不出去，会降额甚至烧毁
    机械限位与制动 断电时重力会让手臂自行跌落 ⚠

    所以「一体化」不是物理上的堆叠，而是功能上的整合： 把原本散落在连杆上的零件，重构进一个可独立测试、独立更换的单元

    4.1 案例的定位：需求先于构型¶

    第 5 张 第 2 个关节（蜗轮/大齿轮 + 离合盘 + 球弹簧） 讲传动 + 过载保护

    4.2 为什么选这个构型¶

    从第 1 张图可以看到，这台臂是六个转动副串接的关节型臂， 前三个关节负责把末端送到位置，后三个关节负责姿态， 腕部三轴相交（图里末端附近的三个红色箭头都指向同一个中心）。

    为什么科研定制臂也照抄了这个经典构型：

    理由 说明
    有封闭解 三轴相交 → 有解析逆解 → 实时控制好做，不用迭代
    任务是以姿态为主 超声扫描需要在保持接触的同时调整探头角度
    结构简单、易加工 定制件数量少，六个关节全用转动副，不用设计移动副的导轨
    柔顺要求 要「机械约束力」可控，结构要轻、要能被动退让

    定制臂不等于「什么都可以自由发挥」

    从零设计看起来最自由，其实约束最多。案例三面临的是这么一组矛盾：

    想要 但受限于
    末端灵敏、能感知接触力 结构要轻，刚度就会下降
    要能贴住人体表面 必须有被动柔顺，不能纯靠位置控制
    关节多、灵活 每个关节都要驱动与走线，重量与复杂度上升
    体积小、能靠近患者 电机与减速器必须塞得很小，扭矩就不够

    所以定制设计的真正难点不是「想出一个新构型」， 而是在一堆互相打架的要求之间找到那个勉强能接受的平衡点

    4.3 逐个关节看传动方案¶

    案例三最有价值的地方，是它把每一个关节的传动方案都画出来了。 把它们串起来看，会发现一条很实在的设计规律： 越靠末端，传动越简单、零件越小、精度要求越高。

    关节 课件图中出现的零件 传动方案 为什么这么选
    第 1 关节 小型步进电机、附着在电机轴上的小齿轮、连着六角键的大齿轮、轴承、轴环 一级齿轮减速 转速需求低，只要扭矩够、结构薄
    第 2 关节 小型步进电机 + 小齿轮、大齿轮、大轴承、定位孔、离合盘、球弹簧 齿轮减速 + 离合/过载保护 这个关节承受的力矩最大，需要防过载
    第 3 关节 小型步进电机 + 小齿轮、大齿轮、轴承座、六角键、轴承 齿轮减速 + 键连接 用键传递扭矩，便于装配与维修
    第 4 关节 小型步进电机 + 小齿轮、长齿轮、轴承 齿轮减速（用长齿轮跨越距离） 要在有限宽度里把动力送到另一侧
    末端 大锥齿轮 + 键结构、末端轴环、定制力传感器、探头 锥齿轮换向 + 力感知 需要在末端改变传动方向，并测接触力

    从这张表能读出三条设计经验：

    第一条：齿轮是最通用的关节传动方式。 齿轮能在很小的空间里实现减速、换向（锥齿轮）、跨越距离（长齿轮）， 而且零件便宜、容易加工。代价是有回差、需要润滑与密封

    第二条：保护机构要装在最危险的关节上。 第 2 关节上出现了离合盘与球弹簧，这是典型的过载保护结构： 当力矩超过预设值时，弹簧被压缩，离合器打滑，传动断开。 为什么装在肩关节：它承受的力矩最大， 一旦末端撞上东西，这里最容易损坏电机或齿轮

    第三条：键连接是「可拆」的保证。 课件多次画出六角键（hexagon keyway），它不是传动方案， 而是扭矩传递与定心的接口：轴和轮之间用键配合， 拆下来之后还能装回原来那个角位置（只要不换键）。 对需要反复装配的科研样机来说，这一点比省几个零件重要得多

    4.4 末端：为什么定制臂的难点最后都落在末端¶

    案例三的最后一页单独画了末端，这一页信息量很大：

    末端里的零件 作用
    大锥齿轮（带键槽） 把动力换向 90°，驱动探头的自转
    末端轴环（holder） 固定探头与传感器组件
    末端上的键结构 保证探头安装的角向重复性
    定制的力传感器结构 测量探头与人体的接触力
    超声探头 真正的执行器

    为什么末端要单独设计： 前面所有关节的努力，最后都要通过末端作用到任务对象上。 末端差一点，前面再准也白搭。而末端恰恰是最难做的，因为它：

    难点 说明
    空间最小 末端最细，所有零件都要微型化
    受力最杂 要同时承受扭矩、弯矩和接触反力
    离传感器最近 力传感器要装在力传递路径上，不能隔太多柔顺环节
    要能换 不同任务要换不同工具，接口必须标准化

    一句话：机构设计剖析的意义，就是把「末端要什么」一层层往回翻译成「每个关节该怎么做」。

    五、从「平行关节轴」再看一次封闭解¶

    5.1 Pieper 准则的两个充分条件¶

    本课程课件在讲逆运动学时给出了Pieper 准则： 如果六自由度机器人满足下面两个充分条件之一，就能得到封闭解：

    条件 课件的例子
    （1）三个相邻关节轴相交于一点 某型机械臂最后三个关节轴相交于一点
    （2）三个相邻关节轴相互平行 某型协作臂第 2、第 3、第 4 关节轴平行

    案例一用的是条件（1），案例二里这种协作臂用的正是条件（2）。

    为什么「三个轴平行」也能解耦： 三条平行的转动轴，两两之间的相对转动都发生在同一个方向的平面上。 把三条轴投影到垂直于它们的那个平面里，整个小臂部分就退化成一个平面三杆机构， 可以用平面几何直接解 —— 而不是原来那种三维的联立方程

    5.2 平行轴带来的几何好处¶

    设三个平行关节轴的角速度分别是 \(\dot\theta_2\)、\(\dot\theta_3\)、\(\dot\theta_4\)。 因为它们都绕同一个方向转，末端在垂直于该方向的那个平面上的位移， 只由这三个角的两两和与差决定：

    \[\phi_{234} = \theta_2 + \theta_3 + \theta_4\]

    三个绕平行轴转的关节， 对「工具绕该方向的总转角」的贡献是代数和， 它们的中间结果不影响这个总和。 所以「工具朝向」这一个自由度，可以用一个方程解出来， 剩下两个自由度再用平面几何解

    而如果三个轴不平行，每个关节的转动方向都不同， 就必须写成完整的旋转矩阵乘积，无法这样拆开 ⚠

    5.3 两种条件的对比¶

    把两个准则放在一起，可以看到它们各自适合什么场合：

    对比项 条件（1）三轴相交 条件（2）三轴平行
    相交/平行的部位 通常在最靠近末端的腕部 通常在中段（第 2、3、4 轴）
    解耦把什么分开 位置与姿态 平面内与平面外
    典型外形 传统工业机械臂 模块化协作臂
    关节外壳形状 腕部要做成球状（要容纳三条交叉的轴） 三个关节外壳可以做成相同的扁平饼状
    加工与装配 腕部结构复杂，装配难度高 关节模块可以互相复用，装配简单 ✓
    适合的负载 大负载、高刚度 中小负载、轻量、安全

    这是一条很实用的选型经验： 传统工业机械臂靠「三轴相交」拿封闭解， 模块化协作臂靠「三轴平行」拿封闭解。 两条路都能避免数值迭代，但对制造工艺的要求完全不同

    「有封闭解」不等于「任意位置都能解」

    得到封闭解只是说明推导形式上能写出解析表达式， 并不保证目标点一定能到达。下面几件事仍然会让解不存在或不可用：

    情形 后果
    目标点超出工作空间 位置方程无解，数学上就是某个根号内出现负数 ⚠
    目标点落在够不到的空洞里 同样是位置方程无解
    解出来的角度超出行程限位 数学有解、机械做不到
    落在奇异位形上 有解但需要无穷大的关节速度，实际不能走
    多个解都不满足姿态要求 位置对了、姿态对不上

    所以工程上「有没有封闭解」和「这个点能不能干」是两件独立的事， 都要检查

    六、三维构型对比：同一组尺寸，三种腕部¶

    6.1 三种腕部构型的定义¶

    把前面讲的串起来，本页可以给出一个清晰的分类：

    腕部构型 三条腕轴的关系 是否满足 Pieper 条件
    球腕（三轴相交） 三条轴交于一点（腕心） 满足条件（1）✓
    偏置腕（小偏置） 第 4、5、6 轴中有两轴错开一个小距离 不满足 ⚠
    平行腕 三条腕轴两两平行 满足条件（2）✓

    为什么要专门比较这三种： 正因为它们「看起来都是三个转动关节」，能力却差得很远， 这正是最容易在选型时看走眼的地方。

    七、平衡、走线与限位：三个容易被忽略的设计点¶

    7.1 重力平衡¶

    前面一直在讲「怎么把力传过去」，但还有一个更基础的问题： 断电或者电机不出力的时候，手臂会不会自己掉下来？

    会的，而且越是大臂，越严重。 设大臂质量 \(m_1 = 20\ \text{kg}\)，重心到肩关节的距离 \(r_1 = 0.35\ \text{m}\)， 小臂与末端合计质量 \(m_2 = 12\ \text{kg}\)，作用点到肩关节的距离 \(r_2 = 0.70\ \text{m}\)， 肩关节的俯仰角是 \(\theta\)（从水平位置算起，向上为正）。

    重力对肩关节轴线的力矩为：

    \[\tau_g(\theta) = -(m_1 g r_1 + m_2 g r_2)\cos\theta\]

    代入数值：

    \[\tau_g(\theta) = -(20 \times 9.81 \times 0.35 + 12 \times 9.81 \times 0.70)\cos\theta\]

    先把括号里算清：

    \[20 \times 9.81 = 196.2,\qquad 196.2 \times 0.35 = 68.67\]
    \[12 \times 9.81 = 117.72,\qquad 117.72 \times 0.70 = 82.404\]

    两部分相加：

    \[68.67 + 82.404 = 151.074\ \text{N}\cdot\text{m}\]

    所以：

    \[\tau_g(\theta) = -151.074\cos\theta\ \text{N}\cdot\text{m}\]

    当 \(\theta = 0\)（手臂水平伸出）时，\(|\tau_g| = 151.074\ \text{N}\cdot\text{m}\) —— 这是最大值； 当 \(\theta = \pm 90°\)（手臂竖直向上或向下）时，\(|\tau_g| = 0\)。

    这个式子说明什么：重力力矩随姿态按余弦变化， 最危险的位置是手臂水平伸出时

    所以设计上必须做两件事：

    做法 目的
    机械平衡（配重块 / 弹簧 / 气缸） 抵消一部分重力矩，让电机只需出很小的力矩
    失电制动器（抱闸） 断电时把关节锁死，防止手臂自由跌落

    配重块怎么算：在肩关节的另一侧、距离 \(r_c\) 处加一块质量 \(m_c\) 的配重， 它产生的力矩是 \(+m_c g r_c \cos\theta\)（方向相反）。 要和上面那三项配平（只配平前两项，末端负载不配平）：

    \[m_c g r_c = m_1 g r_1 + m_2 g r_2\]

    两边消掉 \(g\)：

    \[m_c r_c = 68.67 + 82.404 = 151.074\ \text{kg}\cdot\text{m}\]

    如果取 \(r_c = 0.25\ \text{m}\)：

    \[m_c = \frac{151.074}{0.25} \approx 604.296\ \text{kg}\]

    这个结果明显不合理 —— 配重块要 600 多公斤，机器根本带不动

    为什么会这样：因为配重块的力臂 \(r_c = 0.25\ \text{m}\) 比被平衡的力臂短， 力臂越短，需要的质量越大。

    正确的做法是把配重放得足够远，或者改用弹簧平衡机构：

    方案 力臂 需要的补偿
    配重块 短力臂 → 需要很大质量 不划算 ⚠
    配重块（长力臂） \(r_c = 0.7\ \text{m}\) 时 \(m_c \approx 215.8\ \text{kg}\) 仍然很重
    弹簧平衡 靠弹簧的变力特性匹配余弦规律 弹簧刚度小、重量轻 ✓
    气缸平衡 同样提供变力 需要气源

    这就是设计剖析要教的第一手经验： 一个简单的力学式子算出来，往往就会否决一个看起来很自然的方案。

    配重不一定让电机更省电

    直觉上「加了配重，电机省力了，应该更省电」。实际上不一定：

    代价 说明
    惯量增加 配重块本身也有质量，所有关节的转动惯量都变大 ⚠
    加速变慢 惯量越大，同样的扭矩下加速度越小，节拍变慢
    基座负担 配重块的质量最终也压在第 1 轴与底座上
    只平衡重力 配重对加减速所需的力矩没有任何帮助

    所以配重只在一种情况下明显划算： 手臂长时间停留在同一个姿态（比如水平伸出做点焊）， 这时重力矩是主要负担，配重能直接降低电机的持续发热

    如果是频繁大幅摆动的任务，配重带来的惯量代价可能超过收益

    7.2 内部走线¶

    线缆问题在设计里常被当成「细节」，但它经常是压垮方案的那一根稻草。

    如果线缆走在关节外部，会发生什么：

    现象 后果
    关节反复转动 线缆被反复弯折，疲劳断裂 ⚠
    线缆悬在臂外 容易被工件、夹具刮伤
    线缆长度要留余量 余量会形成线环，运动时甩动、打结
    占用外部空间 影响末端可达范围

    所以现代机械臂都做内部走线，基本手法有三种：

    手法 适用位置 说明
    中央通孔 一体化关节 线缆从关节轴中心穿过，关节转动不影响线缆路径 ✓
    柔性弯折区 需要大角度摆动的关节间 留出一段「S 形」让线缆有控制的弯折
    滑环 需要连续整圈回转的关节 用导电滑环实现无限制回转，但成本与可靠性代价高

    走线对机构设计的具体影响： 关节的中空孔径不是随便定的，它由所有要穿过的线缆束的直径决定。 线缆越多、越粗，关节孔就越大，关节外壳就越粗 —— 而外壳变粗又会影响相邻连杆的干涉关系。 这就是一个典型的「机械与电气互相牵制」的设计回路

    7.3 限位与制动¶

    案例三第 2 关节上出现的离合盘与球弹簧， 除了过载保护，还承担了「限制转角范围」的职能。

    保护装置 保护什么 触发条件
    机械限位块 防止关节越过设计角度 转角到极限位置时硬挡住
    离合器（球弹簧式） 防止传动链被扭坏 力矩超过弹簧预紧力时打滑 ✓
    失电制动器 防止断电时重力坠落 断电瞬间抱闸 ⚠
    软件限位 在到达机械限位前就减速停止 由控制器根据编码器判断

    四层保护的关系是「从软到硬」： 先靠软件限位在日常运动中止步； 软件失效时靠机械限位兜底； 机构被外力强行推动时靠离合器打滑卸掉扭矩； 断电时靠制动器防止坠落

    为什么定制样机更要重视这一步： 科研样机常常在有人靠近的环境里调试， 一旦控制出错，机械保护是唯一还起作用的那一层 ⚠

    八、把设计步骤串起来¶

    8.1 从任务到构型的五步¶

    把三个案例的共性抽出来，可以得到一条通用的设计流程：

    步骤 要回答的问题 输出
    第一步：数需求 要控制哪几个量？位置 3 个够不够，姿态要几个？ 需要的自由度数目
    第二步：定构型 前 3 轴怎么排（PPP/RRP/RPP/RRR）？腕部怎么排？ 构型代码 + 腕部类型
    第三步：保解耦 有没有满足两个充分条件之一？能不能拿到封闭解？ 解耦方式与求解路线
    第四步：配传动 每个关节用哪种减速器、传动比多少、中空孔径多大？ 关节模块参数
    第五步：加保护 平衡、限位、制动、走线、过载保护都安排了吗？ 全部细节

    注意这五步的顺序不能颠倒： 第三步「保解耦」必须在第四步「配传动」之前完成， 否则传动链已经画好了，再发现有耦合只能返工

    九、典型例题¶

    例题 1：判断能不能拿到封闭解¶

    有三台六自由度机械臂，关节轴的几何关系分别如下：

    （a）第 1、2、3 轴两两不平行也不相交；第 4、5、6 轴交于同一点。

    （b）第 1、2、3 轴两两不平行也不相交；第 4、5、6 轴也不相交，但第 2、3、4 轴互相平行。

    （c）第 1、2、3 轴两两不平行也不相交；第 4、5、6 轴两两不平行、不相交，也没有三个轴平行。

    （1） 分别判断哪几台能拿到封闭解。 （2） 说明理由。 （3） 拿不到封闭解的那台，工程上怎么办？

    思路

    回到 Pieper 准则的两个充分条件：三个相邻关节轴相交于一点， 或者三个相邻关节轴相互平行。只要满足其中一个就够了。

    逐台检查「有没有三个相邻的轴满足这两个条件之一」—— 注意必须是相邻的，隔开的不能算。

    解答

    （1）（2）逐台判断。

    机器 相邻三轴的关系 满足哪条条件 结论
    （a） 第 4、5、6 轴交于一点 条件（1）✓ 有封闭解 ✓
    （b） 第 2、3、4 轴互相平行 条件（2）✓ 有封闭解 ✓
    （c） 没有任何三个相邻轴相交或平行 都不满足 一般无封闭解 ⚠

    展开说明：

    （a） 这是最经典的做法。腕部三轴交于一点， 于是工具尖点的位置只由前三个关节决定， 腕部转动只改姿态。位置方程里不含第 4、5、6 轴的角度， 可以先把前三个角解出来，再回代解姿态 —— 就是位置与姿态解耦

    （b） 第 2、3、4 轴平行，把这三个轴投影到垂直于它们的平面里， 这三个关节就退化成平面内的三杆机构，可用平面几何直接求解。 对应的总量关系是：

    \[\phi_{234} = \theta_2 + \theta_3 + \theta_4\]

    「工具绕该方向的总转角」只由三者之和决定， 于是姿态的一个自由度可以先解出来，剩下的再用平面几何补

    （c） 三个条件都不满足时，位置和姿态方程互相耦合， 6 个未知数必须联立，而且不能化成多项式的低次形式， 一般没有解析表达式

    （3）工程上怎么办。

    做法 说明
    用数值迭代解 给定初始关节角，反复逼近目标位姿
    离线规划 + 在线插值 离线算好整条轨迹，实时只做小范围修正
    改构型 这是最根本的 —— 在设计阶段就把腕部改成三轴相交或让三个轴平行 ✓
    加冗余关节 多一个自由度可用来自如地绕开病态区

    关键提醒：本课程课件指出， 「在设计机器人的构型时就要考虑封闭解的存在性」 —— 也就是说这件事应该在画图之前就定下来， 而不是等样机做出来才发现实时控制跑不动

    结论：（a）与（b）有封闭解，（c）一般没有； 能否有封闭解由关节轴的几何关系决定，属于构型层面的决策。

    例题 2：算一个关节需要多大的减速比¶

    某机械臂的肩关节要求：

    • 输出扭矩不低于 \(180\ \text{N}\cdot\text{m}\)；
    • 关节最大转速不低于 \(18\ \text{r/min}\)；
    • 可选的电机额定扭矩为 \(1.5\ \text{N}\cdot\text{m}\)，额定转速 \(3000\ \text{r/min}\)；
    • 现有减速器效率均为 \(\eta = 0.80\)。

    （1） 只看扭矩，减速比至少要多大？ （2） 只看转速，减速比最大能取多少？ （3） 综合两者，减速比应取什么范围？如果不能满足，怎么改？ （4） 若取 \(N = 150\)，关节实际输出扭矩是多少？

    思路

    两个不等式分别给出减速比的下限和上限： 扭矩关系 \(\tau_{\text{out}} = N\eta\tau_{\text{in}}\) 要求 \(N\) 足够大； 转速关系 \(\omega_{\text{out}} = \omega_{\text{in}}/N\) 要求 \(N\) 足够小。 把两个不等式都解出来，再看有没有交集。

    解答

    （1）只看扭矩，求 \(N\) 的下限。

    由扭矩关系：

    \[\tau_{\text{out}} = N\eta\tau_{\text{in}} \ge 180\]

    代入 \(\eta = 0.80\)、\(\tau_{\text{in}} = 1.5\)：

    \[N \times 0.80 \times 1.5 \ge 180\]

    先算系数：

    \[0.80 \times 1.5 = 1.2\]

    所以：

    \[1.2N \ge 180 \;\Longrightarrow\; N \ge \frac{180}{1.2} = 150\]

    下限是 \(N \ge 150\)

    （2）只看转速，求 \(N\) 的上限。

    由转速关系：

    \[\omega_{\text{out}} = \frac{\omega_{\text{in}}}{N} \ge 18\]

    代入 \(\omega_{\text{in}} = 3000\)：

    \[\frac{3000}{N} \ge 18 \;\Longrightarrow\; N \le \frac{3000}{18} \approx 166.667\]

    上限是 \(N \le 166.667\)

    （3）综合两者。

    \[150 \le N \le 166.667\]

    这个区间非空，所以在现有条件下可行， 取区间内的任意值都可以， 常见做法是取整到一个标准减速比，比如 \(N = 160\)

    如果不能满足怎么办（比如上限算出来小于下限）：

    改法 效果
    换更大扭矩的电机 直接抬高下限的分子，让下限变小
    换单级比更大的减速器（如谐波、RV） 把可行区间整体右移
    降低关节最大转速要求 抬高上限，放宽约束
    加入第二级减速 总传动比等于各级之积，容易做到很大

    （4）取 \(N = 150\) 时的实际输出扭矩。

    \[\tau_{\text{out}} = 150 \times 0.80 \times 1.5 = 150 \times 1.2 = 180\ \text{N}\cdot\text{m}\]

    此时关节转速为：

    \[\omega_{\text{out}} = \frac{3000}{150} = 20\ \text{r/min}\]

    正好同时满足扭矩（恰好 \(180\)）与转速（\(20 \ge 18\)）两条要求

    注意一个易错点：这里扭矩恰好等于要求值， 意味着没有任何余量。实际设计时通常会留 \(1.5\) 倍以上的安全系数， 因为还要计入摩擦、加减速时的惯性力矩， 以及减速器长期使用后效率下降

    结论：可行区间 \(150 \le N \le 166.667\)； 取 \(N = 150\) 时输出扭矩 \(180\ \text{N}\cdot\text{m}\)、转速 \(20\ \text{r/min}\)。

    例题 3：为什么末端加 1 公斤代价这么大¶

    某机械臂的末端要换一个更重的工具，质量比原来增加 \(1.0\ \text{kg}\)。 该工具到各关节轴线的距离分别是：

    关节 到该工具质心的距离
    第 6 轴（最后一个腕关节） \(0.10\ \text{m}\)
    第 5 轴 \(0.16\ \text{m}\)
    第 4 轴（腕部回转） \(0.16\ \text{m}\)
    第 2 轴（肩） \(0.85\ \text{m}\)

    （1） 分别计算这 \(1.0\ \text{kg}\) 对每个关节转动惯量的贡献。 （2） 这个增量对哪个关节影响最大？ （3） 如果不想重新选电机，有哪些补偿办法？

    思路

    把末端新增的质量当成一个质点， 它到第 \(i\) 个关节轴线的垂直距离是 \(r_i\)， 那么它对第 \(i\) 个关节转动惯量的贡献就是 \(\Delta J_i = \Delta m\, r_i^{2}\)。

    关键在平方上：距离翻倍，惯量贡献涨到 4 倍。

    解答

    （1）逐关节计算。

    公式：

    \[\Delta J_i = \Delta m\, r_i^{\,2}, \qquad \Delta m = 1.0\ \text{kg}\]

    逐个代入：

    第 6 轴：

    \[\Delta J_6 = 1.0 \times 0.10^2 = 1.0 \times 0.01 = 0.01\ \text{kg}\cdot\text{m}^2\]

    第 5 轴：

    \[\Delta J_5 = 1.0 \times 0.16^2 = 1.0 \times 0.0256 = 0.0256\ \text{kg}\cdot\text{m}^2\]

    第 4 轴：

    \[\Delta J_4 = 1.0 \times 0.16^2 = 0.0256\ \text{kg}\cdot\text{m}^2\]

    第 2 轴：

    \[\Delta J_2 = 1.0 \times 0.85^2 = 1.0 \times 0.7225 = 0.7225\ \text{kg}\cdot\text{m}^2\]

    汇总：

    关节 距离 / m 惯量贡献 / (kg·m²) 相对第 6 轴
    第 6 轴 \(0.10\) \(0.0100\) \(1.00\)
    第 5 轴 \(0.16\) \(0.0256\) \(2.56\)
    第 4 轴 \(0.16\) \(0.0256\) \(2.56\)
    第 2 轴 \(0.85\) \(0.7225\) \(72.25\)

    （2）影响最大的关节。

    是第 2 轴（肩关节），贡献 \(0.7225\ \text{kg}\cdot\text{m}^2\)， 是第 6 轴的 72.25 倍

    为什么差距这么大：距离从 \(0.10\) 涨到 \(0.85\) 只涨了 \(8.5\) 倍， 但平方之后涨了 \(8.5^2 = 72.25\) 倍。 平方关系意味着「远离轴线的质量」代价按距离的平方放大

    这条结论直接解释了案例一的设计动机： 案例一之所以把电机全部放到肩部附近、用长传动链把动力送到腕部， 就是为了不让电机本身成为那个「远离轴线的质量」。 一个装在腕部的电机，对肩关节的惯量贡献， 会远大于它装在地面基座上的时候

    （3）补偿办法。

    办法 原理 代价
    加配重 在肩关节另一侧加质量，抵消重力矩 惯量进一步增加，可能得不偿失 ⚠
    加大减速比 负载惯量归算到电机侧要除以 \(N^2\) 关节变慢
    换大电机 直接用更大的扭矩 重量与体积上升，又回到同一问题
    降低加速度 减小 \(\dot\omega\)，需要的力矩就小 节拍变慢
    把工具做轻 从源头减少 \(\Delta m\) 有时是唯一划算的办法 ✓

    注意「加配重」这条为什么常常不划算： 配重本身也有质量，它同样按 \(r^2\) 贡献惯量。 只有当手臂长时间停在固定姿态、重力矩是主要负担时，配重才真正划算

    结论：末端 \(1\ \text{kg}\) 对肩关节的惯量贡献约 \(0.7225\ \text{kg}\cdot\text{m}^2\)， 是它对最后一个腕关节贡献的 \(72.25\) 倍； 这个平方关系是「电机尽量靠近基座」这条设计原则的最终依据。

    例题 4：为一项任务选定构型与传动方案¶

    某任务要在一个人体表面上移动一个超声探头，要求：

    • 探头始终贴住皮肤，接触力不能太大也不能太小；
    • 探头要能在保持接触的同时绕自身轴自转，以便改变扫描切面；
    • 工作范围是一个大约 \(0.3\ \text{m} \times 0.3\ \text{m} \times 0.2\ \text{m}\) 的区域；
    • 机器不能太重，末端要足够细，能伸进狭小空间；
    • 一旦控制出错，机器不能压伤人体。

    （1） 需要几个自由度？为什么？ （2） 腕部为什么要做成三轴相交？如果不相交会怎样？ （3） 传动方案上，选「远端长传动链」还是「一体化关节」？说明理由。 （4） 安全上必须加哪些机构保护？

    思路

    逐条把需求翻译成机构语言： 「探头位置」= 3 个定位自由度；「探头朝向 + 自转」= 2 ～ 3 个姿态自由度。 腕部问题的关键在位置与姿态要不要解耦。 传动方案的取舍要看末端重量和关节体积。 安全那一条要回想「保护装置从软到硬的四层」。

    解答

    （1）需要几个自由度。

    逐条列：

    需求 需要的量 个数
    探头到达指定位置 空间 3 个坐标 \(3\)
    探头指向指定方向 朝线的 2 个方向角 \(2\)
    探头绕自身轴自转（改扫描切面） 自转 1 个角 \(1\)
    合计 \(6\)

    所以需要六个自由度 注意自转这一条不能省：超声扫描要改变切面， 靠的是探头绕自身轴的转动，这是一个独立的自由度， 不能靠「改变指向」来替代 ⚠

    （2）腕部为什么三轴相交。

    必须三轴相交，理由有二：

    理由 说明
    位置与姿态解耦 腕部转动不改变腕心位置，前 3 轴只管送到位、后 3 轴只管摆姿态，可以分开解 ✓
    有封闭解，控制快 探头要实时贴住皮肤微调，控制周期必须短，不能靠迭代 ⚠

    如果不相交会怎样：

    后果 说明
    位置与姿态耦合 腕部一转，探头尖端的位置也跟着漂，前三个关节必须反复补偿
    只能数值迭代 求解变慢，实时性差
    贴皮肤的力控变难 位置漂移会直接变成接触力波动，可能压伤或脱离

    （3）传动方案的选择。

    要权衡的是「末端重量」与「关节体积」。比较：

    方案 末端重量 关节体积 装配难度 适合本例吗
    远端长传动链 轻 ✓ 细 ✓ 高（链长、回差难控） 部分适合
    一体化关节（小电机 + 小型减速器） 较重 ⚠ 较粗 ⚠ 低 ✓ 更合适 ✓
    自制齿轮副（逐关节定制） 可控 按空间定制 ✓ 高 ⚠ 最合适 ✓

    本例选第三种（逐关节自制齿轮副），近似一体化思路但要更轻。 理由：

    理由 说明
    工作范围小 只需要 \(0.3\ \text{m}\) 量级的区域，臂可以做得短而轻 ✓
    要求细 末端要伸进狭小空间，关节必须做薄，标准一体化模块太粗 ⚠
    扭矩需求小 负载只有探头，不需要大传动比的大减速器
    自制件可控 可以按可用空间设计齿轮副与轴承座 ✓

    注意：这正是本课程课件案例三的做法 —— 小型步进电机 + 一级齿轮副 + 轴承 + 键连接， 没有用大传动比的成品减速器，因为这个任务根本不需要

    （4）安全上必须加的机构保护。

    按「从软到硬」的四层组织：

    层次 装置 保护什么
    软件层 软件限位 + 力反馈限幅 正常工作时限速、限力
    机械层 机械限位块 软件失效时兜底，防止转角越界
    传动层 离合器（过载打滑） 探头被顶住时卸掉扭矩，不扭坏传动链 ✓
    断电层 失电制动器（抱闸） 断电时防止手臂在重力下自行落下 ⚠

    本例还特别需要两点：

    特殊要求 做法
    不能压伤人体 末端加定制力传感器，把接触力闭环到控制里
    要能被动退让 结构上留被动柔顺（弹性环节），使意外碰撞时能退开

    关键提醒：对接触人体的任务， 「位置控制」本身是不够的，必须把力作为反馈量。 这也是本课程课件案例三在末端画出「定制力传感器结构」的原因

    结论：需要 \(6\) 个自由度； 腕部必须三轴相交以获得解耦与封闭解； 传动上采用逐关节定制的轻量齿轮副而非通用一体化模块； 保护上必须配齐「软件限位 → 机械限位 → 离合器 → 制动器」四层， 并额外加入力反馈与被动柔顺。

    十、自测¶

    Q1 判断对错并说明理由。

    （a）只要一台六自由度机器人有封闭解，它对空间中的任意位姿就都能到达。

    （b）腕部做成三轴相交之后，逆运动学就可以分成「先解位置、再解姿态」两步。

    （c）案例一那种「电机放在肩部、用长传动链传到腕部」的做法，是为了省电机数量。

    （d）「三个相邻关节轴相互平行」和「三个相邻关节轴相交于一点」都能带来封闭解。

    答案

    （a）错 「有封闭解」说的是能写出解析表达式，不是任意位姿都能到达。 下面这些情况仍然无解或不可用：

    情形 后果
    目标点超出工作空间 位置方程无解（根号内出现负数）
    解出的关节角超出行程限位 数学有解、机械做不到
    落在奇异位形 有解但需要无穷大的关节速度

    （b）对 ✓ 三轴相交意味着三条腕轴交于同一点（腕心）， 腕部转动不改变腕心位置，所以工具尖点的位置只由前 3 个关节决定。 于是可以先把前 3 个角解出来，再回代解后 3 个角。 前提是工具尖点相对腕心的偏移量固定，否则这一步还要多一次补偿。

    （c）错 ⚠ 省的不是电机数量，而是末端重量更重要。 真正的动机是：质量对转动惯量的贡献是 \(\Delta m\, r^2\)， 越靠末端的质量被平方放大。 把电机挪到臂根，是让重物远离末端，从而同时减少多个关节的惯量负担。 如果只是为了省电机，就近驱动反而更简单。

    （d）对 ✓ 这正是 Pieper 准则给出的两个充分条件。 工程上两条路都在用：传统工业臂多用「三轴相交」， 模块化协作臂多用「三轴平行」。 两者都能避免数值迭代，但对制造工艺的要求不同。

    Q2 某机构的三个参数如下，请判断并计算。

    某关节使用的电机额定扭矩 \(2.0\ \text{N}\cdot\text{m}\)， 减速器减速比为 \(N = 80\)，效率 \(\eta = 0.75\)。

    （1）关节输出扭矩是多少？ （2）若负载惯量为 \(0.04\ \text{kg}\cdot\text{m}^2\)，归算到电机侧的负载惯量是多少？ （3）这个归算值对控制有什么好处？

    提示

    输出扭矩用 \(\tau_{\text{out}} = N\eta\tau_{\text{in}}\)； 负载惯量归算要除以 \(N^2\eta\)：\(J_{\text{ref}} = \dfrac{J_{\text{load}}}{N^2\eta}\)。 第三问要想「电机实际要拖动多大的等效惯量」。

    答案

    （1）关节输出扭矩。

    \[\tau_{\text{out}} = N\eta\tau_{\text{in}} = 80 \times 0.75 \times 2.0\]

    先算系数：

    \[80 \times 0.75 = 60\]

    所以：

    \[\tau_{\text{out}} = 60 \times 2.0 = 120\ \text{N}\cdot\text{m}\]

    （2）归算到电机侧的负载惯量。

    先算分母：

    \[N^2\eta = 80^2 \times 0.75 = 6400 \times 0.75 = 4800\]

    所以：

    \[J_{\text{ref}} = \frac{0.04}{4800} \approx 0.0000083\ \text{kg}\cdot\text{m}^2\]

    也就是约 \(8.3 \times 10^{-6}\ \text{kg}\cdot\text{m}^2\)

    （3）对控制的好处。

    电机要驱动的等效惯量，从「\(0.04\)」降到「\(0.0000083\)」， 缩小了 \(4800\) 倍 ⚠ 好处有两层：

    好处 说明
    响应快 惯量越小，同样的扭矩下角加速度越大，能跟得上快速指令
    容易稳定 负载惯量与电机转子惯量的比值越小，位置环越容易调稳

    但也要注意代价：

    代价 说明
    关节变慢 转速被缩小了 \(N\) 倍，最高速受限
    回差 减速器的齿隙会带来传动误差，反向运动时尤其明显 ⚠
    效率损失 \(\eta\) 不到 \(1\)，一部分功率变成热

    所以减速比不是越大越好： 扭矩和惯量都随 \(N\)（或 \(N^2\)）改善， 但速度和精度反过来变差，最后要按任务需求折中

    Q3 某六轴机械臂的大臂质量 \(12\ \text{kg}\)，重心到肩关节轴线 \(0.30\ \text{m}\)； 小臂与末端合计 \(8\ \text{kg}\)，作用点到肩关节轴线 \(0.60\ \text{m}\)。

    （1）肩关节在手臂水平伸出时承受多大的重力力矩？ （2）若改用一块 \(r_c = 0.30\ \text{m}\) 的配重来完全平衡，配重需要多重？ （3）这个结果说明什么？实际应该怎么做？

    答案

    （1）水平伸出时的重力力矩。

    手臂水平伸出时，重力的作用线与关节轴线的垂直距离就是各质心到轴线的距离， 重力矩为：

    \[\tau_g = m_1 g r_1 + m_2 g r_2\]

    代入 \(m_1 = 12\)、\(r_1 = 0.30\)、\(m_2 = 8\)、\(r_2 = 0.60\)、\(g = 9.81\)：

    第一项：

    \[m_1 g r_1 = 12 \times 9.81 \times 0.30 = 117.72 \times 0.30 = 35.316\ \text{N}\cdot\text{m}\]

    第二项：

    \[m_2 g r_2 = 8 \times 9.81 \times 0.60 = 78.48 \times 0.60 = 47.088\ \text{N}\cdot\text{m}\]

    相加：

    \[\tau_g = 35.316 + 47.088 = 82.404\ \text{N}\cdot\text{m}\]

    注意：这个值是最大值，因为水平伸出时力臂最长。 手臂抬到竖直位置时力臂为零，重力矩也降为零。式子是：

    \[\tau_g(\theta) = -82.404\cos\theta\]

    其中 \(\theta\) 是从水平位置算起的俯仰角

    （2）配重需要多重。

    配重产生的平衡力矩要与上面相等（力臂方向相反）：

    \[m_c g r_c = m_1 g r_1 + m_2 g r_2\]

    两边约掉 \(g\)：

    \[m_c r_c = m_1 r_1 + m_2 r_2 = 12 \times 0.30 + 8 \times 0.60 = 3.6 + 4.8 = 8.4\ \text{kg}\cdot\text{m}\]

    代入 \(r_c = 0.30\ \text{m}\)：

    \[m_c = \frac{8.4}{0.30} = 28\ \text{kg}\]

    配重需要 \(28\ \text{kg}\) ⚠ —— 比大臂本体的 \(12\ \text{kg}\) 还重一倍多。

    （3）这说明什么，实际怎么做。

    说明：配重的质量与力臂成反比。 力臂短了，质量就要大；把配重放在短力臂上是很不划算的。

    观察 数据 含义
    被平衡的“质量矩” \(8.4\ \text{kg}\cdot\text{m}\) 这就是要抵消掉的总量
    配重放在 \(r_c = 0.30\) 需要 \(28\ \text{kg}\) 太重大，本末倒置 ⚠
    配重放到 \(r_c = 0.84\) 只需 \(10\ \text{kg}\) 力臂翻倍多，质量降到合理的量级

    实际做法（按优先顺序）：

    做法 说明
    把配重放远 力臂加长，质量按同样比例下降 ✓
    用弹簧平衡机构 弹簧的变力特性天然匹配余弦规律，重量远比配重小 ✓
    用气缸/氮气弹簧平衡 同样提供变力，但需要气源与维护
    不加平衡，靠电机扛 只在负载小、速度低、长时间不动的场合可行

    还要记住一条：配重会带来额外的转动惯量， 因为配重自己也有质量 \(m_c\)，它对关节的惯量贡献是 \(m_c r_c^2\)。 本例取 \(r_c = 0.30\) 时，配重本身的惯量贡献是 \(28 \times 0.30^2 = 2.52\ \text{kg}\cdot\text{m}^2\) —— 不算小 所以平衡方案要力矩和惯量一起算，不能只看力矩。

    Q4 某六轴机械臂的内六角扳手式任务（保持末端位置不变、只转动工具）无法完成， 排查发现：工具尖点到最后一个腕关节轴线的偏移量较大， 且第 4、5、6 轴不相交于一点。

    （1）为什么这个任务完不成？ （2）这三条轴如果不相交，最直接的后果是什么？ （3）如果允许改设计，你会怎么改？改完有什么代价？ （4）如果来不及改设计，软件上有什么补救办法？

    答案

    （1）为什么完不成。

    任务要求是「末端位置不变，只改变姿态」，也就是纯转动的动作。 在腕部三轴相交的机器上，这很容易：让前 3 个关节静止， 只转第 4、5、6 轴，工具尖点绕腕心画圆，腕心不动。

    但这台机器有三轴不相交，于是：

    现象 后果
    腕部一转，工具尖点位置就漂 位置与姿态耦合，转姿态必然带偏位置 ⚠
    位置漂移量随偏置量增大 偏置越大漂得越厉害
    想保持位置就得动前 3 轴补偿 前 3 轴一动，姿态又变了 → 反复迭代

    所以「只转不改位置」这个动作在这台机器上做不到纯腕部实现， 必须前 3 轴和后 3 轴联动才能近似完成 ✓

    （2）最直接的后果。

    拿不到封闭解，位置与姿态不能解耦。

    在腕部三轴相交的机器上，位置方程只含前 3 个关节角， 所以可以「先解位置、再解姿态」； 三轴不相交之后，位置方程里会混进第 4、5、6 轴的角度， 6 个未知数只能联立求解 ➜ 只能用数值迭代

    由此带来一串连锁后果：

    连锁后果 说明
    求解变慢 迭代比解析慢得多，控制周期被拉长
    需要初始值 数值解必须给定关节角初值（常见做法是取零）
    可能收敛到别的解 初值不好时会跳到姿态完全不同的解上
    贴合作业更危险 位置漂移直接变成接触力波动

    （3）允许改设计时怎么改。

    改法 具体措施 代价
    首选：把腕轴挪到相交 调整第 4、5 轴的轴向位置，使三条轴共点 腕部外壳要做成球状，体积与装配难度上升 ⚠
    次选：把偏移量做小 保留偏置但压到很小 仍是耦合，只是漂移变小，没解决根本问题
    改成平行腕 让三条腕轴两两平行 腕部不能像球腕那样绕任意方向摆，姿态范围受限
    加一个冗余关节 用 7 个关节，多出的自由度专门补偿漂移 ✓ 多一套驱动、走线与重量

    （4）来不及改设计时的软件补救。

    办法 说明
    联动补偿 在控制里同时算前 3 轴和后 3 轴，让它们一起动以维持末端点 ✓
    预标定误差模型 事先测出不同腕姿态下的漂移量，做成查表补偿
    降低速度 减慢动作，让数值迭代收敛得更稳
    选好初始值 用上一个时刻的解作为这一次的初值，避免跳到别的解
    力的闭环 对接触型任务，用末端力传感器做闭环，直接压制位置漂移的影响 ✓

    关键认识： 「三轴相交」是运动学上的结构性优势，软件补救只能缓解、不能消除。 它最应该在做构型决策的时候就定下来 —— 这正是本课程课件说「在设计机器人的构型时就要考虑封闭解的存在性」的含义 等结构做完再想办法，代价要大得多。

    十一、小结¶

    要记住的 为什么
    设计剖析与分析是反方向的 分析给定位形算末端；设计从任务倒推构型，没有唯一答案 ✓
    串联开链的自由度等于关节数 开链不像单环闭链那样被机架锁掉自由度
    单环机构（如四杆）只要 1 个输入 自由度 1 指的是独立输入只有一个，末端轨迹由取点位置决定
    案例一 = 经典工业臂，长传动链铺满整条臂 课件用基座剖面与两张传动链爆炸图说明「简单外形 + 复杂内部」
    越靠基座的关节做得越粗壮 它要承载整条手臂与负载，且力臂最长、倾覆力矩最大
    动力尽量从臂根送到末端（远端驱动） 质量对惯量的贡献是 \(\Delta m r^2\)，越靠末端被平方放大 ⚠
    腕部三轴相交 → 位置与姿态解耦 前 3 轴定腕心位置，后 3 轴只改姿态，6 个未知数拆成 3 + 3 ✓
    解耦的价值在「解起来多贵」 线性方程组规模从 \(36\) 降到 \(9\)，控制周期直接受益
    案例二 = 一体化关节 电机 + 减速器 + 驱动器 + 编码器整合进一个可独立更换的模块
    RV / 谐波 / 行星三种减速器的分工 RV 刚度高承载大；谐波单级比大体小；行星效率高结构紧凑
    减速器用转速换扭矩，并把负载惯量除以 \(N^2\) 这是关节既能出力又快响应的数学原因 ✓
    一体化关节必须带中空走线孔 线缆从关节中心穿过，关节转动不改变线缆路径
    案例三 = 科研任务驱动的定制臂 八页图讲的就是「任务 → 构型 → 逐关节传动 → 末端接口」
    定制臂也照用三轴相交的腕 因为它同样需要封闭解、需要实时控制 ⚠
    过载保护装在最危险的关节上 定制臂第 2 关节画出了离合盘 + 球弹簧
    键连接保证「可拆且可重复装配」 六角键既传扭矩又定心，便于维修与重装
    末端是定制臂的最终难点 空间最小、受力最杂、要装力传感器、还需可换接口
    Pieper 准则的两个充分条件 三轴相交，或三轴平行；满足其一就有封闭解 ✓
    有封闭解 ≠ 任意位姿都能到 超工作空间、超行程限位、奇异位形都会让解不可用 ⚠
    偏置腕会让腕心跑动 末端位置随腕姿态漂移，且只能靠数值迭代求解
    重力矩随姿态按余弦变化 手臂水平伸出时最大；\(\tau_g(\theta) = -Gr\cos\theta\)
    配重质量与力臂成反比 力臂短就得用大质量，常常不划算；弹簧平衡更轻 ✓
    配重不一定省电 它只平衡重力，不帮加减速，还额外增加惯量 ⚠
    保护要分四层：软件限位 → 机械限位 → 离合器 → 制动器 从软到硬逐层兜底，接触人体的任务尤其不能省
    三个案例是同一运动学骨架的三种工程实现 差别全在「传动怎么放」和「保护怎么做」上 ✓
