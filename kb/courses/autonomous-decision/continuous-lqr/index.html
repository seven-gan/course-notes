    连续时间最优控制¶

    上一页的状态方程是差分式 \(\boldsymbol{x}_{k+1}=A\boldsymbol{x}_k+B\boldsymbol{u}_k\)。 这一页换成微分式：

    \[ \dot{\boldsymbol{x}}(t) = A\boldsymbol{x}(t) + B\boldsymbol{u}(t) \]

    代价也从"求和"变成"积分"：

    \[ J = \frac12\boldsymbol{x}^{\mathsf T}(t_f)S\boldsymbol{x}(t_f) + \frac12\int_{t_0}^{t_f} \left(\boldsymbol{x}^{\mathsf T}Q\boldsymbol{x} + \boldsymbol{u}^{\mathsf T}R\boldsymbol{u}\right)\mathrm{d}t \]

    这两处替换带来一个技术问题：求和可以直接对离散变量求偏导， 而积分里的 \(\boldsymbol{u}(t)\) 是一条函数曲线—— 对函数求极值需要新工具，这就是变分法。

    一、变分法的三个基本概念¶

    1.1 泛函与变分¶

    泛函是"函数的函数"：输入一条曲线 \(u(t)\)，输出一个数 \(J[u]\)。 上面那个代价 \(J\) 就是一个泛函。

    变分 \(\delta J\) 是泛函的"微分"： 在曲线 \(u\) 上叠加一个微小扰动 \(\delta u\)，看 \(J\) 变了多少。

    \[ J[u+\delta u] - J[u] = \underbrace{\delta J}_{一阶} + \underbrace{O(\delta u^2)}_{高阶} \]

    取极值的必要条件与静态优化完全平行：

    \[ \delta J = 0 \]

    这个平行关系值得注意：静态优化求 \(\nabla L=0\)， 变分法求 \(\delta J=0\) —— 同一条思路，只是"变量"从向量换成了函数。

    1.2 为什么扰动要在端点取零¶

    推导中会用到分部积分：

    \[ \int_{t_0}^{t_f}\lambda^{\mathsf T}\,\delta\dot{\boldsymbol{x}}\,\mathrm{d}t = \left[\lambda^{\mathsf T}\delta\boldsymbol{x}\right]_{t_0}^{t_f} - \int_{t_0}^{t_f}\dot{\lambda}^{\mathsf T}\,\delta\boldsymbol{x}\,\mathrm{d}t \]

    边界项 \(\left[\cdot\right]\) 里是 \(\delta\boldsymbol{x}(t_0)\) 与 \(\delta\boldsymbol{x}(t_f)\)。 若初末状态固定，那么扰动在这两端必须为零：

    \[ \delta\boldsymbol{x}(t_0) = \delta\boldsymbol{x}(t_f) = \boldsymbol{0} \]

    这样边界项才消失，剩下的积分才给出可用的方程。 若末端自由，边界项不消失，就会多出横截条件 （用它反解末端协态，见第四节）。

    1.3 用拉格朗日乘子把动态约束接进来¶

    与离散情形一样，引入协态 \(\boldsymbol{\lambda}(t)\)， 把微分方程约束乘上 \(\boldsymbol{\lambda}^{\mathsf T}\) 加进被积函数：

    \[ \mathcal{J} = \frac12\boldsymbol{x}^{\mathsf T}(t_f)S\boldsymbol{x}(t_f) + \int_{t_0}^{t_f}\left[\frac12\left(\boldsymbol{x}^{\mathsf T}Q\boldsymbol{x} + \boldsymbol{u}^{\mathsf T}R\boldsymbol{u}\right) + \boldsymbol{\lambda}^{\mathsf T}\left(A\boldsymbol{x} + B\boldsymbol{u} - \dot{\boldsymbol{x}}\right)\right]\mathrm{d}t \]

    被积函数中"被积的那个函数"有个名字：

    \[ H(\boldsymbol{x},\boldsymbol{u},\boldsymbol{\lambda}) = \frac12\left(\boldsymbol{x}^{\mathsf T}Q\boldsymbol{x} + \boldsymbol{u}^{\mathsf T}R\boldsymbol{u}\right) + \boldsymbol{\lambda}^{\mathsf T}\left(A\boldsymbol{x}+B\boldsymbol{u}\right) \]

    这就是哈密顿函数。它在最优控制里的地位相当于静态优化里的拉格朗日函数。

    二、一阶条件¶

    对 \(\mathcal{J}\) 取变分并令其为零，得到三组方程。

    对 \(\boldsymbol{u}\) 求导（\(H\) 里 \(\boldsymbol{u}\) 只出现在二次项与 \(\boldsymbol{\lambda}^{\mathsf T}B\boldsymbol{u}\) 中）：

    \[ \frac{\partial H}{\partial\boldsymbol{u}} = R\boldsymbol{u} + B^{\mathsf T}\boldsymbol{\lambda} = \boldsymbol{0} \;\Longrightarrow\; \boxed{\ \boldsymbol{u} = -R^{-1}B^{\mathsf T}\boldsymbol{\lambda}\ } \]

    对 \(\boldsymbol{\lambda}\) 求导给出状态方程（约束本身）：

    \[ \dot{\boldsymbol{x}} = \frac{\partial H}{\partial\boldsymbol{\lambda}} = A\boldsymbol{x} + B\boldsymbol{u} \]

    对 \(\boldsymbol{x}\) 求导（配合分部积分）给出协态方程：

    \[ \dot{\boldsymbol{\lambda}} = -\frac{\partial H}{\partial\boldsymbol{x}} = -Q\boldsymbol{x} - A^{\mathsf T}\boldsymbol{\lambda} \]

    这三式合起来就是连续时间的完整一阶条件。它们的形式很像 Hamilton 方程：

    \[ \dot{\boldsymbol{x}} = \frac{\partial H}{\partial\boldsymbol{\lambda}}, \qquad \dot{\boldsymbol{\lambda}} = -\frac{\partial H}{\partial\boldsymbol{x}} \]

    注意符号的对称性：一个正、一个负。 这不是巧合，而是 \(H\) 同时含 \(\boldsymbol{x}\) 与 \(\boldsymbol{\lambda}\) 的结果。

    这组方程不能直接积分——两端条件分居首尾

    状态方程给 \(\boldsymbol{x}(t_0)\) 处的初值条件， 协态方程给 \(\boldsymbol{\lambda}(t_f)\) 处的终端条件（下节给出）。 一个在前、一个在后 → 两点边值问题 ⚠

    这与离散情形（上一页）完全同构。 解法也是同构的：猜协态与状态成正比，把问题化为矩阵方程。

    三、连续时间 LQR¶

    3.1 关键猜测¶

    设协态与状态成线性关系：

    \[ \boldsymbol{\lambda}(t) = P(t)\,\boldsymbol{x}(t) \]

    为什么这个假设合理：代价是二次的、动态是线性的， 所以最优控制的三个量（控制、状态、协态）都应是彼此的线性函数。

    3.2 代入并消去状态¶

    对假设求导：

    \[ \dot{\boldsymbol{\lambda}} = \dot{P}\boldsymbol{x} + P\dot{\boldsymbol{x}} \]

    把协态方程与状态方程代入，并用 \(\boldsymbol{u}=-R^{-1}B^{\mathsf T}P\boldsymbol{x}\)：

    \[ \dot{P}\boldsymbol{x} + P\left(A\boldsymbol{x} - BR^{-1}B^{\mathsf T}P\boldsymbol{x}\right) = -Q\boldsymbol{x} - A^{\mathsf T}P\boldsymbol{x} \]

    因为这对任意 \(\boldsymbol{x}\) 成立，矩阵本身必须满足：

    \[ -\dot{P} = PA + A^{\mathsf T}P - PBR^{-1}B^{\mathsf T}P + Q \]

    整理成标准形式：

    \[ \boxed{\ -\dot{P} = A^{\mathsf T}P + PA + Q - PBR^{-1}B^{\mathsf T}P\ } \]

    这就是连续时间黎卡提方程。

    3.3 终端条件与增益¶

    边界项给出终端条件：

    \[ P(t_f) = S \]

    于是黎卡提方程要从 \(t_f\) 反向积分到 \(t_0\) —— 与离散情形反向递推对应。

    解出 \(P(t)\) 后，最优控制是时变状态反馈：

    \[ \boldsymbol{u}(t) = -K(t)\boldsymbol{x}(t), \qquad K(t) = R^{-1}B^{\mathsf T}P(t) \]

    3.4 与离散情形对照¶

    离散（上一页） 连续（本页）
    动态 \(\boldsymbol{x}_{k+1}=A\boldsymbol{x}_k+B\boldsymbol{u}_k\) \(\dot{\boldsymbol{x}}=A\boldsymbol{x}+B\boldsymbol{u}\)
    代价 求和 积分
    求解工具 矩阵递推 变分法
    黎卡提 \(S_k=Q+A^{\mathsf T}S_{k+1}(\cdot)^{-1}A\) \(-\dot{P}=A^{\mathsf T}P+PA+Q-PBR^{-1}B^{\mathsf T}P\)
    方向 从 \(N\) 反向递推 从 \(t_f\) 反向积分
    控制 \(\boldsymbol{u}_k=-K_k\boldsymbol{x}_k\) \(\boldsymbol{u}(t)=-K(t)\boldsymbol{x}(t)\)

    两侧的形式一一对应，连"反向"这一点都一样。

    为什么两侧用了不同字母

    教材第 2 章（离散）用 \(S_k\)，第 3 章（连续）用 \(P(t)\) —— 沿用的是教材的习惯，本页也跟着用，方便你对照原书。

    两者的角色完全相同：都是"剩余代价的二次型系数矩阵"， 区别只在离散用下标、连续用时间变量。 对照时可以把 \(S_k\) 与 \(P(t)\) 看成同一个东西。

    反向积分的结果很有规律：\(P(t)\) 很快趋于稳态。

    以终端条件 \(P(t_f)=2\)、系统 \(\dot x=u\) 为例：

    往回走的时刻 \(t\) \(P(t)\)
    5.0（终端） 1.997
    4.0 1.094
    3.0 1.012
    2.0 1.002
    1.0 1.0002

    可见离开终端约 3 个时间单位后，\(P(t)\) 就已经接近稳态值 \(P=1\)。

    这正是下一节"稳态控制"的依据： 若任务时长远大于这个"收敛时间"， 就可以直接用常数增益 \(K\)，不必存整条 \(K(t)\)。

    四、稳态控制与次优反馈¶

    4.1 稳态黎卡提方程¶

    当 \(t_f\) 足够远时 \(P(t)\) 趋于常数，令 \(\dot{P}=0\)：

    \[ A^{\mathsf T}P + PA + Q - PBR^{-1}B^{\mathsf T}P = \boldsymbol{0} \]

    这叫代数黎卡提方程（ARE）。它给出常数增益：

    \[ K = R^{-1}B^{\mathsf T}P \]

    工程意义：只需离线解一次矩阵方程，在线做一次矩阵乘向量即可， 与离散稳态情形完全一致。

    4.2 末端自由时的横截条件¶

    若末端不固定，1.2 节那个边界项不消失，而是给出：

    \[ \boldsymbol{\lambda}(t_f) = \frac{\partial\phi}{\partial\boldsymbol{x}(t_f)} \]

    其中 \(\phi\) 是末端代价。这一条叫横截条件，它替代了"末端固定"这个信息。

    若末端完全自由且无末端代价（\(\phi=0\)），则：

    \[ \boldsymbol{\lambda}(t_f) = \boldsymbol{0} \]

    即终端协态为零。

    4.3 一次成型与次优反馈¶

    控制方式 增益 代价
    有限时域最优 时变 \(K(t)\) 需存整条 \(K(t)\)，实现复杂
    稳态最优 常数 \(K\) 只在 \(t_f\to\infty\) 时才真正最优
    次优反馈 用等效准则解出的常数 \(K\) 不是最优，但闭环稳定、实现最简单

    次优反馈的思路：既然稳态增益实现最简单， 那就换一个二次型准则（而非原始准则），使它的稳态解恰好给出想要的闭环特性。 代价是"不再最优"，收益是"可实现且稳定"。

    这个取舍在工程上非常常见：最优性让位于可实现性。

    这组数给出了一条实用判据： 终端时间较短时时变效应不可忽略，必须用 \(K(t)\)； \(t_f\) 足够大（本例约 5 倍时间常数以上）后，稳态增益就够用了。

    五、例题¶

    例题 1：求一维 LQR 的最优控制¶

    题目：\(\dot{x}=u\)，\(Q=1\)、\(R=1\)、\(S=1\)、\(t_f\) 很大。 求稳态增益 \(K\) 与闭环极点。

    思路

    这是积分器模型（\(a=0\)、\(b=1\)）， 先解代数黎卡提方程，再代入 \(K=R^{-1}BP\)。

    解答

    第一步：代数黎卡提方程。

    \(a=0\)、\(b=1\)、\(q=1\)、\(r=1\)，代入 \(a^{\mathsf T}P+Pa+q-Pbr^{-1}b^{\mathsf T}P=0\)：

    \[ 0 + 0 + 1 - P\cdot 1\cdot 1\cdot P = 0 \;\Longrightarrow\; P^2 = 1 \]

    取正根（\(P\) 必须正定）：

    \[ P = 1 \]

    第二步：增益。

    \[ K = R^{-1}BP = 1\times1\times1 = 1 \]

    第三步：闭环极点。

    \[ \dot{x} = -Kx = -x \;\Longrightarrow\; \text{极点 } s = -1 \]

    答案：\(P=1\)、\(K=1\)，闭环极点在 \(-1\)。

    它在左半平面，所以闭环稳定。

    例题 2：为什么 \(Q\) 增大闭环更快¶

    题目：承上题，若 \(Q=4\)（\(R\) 不变），求新的 \(K\) 与闭环极点。

    思路

    同样解 \(P^2=Q\)。

    解答

    代数黎卡提方程变为 \(Q-P^2=0\)，即

    \[ P = \sqrt{Q} = 2 \]

    于是

    \[ K = P = 2,\qquad \text{闭环极点 } s = -2 \]

    极点从 \(-1\) 左移到 \(-2\)，收敛更快。

    规律：对积分器模型有 \(K=\sqrt{Q/R}\) —— 增益随 \(Q/R\) 按平方根增长。 所以想把响应速度提高一倍，\(Q\) 要提高到四倍。

    例题 3：横截条件的作用¶

    题目：若末端完全自由且无末端代价，终端协态是多少？ 它如何替代"末端固定"这个信息？

    思路

    横截条件来自分部积分的边界项。

    解答

    横截条件为 \(\boldsymbol{\lambda}(t_f)=\partial\phi/\partial\boldsymbol{x}(t_f)\)。 末端无代价即 \(\phi=0\)，所以

    \[ \boldsymbol{\lambda}(t_f) = \boldsymbol{0} \]

    因为 \(\boldsymbol{\lambda}=P\boldsymbol{x}\)，而 \(\boldsymbol{x}(t_f)\) 未知， 所以这要求 \(P(t_f)=\boldsymbol{0}\)。

    它替代了什么：黎卡提方程是一阶矩阵微分方程， 只需要一个边界条件就能定解。 末端固定时靠 \(\boldsymbol{x}(t_f)\) 定，末端自由时就靠这条横截条件定 —— 两者都是"补足唯一性所需的那一个条件"。

    例题 4：什么时候能用稳态增益¶

    题目：某系统用连续 LQR，\(t_f=0.5\) s 时整条 \(P(t)\) 相对稳态的偏差约 0.6， \(t_f=20\) s 时降到 0.001 以下。工程上该怎么选？

    思路

    比较"任务实际时长"与"黎卡提方程收敛到稳态所需的时间"。

    解答

    第一步：读数据。

    \(t_f\) 偏差 判断
    0.5 s 0.6 时变效应显著，稳态增益不可用
    20 s 小于 0.001 稳态增益够用

    第二步：工程选择。

    任务时长 该用 原因
    与收敛时间可比 时变 \(K(t)\) 稳态假设不成立
    远大于收敛时间 常数 \(K\) 离线算一次，在线最省

    答案：短任务用时变增益，长任务用稳态增益。

    附带提醒：若末端有硬约束（要求精确到达某状态）， 时变增益不可省 —— 因为这正是终端条件起作用的时段。

    小结¶

    内容 关键结论
    变分法 泛函取极值的条件是 \(\delta J=0\)，与 \(\nabla L=0\) 平行
    哈密顿函数 \(H=\frac12(\boldsymbol{x}^{\mathsf T}Q\boldsymbol{x}+\boldsymbol{u}^{\mathsf T}R\boldsymbol{u})+\boldsymbol{\lambda}^{\mathsf T}(A\boldsymbol{x}+B\boldsymbol{u})\)
    一阶条件 \(\dot{\boldsymbol{x}}=\partial H/\partial\boldsymbol{\lambda}\)，\(\dot{\boldsymbol{\lambda}}=-\partial H/\partial\boldsymbol{x}\)，\(\partial H/\partial\boldsymbol{u}=0\)
    两端条件 状态给初值、协态给终端值 → 两点边值问题
    黎卡提方程 \(-\dot{P}=A^{\mathsf T}P+PA+Q-PBR^{-1}B^{\mathsf T}P\)，从 \(t_f\) 反向积分
    稳态 令 \(\dot{P}=0\) 得代数黎卡提方程，增益变常数
    次优反馈 用等效准则换实现简单，放弃最优性
