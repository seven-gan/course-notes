    动态规划¶

    前两页用的是同一条思路：写出最优性条件，然后猜一个解的形式。 这一页换一条完全不同的路。

    核心想法：不要一次性解整个 \(N\) 步问题，而是从最后一步倒着走， 每一步只解决"从当前时刻到终点"这一个子问题。

    \[ \text{把 } N \text{ 步的联合优化} \quad\Longrightarrow\quad N \text{ 个单步问题的序列} \]

    为什么这样能行：最优策略有一个特殊性质 —— 它的任何后缀也是最优的。这个性质叫最优性原理， 是整章的支点。

    一、最优性原理¶

    1.1 陈述¶

    最优性原理：从最优轨道的任意中间时刻出发， 剩余部分仍然是从该时刻到终点的最优轨道。

    反证很直接：若剩余部分不是最优的， 那把它换成更优的那条，整条轨道就会变更好 —— 与"原轨道已是最优"矛盾。

    注意这个性质并不平凡：它成立是因为"未来只依赖当前状态， 不依赖如何到达这里"。若系统有记忆（依赖历史），这条就不成立。

    1.2 它给出的递推结构¶

    设值函数为"从状态 \(\boldsymbol{x}\) 出发、还剩 \(k\) 步时的最小代价"：

    \[ V_k(\boldsymbol{x}) = \min_{\boldsymbol{u}_k,\dots,\boldsymbol{u}_{N-1}} \left[\text{从 } \boldsymbol{x} \text{ 到终点的代价}\right] \]

    最优性原理把它变成一个递推：

    \[ V_k(\boldsymbol{x}) = \min_{\boldsymbol{u}} \left\{g(\boldsymbol{x},\boldsymbol{u}) + V_{k+1}\left(f(\boldsymbol{x},\boldsymbol{u})\right)\right\} \]

    逐项读： \(g(\boldsymbol{x},\boldsymbol{u})\) 是这一步的即时代价， \(V_{k+1}(f(\boldsymbol{x},\boldsymbol{u}))\) 是"走完这一步之后， 从新状态出发的最小剩余代价"。

    这个式子就是动态规划的核心（叫 Bellman 方程）。 它把"\(k\) 步优化"化成"一次 min 加上一个已经算好的 \(k-1\) 步结果"。

    求解方向是从后往前：先算 \(V_0\)（只剩末一步）， 再算 \(V_1\)，…直到 \(V_N\)。

    动态规划要付的代价是「状态空间」

    递推本身很简单，但 \(V_k(\boldsymbol{x})\) 是定义在整个状态空间上的函数。 若状态是连续量，就需要对每个 \(\boldsymbol{x}\) 都能取值 —— 实际只能用离散网格或函数近似 ⚠

    这就是"维数灾难"的来源：状态维数每加一， 网格点数量按指数增长。

    二、离散时间系统¶

    2.1 线性二次情形的递推¶

    取二次代价与线性动态：

    \[ g(\boldsymbol{x}_k,\boldsymbol{u}_k) = \boldsymbol{x}_k^{\mathsf T}Q\boldsymbol{x}_k + \boldsymbol{u}_k^{\mathsf T}R\boldsymbol{u}_k, \qquad \boldsymbol{x}_{k+1} = A\boldsymbol{x}_k + B\boldsymbol{u}_k \]

    猜测值函数也是二次型：

    \[ V_k(\boldsymbol{x}) = \boldsymbol{x}^{\mathsf T}S_k\boldsymbol{x} \]

    为什么这个猜测合理：二次代价 + 线性动态， 最优值函数必然是状态的二次型（与 LQR 同一逻辑）。

    2.2 代入并完成 min¶

    把猜测代入 Bellman 方程：

    \[ \boldsymbol{x}^{\mathsf T}S_k\boldsymbol{x} = \min_{\boldsymbol{u}}\left\{ \boldsymbol{x}^{\mathsf T}Q\boldsymbol{x} + \boldsymbol{u}^{\mathsf T}R\boldsymbol{u} + (A\boldsymbol{x}+B\boldsymbol{u})^{\mathsf T} S_{k+1}(A\boldsymbol{x}+B\boldsymbol{u})\right\} \]

    对 \(\boldsymbol{u}\) 求导并令零（括号内是 \(\boldsymbol{u}\) 的二次型）：

    \[ 2R\boldsymbol{u} + 2B^{\mathsf T}S_{k+1}(A\boldsymbol{x}+B\boldsymbol{u}) = \boldsymbol{0} \]

    解出最优控制：

    \[ \boldsymbol{u}^* = -\left(R + B^{\mathsf T}S_{k+1}B\right)^{-1} B^{\mathsf T}S_{k+1}A\,\boldsymbol{x} \]

    这就是 LQR 的最优增益（记为 \(K_k\)）， 与上一页（离散 LQR）用拉格朗日乘子得到的结果完全一致。

    2.3 代回得到黎卡提递推¶

    把 \(\boldsymbol{u}^*\) 代回并整理，得

    \[ S_k = Q + A^{\mathsf T}S_{k+1} \left(I + BR^{-1}B^{\mathsf T}S_{k+1}\right)^{-1}A \]

    与上一页的黎卡提递推是同一个式子。

    这个巧合值得注意：两页用了完全不同的推导 （其一为拉格朗日乘子 + 变分，其二为最优性原理 + 动态规划）， 却得到同一个结果。这说明二次型问题的结构足够强， 以至于不同的路径都通向同一个答案。

    关键对照：动态规划的反向递推与直接解代数黎卡提方程， 给出的是同一个增益。

    以 \(A=\begin{bmatrix}1 & 0.2\\ 0 & 1\end{bmatrix}\)、 \(B=\begin{bmatrix}0\\1\end{bmatrix}\)、\(Q=I\)、\(R=1\) 为例：

    方法 稳态增益 \(K\)
    动态规划反向递推（\(N=40\)） \([0.5634,\ 0.7952]\)
    代数黎卡提方程直接解 \([0.5634,\ 0.7952]\)

    两者在四位小数上完全一致。

    为什么必然一致：Bellman 方程与黎卡提方程在稳态下是同一个方程 —— 只是推导路径不同（一个用最优性原理逐段递推， 一个用变分法求驻定条件）。结论相同是结构性保证，不是偶然。

    三、连续时间系统¶

    3.1 从离散到连续的极限¶

    把时间步取为 \(\Delta t\)，动态近似为

    \[ \boldsymbol{x}(t+\Delta t) \approx \boldsymbol{x} + \Delta t\cdot \left(A\boldsymbol{x}+B\boldsymbol{u}\right) \]

    代入 Bellman 方程，两边减去 \(\boldsymbol{x}^{\mathsf T}P\boldsymbol{x}\)， 除以 \(\Delta t\) 并令 \(\Delta t\to0\)，就得到连续时间的 Bellman 方程：

    \[ -\frac{\partial V}{\partial t} = \min_{\boldsymbol{u}}\left\{ L(\boldsymbol{x},\boldsymbol{u}) + \left(\frac{\partial V}{\partial\boldsymbol{x}}\right)^{\mathsf T} \left(A\boldsymbol{x}+B\boldsymbol{u}\right)\right\} \]

    其中 \(L\) 是代价率（每单位时间的代价）。

    3.2 哈密顿-雅可比-贝尔曼方程¶

    对 \(\boldsymbol{u}\) 求 min（利用 \(L\) 对 \(\boldsymbol{u}\) 是二次型）：

    \[ \frac{\partial L}{\partial\boldsymbol{u}} + B^{\mathsf T}\frac{\partial V}{\partial\boldsymbol{x}} = \boldsymbol{0} \]

    对

    \[ L=\frac12\left(\boldsymbol{x}^{\mathsf T}Q\boldsymbol{x} +\boldsymbol{u}^{\mathsf T}R\boldsymbol{u}\right) \]

    有 \(\partial L/\partial\boldsymbol{u}=R\boldsymbol{u}\)，于是

    \[ \boldsymbol{u}^* = -R^{-1}B^{\mathsf T}\frac{\partial V}{\partial\boldsymbol{x}} \]

    代回，得到一个关于 \(V\) 的非线性偏微分方程：

    \[ \boxed{\ -\frac{\partial V}{\partial t} = \frac12\boldsymbol{x}^{\mathsf T}Q\boldsymbol{x} + \left(\frac{\partial V}{\partial\boldsymbol{x}}\right)^{\mathsf T}A\boldsymbol{x} - \frac12\left(\frac{\partial V}{\partial\boldsymbol{x}}\right)^{\mathsf T} BR^{-1}B^{\mathsf T}\frac{\partial V}{\partial\boldsymbol{x}}\ } \]

    这就是哈密顿-雅可比-贝尔曼方程（HJB）。

    它为什么重要：HJB 是非线性最优控制的通用方程 —— 不限线性动态、不限二次代价。但它是偏微分方程， 一般没有解析解，只能数值求解。

    3.3 线性二次情形：HJB 退化为黎卡提¶

    对线性二次问题，仍然猜二次型值函数：

    \[ V(\boldsymbol{x},t) = \boldsymbol{x}^{\mathsf T}P(t)\boldsymbol{x} \]

    于是 \(\partial V/\partial\boldsymbol{x} = 2P\boldsymbol{x}\)。 代入 HJB，两边都是 \(\boldsymbol{x}\) 的二次型， 消去 \(\boldsymbol{x}\) 后得到一个矩阵常微分方程：

    \[ -\dot{P} = A^{\mathsf T}P + PA + Q - PBR^{-1}B^{\mathsf T}P \]

    这正是上一页的连续时间黎卡提方程。

    所以三者是同一个东西的三种面孔：

    方法 得到
    变分法（上一页） 黎卡提方程
    动态规划（本页） HJB 方程，线二次时退化为黎卡提方程
    拉格朗日乘子（离散页） 黎卡提递推

    非线性问题只能用 HJB，而 HJB 难解 —— 这正是下一章（强化学习）的出发点： 不解 HJB，而是用数据直接学最优策略。

    残差在所有 \(x\) 上都是零 —— 这说明二次型猜测是正确的， HJB 在线性二次情形下确实退化为矩阵方程。

    四、动态规划的边界与局限¶

    4.1 三种求解思路的对照¶

    变分法 动态规划 强化学习（下一章）
    需要模型 需要 需要 不需要
    得到什么 最优性条件 值函数 + 策略 值函数估计 + 策略
    方程 黎卡提 / 两点边值 HJB / Bellman Bellman（采样版）
    非线性问题 难 HJB 难解 可处理
    主要困难 两点边值 维数灾难 采样效率

    4.2 维数灾难¶

    若状态是 \(n\) 维、每维离散成 \(m\) 个格点， 值函数的存储量是

    \[ m^n \]

    这个增长是指数的。\(n=10\)、\(m=10\) 时就是 \(10^{10}\) 个数值 —— 内存根本放不下。

    所以动态规划在实际中只适合：

    适用情形 为什么
    低维状态（约 \(n\le3\)） 网格可接受
    线性二次问题 值函数是二次型，用矩阵表示（\(n^2\) 个数而非 \(m^n\)）
    有限状态集 状态本来就离散（如棋盘、队列）

    注意第二行：线性二次情形下"值函数是二次型"这个先验 把 \(m^n\) 降成了 \(n^2\) —— 这才是 LQR 能在高维系统中实用的真正原因。

    4.3 与"穷举"的复杂度对比¶

    方法 复杂度 说明
    穷举所有控制序列 \(m^{N}\) 随时间指数增长
    动态规划 \(N\times m^{n}\) 随时间线性，只随状态维数指数

    动态规划的价值就在这里： 它把"随时间指数增长"换成了"随时间线性、 随状态维数指数增长"。

    对长时域问题（\(N\) 很大）这是巨大的改进； 但对高维状态问题（\(n\) 大）它同样不可行。

    五、例题¶

    例题 1：两阶段动态规划¶

    题目：\(\boldsymbol{x}_{k+1}=\boldsymbol{x}_k+\boldsymbol{u}_k\)， 代价 \(J=x_2^2+u_0^2+u_1^2\)，初值 \(x_0=1\)。 用动态规划求 \(u_0^*\)、\(u_1^*\) 与最优代价。

    思路

    从最后一步倒推：先解 \(V_1\)，再解 \(V_2\)。

    解答

    第一步：定义值函数。

    \(V_k(x)\) = 从 \(x\) 出发、还剩 \(k\) 步的最小代价。

    第二步：\(V_1\)（只剩一步）。

    \[ V_1(x) = \min_{u_1}\left[u_1^2 + (x+u_1)^2\right] \]

    对 \(u_1\) 求导：\(2u_1+2(x+u_1)=0\)，得

    \[ u_1^* = -\frac{x}{2}, \qquad V_1(x) = \frac{x^2}{4} + \frac{x^2}{4} = \frac{x^2}{2} \]

    第三步：\(V_2\)（还剩两步）。

    \[ V_2(x) = \min_{u_0}\left[u_0^2 + V_1(x+u_0)\right] = \min_{u_0}\left[u_0^2 + \frac{(x+u_0)^2}{2}\right] \]

    求导：\(2u_0 + (x+u_0) = 0\)，得

    \[ u_0^* = -\frac{x}{3} \]

    第四步：代入初值。

    \[ u_0^* = -\frac{1}{3},\qquad x_1 = 1-\frac13 = \frac23 \]
    \[ u_1^* = -\frac{x_1}{2} = -\frac13 \]
    \[ J^* = V_2(1) = \frac{1}{9} + \frac{1}{2}\cdot\frac{4}{9} = \frac{1}{9}+\frac{2}{9} = \frac13 \]

    答案：\(u_0^*=u_1^*=-\tfrac13\)，\(J^*=\tfrac13\)。

    可以验证此时 \(x_2 = \frac23-\frac13=\frac13\)， 所以 \(J = (\frac13)^2+(\frac13)^2+(\frac13)^2 = \frac13\) ✓

    例题 2：为什么值函数是二次型¶

    题目：说明在线性二次问题中，值函数必然形如 \(V_k(\boldsymbol{x})=\boldsymbol{x}^{\mathsf T}S_k\boldsymbol{x}\)。

    思路

    用归纳法：若 \(V_{k+1}\) 是二次型，看 \(V_k\) 是什么。

    解答

    第一步：基底。

    终端值函数 \(V_0(\boldsymbol{x})=\boldsymbol{x}^{\mathsf T}Q_N\boldsymbol{x}\) 是二次型。

    第二步：归纳步。

    设 \(V_{k+1}(\boldsymbol{x})=\boldsymbol{x}^{\mathsf T}S_{k+1}\boldsymbol{x}\)。 代入 Bellman 方程：

    \[ V_k(\boldsymbol{x}) = \min_{\boldsymbol{u}}\Big\{ \boldsymbol{x}^{\mathsf T}Q\boldsymbol{x} + \boldsymbol{u}^{\mathsf T}R\boldsymbol{u} + (A\boldsymbol{x}+B\boldsymbol{u})^{\mathsf T}S_{k+1} (A\boldsymbol{x}+B\boldsymbol{u})\Big\} \]

    花括号内是 \((\boldsymbol{x},\boldsymbol{u})\) 的联合二次型 （每项都是二次）。

    第三步：完成 min。

    对 \(\boldsymbol{u}\) 求导得到线性方程， 解出 \(\boldsymbol{u}^*=F\boldsymbol{x}\) 是 \(\boldsymbol{x}\) 的线性函数。 把它代回二次型，得到 \(\boldsymbol{x}\) 的二次型。

    结论：\(V_k\) 也是二次型，\(V_k(\boldsymbol{x})=\boldsymbol{x}^{\mathsf T}S_k\boldsymbol{x}\) ✓

    这个结论的价值：值函数只要存一个 \(n\times n\) 矩阵 \(S_k\)， 而不需要在状态网格上存 \(m^n\) 个值 —— 这就是维数灾难的突破口。

    例题 3：动态规划与穷举的复杂度差¶

    题目：\(n=3\) 维状态、每维 \(m=10\) 个格点、\(N=100\) 步。 比较穷举与动态规划的计算量。

    思路

    穷举是 \(m^N\)，动态规划是 \(N\times m^n\)。

    解答

    第一步：穷举。

    \[ m^N = 10^{100} \]

    这是天文数字，完全不可行。

    第二步：动态规划。

    \[ N\times m^n = 100\times 10^3 = 10^5 \]

    第三步：对比。

    \[ \frac{10^{100}}{10^{5}} = 10^{95} \]

    动态规划快了 \(10^{95}\) 倍。

    答案：穷举不可行，动态规划只要 \(10^5\) 次运算。

    但要清醒：这个优势随 \(n\) 迅速消失。 若改成 \(n=10\)、\(m=10\)，动态规划变成 \(100\times10^{10}=10^{12}\)， 又不可行了 —— 这就是维数灾难。

    例题 4：为什么强化学习要放弃模型¶

    题目：HJB 方程在非线性问题上通常解不出来。 强化学习如何绕开这个困难？

    思路

    关键在"要不要知道 \(f\) 与 \(L\)"。

    解答

    第一步：HJB 的困难在哪。

    HJB 是关于 \(V\) 的非线性偏微分方程， 需要知道动态 \(f\) 与代价 \(L\) 才能写出，写出后一般也无解析解。

    第二步：强化学习的绕法。

    它不使用 HJB 本身，而是用 Bellman 方程的采样形式：

    \[ V(\boldsymbol{x}) \approx \mathbb{E}\left[r + \gamma V(\boldsymbol{x}')\right] \]

    其中 \(r\) 与 \(\boldsymbol{x}'\) 都是观测到的（不需要模型预测）。

    第三步：好处与代价。

    需要模型 主要困难
    HJB / 动态规划 需要 方程难解、维数灾难
    强化学习 不需要 采样效率低、方差大

    答案是：强化学习用"大量交互数据"换掉了"模型与解析解"， 于是能处理非线性问题，代价是数据需求量很大。

    小结¶

    内容 关键结论
    最优性原理 最优轨道的任意后缀也是最优的
    Bellman 方程 \(V_k(\boldsymbol{x})=\min_{\boldsymbol{u}}\{g+V_{k+1}(f)\}\)
    求解方向 从终端反向递推
    线性二次 值函数是二次型，退化为黎卡提方程
    HJB 方程 非线性问题的一般最优性条件（偏微分方程，通常无解析解）
    维数灾难 存储量 \(m^n\)，随状态维数指数增长
    LQR 能实用的原因 值函数是二次型 → 只存 \(n^2\) 个数而非 \(m^n\)
