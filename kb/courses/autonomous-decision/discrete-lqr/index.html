    离散时间最优控制¶

    上一页的 \(\boldsymbol{u}\) 是一个固定向量。这一页把它换成序列：

    \[ \boldsymbol{u}_0,\ \boldsymbol{u}_1,\ \dots,\ \boldsymbol{u}_{N-1} \]

    同时系统还有状态演化：

    \[ \boldsymbol{x}_{k+1} = A\boldsymbol{x}_k + B\boldsymbol{u}_k \]

    这两个变化使问题性质完全不同：\(N\) 步的决策互相耦合 —— 今天的控制既影响今天的代价，又通过状态影响之后所有时刻。 不能像静态优化那样"一次解出来"。

    先解决一个前置问题：这种带耦合的问题，用什么方法把约束消掉。

    一、把动态约束写进代价¶

    1.1 问题形式¶

    \[ \min_{\boldsymbol{u}_0,\dots,\boldsymbol{u}_{N-1}} J \]

    其中代价是各步代价之和：

    \[ J = \phi(\boldsymbol{x}_N) + \sum_{k=0}^{N-1}\left(\boldsymbol{x}_k^{\mathsf T}Q\boldsymbol{x}_k + \boldsymbol{u}_k^{\mathsf T}R\boldsymbol{u}_k\right) \]

    逐项读： \(\boldsymbol{x}_k^{\mathsf T}Q\boldsymbol{x}_k\) 惩罚状态偏离原点， \(\boldsymbol{u}_k^{\mathsf T}R\boldsymbol{u}_k\) 惩罚控制能量的消耗， \(\phi(\boldsymbol{x}_N)\) 是末端代价（终端约束的软形式）。

    代价与约束的关系：若让 \(Q\) 或 \(R\) 趋于无穷大， 等价于强制对应的量趋于零 —— 这就是用代价代替硬约束的思路。

    1.2 用拉格朗日乘子消去动态¶

    约束有 \(N\) 个（每个时刻一个），所以引入 \(N\) 个乘子向量 \(\boldsymbol{\lambda}_1,\dots,\boldsymbol{\lambda}_N\)：

    \[ \mathcal{L} = \phi(\boldsymbol{x}_N) + \sum_{k=0}^{N-1}\left[\boldsymbol{x}_k^{\mathsf T}Q\boldsymbol{x}_k + \boldsymbol{u}_k^{\mathsf T}R\boldsymbol{u}_k\right. \left.+ \boldsymbol{\lambda}_{k+1}^{\mathsf T} \left(A\boldsymbol{x}_k + B\boldsymbol{u}_k - \boldsymbol{x}_{k+1}\right)\right] \]

    乘子的物理意义：\(\boldsymbol{\lambda}_k\) 衡量"\(\boldsymbol{x}_k\) 变化一个单位会带来多少代价增量"， 所以它叫协态（costate）。

    1.3 求导得到三组方程¶

    对 \(\boldsymbol{x}_k\) 求导（注意 \(\boldsymbol{x}_k\) 在 \(k\) 与 \(k+1\) 两处出现）：

    \[ \frac{\partial\mathcal{L}}{\partial\boldsymbol{x}_k} = 2Q\boldsymbol{x}_k + A^{\mathsf T}\boldsymbol{\lambda}_{k+1} - \boldsymbol{\lambda}_k = \boldsymbol{0} \]

    整理成协态方程：

    \[ \boldsymbol{\lambda}_k = 2Q\boldsymbol{x}_k + A^{\mathsf T}\boldsymbol{\lambda}_{k+1}, \qquad k = 0,\dots,N-1 \]

    对 \(\boldsymbol{x}_N\) 求导得到终端条件：

    \[ \boldsymbol{\lambda}_N = \frac{\partial\phi}{\partial\boldsymbol{x}_N} \]

    对 \(\boldsymbol{u}_k\) 求导并令零：

    \[ 2R\boldsymbol{u}_k + B^{\mathsf T}\boldsymbol{\lambda}_{k+1} = \boldsymbol{0} \;\Longrightarrow\; \boldsymbol{u}_k = -\frac{1}{2}R^{-1}B^{\mathsf T}\boldsymbol{\lambda}_{k+1} \]

    这三组方程就是离散最优控制的完整一阶条件。它们的形式很有特点：

    方程 方向
    状态方程 前向（\(k\to k+1\)）
    协态方程 后向（\(k+1\to k\)）
    控制方程 代数关系（逐点）

    前向与后向同时出现，这就是"两点边值问题" —— 它不能直接迭代求解，必须找别的结构。

    二、把协态写成状态的线性函数¶

    2.1 关键的猜测¶

    两点边值问题难在"一端给初值、一端给终端条件"。 突破口是猜协态与状态成正比：

    \[ \boldsymbol{\lambda}_k = 2S_k\boldsymbol{x}_k \]

    其中 \(S_k\) 是待定矩阵。这个假设不是凭空来的：它是线性二次问题的 自然形式（代价二次、动态线性 → 最优控制也是线性的）。

    2.2 代入协态方程¶

    把假设代入 \(\boldsymbol{\lambda}_k = 2Q\boldsymbol{x}_k + A^{\mathsf T}\boldsymbol{\lambda}_{k+1}\)：

    \[ 2S_k\boldsymbol{x}_k = 2Q\boldsymbol{x}_k + 2A^{\mathsf T}S_{k+1}\boldsymbol{x}_{k+1} \]

    把状态方程 \(\boldsymbol{x}_{k+1} = A\boldsymbol{x}_k + B\boldsymbol{u}_k\) 与控制律 \(\boldsymbol{u}_k = -R^{-1}B^{\mathsf T}S_{k+1}\boldsymbol{x}_{k+1}\) 代入， 消去 \(\boldsymbol{x}_k\)（对任意 \(\boldsymbol{x}_k\) 成立）， 得到矩阵递推式。

    2.3 黎卡提递推¶

    化简后得到一个矩阵二次递推，称为离散黎卡提方程：

    \[ \boxed{ \begin{aligned} P_k &= Q + A^{\mathsf T}P_{k+1} \left(I + BR^{-1}B^{\mathsf T}P_{k+1}\right)^{-1}A\\[2pt] K_k &= \left(R + B^{\mathsf T}P_{k+1}B\right)^{-1}B^{\mathsf T}P_{k+1}A\\[2pt] \boldsymbol{u}_k &= -K_k\boldsymbol{x}_k \end{aligned}} \]

    递推方向是从后往前：由 \(P_N = Q_N\) 开始（终端条件）， 逐步算出 \(P_{N-1},P_{N-2},\dots,P_0\)。

    这解决了 1.3 节的两点边值困境：不需要同时满足两端条件， 而是从终端反向把 \(P_k\) 全部算出来，在线时只需

    \[ \boldsymbol{u}_k = -K_k\boldsymbol{x}_k \]

    —— 一个状态反馈，不需要在线求解优化问题。

    LQR 的真正价值在于「离线算增益、在线只用乘法」

    黎卡提递推离线做一次（\(N\) 步矩阵运算）， 得到整条增益序列 \(K_0,\dots,K_{N-1}\) 并存储。

    在线运行时只需要做一次矩阵乘向量，实时性极好。 这是最优控制能用于实际系统的前提。

    代价是对模型精度要求高 —— 增益是按 \(A,B,Q,R\) 算的， 模型不准则最优性不成立。

    三、稳态 LQR¶

    3.1 为什么会有稳态¶

    上面 \(K_k\) 是时变的。但很多场合 \(N\) 很大（或 \(N\to\infty\)）， 此时 \(P_k\) 会收敛到一个常数矩阵：

    \[ P_k \to P,\qquad K_k \to K \]

    于是反馈增益变成常数，实现上简单得多。

    3.2 稳态黎卡提方程¶

    令递推式中 \(P_k = P_{k+1} = P\)，得到代数黎卡提方程（ARE）：

    \[ P = Q + A^{\mathsf T}P\left(I + BR^{-1}B^{\mathsf T}P\right)^{-1}A \]

    稳态增益：

    \[ K = \left(R + B^{\mathsf T}PB\right)^{-1}B^{\mathsf T}PA \]

    这是一个非线性矩阵方程，但可以迭代求解： 从 \(P = Q\) 出发反复代入递推式，收敛后即为解。

    import numpy as np

# 一维离散系统：x_{k+1} = a x_k + b u_k
a, b = 1.05, 0.5
Q, R = 1.0, 1.0

# 用黎卡提递推（反向）算有限时域增益
N = 30
P = Q                      # 终端条件 P_N = Q
Ks = []
for k in range(N - 1, -1, -1):
    K = (R + b * b * P) ** -1 * b * P * a
    P = Q + a * a * P / (1.0 + b * b * P / R)
    Ks.append((k, K, P))

print("有限时域：从终端反向算出的增益（只列部分）")
print("k".ljust(6) + "K_k".ljust(14) + "P_k")
for k, K, Pv in Ks[:4] + Ks[-3:]:
    print(("%d" % k).ljust(6) + ("%.6f" % K).ljust(14) + "%.6f" % Pv)

print()
print("观察：K_k 随 k 减小迅速收敛到常数（稳态）")
Pss = Q
for _ in range(500):
    Pss = Q + a * a * Pss / (1.0 + b * b * Pss / R)
Kss = (R + b * b * Pss) ** -1 * b * Pss * a
print("稳态 P = %.8f" % Pss)
print("稳态 K = %.8f" % Kss)

# 直接解代数黎卡提方程复核
c = a * a
disc = (c * R - Q * b * b - R) ** 2 + 4.0 * Q * b * b * R
P2 = (R + Q * b * b - c * R + np.sqrt(disc)) / (2.0 * b * b)
print("解析解 P = %.8f（与迭代一致）" % P2)

    3.3 闭环稳定性¶

    稳态 LQR 有一条重要性质：

    \[ \text{闭环矩阵 } (A - BK) \text{ 的全部特征值都在单位圆内} \]

    条件：\((A,B)\) 可稳、\((Q^{1/2},A)\) 可检测。

    这意味着 LQR 自动给出稳定控制器 —— 不需要额外设计。 原因可以从代价函数看出来：代价含 \(\sum\boldsymbol{x}^{\mathsf T}Q\boldsymbol{x}\)， 若状态发散，代价必趋于无穷，而最优解要求代价有限。

    import numpy as np

# 验证闭环稳定性：多种权重组合下闭环极点都在单位圆内
A = np.array([[1.1, 0.3],
              [0.0, 0.95]])
B = np.array([[0.0],
              [1.0]])

print("不同 Q、R 下的闭环极点模长（都需小于 1）")
print("Q".ljust(22) + "R".ljust(8) + "闭环极点模长".ljust(26) + "稳定")
for Qd, Rd in [((1.0, 1.0), 1.0), ((10.0, 1.0), 1.0),
               ((1.0, 10.0), 1.0), ((1.0, 1.0), 0.01)]:
    Q = np.diag(Qd)
    R = np.array([[Rd]])
    # 迭代求 ARE 的解
    P = Q.copy()
    for _ in range(2000):
        K = np.linalg.solve(R + B.T @ P @ B, B.T @ P @ A)
        P = Q + A.T @ P @ (A - B @ K)
    K = np.linalg.solve(R + B.T @ P @ B, B.T @ P @ A)
    poles = np.linalg.eigvals(A - B @ K)
    mags = np.abs(poles)
    print(("diag%s" % (Qd,)).ljust(22) + ("%.2f" % Rd).ljust(8)
          + ("%.6f, %.6f" % tuple(mags)).ljust(26)
          + ("是" if mags.max() < 1 else "否"))

    import numpy as np

# 闭环仿真：对比两组 Q、R 的实际响应
A = np.array([[1.1, 0.3],
              [0.0, 0.95]])
B = np.array([[0.0],
              [1.0]])


def lqr_gain(Q, R):
    """迭代求代数黎卡提方程的解，返回稳态增益。"""
    P = Q.copy()
    for _ in range(3000):
        K = np.linalg.solve(R + B.T @ P @ B, B.T @ P @ A)
        P = Q + A.T @ P @ (A - B @ K)
    return np.linalg.solve(R + B.T @ P @ B, B.T @ P @ A)


x0 = np.array([[1.0], [1.0]])
print("初始状态 x0 = [1, 1]（偏离原点，需要收敛回去）")
print()
print("权重".ljust(24) + "控制峰值".ljust(14) + "第 20 步状态范数")
for name, Qd, Rd in [("Q=diag(1,1), R=1", (1.0, 1.0), 1.0),
                     ("Q=diag(50,50), R=1", (50.0, 50.0), 1.0),
                     ("Q=diag(1,1), R=100", (1.0, 1.0), 100.0)]:
    K = lqr_gain(np.diag(Qd), np.array([[Rd]]))
    x = x0.copy()
    umax = 0.0
    for k in range(20):
        u = -K @ x
        umax = max(umax, abs(float(u)))
        x = A @ x + B @ u
    print(name.ljust(24) + ("%.4f" % umax).ljust(14)
          + "%.6f" % float(np.linalg.norm(x)))
print()
print("结论：加大 Q 收敛更快但控制峰值更大；加大 R 控制更省但收敛更慢")

    四、例题¶

    例题 1：一维两步 LQR¶

    题目：\(x_{k+1} = x_k + u_k\)，\(Q=1\)、\(R=1\)、\(N=2\)， 终端代价 \(P_2 = 1\)（即 \(\phi = x_2^2\)）。 求 \(K_1\)、\(K_0\) 与 \(P_1\)、\(P_0\)。

    思路

    从终端 \(P_2\) 反向递推，逐步用黎卡提式。

    解答

    第一步：算 \(K_1\) 与 \(P_1\)。

    这里 \(A=1\)、\(B=1\)、\(Q=1\)、\(R=1\)，\(P_2=1\)：

    \[ K_1 = \frac{BP_2A}{R+B^2P_2} = \frac{1\times1\times1}{1+1} = 0.5 \]
    \[ P_1 = Q + \frac{A^2P_2}{1+B^2P_2/R} = 1 + \frac{1}{2} = 1.5 \]

    第二步：算 \(K_0\) 与 \(P_0\)。

    \[ K_0 = \frac{1\times1.5\times1}{1+1.5} = \frac{1.5}{2.5} = 0.6 \]
    \[ P_0 = 1 + \frac{1.5}{2.5} = 1.6 \]

    答案是 \(K_1=0.5\)、\(K_0=0.6\)，\(P_1=1.5\)、\(P_0=1.6\)。

    注意 \(P_k\) 从终端往前递增（\(1 \to 1.5 \to 1.6\)）， 这符合直觉：越靠近起点的剩余问题越长，剩余代价越大。

    例题 2：\(Q\) 与 \(R\) 的取舍¶

    题目：某一维系统。分别取 \(Q/R = 100\) 与 \(Q/R = 0.01\)， 说明闭环极点的差别，以及工程含义。

    思路

    \(Q/R\) 大表示"更看重状态收敛"，小表示"更看重控制省"。

    解答

    第一步：两种情形的极点。

    \(Q/R = 100\)（重状态）时，增益大，闭环极点靠近原点 —— 收敛快。 \(Q/R = 0.01\)（重控制）时，增益小，闭环极点靠近 1 —— 收敛慢。

    第二步：工程含义。

    这个比值就是性能与代价的调节旋钮：

    \(Q/R\) 侧向 后果
    大 快速收敛状态 控制量大、执行器负担重
    小 节省控制能量 收敛慢、响应迟缓

    注意只有比值重要：把 \(Q\) 与 \(R\) 同时放大 \(c\) 倍， \(J\) 整体放大 \(c\) 倍，但最优控制律不变

    例题 3：为什么 LQR 一定稳定¶

    题目：说明为什么 LQR 的闭环自动稳定，不需要额外加稳定约束。

    思路

    从代价函数的有界性出发。

    解答

    第一步：代价必须有限。

    LQR 的最优解使 \(J\) 取最小值，而 \(J\) 是一个有限数 （例如取 \(\boldsymbol{u}_k\equiv 0\) 就给出一个有限值）。

    第二步：若闭环不稳定会怎样。

    闭环不稳定时状态发散，于是

    \[ \sum_{k=0}^{N-1}\boldsymbol{x}_k^{\mathsf T}Q\boldsymbol{x}_k \to \infty \]

    （只要 \(Q\) 正定，\(\boldsymbol{x}\ne0\) 就会让这一项为正。） 那么 \(J\) 也是无穷大，与"最优解给出有限代价"矛盾。

    第三步：结论。

    所以最优解必然使状态收敛，即闭环稳定。

    稳定性在这里是优化结果的副产品， 而不是需要额外施加的约束。这是 LQR 相对极点配置等方法的一大优势。

    例题 4：稳态增益什么时候能用¶

    题目：某系统用有限时域 LQR，\(N=5\) 时增益还在明显变化， \(N=50\) 时已几乎不变。说明实际工程该怎么选。

    思路

    关键是"增益序列收敛到稳态所需的时间"与"控制任务实际持续多久"的比较。

    解答

    第一步：判断收敛所需步数。

    从例题 3 与 3.2 节的数据看，增益通常在十步左右就接近稳态。 所以 \(N=5\) 太短（末端效应明显），\(N=50\) 足够。

    第二步：工程选择。

    实际任务时长 该用
    很短（步数与收敛步数可比） 时变增益 \(K_k\)，必须反向递推
    长（远大于收敛步数） 稳态增益 \(K\)，算一次即可

    第三步：为什么要区分。

    用稳态增益可以离线算一次，在线只做矩阵乘法； 而时变增益需要存整条序列，实现上更麻烦。

    答案是：先算一下增益收敛需要多少步，再决定。
