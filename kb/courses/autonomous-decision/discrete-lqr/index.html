    离散时间最优控制¶

    上一页的 \(\boldsymbol{u}\) 是一个固定向量。这一页把它换成序列：

    \[\boldsymbol{u}_0,\ \boldsymbol{u}_1,\ \dots,\ \boldsymbol{u}_{N-1}\]

    同时系统有状态演化：

    \[\boldsymbol{x}_{k+1} = A\boldsymbol{x}_k + B\boldsymbol{u}_k\]

    这两个变化使问题性质完全不同：\(N\) 步决策互相耦合 —— 今天的控制既影响今天的代价，又通过状态影响之后所有时刻。 不能像静态优化那样"一次解出来"。

    本页推导完全按教材 2.2 节走，符号也与教材一致 （增益矩阵用 \(S_k\) 而不是 \(P_k\)，代价含 \(\frac12\)）—— 这样你对照原书时能逐行对上。

    一、问题的提出¶

    1.1 性能指标与假设¶

    设初始时刻为 \(i\)、终止时刻为 \(N\)。性能指标是二次型：

    \[J_i = \frac12\boldsymbol{x}_N^{\mathsf T}S_N\boldsymbol{x}_N + \frac12\sum_{k=i}^{N-1}\left(\boldsymbol{x}_k^{\mathsf T}Q_k\boldsymbol{x}_k + \boldsymbol{u}_k^{\mathsf T}R_k\boldsymbol{u}_k\right)\]

    逐项说明（教材 (2.2-2) 式）：

    项 含义 为什么这样设计
    \(\boldsymbol{x}_N^{\mathsf T}S_N\boldsymbol{x}_N\) 终端代价 惩罚终点偏离期望状态的程度
    \(\boldsymbol{x}_k^{\mathsf T}Q_k\boldsymbol{x}_k\) 状态代价 惩罚过程中的状态偏离
    \(\boldsymbol{u}_k^{\mathsf T}R_k\boldsymbol{u}_k\) 控制代价 惩罚控制能量消耗
    \(\frac12\) 系数 纯为求导后不带 2；教材就是这样写的

    关于矩阵的假设（教材明确列出，后面每步都要用）：

    \[S_N \succeq 0,\qquad Q_k \succeq 0,\qquad R_k \succ 0, \qquad \text{三者都对称}\]

    为什么要这些假设：

    · \(R_k \succ 0\) 保证 \(u_k^{\mathsf T}R_ku_k\) 是严格凸的 → 后面令一阶导为零得到的确实是极小点（不然可能只是驻点） · \(Q_k \succeq 0\)、\(S_N\succeq0\) 允许半正定 → 只惩罚关心的方向， 不必要求每个状态分量都被惩罚 · 对称性是二次型求导公式的前提

    代价与约束的关系：若让 \(Q_k\) 或 \(R_k\) 的某个权趋于无穷大， 等价于强制对应的量趋于零。所以用代价可以近似代替硬约束 —— 这是把"必须满足的条件"软化进目标函数的标准手法， 也是 LQR 能把约束问题纳入统一框架的原因。

    目标：找控制序列 \(\boldsymbol{u}_i,\dots,\boldsymbol{u}_{N-1}\) 使 \(J_i\) 最小。

    矩阵都是时变的（带下标 \(k\)）。教材原话： we drop the subscripts on the plant and weighting matrices —— 所以某些步骤会暂时省略下标让式子好读。

    1.2 为什么不能直接对 \(u_k\) 求导¶

    性能指标里 \(u_k\) 不仅出现在自己那一项，还通过 \(\boldsymbol{x}_{k+1}=A\boldsymbol{x}_k+B\boldsymbol{u}_k\) 影响之后所有时刻的 \(x_{k+1},\dots,x_N\)。

    所以 \(J_i\) 对 \(u_k\) 的依赖是隐式的， 必须先把动态约束"接进"目标函数才谈得上求导。

    这就是引入哈密顿函数的原因 —— 它相当于静态优化里的拉格朗日函数： 用乘子把约束加进目标，把有约束问题转成无约束问题。

    二、哈密顿函数与三组方程¶

    2.1 构造哈密顿函数¶

    引入乘子（协态）序列 \(\boldsymbol{\lambda}_{i+1},\dots,\boldsymbol{\lambda}_N\)， 每步一个，把该步的动态约束加进目标。定义哈密顿函数：

    \[H_k = \frac12\left(\boldsymbol{x}_k^{\mathsf T}Q_k\boldsymbol{x}_k + \boldsymbol{u}_k^{\mathsf T}R_k\boldsymbol{u}_k\right) + \boldsymbol{\lambda}_{k+1}^{\mathsf T} \left(A_k\boldsymbol{x}_k + B_k\boldsymbol{u}_k\right)\]

    这是教材 (2.2-3) 式。

    怎么读它：

    部分 含义
    \(\frac12(\boldsymbol{x}_k^{\mathsf T}Q_k\boldsymbol{x}_k+\boldsymbol{u}_k^{\mathsf T}R_k\boldsymbol{u}_k)\) 这一步的即时代价
    \(\boldsymbol{\lambda}_{k+1}^{\mathsf T}(A_k\boldsymbol{x}_k+B_k\boldsymbol{u}_k)\) 这一步之后到达的状态，用 \(\boldsymbol{\lambda}_{k+1}\) 加权
    整体 即时代价 + 未来状态的价值

    为什么 \(\boldsymbol{\lambda}\) 的下标是 \(k+1\) 而不是 \(k\)： 它标记的是转移之后那个状态 \(\boldsymbol{x}_{k+1}\)。 教材这样选，是为了让接下来得到的协态方程与状态方程形式对称。

    2.2 状态方程¶

    \(H_k\) 对 \(\boldsymbol{\lambda}_{k+1}\) 求偏导。 \(\boldsymbol{\lambda}_{k+1}\) 只出现在最后一项，而那一项对它线性，所以

    \[\frac{\partial H_k}{\partial \boldsymbol{\lambda}_{k+1}} = A_k\boldsymbol{x}_k + B_k\boldsymbol{u}_k\]

    它正好是动态约束的右边，于是（教材 (2.2-4) 式）

    \[\boxed{\ \boldsymbol{x}_{k+1} = \frac{\partial H_k}{\partial\boldsymbol{\lambda}_{k+1}} = A_k\boldsymbol{x}_k + B_k\boldsymbol{u}_k\ }\]

    为什么这一步只是"还原"：哈密顿函数里那项本来就是从约束"搬"过来的， 对它求导自然回到原约束。

    2.3 协态方程¶

    \(H_k\) 对 \(\boldsymbol{x}_k\) 求偏导。\(\boldsymbol{x}_k\) 出现在两处：

    出现位置 对 \(\boldsymbol{x}_k\) 求导
    \(\frac12\boldsymbol{x}_k^{\mathsf T}Q_k\boldsymbol{x}_k\) \(Q_k\boldsymbol{x}_k\)
    \(\boldsymbol{\lambda}_{k+1}^{\mathsf T}A_k\boldsymbol{x}_k\) \(A_k^{\mathsf T}\boldsymbol{\lambda}_{k+1}\)

    所以（教材 (2.2-5) 式）

    \[\boxed{\ \boldsymbol{\lambda}_k = \frac{\partial H_k}{\partial\boldsymbol{x}_k} = Q_k\boldsymbol{x}_k + A_k^{\mathsf T}\boldsymbol{\lambda}_{k+1}\ }\]

    二次型求导的依据：对对称矩阵 \(Q\)，

    \[\frac{\partial}{\partial\boldsymbol{x}} \left(\boldsymbol{x}^{\mathsf T}Q\boldsymbol{x}\right) = 2Q\boldsymbol{x}\]

    所以 \(\frac12\boldsymbol{x}^{\mathsf T}Q\boldsymbol{x}\) 的梯度正好是 \(Q\boldsymbol{x}\) —— 这就是代价里那个 \(\frac12\) 的作用。

    线性项求导的依据：

    \[\frac{\partial}{\partial\boldsymbol{x}} \left(\boldsymbol{a}^{\mathsf T}\boldsymbol{x}\right) = \boldsymbol{a}\]

    这里 \(\boldsymbol{a}^{\mathsf T}=\boldsymbol{\lambda}_{k+1}^{\mathsf T}A_k\)，

    故梯度为 \(A_k^{\mathsf T}\boldsymbol{\lambda}_{k+1}\)。

    协态的物理意义：\(\boldsymbol{\lambda}_k\) 表示 "\(\boldsymbol{x}_k\) 变化一个单位会给总代价带来多少增量"， 所以又叫影子价格 —— 衡量状态的边际价值。

    2.4 驻定条件（求出控制律）¶

    \(\boldsymbol{u}_k\) 也出现在两处：

    \[\frac{\partial H_k}{\partial\boldsymbol{u}_k} = \underbrace{R_k\boldsymbol{u}_k}_{\text{来自}\ \frac12\boldsymbol{u}^{\mathsf T}R\boldsymbol{u}} + \underbrace{B_k^{\mathsf T}\boldsymbol{\lambda}_{k+1}}_{\text{来自}\ \boldsymbol{\lambda}^{\mathsf T}B\boldsymbol{u}}\]

    令其为零（教材 (2.2-6) 式）：

    \[0 = \frac{\partial H_k}{\partial\boldsymbol{u}_k} = R_k\boldsymbol{u}_k + B_k^{\mathsf T}\boldsymbol{\lambda}_{k+1}\]

    为什么"令为零"就是极小：假设 \(R_k\succ0\)， 所以 \(H_k\) 对 \(\boldsymbol{u}_k\) 是严格凸的二次函数 （二阶导是 \(R_k\succ0\)）—— 凸函数的驻点就是全局极小点。

    解出控制律（教材 (2.2-7) 式）：

    \[\boxed{\ \boldsymbol{u}_k = -R_k^{-1}B_k^{\mathsf T}\boldsymbol{\lambda}_{k+1}\ }\]

    注意它暂时还不能用：右边是下一步的协态， 而协态序列还不知道 —— 需要接下来的推导。

    2.5 三组方程小结¶

    方程 式子 方向 教材
    状态方程 \(\boldsymbol{x}_{k+1}=A_k\boldsymbol{x}_k+B_k\boldsymbol{u}_k\) 前向 (2.2-4)
    协态方程 \(\boldsymbol{\lambda}_k=Q_k\boldsymbol{x}_k+A_k^{\mathsf T}\boldsymbol{\lambda}_{k+1}\) 后向 (2.2-5)
    驻定条件 \(\boldsymbol{u}_k=-R_k^{-1}B_k^{\mathsf T}\boldsymbol{\lambda}_{k+1}\) 代数 (2.2-7)

    前向与后向同时出现，这就是"两点边值问题" —— 状态从 \(\boldsymbol{x}_i\) 往前推，协态从 \(\boldsymbol{\lambda}_N\) 往回推， 两端条件分居首尾，不能直接迭代求解。

    教材也指出了这个困难

    教材原话：This system is difficult to solve since part of it develops forward and part backward in time.

    所以下一步必须找结构性的突破，而不是硬解。

    三、从两点边值到黎卡提方程¶

    3.1 关键的猜测：\(\boldsymbol{\lambda}_k=S_k\boldsymbol{x}_k\)¶

    突破口是猜协态与状态成正比：

    \[\boldsymbol{\lambda}_k = S_k\boldsymbol{x}_k\]

    其中 \(S_k\) 是待定 \(n\times n\) 矩阵。

    这个假设为什么合理（教材的论证路线）： 先用驻定条件消去 \(\boldsymbol{u}_k\) —— 把 \(\boldsymbol{u}_k=-R^{-1}B^{\mathsf T}\boldsymbol{\lambda}_{k+1}\) 代入状态方程 (2.2-4)，得（教材 (2.2-8) 式）

    \[\boldsymbol{x}_{k+1} = A\boldsymbol{x}_k - BR^{-1}B^{\mathsf T}\boldsymbol{\lambda}_{k+1}\]

    再把状态方程与协态方程写成一个联立系统 （教材 (2.2-9) 式）：

    \[\begin{bmatrix}\boldsymbol{x}_{k+1}\\ \boldsymbol{\lambda}_k\end{bmatrix} = \underbrace{\begin{bmatrix}A & -BR^{-1}B^{\mathsf T}\\ Q & A^{\mathsf T}\end{bmatrix}}_{H} \begin{bmatrix}\boldsymbol{x}_k\\ \boldsymbol{\lambda}_{k+1}\end{bmatrix}\]

    这个 \(2n\times2n\) 矩阵叫离散哈密顿矩阵。 教材给出了它的定义：满足

    \[JHJ = H^{\mathsf T},\qquad J = \begin{bmatrix}0 & -I_n\\ I_n & 0\end{bmatrix}\]

    哈密顿结构意味着什么（这是理解 \(S_k\) 假设的关键）： 它保证特征值成对出现 —— 若 \(\mu\) 是特征值，则 \(1/\mu\) 也是。 于是闭环系统的特征值一半在单位圆内（稳定）、 一半在单位圆外（不稳定）。

    于是可以把 \(2n\) 维问题解耦成两半， 而"稳定的一半"可以用 \(n\times n\) 矩阵 \(S_k\) 参数化， 即 \(\boldsymbol{\lambda}_k=S_k\boldsymbol{x}_k\)。

    所以这个假设不是凭空猜的，而是哈密顿结构的必然结果 ✓

    3.2 逐步代入求出递推¶

    第一步：把假设写到 \(k+1\) 时刻。

    \[\boldsymbol{\lambda}_{k+1} = S_{k+1}\boldsymbol{x}_{k+1}\]

    第二步：代入状态方程。 用 \(\boldsymbol{x}_{k+1}=A\boldsymbol{x}_k+B\boldsymbol{u}_k\)：

    \[\boldsymbol{\lambda}_{k+1} = S_{k+1}\left(A\boldsymbol{x}_k + B\boldsymbol{u}_k\right)\]

    第三步：代入控制律 \(\boldsymbol{u}_k=-R^{-1}B^{\mathsf T}\boldsymbol{\lambda}_{k+1}\)：

    \[\boldsymbol{\lambda}_{k+1} = S_{k+1}\left(A\boldsymbol{x}_k - BR^{-1}B^{\mathsf T}\boldsymbol{\lambda}_{k+1}\right)\]

    第四步：把含 \(\boldsymbol{\lambda}_{k+1}\) 的项移到左边。

    \[\boldsymbol{\lambda}_{k+1} + S_{k+1}BR^{-1}B^{\mathsf T}\boldsymbol{\lambda}_{k+1} = S_{k+1}A\boldsymbol{x}_k\]

    提取公因子：

    \[\left(I + S_{k+1}BR^{-1}B^{\mathsf T}\right)\boldsymbol{\lambda}_{k+1} = S_{k+1}A\boldsymbol{x}_k\]

    第五步：解出 \(\boldsymbol{\lambda}_{k+1}\)。

    \[\boldsymbol{\lambda}_{k+1} = \left(I + S_{k+1}BR^{-1}B^{\mathsf T}\right)^{-1} S_{k+1}A\boldsymbol{x}_k\]

    第六步：代入协态方程 \(\boldsymbol{\lambda}_k=Q\boldsymbol{x}_k+A^{\mathsf T}\boldsymbol{\lambda}_{k+1}\)：

    \[S_k\boldsymbol{x}_k = Q\boldsymbol{x}_k + A^{\mathsf T}\left(I + S_{k+1}BR^{-1}B^{\mathsf T}\right)^{-1} S_{k+1}A\boldsymbol{x}_k\]

    第七步：这个式子对任意 \(\boldsymbol{x}_k\) 成立，所以矩阵本身相等。

    \[S_k = Q + A^{\mathsf T}\left(I + S_{k+1}BR^{-1}B^{\mathsf T}\right)^{-1} S_{k+1}A\]

    3.3 用矩阵恒等式化简¶

    上式含一个 \((I+\cdots)^{-1}\)，用矩阵求逆引理化成教材的形式。

    引理（Woodbury 恒等式的特例）：

    \[\left(I + SBR^{-1}B^{\mathsf T}\right)^{-1}S = S - SB\left(B^{\mathsf T}SB + R\right)^{-1}B^{\mathsf T}S\]

    怎么验证：把右边乘上 \(\left(I+SBR^{-1}B^{\mathsf T}\right)\)， 展开整理后得到 \(S\)，说明两边确实相等。

    逐步验证一下（这也是常见的习题）：

    \[\left[S - SB(B^{\mathsf T}SB+R)^{-1}B^{\mathsf T}S\right] \left(I + SBR^{-1}B^{\mathsf T}\right)\]

    第一项乘出来是 \(S + SBR^{-1}B^{\mathsf T}S\)； 第二项乘出来是

    \[SB(B^{\mathsf T}SB+R)^{-1}B^{\mathsf T}S + SB(B^{\mathsf T}SB+R)^{-1}B^{\mathsf T}SBR^{-1}B^{\mathsf T}S\]

    。

    把后两项合并（提取 \(B^{\mathsf T}SBR^{-1}B^{\mathsf T}S\) 的公因子）， 利用恒等式

    \[R^{-1} - R^{-1}(B^{\mathsf T}SB+R)^{-1}B^{\mathsf T}SB\,R^{-1} = R^{-1}(B^{\mathsf T}SB+R)^{-1}R\]

    ，

    整个表达式化简为 \(S\) ✓

    代入后得到黎卡提递推方程（教材 (2.2-11) 式）：

    \[\boxed{\ S_k = A_k^{\mathsf T}\left[S_{k+1} - S_{k+1}B_k \left(B_k^{\mathsf T}S_{k+1}B_k + R_k\right)^{-1} B_k^{\mathsf T}S_{k+1}\right]A_k + Q_k\ }\]

    递推方向是从后往前：由终端条件 \(S_N\) 开始 （\(S_N\) 已在代价里给定），逐步算出 \(S_{N-1},\dots,S_i\) ✓

    3.4 增益与最优代价¶

    增益矩阵（教材 (2.2-12) 式）： 把 \(\boldsymbol{\lambda}_{k+1}=S_{k+1}\boldsymbol{x}_{k+1}\) 与 \(\boldsymbol{x}_{k+1}=A\boldsymbol{x}_k+B\boldsymbol{u}_k\) 都代回控制律 \(\boldsymbol{u}_k=-R^{-1}B^{\mathsf T}\boldsymbol{\lambda}_{k+1}\)：

    \[\boldsymbol{u}_k = -R^{-1}B^{\mathsf T}S_{k+1} \left(A\boldsymbol{x}_k + B\boldsymbol{u}_k\right)\]

    展开并把含 \(\boldsymbol{u}_k\) 的项移到左边：

    \[\left(I + R^{-1}B^{\mathsf T}S_{k+1}B\right)^{-1}\boldsymbol{u}_k = -R^{-1}B^{\mathsf T}S_{k+1}A\boldsymbol{x}_k\]

    用 \((I+R^{-1}M)^{-1}R^{-1} = (M+R)^{-1}\) 整理，得

    \[\boxed{\ K_k = \left(B_k^{\mathsf T}S_{k+1}B_k + R_k\right)^{-1} B_k^{\mathsf T}S_{k+1}A_k,\qquad \boldsymbol{u}_k = -K_k\boldsymbol{x}_k\ }\]

    最优代价（教材 (2.2-13) 式）：

    \[J_i^* = \frac12\boldsymbol{x}_i^{\mathsf T}S_i\boldsymbol{x}_i\]

    这个式子的意义：初始代价完全由 \(\boldsymbol{x}_i\) 与 \(S_i\) 决定， 而 \(S_i\) 只依赖 \(A,B,Q,R\) 与终端条件 —— 与具体初始状态无关。所以可以离线算一次 \(S_i\)，对任意初值都适用。

    LQR 的真正价值：离线算增益、在线只做矩阵乘法

    黎卡提递推离线做一次（\(N\) 步矩阵运算）， 得到整条增益序列 \(K_i,\dots,K_{N-1}\) 并存储。

    在线运行时只需做一次矩阵乘向量 \(\boldsymbol{u}_k=-K_k\boldsymbol{x}_k\)， 实时性极好。这是最优控制能用于实际系统的前提。

    代价是对模型精度要求高 —— 增益按 \(A,B,Q,R\) 算出， 模型不准则最优性不成立。

    用一组具体数据把递推走一遍（这是理解递推最有效的办法）。

    取 \(A=\begin{bmatrix}1 & 0.2\\ 0 & 1\end{bmatrix}\)、 \(B=\begin{bmatrix}0\\1\end{bmatrix}\)、\(Q=I\)、\(R=1\)， 终端条件 \(S_N=Q\)。

    先看一维情形，便于手算。设 \(a=b=q=r=1\)，递推化为

    \[s_k = s_{k+1} - \frac{s_{k+1}^2}{s_{k+1}+1} + 1, \qquad k_k = \frac{s_{k+1}}{s_{k+1}+1}\]

    从 \(s_N=1\) 往回算：

    \(k\) \(s_{k+1}\) \(k_k\) \(s_k\)
    \(N-1\) \(1\) \(0.5\) \(1-\frac{1}{2}+1=1.5\)
    \(N-2\) \(1.5\) \(1.5/2.5=0.6\) \(1.5-\frac{2.25}{2.5}+1=1.6\)
    \(N-3\) \(1.6\) \(1.6/2.6\approx0.615\) \(\approx1.615\)

    可见 \(s_k\) 与 \(k_k\) 很快趋于常数，这就是稳态。令 \(s_{k+1}=s_k=s\)：

    \[s = s - \frac{s^2}{s+1} + 1 \;\Longrightarrow\; s^2 = s+1 \;\Longrightarrow\; s = \frac{1+\sqrt5}{2}\approx1.618\]

    这个值是黄金比，稳态增益 \(k=\dfrac{s}{s+1}\approx0.618\)。

    再看二维的完整结果（同样参数，\(N\) 足够大）：

    \[S = \begin{bmatrix}7.0574 & 1.7749\\ 1.7749 & 2.1502\end{bmatrix}, \qquad K = \begin{bmatrix}0.5634 & 0.7952\end{bmatrix}\]

    把 \(S\) 与 \(K\) 代回代数黎卡提方程

    \[S=A^{\mathsf T}\left[S-SB\left(B^{\mathsf T}SB+R\right)^{-1} B^{\mathsf T}S\right]A+Q\]

    两边应当相等 —— 这是检验计算结果的标准办法。

    两条路互相印证：反向递推收敛到的 \(S\) 与代数黎卡提方程的解 在四位小数上完全一致，说明「有限时域反向递推」与 「无穷时域代数方程」在稳态下是同一件事。

    反过来看这件事的两面：

    · 收敛很快 —— 几十步后 \(K\) 就基本不变， 所以长任务可以直接用稳态增益 · 两条路一致 —— 反向递推的终值（\(S=\begin{bmatrix}7.0574 & 1.7749\\ 1.7749 & 2.1502\end{bmatrix}\)） 与代数黎卡提方程的解在四位小数上相同

    这不是巧合：当 \(N\to\infty\) 时递推的固定点就是代数方程的解。 两条路算的是同一个东西，只是一个从终端迭代过去、一个直接解方程。

    四、稳态情形的另一视角：李雅普诺夫方程¶

    4.1 稳态黎卡提方程¶

    当 \(N\to\infty\)（或 \(N\) 足够大）时 \(S_k\) 趋于常数，令 \(S_k=S_{k+1}=S\)：

    \[\boxed{\ S = A^{\mathsf T}\left[S - SB\left(B^{\mathsf T}SB + R\right)^{-1} B^{\mathsf T}S\right]A + Q\ }\]

    与有限时域的区别：不再有终端条件，而是要解代数方程。 求解靠迭代（从任意 \(S\succeq0\) 出发反复代入）—— 它是压缩映射，所以必然收敛。

    4.2 与李雅普诺夫方程的联系¶

    推导思路：把稳态黎卡提方程展开，用闭环 \(\boldsymbol{x}_{k+1}=(A-BK)\boldsymbol{x}_k\) 代入状态方程。

    "从 \(\boldsymbol{x}_0\) 出发的无穷时域代价"按定义是

    \[J = \frac12\sum_{k=0}^{\infty}\boldsymbol{x}_k^{\mathsf T} \left(Q + K^{\mathsf T}RK\right)\boldsymbol{x}_k\]

    这里用了 \(\boldsymbol{u}_k=-K\boldsymbol{x}_k\)，所以

    \[\boldsymbol{x}^{\mathsf T}Q\boldsymbol{x} + \boldsymbol{u}^{\mathsf T}R\boldsymbol{u} = \boldsymbol{x}^{\mathsf T}\left(Q + K^{\mathsf T}RK\right)\boldsymbol{x}\]

    又因为 \(\boldsymbol{x}_k=(A-BK)^k\boldsymbol{x}_0\)，代入得

    \[J = \frac12\boldsymbol{x}_0^{\mathsf T} \left[\sum_{k=0}^{\infty}\left((A-BK)^{\mathsf T}\right)^k \left(Q + K^{\mathsf T}RK\right)(A-BK)^k\right]\boldsymbol{x}_0\]

    而由最优性，\(J=\frac12\boldsymbol{x}_0^{\mathsf T}S\boldsymbol{x}_0\)。 两者对比 ⇒ 中间那个级数必须等于 \(S\)：

    \[S = \sum_{k=0}^{\infty}\left((A-BK)^{\mathsf T}\right)^k \left(Q + K^{\mathsf T}RK\right)(A-BK)^k\]

    把这个级数的项错位相减： 令 \(M=Q+K^{\mathsf T}RK\)、\(\Phi=A-BK\)。级数是 \(S=\sum_k(\Phi^{\mathsf T})^kM\Phi^k\)。那么

    \[\Phi^{\mathsf T}S\Phi = \sum_{k=0}^{\infty}(\Phi^{\mathsf T})^{k+1}M\Phi^{k+1} = S - M\]

    （第一项 \(k=0\) 的被减掉了。）移项得离散李雅普诺夫方程：

    \[\boxed{\ (A-BK)^{\mathsf T}S(A-BK) = S - \left(Q + K^{\mathsf T}RK\right)\ }\]

    为什么这个方程重要：它把"最优控制"与"稳定性分析"接了起来 ——

    方程 回答什么问题
    黎卡提方程 最优增益 \(K\) 是多少（设计问题）
    李雅普诺夫方程 给定 \(K\)，闭环稳不稳（分析问题）

    4.3 由李雅普诺夫方程证明稳定性¶

    第一步：取李雅普诺夫函数。

    由李雅普诺夫方程可以证明 \(S\succ0\)（若 \(Q\succ0\)），定义

    \[V(\boldsymbol{x}_k) = \boldsymbol{x}_k^{\mathsf T}S\boldsymbol{x}_k \gt 0 \qquad(\boldsymbol{x}_k\ne\boldsymbol{0})\]

    第二步：算它沿闭环轨迹的变化。

    \[\boldsymbol{x}_{k+1}=(A-BK)\boldsymbol{x}_k \;\Longrightarrow\; V(\boldsymbol{x}_{k+1}) = \boldsymbol{x}_k^{\mathsf T} (A-BK)^{\mathsf T}S(A-BK)\boldsymbol{x}_k\]

    代入李雅普诺夫方程：

    \[V(\boldsymbol{x}_{k+1}) = \boldsymbol{x}_k^{\mathsf T} \left[S - (Q+K^{\mathsf T}RK)\right]\boldsymbol{x}_k\]

    第三步：作差。

    \[\Delta V = V(\boldsymbol{x}_{k+1}) - V(\boldsymbol{x}_k) = -\boldsymbol{x}_k^{\mathsf T}\left(Q+K^{\mathsf T}RK\right)\boldsymbol{x}_k \;\le\; 0\]

    因为 \(Q\succeq0\)、\(R\succ0\)，右边恒非正。

    第四步：结论。

    \(V\gt0\) 且每步不增 → 这正是李雅普诺夫稳定的定义，故闭环稳定 ✓

    所以稳定性是优化结果的推论，不是额外施加的约束。 这就是 LQR 相对极点配置等方法的一大优势。

    五、例题¶

    例题 1：一维两步 LQR（手算全过程）¶

    题目：\(x_{k+1}=x_k+u_k\)，\(Q=1\)、\(R=1\)、\(N=2\)， 终端条件 \(S_2=1\)。求 \(K_1\)、\(K_0\) 与 \(S_1\)、\(S_0\)。

    思路

    按教材 (2.2-11)、(2.2-12) 式从终端反向递推： 先用 \(S_2\) 算 \(K_1\) 与 \(S_1\)，再用 \(S_1\) 算 \(K_0\) 与 \(S_0\)。

    解答

    已知：\(A=1\)、\(B=1\)、\(Q=1\)、\(R=1\)、\(S_2=1\)。

    第一步：求 \(K_1\)（用 \(S_2\)）。

    \[K_k=\left(B^{\mathsf T}S_{k+1}B+R\right)^{-1}B^{\mathsf T}S_{k+1}A\]

    分母为 \(B^{\mathsf T}S_2B+R = 1\cdot1\cdot1+1 = 2\)，分子为 \(B^{\mathsf T}S_2A = 1\)，所以

    \[K_1 = \frac12 = 0.5\]

    第二步：求 \(S_1\)（用 \(S_2\)）。

    \[S_k=A^{\mathsf T}\left[S_{k+1}-S_{k+1}B \left(B^{\mathsf T}S_{k+1}B+R\right)^{-1}B^{\mathsf T}S_{k+1}\right]A+Q\]

    代入 \(S_2=1\)：

    \[S_1 = 1\cdot\left[1 - 1\cdot1\cdot\frac{1}{2}\cdot1\cdot1\right] \cdot1 + 1 = 1 - 0.5 + 1 = 1.5\]

    第三步：求 \(K_0\)（用 \(S_1\)）。

    分母 \(=1.5+1=2.5\)，分子 \(=1.5\)：

    \[K_0 = \frac{1.5}{2.5} = 0.6\]

    第四步：求 \(S_0\)（用 \(S_1\)）。

    \[S_0 = 1\cdot\left[1.5 - 1.5\cdot1\cdot\frac{1}{2.5} \cdot1\cdot1.5\right]\cdot1 + 1 = 1.5 - \frac{2.25}{2.5} + 1 = 1.6\]

    答案：\(K_1=0.5\)、\(K_0=0.6\)，\(S_1=1.5\)、\(S_0=1.6\)。

    检验：\(S_k\) 从终端往前递增（\(1\to1.5\to1.6\)）—— 越靠近起点"剩余问题越长"，剩余代价越大 ✓

    最优代价：\(J_0^*=\frac12x_0^{\mathsf T}S_0x_0=0.8x_0^2\)。

    例题 2：\(Q\) 与 \(R\) 的取舍¶

    题目：一维系统 \(A=B=1\)。分别取 \(Q/R=100\) 与 \(Q/R=0.01\)， 说明增益与闭环极点的差别及工程含义。

    思路

    一维情形可由稳态黎卡提方程解出 \(S\) 与 \(Q/R\) 的关系， 再看闭环极点 \(A-BK\)。

    解答

    第一步：求一维稳态关系。

    稳态黎卡提方程（\(A=B=1\)）： \(S = S - \dfrac{S^2}{S+R} + Q\)。两边减 \(S\)：

    \[0 = -\frac{S^2}{S+R} + Q \;\Longrightarrow\; S^2 = Q(S+R)\]

    第二步：取两种极限。

    \(Q/R\) \(S\) 的近似 \(K=\dfrac{S}{S+R}\) 闭环极点 \(1-K\)
    \(100\) \(\approx\sqrt{100}=10\)（大） \(\approx0.91\) \(\approx0.09\)（快）
    \(0.01\) \(\approx0.1\)（小） \(\approx0.09\) \(\approx0.91\)（慢）

    第三步：工程含义。

    \(Q/R\) 侧重 后果
    大 快速收敛状态 控制量大、执行器负担重
    小 节省控制能量 收敛慢、响应迟缓

    注意只有比值重要：把 \(Q\) 与 \(R\) 同时放大 \(c\) 倍， \(J\) 整体放大 \(c\) 倍，但最优控制律不变 ✓

    例题 3：为什么 LQR 一定稳定¶

    题目：从李雅普诺夫方程出发，说明 LQR 闭环必然稳定。

    思路

    用 4.2 节的 \((A-BK)^{\mathsf T}S(A-BK)=S-(Q+K^{\mathsf T}RK)\)， 对 \(S\) 取李雅普诺夫函数。

    解答

    第一步：取李雅普诺夫函数。

    \[V(\boldsymbol{x}_k)=\boldsymbol{x}_k^{\mathsf T}S\boldsymbol{x}_k \gt 0\]

    第二步：沿闭环轨迹的变化。

    \[V(\boldsymbol{x}_{k+1})=\boldsymbol{x}_k^{\mathsf T} (A-BK)^{\mathsf T}S(A-BK)\boldsymbol{x}_k\]

    代入李雅普诺夫方程：

    \[V(\boldsymbol{x}_{k+1}) = \boldsymbol{x}_k^{\mathsf T} \left[S-(Q+K^{\mathsf T}RK)\right]\boldsymbol{x}_k\]

    第三步：作差。

    \[\Delta V = -\boldsymbol{x}_k^{\mathsf T} \left(Q+K^{\mathsf T}RK\right)\boldsymbol{x}_k \le 0\]

    因为 \(Q\succeq0\)、\(R\succ0\)，右边恒非正。

    第四步：结论。

    \(V\gt0\) 且每步不增 → 李雅普诺夫稳定，故闭环稳定 ✓

    所以稳定性是优化结果的推论，不需额外施加约束。

    例题 4：什么时候能用稳态增益¶

    题目：某系统 \(N=5\) 时增益还在明显变化，\(N=50\) 时已几乎不变。 工程上该怎么选？

    思路

    比较"增益收敛所需步数"与"任务实际步数"。

    解答

    第一步：判断收敛步数。

    由例题 1 与本节数据：\(K\) 从 \(0.5\)（终端）迅速趋向稳态， 一般系统约十步就接近稳态。

    第二步：工程选择。

    任务时长 该用 原因
    很短（与收敛步数可比） 时变 \(K_k\) 稳态假设不成立
    长（远大于收敛步数） 常数 \(K\) 离线算一次，在线最省

    第三步：末端效应的例外。

    若末端有硬约束（要求精确到达某状态）， 时变增益不可省 —— 那正是终端条件起作用的时段。
