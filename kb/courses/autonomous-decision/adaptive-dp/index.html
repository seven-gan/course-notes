    自适应动态规划¶

    上一页的强化学习有个现实障碍：它需要大量试错， 而物理系统在试错期间必须保持安全。

    自适应动态规划（ADP）就是为这个场景设计的： 把"已知的稳定性结构"嵌进学习框架，只让算法学未知的部分。

    它的核心做法是把一个函数拆成两部分：

    \[ V(\boldsymbol{x}) = \underbrace{\boldsymbol{x}^{\mathsf T}P\boldsymbol{x}}_{\text{已知的结构}} + \underbrace{\text{未知的修正项}}_{\text{用数据学}} \]

    这个拆分的价值：即使修正项还完全不准， 第一项也已经提供了基本稳定的反馈 —— 于是学习过程是"在稳定基础上改进"，而不是"从零摸索"。

    一、为什么需要自适应动态规划¶

    1.1 两类方法的困境¶

    方法 有什么 缺什么
    最优控制（LQR / HJB） 稳定性保证、解析结构 需要精确模型
    强化学习 不需要模型 试错期间无保证

    ADP 的目标：同时拿到两边的长处。 做法是引入参数化值函数近似，并用最小二乘（而非随机试错） 来估计参数。

    1.2 参数化值函数¶

    把值函数写成"已知基函数 + 未知权重"的形式：

    \[ V(\boldsymbol{x}) = \boldsymbol{w}^{\mathsf T}\boldsymbol{\phi}(\boldsymbol{x}) \]

    其中 \(\boldsymbol{\phi}(\boldsymbol{x})\) 是基函数向量（如各次幂、各阶交叉项）， \(\boldsymbol{w}\) 是待学权重。

    在线性二次情形，取二次基函数：

    \[ \boldsymbol{\phi}(\boldsymbol{x}) = \left[x_1^2,\ x_1x_2,\ \dots,\ x_n^2\right]^{\mathsf T} \]

    于是值函数 \(V=\boldsymbol{x}^{\mathsf T}P\boldsymbol{x}\) 恰好对应 某个权重 \(\boldsymbol{w}\)（即 \(P\) 的各元素）。

    这就把"学一个函数"变成了"学一组参数" —— 维数从"状态空间的点数 \(m^n\)"降到"参数个数 \(O(n^2)\)"， 绕开了维数灾难 ✓

    值函数近似会破坏理论保证（这是真实代价）

    动态规划 / 策略迭代的收敛性证明都假设值函数被精确表示。 一旦换成参数化近似，"策略改进定理"就可能不再成立 —— 迭代可能震荡、甚至发散 ⚠

    这在文献里叫"致命三要素"（值函数近似 + 自举 + 离线策略）。 自适应动态规划必须额外论证稳定性，不能直接套用表格情形的结论。

    二、评价网络与执行网络¶

    2.1 两个网络的分工¶

    ADP 的典型结构用两个参数化函数：

    名称 近似什么 体现什么
    评价网络（critic） \(V(\boldsymbol{x})\) 或 \(Q(\boldsymbol{x},\boldsymbol{u})\) "当前策略价值多少"
    执行网络（actor） \(\pi(\boldsymbol{x})\) "该采取什么动作"

    为什么需要两个：值函数与策略是相互依赖的 （值由策略定义、策略由值改进）。 若只有一个网络，就得在"评估"与"改进"之间来回切换， 实现上难以同时保持两者的稳定性。

    2.2 两类实现方式¶

    方式 评价网络 执行网络
    启发式动态规划（HDP） 近似 \(V\) 由 \(\arg\min\) 或 \(\arg\max\) 实时求解
    双启发式动态规划（DHP） 近似 \(\lambda=\partial V/\partial\boldsymbol{x}\) 由一阶条件给出
    行动依赖 HDP（ADHDP） 近似 \(Q(\boldsymbol{x},\boldsymbol{u})\) 由 \(\arg\min_{\boldsymbol{u}}Q\) 给出

    第二行值得注意：DHP 学的是协态的梯度而不是值函数本身。 因为控制律直接用 \(\partial V/\partial\boldsymbol{x}\) （\(\boldsymbol{u}=-R^{-1}B^{\mathsf T}\partial V/\partial\boldsymbol{x}\)）， 直接学这个梯度比学 \(V\) 更省一步，精度也更高。

    2.3 权重的更新：最小二乘¶

    以评价网络为例。由贝尔曼方程，理想的权重 \(\boldsymbol{w}\) 应满足"两边相等"：

    \[ \boldsymbol{w}^{\mathsf T}\boldsymbol{\phi}(\boldsymbol{x}_k) = R_k + \gamma\,\boldsymbol{w}^{\mathsf T}\boldsymbol{\phi}(\boldsymbol{x}_{k+1}) \]

    移项得到残差：

    \[ e_k = R_k + \gamma\,\boldsymbol{w}^{\mathsf T} \boldsymbol{\phi}(\boldsymbol{x}_{k+1}) - \boldsymbol{w}^{\mathsf T}\boldsymbol{\phi}(\boldsymbol{x}_k) \]

    用最小二乘让残差的平方和最小。把 \(N\) 个样本排成矩阵：

    \[ \Phi_k = \left[\boldsymbol{\phi}(\boldsymbol{x}_k) - \gamma\boldsymbol{\phi}(\boldsymbol{x}_{k+1})\right]^{\mathsf T}, \qquad \boldsymbol{r} = \left[R_1,\dots,R_N\right]^{\mathsf T} \]

    则残差为 \(e = \boldsymbol{r} - \Phi\boldsymbol{w}\)，最小二乘解是

    \[ \boldsymbol{w} = \left(\Phi^{\mathsf T}\Phi\right)^{-1}\Phi^{\mathsf T}\boldsymbol{r} \]

    这就是"最小二乘"这个名字的来历： 把"贝尔曼方程的两边之差"的平方和压到最小。

    与随机梯度下降的对比：

    最小二乘（批处理） 随机梯度（TD）
    用多少数据 攒够一批再算 每个样本更新一次
    收敛速度 快（一次算到底） 慢（逐步挪）
    内存 需存一批数据 只需当前样本
    适用 仿真可批量采样 在线实时

    对无人系统的离线设计场景（用仿真批量采样）， 最小二乘明显更合适 —— 这也是 ADP 常用它的原因 ✓

    这个做法的可行性靠两点保证：

    · 样本要足够（这里举的是 200 个样本的量级）， 否则 \(\Phi^{\mathsf T}\Phi\) 病态，解不稳定 · 基函数要与值函数的形状匹配 —— 二次型值函数就取二次基函数， 若基函数选错，再多样本也拟合不出正确形状

    先把这个反解过程在一维情形上走通，全部数字都能手算。 取

    \[x_{k+1} = 0.9\,x_k + 0.5\,u_k, \qquad \text{单步代价} = x_k^2 + u_k^2, \qquad \gamma = 0.95\]

    值函数取二次型 \(V(x)=Px^2\)。判别标志：方程里出现 \(P^2\)， 说明它是二次的 —— 所以下面解的是一元二次方程，不是线性方程。

    第一步：写出黎卡提递推式。 把 \(V=Px^2\)、单步代价 \(x^2+u^2\) 代入贝尔曼方程， 对 \(u\) 求极小（这一步与 LQR 完全相同）： 最优 \(u^*=-\dfrac{\gamma abP}{r+\gamma b^2P}x\)，代回得

    \[P = q + \gamma a^2P - \frac{\left(\gamma abP\right)^2}{r+\gamma b^2P}\]

    第二步：逐项代入数值。 \(a=0.9\)、\(b=0.5\)、\(q=r=1\)、\(\gamma=0.95\)，于是

    \[\gamma a^2 = 0.95\times0.81 = 0.7695, \qquad \gamma b^2 = 0.95\times0.25 = 0.2375, \qquad \gamma ab = 0.4275\]

    第三步：两边同乘 \(r+\gamma b^2P=1+0.2375P\)，把分式化掉。

    \[P\left(1+0.2375P\right) = \left(1+0.7695P\right)\left(1+0.2375P\right) - 0.4275^2P^2\]

    注意 \(0.4275^2 = 0.18275625\)，而右边展开时 \(0.7695\times0.2375\) 也正好等于 \(0.18275625\) —— 这两个 \(P^2\) 项相互抵消。整理后只剩

    \[0.2375\,P^2 - 0.007\,P - 1 = 0\]

    第四步：解这个一元二次方程，取正根。

    \[P = \frac{0.007 + \sqrt{0.007^2 + 4\times0.2375}}{2\times0.2375} = \frac{0.007 + 0.974705}{0.475} \approx 2.066746\]

    这就是精确值 \(P=2.06674646\) —— 手算到小数点后六位。

    第五步：用数据反解，看能不能把这个 \(P\) 找回来。 取 200 个采样点 \(x\) 均匀落在 \([-2,2]\)， 用一个固定增益 \(u=-Kx\)（\(K\) 取由精确 \(P\) 算出的值）生成配对数据， 再对 \(\hat{P}\) 做最小二乘：

    \[x_k^2\hat{P} - \gamma x_{k+1}^2\hat{P} = x_k^2+u_k^2\]

    结果：反解得到 \(\hat{P} = 2.06674646\)，与手算值 相对误差 \(2.1\times10^{-16}\) —— 也就是到机器精度才分开。

    这个结果说明什么、又没说明什么，要分开看：

    · 说明：反解这一步（最小二乘）用到的输入只有 配对数据 \((x_k,x_{k+1})\) 与即时回报，并不需要知道 \(a\)、\(b\)； 它也没有解黎卡提方程。\(P\) 是"从数据里读出来"的 · 没说明：这批数据本身仍是用模型（\(a\)、\(b\)）仿真生成的。 所以这一步验证的是反解环节，不是"完全无模型"。 误差小到 \(10^{-16}\)，是因为数据无噪声、基函数又恰好对得上 —— 这两个条件是理想化的，实机上不会这么干净

    真正落到实机会怎样：数据带量测噪声、基函数未必匹配、 状态分布也未必覆盖工作区间。这三条任何一条变差， 误差都会从 \(10^{-16}\) 抬升到百分之几甚至更高 —— 这正是 2.3 节那两条"可行性保证"的必要性所在。

    需要注意的边界：最小二乘给的是"在采样范围内的最优拟合"。 若状态超出采样范围，外推不可靠 —— 这也是下一页要讲的工程问题。

    三、积分强化学习¶

    3.1 连续时间的关键困难¶

    连续时间贝尔曼方程含 \(\dot{\boldsymbol{x}}\)：

    \[ -V(\boldsymbol{x}(t)) = \int_t^{t+T}\left[L+\dot{V}\right]\mathrm{d}\tau \]

    要求 \(\dot{\boldsymbol{x}}\) 意味着要知道动态 \(f\) —— 这恰恰是我们想避开的 ⚠

    3.2 用积分消掉 \(\dot{\boldsymbol{x}}\)¶

    关键技巧：把 \(\dot{V}\) 沿轨迹积分，用微积分基本定理消掉：

    \[ \int_t^{t+T}\dot{V}(\boldsymbol{x}(\tau))\,\mathrm{d}\tau = V(\boldsymbol{x}(t+T)) - V(\boldsymbol{x}(t)) \]

    于是方程里不再出现 \(\dot{\boldsymbol{x}}\)， 只出现状态在两个时刻的取值：

    \[ V(\boldsymbol{x}(t)) = \int_t^{t+T}L(\boldsymbol{x},\boldsymbol{u})\,\mathrm{d}\tau + V(\boldsymbol{x}(t+T)) \]

    这就是积分强化学习（IRL）。

    它的价值在于： · 只需要状态轨迹与即时代价，不需要 \(f\) · 积分对噪声有平滑作用（比逐点求导稳定得多）

    代入参数化形式 \(\boldsymbol{w}^{\mathsf T}\boldsymbol{\phi}(\boldsymbol{x})\)：

    \[ \boldsymbol{w}^{\mathsf T}\left[\boldsymbol{\phi}(\boldsymbol{x}(t)) - \boldsymbol{\phi}(\boldsymbol{x}(t+T))\right] = \int_t^{t+T}L\,\mathrm{d}\tau \]

    这又变回一个线性最小二乘问题 —— 与离散情形式子同构。

    3.3 为什么积分形式对噪声更稳¶

    用 \(\dot{\boldsymbol{x}}\) 用积分
    需要什么 状态的导数 状态的值
    噪声影响 求导放大高频噪声 ⚠ 积分平滑掉高频 ✓
    数据要求 平滑轨迹 普通轨迹

    "求导放大噪声"是实测中很常见的失败原因： 采样得到的 \(\boldsymbol{x}\) 有测量噪声， 差分求 \(\dot{\boldsymbol{x}}\) 时噪声被除以很小的 \(\Delta t\) 而放大。

    所以积分形式不只是"理论漂亮"，而是实测更可用的选择。

    把上面的式子用一组具体数走一遍， 并在过程中把一个容易踩的坑标出来。

    取一维系统

    \[\dot{x} = -x + u, \qquad L = x^2 + u^2\]

    第一步：先算这个系统的精确最优 \(P^*\)。 连续黎卡提方程 \(2PA - PBR^{-1}B^{\mathsf T}P + Q = 0\)， 代入 \(A=-1\)、\(B=1\)、\(Q=R=1\)：

    \[-2P - P^2 + 1 = 0 \;\Longrightarrow\; P^2 + 2P - 1 = 0 \;\Longrightarrow\; P^* = \sqrt2 - 1 \approx 0.414214\]

    这一步最容易写错，务必按 \(A\) 的符号代： 本例 \(A=-1\) 是稳定系统，正根是 \(\sqrt2-1\approx0.414\)； 而 \(1+\sqrt2\approx2.414\) 是 \(A=+1\)（不稳定）时的解。 两个数只差一个正负号、结果差 5 倍多 —— 开平方前一定要把 \(A\) 的符号核对一遍。

    第二步：用积分关系反解。 采样时不必知道最优增益，随便取一个次优的 \(K=0.4\)， 用 \(u=-Kx\) 跑 60 段轨迹（每段从 \(x_0\sim U(-2,2)\) 出发， 仿真步长 \(0.01\)、每段 \(0.3\) s）。 对每段记录两端的 \(x^2\) 与该段累积代价 \(\int L\,\mathrm{d}t\)，得到方程

    \[\left[x(t)^2 - x(t+T)^2\right]\hat{P} = \int_t^{t+T}L\,\mathrm{d}t\]

    60 个方程、1 个未知数，最小二乘解出 \(\hat{P} = 0.417206\)。

    第三步：这个 \(0.417206\) 算得对不对？ 它离 \(P^*=0.414214\) 只差 \(0.72\%\) —— 在只用状态值与累积代价、完全不碰导数的前提下， 这已经是相当准的复原。

    那为什么不是零误差？ 因为 \(K=0.4\) 是一个次优增益， 而反解出的 \(\hat P\) 严格来说是"固定增益 \(K=0.4\) 下那条轨迹的值函数系数"。 把 \(K=0.4\) 代进固定增益的值函数公式可以自己验证：

    \[P(K) = \frac{1+K^2}{2\left(1+K\right)} = \frac{1+0.16}{2\times1.4} = 0.414286\]

    反解值 \(0.417206\) 与它只差 \(0.7\%\)（这部分来自采样噪声与有限窗口）。 而 \(P(0.4)=0.414286\) 又恰好非常接近 \(P^*=0.414214\) —— 本例的最优增益 \(K^*=P^*\approx0.414\)，与探测用的 \(0.4\) 几乎重合， 所以这次反解看起来"几乎直接得到了最优值"。

    结论要看两层：

    · IRL 确实成立：只用状态值与累积代价就反解出了值函数， 不需要 \(\dot x\)、不需要 \(f\) —— 这是积分形式的核心价值 · 反解出来的是"所用增益下的值函数"：若探测增益离最优很远， 反解值就明显偏离 \(P^*\)，必须靠迭代改进增益才能逼到最优。 本例只是恰好选得接近，才没有暴露这个差别

    这组数值也解释了 3.3 节为何强调积分： 整段计算只用 \(x(t)\) 与 \(x(t+T)\) 两个时刻的状态值， 一次求导都没有 —— 量测噪声因此不会被放大。

    四、在无人系统中的应用¶

    4.1 三条技术路线的关系¶

    层次 方法 需要模型 稳定性保证
    解析最优 LQR / HJB 需要 有
    表格动态规划 值迭代 / 策略迭代 需要 有
    自适应动态规划 评价网络 + 执行网络 不需要 需额外论证
    无模型强化学习 DQN / 策略梯度 不需要 一般没有

    这张表建议的做法很清楚：能建模就用 LQR； 只有"模型实在写不出来"时才往下走，并且必须自己做稳定性论证。

    4.2 典型应用场景¶

    场景 为什么用 ADP
    高超声速飞行器 气动参数随马赫数与攻角剧烈变化，在线辨识跟不上
    无人机编队 通道间耦合复杂，模型阶数高
    未知环境下的路径跟踪 环境扰动无法建模
    非线性执行器故障 故障模式无法预先枚举

    共同点：模型结构复杂或参数漂移显著，但能在线采集数据。

    4.3 工程上的注意事项¶

    问题 应对
    激励不足 → 参数不可辨 加探测噪声（保证持续激励）
    权重初值差 → 早期不稳定 用 LQR 解作为初值
    采样数据相关性强 用经验回放（打乱样本）
    状态量测噪声 优先用积分形式
    网络逼近误差 保留基线控制器兜底

    倒数第二条要特别说：上面 3.3 节讲过积分形式对噪声更稳， 这在实机上非常关键 —— 量测噪声是必然存在的。

    最后一条是工程底线：ADP 是"改进"而非"替代"。 实机上通常保留一个基本稳定的控制器， ADP 只在其基础上做修正，即使学习失败也能安全返回 ✓

    两种初值最终都收敛，但过程差别很大：

    初值 第 1 轮得到 12 轮后 与精确解之差
    零初值（\(P_0=0.1\)） \(3.7689\) \(2.0667\) \(1.3\times10^{-15}\)
    LQR 解作初值 \(2.0667\) \(2.0667\) \(1.3\times10^{-15}\)

    精确解 \(P=2.066746\)（与 2.3 节手算出的那个 \(P\) 是同一个， 参数也相同：\(a=0.9\)、\(b=0.5\)、\(q=r=1\)、\(\gamma=0.95\)）。

    两步就能把这张表读完：

    第一步：看零初值为什么会"跑过头"。 取 \(P_0=0.1\)，第一轮由 \(P\) 反解后跳到 \(3.7689\) —— 比答案 \(2.0667\) 大了 \(82\%\)。原因是这一轮的增益很小， 采到的数据里控制的作用弱，最小二乘就当"代价主要由状态引起"， 于是把 \(P\) 估得偏大。第二轮再纠正回来，此后 10 轮细化小数， 12 轮后落到 \(10^{-15}\) 量级。

    第二步：看 LQR 初值为什么"一步到位"。 用 LQR 解开局，意味着 \(P_0\) 已经等于 \(2.0667\)（精确解）。 这时增益就是最优增益，采出来的数据与模型自洽， 最小二乘解出来还是同一个数 —— 于是第 1 轮就已经在答案上。

    这一栏才是有用的那栏：两者最终精度相同（都是 \(10^{-15}\)）， 但"早期的过程"完全不同： 零初值在头两轮给出偏了 \(82\%\) 的 \(P\)， 而这个 \(P\) 会直接变成控制增益下发给系统。

    这就是工程上必须用"基线控制器兜底"的原因： 用 LQR 解作初值时，第 1 轮系统就已经是安全的； 零初值即使最终也能收敛，早期的控制量却可能很差。 学习过程本身要花时间，而物理系统在这段时间里是要飞、要跑的。

    换句话说：ADP 的价值是"在稳定基础上改进"， 而不是"从零学起" —— 初值的选择直接决定学习早期的安全性。

    五、例题¶

    例题 1：把值函数写成参数化形式¶

    题目：二维状态 \(\boldsymbol{x}=(x_1,x_2)\)， 写出二次型值函数 \(V=\boldsymbol{x}^{\mathsf T}P\boldsymbol{x}\) 的参数化形式与参数个数。

    思路

    把 \(P\) 展开成对称矩阵，逐项对应二次基函数。

    解答

    第一步：展开。

    \[ V = p_{11}x_1^2 + 2p_{12}x_1x_2 + p_{22}x_2^2 \]

    第二步：写成 \(\boldsymbol{w}^{\mathsf T}\boldsymbol{\phi}\)。

    \[ \boldsymbol{\phi}(\boldsymbol{x}) = \left[x_1^2,\ x_1x_2,\ x_2^2\right]^{\mathsf T}, \qquad \boldsymbol{w} = \left[p_{11},\ 2p_{12},\ p_{22}\right]^{\mathsf T} \]

    第三步：数参数。

    独立参数 3 个（对称矩阵有 \(n(n+1)/2\) 个）。 \(n=2\) 时是 3。

    对比：若用状态网格、每维 10 个点， 需要 \(10^2 = 100\) 个值。 参数化把 100 降到 3 —— 这就是它绕开维数灾难的方式。

    例题 2：为什么 DHP 学协态梯度而不学值函数¶

    题目：说明 DHP（学 \(\partial V/\partial\boldsymbol{x}\)）相对 HDP（学 \(V\)） 的优势。

    思路

    看控制律里用的是什么。

    解答

    第一步：控制律的形式。

    \[ \boldsymbol{u}^* = -R^{-1}B^{\mathsf T}\frac{\partial V}{\partial\boldsymbol{x}} \]

    它直接用梯度，不用 \(V\) 本身。

    第二步：HDP 要多做一步。

    学 \(V\) 后，还得再对 \(\boldsymbol{x}\) 求一次导才能得到控制律。 若 \(V\) 是近似的，求导会放大误差 ⚠

    第三步：DHP 的优势。

    DHP 直接近似 \(\boldsymbol{\lambda}=\partial V/\partial\boldsymbol{x}\)， 省掉求导这一步，精度更高。

    代价：\(\boldsymbol{\lambda}\) 是 \(n\) 维向量， 比标量 \(V\) 多 \(n\) 倍参数与计算量。

    例题 3：积分形式为什么更适合实测¶

    题目：状态量测有噪声时，为什么"用 \(\dot{\boldsymbol{x}}\) 的贝尔曼方程" 比"用积分形式的贝尔曼方程"更差？

    思路

    看差分求导对噪声的作用。

    解答

    第一步：差分求导的放大效应。

    用有限差分估 \(\dot{\boldsymbol{x}}\)：

    \[ \dot{\boldsymbol{x}} \approx \frac{\boldsymbol{x}(t+\Delta t)-\boldsymbol{x}(t)}{\Delta t} \]

    若量测噪声幅度为 \(\sigma\)，则差分后幅度约为

    \[ \frac{\sqrt{2}\sigma}{\Delta t} \]

    \(\Delta t\) 越小，噪声被放得越大。

    第二步：积分的作用。

    积分是平滑算子，高频噪声在积分后互相抵消。 信号（低频）保留，噪声（高频）被压掉。

    第三步：结论。

    用积分形式时，样本里只有 \(\boldsymbol{x}\) 的值， 没有"除以 \(\Delta t\)"这一步 —— 所以噪声不会被放大。

    答案是：因为求导是"放大高频"的运算， 而量测噪声正是高频的；积分恰好相反。

    例题 4：为什么必须用基线控制器兜底¶

    题目：从例 1 与 3.3 节的数据看，ADP 会收敛。 为什么工程上还要额外保留一个基线控制器？

    思路

    考虑"学习失败"与"学习早期"两种情形。

    解答

    第一步：学习失败的可能。

    失败原因 后果
    数据激励不足 参数不可辨，估计随意
    样本相关性强 最小二乘矩阵病态
    状态超出训练范围 外推不可靠
    网络结构不匹配 系统性偏差

    这些在实机上都会发生，且不一定会立刻显现。

    第二步：学习早期的问题。

    即使最终会收敛，第 1 轮参数可能很差。 若此时直接用它控制，系统可能已经出事了。

    第三步：兜底的作用。

    保留一个基本稳定的控制器（如 LQR 或 PID）， ADP 只输出修正量：

    \[ \boldsymbol{u} = \underbrace{\boldsymbol{u}_{\text{baseline}}}_{\text{保证稳定}} + \underbrace{\Delta\boldsymbol{u}_{\text{ADP}}}_{\text{改进}} \]

    答案是：因为学习过程本身有风险， 而物理系统不能承受"学失败"的后果。 兜底让系统在最坏情况下仍然是稳定的。

    小结¶

    概念 内容 作用
    参数化值函数 \(V=\boldsymbol{w}^{\mathsf T}\boldsymbol{\phi}(\boldsymbol{x})\) 把学函数变成学参数，绕开维数灾难
    评价网络 近似 \(V\) 或 \(Q\) 评估当前策略
    执行网络 近似 \(\pi\) 给出控制量
    最小二乘 \(\boldsymbol{w}=(\Phi^{\mathsf T}\Phi)^{-1}\Phi^{\mathsf T}\boldsymbol{r}\) 用一批数据一次算出权重
    DHP 学 \(\partial V/\partial\boldsymbol{x}\) 省掉求导，精度更高
    积分强化学习 用积分消掉 \(\dot{\boldsymbol{x}}\) 不需要动态、对噪声更稳
    工程底线 基线控制器 + ADP 修正 学习失败时仍稳定

    三条要点：

    1. ADP 的出发点是"已知的稳定性结构 + 未知的修正项" —— 不是从零学，而是在稳定基础上改进。
    2. 参数化 + 最小二乘是绕开维数灾难的关键： 参数个数 \(O(n^2)\) 取代网格点 \(m^n\)。
    3. 积分形式与基线兜底是工程可用的两个前提： 前者对付量测噪声，后者对付学习风险。
