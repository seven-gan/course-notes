    微分对策¶

    前面五章都只有一个决策者：静态优化是自己选 \(\boldsymbol{u}\)、LQR 是自己设计反馈、 动态规划是自己定策略 —— 无论哪一条路，都是"我选控制，让代价最小"。

    这一章把对手请进系统。除了我们可控的输入 \(\boldsymbol{u}\)， 系统里还多出一个不受我们控制、而且专门往坏里推的输入 \(\boldsymbol{d}\)：

    \[ \dot{\boldsymbol{x}} = f(\boldsymbol{x}) + g(\boldsymbol{x})\boldsymbol{u} + k(\boldsymbol{x})\boldsymbol{d} \]

    此时"最优"的含义变了：我们不再问"怎样让代价最小"， 而要问"如果对手总会挑最坏的那一手，我该怎么办"。

    看起来差不多的说法 实际差别 后果
    「对抗」就是系统里有噪声 噪声是随机的，对策里的 \(\boldsymbol{d}\) 是有策略、专挑最坏方向的 按噪声去处理会系统性低估最坏情况
    \(\min\) 与 \(\max\) 可以随便交换顺序 一般不能；能交换要满足 Isaacs 条件 交换错了会得到一个并不存在的"解"
    H∞ 控制是另一套理论 它就是零和博弈的线性二次特例 会以为要另学一套，其实是同一个方程

    这一页的核心问题

    要算的是最坏情况下的最优：\(\min_{\boldsymbol{u}}\max_{\boldsymbol{d}} J\)。

    当 \(\min\) 与 \(\max\) 可以交换顺序时，存在一个鞍点 \((\boldsymbol{u}^*,\boldsymbol{d}^*)\)，它的值 \(V^*\) 就叫对策值。 整章的技术核心就是：这个交换什么时候成立，成立后方程长什么样。

    一、用 Pontryagin 最小原理与 Bellman 方程重新导出最优控制¶

    （大纲 6.1 ｜ 教材 10.1）

    先看单人情形。为什么要在对策这一章里重讲最优控制？ 因为对策的每一步推理都跟它同形 —— 先把"单人"的结果写成 Hamiltonian 语言，后面"多一个对手"就只是多一个输入而已。

    1.1 系统与值积分¶

    考虑连续时间非线性仿射系统

    \[ \dot{\boldsymbol{x}} = F(\boldsymbol{x},\boldsymbol{u}) = f(\boldsymbol{x}) + g(\boldsymbol{x})\boldsymbol{u},\qquad \boldsymbol{x}(t)\in\mathbb{R}^n,\ \boldsymbol{u}(t)\in\mathbb{R}^m \tag{10.1-1} \]

    其中 \(f\) 局部 Lipschitz、\(f(\boldsymbol{0})=\boldsymbol{0}\)， 所以 \(\boldsymbol{x}=\boldsymbol{0}\) 是平衡点。与之相配的值积分是

    \[ V(\boldsymbol{x}(t)) = \int_t^{\infty} r(\boldsymbol{x},\boldsymbol{u})\,d\tau = \int_t^{\infty}\left(Q(\boldsymbol{x}) + \boldsymbol{u}^{\mathsf T}R\boldsymbol{u}\right)d\tau, \qquad Q(\boldsymbol{x})>0,\ R>0 \tag{10.1-2} \]

    读法：\(V(\boldsymbol{x}(t))\) 是"从当前状态出发、用某个控制律一路走到无穷"所累积的总代价。 一个控制律称为可容许的，如果它连续、能镇定系统 (10.1-1)、并让 (10.1-2) 有界。 最优控制问题就是：在所有可容许控制里挑一个，使 \(V\) 最小。

    注意这里的指标是 \(Q(\boldsymbol{x})+\boldsymbol{u}^{\mathsf T}R\boldsymbol{u}\)， 不含 \(\frac12\)。这个写法出自教材第 10 章； 上一章（动态规划）用的是 \(\frac12(\boldsymbol{x}^{\mathsf T}Q\boldsymbol{x}+\boldsymbol{u}^{\mathsf T}R\boldsymbol{u})\)。 两者的差别会在 1.3 节显现为一个 \(\frac12\) 因子， 本页按教材第 10 章的写法，并在用到的地方点明差异。

    1.2 Bellman 方程：Hamiltonian 被令为零¶

    \(V\) 通过 \(\boldsymbol{x}(t)\) 依赖时间，用 Leibniz 公式求导：

    \[ \frac{dV}{dt} = \left(\frac{\partial V}{\partial \boldsymbol{x}}\right)^{\mathsf T}\dot{\boldsymbol{x}} \]

    把 (10.1-2) 的被积函数记为 \(r\)，则值积分与下面这个微分等式等价：

    \[ 0 = r(\boldsymbol{x},\boldsymbol{u}) + \dot V = Q(\boldsymbol{x}) + \boldsymbol{u}^{\mathsf T}R\boldsymbol{u} + \left(\frac{\partial V}{\partial \boldsymbol{x}}\right)^{\mathsf T} \left(f(\boldsymbol{x})+g(\boldsymbol{x})\boldsymbol{u}\right) \equiv \mathcal{H}\!\left(\boldsymbol{x},\frac{\partial V}{\partial \boldsymbol{x}},\boldsymbol{u}\right) \tag{10.1-3} \]

    右边这个量 \(\mathcal{H}\) 就叫 Hamiltonian 函数。 于是 (10.1-3) 说的是：在最优值函数上，Hamiltonian 恒等于零。

    变分法里的 Hamiltonian 并不等于零，别把两处混起来

    在第 4 章用变分法推导时，Hamiltonian 只是一个中间量 —— 它的各个偏导数分别给出状态方程、协态方程与最优控制， 但没有任何地方要求它为零。

    这里之所以出现 \(\mathcal{H}=0\)，是因为它来自 "对值积分 (10.1-2) 求导"这一步，是那份积分的微分等价形式。 两处的 \(\mathcal{H}\) 是同一个函数，但约束不同。

    还有一处更值得记住的对应：变分法里的协态 \(\boldsymbol{\lambda}\)， 就是这里的梯度 \(\nabla V(\boldsymbol{x})\)。

    1.3 Pontryagin 最小原理给出最优控制律¶

    选控制使值最小，其必要条件就是 Pontryagin 最小原理（PMP）：

    \[ \mathcal{H}\!\left(\boldsymbol{x}^*,\frac{\partial V^*}{\partial \boldsymbol{x}},\boldsymbol{u}^*\right) \le \mathcal{H}\!\left(\boldsymbol{x}^*,\frac{\partial V^*}{\partial \boldsymbol{x}},\boldsymbol{u}\right) \qquad\text{对一切可容许 }\boldsymbol{u} \tag{10.1-4} \]

    其中 \(*\) 标记最优的状态、值函数与控制。因为 \(\boldsymbol{u}\) 无约束， (10.1-4) 等价于驻定条件

    \[ \frac{\partial \mathcal{H}}{\partial \boldsymbol{u}} = \boldsymbol{0} \tag{10.1-5} \]

    把 (10.1-3) 代入求导：对 \(\boldsymbol{u}\) 求导时只有 \(\boldsymbol{u}^{\mathsf T}R\boldsymbol{u}\) 与 \(\nabla V^{\mathsf T}g\boldsymbol{u}\) 两项活着，得到 \(2R\boldsymbol{u} + g^{\mathsf T}(\boldsymbol{x})\nabla V = \boldsymbol{0}\)，于是

    \[ \boldsymbol{u} = \boldsymbol{u}(V(\boldsymbol{x})) \equiv -\frac12 R^{-1}g^{\mathsf T}(\boldsymbol{x})\nabla V(\boldsymbol{x}) \tag{10.1-6} \]

    这里那个 \(\frac12\) 正是 1.1 节说过的口径差：因为指标里 \(R\) 前没有 \(\frac12\)， 求导后 \(2R\) 的因子留下了 \(\frac12\)。若像上一章那样把指标写成 \(\frac12(\boldsymbol{x}^{\mathsf T}Q\boldsymbol{x}+\boldsymbol{u}^{\mathsf T}R\boldsymbol{u})\)， 同一个式子会写成 \(\boldsymbol{u}=-R^{-1}g^{\mathsf T}\nabla V\) —— 两者是同一个结果，只是 \(R\) 的口径不同。读文献时必须先看清指标里有没有 \(\frac12\)。

    把 (10.1-6) 代回 (10.1-3)，并写成梯度 \(\nabla V = \partial V/\partial\boldsymbol{x}\) 的形式：

    \[ 0 = Q(\boldsymbol{x}) + \nabla V^{\mathsf T}(\boldsymbol{x}) f(\boldsymbol{x}) - \frac14 \nabla V^{\mathsf T}(\boldsymbol{x}) g(\boldsymbol{x}) R^{-1} g^{\mathsf T}(\boldsymbol{x}) \nabla V(\boldsymbol{x}), \qquad V(\boldsymbol{0})=0 \tag{10.1-7} \]

    这就是 HJB 方程（上一章已见过），它也可以写成更紧凑的两种形式：

    \[ 0 = \min_{\boldsymbol{u}} \left[\mathcal{H}(\boldsymbol{x},\nabla V^*,\boldsymbol{u})\right] \tag{10.1-8} \qquad\text{或}\qquad 0 = \mathcal{H}(\boldsymbol{x}^*,\nabla V^*,\boldsymbol{u}^*) \tag{10.1-9} \]

    三件事连起来读：Hamiltonian 是核心对象 → 它对 \(\boldsymbol{u}\) 求导给出控制律 → Bellman 方程说它恒为零。求解顺序是"先解 (10.1-7) 得到 \(V^*>0\)， 再用 (10.1-6) 把最优控制写成状态反馈 \(\boldsymbol{u}(V^*(\boldsymbol{x}))\)"。

    1.4 三条推导路线给出同一个 HJB¶

    变分法（第 4 章） 动态规划（第 5 章） 本章（PMP + Bellman）
    出发点 增广泛函、取变分 最优性原理 Hamiltonian + PMP
    中间量 协态 \(\boldsymbol{\lambda}\) 值函数 \(V\) 梯度 \(\nabla V\)（即协态）
    得到 两点边值 / 黎卡提方程 HJB 方程 HJB 方程
    额外结论 无 \(\mathcal{H}\) 不必为零 \(\mathcal{H}=0\)

    三条路给出同一个 HJB，这本身就是结论：HJB 是这类最优控制问题的共同核心， 而这一章选"PMP + Bellman"这条路的理由，是它能原样推广到有对手的情形 —— 把 \(\min\) 换成 \(\min\max\) 就行。

    二、两人零和博弈¶

    （大纲 6.2 ｜ 教材 10.2）

    2.1 系统与性能指标¶

    \[ \dot{\boldsymbol{x}} = f(\boldsymbol{x}) + g(\boldsymbol{x})\boldsymbol{u} + k(\boldsymbol{x})\boldsymbol{d}, \qquad \boldsymbol{d}(t)\in\mathbb{R}^q \tag{10.2-1} \]

    系统有两个输入：控制 \(\boldsymbol{u}\)（我们选，想最小化代价） 与扰动 \(\boldsymbol{d}\)（对方选，想最大化代价）。性能指标取

    \[ J(\boldsymbol{x}(0),\boldsymbol{u},\boldsymbol{d}) = \int_0^\infty \left(Q(\boldsymbol{x}) + \boldsymbol{u}^{\mathsf T}R\boldsymbol{u} - \gamma^2\|\boldsymbol{d}\|^2\right)d\tau, \qquad Q = h^{\mathsf T}h \ge 0,\ R=R^{\mathsf T}>0,\ \gamma>0 \tag{10.2-2} \]

    两个符号要看清楚：\(\boldsymbol{u}\) 前面是 \(+\)，\(\boldsymbol{d}\) 前面是 \(-\)。 想让 \(J\) 小的一方会希望 \(\boldsymbol{d}\) 也小 —— 因为 \(\boldsymbol{d}\) 越大， \(-\gamma^2\|\boldsymbol{d}\|^2\) 这一项越负、\(J\) 越小，正合对手的心意。 这个"符号差"就是把两人推到对立面的机关。 至于 \(\gamma\) 的物理含义，要等第三节才看清，这里先把它当成"给扰动留的配额"。

    2.2 鞍点与 Nash 条件¶

    \[ V^*(\boldsymbol{x}(0)) = \min_{\boldsymbol{u}}\max_{\boldsymbol{d}} J(\boldsymbol{x},\boldsymbol{u},\boldsymbol{d}) = \max_{\boldsymbol{d}}\min_{\boldsymbol{u}} J(\boldsymbol{x},\boldsymbol{u},\boldsymbol{d}) \tag{10.2-4} \]

    这一点最要紧：一般情况下 \(\min\max \ne \max\min\)。 两者相等时，存在一个鞍点 \((\boldsymbol{u}^*,\boldsymbol{d}^*)\)，\(V^*\) 叫对策值。 等价的 Nash 均衡条件是

    \[ J(\boldsymbol{x}(0),\boldsymbol{u}^*,\boldsymbol{d}) \le J(\boldsymbol{x}(0),\boldsymbol{u}^*,\boldsymbol{d}^*) \le J(\boldsymbol{x}(0),\boldsymbol{u},\boldsymbol{d}^*) \qquad\text{对一切 }\boldsymbol{u},\boldsymbol{d} \tag{10.2-5} \]

    读法：两边都没有单方面改变策略的动机 —— 固定住对手的策略，自己一改只会更差。 左半边说的是"扰动方已取到最坏"，右半边说的是"控制方已取到最优"。

    \(\min\max\) 与 \(\max\min\) 的差别不是文字游戏，它们对应谁先动手：

    \(\max_{\boldsymbol{d}}\min_{\boldsymbol{u}} J\) \(\min_{\boldsymbol{u}}\max_{\boldsymbol{d}} J\)
    谁后动手 控制方（先看 \(\boldsymbol{d}\) 再选 \(\boldsymbol{u}\)） 扰动方（先看 \(\boldsymbol{u}\) 再挑最坏的 \(\boldsymbol{d}\)）
    谁占便宜 控制方 扰动方
    一般关系 它是 \(\min\max\) 的下界 它是 \(\max\min\) 的上界
    相等时 存在鞍点 此时两边都取到 \(V^*\)

    一般关系就是弱对偶：\(\max_{\boldsymbol{d}}\min_{\boldsymbol{u}} J \le \min_{\boldsymbol{u}}\max_{\boldsymbol{d}} J\)。 两边相等时，\(\max\min\) 与 \(\min\max\) 可以互换 —— 这正是鞍点的定义， 也是"对策值"这个词站得住脚的前提。注意如果 \(J\) 对 \(\boldsymbol{u}\) 不凸、 对 \(\boldsymbol{d}\) 不凹，两条边可能严格不等，那时鞍点不存在， 只能谈上值与下值两个不同的数。

    2.3 值函数、Bellman 方程与 Isaacs 条件¶

    对固定的反馈策略 \(\boldsymbol{u}(\boldsymbol{x})\)、\(\boldsymbol{d}(\boldsymbol{x})\)， 值函数仍是 (10.2-2) 那份积分，此时它只依赖初始状态：

    \[ V(\boldsymbol{x}(t),\boldsymbol{u},\boldsymbol{d}) = \int_t^\infty \left(h^{\mathsf T}h + \boldsymbol{u}^{\mathsf T}R\boldsymbol{u} - \gamma^2\|\boldsymbol{d}\|^2\right)d\tau \tag{10.2-6} \]

    同样用 Leibniz 求导，得到零和博弈的 Bellman 方程：

    \[ 0 = h^{\mathsf T}h + \boldsymbol{u}^{\mathsf T}R\boldsymbol{u} - \gamma^2\|\boldsymbol{d}\|^2 + \nabla V^{\mathsf T}(f + g\boldsymbol{u} + k\boldsymbol{d}) \equiv \mathcal{H}(\boldsymbol{x},\nabla V,\boldsymbol{u},\boldsymbol{d}) \tag{10.2-7} \]

    需求鞍点的必要条件（Nash 条件 (10.2-4) 的必要条件）就是 Isaacs 条件：

    \[ \min_{\boldsymbol{u}}\max_{\boldsymbol{d}}\ \mathcal{H}(\boldsymbol{x},\nabla V,\boldsymbol{u},\boldsymbol{d}) = \max_{\boldsymbol{d}}\min_{\boldsymbol{u}}\ \mathcal{H}(\boldsymbol{x},\nabla V,\boldsymbol{u},\boldsymbol{d}) \tag{10.2-8} \]

    它等价于下面的点态不等式（对一切策略 \(\boldsymbol{u},\boldsymbol{d}\)，逐时刻成立）：

    \[ \mathcal{H}(\boldsymbol{x},\nabla V,\boldsymbol{u}^*,\boldsymbol{d}) \le \mathcal{H}(\boldsymbol{x},\nabla V,\boldsymbol{u}^*,\boldsymbol{d}^*) \le \mathcal{H}(\boldsymbol{x},\nabla V,\boldsymbol{u},\boldsymbol{d}^*) \tag{10.2-9} \]

    Isaacs 条件就是 PMP 在博弈里的推广：单人时 (10.1-4) 只有一个 \(\min\)， 现在要在同一时刻既取 \(\min\) 又取 \(\max\)。

    没有 Isaacs 条件，就没有单一的「对策值」

    Isaacs 条件成立，\(\min\max=\max\min\)，才有鞍点、才有唯一的对策值。 不成立时，上下两个值不相等，只能说"对策的值在某个区间里"， 这时固定的最优反馈策略可能根本不存在。 所以下面所有推导都以 Isaacs 条件为前提。

    2.4 驻定条件给出两个策略¶

    在均衡点上有两个驻定条件：

    \[ \frac{\partial \mathcal{H}}{\partial \boldsymbol{u}} = \boldsymbol{0}, \qquad \frac{\partial \mathcal{H}}{\partial \boldsymbol{d}} = \boldsymbol{0} \tag{10.2-10} \]

    先看二阶导：由 (10.2-7) 得 \(\partial^2\mathcal{H}/\partial\boldsymbol{u}^2 = 2R > 0\)， 而 \(\partial^2\mathcal{H}/\partial\boldsymbol{d}^2 = -2\gamma^2 \lt 0\)。 同一个驻点，对 \(\boldsymbol{u}\) 是极小、对 \(\boldsymbol{d}\) 是极大 —— 这正是"鞍点"的字面含义，也是代码里 saddle 这个名字的由来。

    分别求导并解出：

    \[ \boldsymbol{u} = \boldsymbol{u}(V(\boldsymbol{x})) \equiv -\frac12 R^{-1}g^{\mathsf T}(\boldsymbol{x})\nabla V \tag{10.2-11} \]
    \[ \boldsymbol{d} = \boldsymbol{d}(V(\boldsymbol{x})) \equiv \frac{1}{2\gamma^2} k^{\mathsf T}(\boldsymbol{x})\nabla V \tag{10.2-12} \]

    两个式子符号相反：控制项要"抵消"状态梯度（把 \(\boldsymbol{x}\) 往零拉）， 扰动项却"顺着"状态梯度推（把 \(\boldsymbol{x}\) 推离零）。这就是对抗。

    把 (10.2-11)、(10.2-12) 代回 (10.2-7)，得到 哈密顿-雅可比-艾萨克斯方程（HJI）：

    \[ 0 = h^{\mathsf T}h + \nabla V^{\mathsf T}(\boldsymbol{x}) f(\boldsymbol{x}) - \frac14 \nabla V^{\mathsf T}(\boldsymbol{x}) g(\boldsymbol{x}) R^{-1} g^{\mathsf T}(\boldsymbol{x}) \nabla V(\boldsymbol{x}) + \frac{1}{4\gamma^2} \nabla V^{\mathsf T}(\boldsymbol{x}) k k^{\mathsf T} \nabla V(\boldsymbol{x}), \qquad V(\boldsymbol{0})=0 \tag{10.2-13} \]

    与单人情形 (10.1-7) 逐项对照：前三项一字不差， 只多出最后一项 \(+\frac{1}{4\gamma^2}\nabla V^{\mathsf T}kk^{\mathsf T}\nabla V\)。 这一项的意思是：对手也在通过 \(\gamma\) 影响值函数 —— \(\gamma\) 越小，这一项越大，值函数被抬高得越厉害（对手越强）。

    2.5 一个关键引理：Hamiltonian 是「偏差的二次型」¶

    引理 10.2-1：对任意产生有限值的策略 \(\boldsymbol{u}(\boldsymbol{x}),\boldsymbol{d}(\boldsymbol{x})\)， 设 \(V\ge 0\) 是 (10.2-7) 的对应解，并按 (10.2-11)、(10.2-12) 定义 \(\boldsymbol{u}^*,\boldsymbol{d}^*\)，则

    \[ \mathcal{H}(\boldsymbol{x},\nabla V,\boldsymbol{u},\boldsymbol{d}) = \mathcal{H}(\boldsymbol{x},\nabla V,\boldsymbol{u}^*,\boldsymbol{d}^*) + (\boldsymbol{u}-\boldsymbol{u}^*)^{\mathsf T}R(\boldsymbol{u}-\boldsymbol{u}^*) - \gamma^2\|\boldsymbol{d}-\boldsymbol{d}^*\|^2 \tag{10.2-15} \]

    怎么来的：把 (10.2-7) 中的 \(\boldsymbol{u}\)、\(\boldsymbol{d}\) 项配方（即教材习题 10.2-1）。 配方的中间量就是 (10.2-11)、(10.2-12) 那两个驻定点。

    为什么它有用：若 \(V\) 是 HJI (10.2-13) 的解，则 \(\mathcal{H}(\boldsymbol{u}^*,\boldsymbol{d}^*)=0\)，于是

    \[ \mathcal{H}(\boldsymbol{x},\nabla V^*,\boldsymbol{u},\boldsymbol{d}) = (\boldsymbol{u}-\boldsymbol{u}^*)^{\mathsf T}R(\boldsymbol{u}-\boldsymbol{u}^*) - \gamma^2\|\boldsymbol{d}-\boldsymbol{d}^*\|^2 \tag{10.2-16} \]

    右边在 \((\boldsymbol{u}^*,\boldsymbol{d}^*)\) 处两项同时为零，取到鞍点值； 离开鞍点后第一项（\(\ge 0\)）上升、第二项（\(\le 0\)）下降， 一边升一边降，鞍点的形状就显出来了。

    2.6 定理：HJI 的半正定解就是 Nash 解¶

    定理 10.2-2：设对策 (10.2-3) 有有限值。取 \(\gamma > \gamma^* > 0\)， 设 \(V^*(\boldsymbol{x})\in C^1\) 是 HJI (10.2-13) 的光滑半正定解，且使闭环

    \[ \dot{\boldsymbol{x}} = f(\boldsymbol{x}) + g\boldsymbol{u}^* + k\boldsymbol{d}^* = f(\boldsymbol{x}) - \frac12 gR^{-1}g^{\mathsf T}\nabla V^* + \frac{1}{2\gamma^2} k k^{\mathsf T}\nabla V^* \tag{10.2-18} \]

    局部渐近稳定；又设系统 \(\dot{\boldsymbol{x}}=f+g\boldsymbol{u},\ \boldsymbol{y}=h(\boldsymbol{x})\) 零状态可观（\(\boldsymbol{u}\equiv\boldsymbol{0},\boldsymbol{y}\equiv\boldsymbol{0}\Rightarrow\boldsymbol{x}=\boldsymbol{0}\)）。 则 (10.2-11)、(10.2-12) 给出的 \((\boldsymbol{u}^*,\boldsymbol{d}^*)\) 是鞍点均衡， 对策有值，且对策值就是 \(V^*(\boldsymbol{x}(0))\)。

    证明的思路值得记下来（它也是这一章的思维方式）。 对任意 \(C^1\) 的 \(V\)，把 \(\int r\,d\tau\) 加上再减去 \(\int \dot V d\tau\)，用 \(V(\boldsymbol{x}(\infty))=0\)：

    \[ J_T(\boldsymbol{x}(0),\boldsymbol{u},\boldsymbol{d}) = \int_0^T \left(h^{\mathsf T}h + \boldsymbol{u}^{\mathsf T}R\boldsymbol{u} - \gamma^2\|\boldsymbol{d}\|^2\right)dt + \int_0^T \dot V dt - V(\boldsymbol{x}(T)) + V(\boldsymbol{x}(0)) \]

    把 \(\dot V = \nabla V^{\mathsf T}(f+g\boldsymbol{u}+k\boldsymbol{d})\) 并进第一项， 括号里恰好拼成 \(\mathcal{H}\)：

    \[ J_T = \int_0^T \mathcal{H}(\boldsymbol{x},\nabla V,\boldsymbol{u},\boldsymbol{d})\,dt - V(\boldsymbol{x}(T)) + V(\boldsymbol{x}(0)) \]

    再令 \(V=V^*\) 满足 HJI（即 \(\mathcal{H}(\boldsymbol{u}^*,\boldsymbol{d}^*)=0\)）、 用引理 (10.2-16) 把 \(\mathcal{H}\) 换掉，并对 \(T\to\infty\) 取极限：

    \[ J(\boldsymbol{x}(0),\boldsymbol{u},\boldsymbol{d}) = \int_0^\infty\left[(\boldsymbol{u}-\boldsymbol{u}^*)^{\mathsf T}R(\boldsymbol{u}-\boldsymbol{u}^*) - \gamma^2\|\boldsymbol{d}-\boldsymbol{d}^*\|^2\right]dt + V^*(\boldsymbol{x}(0)) \]

    右边在 \((\boldsymbol{u}^*,\boldsymbol{d}^*)\) 处取鞍点值 \(V^*(\boldsymbol{x}(0))\)， 这就证明了 (10.2-5)。

    顺带得到一个重要认识：\(V^*\) 同时是值函数、又是闭环系统的 Lyapunov 函数、 还是性能指标本身（\(J^*=V^*\)）。这三个身份是同一个东西 —— 后面第三节的稳定性证明、第四节的多玩家推广，都靠这一点。

    两个容易踩的坑

    第一，HJI 的半正定解可能有多个。要选的是最小半正定解 （不存在比它更小的非负解）—— 只有它对应闭环稳定， 这一点与第 3 章里"黎卡提方程要取稳定解"是同一回事。

    第二，非线性 HJI 一般没有光滑解，通常只有粘性解， 实际只能离线数值求解。这正是后面第 7、8 章转向 "用数据在线学"的动机。

    三、零和博弈在 H∞ 控制中的应用¶

    （大纲 6.3 ｜ 教材 10.3）

    3.1 有界 L2 增益问题¶

    给系统 (10.2-1) 配上输出 \(\boldsymbol{y}=h(\boldsymbol{x})\)， 再把性能输出定义为 \(\boldsymbol{z}(t)=[\boldsymbol{u}^{\mathsf T}(t)\ \ \boldsymbol{y}^{\mathsf T}(t)]^{\mathsf T}\)。 要求找一个反馈 \(\boldsymbol{u}(\boldsymbol{x})\)，使得在 \(\boldsymbol{x}(0)=\boldsymbol{0}\) 时， 对一切 \(\boldsymbol{d}\in L_2[0,\infty)\) 和一切 \(T>0\) 都有

    \[ \frac{\int_0^T\|\boldsymbol{z}(t)\|^2 dt}{\int_0^T\|\boldsymbol{d}(t)\|^2 dt} = \frac{\int_0^T\left(h^{\mathsf T}h + \boldsymbol{u}^{\mathsf T}R\boldsymbol{u}\right)dt} {\int_0^T\|\boldsymbol{d}(t)\|^2 dt} \le \gamma^2 \tag{10.3-1} \]

    读法：从扰动到性能输出的"能量放大倍数"不超过 \(\gamma\)。 这就是"有界 \(L_2\) 增益"。\(H_\infty\) 控制问题则更进一步：求最小的 \(\gamma^*>0\)， 使得任意 \(\gamma>\gamma^*\) 时 (10.3-1) 都有解 —— 这个 \(\gamma^*\) 就叫 \(H_\infty\) 增益（线性情形有显式表达）。

    与零和博弈的连接点在这里：\(H_\infty\) 里的 \(\boldsymbol{d}\) 是外来的、 不可控的扰动；但设计要求"对一切 \(\boldsymbol{d}\) 都成立"， 等价于把 \(\boldsymbol{d}\) 当成一个会挑最坏情况的对手。 于是"最坏情形下设计 \(\boldsymbol{u}\)"这件事，恰好就是 (10.2-3) 那个零和博弈。

    3.2 HJI 的解给出 H∞ 控制器¶

    定理 10.3-1：取 \(\gamma>\gamma^*>0\)，设 \(V^*>0\) 是 HJI (10.2-13) 的光滑正定解， 且 (10.2-17) 零状态可观。则用

    \[ \boldsymbol{u}^* = -\frac12 R^{-1}g^{\mathsf T}\nabla V^* \tag{10.2-11} \]

    得到的闭环 \(\dot{\boldsymbol{x}} = f(\boldsymbol{x}) + g(\boldsymbol{x})\boldsymbol{u}^*\) 局部渐近稳定，并且对一切 \(\boldsymbol{d}\in L_2\) 都满足 (10.3-1)。

    证明的关键一步。由两条求导关系可得

    \[ \frac{dV}{dt} + h^{\mathsf T}h + \boldsymbol{u}^{\mathsf T}R\boldsymbol{u} - \gamma^2\boldsymbol{d}^{\mathsf T}\boldsymbol{d} = \mathcal{H}(\boldsymbol{x},\nabla V,\boldsymbol{u},\boldsymbol{d}) = -\gamma^2\|\boldsymbol{d}-\boldsymbol{d}^*\|^2 + (\boldsymbol{u}-\boldsymbol{u}^*)^{\mathsf T}R(\boldsymbol{u}-\boldsymbol{u}^*) \]

    这里第二次等号用了引理 (10.2-16)。取 \(\boldsymbol{u}=\boldsymbol{u}^*\)，第一项消失：

    \[ \frac{dV}{dt} + h^{\mathsf T}h + \boldsymbol{u}^{\mathsf T}R\boldsymbol{u} - \gamma^2\boldsymbol{d}^{\mathsf T}\boldsymbol{d} \le 0 \tag{10.3-3} \]

    对任意 \(\boldsymbol{d}\) 都成立。两边从 \(0\) 到 \(T\) 积分，令 \(\boldsymbol{x}(0)=\boldsymbol{0}\) （于是 \(V(0)=0\)）并注意 \(V(\boldsymbol{x}(T))>0\)：

    \[ \int_0^T\left(h^{\mathsf T}h + \boldsymbol{u}^{\mathsf T}R\boldsymbol{u}\right)dt \le \gamma^2\int_0^T \boldsymbol{d}^{\mathsf T}\boldsymbol{d}\,dt \]

    (10.3-1) 得证。顺带：在 (10.3-3) 里取 \(\boldsymbol{d}=\boldsymbol{0}\)，得到 \(dV/dt \le -\|\boldsymbol{z}\|^2 \le 0\)，所以 \(V\) 是 Lyapunov 函数， 闭环稳定（严格论证还要用 LaSalle 定理与零状态可观，此处不展开）。

    (10.2-12) 那个

    \[ \boldsymbol{d}^* = \frac{1}{2\gamma^2}k^{\mathsf T}\nabla V^* \tag{10.2-12} \]

    叫最坏扰动。要看清它的身份：它不是"要去施加的扰动"， 而是设计时假想的那个把性能推到最不利方向的扰动， 用来检验控制器在边界情况下够不够好。

    3.3 线性二次零和对策与博弈黎卡提方程¶

    现在把问题限制到线性二次情形：动态

    \[ \dot{\boldsymbol{x}} = A\boldsymbol{x} + B\boldsymbol{u} + D\boldsymbol{d} \tag{10.3-4} \]

    值取二次型（\(\frac12\) 又回来了，因为线性二次的指标惯例带 \(\frac12\)）：

    \[ V(\boldsymbol{x}(t),\boldsymbol{u},\boldsymbol{d}) = \frac12\int_t^\infty\left(\boldsymbol{x}^{\mathsf T}H^{\mathsf T}H\boldsymbol{x} + \boldsymbol{u}^{\mathsf T}R\boldsymbol{u} - \gamma^2\|\boldsymbol{d}\|^2\right)d\tau, \qquad V(\boldsymbol{x}) = \frac12\boldsymbol{x}^{\mathsf T}S\boldsymbol{x} \tag{10.3-5,\ 10.3-6} \]

    设反馈 \(\boldsymbol{u}=-K\boldsymbol{x}\)、\(\boldsymbol{d}=L\boldsymbol{x}\)，代入 Bellman 方程 (10.2-7) 并消去 \(\boldsymbol{x}\)，得到一个关于 \(S\) 的 Lyapunov 方程（给定 \(K,L\)）：

    \[ S(A-BK+DL) + (A-BK+DL)^{\mathsf T}S + H^{\mathsf T}H + K^{\mathsf T}RK - \gamma^2L^{\mathsf T}L = 0 \tag{10.3-9} \]

    再由驻定条件 (10.2-10) 得到两个增益：

    \[ \boldsymbol{u}(\boldsymbol{x}) = -R^{-1}B^{\mathsf T}S\boldsymbol{x} = -K\boldsymbol{x}, \qquad \boldsymbol{d}(\boldsymbol{x}) = \frac{1}{\gamma^2}D^{\mathsf T}S\boldsymbol{x} = L\boldsymbol{x} \tag{10.3-10,\ 10.3-11} \]

    把它们代回 (10.3-9)，消掉 \(K,L\)，得到博弈代数黎卡提方程（GARE）：

    \[ 0 = A^{\mathsf T}S + SA + H^{\mathsf T}H - SBR^{-1}B^{\mathsf T}S + \frac{1}{\gamma^2}SDD^{\mathsf T}S \tag{10.3-12} \]

    与 LQR 的 ARE 逐项对比：前四项一模一样， 只多出最后一项 \(+\frac{1}{\gamma^2}SDD^{\mathsf T}S\)。 这一项就是对手的"位置"（\(D\)）与"强度"（\(1/\gamma^2\)）。

    存在 \(S>0\) 的条件是：\((A,B)\) 可镇定、\((A,\sqrt{Q})\) 可观测、且 \(\gamma>\gamma^*\)。 解也可能不止一个，要的是使 \((A-BK+DL)\) 极点全在左半平面的那个最小半正定解 （"稳定解"）—— 与第 3 章里 ARE 取稳定解的做法完全类似， 稳定解同样对应某个 Hamiltonian 矩阵的稳定特征空间。

    3.4 临界增益怎么来的（标量情形）¶

    把 (10.3-12) 用在标量系统上，\(\gamma^*\) 会自己冒出来。 取 \(A=0\)、\(B=1\)、\(D=1\)、\(H^{\mathsf T}H=q>0\)、\(R=r>0\)，GARE 变成

    \[ 0 = 0 + 0 + q - \frac{S^2}{r} + \frac{S^2}{\gamma^2} = q + S^2\left(\frac{1}{\gamma^2} - \frac{1}{r}\right) \]

    要 \(S>0\)，必须先有 \(\dfrac{1}{\gamma^2} \lt \dfrac{1}{r}\)，即

    \[ \gamma \gt \sqrt{r} \equiv \gamma^* \]

    这就是临界增益的来历：它不是一个额外的假设， 而是 GARE 有正解这一条件本身给出来的。 解出正根

    \[ S = \sqrt{\frac{q\,r\,\gamma^2}{\gamma^2 - r}} \]

    再取 \(\gamma\to\infty\)：\(S\to\sqrt{qr}\)，而这正是同一系统在没有扰动时的 LQR 解 （\(0=q-S^2/r\)）。所以\(\gamma\) 越大，对策解越接近 LQR 解； \(\gamma\) 越小、对手越强，\(S\) 被抬得越高、越难满足。

    上图（右侧那张）画的正是这个式子：取 \(q=1\)、\(r=4\)，则 \(\gamma^*=\sqrt4=2\)， 曲线在 \(\gamma\to2^+\) 处发散，在 \(\gamma\to\infty\) 处趋于 \(2\) —— 那条水平的渐近线就是 LQR 值 \(\sqrt{qr}=2\)。

    四、多人非零和博弈¶

    （大纲 6.4 ｜ 教材 10.4）

    零和博弈是"一人所得即他人所失"。但真实的多智能体系统里， 既有朝共同目标使劲的合作，也有各自打算的竞争。这一节把两者放进同一套方程。

    4.1 系统与各自的目标¶

    \[ \dot{\boldsymbol{x}} = f(\boldsymbol{x}) + \sum_{j=1}^{N} g_j(\boldsymbol{x})\boldsymbol{u}_j, \qquad \boldsymbol{u}_j\in\mathbb{R}^{m_j} \tag{10.4-1} \]

    有 \(N\) 个玩家，都通过影响同一个状态 \(\boldsymbol{x}\) 而互相影响。 第 \(i\) 个玩家的性能指标是

    \[ J_i = \int_0^\infty\left(Q_i(\boldsymbol{x}) + \sum_{j=1}^{N}\boldsymbol{u}_j^{\mathsf T}R_{ij}\boldsymbol{u}_j\right)d\tau, \qquad Q_i\ge 0,\ R_{ii}>0,\ R_{ij}\ge 0\ (j\ne i) \tag{10.4-2} \]

    \(R_{ij}\) 的两种角色要分清：\(R_{ii}>0\) 是"我自己控制的代价权重"； \(R_{ij}\ge 0\ (j\ne i)\) 是"别人的控制对我代价的影响" —— 这一项就是耦合的来源，也是合作与竞争能同时进方程的原因。

    4.2 Nash 均衡的定义¶

    定义 10.4-1：策略组 \(\{\boldsymbol{u}_1^*,\dots,\boldsymbol{u}_N^*\}\) 称为 \(N\) 人博弈的 Nash 均衡解，如果

    \[ J_i^* \triangleq J_i(\boldsymbol{u}_1^*,\dots,\boldsymbol{u}_i^*,\dots,\boldsymbol{u}_N^*) \le J_i(\boldsymbol{u}_1^*,\dots,\boldsymbol{u}_i,\dots,\boldsymbol{u}_N^*), \qquad \forall \boldsymbol{u}_i,\ \forall i\in\underline{N} \tag{10.4-4} \]

    \(\{J_1^*,\dots,J_N^*\}\) 叫Nash 均衡值组。

    读法：任何一个人单方面改自己的策略，都只会让自己更差 —— 与 (10.2-5) 的"两边都不愿单独改变"是同一条，只是人数变多。

    非零和博弈没有「一个」对策值

    零和时可用的那句话"对策值 \(V^*\) 是唯一的"，在这里不成立。 非零和时每个人有自己的最优值 \(J_i^*\)，这些数一般不相等， \(J_1^*=-J_2^*\) 只在零和的特殊情形才成立。 所以结论只能是一个值组 \(\{J_i^*\}\)，不能说"这个博弈的值为……"。

    4.3 驻定条件与耦合的 Hamilton-Jacobi 方程¶

    第 \(i\) 个玩家的 Hamiltonian 是

    \[ \mathcal{H}_i = Q_i(\boldsymbol{x}) + \sum_{j=1}^{N}\boldsymbol{u}_j^{\mathsf T}R_{ij}\boldsymbol{u}_j + (\nabla V_i)^{\mathsf T}\left(f(\boldsymbol{x}) + \sum_{j=1}^{N}g_j(\boldsymbol{x})\boldsymbol{u}_j\right) \tag{10.4-6} \]

    均衡处的驻定条件与两人情形不同：每个人只对自己的控制求驻定，

    \[ \frac{\partial \mathcal{H}_i}{\partial \boldsymbol{u}_i} = \boldsymbol{0}, \qquad i\in\underline{N} \quad\Longrightarrow\quad \boldsymbol{u}_i = -\frac12 R_{ii}^{-1}g_i^{\mathsf T}(\boldsymbol{x})\nabla V_i \tag{10.4-7,\ 10.4-8} \]

    而 \(\partial^2\mathcal{H}_i/\partial\boldsymbol{u}_i^2 = 2R_{ii}>0\)， 所以每个人都在最小化自己的 \(\mathcal{H}_i\)，不再有人取 \(\max\)。 这是与零和博弈最关键的结构差别：

    两人零和 \(N\) 人非零和
    Hamiltonian 全场只有一个 \(\mathcal{H}\) 每人一个 \(\mathcal{H}_i\)
    驻定条件 同一 \(\mathcal{H}\) 对 \(\boldsymbol{u}\) 取 \(\min\)、对 \(\boldsymbol{d}\) 取 \(\max\) 每人只对自己取 \(\min\)
    需要谁的信息 共同未知量 \(\nabla V\) 第 \(i\) 个方程里出现所有 \(\nabla V_j\)

    把 (10.4-8) 代回 (10.4-6)，得到 \(N\) 个耦合的 Hamilton-Jacobi 方程（闭环形式）：

    \[ 0 = (\nabla V_i)^{\mathsf T}\left(f(\boldsymbol{x}) - \frac12\sum_{j=1}^{N} g_j R_{jj}^{-1} g_j^{\mathsf T}\nabla V_j\right) + Q_i(\boldsymbol{x}) + \frac14\sum_{j=1}^{N}\nabla V_j^{\mathsf T} g_j R_{jj}^{-T} R_{ij} R_{jj}^{-1} g_j^{\mathsf T}\nabla V_j \tag{10.4-10} \]

    "耦合"体现在哪里：第 \(i\) 个方程里的未知量不只是 \(\nabla V_i\)， 而是所有 \(\nabla V_j\)（\(j=1,\dots,N\)）。 所以不能一个方程一个方程地解，必须联立求解这 \(N\) 个偏微分方程。

    4.4 定理：耦合 HJ 的解给出 Nash 均衡¶

    定理 10.4-2：设 \(Q_i(\boldsymbol{x})>0\)，\(V_i>0\ (i\in\underline{N})\) 是耦合 HJ 方程的光滑解，控制由 (10.4-8) 给出。则

    （a）稳定性：闭环系统 (10.4-9) 渐近稳定，\(V_i\) 可作 Lyapunov 函数。 理由只需一行 —— 沿闭环轨迹求导，

    \[ \dot V_i = \nabla V_i^{\mathsf T}\dot{\boldsymbol{x}} = -\frac12\left(Q_i(\boldsymbol{x}) + \sum_{j=1}^{N}\boldsymbol{u}_j^{\mathsf T}R_{ij}\boldsymbol{u}_j\right) \tag{10.4-16} \]

    因为 \(Q_i>0\)，右边是负定的，于是 \(V_i\) 是 Lyapunov 函数。

    （b）均衡性：\(\{\boldsymbol{u}_i^*\}\) 构成 Nash 均衡，对应值 \(J_i^* = V_i(\boldsymbol{x}(0))\)。

    证明的思路与定理 10.2-2 完全同构：把 \(J_i\) 加上再减去 \(\int \dot V_i\,dt\)， 拼成 \(\mathcal{H}_i\)，再用"配方式"的引理 10.4-2 展开， 最后令 \(\boldsymbol{u}_i=\boldsymbol{u}_i^*\) 就得到 \(J_i^*=V_i(\boldsymbol{x}(0))\)。 两处结论都能一句话概括：值函数同时就是 Lyapunov 函数。

    4.5 合作与竞争的分解¶

    多人博弈最有意思的地方，是每个人的目标可以拆开：

    \[ J_i = \frac1N\sum_{j=1}^{N}J_j + \frac1N\sum_{j=1}^{N}(J_i - J_j) \equiv J_{\text{team}} + J_{\text{conflict}}^{i} \tag{10.4-19} \]

    两部分各管一件事：

    记号 是什么 度量的东西
    \(J_{\text{team}}\) \(N\) 个目标的重心 有多少是共同利益（团队"重心"）
    \(J_{\text{conflict}}^{i}\) 第 \(i\) 个目标偏离平均值多少 有多少是彼此冲突

    这一步的威力在于：零和只是它的一个特例。 两人零和时 \(J_2=-J_1\)，于是

    \[ J_{\text{team}} = \frac{J_1+J_2}{2} = 0, \qquad J_{\text{conflict}}^{1} = \frac{J_1-J_2}{2} = J_1 \]

    共同利益为零、只剩冲突 —— 这正是"合作与竞争能被同一套方程描述"的机关： \(\gamma\) 与 \(R_{ij}\) 的取值决定这两部分的比例，取到极端就是零和。

    4.6 线性二次多人对策：耦合黎卡提方程¶

    线性动态加二次指标：

    \[ \dot{\boldsymbol{x}} = A\boldsymbol{x} + \sum_{j=1}^{N}B_j\boldsymbol{u}_j, \qquad J_i = \frac12\int_0^\infty\left(\boldsymbol{x}^{\mathsf T}Q_i\boldsymbol{x} + \sum_{j=1}^{N}\boldsymbol{u}_j^{\mathsf T}R_{ij}\boldsymbol{u}_j\right)dt \tag{10.4-20,\ 10.4-21} \]

    耦合 HJ (10.4-10) 就退化成 \(N\) 个耦合的广义代数黎卡提方程：

    \[ 0 = P_i A_c + A_c^{\mathsf T}P_i + Q_i + \sum_{j=1}^{N} P_j B_j R_{jj}^{-T} R_{ij} R_{jj}^{-1} B_j^{\mathsf T} P_j, \qquad A_c = A - \sum_{i=1}^{N}B_i R_{ii}^{-1}B_i^{\mathsf T}P_i \tag{10.4-22} \]

    注意耦合的形状：第 \(i\) 个方程里出现了所有 \(P_j\)。 单人 LQR 只要解一个黎卡提方程，这里要联立解 \(N\) 个。

    若这组 \(P_i\) 存在，且对每个 \(i\)， \(\left(A-\sum_{j\ne i}B_jR_{jj}^{-1}B_j^{\mathsf T}P_j,\ B_i\right)\) 可镇定、 \(\left(A-\sum_{j\ne i}B_jR_{jj}^{-1}B_j^{\mathsf T}P_j,\ Q_i+\sum_{j\ne i}P_jB_jR_{jj}^{-T}R_{ij}R_{jj}^{-1}B_j^{\mathsf T}P_j\right)\) 可检测， 则

    \[ \boldsymbol{u}_i^*(\boldsymbol{x}) = -K_i\boldsymbol{x} = -\frac12 R_{ii}^{-1}B_i^{\mathsf T}P_i\boldsymbol{x} \]

    构成 Nash 均衡，且闭环 \(\dot{\boldsymbol{x}}=A_c\boldsymbol{x}\) 渐近稳定 —— \(A_c\) 里那个 \(\sum_i B_iR_{ii}^{-1}B_i^{\mathsf T}P_i\) 是所有人控制效果的叠加。

    4.7 三类对策的一张总表¶

    单人最优控制 两人零和博弈 \(N\) 人非零和博弈
    决策者 1 个 2 个（完全对立） \(N\) 个（部分合作）
    判据 \(\min\) \(\min\max=\max\min\) Nash 均衡
    方程 HJB / ARE HJI / GARE 耦合 HJ / 耦合 GARE
    结果 一个 \(V^*\) 一个 \(V^*\) 一个值组 \(\{J_i^*\}\)
    与 LQR/ARE 的差 —— 多 \(+\frac{1}{4\gamma^2}\nabla V^{\mathsf T}kk^{\mathsf T}\nabla V\) 多 \(N-1\) 个联立方程
    稳定性 \(V\) 是 Lyapunov 函数 同上 每个 \(V_i\) 都是 Lyapunov 函数

    五、例题¶

    例题 1：用 Hamiltonian + PMP 解标量 LQR¶

    题目：标量系统 \(\dot x = ax + bu\)，指标 \(J=\int_0^\infty (qx^2 + ru^2)\,dt\)，取 \(a=b=q=r=1\)、\(x_0=1\)。 用 (10.1-6)、(10.1-7) 求最优控制与最小代价。

    思路

    猜值函数是二次型 \(V(x)=px^2\)，代入 HJB (10.1-7) 定出 \(p\)， 再用 (10.1-6) 把控制写成状态反馈。

    解答

    第一步：写出梯度。 \(V(x)=px^2\)，所以 \(\nabla V = 2px\)。

    第二步：代入 HJB (10.1-7)。 这里 \(g=b\)、\(R=r\)、\(f=ax\)，逐项算：

    \[ 0 = qx^2 + (2px)(ax) - \frac14\cdot\frac{(2px)^2 b^2}{r} \]

    取 \(a=b=q=r=1\)，整理（\(x\ne 0\) 时两边同除 \(x^2\)）：

    \[ 0 = 1 + 2p - p^2 \;\Longrightarrow\; p^2 - 2p - 1 = 0 \;\Longrightarrow\; p = 1 \pm \sqrt2 \]

    值函数必须正定，取正根 \(p = 1+\sqrt2 \approx 2.4142\)。

    第三步：写控制律 (10.1-6)。

    \[ u = -\frac12 R^{-1}g^{\mathsf T}\nabla V = -\frac12\cdot 1\cdot 1\cdot 2px = -px = -(1+\sqrt2)\,x \]

    所以最优增益 \(K = p \approx 2.414\)，控制是 \(u^*=-2.414x\)。

    第四步：验算。 闭环 \(\dot x = (a-bK)x = (1-2.4142)x = -1.4142x\)， 极点 \(-\sqrt2 \approx -1.414\)，稳定。 用 ARE 交叉验证：\(A^{\mathsf T}p + pA + Q - pBR^{-1}B^{\mathsf T}p = 2p + 1 - p^2 = 0\)， 与第二步是同一个方程。

    答案：\(u^* = -(1+\sqrt2)x \approx -2.414x\)，闭环极点 \(-\sqrt2\)， 最小代价 \(V^*(x_0) = (1+\sqrt2)x_0^2\)（\(x_0=1\) 时约 \(2.414\)）。

    例题 2：两人零和博弈的 HJI 与鞍点¶

    题目：标量系统 \(\dot x = u + d\)（无漂移）， \(J=\int_0^\infty (x^2 + u^2 - \gamma^2 d^2)\,dt\)。 求两个策略 (10.2-11)、(10.2-12)、HJI (10.2-13)，以及使该 HJI 有正解的最小 \(\gamma^*\)。

    思路

    先由两个驻定条件写出 \(u\)、\(d\) 关于 \(\nabla V\) 的表达式， 再代回 HJI 得到关于 \(\nabla V\) 的方程；仍猜 \(V=sx^2\)。

    解答

    第一步：写出梯度。 \(V(x)=sx^2\)，\(\nabla V = 2sx\)。

    第二步：两个策略。 这里 \(g=k=R=1\)， 代入 (10.2-11)、(10.2-12)：

    \[ u^* = -\frac12\cdot 1\cdot 1\cdot 2sx = -sx, \qquad d^* = \frac{1}{2\gamma^2}\cdot 1\cdot 2sx = \frac{sx}{\gamma^2} \]

    第三步：代入 HJI (10.2-13)。 本例 \(f(x)=0\)、\(h^{\mathsf T}h=x^2\)， 所以第一、第二项是 \(x^2\) 与 \(0\)，第三、第四项都含 \((2sx)^2=4s^2x^2\)：

    \[ 0 = x^2 + 0 - \frac14\cdot 4s^2x^2 + \frac{1}{4\gamma^2}\cdot 4s^2x^2 = x^2 - s^2x^2 + \frac{s^2x^2}{\gamma^2} \]

    两边同除 \(x^2\)（\(x\ne 0\)）：

    \[ 0 = 1 - s^2\left(1 - \frac{1}{\gamma^2}\right) \;\Longrightarrow\; s^2 = \frac{\gamma^2}{\gamma^2-1}, \qquad s = \frac{\gamma}{\sqrt{\gamma^2-1}} \]

    第四步：定出 \(\gamma^*\)。 要 \(s\) 为正，必须 \(\gamma^2-1>0\)，即

    \[ \gamma \gt 1 \equiv \gamma^* \]

    第五步：取 \(\gamma=2\) 做数值核对。 \(s = 2/\sqrt3 \approx 1.1547\)，于是 \(u^*=-1.1547x\)、\(d^*=1.1547x/4 = 0.2887x\)。 闭环动力 \(\dot x = u^*+d^*\) 化为 \(s\left(\frac{1}{\gamma^2}-1\right)x = 1.1547\times(-0.75)x = -0.866x\)， 极点 \(-0.866\lt 0\)，稳定。

    答案：\(\gamma^*=1\)；\(\gamma=2\) 时 \(s=2/\sqrt3\approx1.155\)， \(u^*\approx-1.155x\)，最坏扰动 \(d^*\approx0.289x\)，闭环极点约 \(-0.866\)。

    顺带核一下：把 \(A=0,B=1,D=1,q=1,R=1\) 代进 GARE (10.3-12)， 得到 \(0 = 1 - S^2 + S^2/\gamma^2\)，与第三步完全一致 —— 标量情形的 HJI 与 GARE 是同一个方程。

    例题 3：H∞ 临界增益与稳定解¶

    题目：线性系统 \(\dot x = u + d\)，性能输出 \(z=[u\ \ x]^{\mathsf T}\)， 取 \(R=4\)、\(H^{\mathsf T}H=1\)。求 \(\gamma^*\) 与 GARE 的稳定解 \(S\)， 并取 \(\gamma=3\) 算出增益与闭环极点。

    思路

    直接把 \(A=0,B=1,D=1\) 代进 GARE (10.3-12)； 再把 \(S\) 代回 (10.3-10)、(10.3-11) 得 \(K\)、\(L\)，闭环极点就是 \(-K+L\)。

    解答

    第一步：写 GARE。 \(A=0\)、\(B=D=1\)、\(H^{\mathsf T}H=1\)、\(R=4\)：

    \[ 0 = 0 + 0 + 1 - \frac{S^2}{4} + \frac{S^2}{\gamma^2} \;\Longrightarrow\; S^2\left(\frac14 - \frac1{\gamma^2}\right) = 1 \;\Longrightarrow\; S = \frac{2\gamma}{\sqrt{\gamma^2-4}} \]

    第二步：临界增益。 要 \(S>0\)，须 \(\gamma^2-4>0\)，故 \(\gamma^*=\sqrt4=2\)。 这正是 \(\gamma^*=\sqrt R\)。

    第三步：取 \(\gamma=3\)。

    \[ S = \frac{2\times 3}{\sqrt{9-4}} = \frac{6}{\sqrt5} \approx 2.6833 \]

    第四步：两个增益。

    \[ K = R^{-1}B^{\mathsf T}S = \frac{S}{4} \approx 0.6708, \qquad L = \frac{1}{\gamma^2}D^{\mathsf T}S = \frac{S}{9} \approx 0.2981 \]

    第五步：闭环极点。 \(\dot x = (A - BK + DL)x = (-K+L)x\)：

    \[ -K+L = -0.6708 + 0.2981 = -0.3727 \lt 0 \]

    稳定。最坏扰动就是 \(d^*=Lx\approx0.298x\)。

    答案：\(\gamma^*=2\)；\(\gamma=3\) 时 \(S=6/\sqrt5\approx2.683\)， \(K\approx0.671\)，\(L\approx0.298\)，闭环极点约 \(-0.373\)。

    再核一个极限：\(\gamma\to\infty\) 时 \(S\to\sqrt{qr}=2\)， 正好是无扰动时 LQR 方程 \(0=1-S^2/4\) 的解 —— 与图中那条水平渐近线一致（图上标的就是 \(q=1,r=4\) 这条曲线）。

    例题 4：合作与竞争的分解¶

    题目：两人博弈中 \(J_1 = x^2+u_1^2\)，\(J_2 = 2x^2+u_2^2\)。 求 \(J_{\text{team}}\) 与 \(J_{\text{conflict}}^{1}\)，说明两人有无共同利益。 若改成 \(J_2=-J_1\)，这两个量变成什么？

    思路

    用分解式 (10.4-19)：\(J_{\text{team}}=\frac12(J_1+J_2)\)， \(J_{\text{conflict}}^{i}=\frac12(J_i-J_j)\)（\(j\ne i\)）。

    解答

    第一步：算 \(J_{\text{team}}\)。

    \[ J_{\text{team}} = \frac{J_1+J_2}{2} = \frac{3x^2 + u_1^2 + u_2^2}{2} \]

    \(x^2\)、\(u_1^2\)、\(u_2^2\) 的系数都是正的，说明两人都希望状态与控制小 —— 有实打实的共同利益。

    第二步：算 \(J_{\text{conflict}}^{1}\)。

    \[ J_{\text{conflict}}^{1} = \frac{J_1-J_2}{2} = \frac{-x^2 + u_1^2 - u_2^2}{2} = -\frac{x^2}{2} + \frac{u_1^2-u_2^2}{2} \]

    它的 \(x^2\) 项系数是 \(-\frac12\)：玩家 1 从"状态偏大"里占到相对好处， 玩家 2 则相反。对状态有冲突，对控制没有交叉耦合。

    第三步：改成 \(J_2=-J_1\)。

    \[ J_{\text{team}} = \frac{J_1-J_1}{2} = 0, \qquad J_{\text{conflict}}^{1} = \frac{J_1-(-J_1)}{2} = J_1, \qquad J_{\text{conflict}}^{2} = -J_1 \]

    答案：原题中 \(J_{\text{team}}=\frac{3x^2+u_1^2+u_2^2}{2}>0\)， 两人有共同利益，同时在对状态取向上有冲突； 改成 \(J_2=-J_1\) 后 \(J_{\text{team}}=0\)、\(J_{\text{conflict}}^{1}=J_1\)， 退化为纯零和 —— 这就是 \(J_{\text{team}}\) 与 \(J_{\text{conflict}}\) 想区分的东西。

    内容 关键结论
    对策的判据 最坏情况下的最优：\(\min\max\)
    鞍点存在的条件 \(\min\max=\max\min\)，即 Isaacs 条件成立
    两个策略 \(u^*=-\frac12R^{-1}g^{\mathsf T}\nabla V\)，\(d^*=\frac{1}{2\gamma^2}k^{\mathsf T}\nabla V\)（符号相反）
