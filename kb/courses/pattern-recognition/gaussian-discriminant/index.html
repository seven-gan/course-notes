    高斯密度下的判别函数¶

    前面两页把判别函数写成了抽象形式 \(g_i(x) = p(x\mid\omega_i)P(\omega_i)\)。 抽象形式没法用 —— 你没法对一个没有具体表达式的 \(p(x\mid\omega_i)\) 做任何计算。

    这一页做的事很具体：假设每一类的类条件密度是高斯分布， 把它代进判别函数，一步步化简，看决策面变成什么形状。

    为什么要专门假设高斯 —— 课件给了三条理由，都值得记住：

    理由 说明
    熵最大 在给定均值和方差的所有分布中，正态分布的熵最大 ✓
    中心极限定理 大量独立随机变量之和趋近正态分布 ✓
    实际吻合 很多类别的特征分布近似正态 ✓

    这三条的组合含义很重要： 前两条说明高斯在信息论与概率论上处于「最一般」的位置； 第三条说明它在实际数据里经常成立。 所以在不知道真实分布时，高斯是最合理的第一选择 ✓

    这一页的主线

    整页只做一件事：把高斯密度代进判别函数，化简，看决策面形状。

    化简的结果由协方差矩阵怎么取决定，共三种情形：

    情形 协方差假设 判别函数 决策面形状
    一 各类相同且是球形（\(\sigma^2 I\)） 线性 超平面
    二 各类相同（\(\Sigma\)，非球形） 线性 超平面（方向不同）
    三 各类不同（\(\Sigma_i\)） 二次 二次曲面 ✓

    这一页的全部推导都服务于这张表 —— 三次化简的差别只在于哪些项能丢掉 ✓

    一、高斯密度的两种形式¶

    1.1 单变量正态分布¶

    密度函数：

    \[p(x) = \frac{1}{\sqrt{2\pi}\,\sigma}\exp\left[-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^2\right]\]

    记法：\(x \sim \mathcal{N}(\mu, \sigma^2)\)。

    两个参数的定义（课件明确给了积分形式）：

    \[\mu = \mathbb{E}[x] = \int_{-\infty}^{\infty} x\,p(x)\,dx, \qquad \sigma^2 = \mathbb{E}\left[(x-\mu)^2\right] = \int_{-\infty}^{\infty} (x-\mu)^2 p(x)\,dx\]

    逐项读密度函数：

    部分 作用
    \(\dfrac{1}{\sqrt{2\pi}\,\sigma}\) 归一化常数，保证全积分等于 1 ✓
    \(-\dfrac{1}{2}\left(\dfrac{x-\mu}{\sigma}\right)^2\) 指数上的标准化平方距离
    \(\mu\) 决定曲线的位置（峰值在哪）
    \(\sigma\) 决定曲线的宽度（越大越胖、峰越低）

    三条性质（课件列出）：

    性质 式子 含义
    非负 \(p(x) \geq 0\) 密度不可能是负的 ✓
    归一 \(\int_{-\infty}^{\infty} p(x)\,dx = 1\) 概率总和为 1
    定义域 \(-\infty \lt x \lt +\infty\) 全域都有值（尾巴不会真到 0）⚠

    第三条值得强调：高斯的支撑集是整个实轴 —— 哪怕 \(x\) 离 \(\mu\) 有 10 个 \(\sigma\)，密度也不等于 0，只是非常小。 这一点在推导决策面时很重要：两条高斯曲线永远有重叠 ✓ （这也是上一页 分类错误率分析 里「错误率不为 0」的根本原因）

    1.2 多元正态分布¶

    密度函数：

    \[p(x) = \frac{1}{(2\pi)^{d/2}\,\lvert\Sigma\rvert^{1/2}} \exp\left[-\frac{1}{2}(x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu)\right]\]

    记法：\(x \sim \mathcal{N}(\mu, \Sigma)\)。

    逐个符号定义（这张表必须吃透，后面每一步都用到）：

    符号 类型 含义 取值范围
    \(d\) 标量 特征维数 正整数
    \(x\) \(d\) 维列向量 特征向量，\(x = [x_1,\dots,x_d]^{\mathsf{T}}\) \(x \in \mathbb{R}^d\)
    \(\mu\) \(d\) 维列向量 均值向量，\(\mu = \mathbb{E}[x]\) \(\mu \in \mathbb{R}^d\)
    \(\Sigma\) \(d \times d\) 矩阵 协方差矩阵 对称、正定 ✓
    \(\lvert\Sigma\rvert\) 标量 协方差矩阵的行列式 \(\gt 0\) ✓
    \(\Sigma^{-1}\) \(d \times d\) 矩阵 协方差矩阵的逆 存在（因 \(\Sigma\) 正定）

    均值向量的定义（课件给了逐分量的积分）：

    \[\mu_i = \mathbb{E}[x_i] = \int_{-\infty}^{\infty} x_i\,p(x_i)\,dx_i, \qquad i = 1, 2, \dots, d\]

    协方差矩阵的每个元素：

    \[\Sigma_{ij} = \mathbb{E}\left[(x_i - \mu_i)(x_j - \mu_j)\right]\]

    注意对角线与非对角线：

    位置 含义
    对角线 \(\Sigma_{ii}\) 第 \(i\) 维的方差（自己的散布程度）✓
    非对角线 \(\Sigma_{ij}\)（\(i \neq j\)） 第 \(i\) 与第 \(j\) 维的协方差（联动程度）

    为什么 \(\Sigma\) 一定对称：因为 \(\Sigma_{ij} = \Sigma_{ji}\)（乘法可交换）✓

    二、等密度轨迹与马氏距离¶

    这一节要说明「高斯的等密度面长什么样」，它是后面判断决策面形状的基础。

    2.1 指数上的那个二次型就是马氏距离的平方¶

    看多元高斯密度函数的指数部分：

    \[-\frac{1}{2}\underbrace{(x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu)}_{\text{二次型}}\]

    注意：这个二次型与 \(x\) 有关、与密度的具体数值无关。 所以「密度相等」等价于「这个二次型相等」✓

    定义马氏距离：

    \[d_M(x, \mu) = \sqrt{(x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu)}\]

    于是：

    \[\text{密度相等} \iff \text{马氏距离相等} \iff (x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu) = \text{常数}\]

    这就是「等密度轨迹」的定义式 ✓

    2.2 等密度面是椭球¶

    结论：\((x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu) = r^2\) 描述的曲面是椭球。

    椭球的轴由什么决定（这一步需要特征分解，链接 特征值与特征向量）：

    因为 \(\Sigma\) 是对称正定矩阵，它可以分解为

    \[\Sigma = U \Lambda U^{\mathsf{T}}\]

    其中 \(\Lambda = \operatorname{diag}(\lambda_1,\dots,\lambda_d)\) 是特征值对角阵， \(U\) 的列是特征向量（彼此正交）。

    于是 \(\Sigma^{-1} = U \Lambda^{-1} U^{\mathsf{T}}\)，等密度面变成

    \[(x-\mu)^{\mathsf{T}}U\Lambda^{-1}U^{\mathsf{T}}(x-\mu) = r^2\]

    令 \(y = U^{\mathsf{T}}(x-\mu)\)（这是一次坐标旋转），式子化为

    \[\sum_{i=1}^{d}\frac{y_i^2}{\lambda_i} = r^2\]

    这就是标准椭球方程（把每项除以 \(r^2\lambda_i\) 单位化后即标准形式）。

    所以几何含义是：

    量 决定什么
    特征向量（\(U\) 的列） 椭球的轴方向 ✓
    特征值 \(\lambda_i\) 各轴的长度（半轴长 \(\propto \sqrt{\lambda_i}\)）✓
    \(\mu\) 椭球的中心

    特别情形：若 \(\Sigma = \sigma^2 I\)（所有特征值相等）， 则 \(\sum y_i^2/\sigma^2 = r^2\) 是球面（二维时是圆）✓ —— 这就是「球形协方差」这个说法的来源。

    import numpy as np

mu = np.array([2.0, 3.0])
S = np.array([[4.0, 1.0],
              [1.0, 2.0]])
Si = np.linalg.inv(S)

print("二次型 d^2 = (x-mu)^T S^-1 (x-mu)（马氏距离的平方）")
print("x            d^2        d_M")
for x in ([2.0, 3.0], [4.0, 3.0], [2.0, 5.0], [6.0, 3.0], [0.0, 0.0]):
    d = np.array(x) - mu
    q = float(d @ Si @ d)
    print("%-12s %8.6f   %8.6f" % (x, q, np.sqrt(q)))
print()
print("注意 x=[2,3] 是均值本身，d^2 = 0 ✓")
print("而 x=[4,3] 与 x=[2,5] 的马氏距离并不等于它们的欧氏距离：")
for x in ([4.0, 3.0], [2.0, 5.0]):
    d = np.array(x) - mu
    print("  x=%s  欧氏距离=%.6f  马氏距离=%.6f"
          % (x, np.linalg.norm(d), np.sqrt(float(d @ Si @ d))))

    2.3 为什么不用欧氏距离¶

    情形 欧氏距离 马氏距离
    各维量纲不同（如一个用米、一个用毫米） 会被量纲大的那一维主导 ⚠ 自动归一化，不受量纲影响 ✓
    各维相关（\(\Sigma\) 非对角） 完全忽略相关性 ✗ 把相关性考虑进去 ✓
    \(\Sigma = I\) 两者相同 两者相同 ✓

    一句话：马氏距离把「各维尺度不同」与「各维相关」这两件事都处理掉了 ✓

    2.4 白化：把任何高斯变成球形¶

    定义白化变换：取 \(\Sigma\) 的一个「平方根」\(L\)（如 Cholesky 分解 \(\Sigma = LL^{\mathsf{T}}\)）， 令

    \[y = L^{-1}(x - \mu)\]

    则 \(y\) 的协方差是

    \[\operatorname{Cov}(y) = L^{-1}\Sigma L^{-\mathsf{T}} = L^{-1}LL^{\mathsf{T}}L^{-\mathsf{T}} = I\]

    2.5 线性变换下马氏距离不变¶

    最后补一条重要性质（课件提到「线性变换」）：

    若 \(y = Ax\)（\(A\) 可逆），则马氏距离不变 ✓

    证明思路：变换后均值变 \(\mu_y = A\mu_x\)，协方差变 \(\Sigma_y = A\Sigma_x A^{\mathsf{T}}\)， 所以

    \[(y-\mu_y)^{\mathsf{T}}\Sigma_y^{-1}(y-\mu_y) = (x-\mu_x)^{\mathsf{T}}A^{\mathsf{T}}(A\Sigma_x A^{\mathsf{T}})^{-1}A(x-\mu_x)\]
    \[= (x-\mu_x)^{\mathsf{T}}A^{\mathsf{T}}A^{-\mathsf{T}}\Sigma_x^{-1}A^{-1}A(x-\mu_x) = (x-\mu_x)^{\mathsf{T}}\Sigma_x^{-1}(x-\mu_x)\]

    中间那步用了 \((A\Sigma A^{\mathsf{T}})^{-1} = A^{-\mathsf{T}}\Sigma^{-1}A^{-1}\) ✓

    这条性质的实践含义： 换一组特征（做线性变换）不会改变马氏距离， 所以基于马氏距离的判断不会因为换了特征表示就翻案 ✓ —— 这正是它在统计识别里被广泛使用的原因。

    三、判别函数的通用化简起点¶

    3.1 取对数判别函数¶

    从最一般的形式出发。判别函数取「似然 × 先验」（上一页 判别函数与决策面 说明过它等价于后验）：

    \[g_i(x) = p(x \mid \omega_i)\,P(\omega_i)\]

    把高斯密度代进去：

    \[g_i(x) = \frac{P(\omega_i)}{(2\pi)^{d/2}\lvert\Sigma_i\rvert^{1/2}} \exp\left[-\frac{1}{2}(x-\mu_i)^{\mathsf{T}}\Sigma_i^{-1}(x-\mu_i)\right]\]

    这个形式有个麻烦：多个 \(g_i\) 比较时要做连乘与指数运算， 数值上容易下溢（指数部分可能到 \(-10^3\) 量级，\(e^{-1000}\) 直接变 0）⚠

    取对数（\(\ln\) 单调增，不改变谁大谁小）：

    \[\ln g_i(x) = \ln P(\omega_i) - \frac{d}{2}\ln(2\pi) - \frac{1}{2}\ln\lvert\Sigma_i\rvert - \frac{1}{2}(x-\mu_i)^{\mathsf{T}}\Sigma_i^{-1}(x-\mu_i)\]

    3.2 丢掉与类别无关的项¶

    关键观察：\(-\dfrac{d}{2}\ln(2\pi)\) 这一项里没有 \(i\) —— 它对所有类别都一样 ✓

    所以丢掉它不影响谁最大（上一页讲过「减去同一个常数不改变大小关系」）。 得到简化后的判别函数：

    \[\boxed{\;g_i(x) = -\frac{1}{2}(x-\mu_i)^{\mathsf{T}}\Sigma_i^{-1}(x-\mu_i) - \frac{1}{2}\ln\lvert\Sigma_i\rvert + \ln P(\omega_i)\;}\]

    这后面两项值得标注清楚（它们在不同情形下待遇不同）：

    项 含 \(i\) 吗 在情形一/二能丢吗
    \(-\dfrac{1}{2}(x-\mu_i)^{\mathsf{T}}\Sigma_i^{-1}(x-\mu_i)\) 含（通过 \(\mu_i,\Sigma_i\)） 不能丢，是主体 ✓
    \(-\dfrac{1}{2}\ln\lvert\Sigma_i\rvert\) 含（通过 \(\Sigma_i\)） 情形一、二能丢（因为 \(\Sigma_i\) 都相同）✓
    \(\ln P(\omega_i)\) 含 永远不能丢 ⚠（先验就是重点）

    这三项的待遇差异，就是三种情形的全部区别

    记住这张表，后面三节都是它的展开：

    情形 \(\Sigma_i\) 的关系 \(\ln\lvert\Sigma_i\rvert\) 项 二次项能否消 决策面
    一 都是 \(\sigma^2 I\) 可丢（都相同） 能消（见第四节） 超平面
    二 都是 \(\Sigma\) 可丢（都相同） 能消（见第五节） 超平面
    三 各不相同 不能丢 ⚠ 不能消 ⚠ 二次曲面

    一句话：决策面是直线还是曲线，取决于「二次项能不能消掉」； 而二次项能不能消，取决于 \(\Sigma_i\) 是否随 \(i\) 变化 ✓

    3.3 展开二次项（后面反复用到）¶

    把二次项展开，这一步之后的每次化简都从它出发。设

    \[d_i^2(x) = (x-\mu_i)^{\mathsf{T}}\Sigma_i^{-1}(x-\mu_i)\]

    展开（逐步写，不跳步）：

    \[d_i^2(x) = \left[x^{\mathsf{T}} - \mu_i^{\mathsf{T}}\right]\Sigma_i^{-1}\left[x - \mu_i\right]\]

    先算左边括号乘矩阵：

    \[= x^{\mathsf{T}}\Sigma_i^{-1}x - x^{\mathsf{T}}\Sigma_i^{-1}\mu_i - \mu_i^{\mathsf{T}}\Sigma_i^{-1}x + \mu_i^{\mathsf{T}}\Sigma_i^{-1}\mu_i\]

    注意中间两项其实是相等的：\(x^{\mathsf{T}}\Sigma_i^{-1}\mu_i\) 是标量， 而 \((\mu_i^{\mathsf{T}}\Sigma_i^{-1}x)^{\mathsf{T}} = x^{\mathsf{T}}\Sigma_i^{-\mathsf{T}}\mu_i\)， 又因为 \(\Sigma_i\) 对称所以 \(\Sigma_i^{-\mathsf{T}} = \Sigma_i^{-1}\) —— 两者确实是同一个数 ✓

    所以合并中间两项：

    \[d_i^2(x) = x^{\mathsf{T}}\Sigma_i^{-1}x - 2\mu_i^{\mathsf{T}}\Sigma_i^{-1}x + \mu_i^{\mathsf{T}}\Sigma_i^{-1}\mu_i\]

    这三项各含什么（这是后面判断「能丢什么」的依据）：

    项 关于 \(x\) 的次数 含 \(i\) 吗
    \(x^{\mathsf{T}}\Sigma_i^{-1}x\) 二次 通过 \(\Sigma_i\)
    \(-2\mu_i^{\mathsf{T}}\Sigma_i^{-1}x\) 一次（线性） 通过 \(\mu_i,\Sigma_i\)
    \(\mu_i^{\mathsf{T}}\Sigma_i^{-1}\mu_i\) 零次（常数） 通过 \(\mu_i,\Sigma_i\) ✓

    关键点：二次项的系数矩阵是 \(\Sigma_i^{-1}\)。 如果 \(\Sigma_i\) 与 \(i\) 无关，那么这一项对所有类别形式相同， 就可以像「减去同一个常数」那样整体丢掉 ✓ —— 这正是情形一、二能化成线性的原因。

    四、情形一：协方差相同且为球形¶

    假设：所有类别的协方差矩阵都是同一个球形矩阵

    \[\Sigma_i = \sigma^2 I \quad \text{对所有 } i\]

    其中 \(\sigma^2\) 是一个共同的标量（各类方差相同）， \(I\) 是单位阵（各维独立、尺度相同）。

    4.1 代入化简¶

    从第三节的通用形式出发：

    \[g_i(x) = -\frac{1}{2}(x-\mu_i)^{\mathsf{T}}\Sigma_i^{-1}(x-\mu_i) - \frac{1}{2}\ln\lvert\Sigma_i\rvert + \ln P(\omega_i)\]

    第一步：算 \(\Sigma_i^{-1}\) 与 \(\lvert\Sigma_i\rvert\)。

    \[\Sigma_i^{-1} = \frac{1}{\sigma^2}I, \qquad \lvert\Sigma_i\rvert = \sigma^{2d}\]

    第二步：代进去。

    \[g_i(x) = -\frac{1}{2}\cdot\frac{1}{\sigma^2}(x-\mu_i)^{\mathsf{T}}I(x-\mu_i) - \frac{1}{2}\ln\sigma^{2d} + \ln P(\omega_i)\]

    注意 \((x-\mu_i)^{\mathsf{T}}I(x-\mu_i) = \lVert x-\mu_i\rVert^2\) —— 在这个情形下马氏距离就是欧氏距离 ✓

    第三步：化简。

    \[g_i(x) = -\frac{\lVert x-\mu_i\rVert^2}{2\sigma^2} - \frac{d}{2}\ln\sigma^2 + \ln P(\omega_i)\]

    第四步：丢掉与 \(i\) 无关的项。

    \(-\dfrac{d}{2}\ln\sigma^2\) 里没有 \(i\)（\(\sigma\) 各类共用）→ 丢掉 ✓

    \[g_i(x) = -\frac{\lVert x-\mu_i\rVert^2}{2\sigma^2} + \ln P(\omega_i)\]

    4.2 再展开一次，得到线性形式¶

    把 \(\lVert x-\mu_i\rVert^2\) 展开：

    \[\lVert x-\mu_i\rVert^2 = \lVert x\rVert^2 - 2\mu_i^{\mathsf{T}}x + \lVert\mu_i\rVert^2\]

    代进去：

    \[g_i(x) = -\frac{\lVert x\rVert^2}{2\sigma^2} + \frac{\mu_i^{\mathsf{T}}x}{\sigma^2} - \frac{\lVert\mu_i\rVert^2}{2\sigma^2} + \ln P(\omega_i)\]

    关键一步：\(-\dfrac{\lVert x\rVert^2}{2\sigma^2}\) 里没有 \(i\) → 丢掉 ✓

    得到完全线性的判别函数：

    \[g_i(x) = \frac{1}{\sigma^2}\mu_i^{\mathsf{T}}x - \frac{1}{2\sigma^2}\lVert\mu_i\rVert^2 + \ln P(\omega_i)\]

    4.3 写成标准线性形式¶

    \[g_i(x) = w_i^{\mathsf{T}}x + w_{i0}, \qquad w_i = \frac{\mu_i}{\sigma^2}, \qquad w_{i0} = \ln P(\omega_i) - \frac{\lVert\mu_i\rVert^2}{2\sigma^2}\]

    结论：判别函数是线性的，所以决策面（\(g_1 = g_2\)）是超平面 ✓

    注意 \(w_i\) 的方向：\(w_i = \mu_i/\sigma^2\) —— 权重向量与均值向量同方向（只差一个正的比例因子）✓

    4.4 两类的决策面方程（完整推导）¶

    两类情形，令 \(g(x) = g_1(x) - g_2(x)\)， 判决规则是「\(g(x) \gt 0\) 判 \(\omega_1\)，否则判 \(\omega_2\)」。

    代入展开：

    \[g(x) = \frac{\mu_1^{\mathsf{T}}x}{\sigma^2} - \frac{\lVert\mu_1\rVert^2}{2\sigma^2} + \ln P(\omega_1) - \frac{\mu_2^{\mathsf{T}}x}{\sigma^2} + \frac{\lVert\mu_2\rVert^2}{2\sigma^2} - \ln P(\omega_2)\]

    整理：

    \[g(x) = \underbrace{\frac{\mu_1 - \mu_2}{\sigma^2}}_{w}^{\mathsf{T}}x + \underbrace{\frac{\lVert\mu_2\rVert^2 - \lVert\mu_1\rVert^2}{2\sigma^2} + \ln\frac{P(\omega_1)}{P(\omega_2)}}_{w_0}\]

    决策面是 \(g(x) = 0\)：

    \[w^{\mathsf{T}}x + w_0 = 0\]

    4.5 决策面的几何解释¶

    把上式改写成「点到某个参考点的形式」。定义

    \[w = \mu_1 - \mu_2, \qquad x_0 = \frac{\mu_1 + \mu_2}{2} - \frac{\sigma^2}{\lVert\mu_1-\mu_2\rVert^2}\,\ln\frac{P(\omega_1)}{P(\omega_2)}\,(\mu_1 - \mu_2)\]

    则决策面方程可以化成

    \[w^{\mathsf{T}}(x - x_0) = 0\]

    这个形式直接告诉你两件事：

    结论 理由
    决策面垂直于 \(w = \mu_1-\mu_2\) ✓ 方程是 \(w^{\mathsf{T}}(x-x_0)=0\)，「法向量」就是 \(w\)
    决策面经过 \(x_0\) 点 ✓ 代入 \(x = x_0\) 得 0

    逐项读 \(x_0\) 这个点：

    部分 含义
    \(\dfrac{\mu_1+\mu_2}{2}\) 两类均值的中点
    \(-\dfrac{\sigma^2}{\lVert\mu_1-\mu_2\rVert^2}\ln\dfrac{P(\omega_1)}{P(\omega_2)}(\mu_1-\mu_2)\) 先验带来的平移 ✓

    先验相等时（\(P(\omega_1) = P(\omega_2)\)）：\(\ln 1 = 0\)，第二项为零，于是

    \[x_0 = \frac{\mu_1 + \mu_2}{2} \quad \text{（正好是中点）✓}\]

    先验不等时：平移方向是 \(\mu_1 - \mu_2\) 的方向，正负由 \(\ln\frac{P(\omega_1)}{P(\omega_2)}\) 决定：

    先验关系 平移方向 效果
    \(P(\omega_1) \gt P(\omega_2)\) 朝 \(\omega_2\) \(\omega_1\) 的区域变大 ✓
    \(P(\omega_1) \lt P(\omega_2)\) 朝 \(\omega_1\) \(\omega_2\) 的区域变大

    这与上一页的结论一致：边界朝先验小的那一类移动 ✓

    五、情形二：协方差相同但不一定是球形¶

    假设：各类协方差矩阵相同，但是一般的矩阵（各维方差可不同、可相关）

    \[\Sigma_i = \Sigma \quad \text{对所有 } i\]

    这个假设比情形一宽松得多，实际中也更常用 —— 只要「各类的散布方式相同」，就属于这个情形 ✓

    5.1 代入化简¶

    \[g_i(x) = -\frac{1}{2}(x-\mu_i)^{\mathsf{T}}\Sigma^{-1}(x-\mu_i) - \frac{1}{2}\ln\lvert\Sigma\rvert + \ln P(\omega_i)\]

    第一步：丢掉常数项。 \(\lvert\Sigma\rvert\) 与 \(i\) 无关 → \(-\frac{1}{2}\ln\lvert\Sigma\rvert\) 可丢掉 ✓

    \[g_i(x) = -\frac{1}{2}(x-\mu_i)^{\mathsf{T}}\Sigma^{-1}(x-\mu_i) + \ln P(\omega_i)\]

    第二步：用第三节的展开式。

    \[(x-\mu_i)^{\mathsf{T}}\Sigma^{-1}(x-\mu_i) = x^{\mathsf{T}}\Sigma^{-1}x - 2\mu_i^{\mathsf{T}}\Sigma^{-1}x + \mu_i^{\mathsf{T}}\Sigma^{-1}\mu_i\]

    第三步：关键一步 —— 丢掉二次项。 \(-\dfrac{1}{2}x^{\mathsf{T}}\Sigma^{-1}x\) 里没有 \(i\)（\(\Sigma\) 各类共用）→ 丢掉 ✓

    得到线性判别函数：

    \[g_i(x) = \left(\Sigma^{-1}\mu_i\right)^{\mathsf{T}}x - \frac{1}{2}\mu_i^{\mathsf{T}}\Sigma^{-1}\mu_i + \ln P(\omega_i)\]

    5.2 与情形一的对比¶

    \[g_i(x) = w_i^{\mathsf{T}}x + w_{i0}, \qquad w_i = \Sigma^{-1}\mu_i, \qquad w_{i0} = \ln P(\omega_i) - \frac{1}{2}\mu_i^{\mathsf{T}}\Sigma^{-1}\mu_i\]
    情形一（\(\Sigma = \sigma^2 I\)） 情形二（\(\Sigma\) 一般）
    \(w_i\) \(\mu_i/\sigma^2\)（与 \(\mu_i\) 同方向） \(\Sigma^{-1}\mu_i\)（方向被 \(\Sigma\) 扭转）
    常数项 \(-\dfrac{\lVert\mu_i\rVert^2}{2\sigma^2}\) \(-\dfrac{1}{2}\mu_i^{\mathsf{T}}\Sigma^{-1}\mu_i\)（换马氏内积）
    决策面 超平面 仍是超平面 ✓
    法向量 \(\mu_1 - \mu_2\) \(\Sigma^{-1}(\mu_1-\mu_2)\) ⚠

    结论：决策面仍是超平面，但法向量方向变了 ✓

    5.3 用白化把它化回情形一¶

    思路：做白化变换 \(y = L^{-1}x\)（\(L\) 是 \(\Sigma\) 的 Cholesky 因子）， 则 \(y\) 的协方差是单位阵 → 问题变成情形一 ✓

    白化后的权重（情形一的结论）是 \(\mu_i^y = L^{-1}\mu_i\)； 变回原空间要乘 \(L^{-\mathsf{T}}\)：

    六、情形三：协方差各不相同¶

    假设：每一类有自己的协方差矩阵

    \[\Sigma_i \quad \text{随 } i \text{ 变化}\]

    这是最一般的情形，也最贴近实际（各类的散布方式往往不同）。

    6.1 代入：二次项消不掉¶

    从通用形式出发（这次什么都没有可以丢）：

    \[g_i(x) = -\frac{1}{2}(x-\mu_i)^{\mathsf{T}}\Sigma_i^{-1}(x-\mu_i) - \frac{1}{2}\ln\lvert\Sigma_i\rvert + \ln P(\omega_i)\]

    用第三节的展开式代入二次项：

    \[g_i(x) = -\frac{1}{2}x^{\mathsf{T}}\Sigma_i^{-1}x + \mu_i^{\mathsf{T}}\Sigma_i^{-1}x - \frac{1}{2}\mu_i^{\mathsf{T}}\Sigma_i^{-1}\mu_i - \frac{1}{2}\ln\lvert\Sigma_i\rvert + \ln P(\omega_i)\]

    关键差别：第一项 \(-\dfrac{1}{2}x^{\mathsf{T}}\Sigma_i^{-1}x\) 里 \(\Sigma_i\) 带着下标 \(i\) —— 它对每个类别都不同， 不能再当作「同一个常数」丢掉 ⚠

    所以判别函数里保留了 \(x\) 的二次项。

    6.2 二次判别函数（QDF）¶

    整理成标准二次型形式：

    \[g_i(x) = x^{\mathsf{T}}A_i x + b_i^{\mathsf{T}}x + c_i\]

    其中系数分别是

    \[A_i = -\frac{1}{2}\Sigma_i^{-1} \qquad b_i = \Sigma_i^{-1}\mu_i \qquad c_i = -\frac{1}{2}\mu_i^{\mathsf{T}}\Sigma_i^{-1}\mu_i - \frac{1}{2}\ln\lvert\Sigma_i\rvert + \ln P(\omega_i)\]

    逐项读：

    项 形状 由什么决定
    \(x^{\mathsf{T}}A_i x\) 二次型（\(d \times d\) 矩阵） 逆协方差 \(\Sigma_i^{-1}\)
    \(b_i^{\mathsf{T}}x\) 线性项（\(d\) 维向量） \(\Sigma_i^{-1}\mu_i\)
    \(c_i\) 常数 均值、行列式、先验

    这个名字的来源：\(g_i\) 里含有二次项， 所以叫二次判别函数（QDF, Quadratic Discriminant Function） ✓

    6.3 两类的决策面方程¶

    两类时令 \(g(x) = g_1(x) - g_2(x)\)，决策面是 \(g(x) = 0\)。 按上面的形式整理：

    \[x^{\mathsf{T}}A x + b^{\mathsf{T}}x + c = 0\]

    其中（逐个给出）

    \[A = A_1 - A_2 = -\frac{1}{2}\left(\Sigma_1^{-1} - \Sigma_2^{-1}\right)\]
    \[b = b_1 - b_2 = \Sigma_1^{-1}\mu_1 - \Sigma_2^{-1}\mu_2\]
    \[c = c_1 - c_2 = -\frac{1}{2}\mu_1^{\mathsf{T}}\Sigma_1^{-1}\mu_1 + \frac{1}{2}\mu_2^{\mathsf{T}}\Sigma_2^{-1}\mu_2 - \frac{1}{2}\ln\frac{\lvert\Sigma_1\rvert}{\lvert\Sigma_2\rvert} + \ln\frac{P(\omega_1)}{P(\omega_2)}\]

    决策面的形状由 \(A\) 的特征值决定（这是一个很有用的判据）：

    \(A\) 的特征值情况 决策面形状
    两个特征值同号且都不为 0 椭圆 / 圆（闭合曲线）
    两个特征值异号 双曲线（两支/四支）
    有一个特征值为 0（\(A\) 退化） 抛物线型（或退化成直线对）

    为什么：\(A\) 决定了二次曲面的类型，这是二次型分类的标准结论 ✓

    7.3 工程选择建议¶

    情形 什么时候用 说明
    情形一 各维尺度相近、互不相关，且样本很少 最省参数 ✓
    情形二 各维尺度不同或相关，但类间散布方式相似 实践中最常用 ✓
    情形三 各类散布方式确实明显不同，且样本充足 小心过拟合 ⚠

    一个重要的实践原则（值得单独记住）：

    「共享协方差」通常是比「各类独立」更稳的选择

    选择 优点 风险
    共享协方差（情形二） 参数少、稳、不易过拟合 ✓ 若各类散布确实不同，会欠拟合
    各类独立协方差（情形三） 灵活、能拟合弯曲边界 参数按 \(c\) 倍增长，易过拟合 ⚠

    判断方法：看各类样本数是否足够估各自的协方差。 如果某一类只有几十个样本而维数有几十维，协方差矩阵根本估不出来 （甚至可能不可逆）⚠

    实践做法：

    做法 说明
    先试情形二 作为基线 ✓
    若训练/测试误差差距大 说明过拟合，回到情形二
    若类间散布差异明显且样本充足 才用情形三

    例题 1：从高斯密度导出线性判别函数¶

    两类问题，一维特征 \(x\)。已知

    \[p(x\mid\omega_1) = \mathcal{N}(0, 1), \qquad p(x\mid\omega_2) = \mathcal{N}(3, 1), \qquad P(\omega_1) = P(\omega_2) = 0.5\]

    求：(a) 判别函数；(b) 决策边界；© 边界处的后验概率。

    思路

    属于情形一（协方差都是 \(1 = \sigma^2\)、且是一维）。 直接代 4.3 节的公式 \(g_i(x) = \frac{\mu_i}{\sigma^2}x - \frac{\mu_i^2}{2\sigma^2} + \ln P(\omega_i)\)。 边界处 \(g_1 = g_2\)，且后验应当是 \(0.5\)（等先验 + 边界）。

    解答

    （a）判别函数。 这里 \(\sigma^2 = 1\)，\(\mu_1 = 0\)，\(\mu_2 = 3\)， 代入公式：

    \[g_1(x) = \frac{0}{1}x - \frac{0^2}{2 \times 1} + \ln 0.5 = \ln 0.5 \approx -0.693147\]
    \[g_2(x) = \frac{3}{1}x - \frac{3^2}{2 \times 1} + \ln 0.5 = 3x - 4.5 - 0.693147\]

    所以

    \[g_2(x) = 3x - 5.193147\]

    注意 \(g_1\) 是常数 —— 因为 \(\mu_1 = 0\)，线性项与二次项都消失了 ✓

    （b）决策边界。 令 \(g_1(x) = g_2(x)\)：

    \[-0.693147 = 3x - 5.193147\]
    \[3x = 4.5, \qquad x = 1.5\]

    边界在 \(x = 1.5\) —— 正好是两均值的中点 \((0+3)/2 = 1.5\) ✓ （因为先验相等，边界过中点）

    判决规则：\(x \gt 1.5\) 判 \(\omega_2\)，否则判 \(\omega_1\)。

    （c）边界处的后验概率。 在 \(x = 1.5\)：

    \[p(1.5 \mid \omega_1) = \frac{1}{\sqrt{2\pi}}\exp\left[-\frac{1.5^2}{2}\right] \approx 0.398942 \times e^{-1.125} \approx 0.398942 \times 0.324652 \approx 0.129518\]
    \[p(1.5 \mid \omega_2) = \frac{1}{\sqrt{2\pi}}\exp\left[-\frac{(1.5-3)^2}{2}\right] \approx 0.398942 \times e^{-1.125} \approx 0.129518\]

    两者完全相等 ✓（因为 \(x=1.5\) 离两个均值都是 \(1.5\)，对称）

    所以后验：

    \[P(\omega_1 \mid 1.5) = \frac{0.129518 \times 0.5}{0.129518 \times 0.5 + 0.129518 \times 0.5} = 0.5\]
    \[P(\omega_2 \mid 1.5) = 0.5\]

    边界处后验恰为 \(0.5\) —— 这是「等先验 + 对称」的必然结果 ✓

    例题 3：判断决策面形状¶

    两类问题，二维特征。已知

    \[\mu_1 = \mu_2 = [0,0]^{\mathsf{T}}, \qquad \Sigma_1 = \begin{pmatrix} 3 & 0 \\ 0 & 0.5 \end{pmatrix}, \qquad \Sigma_2 = \begin{pmatrix} 0.5 & 0 \\ 0 & 3 \end{pmatrix}, \qquad P(\omega_1) = P(\omega_2) = 0.5\]

    问：(a) 属于哪种情形？(b) 决策面是什么形状？© 两类各在什么区域获胜？

    思路

    协方差不同 → 情形三。 要算 \(A\) 的特征值判断形状。注意两类均值相同， 所以线性项 \(b = 0\)，决策面只由 \(A\) 与 \(c\) 决定。

    解答

    （a）属于情形三 —— 两类的协方差矩阵不相同， 所以要用二次判别函数 ✓

    （b）算决策面。

    先算两个逆矩阵（对角矩阵的逆就是取倒数）：

    \[\Sigma_1^{-1} = \begin{pmatrix} 1/3 & 0 \\ 0 & 2 \end{pmatrix}, \qquad \Sigma_2^{-1} = \begin{pmatrix} 2 & 0 \\ 0 & 1/3 \end{pmatrix}\]
    \[A = -\frac{1}{2}\left(\Sigma_1^{-1} - \Sigma_2^{-1}\right) = -\frac{1}{2}\begin{pmatrix} 1/3 - 2 & 0 \\ 0 & 2 - 1/3 \end{pmatrix} = -\frac{1}{2}\begin{pmatrix} -5/3 & 0 \\ 0 & 5/3 \end{pmatrix} = \begin{pmatrix} 5/6 & 0 \\ 0 & -5/6 \end{pmatrix}\]

    线性项：因为 \(\mu_1 = \mu_2 = 0\)，所以

    \[b = \Sigma_1^{-1}\mu_1 - \Sigma_2^{-1}\mu_2 = 0\]

    常数项：

    \[c = -\frac{1}{2}\mu_1^{\mathsf{T}}\Sigma_1^{-1}\mu_1 + \frac{1}{2}\mu_2^{\mathsf{T}}\Sigma_2^{-1}\mu_2 - \frac{1}{2}\ln\frac{\lvert\Sigma_1\rvert}{\lvert\Sigma_2\rvert} + \ln\frac{P(\omega_1)}{P(\omega_2)}\]

    \(\lvert\Sigma_1\rvert = 3 \times 0.5 = 1.5\)，\(\lvert\Sigma_2\rvert = 0.5 \times 3 = 1.5\)， 两者相等，所以对数项为 0；均值项也为 0；先验相等所以最后一项也是 0：

    \[c = 0\]

    决策面方程：

    \[\frac{5}{6}x^2 - \frac{5}{6}y^2 = 0 \quad\Longrightarrow\quad x^2 = y^2 \quad\Longrightarrow\quad y = \pm x\]

    决策面是两条过原点的直线（\(y = x\) 与 \(y = -x\)）✓

    （c）两类各在什么区域获胜。

    取一个测试点判断符号。在 \((1, 0)\) 处：

    \[A \text{ 项} = \frac{5}{6} \times 1 - \frac{5}{6} \times 0 = \frac{5}{6} \gt 0\]

    所以 \(g(1,0) = g_1 - g_2 \gt 0\) → 判 \(\omega_1\) ✓

    这符合直觉：在 \((1,0)\) 处，\(x\) 方向偏移 \(1\)、 \(y\) 方向偏移 \(0\)。 \(\Sigma_1\) 在 \(x\) 方向方差大（\(3\)）、\(\Sigma_2\) 在 \(x\) 方向方差小（\(0.5\)）—— 所以「\(x\) 方向偏移大」更像 \(\omega_1\) 的典型样本 ✓

    例题 4：白化前后的一致性¶

    二维问题，两类均值

    \[\mu_1 = [2,2]^{\mathsf{T}}, \qquad \mu_2 = [8,6]^{\mathsf{T}}, \qquad \Sigma = \begin{pmatrix} 4 & 2 \\ 2 & 3 \end{pmatrix} \text{（两类共用）}\]

    问：(a) 属于哪种情形？(b) 用白化把问题变成情形一，验证权重向量一致。

    思路

    协方差共用 → 情形二。白化用 Cholesky 分解 \(\Sigma = LL^{\mathsf{T}}\)， 变换 \(y = L^{-1}x\) 后协方差变成单位阵。 权重在原空间应为 \(\Sigma^{-1}(\mu_1-\mu_2)\)； 在白化空间应为 \(\mu_1^y - \mu_2^y\)，两者相差一个 \(L^{-\mathsf{T}}\)。

    解答

    （a）属于情形二 —— 协方差矩阵两类共用，但是一般的矩阵 （有非对角元素 \(2\)，说明两维相关）✓

    所以决策面是超平面（二维时是直线） ✓

    （b）白化验证。

    第一步：Cholesky 分解。 找下三角 \(L\) 使 \(\Sigma = LL^{\mathsf{T}}\)：

    \[L = \begin{pmatrix} 2 & 0 \\ 1 & \sqrt{2} \end{pmatrix}\]

    核对：

    \[LL^{\mathsf{T}} = \begin{pmatrix} 2 & 0 \\ 1 & \sqrt{2} \end{pmatrix} \begin{pmatrix} 2 & 1 \\ 0 & \sqrt{2} \end{pmatrix} = \begin{pmatrix} 4 & 2 \\ 2 & 1 + 2 \end{pmatrix} = \begin{pmatrix} 4 & 2 \\ 2 & 3 \end{pmatrix} ✓\]

    第二步：算白化矩阵 \(L^{-1}\)。

    \[L^{-1} = \begin{pmatrix} 1/2 & 0 \\ -1/(2\sqrt{2}) & 1/\sqrt{2} \end{pmatrix}\]

    第三步：白化后的均值。

    \[\mu_1^y = L^{-1}\mu_1 = \begin{pmatrix} 1/2 & 0 \\ -1/(2\sqrt{2}) & 1/\sqrt{2} \end{pmatrix} \begin{pmatrix} 2 \\ 2 \end{pmatrix} = \begin{pmatrix} 1 \\ -1/\sqrt{2} + \sqrt{2} \end{pmatrix} = \begin{pmatrix} 1 \\ \sqrt{2}/2 \end{pmatrix}\]
    \[\mu_2^y = L^{-1}\mu_2 = \begin{pmatrix} 4 \\ -4/(2\sqrt{2}) + 6/\sqrt{2} \end{pmatrix} = \begin{pmatrix} 4 \\ \sqrt{2} \end{pmatrix}\]

    第四步：白化空间的权重（情形一的结论）。

    \[w^y = \mu_1^y - \mu_2^y = \begin{pmatrix} -3 \\ -\sqrt{2}/2 \end{pmatrix}\]

    第五步：变回原空间。

    \[w = L^{-\mathsf{T}}w^y = \begin{pmatrix} 1/2 & -1/(2\sqrt{2}) \\ 0 & 1/\sqrt{2} \end{pmatrix} \begin{pmatrix} -3 \\ -\sqrt{2}/2 \end{pmatrix} = \begin{pmatrix} -3/2 + 1/4 \\ -1/2 \end{pmatrix} = \begin{pmatrix} -5/4 \\ -1/2 \end{pmatrix}\]

    直接验证：由 5.2 节，原空间权重应是 \(\Sigma^{-1}(\mu_1-\mu_2)\)。

    \[\mu_1 - \mu_2 = \begin{pmatrix} -6 \\ -4 \end{pmatrix}\]
    \[\Sigma^{-1} = \frac{1}{4 \times 3 - 2 \times 2}\begin{pmatrix} 3 & -2 \\ -2 & 4 \end{pmatrix} = \frac{1}{8}\begin{pmatrix} 3 & -2 \\ -2 & 4 \end{pmatrix}\]
    \[\Sigma^{-1}(\mu_1-\mu_2) = \frac{1}{8}\begin{pmatrix} 3 \times (-6) + (-2)(-4) \\ -2 \times (-6) + 4 \times (-4) \end{pmatrix} = \frac{1}{8}\begin{pmatrix} -18 + 8 \\ 12 - 16 \end{pmatrix} = \frac{1}{8}\begin{pmatrix} -10 \\ -4 \end{pmatrix} = \begin{pmatrix} -5/4 \\ -1/2 \end{pmatrix} ✓\]

    两条路径完全一致 ✓ —— 印证了「白化把情形二化成情形一」这个等价性。

    提示

    想一想有没有「协方差不同、但决策面仍是直线」的特殊情况。 提示：看 \(A\) 的表达式 \(A = -\frac{1}{2}(\Sigma_1^{-1}-\Sigma_2^{-1})\)。

    Q4 情形一与情形二的决策面都是超平面。 它们唯一的共同点与关键差别分别是什么？

    提示

    两者的判别函数形式都是 \(w^{\mathsf{T}}x + w_0\)。 比较 \(w\) 的表达式。

    解答

    唯一的共同点：决策面都是超平面 ✓

    理由：两者的判别函数都是 \(x\) 的线性函数， 所以「\(g_1 - g_2 = 0\)」是线性方程 → 超平面 ✓

    关键差别：权重向量 \(w\) 的表达式不同 ⚠

    情形一 情形二
    协方差 \(\sigma^2 I\)（球形） \(\Sigma\)（一般，可含相关）
    权重 \(w\) \(\dfrac{\mu_1-\mu_2}{\sigma^2}\) \(\Sigma^{-1}(\mu_1-\mu_2)\)
    \(w\) 的方向 与 \(\mu_1-\mu_2\) 同向 ✓ 被 \(\Sigma^{-1}\) 扭转 ⚠
    决策面法向 \(\mu_1-\mu_2\) \(\Sigma^{-1}(\mu_1-\mu_2)\)

    这个差别的几何含义：

    情形一：决策面垂直于两类均值的连线 ✓ —— 因为 \(w\) 就是 \(\mu_1-\mu_2\) 的方向。

    情形二：决策面不垂直于均值连线 ⚠ —— 因为 \(w\) 被 \(\Sigma^{-1}\) 旋转了。 旋转的角度取决于 \(\Sigma\) 的各向异性程度与相关性。

    为什么会有这个差别（直觉解释）： \(\Sigma^{-1}\) 的作用是「按各维方差反比加权」—— 方差大的方向权重小、方差小的方向权重大 ✓ 所以：

    情形 决策面的倾斜
    各维方差相同（情形一） 不需要调整，垂直于均值连线 ✓
    某维方差明显更大（情形二） 决策面朝方差大的方向倾斜 —— 因为那一维「不确定性大，判错的代价小」⚠

    小结¶

    要记住的 为什么
    高斯假设的三条理由 熵最大（额外假设最少）、中心极限定理、实际吻合 ✓
    一维密度 \(p(x) = \frac{1}{\sqrt{2\pi}\sigma}e^{-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^2}\) 课件要求「公式要牢记」
    多元密度的指数里是马氏距离的平方 这个二次型是后面一切的起点 ✓
    协方差矩阵：对角是方差、非对角是协方差，对称正定 \(\Sigma_{ij} = \mathbb{E}[(x_i-\mu_i)(x_j-\mu_j)]\)
    等密度面是椭球 轴方向由特征向量定、轴长由特征值定 ✓
    马氏距离 \(d_M = \sqrt{(x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu)}\) 处理了「量纲不同」与「各维相关」两件事 ✓
    \(\Sigma = I\) 时马氏距离 = 欧氏距离 所以欧氏距离是特例
    马氏距离在线性变换下不变 换特征表示不会让判断翻案 ✓
    白化 \(y = L^{-1}(x-\mu)\) 把协方差变成单位阵 任何「协方差相同」的问题白化后都变成情形一 ✓
    对数判别函数 \(g_i = -\frac{1}{2}d_{M,i}^2 - \frac{1}{2}\ln\lvert\Sigma_i\rvert + \ln P(\omega_i)\) 丢掉与 \(i\) 无关的项不影响判决
    \(\ln P(\omega_i)\) 永远不能丢 先验就是判决的重点 ⚠
    情形一：\(\Sigma_i = \sigma^2 I\) → 线性 → 超平面 \(w = \mu_i/\sigma^2\)，与均值同方向
    情形二：\(\Sigma_i = \Sigma\) → 线性 → 超平面 \(w = \Sigma^{-1}\mu_i\)，方向被扭转 ⚠
    情形三：\(\Sigma_i\) 各不同 → 二次 → 二次曲面 二次项消不掉，因为 \(\Sigma_i\) 带下标 ✓
    决策面形状看 \(A\) 的特征值 同号→椭圆；异号→双曲线；有 0→退化
    决策面一般垂直于 \(\mu_1-\mu_2\)（情形一） 情形二则不垂直，偏角由 \(\Sigma\) 的偏离程度决定
    先验相等时边界过均值中点 平移项 \(\ln\frac{P_1}{P_2} = 0\) ✓
    边界朝先验小的类移动 与上一页结论一致
    参数量：情形一与维数无关；情形二、三按 \(d^2\) 增长 高维时必须优先考虑情形二 ⚠
    实践首选「共享协方差」（情形二） 参数少、稳、不易过拟合 ✓
    复杂度越高，需要的样本越多 线性→二次→多层网络，过拟合风险递增 ⚠
