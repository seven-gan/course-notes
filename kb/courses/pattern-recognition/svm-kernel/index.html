    支持向量机与核方法¶

    线性分类器 找到了一个能分开数据的超平面， 但能分开的超平面有无穷多个。这一页要问：

    这么多条里面，哪一条最好？

    支持向量机给出的答案出人意料地简洁：让间隔最大。 而它的后果非常深远 —— 对偶形式里只出现内积， 于是可以把内积换成核函数，把线性方法整体搬进高维空间。

    这一页的两个主线

    主线 1：间隔最大化 从几何直觉出发 → 写成优化问题 → 转成对偶 → 发现只有少数样本起作用

    主线 2：核技巧 对偶里只有内积 → 把内积换成核 → 不用显式升维也能实现非线性分类

    两条主线是同一条推导的两个阶段

    一、为什么是最大间隔¶

    1.1 无穷多条分界线¶

    设两类线性可分。存在无穷多个超平面能正确分开它们。 那么挑哪一条？

    几何直觉：应当挑离两类都尽量远的那条 —— 因为边界附近的样本最容易受噪声影响， 把"缓冲带"做宽，对新样本的容错空间就大

    这就引出了间隔的概念。

    1.2 函数间隔与几何间隔¶

    设超平面为 \(\boldsymbol{w}^{\mathsf T}\boldsymbol{x} + b = 0\)， 判别函数 \(g(\boldsymbol{x}) = \boldsymbol{w}^{\mathsf T}\boldsymbol{x}+b\)。 把标签取为 \(y_i \in \{-1,+1\}\)。

    函数间隔：

    \[ \hat\gamma_i = y_i\left(\boldsymbol{w}^{\mathsf T}\boldsymbol{x}_i + b\right) \]

    它的缺陷：把 \(\boldsymbol{w},b\) 同时放大 \(k\) 倍， 函数间隔也放大 \(k\) 倍，但超平面根本没变

    所以函数间隔不是几何量 —— 必须除掉 \(\|\boldsymbol{w}\|\) 才能得到真正的距离。

    几何间隔：

    \[ \gamma_i = \frac{y_i\left(\boldsymbol{w}^{\mathsf T}\boldsymbol{x}_i+b\right)} {\|\boldsymbol{w}\|} \]

    这正好是点到超平面的距离 （因为分母 \(\|\boldsymbol{w}\|\) 把尺度因子彻底消掉了。）

    1.3 写成优化问题¶

    目标：让所有样本中最小的那个几何间隔尽量大。

    \[ \max_{\boldsymbol{w},b}\ \min_i\ \gamma_i \]

    处理这个"最小中的最大"：先固定函数间隔为 1。 为什么可以固定？因为缩放 \(\boldsymbol{w},b\) 不改变超平面， 所以总能选一个缩放使最近点的函数间隔恰好为 1

    固定后有：

    \[ y_i(\boldsymbol{w}^{\mathsf T}\boldsymbol{x}_i+b)\ \ge 1, \qquad i=1,\dots,n \]

    而最小几何间隔就是 \(1/\|\boldsymbol{w}\|\)。于是

    \[ \max\ \frac{1}{\|\boldsymbol{w}\|} \;\Longleftrightarrow\; \min\ \frac{1}{2}\|\boldsymbol{w}\|^2 \]

    为什么要写成平方：\(\|\boldsymbol{w}\|^2\) 是光滑的凸函数， 求导方便；而 \(\|\boldsymbol{w}\|\) 在原点不可导 加 \(\frac12\) 只是为了让求导后系数干净。

    最终的硬间隔问题：

    \[ \min_{\boldsymbol{w},b}\ \frac12\|\boldsymbol{w}\|^2 \quad\text{s.t.}\quad y_i(\boldsymbol{w}^{\mathsf T}\boldsymbol{x}_i+b)\ge1 \]

    1.4 支持向量的定义¶

    约束取等号的那些样本，也就是恰好落在间隔边界上的点， 就叫支持向量

    它们的关键性质：只有它们决定超平面。 把任何非支持向量删掉，或者移到间隔带之外，超平面完全不变

    这个性质很反直觉（通常"数据越多越好"），但它是对偶形式的直接后果。

    import numpy as np

# 一个四点的线性可分例子（两类各两点）
X = np.array([[1.0, 2.0], [2.0, 1.5], [-1.0, -1.0], [-1.5, -0.5]])
y = np.array([1.0, 1.0, -1.0, -1.0])

# 直接构造一个可行解（两类的均值差方向），再看间隔
w = X[y > 0].mean(axis=0) - X[y < 0].mean(axis=0)
b = -0.5 * (X[y > 0].mean(axis=0) + X[y < 0].mean(axis=0)) @ w

print("方向（未归一化）:", np.round(w, 3))
print("偏置           : %.3f" % b)
print()
print("样本".ljust(16) + "判别值".ljust(12) + "函数间隔".ljust(12) + "几何间隔")
for k in range(len(X)):
    g = float(w @ X[k] + b)
    print(("%s" % str(X[k])).ljust(16)
          + ("%+.3f" % g).ljust(12)
          + ("%+.3f" % (y[k] * g)).ljust(12)
          + "%.4f" % (y[k] * g / np.linalg.norm(w)))

    二、转成对偶问题¶

    2.1 写拉格朗日函数¶

    对每个约束引入乘子 \(\alpha_i \ge 0\)：

    \[ L(\boldsymbol{w},b,\boldsymbol{\alpha}) = \frac12\|\boldsymbol{w}\|^2 - \sum_{i=1}^{n}\alpha_i\left[y_i(\boldsymbol{w}^{\mathsf T}\boldsymbol{x}_i+b)-1\right] \]

    为什么减而不是加：我们把约束写成 \(1-y_i(\cdot)\le 0\) 的形式， 标准做法是减去 \(\alpha_i\) 乘约束

    2.2 对 \(\boldsymbol{w}\) 和 \(b\) 求极小¶

    对 \(\boldsymbol{w}\) 求梯度并令零：

    \[ \nabla_{\boldsymbol{w}}L = \boldsymbol{w} - \sum_i \alpha_i y_i \boldsymbol{x}_i = 0 \]

    于是得到第一个关键关系：

    \[ \boldsymbol{w} = \sum_{i=1}^{n}\alpha_i y_i \boldsymbol{x}_i \]

    这个式子的含义极重要： 最优的 \(\boldsymbol{w}\) 是训练样本的线性组合， 而且组合系数就是拉格朗日乘子

    对 \(b\) 求导并令零：

    \[ \frac{\partial L}{\partial b} = -\sum_i \alpha_i y_i = 0 \;\Longrightarrow\; \sum_i \alpha_i y_i = 0 \]

    这是第二个关键关系（一个等式约束）。

    2.3 回代得到对偶¶

    把两个关系代回 \(L\)。先处理第一项（用 \(\boldsymbol{w}=\sum_i\alpha_iy_i\boldsymbol{x}_i\)）：

    \[ \frac12\|\boldsymbol{w}\|^2 = \frac12\sum_i\sum_j \alpha_i\alpha_j y_i y_j \boldsymbol{x}_i^{\mathsf T}\boldsymbol{x}_j \]

    再处理含 \(b\) 的项：因为 \(\sum_i\alpha_iy_i=0\)，含 \(b\) 的项整块消失：

    \[ \sum_i \alpha_i y_i b = b\sum_i\alpha_i y_i = 0 \]

    合并同类项后得到对偶问题：

    \[ \max_{\boldsymbol{\alpha}}\ \sum_{i=1}^{n}\alpha_i - \frac12\sum_{i,j}\alpha_i\alpha_j y_i y_j \boldsymbol{x}_i^{\mathsf T}\boldsymbol{x}_j \]
    \[ \text{s.t.}\quad \alpha_i \ge 0,\qquad \sum_i \alpha_i y_i = 0 \]

    请注意这里出现的东西：

    \[ \boxed{\ \boldsymbol{x}_i^{\mathsf T}\boldsymbol{x}_j\ } \]

    对偶问题里，样本只以「内积」的形式出现 这就是核技巧的入口 —— 第二节会用到。

    2.4 预测式也只含内积¶

    把 \(\boldsymbol{w}=\sum_i\alpha_iy_i\boldsymbol{x}_i\) 代入判别函数：

    \[ g(\boldsymbol{x}) = \boldsymbol{w}^{\mathsf T}\boldsymbol{x} + b = \sum_{i}\alpha_i y_i\left(\boldsymbol{x}_i^{\mathsf T}\boldsymbol{x}\right) + b \]

    新样本的判别也只需要与训练样本做内积

    2.5 KKT 条件给出支持向量¶

    KKT 的互补松弛条件：

    \[ \alpha_i\left[y_i(\boldsymbol{w}^{\mathsf T}\boldsymbol{x}_i+b)-1\right] = 0 \]

    逐项读：每个样本的乘子与它的"松弛量"至少一个是零。

    情形 约束状态 乘子
    样本在间隔边界上 取等号 \(\alpha_i \gt 0\)（是支持向量）
    样本在间隔带外 严格大于 1 \(\alpha_i = 0\)（不是支持向量）

    import numpy as np

# 用坐标上升（SMO 的思路）解对偶，验证"只有支持向量的乘子大于零"
X = np.array([[1.0, 2.0], [2.0, 1.5], [-1.0, -1.0], [-1.5, -0.5]])
y = np.array([1.0, 1.0, -1.0, -1.0])
n = len(X)

K = X @ X.T
Q = np.outer(y, y) * K


def dual_obj(a):
    """对偶目标（要最大化）。"""
    return a.sum() - 0.5 * a @ Q @ a


# 坐标上升：每轮挑一对乘子 (i, j) 做一步解析更新
a = np.zeros(n)
for _ in range(5000):
    for i in range(n):

        gi = 1.0 - float((Q @ a)[i])

    # 把等式约束 sum(a_i y_i) = 0 投影回来（只调正的乘子那一侧）
    s = float(a @ y)
    if abs(s) > 1e-9:
        idx = np.where(a > 1e-9)[0]
        a[idx] -= s * y[idx] / max(len(idx), 1)
        a = np.maximum(a, 0.0)

b = float(np.mean([y[k] - w @ X[k] for k in sv])) if len(sv) else 0.0

    支持向量机为什么抗过拟合

    因为最终模型只依赖少数几个样本（支持向量）。

    好处有两条：

    · 对非支持向量的扰动不敏感 —— 数据里大量的"容易样本"怎么变 都不影响超平面 · 解是稀疏的 —— 存储与预测只需保存支持向量

    这也是为什么 SVM 在小样本、高维（如基因数据、文本）上表现很好。

    三、软间隔：允许错几个¶

    3.1 硬间隔的困境¶

    硬间隔要求完全可分。但真实数据常常：

    • 有噪声：个别样本落在对方区域
    • 非线性可分：根本不存在这样的超平面

    硬间隔问题此时无解

    3.2 引入松弛变量¶

    给每个样本一个松弛量 \(\xi_i \ge 0\)，把约束放松：

    \[ y_i(\boldsymbol{w}^{\mathsf T}\boldsymbol{x}_i+b)\ \ge 1 - \xi_i \]

    \(\xi_i\) 的含义：该样本违反约束的程度

    新的目标（间隔大 + 违反少）：

    \[ \min_{\boldsymbol{w},b,\boldsymbol{\xi}}\ \frac12\|\boldsymbol{w}\|^2 + C\sum_i \xi_i \]

    \(C\) 的作用：

    \(C\) 取值 倾向 后果
    很大 几乎不允许违反 接近硬间隔，容易过拟合 ⚠
    很小 容忍较多违反 间隔宽，可能欠拟合 ⚠

    3.3 对偶形式只多一个上界¶

    关键结论：软间隔的对偶问题与硬间隔几乎一样， 只是乘子多了个上界：

    \[ 0 \le \alpha_i \le C \]

    为什么多出上界：\(\xi_i \ge 0\) 这个约束也要引入乘子， 两组乘子配合边界条件后，把 \(\alpha_i\) 压在了 \([0,C]\) 区间内

    推论的读法：

    \(\alpha_i\) 含义
    \(= 0\) 间隔带外，不影响模型
    \(0 \lt \alpha_i \lt C\) 恰在间隔边界上
    \(= C\) 在间隔带内或分错（越界样本）⚠

    注意第三行：\(C\) 是上界，所以违反约束的样本乘子被"顶到" \(C\) —— 这正好符合"它们贡献最大"的直觉

    四、核技巧¶

    4.1 从"升维"的困难说起¶

    非线性可分的问题（例如"圆内 vs 圆外"）在低维找不到超平面， 但映射到高维后可能就可分了：

    \[ \boldsymbol{x}\ \longmapsto\ \phi(\boldsymbol{x}) \]

    直接升维的困难：映射后的维数可能极高甚至无穷 （例如高斯核对应无穷维），显式算出 \(\phi(\boldsymbol{x})\) 根本不可行

    4.2 核技巧的关键观察¶

    回看 2.3 与 2.4 节：对偶问题与预测式里， 样本只以 \(\boldsymbol{x}_i^{\mathsf T}\boldsymbol{x}_j\) 的形式出现。

    所以：只要把内积换掉就够了，完全不需要显式的 \(\phi\)：

    \[ \boldsymbol{x}_i^{\mathsf T}\boldsymbol{x}_j \;\longrightarrow\; K(\boldsymbol{x}_i,\boldsymbol{x}_j) = \phi(\boldsymbol{x}_i)^{\mathsf T}\phi(\boldsymbol{x}_j) \]

    这就是核技巧 ✓ —— 它把"先升维再算内积"换成"直接在原空间算一个函数"。

    核函数与显式内积等价：

    import numpy as np

def phi(x):
    """二维到三维的显式特征映射： (x1,x2) -> (x1^2, sqrt(2)x1x2, x2^2)"""
    return np.array([x[0] ** 2, np.sqrt(2.0) * x[0] * x[1], x[1] ** 2])

pairs = [((1.0, 2.0), (3.0, 1.0)),
         ((0.5, -1.0), (-2.0, 0.25)),
         ((1.5, 1.5), (1.5, 1.5))]

print("验证  K(x,y) = (x^T y)^2  等于  phi(x)^T phi(y)")
print("x".ljust(16) + "y".ljust(16) + "核函数值".ljust(14) + "显式内积".ljust(14)
      + "差")
for x, yv in pairs:
    k_val = float(np.dot(x, yv) ** 2)
    ip = float(phi(np.array(x)) @ phi(np.array(yv)))
    print(("%s" % str(x)).ljust(16) + ("%s" % str(yv)).ljust(16)
          + ("%.4f" % k_val).ljust(14) + ("%.4f" % ip).ljust(14)
          + "%.2e" % abs(k_val - ip))
print()
print("结论：核函数在原空间只做一次内积，却等价于三维空间的内积 ✓")

    4.3 什么样的函数能当核¶

    Mercer 条件：\(K\) 是合法核函数的充要条件是， 对任意有限样本集，核矩阵（Gram 矩阵）半正定：

    \[ K_{ij} = K(\boldsymbol{x}_i,\boldsymbol{x}_j) \;\Longrightarrow\; \boldsymbol{K} \succeq 0 \]

    为什么需要这个条件：因为 \(\boldsymbol{K}\) 必须是某个高维空间里的 Gram 矩阵 —— 而 Gram 矩阵必然半正定

    几种常用核：

    名称 形式 特点
    线性核 \(\boldsymbol{x}_i^{\mathsf T}\boldsymbol{x}_j\) 退回线性分类器
    多项式核 \((\boldsymbol{x}_i^{\mathsf T}\boldsymbol{x}_j + c)^d\) 显式的高维映射
    高斯（RBF）核 \(\exp(-\gamma\|\boldsymbol{x}_i-\boldsymbol{x}_j\|^2)\) 无穷维映射，最常用 ✓
    Sigmoid 核 \(\tanh(\cdot)\) 与神经网络有关联

    高斯核为什么对应无穷维：把 \(\exp(-\gamma\|x-y\|^2)\) 展开成幂级数， 每一项对应一个多项式特征，阶数无上限 → 无穷多项

    核函数不是"随便换"的

    三个常见误区：

    ① 不满足半正定的函数不能当核。硬用会导致对偶问题非凸， 求解器给出的结果没有意义

    ② 核参数要调。高斯核的 \(\gamma\) 控制"影响范围"： \(\gamma\) 太大 → 每个样本只影响自己（过拟合）； \(\gamma\) 太小 → 过于平滑（欠拟合）

    ③ 核矩阵是 \(n\times n\) 的。\(n\) 很大时（如 \(10^6\)） 存储与计算都不可行，需要近似方法（随机特征、Nyström 等）

    五、泛化能力：为什么大间隔是好的¶

    5.1 结构风险最小化¶

    经验风险最小化只管训练误差，容易过拟合。 结构风险最小化同时考虑：

    \[ R_{\text{结构}} = R_{\text{经验}} + \lambda\,\Omega(f) \]

    其中 \(\Omega(f)\) 是模型的复杂度惩罚。

    SVM 的巧妙之处：最小化 \(\|\boldsymbol{w}\|^2\) 本身就是复杂度惩罚 所以 SVM 天然就是结构风险最小化 —— 不需要额外加正则项。

    5.2 VC 维与泛化界¶

    VC 维衡量一个函数族的"表达能力"：能打散的最大样本数。

    关键结论：对间隔为 \(\gamma\) 的线性分类器， 其 VC 维满足

    \[ h \le \min\left(\left\lceil\frac{R^2}{\gamma^2}\right\rceil,\ d\right) + 1 \]

    其中 \(R\) 是数据所在球的半径，\(d\) 是特征维数。

    间隔越大，VC 维越小 → 泛化误差界越紧 → 越不容易过拟合

    泛化误差界（以概率 \(1-\delta\) 成立）：

    \[ R_{\text{真}} \le R_{\text{经验}} + \sqrt{\frac{h\left(\ln(2n/h)+1\right)-\ln(\delta/4)}{n}} \]

    两个关键观察：

    • 第二项随 \(n\) 增大而减小 → 样本越多越可信
    • 第二项随 \(h\) 增大而增大 → 复杂度越高越危险

    这就解释了 SVM 的核心设计： 不管特征维数多高，只要间隔大，泛化界就能保证 这也是它在高维小样本上表现优秀的理论依据。

    六、例题¶

    例题 1：证明缩放不变性¶

    题目：设超平面 \(\boldsymbol{w}^{\mathsf T}\boldsymbol{x}+b=0\)。 证明把 \((\boldsymbol{w},b)\) 换成 \((k\boldsymbol{w},kb)\)（\(k \gt 0\)） 后，超平面本身与所有点到它的几何距离都不变。

    思路

    几何距离公式分母带 \(\|\boldsymbol{w}\|\)，看 \(k\) 如何约掉。

    解答

    第一步：超平面不变。

    对所有 \(\boldsymbol{x}\) 满足 \(\boldsymbol{w}^{\mathsf T}\boldsymbol{x}+b=0\)， 有 \(k(\boldsymbol{w}^{\mathsf T}\boldsymbol{x}+b)=0\)， 所以同一批点仍在超平面上

    第二步：几何距离。

    \[ \gamma = \frac{|\boldsymbol{w}^{\mathsf T}\boldsymbol{x}+b|}{\|\boldsymbol{w}\|} \]

    换成缩放后的参数：

    \[ \gamma' = \frac{|k(\boldsymbol{w}^{\mathsf T}\boldsymbol{x}+b)|}{\|k\boldsymbol{w}\|} = \frac{k|\boldsymbol{w}^{\mathsf T}\boldsymbol{x}+b|}{k\|\boldsymbol{w}\|} = \gamma \]

    答案：几何距离确实不变

    几何间隔是真正的几何量，而函数间隔不是。 所以写优化问题时必须固定缩放（如令最近点函数间隔为 1）， 否则目标函数可以被"缩放"到任意大

    例题 2：手算一个二维 SVM¶

    题目：两个样本：正类 \((1,1)\)、负类 \((-1,-1)\)。 求最大间隔超平面与间隔宽度。

    思路

    由对称性猜 \(\boldsymbol{w}\) 的方向，再用约束取等号定尺度。

    解答

    第一步：猜方向。

    两类点连线方向是 \((1,1)\)，最大间隔超平面应与之垂直：

    \[ \boldsymbol{w} = (a,\ a) \]

    第二步：用约束定尺度。

    对正类 \(y=+1\)：

    \[ a\cdot1 + a\cdot1 + b = 1 \ \Rightarrow\ 2a+b=1 \]

    对负类 \(y=-1\)：

    \[ -(-a\cdot1-a\cdot1+b)... \]

    直接写：\(y_2(\boldsymbol{w}^{\mathsf T}\boldsymbol{x}_2+b)=1\)， 而 \(y_2=-1\)、\(\boldsymbol{x}_2=(-1,-1)\)：

    \[ -1\cdot(-a-a+b)=1 \ \Rightarrow\ 2a-b=1 \]

    第三步：解方程组。

    \[ 2a+b=1,\qquad 2a-b=1 \ \Longrightarrow\ b=0,\ a=\frac12 \]

    答案：\(\boldsymbol{w}=(\tfrac12,\tfrac12)\)、\(b=0\)； 间隔宽度为

    \[ \frac{2}{\|\boldsymbol{w}\|} = \frac{2}{\sqrt{1/2}} = \sqrt{8} \approx 2.83 \]

    两个支持向量的中点正是原点， 超平面穿过它们的垂直平分线 —— 与几何直觉一致。

    两个样本的乘子都 \(\gt 0\)（都是支持向量）， 所以这个例子里所有样本都是支持向量（样本太少）

    例题 3：核矩阵的半正定判定¶

    题目：判断 \(K(\boldsymbol{x},\boldsymbol{y}) = (\boldsymbol{x}^{\mathsf T}\boldsymbol{y})^2\) （二维情形）是否为合法核，并写出对应的 \(\phi\)。

    思路

    直接构造特征映射，看能否写成内积。

    解答

    第一步：展开。

    设 \(\boldsymbol{x}=(x_1,x_2)\)、\(\boldsymbol{y}=(y_1,y_2)\)：

    \[ (\boldsymbol{x}^{\mathsf T}\boldsymbol{y})^2 = (x_1y_1+x_2y_2)^2 = x_1^2y_1^2 + 2x_1x_2y_1y_2 + x_2^2y_2^2 \]

    第二步：配成内积。

    \[ = \begin{pmatrix}x_1^2\\ \sqrt2 x_1x_2\\ x_2^2\end{pmatrix}^{\mathsf T} \begin{pmatrix}y_1^2\\ \sqrt2 y_1y_2\\ y_2^2\end{pmatrix} \]

    第三步：结论。

    所以取

    \[ \phi(\boldsymbol{x}) = \left(x_1^2,\ \sqrt2\,x_1x_2,\ x_2^2\right)^{\mathsf T} \]

    就能写成 \(\phi(\boldsymbol{x})^{\mathsf T}\phi(\boldsymbol{y})\)

    答案：是合法核。

    二维输入（2 维）被映射到三维空间， 而核函数只在原空间做一次内积加平方 —— 省掉了显式计算 \(\phi\) 的开销

    这就是核技巧的收益：升维的代价被"藏进"了核函数里。

    例题 4：\(C\) 与 \(\gamma\) 的作用¶

    题目：某人在高斯核 SVM 上得到结果很差： 训练集几乎全对但测试集很差。 他调小 \(C\) 没改善，又调大 \(\gamma\) 反而更差。分析问题在哪，该怎么调。

    思路

    先判断是过拟合还是欠拟合，再分别看 \(C\) 与 \(\gamma\) 各自控制什么。

    解答

    第一步：判断症状。

    「训练几乎全对、测试很差」是典型的过拟合

    第二步：分析第一次调整。

    调小 \(C\) 确实是对的方向（减小 \(C\) 会放宽约束、降低过拟合）。 没改善说明过拟合的主因不在 \(C\)。

    第三步：分析第二次调整。

    调大 \(\gamma\) 是错的方向 因为 \(\gamma\) 越大，每个样本的"影响半径"越小， 决策边界越贴紧训练点 → 过拟合更严重。

    正确方向是调小 \(\gamma\)（让边界更平滑）。

    答案：主因是 \(\gamma\) 太大；应调小 \(\gamma\)， 并配合调小 \(C\)。

    两个超参数控制的东西不同：

    超参数 控制 调大则
    \(C\) 对违反约束的惩罚强度 更贴近训练数据（更易过拟合）
    \(\gamma\) 核的影响范围 边界更复杂（更易过拟合）

    两者都往"过拟合"方向调大，但机理不同 —— 所以调参时要分开诊断，别一起动
