    决策树与集成学习¶

    前面几页的方法（贝叶斯、线性分类器、SVM）都可以写成一个数学表达式。

    决策树不一样：它的判别过程是一串 "如果…就…"的判断 —— 结构化、可解释，而且不需要任何概率假设。

    这一页讲两件事：一棵树怎么长，以及很多棵树怎么一起用。

    为什么决策树值得单独讲

    优点 说明
    可解释 判别路径能直接读出来 —— 医疗、金融等场景要求这个 ✓
    不需假设分布 不像贝叶斯方法要假设高斯
    能处理混合类型 连续、离散、缺失值都能处理
    不需要归一化 它的分裂只看阈值比较，与尺度无关 ✓

    它也是集成方法的基础 —— 随机森林、梯度提升都以树为基学习器， 这几类方法是表格数据上最常用的强基线。

    一、决策树的基本结构¶

    1.1 递归分裂¶

    一棵决策树的构造是递归的：

    1. 在当前节点，选一个特征和一个阈值
    2. 按这个"问题"把样本分成两份
    3. 对每一份重复上面的过程
    4. 直到满足停止条件

    关键问题：每一步该选哪个特征、哪个阈值？

    答案：选能让子集尽可能"纯"的那一个

    1.2 "纯"怎么度量¶

    三种常用判据，本质上都在度量"不纯度"：

    判据 表达式 特点
    信息增益 熵的下降量 ID3 用；偏向取值多的特征 ⚠
    信息增益率 增益 ÷ 特征自身的熵 C4.5 用；修正了上面的偏向 ✓
    基尼系数 \(\sum_k p_k(1-p_k)\) CART 用；不用算对数，快 ✓

    三种判据的对照细节：

    熵 基尼系数
    表达式 \(-\sum_k p_k\log_2 p_k\) \(\sum_k p_k(1-p_k)\)
    纯节点（某类占 1） 0 0
    二类各半 1 0.5
    计算代价 含对数，较慢 只有乘法，快 ✓

    为什么信息增益偏向取值多的特征：

    考虑用"学号"这个特征分裂 —— 每个样本一个取值， 于是每个子节点只有一个样本，纯度必然是 100%， 信息增益达到最大。

    但这个分裂完全没有泛化能力 信息增益率正是为了惩罚这种情形： 它除以特征自身的熵（取值越多熵越大），把比值压下来

    1.3 三种经典算法的差别¶

    算法 分裂判据 树结构 连续特征 缺失值
    ID3 信息增益 多叉 不直接支持 不支持
    C4.5 信息增益率 多叉 支持（二分） 支持
    CART 基尼系数 二叉 支持 ✓ 支持

    CART 只用二叉树这一点很关键： 它把多类别特征也拆成多次二分 —— 这让后续的剪枝与集成处理都更简单

    二、过拟合与剪枝¶

    2.1 树为什么会过拟合¶

    如果不加限制地长下去，树可以把每一个训练样本都分到自己的叶子里 —— 训练误差为零，但泛化能力极差

    极端情形：每个叶子只有一个样本，那么"判别规则"就是 "这个样本的每一个特征值都恰好等于训练时的值" —— 毫无意义。

    2.2 两种剪枝¶

    类型 做法 优点 缺点
    预剪枝 生长时提前停止 快 可能欠拟合（贪心停早了）⚠
    后剪枝 长完再回删 通常更好 ✓ 计算量大

    预剪枝的停止条件（常见几条）：

    • 节点样本数小于某个阈值
    • 不纯度下降小于某个阈值
    • 树深达到上限
    • 节点内所有样本同类

    后剪枝的思路：对每个内部节点，试着把它换成一个叶子， 若换后（在验证集上）效果不下降就保留这个简化

    为什么后剪枝通常更好：预剪枝的停止是贪心的 —— 当前这一步看着没用，但再分两步可能就很有用； 预剪枝会错过这种情况

    剪枝的三个常见误区

    ① 用训练集判断要不要剪枝。 剪枝的目的是改善泛化，所以必须用验证集判断 ⚠ 用训练集的话，"剪掉"永远会让训练误差变大 → 永远不剪。

    ② 以为"树越深越准"。 深处学到的往往是噪声。树深与准确率的关系是先升后降的

    ③ 忘了类别不平衡的影响。 若 99% 样本属于一类，一个"全判成该类"的单节点树准确率就有 99% —— 剪枝可能会保留这种毫无意义的树 此时要用不纯度而不是准确率来判断。

    三、集成学习：为什么"一群弱分类器"更强¶

    3.1 核心思想¶

    单个模型总有它的"盲区"。若把多个模型的判断综合起来， 各自的错误可能互相抵消

    但有一个前提：各模型的错误必须不相关。 若所有模型犯同样的错，综合起来还是错的

    把这一点写成公式：设 \(M\) 个模型各自方差为 \(\sigma^2\)、 两两相关系数为 \(\rho\)，则平均后的方差是

    \[ \operatorname{Var}\left(\frac1M\sum_{m=1}^M\hat f_m\right) = \rho\,\sigma^2 + \frac{1-\rho}{M}\,\sigma^2 \]

    逐项读这个式子：

    项 随 \(M\) 增大
    \(\rho\sigma^2\) 不变 ⚠
    \(\frac{1-\rho}{M}\sigma^2\) 趋于零 ✓

    两个立即有用的结论：

    • \(M\) 增大能消掉第二项 —— 所以模型多一点通常更好
    • 第一项消不掉 —— 所以降低相关性 \(\rho\) 才是关键 ✓

    这就解释了随机森林为什么要"随机"两次

    3.2 装袋（Bagging）¶

    做法：

    1. 从训练集有放回地抽样，得到 \(M\) 个不同的训练子集
    2. 在每个子集上训练一个模型
    3. 分类问题投票，回归问题平均

    为什么有效：每个子集不同 → 各模型学到的细节不同 → 误差相关性降低

    自助抽样的一个性质（值得知道）： 从 \(n\) 个样本中有放回抽 \(n\) 次，约 \(1/e\approx36.8\%\) 的样本抽不到。

    \[ \left(1-\frac1n\right)^n \xrightarrow{n\to\infty} \frac1e \approx 0.368 \]

    这些"袋外样本"（out-of-bag）可以免费当验证集用

    3.3 随机森林：两层随机¶

    第一层随机：对样本做自助抽样（与装袋相同）。

    第二层随机：每次分裂时，只从随机抽取的特征子集里选最优的。

    第二层才是随机森林的关键 ✓

    为什么：如果所有特征都参与竞争，那么当某个特征很强时， 每棵树都会选它 → 树与树结构相似 → 相关性 \(\rho\) 高 → 按 3.1 的公式，平均的收益被第一项卡住

    限制特征子集迫使不同的树用不同的特征， 让结构真正分化开来

    常用设置：分类任务每次试 \(\sqrt{d}\) 个特征，回归任务试 \(d/3\) 个。

    随机森林的三个额外好处：

    好处 说明
    特征重要性 统计每个特征带来的不纯度下降，可排序 ✓
    袋外误差 不用额外切验证集 ✓
    并行 各棵树互不依赖，可以完全并行训练 ✓

    3.4 提升（Boosting）：串行地"补短板"¶

    与装袋的根本差别：

    装袋 提升
    训练方式 并行 串行 ⚠
    各模型地位 平等 加权（后面的更重要）
    关注点 降方差 降偏差
    基学习器 强一些（深树） 很弱（浅树/树桩）

    AdaBoost 的核心思路：

    1. 初始时所有样本权重相同
    2. 训练一个弱分类器
    3. 把分错的样本权重调高（让下一个分类器更关注它们）
    4. 给这个分类器一个权重（错误率越低权重越大）
    5. 重复，最后加权投票

    分类器权重的公式：

    \[ \alpha_m = \frac12\ln\frac{1-e_m}{e_m} \]

    \(e_m\) 是错误率。 错误率低于 0.5 时 \(\alpha_m \gt 0\)（有发言权）； 错误率恰好 0.5 时 \(\alpha_m = 0\)（等于瞎猜，权重为零）； 错误率高于 0.5 时 \(\alpha_m \lt 0\) —— 这意味着"反向投票"反而更好

    集成方法不是"越多越好"

    ① 提升对噪声和离群点敏感。 AdaBoost 会给难以分类的样本越来越大的权重 —— 而真正的离群点永远分不对，于是权重被无限放大， 最终把模型带偏

    ② 树太深会让提升失去意义。 提升的威力来自"用很多弱学习器"； 若基学习器本身就过拟合，串行叠加只会更快过拟合

    ③ 随机森林的树太少时，方差仍然大。 按 3.1 的公式，\(M\) 小的时候第二项还很大

    ④ 集成会牺牲可解释性。 上百棵树的投票结果没法读成一条判别规则 —— 这正好丢掉了决策树最大的优点 需要可解释时，用单棵剪过枝的树，或用特征重要性做近似解释。

    import numpy as np


def entropy(counts):
    """按各类计数算熵（以 2 为底）。"""
    c = np.asarray(counts, dtype=float)
    p = c / c.sum()
    p = p[p > 0]
    return float(-(p * np.log2(p)).sum())


def gini(counts):
    """按各类计数算基尼系数。"""
    c = np.asarray(counts, dtype=float)
    p = c / c.sum()
    return float(1.0 - (p ** 2).sum())

    p = c / c.sum()
    p = p[p > 0]
    return float(-(p * np.log2(p)).sum())

# 增益率：除以特征自身的熵
def split_entropy(sizes):
    p = np.asarray(sizes, dtype=float) / sum(sizes)
    p = p[p > 0]
    return float(-(p * np.log2(p)).sum())

          % (name, se, g, se, g / se if se > 0 else 0.0))

    五、例题¶

    例题 1：手算信息增益¶

    题目：某节点有 10 个样本，正负各 5 个。 用特征 \(A\) 分裂成两个子集：\(D_1\) 有 6 个（正 3 负 3），\(D_2\) 有 4 个（正 2 负 2）。 求信息增益。

    思路

    先算根节点熵、再算子集熵的加权平均，两者相减。

    解答

    第一步：根节点熵。

    \[ H(D) = -\frac{5}{10}\log_2\frac{5}{10} -\frac{5}{10}\log_2\frac{5}{10} = 1 \]

    第二步：两个子集的熵。

    两个子集都是"正负各半"，所以：

    \[ H(D_1) = 1,\qquad H(D_2) = 1 \]

    第三步：加权平均。

    \[ \frac{6}{10}\times1 + \frac{4}{10}\times1 = 1 \]

    第四步：求增益。

    \[ \text{Gain} = 1 - 1 = 0 \]

    答案：信息增益为 0

    这个分裂完全没有信息量 —— 它没有让子集变得更"纯"

    所以特征 \(A\) 不会被选中（除非所有其他候选的增益也是 0）。 这也说明一个直觉：分裂的价值在于"分开"，而不在于"切开"。

    例题 2：基尼系数与熵的对比¶

    题目：某节点二类分布为 \((0.5, 0.5)\)。 分别算熵与基尼系数；再算 \((0.9, 0.1)\) 的两种值。

    思路

    直接代入两个公式。

    解答

    第一步：\((0.5, 0.5)\)。

    \[ H = -0.5\log_2 0.5 - 0.5\log_2 0.5 = 1 \]
    \[ \text{Gini} = 1 - (0.5^2 + 0.5^2) = 1 - 0.5 = 0.5 \]

    第二步：\((0.9, 0.1)\)。

    \[ H = -0.9\log_2 0.9 - 0.1\log_2 0.1 \approx 0.9\times0.152 + 0.1\times3.322 \approx 0.469 \]
    \[ \text{Gini} = 1 - (0.81 + 0.01) = 0.18 \]

    答案：\((0.5,0.5)\) 时熵 1.00、基尼 0.50； \((0.9,0.1)\) 时熵 0.47、基尼 0.18

    两个判据的数值不同但单调趋势一致 —— 都不纯度越高值越大。

    实践中选哪个：基尼系数算得快（无对数运算）， 而且两者选出的树通常很接近

    例题 3：为什么随机森林要限制特征¶

    题目：设单个模型的方差为 1。用 20 个模型做平均。 若模型两两相关系数为 0.8，平均后的方差是多少？ 若降到 0.3 呢？说明随机森林"第二层随机"的价值。

    思路

    用方差公式 \(\rho\sigma^2 + \frac{1-\rho}{M}\sigma^2\)。

    解答

    第一步：\(\rho = 0.8\)、\(M = 20\)。

    \[ \operatorname{Var} = 0.8\times1 + \frac{0.2}{20}\times1 = 0.8 + 0.01 = 0.81 \]

    第二步：\(\rho = 0.3\)、\(M = 20\)。

    \[ \operatorname{Var} = 0.3 + \frac{0.7}{20} = 0.3 + 0.035 = 0.335 \]

    答案：\(0.81\) 与 \(0.335\)

    第三步：对比单模型。

    情形 方差 相对单模型
    单模型 1.000 —
    \(\rho=0.8\)、20 个 0.810 降 19%
    \(\rho=0.3\)、20 个 0.335 降 66% ✓

    相关系数从 0.8 降到 0.3，收益翻了三倍多

    而"限制每次分裂的特征子集"正是降低 \(\rho\) 的手段 —— 这就是随机森林比普通装袋更有效的定量依据

    例题 4：判断该用什么方法¶

    题目：四个需求，分别选什么方法。 （甲）要给医生一个能读出来的判别规则； （乙）表格数据追求最高的预测精度； （丙）数据含大量离群点，且要能解释； （丁）特征维度很高（上万），需要特征重要性排序。

    思路

    从"可解释性 vs 精度"与"对噪声的稳健性"两个维度考虑。

    解答

    甲：单棵剪过枝的决策树。

    · 要可读的规则 → 只有单棵树能给 · 集成方法虽然更准，但没法读成一条规则

    乙：梯度提升树或随机森林。

    · 表格数据上这两类通常是最强基线 · 放弃可解释性，换精度

    丙：随机森林。

    · 随机森林对离群点比提升方法稳健 —— 因为各棵树独立投票，单个离群点影响有限 · 提升方法（如 AdaBoost）会给难分样本不断加权， 离群点会被越放越大 · 随机森林还能给出特征重要性，保留部分解释能力

    丁：随机森林。

    · 每次只试 \(\sqrt{d}\) 个特征 → 高维下训练仍然可行 · 特征重要性排序正是它的自带功能 · 对比：SVM 在万维上也可以，但不给特征重要性

    答案：甲用单棵剪枝树；乙用提升树/随机森林； 丙用随机森林；丁用随机森林。

    可解释性与精度往往是取舍关系

    选择顺序建议是：

    1. 先明确是否必须可解释（这常常是硬约束）
    2. 再在可用的方法里选精度最高的
    3. 数据有离群点时，优先选对离群点稳健的

    七、小结¶

    内容 要点 易错点
    分裂判据 信息增益 / 增益率 / 基尼系数 忽略增益的多取值偏向 ⚠
    三种算法 ID3 / C4.5 / CART，CART 只做二叉 混用判据与结构
    剪枝 预剪枝快但可能欠拟合，后剪枝更好 用训练集判断 ⚠
    装袋 自助抽样 + 并行，降方差 忘了袋外样本可当验证集
    随机森林 两层随机（样本 + 特征） 以为随机没有理论依据
    提升 串行 + 加权，降偏差 树太深、对离群点敏感 ⚠

    三条最该带走的结论：

    1. 分裂的价值在于"分得纯"，而不在于"切得开" —— 信息增益为零的分裂等于白切
    2. 集成的收益被"相关性"卡住 —— 公式里的 \(\rho\sigma^2\) 那一项不会随模型增多而消失， 所以降低相关性比增加模型数更重要
    3. 可解释性与精度常常冲突 —— 需要规则就给单棵树，需要精度就用集成， 两者不可兼得时先问清需求
