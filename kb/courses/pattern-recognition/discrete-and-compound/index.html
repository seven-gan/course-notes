    离散特征与复合模式¶

    这一页解决两个问题： （1）特征不是连续数值，而是一堆「是 / 否」时，前面那套判决规则还能不能用？ （2）一个样本由很多部分组成、每个部分各自有一个判决结果时，怎么把它们合起来判？

    前一页的判别函数、决策面、马氏距离， 全都建立在一个共同前提上：特征 \(x\) 是一个连续向量， 描述它的是概率密度 \(p(x\mid\omega_i)\)。 可现实里大量的特征根本不是连续数值：

    特征 取值 是连续量吗
    某症状是否出现 有 / 无 不是，两档
    问卷某一题的选项 1 / 2 / 3 / 4 / 5 不是，五档
    一段文本里某个词出现几次 \(0, 1, 2, \dots\) 不是，可数但离散
    像素是不是偏红 是 / 否 不是，两档

    这类特征用密度去描述根本无从下手 —— 你没法对一个只知道「有 / 无」的变量画一条平滑的密度曲线。 所以必须单独处理，这就是本页第一部分（对应课件 §2.8）的内容。

    第二个问题完全换了个方向。 前面每一页都在讲「一个样本属于哪一类」。 但很多任务的样本本身是拼起来的： 一个词由好几个字母组成，一次诊断由好几项检查共同支撑， 一个判断由好几个传感器投票决定。 每一部分都已经有自己的判决结果了， 我们要做的是把这些判决结果再综合成一个总体结论。 这就是本页第二部分（对应课件 §2.9）的内容。

    这一页的主线

    两件事看着毫不相干，其实共用同一套机械：

    部分 把什么当特征 用的公式
    离散特征 原始的离散观测值 把密度换成概率，其余不变
    复合模式 第一层的判决结果 把判决结果当离散特征，再判一次

    所以第二部分的本质是：把第一部分的方法， 套在第一层的输出上，做一次「判决的判决」

    一、为什么要把离散特征单独拿出来讲¶

    1.1 前面几节一直默认「特征连续」¶

    回顾已经得到的判决规则（最小错误率，也叫最大后验概率判决）：

    \[\text{判 } \omega_i \quad\text{当}\quad P(\omega_i\mid x) = \max_j P(\omega_j\mid x)\]

    这条规则本身不依赖 \(x\) 是连续还是离散。 但把它用贝叶斯公式展开时：

    \[P(\omega_i\mid x) = \frac{p(x\mid\omega_i)\,P(\omega_i)}{p(x)}\]

    分母是证据：

    \[p(x) = \sum_{j=1}^{c} p(x\mid\omega_j)\,P(\omega_j)\]

    这里的 \(p(x\mid\omega_i)\) 是类条件概率密度， \(c\) 是类别总数，\(\omega_1,\dots,\omega_c\) 是全部类别。

    关键一步：分母 \(p(x)\) 对所有类别都一样， 所以比较 \(P(\omega_i\mid x)\) 的大小， 等价于比较分子 \(p(x\mid\omega_i)P(\omega_i)\) 的大小。 分母可以整项丢掉 —— 这一点在判别函数那一页已经彻底讲透了。

    丢掉分母之后，规则里只剩下密度和先验的乘积。 于是问题来了：如果 \(x\) 是离散的，这个乘积怎么写？

    1.2 离散特征长什么样¶

    课件把离散特征归纳成两类典型场合， 两者在日常里都极其常见：

    场合 例子 取值集合
    问卷调查 每个问题有 2 个或多个选项 \(\{1, 2, \dots, K\}\)
    医疗诊断 是否有某个症状 \(\{0, 1\}\)

    课件的说法是：这类变量的分布用非参数、直方图表示 —— 也就是直接把每个取值上的频率数出来，不做任何函数形式的假设。

    这句「直方图表示」很重要。它的意思是： 离散情形下，我们不需要假定分布属于某个族（比如正态族）， 只需要把每个取值组合上的概率数出来就行。 这比连续情形更朴素，但代价立刻在下一小节出现。

    1.3 记号必须改：概率用大写，密度用小写¶

    这是全页最容易搞混、也最容易被扣分的一点

    记号 名字 含义 量纲
    \(p(x\mid\omega_i)\) 类条件概率密度 连续随机变量的密度值 密度的倒数
    \(P(x\mid\omega_i)\) 类条件概率 离散随机变量取到该值的概率 无量纲

    为什么必须分开写：密度不是概率，它完全可以大于 \(1\)。 举个最直接的例子：标准差只有 \(0.2\) 的正态分布， 在中心处的密度达到 \(1.994711\) —— 一个「概率」怎么可能大于 \(1\)？

    反过来，离散概率一定在 \([0,1]\) 之间，而且同一变量的所有取值加起来必须等于 \(1\)。 这条归一化约束是离散情形独有的、极强的信息， 后面正是靠它推出参数个数的。

    密度不能当概率用

    看到 \(p(x\mid\omega_i)\) 时，千万不要说「这个概率是多少」。 它只是密度的数值，要变成概率还得乘一小段区间长度。

    正确的说法是：

    情形 写法 怎么理解
    连续 \(p(x\mid\omega_i)\) 密度，必须再乘区间长度才是概率
    离散 \(P(x\mid\omega_i)\) 概率，本身就是一个概率

    这一页之后统一用大写 \(P\) 表示离散概率、小写 \(p\) 表示连续密度

    用具体数字手算一遍上面两条结论。 手算比跑代码更能暴露「密度不是概率」这件事的关键。

    手算 1：标准正态在中心处的密度。

    标准正态的密度函数是

    \[p(t) = \frac{1}{\sqrt{2\pi}}\exp\left(-\frac{t^{2}}{2}\right)\]

    把 \(t = 0\) 代进去：指数部分是 \(\exp(0) = 1\)，前面的系数是

    \[\frac{1}{\sqrt{2\pi}} = \frac{1}{2.506628} = 0.398942\]

    所以 \(p(0) = 0.398942\)。这个数小于 \(1\)，看不出问题。

    手算 2：把标准差压到 \(0.2\)。

    一般正态的密度函数是

    \[p(t) = \frac{1}{s\sqrt{2\pi}}\exp\left(-\frac{(t - m)^{2}}{2s^{2}}\right)\]

    取 \(m = 0\)、\(s = 0.2\)，仍然看 \(t = 0\)：指数部分还是 \(\exp(0) = 1\)，只剩前面的系数

    \[p(0) = \frac{1}{s\sqrt{2\pi}} = \frac{1}{0.2 \times 2.506628} = \frac{1}{0.501326} = 1.994711\]

    \(1.994711 \gt 1\) —— 一个「概率」绝不可能大于 \(1\)，所以它只能叫密度

    为什么密度可以这么大：分布越集中，曲线就抬得越高越窄。 总面积恒为 \(1\) 这条约束管的是曲线下面的面积，不是曲线的高度。 把同样多的面积挤进更窄的横轴区间里，高度自然就上去了

    手算 3：密度乘上区间长度，才得到概率。

    在 \(t = 0\) 附近取一小段宽度 \(\Delta\)，这一段的面积近似就是「高 \(\times\) 宽」：

    取的宽度 \(\Delta\) 计算过程 得到的概率
    \(0.5\) \(0.398942 \times 0.5\) \(0.199471\)
    \(0.01\) \(0.398942 \times 0.01\) \(0.003989\)
    \(0.001\) \(0.398942 \times 0.001\) \(0.000399\)

    同一个密度值 \(0.398942\)，乘上三种不同的宽度，得到三个完全不同的数， 最大与最小之间差了 \(500\) 倍。 这一列数字就是「密度本身不是概率」的直接证据： 它必须配上一段区间长度，才变成一个概率量 ✓

    这里说清了密度与概率的关系：密度是单位长度上的概率， 概率是把密度沿长度积起来的结果；区间很短时，积分就退化成乘法。

    连续特征在图上长什么样：每一个类别给出一条密度曲线， 把先验乘上去，谁的曲线高就判谁。 下面这张图就是前一页反复讲的那件事的图形版。

    看图要看的三个地方：

    • 两条曲线的高度差，就是两类「证据强弱」的差；
    • 虚线是两条加权密度（先验乘密度）的交点 —— 交点左边判第 1 类、右边判第 2 类；
    • 纵轴的单位是「密度的倒数」，所以纵轴数值本身不是概率， 要得到概率必须看曲线下的面积 ✓

    注意这里两类的方差都取 \(1\)，所以两条曲线一样高、一样胖， 唯一的区别是位置（一个中心在 \(0\)，一个中心在 \(2.6\)）。 方差一旦不同，两条曲线连胖瘦都不一样，判决面就会变复杂 —— 这正是后面「高斯密度下的判别函数」那一页要处理的事情。

    手算 4：离散情形根本不需要这一步。

    若某个二值特征在第 1 类上 \(P(x = 1\mid\omega_1) = 0.7\)， 那么 \(P(x = 0\mid\omega_1)\) 由归一化条件立即得到：

    \[P(x = 0\mid\omega_1) = 1 - P(x = 1\mid\omega_1) = 1 - 0.7 = 0.3\]

    核对：\(0.3 + 0.7 = 1\)

    这个 \(0.7\) 本身就是一个概率，它不需要乘任何长度。 理由很朴素：一个离散取值点没有「长度」可言 —— \(x\) 要么取 \(1\)、要么取 \(0\)，中间不存在「介于两者之间的取值」， 谈不上「落在 \(1\) 附近多宽的一小段里」

    把两条路线并排放在一起看：

    环节 连续特征 离散特征
    描述工具 概率密度 \(p(x\mid\omega_i)\) 概率 \(P(x\mid\omega_i)\)
    数值能否大于 \(1\) 能（例：\(1.994711\)） 不能，必在 \([0,1]\) 内
    变成概率要做什么 乘区间长度 \(\Delta\)（或做积分） 什么都不用做 ✓
    归一化条件 \(\int p(x)\,dx = 1\) \(\sum_x P(x) = 1\)
    该看曲线的什么 曲线下的面积 单个点的高度

    这张表的最后一行最值得记：连续情形看面积，离散情形看点的高度。 考试里凡是问「这是不是概率」，先问一句：这个变量能不能一个一个数出来 ✓

    二、离散情形的判决规则¶

    2.1 把密度换成概率，其余一个字不改¶

    连续情形的判决规则（丢掉分母之后的形态）：

    \[\text{判 } \omega_i \quad\text{当}\quad p(x\mid\omega_i)\,P(\omega_i) = \max_{j=1}^{c}\bigl[p(x\mid\omega_j)\,P(\omega_j)\bigr]\]

    离散情形只需把每个 \(p\) 换成 \(P\)：

    \[\text{判 } \omega_i \quad\text{当}\quad P(x\mid\omega_i)\,P(\omega_i) = \max_{j=1}^{c}\bigl[P(x\mid\omega_j)\,P(\omega_j)\bigr]\]

    这里：

    • \(x\) 是离散特征向量（可以是单个数，也可以是多维组合）；
    • \(\omega_1,\dots,\omega_c\) 是 \(c\) 个类别；
    • \(P(\omega_j)\) 是第 \(j\) 类的先验概率，满足 \(\sum_j P(\omega_j) = 1\) 且 \(P(\omega_j) \geq 0\)；
    • \(P(x\mid\omega_j)\) 是类条件概率，即「已知真类别是 \(\omega_j\) 时，观测到 \(x\) 的概率」。

    怎么读这条规则：它说「把每个类别的『观测概率 \(\times\) 先验』都算出来，挑最大的那个」。 和连续情形相比，公式的形状一模一样，只有小写 \(p\) 变大写 \(P\)。

    2.2 为什么形状一样：追一遍推导¶

    不能只凭「看起来像」就照抄。把连续情形重新推一遍，看那个「乘区间长度」的步骤在哪：

    第一步，连续情形下的后验（贝叶斯公式）：

    \[P(\omega_i\mid x) = \frac{p(x\mid\omega_i)\,P(\omega_i)}{p(x)}\]

    第二步，把「密度」翻译成「概率」，需要一小段区间： \(x\) 落在以 \(x\) 为中心、体积为 \(\Delta\) 的小块里的概率近似是

    \[P(\text{落进这一小块}\mid\omega_i) \approx p(x\mid\omega_i)\cdot \Delta\]

    第三步，代进后验：

    \[P(\omega_i\mid \text{落进这一小块}) \approx \frac{p(x\mid\omega_i)\,\Delta\,P(\omega_i)}{\sum_j p(x\mid\omega_j)\,\Delta\,P(\omega_j)} = \frac{p(x\mid\omega_i)\,P(\omega_i)}{\sum_j p(x\mid\omega_j)\,P(\omega_j)}\]

    第四步，关键观察：分子分母里的 \(\Delta\) 完全约掉了。

    这就是为什么连续情形的判决规则里从来不需要真的写 \(\Delta\) —— 乘不乘同一个常数，不影响谁最大。 但请记住：\(\Delta\) 之所以能约掉，是因为它对所有类别是同一个数。

    第五步，离散情形根本不需要这个翻译步骤：

    \[P(\omega_i\mid x) = \frac{P(x\mid\omega_i)\,P(\omega_i)}{P(x)}, \qquad P(x) = \sum_{j=1}^{c} P(x\mid\omega_j)\,P(\omega_j)\]

    \(P(x\mid\omega_i)\) 本身已经是概率，直接就是「落进这一个取值点的概率」， 不需要再乘任何区间长度 —— 因为一个离散点没有「长度」。

    2.3 唯一的区别：要不要乘区间长度¶

    把两边的差别整理成一张表：

    对比项 连续情形 离散情形
    类条件项 密度 \(p(x\mid\omega_i)\) 概率 \(P(x\mid\omega_i)\)
    它是概率吗 不是，可以大于 1 是，必在 \([0,1]\) 内
    变成概率要做什么 乘区间长度 \(\Delta\) 什么都不用做 ✓
    判决规则形式 \(p(x\mid\omega_i)P(\omega_i)\) 取最大 \(P(x\mid\omega_i)P(\omega_i)\) 取最大
    分母 \(p(x)\) / \(P(x)\) 与类别无关，可丢掉 与类别无关，可丢掉
    \(\Delta\) 的影响 各类相同，自动约掉 不存在

    要点：离散情形比连续情形更简单 —— 少了一步「乘区间长度」，因为离散概率本来就是概率

    别把两个记号写反

    这两种错误都会实际造成算错：

    错误写法 为什么错
    离散情形也乘一个 \(\Delta\) 离散点没有区间长度，乘上去纯属多余，还会把数值弄错
    连续情形直接说「\(p(x\mid\omega_i)\) 就是概率」 密度不是概率，可以大于 1，说法本身错

    判断办法很简单：看这个变量能不能一个一个数出来。 能数（是否、几档、几次）就是离散，用 \(P\)； 不能数（长度、电压、温度）就是连续，用 \(p\)。

    2.4 同两组数字，两种口径各手算一遍¶

    下面的对照不用代码，全部手算，目的是看清一件事： 两种口径的判决结论完全一致，差别只在连续口径里多乘了一个 \(\Delta\)。

    第一组：连续口径。

    设定：两类都是一维正态，均值 \(\mu_1 = 160\)、\(\mu_2 = 172\)，共用标准差 \(s = 5\)， 先验 \(P(\omega_1) = P(\omega_2) = 0.5\)，区间宽度取 \(\Delta = 0.02\)。

    先把公共系数算出来：

    \[\frac{1}{s\sqrt{2\pi}} = \frac{1}{5 \times 2.506628} = \frac{1}{12.533141} = 0.079788\]

    于是两类的密度分别是

    \[p(x\mid\omega_1) = 0.079788 \times \exp\left(-\frac{(x - 160)^{2}}{50}\right)\]
    \[p(x\mid\omega_2) = 0.079788 \times \exp\left(-\frac{(x - 172)^{2}}{50}\right)\]

    \[-\frac{(166 - 160)^2}{50} = -\frac{36}{50} = -0.72, \qquad \exp(-0.72) = 0.486752\]
    \[p(166\mid\omega_1) = 0.079788 \times 0.486752 = 0.038837\]

    再算第 2 类：\(-\frac{(166-172)^2}{50} = -0.72\)，指数部分一模一样，所以

    \[p(166\mid\omega_2) = 0.038837\]

    两类密度完全相等 —— 因为 \(166\) 到两个均值的距离都是 \(6\)， 而两类方差相同，密度只依赖距离。这就是判决边界上的点。

    手算 \(x_0 = 168\)：

    \[-\frac{(168 - 160)^{2}}{50} = -\frac{64}{50} = -1.28, \qquad \exp(-1.28) = 0.278037\]
    \[p(168\mid\omega_1) = 0.079788 \times 0.278037 = 0.022184\]
    \[-\frac{(168 - 172)^{2}}{50} = -\frac{16}{50} = -0.32, \qquad \exp(-0.32) = 0.726149\]

    三、独立二值特征：课件 §2.8 的重点¶

    3.1 问题设定¶

    课件把最常用的一类离散特征单独拎出来处理，设定非常具体：

    符号 含义 取值范围
    \(d\) 特征的维数（有几个二值特征） 正整数
    \(x = (x_1, x_2, \dots, x_d)\) 待判样本的特征向量 每一维只有两个取值
    \(x_k\) 第 \(k\) 个特征 \(x_k \in \{0, 1\}\)
    \(c\) 类别数 本小节先看 \(c = 2\)
    \(p_k\) 第 1 类中「第 \(k\) 维取 \(1\)」的概率 \(p_k = P(x_k = 1 \mid \omega_1)\)
    \(q_k\) 第 2 类中「第 \(k\) 维取 \(1\)」的概率 \(q_k = P(x_k = 1 \mid \omega_2)\)
    \(P(\omega_i)\) 第 \(i\) 类的先验概率 \(i = 1, 2\)

    这里 \(k\) 从 \(1\) 跑到 \(d\)，所以 \(p\) 和 \(q\) 各是一串数： \(p_1, \dots, p_d\) 与 \(q_1, \dots, q_d\)。

    注意 \(p_k\) 与 \(q_k\) 的关系：既然 \(x_k\) 只取 \(0\) 或 \(1\)，那么 「取 \(0\)」的概率就把剩下的补满：

    \[P(x_k = 0 \mid \omega_1) = 1 - p_k, \qquad P(x_k = 0 \mid \omega_2) = 1 - q_k\]

    这就是二值特征最省事的地方 —— 每一维只需要记住一个数（取 \(1\) 的概率）， 另一个数自动由归一化确定 ✓

    3.2 不假设独立会怎样：参数个数指数爆炸¶

    先把「不假设独立」的情形算清楚，才知道独立假设省了多少。 这件事要用三步推导，每一步都不能跳。

    3.2.1 第一步：数一共有多少种取值组合¶

    每一个二值特征有 \(2\) 种取法（\(0\) 或 \(1\)）。\(d\) 个特征各自独立地选一种， 按乘法原理，组合总数是

    \[2 \times 2 \times \cdots \times 2 = 2^{d} \quad\text{种组合}\]

    手算两个数：\(d = 3\) 时是 \(2^{3} = 8\) 种组合； \(d = 10\) 时是 \(2^{10} = 1024\) 种组合。 注意 \(d\) 只是从 \(3\) 涨到 \(10\)，组合数就从 \(8\) 涨到 \(1024\) —— 维数在加法上增长，组合数在乘法上增长 ⚠

    3.2.2 第二步：这些组合要指定几个概率值¶

    要让 \(P(x\mid\omega_1)\) 成为一个合法的概率分布， 就得给这 \(2^{d}\) 种组合每一种都指定一个概率。 把它们记成

    \[a_1,\ a_2,\ \dots,\ a_{2^{d}}\]

    看起来需要 \(2^{d}\) 个数。但这里有个陷阱：\(2^{d}\) 是「分量的个数」， 不等于「可以自由挑选的个数」。

    3.2.3 第三步：归一化条件把最后一个数绑死¶

    合法的概率分布必须同时满足两条：

    \[a_i \geq 0 \quad (i = 1, 2, \dots, 2^{d}), \qquad \sum_{i=1}^{2^{d}} a_i = 1\]

    第二条就是归一化。现在按顺序一个一个地定：

    • \(a_1\) 可以随便定吗？可以，只要它落在 \([0,1]\) 里；
    • \(a_2\) 呢？也可以，只要 \(a_1 + a_2 \leq 1\)；
    • ……一直下去，\(a_{2^{d}-1}\) 也可以自己定；
    • 到了最后一个 \(a_{2^{d}}\)，它没有选择的余地了。把求和式移项：
    \[a_{2^{d}} = 1 - \left(a_1 + a_2 + \cdots + a_{2^{d}-1}\right)\]

    最后一个数被前面 \(2^{d} - 1\) 个数完全决定，它自己一点自由度都没有。 所以自由参数的个数是

    \[\boxed{\,2^{d} - 1\,}\]

    「自由参数」这个词要抠一下：它数的是可以独立变动的数的个数， 不是「纸上写下来的符号」的个数。 最后一个符号当然还是要写出来的，但它只是一个由前面推出来的结果， 不占用一个自由度

    手算核对 \(d = 3\)（\(8\) 种组合的情形）。设八个概率分别是

    \[a_{000},\ a_{001},\ a_{010},\ a_{011},\ a_{100},\ a_{101},\ a_{110},\ a_{111}\]

    前七个随便取，比如都取 \(0.1\)（和是 \(0.7\)），那么第八个只能是

    \[a_{111} = 1 - 0.7 = 0.3\]

    一共 \(8\) 个符号，真正自由的只有 \(7\) 个 ✓ 与 \(2^{3} - 1 = 7\) 一致。

    3.2.4 独立假设下为什么只要 \(d\) 个参数¶

    现在换成独立假设，把 \(d\) 维的联合概率拆成 \(d\) 个一维概率的乘积：

    \[P(x\mid\omega_1) = P(x_1\mid\omega_1) \times P(x_2\mid\omega_1) \times \cdots \times P(x_d\mid\omega_1)\]

    逐维数一遍自由度。只看第 \(k\) 维：它是个二值变量， 分布由两个数 \(P(x_k = 1\mid\omega_1)\) 与 \(P(x_k = 0\mid\omega_1)\) 描述。 这两个数同样受归一化约束

    \[P(x_k = 0\mid\omega_1) + P(x_k = 1\mid\omega_1) = 1\]

    于是每一维也只有一个自由度：只要记住 \(p_k \equiv P(x_k = 1\mid\omega_1)\)， 另一个数自动是 \(1 - p_k\)。\(d\) 维各贡献一个自由度，合起来是

    \[d \quad\text{个参数}\]

    两类情形各自要 \(d\) 个，所以两类合计 \(2d\) 个； 而不假设独立时两类合计是 \(2(2^{d} - 1)\)。

    关键对比：不假设独立时，自由度在 \(d\) 的指数上； 假设独立之后，自由度落在 \(d\) 的一次项上。 从「\(2^{d} - 1\)」到「\(d\)」这一步，就是维数灾难被压回去的那一刀

    对比项 不假设独立 假设各维条件独立
    每一类要估的参数个数 \(2^{d} - 1\)（指数增长）⚠ \(d\)（线性增长）✓
    两类合计 \(2(2^{d} - 1)\) \(2d\)

    3.3 参数估不出来的具体后果¶

    课件明确指出：\(d\) 一高，参数的存储和估计都会出问题。 把「估不出来」这件事说透：

    假设 \(d = 20\)，需要估 \(2^{20} - 1 = 1048575\) 个参数。 每个参数要估得靠谱，经验上至少要看到它对应的组合出现若干次。 若要求每个参数平均见到 \(10\) 个样本，就需要

    \[1048575 \times 10 = 10485750\]

    也就是一千万级的样本。而很多实际任务里，某一类的样本可能只有几百个 —— 连参数个数都填不满。

    更糟的是：那些很少出现的取值组合， 要么一次都没见到（概率被估成 \(0\)）， 要么只见到一两次（概率被估得离谱）。 这两件事都会让判决严重出错

    维数灾难不是「算得慢」，而是「根本没法估」

    初学者常以为维数高只是「计算量大一点」。 这里的情形更严重：样本量根本不足以支撑参数个数， 所以问题不是效率，而是参数估计本身失效。

    误解 实际情况
    维数高只是算得慢 参数个数指数增长，样本量跟不上
    样本多就能解决 样本量要按指数级一起涨，通常做不到
    少见的组合可以忽略 忽略等于把概率当 \(0\)，判决会直接翻错

    独立假设就是用来把指数级需求压回线性级的那一刀。 它是一笔明确的交易：用「模型可能不准」换「参数估得出来」

    这就是朴素贝叶斯分类器的由来。 它的核心假设只有一条：在给定类别的条件下，各维特征相互独立。 课件在这里点出了它的名字与出发点，更细的内容留待后续章节展开。

    3.4 似然比：从连乘推到线性判别函数¶

    现在把独立假设代进判决规则，看它化简成什么样子。 课件给的路线是似然比（likelihood ratio）。

    第一步：写出两个类的类条件概率。

    利用独立性，把 \(d\) 维的联合概率拆成 \(d\) 个单独的乘积。 对第 \(k\) 维，如果 \(x_k = 1\)，它贡献因子 \(p_k\)； 如果 \(x_k = 0\)，它贡献因子 \(1 - p_k\)。用一个式子统一写出来：

    \[P(x_k\mid\omega_1) = p_k^{\,x_k}\,(1 - p_k)^{\,1 - x_k}\]

    检验一下这个写法：把 \(x_k = 1\) 代进去，指数变成 \(p_k^{1}(1-p_k)^{0} = p_k\)； 把 \(x_k = 0\) 代进去，得到 \(p_k^{0}(1-p_k)^{1} = 1 - p_k\)。 所以这个「指数技巧」把两种情况合成了一行 —— \(x_k\) 在指数位置上当开关用。

    于是两个类的类条件概率是：

    \[P(x\mid\omega_1) = \prod_{k=1}^{d} p_k^{\,x_k}\,(1 - p_k)^{\,1 - x_k}, \qquad P(x\mid\omega_2) = \prod_{k=1}^{d} q_k^{\,x_k}\,(1 - q_k)^{\,1 - x_k}\]

    第二步：写出两类情形的判决量。

    两类情形只需要一个判别函数，取两个「似然乘先验」的比值再取对数：

    \[g(x) = \ln\frac{P(x\mid\omega_1)\,P(\omega_1)}{P(x\mid\omega_2)\,P(\omega_2)}\]

    \(g(x) \gt 0\) 判 \(\omega_1\)，\(g(x) \lt 0\) 判 \(\omega_2\)。 把对数的性质用上（\(\ln\) 把乘变成加）：

    \[g(x) = \underbrace{\ln\frac{P(x\mid\omega_1)}{P(x\mid\omega_2)}}_{\text{似然比的对数}} + \ln\frac{P(\omega_1)}{P(\omega_2)}\]

    第三步：把似然比展开。

    \[\frac{P(x\mid\omega_1)}{P(x\mid\omega_2)} = \frac{\prod_{k=1}^{d} p_k^{\,x_k}(1-p_k)^{1-x_k}} {\prod_{k=1}^{d} q_k^{\,x_k}(1-q_k)^{1-x_k}} = \prod_{k=1}^{d} \frac{p_k^{\,x_k}(1-p_k)^{1-x_k}}{q_k^{\,x_k}(1-q_k)^{1-x_k}}\]

    （第二步用到「分子分母都是同维数的连乘，可以逐项相除」。）

    取对数后，连乘变成连加：

    \[\ln\frac{P(x\mid\omega_1)}{P(x\mid\omega_2)} = \sum_{k=1}^{d} \ln\frac{p_k^{\,x_k}(1-p_k)^{1-x_k}}{q_k^{\,x_k}(1-q_k)^{1-x_k}}\]

    第四步：把每一项按 \(x_k\) 是 \(0\) 还是 \(1\) 拆开。

    当 \(x_k = 1\) 时，这一项是 \(\ln(p_k/q_k)\)； 当 \(x_k = 0\) 时，这一项是 \(\ln\bigl((1-p_k)/(1-q_k)\bigr)\)。 用和前面同一个技巧（\(x_k\) 当开关）：

    \[\ln\frac{p_k^{\,x_k}(1-p_k)^{1-x_k}}{q_k^{\,x_k}(1-q_k)^{1-x_k}} = x_k \ln\frac{p_k}{q_k} + (1 - x_k)\ln\frac{1-p_k}{1-q_k}\]

    第五步：把所有项加起来，按 \(x_k\) 归并。

    把第 \(k\) 项拆成「含 \(x_k\) 的部分」与「不含 \(x_k\) 的部分」：

    \[x_k \ln\frac{p_k}{q_k} + \ln\frac{1-p_k}{1-q_k} - x_k\ln\frac{1-p_k}{1-q_k}\]

    （因为 \((1-x_k)\ln\frac{1-p_k}{1-q_k} = \ln\frac{1-p_k}{1-q_k} - x_k\ln\frac{1-p_k}{1-q_k}\)。）

    前两项含 \(x_k\) 的合并：

    \[x_k\left[\ln\frac{p_k}{q_k} - \ln\frac{1-p_k}{1-q_k}\right] = x_k \ln\frac{p_k(1-q_k)}{q_k(1-p_k)}\]

    （用 \(\ln a - \ln b = \ln(a/b)\)，并把两个分式合起来： \(\frac{p_k/q_k}{(1-p_k)/(1-q_k)} = \frac{p_k(1-q_k)}{q_k(1-p_k)}\)。）

    第六步：得到线性判别函数。

    把上面整理的结果代回 \(g(x)\)：

    \[g(x) = \sum_{k=1}^{d} x_k \ln\frac{p_k(1-q_k)}{q_k(1-p_k)} + \sum_{k=1}^{d}\ln\frac{1-p_k}{1-q_k} + \ln\frac{P(\omega_1)}{P(\omega_2)}\]

    按课件的记号，把它写成线性形式：

    \[g(x) = \sum_{k=1}^{d} w_k\,x_k + w_0\]

    其中每一项的权是

    \[w_k = \ln\frac{p_k\,(1 - q_k)}{q_k\,(1 - p_k)}, \qquad k = 1, 2, \dots, d\]

    常数项是

    \[w_0 = \sum_{k=1}^{d}\ln\frac{1 - p_k}{1 - q_k} + \ln\frac{P(\omega_1)}{P(\omega_2)}\]

    怎么读这个结果：

    • \(g\) 是 \(x\) 的线性函数 —— 没有平方项、没有交叉项。 所以独立二值特征的判别函数是线性判别函数， 决策面在 \(d\) 维空间里是一张超平面 ✓
    • \(w_k\) 衡量第 \(k\) 维的判别能力。 若 \(p_k = q_k\)（两类在这一维上完全一样），则 \(w_k = \ln\frac{p_k(1-p_k)}{p_k(1-p_k)} = \ln 1 = 0\) —— 这一维自动被弃掉，一点都不影响判决 ✓
    • \(w_0\) 里第一部分是「\(1-p_k\) 与 \(1-q_k\) 的差距」， 第二部分是先验比 —— 先验大的那一类整体得分被抬高一截。

    线性不等于「简单」，而是「没有交叉项」

    「线性判别函数」这个词容易被误读成「这个分类器很弱」。 准确的意思是：判别函数里不出现 \(x\) 的任何二次及更高次项。

    说法 对不对 说明
    独立二值特征 → 线性判别函数 对 ✓ 权 \(w_k\) 不依赖 \(x\)，只有 \(x_k\) 的一次项
    线性 → 一定效果差 错 线性指的是函数形式，与效果好坏是两件事
    线性 → 决策面是超平面 对 ✓ 令 \(g(x) = 0\) 得到的是一张超平面

    另外要留神：线性来自「独立假设」，不是自动成立的。 若各维真的相关，真正的判决量里会出现交叉项 \(x_j x_k\)， 那时 \(g\) 就不再是线性的了 ⚠

    • \(\sum x_k = 0\) 时 \(g = -2.748872\)，后验只有 \(0.060150\) —— 强烈的 \(\omega_2\)；
    • \(\sum x_k = 1\) 时 \(g = -1.362578\)，仍然是 \(\omega_2\)，但后验升到 \(0.203822\)；
    • \(\sum x_k = 2\) 时 \(g = 0.023717\)，刚刚翻转成正，后验 \(0.505929\)， 判 \(\omega_1\)；
    • \(\sum x_k = 3\) 时 \(g = 1.410011\)，后验 \(0.803768\)，稳定的 \(\omega_1\)

    这组数字有一处值得停下来看：从 \(\sum x_k = 2\) 起判决就翻过来了， 也就是说这个分类器在 \(\sum x_k = 2\) 处做了一个非常勉强的决定 —— \(g = 0.023717\) 只比 \(0\) 大一点点（后验 \(0.5059\)）。 这说明 \(p_k = 0.8\) 与 \(q_k = 0.5\) 的差距并不算大， 三维还不够让判决变得果断

    边界情况要说清：如果 \(g(x)\) 恰好等于 \(0\)， 就说明两个类的后验相等，判哪一类都可以（在最小错误率意义下两者等价）。 习惯上判给编号小的那一类，但这不是规则要求的。

    3.6 对数形式的判别函数¶

    上面 \(g(x) = \sum_k w_k x_k + w_0\) 这个形式，其实已经是「取过对数」的结果了。 把中间那一步单独拎出来看：

    \[g_i(x) = \ln P(\omega_i) + \sum_{k=1}^{d}\ln P(x_k\mid\omega_i)\]

    这里 \(g_i(x)\) 是第 \(i\) 类的判别函数，\(P(\omega_i)\) 是它的先验， \(P(x_k\mid\omega_i)\) 是它在第 \(k\) 维上的条件概率。怎么读它： 它说「第 \(i\) 类的总分 \(=\) 先验的对数 \(+\) 每一维各自贡献的对数之和」。

    为什么离散情形特别需要这个形式，有三条理由：

    理由 说明
    各项量级相近 每一项都是「概率的对数」，函数形状相同，不会有一项独大 ✓
    每一维的贡献可以单独看 每一项只涉及一个 \(x_k\)，可解释性强 ✓
    便于处理缺失数据 缺哪一维就跳过那一项，不影响其余项 ✓

    第一条尤其要紧。如果直接连乘 \(d\) 个概率， 当 \(d\) 大、每个概率又都小于 \(1\) 时，乘积会迅速掉到下溢区， 最后变成 \(0\)。变成 \(0\) 之后两个类比大小就毫无意义了 —— 两边都是 \(0\)，谁大谁小看不出来

    下溢不是「精度不够」，而是「判决失效」

    数值下溢最容易被低估的地方在于：它看起来只是「数变小了」， 但实际后果是判决机制被破坏。

    阶段 直接连乘 取对数
    数值还正常 可以比大小 可以比大小
    数值掉到下溢区 被压成同一个数（甚至 \(0\)） 仍然是一个正常的负数
    能否判决 不能，两个类的得分变得完全相同 ✗ 能 ✓

    所以取对数在这里不是为了「好看」，而是让判决继续有效。 这一点在判别函数那一页已经讲过，本节用离散特征的具体数字再确认一次。

    这说明什么：取对数不是为了「写得好看」，也不是单纯的省事， 它是在保住判决本身。只要还在用「比较两个得分的大小」这套逻辑， 就必须保证两个得分没有同时被压成同一个数。

    取对数为什么不会改变判决：一句话的代数证明。

    设两类的「似然乘先验」分别是 \(A\) 与 \(B\)，且 \(A \gt B \gt 0\)。 因为 \(\ln\) 是单调递增函数，所以

    \[A \gt B \quad\Longleftrightarrow\quad \ln A \gt \ln B\]

    注意这里的条件是 \(A \gt 0\)、\(B \gt 0\)。 一旦下溢把 \(A\)、\(B\) 都变成 \(0\)，前提就没了， 「\(\ln\) 单调」这条性质也就无从谈起 —— 这就是下溢真正危险的地方 ✓

    再把乘积的对数拆开。由对数的基本性质

    \[\ln(a_1 a_2 \cdots a_d) = \ln a_1 + \ln a_2 + \cdots + \ln a_d\]

    这一步把 \(d\) 次乘法换成了 \(d\) 次加法， 而加法不会下溢（只会变成一个绝对值较大的负数）， 所以判决量始终保得住。

    用这条性质核对一个具体样本。 取 \(d = 6\) 的二值样本

    \[x = (1, 1, 0, 1, 0, 1)\]

    两类参数是 \(p = (0.80, 0.75, 0.70, 0.65, 0.60, 0.55)\)、 \(q = (0.30, 0.35, 0.40, 0.45, 0.50, 0.55)\)，先验各 \(0.5\)。

    路径一（直接连乘）：\(x_k = 1\) 的维取 \(p_k\)，\(x_k = 0\) 的维取 \(1 - p_k\)：

    \[P(x\mid\omega_1) = 0.80 \times 0.75 \times 0.30 \times 0.65 \times 0.40 \times 0.55\]

    逐步相乘：\(0.80 \times 0.75 = 0.60\)；\(\times 0.30 = 0.18\)； \(\times 0.65 = 0.117\)；\(\times 0.40 = 0.0468\)；\(\times 0.55 = 0.02574\) ✓

    同类地

    \[P(x\mid\omega_2) = 0.30 \times 0.35 \times 0.60 \times 0.45 \times 0.50 \times 0.55 = 0.00779625\]

    加上先验（各乘 \(0.5\)）后比较：\(0.01287\) 与 \(0.003898125\)，判 \(\omega_1\)。

    路径二（逐项取对数再相加）：

    \[\ln(0.5) + \bigl[\ln 0.80 + \ln 0.75 + \ln 0.30 + \ln 0.65 + \ln 0.40 + \ln 0.55\bigr]\]

    各对数依次是 \(-0.223144\)、\(-0.287682\)、\(-1.203973\)、\(-0.430783\)、 \(-0.916291\)、\(-0.597837\)，六项之和是 \(-3.659710\)，再加 \(\ln 0.5 = -0.693147\)：

    \[g_1 = -3.659710 - 0.693147 = -4.352857\]

    同类地 \(g_2 = -4.854113 - 0.693147 = -5.547260\)。 \(g_1 \gt g_2\)，同样判 \(\omega_1\) ✓

    两条路径必须给出同一个判决量。把路径一的比值取对数：

    \[\ln\frac{P(x\mid\omega_1)P(\omega_1)}{P(x\mid\omega_2)P(\omega_2)} = \ln\frac{0.01287}{0.003898125} = \ln 3.301530 = 1.194403\]

    而路径二的两个得分之差是

    \[g_1 - g_2 = -4.352857 - (-5.547260) = 1.194403\]

    完全相等，最后一位也对得上

    这就是推导无误的证据：「先连乘再取对数」与「先逐项取对数再相加」 是同一件事的两种写法，判决量一个字都没变。

    再核对一件事：取对数之后，每一项的量级是不是真的相近。

    把若干典型概率取自然对数，做成一张手算表：

    概率 手算 \(\ln(\cdot)\) 落在哪个范围
    \(0.05\) \(\ln 0.05 = -2.995732\) 接近 \(-3\)
    \(0.10\) \(\ln 0.10 = -2.302585\) 约 \(-2.3\)
    \(0.20\) \(\ln 0.20 = -1.609438\) 约 \(-1.6\)
    \(0.30\) \(\ln 0.30 = -1.203973\) 约 \(-1.2\)
    \(0.50\) \(\ln 0.50 = -0.693147\) 约 \(-0.7\)
    \(0.70\) \(\ln 0.70 = -0.356675\) 约 \(-0.36\)
    \(0.90\) \(\ln 0.90 = -0.105361\) 约 \(-0.11\)
    \(0.95\) \(\ln 0.95 = -0.051293\) 约 \(-0.05\)

    怎么读这张表：不管原来的概率是 \(0.05\) 还是 \(0.95\)， 取了对数之后都落在 \([-3, 0]\) 这个很窄的区间里。

    这个「窄」有什么用，对比一下两种做法在 \(d\) 增大时的表现：

    做法 单个量级 \(d\) 项合起来之后的量级 会不会被压成 \(0\)
    直接连乘 都小于 \(1\) \(d\) 项相乘，随 \(d\) 指数缩小 ⚠ 会，\(d\) 一高就归零
    取对数再相加 都落在 \([-3,0]\) \(d\) 项相加，随 \(d\) 线性变负 ✓ 不会，只是一个负数

    关键区别在最后一行：乘法会把量级往 \(0\) 压，而且是指数地压； 加法只会把量级往负数方向线性拉。 \(d = 8000\) 时，\(8000\) 个 \([-3,0]\) 里的数相加，最坏也只是 \(-24000\) —— 一个完全正常的双精度数；而同样 \(8000\) 个小于 \(1\) 的数相乘，早就归零了

    取对数不只是为了防下溢，它还顺带把「每一项的量级彼此相当、 不会有一项独大」这个性质送给了我们。 这一条又直接带来两个实用后果： 每一维的贡献可以单独拿出来看，缺失某一维时也只需要跳过那一项。 下面分别说。

    对数形式还有一个非常实用的附带好处：每一维的贡献都单独可看。 把对数形式的判别函数改成两类相减的形式：

    \[g_1(x) - g_2(x) = \ln\frac{P(\omega_1)}{P(\omega_2)} + \sum_{k=1}^{d}\ln\frac{P(x_k\mid\omega_1)}{P(x_k\mid\omega_2)}\]

    右边的求和里，每一项只和单独一维有关。 所以可以把每一项的正负号看成「这一维单独投票的方向」， 把数值大小看成「这一维的态度有多强」。

    顺着这个思路，缺失数据也变得好处理： 如果第 \(k\) 维没测到，那就跳过求和里的第 \(k\) 项， 其余各项照常算。这比「随便填一个平均数」要克制得多 —— 因为跳过等于承认「这一维不表态」，而填值等于假造了一个证据 ⚠

    用一个 \(8\) 维的例子把「每一维单独投票」这件事手算出来。

    取一个整齐的设定：第 1 类每一维取 \(1\) 的概率从 \(0.60\) 递增到 \(0.95\)， 第 2 类从 \(0.50\) 递减到 \(0.15\)：

    维 \(k\) \(1\) \(2\) \(3\) \(4\) \(5\) \(6\) \(7\) \(8\)
    \(p_k\)（取 \(1\) 属第 1 类） \(0.60\) \(0.65\) \(0.70\) \(0.75\) \(0.80\) \(0.85\) \(0.90\) \(0.95\)
    \(q_k\)（取 \(1\) 属第 2 类） \(0.50\) \(0.45\) \(0.40\) \(0.35\) \(0.30\) \(0.25\) \(0.20\) \(0.15\)

    第 \(k\) 维的贡献是「已知 \(x_k\) 时，两类的条件概率之比的对数」：

    \[\text{贡献}_k = x_k \ln\frac{p_k}{q_k} + (1 - x_k)\ln\frac{1-p_k}{1-q_k}\]

    注意 \(x_k\) 在这里只当开关用：取 \(1\) 就留左边那项，取 \(0\) 就留右边那项。

    \(5\) \(0\) \(0.20 / 0.70\) \(\ln 0.285714\) \(-1.252763\) 支持 \(\omega_2\)
    \(6\) \(1\) \(0.85 / 0.25\) \(\ln 3.4\) \(+1.223775\) 支持 \(\omega_1\)
    \(7\) \(1\) \(0.90 / 0.20\) \(\ln 4.5\) \(+1.504077\) 支持 \(\omega_1\)

    每一项的量级都在个位数以内，没有哪一项压倒性地大 —— 这正是前面说的「各项量级相近、可以单独比较」的意思

    再看「跳过缺失维」会发生什么。 假设第 \(4\) 维没测到， 按前面的说法，把它的贡献整项拿掉，其余七项照算：

    \[-0.306046 - 0.762140 = -1.068186\]

    \[(-0.306046) - (-1.068186) = 0.762140\]

    观察 含义

    判决方向没变（仍然是负号） 本例中方向没被翻转，但不能指望每次都这样
    变化量正好等于第 \(4\) 维的贡献 说明求和确实是逐项可拆的 ✓

    3.7 独立性假设不成立时会怎样¶

    3.8 一个完整的二值特征手算例子¶

    前面都是拿课件的例子。这里从头设计一个，每一步都手算到底， 每一步都写清用了哪条公式。

    场景：判断一个人今天会不会出门。 只用两个二值特征：

    符号 含义 取值
    \(x_1\) 今天是不是晴天 \(1\) 是，\(0\) 不是
    \(x_2\) 今天是不是周末 \(1\) 是，\(0\) 不是
    \(\omega_1\) 出门 —
    \(\omega_2\) 不出门 —

    先验（这两类在总体中的比例）：

    \[P(\omega_1) = 0.4, \qquad P(\omega_2) = 0.6\]

    类条件概率（每一类里，各个特征取 \(1\) 的频率）：

    特征 出门时取 1 的概率 不出门时取 1 的概率
    \(x_1\)（晴天） \(p_1 = 0.9\) \(q_1 = 0.5\)
    \(x_2\)（周末） \(p_2 = 0.8\) \(q_2 = 0.3\)

    先验与类条件概率都定完了，接下来纯手算。

    第一步：算每一维的权。

    \[w_1 = \ln\frac{p_1(1 - q_1)}{q_1(1 - p_1)} = \ln\frac{0.9 \times 0.5}{0.5 \times 0.1} = \ln\frac{0.45}{0.05} = \ln 9 = 2.197225\]
    \[w_2 = \ln\frac{p_2(1 - q_2)}{q_2(1 - p_2)} = \ln\frac{0.8 \times 0.7}{0.3 \times 0.2} = \ln\frac{0.56}{0.06} = \ln 9.333333 = 2.233592\]

    \(w_1 = 2.197225\)、\(w_2 = 2.233592\)，两个都是正数， 说明「晴天」和「周末」都在往「出门」拉，而且拉的力量差不多大 （周末略强一点点）。

    第二步：算常数项。

    先算三维…这里只有两维，所以只算两项：

    \[\ln\frac{1 - p_1}{1 - q_1} = \ln\frac{0.1}{0.5} = \ln 0.2 = -1.609438\]
    \[\ln\frac{1 - p_2}{1 - q_2} = \ln\frac{0.2}{0.7} = \ln 0.285714 = -1.252763\]

    先验比：

    \[\ln\frac{P(\omega_1)}{P(\omega_2)} = \ln\frac{0.4}{0.6} = \ln 0.666667 = -0.405465\]

    全部加起来：

    \[w_0 = (-1.609438) + (-1.252763) + (-0.405465) = -3.267666\]

    \(w_0 = -3.267666\) 是负数且绝对值很大。 它意味着：如果两个特征都不表态（都不取 \(1\)）， \(g(x) = -3.267666 \lt 0\)，判「不出门」。 这与先验一致 —— 「不出门」的先验是 \(0.6\)，占多数

    第三步：逐个组合手算判决。

    判别函数是

    \[g(x) = 2.197225\,x_1 + 2.233592\,x_2 - 3.267666\]

    组合一：\(x = (0, 0)\)，既不晴也不是周末

    \[g = 2.197225 \times 0 + 2.233592 \times 0 - 3.267666 = -3.267666 \lt 0\]

    判「不出门」。

    组合二：\(x = (0, 1)\)，不晴但是周末

    \[g = 0 + 2.233592 - 3.267666 = -1.034074 \lt 0\]

    判「不出门」。（周末一个人还不足以翻盘。）

    组合三：\(x = (1, 0)\)，晴天但不是周末

    \[g = 2.197225 + 0 - 3.267666 = -1.070441 \lt 0\]

    判「不出门」。（晴天一个人也不够。）

    组合四：\(x = (1, 1)\)，晴天且周末

    \[g = 2.197225 + 2.233592 - 3.267666 = 1.163151 \gt 0\]

    判「出门」

    第四步：验一个后验概率，把「判决」和「概率」对上。

    再看 \(x = (1, 1)\)。先算两个类的类条件概率（用独立假设）：

    \[P(x\mid\omega_1) = p_1^{1}(1-p_1)^{0} \cdot p_2^{1}(1-p_2)^{0} = 0.9 \times 0.8 = 0.72\]
    \[P(x\mid\omega_2) = q_1^{1}(1-q_1)^{0} \cdot q_2^{1}(1-q_2)^{0} = 0.5 \times 0.3 = 0.15\]

    再加先验、归一化（分母是两个类各自「似然乘先验」之和）：

    \[P(\omega_1\mid x) = \frac{0.72 \times 0.4}{0.72 \times 0.4 + 0.15 \times 0.6} = \frac{0.288}{0.288 + 0.09} = \frac{0.288}{0.378} = 0.761905\]

    怎么读：看到「晴天且周末」之后，「出门」的概率从先验的 \(0.4\) 升到 \(0.761905\) —— 两个证据把它推过了 \(0.5\) 这条线 ✓

    第五步：核对。 第五步：把四个组合排成一张表，并核对三条路径是否给出同一个数。

    上面每一步都是手算的。把四个组合的类条件概率、后验、判别函数值列在一起：

    组合 \(P(x\mid\text{出门})\) \(P(x\mid\text{不出门})\) \(P(\text{出门}\mid x)\) \(g(x)\) 判决
    \((0,0)\) \(0.1 \times 0.2 = 0.02\) \(0.5 \times 0.7 = 0.35\) \(0.036697\) \(-3.267666\) 不出门
    \((0,1)\) \(0.1 \times 0.8 = 0.08\) \(0.5 \times 0.3 = 0.15\) \(0.262295\) \(-1.034074\) 不出门
    \((1,0)\) \(0.9 \times 0.2 = 0.18\) \(0.5 \times 0.7 = 0.35\) \(0.255319\) \(-1.070441\) 不出门
    \((1,1)\) \(0.9 \times 0.8 = 0.72\) \(0.5 \times 0.3 = 0.15\) \(0.761905\) \(+1.163151\) 出门 ✓

    表里的后验是怎么手算的，以 \((1,1)\) 为例： 先把两个类的「似然乘先验」算出来

    \[a = 0.72 \times 0.4 = 0.288, \qquad b = 0.15 \times 0.6 = 0.09\]

    再归一化（分母就是两者之和）：

    \[P(\omega_1\mid x) = \frac{a}{a + b} = \frac{0.288}{0.288 + 0.09} = \frac{0.288}{0.378} = 0.761905\]

    判决函数值 \(g\) 是怎么手算的：\(g = \ln(a/b)\)，

    \[g = \ln\frac{0.288}{0.09} = \ln 3.2 = 1.163151\]

    现在证明「后验」和「判别函数」本来就是一回事。 把上面两个式子放在一起看：

    \[P = \frac{a}{a + b}, \qquad g = \ln\frac{a}{b}\]

    先算几率（后验除以「非后验」）：

    \[\frac{P}{1 - P} = \frac{a/(a+b)}{b/(a+b)} = \frac{a}{b}\]

    （这一步只用到分母相同，\((a+b)\) 直接约掉。） 两边取对数：

    \[\ln\frac{P}{1 - P} = \ln\frac{a}{b} = g\]

    所以判别函数值就是后验的对数几率，两者是一一对应的： 知道 \(g\) 就知道 \(P\)，反之亦然 ✓

    反解出 \(P\)：从 \(\ln\frac{P}{1-P} = g\) 出发，两边取指数得 \(\frac{P}{1-P} = e^{g}\)， 移项得 \(P = e^{g}(1 - P) = e^{g} - e^{g}P\)，即 \(P(1 + e^{g}) = e^{g}\)， 两边同除以 \((1 + e^{g})\)：

    \[P = \frac{e^{g}}{1 + e^{g}} = \frac{1}{1 + e^{-g}}\]

    用具体数字核对这个公式。\((1,1)\) 时 \(g = 1.163151\)，于是

    \[e^{-g} = e^{-1.163151} = \frac{1}{3.2} = 0.3125\]

    （这里用到了 \(e^{1.163151} = 3.2\)，这正是 \(g = \ln 3.2\) 的定义。）

    \[P = \frac{1}{1 + 0.3125} = \frac{1}{1.3125} = 0.761905\]

    与表里手算的后验逐位相同 ✓

    三条路径的关系：

    路径 算的是什么 \((1,1)\) 时的值
    直接连乘后归一化 后验概率 \(P(\omega_1\mid x)\) \(0.761905\)
    取对数相减 \(g_1 - g_2\) 对数似然比加对数先验比 \(1.163151\)
    线性判别函数 \(\sum_k w_k x_k + w_0\) 同一个对数比，换个写法 \(1.163151\)

    后两个数完全相同，因为它们本来就是同一个 \(g\)； 而第一个数与 \(g\) 之间差一个 \(P = 1/(1 + e^{-g})\) 的换算。 三条路径描述的是同一个判决量，只是刻度不同 ✓

    这说明什么：以后算题时，只要算出 \(g\) 的符号就能判类， 不必再算后验 —— 但如果题目要的是概率，就必须做那一次换算， 不能把 \(g\) 当成概率直接写上去 ⚠

    从这个例子能看出的一般规律：

    观察 一般结论
    晴天（\(w_1 = 2.197\)）与周末（\(w_2 = 2.234\)）力量接近 权的大小直接反映该维的判别能力
    单个特征都不足以翻盘（\(g\) 仍是负） 线性判别函数是累加的，证据要够多才翻
    两个特征同时出现时判决翻转 「证据累加」意味着证据之间可以互相支持 ✓
    \(x = (1,1)\) 的后验 \(0.7619\) 相当自信 但这份自信建立在独立性假设上 ⚠

    一句话记住离散情形的判别函数

    \[g(x) = \sum_{k=1}^{d} w_k x_k + w_0\]

    这个式子可以读成：每一维各自投一票，票的权重是 \(w_k\)， 基础分是 \(w_0\)，总分超过 \(0\) 就判第 1 类。

    三点推论：

    推论 依据
    某维两类一样（\(p_k = q_k\)）时 \(w_k = 0\)，自动弃权 \(\ln 1 = 0\)
    权重可以为负 \(p_k \lt q_k\) 时 \(\ln\) 里小于 \(1\)
    先验改变只动 \(w_0\)，不动 \(w_k\) 先验只出现在常数项里

    最后一条很实用：想调先验的影响，只需改一个数， 不必重算所有的权 ✓

    四、复合模式分类：问题设定¶

    4.1 什么是「复合模式」¶

    前面所有内容都在处理一个「无结构的特征向量」： 把一整堆观测值排成一行 \(x = (x_1,\dots,x_d)\)，然后判它属于哪一类。

    课件的说法是：通常大多把样本当成一个无结构的特征向量， 而复合模式强调「模式是由部件 \(+\) 部件之间的关系共同组成」。

    课件对复合模式识别（也叫组合模式识别）的表述是： 将多个简单子模式（基元）组合在一起，构成一个整体复合模式，再对其整体进行识别。 它不再只看单一特征，而是利用子模式之间的结构关系、空间/时序约束， 来完成模式分类。

    说法 关注点
    无结构特征向量 每个分量都是平权的观测值，它们之间没有关系
    复合模式 样本被拆成若干部分，各部分之间还有关系

    最典型的一个例子是字符串识别。课件用它来引出问题：

    \[X = (x_1, x_2, \dots, x_n), \qquad \boldsymbol{\omega} = (\omega_1, \omega_2, \dots, \omega_n)\]

    这里 \(X\) 是整串的观测（比如依次扫到的 \(n\) 个字符图像）， \(\boldsymbol{\omega}\) 是整串的类别序列 —— 注意它是一个序列，不是一个标量。第 \(i\) 个位置上取第几个字母， 就是 \(\omega_i\) 要回答的问题。

    为什么这件事不平凡：如果字母表有 \(c\) 个字母， 长度为 \(n\) 的串一共有 \(c^{n}\) 种可能。 \(c = 26\)、\(n = 5\) 时就有 \(26^5 = 11881376\) 种组合。 课件明确指出：类别数巨大，\(p(X\mid\boldsymbol{\omega})\) 的存储和估计困难 ⚠

    这条困难和我们前面讲的「维数灾难」是同一个病， 只是换了个地方发作：前面是「特征维数高 → 参数指数增长」， 这里是「串的长度高 → 类别组合指数增长」。

    4.2 三个通俗的场合¶

    复合模式不只是字符串识别。凡是「先分开判、再合起来判」的任务都属于这一类：

    场合 各部分的局部判决 总体决策
    词识别 每个字母的识别结果 整个词是什么
    医学诊断 每一项检查的二值判断（阳性 / 阴性） 最终诊断结论
    多传感器融合 每个传感器的判断 最终判断
    版面分析 每个区域属于什么类型 整页的版面结构
    语音识别 每一帧的音素判决 整句说的是什么

    这些任务的共同点是： 「部分」已经判完了，我们手上拿到的是一串判决结果， 要把它变成一个关于整体的结论。 ✓

    4.3 课件给出的两条技术路线¶

    课件在 §2.9 里给了两条思路，要注意它们的区别：

    路线 表述 输入是什么
    路线一 多个模式同时分类，用上下文条件依赖串起来 各部分的观测
    路线二 把多个分类器的决策当作多维特征，用 Bayes 方法重新分类 各部分的判决结果

    路线一的关键式子是课件给的这一串条件概率：

    \[P(\boldsymbol{\omega}) = P(\omega_1, \omega_2, \dots, \omega_n) = P(\omega_1)\prod_{i=2}^{n}P(\omega_i \mid \omega_{i-1})\]

    课件把它标注为「上下文条件依赖」， 并且指出先验假设是 Markov chain（马尔可夫链）， 对应的完整模型是隐马尔可夫模型（Hidden Markov Model）， 在教材第 3 章展开。

    这个式子在说什么：第 \(i\) 个位置的类别只依赖前一个位置的类别， 再往前的就不管了。这就是「一阶马尔可夫假设」。 它把 \(P(\boldsymbol{\omega})\) 需要的参数从「所有 \(c^{n}\) 种序列的组合」 压回到「\(c\) 个初始概率 \(+\) \(c \times c\) 个转移概率」—— 又是一次「用假设换可行性」的交易

    路线二是本页后半部分的重点，课件对它的原话是 「多个分类器的决策当作多维特征，Bayes 方法重新分类」。 这条路线的输入不是原始观测，而是第一层的判决结果。 下面单独展开。

    5.2 关键：这是「判决的融合」，不是「数据的融合」¶

    这一点必须讲清，否则整个框架会被理解偏 ⚠

    决策融合 第二层 第一层的判决结果 把多个传感器的判断结果合起来

    两层结构做的是决策融合 —— 数据在第一层就已经被消化成判决了。 课件的表述是「多个分类器的决策当作多维特征」，说的正是这件事

    课件在这一点上还给了一句重要的限定： 多分类器融合（Ensemble learning）与复合模式识别类似， 但要注意「通常情况下，这是同一个模式的不同分类结果，而不是多个模式」。

    这句话把两类问题分开了：

    问题 各部分的关系
    复合模式（如字符串识别） 各部分是不同的子模式，它们组合成整体
    多分类器融合 各部分指的是同一个模式被多个分类器各判了一次

    两者在数学形式上几乎一样（都是「把多个判决当特征再判一次」）， 但含义不同：前者的「部分」是空间或时序上的不同位置， 后者的「部分」是同一目标的多次判断。 用同一套公式没问题，但解释时必须说清是哪一种 ⚠

    5.3 好处与代价¶

    好处：

    好处 说明
    降低单点错误的影响 一个部分判错，不必然导致整体判错 ✓
    可以分层调试 哪一层出问题容易定位：先看第一层各部分的准确率，再看第二层
    各层可用不同方法 第一层可以用任意分类器，甚至每个部分用不同方法
    可以用验证数据估参数 第二层需要的条件概率可以在验证集上直接数出来

    代价：

    代价 说明
    第二层拿到的是离散判决 丢失了置信度信息 ⚠
    中间信息不可逆 第一层一旦把观测压成判决，原始信息就回不来了
    两层误差会叠加 第一层的偏差会被第二层当成真的证据继续放大

    「丢失置信度」这一条最值得展开。 看一个具体场景：两个部分都判「第 1 类」， 但其中一个是「\(51\%\) 勉强倾向第 1 类」， 另一个是「\(99\%\) 几乎肯定是第 1 类」。 硬判决把两者完全等同 —— 都只是一票。 而如果第一层输出的是后验概率， 第二层就能知道「这一票的份量有多重」

    课件也提示了这个改进方向： 多分类器融合还可以把分类器输出的判别函数值或排序作为重新分类的特征， 设计一个新的分类器（Meta-classifier）。 这就是从「硬判决」升级到「软判决」的思路， 后面的「软判决与硬判决的对比」一节会把两者的差距用具体数字量化。

    两层结构的输入必须是「判决」，不是「观测」

    写两层结构时最常犯的错，是把第一层的原始输入 直接搬进第二层当特征。

    写法 对不对 后果
    第二层输入 = 第一层的判决 \(e_1,\dots,e_K\) 对 ✓ 维度低、参数少，可以估
    第二层输入 = 第一层的原始观测 错 等于没分层，维度和参数一点没省

    判断标准：第二层的特征维数应该等于「部分的个数」， 而不是「每个部分的特征个数」。

    还有一个相关的误区：以为分层一定能提高准确率。 这也不是自动成立的 —— 见下一节

    六、第二层的贝叶斯判决¶

    6.1 符号与判决规则¶

    先把记号定清楚。

    符号 含义 取值范围
    \(K\) 部分的个数（第一层有几个分类器） 正整数
    \(e_k\) 第 \(k\) 部分的判决结果 \(e_k \in \{\omega_1,\dots,\omega_c\}\)
    \(e = (e_1,\dots,e_K)\) 判决向量（第二层的特征） 每个分量是类别标号
    \(y\) 总体类别（第二层要判的东西） \(y \in \{\omega_1,\dots,\omega_c\}\)
    \(P(y = \omega_i)\) 总体类别的先验 \(\sum_i P(\omega_i) = 1\)
    \(P(e_k = \omega_j \mid y = \omega_i)\) 真类为 \(\omega_i\) 时，第 \(k\) 部分判成 \(\omega_j\) 的概率 就是第 \(k\) 个分类器的混淆矩阵

    注意 \(c\) 在这里同时是总体类别的个数和每个部分判决的可能值个数。 （一般情形下这两者可以不同，本页按相同处理，记号最简单。）

    第二层的判决规则和第一部分形式完全一致，只是特征换成了 \(e\)：

    \[\text{判 } \omega_i \quad\text{当}\quad P(\omega_i)\prod_{k=1}^{K}P(e_k\mid\omega_i) = \max_{j=1}^{c}\Bigl[P(\omega_j)\prod_{k=1}^{K}P(e_k\mid\omega_j)\Bigr]\]

    怎么读它：把「每个部分的判决」当成 \(K\) 个离散特征， 用朴素贝叶斯再判一次。

    6.2 独立性假设在这里是什么意思¶

    上面公式里那个连乘，蕴含了一个假设：

    在给定总体类别 \(y\) 的条件下，各个部分的判决 \(e_1,\dots,e_K\) 相互独立。

    用公式写出来就是：

    \[P(e_1,\dots,e_K\mid y = \omega_i) = \prod_{k=1}^{K}P(e_k\mid y = \omega_i)\]

    左边是「联合概率」，右边是「各自概率的连乘」。 这个等式不是自动成立的，它是一条假设。

    这个假设合理吗？ 要分情况讨论：

    情况 独立性是否合理 理由
    各部分由不同传感器 / 不同特征得到 较合理 ✓ 不同的物理来源，误差来源相对独立
    各部分高度相关（如同一传感器的相邻片段） 不合理 ⚠ 相邻片段共享同一份噪声，一个错常常带着另一个也错
    各部分由同一个模型的多次判断得到 视情况 若用的是同一批训练数据、同一类误差，则很可能相关
    用第一层的后验概率而非硬判决 独立性要求被部分放松 保留更多信息，通常效果更好 ✓

    为什么相关性会害人：如果各部分高度相关， 就相当于同一份错误被反复计入， 第二层会误以为「这么多部分都这么说，那一定没错」—— 后验被推得过分极端，一错就是一起错 ✗

    课件对依赖性给出了两条工程上常用的近似办法：

    办法 式子 保留了什么依赖
    Naïve Bayes（朴素贝叶斯） \(P(e_1,\dots,e_K\mid\omega_i) = \prod_{k=1}^{K}P(e_k\mid\omega_i)\) 什么都不保留（完全独立）
    Dependency tree approximation（依赖树近似） \(P(e_1,\dots,e_K\mid\omega_i) = \prod_{k=1}^{K}P(e_k\mid \mathrm{Pa}(e_k),\omega_i)\) 每个 \(e_k\) 保留一个父节点的依赖

    依赖树里的 \(\mathrm{Pa}(e_k)\) 读作「\(e_k\) 的父节点」， 也就是「\(e_k\) 除了依赖类别之外，还额外依赖的那一个部分」。 它比完全独立灵活一点，参数又只多一点点。

    6.3 第二层融合：拿一个样本手算到底¶

    判决规则已经推完了，这一节用一个具体样本把「累加」的过程一步一步算出来， 顺便看清两层结构到底比单用一个分类器强在哪里。

    这些数字取决于具体数据，不是定理 ⚠ 但两个结论是稳定的： 融合比单用一个分类器好得多（\(0.85 \to 0.95\)）， 而加权（贝叶斯融合）比不加权（多数表决）又好一点点 ✓

    为什么贝叶斯融合比多数表决好：因为贝叶斯融合知道每个部分有多准。 上面那张混淆矩阵里，第 1 部分的对角线是 \(0.86\)、第 5 部分是 \(0.64\) —— 同样投一票，第 1 部分的份量比第 5 部分重得多。 贝叶斯融合把这个「份量」写进了 \(\ln P(e_k\mid\omega_i)\) 的数值里， 多数表决却给每一票完全相同的权重。 份量用进公式，判决自然更准 ✓

    再看一次第 1 部分那一行：它加入的三个数是 \(-0.1475\)、\(-2.5752\)、\(-2.5349\)， 第 1 类那个明显比其他两个「不那么负」；而第 5 部分加入的是 \(-0.4419\)、\(-1.6990\)、\(-1.6821\)，三个数之间的差距小得多。 差距越小，说明这个部分的判别力越弱 —— 对数形式把每一部分的判别力直接写在数字上了 ✓

    6.4 错误率的权衡：融合什么时候有效¶

    前面看到融合确实涨了准确率。但这件事不是无条件的 —— 必须把「什么时候有效」说清楚，否则很容易误用。

    先讲一个来自投票理论的经典结果。 假设：

    • 有 \(n\) 个相互独立的判决（\(n\) 取奇数，避免平票）；
    • 每个单个判决的正确率都是同一个数 \(p\)；
    • 用多数表决（超过半数的那一边胜出）来融合。

    那么整体正确率是「多数票正确」的概率。多数票正确的情形包括 「恰有一半以上的人正确」，所以：

    \[P(\text{整体正确}) = \sum_{k = \lceil n/2 \rceil}^{n} \binom{n}{k}\,p^{k}\,(1-p)^{\,n-k}\]

    这里：

    • \(\binom{n}{k}\) 是组合数，读作「\(n\) 选 \(k\)」， 表示「从 \(n\) 个判决里挑出是哪 \(k\) 个判对了」的方式数；
    • \(p^{k}\) 是这 \(k\) 个判对的概率；
    • \((1-p)^{n-k}\) 是剩下 \(n-k\) 个判错的概率；
    • 求和从 \(\lceil n/2 \rceil\) 开始 —— 因为 \(n\) 是奇数， 「多数」最少就是「一半再多一个」。

    关键结论：当 \(p \gt 0.5\) 且判决相互独立时， 这个和式随 \(n\) 增加而单调上升，并且趋向 \(1\) ✓ 反过来，当 \(p \lt 0.5\) 时， 整体正确率随 \(n\) 增加反而下降，趋向 \(0\) ⚠

    直觉解释：多数表决是在「放大群体的倾向」。 如果群体整体上偏正确（\(p \gt 0.5\)），放大它就越放大越对； 如果群体整体上偏错（\(p \lt 0.5\)），放大它就越放大越错。 所以表决本身不会创造正确性，它只是把原有的倾向放大。

    还有第三种情形，也最容易被忽略：各判决完全相关。 这时不管有多少个判决，它们实际上是同一个判决， \(n\) 再大也等同于 \(n = 1\) —— 一点改善都没有 ⚠

    """n 个独立判决、单个正确率 pv 时，多数表决的理论正确率。"""
    return sum(comb(n, k) * pv ** k * (1 - pv) ** (n - k)
               for k in range(n // 2 + 1, n + 1))


def sim(n, pv):
    """模拟：n 个相互独立的判决，数多数那一派是否正确。"""
    votes = (rng.random((N, n)) < pv).sum(axis=1)
    return float((votes > n / 2).mean())

    这三种情形的对比，推翻了三个常见的误解：

    误解 实际情况

    单个分类器差一点无所谓，靠投票补 单个低于 \(0.5\) 时，投票会让它更差 ✗
    只要数量多，相关性不重要 完全相关时，数量再多也等于 \(1\) 个 ✗

    用一句话概括这一节的结论：

    融合只在「各判决有一定独立性，且单个判决都不太差」时才有收益 ✓

    实际做融合之前，最好先做两件事： （1）测一下各部分两两之间的相关性； （2）测一下每个部分单独的准确率，确认都在 \(0.5\) 以上。 这两件事都不通过，融合很可能是白做。

    6.5 软判决与硬判决的对比¶

    最后回到前面提到的那个代价：第二层拿到的是硬判决， 丢失了置信度信息。这一节把差距量化。

    两种做法：

    做法 第一层输出什么 第二层怎么用
    硬判决 一个类别标号（\(0\) 或 \(1\)） 数票数
    软判决 一个后验概率（\(0\) 到 \(1\) 之间的数） 把概率转成对数几率再加起来

    为什么软判决要转成对数几率：对数几率定义为

    \[\mathrm{logit}(v) = \ln\frac{v}{1 - v}\]

    这里 \(v\) 是第 1 类的后验概率。 它的好处是：独立证据的对数几率可以直接相加 —— 这正是朴素贝叶斯的对数形式（回顾 \(g(x) = \sum_k w_k x_k + w_0\)）。 相加之后再用反函数换回概率：

    \[\sigma(z) = \frac{1}{1 + e^{-z}}\]

    怎么读这两个函数： \(\mathrm{logit}\) 把「概率」翻译成「证据强度」，\(0.5\) 对应 \(0\)（不表态）， 越靠近 \(1\) 越正、越靠近 \(0\) 越负； \(\sigma\) 是它的反函数，把证据强度换回概率 ✓

    先手算几个对数几率，后面三个情形都要用到它们。

    对数几率定义为 \(\mathrm{logit}(v) = \ln\frac{v}{1 - v}\)，逐个数手算：

    后验概率 \(v\) 手算过程 \(\mathrm{logit}(v)\)
    \(0.55\) \(\ln\frac{0.55}{0.45} = \ln 1.222222\) \(+0.200671\)
    \(0.48\) \(\ln\frac{0.48}{0.52} = \ln 0.923077\) \(-0.080043\)
    \(0.99\) \(\ln\frac{0.99}{0.01} = \ln 99\) \(+4.595120\)
    \(0.60\) \(\ln\frac{0.60}{0.40} = \ln 1.5\) \(+0.405465\)
    \(0.70\) \(\ln\frac{0.70}{0.30} = \ln 2.333333\) \(+0.847298\)
    \(0.90\) \(\ln\frac{0.90}{0.10} = \ln 9\) \(+2.197225\)

    怎么读这张表：\(v = 0.5\) 时对数几率是 \(0\)（不表态）； 越靠近 \(1\) 越正，越靠近 \(0\) 越负； 而且远离 \(0.5\) 一点点，对数几率变化很小（\(0.48\) 只有 \(-0.080043\)）， 远离得多了才迅速变大（\(0.99\) 达到 \(4.595120\)）✓

    情形一：五个部分全都只是勉强支持第 1 类（后验都是 \(0.55\)）。

    软判决把五个对数几率相加（先验相等，起点为 \(0\)）：

    \[z = 5 \times 0.200671 = 1.003353\]

    再用 \(\sigma(z) = \frac{1}{1 + e^{-z}}\) 换回概率。先算 \(e^{-1.003353}\)：

    \[e^{-1.003353} = 0.366648\]
    \[P(\omega_1\mid x) = \frac{1}{1 + 0.366648} = 0.731717\]

    软判决说：倾向第 1 类，后验约 \(0.7317\)。

    硬判决那边：五票全部投给第 1 类，票数 \(5\) 比 \(0\)，看起来压倒性。 但票数看不出这五份证据每一份都很弱 ⚠ 五份「\(0.55\)」的证据加在一起，只把后验推到 \(0.73\)， 离「\(5\) 票对 \(0\) 票」给人的印象差得很远。

    情形二：一个部分很自信（\(0.99\)），两个部分几乎不表态（\(0.48\)）。

    这一例最精彩 —— 两种做法会给出相反的判决。

    软判决：先把三个后验换成对数几率，

    \[\mathrm{logit}(0.99) = 4.595120, \qquad \mathrm{logit}(0.48) = -0.080043 \ (\text{两个})\]

    相加：

    \[z = 4.595120 + (-0.080043) + (-0.080043) = 4.595120 - 0.160086 = 4.435034\]

    换回概率：

    \[e^{-4.435034} = 0.011855, \qquad P(\omega_1\mid x) = \frac{1}{1 + 0.011855} = 0.988284\]

    软判决：判 \(\omega_1\)，后验约 \(0.9883\)。

    硬判决：先把三个概率过一遍 \(0.5\) 这条线变成票 —— \(0.99 \gt 0.5\) 投 \(\omega_1\)，两个 \(0.48 \lt 0.5\) 投 \(\omega_2\)。 票数是 \(\omega_1\) 得 \(1\) 票、\(\omega_2\) 得 \(2\) 票，判 \(\omega_2\) ⚠

    做法 结果 依据
    软判决 判 \(\omega_1\)，后验约 \(0.9883\) 那一份 \(0.99\) 的证据太强了
    硬判决 判 \(\omega_2\) 票数 \(1\) 比 \(2\)

    同一个输入，两种做法判决相反。

    哪一个更可信？软判决 —— 因为那两份 \(0.48\) 的证据几乎不表态。 \(0.48\) 对应的对数几率只有 \(-0.080043\)，非常接近 \(0\)， 它们与「不表态」（\(0.5\)）的差距小得可以忽略。 把它们当成两张坚定的反对票，显然曲解了原意 ⚠

    情形三：硬判决要把一票折算成证据强度，必须先假定一个准确率。

    硬判决只知道「投了 \(\omega_1\)」这一件事，想知道这一票有多重， 就得额外假定「这个分类器的准确率是多少」：

    假定的单个准确率 一票折算成的对数几率 数值
    \(0.60\) \(\ln\frac{0.60}{0.40}\) \(0.405465\)
    \(0.70\) \(\ln\frac{0.70}{0.30}\) \(0.847298\)
    \(0.90\) \(\ln\frac{0.90}{0.10}\) \(2.197225\)

    假定 \(0.6\) 时一票值 \(0.405465\)，假定 \(0.9\) 时值 \(2.197225\)，相差五倍多 ⚠ 而这个假定没法从数据里得到 —— 分类器只给了类别标号，没给准确率。

    软判决根本不需要这个假定，因为概率本身就是强度信息 ✓

    把三个情形放在一起看：

    观察 含义
    五份弱证据（\(0.55\)）累加只到 \(0.7317\) 证据弱的时候，数量多也堆不出高置信度
    一份强证据（\(0.99\)）压过两份极弱证据（\(0.48\)） 对数几率相加自动做到了「按强度加权」
    折算硬判决必须先假定准确率 这个假定是硬判决固有的信息缺口

    这说明什么：如果第一层能输出概率（很多分类器都能）， 就用概率。硬判决只在第一层确实只给类别标号时才退而求其次。 而且要注意：一旦退而求其次，你就得自己补一个准确率假定， 这个假定错了，融合结果就会跟着错。

    结论：软判决严格优于硬判决，因为它多带了一份信息（离 \(0.5\) 有多远）， 又少了一个假设（那个假定的准确率）。 第一层只给标号时才不得已用硬判决， 而这时错误率的上限已经被那个无法验证的假设锁死了 ⚠

    七、典型例题¶

    例题 1：把课件那组数字改一改¶

    课件例子是 \(P(\omega_1) = P(\omega_2) = 0.5\)、 \(p_i = 0.8\)、\(q_i = 0.5\)、\(d = 3\)。 现在只改一处：把先验改成 \(P(\omega_1) = 0.2\)、\(P(\omega_2) = 0.8\)， 其余不动。

    (a) 每一维的权 \(w_k\) 变了吗？为什么？ (b) 常数项 \(w_0\) 变成多少？ © \(x = (1,1,1)\) 时判哪一类？ (d) 说明这次改动对判决面的影响。

    思路

    \(w_k\) 的公式里只出现 \(p_k\) 和 \(q_k\)，不出现先验， 所以先验一变，权一个都不变。 先验只出现在 \(w_0\) 的最后一项 \(\ln\frac{P(\omega_1)}{P(\omega_2)}\) 里。 先算出 \(w_0\) 的变化量，其余照抄课件数字。

    解答

    (a) 权一个都没变

    \[w_k = \ln\frac{p_k(1 - q_k)}{q_k(1 - p_k)}\]

    这个式子里只有 \(p_k\) 和 \(q_k\)，先验根本不在其中。 所以三个权仍然是

    \[w_1 = w_2 = w_3 = \ln 4 = 1.386294\]

    一般结论：先验只影响常数项 \(w_0\)，不影响任何 \(w_k\) ✓

    (b) 常数项的变化

    先算改变量。原先是 \(\ln\frac{0.5}{0.5} = 0\)， 现在是

    \[\ln\frac{0.2}{0.8} = \ln 0.25 = -1.386294\]

    所以

    \[w_0 = -2.748872 + (-1.386294) = -4.135167\]

    （第一步 \(-2.748872\) 是 \(\sum_k \ln\frac{1-p_k}{1-q_k}\) 那部分， 与先验无关，照抄课件结果。）

    © \(x = (1,1,1)\) 时的判决

    \[g(x) = 1.386294 \times 3 - 4.135167 = 4.158882 - 4.135167 = 0.023717 \gt 0\]

    判 \(\omega_1\)。

    这一问最值得注意：依然是判 \(\omega_1\)， 但 \(g\) 从原来的 \(1.410011\) 掉到 \(0.023717\) —— 几乎贴在决策面上 也就是说，先验把 \(\omega_1\) 压到 \(0.2\) 之后， 「三维全取 \(1\)」这个相当强的证据才刚刚够翻过判决线。

    (d) 对判决面的影响

    判决面方程是 \(\sum_k w_k x_k + w_0 = 0\)，即

    \[1.386294\sum_k x_k = 4.135167 \quad\Longrightarrow\quad \sum_k x_k = 2.982892\]

    原先（\(w_0 = -2.748872\)）是

    \[\sum_k x_k = \frac{2.748872}{1.386294} = 1.982892\]

    判决面从「\(\sum x_k = 1.98\) 处」移到了「\(2.98\) 处」， 向右（对 \(\omega_1\) 不利的方向）移动了整整 \(1\) 个单位。

    移动方向的一般规律：

    哪个先验被调小 判决面移动方向 谁的「地盘」变小
    \(\omega_1\) 从 \(0.5\) 降到 \(0.2\) 往 \(\omega_1\) 这边推 \(\omega_1\) 的地盘变小

    因为 \(\ln\frac{P(\omega_1)}{P(\omega_2)}\) 从 \(0\) 变成 \(-1.386294\)， 相当于给 \(\omega_1\) 的得分扣掉 \(1.386294\) 分， 那么 \(\omega_1\) 就必须靠更多的 \(x_k = 1\) 才能补回来 ✓

    用一张手算对照表把两种先验下的结果并排看。

    表里每一格都写清算法，方便逐项核对：

    \(P(\omega_1)\) \(w_0\) 的手算过程 阈值 \(\sum_k x_k\) \(x = (1,1,1)\) 时的 \(g\) 判决
    \(0.5\) \(-2.748872 + \ln 1 = -2.748872\) \(2.748872 / 1.386294 = 1.982892\) \(3 \times 1.386294 - 2.748872 = 1.410011\) \(\omega_1\)
    \(0.2\) \(-2.748872 + \ln 0.25 = -4.135167\) \(4.135167 / 1.386294 = 2.982892\) \(3 \times 1.386294 - 4.135167 = 0.023717\) \(\omega_1\)

    三个数必须一起看：

    • \(3 \times 1.386294 = 4.158882\) 是三维修的总得分，两种先验下完全一样；
    • 阈值之差是 \(2.982892 - 1.982892 = 1.000000\)，正好一个整单位；
    • \(x = (1,1,1)\) 的 \(g\) 从 \(1.410011\) 掉到 \(0.023717\)， 但仍然大于 \(0\)，所以判决没有翻转，只是变得极其勉强 ⚠

    这一问最值得记住的一点：先验改变只挪动阈值、不改变权的方向， 所以它不会让判决乱掉，只会让决策面平移。 平移一个整单位意味着：\(\omega_1\) 需要多一维取 \(1\) 才够翻盘 —— 而三维样本总共只有三维，\(1.410011 \to 0.023717\) 已经把余量吃光了 ✓

    例题 2：三位二值特征的手算与核对¶

    两个类、三个二值特征，参数如下：

    项 值
    \(P(\omega_1)\) \(0.7\)
    \(P(\omega_2)\) \(0.3\)
    \(p = (p_1,p_2,p_3)\) \((0.9,\ 0.4,\ 0.6)\)
    \(q = (q_1,q_2,q_3)\) \((0.2,\ 0.6,\ 0.3)\)

    待判样本 \(x = (1, 0, 1)\)。

    (a) 每一维的权 \(w_k\) 与常数项 \(w_0\)； (b) 判别函数值 \(g(x)\)，并给出判决； © 直接算后验 \(P(\omega_1\mid x)\) 核对； (d) 哪一维的判别能力最强？

    思路

    三件事分开算，别混在一起： 先算 \(w_k = \ln\frac{p_k(1-q_k)}{q_k(1-p_k)}\)； 再算 \(w_0 = \sum_k\ln\frac{1-p_k}{1-q_k} + \ln\frac{P(\omega_1)}{P(\omega_2)}\)； 最后把 \(x\) 代进 \(g(x) = \sum_k w_k x_k + w_0\)。 注意 \(x_2 = 0\)，所以第 2 维不进求和，但它的 \(w_0\) 部分照样要算 ⚠

    解答

    (a) 每一维的权

    第 1 维：

    \[w_1 = \ln\frac{0.9 \times (1 - 0.2)}{0.2 \times (1 - 0.9)} = \ln\frac{0.9 \times 0.8}{0.2 \times 0.1} = \ln\frac{0.72}{0.02} = \ln 36 = 3.583519\]

    第 2 维：

    \[w_2 = \ln\frac{0.4 \times (1 - 0.6)}{0.6 \times (1 - 0.4)} = \ln\frac{0.4 \times 0.4}{0.6 \times 0.6} = \ln\frac{0.16}{0.36} = \ln 0.444444 = -0.810930\]

    注意 \(w_2\) 是负的 ⚠ —— 因为 \(p_2 = 0.4 \lt q_2 = 0.6\)， 第 2 维取 \(1\) 反而是往第 2 类拉。

    第 3 维：

    \[w_3 = \ln\frac{0.6 \times (1 - 0.3)}{0.3 \times (1 - 0.6)} = \ln\frac{0.6 \times 0.7}{0.3 \times 0.4} = \ln\frac{0.42}{0.12} = \ln 3.5 = 1.252763\]

    常数项，先算三组 \(\ln\frac{1-p_k}{1-q_k}\)：

    \[\ln\frac{1-0.9}{1-0.2} = \ln\frac{0.1}{0.8} = \ln 0.125 = -2.079442\]
    \[\ln\frac{1-0.4}{1-0.6} = \ln\frac{0.6}{0.4} = \ln 1.5 = 0.405465\]
    \[\ln\frac{1-0.6}{1-0.3} = \ln\frac{0.4}{0.7} = \ln 0.571429 = -0.559616\]

    三组相加：\(-2.079442 + 0.405465 - 0.559616 = -2.233593\)。

    先验比那一项：

    \[\ln\frac{0.7}{0.3} = \ln 2.333333 = 0.847298\]

    所以

    \[w_0 = -2.233593 + 0.847298 = -1.386295\]

    (b) 判别函数值与判决

    \(x = (1, 0, 1)\)，所以只有第 1 维和第 3 维进求和：

    \[g(x) = w_1 \times 1 + w_2 \times 0 + w_3 \times 1 + w_0 = 3.583519 + 0 + 1.252763 - 1.386295 = 3.449987 \gt 0\]

    判 \(\omega_1\) ✓

    © 直接算后验核对

    先算两个类的类条件概率（用独立假设）。 注意 \(x = (1, 0, 1)\)，所以第 2 维取 \(0\)，要用 \((1 - p_2)\) 与 \((1 - q_2)\)：

    \[P(x\mid\omega_1) = p_1^{1}(1-p_1)^{0} \cdot p_2^{0}(1-p_2)^{1} \cdot p_3^{1}(1-p_3)^{0} = 0.9 \times 0.6 \times 0.6 = 0.324\]
    \[P(x\mid\omega_2) = q_1^{1}(1-q_1)^{0} \cdot q_2^{0}(1-q_2)^{1} \cdot q_3^{1}(1-q_3)^{0} = 0.2 \times 0.4 \times 0.3 = 0.024\]

    注意这里容易出错：第 2 维的因子是 \((1 - q_2) = 1 - 0.6 = 0.4\)， 不是 \(q_2 = 0.6\) ⚠

    再加先验、归一化：

    \[P(\omega_1\mid x) = \frac{0.324 \times 0.7}{0.324 \times 0.7 + 0.024 \times 0.3} = \frac{0.2268}{0.2268 + 0.0072} = \frac{0.2268}{0.234} = 0.969231\]

    后验 \(0.969231 \gt 0.5\)，判 \(\omega_1\)，与 (b) 一致

    核对两个口径的关系：对数几率应当等于 \(g(x)\)。检验：

    \[\ln\frac{0.969231}{1 - 0.969231} = \ln\frac{0.969231}{0.030769} = \ln 31.5 = 3.449988\]

    而 (b) 里 \(g(x) = 3.449987\) ✓ 两者一致 （末位差 \(10^{-6}\) 是四舍五入到 \(6\) 位小数造成的）。

    顺便验证似然比那条路径：先算类条件概率的比值

    \[\frac{P(x\mid\omega_1)}{P(x\mid\omega_2)} = \frac{0.324}{0.024} = 13.5, \qquad \ln 13.5 = 2.602690\]

    再加上先验比

    \[\ln\frac{0.7}{0.3} = \ln 2.333333 = 0.847298\]
    \[2.602690 + 0.847298 = 3.449988\]

    三条路径（线性形式、后验反推、似然比 \(+\) 先验比）给出同一个数 这就是判别函数推导正确的最直接证据。

    (d) 哪一维判别能力最强

    看权的绝对值：

    维 \(w_k\) 判别能力
    第 1 维 \(3.583519\) 最强 ✓
    第 2 维 \(-0.810930\) 中等，且方向相反 ⚠
    第 3 维 \(1.252763\) 次强

    例题 3：多数表决什么时候会帮倒忙¶

    某任务需要融合 \(n\) 个判决。

    (a) 各判决独立、单个正确率 \(p = 0.6\)、\(n = 3\) 时，整体正确率是多少？（手算） (b) \(n = 5\) 时呢？ © 若各判决完全相关，\(n = 101\) 时整体正确率是多少？ (d) 若单个正确率只有 \(p = 0.45\)，\(n\) 增加会怎样？

    思路

    用多数表决的正确率公式 \(P = \sum_{k=\lceil n/2\rceil}^{n}\binom{n}{k}p^{k}(1-p)^{n-k}\)。 \(n = 3\) 时多数票是 \(2\) 票或 \(3\) 票；\(n = 5\) 时是 \(3, 4, 5\) 票。 完全相关时所有判决是同一个，\(n\) 不起作用。 \(p \lt 0.5\) 时求和区间的概率质量会随 \(n\) 变小。

    解答

    (a) \(p = 0.6\)、\(n = 3\)

    多数票要求 \(k = 2\) 或 \(k = 3\)：

    \[P = \binom{3}{2}(0.6)^2(0.4)^1 + \binom{3}{3}(0.6)^3(0.4)^0\]

    先算组合数：\(\binom{3}{2} = 3\)，\(\binom{3}{3} = 1\)。 再算幂：\((0.6)^2 = 0.36\)，\((0.6)^3 = 0.216\)，\((0.4)^1 = 0.4\)。

    \[P = 3 \times 0.36 \times 0.4 + 1 \times 0.216 \times 1 = 0.432 + 0.216 = 0.648\]

    整体正确率 \(0.648\) —— 比单个的 \(0.6\) 高了 \(0.048\) ✓

    (b) \(p = 0.6\)、\(n = 5\)

    多数票要求 \(k = 3, 4, 5\)。组合数：\(\binom{5}{3} = 10\)、 \(\binom{5}{4} = 5\)、\(\binom{5}{5} = 1\)。幂：\((0.6)^3 = 0.216\)、 \((0.6)^4 = 0.1296\)、\((0.6)^5 = 0.07776\)、 \((0.4)^2 = 0.16\)、\((0.4)^1 = 0.4\)、\((0.4)^0 = 1\)。

    \[P = 10 \times 0.216 \times 0.16 + 5 \times 0.1296 \times 0.4 + 1 \times 0.07776 \times 1\]

    逐项算：

    项 计算 值
    \(k = 3\) \(10 \times 0.216 \times 0.16\) \(0.345600\)
    \(k = 4\) \(5 \times 0.1296 \times 0.4\) \(0.259200\)
    \(k = 5\) \(1 \times 0.07776 \times 1\) \(0.077760\)
    合计 — \(0.682560\)

    整体正确率 \(0.682560\) —— 又涨了 \(0.03456\)

    对比一下：\(0.6 \to 0.648 \to 0.682560\)， 确实随 \(n\) 上升，而且上升的幅度在变小。

    © 完全相关、\(n = 101\)

    整体正确率仍然是 \(0.6\)，与 \(n = 1\) 完全一样

    理由：完全相关意味着 \(101\) 个判决永远给出同一个答案。 要么 \(101\) 票全对，要么 \(101\) 票全错。 多数表决的结果就是那唯一的一个答案， 所以正确率就是单个判决的正确率 \(0.6\)。 \(n\) 从 \(1\) 涨到 \(101\)，一点改善都没有。

    (d) \(p = 0.45 \lt 0.5\) 时会怎样

    越来越差

    直觉：多数表决放大的是「群体的倾向」。 \(p = 0.45\) 说明群体整体偏错， 放大之后整体正确率趋向 \(0\)。

    条件 \(n\) 增加的效果

    \(n\) \(p = 0.45\)（单判决偏错） \(p = 0.6\)（单判决偏对） \(p = 0.7\)（单判决更对）

    例题 4：两层结构里的独立性被破坏¶

    某个诊断任务有 \(4\) 项检查，每项给一个二值判决。 真类别只有两个：\(\omega_1\)（有病）、\(\omega_2\)（没病）。

    实际情况是：这 \(4\) 项检查里有 \(2\) 项是同一台仪器的两个相近读数， 它们高度相关 —— 要么一起对，要么一起错。 另外 \(2\) 项来自不同仪器，相互独立。

    (a) 如果按朴素贝叶斯（假设全部独立）融合，会发生什么？ (b) 该怎么改？ © 依赖树近似能不能解决这个问题？

    思路

    问题不在「独立性假设是错的」（这个永远有点错）， 而在于把同一份信息数了两遍。 先想清楚「重复计数」的后果是什么方向（过高还是过低）， 再想怎么在建模时把这份重复去掉。

    解答

    (a) 按朴素贝叶斯融合会发生什么

    朴素贝叶斯会把 \(4\) 项全部当成独立证据连乘：

    \[P(\omega_i)\prod_{k=1}^{4}P(e_k\mid\omega_i)\]

    问题在于那 \(2\) 个高度相关的读数： 同一份证据被计入了两次。

    后果是后验被推得过分极端 ⚠

    具体的表现：

    情形 朴素贝叶斯的后验 应有的后验
    两个相关读数都判 \(\omega_1\) 极其接近 \(1\)（虚高） 明显低于朴素值
    两个相关读数都判 \(\omega_2\) 极其接近 \(0\)（虚低） 明显高于朴素值

    最危险的方向是第一种：两个相关读数一致地判错时， 朴素贝叶斯会给出一个接近 \(1\) 的自信错误 —— 它把「同一个错误说了两遍」误读成「两个独立来源都这么说」✗

    这与 §3.7 那个「两列完全相同」的实验是同一个机理： 那个实验里错误率被放大了 \(2.0\) 倍， 诊断场景下后果更严重 —— 因为错误是以「高度自信」的形式给出的。

    (b) 该怎么改

    三条可行做法，按推荐程度排列：

    做法 具体操作 效果
    合并相关项 把 \(2\) 个相关读数合成 \(1\) 项（或只留一个） 最直接，从根源去掉重复 ✓
    用软判决 让第 1 层输出后验概率而非硬判决 保留信息，减轻极端化 ✓
    显式建依赖 用依赖树把这两项连起来 保留部分依赖，参数略增

    为什么「合并」最干净：独立性假设之所以被违反， 是因为这两项本来就不是独立的信息源。 把它们合成一项之后，剩下的 \(3\) 项之间独立性就合理得多， 朴素贝叶斯的前提也就基本站得住了 ✓

    注意合并的代价：合并意味着丢掉一部分细节。 如果这两项确实各自还有一点独立的信息 （比如读数的时间点不同），合并就会损失它。 这时可以退而用第三种做法。

    © 依赖树近似能不能解决

    能，但只能部分解决 ✓⚠

    依赖树近似把联合分布写成

    \[P(e_1,\dots,e_K\mid\omega_i) = \prod_{k=1}^{K}P(e_k\mid \mathrm{Pa}(e_k), \omega_i)\]

    这里 \(\mathrm{Pa}(e_k)\) 是 \(e_k\) 的父节点。 只要把两个相关读数设成「一个做另一个的父节点」， 这份依赖就被显式建模了：

    做法 对这份依赖的处理
    朴素贝叶斯 假装不存在（假设独立） ✗
    依赖树 显式写进条件里：\(P(e_2\mid e_1,\omega_i)\) ✓
    完全联合 全都建模，但参数爆炸

    所以依赖树确实能修掉这一个具体问题。

    为什么只是「部分」解决： 依赖树给每个节点只留一个父节点。 如果有三项互相纠缠（\(e_1\) 与 \(e_2\) 相关，\(e_2\) 又与 \(e_3\) 相关）， 依赖树的表达能力就不够了 —— 它没法同时表达两条依赖。 这时要么换更复杂的图模型，要么回到「合并」这条更朴素的路。

    一般的判断顺序（这是本页最后一条实用建议）：

    顺序 检查什么 不行就怎么办
    1 各部分的输入是不是相互独立的来源 合并或剔除冗余部分
    2 各部分单独的准确率是否都高于 \(0.5\) 太差的先改进或剔除
    3 第一层能否输出概率 能就用软判决
    4 还有明显依赖残留 用依赖树等更强的模型

    把上面的判断用具体数字手算一遍。

    设从验证数据上估出三个数（已给定）：

    \[P(\omega_1) = 0.05, \qquad P(e = 1\mid\omega_1) = 0.9, \qquad P(e = 1\mid\omega_2) = 0.1\]

    前两项是同一台仪器的相近读数（记为 \(s\)，两列完全相同）， 后两项来自相互独立的仪器（记为 \(s_3\)、\(s_4\)）。

    两种数法：

    • 朴素：把 \(4\) 项全部当独立证据，\(s\) 被计两遍；
    • 合并：把两列重合的读数合并成一项，只用 \(3\) 项，\(s\) 只计一遍。

    判决量是「先验 \(\times\) 各项类条件概率的连乘」， 判决取后验 \(P(\omega_1\mid x)\) 是否超过 \(0.5\)。

    逐例手算：

    输入 \((s, s, s_3, s_4)\) 朴素的手算 合并的手算 后验（朴素 / 合并） 判决
    \((1,1,1,1)\) \(0.05 \times 0.9^{4} = 0.032805\) 对 \(0.95 \times 0.1^{4} = 0.000095\) \(0.05 \times 0.9^{3} = 0.036450\) 对 \(0.95 \times 0.1^{3} = 0.000950\) \(0.997112\) / \(0.974599\) 都判 \(\omega_1\)
    \((1,1,0,0)\) \(0.05 \times 0.9^{2} \times 0.1^{2} = 0.000405\) 对 \(0.95 \times 0.1^{2} \times 0.9^{2} = 0.007695\) \(0.05 \times 0.9 \times 0.1^{2} = 0.000450\) 对 \(0.95 \times 0.1 \times 0.9^{2} = 0.076950\) \(0.050000\) / \(0.005814\) 都判 \(\omega_2\)
    \((0,0,1,1)\) \(0.05 \times 0.9^{2} \times 0.1^{2} = 0.000405\) 对 \(0.95 \times 0.1^{2} \times 0.9^{2} = 0.007695\) \(0.05 \times 0.9^{2} \times 0.1 = 0.004050\) 对 \(0.95 \times 0.1^{2} \times 0.9 = 0.008550\) \(0.050000\) / \(0.321429\) 都判 \(\omega_2\)

    抽第一行核对后验：\(0.032805 / (0.032805 + 0.000095) = 0.032805 / 0.032900 = 0.997112\) ✓

    第一行：四项全判「阳性」，朴素给出 \(0.997112\)、合并给出 \(0.974599\) —— 朴素更接近 \(1\)，这就是「虚高」 ⚠ 重复计数把同一份证据数了两遍，等于给那一份证据加了一倍的权重。

    第二行与第三行：后验数值明显不同，但判决方向一致。 差别就来自 \(s\) 那一份证据被数了几遍。

    有没有可能连判决方向都翻掉：有的。 把情形缩到「只有一列读数」再来一次： 朴素（数两遍）给出 \(P(\omega_1\mid x) = 0.810000\)，判 \(\omega_1\)； 合并（只数一遍）给出 \(0.321429\)，判 \(\omega_2\) —— 同一份输入，判决方向相反 ⚠ 这就是重复计数最危险的后果：它会把一个正确的否定判断翻成肯定的误判。

    这正是本页 §3.7 那个实验的机理： 那里两列完全相同的观测让测试集错误率放大了 \(2.0\) 倍。 本例题的场景更严重 —— 因为错误是以「高度自信」的形式给出的。

    八、自测¶

    Q1 判断对错并说明理由：

    某位同学的判别函数写成

    \[g(x) = \ln\frac{P(x\mid\omega_1)}{P(x\mid\omega_2)} + \ln\frac{P(\omega_1)}{P(\omega_2)}\]

    他把 \(P(x\mid\omega_1)\) 直接当成「观测到 \(x\) 的概率」。

    (a) 如果 \(x\) 是连续特征，这个说法对不对？ (b) 如果 \(x\) 是离散特征呢？ © 这个 \(g(x)\) 的判决规则是什么？

    提示

    先分清「密度」和「概率」。 再看题目里有没有出现「\(x\) 落在某个小区域」这样的说法 —— 有的话就是连续情形，必须乘区间长度。

    解答

    (a) 连续情形：说法不对 ✗

    \(P(x\mid\omega_1)\) 在连续情形下是概率密度， 它不是概率，可以大于 \(1\)。

    举个算过的例子：标准差 \(0.2\) 的正态分布在中心处的密度是 \(1.994711\)。 一个「概率」不可能大于 \(1\)，所以它显然不是概率

    要说成「概率」，必须写成「\(x\) 落在某个小区间里的概率」， 也就是 \(p(x\mid\omega_1)\Delta\)。

    (b) 离散情形：说法对

    离散时 \(P(x\mid\omega_1)\) 就是「变量取到这一个具体值的概率」， 它确实是一个概率，必在 \([0,1]\) 之间， 而且对同一变量的所有取值求和必须等于 \(1\)。

    © 判决规则

    这是两类情形，故只需看 \(g(x)\) 的符号：

    \(g(x)\) 的符号 判为
    \(g(x) \gt 0\) \(\omega_1\)
    \(g(x) \lt 0\) \(\omega_2\)
    \(g(x) = 0\) 两类的后验相等，判哪一类都行

    为什么：\(g(x)\) 是「\(\omega_1\) 的得分除以 \(\omega_2\) 的得分」再取对数。 若 \(g(x) \gt 0\)，说明分子大于分母，即 \(P(x\mid\omega_1)P(\omega_1) \gt P(x\mid\omega_2)P(\omega_2)\)， 按判决规则应判 \(\omega_1\)

    把三小问的判据手算列成一张表。

    (a) 连续情形：密度能不能大于 \(1\)，手算一个就够。 取 \(m = 0\)、\(s = 0.2\)、\(t = 0\)：

    \[p(0) = \frac{1}{0.2 \times \sqrt{2\pi}} = \frac{1}{0.2 \times 2.506628} = 1.994711\]

    \(1.994711 \gt 1\)，所以它不可能是概率 ✗ 要变成概率还得乘区间长度，例如乘 \(\Delta = 0.01\)：

    \[1.994711 \times 0.01 = 0.019947\]

    这才是一个合法的概率值

    (b) 离散情形：手算一个二值分布。 设 \(P(x=0\mid\omega_1) = 0.3\)、\(P(x=1\mid\omega_1) = 0.7\)，则

    \[0.3 + 0.7 = 1.0\]

    两个数都在 \([0,1]\) 内、加起来等于 \(1\) —— 它本身就是概率

    © 判决规则：\(g(x)\) 的符号与判类一一对应：

    \(g(x)\) 的取值 手算核对 判为
    \(g = -2.0 \lt 0\) \(\omega_2\) 得分是 \(\omega_1\) 的 \(e^{2} = 7.389\) 倍 \(\omega_2\)
    \(g = 0\) 两类得分相等，\(e^{0} = 1\) 判哪一类都行
    \(g = 3.0 \gt 0\) \(\omega_1\) 得分是 \(\omega_2\) 的 \(e^{3} = 20.086\) 倍 \(\omega_1\)

    中间那一行最容易被忽略：\(g = 0\) 意味着 \(\frac{a}{b} = e^{0} = 1\)， 也就是 \(a = b\)，两类后验都是 \(0.5\)， 在最小错误率意义下判哪一类都等价 习惯上判编号小的那一类，但这不是规则的要求。

    Q2 某两类问题，\(d = 3\) 个二值特征， \(p = (0.7, 0.7, 0.7)\)、\(q = (0.4, 0.4, 0.4)\)、先验相等。

    (a) 每一维的权是多少？ (b) 常数项是多少？ © 至少要有几维取 \(1\) 才会判 \(\omega_1\)？ (d) 如果 \(d = 20\)、参数照旧，这个阈值会变成多少维？

    提示

    三维完全对称，所以三个权都相同。 阈值就是让 \(g(x) = 0\) 的那个 \(\sum_k x_k\)。 最后一问要先写出一般的阈值公式，再代 \(d = 20\)。

    解答

    (a) 每一维的权

    \[w_k = \ln\frac{p_k(1 - q_k)}{q_k(1 - p_k)} = \ln\frac{0.7 \times 0.6}{0.4 \times 0.3} = \ln\frac{0.42}{0.12} = \ln 3.5 = 1.252763\]

    三维相同：\(w_1 = w_2 = w_3 = 1.252763\)。

    (b) 常数项

    先算单维的那部分：

    \[\ln\frac{1 - 0.7}{1 - 0.4} = \ln\frac{0.3}{0.6} = \ln 0.5 = -0.693147\]

    三维相加：\(3 \times (-0.693147) = -2.079442\)。

    先验比：\(\ln\frac{0.5}{0.5} = 0\)。

    \[w_0 = -2.079442\]

    © 阈值是几维

    判别函数 \(g(x) = 1.252763\sum_k x_k - 2.079442\)。 令 \(g \gt 0\)：

    \[1.252763\sum_k x_k \gt 2.079442 \quad\Longrightarrow\quad \sum_k x_k \gt \frac{2.079442}{1.252763} = 1.659884\]

    所以需要 \(\sum_k x_k \geq 2\)，也就是至少两维取 \(1\)

    验证一下 \(\sum_k x_k = 2\)：

    \[g = 1.252763 \times 2 - 2.079442 = 2.505526 - 2.079442 = 0.426084 \gt 0\]

    确实翻正。再验证 \(\sum_k x_k = 1\)：

    \[g = 1.252763 - 2.079442 = -0.826679 \lt 0\]

    仍然判 \(\omega_2\)

    (d) \(d = 20\) 时的阈值

    一般地，\(d\) 维对称情形下：\(w_k\) 都等于 \(w\)， \(w_0 = d\ln\frac{1-p}{1-q} + \ln\frac{P(\omega_1)}{P(\omega_2)}\)。

    阈值条件是

    \[w\sum_k x_k + w_0 \gt 0 \quad\Longrightarrow\quad \sum_k x_k \gt \frac{-w_0}{w} = \frac{-d\ln\frac{1-p}{1-q} - \ln\frac{P_1}{P_2}}{w}\]

    先验相等时最后一项为 \(0\)，于是

    \[\text{阈值} = \frac{-d \times (-0.693147)}{1.252763} = \frac{0.693147\,d}{1.252763} = 0.553292\,d\]

    \(d = 20\) 时：

    \[\text{阈值} = 0.553292 \times 20 = 11.065895\]

    也就是需要 \(\sum_k x_k \geq 12\) —— \(20\) 维里至少要 \(12\) 维取 \(1\)

    怎么读这个结果：

    \(d\) 阈值所需维数 占比
    \(3\) \(2\) \(66.7\%\)
    \(20\) \(12\) \(60\%\)

    占比基本稳定在 \(55\%\) 左右（理论值就是 \(0.553292\)）。 这说明：对称情形下，「需要多少比例的证据」与维数无关 —— 它只由 \(p\)、\(q\) 决定。维数增加不会让阈值的比例变苛刻， 但会让「达到这个比例」越来越难（因为要求更多维正好取 \(1\)）

    把不同 \(d\) 下的阈值做成手算对照表。

    对称情形的阈值公式是

    \[\text{阈值} = \frac{-w_0}{w} = \frac{-d \times \ln\frac{1-p}{1-q}}{w} = \frac{0.693147\,d}{1.252763} = 0.553294\,d\]

    逐格手算：

    \(d\) 手算 \(w_0 = 0.693147 d\)（取负） 手算阈值 \(= 0.553294 d\) 所需维数 占比
    \(3\) \(-2.079442\) \(1.659884\) \(2\) \(66.67\%\)
    \(5\) \(-3.465736\) \(2.766474\) \(3\) \(60.00\%\)
    \(10\) \(-6.931472\) \(5.532948\) \(6\) \(60.00\%\)
    \(20\) \(-13.862944\) \(11.065895\) \(12\) \(60.00\%\)
    \(50\) \(-34.657359\) \(27.664738\) \(28\) \(56.00\%\)

    「所需维数」怎么来的：\(\sum_k x_k\) 只能取整数， 条件 \(\sum_k x_k \gt 1.659884\) 意味着至少取 \(2\)； \(d = 20\) 时要求 \(\sum_k x_k \gt 11.065895\)，所以至少取 \(12\) ✓

    核对 \(d = 3\) 的两个边界：

    \[\sum_k x_k = 2:\quad g = 1.252763 \times 2 - 2.079442 = 0.426084 \gt 0 \ \checkmark\]
    \[\sum_k x_k = 1:\quad g = 1.252763 \times 1 - 2.079442 = -0.826679 \lt 0 \ \checkmark\]

    一个翻正、一个仍为负，阈值卡在两维与一维之间，与 \(1.659884\) 一致 ✓

    怎么读「占比」这一列：\(d\) 从 \(3\) 涨到 \(50\)， 所需维数的比例基本稳在 \(55\% \sim 66\%\) 之间（理论值就是 \(0.553294\)）。 这说明：对称情形下，「需要多少比例的证据」与维数无关， 它只由 \(p\)、\(q\) 决定。

    但这里有一个反直觉的推论 ⚠： 比例稳定不等于容易达到。 \(d = 20\) 时要求 \(20\) 维里恰好有 \(12\) 维取 \(1\)； 若每一维取 \(1\) 的概率是 \(0.6\)（正好等于阈值比例）， 「恰好 \(12\) 维取 \(1\)」只是二项分布的一个尾巴。 维数越高，落在这个尾巴上的概率越小 —— 这正是维数灾难的另一副面孔。

    Q3 某融合系统有 \(5\) 个分类器，每个准确率都是 \(0.8\)。

    (a) 若它们完全独立，多数表决的准确率大概是多少？ (b) 若它们的错误完全相关（每次要么全对、要么全错），准确率是多少？ © 若它们完全独立但每个准确率只有 \(0.4\)，\(n = 5\) 时的准确率是多少？ (d) 从这三问能得出什么结论？

    提示

    (a) 用多数表决公式，\(n = 5\) 时多数票是 \(3, 4, 5\) 票。 (b) 完全相关时 \(n\) 不起作用，结果就是单个的准确率。 © 公式不变，只把 \(p\) 换成 \(0.4\)。 (d) 把三问的答案并排看。

    解答

    (a) 完全独立，\(p = 0.8\)，\(n = 5\)

    \[P = \sum_{k=3}^{5}\binom{5}{k}(0.8)^{k}(0.2)^{5-k}\]

    逐项算：

    \(k\) \(\binom{5}{k}\) \((0.8)^k\) \((0.2)^{5-k}\) 乘积
    \(3\) \(10\) \(0.512\) \(0.04\) \(0.204800\)
    \(4\) \(5\) \(0.4096\) \(0.2\) \(0.409600\)
    \(5\) \(1\) \(0.32768\) \(1\) \(0.327680\)
    合计 — — — \(0.942080\)

    整体准确率 \(0.942080\) ✓ —— 比单个的 \(0.8\) 高了 \(0.142\)。

    (b) 错误完全相关

    仍然是 \(0.8\) ⚠

    因为 \(5\) 个分类器永远给出同一个答案， 要么 \(5\) 个都对（概率 \(0.8\)），要么 \(5\) 个都错（概率 \(0.2\)）。 多数表决拿到的就是这唯一的答案，准确率一点没变。

    © 完全独立，\(p = 0.4\)，\(n = 5\)

    \[P = \sum_{k=3}^{5}\binom{5}{k}(0.4)^{k}(0.6)^{5-k}\]
    \(k\) \(\binom{5}{k}\) \((0.4)^k\) \((0.6)^{5-k}\) 乘积
    \(3\) \(10\) \(0.064\) \(0.36\) \(0.230400\)
    \(4\) \(5\) \(0.0256\) \(0.6\) \(0.076800\)
    \(5\) \(1\) \(0.01024\) \(1\) \(0.010240\)
    合计 — — — \(0.317440\)

    整体准确率 \(0.317440\) ⚠ —— 低于单个的 \(0.4\)！融合帮了倒忙。

    (d) 结论

    三问放在一起看：

    情形 单个准确率 融合后（\(n = 5\)） 融合的方向
    独立，\(p = 0.8\) \(0.8\) \(0.942080\) 变好 ✓
    完全相关，\(p = 0.8\) \(0.8\) \(0.8\) 没变 ⚠
    独立，\(p = 0.4\) \(0.4\) \(0.317440\) 变差 ✗

    三条结论：

    1. 融合不是自动有效的，它依赖「各部分相互独立」这个前提；
    2. 单个判决必须好于瞎猜（\(p \gt 0.5\)），否则融合会放大错误；
    3. 如果各部分高度相关，再多个数也等于一个， 这时该做的是改进单个分类器或增加真正独立的证据源， 而不是继续堆数量。

    三小问的手算过程与结果并排放在一张表里。

    (a) 完全独立、\(p = 0.8\)、\(n = 5\) 的手算在上面的表里已经逐步列出， 三项乘积是 \(0.204800 + 0.409600 + 0.327680 = 0.942080\) ✓

    © 完全独立、\(p = 0.4\)、\(n = 5\) 同样三步， 三项乘积是 \(0.230400 + 0.076800 + 0.010240 = 0.317440\) ✓

    情形 单个准确率 多数表决的手算结果 与单个相比 融合的方向
    独立，\(p = 0.8\) \(0.800000\) \(0.942080\) 高 \(0.142080\) 变好 ✓
    完全相关，\(p = 0.8\) \(0.800000\) \(0.800000\) 一点没变 不变 ⚠
    独立，\(p = 0.4\) \(0.400000\) \(0.317440\) 低 \(0.082560\) 变差 ✗

    第二行的道理：五个分类器永远给出同一个答案， 要么五个全对（概率 \(0.8\)），要么五个全错（概率 \(0.2\)）。 多数表决拿到的就是那唯一的答案，所以准确率等于单个的准确率， 与 \(n\) 取多少毫无关系。

    再核对一次「\(n\) 增大不会改变完全相关的情形」： 不管 \(n = 1\)、\(n = 5\) 还是 \(n = 101\)， 全体要么齐刷刷对、要么齐刷刷错，所以正确率恒为 \(0.8\) ✓ 数量在这个情形下完全没有意义 ⚠

    Q4 某两层融合系统，第一层有 \(K = 3\) 个分类器， 输出的是后验概率（软判决）。某个样本上三个分类器给出：

    \[v = (0.9,\ 0.7,\ 0.3)\]

    这里的 \(v_k\) 是第 \(k\) 个分类器给出的「属于 \(\omega_1\) 的后验概率」。 先验相等。

    (a) 用硬判决 + 多数表决判哪一类？ (b) 用软判决（对数几率相加）融合，结果是什么？ © 两种做法为什么不同？

    提示

    硬判决要先把概率过一遍 \(0.5\) 这条线变成票。 软判决要把每个 \(v_k\) 换成 \(\mathrm{logit}(v_k) = \ln\frac{v_k}{1-v_k}\)， 加起来再用 \(\sigma(z) = \frac{1}{1+e^{-z}}\) 换回概率。

    解答

    (a) 硬判决 + 多数表决

    先把三个概率过一遍 \(0.5\)：

    \(k\) \(v_k\) 是否 \(\gt 0.5\) 票投给
    \(1\) \(0.9\) 是 \(\omega_1\)
    \(2\) \(0.7\) 是 \(\omega_1\)
    \(3\) \(0.3\) 否 \(\omega_2\)

    票数：\(\omega_1\) 得 \(2\) 票，\(\omega_2\) 得 \(1\) 票。

    判 \(\omega_1\) ✓

    (b) 软判决（对数几率相加）

    逐个算对数几率：

    \[\mathrm{logit}(0.9) = \ln\frac{0.9}{0.1} = \ln 9 = 2.197225\]
    \[\mathrm{logit}(0.7) = \ln\frac{0.7}{0.3} = \ln 2.333333 = 0.847298\]
    \[\mathrm{logit}(0.3) = \ln\frac{0.3}{0.7} = \ln 0.428571 = -0.847298\]

    相加（先验相等，起点为 \(0\)）：

    \[z = 2.197225 + 0.847298 - 0.847298 = 2.197225\]

    注意中间两个数正好抵消（\(0.847298\) 与 \(-0.847298\)）—— 因为 \(\mathrm{logit}(0.7) = -\mathrm{logit}(0.3)\) （\(0.7\) 与 \(0.3\) 关于 \(0.5\) 对称）。

    换回概率：

    \[P(\omega_1\mid v) = \sigma(2.197225) = \frac{1}{1 + e^{-2.197225}}\]

    算 \(e^{-2.197225}\)：由 \(\ln 9 = 2.197225\) 得 \(e^{2.197225} = 9\)， 所以 \(e^{-2.197225} = 1/9 = 0.111111\)。

    \[P(\omega_1\mid v) = \frac{1}{1 + 0.111111} = \frac{1}{1.111111} = 0.9\]

    后验恰好是 \(0.9\) —— 也就是等于最有信心的那个分类器的判断， 因为另外两个正好互相抵消了 ✓

    判 \(\omega_1\)，与 (a) 一致。

    © 为什么两种做法不同（这次结果相同，但一般会不同）

    这一问的结果恰好相同，是有原因的： 这里三个概率正好满足「另外两个对数几率互为相反数」， 所以它们相抵之后只剩下第一个的贡献， 而第一个 \(v_1 = 0.9\) 本来就指向 \(\omega_1\)， 所以硬判决和软判决恰好都判 \(\omega_1\)。

    但两者给出判决的理由完全不同：

    做法 判 \(\omega_1\) 的理由 隐含的「证据强度」
    硬判决 票数是 \(2\) 比 \(1\) 每票等权，看不出 \(v_k\) 有多接近 \(0.5\)
    软判决 对数几率和为 \(2.197225 \gt 0\) 直接用了 \(v_k\) 的大小

    一般情形下两者会分歧，本页 §6.5 已经给过一个具体例子： \(v = (0.99, 0.48, 0.48)\) 时， 软判决判 \(\omega_1\)（后验约 \(0.9883\)）， 硬判决判 \(\omega_2\)（票数 \(1\) 比 \(2\)）—— 判决相反 ⚠

    差别的根源：

    差别 说明
    硬判决丢掉了「离 \(0.5\) 有多远」 \(0.51\) 和 \(0.99\) 都只是「一票」，完全等同
    硬判决隐含了一个「准确率假设」 要把一票折算成证据强度，必须假定一个数
    软判决直接使用概率本身 概率的大小就是证据强度，不需额外假设

    所以：只要第一层能给出概率， 就用软判决 —— 它信息更多、少一个假设、通常也更准 ✓

    把三小问的数值手算列出来。

    (a) 硬判决：把三个后验过一遍 \(0.5\) 这条线：

    \(k\) \(v_k\) 与 \(0.5\) 比较 这一票投给
    \(1\) \(0.90\) \(0.90 \gt 0.5\) \(\omega_1\)
    \(2\) \(0.70\) \(0.70 \gt 0.5\) \(\omega_1\)
    \(3\) \(0.30\) \(0.30 \lt 0.5\) \(\omega_2\)

    票数 \(\omega_1\) 得 \(2\) 票、\(\omega_2\) 得 \(1\) 票，判 \(\omega_1\) ✓

    (b) 软判决：三个对数几率相加（先验相等，起点为 \(0\)）：

    \[z = \mathrm{logit}(0.9) + \mathrm{logit}(0.7) + \mathrm{logit}(0.3)\]

    手算每一项：

    \[\mathrm{logit}(0.9) = \ln 9 = 2.197225\]
    \[\mathrm{logit}(0.7) = \ln 2.333333 = 0.847298\]
    \[\mathrm{logit}(0.3) = \ln 0.428571 = -0.847298\]

    注意后两个数正好互为相反数 —— 因为 \(0.7\) 与 \(0.3\) 关于 \(0.5\) 对称， 而 \(\mathrm{logit}(v) = -\mathrm{logit}(1 - v)\)。于是

    \[z = 2.197225 + 0.847298 - 0.847298 = 2.197225\]

    换回概率：由 \(\ln 9 = 2.197225\) 得 \(e^{2.197225} = 9\)， 所以 \(e^{-2.197225} = 1/9 = 0.111111\)，

    \[P(\omega_1\mid v) = \frac{1}{1 + 0.111111} = \frac{1}{1.111111} = 0.900000\]

    后验恰好等于最有信心的那个分类器的输出（\(0.9\)）， 因为另外两个正好互相抵消 ✓ 判决与 (a) 一致。

    © 一般情形下两者会分歧 —— 手算一组：

    输入 硬判决的手算 软判决的手算
    \(v = (0.9, 0.7, 0.3)\) 票数 \(2\) 比 \(1\)，判 \(\omega_1\) \(z = 2.197225 \gt 0\)，后验 \(0.9\)，判 \(\omega_1\)
    \(v = (0.99, 0.48, 0.48)\) 票数 \(1\) 比 \(2\)，判 \(\omega_2\) ⚠ \(z = 4.595120 - 0.160086 = 4.435034\)，后验 \(0.988284\)，判 \(\omega_1\)

    第二行的两个判决相反，而软判决是对的： 两个 \(0.48\) 的证据强度只有 \(\pm 0.08\)，几乎等于不表态， 把它们当成两张坚定的反对票显然曲解了原意 ✓

    小结¶

    要记住的 为什么
    离散特征用 \(P(\cdot)\)，连续特征用 \(p(\cdot)\) 密度不是概率，可以大于 \(1\)；概率必在 \([0,1]\) 内
    离散情形的判决规则与连续情形形状完全相同 把密度换成概率即可，不需要额外改公式
    唯一的区别是「要不要乘区间长度」 连续要乘 \(\Delta\) 才变成概率；离散概率本来就是概率 ✓
    \(\Delta\) 能在判决里约掉，因为各类相同 这是为什么连续情形的公式里从不出现 \(\Delta\)
    二值特征每维只需一个参数 「取 \(0\)」的概率由归一化自动确定为 \(1 - p_k\)
    不假设独立时要估 \(2^d - 1\) 个参数 维数每加 \(1\)，参数个数翻一倍 ⚠
    假设独立后每类只要 \(d\) 个参数 从指数级压回线性级，这是维数灾难的那一刀 ✓
    独立二值特征的判别函数是线性的 \(g(x) = \sum_k w_k x_k + w_0\)，决策面是超平面
    \(w_k = \ln\frac{p_k(1-q_k)}{q_k(1-p_k)}\) 衡量第 \(k\) 维的判别能力 \(p_k = q_k\) 时 \(w_k = 0\)，该维自动弃权
    \(w_0\) 里含先验比，\(w_k\) 里不含先验 想调查先验影响，只需改一个数
    判别函数要用对数形式 直接连乘在高维下会下溢成 0，判决彻底失效 ⚠
    对数形式里每一维的贡献可以单独看 可解释性强，缺失数据只需跳过对应项
    独立性假设不成立会被成倍放大 同一份信息数两遍 → 后验过分极端 → 错误率上涨 ⚠
    复合模式 = 多个子模式组合成整体再识别 强调「部件 \(+\) 部件之间的关系」
    两层结构：第一层局部判决，第二层综合判决 第二层把判决结果当离散特征，再套一次贝叶斯
    这是「判决的融合」，不是「数据的融合」 数据在第一层就被消化掉了 ⚠
    第二层的判决规则与第一部分形式相同 独立性假设：给定总体类别后各部分判决相互独立
    「同一模式的多分类器融合」与「复合模式」含义不同 前者是同一目标判多次，后者是不同子模式
    融合只在「独立且单个都不太差」时才有收益 \(p \lt 0.5\) 时融合反而更差 ⚠
    完全相关时，数量再多也等于一个 没有独立的信息增量，改善为零 ⚠
    软判决（概率）优于硬判决（标号） 硬判决丢掉了「离 \(0.5\) 有多远」的信息
    把硬判决折算成证据强度必须额外假定准确率 这个假定无法从数据里得到，是硬判决的固有缺陷
