    贝叶斯网络与概率图模型¶

    前面几页处理的问题，变量个数都不多：一个特征向量 \(x\) 有几维， 就当成几个随机变量。可一旦要建模很多个变量之间的互相影响 （比如一张诊断记录里几十个症状、指标、病史）， 直接列出联合分布立刻就行不通了。

    这一页讲的是怎么把「变量太多」这件事压回去： 用一张图写明「谁直接依赖谁」，让联合分布从 一张填不满的大表变成几个小表的乘积。

    这一页要建立的两个直觉

    ① 图不是画着好看的，它是参数的压缩协议 有向无环图上的每条边都对应一个"谁出现在谁的条件里"的约定。 边少一条，参数就少一批；边全连满，图就退化回那张填不满的大表。

    ② 图上最难的不是算法，是方向 "观测了一个变量之后，另外两个变量是变独立还是变相关"—— 这个问题不能靠直觉，尤其遇到对撞结构时会完全反直觉 ⚠

    一、为什么需要图模型：联合分布撑不住¶

    1.1 参数个数的指数爆炸¶

    设模型里有 \(d\) 个二值随机变量 \(X_1, \dots, X_d\)。 要在没有任何结构假设的前提下写清楚它们的联合分布 \(P(X_1 = x_1, \dots, X_d = x_d)\)，就必须给出 \(2^d\) 个格子上的取值。

    但这 \(2^d\) 个数不是自由的：所有格子求和等于 \(1\)， 所以只要知道其中 \(2^d - 1\) 个，最后一个就被确定了。 于是自由参数个数是

    \[ 2^{d} - 1 \]

    这个数字增长得有多快，看下面这张表就够了。

    变量个数 \(d\) 联合表自由参数个数 一位一位写下来 量级
    3 7 7 个位
    5 31 31 十位
    10 1023 1,023 千
    20 1048575 1,048,575 百万
    30 1073741823 1,073,741,823 十亿 ⚠
    50 约 \(1.13 \times 10^{15}\) 1.13 千万亿 远超存储 ⚠

    最后一列值得盯一会儿：\(d = 50\) 时参数已经到千万亿量级。 而一个稍像样的模式识别问题，变量个数轻松超过 \(50\)。 这不是算力不够的问题，是「参数本身就是天文数字」的问题 ⚠

    更要命的还不是存储，而是估计。 假设每个格子都要从数据里估出来。 要让 \(10^{15}\) 个格子每格平均有 \(10\) 个样本， 需要 \(10^{16}\) 条训练样本 —— 这个数量级上， 永远不可能有足够的数据填满这张表 ⚠

    1.2 出路：条件独立性¶

    指数爆炸的根源在于"所有变量两两之间都可能直接相关"这个最坏假设。 真实问题里这个假设几乎从不成立：

    • 一张语音帧的相邻采样点强相关，与十帧之外的采样点基本无关；
    • 一篇文档里的某个词，与同一个主题下的其他词相关， 与另一个主题下的词关系很弱；
    • 一个症状通常由有限的几个病因直接影响，而不是所有病因。

    把这些"直接相关的边"画成一张有向图， 就得到了贝叶斯网络（也叫信念网络）：

    每个节点是一个随机变量，每条有向边 \(X \to Y\) 表示 「\(Y\) 的概率直接取决于 \(X\)」。 图必须无环（不能 \(X \to Y \to Z \to X\) 绕回来）， 否则概率的定义会自相矛盾。

    边的多少决定参数的多少。仍用二值变量， 若每个节点最多有 \(k\) 个父节点，则每个节点只需 \(2^k\) 个条件概率值，全网络自由参数个数约为

    \[ d \cdot 2^{k} \]

    对比一下：\(d = 30\)、每个节点最多 \(2\) 个父节点时， 上面这张表的行是 \(\approx 30 \times 4 = 120\) 个参数， 而自由联合表要 \(1073741823\) 个。 差了大约七百万倍。这就是「把参数大幅压下来」的确切含义 ✓

    读这张图的一个要点：图中 \(X_1\) 与 \(X_2\) 都指向 \(X_3\)， \(X_3\) 又分别指向 \(X_4\) 与 \(X_5\)。 图上没有\(X_1 \to X_4\) 这样的边， 所以 \(X_1\) 对 \(X_4\) 的影响只能"经由 \(X_3\) 传递"—— 这个"经由"就是下一节要讲的链条结构。

    1.3 一张表看懂"结构换参数"¶

    结构 边的说法 自由参数个数（\(d\) 个二值变量） 适用场景
    全连接（无假设） 任意两变量都可能直接相关 \(2^d - 1\) 变量极少，或数据极多
    树（每个节点一个父节点） 每条边是一个"直接依赖" \(1 + 2(d-1)\) 层级分明的因果链
    朴素贝叶斯（一个共同父） 只有一个父节点：类别 \(1 + 2d\) 特征近似独立
    一般网络（每个节点 \(\le k\) 个父） 依赖关系是稀疏的 约 \(d \cdot 2^k\) 稀疏因果结构

    观察最后两行：树结构和朴素贝叶斯的参数个数都只是 关于 \(d\) 的线性函数，而全连接是指数函数。 一旦用上结构假设，\(d\) 从 \(10\) 增到 \(100\) 只让参数增加约十倍； 不假设结构则增加约 \(2^{90}\) 倍 —— 后者根本不是一个可以讨论的量级 ⚠

    二、联合分布的分解式¶

    2.1 通式¶

    设网络有 \(d\) 个节点 \(X_1, \dots, X_d\)， 用 \(\mathrm{Pa}(X_i)\) 表示图中 \(X_i\) 的父节点集合。 则联合分布恰好可以写成

    \[ P(X_1, X_2, \dots, X_d) = \prod_{i=1}^{d} P\bigl(X_i \mid \mathrm{Pa}(X_i)\bigr) \]

    这就是贝叶斯网络的分解式（factorization）。 它不是一个近似，而是「图 + 每个节点的条件概率表」这套表示 与某一族联合分布之间的一个精确对应 ✓

    2.2 每个因子的含义¶

    逐项拆开看，上式的每一个因子都对应图上的一件事：

    因子 在图上是什么 参数从哪里来 怎么读
    \(P(X_i \mid \mathrm{Pa}(X_i))\) 节点 \(X_i\) 与它所有入边 由 \(X_i\) 的一张小表给出 父节点给定后，\(X_i\) 还剩多少不确定性
    \(\mathrm{Pa}(X_i) = \varnothing\) 没有入边的根节点 只需一个先验 它的取值不受任何其他节点影响
    因子连乘 顺着图的拓扑顺序写一遍 每个节点贡献一张表 整张联合表是这些小表的乘积

    关键理解：分解式之所以成立，靠的是每个节点只依赖它的父节点， 而与它的非后代节点无关。这正是下面"条件独立性"一节要严格化的内容。

    2.3 分解式为什么能成立：从链式法则出发推¶

    不假设任何东西时，联合分布可以用乘法链式法则一步步拆开：

    \[ P(X_1, \dots, X_d) = P(X_1)\,P(X_2 \mid X_1)\,P(X_3 \mid X_1, X_2) \cdots P(X_d \mid X_1, \dots, X_{d-1}) \]
    \[ P(X_1, \dots, X_d) = \prod_{i=1}^{d} P\bigl(X_i \mid X_1, \dots, X_{i-1}\bigr) \]

    这一步永远正确，不需要任何假设。 但它的条件太长了：第 \(i\) 个因子要依赖前面 \(i-1\) 个变量， 参数个数依然是 \(2^d\) 量级，一点没省 ⚠

    贝叶斯网络的分解式，就是把每个因子的条件集合从 \(\{X_1, \dots, X_{i-1}\}\) 缩小到 \(\mathrm{Pa}(X_i)\)：

    \[ P\bigl(X_i \mid X_1, \dots, X_{i-1}\bigr) = P\bigl(X_i \mid \mathrm{Pa}(X_i)\bigr) \]

    这一步为什么可以缩减，标准做法是先按图的拓扑序给节点编号 （父节点编号一定小于子节点编号），此时会有

    \[ \mathrm{Pa}(X_i) \subseteq \{X_1, \dots, X_{i-1}\} \]

    于是要证的缩减就变成「条件里多出来的那些变量可以删掉」。 多出来的是哪些：编号在 \(X_i\) 之前、但不是 \(X_i\) 父节点的那些节点。 按图的结构，它们之所以编号在前，是因为它们是某个祖先或旁支， 并不直接决定 \(X_i\) 的取值，所以给定父节点后它们不再提供信息 ✓

    更形式化的说法：图上的每个节点 \(X_i\) ， 在给定父节点后，与它的所有非后代节点条件独立。 把这句话用在链式法则的每个因子上，就得到分解式。 它的严格证明依赖 d-分离，下一节会把这个概念讲透。

import numpy as np

rng = np.random.default_rng(42)

# 链式网络 X1 → X2 → X3 → X4 的条件概率表
theta1 = 0.30
theta = {2: (0.10, 0.80), 3: (0.20, 0.65), 4: (0.05, 0.55)}
cells = list(itertools.product([0, 1], repeat=4))


def cpt(i, x):
    """节点 Xi 取 x[i-1] 的概率，条件是父节点取 x[i-2]。"""
    if i == 1:
        return theta1 if x[0] == 1 else 1.0 - theta1
    q = theta[i][x[i - 2]]
    return q if x[i - 1] == 1 else 1.0 - q


# 路线 A：按分解式 P(X1) P(X2|X1) P(X3|X2) P(X4|X3) 逐格相乘
joint = {x: cpt(1, x) * cpt(2, x) * cpt(3, x) * cpt(4, x) for x in cells}


def mass(fixed):
    """对满足 fixed 的所有格子求和，fixed 形如 {下标: 取值}。"""
    return sum(v for x, v in joint.items()
               if all(x[i] == val for i, val in fixed.items()))


def cond(target, given):
    """P(target | given)，两者都是 {下标: 取值}。"""
    both = dict(given)
    both.update(target)
    return mass(both) / mass(given)

    """路线 B：从联合表出发，按 P(X1)P(X2|X1)P(X3|X1,X2)P(X4|X1,X2,X3) 算。"""

    三、条件独立性与 d-分离¶

    3.1 条件独立的定义与直觉¶

    两个随机变量 \(X\) 与 \(Y\) 在给定 \(Z\) 时条件独立，记作 \(X \perp Y \mid Z\)，定义是

    \[ P(X, Y \mid Z) = P(X \mid Z)\,P(Y \mid Z) \]

    等价形式（当 \(P(Y, Z) \gt 0\) 时）是

    \[ P(X \mid Y, Z) = P(X \mid Z) \]

    第二种形式更好用：它说的是 「知道了 \(Z\) 之后，\(Y\) 这个信息对 \(X\) 不再有额外贡献」。 这正是"条件独立"这个名字的来历 —— 不是"\(X\) 与 \(Y\) 无关"， 而是"在 \(Z\) 的条件下它们无关" ⚠

    特别提醒：\(X \perp Y\)（边缘独立）与 \(X \perp Y \mid Z\)（条件独立）互不推出。 这一页里最反直觉的内容全都在这个缝隙里 ⚠

    3.2 三种基本结构¶

    任意一条路径都可以拆成这三种基本连接。 判据的关键是：路径上的中间节点是否被观测。

    其一，链式 \(X \to Z \to Y\)： "原因 → 中介 → 结果"。 未观测 \(Z\) 时，\(X\) 的变化会通过 \(Z\) 影响 \(Y\)， 所以两端相关；一旦观测了 \(Z\)， \(Z\) 的取值已被固定，\(X\) 就再也无法通过 \(Z\) 影响 \(Y\)， 于是两端转为独立 ✓

    其二，共同父（共同原因） \(Z \to X\)、\(Z \to Y\)： 一个共同的原因同时影响两个结果。 未观测 \(Z\) 时，看到 \(X\) 的值会更新对 \(Z\) 的判断， 进而改变对 \(Y\) 的判断，所以两端相关； 观测 \(Z\) 后这条路被截断，两端转为独立 ✓

    其三，共同子（对撞结构） \(X \to Z \leftarrow Y\)： 两条边箭头相向，在 \(Z\) 处"对撞"。 未观测 \(Z\) 时，\(X\) 与 \(Y\) 各自独立地影响 \(Z\)， 彼此之间没有任何通路，所以两端本来独立； 而观测 \(Z\) 之后，\(Z\) 的取值同时约束了 \(X\) 与 \(Y\) —— 两端反而变得相关 ⚠⚠

    第三种结构是全部反直觉的来源。举一个具体例子来固定它： 设 \(Z\) 表示"地面湿"，\(X\) 表示"下雨"，\(Y\) 表示"洒水车作业"。 不下雨的日子与洒水车是否作业本来互相无关（\(X \perp Y\)）。 但只要我们知道地面湿了（\(Z\) 被观测）， "没下雨"就会推高"洒水车作业过"的可能性， 而"下过雨"会压低它 —— 两个原本无关的事件，因为观察了共同结果而相关 ✓

    反过来还有更绕的一层：若 \(Z\) 有后代 \(W\)， 那么观测 \(W\) 也会打开 \(X \to Z \leftarrow Y\) 这条路。 因为 \(W\) 携带了关于 \(Z\) 的信息， 观测 \(W\) 就等于部分观测了 \(Z\)。 这一点在建模时最容易漏 ⚠

    3.3 d-分离¶

    把上面的判据推广到整张图，就得到 d-分离（d-separation， "d"指方向 directional）。给定一个证据集合 \(E\)（已观测的节点集）， 判断 \(X\) 与 \(Y\) 是否在 \(E\) 下条件独立，方法是看每一条路径：

    如果每一条从 \(X\) 到 \(Y\) 的路径都被 \(E\) 阻断， 则 \(X\) 与 \(Y\) 被 \(E\) d-分离，记作 \(X \perp_d Y \mid E\)。 一条路径被阻断，意味着这条路径上至少有一个节点满足下列条件之一：

    • 它是链式结构 \(A \to Z \to B\) 的中间节点，且 \(Z \in E\)；
    • 它是共同父结构 \(Z \to A\)、\(Z \to B\) 的中间节点，且 \(Z \in E\)；
    • 它是对撞结构 \(A \to Z \leftarrow B\) 的对撞节点， 且 \(Z \notin E\)、它的任何后代也不在 \(E\) 中。

    注意第三条的「不」：对撞节点没被观测才阻断路径。 一旦它（或它的后代）被观测，路径就被打开而不是阻断 ⚠

    d-分离与条件独立的关系是一件事的两面：

    • soundness（可靠性）：若 \(X \perp_d Y \mid E\)， 则在这些图的每一个分布里都有 \(X \perp Y \mid E\)；
    • completeness（完备性）：若 \(X\) 与 \(Y\) 不被 \(E\) d-分离， 则存在至少一个与图相符的分布，使 \(X\) 与 \(Y\) 不条件独立。

    这两条合起来说明 d-分离是"信息最多"的判据： 它给出的是图能保证的全部条件独立性，不多不少 ✓

    看图时把三列对照着看：左、中两列的结论都是「观测后独立」， 只有右面的共同子结构是「观测后相关」。 配色不同不是装饰，是为了让"方向"这件事在视觉上先分离开。

def dev(joint):
    """返回 (两端边缘相关偏差, 给定 Z 后两端条件相关偏差)。"""
    tot = sum(joint.values())
    p = {k: v / tot for k, v in joint.items()}
    pX1 = sum(v for k, v in p.items() if k[0] == 1)
    pY1 = sum(v for k, v in p.items() if k[2] == 1)
    p11 = sum(v for k, v in p.items() if k[0] == 1 and k[2] == 1)
    marg = abs(p11 - pX1 * pY1)
    cond = 0.0
    for z in (0, 1):
        pz = sum(v for k, v in p.items() if k[1] == z)
        for x in (0, 1):
            for y in (0, 1):
                pxy = p[(x, z, y)] / pz
                px = sum(v for k, v in p.items()
                         if k[0] == x and k[1] == z) / pz
                py = sum(v for k, v in p.items()
                         if k[1] == z and k[2] == y) / pz
                cond = max(cond, abs(pxy - px * py))
    return marg, cond

    四、变量消元：把求和顺序安排好¶

    4.1 推断要算什么¶

    有了图与条件概率表，下一步是推断： 在已知一部分变量取值的前提下，回答关于另一部分变量的概率问题。 最常见的形式是求边缘概率：

    \[ P(Q) = \sum_{H} P(Q, H) \]

    其中 \(Q\) 是查询变量（要算的），\(H\) 是其余全部变量（要被求和消掉的）。 这个求和是对 \(H\) 中所有变量的所有取值组合做的， 所以直接照写就是组合爆炸：

    \[ P(Q) = \sum_{h_1} \sum_{h_2} \cdots \sum_{h_m} P(Q, h_1, \dots, h_m) \]

    复杂度是 \(H\) 中变量取值组合的个数，也就是指数级 ⚠

    4.2 关键洞察：把求和移进连乘里¶

    变量消元的全部思想只有一句话： 利用分解式，把"先展开、后求和"改成"边乘边求和"。

    把分解式代入上式。以一条链 \(X_1 \to X_2 \to X_3 \to X_4\) 为例， 联合分布是

    \[ P(x_1, x_2, x_3, x_4) = P(x_1)\,P(x_2 \mid x_1)\,P(x_3 \mid x_2)\,P(x_4 \mid x_3) \]

    假设我们要算 \(P(x_1)\)，需要把 \(x_2, x_3, x_4\) 全部求和掉：

    \[ P(x_1) = \sum_{x_2} \sum_{x_3} \sum_{x_4} P(x_1)\,P(x_2 \mid x_1)\,P(x_3 \mid x_2)\,P(x_4 \mid x_3) \]

    先看最里面那层对 \(x_4\) 的求和：\(x_4\) 只出现在 \(P(x_4 \mid x_3)\) 这一个因子里，与其他因子无关， 所以它可以单独求和：

    \[ \sum_{x_4} P(x_4 \mid x_3) = 1 \]

    这一项直接变成了常数 \(1\)，整个因子消失了 ✓ 原来的四重求和瞬间少了一层：

    \[ P(x_1) = \sum_{x_2} \sum_{x_3} P(x_1)\,P(x_2 \mid x_1)\,P(x_3 \mid x_2) \]

    同样的道理，\(x_3\) 只出现在 \(P(x_3 \mid x_2)\) 里， 先把它求和：

    \[ \sum_{x_3} P(x_3 \mid x_2) = 1 \]

    于是

    \[ P(x_1) = \sum_{x_2} P(x_1)\,P(x_2 \mid x_1) = P(x_1) \sum_{x_2} P(x_2 \mid x_1) = P(x_1) \]

    链式结构上，消元几乎什么都没算就得到了答案 ✓ 这并非巧合：链上的因子恰好都能单独归一化。

    4.3 中间因子从哪来：合并的代价¶

    上一节之所以顺利，是因为每个待消变量只出现在一个因子里， 可以单独求和、直接归一化成 \(1\)。 一旦一个待消变量同时出现在多个因子里， 就必须先把这些因子乘起来，乘出来的东西就是中间因子。

    规则：要消掉变量 \(Z\)，先把所有含 \(Z\) 的因子收集起来， 把它们的作用域取并集再相乘。设这个并集里有 \(s\) 个变量， 则中间因子含 \(2^s\) 个数值 —— 这个数就是它的"大小"， 也是这一步真正的内存开销 ✓

    从链条上看这条规则最清楚。 取 \(X_1 \to X_2 \to X_3 \to X_4\)，四个初始因子与它们的作用域是：

    初始因子 作用域 含多少个数值
    \(P(x_1)\) \(\{X_1\}\) \(2^1 = 2\)
    \(P(x_2 \mid x_1)\) \(\{X_1, X_2\}\) \(2^2 = 4\)
    \(P(x_3 \mid x_2)\) \(\{X_2, X_3\}\) \(2^2 = 4\)
    \(P(x_4 \mid x_3)\) \(\{X_3, X_4\}\) \(2^2 = 4\)

    起始的因子最大只有 \(4\) 个数值。 要算 \(P(x_1)\) 就得消掉 \(X_2, X_3, X_4\)， 而换个顺序就能让它膨胀：

    顺序 消元过程 最大中间因子
    好：\(X_4, X_3, X_2\) 每次合并的两个因子作用域都是 \(\{X_i, X_{i+1}\}\)，并集仍是 \(2\) 个变量 \(2^2 = 4\)
    坏：\(X_2, X_4, X_3\) 消 \(X_2\) 时，\(\{X_1, X_2\}\) 与 \(\{X_2, X_3\}\) 并集成 \(\{X_1, X_2, X_3\}\) \(2^3 = 8\)

    坏在哪里：\(X_2\) 处在链条中间， 它左边和右边的两张表都要并进同一个因子， 于是作用域一下子从 \(2\) 个变量涨到 \(3\) 个变量 ⚠ 而先消 \(X_4\)（链条末端）时，它只出现在一张表里， 合并后作用域反而缩到 \(1\) 个变量。

    把这个规则推广到一般图，就得到挑选顺序的直觉： 优先消掉"当前只出现在一个因子里"的变量（也就是叶子节点）， 并尽量让合并后的作用域最小 ✓

    代价的上界由什么决定：反复合并会把作用域越滚越大， 最坏情况下中间因子的规模可以达到整张联合表的大小 \(2^d\)。 图越稠密、树宽越大，这个上界越接近现实 —— 这正是下一节"推断为什么难"的根源 ⚠

    4.4 变量消元的完整步骤¶

    把上面的经验整理成可以照着做的流程：

    1. 确定查询与证据。把证据变量固定到它们的观测值上 （等价于把相关因子当成已知）；
    2. 挑一个消元顺序，得到变量列表 \(\pi\)；
    3. 对 \(\pi\) 中每个变量 \(Z\) 依次执行：
      • 把所有含 \(Z\) 的因子收集起来；
      • 把它们相乘，得到一个含 \(Z\) 的新因子；
      • 对 \(Z\) 求和，把它从新因子的作用域里去掉；
      • 把新因子放回因子集合；
    4. 所有序列变量消完后，把剩下的因子相乘，得到查询变量的分布；
    5. 归一化（除以总和），使概率之和为 \(1\)。

    注意第 5 步不能省。消元过程中我们一直在省略归一化常数， 最后算出的往往是一个未归一化的得分， 必须除掉总和才是概率 ✓

         ("X3", "X4"): (0.90, 0.20), ("X4", "X5"): (0.70, 0.15)}


def child_table(pa, ch):
    """返回 t[a, c] = P(ch = c | pa = a)。"""
    t = np.zeros((2, 2))
    for a in (0, 1):
        for c in (0, 1):
            t[a, c] = (table[(pa, ch)][a] if c == 1
                       else 1.0 - table[(pa, ch)][a])
    return t


def mul(A, sa, B, sb):
    """两个因子相乘，结果的作用域是两个作用域的并集。"""
    su = list(sa) + [v for v in sb if v not in sa]
    out = np.zeros((2,) * len(su))
    for idx in np.ndindex(out.shape):
        d = dict(zip(su, idx))
        out[idx] = A[tuple(d[v] for v in sa)] * B[tuple(d[v] for v in sb)]
    return out, tuple(su)


def eliminate(facs, order):
    """按 order 消元，返回 (最后的因子, 过程中最大的因子含多少个数值)。"""
    facs, biggest = list(facs), max(int(f.size) for f, _ in facs)
    for v in order:
        part = [(f, s) for f, s in facs if v in s]
        facs = [(f, s) for f, s in facs if v not in s]
        cur, su = part[0]
        for f, s in part[1:]:
            cur, su = mul(cur, su, f, s)
        biggest = max(biggest, int(cur.size))
        cur = cur.sum(axis=su.index(v))
        facs.append((cur, tuple(x for x in su if x != v)))
    cur, su = facs[0]
    for f, s in facs[1:]:
        cur, su = mul(cur, su, f, s)
    return cur, biggest


def brute_force():
    """不做消元：先把 2 的 5 次方个格子的联合概率全展开再求和。"""
    first = np.array([1.0 - p1, p1])
    joint = np.zeros((2,) * 5)
    for idx in np.ndindex(joint.shape):
        v = first[idx[0]]
        for k in range(1, 5):
            q = table[(VARS[k - 1], VARS[k])][idx[k - 1]]
            v *= q if idx[k] == 1 else 1.0 - q
        joint[idx] = v
    return joint.sum(axis=tuple(range(1, 5))), int(joint.size)

    • 改成近似：接受一定误差，换取多项式时间 —— 见下一节。

    五、推断的复杂度：为什么没有"万能高效算法"¶

    5.1 精确推断是难的¶

    变量消元的代价由最大中间因子的大小决定。 而"能否找到一组合适的消元顺序，让所有中间因子都不超过某个规模"这个问题， 本身就是一个组合优化问题。

    结论是明确的：在一般的有向无环图（或无向图）上做精确推断， 是 NP 难问题。更细一层，即使在近似意义下， 对某些推断任务也可能难以达到任意精度。

    这条结论的正确读法（容易被误读成"贝叶斯网络没用"）：

    • 它说的是最坏情况。存在一整类图，其上精确推断不可能在多项式时间内完成；
    • 许多实际结构是"简单"的：树、森林、单连通图上的推断 可以线性时间完成，而这类结构在工程中出现得非常频繁；
    • 难点集中在稠密连接、环多、父节点多的区域 ⚠

    图论上刻画"难度"的量主要有两个： 树宽（treewidth）与分支数（即最大入度）。 树宽小意味着存在一条"通道状"的分解，把小规模消息依次传过去。 树宽是决定精确推断难易的核心指标 ✓

    5.2 不同结构的代价对照¶

    图的结构 精确推断的复杂度 原因
    链、树、森林（树宽为 1） 与变量个数成线性 消息只沿一条路径传递，无环
    多棵树的松耦合 仍然是多项式（与树宽成指数） 中间因子规模由树宽控制
    一般有向无环图 NP 难 ⚠ 消元顺序的组合搜索本身就是难的
    允许近似 通常可达多项式时间，但精度无保证 用采样或变分把难点绕开

    注意第二行那句"与树宽成指数"：它精确地说明了难点在哪 —— 代价是关于树宽指数级、关于变量个数多项式级。 所以"图很大"不等于"难"，图很稠密才是难 ✓

    5.3 近似方向¶

    工程上处理难推断主要有两条路：

    • 采样法（蒙特卡洛）：从分布里抽样本，用样本频率估计概率。 思路直白、适用范围广，代价是需要的样本量可能很大； 马尔可夫链蒙特卡洛是其中最主流的一支；
    • 变分法：不用样本，而是在一个易于处理的分布族里 找一个与真实后验最接近的分布，把推断转成优化问题。 收敛快、通常能给出确定性结果，代价是精度有系统偏差 ⚠

    两者是互补的：采样法渐近精确但慢，变分法快但有偏。 这一页的前置内容已讲过其中一种变分思路 （用下界函数把难算的对数配分函数夹住）， 其思想可以直接搬到图模型上 ✓

    别把「NP 难」当成「不能用」

    NP 难是最坏情况的结论。实际项目里更常见的情形是：

    • 图是稀疏的、树宽很小 → 精确推断很快；
    • 图确实稠密 → 但只需要局部的答案 （比如只关心某个变量在给定几个证据后的分布）， 此时可以在子图上做精确推断，效果往往够用；

    真正该避免的做法是：不看结构， 直接对全部变量做暴力求和或全枚举 —— 这在 \(20\) 个二值变量上就已经是百万级，\(40\) 个就完全不可行 ⚠

    六、朴素贝叶斯：共同父结构的特例¶

    6.1 它的图长什么样¶

    把上一页的分类器放到图上看，朴素贝叶斯的图特别简单： 只有一个根节点（类别标签 \(C\)）， 每个特征 \(X_1, \dots, X_d\) 都是它的子节点，且特征之间没有边。

    \[ C \to X_1,\quad C \to X_2,\quad \dots,\quad C \to X_d \]

    这就是共同父结构的直接应用：\(C\) 是唯一的共同父节点， 所有特征共享同一个父节点，而它们之间互不相连。

    按分解式写出它的联合分布，立即得到熟悉的公式：

    \[ P(C, X_1, \dots, X_d) = P(C) \prod_{j=1}^{d} P(X_j \mid C) \]

    6.2 这解释了它的假设¶

    把上式两边除以 \(P(X_1, \dots, X_d)\)，得到后验：

    \[ P(C \mid X_1, \dots, X_d) \propto P(C) \prod_{j=1}^{d} P(X_j \mid C) \]

    右边这一串乘积就是"朴素贝叶斯假设特征条件独立"的确切含义 —— 它并不是天真地认为"特征在现实中互不相关"， 而是认为"在给定类别之后，特征之间不再有直接的信息通道" ✓

    这是一条弱得多的假设，也是它常常还管用的原因： 同一个类别的样本里，特征之间的相关性往往可以"归因"到类别上。

    6.3 这个假设什么时候会坏¶

    结构假设的代价也在这里：只要图上缺的那条边在现实中确实存在， 置信度就会算错。典型失效场景：

    失效场景 图上缺了什么边 后果
    两个特征几乎是同一个信息 \(X_1 \to X_2\) 同一份证据被重复计入两次，后验过度自信 ⚠
    特征之间存在传递依赖 \(X_1 \to X_2 \to X_3\) 相关性被当成独立证据，概率被拉到 0 或 1
    特征依赖某个未建模的隐变量 隐变量 \(\to\) 各特征 该隐变量造成的相关全部被忽略
    特征在类别内强相关 \(X_1 \to X_2\)（类别内） 概率估计偏离，阈值附近的样本被误判

    第一行最值得记住：若两个特征在给定类别后仍高度相关， 朴素贝叶斯会把同一个证据数两遍， 于是后验概率被推向 \(0\) 或 \(1\) —— 输出看起来"很有把握"，实际上这份把握是虚的 ⚠

    补救思路有三条常见路线： 去掉冗余特征（让图上确实没有那条边）、 加边（显式建模特征之间的依赖，代价是参数变多）、 引入隐变量（把未观测的共同原因建出来）。

classes = ["晴", "雨"]
train = [("晴", 0, 0, 1), ("晴", 0, 0, 1), ("晴", 0, 1, 0), ("晴", 0, 0, 1),
         ("晴", 1, 0, 1), ("晴", 0, 1, 0), ("晴", 0, 0, 1), ("晴", 0, 0, 1),

def fit(alpha):
    """先验与条件概率都用「极大似然 + 拉普拉斯平滑」估计。"""
    pri, like = {}, {}
    for c in classes:
        rows = [r for r in train if r[0] == c]
        pri[c] = (len(rows) + alpha) / (len(train) + 2 * alpha)
        like[c] = [(sum(r[1 + j] for r in rows) + alpha)
                   / (len(rows) + 2 * alpha) for j in range(3)]
    return pri, like


def predict(pri, like, x):
    """返回 (打分最高的类别, 两类的联合打分)。"""
    score = {}
    for c in classes:
        s = pri[c]
        for j in range(3):
            s *= like[c][j] if x[j] == 1 else 1.0 - like[c][j]
        score[c] = s
    return max(score, key=score.get), score

    七、参数学习与平滑¶

    7.1 要学什么¶

    网络结构给定后，剩下的工作是估条件概率表： 对每个节点 \(X_i\) 与它的父节点的每一种取值组合 \(\mathrm{pa}\)， 估出 \(P(X_i \mid \mathrm{Pa}(X_i) = \mathrm{pa})\)。

    极大似然估计非常直接：数频数、除总数。

    \[ \hat{P}(X_i = a \mid \mathrm{Pa}(X_i) = \mathrm{pa}) = \frac{N(X_i = a,\ \mathrm{Pa}(X_i) = \mathrm{pa})} {N(\mathrm{Pa}(X_i) = \mathrm{pa})} \]

    其中 \(N(\cdot)\) 表示该组合在训练数据里出现的次数。 这个估计式没有任何需要优化的东西 —— 只需一次遍历数据、若干个计数器 ✓

    7.2 为什么必须平滑¶

    上面这个频率式有一个致命弱点：分子可能为零。 只要某个组合在训练数据里一次都没出现，估计出的概率就是 \(0\)。

    而零一旦进了连乘，后果是毁灭性的：

    \[ P(\text{某个样本}) = P(C) \prod_{j=1}^{d} P(X_j \mid C) \]

    只要其中某个 \(P(X_j = a \mid C) = 0\)， 整个样本的联合概率就是 \(0\) —— 不管其余 \(d-1\) 个因子多么正常 ⚠ 在分类任务里，这直接意味着"这个类别被排除"， 而且排除的理由仅仅是"没见过"，不是"不可能" ⚠

    更麻烦的是它发生在哪：\(d\) 越大，需要估计的特征组合数增长越快， "某个组合没出现过"的概率越高。 上面那段代码里，\(d = 3\)、只有 \(16\) 条样本就踩到了这个坑； 真实场景下 \(d\) 动辄上百，零概率几乎必然出现 ⚠

    7.3 拉普拉斯平滑¶

    修法叫拉普拉斯平滑（也叫加一平滑）， 做法极其简单：分子加 \(\alpha\)、分母加 \(\alpha\) 乘以取值的种数。

    \[ \hat{P}(X_i = a \mid \mathrm{Pa} = \mathrm{pa}) = \frac{N(X_i = a,\ \mathrm{Pa} = \mathrm{pa}) + \alpha} {N(\mathrm{Pa} = \mathrm{pa}) + \alpha \cdot K} \]

    其中 \(K\) 是 \(X_i\) 的取值个数（二值变量时 \(K = 2\)）， \(\alpha \gt 0\) 是平滑强度，\(\alpha = 1\) 就是"加一"。

    分母为什么要加 \(\alpha K\)：因为分子一共加了 \(\alpha \cdot K\) （每种取值各加 \(\alpha\)），要让这一行所有取值的概率之和仍然等于 \(1\)， 分母必须加上相同的量 ✓ 这是最容易抄错的地方 ⚠

    估计方式 公式 零概率 偏差
    极大似然 \(N(a, \mathrm{pa}) / N(\mathrm{pa})\) 可能为 0 ⚠ 无
    拉普拉斯（\(\alpha=1\)） \((N(a, \mathrm{pa}) + 1) / (N(\mathrm{pa}) + K)\) 恒为正 ✓ 小样本时明显
    一般平滑（\(0 \lt \alpha \lt 1\)） \((N(a, \mathrm{pa}) + \alpha) / (N(\mathrm{pa}) + \alpha K)\) 恒为正 ✓ 随 \(\alpha\) 增大而增大

    怎么理解它：拉普拉斯平滑等价于 在每个格子事先放一个"虚拟样本"， 相当于在数据之前注入一个均匀的先验。 所以它也被看作"从纯频率走向贝叶斯估计"的一小步 ✓

    7.4 平滑的度：\(\alpha\) 怎么选¶

    \(\alpha\) 不是越大越好，它做的是一个偏差—方差权衡：

    • \(\alpha\) 太小 → 接近极大似然，\(\alpha = 0\) 时退化成原式，零概率问题回来了；
    • \(\alpha\) 太大 → 每个格子都被先验拉平，数据里真实的差异被抹掉 ⚠

    经验做法：先用 \(\alpha = 1\) 跑通全流程，确认不再出现零概率； 然后在一个验证集上试几个不同的 \(\alpha\)，选效果最好的。 如果数据量很大，\(\alpha\) 的影响会自然变小， 因为加的常数相对于大量频数可以忽略 ✓

    平滑的受益方是「小样本格子」，不是整体准确率

    平滑往往不怎么改善总体准确率，它主要改善的是：

    • 不再出现概率为零的断言 —— 这一点在需要输出置信度的场合至关重要；
    • 罕见组合的估计更稳 —— 这些格子恰恰是 MLE 最不可靠的地方；
    • 数值稳定性 —— 避免连乘中出现零或下溢。

    所以别只用准确率来给 \(\alpha\) 打分。 若下游要用到概率值本身（比如做代价敏感决策、做融合）， 平滑带来的改善会比准确率上体现出来的大得多 ✓

    八、例题¶

    例题 1：写出图上的分解式并数参数¶

    题目：一个贝叶斯网络含四个二值变量 \(X_1, X_2, X_3, X_4\)， 边为 \(X_1 \to X_2\)、\(X_2 \to X_3\)、\(X_1 \to X_4\)。 写出联合分布的分解式，并数出需要估计多少个自由参数； 再用全连接（无任何结构假设）作对照。

    思路

    先按拓扑序给节点编号，让父节点编号小于子节点编号。 然后对每个节点查它的父节点集合，写出一个条件概率因子， 因子个数就是节点个数。

    数参数时分两步：每个因子有多少个格子， 以及每个格子里有多少个数是自由的（因为同一行求和等于 1）。

    解答

    第一步：确定每个节点的父节点集合。

    节点 父节点集合 \(\mathrm{Pa}(X_i)\) 父节点个数
    \(X_1\) \(\varnothing\) 0
    \(X_2\) \(\{X_1\}\) 1
    \(X_3\) \(\{X_2\}\) 1
    \(X_4\) \(\{X_1\}\) 1

    第二步：写分解式。

    \[ P(X_1, X_2, X_3, X_4) = P(X_1)\,P(X_2 \mid X_1)\,P(X_3 \mid X_2)\,P(X_4 \mid X_1) \]

    第三步：数自由参数。 每个二值节点的因子，在父节点每取一组值时， 只要定 \(1\) 个数（另一个由"和为 \(1\)"确定）。 于是各因子贡献：

    因子 格子数 每格自由参数 小计
    \(P(X_1)\) 1 1 1
    \(P(X_2 \mid X_1)\) 2 1 2
    \(P(X_3 \mid X_2)\) 2 1 2
    \(P(X_4 \mid X_1)\) 2 1 2

    合计 \(1 + 2 + 2 + 2 = 7\) 个自由参数。

    第四步：与全连接对照。 全连接要 \(2^4 - 1 = 15\) 个自由参数。 本例 7 个，正好省掉一半多 —— 省下来的正是 \(X_3\) 与 \(X_4\) 之间、\(X_2\) 与 \(X_4\) 之间这些图中没有的边 ✓

    注意：省掉一半看着不多，但变量数一多， 乘法效应是指数级的 —— 这正是第一节那张表要说的事 ⚠

    例题 2：验证链式结构的条件独立¶

    题目：链式结构 \(X_1 \to X_2 \to X_3\)， \(X_1\) 为二值且 \(P(X_1 = 1) = 0.4\)， \(P(X_2 = 1 \mid X_1 = 0) = 0.2\)、\(P(X_2 = 1 \mid X_1 = 1) = 0.7\)， \(P(X_3 = 1 \mid X_2 = 0) = 0.3\)、\(P(X_3 = 1 \mid X_2 = 1) = 0.8\)。 验证：\(X_1\) 与 \(X_3\) 在未观测 \(X_2\) 时相关， 在观测 \(X_2 = 1\) 后条件独立。

    思路

    "相关"要比较 \(P(X_1 = 1)P(X_3 = 1)\) 与 \(P(X_1 = 1, X_3 = 1)\)； "条件独立"要比较 \(P(X_1 = 1 \mid X_2 = 1)\,P(X_3 = 1 \mid X_2 = 1)\) 与 \(P(X_1 = 1, X_3 = 1 \mid X_2 = 1)\)。

    算联合概率时，用分解式 \(P(x_1, x_2, x_3) = P(x_1)P(x_2 \mid x_1)P(x_3 \mid x_2)\)， 对不需要的变量求和。

    解答

    第一步：算边缘概率 \(P(X_1 = 1)\) 与 \(P(X_3 = 1)\)。

    \(P(X_1 = 1) = 0.4\) 是给定的。

    \(P(X_3 = 1)\) 要从 \(X_2\) 传过来。先算 \(P(X_2 = 1)\)：

    \[ P(X_2 = 1) = 0.6 \times 0.2 + 0.4 \times 0.7 = 0.12 + 0.28 = 0.40 \]

    再算 \(P(X_3 = 1)\)：

    \[ P(X_3 = 1) = 0.6 \times 0.3 + 0.4 \times 0.8 = 0.18 + 0.32 = 0.50 \]

    第二步：算 \(P(X_1 = 1, X_3 = 1)\)。 需要对 \(X_2\) 的两种取值求和：

    \[ P(X_1 = 1, X_3 = 1) = 0.4 \times 0.3 \times 0.3 + 0.4 \times 0.7 \times 0.8 \]
    \[ P(X_1 = 1, X_3 = 1) = 0.036 + 0.224 = 0.260 \]

    第三步：判断未观测时是否独立。

    \[ P(X_1 = 1)P(X_3 = 1) = 0.4 \times 0.5 = 0.200 \neq 0.260 \]

    不相等，所以 \(X_1\) 与 \(X_3\) 在未观测 \(X_2\) 时相关 ✓ 差值 \(0.06\) 就是"经由 \(X_2\) 传递"的那部分信息。

    第四步：观测 \(X_2 = 1\) 后重算。

    \[ P(X_1 = 1 \mid X_2 = 1) = \frac{0.4 \times 0.7}{0.40} = 0.70 \]

    而 \(P(X_3 = 1 \mid X_2 = 1) = 0.80\) 就是给定的条件表。 两者相乘：

    \[ 0.70 \times 0.80 = 0.56 \]

    再直接算 \(P(X_1 = 1, X_3 = 1 \mid X_2 = 1)\)：

    \[ P(X_1 = 1, X_3 = 1 \mid X_2 = 1) = \frac{0.4 \times 0.7 \times 0.8}{0.40} = \frac{0.224}{0.40} = 0.56 \]

    两式相等，条件独立成立 ✓

    结论：\(X_1 \perp X_3\)（不成立）、\(X_1 \perp X_3 \mid X_2\)（成立）。 观测中介节点把通路截断了，这就是链式结构的完整含义。

    例题 3：对撞结构——观测后为什么相关¶

    题目：对撞结构 \(X \to Z \leftarrow Y\)， \(X\) 与 \(Y\) 独立且各以概率 \(0.5\) 取 \(0\) 或 \(1\)， 条件概率表为

    \[ P(Z = 1 \mid X, Y) = 0.1 \text{（当 } X = Y \text{）},\qquad P(Z = 1 \mid X, Y) = 0.9 \text{（当 } X \neq Y \text{）} \]

    求 \(P(X = 1)\)、\(P(X = 1 \mid Y = 1)\)、 \(P(X = 1 \mid Y = 1, Z = 1)\)、\(P(X = 1 \mid Y = 1, Z = 0)\)， 并解释结果。

    思路

    由于 \(X\) 与 \(Y\) 独立，\(P(X = 1 \mid Y = 1)\) 应当等于 \(P(X = 1)\)。 关键是后两个：给定 \(Z = 1\) 时， \(Z\) 的取值同时约束了 \(X\) 与 \(Y\)，要老老实实按贝叶斯公式算。

    计算时用一个技巧：先写出联合概率 \(P(x, y, z) = 0.25 \times P(z \mid x, y)\)， 再对不需要的变量求和。

    解答

    第一步：未观测 \(Z\) 时。

    因为 \(X\) 与 \(Y\) 独立、都取 \(0.5\)，所以

    \[ P(X = 1) = 0.5000, \qquad P(X = 1 \mid Y = 1) = 0.5000 \]

    两者相同，说明未观测 \(Z\) 时 \(X\) 与 \(Y\) 独立 ✓

    第二步：给定 \(Z = 1\) 时。 先算 \(P(Y = 1, Z = 1)\)。对 \(X\) 的两种取值求和：

    \[ P(Y = 1, Z = 1) = 0.25 \times 0.9 + 0.25 \times 0.1 = 0.25 \]

    再算 \(P(X = 1, Y = 1, Z = 1) = 0.25 \times 0.1 = 0.025\)， 因为此时 \(X = Y = 1\) 属于"相等"情形。

    \[ P(X = 1 \mid Y = 1, Z = 1) = \frac{0.025}{0.25} = 0.1000 \]

    第三步：给定 \(Z = 0\) 时。

    \[ P(Y = 1, Z = 0) = 0.25 \times 0.1 + 0.25 \times 0.9 = 0.25 \]
    \[ P(X = 1, Y = 1, Z = 0) = 0.25 \times 0.9 = 0.225 \]
    \[ P(X = 1 \mid Y = 1, Z = 0) = \frac{0.225}{0.25} = 0.9000 \]

    第四步：结果汇总。

    条件 概率值 与 \(0.5\) 的偏离
    \(P(X = 1)\) 0.5000 0（基准）
    \(P(X = 1 \mid Y = 1)\) 0.5000 0（独立）✓
    \(P(X = 1 \mid Y = 1, Z = 1)\) 0.1000 \(-0.4\)（强负相关）⚠
    \(P(X = 1 \mid Y = 1, Z = 0)\) 0.9000 \(+0.4\)（强正相关）⚠

    怎么读这张表：观测 \(Z = 1\) 说明"\(X\) 与 \(Y\) 不相等"， 而我们又知道 \(Y = 1\)，于是 \(X\) 只能是 \(0\)， 所以 \(P(X = 1 \mid Y = 1, Z = 1) = 0.1\) 是个很小的数 —— \(0.1\) 而不是 \(0\)，因为 \(P(Z = 1 \mid X = Y) = 0.1\) 并非零， "相等"的情形仍有 \(10\%\) 的可能 ⚠

    结论：观测对撞节点让两个本来独立的变量变得强相关， 而且这里的相关是负相关（\(Z = 1\) 时 \(X\) 与 \(Y\) 倾向于相反）。 这就是 d-分离第三条判据说的"路径被打开"。

    例题 4：设计一个消元顺序并比较代价¶

    题目：链式网络 \(X_1 \to X_2 \to X_3 \to X_4 \to X_5\)， 全部是二值变量，要计算 \(P(X_1)\)。 请分别给出一个"好"顺序与一个"坏"顺序， 说明各自的中间因子最大规模，并解释差别的原因。

    思路

    中间因子的大小只取决于它作用域里有几个变量： \(s\) 个二值变量就要 \(2^s\) 个数值。 所以要把作用域尽量小的因子先处理掉， 也就是优先消掉那些"只出现在少数因子里"的变量。

    每个节点 \(X_i\) 的因子作用域是 \(\{X_{i-1}, X_i\}\)（根节点是 \(\{X_1\}\)）。 消一个变量时，要把它涉及的所有因子先相乘。

    解答

    好顺序：从两端往中间消，如 \(X_5, X_4, X_3, X_2\)。

    步骤 消掉 合并出的因子作用域 因子大小
    1 \(X_5\) 只有 \(P(X_5 \mid X_4)\) 含它 → \(\{X_4\}\) \(2\)
    2 \(X_4\) 上一步的因子与 \(P(X_4 \mid X_3)\) → \(\{X_3\}\) \(2\)
    3 \(X_3\) 上一步的因子与 \(P(X_3 \mid X_2)\) → \(\{X_2\}\) \(2\)
    4 \(X_2\) 上一步的因子与 \(P(X_2 \mid X_1)\) → \(\{X_1\}\) \(2\)

    最大中间因子只有 \(2\) 个数值。

    坏顺序：先消中间的 \(X_3\)，如 \(X_3, X_2, X_4, X_5\)。

    步骤 消掉 合并出的因子作用域 因子大小
    1 \(X_3\) \(P(X_3 \mid X_2)\) 与 \(P(X_4 \mid X_3)\) 相乘 → \(\{X_2, X_3, X_4\}\) \(8\)
    2 \(X_2\) 上面的大因子与 \(P(X_2 \mid X_1)\) 相乘 → \(\{X_1, X_2, X_4\}\)，再消 \(X_2\) → \(\{X_1, X_4\}\) \(8\)
    3 \(X_4\) 继续消 → \(\{X_1, X_5\}\) \(4\)
    4 \(X_5\) 继续消 → \(\{X_1\}\) \(2\)

    最大中间因子达到 \(8\) 个数值，是"好顺序"的 \(4\) 倍。

    差别的原因：消掉 \(X_3\) 时， 它同时是 \(X_2\) 的子节点和 \(X_4\) 的父节点， 两个因子必须合并，作用域从 \(2\) 个变量涨到 \(3\) 个变量， \(2^3 = 8\)。 而先消 \(X_5\)（链的末端）时， 它只出现在一个因子里，合并后作用域反而缩到 \(1\) 个变量 ✓

    推广：优先消掉"当前只出现在一个因子里"的变量， 或者等价的"叶子节点"， 是控制中间因子规模最基本的启发式规则 ✓ 上面那段代码跑遍全部 \(120\) 个顺序后， 最大中间因子的取值范围是 \(4\) 到 \(8\) —— 与本题手算的结论完全一致 ✓

    小结¶

    概念 核心内容 关键量 易错点
    图模型的作用 用结构假设压缩参数 自由联合表 \(2^d - 1\) vs 稀疏图约 \(d \cdot 2^k\) 以为参数多只是"慢" ⚠
    分解式 \(P(X_1, \dots, X_d) = \prod_i P(X_i \mid \mathrm{Pa}(X_i))\) 每个节点一张小表 忘记图必须无环
    链式结构 \(X \to Z \to Y\) 未观测相关，观测后独立 记成"观测后相关" ⚠
    共同父结构 \(Z \to X\)、\(Z \to Y\) 未观测相关，观测后独立 同上
    共同子结构 \(X \to Z \leftarrow Y\) 未观测独立，观测后相关 ⚠ 与直觉相反 ⚠⚠
    d-分离 每条路径都被阻断才独立 对撞节点未观测才阻断 漏掉"对撞节点的后代" ⚠
    变量消元 边乘边求和，改变求和顺序 最大中间因子 \(2^s\) 忘记最后归一化 ⚠
    消元顺序 决定代价，不改变答案 优先消叶子节点 先消中间变量 → 因子膨胀 ⚠
    推断复杂度 一般图精确推断 NP 难 树宽是核心指标 误读成"完全不能用" ⚠
    近似推断 采样法 / 变分法 无偏但慢 vs 快但有偏 以为变分法能得到精确值 ⚠
    朴素贝叶斯 共同父结构的特例 \(C \to X_j\)，特征间无边 把假设读成"特征无关" ⚠
    平滑 加 \(\alpha\)，分母加 \(\alpha K\) \(\alpha\) 是可调参数 分母写成 \(+\alpha\) ⚠

    四条最该带走的结论：

    1. 图结构是参数的压缩协议，不是画着好看的示意图 —— 每条缺失的边都对应一批被省掉的参数， 也对应一条"未被建模的依赖"，省参数与建错模型是同一件事的两面 ⚠
    2. 方向决定相关性的走向，对撞结构必须单独记 —— 链式与共同父都是"观测后独立"， 唯有共同子观测后反而相关； 更要注意"对撞节点的后代被观测"同样会打开路径 ⚠⚠
    3. 变量消元的顺序只影响代价、不影响答案 —— 所以可以放心优化顺序； "优先消叶子节点"是最实用的启发式， 而多个查询共用一轮计算要靠置信传播这类方法 ✓
    4. 平滑的作用是消灭零概率，而不只是提升准确率 —— 一个零就足以让整条连乘归零， 在需要输出置信度的场合，这个零比准确率下降危险得多 ⚠
