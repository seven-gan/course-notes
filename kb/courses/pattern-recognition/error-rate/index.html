    分类错误率分析¶

    上一页 最小错误率决策 已经证明了一件事： 「判给后验概率最大的那一类」能让平均错误率最小。 按照本站的写法，那个证明只需要一句话带过 —— 本页不再重复「平均错误率的定义」与「逐点最优的证明」， 需要的读者请回看那一页。

    本页要往前再走一步，回答三个更实际的问题：

    错误率到底怎么算？它有多大？又由什么决定？

    只记住结论的说法 实际差别 后果
    「最小错误率决策是最优的」 这是一句方向性结论，没有数字 不知道最优能好到什么程度
    「错误率就是分错的样本比例」 那只是测试集上的估计，不是理论量 换一个测试集，数字就变了 ⚠
    「错都错在边界附近」 真正决定错误率大小的是两类分布的重叠程度 光去调边界，改不动错误率量级

    这一页的主线

    整页围绕一个公式展开：判决边界 \(t\) 一旦定下来， 平均错误率就是两条加权密度曲线中较低的那一条下方的总面积。

    这句话分四步落地：

    步 做什么 在哪一节
    1 写出 \(P(e)\) 的区域分解式，并把每一项的来历讲清楚 二
    2 证明 \(P(e)\) 等于重叠面积，给出几何图像 三
    3 找出错误率由哪些参数决定，给出可分性判据 四
    4 讨论多类情形，以及「理论错误率」与「测试集错误率」的差别 五、六、七、八

    读懂这四步，你就能指着一个具体的分类问题说清楚错误率大约是多少、还能不能降下去 ✓

    一、这一页要解决什么¶

    1.1 上一页留下了什么问题¶

    先把上一页的两条结论原样搬过来（不再推导）：

    上一页的结论 具体内容
    判决规则 判 \(\omega_1\) 当 \(P(\omega_1 \mid x) \gt P(\omega_2 \mid x)\)，否则判 \(\omega_2\)
    最优性 在每一个 \(x\) 上都这样做，整体平均错误率最小 ✓

    这两条都是定性的：它们告诉你「怎么做才对」， 但没有告诉你「这样做以后，错多少」。

    「错多少」这件事必须算出来，因为：

    如果不知道错误率的数量级 会出什么问题
    不知道它有多小 无法判断「这个特征够不够用」，也不知道要不要换特征 ⚠
    不知道它由什么决定 无法判断「继续调算法」还有没有意义
    不知道它怎么估 拿测试集上一个数当真值，被随机波动骗 ⚠

    1.2 记号统一¶

    本页沿用上一页的记号与数值，只解释第一次出现的新记号：

    记号 含义 取值范围
    \(\omega_1, \omega_2\) 两个类别 固定两个符号
    \(x\) 一维观测（特征） 实数轴 \(\mathbb{R}\) 上的一个数
    \(P(\omega_i)\) 先验概率：不看 \(x\) 时它属于第 \(i\) 类的概率 \([0,1]\)，且 \(P(\omega_1) + P(\omega_2) = 1\)
    \(p(x \mid \omega_i)\) 类条件概率密度：已知它是第 \(i\) 类时 \(x\) 的分布密度 非负，在整条轴上积分为 \(1\)
    \(P(\omega_i \mid x)\) 后验概率：看到 \(x\) 之后它属于第 \(i\) 类的概率 \([0,1]\)，两者之和为 \(1\)
    \(p(x)\) 混合密度：\(p(x) = p(x \mid \omega_1)P(\omega_1) + p(x \mid \omega_2)P(\omega_2)\) 也是密度，积分为 \(1\)
    \(R_1, R_2\) 判决区域：判成第 \(1\) 类的 \(x\) 的集合、判成第 \(2\) 类的 \(x\) 的集合 两个集合，合起来覆盖整条轴
    \(t\) 判决边界：把轴切成 \(R_1\) 与 \(R_2\) 的那个分界点 一个实数
    \(P(e)\) 平均错误率（本页的主角） \([0,1]\)，\(e\) 是 error 的缩写

    一个约定：本页所有「积分」都是在实数轴上做的定积分， \(\int_{R_1}\) 表示「在集合 \(R_1\) 上积分」。

    1.3 本页固定使用的数值例子¶

    为了让每一节都能算出具体的数，全页统一用下面这一组参数（与上一页完全相同）：

    参数 符号 数值
    第一类均值 \(\mu_1\) \(15\)
    第一类标准差 \(\sigma_1\) \(3\)
    第一类先验 \(P(\omega_1)\) \(0.6\)
    第二类均值 \(\mu_2\) \(22\)
    第二类标准差 \(\sigma_2\) \(4\)
    第二类先验 \(P(\omega_2)\) \(0.4\)
    判决边界 \(t\) \(19.134613\)

    两类都是一维高斯，即

    \[p(x \mid \omega_i) = \frac{1}{\sqrt{2\pi}\,\sigma_i}\exp\left[-\frac{(x - \mu_i)^2}{2\sigma_i^2}\right]\]

    它是一条「钟形曲线」。 \(\mu_i\) 决定钟形的中心在哪，\(\sigma_i\) 决定钟形有多胖 —— \(\sigma_i\) 越大，曲线越矮越宽，两类就越容易互相「渗」过去。 这一点是后面第四节的关键 ✓

    二、一维两类情形的错误率公式¶

    2.1 判决边界把一个类分成了两半¶

    先看判决边界 \(t\) 做了什么。本课程课件在讲错误率时明确「以一维为例」：

    判决边界 \(t\) 把整条实数轴砍成左右两段：

    判决区域 具体含义 积分表示
    \(R_1\) 落在这里的样本，我们判它属于 \(\omega_1\) \(R_1 = (-\infty, t)\)
    \(R_2\) 落在这里的样本，我们判它属于 \(\omega_2\) \(R_2 = (t, \infty)\)

    注意两个细节（这两点很容易被忽略，但决定了公式对不对）：

    细节 说明
    两个区域能不能重叠？ 不能。\(R_1 \cup R_2\) 是整条实数轴，\(R_1 \cap R_2\) 是空集，判决才不会自相矛盾
    边界点 \(t\) 本身归哪边？ 连续分布下 \(x = t\) 的概率是 \(0\)，归哪一边都不影响积分结果 ✓（这一点在第七节的离散特征里就不成立了 ⚠）

    2.2 错误只可能出现在两种情形里¶

    「判错」这件事只有两种可能，本课程课件把这两种情形讲得很直白：

    情形 样本落在哪 我们判成 真实类别 这一枝的概率
    情形一 \(R_2\) 里 \(\omega_2\) 其实是 \(\omega_1\) \(P(\omega_1 \mid x)\)
    情形二 \(R_1\) 里 \(\omega_1\) 其实是 \(\omega_2\) \(P(\omega_2 \mid x)\)

    这两行就是「给定 \(x\) 时的条件错误率」：

    \[P(\text{error} \mid x) = \min\left[P(\omega_1 \mid x),\; P(\omega_2 \mid x)\right]\]

    赔率最小的那一边，就是「万一判错」时会踩到的那一边。 判 \(\omega_1\) 时错的可能只有「它其实是 \(\omega_2\)」，概率是 \(P(\omega_2 \mid x)\)； 判 \(\omega_2\) 时错的可能只有「它其实是 \(\omega_1\)」，概率是 \(P(\omega_1 \mid x)\)。 所以条件错误率取两者中的较小值

    2.3 从「条件错误率」到「平均错误率」¶

    \(P(\text{error} \mid x)\) 是在某个具体的 \(x\) 上犯错的概率，它是一个随 \(x\) 变化的函数。 要知道总体错多少，还得把「出现这个 \(x\) 的可能性」也算进去 —— 这个权重就是混合密度 \(p(x)\)。

    \[P(e) = \int_{-\infty}^{\infty} P(\text{error} \mid x)\, p(x)\, dx\]

    把整条轴上每个点的「在那里犯错的概率」乘以「那个点出现的概率密度」， 再全部加起来。这就是本课程课件说的「考虑样本自身的分布之后的平均错误率」。

    这一步为什么是「加权平均」而不是「取平均」，值得拆开看一遍：

    第 1 步：先想清楚 \(P(\text{error} \mid x)\) 是一个函数，不是一个数。 每个 \(x\) 处都有自己的条件错误率，\(x = 0\) 处可能错 \(2\%\)，\(x = 20\) 处可能错 \(30\%\)。

    第 2 步：如果直接把「每个 \(x\) 的条件错误率」加总再除以 \(x\) 的个数， 就隐含假设了「每个 \(x\) 出现的概率一样大」—— 这在连续分布下根本没有意义， 因为 \(x\) 有不可数无穷多个，谈不上「个数」。

    第 3 步：正确的做法是把「条件错误率」按「\(x\) 出现的概率密度 \(p(x)\)」加权。 密度大的地方（样本聚集的地方）权重大，密度小的地方权重小。 这就是积分里乘 \(p(x)\) 的来历

    用 \(P(\text{error} \mid x) \cdot p(x) = \min\left[p(x \mid \omega_1)P(\omega_1),\, p(x \mid \omega_2)P(\omega_2)\right]\) 可以把上面两段合成一句（下一节要讲这条）： 平均错误率是整个特征空间上条件错误概率按样本密度加权积分的结果

    2.4 把积分按区域拆开¶

    现在把上一小节的积分拆成两段 —— 一段在 \(R_1\) 上，一段在 \(R_2\) 上。 在 \(R_1\) 上判 \(\omega_1\)，所以条件错误率是 \(P(\omega_2 \mid x)\)； 在 \(R_2\) 上判 \(\omega_2\)，所以条件错误率是 \(P(\omega_1 \mid x)\)。于是

    \[P(e) = \int_{R_1} P(\omega_2 \mid x)\, p(x)\, dx + \int_{R_2} P(\omega_1 \mid x)\, p(x)\, dx\]

    现在用贝叶斯定理把后验换成「类条件密度 \(\times\) 先验」。 这一步是本页推导里唯一的「技巧」，必须一步步写清楚：

    第 1 步：写出贝叶斯定理本身。

    \[P(\omega_i \mid x) = \frac{p(x \mid \omega_i)\, P(\omega_i)}{p(x)}\]

    第 2 步：两边同乘 \(p(x)\)。左边是 \(P(\omega_i \mid x)\, p(x)\)， 右边分母的 \(p(x)\) 与乘上去的 \(p(x)\) 约掉：

    \[P(\omega_i \mid x)\, p(x) = p(x \mid \omega_i)\, P(\omega_i)\]

    为什么能约：\(p(x) \gt 0\)（密度非负，且高斯密度处处为正）， 所以 \(p(x)\) 是非零的数，不是「除以零」。这一步没有任何新定理， 只是把「后验 × 混合密度」换成等价的「类条件密度 × 先验」

    第 3 步：把这条代入上一小节的积分。第一项里是 \(P(\omega_2 \mid x)p(x)\)， 换成 \(p(x \mid \omega_2)P(\omega_2)\)；第二项同理换 \(P(\omega_1 \mid x)p(x)\)。 注意 \(P(\omega_i)\) 与 \(x\) 无关，是常数，可以提到积分号外面：

    \[P(e) = P(\omega_2)\int_{R_1} p(x \mid \omega_2)\, dx + P(\omega_1)\int_{R_2} p(x \mid \omega_1)\, dx\]

    后验概率从公式里完全消失了。 错误率只由「类条件密度（分布的形状）」和「先验（各类有多常见）」决定 —— 这正是「错误率是分布的性质，不是算法的性质」这句话的数学来源

    2.5 最终公式与逐项解释¶

    把 \(R_1 = (-\infty, t)\)、\(R_2 = (t, \infty)\) 代进去，得到本页的第一个主角公式：

    \[P(e) = P(\omega_1)\int_{t}^{\infty} p(x \mid \omega_1)\, dx \;+\; P(\omega_2)\int_{-\infty}^{t} p(x \mid \omega_2)\, dx\]

    逐项解释如下（每一项都单独说清楚「它是什么」「为什么这么写」）：

    项 它是什么 为什么这么写
    第一项 \(P(\omega_1)\int_{t}^{\infty} p(x \mid \omega_1)\, dx\) 第一类被错判成第二类的总概率 样本本来是 \(\omega_1\)（先验 \(P(\omega_1)\) 是加权），但它的 \(x\) 落在了 \(t\) 右边，于是被我们判成 \(\omega_2\) —— 错 ⚠
    第二项 \(P(\omega_2)\int_{-\infty}^{t} p(x \mid \omega_2)\, dx\) 第二类被错判成第一类的总概率 样本本来是 \(\omega_2\)（先验 \(P(\omega_2)\) 是加权），但它的 \(x\) 落在了 \(t\) 左边，于是被我们判成 \(\omega_1\) —— 错 ⚠
    为什么两项相加 两种判错情形互不相容 「本来是 \(\omega_1\) 被误判」和「本来是 \(\omega_2\) 被误判」不可能同时发生，所以概率可以直接加 ✓

    一句话记住这个公式： 「本该长在右边的那部分左边尾巴」（第一项）加上「本该长在左边的那部分右边尾巴」（第二项）。 每一条尾巴都要先乘上它自己的先验，因为尾巴里到底有多少样本，取决于这一类本来有多常见

    公式里两个积分限最容易对调

    第一项是 \(\int_{t}^{\infty}\)，第二项是 \(\int_{-\infty}^{t}\) —— 两个积分的方向是反的，这是故意的。

    记忆方法：看积分限的对侧。 第一项归 \(\omega_1\) 管，可是它的积分区间 \([t, \infty)\) 落在 \(\omega_2\) 的地盘上， 所以第一项积的一定是 \(\omega_1\) 的错判部分。

    如果把两处积分限写成同一个方向，会算出一个看起来「合理」但其实毫无意义的数

    import numpy as np
from scipy.stats import norm

mu1, s1, prior1 = 15.0, 3.0, 0.6
mu2, s2, prior2 = 22.0, 4.0, 0.4

def log_post_diff(x):
    """判决函数之差 g2(x) - g1(x)：为正判 w2，为负判 w1。"""
    return (np.log(prior2) - np.log(prior1)
            + np.log(s1) - np.log(s2)
            - (x - mu2) ** 2 / (2 * s2 ** 2)
            + (x - mu1) ** 2 / (2 * s1 ** 2))

def bisect_root(lo, hi, f, tol=1e-12, max_iter=200):
    """二分法：在 [lo, hi] 上求 f 的零点（要求 f(lo) 与 f(hi) 异号）。"""
    flo = f(lo)
    if flo * f(hi) > 0:
        raise ValueError("区间两端同号，二分法不适用")
    for _ in range(max_iter):
        mid = 0.5 * (lo + hi)
        fmid = f(mid)
        if fmid == 0.0 or (hi - lo) < tol:
            return mid
        if flo * fmid < 0:
            hi = mid
        else:
            lo, flo = mid, fmid
    return 0.5 * (lo + hi)

print("f(18) 与 f(21) 的符号:", int(np.sign(log_post_diff(18.0))), int(np.sign(log_post_diff(21.0))))
t = bisect_root(18.0, 21.0, log_post_diff)
print("二分法求得的判决边界 t =", round(t, 6))
print("在 t 处判决函数之差 =", round(log_post_diff(t), 12))
print("两类均值为 15 与 22，边界落在均值之间:", mu1 < t < mu2)

    2.8 手算核对：用标准正态分布表也能算出来¶

    数值积分是「算出来的」，还需要手算一遍去核对， 否则公式写错了你也不会发现。

    思路：把每一类的积分换成标准正态分布。做法是标准化 （减均值再除标准差），把 \(x\) 换成 \(z\)：

    量 定义 含义
    \(z_1\) \(z_1 = \dfrac{t - \mu_1}{\sigma_1}\) 把边界 \(t\) 换算到 \(\omega_1\) 的标准刻度上
    \(z_2\) \(z_2 = \dfrac{t - \mu_2}{\sigma_2}\) 把边界 \(t\) 换算到 \(\omega_2\) 的标准刻度上
    \(\Phi(z)\) 标准正态分布的累积分布函数 \(\Phi(z) = \int_{-\infty}^{z}\frac{1}{\sqrt{2\pi}}e^{-u^2/2}\,du\)，即「标准正态小于 \(z\) 的概率」

    代入本页数值：

    \[z_1 = \frac{19.134613 - 15}{3} = \frac{4.134613}{3} \approx 1.378204\]
    \[z_2 = \frac{19.134613 - 22}{4} = \frac{-2.865387}{4} \approx -0.716347\]

    再换两项积分。第一项是 \(\omega_1\) 落在 \([t, \infty)\) 的质量：

    \[\int_{t}^{\infty} p(x \mid \omega_1)\, dx = P(x \gt t \mid \omega_1) = 1 - \Phi(z_1)\]

    怎么读这一步：「大于 \(t\)」在标准化之后就是「大于 \(z_1\)」， 而「大于 \(z_1\)」的概率是 \(1 - \Phi(z_1)\)。 查表得 \(\Phi(1.378204) \approx 0.915930\)，所以 \(1 - \Phi(z_1) \approx 0.084070\)。

    第二项是 \(\omega_2\) 落在 \((-\infty, t]\) 的质量：

    \[\int_{-\infty}^{t} p(x \mid \omega_2)\, dx = P(x \lt t \mid \omega_2) = \Phi(z_2)\]

    注意这里没有用 \(1 - \Phi\)：因为 \(z_2\) 是负的（\(-0.716347\)）， 「小于 \(t\)」直接就是 \(\Phi(z_2) \approx 0.236889\)

    两项分别乘上先验，再加起来：

    计算步骤 算式 数值
    第一项尾巴质量 \(1 - \Phi(z_1)\) \(1 - 0.915930 = 0.084070\)
    第一项（乘先验） \(P(\omega_1)\times 0.084070\) \(0.6 \times 0.084070 = 0.050442\)
    第二项尾巴质量 \(\Phi(z_2)\) \(0.236889\)
    第二项（乘先验） \(P(\omega_2)\times 0.236889\) \(0.4 \times 0.236889 = 0.094756\)
    合计 两项相加 \(\mathbf{0.145198}\) ✓

    手算结果与数值积分完全一致（\(0.145198\) vs \(0.145198\)）， 说明 2.5 节的公式与代码都没有写错。 整条推导链 —— 「条件错误率 → 区域分解 → 标准化 → 查表」—— 每个环节都自洽，你可以放心地在考场上用同样的步骤手算出错误率

    两个尾巴里有一个要用 1 减

    第一项用 \(1 - \Phi(z_1)\)，第二项用 \(\Phi(z_2)\)，两项形式不同。

    判断方法：看标准化后的数值是正还是负。 \(z_1 = 1.378\) 是正的，说明边界 \(t\) 在 \(\omega_1\) 均值的右边， 「大于 \(t\)」是一条右尾，要用 \(1 - \Phi\)； \(z_2 = -0.716\) 是负的，说明 \(t\) 在 \(\omega_2\) 均值的左边， 「小于 \(t\)」是一条左尾，\(\Phi\) 本身就已经是概率，不用再减

    写成统一形式也可以：\(P(x \gt t \mid \omega_1) = 1 - \Phi(z_1)\) 与 \(P(x \lt t \mid \omega_2) = \Phi(z_2)\) 其实都是 \(\Phi\) 的组合， 只要记住「\(\Phi\) 是『小于』的概率」就不会搞反

    2.9 两项的相对大小说明了什么¶

    两个数摆在一起非常值得琢磨：

    项 数值 占 \(P(e)\) 的比例
    第一类被错判 \(P(\omega_1)\int_t^{\infty} p(x\mid\omega_1)dx\) \(0.050442\) \(34.74\%\)
    第二类被错判 \(P(\omega_2)\int_{-\infty}^{t} p(x\mid\omega_2)dx\) \(0.094755\) \(65.26\%\)
    总错误率 \(P(e)\) \(\mathbf{0.145198}\) \(100\%\)

    三、错误率的几何解释：重叠面积¶

    3.1 换一个角度看同一个公式¶

    2.5 节把 \(P(e)\) 写成了两个尾巴之和。这一节换一个写法， 会得到一个好记得多的几何图像 —— 而且这个图像不依赖「一维」「两类」这些限制。

    先给两条曲线起个名字。加权密度（把先验乘进类条件密度里）定义为

    \[q_1(x) = p(x \mid \omega_1)\,P(\omega_1), \qquad q_2(x) = p(x \mid \omega_2)\,P(\omega_2)\]

    怎么读这两个式子：\(q_i(x)\) 不再是「密度」，它把先验也算进去了， 所以 \(\int_{-\infty}^{\infty} q_i(x)\,dx = P(\omega_i)\)，而不是 \(1\)。 两条曲线下的总面积分别是 \(0.6\) 与 \(0.4\)。

    3.2 证明 \(P(e)\) 等于较低包络下方的面积¶

    要证的目标：

    \[P(e) = \int_{-\infty}^{\infty} \min\big[q_1(x),\; q_2(x)\big]\, dx\]

    第一步：把条件错误率写成加权密度。

    从 2.2 节出发：

    \[P(\text{error} \mid x) = \min\big[P(\omega_1 \mid x),\; P(\omega_2 \mid x)\big]\]

    两边同乘 \(p(x)\)。注意 \(p(x)\) 是一个与类别无关的正数， 所以它可以挪进 \(\min\) 里面（正数相乘不改变大小关系）：

    \[P(\text{error} \mid x)\, p(x) = \min\big[P(\omega_1 \mid x)\,p(x),\; P(\omega_2 \mid x)\,p(x)\big]\]

    第二步：用贝叶斯定理把后验换成加权密度。

    2.4 节已经证明 \(P(\omega_i \mid x)\,p(x) = p(x \mid \omega_i)\,P(\omega_i) = q_i(x)\)， 代进去就得到

    \[P(\text{error} \mid x)\, p(x) = \min\big[q_1(x),\; q_2(x)\big]\]

    怎么读这一步：左边是「在 \(x\) 处犯错、同时 \(x\) 会出现的联合密度」， 右边是「两条加权密度中较低的那一条」。 条件错误率乘上混合密度，恰好等于两条加权密度里较小的那个

    第三步：对 \(x\) 积分。

    \[P(e) = \int_{-\infty}^{\infty} P(\text{error} \mid x)\, p(x)\, dx = \int_{-\infty}^{\infty} \min\big[q_1(x),\; q_2(x)\big]\, dx\]

    这就是要证的结论

    第四步：与 2.5 节的公式对得上吗？ 逐点看 \(q_1\) 与 \(q_2\) 谁大谁小。 两个高斯型曲线最多有两个交点，本页参数下的两个交点是 \(t = 19.134613\)（主边界）与 \(-7.134613\)（极左尾部，几乎不携带质量）：

    区间 \(q_1\) 与 \(q_2\) 谁大 \(\min\) 取谁 这一段的面积 对应 2.5 节的哪一项
    \((-\infty, t)\) \(q_1 \gt q_2\) \(q_2\) \(\int_{-\infty}^{t} q_2\,dx\) 第二项
    \((t, \infty)\) \(q_2 \gt q_1\) \(q_1\) \(\int_{t}^{\infty} q_1\,dx\) 第一项

    怎么读这张表：在中心区域的左边，第二类的加权密度更低（因为第二类的中心在右边）， 所以 \(\min\) 取的是 \(q_2\)；在右边反之。两段一加，正好是 2.5 节的两个尾巴 「重叠面积」和「两个尾巴之和」是同一个东西的两种说法。

    这个等价性把「错误率」从「一堆积分符号」 翻译成了一句话 —— 错误率就是两条曲线互相盖住的那片地有多大。 看懂这句话，后面所有关于「什么决定错误率」的结论都能直接从图上读出来

    3.4 一个重要推论：重叠面积就是错误率的下界¶

    从几何图像可以直接读出一件事： \(\int \min[q_1, q_2]\,dx\) 完全与判决边界无关。

    • 如果我们把边界挪到别处，\(\min\) 覆盖的区域一点都不会变小， 只会在某一段改用较高的那条曲线，于是总面积变大
    • 只有当边界恰好取在交点 \(t\) 上时，\(\min\) 才会在每一段都取到较低的那条曲线， 总面积取到最小值

    这就是「贝叶斯边界最优」的几何证明 —— 它和上一页的逐点证明是同一件事的两个说法： 逐点取后验最大 \(\Leftrightarrow\) 逐点取较低包络 \(\Leftrightarrow\) 总面积最小

    错误率只由「重叠」决定，不由算法决定

    这句话是本页最重要的一句话：

    两条加权密度曲线一旦定下来，最小错误率就是一个固定的数 \(0.145198\)。

    换分类器、换优化算法、换损失函数、把网络加深 —— 只要特征与分布没变， 这个数就降不下去 能降它的只有两件事：换特征（把两条曲线拉开）或改分布假设（比如知道更多先验信息）。

    本课程课件里对这一点有明确表述：贝叶斯错误率是理论下界， 其他任何决策规则（最小距离、固定阈值、神经网络等）都不可能低于它

    四、错误率随参数变化的规律¶

    4.1 三个参数，三条规律¶

    \(P(e)\) 的公式里只有三个可以动的量：均值 \(\mu_i\)、标准差 \(\sigma_i\)、先验 \(P(\omega_i)\)。 它们对错误率的影响方向如下（下一小节起逐条手算验证）：

    参数 变化方向 总错误率 直观解释
    均值距离 \(\Delta = \lvert\mu_1 - \mu_2\rvert\) 变大 下降 ✓ 两条曲线被拉开，重叠变小
    标准差 \(\sigma\) 变大 上升 ⚠ 两条曲线变胖，重叠变大
    先验 \(P(\omega_1)\) 越悬殊 下降（但少数类更惨） ⚠ 边界被推向少数类，多数的错判被压下去

    这三条规律有一个共同的含义：错误率衡量的不是「分类器聪不聪明」， 而是特征本身把两类分得开不开。 分开就是 \(\Delta\) 大、\(\sigma\) 小 —— 这也是「特征工程」比「换模型」更值钱的原因

    把这三条规律画在一张图上：横轴是「均值距离除以标准差」的比值（第 4.6 节会把它正式命名为 \(d'\)）， 纵轴是贝叶斯错误率。曲线单调下降，而且下降越来越快 —— 距离每拉开一点，错误率掉的幅度越来越大。

    怎么读这张图：横轴已经把距离和散布合成一个比值了。 只看距离不看散布是没意义的：距离 \(7\) 配 \(\sigma = 3.5\)（比值 \(2\)）的错误率， 和距离 \(7\) 配 \(\sigma = 10\)（比值 \(0.7\)）的错误率差了几十倍（4.2、4.3 节会手算）。 图上标的两条水平虚线分别是 \(1\%\) 与 \(5\%\) —— 曲线穿过 \(5\%\) 线的地方大约在比值 \(3.3\) 处， 这正是「要错误率低于 \(5\%\)，比值至少要 3.3」的图形化说法

    怎么读这张表：\(\sigma\) 从 \(1.0\) 涨到 \(10.0\)（\(10\) 倍）， \(P(e)\) 从 \(0.000233\) 涨到 \(0.363169\)（约 \(1560\) 倍）

    这里出现了一个关键量：第二列 \(\Delta/\sigma\) 就是下一小节要讲的可分性判据。 看它的作用 —— 它从 \(7.0\) 掉到 \(0.7\)，错误率就涨到天上去了。 \(\Delta/\sigma\) 是错误率的唯一决定因素（先验相等时）， \(\Delta\) 和 \(\sigma\) 各自单独的值反而不重要 （对照 4.2 与 4.3 两张表：\(\Delta = 7, \sigma = 3.5\) 与 \(\Delta = 14, \sigma = 7\) 是同一个比值 \(2\)，错误率必然都是 \(0.158655\)。）

    4.4 规律三：先验变悬殊，总错误率下降但少数类更惨¶

    4.5 等方差等先验时的闭式解¶

    前两个参数扫出来的规律很漂亮，但都是表格。能不能写出一个公式， 让人不必查程序就能估出错误率？可以 —— 只要加两个假设。

    假设（这一小节全程成立）：

    假设 写法 为什么这么假设
    等方差 \(\sigma_1 = \sigma_2 = \sigma\) 两类散布一样，此时判别边界退化成一条垂直平分线
    等先验 \(P(\omega_1) = P(\omega_2) = \dfrac{1}{2}\) 两类一样常见，边界不被先验推偏

    为了少写符号，定义一个量：

    \[\Delta = \lvert\mu_1 - \mu_2\rvert\]

    \(\Delta\) 是两类均值的距离，单位与 \(x\) 相同（本页是「厘米」）。 不失一般性，下面假设 \(\mu_2 \gt \mu_1\)，于是 \(\Delta = \mu_2 - \mu_1\)。

    第一步：求判决边界 \(t\)。

    判决边界满足两条加权密度相等，也就是 2.6 节的 \(g(x) = 0\)。 把 \(\sigma_1 = \sigma_2 = \sigma\) 与 \(P(\omega_1) = P(\omega_2)\) 代入， \(\ln\frac{P(\omega_2)}{P(\omega_1)} = \ln 1 = 0\)、\(\ln\frac{\sigma_1}{\sigma_2} = \ln 1 = 0\)， 两项一起消失：

    \[-\frac{(x-\mu_2)^2}{2\sigma^2} + \frac{(x-\mu_1)^2}{2\sigma^2} = 0\]

    两边同乘 \(2\sigma^2\)（\(\sigma \gt 0\)，系数不为零）：

    \[-(x-\mu_2)^2 + (x-\mu_1)^2 = 0\]

    移项：

    \[(x-\mu_1)^2 = (x-\mu_2)^2\]

    两边开方要带正负号 —— 这是最容易漏一步的地方：

    \[x - \mu_1 = \pm\,(x - \mu_2)\]

    取正号：\(x - \mu_1 = x - \mu_2\)，两边消掉 \(x\) 得 \(-\mu_1 = -\mu_2\)， 即 \(\mu_1 = \mu_2\) —— 但这与「两类均值不同」矛盾，所以正号不成立 ✗

    取负号：\(x - \mu_1 = -(x - \mu_2) = -x + \mu_2\)， 移项得 \(2x = \mu_1 + \mu_2\)，于是

    \[t = \frac{\mu_1 + \mu_2}{2}\]

    怎么读这个结果：等方差等先验时，判决边界就是两个均值的中点。 这就是「取中点」这个经验做法唯一正确的场合 ✓ 换成先验不等或方差不等（如 2.6 节的本页参数），中点就不再是边界了

    第二步：把两个标准化量算出来。

    \[z_1 = \frac{t - \mu_1}{\sigma} = \frac{\frac{\mu_1+\mu_2}{2} - \mu_1}{\sigma} = \frac{\frac{\mu_2-\mu_1}{2}}{\sigma} = \frac{\mu_2-\mu_1}{2\sigma} = \frac{\Delta}{2\sigma}\]
    \[z_2 = \frac{t - \mu_2}{\sigma} = \frac{\frac{\mu_1+\mu_2}{2} - \mu_2}{\sigma} = \frac{\frac{\mu_1-\mu_2}{2}}{\sigma} = -\frac{\Delta}{2\sigma} = -z_1\]

    关键观察：\(z_2 = -z_1\)。也就是说，边界相对两类都在同样远的地方， 只是方向相反 —— 这正是「中点 + 等方差」的结果

    第三步：代进 2.8 节的两个尾巴公式。

    \[P(e) = P(\omega_1)\big[1 - \Phi(z_1)\big] + P(\omega_2)\,\Phi(z_2)\]

    把 \(P(\omega_1) = P(\omega_2) = \frac{1}{2}\)、\(z_2 = -z_1\) 代进去：

    \[P(e) = \frac{1}{2}\big[1 - \Phi(z_1)\big] + \frac{1}{2}\,\Phi(-z_1)\]

    第四步：用 \(\Phi\) 的对称性把两项合并。

    标准正态分布关于 \(0\) 对称，所以对任意实数 \(z\) 都有

    \[\Phi(-z) = 1 - \Phi(z)\]

    为什么：\(\Phi(-z)\) 是「标准正态小于 \(-z\)」的概率， \(1-\Phi(z)\) 是「标准正态大于 \(z\)」的概率； 由于左右对称，这两个概率完全相等

    把这条对称关系用在上式第二项上（取 \(z = z_1\)）：

    \[\Phi(-z_1) = 1 - \Phi(z_1)\]

    代回去：

    \[P(e) = \frac{1}{2}\big[1 - \Phi(z_1)\big] + \frac{1}{2}\big[1 - \Phi(z_1)\big] = 1 - \Phi(z_1)\]

    再用一次对称性（把 \(1 - \Phi(z_1)\) 写成 \(\Phi(-z_1)\)）：

    \[\boxed{\;P(e) = \Phi\!\left(-\frac{\Delta}{2\sigma}\right)\;}\]

    怎么读这个结果：等方差、等先验时， 平均错误率就是「标准正态小于 \(-\frac{\Delta}{2\sigma}\)」的概率。 只有当两类距离 \(\Delta\) 相对于散布 \(\sigma\) 足够大时，这个概率才小

    这个闭式解把 4.2、4.3 两张手算表合并成了一行公式 —— 表里的每一行都是往这个公式里代一个数。公式里只有比值 \(\Delta/\sigma\) 一个量， 所以「拉开距离」和「压小散布」对错误率的作用完全等价， 这是后面可分性判据 \(d'\) 的来源

    4.6 可分性判据 \(d'\)¶

    把闭式解里的那个比值单独拎出来命名：

    \[d' = \frac{\lvert\mu_1 - \mu_2\rvert}{\sigma} = \frac{\Delta}{\sigma}\]

    \(d'\) 读作「d 撇」，中文常叫可分性判据或可分性指数。 它是一个不带量纲的数（长度除以长度），所以可以跨问题比较。

    闭式解用 \(d'\) 写出来更简洁：

    \[P(e) = \Phi\!\left(-\frac{d'}{2}\right)\]

    \(d'\) 越大，\(-d'/2\) 越负，\(\Phi\) 的取值越接近 \(0\)， 错误率越小

    与 4.2、4.3 节两张表对得上吗：对得上。

    表 参数 \(d' = \Delta/\sigma\) \(P(e) = \Phi(-d'/2)\)
    4.2 节第 3 行 \(\Delta = 7\)，\(\sigma = 3.5\) \(2.0\) \(0.158655\) ✓
    4.2 节第 5 行 \(\Delta = 14\)，\(\sigma = 3.5\) \(4.0\) \(0.022750\) ✓
    4.3 节第 1 行 \(\Delta = 7\)，\(\sigma = 1.0\) \(7.0\) \(0.000233\) ✓
    4.3 节第 5 行 \(\Delta = 7\)，\(\sigma = 10.0\) \(0.7\) \(0.363169\) ✓

    注意后两行：\(\Delta\) 完全没变（都是 \(7\)）， 只因为 \(\sigma\) 从 \(1.0\) 换成 \(10.0\)，错误率就从 \(0.000233\) 变成 \(0.363169\)。 决定错误率的是比值 \(d'\)，不是 \(\Delta\) 本身

    要错误率不超过某个目标，\(d'\) 需要多大？ 把 \(P(e) = \Phi(-d'/2) \le p_0\) 反解：

    \[-\frac{d'}{2} \le \Phi^{-1}(p_0) \;\Longrightarrow\; d' \ge -2\,\Phi^{-1}(p_0)\]
    目标错误率 \(p_0\) 需要的 \(-d'/2\) 需要的 \(d'\)
    \(10\%\) \(-1.281552\) \(2.563103\)
    \(5\%\) \(-1.644854\) \(3.289707\)
    \(1\%\) \(-2.326348\) \(\mathbf{4.652696}\)
    \(0.1\%\) \(-3.090232\) \(6.180465\)

    怎么读这张表：要让错误率降到 \(1\%\)，两类的均值距离必须至少是标准差的 \(4.65\) 倍。 这是一个非常实用的设计目标：

    设计场景 用法
    已知两类分布 先算 \(d'\)，再查 \(P(e)\)，判断这个特征够不够用 ✓

    把 d 撇当成「信噪比」来用

    \(d' = \Delta/\sigma\) 的直观含义是：「两类差多远」除以「每类有多胖」。

    它像一个信噪比： - 分子 \(\Delta\) 是「有用的信号」（两类真的有差别） - 分母 \(\sigma\) 是「噪声」（类内波动，会把差别糊掉）

    所以 \(d'\) 是一个无量纲的特征质量指标， 比「错误率」本身更适合用来描述「这个特征好不好」： 错误率还受先验影响，\(d'\) 只取决于特征

    参数变化 边界 \(t\) 怎么动 总错误率 两类的错判率 能不能靠调边界救回来
    \(\Delta\) 变大 基本不动（中点附近） 下降 ✓ 两类都下降 不需要救，本来就在变好
    \(\sigma\) 变大 基本不动（中点附近） 上升 ⚠ 两类都上升 救不回来，只能换特征 ⚠
    先验越悬殊 明显朝少数类移动 下降 ✓ 多数类下降、少数类上升 ⚠ 边界本来就在动，是同一件事
    换更强的分类器 不动 不变 不变 完全救不回来 ⚠

    最后一行要单独强调：在分布已知的前提下， 换分类器不能让 \(P(e)\) 变化 —— 因为贝叶斯错误率已经是下界， 任何分类器的错误率都 \(\ge\) 它。这条结论本课程课件里说得很明确

    五、错误率的最优性：\(X^*\) 与 \(X_B\) 是哪个点¶

    5.1 本课程课件里的那句话¶

    本课程课件在讲两类情形平均错分概率时，配了一张「两条加权密度 + 两个候选点」的图， 并在图旁写下了一句判语：

    \(X^*\) 不是一个最优化的决策点，\(X_B\) 是一个最优化的决策点

    注意这里是两个符号，不是同一个点的两种写法：

    符号 位置特征 本课程课件的判语
    \(X^*\) 落在曲线交叉区域内的一个候选点 不是最优化的决策点 ✗
    \(X_B\) 两条加权密度曲线的交点 是最优化的决策点 ✓

    下标 \(B\) 的含义：\(B\) 取自 Bayes（贝叶斯）。 \(X_B\) 就是贝叶斯边界 —— 本页参数下它等于 \(t = 19.134613\)

    5.2 为什么 \(X^*\) 不是最优的¶

    本课程课件为什么要在图上标一个「不是最优」的点？因为这是最容易犯的错。

    设想有人这样想：「既然要最小化总错误率， 那就在两类分布的交叉区域里随便找个点当边界吧。」—— 这就是 \(X^*\) 的来历：一个看起来在合理范围里的候选点

    它为什么不对：从第三节的几何图像可以立刻看出来。 错误率是 \(\int\min[q_1,q_2]\,dx\)，它只在两条曲线的交点处取到最小值。 只要边界偏离交点，就会有一段改用较高的那条曲线，面积必然变大

    具体差多少？用 2.10 节的手算表：

    候选阈值 \(P(e)\) 比最优值多出多少
    \(19.0\)（离 \(X_B\) 只差 \(0.13\)） \(0.145378\) \(+0.000180\)
    \(18.5\)（两类均值中点） \(0.149318\) \(+0.004121\)
    \(18.0\) \(0.158655\) \(+0.013457\)
    \(15.0\)（\(\omega_1\) 的均值） \(0.316024\) \(+0.170826\)

    怎么读这张表：即使把边界放得很接近最优位置（\(19.0\) 与 \(19.1346\) 只差 \(0.13\)）， 错误率也已经多出了 \(0.000180\) —— 是最优错误率的 \(0.12\%\)。 离得越远，代价越大

    这里有个很实际的教训：错误率在最优值附近是非常平坦的， 所以「差不多就行了」在实用上往往可以接受； 但「差不多」和「最优」之间的差距确实存在， 而且 \(\min[q_1,q_2]\) 的最小值只有一个点能达到

    5.3 用候选阈值扫描验证最优点就是贝叶斯边界¶

    口说无凭，把 2.10 节那张手算表再拿来看一遍： 表里 \(P(e)\) 最小的那一行，恰好就是 \(t = 19.134613\)。 这就是「网格搜索」的思路 —— 把候选阈值都摆出来，逐个算 \(P(e)\)，取最小的那个。 2.10 节的表已经做到这一点，不需要再跑程序

    如果扫描得足够密（例如步长 \(0.0005\) 从 \(17\) 扫到 \(22\)，共一万个点）， 网格上最小的点是 \(t = 19.1345\)，与 \(X_B = 19.134613\) 只差 \(0.000113\)， 网格最小错误率与贝叶斯错误率之差约 \(1.26\times10^{-10}\)（这是网格步长带来的分辨率极限）。 结论：纯网格搜索自己就能找到贝叶斯边界，不需要任何公式 （这些数值已由本课程课件按网格扫描核对。）

    \(X_B\) 与 \(X^*\) 的判决总结：

    点 是不是最优决策点 依据
    \(X^*\)（交叉区域里随手取的候选点） 不是 ✗ 除了 \(X_B\) 那一点，任何阈值都让 \(P(e)\) 更大 ✓
    \(X_B\)（两条加权密度的交点） 是 ✓ 该点处 \(\min[q_1,q_2]\) 在每一段都取到较低曲线，面积最小 ✓

    再补一句几何上的理由：\(X_B\) 的两条曲线高度相等 （第 3.5 节的代码输出 \(w_1(t) = w_2(t) = 0.0308660013\)）， 意思是「在这里，判成哪一类，错判的概率一样大」—— 往任何一侧挪，都会让某一类的错判概率超过另一类， 而总错误率的增加量大于减少量，于是总错误率上升

    六、0-1 损失与最大后验决策的关系¶

    6.1 0-1 损失矩阵¶

    前五节一直在讲「错误率」，但「错」这件事本身是有代价的。 把代价写成矩阵，就是损失矩阵：

    \[\lambda_{ij} = \text{真实类别是 } \omega_j \text{ 时，我们判成 } \omega_i \text{ 所付出的代价}\]

    怎么读这个记号：下标第一个是「我们判的」，第二个是「真实的」 —— 顺序不能反，否则整个矩阵会转置 ⚠

    0-1 损失是最简单的一种代价约定（\(c = 2\) 的两类情形）：

    我们的判决 \(\downarrow\) \ 真实类别 \(\rightarrow\) \(\omega_1\) \(\omega_2\)
    判 \(\omega_1\) \(0\) \(1\)
    判 \(\omega_2\) \(1\) \(0\)

    要点：判对了不要钱（\(0\)），判错了收 \(1\) 元（\(1\)）。 「所有错误代价都一样」正是这个矩阵的全部含义 （多类的 0-1 损失矩阵就是把这张表扩成 \(c \times c\)，对角线全是 \(0\)、非对角线全是 \(1\)。）

    6.2 条件风险就是错误概率¶

    下一页 最小风险决策 会把风险理论完整讲一遍， 这里只取一个结论用：在 0-1 损失下，条件风险恰好等于错误概率。

    条件风险的定义是「在给定 \(x\) 时，采取某个判决动作 \(\alpha_i\) 的期望代价」：

    \[R(\alpha_i \mid x) = \sum_{j=1}^{c} \lambda_{ij}\, P(\omega_j \mid x)\]

    把 0-1 损失 \(\lambda_{ij} = 1 - \delta_{ij}\)（\(\delta_{ij}\) 是「相同为 \(1\)、不同为 \(0\)」的指示量） 代进去，「判对」的那一项 \(\lambda_{ii} = 0\) 消失，只剩下所有判错的情形：

    \[R(\alpha_i \mid x) = \sum_{j \neq i} P(\omega_j \mid x) = 1 - P(\omega_i \mid x)\]

    怎么读这一步：类条件概率对 \(j\) 求和一定是 \(1\)（\(x\) 必属于某一类）， 所以「除第 \(i\) 类以外的概率之和」\(= 1 - P(\omega_i \mid x)\)。 而这正是 2.2 节写的条件错误率

    量 表达式 是不是同一个东西
    条件风险（0-1 损失） \(1 - P(\omega_i \mid x)\) ✓
    条件错误率（判成 \(\omega_i\) 时） \(1 - P(\omega_i \mid x)\) ✓

    所以「最小化风险」和「最小化错误率」在 0-1 损失下是同一个数学问题

    6.3 三者合一¶

    把上面几节串起来，就得到本页与上一页的核心等价链：

    说法 具体操作 等价原因
    最小风险 选 \(R(\alpha_i \mid x)\) 最小的动作 0-1 损失下 \(R = 1 - P(\omega_i\mid x)\)，最小化 \(R\) 就是最大化 \(P(\omega_i\mid x)\)
    最大后验 选 \(P(\omega_i \mid x)\) 最大的类 与上一行是同一个操作 ✓
    最小错误率 让 \(P(e)\) 最小 上一页已证：逐点最大化后验 \(\Rightarrow\) 整体 \(P(e)\) 最小

    三者合一的完整链条：

    \[\text{0-1 损失} \;\Longrightarrow\; \text{条件风险} = \text{条件错误率} \;\Longrightarrow\; \text{最小风险} = \text{最大后验} = \text{最小错误率}\]

    怎么读这条链：三个名字听着像是三种不同的方法， 在 0-1 损失这个前提下完全是同一件事 这也是为什么本页可以放心地把它们混着说 —— 前提不变。

    总错误率的第三种写法（本课程课件在讲 0-1 cost 时给出的形式）： 既然 MAP 判决在每个 \(x\) 上取的都是最大的那个加权密度 \(\max_i q_i(x)\)， 那么正确率就是把这条「上包络」下方的面积积起来：

    \[P(\text{correct}) = \int_{-\infty}^{\infty} \max_{i}\, p(x \mid \omega_i)\,P(\omega_i)\, dx, \qquad P(e) = 1 - \int_{-\infty}^{\infty} \max_{i}\, p(x \mid \omega_i)\,P(\omega_i)\, dx\]

    怎么读这两个式子：\(\max\) 与 \(\min\) 是对偶的 —— 第三节说错误率是「较低包络下方的面积」， 这里说正确率是「较高包络下方的面积」，两者加起来恰好是 \(1\) ✓

    数值核对：在本页参数下，上包络面积（正确率）为 \(0.854802\)， \(1\) 减去它得 \(0.145198\)，与 2.7 节的两个尾巴之和完全一致 —— 「正确率 = 1 − 错误率」这条恒等式三种写法数值吻合 ✓ （若用手算：\(0.854802\) 已经包含「\(\omega_1\) 在 \((-\infty,t]\) 上」与 「\(\omega_2\) 在 \([t,\infty)\) 上」两块正确质量，加起来正好是 \(1 - 0.145198\)。）

    0-1 损失一旦被改动，「三者合一」立刻失效

    上面整条等价链的唯一前提就是「判错代价都是 \(1\)」。

    一旦代价不对称，条件风险不再是 \(1 - P(\omega_i\mid x)\)， 最小风险决策会转向代价低的那一侧，此时它与最大后验不再是同一个规则 ⚠

    那时代价高的类宁可被多判几次，也不能漏 —— 这正是下一页 最小风险决策 要处理的事 ✓

    判断自己该用哪一套的方法很简单：问一句「两种错法的后果一样吗」。 一样，就用本页的 \(P(e)\)；不一样，就得用期望风险 ⚠

    七、多类情形的错误率¶

    7.1 多类错误率的写法¶

    两类情形的公式是靠「两个区域 \(R_1, R_2\)」写出来的。 类数变成 \(c\) 以后，思路完全一样：每个类分到一块区域，落在自己区域里才算对。

    \[P(e) = 1 - \sum_{i=1}^{c} P(\omega_i)\int_{R_i} p(x \mid \omega_i)\, dx\]

    逐项解释：

    表达式 它是什么 为什么这么写
    \(R_i\) 第 \(i\) 类的判决区域：落在这里的样本会被判成 \(\omega_i\) 多类时区域不止两个，\(R_1,\dots,R_c\) 互不重叠且覆盖整个空间
    \(\int_{R_i} p(x\mid\omega_i)\,dx\) 第 \(i\) 类的样本恰好落在自己区域里的概率 落在自己区域里 = 判对了 ✓
    \(P(\omega_i)\int_{R_i} p(x\mid\omega_i)\,dx\) 第 \(i\) 类的正确率贡献 先验是权重，因为第 \(i\) 类本来有多常见
    \(\sum_{i=1}^{c}(\cdot)\) 把所有类的正确率贡献加起来 各类互不相容，概率可加 ✓
    \(1 - (\cdot)\) 正确率的补 「判对」与「判错」是互补事件，所以一减就得到错误率 ✓

    换个名字：中间那个求和就是平均分类精度（accuracy）， 本课程课件把它单独写出来。于是这一节的核心恒等式可以记成一句大白话：

    \[P(e) = 1 - \text{平均分类精度}\]

    怎么读这个式子：「错误率 = 1 减正确率」。 听起来像废话，但它的价值在于：多类情形下，「正确」比「错误」好写得多 —— 错误要枚举 \(c(c-1)\) 种「把 \(i\) 判成 \(j\)」的组合， 正确只需要 \(c\) 项 ✓（两类情形下这两种写法本页都见过：第三节的 \(\min\) 与这里的 \(1-\max\)。）

    7.2 多类时没有「一个阈值」这种说法¶

    两类一维问题的判决边界是一个点 \(t\)。 三类一维问题需要两个点，把轴切成三段。三类以上、维度再高， 判决区域就变成了一般形状的区域：

    情形 判决边界的形态 需要几个「边界点」
    两类一维 一个点 \(1\)
    三类一维 两个点 \(2\)（本页例子）
    \(c\) 类一维 \(c-1\) 个点，两端的两段是无界的 \(c-1\)
    \(c\) 类 \(d\) 维 由几个曲面拼成的区域边界 没有「几个点」这种说法了 ⚠

    最后一行要强调：二维以上就没有「阈值」这个方便的概念了。 讲多类问题时，正确的说法是判决区域（decision region）， 而不是「几个阈值」⚠

    还有一个容易想错的地方：多类的判决区域不一定被有界地包住。 以本课程课件里的一个三类例子为例（\(\mu = (0, 4, 7)\)、\(\sigma = (1, 1.5, 1)\)、 先验 \((0.4, 0.35, 0.25)\)，在 \([-8, 16]\) 上逐点比较三类判别函数）， 判决区域分段为：

    判决区域 区间
    \(R_1\)（判 \(\omega_1\)） \([-8.000, 1.798]\) 无界向左延伸
    \(R_2\)（判 \(\omega_2\)） \([1.798, 5.766]\)
    \(R_3\)（判 \(\omega_3\)） \([5.766, 13.034]\)
    \(R_2\)（判 \(\omega_2\) 又出现） \([13.034, 16.000]\) 无界向右延伸

    读这张表：\(R_1 = (-\infty, 1.798]\) 无界，\(R_3 = [5.766, 13.034]\) 有界， \(\omega_2\) 竟然出现在两段上（\([1.798, 5.766]\) 与 \([13.034, \infty)\)）⚠

    为什么 \(\omega_2\) 会被切成两段：\(\omega_2\) 的标准差最大（\(\sigma_2 = 1.5\)， 另外两类都是 \(1.0\)），它的曲线又矮又胖， 左右两条尾巴都盖到了别人的地盘上，于是它的判决区域被挤成了两段。 这是多类问题的一个典型现象：判决区域不是简单按均值顺序排开的 ✓

    7.3 多类错误率怎么算：三步手算流程¶

    多类错误率不需要模拟，也不需要数值积分 —— 手算三步就能走完。 以例题 4 的参数为例（那里有完整的数字），流程是：

    第一步：定区域。 先求出所有判决边界（等方差时相邻两类的边界可用闭式解， 见 4.5 节推广），把轴切成 \(c\) 段（中间某一段可能被挤掉，见 7.2 节的 \(\omega_2\)）。

    第二步：逐类算正确率。 对第 \(i\) 类，算「落在自己区域里」的概率。 端点的类是单尾（一个 \(\Phi\)），中间的类是双尾（两个 \(\Phi\) 相减）。

    第三步：加权求和再取补。 每类的正确率乘上自己的先验，全部相加得平均精度， \(1\) 减精度就是 \(P(e)\)。

    以 7.2 节那个三类例子核对数值（已按上述流程计算，来源：本课程课件）： 三类各自的错判贡献为 \(0.014435\)、\(0.066721\)、\(0.027135\)，相加等于 \(0.108291\)， 与「\(1\) 减去平均精度」完全一致 ✓

    观察 说明
    三类贡献相加 \(= 0.108291\) 验证了 \(1 - \sum_i\) 的公式：逐类错判贡献相加就是总错误率 ✓
    \(\omega_2\) 的贡献占了 \(61.6\%\) 它标准差最大，最容易被判错 —— 与第二节「第二类贡献更多」是同一个道理 ✓

    顺带手算一个量：如果上面的 \(0.108\) 是用 \(200000\) 个样本模拟出来的， 估计值的标准误是多少？按第八节的公式：

    \[\text{SE} \approx \sqrt{\frac{0.108\times 0.892}{200000}} \approx 0.0007\]

    模拟观测到的误差约 \(0.0001\)，比标准误还小，完全正常 ✓

    7.4 两类与多类的公式对照¶

    对比项 两类 多类
    错误率公式 \(P(e) = P(\omega_1)\int_{R_2}p(x\mid\omega_1)dx + P(\omega_2)\int_{R_1}p(x\mid\omega_2)dx\) \(P(e) = 1 - \sum_{i=1}^{c}P(\omega_i)\int_{R_i}p(x\mid\omega_i)dx\)
    正确率写法 \(P(\text{correct}) = \sum_{i=1}^{2}P(\omega_i)\int_{R_i}p(x\mid\omega_i)dx\) 同左，\(i\) 加到 \(c\) ✓
    判决边界的形态 一个点 \(t\) \(c-1\) 个点（一维）；高维是区域边界
    需要枚举的「错法」 \(2\) 种 \(c(c-1)\) 种 ⚠
    两式为什么等价 两类时「判错」就是「判给另一类」 多类时「判错」有 \(c-1\) 种，所以用 \(1-\) 正确率更方便 ✓

    多类错误率不是「两两错误率」的简单相加

    三种类两两之间的关系，不能拼出三类的总错误率。

    反例就是上面那个例子：\(\omega_2\) 的判决区域被切成了两段， 它同时与 \(\omega_1\) 和 \(\omega_3\) 相邻。 如果分别去算「\(\omega_1\) 与 \(\omega_2\) 的两类错误率」和「\(\omega_2\) 与 \(\omega_3\) 的两类错误率」， 再把它们加起来，会得到完全没有意义的数 —— 因为同一个区域会被重复计算 ⚠

    正确做法只有一条：先确定完整的判决区域 \(R_1,\dots,R_c\)，再逐类积自己的正确质量 ✓

    7.5 多类时的「可分性」怎么看¶

    两类时有 \(d' = \Delta/\sigma\) 这样一个干净的判据，多类时就没有了。 但两条直观规律还在（都是前面几节结论的直接推广）：

    规律 两类时的说法 多类时的说法
    类间距离 \(\Delta\) 大就易分 每一对相邻类之间的距离都要够大 ⚠
    类内散布 \(\sigma\) 小就易分 任何一个类的 \(\sigma\) 特别大，都会拖高总错误率（上面的 \(\omega_2\)）⚠

    本课程课件里对这一点有总结性的话：增加具有判别性的特征可以增大类别之间的可分性， 从而改善贝叶斯分类错误率。 注意这里说的是「特征」而不是「分类器」 —— 与 3.4 节的结论一致： 错误率的下界由特征本身含有的区分信息决定 ✓

    八、错误率估计的实践问题¶

    8.1 理论错误率算不出来的原因¶

    前面七节算了十几个 \(P(e)\) 的具体数字，但有一个前提从头到尾没变：

    每一节都假设两类分布是已知的 —— 均值、标准差、先验都写在那里。

    本课程课件在讲「最优下界」时明确提了一句： 贝叶斯错误率通常无法直接计算，只有在分布已知（如高斯）、低维、形式简单时， 才能写出解析表达式 ⚠

    为什么实际做不到：

    需要什么 实际有什么 后果
    真实的 \(p(x \mid \omega_i)\) 只有一堆样本 不知道真实密度，\(P(e)\) 无从积分 ⚠
    真实的先验 \(P(\omega_i)\) 样本比例（还不准） 先验本身也是估的 ⚠
    真实的判决区域 \(R_i\) 训练出来的分类器给出一个近似区域 区域与真实的最优区域有差距 ⚠

    所以实际的做法是：拿一个测试集， 把分类器在上面跑一遍，数一数错了几个，用比例当错误率的估计。 这就是下一小节的内容 ✓

    8.2 测试集错误率是一个随机变量¶

    这一点很关键，而且最容易被忽略：

    \[\hat{p} = \frac{\text{测试集中分错的样本数}}{N}\]

    分子是一个随机变量（换一个测试集，错的个数就会变）， 所以 \(\hat{p}\) 也是随机变量。它有自己的分布、自己的期望、自己的标准差 ⚠

    它的期望是多少：如果测试集是从真实分布里独立同分布地抽出来的， 而分类器是固定的（不是在这个测试集上训练的）， 那么每一个样本被分错的概率都是真实的 \(p = P(e)\)，于是

    \[\mathbb{E}[\hat{p}] = p\]

    它的标准差是多少：错的个数服从二项分布 \(B(N, p)\)。 这里把「为什么是 \(\sqrt{p(1-p)/N}\)」完整推一遍，考试可能会考：

    第 1 步：设第 \(i\) 个样本的错判指示变量为 \(X_i\)， 错记为 \(1\)、记对为 \(0\)。每个 \(X_i\) 都是伯努利变量： \(X_i = 1\) 的概率是 \(p\)，\(X_i = 0\) 的概率是 \(1-p\)。

    第 2 步：单个伯努利变量的期望与方差。期望是

    \[\mathbb{E}[X_i] = 1\times p + 0\times(1-p) = p\]

    方差的定义是 \(\mathrm{Var}(X_i) = \mathbb{E}[X_i^2] - \big(\mathbb{E}[X_i]\big)^2\)。 先算 \(\mathbb{E}[X_i^2]\)：因为 \(X_i\) 只取 \(0\) 或 \(1\)，所以 \(X_i^2 = X_i\)， 于是 \(\mathbb{E}[X_i^2] = \mathbb{E}[X_i] = p\)。代回定义：

    \[\mathrm{Var}(X_i) = p - p^2 = p(1-p)\]

    第 3 步：总错判个数是 \(K = X_1 + \cdots + X_N\)，它的期望是

    \[\mathbb{E}[K] = N\,\mathbb{E}[X_i] = Np\]

    第 4 步：样本互相独立，所以方差相加：

    \[\mathrm{Var}(K) = N\,\mathrm{Var}(X_i) = Np(1-p)\]

    第 5 步：比例估计 \(\hat{p} = K / N\)，常数因子 \(1/N\) 提出方差时要平方：

    \[\mathrm{Var}(\hat{p}) = \frac{\mathrm{Var}(K)}{N^2} = \frac{p(1-p)}{N}\]

    开方，就得到标准误：

    \[\text{SE}(\hat{p}) = \sqrt{\frac{p\,(1-p)}{N}}\]

    这说明什么：标准误只由 \(p\) 和 \(N\) 决定，与分布的形状无关。 \(p = 0.5\) 时 \(p(1-p)\) 最大，此时 SE 最大； \(p\) 很接近 \(0\) 或 \(1\) 时 SE 会小一些 ✓

    它有两层含义：

    含义 说法
    「\(\hat{p}\) 抖动的幅度」 重复抽很多次测试集，\(\hat{p}\) 大约在 \(p \pm \text{SE}\) 里晃 ✓
    「\(N\) 到底够不够」 SE 与 \(\sqrt{N}\) 成反比，样本翻四倍才能把 SE 减半 ⚠

    8.4 为什么不能用 100 个样本判断两个模型谁更好¶

    这是本页最实用的一条结论，值得单独推一遍。

    问题设定：模型 A 的真实错误率是 \(0.15\)，模型 B 是 \(0.13\)， B 真的更好。用 \(N = 100\) 的测试集去比，能不能选对？

    第一步：弄清楚两个估计值的抖动幅度。 两个模型在同一个测试集上评估，误差是相关的； 但为了得到数量级上的直觉，先按独立来估（这给出一个乐观的上界）：

    \[\text{SE}(\hat{p}_A) = \sqrt{\frac{0.15\times 0.85}{100}} \approx 0.0357, \qquad \text{SE}(\hat{p}_B) = \sqrt{\frac{0.13\times 0.87}{100}} \approx 0.0336\]

    第二步：看差值。 两个估计值之差 \(\hat{p}_A - \hat{p}_B\) 的真实值是 \(0.15 - 0.13 = 0.02\)， 它的标准误约为

    \[\text{SE}(\hat{p}_A - \hat{p}_B) \approx \sqrt{0.0357^2 + 0.0336^2} \approx 0.0490\]

    第三步：比一比「信号」和「噪声」。

    \[\frac{\text{真实差距}}{\text{差值的标准误}} \approx \frac{0.02}{0.0490} \approx 0.41\]

    结论：真实差距只有噪声的不到一半。 也就是说，\(\hat{p}_A - \hat{p}_B\) 这个量很容易翻符号 —— 测试集上看起来 A 更好，完全是随机波动造成的

    8.3 节的实验给了一致的答案：\(2000\) 次重复中， 「测试集上表现更好的那个恰好是真正更好的 B」的比例只有 \(0.6295\) —— 有 \(37\%\) 的概率选错。

    差多少才够：要让差值的方向基本可靠（比如「真实差距 ≥ 2 倍标准误」）， 在 \(p \approx 0.15\) 附近大约需要

    \[0.02 \ge 2\sqrt{\frac{2\times 0.15\times 0.85}{N}} \;\Longrightarrow\; N \ge \frac{8\times 0.15\times 0.85}{0.02^2} \approx 2550\]

    怎么读这个结果：要可靠地区分错误率 \(0.15\) 与 \(0.13\) 的两个模型， 测试集规模至少要两千多。 换成一个直观的说法：\(100\) 个样本只够分辨「好坏差好几倍」的模型， 不够分辨「差了十几个百分点」的模型 ⚠

    测试集不能拿去调参数，否则估计会变乐观

    \(\text{SE} = \sqrt{p(1-p)/N}\) 的推导用了一个前提： 分类器与测试集是独立的 —— 分类器没看过这些测试样本 ✓

    如果反复用测试集来挑阈值、选特征、比模型， 那么被选中的那个模型恰好在这批样本上运气好， 它的测试错误率会系统性低于真实错误率 ⚠

    这不是「估计得不够准」，而是「估计有偏」—— 再增加 \(N\) 也救不回来，因为偏差来自「选择」这个动作本身。

    正确做法是把数据分成三份：训练集（拟合参数）、 验证集（调阈值、选模型）、测试集（只在最后报一次数）✓ \(N\) 再小的问题，也是「多留一份验证集」比「把测试集用两遍」更值得 ⚠

    用途 说明

    造数据做实验 像本页这样，先设定分布、算出真值，再看估计方法靠不靠谱 ✓

    典型例题¶

    例题 1：把两项错误率与它们的占比算出来¶

    沿用本页参数（\(\mu_1=15,\sigma_1=3,P(\omega_1)=0.6\)； \(\mu_2=22,\sigma_2=4,P(\omega_2)=0.4\)；\(t = 19.134613\)）， 分别算出两类被错判的概率，并说明哪一类被错判得更多。

    思路

    先说清做法：两项分别是「\(\omega_1\) 越过 \(t\) 向右」与「\(\omega_2\) 越过 \(t\) 向左」。 每一类都要先标准化，再查 \(\Phi\)，最后乘上自己的先验。

    注意两个尾巴取 \(\Phi\) 的方式不一样，这是最容易错的一步。

    解答

    第一步：算两个标准化量。 标准化就是「减均值再除标准差」。

    \[z_1 = \frac{t - \mu_1}{\sigma_1} = \frac{19.134613 - 15}{3} = \frac{4.134613}{3} \approx 1.378204\]
    \[z_2 = \frac{t - \mu_2}{\sigma_2} = \frac{19.134613 - 22}{4} = \frac{-2.865387}{4} \approx -0.716347\]

    第二步：算两个尾巴概率。

    尾巴 算式 数值
    \(\omega_1\) 落在 \([t,\infty)\) \(1 - \Phi(1.378204) = 1 - 0.915930\) \(0.084070\)
    \(\omega_2\) 落在 \((-\infty,t]\) \(\Phi(-0.716347)\) \(0.236889\)

    怎么读这两行：第一行是「\(\omega_1\) 的样本有多大比例跑到边界右边」， 第二行是「\(\omega_2\) 的样本有多大比例跑到边界左边」。 第二行明显更大（\(0.2369\) 对 \(0.0841\)），约是它的 \(2.8\) 倍。

    第三步：乘先验，得到两项错判概率。

    项 算式 数值 占 \(P(e)\) 的比例
    \(\omega_1\) 被错判 \(0.6 \times 0.084070\) \(0.050442\) \(34.74\%\)
    \(\omega_2\) 被错判 \(0.4 \times 0.236889\) \(0.094756\) \(65.26\%\)
    总错误率 两项相加 \(\mathbf{0.145198}\) \(100\%\)

    第四步：回答「哪一类被错判得更多」。 \(\omega_2\) 被错判得更多， 它贡献了总错误率的约 \(65\%\)。原因有两个：

    原因 具体说明
    \(\sigma_2 = 4\) 比 \(\sigma_1 = 3\) 大 第二类曲线更胖，越界的尾巴更重
    \(P(\omega_1) = 0.6 \gt P(\omega_2)\) 边界被推向 \(\omega_2\) 一侧，\(\omega_2\) 的区域被压窄

    但要注意：尾巴比例的 \(2.8\) 倍在乘上先验后缩到了 \(1.88\) 倍， 因为 \(\omega_2\) 的先验更小（\(0.4\) 对 \(0.6\)）。

    实践结论：想降总错误率，改进 \(\omega_2\) 的分布比改进 \(\omega_1\) 更划算 ✓

    例题 2：用可分性判据做设计¶

    某两类的特征服从一维高斯，\(\mu_1 = 10\)、\(\mu_2 = 16\)、\(\sigma_1 = \sigma_2 = 2\)， 先验相等。 （1）求判决边界与平均错误率。 （2）若要求错误率不超过 \(1\%\)，在 \(\Delta = 6\) 不变的前提下，标准差要压到多少？

    思路

    等方差 + 等先验，可以直接用 4.5 节的闭式解，不必做数值积分。 第二问是反问题：把 \(d'\) 的目标值解出来，再除以距离。

    提示：\(d' = \Delta/\sigma\)，所以固定 \(\Delta\) 时 \(\sigma\) 与 \(d'\) 成反比。

    解答

    第一问第 1 步：求边界。 等方差等先验 → 边界在两个均值的中点：

    \[t = \frac{\mu_1 + \mu_2}{2} = \frac{10 + 16}{2} = 13.000000\]

    第一问第 2 步：算两个标准化量。

    \[z_1 = \frac{13 - 10}{2} = 1.5, \qquad z_2 = \frac{13 - 16}{2} = -1.5\]

    第一问第 3 步：算错误率。

    \[P(e) = \frac{1}{2}\big[1 - \Phi(1.5)\big] + \frac{1}{2}\Phi(-1.5) = \Phi(-1.5) \approx 0.066807\]

    （因为 \(\Phi(-1.5) = 1 - \Phi(1.5) = 1 - 0.933193 = 0.066807\)，两项合并。）

    第一问第 4 步：用 \(d'\) 核对。

    \[d' = \frac{\Delta}{\sigma} = \frac{6}{2} = 3.0, \qquad P(e) = \Phi\!\left(-\frac{3.0}{2}\right) = \Phi(-1.5) \approx 0.066807 ✓\]

    第二问：反解 \(d'\)。 从 \(P(e) = \Phi(-d'/2) \le 0.01\) 出发， 两边取 \(\Phi^{-1}\)（它是单调递增的，所以不等号方向不变）：

    \[-\frac{d'}{2} \le \Phi^{-1}(0.01) = -2.326348\]

    两边乘 \(-2\)（乘负数要变不等号方向）：

    \[d' \ge 2 \times 2.326348 = 4.652696\]

    现在固定 \(\Delta = 6\)，由 \(d' = \Delta/\sigma \ge 4.652696\) 解出

    \[\sigma \le \frac{\Delta}{d'} = \frac{6}{4.652696} \approx 1.289575\]

    结论：现在的 \(\sigma = 2\) 要压到约 \(1.29\) 以下， 也就是标准差要缩小约 \(36\%\)，才能把错误率从 \(6.68\%\) 压到 \(1\%\) ✓

    怎么读这个结论：把它翻成大白话 —— 「光把两类中心拉远 \(6\) 个单位还不够，类内波动必须一起压下去」。 这也解释了为什么特征工程里「降低类内方差」和「拉大类间距离」同等重要 ✓

    例题 3：先验悬殊时，中点不再是最优边界¶

    两类一维高斯：\(\mu_1 = 0\)、\(\mu_2 = 3\)、\(\sigma_1 = \sigma_2 = 1\)， 但先验不相等：\(P(\omega_1) = 0.75\)、\(P(\omega_2) = 0.25\)。 （1）求最优判决边界与错误率。 （2）若误用两类均值中点当边界，错误率会差多少？

    思路

    这是「等方差但先验不等」的情形，闭式解仍然存在， 但要多带一个先验项：\(t = \frac{\mu_1+\mu_2}{2} + \frac{\sigma^2}{\mu_2-\mu_1}\ln\frac{P(\omega_1)}{P(\omega_2)}\)。

    注意 \(\ln\) 里的分子分母要和 \(\mu_2-\mu_1\) 的符号配套， 否则边界会跑错方向。算完再用「先验大的类区域更大」检查一遍。

    解答

    第一问第 1 步：算先验比的对数。

    \[\ln\frac{P(\omega_1)}{P(\omega_2)} = \ln\frac{0.75}{0.25} = \ln 3 \approx 1.098612\]

    第一问第 2 步：代进边界公式。 等方差时 \(\sigma_1 = \sigma_2 = \sigma = 1\)， \(\mu_2 - \mu_1 = 3\)，所以修正项的系数是 \(\frac{\sigma^2}{\mu_2-\mu_1} = \frac{1}{3}\)：

    \[t = \frac{0 + 3}{2} + \frac{1}{3}\times 1.098612 = 1.5 + 0.366204 = 1.866204\]

    检查方向：\(P(\omega_1) = 0.75\) 更大，所以 \(\omega_1\) 的区域应该更大， 边界应该朝 \(\omega_2\) 移动（往右）。\(t = 1.866204 \gt 1.5\) ✓ 方向正确。

    第一问第 3 步：算两个标准化量。

    \[z_1 = \frac{1.866204 - 0}{1} = 1.866204, \qquad z_2 = \frac{1.866204 - 3}{1} = -1.133796\]

    第一问第 4 步：算错误率。

    \[P(e) = 0.75\big[1 - \Phi(1.866204)\big] + 0.25\,\Phi(-1.133796)\]
    项 算式 数值
    尾巴 1 \(1 - \Phi(1.866204) = 1 - 0.968994\) \(0.031006\)
    尾巴 2 \(\Phi(-1.133796)\) \(0.128440\)
    项 1 \(0.75 \times 0.031006\) \(0.023255\)
    项 2 \(0.25 \times 0.128440\) \(0.032110\)
    \(P(e)\) 两项相加 \(\mathbf{0.055365}\)

    第二问：误用中点的代价。 取 \(t = 1.5\)，则 \(z_1 = 1.5\)、\(z_2 = -1.5\)， 于是

    \[P(e) = 0.75\big[1 - \Phi(1.5)\big] + 0.25\,\Phi(-1.5) = 0.75 \times 0.066807 + 0.25 \times 0.066807 = 0.066807\]

    （最后一步因为 \(1 - \Phi(1.5) = \Phi(-1.5)\)，两项合并成 \(\Phi(-1.5)\)。）

    相差：\(0.066807 - 0.055365 = 0.011442\)， 也就是说误用中点会让错误率高出约 \(20.67\%\) ⚠

    结论：先验 \(3:1\) 悬殊的时候，「取中点」这个经验做法会让错误率高出两成。 先验越不均衡，中点的偏差越大 ⚠ （对照 4.4 节的表格：\(P(\omega_1)\) 从 \(0.5\) 涨到 \(0.99\) 时， 边界从 \(18.48\) 一路挪到 \(24.57\)，早就离中点很远了。）

    例题 4：三类问题¶

    三类一维高斯，\(\mu_1 = 0\)、\(\mu_2 = 2\)、\(\mu_3 = 5\)， \(\sigma_1 = \sigma_2 = \sigma_3 = 1\)，先验 \(P(\omega_1) = 0.5\)、\(P(\omega_2) = 0.3\)、\(P(\omega_3) = 0.2\)。 求两条判决边界、逐类正确率与平均错误率。

    思路

    等方差多类时，每一对相邻类之间的边界可以单独用等方差闭式解求出来， 但要注意先验的下标配对。

    顺序是：先求两个边界点，再用它们把轴切成三段； 每段积分得到该类的正确率，加权求和就是精度，\(1\) 减精度就是错误率。

    解答

    第一步：求第一条边界（\(\omega_1\) 与 \(\omega_2\) 之间）。 等方差闭式解

    \[t_{12} = \frac{\mu_1+\mu_2}{2} + \frac{\sigma^2}{\mu_2-\mu_1}\ln\frac{P(\omega_1)}{P(\omega_2)}\]

    代入：\(\frac{\mu_1+\mu_2}{2} = 1\)，\(\frac{\sigma^2}{\mu_2-\mu_1} = \frac{1}{2}\)， \(\ln\frac{0.5}{0.3} = \ln 1.666667 \approx 0.510826\)

    \[t_{12} = 1 + \frac{1}{2}\times 0.510826 = 1 + 0.255413 = 1.255413\]

    第二步：求第二条边界（\(\omega_2\) 与 \(\omega_3\) 之间）。 \(\frac{\mu_2+\mu_3}{2} = 3.5\)，\(\frac{\sigma^2}{\mu_3-\mu_2} = \frac{1}{3}\)， \(\ln\frac{0.3}{0.2} = \ln 1.5 \approx 0.405465\)

    \[t_{23} = 3.5 + \frac{1}{3}\times 0.405465 = 3.5 + 0.135155 = 3.635155\]

    检查顺序：\(t_{12} = 1.255413 \lt t_{23} = 3.635155\) ✓ 两个边界不交叉，三段区域才成立。 如果算出来 \(t_{12} \gt t_{23}\)，说明中间那一类的区域被挤掉了， 这时要回头检查先验是否写错 ⚠

    第三步：算逐类正确率。 三段区域是 \(R_1 = (-\infty, t_{12}]\)、\(R_2 = (t_{12}, t_{23}]\)、\(R_3 = (t_{23}, \infty)\)。

    类 正确率算式 标准化变量 数值
    \(\omega_1\) \(1 - \Phi\!\left(\frac{t_{12}-\mu_1}{1}\right) = 1 - \Phi(1.255413)\) \(1.255413\) \(0.104664\)
    \(\omega_2\) \(\Phi\!\left(\frac{t_{23}-\mu_2}{1}\right) - \Phi\!\left(\frac{t_{12}-\mu_2}{1}\right) = \Phi(1.635155) - \Phi(-0.744587)\) \(1.635155\)，\(-0.744587\) \(0.720731\)
    \(\omega_3\) \(1 - \Phi\!\left(\frac{t_{23}-\mu_3}{1}\right) = 1 - \Phi(-1.364845)\) \(-1.364845\) \(0.913849\)

    怎么读中间那一行：\(\omega_2\) 的正确率是「落在 \(R_2\) 里」的概率， 而 \(R_2\) 是中间一段，所以要用两个 \(\Phi\) 相减 （上界减下界）。这是三类与两类最大的书写差别 ✓

    第四步：加权求精度。

    类 \(P(\omega_i)\) 正确率 贡献
    \(\omega_1\) \(0.5\) \(0.104664\) \(0.05233224\)
    \(\omega_2\) \(0.3\) \(0.720731\) \(0.21621932\)
    \(\omega_3\) \(0.2\) \(0.913849\) \(0.18276982\)
    平均分类精度 \(\mathbf{0.45132138}\)

    第五步：\(1\) 减精度。

    \[P(e) = 1 - 0.45132138 = \mathbf{0.54867862}\]

    这个数字大得吓人，为什么：\(\omega_1\) 的正确率只有 \(0.105\) —— 也就是说九成的 \(\omega_1\) 样本都被判错了 ⚠

    原因看边界位置：\(\omega_2\) 的先验（\(0.3\)）只是略小于 \(\omega_1\)（\(0.5\)）， 但 \(\omega_1\) 与 \(\omega_2\) 的均值只差 \(2\)（一个标准差）， 两类几乎完全重叠。先验的优势不足以抵消重叠， 于是 \(\omega_1\) 的一大块被划给了 \(\omega_2\)。

    这正好印证了第三节的几何结论：错误率由重叠程度决定， 当重叠严重时（\(d'\) 只有 \(2\)），总错误率必然很高 ✓

    最后核对一下公式：三类错判贡献 \(0.5 \times (1-0.104664) = 0.447668\)、 \(0.3 \times (1-0.720731) = 0.083781\)、 \(0.2 \times (1-0.913849) = 0.017230\)， 三者相加 \(= 0.548679\)，与 \(1 - \text{精度}\) 完全一致 ✓ 这说明第七节的公式 \(P(e) = 1 - \sum_i P(\omega_i)\int_{R_i}p(x\mid\omega_i)dx\) 与「逐类错判贡献相加」是同一件事 ✓

    自测¶

    Q1 沿用本页参数（\(\mu_1=15,\sigma_1=3\)、\(\mu_2=22,\sigma_2=4\)）， 但把先验从 \(0.6/0.4\) 改成 \(0.5/0.5\)。 新的判决边界与新的平均错误率分别是多少？错误率是升了还是降了？为什么这个方向和直觉相反？

    提示

    方差仍然不等，所以不能用中点公式直接当答案， 要用 2.6 节的判决函数 \(g(x) = 0\) 解出新的边界。

    思路：先解出新边界，再代两项尾巴公式。

    解答

    第一步：求新边界。 判据仍然是 \(g(x) = 0\)，只是 \(\ln\frac{P(\omega_2)}{P(\omega_1)}\) 从 \(\ln\frac{0.4}{0.6}\) 变成 \(\ln\frac{0.5}{0.5} = 0\)。 用二分法在 \([16, 30]\) 上求解，得到

    \[t_{\text{新}} \approx 18.4834\]

    检查方向：先验变得均衡（\(0.5\) 对 \(0.5\) 时 \(\omega_1\) 不再占优）， 边界从 \(19.134613\) 左移到 \(18.4834\) ✓ 这与「边界朝先验小的类移动」一致 —— 之前 \(\omega_2\) 是少数类， 现在两类平权，边界就该往中间退。

    第二步：算新错误率。 用两项尾巴公式，标准化后查表：

    \[z_1 = \frac{18.4834-15}{3} \approx 1.1611, \qquad 1 - \Phi(z_1) = 1 - 0.877256 = 0.122744\]
    \[z_2 = \frac{18.4834-22}{4} \approx -0.8791, \qquad \Phi(z_2) = 0.189710\]
    项 算式 数值
    项 1 \(0.5 \times 0.122744\) \(0.061372\)
    项 2 \(0.5 \times 0.189710\) \(0.094855\)
    \(P(e)\) 相加 \(\mathbf{0.156227}\)

    第三步：比较方向。 \(0.156227 \gt 0.145198\)， 也就是说先验变均衡以后，总错误率反而升高了。

    为什么是升：原来的 \(0.6/0.4\) 先验让边界偏向 \(\omega_2\)， 牺牲了少数类的一小块、换来了多数类的一大块 —— 从「按先验加权的平均错误率」这个目标看，这是划算的 ✓

    均衡先验下边界退回 \(18.4834\)，\(\omega_2\) 的那块地要回来了一些， 于是 \(\omega_2\) 的错判少了、\(\omega_1\) 的错判多了， 净效果是总量上升 —— 因为这次「交换」不再有先验优势做补贴 ⚠

    为什么和直觉相反：很多人觉得「两类一样常见 = 最公平 = 最好」。 公平是对两类各自的错判率说的，不是对总错误率说的。 总错误率是一个加权和，权重变了，「最优」的位置自然就变 ✓

    Q2 两类一维高斯：\(\mu_1 = 0\)、\(\mu_2 = 4\)、\(\sigma_1 = \sigma_2 = 1\)，先验各 \(0.5\)。 （1）求 \(d'\) 与 \(P(e)\)。 （2）若要把 \(P(e)\) 压到 \(5\%\) 以内，\(d'\) 至少要多大？ 在 \(\Delta = 4\) 不变的前提下，\(\sigma\) 要压到多少以下？

    提示

    等方差等先验，直接查 4.5 节的闭式解 \(P(e) = \Phi(-d'/2)\)。

    第二问是反问题：先用 \(\Phi^{-1}(0.05)\) 求出需要的 \(-d'/2\)， 再反解 \(d'\)，最后用 \(d' = \Delta/\sigma\) 换成对 \(\sigma\) 的要求。

    解答

    第一问： 先算可分性判据。

    \[d' = \frac{\Delta}{\sigma} = \frac{\lvert 0 - 4\rvert}{1} = 4.0\]

    代进闭式解：

    \[P(e) = \Phi\!\left(-\frac{4.0}{2}\right) = \Phi(-2.0) \approx 0.022750\]

    也就是约 \(2.28\%\)。

    第二问第 1 步：反解需要的 \(z\) 值。 要求 \(\Phi(-d'/2) \le 0.05\)。 记 \(z = -d'/2\)，则要求 \(\Phi(z) \le 0.05\)。 因为 \(\Phi\) 单调递增，取 \(\Phi^{-1}\) 后不等号方向不变：

    \[z \le \Phi^{-1}(0.05) \approx -1.644854\]

    所以 \(-d'/2 \le -1.644854\)，两边乘 \(-2\)（乘负数要翻不等号），得

    \[d' \ge 2 \times 1.644854 = 3.289707\]

    第二问第 2 步：换成对 \(\sigma\) 的要求。 固定 \(\Delta = 4\)， 由 \(d' = \Delta/\sigma \ge 3.289707\) 得

    \[\sigma \le \frac{4}{3.289707} \approx 1.215944\]

    结论：当前 \(P(e) = 2.275\%\) 本来就低于 \(5\%\)， 所以这一问的实际意义是反向的 —— 它告诉你还有多少余量：\(\sigma\) 可以从 \(1.0\) 放宽到约 \(1.216\) （放宽约 \(22\%\)）而仍然满足 \(5\%\) 的要求 ✓

    注意这里的措辞：\(d' = 4.0\) 已经超过了 \(3.289707\) 这个门槛， 所以结论是「有余量」而不是「不达标」。 做这类反问题时一定要把算出来的要求与当前值比较一遍， 否则容易出现「解出了一个更大的数却说是改进」的错误 ⚠

    第一步：算两个标准化量。

    第二步：算两个尾巴。

    量 算式 数值
    \(1 - \Phi(1.666667)\) \(1 - 0.952210\) \(0.047790\)
    \(\Phi(-0.5)\) 查表 \(0.308538\)

    项 算式 数值

    第五步：这说明什么性质。 边界从 \(19.134613\) 挪到了 \(20.0\)， 挪动了 \(0.8654\)（相当于 \(\sigma_1\) 的 \(0.29\) 倍，不算小）， 但错误率只上升了 \(0.006892\)（绝对值），相对上升不到 \(5\%\) ✓

    Q4 用 \(N = 200\) 的测试集比较两个模型： 模型 1 的真实错误率 \(p_1 = 0.15\)，模型 2 的真实错误率 \(p_2 = 0.12\)。 （1）两个估计值的标准误各是多少？ （2）真实差距「差距 / 差值的标准误」是多少？ （3）要让差距达到 \(2\) 倍标准误，测试集至少要多大？

    提示

    单个估计值的标准误是 \(\sqrt{p(1-p)/N}\)； 两个估计值之差的标准误按独立近似是 \(\sqrt{\text{SE}_1^2 + \text{SE}_2^2}\)。

    第三问把「差距 = 2 × 差值标准误」当成方程解 \(N\)。

    解答

    第一问：两个标准误。 代 \(\text{SE} = \sqrt{p(1-p)/N}\)，\(N = 200\)：

    \[\text{SE}_1 = \sqrt{\frac{0.15\times 0.85}{200}} = \sqrt{\frac{0.1275}{200}} = \sqrt{0.000638} \approx 0.025249\]
    \[\text{SE}_2 = \sqrt{\frac{0.12\times 0.88}{200}} = \sqrt{\frac{0.1056}{200}} = \sqrt{0.000528} \approx 0.022978\]
    量 数值
    \(\text{SE}_1\) \(0.025249\)
    \(\text{SE}_2\) \(0.022978\)

    第二问：差值的标准误与比值。 两个估计值之差的标准误（按独立近似）：

    \[\text{SE}_{\text{差}} = \sqrt{0.025249^2 + 0.022978^2} = \sqrt{0.000638 + 0.000528} \approx 0.034139\]

    真实差距是 \(0.15 - 0.12 = 0.03\)，于是

    \[\frac{\text{真实差距}}{\text{SE}_{\text{差}}} = \frac{0.03}{0.034139} \approx 0.8787\]

    怎么读这个数：真实差距还不到差值标准误的 \(0.9\) 倍 ⚠ 如果按正态近似，用这批数据判断「谁更好」的成功率只有 \(\Phi(0.8787) \approx 0.8102\) —— 大约有 \(19\%\) 的概率会选错模型。

    第三问：反解 \(N\)。 要求

    \[\frac{p_1 - p_2}{\text{SE}_{\text{差}}} \ge 2\]

    把 \(\text{SE}_{\text{差}} = \sqrt{\dfrac{p_1(1-p_1)}{N} + \dfrac{p_2(1-p_2)}{N}} = \sqrt{\dfrac{p_1(1-p_1)+p_2(1-p_2)}{N}}\) 代进去，两边平方：

    \[\frac{(p_1-p_2)^2}{\dfrac{p_1(1-p_1)+p_2(1-p_2)}{N}} \ge 4 \;\Longrightarrow\; N \ge \frac{4\big[p_1(1-p_1)+p_2(1-p_2)\big]}{(p_1-p_2)^2}\]

    代入 \(p_1(1-p_1) = 0.1275\)、\(p_2(1-p_2) = 0.1056\)、\((p_1-p_2)^2 = 0.0009\)：

    \[N \ge \frac{4\times(0.1275 + 0.1056)}{0.0009} = \frac{4\times 0.2331}{0.0009} \approx 1036\]

    结论：\(200\) 个样本远远不够，至少要一千量级的测试集， 才能有把握地说出「模型 1 比模型 2 差」

    这也和第八节的实验对得上：那里用 \(100\) 个样本比较 真实差距 \(0.02\) 的两个模型，选错的概率高达 \(37\%\)

    一个细节：如果图省事，把两个 \(p(1-p)\) 都用较大的 \(p_1(1-p_1) = 0.1275\) 代替， 得到更保守的 \(N \ge \frac{8\,p_1(1-p_1)}{(p_1-p_2)^2} = \frac{8\times 0.1275}{0.0009} \approx 1134\)。 两种写法都是量级估计，结论完全一致： 需要一个一千量级的测试集

    再强调一次：这些数字都建立在「测试集与分类器独立」的前提上。 如果测试集被反复拿来调参，估计值会系统性偏乐观， 增加 \(N\) 也修不好

    小结¶

    要记住的 为什么
    两类错误率 \(P(e) = P(\omega_1)\int_t^{\infty}p(x\mid\omega_1)dx + P(\omega_2)\int_{-\infty}^{t}p(x\mid\omega_2)dx\) 两项方向相反，分别对应两类各越过一次边界 ✓
    本页数值：\(t = 19.134613\)，\(P(e) = 0.145198\) 两项贡献 \(0.050442\) 与 \(0.094755\)，第二类占 \(65\%\) ✓
    两项的相对大小由「尾巴质量 × 先验」共同决定 尾巴比例差 \(2.8\) 倍，乘先验后缩到 \(1.88\) 倍 ✓
    几何解释：\(P(e) = \int\min[q_1(x), q_2(x)]dx\) 较低包络下方的总面积；与两个尾巴之和数值完全一致 ✓
    重叠面积与判决边界无关 所以它是正确的下界；换分类器、换算法都降不下去 ⚠
    均值距离变大 → 错误率下降 高斯尾部按 \(e^{-z^2/2}\) 衰减，收益是指数级的 ✓
    标准差变大 → 错误率上升 曲线变胖、重叠变大，只能靠换特征救 ⚠
    先验悬殊 → 总错误率下降、少数类错判率上升 边界被推向少数类；总错误率好看不等于分类器好用 ⚠
    等方差等先验闭式解 \(P(e) = \Phi\!\left(-\frac{\Delta}{2\sigma}\right)\) 推导用到 \(\Phi(-z) = 1-\Phi(z)\) 的对称性 ✓
    可分性判据 \(d' = \frac{\lvert\mu_1-\mu_2\rvert}{\sigma}\) 无量纲，只由特征决定，是衡量「特征好不好」的指标 ✓
    要错误率 ≤ 1%，需 \(d' \ge 4.652696\) 通用反解公式 \(d' \ge -2\Phi^{-1}(p_0)\) ✓
    \(X^*\) 不是最优决策点，\(X_B\) 才是 \(X_B\) 就是两条加权密度曲线的交点，即贝叶斯边界 ✓
    候选阈值扫描的最小点就是 \(X_B\) 2.10 节手算表里 \(P(e)\) 最小的一行正是 \(t = 19.134613\) ✓
    错误率在最优值附近非常平坦 边界挪 \(0.87\) 只多 \(0.0069\)；挪到 \(t = 15\) 会多 \(0.17\) ⚠
    0-1 损失下三者合一 条件风险 \(\sum_{j\neq i}P(\omega_j\mid x) = 1 - P(\omega_i\mid x)\) = 条件错误率 ✓
    代价不对称时三者不再合一 那就要用下一页的期望风险，边界会朝代价高的那侧退让 ⚠
    多类错误率 \(P(e) = 1 - \sum_{i=1}^{c}P(\omega_i)\int_{R_i}p(x\mid\omega_i)dx\) 多类时「正确」比「错误」好写；等于 \(1\) 减平均分类精度 ✓
    多类不能用「一个阈值」描述 一维要 \(c-1\) 个边界点；高维是判决区域，且区域可能分成两段 ⚠
    多类错误率不是两两错误率之和 相邻关系会重复计算，必须先把完整的 \(R_1,\dots,R_c\) 定下来 ✓
    理论错误率需要真实分布已知 实际做不到，所以本课程课件说它「通常无法直接计算」⚠
    测试集错误率是随机变量 标准误 \(\sqrt{p(1-p)/N}\)，与 \(\sqrt{N}\) 成反比 ✓
    不能用 100 个样本判断两个模型谁更好 \(p=0.15\) 与 \(0.13\) 的真实差距只有噪声的 \(0.41\) 倍 ⚠
    测试集不能反复用来调参 会让估计有偏，加 \(N\) 也修不好 ⚠
