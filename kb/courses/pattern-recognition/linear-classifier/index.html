    线性分类器设计¶

    上一页 非参数方法 走的是一条「不假设分布形状」的路： 用样本邻域里的密度估计直接做判决，边界的形状完全由数据自己长出来。

    这一页换一条路：先把边界的形状规定死，再让数据去确定它的参数。 把形状规定成最简单的那一种 —— 直线、平面、超平面 —— 就是线性分类器。

    为什么先学线性的 —— 本课程课件给了三条理由，都值得记住：

    • 参数最少 —— \(d\) 维特征只要 \(d+1\) 个参数，样本少也估得动
    • 性质最好证 —— 判别函数是线性的，凸性、唯一性、收敛性都有严格结论
    • 是一切推广的起点 —— 支持向量机、线性判别分析、单层网络都是它的直接后代

    这一页的主线

    整页只做一件事：给「一条直线」定参数。

    围绕这件事会走五步：

    1. 先说清几何意义：法向量定方向、偏置定位置
    2. 再把偏置吸收进权向量（增广写法），形式统一成内积
    3. 再把「直线」推广成「弯曲的边界」（广义线性判别函数）
    4. 然后给三种设计准则：感知器、松弛、最小二乘
    5. 最后讲多类扩展与线性方法的硬边界（异或问题）

    五个步骤里，第四步是重点，也是本页代码全部集中的地方。

    一、判别函数与超平面的几何意义¶

    1.1 两类的线性判别函数¶

    定义（两类问题，\(\omega_1\) 与 \(\omega_2\)）：

    \[g(x) = \boldsymbol{w}^{\mathsf T}x + b\]

    判决规则：\(g(x) \gt 0\) 判 \(\omega_1\)，\(g(x) \lt 0\) 判 \(\omega_2\)， \(g(x) = 0\) 落在边界上（按约定归入任一类，或作为拒识点）。

    符号说明（这张表要背下来，后面每一节都在用它）：

    符号 类型 含义 作用
    \(\boldsymbol{w}\) \(d\) 维列向量 权向量 决定超平面的方向 ✓
    \(b\) 标量 偏置（阈值） 决定超平面的位置 ✓
    \(g(x)\) 标量 判别函数值 符号给类别，绝对值给「把握」
    \(d\) 标量 特征维数 与 \(\boldsymbol{w}\) 的分量个数相同

    先看一张图，把「判别函数」与「决策面」的对应关系钉在脑子里：

    上图画的是一维特征的退化情形：横轴是特征 \(x\)，纵轴是判别函数值 \(g(x)\)。 判别函数是一条直线，它与横轴的交点就是分类边界 —— 交点左边 \(g \lt 0\)、右边 \(g \gt 0\)，两条判决区域由此分开。

    这张图的作用是打破一个常见误解： 不要以为「判别函数的图像」就是「决策面的图像」。 判别函数画出来是一条斜线（\(d=1\) 时）， 决策面只是这条斜线与零轴的交点（\(d=1\)）或零等值线（\(d \gt 1\)）。 两者维数差一，这是最容易被绕晕的地方

    1.2 把「方向」和「位置」分开看¶

    第一步：\(\boldsymbol{w}\) 定方向。

    设 \(x_1\)、\(x_2\) 都在决策面上，则 \(g(x_1) = g(x_2) = 0\)，两式相减：

    \[g(x_1) - g(x_2) = \boldsymbol{w}^{\mathsf T}(x_1 - x_2) = 0\]

    要点：\(\boldsymbol{w}\) 与决策面上任意一条连线正交 —— 所以 \(\boldsymbol{w}\) 是决策面的法向量

    一句话：\(\boldsymbol{w}\) 指向的那一侧，就是 \(g \gt 0\) 的那一类。

    第二步：\(b\) 定位置。

    法向量只管方向，方向定了之后，这个平面还可能在平行地滑动。 滑到哪儿，由 \(b\) 决定：

    • \(b = 0\)：决策面过原点
    • \(b \neq 0\)：决策面平移 \(\dfrac{\lvert b\rvert}{\lVert\boldsymbol{w}\rVert}\) 的距离
    • \(b \gt 0\)：平面朝 \(-\boldsymbol{w}\) 的方向移（原点一侧被判给 \(\omega_1\)）

    所以设计一个线性分类器，就是设计 \(\boldsymbol{w}\) 和 \(b\) 这两个东西

    1.3 判别函数值到底代表什么¶

    判别函数值 \(g(x)\) 不是距离，这一点必须说清楚 ⚠

    如果把 \(\boldsymbol{w}\) 整体放大两倍（\(2\boldsymbol{w}\)、\(2b\)）， 判决结果一点不变（符号相同），但 \(g(x)\) 的值放大两倍。 所以 \(g(x)\) 的绝对值没有几何意义。

    有几何意义的是它除以 \(\lVert\boldsymbol{w}\rVert\)：

    \[r(x) = \frac{g(x)}{\lVert\boldsymbol{w}\rVert} = \frac{\boldsymbol{w}^{\mathsf T}x + b}{\lVert\boldsymbol{w}\rVert}\]

    这就是点 \(x\) 到超平面的有向距离： 正号表示在 \(\boldsymbol{w}\) 指向的那一侧，负号表示在另一侧。

    推导思路：把 \(x\) 沿法向量方向分解， \(x = x_p + t\,\dfrac{\boldsymbol{w}}{\lVert\boldsymbol{w}\rVert}\)， 其中 \(x_p\) 是 \(x\) 在超平面上的正交投影。 代入判别函数并利用 \(g(x_p) = 0\)、\(\boldsymbol{w}^{\mathsf T}\boldsymbol{w} = \lVert\boldsymbol{w}\rVert^2\)， 立刻得到 \(t = g(x)/\lVert\boldsymbol{w}\rVert\) ✓

    正交投影点本身也有闭式解，后面例题会手算：

    \[x_p = x - \frac{g(x)}{\lVert\boldsymbol{w}\rVert^{2}}\,\boldsymbol{w}\]

    别把 g(x) 当成距离

    \(g(x)\) 的值随 \(\boldsymbol{w}\) 的尺度变化，只有 \(g(x)/\lVert\boldsymbol{w}\rVert\) 才是欧氏距离。

    训练时如果准则函数里用了 \(g(x)\) 本身， 权向量的长度会被准则牵着走， 这时「收敛了」只说明符号对了，不说明边界位置合理 ⚠

    1.4 三种可分性¶

    给定训练集，线性判别函数能做到什么程度，取决于数据本身：

    情形 条件 线性分类器的表现
    线性可分 存在 \(\boldsymbol{w}, b\) 使全部样本判对 有无穷多解，需再定准则挑一个 ✓
    线性不可分 找不到这样的 \(\boldsymbol{w}, b\) 只能退而求其次（最小错分、最小平方误差）⚠
    近似可分 只有少数样本越界 引入余量或松弛变量处理 ⚠

    这张表的意义：同一个算法，在两种情形下的行为完全不同。 感知器在可分时保证收敛，在不可分时会一直震荡， 所以「跑不完」本身就是一条诊断信息 ✓

    二、增广特征写法¶

    2.1 把偏置吸收进权向量¶

    每一节都要写 \(\boldsymbol{w}^{\mathsf T}x + b\) 太啰嗦，而且 推导时总要单独处理那个 \(b\)，容易出错。有个标准做法能把它消掉。

    做法：给每个样本补一个恒为 1 的分量，同时给权向量补上 \(b\)：

    \[\tilde{x} = \begin{pmatrix} x \\ 1 \end{pmatrix} \in \mathbb{R}^{d+1}, \qquad a = \begin{pmatrix} \boldsymbol{w} \\ b \end{pmatrix} \in \mathbb{R}^{d+1}\]

    于是：

    \[g(x) = \boldsymbol{w}^{\mathsf T}x + b = a^{\mathsf T}\tilde{x}\]

    一句话：偏置不是「额外的参数」，只是「第 \(d+1\) 个输入恒为 1 的权重」

    这两种写法完全等价：

    项目 原写法 增广写法
    特征 \(x \in \mathbb{R}^{d}\) \(\tilde{x} = (x, 1) \in \mathbb{R}^{d+1}\)
    参数 \(\boldsymbol{w}\) 与 \(b\) 分开 \(a = (\boldsymbol{w}, b)\) 合一个
    判别函数 \(\boldsymbol{w}^{\mathsf T}x + b\) \(a^{\mathsf T}\tilde{x}\)
    决策面 \(\boldsymbol{w}^{\mathsf T}x + b = 0\) \(a^{\mathsf T}\tilde{x} = 0\)（过原点）✓
    推导时的麻烦 每次要单独移项 没有麻烦 ✓

    注意最后一行：增广之后，决策面在增广空间里变成了「过原点的超平面」。 这个「过原点」不是巧合，而是把「平移」这件事塞进了多出来的那一维里

    2.2 齐次形式的好处与代价¶

    好处（三条，都很实在）：

    • 形式统一：所有公式都只剩内积，不再出现「\(+b\)」这种尾巴
    • 几何统一：决策面过原点，垂直性、投影、余量全部复用同一套说法
    • 证明统一：感知器收敛定理的经典证明就是在增广空间做的

    代价（两条，也要说）：

    • 多了一维：\(d\) 维变 \(d+1\) 维，参数多了一个
    • 尺度不定：\(a\) 整体乘正数，判决不变 → 解不唯一， 需要额外规则（如归一化 \(\lVert a\rVert = 1\)）才能挑出唯一解 ⚠

    增广之后不要重复加偏置

    增广写法里，\(a\) 的最后一个分量就是 \(b\)。

    常见错误是写了 \(a^{\mathsf T}\tilde{x} + b\) —— 等于把偏置算了两遍，边界位置会莫名其妙地偏

    判据很简单：看决策面过不过原点。 增广写法下必须过原点；如果不过，说明多加了什么。

    2.3 规范化：把两类合成一个条件¶

    增广之后再做第二步处理，就能把「两类样本」变成一个统一条件。

    做法：把 \(\omega_2\) 的样本整体取反：

    \[z_i = \begin{cases} +\tilde{x}_i, & x_i \in \omega_1 \\ -\tilde{x}_i, & x_i \in \omega_2 \end{cases}\]

    效果：原来要求「\(\omega_1\) 的样本 \(a^{\mathsf T}\tilde{x} \gt 0\)」且 「\(\omega_2\) 的样本 \(a^{\mathsf T}\tilde{x} \lt 0\)」， 现在两类都要求同一个不等式：

    \[a^{\mathsf T}z_i \gt 0, \qquad i = 1, 2, \dots, N\]

    这是整个第五、六节的基础 ✓ 没有规范化，「错分样本」要分两种情形讨论； 规范化之后，错分只有一种定义：\(a^{\mathsf T}z_i \leq 0\)。

    三、广义线性判别函数¶

    3.1 为什么要推广¶

    线性判别函数的能力上限很清楚：只能画直线/平面。 但真实数据里，边界常常是弯的（上一节表里的「线性不可分」情形）。

    一个自然的想法：先对特征做一次非线性变换， 把数据搬到另一个空间；如果在新空间里数据变线性可分了， 就在新空间里用线性判别函数。

    定义：取一组基函数 \(\varphi_1, \dots, \varphi_m\)，令

    \[\phi(x) = \bigl(\varphi_1(x), \varphi_2(x), \dots, \varphi_m(x)\bigr)^{\mathsf T}\]

    则

    \[g(x) = \boldsymbol{w}^{\mathsf T}\phi(x) + b\]

    叫广义线性判别函数。

    关键理解：「广义线性」对 \(x\) 是非线性的，对参数 \(\boldsymbol{w}\) 仍是线性的 ✓

    这一点为什么重要：所有线性分类器的理论（凸性、收敛定理、 正规方程）只在「对参数线性」这一条上成立， 和「对输入是否线性」无关。所以搬到 \(\phi\) 空间后，旧结论全部可用 ✓

    上图是这一操作的直观版本：原始二维空间里，两类样本是同心圆， 找不到任何一条直线能分开它们； 但作特征映射之后，边界变成新空间里的超平面。 「弯」不是被学出来的，是被映射「搬到」高维里去的 ✓

    3.2 一个最小的例子：一维二次判别¶

    哪怕原始只有一维特征，加上一次变换就能得到二次边界：

    \[\phi(x) = \begin{pmatrix} x \\ x^2 \end{pmatrix}, \qquad g(x) = w_1 x + w_2 x^2 + b\]

    \(g(x) = 0\) 是 \(x\) 的二次方程：

    • 两个实根 → 判决区间被切成三段，中间一段判一类、两边判另一类
    • 一个实根（判别式为 0）→ 退化成一个点
    • 无实根 → 整个实轴判同一类（这个判别函数失效了）

    注意最后一行：广义线性判别函数可能「退化」成恒正或恒负， 这时它一个样本也分不开。出现这种情况说明 \(\phi\) 选得不合适， 而不是数据不可分

    3.3 三种做法的对比¶

    特征变换这条路有三种走法，课上都必须分清：

    做法 形式 参数量 显式算 \(\phi\)
    原始线性 \(\boldsymbol{w}^{\mathsf T}x + b\) \(d+1\) 不需要
    广义线性 \(\boldsymbol{w}^{\mathsf T}\phi(x) + b\) \(m+1\) 需要 ✓
    核方法 \(\sum_i \alpha_i K(x_i, x) + b\) \(N+1\) 不需要 ⚠

    三者的递进关系：

    • 从第一行到第二行：换坐标，能力变强，代价是维度 \(m\) 可能远大于 \(d\)
    • 从第二行到第三行：不显式换坐标，只算内积 \(K(x_i, x_j) = \phi(x_i)^{\mathsf T}\phi(x_j)\)， 从而能对付无穷维 \(\phi\)

    广义线性的代价是「维数」与「样本量」

    把 \(d\) 维特征展开成所有二次项，维数从 \(d\) 涨到 \(d(d+3)/2\) —— 平方级增长。

    而参数个数 \(m+1\) 就是需要估计的量， 按本课程前面「维数灾难」那一节的结论， 样本量必须跟着涨，否则参数估不准、泛化变差 ⚠

    判断准则：先用线性试；线性明显不够再上二次； 再不够就换核方法或多层网络 —— 别一上来就展开二次项。

    3.4 线性可分性只与「解集是否为空」有关¶

    最后纠正一个说法上的含糊。

    线性可分分为两种：

    • 严格线性可分：存在 \(a\) 使得 \(a^{\mathsf T}z_i \gt 0\) 对全部 \(i\)
    • 非严格可分：存在 \(a\) 使得 \(a^{\mathsf T}z_i \geq 0\) 对全部 \(i\)， 其中至少有一个取等号

    差别在于「有没有样本恰好落在边界上」。 非严格可分时，边界上那些样本的判决是任意的， 它们的类别归属完全取决于算法内部的取等号约定， 换一种实现就可能翻案

    所以在报告结果时要说清是哪种可分性， 不要笼统地说「数据是线性可分的」。

    四、感知准则函数¶

    4.1 设计准则：把「分类对不对」变成「一个数最小」¶

    有了判别函数的形式，接下来的问题是：怎么定 \(a\)？

    直接对着「错分样本个数最少」去优化是行不通的 —— 错分个数是整数，对 \(a\) 不可导，没法用梯度方法

    所以需要一个「可导的代理目标」，这就是准则函数（判据）。 要求有三条：

    要求 理由
    非负 才能说「最小值」；否则可以无下界地降 ✓
    对 \(a\) 可导（或至少分段可导） 才能用迭代法求解 ✓
    \(J(a) = 0\) 等价于「全部分对」 才能说「求到最小值就是求到了解」⚠

    第三条最关键：准则函数的设计，本质上就是「挑一个代理目标」， 代理目标选得好不好，直接决定算法行为。

    4.2 感知准则函数的定义¶

    定义（只在错分样本上求和）：

    \[J_P(a) = \sum_{z_i \in \mathcal{M}} (-a^{\mathsf T}z_i)\]

    其中 \(\mathcal{M} = \{z_i : a^{\mathsf T}z_i \leq 0\}\) 是当前的错分样本集。

    逐项读这个式子：

    • \(a^{\mathsf T}z_i \leq 0\) 表示错分（规范化之后两类条件已经统一）
    • 前面加负号，\(-a^{\mathsf T}z_i \geq 0\) —— 让它变成一个非负量
    • 求和 → 错分样本越多、越「深」地错，\(J_P\) 越大

    几何解释：\(-a^{\mathsf T}z_i\) 可以看成 「样本 \(z_i\) 被错分的那一边、离边界有多远」的一个代数量 （严格说它不是欧氏距离，而是「投影的负值」； 除以 \(\lVert a\rVert\) 才是距离 —— 见 1.3 节的警告）

    感知准则函数的两句话总结

    第一句：\(J_P(a)\) 是「所有错分样本投影之负」的总和。

    第二句：在 \(a \neq 0\) 的前提下， \(J_P(a) = 0\) 等价于「没有错分样本」

    第二句里那个「\(a \neq 0\)」不能漏 —— \(a = 0\) 时所有样本都落在错分集里， 但每项都是 \(0\)，求和也是 \(0\)， 所以 \(J_P\) 会「误报」成已经完成。这一点在例题 2 里会算到

    两句话合起来，就把分类问题翻译成了无约束优化问题。

    4.3 梯度与迭代公式¶

    \(J_P\) 对 \(a\) 求梯度：只有错分样本那一部分对 \(a\) 有贡献，每项是 \(-a^{\mathsf T}z_i\)， 对 \(a\) 求导得 \(-z_i\)，所以

    \[\nabla J_P(a) = -\sum_{z_i \in \mathcal{M}} z_i\]

    要点：梯度就是「错分样本之和取负」

    梯度下降（步长 \(\rho \gt 0\)，负梯度方向）：

    \[a_{k+1} = a_k - \rho\,\nabla J_P(a_k) = a_k + \rho \sum_{z_i \in \mathcal{M}} z_i\]

    这就是「批量修正」：一次把所有错分样本加起来挪一步。

    单样本修正（每次只取一个错分样本）：

    \[a_{k+1} = a_k + \rho\,z_i, \qquad z_i \in \mathcal{M}\]

    这就是感知器算法，也叫固定增量法（\(\rho\) 固定）。

    两种修正方式对比：

    项目 批量修正 单样本修正
    每次用几个样本 全部错分样本 一个错分样本 ✓
    每轮更新次数 1 次 错分个数次
    梯度方向 真实梯度 真实梯度的一个分量
    \(J_P\) 单调性 单调不增 ✓ 不保证单调 ⚠
    实践偏好 稳定但慢 快、简单、常用 ✓

    注意第 4 行：单样本修正不保证 \(J_P\) 每次更新都下降， 但保证收敛（下一节给证明）。这两件事不矛盾 —— 收敛性靠的是「解的几何性质」，不是「目标函数的单调性」

    4.4 步长与初始值的影响¶

    步长 \(\rho\) 不改结论，只改过程：

    步长 影响
    \(\rho\) 太小 收敛慢，迭代次数多
    \(\rho\) 太大 单步跳过头，可能震荡 ⚠
    \(\rho\) 取常数 固定增量法 ✓
    \(\rho_k\) 递减（如 \(\rho_k = c/k\)） 变增量法，收敛更稳

    初始值 \(a_0\) 的选择：

    • \(a_0 = 0\) 是最常用的选择（解一定存在时，从 0 出发必然收敛）✓
    • \(a_0 \neq 0\) 也可以，但最终解会不同 —— 因为线性可分时解有无穷多个，算法只保证「找到其中一个」

    这一点必须提醒：「感知器收敛了」不等于「找到了好边界」， 只等于「找到了一个把样本分对的边界」。 不同的初始值、不同的样本顺序， 会给出不同的边界，泛化性能也可能差很多

    下面这张图把这套迭代机制画出来： 每遇上一次错分样本，权向量就被推一下， 推的方向与错分样本自己同向， 直到所有样本都落在正确的一侧。

    看图时要抓住三件事：

    • 边界是「被推出来的」，不是「被算出来的」 —— 最终位置完全由「推过哪些样本、按什么顺序推」决定
    • 推的方向就是错分样本的方向 —— 这正是更新式 \(a \leftarrow a + \rho z_i\) 的几何含义
    • 停止条件是「这一轮没人被推」 —— 也就是「这一轮没有错分样本」， 而不是「\(J_P\) 到了某个小值」

    这张图同时也暴露了感知器的短板： 图上边界几乎贴着某些样本。 感知器对「贴多近」完全不在意，只要符号对就满足 —— 这正是下一节要修的毛病

    五、感知器收敛定理¶

    5.1 定理的完整陈述¶

    定理（感知器收敛定理）：

    设训练集 \(Z = \{z_1, \dots, z_N\}\) 线性可分 （存在 \(a^{*}\) 使得 \(a^{*\mathsf T}z_i \gt 0\) 对全部 \(i\) 成立）。 取 \(\rho \gt 0\)（常数），从任意初始 \(a_0\) 出发， 按规则 \(a_{k+1} = a_k + \rho\, z_{i_k}\)（仅当 \(a_k^{\mathsf T}z_{i_k} \leq 0\) 时修正） 迭代，则序列在有限步内停止，即存在 \(k^{*}\) 使得 \(a_{k^{*}}^{\mathsf T}z_i \gt 0\) 对全部 \(i\) 成立。

    这句话里的每一个限定都不能删，逐条列出来：

    前提 为什么不能删
    线性可分 不可分时算法永远不停（会无限循环）⚠
    常数步长 \(\rho \gt 0\) 变步长时该证明不适用，需要另一套论据
    仅在错分时修正 修正的条件是「\(a^{\mathsf T}z_i \leq 0\)」，这是算法的一部分
    任意初始值 这一点很强，说明收敛性与初值无关 ✓
    增广 + 规范化写法 证明是在这个框架里做的（否则要分两类讨论）

    还有两个「没有说」但极其重要的事，必须单独点明：

    收敛定理没有保证的两件事

    第一，它没说收敛到哪一个解。

    线性可分时解有无穷多个，定理只保证「有限步后停在一个解上」。 这个解由初始值与样本顺序共同决定， 换个顺序就可能得到完全不同的边界

    第二，它没说迭代次数的上界有多小。

    定理的证明会给一个上界 \(\left(\dfrac{R}{\gamma}\right)^2\) （\(R\) 是样本最大模长、\(\gamma\) 是最优间隔）。 当 \(\gamma\) 很小（数据「勉强」可分）时， 这个上界会大得没有实用意义 —— 下一小节会用具体数字展示这一点。

    5.2 证明思路（三步）¶

    完整证明很长，但骨架只有三步，每一步的「想干什么」要看懂。

    第一步：证明 \(\lVert a_k\rVert\) 有一个下界（而且会往上涨）。

    利用存在最优解 \(a^{*}\) 这一条件。把 \(a^{*}\) 归一化，使 \(\lVert a^{*}\rVert = 1\)， 并记 \(\gamma = \min_i a^{*\mathsf T}z_i \gt 0\)（这就是最优间隔）。

    每次修正发生在 \(a_k^{\mathsf T}z_i \leq 0\) 时，因此：

    \[a^{*}{}^{\mathsf T}a_{k+1} = a^{*}{}^{\mathsf T}a_k + \rho\,a^{*\mathsf T}z_i \;\geq\; a^{*}{}^{\mathsf T}a_k + \rho\gamma\]

    递推 \(k\) 次，配合 Cauchy–Schwarz 不等式 \(a^{*}{}^{\mathsf T}a_{k+1} \leq \lVert a^{*}\rVert\,\lVert a_{k+1}\rVert = \lVert a_{k+1}\rVert\)， 得到

    \[\lVert a_{k+1}\rVert \;\geq\; \rho\,k\,\gamma\]

    这一步的直觉：\(a^{*}\) 与 \(a_k\) 的夹角在变小 —— \(a_k\) 每修正一次，就朝真正该去的方向多走一点 ✓

    第二步：证明 \(\lVert a_k\rVert^2\) 有一个上界（涨得没这么快）。

    每次修正时 \(a_k^{\mathsf T}z_i \leq 0\)，展开平方：

    \[\lVert a_{k+1}\rVert^2 = \lVert a_k + \rho z_i\rVert^2 = \lVert a_k\rVert^2 + 2\rho\,a_k^{\mathsf T}z_i + \rho^2\lVert z_i\rVert^2 \;\leq\; \lVert a_k\rVert^2 + \rho^2 R^2\]

    其中 \(R = \max_i \lVert z_i\rVert\)。

    这一步的直觉：模长的平方每次最多涨 \(\rho^2R^2\) —— 匀速、线性的增长，不会暴涨

    第三步：两个界「打架」，解出 \(k\) 的上界。

    由第一步 \(\lVert a_{k+1}\rVert \geq \rho k\gamma\)， 两边平方后代入第二步的上界 \(\lVert a_{k+1}\rVert^2 \leq \lVert a_0\rVert^2 + k\rho^2R^2\)：

    \[\rho^2k^2\gamma^2 \;\leq\; \lVert a_0\rVert^2 + k\,\rho^2 R^2\]

    解这个关于 \(k\) 的二次不等式，得到

    \[k \;\leq\; \frac{R^2}{\gamma^2} + \frac{\lVert a_0\rVert^2}{\rho^2\gamma^2}\]

    因为右边是有限的常数，\(k\) 不可能无限增长 —— 而每次修正都严格增大 \(k\)，所以修正次数有限 ✓ 有限次修正后，\(a^{\mathsf T}z_i \leq 0\) 不再发生，算法停止。

    三步串起来看：

    步骤 证的东西 用的工具 关键量
    一 模长下界（线性增长） 存在最优解 + Cauchy–Schwarz 最优间隔 \(\gamma\) ✓
    二 模长平方上界（线性增长） 错分条件 + 展开平方 样本最大模长 \(R\) ✓
    三 上下界矛盾 → 迭代有限 解二次不等式 \(R^2/\gamma^2\) ⚠

    这个证明有两条重要的「副产品」：

    • 定理的证明同时也是「最优间隔存在」的证明 —— 第一步用到的 \(\gamma\) 是数据自身的性质，不是算法的产物 ✓
    • 上界 \(R^2/\gamma^2\) 与步长 \(\rho\)、初始值 \(a_0\) 都无关（主项）， 这说明收敛速度由数据的几何决定，调参改不了根本 ✓

    这个界是上界，不是实际迭代次数

    它是上界，而且是很松的上界。 实际运行通常远快于它 —— 下一小节会用具体数字对照。

    反过来，它仍然是有用的诊断量： 如果发现 \(\gamma\) 很小（数据「勉强」可分）， 那就要预期感知器很慢、而且解很不稳定 ⚠

    六、松弛方法与余量¶

    6.1 感知器的两个毛病¶

    回顾上一节的输出：最小投影只有 0.0783，几何间隔只有 0.0163。 这说明感知器给出来的边界几乎是「擦着」某个样本过去的。

    感知器的两个天生毛病：

    毛病 表现 后果
    不要求余量 只要符号对就停 边界贴着样本，噪声一来就翻 ⚠
    解不唯一 无穷多解里随便挑一个 结果依赖顺序与初值，不可复现 ⚠

    改进的方向：把「分对」升级成「分对并且留出余量」 ✓

    6.2 余量与松弛变量的定义¶

    余量（margin）：要求投影至少大于某个正数 \(b \gt 0\)：

    \[a^{\mathsf T}z_i \;\geq\; b, \qquad i = 1, 2, \dots, N\]

    \(b\) 就是余量，它把「不严格的不等式」变成「有间隔的不等式」 ✓

    松弛变量（slack）：线性可分时 \(b\) 可以取正； 不可分时必然有样本满足不了，于是给每个样本配一个松弛量 \(\xi_i \geq 0\)，把条件放松成：

    \[a^{\mathsf T}z_i \;\geq\; b - \xi_i, \qquad \xi_i \geq 0\]

    读法：\(\xi_i = 0\) 表示这个样本满足余量； \(\xi_i \gt 0\) 表示违反了 \(\xi_i\) 那么多； 如果 \(\xi_i \geq b\)，这个样本连符号都错了 ⚠

    概念 数学形式 含义
    余量 \(b\) \(a^{\mathsf T}z_i \geq b\) 要求「分对 + 留出间隔」✓
    松弛变量 \(\xi_i\) \(a^{\mathsf T}z_i \geq b - \xi_i\) 允许个别样本越界 ⚠
    零松弛 \(\xi_i = 0\) 该样本满足余量 ✓
    完全错分 \(\xi_i \geq b\) 该样本符号都错了 ⚠

    6.3 松弛准则函数¶

    把感知准则函数里的 \(0\) 换成 \(b\)，就得到松弛准则函数：

    \[J_r(a) = \frac{1}{2}\sum_{z_i \in \mathcal{M}_b} \frac{\left(b - a^{\mathsf T}z_i\right)^2}{\lVert z_i\rVert^{2}}\]

    其中 \(\mathcal{M}_b = \{z_i : a^{\mathsf T}z_i \lt b\}\) 是不满足余量的样本集。

    为什么要除以 \(\lVert z_i\rVert^2\)：不除的话， 模长大的样本会主导整个目标函数， 长样本一点点没满足，就压过了短样本的一大截 除以 \(\lVert z_i\rVert^2\) 相当于把每个样本的「发言权」归一化

    梯度（对每个违反样本求导）：

    \[\nabla J_r(a) = -\sum_{z_i \in \mathcal{M}_b} \frac{b - a^{\mathsf T}z_i}{\lVert z_i\rVert^{2}}\,z_i\]

    批量修正：

    \[ a_{k+1} = a_k + \rho\sum_{i \in \mathcal{M}_b} \dfrac{b - a^{\mathsf T}z_i}{\lVert z_i\rVert^{2}}z_i \]

    梯度下降的收敛条件（这是松弛方法相对感知器的理论优势）：

    准则 收敛保证
    感知准则 \(J_P\) 线性可分时有限步收敛（定理）✓
    松弛准则 \(J_r\) 只要 \(0 \lt \rho \lt 2\)，\(J_r\) 单调不增且收敛 ✓
    松弛准则 且当 \(J_r\) 的 Hessian 正定时线性收敛 ✓

    注意：\(J_r\) 用的是严格不等式（\(\lt b\) 而非 \(\leq b\)）， 所以它对 \(a\) 处处可导、梯度连续 —— 这正是它能保证单调下降的原因 ✓

    余量 b 不是越大越好

    \(b\) 越大，要求越严。

    线性可分时，总存在某个 \(b_{\max}\) 使条件仍然有解； 一旦 \(b \gt b_{\max}\)，条件无解， 迭代会一直震荡（永远消不掉违反样本）⚠

    实践判据：先设一个较小的 \(b\) 跑通，再逐步加大， 直到违反样本数突然不再下降 —— 那个位置附近就是 \(b_{\max}\)。

    """松弛准则的批量修正，返回解与 J 的轨迹。"""
    a = np.zeros(3)

        trace.append(J)
        if not viol.any():
            break
        a = a + rho * ((b - m[viol]) / nz2[viol]) @ Z[viol]
    return a, trace

    • 这就是松弛方法的核心机制：你要求多少，它就给你多少 —— 因为 \(J_r = 0\) 的定义就是「所有样本的投影都不小于 \(b\)」✓
    • \(J_r\) 逐次不增（True）：这是松弛准则相对感知准则的理论优势 ✓
    • 迭代次数都是 \(2\)：因为批量修正一步就把所有违反样本一次拉到位； 真实的迭代法不会这么快，这里只是因为步长取到了 \(1.0\) ⚠

    一个必须点破的坑：

    现象 原因
    最小投影正好等于 \(b\) 余量条件是闭条件，\(J_r = 0\) 恰好对应「投影 \(\geq b\)」✓
    但几何间隔（除以 \(\lVert\boldsymbol{w}\rVert\)）没有变大 因为 \(b\) 只约束投影，不约束权向量的长度 ⚠
    \(b\) 越大，\(\lVert\boldsymbol{w}\rVert\) 也越大 投影要涨到 \(b\)，权向量的模长跟着涨，两者约掉了 ⚠

    最后一行是很关键的提醒： 「松弛方法的余量」不是「几何间隔」。 想真正最大化几何间隔，必须显式地约束 \(\lVert\boldsymbol{w}\rVert\) —— 这正是支持向量机做的事 ✓

    6.6 三级递进：从「符号对」到「间隔最大」¶

    把本页前面的三张图串起来，正好是一条完整的线索：

    • 判别函数图（第一节）：符号定类别，绝对值只表示把握
    • 映射图（第三节）：弯曲边界来自特征空间的变换
    • 感知器图（第四节）：错分样本把权向量推着走，直到全部分对

    再加上本节讲的余量，这条线索就补上了最后一块：

    目标 要求 对应的方法
    只要符号对 \(a^{\mathsf T}z_i \gt 0\) 感知器 ✓
    符号对且投影留余量 \(a^{\mathsf T}z_i \geq b\) 松弛方法 ✓
    符号对且几何间隔最大 最大化 \(\dfrac{a^{\mathsf T}z_i}{\lVert a\rVert}\) 最大间隔方法 ✓

    三级之间的关系是「逐级加严」， 所以最大间隔的方法在可分数据上一定也能满足前两级的要求 ✓

    七、线性最小二乘¶

    7.1 把分类当回归做¶

    前面两种准则都是「分段」或「只在违反样本上求和」的， 它们的共同麻烦是：没有闭式解，必须迭代。

    最小二乘走的是完全不同的路： 把「分成两类」直接当成「拟合一个数值目标」来做。

    设定：

    • 给每个样本配一个数值目标 \(t_i\)：\(\omega_1\) 取 \(+1\)， \(\omega_2\) 取 \(-1\)（这是最常用的取法）
    • 目标函数是所有样本的残差平方和：
    \[J_{LS}(a) = \sum_{i=1}^{N}\left(a^{\mathsf T}\tilde{x}_i - t_i\right)^2 = \lVert \tilde{X}a - t\rVert^{2}\]

    关键差别（对比 4.2 节的 \(J_P\)）：

    项目 感知准则 \(J_P\) 最小二乘 \(J_{LS}\)
    求和范围 只有错分样本 全部样本 ⚠
    是否用 \(t_i\) 不用（只用符号） 用数值目标 ✓
    损失形状 分段线性 平方 ⚠
    求解方式 迭代 解方程（一步到位）✓

    注意第一行：\(J_{LS}\) 把已经分对的样本也算进损失， 而且分得越「远」贡献越大。 这是它有闭式解的代价，也是它对离群点敏感的原因

    7.2 正规方程与闭式解¶

    \(J_{LS}\) 是 \(a\) 的二次函数，可以直接求极值点。

    求导。把每个样本的增广特征堆成设计矩阵 \(\tilde{X}\)（\(N \times (d+1)\)）， 目标堆成向量 \(t\)，则

    \[\nabla J_{LS}(a) = 2\tilde{X}^{\mathsf T}\left(\tilde{X}a - t\right)\]

    令梯度为零，得到正规方程：

    \[\tilde{X}^{\mathsf T}\tilde{X}\,a = \tilde{X}^{\mathsf T}t\]

    当 \(\tilde{X}^{\mathsf T}\tilde{X}\) 可逆时，直接解出：

    \[a^{*} = \left(\tilde{X}^{\mathsf T}\tilde{X}\right)^{-1}\tilde{X}^{\mathsf T}t\]

    注意这里没有迭代、没有步长、没有初始值 —— 一次矩阵求解就结束

    三个必须交代的细节：

    细节 说明
    可逆性 \(\tilde{X}^{\mathsf T}\tilde{X}\) 可能奇异（样本数少于维数，或特征共线）⚠
    奇异时的处理 用伪逆代替，得到最小范数解 ✓
    失败模式 不存在「不收敛」；失败是给出了一个分类性能很差的解 ⚠

    第三行特别值得说明： 最小二乘永远给你一个答案，但从不给警告。 所以它的错误表现为「结果看着正常，但错误率就是高」， 排查时容易误以为是数据有问题

    7.3 几何意义：残差竖线¶

    把一维情形画出来最直观：

    上图里那些竖直的短线就是残差 —— 每个样本点到拟合直线的偏差。 最小二乘在做的事，就是让这些短线的长度平方和最小。

    为什么是「竖直」而不是「垂直」：因为回归把横轴当自变量、 纵轴当因变量，只在因变量方向上量误差。 这一点在分类问题里有重要后果：特征方向的误差被完全忽略了

    换到分类场景，这个后果很显眼：

    现象 原因
    样本在特征方向很分散 只要 \(t_i\) 对，残差就不大 ✓
    样本在 \(t\) 方向偏离 残差被平方放大 ⚠
    分对了、而且 \(g\) 很大 反而被惩罚 ⚠

    最后一行是最反直觉的地方： 最小二乘惩罚「过度自信」。 一个被正确分类、而且离边界很远的样本， 如果 \(g(x) = 3\) 而 \(t = 1\)，它贡献 \((3-1)^2 = 4\) 的损失 —— 分对了还被罚 这与「分类只看符号」的目标根本不一致。

    • 方向是朝 \(-1\) 类那边偏的：\(-1\) 类只有 \(10\) 个样本， 为了让这 \(10\) 个样本的残差小一点， 回归线整体往 \(-1\) 类那边压

    甲 → 丙（离群点）：

    • 只加了一个点（占 \(1\%\)），阈值就动了 \(0.1538\) —— 相当于把边界整体挪走了不小的距离
    • 机制：这个点的残差是 \((g+12)^2\) 级别， 平方之后成了整个目标函数里最大的一项， 优化自然优先去迁就它
    • 如果换成感知准则或松弛准则：这个点只是一个「被错分的样本」， 权重和别的错分样本一样，不会有这种支配效应

    分类型任务慎用最小二乘的直接形式

    最小二乘对特征尺度、类别比例、离群点三件事都很敏感， 而且惩罚「分类正确但离得远」的样本。

    什么时候可以用：样本干净、类别均衡、只想要一个快速基线。 什么时候别用：数据里有明显离群点，或类别比例悬殊

    另外记住一个正面结论：当目标值取成 \(N/n_1\) 与 \(N/n_2\)（\(n_i\) 是第 \(i\) 类样本数）时， 最小二乘解的「方向」与线性判别分析的解方向一致 这说明最小二乘不是错的，只是目标函数与分类目标错位。

    7.5 缺陷二：解的性质与分类目标不一致¶

    把最小二乘的几条缺陷并排看，它们都源自同一处错位：

    缺陷 表现 根因
    惩罚正确但离得远的样本 \(g \gt 1\) 时残差仍为正 ⚠ 用 \(\pm 1\) 当「理想预测值」⚠
    对离群点敏感 一个点就能支配目标 ⚠ 平方损失 ⚠
    偏置被类别比例拉偏 边界朝少数类移动 ⚠ 最小化的是预测值误差，不是分类错误 ✓
    不保证有间隔 解可能贴着样本 ⚠ 目标函数里没有余量项 ⚠

    换一个角度看这张表： 这几条不是几个独立缺陷，而是同一个设计选择在不同侧面的表现 —— 「把分类当成回归」。

    所以正确的用法是： 把它当成「快速得到一条还行的边界」的工具， 而不是「一个分类算法」。 想真正优化分类性能，就该用直接面向分类错误的准则 —— 感知准则、松弛准则、最大间隔、对数似然

    八、多类扩展¶

    8.1 三种基本方案¶

    前面所有讨论都是两类。多类怎么办？ 没有「唯一正确」的做法，只有三种主流方案，各有取舍。

    方案一：一对多（One-vs-All，OVA）

    对 \(K\) 个类，训练 \(K\) 个二类分类器： 第 \(k\) 个把「\(\omega_k\)」当正类、「其余全部」当负类。 判决时算 \(K\) 个判别函数，取最大的那个： \(\hat{y} = \arg\max_k g_k(x)\)。

    方案二：一对一（One-vs-One，OvO）

    每两个类训练一个分类器，共 \(\dfrac{K(K-1)}{2}\) 个。 每个分类器只在这两个类的样本上训练。 判决时让所有分类器投票，得票最多的类胜出。

    方案三：多对多（纠错输出码，ECOC）

    把 \(K\) 个类用若干个二类问题的编码表示， 每个类对应一个长度为 \(L\) 的码字（\(L\) 个 \(\pm 1\)）， 训练 \(L\) 个二类分类器。 判决时把 \(L\) 个输出拼成一个码字， 查表找最近的类码字（汉明距离最小）。

    方案三的关键点是「纠错」： 因为用了 \(L\) 个分类器而类别只有 \(K\) 个（\(L \gt \log_2 K\)）， 个别分类器判错不会改变最终结果 这正像通信里的纠错码：冗余换取容错

    8.2 三种方案的量化对比¶

    这是多类扩展最该记住的一张表：

    项目 一对多 OVA 一对一 OvO 多对多（ECOC）
    分类器个数 \(K\) \(\dfrac{K(K-1)}{2}\) \(L\)（人为指定）✓
    每个分类器用多少样本 全部 \(N\) ⚠ 只用两类的样本 ✓ 由编码决定
    单分类器训练代价 高 ⚠ 低 ✓ 中等
    判决时的计算量 \(K\) 次 ✓ \(\frac{K(K-1)}{2}\) 次 \(L\) 次
    是否存在不可判定区 有（0 票或平票）⚠ 有（平票）⚠ 无（最近码字总存在）✓
    类别不平衡的影响 严重（正负比 \(1:(K-1)\)）⚠ 轻（两类大致均衡）✓ 视编码而定
    容错能力 无 无 ⚠ 有（码距足够可纠错）✓

    逐行读三处关键：

    第一，分类器个数。 \(K=10\) 时 OVA 是 \(10\) 个、OvO 是 \(45\) 个。 OvO 的分类器多得多，但每个只需要两类的样本， 所以总训练量其实差不多 不要只看个数下结论。

    第二，不可判定区 —— 这是 OVA 与 OvO 都有的硬伤：

    方案 不可判定的情形 后果
    OVA 没有任何判别函数给正（0 票），或有两个并列最大 ⚠ 判决无定义 ⚠
    OvO 两个类的得票数相同 判决无定义 ⚠
    ECOC 几乎不存在 最近码字总是唯一的 ✓

    OVA 的「0 票」不是罕见现象 —— 当三个类互相「抢」边界时，一个样本可能落到三个判别函数都判负的区域里。 这时必须补一条消歧规则（取最大分数、或用拒识）， 而那就已经脱离了原来的判决定义

    第三，类别不平衡。 OVA 的每一个二类问题里，正类是 \(1\) 份、负类是 \(K-1\) 份。 \(K=10\) 时正负比例是 \(1:9\) —— 这正好踩在上一节讲的「最小二乘偏置被拉偏」的坑上 OvO 里每个问题是两个类，比例天然接近 \(1:1\)，就绕开了这个坑

    8.3 多类为什么不能直接类比两类¶

    一个必须点破的概念混淆。

    在两类问题里， 「\(g_1 \gt g_2\)」与「\(g_1 - g_2 \gt 0\)」是同一件事 —— 所以只需要一个判别函数。

    在多类问题里，这个等价关系就断了：

    情形 判别函数个数 判决方式
    两类 \(1\) 个（\(g = g_1 - g_2\)）✓ 看符号 ✓
    \(K\) 类，用每个类一个分数 \(K\) 个 ✓ 取最大 ✓
    \(K\) 类，用两两之差 \(\frac{K(K-1)}{2}\) 个 两两比较 + 投票

    为什么「\(K\) 个函数 + 取最大」是主流： 它把「\(K\) 个类互相比较」简化为「每个类算一个分数，比大小」， 训练和判决都最省事

    代价是：判别函数的值不再是「有向距离」 两类时 \(g(x)\) 除以 \(\lVert\boldsymbol{w}\rVert\) 有几何意义； \(K\) 类时 \(g_k(x)\) 的绝对值只是分数的量纲， 跨类比较才有意义，它本身不代表到任何边界的距离 这一点在做拒识、阈值判决时特别容易出错。

    8.4 三种方案的选择建议¶

    场景 推荐 理由
    类别数少（\(K \leq 4\)） OVA 分类器少、实现简单、够用 ✓
    类别数多、单分类器训练慢 OvO 每个分类器只碰两类样本，训练快 ✓
    需要容错、允许冗余 ECOC 码距提供纠错能力 ✓
    类别严重不平衡 OvO 或 ECOC 避开 \(1:(K-1)\) 的正负比 ⚠
    要求判决处处有定义 ECOC 不存在 0 票或平票区 ✓
    追求可解释、要画出来 OVA 每个类一条边界，看得见 ✓

    最后一行值得多说一句：OVA 的第 \(k\) 个判别函数 本身是一条超平面，可以画出来、 也能解释成「这个类的分数由哪些特征决定」。 OvO 与 ECOC 的判决是投票或查表的结果， 没有一个对应的单一超平面 —— 可解释性差得多

    九、线性方法的固有局限¶

    9.1 异或问题：线性分类器的试金石¶

    异或（XOR）问题是线性分类器能力的标准反例。

    数据：四个样本，两个特征，取值都是 \(\pm 1\)：

    样本 \(x_1\) \(x_2\) 类别
    1 \(+1\) \(+1\) \(\omega_1\)
    2 \(-1\) \(-1\) \(\omega_1\)
    3 \(+1\) \(-1\) \(\omega_2\)
    4 \(-1\) \(+1\) \(\omega_2\)

    类别规律：\(x_1 x_2 = +1\) 时属于 \(\omega_1\)， \(x_1 x_2 = -1\) 时属于 \(\omega_2\) —— 这就是「异或」。

    几何上看：\(\omega_1\) 的两个点在第一、第三象限， \(\omega_2\) 的两个点在第二、第四象限 —— 它们排成交叉的两条对角线。

    结论：没有任何一条直线能把它们分开

    9.2 为什么分不开：两条独立的理由¶

    理由一：凸包判据（几何）。

    判据：两个集合能被超平面分开，当且仅当它们的凸包不相交

    • \(\omega_1\) 的凸包是从 \((1,1)\) 到 \((-1,-1)\) 的线段
    • \(\omega_2\) 的凸包是从 \((1,-1)\) 到 \((-1,1)\) 的线段

    两条线段都在原点相交 → 凸包相交 → 不可分

    这个判据的价值在于它是「集合层面」的： 它不依赖于用什么准则去训练， 所以能一次性断言「所有线性判别函数都做不到」

    理由二：代数验证（不等式相加出矛盾）。

    假设存在 \(w_1, w_2, b\) 使得四个不等式都成立：

    样本 要求
    \((+1, +1) \in \omega_1\) \(w_1 + w_2 + b \gt 0\)
    \((-1, -1) \in \omega_1\) \(-w_1 - w_2 + b \gt 0\)
    \((+1, -1) \in \omega_2\) \(w_1 - w_2 + b \lt 0\)
    \((-1, +1) \in \omega_2\) \(-w_1 + w_2 + b \lt 0\)

    把前两个不等式相加：左边是 \(2b\)，右边是 \(0\)，所以 \(b \gt 0\)。 把后两个不等式相加：左边是 \(2b\)，右边是 \(0\)，所以 \(b \lt 0\)。

    \(b \gt 0\) 与 \(b \lt 0\) 同时成立，矛盾 —— 所以这样的 \(w_1, w_2, b\) 不存在

    这个证明很短、很干净，而且不依赖任何几何直觉， 非常适合手写

    异或不可分是「线性」的局限，不是「分类器」的局限

    容易把这件事说成「感知器太笨」或「最小二乘不够好」。 这是错的。

    判据是集合层面的：只要两类样本的凸包相交， 任何线性判别函数（不论用哪种准则去定参数） 都不可能把它们分开

    所以异或问题上的失败与算法无关， 是「用超平面做划分」这个假设失败了。

    9.3 出路：把异或变成线性可分¶

    解法一：加一个交叉项。

    取 \(\phi(x) = (x_1, x_2, x_1 x_2)\)， 则 \(g(x) = w_1x_1 + w_2x_2 + w_3x_1x_2 + b\)。

    取 \(w_1 = w_2 = 0\)、\(w_3 = 1\)、\(b = 0\)，则 \(g(x) = x_1 x_2\) —— \(\omega_1\) 处 \(g \gt 0\)、\(\omega_2\) 处 \(g \lt 0\)，完全正确

    这就是第三节讲的广义线性判别函数： 在原始二维空间里它是双曲线（不是直线）， 但在三维的 \(\phi\) 空间里它是一个平面

    解法二：加一个隐藏层。

    先分别判断「横坐标为正」与「纵坐标为正」， 再把两个结果组合（相同判 \(\omega_1\)、不同判 \(\omega_2\)）—— 这就是两层网络的最小版本。 异或问题正是「单层不行、两层行」的经典例子

    解法三：换用非参数方法。

    用 K 近邻：异或的四个点互相距离都不小， \(K = 1\) 就能全部分对 （这也说明：上一页的非参数方法不受这个限制）

    三条出路的共同点：

    解法 本质 代价
    加交叉项 特征变换（显式设计） 需要人工设计特征 ⚠
    加隐藏层 特征变换（学出来的） 参数变多、需要更多样本 ⚠
    换非参数方法 放弃「边界是超平面」 判决慢、要存全部样本 ⚠

    读这张表：三条路的本质是同一件事 —— 放弃「边界必须是超平面」 ✓ 区别只在「谁来放弃」：人（设计特征）、网络（学特征）、还是方法本身。

    所以线性分类器的定位应该这样说： 它是「一切方法的基本构件」，不是「一个够用就够了的方案」。 遇到线性不可分，要换的不是算法，而是表示

    例题 1：判别函数的几何量手算¶

    题目：已知 \(g(x) = 2x_1 - x_2 - 1\)。 （甲）写出 \(\boldsymbol{w}\) 与 \(b\)，并求 \(\lVert\boldsymbol{w}\rVert\)； （乙）求点 \(x_0 = (2, 1)^{\mathsf T}\) 的判别函数值与到决策面的有向距离； （丙）求 \(x_0\) 在决策面上的正交投影点； （丁）判断点 \((-1.5, 1)^{\mathsf T}\) 属于哪一类。

    思路

    这是第一节的四个基本量，全是直接套公式： \(\boldsymbol{w}\) 取 \(g\) 的一次项系数，\(b\) 取常数项； 有向距离用 \(g/\lVert\boldsymbol{w}\rVert\)； 投影点用「减掉沿法向的分量」。

    注意（丁）要算完判别函数看符号， 不要凭坐标位置猜

    解答

    （甲）读出参数并求模长。

    一次项系数直接读出来：\(\boldsymbol{w} = (2, -1)^{\mathsf T}\)，\(b = -1\)。

    \[\lVert\boldsymbol{w}\rVert = \sqrt{2^2 + (-1)^2} = \sqrt{5} \approx 2.236068\]

    （乙）算判别函数值与有向距离。

    \[g(x_0) = 2 \times 2 - 1 \times 1 - 1 = 4 - 1 - 1 = 2\]
    \[r(x_0) = \frac{g(x_0)}{\lVert\boldsymbol{w}\rVert} = \frac{2}{2.236068} \approx 0.894427\]

    正值表示 \(x_0\) 在 \(\boldsymbol{w}\) 指向的那一侧， 也就是 \(\omega_1\) 那一边 ✓

    注意：\(g(x_0) = 2\) 而距离是 \(0.894\) —— 两者数值不同，这正是 1.3 节强调的重点 ⚠

    （丙）求正交投影点。

    用公式 \(x_p = x_0 - \dfrac{g(x_0)}{\lVert\boldsymbol{w}\rVert^2}\boldsymbol{w}\)。 先算系数：

    \[\frac{g(x_0)}{\lVert\boldsymbol{w}\rVert^{2}} = \frac{2}{5} = 0.4\]

    再逐分量减：

    \[x_p = \begin{pmatrix} 2 \\ 1 \end{pmatrix} - 0.4\begin{pmatrix} 2 \\ -1 \end{pmatrix} = \begin{pmatrix} 1.2 \\ 1.4 \end{pmatrix}\]

    验算：\(g(x_p) = 2 \times 1.2 - 1.4 - 1 = 2.4 - 2.4 = 0\) 判别函数为 \(0\)，说明它确实落在决策面上

    （丁）判断 \((-1.5, 1)\) 的类别。

    \[g = 2 \times (-1.5) - 1 \times 1 - 1 = -3 - 1 - 1 = -5\]

    \(g \lt 0\)，判 \(\omega_2\)

    有向距离 \(= -5/2.236068 \approx -2.236068\) —— 负号表示在 \(\boldsymbol{w}\) 的反方向那一侧

    几个量的汇总：

    量 值 说明
    \(\boldsymbol{w}\) \((2, -1)^{\mathsf T}\) 法向量，定方向 ✓
    \(b\) \(-1\) 偏置，定位置 ✓
    \(\lVert\boldsymbol{w}\rVert\) \(2.236068\) 距离的换算系数
    \(g(x_0)\) \(2\) 不是距离 ⚠
    \(r(x_0)\) \(0.894427\) 才是距离 ✓
    投影点 \(x_p\) \((1.2, 1.4)^{\mathsf T}\) 落在决策面上 ✓

    同一组参数要算好几个量， 其中只有 \(r\) 有几何意义； \(g\) 的值随 \(\boldsymbol{w}\) 缩放而变， 拿它当距离是最常见的错误

    例题 2：用感知器准则手算一步修正¶

    题目：规范化样本为 \(z_1 = (1, 2, 1)^{\mathsf T}\)、 \(z_2 = (-2, 1, 1)^{\mathsf T}\)。 取 \(a_0 = (0, 0, 0)^{\mathsf T}\)，步长 \(\rho = 1\)。 （甲）按单样本修正法，逐个处理 \(z_1, z_2\)，写出每一步的 \(a\)； （乙）判断此时是否已经全部分对； （丙）说明「\(J_P(a) = 0\)」是否必然意味着「全部分对」。

    思路

    规则只有一条：拿当前 \(a\) 算 \(a^{\mathsf T}z_i\)， 若不大于 0 就修正 \(a \leftarrow a + \rho z_i\)，否则不动。

    注意是逐个样本走一遍（不是一次把所有错分样本加起来）， 而且要按题目给的点顺序处理

    （丙）问的是准则函数的一个细节， 请回去看 \(a = 0\) 处 \(J_P\) 的取值。

    解答

    （甲）逐步修正。

    第 1 步，处理 \(z_1\)。

    先算内积：\(a_0^{\mathsf T}z_1 = 0 + 0 + 0 = 0\)。

    \(0 \leq 0\) → 错分，修正：

    \[a_1 = a_0 + z_1 = (0,0,0) + (1,2,1) = (1, 2, 1)\]

    第 2 步，处理 \(z_2\)。

    算内积：

    \[ a_1^{\mathsf T}z_2 = 1 \times (-2) + 2 \times 1 + 1 \times 1 = -2 + 2 + 1 = 1 \]

    \(1 \gt 0\) → 已分对，不修正：

    \[a_2 = a_1 = (1, 2, 1)\]

    （乙）检查是否全部分对。

    样本 \(a_2^{\mathsf T}z_i\) 是否分对
    \(z_1 = (1,2,1)\) \(1 + 4 + 1 = 6\) ✓
    \(z_2 = (-2,1,1)\) \(-2 + 2 + 1 = 1\) ✓

    两个都大于 \(0\)，所以一轮就收敛了

    一般情形要反复扫过多轮，直到某一轮一个样本都不需要修正为止。 判据是「这一轮的修正次数为 0」， 而不是「所有 \(a^{\mathsf T}z_i\) 恰好相等」

    （丙）「\(J_P(a) = 0\)」并不必然意味着「全部分对」。

    反例就是初始点 \(a_0 = 0\)。此时：

    \[J_P(a_0) = \sum_{z_i \in \mathcal{M}}(-a_0^{\mathsf T}z_i) = 0 + 0 = 0\]

    但它显然不是解 —— 所有样本的内积都是 \(0\)， 一个都没被判对 ⚠

    原因是 \(J_P = 0\) 有两种可能：

    情形 错分集 \(\mathcal{M}\) \(J_P\) 是不是解
    \(a \neq 0\) 且无错分 空集 \(0\) ✓ 是解 ✓
    \(a = 0\) 全部样本（都满足 \(\leq 0\)）⚠ \(0\) ⚠ 不是解 ⚠

    区别在于「求和为空」还是「每一项都为零」 ✓

    这说明什么：准则函数与分类目标之间需要一个额外的条件 （\(a \neq 0\)）才能画等号 ⚠ 这也是实践里从 \(a = 0\) 出发时必须先修正一次的原因 —— 否则算法会「认为」已经没什么可做的了。

    例题 3：比较三种准则在同一数据上的行为¶

    题目：某数据集上， 感知器得到的最小投影是 \(0.078\)、\(\lVert\boldsymbol{w}\rVert = 4.71\)； 换成松弛准则（\(b = 1\)）后最小投影是 \(1.000\)、\(\lVert\boldsymbol{w}\rVert = 15.80\)。 （甲）两个解哪个「更好」，怎么比？ （乙）为什么松弛准则的投影大了十几倍，几何间隔却没涨那么多？ （丙）如果要求「噪声进来也不容易翻案」，该看哪个量？

    思路

    分清两个量：投影（\(a^{\mathsf T}z\)）与 几何间隔（投影除以 \(\lVert\boldsymbol{w}\rVert\)）。

    投影的单位与 \(a\) 的尺度绑定，几何间隔才是尺度无关的。 再想一下「噪声」在几何上是什么。

    解答

    （甲）不能直接比投影，要换成几何间隔。

    判据：投影是不可比的量。 松弛准则的 \(b = 1\) 只是把要求写进了目标函数， 它的解满足「投影 \(\geq 1\)」是算法的设计结果， 不代表它的边界在几何上离样本更远 ⚠

    正确的比较方式是把两者都换算成几何间隔：

    准则 最小投影 模长 几何间隔
    感知器 \(0.078\) \(4.71\) \(0.0166\)
    松弛（\(b = 1\)） \(1.000\) \(15.80\) \(0.0633\)

    换算公式：几何间隔 \(=\) 最小投影除以权向量的模长。

    换成几何间隔后，松弛确实更好（\(0.0633\) 对 \(0.0166\)） —— 但提升幅度约四倍，不是十几倍 ✓

    （乙）为什么投影涨了十几倍而几何间隔只涨四倍。

    因为 \(b\) 约束的是投影，而投影等于 模长乘以几何间隔（再乘一个固定的比例系数）。

    要让投影从 \(0.078\) 涨到 \(1.000\)，最省事的办法就是把 \(a\) 整体放大。 事实上模长从 \(4.71\) 涨到 \(15.80\)，放大了约 \(3.35\) 倍； 而几何间隔放大了 \(0.0633/0.0166 \approx 3.81\) 倍 —— 投影的放大倍数（约 \(12.8\) 倍）几乎全被模长的变大吃掉了 ⚠

    一句话：光靠「投影等于 \(b\)」这条约束，无法阻止模长跟着涨， 所以它对几何间隔只有间接、有限的提升作用 ✓

    （丙）该看几何间隔。

    理由：几何间隔是尺度无关的， 它直接量化「边界离最近的样本有多远」。

    噪声的几何含义：一个样本被扰动后移动了 \(\delta\)。 如果这个样本到边界的几何距离小于 \(\delta\)， 它就可能跨过边界，判决翻案 ⚠

    所以判据是：

    要做的事 看什么
    判断边界稳不稳 几何间隔 ✓
    判断感知器迭代停了没有 投影 \(a^{\mathsf T}z_i\) 的符号 ✓
    判断余量条件满足没满足 投影与 \(b\) 的大小 ✓
    想让边界真正稳 显式最大化几何间隔 ✓

    这说明什么：「余量」有两种含义 —— 数学上的「投影大于 \(b\)」与几何上的「距离大于某个量」。 松弛方法用的是前者，最大间隔方法用的是后者 ⚠ 混淆这两者，会把「松弛方法的解比较稳」这句话说过头。

    例题 4：判断该用多类方案的哪一种¶

    题目：四个场景，分别选一对多、一对一、还是多对多。 （甲）\(4\) 个类，样本干净、想要能画出来解释； （乙）\(26\) 个类，单个分类器训练一次要几小时； （丙）\(8\) 个类，个别类样本极少，且训练标签有噪声； （丁）\(3\) 个类，要求判决任何样本都有确定结果，不允许「无法判定」。

    思路

    从三个角度选：分类器个数（训练代价）、 正负样本比例（类别不平衡）、 是否存在不可判定区。 再考虑「要不要可解释」这个附加要求。

    解答

    （甲）一对多（OVA）。

    • \(K = 4\) 只训 \(4\) 个分类器，代价小 ✓
    • 每个分类器就是一条超平面，可以画出来解释 ✓
    • 这是「可解释性」硬要求下的首选 ⚠ （OvO 与 ECOC 的判决是投票或查表，没有单一超平面对应）

    （乙）一对一（OvO）。

    • 每对训一个分类器：\(\dfrac{26 \times 25}{2} = 325\) 个 —— 个数虽多，但每个只用两类的样本 ✓
    • OVA 的话，每个分类器都要用全部 26 类的样本， 单次训练时间接近原来的一类问题规模，乘以 \(26\) 之后总量更大 ⚠
    • 不要被「325 个分类器」这个数字吓住 —— 判决时可以配合剪枝，不必每次都跑完

    （丙）一对一，或纠错输出码。

    • OVA 的每个问题正负比是 \(1:7\)，正踩在类别不平衡的坑上 ⚠
    • OvO 每个问题只涉及两类，比例天然接近 \(1:1\) ✓
    • 训练标签有噪声 → 希望有容错 → 这正是 ECOC 的码距能提供的： 个别分类器判错不影响最终结果 ✓
    • 所以最优是 ECOC，OvO 也可以接受

    （丁）纠错输出码（ECOC）。

    • OVA 有「0 票」区域（没有任何类把样本判给自己）⚠
    • OvO 有「平票」情形 ⚠
    • ECOC 用「最近的码字」判决，任何输出向量都能找到最近的那个码字， 所以判决处处有定义 ✓
    • 唯一的例外是「恰好等距」，但那要求码字设计得极差， 用随机编码几乎不会遇到 ✓

    汇总表：

    场景 选择 关键理由
    甲 一对多 可解释、分类器少 ✓
    乙 一对一 单次训练代价分摊到两类的子集 ✓
    丙 多对多（ECOC） 容错 + 避开不平衡 ✓
    丁 多对多（ECOC） 判决处处有定义 ✓

    这说明什么：多类扩展没有「通用最优方案」， 选择取决于你更怕哪一种失败 —— 怕训练慢、怕不平衡、还是怕判决无定义 ⚠ 四个场景分别对应了四种不同的「怕」。

    Q1 判别函数 \(g(x) = \boldsymbol{w}^{\mathsf T}x + b\) 中， \(\boldsymbol{w}\) 与 \(b\) 各自决定决策面的什么？ 为什么 \(g(x)\) 本身不是「点到决策面的距离」， 而 \(g(x)/\lVert\boldsymbol{w}\rVert\) 是？ 两者相差的那个模长因子是干什么用的？

    Q2 增广特征写法把 \(b\) 吸收进权向量后， 决策面在增广空间里有什么变化？ 为什么这个变化能让「平移」这件事变得自然？ 再说明：为什么增广之后还要做「规范化」（把 \(\omega_2\) 的样本取反）？

    Q3 写出感知准则函数 \(J_P(a)\) 的定义， 并说明它与「全部分对」是不是无条件等价（提示：看看 \(a = 0\)）。 再看感知器收敛定理：它需要哪两个前提？ 定理的证明用了哪两个「界」？为什么这两个界冲突就能证明有限步收敛？ 最后说明：定理没有保证的两件事是什么。

    Q4 线性最小二乘在分类任务上有哪些固有缺陷？ 至少说出两条，并各说明它的根因（不要只说现象）。 再回答：异或问题为什么不可能被任何线性判别函数分开？ 给出几何与代数两条理由，并说明这个问题不是算法不够好造成的。

    小结¶

    要记住的 内容 易错点
    判别函数 \(g(x) = \boldsymbol{w}^{\mathsf T}x + b\)，符号定类别 把 \(g\) 的值当距离 ⚠
    \(\boldsymbol{w}\) 的作用 法向量，指向 \(g \gt 0\) 的一侧 以为 \(\boldsymbol{w}\) 决定位置 ⚠
    \(b\) 的作用 决定超平面平移多少 忘了 \(b = 0\) 时过原点
    有向距离 \(g(x)/\lVert\boldsymbol{w}\rVert\) 尺度无关，才是几何量 ✓
    正交投影 \(x_p = x - \dfrac{g(x)}{\lVert\boldsymbol{w}\rVert^2}\boldsymbol{w}\) 系数里是模长的平方 ⚠
    增广写法 \(\tilde{x} = (x, 1)\)，\(a = (\boldsymbol{w}, b)\) 决策面必过原点 ✓
    规范化 \(\omega_2\) 的样本整体取反 两类条件统一成 \(a^{\mathsf T}z \gt 0\) ✓
    广义线性 \(g(x) = \boldsymbol{w}^{\mathsf T}\phi(x) + b\) 对参数仍线性，旧结论全可用 ✓
    广义线性的代价 维数平方级增长 → 样本量要跟上 一上来就展开二次项 ⚠
    感知准则函数 \(J_P(a) = \sum_{z_i \in \mathcal{M}}(-a^{\mathsf T}z_i)\) 只在错分样本上求和 ✓
    感知准则的梯度 \(\nabla J_P = -\sum_{z_i \in \mathcal{M}} z_i\) 就是「错分样本之和取负」✓
    \(J_P = 0\) 的陷阱 \(a = 0\) 时 \(J_P = 0\) 但不是解 需 \(a \neq 0\) 才有等价性 ⚠
    单样本修正 \(a \leftarrow a + \rho z_i\) \(J_P\) 不保证单调下降 ⚠
    收敛定理前提 线性可分 + 常数步长 不可分时永不停止 ⚠
    收敛定理的两个界 模长下界线性增长、模长平方上界线性增长 冲突 → 有限步 ✓
    定理没保证的 收敛到哪个解、上界有多紧 解依赖顺序与初值 ⚠
    界 \((R/\gamma)^2\) 只是上界，可能极松（差几千倍） 但可用于诊断 \(\gamma\) 是否太小 ⚠
    松弛准则 \(J_r = \frac{1}{2}\sum\left(b-a^{\mathsf T}z_i\right)^2/\lVert z_i\rVert^2\) 除以模长平方归一化发言权 ✓
    余量 \(b\) 的含义 要求的最小投影 \(b\) 过大 → 无解、震荡 ⚠
    松弛 vs 几何间隔 投影受 \(b\) 约束，几何间隔不一定涨 想稳要显式约束模长 ⚠
    最小二乘的形式 \(a^{*} = (\tilde{X}^{\mathsf T}\tilde{X})^{-1}\tilde{X}^{\mathsf T}t\) 奇异时用伪逆 ✓
    最小二乘的缺陷一 惩罚「分类正确但离得远」的样本 目标值取 \(\pm 1\) 造成 ⚠
    最小二乘的缺陷二 对离群点极敏感（平方放大） 一个点就能支配目标 ⚠
    最小二乘的缺陷三 类别不平衡把偏置拉偏 边界朝少数类移动 ⚠
    多类方案 一对多 / 一对一 / 多对多 个数 \(K\)、\(\frac{K(K-1)}{2}\)、\(L\) ✓
    一对多的坑 有「0 票」不可判定区 + 正负比 \(1:(K-1)\) 必须补消歧规则 ⚠
    一对一的优点 每个问题只用两类样本 分类器个数多，但训练总量相近 ✓
    多对多的优点 码距提供纠错、判决处处有定义 需要设计编码 ✓
    线性方法的硬边界 异或问题不可分 与算法无关，是假设失败 ⚠
    异或的代数证明 前两式相加得 \(b \gt 0\)，后两式相加得 \(b \lt 0\) 矛盾 → 解不存在 ✓
    凸包判据 可分 ⟺ 两个凸包不相交 异或的两条凸包线段在原点相交 ✓
    出路 加交叉项 / 加隐藏层 / 换非参数方法 本质都是放弃超平面假设 ✓

    三条最该带走的结论：

    1. 线性分类器的全部设计工作，就是「挑一个准则函数」 —— 目标函数挑好了，剩下的都是求极值的技术问题。 感知准则、松弛准则、最小二乘的差别， 全在「求和范围」与「损失形状」这两处 ✓
    2. 收敛定理的价值在「有限步」三个字，不在那个数字 —— 它告诉我们「线性可分时一定能停」， 但停在哪、停多快，定理都不管。 所以实践中要看几何间隔，而不是看迭代次数 ⚠
    3. 遇到线性不可分，要换的是「表示」，不是「算法」 —— 异或问题换任何线性准则都无解， 但加一个交叉项就解决了。 这是通往特征工程与多层网络的那道门 ✓

    上一页：非参数方法 —— Parzen 窗与 K 近邻：不假设分布形状， 用样本邻域直接估计密度，边界形状完全由数据决定。

    下一页：非线性分类器 —— 本页最后留下的那道门： 一旦承认「边界不必是超平面」， 就要回答「那该是什么形状、又该怎么学出来」。
