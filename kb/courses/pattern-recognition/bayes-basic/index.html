    贝叶斯决策的数学基础¶

    这一页解决一个问题：怎么用概率把「我该判它属于哪一类」变成一次计算？

    先说清楚为什么需要概率。

    假设你要判断一条刚捕上来的鱼是鲈鱼还是三文鱼。 你手上唯一的依据是：这条鱼的长度 \(x\)。

    一个很自然的想法是定一条线：比 \(x\) 长的算三文鱼，比它短的算鲈鱼。 问题立刻来了：

    疑问 说明
    这条线划在哪？ 拍脑袋定，没有任何依据
    两种鱼长度有重叠怎么办？ 一定会有重叠，重叠区怎么判都是猜
    判错了谁的损失大？ 如果三文鱼贵十倍，判错方向不一样代价不一样

    贝叶斯决策就是给这三个问题一个统一答案的框架： 它把「先验知识」「观测证据」「判决代价」三样东西 用一个公式合起来，并且证明这样做的平均错误率最低。

    这一页先把三个基本零件讲清楚：先验概率、类条件概率密度、后验概率。 下一节（最小错误率决策）再讲怎么用它们判决。

    这一页的主线

    整页只围绕一个公式展开 —— 贝叶斯公式：

    \[\underbrace{P(\omega_i \mid x)}_{\text{后验}} = \frac{\overbrace{p(x \mid \omega_i)}^{\text{似然}} \cdot \overbrace{P(\omega_i)}^{\text{先验}}}{\underbrace{p(x)}_{\text{证据}}}\]

    读懂它的关键是搞清四个名字分别对应「我们已知什么」和「我们想求什么」： 我们能测的是 \(x\)，我们想求的是「\(x\) 属于各类的可能性」， 而这个公式告诉我们：只要知道先验和似然，后验就自动确定了 ✓

    一、问题设定：三个符号先说清¶

    先把整章的记号统一，后面不再重复。

    符号 念法 含义 我们是否已知
    \(\omega\) omega 类别（随机变量） —
    \(\omega_1, \omega_2, \dots, \omega_c\) — 具体的 \(c\) 个类别 已知有哪些类
    \(x\) — 特征向量（观测到的数据） 可以测到 ✓
    \(P(\omega_i)\) 「omega i 的先验」 类别 \(\omega_i\) 出现的概率 需要事先知道
    \(p(x \mid \omega_i)\) 「给定 omega i 时 x 的密度」 类别 \(i\) 的类条件概率密度 需要事先知道
    \(P(\omega_i \mid x)\) 「给定 x 时 omega i 的后验」 看到 \(x\) 之后，它属于类 \(i\) 的概率 想求的目标 ✓

    为什么类别与特征一个用希腊字母、一个用拉丁字母？

    本页统一用这个约定（很多教材也这么做）：

    记号 类型 说明
    \(P(\cdot)\) 大写 P 概率 用于离散随机变量，取值是「概率」
    \(p(\cdot)\) 小写 p 密度 用于连续随机变量，取值是「概率密度」

    为什么必须区分：连续情形下 \(p(x \mid \omega_i)\) 的值不是概率， 它可以大于 1（比如 \(x\) 是方差很小的正态分布时，峰值密度可达几百）。 概率必须 ≤ 1，密度不必 —— 这是初学最容易混的一点 ⚠

    好消息：贝叶斯公式在两种情形下形式完全一样， 而且判决规则只用到比值，密度里那个 「不是概率」的常数会约掉。所以本页先按连续情形讲 ✓

    两类问题的具体设定（后面反复用它）¶

    为了让每一步都能手算，我们固定一个最简单的场景：

    设定 值
    类别数 \(c = 2\)，即 \(\omega_1\)（鲈鱼）、\(\omega_2\)（三文鱼）
    特征 \(x\) = 鱼的长度（一维，单位：厘米）
    先验 \(P(\omega_1) = 0.6\)，\(P(\omega_2) = 0.4\)
    类条件密度 都当作正态分布（下一节给出具体参数）

    先验的两个基本性质（后面会用到）：

    \[P(\omega_1) + P(\omega_2) = 1, \qquad P(\omega_i) \geq 0\]

    第一条叫归一化，第二条叫非负性。 如果 \(c\) 类，则 \(\sum_{i=1}^{c} P(\omega_i) = 1\)。

    为什么求和必须是 1：因为每条鱼必然属于某一类， 把所有类别的概率加起来就是「所有可能」的总概率 ✓

    二、先验概率：还没看数据时，我们已经知道什么¶

    定义：\(P(\omega_i)\) 是在看到特征 \(x\) 之前， 一个样本属于类 \(\omega_i\) 的概率。

    为什么叫「先」 —— 它表示先于观测的知识。 在鱼这个例子里，它的来源是：

    来源 说明
    渔场地点 不同海域两种鱼的比例不同
    季节 洄游季节某一种会明显变多
    历史统计 长期捕捞记录给出的经验比例

    注意先验不是「瞎猜」 —— 它是已有的、来自经验或历史数据的量化知识。 这一点很重要：贝叶斯方法不是「主观随意」， 而是把已知信息明确写成数字，方便后面和观测证据结合 ⚠

    如果只用先验会怎样¶

    既然知道 \(P(\omega_1) = 0.6 \gt P(\omega_2) = 0.4\)， 一个最朴素的判决规则是：

    \[\text{判为 } \omega_1,\quad \text{当 } P(\omega_1) \gt P(\omega_2); \qquad \text{否则判为 } \omega_2\]

    但这个规则完全不看鱼的长度 —— 每条鱼都判成鲈鱼。

    现象 后果
    规则与 \(x\) 无关 所有样本判同一类，等于没做识别 ✗
    错误率 = 少数类的比例 本例为 \(P(\omega_2) = 0.4\)，即错 40% ✗

    错误率怎么算：既然永远判 \(\omega_1\)， 那么只有真正是 \(\omega_2\) 的样本会错，所以

    \[P(\text{error}) = P(\omega_2) = 0.4\]

    这告诉我们一件事：先验有用，但远远不够。 必须引入「观测信息」✓ 这就是下一节。

    三、类条件概率密度：每一类自己的「长相」¶

    定义：\(p(x \mid \omega_i)\) 是在已知样本属于类 \(\omega_i\) 的条件下， 特征 \(x\) 的概率密度。

    怎么读这个式子：竖线读作「在……条件下」， 所以 \(p(x \mid \omega_i)\) 读作 「给定类别是 \(\omega_i\) 时，特征取 \(x\) 的密度」。

    直觉：它描述第 \(i\) 类样本在特征空间里长什么样。

    类别 可能的样子
    \(\omega_1\)（鲈鱼） 长度集中在较小值附近
    \(\omega_2\)（三文鱼） 长度集中在较大值附近

    为什么叫「类条件」 —— 它的条件是「类别已知」。 这一点最容易搞混，下面专门辨析。

    p(x|ω) 和 P(ω|x) 的区别：这是全章最容易搞反的地方

    两者的条件与结果完全对调：

    \(p(x \mid \omega_i)\) \(P(\omega_i \mid x)\)
    读作 给定类别，特征的密度 给定特征，类别的概率
    谁是被条件 类别 特征
    谁是结果 特征 类别
    实际含义 「鲈鱼的长度分布」 「长 20cm 的鱼是鲈鱼的概率」
    怎么得到 训练阶段估出来 ✓ 判决时用公式算 ✓
    在公式里的名字 似然 后验

    一句话记住： \(p(x \mid \omega)\) 是「从类别推特征」（建模时用）， \(P(\omega \mid x)\) 是「从特征推类别」（判决时用）。 我们要的是后者，但能直接估的只有前者 —— 贝叶斯公式的作用正是把前者转成后者 ✓

    为什么会搞反：因为写出来长得像，只差两个符号的位置。 建议每次看到条件概率，先念一遍「在……条件下」， 确认谁是被条件的那个 ⚠

    用正态分布给一个具体例子¶

    本页固定用这两个密度（下一节 高斯密度下的判别函数 会系统讲）：

    \[p(x \mid \omega_1) = \frac{1}{\sqrt{2\pi}\,\sigma_1}\exp\!\left[-\frac{(x-\mu_1)^2}{2\sigma_1^2}\right], \quad \mu_1 = 15,\ \sigma_1 = 3\]
    \[p(x \mid \omega_2) = \frac{1}{\sqrt{2\pi}\,\sigma_2}\exp\!\left[-\frac{(x-\mu_2)^2}{2\sigma_2^2}\right], \quad \mu_2 = 22,\ \sigma_2 = 4\]

    参数的读法：

    符号 含义 本页取值
    \(\mu_i\) 第 \(i\) 类长度的均值 15 cm、22 cm
    \(\sigma_i\) 第 \(i\) 类长度的标准差 3 cm、4 cm
    \(\sigma_i^2\) 方差 9、16

    两个密度的形状差异说明什么：

    观察 含义
    \(\mu_1 \lt \mu_2\) 鲈鱼平均更短
    \(\sigma_1 \lt \sigma_2\) 鲈鱼长度更集中，三文鱼更分散
    两条曲线在某个位置相交 交点附近两类同样可能，最难判 ✓

from scipy.stats import norm

# 两类的类条件密度参数
mu1, s1 = 15.0, 3.0     # 鲈鱼：均值 15cm，标准差 3cm
mu2, s2 = 22.0, 4.0     # 三文鱼：均值 22cm，标准差 4cm

# 看几个具体长度处的密度值
for x in [10.0, 15.0, 20.0, 22.0, 30.0]:

    p2 = norm.pdf(x, mu2, s2)
    print("x=%5.1f  p(x|w1)=%.6f  p(x|w2)=%.6f  谁大: %s"
          % (x, p1, p2, "w1" if p1 > p2 else "w2"))

x= 15.0  p(x|w1)=0.132981  p(x|w2)=0.021569  谁大: w1

    注意 x=15 那一行：\(p(x\mid\omega_1)\) 达到峰值 （因为 15 正是 \(\mu_1\)），但 \(p(x \mid \omega_2)\) 也不小 —— 这就是重叠区 ✓

    密度值可以大于 1，这不是错误

    如果把 \(\sigma_1\) 改成 0.5，会发现 \(p(15 \mid \omega_1)\) 的数值能到 0.8 甚至更大， 而 \(\sigma_1 = 0.05\) 时能超过 7。

    为什么：密度的单位是「概率 / 单位长度」， 区间越窄、峰值越高，但曲线下总面积恒为 1。 所以密度值本身没有「≤ 1」的限制 ⚠

    怎么正确理解密度：不能问「\(x\) 恰好等于 15 的概率」 （连续情形下这个概率是 0）， 只能问「\(x\) 落在 \([14.5, 15.5]\) 的概率」， 它约等于 \(p(15) \times 1\)。密度的作用是「乘以区间长度得到概率」 ✓

    四、后验概率：看到数据之后，我们的判断是什么¶

    定义：\(P(\omega_i \mid x)\) 是在观测到特征 \(x\) 之后， 样本属于类 \(\omega_i\) 的概率。

    为什么叫「后」 —— 它表示后于观测的知识 ✓

    这才是我们真正想要的量 —— 因为「这条鱼长 20cm，它是鲈鱼的概率」正是判决需要的信息。

    问题：这个量没法直接统计出来。 你没法去数「世界上所有长 20.0000cm 的鱼里有多少是鲈鱼」—— 长度是连续变量，每一个具体值的样本数都是 0 ⚠

    那怎么办：用贝叶斯公式从能估的量算出来 ✓

    五、贝叶斯公式：把「能估的」转成「想要的」¶

    5.1 先看两个更简单的规则¶

    规则一：乘法法则（联合概率）

    两个事件同时发生的概率：

    \[P(\omega_i, x) = P(\omega_i \mid x)\, p(x)\]

    怎么读：读作「先有 \(x\)，再在 \(x\) 里找 \(\omega_i\)」。 先乘「\(x\) 发生的密度」\(p(x)\)， 再乘「在 \(x\) 里属于 \(\omega_i\) 的比例」\(P(\omega_i \mid x)\) ✓

    同一个联合概率也可以反过来拆：

    \[P(\omega_i, x) = p(x \mid \omega_i)\, P(\omega_i)\]

    怎么读：读作「先有类别 \(\omega_i\)，再在 \(\omega_i\) 里找 \(x\)」。 先乘「类别 \(i\) 的概率」\(P(\omega_i)\)， 再乘「在这一类里取到 \(x\) 的密度」\(p(x \mid \omega_i)\) ✓

    两条式子左边相等（都是同一个联合概率），所以：

    \[P(\omega_i \mid x)\, p(x) = p(x \mid \omega_i)\, P(\omega_i)\]

    5.2 移项就得到贝叶斯公式¶

    把上式两边同除以 \(p(x)\)（只要 \(p(x) \gt 0\)）：

    \[\boxed{\,P(\omega_i \mid x) = \frac{p(x \mid \omega_i)\, P(\omega_i)}{p(x)}\,}\]

    这就是贝叶斯公式。 整个推导只用了「同一个联合概率可以两种方式拆」+「移项」， 没有任何跳步 ✓

    5.3 分母 \(p(x)\) 怎么算：全概率公式¶

    \(p(x)\) 的含义：不管属于哪一类，特征取 \(x\) 的密度。 它叫证据（evidence）。

    怎么求：既然样本必然属于某一类，而各类互斥， 那么「取到 \(x\)」这件事就是「取到 \(x\) 且属于 \(\omega_1\)」 或「取到 \(x\) 且属于 \(\omega_2\)」…… 把所有类加起来：

    \[p(x) = \sum_{j=1}^{c} p(x \mid \omega_j)\, P(\omega_j)\]

    这个式子是全概率公式在连续情形下的写法。 两类时展开：

    \[p(x) = p(x \mid \omega_1)P(\omega_1) + p(x \mid \omega_2)P(\omega_2)\]

    5.4 把两个式子合起来：完整形式¶

    \[P(\omega_i \mid x) = \frac{p(x \mid \omega_i)\, P(\omega_i)}{\displaystyle\sum_{j=1}^{c} p(x \mid \omega_j)\, P(\omega_j)}\]

    这个分母有一个非常重要的性质：

    分母与类别无关 —— 这是判决能大幅简化的原因

    看公式：分母的求和里，\(j\) 从 1 到 \(c\) 遍历所有类别， 里面没有出现 \(i\)。也就是说：

    观察 含义
    分母对 \(\omega_1, \omega_2, \dots, \omega_c\) 是同一个值 它是 \(x\) 的函数，不是类的函数 ✓
    它的作用只是归一化 保证 \(\sum_i P(\omega_i \mid x) = 1\) ✓
    比较各类后验时它可以不管 因为同分母比较分子就行 ✓

    这条性质直接引出判决规则：要比较 \(P(\omega_1 \mid x)\) 和 \(P(\omega_2 \mid x)\)， 只需要比较分子 \(p(x \mid \omega_1)P(\omega_1)\) 和 \(p(x \mid \omega_2)P(\omega_2)\) ✓

    所以后面会把分子单独起个名字 —— 下一节的「判别函数」\(g_i(x)\)。

    三个高频混淆点

    混淆一：把似然说成「类别的概率」

    ✗ 错：\(p(x \mid \omega_1) = 0.8\) 表示「80% 的可能是鲈鱼」。 ✓ 对：它表示「如果它是鲈鱼，长度取到 \(x\) 的密度是 0.8」。 区别在于 \(p(x\mid\omega)\) 完全没有告诉你「它是不是鲈鱼」 —— 那要看先验和后验 ⚠

    混淆二：认为先验「不客观」所以不可信

    先验确实依赖来源，但贝叶斯公式的价值正在于「先验不精确也能用」： 数据足够多时，似然会主导结果，先验被「洗掉」。 而且先验写出来了就可以被讨论、被修正 —— 比藏在脑子里不写出来要好得多 ✓

    混淆三：把 \(P(\omega_i \mid x)\) 的 \(x\) 当成「事件」

    连续情形下 \(P(\omega_i \mid x)\) 里的 \(x\) 是一个具体的值， 不是事件。严格写法是对「\(x\) 落在 \(x\) 的小邻域内」取极限。 但在判决时我们只比较不同 \(i\) 的后验， 邻域长度相同会约掉，所以可以放心地写成 \(P(\omega_i \mid x)\) ✓

    七、完整手算例子：HIV 检测¶

    这是贝叶斯公式最著名的例子，因为它违反直觉， 正好能检验你是否真的理解了先验的作用。

    7.1 题目¶

    某市居民做 HIV 血液检测，结果呈阳性。已知三个数字：

    已知 值 含义
    患病率 \(p = 0.0001\) 全市约万分之一的人携带 HIV
    灵敏度 \(0.99\) 患病者中检测阳性的概率
    误检率 \(0.01\) 未患病者中检测阳性的概率

    问：检测呈阳性的人，真正携带 HIV 的概率是多少？

    7.2 建模：把文字翻译成符号¶

    先定义事件与假说：

    记号 事件
    \(\omega_1\) 携带 HIV（患病）
    \(\omega_2\) 不携带 HIV
    \(T\) 检测结果为阳性
    \(\bar{T}\) 检测结果为阴性

    把三个已知数字对应到符号上（这一步最容易出错，务必核对）：

    文字描述 符号 值
    患病率 \(P(\omega_1)\) \(0.0001\)
    灵敏度：患病者检测阳性的概率 \(P(T \mid \omega_1)\) \(0.99\)
    误检率：未患病者检测阳性的概率 \(P(T \mid \omega_2)\) \(0.01\)

    我们要求的目标是 \(P(\omega_1 \mid T)\) —— 注意方向和已知量相反 ✓

    7.3 先算两个互补的概率¶

    注意：已知量给的是「患病/未患病」下的检测概率， 但我们还需要「患病/未患病」各自的先验：

    \[P(\omega_2) = 1 - P(\omega_1) = 1 - 0.0001 = 0.9999\]

    这一步不能漏 —— 分母要用到它 ⚠

    7.4 代入贝叶斯公式¶

    \[P(\omega_1 \mid T) = \frac{P(T \mid \omega_1)\, P(\omega_1)}{P(T \mid \omega_1)P(\omega_1) + P(T \mid \omega_2)P(\omega_2)}\]

    分母用全概率公式展开成两项（因为只有两类：患病 / 未患病）。

    先算分子：

    \[P(T \mid \omega_1) P(\omega_1) = 0.99 \times 0.0001 = 0.000099\]

    再算分母的两项：

    \[\begin{aligned} P(T \mid \omega_1) P(\omega_1) &= 0.99 \times 0.0001 = 0.000099 \\ P(T \mid \omega_2) P(\omega_2) &= 0.01 \times 0.9999 = 0.009999 \end{aligned}\]

    分母 就是两项之和：

    \[P(T) = 0.000099 + 0.009999 = 0.010098\]

    最后相除：

    \[P(\omega_1 \mid T) = \frac{0.000099}{0.010098} \approx 0.009804 \approx 0.98\%\]

    7.5 结果解读 —— 这就是反直觉的地方¶

    量 值 说明
    检测灵敏度 99% 患病者几乎都能查出来
    误检率 1% 未患病者只有 1% 误报
    阳性者真正患病的概率 0.98% 远低于直觉的 99% ⚠

    为什么这么低：关键在于基率（先验）。

    想象 100 万人来做检测：

    人群 人数 检测结果
    真患病 \(10^6 \times 0.0001 = 100\) 人 约 99 人阳性 ✓
    未患病 \(10^6 \times 0.9999 \approx 999900\) 人 约 \(999900 \times 0.01 \approx 9999\) 人误报阳性 ✗
    阳性总数 — \(99 + 9999 = 10098\) 人

    在这 10098 个阳性里，真患病的只有 99 人：

    \[\frac{99}{10098} \approx 0.0098 \approx 0.98\%\]

    看清楚了：不是检测不准，而是未患病的人太多了 —— 哪怕只有 1% 误报，绝对人数（9999）也远远盖过真患病的人数（99）✓

    基率谬误（base rate fallacy）

    这个现象有个专门的名字，值得记住：

    直觉判断 实际
    「灵敏度 99%，所以阳性就是 99% 患病」 错误：忽略了基率
    只看 \(P(T \mid \omega_1)\) 忘了先验 \(P(\omega_1)\) 极小

    判断自己有没有犯这个错的方法： 问一句「这个病本身有多常见」。 如果答案是很罕见，那任何检测的阳性结果都需要再确认一次 ✓

    实践含义：这就是为什么筛查会「初筛 + 复检」—— 复检时的先验已经变成「初筛阳性者」，基率大幅提高， 第二次阳性的后验就会高得多。

    八、贝叶斯方法适用在哪、前提是什么¶

    课件里提到的领域（这里只列领域，不涉及具体机构）：

    领域 用贝叶斯做什么
    生物信息 基因调控关系推断
    金融 投资策略、风险定价
    文本 垃圾邮件过滤
    自动驾驶 结合传感器与地图做决策
    语音与语言处理 语言模型、机器翻译
    现代 AI 贝叶斯推断、贝叶斯神经网络、贝叶斯优化

    原理都一样：信息不全 → 用先验补上 → 观测到了就更新 → 得到新的判断 ✓

    但贝叶斯决策的前提必须说清¶

    贝叶斯最优性的三个前提，违反了就不最优

    前提 含义 违反了会怎样
    1. 类别数已知且固定 判决只在给定的 \(c\) 类里选 出现新类别会强行归到旧类 ✗
    2. 先验与类条件密度已知 \(P(\omega_i)\)、\(p(x\mid\omega_i)\) 都要知道 实际中几乎不可能，只能估 ⚠
    3. 每类样本独立同分布 样本之间互不影响 样本相关时概率会算错

    第 2 条是最大的现实障碍： 真实问题里没人告诉你真实分布的参数。 所以实际做法是：

    阶段 做什么
    训练 用训练样本估 \(P(\omega_i)\)（数频率）和 \(p(x\mid\omega_i)\)（假定形状 + 估参数，如最大似然）
    测试 把估出来的参数当真实的用，按贝叶斯规则判决

    这样得到的结果就不再是「理论最优」了 —— 它是「在参数估计正确的前提下最优」。 参数估得不准，性能就会下降 ✓

    这也是后面几章存在的原因： 从「假定分布已知」走向「分布未知时也能分类」， 就是下一节之后要逐步展开的内容。

    九、典型例题¶

    例题 1：两个后验的直接计算¶

    沿用本页设定（\(\mu_1=15,\sigma_1=3\)，\(\mu_2=22,\sigma_2=4\)， \(P(\omega_1)=0.6\)），求 \(x = 18\) 时的两个后验概率， 并判断该判给哪一类。

    思路

    三步走：先算两个似然（用正态密度公式）， 再乘各自先验得到分子，最后用全概率公式算分母并归一化。

    解答

    第一步：算似然。 正态密度：

    \[p(x \mid \omega_i) = \frac{1}{\sqrt{2\pi}\,\sigma_i}\exp\!\left[-\frac{(x-\mu_i)^2}{2\sigma_i^2}\right]\]

    对 \(\omega_1\)（\(\mu_1=15,\sigma_1=3\)，\(x=18\)）：

    \[\frac{(18-15)^2}{2 \times 3^2} = \frac{9}{18} = 0.5\]
    \[\frac{1}{\sqrt{2\pi}\times 3} = \frac{1}{7.5199} \approx 0.13300\]
    \[p(18 \mid \omega_1) \approx 0.13300 \times e^{-0.5} \approx 0.13300 \times 0.60653 \approx 0.08066\]

    对 \(\omega_2\)（\(\mu_2=22,\sigma_2=4\)，\(x=18\)）：

    \[\frac{(18-22)^2}{2 \times 4^2} = \frac{16}{32} = 0.5\]
    \[\frac{1}{\sqrt{2\pi}\times 4} = \frac{1}{10.0265} \approx 0.09974\]
    \[p(18 \mid \omega_2) \approx 0.09974 \times 0.60653 \approx 0.06049\]

    第二步：乘先验得分子。 注意两个指数的 \(e^{-0.5}\) 恰好相同（因为 \((18-15)^2/18 = (18-22)^2/32 = 0.5\)）， 所以差别只来自前面的系数和先验。

    \[p(x\mid\omega_1)P(\omega_1) \approx 0.08066 \times 0.6 \approx 0.04840\]
    \[p(x\mid\omega_2)P(\omega_2) \approx 0.06049 \times 0.4 \approx 0.02420\]

    第三步：归一化求后验。

    分母（全概率）：

    \[p(18) \approx 0.04840 + 0.02420 = 0.07260\]

    后验：

    \[P(\omega_1 \mid 18) \approx \frac{0.04840}{0.07260} \approx 0.6667\]
    \[P(\omega_2 \mid 18) \approx \frac{0.02420}{0.07260} \approx 0.3333\]

    判决：因为 \(P(\omega_1 \mid 18) \gt P(\omega_2 \mid 18)\)， 判为鲈鱼（\(\omega_1\)）✓

    例题 4：为什么分母可以对不同类共用¶

    给出一个具体数值例子，说明「比较后验」和「比较分子」 会得到完全相同的判决，并解释原因。

    思路

    取三个不同的 \(x\)，同时算出后验和分子， 检查两者的排序关系是否总是一致。

    解答

    先讲原因：设两类，分母记为 \(D(x) = p(x\mid\omega_1)P(\omega_1) + p(x\mid\omega_2)P(\omega_2)\)。 它是正的（两个密度都 ≥ 0，且至少一个严格为正）， 而且对 \(\omega_1\) 和 \(\omega_2\) 是同一个数。所以

    \[P(\omega_1\mid x) \gt P(\omega_2\mid x) \iff \frac{N_1}{D} \gt \frac{N_2}{D} \iff N_1 \gt N_2\]

    其中 \(N_i = p(x\mid\omega_i)P(\omega_i)\) 是分子。 除以同一个正数不改变不等号方向 ✓

    Q3 某系统两类先验相等（各 0.5）。 已知 \(p(x\mid\omega_1) = 0.2\)、\(p(x\mid\omega_2) = 0.8\)。 求 \(p(x)\)、两个后验，并判断「先验相等时，判决是否等价于比较似然」。

    提示

    先验相等时分子只剩 \(\frac{1}{2}\) 倍，看它会不会影响大小关系。

    解答

    分母：

    \[p(x) = 0.2 \times 0.5 + 0.8 \times 0.5 = 0.1 + 0.4 = 0.5\]

    后验：

    \[P(\omega_1\mid x) = \frac{0.1}{0.5} = 0.2, \qquad P(\omega_2\mid x) = \frac{0.4}{0.5} = 0.8\]

    发现：后验恰好等于似然（\(0.2\) 和 \(0.8\)）。 这不是巧合：

    \[P(\omega_i \mid x) = \frac{p(x\mid\omega_i) \times \frac{1}{c}}{\sum_j p(x\mid\omega_j)\times \frac{1}{c}} = \frac{p(x\mid\omega_i)}{\sum_j p(x\mid\omega_j)}\]

    共同的 \(\frac{1}{c}\) 被约掉了 ✓

    所以结论：先验相等时，比较后验等价于比较似然。

    先验 判决依据
    相等（均匀先验） 直接比似然 ✓ 这就是最大似然（ML）判决
    不等 必须比似然 × 先验 ✓ 这是最大后验（MAP）判决

    这条关系很重要：它说明最大似然判决是贝叶斯判决在均匀先验下的特例。 很多教材先讲最大似然再讲贝叶斯，实际关系是这样一个包含关系 ✓

    (a) 直接套公式。 (b) 把 (a) 算出的后验当作第二次的先验， 再套一次同样的公式。这就是「序贯更新」。

    解答

    （a）一次检测

    \(P(\omega_1) = 0.01\)，\(P(\omega_2) = 0.99\)， \(P(T\mid\omega_1) = 0.90\)，\(P(T\mid\omega_2) = 0.05\)。

    分子：\(0.90 \times 0.01 = 0.009\)

    分母：\(0.90\times0.01 + 0.05\times0.99 = 0.009 + 0.0495 = 0.0585\)

    \[P(\omega_1\mid T_1) = \frac{0.009}{0.0585} \approx 0.15385 \approx 15.39\%\]

    （b）两次检测都阳性

    用序贯更新：把 (a) 的结果当第二次的先验。

    新的先验：\(P(\omega_1) = 0.15385\)，\(P(\omega_2) = 1 - 0.15385 = 0.84615\)

    分子：\(0.90 \times 0.15385 = 0.13846\)

    分母：\(0.90\times0.15385 + 0.05\times0.84615 = 0.13846 + 0.04231 = 0.18077\)

    \[P(\omega_1\mid T_1,T_2) = \frac{0.13846}{0.18077} \approx 0.76595 \approx 76.60\%\]

    从 15% 涨到 77% —— 第二次检测把「未患病者误报」这个 最可能的解释基本排除了 ✓

    为什么可以把后验当前验： 因为两次检测在给定真实状态下条件独立，于是

    \[P(T_1, T_2 \mid \omega_i) = P(T_1\mid\omega_i)\,P(T_2\mid\omega_i)\]

# (b) 序贯：把 post1 当前验
n2 = sens * post1
d2 = sens * post1 + fpr * (1 - post1)
post2 = n2 / d2
print("两次阳性后验 = %.6f  (%.2f%%)" % (post2, post2 * 100))

# 直接算（条件独立，联合似然相乘）验证等价
joint1 = sens ** 2
joint2 = fpr ** 2
direct = joint1 * p1 / (joint1 * p1 + joint2 * p2)
print("直接联合计算 = %.6f" % direct)
print("两条路一致吗 :", abs(direct - post2) < 1e-12)

    小结¶

    要记住的 为什么
    \(P(\omega_i)\) 是先验，\(p(x\mid\omega_i)\) 是似然 前者「看数据前」，后者「给定类别的数据分布」
    \(P(\omega_i\mid x)\) 是后验，是我们要求的目标 它直接回答「这属于哪类」
    \(p(x) = \sum_j p(x\mid\omega_j)P(\omega_j)\) 是证据 全概率公式，起归一化作用
    分母 \(p(x)\) 与类别无关 所以判决只需比较分子 \(p(x\mid\omega_i)P(\omega_i)\) ✓
    \(p(x\mid\omega)\) 不是概率，可以大于 1 它是密度，单位是「概率/单位长度」
    条件方向别搞反 \(p(x\mid\omega)\) 从类推特征；\(P(\omega\mid x)\) 从特征推类
    先验相等时，MAP 退化成 ML 所以最大似然是贝叶斯的特例
    罕见事件的检测阳性要警惕基率谬误 先验极小时，即使误检率低，假阳性也会占多数
    后验可以当前验反复更新 这就是序贯贝叶斯，滤波类算法的基础
    贝叶斯最优有前提 类别固定、分布已知、样本独立；实际中分布只能估
