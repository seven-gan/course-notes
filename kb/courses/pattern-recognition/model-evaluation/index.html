    模式识别系统的评价¶

    前面十几页都在讲怎么造一个分类器。这一页讲一个同样重要、 而且更容易出错的问题：

    怎么知道它到底好不好？

    为什么这件事容易出错：因为"好"的定义依赖场景。 同一个分类器，用不同指标评价可能得到完全相反的结论 而选错指标会导致上线一个不该上线的系统。

    这一页要建立的两个观念

    ① 指标不是中性的 每个指标都隐含地假设了"哪类错误更严重"。 用错指标 = 用错误的标准做决策

    ② 评估本身会骗人 信息泄露、测试集反复使用、类别不平衡 —— 这些都会让报告的数字明显好于真实性能

    一、混淆矩阵：一切指标的来源¶

    1.1 四个格子¶

    对二分类问题，把预测与真实交叉，得到混淆矩阵：

    预测为正 预测为负
    真实为正 真正例 TP 假负例 FN
    真实为负 假正例 FP 真负例 TN

    为什么一切指标都要回到这张表： 所有常用指标都是这四个数的不同组合 理解了这张表，任何指标都能自己推出来。

    1.2 两类错误的代价往往不同¶

    错误 含义 典型场景与后果
    FN（漏报） 有病判成没病 漏诊：延误治疗 ⚠
    FP（误报） 没病判成有病 复查、虚惊、成本

    关键认识：这两类错误的代价几乎从不对等。

    所以不存在"最好的指标" —— 只有"与场景代价结构匹配的指标"

    1.3 四个基本指标¶

    指标 公式 分母是什么 回答的问题
    准确率 \(\dfrac{TP+TN}{TP+FP+FN+TN}\) 全部样本 整体判对的比例
    精确率 \(\dfrac{TP}{TP+FP}\) 预测为正的 判为正的里面有多少是真
    召回率 \(\dfrac{TP}{TP+FN}\) 真实为正的 真里面逮到了多少
    特异度 \(\dfrac{TN}{TN+FP}\) 真实为负的 真负的里面排除了多少

    精确率与召回率的分母最容易记混 —— 一个简单记法：

    • 精确率看预测（预报为准的准不准）
    • 召回率看真实（真的找回了多少）

    1.4 精确率与召回率的权衡¶

    这两者通常此消彼长：想让召回率高就得"宁可错判也不漏"， 但这样精确率会降

    怎么调这个平衡：移动判决阈值

    阈值调整 精确率 召回率
    提高阈值（更谨慎判正） 升 ✓ 降
    降低阈值（更倾向判正） 降 升 ✓

    F1 值是两者的调和平均，用来给一个综合分数：

    \[ F_1 = \frac{2\,\text{Precision}\cdot\text{Recall}} {\text{Precision}+\text{Recall}} \]

    为什么用调和平均而不是算术平均：调和平均对小的那个更敏感 —— 若一个指标很低，F1 就低。

    这一点很重要：算术平均下 \((1.0,\ 0.0)\) 会得到 0.5， 看起来"还行"；而调和平均得 0， 正确地反映了"有一个维度完全失效"

    更一般的 \(F_\beta\)（\(\beta\) 控制偏好）：

    \[ F_\beta = (1+\beta^2)\,\frac{\text{Precision}\cdot\text{Recall}} {\beta^2\,\text{Precision}+\text{Recall}} \]

    要点：\(\beta \gt 1\) 偏向召回率，\(\beta \lt 1\) 偏向精确率

    准确率在类别不平衡时几乎无用

    设某病患病率 1%。一个把所有样本都判为"没病"的分类器：

    \[ \text{准确率} = \frac{9900}{10000} = 99\% \]

    它什么也没学到，准确率却有 99%

    更糟的是：看到"99% 准确率"的人会以为系统很好。

    对策（至少用其一）：

    · 报告召回率与精确率（此时召回率是 0，问题立刻暴露） · 用平衡准确率（召回率与特异度的平均） · 用 ROC 的 AUC 或 PR 的 AUC · 报告相对于基线的提升（而不是绝对准确率）

    二、ROC 与 PR 曲线¶

    2.1 ROC 曲线¶

    ROC 曲线是扫描所有阈值，画出的一条曲线：

    • 横轴：假正例率 \(\text{FPR} = \dfrac{FP}{FP+TN}\)
    • 纵轴：真正例率 \(\text{TPR} = \dfrac{TP}{TP+FN}\)（就是召回率）

    曲线的四个关键点：

    点 含义
    \((0,0)\) 全部判负
    \((1,1)\) 全部判正
    \((0,1)\) 完美分类器 ✓
    对角线 随机猜测（无区分能力）

    AUC（曲线下面积）是常用的汇总指标：

    AUC 含义
    0.5 等于瞎猜
    0.7–0.8 一般
    0.8–0.9 良好
    > 0.9 优秀 ✓

    AUC 的一个重要含义：随机取一个正样本和一个负样本， 分类器给正样本打分更高的概率

    这个解释很实用：它说明 AUC 衡量的是排序能力， 与阈值无关

    2.2 PR 曲线¶

    PR 曲线以召回率为横轴、精确率为纵轴。

    ROC 与 PR 的适用场合：

    场合 用哪个
    正负样本大致均衡 ROC 更稳 ✓
    正样本极少（如 1%） PR 更敏感 ✓
    关心排序能力 ROC
    关心"判为正"的准确性 PR

    为什么正样本极少时要用 PR：

    因为 FPR 的分母是 \(FP+TN\)，TN 极大， 所以即使 FP 增加很多，FPR 也只涨一点点 —— ROC 曲线看起来仍然很漂亮，掩盖了问题

    而 PR 曲线的分母含 \(TP+FP\)，FP 的增加会直接压低精确率， 问题暴露得很清楚

    不要反复用同一个测试集调参

    这是比信息泄露更隐蔽的一种错误。

    机制：每次用测试集评估、根据结果调参、再评估…… 于是测试集的信息通过你的决策泄露进了模型

    后果：报告的性能系统性偏高， 换一个真正的独立测试集时会明显下降。

    正确做法：

    数据 用途 能碰几次
    训练集 拟合参数 多次
    验证集 调超参、选模型 多次
    测试集 最终报告一次 一次 ⚠

    如果必须反复看测试集，就应该承认它已经变成验证集， 并另找一批新数据做最终评估。

    三、代价敏感与阈值选择¶

    3.1 把代价写进决策¶

    若误报代价是 \(c_{FP}\)、漏报代价是 \(c_{FN}\)， 期望代价最小的判据不是"后验概率大于 0.5"，而是：

    \[ \text{判为正} \iff P(\text{正}\mid x) \gt \frac{c_{FP}}{c_{FP}+c_{FN}} \]

    阈值由代价比决定，而不是固定在 0.5

    代入两个极端：

    情形 阈值 倾向
    \(c_{FN} \gg c_{FP}\)（漏报很严重） 阈值很小 宁可误报 ✓
    \(c_{FP} \gg c_{FN}\)（误报很严重） 阈值很大 宁可漏报 ✓

    这就是"阈值该定多少"这个问题的完整答案 —— 它不是一个技术选择，而是代价结构的直接体现

    3.2 从 PR 曲线上选工作点¶

    既然代价比给出了阈值，那么：

    1. 画出 PR 曲线（或 ROC 曲线）
    2. 用代价比算出理论阈值
    3. 在曲线上找到对应的工作点
    4. 报告该点的精确率/召回率（而不是只报 AUC）

    为什么不能只报 AUC：AUC 是全阈值平均， 而实际系统只工作在一个阈值上 两个 AUC 相同的分类器，在你的工作点上可能差很多。

    3.3 三种重采样的适用场合¶

    手段 做法 注意
    欠采样 丢弃部分多数类 丢信息 ⚠
    过采样 复制少数类 容易过拟合 ⚠
    合成（SMOTE） 在少数类间插值生成 仍可能过拟合

    关键提醒：重采样必须在交叉验证的每一折内部做 ⚠ 否则就是第一节说的信息泄露。

    四、显著性检验：差的那一点是真的吗¶

    4.1 为什么需要检验¶

    两个模型在测试集上得到 0.841 与 0.836。 这 0.005 的差距是真实的，还是抽样噪声？

    不能凭"数字更大"就下结论 ⚠

    4.2 配对检验¶

    K 折交叉验证天然给出配对数据 —— 同一次划分上，两个模型各有一个误差。

    配对 \(t\) 检验的做法：

    1. 记第 \(k\) 折上两个模型的误差差 \(d_k = e_k^{(A)} - e_k^{(B)}\)
    2. 检验 \(\bar d\) 是否显著不为零
    \[ t = \frac{\bar d}{s_d/\sqrt K} \]

    为什么要"配对"：同一折上的两个误差面临同样的数据难度， 配对后能把"折之间的难度差异"消掉，检验更灵敏

    注意 \(K\) 折的数据不独立（训练集高度重叠）， 所以标准的 \(t\) 检验偏乐观 —— 严格场合应使用修正方法或多次重复 K 折

    4.3 实践建议¶

    建议 理由
    报均值 ± 标准误 单个数字不说明稳定性 ✓
    用配对检验 消除折间难度差异
    重复多次 K 折 应对划分的随机性
    不要只报最好的一次 那是选择性报告 ⚠

    最后一条尤其重要：如果跑了 10 个配置， 只报最好的那个"±0.00x"，那就是把噪声当成了性能

    五、一个完整的评估流程¶

    把前面的东西串成一个可执行的清单：

    1. 先确定代价结构：哪类错误更严重、严重多少倍 → 由此定阈值，而不是默认 0.5
    2. 选与该代价匹配的指标： 平衡数据看准确率/ROC；不平衡数据看召回率/PR

    5. 报告时要给：均值、标准误、混淆矩阵、 以及相对于基线的提升
    6. 做显著性检验：差距是否超出噪声

# 用一个小混淆矩阵，把各指标的差别算出来
# 场景：疾病筛查，患病率 1%
N = 10000
n_pos = 100
n_neg = N - n_pos


def metrics(tp, fn, fp, tn):
    acc = (tp + tn) / (tp + fn + fp + tn)
    prec = tp / (tp + fp) if (tp + fp) else 0.0
    rec = tp / (tp + fn) if (tp + fn) else 0.0
    spec = tn / (tn + fp) if (tn + fp) else 0.0
    f1 = (2 * prec * rec / (prec + rec)) if (prec + rec) else 0.0
    bal = 0.5 * (rec + spec)
    return acc, prec, rec, spec, f1, bal

    import numpy as np

# 用配对 t 检验判断两个模型的差距是否显著
rng = np.random.default_rng(42)
K = 10
# 模拟 10 折上两个模型的误差（B 略好，但差距很小）
err_A = rng.normal(0.168, 0.012, K)
err_B = err_A - rng.normal(0.004, 0.006, K)   # 配对：差值独立于折的难度

d = err_A - err_B
n = len(d)
mean_d = float(d.mean())
sd = float(d.std(ddof=1))
t = mean_d / (sd / np.sqrt(n))

print("K = %d 折，配对差 d_k = err_A - err_B" % K)
print("  平均差 %.5f，标准差 %.5f" % (mean_d, sd))
print("  配对 t 统计量 = %.3f" % t)
print()
print("临界值参考（双侧 5%%）：自由度 %d 时约 2.262" % (n - 1))
print("  结论：%s" % ("差距显著" if abs(t) > 2.262
                      else "差距不显著（可能是噪声）⚠"))
print()
print("看一下逐折的差值：")
print("折号".ljust(8) + "差值")
for k in range(n):
    print(("%d" % (k + 1)).ljust(8) + "%+.5f" % d[k])

    六、例题¶

    例题 1：手算指标¶

    题目：某分类器在 200 个样本上的结果： \(TP=60\)、\(FN=20\)、\(FP=30\)、\(TN=90\)。 求准确率、精确率、召回率、F1。

    思路

    逐个代入公式，注意精确率的分母是预测为正的、召回率的分母是真实为正的。

    解答

    第一步：准确率。

    \[ \frac{60+90}{200} = \frac{150}{200} = 0.75 \]

    第二步：精确率。

    \[ \frac{60}{60+30} = \frac{60}{90} \approx 0.6667 \]

    第三步：召回率。

    \[ \frac{60}{60+20} = \frac{60}{80} = 0.75 \]

    第四步：F1。

    \[ F_1 = \frac{2\times0.6667\times0.75}{0.6667+0.75} = \frac{1.0}{1.4167} \approx 0.7059 \]

    答案：准确率 0.750、精确率 0.667、召回率 0.750、F1 0.706

    准确率与召回率恰好相同（都是 0.75）， 这不是巧合 —— 因为 \(TP+FP = TP+FN\)（90 vs 80）接近。 两者相同意味着"判为正的个数"与"真实为正的个数"接近

    例题 2：用 F1 揭穿一个假象¶

    题目：分类器甲得到 \((\text{Precision}, \text{Recall}) = (1.0,\ 0.02)\)， 乙得到 \((0.70,\ 0.70)\)。分别算算术平均与 \(F_1\)， 并判断哪个分类器更好。

    思路

    分别算两种平均，看结论是否一致。

    解答

    第一步：算术平均。

    甲：\((1.0+0.02)/2 = 0.51\) 乙：\((0.70+0.70)/2 = 0.70\)

    第二步：\(F_1\)（调和平均）。

    甲：

    \[ F_1 = \frac{2\times1.0\times0.02}{1.0+0.02} = \frac{0.04}{1.02} \approx 0.039 \]

    乙：

    \[ F_1 = \frac{2\times0.7\times0.7}{1.4} = 0.70 \]

    第三步：判断。

    分类器 算术平均 \(F_1\) 实际问题
    甲 0.51 0.039 只找回了 2% 的正样本 ⚠
    乙 0.70 0.70 两边都还行 ✓

    答案：乙明显更好；算术平均掩盖了甲的严重缺陷。

    甲"精确率 100%"听起来完美， 但它几乎什么都不判为正（召回率 2%）—— 这样的分类器在实用上毫无价值

    调和平均正确地把它压到了 0.039 这就是为什么综合评价分类器时要用 F1 而不是算术平均。

    例题 3：不平衡数据下该用哪个指标¶

    题目：某欺诈检测任务，欺诈样本占 0.5%。 甲模型的 ROC-AUC 是 0.94，看 PR 曲线的 AUC 只有 0.12； 乙模型的 ROC-AUC 是 0.92，PR-AUC 是 0.45。 选哪个？

    思路

    想清楚 ROC 的 FPR 分母是什么，以及它在极不平衡时会怎样。

    解答

    第一步：分析 ROC 的问题。

    FPR 的分母是 \(FP+TN\)，而 \(TN\) 极大（99.5% 都是负样本）。 所以即使 FP 涨得很多，FPR 也涨得很慢

    结果：ROC 曲线看起来漂亮（AUC 0.94）， 但实际判为正的样本里可能大部分是误报 —— 这正是甲模型 PR-AUC 只有 0.12 的含义。

    第二步：比较两模型。

    模型 ROC-AUC PR-AUC 判断
    甲 0.94 0.12 排序能力好，但正例判不准 ⚠
    乙 0.92 0.45 综合更实用 ✓

    第三步：结论。

    选乙。甲的 ROC-AUC 虽然更高， 但那 0.02 的差距来自被 TN 稀释的 FPR， 对实际业务没有意义。

    答案：选乙，因为 PR 曲线更反映"判为正"的实际质量。

    极不平衡时，ROC-AUC 会给出误导性结论 判断规则很简单：

    \[ \text{正样本占比极低} \;\Longrightarrow\; \text{优先看 PR} \]

    另外要注意 PR-AUC 的基线与正样本比例有关 （本例约 0.005），而 ROC 的基线恒为 0.5 —— 所以 PR-AUC 的绝对值不能直接与 0.5 比较 ✓

    例题 4：找出评估流程里的三个错误¶

    题目：某人这样评估： ① 用全部数据做标准化和特征选择； ② 用 5 折交叉验证比较 20 个模型配置，选验证误差最小的； ③ 把这 20 个配置在测试集上也跑一遍，报其中测试误差最小的那个。 指出错误。

    思路

    逐个检查：哪一步用了全体数据？测试集被碰了几次？

    解答

    错误 ①：标准化与特征选择用了全体数据。

    验证折的信息通过"哪些特征重要"泄露进了训练过程 这会让验证误差偏低。

    修正：把这两步放进每一折内部重新执行。

    错误 ②：测试集被用了 20 次。

    虽然第 ② 步只用验证集选模型（这一步是对的）， 但第 ③ 步在测试集上跑了20 个配置并取最小值 —— 这就是在测试集上做选择

    关键：取最小值的操作会让报告的数字系统性偏低， 因为"20 个里的最小值"必然小于真实期望。

    错误 ③：报最小值而不是预定模型的结果。

    正确的流程是：

    1. 用验证集选出一个配置
    2. 只在测试集上跑这一次
    3. 报这个数（不管它好不好看）

    答案：三处错误 —— ①折外做预处理、②测试集被反复使用、 ③用测试集做选择并报最优值。

    "多试几次取最好"是最常见的自欺方式

    它几乎必然给出乐观的数字， 而且你不会从数字本身看出问题 —— 只有独立的新数据才能揭穿它。

    八、小结¶

    概念 要点 易错点
    混淆矩阵 一切指标的来源 不区分两类错误的代价
    精确率 分母是预测为正的 与召回率分母记混 ⚠
    召回率 分母是真实为正的 —
    F1 调和平均，对低值敏感 用算术平均代替 ⚠
    准确率 仅在类别均衡时有意义 不平衡时严重误导 ⚠
    ROC / AUC 与阈值无关的排序能力 正样本极少时虚高 ⚠
    PR 对正类更敏感 基线不等于 0.5
    代价敏感阈值 \(c_{FP}/(c_{FP}+c_{FN})\) 默认用 0.5 ⚠
    显著性检验 配对 \(t\) 检验 不检验就下结论 ⚠

    三条最该带走的结论：

    1. 指标的选法由代价结构决定 —— 先回答"哪类错误更严重、严重多少倍"， 再定阈值、再选指标
    2. 类别不平衡时，准确率与 ROC 都会骗人 —— 要改用召回率 / PR 曲线，并报告相对于基线的提升
    3. 测试集只能碰一次 —— 反复用它选模型是最隐蔽也最普遍的评估错误
