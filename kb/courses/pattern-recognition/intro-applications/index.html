    应用领域与典型任务¶

    这一页解决一个问题：模式识别到底用在哪些地方？这些地方的识别任务，形式是不是同一回事？

    前一页理清了「模式识别是什么」——从观测数据判断它属于哪一类。 但「判断属于哪一类」这句话太笼统了，落到具体场景上会变出好几种完全不同的形式： 有时要对整张图给一个名字，有时要框出图里的每个目标， 有时要给每一个像素都贴上标签，有时要判断「这是不是同一个人」。 这四种形式的输出根本不是一回事，混淆的代价很实在。

    看起来差不多的说法 实际差别 后果
    「都是识别」 分类、检测、分割、识别这四种形式的输出对象根本不是同一个 该框目标却只给了整图标签，任务做不成
    「数据越多越好」 数据多只是前提；难点在类内差异、遮挡、尺度、标注成本 以为堆数据就能解决，一遇到真实场景还是崩
    「人脸识别和图像分割差不多」 一个输出一个类别标签，一个输出每个像素各一个标签 指标选错，效果好坏根本没法判断

    这一页的主线

    整页回答两个问题：模式识别现在用在哪些地方？这些地方的任务能归成哪几种形式？

    一句话概括：课件先用「数字化」说明了为什么今天必须让机器去识别， 再按数据类型把应用铺开；而所有这些应用，最后都落在 分类、检测、分割、识别这四种基本形式上。

    读这一页时请一直问自己：这个应用的输出到底是什么形状的？

    一、为什么模式识别现在这么重要¶

    1.1 课件给出的前提：来源丰富、数量巨大¶

    课件在进入应用这一节的时候，先给了一句总纲式的话， 后面整整几十页的应用都是从这一句里长出来的：

    通过数字化手段来获取感知数据：来源丰富、数量巨大。

    这句话很短，但里面每一个词都在承重，值得拆开讲。

    「数字化手段」指的是把物理世界的信号变成数字信号的那一整套技术： 相机把光变成像素矩阵，麦克风把声波变成一串采样值， 各类传感器把温度、压力、位移变成数值。 这件事做完之后，原来只存在于物理世界里的信息就变成了计算机可以读写的数据。 换句话说，数字化是模式识别的前提 —— 没有数字化，就没有「数据」可识别。

    「感知数据」指的是由传感器获取、反映客观世界状态的数据。 它和「抽象数据」相对：一份财务报表、一张业务流水表属于抽象数据， 而一段监控视频、一张遥感图像、一段语音属于感知数据。 课件在讲三者关系时已经给模式识别定过位： 主要针对感知数据，面向应用。 这就解释了为什么这一节几乎全是图像、视频、语音、遥感这类内容 —— 它们都是感知数据。

    「来源丰富、数量巨大」其实是两个独立的判断，各自都有分量：

    • 来源丰富说的是种类多。课件在这一页列出了一长串来源： 视觉监控、机器人感知、卫星遥感、智能眼镜、RGB-D 成像、 各种文档、电视、网络视频，以及来自互联网和物联网的数据。 种类多意味着任务形式多种多样，不可能用一套规则包打天下。
    • 数量巨大说的是规模大。这一条更关键， 因为它直接决定了「人来做」这条路走不通。

    数据多不等于问题变简单

    课件讲了「数量巨大」，很容易顺势推出一个错误结论： 「数据这么多，模型一学就会了」。

    数据多只解决了训练素材够不够的问题，它不解决下面这些： - 类内差异大：同一个人在正面、侧面、低头的照片里，差别可能比两个人之间还大； - 类间差异小：两种不同的树，在图像上可能几乎一模一样； - 标注昂贵：数据多不等于标好类的数据多，一张医学影像的标注得由专家来做。

    所以「数量巨大」是前提，不是保证。 这一点在第五节的「难点归纳」里还会专门展开 ✓

    1.3 从数据来源到识别任务¶

    课件列出的每一种感知数据，落到识别任务上，问的问题是不一样的。 例如「图像」这一类里，既可以问「整张图是什么」， 也可以问「图里有没有人」，还可以问「每个像素属于什么」。 把这条对应关系列出来，就是本页的第一张骨架表：

    数据来源 对应的识别任务 输出的粒度 课件的例子
    图像 目标分类 整幅图一个类别 飞机分类识别、舰船分类识别、商品图片分类
    图像 目标检测 每个目标一个框 交通标志检测、车辆目标检测、行人检测
    图像 图像分割 每个像素一个标签 城市房屋分割、医学图像分割、精细目标分割
    图像 生物特征识别 一个身份编号 人脸识别、行人再识别、指纹与虹膜识别
    视频 目标检测 + 跟踪 每帧的框 + 帧间对应关系 区域人群监控、人物入侵检测和跟踪
    音频 语音识别、说话人识别 文字序列 / 身份编号 语音识别、以语音搜图
    文本 文本分类、信息抽取 类别标签 / 结构化字段 垃圾短信与垃圾邮件识别、敏感内容监测
    多模态 跨模态生成与检索 文本序列 / 排序结果 图像句子描述、以图搜图、以文搜图
    遥感多波段 目标识别 + 地物分类 类别标签 / 逐像素标签 高光谱目标识别、高光谱地物目标分类
    传感器数值 分类与回归预测 类别标签 / 数值 用电异常行为分析、信用评估、需求预测

    这张表要横着读和竖着读两种读法：

    • 横着读：同一类数据（比如图像）可以承载好几种不同粒度的任务 —— 这是第四节要归纳的「四种基本形式」的由来。
    • 竖着读：同一类任务（比如「判断有没有」）可以出现在好几种数据上 —— 这是「按数据类型分」和「按任务形式分」是两条不同的分类线的原因。

    两条分类线不要混

    本页有两条互相垂直的分类线：

    分类线 怎么分 结果
    按数据类型 数据长什么样 图像类、视频类、音频类、文本类、多模态类……
    按任务形式 要输出什么 分类、检测、分割、识别

    它们互相垂直：图像数据上可以跑四种任务中的任何一种， 而「检测」这种任务也可以跑在图像、视频、遥感数据上。 搞混这两条线，就会出现「把语音识别说成图像分割的一种」这类错误。

    2.1 课件列出的应用大方向¶

    课件在讲完「为什么重要」之后，直接给了一张应用方向清单。 这张清单本身就是按应用领域来分的，一共十条，逐条抄下来是：

    舆情分析 互联网、大数据
    智能人机交互 表情、手势、声音、符号

    这张清单有一个很值得注意的地方： 它列的十个方向里，数据种类几乎都不止一种。 「安全监控」既用到图像（人脸），也用到视频（行为）； 「智能人机交互」同时用到表情、手势、声音三种数据。 这正好印证了 1.3 节说的那条规律： 同一个应用方向底下，往往挂着一串不同粒度的识别任务。

    2.2 按数据类型组织的总览表¶

    需要用户配合 不需要用户配合

    3.2 人脸识别：把「开放环境远距离多尺度」拆成三个难点¶

    课件在人脸识别这一页只写了一行字，但这一行字信息量最大：

    开放环境远距离多尺度人脸识别

    这句话不是三个形容词的堆砌，而是三个各自独立、叠加起来就极其困难的技术难点。 下面逐个拆开讲。

    3.2.1 「开放环境」：受控与非受控的分界线¶

    受控环境指的是采集条件被安排过的场景： 人站在固定位置，正面朝向相机，光照均匀， 相机高度和角度固定，背景干净或纯色。 这种人脸识别在很早就做到了实用。

    开放环境指的是采集条件完全不受控的场景： 人在走动中、光照忽明忽暗、可能背光、 表情在变、可能戴着眼镜或口罩、角度可能是侧面甚至只剩半张脸、 背景里还有成百上千个干扰目标。

    为什么这一条这么难：受控环境里相机看到的几乎是同一个姿态， 所以「同一个人」的照片彼此高度相似，「不同的人」也有明显差别； 而开放环境里，同一个人在不同条件下的两张照片，差别可能比两个不同的人还大。 这个问题在第五节里叫类内差异大。

    3.2.2 「远距离」：像素不够，特征就无从谈起¶

    \[p = \frac{f \cdot H}{d}\]

    三个难点是相乘的，不是相加的

    把「开放环境」「远距离」「多尺度」当成三个独立的困难来算， 很容易得出「有点难但还行」的结论。实际上它们是同时作用、互相恶化的：

    难点组合 恶化方式
    远距离 + 开放环境 距离远 → 像素少 → 本来就少的细节再被光照和姿态抹掉一层
    尺度 + 远距离 想把远处目标放大，近处目标就超出尺度范围，两头不能兼顾
    开放环境 + 尺度 同一个人在小尺度下本来就模糊，非正面姿态会进一步丢信息

    所以真实系统往往不是「一个大模型解决一切」， 而是由粗到细的级联：先在大范围里找到可疑区域， 再逐步放大、逐级判别。这就是课件把「天 → 空 → 地」特意写出来的用意。

    3.3 视频监控：检测与跟踪是两件事¶

    课件在视频监控这一页给了两个例子：

    课件的例子 任务描述
    大型活动区域的人群监控 在人群中判断「哪里有人、有多少人」
    城铁线路的人物入侵检测和跟踪 判断「有没有人进入不该进的区域」，并持续跟住这个人

    这两个例子合起来正好说明：监控类任务里，「检测」和「跟踪」是两件事。

    检测回答的是「这一时刻画面里有没有目标、在哪里」。 它的输出是逐帧的目标框（或者更简单：一个「有 / 无」的判断）。 跟踪回答的是「这一时刻的这个目标，和上一时刻的那个目标是同一个吗」。 它的输出是跨帧的对应关系 —— 给每个目标一个在时间里保持一致的编号。

    为什么必须分成两件事： 如果每一帧都独立做检测，第 1 帧检测到「一个人」， 第 2 帧又检测到「一个人」，但系统并不知道这两个是同一个人， 于是无法回答「这个人是从哪个方向过来的」「他在这个区域待了多久」。 而监控的实际需求恰恰是后一类问题。

    跟踪特有的难点是遮挡：

    情况 会发生什么 后果
    目标被树、柱子、车辆挡住一部分 检测器可能把同一个目标拆成两个，或者直接漏检 编号断裂，出现「一个人变成两个」
    多人互相遮挡 检测框重叠，对应关系无法用位置直接判断 编号互换，出现「张冠李戴」
    目标完全消失一段时间后重新出现 系统不知道回来的是不是原来那个人 需要「再识别」能力来把身份接上

    这里出现了一个关键连接：第三行的「重新出现后判断是不是同一个人」， 在任务形式上属于第四节的识别，和 3.1 节的生物特征识别是同一类问题。 课件在应用实例里也把「人脸识别 / 开放条件下行人再识别」并列写在一起， 就是因为行人再识别解决的正是「同一个人在不同摄像头、不同时间的画面里怎么认出来」。

    3.4.1 高光谱与普通图像到底差在哪¶

    3.4.2 课件给出的具体例子与难点¶

    课件给出了两组高光谱结果，每组都用颜色代表地物类别（这类用颜色代替类别的图叫伪彩色标注图）：

    课件给出的类别与颜色 出现在哪一组

    红色 = 树，蓝色 = 水，绿色 = 土，黑色 = 路 第二组

    同一批颜色在不同组里代表不同地物 —— 这本身就说明一件事： 颜色只是显示用的标记，真正的类别信息在数据里，不在颜色里。 读这类图时必须先看它给的图例，否则会把两组结论读混。

    课件在这两组结果上比较了几种方法，包括 NMF、L1-NMF、L½-NMF 和课件方法的对比， 并且在另一页写明：「我们的方法：小样本」， 方法要点是 SVM + 波段选择 + 小样本（2011）， 以及 基于结构稀疏学习的高光谱解混（2013）。

    先把这些名词的性质分清楚，这是读课件时最容易混的地方：

    名词 它属于哪一类 要解决什么
    NMF / L1-NMF / L½-NMF 对解混问题的不同约束方式 一个像素里混了多种地物，怎么把成分拆开
    解混（unmixing） 一类处理思路 像素不是纯的，要把混合比例估出来
    SVM 一种分类器 在特征空间里找分类边界
    波段选择 一种降维手段 100 个波段太多，挑出最有用的一批
    结构稀疏学习 一种正则化思路 利用「同类地物在空间上聚成片」这个结构，压制噪声

    为什么高光谱特别需要「小样本」和「波段选择」 —— 这一条其实和 3.4.1 的数出来的 100 倍是同一件事：

    • 维度一高，每一个样本要用到的参数量就跟着涨，而带标签的高光谱数据很少（标注要专家逐像素标）；
    • 波段之间高度相关，信息是冗余的，全用上反而会放大噪声；
    • 所以「减少要估计的东西」（波段选择）和「小样本下也能工作」（大间隔思路）就成了主流选择。

    课件在展示结果时把 伪彩色图像、若干对比方法的分类图、以及真值图 并排放在一起， 并点出要在边缘和细节上比较 —— 这正是分割类任务评价的典型做法： 不看整体好看不好看，看图例颜色有没有在细节处贴到真值上。

    「像素级分类」和「整幅图分类」不是一回事

    高光谱地物分类的正式名字叫像素级分类，它的输出是一张和输入同样大小的标签图。 这和「给整幅图一个类别」是两个不同粒度的任务：

    任务 输出 指标
    整幅图分类 一个类别标签 准确率
    像素级分类 每个像素一个标签 逐像素比对，常看各类的交并比

    两者混用会带来一个隐蔽的错误： 用整图分类的准确率去评价像素级分割。 一张 95% 是背景的图，只要把所有像素都判成背景，整图准确率也能有 95% —— 但目标一个都没找到。这个陷阱在第五节的「类别不平衡」里会量化 ✓

    3.5 图像分割：把「分成同性质的区域」这句话讲透¶

    课件在图像语义分割这一页给了一句英文原话，并配了一句中文的任务说明。 两句话要对照着读才完整：

    Segment image into different regions such that each region has the same semantic meaning. （把图像分成不同的区域，使得每一个区域具有相同的语义含义。）

    • 任务：为属于同一类目标的像素赋相同的类别标签

    关键词：图像语义分割、像素级分类

    先把两句话译准：

    • 第一句的重点在 such that each region has the same semantic meaning —— 分出来的每个区域内部要「性质一致」。这里的「性质」不是「颜色一样」， 而是语义上属于同一类东西。
    • 第二句把「性质一致」翻译成了可操作的说法 —— 给同一类目标的像素，贴上相同的类别标签。

    为什么「性质一致」必须解释成「语义一致」而不是「颜色一致」： 一副黑白照片里，一件白色衬衫和一面白墙颜色一模一样， 但它们是两个不同的东西； 反过来，一件条纹衬衫上一黑一白的像素颜色完全不同， 却都属于同一件衬衫。 所以分割判别的依据是语义，不是灰度或颜色。 这正是「语义分割」这个名字里「语义」两个字的来由。

    输出是什么形状 —— 这是理解分割最关键的一点： 输入是「高 × 宽 × 通道」，输出是「高 × 宽」的一张标签图（也叫掩码）， 每一个像素都有且只有一个类别标签。 所以分割的正式名字也叫像素级分类：把每一个像素当作一个样本，做分类。

rng = np.random.default_rng(42)
H, W = 24, 24
img = rng.normal(60.0, 5.0, size=(H, W))          # 背景：灰度约 60

def components(mask):
    """数一数 mask 里有多少个四连通的前景区域。"""
    seen = np.zeros(mask.shape, dtype=bool)
    n = 0
    for i in range(mask.shape[0]):
        for j in range(mask.shape[1]):
            if not mask[i, j] or seen[i, j]:
                continue
            n += 1
            stack = [(i, j)]
            seen[i, j] = True
            while stack:
                a, b = stack.pop()
                for da, db in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                    x, y = a + da, b + db
                    if (0 <= x < mask.shape[0] and 0 <= y < mask.shape[1]
                            and mask[x, y] and not seen[x, y]):
                        seen[x, y] = True
                        stack.append((x, y))
    return n

    四、识别任务的四种基本形式¶

    4.1 四种形式的一句话定义¶

    把前面所有例子放到一起，可以归纳出四种基本形式。 它们不是四种方法，而是四种「问法」 —— 问法不同，输出就不同。

    形式 一句话回答的问题 输出是什么
    分类（classification） 这幅图整体属于哪一类？ 一个类别标签
    检测（detection） 图里有没有目标？在哪儿？有几个？ 一串目标框，每个框带类别
    分割（segmentation） 每一个像素分别属于哪一类？ 一张与输入同大小的标签图
    识别（对象识别 / recognition） 这是哪一个具体对象？ 一个对象编号（类别数随对象库增长）

    4.2 对照表：输入输出、标注形式、典型指标、例子¶

    形式 输入 输出 训练数据的标注形式 典型指标 课件里的例子
    分类 一幅图（或一段信号、一段文本） 一个类别标签 整幅图一个标签 准确率、混淆矩阵 飞机分类识别、舰船分类识别、商品图片分类、垃圾短信识别
    检测 一幅图（或一帧视频） \(N\) 个目标框，每个框形如「位置 + 类别 + 置信度」 每个目标一个框，还要给框标类别 查全率、精确率、平均精度、ROC 与 AUC 交通标志检测、车辆目标检测、行人检测、人物入侵检测

    第三，四种形式的「标注成本」差别极大。 按单个样本算的标注成本，从低到高大致是：

    形式 一个样本要标注多少东西 成本感受
    分类 一个标签 最低
    检测 每个目标一个框（框要画准） 中等，且目标数不定
    识别 若干张样本 + 对象编号 中等，但需要成组收集
    分割 逐像素标签 最高，医学影像还要专家来做

    这张成本表解释了一个现象：为什么课件讨论「小样本」「半监督」时， 例子里常常是分割和检测类任务 —— 因为它们的标注最贵，样本量最缺。这也接到第五节的「标注贵」这条难点。

    4.3 四种形式不是互斥的，而是层层加深¶

    四种形式之间的关系可以这样理解：后一种是前一种的加密版本。

    关系 说明 例子
    检测 → 分类 检测先找到框，再把框里的内容分类 车辆检测：先框出车，再说是什么车
    分割 → 分类 分割就是「对每个像素各做一次分类」 高光谱地物分类：每个像素判一次类别
    识别 → 分类 识别可以看成「类别数很大的分类」 人脸识别：类别数 = 注册人数
    检测 + 识别 先找到人，再判断这个人是谁 人脸识别系统：人脸定位 → 人脸识别

    最后一行正是课件讲计算机模式识别时给的流程： 课件在这一节配了人脸识别的例子，把流程画成 人脸描述 → 人脸定位 → 人脸识别 三步。 这三步恰好对应本页的三种形式：

    课件步骤 对应本页的形式 输出
    人脸描述 特征提取（不是最终任务，是前置步骤） 一组数值
    人脸定位 检测 目标框
    人脸识别 识别 身份编号

    这说明一个完整的实用系统往往同时包含好几种形式， 不能把它简单归成「这是一个分类问题」。

    看到新任务，先问三个问题

    以后遇到任何新场景，都可以用这三问快速定位任务形式：

    1. 最终答案是一个标签，还是一组位置，还是一张标签图，还是一个编号？ —— 这一问直接决定形式。
    2. 类别数会变吗？ 不变 → 分类；随对象库增长 → 识别。
    3. 答案的空间粒度是什么？ 整图 → 分类；目标级 → 检测；像素级 → 分割。

    这三问的顺序不能反：先看输出，再看类别数，最后看粒度。 多数人出错是因为一上来就问「用什么算法」，而不是先问「要输出什么」。

    五、难点归纳：为什么真实场景这么难¶

    这一节把前面例子里的困难抽出来，归纳成八条。 每一条都配一个说明，说明它「为什么难」以及「在哪个例子里出现过」。 请注意：这八条不是并列的八件事，它们有些是数据本身的性质， 有些是采集条件的干扰，有些是工程成本的约束。

    难点的来源 包含哪几条
    类别本身的性质 类内差异大、类间差异小
    采集条件的干扰 遮挡、光照与尺度变化、视角变化、背景复杂
    数据与成本的约束 样本少、标注贵

    5.1 类内差异大：同一个人，长得像两个人¶

    定义：「类内差异」指的是同一个类别内部不同样本之间的差别。 类内差异大，意味着「同一类」这个标签底下的样本彼此长得很不一样。

    为什么难：分类算法要学的规则是「同类相似、异类相异」。 如果同类样本自己都不相似，那这条规则就没有立足点 —— 算法会误以为「这两个样本差别这么大，一定是两类」， 于是把同一个人判成两个人，或者把同一种地物判成两种。

    课件里的例子：开放环境下的人脸识别。 同一个人的正面照、侧脸照、低头照、戴口罩的照片， 彼此的差别可能比两个人之间的差别还大。

    5.2 类间差异小：两种东西，长得几乎一样¶

    定义：「类间差异」指的是不同类别之间样本的差别。 类间差异小，意味着「两类」之间的界限本来就模糊。

    为什么难：类间差异小的时候， 两类样本在特征空间里重叠在一起， 再强的分类器也只能在重叠区域里「猜」，错误率有下界。

    课件里的例子：高光谱里同一大类下的细分类别 —— 课件用四类地物（沥青、树木、草地、屋顶）做过对比， 其中「树」和「草地」这种植被类地物，在部分波段上反射特性接近。 这也是课件为什么要在方法里加入波段选择： 把有用的光谱差异挑出来，把没用的冗余去掉，就是在放大类间差异。

    import numpy as np

rng = np.random.default_rng(42)


def make(n, center, spread):
    """造 n 个二维样本，围绕 center 散布，离散程度由 spread 控制。"""
    return rng.normal(center, spread, size=(n, 2))


A = make(50, [0.0, 0.0], 0.4)    # 类 A：紧致
B = make(50, [1.2, 0.0], 0.4)    # 类 B：与 A 距离近，且同样紧致 → 类间差异小
C = make(50, [0.6, 0.0], 2.5)    # 类 C：位置居中，但非常分散 → 类内差异大


def mean_dist_within(X):
    """类内平均距离：同一类中所有样本对距离的平均（不含自己和自己）。"""
    d = np.sqrt(((X[:, None, :] - X[None, :, :]) ** 2).sum(-1))
    n = len(X)
    return d.sum() / (n * n - n)


def mean_dist_between(X, Y):
    """类间平均距离：两个类的所有样本对距离的平均。"""
    d = np.sqrt(((X[:, None, :] - Y[None, :, :]) ** 2).sum(-1))
    return d.mean()


print("%-14s %14s" % ("比较对象", "平均距离"))
for name, X, Y in [("A 类内部", A, None), ("B 类内部", B, None),
                   ("C 类内部", C, None),
                   ("A 与 B 之间", A, B), ("A 与 C 之间", A, C)]:
    v = mean_dist_within(X) if Y is None else mean_dist_between(X, Y)
    print("%-14s %14.4f" % (name, v))

wa, wb, wc = mean_dist_within(A), mean_dist_within(B), mean_dist_within(C)
bab, bac = mean_dist_between(A, B), mean_dist_between(A, C)
print()
print("A、B 的类内距离平均 = %.4f，A 与 B 的类间距离 = %.4f"
      % ((wa + wb) / 2, bab))
print("→ 类间 / 类内 = %.2f，小于 3，说明两个类有大量重叠，很难分"
      % (bab / ((wa + wb) / 2)))
print()
print("C 的类内距离 = %.4f，是 A 的 %.1f 倍" % (wc, wc / wa))
print("而 A 与 C 的类间距离 = %.4f" % bac)
print("→ 类间 / 类内 = %.2f，小于 1：C 类内部散得比它跟别人还远"
      % (bac / wc))
print("   这种情况下「类内相似」的假设完全失效")

    5.3 遮挡：目标的一部分根本看不见¶

    定义：目标被其他物体挡住了一部分。 为什么难：分类算法看到的输入少了信息， 但它不知道自己缺的是哪一块 —— 它可能把「半个车」当成一个新类别，也可能把「被挡住的两个人」当成一个人。 课件里的例子：视频监控里的人物入侵检测和跟踪 —— 城铁沿线有柱子、树木、其他车辆，目标被遮挡是常态。

    5.4 光照与尺度变化：同一个东西，亮度差一百倍、大小差一百倍¶

    定义：光照变化指同一物体在不同照明条件下的亮度差异； 尺度变化指同一物体在图像上占的像素数差异。 为什么难：这两件事改变的是像素值本身，而不是物体本身 —— 算法拿到的数字变了，但「答案」不该变。 课件里的例子：「开放环境远距离多尺度人脸识别」这一整句话就是这两条的集合， 3.2 节已经把「远距离」和「多尺度」分别算清了。 此外车辆检测那一页特意写了「可以针对不同尺度的城市交通场景」。

    5.5 视角变化：换个角度就换了一张脸¶

    定义：同一物体从不同角度被拍摄。 为什么难：视角变化会改变可见的部分（侧面看不到另一只眼睛）、 改变各部分的相对位置（透视形变）、 也会改变遮挡关系（3.5 节）。 课件里的例子：行人再识别要解决「同一个人在不同摄像头拍到的画面里认出来」， 而不同摄像头的高度、朝向、距离都不一样，视角必然变化。

    5.6 背景复杂：要找的东西淹没在干扰里¶

    定义：目标周围的干扰物多、种类杂、密度高。 为什么难：检测类任务要在图像里穷举所有可能位置， 背景越复杂，「把背景误判成目标」的概率就越高（这就是虚警）。 课件里的例子：课件在车辆检测里区分了 「大范围场景（天）→ 局部场景（空）→ 具体目标（地）」三个层次， 之所以要由粗到细，就是为了在复杂背景里先把候选区域缩小。

    5.7 样本少：想学的类，手里没几个例子¶

    定义：可用于训练的带标签样本数量太少。 为什么难：参数越多的模型需要的样本越多（这一条在统计学习里叫维数灾难， 本页只提现象）：样本少的时候， 模型可以把训练样本全部记住（训练集上接近 100%）， 但换到新样本上就大幅下降 —— 也就是过拟合。 课件里的例子：课件把方法写成 「SVM + 波段选择 + 小样本」（2011）， 并在方法对比表里标明「小样本情况下性能良好」是某些方法的优势； 同时课件也点出小语种的语料资源稀缺是自然语言处理的核心科学问题之一。

    5.8 标注贵：标签本身要花很大代价才能拿到¶

    定义：把原始数据变成「带标签的数据」所需要的成本。 为什么难：数据多不等于标注过的数据多，而监督学习需要的是后者。 并且不同任务的标注成本差别巨大（见 4.2 节那张成本表）： 整图一个标签最便宜，逐像素标签最贵。 课件里的例子：医学图像分割要从 CT、MRI、X 光影像中分离出 器官、肿瘤、血管 —— 这类逐像素标注必须由专业人员完成。 这一条还引出一个连带后果：标注贵 → 样本少 → 只能靠 半监督、迁移学习、小样本学习这些方法来缓解， 而这些方法恰好是课件在方法分类里单列出来的几个方向。

    八条难点里，有三条是「方法救不了」的

    把八条难点按「靠什么缓解」分一下，结论会让人清醒一点：

    难点 主要靠什么缓解 能不能彻底解决
    光照与尺度变化 数据增广、多尺度特征、归一化 能大幅缓解
    视角变化 多视角训练、三维结构建模 能大幅缓解
    遮挡 上下文推理、跟踪补全 能大幅缓解，难以彻底
    背景复杂 更深的模型、更多负样本 能缓解，但要付出虚警代价
    类内差异大 度量学习、更大容量模型 只能缓解，是内在性质
    类间差异小 更多特征、更好的特征（如光谱） 不能彻底解决，错误率有下界
    样本少 小样本方法、先验知识 不能彻底解决，信息量就那么多
    标注贵 半监督、主动学习、弱标注 不能彻底解决，是资源约束

    最后三行是真正的天花板： 类间差异小是数据本身的信息量问题， 样本少和标注贵是资源约束问题 —— 它们不是「方法不够好」造成的。 所以在真实项目里，遇到这三条时正确的做法往往是 改任务定义（比如把「细分到亚种」改成「先分大类」） 而不是继续加大模型 ✓

    六、模式识别与其它学科的关系¶

    6.1 课件给出的相关学科清单¶

    课件在讲模式识别的相关学科时，给了一个明显的缩进结构：

    人工智能 - 模式识别 - 机器学习 - 数据挖掘 - 计算机视觉 - 自然语言处理

    这个缩进说明了两层关系，两层都要读懂：

    关系 内容
    都属于人工智能 五项都是人工智能的下级分支，它们是人工智能这个「大筐」里的内容
    彼此并列 模式识别、机器学习、数据挖掘、计算机视觉、自然语言处理之间不是包含关系，谁也不装在谁里面

    「并列」这个词必须理解准：并列不等于没有交集。 它们的关系是同一层级的、互相交叉的：

    交叉形式 例子
    同一任务被两边都研究 图像分类：模式识别把它当经典任务，计算机视觉把它当核心问题
    同一方法被两边都用 SVM、神经网络：机器学习提供算法，模式识别用它建模型
    数据对象决定侧重不同 模式识别偏感知数据（图像、语音），数据挖掘偏非感知与混合数据

    决策表里最重要的一行

    第七行「这个样本是不是某个人的」经常被忽略， 但它把识别和认证区分开了，而这两者的指标完全不同：

    识别（1 : N） 认证（1 : 1）
    问题 这是库里 1000 个人里的哪一个 这是不是指定的那一个
    输出 一个编号 是或否
    主要风险 认成别人（误认） 误放行（虚警）或误拒绝（漏报）
    类别数 随库增长 永远是 2 类

    做成产品时选错这一行，会导致指标和验收标准全部选错： 识别关心的是「首位命中率」，认证关心的是「虚警率和漏报率」。

    这张表的使用顺序要固定下来： 先问输出粒度（整图 / 目标 / 像素 / 编号），再问类别数变不变，最后才问用什么算法。 很多项目一开始就跑偏，就是因为直接跳到第三步， 按「我要用最新的模型」去选方法，而不是按「我要什么输出」去选任务。

    典型例题¶

    例题 1：判断任务形式并写出输出形状¶

    下面四个场景，请分别判断属于哪一类任务形式，并写出模型的输出是什么形状。

    1. 判断一张拍摄到的飞机属于运输机、战斗机、预警机还是轰炸机。
    2. 在一幅城市交通图像里，把行人、摩托车、机动车分别框出来。
    3. 在一幅城市遥感影像里，为每个像素标注道路、建筑、植物、车辆或其它。
    4. 判断监控画面里的这个行人，是不是上一路摄像头里出现过的那个人。
    思路

    这类题不要凭感觉答，按 4.3 节固定的三问顺序走：

    1. 最终答案是一个标签、一组位置、一张标签图，还是一个编号？
    2. 类别数是固定的还是随对象库增长的？
    3. 答案的空间粒度是整图、目标级还是像素级？

    特别要注意第 4 小题： 「是不是同一个人」听起来像二分类， 但要先在两个候选之间做匹配，这一步属于识别（1 : N 或 1 : 1 比对）， 而不是普通的分类。换句话说，识别要先有两边的东西可比。

    常见错误：把第 2 小题答成「分类（多类）」。 错在把「有几个框」这个变长输出忽略了 —— 分类的输出永远是固定长度的。

    解答
    小题 形式 输出内容 输出形状
    1 分类 四个机型里选一个 1 个类别标签
    2 检测 每个目标一个框 + 类别 \(N\) 个框，\(N\) 由图里目标数决定
    3 分割（像素级分类） 每个像素一个类别 与输入同高同宽的标签图
    4 识别（更准确地说是行人再识别） 同一个人 / 不是同一个人 1 个判断，或库中一个编号

    四道小题各自的判别依据：

    • 第 1 题：输入一幅图 → 输出一个标签，类别数（4 个机型）固定 → 分类。 课件对应的例子是飞机分类识别，课件还给了各类的识别精度和一个平均指标。
    • 第 2 题：输出是框，而且框的个数不固定 → 检测。 课件对应的例子是行人与摩托车检测、机动车检测， 课件用「天 → 空 → 地」来描述不同尺度下的检测。
    • 第 3 题：输出与输入同高同宽，每个像素都有标签 → 分割。 课件对应的例子是城市房屋分割，课件给出了「房屋、绿植、道路、车辆、其它」五类。
    • 第 4 题：要判断的是身份是否一致，输出是「同一个人 / 不是」 或者库中某个编号 → 识别。 课件把「人脸识别 / 开放条件下行人再识别」并列写在应用实例里， 正是因为它们解决的是同一个问题：跨视角、跨时间地把身份接上。

    四道小题连起来还有一个规律： 从第 1 题到第 4 题，输出的信息量在增加 —— 分类只给一个标签，检测要给一串位置，分割要给每个像素都表态， 识别要在候选集合里找出唯一一个。 这解释了为什么它们对标注的要求越来越高（4.2 节那张成本表）。

    例题 2：解释「开放环境远距离多尺度」三个难点¶

    课件用「开放环境远距离多尺度人脸识别」这十二个字概括了一个应用。 请分别解释这三个词的技术含义， 并说明它们为什么会互相恶化，而不是各自独立。

    思路

    这题的坑在于把三个词当成三个形容词复述一遍， 例如答「开放环境就是环境很开放」。这样等于没答。

    正确的做法是：对每一个词，都要说清 它改变了什么量（像素数？姿态分布？光照分布？） 以及这个量变了以后算法会遇到什么问题。 最后一部分「互相恶化」需要举出至少一组具体的乘法效应。

    解答
    词 技术含义 改变了什么 带来的困难
    开放环境 采集条件不受控：光照、姿态、表情、表情遮挡、背景都不可预定 让类内分布变得很宽 同一个人的两张照片差别可能超过两名不同的人 → 类内差异大
    远距离 目标到相机距离大 让像素数按距离反比减少 距离 50 米时脸高只剩约 5 个像素，纹理与五官细节全部丢失 → 可用特征不够
    多尺度 同一场景里目标像素数跨好几个数量级 让所需的感受野跨度极大 小尺度上有效的特征（眼角形状）在大尺度上完全不同，一套参数难以兼顾 → 顾此失彼

    三者互相恶化的两条具体路径：

    组合 恶化方式
    远距离 + 开放环境 距离远本来就把细节压掉了大半，此时光照不好或姿态偏离正脸，会把剩下的一点信息再抹掉一层；两个损失是乘在一起的
    远距离 + 多尺度 为了处理远处的小目标必须放大或使用高分辨率输入，但同一场景里近处的目标又要求小感受野 —— 同一个系统要同时满足两个相反的要求

    工程上的应对（课件用「天 → 空 → 地」给了思路）：

    1. 由粗到细的级联：先在大范围快速筛出候选区域，再逐步放大精细判别；
    2. 尺度归一化：把不同尺度的目标映射到同一个尺度空间后再比较；
    3. 分工处理：远处目标走「先检测定位、后识别」的两段流程， 而不是指望一个模型一次做完。

    关键结论：这三个词不是并列的三个难度， 而是同一条难度曲线上的三个不同侧面 —— 距离决定像素数，像素数决定尺度，环境决定同类样本的分散程度， 三者最终都汇聚到同一个后果上：输入里的可用信息量不够。

    例题 3：高光谱与普通图像的区别，以及配套方法¶

    课件在讲高光谱地物目标分类时，方法要点写的是 「SVM + 波段选择 + 小样本」， 另一处写的是「基于结构稀疏学习的高光谱解混」。

    请回答： 1. 高光谱图像与普通彩色图像在数据结构上差在哪？ 2. 为什么高光谱任务特别强调波段选择？ 3. 为什么强调小样本？

    思路

    三问是一条链子： 数据结构 → 维度变高 → 参数量增大 → 需要降维和抗小样本。

    答第一问要给具体的形状（比如 \((H, W, B)\) 和 \((H, W, 3)\)）， 不能只说「高光谱波段多」。 答第二问要说到「冗余」和「噪声放大」两层。 答第三问要说到「标注成本」和「维度与样本数的匹配」两层。

    易错点：把「解混」当成一种分类器。 它不是分类器，而是处理「一个像素混了多种地物」这件事的思路， 解混之后通常还要再分类。

    解答

    第 1 问：数据结构上的差别

    普通彩色图像 高光谱图像
    每个像素的值个数 3（红、绿、蓝） 几十到上百个波段
    数据形状 \((H, W, 3)\) \((H, W, B)\)，\(B\) 是波段数
    维度数 3 3（但第三个维度的长度大得多）
    能回答的问题 亮不亮、什么颜色 反射的光谱曲线长什么样

    关键差别是第三个维度的长度： 同样是 \(8 \times 8\) 个像素，波段数 100 时元素总数是 6400， 波段数 1 时只有 64，相差整 100 倍。 多出来的信息正是判别材质的依据 —— 沥青、草地、屋顶在可见光下可能都很暗， 但它们在各波段上的反射率组合不同。

    第 2 问：为什么强调波段选择

    两个理由：

    1. 波段之间高度相关，信息是冗余的。 相邻波段的读数往往几乎相同，全用上只是把同一个信息数了两遍， 而每一次都引入一份噪声。
    2. 维度一高，要估计的参数就跟着涨。 参数多了，需要的数据量也跟着涨， 而带标签的高光谱数据恰恰很少 —— 这就通向第 3 问。

    所以波段选择的作用是「保留差异、丢掉冗余」： 挑出对不同地物最敏感的那些波段， 相当于在放大类间差异（5.2 节）的同时降低参数负担。

    第 3 问：为什么强调小样本

    两层原因：

    1. 标注昂贵：高光谱地物分类是逐像素标注，属于成本最高的一类标注（4.2 节）； 而且判读地物类别需要专业知识。
    2. 维度与样本数要匹配：参数越多，需要的样本越多； 样本不够时，模型会把训练样本记住而不是学到规律（过拟合）。

    这正是课件把方法写成 「SVM + 波段选择 + 小样本」 的原因： 三件事分别对应一个分类器、一个降维手段、一个数据条件。 SVM 走的是「大间隔」的思路，在样本少时相对不容易过拟合， 所以课件在方法对比里注明它「小样本情况下性能良好」。

    至于「基于结构稀疏学习的高光谱解混」，它解决的是另一个问题： 一个像素里往往混了多种地物（比如一棵树的边缘像素里既有树也有土）， 直接把整像素判给某一类会带来系统性偏差。 「解混」就是先把混合比例估出来， 「结构稀疏」则是利用同类地物在空间上聚成片这个结构约束， 让估出来的成分图不要被噪声打得七零八落。

    第 2 问：车辆类的查全率 = 0

    因为查全率的分母是真实目标个数（车辆像素共 84598378 个）， 而全判成道路时，车辆像素一个也没有被判对，分子是 0。 所以车辆类查全率 = 0.000000。

    这个结果和 32.74% 的总准确率放在一起看，就是这道题的核心： 同一个模型，总准确率看起来「还行」，而在我们最关心的类上完全是 0 分。

    第 3 问：为什么不能只报总准确率

    三个理由：

    1. 总准确率被大类主导。 道路、建筑、植物三类合计占了 88.4%， 少数类（车辆 1.42%）对总数的贡献极小 —— 它从 0 提到 1.0，也最多让总准确率涨 1.42 个百分点。
    2. 任务的价值往往在少数类。 城市房屋分割这个任务里， 车辆恰恰是最需要被找出来的目标之一（交通分析、违规停车检测）。 一个把车辆全部漏掉的模型，在城市管理场景里几乎没有价值。
    3. 总准确率不能反映「错在哪里」。 是漏检（车辆判成道路） 还是虚警（道路判成车辆），总准确率一律不区分。

    应该报什么：

    指标 回答的问题
    分类别的查全率 每一类各找回了多少（少数类必须单独看）
    分类别的精确率 判成该类的像素里有多少是对的
    分类别的交并比 该类预测区域与真值区域的重合程度（分割任务主指标）
    宏平均与微平均 不同类别样本数差很大时，两种平均会给出很不同的结论

    课件在讲多类问题的 Recall、Precision、F1 时专门区分了这两种平均方式： 宏平均是直接对所有类别的指标取算术平均，每个类权重相同； 微平均是先把所有类别的 TP、FP、FN 加起来再算， 每个类的权重大致正比于它的样本数。 在类别不平衡的场合，宏平均对少数类更公平，微平均会被大类带着走 —— 这正是上面那个「全判成道路」例子的教训。

    自测¶

    Q1 课件在进入应用这一节时先给了一句总纲： 「通过数字化手段来获取感知数据：来源丰富、数量巨大」。 请说明「数字化」这个词在这里为什么是必要的一环， 以及「来源丰富」和「数量巨大」各自意味着什么不同的挑战。

    解答

    「数字化」是必要的一环，因为它是「数据」这件事的前提。 模式识别要处理的输入必须是计算机能读写的东西， 而物理世界里的光、声、压力本身不是数据。 数字化做的事就是：用传感器把这些信号采集下来，并变成数字量。 没有这一步，「模式识别」连输入都拿不到。

    「来源丰富」和「数量巨大」是两个不同的挑战：

    说法 含义 带来的挑战
    来源丰富 数据种类多：图像、视频、音频、文本、遥感多波段、传感器数值 任务形式多样，不可能用一套规则应付所有场景（对应第四节的四种形式）
    数量巨大 数据规模大，且持续增长 人工处理在量上完全不可行（1.2 节算出来的人工覆盖率约 \(10^{-9}\)）

    一句话区分： 「来源丰富」让事情变「杂」，「数量巨大」让事情变「大」。 前者要求任务形式上的多样性，后者要求自动化 —— 这两条合起来，才是「让机器自动识别」成为唯一可行选择的理由。

    Q2 请写出识别任务的四种基本形式， 并为每一种写出：输出是什么、课件里的一个例子。

    解答
    形式 输出 课件的例子
    分类 一个类别标签（整幅图一个答案） 飞机分类识别、舰船分类识别、商品图片分类
    检测 一串目标框，每个框带位置、类别、置信度 交通标志检测、车辆目标检测、行人检测、人物入侵检测
    分割 与输入同高同宽的标签图，逐像素一个标签 图像语义分割、城市房屋分割、医学图像分割、高光谱地物分类
    识别 对象库里某个编号，或「不在库中」 人脸识别、行人再识别、指纹与虹膜识别、声纹识别

    两条容易答漏的补充：

    1. 分类和识别的输出形状一样，区别在类别数是否固定： 分类的类别数是固定的（机型 4 类、地物 5 类）， 识别的类别数随注册人数增长（今天 1000 人，明天 2000 人）。
    2. 检测的输出是变长的：框的个数取决于图里有几个目标， 这带来「怎么算框对上了」「怎么算漏检与虚警」两个额外问题。

    Q3 课件把「类内差异」和「类间差异」这两个词背后的困难放在了不同的应用里。 请说明这两个词各自的含义， 并说明它们哪个是「方法救不了」的，为什么。

    解答

    两个词的含义：

    词 含义
    类内差异 同一个类别内部不同样本之间的差别。类内差异大 = 同一类的东西彼此长得不像
    类间差异 不同类别之间样本的差别。类间差异小 = 两类东西长得几乎一样

    量化方式：两者都用「平均距离」度量，真正决定难易的是比值。 类间平均距离除以类内平均距离：比值大就好分，接近 1 就难分。

    哪个方法救不了：类间差异小。

    理由是它属于数据本身的信息量问题，不是方法问题：

    情况 能不能靠方法解决 为什么
    类内差异大 能大幅缓解 差异来自姿态、光照等外在因素，可以通过数据增广、度量学习把同类样本拉近
    类间差异小 不能彻底解决 两类样本在特征空间里本来就重叠，任何判别规则在重叠区域都只能猜，错误率有下界

    所以遇到类间差异小的任务，正确的做法往往是 换更有效的特征（课件的例子：从颜色换成光谱曲线，用波段选择放大差异）、 或者改任务定义（先分大类，再在需要时细分）， 而不是指望换一个更强的模型就能解决。

    Q4 课件讲到「模式识别」「机器学习」「数据挖掘」「计算机视觉」「自然语言处理」时， 用缩进把它们列在「人工智能」之下。 请说明这个缩进结构表达了哪两层关系， 以及「并列」是否意味着「没有交集」。

    解答

    这个缩进表达了两层关系：

    关系 内容
    同属人工智能 五项都是人工智能的下级分支 —— 人工智能是包含它们的那个「大筐」
    彼此并列 五项之间没有包含关系，谁也不装在谁里面

    「并列」不意味着没有交集，恰恰相反：

    交叉形式 例子
    同一任务被两边研究 图像分类：模式识别当经典任务，计算机视觉当核心问题
    同一方法被两边使用 SVM、神经网络：机器学习给算法，模式识别用来建模型
    数据对象决定侧重 模式识别偏感知数据、面向应用；数据挖掘偏非感知与混合数据

    课件自己也引了一句总结：这几个术语「很难分开，因为它们在范围上大量重叠」。

    一句话概括这两层关系： 分类上是并列的（谁也不包含谁），工作中是交叉的（方法互相借用、任务经常重合）。 理解这一点很实际 —— 它意味着同一个任务在不同的学科材料里 可能用不同的名字出现，但它们讲的是同一件事。

    小结¶

    要记住的 为什么
    数字化是模式识别的前提 没有数字化就没有「数据」，模式识别连输入都拿不到
    感知数据的两个特点：来源丰富、数量巨大 「丰富」让任务变杂，「巨大」让自动化成为唯一选择
    人工覆盖率约 \(10^{-9}\) 量级 数量到了这个量级，人再看也覆盖不了零头
    两条分类线互相垂直 按数据类型分（图像/视频/音频/文本）与按任务形式分（分类/检测/分割/识别）不能混
    生物特征识别是个取舍，不是排名 精度高往往需要用户配合（虹膜、指静脉），不配合的精度就低（签名、步态）
    「开放环境」改变的是类内差异 采集条件不受控，同一个人的两张照片差别可能超过两个人
    「远距离」的本质是像素数反比下降 像素高度 \(= f \cdot H / d\)，距离 50 米时脸高只剩约 5 像素
    「多尺度」的本质是感受野跨度极大 小尺度上有效的特征在大尺度上完全不同，一套参数难以兼顾
    三个难点是相乘的 远距离把细节压掉，开放环境再抹一层，损失叠加而非并列
    检测和跟踪是两件事 检测管「这一帧在哪里」，跟踪管「跨帧是不是同一个」
    高光谱多出的是光谱维度 \((H, W, B)\) 比 \((H, W, 3)\) 每个像素多出上百个读数，能判别材质
    解混、波段选择、SVM 是三件不同的事 解混处理混合像素，波段选择降维去冗余，SVM 是分类器
    分割 = 像素级分类 输出与输入同高同宽，每个像素一个标签
    「性质一致」指的是语义一致 不是颜色一致，所以分割叫「语义」分割
    阈值法能演示分割的困难 单独看灰度的阈值法在灰度重叠时会把区域切碎或整体漏掉
    类别不平衡会骗指标 城市房屋分割里最多类与最少类相差 23 倍，全判成道路也有 32.74% 的准确率
    四种基本形式的输入输出完全不同 分类给一个标签，检测给一串框，分割给一张标签图，识别给一个编号
    分类与识别的区别在类别数是否固定 分类类别数固定，识别随对象库增长；输出形状看起来一样
    识别（1:N）与认证（1:1）指标不同 识别看首位命中率，认证看虚警率与漏报率
    八条难点分三类来源 类别性质（类内差异大、类间差异小）、采集干扰（遮挡、光照与尺度、视角、背景）、资源约束（样本少、标注贵）
    类间差异小、样本少、标注贵是天花板 它们是信息量和资源问题，不是方法不够好，需要改任务定义
    标注成本从低到高：分类 < 检测 < 识别 < 分割 分割要逐像素标注，医学影像还要专家来做
    五个方向并列都属于人工智能，且高度交叉 没有任何一对互相包含，但重叠普遍存在（模式识别与计算机视觉重叠占比最高）
    选任务形式的顺序不能反 先问输出粒度，再问类别数变不变，最后才问用什么算法
