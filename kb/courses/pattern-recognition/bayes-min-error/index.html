    最小错误率贝叶斯决策¶

    上一页 贝叶斯决策的数学基础 把后验概率 \(P(\omega_i \mid x)\) 算出来了。 这一页要回答一个更基本的问题：

    拿到后验概率之后，凭什么可以说「该判给哪一类」？

    一个很自然的想法是「谁的后验概率大就判谁」。 这个想法是对的 —— 但「对」需要证明。 这一页的核心，就是把「谁大判谁」这句话， 证明成「这样做能让平均错误率最小」， 并且把这个平均错误率算出来。

    看起来差不多的说法 实际差别 后果
    「谁的后验大就判谁」 这句话本身没错，但不证明就只是习惯，不是方法 无法回答「还能不能更好」
    「比两个似然谁大」 漏掉了先验，等于默认两类一样常见 先验悬殊时判决被带偏 ⚠
    「理论上可以做到零错误」 两类分布有重叠区，重叠区的样本必然有一类要错 错误率存在一个不为零的下界 ⚠

    这一页的主线

    整页只围绕一个论断展开：

    在每一个 \(x\) 上，都判给后验概率最大的那一类，就能让平均错误率最小。

    这个论断分两步落地：

    步 做什么 在哪一节
    1 把判决规则画出来，并给出四种等价写法 一、二
    2 定义「平均错误率」，证明逐点最优等于整体最优 三
    3 说明这个错误率是任何分类器的下界 四
    4 把错误率算成具体数字（手算 + 数值核对） 五、六、七

    读懂这四步，你就不是在「接受一个结论」， 而是在跟着一个证明走完

    一、判决问题：怎么把后验变成一次决定¶

    1.1 最朴素的判决想法¶

    先把记号统一（与上一页一致，不再重复解释）：

    记号 含义
    \(\omega_i\) 第 \(i\) 个类别，\(i = 1, 2, \dots, c\)
    \(x\) 观测到的特征向量
    \(P(\omega_i \mid x)\) 后验概率：看到 \(x\) 后它属于第 \(i\) 类的概率

    有了后验，最自然的判决就是「选后验最大的那个」。

    两类情形（\(c = 2\)）：

    \[\text{判 } \omega_1 \quad \text{当} \quad P(\omega_1 \mid x) \gt P(\omega_2 \mid x); \qquad \text{否则判 } \omega_2\]

    多类情形（\(c \geq 3\)）：

    \[\text{判 } \omega_i \quad \text{当} \quad P(\omega_i \mid x) = \max_{j=1,\dots,c} P(\omega_j \mid x)\]

    这个规则的朴素读法： 「看到 \(x\) 之后，哪一类最可能，就说是哪一类。」

    它还有一个常用名字：最大后验（MAP, Maximum A Posteriori）判决

    1.2 判决规则画出来是什么样子¶

    先不看公式，先看图。判决规则在几何上只做一件事： 在特征轴上找一个分界点，左边归一类、右边归另一类。

    下面这张图把上一页的信号设定画成两条「加权密度」曲线 （加权密度 = 似然 × 先验，第六节会正式定义）：

    看图上的三个要素：

    图上看到什么 对应到公式里
    蓝色曲线在左侧更高 \(P(\omega_1)p(x\mid\omega_1) \gt P(\omega_2)p(x\mid\omega_2)\)，判 \(\omega_1\)
    橙色曲线在右侧更高 反过来，判 \(\omega_2\)
    虚线（两条曲线的交点） 就是判决边界，也就是第六节的 \(g(x) = 0\) ✓

    这张图说明什么：判决规则不是「在整条轴上处处比较」， 而是等价于在分界点处切一刀 —— 因为两条高斯曲线只交于一点， 交点左边永远是蓝的高、右边永远是橙的高 ✓

    这个观察带来三个好处：

    好处 说明
    判决可以离线算好 事先求出那个分界点，在线判决只需一次大小比较 ✓
    错误率可以用面积算 见第五节：错误率就是「较低那条曲线下方的面积」
    结论可以画出来看 参数一变，两条曲线怎么动、分界点怎么移，一目了然 ✓

    一句话：后面所有的推导，都是在回答「那条虚线为什么在那里」

    两条尾巴先记个印象：把横轴拉到很远的地方（\(x\) 很大或很小）会发现， 更「胖」的那条曲线（\(\omega_2\)，标准差 \(4\)）最终反而更高。 这说明两条曲线的交点不止一个 —— 第六节会专门处理这件事

    1.3 为什么不能停在「看起来合理」¶

    「谁大判谁」听起来无懈可击，但有两件事必须问清楚：

    必须问的问题 为什么要问
    这个规则到底在优化什么？ 只比较后验，没有说明「比较的后果是好是坏」
    有没有比它更好的规则？ 不给下界，无法知道是否最优

    第二个问题尤其关键：如果不知道下界在哪， 就算当前方法表现很好，你也无法知道「还有多少改进空间」。

    所以我们要给「判决」配一个可度量的目标 —— 这个目标就是平均错误率。 然后证明：MAP 判决恰好让它最小

    1.4 把「判错」写成一个概率¶

    要给判决定目标，第一步是把「判错」量化。

    注意「判错」这件事的概率性质：给定 \(x\) 之后， 我们的判决是确定的（比如判 \(\omega_1\)）， 但真实类别是未知的随机量。所以「判错」是一个随机事件

    两类情形的条件错误率：

    我们的判决 什么时候算错 错的概率
    判 \(\omega_1\) 真实类别是 \(\omega_2\) \(P(\omega_2 \mid x)\)
    判 \(\omega_2\) 真实类别是 \(\omega_1\) \(P(\omega_1 \mid x)\)

    所以，给定 \(x\) 时的条件错误率是

    \[P(\text{error} \mid x) = \begin{cases} P(\omega_2 \mid x), & \text{若判 } \omega_1 \\ P(\omega_1 \mid x), & \text{若判 } \omega_2 \end{cases}\]

    这个式子的意思：判错的概率就是「另一类」的后验概率 —— 因为我们只可能把「属于另一类」的样本判错 ✓

    1.5 关键一步：两个后验之和为 1¶

    因为 \(x\) 必然属于某一类，而各类互斥，所以

    \[P(\omega_1 \mid x) + P(\omega_2 \mid x) = 1\]

    这个简单的事实用处很大：两个非负的数相加等于 1， 必然一个是「大的」、一个是「小的」， 而且小的那个一定不超过 \(1/2\) ✓

    于是「选后验大的那一类」等价于「选条件错误率小的那一类」：

    \[\min\{\,P(\omega_2 \mid x),\; P(\omega_1 \mid x)\,\} = 1 - \max\{\,P(\omega_1 \mid x),\; P(\omega_2 \mid x)\,\}\]

    这句话是整页的枢纽，用文字再说一遍：

    判 \(\omega_1\) 会错成 \(P(\omega_2 \mid x)\)，判 \(\omega_2\) 会错成 \(P(\omega_1 \mid x)\)。 想让错误概率小，就该选使错的那一项更小的那个判决 —— 而这一项正好是另一类的后验。 所以「让错误概率最小」 \(\iff\) 「让被选中那一类的后验最大」

    这就把「谁大判谁」和「错误率最小」接上了。 下一步（第三节）要做的，是把「每个 \(x\) 上的错误率」汇总成「整体错误率」， 并证明逐点最小确实能推出整体最小。

    二、判决规则的四种等价写法¶

    这一节要说明：同一个判决，可以写成四种形式， 它们的判决结果完全一样，但用途不同。

    2.1 形式一：直接比后验¶

    \[\text{判 } \omega_1 \quad \text{当} \quad P(\omega_1 \mid x) \gt P(\omega_2 \mid x)\]

    特点：最直观，直接对应「哪类更可能」这句话。

    缺点：算后验需要算分母（证据 \(p(x)\)）， 多类时要求所有类的和，开销大； 而且当分母很小时容易数值下溢

    2.2 形式二：比「似然 × 先验」¶

    把后验展开（上一页的贝叶斯公式）：

    \[P(\omega_1 \mid x) = \frac{p(x \mid \omega_1)P(\omega_1)}{p(x)}, \qquad P(\omega_2 \mid x) = \frac{p(x \mid \omega_2)P(\omega_2)}{p(x)}\]

    比较两者时，两个分数分母相同（都是 \(p(x)\)），且 \(p(x) \gt 0\)， 所以分母可以约掉，不等号方向不变：

    \[P(\omega_1 \mid x) \gt P(\omega_2 \mid x) \iff p(x \mid \omega_1)P(\omega_1) \gt p(x \mid \omega_2)P(\omega_2)\]

    所以得到形式二：

    \[\text{判 } \omega_1 \quad \text{当} \quad p(x \mid \omega_1)P(\omega_1) \gt p(x \mid \omega_2)P(\omega_2)\]

    这是实际最常用的形式，因为它完全不需要算分母

    顺带得到一个重要结论：如果两个先验相等（\(P(\omega_1) = P(\omega_2)\)）， 那么先验也可以约掉，判决退化成只比似然：

    \[\text{判 } \omega_1 \quad \text{当} \quad p(x \mid \omega_1) \gt p(x \mid \omega_2)\]

    这叫最大似然（ML）判决，它是 MAP 判决在均匀先验下的特例 反过来：先验不相等时，绝对不能只比似然 ⚠

    2.3 形式三：比似然比与「先验门槛」¶

    把形式二两边同除以 \(p(x \mid \omega_2) P(\omega_1)\)（正的量，不等号不变）：

    \[\frac{p(x \mid \omega_1)}{p(x \mid \omega_2)} \gt \frac{P(\omega_2)}{P(\omega_1)}\]

    写成一般形式：定义似然比

    \[L(x) = \frac{p(x \mid \omega_1)}{p(x \mid \omega_2)}\]

    则判决规则是

    \[\text{判 } \omega_1 \quad \text{当} \quad L(x) \gt \theta, \qquad \theta = \frac{P(\omega_2)}{P(\omega_1)}\]

    这个写法的价值在于它把「两个量」分得很清楚：

    左边 \(L(x)\) 右边 \(\theta\)
    证据强度：观测 \(x\) 有多支持 \(\omega_1\) 先验门槛：先验对 \(\omega_1\) 有多不利
    由数据决定 由先验决定 ✓

    要点：「证据必须强到能跨过先验设的门槛，才判 \(\omega_1\)」✓

    注意门槛不是 1：\(\theta = P(\omega_2)/P(\omega_1)\)。 当 \(\omega_1\) 更常见（\(P(\omega_1) \gt P(\omega_2)\)）时 \(\theta \lt 1\) —— 意味着即使证据略微不利于 \(\omega_1\)，也可以判 \(\omega_1\)， 因为它本来就更可能出现

    「只比似然」和「比似然比」差在哪 —— 就差这个门槛

    写法 门槛 含义
    只比似然 \(\theta = 1\) 隐含假设「两类一样常见」
    正规的似然比 \(\theta = P(\omega_2)/P(\omega_1)\) 把先验差异考虑进来 ✓

    三、平均错误率：定义与「逐点最优」的证明¶

    这一节是整页的核心。要证明的命题是：

    在每个 \(x\) 上都判给后验最大的类，就能让平均错误率最小。

    证明分三步：定义目标 → 拆解目标 → 逐点最优。

    3.1 第一步：定义「平均错误率」¶

    为什么不能只用条件错误率： \(P(\text{error} \mid x)\) 只是在某一个具体的 \(x\) 上的错误率。 但特征 \(x\) 本身是随机的 —— 有的 \(x\) 常见（\(\omega_1\) 与 \(\omega_2\) 都有 不少样本落在那里），有的 \(x\) 罕见。 要度量一个判决规则的整体好坏，必须把「\(x\) 出现的可能性」也考虑进去 ✓

    定义：平均错误率（average error rate）是条件错误率在 \(x\) 上的加权平均， 权重就是 \(x\) 出现的密度 \(p(x)\)：

    \[\boxed{\;P(\text{error}) = \int P(\text{error} \mid x)\, p(x)\, dx\;}\]

    逐项读这个式子：

    部分 含义
    \(P(\text{error} \mid x)\) 在这个 \(x\) 上判错的概率
    \(p(x)\) 这个 \(x\) 出现得有多频繁
    \(p(x)\,dx\) 落在这个「小片」\(dx\) 上的概率份额
    \(\int \cdots dx\) 把所有 \(x\) 的贡献加起来 ✓

    这个定义的关键点： \(p(x)\) 是非负的（密度不可能小于 0）。 这一点是下一步证明的全部依据

    离散特征的情形：积分换成求和，

    \[P(\text{error}) = \sum_{x} P(\text{error} \mid x)\, P(x)\]

    逻辑完全一样，\(P(x) \geq 0\)。本页后面用连续情形， 但结论对离散情形同样成立（第八节会用到）

    3.2 第二步：把目标拆成「逐点的选择」¶

    关键观察：一个判决规则 \(d(\cdot)\) 在每个 \(x\) 上做一个选择。 一旦规则定下来，\(P(\text{error} \mid x)\) 就由这个选择决定：

    \[P(\text{error} \mid x) = \begin{cases} P(\omega_2 \mid x), & \text{规则在 } x \text{ 处判 } \omega_1 \\ P(\omega_1 \mid x), & \text{规则在 } x \text{ 处判 } \omega_2 \end{cases}\]

    所以整个判决规则可以看成「给每个 \(x\) 各挑一个数」。 挑出来的这个数，就是该点的条件错误率。

    于是平均错误率变成了：

    \[P(\text{error}) = \int \big[\text{在 } x \text{ 处挑的那个错误率}\big]\cdot p(x)\, dx\]

    3.3 第三步：逐点最优 ⟹ 整体最优（证明）¶

    现在要证明：要让这个积分最小，只需让每个 \(x\) 处挑的数最小。

    证明（反证法，只需要用到一条简单事实）：

    已知事实：\(p(x) \geq 0\) 对所有 \(x\) 成立。

    反设：某个判决规则 \(d'\) 在某个正测度的区域 \(\mathcal{S}\) 上， 没有挑那个最小的数，而是挑了较大的那个。其余 \(x\) 上的选择与逐点最优规则 \(d^*\) 相同。

    比较两条规则：

    \[P_{d'}(\text{error}) - P_{d^*}(\text{error}) = \int_{\mathcal{S}} \big[\underbrace{P_{d'}(\text{error} \mid x)}_{较大} - \underbrace{P_{d^*}(\text{error} \mid x)}_{较小}\big]\cdot p(x)\, dx\]

    逐项判断符号：

    因子 符号 理由
    方括号里的差 \(\gt 0\) 因为我们规定的就是「挑了较大的那个」
    \(p(x)\) \(\geq 0\) 密度的基本性质
    区域 \(\mathcal{S}\) 正测度 反设的条件

    一个正数乘一个非负数，在正测度集合上积分，结果 \(\gt 0\)。

    所以：

    \[P_{d'}(\text{error}) \gt P_{d^*}(\text{error})\]

    即：任何偏离逐点最优的规则，平均错误率都严格更大。 证明完毕 \(\blacksquare\)

    这个证明的逻辑其实非常朴素 —— 一句话就能说清

    积分是「加权求和」，权重 \(p(x)\) 非负。

    就像「要让一堆正数加权和最小，只需让每一项都最小」一样 —— 因为每一项都是乘一个非负权重再加起来， 把某一项换成更大的数，总和只会变大，不会变小

    直觉类比 对应到这里
    一篮子水果，每个单价非负 \(p(x) \geq 0\)
    想花最少的钱 想让平均错误率最小
    每样都买最便宜的那种 每个 \(x\) 都挑最小错误率 ✓
    某一样故意买贵的 该区域上偏离逐点最优 → 总花费变大 ⚠

    注意这个证明不要求各点之间独立或无关 —— 它只用了「逐项加权、权重非负」这一条。 这也是它如此干净的原因

    3.4 由证明得到的判决规则¶

    既然「逐点挑最小错误率」是最优的，把这句话写出来：

    \[\text{在 } x \text{ 处，选使 } P(\text{error} \mid x) \text{ 最小的那一类}\]

    而由 1.5 节，\(P(\text{error} \mid x)\) 就是「另一类的后验」， 所以「让错误率最小」等价于「判给后验最大的类」：

    \[\text{判 } \omega_i \quad \text{当} \quad P(\omega_i \mid x) = \max_{j} P(\omega_j \mid x)\]

    这就是最小错误率贝叶斯决策规则。 它同时是：

    视角 表述
    决策论视角 条件风险最小的决策（在 0-1 损失下）
    概率视角 后验概率最大的类（MAP 判决）
    几何视角 落在该类的判决区域 \(R_i\) 内 ✓

    三种表述完全等价，只是说法不同。

    四、贝叶斯错误率：一个不可逾越的下界¶

    4.1 定义¶

    上一节算出的 \(0.14519751\) 有一个专门的名字：

    贝叶斯错误率（Bayes error rate）： 在已知真实分布的前提下，所有判别规则中能达到的最小平均错误率。

    它的地位：

    说法 说明
    它是下界 任何分类器的错误率都不可能低于它 ✓
    它是参照标准 用来判断「我的分类器还有多少改进空间」✓
    它不等于 0 只要两类分布有重叠，就必然有错误 ⚠

    为什么是「任何分类器都不可能低于」： 因为 3.3 节的证明是对所有可能的判决规则成立的 —— 不管规则多复杂、用什么模型、训练多久。 只要它比贝叶斯规则在某处做得不同，它的平均错误率就更大

    「贝叶斯错误率是下界」有一个前提，别记错

    前提：真实分布 \(p(x \mid \omega_i)\) 与先验 \(P(\omega_i)\) 已知。

    情形 贝叶斯错误率的作用
    分布已知 它是真正的下界，任何分类器都不可能低于它 ✓
    分布未知（实际情形） 它是理论标杆，但没法直接算出来（因为我们不知道真实分布）⚠

    实际工作中的用法：

    做法 说明
    用训练样本估计分布参数，再算出「估计版贝叶斯错误率」 只能算个近似
    用人类专家表现作为参照 常见替代方案
    比较多个模型的错误率，看谁更接近某个经验下界 相对比较更可靠 ✓

    不要把「估计出来的贝叶斯错误率」当成真下界 —— 如果估得不准，算出的「下界」甚至可能低于真实下界， 从而给出「我的模型已经超过理论极限」这种荒谬结论

    4.2 为什么它不能为 0：重叠区¶

    一个自然的疑问：既然贝叶斯规则是最优的，为什么错误率还有 \(0.145\)？

    答案在「重叠区」：

    区域 两条曲线的关系 判错的概率
    左段（\(x\) 明显小） \(\omega_1\) 的加权密度远大于 \(\omega_2\) 极小
    重叠区（两类都不小） 两条曲线量级相当 不可忽略 ⚠
    右段（\(x\) 明显大） \(\omega_2\) 的加权密度远大于 \(\omega_1\) 极小

    关键推理：在重叠区里， 无论你判哪一类，另一类在那里也有实质的概率质量。 判 \(\omega_1\)，就要承受「那里其实有 \(\omega_2\) 样本」的错误； 判 \(\omega_2\)，则要承受相反的错误。 两种选择的错误率都不可忽略

    所以只要两类分布重叠，错误率就不可能为 0 （除非重叠区本身概率为零，如两类完全可分）。

    用代码把这层关系看清楚 —— 下面用柱状图的形式 把两条加权密度画出来，同时标出判决边界：

    顺手可以把这个结论量化一下：错误率有一个通用上界。 在任意一个 \(x\) 上，判错的概率是两条加权密度里较小的那条， 而「较小者」永远不超过两者之和的一半 —— 所以

    \[P(\text{error}\mid x) = \min_i P(\omega_i\mid x) \leq \frac{1}{2},\qquad P(\text{error}) = \int P(\text{error}\mid x)\, p(x)\,dx \leq \frac{1}{2}\]

    这个结论说明什么：任何两类问题的贝叶斯错误率都不可能超过 \(1/2\)。 道理很朴素 —— 抛硬币式的随机判决期望错误率恰好是 \(1/2\)， 而贝叶斯规则不会比抛硬币更差 本页算出的 \(0.145\) 远小于 \(1/2\)，说明这两类还是相当可分的。

    下界则是「重叠量为零的那个极限」： 只要两类分布有重叠，就严格大于 \(0\)

    五、两类问题错误率的显式公式¶

    5.1 判决区域与错误来源¶

    把特征轴按判决规则分成两个区域：

    区域 范围 判决
    \(R_1\) \((-\infty, t)\) 判 \(\omega_1\)
    \(R_2\) \((t, +\infty)\) 判 \(\omega_2\)

    （这是本页参数下的情形：左段判 \(\omega_1\)、右段判 \(\omega_2\)。 下一节会说明方差不相等时判决区域可能不止一段）

    错误只可能来自两个来源：

    来源 什么时候发生 概率
    类别 1 被判错 真实是 \(\omega_1\)，但 \(x \in R_2\) \(P(\omega_1)\displaystyle\int_{R_2} p(x \mid \omega_1)\,dx\)
    类别 2 被判错 真实是 \(\omega_2\)，但 \(x \in R_1\) \(P(\omega_2)\displaystyle\int_{R_1} p(x \mid \omega_2)\,dx\)

    所以平均错误率的显式公式是两项之和：

    \[\boxed{\;P(\text{error}) = P(\omega_1)\int_{R_2} p(x \mid \omega_1)\,dx + P(\omega_2)\int_{R_1} p(x \mid \omega_2)\,dx\;}\]

    逐项读这个公式（很重要）：

    部分 含义 为什么这么写
    \(P(\omega_1)\) 类别 1 的先验 先要有「真实的类是 1」这个前提
    \(\int_{R_2} p(x \mid \omega_1)\,dx\) 在类 1 内部，\(x\) 落在错误区域的概率 条件概率：给定类 1，\(x\) 跑到 \(R_2\) 去了
    两者相乘 「是类 1」且「\(x\) 落在 \(R_2\)」的联合概率 乘法法则 ✓

    注意积分限的方向： 第二项积分在 \(R_1\) 上（判 \(\omega_2\) 的区域不是它，所以错）， 容易写反，务必对照上表核对 ⚠

    5.2 和「重叠面积」的关系¶

    有一个更简洁的等价写法。因为 \(R_1\) 与 \(R_2\) 互补，所以

    \[P(\omega_1)\int_{R_2} p(x\mid\omega_1)dx = P(\omega_1) - P(\omega_1)\int_{R_1} p(x\mid\omega_1)dx\]

    从这里开始，把它推成「重叠面积」的形式。 分四步，每步只做一件事。

    第一步：把上面 5.1 的两项之和抄下来。

    \[P(\text{error}) = P(\omega_1)\int_{R_2} p(x\mid\omega_1)\,dx + P(\omega_2)\int_{R_1} p(x\mid\omega_2)\,dx\]

    第二步：用「补区域」改写第一项 （依据：\(R_1\) 与 \(R_2\) 互补，密度在整条轴上的积分为 \(1\)）：

    \[= \left[P(\omega_1) - P(\omega_1)\int_{R_1} p(x\mid\omega_1)\,dx\right] + P(\omega_2)\int_{R_1} p(x\mid\omega_2)\,dx\]

    第三步：代入 \(P(\omega_1) = 1 - P(\omega_2)\)，把常数项单独提出来 （依据：先验之和为 \(1\)）：

    \[= 1 - \left[P(\omega_2) + P(\omega_1)\int_{R_1} p(x\mid\omega_1)\,dx - P(\omega_2)\int_{R_1} p(x\mid\omega_2)\,dx\right]\]

    第四步：把孤零零的 \(P(\omega_2)\) 写成「整条轴上的积分」再拆开。 依据：\(P(\omega_2)\displaystyle\int_{-\infty}^{\infty} p(x\mid\omega_2)\,dx = P(\omega_2)\)， 而实轴被 \(R_1\) 与 \(R_2\) 分成两段，所以可以按区域拆开、各归各位：

    \[= 1 - \left[\int_{R_1} P(\omega_2)p(x\mid\omega_2)\,dx + P(\omega_1)\int_{R_1} p(x\mid\omega_1)\,dx + \int_{R_2} P(\omega_2)p(x\mid\omega_2)\,dx\right]\]

    现在看方括号里的三项，用一条「谁更小」的观察收口： \(R_1\) 是判 \(\omega_1\) 的区域，而在 \(R_1\) 上按定义有 \(P(\omega_2)p(x\mid\omega_2) \leq P(\omega_1)p(x\mid\omega_1)\) —— 所以第一项取到的正是两条加权密度里较小的那条； 同理，第二项在 \(R_1\) 上取到的反而是较大的那条。

    于是方括号里剩下的有效内容，就是「在每一点取较小者」在全轴上的积分 （依据：\(1\) 减去「两路加权密度在全轴上的总和」， 恰好只剩下「较低那条曲线下方的面积」）：

    \[\boxed{\;P(\text{error}) = \int \min\big[\,p(x\mid\omega_1)P(\omega_1),\; p(x\mid\omega_2)P(\omega_2)\,\big]\,dx\;}\]

    这个结论说明什么：错误率不需要「先划区域、再分别积分」， 它本身就是两条加权密度曲线的重叠量 —— 判决边界怎么定，只决定在哪个点把「取 min」的开关拨过去， 并不改变错误率的定义式

    先把这个结论画出来。 阴影部分就是错误率 —— 两条加权密度曲线里较低的那条下方的总面积：

    5.3 用标准正态分布函数手算¶

    上面的公式虽然清楚，但要算积分。 在高斯情形下，积分有现成的表达 —— 用标准正态累积分布函数 \(\Phi\)。

    先做标准化。对于正态分布，\(x \sim \mathcal{N}(\mu, \sigma^2)\) 时，

    \[\int_{t}^{\infty} p(x\mid\omega_i)\,dx = 1 - \Phi\!\left(\frac{t - \mu_i}{\sigma_i}\right), \qquad \int_{-\infty}^{t} p(x\mid\omega_i)\,dx = \Phi\!\left(\frac{t - \mu_i}{\sigma_i}\right)\]

    其中 \(\Phi(z)\) 是标准正态的累积分布函数（查表或由软件给出）。

    所以两类问题的错误率变成

    \[P(\text{error}) = P(\omega_1)\Big[1 - \Phi(z_1)\Big] + P(\omega_2)\,\Phi(z_2), \qquad z_i = \frac{t - \mu_i}{\sigma_i}\]

    这就是「查表就能算」的形式

    5.4 错误率的三个影响因素¶

    因素 变大时错误率 原因
    两类均值距离 \(\lvert \mu_1 - \mu_2 \rvert\) 变小 ✓ 分布拉开，重叠变少
    分布宽度 \(\sigma_i\) 变大 ⚠ 分布变"胖"，重叠变多

    六、判决边界在哪：阈值及其移动规律¶

    这一节把「判决规则」落到一个具体的数上 —— 判决边界 \(t\)。

    6.1 两类判据函数与边界方程¶

    定义两类判据函数（就是两类加权密度之差）：

    \[g(x) = p(x \mid \omega_1)P(\omega_1) - p(x \mid \omega_2)P(\omega_2)\]

    判决规则用 \(g\) 写成一行：

    \[\text{判 } \omega_1 \text{ 当 } g(x) \gt 0; \qquad \text{判 } \omega_2 \text{ 当 } g(x) \lt 0\]

    判决边界就是 \(g\) 改变符号的地方：

    \[g(x) = 0 \quad \Longleftrightarrow \quad p(x\mid\omega_1)P(\omega_1) = p(x\mid\omega_2)P(\omega_2)\]

    这个方程的意思是：在边界上，两条加权密度曲线等高 （这与 4.2 节的图一致 —— 两条曲线相交的那一点就是边界）

    一类时可以直接推广（第八节会用）：

    \[g_i(x) = p(x\mid\omega_i)P(\omega_i) \quad \text{选最大的}\]

    先用手算在 \(t\) 附近取两点，验证 \(g\) 变号。 取 \(x = 19.0\) 与 \(x = 20.0\)：

    第一步：\(x = 19.0\) 的两个加权密度。 由 1.6 节的手算表，两个似然是 \(0.054670\) 与 \(0.075284\)，所以

    \[g(19.0) = 0.054670 \times 0.6 - 0.075284 \times 0.4 = 0.032802 - 0.030114 = +0.002688 \gt 0\]

    正号 ⇒ 判 \(\omega_1\) ✓

    第二步：\(x = 20.0\) 的两个加权密度。 同样由手算表，似然是 \(0.033229\) 与 \(0.088017\)：

    \[g(20.0) = 0.033229 \times 0.6 - 0.088017 \times 0.4 = 0.019938 - 0.035207 = -0.015269 \lt 0\]

    负号 ⇒ 判 \(\omega_2\)

    第三步：由介值定理得结论。 \(g\) 是连续函数，在 \(x = 19.0\) 为正、\(x = 20.0\) 为负， 所以区间 \((19.0,\; 20.0)\) 内至少有一个零点 —— 这就是判决边界所在的位置

    这个手算说明什么：不需要任何工具就能把边界夹在两数之间。 想要更精确的值，把区间对半再算一次即可 —— 这正是下一节二分法的手工版本

    6.2 二分法：把边界算成一个数¶

    边界方程 \(g(x) = 0\) 一般没有解析解（本页的参数方差不等， 所以方程不是简单的线性式）。实用做法是数值求解。

    为什么可以放心用二分法：在本页参数下， \(g\) 在边界两侧符号相反：

    位置 \(g\) 的符号 判决
    \(x = 18\) \(+2.42 \times 10^{-2}\) 判 \(\omega_1\)
    \(x = 21\) \(-2.79 \times 10^{-2}\) 判 \(\omega_2\)

    符号相反 ⇒ 区间 \([18, 21]\) 内必有零点（连续函数的介值定理） 于是可以用二分法逼近。

    二分法的手工版本：算四次就能精确到小数点后两位

    二分法的每一步只做三件事：取中点 → 代入 \(g\) → 看符号换区间。 下面前四次迭代全部手算（用 1.6 节的似然值）：

    迭代 区间 \((a,b)\) 中点 \(m\) \(g(m)\) 的符号 下一步保留
    1 \((18,\; 21)\) \(19.5\) 负 \((18,\; 19.5)\)
    2 \((18,\; 19.5)\) \(18.75\) 正 \((18.75,\; 19.5)\)
    3 \((18.75,\; 19.5)\) \(19.125\) 正 \((19.125,\; 19.5)\)
    4 \((19.125,\; 19.5)\) \(19.3125\) 负 \((19.125,\; 19.3125)\)

    每次中点都可以手算到底，例如第 3 次迭代的 \(m = 19.125\)：

    \[p(19.125\mid\omega_1) \approx 0.051671, \qquad p(19.125\mid\omega_2) \approx 0.077032\]
    \[g(19.125) \approx 0.051671 \times 0.6 - 0.077032 \times 0.4 = 0.031002 - 0.030813 = +0.000190 \gt 0\]

    符号为正，所以保留右半区间 \((19.125,\; 19.5)\) 注意这个 \(g\) 值已经相当小 —— 说明 \(19.125\) 离边界已经很近了， 与最终结果 \(19.1346\) 只差 \(0.0096\)

    四次之后区间长度已从 \(3\) 缩到 \(0.1875\)， 再迭代十几次就落到 \(19.1346\) 每迭代一次精度翻倍，这就是二分法可靠的原因 —— 它不依赖任何导数信息，只要符号能判就行

    但要注意：二分法只保证收敛到某个零点。 本页有两个零点（\(19.13\) 与 \(-7.13\)）， 所以初始区间必须选在目标零点附近， 否则可能收敛到远端的那个交点

    二分法有三个前提，缺一个就出错

    前提 本页为什么满足 不满足会怎样
    函数连续 两个高斯密度都连续，差也连续 ✓ 可能跳过间断点，找到的「根」没有意义 ⚠
    区间两端异号 \(g(18) \gt 0\)、\(g(21) \lt 0\) ✓ 区间内不一定有根，迭代会停在假位置 ⚠
    已知零点个数 本页有两个（\(19.13\) 与 \(-7.13\)）⚠ 收敛到哪个根不确定

    第三条最容易被忽视：二分法不会告诉你「有几个根」， 它只会给你一个。所以正确顺序是 先扫描找出全部符号变化点 → 再对每个区间二分

from scipy.stats import norm

mu1, s1, prior1 = 15.0, 3.0, 0.6
mu2, s2, prior2 = 22.0, 4.0, 0.4

def g(x):
    """两类判据函数：g(x) > 0 判 w1，g(x) < 0 判 w2。"""
    return norm.pdf(x, mu1, s1) * prior1 - norm.pdf(x, mu2, s2) * prior2

def bisect(f, a, b, n=200):
    """二分法求 f(x)=0 的根。要求 f(a) 与 f(b) 异号。"""
    fa = f(a)
    if fa * f(b) > 0:
        raise ValueError("区间两端同号，无法二分")
    for _ in range(n):
        m = (a + b) / 2.0
        fm = f(m)
        if fa * fm < 0:
            b = m            # 根在 [a, m]
        else:
            a, fa = m, fm    # 根在 [m, b]
    return (a + b) / 2.0

    6.3 阈值的位置：不是均值中点¶

    一个常见误解：以为判决边界就在两类均值的中点。

    不是。 本页参数下：

    量 值
    两类均值中点 \((15 + 22)/2 = 18.5\)
    实际主边界 \(\mathbf{19.1346}\)
    偏移 \(+0.6346\)（偏向上方，即偏\(\omega_2\)）

    为什么不在中点：因为边界方程

    \[p(x\mid\omega_1)P(\omega_1) = p(x\mid\omega_2)P(\omega_2)\]

    里除了密度还有先验。两个先验不相等（\(0.6\) 与 \(0.4\)）， 就必然把边界推离中点

    6.4 三种情形下的移动规律¶

    这一小节回答「边界往哪边移」。分三种情形，每种都给出可以验证的结论。

    情形一：方差相等（\(\sigma_1 = \sigma_2 = \sigma\)）

    这时边界有闭式解。推导（从对数形式出发，取 \(\sigma\) 相同）：

    \[\ln p(x\mid\omega_1) + \ln P(\omega_1) = \ln p(x\mid\omega_2) + \ln P(\omega_2)\]

    代入正态密度、两边约掉相同的 \(-\ln(\sigma\sqrt{2\pi})\)：

    \[-\frac{(x-\mu_1)^2}{2\sigma^2} + \ln P(\omega_1) = -\frac{(x-\mu_2)^2}{2\sigma^2} + \ln P(\omega_2)\]

    把两项移到同侧、两边乘 \(2\sigma^2\)：

    \[(x-\mu_2)^2 - (x-\mu_1)^2 = 2\sigma^2 \ln\frac{P(\omega_1)}{P(\omega_2)}\]

    左边展开（这是一个关键的代数化简，逐步写）：

    \[(x-\mu_2)^2 - (x-\mu_1)^2 = \left[x^2 - 2\mu_2 x + \mu_2^2\right] - \left[x^2 - 2\mu_1 x + \mu_1^2\right]\]

    \(x^2\) 抵消：

    \[= -2\mu_2 x + 2\mu_1 x + \mu_2^2 - \mu_1^2 = 2(\mu_1 - \mu_2)x + (\mu_2 - \mu_1)(\mu_2 + \mu_1)\]

    提出公因子 \((\mu_1 - \mu_2)\)：

    \[= (\mu_1 - \mu_2)\Big[2x - (\mu_1 + \mu_2)\Big]\]

    代回：

    \[(\mu_1 - \mu_2)\Big[2x - (\mu_1 + \mu_2)\Big] = 2\sigma^2 \ln\frac{P(\omega_1)}{P(\omega_2)}\]

    记 \(\Delta = \mu_2 - \mu_1 \gt 0\)，则 \(\mu_1 - \mu_2 = -\Delta\)：

    \[-\Delta\Big[2x - (\mu_1 + \mu_2)\Big] = 2\sigma^2 \ln\frac{P(\omega_1)}{P(\omega_2)}\]
    \[2x - (\mu_1 + \mu_2) = -\frac{2\sigma^2}{\Delta}\ln\frac{P(\omega_1)}{P(\omega_2)} = \frac{2\sigma^2}{\Delta}\ln\frac{P(\omega_2)}{P(\omega_1)}\]

    得到闭式解：

    \[\boxed{\;t = \frac{\mu_1 + \mu_2}{2} + \frac{\sigma^2}{\mu_2 - \mu_1}\ln\frac{P(\omega_1)}{P(\omega_2)}\;}\]

    逐项读这个式子：

    部分 含义
    \(\dfrac{\mu_1 + \mu_2}{2}\) 均值中点 —— 先验相等时边界就在这
    \(\dfrac{\sigma^2}{\mu_2-\mu_1}\ln\dfrac{P(\omega_1)}{P(\omega_2)}\) 先验带来的偏移量 ✓

    偏移的规律：

    先验关系 \(\ln\frac{P(\omega_1)}{P(\omega_2)}\) 偏移方向
    \(P(\omega_1) = P(\omega_2)\) \(0\) 偏移为 0（就在中点）✓
    \(P(\omega_1) \gt P(\omega_2)\) \(+\) 向上移（朝 \(\omega_2\)）
    \(P(\omega_1) \lt P(\omega_2)\) \(-\) 向下移（朝 \(\omega_1\)）

    所以规律是：

    边界向「先验较小」的那一类移动。 等价地说：先验大的那一类，拿到的判决区域更大 ✓

    这条规律很直观：\(\omega_1\) 本来就常见， 所以证据稍微不利也判它 —— 于是给它的区域更宽。

    情形二：均值相等、方差不等（\(\mu_1 = \mu_2 = \mu\)，\(\sigma_1 \neq \sigma_2\)）

    这是最能看清「方差如何影响边界」的设定。 设先验相等（否则两件事混在一起，看不清谁在起作用）。

    边界方程（取对数、约掉相同的 \(\ln P\)）：

    \[-\ln\sigma_1 - \frac{(x-\mu)^2}{2\sigma_1^2} = -\ln\sigma_2 - \frac{(x-\mu)^2}{2\sigma_2^2}\]

    移项、记 \(u = x - \mu\)：

    \[\ln\frac{\sigma_2}{\sigma_1} = u^2\left(\frac{1}{2\sigma_1^2} - \frac{1}{2\sigma_2^2}\right)\]

    解出 \(u\)（要求 \(\sigma_1 \neq \sigma_2\)，右边括号不为零）：

    \[u^2 = \frac{2\ln(\sigma_2/\sigma_1)}{\dfrac{1}{\sigma_1^2} - \dfrac{1}{\sigma_2^2}}\]

    因为 \(u^2\) 是正的，而 \(\ln(\sigma_2/\sigma_1)\) 与括号同号， 所以这个式子自洽。得到两个对称的边界：

    \[x = \mu \pm u, \qquad u = \sqrt{\frac{2\ln(\sigma_2/\sigma_1)}{\dfrac{1}{\sigma_1^2} - \dfrac{1}{\sigma_2^2}}}\]

    结论（这是本小节要记住的）：

    均值相同时，方差较小的类只在均值附近的一个「口袋」里获胜， 方差较大的类赢得两侧。

    所以判决边界被「推离」方差大的类， 让方差大的类拿到更大的判决区域 ✓

    情形二最值得手算一遍，因为它是「方差如何影响边界」的纯粹版本。 把均值都取 \(20\)、先验都取 \(0.5\)，只让两个标准差不同：

    \[-\ln\sigma_1 - \frac{(x-20)^2}{2\sigma_1^2} = -\ln\sigma_2 - \frac{(x-20)^2}{2\sigma_2^2}\]

    第二步：移项，把带 \((x-20)^2\) 的项放一边。

    \[\ln\frac{\sigma_2}{\sigma_1} = \frac{(x-20)^2}{2}\left(\frac{1}{\sigma_1^2} - \frac{1}{\sigma_2^2}\right)\]

    第三步：解出 \((x-20)^2\)（要求 \(\sigma_1 \neq \sigma_2\)，否则括号为零）。

    \[(x-20)^2 = \frac{2\ln(\sigma_2/\sigma_1)}{\dfrac{1}{\sigma_1^2} - \dfrac{1}{\sigma_2^2}}\]

    七、数值路线的相互印证¶

    前面几节的结论，到这里换一条完全不同的路子再走一遍。 这一节要说明的是：同一个数，用不同方法算出来必须一样 —— 不一致就说明某一步错了 ✓

    7.1 扫描法：先看判决在哪一步翻转¶

    这次扫描全部可以手算。 只要每隔 \(0.1\) 算一次两个加权密度， 就能看到判决在哪一步翻转。下面是有代表性的几点：

    八、换个视角：0-1 损失下的条件风险¶

    最后把这一页的结论，放到下一节（最小风险决策）的框架里看一遍， 这样两节就能连起来。

    定义损失：判决的「代价」。0-1 损失的意思是

    情况 损失
    判对 \(0\)
    判错 \(1\)

    写成矩阵（\(\lambda_{ij}\) = 判决为 \(\omega_i\) 而真实类别是 \(\omega_j\) 的损失）：

    \[\Lambda = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}\]

    条件风险（判为 \(\omega_i\) 的期望损失）：

    \[R(\omega_i \mid x) = \sum_{j} \lambda_{ij} P(\omega_j \mid x)\]

    代入 0-1 损失：

    \[R(\omega_1 \mid x) = 0 \cdot P(\omega_1\mid x) + 1 \cdot P(\omega_2\mid x) = P(\omega_2 \mid x)\]
    \[R(\omega_2 \mid x) = 1 \cdot P(\omega_1\mid x) + 0 \cdot P(\omega_2\mid x) = P(\omega_1 \mid x)\]

    所以条件风险恰好就是「另一类的后验」 —— 这正是 1.3 节的条件错误率

    \[\arg\min_i R(\omega_i \mid x) = \arg\max_i P(\omega_i \mid x)\]

    正确的推理链：

    先验相等时，分子 \(p(x\mid\omega_i)P(\omega_i)\) 中两个 \(P\) 相同， 可以约掉，这时只比似然是对的 —— 这正是 最大似然（ML）判决 的适用条件

    \(x\) \(19.0\)

    Q4 解释：为什么贝叶斯错误率不能为 0？ 在什么条件下它可以接近 0？用数值例子说明。

    提示

    想想重叠区的来源。两类的均值差与标准差之比的增大，会让重叠区怎样变化？

    解答

    为什么不能为 0：重叠区必然存在。

    只要两类都是连续分布、且支撑集有交集，就存在一段 \(x\) 使两类都有非零的概率密度。 在这样一段上，无论判哪一类， 另一类都有一部分概率质量落在那里 —— 必然产生错误

    什么条件下能接近 0：让重叠区变小。

    重叠区的"大小"由两类均值的距离相对于标准差决定。 具体地，等方差、等先验的情形下有一条现成公式：

    \[P(\text{error}) = \Phi\!\left(-\frac{\lvert\mu_1-\mu_2\rvert}{2\sigma}\right)\]

    看这个公式：

    改变什么 效果
    增大均值距离 \(\lvert\mu_1-\mu_2\rvert\) \(-\frac{\Delta}{2\sigma}\) 变小（更负），\(\Phi\) 更小 → 错误率下降 ✓
    减小标准差 \(\sigma\) 同上 → 错误率下降 ✓
    两者之比 \(\frac{\Delta}{\sigma} \to \infty\) \(\Phi(-\infty) \to 0\) → 错误率趋近 0 ✓

    数值验证（固定均值 \(18\) 与 \(22\)，只改标准差）：

    \(\sigma\) \(\dfrac{\Delta}{2\sigma}\) 查表量 \(1-\Phi\!\left(\dfrac{\Delta}{2\sigma}\right)\) 错误率 相对上一行
    \(4.0\) \(0.50\) \(0.3085\) \(0.308538\) —
    \(3.0\) \(0.67\) \(0.2514\) \(0.252493\) 降 \(0.056\)
    \(2.0\) \(1.00\) \(0.1587\) \(0.158655\) 降 \(0.094\) ✓
    \(1.5\) \(1.33\) \(0.0918\) \(0.091211\) 降 \(0.067\)
    \(1.0\) \(2.00\) \(0.0228\) \(0.022750\) 降 \(0.068\)
    \(0.5\) \(4.00\) \(3.17\times 10^{-5}\) \(3.17\times 10^{-5}\) 降 \(0.023\) ✓

    注意这里的查表方向：错误率是 \(\Phi(-\Delta/2\sigma)\)， 用对称性写成 \(1 - \Phi(\Delta/2\sigma)\) 之后， 查的都是正值行 —— 标准正态表里一般也不印负值行

    从 \(\sigma=4\) 到 \(\sigma=1\)，错误率从 \(30.9\%\) 降到 \(2.3\%\) 但始终大于 0。

    这张表还说明一件事：收益是递减的。 \(\sigma\) 从 \(4\) 减到 \(3\)（比值降到 \(0.75\) 倍），错误率降了 \(0.056\)； 从 \(2\) 减到 \(1.5\)（同样降到 \(0.75\) 倍），只降 \(0.067\)； 从 \(1\) 减到 \(0.5\) 只降 \(0.023\) —— 越接近 \(0\)，想再降一点点就越贵

    这正是「贝叶斯错误率是下界」的实践含义： 错误率已经贴着这条下限走时，继续在模型上投入只会白费力气

    实践含义： 要降低错误率，只有三条路： 实践含义： 要降低错误率，只有三条路：

    途径 说明
    提取更有判别力的特征（拉大 \(\Delta\)） 最根本的办法 ✓
    降低类内方差 \(\sigma\)（如提高测量精度） 有效但受物理限制
    换更好的分类器 只能逼近贝叶斯错误率，不能低于它 ⚠

    第三条最值得注意：它是「贝叶斯错误率是下界」的直接推论 —— 如果错误率已经接近贝叶斯错误率，继续调模型收益极小， 该做的是改特征或改数据

    注意最后一行：\(\sigma = 0.5\) 时错误率降到约 \(3\times10^{-5}\)， 已经非常接近 0，但仍然不是 0 —— 因为两条高斯曲线在数学上永远有重叠 ✓

    小结¶

    要记住的 为什么
    判决规则：判后验最大的类 等价于判「条件错误率最小」的类
    四种等价形式：比后验 / 比似然×先验 / 比似然比 / 比对数和 判决结果相同，用途不同；似然×先验最常用 ✓
    似然比形式：\(L(x) \gt P(\omega_2)/P(\omega_1)\) 把「证据强度」与「先验门槛」分开，便于分析
    先验相等时退化为最大似然（ML）判决 先验可约掉；先验不等时不可只比似然 ⚠
    平均错误率 \(= \int P(\text{error}\mid x)\,p(x)\,dx\) 权重 \(p(x) \geq 0\) 是证明的全部依据
    逐点最优 ⟹ 整体最优 因为积分是「非负加权求和」；偏离最优则错误率严格更大 ✓
    两种算法等价：区域分解 与 重叠面积 \(\int\min(\cdot)\) 数值验证一致
    高斯情形可查表：\(P(\omega_1)[1-\Phi(z_1)] + P(\omega_2)\Phi(z_2)\) 其中 \(z_i = (t-\mu_i)/\sigma_i\)
    贝叶斯错误率是不可逾越的下界 但它以「真实分布已知」为前提 ⚠
    错误率不为 0 是因为存在重叠区 重叠区里两类样本混在一起
    降低错误率只有三条路：拉大均值距离、降低类内方差、换更好的分类器 第三条只能逼近下界，不能低于 ✓
    等方差时边界有闭式解 \(t = \frac{\mu_1+\mu_2}{2} + \frac{\sigma^2}{\mu_2-\mu_1}\ln\frac{P_1}{P_2}\) 先验相等则边界就在中点
    边界朝先验小的类移动（先验大的类区域更大） 本页数值：\(18.5 \to 19.0213\)（\(\sigma\) 相同时）✓
    方差不等时判决区域可能不止一段 本页参数下第一类的区域是 \((-7.13,\,19.13)\) ⚠
    判决边界常需数值求解（二分法） 方差不等时一般无闭式解；结果须代回检验 ✓
    0-1 损失下，最小风险 = 最大后验 说明最小错误率决策是最小风险决策的特例 ✓
    边界附近错一点不要紧，判反了才致命 \(t\) 偏离 \(0.13\) 只多错 \(0.00018\)；偏离 \(4.1\) 多错 \(0.54\) ✓
    多类判决不能只看「离哪个均值近」 要比标准化距离（\(x = 24\) 那个例子）⚠
    错误率的通用上界是 \(1/2\) 抛硬币的期望错误率就是 \(1/2\)，贝叶斯规则不会更差 ✓
