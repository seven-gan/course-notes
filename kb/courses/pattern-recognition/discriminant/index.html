    判别函数与决策面¶

    这一页解决一个问题：怎么把「比较后验概率」这件事， 重新写成「几个函数比大小」？

    上一页得到了最小风险判决规则：算出各类的后验概率，挑最大的那一类。 规则本身没错，但照着它一步步硬算，会遇到两个麻烦：

    看起来差不多 实际差别 后果
    每次都算后验概率 后验的分母是全概率，要对所有类求和 类别一多，每个样本都多算一大圈
    概率值本身 多维密度是连乘，每一维都小于 1 维数一高就数值下溢成 0，比大小彻底失效
    判决只关心「谁最大」 完全不需要知道最大值究竟是多少 说明存在大量互相等价的写法

    把这两件事想通，就会自然地引出这一页的主角 —— 判别函数。 它把「谁的几率大」抽象成「谁的函数值大」， 让判决规则从「算概率」变成「比大小」， 也顺带解释了为什么同一件事可以有那么多看起来不一样的公式。

    这一页还顺路补上两个下一节必需的地基： 多元正态密度公式，以及马氏距离。

    这一页的核心问题

    整页只围绕一句话展开：

    判决只依赖判别函数之间的「序」，不依赖它们的「值」。

    由此推出三件事：

    推论 说明
    判别函数可以随便换形式 只要保证各类之间的大小关系不变
    判决面可以只看差 两类时把两个判别函数相减，只看正负号
    决策面与数值无关 决策面就是「差等于 0」的那张等值面

    一、为什么需要「判别函数」这个概念¶

    1.1 先回头看判决规则本身¶

    前几页得到的最小风险判决规则，用后验概率写成：

    \[\text{判 } \omega_i \quad \text{当} \quad P(\omega_i \mid x) \gt P(\omega_j \mid x) \quad \text{对所有 } j \neq i\]

    先把符号定义清楚：

    符号 含义 取值范围
    \(c\) 类别总数 正整数
    \(\omega_1, \dots, \omega_c\) 各个类别 —
    \(x\) 观测到的特征向量，\(d\) 维 \(x \in \mathbb{R}^d\)
    \(P(\omega_i \mid x)\) 看到 \(x\) 后它属于第 \(i\) 类的后验概率 \([0,1]\)

    怎么读这个规则：把 \(c\) 个后验概率都算出来，谁最大就判谁。 「对所有 \(j \neq i\) 都成立」这句话的意思是， 这个最大值必须严格大于其余每一个（不能有并列）。

    1.2 麻烦一：分母是公共的，但每次都要算¶

    把贝叶斯公式代进去：

    \[P(\omega_i \mid x) = \frac{p(x \mid \omega_i)\,P(\omega_i)}{p(x)}, \qquad p(x) = \sum_{j=1}^{c} p(x \mid \omega_j)\,P(\omega_j)\]

    分母 \(p(x)\) 与 \(i\) 无关 —— 它是「不管属于哪一类，观测到 \(x\) 的总概率」， 所以 \(c\) 个后验概率用的是同一个分母。

    \[\begin{aligned} \text{判 } \omega_i &\iff \frac{p(x \mid \omega_i)P(\omega_i)}{p(x)} \gt \frac{p(x \mid \omega_j)P(\omega_j)}{p(x)} \quad \forall j \neq i \\ &\iff p(x \mid \omega_i)P(\omega_i) \gt p(x \mid \omega_j)P(\omega_j) \quad \forall j \neq i \end{aligned}\]

    这一步是怎么消掉的：两边同乘 \(p(x)\)。 \(p(x)\) 是一个正数（密度值为正），乘一个正数不会改变不等号方向 ✓

    结论：分母根本不用算。 只有「需要报告一个具体的概率值」时，才需要回头除以 \(p(x)\)。

    1.3 麻烦二：连乘会下溢，这是真正要命的地方¶

    如果 \(d\) 个特征相互独立，那么 \(d\) 维的类条件密度可以拆成 \(d\) 个一维密度相乘：

    \[p(x \mid \omega_i) = \prod_{k=1}^{d} p(x_k \mid \omega_i)\]

    每一个一维密度通常在 \(0.01\) 到 \(1\) 这个量级。乘 \(d\) 次就指数级变小：

    维数 \(d\) 每维取 \(0.1\) 时的连乘结果 是否还能用浮点数表示
    \(d = 50\) \(10^{-50}\) 能，双精度最小约 \(10^{-308}\)
    \(d = 200\) \(10^{-200}\) 勉强能
    \(d = 320\) \(10^{-320}\) 超出下限，已经失真
    \(d = 400\) \(10^{-400}\) 直接变成 0

    只要变成 0，所有类的判别函数值就都是 0， 「谁大谁小」的信息全部丢失，判决直接失效 ⚠

    办法 做法 为什么可行
    去掉分母 只比较 \(p(x\mid\omega_i)P(\omega_i)\) 除以同一个正数不改变大小关系
    取对数 比较 \(\ln p(x\mid\omega_i) + \ln P(\omega_i)\) 对数函数单调增，不改变大小关系

    取对数有一个前提：函数值必须是正数

    \(\ln\) 只在正数上有定义。\(p(x\mid\omega_i)\) 是密度，恒为正， \(P(\omega_i)\) 也恒为正（除非某一类的先验恰好是 0）， 所以取对数在数学上是安全的。

    但如果你手里那个「判别函数」的值可能是负数或零， 就不能对它取对数。此时可以改取 \(\ln(\cdot + C)\) 这种平移形式， 只要 \(C\) 足够大使全体为正 —— 平移不改变大小关系 ✓

    1.4 关键洞察：判决只需要「序」¶

    把 1.2 和 1.3 两件事合起来看，会发现一个共同点：

    操作 做的事 为什么不影响判决
    除以 \(p(x)\) 所有类除以同一个正数 不等式两边同除正数，方向不变
    取对数 所有类过同一个单调增函数 单调增函数保序
    乘一个正常数 \(a \gt 0\) 所有类扩大同一倍数 不等式两边同乘正数，方向不变
    加一个正常数 \(b\) 所有类平移同一个量 比较的是差，平移会抵消

    这四种操作都用一个词概括：保序变换。 只要对所有类施加同一个保序变换， 「谁最大」这个结论就完全不变 ✓

    于是可以彻底换个说法： 我们不需要那个具体是概率的函数， 只需要一个能在各类之间保持同样先后次序的函数。 这样的函数就叫判别函数。

    二、判别函数的定义与「不唯一」¶

    2.1 正式定义¶

    定义（判别函数）：一组函数

    \[g_1(x),\; g_2(x),\; \dots,\; g_c(x)\]

    如果对某个 \(x\)，有

    \[g_i(x) \gt g_j(x) \qquad \text{对所有 } j \neq i\]

    就把 \(x\) 判归 \(\omega_i\) 类。

    怎么读这个定义：这里完全不出现概率。 \(g_i\) 可以是任何实值函数， 唯一的用处就是给每个类「打一个分」， 然后拿最高的那个分对应的类当答案。

    把分类器看成一台机器（这是本节最直观的一幅图）：

    机器部件 作用
    输入端 接收 \(d\) 个特征值 \(x_1, x_2, \dots, x_d\)
    中间层 并行算出 \(c\) 个判别函数值 \(g_1(x), \dots, g_c(x)\)
    输出端 一个最大值选择器，输出最大值对应的类别标号

    也就是说：分类器 = \(c\) 个判别函数 + 一个取最大值的操作。 后面看到线性分类器、二次分类器、神经网络， 区别只在于中间的 \(g_i\) 长什么样 ✓

    2.2 判别函数不唯一 ⚠¶

    这是本节最容易被忽略、但最重要的一条性质。

    性质（判别函数的不唯一性）： 设 \(g_1(x), \dots, g_c(x)\) 是一组判别函数， \(\varphi\) 是任意一个严格单调增的函数，则

    \[\tilde g_i(x) = \varphi\bigl(g_i(x)\bigr), \qquad i = 1, 2, \dots, c\]

    也是一组合法判别函数，而且两组的判决结果完全相同。

    证明（两行，不跳步）：

    设有 \(g_i(x) \gt g_j(x)\)。 因为 \(\varphi\) 严格单调增，两边同时过 \(\varphi\) 得

    \[\varphi\bigl(g_i(x)\bigr) \gt \varphi\bigl(g_j(x)\bigr) \quad\Longrightarrow\quad \tilde g_i(x) \gt \tilde g_j(x)\]

    反过来，由 \(\tilde g_i(x) \gt \tilde g_j(x)\) 也是同理反推回 \(g_i(x) \gt g_j(x)\)。 两个方向都成立，说明大小关系一一对应， 所以「最大值是谁」不会变 ✓

    三条红线：这样做会改变判决

    上面说的是「对所有类施加同一个保序变换」。 下面三种做法都会破坏判决：

    错误做法 为什么错 例子（直观）
    乘一个负数 不等号方向全部翻转 \(g = (1, 2)\) 乘 \(-1\) 得 \((-1,-2)\)，最大者从第 2 个变成第 1 个
    对不同的类用不同的变换 类与类之间的可比性被破坏 第 1 类乘 \(100\)，第 2 类不变，比较已经无意义
    加不同的常数到各类 相当于人为给某些类加分 第 1 类加 \(5\)，第 2 类加 \(0\) → 判决整体偏向第 1 类

    特别注意第二条：\(\tilde g_i = \varphi_i(g_i)\) 里下标 \(i\) 是跟着类走的， 这不是保序变换，判决通常会变 ✗

    2.3 一般形式¶

    课件里还给出了一个更一般的写法：

    \[g_i(x) = f\bigl(p(x \mid \omega_i)\bigr) + h(x, \omega_i)\]

    符号说明：

    符号 含义 要求
    \(f(\cdot)\) 对密度的变换（如取对数） 必须是单调增的
    \(h(x, \omega_i)\) 附加项 只能含与类别有关或与 \(x\) 有关的合法组合

    怎么读懂它：\(f\) 负责把「连乘」变成「相加」（解决下溢）， \(h\) 负责塞进先验概率这类「与类别有关」的信息。

    注意 \(h(x, \omega_i)\) 里 \(x\) 的位置： 如果 \(h\) 中含有一项与类别无关的 \(h_0(x)\)，那么它对所有类都一样， 在做差时会自动消掉 —— 这正是下面第四节「决策面方程」能化简的根源 ✓

    三、从后验导出的三个等价判别函数¶

    现在按由「精确」到「好用」的顺序，逐个写出三个判别函数， 并说明它们判决结果完全一致。

    3.1 形式一：直接用后验概率¶

    \[g_i(x) = P(\omega_i \mid x), \qquad i = 1, 2, \dots, c\]

    这是最「标准」的一组 —— 它的值有明确含义（就是概率）， 范围在 \([0,1]\)，\(c\) 个值加起来正好是 1。

    优点：可解释性最强，能直接回答「有多大的把握」。

    缺点：必须算分母 \(p(x)\)，而 \(p(x)\) 是 \(c\) 项的求和。 类别数 \(c\) 很大时，每个样本都要多算这一圈；

    更麻烦的是：\(c\) 个后验都算出来之后， 其实只用在里面找最大的一个 —— 分母白算了。

    3.2 形式二：去掉分母（最常用）¶

    \[g_i(x) = p(x \mid \omega_i)\,P(\omega_i), \qquad i = 1, 2, \dots, c\]

    怎么从形式一得到它：把贝叶斯公式代进形式一，得到

    \[g_i(x) = \frac{p(x \mid \omega_i)P(\omega_i)}{p(x)}\]

    这里 \(p(x)\) 与 \(i\) 无关，是 \(c\) 个类共用的同一个正数。 除以同一个正数不改变大小关系，于是可以直接把它删掉 ✓

    注意 \(g_i\) 现在不是概率了：它可能大于 1， \(c\) 个值加起来也不再是 1。但这完全不影响判决 —— 判别函数只需要保持序，不需要是概率 ⚠

    这是实际实现里最常用的一组，因为它既省掉了分母， 又避免了取对数带来的额外开销。

    3.3 形式三：取对数（数值最稳）¶

    \[g_i(x) = \ln p(x \mid \omega_i) + \ln P(\omega_i)\]

    怎么从形式二得到它：形式二是一个乘积， 对它整体取对数，乘积就变成求和：

    \[\begin{aligned} \ln\Bigl[p(x\mid\omega_i)\,P(\omega_i)\Bigr] &= \ln p(x\mid\omega_i) + \ln P(\omega_i) \end{aligned}\]

    这里用到了对数的两条基本性质：

    性质 式子 在这里的作用
    乘积的对数 = 对数之和 \(\ln(ab) = \ln a + \ln b\) 把连乘变成连加，解决下溢
    对数函数单调增 \(a \gt b \gt 0 \Rightarrow \ln a \gt \ln b\) 保证大小关系不变

    为什么开发时最偏爱它：\(d\) 维独立时密度是 \(d\) 个数的连乘， 取对数之后变成 \(d\) 个数的加法。 加法不会下溢，而且每一项都可以单独计算、单独检查 ✓

    注意符号方向：\(\ln\) 的值都是负的（因为密度和先验都小于 1）， 所以判别函数值常常见到 \(-3.5\) 这种负数。 这没关系 —— 我们只比大小，\(-3.5 \gt -4.2\) 照样成立 ✓

    四、决策面与决策边界¶

    前面讲的都是「给定一个 \(x\)，怎么判」。 这一节换个视角问一个几何问题：

    特征空间里的点被分成几块？它们之间的分界线长什么样？

    这个问题看起来只是「换个说法」，其实很有用 —— 它让我们能画图、能预判形状、能一眼看出某个分类器的能力上限。

    4.1 决策区域：把特征空间切块¶

    定义（决策区域）：对 \(c\) 类问题， 按判决规则可以把 \(d\) 维特征空间分成 \(c\) 个区域

    \[R_1, R_2, \dots, R_c\]

    其中 \(R_i\) 是「所有会被判为 \(\omega_i\) 的点」组成的集合：

    \[R_i = \bigl\{x \;\big|\; g_i(x) \gt g_j(x) \ \text{对所有} \ j \neq i\bigr\}\]

    怎么读这个定义：\(R_i\) 就是第 \(i\) 类的「地盘」。 任何一个落进 \(R_i\) 的样本都会被判成 \(\omega_i\)。

    两条必须点明的性质：

    性质 说明
    覆盖性 每个点至少属于一个区域（否则判决规则有漏洞）
    互斥性 一个点不会同时落进两个区域，因为「严格大于所有 \(j\neq i\)」最多对一个 \(i\) 成立

    关于等号归哪边：判决规则用的是严格不等号 \(\gt\)， 所以「两个判别函数恰好相等」的点不属于任何区域， 它们正好落在下一段要讲的决策面上。

    实践中的处理：计算机里两个浮点数几乎不会精确相等， 所以这类点实际上由实现的比较顺序决定（先比到的赢）。 要做成确定性的分类器，必须显式规定： 相等时判给下标最小的类，或判给先验最大的类 ✓

    4.2 决策面：区域的边界¶

    定义（决策面 / 决策边界）： 分隔两个相邻决策区域 \(R_i\) 与 \(R_j\) 的点集，称为决策面， 其方程是

    \[g_i(x) = g_j(x)\]

    怎么读这个式子：决策面就是「两个类的判别函数打成平手」的地方。 在这张面上，判成哪一类都说得通，所以它是一条分界线。

    决策面是超曲面：当特征维数是 \(d\) 时， 一个等式约束通常把一个 \(d\) 维空间切出一张 \((d-1)\) 维的面：

    特征维数 \(d\) 决策面的几何形状 若判别函数是线性的
    \(1\) 一些分界点 一个点
    \(2\) 一些曲线（或曲线段） 一条直线
    \(3\) 一些曲面（或曲面片） 一个平面
    \(d\) 一些超曲面（或超曲面片） 一个超平面

    注意「曲线段」这个词：决策面不一定是完整的一条曲线， 它可能被别的类的区域切断，只剩中间一段。 三类以上时这种情况很常见 ✓

    为什么要求「相邻」：如果 \(R_i\) 与 \(R_j\) 根本不相邻， 它们之间隔着第三个类的区域，那么 \(g_i = g_j\) 的点集里 有一部分落在别的区域内部，不构成真正的边界。 所以严格说，决策面是 \(g_i = g_j\) 那个点集里落在两个区域交界处的那一部分 ⚠

    4.3 两类情形：只需要一个判别函数¶

    两类是最常用也最重要的情形。它的特别之处在于： \(c = 2\) 时那两个判别函数 \(g_1, g_2\) 必然一高一低， 所以没有必要分别算两个数再比 —— 直接看差就行。

    定义：

    \[g(x) = g_1(x) - g_2(x)\]

    判决规则：

    \[g(x) \gt 0 \ \Rightarrow\ \text{判为 } \omega_1; \qquad g(x) \lt 0 \ \Rightarrow\ \text{判为 } \omega_2; \qquad g(x) = 0 \ \Rightarrow\ \text{落在决策面上}\]

    怎么读：\(g \gt 0\) 就是 \(g_1 \gt g_2\)，也就是第 1 类赢。 把「比较两个数」变成「看一个数的符号」，实现上更省事 ✓

    把几种常见的 \(g(x)\) 写出来：

    依据 \(g(x)\) 的写法
    后验之差 \(g(x) = P(\omega_1 \mid x) - P(\omega_2 \mid x)\)
    去分母（最常用） \(g(x) = p(x \mid \omega_1)P(\omega_1) - p(x \mid \omega_2)P(\omega_2)\)
    取对数 \(g(x) = \ln\dfrac{p(x\mid\omega_1)}{p(x\mid\omega_2)} + \ln\dfrac{P(\omega_1)}{P(\omega_2)}\)
    风险之差（最小风险时） \(g(x) = R(\alpha_1 \mid x) - R(\alpha_2 \mid x)\)

    注意最后一行：用风险之差时，\(g(x)\) 越小越好 （风险越小越好），所以判决规则变成「\(g(x) \lt 0\) 判 \(\omega_1\)」。 它和前三行符号习惯相反。 这两种习惯在文献里都有人用，看公式时先确认大者判哪一类 ⚠

    4.4 决策面方程：本页的核心¶

    两类的决策面是「两个判别函数相等」的点集：

    \[g_1(x) = g_2(x)\]

    把它移项，就得到著名的决策面方程：

    \[g(x) = g_1(x) - g_2(x) = 0\]

    这两个写法完全等价，只是后者更便于计算。它的含义有三层：

    层次 内容
    代数上 解一个方程，解集就是决策面
    几何上 \(g(x)=0\) 是 \(g\) 的一条零水平集（等值线或等值面）
    实践上 只要 \(g\) 的形式确定了，决策面的形状就确定了

    必须强调的一点：决策面只由「\(g(x) = 0\)」这个方程决定， 与 \(g(x)\) 在别处的具体数值完全无关 ⚠

    为什么能这么说：判别函数的职责只是「比大小」， 换成 \(50g(x)\)、\(g(x)+7\)、\(e^{g(x)}\)（前提还有零点的位置）， 决策区域一个点都不会变。 决策面作为区域的边界，自然也不变。

    但有一处需要小心：「\(g(x)=0\)」这个写法默认了 决策面对应 \(g\) 的零水平集。如果我们手上是原判别函数 \(g_1\) 与 \(g_2\)，而决策面方程写的是 \(g_1 = g_2\)， 这时没有单独的 \(g\)，就不能写成 \(g(x) = 0\)。

    安全写法：先定义差式 \(g = g_1 - g_2\)， 再写 \(g(x) = 0\)。这样零水平集与决策面必然重合 ✓

    「判别函数不唯一」这件事后面会一直用到

    本节给出的三种形式 \(P(\omega_i\mid x)\)、 \(p(x\mid\omega_i)P(\omega_i)\)、\(\ln p + \ln P\) 是同一组东西的三种写法， 它们判决结果完全相同。

    这一点在下一节特别重要：下一节会给出好几种 「看起来完全不一样」的判别函数 （最近距离分类器、线性判别函数、二次判别函数……）， 它们的形式差异极大，甚至有一项在这一种里被整项丢掉。

    丢掉一项为什么还能等价？ 因为被丢掉的那项 与类别下标 \(i\) 无关，对所有类都是同一个值， 比大小时自动抵消 ✓

    所以看到两个判别函数「长得不一样」时， 第一件事是问：差的那一项与类别有关吗？ 与类别无关就是等价的。

    五、从贝叶斯到决策面的完整推导¶

    这一节把线索接起来：从贝叶斯公式出发，一步步导出决策面方程， 中间每一步都写清楚。

    5.1 出发点：两类、取对数的判别函数¶

    两类情形，用 3.3 节的取对数形式：

    \[g_1(x) = \ln p(x \mid \omega_1) + \ln P(\omega_1)\]
    \[g_2(x) = \ln p(x \mid \omega_2) + \ln P(\omega_2)\]

    为什么选这两个：取对数后没有下溢风险， 而且两式相减时结构最清楚。

    5.2 相减：常数项自动合并¶

    按 4.3 节的定义取差：

    \[\begin{aligned} g(x) &= g_1(x) - g_2(x) \\ &= \Bigl[\ln p(x \mid \omega_1) + \ln P(\omega_1)\Bigr] - \Bigl[\ln p(x \mid \omega_2) + \ln P(\omega_2)\Bigr] \end{aligned}\]

    把括号拆开、重新分组：

    \[\begin{aligned} g(x) &= \ln p(x \mid \omega_1) + \ln P(\omega_1) - \ln p(x \mid \omega_2) - \ln P(\omega_2) \\ &= \Bigl[\ln p(x \mid \omega_1) - \ln p(x \mid \omega_2)\Bigr] + \Bigl[\ln P(\omega_1) - \ln P(\omega_2)\Bigr] \end{aligned}\]

    这一步只是把同类项归拢，没有任何近似。

    5.3 把两个括号写成比值¶

    用对数的差等于商的对数：\(\ln a - \ln b = \ln(a/b)\)，得

    \[g(x) = \ln\frac{p(x\mid\omega_1)}{p(x\mid\omega_2)} + \ln\frac{P(\omega_1)}{P(\omega_2)}\]

    这就是课件上那个式子 ✓ 现在逐项读懂它：

    项 名字 作用
    \(\ln\dfrac{p(x\mid\omega_1)}{p(x\mid\omega_2)}\) 似然比的对数 由观测数据决定，随 \(x\) 变化
    \(\ln\dfrac{P(\omega_1)}{P(\omega_2)}\) 先验比的对数 由先验知识决定，是一个常数（与 \(x\) 无关）

    这个分解非常有价值，因为它把「证据」和「偏见」分开了：

    情形 谁主导 结果
    似然比很大（数据强烈偏向第 1 类） 第一项主导 即使先验不利也判第 1 类
    似然比接近 1（数据说不清） 第二项主导 由先验决定，谁先验大判谁
    先验相等 \(P(\omega_1) = P(\omega_2)\) 第二项 = 0 退化成最大似然判决 ✓

    5.4 让 \(g(x) = 0\)：得到决策面方程¶

    令

    \[\ln\frac{p(x\mid\omega_1)}{p(x\mid\omega_2)} + \ln\frac{P(\omega_1)}{P(\omega_2)} = 0\]

    移项。先把第二项移到右边：

    \[\ln\frac{p(x\mid\omega_1)}{p(x\mid\omega_2)} = -\ln\frac{P(\omega_1)}{P(\omega_2)}\]

    再用「负号可以翻进对数里面」这一步：\(-\ln a = \ln(1/a)\)，于是

    \[\ln\frac{p(x\mid\omega_1)}{p(x\mid\omega_2)} = \ln\frac{P(\omega_2)}{P(\omega_1)}\]

    为什么这一步值得单独写：很多人直接把 \(-\ln(P_1/P_2)\) 当成 \(\ln(P_1/P_2)\) 用，最后得到倒过来的决策面 ✗

    两边取指数（\(e\) 的幂函数），消掉对数：

    \[\frac{p(x\mid\omega_1)}{p(x\mid\omega_2)} = \frac{P(\omega_2)}{P(\omega_1)}\]

    这就是决策面的「似然比等于常数」形式 —— 左端是数据给出的似然比，右端是一个不依赖 \(x\) 的常数阈值。

    怎么读：当两个类条件密度的比值恰好等于先验的反比时， 两类的后验正好打平，判决无从下手 —— 这正是决策面上的点 ✓

    把两边同时取倒数，得到另一个常见的等价写法：

    \[\frac{p(x\mid\omega_2)}{p(x\mid\omega_1)} = \frac{P(\omega_1)}{P(\omega_2)}\]

    两种写法等价，看哪种顺眼就用哪种 —— 但不能把分子分母写反，那样得到的是另一条线 ⚠

    5.5 关键一步：只要知道密度形式，就能化简成几何形状¶

    上面那个式子还是「密度之比」这种抽象形式。 要把它变成直线、曲线这样的几何对象，必须把密度的具体形式代进去。

    这是本节最重要的一句话：

    决策面的形状完全由类条件密度的形式决定。 密度形式定了，\(g(x)=0\) 就能化成具体的几何方程。

    类条件密度的假设 决策面的形状
    一维正态，等方差 一个分界点
    多元正态，协方差相同 一张超平面（直线/平面）
    多元正态，协方差不同 一张超二次曲面（抛物面/椭球面/双曲面等）
    非参数（不做分布假设） 形状任意，只能逐点判定

    具体的化简过程属于下一节（高斯密度下的判别函数）， 本节先把「化简是可能的」这件事说清楚： 因为正态密度的对数里只有 \(x\) 的二次项、一次项和常数项， 两类相减时二次项可能消掉、也可能不消掉 —— 这正是上面表格前两行的来源 ✓

    为什么还要专门去求决策面？

    既然有了判别函数就能分类，决策面似乎是多余的 —— 不是。 它至少带来三个好处：

    好处 说明
    直观 一张图能看出分界线在哪、形状如何，比看一堆数字快得多
    便于分析 决策面的形状决定了分类器能表达多复杂的边界（能力上限）
    便于估计参数 有些算法直接估计决策面的参数，不必回头估计密度

    尤其第三点：很多实用算法根本不估计概率密度， 而是直接找一个决策面 —— 这条路叫判别式方法， 和「先估密度再用贝叶斯」这条生成式方法是两条平行的路线 ✓

    六、一元与多元正态分布¶

    决策面最经典的情形就是「各类都服从正态分布」。 这一节把正态密度的公式和符号准备齐，下一节直接拿来用。

    为什么正态分布值得这么重视（三条理由，课件专门列了）：

    理由 说明
    熵最大 在给定均值和方差的所有分布中，正态分布的熵最大
    中心极限定理 大量独立随机变量之和趋近正态分布
    实际吻合 很多实际场景中，类别的特征分布确实接近正态

    第三条是最实用的：如果你只知道均值和方差， 选正态分布是最「不武断」的选择（熵最大意味着最少额外假设）✓

    6.1 单变量正态密度¶

    随机变量 \(x\) 服从均值为 \(\mu\)、方差为 \(\sigma^2\) 的正态分布，记作

    \[x \sim N(\mu, \sigma^2)\]

    它的概率密度函数是：

    \[p(x) = \frac{1}{\sqrt{2\pi}\,\sigma} \exp\left[-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^{2}\right]\]

    逐项解释这个公式：

    符号 名称 含义与取值
    \(x\) 自变量 任意实数，\(-\infty \lt x \lt +\infty\)
    \(\mu\) 均值 密度的峰值位置（左右对称轴），实数
    \(\sigma\) 标准差 必须 \(\sigma \gt 0\)，控制密度的宽窄
    \(\sigma^2\) 方差 \(\sigma\) 的平方，恒为正
    \(\frac{1}{\sqrt{2\pi}\,\sigma}\) 归一化常数 保证密度在全轴的积分等于 1
    \(\exp[\cdot]\) 指数函数 即 \(e^{(\cdot)}\)，把负的二次式映射到 \((0,1]\)

    先看指数里的那部分：记

    \[z = \frac{x - \mu}{\sigma}\]

    \(z\) 叫标准化变量，它回答的是 「这个点离均值有几个标准差远」。

    这里是第一次出现「用标准差做尺子」的思想， 请记住它 —— 第七节的马氏距离就是把这个思想推广到多维 ✓

    再逐项看几何含义：

    量的取值 密度的表现 几何解释
    \(x = \mu\) 取到最大值 \(\frac{1}{\sqrt{2\pi}\sigma}\) 峰值在均值处
    \(x = \mu \pm \sigma\) 降到峰值的 \(e^{-1/2} \approx 0.6065\) 倍 一个标准差处已明显下降
    \(x = \mu \pm 2\sigma\) 降到峰值的 \(e^{-2} \approx 0.135\) 倍 两个标准差处几乎到尾巴
    \(x = \mu \pm k\sigma\) 降到峰值的 \(e^{-k^2/2}\) 倍 以标准差为单位衡量远近
    \(\lvert x - \mu\rvert\) 变大 密度对称地趋近 0 两端各有一条尾巴

    关键洞察：密度的大小只依赖 \(|x-\mu|/\sigma\) 这一个量。 换句话说，在正态分布里， 「离均值几个标准差」完全决定了一个点的密度值 ⚠

    6.2 多元正态密度¶

    现在把维数升到 \(d\) 维。\(x\) 是一个 \(d\) 维列向量：

    \[x = (x_1, x_2, \dots, x_d)^{\mathsf{T}}\]

    它服从均值向量 \(\mu\)、协方差矩阵 \(\Sigma\) 的多元正态分布，记作

    \[x \sim N(\mu, \Sigma)\]

    概率密度函数是：

    \[p(x\mid\omega_i) = \frac{1}{(2\pi)^{d/2}\,\lvert\Sigma_i\rvert^{1/2}} \exp\left[-\frac{1}{2}(x-\mu_i)^{\mathsf{T}}\Sigma_i^{-1}(x-\mu_i)\right]\]

    逐个符号解释（每一个都第一次出现，务必看清）：

    符号 名称 形状 含义与要求
    \(d\) 维数 标量 特征个数，正整数
    \(\mu_i\) 均值向量 \(d \times 1\) 第 \(i\) 类数据的中心，\(E\{x\} = \mu_i\)
    \(\Sigma_i\) 协方差矩阵 \(d \times d\) 描述各维的离散程度与相关性
    \(\lvert\Sigma_i\rvert\) 行列式 标量 必须 \(\gt 0\)（否则矩阵不可逆，密度无定义）
    \(\Sigma_i^{-1}\) 逆矩阵 \(d \times d\) 出现在指数里，见下
    \((x-\mu_i)\) 偏差向量 \(d \times 1\) 点相对于中心的偏移
    \((2\pi)^{d/2}\) 归一化因子 标量 保证全空间积分为 1
    \(\exp[\cdot]\) 指数函数 标量 与一维情形同理

    怎样把密度写成真值：\(E\{x\} = \mu_i\) 的意思是

    \[E\{x\} = \int_{\mathbb{R}^d} x\, p(x)\,\mathrm{d}x = \mu_i\]

    式子里的 \(x\) 是随机向量，积分是在整个 \(d\) 维空间上做的：

    \[\int_{-\infty}^{+\infty}\cdots\int_{-\infty}^{+\infty} p(x)\,\mathrm{d}x_1\cdots \mathrm{d}x_d = 1\]

    这就是「归一化」在 \(d\) 维时的样子 ✓

    6.4 等密度轨迹：椭球¶

    定义（等密度轨迹）：密度 \(p(x)\) 取同一个值的所有 \(x\) 组成的集合。

    从多元正态密度公式可以看出：\(p(x)\) 只通过指数里那一项依赖 \(x\)， 前面的 \(\frac{1}{(2\pi)^{d/2}|\Sigma|^{1/2}}\) 是常数。 所以「密度相等」等价于「指数里那一项相等」 ✓

    于是等密度轨迹的方程是：

    \[(x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu) = \text{const}\]

    几何形状：这是一个超椭球面。特殊情况下（各方向扩散程度相同） 退化为超球面或圆形。

    椭球的轴由什么决定 —— 这是本节最容易混清的一点：

    几何量 由谁决定
    轴的方向 \(\Sigma\) 的特征向量
    轴的长度 \(\Sigma\) 的特征值（长度与特征值成正比）

    欧氏距离不知道这个差别，马氏距离知道 —— 这就是下一节的主题 ✓

    6.5 协方差矩阵的性质¶

    课件专门列了协方差矩阵的性质，这里逐条说清。

    定义：\(\Sigma = E\{(x-\mu)(x-\mu)^{\mathsf{T}}\}\)， 元素是 \(\sigma_{ij} = E\{(x_i-\mu_i)(x_j-\mu_j)\}\)。

    性质清单：

    编号 性质 含义
    1 实对称 \(\Sigma = \Sigma^{\mathsf{T}}\)，即 \(\sigma_{ij} = \sigma_{ji}\)
    2 正定 对任意非零向量 \(v\) 有 \(v^{\mathsf{T}}\Sigma v \gt 0\)
    3 可对角化 存在正交矩阵 \(\Phi\) 使 \(\Sigma = \Phi\Lambda\Phi^{\mathsf{T}}\)
    4 特征向量正交归一 \(\varphi_i^{\mathsf{T}}\varphi_j = 1\)（\(i=j\)），\(0\)（\(i\neq j\)）
    5 特征值非负 \(\lambda_i \geq 0\)；正定时严格 \(\gt 0\)
    6 特征值分解成和式 \(\Sigma = \sum_{i=1}^{d}\lambda_i\varphi_i\varphi_i^{\mathsf{T}}\)

    逐条解释：

    性质 1（实对称）怎么来的：协方差阵的元素满足

    \[\sigma_{ij} = E\{(x_i-\mu_i)(x_j-\mu_j)\} = E\{(x_j-\mu_j)(x_i-\mu_i)\} = \sigma_{ji}\]

    交换两个实数的乘法顺序不影响结果，所以矩阵必然对称 ✓

    性质 2（正定）：把二次型展开，它可以写成 \(E\{\bigl(v^{\mathsf{T}}(x-\mu)\bigr)^2\}\)， 是一个平方的期望，所以非负； 只要 \(x-\mu\) 不会恒垂直于 \(v\)，它就是严格正的 ✓

    为什么正定很重要： 密度公式里出现了 \(|\Sigma|\) 和 \(\Sigma^{-1}\)。 正定保证 \(|\Sigma| \gt 0\)（可逆），也保证密度不会退化到低维面上 ⚠ 如果 \(\Sigma\) 只是半正定（某个特征值为 0）， 说明数据其实被限制在一个低维子空间里，此时 \(d\) 维密度无定义。

    性质 3、6（对角化与求和式）：\(\Sigma = \Phi\Lambda\Phi^{\mathsf{T}}\)， 其中 \(\Phi = [\varphi_1, \varphi_2, \dots, \varphi_d]\) 是特征向量排成的矩阵， \(\Lambda = \mathrm{diag}(\lambda_1, \dots, \lambda_d)\) 是特征值排成的对角阵。

    求和式怎么来的：把 \(\Sigma = \Phi\Lambda\Phi^{\mathsf{T}}\) 按分块写成求和：

    \[\Sigma = \sum_{i=1}^{d}\lambda_i\,\varphi_i\varphi_i^{\mathsf{T}}\]

    怎么读：每一项 \(\lambda_i\varphi_i\varphi_i^{\mathsf{T}}\) 是一个只指向 \(\varphi_i\) 方向的秩 1 矩阵， 前乘系数 \(\lambda_i\) 就是那个方向的「强度」。 所以协方差矩阵是 \(d\) 个正交方向的强度叠加 ✓

    性质 4、5 的矩阵化写法：

    \[\Phi^{\mathsf{T}}\Phi = I \quad\Longrightarrow\quad \Phi^{-1} = \Phi^{\mathsf{T}}\]
    \[\Sigma\varphi_i = \lambda_i\varphi_i, \qquad \varphi_i^{\mathsf{T}}\Sigma\varphi_i = \lambda_i\]

    最后那个式子怎么来的： 在 \(\Sigma\varphi_i = \lambda_i\varphi_i\) 两边左乘 \(\varphi_i^{\mathsf{T}}\)， 再用 \(\varphi_i^{\mathsf{T}}\varphi_i = 1\) 得 \(\varphi_i^{\mathsf{T}}\Sigma\varphi_i = \lambda_i\varphi_i^{\mathsf{T}}\varphi_i = \lambda_i\) ✓

    还有一个常用的结论（对角化形式的推论）：把 \(\Sigma = \Phi\Lambda\Phi^{\mathsf{T}}\) 左右两边分别左乘 \(\Phi^{\mathsf{T}}\)、右乘 \(\Phi\)，得

    \[\Phi^{\mathsf{T}}\Sigma\Phi = \Lambda\]

    因为（一步一步写）：

    \[\begin{aligned} \Phi^{\mathsf{T}}\Sigma\Phi &= \Phi^{\mathsf{T}}\bigl(\Phi\Lambda\Phi^{\mathsf{T}}\bigr)\Phi \\ &= \bigl(\Phi^{\mathsf{T}}\Phi\bigr)\Lambda\bigl(\Phi^{\mathsf{T}}\Phi\bigr) \\ &= I\Lambda I = \Lambda \end{aligned}\]

    第二步用到了结合律（把括号挪位置不改变乘积）， 第三步用的是 \(\Phi^{\mathsf{T}}\Phi = I\) ✓

    这个式子说明：用 \(\Phi\) 当坐标变换矩阵， 可以把协方差矩阵变成对角阵 —— 也就是在新坐标系里各维互不相关。 这正是「主轴方向」这个说法的来历 ✓

    七、马氏距离：为什么不能只用欧氏距离¶

    这一节是全文最实用的一段。前面反复出现的那个二次型， 现在给它一个正式名字，并说明它为什么非有不可。

    7.1 定义¶

    定义（马氏距离）：样本 \(x\) 到中心 \(\mu\) 的马氏距离是

    \[d_M(x, \mu) = \sqrt{(x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu)}\]

    符号说明：\(\Sigma\) 是这组数据（或这一类数据）的协方差矩阵， 必须正定可逆。

    怎么读这个定义： 把它和一维的情形并排看，就明白它在干什么 ——

    维数 距离形式 在度量什么
    一维 \(\lvert x-\mu\rvert\) 离中心多远（绝对量的差）
    一维（标准化） \(\dfrac{\lvert x-\mu\rvert}{\sigma}\) 离中心几个标准差
    多维（马氏） \(\sqrt{(x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu)}\) 离中心几个「标准差」（多维版）

    核心直觉：马氏距离是用数据自身的形状当尺子量出来的距离。 \(\Sigma^{-1}\) 起的作用，就是把各维的尺度差异和相关性都折算掉 ✓

    7.2 为什么不用欧氏距离¶

    欧氏距离的定义是

    \[d_E(x, \mu) = \sqrt{(x-\mu)^{\mathsf{T}}(x-\mu)} = \sqrt{\sum_{k=1}^{d}(x_k-\mu_k)^2}\]

    它在做一件很武断的假设：各维的「一米」是一样长的， 而且各维之间没有相关性。

    实际数据常常不满足：

    问题 具体表现 欧氏距离的后果
    量纲不同 第 1 维单位是毫米、第 2 维单位是千克 改一下单位，最近邻就变了 —— 结论不稳定 ⚠
    尺度差异大 第 1 维的标准差是 \(10\)，第 2 维是 \(0.01\) 第 1 维的偏差完全淹没第 2 维的偏差
    维度相关 两个特征高度正相关（比如身高与体重） 同一个信息被重复计算两次，该方向被过分放大
    特征冗余 某些方向其实几乎没变化 那些方向上的噪声被当成真信号

    第一条最要命：欧氏距离依赖单位的选择。 米和厘米只是换个写法，物理上什么都没变， 但欧氏距离的数值会变 100 倍，最近邻可能就换了 ✗

    马氏距离怎么解决这四条：\(\Sigma^{-1}\) 里每个元素都是数据自己算出来的， 量纲、尺度、相关性全部自动包含进去：

    欧氏距离的问题 马氏距离的应对
    量纲不同 \(\Sigma\) 随单位一起变，\(\Sigma^{-1}\) 正好把它约回来
    尺度差异大 除以各维方差，尺度小的维度被自动放大
    维度相关 \(\Sigma\) 的非对角元记录相关性，\(\Sigma^{-1}\) 把它扣除
    特征冗余 接近零的特征值方向被 \(\Sigma^{-1}\) 强烈抑制

    7.4 与欧氏距离的关系：\(\Sigma = I\) 时两者相同¶

    把 \(\Sigma = I\) 代入马氏距离定义：

    \[d_M(x,\mu) = \sqrt{(x-\mu)^{\mathsf{T}}I^{-1}(x-\mu)} = \sqrt{(x-\mu)^{\mathsf{T}}(x-\mu)} = d_E(x,\mu)\]

    因为 \(I^{-1} = I\)，单位阵乘任何向量都不变 ✓

    这句话的完整含义：

    \[\Sigma = I \quad\Longleftrightarrow\quad \text{各维方差都是 } 1 \text{ 且互不相关} \quad\Longrightarrow\quad d_M = d_E\]

    所以欧氏距离是马氏距离的一个特例 —— 它隐含地假设了「各维方差为 1、互不相关」⚠

    7.5 线性变换下的不变性¶

    这是马氏距离最重要的性质，也是它和欧氏距离最本质的区别。

    性质：做任意可逆线性变换 \(y = Ax\)（\(A\) 为可逆方阵）， 马氏距离保持不变。

    先看变换后数据的分布：原数据 \(x \sim N(\mu, \Sigma)\)， 线性变换后 \(y = Ax\) 仍然是正态分布（这是多元正态的性质之一）， 其参数是

    \[\mu_y = A\mu, \qquad \Sigma_y = A\Sigma A^{\mathsf{T}}\]

    这两个式子怎么来的：

    期望的线性性给出第一个：

    \[E\{y\} = E\{Ax\} = A\,E\{x\} = A\mu\]

    协方差按定义展开，就是用第二个：

    \[\begin{aligned} \Sigma_y &= E\bigl\{(y-\mu_y)(y-\mu_y)^{\mathsf{T}}\bigr\} \\ &= E\bigl\{A(x-\mu)(x-\mu)^{\mathsf{T}}A^{\mathsf{T}}\bigr\} \\ &= A\,E\bigl\{(x-\mu)(x-\mu)^{\mathsf{T}}\bigr\}A^{\mathsf{T}} = A\Sigma A^{\mathsf{T}} \end{aligned}\]

    第二步把 \(A\) 提到期望外面是允许的： \(A\) 是常数矩阵，不随随机向量变化 ✓

    现在算变换后的马氏距离：

    \[\begin{aligned} d_M^2(y, \mu_y) &= (y-\mu_y)^{\mathsf{T}}\Sigma_y^{-1}(y-\mu_y) \\ &= \bigl[A(x-\mu)\bigr]^{\mathsf{T}} \bigl[A\Sigma A^{\mathsf{T}}\bigr]^{-1} \bigl[A(x-\mu)\bigr] \end{aligned}\]

    关键一步是求逆。用逆矩阵的乘积公式 \((PQR)^{-1} = R^{-1}Q^{-1}P^{-1}\)，取 \(P = A\)、\(Q = \Sigma\)、\(R = A^{\mathsf{T}}\)：

    \[\bigl[A\Sigma A^{\mathsf{T}}\bigr]^{-1} = (A^{\mathsf{T}})^{-1}\Sigma^{-1}A^{-1}\]

    代回去：

    \[\begin{aligned} d_M^2(y, \mu_y) &= (x-\mu)^{\mathsf{T}}A^{\mathsf{T}} (A^{\mathsf{T}})^{-1}\Sigma^{-1}A^{-1} A(x-\mu) \\ &= (x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu) \\ &= d_M^2(x, \mu) \end{aligned}\]

    中间两个约掉的地方很重要： \(A^{\mathsf{T}}(A^{\mathsf{T}})^{-1} = I\)， \(A^{-1}A = I\)，两处都约掉单位阵 ✓

    结论：开方后 \(d_M(y,\mu_y) = d_M(x,\mu)\)，马氏距离不变 ✓

    欧氏距离在同样变换下的表现：

    \[\begin{aligned} d_E^2(y, \mu_y) = (Ax - A\mu)^{\mathsf{T}}(Ax - A\mu) = (x-\mu)^{\mathsf{T}}A^{\mathsf{T}}A(x-\mu) \end{aligned}\]

    注意这里出现的是 \(A^{\mathsf{T}}A\) 而不是 \(I\) —— 它一般不等于 \((x-\mu)^{\mathsf{T}}(x-\mu)\)， 所以欧氏距离通常会变 ✗

    举个最小例子：\(A = 2I\)（所有维都放大两倍）， 欧氏距离直接放大两倍，马氏距离不变。

    八、决策面形状预览：三种情形¶

    把前面所有线索合起来，就能回答一个预测性的问题： 假设各类都服从正态分布，决策面会是什么形状？

    答案取决于协方差矩阵怎么假设。三种情形如下：

    情形 协方差矩阵 判别函数 决策面
    一 各类协方差相同，且是 \(\sigma^2 I\) 线性 超平面（\(\Sigma=I\) 时垂直于两类均值连线）
    二 各类协方差相同，一般形式 \(\Sigma\) 线性 超平面（一般不与均值连线垂直）
    三 各类协方差不同 二次 超二次曲面（超椭球面/超双曲面/超球面等）

    为什么情形一、二都得到线性判别函数 —— 关键在指数里那个二次型展开后会出现一项 \(x^{\mathsf{T}}\Sigma^{-1}x\)：

    \[(x-\mu_i)^{\mathsf{T}}\Sigma^{-1}(x-\mu_i) = x^{\mathsf{T}}\Sigma^{-1}x - 2\mu_i^{\mathsf{T}}\Sigma^{-1}x + \mu_i^{\mathsf{T}}\Sigma^{-1}\mu_i\]

    注意第一项 \(x^{\mathsf{T}}\Sigma^{-1}x\) 里完全没有 \(i\) —— 它是所有类共有的。两类相减时这一项正好抵消：

    \[g(x) = g_1(x) - g_2(x) = w^{\mathsf{T}}x + w_0\]

    其中

    \[w = \Sigma^{-1}(\mu_1 - \mu_2), \qquad w_0 = -\frac{1}{2}\bigl(\mu_1^{\mathsf{T}}\Sigma^{-1}\mu_1 - \mu_2^{\mathsf{T}}\Sigma^{-1}\mu_2\bigr) + \ln\frac{P(\omega_1)}{P(\omega_2)}\]

    因为二次项消掉了，剩下的只有 \(x\) 的一次项和常数项， 所以 \(g\) 是线性的，决策面 \(g(x)=0\) 是一张超平面 ✓

    情形三为什么是二次的：两类协方差不同时， \(x^{\mathsf{T}}\Sigma_1^{-1}x\) 与 \(x^{\mathsf{T}}\Sigma_2^{-1}x\) 不再抵消，二次项留在 \(g(x)\) 里，所以 \(g\) 是二次函数， \(g(x)=0\) 是超二次曲面。

    具体是哪种二次曲面，取决于 \(\Sigma_1\)、\(\Sigma_2\)、 \(\mu_1\)、\(\mu_2\) 和两个先验 —— 可以是超椭球面、超双曲面，也可能退化成超球面甚至超平面 ✓ 具体推导留到下一节。

    \[x_0 = 166 - \frac{5^2}{160-172}\times 1.386294 = 166 - \frac{25}{-12}\times 1.386294\]

    \[x_0 = 166 - (-2.083333)(1.386294) = 166 + 2.888113 = 168.888113\]

    决策面移到 \(x = 168.89\) ✓

    移动量：

    \[168.888113 - 166 = +2.888113\]

    也就是向右移动了 \(2.89\)。

    项 值 含义

    两维不相关时 \(\Sigma\) 是对角阵， \(\Sigma^{-1}\) 就是「各维取倒数」。 马氏距离平方 = 各维「偏差除以该维标准差」的平方和。

    \[d_E(a) = \sqrt{5^2 + 0^2} = 5\]
    \[d_M(a) = \sqrt{5^2 \times 0.04 + 0^2 \times 100} = \sqrt{1 + 0} = 1\]

    \[d_E(b) = \sqrt{0^2 + 0.15^2} = 0.15\]
    \[d_M(b) = \sqrt{0^2 \times 0.04 + 0.15^2 \times 100} = \sqrt{0 + 2.25} = 1.5\]

    \(a\) \(5\) \(1\)
    \(b\) \(0.15\) \(1.5\)
    谁更近 \(b\)（\(0.15 \lt 5\)） \(a\)（\(1 \lt 1.5\)）

    候选 第 1 维偏了几个标准差 第 2 维偏了几个标准差 合计距离

    十一、自测¶

    Q1 判断对错并说明理由：

    某分类器用 \(g_1(x) = P(\omega_1\mid x)\)、\(g_2(x) = P(\omega_2\mid x)\) 做判决。 现在把它换成 \(g_1' = \ln P(\omega_1\mid x)\)、 \(g_2' = \ln P(\omega_2\mid x)\)，判决结果会变吗？ 如果换成 \(g_1'' = 2g_1 - 5\)、\(g_2'' = 2g_2 - 5\) 呢？

    提示

    两次换的都是同一个变换作用在所有类上。 先判断该变换是不是严格单调增。

    解答

    两次都不会变 ✓

    第一次：\(\ln\) 变换

    \(\ln\) 在 \((0, +\infty)\) 上严格单调增。 后验概率的取值在 \((0, 1]\) 内（实际上在 \((0,1)\)）， 所以 \(g_1, g_2\) 都在 \(\ln\) 的定义域内。

    对任意 \(g_1 \gt g_2 \gt 0\)，有 \(\ln g_1 \gt \ln g_2\)， 大小关系逐对保持，所以判决不变 ✓

    有一个边界情形要注意：如果某一类的后验恰好等于 \(0\) （先验为 \(0\) 时会发生），\(\ln 0\) 无定义 ✗ 这时的处理办法是：先把那个不可能出现的类直接排除， 再对剩下的类取对数。

    第二次：仿射变换 \(2g-5\)

    这个变换是 \(g \mapsto 2g - 5\)。 系数 \(2 \gt 0\)，所以它是严格单调增的：

    \[g_1 \gt g_2 \ \Longrightarrow\ 2g_1 - 5 \gt 2g_2 - 5\]

    减去同一个常数 \(5\) 不影响不等号方向， 乘上正数 \(2\) 也不影响 ✓

    结论表：

    变换 单调增？ 判决会变？
    \(g \mapsto \ln g\)（\(g \gt 0\)） 是 不变
    \(g \mapsto 2g-5\) 是 不变
    \(g \mapsto -g\) 否（递减） 必变
    \(g \mapsto g^2\)（\(g\) 可能为负） 否 可能变

    Q2 某两类问题，协方差矩阵都是 \(I\)， \(\mu_1 = (0,0)^{\mathsf{T}}\)、\(\mu_2 = (4,0)^{\mathsf{T}}\)， 先验 \(P(\omega_1) = 0.9\)、\(P(\omega_2) = 0.1\)。

    (a) 写出 \(g(x) = g_1(x) - g_2(x)\) 的表达式。 (b) 决策面方程是什么？它在特征空间里是什么形状？ © 决策面经过中点 \((2,0)\) 吗？为什么？

    提示

    协方差相同且为 \(I\) 时，直接用这个公式：

    \[g(x) = x^{\mathsf{T}}(\mu_1-\mu_2) - \frac{1}{2}\bigl(\mu_1^{\mathsf{T}}\mu_1 - \mu_2^{\mathsf{T}}\mu_2\bigr) + \ln\frac{P_1}{P_2}\]

    把数字代进去，看看 \(x_2\) 的系数是多少。

    解答

    （a）表达式

    两类协方差都是 \(I\)，按 8.1 节前的公式：

    \[\mu_1^{\mathsf{T}}\mu_1 = 0 + 0 = 0, \qquad \mu_2^{\mathsf{T}}\mu_2 = 16 + 0 = 16\]
    \[w = \mu_1 - \mu_2 = (-4, 0)^{\mathsf{T}}\]
    \[w_0 = -\frac{1}{2}(0 - 16) + \ln\frac{0.9}{0.1} = 8 + \ln 9 = 8 + 2.197225 = 10.197225\]

    所以

    \[g(x) = -4x_1 + 0\cdot x_2 + 10.197225 = -4x_1 + 10.197225\]

    （b）决策面

    令 \(g(x) = 0\)：

    \[-4x_1 + 10.197225 = 0 \quad\Longrightarrow\quad x_1 = 2.549306\]

    这是一条竖直直线（\(x_2\) 的系数为 \(0\)， 所以方程里不出现 \(x_2\)）。 它把二维平面分成左右两块 ✓

    （c）经过中点吗

    不经过 ✗ 中点 \((2, 0)\) 处的函数值是

    \[g(2, 0) = -4(2) + 10.197225 = 2.197225 \gt 0\]

    为什么：中点只有先验相等时才在决策面上。 这里 \(\ln(0.9/0.1) = 2.197225 \gt 0\)， 相当于给第 1 类额外加了 \(2.197225\) 分， 所以第 1 类的地盘向右扩张，分界线从 \(x_1 = 2\) 移到 \(x_1 = 2.549\) ✓

    (a) 这个矩阵有哪些性质？逐条检查。 (b) 这个分布的等密度轨迹是圆还是椭圆？ © 长短轴各多长？方向如何？

    提示

    按 6.5 节的性质清单逐条对：对称、正定、可对角化、 特征值、迹、行列式。 对角矩阵的特征值就是对角元。

    解答

    （a）性质逐条检查

    性质 检查 结论
    实对称 \(\sigma_{12} = \sigma_{21} = 0\) 满足 ✓
    正定 对角元 \(9 \gt 0\)、\(4 \gt 0\)，且非对角为 \(0\) 满足 ✓
    特征值 对角矩阵的特征值就是对角元：\(\lambda_1 = 9\)、\(\lambda_2 = 4\) 全为正 ✓
    可对角化 本身就是对角阵，\(\Phi = I\)、\(\Lambda = \Sigma\) 满足 ✓
    迹 \(9 + 4 = 13\)，与特征值之和 \(9+4 = 13\) 一致 满足 ✓
    行列式 \(9 \times 4 - 0 = 36\)，与特征值之积 \(9\times4 = 36\) 一致 满足 ✓

    （b）圆还是椭圆

    是椭圆 ✗（不是圆）

    判据：等密度轨迹退化为圆（球面）的条件是 各方向扩散程度相同，也就是 \(\Sigma\) 的特征值全部相等。 这里 \(9 \neq 4\)，所以是椭圆 ✓

    （c）轴长与方向

    等密度轨迹的方程是

    \[\frac{x_1^2}{9} + \frac{x_2^2}{4} = \text{const}\]

    把它写成标准椭圆形式（除以 const）：

    \[\frac{x_1^2}{9c} + \frac{x_2^2}{4c} = 1\]

    所以半轴长分别是 \(3\sqrt{c}\) 与 \(2\sqrt{c}\) —— 正比于 \(\sqrt{\lambda_1} = 3\) 与 \(\sqrt{\lambda_2} = 2\) ✓ 这与「主轴长度与特征值成正比」的结论对应 （注意严格说轴长与特征值的平方根成正比， 因为密度里是 \(r^2\) 而不是 \(r\)）。

    长短轴之比：\(\sqrt{9/4} = 1.5\)。

    小结¶

    要记住的 为什么
    判别函数是一组函数 \(g_i(x)\)，判最大者 把「算概率」变成「比大小」，是后面所有分类器的统一框架
    判决只依赖判别函数之间的序 所以存在大量等价形式；换形式不影响判决
    保序变换（乘正数、加常数、取对数）不改变判决 这是「判别函数不唯一」的根源
    乘负数、给不同类加不同常数会改变判决 一旦破坏「所有类用同一个变换」，比较就失去意义
    \(g_i = p(x\mid\omega_i)P(\omega_i)\) 最常用 分母 \(p(x)\) 与类别无关，可以整项丢掉
    \(g_i = \ln p(x\mid\omega_i) + \ln P(\omega_i)\) 数值最稳 把连乘变成连加，避免高维下溢出为 0
    决策面方程 \(g_i(x) = g_j(x)\) 两个类判别函数打平的地方就是分界线
    两类时只看 \(g(x) = g_1 - g_2\) 的符号 把「比两个数」简化成「看一个数的正负」
    决策面方程 \(g(x) = 0\) 本页最核心的一个等式，它确定全部决策区域
    决策面的形状由 \(g\) 的形式决定 \(g\) 线性则决策面是超平面，\(g\) 二次则是超二次曲面
    \(g(x) = \ln\frac{p(x\mid\omega_1)}{p(x\mid\omega_2)} + \ln\frac{P(\omega_1)}{P(\omega_2)}\) 似然比 + 先验比，前者靠数据、后者靠先验
    决策面 = 似然比等于先验反比的那些点 这就是「\(g=0\)」的物理含义
    多元正态密度的指数项就是马氏距离平方 \((x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu) = r^2\)
    高斯的等密度轨迹是椭球 轴方向由特征向量定，轴长由特征值定（正比于 \(\sqrt{\lambda}\)）
    协方差矩阵：对称、正定、可对角化 正定保证可逆，才能定义密度与马氏距离
    \(\operatorname{tr}(\Sigma) = \sum\lambda_i\)、\(\lvert\Sigma\rvert = \prod\lambda_i\) 跑代码时的两条自检等式
    马氏距离 \(d_M = \sqrt{(x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu)}\) 用数据自身形状当尺子，「离中心几个标准差」的多维版
    量纲不同、尺度差异大、维度相关时必须用马氏距离 欧氏距离隐含「各维方差为 1、互不相关」的错误假设
    \(\Sigma = I\) 时马氏退化成欧氏 所以欧氏距离是马氏距离的特例
    马氏距离对线性变换 \(y = Ax\) 不变，欧氏距离会变 马氏度量的是数据的内在结构，欧氏度量的是坐标选择
    协方差相同 → 线性判别函数 → 超平面决策面 因为 \(x^{\mathsf{T}}\Sigma^{-1}x\) 这一项两类相同，做差时抵消
    协方差不同 → 二次判别函数 → 超二次曲面 二次项不再抵消，所以决策面弯了
    决策面垂直的是 \(w\)，不是两类均值连线 只有 \(\Sigma \propto I\) 时两者才重合
