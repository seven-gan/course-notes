    判别函数与决策面¶

    这一页解决一个问题：怎么把「比较后验概率」这件事， 重新写成「几个函数比大小」？

    上一页得到了最小风险判决规则：算出各类的后验概率，挑最大的那一类。 规则本身没错，但照着它一步步硬算，会遇到两个麻烦：

    看起来差不多 实际差别 后果
    每次都算后验概率 后验的分母是全概率，要对所有类求和 类别一多，每个样本都多算一大圈
    概率值本身 多维密度是连乘，每一维都小于 1 维数一高就数值下溢成 0，比大小彻底失效
    判决只关心「谁最大」 完全不需要知道最大值究竟是多少 说明存在大量互相等价的写法

    把这两件事想通，就会自然地引出这一页的主角 —— 判别函数。 它把「谁的几率大」抽象成「谁的函数值大」， 让判决规则从「算概率」变成「比大小」， 也顺带解释了为什么同一件事可以有那么多看起来不一样的公式。

    这一页还顺路补上两个下一节必需的地基： 多元正态密度公式，以及马氏距离。

    这一页的核心问题

    整页只围绕一句话展开：

    判决只依赖判别函数之间的「序」，不依赖它们的「值」。

    由此推出三件事：

    推论 说明
    判别函数可以随便换形式 只要保证各类之间的大小关系不变
    判决面可以只看差 两类时把两个判别函数相减，只看正负号
    决策面与数值无关 决策面就是「差等于 0」的那张等值面

    这句话是整个模式识别里最省钱的一句话： 它把「必须精确计算概率」降级成「只需要把顺序排对」。 后面所有分类器 —— 线性、二次、神经网络 —— 都是在这句话的框架里换一种 \(g_i\) 的写法而已 ✓

    一、为什么需要「判别函数」这个概念¶

    1.1 先回头看判决规则本身¶

    前几页得到的最小风险判决规则，用后验概率写成：

    \[\text{判 } \omega_i \quad \text{当} \quad P(\omega_i \mid x) \gt P(\omega_j \mid x) \quad \text{对所有 } j \neq i\]

    先把符号定义清楚：

    符号 含义 取值范围
    \(c\) 类别总数 正整数
    \(\omega_1, \dots, \omega_c\) 各个类别 —
    \(x\) 观测到的特征向量，\(d\) 维 \(x \in \mathbb{R}^d\)
    \(P(\omega_i \mid x)\) 看到 \(x\) 后它属于第 \(i\) 类的后验概率 \([0,1]\)
    \(p(x \mid \omega_i)\) 第 \(i\) 类的类条件密度 非负
    \(P(\omega_i)\) 第 \(i\) 类的先验概率 \([0,1]\)
    \(p(x)\) 全概率密度，各类的公共分母 正数

    怎么读这个规则：把 \(c\) 个后验概率都算出来，谁最大就判谁。 「对所有 \(j \neq i\) 都成立」这句话的意思是， 这个最大值必须严格大于其余每一个（不能有并列）。

    1.2 麻烦一：分母是公共的，但每次都要算¶

    把贝叶斯公式代进去：

    \[P(\omega_i \mid x) = \frac{p(x \mid \omega_i)\,P(\omega_i)}{p(x)}, \qquad p(x) = \sum_{j=1}^{c} p(x \mid \omega_j)\,P(\omega_j)\]

    分母 \(p(x)\) 与 \(i\) 无关 —— 它是「不管属于哪一类，观测到 \(x\) 的总概率」， 所以 \(c\) 个后验概率用的是同一个分母。

    关键的一步推导（不跳步）： 把判决规则里的两个后验都换成上面这个分式。

    \[\begin{aligned} \text{判 } \omega_i &\iff \frac{p(x \mid \omega_i)P(\omega_i)}{p(x)} \gt \frac{p(x \mid \omega_j)P(\omega_j)}{p(x)} \quad \forall j \neq i \\ &\iff \frac{p(x \mid \omega_i)P(\omega_i)}{p(x)} - \frac{p(x \mid \omega_j)P(\omega_j)}{p(x)} \gt 0 \quad \forall j \neq i \\ &\iff \frac{p(x \mid \omega_i)P(\omega_i) - p(x \mid \omega_j)P(\omega_j)}{p(x)} \gt 0 \quad \forall j \neq i \\ &\iff p(x \mid \omega_i)P(\omega_i) - p(x \mid \omega_j)P(\omega_j) \gt 0 \quad \forall j \neq i \\ &\iff p(x \mid \omega_i)P(\omega_i) \gt p(x \mid \omega_j)P(\omega_j) \quad \forall j \neq i \end{aligned}\]

    每一步的根据都写在下面，请逐条对上：

    步骤 做了什么 依据
    1 → 2 把不等号移项成「左边减右边大于 0」 不等号两边同时减去同一个量，方向不变
    2 → 3 两个同分母分式合并成一个分式 同分母分数相减，分母不变、分子相减
    3 → 4 两边同乘 \(p(x)\)，去掉分母 \(p(x)\) 是正数，乘正数不改变不等号方向
    4 → 5 把「差大于 0」写成「左边大于右边」 移项，同样是两边加同一个量

    「\(p(x)\) 是正数」这件事必须先确认： \(p(x) = \sum_j p(x\mid\omega_j)P(\omega_j)\) 是若干非负项之和。 只要对至少一个 \(x\)、至少一个类，密度不为零， 这个和就是严格正的 ✓ （只有全体密度在某点同时为 0 才例外，那种情况下任何判决规则都没有依据。）

    结论：分母根本不用算。 只有「需要报告一个具体的概率值」时，才需要回头除以 \(p(x)\)。

    这个结论值多少：设类别数 \(c\)、样本数 \(n\)， 需要估计的类条件参数总数为 \(P\)。两种做法的开销对照如下：

    做法 每个样本要算的量 要对所有类求和吗 需要知道 \(p(x)\) 吗
    先算后验再比大小 \(c\) 个密度，外加一次 \(c\) 项求和 需要 需要
    直接比加权密度 \(c\) 个密度 不需要 不需要

    判别函数的写法省掉的是「分母那一圈求和」 —— 类别数 \(c\) 越大，省下的计算越多。 而两类情形的相减（第 4.3 节）还会再省掉一半的乘法 ✓

    1.3 麻烦二：连乘会下溢，这是真正要命的地方¶

    如果 \(d\) 个特征相互独立，那么 \(d\) 维的类条件密度可以拆成 \(d\) 个一维密度相乘：

    \[p(x \mid \omega_i) = \prod_{k=1}^{d} p(x_k \mid \omega_i)\]

    每一个一维密度通常在 \(0.01\) 到 \(1\) 这个量级。乘 \(d\) 次就指数级变小：

    维数 \(d\) 每维取 \(0.1\) 时的连乘结果 是否还能用浮点数表示
    \(d = 50\) \(10^{-50}\) 能，双精度最小约 \(10^{-308}\)
    \(d = 200\) \(10^{-200}\) 勉强能
    \(d = 320\) \(10^{-320}\) 超出下限，已经失真
    \(d = 400\) \(10^{-400}\) 直接变成 0

    只要变成 0，所有类的判别函数值就都是 0， 「谁大谁小」的信息全部丢失，判决直接失效 ⚠

    「失真」和「变成 0」是两件不同的坏事，都值得说清：

    现象 数学上发生了什么 后果
    下溢成 0 结果小于最小可表示的正数，被舍入到 0 所有类并列，判决无依据
    逐渐失真 两个很接近的真值被舍入到同一个浮点数 本来第 1 类略大，却显示相等
    上溢 反过来，值太大超过上限变成无穷 同样无法比较

    取对数就是针对这三条的统一解药： \(\ln \prod_k p_k = \sum_k \ln p_k\)， 把「\(d\) 个小正数相乘」换成「\(d\) 个负数相加」。 加法不会把量级压到 \(10^{-320}\) 那种地步， 每一项还都能单独查看、单独检查 ✓

    取对数有一个前提：函数值必须是正数

    \(\ln\) 只在正数上有定义。\(p(x\mid\omega_i)\) 是密度，恒为正， \(P(\omega_i)\) 也恒为正（除非某一类的先验恰好是 0）， 所以取对数在数学上是安全的。

    但如果你手里那个「判别函数」的值可能是负数或零， 就不能对它取对数。此时可以改取 \(\ln(\cdot + C)\) 这种平移形式， 只要 \(C\) 足够大使全体为正 —— 平移不改变大小关系 ✓

    还有一个隐蔽的坑：先验恰好为 0 的那一类， \(\ln P(\omega_i)\) 无定义。这类先验为 0 的类本来就不可能出现， 正确做法是先把它从类别集合里删掉，再对剩下的类取对数 ✓

    1.4 关键洞察：判决只需要「序」¶

    把 1.2 和 1.3 两件事合起来看，会发现一个共同点：

    操作 做的事 为什么不影响判决
    除以 \(p(x)\) 所有类除以同一个正数 不等式两边同除正数，方向不变
    取对数 所有类过同一个单调增函数 单调增函数保序
    乘一个正常数 \(a \gt 0\) 所有类扩大同一倍数 不等式两边同乘正数，方向不变
    加一个常数 \(b\) 所有类平移同一个量 比较的是差，平移会抵消

    这四种操作都用一个词概括：保序变换。 只要对所有类施加同一个保序变换， 「谁最大」这个结论就完全不变 ✓

    于是可以彻底换个说法： 我们不需要那个具体是概率的函数， 只需要一个能在各类之间保持同样先后次序的函数。 这样的函数就叫判别函数。

    四次保序操作在一条数轴上的效果（取两个值 \(g_1 = 0.3\)、\(g_2 = 0.9\)）：

    操作 变换后第 1 类 变换后第 2 类 序还保持吗
    原值 \(0.3\) \(0.9\) —
    乘 \(3\) \(0.9\) \(2.7\) 保持 ✓
    加 \(7\) \(7.3\) \(7.9\) 保持 ✓
    取 \(\ln\) \(-1.203973\) \(-0.105361\) 保持 ✓
    取负 \((-g)\) \(-0.3\) \(-0.9\) 翻转了 ✗

    最后一行是唯一的红线：取负号是严格递减函数，不是保序变换。

    二、判别函数的定义与「不唯一」¶

    2.1 正式定义¶

    定义（判别函数）：一组函数

    \[g_1(x),\; g_2(x),\; \dots,\; g_c(x)\]

    如果对某个 \(x\)，有

    \[g_i(x) \gt g_j(x) \qquad \text{对所有 } j \neq i\]

    就把 \(x\) 判归 \(\omega_i\) 类。

    怎么读这个定义：这里完全不出现概率。 \(g_i\) 可以是任何实值函数， 唯一的用处就是给每个类「打一个分」， 然后拿最高的那个分对应的类当答案。

    把分类器看成一台机器（这是本节最直观的一幅图）：

    机器部件 作用
    输入端 接收 \(d\) 个特征值 \(x_1, x_2, \dots, x_d\)
    中间层 并行算出 \(c\) 个判别函数值 \(g_1(x), \dots, g_c(x)\)
    输出端 一个最大值选择器，输出最大值对应的类别标号

    也就是说：分类器 = \(c\) 个判别函数 + 一个取最大值的操作。 后面看到线性分类器、二次分类器、神经网络， 区别只在于中间的 \(g_i\) 长什么样 ✓

    换成判别函数的说法之后，判决规则的形式变化：

    项 后验概率的说法 判别函数的说法
    输入 特征向量 \(x\) 同样的特征向量 \(x\)
    中间量 \(c\) 个后验概率，和为 1 \(c\) 个任意实数，和没有要求
    输出 概率最大的类标 函数值最大的类标
    对数值的要求 必须精确（否则概率失真） 只要序对（数值可以随便）

    2.2 判别函数不唯一 ⚠¶

    这是本节最容易被忽略、但最重要的一条性质。

    性质（判别函数的不唯一性）： 设 \(g_1(x), \dots, g_c(x)\) 是一组判别函数， \(\varphi\) 是任意一个严格单调增的函数，则

    \[\tilde g_i(x) = \varphi\bigl(g_i(x)\bigr), \qquad i = 1, 2, \dots, c\]

    也是一组合法判别函数，而且两组的判决结果完全相同。

    证明（逐步写，不跳步）：

    第一步：设有 \(g_i(x) \gt g_j(x)\)。 因为 \(\varphi\) 严格单调增，对一个严格增函数而言「自变量大则函数值大」， 所以两边同时过 \(\varphi\) 得

    \[\varphi\bigl(g_i(x)\bigr) \gt \varphi\bigl(g_j(x)\bigr) \quad\Longrightarrow\quad \tilde g_i(x) \gt \tilde g_j(x)\]

    第二步：反过来设 \(\tilde g_i(x) \gt \tilde g_j(x)\)。 若 \(g_i(x) \le g_j(x)\)，由严格单调增会得到 \(\tilde g_i(x) \le \tilde g_j(x)\)，与假设矛盾； 所以只能有 \(g_i(x) \gt g_j(x)\)。

    两个方向都成立，说明大小关系一一对应， 所以「最大值是谁」不会变 ✓

    这条性质的实际用途：

    用途 说明
    换掉不方便计算的形式 乘积换成求和、概率换成负对数
    丢掉与类无关的项 那些项对所有类相同，等价于加同一个常数
    跨模型比较判别函数 只要两个模型差一个保序变换，判决行为相同

    三条红线：这样做会改变判决

    上面说的是「对所有类施加同一个保序变换」。 下面三种做法都会破坏判决：

    错误做法 为什么错 例子（直观）
    乘一个负数 不等号方向全部翻转 \(g = (1, 2)\) 乘 \(-1\) 得 \((-1,-2)\)，最大者从第 2 个变成第 1 个
    对不同的类用不同的变换 类与类之间的可比性被破坏 第 1 类乘 \(100\)，第 2 类不变，比较已经无意义
    加不同的常数到各类 相当于人为给某些类加分 第 1 类加 \(5\)，第 2 类加 \(0\) → 判决整体偏向第 1 类

    特别注意第二条：\(\tilde g_i = \varphi_i(g_i)\) 里下标 \(i\) 是跟着类走的， 这不是保序变换，判决通常会变 ✗

    怎么快速自检：把变换写成 \(\tilde g_i = a\,g_i + b\)（\(a \gt 0\)，\(b\) 与 \(i\) 无关）就安全； 只要 \(a\)、\(b\) 里出现了跟着类下标 \(i\) 变的东西，就必须重新验证 ⚠

    「加不同常数会变」为什么这么重要： 后验概率和先验有关，而先验正是「按类不同」的常数。 所以 \(\ln P(\omega_i)\) 看上去像「给某些类加分」， 它能留在判别函数里；而 \(-\ln p(x)\) 与类无关，只能被丢掉 ✓

    这里还有一条容易记反的结论： 给所有类加同一个常数 → 判决不变； 给不同类加不同常数 → 判决必变。 两者的区别只在「这个常数跟不跟 \(i\) 走」。

    2.3 一般形式¶

    本课程课件里还给出了一个更一般的写法：

    \[g_i(x) = f\bigl(p(x \mid \omega_i)\bigr) + h(x, \omega_i)\]

    符号说明：

    符号 含义 要求
    \(f(\cdot)\) 对密度的变换（如取对数） 必须是严格单调增的
    \(h(x, \omega_i)\) 附加项 只能含与类别有关或与 \(x\) 有关的合法组合

    怎么读懂它：\(f\) 负责把「连乘」变成「相加」（解决下溢）， \(h\) 负责塞进先验概率这类「与类别有关」的信息。

    这个写法为什么能覆盖前面两种形式：

    想要的形式 取 \(f\) 取 \(h\)
    去分母的乘积形式 \(f(u) = u\)（恒等，单调增） \(h = \ln P(\omega_i)\)（或直接乘）
    取对数形式 \(f(u) = \ln u\) \(h = \ln P(\omega_i)\)
    只要序的抽象形式 任意严格单调增函数 任意与类有关的合法项

    注意 \(h(x, \omega_i)\) 里 \(x\) 的位置： 如果 \(h\) 中含有一项与类别无关的 \(h_0(x)\)，那么它对所有类都一样， 在做差时会自动消掉 —— 这正是下面第四节「决策面方程」能化简的根源 ✓

    「与类别无关」的项只能丢，不能改

    \(h_0(x)\) 这一类项与类别下标 \(i\) 无关，所以做差时抵消， 丢掉它完全合法。

    但要小心两种误用：

    误用 后果
    只对一部分类丢掉这一项 相当于给一部分类偷偷减了一项
    把 \(h_0(x)\) 换成一个与 \(x\) 有关但当次不同的函数 决策面形状可能整体改变，必须重新推导

    判断口诀：先问「这一项里有没有 \(i\)」，再决定能不能丢 ✓

    两条由本课程课件沿用的记法约定：

    记法 含义
    \(g_i\) 下标 \(i\) 永远指「第 \(i\) 类」 不许让 \(i\) 去表示样本序号，否则与类别标号混淆
    判决写成 \(\arg\max_i g_i(x)\) 只关心下标，不关心最大值的大小

    三、从后验导出的三个等价判别函数¶

    现在按由「精确」到「好用」的顺序，逐个写出三个判别函数， 并说明它们判决结果完全一致。

    3.1 形式一：直接用后验概率¶

    \[g_i(x) = P(\omega_i \mid x), \qquad i = 1, 2, \dots, c\]

    这是最「标准」的一组 —— 它的值有明确含义（就是概率）， 范围在 \([0,1]\)，\(c\) 个值加起来正好是 1。

    优点：可解释性最强，能直接回答「有多大的把握」。

    缺点：必须算分母 \(p(x)\)，而 \(p(x)\) 是 \(c\) 项的求和。 类别数 \(c\) 很大时，每个样本都要多算这一圈。

    更麻烦的是：\(c\) 个后验都算出来之后， 其实只用在里面找最大的一个 —— 分母白算了。

    3.2 形式二：去掉分母（最常用）¶

    \[g_i(x) = p(x \mid \omega_i)\,P(\omega_i), \qquad i = 1, 2, \dots, c\]

    怎么从形式一得到它：把贝叶斯公式代进形式一，得到

    \[g_i(x) = \frac{p(x \mid \omega_i)P(\omega_i)}{p(x)}\]

    这里 \(p(x)\) 与 \(i\) 无关，是 \(c\) 个类共用的同一个正数。 除以同一个正数不改变大小关系，于是可以直接把它删掉 ✓

    注意 \(g_i\) 现在不是概率了：它可能大于 1， \(c\) 个值加起来也不再是 1。但这完全不影响判决 —— 判别函数只需要保持序，不需要是概率 ⚠

    这是实际实现里最常用的一组，因为它既省掉了分母， 又避免了取对数带来的额外开销。

    3.3 形式三：取对数（数值最稳）¶

    \[g_i(x) = \ln p(x \mid \omega_i) + \ln P(\omega_i)\]

    怎么从形式二得到它：形式二是一个乘积， 对它整体取对数，乘积就变成求和：

    \[\begin{aligned} \ln\Bigl[p(x\mid\omega_i)\,P(\omega_i)\Bigr] &= \ln p(x\mid\omega_i) + \ln P(\omega_i) \end{aligned}\]

    这里用到了对数的两条基本性质：

    性质 式子 在这里的作用
    乘积的对数 = 对数之和 \(\ln(ab) = \ln a + \ln b\) 把连乘变成连加，解决下溢
    对数函数单调增 \(a \gt b \gt 0 \Rightarrow \ln a \gt \ln b\) 保证大小关系不变

    为什么开发时最偏爱它：\(d\) 维独立时密度是 \(d\) 个数的连乘， 取对数之后变成 \(d\) 个数的加法。 加法不会下溢，而且每一项都可以单独计算、单独检查 ✓

    注意符号方向：\(\ln\) 的值都是负的（因为密度和先验都小于 1）， 所以判别函数值常常见到 \(-3.5\) 这种负数。 这没关系 —— 我们只比大小，\(-3.5 \gt -4.2\) 照样成立 ✓

    三者一张总表：

    形式 表达式 值的身份 需要分母吗 数值风险 常用度
    一 \(P(\omega_i\mid x)\) 概率，和恒为 1 需要 低 少
    二 \(p(x\mid\omega_i)P(\omega_i)\) 加权密度，可大于 1 不需要 高维下溢 最常用
    三 \(\ln p(x\mid\omega_i) + \ln P(\omega_i)\) 负对数，通常为负 不需要 无下溢 数值首选

    3.4 三者的等价性：手算一个例子¶

    取一个两类的例子：\(x = (3.5, 12.0)\)， 两个类的均值分别是 \((3.0, 10.0)\) 与 \((6.0, 14.0)\)， 共用方差 \(4.0\)，先验分别是 \(0.6\) 与 \(0.4\)。

    先把它化成独立的一维问题：两类共用协方差 \(\Sigma = 4I\)， 所以二次型可以按维拆开算。先算两个偏差向量：

    \[x - \mu_1 = (3.5-3.0,\ 12.0-10.0)^{\mathsf{T}} = (0.5,\ 2.0)^{\mathsf{T}}\]
    \[x - \mu_2 = (3.5-6.0,\ 12.0-14.0)^{\mathsf{T}} = (-2.5,\ -2.0)^{\mathsf{T}}\]

    再算两个马氏距离平方（\(\Sigma^{-1} = \frac{1}{4}I\)， 所以每一维的偏差先平方、求和、再除以 \(4\)）：

    \[r_1^2 = \frac{0.5^2 + 2.0^2}{4} = \frac{0.25 + 4.00}{4} = \frac{4.25}{4} = 1.0625\]
    \[r_2^2 = \frac{(-2.5)^2 + (-2.0)^2}{4} = \frac{6.25 + 4.00}{4} = \frac{10.25}{4} = 2.5625\]

    接着算取对数的类条件密度。 二维正态密度的对数里，常数项 \(-\ln(2\pi) - \ln 4\) 与类别无关，先记作 \(-c\)：

    \[\ln p(x\mid\omega_1) = -c - \frac{1}{2}r_1^2, \qquad \ln p(x\mid\omega_2) = -c - \frac{1}{2}r_2^2\]

    （这一步的依据见第 6.2 节的多元正态密度公式： 指数里就是 \(-\frac{1}{2}r^2\)，前面的归一化常数取对数后是常数。）

    代进形式三：

    \[g_1 = -c - 0.53125 + \ln 0.6 = -c - 0.53125 - 0.510826 = -c - 1.042076\]
    \[g_2 = -c - 1.28125 + \ln 0.4 = -c - 1.28125 - 0.916291 = -c - 2.197541\]

    两类相减时 \(-c\) 自动消掉：

    \[g_1 - g_2 = (-c - 1.042076) - (-c - 2.197541) = 1.155465 \gt 0\]

    判为 \(\omega_1\) ✓

    用形式二再算一遍，看能不能得到同一个结论。 形式二要拿到具体的密度值，所以常数项这次不能丢： \(c\) 的具体值是

    \[c = \ln(2\pi) + \ln 4 = 1.837877 + 1.386294 = 3.224171\]

    于是

    \[g_1 = e^{-3.224171 - 0.53125} \times 0.6 = 0.023442 \times 0.6 = 0.014065\]
    \[g_2 = e^{-3.224171 - 1.28125} \times 0.4 = 0.011182 \times 0.4 = 0.004473\]

    两者的比值：

    \[\frac{g_1}{g_2} = \frac{0.014065}{0.004473} \approx 3.145, \qquad e^{1.155465} \approx 3.175\]

    两个数在舍入误差范围内一致 —— 因为形式三就是形式二取了对数，\(e^{g_1-g_2}\) 当然等于两个乘积的比 ✓ （手算到 6 位有效数字，\(3.145\) 与 \(3.175\) 的差异全部来自中间乘积的舍入。）

    再用形式一验证第三遍。形式一要把两个加权密度归一化：

    \[p(x) = g_1 + g_2 = 0.014065 + 0.004473 = 0.018538\]
    \[P(\omega_1\mid x) = \frac{0.014065}{0.018538} = 0.758705, \qquad P(\omega_2\mid x) = \frac{0.004473}{0.018538} = 0.241287\]

    三种形式的手算结果并排放在一起：

    形式 第 1 类的值 第 2 类的值 谁大 比值
    一：后验概率 \(0.758705\) \(0.241287\) 第 1 类 \(3.144\)
    二：去分母乘积 \(0.014065\) \(0.004473\) 第 1 类 \(3.145\)
    三：取对数 \(-c - 1.042076\) \(-c - 2.197541\) 第 1 类 差 \(1.155465\)

    三个形式给出的数值完全不同（一个是概率、一个是乘积、一个是负对数）， 但一致地指向第 1 类 ✓

    还能再验证一件事：形式一与形式二的比值恒定。 把两行相除，公共分母 \(p(x) = 0.018538\) 正好约掉，所以两个比值必然相等 —— 上面的 \(3.144\) 与 \(3.145\) 就是这么来的。

    这说明什么：以后看到「同一个样本、三种不同的数」不要慌， 只要把它们都看成对同一个序的三种编码，判决就一定一致。 考试里真正会被考的只有两件事： 形式之间怎么互相推、以及哪些项可以丢 ✓

    三个形式等价，不等于可以随便混着用

    三条必须守住的规矩：

    规矩 违反的后果
    同一个样本的各个类，必须用同一个形式 拿第 1 类的后验和第 2 类的对数比大小，结果毫无意义
    比大小的对象必须是同一类别集合 类别集合变了，判决当然变
    等号（并列）需要有明确的处理规则 浮点下几乎不会精确相等，行为取决于实现的比较顺序

    第三条在实现时特别要注意：规则必须先定下来。 要么定一个容差 \(\varepsilon\)，两个值之差小于 \(\varepsilon\) 时按固定规则裁决； 要么干脆规定「并列时判给下标最小的类」。 不写这条规则，同一个样本换台机器可能得到不同结果 ⚠

    例题 1：三种形式的等价性证明¶

    题目：设两类的判别函数取形式二

    \[g_i(x) = p(x\mid\omega_i)P(\omega_i), \qquad i = 1, 2\]

    而先验相等 \(P(\omega_1) = P(\omega_2) = 0.5\)。

    (a) 证明此时判决退化为「比较类条件密度」。 (b) 若改成比较 \(\ln g_i(x)\)，判决会不会变？为什么？ © 若只对第 1 类取对数、第 2 类保持原样，判决会怎样？

    思路

    前两问都在考「保序变换」这一件事： 先让读者认出「乘同一个常数」和「过同一个单调增函数」两种保序操作。 第三问是反例，用来检验「必须对所有类施加同一个变换」这条红线。

    解答

    （a）先验相等时退化为比密度

    先验相等，于是两个判别函数里的共同因子 \(0.5\) 是同一个正数：

    \[g_1(x) = 0.5\,p(x\mid\omega_1), \qquad g_2(x) = 0.5\,p(x\mid\omega_2)\]

    比较 \(g_1\) 与 \(g_2\) 就是比较

    \[0.5\,p(x\mid\omega_1) \gt 0.5\,p(x\mid\omega_2)\]

    两边同除以正数 \(0.5\)，得

    \[p(x\mid\omega_1) \gt p(x\mid\omega_2)\]

    所以判决退化成「谁的类条件密度大就判谁」 ✓ 这就是最大似然判决：先验不提供任何偏向时，只能听数据的。

    （b）取对数不改变判决

    \(\ln\) 在正数上严格单调增，而 \(g_i \gt 0\)（密度与先验都为正）， 所以对两个类同时取对数是一个保序变换：

    \[g_1 \gt g_2 \ \Longleftrightarrow\ \ln g_1 \gt \ln g_2\]

    由第 2.2 节的性质，判决完全不变 ✓

    （c）只对第 1 类取对数会出问题

    这时新的判别函数是

    \[\tilde g_1 = \ln g_1, \qquad \tilde g_2 = g_2\]

    两者已经不是同一把尺子。举一个具体数字： 取 \(g_1 = 0.6\)、\(g_2 = 0.5\)，原本 \(g_1 \gt g_2\)，判第 1 类； 变换后 \(\tilde g_1 = \ln 0.6 = -0.510826\)，而 \(\tilde g_2 = 0.5\)， 于是 \(\tilde g_1 \lt \tilde g_2\)，判决翻转成第 2 类 ✗

    原因：\(\ln\) 把 \((0,1)\) 的数映射到 \((-\infty, 0)\)， 而 \(g_2\) 还留在 \((0,1)\) —— 一边被压到负数区、一边留在正数区， 大小关系当然被破坏。

    这个结论说明什么：等价性从来不是「某个函数的性质」， 而是「同一变换同时施加于所有类」这条纪律的性质 ⚠

    例题 2：先验变化怎么推动决策面（一维手算）¶

    题目：一维两类问题，两类都服从等方差正态分布， 均值 \(\mu_1 = 170\)、\(\mu_2 = 178\)，共用标准差 \(\sigma = 6\)。

    (a) 先验 \((0.5, 0.5)\) 时决策面在哪？ (b) 先验改成 \((0.3, 0.7)\) 后决策面移到哪里？移动了多少？ © 移动方向有没有规律？

    思路

    直接用「两类等方差、一维正态」的决策面闭式解：

    \[x_0 = \frac{\mu_1+\mu_2}{2} - \frac{\sigma^2}{\mu_1-\mu_2} \ln\frac{P(\omega_1)}{P(\omega_2)}\]

    这个公式下一节会给出完整推导，这里先用结论。 注意分母是 \(\mu_1 - \mu_2\)（不是 \(\mu_2 - \mu_1\)）， 符号搞错会让决策面跑错一边 ⚠

    解答

    （a）先验相等

    \[\ln\frac{0.5}{0.5} = \ln 1 = 0\]

    第二项为零，只剩中点：

    \[x_0 = \frac{170+178}{2} = \frac{348}{2} = 174\]

    决策面在 \(x = 174\)，正好是中点 ✓

    （b）先验 \((0.3, 0.7)\)

    先算对数项：

    \[\ln\frac{0.3}{0.7} = \ln 0.428571 = -0.847298\]

    再算系数：

    \[\frac{\sigma^2}{\mu_1-\mu_2} = \frac{36}{170-178} = \frac{36}{-8} = -4.5\]

    代进公式：

    \[x_0 = 174 - (-4.5)\times(-0.847298) = 174 - 3.812841 = 170.187159\]

    决策面移到 \(x = 170.19\)（保留两位小数）✓

    （c）移动方向

    \[170.187159 - 174 = -3.812841\]

    也就是向左移动了 \(3.81\)，朝着先验更小的第 1 类（均值 \(170\)）那边。

    一般规律：先验大的那一类，决策面向对方移动。 因为先验大意味着它的判别函数被整体抬高、地盘变大， 分界线自然要往对方那边让。 反过来说，先验小的那一类会被「牺牲」一部分地盘 ✓

    把四组先验的手算结果列成对照表（这就是原来「代码扫参数打印表」的位置）：

    先验 \((P_1, P_2)\) \(\ln(P_1/P_2)\) \(-\frac{\sigma^2}{\mu_1-\mu_2}\ln\frac{P_1}{P_2}\) 决策面 \(x_0\) 相对中点 \(174\) 的位移
    \((0.5, 0.5)\) \(0\) \(0\) \(174.000\) \(0\)
    \((0.4, 0.6)\) \(-0.405465\) \(-1.824593\) \(172.175\) \(-1.825\)
    \((0.3, 0.7)\) \(-0.847298\) \(-3.812841\) \(170.187\) \(-3.813\)
    \((0.2, 0.8)\) \(-1.386294\) \(-6.238324\) \(167.762\) \(-6.238\)

    读这张表的三个要点：

    观察 结论
    先验比越小（第 1 类越不受待见） 决策面越往第 1 类中心靠，第 1 类地盘越小
    先验相等时位移恰好为 \(0\) 对称性：两类完全对称则分界居中
    位移与 \(\ln(P_1/P_2)\) 成正比 因为公式里它就是一次项，没有高阶项

    一个容易忽略的比例关系：位移量 \(= 4.5 \times \lvert\ln(P_1/P_2)\rvert\)。 这里的 \(4.5 = \sigma^2/\lvert\mu_1-\mu_2\rvert = 36/8\)， 完全由数据的尺度决定，与先验无关 ✓ 所以先验每变化多少、边界移动多少，是可以快速口算的。

    四、决策面与决策边界¶

    前面讲的都是「给定一个 \(x\)，怎么判」。 这一节换个视角问一个几何问题：

    特征空间里的点被分成几块？它们之间的分界线长什么样？

    这个问题看起来只是「换个说法」，其实很有用 —— 它让我们能画图、能预判形状、能一眼看出某个分类器的能力上限。

    4.1 决策区域：把特征空间切块¶

    定义（决策区域）：对 \(c\) 类问题， 按判决规则可以把 \(d\) 维特征空间分成 \(c\) 个区域

    \[R_1, R_2, \dots, R_c\]

    其中 \(R_i\) 是「所有会被判为 \(\omega_i\) 的点」组成的集合：

    \[R_i = \bigl\{x \;\big|\; g_i(x) \gt g_j(x) \ \text{对所有} \ j \neq i\bigr\}\]

    怎么读这个定义：\(R_i\) 就是第 \(i\) 类的「地盘」。 任何一个落进 \(R_i\) 的样本都会被判成 \(\omega_i\)。

    两条必须点明的性质：

    性质 说明
    覆盖性 每个点至少属于一个区域（否则判决规则有漏洞）
    互斥性 一个点不会同时落进两个区域，因为「严格大于所有 \(j\neq i\)」最多对一个 \(i\) 成立

    关于等号归哪边：判决规则用的是严格不等号 \(\gt\)， 所以「两个判别函数恰好相等」的点不属于任何区域， 它们正好落在下一段要讲的决策面上。

    实践中的处理：计算机里两个浮点数几乎不会精确相等， 所以这类点实际上由实现的比较顺序决定（先比到的赢）。 要做成确定性的分类器，必须显式规定： 相等时判给下标最小的类，或判给先验最大的类 ✓

    4.2 决策面：区域的边界¶

    定义（决策面 / 决策边界）： 分隔两个相邻决策区域 \(R_i\) 与 \(R_j\) 的点集，称为决策面， 其方程是

    \[g_i(x) = g_j(x)\]

    怎么读这个式子：决策面就是「两个类的判别函数打成平手」的地方。 在这张面上，判成哪一类都说得通，所以它是一条分界线。

    决策面是超曲面：当特征维数是 \(d\) 时， 一个等式约束通常把一个 \(d\) 维空间切出一张 \((d-1)\) 维的面：

    特征维数 \(d\) 决策面的几何形状 若判别函数是线性的
    \(1\) 一些分界点 一个点
    \(2\) 一些曲线（或曲线段） 一条直线
    \(3\) 一些曲面（或曲面片） 一个平面
    \(d\) 一些超曲面（或超曲面片） 一个超平面

    注意「曲线段」这个词：决策面不一定是完整的一条曲线， 它可能被别的类的区域切断，只剩中间一段。 三类以上时这种情况很常见 ✓

    为什么要求「相邻」：如果 \(R_i\) 与 \(R_j\) 根本不相邻， 它们之间隔着第三个类的区域，那么 \(g_i = g_j\) 的点集里 有一部分落在别的区域内部，不构成真正的边界。 所以严格说，决策面是 \(g_i = g_j\) 那个点集里落在两个区域交界处的那一部分 ⚠

    4.3 两类情形：只需要一个判别函数¶

    两类是最常用也最重要的情形。它的特别之处在于： \(c = 2\) 时那两个判别函数 \(g_1, g_2\) 必然一高一低， 所以没有必要分别算两个数再比 —— 直接看差就行。

    定义：

    \[g(x) = g_1(x) - g_2(x)\]

    判决规则：

    \[g(x) \gt 0 \ \Rightarrow\ \text{判为 } \omega_1; \qquad g(x) \lt 0 \ \Rightarrow\ \text{判为 } \omega_2; \qquad g(x) = 0 \ \Rightarrow\ \text{落在决策面上}\]

    怎么读：\(g \gt 0\) 就是 \(g_1 \gt g_2\)，也就是第 1 类赢。 把「比较两个数」变成「看一个数的符号」，实现上更省事 ✓

    两类与多类的差别一张表说清：

    对比项 两类 \(c=2\) 多类 \(c \geq 3\)
    判别函数个数 可以只保留 1 个（差式） 必须保留 \(c\) 个
    判决方式 看符号 取最大值
    决策面 一条方程 \(g(x)=0\) 最多 \(c(c-1)/2\) 对两两界面
    计算量 省一半 不省

    关于「最多 \(c(c-1)/2\) 对」：\(c\) 个类两两配对共有 \(C_c^2 = c(c-1)/2\) 种组合， 但是否每一对都真的形成一段边界，要看这两个类的区域是否相邻。 很多对其实被第三个类隔开，不出现在最终的分界图上 ✓

    把几种常见的 \(g(x)\) 写出来：

    依据 \(g(x)\) 的写法
    后验之差 \(g(x) = P(\omega_1 \mid x) - P(\omega_2 \mid x)\)
    去分母（最常用） \(g(x) = p(x \mid \omega_1)P(\omega_1) - p(x \mid \omega_2)P(\omega_2)\)
    取对数 \(g(x) = \ln\dfrac{p(x\mid\omega_1)}{p(x\mid\omega_2)} + \ln\dfrac{P(\omega_1)}{P(\omega_2)}\)
    风险之差（最小风险时） \(g(x) = R(\alpha_1 \mid x) - R(\alpha_2 \mid x)\)

    注意最后一行：用风险之差时，\(g(x)\) 越小越好 （风险越小越好），所以判决规则变成「\(g(x) \lt 0\) 判 \(\omega_1\)」。 它和前三行符号习惯相反。 这两种习惯在文献里都有人用，看公式时先确认大者判哪一类 ⚠

    「几个判别函数」与「一个差式」的对应关系：

    两类的说法 差式的说法 等价条件
    \(g_1(x) \gt g_2(x)\) \(g(x) \gt 0\) 定义 \(g = g_1 - g_2\)
    \(g_1(x) \lt g_2(x)\) \(g(x) \lt 0\) 同上
    两个函数打平 \(g(x) = 0\) 同上
    区域 \(R_1\) \(\{x : g(x) \gt 0\}\) 同上

    4.4 决策面方程：本页的核心¶

    两类的决策面是「两个判别函数相等」的点集：

    \[g_1(x) = g_2(x)\]

    把它移项，就得到著名的决策面方程：

    \[g(x) = g_1(x) - g_2(x) = 0\]

    这两个写法完全等价，只是后者更便于计算。它的含义有三层：

    层次 内容
    代数上 解一个方程，解集就是决策面
    几何上 \(g(x)=0\) 是 \(g\) 的一条零水平集（等值线或等值面）
    实践上 只要 \(g\) 的形式确定了，决策面的形状就确定了

    下面这张图把「判别函数」与「决策面」画在同一张坐标系里， 请重点看三件事：曲线穿过横轴的那一点、横轴上下两侧的判类、 以及「切掉曲线换一条形状完全不同、但零点不变的曲线，分界仍然一样」：

    图上要读出的三个信息：

    图上元素 含义
    那条斜线 \(g(x)\) 判别函数本身，取值随 \(x\) 变化
    它与横轴的交点 决策面，即 \(g(x) = 0\) 的那一点
    交点左右两侧 \(g \gt 0\) 判第 1 类，\(g \lt 0\) 判第 2 类

    必须强调的一点：决策面只由「\(g(x) = 0\)」这个方程决定， 与 \(g(x)\) 在别处的具体数值完全无关 ⚠

    为什么能这么说：判别函数的职责只是「比大小」， 换成 \(50g(x)\)、\(g(x)+7\)、\(e^{g(x)}\)（前提还有零点的位置）， 决策区域一个点都不会变。 决策面作为区域的边界，自然也不变。

    但有一处需要小心：「\(g(x)=0\)」这个写法默认了 决策面对应 \(g\) 的零水平集。如果我们手上是原判别函数 \(g_1\) 与 \(g_2\)，而决策面方程写的是 \(g_1 = g_2\)， 这时没有单独的 \(g\)，就不能写成 \(g(x) = 0\)。

    安全写法：先定义差式 \(g = g_1 - g_2\)， 再写 \(g(x) = 0\)。这样零水平集与决策面必然重合 ✓

    一维情形的手算：两类都是一维正态，均值 \(170\) 与 \(178\)， 共用标准差 \(6\)（这就是例题 2 的数据）。 把取对数后的差式写出来：

    \[\begin{aligned} g(x) &= g_1(x) - g_2(x) \\ &= \Bigl[-\tfrac{1}{2}\Bigl(\tfrac{x-170}{6}\Bigr)^2 - c\Bigr] - \Bigl[-\tfrac{1}{2}\Bigl(\tfrac{x-178}{6}\Bigr)^2 - c\Bigr] + \ln 0.5 - \ln 0.5 \\ &= -\tfrac{1}{2}\Bigl(\tfrac{x-170}{6}\Bigr)^2 + \tfrac{1}{2}\Bigl(\tfrac{x-178}{6}\Bigr)^2 \end{aligned}\]

    第二步做了两件事： 两个 \(-c\) 相互抵消（\(c\) 与类别无关）， 先验相等所以 \(\ln P\) 那两项也抵消 ✓

    代入 \(x = 174\) 验证决策面：

    \[g(174) = -\tfrac{1}{2}\Bigl(\tfrac{174-170}{6}\Bigr)^2 + \tfrac{1}{2}\Bigl(\tfrac{174-178}{6}\Bigr)^2 = -\tfrac{1}{2}(0.444444)^2 + \tfrac{1}{2}(0.444444)^2 = 0 ✓\]

    再取两边各一个点确认符号：

    \[g(170) = -\tfrac{1}{2}(0)^2 + \tfrac{1}{2}\Bigl(\tfrac{-8}{6}\Bigr)^2 = 0 + \tfrac{1}{2}(1.777778) = 0.888889 \gt 0 \Rightarrow \text{判 } \omega_1\]
    \[g(178) = -\tfrac{1}{2}(1.777778) + \tfrac{1}{2}(0)^2 = -0.888889 \lt 0 \Rightarrow \text{判 } \omega_2\]

    这就是「决策面是一个点」在一维里的样子： \(x \lt 174\) 判第 1 类，\(x \gt 174\) 判第 2 类，\(x = 174\) 落在面上 ✓

    把闭式解与手算结果并排核对：

    先验 闭式解给出的 \(x_0\) 手算 \(g(x_0)\) 是否为零
    \((0.5, 0.5)\) \(174.000000\) \(0\) 是 ✓
    \((0.3, 0.7)\) \(170.187159\) \(0\) 是 ✓

    顺便要在这里提醒一个易错点：

    「判别函数不唯一」这件事后面会一直用到

    本节给出的三种形式 \(P(\omega_i\mid x)\)、 \(p(x\mid\omega_i)P(\omega_i)\)、\(\ln p + \ln P\) 是同一组东西的三种写法， 它们判决结果完全相同。

    这一点在下一节特别重要：下一节会给出好几种 「看起来完全不一样」的判别函数 （最近距离分类器、线性判别函数、二次判别函数……）， 它们的形式差异极大，甚至有一项在这一种里被整项丢掉。

    丢掉一项为什么还能等价？ 因为被丢掉的那项 与类别下标 \(i\) 无关，对所有类都是同一个值， 比大小时自动抵消 ✓

    所以看到两个判别函数「长得不一样」时， 第一件事是问：差的那一项与类别有关吗？ 与类别无关就是等价的。

    一个可以随手用的检查：把两个待比较的式子相减， 如果结果恒等于 0（对任意 \(x\)）， 那它们就是同一个判别函数；如果差出来的是保序变换， 判决也仍然相同 ⚠

    五、从贝叶斯到决策面的完整推导¶

    这一节把线索接起来：从贝叶斯公式出发，一步步导出决策面方程， 中间每一步都写清楚。

    5.1 出发点：两类、取对数的判别函数¶

    两类情形，用 3.3 节的取对数形式：

    \[g_1(x) = \ln p(x \mid \omega_1) + \ln P(\omega_1)\]
    \[g_2(x) = \ln p(x \mid \omega_2) + \ln P(\omega_2)\]

    为什么选这两个：取对数后没有下溢风险， 而且两式相减时结构最清楚。

    5.2 相减：常数项自动合并¶

    按 4.3 节的定义取差：

    \[\begin{aligned} g(x) &= g_1(x) - g_2(x) \\ &= \Bigl[\ln p(x \mid \omega_1) + \ln P(\omega_1)\Bigr] - \Bigl[\ln p(x \mid \omega_2) + \ln P(\omega_2)\Bigr] \end{aligned}\]

    把括号拆开、重新分组：

    \[\begin{aligned} g(x) &= \ln p(x \mid \omega_1) + \ln P(\omega_1) - \ln p(x \mid \omega_2) - \ln P(\omega_2) \\ &= \Bigl[\ln p(x \mid \omega_1) - \ln p(x \mid \omega_2)\Bigr] + \Bigl[\ln P(\omega_1) - \ln P(\omega_2)\Bigr] \end{aligned}\]

    这一步只是把同类项归拢，没有任何近似。

    5.3 把两个括号写成比值¶

    用对数的差等于商的对数：\(\ln a - \ln b = \ln(a/b)\)，得

    \[g(x) = \ln\frac{p(x\mid\omega_1)}{p(x\mid\omega_2)} + \ln\frac{P(\omega_1)}{P(\omega_2)}\]

    这就是本课程课件上那个式子 ✓ 现在逐项读懂它：

    项 名字 作用
    \(\ln\dfrac{p(x\mid\omega_1)}{p(x\mid\omega_2)}\) 似然比的对数 由观测数据决定，随 \(x\) 变化
    \(\ln\dfrac{P(\omega_1)}{P(\omega_2)}\) 先验比的对数 由先验知识决定，是一个常数（与 \(x\) 无关）

    这个分解非常有价值，因为它把「证据」和「偏见」分开了：

    情形 谁主导 结果
    似然比很大（数据强烈偏向第 1 类） 第一项主导 即使先验不利也判第 1 类
    似然比接近 1（数据说不清） 第二项主导 由先验决定，谁先验大判谁
    先验相等 \(P(\omega_1) = P(\omega_2)\) 第二项 = 0 退化成最大似然判决 ✓

    「似然比接近 1」为什么等于「数据说不清」： 似然比 \(= p(x\mid\omega_1)/p(x\mid\omega_2)\)。 它等于 1 表示两类的密度在这个点上一样大， 数据对两个类不偏不倚，此时第二项就成了唯一的裁决者 ✓

    5.4 让 \(g(x) = 0\)：得到决策面方程¶

    令

    \[\ln\frac{p(x\mid\omega_1)}{p(x\mid\omega_2)} + \ln\frac{P(\omega_1)}{P(\omega_2)} = 0\]

    移项。先把第二项移到右边：

    \[\ln\frac{p(x\mid\omega_1)}{p(x\mid\omega_2)} = -\ln\frac{P(\omega_1)}{P(\omega_2)}\]

    再用「负号可以翻进对数里面」这一步：\(-\ln a = \ln(1/a)\)，于是

    \[\ln\frac{p(x\mid\omega_1)}{p(x\mid\omega_2)} = \ln\frac{P(\omega_2)}{P(\omega_1)}\]

    为什么这一步值得单独写：很多人直接把 \(-\ln(P_1/P_2)\) 当成 \(\ln(P_1/P_2)\) 用，最后得到倒过来的决策面 ✗

    两边取指数（\(e\) 的幂函数），消掉对数：

    \[\frac{p(x\mid\omega_1)}{p(x\mid\omega_2)} = \frac{P(\omega_2)}{P(\omega_1)}\]

    这就是决策面的「似然比等于常数」形式 —— 左端是数据给出的似然比，右端是一个不依赖 \(x\) 的常数阈值。

    怎么读：当两个类条件密度的比值恰好等于先验的反比时， 两类的后验正好打平，判决无从下手 —— 这正是决策面上的点 ✓

    把两边同时取倒数，得到另一个常见的等价写法：

    \[\frac{p(x\mid\omega_2)}{p(x\mid\omega_1)} = \frac{P(\omega_1)}{P(\omega_2)}\]

    两种写法等价，看哪种顺眼就用哪种 —— 但不能把分子分母写反，那样得到的是另一条线 ⚠

    用例题 2 的数字验一遍这个阈值形式。 \(\mu_1 = 170\)、\(\mu_2 = 178\)、\(\sigma = 6\)、先验 \((0.3, 0.7)\)。 阈值是

    \[\frac{P(\omega_2)}{P(\omega_1)} = \frac{0.7}{0.3} = 2.333333\]

    决策面位置 \(x_0 = 170.187159\)，代入左端：

    \[\frac{p(x_0\mid\omega_1)}{p(x_0\mid\omega_2)} = \exp\Bigl[\tfrac{1}{2}\Bigl(\tfrac{x_0-178}{6}\Bigr)^2 - \tfrac{1}{2}\Bigl(\tfrac{x_0-170}{6}\Bigr)^2\Bigr]\]

    先算两个标准化偏差：

    \[\frac{170.187159-178}{6} = \frac{-7.812841}{6} = -1.302140, \qquad \frac{170.187159-170}{6} = \frac{0.187159}{6} = 0.031193\]

    再算指数：

    \[\tfrac{1}{2}(-1.302140)^2 - \tfrac{1}{2}(0.031193)^2 = 0.847784 - 0.000487 = 0.847297\]

    取指数：\(e^{0.847297} = 2.333333\) ✓

    与阈值 \(2.333333\) 完全一致 —— 这就是「似然比等于先验反比」的数值证据 ✓

    5.5 关键一步：只要知道密度形式，就能化简成几何形状¶

    上面那个式子还是「密度之比」这种抽象形式。 要把它变成直线、曲线这样的几何对象，必须把密度的具体形式代进去。

    这是本节最重要的一句话：

    决策面的形状完全由类条件密度的形式决定。 密度形式定了，\(g(x)=0\) 就能化成具体的几何方程。

    类条件密度的假设 决策面的形状
    一维正态，等方差 一个分界点
    多元正态，协方差相同 一张超平面（直线/平面）
    多元正态，协方差不同 一张超二次曲面（抛物面/椭球面/双曲面等）
    非参数（不做分布假设） 形状任意，只能逐点判定

    具体的化简过程属于下一节（高斯密度下的判别函数）， 本节先把「化简是可能的」这件事说清楚： 因为正态密度的对数里只有 \(x\) 的二次项、一次项和常数项， 两类相减时二次项可能消掉、也可能不消掉 —— 这正是上面表格前两行的来源 ✓

    把「二次项消不消掉」这件事提前说透（这是下一节的主线索）：

    情形 \(x^{\mathsf{T}}\Sigma^{-1}x\) 这一项 做差后还剩什么 决策面
    两类协方差相同 两类完全相同 只剩一次项与常数项 超平面
    两类协方差不同 两类不同 二次项留着 超二次曲面

    为什么协方差相同时这一项会完全相同： 它是 \(x\) 的二次型，系数矩阵就是 \(\Sigma^{-1}\)。 两类共用同一个 \(\Sigma\)，于是系数矩阵也同一个， 整个二次型逐项相同，做差时自然消失 ✓

    为什么还要专门去求决策面？

    既然有了判别函数就能分类，决策面似乎是多余的 —— 不是。 它至少带来三个好处：

    好处 说明
    直观 一张图能看出分界线在哪、形状如何，比看一堆数字快得多
    便于分析 决策面的形状决定了分类器能表达多复杂的边界（能力上限）
    便于估计参数 有些算法直接估计决策面的参数，不必回头估计密度

    尤其第三点：很多实用算法根本不估计概率密度， 而是直接找一个决策面 —— 这条路叫判别式方法， 和「先估密度再用贝叶斯」这条生成式方法是两条平行的路线 ✓

    两条路线的差别一张表：

    对比项 生成式方法 判别式方法
    先做什么 先估 \(p(x\mid\omega_i)\) 与 \(P(\omega_i)\) 直接找一个 \(g(x)\)
    中间产物 有概率意义，可解释 没有概率意义，只有序
    需要的样本量 大（要估整个密度） 相对小（只估界面）
    本页的关系 第 1–3 节走的这条路 第 4–8 节逐渐转向这条路

    六、一元与多元正态分布¶

    决策面最经典的情形就是「各类都服从正态分布」。 这一节把正态密度的公式和符号准备齐，下一节直接拿来用。

    为什么正态分布值得这么重视（三条理由，本课程课件专门列了）：

    理由 说明
    熵最大 在给定均值和方差的所有分布中，正态分布的熵最大
    中心极限定理 大量独立随机变量之和趋近正态分布
    实际吻合 很多实际场景中，类别的特征分布确实接近正态

    第三条是最实用的：如果你只知道均值和方差， 选正态分布是最「不武断」的选择（熵最大意味着最少额外假设）✓

    6.1 单变量正态密度¶

    随机变量 \(x\) 服从均值为 \(\mu\)、方差为 \(\sigma^2\) 的正态分布，记作

    \[x \sim N(\mu, \sigma^2)\]

    它的概率密度函数是：

    \[p(x) = \frac{1}{\sqrt{2\pi}\,\sigma} \exp\left[-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^{2}\right]\]

    逐项解释这个公式：

    符号 名称 含义与取值
    \(x\) 自变量 任意实数，\(-\infty \lt x \lt +\infty\)
    \(\mu\) 均值 密度的峰值位置（左右对称轴），实数
    \(\sigma\) 标准差 必须 \(\sigma \gt 0\)，控制密度的宽窄
    \(\sigma^2\) 方差 \(\sigma\) 的平方，恒为正
    \(\frac{1}{\sqrt{2\pi}\,\sigma}\) 归一化常数 保证密度在全轴的积分等于 1
    \(\exp[\cdot]\) 指数函数 即 \(e^{(\cdot)}\)，把负的二次式映射到 \((0,1]\)

    先看指数里的那部分：记

    \[z = \frac{x - \mu}{\sigma}\]

    \(z\) 叫标准化变量，它回答的是 「这个点离均值有几个标准差远」。

    这里是第一次出现「用标准差做尺子」的思想， 请记住它 —— 第七节的马氏距离就是把这个思想推广到多维 ✓

    再逐项看几何含义：

    量的取值 密度的表现 几何解释
    \(x = \mu\) 取到最大值 \(\frac{1}{\sqrt{2\pi}\sigma}\) 峰值在均值处
    \(x = \mu \pm \sigma\) 降到峰值的 \(e^{-1/2} \approx 0.6065\) 倍 一个标准差处已明显下降
    \(x = \mu \pm 2\sigma\) 降到峰值的 \(e^{-2} \approx 0.135\) 倍 两个标准差处几乎到尾巴
    \(x = \mu \pm k\sigma\) 降到峰值的 \(e^{-k^2/2}\) 倍 以标准差为单位衡量远近
    \(\lvert x - \mu\rvert\) 变大 密度对称地趋近 0 两端各有一条尾巴

    关键洞察：密度的大小只依赖 \(|x-\mu|/\sigma\) 这一个量。 换句话说，在正态分布里， 「离均值几个标准差」完全决定了一个点的密度值 ⚠

    手算一次验证这张表：\(\mu = 170\)、\(\sigma = 6\)，取 \(x = 176\)。

    第一步，标准化变量：

    \[z = \frac{176-170}{6} = \frac{6}{6} = 1\]

    第二步，峰值密度（\(z = 0\) 处的值）：

    \[p(170) = \frac{1}{\sqrt{2\pi}\times 6} = \frac{1}{2.506628\times 6} = \frac{1}{15.039772} = 0.066490\]

    第三步，\(z = 1\) 处的密度：

    \[p(176) = 0.066490 \times e^{-1/2} = 0.066490 \times 0.606531 = 0.040329\]

    第四步，核对第四条结论 \(e^{-k^2/2}\)： 把两者相除

    \[\frac{p(176)}{p(170)} = 0.606531 = e^{-1/2} ✓\]

    第五步，一个经典结论：标准正态在一个标准差内的概率

    \[\int_{-1}^{1}\frac{1}{\sqrt{2\pi}}e^{-z^2/2}\,\mathrm{d}z = 0.682689\]

    上面那张表的四行，可以一次算出来核对（峰值、一个标准差处的密度、一个标准差内的概率）：

    6.2 多元正态密度¶

    现在把维数升到 \(d\) 维。\(x\) 是一个 \(d\) 维列向量：

    \[x = (x_1, x_2, \dots, x_d)^{\mathsf{T}}\]

    它服从均值向量 \(\mu\)、协方差矩阵 \(\Sigma\) 的多元正态分布，记作

    \[x \sim N(\mu, \Sigma)\]

    概率密度函数是：

    \[p(x\mid\omega_i) = \frac{1}{(2\pi)^{d/2}\,\lvert\Sigma_i\rvert^{1/2}} \exp\left[-\frac{1}{2}(x-\mu_i)^{\mathsf{T}}\Sigma_i^{-1}(x-\mu_i)\right]\]

    逐个符号解释（每一个都第一次出现，务必看清）：

    符号 名称 形状 含义与要求
    \(d\) 维数 标量 特征个数，正整数
    \(\mu_i\) 均值向量 \(d \times 1\) 第 \(i\) 类数据的中心，\(E\{x\} = \mu_i\)
    \(\Sigma_i\) 协方差矩阵 \(d \times d\) 描述各维的离散程度与相关性
    \(\lvert\Sigma_i\rvert\) 行列式 标量 必须 \(\gt 0\)（否则矩阵不可逆，密度无定义）
    \(\Sigma_i^{-1}\) 逆矩阵 \(d \times d\) 出现在指数里，见下
    \((x-\mu_i)\) 偏差向量 \(d \times 1\) 点相对于中心的偏移
    \((2\pi)^{d/2}\) 归一化因子 标量 保证全空间积分为 1
    \(\exp[\cdot]\) 指数函数 标量 与一维情形同理

    怎样把密度写成真值：\(E\{x\} = \mu_i\) 的意思是

    \[E\{x\} = \int_{\mathbb{R}^d} x\, p(x)\,\mathrm{d}x = \mu_i\]

    式子里的 \(x\) 是随机向量，积分是在整个 \(d\) 维空间上做的：

    \[\int_{-\infty}^{+\infty}\cdots\int_{-\infty}^{+\infty} p(x)\,\mathrm{d}x_1\cdots \mathrm{d}x_d = 1\]

    这就是「归一化」在 \(d\) 维时的样子 ✓

    公式里出现 \(\lvert\Sigma\rvert^{1/2}\) 的原因（不跳步地看一遍）： 把 \(x\) 沿 \(\Sigma\) 的主轴方向拉伸，密度要从「标准正态」变过来， 体积的放大倍数正好是 \(\lvert\Sigma\rvert^{1/2}\)， 所以归一化因子要除以它。

    展开成逐步的形式：

    步骤 式子 依据
    1 标准正态的密度是 \((2\pi)^{-d/2}\exp(-\tfrac{1}{2}z^{\mathsf{T}}z)\) 各维独立同分布相乘
    2 令 \(z = \Sigma^{-1/2}(x-\mu)\) 把椭球拉回球
    3 体积元变换 \(\mathrm{d}z = \lvert\Sigma\rvert^{-1/2}\mathrm{d}x\) 线性变换的雅可比行列式
    4 合并得密度 \(\propto \exp(-\tfrac{1}{2}(x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu))\) 代入 \(z^{\mathsf{T}}z\)

    这四步说明什么：多元正态密度就是「球对称的正态」 被 \(\Sigma^{1/2}\) 拉成椭球之后的样子， 而前面那个 \(\lvert\Sigma\rvert^{1/2}\) 就是从球到椭球的体积补偿 ✓

    6.3 指数里那一项：马氏距离的平方¶

    把指数里的二次型单独拎出来看：

    \[(x-\mu_i)^{\mathsf{T}}\Sigma_i^{-1}(x-\mu_i)\]

    先看一个具体数字：取 \(\mu = (2, 5)^{\mathsf{T}}\)， \(\Sigma = \begin{pmatrix}4 & 1\\ 1 & 9\end{pmatrix}\)， \(x = (3, 7)^{\mathsf{T}}\)：

    步骤 计算 结果
    偏差向量 \(x - \mu\) \((1, 2)^{\mathsf{T}}\)
    行列式 \(4\times 9 - 1\times 1\) \(35\)
    逆矩阵 \(\frac{1}{35}\begin{pmatrix}9 & -1\\ -1 & 4\end{pmatrix}\) \(\begin{pmatrix}0.257143 & -0.028571\\ -0.028571 & 0.114286\end{pmatrix}\)
    二次型 \((1,2)\Sigma^{-1}(1,2)^{\mathsf{T}}\) \(0.6\)

    把「二次型」那一行拆开算一遍，看它是怎么得到 \(0.6\) 的：

    先算 \(\Sigma^{-1}\) 乘偏差向量（矩阵乘向量，逐行做点积）：

    \[\begin{pmatrix}0.257143 & -0.028571\\ -0.028571 & 0.114286\end{pmatrix} \begin{pmatrix}1\\2\end{pmatrix} = \begin{pmatrix}0.257143\times 1 + (-0.028571)\times 2\\ -0.028571\times 1 + 0.114286\times 2\end{pmatrix} = \begin{pmatrix}0.200001\\ 0.200001\end{pmatrix}\]

    再左乘 \((x-\mu)^{\mathsf{T}} = (1, 2)\)：

    \[r^2 = 1\times 0.200001 + 2\times 0.200001 = 0.200001 + 0.400002 = 0.600003\]

    与表中的 \(0.6\) 一致（微小差异来自中间步骤只保留 6 位小数）✓

    这项的名字就是马氏距离的平方：

    \[\underbrace{(x-\mu_i)^{\mathsf{T}}\Sigma_i^{-1}(x-\mu_i)}_{r^2} = \bigl[d_M(x, \mu_i)\bigr]^2\]

    为什么它值得单独起个名字：因为它是一维情形里 \(\left(\frac{x-\mu}{\sigma}\right)^2\) 的直接推广 ——

    情形 用的「尺子」 平方后的量
    一维 \(\sigma\)（一个数） \(\left(\dfrac{x-\mu}{\sigma}\right)^2\)
    多维 \(\Sigma^{-1}\)（一个矩阵） \((x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu)\)

    一维是多维的退化情形：\(d = 1\) 时 \(\Sigma\) 就是一个数 \(\sigma^2\)， \(\Sigma^{-1} = 1/\sigma^2\)，二次型变成 \((x-\mu)\cdot\frac{1}{\sigma^2}\cdot(x-\mu) = \left(\frac{x-\mu}{\sigma}\right)^2\) ✓ 完全吻合。

    6.4 等密度轨迹：椭球¶

    定义（等密度轨迹）：密度 \(p(x)\) 取同一个值的所有 \(x\) 组成的集合。

    从多元正态密度公式可以看出：\(p(x)\) 只通过指数里那一项依赖 \(x\)， 前面的 \(\frac{1}{(2\pi)^{d/2}|\Sigma|^{1/2}}\) 是常数。 所以「密度相等」等价于「指数里那一项相等」 ✓

    这一步值得写清楚： 设 \(p(x) = K\exp(-r^2/2)\)，其中 \(K\) 与 \(x\) 无关。 若 \(p(x_1) = p(x_2)\)，则

    \[K\exp(-r_1^2/2) = K\exp(-r_2^2/2) \ \Longrightarrow\ \exp(-r_1^2/2) = \exp(-r_2^2/2) \ \Longrightarrow\ r_1^2 = r_2^2\]

    中间那一步两边同除以正数 \(K\)， 最后那一步用了指数函数的单调性（严格增，所以一一对应）✓

    于是等密度轨迹的方程是：

    \[(x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu) = \text{const}\]

    几何形状：这是一个超椭球面。特殊情况下（各方向扩散程度相同） 退化为超球面或圆形。

    椭球的轴由什么决定 —— 这是本节最容易混清的一点：

    几何量 由谁决定
    轴的方向 \(\Sigma\) 的特征向量
    轴的长度 \(\Sigma\) 的特征值（长度与特征值的平方根成正比）

    「轴长正比于 \(\sqrt{\lambda}\)」为什么是平方根： 等密度方程里出现的是 \(r^2\)，沿着第 \(i\) 个主轴走， 二次型等于 \((t^2/\lambda_i)\)（\(t\) 是沿该轴的位移长度）。 令它等于常数 \(c\)，得 \(t = \sqrt{\lambda_i c}\)， 所以长度与 \(\sqrt{\lambda_i}\) 成正比 ✓

    用具体数字感受一下：取一个两维协方差矩阵， 长短轴之比取 \(3:1\)，长轴方向与水平成 \(0.7\) 弧度。 沿三个方向各取一个点，看它们的欧氏距离与马氏距离：

    取点方式 欧氏距离 马氏距离 是否同一条等密度线
    \(+3u_1\)（长轴方向，走 \(3\)） \(3.0000\) \(1.000000\) 是 ✓
    \(-3u_1\)（长轴反方向，走 \(3\)） \(3.0000\) \(1.000000\) 是 ✓
    \(+1u_2\)（短轴方向，走 \(1\)） \(1.0000\) \(1.000000\) 是 ✓

    这张手算表说明三件事：

    行的对比 结论
    \(3u_1\) 与 \(-3u_1\) 欧氏距离相同、马氏距离相同 → 左右对称，方向无所谓
    \(3u_1\) 与 \(1u_2\) 欧氏距离一个是 \(3\)、一个是 \(1\)，但马氏距离都是 \(1\)
    三行的马氏距离 全为 \(1\)，所以三点在同一条等密度轨迹上

    第三行是最值得看的一行： \(3u_1\) 这个点离中心欧氏距离 \(3\)， 而 \(1u_2\) 这个点离中心欧氏距离只有 \(1\)， 但它们在同一个椭圆上（密度完全相同）。

    这说明一件事：

    欧氏距离在等密度轨迹这件事上会给出完全错误的印象

    如果只看欧氏距离，会觉得 \(1u_2\) 比 \(3u_1\) 「离中心近得多」。 但对这个高斯分布而言，两个点的密度一模一样。

    原因：椭圆的长轴方向「宽敞」，沿这个方向走很远密度才下降； 短轴方向「狭窄」，稍微偏离密度就掉下来。

    欧氏距离不知道这个差别，马氏距离知道 —— 这就是下一节的主题 ✓

    考试里这条最常见的考法： 给一个对角协方差矩阵、给两个候选点， 问「按欧氏距离谁近、按马氏距离谁近」。 正确的做法是逐维算偏差除以该维标准差、再求平方和， 不要只看坐标差的大小 ⚠

    6.5 协方差矩阵的性质¶

    本课程课件专门列了协方差矩阵的性质，这里逐条说清。

    定义：\(\Sigma = E\{(x-\mu)(x-\mu)^{\mathsf{T}}\}\)， 元素是 \(\sigma_{ij} = E\{(x_i-\mu_i)(x_j-\mu_j)\}\)。

    性质清单：

    编号 性质 含义
    1 实对称 \(\Sigma = \Sigma^{\mathsf{T}}\)，即 \(\sigma_{ij} = \sigma_{ji}\)
    2 正定 对任意非零向量 \(v\) 有 \(v^{\mathsf{T}}\Sigma v \gt 0\)
    3 可对角化 存在正交矩阵 \(\Phi\) 使 \(\Sigma = \Phi\Lambda\Phi^{\mathsf{T}}\)
    4 特征向量正交归一 \(\varphi_i^{\mathsf{T}}\varphi_j = 1\)（\(i=j\)），\(0\)（\(i\neq j\)）
    5 特征值非负 \(\lambda_i \geq 0\)；正定时严格 \(\gt 0\)
    6 特征值分解成和式 \(\Sigma = \sum_{i=1}^{d}\lambda_i\varphi_i\varphi_i^{\mathsf{T}}\)

    逐条解释：

    性质 1（实对称）怎么来的：协方差阵的元素满足

    \[\sigma_{ij} = E\{(x_i-\mu_i)(x_j-\mu_j)\} = E\{(x_j-\mu_j)(x_i-\mu_i)\} = \sigma_{ji}\]

    交换两个实数的乘法顺序不影响结果，所以矩阵必然对称 ✓

    性质 2（正定）：把二次型展开，它可以写成 \(E\{\bigl(v^{\mathsf{T}}(x-\mu)\bigr)^2\}\)， 是一个平方的期望，所以非负； 只要 \(x-\mu\) 不会恒垂直于 \(v\)，它就是严格正的 ✓

    为什么正定很重要： 密度公式里出现了 \(|\Sigma|\) 和 \(\Sigma^{-1}\)。 正定保证 \(|\Sigma| \gt 0\)（可逆），也保证密度不会退化到低维面上 ⚠ 如果 \(\Sigma\) 只是半正定（某个特征值为 0）， 说明数据其实被限制在一个低维子空间里，此时 \(d\) 维密度无定义。

    性质 3、6（对角化与求和式）：\(\Sigma = \Phi\Lambda\Phi^{\mathsf{T}}\)， 其中 \(\Phi = [\varphi_1, \varphi_2, \dots, \varphi_d]\) 是特征向量排成的矩阵， \(\Lambda = \mathrm{diag}(\lambda_1, \dots, \lambda_d)\) 是特征值排成的对角阵。

    求和式怎么来的：把 \(\Sigma = \Phi\Lambda\Phi^{\mathsf{T}}\) 按分块写成求和：

    \[\Sigma = \sum_{i=1}^{d}\lambda_i\,\varphi_i\varphi_i^{\mathsf{T}}\]

    怎么读：每一项 \(\lambda_i\varphi_i\varphi_i^{\mathsf{T}}\) 是一个只指向 \(\varphi_i\) 方向的秩 1 矩阵， 前乘系数 \(\lambda_i\) 就是那个方向的「强度」。 所以协方差矩阵是 \(d\) 个正交方向的强度叠加 ✓

    性质 4、5 的矩阵化写法：

    \[\Phi^{\mathsf{T}}\Phi = I \quad\Longrightarrow\quad \Phi^{-1} = \Phi^{\mathsf{T}}\]
    \[\Sigma\varphi_i = \lambda_i\varphi_i, \qquad \varphi_i^{\mathsf{T}}\Sigma\varphi_i = \lambda_i\]

    最后那个式子怎么来的： 在 \(\Sigma\varphi_i = \lambda_i\varphi_i\) 两边左乘 \(\varphi_i^{\mathsf{T}}\)， 再用 \(\varphi_i^{\mathsf{T}}\varphi_i = 1\) 得 \(\varphi_i^{\mathsf{T}}\Sigma\varphi_i = \lambda_i\varphi_i^{\mathsf{T}}\varphi_i = \lambda_i\) ✓

    还有一个常用的结论（对角化形式的推论）：把 \(\Sigma = \Phi\Lambda\Phi^{\mathsf{T}}\) 左右两边分别左乘 \(\Phi^{\mathsf{T}}\)、右乘 \(\Phi\)，得

    \[\Phi^{\mathsf{T}}\Sigma\Phi = \Lambda\]

    因为（一步一步写）：

    \[\begin{aligned} \Phi^{\mathsf{T}}\Sigma\Phi &= \Phi^{\mathsf{T}}\bigl(\Phi\Lambda\Phi^{\mathsf{T}}\bigr)\Phi \\ &= \bigl(\Phi^{\mathsf{T}}\Phi\bigr)\Lambda\bigl(\Phi^{\mathsf{T}}\Phi\bigr) \\ &= I\Lambda I = \Lambda \end{aligned}\]

    第二步用到了结合律（把括号挪位置不改变乘积）， 第三步用的是 \(\Phi^{\mathsf{T}}\Phi = I\) ✓

    这个式子说明：用 \(\Phi\) 当坐标变换矩阵， 可以把协方差矩阵变成对角阵 —— 也就是在新坐标系里各维互不相关。 这正是「主轴方向」这个说法的来历 ✓

    两条常用的数值关系（可以用来做自检）：

    关系 式子 手算自检的用法
    迹 = 特征值之和 \(\operatorname{tr}(\Sigma) = \sum_i \lambda_i\) 算出特征值后加一遍，对不上说明算错了
    行列式 = 特征值之积 \(\lvert\Sigma\rvert = \prod_i \lambda_i\) 同理，乘一遍即可

    手算一个二阶的例子：\(\Sigma = \begin{pmatrix}4 & 2\\ 2 & 3\end{pmatrix}\)。

    第一步，行列式：

    \[\lvert\Sigma\rvert = 4\times 3 - 2\times 2 = 12 - 4 = 8\]

    第二步，特征值（二阶用「迹与行列式」反解最快）： 迹 \(= 4+3 = 7\)，设两个特征值为 \(\lambda_1, \lambda_2\)，则

    \[\lambda_1 + \lambda_2 = 7, \qquad \lambda_1\lambda_2 = 8\]

    解这个方程组：把 \(\lambda_2 = 7-\lambda_1\) 代入第二个式子，

    \[\lambda_1(7-\lambda_1) = 8 \ \Longrightarrow\ \lambda_1^2 - 7\lambda_1 + 8 = 0\]
    \[ \lambda_1 = \frac{7 \pm \sqrt{49-32}}{2} = \frac{7 \pm \sqrt{17}}{2} = 5.561553 \ \text{或}\ 1.438447\]

    两个都是正数 → 矩阵正定 ✓

    第三步，核对两条数值关系：

    \[5.561553 + 1.438447 = 7.000000 = \operatorname{tr}(\Sigma) ✓\]
    \[5.561553 \times 1.438447 = 8.000000 = \lvert\Sigma\rvert ✓\]

    第四步，顺便得到白化变换的直觉： 取 \(W = \Lambda^{-1/2}\Phi^{\mathsf{T}}\)，

    \[\begin{aligned} W\Sigma W^{\mathsf{T}} &= \Lambda^{-1/2}\Phi^{\mathsf{T}} \bigl(\Phi\Lambda\Phi^{\mathsf{T}}\bigr) \bigl(\Lambda^{-1/2}\Phi^{\mathsf{T}}\bigr)^{\mathsf{T}} \\ &= \Lambda^{-1/2}\Phi^{\mathsf{T}}\Phi\Lambda\Phi^{\mathsf{T}} \Phi\Lambda^{-1/2} \\ &= \Lambda^{-1/2}\,\Lambda\,\Lambda^{-1/2} = I \end{aligned}\]

    关键的两步：\(\Phi^{\mathsf{T}}\Phi = I\)（正交性）， 以及对角阵的转置是自己（\(\Lambda^{\mathsf{T}} = \Lambda\)）✓

    这就解释了前面那句「特征值决定轴长」： 在 \(\Lambda\) 的坐标系里，各轴的标准差正好是 \(\sqrt{\lambda_i}\)。 所以特征值越大，那个方向的分布越宽 ✓ 本例里两个方向的标准差是 \(\sqrt{5.561553} = 2.358\) 与 \(\sqrt{1.438447} = 1.199\)， 长短之比约 \(1.97:1\) —— 椭圆已经相当扁了。

    七、马氏距离：为什么不能只用欧氏距离¶

    这一节是全文最实用的一段。前面反复出现的那个二次型， 现在给它一个正式名字，并说明它为什么非有不可。

    7.1 定义¶

    定义（马氏距离）：样本 \(x\) 到中心 \(\mu\) 的马氏距离是

    \[d_M(x, \mu) = \sqrt{(x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu)}\]

    符号说明：\(\Sigma\) 是这组数据（或这一类数据）的协方差矩阵， 必须正定可逆。

    怎么读这个定义： 把它和一维的情形并排看，就明白它在干什么 ——

    维数 距离形式 在度量什么
    一维 \(\lvert x-\mu\rvert\) 离中心多远（绝对量的差）
    一维（标准化） \(\dfrac{\lvert x-\mu\rvert}{\sigma}\) 离中心几个标准差
    多维（马氏） \(\sqrt{(x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu)}\) 离中心几个「标准差」（多维版）

    核心直觉：马氏距离是用数据自身的形状当尺子量出来的距离。 \(\Sigma^{-1}\) 起的作用，就是把各维的尺度差异和相关性都折算掉 ✓

    7.2 为什么不用欧氏距离¶

    欧氏距离的定义是

    \[d_E(x, \mu) = \sqrt{(x-\mu)^{\mathsf{T}}(x-\mu)} = \sqrt{\sum_{k=1}^{d}(x_k-\mu_k)^2}\]

    它在做一件很武断的假设：各维的「一米」是一样长的， 而且各维之间没有相关性。

    实际数据常常不满足：

    问题 具体表现 欧氏距离的后果
    量纲不同 第 1 维单位是毫米、第 2 维单位是千克 改一下单位，最近邻就变了 —— 结论不稳定 ⚠
    尺度差异大 第 1 维的标准差是 \(10\)，第 2 维是 \(0.01\) 第 1 维的偏差完全淹没第 2 维的偏差
    维度相关 两个特征高度正相关（比如两个高度相关的尺寸指标） 同一个信息被重复计算两次，该方向被过分放大
    特征冗余 某些方向其实几乎没变化 那些方向上的噪声被当成真信号

    第一条最要命：欧氏距离依赖单位的选择。 米和厘米只是换个写法，物理上什么都没变， 但欧氏距离的数值会变 100 倍，最近邻可能就换了 ✗

    马氏距离怎么解决这四条：\(\Sigma^{-1}\) 里每个元素都是数据自己算出来的， 量纲、尺度、相关性全部自动包含进去：

    欧氏距离的问题 马氏距离的应对
    量纲不同 \(\Sigma\) 随单位一起变，\(\Sigma^{-1}\) 正好把它约回来
    尺度差异大 除以各维方差，尺度小的维度被自动放大
    维度相关 \(\Sigma\) 的非对角元记录相关性，\(\Sigma^{-1}\) 把它扣除
    特征冗余 接近零的特征值方向被 \(\Sigma^{-1}\) 强烈抑制

    7.3 反例：两种距离给出不一样的最近邻¶

    光说不够，手算一个出来看。构造一个两维数据， 第 1 维标准差是 \(10\)、第 2 维标准差只有 \(0.01\)， 也就是两维的「尺度」差了 \(1000\) 倍：

    项 值
    中心 \(\mu\) \((1000, 0)\)
    协方差 \(\Sigma\) \(\begin{pmatrix}100 & 0\\ 0 & 0.0001\end{pmatrix}\)
    候选点 \(a\) \((1010, 0)\)
    候选点 \(b\) \((1000, 0.03)\)

    先手算：

    候选 偏差向量 欧氏距离 马氏距离
    \(a\) \((10, 0)\) \(\sqrt{10^2+0^2} = 10\) \(\sqrt{(10/10)^2 + 0} = 1\)
    \(b\) \((0, 0.03)\) \(\sqrt{0+0.03^2} = 0.03\) \(\sqrt{0 + (0.03/0.01)^2} = 3\)

    把马氏距离那两格再拆细一点： 因为 \(\Sigma\) 是对角阵，\(\Sigma^{-1}\) 就是对角元取倒数，

    \[\Sigma^{-1} = \begin{pmatrix}0.01 & 0\\ 0 & 10000\end{pmatrix}\]

    于是

    \[d_M^2(a) = 10^2\times 0.01 + 0^2\times 10000 = 1 + 0 = 1 \ \Longrightarrow\ d_M(a) = 1\]
    \[d_M^2(b) = 0^2\times 0.01 + 0.03^2\times 10000 = 0 + 9 = 9 \ \Longrightarrow\ d_M(b) = 3\]

    看到了吗：

    • 按欧氏距离，\(b\)（\(0.03\)）比 \(a\)（\(10\)）近得多 → 判 \(b\)
    • 按马氏距离，\(a\)（\(1\)）比 \(b\)（\(3\)）近 → 判 \(a\)

    两个结论完全相反 ✗

    再看一次数字的意义：\(a\) 的马氏距离是 \(1\)， 意思是「\(a\) 偏离中心整整 \(1\) 个标准差」（第 1 维的标准差正好是 \(10\)）； \(b\) 的马氏距离是 \(3\)，意思是「\(b\) 偏离中心 \(3\) 个标准差」 （第 2 维标准差只有 \(0.01\)，\(0.03\) 就是 \(3\) 个）。

    从「几个标准差」的角度看，\(a\) 比 \(b\) 正常得多 ✓ 第 2 维是个「极度敏感」的方向 —— 只要偏 \(0.03\) 就已经偏出 \(3\) 个标准差， 在正态假设下这种点非常罕见（\(3\sigma\) 以外约 \(0.3\%\)）。

    7.4 与欧氏距离的关系：\(\Sigma = I\) 时两者相同¶

    把 \(\Sigma = I\) 代入马氏距离定义：

    \[d_M(x,\mu) = \sqrt{(x-\mu)^{\mathsf{T}}I^{-1}(x-\mu)} = \sqrt{(x-\mu)^{\mathsf{T}}(x-\mu)} = d_E(x,\mu)\]

    因为 \(I^{-1} = I\)，单位阵乘任何向量都不变 ✓

    这句话的完整含义：

    \[\Sigma = I \quad\Longleftrightarrow\quad \text{各维方差都是 } 1 \text{ 且互不相关} \quad\Longrightarrow\quad d_M = d_E\]

    所以欧氏距离是马氏距离的一个特例 —— 它隐含地假设了「各维方差为 1、互不相关」⚠

    手算验证（取一个 \(\Sigma = I\) 的三维例子）： \(\mu = (0, 0, 0)\)、\(x = (1, 2, 2)\)。

    \[d_E = \sqrt{1^2+2^2+2^2} = \sqrt{9} = 3\]
    \[d_M = \sqrt{1^2\times 1 + 2^2\times 1 + 2^2\times 1} = \sqrt{9} = 3 ✓\]

    两个数完全相同，因为 \(I^{-1}\) 乘上去什么也没改变 ✓

    7.5 线性变换下的不变性¶

    这是马氏距离最重要的性质，也是它和欧氏距离最本质的区别。

    性质：做任意可逆线性变换 \(y = Ax\)（\(A\) 为可逆方阵）， 马氏距离保持不变。

    先看变换后数据的分布：原数据 \(x \sim N(\mu, \Sigma)\)， 线性变换后 \(y = Ax\) 仍然是正态分布（这是多元正态的性质之一）， 其参数是

    \[\mu_y = A\mu, \qquad \Sigma_y = A\Sigma A^{\mathsf{T}}\]

    这两个式子怎么来的：

    期望的线性性给出第一个：

    \[E\{y\} = E\{Ax\} = A\,E\{x\} = A\mu\]

    协方差按定义展开，就是用第二个：

    \[\begin{aligned} \Sigma_y &= E\bigl\{(y-\mu_y)(y-\mu_y)^{\mathsf{T}}\bigr\} \\ &= E\bigl\{A(x-\mu)(x-\mu)^{\mathsf{T}}A^{\mathsf{T}}\bigr\} \\ &= A\,E\bigl\{(x-\mu)(x-\mu)^{\mathsf{T}}\bigr\}A^{\mathsf{T}} = A\Sigma A^{\mathsf{T}} \end{aligned}\]

    第二步把 \(A\) 提到期望外面是允许的： \(A\) 是常数矩阵，不随随机向量变化 ✓

    现在算变换后的马氏距离：

    \[\begin{aligned} d_M^2(y, \mu_y) &= (y-\mu_y)^{\mathsf{T}}\Sigma_y^{-1}(y-\mu_y) \\ &= \bigl[A(x-\mu)\bigr]^{\mathsf{T}} \bigl[A\Sigma A^{\mathsf{T}}\bigr]^{-1} \bigl[A(x-\mu)\bigr] \end{aligned}\]

    关键一步是求逆。用逆矩阵的乘积公式 \((PQR)^{-1} = R^{-1}Q^{-1}P^{-1}\)，取 \(P = A\)、\(Q = \Sigma\)、\(R = A^{\mathsf{T}}\)：

    \[\bigl[A\Sigma A^{\mathsf{T}}\bigr]^{-1} = (A^{\mathsf{T}})^{-1}\Sigma^{-1}A^{-1}\]

    代回去：

    \[\begin{aligned} d_M^2(y, \mu_y) &= (x-\mu)^{\mathsf{T}}A^{\mathsf{T}} (A^{\mathsf{T}})^{-1}\Sigma^{-1}A^{-1} A(x-\mu) \\ &= (x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu) \\ &= d_M^2(x, \mu) \end{aligned}\]

    中间两个约掉的地方很重要： \(A^{\mathsf{T}}(A^{\mathsf{T}})^{-1} = I\)， \(A^{-1}A = I\)，两处都约掉单位阵 ✓

    结论：开方后 \(d_M(y,\mu_y) = d_M(x,\mu)\)，马氏距离不变 ✓

    欧氏距离在同样变换下的表现：

    \[\begin{aligned} d_E^2(y, \mu_y) = (Ax - A\mu)^{\mathsf{T}}(Ax - A\mu) = (x-\mu)^{\mathsf{T}}A^{\mathsf{T}}A(x-\mu) \end{aligned}\]

    注意这里出现的是 \(A^{\mathsf{T}}A\) 而不是 \(I\) —— 它一般不等于 \((x-\mu)^{\mathsf{T}}(x-\mu)\)， 所以欧氏距离通常会变 ✗

    举个最小例子：\(A = 2I\)（所有维都放大两倍）， 欧氏距离直接放大两倍，马氏距离不变。

    手算验证这个最小例子： 设 \(\Sigma = I\)、\(\mu = (0,0)\)、\(x = (1, 0)\)。

    变换前：

    \[d_E^2 = 1^2 + 0^2 = 1, \qquad d_M^2 = 1\]

    取 \(A = 2I\)，则 \(y = (2, 0)\)，\(\mu_y = (0,0)\)，\(\Sigma_y = 4I\)：

    \[d_E^2(y) = 2^2 + 0^2 = 4 \quad (\text{放大到 } 4 \text{ 倍，即长度 } 2 \text{ 倍}) ✗\]
    \[d_M^2(y) = 2^2 \times \tfrac{1}{4} + 0^2 \times \tfrac{1}{4} = 1 ✓\]

    马氏距离一点没变，欧氏距离翻了两倍 —— 这就是「谁度量的是数据的内部结构」的分水岭 ✓

    为什么「不变性」这么重要：它意味着 马氏距离对特征做线性变换是稳健的。 在实际问题里，「换一组特征」通常就是一次线性变换 （比如旋转、缩放、坐标变换）， 用马氏距离做的判断不会因为换了特征表示就翻案 ✓

    欧氏距离就做不到这一点 —— 稍微换个特征组合， 最近邻可能就变成另一个点了， 这说明它度量的不是数据本身的内在结构，而是坐标系统的偶然选择 ⚠

    「\(A^{\mathsf{T}}A\) 到底把向量放大多少倍」也要说清： 对任意向量 \(d\)，

    \[\lVert Ad\rVert^2 = (Ad)^{\mathsf{T}}(Ad) = d^{\mathsf{T}}A^{\mathsf{T}}Ad\]

    放大倍数随方向变化，变化范围由 \(A^{\mathsf{T}}A\) 的特征值控制：

    量 含义
    \(\sqrt{\lambda_{\max}(A^{\mathsf{T}}A)}\) 放大倍数的上界
    \(\sqrt{\lambda_{\min}(A^{\mathsf{T}}A)}\) 放大倍数的下界
    两者不等时 不同方向放大倍数不同 → 欧氏距离必变

    后一条就是欧氏距离会变的根本原因： \(A\) 对不同方向的放大倍数不一样（受 \(A^{\mathsf{T}}A\) 的特征值控制）， 所以 \(\lVert Ax-A\mu\rVert\) 和 \(\lVert x-\mu\rVert\) 一般不会相等 ✗

    而马氏距离用 \(\Sigma^{-1}\) 把这个「方向差异」恰好抵消掉了， 所以它不变 ✓

    7.6 一张对照表总结欧氏与马氏¶

    把这一节的内容收成一张表：

    对比项 欧氏距离 马氏距离
    定义 \(\sqrt{(x-\mu)^{\mathsf{T}}(x-\mu)}\) \(\sqrt{(x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu)}\)
    用到的信息 只用 \(x\) 与 \(\mu\) 还要用 \(\Sigma\)
    各维权重 全部相等（都是 1） 由各维方差自动决定
    维度相关性 忽略 由 \(\Sigma\) 的非对角元体现
    量纲变化 数值随之变化 ✗ 数值不变 ✓
    线性变换 \(y=Ax\) 一般会变 ✗ 不变 ✓
    \(\Sigma = I\) 时 与马氏相同 与欧氏相同
    等值面形状 球面（圆） 与 \(\Sigma\) 的等密度椭球同形状

    最后一行值得单独说：马氏距离的等值面 \((x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu) = c^2\) 和正态分布的等密度轨迹是同一族椭球。 所以「马氏距离相等的点」正好就是「密度相等的点」✓ 这就是为什么高斯密度里的二次型必须是马氏距离， 而不能换成欧氏距离。

    八、决策面形状预览：三种情形¶

    把前面所有线索合起来，就能回答一个预测性的问题： 假设各类都服从正态分布，决策面会是什么形状？

    答案取决于协方差矩阵怎么假设。三种情形如下：

    情形 协方差矩阵 判别函数 决策面
    一 各类协方差相同，且是 \(\sigma^2 I\) 线性 超平面（垂直于两类均值连线）
    二 各类协方差相同，一般形式 \(\Sigma\) 线性 超平面（一般不与均值连线垂直）
    三 各类协方差不同 二次 超二次曲面（超椭球面/超双曲面/超球面等）

    情形一、二为什么都得到线性判别函数 —— 完整推导（不跳步）。

    第一步，写出两类协方差相同时的取对数判别函数。 把 6.2 节的多元正态密度代进 \(g_i = \ln p(x\mid\omega_i) + \ln P(\omega_i)\)：

    \[\ln p(x\mid\omega_i) = -\frac{d}{2}\ln(2\pi) - \frac{1}{2}\ln\lvert\Sigma\rvert - \frac{1}{2}(x-\mu_i)^{\mathsf{T}}\Sigma^{-1}(x-\mu_i)\]

    （这里 \(\Sigma_i = \Sigma\) 与类无关，所以 \(\lvert\Sigma\rvert\) 这一项也与类无关。）

    第二步，把二次型展开。逐个括号乘出来：

    \[\begin{aligned} (x-\mu_i)^{\mathsf{T}}\Sigma^{-1}(x-\mu_i) &= x^{\mathsf{T}}\Sigma^{-1}x - x^{\mathsf{T}}\Sigma^{-1}\mu_i - \mu_i^{\mathsf{T}}\Sigma^{-1}x + \mu_i^{\mathsf{T}}\Sigma^{-1}\mu_i \end{aligned}\]

    中间两项是同一个标量，合并成 \(-2\mu_i^{\mathsf{T}}\Sigma^{-1}x\)：

    \[(x-\mu_i)^{\mathsf{T}}\Sigma^{-1}(x-\mu_i) = x^{\mathsf{T}}\Sigma^{-1}x - 2\mu_i^{\mathsf{T}}\Sigma^{-1}x + \mu_i^{\mathsf{T}}\Sigma^{-1}\mu_i\]

    「中间两项是同一个标量」这一步的依据（很容易被跳过去）： \(x^{\mathsf{T}}\Sigma^{-1}\mu_i\) 是一个 \(1\times 1\) 矩阵，也就是一个数。 数的转置等于自身，所以

    \[x^{\mathsf{T}}\Sigma^{-1}\mu_i = \bigl(x^{\mathsf{T}}\Sigma^{-1}\mu_i\bigr)^{\mathsf{T}} = \mu_i^{\mathsf{T}}\Sigma^{-1\mathsf{T}}x = \mu_i^{\mathsf{T}}\Sigma^{-1}x\]

    最后一步用了 \(\Sigma\) 对称（对称矩阵的逆也对称，\(\Sigma^{-1\mathsf{T}} = \Sigma^{-1}\)）✓

    第三步，代回去，得到两类的判别函数：

    \[g_i(x) = -\frac{1}{2}x^{\mathsf{T}}\Sigma^{-1}x + \mu_i^{\mathsf{T}}\Sigma^{-1}x - \frac{1}{2}\mu_i^{\mathsf{T}}\Sigma^{-1}\mu_i + \ln P(\omega_i) + \text{const}\]

    （\(\text{const}\) 是把 \(-\frac{d}{2}\ln(2\pi) - \frac{1}{2}\ln\lvert\Sigma\rvert\) 合起来的那一堆， 它与 \(i\) 无关。）

    第四步，做差。注意第一项 \(-\frac{1}{2}x^{\mathsf{T}}\Sigma^{-1}x\) 里没有 \(i\)， 两类完全相同，做差时自动消掉， \(\text{const}\) 同样消掉：

    \[g(x) = g_1(x) - g_2(x) = \mu_1^{\mathsf{T}}\Sigma^{-1}x - \mu_2^{\mathsf{T}}\Sigma^{-1}x - \frac{1}{2}\bigl(\mu_1^{\mathsf{T}}\Sigma^{-1}\mu_1 - \mu_2^{\mathsf{T}}\Sigma^{-1}\mu_2\bigr) + \ln\frac{P(\omega_1)}{P(\omega_2)}\]

    第五步，把一次项合并成法向量形式。 因为 \(\mu_1^{\mathsf{T}}\Sigma^{-1}x = \bigl(\Sigma^{-1}\mu_1\bigr)^{\mathsf{T}}x\) （同样用「数的转置等于自身」与 \(\Sigma^{-1}\) 对称）：

    \[g(x) = w^{\mathsf{T}}x + w_0\]

    其中

    \[w = \Sigma^{-1}(\mu_1 - \mu_2), \qquad w_0 = -\frac{1}{2}\bigl(\mu_1^{\mathsf{T}}\Sigma^{-1}\mu_1 - \mu_2^{\mathsf{T}}\Sigma^{-1}\mu_2\bigr) + \ln\frac{P(\omega_1)}{P(\omega_2)}\]

    因为二次项消掉了，剩下的只有 \(x\) 的一次项和常数项， 所以 \(g\) 是线性的，决策面 \(g(x)=0\) 是一张超平面 ✓

    情形三为什么是二次的：两类协方差不同时， \(-\frac{1}{2}x^{\mathsf{T}}\Sigma_1^{-1}x\) 与 \(+\frac{1}{2}x^{\mathsf{T}}\Sigma_2^{-1}x\) 不再抵消，二次项留在 \(g(x)\) 里，所以 \(g\) 是二次函数， \(g(x)=0\) 是超二次曲面。 另外这时 \(\lvert\Sigma_1\rvert\) 与 \(\lvert\Sigma_2\rvert\) 也不相等， 行列式那一项不能再丢，它会进入 \(w_0\)：

    \[w_0 \text{ 中多出 } -\frac{1}{2}\ln\frac{\lvert\Sigma_1\rvert}{\lvert\Sigma_2\rvert}\]

    具体是哪种二次曲面，取决于 \(\Sigma_1\)、\(\Sigma_2\)、 \(\mu_1\)、\(\mu_2\) 和两个先验 —— 可以是超椭球面、超双曲面，也可能退化成超球面甚至超平面 ✓ 具体推导留到下一节。

    三种情形一张对照表：

    对比项 情形一 情形二 情形三
    协方差假设 \(\Sigma_1=\Sigma_2=\sigma^2 I\) \(\Sigma_1=\Sigma_2=\Sigma\) \(\Sigma_1 \neq \Sigma_2\)
    二次项 \(x^{\mathsf{T}}\Sigma^{-1}x\) 两类相同，消掉 两类相同，消掉 两类不同，留下
    \(\ln\lvert\Sigma\rvert\) 项 消掉 消掉 留下
    判别函数 线性 线性 二次
    决策面 超平面，垂直于均值连线 超平面，一般不垂直 超二次曲面
    待估参数（\(d\) 维） 约 \(2\) 个（两个均值） 约 \(2 + d(d+1)/2\) 个 约 \(2 + d(d+1)\) 个

    最后一行是「为什么不要轻易用情形三」的经济学理由： 参数个数随 \(d^2\) 增长，样本不够时估计出来的协方差矩阵会很不可靠 ⚠

    8.1 「决策面垂直于均值连线」到底什么时候成立¶

    这是本节最容易被记错的一条，务必分清。

    决策面的法向量不一定沿着两类均值的连线方向

    在最简单的情形（两类协方差都是 \(\sigma^2 I\)）下， \(w = \Sigma^{-1}(\mu_1-\mu_2) = \frac{1}{\sigma^2}(\mu_1-\mu_2) \propto \mu_1-\mu_2\)， 所以决策面垂直于两类均值的连线， \(w\) 确实指向「从第 2 类均值指向第 1 类均值」的方向。

    但协方差矩阵是普通矩阵时，\(w = \Sigma^{-1}(\mu_1-\mu_2)\) 与 \(\mu_1-\mu_2\) 一般不再同向 ⚠ 因为 \(\Sigma^{-1}\) 会把向量「扭转」一下。

    记住这个结论：决策面垂直于 \(w\)，而不是垂直于均值连线。 只有在 \(\Sigma \propto I\) 时两者才重合。

    一个容易被误导的说法：「协方差相同 → 决策面垂直于均值连线」。 这句只在协方差是球形时才对。 协方差相同但一般时，决策面仍然垂直于连线的情况只是巧合 ✓

    下面这张图画的正是「协方差是球形」这一最简单的情形， 请重点看：连线（虚线）与决策面（实线）互相垂直， 交点正好落在两类均值的中点：

    手算核对图上的几何关系（用例题 1 的数据）：

    \[\mu_1 = (0, 3)^{\mathsf{T}}, \qquad \mu_2 = (3, 3)^{\mathsf{T}}\]

    连线方向：

    \[\mu_1 - \mu_2 = (-3, 0)^{\mathsf{T}}\]

    把 \(\Sigma = I\) 代入 \(w = \Sigma^{-1}(\mu_1-\mu_2)\)：

    \[w = (-3, 0)^{\mathsf{T}}\]

    \(w\) 与 \(\mu_1-\mu_2\) 完全相同（因为 \(\Sigma^{-1} = I\) 什么也没改）， 所以决策面作为 \(w\) 的垂面，当然也垂直于均值连线 ✓

    再看一般协方差时这个关系怎么被破坏。 取 \(\mu_A = (1,1)\)、\(\mu_B = (4,3)\)、 \(\Sigma = \begin{pmatrix}2 & 0.5\\ 0.5 & 1.5\end{pmatrix}\)，先验相等。

    第一步，连线方向：

    \[\mu_A - \mu_B = (-3, -2)^{\mathsf{T}}, \qquad \text{斜率} = \frac{-2}{-3} = 0.6667\]

    第二步，求 \(\Sigma^{-1}\)。先算行列式：

    \[\lvert\Sigma\rvert = 2\times 1.5 - 0.5\times 0.5 = 3 - 0.25 = 2.75\]

    再按二阶求逆公式：

    \[\Sigma^{-1} = \frac{1}{2.75}\begin{pmatrix}1.5 & -0.5\\ -0.5 & 2\end{pmatrix} = \begin{pmatrix}0.545455 & -0.181818\\ -0.181818 & 0.727273\end{pmatrix}\]

    第三步，求 \(w\)：

    \[w = \Sigma^{-1}(\mu_A-\mu_B) = \begin{pmatrix}0.545455 & -0.181818\\ -0.181818 & 0.727273\end{pmatrix} \begin{pmatrix}-3\\-2\end{pmatrix} = \begin{pmatrix}-1.636365 + 0.363636\\ 0.545454 - 1.454546\end{pmatrix} = \begin{pmatrix}-1.272729\\ -0.909092\end{pmatrix}\]

    第四步，比较两个方向：

    向量 分量 斜率
    均值连线 \(\mu_A-\mu_B\) \((-3, -2)\) \(0.6667\)
    法向量 \(w = \Sigma^{-1}(\mu_A-\mu_B)\) \((-1.272727, -0.909091)\) \(-0.909091 / -1.272727 = 0.7143\)

    两个斜率不一样（\(0.6667\) 与 \(0.7143\)）， 所以决策面不垂直于均值连线 ✓ 差别的来源就是 \(\Sigma^{-1}\) —— 它把连线方向「扭转」了一点。

    决策面经过哪里：先验相等时经过两点中点

    \[x_0 = \frac{\mu_A+\mu_B}{2} = (2.5,\ 2.0)^{\mathsf{T}}\]

    验证 \(x_0\) 在决策面上：

    \[w^{\mathsf{T}}x_0 = -1.272727\times 2.5 + (-0.909091)\times 2.0 = -3.181818 - 1.818182 = -5.0\]
    \[g(x_0) = w^{\mathsf{T}}x_0 + w_0 = -5.0 + 5.0 = 0 ✓\]

    这说明什么：两类协方差相同时， 决策面一定经过两类均值的中点（先验相等时）。 先验不等时它就从中点偏移，偏移量正是 \(\ln(P_1/P_2)\) 折算出来的那一段 ✓

    九、广义线性判别函数：把弯曲的边界「掰直」¶

    到这里为止，我们处理过的决策面只有两类形状： 超平面（线性判别函数）和超二次曲面（二次判别函数）。 这一节补一个非常重要的推广思路 —— 把特征先映射到高维，再在高维里画超平面。

    9.1 为什么需要它¶

    先看一个具体的困境。一维问题里，第 1 类的样本落在 \([-1, 1]\) 内， 第 2 类的样本落在两边的 \([-3,-1]\) 与 \([1,3]\) 上。 这时判别规则是

    \[\text{判 } \omega_1 \quad \text{当} \quad -1 \lt x \lt 1\]

    这不是一个线性判别函数能表达的（线性规则只有一个分界点， 而这里需要两个分界点）， 但它是二次的：

    \[g(x) = 1 - x^2, \qquad g(x) \gt 0 \Rightarrow \text{判 } \omega_1\]

    推广到两维：第 1 类落在一个圆里，第 2 类落在圆外， 判别规则是

    \[g(x) = r_0^2 - (x_1^2 + x_2^2)\]

    注意 \(g\) 里出现了 \(x_1^2\)、\(x_2^2\) 这样的乘积/平方项 —— 它在原空间里不是线性的，但如果把这些项看成新的坐标， 它就是线性的了 ✓

    9.2 定义与逐步推导¶

    做法：定义一组基函数（记作 \(\phi_k(x)\)）， 把 \(d\) 维的 \(x\) 映射成 \(m\) 维的新向量

    \[y = \bigl(\phi_1(x), \phi_2(x), \dots, \phi_m(x)\bigr)^{\mathsf{T}}\]

    然后在 \(y\) 空间里用线性判别函数：

    \[g(x) = a^{\mathsf{T}}y + a_0 = \sum_{k=1}^{m} a_k\,\phi_k(x) + a_0\]

    它就是「广义线性判别函数」 —— 名字里带「线性」，指的是对系数 \(a_k\) 线性， 不是对原始特征 \(x\) 线性 ✓

    「二次判别函数是它的特例」这一步不跳步地展开。 取 \(d = 2\)，原始特征 \((x_1, x_2)\)。 把下面这 \(6\) 个量当新坐标：

    \[y = \bigl(1,\ x_1,\ x_2,\ x_1^2,\ x_2^2,\ x_1x_2\bigr)^{\mathsf{T}}\]

    一般的二次判别函数可以写成

    \[g(x) = c_0 + c_1x_1 + c_2x_2 + c_3x_1^2 + c_4x_2^2 + c_5x_1x_2\]

    逐项与 \(a^{\mathsf{T}}y\) 对照：

    原式中的项 对应的新坐标 \(\phi_k(x)\) 对应系数 \(a_k\)
    \(c_0\) \(\phi_1 = 1\) \(a_1 = c_0\)
    \(c_1x_1\) \(\phi_2 = x_1\) \(a_2 = c_1\)
    \(c_2x_2\) \(\phi_3 = x_2\) \(a_3 = c_2\)
    \(c_3x_1^2\) \(\phi_4 = x_1^2\) \(a_4 = c_3\)
    \(c_4x_2^2\) \(\phi_5 = x_2^2\) \(a_5 = c_4\)
    \(c_5x_1x_2\) \(\phi_6 = x_1x_2\) \(a_6 = c_5\)

    所以二次判别函数 = 在 \(6\) 维新空间里的线性判别函数 ✓

    一般 \(d\) 维时新坐标有多少个： \(1\)（常数项）+ \(d\)（一次项）+ \(d\)（平方项）+ \(d(d-1)/2\)（交叉项）

    \[m = 1 + 2d + \frac{d(d-1)}{2} = \frac{(d+1)(d+2)}{2}\]

    这个数字长得很快（下表就是它）：

    原始维数 \(d\) 新空间维数 \(m\) 增长倍数
    \(1\) \(3\) \(3\)
    \(2\) \(6\) \(3\)
    \(5\) \(21\) \(4.2\)
    \(10\) \(66\) \(6.6\)
    \(20\) \(231\) \(11.6\)

    这张表说明什么：把边界「掰直」的代价是维数按平方增长。 维数一高，参数估计所需的样本量也跟着暴涨 —— 这正是「维数灾难」的一个具体表现 ⚠

    下图把这件事画出来了：原始空间里那条弯曲（圆形）的边界， 在做完特征映射之后变成了一张直的超平面：

    「变成超平面」这件事的关键在哪： 新坐标 \(y\) 与原坐标 \(x\) 之间是非线性关系（\(y_4 = x_1^2\)）， 所以「原空间里的一条曲线」在 \(y\) 空间里可以是「平的」。 判别函数对新坐标 \(y\) 是线性的，对原坐标 \(x\) 是二次的 ✓

    例题 3：写出判别函数并求决策面（两类、单位协方差）¶

    两类都是二维正态分布，协方差矩阵都是单位阵 \(I\)：

    项 值
    \(\mu_1\) \((0, 3)^{\mathsf{T}}\)
    \(\mu_2\) \((3, 3)^{\mathsf{T}}\)
    \(\Sigma_1 = \Sigma_2\) \(I\)
    \(P(\omega_1)\) \(0.4\)
    \(P(\omega_2)\) \(0.6\)
    待判样本 \(x\) \((1, 4)^{\mathsf{T}}\)

    求：(a) 两个类的马氏距离平方； (b) 取对数判别函数 \(g_1\)、\(g_2\)； © 判决结果； (d) 把它写成线性形式 \(g(x) = w^{\mathsf{T}}x + w_0\)，并求决策面。

    思路

    协方差都是 \(I\)，所以马氏距离平方就退化成欧氏距离平方。 取对数判别函数用 3.3 节的公式。 写线性形式时注意：\(x^{\mathsf{T}}x\) 这一项两类相同， 可以直接丢掉。 最后求决策面时，令 \(g(x) = 0\) 解出 \(x_1\) 即可。

    解答

    （a）马氏距离平方

    \(\Sigma = I\) 时 \(\Sigma^{-1} = I\)，所以

    \[r_1^2 = (x-\mu_1)^{\mathsf{T}}(x-\mu_1) = (1-0)^2 + (4-3)^2 = 1 + 1 = 2\]
    \[r_2^2 = (x-\mu_2)^{\mathsf{T}}(x-\mu_2) = (1-3)^2 + (4-3)^2 = 4 + 1 = 5\]

    （b）取对数判别函数

    二维正态密度的对数（丢掉两类共有的常数项）是

    \[\ln p(x\mid\omega_i) = -\frac{1}{2}r_i^2\]

    代进 \(g_i = \ln p(x\mid\omega_i) + \ln P(\omega_i)\)：

    \[g_1 = -0.5 \times 2 + \ln 0.4 = -1 - 0.916291 = -1.916291\]
    \[g_2 = -0.5 \times 5 + \ln 0.6 = -2.5 - 0.510826 = -3.010826\]

    （c）判决

    \[g_1 - g_2 = -1.916291 - (-3.010826) = 1.094535 \gt 0\]

    判为 \(\omega_1\) ✓

    （d）线性形式

    \(\Sigma = I\) 时按 8.1 节的公式：

    \[w = \Sigma^{-1}(\mu_1 - \mu_2) = (0-3,\ 3-3)^{\mathsf{T}} = (-3, 0)^{\mathsf{T}}\]
    \[w_0 = -\frac{1}{2}\bigl(\mu_1^{\mathsf{T}}\mu_1 - \mu_2^{\mathsf{T}}\mu_2\bigr) + \ln\frac{P(\omega_1)}{P(\omega_2)}\]

    先算两个平方： \(\mu_1^{\mathsf{T}}\mu_1 = 0+9 = 9\)， \(\mu_2^{\mathsf{T}}\mu_2 = 9+9 = 18\)，所以

    \[w_0 = -\frac{1}{2}(9 - 18) + \ln\frac{0.4}{0.6} = 4.5 - 0.405465 = 4.094535\]

    验证：\(w^{\mathsf{T}}x + w_0 = (-3)(1) + 0\times 4 + 4.094535 = 1.094535\) —— 与 © 的 \(g_1 - g_2\) 完全一致 ✓

    决策面位置：\(w^{\mathsf{T}}x + w_0 = 0\)，即

    \[-3x_1 + 4.094535 = 0 \quad\Longrightarrow\quad x_1 = 1.364845\]

    是一条竖直线（\(x_2\) 的系数是 \(0\)）， 因为 \(w = (-3, 0)\) 沿着 \(x_1\) 轴，所以决策面垂直于 \(x_1\) 轴 ✓

    这个结果说明什么：\(w\) 的第二个分量恰好是 \(0\)， 意味着第 2 维特征对判决完全没有贡献 —— 两个类的 \(x_2\) 均值都是 \(3\)， 所以 \(x_2\) 方向上两类没有可分性。 考试里遇到这种「某一维没贡献」，不要慌， 它只是那一维的均值差为零 ✓

    例题 4：算出一个点的多元正态密度¶

    二维正态分布：\(\mu = (1, 2)^{\mathsf{T}}\)， \(\Sigma = \begin{pmatrix}2 & 0.5\\ 0.5 & 1\end{pmatrix}\)。 求 \(x = (2, 3)^{\mathsf{T}}\) 处的： (a) 行列式与逆矩阵； (b) 马氏距离平方与马氏距离； © 密度值 \(p(x)\)。

    思路

    按 6.2 节的公式一步步算，不要跳步。 先算行列式（\(2\times2\) 矩阵用 \(\lvert\Sigma\rvert = \sigma_{11}\sigma_{22} - \sigma_{12}^2\)）， 再算逆矩阵，然后套二次型，最后乘上前面的常数因子。

    解答

    （a）行列式与逆矩阵

    \[\lvert\Sigma\rvert = 2 \times 1 - 0.5^2 = 2 - 0.25 = 1.75\]

    二阶矩阵求逆的公式是

    \[\begin{pmatrix}a & b\\ c & d\end{pmatrix}^{-1} = \frac{1}{ad-bc}\begin{pmatrix}d & -b\\ -c & a\end{pmatrix}\]

    代入 \(a=2,\ b=0.5,\ c=0.5,\ d=1\)，且 \(ad-bc = 1.75\)：

    \[\Sigma^{-1} = \frac{1}{1.75}\begin{pmatrix}1 & -0.5\\ -0.5 & 2\end{pmatrix} = \begin{pmatrix}0.571429 & -0.285714\\ -0.285714 & 1.142857\end{pmatrix}\]

    （b）马氏距离

    偏差向量：\(x - \mu = (2-1,\ 3-2)^{\mathsf{T}} = (1, 1)^{\mathsf{T}}\)

    二次型逐步算。先做矩阵乘向量：

    \[\Sigma^{-1}(x-\mu) = \begin{pmatrix}0.571429 & -0.285714\\ -0.285714 & 1.142857\end{pmatrix}\begin{pmatrix}1\\1\end{pmatrix} = \begin{pmatrix}0.571429-0.285714\\ -0.285714+1.142857\end{pmatrix} = \begin{pmatrix}0.285714\\ 0.857143\end{pmatrix}\]

    再左乘 \((x-\mu)^{\mathsf{T}} = (1, 1)\)：

    \[r^2 = 0.285714 \times 1 + 0.857143 \times 1 = 1.142857\]
    \[r = \sqrt{1.142857} = 1.069045\]

    （c）密度值

    \(d = 2\)，所以归一化常数是

    \[\frac{1}{(2\pi)^{d/2}\lvert\Sigma\rvert^{1/2}} = \frac{1}{2\pi \times \sqrt{1.75}}\]

    逐项算：\(2\pi = 6.283185\)，\(\sqrt{1.75} = 1.322876\)， 乘积 \(= 8.311282\)，所以常数 \(= 1/8.311282 = 0.120318\)。

    指数部分：\(e^{-r^2/2} = e^{-0.571429} = 0.564647\)。

    \[p(x) = 0.120318 \times 0.564647 = 0.067941\]

    注意这个数字小于 \(1\) —— 但如果你把 \(\Sigma\) 换得更「窄」 （比如两维方差都是 \(0.01\)），密度完全可以大于 \(1\)， 因为它是密度不是概率 ⚠

    这个结果说明什么：密度值本身与分类无关， 它只是「这个点在这类分布下有多典型」的一个度量。 真正做判决时只需要比较两个类的密度（或它们的对数）， 所以常数因子 \(0.120318\) 完全可以不算 ✓

    顺带记住一个反直觉的事实： \(x = (2,3)\) 的两维偏差都是 \(1\)， 但马氏距离不是 \(\sqrt{2}\) 而是 \(1.069\) —— 原因是 \(\Sigma\) 的非对角元 \(0.5\) 表示两维正相关， 二次型把这一份相关性也算了进去： \(r^2 = 1.142857\) 比 \(2\) 小，说明正相关让这个点显得更「正常」 ✓

    十二、自测¶

    Q1 判断对错并说明理由：

    某分类器用 \(g_1(x) = P(\omega_1\mid x)\)、\(g_2(x) = P(\omega_2\mid x)\) 做判决。 现在把它换成 \(g_1' = \ln P(\omega_1\mid x)\)、 \(g_2' = \ln P(\omega_2\mid x)\)，判决结果会变吗？ 如果换成 \(g_1'' = 2g_1 - 5\)、\(g_2'' = 2g_2 - 5\) 呢？

    提示

    两次换的都是同一个变换作用在所有类上。 先判断该变换是不是严格单调增。

    解答

    两次都不会变 ✓

    第一次：\(\ln\) 变换

    \(\ln\) 在 \((0, +\infty)\) 上严格单调增。 后验概率的取值在 \((0, 1]\) 内（实际上在 \((0,1)\)）， 所以 \(g_1, g_2\) 都在 \(\ln\) 的定义域内。

    对任意 \(g_1 \gt g_2 \gt 0\)，有 \(\ln g_1 \gt \ln g_2\)， 大小关系逐对保持，所以判决不变 ✓

    有一个边界情形要注意：如果某一类的后验恰好等于 \(0\) （先验为 \(0\) 时会发生），\(\ln 0\) 无定义 ✗ 这时的处理办法是：先把那个不可能出现的类直接排除， 再对剩下的类取对数。

    第二次：仿射变换 \(2g-5\)

    这个变换是 \(g \mapsto 2g - 5\)。 系数 \(2 \gt 0\)，所以它是严格单调增的：

    \[g_1 \gt g_2 \ \Longrightarrow\ 2g_1 - 5 \gt 2g_2 - 5\]

    减去同一个常数 \(5\) 不影响不等号方向， 乘上正数 \(2\) 也不影响 ✓

    结论表：

    变换 单调增？ 判决会变？
    \(g \mapsto \ln g\)（\(g \gt 0\)） 是 不变
    \(g \mapsto 2g-5\) 是 不变
    \(g \mapsto -g\) 否（递减） 必变
    \(g \mapsto g^2\)（\(g\) 可能为负） 否 可能变

    注意 \(g^2\) 那一行：虽然本例中 \(g\) 全为正， 但一般情形下 \(g\) 可能含负数， 此时 \(g^2\) 会把「最小的负数」变成「最大的正数」，判决直接翻转 ✗ 这也是为什么取对数比取平方更安全 —— 对数的定义域本身就限制了输入必须为正。

    一个可以随手用的检查：把两个待比较的式子相减， 如果结果恒等于 0（对任意 \(x\)）， 那它们就是同一个判别函数；如果差出来的是一个保序变换， 判决也仍然相同 ⚠

    协方差相同且为 \(I\) 时，直接用这个公式：

    (a) 分别算它的欧氏距离与马氏距离。 (b) 如果不看协方差矩阵，只看欧氏距离， 会误判这个点「离中心多远」吗？

    提示

    \(\Sigma\) 是对角阵且对角元是 \(4\) 和 \(1\)， \(\Sigma^{-1}\) 就是对角元取倒数。 马氏距离平方 = \(x_1^2/4 + x_2^2/1\)。

    解答

    （a）两个距离

    欧氏距离：

    \[d_E^2 = 2^2 + 3^2 = 4 + 9 = 13, \qquad d_E = 3.605551\]

    马氏距离：\(\Sigma^{-1} = \begin{pmatrix}0.25 & 0\\ 0 & 1\end{pmatrix}\)，所以

    \[d_M^2 = \frac{2^2}{4} + \frac{3^2}{1} = 1 + 9 = 10, \qquad d_M = 3.162278\]

    （b）会不会误判

    会 ✗ 而且误判的方式很有代表性。

    维度 坐标值 该维标准差 偏了几个标准差
    第 1 维 \(2\) \(2\) \(1\) 个
    第 2 维 \(3\) \(1\) \(3\) 个

    看欧氏距离：\(2\) 和 \(3\) 是两个差不多的数， 似乎两个方向「偏离程度相当」。

    看标准差个数：第 1 维只偏了 \(1\) 个标准差（很平常）， 第 2 维偏了 \(3\) 个标准差（非常罕见）。

    在正态假设下，\(3\) 个标准差以外的概率约 \(0.3\%\) —— 这个点主要是被第 2 维「拉远」的 ✓

    两个距离差在哪：就差在「要不要除以标准差」这一件事上。 欧氏距离把两维的偏移都当成「同样的距离」， 马氏距离把每一维都换算成「几个标准差」之后才相加。

    这个结论说明什么：看到协方差矩阵的对角元相差很大时， 第一反应应该是「欧氏距离会误判」， 而不是直接用坐标差的大小做判断 ✓

    Q4 某两类问题的协方差矩阵是 \(\Sigma = \begin{pmatrix}9 & 0\\ 0 & 4\end{pmatrix}\)。

    (a) 这个矩阵有哪些性质？逐条检查。 (b) 这个分布的等密度轨迹是圆还是椭圆？ © 长短轴各多长？方向如何？

    提示

    按 6.5 节的性质清单逐条对：对称、正定、可对角化、 特征值、迹、行列式。 对角矩阵的特征值就是对角元。

    解答

    （a）性质逐条检查

    性质 检查 结论
    实对称 \(\sigma_{12} = \sigma_{21} = 0\) 满足 ✓
    正定 对角元 \(9 \gt 0\)、\(4 \gt 0\)，且非对角为 \(0\) 满足 ✓
    特征值 对角矩阵的特征值就是对角元：\(\lambda_1 = 9\)、\(\lambda_2 = 4\) 全为正 ✓
    可对角化 本身就是对角阵，\(\Phi = I\)、\(\Lambda = \Sigma\) 满足 ✓
    迹 \(9 + 4 = 13\)，与特征值之和 \(9+4 = 13\) 一致 满足 ✓
    行列式 \(9 \times 4 - 0 = 36\)，与特征值之积 \(9\times4 = 36\) 一致 满足 ✓

    （b）圆还是椭圆

    是椭圆（不是圆）

    判据：等密度轨迹退化为圆（球面）的条件是 各方向扩散程度相同，也就是 \(\Sigma\) 的特征值全部相等。 这里 \(9 \neq 4\)，所以是椭圆 ✓

    （c）轴长与方向

    等密度轨迹的方程是

    \[\frac{x_1^2}{9} + \frac{x_2^2}{4} = \text{const}\]

    把它写成标准椭圆形式（两边同除以 const）：

    \[\frac{x_1^2}{9c} + \frac{x_2^2}{4c} = 1, \qquad c \gt 0\]

    所以半轴长分别是 \(3\sqrt{c}\) 与 \(2\sqrt{c}\) —— 正比于 \(\sqrt{\lambda_1} = 3\) 与 \(\sqrt{\lambda_2} = 2\) ✓ 这与「主轴长度与特征值有关」的结论对应 （注意严格说轴长与特征值的平方根成正比， 因为密度里是 \(r^2\) 而不是 \(r\)）。

    方向：本例 \(\Sigma\) 是对角阵， 特征向量就是坐标轴方向 \((1,0)\) 与 \((0,1)\)； 长轴沿第 1 维（\(\lambda_1 = 9\) 对应的方向）✓

    长短轴之比：\(\sqrt{9/4} = 1.5\)。

    这个结论说明什么： 对角协方差矩阵的几何含义非常直白 —— 对角元就是各维的方差，特征向量就是坐标轴。 遇到非对角元不为零的矩阵时才需要真正做特征分解； 对角情形可以直接读出来 ✓

    小结¶

    要记住的 为什么
    判别函数是一组函数 \(g_i(x)\)，判最大者 把「算概率」变成「比大小」，是后面所有分类器的统一框架
    判决只依赖判别函数之间的序 所以存在大量等价形式；换形式不影响判决
    保序变换（乘正数、加常数、取对数）不改变判决 这是「判别函数不唯一」的根源
    乘负数、给不同类加不同常数会改变判决 一旦破坏「所有类用同一个变换」，比较就失去意义
    \(g_i = p(x\mid\omega_i)P(\omega_i)\) 最常用 分母 \(p(x)\) 与类别无关，可以整项丢掉
    \(g_i = \ln p(x\mid\omega_i) + \ln P(\omega_i)\) 数值最稳 把连乘变成连加，避免高维下溢出为 0
    决策面方程 \(g_i(x) = g_j(x)\) 两个类判别函数打平的地方就是分界线
    两类时只看 \(g(x) = g_1 - g_2\) 的符号 把「比两个数」简化成「看一个数的正负」
    决策面方程 \(g(x) = 0\) 本页最核心的一个等式，它确定全部决策区域
    决策面的形状由 \(g\) 的形式决定 \(g\) 线性则决策面是超平面，\(g\) 二次则是超二次曲面
    \(g(x) = \ln\frac{p(x\mid\omega_1)}{p(x\mid\omega_2)} + \ln\frac{P(\omega_1)}{P(\omega_2)}\) 似然比 + 先验比，前者靠数据、后者靠先验
    决策面 = 似然比等于先验反比的那些点 这就是「\(g=0\)」的物理含义
    多元正态密度的指数项就是马氏距离平方 \((x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu) = r^2\)
    高斯的等密度轨迹是椭球 轴方向由特征向量定，轴长与 \(\sqrt{\lambda}\) 成正比
    协方差矩阵：对称、正定、可对角化 正定保证可逆，才能定义密度与马氏距离
    \(\operatorname{tr}(\Sigma) = \sum\lambda_i\)、\(\lvert\Sigma\rvert = \prod\lambda_i\) 手算与写代码时的两条自检等式
    马氏距离 \(d_M = \sqrt{(x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu)}\) 用数据自身形状当尺子，「离中心几个标准差」的多维版
    量纲不同、尺度差异大、维度相关时必须用马氏距离 欧氏距离隐含「各维方差为 1、互不相关」的错误假设
    \(\Sigma = I\) 时马氏退化成欧氏 所以欧氏距离是马氏距离的特例
    马氏距离对线性变换 \(y = Ax\) 不变，欧氏距离会变 马氏度量的是数据的内在结构，欧氏度量的是坐标选择
    协方差相同 → 线性判别函数 → 超平面决策面 因为 \(x^{\mathsf{T}}\Sigma^{-1}x\) 这一项两类相同，做差时抵消
    协方差不同 → 二次判别函数 → 超二次曲面 二次项不再抵消，所以决策面弯了
    决策面垂直的是 \(w\)，不是两类均值连线 只有 \(\Sigma \propto I\) 时两者才重合
    做差时只丢掉与类别下标 \(i\) 无关的项 这是从本页到下一节所有化简的统一依据
    把特征映射到高维，弯曲边界可以变成超平面 二次判别函数 = 高维空间里的线性判别函数
