    聚类分析¶

    前面所有方法都假设训练样本带有标签。这一页换一种情形：

    没有标签，只看数据本身的分布，能不能发现结构？

    这就是无监督学习。它的目标不再是"分类别"， 而是"把相似的放到一起"——背后的假设是： 相似的样本属于同一个"簇"，而簇对应某种真实的潜在结构。

    聚类与分类的根本差别

    分类（有监督） 聚类（无监督）
    有没有标签 有 没有 ⚠
    目标 学一个映射 发现结构
    结果好不好 有客观标准（错误率） 没有唯一标准 ⚠
    类别数 已知 通常未知

    最后两行是关键难点： 聚类没有"正确答案"，所以同样的数据用不同方法会得到不同结果， 而且无法客观判断谁对 —— 只能靠领域判断和后验验证。

    一、K 均值：最常用也最需要小心¶

    1.1 目标函数¶

    把 \(n\) 个样本分成 \(K\) 个簇 \(C_1,\dots,C_K\)，最小化簇内平方和：

    \[ J = \sum_{k=1}^{K}\sum_{x_i \in C_k} \left\|x_i - \mu_k\right\|^2 \]

    其中 \(\mu_k\) 是第 \(k\) 个簇的均值：

    \[ \mu_k = \frac{1}{|C_k|}\sum_{x_i\in C_k}x_i \]

    这个目标函数的直觉：每个点到它所属簇中心的距离平方和越小， 簇就越"紧" ✓

    1.2 为什么必须迭代：两个耦合的未知量¶

    目标是同时求簇划分和簇中心，但两者互相依赖：

    未知量 依赖
    簇划分 \(C_k\) 要知道中心 \(\mu_k\) 才能决定谁属于谁
    簇中心 \(\mu_k\) 要知道划分 \(C_k\) 才能算出中心

    这是一个"鸡生蛋"的结构 —— 不能直接求解。 但固定其中一个，另一个就有闭式解：

    固定 求 闭式解
    中心 \(\mu_k\) 划分 \(C_k\) 每个点分给最近的中心 ✓
    划分 \(C_k\) 中心 \(\mu_k\) 簇内均值 ✓

    于是自然得到交替迭代：

    1. 分配步：把每个样本分给最近的中心
    2. 更新步：重算每个簇的均值
    3. 重复直到划分不再变化

    1.3 为什么一定收敛¶

    关键观察：每一步都不会让 \(J\) 增大。

    步骤 为什么 \(J\) 不增
    分配步 每个点分给最近的簇 → 该点的距离项取最小 ✓
    更新步 均值是使簇内平方和最小的点 —— 这正是「均值」的定义 ✓

    而 \(J\) 只能取有限多个值（划分方案是有限的）， 所以不可能无限下降 → 必收敛 ✓

    收敛 ≠ 全局最优

    K 均值收敛到的是局部最优，而且：

    ① 结果依赖初始化。不同初值可能给出完全不同的划分 ⚠ → 标准做法：多次随机初始化，取 \(J\) 最小的那次

    ② \(K\) 必须事先给定。给错了就是错的 —— 而且没有客观方法知道 \(K\) 对不对 ⚠

    ③ 只适合"球形、等大"的簇。因为用的距离是欧氏距离、 且隐含假设各簇方差相同 —— 遇到细长、大小悬殊、或套环状的簇会失败 ⚠

    ④ 对离群点敏感。均值不是稳健统计量， 一个远离的离群点会把簇中心整体拉偏 ⚠

    1.4 怎么选 K：肘部法与轮廓系数¶

    肘部法：画出 \(J\) 随 \(K\) 的变化，看拐点。

    为什么会有拐点：\(K\) 增大时 \(J\) 必然下降 （\(K=n\) 时 \(J=0\)），但下降速度在真实簇数附近会明显变缓 ✓

    import numpy as np

rng = np.random.default_rng(42)
X = np.vstack([rng.normal([0.0, 0.0], 0.55, size=(60, 2)),
               rng.normal([3.0, 1.0], 0.55, size=(60, 2)),
               rng.normal([1.0, 3.2], 0.55, size=(60, 2))])


def kmeans(X, K, seed=0):
    """返回 (划分, 中心, 目标函数值, 迭代轮数)。"""
    r = np.random.default_rng(seed)
    C = X[r.choice(len(X), K, replace=False)]
    for it in range(200):
        d = np.stack([np.linalg.norm(X - c, axis=1) for c in C], axis=1)
        lab = d.argmin(axis=1)
        C_new = np.array([X[lab == k].mean(axis=0) if (lab == k).any()
                          else C[k] for k in range(K)])
        if np.allclose(C_new, C):
            break
        C = C_new
    J = float(sum(np.sum((X[lab == k] - C[k]) ** 2)
                  for k in range(K)))
    return lab, C, J, it + 1


print("K 均值：目标函数随 K 单调下降（这是必然的）")
print("K".ljust(6) + "目标函数 J".ljust(14) + "迭代轮数".ljust(12) + "比上一行降幅")
prev = None
for K in [2, 3, 4, 5, 6]:
    _, _, J, it = kmeans(X, K, seed=7)
    drop = "-" if prev is None else "%.1f" % (prev - J)
    print(("%d" % K).ljust(6) + ("%.1f" % J).ljust(14)
          + ("%d" % it).ljust(12) + drop)
    prev = J

    轮廓系数：对每个样本算

    \[ s(i) = \frac{b(i) - a(i)}{\max\{a(i),\,b(i)\}} \]

    符号含义：

    符号 含义
    \(a(i)\) 样本 \(i\) 到同簇其他点的平均距离
    \(b(i)\) 样本 \(i\) 到最近的其他簇的平均距离

    读法：\(s(i)\) 接近 1 说明"离本簇近、离别的簇远"（分得好）； 接近 \(-1\) 说明可能分错了簇 ✓

    两者的分工：

    方法 给什么 局限
    肘部法 一个主观的拐点 拐点有时不明显 ⚠
    轮廓系数 每个 \(K\) 的平均得分 偏向凸形簇

    实践建议：两个都算，再结合领域知识定 ⚠

    import numpy as np

rng = np.random.default_rng(11)
X = np.vstack([rng.normal([0.0, 0.0], 0.55, size=(60, 2)),
               rng.normal([3.0, 1.0], 0.55, size=(60, 2)),
               rng.normal([1.0, 3.2], 0.55, size=(60, 2))])


def kmeans_once(X, K, seed):
    r = np.random.default_rng(seed)
    C = X[r.choice(len(X), K, replace=False)]
    for _ in range(200):
        d = np.stack([np.linalg.norm(X - c, axis=1) for c in C], axis=1)
        lab = d.argmin(axis=1)
        C_new = np.array([X[lab == k].mean(axis=0) if (lab == k).any()
                          else C[k] for k in range(K)])
        if np.allclose(C_new, C):
            break
        C = C_new
    return float(sum(np.sum((X[lab == k] - C[k]) ** 2)
                     for k in range(K)))

    二、模糊 K 均值¶

    2.1 硬分配的问题¶

    K 均值把每个点强制分给一个簇。 但边界附近的点，它的归属其实是不确定的。

    一个反直觉的例子：某个点恰好落在两个簇中间， K 均值会按"哪个中心近一点点"来决定 —— 但下一次迭代中心一动，它可能就跳到另一簇去了 ⚠

    2.2 引入隶属度¶

    模糊 K 均值（FCM）用隶属度 \(u_{ik}\in[0,1]\) 替代 0/1 分配， 满足归一化：

    \[ \sum_{k=1}^{K}u_{ik} = 1,\qquad i=1,\dots,n \]

    目标函数改为：

    \[ J_m = \sum_{i=1}^{n}\sum_{k=1}^{K} u_{ik}^{m}\left\|x_i-\mu_k\right\|^2 \]

    \(m\) 的含义：模糊指数，控制"模糊程度"。

    \(m\) 取值 效果
    \(m \to 1\) 退化为硬 K 均值 ✓
    \(m\) 增大 隶属度趋于均匀（更"模糊"）
    常用 \(m = 2\)

    2.3 更新式¶

    隶属度更新：

    \[ u_{ik} = \frac{1} {\displaystyle\sum_{j=1}^{K} \left(\dfrac{\|x_i-\mu_k\|}{\|x_i-\mu_j\|}\right)^{\frac{2}{m-1}}} \]

    怎么读这个式子：离谁近，谁的比例就大 —— 而且 \(u_{ik}\) 是所有簇距离比值的函数，不是只看最近的那个 ✓

    中心更新：

    \[ \mu_k = \frac{\sum_i u_{ik}^{m}x_i}{\sum_i u_{ik}^{m}} \]

    注意这是加权平均，权重是隶属度的 \(m\) 次方 ✓

    与 K 均值的关系：两者都是交替优化， FCM 只是把"硬分配"换成了"软权重" —— 思想与 EM 与混合模型 完全一致 ✓

    三、层次聚类¶

    3.1 不需要预先定 K¶

    这是它最大的优点：生成一棵聚类树， 想要几个簇就在树上切一刀 ✓

    3.2 两种方向¶

    方向 做法 复杂度
    凝聚（自下而上） 每个点算一个簇，逐步合并最近的 \(O(n^2\log n)\) 或更高
    分裂（自上而下） 全部算一个簇，逐步拆分 实现更难

    实践中最常用凝聚法 ✓

    3.3 关键的歧义：两个簇之间"距离"怎么定义¶

    这是层次聚类的核心设计选择，不同定义给出完全不同的结果 ⚠

    方法 簇间距离定义 倾向
    单链 两组间最近两点距离 容易形成长条状簇，会被离群点"拉链"⚠
    全链 两组间最远两点距离 倾向紧凑簇，对离群点稳健
    平均链 两组间所有点对平均距离 折中，最常用 ✓
    Ward 合并后簇内平方和增量最小 与 K 均值目标一致 ✓

    单链的"拉链效应"：只要两个簇各有一个点比较近， 它们就会被合并 —— 哪怕整体上两个簇离得很远 ⚠

    这是层次聚类最容易踩的坑。

    3.4 与 K 均值的对比¶

    对照项 K 均值 层次聚类
    是否要定 \(K\) 必须 ⚠ 不用 ✓
    结果形式 平坦划分 树
    确定性 依赖初值 确定 ✓
    复杂度 低 高（\(n\) 大时不可行）
    能否回溯 不能 切在别处即可 ✓

    实践建议：数据量小时用层次聚类探索结构， 确定 \(K\) 之后再用 K 均值（或 GMM）做最终划分 ✓

    四、谱聚类：换到"图"上看问题¶

    4.1 为什么需要它¶

    K 均值与层次聚类用欧氏距离， 所以对非凸形状（套环、双月）的簇会失败 ⚠

    关键思路转变：不比较"距离远近"，而比较"连接紧密程度" ✓

    4.2 建图与拉普拉斯矩阵¶

    把样本看成图的节点，用相似度做边的权重（如高斯核）：

    \[ w_{ij} = \exp\!\left(-\frac{\|x_i-x_j\|^2}{2\sigma^2}\right) \]

    构造度矩阵 \(D\)（对角元 \(d_i=\sum_j w_{ij}\)） 与拉普拉斯矩阵：

    \[ L = D - W \]

    为什么用拉普拉斯矩阵：它有两条极有用的性质 ——

    • \(L\) 的每一行和为 0（因为 \(d_i = \sum_j w_{ij}\)）→ 所以常数向量是零特征值对应的特征向量 ✓
    • \(L\) 半正定 → 所有特征值非负 ✓

    二次型的形式很关键（后面要用）：

    \[ f^{\mathsf T}Lf = \frac12\sum_{i,j}w_{ij}(f_i-f_j)^2 \]

    怎么读：相邻节点如果标签差别大，代价就大 ✓ 所以最小化这个二次型，就是让图上相邻的点标签尽量一致。

    4.3 从最小割到特征向量¶

    最朴素的聚类目标是最小化割：

    \[ \operatorname{cut}(A,B) = \sum_{i\in A,\,j\in B}w_{ij} \]

    但它有个退化解：把孤立的一个点切出去， 割就很小 —— 显然不是想要的 ⚠

    修正办法：归一化割（Ncut），除以各子集的"体积"：

    \[ \operatorname{Ncut}(A,B) = \frac{\operatorname{cut}(A,B)}{\operatorname{vol}(A)} + \frac{\operatorname{cut}(A,B)}{\operatorname{vol}(B)} \]

    松弛后的解：把"离散标签"放松成实数向量， 问题变成一个特征值问题：

    \[ (D-W)\,f = \lambda D f \]

    取前 \(k\) 个最小非零特征值对应的特征向量， 每个样本在这 \(k\) 个特征向量上的取值作为新坐标， 再对它们做 K 均值 ✓

    这就解释了谱聚类为什么能处理非凸簇： 它先把数据映射到"图结构"表示的新空间， 在那个空间里，同类样本自然聚在一起 ✓

    谱聚类的三个实操注意点

    ① 相似度函数的尺度 \(\sigma\) 极其关键。 \(\sigma\) 太小 → 图变成一堆孤立点（连自己都不连）； \(\sigma\) 太大 → 图变成全连接（失去结构信息）⚠ 常用做法：取到第 \(k\) 近邻距离的某种统计量。

    ② 图应该是稀疏的。若用全部样本对建图， 则为 \(O(n^2)\) 的矩阵，\(n\) 大时根本存不下 ⚠ 常用 \(k\) 近邻图或 \(\epsilon\) 邻域图。

    ③ 特征值分解的复杂度是 \(O(n^3)\)。 即使建图稀疏，稠密特征分解也很贵。 大 \(n\) 时需用稀疏特征求解器或近似方法 ⚠

    五、聚类有效性：怎么判断"分得好不好"¶

    5.1 外部指标（有真实标签时）¶

    如果能拿到一部分真实标签，可以用：

    指标 含义
    兰德指数 划分一致的样本对占比
    调整兰德指数 对随机划分做了修正
    F 值 把聚类结果与真实标签做匹配后算精确率/召回率

    5.2 内部指标（没有真实标签）¶

    指标 思路 越大越好？
    轮廓系数 本簇紧、离他簇远 是 ✓
    Davies–Bouldin 簇内散度 / 簇间距离 越小越好 ⚠
    Calinski–Harabasz 类间方差 / 类内方差 是 ✓

    注意第三行的方向：不同指标"越大越好"还是"越小越好"不同， 用之前一定要查清楚 ⚠

    import numpy as np

# 构造"同心圆环"，演示 K 均值为何必然失败
th = np.linspace(0, 2 * np.pi, 60, endpoint=False)
inner = np.column_stack([0.5 * np.cos(th), 0.5 * np.sin(th)])
outer = np.column_stack([1.8 * np.cos(th), 1.8 * np.sin(th)])
X = np.vstack([inner, outer])


def kmeans(X, K, seed=0):
    r = np.random.default_rng(seed)
    C = X[r.choice(len(X), K, replace=False)]
    for _ in range(200):
        d = np.stack([np.linalg.norm(X - c, axis=1) for c in C], axis=1)
        lab = d.argmin(axis=1)
        C_new = np.array([X[lab == k].mean(axis=0) if (lab == k).any()
                          else C[k] for k in range(K)])
        if np.allclose(C_new, C):
            break
        C = C_new
    return lab


lab = kmeans(X, 2, seed=3)
# 真实标签：前 60 个是内环，后 60 个是外环
truth = np.array([0] * 60 + [1] * 60)
# 统计"簇内同类比例"（越接近 1 说明划分越贴合真实结构）
agree = 0.0
for k in range(2):
    idx = np.where(lab == k)[0]
    if len(idx) == 0:
        continue
    frac0 = float((truth[idx] == 0).mean())
    agree += max(frac0, 1 - frac0) * len(idx)
print("同心圆环数据（内环 60 点 + 外环 60 点）")
print("K 均值划分为 2 簇后，簇内与真实结构一致的比例：%.3f"
      % (agree / len(X)))
print()
print("对照：每簇中心离原点的距离")
for k in range(2):
    idx = np.where(lab == k)[0]
    c = X[idx].mean(axis=0)
    print("  簇 %d 中心半径 = %.3f（点数为 %d）"
          % (k, float(np.linalg.norm(c)), len(idx)))
print()
print("结论：两个中心半径接近，说明 K 均值把圆环沿半径切开了 ⚠")

  簇 0 中心半径 = 0.708（点数为 62）
  簇 1 中心半径 = 0.757（点数为 58）

    内部指标不能替代领域判断

    所有内部指标都隐含了某种"好簇"的定义 （如紧扣、分离）。它们都会偏好凸形、等大的簇 ⚠

    后果：如果用轮廓系数去评价一个套环状的真实结构， 谱聚类的正确答案可能得分低于错误的 K 均值结果。

    所以指标只能作为参考，最终要靠：

    · 领域解释：分出来的簇有没有实际意义 · 稳定性：换抽样、换参数，划分是否稳定 · 外部验证：能否用独立数据或实验证实

    六、例题¶

    例题 1：手算一次 K 均值迭代¶

    题目：一维数据 \(\{1, 2, 4, 8, 9\}\)， 初始中心取 \(\mu_1=1\)、\(\mu_2=9\)。走一轮分配与更新。

    思路

    先按"离谁近"分配，再算每簇均值。

    解答

    第一步：分配（看与 1 和 9 的距离）。

    样本 到 1 的距离 到 9 的距离 分配给
    1 0 8 簇 1
    2 1 7 簇 1
    4 3 5 簇 1
    8 7 1 簇 2
    9 8 0 簇 2

    簇 \(C_1=\{1,2,4\}\)、\(C_2=\{8,9\}\)。

    第二步：更新中心。

    \[ \mu_1 = \frac{1+2+4}{3} = \frac{7}{3} \approx 2.33 \]
    \[ \mu_2 = \frac{8+9}{2} = 8.50 \]

    答案：中心变为 \(2.33\) 与 \(8.50\) ✓

    这说明什么：一轮之后中心已经明显向左移动。 下一轮会重新分配，这时 4 与 2.33 的距离是 1.67、 与 8.50 的距离是 4.5 —— 仍然留在簇 1，说明这个划分会稳定下来 ✓

    例题 2：算轮廓系数¶

    题目：某个点 \(i\) 到同簇其余点的平均距离 \(a(i)=2.0\)， 到最近另一簇的平均距离 \(b(i)=6.0\)。求轮廓系数并解释。

    思路

    直接代入 \(s = (b-a)/\max\{a,b\}\)。

    解答

    第一步：代入。

    \[ s(i) = \frac{6.0-2.0}{\max\{2.0,\ 6.0\}} = \frac{4.0}{6.0} \approx 0.667 \]

    答案：约 \(0.667\) ✓

    第二步：解读。

    \(s(i)\) 的取值范围是 \(-1\) 到 \(1\)：

    取值 含义
    接近 1 离本簇很近，离别的簇很远 → 分得好 ✓
    接近 0 两个距离差不多 → 归属模糊 ⚠
    接近 \(-1\) 离别的簇更近 → 可能分错了 ⚠

    \(0.667\) 属于"分得不错"的范围。

    这说明什么：轮廓系数是每个样本一个数， 可以找出"最可疑的那些点"（\(s\) 最小的）， 这对排查异常样本很有用 ✓

    例题 3：单链聚类的"拉链"效应¶

    题目：两个簇，簇 1 有点 \((0,0)\)、\((1,0)\)、\((2,0)\)， 簇 2 有点 \((100,0)\)、\((101,0)\)。 用单链（最近点距离）做层次聚类，它们会在哪一步合并？ 这个结果合理吗？

    思路

    单链只看最近的两个点，不论它们各自属于哪个簇。

    解答

    第一步：算簇间最近距离。

    簇 1 中离簇 2 最近的是 \((2,0)\)； 簇 2 中离簇 1 最近的是 \((100,0)\)。

    \[ d_{\text{单链}} = 100 - 2 = 98 \]

    第二步：与其他合并比较。

    簇 1 内部相邻点距离是 1；簇 2 内部是 1。 所以合并顺序是：先簇内合并（距离 1）， 然后这两个簇在距离 98 时合并。

    第三步：判断合理性。

    这看起来没问题（98 远大于 1）。 但若簇 1 里再多一个点 \((99,0)\)（离群点）， 单链距离就骤降到 1，两个簇会立刻合并 ⚠

    答案：本例合并距离 98；但单链对离群点极其敏感， 一个"桥接点"就能让远处的簇被合并。

    这说明什么：这就是拉链效应。 改用全链或平均链可以避免 （它们要看所有点对，单个桥接点影响有限）✓

    例题 4：判断该用哪种方法¶

    题目：三组数据，分别说明适合用哪种聚类方法并给出理由。 （甲）样本量大、簇近似球形且大小接近； （乙）数据量小，不知道有几个簇，想先看结构； （丙）簇是"同心圆环"形状。

    思路

    从形状假设、数据量、是否需要预先定 K 三个角度考虑。

    解答

    甲：K 均值（或 GMM）。

    · 球形、等大 → 正好符合 K 均值的隐含假设 ✓ · 样本量大 → K 均值复杂度低（每次迭代 \(O(nKd)\)）✓

    乙：层次聚类。

    · 不用预先定 \(K\) → 可以从树状图上观察结构 ✓ · 数据量小 → \(O(n^2\log n)\) 的复杂度可以接受 ✓

    丙：谱聚类。

    · 同心圆环是非凸的 → K 均值/层次聚类必然失败 ⚠ · 谱聚类先建图再谱分解，不依赖欧氏距离的凸性 ✓

    答案：甲用 K 均值，乙用层次聚类，丙用谱聚类。

    这说明什么：没有"最好的"聚类算法，只有"适合"的 ⚠

    选择依据是三条：

    依据 影响
    簇的形状假设 决定算法族（距离型 vs 图型）
    数据量 决定复杂度上限
    是否知道 \(K\) 决定能否用层次聚类探索

    七、自测¶

    Q1 为什么 K 均值必须交替迭代而不能直接求解？ 说明每一步为什么都不会让目标函数增大。

    Q2 单链与全链聚类的区别是什么？"拉链效应"是怎么产生的？

    Q3 谱聚类为什么能处理非凸形状的簇？ 它把问题转化成了什么数学形式？

    Q4 内部有效性指标有什么共同局限？ 在没有真实标签时，应该靠什么来判断聚类结果是否可信？

    八、小结¶

    方法 核心机制 要不要定 K 适合的簇形状 主要风险
    K 均值 交替「分配 / 更新」，最小化簇内平方和 要 ⚠ 球形、等大 初值敏感、离群点敏感
    模糊 K 均值 用隶属度替代硬分配 要 同上，但输出软归属 模糊指数 \(m\) 要调
    层次聚类 逐步合并，生成树 不要 ✓ 取决于簇间距离定义 单链的拉链效应 ⚠
    谱聚类 建图 + 拉普拉斯特征分解 要 非凸（套环等）✓ 尺度参数与 \(O(n^3)\) 代价

    三条最该带走的结论：

    1. 聚类没有唯一正确答案 —— 没有标签就没有客观标准，指标只能参考， 最终要靠领域解释 + 稳定性 + 外部验证 ✓
    2. 选算法先看簇的形状假设 —— 用欧氏距离的方法（K 均值、层次聚类） 在非凸结构上必然失败，这时要换谱聚类 ⚠
    3. K 均值的每一步都不让目标函数增大，所以必收敛 —— 但收敛到的是局部最优， 必须多初值取最好 ⚠
