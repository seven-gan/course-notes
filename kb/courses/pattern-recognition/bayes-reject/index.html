    带拒识的决策¶

    上一页 最小错误率决策 把判决规则本身讲清了： 在每一个 \(x\) 上，都判给后验概率最大的那一类，平均错误率最小。 这一页要给它补上一个经常被忽略的选项：

    可不可以不判？

    答案是可以，而且这个选项有正式的名字 —— 拒识（reject）。 加上拒识之后，分类器的输出就从「\(c\) 个类别里挑一个」 变成「\(c\) 个类别里挑一个，或者承认我拿不准」。

    三个说法看着差不多，差别却很大：

    容易接受的说法 实际差别 后果
    分类器就应该给每个样本一个标签 漏掉了「承认拿不准」也是个合法输出 逼着分类器在边界样本和陌生样本上硬判，产生高代价的错判 ⚠
    拒识就是分类失败 拒识是一次主动的、经过计算的动作，有成本也有收益 把拒识当失败，就不敢用，白白错过降低错判率的机会
    阈值越高越安全 提高阈值确实降低错判率，但拒识率会迅速上升 大量样本被推到人工环节，处理不过来，系统事实上不可用 ⚠

    这一页的主线

    整页只做一件事：把「拒识」看成第 \(c+1\) 个决策动作， 然后在 \(c+1\) 个动作里挑期望损失最小的那个。

    这样一看，拒识和「判 \(\omega_1\)」「判 \(\omega_2\)」是同一种东西 —— 都是一个动作，都要算它要付多少代价，然后比大小 ✓

    落地路线：

    步 做什么 在哪一节
    1 说清为什么需要拒识、拒识有哪两种情形 一、二
    2 定义拒识阈值 \(T\)，写出判决规则，并画出三个区域 三
    3 定义三个指标，并验证三者之和恒等于 \(1\) 四
    4 说清拒识的代价（它不是免费的） 五
    5 从风险最小化出发，一步步推出最优阈值 六
    6 推广到多类情形，再看开放集识别 七、八
    7 把结论落到医疗、门禁、驾驶、审核四个场景 九

    这一页几乎不依赖代码：全部结论都用纸笔推得出来， 只在五个关键位置用代码复核一遍（判别边界与拒识区端点、三个指标、 \(T\) 扫描、被拒样本的成分、损失取极端值）， 防止推导里的算术错误溜过去 ✓

    一、为什么需要拒识¶

    1.1 本课程课件给出的理由：错判会带来严重后果¶

    本课程课件引入这一节时，只写了很短的一句，但这句话是整节的起点：

    错误识别可能带来严重后果。 是否每次一定要做出决策？ 在有的情况下，不做决策比做出错误率很大的决策会更好。

    这句话其实含两个论断，都要拆开读：

    论断 它在说什么 为什么重要
    错误识别可能带来严重后果 「判错」的代价不是零，而且不同错误的代价往往不一样 说明错误率不是唯一值得看的度量
    不做决策可能比做出错误率很大的决策更好 「不判」是一个可以被选中的动作 说明判决动作的集合里应该多一个成员 ✓

    关键在第二个论断：它把「不判」从「系统出故障」 重新定义成了「系统的一个正常选项」。

    1.2 落到具体场景，代价有多大¶

    先看四个场景里，「硬判」和「拒识」各会发生什么。

    场景 如果硬判一个类会怎样 如果允许拒识会怎样
    医疗辅助诊断 把可疑病灶判成「正常」，患者被放回家观察 ⚠ 标成「可疑」，转给医生重点看这一张片子 ✓
    自动驾驶 把横穿的行人判成「路面」，直接碾过去 ⚠ 标成「不确定」，减速或交给人接管 ✓
    金融风控 把欺诈交易判成「正常」，资金已经被转走 ⚠ 标成「高风险」，转人工复核后再放行 ✓
    内容审核 把高风险内容判成「安全」，内容直接上线 ⚠ 标成「需复核」，转人工判断 ✓

    这四个场景有同一个结构：

    • 错判的代价很大，而且两类错误的代价并不对称；
    • 拒识的代价只是多花一点人力或者时间；
    • 所以「多花一点人力」和「错一次」之间，天平明显偏向前者 ✓

    1.3 「拒识」不是分类失败¶

    把拒识当成「分类失败」是最常见的误解

    拒识不是分类器坏掉了，也不是「没算出来」。

    它是一次主动的、经过计算的输出： 分类器明确地说「这个样本我没有把握，请交给别的环节」。

    反过来想一想：如果分类器从不说自己不确定， 那么它在边界样本和陌生样本上给出的标签， 和它在简单样本上给出的标签长得一模一样 ⚠ 使用者完全无从分辨哪些结果可信 —— 这才是真正危险的地方。

    再把「拒识」这笔账的两面摊开：

    拒识带来的 具体是什么
    收益 错判率下降；那些后果严重的错判被提前拦下来 ✓
    成本 被拒的样本必须有别的环节接着处理（人工、更慢的检测、更多传感器），要花时间和钱 ⚠
    结论 拒识是有代价的选项，不是免费的好事 —— 值不值得拒，要用损失去算（第六节）

    最后，本课程课件在这一页的配图里还特意举了一类很典型的样本： 把英文字母送进数字识别器、把不认识的符号送进字母识别器。 这些样本本来就不该被判成任何一类。 这类问题叫开放集问题，第八节专门讲。

    1.4 这一节用到的记号¶

    为了避免和上一页脱节，先把这一页反复用到的符号列出来。 前五个与 最小错误率决策 完全一致，不再重新解释。

    记号 含义 取值范围
    \(\omega_i\) 第 \(i\) 个类别，\(i = 1, 2, \dots, c\) 离散，共 \(c\) 个
    \(x\) 观测到的特征（这一页大多用一维，便于画图） 实数
    \(P(\omega_i)\) 先验概率 \([0, 1]\)，\(\sum_i P(\omega_i) = 1\)
    \(p(x \mid \omega_i)\) 类条件概率密度 非负，可大于 \(1\)
    \(P(\omega_i \mid x)\) 后验概率 \([0, 1]\)，\(\sum_i P(\omega_i \mid x) = 1\)
    \(T\) 拒识阈值，本页的主角 \([0, 1]\)（更常见的是 \([1/c, 1)\)）
    \(\lambda_e\) 判错一个样本的损失 正数
    \(\lambda_r\) 拒识一个样本的损失 正数，一般 \(\lambda_r \lt \lambda_e\)
    \(\mathcal{A}_i\) 判决区：判为 \(\omega_i\) 的 \(x\) 的集合 实数轴上的一段
    \(\mathcal{R}\) 拒识区：拒识的那些 \(x\) 的集合 实数轴上的一段
    \(\omega_{\text{reject}}\) 「拒识」这个动作所代表的第 \(c+1\) 类 它不是真实类别，是一个动作 ✓

    最后一行要特别说明：本课程课件把拒识写成「\(c+1\) 个类」， 意思是把「拒识」当成一个独立的决策动作， 在 \(c+1\) 个动作里挑期望损失最小的那一个。

    所以「\(\omega_{\text{reject}}\)」不代表一种真实存在的样本， 它代表一个动作。这个视角是整节推导的关键 ✓

    为什么要专门造一个动作，而不是把拒识当成一个「额外的类」： 因为类和动作的代价结构不同。真实类别的样本有先验、有密度、有分布形状； 而「拒识」这个动作没有任何分布假设， 它只有一个价格，而且这个价格与样本长什么样无关（第 5.2 节会正式说明）。 把这一点记住，第六节的推导就只是代公式了 ✓

    二、拒识的两种情形¶

    「我拿不准」其实包含两种完全不同的情况， 分不清这两种，后面的阈值就会用错地方。

    2.1 情形一：样本不属于任何已知类¶

    这是什么情况： 测试时送进来的样本，根本不属于训练时定义的那 \(c\) 个类。 它可能来自一个新出现的类，也可能是传感器故障、异常噪声。

    它长什么样： 它远离所有已知类的中心，落在所有已知类密度的很低的尾巴上。

    难点在这里： 如果只看后验概率，你会发现不了它 —— 因为后验是归一化过的， 无论 \(x\) 多离谱，\(\sum_i P(\omega_i \mid x) = 1\) 总成立， 于是总有一个「相对最像」的类跳出来 ⚠

    所以识别情形一必须用别的量，例如：

    可用的量 为什么它有用
    到最近类中心的距离（按标准差计） 距离大 → 不在任何已知类附近
    已知类的密度值 \(p(x \mid \omega_i)\) 本身 它没有归一化，可以直接和「多小算小」比较
    给「未知类」也配一个先验与密度 把未知变成一个能被比较的类（第八节）

    2.2 情形二：样本落在两类边界附近¶

    这是什么情况： 样本确实属于已知的某一类，但它落在两类分布的重叠区里， 两类看起来都像。

    它长什么样： 最大后验概率接近 \(1/c\)。两类情形下，就是 \(P(\omega_1 \mid x)\) 和 \(P(\omega_2 \mid x)\) 都在 \(0.5\) 附近。

    难点在哪里： 这一类样本用后验就看得出来 —— 最大值不够大， 说明证据不够，谁都不能确定 ✓

    它为什么难以避免： 上一页已经说明过，只要两类分布有重叠， 重叠区的样本必然有一部分会被判错， 这部分错误率是贝叶斯错误率的一部分 ⚠ 拒识不能消掉重叠，但可以把重叠区里没把握的样本挑出来。

    2.3 两种情形的对照¶

    把两种情形放在一起看，区别就清楚了。

    2.4 只按后验分不清这两种情形¶

    这一点值得单独强调，因为它是新手最常踩的坑。

    后验的定义是

    \[P(\omega_i \mid x) = \frac{p(x \mid \omega_i)\,P(\omega_i)}{\sum_{j=1}^{c} p(x \mid \omega_j)\,P(\omega_j)}\]

    怎么读这个式子：分母是同一个数（对所有 \(i\) 都一样）。 所以分子全都极小时，后验照样被「放大」成一组和为 \(1\) 的数， 其中必然有一个是最大的。

    为了把这件事算清楚，先固定这一页后面反复使用的两类分布：

    类别 均值 \(\mu\) 标准差 \(\sigma\) 先验 \(P\)
    \(\omega_1\) \(15\) \(3\) \(0.6\)
    \(\omega_2\) \(22\) \(4\) \(0.4\)

    这两个先验不相等，所以两类密度曲线高度不一样， 判决边界也不会落在两类中心的正中间。

    再把这两个类条件密度画出来：

    图里的两条曲线是加权密度 \(P(\omega_i)\,p(x \mid \omega_i)\)。 判决边界恰好落在它们相交的位置，因为相交就意味着两类的分子相等， 于是两个后验都等于 \(0.5\)，分不出高下。

    现在做一个纯粹的手算对照。取 \(x = 33\) 这个样本：

    第一步：算它离两个类中心各有多远（以标准差为单位）。

    \[\frac{\lvert 33 - 22 \rvert}{4} = \frac{11}{4} = 2.75 \ \text{个} \ \sigma\]
    \[\frac{\lvert 33 - 15 \rvert}{3} = \frac{18}{3} = 6 \ \text{个} \ \sigma\]

    第二步：算两个类条件密度。先算常数因子：

    \[\frac{1}{\sigma_1\sqrt{2\pi}} = \frac{1}{3 \times 2.506628} = \frac{1}{7.519884} = 0.132981\]
    \[\frac{1}{\sigma_2\sqrt{2\pi}} = \frac{1}{4 \times 2.506628} = \frac{1}{10.026513} = 0.099736\]

    再算指数上的那一项。对 \(\omega_1\) 是 \((33-15)^2 = 324\)， 除以 \(2\sigma_1^2 = 18\) 得 \(18\)；对 \(\omega_2\) 是 \((33-22)^2 = 121\)， 除以 \(2\sigma_2^2 = 32\) 得 \(3.78125\)。代入：

    \[p(33 \mid \omega_1) = 0.132981 \times e^{-18} \approx 0.132981 \times 1.522998 \times 10^{-8} \approx 2.025 \times 10^{-9}\]
    \[p(33 \mid \omega_2) = 0.099736 \times e^{-3.78125} \approx 0.099736 \times 0.022852 = 2.279 \times 10^{-3}\]

    第三步：乘先验得分子。

    \(\omega_2\) \(2.279 \times 10^{-3}\) \(0.4\) \(9.116 \times 10^{-4}\)

    \[P(\omega_2 \mid 33) = \frac{9.116 \times 10^{-4}}{9.116 \times 10^{-4}} \approx 1.000000\]
    \[\max_i P(\omega_i \mid 33) \approx 1.000000\]

    三、拒识的判决规则¶

    3.1 从「比大小」改成「够不够大」¶

    上一页的判决规则是比大小：谁的后验最大就判谁。 这条规则有一个隐含假设：

    每个样本都一定要被贴上某个标签。

    拒识的做法就是把这条假设拆掉，加一个门槛： 后验最大的那一类，光最大还不够，还要足够大。

    引入拒识阈值 \(T\) 之后，判决规则写成：

    \[ \text{判 } \omega_i \text{ 当 } P(\omega_i \mid x) = \max_{j=1,\dots,c} P(\omega_j \mid x) \gt T; \qquad \text{否则拒识} \]

    怎么读这个规则： 「先找出后验最大的那一类。 如果这个最大值超过了门槛 \(T\)，就判给它； 否则（最大值都没过门槛）就说明没有任何一类足够有把握 —— 拒识。」

    等号归哪边

    这条规则里，边界情形 \(P(\omega_i \mid x) = T\) 的样本判拒识（因为条件写的是 \(\gt\)）。 这个约定很重要，它保证了 \(T\) 减小时不拒识的样本集合单调不减： \(T\) 取某个值时被拒的样本，在 \(T\) 更小时一定也还会被拒 ✓

    换句话说，拒识区域随着 \(T\) 增大而单调扩大， 这样后面才会出现「\(T\) 上升 → 拒识率上升」这样干净的单调性。

    3.2 为什么门槛设在「最大后验」上¶

    这个设计有三个层次的理由，缺一层理解都不牢。

    第一层：判决的成败只看被选中的那一类。

    判决规则的动作是「选中后验最大的那一类」。 给定 \(x\) 之后，条件错误率（上一页算过）是

    \[P(\text{error} \mid x) = 1 - \max_{j=1,\dots,c} P(\omega_j \mid x)\]

    怎么读这个式子：判错的概率 = \(1\) 减去「被选中那一类的后验」。 注意这个式子里只出现最大值，别的后验都不出现。 所以要衡量「这次判决有多不可靠」，唯一相关的量就是最大值。\(\square\)

    第二层：用非最大类的后验当门槛，含义就会被搞乱。

    假设改成「\(P(\omega_{\text{次大}} \mid x) \gt T\) 时才判决」， 那含义变成「第二像的类得挺像的才判决」—— 这其实是在要求证据冲突足够大， 它和「判决是否可靠」不是同一件事，而且多类情形下完全没有统一的读法 ⚠

    第三层：\(T\) 要和一个有上界的量比较。

    后验的概率范围是 \([1/c, 1]\)（\(c\) 类的情形：最大值至少是 \(1/c\)，至多是 \(1\)）。 所以 \(T\) 的物理意义非常清楚： 「要求被选中那一类的后验至少达到 \(T\)」—— 这句话不需要任何额外解释就能说出来 ✓

    3.3 先把「最大后验」这个量算出来¶

    规则里反复出现 \(\max_j P(\omega_j \mid x)\)，所以先给它一个名字：

    \[\mathrm{maxP}(x) \;=\; \max_{j=1,\dots,c} P(\omega_j \mid x)\]

    怎么读它：maxP 是这次判决的自信度。 它接近 \(1\) 表示「几乎确定」，接近 \(1/c\) 表示「几类都差不多」。

    现在把两类情形下 maxP 的取值逐个手算出来。两个后验满足

    \[P(\omega_1 \mid x) + P(\omega_2 \mid x) = 1\]

    所以只要算出一个，另一个就是 \(1\) 减它，而

    \[\mathrm{maxP}(x) = \max\bigl(P(\omega_1 \mid x),\ 1 - P(\omega_1 \mid x)\bigr)\]

    以 \(x = 19.5\) 为例，一步步算到底。

    第一步：两个类条件密度。 常数因子在 2.4 节已经算过， 是 \(0.132981\) 与 \(0.099736\)。

    \[p(19.5 \mid \omega_1) = 0.132981 \times \exp\Bigl[-\frac{(19.5-15)^2}{2 \times 3^2}\Bigr] = 0.132981 \times e^{-1.125}\]

    \(e^{-1.125} = 0.324652\)，所以 \(p(19.5 \mid \omega_1) = 0.043173\)。

    \[p(19.5 \mid \omega_2) = 0.099736 \times \exp\Bigl[-\frac{(19.5-22)^2}{2 \times 4^2}\Bigr] = 0.099736 \times e^{-0.195313}\]

    \(e^{-0.195313} = 0.822578\)，所以 \(p(19.5 \mid \omega_2) = 0.082040\)。

    第二步：乘先验得分子。

    类 似然 先验 分子
    \(\omega_1\) \(0.043173\) \(0.6\) \(0.025904\)
    \(\omega_2\) \(0.082040\) \(0.4\) \(0.032816\)

    第三步：分母与两个后验。

    \[\text{分母} = 0.025904 + 0.032816 = 0.058720\]
    \[P(\omega_1 \mid 19.5) = \frac{0.025904}{0.058720} = 0.441139 \qquad P(\omega_2 \mid 19.5) = \frac{0.032816}{0.058720} = 0.558861\]

    第四步：取最大值。 校验一下两个后验之和： \(0.441139 + 0.558861 = 1.000000\) ✓ 于是

    \[\mathrm{maxP}(19.5) = 0.558861\]

    同样地手算几个位置，就得到这张 maxP 对照表：

    \(x\) \(P(\omega_1 \mid x)\) \(P(\omega_2 \mid x)\) \(\mathrm{maxP}(x)\)
    \(15.0\) \(0.902419\) \(0.097581\) \(0.902419\)
    \(19.5\) \(0.441139\) \(0.558861\) \(0.558861\)
    \(24.0\) \(0.024558\) \(0.975442\) \(0.975442\)
    \(30.0\) \(0.000055\) \(0.999945\) \(0.999945\)

    读这张表要注意三件事：

    观察 数字 含义
    不拒识时的判决边界 \(t = 19.134613\) 这就是上一页算过的那个边界，与拒识无关 ✓
    边界处的 maxP 恰好 \(0.5\) 两类平票，这是「最没把握」的位置，必然被拒（只要 \(T \gt 0.5\)）
    远离边界处的 maxP \(30\) 处达到 \(0.999945\) 样本越典型，自信度越高，越不会被拒 ✓

    所以拒识的作用范围是「边界附近的一圈」， 而不是随机地把样本扔掉。这一点在第五节会用数字再确认一次。

    3.4 阈值 \(T\) 的取值含义¶

    \(T\) 是这一节唯一的可调参数，它的取值范围和每个特殊值都要说清。

    \(T\) 的取值 效果 说明
    \(T = 0\)（或 \(\to 0\)） 相当于不拒识 因为 \(\max_j P(\omega_j \mid x) \geq 1/c \gt 0\) 恒成立，条件总满足 ✓
    \(T \leq 1/c\) 也相当于不拒识 多类情形下 maxP 的下界是 \(1/c\)，门槛压到 \(1/c\) 以下就没有筛掉任何样本
    \(T\) 增大 拒识率上升、错误识别率下降 门槛变严，更多「没把握」的样本被推出判决 ✓
    \(T \to 1\) 几乎全部拒识 ⚠ 只有 maxP 精确等于 \(1\) 的样本才判；在连续分布下这种样本测度为零
    \(T = 1\) 全都拒识 除非后验恰好等于 \(1\)，而这要求另一类的后验恰好为 \(0\)

    不要把 T 和「判决边界」混为一谈

    这是新手最容易混淆的一对概念：

    概念 是多少个点 / 段 是谁在动 改变它会影响
    判决边界 \(t\)（两类时是一个点） 一个点 由先验与类条件密度决定 判 \(\omega_1\) 还是判 \(\omega_2\)，不影响是否拒识
    拒识阈值 \(T\) 一个数 由损失决定（第六节） 判还是拒，不影响判给哪一类

    换句话说：判决边界决定「判给谁」，阈值 \(T\) 决定「判还是不判」。 这是两件互相独立的事 ✓

    在两类情形下，这两件事合起来正好把整条实数轴切成了三段： \(\{\text{判 } \omega_1\} \cup \{\text{拒识}\} \cup \{\text{判 } \omega_2\}\)， 中间的拒识段夹在两个判决区之间。

    3.5 拒识区的几何图像¶

    把上一小节的结论画出来，三个区域的位置就一目了然。

    在两类情形下，\(P(\omega_1 \mid x)\) 随 \(x\) 单调下降，于是：

    • 在判决边界左侧，\(\omega_1\) 的后验更大，\(\mathrm{maxP} = P(\omega_1 \mid x)\)； 条件 \(P(\omega_1 \mid x) \lt T\) 把最左边一小段划进拒识区；
    • 在判决边界右侧，\(\omega_2\) 的后验更大，\(\mathrm{maxP} = P(\omega_2 \mid x) = 1 - P(\omega_1 \mid x)\)； 条件 \(1 - P(\omega_1 \mid x) \lt T\) 把最右边一小段划进拒识区；
    • 中间剩下的一段同时不满足这两个条件，没有过门槛的类，于是拒识。

    图里三个区域的分工是： 左段判 \(\omega_2\)、中间拒识、右段判 \(\omega_1\)。 两条竖直虚线就是拒识区的两端。

    注意两个判决区在左右两侧「换了位」： 这是两类先验与方差都不相等时常见的现象 —— \(\omega_1\) 的方差小（\(\sigma_1 = 3\)），密度在中心处更高但衰减更快， 所以极左端反而由 \(\omega_2\) 胜出。

    对 \(T = 0.8\)，两个端点可以精确算出来：

    端点 位置 满足什么条件
    左端点 \(lo\) \(16.746253\) \(\mathrm{maxP}(lo) = P(\omega_1 \mid lo) = 0.8\)
    右端点 \(hi\) \(21.151045\) \(\mathrm{maxP}(hi) = P(\omega_2 \mid hi) = 0.8\)
    区间 判决 区间长度
    \((-\infty,\ 16.746253)\) 判 \(\omega_1\) ✓ 无限长
    \([16.746253,\ 21.151045]\) 拒识 ⚠ \(4.404792\)
    \((21.151045,\ +\infty)\) 判 \(\omega_2\) ✓ 无限长

    两个区间的端点都由 \(P(\omega_1 \mid x)\) 决定，这一点很关键：

    \[P(\omega_1 \mid lo) = 0.8 \quad \text{（左侧 } \omega_1 \text{ 领先，用它自己的阈值）}\]
    \[P(\omega_1 \mid hi) = 1 - 0.8 = 0.2 \quad \text{（右侧 } \omega_2 \text{ 领先，所以要对 } \omega_2 \text{ 用阈值）}\]

    所以只要会解 \(P(\omega_1 \mid x) = 0.8\) 和 \(P(\omega_1 \mid x) = 0.2\) 这两个方程， 拒识区的端点就是解析可求的，不必靠画图目测 ✓

    3.6 三种等价写法¶

    规则用「最大后验」写最直观，但实际计算里还常用另外两种写法。 它们在数学上完全等价，只是换个量来比较更顺手。

    两类情形（\(c = 2\)）先说清楚。记 \(p_1 = P(\omega_1 \mid x)\)，\(p_2 = P(\omega_2 \mid x)\)， 两者之和为 \(1\)。

    （a）最大后验形式

    \[\text{判决 当 } \max(p_1, p_2) \gt T\]

    （b）后验差值形式

    设 \(p_1 \geq p_2\)，则 \(\max(p_1, p_2) = p_1\)。把 \(p_2 = 1 - p_1\) 代进去：

    \[\lvert p_1 - p_2 \rvert = p_1 - p_2 = p_1 - (1 - p_1) = 2p_1 - 1 = 2\max(p_1,p_2) - 1\]

    所以 \(\max(p_1,p_2) \gt T\) 等价于

    \[\lvert p_1 - p_2 \rvert \gt 2T - 1\]

    怎么读它：两类情形下，两个后验的差超过 \(2T-1\) 才判决。 \(T = 0.5\) 时门槛是 \(0\)（总满足，即不拒识）； \(T = 0.75\) 时门槛是 \(0.5\)（两个后验至少差一半）✓

    （c）似然比形式

    多类的后验比不方便，但两类的似然比很常用。 记 \(L(x) = \dfrac{p(x \mid \omega_1)}{p(x \mid \omega_2)}\)。 后验之比与似然比只差一个与 \(x\) 无关的因子：

    \[\frac{P(\omega_1 \mid x)}{P(\omega_2 \mid x)} = \frac{p(x\mid\omega_1)}{p(x\mid\omega_2)} \cdot \frac{P(\omega_1)}{P(\omega_2)} = L(x)\cdot\frac{P(\omega_1)}{P(\omega_2)}\]

    如果先验相等（\(P(\omega_1) = P(\omega_2)\)），那么两个后验之比就等于似然比。 此时「\(\max(p_1,p_2) \gt T\)」等价于

    \[L(x) \gt \frac{T}{1-T} \qquad \text{或} \qquad L(x) \lt \frac{1-T}{T}\]

    怎么读它：\(T/(1-T)\) 就是「一边压倒另一边」的似然比门槛。 \(T = 0.8\) 时门槛是 \(4.0\)，意思是证据要强到 4 倍以上才判决 ✓

    \(16.0\) \(0.853500\) \(0.707100\) 超过 ✓ 判 \(\omega_1\)
    \(16.7\) \(0.803830\) \(0.607700\) 超过 ✓ 判 \(\omega_1\)
    \(17.0\) \(0.777700\) \(0.555400\) 不到 拒识 ⚠
    \(21.0\) \(0.218300\) \(0.563400\) 不到 拒识 ⚠
    \(21.2\) \(0.194300\) \(0.611400\) 超过 ✓ 判 \(\omega_2\)
    \(24.0\) \(0.024558\) \(0.950884\) 超过 ✓ 判 \(\omega_2\)

    写法 什么时候更顺手
    最大后验形式 讲道理、写规则时最直接；多类情形下只有这一种能直接推广 ✓
    后验差值形式 两类情形下便于画「差值曲线」，也便于和 K-L 类分析衔接
    似然比形式 先验相等时可约掉归一化，测量上只需比两个密度之比 ⚠ 只在两类时方便

    四、拒识的三个指标¶

    有了规则，接着要问：这套规则表现到底怎么样？ 答案不再是「正确率 + 错误率」两个数，而是三个数。

    4.1 三个指标的定义¶

    先定义判决区域。给定阈值 \(T\)，把特征空间切成这些部分：

    记号 含义
    \(\mathcal{A}_i\) 判决区：判为 \(\omega_i\) 的 \(x\) 的集合，\(i = 1, 2, \dots, c\)
    \(\mathcal{R}\) 拒识区：拒识的 \(x\) 的集合

    一个样本送进来，只可能有三种结果，而且三者互斥：

    结果 什么时候发生
    判对 \(x \in \mathcal{A}_i\) 且真实类别就是 \(\omega_i\)
    判错 \(x \in \mathcal{A}_i\) 但真实类别是 \(\omega_j\)（\(j \neq i\)）
    拒识 \(x \in \mathcal{R}\)

    对应地定义三个指标（都按全体样本为分母）：

    \[p_c = P(\text{判对}), \qquad p_e = P(\text{判错}), \qquad p_r = P(\text{拒识})\]

    怎么读它们： \(p_c\) 是正确识别率，\(p_e\) 是错误识别率（也就是错误率）， \(p_r\) 是拒识率。三者都是概率，都在 \([0, 1]\) 内。

    把 \(p_c\) 展开成积分，就看得出它和判决区的关系：

    \[p_c = \sum_{i=1}^{c} \int_{\mathcal{A}_i} P(\omega_i \mid x)\, p(x)\, \mathrm{d}x = \sum_{i=1}^{c} P(\omega_i)\int_{\mathcal{A}_i} p(x \mid \omega_i)\, \mathrm{d}x\]

    怎么读它：左边按「后验」写，右边按「类条件密度乘先验」写， 两者相等是因为 \(P(\omega_i \mid x) p(x) = p(x \mid \omega_i) P(\omega_i)\)。 注意积分只在 \(\mathcal{A}_i\) 上做 —— 拒识区的样本不进这个积分 ✓

    错误识别率同样写成「在判决区上积分条件错误率」：

    \[p_e = \sum_{i=1}^{c} \int_{\mathcal{A}_i} \bigl[1 - P(\omega_i \mid x)\bigr]\, p(x)\, \mathrm{d}x\]

    怎么读它：\(1 - P(\omega_i \mid x)\) 就是上一页算过的条件错误率， 现在只在判决区上积分。拒识区的条件错误率不被计入 ✓

    而拒识率最简单：

    \[p_r = \int_{\mathcal{R}} p(x)\, \mathrm{d}x\]

    怎么读它：被拒那一段的概率质量，与判决对不对完全无关 ✓

    4.2 三者的关系：和恒等于 1¶

    三个指标之间有一条非常干净的关系：

    \[p_c + p_e + p_r = 1\]

    推导（不跳步）。取任意一个样本 \(x\)，按上面的判决区域划分： 它要么落在拒识区 \(\mathcal{R}\)，要么落在某个判决区 \(\mathcal{A}_i\)； 落在 \(\mathcal{A}_i\) 时，它的真实类别要么是 \(\omega_i\)、要么不是。于是三种情况

    \[\underbrace{x \in \mathcal{R}}_{p_r}, \qquad \underbrace{x \in \mathcal{A}_i \text{ 且真实类别是 } \omega_i}_{p_c}, \qquad \underbrace{x \in \mathcal{A}_i \text{ 且真实类别不是 } \omega_i}_{p_e}\]

    互斥且穷尽（覆盖了所有可能），所以概率加起来是 \(1\)。\(\square\)

    换成积分写一遍，会更清楚「为什么恰好是 1」：

    \[\int_{\mathcal{A}} p(x)\,\mathrm{d}x + \int_{\mathcal{R}} p(x)\,\mathrm{d}x = \int_{\mathcal{A} \cup \mathcal{R}} p(x)\,\mathrm{d}x = \int_{\text{全空间}} p(x)\,\mathrm{d}x = 1\]

    其中 \(\mathcal{A} = \mathcal{A}_1 \cup \dots \cup \mathcal{A}_c\) 是所有判决区的并集， 而第一项 \(\int_{\mathcal{A}} p(x)\mathrm{d}x\) 恰好就是 \(p_c + p_e\)。

    怎么读这个推导：判决区与拒识区拼起来正好是全空间（不漏不重）， 所以两部分的概率质量加起来必然是 \(1\) ✓

    并排对比一下，差别就清楚了：

    情形 恒等式 原因
    不拒识（上一页） \(p_c + p_e = 1\) 每个样本都被贴上标签，只有对/错两种结果 ✓
    有拒识（本页） \(p_c + p_e + p_r = 1\) 多了一类结果，等式右边还是 1，左边多了一项 ⚠

    多出拒识率这一项，等式右边不会变宽

    很容易误以为「多了拒识这条出路，正确率的门槛就松了」。 其实恒等式右边永远是 \(1\)，\(p_r\) 是从 \(p_c + p_e\) 里抢走的： 拒识率每增加 \(0.1\)，正确识别率与错误识别率之和就必然减少 \(0.1\) ⚠

    所以「拒识率 \(0.284631\)、错误识别率 \(0.049906\)」听起来很美， 但它和「正确识别率 \(0.665463\)」是同一件事的三种说法。 真正要算的账是：被拒的那 \(28\%\) 样本谁来处理、要花多少钱（第五节）✓

    4.3 把三个指标算出来（手算 + 一个闭式端点）¶

    import numpy as np
from scipy.stats import norm
from scipy.optimize import brentq

mu1, sigma1, prior1 = 15.0, 3.0, 0.6
mu2, sigma2, prior2 = 22.0, 4.0, 0.4


def post1(x):
    a = prior1 * norm.pdf(x, mu1, sigma1)
    b = prior2 * norm.pdf(x, mu2, sigma2)
    return a / (a + b)


def maxP(x):
    p = post1(x)
    return max(p, 1.0 - p)

err = prior2 * norm.cdf(lo, mu2, sigma2) + prior1 * (1.0 - norm.cdf(hi, mu1, sigma1))

    错误识别率 随 \(T\) 单调下降 反推「错误率目标」要配多大的 \(T\)
    正确识别率 随 \(T\) 单调下降 提醒你代价在哪 ⚠

    4.5 拒识究竟发生在哪里¶

    前面说「拒识的是边界附近的样本」，这个说法要用数字验证， 不能停在直觉上。

    办法是算条件拒识率：只在某一个局部区域里数拒识比例。 如果拒识真的集中在重叠区，那么在重叠区内部统计的拒识率， 应该明显高于全局拒识率。

    先把重叠区定义清楚：取两类各自 \(\pm 2\sigma\) 区间的交集，即

    \[\Bigl[\max(\mu_1 - 2\sigma_1,\ \mu_2 - 2\sigma_2),\; \min(\mu_1 + 2\sigma_1,\ \mu_2 + 2\sigma_2)\Bigr]\]

    代入数字：\(\max(15-6,\ 22-8) = \max(9, 14) = 14\)， \(\min(15+6,\ 22+8) = \min(21, 30) = 21\)，所以重叠区是 \([14, 21]\)。

    手算对照（\(T = 0.8\)，拒识区 \([16.746253,\ 21.151045]\)）：

    检查项 手算 说明
    拒识区与重叠区的关系 \([16.746253,\ 21.151045] \subset [14,\ 21]\) 拒识区整段都在重叠区内部 ✓
    拒识区的长度 \(4.404792\) 重叠区长度是 \(7\)，拒识只占了其中一段
    \(\omega_1\) 落在 \([14,\ 16.746253]\) 的质量 \(0.6 \times [\Phi(0.582084) - \Phi(-0.333333)]\approx 0.6 \times (0.719745 - 0.369441) = 0.210182\) 这段落在重叠区里、但证据够强，照常判 \(\omega_1\) ✓
    \(\omega_2\) 落在 \([21.151045,\ 21]\) 之外的部分 无（\(hi \gt 21\)） 拒识区右端越过了 \(\pm 2\sigma\) 的交集边界

    结论：拒识不是随机丢样本，它精确地作用在两类分布交叠的那一段。 这正是设计它的目的：把「不敢确定」的地方空出来交给后续环节， 而不是在那里硬猜 ⚠

    再补一个可以自己动手的点：怎样把「是否偏离等先验」看成一阶效应。 上一页已经说明，先验相等的两类判决边界就是两类中心的中点； 先验一变，边界就朝先验小的那一类挪。 本页的两个先验是 \(0.6\) 与 \(0.4\)，所以边界 \(19.134613\) 比中点 \(\frac{15+22}{2} = 18.5\) 偏右了约 \(0.63\) ✓ 这说明：边界的位置由先验与密度共同决定， 而拒识区的宽度由阈值 \(T\) 决定 —— 两者互不干扰， 这也是为什么可以「先定边界、再定 \(T\)」✓

    重叠区不是「错判区」

    两件事相关但不等价，容易混：

    区域 里面会发生什么
    重叠区 两类密度都非零；判对和判错都发生在这里
    拒识区 重叠区里按证据强度筛出来的那一段（最大后验不够大的那段）

    所以重叠区比拒识区大：\(T = 0.8\) 时拒识区只覆盖了 \([16.746253,\ 21.151045]\)， 而重叠区是 \([14,\ 21]\)。那些「虽落在重叠区、但证据够强」的样本照样给标签 ✓

    这也解释了为什么拒识不是「把整个重叠区扔掉」—— 它是按证据强度筛，而不是按位置一刀切。

    5.2 两种损失要分清¶

    上面说「误伤的量是收益的两倍」，但这个比较不能直接下结论， 因为它把两种东西按同一个权重相加了。实际上它们不是同一种代价：

    损失类型 记号 具体是什么 典型量级
    判错的损失 \(\lambda_e\) 医学上漏诊、自动驾驶撞人、资金被划走、违规内容上线 很大，且各类之间通常还不一样 ⚠
    拒识的损失 \(\lambda_r\) 转人工复核的人工成本、延迟、再检测一遍的设备开销 相对小，但不是零 ✓

    这两笔账的性质完全不同：

    • 「误伤了一次判对」这件事本身不产生损失， 它只是少赚了一次正确的判决，真正的损失是后面那道人工环节的开销 \(\lambda_r\)；
    • 「避免了一次错判」省下的是 \(\lambda_e\)， 而 \(\lambda_e\) 往往比 \(\lambda_r\) 高出很多倍。

    所以正确的做法不是比「个数」，而是给每个样本算期望损失再相加：

    \[R(\text{拒识}) = \lambda_r, \qquad R(\text{判 } \omega_i) = \lambda_e \cdot \bigl[1 - P(\omega_i \mid x)\bigr]\]

    怎么读这两个式子：

    • 拒识一个样本，无论真实类别是什么都付 \(\lambda_r\)（人工复核的成本固定）；
    • 判 \(\omega_i\) 一个样本，只有 \(1 - P(\omega_i \mid x)\) 的概率会判错， 所以期望损失是 \(\lambda_e\) 乘上这个概率 ✓

    为什么拒识的损失与真实类别无关

    这是拒识和判决最大的结构差别：

    动作 损失与什么有关 与什么无关
    判 \(\omega_i\) 与后验 \(P(\omega_i \mid x)\) 有关（判错的概率） 不与真实类别直接挂钩（真实类别未知）
    拒识 只有常数 \(\lambda_r\) 完全与 \(x\) 无关 ✓

    「拒识的损失是常数」这件事，正是第六节能把阈值 \(T\) 写成闭式的全部原因 —— 常数项在两边比较时不会随 \(x\) 变化，一移项就成了一个门槛 ✓

    用 \(T = 0.8\) 这组数字体会一下：在被拒的那批样本里， 拒识「避免的错判」有 \(0.095470\) 的份额， 但要为全部 \(0.282270\) 的拒识样本各付一次 \(\lambda_r\)。 所以拒识合不合算，取决于 \(\lambda_e\) 比 \(\lambda_r\) 大多少倍 —— 这正是下一节要算的比值 ✓

    5.3 什么时候拒识才值得¶

    把上面的期望损失代进「哪个动作损失小就选哪个」，就能直接算出结论。

    判错比拒识更疼时（\(\lambda_e (1 - P_{\max}) \gt \lambda_r\)），拒识合算； 反过来则不如直接判。这个比较在第六节会化成一条关于 \(T\) 的门槛。

    先给三个具体场景看量级差别：

    场景 判错损失 \(\lambda_e\) 拒识损失 \(\lambda_r\) \(\lambda_r/\lambda_e\) 该不该大量拒识
    医疗筛查（漏诊后果严重） 很大 一次人工读片 很小 ✓ 应该：宁可疑，转人工
    内容初审（错判可及时撤回） 中等 人工复核 中等 适度拒识 ✓
    标签粗分类（错了可重标） 很小 人工复核 接近 \(1\) 不值得拒识 ⚠

    最后一行是关键：如果两种损失的差别不大， 那么拒识就没有必要 —— 直接判反而更省事 ✓

    反过来说：这也是为什么拒识在医疗、自动驾驶、风控这类场景被广泛使用， 而在普通的内容标注、商品分类里很少用 —— 差别不在数学，而在两类损失的比值。

    把上一张表读成三个数字，结论就很具体了。 假设你手里有一批样本、一个训练好的分类器， 唯一能改的就是「拒还是不拒」，那么决策链其实只有三步：

    步 做什么 依据
    1 估出两类损失的比值 \(\lambda_r/\lambda_e\) 这是任务的性质：人工复核要多少钱、漏诊要多少钱
    2 算出 \(T = 1 - \lambda_r/\lambda_e\) 这是第六节的结论，与分布无关 ✓
    3 用 \(T\) 判决，并核对拒识率是否在出口的承受范围内 出口处理量有限，这一步是工程约束 ⚠

    第 1 步最关键，也最容易被跳过。看下面这三行：

    场景 \(\lambda_r/\lambda_e\) 的来源 算出来的 \(T\)
    漏诊的代价是复核的 \(20\) 倍 由临床流程定的比值 \(1 - 0.05 = 0.95\)
    是 \(5\) 倍 由人工成本定的比值 \(1 - 0.20 = 0.80\)
    是 \(1.25\) 倍 差不多一样贵 \(1 - 0.80 = 0.20\)，实际等于不拒 ⚠

    最后一行提醒一件事：当两个比值接近 \(1\) 时， \(T\) 会低于 \(1/c\)，此时拒识在数学上就已经失效了 —— 不是因为公式坏了，而是因为这个任务本来就不该用拒识 ✓

    「拒识率越高系统越安全」是错的

    常见的错误推理链： 「拒识率 \(0.9\) → 错误识别率只有 \(0.0003\) → 系统非常安全」。

    问题在于：那 \(90\%\) 被拒的样本并没有消失， 它们全部压到了后面的环节。所以这个推理缺了一步：

    缺失的问题 为什么必须问
    后面那道环节能不能处理这么多？ 人工复核的处理量是有限的 ⚠
    处理它的成本 \(\lambda_r\) 有多高？ 成本一旦接近 \(\lambda_e\)，拒识就白做了
    被拒样本本身不判，会不会误了事？ 有些场景「不判」本身就是一种损失 ⚠

    因此工程上常见的做法是在固定拒识率上限下调阈值， 而不是无脑往上推 \(T\) ✓

    六、最优阈值怎么定¶

    到这里，\(T\) 一直是一个「人给的」参数。这一节回答最后一个问题： \(T\) 应该取多少才最合算？

    答案由两个损失决定：判错损失 \(\lambda_e\) 与拒识损失 \(\lambda_r\)。 下面把这条结论一步步推出来，每一步都写清依据。

    6.1 先把损失写成两个常数¶

    完整的最小风险决策允许任意一对损失 \(\lambda_{ij}\)（把 \(\omega_j\) 判成 \(\omega_i\) 的损失）。 本课程课件在这一节做了一个简化假设：所有「判错」的代价相等，都记为 \(\lambda_e\)。 写成表格就是：

    动作 真实是 \(\omega_1\) 真实是 \(\omega_2\) 拒识动作的损失
    判 \(\omega_1\) \(0\) \(\lambda_e\) —
    判 \(\omega_2\) \(\lambda_e\) \(0\) —
    拒识 \(\lambda_r\) \(\lambda_r\) \(\lambda_r\)

    怎么读这张表：行是「我们做的动作」，列是「真实类别」。 判对了损失是 \(0\)（这个约定只是为了方便，因为只有损失之间的差才影响决策）， 判错了统一付 \(\lambda_e\)，拒识统一付 \(\lambda_r\)。

    这个假设的含义：它把「拒识」当成第 \(c+1\) 个动作： 这个动作有一个固定的价格 \(\lambda_r\)， 它的价格与真实类别无关（因为拒识时我们根本不知道真实类别）✓

    6.2 第一步：写出条件风险的定义¶

    最小风险决策的做法是：对每个动作算期望损失（也叫条件风险）， 然后选最小的那个。定义是

    \[R(\alpha \mid x) = \sum_{j=1}^{c} \lambda(\alpha \mid \omega_j)\, P(\omega_j \mid x)\]

    怎么读这个式子：动作 \(\alpha\) 的期望损失 = 「真实类别是 \(\omega_j\) 时这个动作要付的损失」乘上「真实类别是 \(\omega_j\) 的概率」， 对所有 \(j\) 求和。

    为什么是对后验加权，而不是对先验加权： 我们是在看到 \(x\) 之后才决定动作的， 所以「真实类别是什么」的不确定性应当用后验 \(P(\omega_j \mid x)\) 来度量， 而不是用先验。这一步是整节推导的出发点，不能跳 ✓

    6.3 第二步：算判 \(\omega_i\) 的条件风险¶

    动作一：判 \(\omega_i\)。 查 6.1 的损失表， 只有 \(j \neq i\) 的项付 \(\lambda_e\)，\(j = i\) 那一项付 \(0\)。代入定义：

    \[R(\alpha_i \mid x) = \sum_{j=1}^{c} \lambda(\alpha_i \mid \omega_j)\, P(\omega_j \mid x) = \lambda_e \sum_{j \neq i} P(\omega_j \mid x)\]

    把「\(j \neq i\) 求和」换成「全部求和再减掉 \(j = i\)」，这是同一个集合的两种写法：

    \[\sum_{j \neq i} P(\omega_j \mid x) = \underbrace{\sum_{j=1}^{c} P(\omega_j \mid x)}_{=\,1} - P(\omega_i \mid x)\]

    后验之和恒为 \(1\)（这正是上一页反复用到的那条性质），于是

    \[R(\alpha_i \mid x) = \lambda_e \bigl[1 - P(\omega_i \mid x)\bigr]\]

    怎么读它：判 \(\omega_i\) 的期望损失 = \(\lambda_e\) 乘上判错的概率。 这个式子有两个极端：后验 \(P(\omega_i \mid x) \to 1\) 时损失 \(\to 0\)； 后验 \(\to 1/c\) 时损失 \(\to \lambda_e (1 - 1/c)\) ✓

    这个结论说明什么：它把「判错有多疼」和「有多可能判错」两件事乘在了一起。 后验很小时，即使 \(\lambda_e\) 不大，乘积也可能很大 —— 这就是该拒识的信号。

    6.4 第三步：算拒识的条件风险¶

    动作二：拒识。 拒识时无论真实类别是什么都付 \(\lambda_r\)，所以代入定义：

    \[R(\alpha_{\text{reject}} \mid x) = \sum_{j=1}^{c} \lambda_r\, P(\omega_j \mid x) = \lambda_r \underbrace{\sum_{j=1}^{c} P(\omega_j \mid x)}_{=\,1} = \lambda_r\]

    这一步的关键是把常数提出来：\(\lambda_r\) 与 \(j\) 无关， 所以可以提到求和号外面，剩下的求和又等于 \(1\)。

    怎么读它：拒识的期望损失就是一个与 \(x\) 无关的常数 \(\lambda_r\)。

    这个结论说明什么：它说明「拒识的损失」在图上是一条水平线， 而判决的损失是一条起伏的曲线。两条线一比， 曲线高出水平线的那一段就该拒识 ✓

    6.5 第四步：先解决「判给谁」¶

    现在做比较。我们要在 \(c\) 个判决动作和 1 个拒识动作里挑期望损失最小的。

    在所有判决动作里比较。 \(R(\alpha_i \mid x) = \lambda_e [1 - P(\omega_i \mid x)]\)， 其中 \(\lambda_e \gt 0\) 是常数。要让它最小，就要让括号里的 \(1 - P(\omega_i \mid x)\) 最小， 也就是让 \(P(\omega_i \mid x)\) 最大。记

    \[P_{\max}(x) = \max_{j=1,\dots,c} P(\omega_j \mid x)\]

    于是判决动作里最优的那一个是

    \[R_{\text{best}}(x) = \lambda_e\bigl[1 - P_{\max}(x)\bigr]\]

    这个结论说明什么：拒识的引入不改变「判给谁」， 它只决定「判还是不判」。 换句话说，加上拒识之后，判决边界不动 ✓ 这一点很反直觉，但在 6.3 的式子里写得很清楚 —— \(\lambda_e\) 是公因子，它的大小不影响哪个 \(P(\omega_i \mid x)\) 最大。

    6.6 第五步：解出「什么时候该拒识」¶

    把两个动作放在一起比。

    \[R_{\text{best}}(x) = \lambda_e\bigl[1 - P_{\max}(x)\bigr] \qquad \text{与} \qquad R(\text{拒识} \mid x) = \lambda_r\]

    拒识当且仅当拒识的损失严格更小：

    \[\lambda_r \lt \lambda_e\bigl[1 - P_{\max}(x)\bigr]\]

    怎么读这个不等式： 左边是「拒识要花的钱」，右边是「硬判一次预计会花的钱」。 当硬判预计比拒识还贵时，就该拒识 ✓

    下面把不等式逐步整理成关于 \(P_{\max}\) 的门槛。 先把右边展开：

    \[\lambda_r \lt \lambda_e - \lambda_e P_{\max}(x)\]

    两边同时加上 \(\lambda_e P_{\max}(x)\)（不等式两边同加同一个量，方向不变）：

    \[\lambda_r + \lambda_e P_{\max}(x) \lt \lambda_e\]

    两边同时减去 \(\lambda_r\)：

    \[\lambda_e P_{\max}(x) \lt \lambda_e - \lambda_r\]

    两边同时除以 \(\lambda_e\)。因为 \(\lambda_e \gt 0\)，除正数不等号方向不变：

    \[P_{\max}(x) \lt \frac{\lambda_e - \lambda_r}{\lambda_e} = 1 - \frac{\lambda_r}{\lambda_e}\]

    写成结论：

    \[\boxed{\,P_{\max}(x) \lt 1 - \frac{\lambda_r}{\lambda_e}\,}\]

    这个结论说明什么： 后验的最大值低到某个门槛以下就该拒识， 而这个门槛只由两个损失的比值决定，与分布形状、与先验都无关 ✓

    把它和第三节的判决规则（那里写的是「判决当 \(P_{\max} \gt T\)」）对起来， 立刻得到阈值的取值：

    \[\boxed{\,T = 1 - \frac{\lambda_r}{\lambda_e}\,}\]

    这就是最优阈值：不是拍脑袋定的，而是从两个损失算出来的。

    再核一遍这个结论是怎么用的：取 \(\lambda_e = 5\)、\(\lambda_r = 1\)，则

    \[T = 1 - \frac{1}{5} = 1 - 0.2 = 0.8\]

    这正好是本页从第三节起一直用的那个 \(T\) ✓

    用 \(x = 19.5\) 这个样本把两边都算一遍（它的 \(\mathrm{maxP} = 0.558861\)）：

    \[R_{\text{best}}(19.5) = 5 \times (1 - 0.558861) = 5 \times 0.441139 = 2.205695\]
    \[R(\text{拒识} \mid 19.5) = 1\]

    \(2.205695 \gt 1\)，硬判更贵，所以拒识。 用阈值判也一样：\(0.558861 \lt 0.8\)，同样得拒识 ✓ 两种算法一致 —— 这说明 \(T = 0.8\) 与「两笔损失相等」是同一件事。

    两个损失必须满足拒识损失不超过判错损失

    阈值 \(T = 1 - \lambda_r/\lambda_e\) 只有在这个范围里才有意义：

    情形 \(T\) 后果
    \(\lambda_r \lt 0\) \(T \gt 1\) 拒识「倒赚钱」，模型会疯狂拒识 ⚠ 现实中不存在
    \(0 \leq \lambda_r \leq \lambda_e\) \(0 \leq T \leq 1\) 正常区间，阈值随比值下降 ✓
    \(\lambda_r \gt \lambda_e\) \(T \lt 0\) 拒识永远不划算，阈值失去意义，等价于不拒识 ✓

    第三种情况在实践中很常见（有些场景「不判」本身就很贵）， 这时直接把拒识关掉才是对的 —— 不要写一个负阈值然后指望它工作 ⚠

    6.7 两个极端：\(T \to 1\) 与 \(T = 0\)¶

    把 \(T = 1 - \lambda_r/\lambda_e\) 里的比值推向两端，两个极端就都清楚了。

    极端一：拒识几乎无代价（\(\lambda_r \to 0\)）。

    \[T = 1 - \frac{\lambda_r}{\lambda_e} \longrightarrow 1\]

    门槛被推到 \(1\)，只有最大后验精确等于 \(1\) 才判， 在连续分布下这种样本概率为零 —— 所以几乎全部拒识 ✓

    这合理吗？合理：如果拒识不花钱， 那么只要有任何一点不确定性就该拒识，反正拒绝了也没有损失。

    极端二：两种损失相等（\(\lambda_r = \lambda_e\)）。

    \[T = 1 - \frac{\lambda_e}{\lambda_e} = 0\]

    门槛降到 \(0\)，而最大后验恒有 \(P_{\max} \geq 1/c \gt 0\)， 所以条件总满足 —— 也就是一个都不拒 ✓

    这合理吗？也合理：如果拒识和判错一样贵， 那拒识就没有任何优势了，干脆一律判决。

    一般情形：\(0 \lt \lambda_r \lt \lambda_e\) 时 \(0 \lt T \lt 1\)， 阈值随比值线性下降。这张表把整条变化线列出来：

    \(\lambda_r/\lambda_e\) \(T = 1 - \lambda_r/\lambda_e\) 行为
    \(0\)（拒识免费） \(1.0\) 几乎全拒 ⚠
    \(0.05\) \(0.95\) 大量拒识
    \(0.2\) \(0.80\) 明显拒识，本页的示例参数 ✓
    \(0.5\) \(0.50\) 边界样本才拒
    \(0.8\) \(0.20\) 门槛低于 \(1/2\)，两类情形下实际不拒
    \(1.0\)（两者一样贵） \(0.0\) 不拒 ✓

    注意 \(0.8\) 那一行的一个细节：两类情形下最大后验的最小值是 \(0.5\)， 所以 \(T = 0.2\) 这个门槛低于最小值，效果和 \(T = 0.5\) 一样是「不拒」； 真正让拒识「起步」的门槛是 \(1/c\) ✓

from scipy.stats import norm
from scipy.optimize import brentq

mu1, sigma1, prior1 = 15.0, 3.0, 0.6
mu2, sigma2, prior2 = 22.0, 4.0, 0.4
t = 19.134613


def maxP(x):
    a = prior1 * norm.pdf(x, mu1, sigma1)
    b = prior2 * norm.pdf(x, mu2, sigma2)
    p = a / (a + b)
    return max(p, 1.0 - p)


def rates(T):
    # 给定阈值，求（拒识率, 正确识别率, 错误识别率）
    if T <= 0.5:
        left = right = t
    else:
        left = brentq(lambda v: maxP(v) - T, 10.0, t)
        right = brentq(lambda v: maxP(v) - T, t, 40.0)
    pc = prior1 * norm.cdf(left, mu1, sigma1) + prior2 * (1.0 - norm.cdf(right, mu2, sigma2))
    pe = prior2 * norm.cdf(left, mu2, sigma2) + prior1 * (1.0 - norm.cdf(right, mu1, sigma1))
    return 1.0 - pc - pe, pc, pe


lam_e = 5.0

    这条曲线是一个「U」，形状的物理含义很清楚：

    • 左边太高：拒识太少，判错的样本太多，\(\lambda_e\) 累积起来；
    • 右边太高：拒识太多，拒识成本 \(\lambda_r\) 累积起来；
    • 最低点在中间，位置恰由两个损失的比值决定 ✓

    \(0.0\) \(1.00\) 拒识率 \(1.000000\)，错误率 \(0\) 一致 ✓ 几乎全拒

    「先降后升」是这一类问题的通用形状

    只要问题是「一个动作用常数代价换掉一个随机代价」， 最优解几乎都是这种 U 形曲线的谷底：

    曲线 左侧成本 右侧成本
    本页：拒识阈值 \(T\) 判错的代价 \(\lambda_e p_e\) 拒识的代价 \(\lambda_r p_r\)
    假设检验：显著性水平 漏检（第二类错误） 误报（第一类错误）
    正则化：惩罚系数 欠拟合 过拟合

    所以「找到谷底」比「把某一侧压到最小」更重要 —— 把 \(T\) 推到 \(0.95\) 确实让错误率只剩 \(0.007453\)， 但总损失 \(0.712146\) 反而比不拒识还差 ⚠

    七、多类情形的推广¶

    7.1 规则本身几乎不用改¶

    第三节的规则从一开始就是按 \(c\) 类写的：

    \[\text{判 } \omega_i \text{ 当 } \max_{j=1,\dots,c} P(\omega_j \mid x) \gt T; \qquad \text{否则拒识}\]

    多类情形下它一个字都不用改，只是 maxP 的下界变了： \(c\) 类时最大值至少是 \(1/c\)（因为 \(c\) 个和为 \(1\) 的数里最大者不可能小于均值），所以

    \(c\) maxP 的理论下界 门槛必须超过这个值才可能拒识
    \(2\) \(0.5\) \(T \gt 0.5\)
    \(3\) \(0.333\) \(T \gt 0.333\)
    \(10\) \(0.1\) \(T \gt 0.1\) ⚠

    最后一行是个容易翻车的点：类数一多，\(1/c\) 就很小， 一个「看起来很高」的阈值（比如 \(T = 0.5\)）在 \(10\) 类问题里已经极严了， 拒识率会高得离谱 ⚠

    所以要养成一个习惯：看到阈值先把它和 \(1/c\) 比一比。

    6.6 节的推导在多类下同样成立，因为那里只用到了 「判决里最优的那个动作是判后验最大的类」这一条， 而它在 \(c\) 类下依然成立。所以 \(T = 1 - \lambda_r/\lambda_e\) 是通用的 ✓

    7.2 拒识区在多类下长什么样¶

    多类情形下的几何图像和两类不同：

    情形 拒识区的形态
    两类 中间一段连续的区间（本页的例子里就是一段）
    多类 判决区之间的一条条缝隙，每一对相邻类之间都可能有一段 ✓

    直观地说，每个「两类都像」的位置附近都可能出现一小段拒识区， 这些段拼起来就是整个拒识区。

    手算一个三类的小例子（这个形状值得自己画一遍）： 设三个类在同一维上依次排开，均值分别是 \(0\)、\(4\)、\(9\)， 标准差分别是 \(1\)、\(1\)、\(2\)，先验分别是 \(0.4\)、\(0.4\)、\(0.2\)，取 \(T = 0.7\)。

    相邻的一对 交界大概在哪 为什么会出现拒识段
    \(\omega_1\) 与 \(\omega_2\) \(x \approx 2\) 两类距离 \(4\)、标准差都是 \(1\)，重叠窄，拒识段也窄
    \(\omega_2\) 与 \(\omega_3\) \(x \approx 6\) 到 \(7\) \(\omega_3\) 的标准差是 \(2\)、\(\omega_2\) 是 \(1\)，尺度差一倍，重叠宽，拒识段最宽 ⚠

    结论：拒识段的宽度由相邻两类的重叠程度决定 —— 方差大、间距小的一对，拒识段就宽 ✓

    7.3 多类的另一种写法：类间距离¶

    多类情形下，「最大后验够不够大」还可以换个角度理解 —— 看两个最强候选之间差多少。

    记 \(P_{(1)}(x)\) 为最大的后验，\(P_{(2)}(x)\) 为第二大的后验。因为有 \(c\) 类且和恒为 \(1\)， 其余 \(c-2\) 个后验之和不超过 \(1 - P_{(1)} - P_{(2)}\)，于是可以写出一个充分条件：

    \[P_{(1)}(x) \gt T \quad \Longleftarrow \quad P_{(1)}(x) - P_{(2)}(x) \gt cT - 1 \quad \text{（充分但不必要）}\]

    怎么读这个式子：如果前两名的后验拉开了足够大的差距， 那么第一名肯定过了门槛。

    这个充分条件怎么来的（不跳步）。 \(c\) 个后验之和恒等于 \(1\)。把前两名单独拎出来：

    \[P_{(1)}(x) + P_{(2)}(x) + \sum_{\text{其余 } c-2 \text{ 个}} P_{(j)}(x) = 1\]

    这一步只是把求和拆成三块，没有任何近似 ✓

    由于「其余 \(c-2\) 个」每一个都不超过第二名，所以它们的和不超过 \((c-2) P_{(2)}(x)\)：

    \[\sum_{\text{其余 } c-2 \text{ 个}} P_{(j)}(x) \leq (c-2)\, P_{(2)}(x)\]

    代回上一个式子，就把 \(c\) 个未知量压成了两个：

    \[1 \leq P_{(1)}(x) + P_{(2)}(x) + (c-2) P_{(2)}(x) = P_{(1)}(x) + (c-1) P_{(2)}(x)\]

    这一步的依据：把「其余那些」全都放大到第二名的大小， 和不减，于是得到一个上界关系 ✓

    从这条关系可以反推出「第一名必须足够大」的条件。把 \(P_{(2)}(x) = P_{(1)}(x) - \bigl[P_{(1)}(x) - P_{(2)}(x)\bigr]\) 代进去并整理， 得到的就是前面那个充分条件：

    \[P_{(1)}(x) - P_{(2)}(x) \gt cT - 1 \quad \Longrightarrow \quad P_{(1)}(x) \gt T\]

    用 \(c = 3\)、\(T = 0.7\) 验一下门槛： \(cT - 1 = 3 \times 0.7 - 1 = 1.1\)， 而三个和为 \(1\) 的后验里，最大值与次大值之差最多是 \(1\)， 永远达不到 \(1.1\) —— 说明这个条件在 \(c = 3\)、\(T = 0.7\) 时根本用不上 ⚠ 这也解释了为什么它只是「充分」而没什么用。

    它为什么只是充分条件：\(c \gt 2\) 时可能有三个类都很像， 即使第一名和第二名差距不大，胜出者也还是过了门槛。 所以多类情形下直接算 maxP 最稳，这个「差距形式」只当参考 ✓

    小结多类推广的三条要点：

    要点 内容
    规则不变 仍是「最大后验超过 \(T\) 才判」 ✓
    门槛的感觉要变 别忘了和 \(1/c\) 比；\(c\) 越大，同一个 \(T\) 越严 ⚠
    拒识区变多段 每对相邻类之间都可能出现一段；方差越大的一对越宽 ✓

    八、开放集识别¶

    前七节都在处理情形二（样本属于已知类，只是边界附近难分）。 情形一要难得多，它有专门的名字。

    8.1 闭集 与 开放集¶

    本课程课件用两张图对比了这两种设定。

    设定 假设 测试时会出现什么 后果
    闭集 训练样本和测试样本都来自预设的 \(c\) 个类 只有这 \(c\) 类的样本 分类器只要在这 \(c\) 个里挑一个，问题相对干净 ✓
    开放集 测试样本可能不属于这 \(c\) 个类 会有异常样本（属于没见过的类） 分类器必须有能力说「这不属于我知道的任何一类」 ⚠

    「开放集」的核心困难，本课程课件讲得很直接：

    训练时只能用已知的 \(c\) 个类来训练分类器， 因为异常样本没有训练集 —— 你根本不知道会出现什么新类。

    这句话的含义值得展开： 闭集问题里，你可以把「所有可能的类」都拿到训练数据； 开放集问题里，未知类在训练时是不可见的， 不能简单地「把未知也当成一个类来训练」⚠

    8.2 难点：模型对未知类会给出「自信的错误答案」¶

    开放集最麻烦的地方不是「不知道」， 而是模型不知道自己不知道 —— 它会给出很高的置信度。

    回忆 2.4 节的手算：\(x = 33\) 这个样本（离 \(\omega_2\) 有 \(2.75\) 个 \(\sigma\)）， 在只含两类的后验里，它的最大后验是 \(0.999999\)。

    这还不算最糟的。把这个未知类样本成批送进去统计一遍， 结果会让人更不舒服：

    样本 平均最大后验 被拒识比例（\(T = 0.8\)）
    已知类样本 \(0.855498\) \(0.282270\) ⚠ 拒了将近三成
    未知类样本 \(0.998802\) \(0.000200\) ⚠ 几乎一个都没拒

    单纯的阈值拒识救不了开放集

    这张表说明的事情违反直觉，但非常重要：

    • 已知类样本的自信度只有 \(0.855\)，被拒了 \(28\%\)；
    • 未知类样本的自信度高达 \(0.999\)，只被拒了 \(0.02\%\) ⚠

    也就是说：阈值把「该留下的」拒掉了不少，却几乎没拦住「该拒的」。

    原因在 2.4 节已经说过：后验是归一化的， 只要观测到的 \(x\) 落在某个已知类的尾部， 归一化就会把那一类的后验放大到接近 \(1\)。 样本越远离所有已知类，这个放大效应越明显。

    所以：只加一个阈值，不能解决开放集问题 ⚠ 阈值拒识擅长处理情形二（两类都像）， 对情形一（谁也不像）几乎无效 ✓

    这个问题在深度模型上更严重。 本课程课件提到， 利用深度模型做歧义与异常的拒识很难， 原因是深度模型的输出置信度会出现过拟合（过于自信）—— 它给出的高置信度并不代表真的可靠 ⚠

    根源是同一个：如果训练时从未见过某个区域的样本， 模型就没有任何理由在那里输出低置信度； 它在外推区域的行为是没有约束的， 于是「距离越远、置信度越高」这种荒谬现象就出现了 ✓

    8.3 把「未知」当成第 \(c+1\) 个类¶

    本课程课件在开放集那一页给了一种更正规的处理思路： 给「未知」也配一套先验和概率密度，把它当成一个能被比较的类。

    设已知类为 \(\omega_1, \dots, \omega_c\)，未知类记为 \(\omega_{c+1}\)。 假设未知类的先验是 \(p_{c+1}\)，且它的条件密度近似为一个小常数 \(\rho\)（\(\rho\) 很小）：

    \[p(x \mid \omega_{c+1}) \approx \rho\]

    怎么读这个假设：未知类不知道长什么样，所以退回最保守的假设 —— 它在整个空间里均匀地稀疏分布。\(\rho\) 很小，表示「未知样本总体上不多」✓

    这样一来，未知类就是一个正常的类了，可以和别的类一起算后验：

    \[P(\omega_{c+1} \mid x) = \frac{\rho\, p_{c+1}}{\sum_{j=1}^{c} p(x \mid \omega_j)\, p_j \;+\; \rho\, p_{c+1}}\]

    怎么读这个式子：分母里多出一项 \(\rho\,p_{c+1}\)， 它代表「这个样本来自未知类」那部分概率质量。 因此每个已知类的后验都会被压低一点 ✓

    于是判决规则变成：在 \(c+1\) 个候选里取后验最大的那个， 若最大的是 \(\omega_{c+1}\)，就是拒识。

    从最小风险的角度看，这一步和第 6.6 节是同一个推导。 把所有候选（\(c\) 个已知类加上未知类）写成动作， 每个动作的条件风险用 6.2 的定义算，取最小的那个， 得到的正是「比后验」这条规则 —— 因为损失表是对称的，\(\lambda_e\) 又是公因子 ✓

    这解释了为什么它比纯阈值好： 当 \(x\) 落在所有已知类的尾部时， 分母里的 \(\sum_j p(x \mid \omega_j) p_j\) 变得非常小， 于是未知类那一项 \(\rho\,p_{c+1}\) 相对变大， \(\omega_{c+1}\) 的后验就可能胜出 ✓

    这也解释了 8.2 节的失败： 纯阈值只比较归一化后的比例，未知类那一项根本不在分母里， 所以无论 \(x\) 多离谱，比例都被强行「摊」成 \(1\) ⚠

    手算一个位置体会一下：设已知两类先验合计 \(0.95\)（分别是 \(0.57\)、\(0.38\)）， 未知类先验 \(p_{c+1} = 0.05\)、密度 \(\rho = 0.05\)。 取 \(x = 32\)：

    类 加权联合量 后验
    \(\omega_1\) \(0.57 \times p(32 \mid \omega_1) \approx 0\) \(0.000000\)
    \(\omega_2\) \(0.38 \times p(32 \mid \omega_2) = 0.38 \times 0.002187 = 0.000831\) \(0.399800\)
    未知类 \(0.05 \times 0.05 = 0.002500\) \(\mathbf{0.600200}\) ✓

    分母是 \(0.000831 + 0.002500 = 0.003331\)，未知类胜出，于是判拒识。

    关键对比：同一个 \(x = 32\)， 在 8.2 节的纯阈值方案里它的最大后验接近 \(1\)（必然被判成 \(\omega_2\)）； 在这里未知类的后验是 \(0.600200\)，未知类胜出 ✓

    成批统计也一致：

    样本 被拒比例（纯阈值 \(T = 0.8\)） 被拒比例（含未知类）
    已知类样本 \(0.282270\) ⚠ 误伤严重 \(0.006800\) ✓ 几乎不误伤
    未知类样本 \(0.000200\) ⚠ 完全拦不住 \(0.295650\) ✓ 拦住了约三成

    它的代价：未知类的先验 \(p_{c+1}\) 与密度 \(\rho\) 都是猜的。 \(\rho\) 定大一点，拒识就多；定小一点，拒识就少 ⚠ 这正是 8.5 节表格里说的「需要设定未知类的先验与密度」这个局限 ✓

    一个重要的观察：含未知类的方案同时改善了两种错误 —— 已知类的误伤从 \(0.282270\) 降到 \(0.006800\)（降到十分之一以下）， 未知类的拦截从 \(0.000200\) 升到 \(0.295650\)。 两件事一起变好，说明它不是在「权衡」，而是把缺失的那一项补上了 ✓

    8.4 课件提到的一种思路：用语言引导的目标定位¶

    本课程课件在开放集这一节的末尾给了一个正面例子，思路值得记住。

    传统做法的局限：经典的目标检测模型 只能识别训练时定义好的固定类别。 输出层的维度在训练时就固定了， 所以「训练时没定义过的类别」永远认不出来 —— 局限性很大 ⚠

    课件的思路：用语言引导的目标定位来突破这个限制。

    做法 具体内容
    文本提示 用文字动态地指定这次要检测哪些类别。比如输入「狗、自行车、天空」，就检测这几样，不需要重新训练模型 ✓
    多模态融合 把图像特征和文本特征放在同一个表示空间里做匹配，让模型理解「这段文字描述的内容」和「图上这块区域」是不是同一件事 ✓
    零样本迁移 因为类别由文字描述决定，所以对训练时完全没见过的类别也能工作 ✓

    这个思路对开放集问题的启发：

    传统闭集分类器 语言引导的做法
    输出层固定 \(c\) 个槽位，只能在这 \(c\) 个里挑 类别由文字描述临时给出，槽位可以变 ✓
    遇到新类只能给出「最像的旧类」 可以用文字描述新类，或不匹配任何文字时自动不确定 ✓
    未知类的定义在训练时就必须定死 未知类在使用时才被描述 ⚠

    一句话总结课件的要点： 把「类别」从固定的输出槽位变成可以用文字描述的概念， 开放性就有了着落。

    把它和前面的框架对起来看，会发现它换掉的只是「类别的定义方式」： 闭集分类器的类别定义在训练时固定（输出层有多少个槽位）， 语言引导的做法把类别定义挪到使用时（用一段文字临时指定）。 类别一旦可以临时给出，「未知类」这个概念就不再是一个固定的槽位， 而是一个待描述的对象 —— 这正是开放集想要的东西 ✓

    注意：这条路线让系统更灵活，但不等于解决了开放集 —— 如果输入里出现的东西连合适的词都没有， 语言引导也一样接不住 ⚠ 所以阈值、距离、密度这几类手段仍然需要保留。

    8.5 常用手段一览¶

    把开放集识别的常见手段从原理层面归纳成一张表。

    手段 原理 优点 局限
    阈值法 用最大后验（或其它置信度）和阈值比 实现最简单，几乎无额外成本 ✓ 对远离已知类的样本反而更自信 ⚠
    距离度量 算样本到各已知类中心（或原型）的距离，超出半径就拒识 直接反映「像不像已知类」✓ 距离阈值难定；类内方差大时容易误伤
    含概率密度的判别 给未知类配一个低密度（8.3 节的做法），在 \(c+1\) 个候选里比后验 有明确的风险解释，和最小风险决策一致 ✓ 需要设定未知类的先验与密度 ⚠
    密度估计 / 生成式方法 用生成模型估计已知类的密度，密度过低就拒识 不依赖后验归一化，直接看绝对密度 ✓ 高维下密度很难估准 ⚠
    用额外数据学「未知」 拿一些近似异常的样本当未知类的训练数据 把问题变回闭集，可直接用现成的判别方法 ✓ 收集的异常样本必然覆盖不全真实未知 ⚠

    这张表的最后一列值得多看一眼： 每种手段都有一处「漏」的地方。 这正是本页反复强调的那句 —— 开放集问题的困难在于未知类不可见， 所以任何方法都只能在假设的层面上补，不能真正补齐 ⚠

    工程上常见的组合： 用距离/密度对付「谁也不像」的情形一， 用阈值拒识对付「两类都像」的情形二， 再给两者都留一条人工复核的出口 ✓

    用一张表把两种手段的分工说清：

    工具 算的是什么 在已知样本上 在未知样本上
    最大后验 \(\max_i P(\omega_i \mid x)\)（归一化量） 高 ✓ 也高 ⚠ 方向反了
    到最近类中心的距离 \(\min_i \lvert x - \mu_i \rvert / \sigma_i\)（非归一化量） 小 ✓ 大 ✓ 方向对

    距离阈值该取多大的手算参考： 取 \(1.5\sigma\) 时，已知类里约有 \(13.4\%\) 的样本会被误拒 （两侧尾巴之和 \(2\Phi(-1.5) = 2 \times 0.066807\)）， 而未知类样本能被拦下大半 —— 所以距离法也要同时看误伤和拦截，不能只盯一个数 ✓

    九、实际应用中的拒识¶

    把前面所有结论落到四个常见场景上。

    场景 什么情况触发拒识 拒识后交给谁 为什么这里拒识划算
    医疗辅助诊断 病灶区域的最大后验低、或影像特征离训练集里的病例都很远 医生重点复核这份病例 ✓ 漏诊的代价 \(\lambda_e\) 远大于一次人工读片 \(\lambda_r\)
    人脸识别门禁 人脸后验不够、或与库里所有人脸的距离都偏大 要求刷卡或输密码 ✓ 冒认放行的安全代价远大于多刷一次卡的麻烦
    自动驾驶 感知结果置信度低、或检测框与任何已知类别都不匹配 减速 / 提醒驾驶员接管 ✓ 误判的代价是不可逆的，必须给人留出干预时间
    内容审核 风险分不高不低、或内容特征不在已有违规样本覆盖范围内 转人工复核 ✓ 一旦放行违规内容，召回成本极高；且人工量可控

    这四个场景共享同一个模式，值得单独写出来：

    共同点 说明
    两类损失差别很大 错判的代价远大于拒识的代价，所以 \(\lambda_r/\lambda_e\) 小，\(T\) 应该取高一些 ✓
    拒识有明确的出口 拒判之后不是「什么都不做」，而是转给一个具体的环节 ✓
    出口的处理量有限 所以不能把 \(T\) 一路往 \(1\) 推，必须控制拒识率 ⚠
    出问题时有人负责 拒识把决定权交回给人，责任链是清楚的 ✓

    用本页的数字感受一下「出口处理量有限」这条约束： 如果每天有 \(10\) 万条样本，\(T = 0.8\) 时拒识率 \(0.284631\)， 就是每天约 \(2.85\) 万条要转人工； 把 \(T\) 提到 \(0.95\)，拒识率 \(0.674881\)，变成每天约 \(6.75\) 万条 —— 错误率是降到了 \(0.007453\)，但人工环节根本接不住 ⚠

    四个场景里最容易踩的坑各不相同

    场景 特有的坑
    医疗辅助诊断 拒识率太高会让医生看不过来，最后反而变成走过场 ⚠
    人脸识别门禁 拒识太频繁，用户会觉得「这系统根本没用」，转而要求把阈值调低 ⚠
    自动驾驶 拒识必须在毫秒级完成并触发减速，不能只是「记录一条日志」 ⚠
    内容审核 低风险内容被大量误拒，会伤害正常发布，要分开统计各类的拒识率 ⚠

    共同教训：「拒识之后做什么」必须和拒识本身一起设计， 否则拒识只是一个看起来很美的数字 ✓

    典型例题¶

    例题一：算一个样本的三个指标贡献¶

    两类高斯分布：\(\mu_1 = 15\)，\(\sigma_1 = 3\)，先验 \(0.6\)； \(\mu_2 = 22\)，\(\sigma_2 = 4\)，先验 \(0.4\)。样本 \(x = 19.5\)，阈值 \(T = 0.8\)。 求两个后验、判决结果，并说明这个样本对三个指标各贡献了什么。

    思路

    第一步：算两个类条件密度（常数因子在 2.4 节已经算好）。 第二步：乘先验得分子，加起来是分母，除出后验。 第三步：取最大值和 \(T\) 比 —— 注意比较的是最大值，不是随便哪个后验。 第四步：用期望损失再核一遍，两种算法必须一致。

    解答

    第一步：两个类条件密度。 常数因子 \(\frac{1}{3\sqrt{2\pi}} = 0.132981\)，\(\frac{1}{4\sqrt{2\pi}} = 0.099736\)。

    \[p(19.5 \mid \omega_1) = 0.132981 \times e^{-1.125} = 0.132981 \times 0.324652 = 0.043173\]
    \[p(19.5 \mid \omega_2) = 0.099736 \times e^{-0.195313} = 0.099736 \times 0.822578 = 0.082040\]

    第二步：乘先验、求分母。

    类 似然 先验 分子
    \(\omega_1\) \(0.043173\) \(0.6\) \(0.025904\)
    \(\omega_2\) \(0.082040\) \(0.4\) \(0.032816\)
    \[\text{分母} = 0.025904 + 0.032816 = 0.058720\]

    第三步：两个后验。

    \[P(\omega_1 \mid 19.5) = \frac{0.025904}{0.058720} = 0.441139\]
    \[P(\omega_2 \mid 19.5) = \frac{0.032816}{0.058720} = 0.558861\]

    校验：\(0.441139 + 0.558861 = 1.000000\) ✓

    第四步：和阈值比。

    \[\mathrm{maxP}(19.5) = 0.558861 \lt 0.8 \quad \Longrightarrow \quad \textbf{拒识}\]

    第五步：用期望损失再核一遍。

    \[R(\text{判 } \omega_2 \mid 19.5) = 5 \times (1 - 0.558861) = 5 \times 0.441139 = 2.205695\]
    \[R(\text{拒识} \mid 19.5) = 1\]

    \(2.205695 \gt 1\)，硬判更贵，所以拒识 —— 与第四步结论一致 ✓

    第六步：这个样本对三个指标贡献了什么。

    阈值 判决结果 对正确识别率 对错误识别率 对拒识率
    \(T = 0.55\) 判 \(\omega_2\) 若真实是 \(\omega_2\) 则 \(+1\) 份额 若真实是 \(\omega_1\) 则 \(+1\) 份额 \(0\) ✓
    \(T = 0.8\) 拒识 \(0\) \(0\) \(+1\) 份额 ✓

    注意「\(+1\) 份额」的意思：单看一个样本，它要么进「判对」桶， 要么进「判错」桶，要么进「拒识」桶 —— 只能进一个。 这正是「三者之和恒等于 \(1\)」在最微观层面的体现 ✓

    若在 \(T = 0.8\) 下非要判，条件错误率是 \(1 - 0.558861 = 0.441139\)， 接近一半 —— 这就是拒识把它留下的理由 ⚠

    例题二：算出 \(T = 0.8\) 时拒识区的两个端点¶

    分布同例题一（\(\mu_1 = 15\)，\(\sigma_1 = 3\)，\(P_1 = 0.6\)；\(\mu_2 = 22\)，\(\sigma_2 = 4\)，\(P_2 = 0.4\)）。 求 \(T = 0.8\) 时拒识区的两个端点，并判断 \(x = 16.7\) 与 \(x = 21.2\) 该怎么处理。

    思路

    拒识区的端点由 \(\mathrm{maxP}(x) = T\) 确定。因为 \(\mathrm{maxP}\) 在判决边界两侧 分别等于 \(P(\omega_1 \mid x)\) 与 \(P(\omega_2 \mid x)\)，所以端点方程是 \(P(\omega_1 \mid x) = 0.8\)（左端）与 \(P(\omega_2 \mid x) = 0.8\)（右端）。

    不必用数值求根：把方程两边取密度之比，会化成一个二次方程。

    解答

    第一步：把「左端」的方程写出来。 左端在判决边界左边， 那里 \(\omega_1\) 领先，条件 \(\mathrm{maxP} \lt T\) 就是 \(P(\omega_1 \mid x) \lt 0.8\)， 所以分界点是 \(P(\omega_1 \mid x) = 0.8\)。写成分子分母：

    \[\frac{P_1\, p(x \mid \omega_1)}{P_1 p(x \mid \omega_1) + P_2 p(x \mid \omega_2)} = 0.8\]

    第二步：把分式化成比值。 两边取倒数再减 \(1\)：

    \[\frac{P_2\, p(x \mid \omega_2)}{P_1\, p(x \mid \omega_1)} = \frac{1 - 0.8}{0.8} = 0.25\]

    两边取自然对数，并代入两类正态密度的对数：

    \[\ln\frac{P_2}{P_1} - \frac{(x-\mu_2)^2}{2\sigma_2^2} + \frac{(x-\mu_1)^2}{2\sigma_1^2} = \ln 0.25\]

    第三步：整理成二次方程。 把两个平方项展开并乘上 \(2\sigma_1^2\sigma_2^2\)， 得到 \(\sigma_1^2 - \sigma_2^2\) 作二次项系数的方程。代入本题数字：

    \[-7x^2 + 84x + 82.521 = 0\]

    第四步：解方程。 判别式

    \[\Delta = 84^2 + 4 \times 7 \times 82.521 = 7056 + 2310.6 = 9366.6\]
    \[\sqrt{\Delta} = 96.780\]

    两个根是

    \[x = \frac{-84 \pm 96.780}{-14} \quad \Longrightarrow \quad x_1 = 16.746253, \quad x_2 = -4.746253\]

    判决边界是 \(t = 19.134613\)，所以比 \(t\) 小的那个根才是左端点：

    \[lo = 16.746253\]

    第五步：右端点。 右端在判决边界右边，那里 \(\omega_2\) 领先， 条件是 \(P(\omega_2 \mid x) = 0.8\)，也就是 \(P(\omega_1 \mid x) = 0.2\)。 同样取比值：

    \[\frac{P_2\, p(x \mid \omega_2)}{P_1\, p(x \mid \omega_1)} = \frac{0.8}{0.2} = 4\]

    代入数字得 \(-7x^2 + 84x + 1038.479 = 0\)，判别式 \(\Delta = 7056 + 29077 = 36133\)，\(\sqrt{\Delta} = 190.087\)，于是

    \[x = \frac{-84 \pm 190.087}{-14} \quad \Longrightarrow \quad hi = 21.151045\]

    （另一个根 \(-7.577707\) 在 \(t\) 左侧，舍去。）

    第六步：两个样本的判决。

    样本 \(\mathrm{maxP}\) 落在哪 处理
    \(x = 16.7\) \(0.803830\) 左端 \(16.746253\) 的左边 \(\mathrm{maxP} \gt 0.8\)，判 \(\omega_1\) ✓
    \(x = 21.2\) \(0.805700\) 右端 \(21.151045\) 的右边 \(\mathrm{maxP} \gt 0.8\)，判 \(\omega_2\) ✓

    注意 \(16.7\) 与 \(21.2\) 这两个数有多近： 它们离两端点都只差 \(0.05\) 左右， 而判决结论已经翻了过来 —— 这说明端点附近的判决对阈值非常敏感 ⚠

    第七步：整理成表。

    量 值
    不拒识的判决边界 \(t\) \(19.134613\)
    拒识区 \([16.746253,\ 21.151045]\)
    拒识区长度 \(4.404792\)
    左段判决 判 \(\omega_1\)（\(x \lt 16.746253\)）
    右段判决 判 \(\omega_2\)（\(x \gt 21.151045\)）

    这一步最值得记住的技巧：把「后验等于某个值」化成 「两类密度的比值等于某个值」，两边取对数后就是二次方程 —— 高斯情形下端点总是解析可求的 ✓

    例题三：想要错误率减半，要付多少拒识代价¶

    错误识别率随 \(T\) 单调下降，所以可以二分搜索：先在 \(T = 0.5\) 与 \(T = 0.95\) 之间取中点，看错误率比目标大还是小，再缩小区间。

    目标值先算出来：\(0.145198 / 2 = 0.072599\)。

    第一步：二分搜索的区间与判据。

    端点 \(T\) 错误识别率 与目标 \(0.072599\) 比
    左 \(0.50\) \(0.145198\) 偏大，要往右挪
    右 \(0.95\) \(0.007453\) 偏小，要往左挪

    轮次 \(T\) 错误识别率 结论

    指标 值

    错误识别率 \(0.072825\)

    量 值

    例题四：未知类样本为什么会被「自信地」判错¶

    训练集只有例题一的那两类。测试时来了一个样本 \(x = 30\)， 它其实属于一个训练时没见过的类。 求在只含两类的后验里它的最大后验，并解释这个现象。

    思路

    只算已知两类的似然 —— 关键就在这一步：未知类根本不在分母里。 然后把得到的数字和「它离已知类有多远」放在一起看。

    解答

    第一步：算两个类条件密度。 指数上的项先算：

    \[\frac{(30-15)^2}{2 \times 3^2} = \frac{225}{18} = 12.5 \qquad \frac{(30-22)^2}{2 \times 4^2} = \frac{64}{32} = 2\]

    代入常数因子：

    \[p(30 \mid \omega_1) = 0.132981 \times e^{-12.5} = 0.132981 \times 3.726653 \times 10^{-6} \approx 4.956 \times 10^{-7}\]
    \[p(30 \mid \omega_2) = 0.099736 \times e^{-2} = 0.099736 \times 0.135335 = 0.013498\]

    第二步：乘先验得分子。

    类 似然 先验 分子
    \(\omega_1\) \(4.956 \times 10^{-7}\) \(0.6\) \(2.973 \times 10^{-7}\)
    \(\omega_2\) \(0.013498\) \(0.4\) \(0.005399\)
    \[\text{分母} = 2.973 \times 10^{-7} + 0.005399 \approx 0.005399\]

    注意：\(\omega_1\) 那一项比 \(\omega_2\) 小了四个数量级， 所以分母几乎完全由 \(\omega_2\) 决定。

    第三步：后验。

    \[P(\omega_2 \mid 30) = \frac{0.005399}{0.005399} = 0.999945 \qquad P(\omega_1 \mid 30) \approx 0.000055\]
    \[\mathrm{maxP}(30) = 0.999945\]

    第四步：和阈值比。

    阈值 \(0.999945 \gt T\)？ 结果
    \(T = 0.8\) 是 判 \(\omega_2\) ⚠
    \(T = 0.99\) 是 仍判 \(\omega_2\) ⚠
    \(T = 0.9999\) 否 才拒识

    要拦下它，阈值得高到 \(0.9999\) —— 而那样一来，绝大部分正常样本都会被拒掉 ⚠

    第五步：解释这个现象。 问题出在归一化上。后验是

    \[P(\omega_i \mid x) = \frac{p(x \mid \omega_i) P(\omega_i)}{\sum_{j=1}^{c} p(x \mid \omega_j) P(\omega_j)}\]

    分母只对已知的 \(c\) 个类求和。 当 \(x = 30\) 时，两个已知类的密度都很小 （\(4.956 \times 10^{-7}\) 与 \(0.013498\)）， 可分母把这两个很小的数互相归一化了 —— 于是 \(0.013498\) 相对于 \(4.956\times10^{-7}\) 显得「大得惊人」， 后验被推到 \(0.999945\) ✓

    用一句话说清： 后验回答的是「在这 \(c\) 个已知类里，哪个最像」， 它从来没有回答过「这个样本到底像不像任何已知类」⚠

    第六步：换个量就看得出来。

    量 \(x = 30\) 的值 说明
    最大后验 \(0.999945\) 看起来极其自信 ⚠
    到 \(\omega_2\) 中心的距离 \(\lvert 30 - 22 \rvert / 4 = 2\) 个 \(\sigma\) 已经算「比较远」了
    到 \(\omega_1\) 中心的距离 \(\lvert 30 - 15 \rvert / 3 = 5\) 个 \(\sigma\) 极远 ⚠
    到最近类中心的距离 \(2\) 个 \(\sigma\) 这才是判断「像不像」的正确量 ✓

    结论：这个样本离最近的已知类中心也有 \(2\sigma\)， 却在后验上显得「几乎确定」。这就是 8.2 节说的 「模型对未知类给出自信的错误答案」，也是开放集问题难的核心原因 ⚠

    第七步：往更远的位置看一眼，现象会更刺眼。

    \(x\) 最大后验 到最近类中心的距离
    \(24.0\) \(0.975442\) \(0.5\) 个 \(\sigma\)
    \(28.0\) \(0.999485\) \(1.5\) 个 \(\sigma\)
    \(33.0\) \(0.999999\) \(2.75\) 个 \(\sigma\)
    \(40.0\) \(1.000000\) \(4.5\) 个 \(\sigma\)

    越远越自信 —— 这张表把「归一化」的破坏力写得很清楚 ✓

    自测¶

    Q1 两类问题：\(\mu_1 = 10\)，\(\sigma_1 = 2\)，\(P(\omega_1) = 0.5\)； \(\mu_2 = 16\)，\(\sigma_2 = 2\)，\(P(\omega_2) = 0.5\)。 取 \(T = 0.9\)。样本 \(x = 14\) 应该判给哪一类，还是拒识？

    提示

    等方差等先验，两个似然里都有同一个因子 \(\frac{1}{\sigma\sqrt{2\pi}}\)，可以约掉， 所以只需要比 \(\exp\bigl[-\frac{(x-\mu_1)^2}{2\sigma^2}\bigr]\) 和 \(\exp\bigl[-\frac{(x-\mu_2)^2}{2\sigma^2}\bigr]\)。 算完似然记得乘先验（这里相等，不影响大小关系），再归一化。

    解答

    第一步：两个似然。

    \[\frac{1}{\sigma\sqrt{2\pi}} = \frac{1}{2 \times 2.506628} = 0.199471\]
    \[p(14 \mid \omega_1) = 0.199471 \times e^{-2} = 0.199471 \times 0.135335 = 0.026995\]
    \[p(14 \mid \omega_2) = 0.199471 \times e^{-0.5} = 0.199471 \times 0.606531 = 0.120985\]

    第二步：乘先验。 两个先验都是 \(0.5\)，所以分子分别是 \(0.013498\) 与 \(0.060493\)，分母是 \(0.073990\)。

    第三步：两个后验。

    \[P(\omega_1 \mid 14) = \frac{0.013498}{0.073990} = 0.182426 \qquad P(\omega_2 \mid 14) = \frac{0.060493}{0.073990} = 0.817574\]

    校验：\(0.182426 + 0.817574 = 1.000000\) ✓

    第四步：和阈值比。

    \[\mathrm{maxP}(14) = P(\omega_2 \mid 14) = 0.817574 \lt 0.9 \quad \Longrightarrow \quad \textbf{拒识}\]

    注意：如果只按上一页的规则，这里会判 \(\omega_2\)（后验 \(0.82\) 明显最大）。 加上阈值 \(0.9\) 之后它被拒了 —— 因为 \(x = 14\) 正好在两类中点的附近（中点 \(13\)，它离中点只差 \(1\)）⚠

    第五步：若非要判，条件错误率。

    \[P(\text{error} \mid 14) = 1 - 0.817574 = 0.182426\]

    也就是接近两成会判错 —— 这就是拒识的理由 ✓

    Q2 判断对错并说明理由：

    「拒识会提高系统可靠性，所以阈值 \(T\) 越大越好，最好推到接近 \(1\)。」

    提示

    想一想三者的恒等式，再想一想被拒的样本去哪了。 另外，\(T \to 1\) 时拒识率会变成多少？

    解答

    错。 这句话有三个问题。

    问题一：混淆了「错误率」和「系统表现」。

    由恒等式 \(p_c + p_e + p_r = 1\)，把 \(T\) 往上推时：

    \(T\) 拒识率 错误识别率 正确识别率 系统还能用吗
    \(0.80\) \(0.284631\) \(0.049906\) \(0.665463\) 可以 ✓
    \(0.90\) \(0.482207\) \(0.021418\) \(0.496375\) 吃力 ⚠
    \(0.95\) \(0.674881\) \(0.007453\) \(0.317666\) 几乎不可用 ⚠

    错误识别率确实降到了千分之七，但三分之二以上的样本需要人工处理 —— 这时系统的实际吞吐量已经崩塌了 ⚠

    问题二：忽略了拒识不是免费的。

    第 5.1 节算过：\(T = 0.8\) 时，被拒样本里只有 \(0.338222\) 本来会判错， 另外 \(0.661778\) 本来会判对。阈值继续调高时这个比例更差 —— \(T = 0.95\) 时只剩 \(0.205442\)， 也就是每拒 \(5\) 个样本才摊上 \(1\) 个本来会判错的 ✓

    问题三：忽略了两笔损失的大小关系。

    \[T = 1 - \frac{\lambda_r}{\lambda_e}\]

    这个公式说明 \(T\) 不是「越大越好」， 而是由任务的损失比决定的一个具体值。

    情形 正确做法
    \(\lambda_r \ll \lambda_e\)（拒识很便宜） \(T\) 应该确实很大 ✓ 这句话在这一种情形下对
    \(\lambda_r \approx \lambda_e\) \(T\) 应该接近 \(0\)，也就是基本不拒识 ⚠
    后面环节处理能力有限 \(T\) 要按容量倒推，而不是按错误率倒推

    正确的说法：

    拒识能把错误识别率压低，但代价是把样本推给后续环节。 最优阈值由判错损失与拒识损失的比值决定， 而不是「越大越好」✓

    Q3 三类问题：\(\mu = (0,\ 4,\ 9)\)，\(\sigma = (1,\ 1,\ 2)\)，先验 \((0.4,\ 0.4,\ 0.2)\)。 取 \(T = 0.6\)。样本 \(x = 6.5\) 应该怎么处理？

    提示

    三类都要算后验，别漏掉第三类。 先算三个似然，各自乘先验，再除以三者之和。

    解答

    第一步：三个似然。 注意三类标准差不同，前面的系数也不一样： \(\frac{1}{\sigma\sqrt{2\pi}}\) 分别是 \(0.398942\)（\(\sigma=1\)）与 \(0.199471\)（\(\sigma=2\)）。

    \[p(6.5 \mid \omega_1) = 0.398942 \times e^{-\frac{6.5^2}{2}} = 0.398942 \times e^{-21.125} \approx 2.670 \times 10^{-10}\]
    \[p(6.5 \mid \omega_2) = 0.398942 \times e^{-\frac{2.5^2}{2}} = 0.398942 \times e^{-3.125} = 0.398942 \times 0.043937 = 0.017528\]
    \[p(6.5 \mid \omega_3) = 0.199471 \times e^{-\frac{(-2.5)^2}{8}} = 0.199471 \times e^{-0.78125} = 0.199471 \times 0.457833 = 0.091325\]

    第二步：乘先验。

    类 似然 先验 分子
    \(\omega_1\) \(2.670 \times 10^{-10}\) \(0.4\) \(1.068 \times 10^{-10}\)
    \(\omega_2\) \(0.017528\) \(0.4\) \(0.007011\)
    \(\omega_3\) \(0.091325\) \(0.2\) \(0.018265\)
    \[\text{分母} = 0.007011 + 0.018265 = 0.025276\]

    第三步：三个后验。

    类 计算 后验
    \(\omega_1\) \(1.068\times10^{-10} / 0.025276\) \(\approx 0.000004\)
    \(\omega_2\) \(0.007011 / 0.025276\) \(0.277388\)
    \(\omega_3\) \(0.018265 / 0.025276\) \(0.722612\)

    校验：\(0.000004 + 0.277388 + 0.722612 = 1.000004\) ✓（末位来自四舍五入）

    第四步：和阈值比。

    \[\mathrm{maxP}(6.5) = 0.722612 \gt 0.6 \quad \Longrightarrow \quad \textbf{判 } \omega_3\]

    第五步：和「只比后验」对比。

    情形 结果
    不拒识（上一页规则） 判 \(\omega_3\)（后验最大）✓
    \(T = 0.6\) 判 \(\omega_3\)（\(0.722612 \gt 0.6\)）✓ 结论相同
    \(T = 0.75\) 拒识（\(0.722612 \lt 0.75\)）⚠

    所以本例的判决对阈值是敏感的 —— 阈值从 \(0.6\) 提一档到 \(0.75\)，结论就从「判 \(\omega_3\)」变成「拒识」⚠

    注意 \(1/c\) 这个参照：三类情形下 maxP 的理论下界是 \(1/3 = 0.333\)， 而这里 \(T = 0.6\) 已经远超它，所以拒识会相当积极； 若换成 \(T = 0.35\)，本例几乎不会拒识任何样本 ✓

    Q4 解释：为什么「只加一个阈值」不能解决开放集问题？ 说明两种情形分别该用什么量来判断，并各举一个量。

    提示

    关键是后验的定义里那个分母：它对哪些类求和？ 如果这个样本不属于其中的任何一个类，分母会变成什么？

    解答

    第一步：回到后验的定义。

    \[P(\omega_i \mid x) = \frac{p(x \mid \omega_i)\,P(\omega_i)}{\sum_{j=1}^{c} p(x \mid \omega_j)\,P(\omega_j)}\]

    关键在分母：它只对训练时已有的 \(c\) 个类求和。 所以后验回答的问题始终是：

    「在这 \(c\) 个已知类里，哪个最像？」

    它从来没有回答过「这个样本像不像任何已知类」⚠

    第二步：看分母在未知样本上会发生什么。

    设 \(x\) 来自一个未知类，它离所有已知类的中心都很远。 此时每一个 \(p(x \mid \omega_j)\) 都极小，于是分母

    \[\sum_{j=1}^{c} p(x \mid \omega_j)\,P(\omega_j) \approx \text{极小数}\]

    但这个极小数仍然把分子归一化了： 只要某一类的密度比别的大若干倍（哪怕两者都极小）， 它的后验就会接近 \(1\) ⚠

    本页的数字：\(x = 30\) 时（离 \(\omega_2\) 有 \(2\sigma\)）最大后验是 \(0.999945\)； \(x = 33\) 时（离 \(\omega_2\) 有 \(2.75\sigma\)）是 \(0.999999\)。 成批的未知类样本平均最大后验高达 \(0.998802\)， 而已知类样本的平均值只有 \(0.855498\) —— 未知样本反而更自信 ⚠

    第三步：所以阈值拒识在这里失效。

    做法 已知类样本被拒 未知类样本被拒 有效吗
    最大后验 \(< 0.8\) \(0.282270\) \(0.000200\) 完全无效 ⚠
    距离 \(> 2\sigma\) 约 \(0.045500\) 约 \(0.500000\) 有效 ✓

    阈值把该留的拒了 \(28\%\)，却几乎没拦住该拒的 —— 因为待比较的量本身在未知样本上给出了大值。

    第四步：两种情形该用什么量。

    情形 问题 该用的量 为什么
    情形一：不属于任何已知类 开放集 到最近类中心的距离（按 \(\sigma\) 归一化）✓ 它是非归一化的，样本远离时它变大，方向正确
    情形二：落在两类边界附近 不确定 最大后验概率 ✓ 它是归一化的，两类的证据互相抵消时它会变小，方向也对

    也可以换成密度来做情形一：用已知类的密度绝对值 （如 \(\max_j p(x \mid \omega_j) P(\omega_j)\)）和一个小常数比。 理由和距离一样 —— 这个量没有被归一化， 样本离得远时它变小，可以直接和「多小算小」比较 ✓

    第五步：更正规的办法（8.3 节）。

    给未知类也配一套先验 \(p_{c+1}\) 和密度 \(\rho\)（一个小常数）， 把它当成第 \(c+1\) 个类一起算后验。 这时分母里多了一项 \(\rho\,p_{c+1}\)， 当所有已知类密度都极小时，这一项相对变大， 未知类就有机会胜出 ✓

    本页的手算例子：\(x = 32\) 处未知类的后验是 \(0.600200\)，胜出； 而在纯阈值方案里同一个样本的最大后验接近 \(1\)。

    这正是本课程课件说的那句： 把「拒绝」当成第 \(c+1\) 个独立决策动作，在 \(c+1\) 个动作里最小期望损失 ✓

    一句话总结：阈值不是不能用来拒识， 而是它只擅长处理「两类都像」的不确定， 对「谁也不像」的陌生样本几乎无能为力 ⚠ 开放集需要的是非归一化的度量（距离、密度，或者显式建模的未知类）✓

    小结¶

    要记住的 为什么
    拒识的理由：错误识别可能带来严重后果 本课程课件原话；医疗、自动驾驶、风控、内容审核都是这个结构 ✓
    拒识不是失败，是有代价的选项 它是一次主动输出，成本和收益都要算 ⚠
    两种情形要分清：不属于任何已知类（开放集）vs 落在两类边界附近（不确定） 该用的量完全不同
    判决规则：\(\max_j P(\omega_j \mid x) \gt T\) 才判，否则拒识 阈值 \(T\) 是这一节唯一的可调参数 ✓
    为什么用最大后验 条件错误率 \(= 1 - \max_j P(\omega_j\mid x)\)，只与最大值有关 ✓
    三个区域：左判决区、中间拒识区、右判决区 判决边界决定「判给谁」，阈值 \(T\) 决定「判还是不判」✓
    \(T\) 的三个特殊值：\(T \to 0\) 不拒；\(T\) 增大拒识升、错判降；\(T \to 1\) 几乎全拒 \(T\) 要和 \(1/c\) 比较才有意义 ⚠
    拒识区两端由 \(\mathrm{maxP} = T\) 定出 高斯情形下可化成二次方程，解析可求 ✓
    三种等价写法：最大后验 / 后验差值 \(2T-1\) / 似然比 \(T/(1-T)\) 判决结果相同，多类时只有第一种能直接推广 ✓
    三个指标：正确识别率 \(p_c\)、错误识别率 \(p_e\)、拒识率 \(p_r\) 三者互斥穷尽
    恒等式 \(p_c + p_e + p_r = 1\) 判决区与拒识区拼起来是全空间；多一项不会让等式变宽 ⚠
    错误率随 \(T\) 单调降、拒识率随 \(T\) 单调升、正确率也随 \(T\) 单调降 第三条最容易被忽略：拒识会连判对的样本一起扔 ⚠
    拒识的代价：被拒样本中约 \(2/3\) 本来会判对 本页数字 \(0.661778\) vs \(0.338222\) ⚠
    边际收益递减：\(T\) 越高，被拒样本里「真该拒」的越少 从 \(0.453800\) 掉到 \(0.205442\) ⚠
    两种损失要分清：判错 \(\lambda_e\) 与拒识 \(\lambda_r\) 拒识的条件风险是常数 \(\lambda_r\)，与 \(x\) 无关 ✓
    最优阈值 \(T = 1 - \lambda_r/\lambda_e\) 由「判错的条件风险超过拒识的条件风险时就该拒识」推出
    推导的关键两步：\(R(\text{判}\omega_i \mid x) = \lambda_e[1 - P(\omega_i\mid x)]\)，\(R(\text{拒识}\mid x) = \lambda_r\) 前者靠 \(\sum_j P(\omega_j \mid x) = 1\)，后者靠损失是常数 ✓
    两个极端：\(\lambda_r \to 0\) 时 \(T \to 1\)（几乎全拒）；\(\lambda_r = \lambda_e\) 时 \(T = 0\)（不拒） 解释了这两个极端 ✓
    \(\lambda_r \gt \lambda_e\) 时应直接关掉拒识 公式会给出负阈值，没有意义 ⚠
    期望损失曲线是先降后升的 U 形 最低点恰在 \(T = 1 - \lambda_r/\lambda_e\) 处，本页扫描验证 ✓
    多类推广：规则不变，但门槛要和 \(1/c\) 比；拒识区变成多段 相邻两类重叠越厉害，拒识段越宽 ✓
    开放集：测试时可能出现训练时没见过的类 闭集假设「测试类别 ⊆ 训练类别」，开放集不成立 ⚠
    开放集的核心难点：未知类没有训练样本 所以不能简单地「把未知当一类来训练」⚠
    深度模型对未知类会过度自信 输出置信度过拟合；本页数字：未知样本平均 maxP \(0.998802\) ⚠
    只加阈值救不了开放集 后验被归一化，越远反而越自信 ⚠
    给未知类配先验与密度，当成第 \(c+1\) 个类 分母里多一项 \(\rho\,p_{c+1}\)，已知类密度极小时它相对变大 ✓
    语言引导的目标定位 用文本提示动态指定类别，融合图像与文本特征，做零样本迁移 ✓
    常用手段：阈值 / 距离 / 密度估计 / 显式建模未知 / 用额外数据学未知 各自有漏，工程上常组合使用 ⚠
    距离与后验互补 距离管「像不像已知类」（非归一化），后验管「哪一类更像」（归一化）✓
    实际应用中：拒识必须有明确的出口 医疗转医生、门禁要求刷卡、驾驶交人接管、审核转人工 ✓

    下一步：拒识这条线走得越深，越会发现判决本身可以被写成 「几个函数比大小」—— 那样才能把「边界在哪、区域怎么分」 画成图、算成解析式。
