    特征提取与降维¶

    前一页 支持向量机与核方法 用核技巧把线性方法搬进了高维空间： 维数高本身不是问题，维数高又没有足够样本才是问题。

    这一页正面处理那个藏在核技巧背后的东西 —— 维数灾难， 并给出两类最经典的应对手段：

    特征提取：把原来的 \(d\) 个特征变换成 \(k\) 个新特征（\(k \lt d\)）。

    特征选择：从原来的 \(d\) 个特征里挑出 \(k\) 个，其余丢掉。

    本页讲第一类（对应本课程大纲 7.1–7.4）， 第二类留给下一页 特征选择（对应 7.5）。

    这一页的三条主线

    主线 1：先量化问题 维数灾难不是一句口号，它有两个可以算出来的后果 —— 体积集中与距离退化。先把它算清楚，后面的方法才有靶子。

    主线 2：线性方法 PCA 最大化投影方差，LDA 最大化类间散度与类内散度之比。 两者都在找"一条好的投影方向"，但一个不看标签、一个必须看标签。

    主线 3：非线性方法 数据其实躺在一张弯曲的低维曲面上时，任何线性投影都会把它揉皱。 流形学习换用"沿曲面的距离"，核 PCA 换用"高维空间里的方差"。

    三条主线是同一个问题从易到难的三次尝试

    一、维数灾难的定量描述¶

    1.1 为什么"维数高"会变成灾难¶

    先看一个日常经验：一维区间 \([0,1]\) 上要均匀铺 10 个点， 每点之间隔 \(0.1\)；二维正方形上要铺到同样密度， 需要 \(10 \times 10 = 100\) 个点；三维要 \(1000\) 个。

    一般地，\(d\) 维单位超立方体里要维持同样的采样密度，样本量按 \(n^d\) 增长

    这就是维数灾难（本课程大纲 7.1）最朴素的样子。 但它有两个更尖锐、更可以量化的后果，下面分别算。

    1.2 后果一：体积集中到角落¶

    问题：单位超立方体的内切球占了总体积的多少？

    \(d\) 维半径为 \(r\) 的球体积是

    \[ V_d(r) = \frac{\pi^{d/2}}{\Gamma\left(\frac d2 + 1\right)} r^{d} \]

    单位立方体的内切球半径是 \(\frac12\)，立方体体积是 \(1\)，于是占比为

    \[ \frac{V_d\!\left(\frac12\right)}{1^d} = \frac{\pi^{d/2}}{2^{d}\,\Gamma\!\left(\frac d2 + 1\right)} \]

    这个比值随 \(d\) 迅速趋于零：

    维数 \(d\) 内切球占立方体体积的比例 直观含义
    2 约 \(0.785\) 圆占了正方形的很大一块
    3 约 \(0.524\) 球刚好过半
    10 约 \(2.49\times10^{-3}\) 球几乎不见了
    50 约 \(1.54\times10^{-28}\) 完全无法想象
    1000 数值上等于 \(0\) 立方体的体积几乎全在"角落"

    换个说法：高维立方体的体积几乎全部集中在角落附近， 而"中心区域"（球内）是空的

    后果：如果样本在立方体里均匀分布， 那么绝大多数样本都落在离中心很远的角落， "中心附近"这个在低维里最有代表性的区域， 在高维里根本采不到样本。

    上图把这条结论画成了两条曲线： 要覆盖同样的密度，样本量随维数按指数增长。 它提醒我们：降维不是"为了快"，而是为了"还有样本可用"。

    1.3 后果二：距离退化（所有点都差不多远）¶

    问题：高维空间里，"最近的点"和"最远的点"差多少？

    设 \(n\) 个样本在 \(d\) 维单位立方体内均匀分布， 记第 \(i\) 个样本到其余样本的最小距离为 \(d_{\min}(i)\)、 最大距离为 \(d_{\max}(i)\)。定义距离对比度

    \[ \rho = \frac{\overline{d_{\max}} - \overline{d_{\min}}}{\overline{d_{\min}}} \]

    理论上：当 \(d \to \infty\) 时 \(\rho \to 0\)。

    直观含义：在很高维的空间里，任意两点之间的距离几乎一样大

    后果非常严重：

    • 任何依赖"距离排序"的方法都失效 —— 最近邻、\(K\) 均值、聚类指标、径向基核的宽度选择， 它们的判别力都建立在"近的确实近、远的确实远"上。
    • 基于距离阈值的分类器退化 —— 阈值取在哪里，邻居集合都差不多大。

    import numpy as np
from math import pi, lgamma

np.random.seed(20240501)

def log_ball_volume(d):
    # 用对数算，避免高维时阶乘溢出
    return 0.5 * d * np.log(pi) - lgamma(0.5 * d + 1.0)

rng = np.random.default_rng(20240501)
print("维数".ljust(6) + "球体积占立方体".ljust(18) + "最近/最远距离比")
for d in (2, 5, 10, 50, 100, 500, 1000):
    vr = np.exp(log_ball_volume(d) - d * np.log(2.0))
    X = rng.random((200, d))
    G = X @ X.T
    sq = np.diag(G)
    d2 = sq[:, None] + sq[None, :] - 2.0 * G
    d2 = np.maximum(d2, 0.0)
    near = np.sqrt(np.where(np.eye(200, dtype=bool), np.inf, d2).min(axis=1))
    far = np.sqrt(np.where(np.eye(200, dtype=bool), -1.0, d2).max(axis=1))
    ratio = near.mean() / far.mean()
    print(("%d" % d).ljust(6) + ("%.3e" % vr).ljust(18) + "%.4f" % ratio)

    第三列趋近于 \(1\) 意味着：最近的点和最远的点几乎一样远 这正好就是 1.3 节说的距离退化。

    维数灾难不是「数据太多」，是「数据太稀」

    常见误解是"维数高 → 信息多 → 应该更容易分"。 真实情况相反：

    · 固定的样本量下，维数越高，样本在空间里越稀疏， 任何非参数方法（密度估计、近邻、聚类）需要的样本量都按 \(n^d\) 增长。

    · 很多特征其实是相关的，真正承载判别信息的自由度远小于 \(d\) —— 所以"降维"往往不是丢信息，而是丢掉冗余与噪声

    这也是为什么本页要花一整节先把这个代价算清楚： 只有知道代价有多大，才知道为什么值得为降维付出变换的代价。

    降维是「有损」的，必须交代损失

    把 \(d\) 维压到 \(k\) 维一定会丢东西。 凡是声称"降维不损失信息"的说法都是错的， 正确的说法只有两种：

    · 数据本来就在低维结构上（冗余维），此时丢的是噪声； · 丢掉的信息对这个任务不重要（判别信息集中在少数方向）， 此时丢的是与任务无关的变化

    所以任何降维方法都必须同时报告保留了多少信息。 PCA 用"保留方差比例"，本页第三节会给出这个量的算法。

    1.4 与此前几页的关系¶

    此前讲过的内容 在本页的位置
    贝叶斯决策需要估计类条件密度 维数越高，需要估计的参数越多（参数量按维数幂次增长）⚠
    非参数密度估计（窗法、近邻法） 直接受距离退化的打击，\(d\) 一大就退化
    线性分类器 / SVM 权重向量的维数就是特征维数，冗余维只会增加方差
    核方法 核宽度（如径向基核的 \(\gamma\)）在高维里极难选

    所以降维与前面每一页都相关 —— 它不是新问题，而是前面所有方法在高维下的共同前提。

    二、特征提取与降维的基本框架¶

    2.1 三种思路¶

    面对 \(d\) 维特征，想得到 \(k\) 维（\(k \lt d\)），有三条路：

    思路 做法 新特征的物理意义 典型方法
    特征提取（本页） 作变换 \(\boldsymbol{z} = W^{\mathsf T}\boldsymbol{x}\) 通常没有，是人造的组合量 ⚠ PCA、LDA、核 PCA、流形学习
    特征选择（下一页） 取一个子集 \(\boldsymbol{z} = \boldsymbol{x}_{S}\) 有，还是原来的物理量 ✓ 过滤式、包裹式、嵌入式
    二者混合 先筛再变 部分有 先做单变量筛选再 PCA

    表格里最关键的一列是"新特征的物理意义" —— 它决定了两类方法真正的取舍：

    • 特征提取压缩得更狠（\(k\) 可以比选择方法小得多）， 但代价是解释性丧失：新特征是原特征的线性组合， 你没法再说"这是温度、那是压力"。
    • 特征选择保留原来特征的物理含义， 在医学、故障诊断这类必须给出理由的场景里往往是硬需求 ✓

    这个取舍的完整讨论放在下一页。本页先专攻特征提取。

    2.2 什么才算"好的 \(k\) 个新方向"¶

    一个变换 \(W \in \mathbb{R}^{d \times k}\) 好不好，取决于我们想保住什么。 最常用的两种目标恰好对应本页的两大方法：

    目标 数学形式 用标签吗 对应方法
    投影后方差最大 \(\max\ \operatorname{tr}(W^{\mathsf T} C W)\) 不用 PCA
    类间散度 / 类内散度最大 \(\max\ \dfrac{W^{\mathsf T} S_b W}{W^{\mathsf T} S_w W}\) 必须用 ✓ LDA

    这里出现了本页最重要的一条分界线：

    PCA 只看到 \(\boldsymbol{x}\)，LDA 还要看到 \(y\)。

    第三节和第五节会分别推导它们，并说明为什么这个差别会在真实数据上 造成完全不同的结果。

    为什么「方差大」是一个合理的目标

    因为方差大 = 变化大 = 信号强，至少有三条理由：

    · 噪声与信号的区分：噪声在各方向上的方差大致相同， 而信号集中在少数方向 —— 保住大方差方向就是提高信噪比

    · 重构误差：本节第四节会证明， 丢掉方差最小的那些方向，恰好等价于让平均重构误差最小。

    · 信息论：在联合高斯假设下， 主成分方向恰好是按"信息量"从大到小排的。

    但要注意第一条推论：如果判别信息恰好落在方差最小的方向上， PCA 会把它丢掉 ⚠ 第五节会用一组数据把这个反面例子跑出来。

    三、PCA：两种推导及其等价性¶

    主成分分析（PCA）的历史上有两条完全不同的出发点：

    1. 几何/统计的角度：找一个方向，使投影后的方差最大。
    2. 逼近/工程的角度：找一个低维子空间，使样本到它的距离最小。

    这两条路的出发点毫无共同之处，但答案是同一组方向 —— 这就是本节要证明的核心结论，也是 PCA 这个方法的"合法性来源"。

    3.1 预备：中心化与总体协方差矩阵¶

    记样本矩阵 \(X \in \mathbb{R}^{n \times d}\)，每行一个样本。 先把每个特征减去自己的均值，得到 \(\tilde{X}\)：

    \[ \tilde{X} = X - \mathbf{1}\boldsymbol{\mu}^{\mathsf T}, \qquad \boldsymbol{\mu} = \frac1n\sum_{i=1}^{n}\boldsymbol{x}_i \]

    为什么必须中心化：协方差衡量的是"围绕均值的波动"。 不中心化就等于把均值当成信号，第一主成分会退化成"均值方向"， 这在几何上毫无意义

    中心化之后，总体协方差矩阵（除以 \(n\)）为

    \[ C = \frac1n \tilde{X}^{\mathsf T}\tilde{X} = \frac1n\sum_{i=1}^{n}(\boldsymbol{x}_i-\boldsymbol{\mu})(\boldsymbol{x}_i-\boldsymbol{\mu})^{\mathsf T} \]

    \(C\) 是对称半正定矩阵，这是后面所有性质的出发点： 对称保证特征向量正交、特征值全是实数； 半正定保证特征值非负。

    3.2 推导一：最大化投影方差¶

    目标：找单位向量 \(\boldsymbol{w}\)，使 \(\boldsymbol{x}\) 在它上面的投影 \(\boldsymbol{w}^{\mathsf T}\boldsymbol{x}\) 的方差最大。

    投影后的方差是

    \[ \operatorname{Var}\!\left(\boldsymbol{w}^{\mathsf T}\boldsymbol{x}\right) = \boldsymbol{w}^{\mathsf T} C \boldsymbol{w} \]

    于是问题写成

    \[ \max_{\boldsymbol{w}}\ \boldsymbol{w}^{\mathsf T}C\boldsymbol{w} \qquad \text{s.t.}\qquad \boldsymbol{w}^{\mathsf T}\boldsymbol{w}=1 \]

    为什么必须有这个约束：\(\boldsymbol{w}^{\mathsf T}C\boldsymbol{w}\) 关于 \(\boldsymbol{w}\) 是二次齐次的 —— 把 \(\boldsymbol{w}\) 放大一倍，目标值变成四倍， 不加约束的话最大值是无穷大，问题没有意义

    解法：拉格朗日乘子法。令

    \[ L(\boldsymbol{w},\lambda) = \boldsymbol{w}^{\mathsf T}C\boldsymbol{w} - \lambda\left(\boldsymbol{w}^{\mathsf T}\boldsymbol{w}-1\right) \]

    对 \(\boldsymbol{w}\) 求梯度并令零：

    \[ \frac{\partial L}{\partial \boldsymbol{w}} = 2C\boldsymbol{w} - 2\lambda\boldsymbol{w} = 0 \;\Longrightarrow\; C\boldsymbol{w} = \lambda\boldsymbol{w} \]

    这是一个特征值方程。代回目标函数得

    \[ \boldsymbol{w}^{\mathsf T}C\boldsymbol{w} = \lambda\,\boldsymbol{w}^{\mathsf T}\boldsymbol{w} = \lambda \]

    结论：目标值就等于特征值。所以 最大化方差 = 取最大特征值对应的特征向量

    第二主成分在与第一主成分正交的约束下再解一次， 得到第二大的特征值对应的特征向量，依此类推。

    3.3 推导二：最小化重构误差¶

    目标：找一组标准正交方向 \(W = [\boldsymbol{w}_1,\dots,\boldsymbol{w}_k] \in \mathbb{R}^{d\times k}\) （满足 \(W^{\mathsf T}W = I_k\)）， 使样本投影再还原之后离原样本最"近"：

    \[ \min_{W}\ J(W) = \sum_{i=1}^{n}\left\| \boldsymbol{x}_i - W W^{\mathsf T}\boldsymbol{x}_i \right\|^2 \]

    注意 \(W W^{\mathsf T}\) 是一个投影矩阵： 它把样本投到 \(W\) 张成的子空间上。 所以这个目标衡量的是样本到该子空间的距离平方和。

    展开目标函数（这一步不跳步，因为它同时用到了两条恒等式）：

    \[ \left\|\boldsymbol{x} - WW^{\mathsf T}\boldsymbol{x}\right\|^2 = \boldsymbol{x}^{\mathsf T}\boldsymbol{x} - 2\,\boldsymbol{x}^{\mathsf T}WW^{\mathsf T}\boldsymbol{x} + \boldsymbol{x}^{\mathsf T}WW^{\mathsf T}WW^{\mathsf T}\boldsymbol{x} \]

    关键在第三项：因为 \(W^{\mathsf T}W = I_k\)， 所以 \(WW^{\mathsf T}WW^{\mathsf T} = WW^{\mathsf T}\)，第三项化简成 \(\boldsymbol{x}^{\mathsf T}WW^{\mathsf T}\boldsymbol{x}\)。 于是

    \[ \left\|\boldsymbol{x} - WW^{\mathsf T}\boldsymbol{x}\right\|^2 = \boldsymbol{x}^{\mathsf T}\boldsymbol{x} - \boldsymbol{x}^{\mathsf T}WW^{\mathsf T}\boldsymbol{x} = \left\|\boldsymbol{x}\right\|^2 - \operatorname{tr}\!\left(W^{\mathsf T}\boldsymbol{x}\boldsymbol{x}^{\mathsf T}W\right) \]

    对全部样本求和，注意 \(\sum_i \|\boldsymbol{x}_i\|^2\) 与 \(W\) 无关：

    \[ J(W) = \underbrace{\sum_{i=1}^{n}\left\|\boldsymbol{x}_i\right\|^2}_{\text{常数}} - n\,\operatorname{tr}\!\left(W^{\mathsf T}CW\right) \]

    所以最小化 \(J(W)\) 等价于最大化 \(\operatorname{tr}(W^{\mathsf T}CW)\)

    3.4 两者为什么等价¶

    现在把两条推导并排放：

    \[ \underbrace{\max_{\boldsymbol{w}}\ \boldsymbol{w}^{\mathsf T}C\boldsymbol{w}} _{\text{推导一：最大方差}} \qquad\qquad \underbrace{\max_{W}\ \operatorname{tr}\!\left(W^{\mathsf T}CW\right)} _{\text{推导二：最小重构误差}} \]

    命题：两个问题的解都是 \(C\) 的前 \(k\) 个最大特征值对应的特征向量。

    证明（逐步）：

    第一步：把问题化成对角形式。 \(C\) 对称半正定，可以做特征分解 \(C = V\Lambda V^{\mathsf T}\)，其中 \(V\) 正交、\(\Lambda\) 对角且元素非负。

    第二步：换变量。 令 \(U = V^{\mathsf T}W\)。由于 \(V\) 正交， \(W^{\mathsf T}W = I\) 等价于 \(U^{\mathsf T}U = I\)，于是

    \[ \operatorname{tr}\!\left(W^{\mathsf T}CW\right) = \operatorname{tr}\!\left(W^{\mathsf T}V\Lambda V^{\mathsf T}W\right) = \operatorname{tr}\!\left(U^{\mathsf T}\Lambda U\right) = \sum_{j=1}^{k}\sum_{i=1}^{d}\lambda_i u_{ij}^2 \]

    第三步：看出上界。 \(U\) 的每一列是单位向量，所以对每列 \(j\) 有 \(\sum_i u_{ij}^2 = 1\)。 把上式按列重排：

    \[ \operatorname{tr}\!\left(U^{\mathsf T}\Lambda U\right) = \sum_{j=1}^{k}\left(\sum_{i=1}^{d}\lambda_i u_{ij}^2\right) \]

    对固定的 \(j\)，括号里是特征值的加权平均（权重和为 \(1\)）， 因此不超过最大的 \(k\) 个特征值之和：

    \[ \sum_{i=1}^{d}\lambda_i u_{ij}^2 \;\le\; \lambda_1 \qquad\left(\lambda_1\ \text{为最大特征值}\right) \]

    对 \(k\) 列一起放缩，可以更紧地写成

    \[ \operatorname{tr}\!\left(U^{\mathsf T}\Lambda U\right) \;\le\; \sum_{j=1}^{k}\lambda_{j} \]

    第四步：确认上界可达。 取 \(U\) 的前 \(k\) 列为标准基向量 \(\boldsymbol{e}_1,\dots,\boldsymbol{e}_k\)（对应最大 \(k\) 个特征值）， 则每一列只在最大特征值位置取 \(1\)，取到上界。 此时 \(W = VU\) 就是 \(C\) 的前 \(k\) 个特征向量

    第五步：把等价性说完整。 结合 3.3 的恒等式

    \[ J(W) = \sum_{i=1}^{n}\left\|\boldsymbol{x}_i\right\|^2 - n\operatorname{tr}\!\left(W^{\mathsf T}CW\right) \]

    右边第一项是常数，于是

    \[ \min_W J(W) \;\Longleftrightarrow\; \max_W \operatorname{tr}\!\left(W^{\mathsf T}CW\right) \;\Longleftrightarrow\; \max_{\boldsymbol{w}}\boldsymbol{w}^{\mathsf T}C\boldsymbol{w}\ \text{逐列解} \]

    三者是同一个优化问题 这就是"最大方差 = 最小重构误差"的完整证明。

    上图是这段话的几何版本：数据在斜方向上摊得最开， 那个方向既是投影方差最大的方向，也是样本到该直线距离平方和最小的方向。 两条推导在图上指的是同一条直线。

    3.5 等价性推出的一条实用结论¶

    回到

    \[ J(W) = \sum_{i=1}^{n}\left\|\boldsymbol{x}_i\right\|^2 - n\sum_{j=1}^{k}\lambda_j \]

    两边同除以 \(\sum_i\|\boldsymbol{x}_i\|^2\)（即总平方和），得到相对重构误差

    \[ \frac{J(W)}{\sum_i\left\|\boldsymbol{x}_i\right\|^2} = 1 - \frac{\sum_{j=1}^{k}\lambda_j}{\sum_{j=1}^{d}\lambda_j} \]

    分母 \(\sum_j\lambda_j\) 恰好是总方差（因为 \(\operatorname{tr}(C) = \sum_j \lambda_j\)）。

    所以

    \[ \text{保留的信息比例} = \frac{\sum_{j=1}^{k}\lambda_j}{\sum_{j=1}^{d}\lambda_j} \]

    这解释了为什么"累积方差贡献率"不是一个人为约定的指标 —— 它同时是方差保留比例和 1 减去相对重构误差

    PCA 与量纲：不标准化的后果

    如果某个特征的单位是"米"，另一个是"毫米"， 后者的数值会大上千倍，它的方差也会大上百万倍。

    结果：PCA 会几乎只挑单位大的那个特征，不管它有没有用

    所以实践中通常有两条路：

    · 先标准化（每个特征减均值、除以标准差）再 PCA —— 等价于对相关系数矩阵做特征分解； · 不标准化，但各特征本来就同量纲、可比（如全部是同一类传感器读数）。

    本节代码走前一条路（数据本来同量纲，但为了与后面的 LDA 统一， 仍按标准化后的尺度讨论）。选哪条路必须在报告里交代清楚 ⚠

    四、PCA 的计算步骤与主成分个数选择¶

    4.1 五步流程¶

    步骤 做什么 为什么这一步不能省
    ① 中心化 每个特征减自己的均值 不中心化则第一主成分变成"均值方向" ⚠
    ② 算协方差 \(C = \tilde{X}^{\mathsf T}\tilde{X}/n\) 它是后续一切计算的输入
    ③ 特征分解 \(C = V\Lambda V^{\mathsf T}\)，特征值降序排 对称矩阵，一定可以正交对角化 ✓
    ④ 选 \(k\) 按累积贡献率或碎石图定 这一步决定"压到几维"
    ⑤ 投影 \(Z = \tilde{X}V_{:,:k}\) 得到 \(k\) 维新特征，供后续分类器使用

    实践提醒：当 \(n \ll d\) 时（基因数据、文本数据常常如此）， \(C\) 是 \(d\times d\) 的，直接做特征分解代价很大。 这时改对 \(n\times n\) 的 \(\tilde{X}\tilde{X}^{\mathsf T}\) 做特征分解， 再用关系 \(\boldsymbol{v} = \tilde{X}^{\mathsf T}\boldsymbol{u}/\sqrt{n\lambda}\) 换回去， 代价从 \(O(d^3)\) 降到 \(O(n^3)\) （这条路在本课程"线性代数"层的特征分解一页有推导。）

    碎石图拐点 看特征值曲线由陡变缓的转折 特征值有明显断层时 拐点靠肉眼判断 ⚠

    P = np.outer(Xc @ u, u)
    return float(((Xc - P) ** 2).sum())

    标准化与「取几个主成分」必须一起决定

    两条常见错误：

    · 先按原始尺度做 PCA，再对主成分做标准化 —— 主成分的尺度本来就是特征值的平方根， 再标准化等于人为抹掉了方差信息，PCA 的排序就白做了

    · 对已标准化的数据用 Kaiser 准则（特征值大于 1） —— 这个准则只在"用相关系数矩阵"时才有"平均特征值为 1"的依据。 用协方差矩阵时它完全没有意义

    正确的顺序是：先决定量纲处理方式，再决定个数判据

    五、线性判别分析（LDA）¶

    5.1 PCA 的盲点¶

    PCA 有一个致命盲点：它只看 \(\boldsymbol{x}\)，完全不看标签 \(y\)。

    后果：如果判别信息恰好落在方差很小的方向上， PCA 会优先丢掉它

    这不是理论上的可能，而是会真实发生的： 只要类内变化在某个方向上很大（方差大）， 而类间差异在另一个方向上很小（方差小）， PCA 就必然抓住前者、放弃后者。

    5.2 Fisher 判据¶

    线性判别分析（LDA）的想法：既然我们有标签，就别浪费它。 希望投影之后

    • 同类样本挤在一起（类内散度 \(S_w\) 小）
    • 不同类样本离得远（类间散度 \(S_b\) 大）

    散度的定义（两类情形）：

    \[ S_w = \sum_{c\in\{1,2\}}\sum_{i:\,y_i=c} \left(\boldsymbol{x}_i - \boldsymbol{m}_c\right) \left(\boldsymbol{x}_i - \boldsymbol{m}_c\right)^{\mathsf T} \]
    \[ S_b = \left(\boldsymbol{m}_1 - \boldsymbol{m}_2\right) \left(\boldsymbol{m}_1 - \boldsymbol{m}_2\right)^{\mathsf T} \]

    这里 \(\boldsymbol{m}_c\) 是第 \(c\) 类样本均值。注意 \(S_b\) 是秩 1 矩阵 —— 两类情形下"类间差异"只有一条连线，这个细节稍后会用到。

    Fisher 判据（要最大化的量）：

    \[ J(\boldsymbol{w}) = \frac{\boldsymbol{w}^{\mathsf T}S_b\boldsymbol{w}} {\boldsymbol{w}^{\mathsf T}S_w\boldsymbol{w}} \]

    商的形式很关键：它对 \(\boldsymbol{w}\) 的尺度不变， 所以这次不需要像 PCA 那样额外加单位长度约束

    5.3 解出判别方向¶

    \(J(\boldsymbol{w})\) 是广义瑞利商，求导令零（分子分母的梯度用商法则）：

    \[ \frac{\partial J}{\partial \boldsymbol{w}} = 0 \;\Longrightarrow\; \left(\boldsymbol{w}^{\mathsf T}S_w\boldsymbol{w}\right) S_b\boldsymbol{w} = \left(\boldsymbol{w}^{\mathsf T}S_b\boldsymbol{w}\right) S_w\boldsymbol{w} \]

    整理成广义特征值问题：

    \[ S_b\boldsymbol{w} = \lambda S_w\boldsymbol{w}, \qquad \lambda = J(\boldsymbol{w}) \]

    两类情形可以直接解出来：因为 \(S_b\boldsymbol{w}\) 一定平行于 \((\boldsymbol{m}_1-\boldsymbol{m}_2)\)，代入即得

    \[ \boldsymbol{w} \;\propto\; S_w^{-1}\left(\boldsymbol{m}_1-\boldsymbol{m}_2\right) \]

    这就是两类 LDA 的闭式解 它的含义非常好记：先用类内散度把空间"白化"， 再沿着白化后的类均值连线方向投影。

    5.4 多类推广与维数上限¶

    多类情形把散度改成

    \[ S_w = \sum_{c=1}^{C}\sum_{i:\,y_i=c} \left(\boldsymbol{x}_i-\boldsymbol{m}_c\right)\left(\boldsymbol{x}_i-\boldsymbol{m}_c\right)^{\mathsf T} \]
    \[ S_b = \sum_{c=1}^{C} n_c\left(\boldsymbol{m}_c-\boldsymbol{m}\right) \left(\boldsymbol{m}_c-\boldsymbol{m}\right)^{\mathsf T} \]

    一条硬性限制：\(S_b\) 是 \(C\) 个秩 1 矩阵之和， 而 \(\sum_c n_c(\boldsymbol{m}_c-\boldsymbol{m}) = 0\)， 所以它的秩最多是 \(C-1\)。

    结论：LDA 最多只能把数据降到 \(C-1\) 维

    类别数 \(C\) LDA 最多可降到几维 说明
    2 1 只可能找出一条判别方向
    3 2 平面内的两个方向
    10 9 再多也没有判别信息了
    100 99 类别多时这个限制通常不成问题

    这条限制不是算法缺陷，而是信息论上的必然： \(C\) 类的可分性最多只有 \(C-1\) 个独立自由度

# 类内沿 y 方向拉长（该方向方差大），类间只沿 x 方向分开（该方向方差小）
n1 = n2 = 250
L = np.linalg.cholesky(np.diag([0.5 ** 2, 2.0 ** 2]))
X1 = rng.standard_normal((n1, 2)) @ L.T + np.array([-0.7, 0.0])
X2 = rng.standard_normal((n2, 2)) @ L.T + np.array([0.7, 0.0])
X = np.vstack([X1, X2])

# 路线一：PCA —— 只看总方差，不看标签
Xc = X - X.mean(axis=0)
w, V = np.linalg.eigh(Xc.T @ Xc / len(X))

if v_pca[0] < 0:
    v_pca = -v_pca

# 路线二：LDA —— 用标签算类内散度 Sw 与类间散度 Sb
m1 = X1.mean(axis=0)
m2 = X2.mean(axis=0)
Sw = np.zeros((2, 2))
for Xi, mi in ((X1, m1), (X2, m2)):
    D = Xi - mi
    Sw += D.T @ D
Sb = (m1 - m2)[:, None] @ (m1 - m2)[None, :]
ev, EV = np.linalg.eig(np.linalg.solve(Sw, Sb))
v_lda = EV[:, int(np.argmax(ev.real))].real.copy()
v_lda = v_lda / np.linalg.norm(v_lda)
if v_lda[0] < 0:
    v_lda = -v_lda

    PCA 与 LDA 的适用条件完全不同

    不要因为"LDA 效果更好"就以为它总是更优。两者的适用条件如下：

    · PCA 是无监督的 —— 任何数据都能用，不需要标签， 在探索性分析、去噪、压缩、可视化里是首选

    · LDA 是有监督的 —— 必须有标签。 它假设各类协方差矩阵相同（同分布形状）， 如果不同，线性判别方向就不是最优的，此时要用二次判别分析

    · LDA 对类别不平衡敏感 —— \(S_b\) 里带了 \(n_c\)， 小类的贡献被压制，可能被大类的方向主导 ⚠

    · LDA 的维数上限是 \(C-1\) —— 需要压到更低维或做可视化时， 这个上限可能刚好不够用

    要点：有标签且目标是分类 → LDA；无标签或目标是压缩 → PCA。

    六、非线性方法：流形学习与核 PCA¶

    6.1 线性方法的根本局限¶

    PCA 与 LDA 找的都是线性投影：\(\boldsymbol{z} = W^{\mathsf T}\boldsymbol{x}\)。 它们隐含地假设：数据在原始空间里就躺在一张平的（线性的）低维子空间上。

    如果数据躺在一张弯曲的曲面上呢？

    想象一张卷起来的纸（二维曲面嵌在三维空间）。 纸上相邻的两点，在三维空间里的直线距离（欧氏距离）可能很远， 但沿着纸面走却只隔一点点。线性投影会把这张纸压扁， 本来离得近的点被压到一起 ✗

    这就是"流形"的概念：数据实际躺在一个 \(k\) 维曲面（流形）上， \(k\) 远小于环境维数 \(d\)。 降维的正确目标不是"找方差最大的平面"， 而是"把这张曲面摊平"。

    6.2 两条经典思路¶

    方法 核心想法 需要什么 得到什么
    Isomap 用图上最短路近似"沿曲面的距离"，再对这个距离矩阵做多维标度 邻域图（\(k\) 近邻或半径） 全局的等距展开 ✓
    LLE 每个点用其邻居线性重建，保持这组重建权重不变，求低维坐标 邻域图 局部几何的保持 ✓
    核 PCA 把数据映射到高维特征空间，在那里做 PCA 核函数 隐式的非线性主成分

    Isomap 与 LLE 的共同点：都先建邻域图， 再用图上的局部信息去近似"沿曲面的几何"。 区别：Isomap 关心全局距离（谁离谁远）， LLE 只关心局部权重（每个点怎么由邻居拼出来）。

    核 PCA 走的是完全不同的路：它不是"把曲面摊平"， 而是把曲面升到更高维空间里让它变平。

    6.3 核 PCA 的推导¶

    第一步：先在高维空间里做普通 PCA。

    设映射 \(\phi\) 把样本送到特征空间，在那里中心化后记为 \(\tilde{\phi}(\boldsymbol{x}_i) = \phi(\boldsymbol{x}_i) - \bar{\phi}\)。 目标是求特征空间协方差矩阵的特征向量 \(\boldsymbol{v}\)：

    \[ C_\phi \boldsymbol{v} = \frac1n\sum_{i=1}^{n}\tilde{\phi}(\boldsymbol{x}_i) \tilde{\phi}(\boldsymbol{x}_i)^{\mathsf T}\boldsymbol{v} = \lambda\boldsymbol{v} \]

    第二步：注意到特征向量一定落在样本张成的空间里。 上面的式子表明 \(C_\phi\boldsymbol{v}\) 是 \(\tilde{\phi}(\boldsymbol{x}_i)\) 的线性组合， 所以最优的 \(\boldsymbol{v}\) 可以写成

    \[ \boldsymbol{v} = \sum_{i=1}^{n}\alpha_i\,\tilde{\phi}(\boldsymbol{x}_i) \]

    第三步：两边同时与 \(\tilde{\phi}(\boldsymbol{x}_j)\) 做内积。 把 \(\boldsymbol{v}\) 的表达式代进去，左边的内积变成

    \[ \tilde{\phi}(\boldsymbol{x}_j)^{\mathsf T}C_\phi\boldsymbol{v} = \frac1n\sum_{i=1}^{n} \underbrace{\tilde{\phi}(\boldsymbol{x}_j)^{\mathsf T}\tilde{\phi}(\boldsymbol{x}_i)} _{\tilde{K}_{ji}}\; \underbrace{\tilde{\phi}(\boldsymbol{x}_i)^{\mathsf T}\boldsymbol{v}} _{(\tilde{K}\boldsymbol{\alpha})_i} \]

    右边同理。于是高维空间里的特征值问题变成了 \(n\) 维的核矩阵问题：

    \[ \tilde{K}\boldsymbol{\alpha} = n\lambda\boldsymbol{\alpha} \]

    第四步：处理中心化。 \(\tilde{K}\) 是"中心化后"的核矩阵，它可以由原始核矩阵直接算出：

    \[ \tilde{K} = K - \mathbf{1}_n K - K\mathbf{1}_n + \mathbf{1}_n K\mathbf{1}_n, \qquad \mathbf{1}_n = \frac1n\mathbf{1}\mathbf{1}^{\mathsf T} \]

    第五步：投影式也不需要显式算出 \(\phi\)。

    \[ \boldsymbol{v}^{\mathsf T}\tilde{\phi}(\boldsymbol{x}) = \sum_{i=1}^{n}\alpha_i\, \tilde{\phi}(\boldsymbol{x}_i)^{\mathsf T}\tilde{\phi}(\boldsymbol{x}) = \sum_{i=1}^{n}\alpha_i\,\tilde{K}(\boldsymbol{x}_i,\boldsymbol{x}) \]

    全部只用核函数的值 ✓ 这就是核技巧在这里的用法。

    • 相隔较远（索引差不少于八十）的点对，"平面距离/测地距离"平均只有 \(0.5761\) —— 也就是说欧氏距离把真实距离压缩到了不足六成， 这正是线性方法必然失败的根源。
    • 与曲线参数 \(t\) 的相关性：线性 PCA 第一主成分是 \(0.8286\)， Isomap 第一坐标是 \(0.9999\)。 Isomap 几乎完美地把这条曲线摊成了一条直线
    • 两端点在嵌入坐标里的距离：PCA 只有 \(0.4674\)（几乎被压到一起）， Isomap 有 \(3.4292\) —— 首尾被正确拉回到了两端

    Isomap 端点间测地距离 \(6.0812\) 与真实弧长 \(18.7522\) 的关系 也值得注意：两者不等（Isomap 用的是弦长累加而不是弧长， 而且首尾之间还隔着一个邻域外的空隙）。 这说明流形学习给的是"保拓扑"的嵌入，不是精确等距

    流形学习与核 PCA 该选哪个

    两者都在对付"数据躺在弯曲曲面上"，但思路相反：

    · 流形学习（Isomap / LLE）是"摊平" —— 它相信数据在一个低维曲面上，努力把这个曲面展开。 优点是嵌入结果的每一维有几何含义（比如 Isomap 的第一坐标 就是"沿曲面的位置"）。缺点是要建邻域图， 对邻域大小 \(k\) 很敏感，而且图不连通时会直接失败

    · 核 PCA 是"提升" —— 它把数据映射到高维空间，在那里做线性 PCA。 优点是不需要建图，只要一个核函数； 缺点是新特征仍然没有物理意义， 而且核宽度参数要靠下游性能来调

    经验法则：需要可解释的低维坐标 → 流形学习； 只要一个能喂给分类器的更好表示 → 核 PCA

    邻域图断裂会让流形学习直接失效

    Isomap 与 LLE 都建在邻域图上。图一旦不连通，测地距离就是无穷大， 双中心化会出现 nan，整个算法崩掉。

    什么时候会断：

    · \(k\) 太小 —— 数据稀疏的地方连不上，图被切成几块； · \(k\) 太大 —— 不相邻的曲面片被错误地连起来， "测地距离"走捷径，展开结果被扭曲

    所以 \(k\) 必须同时满足"图连通"和"不跨片"两个要求， 这两个要求方向相反，需要试。 本节的代码用的是 \(k=6\)（\(240\) 个点、一圈 \(342\) 度）， 这个值刚好让图连通又没有跨片 —— 换了数据就必须重新试。

    例题 1：算一个特征值并判断该保留几个主成分¶

    题目：某数据集的协方差矩阵（已中心化）特征值为 \(5.2,\ 2.1,\ 0.6,\ 0.1\)。 （1）若要求保留方差不低于 \(85\%\)，至少取几个主成分？ （2）若用 Kaiser 准则（特征值大于 1），取几个？ （3）两个答案不同，说明什么？

    思路

    先算总方差与累积占比，再分别按两个判据读出 \(k\)。 最后一问要指出判据本身的经验性。

    解答

    第一步：总方差。

    \[ \lambda_{\text{总}} = 5.2 + 2.1 + 0.6 + 0.1 = 8.0 \]

    第二步：累积占比。

    取几个 累积特征值 累积占比
    1 5.2 65.00%
    2 7.3 91.25% ✓
    3 7.9 98.75%
    4 8.0 100.00%

    达到 \(85\%\) 需要 \(k=2\)。

    第三步：Kaiser 准则。

    特征值大于 \(1\) 的有 \(5.2\) 与 \(2.1\) 两个，所以也是 \(k=2\)。

    答案：两个判据在本例给出相同答案 \(k=2\)

    第四步：关于"两个答案不同"的一般讨论。

    本例恰好相同，但两个判据确实会不一致。原因是：

    判据 依据 什么时候会偏
    累积 \(85\%\) 相对比例 特征值整体很大或很小时，比例阈值不合适
    Kaiser（大于 1） 绝对大小 只在用相关系数矩阵（平均特征值为 1）时才有依据 ⚠

    个数判据都是启发式规则，不是定理 真正该用的做法是把 \(k\) 当超参数， 用下游任务（分类正确率、回归误差）在验证集上选

    例题 2：验证"最大方差 = 最小重构误差"¶

    题目：给定中心化后的样本矩阵 \(\tilde{X}\)（3 个样本，2 个特征）：

    \[ \tilde{X} = \begin{pmatrix} 1 & 0\\ 0 & 1\\ -1 & -1 \end{pmatrix} \]

    求（1）协方差矩阵 \(C\)；（2）它的特征值与特征向量； （3）取第一主成分时的相对重构误差。

    思路

    先算 \(C = \tilde{X}^{\mathsf T}\tilde{X}/n\)， 再特征分解，最后用 \(1 - \lambda_1/(\lambda_1+\lambda_2)\) 求相对误差。

    解答

    第一步：算协方差矩阵。

    \[ \tilde{X}^{\mathsf T}\tilde{X} = \begin{pmatrix} 1 & 0 & -1\\ 0 & 1 & -1 \end{pmatrix} \begin{pmatrix} 1 & 0\\ 0 & 1\\ -1 & -1 \end{pmatrix} = \begin{pmatrix} 2 & 1\\ 1 & 2 \end{pmatrix} \]

    除以 \(n=3\) 得

    \[ C = \frac13\begin{pmatrix}2 & 1\\ 1 & 2\end{pmatrix} \]

    第二步：特征分解。

    \(C\) 与 \(\begin{pmatrix}2 & 1\\ 1 & 2\end{pmatrix}\) 特征向量相同。 对称矩阵的特征向量是 \((1,1)^{\mathsf T}\) 与 \((1,-1)^{\mathsf T}\)：

    \[ \begin{pmatrix}2&1\\1&2\end{pmatrix}\begin{pmatrix}1\\1\end{pmatrix} = 3\begin{pmatrix}1\\1\end{pmatrix}, \qquad \begin{pmatrix}2&1\\1&2\end{pmatrix}\begin{pmatrix}1\\-1\end{pmatrix} = 1\begin{pmatrix}1\\-1\end{pmatrix} \]

    除以 \(3\) 后特征值为

    \[ \lambda_1 = 1,\qquad \lambda_2 = \frac13 \]

    对应的单位特征向量是 \(\frac{1}{\sqrt2}(1,1)^{\mathsf T}\) 与 \(\frac{1}{\sqrt2}(1,-1)^{\mathsf T}\)。

    第三步：相对重构误差。

    \[ \frac{J}{\sum_i\|\boldsymbol{x}_i\|^2} = 1 - \frac{\lambda_1}{\lambda_1+\lambda_2} = 1 - \frac{1}{1+\frac13} = 1 - \frac34 = 0.25 \]

    答案：\(\lambda = (1,\ \tfrac13)\)，方向 \((1,1)\) 与 \((1,-1)\)， 取第一主成分的相对重构误差为 \(0.25\)

    验算：把三个样本投到 \(\frac{1}{\sqrt2}(1,1)\) 上得 \(\frac{1}{\sqrt2},\ \frac{1}{\sqrt2},\ -\sqrt2\)， 还原后确实只剩沿 \((1,1)\) 的分量， 丢掉的正是沿 \((1,-1)\) 的那部分，占四分之一

    "丢掉最小特征值方向"与"重构误差最小"是同一件事 —— 这就是 3.4 节等价性证明在最小例子上的样子

    例题 3：判断该用 PCA 还是 LDA¶

    题目：三个场景，分别说明该用 PCA 还是 LDA，并给出理由。

    （甲）有一批未标注的图像，想压到 2 维做可视化观察结构； （乙）有标注的手写数字（10 类），想把特征压到适合分类的维度； （丙）有标注的数据，但每类只有一个样本。

    思路

    从"有没有标签""标签够不够用""类别数决定维数上限"三个角度判断。

    解答

    甲：PCA。

    · 没有标签 → LDA 无法使用（它必须有 \(y\)）✓ · 目标是探索结构与可视化 → 保留最大方差最合理

    乙：LDA。

    · 有标签，且目标是分类 → 正是 LDA 的设计目的 · 10 类 → LDA 最多降到 \(10-1=9\) 维，压到 \(9\) 维以内没有问题 · 注意：若想压到 2 维，LDA 仍然可以， 但它给出的是"最能分开 10 类的前 2 个方向"， 未必是"方差最大的 2 个方向" —— 这正是我们要的

    丙：都不合适，或者只能用 PCA / 直接不降维。

    · LDA 需要估计类内散度 \(S_w\)， 而 \(S_w\) 要按类累加 \((x-m_c)(x-m_c)^{\mathsf T}\)。 每类只有一个样本时 \(S_w = 0\)， \(S_w^{-1}\) 根本不存在，算法直接崩掉 · 此时只能退到 PCA，或者先做特征选择减少维数， 等样本够了再上 LDA。

    答案：甲用 PCA，乙用 LDA，丙不能用 LDA（类内散度奇异）。

    选方法的第一步是清点"标签够不够"

    三者对照如下：

    场景 有标签 类内样本足够 合适方法
    甲 否 —— PCA（或流形学习）✓
    乙 是 是 LDA ✓
    丙 是但不充分 否 PCA，或先做特征选择

    例题 4：核宽度选得太小会怎样¶

    题目：对一组二维数据做核 PCA，径向基核参数取 \(\gamma = 500\)（数据尺度约 \(1\)）。 观察到的现象是：核矩阵几乎变成单位矩阵。 解释为什么会这样，以及它对降维意味着什么。

    思路

    写出径向基核的表达式，看 \(\gamma\) 很大时指数项的行为， 再判断"核矩阵近似单位矩阵"对特征值分布的影响。

    解答

    第一步：写出核函数。

    \[ K(\boldsymbol{x}_i,\boldsymbol{x}_j) = \exp\!\left(-\gamma\left\|\boldsymbol{x}_i-\boldsymbol{x}_j\right\|^2\right) \]

    第二步：分析 \(\gamma\) 很大的情形。

    若两点的距离 \(\|\boldsymbol{x}_i-\boldsymbol{x}_j\|\) 是 \(O(1)\) 量级， 则指数上是 \(-\gamma \cdot O(1) = -O(\gamma)\)。

    取 \(\gamma = 500\)、两点距离 \(0.5\)，指数为 \(-125\)：

    \[ e^{-125} \approx 10^{-54} \]

    这在双精度浮点里就是 \(0\)

    于是：

    情形 核值 结论
    \(i = j\) \(K_{ii} = 1\) 对角线全是 \(1\)
    \(i \ne j\) 且距离不太小 约 \(0\) 非对角元几乎为 \(0\)

    核矩阵退化成单位矩阵。

    第三步：对降维的后果。

    单位矩阵的任何方向都是特征向量、特征值全相等。 于是：

    · 没有"最重要的主成分" —— 所有方向一样重要， 特征值谱完全平坦 · 求出的"第一主成分"是纯噪声 —— 它由浮点误差决定，换一组数据就完全不同 · 外样本投影也没有意义 —— 新样本与所有训练样本的核值都近似 \(0\)， 投影结果接近常数。

    答案：\(\gamma\) 太大让核矩阵退化成单位矩阵， "核 PCA"退化成了"随机挑一个方向"

    核宽度必须与数据本身的尺度匹配 ⚠

    \(\gamma\) 取值 核矩阵形态 结果
    太小 所有元素都接近 \(1\)（近似秩 1） 退化成只保留均值方向
    合适 谱有明显衰减 ✓ 前几个主成分抓住结构
    太大 近似单位矩阵 退化成随机方向

    所以实践中的做法：把 \(\gamma\) 当成超参数， 用中位数启发式（取 \(\gamma \approx 1/\text{距离中位数}^2\)）定一个起点， 再用交叉验证调

    九、小结¶

    要点 结论 需要注意的地方
    维数灾难 同样密度所需样本量按 \(n^d\) 增长 体积集中到角落、距离退化 ⚠
    距离退化 高维里最近与最远距离之比趋近 1 所有依赖距离的方法都失效 ⚠
    PCA 推导一 最大化投影方差：\(C\boldsymbol{w}=\lambda\boldsymbol{w}\) 必须加单位长度约束 ✓
    PCA 推导二 最小化重构误差：\(\min \operatorname{tr}\) 的对面 与推导一给出同一组方向 ✓
    等价性 \(J(W) = \sum_i\|\boldsymbol{x}_i\|^2 - n\sum_{j\le k}\lambda_j\) 保留能量 = 1 − 相对重构误差 ✓
    主成分个数 累积贡献率 / Kaiser / 碎石图 / 交叉验证 前三个都是启发式规则 ⚠
    LDA 最大化 \(\dfrac{\boldsymbol{w}^{\mathsf T}S_b\boldsymbol{w}}{\boldsymbol{w}^{\mathsf T}S_w\boldsymbol{w}}\) 需要标签，最多降到 \(C-1\) 维 ⚠
    PCA 与 LDA 前者不看标签、后者必须看 判别方向可以几乎正交 ⚠
    流形学习 Isomap 用图上最短路当测地距离 邻域图断裂会直接失效 ⚠
    核 PCA 在高维空间做 PCA，只用核值 核宽度必须匹配数据尺度 ⚠

    三条最该带走的结论：

    1. 降维不是"为了快"，而是"为了还有样本可用" —— 维数灾难的代价是指数级的，降维是在主动丢掉无关变化， 换取统计上的可估计性
    2. PCA 与 LDA 的差别不在算法细节，而在于"看不看标签" —— 这是本页最重要的分界线，它决定了两者在什么场合各自适用。
    3. 线性不行就上非线性，但要先判断数据是不是真的"弯曲" —— 如果数据的低维结构本身就是平的，流形学习与核 PCA 只会额外引入邻域图或核宽度的调参麻烦

    上一页：支持向量机与核方法 —— 对偶问题里只有内积，于是核技巧把线性方法整体搬进了高维空间； 本页则正面处理了"高维为什么危险"以及如何把维数压下来。

    下一页：特征选择 —— 换一条完全不同的路：不做变换，直接从原来的特征里挑出子集。 它的好处是新特征仍然保持原来的物理含义， 代价是能压缩的程度远不如上面这些变换方法。
