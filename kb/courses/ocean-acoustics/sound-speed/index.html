    海水的声学特性¶

    声呐方程里的 \(\text{TL}\) 有两个参数 —— 声速 \(c\) 与 吸收系数 \(\alpha\)。 这一页就把它们讲清楚：海水本身怎样决定声波走多快、损失多少。

    先说清这一页要解决的问题：

    声波在海水里传播，哪些海水性质会影响它？影响有多大？

    一、声速：决定声线走向¶

    1.1 为什么声速这么重要¶

    声速本身不直接出现在声呐方程里（TL 用的是几何扩展 + 吸收）， 但它决定了声线往哪弯 —— 而声线弯不弯，直接决定 「能量是聚在某处还是散开」，从而改变实际的传播损失。 一句话：声速剖面是声场结构的总导演。

    1.2 三个影响因素¶

    海水中声速取决于温度 \(T\)、盐度 \(S\)、静压力（深度 \(z\)） 三个量：

    因素 典型变化范围 对声速的影响 相对重要性
    温度 0–30 ℃ 约 +4.5 m/s 每 ℃ 最大
    盐度 30–38‰ 约 +1.3 m/s 每 ‰ 中等
    深度 0–10 km 约 +0.017 m/s 每 m 深层才显著

    关键结论：温度是主导因素（表层尤其如此）✓

    淡水与海水、空气与海水的声速差别都很大

    介质 声速（m/s）
    空气（20 ℃） 343
    淡水（20 ℃） 1482
    海水（20 ℃，35‰） 1521

    海水比空气快 约 4.4 倍，有两个直接后果： ① 同样的距离，声波在海水里走得快得多（时延小）； ② 波长也长 4.4 倍 —— 这直接影响换能器设计与分辨率。

    def alpha_thorp(f_khz):
    """Thorp 吸收系数（dB/km）。"""
    f2 = f_khz ** 2
    return (0.11 * f2 / (1.0 + f2)
            + 44.0 * f2 / (4100.0 + f2)
            + 2.75e-4 * f2
            + 0.003)


import math

r = 100.0                      # km
spread = 20.0 * math.log10(r * 1000.0)

print("频率(kHz)".ljust(10) + "alpha".ljust(10) + "吸收损失".ljust(12)
      + "扩展损失".ljust(12) + "谁更大")
for f in [0.5, 1.0, 2.0, 5.0, 10.0]:
    a = alpha_thorp(f)
    ab = a * r
    who = "吸收" if ab > spread else "扩展"
    print(("%.1f" % f).ljust(10) + ("%.3f" % a).ljust(10)
          + ("%.1f" % ab).ljust(12) + ("%.1f" % spread).ljust(12) + who)

    频率(kHz)   alpha     吸收损失        扩展损失        谁更大
0.5       0.028     2.8         100.0       扩展
1.0       0.069     6.9         100.0       扩展
2.0       0.135     13.5        100.0       扩展
5.0       0.382     38.2        100.0       扩展
10.0      1.187     118.7       100.0       吸收

    从数上看出的分界线：100 km 时，扩展损失固定为 100 dB， 而约 5 kHz 处吸收开始超过扩展 —— 这就是「远距离必须用低频」的定量依据。

    \[ \begin{aligned} c(T,S,z) = & \ 1448.96 + 4.591T - 5.304\times10^{-2}T^2 + 2.374\times10^{-4}T^3 \\ & + 1.340(S-35) + 1.630\times10^{-2}z + 1.675\times10^{-7}z^2 \\ & - 1.025\times10^{-2}T(S-35) - 7.139\times10^{-13}Tz^3 \end{aligned} \]

    不必背，但要看出哪些是主项、哪些是修正项：

    项 含义
    \(4.591T\) 温度主项（最大）
    \(-5.304\times10^{-2}T^2\) 温度的二阶修正（高温时增速放缓）
    \(1.340(S-35)\) 盐度项（以 35‰ 为基准）
    \(1.630\times10^{-2}z\) 压力主项
    \(-1.025\times10^{-2}T(S-35)\) 温度-盐度耦合（不可忽略）

    经验公式的「基准值」要看清

    \(1448.96\) m/s 对应的是 \(T=0\)、\(S=35\)、\(z=0\) 的情形； 盐度项写成 \((S-35)\) 说明基准盐度是 35‰。 用公式时把基准搞错，会整体偏出几 m/s。

    1.4 典型声速剖面¶

    实际海洋的声速剖面分层明显：

    1
2
3
4
    深度        层名              温度          声速
0 – 100 m   表面等温层        近恒温        近恒定（受季节影响）
100 – 1000 m 主跃层           骤降 20+ ℃    骤降（约 −0.05 /m）
> 1000 m    深海等温层        近恒温 1-2 ℃  缓慢上升（压力主导）

    为什么会形成「极小值」：

    • 上层：温度主导 → 越深越冷 → 声速↓
    • 下层：温度稳定，压力主导 → 越深压力越大 → 声速↑
    • 两者交界处声速最小 → 这就是深海声道轴

    这个极小值的意义极大：声线会被折射回轴附近， 能量被困在声道内，可以传播上千公里（见 深海声道）。

    def sound_speed(T, S, z=0.0):
    """Mackenzie 九项式声速公式（m/s）。
    T: 温度(℃)  S: 盐度(‰)  z: 深度(m)"""
    return (1448.96 + 4.591 * T - 5.304e-2 * T ** 2 + 2.374e-4 * T ** 3
            + 1.340 * (S - 35) + 1.630e-2 * z + 1.675e-7 * z ** 2
            - 1.025e-2 * T * (S - 35) - 7.139e-13 * T * z ** 3)


print("基准点 T=0, S=35, z=0 :", round(sound_speed(0, 35, 0), 3), "m/s")
print()
print("温度的影响（S=35, z=0）：")
for T in [0, 5, 10, 15, 20, 25, 30]:
    print("T = %2d C -> %8.3f m/s" % (T, sound_speed(T, 35, 0)))
print()
print("盐度的影响（T=15, z=0）：")
for S in [30, 32, 34, 35, 36, 38]:
    print("S = %2d   -> %8.3f m/s" % (S, sound_speed(15, S, 0)))
print()
print("深度的影响（T=15, S=35）：")
for z in [0, 100, 500, 1000, 2000, 5000]:
    print("z = %5d m -> %8.3f m/s" % (z, sound_speed(15, 35, z)))

    二、声吸收：决定能走多远¶

    2.1 三种吸收机制¶

    海水对声能的吸收来自三种弛豫过程：

    机制 主导频段 物理原因
    硼酸弛豫 0.1–1 kHz 硼酸分子解离平衡的弛豫
    硫酸镁弛豫 1–100 kHz \(\text{MgSO}_4\) 离子对的弛豫
    纯水粘滞 > 100 kHz 水分子的剪切与体积粘滞

    弛豫指声波压缩海水时，化学平衡需要时间才能跟上； 若声波周期与这个「跟上所需时间」相当，能量就被吸收掉。

    这解释了一个反直觉现象：吸收并不是「频率越高线性增大」， 而是在每个弛豫频率附近增长最快 —— 这就是为什么吸收曲线的 斜率会分段变化。

    2.2 Thorp 经验公式¶

    \[ \alpha(f) \approx \frac{0.11f^2}{1+f^2} + \frac{44f^2}{4100+f^2} + 2.75\times10^{-4}f^2 + 0.003 \quad (\text{dB/km}) \]

    （\(f\) 单位 kHz）

    逐项对应：

    项 弛豫频率 对应机制
    \(\dfrac{0.11f^2}{1+f^2}\) 1 kHz 硼酸
    \(\dfrac{44f^2}{4100+f^2}\) 约 64 kHz 硫酸镁
    \(2.75\times10^{-4}f^2\) — 纯水粘滞（无弛豫，正比 \(f^2\)）
    \(0.003\) — 常数项（低频残余）

    每个弛豫项的极限行为（这是读懂公式的钥匙）：

    \[ f \ll f_r:\ \frac{Af^2}{f_r^2+f^2}\approx\frac{A}{f_r^2}f^2 \quad(\text{正比 } f^2) \]
    \[ f \gg f_r:\ \frac{Af^2}{f_r^2+f^2}\approx A \quad(\text{趋于常数}) \]

    → 低频按 \(f^2\) 增长，过了弛豫频率就「饱和」。

    2.3 数量级感受¶

    频率 \(\alpha\)（dB/km） 100 km 的损失
    0.5 kHz 0.03 3 dB
    1 kHz 0.07 7 dB
    5 kHz 0.38 38 dB
    10 kHz 1.19 119 dB
    50 kHz 17.5 1750 dB（不可用）

    吸收损失在远距离时会「反超」扩展损失

    以 10 kHz、100 km 为例：

    • 扩展损失：\(20\lg(10^5) = 100\) dB
    • 吸收损失：\(1.19\times100 = 119\) dB ← 更大

    距离越远，吸收越占主导（因为它正比 \(r\)，而扩展只按 \(\lg r\)）。 这就是为什么远距离水声通信只能用低频。

    三、海底与海面的声学特性¶

    3.1 海底：反射还是透射¶

    海底对声波的作用取决于底质：

    底质 声速（m/s） 相对海水 反射强度
    泥沙 1450–1550 接近 弱（声波易透入）
    砂 1650–1750 偏高 中等
    岩石 2500–6000 高得多 强

    判据：海底声速 \(c_b\) 与海水声速 \(c_w\) 之比决定反射系数：

    \[ R = \frac{c_b\rho_b - c_w\rho_w}{c_b\rho_b + c_w\rho_w} \]

    「泥底难反射、岩底易反射」 —— 这与直觉一致（硬的东西反射强）

    海底不是「一面镜子」——粗糙度与分层都要考虑

    真实海底有起伏、有分层，所以：

    • 低频（波长远大于起伏）→ 看起来像光滑面，相干反射
    • 高频（波长与起伏可比）→ 散射为主，反射变成漫反射

    频率不同，同一个海底的表现完全不同。 这就是为什么海底反射损失 \(\text{BL}\) 必须说明频率。

    3.2 海面¶

    海面是近乎完美的反射面（空气与海水的特性阻抗差极大）：

    \[ R_{\text{surface}} \approx -1 \quad(\text{幅度几乎全反射，相位反转}) \]

    所以海面反射系数接近 1（能量上讲）—— 这也是表面声道能形成的原因（海面 + 负梯度共同把能量困住）。

    但海面是动的：

    海况 有效起伏 后果
    平静 小 近似镜面反射
    有浪 大 漫反射 + 多普勒展宽（因表面运动）

    多普勒展宽这条值得记住：它会让回波的频谱变宽， 从而影响检测性能（尤其对低速目标）。

    3.3 海洋内部的不均匀性¶

    海水内部并不均匀，有几类内波与湍流结构：

    类型 尺度 对声波的影响
    内波 10–1000 m 声线随机起伏 → 声传播起伏
    细结构 1–10 m 小角度散射
    气泡（近海面） mm–cm 强散射、强吸收

    这些是「声传播起伏」的物理根源（见 声传播起伏）。

    四、把三条特性接回声呐方程¶

    回到声呐方程里的两项：

    特性 进入哪一项 影响方式
    声速剖面 间接影响 TL 决定声线弯曲 → 扩展方式（球面/柱面）
    吸收系数 直接影响 TL 加上 \(\alpha r\) 这一项
    海底/海面 影响 BL、混响 反射损失与混响来源

    关键认识：声速剖面决定「几何」、吸收决定「损耗」。 前者可以把球面扩展变成更有利的柱面扩展（相当于「白赚」）， 后者是纯粹的成本。

    本页最该带走的三条

    1. 声速看温度（+4.5 m/s 每 ℃），盐度与压力影响小得多
    2. 声速极小值形成声道 —— 能量被困住，传播极远
    3. 吸收按 \(f^2\) 增长（过弛豫频率后饱和）→ 远距离只能用低频，这是硬约束

    五、例题¶

    例题 1：算一个典型表层的声速¶

    题目：某海域表层 \(T = 22\ ℃\)、\(S = 34‰\)、\(z = 50\) m。 求声速，并与基准点（\(T=0\)、\(S=35\)、\(z=0\)）比较。

    思路

    直接代入 Mackenzie 九项式，逐项算完再相加。

    解答

    第一步：逐项算。 \(T = 22\)：

    • \(4.591\times22 = 100.99\)
    • \(-5.304\times10^{-2}\times22^2 = -25.67\)
    • \(2.374\times10^{-4}\times22^3 = +2.53\)

    盐度项（\(S-35 = -1\)）：

    • \(1.340\times(-1) = -1.34\)

    深度项（\(z = 50\)）：

    • \(1.630\times10^{-2}\times50 = +0.815\)
    • \(1.675\times10^{-7}\times50^2 \approx +0.0004\)

    耦合项：

    • \(-1.025\times10^{-2}\times22\times(-1) = +0.226\)
    • \(-7.139\times10^{-13}\times22\times50^3 \approx -0.000002\)

    第二步：相加。

    \[ c = 1448.96 + 100.99 - 25.67 + 2.53 - 1.34 + 0.815 + 0.226 \approx 1526.5\ \text{m/s} \]

    结果比基准点（1448.96）高了约 78 m/s， 主要来自温度（\(100.99 - 25.67 + 2.53 = 77.85\)）； 盐度那一项只贡献了 \(-1.34\)。

    例题 2：判断该用哪个频率¶

    题目：要求作用距离 30 km，容许吸收损失不超过 10 dB。 选多高的频率合适？

    思路

    吸收损失 = \(\alpha(f)\times r\)，令它 \(\le 10\) dB 反解 \(\alpha\)， 再查表找对应频率。

    解答

    第一步：反解 \(\alpha\)。

    \[ \alpha\times30\le10 \implies \alpha\le0.333\ \text{dB/km} \]

    第二步：查 \(\alpha\) 表。

    频率 \(\alpha\) 是否可用
    1 kHz 0.069 ✓ 余量很大
    5 kHz 0.382 ✗ 略超
    3 kHz 约 0.20 ✓

    答案：不能超过约 4 kHz —— 30 km 的距离把可用频率压到几 kHz， 想用 10 kHz（\(\alpha = 1.19\)）就得接受 36 dB 的吸收损失。

    例题 3：为什么声速极小值能「困住」声波¶

    题目：定性解释为什么深海声道轴附近的声线会来回摆动而不是一直往下走。

    思路

    从 Snell 定律出发：声线总是向声速小的方向弯曲。 考虑一根从轴向上走的声线。

    解答

    第一步：从轴向上走的情形。

    声道轴上声速最小，往上走声速变大。 由 Snell 定律，声线向声速小的方向弯曲 —— 即向下弯。

    第二步：从轴向下走的情形。

    往下声速也变大（压力主导），所以声线同样向声速小的方向 （即向上）弯曲。

    第三步：合起来。

    两种情况都指向「回到轴」，所以声线被振荡地束缚在轴附近， 呈现正弦状的轨迹。

    这与光纤的折射率分布完全类似 —— 中间折射率大、两侧小，光就被限制在纤芯里。 深海声道就是天然的声学波导，这正是它能传播上千公里的原因。

    例题 4：海底反射的判据¶

    题目：某海域海水 \(c_w = 1500\) m/s、\(\rho_w = 1.02\ \text{g/cm}^3\)， 海底为砂，\(c_b = 1700\) m/s、\(\rho_b = 1.9\ \text{g/cm}^3\)。 求正入射时的反射系数。

    思路

    直接用阻抗比公式，注意每一项都是 \(\rho c\) 的乘积。

    解答

    第一步：算两侧阻抗。

    \[ Z_w = \rho_w c_w = 1.02\times1500 = 1530 \]
    \[ Z_b = \rho_b c_b = 1.9\times1700 = 3230 \]

    第二步：算反射系数。

    \[ R = \frac{Z_b - Z_w}{Z_b + Z_w} = \frac{3230 - 1530}{3230 + 1530} = \frac{1700}{4760} \approx 0.357 \]

    第三步：折成分贝。

    \[ 20\lg R = 20\lg 0.357 \approx -8.9\ \text{dB} \]

    砂底的反射损失约 9 dB（能量上损失一部分）， 比岩石底（\(R\) 更大）弱，比泥底强。

    小结¶

    特性 主导量 定量关系 对声呐方程的影响
    声速 温度 \(+4.5\) m/s 每 ℃ 决定声线弯曲 → 改变 TL 的扩展方式
    声吸收 硫酸镁弛豫 按 \(f^2\) 增长 直接加 \(\alpha r\) 到 TL
    海底 底质声速 阻抗比定反射 影响 BL 与海底混响
    海面 近全反射 \(R\approx1\) 影响干涉与多普勒展宽
    内部不均匀 内波湍流 随机散射 造成声传播起伏

    三条最该带走的结论：

    1. 声速由温度主导（+4.5 m/s 每 ℃），盐度与压力次之
    2. 声速极小值 = 深海声道轴，声线被束缚其中，能传上千公里
    3. 吸收按 \(f^2\) 增长 → 远距离只能用低频，这是硬约束 ⚠
