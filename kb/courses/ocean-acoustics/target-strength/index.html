    目标的声反射与散射¶

    声呐方程里的 \(\text{TS}\) 是最不直观的一项。它把「目标反射多少能量 回来」压缩成一个数：

    \[ \text{TS} = 10\lg\frac{I_{\text{scat}}(1\,\text{m})}{I_{\text{inc}}} \]

    即：距目标等效声中心 1 m 处的散射声强，与入射声强之比（分贝）。

    这一页讲三件事：

    1. 为什么可以把复杂目标当成「一个等效点」（TS 的合法性）
    2. TS 由什么决定（尺寸、形状、姿态、频率）
    3. 同一个目标换个角度能差多少

    一、为什么可以用一个数概括复杂目标¶

    1.1 「等效点」的合法性¶

    真实目标（如潜艇）形状极其复杂。但远场观测时：

    • 目标的最大尺寸 \(L \ll\) 距离 \(r\)
    • 观察到的是总散射能量，而非细节

    所以可以把目标换成「一个点源」，只要求它在接收方向上 产生同样的散射声强。

    这个点的位置叫「等效声中心」 —— 注意它不一定在几何中心， 取决于散射机理（见 1.3）。

    1.2 定义里的「1 m」是什么¶

    \[ \text{TS} = 10\lg\frac{I_{\text{scat}}(1\,\text{m})}{I_{\text{inc}}} \]

    「距目标 1 m」是把散射声强折算到 1 m 处的值 —— 这是规范化的约定，与声源级的「1 m」完全类似。

    这样做的意义：使 TS 与观测距离无关 —— 否则同一个目标， 离得远的观测者算出的 TS 会不同，那就没意义了。

    1.3 三种散射机理¶

    机理 部位 对 TS 的贡献
    镜面反射 正横的大平面（壳体） 最强
    棱角反射 舰桥、围壳、尾舵转角 次强，各方向都有
    弹性散射 内部结构、共振 特定频率上很强

    正横方向 TS 最大：壳体像一块大平板， 镜面反射把能量集中送回。

    尾向 TS 也较大：螺旋桨与尾舵形成角反射器， 在较大角度范围内都有较强反射。

    正首方向最小：声波沿曲面掠过，几乎没有镜面反射， 只剩棱角与弹性散射。

    二、TS 与尺寸、频率的关系¶

    2.1 三个区域¶

    按目标尺寸 \(L\) 与波长 \(\lambda\) 之比，分三个区：

    区 条件 TS 的特征 典型情形
    瑞利区 \(L \ll \lambda\) TS 随 \(f^4\) 增长 小鱼、气泡
    共振区 \(L \approx \lambda\) 出现峰谷振荡 中鱼、结构共振
    几何区 \(L \gg \lambda\) TS 趋于常数 大型目标、高频

    关键认识：不同区域 TS 对频率的依赖完全不同， 所以「某目标 TS = 20 dB」这个数字必须说明频率。

    把「TS 随频率」算成数：同一目标在两个频段的表现。

    import numpy as np


def ts_rayleigh(L, f, c=1500.0):
    """瑞利区（L 远小于波长）：TS 正比于 (L/lambda)^4。"""
    lam = c / f
    return 10.0 * np.log10(np.maximum((L / lam) ** 4, 1e-15) * 0.01)


def ts_geometric(L, f, c=1500.0):
    """几何区（L 远大于波长）：TS = 10lg(A/lambda^2)。"""
    lam = c / f
    A = 0.1 * L * L
    return 10.0 * np.log10(A / lam ** 2)


print("频率(kHz)".ljust(12) + "瑞利区 L=0.1m".ljust(18) + "几何区 L=50m")
for f in [1000, 5000, 10000, 50000]:
    a = ts_rayleigh(0.1, f)
    b = ts_geometric(50, f)
    print(("%.0f" % (f / 1000)).ljust(12) + ("%.1f" % a).ljust(18)
          + "%.1f" % b)

print()
print("每倍频程的增幅：瑞利区 +12 dB，几何区 +6 dB")

每倍频程的增幅：瑞利区 +12 dB，几何区 +6 dB

    小目标（瑞利区）的 TS 增长比大目标快一倍。 所以「提高频率发现小鱼」的效果，远好于「发现大目标」—— 但吸收代价对两者是一样的。

    2.2 几何区的近似式¶

    当目标远大于波长时（几何声学适用），可用投影面积估算：

    \[ \text{TS} \approx 10\lg\frac{A_{\text{proj}}}{\lambda^2} + \text{修正项} \]

    量纲检查：\(A/\lambda^2\) 是无量纲的面积比。 由此得到的频率依赖是：

    \[ \text{TS} \propto -10\lg\lambda^2 = +20\lg f + \text{const} \]

    即频率加倍，TS 增约 6 dB（几何区）。

    用具体数字感受：若某目标在 5 kHz 时 TS = 15 dB， 则 10 kHz 时约 21 dB（几何区）。

    「提高频率让目标更容易被发现」是有代价的

    由 2.2，高频率确实让 TS 变大（+6 dB/倍频程）。

    但由 海水的声学特性，吸收也按 \(f^2\) 增长。

    两者对比（频率从 5 kHz 增到 10 kHz，距离 10 km）：

    项 变化
    TS 增益 \(+6\) dB
    单程吸收增加 \(+8\) dB
    主动声呐合计（双向 TL） \(-16\) dB

    提高频率在远距离上通常得不偿失：净损失约 10 dB。

    import numpy as np


def ts_rayleigh(L, f, c=1500.0):
    """瑞利区（L << lambda）的目标强度近似：TS ∝ (L/lambda)^4。

    这里给出一个**归一化**的示意式，用于比较频率趋势。
    """
    lam = c / f
    x = L / lam
    return 10.0 * np.log10(np.maximum(x ** 4, 1e-12) * 0.01)


def ts_geometric(L, f, c=1500.0):
    """几何区（L >> lambda）：TS = 10lg(A/lambda^2)。"""
    lam = c / f
    A = L * L * 0.1          # 假设投影面积是 L^2 的 10%
    return 10.0 * np.log10(A / lam ** 2)


print("瑞利区（小鱼 L=0.1 m）—— TS 随频率急剧上升：")
for f in [100, 500, 1000, 5000]:
    print("  f = %6d Hz -> TS = %7.1f dB" % (f, ts_rayleigh(0.1, f)))

print()
print("几何区（大目标 L=50 m）—— TS 随频率缓慢上升：")
for f in [1000, 5000, 10000, 50000]:
    print("  f = %6d Hz -> TS = %7.1f dB" % (f, ts_geometric(50, f)))

  f =    100 Hz -> TS =  -107.0 dB
  f =    500 Hz -> TS =   -79.1 dB
  f =   1000 Hz -> TS =   -67.0 dB
  f =   5000 Hz -> TS =   -39.1 dB

几何区（大目标 L=50 m）—— TS 随频率缓慢上升：
  f =   1000 Hz -> TS =    20.5 dB
  f =   5000 Hz -> TS =    34.4 dB
  f =  10000 Hz -> TS =    40.5 dB
  f =  50000 Hz -> TS =    54.4 dB

    瑞利区 TS 增长极快（\(f^4\)，即每倍频 +12 dB）， 几何区只按 \(f^2\)（每倍频 +6 dB）—— 所以小目标的 TS 对频率极其敏感。

    三、姿态的影响（最重要的一节）¶

    3.1 为什么姿态影响这么大¶

    原因：不同方向的有效反射面积完全不同。

    观察方向 主要反射机理 相对 TS
    正横（90°） 壳体镜面反射 最大
    斜前方（30–60°） 部分镜面 + 棱角 中等
    正首（0°） 仅棱角与弹性散射 最小
    正尾（180°） 螺旋桨/尾舵角反射 中等偏大

    同一目标正横与正首的 TS 可差 20–30 dB

    这相当于什么：20 dB = 信号能量差 100 倍 —— 在四次方关系下，作用距离差 约 1.8 倍！

    3.2 为什么会出现「闪烁」¶

    目标姿态随海况变化 → TS 随姿态抖动 → 回波强度剧烈起伏。

    实测特征：

    现象 成因
    快速起伏（秒级） 海面波浪使姿态变化
    慢速起伏（分钟级） 目标转向、航向变化
    深度起伏 目标机动

    工程后果：单次检测不可靠，必须把多次观测积累当作必需手段 （这正是「检测阈」与「积分时间」要一起考虑的原因）。

    一个实用的经验：按「最不利姿态」做设计

    设计探测系统时，不能按正横的最大 TS 算 —— 那会严重高估性能。

    工程上通常按中等姿态的 TS 或统计平均 TS 来估算， 并对最坏情况留余量。

    import numpy as np


def ts_vs_aspect(angle_deg, ts_broadside=20.0, ts_bow=-5.0):
    """简化的 TS-姿态模型：正横最大、正首最小，用 cos 形状插值。

    angle_deg: 0 = 正首，90 = 正横，180 = 正尾
    """
    # 用 |cos(angle)|^2 作为镜面反射的权重（正横=0 -> 权重 1）
    w = np.cos(np.radians(angle_deg)) ** 2
    return ts_bow + (ts_broadside - ts_bow) * w


print("姿态角(度)".ljust(12) + "TS(dB)")
for a in [0, 15, 30, 45, 60, 75, 90]:
    print(("%d" % a).ljust(12) + "%7.1f" % ts_vs_aspect(a))

print()
print("正横与正首的差：%.1f dB" % (ts_vs_aspect(90) - ts_vs_aspect(0)))
print("在四次方关系下，作用距离相差 %.2f 倍"
      % (10 ** ((ts_vs_aspect(90) - ts_vs_aspect(0)) / 40.0)))

    四、典型目标的 TS 量级¶

    目标 TS（dB） 说明
    大型水面舰 25–40 正横最大
    潜艇（正横） 15–25 随频率与涂层变化
    潜艇（正首） −5 ~ +10 明显更小
    鱼群 −30 ~ −10 整体；单鱼约 −40
    单个气泡 −60 ~ −80 弱散射体（但数量多）

    吸声涂层能显著降低 TS

    现代潜艇表面敷设吸声涂层（消声瓦）， 可把 TS 降低 10–15 dB。

    后果：这直接抵消了「提高频率增大 TS」的策略 —— 涂层对高频（\(\lambda\) 与涂层厚度可比时）吸收最好。

    这也是「反潜必须用低频」的又一个原因。

    五、例题¶

    例题 1：频率变化对系统性能的净影响¶

    题目：某系统从 5 kHz 改到 10 kHz（几何区，目标 \(L\gg\lambda\)）。 目标 TS 增 6 dB，但吸收从 0.38 增到 1.19 dB/km。 若作用距离 10 km，净收益如何？

    思路

    算三部分：TS 增益、单程吸收增加、双向吸收增加。 净变化 = TS 增益 − 双向吸收增加。

    解答

    第一步：TS 增益。

    \[ \Delta\text{TS} = +6\ \text{dB} \]

    第二步：吸收增加（单程，10 km）。

    \[ \Delta\alpha\times r = (1.19 - 0.38)\times10 = 8.1\ \text{dB} \]

    第三步：双向。

    \[ 2\times8.1 = 16.2\ \text{dB} \]

    第四步：净变化。

    \[ \Delta = 6 - 16.2 = -10.2\ \text{dB} \]

    答案：净损失约 10 dB，作用距离反而下降 —— 原因是「提高频率增大 TS」这条思路只算了一侧， 而吸收在往返路径上被计入两次。

    例题 2：姿态对作用距离的影响¶

    题目：某目标正横 TS = 20 dB、正首 TS = −5 dB。 若其它参数不变，从正横转向正首，作用距离变化多少？

    思路

    用四次方关系（主动声呐）。

    解答

    第一步：TS 变化。

    \[ \Delta\text{TS} = -5 - 20 = -25\ \text{dB} \]

    第二步：距离变化。

    声呐方程里 TS 只出现一次，而 \(2\text{TL}\) 含 \(40\lg r\)：

    \[ 40\lg\frac{r'}{r} = -25 \implies \lg\frac{r'}{r} = -0.625 \]
    \[ \frac{r'}{r} = 10^{-0.625} \approx 0.24 \]

    答案：距离降到约 24% ⚠ —— 一个 25 dB 的 TS 差就让距离打两折， 这是「姿态信息不可忽略」的定量证据。

    例题 3：从投影面积估算 TS¶

    题目：某目标正横投影面积 \(A = 200\) m²， 工作频率 5 kHz（\(c = 1500\) m/s）。 用几何区近似式估算 TS。

    思路

    算 \(\lambda\)，再用 \(\text{TS} = 10\lg(A/\lambda^2)\)。

    解答

    第一步：算波长。

    \[ \lambda = \frac{1500}{5000} = 0.3\ \text{m} \]

    第二步：算面积比。

    \[ \frac{A}{\lambda^2} = \frac{200}{0.09} \approx 2222 \]

    第三步：转分贝。

    \[ \text{TS} \approx 10\lg 2222 \approx 33.5\ \text{dB} \]

    答案：约 33.5 dB —— 比实测的潜艇 TS（15–25 dB）偏高， 因为该近似式忽略了能量向各个方向散射（只有一部分返回接收方向）， 所以这个式子只能做量级估算，实际 TS 要用测量值。

    例题 4：吸声涂层的影响¶

    题目：某潜艇原 TS = 20 dB，敷设涂层后降 12 dB。 若原作用距离 20 km，新距离是多少？

    思路

    TS 降 12 dB → 用四次方关系。

    解答

    第一步：距离变化。

    \[ 40\lg\frac{r'}{r} = -12 \implies \lg\frac{r'}{r} = -0.3 \]
    \[ \frac{r'}{r} = 10^{-0.3} \approx 0.50 \]

    答案：距离降到约 10 km（减半） ✓ —— 涂层是一种「以 12 dB 换掉一半探测距离」的手段， 对潜艇而言这是极高的战术价值。

    六、自测¶

    Q1 说明 TS 定义里「1 m」的作用。如果去掉这个规范化， 同一个目标在不同距离上测出的 TS 会怎样？为什么这样不行？

    Q2 按 \(L/\lambda\) 分成三个区域，各自的 TS 与频率关系是什么？ 为什么说「某目标 TS = 20 dB」这句话不完整？

    Q3 目标从正横转到正首时，TS 为什么会大幅下降？ 请从反射机理解释，并用四次方关系粗估这个差别对作用距离的影响。

    Q4 某目标在 3 kHz 时 TS = 18 dB。若为几何区， 估算 6 kHz 时的 TS；再结合吸收（0.2 → 0.6 dB/km，距离 20 km）， 判断提高频率的净收益。

    小结¶

    概念 含义 典型值
    TS 定义 距目标 1 m 处散射强度与入射强度比 —
    等效声中心 折算用的虚拟点 不一定是几何中心
    瑞利区 \(L\ll\lambda\)，TS ∝ \(f^4\) 小鱼、气泡
    几何区 \(L\gg\lambda\)，TS ∝ \(f^2\) 大型目标
    姿态影响 正横最大、正首最小 差 20–30 dB ⚠
    吸声涂层 降低 TS −10~15 dB

    三条最该带走的结论：

    1. TS 必须带频率与姿态 —— 这两个条件缺一个数字就没意义 ⚠
    2. 正横与正首可差 20 dB 以上 → 作用距离差 2–4 倍
    3. 提高频率虽然能增大 TS，但吸收是双向计入的 → 远距离上往往净亏损
