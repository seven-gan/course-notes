    海洋环境噪声¶

    声呐方程里的 \(\text{NL}\) 就是这一页的主角。它决定了背景有多吵， 从而直接决定能听多远。

    这一页要解决的问题：

    海洋里的背景噪声有多大？它在不同频段分别由什么引起？

    一、为什么环境噪声这么关键¶

    在声呐方程里，\(\text{NL}\) 与 \(\text{SL}\) 是一对矛盾： 信号和噪声都进入同一个判决式。

    \[ \text{SL} - 2\text{TL} + \text{TS} \;\ge\; \underbrace{\text{NL} - \text{DI} + \text{DT}}_{\text{门槛}} \]

    关键认识：\(\text{DI}\) 只能压低噪声，不能提高信号。 所以当噪声主导时，唯一有效的办法是

    \[ \text{有效噪声} = \text{NL} - \text{DI} \quad\Longrightarrow\quad \text{把 DI 做大（加长基阵）} \]

    这就是为什么「加长基阵」比「加大功率」划算（见 声呐方程）—— 环境噪声是门槛而不是信号，降低它的唯一手段是指向性（空间过滤）。 所以要提升作用距离，先想「DI 能不能再大」，再想功率。

    二、谱级：噪声的「度量方式」¶

    2.1 为什么用谱级¶

    噪声是宽带的（从几 Hz 到几百 kHz 都有能量）。 直接说「噪声级 70 dB」没有意义 —— 必须说明在多宽的带宽内 ⚠

    谱级的定义：

    \[ \text{NL}_0 = 10\lg\frac{I}{I_{\text{ref}}\cdot 1\text{Hz}} \quad(\text{dB re }1\ \mu\text{Pa}^2/\text{Hz}) \]

    即：单位带宽（1 Hz）内的噪声级

    2.2 带宽换算¶

    接收机实际收到的噪声级（总级）：

    \[ \text{NL} = \text{NL}_0 + 10\lg B \]

    其中 \(B\) 是接收带宽（Hz）。

    举例：谱级 55 dB、带宽 100 Hz → 总级 \(= 55 + 20 = 75\) dB

    谱级与总级混用是常见错误

    实测常见错误：查表得到「风成噪声 50 dB」（谱级）， 直接把它当成 \(\text{NL}\) 代进声呐方程， 忘了加 \(10\lg B\)

    若 \(B = 1\) kHz，就漏掉了 30 dB —— 作用距离估算会差出约 20%（因为距离是四次方关系）。

    纪律：写噪声数据时必须标注「谱级」还是「总级」。

    2.3 带宽的取舍¶

    由 \(\text{NL} = \text{NL}_0 + 10\lg B\)：

    带宽 噪声级 对检测的影响
    窄 低 ✓ 但信号也会被削（若信号是宽带的）
    宽 高 ✗ 能容纳宽带信号

    这就是「匹配滤波」的动机：让带宽刚好匹配信号， 既拿到全部信号能量，又不过多引入噪声

    三、三个主要来源¶

    3.1 航运噪声（低频）¶

    来源：远洋商船的机械振动与螺旋桨空化。

    特征 说明
    频段 10–500 Hz
    谱级 60–80 dB（随航运密度变化）
    衰减 约 −6 dB/倍频程

    关键特征：深海与航线附近差异极大。 同一个海域，航运繁忙与安静时可以差 10 dB 以上

    3.2 风成噪声（中频）¶

    来源：海面波浪破碎产生的气泡。

    特征 说明
    频段 0.5–50 kHz
    谱级 40–60 dB
    与风速关系 风速加倍 → 约 +5~6 dB

    这条「风速关系」很实用：

    \[ \text{NL} \propto 20\lg v_{\text{wind}}\ (\text{近似}) \]

    为什么：风越大 → 浪越大 → 破碎气泡越多 → 噪声越强

    def range_ratio(delta_db):
    """噪声升高 delta_db 时，作用距离的相对变化（主动声呐，四次方关系）。"""
    return 10.0 ** (-delta_db / 40.0)

    工程上常把「海况」直接换算成噪声级

    蒲福风级 → 风速 → 噪声级，是一条常用经验链。 做声呐性能预报时，海况是最主要的不确定因素之一

    3.3 热噪声（高频）¶

    来源：海水分子热运动（与电阻的热噪声同源）。

    特征 说明
    频段 > 50 kHz
    谱级 随频率上升
    增长 约 +6 dB/倍频程

    为什么高频反而更吵：热噪声的功率谱密度在声学频段近似与频率无关 （类似白噪声），但换算成声压谱级时要乘上频率相关的因子， 表现为随频率上升

    与吸收的「巧合」：高频时噪声上升，同时吸收也急剧上升， 两者共同把高频「封死」 —— 这是水声只能用中低频的另一个原因

    Wenz 谱是「典型值」，不是「实测值」

    Wenz 谱画的是统计平均的典型谱。真实海域会偏离，原因包括：

    • 本地航运量（可能高 10 dB）
    • 降雨（雨噪声在高频可高 10–20 dB）
    • 生物噪声（虾群、鲸类，特定频段极强）

    做实际预报时，必须用实测或区域模型，不能直接套 Wenz 曲线 ⚠

    import numpy as np


def wenz_shipping(f):
    """航运噪声谱级（低频主导，随频率下降）。f 单位 Hz。"""
    return 60.0 - 20.0 * np.log10(np.maximum(f, 1.0) / 10.0) * 0.5


def wenz_wind(f):
    """风成噪声谱级（中频主导）。"""
    return 55.0 - 25.0 * np.log10(np.maximum(f, 1.0) / 50.0)


def wenz_thermal(f):
    """热噪声谱级（高频主导，随频率上升）。"""
    return 45.0 - 12.0 * np.log10(np.maximum(f, 1.0) / 1000.0)


print("频率(Hz)".ljust(10) + "航运".ljust(9) + "风成".ljust(9) + "热噪声".ljust(9)
      + "主导者")
for f in [10, 100, 1000, 10000, 100000]:
    s, w, t = wenz_shipping(f), wenz_wind(f), wenz_thermal(f)
    who = min([("航运", s), ("风成", w), ("热噪声", t)], key=lambda x: x[1])[0]
    print(("%d" % f).ljust(10) + ("%.1f" % s).ljust(9) + ("%.1f" % w).ljust(9)
          + ("%.1f" % t).ljust(9) + who)

    六、例题¶

    例题 1：估算接收处的总噪声级¶

    题目：某海域中频段谱级 50 dB re 1 μPa²/Hz。 接收机带宽 200 Hz，接收阵 DI = 18 dB。 求有效噪声级（进入声呐方程的那个数）。

    思路

    两步：先把谱级换成总级（加 \(10\lg B\)）， 再减去 DI（指向性对噪声的抑制）。

    解答

    第一步：谱级 → 总级。

    \[ \text{NL} = 50 + 10\lg 200 = 50 + 23.0 = 73.0\ \text{dB} \]

    第二步：减去 DI。

    \[ \text{NL}_{\text{eff}} = \text{NL} - \text{DI} = 73.0 - 18 = 55.0\ \text{dB} \]

    DI 把有效噪声压了 18 dB， 相当于把接收带宽等效地缩小了 60 倍 这就是指向性的价值。

    例题 2：风浪变大的影响¶

    题目：风速从 5 m/s 增到 10 m/s，风成噪声增加多少？ 若原来是 \(\text{NL}_{\text{eff}} = 55\) dB，新的值是多少？ 对作用距离的影响？

    思路

    风速加倍 → 噪声约 +6 dB。距离影响要用四次方关系反推。

    解答

    第一步：噪声增加。

    \[ \Delta\text{NL} \approx 20\lg\frac{10}{5} = 6.0\ \text{dB} \]

    第二步：新的有效噪声。

    \[ \text{NL}_{\text{eff}} = 55 + 6 = 61\ \text{dB} \]

    第三步：对距离的影响（忽略吸收）。 门槛提高 6 dB → 可承受的 \(2\text{TL}\) 少 6 dB：

    \[ 40\lg\frac{r'}{r} = -6 \implies \frac{r'}{r} = 10^{-0.15} \approx 0.71 \]

    答案：作用距离降到约 71%

    海况是作用距离的强敏感因素 —— 风速翻倍就让距离打七折。做性能预报必须考虑海况波动

    例题 3：为什么中频最「安静」¶

    题目：结合三个来源的频率趋势，解释为什么 Wenz 谱在中频出现极小值。

    思路

    看三个来源各自的斜率方向：航运降、风成缓降、 热噪声升。极小的位置就在「降的」与「升的」交汇处。

    解答

    第一步：三个趋势。

    来源 频率趋势
    航运 随 \(f\) 下降（约 −6 dB/倍频程）
    风成 随 \(f\) 缓慢下降（约 −5 dB/倍频程）
    热噪声 随 \(f\) 上升（约 +6 dB/倍频程）

    第二步：找极小。

    低频端由航运主导（值最高），高频端由热噪声主导。 一个下降的曲线与一个上升的曲线的交汇处，就是总噪声的最小处

    第三步：结论。

    极小值出现在风成噪声占主导的频段（约 2–20 kHz）。

    中频工作不是巧合，而是最优选择 —— 这是「设备能做到的频率」与「环境最安静」共同决定的平衡点

    例题 4：降雨的影响¶

    题目：某系统工作频率 50 kHz。降雨使该频段噪声升高 15 dB。 若其它参数不变，作用距离变化多少？

    思路

    噪声升 15 dB → 门槛升 15 dB → 用四次方关系。

    解答

    第一步：门槛变化。

    \[ \Delta(\text{门槛}) = +15\ \text{dB} \]

    第二步：距离变化。

    \[ 40\lg\frac{r'}{r} = -15 \implies \lg\frac{r'}{r} = -0.375 \implies \frac{r'}{r} = 10^{-0.375} \approx 0.42 \]

    答案：距离降到约 42%

    高频系统对降雨极其敏感。 这也是为什么高频声呐（如成像声呐）在雨天性能骤降 —— 它不只是「听得差一点」，而是距离腰斩

    小结¶

    来源 频段 谱级范围 频率趋势 与什么强相关
    航运 10–500 Hz 60–80 dB 下降 (−6 dB/oct) 航线密度
    风成 0.5–50 kHz 40–60 dB 缓降 (−5 dB/oct) 风速
    热噪声 > 50 kHz 随 \(f\) 上升 上升 (+6 dB/oct) 水温
    降雨 高频 +10~20 dB — 雨强
    生物 特定频段 可达 +20 dB — 季节、海域

    三条最该带走的结论：

    1. 总级 = 谱级 + \(10\lg B\) —— 忘了这一项会差几十 dB
    2. 噪声只能靠 DI 压，加长基阵比加功率有效
    3. 中频最安静（航运与热噪声的交汇）→ 声呐工作频段的必然选择
