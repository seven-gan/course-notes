    绪论¶

    这一页要回答三个问题：

    水声学为什么存在？它研究什么？这门课准备怎么讲？

    • 第一个问题是立论：水下为什么只能用声波；
    • 第二个问题是地盘：水声学有哪些分支，各管哪一段；
    • 第三个问题是路线：本课程后面十章分别落在哪里。

    先把本页与课程大纲的对应关系摆出来，后面的展开都按这张表走。

    大纲节 本页对应 一句话

    一、水声学是什么¶

    水声学研究声波在海洋中的产生、传播、散射与接收。 把这句话摊开，一套水声设备其实只做四件事：

    1. 发：用换能器把电信号变成水中的声波；
    2. 走：声波在海水里经历扩展、吸收、折射、反射与散射；
    3. 碰：碰到目标、海面、海底或水中的不均匀体，一部分能量被送回来；
    4. 收：把回来的声波变回电信号，再从中把「有没有、在哪里、是什么」判出来。

    四件事串成一条链，这条链的名字就是声呐。

    「声呐」这个词的来源：它是英文「声导航与测距」的缩写， 最早专指探测水下目标的装置，今天已经泛化成「任何用声波在水下取信息」的设备。

    「水声学」与「水声工程」是两个层面，不要混着用。

    层面 关心什么 典型产物
    水声学（物理层） 声场怎么形成、怎么传播、怎么被扰动 波动方程的解、传播损失模型
    水声工程（系统层） 怎么把声场用起来、算清设备的账 声呐方程、基阵设计、信号处理器

    两层不能分开：工程上写下的每一个分贝，都要在物理上找得到来处 ✓

    这门课的主语是「海洋」，不是「声呐」。 也就是说，本课程更关心海水对声波做了什么， 而不是某一型设备的电路细节 —— 后者属于设备设计课的内容。

    二、为什么用声波，而不用电磁波¶

    这是全页的立论基础，值得慢慢讲透。结论先给出来：

    海水对电磁波几乎是不透明的，对声波却是相对透明的。

    2.1 海水是导体，电磁波一进去就被吃掉¶

    海水含盐，是导电介质（电导率在几个西门子每米量级）。 电磁波进入导体后，场强按指数规律衰减，衰减的特征长度叫趋肤深度：

    \[ \delta = \sqrt{\frac{2}{\omega \mu \sigma}} \]

    其中 \(\omega = 2\pi f\) 是角频率、\(\mu\) 是磁导率、\(\sigma\) 是电导率。

    这条公式要读出两点：

    1. 频率越高，\(\delta\) 越小 —— 高频电磁波连表层都穿不过去；
    2. 电导率越大，\(\delta\) 越小 —— 淡水能传得远一些，海水不行。

    海水取 \(\sigma \approx 4\ \text{S/m}\)，把 10 kHz 代进去：

    \[ \delta \approx 2.5\ \text{m} \qquad \Longrightarrow \qquad \text{衰减} = \frac{8.686}{\delta} \approx 3.45\ \text{dB/m} \]

    换句话说：10 kHz 的电磁波在海水里每走 1 米就掉 3.45 dB， 走 1 km 要掉 3452 dB ⚠

    这个数字有多荒唐？水声里讨论的发射声源级上限不过 200 dB 上下 —— 电磁波走 1 km 掉的量，比发射机的全部能量还大十几个数量级。

    2.2 声波在海水里几乎是「免费」的¶

    同样一片海水，声波的花销小得多。1 kHz 的声波吸收系数只有 0.069 dB/km 量级；即便算上球面扩展（1 km 处 \(20\lg 1000 = 60\) dB）， 1 km 距离上的单程总损失也只有 60 dB 上下。

    import math


def skin_depth(f_hz, sigma=4.0):
    """良导体中的趋肤深度(m)：海水电导率取 sigma 约 4 S/m。"""
    mu = 4e-7 * math.pi
    return math.sqrt(2.0 / (2.0 * math.pi * f_hz * mu * sigma))


def em_loss_db_km(f_hz, sigma=4.0):
    """电磁波在海水中的单程衰减(dB/km)：场按 exp(-z/delta) 衰减。"""
    return 8.686 / skin_depth(f_hz, sigma) * 1000.0


def sound_loss_db_km(f_khz):
    """声波吸收的 Thorp 经验式(dB/km)。"""
    f = f_khz
    return (0.11 * f * f / (1.0 + f * f)
            + 44.0 * f * f / (4100.0 + f * f)
            + 2.75e-4 * f * f + 0.003)


print("频率(kHz)".ljust(12) + "电磁波(dB/km)".ljust(18)
      + "声波(dB/km)".ljust(14) + "相差倍数")
for f_khz in (1.0, 10.0, 100.0):
    e = em_loss_db_km(f_khz * 1000.0)
    s = sound_loss_db_km(f_khz)
    print("%-12.0f%-18.0f%-14.3f%.0f" % (f_khz, e, s, e / s))
print("趋肤深度 10 kHz: %.2f m" % skin_depth(10000.0))

    为什么声波能「免费」：声波是机械波，它的传播依靠水的 可压缩性与密度，而海水恰好是一个很好的弹性介质； 电磁波要在这片导电的盐水里维持场，能量不断被电流耗掉。 一个是走在自己家里，一个是每走一步都要交过路费 ✓

    2.3 三种载体在水下的分工¶

    现在可以把可选的手段排在一张表里，看清各自的生态位：

    载体 频率量级 衰减量级 可用距离 带宽
    电磁波（中高频） 10 kHz ~ 微波 每米几 dB 米级 大，但用不上
    电磁波（极低频） 几十 Hz 很小 上百 km 极小 ⚠
    光波 可见光 每米几百 dB（清澈水） 几十 m 很大
    声波 1 kHz 0.069 dB/km + 扩展损失 上千 km ✓ 小（kHz 量级）

    这张表要读出三件事：

    1. 光与微波只能做「近距离、高带宽」的活： 近距离通信、成像、测量、对接。距离一过百米就没有余地。
    2. 极低频电磁波确实能穿进海水，但波长几十公里，意味着 发射与接收结构要做成庞然大物，而且带宽极低， 一秒钟传不了几个比特 ⚠ 它只适合「报个平安」，不适合传递信息。
    3. 声波是唯一既能远距离传播、又能携带足够信息量的载体 ✓ 所以在水下，「探测」与「通信」这两件事最终都落在声学上。

    「高频能带更多信息」在水下不成立

    空气中的直觉是：频率越高，可用带宽越大。 水里这条直觉反过来 —— 声吸收随频率迅速上升， 高频声波走不远；而走得远的低频段带宽又很窄。

    这正是水声的基本矛盾：距离与带宽不可兼得 ⚠ 后面的章节里，这个矛盾会反复出现：选频就是在这两者之间做取舍。

    2.4 由此得到的四条工程常识¶

    由「海水导电、声波可传」出发，可以立刻推出四条在本课程里反复使用的常识。 它们分别是：低频优先（走远靠低频）、信道有记忆（多途使信号变形）、 环境很吵（噪声与混响都强）、边界不易处理（海面与海底都是不理想的反射面）。 这四条合起来，就构成了后面所有方法背后的约束。

    三、声呐的基本工作方式：主动与被动¶

    3.1 两种工作方式¶

    声呐按「声波是自己发的，还是听别人的」，分成两类。

    主动声呐：自己发、自己听。声波走完整的两趟：

    \[ \text{回声级}\quad \text{EL} = \text{SL} - 2\,\text{TL} + \text{TS} \]

    三项分别对应「发出去多少」「路上来回丢掉多少」「目标送回多少」。

    被动声呐：只接收目标本身辐射的噪声。声波只走一趟：

    \[ \text{接收级}\quad \text{RL} = \text{SL}_{\text{目标}} - \text{TL} \]

    关键差别只有一个：主动要付两次传播损失，被动只付一次。 就是这一点，决定了两者的能力边界完全不同。

    读这张图的要点：能量流程是「发 → 去程 → 目标 → 回程 → 收」， 四项损失依次相扣；主动声呐方程就是把这条链写成等式， 下一章会逐项展开。

    3.2 各自的适用场景¶

    维度 主动声呐 被动声呐
    传播损失 两次（\(2\,\text{TL}\)） 一次（\(\text{TL}\)）
    作用距离 近 远 ✓
    隐蔽性 暴露自己 ⚠ 只收不发 ✓
    能否测距 能（回波时延） 单阵难测距
    依赖条件 目标能反射声波 目标必须发出声音
    典型用途 测距、成像、地形测绘、扫雷 长时间监听、目标预警

    这张表给出的是分工，不是优劣。实践中的配置通常是： 被动负责「先听见」，主动负责「再量准」， 两者接力，才构成完整的探测链路。

    一句话抓住主动与被动的分界

    主动是回声定位：先付出能量，再换回距离与方位。 被动是监听：不付能量，但只能听，不能主动去问。 两者的分水岭只有一条 —— 传播损失算一次还是两次。

    被动声呐会遇到「安静目标」

    被动声呐的全部信息来源是目标的辐射噪声。 如果目标采取降噪措施，辐射级下降若干分贝， 被动作用距离就会按传播规律迅速缩水（低频段尤其明显）。

    这时往往必须回到主动方式，或者改用更低的频段与更大的孔径。 没有任何单一手段能覆盖所有场景 ⚠

    import math


def max_range(budget_db, alpha_db_km, factor, r_hi=2000.0):
    """解传播损失预算方程，返回作用距离(km)。

    budget_db 是留给单程传播损失的额度，factor 是扩展项系数
    （球面 20、柱面 10）。
    """
    def exceed(r_km):
        tl = factor * math.log10(r_km * 1000.0) + alpha_db_km * r_km
        return budget_db - tl

    lo, hi = 0.001, r_hi
    for _ in range(200):
        mid = 0.5 * (lo + hi)
        if exceed(mid) > 0.0:
            lo = mid
        else:
            hi = mid
    return 0.5 * (lo + hi)


SL, TS, NL, DI, DT = 200.0, 10.0, 60.0, 20.0, 10.0
SL_tgt, alpha = 140.0, 0.06

tl_act = (SL + TS - NL + DI - DT) / 2.0   # 主动：先算 2*TL，再折成单程
tl_pas = SL_tgt - NL + DI - DT            # 被动：只有 1*TL

print("主动 2*TL = %.0f dB -> 单程 TL = %.0f dB" % (2.0 * tl_act, tl_act))
print("被动 1*TL = %.0f dB" % tl_pas)
print("扩展方式".ljust(12) + "主动(km)".ljust(14)
      + "被动(km)".ljust(14) + "被动/主动")
for name, factor in (("球面", 20.0), ("柱面", 10.0)):
    ra = max_range(tl_act, alpha, factor)
    rp = max_range(tl_pas, alpha, factor)
    print("%-12s%-14.2f%-14.2f%.2f" % (name, ra, rp, rp / ra))

被动 1*TL = 90 dB
扩展方式        主动(km)        被动(km)        被动/主动
球面          9.37          26.36         2.81
柱面          399.71        544.06        1.36

    两张剖面分别说明两件事：

    • 球面扩展一行说明「一倍的信道预算带来数倍的距离」；
    • 柱面扩展一行说明波导能把距离拉高一个数量级以上 —— 能量被限制在一层海水里，不再向垂直方向散开。

    第二行还附带一个重要提醒：距离的量级主要由信道决定，其次才由设备决定。 这就是为什么本课程把大块篇幅给了海洋信道本身。

    五、海洋声学研究进展与展望¶

    本节对应大纲 1.2。这里不追求面面俱到，只把三条主线讲清楚： 声场怎么算、信号怎么处理、观测怎么做。

    5.1 声场建模方法¶

    把波动方程「解出来」，历史上形成了五类方法，它们的适用范围各不相同。

    方法 适用条件 强项 局限
    射线声学 高频、波长远小于环境尺度 直观，便于多途与到达结构分析 焦散区与影区失效
    简正波 低频、近似水平分层 频散刻画准确，物理图像清晰 强距离相关时计算昂贵
    抛物方程 距离相关环境、单向传播 效率高，适合大范围计算 后向散射处理弱
    波数积分 任意分层、全波解 精度高，可作基准 计算量大
    数值方法 复杂边界与三维 几何适应性强 高频不现实

    选择方法的第一原则是「先看频率与环境」， 而不是先看哪种方法算得快。频率决定了物理图像，环境决定了求解难度。

    5.2 信号处理¶

    处理方向的进展可以概括为四次「视角升级」：

    1. 从时域到空域：波束形成把基阵变成「有方向的耳朵」；
    2. 从空域到「声场指纹」：匹配场处理把整段声场当作目标的指纹， 用声场模型去匹配，从而在浅海多途条件下定位；
    3. 从确定性到稀疏与统计：压缩感知、稀疏重构、自适应处理， 用更少的快拍换取更好的分辨能力；
    4. 从模型驱动到数据驱动：用数据直接学习映射关系， 在模型说不清楚的时候补充经验。

    匹配场处理的杀伤力与脆弱性都在同一个地方： 它高度依赖声场模型与环境参数，环境失配会让性能急剧下降 ⚠， 实际系统中必须配套环境参数估计。

    5.3 矢量水听器与声层析¶

    矢量水听器同步测量声压与质点振速。多出的振速通道带来两样东西： 一是额外的阵增益，二是左右舷分辨能力 —— 单个小尺寸矢量水听器就能测向，这在被动的低频场合特别有价值。

    海洋声层析走的是另一条路：不把声波当「探测信号」， 而把传播时间的变化当作海水的温度计。 利用长距离多途到达时间的微小变化，可以反演出路径上的温度场变化， 把海水的观测变成「用声音来做 CT」。

    5.4 展望¶

    方向 驱动力 关键难点
    低频与远程 低频吸收小、可借波导走远 大孔径基阵的工程实现
    大孔径与稀疏阵 提高增益与分辨 阵列形变与相位校准
    平台组网观测 多点多时同步采样 同步、通信、能耗
    环境自适应处理 抵消环境失配 快速环境参数估计
    数据驱动 复杂场景泛化 标注数据稀缺、可解释性

    要警惕一种想法：以为「有了新算法，物理就不重要了」。 真实情况恰好相反 —— 算法越复杂，对声场模型与环境参数的依赖越强 ⚠

    六、水声学移动观测探测技术研究进展与展望¶

    本节对应大纲 1.3。前面的模型与算法都要靠平台把仪器送到海里去， 平台的进展直接决定了能观测到什么。

    6.1 四类常用平台¶

    平台 运动方式 优势 局限 典型用途
    潜标（锚系） 固定在海底或中层 长期时间序列，站位稳定 只有单点，无法移动 长时序噪声与传播观测
    水下滑翔机 浮力驱动的锯齿剖面 噪声低、续航长 速度慢，带不了大孔径阵 大范围剖面与被动监听
    自治水下航行器 自带动力、可自主规划 机动灵活、可带主动声呐 续航受能源限制 地形测绘与目标探测
    拖曳阵 由水面平台拖曳 孔径大，低频性能好 受平台自噪声影响 低频被动探测

    这张表的读法：四类平台回答的是四类不同的问题。 要时间序列，用潜标；要空间断面，用滑翔机； 要机动与主动能力，用航行器；要大孔径与低频率，用拖曳阵 ✓

    滑翔机为什么在被动声学里特别受重视：它靠浮力差驱动， 没有螺旋桨，自噪声很低，因此能把水听器放在一个相对安静的平台上去听。 它走的锯齿剖面本身就很适合做层化海水的采样。

    6.2 为什么移动观测要关心深海声道¶

    远程低频探测之所以可能，靠的是信道本身的「波导效应」—— 声速在某个深度取极小值，声线被反复折射回来，能量被限制在声道内传播。

    这张图解释了「上千公里」从哪来：轴处声速最小，两侧声速变大， 声线在轴附近上下摆动而不逸出，于是扩展规律从球面变成柱面， 距离随之拉高一个数量级。低频、声道、大孔径，是远程探测的三件套。

    观测平台的选择只用问三个问题

    第一，要时间序列还是要空间断面？ 第二，能不能接受平台自身的噪声？ 第三，能源与回收条件允许多久？ 三个问题的答案基本就把平台定下来了。

    平台自噪声会吃掉探测能力

    滑翔机与航行器都很安静，但远不是无声： 浮力调节机构、姿态控制与推进器都会贡献噪声。 对于弱目标，平台自噪声可能比环境噪声还高， 提高声源级也补不回来 ⚠

    工程上的做法是：把水听器尽量远离振动源，并同步记录平台状态， 在处理阶段做自适应抵消。

    八、例题¶

    例题 1：海水对电磁波与声波的衰减量级差多少¶

    题目：海水电导率取 \(\sigma \approx 4\ \text{S/m}\)。 求 10 kHz 电磁波在海水中的趋肤深度与每公里衰减； 再与 1 kHz 声波在 1 km 距离上的单程总损失比较。

    思路

    电磁波用趋肤深度公式 \(\delta = \sqrt{2/(\omega\mu\sigma)}\)， 衰减按 \(8.686/\delta\)（dB/m）折算； 声波按「球面扩展 + 吸收」两项相加。

    解答

    第一步：算趋肤深度。

    \[ \delta = \sqrt{\frac{2}{2\pi\times10^4 \times 4\pi\times10^{-7} \times 4}} \approx 2.5\ \text{m} \]

    第二步：折算衰减。

    \[ \frac{8.686}{2.5} \approx 3.45\ \text{dB/m} \quad\Longrightarrow\quad 3452\ \text{dB/km} \]

    第三步：声波的账。

    \[ 20\lg(10^3) + 0.069 \times 1 = 60 + 0.069 \approx 60.1\ \text{dB} \]

    第四步：比较。

    载体 距离 单程损失 折算倍数
    电磁波（10 kHz） 1 km 3452 dB 约 \(10^{345}\) 倍
    声波（1 kHz） 1 km 60.1 dB 基准

    这说明什么：差值约 3392 dB，写成功率比是 \(10^{339}\) 量级 —— 这个数已经失去了工程意义 ⚠ 所以「水下用电波探测」不是难，而是在物理上不成立 ✓

    例题 2：同样的目标，主动与被动谁更远¶

    题目：\(\text{SL} = 200\) dB、\(\text{TS} = 10\) dB、\(\text{NL} = 60\) dB、 \(\text{DI} = 20\) dB、\(\text{DT} = 10\) dB、\(\alpha = 0.06\) dB/km。 若改为被动方式、目标辐射级 \(140\) dB，球面扩展下比较两者的作用距离。

    思路

    主动要付两次传播损失，把 \(2\,\text{TL}\) 的额度算出来再折半； 被动只付一次。然后各自解 \(20\lg r + \alpha r = \text{TL}\)。

    解答

    第一步：主动的额度。

    \[ 2\,\text{TL} = \text{SL} + \text{TS} - \text{NL} + \text{DI} - \text{DT} = 200 + 10 - 60 + 20 - 10 = 160\ \text{dB} \]

    所以单程 \(\text{TL} = 80\) dB。

    第二步：被动的额度。

    \[ \text{TL} = \text{SL}_{\text{目标}} - \text{NL} + \text{DI} - \text{DT} = 140 - 60 + 20 - 10 = 90\ \text{dB} \]

    第三步：解距离。

    方式 单程 TL 额度 作用距离
    主动 80 dB 约 9.4 km
    被动 90 dB 约 26.4 km

    这说明什么：仅仅因为少付一趟传播损失， 被动方式的距离就大约是主动的 2.8 倍 ✓ 这也是低频被动监听长期占据主导地位的原因。

    例题 3：发射功率加倍能多探多远¶

    题目：在例题 2 的主动条件下，把发射功率加倍（\(\text{SL}\) 增 3 dB）， 新作用距离是多少？

    思路

    \(\text{SL}\) 多 3 dB，等于单程 \(\text{TL}\) 的额度多 1.5 dB。 距离是四次方根关系，别指望翻倍。

    解答

    第一步：忽略吸收的估算。

    \[ 40\lg\frac{r'}{r} = 3 \implies \frac{r'}{r} = 10^{0.075} \approx 1.19 \]

    第二步：带上吸收的精确值。 单程额度从 80 dB 变成 81.5 dB，解得 \(r' \approx 11.0\) km，

    \[ \frac{r'}{r} \approx \frac{11.0}{9.4} \approx 1.17 \quad(\text{约 } +17\%) \]

    第三步：换成别的办法对比。

    手段 增益 距离变化 代价
    功率加倍 \(\text{SL} + 3\) dB 约 +17% 重做发射机与电源
    阵长加倍 \(\text{DI} + 3\) dB 约 +17% 多排几个水听器
    频率减半 \(\alpha\) 大幅下降 明显增大 需重新设计换能器

    这说明什么：靠加大功率提升距离是最不划算的一条路 ⚠ 同样的 3 dB 增益，加长基阵或降低频率的代价低得多 ✓

    例题 4：30 天里两个平台各能干多少活¶

    题目：水下滑翔机水平速度 0.25 m/s、剖面周期 6 h； 潜标每小时完成一个剖面。比较 30 天里的采样能力。

    思路

    先算单个剖面的水平位移，再乘剖面总数； 潜标只有时间维度，滑翔机才有空间维度。

    解答

    第一步：滑翔机。

    \[ \text{单个剖面水平位移} = 0.25 \times 6 \times 3600 = 5.4\ \text{km} \]
    \[ \text{剖面总数} = \frac{24 \times 30}{6} = 120 \qquad \text{总航程} = 120 \times 5.4 = 648\ \text{km} \]

    第二步：潜标。 \(24 \times 30 = 720\) 个剖面，但全部落在同一个站位上。

    第三步：对比归纳。

    平台 剖面数 空间覆盖 强项
    水下滑翔机 120 一条 648 km 的断面 空间分布
    潜标 720 单点站位 时间序列 ✓

    这说明什么：两者不是替代关系，而是互补关系 ⚠ 一个负责把水平方向铺开，一个负责把时间方向拉长； 移动观测与定点观测配合，才可能同时回答「哪儿」与「何时」。

    九、自测¶

    Q1 从海水的电导率出发，说明为什么水下探测与通信几乎只能用声波。 请给出趋肤深度的表达式，并说明频率升高时它如何变化。

    Q2 主动声呐与被动声呐在传播损失上分别付几次？ 为什么说被动方式「更省能量」，而它又会在什么情况下失效？

    Q3 匹配场处理与矢量水听器分别给系统增加了什么信息？ 为什么匹配场处理对「环境失配」特别敏感？

    Q4 潜标、水下滑翔机、自治水下航行器各自适合回答哪一类观测问题？ 如果任务是「长期监听一片海域的低频声源并定位」，你会怎么搭配平台？

    小结¶

    项 一句话 后续在哪一章
    为什么用声波 海水导电，电磁波每米损失几 dB；声波吸收只有 0.069 dB/km 量级 第 3 章

    三条最该带走的结论：

    1. 声波是水下唯一能远距离携带信息的载体 —— 这是全课程的立论基础，后面所有方法都建立在它之上 ✓
    2. 距离主要取决于信道，其次才取决于设备 —— 波导（比如深海声道）能把扩展规律从球面改成柱面， 距离量级因此提高一个数量级 ✓
    3. 工程上的每一分贝都要在物理上找得到来处 —— 选频、孔径、平台噪声，三者共同决定探测能力， 指望单一手段解决所有问题是不现实的 ⚠
