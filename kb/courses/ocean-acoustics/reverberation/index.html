    海洋中的混响¶

    前面讲了两种「干扰」：环境噪声（背景）与目标回波（想收的）。

    这一页讲第三种，也是主动声呐特有的：

    混响 = 自己发射的声波，被海水中/海面/海底的散射体 散射回来，形成的干扰。

    为什么它是主动声呐的专属问题：被动声呐不发射， 所以不会产生混响 ✓

    混响与噪声的关键差别：

    环境噪声 混响
    来源 外部（航运、风、热） 自己发射的
    与发射的关系 无关 跟着发射走 ⚠
    时间结构 平稳 随距离衰减
    应对手段 指向性（DI） 指向性不解决（同方向！）

    最后一行最关键：混响来自与目标相同的方向， 所以指向性对混响无效 ⚠ 这是混响比噪声更难对付的根本原因。

    把「混响随时间衰减」算成数：用 \(r = ct/2\) 把时间轴换成距离轴， 再按 \(-30\lg r\) 算衰减。

    import math

c = 1500.0
RL0, r0 = 95.0, 0.1        # 参考点

print("时刻(s)".ljust(10) + "距离(m)".ljust(12) + "界面混响级(dB)")
for t in [0.01, 0.05, 0.1, 0.5, 1.0, 5.0]:
    r = c * t / 2.0
    rl = RL0 - 30.0 * math.log10(r / r0)
    print(("%.2f" % t).ljust(10) + ("%.0f" % r).ljust(12) + "%.1f" % rl)

0.10      75          8.7

1.00      750         -21.3

    这说明什么：混响的衰减速率先快后慢（对数尺度下近似直线）—— 距离增 10 倍，混响降 30 dB ✓ 所以近距离时混响是主要干扰，远距离时它已衰减到可忽略。

    一、混响的成因与分类¶

    1.1 散射体的来源¶

    类型 散射体 空间分布
    体积混响 气泡、浮游生物、鱼 充满水体（三维）
    海面混响 海面粗糙、气泡层 二维界面
    海底混响 海底起伏、底质不均 二维界面

    「体积 / 界面」这个区分决定了衰减规律（见第三节）✓

    1.2 为什么混响是「渐变的」¶

    关键机制：发射脉冲结束后，不同距离的散射体陆续到达接收器。

    \[ t = \frac{2r}{c} \quad\Longrightarrow\quad r = \frac{ct}{2} \]

    「\(2r\)」是因为声波要走来回两趟 ✓

    所以时间轴可以直接换成距离轴：

    收到时刻 对应距离
    10 ms 7.5 m
    100 ms 75 m
    1 s 750 m
    10 s 7.5 km

    混响的「衰减」其实是：随着时间推移，能产生回波的散射体 越来越远、照射到的体积/面积越来越大，两者竞争的结果。

    一句话抓住核心

    混响随时间的衰减，是「距离变远使单个散射体贡献变小」 与「照射范围变大使散射体个数变多」相互竞争的结果。 竞争的结果决定了衰减斜率 ✓

    二、散射强度的度量¶

    2.1 体积散射强度 \(S_v\)¶

    \[ S_v = 10\lg\frac{I_{\text{scat}}(1\,\text{m})}{I_{\text{inc}}\cdot V} \quad(\text{dB/m}) \]

    注意单位是 dB/m（因为除以了体积 1 m³）✓

    典型值：

    海域 \(S_v\)
    深层清洁海水 −90 ~ −80 dB/m
    有鱼群/浮游生物 −70 ~ −50 dB/m
    近海面气泡层 −60 ~ −40 dB/m

    关键：\(S_v\) 有强烈的昼夜与深度变化 ⚠ （浮游生物昼夜垂直迁移 —— 白天深、夜间浅）

    2.2 界面散射强度 \(S_s\)¶

    \[ S_s = 10\lg\frac{I_{\text{scat}}(1\,\text{m})}{I_{\text{inc}}\cdot A} \quad(\text{dB}) \]

    注意这里没有单位里的「m」 —— 因为除以的是面积 1 m² ✓

    界面 典型 \(S_s\)
    平静海面 −50 ~ −40 dB
    有浪海面 −40 ~ −25 dB（随海况增大）
    平坦泥底 −40 ~ −30 dB
    粗糙岩底 −25 ~ −15 dB

    把两者的单位差异记住 —— 这是考试常考的细节 ✓

    三、混响的衰减规律（核心）¶

    3.1 推导思路¶

    混响强度 = （散射体个数）\(\times\)（单个散射体的贡献）\(\times\) （传播损失）。

    关键在散射体个数怎么随距离变：

    类型 照射体积/面积 随 \(r\) 的增长
    体积混响 \(V \propto r^2\cdot \dfrac{c\tau}{2}\) \(\propto r^2\)
    海面混响 \(A \propto r\cdot \dfrac{c\tau}{2}\cdot\phi\) \(\propto r\)
    海底混响 同海面 \(\propto r\)

    （\(\tau\) 是脉冲宽度，\(\phi\) 是水平束宽）

    再加上传播损失（球面扩展，来回两趟）：

    \[ \text{TL}_{\text{round}} = 2\times20\lg r = 40\lg r \]

    3.2 三种混响的衰减律¶

    体积混响：

    \[ \text{RL}_v \propto \frac{r^2}{r^4} = \frac{1}{r^2} \quad\Longrightarrow\quad \text{RL}_v \propto -20\lg r \]

    海面/海底混响：

    \[ \text{RL}_s \propto \frac{r}{r^4} = \frac{1}{r^3} \quad\Longrightarrow\quad \text{RL}_s \propto -30\lg r \]

    三条规律（这是本页最该记住的）：

    类型 衰减规律 物理原因
    体积混响 \(-20\lg r\) 散射体数 \(\propto r^2\)，传播 \(\propto r^{-4}\)
    海面混响 \(-30\lg r\) 散射体数 \(\propto r^1\)
    海底混响 \(-30\lg r\) 同海面（但\(S_s\) 更大）

    海底混响常常比海面混响更强（尽管衰减规律相同）

    两者衰减斜率一样（都是 \(-30\lg r\)）， 但海底的 \(S_s\) 通常更大（尤其岩底）⚠

    工程后果：在浅海（声波几乎一定会打到海底）， 海底混响往往是主动声呐的主要限制 —— 而不是环境噪声。

    这解释了为什么浅海主动声呐的作用距离远小于深海。

    import numpy as np


def reverb_level(r, kind="volume", S=0.0, tau=0.01,
                 beam=0.1, r0=1.0):
    """混响级（相对值，dB）。

    散射体数随 r 的增长：
      volume  -> 照射体积 ∝ r^2 * (c*tau/2) * beam^2
      surface -> 照射面积 ∝ r   * (c*tau/2) * beam
    再乘传播损失（2*20lg r = 40lg r 的倒数）
    """
    c = 1500.0
    if kind == "volume":
        n = r ** 2 * (c * tau / 2.0) * beam ** 2
    else:
        n = r ** 1 * (c * tau / 2.0) * beam
    tl = 40.0 * np.log10(r / r0)
    return S + 10.0 * np.log10(n) - tl


print("距离(m)".ljust(10) + "体积混响".ljust(12) + "海面/海底混响")
for r in [100, 500, 1000, 5000, 10000]:
    v = reverb_level(r, "volume")
    s = reverb_level(r, "surface")
    print(("%d" % r).ljust(10) + ("%.1f" % v).ljust(12) + "%.1f" % s)

print()
print("从 r=100 到 r=10000（100 倍）的衰减量：")
v1, v2 = reverb_level(100, "volume"), reverb_level(10000, "volume")
s1, s2 = reverb_level(100, "surface"), reverb_level(10000, "surface")
print("  体积混响衰减 %.1f dB（理论 40 dB = 20lg100）" % (v1 - v2))
print("  界面混响衰减 %.1f dB（理论 60 dB = 30lg100）" % (s1 - s2))

    距离(m)     体积混响        海面/海底混响
100       -51.2       -61.2
500       -65.2       -82.2
1000      -71.2       -91.2
5000      -85.2       -112.2
10000     -91.2       -121.2

从 r=100 到 r=10000（100 倍）的衰减量：
  体积混响衰减 40.0 dB（理论 40 dB = 20lg100）
  界面混响衰减 60.0 dB（理论 60 dB = 30lg100）

    这组数证实了什么：距离增 100 倍， 体积混响降 40 dB、界面混响降 60 dB —— 与 \(-20\lg r\) / \(-30\lg r\) 完全一致 ✓

    四、混响对检测的影响¶

    4.1 混响掩蔽¶

    混响的作用与噪声类似：它掩盖目标回波。

    \[ \text{检测条件}:\quad \text{EL}_{\text{target}} \ge \text{RL} + \text{DT} \]

    （\(\text{RL}\) 是混响级）

    但有个关键差别：噪声是平稳的，混响随时间衰减。

    这带来一个重要推论：

    距离 谁主导 说明
    近 混响 散射体近、回波强
    远 噪声 混响已衰减殆尽

    所以存在一个「交叉距离」 —— 超过它，限制因素从混响变成噪声 ✓

    这个交叉点是性能预报的核心概念

    近距离优化混响（如缩短脉宽、降低旁瓣） 远距离优化噪声（如加大 DI、延长积分）

    两种优化方向不同，所以要先判断「目标在哪个区」 ✓

    4.2 怎么对付混响¶

    手段 原理 限制
    缩短脉宽 减小照射体积/面积 降低信号能量 ⚠
    降低旁瓣 减少非主瓣方向的散射 受阵设计限制
    多普勒滤波 混响近似零多普勒，运动目标有偏移 ✓ 对静止目标无效
    波形设计 用编码波形+匹配滤波 复杂

    「多普勒滤波」这条最有价值： 混响来自静止的散射体（海面/海底）， 而移动目标有多普勒频移 —— 所以可以在频域上把它们分开 ✓

    这是「动目标显示（MTI）」在水声中的对应技术。

    多普勒手段对「静止目标」完全无效

    如果目标是静止的（如坐底潜艇、水雷）， 多普勒滤波无法把回波与混响分开 ⚠

    此时只能靠脉宽、旁瓣、波形等手段。 这是探测静止目标明显更难的根本原因。

    五、例题¶

    例题 1：时间与距离的换算¶

    题目：主动声呐在发射后 0.5 s 收到一段混响。它对应多大距离？

    思路

    用 \(r = ct/2\)（来回两趟）。

    解答

    第一步：代入。

    \[ r = \frac{1500\times0.5}{2} = 375\ \text{m} \]

    答案：375 m。

    这说明什么：0.5 s 对应不到 400 m —— 混响的时间尺度很短（几秒就对应几公里的距离）✓

    例题 2：比较两种混响的衰减¶

    题目：从 1 km 到 20 km（20 倍），体积混响与界面混响 各衰减多少 dB？

    思路

    体积 \(-20\lg(20)\)，界面 \(-30\lg(20)\)。

    解答

    第一步：体积混响。

    \[ 20\lg 20 = 20\times1.301 = 26.0\ \text{dB} \]

    第二步：界面混响。

    \[ 30\lg 20 = 30\times1.301 = 39.0\ \text{dB} \]

    答案：体积降 26 dB，界面降 39 dB。

    这说明什么：界面混响衰减更快 —— 在远距离上，若两者在近处相当，远处将由体积混响主导 ✓

    例题 3：判断限制因素¶

    题目：某浅海主动声呐，在 2 km 处混响级 RL = 75 dB、 环境噪声级 NL = 60 dB（已减 DI）。 在 8 km 处 RL = 55 dB、NL 仍为 60 dB。 判断两个距离上分别由什么限制检测。

    思路

    比较 RL 与 NL 的大小（都是「干扰级」）。

    解答

    第一步：2 km 处。

    \[ \text{RL} = 75 > \text{NL} = 60 \]

    混响主导（干扰更高）⚠

    第二步：8 km 处。

    \[ \text{RL} = 55 < \text{NL} = 60 \]

    噪声主导 ✓

    结论：交叉点在 2–8 km 之间。

    这说明什么：近处要对付混响、远处要对付噪声。 优化手段完全不同，所以必须先判断工作区间 ✓

    例题 4：脉宽对混响的影响¶

    题目：脉宽从 100 ms 减到 10 ms， 混响级变化多少？（假设散射体均匀分布）

    思路

    混响正比于照射体积/面积，而后者正比于脉宽 \(\tau\)。

    解答

    第一步：写出关系。

    \[ \text{RL} \propto 10\lg\tau \]

    第二步：算变化量。

    \[ \Delta\text{RL} = 10\lg\frac{10}{100} = 10\lg 0.1 = -10\ \text{dB} \]

    答案：降低 10 dB ✓

    代价：脉冲能量也降 10 dB（同样的峰值功率）⚠

    这说明什么：缩短脉宽是「有效的但有代价」的手段 —— 它同时降低混响与信号能量，净效果取决于目标强度 （强目标可以用短脉宽，弱目标不划算）✓

    小结¶

    类型 散射体 散射强度单位 衰减规律 典型场景
    体积混响 气泡、生物 dB/m \(-20\lg r\) 有生物层时
    海面混响 海面粗糙 dB \(-30\lg r\) 有浪时
    海底混响 海底起伏 dB \(-30\lg r\) 浅海主要限制 ⚠

    三条最该带走的结论：

    1. 混响来自与目标相同的方向 → 指向性不能抑制它 ⚠
    2. 衰减规律取决于散射体维数：体积 \(-20\lg r\)、界面 \(-30\lg r\) ✓
    3. 近处混响主导、远处噪声主导 —— 存在交叉距离， 优化方向因此不同 ✓
