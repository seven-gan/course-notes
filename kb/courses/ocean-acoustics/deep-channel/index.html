    深海声道与表面声道¶

    上一页给出了 Snell 定律。这一页用一个结论把它用到底：

    声速剖面的极小值（或极大值）能形成「波导」，把声能困住并传得很远。

    这是水声里最有实用价值的现象 —— 它让「几百公里外探测」 从不可能变成可能。

    一、声道的基本原理¶

    1.1 为什么能「困住」声能¶

    回到 Snell 定律的核心结论：射线总向声速小的方向弯。

    考虑声速在某个深度取极小值 \(c_{\min}\)（记该深度为声道轴）：

    射线位置 声速相对轴 弯曲方向 结果
    轴上 最小 — 沿轴直行 ✓
    轴上方 更大 向下（朝声速小） 被推回轴 ✓
    轴下方 更大 向上（朝声速小） 被推回轴 ✓

    两种情况都指向轴 → 射线在轴附近来回振荡 → 能量被束缚

    这就是「波导」：不需要任何实体边界，仅靠声速剖面的极小值 就能把声能限制在一定深度范围内。

    类比：深海声道就是「声学的光纤」

    光纤 深海声道
    纤芯折射率大、包层小 声道轴声速最小、两侧大
    光靠全内反射被束缚 声靠折射被束缚
    可传上百公里 可传上千公里 ✓

    两者是完全相同的物理机制（折射率/声速的「倒梯形」分布）

    1.2 声道轴在哪¶

    海域 声道轴深度 原因
    深海（> 2000 m） 约 1000–1200 m 温度与压力主导的交界处
    中纬度夏季 约 800–1000 m 主跃层较浅
    高纬度 接近表层 表层温度本就低
    浅海 可能不存在 水深不够形成完整剖面

    关键：声道轴深度由「温度主导」与「压力主导」的交界决定， 所以它随纬度与季节变化

    import numpy as np


def c_profile(z, z_axis=1000.0, c_axis=1500.0, k=0.09):
    """声道型声速剖面：在 z_axis 处取极小值。"""
    return c_axis * (1.0 + k * ((z - z_axis) / 3000.0) ** 2)


def trace(z0, theta0_deg, z_max=5000.0, dz=2.0, max_steps=400000):
    """Snell 定律逐段积分追踪声线，返回 (x, z) 数组。"""
    c0 = c_profile(z0)
    p_s = np.sin(np.radians(theta0_deg)) / c0
    xs, zs = [0.0], [z0]
    x = 0.0
    z = z0
    d = 1 if theta0_deg >= 0 else -1
    for _ in range(max_steps):
        c = c_profile(z)
        s = p_s * c
        if abs(s) >= 1.0:
            break
        cos_t = np.sqrt(1.0 - s * s)
        x += d * dz * cos_t / s
        z += d * dz
        xs.append(x)
        zs.append(z)
        if z <= 0 or z >= z_max:
            break
    return np.array(xs), np.array(zs)


print("声源在声道轴 1000 m，各出射角的射线最远水平距离：")
for th in [1, 3, 6, 12, 20]:
    xs, zs = trace(1000.0, th)
    print("  出射角 %2d 度 -> 水平 %9.1f m，深度范围 %4.0f - %4.0f m"
          % (th, xs[-1], zs.min(), zs.max()))

    二、会聚区与影区¶

    2.1 会聚区的形成¶

    在深海（声速随深度单调增，不存在声道轴）时， 另一种结构会出现：会聚区（CZ）。

    形成过程：

    1. 声源在近表层，声线向下弯曲（因为越深声速越大）
    2. 声线到达某个深度后折返向上
    3. 回到海面时（经海面反射）又向下 —— 形成周期性
    4. 在折返点附近，多条声线聚集 → 声强显著增强

    会聚区的特征：

    项目 典型值
    间隔 30–70 km（与水深、声速梯度有关）
    宽度 几 km
    增益 比球面扩展预测值高 10–20 dB ✓

    这非常实用：潜艇可以在会聚区的远距离上被发现 —— 虽然不是连续的，而是一环一环的。

    会聚区之间的「影区」里几乎没有声

    相邻两个会聚区之间是影区：射线到不了，声强比球面扩展 预测值低几十 dB

    后果：深海探测是周期性的 —— 目标「在会聚区」时能发现，「在影区」时突然消失， 然后再出现。

    若不知道这个机制，会误判成「目标消失了」或「设备故障」

    2.2 表面声道¶

    表面声道发生在「声速随深度减小」的表层（通常是等温层加上 轻微的盐度效应），此时：

    • 海面是压力释放边界（\(p = 0\)）
    • 表层是负梯度（声速随深度减）

    两者共同作用：

    因素 作用
    负梯度 射线向上弯（朝声速小的表层）
    海面反射 把它反射回水中（相位反转）

    → 射线在海面与某个深度之间来回反弹 → 被束缚

    表面声道的厚度：几十到一两百米，取决于梯度强度。

    传播特点：

    \[ \text{TL} \approx 10\lg r \quad(\text{柱面扩展}) \]

    注意这里是 \(10\lg r\) 而不是 \(20\lg r\) —— 因为能量被限制在一层里，只能沿水平方向「摊开」， 不能向垂直方向散开 ✓

    这就是柱面扩展的物理来源

    2.3 三种传播模式的对比¶

    模式 形成条件 扩展规律 有效距离
    球面扩展（深水） 无明显波导 \(20\lg r\) 近
    表面声道 表层负梯度 + 海面 \(10\lg r\) 中（几十 km）
    深海声道 声速极小值 \(10\lg r\) 远（上千 km） ✓
    会聚区 深海正梯度 周期性增强 远但间断

    关键认识：能形成波导的，就是「省钱」的传播 —— 因为它把 \(20\lg r\) 换成了 \(10\lg r\)， 相当于把距离的代价减半（对数意义上）

    import numpy as np


def tl_spherical(r_km):
    """球面扩展损失（dB），r 单位 km。"""
    return 20.0 * np.log10(r_km * 1000.0)


def tl_cylindrical(r_km, r0_km=1.0):
    """柱面扩展损失（dB）：以 r0 为参考，按 10lg(r/r0) 增长。"""
    return tl_spherical(r0_km) + 10.0 * np.log10(r_km / r0_km)


print("距离(km)".ljust(10) + "球面(dB)".ljust(12) + "柱面(dB)".ljust(12)
      + "差值(dB)")
for r in [1, 5, 10, 50, 100, 500, 1000]:
    a, b = tl_spherical(r), tl_cylindrical(r)
    print(("%d" % r).ljust(10) + ("%.1f" % a).ljust(12) + ("%.1f" % b).ljust(12)
          + "%.1f" % (a - b))

1         60.0        60.0        0.0
5         74.0        67.0        7.0
10        80.0        70.0        10.0
50        94.0        77.0        17.0
100       100.0       80.0        20.0
500       114.0       87.0        27.0
1000      120.0       90.0        30.0

    这组数说明了什么：距离越远，柱面扩展的优势越大 —— 1000 km 处差出 60 dB（相当于发射功率差 \(10^6\) 倍）

    这就是深海声道能实现洲际探测的定量原因

    四、例题¶

    例题 1：判断能否形成深海声道¶

    题目：某海域声速剖面：表层 1540 m/s、1000 m 处 1480 m/s、 4000 m 处 1520 m/s。能否形成深海声道？声道轴在哪？

    思路

    找声速的极小值 —— 存在极小值就能形成声道。

    解答

    第一步：看趋势。

    深度 声速 趋势
    0 → 1000 m 1540 → 1480 下降（温度主导）
    1000 → 4000 m 1480 → 1520 上升（压力主导）

    第二步：判断。

    在 1000 m 处取极小值 1480 m/s → 能形成深海声道

    第三步：声道轴位置。

    约 1000 m（正好是温度主导与压力主导的转折点）。

    声道轴不是固定的，它由剖面的转折点决定， 随纬度季节变化

    例题 2：用柱面扩展估算作用距离¶

    题目：某深海声道系统，\(\text{SL} = 200\) dB、\(\text{TS} = 15\) dB、 \(\text{NL} = 55\) dB、\(\text{DI} = 20\) dB、\(\text{DT} = 10\) dB， 吸收 \(\alpha = 0.05\) dB/km。 分别在球面与柱面假设下估算作用距离。

    思路

    解声呐方程。柱面用 \(10\lg r\) 而非 \(20\lg r\)， 注意主动声呐要乘 2。

    解答

    第一步：允许的 TL。

    \[ 2\text{TL} = \text{SL} + \text{TS} - (\text{NL} - \text{DI} + \text{DT}) = 200 + 15 - 45 = 170\ \text{dB} \]
    \[ \text{TL} = 85\ \text{dB} \]

    第二步：球面假设。

    \[ 20\lg r + 0.05r = 85 \]

    先忽略吸收：\(20\lg r = 85 \Rightarrow r = 10^{4.25}\approx 17.8\) km。 带回吸收项：\(0.05\times17.8 = 0.9\) dB，修正后约 15 km

    第三步：柱面假设。

    \[ 20\lg(1000) + 10\lg\frac{r}{1} + 0.05r = 85 \]
    \[ 60 + 10\lg r + 0.05r = 85 \Rightarrow 10\lg r + 0.05r = 25 \]

    试 \(r = 300\) km：\(10\lg 300 = 24.8\)，\(0.05\times300 = 15\)， 合计 39.8 —— 太大。试 \(r = 100\) km：\(20 + 5 = 25\)

    答案：柱面约 100 km，球面约 15 km（差 6.7 倍）

    波导能把作用距离提升近一个数量级 —— 这就是声道现象的实际价值

    例题 3：会聚区的间隔¶

    题目：某深海海域，声源与接收都在 100 m 深， 声线在约 3000 m 深处折返。估算会聚区间隔。

    思路

    声线走一个「弧」：下到 3000 m 再回到 100 m。 用近似几何关系估算水平跨度。

    解答

    第一步：理想化。

    把声线近似成圆弧（声速梯度大致均匀时成立）。 从 100 m 下到 3000 m 再回 100 m，弦高约 2900 m。

    第二步：用 Snell 定律估水平跨度。

    对典型的深海剖面，折返一次的水平跨度约为 2–3 倍于折返深度。取 2.5 倍：

    \[ \Delta r \approx 2.5\times2900 \approx 7.3\ \text{km} \]

    第三步：会聚区间隔通常是这个数的几倍 （因为要经过多个折返才重新聚焦到接收深度）。

    实测经验值：30–70 km。

    答案：约 30–70 km（本例条件偏浅，落在下限附近）。

    会聚区间隔主要由折返深度与声速梯度决定， 与频率基本无关

    例题 4：柱面扩展的物理含义¶

    题目：为什么表面声道里扩展损失是 \(10\lg r\) 而不是 \(20\lg r\)？ 请从能量守恒的角度解释。

    思路

    扩展损失的来源是「声能被摊开的面积」。 比较球面（波前是球面）与柱面（波前是柱面）的面积增长。

    解答

    第一步：球面的面积增长。

    波前面积 \(A = 4\pi r^2\)，正比 \(r^2\)。 声强 \(I \propto 1/r^2\) → \(\text{TL} = 20\lg r\)

    第二步：柱面的面积增长。

    能量被限制在一层里，波前是柱面：

    \[ A = 2\pi r H \quad(H\ \text{是声道厚度，常数}) \]
    \[ A \propto r^1 \quad\Longrightarrow\quad I \propto 1/r \quad\Longrightarrow\quad \text{TL} = 10\lg r \]

    第三步：结论。

    竖直方向不再「摊开」 → 面积只按 \(r\) 增长而非 \(r^2\) → 损失减半

    「波导」的全部价值就是把一维的散开 变成零维 —— 竖直方向被束缚住了

    五、自测¶

    Q1 为什么声速剖面的极小值能把声能困住？ 请分别分析射线在轴上方与轴下方时的弯曲方向。

    Q2 写出表面声道里传播损失的表达式，并解释为什么它不是 \(20\lg r\)。 用「波前面积的增长」说明。

    Q3 什么是会聚区？为什么会聚区之间存在「影区」？ 如果不知道这个机制，在深海探测中会导致什么误判？

    Q4 某海域表层 1535 m/s、800 m 处 1478 m/s、3000 m 处 1505 m/s。 判断能否形成声道、声道轴大致在哪， 并估算「球面 vs 柱面」假设下作用距离的差别（用四次方关系粗估即可）。

    小结¶

    结构 形成条件 扩展规律 距离 典型海域
    球面扩展 无波导 \(20\lg r\) 近 浅海、无明显梯度
    表面声道 表层负梯度 + 海面 \(10\lg r\) 几十 km 冬季高纬、近表层
    深海声道 声速极小值 \(10\lg r\) 上千 km ✓ 深海（~1000 m 轴）
    会聚区 深海正梯度 间断增强 30–70 km 周期 深海
    影区 会聚区之间 极低 — 深海

    三条最该带走的结论：

    1. 声速极小值 → 波导 → 柱面扩展（\(10\lg r\)） —— 比球面扩展「省一半」
    2. 会聚区是周期性的：深海探测会出现「发现 → 消失 → 再发现」， 这是正常现象，不是故障
    3. 声道轴深度由剖面转折点决定，随纬度与季节变化
