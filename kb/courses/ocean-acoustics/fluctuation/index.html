    声传播起伏¶

    前面的结论都默认声场稳定，但真实海洋的声速剖面在随时间变化， 于是声场会随机起伏。这一页要回答三个问题： 起伏从哪来、有多大、以及它如何限制系统的性能。

    其中第三个问题的答案最实用：起伏给"长时间累积增益"设了一个硬上限。

    一、起伏的来源¶

    海洋里对声波起作用的不均匀性有三类，按尺度区分：

    来源 尺度 时间尺度 主要影响
    内波 10–1000 m 分钟–小时 声线随机弯折（主导）
    细结构 / 湍流 0.1–10 m 秒–分钟 小角散射、强度闪烁
    随机界面 随海况 秒 海面、海底散射

    内波之所以主导，是因为它的尺度恰好与波长和声道厚度可比。

    1.1 作用机制由尺度决定¶

    机制 条件 后果
    折射 尺度远大于波长 声线路径改变（主导）
    散射 尺度与波长可比 声能散向其他方向
    衍射 尺度远小于波长 通常可忽略

    判据仍然是尺度与波长之比，与射线声学的适用判据同源。

    1.2 内波到声场的传导链¶

    内波本身不是声学量，它通过改变声速剖面起作用：

    内波扰动温跃层位置 → 声速剖面随时间变化 → 声线路径随机改变 → 声场起伏

    所以起伏的根源可以统一归结为「声速剖面的随机扰动」， 内波只是其中最主要的扰动源。

    二、起伏的度量¶

    2.1 振幅起伏：闪烁指数¶

    闪烁指数（scintillation index）是归一化强度方差：

    \[ \text{SI} = \frac{\langle I^2\rangle - \langle I\rangle^2}{\langle I\rangle^2} = \frac{\operatorname{Var}(I)}{\langle I\rangle^2} \]
    SI 值 含义
    0 无起伏（完全稳定）
    1 瑞利起伏（强散射极限，典型值）
    大于 1 强聚焦（焦散区可达 10 以上）

    SI = 1 为什么对应瑞利分布：当大量随机散射叠加时， 合成场幅度服从瑞利分布，其强度服从指数分布； 而指数分布的方差恰好等于均值的平方，所以 SI = 1。

    2.2 相位起伏¶

    相位起伏用相位方差刻画：

    \[ \sigma_\phi^2 = \langle(\phi - \langle\phi\rangle)^2\rangle \]

    它的工程含义是破坏相干处理：当 \(\sigma_\phi\) 超过约 \(\pi\) 时， 相位已完全随机，波束形成与匹配滤波的相干增益基本丧失。

    2.3 相关尺度——比方差更重要的量¶

    量 定义 典型值
    时间相关半径 起伏自相关降到一半的时间 分钟 ~ 小时
    空间相关半径 起伏横向相关长度 几十 m ~ km

    这两个尺度之所以比方差更重要，是因为它们直接给出两个设计上限： 信号可以相干累积多久、多大的阵列还能相干工作。

    起伏是长时间累积的硬上限

    只按噪声考虑时，累积时间越长越好（信噪比按 \(\sqrt{T}\) 改善）。 但一旦超过时间相关半径，信号相位已经随机变化，无法再相干累积， 再延长只是把已起伏的样本平均掉，增益不再增长。

    这就是水声里"无限延长积分时间"无效的原因。处理长度必须按 时间相关半径来设计。

    import numpy as np


def simulate_intensity(n, si=1.0, seed=0):
    """生成均值为 1、方差为 SI 的强度样本（用 gamma 分布）。

    强度服从指数分布时 SI = 1（对应瑞利幅度），
    gamma 分布的形状参数取 k = 1/SI 即可复现各种 SI。
    """
    rng = np.random.default_rng(seed)
    return rng.gamma(shape=1.0 / si, scale=si, size=n)


print("闪烁指数与强度分位数：")
for si in [0.2, 1.0, 3.0]:
    x = simulate_intensity(200000, si=si, seed=42)
    print("  SI=%.1f：均值 %.3f，方差 %.3f" % (si, x.mean(), x.var()))
    print("        5%%分位 %.3f   50%%分位 %.3f   95%%分位 %.3f"
          % (np.percentile(x, 5), np.percentile(x, 50),
             np.percentile(x, 95)))

print()
x = simulate_intensity(200000, si=1.0, seed=7)
lo, hi = np.percentile(x, 5), np.percentile(x, 95)
print("SI=1 时强度的 5%%~95%% 区间跨越 %.1f 倍（约 %.1f dB）"
      % (hi / max(lo, 1e-9), 10.0 * np.log10(hi / max(lo, 1e-9))))

    闪烁指数与强度分位数：
  SI=0.2：均值 1.000，方差 0.201
        5%分位 0.392   50%分位 0.935   95%分位 1.830
  SI=1.0：均值 0.999，方差 1.003
        5%分位 0.052   50%分位 0.691   95%分位 2.992
  SI=3.0：均值 0.998，方差 2.988
        5%分位 0.000   50%分位 0.286   95%分位 4.397

SI=1 时强度的 5%~95% 区间跨越 57.8 倍（约 17.6 dB）

    import numpy as np

# 相干累积的上限：超过时间相关半径后增益不再增长
tau_c = 60.0          # 时间相关半径 (s)
T = 1.0               # 脉冲重复周期 (s)
N_max = tau_c / T

print("时间相关半径 %.0f s，重复周期 %.1f s -> 最大相干累积 %.0f 个脉冲"
      % (tau_c, T, N_max))
print()
print("脉冲数".ljust(10) + "理论相干增益(dB)".ljust(20) + "是否还有效")
for N in [10, 30, 60, 120, 240]:
    gain = 10.0 * np.log10(N)
    ok = "有效" if N <= N_max else "无效（已超相关半径）"
    print(("%d" % N).ljust(10) + ("%.1f" % gain).ljust(20) + ok)
print()
print("注意最后两行：公式仍给出正增益，但那是理论值，实际拿不到")

    时间相关半径 60 s，重复周期 1.0 s -> 最大相干累积 60 个脉冲

脉冲数       理论相干增益(dB)          是否还有效
10        10.0                有效
30        14.8                有效
60        17.8                有效
120       20.8                无效（已超相关半径）
240       23.8                无效（已超相关半径）

注意最后两行：公式仍给出正增益，但那是理论值，实际拿不到

    超过 60 个脉冲后，公式算出的相干增益虽然还在增长，但实际拿不到 —— 相位已经随机化。所以按理想公式设计的处理长度会严重高估性能。

    四、起伏对系统的影响¶

    4.1 三种后果¶

    后果 机制 工程影响
    检测概率波动 回波强度随机 同一目标时有时无
    相干增益损失 相位随机 波束形成、匹配滤波失效
    累积增益饱和 相关性丧失 延长积分不再改善

    4.2 与检测判决的关系¶

    由声呐方程，检测要求回波级超出干扰与检测阈之和。若回波级本身随机， 检测概率就成为随机变量：

    \[ P_d = P(\text{EL} \gt \text{门槛}) \]

    这正是同一目标有时能连续跟踪、有时突然丢失的原因之一 —— 不一定是目标机动，也可能是起伏。

    4.3 应对手段¶

    手段 原理 局限
    减小孔径 / 降低频率 减小相位起伏影响 牺牲分辨率
    非相干累积 只用强度，不看相位 增益低于相干（\(\sqrt{N}\) 对 \(N\)）
    自适应处理 估计并补偿相位 实现复杂
    分集（频率 / 空间） 多个不相关通道平均 需要带宽或孔径

    非相干累积放弃相干增益以换取鲁棒性。在起伏强的海域， 非相干处理反而可能更好：相干处理受起伏影响"白忙一场"， 而非相干至少能稳定累积。

    五、例题¶

    例题 1：由闪烁指数算强度波动范围¶

    题目：某海域测得 SI = 1。用瑞利分布性质求强度在 5%–95% 分位间的跨越倍数。

    思路

    SI = 1 对应强度服从指数分布，其累积分布为 \(F(x) = 1 - e^{-x/\langle I\rangle}\)。

    解答

    第一步：写出分位数公式。

    令 \(F(x) = p\)，解出

    \[ x_p = -\langle I\rangle\ln(1-p) \]

    第二步：算两端。

    \[ x_{0.05} = -\ln 0.95 \approx 0.0513 \]
    \[ x_{0.95} = -\ln 0.05 \approx 2.996 \]

    第三步：比值。

    \[ \frac{x_{0.95}}{x_{0.05}} = \frac{2.996}{0.0513} \approx 58 \]

    约 58 倍，即约 17.7 dB。5% 的时间里强度不到均值的 6%， 这解释了为什么这类目标会"突然出现又突然消失"。

    例题 2：相干累积的上限¶

    题目：时间相关半径 60 s，脉冲重复周期 1 s。 最多能相干累积多少个脉冲？再延长有什么后果？

    思路

    相干累积的时间不能超过相关半径。

    解答
    \[ N_{\max} = \frac{\tau_c}{T} = \frac{60}{1} = 60 \]

    约 60 个脉冲。超过之后信号相位已随机化，相干增益不再增长， 只是把已起伏的样本平均掉。所以"积分时间越长越好"在水声里不成立， 必须按 \(\tau_c\) 设计处理长度。

    例题 3：比较相干与非相干累积¶

    题目：\(N = 100\) 个脉冲。相干与非相干累积的信噪比增益各是多少？ 若相位完全随机，实际能得到多少？

    思路

    相干增益按 \(N\)（即 \(10\lg N\)），非相干按 \(\sqrt{N}\)（即 \(5\lg N\)）。

    解答

    相干（理想）：

    \[ 10\lg 100 = 20\ \text{dB} \]

    非相干：

    \[ 10\lg\sqrt{100} = 10\lg 10 = 10\ \text{dB} \]

    相位完全随机时，相干增益退化为 0 dB（甚至可能为负）， 实际只剩非相干的 10 dB —— 理想 20 dB 与实得 10 dB 相差一倍。 按理想相干增益设计会严重高估性能。

    例题 4：起伏导致的检测概率¶

    题目：某目标平均回波级比门槛高 6 dB。 若回波强度服从指数分布（SI = 1），检测概率是多少？

    思路

    \(P_d = P(I \gt I_0)\)，指数分布的均值为 \(\langle I\rangle\)； 6 dB 对应 \(I_0/\langle I\rangle = 10^{-0.6}\)。

    解答

    第一步：写出概率。

    \[ P_d = e^{-I_0/\langle I\rangle} \]

    第二步：代入数值。

    \[ I_0/\langle I\rangle = 10^{-0.6} \approx 0.251 \]
    \[ P_d = e^{-0.251} \approx 0.78 \]

    约 78%。若回波级恒定（无起伏），同样 6 dB 余量下检测概率接近 100%。 起伏把"稳过"变成了"约八成"，这就是水声系统必须按统计检测设计的原因。

    六、自测¶

    Q1 声传播起伏的根源为什么可以归结为"声速剖面的随机扰动"？ 三类不均匀性中哪一类主导，为什么？

    Q2 写出闪烁指数的定义。为什么 SI = 1 称为瑞利起伏？SI 大于 1 意味着什么？

    Q3 为什么说起伏是长时间累积的硬上限？相干与非相干累积各有什么取舍？

    Q4 某系统时间相关半径 20 s、重复周期 0.5 s。 求最大相干累积脉冲数。若强行累积到 4 倍，信噪比还会改善吗？

    小结¶

    概念 定义或取值 影响
    内波 振幅几 ~ 几十 m 声线随机弯折（主因）
    闪烁指数 \(\operatorname{Var}(I)/\langle I\rangle^2\)，典型值 1 强度起伏约 ±14 dB
    相位方差 随距离增大 相干增益损失
    时间相关半径 起伏自相关半宽，分钟 ~ 小时 相干累积上限
    空间相关半径 横向相关长度，几十 m ~ km 阵列孔径上限

    三条要点：

    1. 起伏根源是声速剖面的随机扰动，内波为主要扰动源。
    2. SI = 1 时强度波动约 17 dB，单次检测因此不可靠。
    3. 相干累积不能超过时间相关半径 —— "积分时间越长越好"不成立。
