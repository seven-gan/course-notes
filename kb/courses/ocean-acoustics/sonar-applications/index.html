    声纳方程的应用¶

    上一页把声呐方程写了出来，这一页要用它干活。

    声呐方程本身只是一条记账规则：把「发射 → 传播 → 反射 → 传播 → 接收」 这条链每一环的增益与损失折算到同一分贝尺度，再与检测门限比较。 会用这个方程的人，能从一个式子里读出三样东西：

    • 性能预报：给出设备参数与海况，算出最远能在多远发现目标；
    • 指标分配：给出战术上要求的距离，反推声源级至少要多大、 基阵增益至少要多少；
    • 敏感性判断：算出改哪一项最划算、改多少换回多少距离。

    这一页就把这三件事讲成可以照着做的步骤。

    这一页的核心问题

    给定声源级、目标强度、噪声级、指向性指数、检测阈这五个数， 怎么一步步算出作用距离？ 反过来，给定距离怎么把这五项指标分配下去？ 最后：哪一项改善 3 dB 对距离最有效？

    一、预报的两种问法与四步流程¶

    1.1 先把方程写成一个「求根问题」¶

    主动声呐方程（上一页已推出）是：

    \[ \text{SL} - 2\text{TL} + \text{TS} = \text{NL} - \text{DI} + \text{DT} \]

    其中每一项单位都是分贝。左边是回声级，右边是可检测的门限。 把传播损失的具体形式代进去，最常用的是

    \[ \text{TL}(r) = 20\lg r + \alpha r \]

    这里 \(r\) 的单位取千米，\(\alpha\) 是海水吸收系数（分贝每千米）。 代入后方程变成

    \[ \text{SL} - 2\left(20\lg r + \alpha r\right) + \text{TS} = \text{NL} - \text{DI} + \text{DT} \]

    关键观察：未知量 \(r\) 在式子里同时出现在 \(\lg r\) 和 \(r\) 两个位置， 这是一个超越方程，没有初等解。

    它不能像一元一次方程那样把 \(r\) 提出来，工程上有两条路 ——

    1. 数值解法：把 \(r\) 从 0.1 千米扫到 100 千米，找使两边相等的那个点；
    2. 图解法：把「实际的传播损失」与「允许的传播损失」各画一条线， 看交点（下一节就讲这个）。

    1.2 两种问法¶

    同一个方程两个方向问，得到两类完全不同的工程问题。

    问法 已知什么 求什么 什么时候用
    正问题：性能预报 声源级、目标强度、噪声级、指向性指数、检测阈、吸收系数 作用距离 \(r\) 论证「这套设备在这片海域能不能用」
    反问题：指标分配 要求的距离 \(r\)、环境与目标参数 声源级（或检测阈、指向性指数） 论证「要做到这个距离，设备至少要多大」

    两种问法都要做：正问题说明现状，反问题说明差距。

    1.3 四步流程¶

    把上面两件事做规范就是下面四步，顺序不能颠倒（理由见本节末警告）。

    第一步：定工作频率与带宽，得到吸收系数与噪声级。 频率一定，\(\alpha\) 就定了（频率越高吸收越大）；带宽一定，噪声级就定了。 注意噪声级必须包含带宽项：

    \[ \text{NL} = \text{NL}_0 + 10\lg(\Delta f) \]

    其中 \(\text{NL}_0\) 是噪声谱级，\(\Delta f\) 是接收机带宽。 最容易漏掉的就是 \(10\lg(\Delta f)\)。

    第二步：定目标姿态，得到目标强度。 目标强度随姿态角变化很大（正横最大、正首最小，可差二十多分贝）。 预报时必须取实际会遇到的最不利姿态，而非「典型值」。

    第三步：定检测性能要求，得到检测阈。 检测阈由检测概率、虚警概率和积累时间共同决定； 要求越严，检测阈越大，作用距离越短。

    第四步：解方程求出距离，再回头核对假设。 求得 \(r\) 之后，要检查它是否落在所选传播模型成立的范围内。 这一步最容易被省略，也最容易出问题。

    把四步整理成表，标出每步的失效后果：

    步骤 需要的输入 隐含的假设 假设不成立会怎样
    一、频率与带宽 工作频率、带宽、海况 噪声谱级在带内平坦、吸收系数按现场条件取值 噪声级偏小 → 距离被高估
    二、目标姿态 目标类型、预期姿态角 取的是最不利姿态 目标强度偏大 → 距离被高估
    三、检测性能 检测概率、虚警概率、积累时间 平均信噪比能代表检测性能 检测阈偏小 → 距离被高估
    四、求解与核对 前三步的全部结果 传播模型与实际海域一致 结果只在纸面上成立

    这张表说明：四步里任一步取值乐观，算出的距离都会偏大， 且方向一致 —— 所以误差会累积，不会互相抵消。

    下面把四步算一遍，看一组具体的数：

    • 噪声级 NL = 45.0 + 10*lg(100) = 65.0 dB
    • 允许的单程传播损失 TL_max = 85.00 dB
    • 数值解作用距离 r = 91.54 km
    • 该处的实际传播损失 TL = 85.00 dB

    注意这段输出：

    • 噪声级那一行：谱级 45 dB 加上带宽项 20 dB，才得到 65 dB。 少了这一项，距离会被高估好几千米；
    • 距离那一行：算出的传播损失与允许值相等，这正是「临界距离」的含义。

    四步的顺序不能颠倒

    很多人一上来就解方程，把噪声级、目标强度随手填个「典型值」， 先算出距离，再回头找参数凑这个结果。

    正确顺序是先定环境与目标，再解方程： 吸收系数、噪声级、目标强度恰恰是随频率、姿态、海况变化最大的三项。

    先解方程等于先给答案再凑条件，得到的距离不能作为设计依据。

    二、品质因数：把方程整理成两条线¶

    2.1 解出「允许的传播损失」¶

    上面用的是「代入传播损失再求根」。换个整理方式，把传播损失解到一边。

    对主动声呐，两边同时加上 \(2\text{TL}\)、再移项：

    \[ 2\text{TL} = \text{SL} + \text{TS} - \text{NL} + \text{DI} - \text{DT} \]

    两边同除 2：

    \[ \text{TL}_{\max} = \frac{\text{SL} + \text{TS} - \text{NL} + \text{DI} - \text{DT}}{2} \]

    被动声呐没有目标强度这一项，也不走双程：

    \[ \text{TL}_{\max} = \text{SL} - \text{NL} + \text{DI} - \text{DT} \]

    右边这个量就叫品质因数（Figure of Merit，简称 FOM）。

    物理含义：FOM 表示的是 —— 在给定的设备条件与环境下，这套系统还能承受多少单程传播损失， 也就是系统对传播损失的预算额度。

    2.2 判据：一条曲线与一条直线¶

    有了 FOM，判据可以写成一句话：

    \[ \text{FOM} \ge \text{TL}(r) \]

    两个量脾气很清楚：

    • \(\text{TL}(r)\) 是实际的传播损失，随距离单调增加；
    • FOM 是允许的传播损失，与距离无关，是一条水平直线。

    系统能发现目标，就是这条曲线始终在直线下方； 两者相等的那一点，就是作用距离。

    图像解法一眼就能看出余量在哪、距离由谁决定：

    2.3 FOM 的三种用法¶

    FOM 不只用来判「能不能发现」，它是一把反复可用的尺子：

    用法 做法 得到什么
    判性能 把 FOM 与所在海域的实际传播损失比较 能不能发现、还富余多少分贝
    给指标 由要求的距离算出传播损失，再要求 FOM 不低于它 声源级或指向性指数的最低要求
    换海域 保持 FOM 不变，换一套传播条件 同一设备在不同海域的距离差多少

    第三种用法最容易被忽略：同一部声呐，在浅海与深海的距离可能差好几倍， 但这是传播损失曲线换了，不是设备变了。

    下面把两条线的数值算出来，看余量怎么随距离变负：

    • 主动 FOM = (SL + TS - NL + DI - DT)/2 = 85.00 dB

    • 被动 FOM = SL - NL + DI - DT = 82.00 dB

    • 距离 r / km 实际 TL / dB FOM - TL / dB

    • r = 10 TL = 25.00 60.00
    • r = 30 TL = 44.54 40.46
    • r = 60 TL = 65.56 19.44
    • r = 90 TL = 84.08 0.92
    • r = 120 TL = 101.58 -16.58

    怎么读这张表：余量在 90 千米处只剩 0.92 分贝，120 千米变为负， 所以作用距离落在 90 与 120 千米之间，与上一节数值解 91.8 千米一致。

    FOM 不是设备的固定指标

    FOM 里含有噪声级与检测阈，这两项都随环境与检测要求变。

    同一部设备：海况差时噪声级升高、检测概率要求高时检测阈增大， FOM 会明显下降。所以「这部设备 FOM 等于 95 分贝」这种说法， 必须带上环境与检测条件才成立。

    把 FOM 当成铭牌上印死的数字，是预报出错的一个常见来源。

    三、参数敏感性：为什么是「四次方」¶

    3.1 距离对不同参数的敏感度不一样¶

    主动声呐里传播损失含 \(20\lg r\)，而方程里是 \(2\text{TL}\)， 合起来距离项是 \(40\lg r\) —— 这就是四次方关系的来源。

    于是若某一项单独改变了 \(\Delta\)（分贝），距离的变化满足

    \[ 40\lg\frac{r_2}{r_1} = \Delta \qquad\Longrightarrow\qquad \frac{r_2}{r_1} = 10^{\Delta/40} \]

    被动声呐只走单程、传播损失含 \(20\lg r\)，所以

    \[ \frac{r_2}{r_1} = 10^{\Delta/20} \]

    怎么读这两个式子：主动声呐里，任何一项改善都要被双程摊掉一半， 所以主动要 12 分贝才能翻倍，被动只要 6 分贝。

    3.2 五项各改善 3 分贝，距离改善多少¶

    把五项分别代入上式，结果如下：五项在方程里的地位完全等价， 距离改善的倍数也完全一样。

    改善项 等效增益 主动作用距离 被动作用距离
    声源级 SL 提高 3 dB +3 dB 1.19 倍（+19%） 1.41 倍（+41%）
    目标强度 TS 提高 3 dB +3 dB 1.19 倍（+19%） 无此项
    指向性指数 DI 提高 3 dB +3 dB 1.19 倍（+19%） 1.41 倍（+41%）
    噪声级 NL 降低 3 dB +3 dB 1.19 倍（+19%） 1.41 倍（+41%）
    检测阈 DT 降低 3 dB +3 dB 1.19 倍（+19%） 1.41 倍（+41%）

    这张表最重要的结论是「3 分贝不解决问题」： 单项改善 3 分贝，主动距离只增加 19%。

    改善项 等效增益 主动距离倍数 被动距离倍数
    SL 提高 3 +3 dB 1.189 1.413
    TS 提高 3 +3 dB 1.189 1.413
    DI 提高 3 +3 dB 1.189 1.413
    NL 降低 3 +3 dB 1.189 1.413
    DT 降低 3 +3 dB 1.189 1.413

    同样的增益，换成更大的数值看看：

    • 增益 3 dB → 主动 1.189 倍，被动 1.413 倍
    • 增益 6 dB → 主动 1.413 倍，被动 1.995 倍
    • 增益 12 dB → 主动 1.995 倍，被动 3.981 倍
    • 增益 24 dB → 主动 3.981 倍，被动 15.849 倍

    输出证实了这一规律：主动声呐 12 分贝翻倍，被动声呐 6 分贝翻倍。

    3.3 五项在工程上的代价并不平等¶

    上面的表容易让人产生错觉：既然五项等价，随便挑一项改就行。 工程上完全不是这样 —— 这五项实现难度差别极大。

    参数 改善手段 主要代价 上限来自哪里
    声源级 SL 加大发射功率 功耗、体积、发热 换能器空化阈值
    目标强度 TS 不能改变（目标自身属性） 只能改工作频段去适应 由目标决定
    指向性指数 DI 增大基阵孔径、增多阵元 安装尺寸、拖曳与艇体限制 平台可用尺寸
    噪声级 NL 远离噪声源、降速、改进部署位置 航速与部署位置受限 自身噪声与本舰速度
    检测阈 DT 延长积累时间、放宽门限 反应变慢、虚警率上升 目标机动与虚警指标

    这张表的用法：当预报结果不满足要求时， 不要按方程顺序去找参数，而要按代价从低到高去改。

    改参数的正确顺序

    先看哪一项「还没到极限」，再看哪一项「代价最小」。

    经验顺序通常是：先降噪声级（最便宜，只要改部署与航速）， 再增大指向性指数（只要平台放得下基阵）， 最后才动声源级（最贵，直接换发射机）。

    反过来做 —— 一上来就加大发射功率 —— 往往既花钱又收效有限。

    四、几种典型场景的设计取舍¶

    不同任务对五项参数的偏好完全不同。下表先给总览，后面逐条展开。

    场景 典型频段 带宽 目标强度来源 主导制约 核心取舍
    远程警戒 很低频（几百赫兹） 窄 正横与正首差别极大 海水吸收与环境噪声 用低频换距离，牺牲分辨力
    主动搜索 中频（几千赫兹） 中等 随姿态起伏明显 混响与目标起伏 加带宽换分辨力，牺牲距离
    近程成像 高频（几百千赫兹） 很宽 几何区散射 吸收极大 只在很近处有效，换清晰成像
    被动监听 宽频带 很宽 无此项 自身噪声与目标安静化 远离自噪声，换低噪声级

    4.1 远程警戒：低频换距离¶

    远程警戒的方程里，吸收系数是最大杀手：它在四次方关系里双向计入， 距离一远，吸收对传播损失的贡献很快超过扩展损失。

    所以这类系统的设计逻辑是：把频率压到最低，用分辨力换距离。 代价是低频时基阵要做得很大才有足够指向性指数， 且低频目标强度往往更小、更依赖目标姿态。

    4.2 主动搜索：双程的代价¶

    主动搜索的每次照射都要走两趟，所以与距离有关的损失都翻倍，带来两个后果：

    • 同一项参数改善，主动声呐只换来被动声呐一半的「对数距离」；
    • 混响也是双程量，近距离时常压过噪声，成为新的限制。

    设计上的取舍是：加带宽能提高距离分辨力、抑制混响， 但带宽变宽会抬高噪声级，距离下降，两者要平衡。

    4.3 近程成像：吸收不再是问题，分辨力才是¶

    高频系统里吸收系数可达每千米几十分贝，听着可怕， 但作用距离本来只有几十米，总吸收损失并不大。

    于是设计重点完全转移：频率越高、带宽越宽，成像越清晰。 方程在这里主要用来确认「这个距离上还有多少余量」， 而不是把距离推到极限。

    4.4 被动监听：方程里没有目标强度¶

    被动声呐方程是

    \[ \text{SL} - \text{TL} = \text{NL} - \text{DI} + \text{DT} \]

    注意两点：没有目标强度，也没有双程。 所以被动系统的性能几乎完全由三件事决定：目标的辐射噪声、 本舰自身噪声、接收基阵的指向性指数。

    这也是拖曳阵存在的理由：把基阵拖离本舰， 就能降噪声级、提指向性指数，两项同时受益。

    五、常见误用与注意事项¶

    下表列出预报中最常见的几类错误及其后果方向。

    误用 表现 后果 正确做法
    把平均信噪比当可靠检测 用平均值判定「能发现」 实际检测概率远低于预期 按检测概率与虚警概率要求取检测阈
    漏掉噪声带宽项 直接用噪声谱级当噪声级 距离被明显高估 噪声级等于谱级加带宽项
    忽略目标姿态 只取一个「典型」目标强度 目标转向时距离骤降 取最不利姿态，必要时做姿态分布统计
    忽略海况 用平静海面的噪声级与吸收系数 恶劣海况下距离大幅缩水 按最不利季节与海况取值
    混用传播模型 在浅海用深海球面扩展公式 结论与实测差几倍 按海域选择传播模型并核对适用范围

    下面单独说清最易出错的三条。

    平均信噪比不等于可靠检测

    声呐方程算出的信噪比是一个平均值。 但实际回波是起伏的：同一目标、同一距离，不同时刻的信噪比可差十几分贝。

    于是会出现：按平均值算出的余量还有好几分贝，实际检测概率却只有几成。

    正确做法：检测阈必须按要求的检测概率与虚警概率来定， 而非按平均值定。要求越严，检测阈越大，距离越短。

    噪声带宽项不能漏

    噪声级是「整个接收带宽内的总噪声」，噪声谱级是「每赫兹的噪声」，关系是

    \[ \text{NL} = \text{NL}_0 + 10\lg(\Delta f) \]

    漏掉那一项，等于把噪声级少算了十几到二十分贝， 作用距离被高估好几千米（数值例子见第一节）。

    反方向也要注意：带宽收窄确实能降低噪声级， 但会牺牲距离分辨力，还可能不匹配信号带宽。

    目标姿态与海况必须按最不利取值

    目标强度的姿态依赖可达二十多分贝， 用四次方关系换算，就是距离打两折到五折。

    海况同理：风浪变大 → 环境噪声升高、海面散射增强 → 作用距离下降。

    预报的用途是「保证能用」，取值原则应是按最不利条件取， 而非按平均值取。平均值只能做统计评估，不能做单次任务规划。

    六、例题¶

    例题 1：由品质因数求作用距离¶

    题目：某主动系统声源级 200 dB、目标强度 10 dB、噪声级 62 dB、 指向性指数 18 dB、检测阈 8 dB，吸收系数 0.4 dB/km。 求作用距离（先用只含扩展损失的近似，再判断吸收的影响方向）。

    思路

    先算允许的单程传播损失（即品质因数），令它等于 \(20\lg r\) 解出距离； 再代入吸收项，判断真实距离比它大还是小。

    解答

    第一步：求品质因数。

    \[ \text{FOM} = \frac{200 + 10 - 62 + 18 - 8}{2} = \frac{158}{2} = 79\ \text{dB} \]

    第二步：忽略吸收，解距离。

    \[ 20\lg r = 79 \implies \lg r = 3.95 \implies r = 10^{3.95} \approx 8.9\times10^{3}\ \text{km} \]

    这个数显然不合理 —— 说明吸收项绝对不能忽略。

    第三步：带上吸收重算。

    解 \(20\lg r + 0.4r = 79\)。代入 \(r = 100\)：

    \[ 20\lg 100 + 0.4\times100 = 40 + 40 = 80\ \text{dB} \]

    比 79 略大，说明根在 100 千米以内。代入 \(r = 95\)：

    \[ 20\lg 95 + 0.4\times95 \approx 39.55 + 38 = 77.6\ \text{dB} \]

    比 79 小。所以根落在 95 与 100 之间。

    答案：约 97 千米（吸收让距离从「几百千米」降到不足一百千米）。

    在海水中，吸收项是决定远程性能的关键项， 只保留扩展损失会给出完全错误的量级。

    例题 2：由距离反求声源级¶

    题目：要求主动系统在 30 千米处仍能发现目标。 已知目标强度 12 dB、噪声级 63 dB、指向性指数 20 dB、检测阈 9 dB， 吸收系数 0.45 dB/km。求声源级至少要多大。

    思路

    反问题：先由距离算出实际传播损失，再要求品质因数不小于它， 最后反解声源级。

    解答

    第一步：算 30 千米处的单程传播损失。

    \[ \text{TL} = 20\lg 30 + 0.45\times30 = 29.54 + 13.5 = 43.04\ \text{dB} \]

    第二步：要求品质因数不小于它。 品质因数的定义是

    \[ \text{FOM} = \frac{\text{SL} + \text{TS} - \text{NL} + \text{DI} - \text{DT}}{2} \ge 43.04 \]

    第三步：反解声源级。

    \[ \text{SL} \ge 2\times43.04 - \text{TS} + \text{NL} - \text{DI} + \text{DT} \]
    \[ \text{SL} \ge 86.08 - 12 + 63 - 20 + 9 = 126.08\ \text{dB} \]

    答案：声源级至少要 126.1 dB。

    反问题的价值在于给出指标下限。 若现有设备只有 120 分贝，缺口 6 分贝 —— 按四次方关系，这 6 分贝对应距离降到约 1.41 分之一， 即约 21 千米。这就是「指标分配」的用法。

    例题 3：五项各改善 3 分贝，谁最划算¶

    题目：某主动系统的作用距离是 20 千米。 现在有四种可选改造：声源级提高 3 分贝、指向性指数提高 3 分贝、 噪声级降低 3 分贝、检测阈降低 3 分贝。 它们各自能把距离提高到多少？如果只能选一项，怎么选？

    思路

    这四项对距离的作用在方程里完全相同，所以先用四次方关系 算出统一的距离倍数，再按工程代价来排序。

    解答

    第一步：算距离倍数。

    \[ \frac{r_2}{r_1} = 10^{3/40} \approx 1.189 \]

    第二步：算新距离。

    \[ r_2 = 20\times1.189 \approx 23.8\ \text{km} \]

    答案：四项改造的效果完全一样，都只能把距离从 20 千米提到约 23.8 千米。

    第三步：按代价排序。 既然效果相同，就看哪一项最容易做到：

    改造项 实现难度 主要代价 排序
    噪声级降低 3 dB 低 改部署位置、降低航速 最优
    指向性指数提高 3 dB 中 基阵尺寸增大 次优
    检测阈降低 3 dB 中 虚警率上升、反应变慢 次优
    声源级提高 3 dB 高 功耗、体积、空化风险 最差

    声呐方程只回答「改多少分贝」， 不回答「怎么改」，后者要靠工程代价表判断 —— 这正是本节例题强调的重点。

    例题 4：漏掉带宽项会高估多少距离¶

    题目：某系统噪声谱级 40 dB、接收带宽 1000 Hz。 预报时若误把谱级直接当噪声级用，作用距离会被高估多少倍？ 其余参数：声源级 205 dB、目标强度 14 dB、指向性指数 21 dB、 检测阈 8 dB、吸收系数 0.4 dB/km。

    思路

    先算出「正确/错误噪声级」两个品质因数，再看距离倍数。 噪声级在品质因数里要除以 2，所以它的误差只贡献一半的传播损失。

    解答

    第一步：正确的噪声级。

    \[ \text{NL} = 40 + 10\lg 1000 = 40 + 30 = 70\ \text{dB} \]

    第二步：两个品质因数。

    \[ \text{FOM}_{\text{正确}} = \frac{205 + 14 - 70 + 21 - 8}{2} = \frac{162}{2} = 81\ \text{dB} \]
    \[ \text{FOM}_{\text{错误}} = \frac{205 + 14 - 40 + 21 - 8}{2} = \frac{192}{2} = 96\ \text{dB} \]

    第三步：传播损失相差 15 分贝，换成距离倍数。

    \[ \frac{r_{\text{错误}}}{r_{\text{正确}}} = 10^{15/40} \approx 2.37 \]

    答案：距离被高估约 1.37 倍，也就是多算了百分之三十七。

    噪声级差 30 分贝，作用距离就多算了三成以上。 而 30 分贝的带宽项往往只是改一个参数的事， 越不起眼的一项，越容易在预报里被漏掉。

    小结¶

    要点 内容 关键数字或提醒
    正问题 已知五项参数，解作用距离 超越方程，须数值解或图解
    反问题 已知距离，求声源级等指标下限 结果是下限，不是标准值
    四步流程 频率带宽 → 目标姿态 → 检测要求 → 求解核对 顺序不可颠倒
    品质因数 允许的单程传播损失 主动除以 2，被动不除
    判据 品质因数不低于实际传播损失 两者相等处即作用距离
    四次方关系 主动 40 分贝距离减半 12 dB 翻倍；被动 6 dB 翻倍
    敏感性 五项在方程中地位等价 3 dB 只换 19% 距离
    工程代价 五项实现难度差别极大 先降噪声级，最后动声源级
    场景取舍 远程低频、近程高频、被动靠拖曳 分辨力与距离互相牵制
    常见误用 平均信噪比、漏带宽项、忽略姿态与海况 都会让距离被高估

    三条最该带走的结论：

    1. 先定环境与目标，再解方程 —— 反过来做等于先给答案再凑条件；
    2. 品质因数是「传播损失预算」 —— 换成两条线的交点，距离一眼可见；
    3. 五项参数在方程里等价，在工程上不等价 —— 效果一样时，永远选代价最小的那一项。
