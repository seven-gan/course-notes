    水声观测与信号处理技术¶

    前面几页讲的是「声波怎么传播」。这一页讲反过来的两件事：

    用声波去"看"海洋，以及怎么从收到的声里提取信息。

    这是水声学里最活跃的方向，也是这一章的主线。挑五个主题展开： 匹配场处理、海洋声学层析、矢量水听器、三维声传播、北极水声学。

    一、匹配场处理（MFP）¶

    1.1 为什么常规波束形成不够用¶

    常规做法：用阵列测「声波从哪个方向来」—— 假设声波以直线从声源走到阵列。

    浅海的问题：声波不走直线 ⚠

    现象 后果
    海底/海面多次反射 同一目标有多条不同方向的到达路径
    声速剖面折射 路径弯曲，方向与几何方向不符
    多途干涉 阵列上收到的是复杂干涉图案，不是单一平面波

    结果：常规波束形成的方位估计会偏，甚至完全失效。

    1.2 核心思想：拿「整个场」去比¶

    匹配场处理的关键转变：

    不再问"波从哪个方向来"，而问"假设声源在某个位置， 我算出的声场长什么样？跟实测的像不像？"

    用数学写出来就是一个相关：

    \[ B(\boldsymbol{r}_s) = \frac{\left|\sum_n p_{\text{meas}}(z_n)\,p_{\text{model}}^{*}(z_n;\boldsymbol{r}_s)\right|^2} {\left(\sum_n |p_{\text{meas}}|^2\right)\left(\sum_n |p_{\text{model}}|^2\right)} \]

    逐项读这个式子：

    符号 含义
    \(p_{\text{meas}}(z_n)\) 第 \(n\) 个水听器实测到的声压
    \(p_{\text{model}}(z_n;\boldsymbol{r}_s)\) 假设声源在 \(\boldsymbol{r}_s\) 时，模型算出的声压
    \(B\) 两者的归一化相关（0 到 1）
    取 \(B\) 最大的 \(\boldsymbol{r}_s\) 就是估计的声源位置 ✓

    为什么这叫「匹配场」：把模型的场与实测的场做匹配 ✓

    一句话抓住核心

    匹配场处理 = 用一个准确的声场模型当"模板库"， 把实测声场与每个候选位置的模板做相关，取最像的那个。 它同时利用了幅度与相位信息，所以比只利用方向的 常规波束形成强得多。

    1.3 依赖与难点¶

    它依赖什么（这条决定了它的工程难度）：

    依赖 要求
    声场模型 必须准确（这就要用 计算海洋声学 的方法）
    声速剖面 必须实测且够准
    海底参数 必须知道（声速、密度、衰减）
    阵列 需要垂直阵或大孔径阵（要采样声场的深度结构）

    匹配场处理对环境参数极其敏感（这是它的根本难点）

    模型声场对声速剖面、海底参数高度敏感 ⚠ 参数稍有偏差，相关峰就可能偏出很远，甚至完全消失。

    所以实际系统通常要同时反演环境参数（称为「环境聚焦」）—— 用一个优化过程，让环境参数与声源位置一起被估出来。

    这让计算量大幅上升，也是 MFP 从理论走向实用最主要的障碍。

    import numpy as np


def model_field(z, z_s, c=1500.0, H=100.0, k_modes=4):
    """简化的浅海简正波模型场（用于演示"相关峰的形状"）。

    只取前 k_modes 个模式的近似叠加，不做严格归一化 ——
    目的是展示「场随参数变化」的敏感度，而非精确声场。
    """
    kz_s = (np.arange(1, k_modes + 1) - 0.5) * np.pi / H
    out = np.zeros_like(z, dtype=complex)
    for m in range(1, k_modes + 1):
        out += (np.sin(kz_s[m - 1] * z_s) * np.sin(kz_s[m - 1] * z)) / m
    return out


z = np.linspace(1.0, 99.0, 60)      # 60 元垂直阵
z_true = 35.0                        # 真实声源深度
p_meas = model_field(z, z_true)      # 实测（模型生成 + 无噪声）

print("扫描候选深度，看相关值：")
print("候选深度(m)".ljust(14) + "相关系数")
best, best_v = None, -1
for zs in np.arange(5.0, 96.0, 5.0):
    pm = model_field(z, zs)
    num = abs(np.vdot(pm, p_meas)) ** 2
    den = (np.vdot(pm, pm).real * np.vdot(p_meas, p_meas).real)
    v = num / den
    if v > best_v:
        best_v, best = v, zs
    mark = "  <- 峰值" if abs(zs - z_true) < 1e-6 else ""
    print(("%.0f" % zs).ljust(14) + ("%.4f" % v) + mark)

print()
print("估计深度 = %.0f m（真值 %.0f m）" % (best, z_true))

    二、海洋声学层析¶

    2.1 用声波当「温度计」¶

    核心想法：声速主要取决于温度（见 海水的声学特性）， 所以测出声速剖面就等于测出温度剖面 ✓

    问题是：怎么"测"几十上百公里外的声速？

    答：用传播时间：

    \[ \tau_i = \int_{\Gamma_i} \frac{\mathrm{d}s}{c(\boldsymbol{r})} \]

    （\(\Gamma_i\) 是第 \(i\) 条声线的路径）

    若测到多条路径的 \(\tau_i\)，就得到一组方程 —— 反演 \(c(\boldsymbol{r})\)， 进而得到温度 ✓

    这就是「层析」（tomography，断层成像）：用穿透式的多条路径 反演介质的内部结构。

    2.2 与医学 CT 的类比¶

    医学 CT 海洋声学层析
    穿透物 X 射线 声波
    观测量 衰减 传播时间
    反演什么 组织密度 声速（= 温度）
    路径 直线（近似） 曲线，且依赖待求的 \(c\) ⚠

    最后一行是关键差别：CT 里射线走直线（已知）， 而海洋声学层析里射线路径本身取决于要求解的声速 —— 这是个非线性反问题，必须迭代 ✓

    2.3 观测量有多小¶

    层析的信号极小 —— 这是它的技术门槛

    声速变化 1 ℃ 约对应 4.5 m/s。在 100 km 的路径上， 这带来的传播时间变化是几十毫秒（见例题 4）⚠

    要在海洋环境中测准几十毫秒的差异，需要：

    · 高精度时钟（原子钟级） · 精确的声源与接收同步 · 对路径的准确估计（否则路径误差比信号还大）

    所以层析从提出到实用用了很长时间 —— 难点不在原理，在精度。

    import numpy as np

# 演示：把"传播时间"对声速变化线性化，得到层析方程组
# tau_i = sum_j (L_ij / c_j)   —— L 是第 i 条路径在第 j 个网格里的长度

rng = np.random.default_rng(42)
n_ray, n_cell = 6, 5
# 构造一个路径长度矩阵（每行一条射线，每列一个网格）
L = rng.uniform(2.0, 20.0, size=(n_ray, n_cell))     # km
c0 = np.full(n_cell, 1500.0)                          # 参考声速

tau0 = (L / c0).sum(axis=1)
print("参考状态下的传播时间（s）：")
for i, t in enumerate(tau0):
    print("  射线 %d: %.6f" % (i + 1, t))

# 第 3 个网格升温 1 ℃ -> 声速 +4.5 m/s
c1 = c0.copy()
c1[2] += 4.5
tau1 = (L / c1).sum(axis=1)

print()
print("第 3 个网格升温 1 ℃ 后的时间变化：")
print("射线".ljust(8) + "变化(ms)")
for i in range(n_ray):
    print(("%d" % (i + 1)).ljust(8) + "%+.3f" % ((tau1[i] - tau0[i]) * 1000))

print()
print("结论：单条射线的变化只有几毫秒 —— 需要极高计时精度 ⚠")

    三、矢量水听器¶

    3.1 传统只测「声压」¶

    传统水听器测的是标量声压 \(p\)。这带来两个限制：

    限制 后果
    只有标量 单点测不出方向（一个数没有方向信息）⚠
    低频灵敏度低 尺寸远小于波长时，输出正比于频率（声压梯度小）

    3.2 同时测「质点振速」¶

    矢量水听器（vector sensor）同时测：

    \[ \text{声压 } p \qquad\text{与}\qquad \text{质点振速 }\boldsymbol{v} = (v_x, v_y, v_z) \]

    多出来的 \(v\) 带来三件事：

    好处 为什么
    单点测向 \(p\) 与 \(v\) 的乘积给出声强矢量，直接指向声源 ✓
    低频性能好 \(v\) 的灵敏度不随频率下降（与 \(p\) 不同）
    抗混响能力 可分辨声源的方向性（混响各方向都有）

    3.3 声强与方向¶

    声强矢量（复数声强）定义为：

    \[ \boldsymbol{I} = \frac{1}{2}\operatorname{Re}\left[\,p^{*}\boldsymbol{v}\,\right] \]

    方向就是声源方向 ✓ —— 这是单点测向的数学基础。

    为什么这对低频特别重要：低频时波长大、阵列做不长（空间受限）， 但单点矢量水听器不需要阵列就能测向 ✓

    矢量水听器最实用的价值

    它把「测向」从需要大孔径阵列变成可以用单个小传感器。 对小型平台（如小型潜航器、浮标）特别有价值。

    代价是：振速传感器的工程实现难（要避免流噪声干扰）， 这是它没能完全取代传统阵的原因。

    四、三维声传播¶

    4.1 什么时候必须考虑三维¶

    大多数水声模型假设声速只随深度变（二维问题）。 但有些情形水平方向的变化不能忽略：

    情形 为什么需要三维
    倾斜海底（大陆坡） 声线遇到斜面会侧向折射
    内波 / 锋面 存在水平声速梯度
    平行于海底斜坡传播 侧向能量输运显著
    海山、峡谷 横向散射与绕射

    4.2 代价¶

    计算量：

    \[ \text{三维} \approx \text{二维} \times N_{\text{横向网格数}} \]

    举例：横向 50 个网格 → 计算量是二维的 50 倍 ⚠

    所以工程策略通常是：

    1. 先用二维模型快速扫参数
    2. 只在怀疑水平变化重要时，才升到三维
    3. 或用「N×2D」近似（沿路径做多个二维切片）

    4.3 一个判据：水平变化有多"慢"¶

    可用绝热近似（模式沿路径缓慢变化、不耦合）的条件是：

    \[ \left|\frac{\partial k_r}{\partial r}\right| \ll k_r^2 \]

    直观含义：模式的水平波数沿路径变化得足够慢， 模式之间不会交换能量 ✓

    若变化快（如跨越锋面、陡峭地形）→ 模式耦合必须考虑 ⚠

    五、北极水声学¶

    5.1 为什么要单独讲¶

    北极的海面不是「海面」 —— 它上面盖着冰。

    常规海面 北极冰面
    边界类型 压力释放（\(p = 0\)） 近似刚性（振速为零）
    反射相位 反相 同相
    后果 不同干涉图案 完全不同的声道结构 ⚠

    这个差别很大：常规海面让声波「反相反射」， 而冰面近似「同相反射」—— 这直接改变了近表面声道的性质。

    5.2 北极的典型声速剖面¶

    北极的声速剖面有独特结构：

    层 特点 原因
    表层（0–50 m） 温度接近冰点、盐度决定声速 融冰淡水与海水混合
    中层 声速随深度增加 盐度升高
    深层 压力主导 与其它海域类似

    关键：表层是正梯度（声速随深度增）—— 声线向下弯，声能离开表面。

    这与温带海域相反（温带表层通常是负梯度）。

    5.3 北极的特殊声学现象¶

    现象 成因
    冰下声道 冰面 + 表层正梯度共同作用
    冰层噪声 冰裂、冰脊摩擦
    冰下反射损失 依冰的粗糙度与厚度而变
    半声道效应 声源在冰下时能量被"压"在冰面附近

    北极实验的工程难度极高

    冰区作业需要破冰船、冰站、专门的耐冰设备；布放与回收 都受冰情限制 ⚠

    所以北极水声数据远少于其它海域 —— 这也意味着北极的声学模型缺少验证数据， 是当前研究的活跃方向。

    六、例题¶

    例题 1：为什么常规波束形成在浅海会失效¶

    题目：某浅海环境，目标距离 10 km。 声波从目标到阵列主要有 5 条到达路径，各路径的到达角相差近 30°。 用常规波束形成估计方位，问题在哪？

    思路

    常规波束形成假设「一个方向、一条路径」。 多条路径会怎样？

    解答

    第一步：常规波束形成的假设。

    它假设阵列收到的是单一平面波： \(p(z_n) = A e^{-jkz_n\sin\theta}\) —— 一个方向 \(\theta\)，其余都是平面波前。

    第二步：实际情况。

    5 条路径各自有不同的到达角，叠加后的场不是平面波。 用单一 \(\theta\) 去拟合这个复杂图案，得不到正确结果。

    第三步：后果。

    表现 原因
    方位估计偏差 多途使等效到达角偏移
    主瓣展宽/分裂 多途干涉产生假峰 ⚠
    增益损失 能量分散在多个方向

    这说明什么：这正是匹配场处理的动机 —— 不再假设单一路径，而是用完整声场模型 ✓

    例题 2：匹配场为什么要"环境聚焦"¶

    题目：某匹配场系统用了一个声速剖面估计值， 其跃层深度比真实值深了 20 m。估计结果可能怎样？

    思路

    模型场与实测场失配。相关峰的位置取决于哪个"假设声源位置" 能让模型场最像实测场。

    解答

    第一步：失配的后果。

    模型场用的是错误的剖面 → 算出的声场与实测不同 → 相关值整体下降。

    第二步：峰值位置。

    更麻烦的是：某个"错误的位置"可能碰巧让模型场更像实测场 —— 于是峰值偏移到错误位置 ⚠

    第三步：应对。

    环境聚焦：把环境参数也当作未知量， 用优化一起估计（声源位置 + 跃层深度 + 海底参数…）。

    这说明什么：MFP 的精度不取决于算法本身， 而取决于环境参数准不准。这也是它工程实现难的根本原因。

    例题 3：矢量水听器单点测向的原理¶

    题目：一个矢量水听器测得 \(p = 1.0\)（相对单位）， 质点振速 \(v_x = 0.6\)、\(v_y = 0.8\)（同相）。 求声强矢量的方向。

    思路

    同相时声强正比于 \(p \cdot \boldsymbol{v}\)， 方向就是 \((v_x, v_y)\) 的方向。

    解答

    第一步：声强矢量。

    同相情形下：

    \[ \boldsymbol{I} \propto p\,\boldsymbol{v} = 1.0\times(0.6,\ 0.8) \]

    第二步：方向。

    \[ \theta = \arctan\frac{0.8}{0.6} = \arctan 1.333 \approx 53.1° \]

    答案：方位角约 53.1°（相对 \(x\) 轴）✓

    第三步：验证幅度。

    \[ |\boldsymbol{v}| = \sqrt{0.6^2 + 0.8^2} = 1.0 \]

    这说明什么：单个传感器就能给出方向， 不需要阵列的空间孔径 ✓ 这是矢量水听器在低频、小平台上的核心价值。

    例题 4：层析的时间分辨率要求¶

    题目：路径长 200 km、平均声速 1500 m/s。 要求分辨 0.2 ℃ 的温度变化（对应声速约 0.9 m/s）。 计时精度至少要多少？

    思路

    \(\tau = L/c\)，求 \(\mathrm{d}\tau\) 与 \(\mathrm{d}c\) 的关系。

    解答

    第一步：求微分关系。

    \[ \tau = \frac{L}{c} \implies \mathrm{d}\tau = -\frac{L}{c^2}\,\mathrm{d}c \]

    第二步：代入。

    \[ |\mathrm{d}\tau| = \frac{200000}{1500^2}\times0.9 = 0.0889\times0.9 \approx 0.08\ \text{s} \]

    答案：约 80 ms。

    第三步：倒过来想。

    要"分辨" 0.2 ℃，计时误差必须远小于 80 ms —— 通常要求 1 ms 量级或更好 ⚠

    这说明什么：层析对计时精度的要求非常苛刻。 这是它的核心工程挑战（而非理论难题）。

    小结¶

    技术 解决什么 核心思想 主要难点
    匹配场处理 浅海多途下定位 用完整声场模型做相关 对环境参数极敏感 ⚠
    海洋层析 大范围测温度剖面 用传播时间反演声速 计时精度（信号只几十 ms）
    矢量水听器 单点测向、低频性能 同时测声压与质点振速 振速传感器抗流噪声
    三维声传播 水平变化不可忽略时 不解耦地算全三维 计算量 × 几十倍 ⚠
    北极水声 冰下环境 冰面近刚性边界 缺数据、作业难

    三条最该带走的结论：

    1. 匹配场处理的核心是「用模型场匹配实测场」 —— 精度取决于环境参数，所以要环境聚焦 ✓
    2. 层析用传播时间反演温度，难点在毫秒级计时精度 ⚠
    3. 矢量水听器把测向从"要孔径"变成"要一个点" ✓
