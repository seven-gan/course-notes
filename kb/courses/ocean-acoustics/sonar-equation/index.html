    声呐方程¶

    这一页是整个水声工程的记账本。它解决一个问题：

    在给定的发射功率和设备条件下，我最多能在多远发现目标？

    先说清楚为什么必须有这样一个方程。

    一、为什么需要一个「方程」¶

    水声里要判断「能不能发现目标」，直觉上要看很多因素： 发射多大功率、海水吸收多少、目标反射多强、环境多吵、接收机多灵敏……

    问题在于这些量的单位五花八门：功率是瓦特、距离是米、 吸收是「每公里损失多少」。直接比大小根本比不了。

    解决办法：全部换算成分贝（级），变成同一个尺子上的加减法

    这就是声呐方程的本质 —— 一本用分贝记账的账本：

    \[ \underbrace{\text{发出去多少}}_{\text{声源级 SL}} \;-\; \underbrace{\text{路上损失多少}}_{\text{传播损失 TL}} \;+\; \underbrace{\text{目标送回来多少}}_{\text{目标强度 TS}} \;\ge\; \underbrace{\text{低于这个就听不见}}_{\text{检测阈 DT}} \]

    后面每一节就是把这几项各自讲清楚。

    要点

    声呐方程是能量守恒的分贝写法： 把「发射 → 传播 → 反射 → 传播 → 接收」这条链上每一环的 增益与损失用同一个单位相加减，最后与门限比较。

    二、级（level）的定义：为什么用分贝¶

    2.1 声压级的定义¶

    水声中不用声压本身，用声压级：

    \[ \text{SPL} = 20\lg\frac{p}{p_{\text{ref}}} \qquad p_{\text{ref}} = 1\ \mu\text{Pa} \]

    为什么用 \(1\ \mu\text{Pa}\)：它是水声中约定的参考声压 （在空气里习惯用 \(20\ \mu\text{Pa}\)，两者不能混用 ⚠）。

    为什么用 \(20\lg\) 而不是 \(10\lg\)：因为声功率正比于声压的平方， 用 \(10\lg\) 定义功率级、\(20\lg\) 定义声压级，两者数值一致。 这样换算时不必反复乘 2

    2.2 分贝是「相对量」¶

    关键认识：分贝不是一个绝对量，它永远是「相对于某个参考值」的比值。

    写法 参考值 用在哪
    dB re 1 μPa \(1\ \mu\text{Pa}\) 水声声压级 ✓
    dB re 1 μPa²/Hz \(1\ \mu\text{Pa}^2/\text{Hz}\) 谱级（单位带宽内的级）
    dB re 1 m \(1\ \text{m}\) 声源级（换算到距声中心 1 m 处）

    这张表对应一条实战纪律：写数字时一定要带参考值， 否则「120 dB」这句话没有意义

    谱级与总级不能直接相加

    谱级是「每赫兹有多少能量」，总级是「整个带宽加起来」。 两者关系：

    \[ \text{总级} = \text{谱级} + 10\lg(\Delta f) \]

    实测常见错误：把「谱级 −60 dB」直接当成「级」，忘了加带宽项， 结果差出十几分贝 —— 整个作用距离估算都偏了

    三、声源级 SL¶

    3.1 定义¶

    声源级衡量「声源有多响」，定义为距声中心 1 m 处的声强所对应的级：

    \[ \text{SL} = 10\lg\frac{I_1}{I_{\text{ref}}} \]

    其中 \(I_1\) 是距声中心 1 m 处的声强，\(I_{\text{ref}}\) 是参考声强。

    为什么要统一到 1 m：这样不同功率、不同尺寸的声源才能公平比较

    3.2 主动声呐的 SL 与发射功率的关系¶

    对于无指向性发射器：

    \[ \text{SL} = 170.8 + 10\lg P_a + \text{DI}_t \]

    其中 \(P_a\) 是辐射声功率（瓦），\(\text{DI}_t\) 是发射指向性指数（dB）。

    这个 \(170.8\) 是怎么来的：它是把「1 W 声功率在 1 m 处产生的声强」 换算成分贝的结果（与水的特性阻抗 \(\rho c\) 有关，取典型值 \(\rho = 1000\ \text{kg/m}^3\)、\(c = 1500\ \text{m/s}\)）。

    怎么读这条式子：

    项 含义 对作用距离的影响
    \(10\lg P_a\) 功率加一倍 = +3 dB 作用距离约增 \(10^{3/40}\approx 1.19\) 倍
    \(\text{DI}_t\) 把能量集中到某个方向 有效增益，等于该方向的聚集倍数

    「发射功率加倍，距离翻倍」是错的

    由声呐方程可以推出（球面扩展、忽略吸收）： 作用距离 \(\propto P_a^{1/4}\)（被动声呐是 \(P_a^{1/2}\)）。

    所以功率加一倍（+3 dB）只让距离增加约 19%，不是 100% 这是水声工程里最贵的一课：想靠加大功率增加距离， 代价是四次方关系，收益极小。

    3.3 指向性指数 DI¶

    指向性指数衡量「能量集中程度」：

    \[ \text{DI} = 10\lg\frac{\text{无指向性时所需功率}}{\text{该方向达到同样强度所需功率}} \]

    DI 就是「在目标方向上，我比全向发射省了多少分贝」

    均匀直线阵的近似式（阵长 \(L\)、波长 \(\lambda\)、且 \(L\gg\lambda\)）：

    \[ \text{DI} \approx 10\lg\frac{2L}{\lambda} \]

    读这条式子的要点：

    把这条权衡算成数：阵长加倍（DI +3 dB）与功率加倍（SL +3 dB）， 对作用距离的影响完全一样，但代价差一个量级。

    import numpy as np


def max_range(SL, TS, NL, DI, DT, alpha_db_km, r_hi=500.0):
    """二分法解主动声呐方程，返回作用距离(km)。"""
    def g(r):
        tl = 20.0 * np.log10(r * 1000.0) + alpha_db_km * r
        return SL - 2.0 * tl + TS - (NL - DI + DT)

    if g(0.01) < 0:
        return 0.0
    lo, hi = 0.01, r_hi
    for _ in range(200):
        mid = 0.5 * (lo + hi)
        if g(mid) > 0:
            lo = mid
        else:
            hi = mid
    return 0.5 * (lo + hi)


base = dict(SL=204.0, TS=15.0, NL=55.0, DI=20.0, DT=10.0,
            alpha_db_km=0.05)
r0 = max_range(**base)
r1 = max_range(**dict(base, SL=207.0))   # 功率加倍 = +3 dB
r2 = max_range(**dict(base, DI=23.0))    # 阵长加倍 = +3 dB

print("基线             : %7.2f km" % r0)
print("功率加倍 (SL+3)  : %7.2f km  增 %.1f%%"
      % (r1, (r1 / r0 - 1.0) * 100.0))
print("阵长加倍 (DI+3)  : %7.2f km  增 %.1f%%"
      % (r2, (r2 / r0 - 1.0) * 100.0))

    基线             :   19.96 km
功率加倍 (SL+3)  :   23.27 km  增 16.6%
阵长加倍 (DI+3)  :   23.27 km  增 16.6%

    两者的距离增益完全相同（都贡献 3 dB） 但阵长加倍只是多排几个水听器，功率加倍却要重做发射机、 电源与散热 —— 代价差一个量级 所以工程结论是：优先把基阵做长。

    • \(L/\lambda\) 加倍 → DI 增 3 dB
    • 想提高 DI，加长基阵比加大功率划算得多 （因为 DI 进入声呐方程是一次方，而功率只有 \(1/4\) 次方效应）

    工程上的取舍：先加阵长，再考虑功率

    DI 增 3 dB → 作用距离约增 19%（与功率加倍效果相同）， 但基阵加长的代价通常远低于把发射功率翻倍

    四、传播损失 TL¶

    4.1 两部分组成¶

    \[ \text{TL} = \underbrace{20\lg r}_{\text{扩展损失}} + \underbrace{\alpha r \times 10^{-3}}_{\text{吸收损失}} \]

    （\(r\) 单位米，\(\alpha\) 单位 dB/km）

    4.2 扩展损失：为什么是 20 lg r¶

    球面扩展（声能向四面八方散开）：

    \[ I(r) \propto \frac{1}{r^2} \;\Longrightarrow\; \text{TL} = 10\lg\frac{I(1)}{I(r)} = 10\lg r^2 = 20\lg r \]

    注意这个 20 的来源：距离加倍 → \(20\lg 2 \approx 6\) dB

    扩展类型 公式 什么场合
    球面扩展 \(20\lg r\) 深水、距离远（不受边界约束）
    柱面扩展 \(10\lg r\) 表面声道、深海声道（能量被限制在层内）
    实际（介于两者之间） \(15\lg r\)、\(17\lg r\) 等 浅海常见

    关键认识：柱面扩展比球面扩展「省一半」 —— 这就是为什么声道的传播距离能远得多

    4.3 吸收系数 α¶

    海水吸收主要由硼酸弛豫、硫酸镁弛豫、纯水粘滞三种机制贡献。

    常用近似式（Thorp 公式，\(f\) 单位 kHz）：

    \[ \alpha \approx \frac{0.11f^2}{1+f^2} + \frac{44f^2}{4100+f^2} + 2.75\times10^{-4}f^2 + 0.003\ \ (\text{dB/km}) \]

    怎么读：

    频段 主导机制 量级
    低频（< 1 kHz） 硼酸弛豫 很小，< 0.1 dB/km
    中频（1–50 kHz） 硫酸镁弛豫 1–10 dB/km
    高频（> 100 kHz） 纯水粘滞 迅速增大

    结论：\(\alpha\) 随频率急剧增大 → 这就是水声通信 只能用低频的根本原因

    距离远时，球面扩展不再是唯一的主要损失

    举例：\(r = 100\ \text{km}\)、\(\alpha = 1\ \text{dB/km}\)：

    \[ \text{TL} = 20\lg(10^5) + 1\times100 = 100 + 100 = 200\ \text{dB} \]

    扩展损失与吸收损失各占一半 若频率再高一倍，\(\alpha\) 可能涨到 5 dB/km，吸收项变成 500 dB —— 完全不可用。

    所以远距离探测必须用低频率。

    4.4 声呐方程里的「2TL」¶

    主动声呐声波要走两趟（去程 + 回程），所以损失是 \(2\text{TL}\)

    这一条的影响很大：作用距离对 TL 是四次方关系 （因为 \(2\text{TL} = 40\lg r\)，反解出 \(r \propto (\cdots)^{1/4}\)）。

    五、目标强度 TS¶

    5.1 定义¶

    目标强度衡量「目标把声波反射回来的能力」：

    \[ \text{TS} = 10\lg\frac{I_{\text{scat}}(1\,\text{m})}{I_{\text{inc}}} \]

    即：距目标等效声中心 1 m 处的散射声强，与入射声强之比（分贝）。

    为什么可以把复杂目标当成「一个等效点」：只要距离足够远， 目标的具体形状不重要，重要的是它往接收方向送回多少能量 这正是 TS 这个量的价值 —— 用一个标量概括复杂目标的散射能力。

    5.2 典型值¶

    目标 TS / dB 说明
    潜艇（正横） 15 ~ 25 与姿态、频率强相关
    潜艇（舰首/舰尾） 0 ~ 10 明显更小
    鱼群 −30 ~ −10 单个鱼约 −40 dB
    小气泡、浮游生物 −60 ~ −80 弱散射体

    TS 不是常数 —— 它随「看的角度」剧烈变化

    同一个目标，正横方向与舰首方向的 TS 可能差 20 dB 以上

    原因：正横时目标像一块大平板（镜面反射强）， 舰首时声波沿曲面掠过（散射弱）。

    后果：只写「某目标 TS = 20 dB」是不完整的， 必须说明姿态角与频率。

    5.3 目标强度与尺寸的关系（高频近似）¶

    当目标尺寸远大于波长远时，几何声学适用，可用投影面积估算：

    \[ \text{TS} \approx 10\lg\frac{A_{\text{proj}}}{\lambda^2}\cdot\frac{1}{\pi} \quad(\text{粗糙近似}) \]

    读这条式子的核心：TS 与 \(\lambda^2\) 成反比， 即频率越高，TS 越大（同一目标）。

    这条结论很有用：提高频率可以「让目标看起来更大」—— 但代价是 \(\alpha\) 急剧增大（见 4.3）。这是一组直接的对立， 也是水声工程设计里最核心的取舍之一 ⚠

    六、噪声级 NL 与指向性指数 DI¶

    6.1 噪声级¶

    噪声级是接收处的背景噪声级（谱级，每赫兹的分贝）：

    来源 频段 典型值
    航运 10–500 Hz 60–80 dB
    风成（海面波浪） 0.5–50 kHz 40–60 dB
    热噪声 > 50 kHz 随频率上升

    （详见 海洋环境噪声）

    6.2 接收指向性指数 DI¶

    接收阵也有指向性，效果是把噪声压下去：

    \[ \text{有效噪声} = \text{NL} - \text{DI} \]

    为什么是「减去 DI」：噪声来自四面八方，而信号只来自一个方向。 指向性阵对目标方向的信号全收，对其他方向的噪声只收一部分

    注意 DI 在声呐方程里的位置和符号 —— 它减去噪声， 不是加到信号上。但数学上等价：\(S - (N - DI) = (S - N) + DI\)

    「信号处理增益」与「指向性指数」不是一回事

    • DI：由基阵几何决定的空间增益（硬件决定）
    • 信号处理增益：由算法得到的增益（如积分时间、匹配滤波）

    两者都进声呐方程，但来源不同： 一个是「把阵摆好」，一个是「把算法做好」

    七、检测阈 DT¶

    7.1 定义¶

    检测阈是「刚能做出可靠判决时，所需的最小信噪比」：

    \[ \text{DT} = 10\lg\left(\frac{S}{N}\right)_{\min} \]

    它与三个因素有关：

    因素 影响
    虚警概率 \(P_{fa}\) 要求越低的虚警 → DT 越高
    检测概率 \(P_d\) 要求越高的检出率 → DT 越高
    积分时间 / 处理方式 积分越长 → DT 越低

    7.2 与判据的关系¶

    工作特征（ROC）决定：给定 \((P_d, P_{fa})\)，DT 就定了。

    常用参考：\(P_d = 0.5\)、\(P_{fa} = 10^{-3}\) 时， 单次检测约需 DT ≈ 6 dB（检波后积分）。

    「检测概率 0.5」是「一半概率检出」—— 不是「可靠检测」

    工程上常说「检测阈 6 dB」，但那是 50% 检测概率下的数

    若要求 \(P_d = 0.9\)，DT 要再加约 4–6 dB。 这直接影响作用距离估算（因为距离是四次方关系，DT 差 6 dB 会让距离差约 20%）。

    所以写作用距离必须说明对应的 \((P_d, P_{fa})\)

    八、把式子组装起来¶

    8.1 主动声呐方程¶

    回声级（目标处返回后被接收阵收到的级）：

    \[ \text{EL} = \text{SL} - 2\text{TL} + \text{TS} \]

    判决条件（回声级要超过「有效噪声 + 检测阈」）：

    \[ \text{EL} - (\text{NL} - \text{DI}) \ge \text{DT} \]

    合起来，主动声呐方程：

    \[ \boxed{\ \text{SL} - 2\text{TL} + \text{TS} = \text{NL} - \text{DI} + \text{DT}\ } \]

    8.2 被动声呐方程¶

    被动声呐只听目标自己发出的噪声（不发射，只有一个 TL）：

    \[ \text{SL} - \text{TL} = \text{NL} - \text{DI} + \text{DT} \]

    8.3 两者的关键差别¶

    主动 被动
    TL 项 \(2\text{TL}\)（来回两趟） \(\text{TL}\)（单程）
    SL 项 自己发射的 目标辐射的
    TS 项 需要（目标反射） 不需要
    距离对功率的依赖 \(P^{1/4}\) \(P^{1/2}\)
    暴露风险 高（主动暴露自己） 低 ✓

    「距离对功率的依赖」那一行很重要：它说明 被动声呐在远距离上更有优势（同样功率，距离增益是平方根 vs 四次根）， 而主动声呐的优点是能测距离（被动只能测方位）

    这张「主动 vs 被动」对照表是本页最该记住的

    考试里问「为什么潜艇用被动声呐搜索、用主动声呐定位」， 答案就在这两行：被动距离远且隐蔽，主动能测距但暴露位置

def alpha_thorp(f_khz):
    f2 = f_khz ** 2

            + 44.0 * f2 / (4100.0 + f2)

def tl(r_km, f_khz):
    r_m = r_km * 1000.0
    return 20.0 * np.log10(r_m) + alpha_thorp(f_khz) * r_km


def max_range(SL, TS, NL, DI, DT, f_khz, hi=3000.0):
    """二分法解 SL - 2*TL + TS = NL - DI + DT，返回距离(km)。"""
    def g(r):
        return SL - 2.0 * tl(r, f_khz) + TS - (NL - DI + DT)

    lo, hi_ = 0.001, hi
    if g(lo) < 0:
        return 0.0
    for _ in range(200):
        mid = 0.5 * (lo + hi_)
        if g(mid) > 0:
            lo = mid
        else:
            hi_ = mid
    return 0.5 * (lo + hi_)

    print("  %5.1f kHz  ->  %8.2f km" % (f, max_range(f_khz=f, **P)))

print("  SL=207 dB -> %7.2f km" % r2)

    九、例题¶

    例题 1：由作用距离反推所需声源级¶

    题目：某主动声呐，\(\text{TS} = 15\) dB、\(\text{NL} = 55\) dB、 \(\text{DI} = 20\) dB、\(\text{DT} = 10\) dB，工作频率 5 kHz， 要求作用距离 10 km（球面扩展，\(\alpha = 0.7\) dB/km）。 求所需的 SL。

    思路

    把 \(r = 10\ \text{km} = 10^4\ \text{m}\) 代进 TL，再解声呐方程。

    解答

    第一步：算传播损失。 扩展项：\(20\lg(10^4) = 80\) dB 吸收项：\(0.7\times10 = 7\) dB

    \[ \text{TL} = 80 + 7 = 87\ \text{dB} \]

    第二步：解声呐方程。

    \[ \text{SL} = \text{NL} - \text{DI} + \text{DT} + 2\text{TL} - \text{TS} \]
    \[ \text{SL} = 55 - 20 + 10 + 2\times87 - 15 = 45 + 174 - 15 = 204\ \text{dB} \]

    第三步：换算成发射功率。 若发射为无指向性（\(\text{DI}_t = 0\)）：

    \[ 10\lg P_a = 204 - 170.8 = 33.2 \implies P_a \approx 2.1\ \text{kW} \]

    204 dB 的声源级是一台千瓦级发射机的水平

    例题 2：为什么「功率加倍」只增加 19% 距离¶

    题目：在例题 1 的条件下，把发射功率加倍，新的作用距离是多少？

    思路

    功率加倍 → \(\text{SL}\) 增 3 dB → 能多走 3 dB 的 TL。 而 \(2\text{TL} = 2(20\lg r + \alpha r/1000)\)，距离是四次方关系。

    解答

    第一步：写出距离关系。 忽略吸收（远场近似），令 \(\text{SL}\) 的变化量为 \(\Delta\)：

    \[ 2\cdot 20\lg r \ \text{增大}\ \Delta \implies 40\lg\frac{r'}{r} = \Delta \]

    第二步：代入 \(\Delta = 3\) dB。

    \[ \lg\frac{r'}{r} = \frac{3}{40} = 0.075 \implies \frac{r'}{r} = 10^{0.075} \approx 1.19 \]

    答案：只增加约 19%（10 km → 11.9 km）。

    作用距离对功率是四次方根关系， 靠加大功率提升距离极其不划算 想显著增加距离，应该降频率（减小 \(\alpha\)）、 加长基阵（提高 DI）、或改善处理（降低 DT）

    例题 3：被动 vs 主动，同一功率谁更远¶

    题目：某平台发射 1 kW。若改成被动方式（目标辐射噪声 等效 SL 降到 150 dB），保持其它参数不变，作用距离如何变化？

    思路

    主动要减 \(2\text{TL}\)，被动只减 \(\text{TL}\)， 所以被动可以承受更大的 TL。把两者的距离关系分别写出来比较。

    解答

    第一步：主动的情形。 由例题 1 的结论：\(2\text{TL} = \text{SL} + \text{TS} - \text{NL} + \text{DI} - \text{DT}\) \(= 204 + 15 - 55 + 20 - 10 = 174\) dB，即 \(\text{TL} = 87\) dB → 10 km

    第二步：被动的情形。

    \[ \text{TL} = \text{SL}_{\text{tgt}} - \text{NL} + \text{DI} - \text{DT} = 150 - 55 + 20 - 10 = 105\ \text{dB} \]

    第三步：换算距离。 \(20\lg r = 105\)（先忽略吸收）\(\implies r = 10^{5.25} \approx 178\ \text{km}\)

    同样的目标、被动方式远得多（10 km → 178 km）

    原因是主动要付两趟传播损失，距离被压缩到四次方根。 这就是潜艇主要靠被动声呐搜索的原因

    例题 4：吸收系数对远距离的决定性影响¶

    题目：要求作用距离 50 km。分别用 1 kHz 和 10 kHz （\(\alpha \approx 0.06\) 与 \(0.9\) dB/km），比较 TL 与所需 SL 的差别。

    思路

    扩展项一样（都是 \(20\lg r\) 的两倍），差别全在吸收项。

    解答

    第一步：扩展项（两者相同）。

    \[ 2\times 20\lg(5\times10^4) = 2\times 94 = 188\ \text{dB} \]

    第二步：吸收项。

    频率 \(\alpha\) 单程 \(2\text{TL}\) 的吸收项
    1 kHz 0.06 dB/km 3 dB 6 dB
    10 kHz 0.9 dB/km 45 dB 90 dB

    第三步：对比。

    频率 总 \(2\text{TL}\) 相对差值
    1 kHz \(188 + 6 = 194\) dB —
    10 kHz \(188 + 90 = 278\) dB +84 dB

    84 dB 相当于发射功率差 \(10^{8.4}\) 倍 —— 完全不可能靠功率补回来

    所以 50 km 级的作用距离只能用低频（1 kHz 量级）， 10 kHz 在这种距离上无法工作

    小结¶

    项 符号 定义 典型值 与什么有关
    声源级 SL 距声中心 1 m 处的级 180–220 dB 发射功率、指向性
    传播损失 TL 扩展 + 吸收 60–120 dB 距离、频率、海况
    目标强度 TS 反射回 1 m 处的级 −40 ~ +25 dB 目标尺寸、姿态、频率
    噪声级 NL 环境噪声谱级 40–80 dB 频段、海况、航运
    指向性指数 DI 空间增益 10–30 dB 基阵尺寸与频率
    检测阈 DT 最小可检测信噪比 5–15 dB \(P_d\)、\(P_{fa}\)、积分时间

    三条最该带走的结论：

    1. 主动方程是 \(\text{SL} - 2\text{TL} + \text{TS} = \text{NL} - \text{DI} + \text{DT}\)， 被动没有 TS 项、TL 只算一次
    2. 距离对功率是四次方根关系（主动）—— 加大功率是最不划算的提升距离手段
    3. 频率是一把双刃剑：高频率让 TS 变大，但 \(\alpha\) 急剧上升， 所以远距离探测只能用低频
