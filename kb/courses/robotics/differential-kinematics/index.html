    机器人微分运动学¶

    上一页解逆解时，反复用到一块东西 —— 雅可比矩阵。 这一页把它讲透：它把关节速度映到末端速度， 能一眼看出哪些位形动不了，还能把力在关节与末端之间换算。 它是「位置」与「速度」之间那座桥。

    一、从位置关系走到速度关系¶

    1.1 位置关系是「弯」的，速度关系是「直」的¶

    正向运动学给出的是

    \[ \boldsymbol{p} = \boldsymbol{f}(\boldsymbol{q}) \]

    这是个非线性关系 —— \(\boldsymbol{f}\) 里全是 \(\cos\)、\(\sin\) 和乘积项， \(\boldsymbol{q}\) 变一点，\(\boldsymbol{p}\) 的变化量说不清是几倍。

    但只要两边对时间求导：

    \[ \dot{\boldsymbol{p}} = \frac{\partial \boldsymbol{f}}{\partial \boldsymbol{q}}\, \dot{\boldsymbol{q}} \]

    右边那个偏导数矩阵只与当前位置 \(\boldsymbol{q}\) 有关，与速度无关 —— 于是在当前位形下，速度关系变成了一个线性关系：

    \[ \dot{\boldsymbol{p}} = \boldsymbol{J}(\boldsymbol{q})\,\dot{\boldsymbol{q}} \]

    这件事的意义：非线性问题难解，线性问题到处都是现成工具。 所以机器人的速度级控制（速度逆解、奇异分析、力控制） 比位置级控制容易得多 —— 代价是它只在当前位置附近有效。

    1.2 微分运动：把「速度」乘上 \(dt\)¶

    工程上更常说的是微分运动，也就是「极短时间内的位移」。 对平移部分是

    \[ \Delta \boldsymbol{p} \approx \boldsymbol{J}(\boldsymbol{q})\,\Delta \boldsymbol{q} \]

    注意这里是「近似」（\(\approx\)）： 因为 \(\boldsymbol{f}\) 是非线性的，\(\boldsymbol{J}\,\Delta\boldsymbol{q}\) 只是一阶展开，丢掉了二阶及以上的项。

    所以 \(\Delta\boldsymbol{q}\) 越小，这个式子越准。 这句话可以实跑验证：

    import numpy as np

d = np.deg2rad
a1, a2 = 1.0, 0.8


def fk(q):
    t1, t2 = q
    return np.array([a1 * np.cos(t1) + a2 * np.cos(t1 + t2),
                     a1 * np.sin(t1) + a2 * np.sin(t1 + t2)])


def jac(q):
    t1, t2 = q
    s1, c1 = np.sin(t1), np.cos(t1)
    s12, c12 = np.sin(t1 + t2), np.cos(t1 + t2)
    return np.array([[-a1 * s1 - a2 * s12, -a2 * s12],
                     [a1 * c1 + a2 * c12, a2 * c12]])


q = np.array([d(30), d(45)])          # 当前位形

# 增量越小，「雅可比预测」越接近「正解真实差分」
for step in (10.0, 1.0, 0.1):
    dq = np.array([d(step), d(-0.7 * step)])
    pred = jac(q) @ dq                # 雅可比给出的线性预测
    true = fk(q + dq) - fk(q)         # 真实位移（正解差分）
    print("关节增量 %5.1f 度：预测 %s  真实 %s  最大偏差 %.2e"
          % (step, np.round(pred, 6), np.round(true, 6),
             np.abs(pred - true).max()))

    读这三行：

    · 关节增量 \(10^\circ\) 时，偏差约 \(1.3\times10^{-2}\) —— 近百分之一的量级， 已经不能忽略 · 增量缩到 \(1^\circ\)，偏差掉到 \(1.3\times10^{-4}\) —— 降了两个数量级 · 增量再缩到 \(0.1^\circ\)，偏差 \(1.35\times10^{-6}\) —— 又降两个数量级

    每缩小 10 倍，偏差缩小 100 倍 —— 这正是一阶展开的特征 （误差是增量的二阶量）。

    记住这个「什么时候能信」的界线

    雅可比只在当前位置的邻域里成立，邻域大小取决于机器人的尺度和位形。

    工程上的经验：控制周期越短，这个近似越安全。 反过来，如果一次要让末端走很远， 不能拿一个雅可比一直积分到底 —— 必须边走边更新 \(\boldsymbol{J}(\boldsymbol{q})\)。

    二、雅可比矩阵：把速度映射过去¶

    2.1 定义¶

    雅可比矩阵就是正向运动学对关节角的偏导数矩阵：

    \[ \boldsymbol{J}(\boldsymbol{q}) = \frac{\partial \boldsymbol{f}}{\partial \boldsymbol{q}} = \begin{bmatrix} \dfrac{\partial p_x}{\partial q_1} & \cdots & \dfrac{\partial p_x}{\partial q_n} \\[2mm] \dfrac{\partial p_y}{\partial q_1} & \cdots & \dfrac{\partial p_y}{\partial q_n} \\[2mm] \dfrac{\partial p_z}{\partial q_1} & \cdots & \dfrac{\partial p_z}{\partial q_n} \end{bmatrix} \]

    维度关系：若任务是 6 维（3 个位置 + 3 个姿态），关节数是 \(n\)， 则 \(\boldsymbol{J}\) 是 \(6\times n\)。

    \(n\) 与 6 的关系 名称 含义
    \(n = 6\) 恰好 一般可以到任意位姿
    \(n > 6\) 冗余 有富余，同一任务有多种做法
    \(n < 6\) 欠驱动 一般到不了任意位姿

    2.2 每一列的几何含义¶

    把 \(\dot{\boldsymbol{p}} = \boldsymbol{J}\dot{\boldsymbol{q}}\) 展开：

    \[ \dot{\boldsymbol{p}} = \boldsymbol{J}_1 \dot{q}_1 + \boldsymbol{J}_2 \dot{q}_2 + \cdots + \boldsymbol{J}_n \dot{q}_n \]

    这就是最有用的一句话： 第 \(i\) 列 \(\boldsymbol{J}_i\) 是「只让第 \(i\) 个关节以单位速度转动时， 末端的速度」 —— 也就是这个关节对末端速度的贡献方向。

    平面两连杆的例子特别直观（两张图能说清）：

    · 第 1 列：只有关节 1 转。末端绕基座画圆， 所以速度方向垂直于「基座 → 末端」这条线，大小等于这条线的长度 · 第 2 列：只有关节 2 转。末端绕肘画圆， 所以速度方向垂直于第二段连杆，大小恒等于 \(a_2\)

    import numpy as np

d = np.deg2rad
a1, a2 = 1.0, 0.8


def fk(q):
    t1, t2 = q
    return np.array([a1 * np.cos(t1) + a2 * np.cos(t1 + t2),
                     a1 * np.sin(t1) + a2 * np.sin(t1 + t2)])


def perp(v):
    """把平面向量逆时针转 90 度"""
    return np.array([-v[1], v[0]])


def jac(q):
    t1, t2 = q
    s1, c1 = np.sin(t1), np.cos(t1)
    s12, c12 = np.sin(t1 + t2), np.cos(t1 + t2)
    return np.array([[-a1 * s1 - a2 * s12, -a2 * s12],
                     [a1 * c1 + a2 * c12, a2 * c12]])


q = np.array([d(30), d(45)])
J = jac(q)
p_end = fk(q)                                     # 基座 -> 末端
p_elbow = np.array([a1 * np.cos(q[0]), a1 * np.sin(q[0])])

print("雅可比 J =")
print(np.round(J, 4))
print()
print("第 1 列 =", np.round(J[:, 0], 4),
      "  基座到末端向量转 90 度 =", np.round(perp(p_end), 4),
      "  一致？", np.allclose(J[:, 0], perp(p_end)))
print("第 2 列 =", np.round(J[:, 1], 4),
      "  肘到末端向量转 90 度 =", np.round(perp(p_end - p_elbow), 4),
      "  一致？", np.allclose(J[:, 1], perp(p_end - p_elbow)))
print()
print("第 2 列的长度 = %.4f（应等于 a2 = %.1f）"
      % (np.linalg.norm(J[:, 1]), a2))
print()

# det J 的闭式：a1 * a2 * sin(theta2) —— 由此立刻看出奇异位形
for t1d, t2d in ((30.0, 60.0), (30.0, 30.0), (30.0, 0.0), (30.0, 180.0)):
    q2 = np.array([d(t1d), d(t2d)])

    2.3 速度椭球：一张图¶

    把关节速度取成一个单位圆（各方向速度都取 1）， 经过 \(\boldsymbol{J}\) 映射后，末端速度的集合变成一个椭圆：

    · 远离奇异：椭圆接近圆 —— 各方向都好动 · 接近奇异：椭圆越来越扁 —— 某个方向几乎动不了 · 到了奇异：椭圆退化成一条线段 —— 那个方向彻底动不了

    所以「椭圆有多扁」就是「位形离奇异有多近」， 这就是可操作度（manipulability）的几何含义 —— 常用长轴与短轴之比来度量，越接近 1 越好。

    三、奇异位形：什么时候「动不了」¶

    3.1 定义：雅可比降秩¶

    奇异位形（singularity）的定义只有一句： 雅可比矩阵 \(\boldsymbol{J}(\boldsymbol{q})\) 不满秩的位形。

    对方形雅可比（\(n=6\)，任务也是 6 维），这等价于

    \[ \det \boldsymbol{J}(\boldsymbol{q}) = 0 \]

    为什么降秩 = 动不了：因为 \(\dot{\boldsymbol{p}} = \boldsymbol{J}\dot{\boldsymbol{q}}\) 里， \(\boldsymbol{J}\) 的列空间就是「末端能瞬时运动的方向集合」。 列空间维数掉下来，就意味着有些方向无论怎么转关节都到不了。

    3.2 平面两连杆：奇异就是「伸直」和「叠回去」¶

    上一节的闭式 \(\det \boldsymbol{J} = a_1a_2\sin\theta_2\) 直接给出答案：

    \[ \sin\theta_2 = 0 \;\Longrightarrow\; \theta_2 = 0^\circ \ \text{或}\ 180^\circ \]

    · \(\theta_2 = 0^\circ\)：两段完全伸直 —— 此时两列雅可比平行， 末端只能沿垂直于手臂的方向动，径向动不了 · \(\theta_2 = 180^\circ\)：两段完全叠回 —— 同样降秩

    为什么是"平行"：回想列的几何含义 —— 第 2 列垂直于连杆 2，第 1 列垂直于「基座 → 末端」。 两段伸直时，「基座 → 末端」和「连杆 2」是同一个方向， 于是这两列方向相同，矩阵的秩就从 2 掉到 1。

    3.3 奇异为什么危险¶

    奇异位形带来的问题不止是"动不了"，更麻烦的是逆解会爆：

    现象 原因
    关节速度需求暴涨 要末端走一段，\(\Delta\boldsymbol{q} = \boldsymbol{J}^{-1}\Delta\boldsymbol{p}\)，\(\boldsymbol{J}\) 趋近奇异时逆趋于无穷
    失去某个方向的运动能力 该方向的位置再也调不动了
    逆解不存在或无穷多 \(\det\boldsymbol{J}=0\) 时 \(\boldsymbol{J}^{-1}\) 根本不存在

    注意最后一条的"两副面孔"： 上一页讲六轴逆解时提到的「腕心落在基座轴线上 → \(\theta_1\) 有无穷多解」， 就是奇异位形 —— 同一个数学条件「降秩」，在位置上表现为"无穷多解"， 在速度上表现为"无穷大速度需求"。

    工程上怎么处理奇异

    ① 别让轨迹穿过奇异位形。 规划时就检查：沿路径的可操作度不能低于阈值。

    ② 必须穿过时，用阻尼最小二乘（DLS）： 把逆解改成

    \[ \Delta \boldsymbol{q} = \boldsymbol{J}^{\mathsf T} \bigl(\boldsymbol{J}\boldsymbol{J}^{\mathsf T} + \lambda^2 \boldsymbol{I}\bigr)^{-1} \Delta \boldsymbol{p} \]

    加上的 \(\lambda\) 项让矩阵始终可逆。 代价是末端会有一点方向上的偏差 —— 用精度换稳定。

    ③ 冗余机器人可以"绕过去"：\(n>6\) 时有富余自由度， 可在不动末端的前提下主动远离奇异。

    3.4 一张图：奇异位形的几何¶

    手臂完全伸直时，两列雅可比指向同一个方向（都垂直于手臂）—— 末端因此只能沿这个方向动，而想沿手臂方向伸缩，瞬时动不了。

    四、静力的转换：\(\boldsymbol{\tau} = \boldsymbol{J}^{\mathsf T}\boldsymbol{F}\)¶

    4.1 用虚功原理推出来（只有两行）¶

    设末端受力 \(\boldsymbol{F}\)（力 + 力矩），关节需要出的力矩为 \(\boldsymbol{\tau}\)。 用虚功原理：让机器人做一个微小虚位移，两边做的功必须相等。

    · 关节侧做功：\(\boldsymbol{\tau}^{\mathsf T}\Delta\boldsymbol{q}\) · 末端侧做功：\(\boldsymbol{F}^{\mathsf T}\Delta\boldsymbol{p} = \boldsymbol{F}^{\mathsf T}\boldsymbol{J}\Delta\boldsymbol{q}\)

    两边相等，且对任意 \(\Delta\boldsymbol{q}\) 都成立，于是

    \[ \boldsymbol{\tau}^{\mathsf T} = \boldsymbol{F}^{\mathsf T}\boldsymbol{J} \qquad\Longrightarrow\qquad \boxed{\ \boldsymbol{\tau} = \boldsymbol{J}^{\mathsf T}\boldsymbol{F}\ } \]

    注意是转置 \(\boldsymbol{J}^{\mathsf T}\)，不是逆 \(\boldsymbol{J}^{-1}\)。 这一点很重要：奇异位形下 \(\boldsymbol{J}\) 不可逆、但 \(\boldsymbol{J}^{\mathsf T}\) 永远存在 —— 所以力可以照常传递，位姿却动不了。这是静力分析和位置分析的关键区别。

    import numpy as np

d = np.deg2rad
a1, a2 = 1.0, 0.8


def jac(q):
    t1, t2 = q
    s1, c1 = np.sin(t1), np.cos(t1)
    s12, c12 = np.sin(t1 + t2), np.cos(t1 + t2)
    return np.array([[-a1 * s1 - a2 * s12, -a2 * s12],
                     [a1 * c1 + a2 * c12, a2 * c12]])


q = np.array([d(30), d(45)])
J = jac(q)

# 末端受力 F 时，关节需要出的力矩 tau = J^T F
F = np.array([3.0, -2.0])              # 末端受力（N）
tau = J.T @ F
print("末端受力 F =", F, "N")
print("关节力矩 tau = J^T F =", np.round(tau, 4), "N m")
print()

# 虚功原理核对：任意关节微小位移下，两侧做功应相等
rng = np.random.default_rng(0)
worst = 0.0
for _ in range(5):
    dq = rng.normal(0, 1e-3, 2)
    worst = max(worst, abs(tau @ dq - F @ (J @ dq)))
print("5 次随机检验，关节侧与末端侧做功的最大差 = %.2e" % worst)
print()

# 速度椭球与力椭球互为倒数：好动的方向，出力小
for t2d in (60.0, 5.0):
    q2 = np.array([d(30), d(t2d)])
    sv = np.linalg.svd(jac(q2), compute_uv=False)
    print("theta2 = %4.1f 度：速度椭球半轴 = %s，力椭球半轴 = %s"
          % (t2d, np.round(sv, 4), np.round(1.0 / sv, 4)))
print()

# 奇异位形：det J = 0，J 不可逆，但 J^T 仍在 —— 位姿动不了，力却照样能传
for t2d in (60.0, 0.0):
    q2 = np.array([d(30), d(t2d)])
    J2 = jac(q2)
    print("theta2 = %5.1f 度：det J = %8.4f，J 的秩 = %d"
          % (t2d, np.linalg.det(J2), np.linalg.matrix_rank(J2)))

    四段输出各说一件事：

    ① 关节力矩 = \(\boldsymbol{J}^{\mathsf T}\boldsymbol{F}\)。 末端受 \((3, -2)\) N 的力，两个关节要出 \(-5.96\) 和 \(-2.73\) N·m （符号相反，说明两个关节出力方向相反，这是正常的）。

    ② 虚功原理核对通过。 5 次随机检验的最大差是 \(8.7\times10^{-19}\) —— 量级上就是浮点舍入误差，说明 \(\boldsymbol{\tau} = \boldsymbol{J}^{\mathsf T}\boldsymbol{F}\) 确实成立。

    ③ 速度椭球与力椭球互为倒数。 \(\theta_2 = 60^\circ\) 时半轴是 \((1.7074,\ 0.4058)\)， 倒过来正好是 \((0.5857,\ 2.4645)\)。 到 \(\theta_2 = 5^\circ\)（接近奇异）时， 速度椭球长轴大到 \(1.97\)、短轴缩到 \(0.035\)， 力椭球则相反：短轴 \(0.51\)、长轴涨到 \(28.2\)。

    这是一条极有用的反直觉结论： 好动的方向，出力小；动不了的方向，反倒最"抗压"。 直觉解释：动不了的方向上，关节的位移对末端没用上 （力臂几乎为零），于是同样的关节力矩能在那里顶住很大的外力。

    ④ 奇异位形：秩从 2 掉到 1。 注意此时 \(\det\boldsymbol{J}=0\) 让位置彻底卡住， 但 \(\boldsymbol{J}^{\mathsf T}\) 依然存在 —— 末端仍然能稳稳顶住外力（这就是上一段说的"抗压"）。

    一句话记住微分运动学的三件事

    · 速度：\(\dot{\boldsymbol{p}} = \boldsymbol{J}\dot{\boldsymbol{q}}\) —— 关节快慢怎么变成末端快慢 · 奇异：\(\boldsymbol{J}\) 降秩 —— 有些方向瞬时动不了 · 静力：\(\boldsymbol{\tau} = \boldsymbol{J}^{\mathsf T}\boldsymbol{F}\) —— 末端受力要关节出多少力矩

    三者共用同一个 \(\boldsymbol{J}\)， 而且速度与力在椭球上是"此消彼长"的（互为倒数）。

    典型例题¶

    例题 1：求平面两连杆的雅可比¶

    平面两连杆机器人，杆长 \(a_1, a_2\)，关节角 \(\theta_1, \theta_2\)。 求其雅可比矩阵，并写出 \(\det\boldsymbol{J}\)。

    思路

    先写正向运动学的 \(x, y\) 表达式， 再分别对 \(\theta_1, \theta_2\) 求偏导。 注意 \(\dfrac{\partial}{\partial\theta_1}(\theta_1+\theta_2) = 1\) 而 \(\dfrac{\partial}{\partial\theta_2}(\theta_1+\theta_2) = 1\) —— 两者都是 1。

    解答

    第一步：写出正向运动学

    \[ x = a_1\cos\theta_1 + a_2\cos(\theta_1+\theta_2),\qquad y = a_1\sin\theta_1 + a_2\sin(\theta_1+\theta_2) \]

    第二步：求四个偏导

    对 \(\theta_1\)（注意复合函数，两项都要导）：

    \[ \frac{\partial x}{\partial\theta_1} = -a_1\sin\theta_1 - a_2\sin(\theta_1+\theta_2) ,\qquad \frac{\partial y}{\partial\theta_1} = a_1\cos\theta_1 + a_2\cos(\theta_1+\theta_2) \]

    对 \(\theta_2\)（只有第二项含 \(\theta_2\)）：

    \[ \frac{\partial x}{\partial\theta_2} = -a_2\sin(\theta_1+\theta_2) ,\qquad \frac{\partial y}{\partial\theta_2} = a_2\cos(\theta_1+\theta_2) \]

    第三步：组装

    \[ \boldsymbol{J} = \begin{bmatrix} -a_1\sin\theta_1 - a_2\sin(\theta_1+\theta_2) & -a_2\sin(\theta_1+\theta_2) \\ a_1\cos\theta_1 + a_2\cos(\theta_1+\theta_2) & a_2\cos(\theta_1+\theta_2) \end{bmatrix} \]

    第四步：行列式 —— 直接展开会有一堆项，但可以用列向量简化： 第 1 列是「基座 → 末端」向量逆时针转 \(90^\circ\)， 第 2 列是「肘 → 末端」向量逆时针转 \(90^\circ\)。 两个向量都转了同一个 \(90^\circ\)，行列式不变，于是

    \[ \det\boldsymbol{J} = \det \begin{bmatrix} x_{\text{端}} & x_{\text{端}} - x_{\text{肘}} \\ y_{\text{端}} & y_{\text{端}} - y_{\text{肘}} \end{bmatrix} = a_1a_2\sin\theta_2 \]

    这一步的验证：代码实跑给出 \(\det\boldsymbol{J} = 0.6928\)， 而 \(a_1a_2\sin 60^\circ = 1 \times 0.8 \times 0.8660 = 0.6928\) ✓

    这个闭式很有用：它一眼告出奇异条件就是 \(\sin\theta_2 = 0\)。

    例题 2：判断位形是不是奇异¶

    平面两连杆（\(a_1 = 1.0,\ a_2 = 0.8\)）处于两个位形： ① \(\theta_2 = 60^\circ\)；② \(\theta_2 = 0^\circ\)。 分别判断哪一个是奇异位形，并说明此时末端瞬时能走哪些方向。

    思路

    用上一题的闭式 \(\det\boldsymbol{J} = a_1a_2\sin\theta_2\)。 再想：两列雅可比平行时，它们的线性组合能张成什么？

    解答

    ① \(\theta_2 = 60^\circ\)：非奇异。

    \[ \det\boldsymbol{J} = 1 \times 0.8 \times \sin 60^\circ = 0.6928 \neq 0 \]

    矩阵满秩（代码实跑确认秩 = 2）。 末端可以沿平面内任意方向瞬时运动 —— 两列雅可比线性无关，张成整个二维平面。

    ② \(\theta_2 = 0^\circ\)：奇异。

    \[ \det\boldsymbol{J} = 1 \times 0.8 \times \sin 0^\circ = 0 \]

    代码实跑确认秩 = 1。此时两段连杆完全伸直， 两列雅可比方向相同（都垂直于手臂）， 它们的线性组合只能张成一条直线：

    · 能走的方向：垂直于手臂（切向）—— 而且能走 —— 因为两列都指向这个方向 · 动不了的方向：沿着手臂（径向） —— 想沿手臂伸出或缩回，瞬时速度只能是零

    求解验证：若硬要让末端沿径向动（比如 \(\Delta\boldsymbol{p} = (1,0)\)）， 方程 \(\boldsymbol{J}\Delta\boldsymbol{q} = \Delta\boldsymbol{p}\) 无解 —— 因为 \(\Delta\boldsymbol{p}\) 不在列空间里。

    补充一点：这个"两列平行"的图像不只出现在两连杆。 任何串联机器人到了奇异位形， 总有某两个（或多个）关节的速度贡献方向重合 —— 表现就是关节数"失去了区分度"。

    例题 3：已知末端受力，求关节力矩¶

    平面两连杆在 \(\theta_1 = 30^\circ,\ \theta_2 = 45^\circ\) 位形下， 末端受 \(\boldsymbol{F} = (3.0,\ -2.0)\) N 的力 （只考虑力，不计力矩分量）。 求两个关节需要输出的力矩。

    思路

    用静力转换 \(\boldsymbol{\tau} = \boldsymbol{J}^{\mathsf T}\boldsymbol{F}\)。 注意是转置，不需要求逆。

    解答

    第一步：写出该位形的雅可比（把角度代入例题 1 的式子）

    \[ \boldsymbol{J} = \begin{bmatrix} -1.2727 & -0.7727 \\ 1.0731 & 0.2071 \end{bmatrix} \]

    第二步：按 \(\boldsymbol{\tau} = \boldsymbol{J}^{\mathsf T}\boldsymbol{F}\) 算

    \[ \boldsymbol{\tau} = \begin{bmatrix} -1.2727 & 1.0731 \\ -0.7727 & 0.2071 \end{bmatrix} \begin{bmatrix} 3.0 \\ -2.0 \end{bmatrix} = \begin{bmatrix} -1.2727\times3 + 1.0731\times(-2) \\ -0.7727\times3 + 0.2071\times(-2) \end{bmatrix} = \begin{bmatrix} -5.9644 \\ -2.7323 \end{bmatrix} \ \text{N·m} \]

    代码实跑结果一致 ✓

    怎么读这个结果：

    · 两个力矩都是负的 —— 说明两个关节都要朝负方向出力， 才能把末端 \((3,-2)\) N 的力"顶住" · 第一个关节的力矩更大（5.96 比 2.73）—— 因为它承担了更长的力臂（整条手臂）

    第三步：为什么用转置、不用逆 —— 这是本题最该记住的一点。 静力关系是转置，转置永远存在； 而位置/速度关系要用逆，逆在奇异位形不存在。 所以"求关节力矩"这类问题永远有答案， "求关节速度"却可能在奇异位形无解。

    例题 4：为什么"动不了的方向反而抗得住外力"¶

    上面代码的第三段输出显示：接近奇异时速度椭球的长轴很长、短轴很短， 而力椭球恰好相反。请解释这个"此消彼长"关系的物理原因。

    思路

    想：末端的位移是靠什么产生的？（关节转动"推"出来的） 再想：如果一个方向上关节怎么转都推不出位移，那意味着什么？

    解答

    核心就一句：位移和力用的是同一套"力臂"，要求却相反。

    先看位移。 末端在某个方向上的可动性， 来自各个关节的转动"推"到那个方向上的分量。 如果某个方向上各关节的推力分量几乎抵消，末端就动不了。

    再看力。 末端在某个方向上受到的力， 要由各关节的力矩来平衡，平衡靠的是虚功相等 （\(\boldsymbol{\tau} = \boldsymbol{J}^{\mathsf T}\boldsymbol{F}\)）。 如果某个方向上关节位移对末端位移的"杠杆比"很小， 那么要在这个方向上顶住外力，只需要很小的关节力矩 —— 换句话说，同样的关节力矩能在那里顶住很大的外力。

    数学上就是：两者互为倒数。

    设 \(\boldsymbol{J}\) 的奇异值是 \(\sigma_1 \ge \sigma_2 \ge \cdots\)，则

    · 速度椭球的半轴 = \(\sigma_i\) · 力椭球的半轴 = \(1/\sigma_i\)

    代码里对得上：\(\theta_2 = 5^\circ\) 时 速度半轴 \((1.9679,\ 0.0354)\)，力半轴 \((0.5082,\ 28.224)\) —— \(1/1.9679 = 0.5082\)，\(1/0.0354 = 28.2\) ✓

    物理直觉的总结： "好动"和"抗压"是一对反义词 —— 这也解释了为什么人伸直手臂举重物时最稳（力臂大、位置精度差）， 而弯着胳膊做精细操作时更灵活（精度高、举不动）。

    工程含义：设计任务时要看到底需要哪个 —— 需要出力就选"力量型"位形，需要精度就选"灵活型"位形， 两者不可能同时最优。

    自测¶

    Q1 为什么机器人的位置关系是非线性的， 而速度关系是线性的？这个差别对控制有什么好处？

    提示

    想：位置关系里有哪些运算？ 再想：对时间求一次导之后，哪些项变成了常数？

    解答

    位置关系是非线性的，因为正向运动学里全是 \(\cos\)、\(\sin\) 和它们的乘积（三角函数本身就非线性）。

    对时间求一次导后变成线性：

    \[ \dot{\boldsymbol{p}} = \frac{\partial \boldsymbol{f}}{\partial \boldsymbol{q}}\dot{\boldsymbol{q}} = \boldsymbol{J}(\boldsymbol{q})\,\dot{\boldsymbol{q}} \]

    关键在于那个偏导数矩阵： 它只与当前位置 \(\boldsymbol{q}\) 有关，与速度无关。 于是在当前位形下，\(\dot{\boldsymbol{p}}\) 与 \(\dot{\boldsymbol{q}}\) 就是一个线性关系。

    对控制的好处：

    ① 可以用线性工具。 解方程、求逆、最小二乘、 伪逆 —— 全都适用于线性关系。

    ② 速度级的逆解很直接。 \(\dot{\boldsymbol{q}} = \boldsymbol{J}^{-1}\dot{\boldsymbol{p}}\) —— 只要 \(\boldsymbol{J}\) 可逆就一步算出来，不用迭代。

    ③ 控制器的结构变简单。 很多机器人的"分解运动速度控制"就是 在每个控制周期算一次 \(\boldsymbol{J}\)，然后按线性关系分配关节速度。

    代价：这个线性关系只在当前位形附近有效（一阶近似）。 所以控制周期不能太长，或者必须边算边更新 \(\boldsymbol{J}\)。

    Q2 雅可比矩阵的第 \(i\) 列，物理含义是什么？ 平面两连杆的两列分别垂直于谁？

    提示

    想：把 \(\dot{\boldsymbol{p}} = \boldsymbol{J}\dot{\boldsymbol{q}}\) 展开成和的形式， 每一项对应什么？ 再想：只有关节 1 转动时，末端绕哪个点画圆？

    解答

    第 \(i\) 列的物理含义：只让第 \(i\) 个关节以单位速度转动时，末端的速度。

    把方程展开：

    \[ \dot{\boldsymbol{p}} = \boldsymbol{J}_1\dot{q}_1 + \boldsymbol{J}_2\dot{q}_2 + \cdots + \boldsymbol{J}_n\dot{q}_n \]

    令只有 \(\dot{q}_i = 1\)、其余为 0，右边就只剩 \(\boldsymbol{J}_i\) —— 所以第 \(i\) 列就是第 \(i\) 个关节对末端速度的"贡献方向"。

    平面两连杆的两列：

    · 第 1 列：只有关节 1 转。末端的运动是绕基座转圈， 所以速度垂直于「基座 → 末端」向量，大小为这条向量的长度 · 第 2 列：只有关节 2 转。末端的运动是绕肘转圈， 所以速度垂直于第二段连杆，大小为 \(a_2\)（与位形无关！）

    代码实跑验证：两列分别等于对应向量逆时针转 \(90^\circ\)， 第 2 列的长度恰好是 \(0.8 = a_2\) ✓

    这个图像的直接用途：判断奇异位形。 当两列平行（方向重合）时，矩阵就降秩 —— 而"基座 → 末端"与"连杆 2"方向重合， 正是手臂完全伸直的情形。

    Q3 什么是奇异位形？为什么它同时表现为「关节速度需求无穷大」 和「逆解无穷多」？工程上怎么处理？

    提示

    先想奇异的数学定义（只有一个条件）。 再想 \(\boldsymbol{J}^{-1}\) 在行列式趋于 0 时会发生什么。

    解答

    定义：雅可比矩阵 \(\boldsymbol{J}\) 不满秩的位形。 对方形雅可比，等价于 \(\det\boldsymbol{J} = 0\)。

    同一个数学条件，在两个问题里表现不同：

    ① 位置问题 → 逆解无穷多（或不存在）。 既然 \(\det\boldsymbol{J}=0\)，\(\boldsymbol{J}\) 就不可逆， 位置级的逆解方程失去唯一性。 上一页遇到的「腕心落在基座旋转轴上， \(\theta_1\) 可以是任意值」就是这么来的 —— 有些关节转了对末端位置毫无影响。

    ② 速度问题 → 逆解趋于无穷大。 速度逆解是 \(\dot{\boldsymbol{q}} = \boldsymbol{J}^{-1}\dot{\boldsymbol{p}}\)。 \(\boldsymbol{J}\) 趋近奇异时，它的逆的元素趋于无穷 —— 于是末端要走一点点，要求的关节速度就"爆"了。

    两种表现其实是同一件事的两面： 某个方向上的运动不需要任何关节动作去实现 （所以位置上有无穷多解）， 反过来要让末端在该方向动，就得用无限大的关节速度去逼近。

    工程处理三条：

    手段 做法
    避开 规划时就限制可操作度，不让轨迹穿过奇异位形
    阻尼最小二乘 把 \(\boldsymbol{J}^{-1}\) 换成 \(\boldsymbol{J}^{\mathsf T}(\boldsymbol{J}\boldsymbol{J}^{\mathsf T} + \lambda^2\boldsymbol{I})^{-1}\)，始终可逆，用精度换稳定
    借助冗余 \(n>6\) 时用富余自由度在不动末端的前提下主动远离奇异

    补充：奇异位形并非全是坏事 —— 静力关系 \(\boldsymbol{\tau} = \boldsymbol{J}^{\mathsf T}\boldsymbol{F}\) 里没有逆，所以在奇异位形下力照样能传递， 甚至可以顶住很大的外力。要"动"就怕奇异，要"顶"反而喜欢奇异。

    Q4 静力转换为什么是 \(\boldsymbol{\tau} = \boldsymbol{J}^{\mathsf T}\boldsymbol{F}\) （转置），而不是 \(\boldsymbol{J}^{-1}\)（逆）？

    提示

    先想这个式子是怎么推出来的（虚功原理）。 再想：转置和逆对矩阵的秩各有什么要求？

    解答

    它是由「虚功相等」推出来的，不是凑出来的。

    让机器人做一个微小虚位移 \(\Delta\boldsymbol{q}\)，则 关节侧做功为 \(\boldsymbol{\tau}^{\mathsf T}\Delta\boldsymbol{q}\)， 末端侧做功为 \(\boldsymbol{F}^{\mathsf T}\Delta\boldsymbol{p} = \boldsymbol{F}^{\mathsf T}\boldsymbol{J}\Delta\boldsymbol{q}\)。

    由虚功原理，两者相等；又因为这对任意 \(\Delta\boldsymbol{q}\) 都成立：

    \[ \boldsymbol{\tau}^{\mathsf T} = \boldsymbol{F}^{\mathsf T}\boldsymbol{J} \;\Longrightarrow\; \boldsymbol{\tau} = \boldsymbol{J}^{\mathsf T}\boldsymbol{F} \]

    为什么"转置"比"逆"更好用（这是问题的关键）：

    存在性 奇异位形下
    \(\boldsymbol{J}^{\mathsf T}\) 永远存在 照样能用
    \(\boldsymbol{J}^{-1}\) 要求 \(\boldsymbol{J}\) 可逆 不存在

    所以：

    · 求关节力矩：永远有答案，即使在奇异位形下 —— 因为力是通过"杠杆"传过去的，不要求矩阵可逆 · 求关节速度：在奇异位形下无解或解趋于无穷 —— 因为要真刀真枪地去"动"

    物理上的原因：力可以被结构承担（不需要运动）， 而速度必须靠运动去实现。 结构在奇异位形下依然完整，所以力照样传得了。

    一句话：速度要"动"，所以怕奇异；力要"扛"，所以不怕。

    小结¶

    要记住的 为什么重要
    位置关系非线性，速度关系线性 求导后偏导矩阵只与位形有关，线性工具全能上
    \(\dot{\boldsymbol{p}} = \boldsymbol{J}(\boldsymbol{q})\dot{\boldsymbol{q}}\) 雅可比是「位置」与「速度」之间的桥
    \(\boldsymbol{J}\) 的第 \(i\) 列 = 第 \(i\) 个关节的速度贡献方向 平面 2R：第 1 列 ⟂ 基座到末端，第 2 列 ⟂ 连杆 2
    微小位移用 \(\Delta\boldsymbol{p}\approx\boldsymbol{J}\Delta\boldsymbol{q}\) 误差是增量的二阶量：增量小 10 倍，误差小 100 倍
    奇异位形 = \(\boldsymbol{J}\) 降秩 平面 2R 的 \(\det\boldsymbol{J} = a_1a_2\sin\theta_2\)，\(\theta_2=0/180^\circ\) 时奇异
    奇异的两副面孔 位置上「无穷多解」，速度上「无穷大速度需求」
    速度椭球越扁越接近奇异 长短轴之比就是可操作度的常用度量
    \(\boldsymbol{\tau} = \boldsymbol{J}^{\mathsf T}\boldsymbol{F}\) 用转置不用逆：力在奇异位形下照样能传
    速度椭球与力椭球互为倒数 好动的方向出力小；动不了的方向最抗压

    四条最容易出错的地方：

    1. 拿一个雅可比积分到底 —— 它只是一阶近似，必须边走边更新
    2. 把奇异位形当成"只是速度慢" —— 它会带来无穷大速度需求与无解
    3. 静力关系写成 \(\boldsymbol{J}^{-1}\) —— 是转置 \(\boldsymbol{J}^{\mathsf T}\)， 这样奇异位形下才有解
    4. 忽略"速度与力此消彼长" —— 灵活和出力不能同时最优，要按任务取舍
