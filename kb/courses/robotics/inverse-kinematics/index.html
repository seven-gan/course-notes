    机器人逆向运动学¶

    上一页是「已知关节角，求末端位姿」—— 那是算，而且一定有唯一答案。 这一页反过来：已知末端要到的位姿，求关节角 —— 这是解方程。 难易的差别只是表象，真正变了的是问题的性质。

    一、逆运动学到底难在哪¶

    1.1 一张表看清区别¶

    问题 已知 求 解的性质
    正向运动学 各关节角 末端位姿 唯一解，直接乘出来
    逆向运动学 末端位姿 各关节角 可能多解、可能无解、可能没有解析解

    为什么会这样：正向运动学是从关节往末端一步步乘， 每一步都是「已知一个确定的矩阵，乘上去」，没有需要选择的地方。 逆向运动学要把这个乘积反解出来 —— 得到的是一组三角函数方程。

    1.2 三类麻烦，性质完全不同¶

    ① 多解 —— 同一个位姿，可能有好几组关节角都能到。

    这不是「算法不好」，而是几何上真的有好几种站法： 胳膊可以从上面绕过去，也可以从下面绕过去；肘可以朝上，也可以朝下。

    ② 无解 —— 目标本身就在机器人的能力之外。

    末端离基座太远（够不着）或太近（缩不到那么紧）， 无论关节怎么转都到不了。

    ③ 没有通用解析解 —— 结构不特殊时，只能迭代。

    串联链越长、结构越一般，那组三角函数方程越难解出闭式。 对一般六轴机构，没有万能的公式， 工程上退而使用数值迭代（下面第四部分讲）。

    记住这个不对称性

    正向运动学是「算」，逆向运动学是「解」。

    后果很实际：控制回路里可以放心地反复算正向运动学 （快、稳定、结果唯一）； 而逆向运动学通常只在规划阶段算一次， 并且必须准备好处理「多解挑哪组」和「无解怎么办」。

    1.3 工作空间：先划清「到得了」的范围¶

    讨论有没有解之前，先把「到得了的点」圈出来：

    名称 含义
    可达工作空间 末端至少能以一个姿态到达的点的集合
    灵巧工作空间 末端能以任意姿态到达的点的集合

    显然灵巧工作空间 ⊆ 可达工作空间，而且通常小很多。

    平面两连杆的例子最能说明问题：两段杆长 \(L_1, L_2\)， 末端到基座的距离 \(r = \sqrt{x^2 + y^2}\) 只能落在闭区间

    \[ |L_1 - L_2| \le r \le L_1 + L_2 \]

    两条边界各有名字：

    · \(r = L_1 + L_2\)：两段完全伸直，这是最远能到的地方 · \(r = |L_1 - L_2|\)：两段完全叠在一起，这是最近能到的地方

    一旦目标落在区间之外，直接判「无解」，不必去迭代 —— 这是工程实现里第一步就该做的过滤。

    二、先把「多解」看个清楚：平面两连杆¶

    2.1 几何上为什么会有两组解¶

    设两段杆长为 \(a_1, a_2\)，关节角 \(\theta_1, \theta_2\)，末端位置 \((x, y)\)。 关键是把「到末端的距离」拿来分析：

    \[ r^2 = x^2 + y^2 = a_1^2 + a_2^2 + 2a_1a_2\cos\theta_2 \]

    看这个式子：右边只有 \(\theta_2\) 一个未知量。 所以 \(\theta_2\) 可以由 \(r\) 直接定出来 —— 但 \(\cos\theta_2\) 相同， \(\theta_2\) 有正负两个值：

    \[ \theta_2 = \pm\arccos\frac{r^2 - a_1^2 - a_2^2}{2a_1a_2} \]

    这两个值的几何含义： \(\theta_2 > 0\) 与 \(\theta_2 < 0\) 正好是肘部朝上和肘部朝下两种站法。

    2.2 完整的两组解¶

    定下 \(\theta_2\) 之后，\(\theta_1\) 也随之确定：

    \[ \theta_1 = \operatorname{atan2}(y,\,x) - \operatorname{atan2}\bigl(a_2\sin\theta_2,\; a_1 + a_2\cos\theta_2\bigr) \]

    为什么 \(\theta_1\) 也分两支：因为 \(\theta_2\) 取正取负， 上面第二项的正负号跟着变，于是 \(\theta_1\) 自动落到两个不同的方向。

    这里正是上一页说的「atan2 不能换成 atan」的地方

    式子里用了两次 atan2。 如果换成普通的 \(\arctan\)，第二、三象限的解会整体转错 \(180^\circ\)， 而且不会报错，只会安静地给出错误关节角。

    规则：只要是在「由坐标反求角度」，就一律用 atan2。

    import numpy as np

d = np.deg2rad
a1, a2 = 1.0, 0.8


def fk(t1, t2):
    """平面 2R 正解：返回末端 (x, y)"""
    return (a1 * np.cos(t1) + a2 * np.cos(t1 + t2),
            a1 * np.sin(t1) + a2 * np.sin(t1 + t2))


def ik(x, y):
    """平面 2R 逆解：返回全部解（最多两组），单位弧度"""
    r2 = x * x + y * y
    c2 = (r2 - a1 ** 2 - a2 ** 2) / (2 * a1 * a2)
    if abs(c2) > 1:
        return []                    # 目标在工作空间之外：无解
    s2 = np.sqrt(1 - c2 ** 2)
    out = []
    for sign in (+1, -1):
        t2 = np.arctan2(sign * s2, c2)
        t1 = (np.arctan2(y, x)
              - np.arctan2(a2 * np.sin(t2), a1 + a2 * np.cos(t2)))
        out.append((t1, t2))
    return out


x, y = fk(d(30), d(60))
print("正解给出末端 = (%.4f, %.4f)" % (x, y))
print()
for k, (t1, t2) in enumerate(ik(x, y), 1):
    x2, y2 = fk(t1, t2)
    print("解 %d：theta1 = %7.2f 度  theta2 = %7.2f 度  ->  末端 (%.4f, %.4f)"
          % (k, np.rad2deg(t1), np.rad2deg(t2), x2, y2))
print()
print("工作空间外的点 (2.5, 0.0) 有解吗？", ik(2.5, 0.0) or "无解")

    正解给出末端 = (0.8660, 1.3000)

解 1：theta1 =   30.00 度  theta2 =   60.00 度  ->  末端 (0.8660, 1.3000)
解 2：theta1 =   82.66 度  theta2 =  -60.00 度  ->  末端 (0.8660, 1.3000)

工作空间外的点 (2.5, 0.0) 有解吗？ 无解

    这个输出把两件事一起说清楚了：

    · 两组解都精确回到同一个末端 —— 逆解不难写，难在挑 · 点 \((2.5, 0)\) 距基座 \(2.5 > a_1 + a_2 = 1.8\)，直接判无解 （代码里靠 \(|\cos\theta_2| > 1\) 挡住，走不到开方那一步）

    2.4 两组解其实互为镜像¶

    把坐标轴转到「基座 → 目标」的方向上再看， 两组解就变成关于这条轴上下对称的镜像 —— 这正是「肘上 / 肘下」的由来。

    这条对称性有个很实用的推论： 平面两连杆的能力只取决于距离 \(r\)，与目标在哪个方向无关 —— 所以它的可达工作空间是一个圆环（内半径 \(|a_1-a_2|\)，外半径 \(a_1+a_2\)）。

    三、六轴串联机器人：把「位置」和「姿态」分开解¶

    3.1 腕心：让问题裂成两半¶

    六轴机器人有 6 个未知角、6 个方程，硬解是强耦合的三角函数组。 但工业机器人几乎都采用球形手腕： 第 4、5、6 三根轴线交于同一点 —— 这个交点叫腕心。

    有了腕心，问题立刻拆成两步：

    步骤 求什么 依据
    逆位置 \(\theta_1,\theta_2,\theta_3\) 腕心的位置只由前三个关节决定
    逆姿态 \(\theta_4,\theta_5,\theta_6\) 腕的姿态相对小臂，只由后三个关节决定

    为什么能拆开：因为第 4、5、6 三个关节只改变手腕的姿态， 不移动腕心。所以先只盯住腕心这一个点解出前三个角， 再回头解手腕的转动 —— 两个较小的方程组，各自都好解。

    找出腕心的位置：从目标位姿 \(\boldsymbol{p}\) 出发， 沿着末端 \(z\) 轴往回退 \(d_6\)（末端到腕心的距离）：

    \[ \boldsymbol{p}_{\text{腕}} = \boldsymbol{p} - d_6\,\boldsymbol{z}_{\text{末端}} \]

    3.2 逆位置：\(\theta_1\) 两解 × 肘部两解¶

    先定 \(\theta_1\)：把腕心投影到基座平面 \(x_0\text{–}y_0\) 上看方位。 若肩部有偏距，一般会得到两组解，习惯上叫「左臂」和「右臂」。

    再定 \(\theta_2, \theta_3\)：在手臂所在的平面内， 这变成一个平面两连杆问题 —— 正是上一节的内容，因此又有 「肘上 / 肘下」两组解。

    于是逆位置最多有 \(2 \times 2 = 4\) 组解。

    一个真实的奇异情形

    如果腕心正好落在基座的旋转轴上（投影到基座平面就是原点）， 那么 \(\theta_1\) 可以是任意值 —— 无穷多解。

    这时机器人的手臂是竖着的，绕基座轴怎么转腕心都不动。 这不只是"解不唯一"，而是雅可比降秩的奇异位形 （下一章会给出统一的判据）。

    3.3 逆姿态：再乘一个 2¶

    每组逆位置解定下来后，前三个关节已知， 于是可以算出小臂坐标系到末端坐标系的相对姿态：

    \[ {}^{3}_{6}R = \bigl({}^{0}_{3}R\bigr)^{\mathsf T}\ {}^{0}_{6}R \]

    再从这个 \(3\times3\) 旋转矩阵里反解 \(\theta_4, \theta_5, \theta_6\)。 欧拉角反解一般也给出两组解 —— 因为腕部可以「翻过来」再转一圈。

    总数因此是：

    \[ \underbrace{2}_{\text{左臂/右臂}} \times \underbrace{2}_{\text{肘上/肘下}} \times \underbrace{2}_{\text{腕翻转}} \;=\; 8 \]

    所以「六轴机器人的逆解最多 8 组」 —— 这是个可以推出来的计数，不是背下来的数字。

    3.4 什么时候能写出解析解¶

    有两类结构存在闭式解：

    结构 条件
    球形手腕 最后三个轴线交于一点（绝大多数工业机器人如此）
    Pieper 准则 存在三个相邻轴线相交于一点或互相平行

    Pieper 准则（Pieper，1968）说的是： 只要三根相邻轴线相交或平行，那个三角函数方程组就能被因式分解成 若干一元方程，从而解析求解。球形手腕正是它的一个特例。

    反过来：不满足这两类条件的六轴机构， 一般没有解析解，只能走数值迭代。

    3.5 一般结构的数值解法：牛顿-拉夫森¶

    思路很朴素：把「末端位置误差」当成要消掉的量，反复修正关节角。

    设当前关节角 \(\boldsymbol{q}\)，希望末端到达 \(\boldsymbol{p}\)：

    \[ \boldsymbol{q}_{k+1} = \boldsymbol{q}_{k} + \boldsymbol{J}^{-1}(\boldsymbol{q}_k)\, \bigl(\boldsymbol{p} - \boldsymbol{f}(\boldsymbol{q}_k)\bigr) \]

    其中 \(\boldsymbol{f}\) 是正运动学，\(\boldsymbol{J} = \partial \boldsymbol{f} / \partial \boldsymbol{q}\) 是雅可比矩阵（下一章的主角）。 这个式子就是高维的牛顿法：用一阶导数把误差线性化，一步推到近似解。

    import numpy as np

d = np.deg2rad
a1, a2 = 1.0, 0.8


def fk(q):
    """平面 2R 正解，返回末端位置向量"""
    t1, t2 = q
    return np.array([a1 * np.cos(t1) + a2 * np.cos(t1 + t2),
                     a1 * np.sin(t1) + a2 * np.sin(t1 + t2)])


def jac(q):
    """平面 2R 的雅可比：把关节速度映到末端速度"""
    t1, t2 = q
    s1, c1 = np.sin(t1), np.cos(t1)
    s12, c12 = np.sin(t1 + t2), np.cos(t1 + t2)
    return np.array([[-a1 * s1 - a2 * s12, -a2 * s12],
                     [a1 * c1 + a2 * c12, a2 * c12]])


def ik_newton(p, q0, iters=30):
    """数值逆解：从初值 q0 出发做牛顿-拉夫森迭代，返回 (解, 迭代次数)"""
    q = np.array(q0, dtype=float)
    n = 0
    for n in range(1, iters + 1):
        e = p - fk(q)                # 末端位置误差
        if np.linalg.norm(e) < 1e-12:
            break
        q = q + np.linalg.solve(jac(q), e)
    return q, n


def wrap(a):
    """把角度折算到 (-180, 180]，方便对比"""
    return (np.rad2deg(a) + 180.0) % 360.0 - 180.0


target = np.array([0.8660, 1.3000])

# 初值不同，收敛到不同的解 —— 这是数值逆解最要留意的性质
for q0 in ([d(10), d(10)], [d(60), d(60)]):
    q, n = ik_newton(target, q0)
    print("初值 (%4.0f, %4.0f) -> theta1 = %6.2f, theta2 = %6.2f 度"
          "  （%2d 次迭代）"
          % (np.rad2deg(q0[0]), np.rad2deg(q0[1]), wrap(q[0]), wrap(q[1]), n))

# 从「完全伸直」的位形出发会失败：那里雅可比降秩（下一章讲）
print()
print("从伸直位形 (0, 0) 出发：", end=" ")
try:
    ik_newton(target, [0.0, 0.0])
except np.linalg.LinAlgError as e:
    print("失败 ——", e)

    初值 (  10,   10) -> theta1 =  82.66, theta2 = -60.00 度  （11 次迭代）
初值 (  60,   60) -> theta1 =  30.00, theta2 =  60.00 度  （ 6 次迭代）

从伸直位形 (0, 0) 出发： 失败 —— Singular matrix

    这 4 行输出里藏了数值解法的全部特点：

    ① 迭代很快。 6～11 次就收敛到 \(10^{-12}\) 以内 —— 牛顿法是二阶收敛，误差平方级下降。

    ② 收敛到哪一组解，取决于初值。 从 \((10^\circ, 10^\circ)\) 出发落到解 2，从 \((60^\circ, 60^\circ)\) 出发落到解 1。 数值法从来不告诉你"一共几组解"，它只给你离初值最近的那一组。

    ③ 初值选在奇异位形上会直接失败。 \((0^\circ, 0^\circ)\) 是手臂完全伸直的位形， 那里的雅可比不可逆（\(\det \boldsymbol{J} = 0\)）， np.linalg.solve 直接抛 Singular matrix。

    工程含义：数值逆解必须配一个「安全的初值」

    由上面第 ②③ 条，工程实现里不能随手拿默认值当初值：

    · 初值取当前关节角 —— 保证解离当前位置最近， 机械臂不会突然甩到另一种站法上去（这也是「增量式」控制的由来） · 初值避开奇异位形 —— 否则迭代第一步就发散或报错 · 加迭代上限与误差阈值 —— 迭代不收敛时必须能退出来， 并向上报告「本周期无解」，而不是卡死控制回路

    这也解释了为什么解析解仍然值钱：解析解一次给出全部解， 可以按「离当前位置最近」去挑；数值解得换好几个初值才能拼出全貌。

    四、解不唯一、或干脆没有解析解时怎么办¶

    4.1 冗余机器人（\(n > 6\)）：无穷多解¶

    关节数多于任务维数时，解不是有限多组，而是一整个流形。 平面三连杆就是最简单的例子：工作空间内部每一点都对应无穷多组解 —— 这种机器人叫运动学冗余。

    怎么挑一组：加一个次要目标，在满足末端位姿的前提下优化它：

    次要目标 想达到的效果
    \(\min \|\dot{\boldsymbol{q}}\|\) 关节运动量最小
    \(\min\) 关节离限位的程度 尽量远离限位、留出余量
    \(\max\) 可操作度 尽量远离奇异位形
    避开障碍 让连杆绕开工作空间里的障碍物

    数学上常用雅可比伪逆 \(\boldsymbol{J}^{\dagger}\)（\(n>6\) 时用 \(\boldsymbol{J}^{\mathsf T}(\boldsymbol{J}\boldsymbol{J}^{\mathsf T})^{-1}\)）， 它给出的解在所有满足任务的关节速度里二范数最小。

    4.2 欠驱动机器人（\(n < 6\)）：一般是「无解」¶

    关节数少于任务维数时，末端根本到不了任意位姿 —— 被动的关节不受控，能主动产生的运动方向少于 6 个。

    不过有两件事仍然成立：

    · 被动关节抗外力的能力：某些方向上它虽然动不了， 却能抵抗外力而不动（对应雅可比零空间） · 欠驱动不等于没用：在重力、动量、接触等自然动力学的帮助下， 欠驱动系统往往仍能完成特定任务（如欠驱动手指的抓取）

    4.3 并联机器人：正逆难易正好对调¶

    机构 正向运动学 逆向运动学
    串联 容易（连乘） 难（多元耦合方程）
    并联 难（要解多条支链的约束方程） 容易（每条支链各自是简单的串联链）

    原因：并联机构的每一条支链都是串联的， 所以「给定末端位姿 → 各支链的关节角」是逐链独立的简单问题； 反过来「给定各支链关节角 → 末端位姿」却要让所有支链同时满足， 就成了耦合方程组。

    这就是「对偶性」的含义：串联难的地方，正好是并联容易的地方。

    看结构决定「哪一头好算」

    判断机器人正逆运动学哪头容易，看运动传递的方向：

    · 一动（少数驱动）牵出多处（多支链）的 → 正解难、逆解易（并联） · 多处（多关节）汇到一处（末端）的 → 正解易、逆解难（串联）

    这条经验在选机构时就能用上： 要让控制端好算，就尽量让"逆解"落在容易的那一侧。

    典型例题¶

    例题 1：平面两连杆求逆解¶

    平面两连杆机器人 \(a_1 = 1.0\)、\(a_2 = 0.8\)，末端要到达点 \((0.8660, 1.3000)\)。 求全部关节角解（单位：度）。

    思路

    先算 \(r^2 = x^2+y^2\)，用余弦定理求 \(\cos\theta_2\)， 再判断 \(|\cos\theta_2|\) 是否超过 1。然后用 \(\mathrm{atan2}\) 求 \(\theta_1\)。

    解答

    第一步：判可达性

    \[ r^2 = 0.8660^2 + 1.3000^2 = 0.7500 + 1.6900 = 2.4400 \]

    \(r = 1.5620\)，而工作空间是 \(|a_1-a_2| = 0.2\) 到 \(a_1+a_2 = 1.8\) 的圆环， \(1.5620\) 落在环内 —— 有解。

    第二步：求 \(\theta_2\)

    \[ \cos\theta_2 = \frac{r^2 - a_1^2 - a_2^2}{2a_1a_2} = \frac{2.44 - 1 - 0.64}{1.6} = 0.5 \]

    所以 \(\theta_2 = \pm 60^\circ\) —— 两组解的分岔就在这里。

    第三步：求 \(\theta_1\)

    末端的方位角是

    \[ \mathrm{atan2}(1.3,\ 0.8660) = 56.31^\circ \]

    对 \(\theta_2 = +60^\circ\)：

    \[ \theta_1 = 56.31^\circ - \mathrm{atan2}(0.8\sin 60^\circ,\ 1 + 0.8\cos 60^\circ) = 56.31^\circ - \mathrm{atan2}(0.6928,\ 1.4) = 56.31^\circ - 26.33^\circ = 30.0^\circ \]

    对 \(\theta_2 = -60^\circ\)：

    \[ \theta_1 = 56.31^\circ - \mathrm{atan2}(-0.6928,\ 1.4) = 56.31^\circ + 26.35^\circ = 82.66^\circ \]

    两组解：\((30.0^\circ, 60.0^\circ)\) 与 \((82.66^\circ, -60.0^\circ)\)。 代码实跑与手算一致 ✓

    例题 2：六轴机器人为什么最多 8 组解¶

    一台六轴、带球形手腕的工业机器人。请说明它的逆解为什么最多有 8 组，并把 8 拆成三个因子的来源。

    思路

    先想清楚「腕心」这个点把问题切成了哪两块。 再分别数「前三个关节有几个解」「后三个关节有几个解」。

    解答

    拆成两块靠的是腕心： 球腕的 4、5、6 轴交于一点，这个交点只随前三个关节移动。

    第一块：逆位置（\(\theta_1, \theta_2, \theta_3\)）—— 4 组

    · \(\theta_1\)：把腕心投影到基座平面定位方位。 有肩部偏距时一般有两组（左臂 / 右臂）。 若腕心正落在基座旋转轴上，则退化成无穷多解（奇异）。 · \(\theta_2, \theta_3\)：在手臂平面内是平面两连杆问题， 因此有两组（肘上 / 肘下）。

    合计 \(2 \times 2 = 4\) 组位置解。

    第二块：逆姿态（\(\theta_4, \theta_5, \theta_6\)）—— 各组位置解再乘 2

    位置解定下后，小臂到末端的相对姿态 \({}^{3}_{6}R = ({}^{0}_{3}R)^{\mathsf T}{}^{0}_{6}R\) 已知， 从中反解三个腕关节角。欧拉角反解有两组解 —— 腕可以「翻过来」再转一圈，末端姿态相同。

    乘起来：

    \[ 2_{\text{臂}} \times 2_{\text{肘}} \times 2_{\text{腕}} = 8 \]

    要点：8 不是背下来的常数，而是三个独立的二值选择的乘积。 结构一变（比如少了肩部偏距），这个数目就跟着变。

    例题 3：判断一个目标点有没有解¶

    机器人末端到基座的距离为 \(2.5\)。该机器人末端能到达的 距离范围是 \([0.2,\ 1.8]\)。请判断有没有逆解， 并说明工程实现上应该在哪一步就把它挡住。

    思路

    先想可达工作空间的边界是什么。 再想：如果先迭代、迭代到一半才发现够不着，会有什么后果？

    解答

    结论：无解。

    因为可达范围是 \([0.2, 1.8]\)，而 \(2.5 > 1.8\) —— 末端已经超出最远可达距离（即两段杆完全伸直时的长度和）。

    工程实现上要在「进迭代之前」就挡住：

    1

    输入：目标位置 p
1. 算 r = |p - 基座|
2. 若 r > 最远可达  或  r < 最近可达：直接返回「无解」   ← 这里挡住
3. 否则再做解析求根 / 数值迭代

    为什么必须前置判据：

    · 数值法会白算。 迭代不会"发现"无解，它会一路跑到 误差不再下降、撞上迭代上限才停 —— 白花时间，控制周期被拖长。 · 能给出有意义的信息。 前置判据可以告诉上层 「这个目标在工作空间之外」，规划器可以据此改目标； 而迭代失败只说得出"没收敛"。 · 避免误判为奇异。 无解和奇异位形都可能表现为"迭代不动"， 提前用几何判据排除无解，才不会把两者混为一谈。

    例题 4：多解时到底该挑哪一组¶

    六轴机器人的逆解有 8 组。给出一条实际可用的挑选策略， 并说明为什么不能「随便取第一组」。

    思路

    想：这 8 组解在几何上差别有多大？ 再想：机械臂在两组解之间切换，末端会怎样运动？

    解答

    推荐策略：按「离当前关节角最近」挑，即最小化 \(\|\boldsymbol{q} - \boldsymbol{q}_{\text{当前}}\|\)。

    理由是三条物理约束叠加出来的：

    ① 关节限位。 8 组解里通常只有少数几组每个关节都在限位范围内 —— 先把越限的整组剔除。这一步往往就能砍掉一大半。

    ② 运动量最小。 从上一次的位置出发，走最短的关节路径到达新解， 末端轨迹最容易预测，也最省时间。

    ③ 远离奇异。 有些解虽然更近，但恰好落在奇异位形附近， 关节速度需求会暴涨。所以一般还会加一个可操作度的下界做过滤。

    为什么不能随便取第一组：

    8 组解在关节空间里相隔很远，但末端位姿完全相同。 如果这一周期取第 1 组、下一周期取第 5 组， 末端不动、关节却要大幅甩动 —— 轻则运动突兀、振动，重则撞到工装或伤人。

    所以「多解」并不等于「随便选一个都行」： 解的正确性只保证末端到位， 而连续性要靠挑选策略来保证。 工程代码里通常写成：

    1
2
3
    候选 = [q for q in 全部解 if 各关节都在限位内]
若能选出候选：返回 argmin |q - q_当前|
否则：报告「本周期无解」，保持当前位姿

    一句话：多解问题的后半段不是数学，而是工程约束下的取舍。

    自测¶

    Q1 为什么正向运动学一定有唯一解，而逆向运动学可能多解甚至无解？ 请从运算方向解释。

    提示

    想：正向运动学每一步在做什么 —— 是「求值」还是「解方程」？ 有没有需要做选择的地方？

    解答

    因为正向运动学是「从关节往末端乘」，每一步都是确定的。

    给定 \(\theta_1, \dots, \theta_n\)，代入每个连杆变换矩阵、连乘， 得到末端位姿。矩阵乘法没有选择余地：给定一组矩阵，乘积唯一。 所以正向运动学一定有唯一解。

    逆向运动学要「解」这组三角函数的非线性方程。 于是三类麻烦都来了：

    · 多解：几何上真的有好几种站法（肘上/肘下、左臂/右臂、腕翻转） · 无解：目标在可达工作空间之外 · 无闭式：结构不特殊时没有通用解析解，只能迭代

    一句话：正向运动学是求值，逆向运动学是解方程 —— 这不是"算法好坏"的差别，而是问题性质的差别。

    Q2 什么是「腕心」？它为什么能让六轴逆解拆成「逆位置 + 逆姿态」两步？

    提示

    想：球形手腕的第 4、5、6 根轴线有什么特殊关系？ 后三个关节转动时，那一个交点会不会移动？

    解答

    腕心是球形手腕中第 4、5、6 三根轴线的公共交点 （要求三轴交于一点，这是「球形手腕」的定义）。

    为什么能拆分： 第 4、5、6 关节只是让手腕绕腕心转动， 不会移动腕心 —— 腕心的位置完全由前三个关节 \(\theta_1,\theta_2,\theta_3\) 决定。

    于是可以：

    ① 先只盯住腕心这个点。 从末端位姿沿末端 \(z\) 轴回退 \(d_6\) 得到腕心的位置，用它反解前三个关节（逆位置）。

    ② 再解手腕。 前三个角已知后， 小臂到末端的相对姿态 \({}^{3}_{6}R = ({}^{0}_{3}R)^{\mathsf T}{}^{0}_{6}R\) 就已知了， 从中反解 \(\theta_4,\theta_5,\theta_6\)（逆姿态）。

    好处：把一个 \(6\times6\) 的强耦合方程组分成了两个较小的问题 —— 前者是「点定位 + 平面两连杆」，后者是「欧拉角反解」， 两者都有现成解法。这就是球形手腕能出解析解的原因。

    Q3 数值逆解「收敛到哪一组解取决于初值」，这在工程上会带来什么后果？ 怎么应对？

    提示

    先想：如果这一周期算出的解和上一周期不是同一组，关节会怎样？ 再想：什么初值能让结果「接得上」上一次？

    解答

    后果：末端位姿没变，关节角却可能突然跳到另一种站法。

    因为 8 组解在关节空间里相隔很远，但在任务空间里完全等价。 如果初值换了，迭代就收敛到另一个解 —— 末端还是那个点，关节却要大幅甩动， 表现为运动突兀、冲击、甚至碰撞。

    另外还有一条：初值落在奇异位形上，迭代第一步就失败 （雅可比不可逆），并抛出求解异常。

    应对办法（工程上的标准做法）：

    措施 作用
    用当前关节角做初值 收敛到离当前位置最近的解，保证连续
    初值避开奇异位形 避免迭代第一步就发散
    加迭代上限与误差阈值 不收敛时能退出，不卡死控制回路
    失败时保持当前位姿并上报 让上层规划器决定改目标还是停车

    补充：正因为数值解只给「离初值最近的一组」， 要拿到全部解就得换多个初值反复跑 —— 这就是解析解仍然值钱的原因：它一次给出全部解，直接按需挑选。

    Q4 并联机器人的逆运动学为什么反而比正向运动学容易？

    提示

    想：并联机构的每条支链本身是什么结构？ 再想：给定位姿求关节角、和给定关节角求位姿，哪个要「同时满足多个支链」？

    解答

    因为每一条支链都是独立的串联链。

    逆向（容易）：给定末端位姿， 每条支链的两端位置都已知了（一端接基座、一端接动平台）， 于是「求这条支链各关节角」就是逐条求解简单的串联链问题 —— 各支链互不相干，可以独立算。

    正向（难）：给定所有支链的关节角， 要反推动平台的位姿，就必须让所有支链同时满足约束 —— 得到一个耦合方程组，且往往有多个解， 还需要处理支链之间的相容性。

    这就是串联与并联的「对偶性」：

    机构 正解 逆解
    串联（多处汇到一处） 易（连乘） 难（耦合方程）
    并联（一处牵出多处） 难（耦合方程） 易（逐链独立）

    所以真正决定「哪一头好算」的，是运动传递的方向， 而不是"串联"或"并联"这两个词本身。

    小结¶

    要记住的 为什么重要
    正解是「算」，逆解是「解」 正解唯一；逆解可能多解、无解、无闭式
    可达工作空间有内外两个边界 平面两连杆是圆环；边界外直接判无解
    平面两连杆有两组解 = 肘上 / 肘下 两组解关于「基座到目标」的连线镜像
    腕心把六轴问题拆成「逆位置 + 逆姿态」 球腕的 ⅘/6 轴交点只随前三个关节动
    六轴最多 8 组解 = \(2\times2\times2\) 是三处二值选择的乘积，不是背的常数
    Pieper 准则：三根相邻轴相交或平行 → 有解析解 球形手腕是它的特例；不满足时只能迭代
    数值解（牛顿法）快，但结果依赖初值 初值取当前关节角，并避开奇异位形
    冗余（\(n>6\)）无穷多解 → 加次要目标挑 用伪逆保证关节速度二范数最小
    并联机构正逆难易对调 逐链独立 → 逆解易；同时满足 → 正解难

    四条最容易出错的地方：

    1. 用 \(\arctan\) 代替 \(\mathrm{atan2}\) —— 第二、三象限的解会整体转错 \(180^\circ\)
    2. 先迭代、后发现够不着 —— 无解应在进迭代前用距离判据挡住
    3. 多解时随手取第一组 —— 末端不动而关节大甩，运动不连续
    4. 初值取在奇异位形上 —— 雅可比不可逆，迭代第一步就失败
