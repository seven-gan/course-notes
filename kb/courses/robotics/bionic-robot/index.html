    仿生机器人¶

    上一页的水下机器人，说到底还是一艘「会自己开会的小潜艇」： 靠螺旋桨把水往后推，靠舵改变方向。 自然界却早就给出了另一种答案 —— 鱼。 它没有桨、没有舵，只靠身体与鳍的波动， 就能在几厘米外急停、原地转向、顺着涡流省力地巡航。 这一页就讲把这套本领搬到机器人身上： 仿鱼机器人身体怎么摆（一）→ 波形怎么产生、怎么调（二）→ 航线怎么跟（三）→ 别的仿生机器人又是怎么回事（四）。

    这一页的主线

    仿生机器人的一切，都可以归到一句话： 推力的来源，从「旋转」换成了「波动」。 于是三件事跟着一起换了： ① 结构 —— 身体要能弯，于是「摆动波形」成了机构设计的核心； ② 控制 —— 波形得由某种「节奏发生器」自己长出来，于是有了 CPG； ③ 评价 —— 好不好不再只看推力，还得看无量纲相似数（Strouhal 数、减缩频率）。 这一页就沿 ①→②→③ 走，最后用一节看别的仿生机器人 —— 你会发现它们和机器鱼吃的是同一套「设计律」。

    「仿生」不等于「长得像」

    把机器人做成鱼的样子，本身一点用都没有。 真正要抄的是鱼的运动规律：体波怎么传、相位差怎么定、频率和摆幅怎么配才高效。 「像鱼」是表象，「像鱼的动力学」才是本质 —— 这是本页会反复回到的一条。

    一、仿鱼机器人结构¶

    1.1 鱼为什么是「摆」，而不是「转」¶

    先看一个对比。给一台普通水下机器人提速，你做的事是让螺旋桨转得更快； 给一条鱼提速，它做的是让身体摆得更快、幅度更大。这两件事在物理上有什么不同？

    螺旋桨的推力来自定常地给水加动量：桨叶在某一瞬间，水在它周围的流场几乎是稳定的， 所以可以用「升力、阻力随速度平方变」这类 准定常公式去算。

    鱼的推力则来自非定常地给水加涡量：身体每一段都在不断改变方向， 水来不及跟上，于是在鳍的后缘卷出涡（前缘涡、尾涡）， 推力主要来自这些涡的结构与脱落节奏，而不是来自「一个稳态攻角」。

    这一条差别，决定了后面所有内容。

    对比项 螺旋桨 / 舵 鱼的身体波动
    推力来源 定常流体动量（准定常） 非定常涡量（前缘涡、尾涡捕获）
    效率关系 随转速平缓变化 只在特定「频率 × 摆幅 ÷ 航速」组合下最高
    机动能力 受舵面限制，转弯半径大 身体本身就是舵，可原地转向、急停
    噪声特征 高速旋转的空化噪声大 低频、隐蔽（军事上最看重这一点）
    建模难度 有成熟的螺旋桨模型 涡的演化难算，理论仍在发展中

    最关键的是第二行：鱼的效率不是「越快越高」的单调关系， 而是存在一个窗口 —— 后面 2.3 节会用 Strouhal 数把它量化出来。 这正是「仿生推进」与「螺旋桨推进」在控制目标上的分水岭： 螺旋桨只管把转速拉上去，而仿生推进必须把频率、摆幅、航速三者配在一起。

    1.2 两大类推进方式：BCF 与 MPF¶

    生物学家把鱼的推进方式分成两大类，这个分类直接决定机器人该怎么造。

    模式 全称 靠什么推 代表鱼 长处 短处
    BCF 身体 / 尾鳍推进（Body and Caudal Fin） 身体波动 + 尾鳍 鲹、鲭、鳗 加速快、巡航效率高 转弯半径大、悬停难
    MPF 中间鳍 / 对鳍推进（Median and Paired Fin） 胸鳍、背鳍、臀鳍 箱鲀、鳐、海龟 机动性极好、能原地转 速度慢、效率低
    • BCF 用「大而慢」的波：整个身体当推进面，波长与体长同量级， 所以推力大、能长时间巡游，但身体一摆，整机就跟着转，精细定位难。
    • MPF 用「小而快」的波：只动鳍，身体基本不动， 于是六个自由度可以解耦着控，适合在礁石缝里钻、在水下作业时悬停； 代价是推进面积小，速度上不去。

    我们的水下平台（UUV）没有高速与作业的双重需求， 所以下面主要讲 BCF —— 也就是「机器鱼」最常见的那一种： 一条能弯的躯干，加一个负责摆动的尾鳍。

    1.3 波动是什么样的波：行波、驻波与体波速度¶

    鱼的身体中线可以写成一个波。关键是这个波必须传播：

    \[ y(x,t) = A(x)\,\sin\!\left(kx - \omega t\right) \]

    其中 \(x\) 是从头部量的体轴坐标，\(k = 2\pi/\lambda\) 是波数（\(\lambda\) 是体波波长）， \(\omega = 2\pi f\) 是角频率，\(A(x)\) 是随位置变化的摆幅包络。

    它有两个要点。

    要点一：波必须往后跑（行波）。 上式里 \(kx - \omega t\) 意味着 波形随时间从头部向尾部推移，它的传播速度是

    \[ V_w = \frac{\omega}{k} = f\,\lambda \]

    这个 \(V_w\) 叫 体波速度。鱼把身体的动量往后方甩， 反作用力就把它自己推向前 —— 这才是推力的来源。 如果换成「驻波」形式 \(y = A(x)\sin(kx)\cos(\omega t)\)， 身体只是原地上下挥舞、波峰不传播，水被来回搅而不是被往后甩， 净推力几乎为零。所以设计机器鱼的第一条铁律是： 要行波，不要驻波。

    把两种波并排画出来，差别一眼可见：行波的波峰随时间一路往尾部推移；驻波的波峰却钉在原地，只在上下翻。

    要点二：包络要「头小尾大」。 鱼的身体像一根悬臂梁： 头部连接着质量与惯性，几乎不动；越往尾端，摆幅越大。 一个常用的包络是二次多项式

    \[ A(x) = L\left(a_0 + a_1 u + a_2 u^2\right),\qquad u = \frac{x}{L} \]

    其中 \(L\) 是体长。\(a_1\) 通常取负、\(a_2\) 取正， 于是曲线先微微收窄、再在尾端迅速放大 —— 这正是鱼的做法： 前段稳住姿态，后段拼命做功。

    行波速度必须大于航速

    如果 \(V_w \le U\)（体波跑得比鱼还慢），波形就追不上前方的水， 推力会迅速塌到零。鱼的正常巡游里 \(V_w/U\) 大约在 1.2 ~ 1.5 —— 这个比值不是随便定的，2.3 节会用细长体理论算出它的来由。

    1.4 算例：把身体波动离散成关节角¶

    真实机器鱼不可能有「连续弯曲的身体」，它是若干连杆串起来的。 于是问题变成：给定想要的体形波形，每一根连杆该转到多少度？ 这就是一次逆运动学 —— 从「期望形状」反解「关节角」。

    做法很直接：把 \([0, L]\) 等分成 \(N\) 段，每一段用中点处的切线角 近似这一根连杆的姿态角；相邻连杆的姿态角之差，就是它们之间关节的转角。

    取一条典型的机器鱼（体长半米、摆尾 1.5 Hz、体波波长等于体长），三个式子要用到的量与系数如下：

    量 取值 含义
    \(L\) \(0.50\) m 体长
    \(f\) \(1.5\) Hz 摆尾频率
    \(\lambda\) \(1.00\) m 体波波长
    \(N\) \(4\) 连杆（关节）数
    \(a_0,\ a_1,\ a_2\) \(0.02,\ -0.08,\ 0.16\) 包络 \(A(u)/L\) 的二项式系数（\(u = x/L\)）

    由前三个量立刻得到角频率、波数与摆动周期：

    \[ \omega = 2\pi f = 9.42\ \text{rad/s},\qquad k = \frac{2\pi}{\lambda} = 6.28\ \text{rad/m},\qquad T = \frac{1}{f} = 0.67\ \text{s} \]

    第一步，写下摆幅包络。 也就是 1.3 节那个 \(A(x)\)，取二次多项式：

    \[ A(x) = L\left(a_0 + a_1 u + a_2 u^2\right),\qquad u = \frac{x}{L} \]

    第二步，求中线的斜率。 对 \(y = A(x)\sin(kx - \omega t)\) 关于 \(x\) 求导：

    \[ \frac{\mathrm{d}y}{\mathrm{d}x} = \frac{\mathrm{d}A}{\mathrm{d}x}\,\sin(kx - \omega t) + A(x)\,k\,\cos(kx - \omega t) \]

    第三步，把斜率换算成连杆姿态角。 第 \(i\) 根连杆取中点 \(x_i = (i + 0.5)\,L/N\)，它的姿态角就取该点的切线角 \(\beta_i = \arctan\!\left(\dfrac{\mathrm{d}y}{\mathrm{d}x}\Big|_{x_i}\right)\)， 相邻连杆姿态角之差就是这一处关节的转角：

    \[ \Delta_i = \beta_i - \beta_{i-1},\qquad i = 2,\dots,N \]

    把上面三步按 \(t = 0,\,0.25T,\,0.5T,\,0.75T\) 逐个代进去，就得到下面的结果。

    也就是说，这条半米长的鱼身上刚好装着半个波。沿体轴 \(x/L = 0,\ 0.25,\ 0.5,\ 0.75,\ 1.0\) 处的摆幅包络 \(A(x)\) 依次是

    1.5 从连续曲线到有限连杆：误差在哪¶

    离散成 \(N\) 根连杆，一定和连续曲线有差。差别来自两处：

    • 弦与弧的差。 连杆是直的，曲线是弯的， 所以任何一根连杆都不可能与它对应的那一段弧完全重合。 这根「以直代曲」的误差随每段弧长 \(L/N\) 的平方减小 —— 连杆越多，误差掉得很快。
    • 捷线近似的差。 我们用「中点切线角」代表整根连杆， 相当于用中点的斜率代替整段， 这也是一个二阶精度近似（中点法的典型性质）。

    于是工程上就出现了一个取舍：

    \[ \text{连杆数 } N \uparrow \;\Rightarrow\; \text{波形更接近理论，但关节更多、更重、更难协调} \]
    • 关节多了，每一段都要舵机、都要传动，重量与复杂度一起涨；
    • 关节多了，控制维度也涨 —— 每个关节既要跟相位、又要跟摆幅， 参数一整排，调参和容错都更麻烦；
    • 而且段太短，水动力上并不划算：太细的尾段只是「乱摆」，不产生有效涡。

    所以真实的机器鱼，躯干通常 3 ~ 6 段，尾巴再单独一两个自由度， 而不是「越多越好」。这和 1.1 节那条结论是一致的： 仿生的目标是「像鱼的动力学」，不是「像鱼的形状」 —— 能把行波做出来，几段就够了。

    二、仿鱼游动机器人运动控制¶

    2.1 波形从哪来：开环回放，还是 CPG¶

    1.4 节算的是一组关节角。但机器人要的是一台能自己产生波形、还能随时改的控制器。 有两类做法。

    做法 A：开环回放。 事先把关节角序列算好、存成表，按时间播放。

    • 好处：简单，不需要任何反馈，验证也容易。
    • 坏处：一点都不会应变。想改速度、想转弯、被撞了一下， 都得重新算表；而且真实关节有摩擦、有迟滞，照播放久了就会跑偏。

    做法 B：中枢模式发生器（CPG）。 给每个关节配一个「振荡器」， 让它们彼此耦合，靠耦合自己长出一个稳定的相位关系。

    • 好处：波形是自己涌现出来的，不是被外生指定的； 改一个参数（相位差、频率、幅值）就改了波形， 不用重新设计控制器；受扰动后还能自动恢复到节律。
    • 坏处：要多调几个耦合参数，而且要保证它确实会收敛（不是越振越乱）。

    CPG 的关键在于耦合项怎么写。最常用的一种是「相邻关节的相位牵引」：

    \[ \dot{\theta}_i = \omega + K\,\sin\!\left(\theta_{i-1} - \theta_i - \varphi\right) \]
    • \(\omega = 2\pi f\) 是每个关节自己的固有角频率（保证大家一起同频）；
    • \(\varphi\) 是相邻关节要维持的相位差（决定波形，1.4 节里「尾端滞后」的那一项）；
    • \(K\) 是耦合强度（决定「多快被拉齐」）。

    它的物理含义很朴素：如果第 \(i\) 个关节比它前一个关节滞后得比 \(\varphi\) 更多， 这一项就把它往前拽一点；滞后得不够，就往后推一点 —— 一推一拽之间，全体自动排成那个固定的相位差。

    2.3 推力有多大：Strouhal 数与细长体理论¶

    能摆出波形，只是第一步。真正要回答的是：这样摆，能产生多大推力？效率多高？ 用纯流体力学算涡太复杂，工程上有两个又好用、又准得惊人的工具。

    工具一：Strouhal 数。 把「频率、摆幅、航速」三个量合成一个无量纲数：

    \[ St = \frac{f\,A_{pp}}{U} \]

    其中 \(A_{pp}\) 是尾端峰峰摆幅（上下摆幅之和）。这个数的作用是：

    • \(St\) 太大：摆得相对来流太猛，横向的动能大多浪费在洗流里，效率低；
    • \(St\) 太小：摆得相对来流太慢，流场接近准定常，涡的优势用不上效率也低。

    而观测到的自然界规律是：处在高效巡游状态的鱼和鸟， \(St\) 几乎都落在 \(0.25 \sim 0.35\) 这个窄带里。 换句话说，鱼不是随心所欲地摆的，它把这三个量锁在了一个比例上。

    工具二：Lighthill 细长体理论。 把鱼近似成一根细长的「波动板」， 可以得到一个解析的推力公式。先算单位长度的附加质量：

    \[ m_a = \frac{\pi}{4}\,\rho\,D^2 \]

    （\(D\) 是尾部体高，\(\rho\) 是水密度）。再把体波代进去，单位长度上的平均推力是

    \[ T = \frac{m_a A^2}{4}\,\omega^2\left[1 - \left(\frac{U}{V_w}\right)^2\right] \]

    （\(A\) 是尾端单边摆幅，\(\omega = 2\pi f\)）。配套的 Froude 效率是

    \[ \eta = \frac{1}{2}\left(1 + \frac{U}{V_w}\right) \]

    这两个式子各说了一件事：

    • 推力式里的 \([\,1 - (U/V_w)^2\,]\) 说明：\(V_w\) 必须大于 \(U\)， 而且 \(V_w = U\) 时推力恰好为零 —— 这就是 1.3 节那条铁律的定量版本。
    • 效率式里 \(V_w\) 在分母：把体波速度提得越高，效率越低 —— 因为「水被往后甩的速度」和「鱼前进的速度」差得越多，能量浪费越大。

    于是推力与效率天生对立：想推得猛，就得把 \(V_w\) 拉高；想省力，就得让 \(V_w\) 靠近 \(U\)。 鱼的选择是 \(V_w/U \approx 1.2 \sim 1.5\) —— 下一节逐个算出来。

    三、路径跟踪控制¶

    3.1 两级问题：内环摆尾，外环跟线¶

    有了波形和推力，机器鱼就能前进了。但任务通常是「沿某条路径走」， 这就需要把「摆尾」和「走线」分成两层：

    • 内环（推进层）：负责产生推力与偏转 —— 也就是第二讲的波形与 CPG。 给它一个「前进速度」和一个「转艏角速度」，它就执行。
    • 外环（制导层）：负责看路 —— 根据当前位姿与期望路径， 算出期望航向，再交给内环去跟。

    这样分层的好处是：换推进方式（鱼尾、螺旋桨、泵喷）不用改制导， 换制导律（直线、曲线、避障）也不用重建波形。 本章第一节讲结构、第二节讲内环，这一节专门讲外环： 给定一条曲线路径，怎么让机器鱼贴着它走。

    3.2 视线制导与前视距离¶

    最经典的制导律叫视线制导（LOS，Line-of-Sight）， 思想朴素得不像话：在期望路径上，找一个位于我前方的「前视点」， 然后让机器人朝那个点飞。

    如果前视点取在沿路径弧长前方 \(\Delta\) 处，那么期望航向就是

    \[ \psi_d = \operatorname{atan2}\!\left(y_{la} - y,\; x_{la} - x\right) \]

    其中 \((x_{la}, y_{la})\) 是前视点坐标。对一条局部近似直线的路径， 这个式子可以化成一个很干净的形式：

    \[ \psi_d = \psi_p - \arctan\!\left(\frac{e}{\Delta}\right) \]

    这里 \(\psi_p\) 是路径的切线方向、\(e\) 是横向误差（机器人到路径的垂距）。 读这个式子，能得到 LOS 的全部性格：

    • \(e = 0\) 时，\(\psi_d = \psi_p\) —— 正好沿路径切线走，不会自己拐弯；
    • \(e \ne 0\) 时，\(\psi_d\) 会被「扭」一个 \(-\arctan(e/\Delta)\) 的角度， 把机器人朝路径拉回去；
    • 而那个「扭」的力度，完全由 \(\Delta\) 决定 —— 这就是全部玄机所在。

    \(\Delta\) 的两难（本页最关键的一个权衡）：

    • \(\Delta\) 太小：前视点离得很近，稍微有点偏差就要求一个很大的修正角。 于是位置测量噪声（\(3\) cm 量级的 DVL/USBL 抖动）被放大成 \(\sigma/\Delta\) 的航向误差， 舵机被噪声推着来回猛打。
    • \(\Delta\) 太大：前视点离得很远，在弯道上前视点会落到路径的外侧， 于是机器人「抄近路、切内角」，误差反而单调变大，动作也变得迟钝。

    取舍办法：\(\Delta\) 要大到压住噪声、小到不切角。 工程经验上常取 \(\Delta \approx 2 \sim 3\) 倍的特征长度（如船长）， 或者让 \(\Delta\) 随航速成比例增大（\(\Delta \propto U\)）， 使得闭环的「响应快慢」不随速度改变。

    3.4 为什么它会收敛：线性化与劳斯–赫尔维茨¶

    上面是「跑出来」的，但为什么 LOS 一定收敛、而且阻尼随 \(\Delta\) 单调变化？ 把系统在小误差下线性化就能看清楚。

    设 \(\psi\) 是实际航向、\(\psi_p\) 是路径切线方向、\(e\) 是横向误差， 令 \(z = \psi - \psi_p\)（航向偏差）。用 3.2 节的小角形式 \(\psi_d - \psi_p \approx -e/\Delta\)， 再设航向环为 \(\dot{\psi} = K(\psi_d - \psi)\)（增益 \(K\)）。两式合起来：

    \[ \dot{e} \approx U\,z, \qquad \dot{z} = -K\left(\frac{e}{\Delta} + z\right) - \dot{\psi}_p \]

    写成状态 \(\begin{bmatrix} e & z \end{bmatrix}^{\mathsf{T}}\) 的线性系统，忽略路径曲率项 \(\dot{\psi}_p\)， 闭环矩阵与特征方程是

    \[ A = \begin{bmatrix} 0 & U \\[2pt] -\dfrac{K}{\Delta} & -K \end{bmatrix}, \qquad s^2 + K\,s + \frac{KU}{\Delta} = 0 \]

    劳斯–赫尔维茨判据：二阶系统 \(s^2 + a_1 s + a_0\) 稳定，当且仅当 所有系数同号且非零 —— 这里 \(a_1 = K > 0\)、\(a_0 = KU/\Delta > 0\)， 只要 \(K\) 为正就稳定。所以 LOS 不是「碰巧能跟」，它有明确的稳定条件。

    再看阻尼。把它对成标准二阶系统 \(s^2 + 2\zeta\omega_n s + \omega_n^2 = 0\)：

    \[ \omega_n = \sqrt{\frac{KU}{\Delta}},\qquad \zeta = \frac{K}{2\omega_n} = \sqrt{\frac{K\,\Delta}{4U}} \]

    阻尼比 \(\zeta\) 与 \(\Delta\) 成正比 —— 这一条解释了 3.3 节的全部现象。 把上面算例用的参数 \(K = 2.0\)、\(U = 0.6\) 代进去：

    \(\Delta\) (m) 自然频率 \(\omega_n\) (rad/s) 阻尼比 \(\zeta\) 系统性格
    \(0.2\) \(2.449\) \(0.408\) 欠阻尼 → 振荡、抖动
    \(0.5\) \(1.549\) \(0.646\) 接近最优阻尼
    \(1.0\) \(1.095\) \(0.913\) 略过阻尼
    \(2.0\) \(0.775\) \(1.291\) 过阻尼 → 变迟钝
    \(4.0\) \(0.548\) \(1.826\) 更迟钝
    \(8.0\) \(0.387\) \(2.582\) 严重过阻尼 → 切角

    \(\zeta\) 从 \(0.408\) 一路涨到 \(2.582\)，与 3.3 节实测的 「角加速度单调下降、误差先降后升」完全对得上：

    • \(\Delta\) 小 → \(\zeta < 1\)（欠阻尼）：系统想快速修正， 于是在路径两侧来回振荡，再叠加噪声放大，就成了那个 \(3264\) 度/s²；
    • \(\Delta\) 大 → \(\zeta \gg 1\)（过阻尼）：系统慢吞吞地爬， 遇到弯道时根本来不及转，只能切角，误差一路涨到 \(0.73\) m。

    所以「选 \(\Delta\)」在控制语言里就是「选阻尼比」： 想要 \(\zeta \approx 0.7\)（工程上常用的「快而不振荡」），就反解出 \(\Delta = 4U\zeta^2/K\)；本例 \(4 \times 0.6 \times 0.49 / 2.0 \approx 0.59\) m —— 和实测最优的 \(0.5\) m 非常接近。理论给出的和一个逐点扫出来的，落在同一处。

    四、其他仿生机器人¶

    仿生不只在水里。这一节看几个「亲戚」，你会发现它们和机器鱼是同一种思路。

    4.1 扑翼飞行机器人¶

    鸟类与昆虫用扑动的翅膀产生升力和推力，与机器鱼的「摆动」是同一件事： 都是非定常流动里的扑动推进。于是它们共享同一套无量纲数：

    • 减缩频率 \(k = \dfrac{\omega c}{2U} = \dfrac{\pi f c}{U}\) （\(c\) 是弦长），刻画非定常程度：\(k\) 越大，前一个涡还没散、下一个就来了；
    • Strouhal 数 \(St = f A_{pp}/U\)：与鱼完全同一套判据。

    扑翼机器人的难点和机器鱼镜像对称：

    难点 机器鱼（水） 扑翼机（空气）
    介质 密度大，惯量与阻尼都大 密度小，惯性小、受扰动敏感
    尺度 米级，低频（1~2 Hz） 厘米级，高频（几十至数百 Hz）
    柔性 尾鳍柔性帮助成形 翅的柔性是气动弹性核心问题
    仿真 涡难算，但准稳态假设不够用 低雷诺数、非定常与柔性耦合更难

    它们和机器鱼共用同一句方法论：先把无量纲数算清楚，再反推频率与尺寸。

    4.2 足式、爬壁与蛇形机器人¶

    • 足式机器人抄的是「弹簧–质量」动力学：腿像弹簧一样存能—放能 （这在 机器人的位置控制 的柔顺与阻抗控制里有呼应）， 步态则常用 CPG 驱动 —— 与 2.1 节机器鱼的相位耦合是同一类控制器。
    • 爬壁机器人抄的是附着：壁虎靠范德华力、昆虫靠爪刺、 蜗牛靠黏液，于是有干黏附、微刺、吸盘、静电等不同技术路线， 共同点是附着要能主动「吸上/松开」，而不是焊死。
    • 蛇形机器人抄的是「非完整约束下的行波」：身体做出侧向行波， 地面摩擦力各向异性（推进方向小、侧向大）， 于是波浪变成了前进 —— 这几乎是 1.3 节机器鱼波形机制的地面翻版。

    共同点很清楚：它们抄的都是运动规律（波形、相位、阻尼、附着）， 而不是外形。这正是本页开头那条警告。

    4.3 算例：无量纲相似数¶

    最后验证一件「反直觉但其实必然」的事： 尺度差了三个数量级的小东西（不同尺度的鱼、虫、鸟）， 为什么能用同一套「设计律」去设计机器人？

    扑翼减缩频率定义为

    \[k = \frac{\omega c}{2U} = \frac{\pi f c}{U}\]

    它衡量的就是「非定常程度」：自然的推进器都工作在非定常流里。

    看 \(k\) 与「判定」这两列：五种尺度跨了三个数量级，\(k\) 却全落在 \(0.1 \sim 2.0\)，无一例外都在非定常区间。

    对象 频率 \(f\) (Hz) 弦长 \(c\) (m) 航速 \(U\) (m/s) \(k = \pi f c / U\) 判定
    鲹科鱼尾鳍 \(1.5\) \(0.050\) \(0.50\) \(0.471\) 非定常
    仿鱼机器鱼尾鳍 \(1.0\) \(0.060\) \(0.30\) \(0.628\) 非定常

    • \(k \gtrsim 0.1\) 意味着处于非定常流区（准定常要 \(k \lesssim 0.05\)）， 也就是说，它们的推力都来自前缘涡、尾涡这类非定常结构， 用定常翼型理论去算会差得很远；
    • 于是仿生设计的第一步几乎总是「先算目标生物的无量纲数」 （\(St\)、\(k\)、雷诺数），再按这个数反推自己的频率与尺寸。

    这就是为什么「照抄外形」一定失败、而「照抄无量纲数」往往成功 —— 尺寸、频率、速度都可以随尺度变，唯有那几个比例不变。

    要抄什么 机器鱼 扑翼机 足式 / 爬壁
    运动规律 体波行波 + 相位滞后 扑动 + 非定常涡 弹簧–质量 + 步态行波

    三个最容易搞错的地方

    1. 以为「做成鱼形」就是仿生。 外形不产生推力，波形与无量纲比例才产生推力； 一条焊死的「鱼形」机器人，和一块砖头没区别。
    2. 以为体波速度可以随便取。 \(V_w \le U\) 时推力恰好为零（2.3 节）， 而 \(V_w/U\) 太大效率又掉得快 —— 它被锁在 \(1.2 \sim 1.5\) 这个窄带里。
    3. 以为前视距离 \(\Delta\) 越小、跟得越紧就越好。 \(\Delta\) 太小 放大测量噪声、把舵机打废（3.3 节 \(3264\) 度/s²）， 这和 \(St\) 太小反而低效（2.4 节）是同一类「过犹不及」。

    例题 1：为什么「驻波」推不动鱼，而「行波」能¶

    问：1.3 节说「要行波，不要驻波」。请从动量的角度说明： \(y = A(x)\sin(kx - \omega t)\) 与 \(y = A(x)\sin(kx)\cos(\omega t)\) 在「能不能把水往后推」上的本质差别在哪？

    解答

    先看两者的区别。 用三角公式把行波拆开：

    \[ A\sin(kx - \omega t) = A\sin(kx)\cos(\omega t) - A\cos(kx)\sin(\omega t) \]

    也就是说，行波 = 两个相差 \(90°\) 的驻波叠加。 反过来，「纯驻波」只有第一项。

    驻波为什么推不动。 纯驻波 \(y = A\sin(kx)\cos(\omega t)\) 里， 所有质点的位移同时达到最大、又同时回到零（只是幅度不同）。 这意味着整个身体在原地上下挥舞：身体各段的速度要么同向、要么反向， 没有「一段向后甩、一段向前收」的错位。 水被来回推挤，一个周期里往后的净动量与往前的净动量相互抵消 —— 时间平均下来，向后的动量流为零，于是没有净推力。

    行波为什么能。 行波里 \(-\omega t\) 项让波峰不断向后移动： 身体上不同段的相位依次相差，于是永远是 「后面一段向这个方向甩，前面一段向那个方向收」。 身体的横向速度沿着身体呈行波分布，这个分布持续不变地把水沿轴向加速， 于是产生一个稳定、非零的向后动量流。反作用力就是推力。

    一句话：推力来自「动量流的时间平均值不为零」； 驻波的平均动量流恰好为零，行波不是。 所以「波必须传播」不是审美，而是推力的必要条件。

    例题 2：为什么同一条鱼只在一个「速度窗口」里高效¶

    问：2.4 节的 Strouhal 表里，固定 \(f = 1.5\) Hz、\(A_{pp} = 0.10\) m， 只有 \(U = 0.50 \sim 0.60\) m/s 落在高效带。请解释 为什么「太快」和「太慢」都不高效，而且原因还不一样。

    解答

    先抓关键式子。 \(St = fA_{pp}/U\) —— 频率和摆幅都固定时，\(St\) 与航速成反比。 高效带是 \(0.25 \le St \le 0.35\)，反解得

    \[ U = \frac{fA_{pp}}{St} \in \left[\frac{0.15}{0.35},\ \frac{0.15}{0.25}\right] = [0.43,\ 0.60]\ \text{m/s} \]

    与上表一致（\(0.50、0.60\) 命中，\(0.30、0.75\) 落空）。

    为什么「太快」（\(U > 0.60\)，\(St\) 偏小）不高效。 航速相对摆速太快，鱼一摆、水就已经被甩到身后了， 流场趋于准定常：前缘涡来不及卷起来就被对流带走， 非定常增升的那部分没机会发挥。推力与效率一起掉。

    为什么「太慢」（\(U < 0.43\)，\(St\) 偏大）也不高效。 航速相对摆速太慢，鱼摆得很猛，但横向速度很大而前进速度很小 —— 大量动能被用来把水往侧面甩（洗流）， 真正变成推力的那一部分占比很小。推得动，但效率亏掉。

    一句话：两个方向都不好，但坏法不同 —— 太快是「来不及形成涡」，太慢是「把劲使在侧向」。 中间那条窗口，才是「摆的节奏」和「前进的速度」匹配得最好的地方。

    例题 3：前视距离 \(\Delta\) 该取多大¶

    问：3.3 节的表里，\(\Delta\) 从 \(0.2\) 增到 \(8.0\)， 横向误差 RMS 先降后升（\(0.0153 \to 0.0112 \to 0.7313\)）， 平均角加速度一直降（\(3264 \to 110\)）。工程上该怎么定 \(\Delta\)？

    解答

    看清两个指标的方向相反。

    • 精度（RMS 误差） 在 \(\Delta \approx 0.5\) m 取最小，是个 U 形；
    • 平滑度（角加速度） 随 \(\Delta\) 单调下降（\(\Delta\) 越大越平滑）。

    所以「选 \(\Delta\)」本质是在两个相反的方向上找折中。

    两端各是什么机理？

    • \(\Delta\) 太小：噪声 \(3\) cm 被 \(\sigma/\Delta\) 放大成航向抖动， 由 3.4 节 \(\zeta = \sqrt{K\Delta/(4U)}\)，\(\Delta\) 小则 \(\zeta\) 小、 欠阻尼 → 来回振荡，于是角加速度冲到 \(3264\) 度/s²。 这一端的代价是「抖动」，误差还在其次。
    • \(\Delta\) 太大：前视点落到弯道外侧，机器人抄近路切角， 误差单调上涨；同时 \(\zeta\) 很大（过阻尼），响应变迟钝。

    怎么定。

    1. 先定阻尼比。 用 \(\zeta = \sqrt{K\Delta/(4U)}\) 反解， 取工程常用的 \(\zeta \approx 0.7\)： \(\Delta = 4U\zeta^2/K = 4 \times 0.6 \times 0.49 / 2.0 \approx 0.59\) m。 与实测最优的 \(0.5\) m 很接近。
    2. 随速度放大。 因为 \(\zeta\) 只含 \(K、U、\Delta\)， 若想让响应快慢不随航速变，就让 \(\Delta \propto U\)。
    3. 兜底经验值：\(\Delta \approx 2 \sim 3\) 倍特征长度（如船长）。

    一句话：\(\Delta\) 不是「越紧越好」也不是「越松越好」， 它是「信道噪声」与「路径曲率」之间的一次配平 —— 最优点在「抖动还能忍、切角还没起」的交界处。

    例题 4：为什么「仿生」抄的是无量纲数，不是外形¶

    问：4.3 节里，蚊翅 \(600\) Hz 对机器鱼 \(1\) Hz，尺度差了三个数量级， 减缩频率 \(k\) 却都在 \(0.1 \sim 2\)。请说明这对设计机器人意味着什么， 以及为什么「照抄外形」必然失败。

    解答

    先理解 \(k\) 的含义。 \(k = \pi f c / U\) 是「非定常程度」的度量：

    • \(k\) 小（\(\lesssim 0.05\)）：流体在一个摆动周期内就稳定下来了， 可以按准定常处理，推力来自稳态升力/阻力；
    • \(k\) 大（\(\gtrsim 0.1\)）：前一个涡还没散，下一个周期就来了， 涡一个接一个排成涡街，推力里非定常涡的成分占主导。

    五种对象 \(k\) 都落在 \(0.1 \sim 2\)，说明它们都在非定常区工作 —— 这就是它们「同为扑动推进」的数学标志， 尺度、频率、速度都可以不同，唯有这个比例相同。

    对设计机器人的意义。

    • 它给出了「抄什么」。 要复现蚊翅的推进机理， 不是把机器做成蚊子那么大，而是把自己的 \(k\) 调到蚊翅的 \(k\) 附近。
    • 它是「缩比」的依据。 想在实验水池里用大尺度的模型复现小生物的流场， 就要让 \(k\)（以及 \(Re\)）保持不变 —— 这就是风洞、水池里「缩比模型」的整套理论。
    • 它划出了「理论禁区」。 若你的机器人 \(k \approx 10\)， 却用定常翼型理论去算推力，结果会差得离谱 —— 因为此时推力根本来自非定常涡，定常理论里没有这项。

    为什么「照抄外形」必然失败。 因为外形只在特定的 \(k\)、\(Re\) 下 才能产生那个机构的流场。你放大了尺寸、却让频率和速度没跟上， \(k\) 就变了，外形还在、机理却没了 —— 就像把一片羽毛放大成一块门板，它绝不可能带着你飞。

    一句话：仿生要抄的是「无量纲数」这条不变式， 不是「形状」这个可变的外壳。

    自测¶

    Q1 请说明 BCF 与 MPF 两种推进方式在结构、能力、适用任务上的差别。 为什么本页的水下平台更倾向 BCF？

    提示

    想一想 1.2 节那张表：哪一种身体跟着动、哪一种只有鳍动？ 「身体跟着动」对机动性和精细作业分别意味着什么？

    解答

    核心差别是「推进面在不在身体上」。

    BCF MPF
    推进面 整个身体 + 尾鳍 只有鳍（胸鳍、背鳍等）
    身体 跟着一起摆 基本不动
    速度 / 效率 高 低
    机动性 转弯半径大、难悬停 极好，能原地转
    适用任务 长距离巡游、快速加速 礁石穿行、水下精细作业

    为什么倾向 BCF。 因为水下无人平台（UUV）的主要任务是 大范围巡游与测绘 —— 它更在乎航程与效率， 而不是在礁石缝里做悬停作业。BCF 的身体波动推力大、效率高， 正对这个需求；代价（转弯半径大）在开阔水域并不致命。

    一句话：BCF 用「整条身体」换效率，MPF 用「只动鳍」换机动 —— 选哪种，取决于任务是「走远路」还是「做细活」。

    Q2 请用 Lighthill 细长体理论的推力公式说明： 为什么体波速度 \(V_w\) 必须大于航速 \(U\)？ 如果 \(V_w = U\)，推力是多少？为什么鱼又不把 \(V_w\) 开到无穷大？

    提示

    推力公式里有一个 \([1 - (U/V_w)^2]\) 的因子， 效率公式里 \(V_w\) 又出现在分母 —— 两个方向正好相反。

    解答

    先写两个式子。 单位长度平均推力

    \[ T = \frac{m_a A^2}{4}\,\omega^2\left[1 - \left(\frac{U}{V_w}\right)^2\right], \qquad \eta = \frac{1}{2}\left(1 + \frac{U}{V_w}\right) \]

    为什么 \(V_w > U\)。 方括号里的因子 \([1 - (U/V_w)^2]\) 必须为正， 推力才为正。\(V_w > U\) 时 \(U/V_w < 1\)，因子为正； \(V_w = U\) 时因子恰好为 \(0\)，推力为零。

    物理上：\(V_w\) 是身体把水往后甩的速度。 只有当甩出去的水比鱼自己跑得还快，才会产生向后的净动量流； 若两者相等，甩出去的水「跟着鱼一起跑」，相对鱼没有动量差 → 没有反作用力。

    为什么不开到无穷大。 看效率式：\(\eta = \frac{1}{2}(1 + U/V_w)\) —— \(V_w\) 在分母，\(V_w \to \infty\) 时 \(\eta \to 1/2\)（即 \(50\%\)）， 而 \(V_w/U = 1.2\) 时 \(\eta = 91.7\%\)。 也就是说，把推力做大（\(V_w\) 拉高）必然牺牲效率 —— 水被甩得太快，大部分动能留在尾流里带走了。

    一句话：\(V_w > U\) 是「能不能推得动」的下限， \(V_w\) 太大是「效率利不利」的上限 —— 鱼被夹在这两条之间，于是停在 \(V_w/U \approx 1.2 \sim 1.5\)。

    Q3 与「开环回放预先算好的关节角序列」相比，CPG 相位耦合好在哪三点？ 为什么 2.2 节强调它是「收敛到」而不是「被指定」？

    提示

    「收敛」意味着：被打断之后会自己爬回来。 这和「查表回放」遇到扰动的表现有什么不同？

    解答

    三点好处：

    1. 调参即调波形。 改相位差 \(\varphi\) 就改波形（波长、弯曲频率）， 改 \(\omega\) 就改频率，改幅值就改摆幅 —— 不用重新设计控制器，而开环回放要重算整张表。
    2. 受扰自恢复（最本质的一条）。 因为波形是靠耦合收敛出来的稳态， 中途被打断（撞到障碍、负载突变）后， 耦合项会再把相位重新拉回行波；而开环回放只会照着走偏的表继续走， 直到下一次重新计算为止。
    3. 同频自洽、参数稀疏。 所有关节共用 \(\omega\)， 耦合只负责对齐相位 —— 对应「体波是单一频率的行波」这个物理事实， 参数少、意义清楚。

    为什么强调「收敛」？ 因为 2.2 节的表里， 相邻相位差是从乱值逐渐靠拢到 \(-60°\) 的（\(t = 0.10\) s 还乱， \(t = 2.00\) s 才整齐）。这个「逐渐」说明—— \(-\varphi\) 这个相位差是系统的「平衡点（吸引子）」，不是我们喂进去的初值。 既然是吸引子，任何偏离最终都会回来， 这才是 CPG 在真实、有扰动的环境里能用的根本原因。

    一句话：开环回放是「背下来的动作」， CPG 是「长出来的节律」—— 前者怕扰动，后者把扰动当成小事。

    Q4 某机器鱼摆尾频率 \(f = 2.0\) Hz、尾端峰峰摆幅 \(A_{pp} = 0.12\) m。 (1) 航速 \(U = 1.0\) m/s 时，\(St\) 是多少？是否落在高效带（\(0.25 \sim 0.35\)）？ (2) 要让 \(St\) 回到高效带，航速应调到什么范围？

    提示

    \(St = fA_{pp}/U\)。第 (2) 问是「给定 \(St\) 区间反解 \(U\) 区间」， 注意 \(St\) 越大意味着 \(U\) 越小。

    解答

    已知： \(f = 2.0\) Hz，\(A_{pp} = 0.12\) m，于是 \(fA_{pp} = 2.0 \times 0.12 = 0.24\) m/s。

    (1) 算 \(St\)。

    \[ St = \frac{fA_{pp}}{U} = \frac{0.24}{1.0} = 0.24 \]

    \(0.24 < 0.25\)，略低于高效带 —— 说明这条鱼当前的航速 相对它的摆速「偏快」了（对应 2.4 节「太快 → \(St\) 偏小 → 接近准定常」）。

    (2) 反解航速区间。 要求 \(0.25 \le St \le 0.35\)， 即

    \[ 0.25 \le \frac{0.24}{U} \le 0.35 \;\Longrightarrow\; \frac{0.24}{0.35} \le U \le \frac{0.24}{0.25} \;\Longrightarrow\; 0.686 \le U \le 0.96\ \text{m/s} \]

    所以把航速降到约 \(0.69 \sim 0.96\) m/s 之间，\(St\) 就回到高效带。 注意方向：为了让 \(St\) 变大，航速要减小 —— 因为 \(f\)、\(A_{pp}\) 固定时 \(St\) 与 \(U\) 成反比。

    一句话：要「更高效」，本例里反而要「游慢一点」—— 这正说明 \(St\) 是一条「比例律」，而不是「越快越好」。

    小结¶

    要记住的 为什么重要
    仿生推进的推力来自非定常涡量，不是稳态动量 决定了效率只在特定比例下最高，控制目标与螺旋桨完全不同
    BCF 用身体 + 尾鳍（高效），MPF 只用鳍（机动） 选哪种取决于任务是「走远路」还是「做细活」
    身体中线是行波 \(y = A(x)\sin(kx - \omega t)\) 要行波不要驻波：驻波的平均动量流为零，没有净推力
    体波速度 \(V_w = f\lambda\)，必须 \(>\) 航速 \(U\) \(V_w = U\) 时推力恰好为零；本例 \(V_w/U \approx 1.2 \sim 1.5\)
    摆幅包络 \(A(x)\) 头小尾大（二次多项式） 尾部约为头部 \(5\) 倍（本例）—— 前段稳姿态、后段做功
    逆运动学：期望体形 → 连杆中点切线角 → 关节角 尾端关节角滞后于中段，正是行波在关节上的样子
    连杆不是越多越好，工程上 \(3 \sim 6\) 段 多了变重、参数变多，而且太短的尾段只乱摆不出涡
    CPG：\(\dot{\theta}_i = \omega + K\sin(\theta_{i-1} - \theta_i - \varphi)\) 波形自发涌现，受扰能自恢复，改 \(\varphi\) 就改波形
    CPG 稳态相位差 \(= -\varphi\)（负号 = 尾端滞后 = 行波） 是吸引子（收敛），不是初值（指定）—— 乱初相位也能收敛到 \(-60°\)
    Strouhal 数 \(St = fA_{pp}/U\)，高效带 \(0.25 \sim 0.35\) 一条鱼只在一个速度窗口里高效（本例约 \(0.43 \sim 0.60\) m/s）
    细长体推力 \(T = \dfrac{m_a A^2}{4}\omega^2\left[1 - (U/V_w)^2\right]\) \(V_w \le U\) 时推力为零；附加质量 \(m_a = \frac{\pi}{4}\rho D^2\)
    Froude 效率 \(\eta = \frac{1}{2}(1 + U/V_w)\) 推力与效率对立：\(V_w/U\) 从 \(1.2\) 到 \(3.0\)，\(\eta\) 从 \(91.7\%\) 掉到 \(66.7\%\)
    LOS 制导：\(\psi_d = \psi_p - \arctan(e/\Delta)\) 把一个横向误差 \(e\) 转成一个修正航向，力度由 \(\Delta\) 定
    前视距离 \(\Delta\) 是两难：太小放噪声、太大切角 本例误差呈 U 形，\(\Delta \approx 0.5\) m 最优
    抖动指标是角加速度，不只是误差 \(\Delta = 0.2\) 时误差看着还行，角加速度却高达 \(3264\) 度/s²，舵机跟不上
    线性化得 \(s^2 + Ks + KU/\Delta = 0\)，劳斯–赫尔维茨必稳 \(\zeta = \sqrt{K\Delta/(4U)}\) 随 \(\Delta\) 单调增 → 解释了整个 U 形
    扑翼、足式、蛇形与机器鱼共享同一套设计法 都抄运动规律 + 无量纲数，不抄外形
    减缩频率 \(k = \pi f c / U\)，非定常要求 \(k \gtrsim 0.1\) 尺度差三个数量级，\(k\) 却都在 \(0.1 \sim 2\)（本例）—— 这是「缩比」的依据

    四条最容易出错的地方：

    1. 把「做成鱼的形状」当成仿生。 外形不产生推力 —— 波形与无量纲比例才产生推力。一条焊死的「鱼形」机器人，和一块砖头没区别。
    2. 以为体波速度可以随便取。 \(V_w \le U\) 时推力恰好为零； 而 \(V_w/U\) 太大又让效率掉得快 —— 它被锁在 \(1.2 \sim 1.5\) 这个窄带里。
    3. 以为前视距离 \(\Delta\) 越小跟得越紧越好。 \(\Delta\) 太小会 放大测量噪声、把舵机抖坏（本例 \(3264\) 度/s²）； 这和 \(St\) 太小时反而低效是同一类「过犹不及」。
    4. 以为尺度不同就不能借鉴。 蚊翅与机器鱼尺度差三个数量级， \(k\) 却在同一区间 —— 可借鉴的从来是无量纲数， 不是尺寸、也不是外形。
