    机器人动力学¶

    前面几页把「在哪」（正解）、「多快」（雅可比）、「怎么走」（规划）都定下来了。 但这些都只是几何上的安排 —— 机器人本身不会动，它最终是被电机力矩推着动的。 要让关节按计划的速度和加速度走，必须先知道「每个关节要出多大力」。 这一页就回答三件事：力矩怎么算（建模）、算什么（两类问题）、算出来干什么（控制）。

    一、为什么运动学不够，还需要动力学¶

    1.1 三个层次：位置 → 速度 → 力¶

    机器人学的主线，其实是一层层把「运动」翻译成「力」：

    层次 关心的量 回答的问题 本课程的哪一页
    位置级 关节角 \(\boldsymbol{q}\) 末端在哪、怎么到 正向 / 逆向运动学
    速度级 关节速度 \(\dot{\boldsymbol{q}}\) 关节转多快、末端动多快 微分运动学（雅可比）
    力级 关节力矩 \(\boldsymbol{\tau}\) 每个关节要出多大力 本页（动力学）

    前两层的答案与质量、惯量无关 —— 无论机械臂是塑料还是钢做的， 只要关节角序列一样，末端就走一样的路。

    但「走得动吗、要多大力」完全取决于质量与惯量： 同样一条轨迹，空载能跑，装了十公斤的抓手可能就带不动了。 动力学就是把质量、惯量、重力、速度耦合全部算进来。

    1.2 两类问题：逆动力学 与 正动力学¶

    动力学方程一旦建立，就有两个方向的使用方式：

    · 逆动力学（inverse dynamics）：已知 \(\boldsymbol{q},\,\dot{\boldsymbol{q}},\,\ddot{\boldsymbol{q}}\)，求 \(\boldsymbol{\tau}\)。 —— 「要这样动，得给多大力」，用于控制与选电机。 · 正动力学（forward dynamics）：已知 \(\boldsymbol{q},\,\dot{\boldsymbol{q}},\,\boldsymbol{\tau}\)，求 \(\ddot{\boldsymbol{q}}\)。 —— 「给了这个力，会怎么动」，用于仿真。

    记住这条主线

    这一页的四节，是同一件事的四个层次： 先搞清动力学能干什么（一）→ 单个刚体怎么描述（二）→ 串起来的多关节方程（三）→ 拿去做控制（四）。 贯穿始终的只有一个式子：\(\boldsymbol{M}(\boldsymbol{q})\ddot{\boldsymbol{q}} + \boldsymbol{C}(\boldsymbol{q},\dot{\boldsymbol{q}})\dot{\boldsymbol{q}} + \boldsymbol{g}(\boldsymbol{q}) = \boldsymbol{\tau}\)。

    1.3 两条技术路线：拉格朗日 与 牛顿-欧拉¶

    建立多关节动力学有两条经典路线：

    · 拉格朗日法：从能量出发（动能减势能），写一个标量函数 \(L\)， 再对每个关节求导 —— 推导清楚、形式统一，适合手推和理解方程结构。 · 牛顿-欧拉法：从力和力矩的平衡出发，沿连杆从基座到末端「前推速度、后推力」—— 计算效率高，适合程序实现。

    两者数学上等价，结果一模一样。本页用拉格朗日法讲清方程的样子， 因为它直接给出那条「\(\boldsymbol{M}\ddot{\boldsymbol{q}}+\boldsymbol{C}\dot{\boldsymbol{q}}+\boldsymbol{g}=\boldsymbol{\tau}\)」的标准形式。

    二、刚体动力学基础¶

    2.1 描述一个刚体需要三个量¶

    在力学里，「一个刚体」不是靠形状描述的，而是靠三个量：

    · 质量 \(m\)：决定平动的惯性； · 质心位置 \(\boldsymbol{c}\)：重力可以看作作用在这一点； · 转动惯量张量 \(\boldsymbol{I}\)：决定转动时的惯性（下一小节细说）。

    注意第三项和前两项完全不同：质量是一个标量， 但转动惯量是一个 \(3\times 3\) 的矩阵 —— 因为「绕哪个轴转」的难易程度不一样。

    2.2 牛顿-欧拉方程：平动 + 转动¶

    刚体的运动拆成两部分，各写一条方程：

    \[ m\,\dot{\boldsymbol{v}} = \boldsymbol{F}, \qquad \boldsymbol{I}\,\dot{\boldsymbol{\omega}} + \boldsymbol{\omega}\times(\boldsymbol{I}\boldsymbol{\omega}) = \boldsymbol{N} \]

    · 左式是平动：质量 × 质心加速度 = 合外力（就是中学的牛顿第二定律）； · 右式是转动：\(\boldsymbol{I}\dot{\boldsymbol{\omega}}\) 是角加速度项， 多出来的 \(\boldsymbol{\omega}\times(\boldsymbol{I}\boldsymbol{\omega})\) 叫陀螺项 —— 它是「转动的物体，角速度方向一变，就产生额外力矩」的来源。

    陀螺项是非线性的（角速度的二次项），这正是机器人动力学「非线性」的第一个来源。

    2.3 转动惯量为什么是矩阵¶

    绕不同轴转，难易程度不同：同样一根细杆， 绕杆的轴转很轻松（质量都贴着轴），绕垂直杆的轴转就费劲（质量都离轴很远）。

    所以惯量必须写成张量：

    \[ \boldsymbol{I} = \begin{bmatrix} I_{xx} & I_{xy} & I_{xz}\\ I_{xy} & I_{yy} & I_{yz}\\ I_{xz} & I_{yz} & I_{zz} \end{bmatrix} \]

    它是对称的（\(I_{xy}=I_{yx}\)），对角元是绕三个坐标轴的惯量， 非对角元叫惯性积，描述「绕一个轴转时，会不会被甩去绕另一个轴转」。

    工程上常用：均质细杆绕中点是 \(I=ml^2/12\)，绕端点是 \(I=ml^2/3\)； 实心圆盘绕中心轴是 \(I=mR^2/2\)。这些常数在手册里都能查到，本页代码里也会用到。

    2.4 实跑：单摆的能量守恒¶

    动力学方程写出来对不对，有一个最硬的检验： 没有外力（\(\tau=0\)）时，机械能必须守恒。

    单摆是最小的刚体动力学系统：质量 \(m\)、摆长 \(l\)、只在重力下摆动， 取转角 \(\theta\) 为关节变量，方程是

    \[ ml^2\ddot{\theta} = -mgl\sin\theta \quad\Longrightarrow\quad \ddot{\theta} = -\frac{g}{l}\sin\theta \]

    用四阶龙格-库塔把它积出来，同时算每一步的机械能 \(E=\frac{1}{2}ml^2\dot{\theta}^2 + mgl(1-\cos\theta)\)：

    import numpy as np

# 单摆：质量 m、摆长 l，只在重力下摆动（关节力矩 τ = 0）
# 方程：m l² θ'' = -m g l sinθ  →  θ'' = -(g/l) sinθ
m, l, g = 1.0, 1.0, 9.81


def deriv(s):
    th, om = s
    return np.array([om, -(g / l) * np.sin(th)])


def energy(s):
    th, om = s
    return 0.5 * m * l**2 * om**2 + m * g * l * (1 - np.cos(th))


def rk4(s0, T, dt):
    """四阶龙格-库塔积分：给定初始状态，向前推 T 秒。"""
    s = np.array(s0, float)
    for _ in range(int(T / dt)):
        k1 = deriv(s)
        k2 = deriv(s + 0.5 * dt * k1)
        k3 = deriv(s + 0.5 * dt * k2)
        k4 = deriv(s + dt * k3)
        s = s + dt / 6 * (k1 + 2 * k2 + 2 * k3 + k4)
    return s


s0 = [np.pi / 3, 0.0]              # 从 60° 静止释放
T, dt = 5.0, 1e-4
send = rk4(s0, T, dt)
E0 = energy(s0)
E1 = energy(send)

print("单摆：m=%.1f kg, l=%.1f m, g=%.2f" % (m, l, g))
print("初始状态  θ0=%.3f°, ω0=%.1f" % (np.degrees(s0[0]), s0[1]))
print("末状态    θ =%.3f°, ω =%.3f rad/s" % (np.degrees(send[0]), send[1]))
print("初始机械能 E0=%.6f J" % E0)
print("末机械能   E1=%.6f J" % E1)
print("能量相对漂移 = %.3e" % (abs(E1 - E0) / E0))

    这条「能量守恒」思路，是检验任何动力学模型的第一把尺子。

    三、串联机器人的动力学¶

    3.1 拉格朗日方程¶

    对 \(n\) 个关节的机器人，先写出拉格朗日函数（动能减势能）：

    \[ L(\boldsymbol{q},\dot{\boldsymbol{q}}) = T(\boldsymbol{q},\dot{\boldsymbol{q}}) - V(\boldsymbol{q}) \]

    然后对每个关节代入拉格朗日方程：

    \[ \frac{d}{dt}\frac{\partial L}{\partial \dot{q}_i} - \frac{\partial L}{\partial q_i} = \tau_i, \qquad i = 1,\dots,n \]

    动能 \(T\) 是关键：它同时含关节自身的转动动能、连杆平动动能， 以及「一个关节动会带动另一个关节」的耦合项 —— 这些耦合项最后都跑进了惯量矩阵 \(\boldsymbol{M}(\boldsymbol{q})\) 里。

    3.2 标准形式¶

    把 \(n\) 个方程整理成矩阵形式，就得到机器人动力学的标准形式：

    \[ \boldsymbol{M}(\boldsymbol{q})\,\ddot{\boldsymbol{q}} + \boldsymbol{C}(\boldsymbol{q},\dot{\boldsymbol{q}})\,\dot{\boldsymbol{q}} + \boldsymbol{g}(\boldsymbol{q}) = \boldsymbol{\tau} \]

    这一条式子是整页的核心，三项各有名字：

    项 名字 物理含义
    \(\boldsymbol{M}(\boldsymbol{q})\ddot{\boldsymbol{q}}\) 惯量项 要产生角加速度，需要克服的惯性（随位形变化）
    \(\boldsymbol{C}(\boldsymbol{q},\dot{\boldsymbol{q}})\dot{\boldsymbol{q}}\) 科氏/离心项 关节速度带来的耦合力（速度为零时为零）
    \(\boldsymbol{g}(\boldsymbol{q})\) 重力项 撑住自重与负载所需的力矩（随位形变化）
    \(\boldsymbol{\tau}\) 关节力矩 电机要出的力（左边是「需要」，右边是「供给」）

    3.3 每一项什么时候为零¶

    记住这几种特殊情况，很多结论就不用推：

    · 静止（\(\dot{\boldsymbol{q}}=\boldsymbol{0}\)）：科氏项为零，只剩 \(\boldsymbol{M}\ddot{\boldsymbol{q}}+\boldsymbol{g}=\boldsymbol{\tau}\)； · 静止且不加速（\(\dot{\boldsymbol{q}}=\ddot{\boldsymbol{q}}=\boldsymbol{0}\)）：\(\boldsymbol{\tau}=\boldsymbol{g}(\boldsymbol{q})\) —— 这时候力矩全部用来「撑住」重力，是可以直接测出来的； · 水平面内的平面机器人：如果重力方向垂直于运动平面，\(\boldsymbol{g}\equiv\boldsymbol{0}\)。

    c2 = np.cos(q[1])
    M11 = m1 * lc1**2 + I1 + m2 * (l1**2 + lc2**2 + 2 * l1 * lc2 * c2) + I2

    3.5 三条结构性性质（可以直接用）¶

    机器人动力学方程不是「任意一个矩阵」，它有普适的结构性质， 很多控制器就是靠这些性质设计的：

    · \(\boldsymbol{M}(\boldsymbol{q})\) 对称正定：物理含义是「动能永远为正」，与位形无关； · \(\dot{\boldsymbol{M}} - 2\boldsymbol{C}\) 反对称：这条性质保证「科氏力不做功」—— 是自适应控制、无源控制的数学基础； · 重力项只与位形有关（\(\boldsymbol{g}(\boldsymbol{q})\)），与速度、加速度无关。

    四、动力学拿来干什么¶

    4.1 计算力矩控制：把模型当作「前馈」¶

    最直接的用途是控制。如果模型已知，就用计算力矩法：

    \[ \boldsymbol{\tau} = \boldsymbol{M}(\boldsymbol{q})\Big[\ddot{\boldsymbol{q}}_d + \boldsymbol{K}_d(\dot{\boldsymbol{q}}_d-\dot{\boldsymbol{q}}) + \boldsymbol{K}_p(\boldsymbol{q}_d-\boldsymbol{q})\Big] + \boldsymbol{C}(\boldsymbol{q},\dot{\boldsymbol{q}})\dot{\boldsymbol{q}} + \boldsymbol{g}(\boldsymbol{q}) \]

    它的思路是「先补偿、再修正」： 先用模型算出「维持轨迹所需的力矩」（前馈）， 再把跟踪误差用 PD（\(\boldsymbol{K}_p\)、\(\boldsymbol{K}_d\)）拉回来。

    代入动力学方程后，非线性项被精确抵消，误差方程变成线性的：

    \[ \ddot{\boldsymbol{e}} + \boldsymbol{K}_d\dot{\boldsymbol{e}} + \boldsymbol{K}_p\boldsymbol{e} = \boldsymbol{0} \]

    于是「误差是否收敛」变成一个二阶线性系统的极点配置问题 —— 这正是下一章位置控制的地基。

    import numpy as np

# 同一台两连杆，跟踪同一条期望轨迹，比较两种控制律
m1 = m2 = 1.0
l1 = l2 = 1.0
lc1 = lc2 = 0.5
I1 = I2 = m1 * l1**2 / 12
g = 9.81

Kp = np.diag([100.0, 100.0])
Kd = np.diag([20.0, 20.0])


def Mmat(q):
    c2 = np.cos(q[1])
    return np.array([
        [m1 * lc1**2 + I1 + m2 * (l1**2 + lc2**2 + 2 * l1 * lc2 * c2) + I2,
         m2 * (lc2**2 + l1 * lc2 * c2) + I2],
        [m2 * (lc2**2 + l1 * lc2 * c2) + I2, m2 * lc2**2 + I2]])


def bias(q, dq):
    """非线性偏置：科氏/离心项 + 重力项。"""
    h = m2 * l1 * lc2 * np.sin(q[1])
    C = np.array([[-h * dq[1], -h * (dq[0] + dq[1])], [h * dq[0], 0.0]])
    G = np.array([(m1 * lc1 + m2 * l1) * g * np.cos(q[0])
                  + m2 * lc2 * g * np.cos(q[0] + q[1]),
                  m2 * lc2 * g * np.cos(q[0] + q[1])])
    return C @ dq + G


def qd(t):
    return np.array([0.6 * np.sin(t), 0.4 * np.cos(t)])


def dqd(t):
    return np.array([0.6 * np.cos(t), -0.4 * np.sin(t)])


def ddqd(t):
    return np.array([-0.6 * np.sin(t), -0.4 * np.cos(t)])


def control(q, dq, t, use_model):
    e, de = qd(t) - q, dqd(t) - dq
    if use_model:
        # 计算力矩：用模型把期望加速度「补偿」进去
        a = ddqd(t) + Kd @ de + Kp @ e
        return Mmat(q) @ a + bias(q, dq)
    # 纯 PD：完全不看模型
    return Kd @ de + Kp @ e


def sim(use_model, T=5.0, dt=1e-3):
    q, dq = qd(0.0).copy(), np.zeros(2)
    for k in range(int(T / dt)):
        t = k * dt
        tau = control(q, dq, t, use_model)
        acc = np.linalg.solve(Mmat(q), tau - bias(q, dq))
        q = q + dt * dq
        dq = dq + dt * acc
    return qd(T) - q, dqd(T) - dq

for label, um in (("纯 PD（不含模型）", False), ("计算力矩（含模型）", True)):
    e, de = sim(um)
    print("%s：末位置误差 = [%8.5f, %8.5f] rad，‖e‖ = %.3e" %
          (label, e[0], e[1], np.linalg.norm(e)))

    读这两行：纯 PD 的末位置误差是 0.163 rad（约 9.3°）， 计算力矩只有 \(5.9\times10^{-5}\) rad —— 差了两千多倍。

    原因不在「PD 不好」，而在「重力一直在拽」： 纯 PD 只有在「有误差」时才出力，于是它必须留一个偏差， 让 PD 项刚好抵消重力 —— 这就是稳态误差。 计算力矩里的 \(\boldsymbol{g}(\boldsymbol{q})\) 项直接把重力补掉， PD 就只需要负责「修小误差」，于是误差能收敛到接近零。

    一句话：控制精度不够时，先问「模型补偿上了没有」，再怪控制器。

    4.3 另外两个用途：选电机 与 仿真¶

    · 选电机：拿一条最苛刻的轨迹跑逆动力学， 得到每个关节的峰值力矩，再乘安全系数去选伺服 —— 这是选型的标准做法； · 仿真：把 \(\boldsymbol{\tau}\) 代进正动力学（\(\ddot{\boldsymbol{q}}=\boldsymbol{M}^{-1}(\boldsymbol{\tau}-\boldsymbol{C}\dot{\boldsymbol{q}}-\boldsymbol{g})\)）， 积分出真实运动 —— 控制算法先在仿真里调好，再上真机。

    例题 1：用拉格朗日法推单连杆的动力学方程¶

    一根均质细杆长 \(l=0.5\) m、质量 \(m=2\) kg，绕一端的水平轴转动（关节在端点）。 求它的动力学方程，并算出「静止、水平（\(\theta=0\)）」时所需的关节力矩。 （绕端点的杆惯量 \(I=ml^2/3\)，质心在 \(l/2\) 处。）

    解答

    第一步：写动能与势能。

    绕端点的转动动能：\(T = \frac{1}{2}I\dot{\theta}^2 = \frac{1}{2}\cdot\frac{ml^2}{3}\dot{\theta}^2\)。

    势能取水平位置为零，质心高度是 \((l/2)\sin\theta\)： \(V = mg\frac{l}{2}\sin\theta\)。

    第二步：拉格朗日函数与求导。

    \[ L = T - V = \frac{ml^2}{6}\dot{\theta}^2 - \frac{mgl}{2}\sin\theta \]
    \[ \frac{\partial L}{\partial\dot{\theta}} = \frac{ml^2}{3}\dot{\theta} \;\Rightarrow\; \frac{d}{dt}\frac{\partial L}{\partial\dot{\theta}} = \frac{ml^2}{3}\ddot{\theta}, \qquad \frac{\partial L}{\partial\theta} = -\frac{mgl}{2}\cos\theta \]

    代入拉格朗日方程，得动力学方程：

    \[ \frac{ml^2}{3}\ddot{\theta} + \frac{mgl}{2}\cos\theta = \tau \]

    第三步：代数值。 静止不动（\(\ddot{\theta}=0\)）、水平（\(\theta=0\)，\(\cos\theta=1\)）：

    \[ \tau = \frac{mgl}{2} = \frac{2\times9.81\times0.5}{2} = 4.905\ \text{N·m} \]

    一句话：水平位置是重力臂最长的位置，所以力矩最大； 转到竖直位置（\(\theta=\pm90°\)）时重力项为零 —— 这就是「重心过了顶点会自己倒」。

    例题 2：为什么惯量矩阵一定对称正定¶

    对任何 \(n\) 关节机器人，为什么 \(\boldsymbol{M}(\boldsymbol{q})\) 一定对称、一定正定？

    解答

    对称性来自动能的表达式。

    动能可以写成二次型：\(T = \frac{1}{2}\dot{\boldsymbol{q}}^{\mathsf T}\boldsymbol{M}(\boldsymbol{q})\dot{\boldsymbol{q}}\)。 而二次型 \(T\) 是一个标量，转置不变：\(T = T^{\mathsf T}\)，于是必须有 \(\boldsymbol{M} = \boldsymbol{M}^{\mathsf T}\) —— 不对称就矛盾。

    正定性来自物理：动能不可能为负。

    对任意非零关节速度 \(\dot{\boldsymbol{q}}\neq\boldsymbol{0}\)， 必有 \(T = \frac{1}{2}\dot{\boldsymbol{q}}^{\mathsf T}\boldsymbol{M}\dot{\boldsymbol{q}} > 0\) （机器人只要动，就一定有动能）。这恰好就是正定的定义。

    本页实跑也验证了：特征值 \(0.163\) 与 \(2.337\) 都大于零。

    一句话：\(\boldsymbol{M}\) 的对称正定不是「碰巧」，而是动能是正标量的必然结果 —— 所以 \(\boldsymbol{M}\) 一定可逆，正动力学 \(\ddot{\boldsymbol{q}}=\boldsymbol{M}^{-1}(\cdots)\) 才总能解。

    例题 3：纯 PD 为什么有稳态误差¶

    本页实跑里，纯 PD 跟踪同一条轨迹，末位置误差是 \(0.163\) rad， 而计算力矩只有 \(5.9\times10^{-5}\) rad。为什么纯 PD 会「差这么多」？

    解答

    因为纯 PD 的力矩完全来自「误差」，而重力是个「不请自来的常数项」。

    纯 PD 律是 \(\boldsymbol{\tau} = \boldsymbol{K}_d\dot{\boldsymbol{e}} + \boldsymbol{K}_p\boldsymbol{e}\)， 它只在有误差时出力。但系统里一直有个重力项在拽 —— 要让关节停在该位置，就必须持续出一点力矩抵消重力。

    稳态时 \(\dot{\boldsymbol{e}}=\boldsymbol{0}\)，于是只能靠 \(\boldsymbol{K}_p\boldsymbol{e} = \boldsymbol{g}(\boldsymbol{q})\) 提供这部分的力矩 —— 这就要求 \(\boldsymbol{e}\) 必须非零。\(\boldsymbol{K}_p\) 越大，误差越小，但永远不为零。

    计算力矩把 \(\boldsymbol{g}(\boldsymbol{q})\) 直接写进控制律， 重力被显式补掉，PD 就只需要修「剩下的小误差」，所以误差能压到 \(10^{-5}\) 量级。

    一句话：纯 PD 的稳态误差是「用偏差换力矩」的必然代价； 加了模型前馈，才有机会把误差压到零。

    例题 4：逆动力学 和 正动力学，分别在什么时候用¶

    同样是动力学方程，为什么要有「求力矩」和「求加速度」两个方向？各用在哪？

    解答

    逆动力学（求 \(\boldsymbol{\tau}\)）用在「知道要怎么动，问需要多大力」的场合。

    · 控制：计算力矩控制就是一步逆动力学 —— 把期望加速度代进去，直接得到该给的力矩； · 选电机：沿最苛刻的轨迹跑逆动力学，取峰值力矩做选型依据； · 负载估算：抓手拿了多重的东西，可以从「实际力矩减空载力矩」反推出来。

    正动力学（求 \(\ddot{\boldsymbol{q}}\)）用在「知道给了多大力，问会怎么动」的场合。

    · 仿真：给定力矩序列，一步步积分出真实轨迹 —— 算法先在这里调好； · 物理引擎：游戏、数字孪生里的机械臂，跑的都是正动力学。

    一句话：逆动力学回答「要多大劲」（控制/选型）， 正动力学回答「会怎么动」（仿真） —— 两者是同一个方程的两种用法。

    自测¶

    Q1 逆动力学和正动力学，各自的已知量和未知量是什么？分别用在什么场合？

    提示

    想：哪一个的答案是「力矩」，哪一个是「加速度」？

    解答

    逆动力学：已知 \(\boldsymbol{q},\dot{\boldsymbol{q}},\ddot{\boldsymbol{q}}\)，求 \(\boldsymbol{\tau}\)。 用在控制（算出该给多大力）和选电机（算峰值力矩）。

    正动力学：已知 \(\boldsymbol{q},\dot{\boldsymbol{q}},\boldsymbol{\tau}\)，求 \(\ddot{\boldsymbol{q}}\)。 用在仿真（给定力矩看怎么动）。

    一句话：要多大劲 → 逆动力学；会怎么动 → 正动力学。

    Q2 标准形式 \(\boldsymbol{M}\ddot{\boldsymbol{q}}+\boldsymbol{C}\dot{\boldsymbol{q}}+\boldsymbol{g}=\boldsymbol{\tau}\) 里，哪一项在机器人静止时为零？哪一项在没有重力时为零？

    提示

    想：科氏项里有没有速度？重力项里有没有质量？

    解答

    静止（\(\dot{\boldsymbol{q}}=\boldsymbol{0}\)）时 \(\boldsymbol{C}\dot{\boldsymbol{q}}=\boldsymbol{0}\)： 科氏/离心项是速度的二次项，速度为零它必为零。

    没有重力（重力方向垂直于运动平面）时 \(\boldsymbol{g}=\boldsymbol{0}\)： 重力项正比于重力加速度 \(g\)，水平面内的平面机械臂就属于这种情况。

    注意：静止时 \(\boldsymbol{M}\ddot{\boldsymbol{q}}+\boldsymbol{g}=\boldsymbol{\tau}\) 仍然可能不为零 —— 「静止」不等于「不需要力矩」，撑住自重也是要出力的。

    一句话：科氏项看速度，重力项看重力方向；静止不代表不用出力。

    Q3 本页用「单摆能量守恒」来检验动力学模型。为什么不用「位置算得准不准」来检验？

    提示

    想：位置误差会因为数值积分方法不同而变化吗？机械能守恒是「精确解」才有的性质吗？

    解答

    因为位置没有「标准答案」可比，而能量守恒是「精确解」的铁律。

    单摆方程是非线性的，没有初等函数形式的解析解 —— 所以「算出来的位置对不对」无从直接判断（换个步长还是不一样）。

    但能量守恒是方程的精确性质：\(\tau=0\) 时系统无外力做功，机械能必须严格守恒。 于是只要积分器够好，能量就应该保持常数 —— 本页实跑中，5 秒后漂移只有 \(9\times10^{-15}\)，说明方程和积分都对。

    一句话：没有标准答案时，就找「解必须满足的不变量」来当尺子。

    Q4 为什么「关节空间里静止不动」的机器人，电机仍然要输出力矩？

    提示

    回到标准形式，看 \(\dot{\boldsymbol{q}}=\ddot{\boldsymbol{q}}=\boldsymbol{0}\) 时方程剩什么。

    解答

    因为方程里剩下的 \(\boldsymbol{\tau}=\boldsymbol{g}(\boldsymbol{q})\) 一般不为零。

    静止且不加速时，\(\boldsymbol{M}\ddot{\boldsymbol{q}}=\boldsymbol{0}\)、\(\boldsymbol{C}\dot{\boldsymbol{q}}=\boldsymbol{0}\)， 动力学方程退化成 \(\boldsymbol{\tau}=\boldsymbol{g}(\boldsymbol{q})\)。

    而 \(\boldsymbol{g}(\boldsymbol{q})\) 是「撑住手臂与负载」所需的力矩 —— 只要手臂伸出、不在竖直下垂位置，重力就会产生力矩， 电机必须顶住它，否则手臂会自己掉下来。

    本页实跑的例子里，这一项高达 \(9.14\) N·m，远大于科氏项。

    一句话：静止 ≠ 不出力；关节要保持位形，就得对抗重力。

    小结¶

    要记住的 为什么重要
    三个层次：位置 → 速度 → 力 动力学是运动学主线上的最后一层
    逆动力学求 \(\boldsymbol{\tau}\)，正动力学求 \(\ddot{\boldsymbol{q}}\) 前者用于控制/选型，后者用于仿真
    拉格朗日法（能量）与牛顿-欧拉法（力）等价 前者好理解，后者算得快
    描述刚体要三样：质量、质心、惯量张量 惯量是矩阵，因为绕不同轴难易不同
    惯量常数：绕中点 \(ml^2/12\)、绕端点 \(ml^2/3\) 手推时直接查用
    检验模型的第一把尺子：能量守恒 实跑漂移仅 \(9\times10^{-15}\)
    标准形式 \(\boldsymbol{M}\ddot{\boldsymbol{q}}+\boldsymbol{C}\dot{\boldsymbol{q}}+\boldsymbol{g}=\boldsymbol{\tau}\) 整页的核心式子
    \(\boldsymbol{M}\) 对称正定（因为动能是正标量） 所以 \(\boldsymbol{M}\) 一定可逆
    \(\boldsymbol{C}\dot{\boldsymbol{q}}\) 在静止时为零 科氏项是速度的二次项
    \(\boldsymbol{\tau}=\boldsymbol{g}(\boldsymbol{q})\) 在静止且不加速时成立 静止也要出力，用来顶住重力
    计算力矩控制：模型前馈 + PD 反馈 把非线性精确抵消，误差方程变线性
    纯 PD 有稳态误差（用偏差换力矩） 实跑：PD \(0.163\) rad vs 计算力矩 \(5.9\times10^{-5}\) rad

    四条最容易出错的地方：

    1. 以为「静止就不用给力矩」 —— 重力项一直存在，撑住自重也要出力
    2. 把 \(\boldsymbol{M}\) 当成常数矩阵 —— 它随位形变化（\(\boldsymbol{M}(\boldsymbol{q})\)），是位形的函数
    3. 用纯 PD 却不给模型补偿，还怪控制器不好 —— 稳态误差是「用偏差换力矩」的必然结果
    4. 忘了科氏项随速度二次增长 —— 低速时可忽略，高速时可能反超重力项
