    机器人的位置控制¶

    上一页把「怎么知道状态」解决了 —— 传感器与融合给出了可信的状态估计。 于是闭环终于可以合上：测出偏差 → 算出该给多大力/多快 → 驱动电机。 这一页讲的，是机器人最基础、也最主流的一类控制：位置控制 —— 让关节（或末端）稳稳地停在 / 跟住指定的位置。 主线是三个层次：单关节怎么闭环（一、二）→ 多关节怎么协调（三）→ 末端怎么保证精度（四）。

    一、位置控制在机器人里处在什么位置¶

    1.1 三层伺服环：电流 / 速度 / 位置¶

    工业机器人的关节一般长这样：伺服电机 + 减速器 + 编码器， 而驱动器内部是嵌套的三层闭环，从内到外：

    层 测什么 控制什么 带宽
    电流环（最内） 绕组电流 电机力矩 最高（kHz 级）
    速度环 角速度 转速 中
    位置环（最外） 角位置 位置 最低

    为什么这样分层：内层快、外层慢 —— 外层的指令，靠内层去「实现」。 位置环只需要下达「转到多少度」，下面两层负责把力矩和速度调好。 这一页讲的，是最外层的「位置环」。

    1.2 两个层次：关节空间 与 笛卡尔空间¶

    机器人位置控制可以在两个层面去做，它们的难度完全不同：

    · 关节空间：直接控制每个关节角 \(\boldsymbol{q}\) —— 简单、成熟， 工业机器人的出厂控制器大多就是这一层； · 笛卡尔空间：直接控制末端位姿 \(\boldsymbol{x}\) —— 更贴近任务（"把杯子移到那"）， 但要经过运动学（正解 / 逆解 / 雅可比），复杂得多，也更容易出问题（奇异性）。

    两者的桥梁是微分运动学：\(\dot{\boldsymbol{x}} = \boldsymbol{J}(\boldsymbol{q})\dot{\boldsymbol{q}}\)。 这句话会在第四节反复用到。

    记住这条主线

    这一页的四节，是同一件事的四个尺度： 先看清位置控制的层次（一）→ 单关节怎么闭环（二）→ 多关节怎么协调（三）→ 末端怎么保证精度（四）。 贯穿始终的只有一个问题：如何让被控量又快又准地跟住目标，同时不被耦合与奇异拖垮。

    1.3 为什么位置控制是「主菜」¶

    · 工业场景大多是「点位 / 轨迹」任务：焊接、搬运、喷涂、上下料 —— 只要走得准，就成了。位置控制够用； · 位置控制是「地基」：力控制、视觉伺服、阻抗控制……都是在位置环之上再套一层。 地基不稳，上层都是空中楼阁。

    所以先把位置控制讲透 —— 它是后面所有控制器件的参照系。

    二、单关节位置控制：一个闭环最小的样子¶

    2.1 关节伺服的简化模型¶

    一个关节，本质上是一个带负载的转动惯量。简化成二阶系统：

    \[ J\ddot{\theta} = \tau - b\dot{\theta} - \tau_d \]

    · \(J\)：折算到关节的总转动惯量（电机 + 减速器 + 连杆）； · \(b\dot{\theta}\)：黏性阻尼（轴承、润滑）； · \(\tau_d\)：恒定负载（重力矩、摩擦、外力 —— 这是稳态误差的根源）； · \(\tau\)：电机（经减速器）给出的关节力矩，也就是我们要设计的控制量。

    2.2 三种控制律：P、PD、PID¶

    最常用的就是 PID（及其退化版）：

    \[ \tau = K_p(\theta_d - \theta) + K_i\!\int_0^t\!\!(\theta_d-\theta)\,d\tau - K_d\,\dot{\theta} \]

    三项各有明确分工：

    项 作用 没有它会怎样
    P（比例） 有偏差就出力 纯 P 必有稳态误差（下面用一个算例说明）
    D（微分） 抑制速度、加阻尼 系统振荡、超调
    I（积分） 累积偏差、补掉恒定负载 稳态误差消不掉

    下面这张方框图把闭环的每个环节摆在一起，恒定负载是从哪里灌进来的也标了出来：

    2.3 算例：P / PD / PID 差在哪¶

    同一台关节、同一个恒定负载，三种控制律跑 3 秒，看稳态误差和超调：

    • 单关节模型：J=0.01, b=0.50，恒定负载 τ_d=0.5 N·m，目标 θ=1.0 rad
    • 控制器 稳态误差(rad) 超调(%)
    • P (Kp=20) 0.02500 10.27
    • PD (Kp=20, Kd=0.5) 0.02500 0.00
    • PID (Kp=20, Ki=100, Kd=0.5) -0.00000 14.68
    • 纯 P 的理论稳态误差 = τ_d/Kp = 0.02500 rad

    读这张表，三件事一目了然：

    1. 纯 P 的稳态误差正好是 \(\tau_d/K_p = 0.5/20 = 0.025\) rad —— 和理论值分毫不差。这不是巧合：稳态时 \(\ddot{\theta}=\dot{\theta}=0\)， 方程退化，必须靠偏差「换」出力矩：\(K_p e = \tau_d\)；
    2. PD 消不掉稳态误差（还是 \(0.025\)），但它把超调压到 0 —— 微分项加阻尼，让系统不过冲；
    3. PID 把稳态误差压到 \(10^{-5}\) 量级以下（表中显示 \(-0.00000\)）—— 积分项累积了那点残余偏差，把恒定负载补掉了。代价是超调变大（\(10.27\%\to14.68\%\)）。

    一句话：P 管「出力」、D 管「稳定」、I 管「消误差」；三者缺一不可，也各有代价。

    把三种控制律的阶跃响应叠在一张图里，残差与超调的差别更直观：

    为什么纯 P 一定有稳态误差

    只要有一个恒定的干扰力矩 \(\tau_d\)（重力、摩擦）， 纯 P 就必须靠偏差出力去抵消它：\(K_p e = \tau_d \Rightarrow e = \tau_d/K_p\)。 偏差是「换取力矩」的代价 —— 想减小，要么加大 \(K_p\)，要么加积分项。 增大 \(K_p\) 只能减小误差、永远消不掉；只有积分项能真正归零。

    三、多关节位置控制：简单办法与它的边界¶

    3.1 独立关节控制：把每个关节当成独立系统¶

    最省事的做法是独立关节控制：忽略关节之间的耦合， 每个关节各自套一个 PID（或 PI + 前馈），互不理会。

    \[ \tau_i = K_{p,i}(q_{d,i}-q_i) + K_{i,i}\!\int\!(q_{d,i}-q_i) - K_{d,i}\dot{q}_i, \qquad i = 1,\dots,n \]

    为什么这招常常够用：机器人关节一般减速比很大（几十到上百）， 折算到电机的负载惯量远小于电机自身惯量 —— 于是「本关节」的动力学占主导，「邻居关节」的耦合成了小扰动。 加上高增益，就能把扰动压下去。

    3.2 但耦合不会消失：它随速度平方增长¶

    回顾第八章的标准形式：

    \[ \boldsymbol{M}(\boldsymbol{q})\ddot{\boldsymbol{q}} + \boldsymbol{C}(\boldsymbol{q},\dot{\boldsymbol{q}})\dot{\boldsymbol{q}} + \boldsymbol{g}(\boldsymbol{q}) = \boldsymbol{\tau} \]

    独立关节控制只把左边的 \(\boldsymbol{M}\ddot{\boldsymbol{q}}\) 近似成对角， 扔掉了完整的 \(\boldsymbol{M}\)、整个科氏项 \(\boldsymbol{C}\dot{\boldsymbol{q}}\) 和重力项 \(\boldsymbol{g}\)。 其中科氏/离心项是速度的二次项 —— 速度一高，它迅速长大。 用一个算例看看它到底多严重（用水平面机械臂，把重力项去掉，单独暴露耦合的影响）：

    • 水平面两连杆（无重力），独立关节 PD：Kp=100, Kd=20
    • 跟踪 q_d(t) = (0.5 sin ωt, 0.5 cos ωt)，ω 越大越快

    不同 \(\omega\) 下的跟踪表现如下：

    ω(rad/s) 峰值关节速度(rad/s) 最大跟踪误差(rad)
    0.5 0.270 0.05564
    1.5 0.788 0.16522

    读这张表：

    · 速度 \(\omega\) 翻 6 倍（\(0.5\to3.0\)），峰值关节速度同比例涨（\(0.270\to1.616\)）； · 跟踪误差涨了近 6.4 倍（\(0.056\to0.357\) rad，约 \(20°\)）—— 因为耦合项 \(\boldsymbol{C}\dot{\boldsymbol{q}}\) 是速度的二次项，误差随之加速恶化。

    这就是独立关节控制的边界：低速、高减速比时够用； 高速、高精度时就顶不住了 —— 必须引入模型信息。

    3.3 两条改进路线¶

    · 计算力矩控制（前馈补偿）：直接逆动力学算出「维持轨迹所需的力矩」， 再叠加 PD 修正误差 —— 第八章已详述，能把非线性精确抵消； · 前馈 + 独立关节反馈：只补重力项 \(\boldsymbol{g}(\boldsymbol{q})\)（因为它不随速度变、最容易算）， 剩下的让 PD 扛 —— 工程上性价比最高的折中。

    独立关节控制什么时候够用

    看两个数：减速比（越大越解耦）和运行速度（越低耦合越小）。 大减速比 + 中低速 → 独立关节 PID 足够； 直驱 / 高动态 / 高精度 → 必须上计算力矩或逆动力学前馈。 判据不是「先进不先进」，而是「耦合项有多大」。

    四、末端位置控制：精度为什么会被「放大」¶

    4.1 关节准 ≠ 末端准¶

    关节空间的控制器能保证每个关节角跟得住目标， 但任务的成败往往取决于末端的位置 —— 而末端位置是关节角的非线性函数：

    \[ \boldsymbol{x} = \boldsymbol{f}(\boldsymbol{q}) \]

    关节误差 \(\delta\boldsymbol{q}\) 会怎么传到末端误差 \(\delta\boldsymbol{x}\)？ 对两边求微分（正是第六章的微分运动学）：

    \[ \boxed{\ \delta\boldsymbol{x} = \boldsymbol{J}(\boldsymbol{q})\,\delta\boldsymbol{q}\ } \]

    关键问题：\(\boldsymbol{J}\) 不是一个「常数缩放」—— 它随位形变化，而且可能退化（奇异）。 \(J\) 一退化，同样的末端运动就需要极大的关节运动（因为 \(\boldsymbol{J}^{-1}\) 失控）。

    4.2 分解运动速度控制：\(\dot{\boldsymbol{q}} = \boldsymbol{J}^{-1}\dot{\boldsymbol{x}}\)¶

    要让末端以指定速度 \(\dot{\boldsymbol{x}}\) 运动，就把速度关系反解：

    \[ \dot{\boldsymbol{q}} = \boldsymbol{J}^{-1}(\boldsymbol{q})\,\dot{\boldsymbol{x}} \]

    这叫分解运动速度控制（resolved motion rate control）： 上层只关心末端的笛卡尔速度，下层由 \(\boldsymbol{J}^{-1}\) 自动算成关节速度。 它把「笛卡尔任务」翻译成了「关节指令」—— 是视觉伺服、力控制的基础模块。

    但它有一个死穴：奇异位形。 当 \(\boldsymbol{J}\) 近似奇异（\(\det\boldsymbol{J}\to0\)）时，\(\boldsymbol{J}^{-1}\) 的元趋向无穷 —— 一点点末端速度，就要关节疯狂旋转去实现。逐项算一遍：

    两连杆（l1=l2=1），沿 y=0 以 0.2 m/s 向外拉，起点 x=0.5 m

    终点 x(m) 末端最大偏差(m) 峰值关节速度(rad/s) 峰值出现在 x(m)
    1.00 1.12e-05 0.258 1.00
    1.90 1.13e-04 0.716 1.90
    1.99 2.27e-04 2.214 1.99

    读这张表：末端始终以恒定速度 \(0.2\) m/s 前进， 但需要的关节速度随「手臂伸得有多直」一路飙升 —— 从 \(0.258\) 涨到 \(2.214\) rad/s（8.6 倍），而且峰值就出现在终点 \(x=1.99\) 处。

    为什么：\(x=1.99\) 时手臂几乎完全伸直（两连杆成一条线）， 这就是奇异位形 —— \(\det\boldsymbol{J}\to0\)， 末端沿 \(+x\) 方向的运动，几乎要靠「肘部把手臂拉直」这一条几乎失效的通道去实现， 于是关节只能越转越快来凑。实际机器人里，这意味着关节超速、力矩饱和、控制器崩溃。

    工程对策：阻尼最小二乘（DLS / Levenberg 法） —— 不老老实实求 \(\boldsymbol{J}^{-1}\)，而是

    \[ \dot{\boldsymbol{q}} = \boldsymbol{J}^{\mathsf T}\big(\boldsymbol{J}\boldsymbol{J}^{\mathsf T}+\lambda^2\boldsymbol{I}\big)^{-1}\dot{\boldsymbol{x}} \]

    \(\lambda\) 是个小「阻尼」。它牺牲一点末端精度，换取关节速度有界 —— 这是所有实用机器人躲奇异的标准手法。

    一句话：末端精度不只是「关节准不准」，更是「位形好不好」； 奇异性是末端位置控制的硬约束，躲不开就只能「减速绕行」。

    例题 1：为什么纯 P 一定有稳态误差¶

    单关节模型 \(J\ddot{\theta} = \tau - b\dot{\theta} - \tau_d\)，控制律 \(\tau = K_p(\theta_d-\theta)\)。 求稳态误差，并说明积分项为什么能消掉它。

    解答

    稳态时所有时间导数都为零：\(\ddot{\theta}=\dot{\theta}=0\)。代入方程：

    \[ 0 = \tau - \tau_d = K_p(\theta_d-\theta) - \tau_d \;\Longrightarrow\; \theta_d-\theta = \frac{\tau_d}{K_p} \]

    所以稳态误差 \(= \tau_d/K_p\) —— 只要 \(\tau_d\neq0\)，就不可能为零。 本页算例：\(\tau_d/K_p = 0.5/20 = 0.025\) rad，与逐项计算完全一致。

    为什么积分项能消掉：加入 \(K_i\int e\) 后，稳态方程变成

    \[ K_p e + K_i\!\int\! e\,dt = \tau_d \]

    稳态时 \(e\) 若为非零常数，积分项 \(\int e\,dt = e\cdot t\) 会随时间无限增大 —— 这不可能收敛。唯一能让系统稳定的，是 \(e\to0\)（此时积分项稳定在某个有限值， 正好等于 \(\tau_d\)）。积分项「记住」了那点残余偏差，用它把恒定负载顶住。

    一句话：纯 P 的稳态误差 \(=\tau_d/K_p\)，是「用偏差换力矩」的必然； 积分项靠「累积」这笔账，把误差归零。

    例题 2：独立关节控制为什么「低速够用、高速不行」¶

    本页算例里，速度 \(\omega\) 从 \(0.5\) 涨到 \(3.0\)，跟踪误差从 \(0.056\) 涨到 \(0.357\) rad。 用动力学方程解释这个「超线性」的增长。

    解答

    根子在科氏/离心项 \(\boldsymbol{C}(\boldsymbol{q},\dot{\boldsymbol{q}})\dot{\boldsymbol{q}}\) 是速度的二次项。

    独立关节控制丢掉了整个 \(\boldsymbol{C}\dot{\boldsymbol{q}}\)（以及重力项、\(\boldsymbol{M}\) 的非对角元）。 这部分被丢掉的力矩，就构成了「未补偿的扰动」，最终表现为跟踪误差。

    既然扰动 \(\propto \|\dot{\boldsymbol{q}}\|^2\)，而 \(\|\dot{\boldsymbol{q}}\| \propto \omega\)， 那么扰动 \(\propto \omega^2\)，误差也就随 \(\omega\) 的平方增长。

    逐项核对：\(\omega\) 从 \(0.5\to3.0\)（\(6\) 倍），\(\omega^2\) 就是 \(36\) 倍； 而误差只涨了 \(0.357/0.056\approx6.4\) 倍 —— 因为 PD 反馈还在部分压制误差， 所以实际增长弱于「纯开环」的平方律，但超线性的趋势非常清楚。

    一句话：耦合项是速度的二次项，所以独立关节控制的误差随速度「加速」恶化 —— 这就是「高速要上模型补偿」的动力学根据。

    例题 3：用雅可比把「关节误差」换算成「末端误差」¶

    两连杆 \(l_1=l_2=1\)、\(\boldsymbol{q}=(30°,90°)\)， 每个关节各有 \(0.001\) rad 的误差。求末端位置误差的量级， 并说明为什么「手臂伸直」时末端精度更脆。

    解答

    第一步：写雅可比。 两连杆（平面）的雅可比是

    \[ \boldsymbol{J} = \begin{bmatrix} -l_1\sin q_1 - l_2\sin(q_1+q_2) & -l_2\sin(q_1+q_2)\\ l_1\cos q_1 + l_2\cos(q_1+q_2) & l_2\cos(q_1+q_2) \end{bmatrix} \]

    代 \(q_1=30°,\ q_2=90°\)、\(l=1\)：

    \[ \boldsymbol{J} = \begin{bmatrix} -0.5 - \sin120° & -\sin120°\\ 0.866 + \cos120° & \cos120° \end{bmatrix} = \begin{bmatrix} -1.366 & -0.866\\ 0.366 & -0.500 \end{bmatrix} \]

    第二步：误差传播。 \(\delta\boldsymbol{x} = \boldsymbol{J}\delta\boldsymbol{q}\)， \(\delta\boldsymbol{q}=(0.001,0.001)\)：

    \[ \delta\boldsymbol{x} = \begin{bmatrix} -1.366-0.866\\ 0.366-0.500\end{bmatrix}\times10^{-3} = \begin{bmatrix} -2.23\\ -0.13\end{bmatrix}\times10^{-3} \;\Rightarrow\; \|\delta\boldsymbol{x}\| \approx 2.2\ \text{mm} \]

    第三步：为什么「伸直」更脆。 当 \(q_2\to0\)（两连杆共线）， \(\boldsymbol{J}\) 的两列趋于线性相关（\(\det\boldsymbol{J}\to0\)）， \(\sigma_{\min}\to0\)，条件数爆炸。此时代数上：

    · 沿奇异方向，\(\boldsymbol{J}\) 几乎「压不出」运动 —— 要产生一点末端位移，关节得转很多（本页算例：峰值关节速度 \(8.6\) 倍）； · 反过来，关节误差在奇异方向上也更容易互相抵消（难以预测）—— 末端精度变得极不可控。

    一句话：末端精度 = 关节精度 × 雅可比的「放大倍数」； 奇异位形就是放大倍数的分母趋于零的地方。

    例题 4：位置控制「顶不住」接触，为什么需要力控制¶

    位置控制能把末端送到指定点 —— 但如果那个点上有个硬东西， 位置控制会发生什么？为什么这时候要换成力控制？

    解答

    会发生「顶死」或「弹飞」。

    位置控制的目标是让位置等于给定值。若目标位置在物体内部（或物体挡在路上）， 控制器只看到「位置还没到」，就会持续加大力矩往外顶 —— 结果要么电机过流 / 结构损坏，要么物体被顶飞，绝无中间态。

    根源：位置控制只关心位置，不关心力。而「接触」本质上是一个 力的问题 —— 位置和力在接触瞬间是强耦合的： \(\delta F \approx k\,\delta x\)（\(k\) 是接触刚度）。位置稍微过一点，力就爆炸。

    正确做法：切换到力控制 / 柔顺控制—— 不再死盯位置，而是控制接触力（或让末端像弹簧一样「软」）。 这正是下一章的内容。

    一句话：位置控制管「到没到」，力控制管「多重」； 一旦任务里有接触，「到没到」就不再是决定成败的量。

    自测¶

    Q1 伺服环的电流环 / 速度环 / 位置环，各自测什么、控制什么？为什么它们的带宽是从内到外依次降低？

    提示

    想：内层要「快」，是为了让外层能把它当成一个「理想的执行器」。

    解答

    · 电流环：测绕组电流，控制电机力矩（电流 ∝ 力矩）—— 带宽最高； · 速度环：测角速度，控制转速 —— 带宽居中； · 位置环：测角位置，控制位置 —— 带宽最低（最外）。

    为什么带宽递减：外层把内层当成为一个已经调好的执行器来用。 只有内层响应足够快，外层才能认为「我下的指令被立刻实现了」，闭环才稳。 如果外层比内层还快，就会自己跟自己打架、失稳。

    一句话：内环快、外环慢，层层套娃 —— 外层的指令，永远靠内层去兑现。

    Q2 纯 P 位置控制的稳态误差等于多少？有哪两条路可以减小它？各自代价是什么？

    提示

    回到稳态方程 \(K_p e = \tau_d\)。

    解答

    稳态误差 \(= \tau_d/K_p\)（\(\tau_d\) 为恒定干扰力矩）。

    两条路：

    · 增大 \(K_p\)：误差反比下降 —— 但永远不为零； 且 \(K_p\) 太大会放大噪声、降低相位裕度、引发振荡（受带宽与采样限制）； · 加积分项 \(K_i\)：积分项累积偏差，把误差真正归零 —— 代价是超调增大、可能积分饱和（需要抗饱和 / 限幅）。

    一句话：加大 P 只能「减小」误差，加 I 才能「消掉」误差； 但两者都要付出稳定性或超调的代价。

    Q3 为什么「独立关节 PID」在多数工业机器人上依然好用？它的适用边界在哪里？

    提示

    想：减速比在这里扮演了什么角色？耦合项随速度怎么变？

    解答

    好用，是因为大减速比天然「解耦」。

    工业关节的减速比常达几十上百，折算到电机的负载惯量远小于电机自身惯量 —— 于是本关节动力学占绝对主导，邻居的耦合项变成小扰动， 高增益 PID 就能把它压下去。再加上控制器结构简单、参数好调、可靠性高。

    适用边界：

    · 速度：耦合项 \(\propto \omega^2\)，高速时误差迅速变大（本页算例已证）； · 减速比：直驱、大负载、柔性关节时解耦假设失效； · 精度要求：微米级、高动态轨迹时，必须上计算力矩 / 逆动力学前馈。

    一句话：独立关节控制是「大减速比 + 中低速」下的最优性价比； 一旦速度或精度要求上来，就得靠模型补偿。

    Q4 分解运动速度控制里，为什么会用 \(\boldsymbol{J}^{-1}\)？在奇异位形附近它出什么问题？怎么补救？

    提示

    想：任务给的是末端速度，关节需要的是关节速度，中间要「翻译」；翻译的逆在奇异处会怎样。

    解答

    用 \(\boldsymbol{J}^{-1}\) 是为了「翻译」：任务空间给的是末端速度 \(\dot{\boldsymbol{x}}\)， 驱动器要的是关节速度 \(\dot{\boldsymbol{q}}\)，两者由 \(\dot{\boldsymbol{x}}=\boldsymbol{J}\dot{\boldsymbol{q}}\) 联系， 反解就是 \(\dot{\boldsymbol{q}}=\boldsymbol{J}^{-1}\dot{\boldsymbol{x}}\)。

    奇异位形附近：\(\det\boldsymbol{J}\to0\)，\(\boldsymbol{J}^{-1}\) 的元发散 —— 一点点末端速度就要极大的关节速度去凑（本页算例：峰值关节速度暴涨 \(8.6\) 倍）， 实际会关节超速、力矩饱和、控制失稳。

    补救：阻尼最小二乘（DLS）

    \[ \dot{\boldsymbol{q}} = \boldsymbol{J}^{\mathsf T}\big(\boldsymbol{J}\boldsymbol{J}^{\mathsf T}+\lambda^2\boldsymbol{I}\big)^{-1}\dot{\boldsymbol{x}} \]

    用 \(\lambda^2\boldsymbol{I}\) 把失控的逆「垫稳」：牺牲一点末端精度，换关节速度有界。 此外还有奇异值截断、路径规划绕开奇异、降速通过等手段。

    一句话：\(\boldsymbol{J}^{-1}\) 负责翻译，奇异处翻译会「失控」； 加阻尼是最常用的「限速」补救。

    小结¶

    要记住的 为什么重要
    伺服三层环：电流 / 速度 / 位置（带宽内高外低） 位置环是最外层，本页的主角
    关节空间 vs 笛卡尔空间（\(\dot{\boldsymbol{x}}=\boldsymbol{J}\dot{\boldsymbol{q}}\) 是桥） 两种控制目标的基本区分
    关节模型 \(J\ddot{\theta}=\tau-b\dot{\theta}-\tau_d\) 单关节闭环的最小模型
    纯 P 稳态误差 \(=\tau_d/K_p\) 「用偏差换力矩」的必然结果
    D 加阻尼（压超调）、I 消稳态误差（但增超调） PID 三项的分工与代价
    独立关节控制：大减速比 + 中低速够用 工业机器人最主流的做法
    耦合项 \(\propto\omega^2\)，所以误差随速度加速恶化 高速必须上模型补偿
    末端误差 \(\delta\boldsymbol{x}=\boldsymbol{J}\delta\boldsymbol{q}\) 关节精度 → 末端精度 的换算
    分解运动速度控制 \(\dot{\boldsymbol{q}}=\boldsymbol{J}^{-1}\dot{\boldsymbol{x}}\) 笛卡尔任务 → 关节指令的标准桥
    奇异位形 \(\det\boldsymbol{J}\to0\)：关节速度失控 算例：峰值速度涨 \(8.6\) 倍
    阻尼最小二乘（DLS）躲奇异 牺牲精度换关节速度有界
    接触时位置控制会「顶死」→ 需要力控制 引出下一章

    四条最容易出错的地方：

    1. 以为「加大 \(K_p\) 就能消掉稳态误差」 —— 只能减小，凡有恒定干扰就必有残差，只有积分能归零
    2. 不管速度，一律用独立关节 PID —— 耦合项随 \(\omega^2\) 增长，高速时误差迅速失控
    3. 忽略奇异位形 —— 关节速度/力矩会在奇异附近爆炸，必须靠 DLS 或绕行
    4. 在接触任务里硬用位置控制 —— 位置和力在接触处强耦合，会「顶死」或「顶飞」，该切力控制
