    机器人的力控制¶

    上一页把位置控制讲透了 —— 只要环境是「空」的，让末端走得准就够了。 但真实任务里永远有接触：装配、打磨、抓取、擦桌子。 一接触，位置和力就绑在一起：位置稍微过一点，力就爆炸。 这一页讲的，是机器人怎么学会「手上使多大劲」—— 主线是四步：看清接触为什么难（一）→ 让末端变「软」（二）→ 把任务拆成「控力方向」和「控位置方向」（三）→ 落到装配这个经典场景（四）。

    一、当任务里有「接触」：位置控制的极限¶

    1.1 位置控制有一个隐含前提：环境是「空」的¶

    位置控制的目标只有一个：让被控位置等于指令值，隐含默认「空间是自由的」—— 只要电机出力，末端总能到任意目标。

    接触打破了这个前提。 末端碰到物体，那个位置就多了一个约束：过不去就是过不去。 此时位置控制器只看到「位置还没到」，于是持续加大力矩往外顶 —— 结果要么电机过流、结构损坏，要么工件被顶飞。位置控制没有「中间态」。

    1.2 接触把「位置」和「力」焊死在一起¶

    接触面上，位置偏差 \(\delta x\) 和接触力 \(F\) 是近似线性、但系数极大的关系：

    \[ \delta F \approx k_{\text{contact}}\,\delta x \]

    \(k_{\text{contact}}\) 是接触刚度，刚性金属件常达 \(10^{5}\sim10^{7}\) N/m —— 位置差 \(0.1\) mm，力的量级就是几十上百牛。

    一句话：位置控制追求「零位置误差」，恰恰等价于「把力推到无穷大」—— 刚性接触面上，「位置精确」和「力可控」不可兼得。

    1.3 两个世界的自由度：位置 与 力，只能选一个¶

    在每一个自由度（方向）上，位置和力是一对共轭量 —— 就像电路里的电压和电流、结构里的位移和载荷：

    方向类型 能指定的 另一个量由什么决定
    自由方向（没接触） 位置 / 速度 力恒为 0
    约束方向（有接触） 力 位置由环境/工件决定

    这就是力控制的第一条铁律：在同一个方向上，位置和力不能同时指定。 要么让机器人「管位置、力随缘」，要么「管力、位置交给环境」。

    两种方向的分工可以画成一张并排对比图：

    这一页的主线

    位置控制管「到没到」，力控制管「多重」。 一旦任务里有接触，成败就不再由位置决定 —— 于是我们依次学会三招：让末端变软（柔顺控制）→ 按方向分工（力/位混合）→ 用到装配上。 贯穿始终的判断只有一条：这个方向上，我该指定位置还是力？

    1.4 力从哪来：先得有「手感」¶

    要给机器人加力控制，前提是能测力 —— 这正是第九章的六维力/力矩传感器、 关节力矩传感器、以及各类触觉传感器的用武之地。 没有力信息，就无从谈力控制；这一点在第四节的装配任务里会格外直观。

    二、柔顺控制：让末端变成一支「弹簧」¶

    2.1 被动柔顺 与 主动柔顺¶

    既然「硬碰硬」会出事，一个直接的办法是让机器人变软。有两条路：

    · 被动柔顺：末端装一个机械弹性件 —— 典型是 RCC（Remote Center of Compliance，远端柔顺中心），用一组弹簧片让末端在某点附近「能歪、能转」。 优点：无需传感器、无延迟、本质安全；缺点：柔顺特性出厂就定死，换任务就得换件； · 主动柔顺：用力传感器 + 控制律，在软件里「算出」软特性。 优点：刚度、阻尼可编程、随任务切换；缺点：依赖传感器与控制带宽，且只能对已测量的力作出反应。

    工业上两者常组合使用：RCC 提供「粗柔顺」吸收大偏差，主动控制提供「精细柔顺」调力。这一节主要讲主动柔顺。

    2.2 阻抗控制：控制「位置—力」的关系¶

    阻抗控制（impedance control，Hogan 1985） 的思路很特别： 它既不死管位置，也不死管力 —— 它控制二者之间的关系。

    把机器人末端在接触方向上设计成一个虚拟的质量—阻尼—弹簧系统：

    \[ \boldsymbol{M}_d\,\ddot{\boldsymbol{x}} + \boldsymbol{B}_d\,\dot{\boldsymbol{x}} + \boldsymbol{K}_d\,(\boldsymbol{x}-\boldsymbol{x}_d) = \boldsymbol{F}_{\text{ext}} \]

    · \(\boldsymbol{x}_d\)：期望的「零力平衡位置」（不是硬指令，是弹簧的自然长度）； · \(\boldsymbol{M}_d,\ \boldsymbol{B}_d,\ \boldsymbol{K}_d\)：希望机器人表现的惯量、阻尼、刚度（都是设计参数）； · \(\boldsymbol{F}_{\text{ext}}\)：环境给末端的外力。

    读这个式子：外力越大，末端偏离 \(\boldsymbol{x}_d\) 越多 —— 偏差不再是「错误」，而是「力」的度量。 环境推它，它就让；力大退得多，\(\boldsymbol{K}_d\) 越小越「软」。 阻抗控制的核心就是：把「力」翻译成「位置偏差」，再用位置环去实现偏差。

    这张图把等效模型的每个元件对齐到实际部件上，末端与接触对象的关系也画了出来：

    一个漂亮的副产品：稳态下 \(\dot{\boldsymbol{x}}=\ddot{\boldsymbol{x}}=0\)，于是

    \[ \boldsymbol{K}_d\,(\boldsymbol{x}-\boldsymbol{x}_d) = \boldsymbol{F}_{\text{ext}} \;\Longrightarrow\; \boldsymbol{F}_{\text{ext}} = \boldsymbol{K}_d\,(\boldsymbol{x}_d-\boldsymbol{x}) \]

    接触力由「目标刚度 \(\boldsymbol{K}_d\)」直接决定，而与接触对象的刚度几乎无关（下面用一组数会验证）。 这是阻抗控制最值钱的性质：面对「不知道有多硬」的环境，它依然给得出一个可预期的力。

    2.3 阻抗 vs 导纳：给力矩机器人，还是给位置机器人¶

    阻抗控制要在末端「表现」出力与偏差的关系，实现上分两族，取决于底层机器人能给什么：

    阻抗控制 导纳控制
    模型关系 位置偏差 \(\to\) 力 力 \(\to\) 位置修正
    输入 / 输出 输入位置，输出力 输入力，输出位置
    底层要求 关节力矩可控（直驱/力矩模式） 有位置内环即可
    典型场景 协作臂、力控专机 传统工业位置控制机器人
    核心方程 \(\boldsymbol{F} = \boldsymbol{K}_d(\boldsymbol{x}_d-\boldsymbol{x})\) \(\boldsymbol{K}_d\,\Delta\boldsymbol{x} = \boldsymbol{F}_{\text{ext}},\ \ \boldsymbol{x}_{\text{cmd}}=\boldsymbol{x}_d+\Delta\boldsymbol{x}\)

    导纳控制是「外环算位置、内环执行位置」：测到外力 \(\boldsymbol{F}_{\text{ext}}\)，用虚拟模型算出该退让多少 \(\Delta\boldsymbol{x}\)，把 \(\boldsymbol{x}_d+\Delta\boldsymbol{x}\) 交给原来的位置控制器 —— 让任何一台「只会做位置」的工业机器人获得柔顺能力，工程上极常见。

    阻抗 / 导纳 一句话区分

    看「输入」是什么、机器人「天生的强项」是什么： 机器人擅长出力（力矩模式）→ 用阻抗（给它位置指令，它自己换算出力）； 机器人擅长走位（位置模式）→ 用导纳（给它力，它换算成位置修正）。 同一种柔顺，两种接线方式。

    2.4 算例：同一面刚性墙，三种控制¶

    把一维质量块 \(m=1\) 对着刚性墙（\(k_w=10^{5}\) N/m）压过去， 目标「再压进去 \(10\) mm」；分别用纯位置 / 阻抗 / 显式力控，看稳态接触力差多少：

    一维撞墙：m=1.0, 墙刚度 k_w=100000 N/m，目标压入 10 mm，力目标 5.0 N

    • 控制方式 稳态接触力(N) 稳态侵入(mm)
    • 纯位置控制 (Kp=5000) 47.62 0.476
    • 阻抗控制 (K=200) 2.00 0.020
    • 力控制 (F_d=5.0 N) 5.00 0.050

    读这张表，三种控制的分工一目了然：

    1. 纯位置控制：接触力 \(47.62\) N —— 是副产物，由位置增益与墙刚度「分压」出来，想设多少由不得你；\(K_p\) 越大、墙越硬它越大 —— 这正是位置控制做接触任务会「出事」的根源；
    2. 阻抗控制：接触力 \(2.00\) N —— 恰好是 \(K_d\cdot x_d = 200\times0.01\)，由「目标刚度」决定、与墙刚度无关，可事先算出、可调；
    3. 力控制：接触力 \(5.00\) N —— 精确等于设定值 \(F_d\)；侵入深度只有 \(0.050\) mm（\(=F_d/k_w\)），位置多少无所谓，力对就行。

    一句话：纯位置控制下，接触力是「命运的赠品」；阻抗控制下，它是「可设计的弹性」； 力控制下，它是「被锁定的指标」。

    三、力/位混合控制：把运动分解到不同方向¶

    3.1 约束坐标系：把任务空间拆成「自由」和「约束」¶

    一次接触任务里，不是所有方向都需要控力。以「拿砂纸打磨桌面」为例：竖直方向要压住桌面（该控力），水平方向要划过去（该控位置）—— 两个方向性质完全不同。

    Mason 提出用约束坐标系（constraint frame, C-frame）组织这件事：在接触点建系，把任务空间逐轴分成两类：

    · 自由方向（free axis）：可自由运动 —— 指定位置/速度，力自然为 0； · 约束方向（constrained axis）：被环境挡住 —— 指定力，位置由环境决定。

    这把上一节的「二选一」从「整个空间」细化到「每个方向」 —— 一个任务可同时在不同方向「控位置」和「控力」。

    3.2 自然约束 与 人工约束¶

    在约束方向上，约束有两个来源，必须分清楚：

    自然约束（natural） 人工约束（artificial）
    由谁决定 环境几何 / 物理（如：扳手拧不动就是拧不动） 任务需求（人指定）
    表现形式 约束方向速度 = 0；自由方向力 = 0 想让它做的那件事
    例子 刚体不能互相穿透、静止物体不产生切向力 「以 \(5\) N 压住」「以 \(0.1\) m/s 划过」
    是否可改 不可改（客观物理） 随便改（改指令即可）

    关键规则：约束方向上自然约束给出「速度=0」，所以用人工约束指定「力」；自由方向上自然约束给出「力=0」，所以用人工约束指定「速度/位置」。 两类约束在每个方向上恰好「互补」，不能重叠、不能留空。

    3.3 力/位混合控制器：一个「选择矩阵」\(\boldsymbol{S}\)¶

    把这个「按方向分工」写成公式，就有了力/位混合控制（hybrid motion–force control）。 用一个对角的选择矩阵 \(\boldsymbol{S}\)（对角元非 \(0\) 即 \(1\)）来标记每个方向：

    \[ \boldsymbol{\tau} = \boldsymbol{J}^{\mathsf T}\Big[\, \underbrace{\boldsymbol{S}\big(\boldsymbol{K}_p(\boldsymbol{x}_d-\boldsymbol{x}) - \boldsymbol{K}_d\dot{\boldsymbol{x}}\big)}_{\text{位置方向：PD 修正}} \;+\; \underbrace{(\boldsymbol{I}-\boldsymbol{S})\big(\boldsymbol{F}_d-\boldsymbol{F}\big)}_{\text{力方向：力误差}} \,\Big] \;+\;\boldsymbol{g}(\boldsymbol{q}) \]

    · \(\boldsymbol{S}\) 的第 \(i\) 个对角元为 \(1\)：该方向走位置控制（力自然为 0）； · \(\boldsymbol{S}\) 第 \(i\) 个对角元为 \(0\)：该方向走力控制（位置随环境）； · \(\boldsymbol{J}^{\mathsf T}\)：把末端笛卡尔空间的「合力和力矩」映射回关节力矩 —— 这正是第六章「力/力矩的雅可比对偶关系」，也是本页与微分运动学的接口。

    为什么必须用 S 矩阵，不能两边都控

    因为位置和力在同一个方向上是共轭的：物理上不允许同时指定。 若两个环同时接管同一个方向，它们会互相打架 —— 位置环说「再进去点」，力环说「退出来」，结果振荡或发散。 \(S\) 的作用就是一纸「分工协议」：一个方向只归一个环。

    3.4 算例：沿「起伏的墙」扫，控力还是控位置¶

    把墙面做成起伏的（幅值 \(\pm0.5\) mm 的正弦），机器人沿墙扫描： \(x\) 方向贴住墙，\(y\) 方向走正弦轨迹。 比较「\(x\) 死守位置」和「\(x\) 控力」两种策略下，接触力有多稳：

    沿起伏墙面扫（起伏 ±0.5 mm），x 方向贴墙、y 方向扫 ±0.1 m 正弦

    控制方式 平均接触力(N) 接触力波动(N) y 最大跟踪误差(m)
    纯位置控制（x 固定） 54.55 29.95 1.59e-02
    力/位混合（x 控力 2 N） 2.00 0.24 1.59e-02

    读这张表，力/位混合的价值就出来了：

    1. 纯位置控制（x 固定）：x 死死钉在 \(0.6\) mm，墙面一起伏接触力就跟着起伏 —— 平均 \(54.55\) N、波动高达 \(29.95\) N。 机器人对「墙面差 \(0.5\) mm」毫无办法，因为它的 \(x\) 被指令锁死了 —— 打磨里意味着忽轻忽重，装配里意味着忽顶忽松；
    2. 力/位混合（x 控力 \(2\) N）：接触力稳稳压在 \(2.00\) N，波动只有 \(0.24\) N（降了两个数量级）—— 机器人自己去追墙面起伏，该退就退、该进就进，力始终不变；
    3. \(y\) 方向跟踪误差两者完全相同（\(1.59\times10^{-2}\) m）：这证明在 \(x\) 方向换掉控制律，对 \(y\) 方向的位置跟踪毫无影响 —— 这正是「混合」的意义：不同方向各管各的，互不干扰。

    一句话：位置控制在接触面上「硬碰硬」，把环境的形状误差全部吃成力的波动； 力/位混合让机器人「顺着环境的形状走」，换来一个稳定的接触力。

    四、力控制的用武之地：轴孔装配¶

    4.1 为什么装配是最经典的力控任务¶

    轴孔装配（peg-in-hole） —— 把一根销插进一个孔 —— 是机器人领域被研究得最多、也最能说明问题的接触任务。 它几乎完美地包含了力控制要面对的全部麻烦：

    · 间隙很小：孔和销的配合间隙常在几十微米量级，比机器人定位精度还紧； · 初始偏心：销和孔轴线对不齐（本页算例取初始偏心 \(2\) mm），一插就撞壁； · 接触力方向会「指路」：孔壁把销往孔心推 —— 这个天然的方向性，正是力控的抓手； · 失败模式危险：位置控制下会卡死（jamming）、顶伤孔壁、甚至损坏工件。

    4.2 位置控制为什么「卡死」¶

    位置控制的逻辑是「不管遇到什么，先把位置开到指令点」。但装配里机器人根本不知道孔在哪（孔位有误差、工件有装配公差）—— 于是朝着错误的目标硬顶：销撞上孔壁、侧向力急剧增大，位置控制器越顶越用力却永远差那一点点。这就是「卡死」。 本页算例复现了这个场景：偏心状态下，位置控制既消不掉偏心，也降不下侧向力。

    4.3 力控为什么能「引」销入孔¶

    关键洞察：侧向接触力的方向天然指向孔心 —— 孔壁把销往里推，等于环境免费告诉你「孔在哪个方向」。

    于是把侧向接触力控到 0，就等价于顺着这个方向滑向孔心：力控用「力」这条线索替代了缺失的「孔位信息」。 一旦销滑进孔内（偏心小于间隙），侧向力自然归零，装配完成。

    所以装配难用纯位置控制、而天生适合柔顺/力控制 —— 位置控制要「先知道位置」，力控制要「能测力」； 在「位置未知但力可测」的场景里，力控制拿到了更靠谱的信息。

    4.4 算例：轴孔装配，位置控制 vs 力控¶

    孔的单边间隙 \(0.5\) mm，初始偏心 \(2\) mm（远大于间隙，一定会撞壁）， 比较「纯位置」和「把侧向力控到 0」两种策略的最终偏心与侧向力：

    轴孔装配：单边间隙 0.5 mm，初始偏心 2.0 mm，接触刚度 1e+05 N/m

    策略 稳态偏心(mm) 侧向接触力(N)
    纯位置控制 0.571 7.14
    力控（目标侧向力 0） 0.345 0.00

    读这张表，装配的两条路彻底分开了：

    1. 纯位置控制：指令是「保持在偏心 \(2\) mm 处」，机器人忠实地执行了，可这毫无意义 —— 最终偏心停在 \(0.571\) mm、侧向力 \(7.14\) N 一直顶在孔壁上，这就是卡死：位置没错（相对指令），力却是灾难；
    2. 力控（目标侧向力 \(0\)）：侧向力被压到 \(0.00\) N，偏心降到 \(0.345\) mm —— 注意 \(0.345 < 0.5\)（间隙），销已进入孔内、不再碰壁。 机器人从头到尾不知道孔在哪，却靠「把力压到 0」自己滑进了孔心。

    一句话：装配的难点不在「走得准」，而在「不知道对得准不准」； 力控制用「接触力」替代「孔位信息」，把「对准」变成了一个「把力调零」的问题 —— 这是它最漂亮的地方。

    例题 1：求纯位置控制的稳态接触力¶

    质量块 \(m=1\) kg，以「再压入 \(x_d=10\) mm」为目标的纯位置控制 （\(K_p=5000\) N/m）撞向刚性墙（\(k_w=10^{5}\) N/m）。 求稳态侵入深度与接触力，并说明为什么这个力「设不了」。

    解答

    稳态条件：\(\dot{x}=0\)（速度为零）、\(a=0\)（合力为零）。 纯位置控制律 \(F = K_p(x_d-x)\)，墙反力 \(F_c = k_w x\)。合力为零要求：

    \[ K_p(x_d-x) = k_w x \;\Longrightarrow\; x = \frac{K_p\,x_d}{K_p + k_w} \]

    代入 \(K_p=5000,\ x_d=0.01,\ k_w=10^{5}\)：

    \[ x = \frac{5000\times0.01}{5000+10^{5}} = \frac{50}{1.05\times10^{5}} = 4.762\times10^{-4}\ \text{m} = 0.476\ \text{mm} \]
    \[ F_c = k_w\,x = 10^{5}\times4.762\times10^{-4} = 47.62\ \text{N} \]

    与逐项计算完全一致（\(47.62\) N / \(0.476\) mm）。

    为什么「设不了」：看 \(F_c = k_w\,x = \dfrac{k_w K_p}{K_p+k_w}\,x_d\) —— 它由 \(K_p\)、\(k_w\)、\(x_d\) 三者共同分压决定。任务只给了 \(x_d\)， 你无法单独指定接触力；墙一变硬、\(K_p\) 一调，力就跟着变。 想让它小一点，只能降 \(K_p\) 或减小 \(x_d\)，而那又会牺牲位置精度。

    一句话：纯位置控制里，接触力是「位置增益与墙刚度分压」的副产物， 不是你能拧的旋钮 —— 这就是它做接触任务会出事的数学根源。

    例题 2：阻抗控制的接触力为什么与「墙」无关¶

    同一面墙，改用阻抗控制（目标刚度 \(K_d=200\) N/m）。 求稳态接触力，并证明当墙足够硬时，它只由 \(K_d\) 和 \(x_d\) 决定。

    解答

    稳态平衡：阻抗控制的虚拟弹簧给出 \(F = K_d(x_d-x)\)，墙反力仍为 \(F_c = k_w x\)。 合力为零：

    \[ K_d(x_d-x) = k_w x \;\Longrightarrow\; x = \frac{K_d\,x_d}{K_d + k_w} \]

    接触力（注意它就是虚拟弹簧的压缩量）：

    \[ F_c = K_d(x_d - x) = K_d\left(x_d - \frac{K_d x_d}{K_d+k_w}\right) = K_d\,x_d\cdot\frac{k_w}{K_d+k_w} \]

    当墙足够硬（\(k_w \gg K_d\)）时：

    \[ \frac{k_w}{K_d+k_w} \to 1 \;\Longrightarrow\; \boxed{\,F_c \to K_d\,x_d\,} \]

    代入 \(K_d=200,\ x_d=0.01\)：\(F_c \to 200\times0.01 = 2.00\) N。 逐项算下来是 \(2.00\) N（墙刚度 \(10^{5}\gg200\)，已足够「硬」）—— 吻合。

    意义：\(F_c \approx K_d x_d\) 不含 \(k_w\) —— 无论墙是钢是铝、是硬是软，只要它够硬，接触力都可预期。 面对「不知道有多硬」的真实环境，这正是阻抗控制最值钱的地方。 想改接触力？调 \(K_d\) 或 \(x_d\) —— 它们都是你手里的设计参数。

    一句话：阻抗控制把「接触力」从「环境的函数」变成了「我自己的参数」，这叫柔顺，也叫鲁棒。

    例题 3：给一个打磨任务，写清每个方向控什么¶

    机器人拿砂纸打磨一个水平桌面：要求竖直方向以 \(5\) N 压紧， 水平方向以 \(0.1\) m/s 匀速划过。 用约束坐标系的思路，说明每个方向控位置还是控力、 自然约束/人工约束各是什么，并写出选择矩阵 \(S\) 的形式。

    解答

    第一步：定约束坐标系。 在接触点建系：\(n\)（法向，竖直）、\(t_1,t_2\)（切向，水平）。

    第二步：逐方向判断。

    方向 自然约束（环境给的） 人工约束（任务要的） 控什么
    法向 \(n\) 不能穿透桌面 → 速度 \(=0\) 压紧力 \(=5\) N 控力
    切向 \(t_1\) 光滑桌面切向力 \(\approx0\) 速度 \(=0.1\) m/s 控位置/速度
    切向 \(t_2\) 同上，切向力 \(\approx0\) 速度 \(=0\) 控位置/速度

    关键：每个方向上，自然约束管住的那个量（法向速度 / 切向力）， 正是我们不能再去指定的量；于是人工约束去指定它的共轭量 —— 法向指定力、切向指定速度。两类约束恰好互补、不重叠。

    第三步：写 \(S\)。 在约束坐标系下（顺序 \(n,t_1,t_2\)）， 位置方向取 \(1\)、力方向取 \(0\)：

    \[ \boldsymbol{S} = \operatorname{diag}(0,\ 1,\ 1) \]

    代入力/位混合律 \(\boldsymbol{\tau} = \boldsymbol{J}^{\mathsf T}\big[\boldsymbol{S}(\cdots) + (\boldsymbol{I}-\boldsymbol{S})(\cdots)\big]\)：

    · 法向（\(S_{nn}=0\)）：走 \((\boldsymbol{I}-\boldsymbol{S})\) 分支 → 力误差 \(F_d-F\)； · 切向（\(S=1\)）：走 \(\boldsymbol{S}\) 分支 → 位置 PD。

    第四步：想一个现实问题 —— 若桌面不平（有起伏）， 法向力控会自动跟着起伏走（该退就退），而切向的位置控制不受影响 —— 这正是上一节算例验证过的结论。

    一句话：把任务拆成「法向控力、切向控位置」， 用一个 \(S\) 矩阵把分工写死 —— 这就是力/位混合控制解决打磨的全部逻辑。

    例题 4：力控为什么能「引」销入孔¶

    轴孔装配里，机器人不知道孔的准确位置，初始偏心 \(2\) mm（远大于 \(0.5\) mm 间隙）。 解释：为什么「把侧向接触力控到 0」就能让销自己滑进孔心？

    解答

    第一步：看清接触力的方向。 销偏在位心一侧、撞上孔壁。孔壁对销的作用力法向垂直于孔壁、指向孔内，也就是天然把销往孔心推 —— 侧向接触力的方向里免费携带了「孔心在哪边」这条信息。

    第二步：力控做了什么。 力控目标是把侧向力压到 0，于是控制器驱动销朝「力减小」的方向走 —— 而这正是背离孔壁、滑向孔心的方向。 只要还在碰壁，力就非零，机器人就一直朝孔心挪；一旦进入孔内（偏心 \(<\) 间隙），力自然归零，任务完成。

    第三步：对照算例。 纯位置控制：偏心 \(0.571\) mm、侧向力 \(7.14\) N（卡在壁上）； 力控：侧向力 \(0.00\) N、偏心 \(0.345\) mm —— 小于间隙 \(0.5\) mm，说明已进入孔内。 两条路的差别不在控制器「好不好」，而在 它们各自依赖的信息不同：位置控制依赖「知道孔在哪」，力控依赖「测得到力」。

    第四步：本质。 装配的困难是「位置信息缺失」；力控制换了一条信息通道，把「对准」翻译成「把力调零」—— 这就是「力控制天生适合装配」的根本原因。

    一句话：接触力是环境给的「路标」，把力调零就是顺着路标走 —— 机器人不必知道孔在哪，力会把它带进去。

    自测¶

    Q1 被动柔顺和主动柔顺各是什么？RCC 属于哪一类，为什么它不需要力传感器？

    提示

    想：柔顺特性是「造出来的」还是「算出来的」？各自能不能改、改起来贵不贵？

    解答

    · 被动柔顺：靠机械弹性结构提供柔顺，典型是 RCC（远端柔顺中心），用弹簧片让末端在某点附近能歪能转。 优点：无需传感器、无延迟、本质安全；缺点：柔顺特性结构定死，换任务得换件； · 主动柔顺：靠力传感器 + 控制律，在软件里「算出」软特性（如阻抗控制）。 优点：刚度/阻尼可编程；缺点：依赖传感器与带宽。

    RCC 属于被动柔顺：柔顺来自弹簧的物理变形 —— 外力的效果直接体现在几何位移上，不需要测量力。 机器人只需照常做位置控制，RCC 会自己「吸收」那点偏差。 一句话：被动柔顺把「软」做进机械里，主动柔顺把「软」写进控制器里。

    Q2 阻抗控制和导纳控制有什么区别？各自适合什么样的底层机器人？

    提示

    看两个维度：模型是「位置→力」还是「力→位置」，以及机器人天生擅长出力还是走位。

    解答
    阻抗控制 导纳控制
    关系 位置偏差 \(\to\) 力 力 \(\to\) 位置修正
    输入/输出 输入位置，输出力 输入力，输出位置
    底层 关节力矩可控 有位置内环即可
    场合 协作臂、直驱力控臂 传统工业位置控制机器人

    · 阻抗控制：机器人自己实时算出该出多大力来实现「位置—力」关系， 要求它能直接控制力矩； · 导纳控制：外层测到力、用虚拟模型算出该退让多少位置， 把修正后的位置交给原来的位置控制器执行 —— 让「只会做位置」的机器人也拥有柔顺，工程上极常见。

    一句话：擅长出力→用阻抗；擅长走位→用导纳。同一种柔顺，两种接线方式。

    Q3 什么是自然约束、什么是人工约束？为什么它们必须「互补」而不能「重叠」？

    提示

    想：谁决定「不能穿墙」？谁决定「以 5 N 压住」？这两者能同时作用在同一个方向上吗？

    解答

    · 自然约束：由环境物理/几何决定、改变不了 —— 如「刚体不能互相穿透」（约束方向速度 \(=0\)）、「光滑面不产生切向力」（自由方向力 \(=0\)）； · 人工约束：由任务需求指定、随时可改 —— 如「以 \(5\) N 压住」「以 \(0.1\) m/s 划过」。

    为什么必须互补：每个方向上自然约束已「占用」一个量（约束方向占速度，自由方向占力）；位置和力是共轭量，同一方向只能指定一个。 所以人工约束必须去指定另一个：约束方向控力、自由方向控位置。 若重叠（既控位置又控力）→ 两环互相打架、振荡甚至发散；若有缺口（两个都不管）→ 机器人在该方向失控（乱冲或乱飘）。

    一句话：自然约束划下「哪些量已经被环境拿走了」， 人工约束只能去填「剩下的空位」—— 一个方向一个环，不能抢、不能空。

    Q4 力/位混合控制里，选择矩阵 \(\boldsymbol{S}\) 起什么作用？为什么不能省掉它、直接「位置和力一起控」？

    提示

    回到「一个方向只能指定一个量」这条铁律；再想位置环和力环同时接管会发生什么。

    解答

    \(\boldsymbol{S}\) 是一张「逐方向的分工表」：对角元为 \(1\) 的方向走位置 PD（力自由为 0），为 \(0\) 的方向走力误差反馈（位置随环境）。 它把「哪些方向控位置、哪些方向控力」显式写成矩阵，清楚又可按条件切换。

    为什么不能省：位置和力在同一方向上是共轭量，物理上不允许同时指定（就像不能同时指定电压和电流）。若两环同时接管同一方向： 位置环说「再进去一点」（位置没到），力环说「退出来一点」（力太大），方向相反、抵消不掉 → 执行器来回振荡甚至发散。 \(\boldsymbol{S}\) 加上 \((\boldsymbol{I}-\boldsymbol{S})\) 恰好互补：每个方向有且仅有一个环接管 —— 这正是「混合」的数学保证。

    一句话：\(\boldsymbol{S}\) 把「一个方向一个环」这条物理铁律， 写成了一个控制器里干净的分工矩阵 —— 省了它，两个环就会打架。

    小结¶

    要记住的 为什么重要
    接触把位置和力焊在一起：\(\delta F\approx k_{\text{contact}}\delta x\) 位置微差 → 力暴大，位置控制做接触会出事
    一个方向只能指定一个量（位置 或 力） 力控制的第一铁律
    被动柔顺（RCC）vs 主动柔顺（传感器+控制律） 两种「让末端变软」的路线
    阻抗控制：\(\boldsymbol{M}_d\ddot{\boldsymbol{x}}+\boldsymbol{B}_d\dot{\boldsymbol{x}}+\boldsymbol{K}_d(\boldsymbol{x}-\boldsymbol{x}_d)=\boldsymbol{F}_{\text{ext}}\) 控的是「位置—力关系」，允许偏差
    阻抗稳态力 \(\approx \boldsymbol{K}_d\boldsymbol{x}_d\)，与墙刚度无关 算例：\(2.00\) N，由目标刚度决定
    阻抗 vs 导纳：位置→力 vs 力→位置 力矩机器人用阻抗，位置机器人用导纳
    约束坐标系：自由方向 / 约束方向 把「二选一」细化到每个方向
    自然约束（环境）与人工约束（任务）恰好互补 一个方向一个环，不能抢、不能空
    力/位混合律含选择矩阵 \(\boldsymbol{S}\) 与 \(\boldsymbol{J}^{\mathsf T}\) \(S\) 分工，\(\boldsymbol{J}^{\mathsf T}\) 把末端的力映射回关节
    算例：纯位置接触力波动 \(29.95\) N → 混合后 \(0.24\) N 力/位混合把环境误差「吃掉」
    轴孔装配：纯位置「卡死」、力控「引销入孔」 力控制用「力」替代「孔位信息」
    力控制的前提是能测力 六维力/矩传感器、关节力矩传感器

    四条最容易出错的地方：

    1. 以为「位置精度够高就能做装配」 —— 接触刚度极高，位置差 \(0.1\) mm 就能催出几十牛的力，位置控制会把环境误差全吃成力
    2. 把阻抗控制和力控制混为一谈 —— 阻抗控制控的是「位置—力关系」（允许偏差、力是结果），力控制直接盯住「力」（偏差是手段）
    3. 在同一个方向上同时指定位置和力 —— 违反共轭铁律，两个环会互相打架、振荡发散，必须用 \(\boldsymbol{S}\) 分工
    4. 忘记「力从哪来」 —— 显式力控制必须有力测量（六维力/矩、关节力矩、触觉）；无力传感器时只能用位置型阻抗近似柔顺
