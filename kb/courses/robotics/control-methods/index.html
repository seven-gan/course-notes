    机器人的控制方法¶

    前面几页已经把「控什么」讲完了 —— 位置、力、柔顺。 但还有一个更底层的追问：用什么「方法」去控？ 这一页把机器人控制的方法族谱摊开：从最经典的 PID， 到滑模变结构、自适应、模糊、神经网络 —— 主线是：先看清「模型哪里不准」（一）→ 逐一看四种方法各自靠什么「不准」的招（二、三、四）。 读的时候盯住三件事：它靠什么、要付什么代价、什么时候该用。

    一、控制方法的谱系：从 PID 到智能控制¶

    1.1 位置控制、力控制都还留着「同一个洞」¶

    第十章的 PID、第十一章的阻抗与力控，本质都在做同一件事： 根据「现在的偏差」算出「该给多大力」。它们都默认了一件事 —— 模型是准的。

    可真实机器人有三个绕不过去的「不准」：

    「不准」的来源 典型例子 后果
    参数不确定 负载质量未知、惯量随抓取物变化、摩擦系数漂移 增益按错的模型调 → 误差大，甚至振荡
    未建模动态 柔性关节、传动间隙、高频谐振 高增益一开就啸叫
    外部扰动 接触力、切削力、阵风、地面起伏 稳态误差、跟踪滞后

    PID 对此只有一招：靠反馈把偏差压小。但反馈有一个硬上限 —— 增益越大响应越快，也越容易振荡。所以在「模型不准」这件事上， 纯反馈天然处于劣势：它手里只有「偏差」这一条信息。

    1.2 五类方法的看家本领¶

    它们的根本差别，是「靠什么东西」来对付那三个「不准」：

    方法 靠什么 要不要模型 一句话
    PID（第 10 章） 纯反馈 不要 简单、可靠，但只靠偏差这一条信息
    滑模变结构 一个「滑模面」+ 强切换 只要「界」 对扰动几乎「免疫」，代价是抖振
    自适应控制 在线估计未知参数 要结构、不要数值 一边干一边学，参数未知也能收敛
    模糊控制 专家经验（规则表） 不要 把「手感」写成规则，无需建模、天然有界
    神经网络控制 数据 / 在线学习 不要 万能逼近，把未知非线性「学」出来

    关键认识：这几种方法不是互相替代，而是「对付不同种类的不准」的专用工具； 工程里它们几乎从不单用，而是组合：模糊滑模、神经网络自适应……

    这一页的主线

    所有控制方法都在回答同一个问题：当模型不可靠时，我还能靠什么？ 后面四节就是四个答案：靠滑模面（二）→ 靠在线估计（三）→ 靠经验规则（四之一）→ 靠数据学习（四之二）。 判断一种方法值不值得用，只看一件事：它在这条「纯反馈基准线」上，赢出的差距能不能被解释。

    1.3 先立一条「及格线」¶

    后面每一节，我都拿同一个基准去对照：不加任何额外机制、只有反馈的控制器。 如果一种方法没能在这条线上赢出可解释的差距，它就不值得上 —— 这不是苛刻，而是本页每一段代码都在做的事。

    二、滑模变结构控制¶

    2.1 核心思想：先划一条「滑模面」，再把它逼上去¶

    滑模控制的思路很独特 —— 它不直接控制误差，而是控制误差「走的路」。

    以单关节 \(J\ddot{\theta} = \tau - b\dot{\theta} - d\) 为例，令误差 \(e = \theta_d - \theta\)， 人为定义一条滑模面：

    \[ s = \dot{e} + \lambda e = 0 \]

    这条式子的含义：只要系统状态落到 \(s=0\) 这条线上， 误差就按 \(\dot{e} = -\lambda e\) 指数衰减到零 —— \(s=0\) 是一条「一进去就安全」的滑行轨道。

    于是控制任务被拆成两步：① 设计 \(s\)（决定误差怎么衰减）；② 用力把状态「推」到 \(s=0\) 上并留住。

    2.2 到达条件与抖振¶

    第二步靠一个切换项：\(s\) 为正就用力推过去，\(s\) 为负就反过来。 代入本页的模型，可以解出滑动变量自己的动力学：

    \[ \dot{s} = -\eta\,\operatorname{sign}(s) + \frac{d}{J} \]

    读这个式子：只要切换强度 \(\eta\) 大于扰动的界 \(|d|/J\)，第一项就永远「盖过」扰动项， \(s\) 必然在有限时间内被压到零（这就是到达条件 \(s\dot{s}<0\)）：

    \[ t_{\text{reach}} \le \frac{|s(0)|}{\eta - |d|/J} \]

    这就是滑模最厉害的地方：只要知道扰动有界（不需要知道它多大）， 就能把它彻底压掉 —— 鲁棒性来自「切换」，而不是来自「模型有多准」。

    但代价立刻来了：\(\operatorname{sign}(s)\) 在 \(s=0\) 处跳变。 理想情况下切换频率无穷大，实际系统采样有限，于是状态在滑模面两侧来回穿越 —— 这就是抖振（chattering）：控制量每步都在抖，会激发高频谐振、磨损执行器。

    2.3 边界层：用一点精度换掉抖振¶

    工程上最常用的一招是边界层：把不连续的 \(\operatorname{sign}(s)\) 换成连续的饱和函数

    \[ \operatorname{sat}\!\left(\frac{s}{\Phi}\right) = \begin{cases} s/\Phi, & |s| \le \Phi\\ \operatorname{sign}(s), & |s| > \Phi \end{cases} \]

    在 \(|s| \le \Phi\) 的「层」内控制量连续变化，抖振被平滑掉。 但代价是精度：层内不再有无限增益压误差，稳态误差不再归零，而是

    \[ s \to \frac{\Phi\,d}{J\eta}, \qquad e \to \frac{s}{\lambda} = \frac{\Phi\,d}{J\eta\lambda} \]

    换句话说：\(\Phi\) 越小越精确、越抖；越大越平滑、越粗糙 —— 这是在「精度」和「执行器寿命」之间拧的一个旋钮。

    滑模为什么能「不靠模型」抗扰动

    因为它不问「扰动有多大」，只问「扰动有界吗」。 只要 \(\eta\) 比扰动界大，切换项就永远盖过扰动 —— 这是一种「用蛮力建立确定性」的思路：把不确定性挤进切换频率里，平均掉。 代价也正是从这来的：切换频率不可能是无限的，挤不掉的那部分就是抖振。

"""第12章 代码1：滑模变结构控制 —— 与 PD 对比，扰动抑制 vs 抖振。"""
import numpy as np

J, b = 0.5, 0.2            # 转动惯量、黏性阻尼（控制器已知）
thd = 1.0                  # 目标角度（定点调节）
d = 0.5                    # 恒定扰动（未建模的负载/摩擦）
dt, T = 1e-3, 4.0
n = int(T / dt)


def sat(v, phi):
    return np.clip(v / phi, -1.0, 1.0)


def run(mode, Kp=40.0, Kd=8.0, lam=10.0, eta=10.0, phi=0.05):
    th, om = 0.0, 0.0
    taus = []
    for k in range(n):
        e = thd - th
        de = -om                       # e 的导数 = -θ̇
        s = de + lam * e               # 滑模面 s = ė + λe
        if mode == "pd":
            tau = Kp * e - Kd * om
        elif mode == "smc":

        acc = (tau - b * om - d) / J
        om += dt * acc
        th += dt * om
        taus.append(tau)
    taus = np.array(taus)
    return abs(thd - th), np.mean(np.abs(np.diff(taus[int(0.5 * n):])))

    三、自适应控制：一边干、一边学¶

    3.1 参数未知怎么办：在线估计¶

    滑模把扰动当成「有界的黑箱」压掉；自适应控制更进一步：它想「知道」那个黑箱。

    以最简单的一维对象为例：\(m\ddot{x} = u\)，真实质量 \(m\) 控制器不知道。 既然不知道，就边控边估：设一个估计值 \(\hat{m}(t)\)，用它去做力矩前馈：

    \[ u = \hat{m}\,a - k_d\,s, \qquad a = \ddot{x}_d - \lambda \dot{e},\qquad s = \dot{e} + \lambda e \]

    这就像一个「会自己调参数的 PD」：\(a\) 是「期望的加速度类信号」，\(\hat{m}\) 把它换算成力矩 —— 前馈；\(s\) 项负责纠偏 —— 反馈。

    3.2 自适应律从哪来：Lyapunov 直接法¶

    问题只剩一个：\(\hat{m}\) 该怎么更新？ 答案是逼着它让「能量」下降。 取 Lyapunov 函数（\(s\) 项是误差能量，\(\tilde{m} = m - \hat{m}\) 是参数误差）：

    \[ V = \tfrac{1}{2} m s^2 + \frac{1}{2\gamma}\tilde{m}^2 \]

    对它求导并代入误差方程（推导见例题 2），只要取

    \[ \boxed{\ \dot{\hat{m}} = -\gamma\,s\,a\ } \]

    就有 \(\dot{V} = -k_d s^2 \le 0\) —— 误差能量单调不增，\(s\to0\)、\(e\to0\) 得到保证。 注意这个律长什么样：\(\dot{\hat{m}} \propto -s\,a\) —— 「滑模面上的偏差」乘上「前馈信号」，就构成了参数的更新方向。

    这里面藏着自适应的两个命门：

    · 需要「持续激励」 —— 如果 \(a\equiv0\)（机器人不动），乘出来恒为零，\(\hat{m}\) 学不到任何东西； · 只保证 \(e\to0\)，不保证 \(\hat{m}\to m\) —— 除非激励足够丰富，否则只保证「够用」，不保证「认对」。

    本页代码为了让估计收敛到真值，特意把期望轨迹做成两个频率叠加的正弦。

"""第12章 代码2：自适应控制 —— 未知负载质量，在线估计并跟踪。"""
import numpy as np

m = 2.0                    # 真实质量（控制器不知道）
dt, T = 1e-3, 8.0
n = int(T / dt)
lam, kd, gamma = 5.0, 10.0, 20.0


def xd(t):    return 0.2 * np.sin(2 * t) + 0.05 * np.sin(5 * t)
def dxd(t):   return 0.4 * np.cos(2 * t) + 0.25 * np.cos(5 * t)
def ddxd(t):  return -0.8 * np.sin(2 * t) - 1.25 * np.sin(5 * t)


def run(mode, mh0=0.5):
    x, v, mh = 0.0, 0.0, mh0        # 初始估计 m̂0=0.5，真值 2.0
    errs = []
    for k in range(n):
        t = k * dt
        e = x - xd(t)
        de = v - dxd(t)
        s = de + lam * e              # 滑模面（误差坐标）
        a = ddxd(t) - lam * de        # 「期望加速度」类信号
        u = mh * a - kd * s           # 用当前估计 m̂ 做前馈 + 反馈
        if mode == "adapt":
            mh += -gamma * s * a * dt # 自适应律 ṁ̂ = -γ s a
            mh = max(0.0, mh)
        v += dt * u / m
        x += dt * v
        errs.append(abs(e))
    errs = np.array(errs)
    return mh, errs[int(0.5 * n):].mean(), errs.max()

"""第12章 代码3：模糊控制 —— 5×5 规则表 → 控制面，以及与线性 PD 的对比。"""
import numpy as np

C = np.array([-1.0, -0.5, 0.0, 0.5, 1.0])       # 语言值：NB NS ZE PS PB
RULE = np.array([                                # 行 = 误差 e，列 = 误差变化率 ė
    [-1.0, -1.0, -1.0, -0.5, 0.0],
    [-1.0, -1.0, -0.5, 0.0, 0.5],
    [-1.0, -0.5, 0.0, 0.5, 1.0],
    [-0.5, 0.0, 0.5, 1.0, 1.0],
    [0.0, 0.5, 1.0, 1.0, 1.0],
])                                               # 每条规则的输出（单点值）


def memb(v):                                     # 三角形隶属度（5 个语言值）
    v = np.clip(v, -1.0, 1.0)
    return np.maximum(0.0, 1.0 - np.abs(v - C) / 0.5)


def fuzzy(e_n, de_n):                            # 模糊化 → 推理（min）→ 解模糊（加权平均）
    w = np.minimum.outer(memb(e_n), memb(de_n))
    return (w * RULE).sum() / (w.sum() + 1e-12)


Ke, Kde, Ku = 1.0, 4.0, 30.0                      # 归一化增益、输出增益
h = 1e-4                                          # 数值微分求「小信号增益」
ge = (fuzzy(h, 0.0) - fuzzy(-h, 0.0)) / (2 * h)
gd = (fuzzy(0.0, h) - fuzzy(0.0, -h)) / (2 * h)
Kp_eq, Kd_eq = Ku * ge / Ke, Ku * gd / Kde        # 等价线性 PD 的增益

print("模糊 PD：5×5 规则表 → 控制面，Ku=%.0f（e 除以 %.1f、ė 除以 %.1f 归一化）"
      % (Ku, Ke, Kde))
print("控制面的小信号增益 df/de=%.4f, df/dė=%.4f → 等价线性 PD：Kp=%.1f, Kd=%.1f"
      % (ge, gd, Kp_eq, Kd_eq))
print()

    4.2 神经网络控制：把未知的非线性「学」出来¶

    如果说模糊是「把人的经验装进去」，神经网络就是「让机器自己长出经验」。

    RBF（径向基函数）网络是最常用的一种：它用一族高斯基函数去拼出任意连续函数：

    \[ \hat{f}(\boldsymbol{z}) = \boldsymbol{W}^{\mathsf T}\boldsymbol{h}(\boldsymbol{z}), \qquad h_i(\boldsymbol{z}) = \exp\!\left(-\frac{\|\boldsymbol{z}-\boldsymbol{c}_i\|^2}{2\sigma^2}\right) \]

    · \(\boldsymbol{c}_i\)：第 \(i\) 个基函数的中心（铺在输入空间的一张网格上）； · \(\boldsymbol{W}\)：权值 —— 也就是要被学习的东西； · 万能逼近定理保证：只要中心够密、数量够多，\(\hat{f}\) 能任意逼近任何连续函数。

    抹平「未知」的办法因此特别直接：把动力学写成 \(\ddot{x} = f(x,\dot{x}) + u\)， \(f\) 未知没关系 —— 用网络去估计它，然后在控制里减掉：

    \[ u = -\hat{f} + \ddot{x}_d - \lambda\dot{e} - k_d s, \qquad \dot{\boldsymbol{W}} = \gamma\,s\,\boldsymbol{h} \]

    这就是「在线学习」：跟踪得好（\(s\) 小），权值就不怎么动；一有偏差（\(s\neq0\)）， 权值就顺着基函数的方向调整，把 \(f\) 补得更准 —— 控制器一边干活、一边把模型「长」出来。

import numpy as np

nm, sig = 7, 0.6                                   # 每维 7 个中心、宽度 0.6
cc = np.linspace(-1.6, 1.6, nm)
cen = np.array([[a, b] for a in cc for b in cc])   # 7×7 = 49 个 RBF 中心


def hfun(z):
    return np.exp(-np.sum((z - cen) ** 2, axis=1) / (2 * sig ** 2))


def ftrue(x, v):                                   # 真实但未知的非线性
    return -3.0 * x - 4.0 * x ** 3 - 1.5 * v


def xd(t):    return 0.6 * np.sin(1.2 * t)
def dxd(t):   return 0.72 * np.cos(1.2 * t)
def ddxd(t):  return -0.864 * np.sin(1.2 * t)


lam, kd, gamma = 10.0, 15.0, 100.0
dt, T = 1e-3, 10.0
n = int(T / dt)


def run(mode):
    x, v, W = 0.0, 0.0, np.zeros(len(cen))
    errs, ferr = [], []
    for k in range(n):
        t = k * dt
        e, de = x - xd(t), v - dxd(t)
        s = de + lam * e                           # 滑模面（误差坐标）
        h = hfun(np.array([x, v]))
        fh = W @ h                                 # 当前网络输出 = 对 f 的估计
        u = ddxd(t) - lam * de - kd * s            # 反馈部分
        if mode == "rbf":
            u = u - fh                             # 减去网络估计 → 前馈补偿
            W = W + dt * gamma * s * h             # 自适应律 Ŵ̇ = γ s h
        xp, vp = x, v
        v += dt * (ftrue(xp, vp) + u)              # 被控对象 ẍ = f(x, ẋ) + u
        x += dt * v
        errs.append(abs(e))
        ferr.append(abs(fh - ftrue(x, v)))
    errs, ferr = np.array(errs), np.array(ferr)
    half = int(0.5 * n)
    return errs[half:].mean(), errs.max(), ferr[half:].max()

print("跟踪 x_d(t)=0.6sin(1.2t)；RBF 网络 7×7=49 个中心，自适应律 Ŵ̇ = γ s h（γ=%.0f）"
      % gamma)
print()
print("控制器                后半段平均|e|(m)    最大|e|(m)    逼近误差 max|f̂-f|")
for mode, label in [("pd", "纯 PD（无补偿）"),
                    ("rbf", "RBF 神经网络补偿")]:
    mae, me, fe = run(mode)

    · 模糊：知识来自人 —— 规则表是人写的，可读、可解释，但不会自己变好； · 神经网络：知识来自数据与在线学习 —— 权值是自己调出来的，能力强，但是黑箱。 一个把人的经验翻译给机器，一个让机器自己长经验 —— 于是工程上干脆两个都要：用模糊给神经网络提供结构与初值，用神经网络去调模糊的规则和隶属度。

    例题 1：滑模的到达条件与到达时间¶

    关节模型 \(J\ddot{\theta} = \tau - b\dot{\theta} - d\)，误差 \(e = \theta_d - \theta\)， 滑模面 \(s = \dot{e} + \lambda e\)，控制律 \(\tau = b\dot{\theta} + J(\lambda\dot{e} + \eta\operatorname{sign}(s))\)。 求 \(\dot{s}\) 的表达式，给出到达条件，并求到达时间的上界。

    解答

    第一步：写出 \(\dot{s}\)。 由 \(e = \theta_d - \theta\)（\(\theta_d\) 为常数）得 \(\dot{e} = -\dot{\theta}\)、\(\ddot{e} = -\ddot{\theta}\)，于是

    \[ \dot{s} = \ddot{e} + \lambda\dot{e} = -\ddot{\theta} + \lambda\dot{e} \]

    第二步：把控制律代进模型。 由 \(J\ddot{\theta} = \tau - b\dot{\theta} - d\)：

    \[ \ddot{\theta} = \frac{\tau - b\dot{\theta} - d}{J} = \frac{J(\lambda\dot{e} + \eta\operatorname{sign}(s)) - d}{J} = \lambda\dot{e} + \eta\operatorname{sign}(s) - \frac{d}{J} \]

    代回 \(\dot{s}\)，\(\lambda\dot{e}\) 正好消掉：

    \[ \boxed{\ \dot{s} = -\eta\operatorname{sign}(s) + \frac{d}{J}\ } \]

    第三步：到达条件。 要保证 \(s\) 被推向零，需要 \(s\dot{s} < 0\)。 当 \(s\) 为正时，\(\dot{s} = -\eta + d/J\)，要它小于零就需要

    \[ \eta > \frac{d}{J} \]

    \(s\) 为负时同理。所以到达条件是「切换强度 \(\eta\) 大于扰动的界 \(d/J\)」 —— 注意：只需要知道扰动 \(d\) 的「界」，不需要知道它的精确值。

    第四步：到达时间。 以 \(s\) 为正为例，\(\dot{s} = -(\eta - d/J)\) 是常数， 于是 \(s\) 从 \(s(0)\) 线性降到零：

    \[ t_{\text{reach}} \le \frac{|s(0)|}{\eta - |d|/J} \]

    本页代码：\(s(0) = \lambda e(0) = 10\times1 = 10\)，\(\eta = 10\)，\(|d|/J = 0.5/0.5 = 1\)， 于是 \(t_{\text{reach}} \le 10/9 \approx 1.1\) s —— 与仿真中「约 1.1 s 后进入滑动阶段」吻合。

    一句话：滑模把「抗扰动」变成了一道只与「界」有关的算术题； 代价是那个切换本身，于是必须再用边界层把抖振收回来。

    例题 2：自适应律为什么取 \(\dot{\hat{m}} = -\gamma s a\)¶

    对象 \(m\ddot{x} = u\)，控制 \(u = \hat{m}a - k_d s\)（\(a = \ddot{x}_d - \lambda\dot{e}\)，\(s = \dot{e} + \lambda e\)）。 取 \(V = \frac{1}{2}ms^2 + \frac{1}{2\gamma}\tilde{m}^2\)（\(\tilde{m} = m - \hat{m}\)）， 证明该自适应律使 \(\dot{V} \le 0\)。

    解答

    第一步：先写 \(s\) 的动力学。 由 \(\ddot{e} = \ddot{x} - \ddot{x}_d\)、\(s = \dot{e}+\lambda e\)：

    \[ \dot{s} = \ddot{e} + \lambda\dot{e} = (\ddot{x} - \ddot{x}_d) + \lambda\dot{e} \]

    代入 \(m\ddot{x} = u = \hat{m}a - k_d s\)，并用 \(a = \ddot{x}_d - \lambda\dot{e}\) 化简：

    \[ \dot{s} = \frac{\hat{m}a - k_d s - m\ddot{x}_d}{m} + \lambda\dot{e} = \frac{\hat{m}a - k_d s - m(\ddot{x}_d - \lambda\dot{e})}{m} = \frac{-\tilde{m}a - k_d s}{m} \]

    整理得关键的误差方程：

    \[ m\dot{s} = -\tilde{m}\,a - k_d s \]

    第二步：对 \(V\) 求导。 注意 \(\dot{\tilde{m}} = -\dot{\hat{m}}\)：

    \[ \dot{V} = m s\dot{s} + \frac{1}{\gamma}\tilde{m}\dot{\tilde{m}} = s(-\tilde{m}a - k_d s) - \frac{1}{\gamma}\tilde{m}\,\dot{\hat{m}} = -k_d s^2 + \tilde{m}\left(-sa - \frac{\dot{\hat{m}}}{\gamma}\right) \]

    第三步：令那个讨厌的交叉项消失。 只要取

    \[ \dot{\hat{m}} = -\gamma\,s\,a \]

    括号里就恒为零，于是

    \[ \dot{V} = -k_d s^2 \le 0 \]

    第四步：这说明什么。 \(V\) 有下界、\(\dot{V}\le0\)，故 \(V\) 收敛、 \(s\) 平方可积；再由 Barbalat 引理可得 \(s\to0\)，进而 \(e\to0\)。 但注意两条「但书」：

    · 若 \(a\equiv0\)（轨迹不动），则 \(\dot{\hat{m}}\equiv0\) —— 参数学不到（需要持续激励）； · \(\dot V\le0\) 只保证 \(s\to0\)，不保证 \(\tilde{m}\to0\) —— 参数收敛到真值还需要激励足够丰富。本页代码用双频正弦轨迹满足这一点， 所以 \(\hat{m}\) 才能从 \(0.5\) 爬到 \(1.997\)。

    一句话：自适应律不是拍脑袋来的，它是「让 Lyapunov 函数里那个交叉项消失」解出来的 —— 这就是 Lyapunov 直接法的用法。

    例题 3：模糊 PD 为什么和线性 PD「打平」¶

    本页代码里，模糊 PD 的控制面在原点附近的小信号增益为 \(1\)， 据此配出等价线性 PD（\(K_p=30,\ K_d=7.5\)）。实跑显示两者超调几乎相同（\(5.05\%\) vs \(4.43\%\)）。 解释这个结果，并说明模糊控制真正的价值在哪里。

    解答

    第一步：为什么「打平」。 模糊控制器在原点附近是线性的： \(25\) 条规则里起主导的是 \(e\)、\(\dot{e}\) 都接近零的那几条， 这些规则的输出与输入近似成正比 —— 所以小信号增益等于 \(1\)， 控制器在这一区域的等效行为就是一个 PD。

    既然阶跃响应的关键段（接近目标、偏差很小）正好落在这个线性区里， 它自然给出与等价线性 PD 几乎一样的超调与调节时间。这不奇怪，这是必然。

    第二步：那差别在哪？ 在大偏差处。看控制面：\(|u|\le 30\) 恒成立； 而线性 PD 的 \(u = 30e + 7.5\dot{e}\) 在 \(e=1,\ \dot{e}=-1\) 时给出 \(22.5\)， 在 \(e=1,\ \dot{e}=1\) 时给出 \(37.5\) —— 会一直往上冲。 模糊的价值，是「非线性 + 有界」这一条，而不是「精度更高」。

    第三步：那它凭什么被用？ 三条实在的理由：

    · 不需要模型 —— 规则表里没有一个物理参数，换个对象照样能跑； · 可读、可改 —— 「快到站要收力」这条经验，改一行表就能体现，调试者看得懂； · 输出有界 —— 天然保护执行器，不需要额外限幅。

    代价也要说清：规则数随输入维数指数增长（维数灾难）； 传统模糊控制不会自己变好（没有学习能力）； 性能高度依赖规则表设计得好不好。

    一句话：模糊控制是一种「表达方式」，不是一种「性能加成」—— 它把专家的手感写成表格，代价是它不会自己进步。

    例题 4：RBF 补偿为什么能降低误差¶

    第 4 节的代码里，纯 PD 的平均跟踪误差为 \(1.12\times10^{-2}\) m， RBF 补偿后降到 \(9.15\times10^{-4}\) m，同时逼近误差从 \(2.67\) 降到 \(0.248\)。 说明这两件事之间的因果关系。

    解答

    第一步：误差从哪来。 控制律 \(u = -\hat{f} + \ddot{x}_d - \lambda\dot{e} - k_d s\) 作用在 \(\ddot{x} = f + u\) 上，得误差方程

    \[ \dot{s} = \left(f - \hat{f}\right) - k_d s = \tilde{f} - k_d s \]

    纯 PD 时 \(\hat{f}\equiv0\)，于是 \(\tilde{f} = f\)（幅值最大约 \(2.67\)）—— 稳态下 \(s \to f/k_d\)，跟踪误差 \(e \approx f/(k_d\lambda)\)。 这就是纯 PD 那 \(1.12\times10^{-2}\) m 的来源：它把整个未知的 \(f\) 都当成扰动硬扛。

    第二步：网络做了什么。 自适应律 \(\dot{\boldsymbol{W}} = \gamma s\boldsymbol{h}\) 不断调整权值，使 \(\hat{f}\to f\)，于是 \(\tilde{f}\) 越来越小 —— 实跑中从 \(2.67\) 降到 \(0.248\)（降了一个数量级）。 代回误差方程：\(\tilde{f}\) 变小多少，\(s\) 的稳态偏差就同比例变小多少 —— 这就是跟踪误差从 \(1.12\times10^{-2}\) 降到 \(9.15\times10^{-4}\)（约 \(12\) 倍）的直接原因。

    第三步：为什么不能「完全消除」。 网络能力有限（\(49\) 个中心、宽度固定）， \(\tilde{f}\) 只能降到 \(0.248\) 而非零。残余误差正比于逼近误差 —— 想让误差再小，就得加中心、调宽度、改进网络结构。 这是所有「学习型控制」的共同宿命：控制的精度上限，就是学习的精度上限。

    一句话：RBF 补偿把误差的源头（未知的 \(f\)）从「扰动」变成了「可学习的量」—— 误差降下来的倍数，正好对应网络逼近 \(f\) 的精度提升倍数。

    自测¶

    Q1 滑模控制的「抖振」是怎么产生的？为什么说它是「滑模天生的」？有哪些抑制手段？

    提示

    想：理想滑模要求切换频率多高？实际系统的采样周期又是多少？

    解答

    产生原因：滑模要求状态始终停在 \(s=0\) 上，这需要无穷高的切换频率 （\(s\) 刚穿过零点，立刻反向切换）。但实际系统有采样周期、执行器带宽、时延， 切换只能以有限频率发生 —— 于是状态在滑模面两侧来回穿越， 控制量每步都在正负之间跳，这就是抖振。 它是「有限切换频率」与「理想滑模要求」之间的固有矛盾，所以说是天生的。

    抑制手段（按常用度）：

    · 边界层（饱和函数 sat） —— 最常用：层内连续化，抖振消除，代价是精度 （本页实跑：抖振 \(9.05 \to 0\)，误差 \(0.00015 \to 0.00050\)）； · 高阶滑模（如 super-twisting）：把不连续作用放到控制量的导数上，兼顾精度与平滑； · 低通滤波控制量、用观测器估计扰动（把切换项换成扰动的连续估计）； · 降低切换增益：\(\eta\) 只需略大于扰动界，越大抖得越凶。

    一句话：抖振是「用有限频率执行无限频率指令」的必然产物； 工程上不追求彻底消除，而是用边界层把它换成一个可接受的精度代价。

    Q2 自适应控制能解决什么问题？它的两个「命门」（持续激励、未建模动态）分别意味着什么？

    提示

    回到自适应律 \(\dot{\hat{m}} = -\gamma sa\)：如果 \(a\) 恒为零会怎样？如果对象里还有你没建模的柔性呢？

    解答

    能解决的：参数不确定 —— 结构已知、数值未知（如负载质量、惯量、摩擦系数）， 可以用在线估计把它们学出来，从而用准前馈 （本页实跑：\(\hat{m}\) 从 \(0.5\) 收敛到 \(1.997\)，误差降约 \(218\) 倍）。

    命门一：持续激励（PE）。自适应律 \(\dot{\hat{m}} = -\gamma s a\) 里， 若 \(a\equiv0\)（机器人不动，或走匀速），更新量恒为零 —— 参数学不到。 更一般地，输入信号必须「足够丰富」（覆盖足够的频率），否则只能保证「误差收敛」， 不保证「参数收敛到真值」。

    命门二：未建模动态。自适应律是基于假定结构正确推导出来的。 若真实对象里还有没建模的部分（柔性、间隙、时延），参数可能被错误地归因到已知参数上， 导致估计漂移，严重时会失稳。工程上常用死区、参数投影、σ-修正等手段兜底， 或把自适应与滑模/鲁棒控制组合（用鲁棒项吸收未建模部分）。

    一句话：自适应擅长「学参数」，不擅长「学结构」—— 它需要足够的激励，也害怕你没告诉它的那些东西。

    Q3 模糊控制和神经网络控制，知识分别从哪来？各自的优、缺点是什么？

    提示

    一边是「专家写规则」，一边是「机器调权值」。各自最怕什么？

    解答
    模糊控制 神经网络控制
    知识来源 专家经验（人写规则表） 数据 / 在线学习（权值自己调）
    优点 无需模型、规则可读可改、输出有界 逼近能力极强（万能逼近）、可在线学习
    缺点 规则数指数增长、不会自己变好 黑箱、需要数据与激励、稳定性分析难
    最怕什么 规则表设计得不好 没有足够的训练信号（激励）

    模糊：把「手感」翻译成规则，可解释是它最大的资产； 但输入一多规则就爆炸，而且性能完全取决于规则设计者。 神经网络：把「函数」学进权值里，能力强是它最大的资产； 但不知道它到底学了什么，而且没有激励就学不到东西。

    工程上的组合：用模糊给出结构与先验（隶属度、规则骨架）， 用神经网络在线调整这些参数（模糊神经网络 / 神经模糊控制）—— 既有可解释性，又有学习能力。

    一句话：模糊是「把人的经验翻译给机器」，神经网络是「让机器自己长经验」； 前者可读但不能学，后者能学但不可读。

    Q4 面对一个具体的控制任务，五类方法（PID / 滑模 / 自适应 / 模糊 / 神经网络）该怎么选？

    提示

    先问三个问题：模型准不准？不确定性是什么性质？能不能接受它的代价？

    解答

    选型靠三个问题：

    ① 模型准不准？ 准 → PID / 基于模型的控制（计算力矩） 就够，别上复杂方法； 不准、但知道界 → 滑模；不准、但知道结构 → 自适应； 完全不懂、只有经验 → 模糊；完全不懂、但有数据 → 神经网络。

    ② 不确定性的性质是什么？ 外部扰动 / 匹配扰动 → 滑模（本页：\(\eta\) 大于 \(\lvert d\rvert/J\) 就能压掉）； 参数漂移（负载变、摩擦变） → 自适应（本页：\(\hat m\) 在线收敛）； 强非线性、无模型 → 模糊 / 神经网络。

    ③ 能不能接受它的代价？ 滑模 → 抖振（可加边界层，牺牲精度）； 自适应 → 需要激励、怕未建模动态； 模糊 → 规则要人写、维数灾难； 神经网络 → 需要数据、黑箱、稳定性最难证。

    工程现实：它们几乎从不单用。常见组合： 计算力矩 + PID（基于模型的标配）、自适应 + 滑模（学参数 + 抗残差）、 模糊 + 神经网络（结构 + 学习）、智能补偿 + PID（智能负责精度、PID 保局部稳定）。 判断标准永远是那句话：哪种方法能用最少的代价，把当前这个「不准」按下去。

    一句话：没有「最好的方法」，只有「和这个不确定性最匹配的方法」—— 选型的本质，是先看清「不准」到底是哪一种。

    小结¶

    要记住的 为什么重要
    三类「不准」：参数不确定 / 未建模动态 / 外部扰动 所有高级方法都在对付它们
    PID 只靠反馈，增益受稳定性限制 纯反馈在「模型不准」时天然劣势
    滑模面 \(s = \dot{e} + \lambda e = 0\)：误差指数衰减的「轨道」 滑模的全部设计都在这条线上
    到达条件 \(s\dot{s}\) 为负，只需 \(\eta\) 大于 \(\lvert d\rvert/J\) 抗扰动只需知道「界」，不必知道「值」
    抖振来自有限切换频率 实跑：sign 版抖振指标 \(9.0473\)
    边界层 \(\operatorname{sat}(s/\Phi)\)：平滑换精度，\(e\approx\Phi d/(J\eta\lambda)\) 实跑：抖振 \(9.05\to0\)，误差 \(0.00015\to0.00050\)
    自适应：\(\dot{\hat{m}} = -\gamma s a\)，由 Lyapunov 直接法解出 实跑：\(\hat{m}\) 从 \(0.5\) 收敛到 \(1.997\)（真值 \(2.0\)）
    自适应的两个命门：持续激励、未建模动态 不动就学不到；学错了可能失稳
    模糊控制三步：模糊化 → 规则推理 → 解模糊 无需模型、规则可读、输出有界
    模糊 PD 与等价线性 PD 几乎持平（\(5.05\%\) vs \(4.43\%\)） 模糊不等于更强，它是一种表达方式
    RBF 网络：\(\hat{f} = \boldsymbol{W}^{\mathsf T}\boldsymbol{h}(\boldsymbol{z})\)，\(\dot{\boldsymbol{W}} = \gamma s\boldsymbol{h}\) 在线把未知的 \(f\) 学出来
    学习型控制的精度上限 = 学习的精度上限 实跑：逼近误差 \(2.67\to0.248\)，跟踪误差随之降 \(12\) 倍
    没有最好的方法，只有最匹配的方法 先看清「不准」是哪一种，再选武器

    四条最容易出错的地方：

    1. 以为「滑模没有代价」 —— 抖振会激发高频谐振、加快执行器磨损，必须用边界层或高阶滑模处理
    2. 把自适应当成「万能估计器」 —— 它需要持续激励才能学到参数，且只对「结构已知」的情形有效，未建模动态会让它失稳
    3. 迷信「模糊 / 神经网络一定更强」 —— 本页实跑已证：模糊 PD 与等价线性 PD 几乎打平；智能方法的价值在「无需模型 / 可学习」，不在自动更优
    4. 在模型够准时硬上高级方法 —— 方法越复杂，参数越多、稳定性越难证、调试越贵；能用 PID 解决的，别上滑模
