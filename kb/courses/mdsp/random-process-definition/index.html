    随机信号与随机过程的定义¶

    这一页只解决一个问题：把「随机信号」这件事在数学上说清楚。

    在传统的信号分析里，我们默认手上的信号是一个确定的函数： 给一个时刻，就有一个确定的数，而且这个数可以用式子写出来。 可是真实世界的信号几乎都带噪声 —— 语音、雷达回波、通信信号、生物电信号， 我们拿到的从来不是一个「干净的确定函数」， 而是一个按某种概率规律产生的东西。

    于是整个学科发生了转向。本课程课件在概述里把这个转向总结成三条演进线索， 而转向之后要做的第一件事，就是给「随机信号」一个数学定义。

    这件事看着简单，其实有三个特别容易混的地方：

    看起来差不多的说法 实际差别 后果
    「随机信号就是没有规律的信号」 随机说的是不可精确预测，不是无规律 会以为随机信号根本没法分析，直接放弃
    「我测到的那条曲线就是随机过程」 一条曲线只是随机过程的一次实现 会拿一条曲线去算「过程的均值」，算出来的是另一个东西
    「过程的均值就是这条曲线的平均」 过程的均值是系综平均，要对很多次实验平均 后面的自相关、功率谱会一路推错

    这一页的主线

    整页只回答一句话：随机过程是「一族随机变量」，不是一个随机变量。

    抓住这一点，下面三个视角就都通了： 固定时刻 → 得到一个随机变量； 固定一次实验 → 得到一条确定性曲线； 两者都固定 → 得到一个数。

    至于「平稳」「遍历」这些更强的假设，属于下一页的内容， 本页只把它们列为分类维度，不展开。

    一、为什么现代信号处理要用随机信号建模¶

    1.1 本课程课件给出的三条演进线索¶

    本课程课件在开篇概述里，用三行字概括了现代数字信号处理的走向。 这三行看起来像口号，其实是三条互相独立的演进线：

    1. 确定性信号 → 随机信号。
    2. 平稳信号处理 → 非平稳信号处理。
    3. 时域 → 频域 → 时频分析。

    这三条线索分别回答三个不同的问题，不要把它们当成一回事：

    线索 从什么 到什么 为什么会发生这个演进
    线索一：分析对象 确定性信号 随机信号 真实信号几乎都带噪声，「确定性」只是一个理想化假设
    线索二：统计特性 平稳信号处理 非平稳信号处理 语音、雷达、生物电的统计特性都随时间变化，不能一律当平稳
    线索三：分析视角 时域、频域 时频分析 傅里叶变换把时间信息换掉了，非平稳信号需要同时看时间和频率

    读这张表要抓住三个「为什么」的性质是不同的：

    • 线索一是关于「对象」的。信号本身是不是一个确定函数？答案是「理想的模型里是，真实世界里不是」。 这不是技术升级，而是研究对象换了。
    • 线索二是关于「假设」的。同一个随机信号，如果它的统计特性不随时间变化（平稳）， 分析工具就简单得多；一旦这个假设不成立（非平稳），整个方法论都要换。
    • 线索三是关于「视角」的。从时域走到频域，是换一种坐标看同一个信号； 从频域再走到时频分析，是因为频域描述丢掉了时间信息， 当信号的频率成分本身在变化时，只看全局频谱就不够了。

    三条线索合起来说的一件事是： 随机性是常态，平稳性是需要检验的假设，而时频分析是处理「统计特性还在变」的工具。

    1.2 为什么会演进：四条互相独立的理由¶

    既然「确定性信号」的定义那么干净，为什么还要转向随机信号？

    第一，真实世界的信号几乎都带噪声。 任何一次实际测量得到的都是被噪声污染过的结果， 而你无法列出噪声的显式表达式 —— 因为噪声本身就是随机的。

    第二，确定性只是一个理想化假设。 在建模时假定信号确定、噪声确定， 数学上很好处理；但一旦要回答「这个估计准不准」「这个滤波器的性能有多好」， 就必须把随机性正式地写进模型里。

    第三，只有分布才能完整描述随机性。 这是第二层的意义： 想知道「下一个值落在某个区间的概率是多大」， 唯一严格的说法就是从联合分布里算出来，任何二阶量都给不出这个答案。

    第四，只有数字特征才能在有限数据上真的算出来。 这是第三层的意义： 我们手上的数据永远是一条有限长的记录， 而均值、方差、自相关都能用求和的形式估计出来，并且它们随样本量收敛。

    第三和第四条看起来矛盾，其实正好说明了为什么工程上必须走 「第二层定性、第三层定量」这条路。

    别把理想化假设当成事实

    确定性信号的定义本身没有错，错的是无条件地用它。

    把观测当确定性信号来建模，等于默认「一切都能精确重现、精确预测」。 这个假设在理想模型里成立，在真实信号上几乎总是不成立。

    更危险的是：它不会报错。你照样能算出结果、画出曲线， 只是这个结果没有精度可言 —— 因为整个推导里根本没有一个地方回答「误差有多大」。

    用四层描述的话说：确定性模型直接停在「第一层」， 拿一条观测曲线当成了整个母体，于是第二层和第三层提供的 「这次建模有多可靠」这条信息被整块丢掉了。

    丢掉的信息是可以量化的。看一个手算就能做尽的例子： 设真正的规律是一条严格的线性下降 \(m_n = 1.0 - 0.1n\)（\(n = 1, 2, \dots, 8\)）， 而你的观测是它叠上一段零均值噪声：

    \[y_n = m_n + \varepsilon_n\]

    这里 \(\varepsilon_n\) 满足 \(\mathbb{E}[\varepsilon_n] = 0\)、\(\mathrm{Var}[\varepsilon_n] = \sigma^{2}\)。

    如果你只报出确定性模型 \(m_n\)，那么第 \(n\) 点的误差就是 \(\varepsilon_n\) 本身。 误差不能预测（第一层失效）， 但它有确定的统计规律：零均值、方差 \(\sigma^{2}\)（第三层有效）。

    二、确定性信号与随机信号¶

    2.1 课件给出的两个定义¶

    本课程课件在「确定性信号和随机信号」这一节里，用了两句话把两者分开。

    确定性信号（也叫可预测信号）：

    根据一定的起始条件或若干过去及当前的观测，能够用数学和物理模型 来准确预测尚未出现的数据。

    这句话里有两个关键词，缺一不可：

    关键词 含义 少了它会怎样
    起始条件 / 若干过去及当前的观测 预测要有依据 没有依据的「预测」其实是猜，不是确定
    数学和物理模型 依据要能写成显式表达式 只有一张表、没有表达式，就没法外推
    准确预测尚未出现的数据 结论必须精确 只能给出「大约是多少」的，就不是确定性信号

    随机信号：课件用一句话划定了它的范围 —— 通常将非确定性或非可预测的信号称为随机信号。

    也就是说，课件的定义方式是用确定性信号反着定义随机信号： 凡是不能用显式模型精确预测未来值的信号，都归到随机信号这一边。 课件接着用一句更形象的话说明随机过程是什么： 随机过程指随时间推移而演化的随机现象。 注意「随时间推移而演化」这半句 —— 它说明随机信号强调的是一族随时间的观测， 而不是孤立的一个随机数。

    2.2 关键澄清：随机不等于无规律¶

    这是本页最容易被读错的一句话，必须专门说清楚。

    「随机」不等于「无规律」

    「随机」这个词在中文口语里常常等于「乱来、没谱、说不清」， 但在数学语言里它的意思非常窄，只有一条：

    给定过去和现在的观测，不能精确预测未来值。

    它没有说「这个信号没有任何规律」。恰恰相反 —— 随机信号之所以还能被研究，正是因为它有确定的统计规律。

    差别在于「确定什么」：

    • 确定性信号：每一个未来的值都可以确定地写出来；
    • 随机信号：每一个未来的值写不出来， 但它的均值、方差、自相关函数、功率谱可以确定地写出来。

    所以，正确的说法是：

    说法 对不对 说明
    「随机信号没有规律」 ✗ 错 它的取值不可预测，但统计特性完全可以确定描述
    「随机信号的统计规律是确定的」 ✓ 对 均值、方差、自相关、功率谱都是确定的函数
    「随机信号只能给出概率性的结论」 ✓ 对 说的是「取值落在某个区间的概率是多大」

    用一句可操作的话总结： 确定性信号预测「下一个值是多少」，随机信号预测「下一个值的分布是什么」。

    2.3 两类信号的完整对照¶

    把上面的内容整理成一张表，这是本页要记住的第一张表：

    对照项 确定性信号 随机信号
    描述方式 显式的数学 / 物理表达式 统计规律（分布、均值、方差、自相关）
    可预测性 未来值可精确预测 未来值不可精确预测，只能给概率性结论
    信息的完整性 知道表达式 = 知道全部信息 知道统计量 ≠ 知道全部信息，单个取值始终不确定
    典型例子 正弦波、多项式、阶跃信号 语音、雷达回波、热噪声、生物电信号
    分析工具 傅里叶变换、Z 变换、系统函数 随机过程 + 统计估计（在变换之前先做统计建模）

    再把这五行的差别压缩成一句话： 确定性信号的分析对象是「函数」，随机信号的分析对象是「一族函数上的概率分布」。

    2.4 两类信号各举几个例子¶

    本课程课件在讲这个区分时，举了四类典型的随机信号：语音、雷达回波、 热噪声、生物电信号。它们的共同点是：

    信号 为什么它是随机的 随机性来自哪里
    语音 同一句话说两遍，波形永远不会一模一样 说话人的发音细节、语速、口腔状态都在变
    雷达回波 目标的距离、姿态、反射截面积都在变 目标运动 + 传播介质的随机扰动
    热噪声 电子热运动引起的电压起伏，原理上就不可预测 物理层面的微观随机过程
    生物电信号 心电、脑电的波形因人因时而异 生理状态连续变化，且叠加大量自发活动

    而典型的确定性信号则是：

    信号 为什么它是确定的
    正弦波 \(A\cos(\omega t + \varphi)\) 三个参数 \(A, \omega, \varphi\) 一旦给定，任意时刻的值都能算出来
    多项式（比如一条抛物线） 系数给定后，代入任意 \(t\) 都能算出确定的值
    阶跃信号 表达式就是「\(t\) 小于 0 时取 0，\(t\) 大于 0 时取 1」，未来值一目了然

    2.5 手算对照表：确定性模型为什么报不出误差¶

    上一节留下的那个例子可以完全手算，不需要任何程序。 取 \(m_n = 1.0 - 0.1n\) 与 \(y_n = m_n + \varepsilon_n\)，并设噪声标准差 \(\sigma = 0.5\)。 手算三列数：模型值 \(m_n\)、观测值 \(y_n\)、误差 \(e_n = y_n - m_n\)。

    1 \(0.9000\) \(1.0524\) \(+0.1524\) \(0.0232\)
    2 \(0.8000\) \(0.2800\) \(-0.5200\) \(0.2704\)
    3 \(0.7000\) \(1.0752\) \(+0.3752\) \(0.1408\)

    \[\frac{1}{8}\sum_{n=1}^{8} e_n^{2} = \frac{2.0602}{8} \approx 0.2575\]

    于是平均绝对误差约为

    \[\frac{1}{8}\sum_{n=1}^{8}|e_n| = \frac{3.3665}{8} \approx 0.4208\]

    这说明什么：\(0.4208\) 这个数不是「模型参数没调好」， 而是噪声自身的量级。理论上一段标准差为 \(0.5\) 的零均值高斯噪声， 其平均绝对误差的期望是

    \[\sigma\sqrt{\frac{2}{\pi}} \approx 0.5 \times 0.7979 \approx 0.3990\]

    和手算出来的 \(0.4208\) 只差 \(0.02\) 左右，而这个差来自 8 个样本的随机波动。

    问题 确定性模型的回答 第三层（数字特征）的回答

    误差的平均水平 答不出来 均值 \(0\)，标准差 \(0.5\)
    误差会不会很大 答不出来 约 \(68\%\) 落在 \(\pm 0.5\) 内

    注意最后一行：手算的均方误差 \(0.2575\) 与理论值 \(\sigma^{2} = 0.25\) 几乎相等， 偏差 \(0.0075\) 来自只有 8 个样本。 这就是「第三层够用」的具体含义：它不预测取值，但它把「能有多准」说清了。

    三、随机过程的数学定义（本页核心）¶

    3.1 课件给出的写法¶

    本课程课件在「随机过程的数学定义」这一节里，先给了一句直观描述， 再给出正式定义。

    直观描述：随机过程指随时间推移而演化的随机现象。

    正式定义：设 \(T\) 是指标（时间）\(t\) 的集合， 如果对每个 \(t \in T\)，有定义在 \(\Omega\) 上的随机变量 \(X(t)\)， 就称随机变量族

    \[X = \{X(t),\ t \in T\}\]

    为一个随机过程。

    这个定义里只有三个符号，但每一个都必须先弄清楚：

    符号 名字 它是什么 取值范围
    \(T\) 参数集 所有可能时刻构成的集合 常取 \(T = \mathbb{R}\) 或 \(T = \mathbb{Z}\)
    \(t\) 时间指标 从 \(T\) 里取出的一个具体时刻 \(t \in T\)
    \(X(t)\) 时刻 \(t\) 处的随机变量 一个随机变量，不是数 取值由实验结果决定
    \(\Omega\) 样本空间 所有可能实验结果（样本点）的集合 见下一节 3.4

    定义里最容易被忽略的三个字：随机变量族

    定义说的是「一族随机变量」，不是「一个」随机变量。

    这就是随机过程和普通随机变量的唯一区别： 普通随机变量只有一次抽取的机会，而随机过程在每一个时刻都配了一个随机变量， 并且这些随机变量之间通过时间下标串在一起。

    常见错误是把它读成「一个随机变量，只不过随时间变」。 这个读法会直接导致一个后果： 你会以为「随机过程的均值」就是沿时间轴求平均。 但按定义，均值是固定时刻、对所有可能实验结果求平均 —— 这两件事完全不同，下一页讲遍历性时说的就是它们什么时候才相等。

    3.2 怎么理解「一族随机变量」：三个视角¶

    理解这个定义最有效的方法，是分别固定不同的东西，看剩下什么。 一共三种固定方式，得到三种完全不同的对象：

    固定什么 得到什么 数学上是什么 怎么用一句话说
    固定 \(t\) 一个随机变量 \(X(t)\) 随机变量 在某一时刻「横切一刀」，看这一刀上的分布
    固定一次实验（一个样本点 \(\zeta\)） 一条确定性函数 样本函数 / 实现 跟踪「一次实验」从头到尾的整条曲线
    两者都固定 一个数 实数 第 \(\zeta\) 次实验在时刻 \(t\) 的观测值 \(X(t, \zeta)\)

    这张表是本页要记住的核心。三个视角可以用一个日常例子类比： 把「全班同学在某次考试中的成绩」当成一个随机过程。

    • 固定时刻（固定科目）：只看数学成绩，这是一个随机变量 —— 有分布、有均值、有方差。
    • 固定一次实验（固定一个学生）：看这个学生的全部科目成绩，这是一条确定的数据记录。
    • 两者都固定：小明的数学成绩，这就是一个数。

    3.4 第二层：分布函数族¶

    要把「所有实验的信息」都装进去，就必须同时描述一切有限个时刻上的联合分布。

    定义：随机过程 \(X = \{X(t), t \in T\}\) 的分布函数族是

    \[F_X(x_1, x_2, \dots, x_N;\, t_1, t_2, \dots, t_N) = P\big(X(t_1) \le x_1,\ X(t_2) \le x_2,\ \dots,\ X(t_N) \le x_N\big)\]

    对一切 \(N\)、一切 \(t_1 < t_2 < \dots < t_N\)、一切实数 \(x_1, \dots, x_N\) 都成立。

    逐个说清这个式子里的每一部分：

    部分 含义 为什么必须有
    \(N\) 取几个时刻 \(N\) 可以取任意正整数，直至无穷
    \(t_1 < \dots < t_N\) 这 \(N\) 个时刻 可以任意选，所以分布是一个函数族而不是一个函数
    \(x_1, \dots, x_N\) 每个时刻的门限 联合分布的取值是「同时不超过各自门限」的概率
    \(P(\cdot)\) 概率测度 由概率空间保证合法性，见下一章

    注意这一层的两个特点。

    第一，它是完整的。数学上可以证明：只要给定了这一族分布， 随机过程的一切概率性质都被确定了 —— 均值、方差、自相关、 「某个值出现的概率」全部可以从中算出来。

    第二，它是不可计算的。\(N\) 有无穷多种取法，每一种里 \(t_1, \dots, t_N\) 又有无穷多种取法，所以这一族分布有无穷多个成员； 更麻烦的是，我们在实际中拿到的数据是一条有限长的记录， 从一条记录里根本估不出整套联合分布。

    为什么还要保留这一层：因为它给出了「均值、自相关这些量到底从哪来」的答案。 第三层的每一个量，都是这一族分布的一个积分或求和：

    第三层的量 从第二层的哪里来
    均值 \(\mu(t)\) 用 \(N = 1\) 的边缘分布 \(F_X(x; t)\) 求积分
    方差 \(\sigma^{2}(t)\) 同样用 \(N = 1\) 的边缘分布求二次中心矩
    自相关 \(R(t_1, t_2)\) 用 \(N = 2\) 的联合分布 \(F_X(x_1, x_2; t_1, t_2)\) 求二重积分
    高阶矩 用 \(N \ge 3\) 的联合分布

    这说明什么：第三层不是「另一个独立的东西」， 而是第二层在只保留二阶以内的矩之后的投影。 所以「均值、自相关能算」这件事本身是有严格依据的 —— 它们就是第二层那些分布的矩，只是我们跳过分布、直接算矩。

    第二层到第三层是一次降维

    从第二层走到第三层，做的动作是投影： 把「整个分布」压缩成「二阶以内的矩」。

    这个投影要付出代价：丢掉了分布的形状信息。 两个截然不同的分布完全可以有相同的均值和方差。 所以第三层「不完整」这句话是字面意义上的、有具体后果的：

    • 对高斯过程，二阶矩决定一切 —— 投影是无损的；
    • 对非高斯过程，二阶矩不够用，必须回到分布本身。

    这就是为什么「高斯假设」在信号处理里这么值钱： 它把第二层和第三层接了起来。

    3.5 三个术语必须分清¶

    中文教材里「随机过程」「样本函数」「随机变量」 这三个词经常被混着用，但它们是三个层次的东西：

    术语 别名 它是什么 「多少个」 例（上面那个矩阵里）
    随机过程 过程、系综 整个随机变量族 \(X = \{X(t), t \in T\}\) 一族 整个 \(6 \times 6\) 矩阵代表的那个东西
    样本函数 实现、样本轨道 固定一次实验得到的确定性函数 一条 矩阵的第 1 行
    随机变量 截面 固定一个时刻得到的随机变量 \(X(t)\) 一个 矩阵的第 3 列

    随机变量 vs 随机过程，这是全页最需要一次记住的对照：

    对照项 随机变量 随机过程
    它是什么 一个数 一条函数（一族随机变量）
    有几个下标 0 个 1 个时间下标 \(t\)
    一次实验给什么 一个取值 一条样本函数
    「平均」对谁做 对取值求期望 对每个时刻分别求期望，得到均值函数
    描述相似性用什么 方差 自相关函数 \(R(t_1,t_2)\)
    为什么后者更麻烦 —— 时刻之间有先后顺序，顺序不能打乱

    一句话：随机变量是一个数，随机过程是一条函数。 理解这句话的关键是「固定什么、看什么变」—— 固定 \(t\) 得到随机变量，固定实验得到样本函数。

    三个术语混用会直接导致算错

    最常见的两种混法，后果都很具体：

    错误说法 错在哪 会算出什么
    「这条样本函数的均值就是过程的均值」 过程均值是系综平均，要对无穷多次实验平均 只有一条曲线时，算出来的是时间平均，不是过程均值
    「随机过程是一个随机变量」 少了「族」这个字，时间结构丢了 会漏掉自相关 \(R(t_1, t_2)\) 这个最重要的量

    正确的读法：随机过程是母体，样本函数是它的一次抽样，随机变量是它在某一时刻的切片。

    另外还有一个容易踩的坑：样本函数必须是「函数」。 如果你做实验时只测了 \(t = 1, 2, 3\) 三个点， 那你拿到的不是一条样本函数，而是三个数（或者叫一个三维随机向量的一个样本）。 只有当时间参数在整个区间上都有观测时，才谈得上「一条曲线」。

    3.6 第三层：均值、自相关、协方差¶

    现在进入本课程真正要用的层次。先把三个量的定义写清楚， 再讲它们之间的关系。

    （一）均值函数：固定时刻 \(t\)，对整个系综求平均

    \[\mu_X(t) = \mathbb{E}[X(t)]\]

    注意这里 \(\mathbb{E}[\cdot]\) 是对所有可能的实验结果求平均， 不是沿时间轴求平均。这一点在 3.2 节已经强调过。

    （二）自相关函数：把两个时刻的乘积拿来做系综平均

    \[R_{XX}(t_1, t_2) = \mathbb{E}\big[X(t_1)X(t_2)\big]\]

    它衡量的是「\(t_1\) 时刻的值和 \(t_2\) 时刻的值有多像」。 \(R\) 大说明两个时刻的值倾向于同号、同大小； \(R\) 接近 \(0\) 说明两个时刻基本无关。

    （三）协方差函数：先把均值减掉，再取相关

    \[C_{XX}(t_1, t_2) = \mathbb{E}\Big[\big(X(t_1) - \mu_X(t_1)\big)\big(X(t_2) - \mu_X(t_2)\big)\Big]\]

    把方括号展开，就能看到这两个量的确定关系。 按定义展开，先拆成四项：

    \[C_{XX}(t_1, t_2) = \mathbb{E}\big[X(t_1)X(t_2)\big] - \mu_X(t_2)\,\mathbb{E}[X(t_1)] - \mu_X(t_1)\,\mathbb{E}[X(t_2)] + \mu_X(t_1)\mu_X(t_2)\]

    为什么能这样拆：因为 \(\mu_X(t_1)\) 与 \(\mu_X(t_2)\) 都是常数 （对系综平均而言），常数可以提到期望号外面。

    再代入 \(\mathbb{E}[X(t_1)] = \mu_X(t_1)\)、\(\mathbb{E}[X(t_2)] = \mu_X(t_2)\)：

    \[C_{XX}(t_1, t_2) = R_{XX}(t_1, t_2) - \mu_X(t_1)\mu_X(t_2) - \mu_X(t_1)\mu_X(t_2) + \mu_X(t_1)\mu_X(t_2)\]

    后三项里有两个 \(-1\) 倍项和一个 \(+1\) 倍项，合并得 \(-1\) 倍项，于是

    \[C_{XX}(t_1, t_2) = R_{XX}(t_1, t_2) - \mu_X(t_1)\,\mu_X(t_2)\]

    这个式子是本页最重要的一条关系，把它记住： 协方差 = 自相关 − 两个均值的乘积。

    这说明什么：自相关里混着「直流分量」的贡献。 即使两个时刻的值完全不相像（纯粹的随机起伏）， 只要均值不为零，\(R_{XX}\) 也不会是零 —— 因为它把 \(\mu^2\) 带进来了。 协方差就是把均值的影响剥掉之后剩下的那个「真的像不像」。 所以比较两个过程的相关性强弱时，用协方差比用自相关更干净。

    把上面几个量汇总成一张对照表，符号与名称一次记清：

    量 记号 定义式 物理意义
    均值 \(\mu_X(t)\) \(\mathbb{E}[X(t)]\) 这一时刻取值的中心位置
    均方值 \(\mathbb{E}[X^{2}(t)]\) 就是 \(R_{XX}(t, t)\) 这一时刻的「总功率」
    方差 \(\sigma_X^{2}(t)\) \(\mathbb{E}\big[(X(t) - \mu_X(t))^{2}\big]\) 这一时刻起伏的大小
    自相关 \(R_{XX}(t_1,t_2)\) \(\mathbb{E}[X(t_1)X(t_2)]\) 两个时刻的原始相似程度
    协方差 \(C_{XX}(t_1,t_2)\) \(R_{XX} - \mu_X(t_1)\mu_X(t_2)\) 扣掉均值后的相似程度
    相关系数 \(\rho\) \(C_{XX}/\sqrt{\sigma^{2}(t_1)\sigma^{2}(t_2)}\) 归一化到 \(\pm 1\) 的相似程度

    3.7 核心恒等式：均方值、方差与均值的关系¶

    这是考试里出现频率最高的一个关系式，必须每一步都能说出来。

    先明确 \(R(0)\) 是什么意思：\(R_{XX}(t_1, t_2)\) 有两个时间自变量； 当两个时刻取同一个时，写成

    \[R_{XX}(0) \equiv R_{XX}(t, t) = \mathbb{E}\big[X(t)X(t)\big] = \mathbb{E}\big[X^{2}(t)\big]\]

    也就是说，\(R(0)\) 就是均方值。

    再写出方差和均值的定义。方差是「偏差平方的期望」：

    \[\sigma^{2} = \mathbb{E}\Big[\big(X - \mu\big)^{2}\Big]\]

    其中 \(\mu = \mathbb{E}[X]\)。为了写法简洁，下面暂时把 \(t\) 省略， 因为整个推导对每个固定的 \(t\) 都成立。

    然后逐步展开。把括号里的平方展开：

    \[\sigma^{2} = \mathbb{E}\big[X^{2} - 2\mu X + \mu^{2}\big]\]

    依据：这里用的是完全平方公式 \((a - b)^{2} = a^{2} - 2ab + b^{2}\)。

    期望是线性的，逐项拆开：

    \[\sigma^{2} = \mathbb{E}[X^{2}] - 2\mu\,\mathbb{E}[X] + \mathbb{E}[\mu^{2}]\]

    依据：\(\mathbb{E}[aX + bY + c] = a\mathbb{E}[X] + b\mathbb{E}[Y] + c\)， 其中常数因子可以直接提到期望号外面。

    现在逐项代入。

    第一项：按上面说的，\(\mathbb{E}[X^{2}] = R(0)\)。

    第二项：\(\mathbb{E}[X] = \mu\)，所以 \(-2\mu\,\mathbb{E}[X] = -2\mu \cdot \mu = -2\mu^{2}\)。

    第三项：\(\mu^{2}\) 是一个常数（它是对系综平均算出来的，不随机）， 常数的期望就是它自己：

    \[\mathbb{E}[\mu^{2}] = \mu^{2}\]

    依据：\(\mathbb{E}[c] = c\)，因为常数随机变量永远只取同一个值。

    三项合起来：

    \[\sigma^{2} = R(0) - 2\mu^{2} + \mu^{2} = R(0) - \mu^{2}\]

    最后一步：把 \(\mu^{2}\) 移到左边，就得到要证的那个式子：

    \[R(0) = \sigma^{2} + \mu^{2}\]

    这说明什么：这个式子的每一部分都有明确的物理含义， 它说的是一句非常实用的话 ——

    等式中的量 叫什么 对应信号的哪一部分
    \(R(0)\) 均方值 总功率
    \(\mu^{2}\) 均值的平方 直流功率（恒定不变的那部分）
    \(\sigma^{2}\) 方差 交流功率（起伏的那部分）

    所以 \(R(0) = \sigma^{2} + \mu^{2}\) 就是功率分解：

    \[\text{总功率} = \text{交流功率} + \text{直流功率}\]

    两条立即可用的推论：

    • 若过程零均值（\(\mu = 0\)），则 \(R(0) = \sigma^{2}\) —— 均方值等于方差；
    • 若过程非零均值，则 \(R(0) > \sigma^{2}\)，多出来的部分正是 \(\mu^{2}\)。

    把 R(0) 直接当方差用是常见错误

    很多推导里 \(R(0)\) 和 \(\sigma^{2}\) 会被随手互换， 只有在零均值时才允许这样做。

    一个具体的反例：设某过程的均值为 \(3\)、方差为 \(4\)， 那么它的 \(R(0) = 4 + 9 = 13\)，是方差的 \(3.25\) 倍。 如果在这个过程上把 \(R(0)\) 当成方差，会直接高估起伏 \(3\) 倍以上。

    正确的顺序永远是：先用均值分离出直流部分，再讨论起伏。

    3.8 自相关函数的性质，以及为什么它这么关键¶

    \(R_{XX}(t_1, t_2)\) 有几个性质是必考的，而且每一条都能从定义直接推出来。

    性质一：对称性（偶函数性）。在平稳的情形下记 \(\tau = t_2 - t_1\)， 则有

    \[R(\tau) = R(-\tau)\]

    推导：把定义式里的两个时刻交换一下位置，

    \[R(-\tau) = \mathbb{E}\big[X(t)X(t - \tau)\big]\]

    依据：交换 \(t_1\) 与 \(t_2\) 的角色，等价于把时间差取反。

    再把上式里的时刻作变量替换（把 \(t\) 整体平移 \(+\tau\)，这不改变系综平均的值， 因为平稳性保证统计量与绝对时刻无关）：

    \[R(-\tau) = \mathbb{E}\big[X(t + \tau)X(t)\big] = \mathbb{E}\big[X(t)X(t + \tau)\big] = R(\tau)\]

    依据：乘法可交换，\(X(t+\tau)X(t) = X(t)X(t+\tau)\)。

    所以 \(R(\tau)\) 是偶函数。这一点在图上看得最清楚 —— 自相关曲线关于纵轴左右对称；图中还标出了它在滞后为零处取到最大值：

    性质二：\(R(0)\) 是所有滞后里最大的。 从图上可以看到，曲线在 \(\tau = 0\) 处达到最高点，向两边衰减。

    怎么理解：\(R(0)\) 是信号和完全重合的自己做相关， 当然相似度最高；\(\tau\) 一旦不为零，就是拿信号和平移过的自己做相关， 相似度只会更低。

    性质三：负相关性也是允许的。图上曲线衰减到零以下再回来， 说明「平移后的信号与原来的信号倾向于反号」。 这不是错误，是真实存在的现象 —— 比如周期信号的 \(R(\tau)\) 就会来回振荡。

    性质四：\(R(0)\) 与方差、均值的关系，就是上一节证过的

    \[R(0) = \sigma^{2} + \mu^{2}\]

    为什么自相关是本课程的核心工具，理由有三条：

    理由 说明
    它抓住了时间结构 均值只描述一个时刻，自相关描述的是两个时刻之间的关联，这是随机过程与随机变量唯一不同的地方
    它和功率谱是一对变换 平稳情形下 \(R(\tau)\) 与功率谱密度互为傅里叶变换，时域和频域通过它连起来
    它是可估计的 用一条有限长的记录就能算出样本自相关，而且是相合估计，数据越多越准

    最后一条尤其重要，它解释了为什么整个课程能建立在「一条记录」之上： 因为我们真正依赖的只有自相关，而自相关是能估的。

    3.9 一个完整的系综手算例题¶

    下面这道小题把上面所有定义走一遍，全部要求手算，不给任何程序结果。

    设 \(X(t) = A\cos(\omega t + \Theta)\)，其中 \(A = 2\)、\(\omega = 0.5\)， \(\Theta\) 在 \([0, 2\pi)\) 上均匀分布。求 \(\mu_X(t)\)、\(\sigma_X^{2}(t)\)、 \(R_{XX}(\tau)\) 与 \(C_{XX}(\tau)\)。

    第一步：算均值。按定义对 \(\Theta\) 取系综平均。因为 \(\Theta\) 均匀分布， 概率密度是 \(1/(2\pi)\)：

    \[\mu_X(t) = \mathbb{E}[2\cos(0.5t + \Theta)] = \frac{2}{2\pi}\int_0^{2\pi}\cos(0.5t + \theta)\,d\theta\]

    依据：连续型随机变量函数的期望是对概率密度积分， \(\mathbb{E}[g(\Theta)] = \int g(\theta)p(\theta)\,d\theta\)。

    令 \(u = 0.5t + \theta\)，则 \(d\theta = du\)，积分限从 \(0.5t\) 到 \(0.5t + 2\pi\)， 正好是一个完整周期，余弦在一个完整周期上的积分为零：

    \[\mu_X(t) = \frac{2}{2\pi}\int_{0.5t}^{0.5t+2\pi}\cos u\,du = \frac{2}{2\pi}\big[\sin u\big]_{0.5t}^{0.5t+2\pi} = 0\]

    所以均值恒为零，且与 \(t\) 无关。

    第二步：算均方值与方差。先算 \(\mathbb{E}[X^{2}]\)：

    \[\mathbb{E}[X^{2}] = \mathbb{E}[4\cos^{2}(0.5t + \Theta)] = \frac{4}{2\pi}\int_0^{2\pi}\cos^{2}(0.5t + \theta)\,d\theta\]

    用倍角公式降幂，\(\cos^{2}u = \dfrac{1 + \cos 2u}{2}\)：

    \[\mathbb{E}[X^{2}] = \frac{4}{2\pi}\int_0^{2\pi}\frac{1 + \cos(1.0t + 2\theta)}{2}\,d\theta\]

    拆成两项。第一项是常数 \(1\) 在一个周期上的积分，即 \(2\pi\)； 第二项里 \(\cos(1.0t + 2\theta)\) 关于 \(\theta\) 的周期是 \(\pi\)， 区间 \([0, 2\pi]\) 正好是两个完整周期，积分为零：

    \[\mathbb{E}[X^{2}] = \frac{4}{2\pi}\cdot\frac{1}{2}\cdot 2\pi + 0 = 2\]

    因为均值为零，所以方差

    \[\sigma_X^{2}(t) = \mathbb{E}[X^{2}] - \mu_X^{2} = 2 - 0 = 2\]

    第三步：用恒等式核对。\(\mu = 0\)、\(\sigma^{2} = 2\)，所以

    \[R(0) = \sigma^{2} + \mu^{2} = 2 + 0 = 2\]

    与第二步算出的 \(\mathbb{E}[X^{2}] = 2\) 一致 ✓。 这一步的意义是：两个不同的算法给出同一个数，可以用来自查。

    第四步：算自相关 \(R_{XX}(\tau)\)。按定义

    \[R_{XX}(\tau) = \mathbb{E}\big[2\cos(0.5t + \Theta)\cdot 2\cos(0.5(t+\tau) + \Theta)\big]\]

    把 \(A^{2} = 4\) 提到期望号外面：

    \[R_{XX}(\tau) = 4\,\mathbb{E}\big[\cos(0.5t + \Theta)\cos(0.5t + 0.5\tau + \Theta)\big]\]

    用积化和差公式 \(\cos\alpha\cos\beta = \dfrac{\cos(\alpha - \beta) + \cos(\alpha + \beta)}{2}\)。 令 \(\alpha = 0.5t + \Theta\)、\(\beta = 0.5t + 0.5\tau + \Theta\)，则

    \[\alpha - \beta = -0.5\tau\]
    \[\alpha + \beta = 1.0t + 0.5\tau + 2\Theta\]

    于是

    \[R_{XX}(\tau) = \frac{4}{2}\,\mathbb{E}\big[\cos(0.5\tau) + \cos(1.0t + 0.5\tau + 2\Theta)\big]\]

    逐项取期望。第一项 \(\cos(0.5\tau)\) 里没有 \(\Theta\)， 所以它是常数，期望就是它自己：

    \[\mathbb{E}[\cos(0.5\tau)] = \cos(0.5\tau)\]

    第二项里含 \(2\Theta\)。因为 \(\Theta\) 在 \([0, 2\pi)\) 上均匀， \(2\Theta\) 就在 \([0, 4\pi)\) 上均匀，走满两个完整周期， 所以它在一个完整周期上的积分为零：

    \[\mathbb{E}[\cos(1.0t + 0.5\tau + 2\Theta)] = 0\]

    两项合起来：

    \[R_{XX}(\tau) = 2\cos(0.5\tau)\]

    第五步：核对 \(R(0)\)。代入 \(\tau = 0\)：\(R(0) = 2\cos 0 = 2\)， 与第二、第三步的结果一致 ✓。

    第六步：算协方差 \(C_{XX}(\tau)\)。用 3.6 节的关系式 \(C = R - \mu(t_1)\mu(t_2)\)。因为均值恒为零，乘积项为零，所以

    \[C_{XX}(\tau) = R_{XX}(\tau) - 0 = 2\cos(0.5\tau)\]

    这说明什么：这个过程中自相关和协方差完全相同， 这不是巧合，而是零均值的直接后果。 反过来说：只有当均值恒为零时，才能用自相关代替协方差； 一旦过程有非零均值（比如例题 1 里那个带随机直流项 \(B\) 的过程）， 两者就会分开，差值恰好是 \(\mu^{2}\)。

    把这一题的关键数字整理成一张手算对照表，方便自查：

    量 手算值 与 \(t\) 有关吗 与参数的关系
    \(\mu_X(t)\) \(0\) 无关 与 \(A\) 无关（余弦整周期积分为零）
    \(\sigma_X^{2}(t)\) \(2\) 无关 等于 \(A^{2}/2\)
    \(R_{XX}(0)\) \(2\) 无关 等于 \(A^{2}/2\)
    \(R_{XX}(\tau)\) \(2\cos(0.5\tau)\) 无关，只依赖 \(\tau\) 幅度 \(A^{2}/2\)、频率 \(\omega\)
    \(C_{XX}(\tau)\) \(2\cos(0.5\tau)\) 无关 零均值，所以与 \(R\) 相同

    四、公理化定义：概率空间是什么¶

    4.1 为什么需要公理化¶

    上面那个定义 \(X = \{X(t), t \in T\}\) 用起来很方便， 但它在数学上留下了一个洞：「随机变量」本身靠什么站得住脚？

    本课程课件在这里提到了一件历史事实： 关于随机过程的公理化定义，主要是由柯尔莫戈洛夫（A. N. Kolmogorov）推动的， 并得到数学研究者的广泛接受和发展。

    课件的原话是：公理化定义中引入了「概率空间」的概念。 也就是说，公理化的做法是先建一个地基（概率空间）， 再在地基上定义随机变量，最后用随机变量族定义随机过程。 三层结构是这样的：

    本课程后续不依赖公理化细节

    你需要记住的只有两句话：

    1. 随机过程是一族随机变量 \(X = \{X(t), t \in T\}\)；
    2. 统计量是能算的 —— 均值、方差、自相关都有明确的定义式。

    \(\Omega\)、\(\mathcal{F}\)、\(P\) 这套东西的作用是保证上面两句话在数学上不自相矛盾， 它回答的是「这个定义合法吗」，不是「该怎么算」。 真正在算的时候，我们从来不会回到 \(\Omega\) 上去， 而是直接用课件 2.1 节给的那些统计特征公式（期望、\(n\) 阶矩、方差、互相关、协方差）在 「随机变量的分布」这一级上操作。

    所以：这一节读一遍建立概念即可，不需要背下测度论的定义。

    五、参数集 \(T\) 的两种类型¶

    5.1 \(T\) 连续与 \(T\) 离散¶

    回到定义里的 \(T\)：课件说 \(T\) 是指标（时间）\(t\) 的集合， 并且对所有 \(t \in T\) 都配了一个随机变量。 \(T\) 有两种基本类型，对应的对象名字也不同：

    对照项 连续时间随机过程 随机序列
    参数集 \(T = \mathbb{R}\)（或一个区间） \(T = \mathbb{Z}\)（整数）
    符号写法 \(X = \{X(t),\ t \in \mathbb{R}\}\) \(X = \{X(n),\ n \in \mathbb{Z}\}\)
    一个时刻 \(t\) 取任意实数 \(n\) 只取整数
    典型来源 物理世界的连续量：热噪声电压、连续语音波形 采样之后的数字信号
    观测到的东西 连续曲线 一列数 \(x(1), x(2), x(3), \dots\)
    统计描述 均值函数 \(\mu(t)\)、自相关 \(R(t_1, t_2)\) 均值 \(\mu(n)\)、自相关 \(r(n_1, n_2)\)
    怎么处理 先用采样定理离散化 直接处理（本来就是离散的）

    数字信号处理处理的本质上是随机序列

    这一点值得单独强调：本课程后面遇到的对象几乎全是随机序列，不是连续时间过程。

    原因很直接 —— 数字信号处理的第一步就是采样。 采样把连续时间轴 \(t\) 换成了整数下标 \(n\)， 于是连续时间随机过程 \(\{X(t)\}\) 也就变成了随机序列 \(\{X(n)\}\)。

    这个转化会在记号上留下痕迹，读课件时要留意：

    连续时间 离散时间 差别
    \(R_x(t_1, t_2)\) \(r_{xx}(n_1, n_2)\) 变量从实数换成整数
    \(R_x(\tau)\)，\(\tau = t_2 - t_1\) \(r_{xx}(k)\)，\(k = n_2 - n_1\) 滞后量从连续变成整数
    时间平均是积分 \(\frac{1}{2T}\int_{-T}^{T}(\cdot)\,dt\) 时间平均是求和 \(\frac{1}{2N+1}\sum_{n=-N}^{N}(\cdot)\) 积分变求和

    5.2 实际数据是「有限长」的，这是个必须记住的落差¶

    还有一个很实际的落差要在这里点出来：

    理论上的随机过程 你手上真正有的数据
    \(T\) 可能是无限的（\(T = \mathbb{Z}\) 含无穷多个整数） 只观测了 \(N\) 个点
    样本函数有无穷多条 通常只有一条（一次实验的一段记录）
    均值是 \(E\{\cdot\}\)，对所有实验平均 只能算 \(\frac{1}{N}\sum_{n=1}^{N}(\cdot)\)

    这个落差是后面所有「估计」问题的根源： 理论上算 \(E\{x(n)\}\) 要对无穷多条样本函数平均， 实际上我们只有一条有限长的记录， 于是只能希望「沿时间轴平均」能代替「沿系综平均」—— 这个希望成立的条件，就叫遍历性，是下一页的主题。

    六、随机过程的分类维度¶

    课件在「随机过程的某些知识」这一节里，先讲了两种统计研究途径 （系综统计和时间统计），然后给了两组核心概念：平稳性与遍历性。 这两组概念同时也是划分随机过程的两个维度。下面把分类维度一次列清， 但本页只列分类名、只给一句话说明，不展开每一个 （平稳与遍历的详细内容在下一页专门讲）：

    划分依据 分成哪几类 一句话说明
    统计特性是否随时间变化 平稳 / 非平稳 联合分布关于时间轴任意偏移是否不变
    统计平均能否替代时间平均 遍历 / 非遍历 系综统计与时间统计的结果是否一致
    分布类型 高斯过程 / 非高斯过程 任意有限个时刻的联合分布是否为高斯分布
    记忆性 白噪声 / 有色噪声 各时刻之间是否互不相关（有无记忆）

    四个维度里，前两个是本课程下一节的主角，这里先把课件给的两句话原样记住：

    平稳性（Stationary）：一个随机过程 \(X(t)\) 需要用一组时刻 \(t_1, t_2, \dots, t_N\) 观测的一组随机变量 \(\{X_1, X_2, \dots, X_N\}\) 的联合统计分布 \(P(x_1, x_2, \dots, x_N)\) 来描述。 对固定的 \(N\)，如果联合分布关于时间轴的任意偏移不变， 则该过程是一个平稳到 \(N\) 阶的随机过程； 如果 \(N \to \infty\) 时过程是平稳的，则是一个严格平稳过程。 课件还点了一句：常见的非平稳过程如均值时变或方差时变的过程， 以及：平稳到二阶的过程称为广义平稳过程。

    遍历性（Ergodicity）：一个随机过程 \(X(t)\) 称为具有遍历性的， 如果该过程按系综统计和按时间统计的结果是一致的。 特别地，如果过程的时间自相关按概率 \(1\) 收敛于系综自相关， 则称该过程具有自相关遍历性。 课件给了一条非常重要的逻辑关系： 一个具有遍历性的过程必定是平稳的，但一个平稳过程不必具有遍历性。

    「平稳」和「遍历」不是一回事，方向也不能反

    这两条逻辑关系必须记准：

    命题 对不对
    遍历 ⇒ 平稳 ✓ 对
    平稳 ⇒ 遍历 ✗ 错（平稳过程不必遍历）

    反过来看更直观：平稳说的是「统计特性不随时间变」， 遍历说的是「一次实验的时间记录能不能代表整个系综」。 一个平稳过程完全可能「所有样本函数都一模一样，只是各自被一个随机常数平移」—— 这种过程统计特性不随时间变（平稳）， 但看一条记录永远看不到那个随机常数（不遍历）。

    本课程后面的维纳滤波、卡尔曼滤波、谱估计， 全都建立在「平稳」甚至「遍历」的假设之上。 所以这两组词一旦混了，后面会一路别扭。

    6.1 两种统计研究途径：系综统计与时间统计¶

    分类维度里反复出现「系综统计」和「时间统计」这两个词， 这里必须先把它们讲清楚，否则下一节看不懂。

    对照项 系综统计（Ensemble statistics） 时间统计（Time statistics）
    研究对象 同一时刻、不同实验的观测值分布 一次实验的时间记录（连续过程或采样序列）
    怎么做 固定 \(t\)，在很多次实验之间统计 固定一条记录，沿时间轴统计
    记号 \(E\{\bullet\}\) 上划线或带上标的时间平均记号
    是否看重时间顺序 不看重 —— 每个数据都被看作一次独立试验的结果 看重 —— 顺序就是它的全部信息
    数学基础 基于观测值分布特性的假定，符合概率论严格的数学基础 符合人们的观测习惯（我们本来就只能拿到一条记录）
    需要什么条件 需要很多次独立实验 只需要一次实验，但要求过程遍历

    课件给的两句评语值得原样记住：

    • 系综统计是基于观测值分布特性假定的统计。 在任何一个时刻，观测量可能随机地取不同数值， 系综统计是对取值的概率特征进行统计。 对大量数据，系综统计强调每个数据都是独立试验结果，不看重时间顺序。
    • 时间统计是基于观测量的时间记录（连续过程或采样序列）， 对观测量的数值分布特征进行统计。

    这两条途径为什么要区分？因为现实里我们通常只有一条记录： 一次雷达回波、一个受试者的一段脑电。时间统计是我们唯一能做的。 而时间统计给出的结果，只有在遍历性成立时，才等于系综统计的结果。

    七、典型随机过程举例¶

    本页最后把几类最常见的随机过程列一遍。每一类只给一句定义 + 一句用在哪， 目的是让你在看到这些名词时不至于陌生， 具体性质会在后续页面逐个展开。

    过程 定义（一句话） 用在哪
    白噪声 各时刻互不相关，功率谱平坦 模型里代表「完全无法预测」的那部分；几乎所有接收机噪声的模型
    高斯过程 任意有限个时刻的联合分布都是多元高斯分布 雷达、通信中的热噪声；线性系统对高斯输入的响应
    正弦过程 \(X(t) = A\cos(\omega t + \Theta)\)，其中 \(\Theta\) 是随机相位 载波、振动信号建模；遍历性的经典例子
    随机游走 / 维纳过程 白噪声的累积和 \(\sum\)，非平稳 陀螺仪零偏、股价、粒子布朗运动建模
    马尔可夫过程 未来只依赖现在，与更早的历史无关 状态空间模型、卡尔曼滤波的状态演化方程

    几个补充说明：

    • 白噪声是最基本的一个。它的名字来自光学：白光包含了所有频率， 所以功率谱在所有频率上都是常数。要特别注意它说的是「不相关」而不是「独立」—— 不相关只约束了二阶矩，独立才是更强的条件（对高斯过程两者等价）。
    • 高斯过程的重要性来自中心极限定理和一条极其实用的性质： 高斯过程经过线性系统后仍然是高斯过程。 所以只要噪声能当高斯看，后面线性滤波的整套推导就都能用。
    • 正弦过程之所以被单独列出来，是因为它是「每条样本函数都完全确定、 整体却随机」的极端例子（随机性只在相位上）。 下一页讲遍历性时，会用它来说明「时间平均能恢复系综平均」需要什么条件。
    • 随机游走 / 维纳过程是「非平稳」的标准例子： 它的方差随时间线性增长，所以统计特性明显随时间变。 它也是理解「为什么要发明非平稳信号处理」的最省事的例子。
    • 马尔可夫过程的核心是记忆长度只有一步。 这个假设把无穷维的联合分布压缩成了「转移概率」，是状态空间方法的起点。

    为什么会有这个差别，根源只有一句： 随机游走是白噪声的累积和。 每一步都在往前面所有步的结果上加东西，所以过去的影响永远不会消失， 方差随时间线性增长；而白噪声每一步都是新的，过去的影响立刻就没了。

    例题 1：在给定过程上分别固定不同的东西¶

    设一个随机过程由下式定义：

    \[X(t) = B + A\cos(\omega t + \Theta)\]

    其中 \(B\) 和 \(\Theta\) 是两个相互独立的随机变量： \(B\) 服从均值为 \(0\)、方差为 \(\sigma_B^2\) 的分布，\(\Theta\) 在 \([0, 2\pi)\) 上均匀分布； \(A\) 与 \(\omega\) 是已知常数。

    请在下面三种操作下，分别说出你得到的是什么对象： （1）固定 \(t = 3\)，让 \(B\) 和 \(\Theta\) 各自随机取一次； （2）固定一次实验（即 \(B\) 和 \(\Theta\) 都抽定），让 \(t\) 从 \(0\) 变到 \(10\)； （3）两者都固定。

    思路

    回到本页那张核心表：看什么在变、什么被固定住。

    • 固定 \(t\)：时间下标消失了，剩下的量只由 \(B\) 和 \(\Theta\) 决定， 所以得到的是一个随机变量。
    • 固定一次实验：\(B\) 和 \(\Theta\) 都变成了两个具体的数， 剩下的式子只是 \(t\) 的普通函数，所以得到的是一条确定性函数。
    • 两者都固定：\(t\) 是数、\(B\) 和 \(\Theta\) 也是数，整个表达式只给出一个数。

    这道题的额外价值在于 \(B\) 这一项。它不是随 \(t\) 振荡的， 而是整条曲线共同被平移的一个随机量 —— 这正是「不遍历」的典型来源，下一页会用到。

    解答
    操作 得到什么 理由
    （1）固定 \(t = 3\) 一个随机变量 \(X(3) = B + A\cos(3\omega + \Theta)\) 时间下标 \(t\) 已固定成常数 \(3\)，剩下的随机性来自 \(B\) 和 \(\Theta\)
    （2）固定一次实验 一条样本函数（确定性函数） \(B\) 和 \(\Theta\) 已抽定成两个数，剩下的只是 \(t\) 的普通函数
    （3）两者都固定 一个数 三个量全是常数，表达式给出一个确定的数值

    关键点一：第（1）问里得到的随机变量有分布，可以做统计： 因为 \(B\) 和 \(\Theta\) 独立，可以逐项算期望。

    \[\mathbb{E}[X(t)] = \mathbb{E}[B] + A\,\mathbb{E}[\cos(\omega t + \Theta)] = 0 + 0 = 0\]

    第一项是 \(\mathbb{E}[B] = 0\)；第二项和第 3.4 节算过的一样， 因为 \(\Theta\) 在完整周期上均匀分布，\(\cos\) 的积分为 \(0\)。

    方差也能算出来（用了两个随机变量独立的性质，所以和的方差等于方差之和）：

    \[\mathrm{Var}[X(t)] = \mathrm{Var}[B] + A^2\,\mathrm{Var}[\cos(\omega t + \Theta)] = \sigma_B^2 + \frac{A^2}{2}\]

    关键点二：这两个统计量与 \(t\) 无关， 所以这个过程在「均值 + 方差」这个层面是平稳的。

    关键点三：B 这一项带来的问题是 —— 它让整条样本函数一起上下平移。 沿时间轴平均时，\(B\) 的贡献平掉不了（因为每条曲线都带着同一个 \(B\)）， 所以即使过程平稳，时间平均也未必等于系综平均。 这就是「平稳但不遍历」的例子，下一页正式讲。

    例题 2：用大样本验证系综均值真的收敛¶

    对随机相位正弦过程 \(X(t) = A\cos(\omega t + \Theta)\)， 取 \(A = 2\)、\(\omega = 0.5\)，\(\Theta\) 在 \([0, 2\pi)\) 上均匀分布。 请回答：

    1. 理论上 \(\mathbb{E}[X(t)]\) 与 \(\mathrm{Var}[X(t)]\) 各是多少？
    2. 如果在 \(t = 2\) 处分别取 \(100\) 条和 \(100000\) 条样本函数，样本均值会怎么变？
    3. 为什么「样本量越大误差越小」这件事对本课程特别重要？
    思路

    第 1 问是纯手算：\(X(t) = A\cos(\omega t + \Theta)\)， 对 \(\Theta\) 在 \([0, 2\pi)\) 上积分即可，注意 \(A\)、\(\omega\)、\(t\) 都是常数。 方差用 \(\mathrm{Var} = \mathbb{E}[X^2] - (\mathbb{E}[X])^2\)， 其中 \(\mathbb{E}[X^2]\) 要用倍角公式把 \(\cos^2\) 降成一次。

    第 2 问是「统计学基本结论」：样本均值的标准差按 \(1/\sqrt{K}\) 缩小， 所以 \(K\) 从 \(100\) 涨到 \(100000\)（涨 \(1000\) 倍）， 误差量级应缩小到约 \(1/\sqrt{1000} \approx 1/31.6\)。

    第 3 问要联系本课程的主线：我们永远拿不到系综， 只有一条有限长的记录，所以「估计量会不会收敛」直接决定方法能不能用。

    解答

    第 1 问。均值：

    \[\mathbb{E}[X(t)] = \frac{A}{2\pi}\int_0^{2\pi}\cos(\omega t + \theta)\,d\theta = 0\]

    （完整周期上的余弦积分为零。）

    二阶矩用倍角公式 \(\cos^2 u = \dfrac{1 + \cos 2u}{2}\)：

    \[\mathbb{E}[X^2(t)] = \frac{A^2}{2\pi}\int_0^{2\pi}\frac{1 + \cos(2\omega t + 2\theta)}{2}\,d\theta = \frac{A^2}{2}\left(1 + 0\right) = \frac{A^2}{2}\]

    所以方差

    \[\mathrm{Var}[X(t)] = \mathbb{E}[X^2] - (\mathbb{E}[X])^2 = \frac{A^2}{2} - 0 = \frac{A^2}{2}\]

    代入 \(A = 2\)：理论均值 \(= 0\)，理论方差 \(= 2\)。

    第 2 问。样本均值是一个随机变量，它的标准差约为 \(\dfrac{\sigma}{\sqrt{K}}\)， 其中 \(\sigma = \sqrt{A^2/2} = \sqrt{2} \approx 1.4142\)。

    • \(K = 100\) 时，标准差约 \(\dfrac{1.4142}{10} \approx 0.1414\)；
    • \(K = 100000\) 时，标准差约 \(\dfrac{1.4142}{316.2} \approx 0.0045\)。

    下面把这张表核对一遍（用 \(A = 2\)、\(\omega = 0.5\)、\(t = 2\)， 并且假设样本量依次取 \(100\)、\(1000\)、\(10000\)、\(100000\)、\(1000000\)）。 理论值：均值 \(= 0\)，方差 \(= A^{2}/2 = 2\)，标准差 \(\sigma = \sqrt{2} \approx 1.4142\)。

    样本均值的标准差按 \(\sigma/\sqrt{K}\) 缩小，手算这一列：

    样本量 \(K\) \(\sqrt{K}\) 手算 \(\sigma/\sqrt{K}\) 与上一步相比缩小了几倍
    \(100\) \(10.0\) \(0.1414\) ——
    \(1000\) \(31.6\) \(0.0447\) 约 \(3.2\) 倍
    \(10000\) \(100.0\) \(0.0141\) 约 \(3.2\) 倍
    \(100000\) \(316.2\) \(0.0045\) 约 \(3.2\) 倍
    \(1000000\) \(1000.0\) \(0.0014\) 约 \(3.2\) 倍

    这张表里最值得记的是最后一列：样本量每扩大 10 倍， 误差只缩小到约 \(1/\sqrt{10} \approx 0.316\)，也就是约三分之一。 所以想把误差再缩小一半，样本量得扩大 4 倍 —— 这个「投入产出比」很差的特性，是后面所有估计问题都要面对的现实。

    同时，无论样本量多大，样本方差都停在 \(2\) 附近： 因为方差是单个随机变量自身的性质，不随样本量变化。 这一点也解释了为什么 \(K\) 从 \(100\) 涨到 \(1000000\)（涨 \(10000\) 倍）之后， 样本均值误差能降下来，而样本方差不会继续往 \(2\) 以下走。

    第 3 问。这一点在本课程里分量很重，理由有三条：

    理由 说明
    系综拿不到 真实数据只有一条记录，\(K = 1\)，永远不是「很多次实验」
    所以只能估 用有限数据算出的是估计量，它本身是随机变量
    估得准不准要看收敛性 只有知道估计量随数据量收敛到理论值，整套方法才有意义

    这正是后面「参数估计」那一页要正式回答的问题： 无偏（平均来看准不准）、有效（波动有多小）、一致（数据越多会不会收敛）。 本例题演示的就是第三条 —— 一致性。

    例题 3：判断一个实际信号该用哪套工具¶

    下面四个信号，请分别判断它更适合当确定性信号还是随机信号建模， 并说明判断依据：

    （1）标准信号源输出的、参数已知的正弦波； （2）同一条正弦波，但经过一个噪声很大的信道送过来； （3）一次雷达回波； （4）一个已知系统对已知输入的阶跃响应。

    思路

    判断依据只有一条：能不能根据起始条件或过去的观测，用显式模型精确预测未来的数据。

    注意要区分「信号本身」和「你拿到的那一份观测」。 第（1）和第（4）问的答案在信号本身； 第（2）问的答案是「信号本身确定，但观测不确定」。

    另外还要问一句：这个问题真正需要回答什么？ 如果只需要稳态输出值，确定性模型够用； 如果要问「噪声有多大、估计有多准」，就必须上随机模型。

    解答
    信号 建模方式 依据
    （1）参数已知的正弦波 确定性 三个参数都给定了，任意时刻的值都能写出显式表达式，未来值可精确预测
    （2）正弦波 + 大噪声信道 随机（或者「确定信号 + 随机噪声」的混合模型） 信号本身确定，但你观测到的那一份带着无法显式写出的随机扰动
    （3）雷达回波 随机 目标距离、姿态、反射截面积都在变，同一目标的两次回波不会一样
    （4）已知系统对已知输入的阶跃响应 确定性 系统函数与输入都已知，输出可以用解析式（或差分方程）精确算出来

    两个补充要点：

    要点一：第（2）问是最常见的情形，也是最容易被含糊过去的情形。 严格地说它不是一个纯粹的随机信号，而是 「确定性信号 + 加性随机噪声」 的复合模型：

    \[Y(t) = s(t) + N(t)\]

    其中 \(s(t)\) 是已知的确定信号，\(N(t)\) 是随机噪声。 一旦写成这个形式，就出现了一整套新问题： 怎么从 \(Y\) 里把 \(s\) 弄出来（滤波）、噪声的强度怎么估（参数估计）。 这些问题在纯确定性框架里根本提不出来，这也是必须引入随机信号的原因。

    要点二：选择哪套模型，取决于要回答什么问题，不取决于信号本身「客观上是随机的」。 一个参数已知的正弦波，如果你只问「\(t = 10\) 时值是多少」， 用确定性模型一句话就答完； 但如果你问「采样时叠了噪声，这个正弦的幅度估出来误差有多大」， 就必须切到随机模型 —— 因为那个问题里的「误差有多大」只有概率能回答。

    这条原则可以概括成：

    你想问 该用的模型
    下一个值是多少 确定性
    下一个值的分布是什么、估计有多准 随机

    例题 4：验证「每条样本函数都是确定的，整体才是随机的」¶

    对随机相位正弦过程 \(X(t) = A\cos(\omega t + \Theta)\)（\(A = 2\)、\(\omega = 0.5\)、 \(\Theta\) 在 \([0, 2\pi)\) 上均匀分布），请用系综统计算出 \(X(t)\) 的自相关函数

    \[R(k) = \mathbb{E}[X(t)X(t + k)]\]

    的理论值，并用 \(50000\) 条样本函数实测一遍做对照。 同时说明：为什么这个过程的每一条样本函数都是完全确定的曲线。

    思路

    理论值要展开乘积再用积化和差：

    \[\cos\alpha\cos\beta = \frac{\cos(\alpha - \beta) + \cos(\alpha + \beta)}{2}\]

    令 \(\alpha = \omega t + \Theta\)、\(\beta = \omega(t + k) + \Theta\)， 于是 \(\alpha - \beta = -\omega k\)，\(\alpha + \beta = 2\omega t + \omega k + 2\Theta\)。

    关键就在这两项的性质不同：

    • \(\cos(\alpha - \beta) = \cos(\omega k)\) 里没有 \(\Theta\)， 所以它是常数，期望就是它自己；
    • \(\cos(\alpha + \beta)\) 里含 \(2\Theta\)，而 \(\Theta\) 在 \([0, 2\pi)\) 上均匀， \(2\Theta\) 正好走满两个完整周期，期望为 \(0\)。

    所以 \(R(k) = \dfrac{A^2}{2}\cos(\omega k)\)。

    第 3 问回到三个视角：固定一次实验时，\(\Theta\) 已经是一个具体的数 \(\theta\)， 表达式 \(A\cos(\omega t + \theta)\) 就是 \(t\) 的普通余弦函数。

    解答

    理论推导。把乘积写开：

    \[R(k) = \mathbb{E}\big[A\cos(\omega t + \Theta)\cdot A\cos(\omega(t+k) + \Theta)\big]\]
    \[= A^2\,\mathbb{E}\left[\frac{\cos(\omega k) + \cos(2\omega t + \omega k + 2\Theta)}{2}\right]\]

    逐项取期望：第一项 \(\cos(\omega k)\) 与随机变量无关，期望是它自身； 第二项对 \(\Theta\) 在 \([0, 2\pi)\) 上积分，因为 \(2\Theta\) 走满两个完整周期，积分为零。 于是

    \[R(k) = \frac{A^2}{2}\cos(\omega k)\]

    代入 \(A = 2\)、\(\omega = 0.5\)：\(R(k) = 2\cos(0.5k)\)。 注意 \(R(0) = 2\) 正好等于方差，这和「自相关在零点等于均方值」是一致的。

    自测¶

    Q1 请写出本课程课件给出的随机过程定义（包括符号和每个符号的含义）， 并说明「随机变量族」这三个字为什么不能省。

    解答

    定义：设 \(T\) 是指标（时间）\(t\) 的集合，如果对每个 \(t \in T\)， 有定义在 \(\Omega\) 上的随机变量 \(X(t)\)， 则称随机变量族 \(X = \{X(t),\ t \in T\}\) 为一个随机过程。

    各符号含义：

    符号 含义
    \(T\) 参数集（指标集合），常为 \(\mathbb{R}\) 或 \(\mathbb{Z}\)
    \(t\) 一个具体时刻，\(t \in T\)
    \(X(t)\) 时刻 \(t\) 处的随机变量
    \(\Omega\) 样本空间（随机事件全体构成的基本空间）

    「随机变量族」三个字不能省的理由：省掉「族」，时间结构就丢了。 具体后果有两个：

    1. 会漏掉 \(X(t_1)\) 与 \(X(t_2)\) 之间的关系，也就是自相关 \(R(t_1, t_2)\)。 这个量恰恰是本课程后面最重要的工具。
    2. 会把「过程的均值」误读成沿时间轴平均。 而按定义，均值是固定时刻、对所有实验结果求平均（系综平均）， 两者只有在遍历性成立时才相等。

    Q2 请说明理解「一族随机变量」的三个视角，并说明三个术语 （随机过程、样本函数 / 实现、随机变量）各自指的是哪一层。

    解答

    三个视角：

    固定什么 得到什么 数学上是什么
    固定 \(t\) 一个随机变量 \(X(t)\) 随机变量
    固定一次实验（一个样本点 \(\zeta\)） 一条确定性函数 样本函数 / 实现
    两者都固定 一个数 实数

    （如果用双参数记号，就是 \(\Omega\) 上的 \(X(t, \zeta)\)： 固定 \(\zeta\) 让 \(t\) 变得样本函数，固定 \(t\) 让 \(\zeta\) 变得随机变量，两者都固定得到一个数。）

    三个术语的层次：

    术语 别名 是哪一层 「多少个」
    随机过程 过程、系综 整个随机变量族 一族（母体）
    样本函数 实现、样本轨道 固定一次实验的结果 一条（一次抽样）
    随机变量 截面 固定一个时刻的结果 一个（一片切片）

    一句话记法：随机过程是母体，样本函数是它的一次抽样，随机变量是它的时刻切片。

    课件在讲统计研究途径时也用了这两个视角的名字： 系综统计对应「固定时刻、在很多次实验之间统计」， 时间统计对应「固定一条记录、沿时间轴统计」。

    Q3 请写出概率空间 \((\Omega, \mathcal{F}, P)\) 的三部分各是什么， 并说明为什么本课程后续不需要依赖公理化细节。

    解答

    三部分：

    组成 记号 名称 含义
    基本空间 \(\Omega\) 样本空间 包涵随机事件全体；每个元素是一次可能的结果
    事件集类 \(\mathcal{F}\) 事件域 全体事件所构成的集类
    概率测度 \(P\) 概率测度 事件或事件集合出现的概率

    课件还指出：\((\Omega, \mathcal{F}, P)\) 构成概率空间， 是更一般测度空间的一种特例（概率空间里总测度被固定为 \(1\)）。

    为什么后续不依赖它：公理化解决的是「这个定义合不合法」， 不是「该怎么算」。公理化的作用是保证「随机变量族」这个概念在数学上站得住； 而真正做计算时，我们操作的对象是随机变量的分布， 用的公式就是课件给出的那几个统计特征： 期望（均值、系综平均）、\(X\) 的函数 \(g(X)\) 的期望、\(n\) 阶矩、方差、（互）相关、（互）协方差。

    所以本课程需要记住的只有两句： 随机过程是一族随机变量；统计量能算（均值、方差、自相关都有定义式）。

    Q4 请说明参数集 \(T\) 取连续和取离散时，对象的名字、记号、数据形式各有什么不同； 为什么说数字信号处理处理的本质上是随机序列？另外， 「理论上」和「实际数据」之间还差着什么？

    解答
    对照项 \(T\) 连续 \(T\) 离散
    对象名字 连续时间随机过程 随机序列
    记号 \(X = \{X(t),\ t \in \mathbb{R}\}\) \(X = \{X(n),\ n \in \mathbb{Z}\}\)
    一个时刻 \(t\) 取任意实数 \(n\) 只取整数
    数据形式 一条连续曲线 一列数 \(x(1), x(2), \dots\)
    典型来源 热噪声电压、连续语音波形 采样之后的数字信号
    统计描述 \(R_x(t_1, t_2)\)、滞后 \(\tau = t_2 - t_1\) \(r_{xx}(n_1, n_2)\)、滞后 \(k = n_2 - n_1\)
    时间平均 积分 \(\frac{1}{2T}\int_{-T}^{T}(\cdot)\,dt\) 求和 \(\frac{1}{2N+1}\sum_{n=-N}^{N}(\cdot)\)

    为什么本质上是随机序列：数字信号处理的第一步就是采样， 采样把连续时间轴 \(t\) 换成整数下标 \(n\)， 连续时间随机过程也就变成了随机序列。 于是后面会遇到的全是 \(x(n)\)、\(r_{xx}(k)\) 这种带整数下标的写法。

    理论上与实际数据的落差：

    理论 实际
    \(T\) 可能含无穷多个时刻 只观测了 \(N\) 个点
    有无穷多条样本函数 通常只有一条
    均值是对所有实验求 \(E\{\cdot\}\) 只能算 \(\frac{1}{N}\sum_{n=1}^{N}\)

    这个落差正是「估计」问题的来源。 把「沿时间平均」当作「沿系综平均」来用， 需要遍历性成立才行 —— 那是下一页的内容。

    小结¶

    本页的主线只有一句话：随机过程是「一族随机变量」，不是一个随机变量。 下面这张表按四层描述的组织顺序排列，读的时候可以顺带回忆每一条属于哪一层。

    要记住的 属于哪一层 为什么
    随机信号的描述分四层，层层加码 总纲 样本函数 → 分布函数族 → 数字特征 → 平稳性，越往下越完整、越难用
    第一层：样本函数 第一层 固定一次实验得到一条确定性函数，也就是「实现」
    第二层：分布函数族 第二层 \(F_X(x_1,\dots,x_N; t_1,\dots,t_N)\)，完整但不可计算
    第三层：数字特征 第三层 均值、方差、自相关、协方差，是第二层在二阶以内的投影
    第四层：平稳性 第四层 对数字特征的时间平移不变性假设，是化简条件而非新统计量
    随机过程的定义 第一层 \(X = \{X(t),\ t \in T\}\)，\(T\) 是指标（时间）集合
    核心三个字是「族」 第一层 随机过程不是一个随机变量，而是一族随机变量
    固定 \(t\) 得到一个随机变量 三视角 这是「截面」视角
    固定一次实验得到一条确定性函数 三视角 这就是样本函数 / 实现
    两者都固定得到一个数 三视角 双参数记号 \(X(t, \zeta)\)
    三个术语不能混 三视角 过程是母体，样本函数是一次抽样，随机变量是时刻切片
    随机变量是一个数，随机过程是一条函数 三视角 前者 0 个下标，后者带时间下标 \(t\)
    均值是系综平均，不是时间平均 第三层 \(\mu_X(t) = \mathbb{E}[X(t)]\)，固定时刻对所有实验平均
    自相关 \(R(t_1,t_2) = \mathbb{E}[X(t_1)X(t_2)]\) 第三层 唯一能刻画「两个时刻有多像」的二阶量
    协方差 = 自相关 − 两均值之积 第三层 \(C = R - \mu(t_1)\mu(t_2)\)，展开定义式即得
    \(R(0)\) 就是均方值 第三层 \(R(0) = R(t,t) = \mathbb{E}[X^{2}(t)]\)
    \(R(0) = \sigma^{2} + \mu^{2}\) 第三层 由 \(\sigma^{2} = \mathbb{E}[X^{2}] - \mu^{2}\) 移项即得，是功率分解
    总功率 = 交流功率 + 直流功率 第三层 \(R(0)\) 对总功率，\(\sigma^{2}\) 对交流，\(\mu^{2}\) 对直流
    零均值时才有 \(R(0) = \sigma^{2}\) 第三层 非零均值时把 \(R(0)\) 当方差用会高估起伏
    零均值时才有 \(C(\tau) = R(\tau)\) 第三层 否则两者相差 \(\mu^{2}\)
    自相关是偶函数 第三层 \(R(\tau) = R(-\tau)\)，交换两个时刻即得
    自相关在滞后为零处最大 第三层 与完全重合的自己最像
    自相关可估计 第三层 一条有限长记录就能算出相合的样本自相关
    概率空间 \((\Omega, \mathcal{F}, P)\) 三部分 公理化 样本空间 / 事件域 / 概率测度
    公理化只保证「合法」，不用于「计算」 公理化 后续只需「一族随机变量 + 能算统计量」这个直观
    \(T\) 连续 → 连续时间随机过程 参数集 \(R_x(t_1, t_2)\)，滞后是连续量
    \(T\) 离散 → 随机序列 参数集 本课程的主要对象，\(r_{xx}(k)\)，滞后是整数
    数字信号处理本质上处理随机序列 参数集 因为采样之后时间已经离散化
    理论有系综，实际只有一条记录 参数集 这个落差就是「估计」问题的总根源
    平稳 / 非平稳 第四层 看统计特性是否随时间变化；常见形态是均值时变或方差时变
    遍历 / 非遍历 第四层 看系综统计与时间统计是否一致
    遍历 ⇒ 平稳，反之不成立 第四层 课件原话：具有遍历性的过程必定平稳，平稳过程不必遍历
    系综统计 vs 时间统计 第四层 前者符合概率论严格基础，后者符合观测习惯
    确定性信号 = 能用显式模型精确预测未来值的信号 预备 三个条件：有依据、有表达式、预测要精确
    随机信号 = 非确定性 / 非可预测的信号 预备 课件用确定性信号反着定义它
    随机不等于无规律 预备 取值不可预测，但均值、方差、自相关、功率谱都可确定描述
    确定性信号预测「下一个值是多少」 预备 随机信号预测「下一个值的分布是什么」
    高斯 / 非高斯、白噪声 / 有色噪声 分类 另两个分类维度（按分布类型、按记忆性）
    随机游走是白噪声的累积和 分类 过去的影响永不消失，方差随时间增长，所以非平稳
    正弦过程是遍历性的经典例子 分类 系综自相关 \(R(\tau) = \frac{A^2}{2}\cos(\omega\tau)\)，每条样本函数却是确定的
    从随机变量到随机过程的阶梯 分类 一个数 → 随机变量 → 随机向量 → 随机过程，每级多加一个下标
    随机过程可以看成无限维随机向量 分类 均值向量→均值函数，协方差矩阵→自相关函数 \(R(t_1, t_2)\)
