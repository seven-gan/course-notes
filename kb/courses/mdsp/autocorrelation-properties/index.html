    自相关函数的性质¶

    这一页只解决一个问题：拿到一条自相关函数，怎么一眼看出它算得对不对。

    上一页讲了自相关的定义：一个广义平稳序列 \(x(n)\) 的自相关是

    \[r_{xx}(m) = \mathbb{E}\{x(n)\,x^{*}(n+m)\}\]

    这个定义式本身不会告诉你「算出来的东西应该长什么样」。于是实际工作中最常见的一幕是： 你写完一段代码，画出一条自相关曲线，看着它好像挺像回事 —— 但它可能根本不可能 对应任何真实信号。比如它在某个滞后上的绝对值超过了 \(r(0)\)，或者它关于原点不对称。

    这一页要记的，就是这些「必然成立的规律」。 有了它们，自相关就不只是一个计算结果， 而是一个可以被检查的对象。

    先用一张表说清「没有性质」和「有性质」的差别：

    只会算自相关 记住性质之后
    拿到一条曲线 看着顺眼就信了 逐条对照，越界立刻警觉
    代码写错了 不知道错在哪，只能猜 多半能定位到分母、去均值或下标
    后面的谱估计 算出来的功率谱可能出现负值，还不知道为什么 知道这是非负定性被破坏的信号
    需要选参数时 凭经验拍一个窗长 用相关时间算出窗长该取多少 ✓

    数学表述 → 直觉解释 → 代码实跑验证。

    最后用一张「性质到用途」的对照表把它们串起来 —— 那张表才是这一页真正要带走的东西 ✓

    先说清一件事：哪些是课件列的，哪些是补充的。 本课程课件在 「实平稳随机信号自相关函数的性质」这一节里，列出的是三条：

    编号 性质 来源
    性质 1 \(r_{xx}(0) \ge \lvert r_{xx}(m)\rvert\) 本课程课件 ✓
    性质 2 \(r_{xx}(m) = r_{xx}(-m)\)（对称 / 偶函数） 本课程课件 ✓
    性质 3 \(r_{xx}(0)\) 与均方值、方差的关系 本课程课件 ✓

    下面从性质 1 开始。

    一、性质 1 与性质 3：\(r_{xx}(0)\) 是最大值，而且就是平均功率¶

    1.1 先看课件给的两行式子¶

    本课程课件在性质部分先写了两行：

    \[\sigma_x^2 = D_x = \mathbb{E}\big\{\big[x(n) - m_x\big]^2\big\} = r_{xx}(0) - m_x^2\]
    \[\mathbb{E}\{x^2(n)\} = r_{xx}(0)\]

    第一行说的是：方差等于 \(r_{xx}(0)\) 减去均值的平方。第二行说的是： 均方值就等于 \(r_{xx}(0)\)。

    这两行式子读起来像是废话，其实里面藏着三个不同的量。先把符号定义清楚， 这是后面所有讨论的地基：

    符号 读法 定义 单位（以电压为例）
    \(m_x\) 均值 \(\mathbb{E}\{x(n)\}\)，与 \(n\) 无关（平稳） 伏特 V
    \(r_{xx}(0)\) 自相关在原点 \(\mathbb{E}\{x(n)\,x(n)\} = \mathbb{E}\{x^2(n)\}\) 伏特平方 V²
    \(\sigma_x^2\) 方差 \(\mathbb{E}\{(x - m_x)^2\}\)，去均值后的均方值 伏特平方 V²
    \(D_x\) 同方差 与 \(\sigma_x^2\) 完全同一个量 伏特平方 V²

    关键观察：\(r_{xx}(0)\) 和 \(\sigma_x^2\) 量纲相同，数值不同， 差的就是直流分量的功率 \(m_x^2\)。

    把第一条式子移项就得到课件的第二条：

    \[r_{xx}(0) = \sigma_x^2 + m_x^2\]

    怎么读：原点处的自相关，等于「交流功率（方差）」加上「直流功率（均值平方）」。 这就是平均功率的含义 —— 如果 \(x(n)\) 是加在 1 欧姆电阻上的电压， 那么 \(r_{xx}(0)\) 的单位是 V²，数值上就等于这个信号的功率 ✓

    1.2 性质 1 的完整表述¶

    课件给出的第三条性质是一个不等式：

    \[r_{xx}(0) \ge \lvert r_{xx}(m)\rvert \quad \text{对一切 } m \text{ 成立}\]

    这里 \(m\) 取遍所有整数（正的、负的、零）。等号什么时候成立？ 这个问题很重要，先给结论，后面再验证：

    情形 等号成立吗 说明
    \(m = 0\) 一定成立 两边都是 \(r_{xx}(0)\)，这是恒等
    \(m \ne 0\) 通常不成立 只在信号有严格周期性时才会在某几个 \(m\) 上取等
    恒定信号 \(x(n) = c\) 对所有 \(m\) 都成立 因为 \(r_{xx}(m) = c^2\) 是常数 ⚠

    最后一行是个容易踩的坑：一条一直不变的信号（纯直流），它的自相关 在任意滞后上都等于 \(c^2\)，也就是处处取等。这说明不等式取等并不总是好消息， 它也可能意味着「这个信号里没有信息」。这一点和后面「衰减很慢说明有趋势」是同一个道理。

    1.3 用代码验证 \(r_{xx}(0) \ge \lvert r_{xx}(m)\rvert\)¶

    在验证之前，必须先确定一件事：分母到底用什么。这是一个绕不开的选择， 而且必须先说清楚，否则后面的数字都不可比。

    有限长数据 \(x(0), x(1), \dots, x(N-1)\) 的自相关估计有两种常见写法：

    写法 公式 性质
    有偏估计 \(\hat r_b(m) = \dfrac{1}{N}\sum_{n=0}^{N-\lvert m\rvert-1} x(n)x(n+m)\) 有偏，但恒有 \(\lvert \hat r_b(m)\rvert \le \hat r_b(0)\) ✓
    无偏估计 \(\hat r_u(m) = \dfrac{1}{N-\lvert m\rvert}\sum_{n=0}^{N-\lvert m\rvert-1} x(n)x(n+m)\) 无偏，但不保证上述不等式 ⚠

    本页代码中的分母约定：除了下面这一组专门对比两种分母差异的代码， 以及纯正弦的例子（那里为了命中解析式 \(A^2/2\cdot\cos\)，用无偏分母）之外， 全部采用「有偏」写法，统一除以 \(N\)。这样做的理由有三条：

    1. 课件在讲自相关估计时给出的实用公式，就是把求和项数换成 \(N\) 的那一版； 课件同时指出它是有偏但渐进无偏的，并且当数据很长时可以用 FFT 快速计算。
    2. 只有统一分母，性质 1 才恒成立，才可以用作判据。
    3. 分母混用是自相关这一节最典型的错误来源，第八节会用一段代码演示它 如何把一条合法的自相关变成不合法的 ⚠

    import numpy as np

rng = np.random.default_rng(42)


def auto(x, m, mode="biased"):
    """有限长自相关的两种分母。

    mode = "biased"   -> 除以 N（本页采用）
    mode = "unbiased" -> 除以 N - |m|
    """
    N = x.size
    k = abs(m)
    s = float(np.dot(x[:N - k], x[k:]))
    return s / (N if mode == "biased" else N - k)


def acf(x, M, mode="biased"):
    return np.array([auto(x, m, mode) for m in range(M + 1)])


x = rng.normal(0.0, 1.0, size=64)
x = x - x.mean()

r_b = acf(x, 8, "biased")
r_u = acf(x, 8, "unbiased")

print("数据长度 N =", x.size)
print("有偏 R(0) = %.6f" % round(r_b[0], 6))
print("无偏 R(0) = %.6f" % round(r_u[0], 6), "（m = 0 时两套分母相同）")
print("m = 1..8 有偏 R(m):", r_b[1:].round(4))
print("m = 1..8 无偏 R(m):", r_u[1:].round(4))

    二、性质 2：实信号的自相关是偶函数¶

    2.1 数学表述与两行推导¶

    课件给出的第二条性质写成：

    \[r_{xx}(m) = r_{xx}(-m)\]

    课件把自协方差也并列写出：\(\mathrm{cov}_{xx}(m) = \mathrm{cov}_{xx}(-m)\)。 两个结论完全平行，因为自协方差只是去均值后的自相关。

    这条性质不需要「显然可得」，两行就能推完，而且推导本身很值得看一遍：

    第一步，写出定义。由广义平稳，\(r_{xx}(m)\) 只与间隔有关：

    \[r_{xx}(m) = \mathbb{E}\{x(n)\,x(n+m)\}\]

    第二步，把指标整体平移。令 \(n' = n + m\)。因为过程是平稳的， 期望不依赖于时间起点，所以可以把整段求和（求期望）重新从 \(n'\) 起算：

    \[r_{xx}(m) = \mathbb{E}\{x(n'-m)\,x(n')\}\]

    第三步，利用期望里乘积可交换顺序（标量乘法交换律）：

    \[r_{xx}(m) = \mathbb{E}\{x(n')\,x(n'-m)\} = r_{xx}(-m)\]

    最后一步用的还是定义：\(\mathbb{E}\{x(n')x(n'-m)\}\) 里两个样本的间隔是 \(n' - (n'-m) = m\) 的相反数，即间隔为 \(-m\)。

    怎么读：整个推导只用了两件事 ——平稳性和实数乘法可交换。 平稳性用来允许「平移指标」，交换律用来把两个因子的顺序调过来。 这也解释了为什么复信号的情形不同：复数乘法不可交换，所以会多出一个共轭。

    2.2 直觉：相关的方向不重要，只看间隔¶

    把 \(x(n)\) 想成一段时间序列。\(r_{xx}(m)\) 问的是：「隔 \(m\) 个采样点， 两个样本有多像？」

    • 从第 10 个点往后看，看第 \(10+m\) 个点，得到的相似度是 \(r_{xx}(m)\)；
    • 从第 \(10+m\) 个点往前看，看第 10 个点，得到的相似度是 \(r_{xx}(-m)\)。

    「往后看」和「往前看」是同一对样本，只是换了个说法。所以两个数必须相等 ✓

    一句话总结：相关的方向不重要，只看间隔的大小。

    2.4 复信号的情形：不要照抄这条性质¶

    复信号必须是共轭对称

    实信号的偶函数性质，到复信号这里要改写成共轭对称：

    \[r_{xx}(-m) = r_{xx}^{*}(m)\]

    原因就是上面推导的第三步失效了。复数的乘法不满足交换律， 而且定义式里第二个因子带共轭：

    \[r_{xx}(m) = \mathbb{E}\{x(n)\,x^{*}(n+m)\}\]

    把两个因子换位时，共轭会跑到另一个因子上去，于是多出一个共轭号。

    如果你在做通信或雷达的信号处理，数据往往是复基带信号， 这里写错会一路错到功率谱。

    一个快速的判别方法：如果算出的 \(r_{xx}(m)\) 是复数，那它就不可能满足 \(r_{xx}(-m) = r_{xx}(m)\)，只能是共轭相等 ⚠

    三、性质 4：周期信号的自相关仍是同周期函数¶

    3.1 这条性质不在课件的三条里¶

    先说清来源：这一节和之后的三节都是本页补充的内容， 用来把课件那三条性质补成一个能实际工作的工具集 ⚠

    3.2 数学表述¶

    设 \(x(n)\) 是一个周期为 \(P\) 的（广义平稳）序列，即 \(x(n + P) = x(n)\) 对所有 \(n\) 成立。 那么它的自相关满足

    \[r_{xx}(m + P) = r_{xx}(m)\]

    也就是说，自相关也是周期为 \(P\) 的周期函数。

    两行推导：

    \[r_{xx}(m + P) = \mathbb{E}\{x(n)\,x(n + m + P)\} = \mathbb{E}\{x(n)\,x(n+m)\} = r_{xx}(m)\]

    中间那一步用的就是周期性 \(x(n+m+P) = x(n+m)\)。

    怎么读：自相关把「相位」这个信息丢掉了，但把「周期」这个信息完整地保留了下来。 这正是它能在噪声里找周期的原因 ✓

    3.3 正弦信号：可以算出解析答案¶

    最简单也最常用的例子是正弦：

    \[x(n) = A\sin(2\pi f_0 n / f_s + \varphi)\]

    它的自相关（在无限长时间意义下）是

    \[r_{xx}(m) = \frac{A^2}{2}\cos\!\left(\frac{2\pi f_0 m}{f_s}\right)\]

    这里 \(f_0\) 是信号频率、\(f_s\) 是采样率，所以 \(f_s / f_0\) 就是每个信号周期有几个采样点。

    怎么读：自相关是一个同频率的余弦，振幅是 \(A^2/2\)。

    • 峰值出现在 \(\frac{2\pi f_0 m}{f_s} = 2\pi k\)，即 \(m = k \cdot \frac{f_s}{f_0}\)；
    • 相邻峰值的间距正好是一个信号周期 ✓

    所以只要在自相关上量一下峰间距，就能反推出信号周期。这就是「在噪声里找周期」的标准做法。

    四、性质 5：非负定性¶

    4.1 表述¶

    这是一条形式上最「重」、但意义最深远的一条：自相关函数是（半）正定的。

    数学表述：对任意有限个时刻 \(t_1, t_2, \dots, t_K\) 和任意一组复数系数 \(a_1, a_2, \dots, a_K\)，都有

    \[\sum_{i=1}^{K}\sum_{j=1}^{K} a_i\,a_j^{*}\,r_{xx}(t_i - t_j) \;\ge\; 0\]

    怎么读：把 \(r_{xx}(t_i - t_j)\) 排成一个 \(K \times K\) 的矩阵

    \[\mathbf{R} = \begin{bmatrix} r_{xx}(0) & r_{xx}(t_1 - t_2) & \cdots \\ r_{xx}(t_2 - t_1) & r_{xx}(0) & \cdots \\ \vdots & \vdots & \ddots \end{bmatrix}\]

    这条性质就是说：这个矩阵对一切取值时刻都是半正定的。

    4.2 它为什么必然成立¶

    证明只有三行，而且非常漂亮，值得看一遍 —— 因为它顺便解释了非负定性到底在说什么。

    考虑一个由系数 \(a_i\) 和信号 \(x(t)\) 构成的线性组合：

    \[Y = \sum_{i=1}^{K} a_i\,x(t_i)\]

    这是一个随机变量。现在看它的模平方的期望：

    \[\mathbb{E}\{\lvert Y\rvert^2\} = \mathbb{E}\Big\{\Big(\sum_i a_i x(t_i)\Big)\Big(\sum_j a_j x(t_j)\Big)^{*}\Big\} = \sum_i\sum_j a_i a_j^{*}\,\mathbb{E}\{x(t_i)x^{*}(t_j)\}\]

    最后一步把期望移进双重求和，并用上定义式 \(\mathbb{E}\{x(t_i)x^{*}(t_j)\} = r_{xx}(t_i - t_j)\)。

    于是得到关键的等式：

    \[\mathbb{E}\{\lvert Y\rvert^2\} = \sum_i\sum_j a_i a_j^{*}\, r_{xx}(t_i - t_j)\]

    而 \(\lvert Y\rvert^2 \ge 0\) 恒成立，所以它的期望也 \(\ge 0\)。 证明完成。

    怎么读：非负定性不是一条外加的限制，而是「自相关本身来自一个真实的随机过程」 这件事的代数分身。任何真实信号生成的自相关，都自动满足它；

    反过来，任何不满足它的函数，都不可能由任何真实信号生成。这才是它的全部威力 ✓

    4.3 它的意义：保证功率谱非负¶

    非负定性在数学上等价于一句话：

    它的傅里叶变换是非负的。

    也就是当 \(\mathbf{R}\) 是半正定矩阵时，对应的功率谱密度满足 \(P_{xx}(\omega) \ge 0\) 对一切 \(\omega\) 成立。

    这为什么重要：功率谱的物理含义是「信号在某个频率上的功率密度」， 功率不可能是负的。所以功率谱非负这条要求是硬性的物理约束。 而它恰恰等价于自相关的非负定性 ✓

    这一步正是下一页「自相关与功率谱」（维纳–辛钦定理）的铺垫： 只要自相关满足非负定性，它对应的谱就一定是一个合法的功率谱。

    检查对象 检查内容 违反的后果
    自相关 \(r_{xx}(m)\) 非负定 它不对应任何真实信号
    功率谱 \(P_{xx}(\omega)\) 非负 出现「负功率」，物理上荒谬 ⚠
    两者关系 互为傅里叶变换 一边违反，另一边必然也违反

    三条性质的分工

    五、性质 6：不相关与白序列¶

    5.1 数学表述¶

    如果自相关满足

    \[r_{xx}(m) = 0 \qquad (m \ne 0)\]

    就称这个序列是不相关的（uncorrelated）。因为 \(r(0) > 0\)， 所以此时自相关是一个冲激（在离散情形下就是克罗内克 \(\delta\)）：

    \[r_{xx}(m) = \sigma_x^2 \,\delta(m), \qquad \delta(m) = \begin{cases} 1, & m = 0 \\ 0, & m \ne 0 \end{cases}\]

    怎么读：\(r_{xx}(m) = 0\) 的含义是「隔 \(m\) 个采样点取样，两个样本之间没有任何线性关系」。 换句话说 —— 当前值对预测下一个值毫无帮助。

    具有这种自相关函数的零均值序列，就称为白序列（白色噪声，white noise）✓

    5.2 课件在这里给过的伏笔¶

    本课程课件在讲「平稳随机序列通过线性系统」时，专门算过白噪声输入的情形： 当输入为白噪声、方差为 \(\sigma^2\) 时，输出的自相关函数正比于系统脉冲响应的自相关。 那一节用的正是 \(r_{xx}(k) = \sigma^2 \delta(k)\) 这个前提。

    也就是说，白噪声这个假设在课程里不是可有可无的装饰， 而是后面推导滤波器输出统计特性时的核心前提 ✓ 所以在自相关性质这一节把「白噪声的判据」讲清楚，是必要的一步。

    5.5 不相关不等于独立¶

    不相关不等于独立

    这是这一节最重要的一句话，也是最容易出错的地方。

    不相关是一个很弱的条件：它只要求协方差为零， 也就是线性关系为零。它完全没有约束任何非线性关系 ⚠

    独立是一个很强的条件：它要求联合分布可以分解成边缘分布的乘积， 也就是任何关系（不只是线性）都不存在。

    逻辑关系是单向的：

    \[\text{独立} \;\Longrightarrow\; \text{不相关}\]

    反过来不成立。只有在联合高斯分布这个特殊情形下， 两者才等价 —— 这也是高斯分布被反复使用的真正原因 ✓

    所以在做信号处理时，「\(r(m) = 0\) 说明独立」这句话是错的， 必须改成：「\(r(m) = 0\) 说明线性不相关」。

    例二（离散版，通常更好懂）：\(K\) 等可能地取 \(\{0, 1, 2, 3\}\)， \(M = (K - 1.5)^2\)。相关系数是 \(+0.004041\)，同样是 \(0\) 附近。

    而这个例子里可以看到 \(M\) 的取值与 \(K\) 的一一对应关系：

    \(K\) 0 1 2 3
    \(M\) 2.25 0.25 0.25 2.25

    \(M\) 只能取两个值：\(K\) 取两端时 \(M = 2.25\)，取中间时 \(M = 0.25\)。 知道 \(K\) 就等于知道 \(M\) —— 依存关系强到极致，相关系数却为 0。

    为什么相关系数为 0：相关系数只度量线性关系。而 \(M\) 与 \(K\) 是 二次的、关于 \(K = 1.5\) 对称的关系，它是曲线而非直线。 沿着一条抛物线看，正相关段与负相关段恰好互相抵消，于是线性相关系数为 0。

    一句话记住区别

    不相关 独立
    约束的是 线性 关系 一切 关系
    \(\mathbb{E}\{XY\} = \mathbb{E}X \cdot \mathbb{E}Y\) 成立 成立
    联合分布可分解 不一定 成立
    蕴含关系 — 独立 \(\Rightarrow\) 不相关 ✓

    对信号处理的直接后果：用自相关 \(r(m)\) 只能检验线性相关。 你的数据可能存在很强的非线性依赖（例如平方关系、饱和关系）， 而自相关一点都看不出来。需要检验非线性关系时， 要看高阶统计量（如双谱）或者直接用互信息 ⚠

    六、性质 7：相关时间¶

    6.1 为什么需要这个量¶

    前面几条性质说的都是「自相关长什么样」。但在实际操作中，还有一个问题绕不开：

    我已经算出自相关了，那它衰减得算快还是算慢？我该拿这个信息做什么？

    「相关时间」就是回答这个问题的量。它把「衰减速度」压缩成一个数， 而这个数可以直接换算成工作参数 ✓

    6.2 定义：从宽的一种说法¶

    自相关是连续下降的，很难说「到哪一点算衰减完了」。所以相关时间的定义， 工程上通常取一个阈值，把「第一次降到阈值以下的滞后」定义为相关时间。 最常用的两个阈值：

    \[r_{xx}(\tau_c) = r_{xx}(0)\,/\,e \qquad \text{（用 } 1/e \approx 0.3679 \text{）}\]
    \[r_{xx}(\tau_c) = r_{xx}(0)\,/\,2 \qquad \text{（用一半）}\]

    这里 \(\tau_c\) 就是相关时间（correlation time）。

    ⚠ 必须先说清阈值，再说数值。同一个信号，用 \(1/e\) 判据和用 \(1/2\) 判据， 算出的相关时间可以差两倍以上。没有说明阈值的「相关时间」是没有意义的数字。

    阈值的物理直觉

    为什么常用 \(1/e\)？因为它和「时间常数」的文化一脉相承： 一阶系统的响应衰减到 \(1/e\) 的时间就是时间常数。

    为什么有时用 \(1/2\)？因为它对应「已经衰减了一半」，更保守， 在需要保证样本足够独立时更好用。

    记住一件事就够：换阈值得到的相关时间不同，但它们之间的相对大小关系不变。 所以比较两个信号时，用哪个阈值都行 —— 只要两个信号用同一个 ✓

    6.3 与 AR(1) 模型的精确对应¶

    对一阶自回归模型 \(y(n) = a\,y(n-1) + e(n)\)，自相关是 \(r(m) = r(0)a^{\lvert m\rvert}\)， 所以可以解析地解出 \(1/e\) 判据下的相关时间：

    \[a^{\tau_c} = \frac{1}{e} \;\Longrightarrow\; \tau_c \ln a = -1 \;\Longrightarrow\; \tau_c = -\frac{1}{\ln a}\]

    当 \(a\) 接近 1 时，\(\ln a \approx -(1 - a)\)，于是有一个很好记的近似：

    \[\tau_c \approx \frac{1}{1 - a}\]

    怎么读：\(a = 0.9\) 时相关时间约为 \(10\) 个采样点；\(a = 0.98\) 时约为 \(50\) 个采样点。 「记忆」的长度与 \(1 - a\) 成反比 ✓

    import numpy as np


def auto(x, m):
    N = x.size
    k = abs(m)
    return float(np.dot(x[:N - k], x[k:])) / N


def ar1(a, N, rng):
    y = np.zeros(N)
    e = rng.normal(0.0, 1.0, N)
    for i in range(1, N):
        y[i] = a * y[i - 1] + e[i]
    return y


def ctime(x, frac):
    """自相关第一次降到 R(0)*frac 以下的滞后。"""
    r = np.array([auto(x, m) for m in range(401)])
    r = r / r[0]
    idx = np.where(r < frac)[0]
    return (int(idx[0]) if idx.size else -1), r

    6.4 相关时间决定什么¶

    相关时间 \(\tau_c\) 不是一个学术概念，它直接决定三个工程参数：

    参数 与 \(\tau_c\) 的关系 理由
    窗长 / 数据长度 至少要几十倍 \(\tau_c\) 自相关估计的方差约为 \(1/N\)，段数越多越准 ✓
    采样间隔 不能远大于 \(\tau_c\) 否则相邻样本几乎无关，等于把连续信号采成了白噪声 ⚠
    分块长度 每块至少几倍 \(\tau_c\) 否则块与块之间高度相关，块平均的方差降不下来

    下面这张表把「相关时间」翻译成具体的采样建议，可以用作速查：

    信号类型 典型 \(\tau_c\) 采样间隔上限 建议最少样本数
    宽带白噪声 1 个采样点 —（本身离散） 几百点
    一般有色噪声 几到几十点 \(\tau_c / 5\) \(50\tau_c\)
    慢变趋势（非平稳） 接近数据长度 需先去掉趋势 ⚠ 不适用

    ⚠ 最后一行要特别注意：如果算出来的相关时间接近数据长度， 那通常不是说明信号相关性强，而是说明数据里混着趋势或直流 —— 这种情况下「相关时间」这个量本身就失去了意义。

    相关时间不能无限外推

    相关时间是从有限数据上算出来的，它本身就有不确定性。 大致上，它的相对误差约为 \(1/\sqrt{N / \tau_c}\)。

    也就是说：\(N = 1000\)、\(\tau_c = 10\) 时，只有约 \(100\) 个「独立段」， 相关时间的相对误差约 \(10\%\)。这个精度足够做工程判断， 但不足以做精细的定量结论 ⚠

    所以相关时间通常只用来做量级判断（是几个点还是几百个点）， 不用来当精确参数。

    一定要分清两种「衰减慢」：

    • 短记忆造成的慢衰减：一阶 AR 且 \(a\) 很大（如 \(0.99\)）， 衰减慢但是指数式的，最终会到 0。这是真相关性 ✓
    • 趋势造成的慢衰减：看起来像直线或极缓慢的曲线， 在数据长度内根本不会到 0。这是假相关性 ⚠

    区分方法：看曲线形状。指数衰减下，把纵轴取对数会变成直线； 趋势下，曲线整体近似一条不衰减的横线。也可以直接用相关时间判断 —— 如果算出的 \(\tau_c\) 接近数据长度 \(N\)，那就是趋势，不是相关性。

    处理办法也不同：真相关性要保留（它是信息）， 趋势要去掉（先去趋势再算自相关）。

#       r[m] = np.dot(x[:N - m], x[m:]) / (N - m)   # 大滞后用「无偏」分母


def raw(x, m):
    """只算内积，分母留给调用者决定。"""
    return float(np.dot(x[:x.size - abs(m)], x[abs(m):]))


x = series[4:28]          # 截出 24 个点，模拟一段短记录

    • 混用分母那一列：\(m = 22\) 时比值是 \(1.358\)，\(m = 23\) 时是 \(1.321\)， 两个滞后越界 ⚠

    分母必须一次性定死

    只有两个安全的选择：

    选择 分母 性质 1 是否成立
    全部有偏 一律除以 \(N\) 恒成立 ✓
    全部无偏 一律除以 \(N - \lvert m\rvert\) 对 \(r(0)\) 也除 \(N\)，比值仍可能超过 1，但不会因为混用而放大

    本页采用「全部有偏」。 理由很实际： 只有这一种写法能保证「比值不超过 1」这条判据恒成立， 才能把它当成自动化的检查手段 ✓

    一旦混用，这条判据就失效了 —— 你会开始怀疑数据， 而真正的问题在代码里。

    九、能量信号与随机信号：自相关的两种定义¶

    这一节把视角拉回来，复习一件很容易混的事 —— 「自相关」这个词在不同语境下是两个不同的式子。 混用会导致量纲错误，而量纲错误往往一路错到功率谱。

    9.1 两种定义的对照¶

    能量信号的自相关 功率信号 / 随机信号的自相关
    适用对象 有限长序列、绝对可和/可积的确定信号 随机过程、周期信号等持续存在的信号
    离散定义 \(R_e(m) = \sum_{n=-\infty}^{\infty} x(n)x(n+m)\) \(r_{xx}(m) = \lim\limits_{N\to\infty}\dfrac{1}{2N+1}\sum\limits_{n=-N}^{N} x(n)x(n+m)\)
    是否除以时长 不除 ✓ 要除（这是关键区别）⚠
    \(R(0)\) 的含义 能量（焦耳） 平均功率（瓦特）
    量纲 （幅度\(^2\)）× 时间/点数 幅度\(^2\)
    与傅里叶的关系 自相关的傅里叶变换 = 能量谱密度 自相关的傅里叶变换 = 功率谱密度

    怎么读：两个式子唯一的差别就是那个 \(\frac{1}{2N+1}\)（离散情形是 \(\frac{1}{N}\)）。

    • 不除 → 结果随数据长度线性增长，描述的是总能量；
    • 除以长度 → 结果收敛到有限值，描述的是平均功率 ✓

    9.2 为什么随机信号必须除以时长¶

    原因很实在：随机信号的能量是无穷大。

    一个持续存在的随机信号，你把它采样得越长，\(\sum x^2(n)\) 就越大，永远不收敛。 所以「能量」这个量对随机信号没有意义。必须换成「单位时间的能量」，也就是功率， 才能得到有限的、可以比较的数。

    这也解释了本页为什么一直用除以 \(N\) 的写法：处理随机信号时， 除以时长是定义的一部分，不是可选项。

    9.3 混用会怎样¶

    混用量纲会一路错到功率谱

    混用有两种典型表现，后果不同但都很严重：

    表现一：随机信号用了能量型的式子（不除）

    \(r(0)\) 会随数据长度线性增长。你换一批更长的数据，\(r(0)\) 就变大 —— 同样的信号，功率读数却随数据长度变化，这显然是错的。

    表现二：能量信号用了功率型的式子（除）

    结果被除上一个任意的长度，\(r(0)\) 不再是能量。 这时如果再去做傅里叶变换指望得到「能量谱密度」，量纲就对不上了 ⚠

    判别方法很简单：看 \(r(0)\) 的单位。

    \(r(0)\) 的单位 说明
    焦耳（幅度\(^2\)·秒） 这是能量信号，用的是不除的定义
    瓦特（幅度\(^2\)） 这是功率/随机信号，用的是除以时长的定义

    如果你算出 \(r(0)\) 的单位是「焦耳」，但数据明明是一段稳态噪声 —— 那就说明定义用错了。

    典型例题¶

    例题 1：验证 \(r(0)\) 是最大值（手算）¶

    题目：已知某零均值平稳序列的自相关在几个滞后上的取值为

    \(m\) 0 1 2 3
    \(r(m)\) 4.0 \(a\) \(-3.2\) 1.5

    问 \(a\) 的取值范围。

    思路

    直接用性质 1：\(\lvert r(m)\rvert \le r(0) = 4.0\) 对一切 \(m\) 成立。

    逐条套上去即可。注意负值也要检查：\(-3.2\) 的绝对值是 \(3.2\)， 小于 \(4.0\)，合法；如果它是 \(-5.0\) 就非法了。

    解答

    性质 1 要求 \(\lvert r(m)\rvert \le r(0)\)，此处 \(r(0) = 4.0\)，所以：

    • \(m = 1\)：\(\lvert a\rvert \le 4.0\)，即
    \[-4.0 \le a \le 4.0\]
    • \(m = 2\)：\(\lvert -3.2\rvert = 3.2 \le 4.0\) ✓ 合法
    • \(m = 3\)：\(\lvert 1.5\rvert = 1.5 \le 4.0\) ✓ 合法

    所以 \(a\) 的取值范围是 \([-4.0,\ 4.0]\)。

    进一步，如果这个序列还满足偶函数性质（性质 2）， 那么 \(r(-m) = r(m)\)，负滞后不用另外给值，可以直接照抄。

    ⚠ 一个额外的提醒：题里给的这组数通过了性质 1 和性质 2 的检查， 但不能保证它是合法的自相关 —— 还要满足非负定。 如果这是考试题，答案到 \([-4.0, 4.0]\) 就够了； 但在工程上，还要再用非负定性复查一遍。

    例题 2：正弦加噪的自相关¶

    题目：某信号为 \(x(n) = 2\cos(2\pi f_0 n/f_s)\)，\(f_0 = 50\) Hz，\(f_s = 1000\) Hz。 问它的自相关在哪些滞后上出现峰值？峰值处的值是多少（用 \(r(0)\) 归一化）？

    思路

    信号是纯余弦，振幅 \(A = 2\)。用正弦的解析式（\(A^2/2\) 换成 \(A^2/2\) 的形式）： 余弦的相位是 0，可以直接套。

    先算周期有多少个采样点，再找使 \(\cos = 1\) 的滞后。

    解答

    第一步：算周期。 每个信号周期有

    \[\frac{f_s}{f_0} = \frac{1000}{50} = 20 \text{ 个采样点}\]

    第二步：写出解析式。 余弦信号的（归一化）自相关是

    \[\frac{r_{xx}(m)}{r_{xx}(0)} = \cos\!\left(\frac{2\pi f_0 m}{f_s}\right) = \cos\!\left(\frac{2\pi m}{20}\right)\]

    第三步：找峰值。 峰值要求 \(\cos\) 取 \(+1\)，即

    \[\frac{2\pi m}{20} = 2\pi k \;\Longrightarrow\; m = 20k, \quad k = 0, 1, 2, \dots\]

    所以峰值出现在 \(m = 0, 20, 40, 60, \dots\)，峰间距为 20 个采样点， 正好等于信号周期。 ✓

    第四步：峰值大小。

    • 归一化后，\(m = 20k\) 处的值是 \(\cos(2\pi k) = 1.0000\)（对一切 \(k\)）；
    • 用无偏分母时，\(r(20k)/r(0) = 1.0000\)，即峰值与 \(r(0)\) 等高；
    • 换用有偏分母（除以 \(N\)）时，第 \(k\) 个峰的高度是 \(\frac{N - 20k}{N}\)， 会随 \(k\) 线性降低 ⚠

    另外，绝对数值上 \(r_{xx}(0) = A^2/2 = 2^2/2 = 2.0\)。

    这就是「在噪声里找周期」的全部原理：峰的位置给出周期， 与信号频率 \(f_0\) 满足 \(f_0 = f_s / P\)。

    例题 3：判断一条自相关是否合法¶

    题目：某同学算出一段数据的自相关（已去均值、统一除以 \(N\)），前几个值为

    \(m\) 0 1 2 3 4
    \(r(m)\) 1.00 0.85 1.12 0.40 0.21

    请指出问题，并给出最可能的两个原因。

    思路

    先做性质 1 的快速筛（比大小），再做性质 2 的快速筛（对称性）。

    哪一条明显被违反了？

    解答

    第一步：性质 1 检查。 \(r(0) = 1.00\) 是最大值，要求 \(\lvert r(m)\rvert \le 1.00\) 对一切 \(m\) 成立。但

    \[r(2) = 1.12 \gt 1.00\]

    违反了性质 1 ⚠

    第二步：性质 2 检查。 题里只给了正滞后，无法直接比对。 但如果这个序列是实信号，\(r(-2) = r(2) = 1.12\)，同样越界。

    第三步：找原因。 违反性质 1 几乎总是计算问题，不是数据问题。 最可能的两个原因，按可能性排序：

    1. 分母混用。这是最常见的。比如大滞后用 \(N - \lvert m\rvert\) 作分母， 而 \(r(0)\) 用 \(N\) 作分母。\(m = 2\) 时前者的分母比后者小， 商就偏大，于是出现「越界」。修法：全部统一除以同一个数。

    2. 归一化时除了错误的量。比如想让人看出「比值」， 却除了样本方差 \(\hat\sigma^2\) 而不是 \(r(0)\)。当 \(r(0)\) 与方差不等时， 算出的比值就可能大于 1（因为 \(r(0) = \hat\sigma^2 + \bar x^2 \ge \hat\sigma^2\)， 反过来除方差就会偏大）。

    ⚠ 注意：不要怀疑数据。 数据本身不可能让合法的自相关越界 —— 这条性质是恒成立的。看到越界，就要去代码里找。

    自测¶

    Q1：一个零均值平稳序列在 \(m = 0\) 处的自相关是 \(r(0) = 9.0\)。 如果它在某个滞后上取值为 \(r(m) = -9.5\)，这条自相关合法吗？为什么？

    参考答案

    不合法。

    性质 1 要求 \(\lvert r(m)\rvert \le r(0)\)。这里

    \[\lvert -9.5\rvert = 9.5 \gt 9.0 = r(0)\]

    被违反。

    关键点：性质 1 是恒成立的，数据本身不可能让它失效。 所以出现这种情况，一定是计算出了问题 —— 最常见的是分母混用（大滞后用 \(N - \lvert m\rvert\)，\(r(0)\) 用 \(N\)）， 其次是归一化时除错了对象。

    ⚠ 另外一个容易忽略的细节：负的超界和正的超界一样非法。 不要以为「负值就没事」。

    Q2：已知 \(x \sim N(0, 1)\)。分别取 \(y = x^2\) 和 \(y = x^3\)， 哪个是「不相关但不独立」的例子？为什么另一个反而不是？

    参考答案

    \(y = x^2\) 是「不相关但不独立」的例子；\(y = x^3\) 不是。

    判别方法：相关系数为零要求 \(\mathrm{Cov}(x, y) = 0\)， 也就是 \(\mathbb{E}\{xy\} - \mathbb{E}x \cdot \mathbb{E}y = 0\)。

    第一步：\(y = x^2\)。 因为 \(x\) 关于原点对称，\(x\) 的奇数阶矩都为 0，所以

    \[\mathbb{E}x = 0, \quad \mathbb{E}y = \mathbb{E}\{x^2\} = 1\]
    \[\mathbb{E}\{xy\} = \mathbb{E}\{x^3\} = 0\]

    于是

    \[\mathrm{Cov}(x, x^2) = 0 - 0 \times 1 = 0 \;\Longrightarrow\; \rho = 0\]

    相关系数为 0 ✓

    但 \(y\) 完全由 \(x\) 决定：知道 \(x\) 就等于知道 \(y\)，没有任何不确定性。 所以不独立 ✓

    第二步：\(y = x^3\)。 同样有 \(\mathbb{E}x = 0\)，而

    \[\mathbb{E}y = \mathbb{E}\{x^3\} = 0\]
    \[\mathbb{E}\{xy\} = \mathbb{E}\{x^4\} = 3 \quad (\text{正态分布的四阶矩})\]

    于是

    \[\mathrm{Cov}(x, x^3) = 3 - 0 \times 0 = 3 \ne 0\]

    相关系数不为零，所以 \(x\) 与 \(x^3\) 是线性相关的。 它不能作为「不相关但不独立」的例子。

    第三步：这个对比说明了什么。

    关系形式 相关系数 能否作为「不相关但不独立」的例子
    偶函数（如 \(x^2\)） \(0\) 可以 ✓
    奇函数（如 \(x^3\)） 非零 不可以 ⚠

    原因：偶函数是关于原点对称的。随着 \(x\) 从负走到正， \(y\) 先降后升，正相关段与负相关段恰好互相抵消， 净的线性相关系数就是 0。

    奇函数则是单调的（在整个区间上同增或同减）， 没有任何抵消，线性相关被完整地保留下来。

    ⚠ 实践提醒：构造「不相关但不独立」的例子时， 要用关于均值对称的非线性关系，否则相关系数不会归零。

    这也提醒了前面那句结论的分量：自相关 \(r(m)\) 只能检验线性关系。 数据里若有偶函数式的非线性依赖（平方、包络检波、整流等）， 自相关完全看不出来。

    Q3：为什么自相关必须满足非负定性？它保证了什么？如果违反会如何？

    参考答案

    为什么必须满足：因为自相关来自真实的随机过程。

    取任意系数 \(a_i\) 和时刻 \(t_i\)，构造线性组合 \(Y = \sum_i a_i x(t_i)\)。 它的模平方期望是

    \[\mathbb{E}\{\lvert Y\rvert^2\} = \sum_i\sum_j a_i a_j^{*} r_{xx}(t_i - t_j)\]

    而 \(\lvert Y\rvert^2 \ge 0\)，所以右式 \(\ge 0\)。 证明完成 —— 非负定不是外加限制，而是「自相关确实来自一个随机过程」的代数表现。

    保证了什么：它等价于自相关的傅里叶变换是非负的， 也就是说对应的功率谱密度 \(P_{xx}(\omega) \ge 0\)。

    违反会如何：

    • 自相关违反 → 它不对应任何真实信号，你的算法或模型有问题；
    • 功率谱违反 → 出现「负功率」，物理上荒谬 ⚠

    因为两者是傅里叶变换对，一边违反，另一边必然也违反。

    实践意义：性质 1 和性质 2 只是必要条件（快速筛子）， 非负定才是充分必要条件。 一个函数可以通过前两条检查而仍然非法 —— 这一点在正文里已经用 三角核的例子演示过了。

    Q4：为什么做自相关分析之前一定要先去均值？如果不去，会出现什么现象？

    参考答案

    原因：直流分量会在自相关里贡献一项常数。

    设 \(x(n) = m + x_0(n)\)，其中 \(m\) 是直流、\(x_0\) 是零均值部分。那么

    \[r_{xx}(m) = \mathbb{E}\{(m + x_0(n))(m + x_0(n+m))\} = m^2 + r_{00}(m)\]

    （交叉项为零，因为 \(x_0\) 的均值为零）

    所以不去均值的自相关 = 直流功率 \(m^2\) + 真实自相关。

    会出现什么现象：

    现象 说明
    \(r(0)\) 被显著抬高 正文实测中从 \(0.5955\) 涨到 \(25.5043\)，因为 \(5^2 = 25\) ⚠
    出现假的长程相关 \(m^2\) 这一项与 \(m\) 无关，隔多远都贡献同样的大小
    周期性被淹没 正文实测：去均值前完全看不到 20 点的周期峰
    相关时间被严重高估 衰减被常数项拖住，算出的 \(\tau_c\) 失去意义 ⚠

    结论：去均值是自相关分析的第一步，没有例外。

    这也正是本课程课件把自协方差（去均值）与自相关（不去均值） 并列列出的原因 —— 它们描述的是两件不同的事， 而做结构分析（找周期、估参数）时必须用前者。

    补充一句操作细节：去均值时用的是样本均值 \(\bar x\) 而不是真值 \(m\)， 这会给 \(r(m)\) 带来一个 \(O(1/N)\) 量级的微小偏差，数据越长影响越小 ✓

    小结¶

    要记住的 为什么
    \(r(0)\) 是最大值：\(\lvert r(m)\rvert \le r(0)\) 检查自相关是否合法的第一道筛子，越界就是代码错了 ✓
    \(r(0)\) 就是平均功率 从自相关直接读功率，不用另外算均方值 ✓
    \(r_{xx}(0) = \sigma_x^2 + m_x^2\) 把功率拆成「交流」和「直流」两部分
    实信号 \(r(m) = r(-m)\)（偶函数） 只算一半滞后，计算量减半 ✓
    复信号 \(r(-m) = r^{*}(m)\) 复信号不能照抄实信号的公式 ⚠
    周期信号的自相关同周期 峰间距就是信号周期，这是「噪声中找周期」的原理 ✓
    非负定 保证功率谱非负，是下一页维纳–辛钦定理的铺垫
    非负定是充要条件，性质 1、2 只是必要条件 通过前两条仍可能非法，只有非负定能一锤定音 ⚠
    \(r(m) = 0\)（\(m \ne 0\)）就是白序列 白噪声的判据，也是后面线性系统分析的常用前提 ✓
    不相关 ≠ 独立 只有联合高斯分布时两者才等价 ⚠
    相关时间 \(\tau_c\) 必须说明阈值 不说阈值的相关时间是没意义的数字 ⚠
    相关时间决定窗长、采样率、分块长度 把「衰减快慢」翻译成工程参数的桥梁 ✓
    先去均值，再算自相关 直流会制造假的长程相关，淹没真实结构 ⚠
    衰减极慢优先怀疑数据而非算法 含趋势/非平稳是真正常见的原因 ✓
    能量信号不除时长（\(r(0)\) 是能量），随机信号除时长（\(r(0)\) 是功率） 混用会导致量纲错误 ⚠
    分母必须一次性定死（本页默认除以 \(N\)） 只有统一分母，性质 1 才恒成立，才能当自动化判据 ✓
