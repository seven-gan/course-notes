    自相关函数的性质¶

    这一页只解决一个问题：拿到一条自相关函数，怎么一眼看出它算得对不对。

    上一页讲了自相关的定义：一个广义平稳序列 \(x(n)\) 的自相关是

    \[r_{xx}(m) = \mathbb{E}\{x(n)\,x^{*}(n+m)\}\]

    这个定义式本身不会告诉你「算出来的东西应该长什么样」。于是实际工作中最常见的一幕是： 你写完一段代码，画出一条自相关曲线，看着它好像挺像回事 —— 但它可能根本不可能 对应任何真实信号。比如它在某个滞后上的绝对值超过了 \(r(0)\)，或者它关于原点不对称。

    这一页要记的，就是这些「必然成立的规律」。 有了它们，自相关就不只是一个计算结果， 而是一个可以被检查的对象。

    先用一张表说清「没有性质」和「有性质」的差别：

    只会算自相关 记住性质之后
    拿到一条曲线 看着顺眼就信了 逐条对照，越界立刻警觉
    代码写错了 不知道错在哪，只能猜 多半能定位到分母、去均值或下标
    后面的谱估计 算出来的功率谱可能出现负值，还不知道为什么 知道这是非负定性被破坏的信号
    需要选参数时 凭经验拍一个窗长 用相关时间算出窗长该取多少 ✓

    数学表述 → 直觉解释 → 代码实跑验证。

    最后用一张「性质到用途」的对照表把它们串起来 —— 那张表才是这一页真正要带走的东西 ✓

    性质 2 \(r_{xx}(m) = r_{xx}(-m)\)（对称 / 偶函数） 本课程课件 ✓
    性质 3 \(r_{xx}(0)\) 与均方值、方差的关系 本课程课件 ✓

    下面从性质 1 开始。

    一、性质 1 与性质 3：\(r_{xx}(0)\) 是最大值，而且就是平均功率¶

    1.1 先看课件给的两行式子¶

    本课程课件在性质部分先写了两行：

    \[\sigma_x^2 = D_x = \mathbb{E}\big\{\big[x(n) - m_x\big]^2\big\} = r_{xx}(0) - m_x^2\]
    \[\mathbb{E}\{x^2(n)\} = r_{xx}(0)\]

    第一行说的是：方差等于 \(r_{xx}(0)\) 减去均值的平方。第二行说的是： 均方值就等于 \(r_{xx}(0)\)。

    这两行式子读起来像是废话，其实里面藏着三个不同的量。先把符号定义清楚， 这是后面所有讨论的地基：

    符号 读法 定义 单位（以电压为例）
    \(m_x\) 均值 \(\mathbb{E}\{x(n)\}\)，与 \(n\) 无关（平稳） 伏特 V
    \(r_{xx}(0)\) 自相关在原点 \(\mathbb{E}\{x(n)\,x(n)\} = \mathbb{E}\{x^2(n)\}\) 伏特平方 V²
    \(\sigma_x^2\) 方差 \(\mathbb{E}\{(x - m_x)^2\}\)，去均值后的均方值 伏特平方 V²
    \(D_x\) 同方差 与 \(\sigma_x^2\) 完全同一个量 伏特平方 V²

    关键观察：\(r_{xx}(0)\) 和 \(\sigma_x^2\) 量纲相同，数值不同， 差的就是直流分量的功率 \(m_x^2\)。

    把第一条式子移项就得到课件的第二条：

    \[r_{xx}(0) = \sigma_x^2 + m_x^2\]

    怎么读：原点处的自相关，等于「交流功率（方差）」加上「直流功率（均值平方）」。 这就是平均功率的含义 —— 如果 \(x(n)\) 是加在 1 欧姆电阻上的电压， 那么 \(r_{xx}(0)\) 的单位是 V²，数值上就等于这个信号的功率 ✓

    1.2 性质 1 的完整表述¶

    课件给出的第三条性质是一个不等式：

    \[r_{xx}(0) \ge \lvert r_{xx}(m)\rvert \quad \text{对一切 } m \text{ 成立}\]

    这里 \(m\) 取遍所有整数（正的、负的、零）。等号什么时候成立？ 这个问题很重要，先给结论，后面再验证：

    情形 等号成立吗 说明
    \(m = 0\) 一定成立 两边都是 \(r_{xx}(0)\)，这是恒等
    \(m \ne 0\) 通常不成立 只在信号有严格周期性时才会在某几个 \(m\) 上取等
    恒定信号 \(x(n) = c\) 对所有 \(m\) 都成立 因为 \(r_{xx}(m) = c^2\) 是常数 ⚠

    最后一行是个容易踩的坑：一条一直不变的信号（纯直流），它的自相关 在任意滞后上都等于 \(c^2\)，也就是处处取等。这说明不等式取等并不总是好消息， 它也可能意味着「这个信号里没有信息」。这一点和后面「衰减很慢说明有趋势」是同一个道理。

    1.3 五条性质总览¶

    前面把性质 1 和性质 3 讲完了，后面几节还有三条。先把五条放在一起看一遍， 有一个整体印象再往下走：

    图里是一条典型的指数衰减型自相关。它能一眼看出的东西有三样，正好对应五条性质里的前三条：

    • 曲线关于纵轴（\(m = 0\)）左右对称 —— 这是性质 2（偶函数）；
    • 最高点落在 \(m = 0\)，两边都更低 —— 这是性质 1（\(r(0)\) 最大）；
    • 最高点的高度就是这条序列的平均功率 —— 这是性质 3。

    后两条（非负定性、周期信号的周期性）在图上不容易直接看出来， 下面逐条用推导给出。

    读图提醒：图上画的是一条衰减型的自相关，这是最常见的情形。 但「最高点在原点」和「左右对称」这两条对任何实平稳序列都成立， 不管它衰减得快还是慢、也不管它有没有周期性。

    1.4 性质 1 的证明¶

    先把性质 1 证一遍。结论是

    \[r_{xx}(0) \ge \lvert r_{xx}(m)\rvert \quad \text{对一切整数 } m \text{ 成立}\]

    证明的思路：不去直接比较两个自相关值，而是构造一个必然非负的期望值， 再从它导出不等式。这个套路在随机信号里反复出现，值得记牢。

    第一步，任取一个非负的随机变量。对任意整数 \(m\)，考虑

    \[Y = x(n) \pm x(n+m)\]

    它的平方恒非负：

    \[Y^2 = \big[x(n) \pm x(n+m)\big]^2 \ge 0\]

    依据：任何实数的平方都不小于零，这一步与具体的信号无关。

    第二步，取期望。因为 \(Y^2 \ge 0\) 是逐点成立的， 取期望之后仍然非负（期望是加权平均，不改变符号）：

    \[\mathbb{E}\big\{Y^2\big\} \ge 0\]

    依据：期望的单调性 —— 若 \(\xi \ge 0\) 逐点成立，则 \(\mathbb{E}\{\xi\} \ge 0\)。

    第三步，把括号展开。用完全平方公式：

    \[Y^2 = x^2(n) + x^2(n+m) \pm 2\,x(n)x(n+m)\]

    第四步，逐项取期望。由广义平稳性，\(\mathbb{E}\{x^2(n)\}\) 与 \(n\) 无关， 而 \(x(n+m)\) 与 \(x(n)\) 是同分布的，所以前两项相等：

    \[\mathbb{E}\big\{x^2(n)\big\} = \mathbb{E}\big\{x^2(n+m)\big\} = r_{xx}(0)\]

    依据：平稳性保证「同分布」，所以二阶矩相同。

    第三项的期望正是自相关的定义：

    \[\mathbb{E}\big\{x(n)\,x(n+m)\big\} = r_{xx}(m)\]

    第五步，合并。两步合起来得到

    \[\mathbb{E}\big\{Y^2\big\} = r_{xx}(0) + r_{xx}(0) \pm 2\,r_{xx}(m) = 2\big[r_{xx}(0) \pm r_{xx}(m)\big]\]

    第六步，用第二步的结论。因为 \(\mathbb{E}\{Y^2\} \ge 0\)， 所以括号里的量非负：

    \[r_{xx}(0) \pm r_{xx}(m) \ge 0\]

    第七步，解出结论。上式对正负号都成立，于是同时有

    \[r_{xx}(m) \ge -r_{xx}(0), \qquad r_{xx}(m) \le r_{xx}(0)\]

    两个不等式合并，就是一条式子：

    \[\boxed{\lvert r_{xx}(m)\rvert \le r_{xx}(0)}\]

    证明完成。 用到的只有三件事：平方非负、期望非负、平稳性。

    这一步说明什么：\(r_{xx}(0)\) 是所有滞后上的上界， 而且这个上界是自相关自身给出的，不需要外部信息。 所以拿到一条算出来的自相关，第一个动作就是拿每个 \(r(m)\) 和 \(r(0)\) 比绝对值。 越界了就去查代码，不要怀疑数据 —— 这条不等式对真实信号恒成立。

    等号什么时候取到：从证明看，等号成立要求 \(\mathbb{E}\{Y^2\} = 0\)。 由于 \(Y^2\) 非负，这等价于 \(Y = x(n) \pm x(n+m)\) 几乎处处为零， 也就是 \(x(n+m) = \mp x(n)\)。两种情形：

    取等条件 信号形态 结论
    \(x(n+m) = x(n)\) 信号以 \(m\) 为周期（或恒定） 合法，是性质 4 的来源 ✓
    \(x(n+m) = -x(n)\) 信号每 \(m\) 点反相（如半个周期） 此时 \(r(m) = -r(0)\)，是负的最大值 ⚠

    第二行是个反直觉的地方：等号不只在「正的最大值」处取到， 也可能在「负的最大值」处取到。例如纯正弦信号，在恰好半个周期处的自相关就是 \(-A^2/2\)，等于 \(-r(0)\) ✓ 所以绝对值符号不能丢。

    1.5 性质 3 的证明：\(r(0) = \sigma^2 + \mu^2\)¶

    性质 3 说原点处的自相关等于平均功率。它也可以一步步推出来， 而且只用到期望的线性性。

    第一步，设均值与方差。记

    \[\mu = \mathbb{E}\{x(n)\}, \qquad \sigma^2 = \mathbb{E}\big\{\big[x(n) - \mu\big]^2\big\}\]

    依据：平稳性保证这两个量都与 \(n\) 无关。

    第二步，把方差展开。用完全平方公式：

    \[\sigma^2 = \mathbb{E}\big\{x^2(n) - 2\mu\,x(n) + \mu^2\big\}\]

    第三步，逐项取期望。用期望的线性性（和的期望等于期望的和）：

    \[\sigma^2 = \mathbb{E}\big\{x^2(n)\big\} - 2\mu\,\mathbb{E}\{x(n)\} + \mu^2\]

    依据：\(\mu\) 是常数，可以提到期望外面。

    第四步，代入两个已知量。\(\mathbb{E}\{x(n)\} = \mu\)， 而 \(\mathbb{E}\{x^2(n)\} = r_{xx}(0)\)（这正是 \(r(0)\) 的定义）

    \[\sigma^2 = r_{xx}(0) - 2\mu \cdot \mu + \mu^2 = r_{xx}(0) - 2\mu^2 + \mu^2\]

    第五步，合并同类项：

    \[\sigma^2 = r_{xx}(0) - \mu^2\]

    第六步，移项，得到要证的式子：

    \[\boxed{r_{xx}(0) = \sigma^2 + \mu^2}\]

    证明完成。

    这一步说明什么：原点处的自相关把信号功率拆成了两块 —— 交流功率（方差 \(\sigma^2\)）和直流功率（均值平方 \(\mu^2\)）。 这两块的性质完全不同：交流部分是信息，直流部分往往只是偏置。

    推论很实用：去均值之后 \(\mu = 0\)，于是 \(r(0) = \sigma^2\)。 这正是后面「做自相关分析必须先去掉直流」的数学依据 —— 不去均值时 \(r(0)\) 里混着一项 \(\mu^2\)，它会把真实结构掩盖掉。

    两条性质的分工

    性质 1 回答「数值够不够小」，性质 3 回答「这个数值是什么意思」。

    • 性质 1 给出上界，是一个检查用的判据；
    • 性质 3 给出物理含义，是一个读数用的公式。

    两条合起来，才算真正读懂了 \(r(0)\)：它不仅必须是最大值， 而且那个最大值有一个明确的物理意义 —— 平均功率 ✓

    题目：已知一段零均值实序列的 4 个采样值

    \(n\) 0 1 2 3
    \(x(n)\) 1 2 3 4

    用有偏分母（除以 \(N = 4\)）求 \(r(0)\)、\(r(1)\)、\(r(2)\)、\(r(3)\)， 并验证性质 1。

    解答

    第一步：先去掉均值。 \(x\) 的均值是 \(\frac{1+2+3+4}{4} = 2.5\)， 所以把每个数减掉 2.5：

    \(n\) 0 1 2 3
    \(x(n)\) \(-1.5\) \(-0.5\) \(0.5\) \(1.5\)

    依据：性质 3 要求 \(r(0) = \sigma^2\)，只有零均值时才直接成立。

    第二步：算 \(r(0)\)。 分母固定为 \(N = 4\)，求和项数是 4：

    \[r(0) = \frac{1}{4}\big[(-1.5)^2 + (-0.5)^2 + 0.5^2 + 1.5^2\big] = \frac{2.25 + 0.25 + 0.25 + 2.25}{4} = \frac{5.00}{4} = 1.25\]

    第三步：算 \(r(1)\)。 滞后 1 时求和项数是 \(N - 1 = 3\) 项， 但分母仍然除以 \(N = 4\)（这是有偏分母的关键）：

    \[r(1) = \frac{1}{4}\big[x(0)x(1) + x(1)x(2) + x(2)x(3)\big]\]

    逐项乘出来：

    \[x(0)x(1) = (-1.5)(-0.5) = 0.75\]
    \[x(1)x(2) = (-0.5)(0.5) = -0.25\]
    \[x(2)x(3) = (0.5)(1.5) = 0.75\]

    三项相加得 \(0.75 - 0.25 + 0.75 = 1.25\)，于是

    \[r(1) = \frac{1.25}{4} = 0.3125\]

    第四步：算 \(r(2)\)。 求和项数是 2：

    \[x(0)x(2) = (-1.5)(0.5) = -0.75, \qquad x(1)x(3) = (-0.5)(1.5) = -0.75\]
    \[r(2) = \frac{-0.75 - 0.75}{4} = \frac{-1.50}{4} = -0.375\]

    第五步：算 \(r(3)\)。 只剩一项：

    \[x(0)x(3) = (-1.5)(1.5) = -2.25 \quad\Longrightarrow\quad r(3) = \frac{-2.25}{4} = -0.5625\]

    第六步：整理成表并验证。

    \(m\) 0 1 2 3
    \(r(m)\) \(1.2500\) \(0.3125\) \(-0.3750\) \(-0.5625\)
    \(\lvert r(m)\rvert / r(0)\) \(1.0000\) \(0.2500\) \(0.3000\) \(0.4500\)

    比值全部不超过 1，性质 1 通过 ✓

    这说明什么：三点结论。

    1. 分母在整个计算中一次也没有变过，永远是 4。变的只是求和项数。 这就是「统一分母」的操作含义 —— 也是手算时最容易写错的地方 ⚠
    2. 随着 \(m\) 增大，比值在 \(0.25\) 到 \(0.45\) 之间，始终远小于 1。 这条数据没有明显的周期性，自相关在递减。
    3. \(r(3)\) 只剩一项乘积，它的绝对值仍然小于 \(r(0)\)。 即使滞后接近数据长度，性质 1 依然成立 —— 这不是巧合， 而是有偏分母的直接结果。

    手算时最容易错的两处

    第一处：算了去均值却仍用原始公式的分母。去均值只改数值，不改分母， 分母始终是 \(N\)。

    第二处：把求和项数当成分母。\(r(1)\) 只有 3 项相加， 但分母是 4 而不是 3。写成 \(\frac{1.25}{3}\) 就变成了无偏分母， 性质 1 随之失效 ⚠

    1.7 分母约定与手算对照表¶

    在讨论具体数值之前，必须先确定一件事：分母到底用什么。 这是一个绕不开的选择，而且必须先说清楚，否则后面的数字都不可比。

    有限长数据 \(x(0), x(1), \dots, x(N-1)\) 的自相关估计有两种常见写法：

    写法 公式 性质
    有偏估计 \(\hat r_b(m) = \dfrac{1}{N}\sum_{n=0}^{N-\lvert m\rvert-1} x(n)x(n+m)\) 有偏，但恒有 \(\lvert \hat r_b(m)\rvert \le \hat r_b(0)\) ✓
    无偏估计 \(\hat r_u(m) = \dfrac{1}{N-\lvert m\rvert}\sum_{n=0}^{N-\lvert m\rvert-1} x(n)x(n+m)\) 无偏，但不保证上述不等式 ⚠

    本页代码中的分母约定：除了下面这一组专门对比两种分母差异的代码， 以及纯正弦的例子（那里为了命中解析式 \(A^2/2\cdot\cos\)，用无偏分母）之外， 全部采用「有偏」写法，统一除以 \(N\)。这样做的理由有三条：

    1. 课件在讲自相关估计时给出的实用公式，就是把求和项数换成 \(N\) 的那一版； 课件同时指出它是有偏但渐进无偏的，并且当数据很长时可以用 FFT 快速计算。

    3. 分母混用是自相关这一节最典型的错误来源，第八节会用一段代码演示它 如何把一条合法的自相关变成不合法的 ⚠

    二、性质 2：实信号的自相关是偶函数¶

    2.1 数学表述与两行推导¶

    课件给出的第二条性质写成：

    \[r_{xx}(m) = r_{xx}(-m)\]

    课件把自协方差也并列写出：\(\mathrm{cov}_{xx}(m) = \mathrm{cov}_{xx}(-m)\)。 两个结论完全平行，因为自协方差只是去均值后的自相关。

    这条性质不需要「显然可得」，两行就能推完，而且推导本身很值得看一遍：

    第一步，写出定义。由广义平稳，\(r_{xx}(m)\) 只与间隔有关：

    \[r_{xx}(m) = \mathbb{E}\{x(n)\,x(n+m)\}\]

    第二步，把指标整体平移。令 \(n' = n + m\)。因为过程是平稳的， 期望不依赖于时间起点，所以可以把整段求和（求期望）重新从 \(n'\) 起算：

    \[r_{xx}(m) = \mathbb{E}\{x(n'-m)\,x(n')\}\]

    第三步，利用期望里乘积可交换顺序（标量乘法交换律）：

    \[r_{xx}(m) = \mathbb{E}\{x(n')\,x(n'-m)\} = r_{xx}(-m)\]

    最后一步用的还是定义：\(\mathbb{E}\{x(n')x(n'-m)\}\) 里两个样本的间隔是 \(n' - (n'-m) = m\) 的相反数，即间隔为 \(-m\)。

    怎么读：整个推导只用了两件事 ——平稳性和实数乘法可交换。 平稳性用来允许「平移指标」，交换律用来把两个因子的顺序调过来。 这也解释了为什么复信号的情形不同：复数乘法不可交换，所以会多出一个共轭。

    2.2 直觉：相关的方向不重要，只看间隔¶

    把 \(x(n)\) 想成一段时间序列。\(r_{xx}(m)\) 问的是：「隔 \(m\) 个采样点， 两个样本有多像？」

    • 从第 10 个点往后看，看第 \(10+m\) 个点，得到的相似度是 \(r_{xx}(m)\)；
    • 从第 \(10+m\) 个点往前看，看第 10 个点，得到的相似度是 \(r_{xx}(-m)\)。

    「往后看」和「往前看」是同一对样本，只是换了个说法。所以两个数必须相等 ✓

    一句话总结：相关的方向不重要，只看间隔的大小。

    2.4 复信号的情形：不要照抄这条性质¶

    复信号必须是共轭对称

    实信号的偶函数性质，到复信号这里要改写成共轭对称：

    \[r_{xx}(-m) = r_{xx}^{*}(m)\]

    原因就是上面推导的第三步失效了。复数的乘法不满足交换律， 而且定义式里第二个因子带共轭：

    \[r_{xx}(m) = \mathbb{E}\{x(n)\,x^{*}(n+m)\}\]

    把两个因子换位时，共轭会跑到另一个因子上去，于是多出一个共轭号。

    如果你在做通信或雷达的信号处理，数据往往是复基带信号， 这里写错会一路错到功率谱。

    一个快速的判别方法：如果算出的 \(r_{xx}(m)\) 是复数，那它就不可能满足 \(r_{xx}(-m) = r_{xx}(m)\)，只能是共轭相等 ⚠

    三、性质 4：周期信号的自相关仍是同周期函数¶

    3.1 这条性质不在课件的三条里¶

    先说清来源：这一节和之后的三节都是本页补充的内容， 用来把课件那三条性质补成一个能实际工作的工具集 ⚠

    3.2 数学表述¶

    设 \(x(n)\) 是一个周期为 \(P\) 的（广义平稳）序列，即 \(x(n + P) = x(n)\) 对所有 \(n\) 成立。 那么它的自相关满足

    \[r_{xx}(m + P) = r_{xx}(m)\]

    也就是说，自相关也是周期为 \(P\) 的周期函数。

    两行推导：

    \[r_{xx}(m + P) = \mathbb{E}\{x(n)\,x(n + m + P)\} = \mathbb{E}\{x(n)\,x(n+m)\} = r_{xx}(m)\]

    中间那一步用的就是周期性 \(x(n+m+P) = x(n+m)\)。

    怎么读：自相关把「相位」这个信息丢掉了，但把「周期」这个信息完整地保留了下来。 这正是它能在噪声里找周期的原因 ✓

    3.3 正弦信号：可以算出解析答案¶

    最简单也最常用的例子是正弦：

    \[x(n) = A\sin(2\pi f_0 n / f_s + \varphi)\]

    它的自相关（在无限长时间意义下）是

    \[r_{xx}(m) = \frac{A^2}{2}\cos\!\left(\frac{2\pi f_0 m}{f_s}\right)\]

    这里 \(f_0\) 是信号频率、\(f_s\) 是采样率，所以 \(f_s / f_0\) 就是每个信号周期有几个采样点。

    怎么读：自相关是一个同频率的余弦，振幅是 \(A^2/2\)。

    • 峰值出现在 \(\frac{2\pi f_0 m}{f_s} = 2\pi k\)，即 \(m = k \cdot \frac{f_s}{f_0}\)；
    • 相邻峰值的间距正好是一个信号周期 ✓

    所以只要在自相关上量一下峰间距，就能反推出信号周期。这就是「在噪声里找周期」的标准做法。

    15 \(3\pi/2\) \(0.0000\) 过零
    20 \(2\pi\) \(1.0000\) 峰 ✓
    25 \(5\pi/2\) \(0.0000\) 过零
    30 \(3\pi\) \(-1.0000\) 谷 ⚠
    40 \(4\pi\) \(1.0000\) 峰 ✓

    把这张表读出来就是结论：

    • 正峰出现在 \(m = 0, 20, 40\)，峰间距 \(20\) 点；
    • 而信号周期恰好是 \(20\) 点 —— 两者完全一致；
    • 中间还有负峰（谷）在 \(m = 10, 30\)，间距也是 \(20\) 点。

    从峰值反推频率：设量得峰间距为 \(P\) 点，则 \(f_0 = f_s / P\)。 代入 \(P = 20\)、\(f_s = 1000\) Hz，得 \(f_0 = 50\) Hz ✓ 与题设一致。

    绝对幅度：\(r(0) = A^2/2 = 2^2/2 = 2.0\)。

    这说明什么：自相关把相位丢掉了，但把周期完整保留了下来。 所以「找周期」这件事不需要知道信号从哪个相位开始 —— 只需要量峰间距。 这就是在噪声里找周期的全部原理，也是性质 4 的实用价值所在。

    别把负峰当成没有周期性

    上表里 \(m = 10\) 处的值是 \(-1.0000\)，是一个负的极大值。 它同样是周期性的证据，不是「信号不相关」⚠

    判断周期要看峰与峰的间距，而不是只看某个值正不正。 如果只盯着 \(m = 10\) 看到负值就下结论，就会漏掉 20 点的周期。

    更稳妥的做法是看绝对值 \(\lvert r(m)\rvert\) 的峰间距， 它在正峰和负峰处都会出现，间距仍然是 20 点 ✓

    自相关看不出相位

    自相关里没有相位信息：\(x(n)\) 和 \(x(n + 1000)\)（前者整体平移）有完全相同的自相关。

    所以在自相关上只能读出「周期是多少」「相似度随间隔如何衰减」， 读不出「从哪个时刻开始」 ⚠

    需要相位信息时，得回到原信号，或者用互相关（与一个已知参考信号作相关）。

    四、性质 5：非负定性¶

    4.1 表述¶

    这是一条形式上最「重」、但意义最深远的一条：自相关函数是（半）正定的。

    数学表述：对任意有限个时刻 \(t_1, t_2, \dots, t_K\) 和任意一组复数系数 \(a_1, a_2, \dots, a_K\)，都有

    \[\sum_{i=1}^{K}\sum_{j=1}^{K} a_i\,a_j^{*}\,r_{xx}(t_i - t_j) \;\ge\; 0\]

    怎么读：把 \(r_{xx}(t_i - t_j)\) 排成一个 \(K \times K\) 的矩阵

    \[\mathbf{R} = \begin{bmatrix} r_{xx}(0) & r_{xx}(t_1 - t_2) & \cdots \\ r_{xx}(t_2 - t_1) & r_{xx}(0) & \cdots \\ \vdots & \vdots & \ddots \end{bmatrix}\]

    这条性质就是说：这个矩阵对一切取值时刻都是半正定的。

    4.2 它为什么必然成立¶

    证明只有三行，而且非常漂亮，值得看一遍 —— 因为它顺便解释了非负定性到底在说什么。

    考虑一个由系数 \(a_i\) 和信号 \(x(t)\) 构成的线性组合：

    \[Y = \sum_{i=1}^{K} a_i\,x(t_i)\]

    这是一个随机变量。现在看它的模平方的期望：

    \[\mathbb{E}\{\lvert Y\rvert^2\} = \mathbb{E}\Big\{\Big(\sum_i a_i x(t_i)\Big)\Big(\sum_j a_j x(t_j)\Big)^{*}\Big\} = \sum_i\sum_j a_i a_j^{*}\,\mathbb{E}\{x(t_i)x^{*}(t_j)\}\]

    最后一步把期望移进双重求和，并用上定义式 \(\mathbb{E}\{x(t_i)x^{*}(t_j)\} = r_{xx}(t_i - t_j)\)。

    于是得到关键的等式：

    \[\mathbb{E}\{\lvert Y\rvert^2\} = \sum_i\sum_j a_i a_j^{*}\, r_{xx}(t_i - t_j)\]

    而 \(\lvert Y\rvert^2 \ge 0\) 恒成立，所以它的期望也 \(\ge 0\)。 证明完成。

    怎么读：非负定性不是一条外加的限制，而是「自相关本身来自一个真实的随机过程」 这件事的代数分身。任何真实信号生成的自相关，都自动满足它；

    反过来，任何不满足它的函数，都不可能由任何真实信号生成。这才是它的全部威力 ✓

    4.3 它的意义：保证功率谱非负¶

    非负定性在数学上等价于一句话：

    它的傅里叶变换是非负的。

    也就是当 \(\mathbf{R}\) 是半正定矩阵时，对应的功率谱密度满足 \(P_{xx}(\omega) \ge 0\) 对一切 \(\omega\) 成立。

    这为什么重要：功率谱的物理含义是「信号在某个频率上的功率密度」， 功率不可能是负的。所以功率谱非负这条要求是硬性的物理约束。 而它恰恰等价于自相关的非负定性 ✓

    这一步正是下一页「自相关与功率谱」（维纳–辛钦定理）的铺垫： 只要自相关满足非负定性，它对应的谱就一定是一个合法的功率谱。

    自相关衰减的快慢与谱的宽窄是一一对应的。 下面这张图把一对自相关与功率谱 画在一起（同一个一阶自回归模型，横轴是数字角频率）：

    读图：三条曲线对应三组不同的参数。自相关衰减越慢，谱就越窄越高； 反过来，自相关衰减越快，谱就越宽越平。

    这正好印证了非负定性的两个侧面：

    • 自相关这边非负定 ⟺ 谱那边处处非负 ✓
    • 自相关这边衰减慢（记忆长）⟺ 谱那边能量集中在低频 ✓

    这说明什么：自相关与功率谱不是两个独立的对象，而是同一个信息的两种表示。 所以只要能验证其中一边，另一边的合法性就自动成立了 —— 这就是后面判定功率谱是否合理时，可以回到自相关来检查的原因。

    检查对象 检查内容 违反的后果
    自相关 \(r_{xx}(m)\) 非负定 它不对应任何真实信号
    功率谱 \(P_{xx}(\omega)\) 非负 出现「负功率」，物理上荒谬 ⚠
    两者关系 互为傅里叶变换 一边违反，另一边必然也违反

    4.4 手算验证：三角核为什么非法¶

    非负定性最容易被误解成「随便造一个像样的函数就行」。这里手算一个反例， 把「偶函数 + 原点最大」并不够这件事算到具体的数字上。

    题目：考察下面这个「三角核」函数

    \(m\) 0 \(\pm 1\) 其他
    \(r(m)\) \(1.0\) \(0.9\) \(0\)

    它显然满足性质 1（\(0.9 \le 1.0\)）和性质 2（\(r(1) = r(-1)\)）。 问它是不是一个合法的自相关函数。

    解答

    第一步：取时刻与系数。 取 \(K = 3\) 个时刻 \(t_1 = 0\)、\(t_2 = 1\)、\(t_3 = 2\)， 系数取

    \[a_1 = 1, \qquad a_2 = -2, \qquad a_3 = 1\]

    依据：非负定要求对任意系数组都非负。只要能找到一组使二次型为负的系数， 它就非法。所以这里是在构造反例，而不是证明性质。

    第二步：写出需要算的二次型。 由 4.1 小节的表述

    \[Q = \sum_{i=1}^{3}\sum_{j=1}^{3} a_i a_j\, r(t_i - t_j)\]

    第三步：列出所有 \(t_i - t_j\) 的值。

    \(i \backslash j\) \(j=1\)（\(t=0\)） \(j=2\)（\(t=1\)） \(j=3\)（\(t=2\)）
    \(i=1\)（\(t=0\)） \(0\) \(-1\) \(-2\)
    \(i=2\)（\(t=1\)） \(1\) \(0\) \(-1\)
    \(i=3\)（\(t=2\)） \(2\) \(1\) \(0\)

    第四步：查表把每个 \(r(t_i - t_j)\) 换成数值。 注意 \(\lvert m\rvert \ge 2\) 时是 \(0\)：

    \(i \backslash j\) \(j=1\) \(j=2\) \(j=3\)
    \(i=1\) \(1.0\) \(0.9\) \(0\)
    \(i=2\) \(0.9\) \(1.0\) \(0.9\)
    \(i=3\) \(0\) \(0.9\) \(1.0\)

    依据：\(r(0) = 1.0\)、\(r(\pm 1) = 0.9\)、\(\lvert m\rvert \ge 2\) 时为 \(0\)。

    第五步：逐项乘系数再求和。 把 \(a_i a_j\) 与上表相乘：

    \[Q = (1)(1)(1.0) + (1)(-2)(0.9) + (1)(1)(0)\]
    \[+ (-2)(1)(0.9) + (-2)(-2)(1.0) + (-2)(1)(0.9)\]
    \[+ (1)(1)(0) + (1)(-2)(0.9) + (1)(1)(1.0)\]

    逐项算出来是

    \[Q = 1.0 - 1.8 + 0 - 1.8 + 4.0 - 1.8 + 0 - 1.8 + 1.0\]

    第六步：合并。

    \[Q = 1.0 + 4.0 + 1.0 - 4 \times 1.8 = 6.0 - 7.2 = -1.2\]
    \[\boxed{Q = -1.2 < 0}\]

    结论：三角核不是合法的自相关函数。 它通过了性质 1 和性质 2 的检查， 但存在一组系数使二次型为负，所以它不可能由任何真实信号生成 ⚠

    这说明什么：三点区分，非常重要。

    检查项 类型 本反例表现
    性质 1（\(\lvert r(m)\rvert \le r(0)\)） 必要条件 通过 ✓
    性质 2（偶函数） 必要条件 通过 ✓
    性质 5（非负定） 充要条件 不通过 ✗

    性质 1 和性质 2 只是快速筛子，非负定才是一锤定音的判据。 一个函数可以同时满足前两条而依然非法 —— 上面这 6 行算术就是全部证据。

    工程上的用法：要检查一条算出来的自相关是否合法， 就把 \(r(t_i - t_j)\) 排成矩阵，看它是不是半正定（最小特征值是否非负）。 矩阵一旦出现负特征值，这条自相关就不可能对应真实信号。

    检查方式 做法 何时使用
    快速筛 比 \(\lvert r(m)\rvert\) 与 \(r(0)\) 每次算完都做，几秒钟
    快速筛 比对 \(r(m)\) 与 \(r(-m)\) 每次算完都做，几秒钟
    完整判据 构造自相关矩阵，看是否半正定 前两项可疑、或要做谱估计之前 ✓

    必要条件不等于充分条件

    性质 1 和性质 2 都只是必要条件。通过了它们， 只说明这条函数「看起来像」自相关，不能说明它合法 ⚠

    这就像「人是哺乳动物」是必要条件 —— 满足它不代表就一定是人。 本节的三角核就是反例：它满足两条必要条件， 却被一组具体的系数（\(1, -2, 1\)）当场证伪。

    只有非负定性是充要条件。要做严格判断，就得算矩阵的半正定性 ✓

    三条性质的分工

    把性质 1、2、5 放在一起看，它们的检查强度是不同的：

    性质 类型 检查难度
    性质 1：\(\lvert r(m)\rvert \le r(0)\) 必要条件 一眼就能看出（比大小）
    性质 2：\(r(m) = r(-m)\) 必要条件 一眼就能看出（对称性）
    性质 5：非负定 充分必要 需要算矩阵特征值或谱

    前两条是快速筛子：几秒钟就能查完，能挡住大部分手算错误和代码错误。 第三条是完备判据：通过前两条的函数仍可能是假的，只有非负定能一锤定音 ✓

    实践中的用法就是：先用前两条快速筛，可疑时再用第三条复查。

    五、性质 6：不相关与白序列¶

    5.1 数学表述¶

    如果自相关满足

    \[r_{xx}(m) = 0 \qquad (m \ne 0)\]

    就称这个序列是不相关的（uncorrelated）。因为 \(r(0) > 0\)， 所以此时自相关是一个冲激（在离散情形下就是克罗内克 \(\delta\)）：

    \[r_{xx}(m) = \sigma_x^2 \,\delta(m), \qquad \delta(m) = \begin{cases} 1, & m = 0 \\ 0, & m \ne 0 \end{cases}\]

    怎么读：\(r_{xx}(m) = 0\) 的含义是「隔 \(m\) 个采样点取样，两个样本之间没有任何线性关系」。 换句话说 —— 当前值对预测下一个值毫无帮助。

    具有这种自相关函数的零均值序列，就称为白序列（白色噪声，white noise）✓

    5.2 课件在这里给过的伏笔¶

    本课程课件在讲「平稳随机序列通过线性系统」时，专门算过白噪声输入的情形： 当输入为白噪声、方差为 \(\sigma^2\) 时，输出的自相关函数正比于系统脉冲响应的自相关。 那一节用的正是 \(r_{xx}(k) = \sigma^2 \delta(k)\) 这个前提。

    也就是说，白噪声这个假设在课程里不是可有可无的装饰， 而是后面推导滤波器输出统计特性时的核心前提 ✓ 所以在自相关性质这一节把「白噪声的判据」讲清楚，是必要的一步。

    5.3 手算对照：白噪声判据怎么用¶

    白噪声的理论自相关是一个冲激：\(r_{xx}(m) = \sigma_x^2\,\delta(m)\)， 除 \(m = 0\) 外处处为零。但手算有限长数据时，得到的不会是精确的零。 下面把这件事用手算量级说清楚。

    第一步：估一下波动的量级。 用有偏分母 \(\hat r(m) = \frac{1}{N}\sum x(n)x(n+m)\)。 当 \(m \ne 0\) 时，求和里的每一项都是两个不相关的随机数之积， 它们的均值是 \(0\)，方差是 \(\sigma^4\)。\(N\) 项相加再除以 \(N\)，于是

    \[\mathrm{Var}\big\{\hat r(m)\big\} \approx \frac{N\sigma^4}{N^2} = \frac{\sigma^4}{N}\]

    依据：独立同分布变量求和的方差等于方差之和。

    第二步：取标准差。 归一化之后（除以 \(r(0) \approx \sigma^2\)），波动量级是

    \[\frac{\sqrt{\sigma^4/N}}{\sigma^2} = \frac{1}{\sqrt{N}}\]

    这就是那条最常用的经验公式：白噪声自相关的波动量级约为 \(1/\sqrt{N}\)。

    第三步：代入一个具体的 \(N\)。 取 \(N = 1024\)，则

    \[\frac{1}{\sqrt{1024}} = \frac{1}{32} = 0.031\]

    第四步：和典型观测值对照。 实际手算（或算完看结果）时， \(m \ne 0\) 处会看到这样的量级：

    滞后 \(m\) \(r(m)/r(0)\) 典型量级 与 \(1/\sqrt{N} = 0.031\) 比较 判断
    0 \(1.0000\) — 恒为 1 ✓
    1\(\sim\)5 约 \(0.0 \sim 0.09\) 一般不超过 \(2\sim3\) 倍 白噪声 ✓
    任意 \(m \ne 0\) 大多在 \(\pm 0.03\) 内 标准差量级 白噪声 ✓

    第五步：给出判据。 结论写成一句话：

    看 \(m \ne 0\) 处的值是否「普遍地」远小于 \(r(0)\)， 而不是要求它们精确等于 0。

    这说明什么：三点，都很实际。

    1. 不要要求精确为零。有限长估计必然有波动，量级就是 \(1/\sqrt{N}\)。 看到 \(m = 1\) 处有个 \(0.088\) 就说「这不是白噪声」，是过度解读 ⚠
    2. 要看的是「普遍性」。个别滞后偶尔超出 2 倍标准差是正常的； 但如果十几个滞后都稳稳地超出 \(1/\sqrt{N}\) 好几倍，那才是真信号。
    3. \(N\) 越大，判据越灵敏。\(N = 1024\) 时阈值量级是 \(0.031\)； 若 \(N = 100\)，阈值涨到 \(0.1\)，同样的真实相关性就更难被发现 —— 这是数据长度换分辨率的老问题 ✓

    白噪声判据的实用口诀

    记住一个数就够了：波动量级 \(= 1/\sqrt{N}\)。

    拿到一段数据的自相关，先算 \(1/\sqrt{N}\)， 再看 \(m \ne 0\) 的值有没有成片地超过它两三倍。 没有 → 判为白噪声；有 → 存在真实的相关结构 ✓

    这个口诀不需要跑代码，口算就能给出判据的阈值。

    5.4 手算对照：白噪声与有色噪声的衰减速度¶

    把白噪声和有色噪声放在一起手算，判据就一目了然了。

    有色噪声用一阶自回归（AR(1)）模型，它的理论自相关是几何级数：

    \[r_{yy}(m) = r_{yy}(0)\,a^{\lvert m\rvert}\]

    依据：由 \(y(n) = a\,y(n-1) + e(n)\) 两边同乘 \(y(n-m)\) 再取期望即得。

    两边同除 \(r_{yy}(0)\)，得到归一化形式 \(a^{\lvert m\rvert}\)。取 \(a = 0.9\)， 逐点手算（\(0.9^m\) 就是连乘 \(m\) 次 \(0.9\)）：

    滞后 \(m\) \(a^m = 0.9^m\) 手算过程 归一化 \(r(m)/r(0)\)
    0 约定为 1 \(1.0000\)
    1 \(0.9\) \(0.9000\)
    2 \(0.9 \times 0.9 = 0.81\) \(0.8100\)
    3 \(0.81 \times 0.9 = 0.729\) \(0.7290\)
    4 \(0.729 \times 0.9 = 0.6561\) \(0.6561\)
    5 \(0.6561 \times 0.9 = 0.5905\) \(0.5905\)
    6 \(0.5905 \times 0.9 = 0.5314\) \(0.5314\)
    10 继续连乘到 \(m = 10\) \(0.3487\)

    关键的一步是找 \(1/2\) 点。 逐点对照上表，\(0.9^m\) 第一次落到 \(0.5\) 以下是

    \[0.9^6 = 0.5314 > 0.5, \qquad 0.9^7 = 0.4783 < 0.5\]

    所以 \(1/2\) 判据下的相关时间约为 \(7\) 个采样点。而 \(1/e\) 判据要求降到 \(0.3679\)：

    \[0.9^{10} = 0.3487 < 0.3679 \quad\Longrightarrow\quad \tau_c = 10 \text{ 个采样点}\]

    手算结果与解析式对照：\(-\frac{1}{\ln 0.9} = -\frac{1}{-0.10536} = 9.49\)， 取整为 \(10\) ✓ 与逐点手算完全一致。

    白噪声那一列：由 5.3 小节，\(m \ne 0\) 时波动量级是 \(1/\sqrt{N}\)。 取 \(N = 1024\)，就是 \(0.031\) —— 与 \(a = 0.9\) 在 \(m = 1\) 处的 \(0.9000\) 差了将近三十倍。

    把两列并排看，判据非常干脆：

    滞后 \(m\) 白噪声（量级 \(1/\sqrt{N} = 0.031\)） AR(1)，\(a = 0.9\) 倍数关系
    1 约 \(0.03\)（量级内） \(0.9000\) 约 30 倍 ✓
    5 约 \(0.03\)（量级内） \(0.5905\) 约 20 倍，完全不可比
    10 约 \(0.03\)（量级内） \(0.3487\) 差距持续拉大

    这说明什么：三点。

    1. 看 \(m = 1\) 就够了。若立刻掉到 \(1/\sqrt{N}\) 的量级以内 → 白噪声； 若还有 \(0.5\) 以上 → 相邻样本高度相关，是有色噪声 ✓
    2. \(a\) 控制「记忆长度」。\(a\) 越接近 1，衰减越慢。 \(a = 0.9\) 的记忆约 10 点，\(a = 0.5\) 只有约 \(1.4\) 点。
    3. 判据的阈值依赖 \(N\)。同一个物理过程，数据越长，白噪声的判据越严格。 所以比较两个信号时必须用同一个 \(N\)（或都先归一化到 \(1/\sqrt{N}\)）⚠

    5.5 手算对照：不相关不等于独立¶

    这是这一节最重要的一句话。用一个手算的例子把它说透。

    不相关不等于独立

    不相关是一个很弱的条件：它只要求协方差为零， 也就是线性关系为零。它完全没有约束任何非线性关系 ⚠

    独立是一个很强的条件：它要求联合分布可以分解成边缘分布的乘积， 也就是任何关系（不只是线性）都不存在。

    逻辑关系是单向的：

    \[\text{独立} \;\Longrightarrow\; \text{不相关}\]

    反过来不成立。只有在联合高斯分布这个特殊情形下， 两者才等价 —— 这也是高斯分布被反复使用的真正原因 ✓

    手算例题：设 \(X\) 取 \(\{-1, 0, 1\}\) 三个值等概率， 令 \(Y = X^2\)。求 \(\mathrm{Cov}(X, Y)\)，并判断 \(X\) 与 \(Y\) 是否独立。

    第一步：列出联合取值表。 三个 \(x\) 各自等概率（各 \(1/3\)）：

    \(x\) 概率 \(y = x^2\)
    \(-1\) \(1/3\) \(1\)
    \(0\) \(1/3\) \(0\)
    \(1\) \(1/3\) \(1\)

    第二步：算 \(\mathbb{E}\{X\}\)。

    \[\mathbb{E}\{X\} = \tfrac{1}{3}(-1) + \tfrac{1}{3}(0) + \tfrac{1}{3}(1) = 0\]

    依据：对称性 —— 取值左右对称，均值必然为零。

    第三步：算 \(\mathbb{E}\{Y\} = \mathbb{E}\{X^2\}\)。

    \[\mathbb{E}\{X^2\} = \tfrac{1}{3}(1) + \tfrac{1}{3}(0) + \tfrac{1}{3}(1) = \tfrac{2}{3}\]

    第四步：算 \(\mathbb{E}\{XY\} = \mathbb{E}\{X^3\}\)。 把每一步的 \(x \cdot x^2 = x^3\) 算出来：

    \[(-1)^3 = -1, \qquad 0^3 = 0, \qquad 1^3 = 1\]
    \[\mathbb{E}\{X^3\} = \tfrac{1}{3}(-1) + \tfrac{1}{3}(0) + \tfrac{1}{3}(1) = \tfrac{-1 + 0 + 1}{3} = 0\]

    第五步：代入协方差公式。

    \[\mathrm{Cov}(X, Y) = \mathbb{E}\{XY\} - \mathbb{E}\{X\}\,\mathbb{E}\{Y\} = 0 - 0 \times \tfrac{2}{3} = 0\]
    \[\boxed{\mathrm{Cov}(X, Y) = 0 \;\Longrightarrow\; X \text{ 与 } Y \text{ 不相关}}\]

    第六步：检验独立性。 看条件概率 \(\mathrm{P}(Y = 1 \mid X = 1)\)：

    \[\mathrm{P}(Y = 1 \mid X = 1) = \mathrm{P}(1^2 = 1) = 1\]

    但如果独立，应当有

    \[\mathrm{P}(Y = 1 \mid X = 1) = \mathrm{P}(Y = 1) = \tfrac{2}{3}\]

    \(1 \ne \frac{2}{3}\)，所以不独立。

    \[\boxed{\text{不相关，但不独立}}\]

    这说明什么：三点，层层递进。

    关系形式 协方差 能否作为「不相关但不独立」的例子
    偶函数（如 \(Y = X^2\)） \(0\) 可以 ✓
    奇函数（如 \(Y = X^3\)） 非零 不可以 ⚠
    1. 偶函数关系是「免费」的反例。\(Y = X^2\) 关于 \(x = 0\) 对称， 当 \(x\) 从负走到正时，\(xy\) 的正负两段恰好互相抵消， 净的线性相关就是零 ✓
    2. 奇函数关系不行。\(Y = X^3\) 是单调的，没有抵消， 协方差算出来是非零的（例如标准正态下 \(\mathbb{E}\{X^4\} = 3 \ne 0\)）。
    3. 对信号处理的直接后果：用自相关 \(r(m)\) 只能检验线性相关。 数据里若存在平方、整流、包络检波这类偶函数式的非线性依赖， 自相关一点都看不出来 ⚠ 需要检验非线性关系时，要看高阶统计量（如双谱）或直接用互信息。

    把「不相关」与「独立」的区别整理成表：

    不相关 独立
    约束的是 线性 关系 一切 关系
    \(\mathbb{E}\{XY\} = \mathbb{E}X \cdot \mathbb{E}Y\) 成立 成立
    联合分布可分解 不一定 成立
    蕴含关系 — 独立 \(\Rightarrow\) 不相关 ✓

    实践提醒：构造「不相关但不独立」的例子时， 要用关于均值对称的非线性关系，否则协方差不会归零。

    六、性质 7：相关时间¶

    6.1 为什么需要这个量¶

    前面几条性质说的都是「自相关长什么样」。但在实际操作中，还有一个问题绕不开：

    我已经算出自相关了，那它衰减得算快还是算慢？我该拿这个信息做什么？

    「相关时间」就是回答这个问题的量。它把「衰减速度」压缩成一个数， 而这个数可以直接换算成工作参数 ✓

    6.2 定义：从宽的一种说法¶

    自相关是连续下降的，很难说「到哪一点算衰减完了」。所以相关时间的定义， 工程上通常取一个阈值，把「第一次降到阈值以下的滞后」定义为相关时间。 最常用的两个阈值：

    \[r_{xx}(\tau_c) = r_{xx}(0)\,/\,e \qquad \text{（用 } 1/e \approx 0.3679 \text{）}\]
    \[r_{xx}(\tau_c) = r_{xx}(0)\,/\,2 \qquad \text{（用一半）}\]

    这里 \(\tau_c\) 就是相关时间（correlation time）。

    ⚠ 必须先说清阈值，再说数值。同一个信号，用 \(1/e\) 判据和用 \(1/2\) 判据， 算出的相关时间可以差两倍以上。没有说明阈值的「相关时间」是没有意义的数字。

    阈值的物理直觉

    为什么常用 \(1/e\)？因为它和「时间常数」的文化一脉相承： 一阶系统的响应衰减到 \(1/e\) 的时间就是时间常数。

    为什么有时用 \(1/2\)？因为它对应「已经衰减了一半」，更保守， 在需要保证样本足够独立时更好用。

    记住一件事就够：换阈值得到的相关时间不同，但它们之间的相对大小关系不变。 所以比较两个信号时，用哪个阈值都行 —— 只要两个信号用同一个 ✓

    6.3 与 AR(1) 模型的精确对应¶

    对一阶自回归模型 \(y(n) = a\,y(n-1) + e(n)\)，自相关是 \(r(m) = r(0)a^{\lvert m\rvert}\)， 所以可以解析地解出 \(1/e\) 判据下的相关时间：

    \[a^{\tau_c} = \frac{1}{e} \;\Longrightarrow\; \tau_c \ln a = -1 \;\Longrightarrow\; \tau_c = -\frac{1}{\ln a}\]

    当 \(a\) 接近 1 时，\(\ln a \approx -(1 - a)\)，于是有一个很好记的近似：

    \[\tau_c \approx \frac{1}{1 - a}\]

    怎么读：\(a = 0.9\) 时相关时间约为 \(10\) 个采样点；\(a = 0.98\) 时约为 \(50\) 个采样点。 「记忆」的长度与 \(1 - a\) 成反比 ✓

    下面把解析式手算的结果与近似的简式并排对照。全部用 \(\tau_c = -\frac{1}{\ln a}\)，\(\ln\) 值取四位小数：

    \(a\) \(\ln a\) \(\tau_c = -1/\ln a\) 手算 取整 近似 \(\frac{1}{1-a}\) 偏差
    \(0.50\) \(-0.6931\) \(1/0.6931 = 1.44\) \(2\) \(2.0\) 近似偏大
    \(0.90\) \(-0.1054\) \(1/0.1054 = 9.49\) \(10\) \(10.0\) 吻合 ✓
    \(0.98\) \(-0.0202\) \(1/0.0202 = 49.50\) \(50\) \(50.0\) 吻合 ✓

    为什么 \(1/e\) 判据下的值是「取整」而不是精确值：相关时间定义为 自相关第一次降到阈值以下的滞后，滞后必须是整数点， 所以 \(9.49\) 这个连续值在实际序列上落在第 \(10\) 个点上。

    换成 \(1/2\) 判据，手算同一个 \(a = 0.9\)。 要求

    \[a^{\tau_c} = \frac{1}{2} \;\Longrightarrow\; \tau_c \ln a = \ln\frac{1}{2} = -0.6931\]
    \[\tau_c = \frac{0.6931}{0.1054} = 6.58 \;\Longrightarrow\; \text{第 } 7 \text{ 个点}\]

    这与 5.4 小节逐点连乘得到的结果完全一致（\(0.9^6 = 0.5314 > 0.5\)， \(0.9^7 = 0.4783 < 0.5\)）✓

    两种判据的对照表：

    \(a\) \(1/e\) 判据（\(\tau_c = -1/\ln a\)） \(1/2\) 判据（\(\tau_c = 0.6931/-\ln a\)） 比值
    \(0.50\) \(2\) \(1\) \(2.0\)
    \(0.90\) \(10\) \(7\) \(1.4\)
    \(0.98\) \(50\) \(35\) \(1.4\)

    这说明什么：三点。

    1. 两种判据给出的数值不同，但排序完全一致。 \(a\) 越大相关时间越长，这个结论不受阈值影响 ✓
    2. 比值稳定在 \(1.4\) 左右（除了 \(a = 0.5\) 的边界情形）。 这是因为 \(\tau_c \propto 1/\ln a\)，两种判据只差一个常数因子 \(\frac{\ln 2}{1} = 0.6931\)，取倒数就是 \(1.44\) ✓
    3. 所以比较两个信号时，只要两个信号用同一个阈值， 结论就不会错。这也正是 6.2 小节那句警告的含义 —— 报告 \(\tau_c\) 必须写明阈值 ⚠

    6.4 相关时间决定什么¶

    相关时间 \(\tau_c\) 不是一个学术概念，它直接决定三个工程参数：

    参数 与 \(\tau_c\) 的关系 理由
    窗长 / 数据长度 至少要几十倍 \(\tau_c\) 自相关估计的方差约为 \(1/N\)，段数越多越准 ✓
    采样间隔 不能远大于 \(\tau_c\) 否则相邻样本几乎无关，等于把连续信号采成了白噪声 ⚠
    分块长度 每块至少几倍 \(\tau_c\) 否则块与块之间高度相关，块平均的方差降不下来

    下面这张表把「相关时间」翻译成具体的采样建议，可以用作速查：

    信号类型 典型 \(\tau_c\) 采样间隔上限 建议最少样本数
    宽带白噪声 1 个采样点 —（本身离散） 几百点
    一般有色噪声 几到几十点 \(\tau_c / 5\) \(50\tau_c\)
    慢变趋势（非平稳） 接近数据长度 需先去掉趋势 ⚠ 不适用

    ⚠ 最后一行要特别注意：如果算出来的相关时间接近数据长度， 那通常不是说明信号相关性强，而是说明数据里混着趋势或直流 —— 这种情况下「相关时间」这个量本身就失去了意义。

    相关时间不能无限外推

    相关时间是从有限数据上算出来的，它本身就有不确定性。 大致上，它的相对误差约为 \(1/\sqrt{N / \tau_c}\)。

    也就是说：\(N = 1000\)、\(\tau_c = 10\) 时，只有约 \(100\) 个「独立段」， 相关时间的相对误差约 \(10\%\)。这个精度足够做工程判断， 但不足以做精细的定量结论 ⚠

    所以相关时间通常只用来做量级判断（是几个点还是几百个点）， 不用来当精确参数。

    8.2 含趋势的数据：衰减极慢¶

    下面手算一条含线性趋势的数据的自相关，看清「慢衰减」是怎么产生的。

    设定：数据为 \(x(n) = 0.05n\)，\(n = 0, 1, \dots, N-1\)，取 \(N = 300\)。 先忽略噪声 —— 噪声只会让结果更乱，不影响结论。

    第一步：先看数据形状。 \(x(n)\) 从 \(x(0) = 0\) 线性涨到 \(x(299) = 14.95\)。 全幅约 \(15\)。

    第二步：写出 \(r(0)\)。 由性质 3，

    \[r(0) = \frac{1}{N}\sum_{n=0}^{N-1} x^2(n) = \frac{0.05^2}{N}\sum_{n=0}^{N-1} n^2\]

    用平方和公式 \(\sum_{n=0}^{N-1} n^2 = \frac{(N-1)N(2N-1)}{6}\)：

    \[r(0) = \frac{0.0025}{300} \times \frac{299 \times 300 \times 599}{6} = \frac{0.0025 \times 299 \times 599}{6} = 74.6\]

    第三步：算 \(r(m)\)。 同理

    \[r(m) = \frac{0.0025}{N}\sum_{n=0}^{N-m-1} n(n+m) = \frac{0.0025}{N}\Big[\sum n^2 + m\sum n\Big]\]

    第四步：取 \(m = 60\) 带入。 此时求和上限是 \(239\)， 用 \(\sum_{n=0}^{239} n = 28680\)、\(\sum_{n=0}^{239} n^2 = 4.58\times 10^6\)：

    \[r(60) = \frac{0.0025}{300}\big[4.58\times 10^{6} + 60 \times 28680\big] = \frac{0.0025}{300}\big[4.58\times 10^{6} + 1.72\times 10^{6}\big]\]
    \[r(60) = \frac{0.0025 \times 6.30\times 10^{6}}{300} = 52.5\]

    第五步：归一化。

    \[\frac{r(60)}{r(0)} = \frac{52.5}{74.6} = 0.704\]

    手算得 \(0.70\)，与实测的 \(0.6931\) 吻合 ✓

    这个结果说明什么：关键在第四步那个加法 —— 趋势项的自相关里，\(\sum n^2\) 和 \(m\sum n\) 两项同阶，都随 \(N^3\) 增长。 所以即使 \(m = 60\) 很大，\(m\sum n\) 相对 \(\sum n^2\) 也只占约 \(\frac{1.72}{4.58} \approx 38\%\)，衰减自然非常慢。

    对照纯噪声：由 5.3 小节，纯噪声在 \(m \ne 0\) 处的比值量级是 \(1/\sqrt{N} = 1/\sqrt{300} = 0.058\)。

    观察 含趋势（手算 \(0.704\)） 平稳噪声（量级 \(0.058\)）
    \(r(1)/r(0)\) 约 \(0.99\) 约 \(0.06\)（量级内）
    \(r(60)/r(0)\) \(0.70\) 约 \(0.06\)（量级内）
    形状 几乎不衰减的斜坡 立刻掉到量级内
    判断 非平稳，含趋势 ⚠ 平稳 ✓

    这说明什么：判据不是看「\(r(m)\) 够不够大」， 而是看它随 \(m\) 的衰减方式。

    • 趋势：\(r(m)/r(0)\) 在大滞后上仍是 \(0.7\) 这个量级， 而且在数据长度内根本不会到零 ⚠
    • 噪声：\(m = 1\) 就掉到 \(1/\sqrt{N}\) 的量级，之后一直在量级内抖动 ✓

    慢衰减不等于「相关性强」

    一定要分清两种「衰减慢」：

    • 短记忆造成的慢衰减：一阶 AR 且 \(a\) 很大（如 \(0.99\)）， 衰减慢但是指数式的，最终会到 0。这是真相关性 ✓
    • 趋势造成的慢衰减：看起来像直线或极缓慢的曲线， 在数据长度内根本不会到 0。这是假相关性 ⚠

    区分方法：看曲线形状。指数衰减下，把纵轴取对数会变成直线； 趋势下，曲线整体近似一条不衰减的横线。也可以直接用相关时间判断 —— 如果算出的 \(\tau_c\) 接近数据长度 \(N\)，那就是趋势，不是相关性。

    处理办法也不同：真相关性要保留（它是信息）， 趋势要去掉（先去趋势再算自相关）。

    一旦混用，这条判据就失效了 —— 你会开始怀疑数据， 而真正的问题在代码里。

    九、能量信号与随机信号：自相关的两种定义¶

    这一节把视角拉回来，复习一件很容易混的事 —— 「自相关」这个词在不同语境下是两个不同的式子。 混用会导致量纲错误，而量纲错误往往一路错到功率谱。

    9.1 两种定义的对照¶

    能量信号的自相关 功率信号 / 随机信号的自相关
    适用对象 有限长序列、绝对可和/可积的确定信号 随机过程、周期信号等持续存在的信号
    离散定义 \(R_e(m) = \sum_{n=-\infty}^{\infty} x(n)x(n+m)\) \(r_{xx}(m) = \lim\limits_{N\to\infty}\dfrac{1}{2N+1}\sum\limits_{n=-N}^{N} x(n)x(n+m)\)
    是否除以时长 不除 ✓ 要除（这是关键区别）⚠
    \(R(0)\) 的含义 能量（焦耳） 平均功率（瓦特）
    量纲 （幅度\(^2\)）× 时间/点数 幅度\(^2\)
    与傅里叶的关系 自相关的傅里叶变换 = 能量谱密度 自相关的傅里叶变换 = 功率谱密度

    怎么读：两个式子唯一的差别就是那个 \(\frac{1}{2N+1}\)（离散情形是 \(\frac{1}{N}\)）。

    • 不除 → 结果随数据长度线性增长，描述的是总能量；
    • 除以长度 → 结果收敛到有限值，描述的是平均功率 ✓

    9.2 为什么随机信号必须除以时长¶

    原因很实在：随机信号的能量是无穷大。

    一个持续存在的随机信号，你把它采样得越长，\(\sum x^2(n)\) 就越大，永远不收敛。 所以「能量」这个量对随机信号没有意义。必须换成「单位时间的能量」，也就是功率， 才能得到有限的、可以比较的数。

    这也解释了本页为什么一直用除以 \(N\) 的写法：处理随机信号时， 除以时长是定义的一部分，不是可选项。

    9.3 混用会怎样¶

    混用量纲会一路错到功率谱

    混用有两种典型表现，后果不同但都很严重：

    表现一：随机信号用了能量型的式子（不除）

    \(r(0)\) 会随数据长度线性增长。你换一批更长的数据，\(r(0)\) 就变大 —— 同样的信号，功率读数却随数据长度变化，这显然是错的。

    表现二：能量信号用了功率型的式子（除）

    结果被除上一个任意的长度，\(r(0)\) 不再是能量。 这时如果再去做傅里叶变换指望得到「能量谱密度」，量纲就对不上了 ⚠

    判别方法很简单：看 \(r(0)\) 的单位。

    \(r(0)\) 的单位 说明
    焦耳（幅度\(^2\)·秒） 这是能量信号，用的是不除的定义
    瓦特（幅度\(^2\)） 这是功率/随机信号，用的是除以时长的定义

    如果你算出 \(r(0)\) 的单位是「焦耳」，但数据明明是一段稳态噪声 —— 那就说明定义用错了。

    典型例题¶

    例题 1：验证 \(r(0)\) 是最大值（手算）¶

    题目：已知某零均值平稳序列的自相关在几个滞后上的取值为

    \(m\) 0 1 2 3
    \(r(m)\) 4.0 \(a\) \(-3.2\) 1.5

    问 \(a\) 的取值范围。

    思路

    直接用性质 1：\(\lvert r(m)\rvert \le r(0) = 4.0\) 对一切 \(m\) 成立。

    逐条套上去即可。注意负值也要检查：\(-3.2\) 的绝对值是 \(3.2\)， 小于 \(4.0\)，合法；如果它是 \(-5.0\) 就非法了。

    解答

    性质 1 要求 \(\lvert r(m)\rvert \le r(0)\)，此处 \(r(0) = 4.0\)，所以：

    • \(m = 1\)：\(\lvert a\rvert \le 4.0\)，即
    \[-4.0 \le a \le 4.0\]
    • \(m = 2\)：\(\lvert -3.2\rvert = 3.2 \le 4.0\) ✓ 合法
    • \(m = 3\)：\(\lvert 1.5\rvert = 1.5 \le 4.0\) ✓ 合法

    所以 \(a\) 的取值范围是 \([-4.0,\ 4.0]\)。

    进一步，如果这个序列还满足偶函数性质（性质 2）， 那么 \(r(-m) = r(m)\)，负滞后不用另外给值，可以直接照抄。

    ⚠ 一个额外的提醒：题里给的这组数通过了性质 1 和性质 2 的检查， 但不能保证它是合法的自相关 —— 还要满足非负定。 如果这是考试题，答案到 \([-4.0, 4.0]\) 就够了； 但在工程上，还要再用非负定性复查一遍。

    例题 2：正弦加噪的自相关¶

    题目：某信号为 \(x(n) = 2\cos(2\pi f_0 n/f_s)\)，\(f_0 = 50\) Hz，\(f_s = 1000\) Hz。 问它的自相关在哪些滞后上出现峰值？峰值处的值是多少（用 \(r(0)\) 归一化）？

    思路

    信号是纯余弦，振幅 \(A = 2\)。用正弦的解析式（\(A^2/2\) 换成 \(A^2/2\) 的形式）： 余弦的相位是 0，可以直接套。

    先算周期有多少个采样点，再找使 \(\cos = 1\) 的滞后。

    解答

    第一步：算周期。 每个信号周期有

    \[\frac{f_s}{f_0} = \frac{1000}{50} = 20 \text{ 个采样点}\]

    第二步：写出解析式。 余弦信号的（归一化）自相关是

    \[\frac{r_{xx}(m)}{r_{xx}(0)} = \cos\!\left(\frac{2\pi f_0 m}{f_s}\right) = \cos\!\left(\frac{2\pi m}{20}\right)\]

    第三步：找峰值。 峰值要求 \(\cos\) 取 \(+1\)，即

    \[\frac{2\pi m}{20} = 2\pi k \;\Longrightarrow\; m = 20k, \quad k = 0, 1, 2, \dots\]

    所以峰值出现在 \(m = 0, 20, 40, 60, \dots\)，峰间距为 20 个采样点， 正好等于信号周期。 ✓

    第四步：峰值大小。

    • 归一化后，\(m = 20k\) 处的值是 \(\cos(2\pi k) = 1.0000\)（对一切 \(k\)）；
    • 用无偏分母时，\(r(20k)/r(0) = 1.0000\)，即峰值与 \(r(0)\) 等高；
    • 换用有偏分母（除以 \(N\)）时，第 \(k\) 个峰的高度是 \(\frac{N - 20k}{N}\)， 会随 \(k\) 线性降低 ⚠

    另外，绝对数值上 \(r_{xx}(0) = A^2/2 = 2^2/2 = 2.0\)。

    这就是「在噪声里找周期」的全部原理：峰的位置给出周期， 与信号频率 \(f_0\) 满足 \(f_0 = f_s / P\)。

    例题 3：判断一条自相关是否合法¶

    题目：某同学算出一段数据的自相关（已去均值、统一除以 \(N\)），前几个值为

    \(m\) 0 1 2 3 4
    \(r(m)\) 1.00 0.85 1.12 0.40 0.21

    请指出问题，并给出最可能的两个原因。

    思路

    先做性质 1 的快速筛（比大小），再做性质 2 的快速筛（对称性）。

    哪一条明显被违反了？

    解答

    第一步：性质 1 检查。 \(r(0) = 1.00\) 是最大值，要求 \(\lvert r(m)\rvert \le 1.00\) 对一切 \(m\) 成立。但

    \[r(2) = 1.12 \gt 1.00\]

    违反了性质 1 ⚠

    第二步：性质 2 检查。 题里只给了正滞后，无法直接比对。 但如果这个序列是实信号，\(r(-2) = r(2) = 1.12\)，同样越界。

    第三步：找原因。 违反性质 1 几乎总是计算问题，不是数据问题。 最可能的两个原因，按可能性排序：

    1. 分母混用。这是最常见的。比如大滞后用 \(N - \lvert m\rvert\) 作分母， 而 \(r(0)\) 用 \(N\) 作分母。\(m = 2\) 时前者的分母比后者小， 商就偏大，于是出现「越界」。修法：全部统一除以同一个数。

    2. 归一化时除了错误的量。比如想让人看出「比值」， 却除了样本方差 \(\hat\sigma^2\) 而不是 \(r(0)\)。当 \(r(0)\) 与方差不等时， 算出的比值就可能大于 1（因为 \(r(0) = \hat\sigma^2 + \bar x^2 \ge \hat\sigma^2\)， 反过来除方差就会偏大）。

    ⚠ 注意：不要怀疑数据。 数据本身不可能让合法的自相关越界 —— 这条性质是恒成立的。看到越界，就要去代码里找。

    例题 4：用相关时间决定分块长度¶

    题目：有一段平稳噪声，采样率 \(f_s = 1000\) Hz。 用 \(1/e\) 判据算出的相关时间是 \(\tau_c = 4\) ms。 现在要做谱估计，每段数据长度取多少点比较合适？

    思路

    先把相关时间换算成采样点数（不是毫秒），再按经验倍数给出建议。

    注意单位：\(\tau_c\) 给的是毫秒，\(f_s\) 给的是 Hz。

    解答

    第一步：把时间换成点数。

    \[\tau_c \text{（点数）} = \tau_c \times f_s = 4 \times 10^{-3}\,\text{s} \times 1000\,\text{Hz} = 4 \text{ 个采样点}\]

    第二步：确定每段长度。 经验上每段至少要覆盖几十个相关时间， 才能让段内的自相关估计稳定。取 \(50\tau_c\)：

    \[L = 50 \times 4 = 200 \text{ 点}\]

    第三步：验算频率分辨率。 每段 \(L = 200\) 点、\(f_s = 1000\) Hz， 所以每个谱线间隔是

    \[\Delta f = \frac{f_s}{L} = \frac{1000}{200} = 5 \text{ Hz}\]

    这个分辨率够不够用，取决于你要分辨的两个频率成分差多少：

    要分辨的最小频率间隔 够不够
    \(\ge 5\) Hz 够 ✓
    \(< 5\) Hz 不够，需要加长每段 ⚠

    第四步：如果分辨率不够怎么办。 加长 \(L\)，但总数据量是有限的， 所以段数会变少，谱估计的方差会变大。这是一个固定的权衡：

    想要 代价
    高频率分辨率（大 \(L\)） 段数少，谱线抖动大 ⚠
    低方差（小 \(L\)，段数多） 频率分辨率差 ⚠

    相关时间在这里的作用，是给 \(L\) 划一条下限： \(L\) 至少要有几十个 \(\tau_c\)，否则段内样本高度相关， 「平均」这件事就起不到降方差的作用。

    一句话：\(\tau_c\) 决定下限，分辨率要求决定上限，在这两者之间选。

    自测¶

    Q1：一个零均值平稳序列在 \(m = 0\) 处的自相关是 \(r(0) = 9.0\)。 如果它在某个滞后上取值为 \(r(m) = -9.5\)，这条自相关合法吗？为什么？

    参考答案

    不合法。

    性质 1 要求 \(\lvert r(m)\rvert \le r(0)\)。这里

    \[\lvert -9.5\rvert = 9.5 \gt 9.0 = r(0)\]

    被违反。

    关键点：性质 1 是恒成立的，数据本身不可能让它失效。 所以出现这种情况，一定是计算出了问题 —— 最常见的是分母混用（大滞后用 \(N - \lvert m\rvert\)，\(r(0)\) 用 \(N\)）， 其次是归一化时除错了对象。

    ⚠ 另外一个容易忽略的细节：负的超界和正的超界一样非法。 不要以为「负值就没事」。

    Q2：已知 \(x \sim N(0, 1)\)。分别取 \(y = x^2\) 和 \(y = x^3\)， 哪个是「不相关但不独立」的例子？为什么另一个反而不是？

    参考答案

    \(y = x^2\) 是「不相关但不独立」的例子；\(y = x^3\) 不是。

    判别方法：相关系数为零要求 \(\mathrm{Cov}(x, y) = 0\)， 也就是 \(\mathbb{E}\{xy\} - \mathbb{E}x \cdot \mathbb{E}y = 0\)。

    第一步：\(y = x^2\)。 因为 \(x\) 关于原点对称，\(x\) 的奇数阶矩都为 0，所以

    \[\mathbb{E}x = 0, \quad \mathbb{E}y = \mathbb{E}\{x^2\} = 1\]
    \[\mathbb{E}\{xy\} = \mathbb{E}\{x^3\} = 0\]

    于是

    \[\mathrm{Cov}(x, x^2) = 0 - 0 \times 1 = 0 \;\Longrightarrow\; \rho = 0\]

    相关系数为 0 ✓

    但 \(y\) 完全由 \(x\) 决定：知道 \(x\) 就等于知道 \(y\)，没有任何不确定性。 所以不独立 ✓

    第二步：\(y = x^3\)。 同样有 \(\mathbb{E}x = 0\)，而

    \[\mathbb{E}y = \mathbb{E}\{x^3\} = 0\]
    \[\mathbb{E}\{xy\} = \mathbb{E}\{x^4\} = 3 \quad (\text{正态分布的四阶矩})\]

    于是

    \[\mathrm{Cov}(x, x^3) = 3 - 0 \times 0 = 3 \ne 0\]

    相关系数不为零，所以 \(x\) 与 \(x^3\) 是线性相关的。 它不能作为「不相关但不独立」的例子。

    第三步：这个对比说明了什么。

    关系形式 相关系数 能否作为「不相关但不独立」的例子
    偶函数（如 \(x^2\)） \(0\) 可以 ✓
    奇函数（如 \(x^3\)） 非零 不可以 ⚠

    原因：偶函数是关于原点对称的。随着 \(x\) 从负走到正， \(y\) 先降后升，正相关段与负相关段恰好互相抵消， 净的线性相关系数就是 0。

    奇函数则是单调的（在整个区间上同增或同减）， 没有任何抵消，线性相关被完整地保留下来。

    ⚠ 实践提醒：构造「不相关但不独立」的例子时， 要用关于均值对称的非线性关系，否则相关系数不会归零。

    这也提醒了前面那句结论的分量：自相关 \(r(m)\) 只能检验线性关系。 数据里若有偶函数式的非线性依赖（平方、包络检波、整流等）， 自相关完全看不出来。

    Q3：为什么自相关必须满足非负定性？它保证了什么？如果违反会如何？

    参考答案

    为什么必须满足：因为自相关来自真实的随机过程。

    取任意系数 \(a_i\) 和时刻 \(t_i\)，构造线性组合 \(Y = \sum_i a_i x(t_i)\)。 它的模平方期望是

    \[\mathbb{E}\{\lvert Y\rvert^2\} = \sum_i\sum_j a_i a_j^{*} r_{xx}(t_i - t_j)\]

    而 \(\lvert Y\rvert^2 \ge 0\)，所以右式 \(\ge 0\)。 证明完成 —— 非负定不是外加限制，而是「自相关确实来自一个随机过程」的代数表现。

    保证了什么：它等价于自相关的傅里叶变换是非负的， 也就是说对应的功率谱密度 \(P_{xx}(\omega) \ge 0\)。

    违反会如何：

    • 自相关违反 → 它不对应任何真实信号，你的算法或模型有问题；
    • 功率谱违反 → 出现「负功率」，物理上荒谬 ⚠

    因为两者是傅里叶变换对，一边违反，另一边必然也违反。

    实践意义：性质 1 和性质 2 只是必要条件（快速筛子）， 非负定才是充分必要条件。 一个函数可以通过前两条检查而仍然非法 —— 这一点在正文里已经用 三角核的例子演示过了。

    Q4：为什么做自相关分析之前一定要先去均值？如果不去，会出现什么现象？

    参考答案

    原因：直流分量会在自相关里贡献一项常数。

    设 \(x(n) = m + x_0(n)\)，其中 \(m\) 是直流、\(x_0\) 是零均值部分。那么

    \[r_{xx}(m) = \mathbb{E}\{(m + x_0(n))(m + x_0(n+m))\} = m^2 + r_{00}(m)\]

    （交叉项为零，因为 \(x_0\) 的均值为零）

    所以不去均值的自相关 = 直流功率 \(m^2\) + 真实自相关。

    会出现什么现象：

    现象 说明
    \(r(0)\) 被显著抬高 正文实测中从 \(0.5955\) 涨到 \(25.5043\)，因为 \(5^2 = 25\) ⚠
    出现假的长程相关 \(m^2\) 这一项与 \(m\) 无关，隔多远都贡献同样的大小
    周期性被淹没 正文实测：去均值前完全看不到 20 点的周期峰
    相关时间被严重高估 衰减被常数项拖住，算出的 \(\tau_c\) 失去意义 ⚠

    结论：去均值是自相关分析的第一步，没有例外。

    这也正是本课程课件把自协方差（去均值）与自相关（不去均值） 并列列出的原因 —— 它们描述的是两件不同的事， 而做结构分析（找周期、估参数）时必须用前者。

    补充一句操作细节：去均值时用的是样本均值 \(\bar x\) 而不是真值 \(m\)， 这会给 \(r(m)\) 带来一个 \(O(1/N)\) 量级的微小偏差，数据越长影响越小 ✓

    小结¶

    先把五条性质列在一起，这是本页的主干：

    编号 性质 一句话的证明依据
    ① 偶函数 \(r(-m) = r(m)\) 平稳性（可平移指标）+ 实数乘法可交换 ✓
    ② \(r(0)\) 最大 \(\lvert r(m)\rvert \le r(0)\) 由 \(E[(x(n) \pm x(n+m))^2] \ge 0\) 展开推得 ✓
    ③ \(r(0)\) 是平均功率 \(r(0) = \sigma^2 + \mu^2\) 方差定义展开 + 期望的线性性 ✓
    ④ 非负定 \(\sum\sum a_i a_j^{*} r(t_i - t_j) \ge 0\) 构造 \(Y = \sum a_i x(t_i)\)，由 \(E\{\lvert Y\rvert^2\} \ge 0\) 推得 ✓
    ⑤ 周期信号 \(r(m+P) = r(m)\) 代回定义，用 \(x(n+m+P) = x(n+m)\) ✓

    取等条件的补充说明（性质 ②）：等号不只在「正的最大值」处取到 —— 当 \(x(n+m) = -x(n)\)（信号反相）时，\(r(m) = -r(0)\)，是负的最大值， 绝对值同样达到上界 ⚠ 所以绝对值符号不能丢。

    再把实践中最常用的几条结论汇总：

    要记住的 为什么
    \(r(0)\) 是最大值：\(\lvert r(m)\rvert \le r(0)\) 检查自相关是否合法的第一道筛子，越界就是代码错了 ✓
    \(r(0)\) 就是平均功率 从自相关直接读功率，不用另外算均方值 ✓
    \(r_{xx}(0) = \sigma_x^2 + m_x^2\) 把功率拆成「交流」和「直流」两部分
    实信号 \(r(m) = r(-m)\)（偶函数） 只算一半滞后，计算量减半 ✓
    复信号 \(r(-m) = r^{*}(m)\) 复信号不能照抄实信号的公式 ⚠
    周期信号的自相关同周期 峰间距就是信号周期，这是「噪声中找周期」的原理 ✓
    非负定 保证功率谱非负，是下一页维纳–辛钦定理的铺垫
    非负定是充要条件，性质 ①② 只是必要条件 三角核反例说明：通过前两条仍可能非法 ⚠
    手算时求和项数不是分母 \(r(1)\) 只有 3 项相加，分母仍是 \(N\) ⚠
    白噪声判据的波动量级是 \(1/\sqrt{N}\) 口算就能定阈值：\(N = 1024\) 时约 \(0.031\) ✓
    \(r(m) = 0\)（\(m \ne 0\)）就是白序列 白噪声的判据，也是后面线性系统分析的常用前提 ✓
    不相关 ≠ 独立 只有联合高斯分布时两者才等价 ⚠
    相关时间 \(\tau_c\) 必须说明阈值 不说阈值的相关时间是没意义的数字 ⚠
    相关时间决定窗长、采样率、分块长度 把「衰减快慢」翻译成工程参数的桥梁 ✓
    自相关与功率谱互为傅里叶变换 衰减越慢谱越窄，两边是同一个信息的两种表示 ✓
    先去均值，再算自相关 直流会制造假的长程相关，淹没真实结构 ⚠
    衰减极慢优先怀疑数据而非算法 含趋势/非平稳是真正常见的原因 ✓
    能量信号不除时长（\(r(0)\) 是能量），随机信号除时长（\(r(0)\) 是功率） 混用会导致量纲错误 ⚠
    分母必须一次性定死（本页默认除以 \(N\)） 只有统一分母，性质 ② 才恒成立，才能当自动化判据 ✓
