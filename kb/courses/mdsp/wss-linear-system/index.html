    平稳序列通过线性系统¶

    这一页解决一个问题：把一个广义平稳的随机序列送进一个线性时不变系统， 输出的统计特性会变成什么样？

    本课程课件在讲完自相关与功率谱之后，只用了一句话交代这件事：

    如果 \(x(n)\) 广义平稳，易证明 \(y(n)\) 也广义平稳，其自相关是……

    然后把三个公式（均值关系、自相关关系、功率谱关系）直接写了出来。 「易证明」三个字对写课件的人是轻松的，对第一次学的读者却是一道墙 ⚠

    这一页的任务就是把这句「易证明」补全 —— 从期望的定义出发，一步一步推到那三个公式，中间不跳任何一步。 推导完之后，再用可以运行的程序把每一步结论验算一遍， 让读者看到公式和数值确实对得上。

    为什么这件事值得花一整页：

    看起来差不多的说法 实际差别在哪里 后果
    「线性系统的作用就是卷积」 那是确定性信号的说法；现在输入是一族随机序列 没法直接写出 \(y(n)\) 的表达式来求谱
    「\(Y(\omega) = X(\omega)H(\omega)\)」 对随机信号，\(X(\omega)\) 本身是随机函数 只能谈功率谱，不能谈谱本身
    「自相关与功率谱是一对变换」 输出的自相关不是简单的相乘，而是两次卷积 必须先证「输出仍平稳」，这些量才有定义
    「滤波器改变频率成分」 真正的影响是 \(\lvert H(\omega)\rvert^2\) 乘在输入功率谱上 相位完全不进功率谱 ✓

    这一页的主线

    整页只围绕三个公式展开，它们是同一条链子的三个环节：

    \[\mu_y = \mu_x \cdot H(0)\]
    \[R_y(m) = R_h(m) * R_x(m)\]
    \[S_y(\omega) = |H(\omega)|^{2} S_x(\omega)\]

    第一个说均值怎么变，第二个说自相关怎么变， 第三个是第二个在频域的等价写法（最常用）✓

    读的时候请盯住一个关键动作：把期望号 \(\mathbb{E}\) 从求和号外面搬到里面。 整个推导的合法性全押在这一步上。

    一、问题的设定：把符号和两个问题先摆清楚¶

    1.1 有哪些已知，要求什么¶

    输入：随机序列 \(x(n)\)，\(n\) 取全体整数。 它是一个广义平稳（wide-sense stationary，缩写 WSS）的随机序列，意思是同时满足两条：

    条件 写法 白话
    均值是常数 \(\mathbb{E}[x(n)] = \mu_x\)，与 \(n\) 无关 不管在哪个时刻看，平均值都一样
    自相关只依赖延迟 \(\mathbb{E}\big[x(n+m)x^{*}(n)\big] = R_x(m)\)，只与 \(m\) 有关 只关心「隔多远」，不关心「从哪开始」

    符号说明（第一次出现，后面直接用）：

    符号 含义 取值范围
    \(n\) 时间下标 整数
    \(x(n)\) 输入的随机序列 复值随机变量（本页例子用实值）
    \(\mu_x\) 输入的均值，\(\mu_x = \mathbb{E}[x(n)]\) 复数
    \(R_x(m)\) 输入的自相关函数，\(R_x(m)=\mathbb{E}\big[x(n+m)x^{*}(n)\big]\) 复数，\(R_x(-m)=R_x^{*}(m)\)
    \((\cdot)^{*}\) 复共轭 —
    \(\mathbb{E}[\cdot]\) 数学期望（系综平均，不是时间平均） —

    系统：一个线性时不变（LTI）系统。它有两个等价的描述：

    描述 记号 含义
    时域 脉冲响应 \(h(n)\) 单位脉冲进系统后的输出
    频域 频率响应 \(H(\omega)\) \(h(n)\) 的离散时间傅里叶变换

    两者是傅里叶变换对：

    \[H(\omega) = \sum_{k=-\infty}^{\infty} h(k)\, e^{-j\omega k}, \qquad h(n) = \frac{1}{2\pi}\int_{-\pi}^{\pi} H(\omega)\, e^{j\omega n}\, d\omega\]

    这里有两处要交代清楚：

    1. \(k\) 在这里是求和哑标（dummy index）， 它的取值范围是使 \(h(k)\) 非零的那些整数。 \(\omega\) 是数字角频率，单位是「弧度/样点」，主值区间取 \([-\pi, \pi]\)。
    2. \(\lvert H(\omega)\rvert\) 叫幅频响应，\(\arg H(\omega)\) 叫相频响应。 这一页后面会看到一个结论：功率谱只看得见前者，看不见后者 ⚠

    输出：输入经过系统后的响应。

    \[y(n) = x(n) * h(n) = \sum_{k=-\infty}^{\infty} h(k)\, x(n-k)\]

    读法：输出是输入的「加权滑动和」—— 权重就是脉冲响应 \(h(k)\)，第 \(n\) 时刻的输出由第 \(n\) 时刻往前各个输入值加权求和得到。

    卷积的完整定义、性质与几何解释， 数学层已经讲得很透，这里不重复， 需要的话请回看 卷积。 傅里叶变换的性质（尤其是「时域卷积 = 频域相乘」和时移性质）见 傅里叶级数与变换。 本页只用这两条已知结论，不重新证明。

    1.2 要问的两个问题¶

    课件的原话是「如果 \(x(n)\) 广义平稳，易证明 \(y(n)\) 也广义平稳」。 这句话里其实藏着两个问题，要分开回答：

    编号 问题 回答它的方式
    问题一 \(y(n)\) 还是广义平稳吗？ 逐条验证 WSS 的两个条件
    问题二 \(y\) 的均值和自相关与 \(x\) 的关系是什么？ 从定义出发逐步推导 ✓

    这两个问题的关系不是并列的，而是有先后：

    • 只有当问题二算出了 \(\mathbb{E}[y(n)]\) 和 \(\mathbb{E}[y(n+m)y^{*}(n)]\) 的具体表达式， 才能拿它们去核对问题一的两个条件是否满足；
    • 也就是说，先算，再判。 「易证明」之所以易，就是因为算完之后一眼就看得出来 ⚠

    下面按这个顺序走：第二节算均值（问题二的一半）， 第三节算自相关（问题二的另一半），第四节回头判平稳（问题一）。

    这一页的推导有前提，别漏掉

    全部推导都依赖两个前提，缺一个结论就可能失效：

    1. 输入是广义平稳的 —— 否则自相关 \(R_x\) 会依赖时间起点 \(n\)， 第三节里「把 \(n\) 消掉」那一步就做不到了。
    2. 系统是 LTI 且稳定 —— 稳定指 \(\sum_k \lvert h(k)\rvert\) 有限（有界输入有界输出稳定）。

    稳定为什么必要：第二节的均值是一个无穷级数 \(\mu_x\sum_k h(k)\)，第三节的自相关是双重无穷级数。 如果 \(\sum_k \lvert h(k)\rvert\) 发散，这些级数可能不收敛， 输出的均值或自相关就根本不存在， 更谈不上「广义平稳」⚠

    二、问题一的第一半：输出的均值（完整推导）¶

    2.1 从定义开始，一步不跳¶

    我们要求的是 \(\mu_y = \mathbb{E}[y(n)]\)。 因为 \(y\) 是随机的，\(\mathbb{E}[\cdot]\) 是对系综取平均 （固定时刻 \(n\)，把所有可能的样本函数在该时刻的取值加权平均）。

    第 1 步：把 \(y(n)\) 的卷积表达式代进去。 这一步只是替换，没有做任何假设：

    \[\mathbb{E}[y(n)] = \mathbb{E}\Big[\sum_{k} h(k)\, x(n-k)\Big]\]

    第 2 步：把期望号搬进求和号里面。

    \[\mathbb{E}\Big[\sum_{k} h(k)\, x(n-k)\Big] = \sum_{k} h(k)\, \mathbb{E}\big[x(n-k)\big]\]

    第 3 步：把 \(h(k)\) 提出来。 \(h(k)\) 是系统的参数，是确定性的数，不是随机变量， 所以它可以自由穿过期望号：

    \[\sum_{k} h(k)\, \mathbb{E}\big[x(n-k)\big]\]

    第 4 步：用输入均值是常数这一条。 因为 \(x\) 广义平稳，\(\mathbb{E}[x(\cdot)]\) 恒等于 \(\mu_x\)， 所以 \(\mathbb{E}[x(n-k)] = \mu_x\) —— 注意这里 \(n-k\) 是某一个整数下标，下面写什么字母都不影响结果：

    \[= \sum_{k} h(k)\, \mu_x = \mu_x \sum_{k} h(k)\]

    第 5 步：把求和认出来。

    \[H(\omega)\Big|_{\omega=0} = \sum_k h(k) e^{-j\cdot 0\cdot k} = \sum_k h(k)\]

    所以

    \[\boxed{\;\mu_y = \mu_x \cdot H(0)\;}\]

    2.2 每一步为什么合法（这是「易证明」真正的门槛）¶

    上面五步里，第 2 步是唯一可能出问题的地方。 读者应该追问：凭什么可以把期望号和无穷求和号交换？

    步骤 用到的理由 什么时候会失效
    代入 \(y\) 的卷积式 定义，无需条件 永不失效
    期望与求和交换 \(\mathbb{E}\) 是线性算子；对绝对收敛的级数，期望与求和可交换 若 \(\sum_k \lvert h(k)\rvert = \infty\) 则可能交换失败 ⚠
    提出 \(h(k)\) \(h\) 是确定性常数 永不失效
    \(\mathbb{E}[x(n-k)] = \mu_x\) 输入的均值平稳性（WSS 第一条） 若 \(x\) 均值随时间漂移则失效
    认出 \(H(0)\) 频率响应在 \(\omega = 0\) 的取值 定义

    关于「期望与求和交换」的直觉解释： 期望本身就是一种加权平均，而加权平均和相加这两种操作是可以换顺序的 —— 「先把每项平均再相加」和「先相加再平均」结果一样。 这一条对有限项求和永远成立；对无穷级数， 只要 \(\sum_k \lvert h(k)\rvert\) 有限（即系统稳定）， 用控制收敛定理就能保证它仍然成立 ✓

    另外一个容易被忽略的点： 上面的推导只用到「\(x\) 的均值是常数」， 根本没有用到「\(x\) 的自相关是常数」。 所以 \(\mu_y = \mu_x H(0)\) 这一条， 对「均值平稳但二阶不平稳」的序列也成立 —— 条件比想象中弱 ✓

    2.3 结论怎么读：直流增益¶

    \[\mu_y = \mu_x \cdot H(0), \qquad H(0) = \sum_k h(k)\]

    读法：输出的平均值 = 输入的平均值 × 系统在零频处的频率响应。

    \(H(0)\) 有个专门的名字：直流增益（DC gain，DC 即直流）。 为什么叫直流？因为 \(\omega = 0\) 对应频率为零的成分， 也就是「一直不变的成分」——恒定分量、直流分量 ✓

    这个公式立刻给出了一个实用结论：

    想要的效果 怎么设计 \(h\) 理由
    保留原信号的直流分量 令 \(H(0) = 1\)（如所有 \(h(k)\) 之和为 1） \(\mu_y = \mu_x\)
    去掉直流分量（去趋势、去偏置） 令 \(H(0) = 0\)（如差分器 \(h=[1,-1]\)） \(\mu_y = 0\) ✓
    放大直流分量 令 \(H(0) \gt 1\) \(\mu_y = \mu_x H(0)\)

    注意 \(H(0)=0\) 和「输出的均值等于 0」是同一件事， 这正是很多滤波器（一阶差分、二阶差分、任何 \(\sum_k h(k)=0\) 的 FIR） 被用来消掉缓慢漂移的原因 ✓

    下面三句话说的是同一件事，考试和实际工作里都会遇到：

    2. 「输出的直流分量 = 输入的直流分量 × 直流增益」；
    3. 「\(\sum_k h(k)\) 就是直流增益」。

    只要记住第 3 条，前两条随时能自己推出来 ✓

    三、问题一的第二半：输出的自相关（本页核心）¶

    均值只用了 WSS 的第一条。要判定 \(y\) 是否广义平稳， 必须再算二阶量 —— 输出的自相关。这就是本页最核心的一段推导。

    3.1 定义出发，符号先摆清¶

    输出的自相关定义为

    \[R_y(m) = \mathbb{E}\big[y(n+m)\,y^{*}(n)\big]\]

    逐个符号读一遍：

    符号 含义
    \(m\) 延迟（lag），整数，可取正、负、零
    \(n\) 参考时刻，整数
    \(n+m\) 比参考时刻晚 \(m\) 个样点（\(m\) 为负则早）
    \(y^{*}(n)\) 第二个因子的共轭，写出来是为了让实值序列也自动成立
    \(R_y(m)\) 目标；我们想看到它只含 \(m\)、不含 \(n\) ✓

    为什么要取共轭：因为序列可能是复值的。 若不取共轭，\(R_y(0) = \mathbb{E}[\lvert y(n)\rvert^2]\) 这个「功率」就可能是复数， 失去物理意义。取了共轭，\(R_y(0) = \mathbb{E}[\lvert y(n)\rvert^{2}]\) 一定是非负实数 ✓ （对实值序列，共轭等于本身，可以不管它。 本页的文字推导保留共轭，代码例子都用实值序列。）

    3.2 代入输出的卷积表达式¶

    这一步把两个因子的卷积式都写出来，一个都不省。

    由 \(y(n) = \sum_k h(k) x(n-k)\)，把 \(n\) 换成 \(n+m\)：

    \[y(n+m) = \sum_{k} h(k)\, x(n+m-k)\]

    （求和哑标用 \(k\)。）

    同样地，\(y(n)\) 本身：

    \[y(n) = \sum_{l} h(l)\, x(n-l)\]

    注意这里换了一个哑标 \(l\) —— 这是必须的。 两个求和不能共用同一个哑标，否则后面没法把它们分开处理。 \(k\) 管第一个因子的时移，\(l\) 管第二个因子的时移，二者互不干涉 ✓

    把它俩乘起来（先不管期望）：

    \[y(n+m)\,y^{*}(n) = \Big(\sum_{k} h(k)\, x(n+m-k)\Big)\Big(\sum_{l} h(l)\, x(n-l)\Big)^{*}\]

    处理共轭：乘积的共轭等于各自共轭的乘积， 即 \((AB)^{*} = A^{*}B^{*}\)。于是

    \[\Big(\sum_{l} h(l)\, x(n-l)\Big)^{*} = \sum_{l} h^{*}(l)\, x^{*}(n-l)\]

    注意这里 \(h\) 也变成 \(h^{*}\) 了 —— 共轭作用在整个括号上，括号里每一项都要共轭， 所以 \(h(l)\) 和 \(x(n-l)\) 双双取共轭 ⚠ （很常见的错误是只给 \(x\) 取共轭，忘掉 \(h\)。）

    于是自相关写成

    \[R_y(m) = \mathbb{E}\Big[\Big(\sum_{k} h(k)\, x(n+m-k)\Big)\Big(\sum_{l} h^{*}(l)\, x^{*}(n-l)\Big)\Big]\]

    3.3 交换期望与求和¶

    两个有限/绝对收敛的求和相乘，可以先展开成双重和：

    \[\Big(\sum_k a_k\Big)\Big(\sum_l b_l\Big) = \sum_k \sum_l a_k b_l\]

    把期望号搬进去（和第二节同一个理由：\(\mathbb{E}\) 是线性算子）：

    \[R_y(m) = \sum_{k} \sum_{l} h(k)\, h^{*}(l)\, \mathbb{E}\big[x(n+m-k)\, x^{*}(n-l)\big]\]

    这里也把 \(h(k)h^{*}(l)\) 提到期望外面了， 因为它们都是确定性常数（系统参数）。

    3.4 关键一步：认出里面的 \(R_x\)¶

    现在看期望里剩下的东西：

    \[\mathbb{E}\big[x(n+m-k)\, x^{*}(n-l)\big]\]

    它是什么？ 回忆 \(R_x\) 的定义：

    \[R_x(m) = \mathbb{E}\big[x(n+m)x^{*}(n)\big]\]

    也就是说，\(R_x\) 的自变量是两个时刻之差。 所以我们只要去算这两个时刻之差是多少：

    因子 时刻
    第一个 \(n+m-k\)
    第二个 \(n-l\)

    作差：

    \[(n+m-k) - (n-l) = n + m - k - n + l = m - k + l\]

    注意 \(n\) 被消掉了 —— 这正是平稳性起作用的地方 ✓

    于是

    \[\mathbb{E}\big[x(n+m-k)\, x^{*}(n-l)\big] = R_x\big(m-k+l\big)\]

    这一步是整个推导的枢纽，值得反复看：

    • 如果 \(x\) 不平稳，右边就还得写成依赖 \(n\) 的形式，\(n\) 消不掉， 最后 \(R_y\) 也会依赖 \(n\)，输出就不是广义平稳的 ⚠
    • 如果 \(x\) 平稳，\(n\) 消掉，\(R_y\) 只含 \(m\) —— 输出平稳一半就证完了 ✓

    3.5 得到双重和¶

    代回去：

    \[\boxed{\;R_y(m) = \sum_{k}\sum_{l} h(k)\, h^{*}(l)\; R_x\big(m-k+l\big)\;}\]

    这个式子已经是对的了，但它不够好看 —— 双重求和看不出运算结构。下面把它整理成两次卷积。

    3.6 双重和是什么运算：两次卷积¶

    先做什么：固定 \(k\)，看内层对 \(l\) 的求和。

    \[\sum_{l} h^{*}(l)\, R_x\big(m-k+l\big)\]

    换一个变量：令 \(i = -l\)，则 \(l = -i\)，求和范围仍然是全体整数，于是

    \[\sum_{i} h^{*}(-i)\, R_x\big(m-k-i\big)\]

    这个形式正是卷积：一般地，

    \[(a * b)(m) = \sum_{i} a(i)\, b(m-i)\]

    把 \(a(i) = h^{*}(-i)\)、\(b(m-i) = R_x(m-k-i)\) 对上， 就认出内层求和是

    \[\underbrace{h^{*}(-m)}_{\text{反转共轭}} * \; R_x(m-k)\]

    再做什么：代入外层对 \(k\) 的求和。

    \[R_y(m) = \sum_{k} h(k)\, \Big[h^{*}(-m) * R_x(m-k)\Big]\]

    再用一次卷积的定义（这次是把 \(h\) 与括号里的东西卷积），得到

    \[R_y(m) = h(m) * \Big[h^{*}(-m) * R_x(m)\Big]\]

    最后一步：卷积可以换个顺序（卷积满足结合律）， 并且 \(h(m)\) 与 \(h^{*}(-m)\) 的卷积可以先算出来：

    \[R_y(m) = \Big[h(m) * h^{*}(-m)\Big] * R_x(m)\]

    3.7 把方括号命名：脉冲响应的自相关¶

    定义

    \[R_h(m) \;\triangleq\; h(m) * h^{*}(-m) = \sum_{k} h(k)\, h^{*}(k-m)\]

    为什么叫「脉冲响应的自相关」： 把 \(R_x\) 的定义里的随机序列换成确定序列 \(h\)， 并且把共轭放在第一个因子上（实值序列时两者无差别）， 得到的就是这个形式 —— 它确实是一个相关运算， 衡量的是 \(h\) 与自己错开 \(m\) 个样点后的相似程度 ✓

    几个立刻能用到的性质：

    性质 式子 说明
    偶对称共轭 \(R_h(-m) = R_h^{*}(m)\) 与一般自相关相同
    零点最大 \(\lvert R_h(m)\rvert \le R_h(0)\) \(R_h(0) = \sum_k \lvert h(k)\rvert^2\) 是系统的能量
    长度 若 \(h\) 长度为 \(L\)，则 \(R_h\) 长度为 \(2L-1\) 卷积把长度相加再减 1

    如果 \(h\) 是实序列（本页的代码例子都是），\(R_h(m) = \sum_k h(k)h(k-m)\)， 就是一个普通的自相关。

    3.8 最终结论¶

    \[\boxed{\;R_y(m) = R_h(m) * R_x(m)\;}\]

    用一句话说：

    输出自相关 = 脉冲响应自相关 与 输入自相关 的卷积。

    这解释了两件事：

    1. 输出为什么还平稳：等式右边只含 \(m\)，不含 \(n\)。 \(n\) 已经被消掉了（3.4 节那一步），所以 \(R_y\) 只依赖延迟 ✓
    2. 系统对相关性的作用：系统不是简单地把 \(R_x\) 平移或缩放， 而是用 \(R_h\) 去「抹」一遍 \(R_x\) —— 这是一个低通式的模糊。 所以滤波后的信号，其自相关通常比原来更「平滑」、相关时间更长 ⚠

    回看课件原话：课件在写出「\(y(n)\) 也广义平稳，其自相关是」之后， 给的正是 \(R_{yy}(m) = \sum_i \sum_l h(i)h^{*}(l) r_{xx}(m+l-i)\) 这个双重和， 接着单独定义了 \(R_{hh}(n) = \sum_i h(i)h^{*}(i+n)\)「脉冲响应序列的自相关」， 并注明「容易得到」\(r_{yy}(m) = r_{hh}(m) * r_{xx}(m)\)。 本页做的就是把这个「容易得到」展开 ✓

    这个验算里最容易搞错的两处

    第一处：延迟的方向。 \(R_y(m) = \sum_i R_h(i)\,R_x(m-i)\) —— \(R_x\) 的自变量是 \(m-i\)，不是 \(m+i\)，也不是 \(i-m\)。 代码里写 Rx(m - lags[i])。 符号搞错时，曲线形状仍会大致对（因为自相关是偶函数）， 但对称的序列会掩盖错误，读数就会偏 ⚠

    第二处：np.correlate 的输出下标。 np.correlate(h, h, "full") 返回的长度是 \(2L-1\)， 它的第 \(i\) 个元素对应延迟 \(i-(L-1)\)。 所以必须同时构造 lags = np.arange(-(L-1), L) 来配对， 不能想当然地把它当 \(m \ge 0\) 的序列用 ⚠

    \[h = [1,\ 0.5,\ -0.25], \qquad \text{长度 } L = 3\]

    第一步：算 \(R_h\)（\(2L-1 = 5\) 个值）。

    \[R_h(m) = \sum_k h(k)h(k-m)\]
    \(m\) 手算 结果
    \(-2\) \(h(0)h(2) = 1\times(-0.25)\) \(-0.25\)
    \(-1\) \(h(0)h(1)+h(1)h(2) = 0.5+0.5\times(-0.25)\) \(0.375\)

    \(1\) 与 \(m=-1\) 相同（实序列偶对称） \(0.375\)
    \(2\) 与 \(m=-2\) 相同 \(-0.25\)

    第二步：设输入是方差 \(\sigma_w^2 = 2\) 的白噪声，即

    第三步：卷积求 \(R_y\)。

    \[R_y(m) = \sum_i R_h(i)\,R_x(m-i) = 2\,R_h(m)\]

    四、回头判定问题一：为什么 \(y\) 也是广义平稳¶

    现在两个量都算出来了，可以回头核查 WSS 的两个条件。

    4.1 逐条核对¶

    WSS 的条件 需要的验证 第二节/第三节的结果 结论
    均值与 \(n\) 无关 \(\mathbb{E}[y(n)]\) 是否为常数 \(\mu_y = \mu_x H(0)\)，右边全是常数 满足 ✓
    自相关只与延迟有关 \(R_y\) 是否只含 \(m\) 3.4 节把 \(n\) 消掉，得 \(R_y = R_h * R_x\) 满足 ✓
    二阶矩有限 \(\mathbb{E}[\lvert y(n)\rvert^2] \lt \infty\) 需要系统稳定才成立 有条件满足 ⚠

    两条都满足 \(\Rightarrow\) \(y(n)\) 是广义平稳的 —— 这就是课件那句「易证明」的全部内容： 它不「易」在计算，而「易」在算完之后一眼看得出来 ✓

    4.3 结论成立的条件（不要漏掉）¶

    不是「任何线性系统 + 任何平稳输入」都成立

    下面前提缺一不可，缺了可能得出错误结论：

    前提 缺了会怎样
    输入广义平稳 \(n\) 消不掉，\(R_y\) 依赖 \(n\)，输出不平稳
    系统线性 无法把 \(y\) 写成卷积叠加
    系统时不变 \(h\) 依赖时刻，卷积形式失效
    系统稳定（\(\sum_k\lvert h(k)\rvert \lt \infty\)） 均值和自相关的级数可能不收敛，输出功率无穷大 ⚠

    一个典型的反例：让系统是 \(y(n) = n \cdot x(n)\) （线性但时变）。输入 \(x\) 平稳， 但 \(\mathbb{E}[y(n)] = n\mu_x\) 随时间线性增长， 方差也随 \(n^2\) 增长 —— 输出完全不平稳 ⚠

    另一个反例：理想微分器 \(H(\omega) = j\omega\)。 它在线性系统理论里常被当作合法系统， 但 \(\sum_k\lvert h(k)\rvert\) 不收敛（\(h\) 不是绝对可和）， 对白噪声输入，输出的功率 \(\frac{1}{2\pi}\int \omega^2 d\omega\) 也是发散的。 实际使用时要先限带 ✓

    五、频域形式：功率谱的乘法关系（最实用的结论）¶

    5.1 怎么从时域关系变到频域¶

    时域上我们已经得到了

    \[R_y(m) = R_h(m) * R_x(m)\]

    做法：两边同时取（离散时间）傅里叶变换。

    基础库里已讲过两条结论，本页直接用：

    结论 内容
    时域卷积定理 卷积的傅里叶变换 = 各自傅里叶变换的乘积
    维纳–辛钦定理 平稳序列自相关的傅里叶变换 = 它的功率谱

    维纳–辛钦定理的证明与逐项讨论属于上一页「自相关与功率谱」的内容，本页不重复。

    逐个因子做变换：

    时域对象 频域对象 为什么
    \(R_x(m)\) \(S_x(\omega)\) 维纳–辛钦定理
    \(R_h(m)\) \(\lvert H(\omega)\rvert^{2}\) 见 5.2 单独说明 ✓
    \(R_y(m)\) \(S_y(\omega)\) 维纳–辛钦定理
    卷积 \(*\) 乘积 \(\times\) 卷积定理

    于是

    \[\boxed{\;S_y(\omega) = \lvert H(\omega)\rvert^{2}\, S_x(\omega)\;}\]

    5.2 单独说明：为什么 \(R_h\) 的傅里叶变换是 \(\lvert H\rvert^2\)¶

    这一步很容易被跳过，但它是「为什么只看幅度」的根源，值得算一遍。

    从定义出发：

    \[R_h(m) = h(m) * h^{*}(-m)\]

    对两边做傅里叶变换。 逐项来：

    第一步：\(h(m)\) 的变换是 \(H(\omega)\)。

    第二步：\(h^{*}(-m)\) 的变换是什么？ 用两次傅里叶变换的性质：

    操作 对频域的影响
    时间反转 \(h(-m)\) \(H(-\omega)\)
    再取共轭 \(h^{*}(-m)\) \(H^{*}(-\omega)\)

    所以 \(h^{*}(-m) \longleftrightarrow H^{*}(-\omega)\)。

    第三步：卷积变乘积。

    \[R_h(m) = h(m) * h^{*}(-m) \;\longleftrightarrow\; H(\omega)\cdot H^{*}(-\omega)\]

    第四步：对实序列 \(h\)（本页所有例子都是）， 傅里叶变换有共轭对称性 \(H(-\omega) = H^{*}(\omega)\)， 于是 \(H^{*}(-\omega) = H(\omega)\)，得到

    \[R_h(m) \longleftrightarrow H(\omega)H(\omega) = H^{2}(\omega)\]

    对复序列则保留 \(H(\omega)H^{*}(-\omega)\) 的形式； 当 \(\omega\) 取实数时它仍然可以写成 \(\lvert H(\omega)\rvert^2\) （因为复序列的功率谱按定义含 \(\lvert\cdot\rvert^2\)）。

    因此

    \[R_h(m) \;\longleftrightarrow\; \lvert H(\omega)\rvert^{2}\]

    读法：脉冲响应的自相关在频域就是幅频响应的平方。 右端只含 \(\lvert H\rvert\)，完全不含相位 —— 这就是 5.4 节那个重要推论的来源 ✓

    顺带得到一条有用的等式：令 \(m = 0\)，

    \[R_h(0) = \frac{1}{2\pi}\int_{-\pi}^{\pi}\lvert H(\omega)\rvert^{2}\,d\omega = \sum_k \lvert h(k)\rvert^{2}\]

    左边是系统能量（时域），右边是频域的能量积分 —— 这是帕塞瓦尔等式在 LTI 系统上的一个具体形态 ✓

    5.3 公式怎么读：三个部分各是什么¶

    \[S_y(\omega) = \lvert H(\omega)\rvert^{2}\, S_x(\omega)\]
    部分 名称 含义 单位量级
    \(S_x(\omega)\) 输入的功率谱 输入在各频率上的功率分布 功率/频率
    \(\lvert H(\omega)\rvert^{2}\) 系统的功率增益 系统对各频率成分的放大/压制倍数 无量纲（或功率比）
    \(S_y(\omega)\) 输出的功率谱 输出的功率分布 功率/频率

    读法：输出功率谱 = 输入功率谱在每一点上乘一个非负的倍数。 这个倍数就是系统的功率增益，它处处非负，因为它是平方。

    频率处的增益 对应行为 结果
    \(\lvert H\rvert^{2} = 1\) 全通 该频率成分原样通过
    \(\lvert H\rvert^{2} \lt 1\) 衰减 该频率成分被压制 ✓
    \(\lvert H\rvert^{2} = 0\) 完全阻断 该频率成分被彻底去掉
    \(\lvert H\rvert^{2} \gt 1\) 放大 该频率成分被增强 ⚠

    注意 \(\lvert H\rvert^{2}\) 不可能为负 —— 这意味着系统永远不能让某个频率的功率变成负的。 滤波器只能「搬运和压制」，不能凭空制造频率成分。 绝对不可能出现「输入在某个频率上功率是 0，输出却在那个频率上功率不为 0」的情况 （除非系统是非线性的，那就不在这个框架里了）✓

    5.4 重要推论：功率谱与相位无关¶

    看公式：

    \[S_y(\omega) = \lvert H(\omega)\rvert^{2} S_x(\omega)\]

    右端出现的是 \(\lvert H(\omega)\rvert\)（幅度）， \(\arg H(\omega)\)（相位）一次都没出现。

    「相位不影响功率谱」是把双刃剑

    这句话没错，但要理解它的两面：

    第一面（好消息）：设计滤波器时， 如果只看输出的功率分布（噪声抑制、频谱整形）， 那么只要设计幅度响应就够了，相位可以随便定 ✓

    第二面（容易误用）：这句话只对功率谱成立。 输出的波形、峰值位置、群延迟全都由相位决定 ⚠ 两个幅度响应完全相同的系统，输出波形可以完全不同。

    一个常见误解：「反正功率谱一样，相位怎么设都行」—— 在需要对波形对齐的场合（通信解调、阵列波束形成、脉冲压缩） 这样想会直接出错 ⚠

    本页的验证代码会打印出：两个只有相位相反的系统， 输出波形最大差 \(4.77\)（差异巨大）， 但功率谱最大差约 \(5\times10^{-12}\)（数值误差级别）—— 这个对比很能说明问题 ✓

    六、几个立刻能用的推论¶

    6.1 总功率怎么变：积分公式¶

    功率谱是「功率/频率」，所以总功率就是功率谱在全频段的积分。 令 \(m = 0\)：

    \[R_y(0) = \frac{1}{2\pi}\int_{-\pi}^{\pi} S_y(\omega)\, d\omega = \frac{1}{2\pi}\int_{-\pi}^{\pi} \lvert H(\omega)\rvert^{2} S_x(\omega)\, d\omega\]
    符号 说明
    \(R_y(0)\) 输出的平均功率，等于 \(\mathbb{E}[\lvert y(n)\rvert^{2}]\)
    \(S_y(\omega)\) 输出功率谱
    \(\frac{1}{2\pi}\int_{-\pi}^{\pi}(\cdot)d\omega\) 数字频率上的平均（相当于对频率取均值）
    \(1/(2\pi)\) 因子 因为 \(\omega\) 单位是弧度/样点，一个周期的长度是 \(2\pi\)

    读法：输出功率 = 输入功率谱被系统功率增益加权积分。 系统在哪个频段增益大，那个频段的输入功率就更被计入输出 ✓

    6.2 白噪声通过理想低通：功率随带宽变化¶

    输入的设定：白噪声，\(R_x(m) = \sigma^2\delta(m)\)， 对应的功率谱是常数 \(S_x(\omega) = \sigma^2\)（这就是「白」的意思：各频率功率一样）。

    系统的设定：理想低通，通带 \([-\omega_c, \omega_c]\)，即

    \[\lvert H(\omega)\rvert = \begin{cases} 1, & \lvert\omega\rvert \le \omega_c\\ 0, & \text{其他}\end{cases}\]

    代公式：

    \[R_y(0) = \frac{1}{2\pi}\int_{-\omega_c}^{\omega_c} \sigma^{2}\, d\omega = \sigma^{2}\cdot\frac{2\omega_c}{2\pi} = \sigma^{2}\cdot\frac{\omega_c}{\pi}\]

    结论：输出功率 = 输入功率谱高度 × 带宽（归一化）。

    \[\text{输出功率} = \sigma^{2}\times\frac{\text{带宽}}{2\pi}\]

    这是降噪原理的全部内容：白噪声的功率均匀分布在所有频率上， 低通滤波只保留 \(\omega_c/\pi\) 这一小部分， 所以噪声功率按带宽比例下降 ✓

    顺带解释 3.10 节那个例子的「功率变大」： 那里输入是白噪声（\(S_x = \sigma_w^2 = 2\)，带宽全开）， 系统 \(\lvert H\rvert^2\) 在某些频段大于 \(1\)， 所以积分结果 \(2.625 \gt 2\) —— 滤波器把某些频率加强了，所以输出总功率反而更大 ⚠

    如果噪声是白的、信号集中在某个窄带里， 那么用一个匹配的窄带滤波器，噪声功率按带宽比下降， 而信号功率几乎不损失 —— 信噪比就提高了 ✓ 怎么把「带宽选在哪」变成一个有解的最优化问题， 是后面最优滤波部分的内容。

    6.5 延伸：白化滤波器（把有色噪声变白）¶

    前面的关系 \(S_y = \lvert H\rvert^{2}S_x\) 可以反着用： 如果想让输出谱是常数（白），就要令

    \[\lvert H(\omega)\rvert^{2} = \frac{S_{\text{目标}}}{S_x(\omega)} \;\Rightarrow\; \lvert H(\omega)\rvert = \frac{\text{常数}}{\sqrt{S_x(\omega)}}\]

    也就是说，在输入功率谱大的地方把系统增益做小， 正好把输入的谱「拉平」。

    这一条在课件里没有展开，本页把它标为延伸： 它的完整讨论（含相位怎么选）属于后续「最优滤波」的内容， 本页只给出这个最基本的思想 ✓

    验证思路：如果输入是 AR(1)（功率谱非平坦）， 用一个 \(h = [1, -\rho]\) 的系统（即 \(\lvert H(\omega)\rvert^2 = \lvert 1-\rho e^{-j\omega}\rvert^{2}\)） 正好与输入的 \(\lvert 1-\rho e^{-j\omega}\rvert^{-2}\) 抵消， 输出就变成白的。

    6.6 理想微分器：为什么求导会放大噪声¶

    系统的设定：理想微分器，\(\lvert H(\omega)\rvert = \lvert\omega\rvert\)。 它对一个正弦输入给出与频率成正比的放大，所以叫微分器。

    输出的功率谱：

    \[S_y(\omega) = \omega^{2} S_x(\omega)\]

    对白噪声输入（\(S_x = \sigma^2 = 1\)）：

    \[R_y(0) = \frac{1}{2\pi}\int_{-\pi}^{\pi}\omega^{2}\, d\omega = \frac{1}{2\pi}\cdot\frac{2\pi^{3}}{3} = \frac{\pi^{2}}{3} \approx 3.2899\]

    对比：输入功率是 \(1\)，输出功率约 \(3.29\) —— 噪声功率涨了 3 倍多，仅仅因为做了差分/求导 ⚠

    为什么：\(\omega^{2}\) 把高频放得特别大（\(\omega\) 越接近 \(\pi\)，放大越多）， 而白噪声在每个频率上都有功率，所以总量被高频项抬起来了 ✓

    七、相关时间与系统时间常数：谁说了算¶

    7.1 什么叫「相关时间」¶

    自相关函数 \(R_x(m)\) 从 \(R_x(0)\) 开始， 随着延迟 \(\lvert m\rvert\) 增大而衰减。 它在多长的延迟上基本衰减完，就是序列的相关时间。

    一个方便的量化指标是归一化一阶自相关：

    \[\rho_1 \;\triangleq\; \frac{R_x(1)}{R_x(0)}\]

    读法：相邻两个样点之间的相似程度。

    \(\rho_1\) 的大小 含义 相关时间
    接近 \(0\) 相邻样点几乎不相关 很短（白噪声就是 \(\rho_1=0\)）
    接近 \(1\) 相邻样点高度相似 很长（变化缓慢）
    为负（如 \(-0.5\)） 相邻样点倾向反号 呈振荡型，另说

    7.2 系统会把相关性「拉长」¶

    回到核心公式：

    \[R_y(m) = R_h(m) * R_x(m)\]

    卷积就是一种「按 \(R_h\) 的形状做滑动平均」。 所以：

    输入的相关时间 系统 \(R_h\) 的宽度 输出的相关时间 谁在主导
    很短（\(\rho_1 \approx 0\)） 宽（系统时间常数大） 由系统决定 系统 ✓
    很长（\(\rho_1 \approx 1\)） 窄（系统几乎是直通） 仍保留输入的长相关 输入 ✓
    很长 宽 更长 两者叠加
    很短 窄 仍然很短 两者都不贡献

    一句话：输出自相关的宽度，大致是两个宽度的「叠加」， 卷积只会让形状变宽，不会变窄 ⚠ （除非系统有负系数，把部分相关抵消掉。）

    7.4 这对「滤波后多久进入稳态」意味着什么¶

    实际含义：任何滤波器都有记忆。 输入加上以后，输出要过一段时间才「稳定下来」。 这段时间的量级由系统的时间常数决定，不是由输入决定 ✓

    场景 该怎么办
    系统时间常数大（窄带、长 FIR） 开始的若干样点要丢弃（弃置期）
    系统时间常数小 弃置期短，可以快速出结果
    输入本身相关时间就很长 更要注意初始条件，累计误差会保留很久

    这也解释了为什么仿真代码里总要把输出的前若干点丢掉： 那些点是系统从零初始状态「爬起来」的过程， 它们不满足平稳性假设， 拿它们去估自相关或功率谱会得到有偏的结果 ⚠

    白噪声，方差 \(\sigma^2\) \(\sigma^{2}\delta(m)\) \(\sigma^{2}\)（常数） \(\sigma^{2}R_h(m)\) \(\sigma^{2}\lvert H\rvert^{2}\) ✓

    8.3 容易混的两组对照¶

    容易混淆的说法 正确的说法 差别
    「输出谱 = 输入谱 × 系统谱」 「输出功率谱 = 输入功率谱 × \(\lvert H\rvert^{2}\)」 随机信号的频谱本身是随机函数，不能直接乘 ⚠
    「自相关乘自相关」 「自相关卷积自相关」 是卷积不是乘积；只有到频域才变乘积 ✓

    滤波器设计里最常见的三个误解

    1. 「功率谱一样，输出就一样」 —— 错。波形、峰值位置、延迟都由相位决定，只有功率谱相同 ⚠
    2. 「输出的均值 = 输入的均值」 —— 只有当 \(H(0)=1\) 时才对；\(H(0)=0\) 的滤波器输出均值是 0 ✓
    3. 「滤波器一定降低总功率」 —— 错。若某频段 \(\lvert H\rvert^{2} \gt 1\)，输出总功率可能反而变大 ⚠ 低通降噪是因为它把通带外的增益压到 0，而不是「滤波」这个动作本身减少功率。

    m = abs(m)
    return float(np.dot(s[m:], s[:len(s) - m]) / len(s))

err_r = max(abs(acf(yc, m) - sum(Rh[i] * Rx(m - lags[i])
                                 for i in range(len(Rh))))
            for m in range(-4, 5))

    先减均值再估自相关和功率谱

    上面那段代码里有一行很容易被忽略，但它很关键：

    xc, yc = x - x.mean(), y - y.mean()

    为什么必须先减均值：我们用的解析式 \(R_x(m) = \frac{\sigma_w^2}{1-\rho^2}\rho^{\lvert m\rvert}\) 描述的是零均值序列的自相关。 如果序列均值是 \(3\)，直接从样本算 \(\mathbb{E}[y(n+m)y(n)]\) 会多出一项 \(\mu_y^{2} = 27.56\)，把结果整体抬高 ⚠

    一般写法：样本自相关要写成「先减均值再做相关」的形式：

    \[\hat{R}_y(m) = \frac{1}{N}\sum_{n=0}^{N-\lvert m\rvert-1} \big(y(n+\lvert m\rvert)-\bar{y}\big)\big(y(n)-\bar{y}\big)\]

    这一步在下一部分讲参数估计时会专门讨论 ✓

    例题 1：手算 \(H(0)\) 与输出均值¶

    题目：输入 \(x(n)\) 是广义平稳序列，均值 \(\mu_x = 4\)。 系统为 \(h = [0.5,\ 0.5,\ 0.5,\ 0.5]\)（四点滑动平均）。 求 \(H(0)\)、输出均值 \(\mu_y\)，并说明这个系统对直流分量的作用。

    思路

    直接用 \(\mu_y = \mu_x H(0)\)，其中 \(H(0) = \sum_k h(k)\)。 先算求和，再乘，最后解读。

    解答

    第一步：算直流增益。

    \[H(0) = \sum_k h(k) = 0.5 + 0.5 + 0.5 + 0.5 = 2.0\]

    第二步：套公式。

    \[\mu_y = \mu_x H(0) = 4 \times 2.0 = 8\]

    第三步：解读。 这个系统的 \(H(0)=2\)，不是 1， 所以它把直流分量放大了 2 倍 ⚠

    很多人会本能地认为「平均四个数不会改变均值」—— 那只对 \(\frac{1}{4}[1,1,1,1]\) 成立。 现在系数之和是 2 而不是 1，输出均值就翻倍了 ✓

    要真正做「不变均值」的滑动平均，系数必须归一化：

    \[h = \tfrac{1}{4}[1,1,1,1], \qquad H(0) = 1, \qquad \mu_y = \mu_x = 4\]

    结论：\(\mu_y = 4\)（归一化）或 \(\mu_y = 8\)（未归一化）， 判决标准只有一个：\(\sum_k h(k)\) 等于多少。

    例题 2：用 \(R_y = R_h * R_x\) 求输出自相关¶

    题目：设 \(h = [1,\ -1]\)（一阶差分）， 输入是方差 \(\sigma_w^{2} = 3\) 的白噪声。 求输出的自相关 \(R_y(m)\) 与输出功率 \(R_y(0)\)。

    思路

    先算 \(R_h\)（长度为 \(2L-1=3\)）， 再用白噪声的特例 \(R_y = \sigma_w^{2}R_h\)。

    解答

    第一步：算 \(R_h(m) = \sum_k h(k)h(k-m)\)。

    \(h(0) = 1\)，\(h(1) = -1\)，其余为零。

    \(m\) 涉及的乘积 \(R_h(m)\)
    \(-1\) \(h(0)h(1) = 1\times(-1)\) \(-1\)
    \(0\) \(h(0)^2 + h(1)^2 = 1+1\) \(2\) ✓
    \(1\) \(h(1)h(0) = (-1)\times1\) \(-1\)
    其他 没有交叠项 \(0\)

    所以 \(R_h = [-1,\ 2,\ -1]\)。

    第二步：用白噪声特例。 白噪声的 \(R_x(m) = \sigma_w^{2}\delta(m)\)， 代入 \(R_y(m) = \sum_i R_h(i)R_x(m-i)\)， 只有 \(m-i=0\) 那一项留下：

    \[R_y(m) = \sigma_w^{2} R_h(m) = 3R_h(m)\]

    第三步：写出结果。

    \[R_y(0) = 3\times2 = 6, \qquad R_y(\pm1) = 3\times(-1) = -3, \qquad R_y(m) = 0 \;\;(|m| \ge 2)\]

    第四步：检查两条恒等式。

    \[R_y(0) = \sigma_w^{2}\sum_k h^{2}(k) = 3\times(1+1) = 6 \;\checkmark\]

    第五步：解读符号。 \(R_y(1) = -3 \lt 0\) —— 相邻输出的相关是负的。 直觉上很合理：差分器输出的相邻样点是「两个相邻增量」， 而白噪声的相邻增量方向相反的可能性更大 ✓

    再验证 \(H(0)\)：\(H(0) = 1-1 = 0\)， 所以这个滤波器输出均值为 0（去直流）✓

    例题 3：为什么 \(R_y(0)\) 会变大——用频域解释¶

    题目：例题 2 里输入功率是 \(3\)，输出功率是 \(6\)， 功率翻倍了。这合理吗？用 \(S_y = \lvert H\rvert^{2}S_x\) 解释。

    思路

    算 \(\lvert H(\omega)\rvert^{2}\) 随 \(\omega\) 变化的曲线， 再对白噪声谱做积分。

    解答

    第一步：写出幅频响应。

    对 \(h = [1,-1]\)：

    \[H(\omega) = 1 - e^{-j\omega}\]

    第二步：算模平方。 用 \(\lvert 1-e^{-j\omega}\rvert = 2\lvert\sin(\omega/2)\rvert\)：

    \[\lvert H(\omega)\rvert^{2} = (1-\cos\omega)^{2} + \sin^{2}\omega = 2 - 2\cos\omega = 4\sin^{2}\!\left(\frac{\omega}{2}\right)\]

    第三步：在不同频率上取值。

    \(\omega\) \(\sin(\omega/2)\) \(\lvert H\rvert^{2}\) 行为
    \(0\) \(0\) \(0\) 直流被完全阻断 ✓
    \(\pi/2\) \(\sin(\pi/4) \approx 0.7071\) \(2\) 放大 2 倍
    \(\pi\) \(\sin(\pi/2)=1\) \(4\) 最高频放大 4 倍 ⚠

    第四步：对白噪声积分。 \(S_x(\omega) = 3\) 为常数：

    \[R_y(0) = \frac{1}{2\pi}\int_{-\pi}^{\pi} 4\sin^{2}\!\frac{\omega}{2}\cdot3\,d\omega = \frac{3\cdot 4}{2\pi}\int_{-\pi}^{\pi}\sin^{2}\!\frac{\omega}{2}\,d\omega\]

    而 \(\frac{1}{2\pi}\int_{-\pi}^{\pi}\sin^{2}\frac{\omega}{2}d\omega = \frac{1}{2}\)，于是

    \[R_y(0) = 3\times4\times\frac{1}{2} = 6 \;\checkmark\]

    与例题 2 完全一致。

    第五步：解读「为什么变大」。 差分器在 \(\omega = 0\) 处增益为 0，看似「只减不加」， 但在接近 \(\pi\) 的高频段增益达到 4， 而白噪声在每个频率上都有功率，所以高频段被大幅放大的部分 盖过了直流段被压掉的部分 —— 总功率净增加 ✓

    结论：「滤波」不等于「减少功率」， 它只是按 \(\lvert H\rvert^{2}\) 重新分配功率。 要减少功率，必须让 \(\lvert H\rvert^{2} \le 1\) 在全频段成立 ⚠

    例题 4：给定输出谱，反推系统的幅度响应¶

    题目：某系统的输入是白噪声，功率谱 \(S_x(\omega) = 2\)。 测得的输出功率谱在 \(\omega = 0\) 处为 \(0\)， 在 \(\omega = \pi\) 处为 \(18\)，且输出功率谱关于 \(\omega\) 平滑变化。 已知系统是一个两点 FIR 滤波器 \(h = [a, b]\)，求 \(a\)、\(b\)。

    思路

    两点 FIR 的幅频响应是 \(\lvert a + be^{-j\omega}\rvert\)， 在 \(\omega=0\) 处是 \(\lvert a+b\rvert\)，在 \(\omega=\pi\) 处是 \(\lvert a-b\rvert\)。 把两个条件写成方程，注意符号可以有多种组合。

    解答

    第一步：列方程。 由 \(S_y = \lvert H\rvert^{2}S_x\)：

    \[\lvert H(0)\rvert^{2} = \frac{S_y(0)}{S_x} = \frac{0}{2} = 0 \;\Rightarrow\; \lvert a+b\rvert = 0 \;\Rightarrow\; b = -a\]
    \[\lvert H(\pi)\rvert^{2} = \frac{S_y(\pi)}{S_x} = \frac{18}{2} = 9 \;\Rightarrow\; \lvert a-b\rvert = 3\]

    第二步：代入求解。 由 \(b = -a\)，\(a - b = 2a\)，于是

    \[\lvert 2a\rvert = 3 \;\Rightarrow\; \lvert a\rvert = 1.5\]

    第三步：写出解族。 \((a,b) = (1.5,\,-1.5)\) 或 \((-1.5,\,1.5)\)。

    第四步：说明为什么有两个解。 它们互为相反数，幅频响应完全相同， 因为 \(\lvert -H(\omega)\rvert = \lvert H(\omega)\rvert\)。 这正好又印证了 5.4 节的结论： 功率谱只能确定幅度，确定不了符号，更确定不了相位 ⚠

    第五步：验证。

    \[\lvert H(\omega)\rvert^{2} = \lvert a(1-e^{-j\omega})\rvert^{2} = 1.5^{2}\times4\sin^{2}\frac{\omega}{2} = 9\sin^{2}\frac{\omega}{2}\]
    • \(\omega=0\)：\(9\times0 = 0\) ✓
    • \(\omega=\pi\)：\(9\times1 = 9\)，乘 \(S_x=2\) 得 \(18\) ✓

    自测¶

    Q1 判断对错并说明理由： 「若输入 \(x(n)\) 广义平稳，系统是 LTI，则输出的自相关 \(R_y(m)\) 等于输入自相关 \(R_x(m)\) 乘上系统直流增益的平方。」

    提示

    想想 \(R_y\) 到底是乘还是卷积， 再想想直流增益 \(H(0)\) 有没有资格出现在 \(R_y\) 的公式里。

    解答

    错，而且错了三处。

    错误点 正确的说法
    说是「乘」 是卷积：\(R_y(m) = R_h(m) * R_x(m)\) ✓
    说「乘 \(H(0)\) 的平方」 出现的是 \(\lvert H(\omega)\rvert^{2}\)，依赖频率，不是常数 \(H(0)\) ✓
    说「\(R_y\) 与 \(R_x\) 成比例」 只有白噪声输入（\(R_x\) 是冲激）时才有比例关系

    正确的完整对照：

    对象 关系
    均值 \(\mu_y = \mu_x\,H(0)\) —— 这里是乘常数 ✓
    自相关 \(R_y(m) = R_h(m) * R_x(m)\) —— 这里是卷积 ✓
    功率谱 \(S_y(\omega) = \lvert H(\omega)\rvert^{2}S_x(\omega)\) —— 这里是逐点相乘 ✓

    为什么会搞错：均值是零阶量（只看一个数）， 自相关是二阶量（看整个函数）， 系统对二阶量的作用必须用卷积/逐点相乘来描述， 不能用一个常数概括 ⚠

    唯一说对的地方：结论里隐含了「输出仍平稳」这个前提， 这一条本身是对的。

    Q2 系统 \(h = [1,\ 0.5]\)，输入 \(x(n)\) 的均值 \(\mu_x = 10\)， 自相关 \(R_x(0) = 4\)、\(R_x(1) = R_x(-1) = 2\)（其余为零）。 求 \(\mu_y\) 与 \(R_y(0)\)。

    \(i\) \(R_h(i)\) \(R_x(-i)\) 乘积

    Q3 两个滤波器的脉冲响应分别是 \(h_1 = [1, 0, 1]\) 与 \(h_2 = [0, 1, 0]\)（中间的 1 在 \(n=0\)）。 输入是同一个白噪声。问： (a) 它们的幅频响应各自是什么？ (b) 输出的功率谱是否相同？ © 输出的波形是否相同？为什么？

    提示

    先算两者的 \(H(\omega)\)，比较模； 再想 \(h_1\) 在时域做了什么（把样点隔一个相加）。

    解答

    （a）幅频响应。

    \[H_1(\omega) = 1 + e^{-j2\omega}, \qquad \lvert H_1(\omega)\rvert^{2} = 2 + 2\cos 2\omega\]
    \[H_2(\omega) = 1, \qquad \lvert H_2(\omega)\rvert^{2} = 1\]

    两者的幅度响应完全不同， 所以这里不是「只有相位不同」的例子 —— 它的作用是提醒：幅度不同时功率谱必然不同 ⚠

    （b）输出功率谱。

    \[S_{y1}(\omega) = (2+2\cos 2\omega)S_x(\omega), \qquad S_{y2}(\omega) = S_x(\omega)\]

    不同。 \(h_1\) 在 \(\omega = \pi/2\) 附近增益为 \(2-2=0\) （因为 \(2+2\cos\pi = 0\)？注意 \(\omega=\pi/2\) 时 \(2\omega=\pi\)，\(\cos\pi=-1\)， 所以 \(\lvert H_1\rvert^{2}=0\)）， 而 \(h_2\) 全通 ✓

    （c）输出波形。

    \(y_2(n) = x(n)\)，就是输入本身； \(y_1(n) = x(n) + x(n-2)\)，是两个相隔 2 个样点的值相加。 波形当然不同 ✓

    这道题的价值在于把三类关系一次讲清：

    比较 \(h_1\) 与 \(h_2\) 结论
    幅度响应 不同 ✓
    功率谱 不同 由幅度决定
    波形 不同 由幅度 + 相位共同决定

    要构造「只有相位不同」的例子， 必须保持 \(\lvert H\rvert\) 一样，比如时间反转 \(h'_1 = [1, 0, 1]\) 的时间反转还是它自己， 所以应该用 \(h = [1, 0.5, 0.25]\) 与它的反转 \([0.25, 0.5, 1]\)（这正是 5.6 节的做法）✓

    Q4 某测量得到的输出功率谱在低频段很低、高频段很高。 （a）能断定系统是「高通」吗？ （b）如果只知道系统幅度响应而不知道相位， 输出的哪些特征可以预测、哪些不能？

    提示

    (a) 想 \(S_y = \lvert H\rvert^{2}S_x\) 里还有一个因子 \(S_x\)。 (b) 回到「功率谱与相位无关」那条结论。

    解答

    （a）不能直接断定。

    因为 \(S_y = \lvert H\rvert^{2}S_x\)，输出谱高有两个可能来源： 系统在高频增益大（高通），或者输入本身在高频功率就大 （有色输入）。两种情况的输出谱可以完全一样 ⚠

    要区分，必须知道 \(S_x\)。 如果输入是白噪声（\(S_x\) 为常数）， 那么输出谱的形状就是 \(\lvert H\rvert^{2}\) 的形状， 这时才能反推系统的幅度响应 ✓

    已知条件 能推断什么
    \(S_x\) 已知且平坦 \(S_y\) 的形状 = 幅度响应的平方形状 ✓
    \(S_x\) 已知但非平坦 需要做除法才能得到 \(\lvert H\rvert^{2}\)
    \(S_x\) 未知 无法分离两者的贡献 ⚠

    （b）可预测与不可预测的特征。

    输出特征 能否由幅度响应预测
    功率谱 \(S_y\) 能 ✓ 只要 \(S_x\) 已知
    总功率 \(R_y(0)\) 能 ✓ 它是 \(S_y\) 的积分
    均值 能 ✓ 只需 \(H(0)\) 这一个数
    自相关函数 \(\lvert R_y\rvert\) 能（它是 \(S_y\) 的逆变换）✓
    波形 \(y(n)\) 不能 ⚠
    峰值出现的位置 不能 ⚠
    群延迟 / 相位失真 不能 ⚠

    一句话：幅度管能量分布，相位管时间位置。 只要关心「有多少功率分布在哪个频率」，看幅度就够； 一旦关心「信号什么时候到、长什么样」，就必须看相位 ✓

    小结¶

    要记住的 为什么
    \(\mu_y = \mu_x\,H(0)\) 期望是线性的，可穿过卷积求和；\(H(0)=\sum_k h(k)\) 是直流增益 ✓
    \(H(0)=0\) 的滤波器输出均值为 0 这就是「去掉直流分量」的原理 ✓
    \(R_y(m) = R_h(m) * R_x(m)\) 自相关是二阶量，系统的作用是卷积而不是相乘 ✓
    \(R_h(m) = h(m) * h^{*}(-m)\) 脉冲响应的自相关，长度是 \(2L-1\)
    \(S_y(\omega) = \lvert H(\omega)\rvert^{2}S_x(\omega)\) 卷积在频域变乘积；这是本页最常用的公式 ✓
    \(R_h\) 的谱是 \(\lvert H(\omega)\rvert^{2}\) 时间反转共轭只改相位，模平方不变 ✓
    功率谱与相位无关 所以只关心功率分布时只需设计幅度 ✓
    但波形与相位高度相关 需要对齐波形、控制延迟时相位是决定性的 ⚠
    输入广义平稳 \(\Rightarrow\) 输出广义平稳 前提：LTI 且稳定，否则级数可能不收敛 ⚠
    白噪声过理想低通：功率 \(=\sigma^{2}\cdot\)带宽\(/2\pi\) 降噪原理的全部内容 ✓
    求导/差分放大高频 \(\lvert H\rvert^{2}=\omega^{2}\)，白噪声功率从 \(1\) 涨到 \(\pi^{2}/3 \approx 3.29\) ⚠
    卷积只会把相关性拉宽 输出的相关时间由输入与系统共同决定，通常由系统主导 ✓
    滤波器不一定降低总功率 若某频段 \(\lvert H\rvert^{2}>1\)，输出功率可能变大 ⚠
    仿真要丢弃起始段 系统建立期不满足平稳假设，会污染统计估计 ✓
