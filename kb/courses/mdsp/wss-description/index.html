    广义平稳过程的统计描述¶

    这一页解决一个问题：一个随机信号那么多条可能的样本，我们到底用哪几个数把它描述清楚？

    上一节我们定义了随机过程，也区分了「系综统计」和「时间统计」两条路。 可是一个随机过程的完整描述是无穷多个时刻上的联合分布， 那是个没法写下来、更没法从数据里估出来的东西。

    这一页要回答的是：能不能只留两个函数，就够工程上用了？

    答案是可以，代价是给随机过程加一条假设 —— 广义平稳。 在这一条假设下，描述一个随机过程只需要：

    要记住的量 是什么 取值范围
    均值 \(\mathbb{E}[X(t)]\) 一个常数 实数或复数
    系综自相关 \(R_X(\tau)\) 只与时间差有关的一个函数 有界函数

    本课程后面几乎所有内容，都在这两个量上做文章。 这不是偷懒， 而是在「假设够宽松、结论够有用」之间取的平衡点。

    这一页的主线

    整页只围绕一个函数展开 —— 系综自相关函数 \(R_X(\tau)\)：

    \[R_X(\tau) = \mathbb{E}\big[X(t+\tau)X^{*}(t)\big]\]

    读懂它的关键是三件事：

    要问的 答案
    对什么取平均 系综（同一时刻、多条样本）✓
    结果还依赖时间吗 不依赖，只依赖时间差 \(\tau\) ✓
    它和「时间自相关」一样吗 不一样，两者相等需要遍历性 ⚠

    一、先把「平稳」这件事讲清楚¶

    1.1 严格平稳：要求所有阶的分布都不随时间平移而变¶

    本课程课件对平稳性的定义是从联合分布出发的：

    一个随机过程 \(X(t)\) 需要用一组时刻 \(t_1, t_2, \dots, t_N\) 上的 一组随机变量 \(\{X_1, X_2, \dots, X_N\}\) 的联合统计分布 \(P(x_1, x_2, \dots, x_N)\) 来描述。

    课件接着说：对固定的 \(N\)，如果联合分布关于时间轴的任意偏移不变， 则该过程是一个平稳到 \(N\) 阶的随机过程；如果 \(N \to \infty\) 时过程是平稳的， 则是一个严格平稳过程。

    把这句话写成公式。所谓「时间轴任意偏移不变」，就是任取一个偏移量 \(\Delta\)：

    \[P\big(x_1, x_2, \dots, x_N \mid t_1, t_2, \dots, t_N\big) = P\big(x_1, x_2, \dots, x_N \mid t_1+\Delta, t_2+\Delta, \dots, t_N+\Delta\big)\]

    怎么读这个式子：把整幅「时间轴」往右拖 \(\Delta\)， 你看到的那组随机变量的联合分布长得一模一样。 换句话说，\(t = 0\) 秒附近的样子，和 \(t = 100\) 秒附近的样子， 在统计意义上分不出来。

    ⚠ 注意条件有多强：它要求每一个 \(N\)、每一组 \(t_1,\dots,t_N\) 都成立。 \(N\) 取遍所有正整数，也就等于要求所有阶的分布都不变。

    课件还点名了两类常见的非平稳过程作为对照： 均值时变或方差时变的过程。这两类过程连一阶、二阶都没保住， 自然更谈不上严格平稳。

    1.2 广义平稳：只要一阶矩和二阶矩满足¶

    课件原文（转述）：如果随机过程的均值是常数且二阶平稳，则称为广义平稳过程。

    拆成两条，一条一条写清。

    条件一：均值为常数。 记随机变量 \(X(t)\) 的期望为 \(\mathbb{E}[X(t)]\)，要求

    \[\mathbb{E}[X(t)] = \mu, \qquad \text{对一切 } t \text{ 成立}\]

    其中 \(t\) 是时间（或时间下标），取值范围是整个时间轴； \(\mu\) 是一个与 \(t\) 无关的常数（对复过程 \(\mu\) 一般是复数）。 「\(\mu\) 与 \(t\) 无关」这句话就是全部内容 —— 今天测和明天测， 平均电平不能变。

    ⚠ 特别提醒：\(\mu\) 是常数，不是零。 很多教材为了省事直接假设均值为零，那是一个额外的简化假设， 不是广义平稳定义的一部分。本页后面的数值例子会把均值设成零， 那是为了对照教科书公式方便，同学们自己看别的材料时要留意这一点。

    条件二：二阶平稳，即自相关只与时间差有关。 要求

    \[R_X(t_1, t_2) = R_X(t_1 - t_2)\]

    怎么读：自相关有两个时间自变量 \(t_1\) 和 \(t_2\)， 一般情况下它是一个二元函数，随便改哪一个都会得到不同的值。 二阶平稳要求它只依赖两个时刻的差 \(t_1 - t_2\)，与它们的绝对位置无关。

    课件正是这么写的：广义平稳过程的自相关与时间的计算起点无关。 所以可以记 \(\tau = t_1 - t_2\)，写成

    \[R_X(t_1, t_2) = R_X(t_1 - t_2) = R_X(\tau)\]

    二阶平稳 = 自相关退化成一元函数。 这一步的降维是本页所有结论的源头： 一个二元函数变成一元函数，意味着只要估计一条曲线， 而不是估计一整张曲面。

    1.3 「广义」到底「广」在哪¶

    这是本页最值得掰扯的一句话。

    严平稳要求所有阶的分布不随时间平移而变； 广义平稳只要求一阶矩（均值）与二阶矩（自相关）满足，所以适用范围大得多。

    把它写成对照表：

    严格平稳（严平稳） 广义平稳（WSS）
    约束对象 所有阶的联合分布 只约束一阶矩 + 二阶矩
    数学条件 任意 \(N\)、任意时刻组的联合分布平移不变 \(\mathbb{E}[X(t)] = \mu\) 且 \(R_X(t_1,t_2) = R_X(t_1-t_2)\)
    包含关系 严平稳 \(\Rightarrow\) 广义平稳（只要二阶矩存在） 广义平稳 不 \(\Rightarrow\) 严平稳 ⚠
    需要二阶矩存在吗 若要求二阶，则需要 需要（否则 \(R_X\) 无定义）
    工程可获得性 几乎无法验证 可以用有限数据估计 ✓

    为什么说「适用范围大得多」：严平稳限制的是整个概率结构， 而广义平稳只限制两个数字类的东西（一个常量和一条曲线）。 假设越弱，越多的实际过程能满足；假设越弱，能推出的结论也越少 —— 这就是全部代价。

    1.4 一个必须澄清的措辞问题¶

    「广义平稳」这个中文词很容易被望文生义成 「比平稳更宽泛的、更弱的一种平稳」。

    这个理解方向是对的，但太模糊，容易导致误用。 准确的说法是：

    广义平稳 = 只在「前两阶矩」这个意义上平稳。 它是一个关于矩的、有限阶的条件，而不是「差不多平稳」。

    ⚠ 为什么这个区别重要：如果误以为「广义平稳就是弱一点的平稳」， 你就会不自觉地认为「平稳该有的性质它大概都有」。 但下面这些严格平稳必然成立的性质，广义平稳并不保证：

    性质 严格平稳 广义平稳
    分布形状不随时间变 保证 ✓ 不保证 ⚠
    三阶及以上的矩不随时间变 保证 ✓ 不保证 ⚠
    概率密度函数的形状不变 保证 ✓ 不保证 ⚠
    均值为常数 保证 ✓ 保证 ✓
    自相关只依赖时间差 保证 ✓ 保证 ✓

    反过来，只有在高斯过程这一类特殊情形下， 二阶矩才反过来决定全部阶的分布， 那时「广义平稳」与「严格平稳」才是等价的（本页第七节会讲）✓

    \[R_{xx}(n+1, n) = \mathbb{E}\big[x(n+1)x(n)\big] = n + 1\]

    起点 \(n = 0\) 时是 1，\(n = 4\) 时是 5，每右移一步就多 1。 观测值 \(2.01, 3.00, 3.99, 4.98, 5.96\) 和 \(1, 2, 3, 4, 5\) 的系统偏差来自 \(x(0)\) 的起点设定与离散化的细节，但增长趋势和理论完全一致。

    「非平稳」不等于「不能用」

    随机游走不是广义平稳过程，但它是极其重要的模型 （陀螺仪漂移、随机趋势、金融价格）。 本课程后续讲维纳滤波和卡尔曼滤波时， 恰恰要处理这类过程 —— 只是那时不能再直接用「\(R_X(\tau)\)」这一套， 而要转而描述增量的统计特性。

    所以看到「非平稳」先别急着判定「这题不能做」， 而要问：换一个描述量，它平稳了吗？ ✓

    二、系综自相关函数：本页的核心¶

    2.1 定义：课件用的就是系综平均¶

    课件的定义（原话转述）：

    一个随机过程 \(x(t)\) 的（系综）自相关函数，定义为 \(R_x(t_1, t_2) = \mathbb{E}\{X_1 X_2^{*}\} = \int x_1 x_2^{*}\,\mathrm{d}P(x_1, x_2)\)

    本页把记号统一成 \(\mathbb{E}\) 与 \(R_X\)，写出来是

    \[R_X(t_1, t_2) = \mathbb{E}\big[X(t_1)\,X^{*}(t_2)\big]\]

    先把每个符号定义清楚（这是本站的硬规矩，不许有没定义的符号）：

    符号 含义 取值范围
    \(t\) 时间，或离散时间下标 实数（连续）；整数（离散）
    \(X(t)\) \(t\) 时刻的随机变量 实数或复数
    \(t_1, t_2\) 两个具体的时刻 与 \(t\) 同域
    \(X(t_1)\) \(t_1\) 时刻的随机变量 同 \(X(t)\)
    \(X^{*}(t_2)\) \(X(t_2)\) 的复共轭 同 \(X(t)\)
    \(\mathbb{E}[\cdot]\) 系综平均（数学期望） 对随机变量全体取平均
    \(R_X(t_1, t_2)\) 自相关函数在 \((t_1, t_2)\) 处的值 有界，\(\lvert R_X \rvert \lt \infty\)
    \(\mathrm{d}P(x_1, x_2)\) 二维积分分布测度 概率测度

    最后一行那个 \(\mathrm{d}P\) 是课件写法的一部分，值得多说一句。 课件里这个定义写成了积分形式 \(\int x_1 x_2^{*}\,\mathrm{d}P(x_1, x_2)\)， 用的是 Riemann-Stieltjes 积分（课件补充材料专门讲了它）。 为什么不用普通积分？因为有些随机变量没有概率密度（离散型、混合型）， 写 \(\int x_1 x_2^{*} p(x_1,x_2)\,\mathrm{d}x_1\mathrm{d}x_2\) 就没有意义了； 用积分分布 \(\mathrm{d}P\) 则任何随机变量都涵盖 ✓ 本页下面一律用 \(\mathbb{E}[\cdot]\) 表示，两者是同一个东西。

    2.2 逐项解释：为什么这么定义¶

    问题 1：为什么是「乘积的期望」？

    自相关要回答的是「\(t_1\) 时刻的值和 \(t_2\) 时刻的值有多像」。 「像」的数学化最自然的方式就是相乘：

    情形 \(X(t_1)X(t_2)\) 的符号 说明
    两个时刻都偏大 正 × 正 = 正 同步涨
    两个时刻都偏小 负 × 负 = 正 同步跌
    一个偏大一个偏小 正 × 负 = 负 反向

    把乘积取期望（也就是对无穷多条样本取平均）， 「同步涨跌」的项会累积起来，正负相消的项会抵消。 所以乘积的期望越大，两个时刻越「同向」 ✓

    ⚠ 注意定义里的两个 \(X\) 都是随机变量本身，不是减去均值以后的值。 减去均值再相乘得到的是自协方差。课件的 2.6 节把两者写在一处：

    \[R_{xx}(k) = \mathbb{E}\{x_n x_{n+k}^{*}\}, \qquad c_{xx}(k) = \mathbb{E}\{(x_n - \mu_x)(x_{n+k} - \mu_x)^{*}\} = R_{xx}(k) - |\mu_x|^2\]

    两个名字不要混：

    记号 名字 减均值了吗 什么时候两者相等
    \(R_{xx}(k)\) 自相关 没有 当 \(\mu_x = 0\) 时 ✓
    \(c_{xx}(k)\) 自协方差 减了 与 \(R_{xx}\) 差一个常数

    为什么课程统一偏爱用自相关 \(R_{xx}\) 而不是自协方差： 下面 2.4 节会看到，\(R_{xx}(0) = \mathbb{E}[|X(t)|^2]\) 恰好是平均功率， 这是一个物理量（第二节第 6 小节的三个性质直接由它推出）。 自协方差没有这个直接解释 ✓

    问题 2：为什么有个共轭星号？

    因为 \(X(t)\) 可以是复数（例如通信里的解析信号、雷达的复包络）。 如果直接写 \(X(t_1)X(t_2)\)，在复情形下这个量不保证是实数， 而「自相关」作为一个可比大小的量，我们希望它是实值的。

    加上共轭之后：

    \[X(t_1)X^{*}(t_2) = \text{（以 } t_1 \text{ 的值为准）} \times \text{（} t_2 \text{ 的值的共轭）}\]

    取期望后是实数（严格地说，\(R_X(t_1,t_2)\) 在复情形下是复数， 但满足共轭对称，见下文）； 取 \(t_1 = t_2 = t\) 时它就退化成 \(\mathbb{E}[|X(t)|^2]\)，必为非负实数 ✓

    如果信号是实的，共轭不起任何作用（实数的共轭就是它自己）， 所以所有公式都能一并适用于实信号 ✓ 这就是为什么加上星号 是零成本的：它统一了实、复两种情形。

    用一个复信号把「星号到底救了多少东西」演出来。 取随机相位的复指数

    \[X(t) = e^{\,j(\omega_0 t + \phi)}, \qquad \phi \text{ 在 } [0, 2\pi) \text{ 上均匀分布}\]

    这个 \(\phi\) 叫随机相位，它让每条样本的相位都不一样。 按定义，\(X(t_1)X^{*}(t_2)\) 里的两个 \(\phi\) 会相减而抵消：

    \[X(t_1)X^{*}(t_2) = e^{\,j(\omega_0 t_1 + \phi)}e^{-j(\omega_0 t_2 + \phi)} = e^{\,j\omega_0(t_1 - t_2)}\]

    \(\phi\) 没了！ 于是期望里没有随机量，\(R_X(t_1,t_2) = e^{j\omega_0(t_1-t_2)}\)， 只依赖时间差 —— 这个过程是广义平稳的 ✓

    反过来，如果不加共轭，两个 \(\phi\) 会相加：

    \[X(t_1)X(t_2) = e^{\,j(\omega_0(t_1+t_2) + 2\phi)}\]

    对 \(\phi\) 均匀分布取期望时，\(e^{j2\phi}\) 在整圈上转满，期望恰好为 \(0\) —— 有用的信息被平均掉了 ⚠

    问题 3：\(t_1\) 和 \(t_2\) 有对称性吗？

    把两个自变量交换：

    \[R_X(t_2, t_1) = \mathbb{E}\big[X(t_2)X^{*}(t_1)\big] = \overline{\mathbb{E}\big[X(t_1)X^{*}(t_2)\big]} = R_X^{*}(t_1, t_2)\]

    中间那一步只是「先取期望再取共轭」与「先取共轭再取期望」相等。 这就是共轭对称性：

    \[R_X(t_2, t_1) = R_X^{*}(t_1, t_2)\]

    怎么读：交换两个时刻，自相关的值变成它的共轭。 实信号时共轭无效，于是 \(R_X(t_2,t_1) = R_X(t_1,t_2)\)， 也就是这个二元函数关于对角线对称。

    记住这条，广义平稳下的「偶函数」性质就好记了 —— 第六节会看到它只是共轭对称在 \(\tau\) 记号下的改写 ✓

    2.3 广义平稳下的简化（本页最关键的一步）¶

    前提：\(X(t)\) 是广义平稳的。由 1.2 节的条件二，\(R_X(t_1, t_2)\) 只依赖 \(t_1 - t_2\)。于是记

    \[\tau = t_1 - t_2, \qquad R_X(\tau) \triangleq R_X(t_1, t_2)\]

    在 \(R_X(\tau)\) 这个记号下，怎么把「期望内部」写成含 \(\tau\) 的形式？ 令 \(t_1 = t + \tau\)、\(t_2 = t\)（\(t\) 是任意「计算起点」），得到

    \[\boxed{\,R_X(\tau) = \mathbb{E}\big[X(t+\tau)X^{*}(t)\big]\,}\]

    这句话的要害在「与 \(t\) 无关，只与 \(\tau\) 有关」 ✓

    请特别注意这个等式同时说了两件事：

    1. 右边的期望确实存在，是一个有限的数；
    2. 这个数不管你把 \(t\) 取成几，结果都一样。

    第 2 条不是废话 —— 它正是「与时间的计算起点无关」的严格表述， 也是本页后面要反复用代码去验证的东西。

    课件把 \(\tau\) 的两种叫法都交代了。在连续时间下 \(\tau\) 是时间差， 在离散时间下对应的是滞后，记成整数 \(m\)。

    2.5 用代码验证：固定 \(\tau\)、扫不同的 \(t\)，结果应当一致¶

    理论说 \(R_X(t+\tau, t)\) 与 \(t\) 无关。这是可以直接用数值实验查证的。

    造一个已知答案的广义平稳过程，最方便的是一阶自回归（AR(1)）过程：

    \[x(n) = a\,x(n-1) + w(n), \qquad w(n) \text{ 是均值 0、方差 1 的白噪声}\]

    在 \(|a| \lt 1\) 且序列已经进入稳态时，它的均值为 0，自相关为

    \[R_X(m) = \frac{a^{|m|}}{1 - a^{2}}\]

    这个理论式怎么来的（不跳步）。

    第一步求 \(R_X(0)\)。把递推式两边乘 \(x(n)\) 再取期望：

    \[\mathbb{E}\big[x(n)x(n)\big] = a\,\mathbb{E}\big[x(n-1)x(n)\big] + \mathbb{E}\big[w(n)x(n)\big]\]

    注意 \(w(n)\) 与 \(x(n-1)\) 独立（当前噪声与过去状态无关）， 但 \(x(n)\) 里含有 \(w(n)\)，所以 \(\mathbb{E}[w(n)x(n)] = \sigma_w^{2} = 1\)； 而 \(\mathbb{E}[x(n-1)x(n)] = R_X(1)\)。于是

    \[R_X(0) = a\,R_X(1) + 1 \tag{1}\]

    第二步求 \(R_X(m)\)（\(m \ge 1\)）。把递推式两边乘 \(x(n-m)\) 再取期望：

    \[\mathbb{E}\big[x(n)x(n-m)\big] = a\,\mathbb{E}\big[x(n-1)x(n-m)\big] + \mathbb{E}\big[w(n)x(n-m)\big]\]

    由于 \(m \ge 1\)，\(x(n-m)\) 只依赖 \(n-m\) 及更早的噪声， 与 \(w(n)\) 独立，所以最后一项为 0。左边是 \(R_X(m)\)， 右边是 \(a\,R_X(m-1)\)，于是

    \[R_X(m) = a\,R_X(m-1) \;\Longrightarrow\; R_X(m) = a^{m}R_X(0) \tag{2}\]

    第三步，把 (2) 取 \(m = 1\) 代入 (1)：

    \[R_X(0) = a\cdot a\,R_X(0) + 1 \;\Longrightarrow\; R_X(0)\big(1 - a^{2}\big) = 1 \;\Longrightarrow\; R_X(0) = \frac{1}{1-a^{2}}\]

    代回 (2) 得到 \(R_X(m) = \dfrac{a^{m}}{1-a^{2}}\)（\(m \ge 0\)）。 由偶函数性质可推广到负滞后，即 \(R_X(m) = \dfrac{a^{|m|}}{1-a^{2}}\) ✓

    取 \(a = 0.8\)，则 \(R_X(0) = 1/(1-0.64) = 2.7778\)，\(R_X(1) = 0.8 \times 2.7778 = 2.2222\)。

    \[\widehat{R}_X(t+\tau, t) = \frac{1}{N}\sum_{k=1}^{N} x_k(t+\tau)\,x_k(t)\]

    估计值随样本数 \(N\) 增大而收敛 按 \(1/\sqrt{N}\) 缩小 正常，符合统计规律 ✓
    估计值始终偏离理论值 不随 \(N\) 缩小 不正常，说明模型或公式错了 ⚠

    判断依据的物理含义：系综自相关是一个期望， 用 \(N\) 条样本估计它，误差自然随 \(N\) 增大而减小（标准误 \(\propto 1/\sqrt{N}\)）。 所以「加大 \(N\) 误差就变小」是理论正确的证据； 「加大 \(N\) 误差不变」则是模型错的证据。这比单看一个数字有用得多 ✓

    三、时间自相关函数：另一条路¶

    3.1 定义¶

    课件在给出系综自相关之后，紧接着说：同时，可以定义按时间统计的自相关。

    \[X(t)X^{*}(t+\tau) \;\;\longleftrightarrow\;\; \lim_{T\to\infty} \frac{1}{T}\int_{-T/2}^{T/2} X(t)X^{*}(t+\tau)\,\mathrm{d}t\]

    本页用带「帽子」的记号把它写成更清楚的形式：

    \[\widehat{R}_X(\tau) = \lim_{T\to\infty} \frac{1}{T} \int_{-T/2}^{T/2} x(t+\tau)\,x^{*}(t)\,\mathrm{d}t\]

    把符号定义清楚：

    符号 含义 取值范围
    \(x(t)\) 某一条具体的样本函数 是一条确定曲线，不是随机变量
    \(T\) 观测时长 正的实数或整数
    \(\tau\) 时间差（滞后） 实数
    \(\widehat{R}_X(\tau)\) 时间自相关（估计量） 随机变量

    三个要点，一个都不能漏：

    要点 说明
    用的是一条样本 \(x(t)\) 小写 \(x\) 且是具体实现，不是大写随机变量 \(X(t)\) ⚠
    沿时间积分/求和 积分的范围是 \([-T/2, T/2]\)，方向是水平的
    除以 \(T\) 再取极限 因为能量无穷，必须归一化到单位时间（第五节细讲）

    课件还专门交代了两个符号的约定，这两条务必记住：

    记号 含义 中文常说
    \(\mathbb{E}\{\bullet\}\) 系综统计符号 理论值
    \(\langle \bullet \rangle\) 或带帽记号 时间统计符号 估计值

    3.2 系综自相关与时间自相关的区别（本页最重要的对照）¶

    这是全页最该记牢的一段。两者写法长得像，含义差得很远。

    系综自相关 \(R_X(\tau)\) 时间自相关 \(\widehat R_X(\tau)\)
    对什么平均 多条第样本（同一时刻） 一条样本（沿时间）
    是随机变量吗 不是（是确定性函数）✓ 是（依赖抽到哪条样本）⚠
    记号 \(R_X\)（理论值） \(\widehat R_X\) 或 \(\langle\cdot\rangle\)（估计值）
    工程可测性 不可直接测（需要多平行实验） 可直接测（有一条数据就够）✓
    要多少数据 需要多条独立的样本函数 只需一条足够长的记录
    求平均方向 图中竖直方向 图中水平方向

    再把这四个差别逐一讲透。

    差别一：平均的对象不同。

    系综自相关跨「样本序号」平均，时间自相关沿「时间轴」平均。 用第二节那张图来说：系综平均是竖着数，时间平均是横着走。

    差别二：是不是随机变量。

    \(R_X(\tau)\) 是期望，期望是对整个概率空间取的，所以它是一个确定的数， 不随你做不做实验而变 ✓

    \(\widehat{R}_X(\tau)\) 是对一条样本算出来的，而抽到哪一条样本是随机的， 所以它是随机变量 ⚠ 换一条样本函数重算，会得到不同的值。

    这一条最容易被忽略，但它决定了后面能不能用时间平均去估计系综量。

    差别三：能不能直接测。

    现实中你只有一台设备、一次记录。你拿不到「同一个过程的很多条样本函数」—— 世界上只有一个信号源，它的输出只有一条实现。 所以 \(R_X(\tau)\) 在物理上不可直接测量，它只是一个理想化的理论量 ✓

    而 \(\widehat{R}_X(\tau)\) 只需要一条样本，是可测的。

    差别四：谁在估计谁。

    这两者的关系不是「哪个更准」，而是估计者与被估计者：

    \[\widehat{R}_X(\tau) \;\;\xrightarrow{\text{希望逼近}}\;\; R_X(\tau)\]

    我们希望用可测的 \(\widehat{R}_X\) 去估计不可测的 \(R_X\)。 这个「希望」什么时候成立？答案是遍历性 —— 下一页的主题。

    我在推导里用的是期望还是极限？ 期望 → 系综；\(T\to\infty\) 的极限 → 时间
    这个量是不是随机的？ 是 → 时间统计；不是 → 系综统计

    严格地说，只有遍历性成立时，两者才相等。 本课程课件原话：一个具有遍历性的过程必定是平稳的， 但一个平稳过程不必具有遍历性。 这句话请务必记住 ✓

    3.4 一条反例：非遍历时两者差得有多远¶

    「两者相等」在遍历条件下才成立。为了看清不相等是什么样， 需要一个平稳但非遍历的过程。最容易构造的玩具模型是

    \[X(t) = A, \qquad A \sim \mathcal{N}(0, 1) \text{ 只抽一次，抽完永远不变}\]

    它的含义是：整个实验从开始到结束，你得到的是一条水平直线， 但这条直线的高度 \(A\) 是随机的 —— 换一套设备重做一遍，会得到另一个高度。

    先算系综自相关。 对任意 \(\tau\)：

    \[R_X(\tau) = \mathbb{E}\big[X(t+\tau)X(t)\big] = \mathbb{E}\big[A \cdot A\big] = \mathbb{E}\big[A^{2}\big] = \sigma_A^{2} = 1\]

    （这里用了 \(A\) 与 \(t\) 无关、且 \(\mathbb{E}[A^{2}]\) 就是方差 \(1\)。）

    再算时间自相关。 抽到某条样本意味着 \(A\) 固定成了某个具体值 \(A_k\)：

    \[\widehat{R}_X(\tau) = \lim_{T\to\infty}\frac{1}{T}\int_{-T/2}^{T/2} A_k \cdot A_k \,\mathrm{d}t = A_k^{2}\]

    （被积函数是常数，积分除以 \(T\) 就得到那个常数。）

    两者对比：

    系综自相关 \(R_X(\tau)\) 时间自相关 \(\widehat R_X(\tau)\)
    表达式 \(\mathbb{E}[A^{2}]\) \(A_k^{2}\)
    数值 恒等于 1 随样本不同，五花八门
    有关系吗 — 只有 \(\mathbb{E}[\widehat R_X] = R_X\)，但单次结果可以远离 1 ⚠

    「平均起来对」不等于「每次都对」

    上面这个例子里，时间自相关的期望确实等于系综自相关： \(\mathbb{E}[A^{2}] = 1 = R_X(\tau)\)。 但这不是遍历性要的东西。

    遍历性要求的是：只要 \(T \to \infty\)，这一次算出来的结果就收敛到 \(R_X\) （以概率 1 收敛，即「几乎必然」）。

    而这个例子里无论 \(T\) 取多大，结果始终是 \(A_k^2\)，永远不会向你希望的 1 靠拢。 它不收敛，所以不遍历 ⚠

    说法 严格吗
    「时间平均的期望等于系综平均」 不充分，这个例子里就成立但不遍历 ⚠
    「时间平均以概率 1 收敛到系综平均」 这才是遍历性 ✓

    这就是为什么课件在定义遍历性时用的是「按概率 1 收敛」，而不是「期望相等」。

    四、离散时间情形：平稳随机序列¶

    课件的 2.6 节标题是「平稳随机序列的统计特征」， 也就是把上一节连续时间的公式搬到序列上。

    4.1 均值¶

    课件给出

    \[\mu_x = \mathbb{E}\{x(n)\} = \int_{-\infty}^{\infty} x_n\,\mathrm{d}P(x_n)\]

    符号：\(n\) 是离散时间下标（整数），\(x(n)\) 是序列在第 \(n\) 点的随机变量。 广义平稳要求 \(\mu_x\) 与 \(n\) 无关。

    写成右边的积分形式是课件原文的写法（用积分分布 \(\mathrm{d}P\)）。 如果概率密度 \(p(\cdot)\) 存在，它可以换成更熟悉的 \(\mu_x = \int_{-\infty}^{\infty} x\,p(x)\,\mathrm{d}x\)。

    4.2 方差与自协方差¶

    课件继续给出

    \[\sigma_x^{2} = \mathbb{E}\big\{(x(n) - \mu_x)^{2}\big\} = \int_{-\infty}^{\infty} (x_n - \mu_x)^{2}\,\mathrm{d}P(x_n)\]
    \[c_{xx}(k) = \mathbb{E}\big\{(x_n - \mu_x)(x_{n+k} - \mu_x)^{*}\big\} = R_{xx}(k) - |\mu_x|^{2}\]

    符号：\(k\) 是滞后（lag），整数；\(\sigma_x^{2}\) 是方差。 第二条式子把自协方差与自相关的关系写出来了，把右边展开就能验证：

    \[\mathbb{E}\big\{(x_n - \mu)(x_{n+k} - \mu)^{*}\big\} = \mathbb{E}\big\{x_n x_{n+k}^{*}\big\} - \mu^{*}\mathbb{E}[x_n] - \mu\,\mathbb{E}\big[x_{n+k}^{*}\big] + \mu\mu^{*} = R_{xx}(k) - |\mu|^{2}\]

    （用了平稳性：\(\mathbb{E}[x_n] = \mathbb{E}[x_{n+k}] = \mu\)。） 取 \(k = 0\) 就得到 \(\sigma_x^{2} = R_{xx}(0) - |\mu_x|^{2}\) ✓

    4.3 自相关与互相关¶

    \[R_{xx}(k) = \mathbb{E}\big\{x_n x_{n+k}^{*}\big\} = \int_{-\infty}^{\infty} x_n x_{n+k}^{*}\,\mathrm{d}P(x_n, x_{n+k})\]
    \[r_{xy}(k) = \mathbb{E}\big\{x_n y_{n+k}^{*}\big\}\]
    记号 名字 涉及几个过程
    \(R_{xx}(k)\) 自相关 一个（\(x\) 与 \(x\)）
    \(r_{xy}(k)\) 互相关 两个（\(x\) 与 \(y\)）
    \(c_{xx}(k)\) 自协方差 一个
    \(c_{xy}(k)\) 互协方差 两个

    4.4 离散形式的系综自相关¶

    把第二节的简化式搬到离散域。记时间差（此时称滞后）为 \(m\)：

    \[R_X(m) = \mathbb{E}\big[x(n+m)\,x^{*}(n)\big]\]

    逐项解释：

    符号 含义 取值范围
    \(m\) 滞后 整数（可以是负的、零、正的）
    \(n\) 起点下标 整数
    \(x(n)\) 第 \(n\) 点的随机变量 实数或复数
    \(R_X(m)\) 离散自相关序列 定义域是全体整数

    ⚠ \(m\) 必须是整数，这是离散情形的本质特点。 在连续时间下 \(\tau\) 可以取任意实数；在离散序列里， 下标只能取整数，所以自相关函数只在整数点上定义。 这一点在下面的代码里看得很清楚：打印出来的是一列离散的值， 而不是一条连续曲线。

    连续改离散，规则是「积分改成求和」：

    连续时间 离散时间
    \(\int_{-\infty}^{\infty}(\cdot)\,\mathrm{d}t\) \(\sum_{n=-\infty}^{\infty}(\cdot)\)
    \(\mathbb{E}[X(t+\tau)X^{*}(t)]\) \(\mathbb{E}[x(n+m)x^{*}(n)]\)
    \(\tau\)（任意实数） \(m\)（整数）
    \(R_X(\tau)\) 是连续函数 \(R_X(m)\) 是序列 ✓

    五、能量信号与功率信号：自相关的归一化方式不同¶

    5.1 两类确定性信号¶

    课件在讲 Wiener-辛钦定理时说了一句关键的话：

    一个绝对可积函数或有限长序列，自相关的傅里叶变换等于信号功率谱。

    这句话里「绝对可积函数或有限长序列」指的就是能量信号。 它们的特点是总能量有限，所以自相关可以直接积分， 不需要除以时长。

    \[R_{xx}(\tau) = \int_{-\infty}^{\infty} x(t+\tau)x^{*}(t)\,\mathrm{d}t \qquad \text{（能量信号，不除时长）}\]
    \[R_{xx}(m) = \sum_{n=-\infty}^{\infty} x(n+m)x^{*}(n) \qquad \text{（有限长序列，不除长度）}\]

    为什么可以不除：因为积分（或求和）本身收敛，结果是一个有限数， 不需要额外的归一化。\(R_{xx}(0) = \int |x(t)|^{2}\mathrm{d}t\) 就是信号总能量 ✓

    5.2 随机功率信号¶

    而随机过程（以及周期信号、持续存在的确定性信号）完全不是这样。 课件明确指出：

    一个平稳随机过程及其自相关在 \((-\infty, \infty)\) 上 一般不是绝对可积的，傅里叶变换的理论不能直接应用。

    这带来的直接后果是：能量是无穷的，直接积分会发散。 所以必须除以时长再取极限：

    \[R_X(\tau) = \lim_{T\to\infty}\frac{1}{T}\int_{-T/2}^{T/2} X(t+\tau)X^{*}(t)\,\mathrm{d}t\]
    \[R_X(m) = \lim_{N\to\infty}\frac{1}{2N+1} \sum_{n=-N}^{N} x(n+m)x^{*}(n)\]

    为什么必须除以：除以时长之后，量纲从「能量」变成了「单位时间的能量」， 也就是功率。随机信号的能量无穷但功率有限，所以定义在功率上。

    5.3 三者的自相关定义对照（混用是常见错误）¶

    ⚠ 这是最需要强调的一张表。三种对象，三种归一化方式， 用错了结论就会错一个因子（甚至错到无穷）。

    对象 自相关定义 除以时长吗 \(R(0)\) 的物理含义
    确定性能量信号 \(\int x(t+\tau)x^{*}(t)\mathrm{d}t\) 不除 ✓ 总能量
    确定性功率信号（周期等） \(\lim\limits_{T\to\infty}\frac{1}{T}\int_{-T/2}^{T/2}(\cdot)\mathrm{d}t\) 除，再取极限 平均功率
    随机过程（广义平稳） \(\mathbb{E}[X(t+\tau)X^{*}(t)]\) 形式上是期望（不用积分的极限） 平均功率 ✓

    第一行和第二行的差别是「除以 \(T\)」；第二行和第三行的差别是「极限还是期望」。 两个差别都很关键：

    差别 说明
    除不除以 \(T\) 决定 \(R(0)\) 是「总能量」还是「平均功率」，量纲就差一个时间 ⚠
    极限还是期望 极限是沿着一条样本做的；期望是跨样本做的（第三节的区别）

    能量信号与功率信号的自相关归一化绝不可混用

    混用会有两个层次的后果，一个比一个严重：

    混用方式 后果
    能量信号的定义套到功率信号上 结果随观测长度 \(T\) 线性增大，不收敛 ⚠
    功率信号的定义套到能量信号上 结果随 \(T\) 趋于 0，把信号看成没了 ⚠
    只记「有个积分」不记有没有 \(1/T\) 差异只表现为一个常数因子，最容易蒙过检查 ⚠

    第三个层次最危险：因为差的是个常数因子，所以 只要不涉及绝对数值，推导「看起来」都对 —— 直到你要解释 \(R(0)\) 到底等于多少、或者做量纲检查的时候，才会发现不对。

    防错手段：每次写下 \(R(0)\)，问自己一句 「这里的 \(R(0)\) 是总能量还是平均功率？」 两者单位不同： 能量信号是「焦耳」，功率信号是「瓦」✓

    5.5 为什么两条线最终还是汇到一起¶

    看到这里可能有点乱：三种定义，难道要分三套理论？

    好消息是不用。背后的逻辑是：

    步骤 内容
    1 对有限长的数据，先按能量信号的定义算（不除以 \(N\)，因为数据有限）
    2 再除以长度，得到按功率的估计
    3 若过程遍历，它就收敛到系综自相关（下一节的主题）

    也就是说：「除以 \(N\)」这个动作，正是把能量信号的计算结果 转成随机过程意义上的自相关估计的那一步。 课件里定义时间自相关时那个 \(1/T\)，干的就是这件事 ✓

    六、实平稳随机信号自相关函数的三个性质¶

    课件的 2.6 节末尾有一页专门标题叫 「实平稳随机信号自相关函数的性质」，给出的是下面这三条。 本页把它们逐条给理由，不只给结论（这是本站的硬规矩）。

    6.1 性质一：偶函数（共轭对称）¶

    \[R_X(-\tau) = R_X^{*}(\tau)\]

    实信号时共轭无效，简化为偶函数：

    \[R_X(-\tau) = R_X(\tau)\]

    理由（不跳步）。 从定义出发：

    \[R_X(-\tau) = \mathbb{E}\big[X(t-\tau)X^{*}(t)\big]\]

    做一个变量替换，把「起点」从 \(t\) 挪到 \(t' = t - \tau\)，于是 \(t = t' + \tau\)：

    \[R_X(-\tau) = \mathbb{E}\big[X(t')X^{*}(t'+\tau)\big]\]

    把这个期望里的两个因子交换顺序，并注意共轭的运算法则 （\(\mathbb{E}[AB^{*}] = \overline{\mathbb{E}[A^{*}B]}\)， 因为取共轭与取期望可以交换）：

    \[\mathbb{E}\big[X(t')X^{*}(t'+\tau)\big] = \overline{\mathbb{E}\big[X^{*}(t')X(t'+\tau)\big]} = R_X^{*}(\tau)\]

    最后一步正是 \(R_X(\tau) = \mathbb{E}[X(t'+\tau)X^{*}(t')]\) 的共轭 ✓

    为什么实信号时变成偶函数：实数的共轭是它自己， 所以 \(R_X^{*}(\tau) = R_X(\tau)\)，于是 \(R_X(-\tau) = R_X(\tau)\) ✓

    这条性质的用处：算自相关时只用算非负的一半，另外一半抄过来就行。 后面讲自相关的傅里叶变换（功率谱）时，偶函数意味着 功率谱是实的偶函数 —— 这也是后面一条重要结论的种子 ✓

    6.2 性质二：原点最大¶

    \[\lvert R_X(\tau) \rvert \le R_X(0)\]

    课件的写法是 \(R_{xx}(0) \ge |R_{xx}(m)|\)。

    理由（用柯西-施瓦茨不等式）。 对任意两个随机变量 \(U\)、\(V\)， 下面的不等式总成立：

    \[\big|\mathbb{E}\big[UV^{*}\big]\big|^{2} \le \mathbb{E}\big[|U|^{2}\big]\,\mathbb{E}\big[|V|^{2}\big]\]

    （这是柯西-施瓦茨不等式在期望上的形式，也叫许瓦兹不等式。）

    取 \(U = X(t+\tau)\)、\(V = X(t)\) 代入：

    \[\big|\mathbb{E}\big[X(t+\tau)X^{*}(t)\big]\big|^{2} \le \mathbb{E}\big[|X(t+\tau)|^{2}\big]\,\mathbb{E}\big[|X(t)|^{2}\big]\]

    左边是 \(|R_X(\tau)|^{2}\)。右边由广义平稳，两个因子相等：

    \[\mathbb{E}\big[|X(t+\tau)|^{2}\big] = \mathbb{E}\big[|X(t)|^{2}\big] = R_X(0)\]

    于是 \(\lvert R_X(\tau) \rvert^{2} \le R_X(0)^{2}\)，两边开方（都是非负的）得到

    \[\lvert R_X(\tau) \rvert \le R_X(0)\]

    \(\blacksquare\)

    等号什么时候成立：柯西-施瓦茨取等号当且仅当 \(U\) 与 \(V\) 线性相关，即 \(X(t+\tau) = c\,X(t)\) 对某个复数 \(c\) 成立。 这说明「\(|R_X|\) 在原点取到最大值」这件事， 在完全相关（也就是信号完全没有随机性、可以完美预测）时才达到 ✓

    6.3 性质三：\(R_X(0)\) 就是平均功率¶

    \[R_X(0) = \mathbb{E}\big[|X(t)|^{2}\big] = \text{平均功率}\]

    理由（一行就能看出）。 在定义里取 \(\tau = 0\)：

    \[R_X(0) = \mathbb{E}\big[X(t)X^{*}(t)\big] = \mathbb{E}\big[|X(t)|^{2}\big]\]

    最后这个量就是「信号幅值平方的期望」，物理上正是功率 （电压平方除以电阻，或直接说均方值）✓

    与第二条性质的关系：明白了 \(R_X(0)\) 是平均功率， 「原点最大」就有了更直观的含义 —— 它说的是 「平均功率是所有滞后上自相关模的最大值」， 也就是「\(R\) 在任何滞后点上的模都不会超过平均功率」✓

    与方差的区别（这里最容易混，务必分清）：

    \[R_X(0) = \mathbb{E}\big[|X|^{2}\big], \qquad \sigma_X^{2} = \mathbb{E}\big[|X|^{2}\big] - |\mu_X|^{2} = R_X(0) - |\mu_X|^{2}\]
    量 名字 减均值了吗 物理含义
    \(R_X(0)\) 均方值 没有 平均功率（含直流分量）
    \(\sigma_X^{2}\) 方差 减了 交流功率（纯波动部分）
    \(\mu_X^{2}\)（或 \(\lvert\mu_X\rvert^2\)） 直流功率 — 均值贡献的那部分

    三者关系可以读成一句工程话：

    \[\underbrace{R_X(0)}_{\text{总平均功率}} = \underbrace{|\mu_X|^{2}}_{\text{直流功率}} + \underbrace{\sigma_X^{2}}_{\text{交流功率}}\]

    只有当 \(\mu_X = 0\) 时，才有 \(R_X(0) = \sigma_X^{2}\) ⚠ 本课程很多推导为了方便假设零均值，一旦忘了这条， 遇到非零均值的情形就会算错。

    7.2 为什么本课程反复只围绕这两个量¶

    理由其实很实在：本课程后面所有的运算都是线性运算。

    后面的内容 用到的是什么
    自相关 ↔ 功率谱（维纳-辛钦） 只用 \(R_X(\tau)\)
    平稳序列通过线性系统 输出均值由 \(\mu_X\) 和系统增益决定；输出自相关由 \(R_X\) 和脉冲响应决定
    维纳滤波 用 \(R_X\) 和互相关解一个方程
    卡尔曼滤波 用二阶矩递推（状态协方差）
    谱估计 从 \(R_X\) 的估计出发

    共同点：输入到输出之间是线性的。 线性运算只涉及加法和数乘，而期望对加法和数乘是「穿得过去」的：

    \[\mathbb{E}[aX_1 + bX_2] = a\,\mathbb{E}[X_1] + b\,\mathbb{E}[X_2]\]

    \(\mathbb{E}[XX]\) 这类二阶量的传递也用同一个道理（两重线性）。 所以线性运算的输出统计量，只依赖输入的均值和自相关， 更高阶的矩根本不参与 ✓

    这就是为什么这门课的整条主线都建立在这两个量上 —— 不是因为它俩最全，而是因为对线性运算它俩最够用。

    7.4 局限：二阶统计不能确定完整分布¶

    ⚠ 这一条必须重点强调。上面说了「均值 + 自相关够用」， 但「够用」是有明确范围的：

    说法 对错
    广义平稳下，线性运算的输出统计量可由均值和自相关确定 对 ✓
    广义平稳下，均值和自相关确定了过程的完整分布 错 ⚠
    广义平稳下，均值和自相关确定了过程的二阶统计 对 ✓

    为什么不能确定完整分布：给出一个均值和一条自相关曲线， 能画出无穷多个不同的随机过程都满足它 —— 它们在前两阶矩上长得一样， 但三阶、四阶、更高阶的矩可以完全不同 ⚠

    一个直观的例子：任何对称分布（均匀、高斯、拉普拉斯、学生 t……） 都可能有相同的均值和方差。只看均值和方差根本分不出它们是哪个分布。

    二阶统计不等于全部分布

    这是本页最容易产生过度自信的一处，必须把范围划清楚：

    说法 判定
    二阶统计确定了过程的二阶矩性质 对 ✓
    二阶统计确定了线性系统输出的二阶统计 对 ✓
    二阶统计确定了过程的完整概率分布 错 ⚠
    二阶统计确定了过程的有限维联合分布 错 ⚠

    反例：本页 7.5 节末尾的代码构造了三个分布 （正态、均匀、拉普拉斯）均值和方差完全相同， 但四阶矩从 \(1.8\) 到 \(6\) 差了 3 倍多。 仅凭均值和自相关，你不可能把它们分开 ⚠

    这带来的实际风险：

    场景 风险
    信号明显非高斯（脉冲噪声、语音稀疏成分） 二阶方法丢掉关键信息 ⚠
    用高斯假设推出的结论套到非高斯数据 结论可能完全失效 ⚠
    用二阶统计量检测「异常」 只对二阶矩变化的异常敏感，对高阶异常不敏感 ⚠

    正确的说法是：二阶统计够线性运算用， 但要谈「分布」「概率」「检测性能」时， 必须明确说明是在高斯假设下，或者另外给出高阶信息 ✓

    7.5 唯一的例外：高斯过程¶

    高斯过程是例外 —— 高斯情形下二阶统计确定一切 ✓

    为什么：高斯分布有一个独特性质 —— 它的概率密度完全由均值和协方差矩阵决定：

    \[p(x) = \frac{1}{(2\pi)^{N/2}|\Sigma|^{1/2}} \exp\left(-\frac{1}{2}(x-\mu)^{\mathsf{T}}\Sigma^{-1}(x-\mu)\right)\]

    这个公式右边出现的参数只有 \(\mu\) 和 \(\Sigma\) 两个（\(N\) 是维数， \(|\Sigma|\) 是行列式）。没有第三个参数 ✓

    因此对高斯过程：

    前提 结论
    过程是高斯的 均值和自相关（协方差）就确定了所有阶的联合分布 ✓
    过程是高斯的且广义平稳 它必然是严格平稳的 ✓
    过程不是高斯的 广义平稳推不出严格平稳 ⚠

    为什么高斯这么特殊：因为高斯分布的高阶累积量全为零 （只有一阶、二阶累积量非零）。高阶信息本来就「等于零」， 所以「不给出高阶信息」等于「给全了」 ✓

    ⚠ 反过来也要小心：说「高斯下二阶确定一切」必须带上高斯这个前提。 很多信号处理教材默认信号是高斯（因为中心极限定理经常适用）， 于是习惯性地只讲二阶统计 —— 一旦信号明显非高斯 （例如脉冲噪声、语音的稀疏成分），这个默认就不成立了， 单靠均值和自相关会丢掉关键信息。

    典型例题¶

    例题 1：判断两个过程是否广义平稳¶

    已知两个离散随机过程（\(w(n)\) 是均值 0、方差 \(\sigma^{2}\) 的独立白噪声）：

    过程 定义
    A \(x(n) = w(n)\)
    B \(x(n) = x(n-1) + w(n)\)，且 \(x(0) = 0\)

    分别求它们的均值和自相关，判断哪个广义平稳。

    思路

    分别按定义算 \(\mathbb{E}[x(n)]\) 和 \(\mathbb{E}[x(n+m)x(n)]\)， 看这两个量是否与 \(n\) 有关。B 的要点是：\(x(n)\) 是前 \(n\) 个 \(w\) 之和。

    解答

    过程 A：白噪声

    均值：\(\mathbb{E}[x(n)] = \mathbb{E}[w(n)] = 0\)，与 \(n\) 无关 ✓

    自相关：因为各时刻独立，\(\mathbb{E}[w(n+m)w(n)]\) 只在 \(m = 0\) 时非零：

    \[R_x(m) = \begin{cases} \sigma^{2}, & m = 0 \\ 0, & m \ne 0 \end{cases}\]

    与 \(n\) 无关 ✓ 所以 A 是广义平稳过程。

    过程 B：随机游走

    均值：\(\mathbb{E}[x(n)] = \mathbb{E}\Big[\sum_{k=1}^{n} w(k)\Big] = 0\)， 与 \(n\) 无关（这一步满足）✓

    自相关：先算 \(x(n+m)\) 与 \(x(n)\) 的乘积再取期望。 因为两者都含有大量公共的 \(w\)，只有公共部分才留下期望：

    \[x(n) = \sum_{k=1}^{n} w(k), \qquad x(n+m) = \sum_{k=1}^{n+m} w(k) = x(n) + \sum_{k=n+1}^{n+m} w(k)\]

    于是

    \[\mathbb{E}\big[x(n+m)x(n)\big] = \mathbb{E}\big[x(n)^{2}\big] + \mathbb{E}\Big[\Big(\sum_{k=n+1}^{n+m}w(k)\Big)x(n)\Big]\]

    第二项为 0（新噪声与过去独立），第一项

    \[\mathbb{E}\big[x(n)^{2}\big] = \sum_{k=1}^{n}\sigma^{2} = n\sigma^{2}\]

    （交叉项的期望为零，因为 \(w(k)\) 之间互不相关。）

    所以

    \[R_x(n+m, n) = n\,\sigma^{2}\]

    ⚠ 这个结果里带着 \(n\) —— 它依赖起点， 不满足「自相关只依赖时间差」。所以 B 不是广义平稳过程。

    某广义平稳且遍历的实过程，理论上 \(R_X(0) = 4\)。 现有两种数据组织方式：

    方式 数据
    甲 1 条长度 \(N = 200000\) 的记录 \(x(0), \dots, x(N-1)\)
    乙 \(M = 2000\) 条长度 1 的样本，即 \(M\) 个来自同一时刻的独立观测

    解答

    估计式的写法

    方式 类型 估计式

    例题 4：能量信号与功率信号的自相关不能混用¶

    某有限长序列 \(x = [1, 2, 2, 1]\)。

    (a) 按能量信号的定义求 \(R_{xx}(0)\)； (b) 按功率信号的定义求 \(R_{xx}(0)\)； © 说明两者相差多少倍，并指出在什么情况下用哪一个。

    思路

    能量信号的定义不除以长度，功率信号要除以长度。 差的那个因子就是长度 \(N\)。

    解答

    先算序列的平方和：

    \[\sum_{n} x^{2}(n) = 1^{2} + 2^{2} + 2^{2} + 1^{2} = 1 + 4 + 4 + 1 = 10\]

    （a）能量信号定义

    \[R_{xx}(0) = \sum_{n} x^{2}(n) = 10\]

    单位是「幅值平方」，物理上就是总能量。

    （b）功率信号定义

    \[R_{xx}(0) = \frac{1}{N}\sum_{n} x^{2}(n) = \frac{10}{4} = 2.5\]

    物理上就是平均功率。

    （c）倍数关系

    \[\frac{10}{2.5} = 4 = N\]

    两者正好相差长度 \(N = 4\) 倍。

    ⚠ 两种定义各自适用的场合：

    对象 用哪个定义 原因
    有限长序列，讨论它的能量 能量信号（不除） 数据有限，积分（求和）收敛 ✓
    持续存在的信号、随机过程 功率信号（除 \(N\)） 能量无穷，必须归一化到单位时间 ✓
    从数据估计随机过程的自相关 除 \(N\) 否则结果随数据长度变化 ⚠

    一个后果示例：如果拿同一个信号的两段数据（长度分别是 1000 和 2000）， 都用不除长度的定义去算，会得到相差 2 倍的结果 —— 看起来像信号功率变了，其实是归一化方式用错了 ⚠

    Q1 判断下列说法对错并说明理由：

    (a) 「广义平稳过程一定是严格平稳过程。」 (b) 「严格平稳过程只要二阶矩存在，就一定是广义平稳过程。」 © 「广义平稳过程的均值一定是 0。」

    提示

    想清楚两个平稳定义之间的强弱关系，以及「常数」和「零」的区别。

    解答

    (a) 错。

    方向搞反了。正确的包含关系是

    \[\text{严格平稳} \;\Longrightarrow\; \text{广义平稳} \qquad\text{（在二阶矩存在的前提下）}\]

    反过来不成立 ⚠ 原因：广义平稳只约束一阶矩和二阶矩， 对三阶及以上的分布毫无要求。一个广义平稳过程的分布形状 完全可以随时间变化，只要均值和自相关不变就行。

    反例（示意）：一个零均值的对称分布序列， 每一时刻的分布从一个对称分布换成另一个同方差的对称分布， 均值和自相关都不变，但三阶矩可能变，所以不是严格平稳。

    (b) 对。

    严格平稳要求所有阶的联合分布对时间平移不变。 二阶矩是一类由分布决定的量（\(\mathbb{E}[X(t)]\) 是一阶、 \(\mathbb{E}[X(t+\tau)X^{*}(t)]\) 是二阶）， 既然所有阶的分布都不变，二阶矩自然也不变， 于是「均值常数」和「自相关只依赖时间差」两条自动满足 ✓

    注意附加条件「二阶矩存在」：严格平稳过程不保证二阶矩有限 （例如柯西分布的尾部太重），这时自相关无定义 ⚠

    © 错。

    广义平稳要求的是均值是常数，不是常数等于 0。

    说法 对不对
    均值与时间无关 对，这是定义 ✓
    均值等于 0 错，这是额外的简化假设 ⚠

    区分这两者的实际意义：\(R_X(0) = \mu_X^{2} + \sigma_X^{2}\)。 如果误以为 \(\mu_X = 0\)，就会把 \(R_X(0)\) 当成纯交流功率， 少算了直流分量（本页例题 2 就是这种情况）✓

    \[R_y(0) = \mathbb{E}\big[y^{2}(n)\big] = \mathbb{E}\big[(0.5w(n) + 0.5w(n-1))^{2}\big]\]

    展开（不跳步）：

    \[= 0.25\,\mathbb{E}\big[w^{2}(n)\big] + 2 \times 0.25\,\mathbb{E}\big[w(n)w(n-1)\big] + 0.25\,\mathbb{E}\big[w^{2}(n-1)\big]\]

    交叉项里 \(w(n)\) 与 \(w(n-1)\) 不相关，期望为 \(0\)；另外两项各为 \(\sigma^{2}\)：

    \[R_y(0) = 0.25\sigma^{2} + 0 + 0.25\sigma^{2} = 0.5\,\sigma^{2}\]

    再算 \(R_y(1) = \mathbb{E}[y(n+1)y(n)]\)。 展开两边的定义：

    \[y(n+1) = 0.5w(n+1) + 0.5w(n), \qquad y(n) = 0.5w(n) + 0.5w(n-1)\]

    相乘后一共 4 项，逐项看期望：

    项 系数 乘积 期望
    \(w(n+1) \cdot w(n)\) \(0.25\) 不同时刻 \(0\)
    \(w(n+1) \cdot w(n-1)\) \(0.25\) 不同时刻 \(0\)
    \(w(n) \cdot w(n)\) \(0.25\) 同一时刻 \(0.25\sigma^{2}\) ✓
    \(w(n) \cdot w(n-1)\) \(0.25\) 不同时刻 \(0\)

    只有第三项留下，所以

    \[R_y(1) = 0.25\,\sigma^{2}\]

    （c）白与有色的区别

    特征 白噪声 \(R_w(m)\) 有色噪声 \(R_y(m)\)
    \(m = 0\) \(\sigma^{2}\) \(0.5\sigma^{2}\)
    \(m = 1\) \(0\) ⚠ \(0.25\sigma^{2}\) ✓
    \(m \ge 2\) \(0\) \(0\)（因为 \(h\) 只有 2 个非零值）
    形状 只有一个尖峰 原点 + 相邻一点

    一句话总结：「白」意味着除原点外自相关全为零； 「有色」意味着存在非零的相邻滞后值 ✓

    ⚠ 一个容易忽视的点：\(R_y(0) = 0.5\sigma^{2}\) 比 \(R_w(0) = \sigma^{2}\) 小 —— 输出功率反而下降了。原因是两个 \(0.5\) 的加权在同一时刻 对同一个噪声的作用方式造成了功率的缩放，这在带阻型系统里很常见。 不要把「滤波」默认理解成「一定增大功率」 ⚠

    小结¶

    要记住的 为什么
    广义平稳 = 均值常数 + 自相关只依赖时间差 两个条件缺一不可，本课程全部结论的假设基础 ✓
    「广义」= 只在前两阶矩意义上平稳 不是「弱一点的平稳」，高阶分布可以随时间变 ⚠
    严平稳 \(\Rightarrow\) 广义平稳（二阶矩存在时） 反向不成立 ⚠
    系综自相关 \(R_X(\tau) = \mathbb{E}[X(t+\tau)X^{*}(t)]\) 定义就是系综平均，与起点 \(t\) 无关 ✓
    星号 \(*\) 是为了统一处理复信号 实信号时它不起作用，零成本 ✓
    \(R_X(t_2,t_1) = R_X^{*}(t_1,t_2)\) 共轭对称；实信号时退化成偶函数 ✓
    系综自相关不是随机变量；时间自相关是 前者是期望（确定值），后者依赖抽到哪条样本 ⚠
    两者相等需要遍历性 遍历的过程必平稳；平稳的过程不必遍历 ⚠
    离散时滞后 \(m\) 是整数 连续时的 \(\tau\) 可以是任意实数
    自相关「只看」跨样本方向 图中竖着数；沿时间数是另一回事 ⚠
    \(R_X(-\tau) = R_X^{*}(\tau)\)，实信号时是偶函数 只需算一半；功率谱因此是实偶函数 ✓
    \(\lvert R_X(\tau) \rvert \le R_X(0)\) 柯西-施瓦茨；等号在完全相关时才取到
    \(R_X(0) = \mathbb{E}[\lvert X \rvert^{2}]\) = 平均功率 含直流分量，量纲检查的锚点 ✓
    \(\sigma_X^{2} = R_X(0) - \lvert\mu_X\rvert^{2}\) 只有零均值时 \(R_X(0) = \sigma_X^{2}\) ⚠
    能量信号自相关不除长度，功率信号要除 差一个因子 \(N\)，混用是常见错误 ⚠
    白噪声自相关只在原点非零 有色噪声会拖出尾巴，尾巴形状反映模型 ✓
    二阶统计不能确定完整分布 不同分布可以有相同的均值和方差 ⚠
    高斯过程是例外 二阶统计确定一切；高斯+广义平稳 = 严格平稳 ✓
    均值 + 自相关表出线性运算所需的全部信息 后继章节全部建立在这两个量上
