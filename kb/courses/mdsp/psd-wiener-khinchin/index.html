    自相关与功率谱¶

    这是本模块理论上的核心一页。它要建立一个联系：

    时域的自相关 \(\longleftrightarrow\) 频域的功率谱

    为什么需要这个联系： 自相关回答「相隔多久还像」，是时域的语言； 但工程上常要问「功率分布在哪些频率上」（设计滤波器、找噪声来源）， 那是频域的语言。 两者必须能互相转换 —— 否则你测到的东西和你要的东西对不上 ⚠

    这一页的主线

    整页围绕一个问题展开（这也是课件明确提出的问题）：

    「自相关的傅里叶变换等于功率谱」这个说法，还成立吗？

    为什么会有这个疑问：

    情形 自相关是否绝对可积 能否直接用傅里叶变换
    确定性有限长信号 是 ✓ 能，直接变换即可
    平稳随机过程 一般不是 ⚠ 不能，积分不收敛

    所以必须先严格定义，才能说「成立」—— 这就是谱分解定理与维纳–辛钦定理要解决的问题

    一、从确定性能量信号说起¶

    这一段是铺垫：先看最简单的情形，把结论拿到手； 第二节再说明为什么随机过程不能照搬。

    1.1 能量信号的自相关¶

    能量信号是指总能量有限、因而在无穷远处衰减到 0 的信号。

    定义它的自相关：

    \[R_{xx}(\tau) = \int_{-\infty}^{\infty} x(t+\tau)\,x^*(t)\,dt\]

    注意两点（与随机过程的区别在这里）：

    特征 说明
    不除以时长 因为能量有限，积分本身收敛 ✓
    用一条确定性函数 没有期望、没有系综 ✓

    1.2 卷积定理给出的结论¶

    关键观察：自相关其实是信号与自己的「时间反转共轭」做卷积：

    \[R_{xx}(\tau) = x(\tau) * x^*(-\tau)\]

    为什么：卷积的定义是 \(x(\tau)*x^*(-\tau) = \int x(\tau - t)x^*(-t)dt\)， 做变量替换 \(u = -t\) 即可化成自相关的形式

    由卷积定理（时域卷积 ⟺ 频域相乘）：

    \[\mathcal{F}[R_{xx}(\tau)] = X(f)\cdot \mathcal{F}[x^*(-\tau)]\]

    而 \(\mathcal{F}[x^*(-\tau)] = X^*(f)\)，所以

    \[\boxed{\;\mathcal{F}[R_{xx}(\tau)] = \lvert X(f)\rvert^2\;}\]

    结论：能量信号的自相关的傅里叶变换，就是它的能量谱密度 \(\lvert X(f)\rvert^2\)

    自相关把信号自己与自己的相关程度完整保留了下来—— 时间反转、卷积、取傅里叶变换，一路上信息都没有丢失。 频域里那条 \(\lvert X(f)\rvert^2\)，正是「每个频率上各带多少能量」。 这一步正是课件说的「可以直接从卷积定理简单地证明」—— 上面三行就是那个证明，没有跳步

# 确定性有限长信号：短时正弦脉冲
L = 128
n = np.arange(L)
x = np.sin(2 * np.pi * 0.1 * n) * np.hanning(L)

# 路径一：线性自相关的傅里叶变换（取幅度）
ac = np.correlate(x, x, mode="full")        # 长度 2L-1
S_from_ac = np.abs(np.fft.rfft(ac))

# 路径二：|X(f)|^2（对 x 补零到同样长度后做变换）
N = 2 * L - 1
X = np.fft.rfft(x, n=N)
mag2 = np.abs(X) ** 2

print("信号长度 L = %d，自相关长度 = %d" % (L, len(ac)))
print()
print("两条路径前 6 个频点的幅度：")
print("  |X(f)|^2         :", np.round(mag2[:6], 6).tolist())
print("  自相关变换的幅度 :", np.round(S_from_ac[:6], 6).tolist())
print()
print("逐点最大绝对差 = %.3e" % np.abs(S_from_ac - mag2).max())
print("→ 两者相同 ⇒ 能量信号的自相关与能量谱是一对傅里叶变换 ✓")

  自相关变换的幅度 : [4.2e-05, 1.2e-05, 4.6e-05, 1.8e-05, 6.1e-05, 3.1e-05]

    看这个结果：两条路径前 6 个频点的幅度完全一致， 逐点最大绝对差在 \(10^{-13}\) 量级 —— 是机器精度，不是近似

    离散采样下的一个细节：自相关序列的峰值不在数组起点， 所以它的傅里叶变换带一个线性相位因子 \(e^{-j\omega(L-1)}\)， 幅度恰好等于 \(\lvert X(f)\rvert^2\)； 所以比较时要比较幅度（或把序列循环移位对齐） 这个相位因子没有信息，真正要的是幅度谱。

    二、随机过程的困难¶

    2.1 为什么不能照搬¶

    平稳随机过程的自相关在 \((-\infty,\infty)\) 上一般不是绝对可积的

    举两个例子看清楚麻烦在哪：

    例一，白噪声：它的自相关是

    \[R(\tau) = \sigma^2 \delta(\tau)\]

    它把全部功率压在一个瞬间。虽然 \(\int \sigma^2\delta(\tau)d\tau = \sigma^2\) 有限， 但白噪声的样本函数处处剧烈振荡，既不是能量有限信号、 也不是绝对可积函数，直接对整条无穷长随机函数做傅里叶变换没有收敛的意义

    例二，常值均值：如果过程有非零常数均值 \(\mu \ne 0\)， 那么自相关里会含一个不衰减的常数项 \(\mu^2\)：

    \[R(\tau) = \mu^2 + C(\tau)\]

    手算这个发散：把常数项单独拿出来积分：

    \[\int_{-\infty}^{\infty} \mu^2\,d\tau = \mu^2 \cdot [\tau]_{-\infty}^{\infty}\]

    看右边：\(\mu^2\) 是正常数，而区间的长度是无限的， 这个「积分」没有任何有限的界 —— 发散 ✗

    所以：「傅里叶变换的理论不能直接应用」 —— 这正是课件提出的问题前提

    2.2 问题的准确表述¶

    课件把这个疑问提得很清楚：

    「自相关的傅里叶变换等于功率谱」这个说法，还成立吗？

    要回答它，必须先把「随机过程的功率谱」定义清楚 —— 因为右边的对象本身还没有严格定义

    直觉上应该怎么定义：随机过程能量无限、但功率有限， 所以应当考虑「单位时间的能量」的期望。这个思路引出下一节的严格定义。

    先看清两个「对手」：

    白噪声 带常数均值的过程
    自相关形状 冲激 \(\sigma^2\delta(\tau)\) 常数底 \(\mu^2\) 之上叠加衰减项
    麻烦在哪 样本函数不收敛、不是能量信号 ⚠ 常数项使积分发散 ⚠
    谱的形状 常数 \(\sigma^2\)（第六节会算） 低频处有一个巨大的峰（趋势能量）

    三、严格定义：截断、期望、极限¶

    这一节给出功率谱的严格定义，只做三件事， 但每一件都有明确的理由，缺一件都不行。

    3.1 第一步：截断¶

    做法：把信号在时间上「切一刀」，只看 \([-T/2, T/2]\) 这一段：

    \[X_T(f) = \int_{-T/2}^{T/2} x(t)\,e^{-j2\pi f t}\,dt\]

    为什么要截断：因为不截断积分不收敛（上一节刚说明） 截断之后积分变成有限的，可以计算

    代价要看清：\(X_T(f)\) 依赖你切了多长、从哪开始切 —— 它本身是个随机变量 ✗

    3.2 第二步：取期望¶

    做法：对 \(\lvert X_T(f)\rvert^2\) 取数学期望：

    \[\mathbb{E}\left[\lvert X_T(f)\rvert^2\right]\]

    为什么要取期望： \(X_T(f)\) 是随机的（依赖抽到哪条样本）， 取期望才能得到一个确定的、与「抽到哪条」无关的量

    注意取的是「模平方的期望」而不是「期望的模平方」 ⚠ 两者完全不同：

    量 含义 会怎样
    \(\lvert\mathbb{E}[X_T(f)]\rvert^2\) 先平均再取模平方 若均值为 0，结果是 0 ✗
    \(\mathbb{E}[\lvert X_T(f)\rvert^2]\) 先取模平方再平均 保留了功率信息 ✓

    为什么前者会失败：零均值过程的 \(\mathbb{E}[X_T(f)] = 0\)， 再取模平方还是 0 —— 什么信息都没了 所以必须先平方、后平均 ✓

    3.3 第三步：除以时长再取极限¶

    做法：

    \[S(f) = \lim_{T\to\infty} \frac{1}{T}\,\mathbb{E}\left[\lvert X_T(f)\rvert^2\right]\]

    为什么要除以 \(T\)： \(\lvert X_T(f)\rvert^2\) 的量纲是「能量」， 它随截断长度 \(T\) 线性增长（切得越长，能量越多）。 除以 \(T\) 之后变成「单位时间的能量」—— 也就是「功率」

    除以 \(T\) 与除以 \(2T\) 的区别：只是常数因子， 不同教材约定不同，不影响结论的形状 （本页统一用 \(1/T\)）

    不除 \(T\) 会怎样：\(S(f)\) 会随 \(T\) 一直增长、不存在极限 ✗

    手算一遍「为什么能量与 \(T\) 成正比」： 对零均值白噪声、在 \(f = 0\) 处， \(X_T(0) = \int_{-T/2}^{T/2} x(t)\,dt\) 近似是 \(T\) 个不相关样本之和， 由方差的叠加性（不相关量的和的方差等于方差之和）：

    \[\mathbb{E}\lvert X_T(0)\rvert^2 = T\,\sigma^2\]

    注意这里完全没有跑代码 —— 结论直接由概率论推出：

    截断长度 \(T\) \(\mathbb{E}\lvert X_T\rvert^2\)（能量） 除以 \(T\)（功率）
    \(256\) \(\approx 256\,\sigma^2\) \(\approx \sigma^2\)
    \(1024\) \(\approx 1024\,\sigma^2\) \(\approx \sigma^2\)
    \(4096\) \(\approx 4096\,\sigma^2\) \(\approx \sigma^2\)
    \(16384\) \(\approx 16384\,\sigma^2\) \(\approx \sigma^2\)

    第一列随 \(T\) 线性增长、无极限；第二列稳定在 \(\sigma^2\) 这就是「必须除以时长」的数理根据。

    3.4 三个步骤的完整小结¶

    步 做法 为什么必须这么做
    1. 截断 只在 \([-T/2, T/2]\) 上积分 否则积分发散 ⚠
    2. 取模平方的期望 \(\mathbb{E}[\lvert X_T\rvert^2]\) 消除随机性；必须先平方后平均 ⚠
    3. 除以 \(T\) 取极限 \(\lim \frac{1}{T}\mathbb{E}[\lvert X_T\rvert^2]\) 从「能量」变成「功率」✓

    四、维纳–辛钦定理与谱分解¶

    4.1 谱分解定理的来龙去脉¶

    课件提到，早期由 Wiener 与 Хинчин（辛钦）的工作严格回答了 「自相关的傅里叶变换是否等于功率谱」这个问题。先看它的结论：

    广义平稳过程的自相关有一个谱分解表达式：

    \[\boxed{\;R(\tau) = \int_{-\infty}^{\infty} S(f)\,e^{j2\pi f\tau}\,df\;}\]

    反过来（在适当条件下）：

    \[S(f) = \int_{-\infty}^{\infty} R(\tau)\,e^{-j2\pi f\tau}\,d\tau\]

    两条式子合起来说明：\(R(\tau)\) 与 \(S(f)\) 构成一对傅里叶变换

    严格地说，谱分解定理的精确表述是一个斯蒂尔切斯积分：

    \[R(\tau) = \int_{-\infty}^{\infty} e^{j2\pi f\tau}\,dF(f)\]

    其中 \(F(f)\) 称为谱分布函数，是单调不减、非负的函数。 为什么必须写 \(dF(f)\) 而不是 \(S(f)df\)： 因为 \(S(f)\) 可能是冲激（如纯正弦过程），普通密度函数写不出来； 用 \(dF(f)\) 就能把「谱线」（\(F\) 的跳变处） 和「连续谱」（\(F\) 平滑上升处）统一处理。 当 \(R(\tau)\) 绝对可积时，\(dF(f) = S(f)\,df\)，就回到上面那对普通积分

    逐项读谱分解式：

    部分 含义
    \(S(f)\) 功率谱密度：频率 \(f\) 处的功率密度
    \(e^{j2\pi f\tau}\) 频率 \(f\) 的复指数（把各频率成分「装配」起来）
    \(\int \cdots df\) 对所有频率加权求和

    这个式子的直观： 自相关可以写成「各频率成分的叠加」，权重就是 \(S(f)\) 换句话说：自相关里含有哪些频率、各占多少功率，全在 \(S(f)\) 里。

    为什么这个定理不平凡：它把第三节的定义（截断 → 期望 → 极限） 和「自相关是时域的、谱是频域的」这两件事接了起来 —— 你不必真的去截断无穷多次，只要知道自相关，谱就完全确定了

    为什么会有「谱分解」这个名字：把自相关看成「由各频率的幂指数装配而成」， 就像把一个向量分解到一组基上；\(S(f)\) 就是每个基方向上的「系数（功率）」。 这跟傅里叶级数把周期函数分解成谐波，是同一个思想，只是基换成了连续频率

    下图用 AR(1) 过程把这对关系画出来： （AR(1) 的自相关按指数衰减、绝对可积，属于上面说的「可积情形」， 其谱是连续谱，恰好落在可以画出来的范围里）

    读图：纵轴是归一化功率谱，横轴是数字角频率 \(\omega\)（只看 \([0,\pi]\)）。 三条曲线对应三个不同的 AR(1) 参数 \(a\)。 \(a\) 越大，自相关衰减越慢，谱就越高越尖 —— 这正是后面第六节要讲的「时宽–带宽反比」规律 （第四节先给出定理，第六节再讲这个规律）

    4.2 为什么 \(S(f) \ge 0\)¶

    这条性质来自自相关的非负定性（上一页 自相关函数的性质 讲过）：

    思路：对任意频率 \(f_0\)，考虑一个「只保留 \(f_0\) 附近成分」的线性滤波。 输出功率是非负的（功率不可能是负的）， 而这个输出功率正比于 \(S(f_0)\)， 所以 \(S(f_0) \ge 0\)

    任何合法的自相关，其傅里叶变换都不可能出现负值 如果一个估计算法给出的谱有负值，说明估计方法有问题（或样本不够）。 第七节会用一个真实反例说明这件事。

    五、离散时间情形¶

    本课程处理的实际是随机序列，所以要把上面的结论写成离散形式。

    5.1 自相关与功率谱的离散对¶

    自相关（上一页已定义）：

    \[R(m) = \mathbb{E}\left[x(n+m)\,x^*(n)\right], \qquad m = 0, \pm 1, \pm 2, \dots\]

    功率谱（DTFT 形式）：

    \[S(\omega) = \sum_{m=-\infty}^{\infty} R(m)\,e^{-j\omega m}\]

    反变换：

    \[R(m) = \frac{1}{2\pi}\int_{-\pi}^{\pi} S(\omega)\,e^{j\omega m}\,d\omega\]

    这就是离散版本的维纳–辛钦定理

    注意频率变量用 \(\omega\)（数字角频率）而不是 \(f\)（物理频率） ⚠ 两者的关系是 \(\omega = 2\pi f / f_s\)（\(f_s\) 是采样率）。 链接 离散傅里叶变换与 FFT 与 采样定理与混叠

    \(S(\omega)=\sum_m R(m)e^{-j\omega m}\) 是怎么来的（与连续情形一一对应）：

    第一步：写出有限长的截断变换。

    \[X_N(\omega) = \sum_{n=0}^{N-1} x(n)\,e^{-j\omega n}\]

    第二步：取模平方，把乘积写成二重求和。

    \[\lvert X_N(\omega)\rvert^2 = \sum_{n=0}^{N-1}\sum_{n'=0}^{N-1} x(n)\,x^*(n')\,e^{-j\omega(n-n')}\]

    第三步：取期望，期望穿进求和。 （交换顺序合法，因为求和只有有限项）

    \[\mathbb{E}\lvert X_N(\omega)\rvert^2 = \sum_{n=0}^{N-1}\sum_{n'=0}^{N-1} R(n-n')\,e^{-j\omega(n-n')}\]

    这里用到平稳性：\(\mathbb{E}[x(n)x^*(n')] = R(n-n')\) 只依赖差值

    第四步：做变量替换 \(m = n-n'\)，把二重求和化成单重求和。 关键在数清楚次数：在 \(N\times N\) 个格点里， 差值 \(m = n-n'\) 出现了恰好 \(N-\lvert m\rvert\) 次 （对角带上的格点数随 \(m\) 线性减少）。于是

    \[\mathbb{E}\lvert X_N(\omega)\rvert^2 = \sum_{m=-(N-1)}^{N-1} (N-\lvert m\rvert)\,R(m)\,e^{-j\omega m}\]

    第五步：除以 \(N\)、取极限 \(N\to\infty\)。

    \[\frac{1}{N}\,\mathbb{E}\lvert X_N(\omega)\rvert^2 = \sum_{m=-(N-1)}^{N-1}\left(1-\frac{\lvert m\rvert}{N}\right)R(m)\,e^{-j\omega m} \;\xrightarrow{N\to\infty}\; \sum_{m=-\infty}^{\infty} R(m)\,e^{-j\omega m}\]

    最后一步的依据：只要 \(\sum_m \lvert R(m)\rvert\) 收敛， 括号里的 \((1-\lvert m\rvert/N)\) 逐点趋于 1，和的极限就是 \(\sum R(m)e^{-j\omega m}\) ✓

    这说明什么：离散版本的推导结构与连续版本一模一样—— 截断求和、模平方的期望、除以 \(N\) 取极限。 所以连续版的直觉（自相关衰减快慢 ⟺ 谱的宽窄）在离散情形完全保留 ✓

    5.2 离散功率谱的三条性质¶

    因为 \(R(m)\) 是离散序列、且（实过程时）是偶序列， 所以 \(S(\omega)\) 有三条必定的性质：

    性质 式子 原因
    周期 \(S(\omega + 2\pi) = S(\omega)\) 离散序列的 DTFT 必然以 \(2\pi\) 为周期 ✓
    偶 \(S(-\omega) = S(\omega)\) \(R(-m) = R(m)\)（实过程）✓
    实且非负 \(S(\omega) \in \mathbb{R}\)，\(S(\omega) \ge 0\) 实过程 → 实；非负定性 → 非负 ✓

    「周期」这条最重要 —— 它是「时域离散 ⟺ 频域周期」这条对偶规律的直接体现 ✓ （在上一页 变换族谱与适用范围 里讲过这条对偶）

    所以看离散功率谱时，只看 \([-\pi, \pi]\) 或 \([0, 2\pi]\) 就够了 ✓

    5.3 有限长数据的精确关系：周期图¶

    上一节的定义里有 \(\mathbb{E}[\cdot]\) 和无穷求和，实际算不了 ⚠ 实际拿到的是有限长的一段 \(x(0),\dots,x(N-1)\)。 这时有一个精确成立的关系：

    \[\lvert X(k)\rvert^2 = \mathrm{DFT}\{\text{圆周自相关}\}(k)\]

    其中 \(X(k)\) 是 \(x\) 的 DFT。写成公式：

    \[\lvert X(k)\rvert^2 = \sum_{m=0}^{N-1} r_c(m)\,e^{-j2\pi km/N}, \qquad r_c(m) = \sum_{n=0}^{N-1} x(n)\,x^*\!\left((n+m) \bmod N\right)\]

    注意「圆周」两个字： \(r_c(m)\) 用的是循环移位（超出 \(N\) 就绕回来）， 而不是真实的自相关（线性）

    为什么这个区别重要：

    量 性质
    圆周自相关的 DFT 恰好等于 \(\lvert X(k)\rvert^2\)——精确恒等 ✓
    线性自相关的傅里叶变换 只有在大样本、且 \(R(m)\) 衰减快时才近似等于它 ⚠

    「周期图」这个名字的来源： 这个量叫周期图（periodogram）， 是最早的功率谱估计方法：

    \[\hat{S}_{\text{per}}(k) = \frac{\lvert X(k)\rvert^2}{N}\]

    六、典型例子与「时宽–带宽反比」¶

    6.1 白噪声：自相关是冲激，谱是常数¶

    定义：\(R(m) = \sigma^2 \delta(m)\)（只有 \(m=0\) 非零）

    手算它的功率谱：

    \[S(\omega) = \sum_{m=-\infty}^{\infty} R(m)e^{-j\omega m} = \sum_{m=-\infty}^{\infty} \sigma^2\delta(m)e^{-j\omega m}\]

    逐项看：\(\delta(m)\) 只在 \(m=0\) 时等于 1，其余全为 0，求和只剩一项：

    \[= \sigma^2 \delta(0)\,e^{0} = \sigma^2\]

    常数 —— 与频率无关 ✓

    这就是「白」的由来： 就像白光包含所有可见光频率一样， 白噪声在所有频率上的功率相同 ✓

    直观理解：

    时域 频域
    相邻样本完全不相关（自相关是冲激） 所有频率等功率（谱是常数）
    「没有任何记忆」 「没有任何偏好」✓

    6.2 正弦过程：谱是「谱线」¶

    过程：\(x(n) = A\sin(\omega_0 n + \Theta)\)，其中 \(\Theta\) 在 \([0, 2\pi)\) 上均匀分布。

    自相关（可以算出）：

    \[R(m) = \frac{A^2}{2}\cos(\omega_0 m)\]

    手算它的功率谱：先用欧拉公式把余弦拆成两个复指数：

    \[\frac{A^2}{2}\cos(\omega_0 m) = \frac{A^2}{4}\left(e^{j\omega_0 m} + e^{-j\omega_0 m}\right)\]

    回忆恒等式（一个复指数在频域是一簇等间隔冲激）：

    \[\sum_{m=-\infty}^{\infty} e^{-j(\omega-\omega_0)m} = 2\pi\sum_{k}\delta(\omega - \omega_0 - 2\pi k)\]

    代入得

    \[S(\omega) = \frac{A^2\pi}{2}\sum_k\Big[\delta(\omega-\omega_0-2\pi k) + \delta(\omega+\omega_0-2\pi k)\Big]\]

    即：功率全部集中在 \(\pm\omega_0\) 两个频率上（再按 \(2\pi\) 周期重复）

    这就是「谱线」 —— 离散的、尖锐的峰

    对比白噪声（这张表是本节的关键）：

    白噪声 正弦过程
    时域自相关 冲激（只有 \(m=0\)） 余弦（周期性、不衰减）
    频域功率谱 常数（全频段） 谱线（集中于两个频率）
    直观 完全不相关 完全周期性 ✓

    两者恰好互为「极端」 —— 一个是「时域最窄、频域最宽」， 另一个是「时域最宽、频域最窄」

    下图把这两个极端放在一起对照： 左图是白噪声的冲激自相关（上）与常数谱（下）， 右图是正弦的余弦自相关（上）与一对谱线（下）， 一眼就能看出「窄对宽、宽对窄」：

    读图：注意两张子图的横轴分别是滞后 \(m\) 和数字角频率 \(\omega\)。 白噪声的自相关只在 \(m=0\) 有值，对应的谱铺满整个频段； 正弦的自相关永不衰减，对应的谱只剩下两条竖线。 这引出下面的一般规律。

    6.3 时宽–带宽反比（一般规律）¶

    规律：

    \[\text{自相关衰减越慢} \;\Longleftrightarrow\; \text{功率谱越窄}\]

    为什么：

    时域 频域 直观
    自相关衰减快（很快不相关） 谱很宽 信号「变化快」→ 含高频成分多
    自相关衰减慢（长时间相关） 谱很窄 信号「变化慢」→ 能量集中在低频 ✓

    两个极端就是上面那两例：

    极端 自相关 谱
    白噪声 衰减最快（一步到 0） 最宽（常数）
    正弦 衰减最慢（永不衰减） 最窄（谱线）✓

    用 AR(1) 手算一遍这个反比： AR(1) 的自相关是 \(R(q) = \sigma^2 a^{q}/(1-a^2)\)， 谱的有效宽度用 \(\omega^2\) 的加权平均平方根来度量。

    先算「自相关衰减到 \(1/e\) 需要多少步」 —— 解 \(a^{q_e} = 1/e\)：

    \[q_e = -\frac{1}{\ln a}\]

    代入 \(a = 0.9\) 手算：

    \[q_e = -\frac{1}{\ln 0.9} = -\frac{1}{-0.1054} \approx 9.49 \qquad \text{（约 9.5 步才衰减到 } 1/e\text{）}\]

    把几组 \(a\) 的结果列成对照表（\(\sigma_\omega\) 是谱的标准差宽度， 谱峰/谱底比来自 \(S(0)/S(\pi)\)）：

    \(0.50\) \(1.44\) \(1.22\) \(9.0\)
    \(0.70\) \(2.80\) \(0.93\) \(32\)
    \(0.90\) \(9.49\) \(0.53\) \(361\)

    读表：\(a\) 从 \(0.3\) 增到 \(0.98\)， 自相关衰减步数从 \(0.83\) 增到 \(49.5\)（变慢）， 而谱宽度从 \(1.47\) 降到 \(0.24\)（变窄）—— 两者严格反向，时宽–带宽反比得到量化印证 ✓

    谱峰/谱底比的来历（\(a=0.9\) 时手算一遍）： 由 \(\lvert 1-ae^{-j\omega}\rvert^2 = 1 - 2a\cos\omega + a^2\)，

    \[S(0) \propto \frac{1}{(1-a)^2} = \frac{1}{0.01} = 100, \qquad S(\pi) \propto \frac{1}{(1+a)^2} = \frac{1}{3.61} \approx 0.277\]

    「时宽–带宽反比」是趋势，不是精确等式

    这个规律说的是趋势：自相关衰减越慢，谱越窄。

    用法 对/错
    定性判断「哪个谱更宽、更窄」 对 ✓
    断言「宽度 = 某个常数 × 相关时间」 错 ✗ —— 具体数值依赖信号模型

    考试和工程里用它做定性判断； 要算具体数字，必须用该模型的闭式谱 （如 AR(1) 的 \(\lvert 1-ae^{-j\omega}\rvert^{-2}\)）

    这个规律的实践意义（很重要）：

    观察到的现象 推断
    自相关衰减很慢 信号里有低频/周期成分或趋势 ⚠
    功率谱在某频率有尖峰 那里有周期成分（可能是干扰）✓
    功率谱很平坦 接近白噪声（如热噪声）✓

    6.4 用真实数据「看」谱峰¶

    任务：一个正弦信号淹没在噪声里，怎么找出它的频率？ 答案：看功率谱的峰

    为什么时域不行、频域行：正弦的功率集中在 \(\omega_0\) 一条线上， 而噪声的功率平摊到整个频段。 于是「信噪比」在时域看是全局平均的，在 \(\omega_0\) 处看却是局部的—— 谱峰的高度相对底噪可以高出几百倍，峰自然清晰可见。

    课件里用「正弦 50 Hz + 高斯噪声（标准差 0.3）」的例子， 实测结果是：谱的峰/中位数约 \(748\)，峰值频率 \(50.78\) Hz， 与真实值只差 \(0.78\) Hz，小于频率分辨率 \(f_s/N_\text{seg} = 1000/512 \approx 1.95\) Hz

    谱分析是一种「能量聚焦」工具 —— 把分散在整个频段的噪声能量、和集中在一条线上的信号能量分开来看， 信号就「现形」了。这是谱估计在工程上最常用的理由

    6.5 窄带滤波降低噪声功率¶

    一条直接可用的推论：如果 \(\lvert H(\omega)\rvert^2\) 只在很窄的频段非零， 那么只有那一小段频率上的噪声能通过 → 输出功率大幅下降

    手算这个结论：若输入是白噪声（谱密度 \(\sigma^2\)）， 滤波器的通带宽度为 \(B\)，则输出功率近似为

    \[P_y \approx \sigma^2 \cdot B\]

    （这其实是下一节「通过线性系统」的公式 \(P_y = \frac{1}{2\pi}\int_{-\pi}^{\pi}\lvert H(\omega)\rvert^2 S_x(\omega)\,d\omega\) 在白噪声、窄带情形下的近似：\(\lvert H\rvert^2\) 只在宽度 \(B\) 的带上约为 1， 积分约等于 \(S_x \cdot B\)）

    量化对照（输入白噪声功率归一化为 1，\(\sigma^2 = 1\)）：

    归一化带宽 \(B\) 输出功率（近似公式 \(B\)） 相对输入
    \(0.50\) \(\approx 0.50\) \(0.50\)
    \(0.20\) \(\approx 0.20\) \(0.20\)
    \(0.05\) \(\approx 0.05\) \(0.05\)
    \(0.01\) \(\approx 0.01\) \(0.01\)

    读表：带宽从 \(0.50\) 缩到 \(0.01\)（缩 50 倍）， 输出功率也缩约 50 倍 —— 输出功率与带宽近似成正比 （课件实测含滤波器过渡带的值是 \(0.50/0.21/0.047/0.010\)，与近似一致）

    滤波器选得越窄，滤掉的噪声越多， 代价是信号本身的带宽也被切掉。 「用带宽换信噪比」是接收机设计的核心权衡之一， 也是下一节「平稳序列通过线性系统」的直接应用

    七、一个反例与实用检查清单：截断自相关会算出负的谱¶

    7.1 原理¶

    真实谱 \(S(\omega) \ge 0\)（4.2 节证明过）。 但由有限数据估计时，如果处理不当， 估出来的谱会出现负值 —— 这在物理上是不可能的

    为什么会出负值：估计谱的常见做法是 「取样本自相关的前 \(M+1\) 项、其余当作 0，再做变换」。 这等于在时域乘了一个矩形窗 \(w(m) = 1\)（\(|m| \le M\)）：

    \[\hat{S}(\omega) = \sum_{m=-M}^{M} R(m)\,e^{-j\omega m} \quad\Longleftrightarrow\quad \hat{S} = S * W \quad\text{（}W\text{ 是矩形窗的谱）}\]

    矩形窗的谱 \(W(\omega)\) 有负的旁瓣（Dirichlet 核在 0 值上下振荡）， 卷积之后就把负值带进了估计结果 ⚠ 更根本的原因：由有限数据得到的有偏自相关估计本身不是正定序列， 非负定性没有被保证 —— 所以无论怎样线性截断都可能出负值。

from scipy.signal import get_window

rng = np.random.default_rng(42)


def psd_from_ac(ac, M, window, nfft=1024):
    """由自相关前 M+1 项做加窗谱估计。"""
    r = np.concatenate([ac[M:0:-1], ac[:M + 1]])   # 对称双边，长度 2M+1
    if window is not None:
        r = r * get_window(window, 2 * M + 1)
    return np.fft.rfft(r, n=nfft).real

    结论 说明
    谱的非负性是「判据」 估出来的谱有负值 → 方法有问题 ⚠
    截断 = 乘矩形窗 而矩形窗的谱有负旁瓣
    加窗是必要的 但本页测试的 Bartlett/Hann 窗也出现负值，说明不只是加窗能解决

    为什么加了窗还有负值：因为这里的自相关是有偏估计， 它本身不是真正的正定序列 —— 非负定性没被保证 ⚠ 彻底的解法是后面章节会讲的参数模型法或子空间法， 它们从模型层面保证谱非负 ✓

    从「谱非负」这件事得到的实用检查习惯

    检查 若失败说明什么
    谱里有负值？ 估计方法或窗选择有问题 ⚠
    谱与横轴围成的面积 ≠ 均方值？ 归一化算错了
    谱不关于 0 对称（实信号）？ 程序里的复数处理有问题
    谱不是 \(2\pi\) 周期？ 频率轴的定义有问题

    这四条是很实用的自查清单 —— 它们都能用「性质」快速判断程序对不对 ✓

    八、典型例题¶

    例题 1：由自相关求功率谱（白噪声 + 余弦）¶

    设平稳序列的自相关为

    \[R(m) = \sigma^2 \delta(m) + \frac{A^2}{2}\cos(\omega_0 m)\]

    求它的功率谱。

    思路

    利用 DTFT 的线性性，分别求两项的变换再加起来。 第一项是冲激（常数谱），第二项是余弦（一对谱线）。 余弦的 DTFT 用欧拉公式展开成两个复指数。

    解答

    第一步：利用线性性拆成两项。

    \[S(\omega) = \sum_{m} \sigma^2\delta(m)e^{-j\omega m} + \frac{A^2}{2}\sum_{m}\cos(\omega_0 m)e^{-j\omega m}\]

    第一项：\(\delta(m)\) 只在 \(m=0\) 时为 1，所以

    \[\sum_{m}\sigma^2\delta(m)e^{-j\omega m} = \sigma^2 \cdot e^{0} = \sigma^2\]

    这是一个常数（与频率无关）

    第二步：算第二项。 用欧拉公式把余弦拆开：

    \[\cos(\omega_0 m) = \frac{e^{j\omega_0 m} + e^{-j\omega_0 m}}{2}\]

    代进去：

    \[\frac{A^2}{2}\cdot\frac{1}{2}\sum_m\left(e^{j\omega_0 m} + e^{-j\omega_0 m}\right)e^{-j\omega m} = \frac{A^2}{4}\sum_m\left(e^{-j(\omega-\omega_0)m} + e^{-j(\omega+\omega_0)m}\right)\]

    用冲激的 DTFT 恒等式：对整数 \(m\) 求和时，

    \[\sum_{m=-\infty}^{\infty} e^{-j(\omega - \omega_0)m} = 2\pi\sum_{k}\delta(\omega - \omega_0 - 2\pi k)\]

    即：一个复指数的「频谱」是在该频率处的一串等间隔冲激 （间隔 \(2\pi\)，因为离散时间信号的谱是周期的）

    所以第二项是四簇冲激（\(\pm\omega_0\) 各一簇，每簇按 \(2\pi\) 重复）。

    第三步：合并结果。

    \[S(\omega) = \sigma^2 + \frac{A^2\pi}{2}\sum_k\Big[\delta(\omega-\omega_0-2\pi k) + \delta(\omega+\omega_0-2\pi k)\Big]\]

    读这个结果：

    部分 含义
    \(\sigma^2\) 连续的平坦底面（白噪声贡献）✓
    两簇冲激（在 \(\pm\omega_0\)） 两条尖锐的谱线（余弦贡献）✓

    这就是「噪声底 + 谱线」的经典形状 —— 实际频谱分析中看到这种图，就说明「信号是正弦 + 噪声」✓

    说明什么：这道题是「谱分解」思想的直接运用 —— 把自相关拆成几块，每块的谱分别算，再线性叠加。 考试时先写线性性，再逐块算，最后合并，中间不跳步即可拿全分 ✓

    例题 2：判断谱的形状¶

    一个平稳序列的自相关为 \(R(m) = 0.9^{\lvert m\rvert}\)。 问：(a) 它的谱在 \(\omega = 0\) 与 \(\omega = \pi\) 处哪个更大？ (b) 这个谱「宽」还是「窄」？

    思路

    \(0.9^{\lvert m\rvert}\) 是典型的 AR(1) 型自相关（\(a = 0.9\)）。 衰减慢 → 谱窄、且能量集中在低频。 可以写出闭式 \(S(\omega) = \frac{1-a^2}{\lvert 1-ae^{-j\omega}\rvert^2}\) 再代入两端比较。

    解答

    （a）比较两端。

    这是 \(a = 0.9\) 的 AR(1) 自相关（前页 广义平稳过程的统计描述 讲过它的性质）。

    直接代入验证：

    \[\lvert 1 - ae^{-j\omega}\rvert^2 = (1-a\cos\omega)^2 + (a\sin\omega)^2 = 1 - 2a\cos\omega + a^2\]

    \(\omega = 0\) 处：\(\cos 0 = 1\)，所以

    \[\lvert 1 - a\rvert^2 = (1-0.9)^2 = 0.01\]

    \(\omega = \pi\) 处：\(\cos\pi = -1\)，所以

    \[\lvert 1 + a\rvert^2 = (1+0.9)^2 = 3.61\]

    因为谱正比于 \(\lvert 1-ae^{-j\omega}\rvert^{-2}\)：

    \[S(0) \propto \frac{1}{0.01} = 100, \qquad S(\pi) \propto \frac{1}{3.61} \approx 0.277\]

    所以 \(S(0) \gg S(\pi)\) ✓

    具体数值（用归一化常数，\(R(0) = 1\) 对应 \(\sigma^2/(1-a^2) = 1\)， 即 \(\sigma^2 = 1 - a^2 = 0.19\)）：

    \[S(0) = \frac{0.19}{0.01} = 19, \qquad S(\pi) = \frac{0.19}{3.61} \approx 0.0526\]

    比值约 \(361\) 倍 ⚠

    （b）宽还是窄。

    窄 ✓ 理由有两条：

    理由 说明
    自相关衰减慢 \(0.9^{m}\) 要 22 步才降到 \(0.1\)（\(0.9^{22} \approx 0.098\)），衰减很慢 ✓
    能量集中在低频 \(S(0)/S(\pi) \approx 361\)，绝大部分功率在 \(\omega\) 接近 0 的地方 ✓

    这就是「时宽–带宽反比」的具体体现 ✔

    例题 3：验证「除以 T」的必要性¶

    某同学算功率谱时忘了除以截断长度 \(T\)。请说明会出现什么问题， 并给出数值证据。

    思路

    \(\lvert X_T(f)\rvert^2\) 的量纲是能量，随 \(T\) 线性增长。 不除 \(T\) 的话，\(T\) 越大结果越大，不存在极限。 用不同 \(T\) 算同一个量，看它是否随 \(T\) 增长。

    解答

    问题：结果的量纲错了，而且随 \(T\) 无限增长 ⚠

    为什么：\(\lvert X_T(f)\rvert^2\) 是「截断后信号的能量」。 截断得越长，包含的能量越多 —— 它与 \(T\) 成正比 ✓

    所以不除 \(T\) 时：

    \[\text{结果} \propto T \;\longrightarrow\; \infty \quad \text{（当 } T \to \infty\text{）}\]

    不存在极限 ✗

    除以 \(T\) 之后：得到「单位时间的能量」= 功率， 它与 \(T\) 无关，极限存在 ✓

    数值证据（用零均值白噪声，在 \(f = 0\) 处算； 由方差叠加性 \(\mathbb{E}\lvert X_T\rvert^2 = T\sigma^2\)，\(\sigma^2 = 1\)）：

    \(T\) \(\mathbb{E}[\lvert X_T\rvert^2]\)（能量） 除以 \(T\)
    \(256\) \(\approx 256\) \(\approx 1.0\)
    \(1024\) \(\approx 1024\) \(\approx 1.0\)
    \(4096\) \(\approx 4096\) \(\approx 1.0\)
    \(16384\) \(\approx 16384\) \(\approx 1.0\)

    第一列随 \(T\) 线性增长，第二列稳定在 \(1.0\)（方差） ✓

    说明什么：判断「定义对不对」先看量纲。 功率谱是「单位频率、单位时间的能量」，两个分母都不能丢： 丢了 \(T\) 会随数据长度发散，丢了频率归一化会量纲错误 ✓

    例题 4：白噪声通过矩形窗后的谱¶

    把白噪声乘上一个长度为 \(N\) 的矩形窗（即只截一段）， 问：它的功率谱与原来的常数谱有什么关系？

    思路

    乘矩形窗 = 频域与矩形窗的频谱卷积。 矩形窗的频谱是 \(\lvert\sin(N\omega/2)/\sin(\omega/2)\rvert^2\) 型（Dirichlet 核）。 所以谱形状被「抹开」成那个形状，出现旁瓣。 这正是上一节提到的「周期图的波动」。

    解答

    第一步：说明关系。

    时域相乘 \(\longleftrightarrow\) 频域卷积。

    截断后的信号 \(x_N(n) = x(n)w(n)\)（\(w\) 是矩形窗）， 它的傅里叶变换是真实谱与窗谱的卷积：

    \[X_N(\omega) = \frac{1}{2\pi}\int_{-\pi}^{\pi}X(\theta)W(\omega-\theta)\,d\theta\]

    所以就算真实信号是白噪声（谱为常数）， 截断后的谱也不再是常数 —— 它被窗的谱「抹」成了有主瓣、有旁瓣的形状 ⚠

    第二步：矩形窗的谱。

    \[\lvert W(\omega)\rvert^2 = \left\lvert\frac{\sin(N\omega/2)}{\sin(\omega/2)}\right\rvert^2\]

    这个函数的特点：

    特征 说明
    主瓣在 \(\omega = 0\)，宽度 \(\approx 4\pi/N\) \(N\) 越大主瓣越窄 ✓
    旁瓣在两侧，幅度衰减但不为 0 旁瓣带来泄漏 ⚠
    与常数谱卷积后 得到「主瓣形状 + 旁瓣」的谱 ✓

    第三步：这解释了周期图的波动。

    真实谱是常数，但估计出的谱是「常数 × 窗谱」的形状 —— 所以估计值在频率上剧烈起伏 ⚠ 这就是上一节 5.3 节提到的「周期图方差大」的直观来源 ✓

    说明什么：矩形窗是最简单的窗，但它的旁瓣也是最差的。 「截断」这个动作本身就在往谱里注入窗的形状 —— 所以谱估计里要仔细选窗、并懂得「窗的形状 = 谱被抹成什么样」✓

    九、自测¶

    Q1 判断对错并说明理由： 「功率谱 \(S(\omega)\) 可能出现负值，因为自相关可以是负的。」

    提示

    自相关可以为负，但谱可以吗？ 回顾第四节「为什么 \(S(f) \ge 0\)」。

    解答

    前半句对，后半句错。

    说法 对错 理由
    「自相关可以是负的」 对 ✓ 例如 \(R(m) = -0.5^{m}\) 这类可以有负值
    「所以谱可能为负」 错 ✗ 谱必定非负，与自相关是否有负值无关 ⚠

    为什么谱必定非负： 由自相关的非负定性（上一页讲过）， 对任意频率 \(\omega_0\)，该频率处的功率就是 \(S(\omega_0)\)， 而功率不可能为负 ✓

    更形式化的理由： 非负定性保证 \(\sum_i\sum_j a_i a_j^* R(m_i-m_j) \ge 0\)。 取 \(a_k = e^{-j\omega_0 k}\) 之类的系数， 这个二次型就化成 \(S(\omega_0) \ge 0\) ✓

    所以「自相关有负值」与「谱有负值」完全是两件事：

    对象 能否为负
    自相关 \(R(m)\) 能 ✓（它是时域的相关程度，可以是负相关）
    功率谱 \(S(\omega)\) 绝对不能 ⚠

    反过来说，这个性质很实用： 如果你估出的谱出现负值，一定是方法或程序有问题， 不是「真实信号有这个性质」✓

    Q2 为什么功率谱的定义里要「先取模平方，再取期望」， 而不是「先取期望，再取模平方」？

    提示

    想一想零均值过程的情形：\(\mathbb{E}[X_T(f)]\) 等于多少？

    解答

    关键原因：对零均值过程，「先取期望」会把信息全部丢掉 ⚠

    算一下：若过程均值为 0，则

    \[\mathbb{E}[X_T(f)] = \int_{-T/2}^{T/2}\mathbb{E}[x(t)]e^{-j2\pi ft}dt = \int_{-T/2}^{T/2}0\,dt = 0\]

    所以「先取期望再取模平方」得到恒为 \(\mathbf{0}\) —— 完全无法反映功率 ✗

    而「先取模平方再取期望」保留了功率信息 因为 \(\lvert X_T(f)\rvert^2\) 是「能量」， 它的期望就是「平均能量」，除以 \(T\) 就是功率

    两种顺序的对比表：

    顺序 表达式 零均值过程的结果 是否可用
    先期望后平方 \(\lvert\mathbb{E}[X_T]\rvert^2\) 恒为 0 ✗ 不可用
    先平方后期望 \(\mathbb{E}[\lvert X_T\rvert^2]\) 正数 ✓ 可用 ✓

    一个直观类比： 想象一批随机符号的「平均幅度」与「平均功率」。

    量 零均值随机符号的结果
    平均幅度（先平均） \(\approx 0\)（正负抵消）✗
    平均功率（先平方） \(\gt 0\)（平方后都为正）✓

    所以「功率」这个词本身就要求先平方

    Q3 白噪声与正弦过程的功率谱各是什么形状？ 它们的自相关又各是什么形状？为什么说它们互为「极端」？

    提示

    回顾第六节的两张对照表。一个「时域最窄」，一个「频域最窄」。

    解答

    逐个列出：

    白噪声 正弦过程
    自相关 \(R(m)\) \(\sigma^2\delta(m)\) —— 冲激 \(\dfrac{A^2}{2}\cos(\omega_0 m)\) —— 余弦
    功率谱 \(S(\omega)\) \(\sigma^2\) —— 常数 在 \(\pm\omega_0\) 处的冲激（谱线）
    时域特征 相邻样本完全不相关 完全周期性（永不衰减）
    频域特征 全频段等功率 功率集中在两个频率

    它们互为「极端」的理由（关键是「时宽–带宽反比」）：

    维度 白噪声 正弦
    时域「宽窄」 自相关最窄（只在 \(m=0\) 非零）✓ 自相关最宽（永不衰减）✓
    频域「宽窄」 谱最宽（常数，铺满全频段）✓ 谱最窄（只剩两条线）✓
    关系 时域最窄 → 频域最宽 时域最宽 → 频域最窄

    两者在「时宽–带宽反比」的两端 —— 这正是「时域越集中、频域越分散」这条规律的两个极限情形。

    中间的连续过渡：AR(1) 过程就是中间情形 —— 自相关按指数衰减（既不立即到 0，也不永不衰减）， 谱是一个有宽度的峰（既不常数、也不是谱线） 参数 \(a\) 控制它在这个「极端轴」上的位置： \(a \to 0\) 接近白噪声，\(a \to 1\) 接近正弦

    对照数值（\(a\) 越小谱越平、越大越尖）：

    AR(1) 参数 \(a\) 谱的平坦度（峰/底） 谱宽度
    \(0.00\) \(1.0\)（完全平坦） \(1.81\)
    \(0.50\) \(9.0\) \(1.22\)
    \(0.90\) \(361\) \(0.53\)
    \(0.99\) \(39601\) \(0.17\)

    读表：\(a \to 0\) 平坦度趋近 1（白噪声）， \(a \to 1\) 平坦度爆炸式增长（趋近谱线）

    Q4 为什么工程上「用一条实测数据算功率谱」是合法的？ 条件是什么？

    提示

    回顾第四节的「遍历性定理的作用」。 关键是把「系综平均」换成「时间平均」需要什么前提。

    解答

    合法性的来源：遍历性

    问题在哪： 功率谱的严格定义里含期望：

    \[S(f) = \lim_{T\to\infty}\frac{1}{T}\mathbb{E}\left[\lvert X_T(f)\rvert^2\right]\]

    而期望需要无穷多次平行实验 —— 工程上根本做不到

    遍历性给出的答案： 如果过程是平稳且遍历的， 时间平均收敛（按概率 1）于系综平均，于是可以把期望去掉：

    \[S(f) = \lim_{T\to\infty}\frac{1}{T}\lvert X_T(f)\rvert^2 \quad \text{（按概率 1）}\]

    右边只需要一条样本 ✓ —— 这就是工程可用性。

    必须满足的条件（三点，缺一不可）：

    条件 为什么需要 违反的后果
    广义平稳 否则自相关不是 \(\tau\) 的一元函数，谱本身没定义 ⚠ 谱随时间变，无意义
    遍历性 否则时间平均 ≠ 系综平均 ✗ 单条数据的谱不能代表整体
    有限二阶矩 \(R(0) = \mathbb{E}[\lvert x\rvert^2] \lt \infty\) 功率无限，谱无意义

    实践中怎么检查（这是最实用的部分）：

    检查 做法 判据
    平稳性 把长信号切 8 段，分别算均值与方差 各段接近 → 平稳 ✓
    遍历性 分段算谱，看是否一致 形状一致 → 近似遍历 ✓
    相关性 看自相关衰减速度 衰减到 0 → 相关时间有限 ✓

    反过来：不满足条件时会出现什么：

    情形 现象
    含趋势（非平稳） 谱在低频有一个巨大的峰，掩盖真实结构 ⚠
    含周期性干扰 谱出现不该有的谱线
    相关时间过长 一段数据里的「独立样本」数很少 → 估计方差极大 ⚠

    说明什么：「一条数据算谱」不是免费的 —— 它隐含了平稳 + 遍历 + 有限二阶矩三个假设。 考试答题时先写假设、再写结论，顺序对了就有分

    小结¶

    要记住的 为什么
    能量信号：自相关的傅里叶变换 = \(\lvert X(f)\rvert^2\) 由卷积定理直接证明（自相关 = \(x\) 与 \(x^*(-\tau)\) 卷积）✓
    随机过程的自相关一般不是绝对可积的 所以傅里叶变换不能直接应用 ⚠
    功率谱的三步定义：截断 → 模平方的期望 → 除以 \(T\) 取极限 每步都有明确理由
    必须「先平方、后期望」 零均值过程「先期望」会得 0 ✗
    必须除以 \(T\) 不然量纲是能量，且随 \(T\) 无限增长 ⚠
    谱分解定理 \(R(\tau) = \int S(f)e^{j2\pi f\tau}df\) 自相关可写成各频率成分的叠加
    维纳–辛钦定理 自相关与功率谱构成一对傅里叶变换 ✓
    \(S(f) \ge 0\) 来自自相关的非负定性；用它检查估计是否正确 ✓
    遍历性把「系综平均」换成「时间平均」 这是「用一条数据算谱」的合法性来源 ✓
    离散情形 \(S(\omega) = \sum_m R(m)e^{-j\omega m}\) 本课程的主要对象
    离散谱三性质：周期 \(2\pi\)、偶、实且非负 只看 \([-\pi,\pi]\) 就够 ✓
    周期图 \(\lvert X(k)\rvert^2/N\) = 圆周自相关的 DFT 有限长数据下精确成立 ✓
    周期图方差大、不随数据量下降 需要分段平均 / 参数模型 / 子空间法 ⚠
    白噪声：自相关冲激、谱常数 「白」= 全频段等功率
    正弦：自相关余弦、谱是谱线 与白噪声互为极端 ✓
