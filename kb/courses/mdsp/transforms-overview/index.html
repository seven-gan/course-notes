    变换族谱与适用范围¶

    这一页解决什么问题：手上这段信号，到底该用哪一个变换。

    本站的「数学基础」层已经把这些变换各自的定义、性质、常用变换对分别讲透了：

    • 傅里叶级数与变换
    • 离散傅里叶变换与 FFT
    • Z 变换与滤波器
    • 拉普拉斯变换
    • 采样定理与混叠
    • 卷积

    所以本页不重复任何一条定义，只回答「什么时候用哪个」这个问题。

    这个问题不是凭兴趣挑出来的。本课程课件在回顾这一组内容时， 明确说出了三个基本关注点：变换的基本性质、适应范围、应用方法与限制。 「适应范围」与「限制」这两条，就是这一页的全部任务。

    先看三个「看着差不多、实际差很远」的情形，它们代表了本页要防住的三类错误：

    看起来差不多的做法 实际差别 后果
    手上只有一段有限长的采样数据，却说「这段数据的频谱是……」 有限长序列做 DFT 隐含了周期延拓假设，只有 DTFT 才是它的真谱 泄漏和栅栏效应被误当成信号自身的性质 ⚠
    拿着正弦信号去算傅里叶变换积分 正弦是功率信号，不满足绝对可积 积分不收敛，严格来说 FT 根本不存在 ⚠
    由 \(X(z)\) 的表达式直接反求 \(x(n)\) 表达式相同时，收敛域不同会给出两个不同的序列 逆变换不唯一，时域结果整体反了 ⚠

    这一页的主线

    先判信号的四个属性 —— 连续还是离散、周期还是非周期、 能量还是功率、有限长还是无限长 —— 再由属性查表选出变换。

    整张族谱可以用两条对偶关系推出来：

    时域周期性 ⟺ 频域离散；时域离散 ⟺ 频域周期。

    把这两条记住，后面所有表格都不用背。

    一、为什么需要这么多变换¶

    1.1 变换不同，是因为处理的信号类型不同¶

    一个刚学完信号与系统的人，最常见的困惑是： 「这几个变换看起来都在做同一件事 —— 把时间上的东西换到频率上看，为什么要有六个？」

    原因只有一条：它们面对的信号不是同一类信号。 而信号的类别，由四个属性决定。这四个属性里， 前两个决定「谱长什么样」，后两个决定「这个变换到底存不存在」：

    信号属性 两种取值 它决定了什么
    时间轴 连续 / 离散 频域是否周期（时域离散则频域周期）✓
    时间上的重复性 周期 / 非周期 频域是否离散（时域周期则频域离散线谱）✓
    能量 能量信号 / 功率信号 积分或求和是否收敛，即变换是否存在
    记录长度 有限长 / 无限长 能不能直接把数据丢进计算机算（DFT）

    这四个属性相互独立，所以组合起来远不止六种。 但真正实用的组合只有六到七种，而每一种恰好被一个变换对上号。 下表把「信号 → 变换」的映射一次列清，这是本页的第一张速查表：

    手上信号的类型 典型例子 该用哪个变换 一句话理由
    连续、周期 正弦、方波、周期脉冲串 FS（傅里叶级数） 周期信号的谱是离散线谱，级数刚好给出这些线
    连续、非周期、能量 单脉冲、衰减振荡 FT（傅里叶变换） 非周期对应连续谱，能量有限保证积分收敛
    连续、非周期、功率 直流、理想化的正弦延长 自相关 + 功率谱，而不是 FT 本身 功率信号不满足绝对可积，FT 严格不存在 ⚠
    离散、周期 以 \(N\) 为周期的采样序列 DFS / DFT 时域周期加时域离散，频域两边都离散，计算机能算 ✓
    离散、非周期、无限长 一阶自回归序列 DTFT，或换成复变量用 Z 变换 谱连续且以 \(2\pi\) 为周期，计算机无法直接给出
    离散、非周期、有限长 一段实测数据 理论用 DTFT，工程用 DFT 近似 有限序列做 DFT，等于先把它周期延拓 ⚠
    描述线性系统的稳定性与频响 差分方程给出的系统 Z 变换（连续系统用拉普拉斯变换） 极点位置同时给出稳定性判据与频率响应

    这张表最值得记住的不是最后那一列，而是第二列与第三列的对应关系： 一旦你能说清手上的信号属于哪一行，变换就唯一确定了，不需要犹豫。

    用错变换最常见的两种方式

    第一种是拿 DFT 当 DTFT 用。 一段实测数据是有限长的非周期序列，它的真谱是 DTFT（连续曲线）。 你直接对它做 DFT，得到的是另一件事：先把数据首尾相接、 无限重复成一个周期序列，再算这个周期序列的谱。 真实的谱曲线因此被「采样 + 泄漏」双重扭曲 ⚠

    第二种是拿 FT 去算功率信号。 正弦、方波、直流这些信号的绝对值积分是发散的， 傅里叶变换的定义式不收敛。工程上仍然说「正弦的频谱是一根谱线」， 这句话是约定说法，严格含义要用自相关函数与功率谱来描述 ✓

    1.2 用错变换是一种「不会报错」的错误¶

    这类错误的麻烦之处在于：程序不会给你任何提示。

    你把一段有限长的数据丢给 FFT，它一定返回一串复数， 一定能画出漂亮的频谱图，一定没有异常抛出。 问题在于这张图上出现的很多细节 —— 那些起伏、那些旁瓣、 那些「峰值为什么不在我预期的那根谱线上」—— 可能全都是错误的假设造出来的， 而不是信号本身的性质。

    import numpy as np

# 一段有限长的非周期序列：先线性上升，再保持
x = np.concatenate([np.linspace(0.0, 0.7, 8, endpoint=False), np.full(8, 0.7)])
print("有限长非周期序列（16 点）:")
print("  前 8 点:", np.round(x[:8], 4))
print("  后 8 点:", np.round(x[8:], 4))
print()
print("若把它交给 DFT，就隐含了一个假设：把这段数据首尾相接、无限重复。")
print("  首尾差 = |x[0] - x[N-1]| = |%.4f - %.4f| = %.4f"
      % (x[0], x[-1], abs(float(x[0]) - float(x[-1]))))
print("  这个跳变不属于原信号，是「周期延拓」造出来的。")
print()
print("跳变带来的谱畸变（同一段信号，截断长度不同）：")
print("  长度 N   首尾差    高频能量占比")
for n in (4, 8, 12, 16):
    seg = x[:n]
    X = np.fft.fft(seg)
    power = np.abs(X) ** 2
    hi = power[n // 2:].sum() / power.sum()
    print("  %4d   %7.4f   %10.4f"
          % (n, abs(float(seg[0]) - float(seg[-1])), float(hi)))
print()
print("结论：同一段数据，只要「怎么延拓」的假设不同，谱就不同。")
print("      用错变换的后果不是算错，而是算出了「另一个信号」的谱。")

    有限长非周期序列（16 点）:
  前 8 点: [0.     0.0875 0.175  0.2625 0.35   0.4375 0.525  0.6125]
  后 8 点: [0.7 0.7 0.7 0.7 0.7 0.7 0.7 0.7]

若把它交给 DFT，就隐含了一个假设：把这段数据首尾相接、无限重复。
  首尾差 = |x[0] - x[N-1]| = |0.0000 - 0.7000| = 0.7000
  这个跳变不属于原信号，是「周期延拓」造出来的。

跳变带来的谱畸变（同一段信号，截断长度不同）：
  长度 N   首尾差    高频能量占比
     4    0.2625       0.2143
     8    0.6125       0.1571
    12    0.7000       0.1229
    16    0.7000       0.0951

结论：同一段数据，只要「怎么延拓」的假设不同，谱就不同。
      用错变换的后果不是算错，而是算出了「另一个信号」的谱。

    输出怎么读：这段数据本身是「先上升、后保持」， 它在物理上没有任何周期性，也不存在首尾衔接的问题。

    但 DFT 要求输入是周期序列，于是它把这个 16 点数据首尾相接， 结果在接缝处凭空出现了一个 \(|0.7 - 0| = 0.7\) 的跳变。 跳变是一种「高频事件」，它的能量因此被塞进了频谱的高频段 —— 右上角那一列「高频能量占比」从 \(0.2143\) 一路降到 \(0.0951\)， 变化的原因不是信号变了，而是截断长度变了、接缝的位置变了。

    判断标准很简单

    如果你算完谱之后需要解释「为什么这里有旁瓣/为什么峰值偏了」， 而解释里的关键词是截断、延拓、加窗， 那说明你用的变换与信号类型不匹配 —— 这不是信号的属性，是工具的属性 ✓

    import numpy as np

x = np.array([1.0, 2.0, 3.0, 2.0, 1.0, 0.5, 0.25, 0.125])
N = x.size
n = np.arange(N)

print("同一段 %d 点数据，四种描述方式各自给出什么：" % N)
print()
X = np.fft.fft(x)
print("1) 当成周期序列 -> DFT")
print("   输出：%d 个复数（离散谱线），频率间隔 = 1/%d = %.4f 周/样点"
      % (N, N, 1.0 / N))
print("   |X[k]| 前 5 个:", np.abs(X[:5]).round(4))
print()
M = 64
w = 2 * np.pi * np.arange(M) / M
Xw = np.array([np.sum(x * np.exp(-1j * wi * n)) for wi in w])
print("2) 当成非周期有限序列 -> DTFT")
print("   输出：一条连续曲线，画图时要自己选 %d 个频点" % M)
print("   |X(Omega)| 前 5 个:", np.abs(Xw[:5]).round(4))
print("   它满足 |X(Omega)| = |X(Omega + 2*pi)|，即谱是周期的")
print()
print("3) 用 Z 变换：输出是整个复平面上的函数 X(z) = 1 + 2z^-1 + 3z^-2 + ...")
print("   在 z = 1（即 Omega = 0）处：X(1) = %.6f" % float(Xw[0].real))
print()
Xp = np.fft.fft(x, 64)
print("4) 同一段数据补零到 64 点再做 DFT（频率网格更细）")
print("   输出：64 个复数，频率间隔 = 1/64 = %.4f 周/样点" % (1.0 / 64))
print("   |Xp[k]| 前 5 个:", np.abs(Xp[:5]).round(4))

   在 z = 1（即 Omega = 0）处：X(1) = 9.875000

   输出：64 个复数，频率间隔 = 1/64 = 0.0156 周/样点

    输出怎么读：四种描述里，数据一个数都没改，变的只有「当成什么」。

    • 第 1 种（DFT）：输出 8 个复数，也就是 8 根谱线，频率间隔是 \(1/8 = 0.1250\) 周每样点。
    • 第 2 种（DTFT）：输出的是连续频率上的函数，代码里用 64 个频点去近似画它。 注意它的前 5 个数值 \(9.8750,\ 9.7666,\ 9.4494,\ 8.9466,\ 8.2946\) 是平滑下降的， 根本没有「8 根谱线」那种离散结构。
    • 第 3 种（Z 变换）：输出是复平面上的函数。只有把 \(z\) 限制在单位圆上， 它才和 DTFT 重合 —— 代码里 \(X(1) = 9.875000\) 正好等于第 2 种在 \(\Omega = 0\) 处的值。
    • 第 4 种（补零后的 DFT）：输出 64 个复数，看上去「更密」了， 但它的前 5 个数值与第 2 种完全一样 —— 因为补零没有增加任何新信息，只是把同一条连续曲线取了更多个点 ✓

    最后一条极其重要，它顺便解释了第 4 节会反复用到的两句话： 补零加密的是频率网格，不是分辨率；频谱上「多出来的点」只是采样更密而已。

    2.2 六个变换之间的三层关系¶

    六个变换看着零散，实际上它们被三层关系串在一起。

    第一层：连续与离散互为镜像。

    连续时间 对应的离散时间版本 差别在哪
    FS（周期信号 → 离散线谱） DFS / DFT（周期序列 → 离散谱） 一个是对连续时间积分，一个是对序号求和
    FT（非周期信号 → 连续谱） DTFT（非周期序列 → 连续周期谱） 离散化让谱周期化了 ✓

    第二层：复变量是「统一版本」。

    变换 推广成复变量之后 限制回虚轴或单位圆之后
    FT 拉普拉斯变换 \(X(s)\) 取 \(s = j\omega\) 得 \(X(j\omega) = \text{FT}\) ✓
    DTFT Z 变换 \(X(z)\) 取 \(z = e^{j\Omega}\) 得 \(X(e^{j\Omega}) = \text{DTFT}\) ✓

    这两行说明了一件重要的事： 拉普拉斯变换与 Z 变换之所以存在，不是为了多一个工具， 而是为了把 FT 与 DTFT 存在性的边界放宽。 FT 要求绝对可积，而 \(\int |e^{-at}\cos\omega_0 t|\,dt\) 在 \(a \le 0\) 时发散； 乘上衰减因子 \(e^{-\sigma t}\) 之后，只要 \(\sigma\) 取得足够大就能收敛 —— 这就是拉普拉斯变换的来历，也是它的收敛域 ROC 的来历 ✓

    第三层：只有 DFT 两边都是离散的。

    变换 时域 频域 计算机能直接算吗
    FS 连续、周期 离散 否（时域要积分）
    FT 连续、非周期 连续 否
    DTFT 离散、非周期 连续 否（频域是连续的）⚠
    DFT 离散、周期 离散 能 ✓
    ZT 离散、非周期 离散或连续（复平面） 否（要取极限或留数）
    LT 连续、非周期 复平面 否

    这张表解释了 DFT 为什么是全课最常用的计算工具： 不是因为 DFT「更本质」，而是因为只有它的输入和输出都是有限个离散数， 计算机才能原样处理。 其它变换想上机，都必须先离散化， 而离散化的那一步，正是误差的来源。

    DFT 不是 DTFT 的替代品，而是它的采样

    这是本课程课件反复强调的一点，也是全页最容易混淆的地方。

    课件在讲 DFT 时明确说了三句话：DFT 是「离散周期序列」的变换； 物理上的「有限序列」或「离散非周期序列」适合用 DTFT 来分析； 对「有限序列」使用 DFT，必须注意它和 DTFT 的差别， 仔细检查结果的合理性，并对误差进行分析和处理。

    也就是说：这段数据的真谱是 DTFT，DFT 只是它的一种近似 —— 而且是「先周期延拓、再等间隔采样」双重操作之后的近似 ⚠

    本站 离散傅里叶变换与 FFT 里有完整的量化推导， 本页只强调一条使用结论：用 DFT 得到的结果，必须把「延拓」与「采样」这两步的代价算进去。

    3.2 两条对偶关系：整张表的钥匙¶

    这张表之所以能记住，是因为它只由两条规律生成。这两条规律必须反复强调：

    两条对偶关系

    关系一：时域周期性 ⟺ 频域离散。 时间上重复，频率上就被「筛」成一根根离散的谱线。

    关系二：时域离散 ⟺ 频域周期。 时间上只取整点，频率上就出现了周期性重复。

    两条关系是双向的，而且互相独立 —— 一条管「离散还是连续」，另一条管「周期还是非周期」。 四个变换，就是这两条规律的两两组合 ✓

    下面逐条把「为什么」讲透。

    关系一：为什么时域周期会让频域离散？

    设连续信号 \(x(t)\) 以 \(T\) 为周期。周期信号可以写成复指数之和

    \[x(t) = \sum_{k=-\infty}^{+\infty} c_k e^{j k \omega_0 t}, \qquad \omega_0 = \frac{2\pi}{T}\]

    这就是傅里叶级数。这里 \(T\) 是周期，单位是秒； \(\omega_0\) 是基频，单位是弧度每秒，取值范围是 \(\omega_0 \gt 0\)； \(k\) 是谐波序号，取遍所有整数；\(c_k\) 是第 \(k\) 次谐波的复幅度。

    这个式子怎么读：它右边是一个求和，而求和只可能给出离散的项。 每一项的频率都是 \(\omega_0\) 的整数倍，也就是 \(0,\ \pm\omega_0,\ \pm 2\omega_0,\ \dots\) 这些等间隔的点。 在这些点之间，\(x(t)\) 里干脆没有任何频率成分 —— 所以它的谱只在这些点上非零，这就是「离散谱」的字面含义 ✓

    反过来看也成立：如果频域只在等间隔的点上有值， 那么把这些复指数加起来，得到的一定是一个周期函数 （因为所有频率都是 \(\omega_0\) 的整数倍，公共周期是 \(T = 2\pi/\omega_0\)）。 这个「反过来」正是关系二的对称版本，也是后面 DFT 能成立的根本原因。

    关系二：为什么时域离散会让频域周期？

    设离散序列 \(x(n)\) 的 DTFT 是

    \[X(e^{j\Omega}) = \sum_{n=-\infty}^{+\infty} x(n) e^{-j\Omega n}\]

    这里 \(n\) 是整数序号（因为信号是离散的，时间只能取整数）， \(\Omega\) 是数字角频率，单位是弧度，取值范围只要看一个周期 \([-\pi, \pi]\) 就够了。

    现在把 \(\Omega\) 换成 \(\Omega + 2\pi\)，逐项看发生了什么：

    \[X(e^{j(\Omega + 2\pi)}) = \sum_{n=-\infty}^{+\infty} x(n) e^{-j(\Omega + 2\pi)n} = \sum_{n=-\infty}^{+\infty} x(n) e^{-j\Omega n} \underbrace{e^{-j 2\pi n}}_{=\,1} = X(e^{j\Omega})\]

    中间那一步用到了关键事实：\(n\) 是整数， 所以 \(e^{-j2\pi n} = \cos(2\pi n) - j\sin(2\pi n) = 1\) 恒成立。 把整个和式每一项都乘上 \(1\)，结果当然不变。

    于是得到结论：\(X(e^{j\Omega})\) 以 \(2\pi\) 为周期。 算式上只差一个 \(e^{-j2\pi n}\)，而它等于 \(1\)； 这个 \(1\) 之所以成立，完全依赖于 \(n\) 是整数 ⚠ 如果时间轴是连续的 \(t\)，\(e^{-j2\pi t}\) 一般不等于 \(1\)， 连续时间信号的谱就不会周期化 —— 这就是「离散 ⟺ 周期」的来历。

    3.3 两条关系合起来：DFT 为什么存在¶

    把两条关系同时用上，就得到本页最重要的一句推论。

    当信号同时满足「离散」和「周期」时：

    • 因为离散（关系二）→ 频域是周期的；
    • 因为周期（关系一）→ 频域是离散的；

    两条合起来：频域既离散又周期。

    而一个「既离散又周期」的东西，只需要 \(N\) 个数就能完整描述它 —— 一个周期里的那 \(N\) 个采样值。这就意味着： 时域存 \(N\) 个数，频域也存 \(N\) 个数，两边都是有限长的。 这就是 DFT 存在的原因，也是 DFT 能用计算机直接算的原因。

    信号的属性组合 频域是离散的吗 频域是周期的吗 频域需要多少个数描述
    连续 + 周期 → FS 是（关系一） 否 无穷多个（但可数）
    连续 + 非周期 → FT 否 否 需要一整条曲线
    离散 + 非周期 → DTFT 否 是（关系二） 需要一整条曲线（在一个周期内）
    离散 + 周期 → DFT 是 是 恰好 \(N\) 个 ✓

    最后一行是唯一「两边都有限」的情形。 这也解释了为什么工程上几乎所有频谱分析最终都落到 DFT 上： 不是因为它更准，而是因为它是唯一能在计算机上精确表示的一格。

    第三件被验证的事是幅度的下降规律。幅度依次是 \(0.640729,\ 0.224994,\ 0.150336,\ 0.127449\)，单调下降。 这里要小心一个常见的误读：不能简单说它「按 \(1/k\) 下降」。 验证方法很机械 —— 把幅度乘上 \(k\)，如果是严格的 \(1/k\)，乘积应当是个常数：

    \(k\) \(1\) \(3\) \(5\) \(7\)
    \(\lvert c_k\rvert\) \(0.640729\) \(0.224994\) \(0.150336\) \(0.127449\)
    \(\lvert c_k\rvert \times k\) \(0.640729\) \(0.674982\) \(0.751681\) \(0.892142\)

    乘积并不恒定，而是从 \(0.64\) 一路爬到 \(0.89\)。 所以它只是「接近」\(1/k\)，并不严格等于 \(1/k\) ⚠

    原因是：离散周期方波的谱是离散 sinc 形式（\(k\) 为奇数时）

    \[c_k = \frac{1}{N}\cdot\frac{\sin(\pi k / 2)}{\sin(\pi k / N)}\]

    只有当 \(N\) 很大、\(\pi k/N\) 很小时，\(\sin(\pi k/N)\) 才近似等于 \(\pi k/N\)， 上式才退化成连续时间情形的 \(1/k\) 形式。 \(N = 16\) 太小，这个近似不成立，所以偏离可见。

    这一条还有一个非常实用的后果： DSP 里说「最高频率是 \(\pi\)」时，指的不是「信号频率到了 \(\pi\) 弧度每秒」， 而是「到了周期的一半，再往上就开始重复了」。 \(2\pi\) 的周期性就是 Nyquist 频率 \(f_s/2\) 的那个「一半」的来历 ✓

    两条关系最容易被弄反的地方

    不要把两条关系交叉记错。正确对应是：

    时域 频域 别记成
    周期 离散 ✗ 不是「周期 → 周期」
    离散 周期 ✗ 不是「离散 → 离散」

    一个顺口的记法：「时间上省事，频率上就麻烦」 —— 时域越规整（周期、离散），频域就越规整（离散、周期）， 规整的两边刚好在 DFT 那一格汇合 ✓

    四、Dirichlet 条件：傅里叶级数什么时候收敛¶

    4.1 三条条件¶

    上一节说「周期信号可以展成傅里叶级数」，这句话里藏着一个前提： 不是所有周期信号都展得开。 本课程课件在给出傅里叶级数的同时，就附上了这个前提 —— Dirichlet 条件。

    一个周期为 \(T\) 的时间函数 \(x(t)\)，只要在一个周期内满足下面三条， 就可以展成正弦与余弦函数的代数和：

    序号 条件 数学写法 通俗含义 它排除掉什么
    1 在一个周期内绝对可积 \(\int_{T} \lvert x(t)\rvert\,dt \lt \infty\) 一个周期里的「总面积」有限 周期内有无穷大的尖峰（如 \(1/t\) 型奇点）
    2 在一个周期内极值点个数有限 极大值、极小值一共只有有限个 信号不会无限来回抖动 无限密集的振荡（如 \(\sin(1/t)\) 型）
    3 在一个周期内间断点个数有限 第一类间断点只有有限个 跳变只有有限处，且每处左右极限都存在 处处不连续的振荡函数

    三条里，第一条最重要，也最容易被忽略。 第二条和第三条是「技术性条件」，实际工程信号几乎不会违反； 而第一条是有实质内容的 —— 它决定了级数的系数积分会不会收敛。

    这里要特别说明一点：Dirichlet 条件里的「绝对可积」只要求在一个周期内积分， 不要求在整个时间轴上积分。 这正是周期信号与功率信号能展成级数、 而它们却不能直接做傅里叶变换的原因 ⚠ 区别不在信号本身，而在积分的区间长度： 一个周期是有限长度，积分当然可能收敛；整条时间轴是无限长度，就未必了。

    4.2 级数收敛到什么¶

    课件给出的结论是一句话，这句话要拆成两半来读：

    满足这些条件时，级数在连续点收敛于原函数，在间断点收敛于左右极限的平均值。

    点的类型 级数收敛到 与原函数的关系
    连续点 \(t_0\) \(x(t_0)\) 完全相等 ✓
    第一类间断点 \(t_0\) \(\dfrac{x(t_0^-) + x(t_0^+)}{2}\) 收敛到左右极限的平均值 ✓

    第二行是重点。设 \(x(t_0^-)\) 表示从左边趋近 \(t_0\) 时的极限， \(x(t_0^+)\) 表示从右边趋近时的极限（这里没写「\(t\) 趋于 \(t_0\)」是为了避免公式里出现裸的 \(<\) 号）。 如果信号在这里从 \(-1\) 跳到 \(+1\)，那么 \(x(t_0^-) = -1\)、\(x(t_0^+) = +1\)，级数在这一点收敛到 \((-1 + 1)/2 = 0\)。

    注意：\(0\) 既不是左极限 \(-1\)，也不是右极限 \(+1\)，更不是 \(x(t_0)\) 本身。 级数在间断点处收敛到的，是一个两头都不沾的中间值。 很多人在算完级数、去和原函数逐点比对时，就是在这里发现「怎么对不上」的 ✓

    课件另外补了两条更强的收敛性结论，它们说明「条件更好时，收敛也更好」：

    附加条件 收敛类型 直观含义
    \(x(t)\) 是连续可微的周期函数 一致收敛 部分和与原函数的最大偏差均匀地趋向 0
    \(x(t)\) 在周期 \(T\) 上平方可积 均方收敛 能量意义上的偏差趋向 0，个别点可以不管

    这两条的关系是：一致收敛最强（每一点都对得上）， 均方收敛最弱（只保证整体能量对得上，个别点可能仍然出错）。

    import numpy as np


def partial(t, K):
    """奇方波的部分和： sum_{k 为奇数, k <= 2K-1} (4/(k*pi)) sin(k t)"""
    s = np.zeros_like(np.asarray(t, dtype=float))
    for k in range(1, 2 * K, 2):
        s = s + (4.0 / (k * np.pi)) * np.sin(k * np.asarray(t, dtype=float))
    return s

print("在跳变点 t = 0 处：左极限 f(0-) = -1，右极限 f(0+) = +1，平均值 = 0")
print()
print("  项数 K      S(0)        S(pi/2)      max|S(t)|")
grid = np.linspace(1e-9, np.pi - 1e-9, 40001)
for K in (1, 3, 10, 100, 2000):
    s0 = float(partial([0.0], K)[0])
    sq = float(partial([np.pi / 2], K)[0])
    peak = float(np.max(np.abs(partial(grid, K))))
    print("  %6d   %+10.6f   %+10.6f   %10.6f" % (K, s0, sq, peak))

    4.4 三条容易搞错的边界¶

    收尾时提醒三件事，它们都属于「等于号归哪边」这类细节：

    容易搞错的点 正确说法
    「Dirichlet 条件保证了级数逐点等于原函数」 只在连续点成立；间断点收敛到左右极限的平均值 ⚠
    「绝对可积要求全时间轴积分有限」 级数只要求一个周期内绝对可积；全轴绝对可积是 FT 的要求 ⚠
    「项数加多了，Gibbs 过冲会消失」 过冲的宽度会变窄，但相对幅度稳定在约 17.9% 不变 ⚠

    有间断点时，不要用「逐点比较」来验收级数

    如果你写完级数后想验证它对不对，千万不要在间断点附近逐点比对。

    正确的验收方法是：

    该在哪验证 该看什么 不该看什么
    远离间断点的连续处 部分和是否贴近原函数 ✓ ——
    间断点本身 是否收敛到左右极限的平均值 ✓ 是否等于原函数 ⚠
    间断点的小邻域 过冲幅度是否稳定（Gibbs）✓ 过冲是否会随项数消失 ⚠

    还有一个更隐蔽的陷阱：如果原信号本身有跳变，而你的模型假设它连续， 那么误差不会平均分布，而是全部集中在跳变附近。 做频谱分析时看到的那些「莫名其妙的旁瓣」，很多时候就是这么来的 ✓

    泄漏指标为 0 是特例，不是常态

    真实数据几乎永远不会这么巧。也就是说：

    情形 泄漏指标 你以为 实际上
    频率恰为 \(k/N\) 接近 \(0\) 算法好 只是运气好，截断位置恰好 ✓
    任意真实频率 明显大于 \(0\) 信号有问题 是截断这一步的固有代价 ⚠

    所以看到频谱「糊」的时候，第一反应应该是 检查截断长度与信号的周期关系，而不是去怀疑采集设备 ✓

    5.3 Z 变换的限制：必须同时给出收敛域¶

    这是本页要求重点交代的第二件事，也是六个变换里最容易在考试和工程里出错的一条。

    先用代码把问题的严重程度摆出来。考虑两个序列：

    \[x_1(n) = a^n u(n) \quad (\text{右边序列}), \qquad x_2(n) = -a^n u(-n-1) \quad (\text{左边序列})\]

    这里 \(a\) 是一个实数（取 \(0 \lt a \lt 1\)），\(u(n)\) 是单位阶跃序列 （\(n \ge 0\) 时取 \(1\)，\(n \lt 0\) 时取 \(0\)）。 第一个序列从 \(n = 0\) 向右延伸，叫右边序列； 第二个序列从 \(n = -1\) 向左延伸，叫左边序列。

    这两个序列在时域上完全是两回事（一个朝右、一个朝左）， 但把它们代进 Z 变换的定义 \(X(z) = \sum_{n} x(n) z^{-n}\) 之后， 代数化简会给出完全相同的表达式：

    \[X_1(z) = X_2(z) = \frac{1}{1 - a z^{-1}}\]

    代码的任务就是验证这个「数学上确实相同」的事实， 同时说明为什么它不构成矛盾：

  ROC 取 |z| > 0.50   ->  逆变换是右边序列 x1(n) = 0.50^n u(n)

    输出怎么读：这张表是「ROC 为什么不能省」的最直接证据。

    • 当 \(z = 0.25\) 时，\(\lvert z\rvert = 0.25 \lt a = 0.5\)： \(x_1\) 的级数发散（数值达到 \(1.607\times10^{60}\)，已经爆掉）， 而 \(x_2\) 的级数收敛到 \(-1.000000\)。
    • 当 \(z = 0.8\) 和 \(z = 2.0\) 时，\(\lvert z\rvert \gt a\)： 反过来，\(x_1\) 收敛（分别收敛到 \(2.666667\) 与 \(1.333333\)）， 而 \(x_2\) 的级数发散。

    关键在于：在同一个 \(z\) 上，两个级数必然一个收敛一个发散。 所以「这个级数在这一点的值是多少」这个问题， 不加上「是哪一个序列的级数」就没有答案。

    于是结论非常明确：

    给出的信息 逆变换的结果 是否唯一
    只给 \(X(z) = 1/(1 - 0.5z^{-1})\) 无法确定 ✗ 不唯一 ⚠
    \(X(z)\) + ROC \(\lvert z\rvert \gt 0.5\) 右边序列 \(0.5^n u(n)\) ✓ 唯一
    \(X(z)\) + ROC \(\lvert z\rvert \lt 0.5\) 左边序列 \(-0.5^n u(-n-1)\) ✓ 唯一

    这就是「Z 变换必须同时给出 ROC」的全部含义： 不是书写规范的问题，而是「少了这句话，问题就有两个答案」。

    正弦 \(\cos(\omega_0 t)\) 否 ⚠ 否 ⚠ 用自相关 + 功率谱描述 ✓
    直流 \(1\) 否 ⚠ 否 ⚠ 同上，功率谱是 \(\omega = 0\) 处的一根线
    周期方波 否 ⚠ 否 ⚠ 用 FS（一个周期内绝对可积）✓

    这张表最后两行给出一条很有用的判断线索： 周期信号改用 FS，随机/持续信号改用功率谱，只有能量有限的单次信号才用 FT。

    「绝对不可积」不是放弃，而是换工具

    很多人在发现正弦不满足绝对可积之后，会得出「那么正弦信号就没法做频域分析了」的结论 —— 这是过度悲观。

    正确的认识是：同一类信号换了工具。

    信号的描述 用的工具 结果长什么样
    确定性、周期 FS 离散线谱，每根线有确定的复幅度 \(c_k\) ✓
    确定性、非周期、能量有限 FT 连续谱密度 \(X(\omega)\) ✓
    持续存在、能量无限 自相关函数 + 功率谱 功率谱在频率上如何分布 ✓

    第三行正是本课程下一部分（随机过程与功率谱）要做的事， 也是为什么功率谱 \(\lvert X(\omega)\rvert^2\) 这个量比 \(X(\omega)\) 本身更常用： 即使用截断的数据去算，功率谱的量级也是稳定的，不会随截断长度无限增长 ✓

    def recommend(domain, periodic, kind, finite=None):
    """按信号属性推荐变换，并指出要小心的地方。

    domain  : 'continuous' 连续时间 / 'discrete' 离散时间
    periodic: True 周期 / False 非周期
    kind    : 'energy' 能量信号 / 'power' 功率信号
    finite  : 只对「离散 + 非周期」有意义，'finite' 或 'infinite'
    """
    notes = []
    if domain == "continuous":
        if periodic:
            name = "FS（傅里叶级数）"
            notes.append("输出是等间距的离散谱线，只在基频整数倍上取值")
            notes.append("周期信号必是功率信号，不要拿 FT 硬套")
        else:
            name = "FT（傅里叶变换）"
            if kind == "power":
                notes.append("功率信号不满足绝对可积，严格来说 FT 不存在")
            else:
                notes.append("能量信号 + 绝对可积，FT 存在且连续")
    else:
        if periodic:
            name = "DFT / DFS（N 点离散傅里叶变换）"
            notes.append("时域周期、频域离散，两边都离散，DFT 才严格成立")
        elif finite == "infinite":
            name = "DTFT"
            notes.append("需要绝对可和；换成复变量 z 就是 Z 变换")
            notes.append("谱是连续的，且以 2*pi 为周期")
        else:
            name = "DTFT（理论正解）+ DFT（工程近似）"
            notes.append("DFT 隐含把数据周期延拓，会带来泄漏与栅栏效应")
            notes.append("补零只能加密频率网格，不能提高真正的分辨率")
    return name, notes

def alias_freq(f0, fs):
    """连续频率 f0 以 fs 采样后，在 [0, fs/2] 里能观测到的等效频率"""
    f = f0 % fs
    return min(f, fs - f)

    题目：序列 \(x(0) = 2\)、\(x(1) = 1\)、\(x(2) = 0\)、\(x(3) = -1\)，其余为零。 求它的 4 点 DFT，并说明这个结果满足什么对称性质。

    思路

    直接按定义式 \(X[k] = \sum_{n=0}^{N-1} x(n)e^{-j2\pi kn/N}\)， 对 \(k = 0, 1, 2, 3\) 各算一遍。 指数项 \(e^{-j2\pi kn/4}\) 只取四个值：\(1, -j, -1, +j\)， 手算完全可行。

    解答

    第一步：写出 \(N = 4\) 时的四个旋转因子。

    \[e^{-j2\pi k n/4} = (e^{-j\pi/2})^{kn} = (-j)^{kn}\]

    所以四个因子分别是 \((-j)^0 = 1\)，\((-j)^1 = -j\)， \((-j)^2 = -1\)，\((-j)^3 = +j\)。

    第二步：\(k = 0\)。

    \[X[0] = 2 + 1 + 0 + (-1) = 2\]

    \(X[0]\) 就是所有样点之和，也叫直流分量。验证：\(2 + 1 + 0 - 1 = 2\) ✓

    第三步：\(k = 1\)。 因子依次是 \(1, -j, -1, +j\)：

    \[X[1] = 2\cdot1 + 1\cdot(-j) + 0\cdot(-1) + (-1)\cdot(+j) = 2 - j - j = 2 - 2j\]

    注意 \((0)\cdot(-1) = 0\)，这一项直接消失； 而 \((-1)\cdot(+j) = -j\)，与 \(1 \cdot (-j) = -j\) 同向相加， 所以虚部是 \(-2j\) 而不是 \(-j\) ⚠

    第四步：\(k = 2\)。 因子依次是 \(1, -1, 1, -1\)：

    \[X[2] = 2\cdot1 + 1\cdot(-1) + 0\cdot1 + (-1)\cdot(-1) = 2 - 1 + 0 + 1 = 2\]

    第五步：\(k = 3\)。 因子依次是 \(1, +j, -1, -j\)：

    \[X[3] = 2\cdot1 + 1\cdot(+j) + 0 + (-1)\cdot(-j) = 2 + j + j = 2 + 2j\]

    例题 3：由极点位置判断离散系统的稳定性¶

    题目：某离散系统的系统函数是

    \[H(z) = \frac{1}{1 - 0.5z^{-1}}, \qquad \text{ROC}: \lvert z\rvert \gt 0.5\]

    判断这个系统是否因果、是否 BIBO 稳定，并写出它的脉冲响应与频率响应。

    思路

    三步走：先找极点，再看极点与单位圆的相对位置， 最后由 ROC 的形式判断序列是左边还是右边。 判据只有一条：单位圆是否落在 ROC 内。

    解答

    第一步：找极点。

    分母 \(1 - 0.5z^{-1} = 0\)，两边乘 \(z\) 得 \(z - 0.5 = 0\)， 所以极点是 \(z = 0.5\)，极点模 \(\lvert z\rvert = 0.5\)。

    第二步：比较极点模与 1。

    极点模 \(0.5 \lt 1\)，也就是说极点在单位圆内部。

    而 ROC 给的是 \(\lvert z\rvert \gt 0.5\)， 这是「最外极点之外的区域」。 既然最外极点的模是 \(0.5 \lt 1\)， 那么 \(\lvert z\rvert \gt 0.5\) 这个区域包含了整个单位圆 ✓

    第三步：判稳定性。

    BIBO 稳定的充要条件是脉冲响应绝对可和， 而绝对可和等价于「单位圆落在 ROC 内」。 本例中单位圆整体落在 ROC 内，所以系统稳定 ✓

    第四步：判因果性。

    ROC 形如 \(\lvert z\rvert \gt r\)（最外极点之外）时， 对应的序列一定是右边序列。 这里 ROC 就是 \(\lvert z\rvert \gt 0.5\)，所以是右边序列， 即 \(h(n) = 0\) 对 \(n \lt 0\) 成立 —— 系统因果 ✓

    第五步：写出脉冲响应。

    \[\frac{1}{1 - az^{-1}} = \sum_{n=0}^{\infty} a^n z^{-n} \;\Longrightarrow\; h(n) = 0.5^n u(n)\]

    其中 \(u(n)\) 是单位阶跃序列。 验证绝对可和：\(\sum_{n=0}^{\infty}0.5^n = \dfrac{1}{1-0.5} = 2\)， 有限，确实绝对可和 ✓

    第六步：用单位圆上的取值写出频率响应。

    \[H(e^{j\Omega}) = \frac{1}{1 - 0.5e^{-j\Omega}}\]

    在几个频率上取值：

    \(\Omega/\pi\) \(\lvert H(\Omega)\rvert\) 说明
    \(0.00\) \(2.000000\) 最大值，直流增益是 2
    \(0.25\) \(1.357197\) 衰减中
    \(0.50\) \(0.894427\) 已低于 1

    例题 4：采样率选错会看到什么频率¶

    题目：某信号里有一个 \(40\) Hz 的成分，采样率选成 \(50\) Hz。 （a）采样后能观测到的等效频率是多少？ （b）要正确记录 \(40\) Hz，采样率至少要多少？ （c）用 DFT 验证（a）的结论。

    思路

    Nyquist 频率是 \(f_s/2\)（这里 \(25\) Hz），\(40\) Hz 已经超过它。 折叠的公式是「先对 \(f_s\) 取余，再折到 \([0, f_s/2]\)」。 验证时用 DFT 找峰值谱线，再换算回频率。

    解答

    第一步：算 Nyquist 频率。

    \[f_{\text{Nyquist}} = \frac{f_s}{2} = \frac{50}{2} = 25 \text{ Hz}\]

    第二步：判断会不会折叠。 信号频率 \(40\) Hz 关于 \(25\) Hz 的比较结果是「大于」， 所以会被折叠 ⚠

    第三步：算折叠后的等效频率。

    规则是：先把 \(f_0\) 对 \(f_s\) 取余，再把结果折到 \([0, f_s/2]\) 内：

    \[f_0 \bmod f_s = 40 \bmod 50 = 40, \qquad \min(40,\ 50-40) = 10 \text{ Hz}\]

    所以采样后能观测到的是 \(10\) Hz，不是 \(40\) Hz ✓

    第四步：算正确记录所需的采样率。

    采样定理要求 \(f_s \gt 2f_0 = 80\) Hz。 所以 \(f_s\) 至少要大于 \(80\) Hz， 取 \(f_s = 100\) Hz 时相对稳妥（留了余量给抗混叠滤波器的过渡带）✓

    第五步：用 DFT 验证。

    取 \(M = 500\) 个样点，频率分辨率是

    \[\frac{f_s}{M} = \frac{50}{500} = 0.1 \text{ Hz}\]

    DFT 的峰值落在第 \(100\) 根谱线上，换算成频率：

    \[100 \times 0.1 = 10.0 \text{ Hz}\]

    与第三步手算的 \(10\) Hz 完全一致 ✓

    第六步：把三种采样率放在一起对比。

    采样率 Nyquist DFT 峰值频率 结果
    \(50\) Hz \(25\) Hz \(10.0000\) Hz 错，被折叠了 ⚠
    \(80\) Hz \(40\) Hz \(40.0000\) Hz 正确 ✓
    \(100\) Hz \(50\) Hz \(40.0000\) Hz 正确 ✓

    注意 \(80\) Hz 这一行：\(f_s = 80\) 时 \(f_0 = 40\) 恰好等于 \(f_s/2\)， 刚好是临界情形。理论上临界点上采样定理要求 \(f_s \gt 2f_0\)（严格大于）， 所以 \(80\) Hz 是边界，工程上不会取它，而会往上留余量 ✓

    Q1 一段 \(N = 200\) 点的实测数据，采样率是 \(f_s\)。 （a）它的频率分辨率是多少？ （b）把它补零到 \(800\) 点再做 DFT，分辨率提高了吗？ （c）如果要分辨两个相隔只有分辨率一半频率的谱峰，补零有用吗？

    提示

    分清两个词：频率网格间隔（补零能改变） 与频率分辨率（由观测时长决定，补零改变不了）。

    解答

    （a）频率分辨率。

    \[\Delta f = \frac{f_s}{N}\]

    以归一化频率（周/样点）表示，就是 \(1/N = 1/200 = 0.0050\) 周/样点 ✓

    （b）补零到 \(800\) 点。

    频率网格间隔变成 \(1/800 = 0.00125\) 周/样点， 比原来细了 4 倍。但这是网格变密，不是分辨率提高 ⚠

    原因：补零只是在数据尾部接上一串零， 它不改变 DTFT 曲线本身（DTFT 只由那 \(N\) 个真实样点决定）， 只是在同一条曲线上取了更多点。 曲线的「宽度」没有变化，两个靠得近的谱峰依然糊在一起 ✓

    （c）分辨相隔半个分辨率的两个谱峰。

    补零没有用。 真正能分辨的最小间隔由观测时长决定：

    \[\Delta f_{\min} = \frac{f_s}{N} = \frac{1}{N T_s}\]

    这个量正比于 \(\dfrac{1}{N T_s}\)，也就是观测的总时长。 两个相隔 \(0.5\Delta f\) 的谱峰，在一个观测窗内本来就不足以分开， 补零只是把这条糊在一起的曲线画得更细 ⚠

    要真正分开它们，只有三条路：

    办法 原理 代价
    增加观测点数 \(N\)（时长不变则须提高 \(f_s\)） 直接减小 \(\Delta f\) 数据量变大
    延长观测时长 减小 \(\Delta f\) 需要更长的记录
    用高分辨率谱估计方法 用先验假设突破窗口限制 有模型风险

    你不知道 DTFT 时 你知道 DTFT 后

    看到峰值频率比真实值偏了一格 知道那是栅栏效应，可以补零缓解 ✓

    以为「FFT 谱」是信号的谱 知道它只是真谱（DTFT）的采样 ✓

    量 是什么 上机能算吗
    DTFT 离散非周期序列的真谱，连续函数 不能直接算 ✓
    DFT DTFT 在 \(N\) 个等间隔点上的采样 能算 ✓
    FFT 计算 DFT 的快速算法 能算，且快 ✓

    一句话结论： 「只用 DFT」在操作上没有问题，「不了解 DTFT」在判断上会出问题。 DFT 给你数字，DTFT 给你解释这些数字为什么长这样 ✓

    Q4 有人给出一个 \(X(z) = \dfrac{1}{1 - 0.5z^{-1}}\)，说「它的逆变换是 \(0.5^n u(n)\)」。 （a）这个说法缺了什么？ （b）缺了它会出什么问题？ （c）补上之后，怎么判系统稳定？

    提示

    想 5.3 节那两个序列：一个右边、一个左边，代数表达式完全相同。 再想 5.4 节：稳定性和 DTFT 存在与否，看的都是同一件事。

    解答

    （a）缺了收敛域 ROC。

    完整的写法应该是

    \[X(z) = \frac{1}{1 - 0.5z^{-1}}, \qquad \text{ROC}: \lvert z\rvert \gt 0.5\]

    （b）缺 ROC 会出什么问题。

    会得到两个都正确、但完全不同的答案 ⚠

    给出的 ROC 逆变换 序列类型
    \(\lvert z\rvert \gt 0.5\) \(0.5^n u(n)\) 右边序列（从 \(n=0\) 向右延伸）✓
    \(\lvert z\rvert \lt 0.5\) \(-0.5^n u(-n-1)\) 左边序列（从 \(n=-1\) 向左延伸）✓

    两个序列在时域上一个朝右、一个朝左， 是完全不同的信号；但它们的 Z 变换代数化简后一模一样。

    所以「缺了 ROC」不是书写不规范，而是答案不唯一： 你给出的那句话，可以被读成两种意思 ✓

    （c）怎么判稳定性。

    判据只有一条：看单位圆 \(\lvert z\rvert = 1\) 是否落在 ROC 内。

    ROC 单位圆在 ROC 内吗 系统稳定吗
    \(\lvert z\rvert \gt 0.5\) 是（\(1 \gt 0.5\)）✓ 稳定 ✓
    \(\lvert z\rvert \lt 0.5\) 否（\(1 \lt 0.5\) 不成立）✗ 不稳定 ⚠

    注意：同一个 \(X(z)\)，只因为 ROC 不同，一个稳定、一个不稳定。 这就是为什么判稳定性时不能只看 \(X(z)\) 的表达式， 必须同时看极点的位置和 ROC 的形式 ✓

    判据的由来：BIBO 稳定要求脉冲响应绝对可和， 而绝对可和正是「单位圆落在 ROC 内」的含义。 所以「单位圆在 ROC 内」这一个几何条件， 同时等价于「稳定」与「DTFT 存在」✓

    import numpy as np

a = 0.5
M = 200


def fmt(v):
    return "%.3e" % v if abs(v) > 1e6 else "%+.6f" % v


n = np.arange(M)
m = np.arange(1, M + 1)

print("两个不同的序列，代数化简后得到完全相同的 X(z)：")
print("  右边序列 x1(n) =  a^n u(n)      ->  X1(z) = 1 / (1 - a z^-1)")
print("  左边序列 x2(n) = -a^n u(-n-1)   ->  X2(z) = 1 / (1 - a z^-1)")
print("  取 a = %.4f" % a)
print()
print("把两个级数分别在几个 z 上求和（各取前 %d 项）：" % M)
print()
print("    z     |z|      sum a^n z^-n      sum -a^n z^-n       谁收敛")
for z in (0.25, 0.8, 2.0):
    s1 = np.sum((a / z) ** n)
    s2 = -np.sum((z / a) ** m)
    who = "x1 收敛 / x2 发散" if abs(z) > a else "x1 发散 / x2 收敛"
    print("  %5.2f   %5.2f   %18s   %18s   %s"
          % (z, abs(z), fmt(s1), fmt(s2), who))
print()
print("同一个 z 上，两个级数必然一个收敛、一个发散。")
print()
print("所以要由 X(z) 反求 x(n)，必须同时给出收敛域 ROC：")
print("  ROC 取 |z| > %.2f   ->  逆变换是右边序列 x1(n) = %.2f^n u(n)" % (a, a))
print("  ROC 取 |z| < %.2f   ->  逆变换是左边序列 x2(n) = -%.2f^n u(-n-1)" % (a, a))
print()

    小结¶

    要记住的 为什么
    时域周期性 ⟺ 频域离散 周期信号的所有频率都是基频整数倍，中间没有成分 ✓
    时域离散 ⟺ 频域周期 \(e^{-j2\pi n}\) 因 \(n\) 为整数而恒等于 1 ✓
    两条关系合起来 → DFT 只有「离散 + 周期」这一格两边都离散，计算机才能精确表示 ✓
    信号属性四问：连续/离散、周期/非周期、能量/功率、有限长/无限长 属性定下来，变换就唯一确定了 ✓
    FS 用于连续周期信号 周期给出离散线谱，功率性质对应「一个周期内可积」✓
    FT 要求全轴绝对可积 功率信号（正弦、直流）严格来说不满足，要用功率谱描述 ⚠
    DTFT 是离散序列的真谱 它是连续函数，计算机存不下，只能取样 ✓
    DFT 是 DTFT 的采样 采样必然丢信息，泄漏与栅栏效应由此而来 ⚠
    Z 变换必须同时给出 ROC 同一个 \(X(z)\) 配不同 ROC 会给出两个完全不同的序列 ⚠
    单位圆在 ROC 内 ⟺ 稳定 ⟺ DTFT 存在 绝对可和、稳定、单位圆落在 ROC 内，三者是同一件事 ✓
    DTFT 是真相，DFT 是抽样，FFT 是算法 三者不是三个变换，是一件事的三个层次 ✓
    补零只加密频率网格，不提高分辨率 分辨率由观测时长决定，补零不增加任何新信息 ⚠
    泄漏来自截断，不来自信号 截整周期可完全消除；加窗可压制旁瓣 ✓
    Gibbs 过冲约 17.9%，加项数压不下去 这是间断点附近的必然现象，只能靠加窗或平滑缓解 ⚠
    混叠是多对一映射，事后无法恢复 只能靠采样前抗混叠滤波预防 ⚠
    傅里叶级数在间断点收敛到左右极限的平均值 不是 \(x(t_0)\)，也不是任何单侧极限 ✓
