    这一页解决什么问题：手上这段信号，到底该用哪一个变换。

    本站的「数学基础」层已经把这些变换各自的定义、性质、常用变换对分别讲透了：

    • 傅里叶级数与变换
    • 离散傅里叶变换与 FFT
    • Z 变换与滤波器
    • 拉普拉斯变换
    • 采样定理与混叠
    • 卷积

    所以本页不重复任何一条定义，只回答「什么时候用哪个」这个问题。

    这个问题不是凭兴趣挑出来的。本课程课件在回顾这一组内容时， 明确说出了三个基本关注点：变换的基本性质、适应范围、应用方法与限制。 「适应范围」与「限制」这两条，就是这一页的全部任务。

    先看三个「看着差不多、实际差很远」的情形，它们代表了本页要防住的三类错误：

    看起来差不多的做法 实际差别 后果
    手上只有一段有限长的采样数据，却说「这段数据的频谱是……」 有限长序列做 DFT 隐含了周期延拓假设，只有 DTFT 才是它的真谱 泄漏和栅栏效应被误当成信号自身的性质 ⚠
    拿着正弦信号去算傅里叶变换积分 正弦是功率信号，不满足绝对可积 积分不收敛，严格来说 FT 根本不存在 ⚠
    由 \(X(z)\) 的表达式直接反求 \(x(n)\) 表达式相同时，收敛域不同会给出两个不同的序列 逆变换不唯一，时域结果整体反了 ⚠

    这一页的主线

    先判信号的四个属性 —— 连续还是离散、周期还是非周期、 能量还是功率、有限长还是无限长 —— 再由属性查表选出变换。

    整张族谱可以用两条对偶关系推出来：

    时域周期性 ⟺ 频域离散；时域离散 ⟺ 频域周期。

    把这两条记住，后面所有表格都不用背。

    一、为什么需要这么多变换¶

    1.1 变换不同，是因为处理的信号类型不同¶

    一个刚学完信号与系统的人，最常见的困惑是： 「这几个变换看起来都在做同一件事 —— 把时间上的东西换到频率上看，为什么要有六个？」

    原因只有一条：它们面对的信号不是同一类信号。 而信号的类别，由四个属性决定。这四个属性里， 前两个决定「谱长什么样」，后两个决定「这个变换到底存不存在」：

    信号属性 两种取值 它决定了什么
    时间轴 连续 / 离散 频域是否周期（时域离散则频域周期）✓
    时间上的重复性 周期 / 非周期 频域是否离散（时域周期则频域离散线谱）✓
    能量 能量信号 / 功率信号 积分或求和是否收敛，即变换是否存在
    记录长度 有限长 / 无限长 能不能直接把数据丢进计算机算（DFT）

    这四个属性相互独立，所以组合起来远不止六种。 但真正实用的组合只有六到七种，而每一种恰好被一个变换对上号。 下表把「信号 → 变换」的映射一次列清，这是本页的第一张速查表：

    手上信号的类型 典型例子 该用哪个变换 一句话理由
    连续、周期 正弦、方波、周期脉冲串 FS（傅里叶级数） 周期信号的谱是离散线谱，级数刚好给出这些线
    连续、非周期、能量 单脉冲、衰减振荡 FT（傅里叶变换） 非周期对应连续谱，能量有限保证积分收敛
    连续、非周期、功率 直流、理想化的正弦延长 自相关 + 功率谱，而不是 FT 本身 功率信号不满足绝对可积，FT 严格不存在 ⚠
    离散、周期 以 \(N\) 为周期的采样序列 DFS / DFT 时域周期加时域离散，频域两边都离散，计算机能算 ✓
    离散、非周期、无限长 一阶自回归序列 DTFT，或换成复变量用 Z 变换 谱连续且以 \(2\pi\) 为周期，计算机无法直接给出
    离散、非周期、有限长 一段实测数据 理论用 DTFT，工程用 DFT 近似 有限序列做 DFT，等于先把它周期延拓 ⚠
    描述线性系统的稳定性与频响 差分方程给出的系统 Z 变换（连续系统用拉普拉斯变换） 极点位置同时给出稳定性判据与频率响应

    这张表最值得记住的不是最后那一列，而是第二列与第三列的对应关系： 一旦你能说清手上的信号属于哪一行，变换就唯一确定了，不需要犹豫。

    关于「离散、非周期」那两行，还要补一句容易漏掉的话： 它们用的是同一个变换（DTFT），差别只在「能不能真的算出来」。 无限长的序列，DTFT 是一个无穷级数的极限， 只要它对每个 \(\Omega\) 都收敛，这条曲线就是严格存在的数学对象； 而有限长的实测数据，DTFT 更加简单 —— 求和只有 \(N\) 项，任何有限长序列的 DTFT 都一定存在 ✓ 这一点常被误解成「有限长序列没有真谱」，其实恰恰相反： 它的真谱存在、连续、唯一，只是计算机存不下一条连续的曲线。

    「有限长数据的真谱」到底是什么

    一句话：有限长序列的真谱是它的 DTFT，是一条连续的曲线。

    这条曲线的样子完全由那 \(N\) 个数决定。 它连续，意味着它有无穷多个取值 —— 这就是计算机不能「原样」处理它的唯一原因。

    所以工程上对有限长数据做的事，本质是换一种表示： 把「一条连续的曲线」换成「\(N\) 个等间隔的采样值」， 也就是 DFT。换表示一定会丢东西， 丢掉的正是「采样点之间的那部分曲线」

    用错变换最常见的两种方式

    第一种是拿 DFT 当 DTFT 用。 一段实测数据是有限长的非周期序列，它的真谱是 DTFT（连续曲线）。 你直接对它做 DFT，得到的是另一件事：先把数据首尾相接、 无限重复成一个周期序列，再算这个周期序列的谱。 真实的谱曲线因此被「采样 + 泄漏」双重扭曲

    第二种是拿 FT 去算功率信号。 正弦、方波、直流这些信号的绝对值积分是发散的， 傅里叶变换的定义式不收敛。工程上仍然说「正弦的频谱是一根谱线」， 这句话是约定说法，严格含义要用自相关函数与功率谱来描述

    真正稳定的只有一件事：只要是同一段数据、同一组 \(N\)， 换一种延拓假设，整张频谱就会跟着变。 变化的原因不是信号变了，而是截断长度变了、接缝的位置变了。 这一点在第四节还会以「泄漏」的名字再出现一次，那里会把它算成一张手算对照表。

    判断标准很简单

    如果你算完谱之后需要解释「为什么这里有旁瓣/为什么峰值偏了」， 而解释里的关键词是截断、延拓、加窗， 那说明你用的变换与信号类型不匹配 —— 这不是信号的属性，是工具的属性

    2.2 退化链一：拉普拉斯变换 ⟹ 傅里叶变换¶

    这是全页最要先讲清的一条，因为考试里最常问「为什么令 \(s = j\omega\) 就退化了」。

    第一步：写出拉普拉斯变换的定义式。

    \[X(s) = \int_{-\infty}^{+\infty} x(t) e^{-s t}\,dt\]

    第二步：把复变量 \(s\) 拆成实部与虚部。

    \[s = \sigma + j\omega\]

    这里 \(\sigma\) 是衰减因子（实部），\(\omega\) 是角频率（虚部）。

    第三步：把 \(s = \sigma + j\omega\) 代进定义式，拆开指数。

    \[X(\sigma + j\omega) = \int_{-\infty}^{+\infty} x(t) e^{-(\sigma + j\omega) t}\,dt = \int_{-\infty}^{+\infty} \left[ x(t) e^{-\sigma t} \right] e^{-j\omega t}\,dt\]

    为什么能这样拆：由指数律 \(e^{-(\sigma + j\omega)t} = e^{-\sigma t} \cdot e^{-j\omega t}\)， 把带 \(\sigma\) 的因子归到信号一边，带 \(\omega\) 的因子留在变换核一边 ✓

    第四步：读这个式子的含义。 它说明：

    \[X(\sigma + j\omega) = \text{FT}\left\{ x(t) e^{-\sigma t} \right\}\]

    也就是「拉普拉斯变换 = 先把信号乘上衰减因子 \(e^{-\sigma t}\)，再作傅里叶变换」。

    第五步：令 \(\sigma = 0\)，也就是让 \(s\) 落在虚轴上。

    \[s = j\omega \quad \Longrightarrow \quad e^{-\sigma t} = e^{0} = 1\]

    代回第三步的式子，衰减因子变回 \(1\)：

    \[X(j\omega) = \int_{-\infty}^{+\infty} x(t) \cdot 1 \cdot e^{-j\omega t}\,dt = \int_{-\infty}^{+\infty} x(t) e^{-j\omega t}\,dt = X(\omega)\]

    第六步：核对存在条件。 右边正是傅里叶变换的定义式， 所以结论是

    \[X(s)\Big|_{s = j\omega} = X(\omega)\]

    而且收敛条件也对得上：拉普拉斯变换的收敛域是 \(\Re(s) \gt \sigma_0\)， 取 \(s = j\omega\) 就是要求 \(\sigma_0 \lt 0\)，即虚轴落在收敛域内； 而傅里叶变换存在要求 \(\int \lvert x(t)\rvert\,dt\) 有限 —— 这两句话是同一件事

    这个结论说明什么：虚轴不是 s 平面上随便一条线， 它是「拉普拉斯变换退回傅里叶变换」的那条线。 所以判断「一个信号的傅里叶变换存不存在」，等价于判断 「s 平面的虚轴是不是落在收敛域里」。

    退化要求虚轴整个落在收敛域内，不是只要有一部分

    常见错误是「只要极点不在虚轴上，FT 就存在」。这句话不严谨。

    正确的判据是：收敛域必须包含整条虚轴。 例如某个信号对应的收敛域是 \(\Re(s) \gt 0\)， 它的极点确实不在虚轴上，但虚轴也不在收敛域内 —— 这时傅里叶变换仍然不存在

    还有一条更隐蔽的差别：拉普拉斯变换的收敛域里可以有极点以外的东西， 但傅里叶变换要求把 \(s\) 限制在虚轴上取值， 而虚轴是一条没有宽度的线，取值时不能沿 \(\sigma\) 方向偏移半分 ✓

    2.3 退化链二：Z 变换 ⟹ DTFT¶

    同样地，这一条也要一步步代进去。

    第一步：写出 Z 变换的定义式。

    \[X(z) = \sum_{n=-\infty}^{+\infty} x(n) z^{-n}\]

    第二步：把复变量 \(z\) 写成极坐标形式。

    \[z = r e^{j\Omega}\]

    这里 \(r = \lvert z\rvert\) 是模（到原点的距离），\(\Omega\) 是辐角（数字角频率）。

    第三步：把 \(z = r e^{j\Omega}\) 代进定义式。

    \[X(r e^{j\Omega}) = \sum_{n=-\infty}^{+\infty} x(n) \left( r e^{j\Omega} \right)^{-n} = \sum_{n=-\infty}^{+\infty} x(n) r^{-n} e^{-j\Omega n}\]

    为什么 \((r e^{j\Omega})^{-n} = r^{-n} e^{-j\Omega n}\)： 积的幂等于幂的积，\((ab)^{-n} = a^{-n} b^{-n}\)， 再对 \(e^{-j\Omega n}\) 用一次指数律即可 ✓

    第四步：把带 \(r\) 的因子归到信号一边。

    \[= \sum_{n=-\infty}^{+\infty} \left[ x(n) r^{-n} \right] e^{-j\Omega n}\]

    右边这个式子就是「序列 \(x(n) r^{-n}\) 的 DTFT」。

    第五步：令 \(r = 1\)，也就是让 \(z\) 落在单位圆上。

    \[r = 1 \quad \Longrightarrow \quad r^{-n} = 1\]

    代回第四步：

    \[X(r e^{j\Omega})\Big|_{r=1} = \sum_{n=-\infty}^{+\infty} x(n) \cdot 1 \cdot e^{-j\Omega n} = X(e^{j\Omega})\]

    第六步：核对存在条件。 因为 \(\lvert z\rvert = r = 1\)， \(\lvert z^{-n}\rvert = 1\)，所以级数的绝对收敛性完全由 \(x(n)\) 决定：

    \[\sum_{n=-\infty}^{+\infty} \lvert x(n)\rvert \lt \infty\]

    这正是 DTFT 的存在条件（序列绝对可和）

    这个结论说明什么：单位圆不是 z 平面上随便一个圆， 它是「Z 变换退回 DTFT」的那个圆。 所以「DTFT 存在吗」与「系统稳定吗」在数学上是同一个问题， 都是问「单位圆有没有落在收敛域里」。

    2.4 退化链三：连续 ⟹ 离散（采样之后的对应关系）¶

    前两条是「复变量退到虚轴」，这一条是「时间轴从连续变成离散」。

    第一步：设 \(x(t)\) 以 \(T_s\) 为采样周期被采样，得到序列。

    \[x(n) = x(n T_s)\]

    第二步：把连续频率与离散频率对应起来。 定义数字角频率

    \[\Omega = \omega T_s\]

    为什么这样定义：\(e^{j\omega t}\) 在采样点 \(t = n T_s\) 上的取值是

    \[e^{j\omega n T_s} = e^{j(\omega T_s) n} = e^{j\Omega n}\]

    也就是说，连续频率 \(\omega\) 与数字频率 \(\Omega\) 的区别， 只差一个采样周期 \(T_s\) 的线性换算

    第三步：看这个换算是多对一的。 因为

    \[\Omega + 2\pi = \omega T_s + 2\pi = (\omega + 2\pi/T_s) T_s\]

    所以连续频率 \(\omega\) 与 \(\omega + 2\pi/T_s = \omega + \omega_s\) 映射到同一个 \(\Omega\)。 换句话说，采样把连续频率轴折叠成了一段长度为 \(\omega_s\) 的区间， 再往外就重复了。

    这个结论说明什么：这就是混叠的来历 —— 不是算法算错了，而是「采样」这个动作本身把不同的连续频率压成了同一个数字频率。 要避免它，只能在采样之前把超过 \(\omega_s/2\) 的成分滤掉。

    2.5 退化链四：DTFT ⟹ DFT（频率取等间隔的点）¶

    第一步：设序列有限长：\(x(n)\) 只在 \(n = 0, 1, \dots, N-1\) 上非零。

    第二步：写出它的 DTFT。

    \[X(e^{j\Omega}) = \sum_{n=0}^{N-1} x(n) e^{-j\Omega n}\]

    第三步：只在这 \(N\) 个等间隔频率点上取值。

    \[\Omega_k = \frac{2\pi k}{N}, \qquad k = 0, 1, \dots, N-1\]

    第四步：把这个 \(\Omega_k\) 代进 DTFT。

    \[X(e^{j\Omega_k}) = \sum_{n=0}^{N-1} x(n) e^{-j (2\pi k/N) n} = \sum_{n=0}^{N-1} x(n) e^{-j 2\pi k n / N} = X[k]\]

    右边正是 DFT 的定义式 ✓

    这个结论说明什么：DFT 不是新造出来的变换， 它就是把 DTFT 在 \(N\) 个等间隔频率点上取样。 所以第三节会用数值逐点核对这件事 —— 如果 DFT 真算出别的东西， 那两列数字就不该逐行相等。

    顺便把反过来的那条链也写清，它同样常考：

    第一步：已知频域是有限个等间隔的点，\(X[k]\)，\(k = 0, \dots, N-1\)。 第二步：按对偶关系，时域一定是周期的，周期是 \(N\)。 第三步：写出这种情形下的时域表达式（这就是 DFT 的逆变换）：

    \[x(n) = \frac{1}{N}\sum_{k=0}^{N-1} X[k] e^{+j 2\pi k n / N}\]

    第四步：核对周期性。 把 \(n\) 换成 \(n + N\)：

    \[x(n + N) = \frac{1}{N}\sum_{k=0}^{N-1} X[k] e^{j 2\pi k (n+N) / N} = \frac{1}{N}\sum_{k=0}^{N-1} X[k] e^{j 2\pi k n / N} \underbrace{e^{j 2\pi k}}_{=\,1} = x(n)\]

    倒数第二步用到的还是同一个事实：\(k\) 是整数，所以 \(e^{j2\pi k} = 1\)

    这个结论说明什么：正变换与逆变换在结构上是完全对称的 —— 正变换用 \(-\) 号指数并求和，逆变换用 \(+\) 号指数并求平均。 「求和」与「求平均」的差别就是那个 \(1/N\)， 它的作用是保证「正变换之后再逆变换」能回到原序列 表里的四条退化链，其实都可以反向再走一遍， 这就是「对偶」二字的完整含义。

    四条退化链一句话串起来

    退化方向 关键代换 几何含义
    拉普拉斯 ⟹ 傅里叶 \(s = j\omega\)（相对 \(\sigma = j\omega\) 的实部） s 平面的虚轴
    Z 变换 ⟹ DTFT \(z = e^{j\Omega}\)（即 \(\lvert z\rvert = 1\)） z 平面的单位圆
    连续 ⟹ 离散 \(\Omega = \omega T_s\) 频率轴折叠成一段
    DTFT ⟹ DFT \(\Omega_k = 2\pi k/N\) 频率轴上取 \(N\) 个等间隔点

    四条链各自独立，合起来正好把六个变换串成一棵树： 拉普拉斯是傅里叶的推广，Z 变换是 DTFT 的推广， DFT 是 DTFT 的采样，而采样是连续到离散的那一步。

    2.8 六个变换之间的三层关系¶

    六个变换看着零散，实际上它们被三层关系串在一起。

    第一层：连续与离散互为镜像。

    连续时间 对应的离散时间版本 差别在哪
    FS（周期信号 → 离散线谱） DFS / DFT（周期序列 → 离散谱） 一个是对连续时间积分，一个是对序号求和
    FT（非周期信号 → 连续谱） DTFT（非周期序列 → 连续周期谱） 离散化让谱周期化了 ✓

    第二层：复变量是「统一版本」。

    变换 推广成复变量之后 限制回虚轴或单位圆之后
    FT 拉普拉斯变换 \(X(s)\) 取 \(s = j\omega\) 得 \(X(j\omega) = \text{FT}\) ✓
    DTFT Z 变换 \(X(z)\) 取 \(z = e^{j\Omega}\) 得 \(X(e^{j\Omega}) = \text{DTFT}\) ✓

    这两行说明了一件重要的事： 拉普拉斯变换与 Z 变换之所以存在，不是为了多一个工具， 而是为了把 FT 与 DTFT 存在性的边界放宽。 FT 要求绝对可积，而 \(\int \lvert e^{-at}\cos\omega_0 t\rvert\,dt\) 在 \(a \le 0\) 时发散； 乘上衰减因子 \(e^{-\sigma t}\) 之后，只要 \(\sigma\) 取得足够大就能收敛 —— 这就是拉普拉斯变换的来历，也是它的收敛域 ROC 的来历

    第三层：只有 DFT 两边都是离散的。

    变换 时域 频域 计算机能直接算吗
    FS 连续、周期 离散 否（时域要积分）
    FT 连续、非周期 连续 否
    DTFT 离散、非周期 连续 否（频域是连续的）⚠
    DFT 离散、周期 离散 能 ✓
    ZT 离散、非周期 离散或连续（复平面） 否（要取极限或留数）
    LT 连续、非周期 复平面 否

    这张表解释了 DFT 为什么是全课最常用的计算工具： 不是因为 DFT「更本质」，而是因为只有它的输入和输出都是有限个离散数， 计算机才能原样处理。 其它变换想上机，都必须先离散化， 而离散化的那一步，正是误差的来源。

    DFT 不是 DTFT 的替代品，而是它的采样

    这是本课程课件反复强调的一点，也是全页最容易混淆的地方。

    课件在讲 DFT 时明确说了三句话：DFT 是「离散周期序列」的变换； 物理上的「有限序列」或「离散非周期序列」适合用 DTFT 来分析； 对「有限序列」使用 DFT，必须注意它和 DTFT 的差别， 仔细检查结果的合理性，并对误差进行分析和处理。

    也就是说：这段数据的真谱是 DTFT，DFT 只是它的一种近似 —— 而且是「先周期延拓、再等间隔采样」双重操作之后的近似

    本站 离散傅里叶变换与 FFT 里有完整的量化推导， 本页只强调一条使用结论：用 DFT 得到的结果，必须把「延拓」与「采样」这两步的代价算进去。

    2.9 四个傅里叶类变换的对照：谁把信号「切」成什么¶

    上一节的图给出的是「适用对象」，这一节把四个傅里叶类变换的切法摆在一起， 因为考试里最爱问「这几个变换的差别到底在哪」。 它们的差别只有三处：切谁、按什么切、切出来是有限个还是无限个。

    变换 把函数按什么基展开 基函数是什么样 需要多少个基 系数怎么算
    FS 基频的整数倍谐波 \(e^{jk\omega_0 t}\)，周期为 \(T\) 可数无穷多个 \(k\) 一个周期上的积分 ✓
    FT 所有实频率 \(e^{j\omega t}\)，周期为 \(2\pi/\omega\) 连续统（不可数） 全轴上的积分 ⚠
    DTFT 所有数字频率 \(e^{j\Omega n}\)，以 \(2\pi\) 为周期 连续统，但只在一个周期内独立 无穷级数 ✓
    DFT \(N\) 个等间隔数字频率 \(e^{j2\pi kn/N}\) 恰好 \(N\) 个 ✓ 有限项求和 ✓

    这张表里最该看的是倒数第二列：

    • FS 只需要可数无穷多个基，因为时域是周期的；
    • FT 需要连续统那么多个基，因为时域是非周期的；
    • DTFT 的基虽然也是连续统，但它们两两之间是重复的（以 \(2\pi\) 为周期）， 所以真正独立的只有一段；
    • DFT 只需要 \(N\) 个基，因为它把「时域周期」和「时域离散」两条都占了

    再补一句关于正交性的话，它是所有傅里叶类展开能成立的共同基础：

    \[\int_{0}^{T} e^{jk\omega_0 t} \overline{e^{jm\omega_0 t}}\,dt = \int_{0}^{T} e^{j(k-m)\omega_0 t}\,dt = \begin{cases} T, & k = m \\ 0, & k \ne m \end{cases}\]

    这个积分结果说明：不同谐波在一个周期内「互相抵消」， 所以求某一个 \(c_k\) 时，把 \(x(t)\) 乘上 \(\overline{e^{jk\omega_0 t}}\) 再积分， 其它谐波的贡献全部变成 \(0\)，只剩下自己那一项 ✓ 离散情形完全一样，只是把积分换成求和、 把 \(e^{jk\omega_0 t}\) 换成 \(e^{j2\pi kn/N}\)， 求和的抵消性质由

    \[\sum_{n=0}^{N-1} e^{j2\pi (k-m)n/N} = \begin{cases} N, & k = m \\ 0, & k \ne m \end{cases}\]

    给出。这一条就是 DFT 正变换公式里那个「只挑出一个 \(k\)」的原理

    3.2 两条对偶关系：整张表的钥匙¶

    这张表之所以能记住，是因为它只由两条规律生成。这两条规律必须反复强调：

    两条对偶关系

    关系一：时域周期性 ⟺ 频域离散。 时间上重复，频率上就被「筛」成一根根离散的谱线。

    关系二：时域离散 ⟺ 频域周期。 时间上只取整点，频率上就出现了周期性重复。

    两条关系是双向的，而且互相独立 —— 一条管「离散还是连续」，另一条管「周期还是非周期」。 四个变换，就是这两条规律的两两组合

    下面逐条把「为什么」讲透。

    关系一：为什么时域周期会让频域离散？

    设连续信号 \(x(t)\) 以 \(T\) 为周期。周期信号可以写成复指数之和

    \[x(t) = \sum_{k=-\infty}^{+\infty} c_k e^{j k \omega_0 t}, \qquad \omega_0 = \frac{2\pi}{T}\]

    这就是傅里叶级数。这里 \(T\) 是周期，单位是秒； \(\omega_0\) 是基频，单位是弧度每秒，取值范围是 \(\omega_0 \gt 0\)； \(k\) 是谐波序号，取遍所有整数；\(c_k\) 是第 \(k\) 次谐波的复幅度。

    这个式子怎么读：它右边是一个求和，而求和只可能给出离散的项。 每一项的频率都是 \(\omega_0\) 的整数倍，也就是 \(0,\ \pm\omega_0,\ \pm 2\omega_0,\ \dots\) 这些等间隔的点。 在这些点之间，\(x(t)\) 里干脆没有任何频率成分 —— 所以它的谱只在这些点上非零，这就是「离散谱」的字面含义

    反过来看也成立：如果频域只在等间隔的点上有值， 那么把这些复指数加起来，得到的一定是一个周期函数 （因为所有频率都是 \(\omega_0\) 的整数倍，公共周期是 \(T = 2\pi/\omega_0\)）。 这个「反过来」正是关系二的对称版本，也是后面 DFT 能成立的根本原因。

    关系二：为什么时域离散会让频域周期？

    设离散序列 \(x(n)\) 的 DTFT 是

    \[X(e^{j\Omega}) = \sum_{n=-\infty}^{+\infty} x(n) e^{-j\Omega n}\]

    这里 \(n\) 是整数序号（因为信号是离散的，时间只能取整数）， \(\Omega\) 是数字角频率，单位是弧度，取值范围只要看一个周期 \([-\pi, \pi]\) 就够了。

    现在把 \(\Omega\) 换成 \(\Omega + 2\pi\)，逐项看发生了什么：

    \[X(e^{j(\Omega + 2\pi)}) = \sum_{n=-\infty}^{+\infty} x(n) e^{-j(\Omega + 2\pi)n} = \sum_{n=-\infty}^{+\infty} x(n) e^{-j\Omega n} \underbrace{e^{-j 2\pi n}}_{=\,1} = X(e^{j\Omega})\]

    中间那一步用到了关键事实：\(n\) 是整数， 所以 \(e^{-j2\pi n} = \cos(2\pi n) - j\sin(2\pi n) = 1\) 恒成立。 把整个和式每一项都乘上 \(1\)，结果当然不变。

    为了把「\(n\) 必须是整数」这一点钉死，我们把两种情形并排算一次：

    情形 指数的取值 是否恒为 \(1\) 结论
    离散时间，\(n\) 取整数 \(e^{-j2\pi n} = \cos(2\pi n) - j\sin(2\pi n)\) 是 ✓ 谱以 \(2\pi\) 为周期重复 ✓
    连续时间，\(t\) 取实数 \(e^{-j2\pi t} = \cos(2\pi t) - j\sin(2\pi t)\) 否 ⚠ 谱不周期化 ⚠

    第二行的「否」是随手取一个 \(t = 0.25\) 就能看到的： \(e^{-j2\pi(0.25)} = e^{-j\pi/2} = -j \ne 1\)。 只要时间轴是连续的，就总能取到让这个因子不等于 \(1\) 的时刻， 于是「平移 \(2\pi\) 后数值不变」就无从谈起。

    于是得到结论：\(X(e^{j\Omega})\) 以 \(2\pi\) 为周期。 算式上只差一个 \(e^{-j2\pi n}\)，而它等于 \(1\)； 这个 \(1\) 之所以成立，完全依赖于 \(n\) 是整数 ⚠ 如果时间轴是连续的 \(t\)，\(e^{-j2\pi t}\) 一般不等于 \(1\)， 连续时间信号的谱就不会周期化 —— 这就是「离散 ⟺ 周期」的来历。

    3.3 两条关系合起来：DFT 为什么存在¶

    把两条关系同时用上，就得到本页最重要的一句推论。

    当信号同时满足「离散」和「周期」时：

    • 因为离散（关系二）→ 频域是周期的；
    • 因为周期（关系一）→ 频域是离散的；

    两条合起来：频域既离散又周期。

    而一个「既离散又周期」的东西，只需要 \(N\) 个数就能完整描述它 —— 一个周期里的那 \(N\) 个采样值。这就意味着： 时域存 \(N\) 个数，频域也存 \(N\) 个数，两边都是有限长的。 这就是 DFT 存在的原因，也是 DFT 能用计算机直接算的原因。

    信号的属性组合 频域是离散的吗 频域是周期的吗 频域需要多少个数描述
    连续 + 周期 → FS 是（关系一） 否 无穷多个（但可数）
    连续 + 非周期 → FT 否 否 需要一整条曲线
    离散 + 非周期 → DTFT 否 是（关系二） 需要一整条曲线（在一个周期内）
    离散 + 周期 → DFT 是 是 恰好 \(N\) 个 ✓

    最后一行是唯一「两边都有限」的情形。 这也解释了为什么工程上几乎所有频谱分析最终都落到 DFT 上： 不是因为它更准，而是因为它是唯一能在计算机上精确表示的一格。

    3.4 「时域离散 ⟺ 频域周期」的三种等价看法¶

    这一条对偶关系之所以必须反复讲，是因为它在不同场合有三种完全不同的说法， 很多人在考场上认不出它们是同一件事。把三种看法列在一起：

    看法 说法 什么时候用它
    代数看法 \(e^{-j2\pi n} = 1\) 对一切整数 \(n\) 成立，所以平移 \(2\pi\) 后谱不变 ✓ 做证明题、写推导
    几何看法 离散频率点 \(0, \pm 1, \pm 2, \dots\) 在单位圆上是绕着圆走，走满一圈就回到原点 ✓ 理解「为什么是 \(2\pi\) 而不是别的数」
    工程看法 采样率 \(f_s\) 定下之后，能表示的最高频率是 \(f_s/2\)，再往上就与低频重合了 ⚠ 选采样率、查混叠

    几何看法值得多写两句，因为它解释了 \(2\pi\) 这个数字怎么来的。 离散序列的每一个频率成分都是一个旋转因子 \(e^{j\Omega n}\)： \(n\) 每增加 \(1\)，相位就前进 \(\Omega\)。 现在让 \(\Omega\) 从 \(0\) 开始慢慢增大：

    \(\Omega\) 的取值 一步前进的相位 观察到的现象
    \(0\) \(0^{\circ}\) 序列不动，是直流 ✓
    \(\pi/2\) \(90^{\circ}\) 每 4 步转回原处
    \(\pi\) \(180^{\circ}\) 每 2 步一正一负，是最高频 ✓
    \(3\pi/2\) \(270^{\circ}\) 与 \(90^{\circ}\) 看起来一样 ⚠
    \(2\pi\) \(360^{\circ}\) 与 \(0^{\circ}\) 完全一样 ⚠

    关键就在最后两行：走了 \(270^{\circ}\) 与走了 \(90^{\circ}\)， 虽然「转的方向」不同，但落在同样的整数时刻上时， 两个序列的取值序列是一模一样的 —— 因为观察者只在整数点上看， 看不见「中间转了多少」。同理 \(\Omega = 2\pi\) 与 \(\Omega = 0\) 完全重合。

    所以「频域以 \(2\pi\) 为周期」不是一条需要背的公式， 它是「只采整数点」这个动作的必然结果： 能区分的只有 \(\Omega\) 在一个 \(2\pi\) 区间内的部分，多出来的都是重复品。 这也正是 Nyquist 频率那个「一半」的来历 —— 一个 \(2\pi\) 区间被正负频率对半分，一半就是一个 \(\pi\) ✓

    四、收敛域：变换存在性的唯一判据¶

    前三条退化链都指向同一个概念：收敛域。 这一节把它单独拿出来讲，因为它是六个变换里最容易被漏掉的信息。

    4.1 收敛域的定义与三条性质¶

    概念 定义 注意
    Z 变换的 ROC 使 \(\sum_{n} \lvert x(n) z^{-n}\rvert \lt \infty\) 的全体 \(z\) 构成的区域 是 z 平面上的环带（可以内半径为 0 或外半径为无穷）
    拉普拉斯变换的 ROC 使 \(\int \lvert x(t) e^{-s t}\rvert\,dt \lt \infty\) 的全体 \(s\) 构成的区域 是 s 平面上的竖带
    为什么可以只算模 \(\lvert x(n) z^{-n}\rvert = \lvert x(n)\rvert \cdot \lvert z\rvert^{-n}\) 收敛性只取决于 \(\lvert z\rvert\)，与辐角 \(\Omega\) 无关 ✓

    第三条是 ROC 能画成「环带」的全部原因： 级数的绝对收敛性只跟 \(\lvert z\rvert\) 有关， 所以只要某个 \(\lvert z\rvert = r_0\) 处收敛，整个圆 \(\lvert z\rvert = r_0\) 上就都收敛。 把这样的圆从小到大扫一遍，收敛的那些圆拼起来就是环带 ✓

    4.2 手算对照：同一个表达式，两个不同的序列¶

    这一条必须用手算走一遍，否则永远记不住。

    先算右边序列。 取 \(x_1(n) = a^n u(n)\)，\(0 \lt a \lt 1\)：

    \[X_1(z) = \sum_{n=-\infty}^{+\infty} x_1(n) z^{-n} = \sum_{n=0}^{+\infty} a^n z^{-n} = \sum_{n=0}^{+\infty} \left( \frac{a}{z} \right)^{n}\]

    这是公比为 \(a/z\) 的几何级数，求和公式是 \(\sum_{n=0}^{\infty} q^n = \dfrac{1}{1-q}\)， 收敛条件是 \(\lvert q\rvert \lt 1\)。代入 \(q = a/z\)：

    \[X_1(z) = \frac{1}{1 - a z^{-1}}, \qquad \left\lvert \frac{a}{z} \right\rvert \lt 1 \;\Longleftrightarrow\; \lvert z\rvert \gt a\]

    再算左边序列。 取 \(x_2(n) = -a^n u(-n-1)\)，它在 \(n \le -1\) 时非零：

    \[X_2(z) = \sum_{n=-\infty}^{+\infty} x_2(n) z^{-n} = -\sum_{n=-\infty}^{-1} a^n z^{-n}\]

    把求和指标换成 \(m = -n\)（\(n\) 从 \(-1\) 到 \(-\infty\) 对应 \(m\) 从 \(1\) 到 \(+\infty\)）：

    \[= -\sum_{m=1}^{+\infty} a^{-m} z^{m} = -\sum_{m=1}^{+\infty} \left( \frac{z}{a} \right)^{m}\]

    这是公比为 \(z/a\) 的几何级数，从 \(m = 1\) 开始，所以 \(\sum_{m=1}^{\infty} q^m = \dfrac{q}{1-q}\)。代入 \(q = z/a\)：

    \[X_2(z) = -\frac{z/a}{1 - z/a} = -\frac{z}{a - z} = \frac{z}{z - a} = \frac{1}{1 - a z^{-1}}, \qquad \lvert z\rvert \lt a\]

    两个结果并排看一看：

    项 右边序列 \(a^n u(n)\) 左边序列 \(-a^n u(-n-1)\)
    时域取值 \(n \ge 0\) 时 \(a^n\)，其余为 \(0\) \(n \le -1\) 时 \(-a^n\)，其余为 \(0\)
    时间上朝哪边延伸 向右 ✓ 向左 ✓
    代数化简结果 \(\dfrac{1}{1 - a z^{-1}}\) \(\dfrac{1}{1 - a z^{-1}}\)
    收敛域 \(\lvert z\rvert \gt a\) \(\lvert z\rvert \lt a\)

    两行的代数表达式一模一样，第三列的收敛域却正好互补。 这就是「Z 变换必须同时给出 ROC」的全部含义： 不是书写规范的问题，而是「少了这句话，问题就有两个答案」。

    用具体数字核一遍。 取 \(a = 0.5\)、\(z = 0.8\)：

    \[X_1(0.8) = \frac{1}{1 - 0.5/0.8} = \frac{1}{1 - 0.625} = \frac{1}{0.375} = 2.666667\]

    而同一个 \(z = 0.8\) 对左边序列来说落在 \(\lvert z\rvert \lt 0.5\) 之外， 级数 \(\sum_m (z/a)^m = \sum_m 1.6^m\) 的公比大于 \(1\)，必然发散 ✗ 所以「\(X(z)\) 在 \(z = 0.8\) 处等于多少」这个问题， 不看 ROC 就没有答案

    「极点相同」不等于「变换相同」

    上面两个序列的极点都是 \(z = a = 0.5\)，完全相同； 表达式也完全相同。唯一的差别是收敛域在极点的哪一侧。

    于是一条极有用的判据：

    收敛域相对于极点的位置 逆变换是什么序列 系统因果吗
    最外极点的外侧（\(\lvert z\rvert \gt\) 最大极点模） 右边序列 因果 ✓
    最内极点的内侧（\(\lvert z\rvert \lt\) 最小极点模） 左边序列 反因果 ⚠
    两个极点之间 双边序列 既非因果也非反因果 ⚠

    所以看到「极点模都小于 1」不能直接下结论说稳定 —— 还得看收敛域是不是取在极点外侧、有没有把单位圆包进去

    \[X(1) = \sum_{n=0}^{\infty} 0.5^{n} = \frac{1}{1 - 0.5} = 2.000000\]

    看清楚两个公比分别是 \(0.25\) 与 \(0.5\)： \(z\) 从单位圆挪到 \(z = 2\) 时，每一项都被额外乘上了 \(2^{-n}\)， 级数收敛得更快，所以和反而更小 ⚠ 这说明「\(X(z)\) 的大小」完全由 \(\lvert z\rvert\) 决定， 它衡量的是级数收敛的速度，而不是信号在某个频率上的强弱。

    顺便把这条常考的算路记下来：判断 \(X(z)\) 在某个点是否等于 DTFT， 只需问一句「这个点的 \(\lvert z\rvert\) 是不是 1」 —— 是，就等于；不是，就不等，没有中间情形 ✓

    4.4 收敛域如何决定变换的存在性¶

    把前面所有内容收成一张判据表，这就是本节的落点：

    变换 收敛域是什么形状 什么条件下「存在」 条件不满足时怎么办
    FT 虚轴 \(\sigma = 0\) 上的取值 虚轴落在拉普拉斯收敛域内 改用拉普拉斯变换，或改用功率谱描述 ⚠
    DTFT 单位圆 \(\lvert z\rvert = 1\) 上的取值 单位圆落在 Z 变换收敛域内 改用 Z 变换，看环带 ⚠
    拉普拉斯变换 s 平面上的竖带 竖带非空 信号增长太快，变换不存在
    Z 变换 z 平面上的环带 环带非空 同上
    DFT 不需要收敛域 只要序列有限长 有限长 ⇒ 自动满足 ✓
    FS 不需要收敛域 一个周期内满足 Dirichlet 条件 改用数值谱分析并说明误差

    这张表是本节最该记住的：前四行的「存在条件」全都写成 「某条线（或某个区域）落在收敛域里」的形式； 后两行之所以例外，是因为它们的积分/求和区间本来就是有限长的 —— 有限区间上的连续函数一定可积，所以自动满足 ✓

    4.5 两个平面的几何对照：s 平面与 z 平面¶

    上面所有判据最后都归结为两句几何的话： 「虚轴在不在竖带里」 和 「单位圆在不在环带里」。 把两个平面摆在一起对照，这两句话就再也不会记混：

    比较项 s 平面（连续时间） z 平面（离散时间）
    复变量 \(s = \sigma + j\omega\) \(z = r e^{j\Omega}\)
    收敛域的形状 竖带（由 \(\sigma\) 的范围决定）✓ 环带（由 \(r = \lvert z\rvert\) 的范围决定）✓
    退化线 虚轴 \(\sigma = 0\) ✓ 单位圆 \(r = 1\) ✓
    退化后得到的变换 傅里叶变换 ✓ DTFT ✓
    稳定性判据 收敛域含虚轴 ✓ 收敛域含单位圆 ✓
    两个平面的对应关系 \(z = e^{s T_s}\) \(\sigma\) 映射成 \(r = e^{\sigma T_s}\)，\(\omega\) 映射成 \(\Omega = \omega T_s\)

    最后一行值得多看一眼：\(z = e^{s T_s}\) 这个映射把 「s 平面的竖线 \(\sigma = \text{常数}\)」变成「z 平面的圆 \(r = \text{常数}\)」， 把「s 平面的横线 \(\omega = \text{常数}\)」变成「z 平面的射线 \(\Omega = \text{常数}\)」。 竖带因此变成环带，虚轴因此变成单位圆 ✓ 所以两个平面的判据长得这么像，不是巧合 —— 它们是同一个判据在两种坐标下的样子。

    再看一个常考的具体情形：两个极点 \(z = 0.5\) 与 \(z = 2\)。 两个极点的模把 \(\lvert z\rvert\) 轴分成三段，于是收敛域有三种取法：

    收敛域取法 逆变换是 因果性 含单位圆吗 稳定性
    \(\lvert z\rvert \gt 2\) 右边序列 因果 ✓ 不含（\(1 \lt 2\)）✗ 不稳定 ⚠
    \(0.5 \lt \lvert z\rvert \lt 2\) 双边序列 非因果 ⚠ 含（\(0.5 \lt 1 \lt 2\)）✓ 稳定 ✓
    \(\lvert z\rvert \lt 0.5\) 左边序列 反因果 ⚠ 不含（\(1 \gt 0.5\)）✗ 不稳定 ⚠

    中间那一行是这张表的考点：它说明 「因果」与「稳定」不是一回事，甚至可能互相冲突。 这个系统的脉冲响应是右边的 \(0.5^n\) 加上左边的 \(-2^n\) 部分， 它在 \(n \to \pm\infty\) 两个方向都收敛得很快（因为 \(2\) 那一支走的是左边）， 所以绝对可和、系统稳定；但它显然不是因果系统 ⚠ 工程上遇到这种情形，通常要先问清要求的是因果还是稳定，再决定收敛域取哪一段。

    4.6 傅里叶级数什么时候收敛：Dirichlet 条件¶

    收敛域管的是「复变量变换在哪些点上收敛」， 而傅里叶级数是另一套收敛问题：它对哪些周期信号成立？ 本课程课件在给出傅里叶级数的同时，就附上了这个前提 —— Dirichlet 条件。

    一个周期为 \(T\) 的时间函数 \(x(t)\)，只要在一个周期内满足下面三条， 就可以展成正弦与余弦函数的代数和：

    序号 条件 数学写法 通俗含义 它排除掉什么
    1 在一个周期内绝对可积 \(\int_{T} \lvert x(t)\rvert\,dt \lt \infty\) 一个周期里的「总面积」有限 周期内有无穷大的尖峰
    2 在一个周期内极值点个数有限 极大值、极小值一共只有有限个 信号不会无限来回抖动 无限密集的振荡
    3 在一个周期内间断点个数有限 第一类间断点只有有限个 跳变只有有限处 处处不连续的振荡函数

    三条里，第一条最重要，也最容易被忽略。 第二条和第三条是「技术性条件」，实际工程信号几乎不会违反； 而第一条是有实质内容的 —— 它决定了级数的系数积分会不会收敛。

    这里要特别说明一点：Dirichlet 条件里的「绝对可积」只要求在一个周期内积分， 不要求在整个时间轴上积分。 这正是周期信号能展成级数、 而它们却不能直接做傅里叶变换的原因 ⚠ 区别不在信号本身，而在积分的区间长度： 一个周期是有限长度，积分当然可能收敛；整条时间轴是无限长度，就未必了。

    收敛到哪里？ 课件给出的结论是一句话，这句话要拆成两半来读： 级数在连续点收敛于原函数，在间断点收敛于左右极限的平均值。

    点的类型 级数收敛到 与原函数的关系
    连续点 \(t_0\) \(x(t_0)\) 完全相等 ✓
    第一类间断点 \(t_0\) \(\dfrac{x(t_0^-) + x(t_0^+)}{2}\) 收敛到左右极限的平均值 ✓

    第二行是重点。设 \(x(t_0^-)\) 表示从左边趋近 \(t_0\) 时的极限， \(x(t_0^+)\) 表示从右边趋近时的极限。 如果信号在这里从 \(-1\) 跳到 \(+1\)，那么 \(x(t_0^-) = -1\)、\(x(t_0^+) = +1\)，级数在这一点收敛到 \((-1 + 1)/2 = 0\)。

    注意：\(0\) 既不是左极限 \(-1\)，也不是右极限 \(+1\)，更不是 \(x(t_0)\) 本身。 级数在间断点处收敛到的，是一个两头都不沾的中间值。 很多人在算完级数、去和原函数逐点比对时，就是在这里发现「怎么对不上」的 ✓

    课件另外补了两条更强的收敛性结论，它们说明「条件更好时，收敛也更好」：

    附加条件 收敛类型 直观含义
    \(x(t)\) 是连续可微的周期函数 一致收敛 部分和与原函数的最大偏差均匀地趋向 0
    \(x(t)\) 在周期 \(T\) 上平方可积 均方收敛 能量意义上的偏差趋向 0，个别点可以不管

    这两条的关系是：一致收敛最强（每一点都对得上）， 均方收敛最弱（只保证整体能量对得上，个别点可能仍然出错）。

    为什么要专门讲这一节。 因为这一节解释了后面所有 「数值结果和理论对不上」的现象里最经典的一个 —— Gibbs 现象。 用 50% 占空比的方波做例子：它在 \(0 \lt t \lt \pi\) 时取 \(+1\)， 在 \(-\pi \lt t \lt 0\) 时取 \(-1\)，周期是 \(2\pi\)。 它的傅里叶级数只含奇次正弦项：

    \[x(t) \;\approx\; S_K(t) = \sum_{k=1,3,5,\dots}^{2K-1} \frac{4}{k\pi}\sin(k t)\]

    这里 \(K\) 是保留的项数，\(S_K(t)\) 是部分和。 去掉那个 \(\pm 1\) 的跳变，级数在连续点处表现完美； 但在跳变附近，部分和会「冲过头」再回来：

    保留项数 \(K\) 连续点 \(t = \pi/2\) 处的部分和 \(\max\lvert S_K(t)\rvert\) 相对 \(1\) 的过冲
    \(1\) \(1.273240\) \(1.273240\) \(27.32\%\)
    \(3\) \(1.103474\) \(1.188357\) \(18.84\%\)
    \(10\) \(0.968248\) \(1.179814\) \(17.98\%\)
    \(100\) \(0.996817\) \(1.178988\) \(17.90\%\)
    \(2000\) \(0.999841\) \(1.178980\) \(17.90\%\)

    这张表要横着读、也要竖着读。

    横着读第一列：\(t = \pi/2\) 是连续点， 部分和从 \(1.273240\) 一路收敛到 \(0.999841\)， 误差在趋于零 ✓ 这说明级数在连续点处确实等于原函数。

    读第二列就不一样了：\(\max\lvert S_K(t)\rvert\) 从 \(1.273240\) 降到 \(1.178980\)， 却停在那里不动了 —— 无论 \(K\) 加到多大，它都比 \(1\) 高出约 \(17.9\%\) ⚠ 这就是 Gibbs 现象：在间断点附近，部分和会「冲过头」再回来， 而且过冲的相对幅度是一个常数，不随项数减小。

    为什么这个常数是 \(17.9\%\) 而不是别的数。 它来自一个与信号无关的定积分。方波在跳变附近的部分和可以用正弦积分函数表示， 过冲的极限值等于

    \[\frac{2}{\pi}\int_{0}^{\pi} \frac{\sin u}{u}\,du - 1 \approx 0.17898\]

    注意这个式子里完全没有方波的参数 —— 没有周期、没有幅度、没有跳变高度。 也就是说，只要信号有跳变，过冲的比例就是这同一个数 ✓ 跳变越高，过冲的绝对值越大，但比例不变。

    Gibbs 现象有一个非常实用的推论，是工程上必须要知道的： 用截断的傅里叶级数（或 DFT）去表示一个带跳变的信号， 在跳变附近一定会出现过冲，而且加项数解决不了。 要压掉它，必须换手段 —— 加窗、平滑、或者干脆避免在跳变附近做判定。 项数加多只是让过冲的宽度变窄，让过冲更贴近跳变位置 ✓

    容易搞错的点 正确说法
    「Dirichlet 条件保证了级数逐点等于原函数」 只在连续点成立；间断点收敛到左右极限的平均值 ⚠
    「绝对可积要求全时间轴积分有限」 级数只要求一个周期内绝对可积；全轴绝对可积是 FT 的要求 ⚠
    「项数加多了，Gibbs 过冲会消失」 过冲的宽度会变窄，但相对幅度稳定在约 17.9% 不变 ⚠

    有间断点时，不要用「逐点比较」来验收级数

    如果你写完级数后想验证它对不对，千万不要在间断点附近逐点比对。

    正确的验收方法是：

    该在哪验证 该看什么 不该看什么
    远离间断点的连续处 部分和是否贴近原函数 ✓ ——
    间断点本身 是否收敛到左右极限的平均值 ✓ 是否等于原函数 ⚠
    间断点的小邻域 过冲幅度是否稳定（Gibbs）✓ 过冲是否会随项数消失 ⚠

    还有一个更隐蔽的陷阱：如果原信号本身有跳变，而你的模型假设它连续， 那么误差不会平均分布，而是全部集中在跳变附近。 做频谱分析时看到的那些「莫名其妙的旁瓣」，很多时候就是这么来的 ✓

    补零不改变收敛域，也不提高分辨率

    补零（在数据尾部接零）是一件很容易被误解的操作，必须说清它改变了什么、没改变什么：

    补零改变了吗 改变什么 不改变什么
    频率网格 网格间隔从 \(1/N\) 变成 \(1/M\)（\(M \gt N\)）✓ ——
    观测长度 不变 ⚠ 数据里只有原来的 \(N\) 个真实样点
    频率分辨率 不变 ⚠ 最小可分辨间隔仍是 \(\approx 1/N\)
    DTFT 曲线 不变 ⚠ 曲线只由那 \(N\) 个真实样点决定

    最后一行是理解一切的关键：DTFT 是「有限长序列」的真谱， 而补零不增加任何新样点，所以真谱一个点都没变 —— 补零后算出的 DFT，只是同一条曲线上多取了几个点 ✓

    所以「补零能提高分辨率」是错的，正确的说法是 「补零只加密读数网格」 ⚠

    五、四个变换的适用条件与限制总表¶

    课件把「限制」明确列为关注点之一，这一节就专门兑现它。 下面先把六个变换的限制排成一张总表。

    5.1 六个变换的限制总表¶

    变换 主要限制 怎么规避
    FS 只处理周期连续信号；且必须满足 Dirichlet 条件；不带时间信息的变化 非周期信号改用 FT；把一个周期内的变化交给短时分析 ✓
    FT 要求全轴绝对可积，功率信号（正弦、直流、方波）严格来说不满足 ⚠ 改用自相关函数与功率谱描述；或乘衰减因子推广成拉普拉斯变换 ✓
    DTFT 谱是连续函数，计算机无法直接存储；且要求序列绝对可和 上机时改用 DFT 近似；绝对可和的边界用 Z 变换放宽 ✓
    DFT 隐含把有限序列周期延拓，会带来泄漏与栅栏效应；谱是 DTFT 的采样，不是 DTFT 本身 ⚠ 选整周期截断；加窗抑制旁瓣；补零只是加密网格，不能提高真实分辨率 ✓
    Z 变换 必须同时给出收敛域 ROC，否则逆变换不唯一；表达式相同可能对应两个完全不同的序列 ⚠ 每次写出 \(X(z)\) 都紧跟一句「ROC: 某条件」；用因果性/稳定性条件锁定 ROC ✓
    拉普拉斯变换 同样依赖 ROC 才唯一；且它是 \(s\) 平面上的函数，画图前必须先规定 \(\sigma\) ⚠ 与 Z 变换同样处理：先写 ROC，再由极点位置判稳定性 ✓

    这张表最后两行说的是同一件事：复变量变换的「限制」主要就是 ROC。 这不是形式上的补充，而是数学上不可省略的信息。

    5.2 手算对照：截断位置决定泄漏程度¶

    泄漏是「有限序列做 DFT」自带的代价，与信号质量无关。 下面用一个余弦信号手算两种截断方式的差别：

    项目 取法一（整周期） 取法二（非整周期）
    截断长度 \(N = 64\) 点 \(N = 64\) 点
    信号周期数 \(8.0\) 个 \(8.5\) 个
    真实频率 \(8.0/64 = 0.1250\) 周/样点 \(8.5/64 = 0.1328\) 周/样点
    是否落在 DFT 网格上 是（正好是 \(k = 8\)）✓ 否（落在 \(k = 8\) 与 \(k = 9\) 之间）⚠
    接缝处是否跳变 不跳（首尾正好接上）✓ 跳变（多出半个周期）⚠
    峰值谱线 \(k = 8\)，幅度 \(32.0000\) \(k = 9\)，幅度 \(20.8231\)
    主瓣外能量占比 \(0.000000\) ✓ \(0.138860\) ⚠
    次大谱线幅度 \(0.000000\) ✓ \(19.916823\) ⚠

    两行数字的差别大得不像「同一个信号」。这些数字全部手算得出来， 思路分四步走：

    第一步：算频率网格间隔。

    \[\Delta f_{\text{网格}} = \frac{1}{N} = \frac{1}{64} = 0.015625 \text{ 周/样点}\]

    第二步：把真实频率折算成「第几格」。 取法一的真实频率是 \(8.0/64 = 0.1250\)，除以网格间隔：

    \[\frac{0.1250}{0.015625} = 8\]

    是整数 —— 所以真实频率恰好落在一根谱线上（第 \(k = 8\) 根）✓ 取法二的真实频率是 \(8.5/64\)，除以网格间隔：

    \[\frac{8.5/64}{1/64} = 8.5\]

    不是整数 —— 真实频率卡在 \(k = 8\) 与 \(k = 9\) 之间， DFT 在这两个序号上都不等于真值 ⚠

    第三步：看接缝处跳不跳。 取法一截了整数个周期，第 \(65\) 个样点与第 \(1\) 个样点取值相同， 周期延拓没有跳变，所以能量全部留在一根谱线上； 取法二多出半个周期（\(8.5 - 8 = 0.5\)），首尾接不上， 接缝处出现跳变，跳变把能量摊到整条频率轴上 ⚠

    第四步：手算峰值幅度。 对取法二，真实频率与两格的偏移是 \(\delta = 8.5/64 - 9/64 = -0.5/64\)。 这半个格的偏移让正弦项被「摊开」，由 DFT 的求和闭式可得：

    \[\lvert X[9]\rvert \approx \left\lvert \frac{\sin(\pi/2)}{\sin(\pi/128)} \right\rvert = \frac{1}{0.024541} = 40.748\]

    而取法一的偏移是 \(\delta = 0\)，峰值幅度是 \(N/2 = 32\)。 两行合起来看：

    取法 真实频率与最近网格的偏移 峰值幅度
    取法一（整周期） \(0\) ✓ \(32.0000\) ✓
    取法二（非整周期） \(0.5\) 格 ⚠ 前半支 \(40.748\)，与后半支相消后 \(20.8231\) ⚠

    这一步是这道题的关键：它说明「峰值幅度掉下来」不是因为能量少了， 而是因为能量被摊到了多根谱线上 —— 所以旁边那根 \(k = 8\) 的谱线幅度高达 \(19.9168\)， 几乎是主峰 \(20.8231\) 的全部

    两件事必须分清，它们经常被混着说：

    现象 由什么造成 表现 怎么缓解
    泄漏（leakage） 截断使信号在接缝处不连续，跳变把能量摊到全频段 谱线「糊」成一片，旁瓣升高 截整周期；加窗（汉宁、汉明等）✓
    栅栏效应（picket fence） DFT 只在等间隔的 \(N\) 个频率点上取值 真正峰值落在两格之间时看不见，位置和幅度都偏 补零加密网格；但真实分辨率由观测长度决定，补零只让「读数」更细 ⚠

    第二行最后半句是本页要反复强调的： 补零加密的是频率网格，不是分辨率。 观测了 \(N\) 个样点，能分辨的最小频率间隔就是 \(f_s/N\)； 补零到 \(4N\) 点，谱线从 \(N\) 根变成 \(4N\) 根， 但那是同一条已经被抹平了的曲线上多取了些点， 两个靠得比 \(f_s/N\) 更近的频率依然分不开

    量 它由什么决定 补零能改变吗
    频率网格间隔 补零后的点数 \(M\) 能，从 \(1/N\) 变成 \(1/M\) ✓
    频率分辨率 观测长度（真实样点数 \(N\)） 不能 ⚠

    补零后的 DFT 值，等价于在原来的 DTFT 曲线上做插值 —— 插值可以让曲线画得更细，但填不出曲线上本来就没有的结构

    5.4 时频对偶的两种极端：白噪声与正弦¶

    「时域离散 ⟺ 频域周期」这条对偶关系，换一个角度看会更清楚： 信号在时域上越「规整」，在频域上就越「散」；反之亦然。

    这张图把两个极端并排画出来：

    图里的两条曲线代表了两种极端情形：白噪声的自相关是一个冲激， 对应的功率谱在整条频率轴上是常数； 正弦的自相关是一个余弦，对应的功率谱是两根孤立的谱线。 冲激与常数互为对偶，余弦与谱线互为对偶。

    为什么会这样？关键在自相关函数与功率谱是一对傅里叶变换：

    时域（自相关 \(r_x(\tau)\)） 频域（功率谱 \(S_x(\omega)\)） 直观读法
    冲激 \(\delta(\tau)\) 常数（平坦的） 时间上「立刻忘记自己」，频率上每个频率都一样强 ✓
    余弦 \(\cos\omega_0\tau\) 两根谱线 \(\delta(\omega \mp \omega_0)\) 时间上「永远记得自己」，频率上只有一个频率有能量 ✓
    指数衰减 \(e^{-\alpha\lvert\tau\rvert}\) 洛伦兹型 \(2\alpha/(\alpha^2+\omega^2)\) 介于两者之间，\(\alpha\) 越大时间上越窄、频率上越宽 ✓

    第三行是理解前两行的钥匙： 自相关在时域上越「窄」，功率谱在频域上就越「宽」。 这个关系不是巧合，它正是傅里叶变换尺度性质的体现： 时域压缩因子 \(1/a\) 对应频域展宽因子 \(a\)。

    用一句话概括这一节的全部内容：

    对偶不是两个公式的对称排版，而是「一个域里的展开，就是另一个域里的压缩」。 时域离散让频域周期，时域周期让频域离散， 自相关变窄让功率谱变宽 —— 它们都是同一件事的不同侧面

    「自相关是冲激」不等于「信号是白噪声」的充分条件

    上面那张图容易引起一个误读：把「自相关是冲激」当成白噪声的定义。 严格来说，二者的关系是：

    说法 是否成立 说明
    白噪声 ⇒ 自相关是冲激 成立 ✓ 定义要求不同时刻不相关
    自相关是冲激 ⇒ 白噪声 不一定 ⚠ 高阶统计量可能仍相关；「白」只约束二阶矩
    功率谱是常数 ⇒ 白噪声 不一定 ⚠ 同上，且有限观测下谱永远不可能是「严格常数」

    第三行还有一个常见误用：实际数据的功率谱永远不可能是常数 —— 因为观测长度有限，谱估计本身带着方差。 看到「谱线起伏很大」时，先问一句「这是信号的谱，还是估计的方差」， 再下结论

    6.1 把决策树写成手查表¶

    原来的做法是写一个函数扫参数打印推荐结果，但那是程序的活； 考试里要的是看到属性就能说出结论。所以把它改成一张手查表：

    信号属性 该用哪个变换 输出长什么样 最容易出的错
    连续 / 周期 / 功率 FS 离散线谱，间距是基频 ✓ 拿 FT 硬套，发现积分发散 ⚠
    连续 / 非周期 / 能量 FT 连续谱密度曲线 ✓ 忘了先验证绝对可积
    连续 / 非周期 / 功率 自相关 + 功率谱 功率谱（频率上的能量分布）✓ 直接用 FT，得到不收敛的积分 ⚠
    离散 / 周期 / 功率 DFT / DFS \(N\) 个离散值 ✓ 把补零当成提高分辨率 ⚠
    离散 / 非周期 / 无限长 / 能量 DTFT 或 Z 变换 连续的周期谱 / 复平面函数 ✓ 只写 \(X(z)\) 不写收敛域 ⚠
    离散 / 非周期 / 有限长 / 能量 理论 DTFT，工程 DFT 连续曲线 / \(N\) 个采样值 ✓ 把 DFT 的输出当成真谱 ⚠

    这张表最值得记住的是最后一列： 六种情形里，有四种的「最容易出的错」都与混淆了两个量有关 —— 把估计当定义、把采样当真谱、把网格当分辨率、把表达式当变换。 所以做判断时的顺序应当是「先问属性，再问代价」： 属性决定用哪个变换，代价决定这个变换在这里可不可信

    七、手算例题¶

    下面四道题都按考试答卷的方式写：每一步单独成行，写清这一步用了什么。

    例题 1：对 \(x(t) = e^{-a t}u(t)\) 把四种变换都算一遍¶

    题目：设 \(t\) 的单位是秒，\(a \gt 0\) 是实常数， 信号为 \(x(t) = e^{-a t}u(t)\)（\(t \lt 0\) 时为零）。 （a）求它的拉普拉斯变换与收敛域； （b）由（a）退化出傅里叶变换； （c）取采样周期 \(T_s\) 把它离散化，求 Z 变换与收敛域； （d）由（c）退化出 DTFT，并写出与（b）的对应关系。

    思路

    这道题的主线就是本页第二节的四条退化链： 先算最「宽」的那个变换（拉普拉斯）， 再令 \(s = j\omega\) 退到傅里叶； 离散之后先算 Z 变换，再令 \(z = e^{j\Omega}\) 退到 DTFT。 每一步都要盯住收敛域，它决定了后面能不能退化 ✓

    解答

    （a）拉普拉斯变换。

    第一步：写出定义式。

    \[X(s) = \int_{-\infty}^{+\infty} x(t) e^{-s t}\,dt\]

    第二步：把 \(x(t) = e^{-a t}u(t)\) 代进去。 因为 \(u(t)\) 在 \(t \lt 0\) 时为 \(0\)，积分下限从 \(-\infty\) 缩到 \(0\)：

    \[X(s) = \int_{0}^{+\infty} e^{-a t} e^{-s t}\,dt = \int_{0}^{+\infty} e^{-(s + a) t}\,dt\]

    第三步：合并被积函数，理由是 \(e^{-at}e^{-st} = e^{-(s+a)t}\)。

    第四步：算这个积分。设 \(\Re(s + a) \gt 0\)，则

    \[\int_{0}^{+\infty} e^{-(s + a) t}\,dt = \left[ \frac{e^{-(s+a)t}}{-(s+a)} \right]_{t=0}^{t=+\infty} = 0 - \frac{1}{-(s+a)} = \frac{1}{s + a}\]

    第五步：写出收敛域。积分收敛的条件是 \(\Re(s + a) \gt 0\)，也就是

    \[X(s) = \frac{1}{s + a}, \qquad \text{ROC}: \Re(s) \gt -a\]

    这个结论说明什么：极点位于 \(s = -a\)， 收敛域是极点右边的半平面。 因为 \(a \gt 0\)，所以 \(-a \lt 0\)，虚轴 \(\Re(s) = 0\) 落在收敛域内

    （b）退化出傅里叶变换。

    第一步：代换 \(s = j\omega\)。由上一步已确认虚轴在收敛域内，所以这个代换合法。

    第二步：代入 \(X(s) = 1/(s + a)\)：

    \[X(j\omega) = \frac{1}{j\omega + a} = \frac{1}{a + j\omega}\]

    第三步：验证它确实等于定义式算出来的结果。 用定义式：\(\int_{0}^{+\infty} e^{-at}e^{-j\omega t}\,dt = \int_0^{+\infty} e^{-(a+j\omega)t}\,dt = \dfrac{1}{a + j\omega}\) ✓ 两者一致。

    第四步：取模，看它的物理含义。

    \[\lvert X(j\omega)\rvert = \frac{1}{\sqrt{a^2 + \omega^2}}\]

    \(\omega = 0\) 时是 \(1/a\)，\(\omega \to \infty\) 时趋于 \(0\) —— 这是一个低通型的频谱

    （c）离散化之后的 Z 变换。

    第一步：以 \(T_s\) 采样。\(x(n) = x(nT_s) = e^{-a n T_s}\)，\(n \ge 0\)。 记

    \[r = e^{-a T_s} \qquad (0 \lt r \lt 1)\]

    于是 \(x(n) = r^{n} u(n)\)。

    第二步：写出 Z 变换定义式并代入。

    \[X(z) = \sum_{n=-\infty}^{+\infty} x(n) z^{-n} = \sum_{n=0}^{+\infty} r^{n} z^{-n} = \sum_{n=0}^{+\infty} \left( \frac{r}{z} \right)^{n}\]

    第三步：用几何级数求和公式 \(\sum_{n=0}^{\infty} q^n = \dfrac{1}{1 - q}\) （收敛要求 \(\lvert q\rvert \lt 1\)），代入 \(q = r/z\)：

    \[X(z) = \frac{1}{1 - r z^{-1}}, \qquad \text{ROC}: \lvert z\rvert \gt r\]

    第四步：核对一下这个结果与（a）的关系。 Z 变换的极点在 \(z = r = e^{-a T_s}\)， 而拉普拉斯变换的极点在 \(s = -a\) —— 两者正好满足 \(z = e^{s T_s}\)： \(e^{-a T_s} = r\) ✓ 这不是巧合，它正是「把 s 平面映射到 z 平面」的那条公式。

    （d）退化出 DTFT。

    第一步：取 \(\lvert z\rvert = 1\)，即 \(z = e^{j\Omega}\)。

    第二步：代入（c）的结果：

    \[X(e^{j\Omega}) = \frac{1}{1 - r e^{-j\Omega}}, \qquad r = e^{-a T_s}\]

    第三步：与（b）对照，写出两边的对应关系：

    \[\lvert X(j\omega)\rvert = \frac{1}{\sqrt{a^2 + \omega^2}}, \qquad \lvert X(e^{j\Omega})\rvert = \frac{1}{\sqrt{1 - 2r\cos\Omega + r^2}}\]

    第四步：说明二者为什么「看起来不一样、其实一致」。 在低频段 \(\omega T_s\) 很小时， \(a + j\omega\) 与 \(1 - r e^{-j\Omega}\)（\(r = e^{-aT_s}\)、\(\Omega = \omega T_s\)） 展开到一阶是成比例的， 所以两条曲线的形状在低频段一致， 差别只在高频段由于周期化而产生的重复 ✓

    这道题的五步总结：

    1. 最宽的变换（拉普拉斯 / Z）先把信号「救活」，让积分/求和收敛；
    2. 令 \(s = j\omega\) 或 \(z = e^{j\Omega}\) 就退化成傅里叶类变换；
    3. 退化的前提是虚轴 / 单位圆落在收敛域内；
    4. 连续到离散的桥是 \(z = e^{sT_s}\)（等价地 \(\Omega = \omega T_s\)）；
    5. 四个结果里，只有 DFT 需要额外的「有限长 + 周期延拓」假设。

    例题 2：由 \(X(s)\) 与收敛域反求时域信号¶

    题目：已知

    \[X(s) = \frac{1}{s + 2}\]

    （a）写出它可能对应的两种收敛域，以及各自的时域信号； （b）判断哪一个的傅里叶变换存在，并说明理由； （c）这两种情形分别对应什么样的系统特性（因果/稳定）。

    思路

    一个极点把 s 平面分成左右两半， 所以同一个 \(X(s)\) 最多对应两个反变换。 判据只有一条：看虚轴在收敛域的哪一边。 先把两种情形的收敛域画清楚，再逐一判断 ✓

    解答

    （a）两种收敛域与两种时域信号。

    第一步：找极点。分母 \(s + 2 = 0\)，得极点 \(s = -2\)， 它把 s 平面分成 \(\Re(s) \gt -2\) 与 \(\Re(s) \lt -2\) 两个区域。

    第二步：区域一 —— 取极点右侧，即 \(\Re(s) \gt -2\)。

    由例题 1（a）已经算过：这个区域对应的时域信号是右边信号（因果）

    \[x_1(t) = e^{-2t}u(t), \qquad \text{ROC}: \Re(s) \gt -2\]

    第三步：区域二 —— 取极点左侧，即 \(\Re(s) \lt -2\)。

    这个区域对应左边信号（反因果）。验证一下：设

    \[x_2(t) = -e^{-2t}u(-t)\]

    它在 \(t \lt 0\) 时非零（这里 \(u(-t)\) 在 \(t \lt 0\) 时为 \(1\)）。 代入定义式，积分上限变成 \(0\)：

    \[X_2(s) = \int_{-\infty}^{0} \left( -e^{-2t} \right) e^{-s t}\,dt = -\int_{-\infty}^{0} e^{-(s+2)t}\,dt\]

    算这个积分，注意下限是 \(-\infty\)：

    \[= -\left[ \frac{e^{-(s+2)t}}{-(s+2)} \right]_{t=-\infty}^{t=0} = \frac{1}{s+2}\left( 1 - \lim_{t\to-\infty} e^{-(s+2)t} \right)\]

    要让 \(t \to -\infty\) 时 \(e^{-(s+2)t} \to 0\)， 需要 \(\Re(s + 2) \lt 0\)，即 \(\Re(s) \lt -2\)。在这个条件下：

    \[X_2(s) = \frac{1}{s+2}, \qquad \text{ROC}: \Re(s) \lt -2\]

    表达式与 \(x_1\) 完全相同 ✓

    （b）哪个的傅里叶变换存在。

    判据：虚轴 \(\Re(s) = 0\) 是否落在收敛域内。

    情形 收敛域 虚轴 \(\Re(s)=0\) 在收敛域内吗 傅里叶变换存在吗
    右边信号 \(e^{-2t}u(t)\) \(\Re(s) \gt -2\) 是（\(0 \gt -2\)）✓ 存在 ✓
    左边信号 \(-e^{-2t}u(-t)\) \(\Re(s) \lt -2\) 否（\(0 \lt -2\) 不成立）✗ 不存在 ⚠

    第二行不存在，也可以直接验算： \(x_2(t)\) 在 \(t \to -\infty\) 时按 \(e^{-2t} \to +\infty\) 增长， 所以 \(\int_{-\infty}^{+\infty} \lvert x_2(t)\rvert\,dt\) 发散， 不满足绝对可积 ⚠

    （c）系统特性。

    情形 收敛域位置 因果吗 稳定吗 频率响应存在吗
    \(x_1(t) = e^{-2t}u(t)\) 极点右侧 ✓ 因果 ✓ 稳定 ✓ 存在 ✓
    \(x_2(t) = -e^{-2t}u(-t)\) 极点左侧 ⚠ 反因果 ⚠ 不稳定 ⚠ 不存在 ⚠

    第二列的「位置」是判据的关键：收敛域取在极点右侧 ⇒ 右边信号 ⇒ 因果。 第一行之所以同时是「稳定」的， 是因为 \(\Re(s) \gt -2\) 这个半平面把虚轴包了进去 —— 稳定 ⟺ 收敛域含虚轴 ⟺ 频率响应存在，三件事是一件事 ✓

    这道题的结论一句话： 只写 \(X(s) = \dfrac{1}{s+2}\) 是不完整的， 它会同时指向一个稳定的因果系统与一个不稳定的反因果系统； 补上收敛域，答案才唯一 ⚠

    例题 3：同一个 \(X(z)\) 的两个逆变换，以及稳定性判断¶

    题目：已知

    \[X(z) = \frac{1}{1 - 0.5z^{-1}}\]

    （a）写出它对应的两个序列及其收敛域； （b）在 \(z = 0.8\) 处，这两个级数哪个收敛？ （c）哪一个对应的系统是稳定的？为什么？（d）补零能让无限长序列直接上机做 DFT 吗？

    思路

    与例题 2 完全同构，只是把 s 平面换成 z 平面、把虚轴换成单位圆。 （b）要用几何级数的公比来判，（c）要用「单位圆是否落在收敛域内」来判， （d）要回到「DFT 要求有限长」这一条 ✓

    解答

    （a）两个序列与两个收敛域。

    第一步：找极点。\(1 - 0.5z^{-1} = 0\)，两边乘 \(z\) 得 \(z - 0.5 = 0\)， 极点 \(z = 0.5\)，模是 \(0.5\)。

    第二步：取极点外侧，\(\lvert z\rvert \gt 0.5\)。

    由 4.2 节的手算结果（把那里的 \(a\) 换成 \(0.5\)），也即例题 1 第（c）问同一套算法：

    \[x_1(n) = 0.5^{n}u(n), \qquad \text{ROC}: \lvert z\rvert \gt 0.5\]

    第三步：取极点内侧，\(\lvert z\rvert \lt 0.5\)。

    \[x_2(n) = -0.5^{n}u(-n-1), \qquad \text{ROC}: \lvert z\rvert \lt 0.5\]

    第四步：核对。把 \(x_1\) 代入定义式： \(\sum_{n \ge 0} 0.5^n z^{-n} = \dfrac{1}{1 - 0.5z^{-1}}\)， 收敛条件 \(\lvert 0.5/z\rvert \lt 1 \Leftrightarrow \lvert z\rvert \gt 0.5\) ✓

    （b）在 \(z = 0.8\) 处哪个收敛。

    第一步：算公比。对 \(x_1\) 的级数，公比是 \(q_1 = 0.5/0.8 = 0.625\)； 对 \(x_2\) 的级数，公比是 \(q_2 = 0.8/0.5 = 1.6\)。

    第二步：比公比的模与 \(1\)。

    序列 公比 \(q\) \(\lvert q\rvert \lt 1\) 吗 在 \(z = 0.8\) 处
    \(x_1(n) = 0.5^n u(n)\) \(0.5/0.8 = 0.625\) 是 ✓ 收敛，和为 \(\dfrac{1}{1-0.625} = 2.666667\) ✓
    \(x_2(n) = -0.5^n u(-n-1)\) \(0.8/0.5 = 1.6\) 否 ⚠ 发散 ⚠

    第三步：结论。在同一个 \(z\) 上，两个级数必然一个收敛、一个发散。 所以「\(X(z)\) 在 \(z = 0.8\) 处等于多少」这个问题， 不加「是哪一个序列的级数」就没有答案 ✓

    （c）哪个系统稳定。

    第一步：写下判据。BIBO 稳定的充要条件是脉冲响应绝对可和， 而绝对可和等价于

    \[\text{单位圆} \lvert z\rvert = 1 \text{ 落在收敛域内}\]

    第二步：逐行判断。

    收敛域 单位圆 \(\lvert z\rvert = 1\) 在收敛域内吗 绝对可和吗 稳定吗
    \(\lvert z\rvert \gt 0.5\) 是（\(1 \gt 0.5\)）✓ \(\sum_{n \ge 0} 0.5^n = 2\) ✓ 稳定 ✓
    \(\lvert z\rvert \lt 0.5\) 否（\(1 \lt 0.5\) 不成立）✗ 发散 ⚠ 不稳定 ⚠

    第三步：说明第一行右边那列的数字怎么来的。 绝对可和就是把每一项取模再求和：

    \[\sum_{n=0}^{+\infty} \lvert 0.5^{n} \rvert = \sum_{n=0}^{+\infty} 0.5^{n} = \frac{1}{1 - 0.5} = 2 \lt \infty\]

    和是有限的 \(2\)，所以绝对可和

    第四步：注意这里的结论强度。 同一个 \(X(z)\)，只因为收敛域不同，一个稳定、一个不稳定 —— 这就是为什么判稳定性时不能只看 \(X(z)\) 的表达式， 必须同时看极点的模与收敛域的形式 ⚠

    （d）补零能不能让无限长序列上机做 DFT。

    不能。 理由分三步说清：

    第一步：DFT 的定义式是对有限个样点求和： \(X[k] = \sum_{n=0}^{N-1} x(n) e^{-j2\pi kn/N}\)。 它要求输入是一段有限长数据，而且默认把它周期延拓。

    第二步：无限长序列 \(0.5^n u(n)\) 的尾部永远不为零 （虽然越来越小，但没有任何一项严格等于零）。 补零是在尾部接零，而这里根本没有「尾部」可以接 —— 补零的位置本身就是无穷远

    第三步：工程上的实际做法是截断： 取前 \(N\) 项 \(x(0), \dots, x(N-1)\)，把其余部分丢掉。 但这样做会引入两件事：

    操作 引入了什么 怎么补偿
    截断到 \(N\) 项 尾部被丢弃 ⇒ 泄漏，谱线被抹宽 ⚠ 选 \(N\) 使 \(0.5^N\) 足够小（如 \(0.5^{20} \approx 10^{-6}\)）✓
    补零到 \(M \gt N\) 点 只加密频率网格 ⚠ 不要指望它提高分辨率 ✓

    所以无限长序列「上机」的完整说法是： 先截断到足够长，再补零加密网格；截断的误差要单独说明

    例题 4：用 4 点 DFT 手算，并核对对称性¶

    题目：序列 \(x(0) = 2\)、\(x(1) = 1\)、\(x(2) = 0\)、\(x(3) = -1\)，其余为零。 求它的 4 点 DFT，并说明这个结果满足什么对称性质。

    思路

    直接按定义式 \(X[k] = \sum_{n=0}^{N-1} x(n)e^{-j2\pi kn/N}\)， 对 \(k = 0, 1, 2, 3\) 各算一遍。 指数项 \(e^{-j2\pi kn/4}\) 只取四个值：\(1, -j, -1, +j\)， 手算完全可行

    解答

    第一步：写出 \(N = 4\) 时的旋转因子。

    \[e^{-j2\pi k n/4} = \left( e^{-j\pi/2} \right)^{kn} = (-j)^{kn}\]

    所以四个因子分别是 \((-j)^0 = 1\)，\((-j)^1 = -j\)， \((-j)^2 = -1\)，\((-j)^3 = +j\)。

    第二步：\(k = 0\)。 四个因子全是 \(1\)：

    \[X[0] = 2 \cdot 1 + 1 \cdot 1 + 0 \cdot 1 + (-1) \cdot 1 = 2\]

    \(X[0]\) 就是所有样点之和，也叫直流分量。验证：\(2 + 1 + 0 - 1 = 2\)

    第三步：\(k = 1\)。 因子依次是 \(1, -j, -1, +j\)：

    \[X[1] = 2\cdot1 + 1\cdot(-j) + 0\cdot(-1) + (-1)\cdot(+j)\]

    逐项算：\(2\cdot1 = 2\)，\(1\cdot(-j) = -j\)，\(0\cdot(-1) = 0\)，\((-1)\cdot(+j) = -j\)。 合并实部与虚部：

    \[X[1] = 2 - j - j = 2 - 2j\]

    注意 \((-1)\cdot(+j) = -j\) 与 \(1\cdot(-j) = -j\) 同向相加， 所以虚部是 \(-2j\) 而不是 \(-j\)

    第四步：\(k = 2\)。 因子依次是 \(1, -1, 1, -1\)：

    \[X[2] = 2\cdot1 + 1\cdot(-1) + 0\cdot1 + (-1)\cdot(-1) = 2 - 1 + 0 + 1 = 2\]

    第五步：\(k = 3\)。 因子依次是 \(1, +j, -1, -j\)：

    \[X[3] = 2\cdot1 + 1\cdot(+j) + 0\cdot(-1) + (-1)\cdot(-j) = 2 + j + j = 2 + 2j\]

    第六步：整理成表。

    \(k\) \(X[k]\) \(\lvert X[k]\rvert\)
    \(0\) \(2\) \(2.000000\)
    \(1\) \(2 - 2j\) \(2.828427\)
    \(2\) \(2\) \(2.000000\)
    \(3\) \(2 + 2j\) \(2.828427\)

    幅度的算法：\(\lvert 2 - 2j\rvert = \sqrt{2^2 + (-2)^2} = \sqrt{8} = 2.828427\)

    第七步：核对对称性。 输入是实序列， 所以 DFT 必然满足共轭对称 \(X[N-k] = \overline{X[k]}\)。 检查 \(k = 1\) 与 \(k = 3\)：\(\overline{2-2j} = 2+2j\) ✓ 正好是 \(X[3]\)。

    注意：共轭对称不等于幅度完全对称 —— 幅度关于 \(k = N/2\) 对称（这里 \(N/2 = 2\)）， 上表里 \(\lvert X[1]\rvert = \lvert X[3]\rvert = 2.828427\)

    这道题顺便验证了「DFT 是 DTFT 的采样」： 把这段数据看成有限非周期序列，它的 DTFT 在 \(\Omega_k = 2\pi k/4\) 处的值就是上表的 \(\lvert X[k]\rvert\)

    自测¶

    Q1 一段 \(N = 200\) 点的实测数据，采样率是 \(f_s\)。 （a）它的频率分辨率是多少？ （b）把它补零到 \(800\) 点再做 DFT，分辨率提高了吗？ （c）如果要分辨两个相隔只有分辨率一半频率的谱峰，补零有用吗？

    提示

    分清两个词：频率网格间隔（补零能改变） 与频率分辨率（由观测时长决定，补零改变不了）

    解答

    （a）频率分辨率。

    \[\Delta f = \frac{f_s}{N}\]

    以归一化频率（周/样点）表示，就是 \(1/N = 1/200 = 0.0050\) 周/样点

    （b）补零到 \(800\) 点。

    频率网格间隔变成 \(1/800 = 0.00125\) 周/样点， 比原来细了 4 倍。但这是网格变密，不是分辨率提高

    原因：补零只是在数据尾部接上一串零， 它不改变 DTFT 曲线本身（DTFT 只由那 \(N\) 个真实样点决定）， 只是在同一条曲线上取了更多点。 曲线的「宽度」没有变化，两个靠得近的谱峰依然糊在一起

    （c）分辨相隔半个分辨率的两个谱峰。

    补零没有用。 真正能分辨的最小间隔由观测时长决定：

    \[\Delta f_{\min} = \frac{f_s}{N} = \frac{1}{N T_s}\]

    这个量正比于 \(\dfrac{1}{N T_s}\)，也就是观测的总时长。 两个相隔 \(0.5\Delta f\) 的谱峰，在一个观测窗内本来就不足以分开， 补零只是把这条糊在一起的曲线画得更细

    要真正分开它们，只有三条路：

    办法 原理 代价
    增加观测点数 \(N\)（时长不变则须提高 \(f_s\)） 直接减小 \(\Delta f\) 数据量变大
    延长观测时长 减小 \(\Delta f\) 需要更长的记录
    用高分辨率谱估计方法 用先验假设突破窗口限制 有模型风险

    Q2 一个以 \(N = 16\) 为周期的离散序列，对它做 16 点 DFT。 （a）谱是离散的还是连续的？ （b）谱是周期的还是非周期的？ （c）把结果与「同一段数据当成非周期序列」时的 DTFT 比较，两者关系是什么？

    提示

    回到第一节的两条对偶关系：周期 ⟺ 离散，离散 ⟺ 周期。 时域同时满足两条，频域就同时满足两条

    解答

    （a）离散还是连续？

    离散。 依据关系一：时域周期性 ⟺ 频域离散。 时域以 \(N = 16\) 为周期，频域就是 \(16\) 根离散谱线

    （b）周期还是非周期？

    周期。 依据关系二：时域离散 ⟺ 频域周期。 时域是离散序列，所以频域以 \(2\pi\) 为周期重复

    （c）与 DTFT 的关系。

    两者是采样关系：把这段 16 点数据看成非周期有限序列时， 它的 DTFT 是一条连续曲线； 对它做 16 点 DFT，得到的是这条连续曲线在 16 个等间隔频率点上的取值

    频点位置是 \(\Omega_k = \dfrac{2\pi k}{16}\)，\(k = 0, 1, \dots, 15\)。 所以 DFT 的输出与 DTFT 在这些点上的值逐点相等（只差浮点舍入）

    这也解释了为什么「离散 + 周期」这一格是唯一能上机计算的一格： 时域周期让频域离散（只需要存有限个数）， 时域离散让频域周期（一个周期内的数就够了）。

    Q3 判断对错并说明理由： 「DTFT 是连续函数，计算机算不了，所以工程上没有必要了解它， 直接用 DFT 就行了。」

    提示

    想两个问题：DFT 到底在算谁？ 如果不知道 DTFT，能不能解释 DFT 结果里的泄漏和栅栏效应？✓

    解答

    这句话前半句对、后半句错，而且错得很有害。

    分句 对错 说明
    「DTFT 是连续函数，计算机算不了」 ✓ 对 频域是连续统，无法用有限个内存表示
    「工程上没有必要了解它」 ✗ 错 不知道 DTFT 就无法解释 DFT 结果的偏差来源 ⚠
    「直接用 DFT 就行了」 ✗ 错 DFT 是 DTFT 的采样，采样必然丢信息 ⚠

    为什么「了解 DTFT」是必需的：

    你不知道 DTFT 时 你知道 DTFT 后
    看到主峰旁边有旁瓣，怀疑信号有问题 知道那是截断（泄漏）的产物 ✓
    看到峰值频率比真实值偏了一格 知道那是栅栏效应，可以补零缓解 ✓
    以为补零能提高分辨率 知道补零只是加密网格，分辨率由观测时长决定 ✓
    以为「FFT 谱」是信号的谱 知道它只是真谱（DTFT）的采样 ✓

    正确的关系是三条。

    量 是什么 上机能算吗
    DTFT 离散非周期序列的真谱，连续函数 不能直接算 ✓
    DFT DTFT 在 \(N\) 个等间隔点上的采样 能算 ✓
    FFT 计算 DFT 的快速算法 能算，且快 ✓

    一句话结论： 「只用 DFT」在操作上没有问题，「不了解 DTFT」在判断上会出问题。 DFT 给你数字，DTFT 给你解释这些数字为什么长这样

    Q4 有人给出一个 \(X(z) = \dfrac{1}{1 - 0.5z^{-1}}\)，说「它的逆变换是 \(0.5^n u(n)\)」。 （a）这个说法缺了什么？ （b）缺了它会出什么问题？ （c）补上之后，怎么判系统稳定？

    提示

    想 4.2 节那两个序列：一个右边、一个左边，代数表达式完全相同。 再想 例题 3 第（c）问：稳定性和 DTFT 存在与否，看的都是同一件事

    解答

    （a）缺了收敛域 ROC。

    完整的写法应该是

    \[X(z) = \frac{1}{1 - 0.5z^{-1}}, \qquad \text{ROC}: \lvert z\rvert \gt 0.5\]

    （b）缺 ROC 会出什么问题。

    会得到两个都正确、但完全不同的答案

    给出的 ROC 逆变换 序列类型
    \(\lvert z\rvert \gt 0.5\) \(0.5^n u(n)\) 右边序列（从 \(n=0\) 向右延伸）✓
    \(\lvert z\rvert \lt 0.5\) \(-0.5^n u(-n-1)\) 左边序列（从 \(n=-1\) 向左延伸）✓

    两个序列在时域上一个朝右、一个朝左， 是完全不同的信号；但它们的 Z 变换代数化简后一模一样。

    所以「缺了 ROC」不是书写不规范，而是答案不唯一： 你给出的那句话，可以被读成两种意思

    （c）怎么判稳定性。

    判据只有一条：看单位圆 \(\lvert z\rvert = 1\) 是否落在 ROC 内。

    ROC 单位圆在 ROC 内吗 系统稳定吗
    \(\lvert z\rvert \gt 0.5\) 是（\(1 \gt 0.5\)）✓ 稳定 ✓
    \(\lvert z\rvert \lt 0.5\) 否（\(1 \lt 0.5\) 不成立）✗ 不稳定 ⚠

    注意：同一个 \(X(z)\)，只因为 ROC 不同，一个稳定、一个不稳定。 这就是为什么判稳定性时不能只看 \(X(z)\) 的表达式， 必须同时看极点的位置和 ROC 的形式 ✓

    判据的由来：BIBO 稳定要求脉冲响应绝对可和， 而绝对可和正是「单位圆落在 ROC 内」的含义。 所以「单位圆在 ROC 内」这一个几何条件， 同时等价于「稳定」与「DTFT 存在」

    一页速查：把这一页压成三步¶

    整页内容可以压成一个三步流程。考试时按这三步走，基本不会选错变换：

    第一步：给信号定位。 只问两个问题 —— 时间轴是连续的还是离散的？在时间上重复还是不重复？ 这两个答案直接把信号放进 2×2 表的一个格子里， 变换的名字就唯一确定了（FS / FT / DFT / DTFT）✓

    第二步：查这个变换的代价。 每个变换都自带一条代价： FS 要求 Dirichlet 条件；FT 要求全轴绝对可积； DTFT 要求谱是连续的、存不下；DFT 要求先周期延拓； Z 变换与拉普拉斯变换要求同时给出收敛域 代价就是「这个变换在这里可不可信」的答案。

    第三步：检查有没有隐藏假设。 这一步最容易漏。 三条最常见的隐藏假设是：

    隐藏假设 它藏在哪一步 破了会怎样
    「这段数据是周期的」 用 DFT 的时候 接缝处凭空出现跳变，泄漏由此而来 ⚠
    「\(X(z)\) 的表达式就是全部信息」 用 Z 变换反求序列时 答案不唯一，可能整体反了 ⚠
    「补零能提高分辨率」 想要分辨两个靠得近的峰时 网格细了，峰还是糊在一起 ⚠

    这三条与第一节那三个「看着差不多、实际差很远」的情形一一对应 —— 全页的问题从它们开始，也到它们结束。

    小结¶

    要记住的 为什么
    时域周期性 ⟺ 频域离散 周期信号的所有频率都是基频整数倍，中间没有成分 ✓
    时域离散 ⟺ 频域周期 \(e^{-j2\pi n}\) 因 \(n\) 为整数而恒等于 1 ✓
    两条关系合起来 → DFT 只有「离散 + 周期」这一格两边都离散，计算机才能精确表示 ✓
    信号属性四问：连续/离散、周期/非周期、能量/功率、有限长/无限长 属性定下来，变换就唯一确定了 ✓
    FS 用于连续周期信号 周期给出离散线谱，功率性质对应「一个周期内可积」✓
    FT 要求全轴绝对可积 功率信号（正弦、直流）严格来说不满足，要用功率谱描述 ⚠
    令 \(s = j\omega\) 得 FT，令 \(z = e^{j\Omega}\) 得 DTFT 两条退化链的几何含义分别是虚轴与单位圆 ✓
    DTFT 是离散序列的真谱 它是连续函数，计算机存不下，只能取样 ✓
    DFT 是 DTFT 的采样 采样必然丢信息，泄漏与栅栏效应由此而来 ⚠
    Z 变换必须同时给出 ROC 同一个 \(X(z)\) 配不同 ROC 会给出两个完全不同的序列 ⚠
    单位圆在 ROC 内 ⟺ 稳定 ⟺ DTFT 存在 绝对可和、稳定、单位圆落在 ROC 内，三者是同一件事 ✓
    DTFT 是真相，DFT 是抽样，FFT 是算法 三者不是三个变换，是一件事的三个层次 ✓
    补零只加密频率网格，不提高分辨率 分辨率由观测时长决定，补零不增加任何新信息 ⚠
    泄漏来自截断，不来自信号 截整周期可完全消除；加窗可压制旁瓣 ✓
    混叠来自采样把频率轴折叠，事后无法恢复 只能靠采样前抗混叠滤波预防 ⚠
    傅里叶级数在间断点收敛到左右极限的平均值 不是 \(x(t_0)\)，也不是任何单侧极限 ✓
