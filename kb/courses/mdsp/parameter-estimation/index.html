    前面几页把「随机信号」这件事在数学上定义清楚了。把结论摆在一起：

    已经解决的问题 结论
    用什么描述一个随机过程 均值 \(\mu\) 与自相关 \(R(m)\)（更一般地，一组参数 \(\theta\)）
    平稳性带来什么好处 统计规律不随时间推移而改变
    遍历性带来什么好处 一条足够长的记录的时间统计，等于全体的系综统计

    但这里有一个迟迟没有正面回答的问题

    前面写的 \(\mu\) 和 \(R(m)\)，定义都建立在系综上 —— 也就是说，要算出它们，你得同时拥有无穷多条可能发生的记录， 而每一时刻都要在所有记录上做平均。

    实际上你手里从来不是「无穷多条记录」，而是「有限长的一条」

    定义里假设的 实际能拿到的
    数据量 无穷多条记录（系综） 一条记录，\(N\) 个点
    平均方式 在所有可能记录上求期望 在 \(N\) 个时间点上求平均
    得到的结果 真正的 \(\mu\)、\(R(m)\) 一个带误差的估计值 ⚠

    于是整门课的工作，可以概括成一句话：

    用有限的观测，去估计那些永远无法真正知道的统计参数。

    这一页就讲这件事：怎么估、估得准不准、样本量够不够。

    这一页的核心问题

    这一页不教你「怎么算一个数」——

    那是 点估计 已经讲过的事。

    这一页解决的是信号处理特有的三个追问：

    追问 本页回答
    从一条有限长的数据里估统计量，估出来的东西可信吗 无偏性、有效性、一致性
    样本量 \(N\) 要多大才够 \(\operatorname{Var} \propto 1/N\)，精度只按 \(\sqrt N\) 增长 ⚠
    估计量必须无偏吗 不一定，偏差-方差权衡常常允许有偏 ✓

    一、为什么「参数估计」是这门课的核心问题¶

    1.1 先说清「参数」在这里指什么¶

    在前面的页里，一个广义平稳随机过程被这样描述：

    \[ \mu = E[X_n], \qquad R(m) = E[X_{n+m}X_n^{*}] \]

    符号约定（后面一直沿用）：

    符号 含义 取值范围
    \(X_n\) 时刻 \(n\) 上的随机变量（大写表示随机） 复数或实数
    \(x_n\) 时刻 \(n\) 上实际观测到的数值（小写表示已发生） 复数或实数
    \(N\) 一条记录里的样本个数 正整数
    \(\mu\) 均值，真值，未知 实数或复数
    \(R(m)\) 滞后 \(m\) 上的自相关，真值，未知 一般取复数
    \(\theta\) 上面这些未知量的统称，叫参数 一个数或一个向量
    \(\hat\theta\) 参数的估计量（带 \(\hat{}\) 号） 一个随机变量

    「带 \(\hat{}\) 号」这件事是理解本页的关键：

    \(\hat\theta\) 是由观测数据算出来的，而数据是随机的， 所以 \(\hat\theta\) 本身也是一个随机变量

    换个数据段再算一次，\(\hat\theta\) 的值就变了。 正因为它是随机变量，才谈得上「它的期望是多少」「它的方差有多大」—— 这两个问题分别对应无偏性和有效性。

    这个「估计量是随机变量」的观念， 点估计 一页已经详细讲过， 这里只提醒一句就过去：

    术语 写法 性质
    参数 \(\theta\) 固定的真值，只是不知道
    估计量 \(\hat\theta = g(X_1,\dots,X_N)\) 随机变量，有期望有方差
    估计值 \(\hat\theta_{\text{观测}}\) 代入具体数据后的一个数

    本页所有的性质（无偏、有效、一致）都是针对「估计量」说的， 不是针对「估计值」说的 ✓ 这一点混淆了，后面全会乱。

    1.2 真实参数永远不知道 —— 这是全部麻烦的来源¶

    下面这句话请务必记牢：

    \(\mu\) 和 \(R(m)\) 是「真值」，但真值永远不可观测。

    为什么：因为要得到 \(E[X_n]\)，你需要对所有可能发生的记录做平均， 而现实中只发生了其中一条。

    所以「参数估计」这件事在逻辑上有一个尴尬之处：

    你想做的事 现实给的限制
    算出 \(\hat\theta\) 与真值 \(\theta\) 的差 不知道 \(\theta\)，算不出这个差 ⚠
    评价「估计得好不好」 只能靠理论推导（假设模型）或重复实验

    这也正是本页后面所有代码的做法：

    既然不知道真值就没法评价，那就先用电脑造出已知真值的数据， 再把估计量跑很多遍，看它的表现。 这种「自己造已知答案的数据」的办法叫蒙特卡洛实验， 是检验估计量性质的标准手段

    1.3 一张表看清整门课在干什么¶

    这张表是全页的骨架，后面每一节都是在填它的细节：

    二、估计量怎么来（一句话带过）¶

    从数据到估计量，有好几条路， 点估计 一页已经把它们讲透了：

    方法 思想 详见

    最大似然 选使观测数据最可能发生的参数 最大似然估计
    贝叶斯 把参数当随机量，用数据更新先验 贝叶斯定理

    本课程课件里也把这几条路都列了出来，而且给出的一条特别有用的结论：

    矩量法的估计是无偏的，也是一致的。

    为什么值得把这句话单独拎出来： 因为「无偏」和「一致」这两个性质，在很多估计方法里都要单独去证明， 而矩量法自动两者都满足

    课件的证明思路（一阶矩的情形，实际上任意阶矩都一样）：

    被估计的参数是理论矩 \(\mu_r = E[X^r]\)， 估计量是样本矩 \(\hat m_r = \frac1N\sum_{i=1}^N X_i^r\)（各观测独立、同分布）。于是

    \[ E[\hat m_r] = E\!\left[\frac1N\sum_{i=1}^{N}X_i^r\right] = \frac1N\sum_{i=1}^{N}E[X_i^r] = \frac1N\sum_{i=1}^{N}\mu_r = \frac1N\cdot N\mu_r = \mu_r \]

    每一步的理由（不跳步）：

    步骤 依据
    把 \(E[\cdot]\) 移到求和号内 期望的线性性
    \(E[X_i^r] = \mu_r\) 对每个 \(i\) 都成立 各个观测同分布
    \(\frac1N \cdot N\mu_r = \mu_r\) 求和恰好 \(N\) 项，都是 \(\mu_r\)

    结论：\(E[\hat m_r] = \mu_r\)，所以样本矩是理论矩的无偏估计

    注意这里其实暗含两个假设：各观测独立，且同分布。 真实信号往往两个都不严格满足（有相关性、有非平稳）， 这正是一开始那个「\(\text{i.i.d.}\) 假设不成立」的担心 后面「实际应用的注意点」一节会回来处理它。

    三、无偏性：平均而言偏不偏¶

    3.1 定义与「偏差」¶

    定义（无偏）：估计量 \(\hat\theta\) 称为无偏的， 如果它的期望等于被估计参数的真值：

    \[ E[\hat\theta] = \theta \qquad \text{对参数的所有取值都成立} \]

    「对参数的所有取值都成立」这半句很重要： 不是「对某个特定的 \(\theta\) 无偏」，而是对每一个可能的 \(\theta\) 都无偏。 否则换个真值估计量就系统偏了，那这个「无偏」没有意义。

    偏差（bias）的定义：

    \[ \operatorname{bias}(\hat\theta) = E[\hat\theta] - \theta \]

    偏差 = 「这个估计量反复用、长期平均」得到的值， 与真值差多少。

    偏差的符号 含义 说法
    \(\operatorname{bias} \gt 0\) 长期平均偏高 高估
    \(\operatorname{bias} = 0\) 长期平均正好 无偏 ✓
    \(\operatorname{bias} \lt 0\) 长期平均偏低 低估

    一个容易搞混的点

    偏差是估计量的期望减去真值，不是「某一次估计值减去真值」。

    说法 对不对
    「这次估出来 4.9，真值 5.0，所以偏差 \(-0.1\)」 错 ✗（这叫残差或误差）
    「把这个估计量用一万次，平均得 4.95，真值 5.0，所以偏差 \(-0.05\)」 对 ✓

    偏差是估计量的性质，误差是一次估计的结果

    3.2 例一：样本均值是均值的无偏估计¶

    这是最干净的例子，但推导一步都不能省。

    设定：\(X_1,\dots,X_N\) 独立同分布，\(E[X_n] = \mu\)，\(\operatorname{Var}(X_n) = \sigma^2\)。 （注意：没有假定高斯分布，任意分布都成立 ✓）

    估计量：

    \[ \hat\mu = \frac1N\sum_{n=1}^{N}X_n \]

    第一步：把期望送进求和号

    \[ E[\hat\mu] = E\!\left[\frac1N\sum_{n=1}^{N}X_n\right] \]

    \(\frac1N\) 是常数，可以提到期望外面（期望的齐次性）：

    \[ = \frac1N\,E\!\left[\sum_{n=1}^{N}X_n\right] \]

    第二步：和号的期望等于期望的和

    \[ = \frac1N\sum_{n=1}^{N}E[X_n] \]

    第三步：代入 \(E[X_n] = \mu\)

    \[ = \frac1N\sum_{n=1}^{N}\mu = \frac1N\cdot N\mu = \mu \]

    第四步：结论

    \[ E[\hat\mu] = \mu \quad\Longrightarrow\quad \operatorname{bias}(\hat\mu) = \mu - \mu = 0 \]

    样本均值是无偏的

    这里用到「同分布」了吗：用到了。 第三步里每个 \(E[X_n]\) 都等于同一个 \(\mu\) 才敢这么写。 如果各个观测的均值不一样（非平稳），这步就不成立

    顺带一个稍后会用的结果（独立性在这里第一次用上）：

    \[ \operatorname{Var}(\hat\mu) = \operatorname{Var}\!\left(\frac1N\sum_{n=1}^{N}X_n\right) = \frac{1}{N^2}\sum_{n=1}^{N}\operatorname{Var}(X_n) = \frac{1}{N^2}\cdot N\sigma^2 = \frac{\sigma^2}{N} \]

    中间那步「和的方差等于方差的和」要求各 \(X_n\) 相互独立 不独立时还要加上各对协方差项 —— 这是个重要的伏笔， 后面讲自相关估计时就会撞上它。

    把四步推导的结论集中记一次：

    结论 用到的条件
    \(\operatorname{bias}(\hat\mu)=0\) 同分布（保证每个 \(E[X_n]\) 都是同一个 \(\mu\)）
    \(\operatorname{Var}(\hat\mu)=\sigma^2/N\) 相互独立（和方差 = 方差之和）
    二者一起给出 MSE \(=\sigma^2/N\) 无偏时 MSE 与方差重合

    这个结论说明什么：样本均值把「无偏」这件事免费做到了 —— 不需要知道 \(\sigma\)，也不需要 \(N\) 足够大，只要同分布，偏差就恒等于 \(0\)。 代价全部落在方差上：\(\sigma^2/N\) 就是我们要为「有限样本」付的钱

    课件的原话也要注意：课件说「矩量估计既是无偏估计，也是一致估计」—— 本页这个例子就是它在一阶矩上的具体化。

    3.2.1 用具体数字手算一遍 \(\operatorname{Var}(\hat\mu)\)¶

    为什么还要手算：考试考的正是这种不带 numpy 的代入。 设真实参数 \(\mu = 5\)、\(\sigma = 2\)、样本量 \(N = 20\)，则

    \[ \operatorname{Var}(\hat\mu) = \frac{\sigma^2}{N} = \frac{2^2}{20} = \frac{4}{20} = 0.2 \]

    开方得标准差：

    \[ \sigma_{\hat\mu} = \sqrt{0.2} \approx 0.4472 \]

    这个数后面还要用，它是「一次估计的典型误差量级」：

    \[ \lvert \hat\mu - \mu \rvert \lesssim 0.4472 \quad\text{（大约七成的概率）} \]

    这个结论说明什么：\(\sigma_{\hat\mu}=0.4472\) 与 \(\sigma=2\) 相除， 正好是 \(1/\sqrt N = 1/\sqrt{20} \approx 0.2236\) 倍 —— 样本量 \(N\) 每翻 4 倍，误差才减半。 这就是「精度只按 \(\sqrt N\) 增长」的含义，后面第八节会专门推它。

    换成 \(N=80\) 再算一次，感受这个规律：

    样本量 \(N\) \(\sigma^2/N\) \(\sigma_{\hat\mu}\) 相对 \(N=20\) 缩小为
    \(20\) \(4/20 = 0.2\) \(0.4472\) \(1\) 倍
    \(80\) \(4/80 = 0.05\) \(0.2236\) \(1/2\) 倍 ✓
    \(320\) \(4/320 = 0.0125\) \(0.1118\) \(1/4\) 倍

    怎么读这张表：样本量变成 \(4\) 倍、\(16\) 倍， 误差却只缩小到 \(1/2\)、\(1/4\) —— 不是线性下降 「多采数据」的收益是递减的，这正是「加数据不是万能」的算术根源。

    3.3 例二：样本方差除以 N 有偏，除以 N-1 才无偏¶

    这个例子的重要性远超它本身 —— 它解释了一个几乎所有用过统计软件的人都见过的现象： 为什么求方差时那个参数叫 ddof=1

    设定：同样的 \(X_1,\dots,X_N\) 独立同分布， \(E[X_n] = \mu\)，\(\operatorname{Var}(X_n) = \sigma^2\)，两者都未知。 要估计的是 \(\sigma^2\)。

    两个候选估计量：

    \[ \hat\sigma_N^2 = \frac1N\sum_{n=1}^{N}\left(X_n - \bar X\right)^2, \qquad S^2 = \frac{1}{N-1}\sum_{n=1}^{N}\left(X_n - \bar X\right)^2 \]

    两个估计量用的数据完全一样，都和 \(N-1\) 倍的差别只在分母上。 下面把它们分别的期望算出来。

    第一步：先把离差平方和改写一下

    记 \(Y_n = X_n - \mu\)（把真均值减掉，于是 \(E[Y_n] = 0\)）。

    注意 \(\bar X - \mu = \frac1N\sum(X_n - \mu) = \bar Y\)，所以

    \[ X_n - \bar X = (X_n - \mu) - (\bar X - \mu) = Y_n - \bar Y \]

    第二步：展开平方和

    \[ \sum_{n=1}^{N}(Y_n-\bar Y)^2 = \sum_{n=1}^{N}\left(Y_n^2 - 2Y_n\bar Y + \bar Y^2\right) \]

    把求和逐项拆开（求和是线性的）：

    \[ = \sum_{n=1}^{N}Y_n^2 - 2\bar Y\sum_{n=1}^{N}Y_n + \sum_{n=1}^{N}\bar Y^2 \]

    第三步：消掉中间项

    注意 \(\sum_{n=1}^{N}Y_n = N\bar Y\)，代入中间项：

    \[ -2\bar Y\cdot N\bar Y = -2N\bar Y^2 \]

    最后一项是 \(N\) 个相同的 \(\bar Y^2\) 相加：

    \[ \sum_{n=1}^{N}\bar Y^2 = N\bar Y^2 \]

    两项合并：\(-2N\bar Y^2 + N\bar Y^2 = -N\bar Y^2\)。于是得到恒等式：

    \[ \sum_{n=1}^{N}\left(X_n-\bar X\right)^2 = \sum_{n=1}^{N}Y_n^2 - N\bar Y^2 \]

    第四步：两边取期望

    第一项：

    \[ E\!\left[\sum_{n=1}^{N}Y_n^2\right] = \sum_{n=1}^{N}E[Y_n^2] = \sum_{n=1}^{N}\operatorname{Var}(Y_n) = \sum_{n=1}^{N}\sigma^2 = N\sigma^2 \]

    这里用了 \(E[Y_n] = 0\)，所以 \(E[Y_n^2] = \operatorname{Var}(Y_n)\)。

    第二项：

    \[ E\!\left[N\bar Y^2\right] = N\,E[\bar Y^2] = N\operatorname{Var}(\bar Y) = N\cdot\frac{\sigma^2}{N} = \sigma^2 \]

    （\(\bar Y = \bar X - \mu\) 的均值是 \(0\)，所以 \(E[\bar Y^2] = \operatorname{Var}(\bar Y)\)； 再代入 \(\operatorname{Var}(\bar X) = \sigma^2/N\)。）

    合起来：

    \[ E\!\left[\sum_{n=1}^{N}\left(X_n-\bar X\right)^2\right] = N\sigma^2 - \sigma^2 = (N-1)\sigma^2 \]

    第五步：代回两个估计量

    \[ E[\hat\sigma_N^2] = \frac1N\cdot(N-1)\sigma^2 = \frac{N-1}{N}\sigma^2 \]
    \[ E[S^2] = \frac{1}{N-1}\cdot(N-1)\sigma^2 = \sigma^2 \]

    结论：

    估计量 分母 期望 偏差 评价
    \(\hat\sigma_N^2\) \(N\) \(\frac{N-1}{N}\sigma^2\) \(-\dfrac{\sigma^2}{N}\) 有偏（偏低） ✗
    \(S^2\) \(N-1\) \(\sigma^2\) \(0\) 无偏 ✓

    这就是「除以分母看起来更怪的 \(N-1\)」的全部理由

    为什么除以 \(N\) 会偏低（直观理解）： 因为式子里用的是 \(\bar X\) 而不是真正的 \(\mu\)。 \(\bar X\) 是从这批数据自己算出来的，它天然就落在这批数据中间， 所以每个点到 \(\bar X\) 的距离，都会比它们到真 \(\mu\) 的距离平均起来小一点

    \[ \sum (X_n - \bar X)^2 \lt \sum (X_n - \mu)^2 \quad\text{（平均而言）} \]

    这正是 \(E[\sum(X_n-\bar X)^2] = (N-1)\sigma^2\) 而不是 \(N\sigma^2\) 的来源 「用数据自己算出来的中心会偏袒这批数据」，这个洞见在后面很多地方会再出现。

    注意偏差 \(-\sigma^2/N\) 随 \(N\) 增大而变小： \(N\) 很大时两个估计量几乎一样。 课件也正是据此说明，有偏但渐近无偏的估计是可以接受的

    算一个具体数字：取 \(\sigma^2 = 4\)，\(N = 8\)。

    \[ E[\hat\sigma_N^2] = \frac{7}{8}\times 4 = 3.5, \qquad E[S^2] = 4 \]

    偏差分别是 \(-0.5\) 和 \(0\)。下面用 \(N=8\)、\(\sigma^2=4\) 手算核对这两个偏差。

    先算除以 \(N\) 的那一个。它的偏差公式是

    \[ \operatorname{bias}(\hat\sigma_N^2) = E[\hat\sigma_N^2] - \sigma^2 \]

    第一步：代入期望的闭式结果 \(E[\hat\sigma_N^2]=\dfrac{N-1}{N}\sigma^2\)：

    \[ E[\hat\sigma_N^2] = \frac{8-1}{8}\times 4 = \frac{7}{8}\times 4 = 3.5 \]

    第二步：减去真值：

    \[ \operatorname{bias}(\hat\sigma_N^2) = 3.5 - 4 = -0.5 \]

    再算除以 \(N-1\) 的那一个：

    \[ E[S^2] = \sigma^2 = 4 \quad\Longrightarrow\quad \operatorname{bias}(S^2) = 4 - 4 = 0 \]

    这个结论说明什么：偏差 \(\dfrac{N-1}{N}\sigma^2 - \sigma^2 = -\dfrac{\sigma^2}{N}\) 不含未知参数以外的东西，所以只要 \(N\to\infty\)，偏差就趋于 \(0\) —— 这就是「渐近无偏」的算术含义。

    手算对照表（把原来扫参数的代码换成这张表）：

    样本量 \(N\) \(\hat\sigma_N^2\) 的期望 \(\hat\sigma_N^2\) 的偏差 \(S^2\) 的偏差 偏差占比 \(1/N\)
    \(4\) \(3\times 4/4 = 3.0\) \(-1.0\) \(0\) \(25\%\)
    \(8\) \(7\times 4/8 = 3.5\) \(-0.5\) \(0\) \(12.5\%\)
    \(16\) \(15\times 4/16 = 3.75\) \(-0.25\) \(0\) \(6.25\%\)
    \(64\) \(63\times 4/64 = 3.9375\) \(-0.0625\) \(0\) \(1.5625\%\)

    怎么读这张表：\(N\) 每翻一倍，偏差就减半， 但永远不为 \(0\) —— 所以 \(\hat\sigma_N^2\) 是无偏的渐近版本， 而 \(S^2\) 对任何有限的 \(N\) 都严格无偏

    除以 N 的版本虽然「有偏」，却不是坏估计量

    这一点常被误解，但课件明确说过：

    在许多情况下，一个有偏但渐近无偏的估计， 具有比无偏估计好得多的分析和计算性质。

    具体到方差估计，两者的表现是这样的：

    比较项 \(\hat\sigma_N^2\)（除以 \(N\)） \(S^2\)（除以 \(N-1\)）
    偏差 \(-\sigma^2/N\) ✗ \(0\) ✓
    方差 略小 ✓ 略大
    均方误差 略小 ✓ 略大
    渐近行为 两者趋同 两者趋同

    所以「有偏」不等于「差」 —— 它只是说「长期平均不等于真值」， 但它的波动更小，一次估计反而可能更接近真值

    这就是 4.2 节要引出均方误差（MSE）的原因

    工程上的选择：

    场景 推荐
    需要严格无偏（如方差分解、ANOVA） \(S^2\)，即除以 \(N-1\) ✓
    只看「一次估计准不准」 差别很小，任选
    信号处理里要接 FFT 常取 \(1/N\)，因为它是一个可变换的数列 ✓

    ddof 这个参数的由来

    很多数值库求方差时会有一个参数控制分母：

    设置 分母 结果
    ddof=0（默认） \(N\) 有偏，偏低
    ddof=1 \(N-1\) 无偏 ✓

    ddof 的意思是「delta degrees of freedom」，即「自由度的扣减量」 —— 分母是 \(N - \text{ddof}\)。

    为什么恰好要扣 \(1\) 个自由度： 因为算离差平方和之前，先用了这批数据算出 \(\bar X\)。 一旦 \(\bar X\) 定下来，这 \(N\) 个离差 \((X_1-\bar X),\dots,(X_N-\bar X)\) 就不再彼此独立了 —— 它们的和恒等于 \(0\)：

    \[ \sum_{n=1}^{N}(X_n - \bar X) = 0 \]

    这个约束吃掉了一个自由度：知道了前 \(N-1\) 个离差， 最后一个可以由「和为 \(0\)」推出来。 所以真正独立的离差只有 \(N-1\) 个

    这也解释了一个常见的困惑：为什么单个数据点时不能算方差。 \(N = 1\) 时 \(\bar X = X_1\)，离差恒为 \(0\)， 除以 \(N-1 = 0\) 还会除零

    四、有效性：波动大不大¶

    无偏只管「平均对不对」，完全不管「单次能不能靠得住」。

    看两个极端的估计量：

    估计量 期望 说明
    \(\hat\theta_1 = \bar X\) \(\mu\) 无偏 ✓
    \(\hat\theta_2\)：以极大概率给出 \(\mu + 1000\)，极小概率给出极小的数 也能凑成 \(\mu\) 无偏但毫无用处 ✗

    所以无偏远远不够。第二个标准就是管「波动」的。

    定义（有效性）：两个估计量都无偏时， 方差更小的那个更有效。

    \[ \operatorname{Var}(\hat\theta_1) \lt \operatorname{Var}(\hat\theta_2) \quad\Longrightarrow\quad \hat\theta_1 \text{ 比 } \hat\theta_2 \text{ 更有效} \]

    把这个估计量反复用很多次， 结果散布得越窄越有效

    「相对效率」的定义（用比值比较，比绝对方差更清楚）：

    \[ \text{相对效率} = \frac{\operatorname{Var}(\hat\theta_2)}{\operatorname{Var}(\hat\theta_1)} \]

    比值为 \(2\) 的含义：想达到同样的精度，不如用 \(\hat\theta_2\) 多采一倍数据

    4.1 例：两个无偏估计量比方差¶

    构造一个最直观的对比：同样是估计均值 \(\mu\)， 但一个用全部样本，另一个只用一半样本。

    \[ A = \frac1N\sum_{n=1}^{N}X_n, \qquad B = \frac{2}{N}\sum_{n=1}^{N/2}X_n \]

    （假设 \(N\) 为偶数，\(B\) 就是「只用前一半数据的均值」。）

    \(B\) 无偏吗：

    \[ E[B] = \frac{2}{N}\sum_{n=1}^{N/2}E[X_n] = \frac{2}{N}\cdot\frac{N}{2}\mu = \mu \]

    无偏

    两个的方差：

    \[ \operatorname{Var}(A) = \frac{\sigma^2}{N}, \qquad \operatorname{Var}(B) = \frac{4}{N^2}\cdot\frac{N}{2}\sigma^2 = \frac{2\sigma^2}{N} \]

    比较：

    \[ \frac{\operatorname{Var}(B)}{\operatorname{Var}(A)} = 2 \]

    结论：\(A\) 更有效，恰好比 \(B\) 有效一倍

    这个结果其实非常朴素：多用了一倍的数据，方差就减半。 但它给出了一个可以推广的规律 —— 方差与用到的样本数成反比， 后面第八节会把这条规律写成通用的形式

    把手算做完整（设 \(\sigma=2\)、\(N=40\)）：

    \[ \operatorname{Var}(A) = \frac{\sigma^2}{N} = \frac{4}{40} = 0.1 \]
    \[ \operatorname{Var}(B) = \frac{\sigma^2}{N/2} = \frac{4}{20} = 0.2 \]

    再算相对有效性，定义（\(A\) 相对 \(B\) 的效率）：

    \[ e(A,B) = \frac{\operatorname{Var}(B)}{\operatorname{Var}(A)} = \frac{0.2}{0.1} = 2 \]

    这个结论说明什么：\(e(A,B)=2>1\)，判定 \(A\) 比 \(B\) 有效。 而「有效一倍」这件事不依赖 \(R\) 次重复实验， 它是两个闭式方差的比值 —— 手算就能得到，不需要仿真

    为什么「方差小的更有效」需要单独定义： 因为两个估计量可能都无偏，也就是期望一样， 此时能区分它们的只剩下波动。方差越小， 估计值落在真值附近的概率越大，也就越「值钱」。

    无偏与有效的手算对照表（原来扫参数的代码换成这张表）：

    估计量 用到的样本数 偏差 \(\operatorname{Var}\) 相对效率
    \(A\) \(N = 40\) \(0\) \(0.1\) \(2\) ✓
    \(B\) \(N/2 = 20\) \(0\) \(0.2\) \(1\)
    \(C\)（只用 \(5\) 个点） \(5\) \(0\) \(0.8\) \(0.25\) ⚠

    怎么读这张表：三个估计量偏差全是 \(0\)， 光看无偏性完全分不出高下； 一旦看方差，差距立刻显现 —— \(C\) 的方差是 \(A\) 的 \(8\) 倍，因此最不有效

    4.2 「无偏」和「有效」可能冲突¶

    到这里为止，两个标准看起来配合得很好：先挑出无偏的，再挑方差最小的。 但现实里会出现一个尴尬的局面

    情形 偏差 方差 该选谁
    无偏 + 小方差 \(0\) 小 毫无疑问选它 ✓
    无偏 + 大方差 \(0\) 大 犹豫
    有偏 + 极小方差 不为 \(0\) 极小 可能反而更好 ✓

    关键的问题是这个：既然偏差和方差都要小， 那有没有一个量能把两者合成一个数，直接比大小？

    有，就是均方误差：

    \[ \text{MSE}(\hat\theta) = E\!\left[(\hat\theta - \theta)^2\right] \]

    它的意义很自然：\(\hat\theta\) 离真值 \(\theta\) 的平均平方距离。 不管这个距离是「系统偏出来的」还是「随机抖出来的」，它都算在里面

    而且它有一个漂亮的分解（下一节完整推导）：

    \[ \text{MSE}(\hat\theta) = \operatorname{bias}^2(\hat\theta) + \operatorname{Var}(\hat\theta) \]

    所以本页接下来的顺序是： 先把一致性讲完（它是第三个标准）， 再用一节把 MSE 讲透，最后用它来重新审视前两个标准

    五、一致性：数据多了会不会收敛¶

    5.1 定义¶

    定义（一致）：估计量 \(\hat\theta_N\) 称为一致的， 如果观测样本数 \(N\) 趋向无穷大时，估计量依概率收敛于真值：

    \[ \lim_{N\to\infty} P\!\left(\left|\hat\theta_N - \theta\right| \gt \varepsilon\right) = 0 \qquad \text{对任意 } \varepsilon \gt 0 \text{ 成立} \]

    符号先定义清楚：

    符号 含义
    \(\hat\theta_N\) 用 \(N\) 个样本算出来的估计量（强调它随 \(N\) 变化）
    \(\varepsilon\) 任意一个正的小量，代表「允许多大的偏差」
    \(\lvert\hat\theta_N - \theta\rvert\) 这一次估计离真值差多远
    \(P(\cdots \gt \varepsilon)\) 「这个差超过 \(\varepsilon\)」这件事发生的概率

    「依概率收敛」的直观含义（请反复读这一句）：

    不是说「\(N\) 大了之后估计值一定等于真值」， 而是说「\(N\) 大了之后，估计值离真值还有明显距离这件事， 发生的可能性趋近于 \(0\)」

    这两句话的差别很关键 ⚠

    说法 对不对
    \(N\) 很大时 \(\hat\theta_N = \theta\) 错 ✗（随机量永远可能偏离）
    \(N\) 很大时，\(\hat\theta_N\) 偏离 \(\theta\) 超过 \(\varepsilon\) 的概率 \(\to 0\) 对 ✓

    换句话说：一致性不排除偶尔估偏， 它只是保证「估偏」这件事越来越罕见。

    5.2 怎么判断一致性：MSE 判据¶

    一个常用的充分判据（由下一节的 MSE 分解得到）：

    \[ \text{MSE}(\hat\theta_N) \to 0 \quad (N\to\infty) \quad\Longrightarrow\quad \hat\theta_N \text{ 是一致的} \]

    推理链（不跳步）：

    1
2
3
4
5
    MSE -> 0
  ↓ 因为 MSE = bias^2 + Var
bias -> 0  且  Var -> 0
  ↓ 方差趋于 0 意味着「偏离」越来越不可能
依概率收敛于真值

    所以「偏差和方差都趋于 \(0\)」就保证一致

    为什么一致性是「最低要求」： 一个不一致的估计量，无论加多少数据都不会变准 ✗ —— 那它基本没有使用价值。

    课件里给出的结论：矩量估计既是无偏的，也是一致的。 本页前面已经证了无偏，下面用手算表看一致性。

    5.3 手算：从 \(N = 10\) 加到 \(N = 100000\)¶

    做法：一致性说的是 \(\operatorname{Var}\to 0\)。 由于 \(E[\hat\mu]=\mu\) 恒成立，偏差恒为 \(0\)， 于是只需要盯住 \(\sigma^2/N\) 这一个数 —— 它随 \(N\) 怎么变。

    代入 \(\sigma=2\)、\(\sigma^2=4\)，逐行手算：

    \[ N=10: \quad \frac{4}{10} = 0.4, \qquad \sqrt{0.4} \approx 0.6325 \]
    \[ N=100: \quad \frac{4}{100} = 0.04, \qquad \sqrt{0.04} = 0.2 \]
    \[ N=1000: \quad \frac{4}{1000} = 0.004, \qquad \sqrt{0.004} \approx 0.0632 \]
    \[ N=10000: \quad \frac{4}{10000} = 0.0004, \qquad \sqrt{0.0004} = 0.02 \]
    \[ N=100000: \quad \frac{4}{100000} = 0.00004, \qquad \sqrt{0.00004} \approx 0.0063 \]

    手算对照表（原代码扫参数打印的表格换成这张）：

    样本量 \(N\) 方差 \(\sigma^2/N\) 波动 \(\sigma/\sqrt N\) 偏差 相对 \(N=10\)
    \(10\) \(0.4\) \(0.6325\) \(0\) \(1\) 倍
    \(100\) \(0.04\) \(0.2\) \(0\) \(1/3.16\) 倍
    \(1000\) \(0.004\) \(0.0632\) \(0\) \(1/10\) 倍
    \(10000\) \(0.0004\) \(0.02\) \(0\) \(1/31.6\) 倍
    \(100000\) \(0.00004\) \(0.0063\) \(0\) \(1/100\) 倍

    怎么读这张表：

    列 说明什么
    方差列：一路降到 \(0.00004\) 单调递减且极限为 \(0\) → 一致性成立 ✓
    偏差列：全是 \(0\) 无偏性在每个 \(N\) 上都成立 ✓
    相对列：\(N\) 涨 \(10\) 倍，误差只降 \(3.16\) 倍 \(\sqrt{10}\approx 3.16\)，正是 \(\sqrt N\) 规律 ⚠

    这个结论说明什么：偏差与方差是两个独立的旋钮。 这里偏差恒为 \(0\)，一致性就完全由方差决定； 而方差 \(\sigma^2/N\to 0\) 又是显然的 —— 所以「矩量估计一致」这件事，其实一行字就证完了

    「波动变小」和「收敛」是两件事，但这里同时发生了

    请分清两个不同的现象：

    现象 说的是什么 判据
    波动变小 方差趋于 \(0\) \(\operatorname{Var} \to 0\)
    收敛到真值 方差与偏差一起趋于 \(0\) \(\text{MSE} \to 0\)

    只满足前者的情形：估计量有偏，但方差趋 \(0\)。 这时所有估计值都紧紧挤在同一个错误的位置上 ✗ —— 它会稳定地收敛，只不过收敛到一个错的答案。

    这就是为什么会「有偏但一致」的反例： \(1000 + \bar X\) 这个估计量，方差与 \(\bar X\) 一样（也趋于 \(0\)）， 但期望是 \(1000 + \mu\)，永远偏 \(1000\)， 它不一致 ✗

    所以判断一致性必须看 MSE，不能只看方差 ✓

    5.4 一致性为什么在信号处理里特别重要：连接遍历性¶

    到这里可以把前面几页的东西接上了。

    课件在讲遍历性时写过一句话，意思是： 如果过程的时间自相关按概率收敛到系综自相关，那么时间统计的结果就是一致的。

    这句话正好是本节的信号处理版本：

    一般统计 信号处理
    数据来源 \(N\) 次独立重复观测 一条记录上的 \(N\) 个时间点
    「\(N\) 增大」意味着 多测几次 记录更长
    一致性保证的是 估计量趋于真值 时间平均趋于系综平均
    保证这件事的假设 独立性 遍历性 ⚠

    所以遍历性就是信号处理里的「一致性假设」

    没有遍历性会怎样： 那你手里这条记录只是无数可能记录中的一条， 无论它多长，它都只反映它自己那一种「运气」， 时间平均不会收敛到系综平均 ✗

    这一步换成手算同样干净。把「一条记录只取前 \(M\) 个点做时间平均」 看成一个估计量，它的方差仍然是 \(\sigma^2/M\)：

    \[ M=4: \quad \frac{4}{4} = 1, \qquad \sqrt{1} = 1 \]
    \[ M=16: \quad \frac{4}{16} = 0.25, \qquad \sqrt{0.25} = 0.5 \]
    \[ M=64: \quad \frac{4}{64} = 0.0625, \qquad \sqrt{0.0625} = 0.25 \]
    \[ M=256: \quad \frac{4}{256} = 0.015625, \qquad \sqrt{0.015625} = 0.125 \]

    手算对照表：

    时间平均长度 \(M\) 方差 \(\sigma^2/M\) 波动 \(\sigma/\sqrt M\) 偏差
    \(4\) \(1\) \(1\) \(0\)
    \(16\) \(0.25\) \(0.5\) \(0\)
    \(64\) \(0.0625\) \(0.25\) \(0\)
    \(256\) \(0.015625\) \(0.125\) \(0\)

    怎么读这张表：

    观察 含义
    偏差一列全是 \(0\) 时间平均是无偏的 ✓
    波动一列按 \(\sqrt M\) 缩小 与 \(\sigma/\sqrt M\) 完全吻合 ✓
    \(M = 256\) 时波动仍有 \(0.125\) 永远不会是 \(0\) ⚠

    最后一点必须记住： 时间平均永远只是一个估计，即使把整条记录用完， 它也不会刚好等于真值

    这个结论说明什么：遍历性把「系综平均」换成了「时间平均」， 但它没有把有限样本的误差消掉 —— 它只是把误差的来源从「不知道别的记录」转移到了「记录长度不够」。 这一点是本节最容易被忽略的地方

    这正是本页开头「真实参数永远不知道」那句话的定量版本 —— 你能拿到的永远是一个带不确定度的数，而不是真值。

    六、均方误差：把无偏与有效合成一个数¶

    6.1 定义¶

    定义：

    \[ \text{MSE}(\hat\theta) = E\!\left[(\hat\theta - \theta)^2\right] \]

    符号与读法：

    符号 含义
    \(\hat\theta - \theta\) 一次估计的误差（可正可负）
    \((\hat\theta - \theta)^2\) 误差的平方（消掉符号）
    \(E[\cdot]\) 在所有可能的观测上取平均

    估计量离真值的平均平方距离。 它是「准不准」的一个单一数字指标

    为什么用平方而不是绝对值：平方对大误差的惩罚更重 （差 \(2\) 倍，惩罚差 \(4\) 倍）， 而且平方里藏着方差，能直接和 \(\operatorname{Var}\) 拼上关系 —— 下面这个分解就是它的回报

    6.2 分解：MSE = 偏差² + 方差¶

    这个分解是本页最重要的一个公式，下面逐步推导，一步不跳。

    第一步：在括号里先加再减 \(E[\hat\theta]\)

    \[ \hat\theta - \theta = \hat\theta - E[\hat\theta] + E[\hat\theta] - \theta \]

    为什么这样配：因为 \(E[\hat\theta] - \theta\) 恰好是偏差， 而 \(\hat\theta - E[\hat\theta]\) 恰好是「估计量围绕自己期望的抖动」， 也就是方差所描述的东西。两项各司其职

    第二步：引入两个记号，把式子缩短

    \[ A = \hat\theta - E[\hat\theta], \qquad b = E[\hat\theta] - \theta = \operatorname{bias}(\hat\theta) \]

    注意 \(b\) 是常数（不随观测变化），而 \(A\) 是随机变量。 于是 \(\hat\theta - \theta = A + b\)。

    第三步：平方后取期望，展开

    \[ \text{MSE} = E\!\left[(A+b)^2\right] = E\!\left[A^2 + 2Ab + b^2\right] \]

    期望是线性的，逐项拆开：

    \[ = E[A^2] + 2b\,E[A] + b^2 \]

    （\(b\) 是常数，可以提到期望外面）

    第四步：算出 \(E[A]\)

    \[ E[A] = E\!\left[\hat\theta - E[\hat\theta]\right] = E[\hat\theta] - E\!\left[E[\hat\theta]\right] \]

    这里 \(E[\hat\theta]\) 本身是一个常数（它是「期望」这个运算的结果）， 所以它的期望就是它自己：

    \[ = E[\hat\theta] - E[\hat\theta] = 0 \]

    所以中间那一项 \(2b\,E[A] = 0\)，整个交叉项消失 （这一步是整个分解的关键，也是「为什么要减去 \(E[\hat\theta]\)」的答案。）

    第五步：认出剩下两项

    \[ E[A^2] = E\!\left[\left(\hat\theta - E[\hat\theta]\right)^2\right] = \operatorname{Var}(\hat\theta) \]

    （这正是方差的定义）

    \[ b^2 = \left(E[\hat\theta] - \theta\right)^2 = \operatorname{bias}^2(\hat\theta) \]

    第六步：合起来

    \[ \boxed{\ \text{MSE}(\hat\theta) = \operatorname{bias}^2(\hat\theta) + \operatorname{Var}(\hat\theta)\ } \]

    平均平方误差 = 系统性偏离的平方 + 随机抖动的方差 两种「错法」被干净地分开了。

    三种特殊情形（边界情况要点明）：

    情形 MSE 变成什么 说明
    无偏 \(\text{MSE} = \operatorname{Var}\) 偏差项为 \(0\)，MSE 就是方差 ✓
    方差为 \(0\) \(\text{MSE} = \operatorname{bias}^2\) 估计量几乎是常数，只差一个固定偏移
    无偏且方差为 \(0\) \(\text{MSE} = 0\) 估计值恒等于真值（现实中不出现）

    第一行非常重要：无偏估计量的 MSE 等于它的方差。 所以「在无偏估计量里挑方差最小的」和「挑 MSE 最小的」是同一件事， 这就是为什么「有效性」可以直接用方差来比较

    6.3 这张分解式的意义¶

    回到第 4.2 节那个尴尬的局面：一个有偏但方差极小的估计量， 到底算不算好？现在有答案了。

    标准 看的是 局限
    无偏性 \(\operatorname{bias}\) 是否为 \(0\) 只看一列，完全不管方差 ⚠
    有效性 \(\operatorname{Var}\) 只在都无偏时才好比较 ⚠
    MSE \(\operatorname{bias}^2 + \operatorname{Var}\) 两者合成一个数，任何估计量都能比 ✓

    MSE 的两条实用推论：

    推论 说明
    有偏估计可能比无偏估计更好 只要「偏差²的增量」小于「方差的减量」✓
    无偏不是必要条件 它只是一个「看起来干净」的中间标准

    课件里也留了这句话（意思与本页完全一致）：

    在许多情况下，一个有偏但渐进无偏的估计， 具有比无偏估计好得多的分析和计算性质。 有时，对有偏估计进行适当的标定，可能使它变成无偏估计。

    最后一句「适当标定可以变成无偏」值得留意： 这正是 \(S^2 = \frac{N}{N-1}\hat\sigma_N^2\) 干的事情 —— 把有偏的估计量乘上一个修正系数就无偏了

    6.4 数值验证：bias² + Var 与直接算的 MSE 相等¶

    bias² + Var \(3.781679\) 与直接算的 MSE 相同 ✓

    这个结论说明什么：分解式是恒等式，不是近似 —— 两条完全独立的算法（一条走定义，一条走分解）给出同一个数， 差别只有 \(10^{-5}\) 量级的浮点舍入

    三者一起核对，这就是任务要求的「数值验证」：

    项 手算值 说明
    \(\text{bias}^2\) \(\sigma^4/N^2 = 16/64 = 0.25\) 偏差平方，正数 ✓
    \(\operatorname{Var}\) \(2\sigma^4(N-1)/N^2 = 3.5\) 波动平方，正数 ✓
    \(\text{bias}^2 + \operatorname{Var}\) \(0.25 + 3.5 = 3.75\) 分解式右边 ✓
    直接算的 MSE \(= 3.75\) 分解式左边，两边相等 ✓

    这个结论说明什么：分解式不是一个近似，而是恒等式 —— 它把「总误差」（MSE）拆成两个物理意义完全不同的部分： 一部分是系统性偏移（bias²），另一部分是随机波动（Var）。 上面这个例子里 \(3.5\) 远大于 \(0.25\)， 说明误差几乎全部来自方差，偏差只占约 \(6.7\%\)

    不要用「一次估计的误差平方」代替 MSE

    MSE 里的 \(E[\cdot]\) 不能省 ⚠

    写法 是不是 MSE
    \((\hat\theta - \theta)^2\) 不是 ✗（这是某一次的结果，可能碰巧很小）
    \(\frac1R\sum_{r=1}^{R}\left(\hat\theta^{(r)} - \theta\right)^2\) 是（对 \(R\) 次重复求平均）✓

    为什么必须是期望：上面手算的 \(3.75\) 是期望意义下的平均误差。 单次实验可能得到 \(\hat\theta = 3.9\)，误差平方只有 \(0.01\)； 也可能得到 \(\hat\theta = 1.0\)，误差平方高达 \(9\)。 只有把大量重复平均起来，才能看到 \(3.75\) 这个数。

    真实场景里算不出 MSE —— 你只有一个 \(\hat\theta\)，也没有真值。 这时只能估计方差那一部分（由数据自己估）， 偏差部分要靠模型假设来判断有无

    6.5 例：有偏但低方差的估计量赢过无偏估计量¶

    构造一个最小、最直观的例子。

    设定：\(N = 4\) 个样本，\(X_n\sim N(1, 4)\)，即 \(\mu = 1\)、\(\sigma = 2\)。 要估计的是 \(\mu\)。

    两个候选：

    估计量 公式 期望 偏差 方差
    样本均值 \(\bar X\) \(\mu\) \(0\) \(\sigma^2/N = 1\)
    收缩估计 \(0.5\,\bar X\) \(0.5\mu\) \(-0.5\mu = -0.5\) \(0.25\sigma^2/N = 0.25\)

    收缩估计的想法：把估计值往 \(0\) 拉一把。 代价是引入了偏差（它长期平均只给出 \(0.5\) 而不是 \(1\)）， 好处是方差降到四分之一

    两个的 MSE（用上一节的分解式直接算）：

    \[ \text{MSE}(\bar X) = 0^2 + 1 = 1 \]
    \[ \text{MSE}(0.5\bar X) = (-0.5)^2 + 0.25 = 0.25 + 0.25 = 0.5 \]

    结果：有偏的收缩估计，MSE 只有无偏样本均值的一半

    这个例子说明了什么：

    结论 说明
    「无偏」不是最优性判据 它只是一个中间标准 ⚠
    偏差可以「买来」方差 只要价格（偏差²）比收益（方差减量）便宜 ✓
    关键前提是偏差要小 这个例子里真值 \(\mu = 1\) 不大，往 \(0\) 拉代价小 ⚠

    注意最后一行：如果真值 \(\mu\) 很大（比如 \(\mu = 100\)）， 那么 \((1-0.5)^2\mu^2 = 2500\)，收缩估计就彻底废了 ✗ 所以收缩必须「往对的地方拉」 —— 这正是加窗、正则化这些技术要选好目标的原因

    七、信号处理里最常见的几个估计量¶

    前面讲的是通用的性质，这一节把它们落到本课程真正会用的三个估计量上。

    估计量 公式 无偏 一致 备注
    样本均值 \(\hat\mu = \frac1N\sum_{n=0}^{N-1}x_n\) ✓ ✓ 方差 \(\sigma^2/N\)
    样本自相关（分母 \(N-\lvert m\rvert\)） \(\hat R(m)\) ✓ ✓ 计算不方便
    样本自相关（分母 \(N\)） \(\tilde R(m)\) ✗ ✓ 便于 FFT ✓
    样本方差 \(\frac{1}{N-1}\sum(x_n-\hat\mu)^2\) ✓ ✓ 分母见 3.3 节

    7.1 样本均值¶

    \[ \hat\mu = \frac1N\sum_{n=0}^{N-1}x_n \]

    这是全课程用得最多的估计量，性质在 3.2 节已经证完：

    性质 结论 依据
    无偏 \(E[\hat\mu] = \mu\) ✓ 期望的线性性
    方差 \(\operatorname{Var}(\hat\mu) = \sigma^2/N\) ✓ 独立性
    一致 \(N\to\infty\) 时收敛 ✓ 由上面两条经 MSE 判据

    唯一要提醒的是它的假设： 上面那条「方差 \(= \sigma^2/N\)」要求 \(x_n\) 互不相关。 真实信号常常有相关性（比如自相关函数衰减很慢的那种）， 这时方差会比 \(\sigma^2/N\) 大得多 ⚠ —— 因为 \(N\) 个点里其实没有 \(N\) 份独立信息。

    为什么「没有 \(N\) 份独立信息」这一点很关键： 信号在进入观测之前，往往已经经过了系统。 下面这张图把这件事画出来 —— 输入序列经过一个线性系统得到输出， 输出的统计特性由系统的频率响应决定。

    图上要看的是：那条曲线就是「用于估计的系统」的幅频特性。 低频处幅度高、高频处幅度低 —— 低频成分在输出里被放大，高频成分被压掉。

    这张图说明什么：只靠输出序列去反推输入参数会很难， 因为系统把某些频率的信息抹掉了 —— 那部分信息在输出里几乎不存在， 再多的观测也无法把它恢复出来 这正是「\(N\) 个点里没有 \(N\) 份独立信息」的频域解释 这个现象叫「有效样本数小于名义样本数」， 后面的谱估计章节会正面处理它。

    7.2 样本自相关 —— 分母取 \(N\) 还是 \(N-\lvert m\rvert\)¶

    要估计的量（系综定义）：

    \[ R(m) = E\!\left[X_{n+m}X_n^{*}\right] \]

    怎么用一条记录估它： 把「在所有可能记录上求期望」换成「沿着时间轴滑动相乘再平均」。 乘积是 \(x_{n+m}x_n^{*}\)，能配成的数据对是 \((x_0,x_m),(x_1,x_{1+m}),\dots\)。

    课件给出了两个估计量，差别只在分母。

    版本一：分母用 \(N-\lvert m\rvert\)（去掉没有配对的那几项）

    \[ \hat R(m) = \frac{1}{N-\lvert m\rvert}\sum_{n=0}^{N-1-\lvert m\rvert}x_{n+m}x_n^{*}, \qquad \lvert m\rvert \lt N \]

    版本二：分母用 \(N\)（不管有没有配对，始终除以 \(N\)）

    \[ \tilde R(m) = \frac{1}{N}\sum_{n=0}^{N-1-\lvert m\rvert}x_{n+m}x_n^{*}, \qquad \lvert m\rvert \lt N \]

    为什么两个都能见到：

    比较项 \(\hat R(m)\)（除以 \(N-\lvert m\rvert\)） \(\tilde R(m)\)（除以 \(N\)）
    无偏性 无偏 ✓ 有偏，偏低 ✗
    偏差大小 \(0\) \(-\frac{\lvert m\rvert}{N}R(m)\)
    渐近无偏 ✓ ✓（当 \(\lvert m\rvert \ll N\)）✓
    计算方式 每个滞后要换一个分母，只能逐点算 ✗ 分母固定，整条自相关可用 FFT 一次算出 ✓

    课件对版本二的评价是：

    估计量 \(\tilde R(m)\) 是有偏的，但当 \(\lvert m\rvert \ll N\) 时偏量很小，是渐进无偏的。 重要的是，当数据很长时，\(\tilde R(m)\) 可以通过 FFT 来计算。

    这一句话把工程取舍说透了： 为了能用 FFT，宁可接受一个小偏差 ✓ —— 这正是第九节「偏差-方差权衡」的第一个实例。

    偏差公式的推导（很短，但要点明）：

    \[ E\!\left[\tilde R(m)\right] = \frac1N\sum_{n=0}^{N-1-\lvert m\rvert}E\!\left[x_{n+m}x_n^{*}\right] = \frac1N\sum_{n=0}^{N-1-\lvert m\rvert}R(m) = \frac{N-\lvert m\rvert}{N}\,R(m) \]

    每一步：

    步骤 依据
    期望送进求和号 期望的线性性
    \(E[x_{n+m}x_n^{*}] = R(m)\) 广义平稳：自相关只依赖滞后，不依赖绝对时刻 ✓
    求和共 \(N-\lvert m\rvert\) 项 配对的数量比 \(N\) 少了 \(\lvert m\rvert\) 个

    所以偏差：

    \[ \operatorname{bias} = \frac{N-\lvert m\rvert}{N}R(m) - R(m) = -\frac{\lvert m\rvert}{N}R(m) \]

    滞后越大，偏差越大， 因为在 \(N\) 项里，没有配对的那 \(\lvert m\rvert\) 项被当成了 \(0\) 一起平均，把结果拉低了

    滞后 \(m = 0\) 时两个版本完全相同（\(\lvert m\rvert = 0\)，分母都是 \(N\)）， 这也是课件把 \(m = 0\) 单独写的原因

    大滞后处的自相关估计非常不可靠

    这是本页最需要记住的一个工程事实

    原因有两层，第一层是偏差：

    滞后 \(m\) 可用样本对数 版本二的偏差比例
    \(0\) \(N\) \(0\)
    \(N/4\) \(0.75N\) \(-25\%\)
    \(N/2\) \(0.5N\) \(-50\%\)
    \(0.9N\) \(0.1N\) \(-90\%\) ✗

    第二层是方差 —— 这一层更致命：

    估计自相关时，可用的样本对数随 \(m\) 增大而减少， 只有 \(N-\lvert m\rvert\) 对。而由第五节和第八节的结论， 估计量的标准差大致按可用样本数的平方根倒数变化：

    \[ \text{std}\!\left[\hat R(m)\right] \propto \frac{1}{\sqrt{N-\lvert m\rvert}} \]

    所以 \(m\) 接近 \(N\) 时，可用样本对数趋于 \(0\)，方差趋于无穷 ✗

    两条效应叠加的后果：

    现象 说明
    大滞后处估计方差很大 换一段数据，估出来的值可能差很多
    大滞后处估计方差大且偏差大 又偏又散，基本没有信息量
    而真值 \(R(m)\) 在大滞后处本来就很接近 \(0\) 于是「噪声盖住了信号」⚠

    这意味着：那些在大滞后处看起来有起伏的估计值， 绝大多数是估计噪声，不是真实的周期性

    工程上的对策（10.3 节会展开）：

    做法 效果
    只用到 \(m \approx N/10\) 的滞后 保证每点还有足够多的样本对 ✓
    对 \(\hat R(m)\) 加窗（乘一个逐渐衰减的窗） 削弱大滞后处的高方差 ⚠
    用参数模型（如 AR 模型）反推自相关 用少量参数避免逐点估计

    这也解释了谱估计中的一个核心困难： 功率谱是自相关的傅里叶变换， 而大滞后处的自相关估计最不可靠， 可它们在谱估计里占的权重并不小 —— 这是后续章节要解决的矛盾

    先看两种分母的对比——用 \(\text{AR}(1)\) 手算。

    设定：\(a = 0.8\)、\(\sigma_w^2 = 1\)、\(N = 256\)，则真实自相关是

    \[ R(k) = \frac{\sigma_w^2}{1-a^2}\,a^{\lvert k\rvert} = \frac{1}{1-0.64}\,0.8^{\lvert k\rvert} = \frac{1}{0.36}\,0.8^{\lvert k\rvert} \approx 2.7778 \times 0.8^{\lvert k\rvert} \]

    先手算 \(R(0)\) 与 \(R(1)\)：

    关键在分母。 滞后 \(k\) 处只有 \(N-k\) 对样本可用， 所以「分母取 \(N\)」的估计量期望是

    \[ E[\hat R_N(k)] = \frac{N-k}{N}\,R(k) \]

    代入 \(k=1\)：

    \[ E[\hat R_N(1)] = \frac{256-1}{256}\times 2.2222 = 0.99609 \times 2.2222 \approx 2.2135 \]

    \[ \operatorname{bias} = 2.2135 - 2.2222 = -0.0087 \]

    7.3 样本方差（回到 3.3 节的 \(N\) 与 \(N-1\)）¶

    估计量：

    \[ \hat\sigma^2 = \frac{1}{N-1}\sum_{n=0}^{N-1}\left(x_n - \hat\mu\right)^2 \]

    性质汇总（依据在 3.3 节）：

    性质 结论
    无偏 分母用 \(N-1\) 时 \(E[\hat\sigma^2] = \sigma^2\) ✓
    一致 ✓（无偏且方差 \(\propto 1/N\)，由 MSE 判据）
    有偏版本 分母用 \(N\) 时偏低 \(\sigma^2/N\) ✗，但方差更小、MSE 更小 ✓

    和前面两个估计量的关系：

    量 用样本均值的程度
    \(\hat\mu\) 它自己就是均值
    \(\hat\sigma^2\) 依赖 \(\hat\mu\)，所以损失一个自由度 ⚠
    \(\hat R(m)\) 不依赖 \(\hat\mu\)，所以 \(m=0\) 时没有这个损失 ✓

    最后一行容易忽略：\(x_{n+m}x_n^{*}\) 里没有出现 \(\hat\mu\)， 所以估计自相关时不存在「先用数据估了个中心、再扣掉一个自由度」的问题。 用 \(N-\lvert m\rvert\) 就是无偏的

    八、估计量的方差随样本量怎么变化¶

    8.1 核心结论：方差与 \(N\) 成反比¶

    对样本均值（前提：\(x_n\) 互不相关，各自方差 \(\sigma^2\)）：

    \[ \operatorname{Var}\!\left(\hat\mu\right) = \frac{\sigma^2}{N} \]

    开方得到标准差：

    \[ \text{std}\!\left(\hat\mu\right) = \frac{\sigma}{\sqrt N} \]

    精度与样本量的平方根成正比，而不是与样本量成正比

    这条规律比它看起来的样子重要得多。把它写成「倍率」的形式更清楚：

    想要的精度倍数 需要的样本量倍数
    \(2\times\)（波动减半） \(4\times\) ⚠
    \(3\times\) \(9\times\)
    \(10\times\) \(100\times\) ⚠
    \(100\times\) \(10000\times\)

    这张表就是「为什么不能靠加数据无限提高精度」的答案 ✓

    算一个具体数字：已知 \(\sigma = 2\)，想把均值的估计标准差从 \(0.2\) 压到 \(0.1\)。

    \[ \frac{2}{\sqrt N} = 0.2 \Rightarrow \sqrt N = 10 \Rightarrow N = 100 \]
    \[ \frac{2}{\sqrt N} = 0.1 \Rightarrow \sqrt N = 20 \Rightarrow N = 400 \]

    精度提高一倍，数据量要从 \(100\) 涨到 \(400\) —— 增加 \(4\) 倍

    8.2 把这条规律手算出来¶

    做法：每个 \(N\) 都代入 \(\operatorname{Var}=\sigma^2/N\) 直接算， 看这些值与 \(\sigma/\sqrt N\) 怎么对应。

    关键是看「\(N\) 翻 \(4\) 倍时，标准差是否恰好减半」 —— 这正是下面手算表里要核对的比值。

    逐步手算，取 \(\sigma = 3\)，所以 \(\sigma^2 = 9\)：

    \[ N=10: \quad \frac{9}{10} = 0.9, \qquad \sqrt{0.9} \approx 0.9487 \]
    \[ N=40: \quad \frac{9}{40} = 0.225, \qquad \sqrt{0.225} \approx 0.4743 \]
    \[ N=160: \quad \frac{9}{160} = 0.05625, \qquad \sqrt{0.05625} \approx 0.2372 \]
    \[ N=640: \quad \frac{9}{640} = 0.0140625, \qquad \sqrt{0.0140625} \approx 0.1186 \]
    \[ N=2560: \quad \frac{9}{2560} = 0.003515625, \qquad \sqrt{0.003515625} \approx 0.0593 \]

    手算对照表（原来的扫参数代码换成这张）：

    样本量 \(N\) 方差 \(\sigma^2/N\) 标准差 \(\sigma/\sqrt N\) \(N\) 的倍数 标准差之比
    \(10\) \(0.9\) \(0.9487\) — —
    \(40\) \(0.225\) \(0.4743\) \(4\) \(2.000\) ✓
    \(160\) \(0.05625\) \(0.2372\) \(4\) \(2.000\) ✓
    \(640\) \(0.0140625\) \(0.1186\) \(4\) \(2.000\) ✓
    \(2560\) \(0.003515625\) \(0.0593\) \(4\) \(2.000\) ✓

    怎么读这张表：

    列 说明
    方差列每行除以 \(4\) \(N\) 涨 \(4\) 倍，方差正好变 \(\dfrac{1}{4}\) ✓
    标准差列每行除以 \(2\) 开方之后，\(\sqrt 4 = 2\) ✓
    「标准差之比」恰好是 \(2\) 样本量 \(\times 4\)，标准差 \(\div 2\) ✓

    验证一下这个比值为什么必然等于 \(2\)：

    \[ \frac{\sigma/\sqrt{N}}{\sigma/\sqrt{4N}} = \sqrt{\frac{4N}{N}} = \sqrt 4 = 2 \]

    这个结论说明什么：「标准差之比」那一列不可能通过取更多数据变成 \(10\) 或 \(100\) —— 它是 \(\sqrt 4 = 2\)，是一个与 \(\sigma\)、\(N\) 都无关的常数 换言之：要把误差缩小 \(10\) 倍，样本量得增加 \(100\) 倍

    「加数据」不是万能的 —— 精度只按根号增长

    这条规律在实际工作上会造成几个反直觉的后果，值得单独标出来

    直觉 实际 后果
    「数据翻倍，精度翻倍」 精度只提高 \(\sqrt 2 \approx 1.41\) 倍 期望落空
    「多测 \(10\) 倍，误差小 \(10\) 倍」 误差只小 \(3.16\) 倍 成本被低估
    「再攒点数据就能看出来」 需要平方倍的数据量 实验规模算错 ✗

    还有两个更隐蔽的坑：

    坑 说明
    相关性 \(\sigma^2/N\) 要求样本互不相关；有相关性时实际方差远大于公式值 ⚠
    偏差不会靠 \(N\) 消掉 \(N\) 只减方差；系统性偏差必须靠改估计量消除 ⚠

    第二行是最要紧的一条： 把 \(N\) 从 \(10^3\) 加到 \(10^6\)，标准差能降 \(\sqrt{1000}\approx 32\) 倍， 但如果估计量有 \(5\%\) 的系统偏差， 这个偏差一点都不会变 —— 它会一直停在那里 ✗

    所以判断一个估计量时，要分开问两件事：

    问题 靠什么解决
    偏差大不大？ 改估计量（如换成 \(N-1\) 分母、做标定修正）✓
    波动大不大？ 加数据（但只按 \(\sqrt N\) 改善）⚠

    九、偏差-方差权衡：宁可有小偏差，换取大幅降方差¶

    9.1 一条常见策略¶

    把前面几节的结论摆在一起，就得到一条工程上极常用的策略：

    宁可有小的偏差，换取大幅降低的方差。

    为什么它常常划得来：因为 MSE 是两项之和， 而这两项在数量级上往往不对等：

    项 常见量级 被 \(N\) 影响的程度
    偏差² 可与 \(1/N^2\) 同阶（很小） 随 \(N\) 减小
    方差 可与 \(1/N\) 同阶（较大） 随 \(N\) 减小

    只要偏差引入得比方差降得少，净值就是正的

    判断标准就是上一节的分解式：

    \[ \text{MSE} = \operatorname{bias}^2 + \operatorname{Var} \ \xrightarrow{\ \text{要变小}\ }\ \Delta\operatorname{bias}^2 \lt \Delta\operatorname{Var} \]

    9.2 信号处理里的三个例子¶

    正则化 解被「拉向」某个先验 抑制解的剧烈振荡 病态反问题、参数辨识 ✓

    它们的共同结构：

    9.3 数值例子：滑动平均的偏差与方差¶

    场景：要估计一个缓慢变化的趋势，观测里混了噪声。

    \[ x_n = c\,n^2 + w_n, \qquad w_n \sim N(0,\sigma^2),\ \sigma = 1 \]

    被估计的目标：窗心处的趋势值。 估计量：取窗心两侧共 \(L\) 个点做滑动平均（\(L\) 取奇数）。

    \[ \hat\theta_L = \frac1L\sum_{j=-(L-1)/2}^{(L-1)/2}x_{n+j} \]

    推导这个估计量的偏差与方差（这是本页最后一个完整推导）。

    第一步：把模型代进去

    \[ \hat\theta_L = \frac1L\sum_{j}x_{n+j} = \frac1L\sum_{j}\left(c\,(n+j)^2 + w_{n+j}\right) \]

    第二步：取期望，求偏差

    目标值是 \(c\,n^2\)（窗心处的真趋势）。噪声期望为 \(0\)，所以

    \[ E[\hat\theta_L] = \frac1L\sum_j c\,(n+j)^2 = c\,n^2 + \frac{c}{L}\sum_j j^2 \]

    （把 \((n+j)^2 = n^2 + 2nj + j^2\) 展开求和； 中间那项 \(\frac{2cn}{L}\sum_j j = 0\)，因为 \(j\) 关于 \(0\) 对称求和）

    所以偏差：

    \[ \operatorname{bias}(\hat\theta_L) = E[\hat\theta_L] - c\,n^2 = \frac{c}{L}\sum_{j}j^2 \]

    这是一个正数（平方和非负）→ 滑动平均会高估一个向上的凸趋势

    第三步：求方差

    \[ \operatorname{Var}(\hat\theta_L) = \frac{1}{L^2}\sum_j\operatorname{Var}(w_{n+j}) = \frac{1}{L^2}\cdot L\sigma^2 = \frac{\sigma^2}{L} \]

    （用了 \(w_n\) 互不相关的假设）

    第四步：MSE 的表达式

    \[ \text{MSE}(\hat\theta_L) = \underbrace{\left(\frac{c}{L}\sum_j j^2\right)^2}_{\text{随 }L\text{ 增大而增大}} + \underbrace{\frac{\sigma^2}{L}}_{\text{随 }L\text{ 增大而减小}} \]

    这两项方向相反 —— 于是一定存在一个最优的 \(L\) ✓ 这就是权衡的数学形态。

    算一个具体的 \(L\) 做手算核对：取 \(c = 0.001\)、\(L = 11\)，那么 \(j\) 取 \(-5,\dots,5\)。

    \[ \sum_{j=-5}^{5}j^2 = 2\left(1^2+2^2+3^2+4^2+5^2\right) = 2(1+4+9+16+25) = 2\times 55 = 110 \]
    \[ \operatorname{bias} = \frac{0.001\times 110}{11} = 0.01 \]
    \[ \operatorname{bias}^2 = 0.0001, \qquad \operatorname{Var} = \frac{1}{11} = 0.0909 \]
    \[ \text{MSE} = 0.0001 + 0.0909 = 0.0910 \]

    注意偏差 \(0.01\) 相比标准差 \(\sqrt{0.0909} = 0.30\) 小得多 —— 偏差可以忽略，方差才是主要矛盾

    下面把整个 \(L\) 序列都手算出来。

    两个来源：离散化偏差 \(\operatorname{bias}(L) = c\cdot\overline{i^2}\)， 噪声方差 \(\operatorname{Var}(L) = \sigma^2/L = 1/L\)。

    以 \(L=11\) 为例走一遍。窗心两侧各取 \(m=5\)，所以 \(i\) 从 \(-5\) 到 \(5\)：

    \[ \overline{i^2} = \frac{2(1^2+2^2+3^2+4^2+5^2)}{11} = \frac{2\times 55}{11} = \frac{110}{11} = 10 \]
    \[ \operatorname{bias}(11) = c\cdot\overline{i^2} = 0.001\times 10 = 0.01 \]
    \[ \operatorname{bias}^2 = 0.0001, \qquad \operatorname{Var} = \frac{1}{11} \approx 0.0909 \]
    \[ \text{MSE} = 0.0001 + 0.0909 = 0.0910 \]

    同样的算法，\(L=41\)（\(m=20\)，\(\overline{i^2}=140\)）：

    \[ \operatorname{bias} = 0.001\times 140 = 0.14, \qquad \operatorname{bias}^2 = 0.0196 \]
    \[ \operatorname{Var} = \frac{1}{41} \approx 0.0244 \quad\Longrightarrow\quad \text{MSE} = 0.0196 + 0.0244 = 0.0440 \]

    手算对照表（原代码扫 \(L\) 参数的输出换成这张）：

    窗长 \(L\) 偏差 \(\operatorname{bias}^2\) \(\operatorname{Var}=1/L\) MSE \(=\) 二者之和
    \(1\) \(0\) \(0\) \(1.0\) \(1.0000\)
    \(5\) \(0.002\) \(0.000004\) \(0.2\) \(0.2000\)
    \(11\) \(0.01\) \(0.0001\) \(0.0909\) \(0.0910\)
    \(21\) \(0.0367\) \(0.001344\) \(0.0476\) \(0.0490\) ✓
    \(41\) \(0.14\) \(0.0196\) \(0.0244\) \(0.0440\) 最优 ✓
    \(81\) \(0.547\) \(0.2988\) \(0.0123\) \(0.3112\) ⚠
    \(161\) \(2.16\) \(4.6656\) \(0.0062\) \(4.6718\) ✗

    怎么读这张表：

    观察 含义
    「偏差」一列随 \(L\) 单调上升 窗越宽，跟不上二次趋势 ⚠
    「方差」一列随 \(L\) 单调下降 平均的点越多，噪声越平 ✓
    「MSE」先降后升 存在最优 \(L\) ✓
    最优点出现在 \(L=41\) 附近 偏差² 刚追上方差的临界处 ✓

    这里有一个非常值得记住的细节： \(L = 41\) 时的 \(0.0440\) 比 \(L = 21\) 时的 \(0.0490\) 还小， 但 \(L = 81\) 时的 \(0.3112\) 已经急剧恶化 ✗ 窗口不能随便加宽 —— 过了最优点，偏差会迅速吃掉所有收益。

    图上印证这件事：下面这张图把两条曲线和它们的和画在一起 —— 偏差平方单调上升、方差单调下降， 而二者的和（MSE）是一条先降后升的 U 形曲线， 最低点正是 \(L\approx 41\)

    图上要看的是：虚线是「偏差平方」（单调上升）， 点线是「方差」（单调下降），实线是「二者之和」即 MSE。 实线的最低点对应最优的窗长 —— 这正是上面手算表里 \(L=41\) 那个位置的图形版本 这张图说明什么：偏差-方差权衡不是一种说法，而是一条有极小值的曲线。 只要偏差与方差反向变化，最优的中间点就必然存在

    加窗（Hamming 等） 压旁瓣降泄漏，代价是主瓣变宽 ✓

    十、实际应用中的三个注意点¶

    前面讲的是理论，这里换成「拿到一段真实数据时该注意什么」的角度。

    注意点 问题 对策
    数据长度有限 估计量有方差，结果不能被当成真值 报告「估计值 ± 不确定度」✓
    数据可能非平稳 统计规律在变，整体平均没有意义 分段估计，看各段是否稳定 ✓
    大滞后处自相关不可靠 可用样本对数少，方差大且偏差大 截断、加窗、改用参数模型 ✓

    10.1 数据长度有限 → 要报告不确定度¶

    这一步经常被跳过，但它决定了结果有没有用。

    一个孤零零的数字「\(\hat\mu = 2.4635\)」传达的信息是不完整的 —— 它没有告诉你「这个数能信到小数点后几位」

    正确的报告形式：

    \[ \hat\theta \pm \text{std}\!\left(\hat\theta\right) \]

    标准差的估计方式（用数据自己估，不需要真值）：

    \[ \widehat{\text{std}}\!\left(\hat\mu\right) = \frac{s}{\sqrt N}, \qquad s = \sqrt{\frac{1}{N-1}\sum_{n=0}^{N-1}\left(x_n-\hat\mu\right)^2} \]

    这个量有个专门的名字：标准误（standard error）

    「\(\pm\) 后面该放几倍」的常见约定：

    倍数 含义 备注
    \(1\) 倍标准误 约 \(68\%\) 的重复实验会落在区间内 最常用来表示「波动量级」
    \(2\) 倍标准误 约 \(95\%\) 常被叫作「\(2\sigma\) 区间」✓
    更高的倍数 更宽的区间 需要时按分布查

    注意这是「估计量的标准差」，不是「数据的标准差」 ⚠ 两者差一个 \(\sqrt N\)：

    量 公式 含义
    数据标准差 \(s\) 单个观测点有多散
    标准误 \(s/\sqrt N\) 估计出来的均值有多不稳 ✓

    下面把这两个量都手算出来对照。设 \(N = 200\)、\(s = 1.0583\)。

    第一步：算 \(\sqrt N\)：

    \[ \sqrt{200} = 14.1421 \]

    第二步：代入标准误公式：

    \[ \frac{s}{\sqrt N} = \frac{1.0583}{14.1421} \approx 0.0748 \]

    第三步：写出一倍的区间：

    \[ \hat\mu \pm \frac{s}{\sqrt N} = 2.4635 \pm 0.0748 \]

    第四步：写出两倍的区间（约九成五的置信水平）：

    \[ 2\times 0.0748 = 0.1497 \quad\Longrightarrow\quad 2.4635 \pm 0.1497 \]

    手算对照表（原代码输出换成这张）：

    量 手算值 含义
    \(\sqrt N\) \(14.1421\) 样本量的平方根 ✓
    \(s\) \(1.0583\) 单个观测有多散 ⚠
    标准误 \(s/\sqrt N\) \(0.0748\) 估计出来的均值有多不稳 ✓
    一倍标准误区间 \(2.4635 \pm 0.0748\) 常见报告格式 ✓
    两倍标准误区间 \(2.4635 \pm 0.1497\) 更保守的报告格式 ✓

    这个结论说明什么：\(s\) 与标准误差了 \(\sqrt N \approx 14\) 倍。 把两者搞混是最常见的报告错误 —— \(s=1.0583\) 描述的是单个数据点的散布， \(0.0748\) 描述的才是估计值本身的不确定度

    为什么必须报不确定度：因为下一节要做的「分段比较」， 靠的就是「两段之间的差有没有超过这个 \(\pm\)」来判断

    10.2 数据可能非平稳 → 分段估计¶

    如果过程的统计规律在记录期间发生了变化（非平稳）， 那么「整条记录的平均」就在平均一堆不同的东西 —— 它既不是前一段的均值，也不是后一段的均值

    对策：把记录切成若干段，每段单独估计， 然后看各段结果是否稳定。

    判断标准（很实用的一个经验规则）：

    分段结果 结论
    各段估计值都在「估计值 ± 若干倍标准误」范围内 可暂按平稳处理 ✓
    各段估计值有系统性的阶梯或趋势 非平稳，整体平均无意义 ✗
    各段估计值跳动很大但无规律 可能样本量不够，加大分段长度 ⚠

    下面把「整体平均」与「分段平均」手算对比。

    设定：前 \(300\) 点均值 \(1\)、后 \(300\) 点均值 \(3\)，两段方差都是 \(1\)。

    第一步：算整体平均（把 \(600\) 点当一个平稳过程）：

    \[ \hat\mu_{\text{整体}} = \frac{300\times 1 + 300\times 3}{600} = \frac{300 + 900}{600} = \frac{1200}{600} = 2 \]

    第二步：看这个数成立吗 —— 前段的真值是 \(1\)，后段的真值是 \(3\)，都不是 \(2\) ✗

    第三步：算每段各自的标准误。每段 \(100\) 点、\(\sigma=1\)：

    \[ \frac{\sigma}{\sqrt{100}} = \frac{1}{10} = 0.1 \]

    手算对照表（原代码打印的分段表换成这张）：

    10.3 大滞后处自相关估计不可靠 → 截断或加权¶

    这一点 7.2 节已经讲透了机制，这里给出「该截到哪」的实操判断。

    判断依据：估计的标准差大致按 \(1/\sqrt{N-\lvert m\rvert}\) 增长。 所以「可用样本对」还剩多少，直接决定了一个估计值值不值得信。

    滞后截断位置 \(M\) 每点可用样本对 判断
    \(M = N/10\) \(0.9N\) 很安全 ✓
    \(M = N/4\) \(0.75N\) 可以接受
    \(M = N/2\) \(0.5N\) 方差已明显增大 ⚠
    \(M = 0.9N\) \(0.1N\) 基本不可用 ✗

    「截断到哪」对整体误差的影响，可以手算出来。 把不同截断长度下「前 \(M\) 个滞后上的 RMS 误差」估出来。

    效应 随 \(M\) 增大 原因

    这个结论说明什么：「数据用满」不等于「结果更好」 RMS 曲线也是一个U 形 —— 和信息增加、噪声增加这两个方向的 竞争结果完全一致。这和 9.3 节的滑动平均是同一个道理

    注意最优点落在 \(M \approx N/4\) 附近，而不是前面表里给的 \(N/10\)。 两个数字不矛盾，因为量的是不同的东西：

    判据 关心什么 答案
    安全性 单个滞后的估计靠不靠得住 截到 \(N/10\) ✓
    最优性 整段滞后用下来平均误差最小 约 \(N/4\) ✓

    \(N/4\) 附近每点仍有约 \(75\%\) 的样本对可用，对平稳性良好的数据是安全的； 但如果数据可能有非平稳，或者对末端的可靠性特别在意， 用更保守的 \(N/10\) 更稳

    大滞后处的第二个对策：加权（加窗）

    做法：把估计出来的自相关乘上一个从中间向两端衰减的窗：

    \[ \tilde R_w(m) = w_m\,\hat R(m), \qquad w_0 = 1,\ w_m \to 0\ (m\to M) \]

    效果：大滞后处（\(m\) 大、方差大）的项被压小， 小滞后处（信息可靠）的项基本保持

    代价：又引入一点偏差 —— 因为真值 \(R(m)\) 也被乘上了 \(w_m\)

    import numpy as np

rng = np.random.default_rng(42)
a, sigma_w, N, R, burn = 0.8, 1.0, 256, 4000, 200
w = rng.normal(0.0, sigma_w, size=(R, N + burn))
xx = np.zeros((R, N + burn))
for n in range(1, N + burn):
    xx[:, n] = a * xx[:, n - 1] + w[:, n]
x = xx[:, burn:]

def true_R(k):
    return sigma_w ** 2 / (1 - a ** 2) * a ** abs(k)

def ac_unb(x, k):
    n = x.shape[1]
    if k == 0:
        return (x * x).sum(axis=1) / n
    return (x[:, :-k] * x[:, k:]).sum(axis=1) / (n - k)

M = 32
print("AR(1): a =", a, "  N =", N, "  加窗截断长度 M =", M)
print("巴特利特窗：w_k = 1 - k/(M+1)")
print()
print("滞后k   理论R(k)   不加窗MSE   加窗MSE    MSE 改善倍数")
for k in [0, 4, 8, 12, 16, 24, 32]:
    est = ac_unb(x, k)
    mse_raw = float(((est - true_R(k)) ** 2).mean())
    wk = 1.0 - k / (M + 1)
    mse_win = float(((wk * est - true_R(k)) ** 2).mean())
    print("%-8d %-11.6f %-12.6f %-11.6f %.3f"
          % (k, true_R(k), mse_raw, mse_win, mse_raw / mse_win))

    「加窗 MSE」一列随 \(k\) 增大反而单调下降 因为真值也小，绝对误差自然小 ✓
    注意这是「相对真值」的误差 加窗后估计值被压小了，而真值也小，所以误差小 ✓

    关键的一点在前面那两列： 「不加窗 MSE」从 \(0.266\) 降到 \(0.160\) 之后就基本不再下降（\(k=4\) 到 \(k=32\) 都在 \(0.15\!-\!0.20\) 之间徘徊）。 这说明不加窗时估计误差被一个「本底」卡住了，而这个本底正是大滞后处的高方差 加上窗之后，误差就能继续往下走

    加窗不是「免费去噪」，而是「换一种错法」

    这一点必须说清，否则会误以为「加窗总是更好」⚠

    窗做了什么：把 \(\hat R(m)\) 乘上 \(w_m\)。 这同时作用于真值部分和噪声部分：

    成分 乘窗之后 后果
    真值 \(R(m)\) 被压成 \(w_mR(m)\) 引入偏差 ✗
    估计噪声 也被压成 \(w_m\cdot\text{noise}\) 降低方差 ✓

    所以选取截断长度 \(M\) 和窗形，本质上是在选一个最优点， 和 9.3 节那个「滑动平均的窗宽」是完全同构的问题

    实践中的经验做法：

    做法 说明
    截断到 \(M \approx N/10\) 附近 每点仍有约 \(90\%\) 的可用样本对 ✓
    用巴特利特窗、汉宁窗等 保证加窗后的自相关仍然是非负定的 ⚠
    不要随手用矩形窗 会产生负的谱估计值 ✗

    最后一行与后续课程直接相关： 谱估计里如果自相关被加上了一个不当的窗， 反变换出来的功率谱可能出现负值 —— 而功率谱按定义不可能为负 这就是「窗的形状必须让自相关保持非负定」这条要求的来源 ✓

    典型例题¶

    例题 1：验证样本均值无偏并求方差¶

    设 \(X_1,\dots,X_N\) 独立同分布，\(E[X_n] = \mu\)，\(\operatorname{Var}(X_n) = \sigma^2\)。 证明 \(\hat\mu = \frac1N\sum_{n=1}^{N}X_n\) 无偏，并求 \(\operatorname{Var}(\hat\mu)\)。

    思路

    用期望的线性性算 \(E[\hat\mu]\)；用「独立时方差可加」算 \(\operatorname{Var}(\hat\mu)\)。 关键是每一步都要说清用了哪条性质。

    解答

    第一部分：无偏

    \[ E[\hat\mu] = E\!\left[\frac1N\sum_{n=1}^{N}X_n\right] = \frac1N E\!\left[\sum_{n=1}^{N}X_n\right] \]

    这里把常数 \(\frac1N\) 提到期望外面（齐次性）。接着把期望送进求和号：

    \[ = \frac1N\sum_{n=1}^{N}E[X_n] = \frac1N\sum_{n=1}^{N}\mu = \frac1N\cdot N\mu = \mu \]

    所以 \(\operatorname{bias}(\hat\mu) = \mu - \mu = 0\)，无偏

    第二部分：方差

    \[ \operatorname{Var}(\hat\mu) = \operatorname{Var}\!\left(\frac1N\sum_{n=1}^{N}X_n\right) \]

    常数提出来要平方：

    \[ = \frac{1}{N^2}\operatorname{Var}\!\left(\sum_{n=1}^{N}X_n\right) \]

    独立性在这里第一次起作用：独立时和的方差等于方差的和：

    \[ = \frac{1}{N^2}\sum_{n=1}^{N}\operatorname{Var}(X_n) = \frac{1}{N^2}\cdot N\sigma^2 = \frac{\sigma^2}{N} \]

    第三部分：由这两条还能顺带得到一致性

    \[ \text{MSE}(\hat\mu) = 0^2 + \frac{\sigma^2}{N} \to 0 \quad (N\to\infty) \]

    由 MSE 判据，\(\hat\mu\) 一致

    第四部分：如果不独立会怎样

    若 \(\operatorname{Cov}(X_i,X_j) = c \neq 0\)（\(i\neq j\)），那么

    \[ \operatorname{Var}\!\left(\sum_{n=1}^{N}X_n\right) = N\sigma^2 + 2\sum_{i \lt j}\operatorname{Cov}(X_i,X_j) = N\sigma^2 + N(N-1)c \]

    除以 \(N^2\)：

    \[ \operatorname{Var}(\hat\mu) = \frac{\sigma^2}{N} + \frac{N(N-1)}{N^2}c \approx \frac{\sigma^2}{N} + c \]

    注意 \(c\) 那一项不随 \(N\) 衰减 ⚠

    情形 方差行为
    独立 \(\propto 1/N\) → 趋于 \(0\) ✓
    有正相关 趋于常数 \(c\) → 不趋于 \(0\) ✗

    结论：「无偏」不需要独立性，但「方差趋于 \(0\)」需要。 这正是信号处理里自相关不为零时，估计量方差被抬高、 有效样本数小于名义样本数的原因

    例题 2：证明 \(S^2\) 无偏（一步不跳）¶

    设 \(X_1,\dots,X_N\) 独立同分布，\(E[X_n]=\mu\)、\(\operatorname{Var}(X_n)=\sigma^2\)。 证明 \(E\!\left[\sum_{n}(X_n-\bar X)^2\right] = (N-1)\sigma^2\)。

    思路

    把 \(X_n - \bar X\) 拆成 \((X_n-\mu) - (\bar X-\mu)\)， 用恒等式 \(\sum(X_n-\bar X)^2 = \sum(X_n-\mu)^2 - N(\bar X-\mu)^2\)。

    解答

    第一步：换元

    记 \(Y_n = X_n - \mu\)，则 \(E[Y_n] = 0\)、\(\operatorname{Var}(Y_n) = \sigma^2\)， 并且 \(\bar Y = \bar X - \mu\)。于是

    \[ X_n - \bar X = Y_n - \bar Y \]

    第二步：展开

    \[ \sum_{n=1}^{N}\left(Y_n-\bar Y\right)^2 = \sum_{n=1}^{N}Y_n^2 - 2\bar Y\sum_{n=1}^{N}Y_n + N\bar Y^2 \]

    第三步：用 \(\sum Y_n = N\bar Y\) 化简中间项

    \[ -2\bar Y\cdot N\bar Y = -2N\bar Y^2 \]

    与最后一项 \(+N\bar Y^2\) 合并：

    \[ \sum_{n=1}^{N}\left(X_n-\bar X\right)^2 = \sum_{n=1}^{N}Y_n^2 - N\bar Y^2 \]

    第四步：逐项取期望

    第一项：因为 \(E[Y_n]=0\)，所以 \(E[Y_n^2] = \operatorname{Var}(Y_n) = \sigma^2\)：

    \[ E\!\left[\sum_{n=1}^{N}Y_n^2\right] = \sum_{n=1}^{N}\sigma^2 = N\sigma^2 \]

    第二项：因为 \(E[\bar Y]=0\)，所以 \(E[\bar Y^2] = \operatorname{Var}(\bar Y) = \sigma^2/N\)：

    \[ E\!\left[N\bar Y^2\right] = N\cdot\frac{\sigma^2}{N} = \sigma^2 \]

    第五步：相减

    \[ E\!\left[\sum_{n=1}^{N}(X_n-\bar X)^2\right] = N\sigma^2 - \sigma^2 = (N-1)\sigma^2 \]

    所以 \(\frac{1}{N-1}\sum(X_n-\bar X)^2\) 是无偏的 而 \(\frac1N\sum(X_n-\bar X)^2\) 的期望是 \(\frac{N-1}{N}\sigma^2\)，偏低 ✗

    这个 \((N-1)\) 的物理来源： 约束 \(\sum(X_n-\bar X) = 0\) 让 \(N\) 个离差只剩 \(N-1\) 个独立的

    例题 3：推导 MSE 分解并核对一个数值¶

    (a) 证明 \(\text{MSE}(\hat\theta) = \operatorname{bias}^2 + \operatorname{Var}\)。 (b) 取 \(\sigma^2 = 4\)、\(N = 8\)，用 \(\hat\sigma_N^2 = SS/N\) 算出三个量的数值。

    思路

    (a) 在 \(\hat\theta-\theta\) 里加一项减一项 \(E[\hat\theta]\)。 (b) 直接代入 \(\operatorname{bias} = -\sigma^2/N\) 和 \(\operatorname{Var} = \frac{2\sigma^4(N-1)}{N^2}\)。

    解答

    (a) 分解

    关键一步是在括号里加减 \(E[\hat\theta]\)：

    \[ \hat\theta - \theta = \left(\hat\theta - E[\hat\theta]\right) + \left(E[\hat\theta] - \theta\right) \]

    记 \(A = \hat\theta - E[\hat\theta]\)（随机量，均值为 \(0\)）， \(b = E[\hat\theta]-\theta\)（常数，就是偏差）。则 \(\hat\theta-\theta = A+b\)。

    \[ \text{MSE} = E\!\left[(A+b)^2\right] = E\!\left[A^2\right] + 2b\,E[A] + b^2 \]

    因为

    \[ E[A] = E[\hat\theta] - E\!\left[E[\hat\theta]\right] = E[\hat\theta]-E[\hat\theta] = 0 \]

    所以交叉项为零，剩下

    \[ \text{MSE} = \underbrace{E\!\left[\left(\hat\theta-E[\hat\theta]\right)^2\right]}_{\operatorname{Var}(\hat\theta)} + \underbrace{b^2}_{\operatorname{bias}^2} \]

    证毕

    (b) 数值

    \[ \operatorname{bias} = -\frac{\sigma^2}{N} = -\frac48 = -0.5, \qquad \operatorname{bias}^2 = 0.25 \]
    \[ \operatorname{Var} = \frac{2\sigma^4(N-1)}{N^2} = \frac{2\cdot 16\cdot 7}{64} = \frac{224}{64} = 3.5 \]
    \[ \text{MSE} = 0.25 + 3.5 = 3.75 \]

    对照无偏的 \(S^2\)（它的方差是 \(\frac{2\sigma^4}{N-1} = \frac{32}{7}\approx 4.571\)）：

    估计量 偏差² 方差 MSE
    \(\hat\sigma_N^2\)（除 \(N\)） \(0.25\) \(3.5\) \(3.75\) ✓
    \(S^2\)（除 \(N-1\)） \(0\) \(4.571\) \(4.571\)

    有偏的那个 MSE 更小 ✓ —— 这与 3.3 节的讨论一致。

    例题 4：自相关估计的分母选择¶

    一条长度 \(N = 256\) 的记录，要估计 \(R(m)\)。 (a) 写出两个估计量并说明偏差。(b) 若只用到 \(m = 8\)，两者的偏差各是多少（用 \(R(8)\) 的比例表示）？ © 若要算到 \(m = 200\)，会有什么问题？

    思路

    (a) 分母 \(N-\lvert m\rvert\) 无偏，分母 \(N\) 有偏。难点在别把「配对数量」和「分母」搞混。 (b) 代入 \(\operatorname{bias} = -\frac{\lvert m\rvert}{N}R(m)\)。 © 看可用样本对还剩多少。

    解答

    (a) 两个估计量

    \[ \hat R(m) = \frac{1}{N-\lvert m\rvert}\sum_{n=0}^{N-1-\lvert m\rvert}x_{n+m}x_n^{*} \qquad\text{（无偏）} \]
    \[ \tilde R(m) = \frac{1}{N}\sum_{n=0}^{N-1-\lvert m\rvert}x_{n+m}x_n^{*} \qquad\text{（有偏）} \]

    注意两者的求和范围完全相同（都是 \(N-\lvert m\rvert\) 项）， 只有分母不同 ⚠ —— 这是最容易看错的一点。

    \(\tilde R(m)\) 的偏差：

    \[ E\!\left[\tilde R(m)\right] = \frac{N-\lvert m\rvert}{N}R(m) \ \Longrightarrow\ \operatorname{bias} = -\frac{\lvert m\rvert}{N}R(m) \]

    (b) \(m=8\)、\(N=256\) 时的偏差

    \[ \frac{\lvert m\rvert}{N} = \frac{8}{256} = \frac{1}{32} = 3.125\% \]

    所以 \(\tilde R(8)\) 的期望是 \(R(8)\) 的 \(96.875\%\) —— 偏低约 \(3.1\%\)

    这个量级通常可以接受，尤其考虑到它能用 FFT 计算。 课件的说法正是：\(\lvert m\rvert \ll N\) 时偏量很小，是渐进无偏的

    © 算到 \(m = 200\) 会怎样

    问题 具体表现
    偏差 \(\frac{200}{256} = 78\%\)，\(\tilde R(200)\) 期望只有真值的 \(22\%\) ✗
    方差 可用样本对只剩 \(256-200 = 56\) 个，方差比 \(m=0\) 时大得多 ⚠
    真值本身 若 \(R(m)\) 已衰减到接近 \(0\)，则估计值基本是噪声 ✓

    结论：\(m = 200\) 处的估计既偏又散，不应作为结论依据 ✗

    合理做法：

    做法 说明
    只用到 \(m \approx 25\)（即 \(N/10\)） 偏差约 \(10\%\)，可用样本对仍有 \(90\%\) ✓
    若一定要看更远的滞后 用更长的记录，而不是硬算 ✗
    用参数模型（AR 等） 由少量参数推出整条自相关 ✓

    一个容易犯的错误： 看到 \(\hat R(m)\) 在大滞后处有周期性起伏， 就断言「信号里有周期成分」✗ —— 那通常只是可用样本对太少造成的估计噪声

    自测¶

    Q1 判断：「既然样本均值是无偏的，那么任何由它算出来的量都是无偏的。」

    提示

    回想 \(\hat\sigma_N^2\) 和 \(S^2\) 的差别，以及「无偏性不能通过函数传递」。

    解答

    不对，这是错的 ✗

    反例一：样本方差

    \(\bar X\) 无偏，但 \(\frac1N\sum(X_n-\bar X)^2\) 的期望是 \(\frac{N-1}{N}\sigma^2\)， 偏低 ✗ 要用 \(\frac{1}{N-1}\) 才无偏

    反例二：一般函数的传递性

    \[ E[g(\hat\theta)] \neq g\!\left(E[\hat\theta]\right) \quad\text{除非 } g \text{ 是仿射函数} \]

    为什么：期望只对线性运算可以随意进出函数。 一旦套上平方、取倒数、取对数这类非线性函数，就不成立了

    一个直观的检验办法：

    问题 判断
    \(g\) 是线性（\(ax+b\)）？ 无偏性可以传递 ✓
    \(g\) 是非线性？ 一般不能传递，要单独验证 ✗

    实际影响：估计标准差 \(\sigma\) 时， \(\sqrt{S^2}\) 不是 \(\sigma\) 的无偏估计 （因为开方是凹函数，由 Jensen 不等式 \(E[\sqrt{S^2}] \lt \sqrt{E[S^2]} = \sigma\)， 所以它偏低）

    Q2 两个无偏估计量 \(A\)、\(B\)，\(\operatorname{Var}(A) = 4\)、\(\operatorname{Var}(B) = 1\)。 (a) 哪个更有效？(b) 若想用 \(A\) 达到 \(B\) 的精度，样本量要增加几倍？

    提示

    (a) 方差越小越有效。(b) 用方差与样本量成反比。

    解答

    (a) \(B\) 更有效，因为 \(\operatorname{Var}(B) \lt \operatorname{Var}(A)\)

    相对效率：

    \[ \frac{\operatorname{Var}(A)}{\operatorname{Var}(B)} = \frac{4}{1} = 4 \]

    要点：\(B\) 「相当于 \(A\) 用了四倍数据」

    (b) 因为 \(\operatorname{Var} \propto 1/N\)，要让方差从 \(4\) 降到 \(1\)， 需要把 \(N\) 增加 \(4\) 倍

    验证：

    估计量 样本量 方差
    \(A\) \(N\) \(4\)
    \(A\) \(4N\) \(1\) ✓
    \(B\) \(N\) \(1\) ✓

    一般公式：

    \[ \frac{N_A}{N_B} = \frac{\operatorname{Var}(B)}{\operatorname{Var}(A)}\ \text{的倒数} = \frac{\operatorname{Var}(A)}{\operatorname{Var}(B)} = 4 \]

    注意这里没有 \(\sqrt{\ }\) ⚠ 因为「样本量」对应的是方差的反比关系， 只有换算到标准差才会出现 \(\sqrt{\ }\)：

    \[ \text{std} \propto \frac{1}{\sqrt N} \]

    把这两件事分开记：

    指标 与 \(N\) 的关系
    方差 \(\propto 1/N\)
    标准差（标准误） \(\propto 1/\sqrt N\) ✓

    Q3 用 1000 个样本估出 \(\hat\mu = 10.0\)，样本标准差 \(s = 5.0\)。 (a) 标准误是多少？(b) 想把这个标准误减半，样本量要多少？© 报告该怎么写？

    提示

    (a) \(s/\sqrt N\)。(b) 用 \(\text{std}\propto 1/\sqrt N\)。© 「估计值 ± 标准误」。

    解答

    (a) 标准误

    \[ \widehat{\text{std}}(\hat\mu) = \frac{s}{\sqrt N} = \frac{5.0}{\sqrt{1000}} = \frac{5.0}{31.6228} \approx 0.1581 \]

    (b) 减半需要的样本量

    设目标标准误 \(0.0791\)。由 \(\frac{s}{\sqrt N} = 0.0791\)：

    \[ \sqrt N = \frac{5.0}{0.0791} \approx 63.246 \quad\Longrightarrow\quad N \approx 4000 \]

    样本量要增加 \(4\) 倍 ✓ —— 这正是「标准差 \(\propto 1/\sqrt N\)」的直接后果

    一般公式：精度提高 \(k\) 倍，样本量需增加 \(k^2\) 倍

    © 报告写法

    \[ \hat\mu = 10.0 \pm 0.16 \qquad(\text{1 倍标准误}) \]
    \[ \hat\mu = 10.0 \pm 0.32 \qquad(\text{2 倍标准误，约 95\%}) \]

    注意几件事 ⚠

    注意点 说明
    \(\pm\) 后面是标准误，不是 \(s\) \(s = 5.0\) 是数据的散布，不是估计的不确定度 ✗
    有效位数要匹配 \(10.0\pm0.16\) 合理；写成 \(10.0000\pm0.1581\) 是假精度 ⚠
    不要漏掉 \(\pm\) 只报 \(10.0\) 会让人以为它是精确的真值 ✗

    Q4 为什么说「偏差-方差权衡」是一种「换法」而不是「免费午餐」？ 举一个本课程里的例子说明它什么时候不划算。

    提示

    想 6.5 节那个往 \(0\) 收缩的例子，以及真值 \(\mu = 100\) 时会怎样。

    解答

    为什么不是免费午餐

    因为 MSE 是两项之和：

    \[ \text{MSE} = \operatorname{bias}^2 + \operatorname{Var} \]

    降低方差的做法，几乎总会同时抬高偏差 只有当

    \[ \Delta\operatorname{bias}^2 \lt \Delta\operatorname{Var} \]

    时总误差才变小。这是一个必须逐案核算的条件 ⚠

    什么时候不划算：收缩的方向错了

    6.5 节里往 \(0\) 收缩之所以成功，是因为真值 \(\mu = 1\) 离 \(0\) 不远：

    真值 \(\mu\) MSE(样本均值) MSE(\(0.5\bar X\)) 结果
    \(1\) \(1.0\) \(0.5\) 收缩赢 ✓
    \(100\) \(1.0\) \(2500.25\) 收缩惨败 ✗

    第二行的 \(2500\) 从哪来：偏差是 \((1-0.5)\mu = 50\)， 平方后就是 \(2500\) —— 偏差随真值线性增长，平方后变成灾难

    本课程里的例子（谱估计）： 为了降低周期图的方差而平滑（分段平均、加窗）， 代价是频率分辨率变差。

    平滑力度 方差 分辨率 适用
    不平滑 大 ✗ 最高 ✓ 要看窄带的细节
    中等平滑 中等 中等 通用场合 ✓
    强平滑 小 ✓ 很差 ✗ 只看宽的谱形

    如果信号里有两个靠得很近的谱峰， 强平滑会把它们抹成一个包 —— 这时「降方差」换来的代价无法接受 ✗

    所以正确的问法是：

    问题 含义
    我要看什么？ 决定「偏差」打在哪个方向上要不要紧 ✓
    偏差和方差的量级各是多少？ 决定这笔交换划不划算 ✓
    有没有更聪明的拉法？ 用数据决定方向（如参数模型）比固定方向更好 ✓

    一句话总结： 权衡成立的前提是「拉的方向大致对」； 方向错了，偏差的平方会迅速吃掉一切收益

    小结¶

    要记住的 为什么
    真实参数 \(\mu\)、\(R(m)\) 永远不可知 只有一条有限长的记录，估计量本身是随机变量 ⚠
    估计量是随机变量，估计值是一个数 所有性质（无偏/有效/一致）都是针对估计量说的 ✓
    偏差 \(= E[\hat\theta]-\theta\) 是「反复使用的长期平均」与真值之差，不是某一次误差 ✓
    样本均值无偏，\(\operatorname{Var} = \sigma^2/N\) 期望的线性性；方差公式需要独立性 ⚠
    样本方差除 \(N\) 偏低 \(\sigma^2/N\)，除 \(N-1\) 无偏 用 \(\bar X\) 代替 \(\mu\) 损失一个自由度 ✓
    有效性 = 方差小 只在都无偏时才好比较；无偏估计量的 MSE 就等于方差 ✓
    一致性 = 依概率收敛 说的是「偏离的可能性趋于 \(0\)」，不是「一定等于真值」⚠
    MSE = 偏差² + 方差 交叉项因 \(E[\hat\theta-E[\hat\theta]]=0\) 而消失 ✓
    MSE 是无偏与有效的统一标准 「无偏」只管一列；MSE 把两种错法合成一个数 ✓
    偏差不会靠加数据消掉 \(N\) 只减方差；系统性偏差必须改估计量 ⚠
    精度只按 \(\sqrt N\) 增长 精度提高 \(2\) 倍要 \(4\) 倍数据；\(10\) 倍要 \(100\) 倍 ⚠
    自相关分母选 \(N\) 还是 \(N-\lvert m\rvert\) 前者有偏但可 FFT；后者无偏但计算不便 ✓
    大滞后处自相关估计不可靠 可用样本对只剩 \(N-\lvert m\rvert\)，偏差与方差同时恶化 ⚠
    偏差-方差权衡：小偏差换大方差降幅 加窗、平滑、正则化都是这一件事 ✓
    加权/加窗的前提是「方向对」 真值大时，固定方向的收缩会灾难性失败 ⚠
    报告要写「估计值 ± 标准误」 单独一个数字传达不出不确定度 ✓
    非平稳数据要分段估计 整体平均可能在任何时刻都不成立 ⚠
    遍历性是信号处理里的一致性假设 有时间平均趋于系综平均，估计才有意义 ✓
    四条评价标准各有分工 无偏管「准不准」、有效管「稳不稳」、一致管「数据多了行不行」、充分管「信息用没用尽」✓
    矩估计：令样本矩 \(=\) 理论矩再解 步骤固定，结果既无偏又一致，但可能不唯一 ✓
    极大似然：先写似然，再取对数求导置零 对数把连乘变连加，求导后方程通常最好解 ✓
