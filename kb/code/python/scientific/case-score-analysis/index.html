    前面 13 页讲的是零件，这一页把它们装成一台机器。

    数据分析真正的难点不在「会不会用 groupby」，而在判断顺序： 先看还是先改？缺失值填均值还是中位数？异常值是删掉还是保留标记？ 这些问题的答案不来自语法，来自你手上的任务。

    所以这一页的每条代码前面都有一句「为什么这么做」。 读完你应当能做到：拿到一份来历不明的表， 按固定顺序把它变成一份别人能复核的统计报告。

    这一页的主线

    本页给出一条别人能复核的分析顺序：先看清数据（第三节），再清洗（第四节），然后派生指标（第五节）、 分组统计（第六节）、找出关键对象（第七节），最后画图核对并导出报告。

    每条代码前面都有一句「为什么这么做」—— 那才是本页真正要带走的东西，代码本身都可以替换。

    这页最容易搞错的三件事

    看起来差不多 实际差别 后果
    「缺失值」与「异常值」 缺失是空的，异常是填了但不可信 只查 isna() 会漏掉 999 分这种「有值但荒谬」的记录
    「删掉异常行」与「标记后填充」 前者少一个人，后者少一个格子 删行会让各班人数、排名全部改变，且无法追溯
    「标准差」与「变异系数」 后者是标准差除以均值 各科均值不同，直接比标准差会得出错误结论

    这三条在后面都有实测代码验证，不用背

    这页需要的库：NumPy、pandas、Matplotlib。 版本不必与示例一致，行为在这个量级的版本上是稳定的。

    能力 具体表现
    看清数据 拿到表先跑一遍体检，能说出「哪里脏」而不是「感觉脏」
    按序清洗 知道列名、类型、重复、异常、缺失的先后顺序为什么不能换
    派生指标 用 pd.cut 分等级、用 rank 排名，并说得出边界值归到哪一档
    分组汇总 一次 agg 拿到人数与四个统计量，而不是反复 groupby
    找关键对象 全班第一、各科最高分、最不均衡的科目
    画图核对 图能画出来，且输出里只留可核对的数字
    写出报告 导出 CSV 与文本报告，全程用临时目录且不留垃圾
    讲清假设 说得出每一步用了什么假设、假设错了会怎样

    一、任务描述¶

    场景：整理一份由人工录入的成绩表，登记时多人经手， 最后要交出一份班级统计报告，回答下面四个问题：

    报告要回答的问题 靠哪几步得到
    每个班有多少人、平均分多少、最好和最差各是谁 分组统计
    全班第一是谁，各科最高分分别多少 找关键对象
    哪门课最不均衡（有人很高有人很低） 标准差与变异系数
    等级分布（优秀/良好/及格各多少人） pd.cut 分档

    为什么要先把任务写清楚：

    因为清洗没有标准答案，判断依据是任务。 同一个「语文缺考」的格子：

    任务 合理处理 为什么
    统计班级均分 用中位数补上 缺考学生的水平不该让整班均分突然掉下来，也不该整行删掉
    统计缺考人数 必须保留空白，不能填 填了以后你就再也数不出缺考人数了 ⚠
    统计总分排名 要么补，要么把该生排除在排名外并注明 两者口径不同，报告里必须说明用哪一种

    结论：先定口径，再动手。反过来做，等于先猜答案。

    清洗不是「越干净越好」

    把「看着不对」的行直接删掉，是最常见的错误做法：

    做法 表面效果 真实代价
    df = df[df["语文"] > 0] 之类粗暴过滤 后面算得很顺 样本结构变了：某些人整行消失，班级人数对不上
    把异常值删掉 均值「好看」了 无法回答「有几个人的成绩不可信」
    把缺失值填 0 代码不用改 平均分被系统性拉低，比不填更糟 ⚠

    本案例采用的策略是：改格子，不改行。 具体理由在第四节展开

    二、构造一份「脏」数据¶

    为什么要自己造数据：真实成绩表涉及隐私，不能放进教学材料； 而且真实数据每次都不一样，输出无法复核。 造一份固定种子的模拟数据，既有真实的「脏」，又能保证每次跑出来完全一样

    模拟数据里要埋进五类最常见的问题：

    # 问题 本案例里的样子 为什么危险
    1 缺失值 语文有两处空白 求均值时 pandas 会跳过，但求「总分」会把整行变成缺失 ⚠
    2 类型错 数学整列是文本，其中一个是「缺考」 整列无法参与算术，df["数学"].mean() 直接报错
    3 重复行 同一个学生出现两次 各类计数、求平均全都被多算一次 ⚠
    4 异常值 语文 999 分、英语 -5 分 不报错、不缺失，但均值被拉到毫无意义
    5 列名多余空格 " 姓名 "、"班级 " 按名字取列报 KeyError，合并两张表时更是对不上

    先把「造数据」这一步封装成模块，后面每个代码块都能直接调用它。 这也顺便演示了工程上的一个习惯：把「造数据/清洗/汇总」写成函数，主流程只做编排。

"""案例用的模拟数据模块。

build_dirty() 造一份含五类问题的成绩表（固定种子，结果可复现）。
build_clean() 按案例的清洗顺序把它洗干净。
"""
import numpy as np
import pandas as pd

SUBJECTS = ["语文", "数学", "英语"]


def build_dirty():
    """造一份「脏」成绩表：固定种子 → 每次运行完全相同。"""
    rng = np.random.default_rng(42)
    n = 30
    df = pd.DataFrame({
        " 姓名 ": [f"学生{i:02d}" for i in range(1, n + 1)],
        "班级 ": rng.choice(["一班", "二班"], size=n),
        "语文": rng.normal(78, 9, n).round(1),
        "数学": rng.normal(72, 14, n).round(1),
        "英语": rng.normal(80, 7, n).round(1),
    })

    df.loc[[3, 17], "语文"] = np.nan          # 问题 1：缺失值
    df["数学"] = df["数学"].astype(str)        # 问题 2：整列变成文本
    df.loc[5, "数学"] = "缺考"                 #         其中一个不是数字
    df.loc[11, "语文"] = 999.0                # 问题 4：越界异常值
    df.loc[7, "英语"] = -5.0                  #         另一门也有
    # 问题 3：同一行完全重复一遍
    df = pd.concat([df, df.iloc[[0]]], ignore_index=True)
    return df


def build_clean():
    """返回清洗后的干净表（顺序与正文第四节一致）。"""
    df = build_dirty()
    df.columns = df.columns.str.strip()                       # ① 列名去空格
    for col in SUBJECTS:
        df[col] = pd.to_numeric(df[col], errors="coerce")     # ② 类型转换
    df = df.drop_duplicates().reset_index(drop=True)          # ③ 去重
    for col in SUBJECTS:
        df[col] = df[col].mask((df[col] < 0) | (df[col] > 100))
    for col in SUBJECTS:                                      # ④ 越界置空
        df[col] = df[col].fillna(df[col].median())            # ⑤ 中位数填充
    return df


if __name__ == "__main__":
    print("参与统计的科目 :", SUBJECTS)
    print("脏数据规模     :", build_dirty().shape)
    print("干净数据规模   :", build_clean().shape)

    四、清洗：从脏到干净¶

    清洗顺序不能随便换。下面这个顺序，每条都有理由：

    顺序 动作 为什么必须在此时做
    1 列名去空格 后面每一步都要按列名取值，名字不对寸步难行
    2 类型转换 文本列无法比较、无法去重、无法算统计量
    3 去重 必须在类型统一之后：同一记录写成 "75.1" 与 75.10 时，靠数值才能判重
    4 异常值置空 必须在填充之前：先填了中位数，越界值就被混进统计量里了 ⚠
    5 缺失值填充 放在最后：它补的是「本来就空」和「刚刚被置空」两类格子，一次补完

    如果顺序反过来（先填充再去重、先置空不去重）， 你会得到「看起来也能跑」但数值悄悄错掉的结果 —— 这是最麻烦的一类错误

    写法 区间含义 60 分属于
    pd.cut(x, bins=[0, 60, 75, 85, 100])（默认 right=True） (0, 60]、(60, 75]、… 及格 ✓
    pd.cut(x, bins=[0, 60, 75, 85, 100], right=False) [0, 60)、[60, 75)、… 不及格 ⚠
    pd.cut(x, bins=[0, 60, 75, 85, 100], include_lowest=True) 最低区间的左端点含 0 用于有恰好为 0 的数据

    为什么默认要选 right=True：成绩惯例是「60 分及格」， 也就是「达到 60 就算过」→ 60 应当归到及格那一档 → 用默认值即可

    而 right=False 那个坑在于：100 分会掉出去变成 NaN —— 因为 (85, 100] 变成 [85, 100) 之后不含 100。 这就是上面边界演示里要注意的事，也是下面这条警告的内容。

    pd.cut 的三个「不报错但结果不对」

    现象 原因 后果
    满分的学生等级是 NaN 用了 right=False，右端点变成开区间 「优秀」人数少一个，还不报错 ⚠
    有个学生等级是 NaN 他的平均分落在 bins 范围之外 统计等级分布时总数对不上人数 ⚠
    标签顺序与区间顺序不匹配 bins 升序、labels 写反 等级全部错位，而且看着很合理 ⚠

    自查办法：分完档立刻 df["等级"].isna().sum()， 再确认各档人数之和等于总人数

    这三条里，前两条都源于「边界」，第三条源于「顺序」， 所以分档之后必须做一次人数核对 —— 也就是上文那句 各等级总人数合计: 30

    先解释两个词的差别：

    指标 公式 单位 能回答
    标准差 各数与均值之差的平方平均后开方 与原数据相同（分） 这门课的绝对波动有多大
    变异系数 标准差 ÷ 均值 无量纲（比例） 这门课的相对波动有多大

    为什么两个都要看：

    科目 均值 标准差 变异系数
    语文 78.46 6.43 0.0820
    数学 71.34 11.07 0.1551
    英语 78.62 5.18 0.0659
    • 语文与英语的均值几乎相同（78.46 与 78.62，差 0.16 分）→ 这两科之间直接比标准差是公平的 → 英语（5.18）比语文（6.43）更均衡。
    • 数学的均值低了 7 分 → 直接比标准差会把「难度」和「离散」混在一起。 用变异系数（0.1551，接近英语的 2.4 倍）才能说清： 数学不只是难，而且差距特别大

    结论：两把尺子指向同一个答案（数学最不均衡）， 但变异系数给出的倍数关系（约 2.4 倍）比标准差（约 2.1 倍） 更接近「相对差距」的含义，而且它不受单位影响 —— 换成百分制以外的计分方式时，标准差会变，变异系数不变

    变异系数什么时候不能用

    变异系数要除以均值，所以它只在均值明显大于 0 时有意义：

    情况 变异系数 说明
    均值 78、标准差 6.4 0.082 正常，可用 ✓
    均值为 0 附近（如误差、温差） 会爆掉或得到荒谬的大数 分母接近 0 ⚠

    上面这段流程能跑、结论对，但它仍然是「一次性脚本」。 真正交付给别人用时，下面这些改动最值钱 —— 按性价比排序：

    加断言校验 出错时才发现的成本最高 关键节点断言：人数、缺失数、异常值数在预期范围内 ✓

    import numpy as np
import pandas as pd


def clean(df, subjects, low=0, high=100):
    """清洗一份成绩表；返回（干净表, 处理记录）。"""
    log = {}
    df = df.copy()                       # 保留原始数据，不覆盖入参
    log["输入行数"] = len(df)

    df.columns = df.columns.str.strip()
    for col in subjects:
        df[col] = pd.to_numeric(df[col], errors="coerce")

    before = len(df)
    df = df.drop_duplicates().reset_index(drop=True)
    log["删除重复行"] = before - len(df)

    marks = {}
    for col in subjects:
        bad = (df[col] < low) | (df[col] > high)
        marks[col] = int(bad.sum())
        df[col] = df[col].mask(bad)
    log["越界置空"] = marks

    filled = int(df[subjects].isna().sum().sum())
    for col in subjects:
        df[col] = df[col].fillna(df[col].median())
    log["填补缺失"] = filled

    assert len(df) > 0, "清洗后没有数据，检查筛条件"
    assert df[subjects].isna().sum().sum() == 0, "仍有缺失值未处理"
    log["输出行数"] = len(df)
    return df, log

    返回 (df, log) 而不是只返回 df 「处理了多少」是结论的一部分，不该随着函数结束而消失 ✓
    用 assert 而不是注释 注释会被忽略，assert 会在数据异常时立刻停下 ✓

    为什么「直接减」会全变 NaN —— 这是 pandas 最著名的坑之一：

    表达式 得到什么 对齐方向
    错误 df - df.mean(axis=1) 每行一个数，是 Series（行索引） 按列名去匹配 → 全对不上 ⚠
    正确 df.sub(row_mean, axis=0) 同上，但显式指定 按行匹配 ✓
    对列 df - df.mean() 每列一个数，是 Series（列名） 默认按列名匹配 → 正好对上 ✓

    规律：DataFrame 减去一个 Series 时， 默认按列名对齐（相当于 axis="columns"）。 列均值恰好带着列名，所以自动对上； 而行均值带着的是行索引，拿去跟列名匹配，全部落空 → 全变缺失

    这就是「按列标准化看起来天然能跑、按行标准化必须显式写 axis」的原因 ✓

    两种标准化的区别：

    按列（每门课） 按行（每个学生）
    用什么减 该列的均值 该行的均值
    语意 「你在班里的相对位置」 「你的三科是否均衡」
    之后每列均值 ≈ 0 ✓ 不一定
    之后每行均值 不一定 ≈ 0 ✓
    适合 课程之间的比较（本页场景）✓ 偏科诊断
    写法 df.mean() 或 axis=0 df.sub(行均值, axis=0) ⚠

    结论与建议：

    要点 说明
    A 能跑，但阅读者看不出意图 不写 axis 就是在赌默认值 ⚠
    按行的写法必须显式 axis=0 漏了会得到一整表 NaN，且不报错 ⚠
    最清楚的写法 df.sub(df.mean(axis=0)).div(df.std(axis=0)) 或加注释 ✓

    通用规律：DataFrame 与 Series 做运算时，一定想清楚「按哪个轴对齐」， 并且把 axis 显式写出来。 不写虽然常常也能对， 但错的那一次不会给你任何提示

    - log["类型转换后缺失格子"]

    要记住的 为什么
    先看清，再动手 清洗不可逆；shape/info/isna/duplicated 四眼体检最便宜
    清洗顺序不能换 列名 → 类型 → 去重 → 置空 → 填充；顺序错了数值悄悄错 ⚠
    pd.to_numeric(..., errors="coerce") 把转不过去的值降级为缺失，而不是丢掉整列 ✓
    errors="ignore" 是坑 整列不转还以为转好了，bug 推后爆发 ⚠
    改格子，不改行 删行会改变样本结构；置空 + 填充保住人数与可追溯性 ✓
    异常值用业务规则判 3σ 会被极端值撑宽，150 分都抓不到 ⚠
    数值列缺失填中位数 比均值抗离群值；分类列填众数或「未知」
    填 0 不是「保守」 它等于注入一个极端值：标准差涨约 4 倍 ⚠
    pd.cut 默认右闭 60 分算及格；用 right=False 时满分 100 会变 NaN ⚠
    分组排名要写 method 默认 average 会给出 1.5 这种小数名次 ⚠
    整体均值 ≠ 各班均值的平均 人数不同，整体是加权平均
    比离散先看量纲 量纲/量级不同用变异系数，量纲相同用标准差 ✓
    均值为 0 附近不能用变异系数 除以接近 0 的数会爆掉 ⚠
    count 数非空，size 数行 有缺失时两者不同，人在缺失数据上最容易数错 ⚠
    df[列] = 筛选结果 是错的 索引对不上会变缺失，等于删行 ⚠
    行内运算显式 axis=1 漏掉会得到完全不同的结果，且不报错 ⚠
    导出用 index=False + utf-8-sig 少一列无名索引，Excel 打开中文不乱码 ✓
    输出只留可核对的量 打印行数、条数、布尔判断；不打印路径与耗时 ✓
    临时文件用完就删 中间产物没有保留价值，跑一百次也不堆垃圾 ✓
    清洗前后做对比表 它是最后一道防线：含 999 时语文均分是 111.42 ⚠
