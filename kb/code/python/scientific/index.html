    Python 科学计算与数据处理¶

    目标：把「会写 Python」变成「能用 Python 做科研与工程计算」。

    这一模块同样是每个知识点单独成页，但有两点不同：

    编程基础模块 本模块
    重点 语法要准确 方法要会用
    每页重心 概念 + 易错点 应用 + 实例 ✓
    例子来源 抽象小例子 贴近真实数据的例子 ✓

    这一模块的学法：以「任务」驱动，而不是以「API」驱动

    不要试图背完 NumPy 的所有函数 —— 那记不住，也没必要。

    正确的方式：记住遇到某类任务该用哪个库的哪类工具。

    你要做的事 用 在哪一页
    数组整体运算（不用循环） NumPy 向量化 广播与向量化
    按条件挑出数据 布尔索引 索引与筛选
    矩阵运算、解方程、特征值 np.linalg 线性代数
    读表格、按列算、分组统计 pandas pandas 三页
    数据脏（缺失/类型乱/重复） 清洗流程 数据清洗
    画图看趋势/分布 Matplotlib 可视化两页
    描述统计、相关、检验 SciPy / 手算 统计与推断
    完整做一个小项目 —— 实战案例

    知识点总览¶

    01 NumPy 数组基础
    ndarray 与 list 的区别、创建数组、dtype、形状与维度、reshape、内存布局
    核心 · 一切数值计算的地基
    02 索引与切片
    基本索引、切片、布尔索引、花式索引、np.where、视图与副本的区别
    核心 · 取数据的能力
    03 广播与向量化
    广播三条规则、ufunc、形状对齐、避免循环、向量化的收益与陷阱
    核心 · NumPy 效率的来源
    04 线性代数与随机数
    矩阵乘法、解线性方程组、逆与伪逆、特征值/SVD、范数、随机数生成器
    重要 · 与线性代数模块对接
    05 Series 与 DataFrame
    两种数据结构、索引对齐、loc/iloc、列操作、查看数据、类型
    核心 · 表格处理的起点
    06 筛选与变换
    条件筛选、多条件、isin/query、列运算、apply/map、排序与排名
    核心 · 最常用的日常操作
    07 数据清洗
    缺失值策略、类型转换、重复值、异常值识别、字符串列处理
    核心 · 真实数据的必经一步
    08 分组聚合与合并
    groupby 心智模型、agg 多种写法、透视表、merge/join/concat
    核心 · 数据分析的主力
    09 数据读写
    CSV/Excel/JSON/Parquet 的读写参数、编码问题、大文件分块、多表

    10 可视化基础

    环境要求¶

    只需要满足两点

    要求 说明
    Python 3.9 或更高 本模块用了 f-string、dict.fromkeys、np.random.default_rng 等
    NumPy / pandas / Matplotlib 三大核心库

    最省事的做法：安装 Anaconda 发行版 —— 它把 Python 与科学计算生态打包在一起，上述库开箱即用

    若已装官方 Python，一条命令补齐：

    pip install numpy pandas matplotlib scipy openpyxl

    注意：本模块多数页面用 NumPy，第 12–13 页用 SciPy 做统计检验， 第 9 页读 Excel 需要 openpyxl。

    务必确认编辑器用的是装了这些库的那个 Python —— 详细排查见 编程基础 · 环境与工具
