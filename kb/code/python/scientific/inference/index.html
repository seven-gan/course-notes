    13 统计推断入门¶

    这一页解决一个问题：手里只有一小撮数据，怎么对「全部数据」下判断，并且知道这个判断有多可靠。

    前面几页讲的是「把已有的数算清楚」——求均值、求方差、算相关系数。 那都是描述统计：数据在你手里，你只是在概括它。

    现实里更常见的是另一种处境：你不可能拿到全部数据， 只能在有限的时间里采到一小部分，然后要回答 「这批零件整体合格吗」「新方案真的更好吗」「这个差异是真实的还是碰巧」。

    这时候光会求均值不够用了，你需要一套能回答「我离真相有多远」的工具。 这套工具就是推断统计，本页把它拆成四块讲清楚：

    模块 回答的问题 本页位置
    抽样分布与中心极限定理 样本均值这个数本身有多不稳定 第三、四节
    区间估计 真值可能落在什么范围里 第五节
    假设检验 观测到的差异能不能用运气解释 第六节
    效应量与陷阱 就算真有差异，差异重要吗 第七、八节

    这页最容易搞错的三件事

    看起来像 实际含义 常见错读
    标准误 SE 估计量（如样本均值）的不确定度 误当成「个体之间的离散度」
    置信区间 一种长期覆盖真值的程序 误成「真值有 95% 概率在里面」
    p 值 H0 为真时观测到这么极端的概率 误成「H0 为真的概率」

    这三条错读在真实报告里出现得极频繁，本页会把它们逐条纠正， 并且每一处都用可运行的代码给出证据

    一、为什么需要推断统计¶

    1.1 总体与样本¶

    先把两个词定死：

    术语 英文 含义 我们能拿到吗
    总体 population 我们真正关心的全部对象（含它们的全部取值） 拿不到（太贵、太多、有破坏性）
    样本 sample 从总体里实际观测到的一小部分 能拿到
    参数 parameter 总体的某个数值特征，如总体均值 拿不到，正是要推断的目标
    统计量 statistic 样本的某个数值特征，如样本均值 能算出来

    为什么只能从样本推断总体：

    • 成本：要测完全部对象，时间和钱都不允许；
    • 不可行：有些总体是无限的（例如「某工艺未来所有批次的产品」）；
    • 破坏性：测一根绳子的抗拉强度，就得把它拉断 —— 测完总体就没了。

    所以现实流程永远是：抽样 → 算统计量 → 用统计量推断参数。 下面这段代码把「总体」和「样本」的差距直观地摆出来：

    import numpy as np

rng = np.random.default_rng(42)

# 造一个「已知总体」，只是为了讲解；现实中总体的真值看不到
population = rng.normal(loc=500.0, scale=100.0, size=100_000)

print("总体大小 N      :", population.size)
print("总体均值 mu     :", round(float(population.mean()), 3))
print("总体标准差 sigma:", round(float(population.std(ddof=0)), 3))
print()
# 现实中能拿到的：一次抽样
sample = rng.choice(population, size=30, replace=False)
print("一次抽样的样本量 n:", sample.size)
print("样本均值 xbar     :", round(float(sample.mean()), 3))
print("样本标准差 s      :", round(float(sample.std(ddof=1)), 3))
print("xbar 与 mu 的差   :",
      round(float(sample.mean() - population.mean()), 3))

    总体大小 N      : 100000
总体均值 mu     : 499.577

    注意上面这段里的一个关键前提：我们之所以知道总体均值是 499.577， 是因为那是用代码造出来的假总体，专门用来演示。 真实场景里你看不到「总体均值」那一行 —— 那正是你要花力气去估计的东西。

    1.2 抽样误差不是「错误」¶

    样本均值 508.405 与总体均值 499.577 差了 8.828，这个差叫抽样误差。

    抽样误差不是「算错了」，它是抽样这件事本身带来的、无法消除的随机偏差。 只要你不普查，它就一定存在。推断统计的全部努力， 就是把这种误差量化出来，让你知道「这个数大概能信到什么程度」。

    import numpy as np

rng = np.random.default_rng(42)
population = rng.normal(loc=500.0, scale=100.0, size=100_000)

print("总体均值 mu =", round(float(population.mean()), 3))
print("同一个总体，重复抽 5 次，每次 n = 30:")
xbars = []
for k in range(5):
    s = rng.choice(population, size=30, replace=False)
    xbars.append(float(s.mean()))
    print(f"第 {k + 1} 次: xbar = {xbars[-1]:.3f}   s = {s.std(ddof=1):.3f}")
print()
print("5 个 xbar 的最小值:", round(min(xbars), 3))
print("5 个 xbar 的最大值:", round(max(xbars), 3))
print("极差              :", round(max(xbars) - min(xbars), 3))

第 2 次: xbar = 519.937   s = 85.688

    看这五次的结果：最小 498.487，最大 519.937，极差达到 21.45。 也就是说，同样的总体、同样的样本量、同样的抽样方法， 仅仅因为「抽到谁」不同，样本均值就在 20 多的范围内跳。

    这个跳动幅度就是推断统计要度量并报告的东西。

    2.2 随机性带来的三个后果¶

    后果 含义 应对
    单次结果不可全信 一次抽样得到的均值只是「众多可能值里的一个」 报告区间，而不是只报一个点
    差异可能只是运气 两组数据看起来不同，未必说明总体不同 做假设检验
    重复实验会变 换个随机种子，结论可能翻转（尤其样本小时） 关注样本量与效应量

    「同一总体抽两次得到不同样本」不是数据质量差

    有人看到两次抽样结果不一致，就以为「采样出了问题」。恰恰相反：

    现象 正常吗 说明
    两次样本均值略有差别 正常 ✓ 这就是抽样随机性
    两次样本均值完全相同 可疑 ⚠ 可能数据被复制了、或被「挑」过
    两次差别极大 需要警惕 可能是样本量太小

    判断依据：差别有多大才算异常，不能靠感觉， 要看抽样分布的标准差（也就是下一节的标准误）。 比标准误小一个量级的差别属于正常抖动；大出好几个标准误才值得追查

    三、抽样分布与中心极限定理¶

    3.1 什么是抽样分布¶

    抽样分布指的不是「一次样本的分布」，而是：

    四、标准误与标准差：极易混淆的一对¶

    4.1 两者的定义¶

    标准差 SD 标准误 SE
    英文 Standard Deviation Standard Error
    描述谁的离散度 个体（一个一个的原始观测） 估计量（样本均值这类的统计量）
    公式 \(\sigma\) 或 \(s\) \(\sigma/\sqrt{n}\) 或 \(s/\sqrt{n}\)
    随样本量变化吗 基本不变（总体性质） 随 n 增大而变小
    回答的问题 「个体之间差多少」 「我算出的这个均值，离真值可能差多少」
    量级 大（和原始数据同量纲） 比 SD 小，小多少取决于 n

    一句话区分：

    • 想知道「一个人和另一个人能差多少」→ 看 SD；
    • 想知道「这次测出来的均值离真值可能差多少」→ 看 SE。

    4.2 两者的数值关系¶

    它们之间只差一个 \(\sqrt{n}\)：

    4.3 完整对比表¶

    对比项 SD（标准差） SE（标准误）
    描述对象 个体观测值的离散度 统计量（估计量）的不确定度
    公式 \(s = \sqrt{\frac{1}{n-1}\sum (x_i-\bar{x})^2}\) \(\mathrm{SE} = s/\sqrt{n}\)
    n 增大时 趋于总体 σ，基本不变 按 \(1/\sqrt{n}\) 缩小
    与 n 的关系 无关 \(\mathrm{SD}/\mathrm{SE} = \sqrt{n}\)
    单位 与原数据相同 与原数据相同
    在论文/报告里 描述数据分布时用 报均值时用（配置信区间）
    典型误用 报均值时错用 SD → 让人低估精度 描述个体分布时错用 SE → 让人误以为数据很集中
    常见倍数 1× 当 n = 25 时只有 SD 的 ⅕

    报「均值 ± 数字」时必须写清是 SD 还是 SE

    这两种写法看着一样，含义差好几倍：

    写法 含义 读的人会以为
    均值 ± SD 约有 68% 的个体落在这个范围内 「个体分布是这样的」✓
    均值 ± SE 关于均值的估计精度 「均值精度这么高」✓
    只写「均值 ± 数字」 没法判断 读者只能猜 ⚠

    为什么危险：同一批数据，n = 100 时 SE 只有 SD 的十分之一。 把 SD 说成 SE，等于把精度夸大了 10 倍，而且从数字上完全看不出破绽。

    写在图上的判断依据：误差棒（error bar）图例必须写明是 SD、SE 还是置信区间， 三者在同一张图上宽度差很大

    五、点估计与区间估计¶

    5.1 点估计¶

    点估计就是「用一个数去猜参数」。样本均值 \(\bar{x}\) 是总体均值 \(\mu\) 的点估计。

    点估计有两个优点：简单、好算。但它几乎肯定不等于真值。 上面的模拟已经证明：同一个总体，样本均值在 20 多的范围里跳。

    所以只报一个点估计，等于隐瞒了不确定性。区间估计就是来补这一块的。

    5.2 置信区间的正确含义¶

    置信区间（confidence interval, CI）是一个由样本算出来的区间。 它的正确解释是频率学派的：

    如果你把「抽样 → 算区间」这套流程重复很多很多次， 那么在重复得到的全部区间里，约有 95% 会包含真值。

    注意这句话的主语是「区间（程序）」，不是「真值」。

    5.3 必须纠正的常见误读¶

    「参数有 95% 的概率落在区间内」是错的

    这是最普遍的一处误读。为什么错：

    说法 对错 原因
    重复抽样时约 95% 的区间包含真值 对 ✓ 这是频率学派的定义
    这个区间有 95% 概率包含真值 不严谨 区间已经算出来了，是固定的
    参数有 95% 概率落在区间内 错 ✗ 参数是一个固定常数，不是随机变量

    核心逻辑：频率学派的概率描述的是「重复操作中某事件出现的比例」。 参数 \(\mu\) 是一个确定但未知的数 —— 它要么在区间里，要么不在， 没有「95% 概率在里面」这回事。随机的是区间，不是参数。

    一个比喻：想象你往一个固定的靶心扔飞镖。 飞镖的落点是随机的，靶心是固定的。 「约 95% 的飞镖落在靶心附近」成立； 「靶心有 95% 的概率在某支已经插在靶上的飞镖附近」就不成立

    想表达「参数的概率」该怎么办：那属于贝叶斯的范畴， 需要先给出参数的先验分布，得到的是可信区间（credible interval）， 那才可以说「参数有 95% 概率在区间内」。 两者的数字可能接近，含义完全不同，报告里必须说清是哪一种。

    六、假设检验¶

    6.1 零假设与备择假设¶

    假设检验的做法是：先假定「没有效应」，再看数据是否与这个假定相容。

    名称 符号 含义 例子
    零假设 \(H_0\) 默认假定：没有差异、没有关系 总体均值等于 100
    备择假设 \(H_1\) 与 \(H_0\) 对立：有差异 总体均值不等于 100

    为什么要把 \(H_0\) 设成「没有效应」： 因为这样我们才能算出一个具体的概率分布（有了具体参数才能算概率）。 \(H_1\) 通常是一大类可能性（均值可以是 101、105、-50……）， 没法直接算概率。所以只能反过来问：「如果是 \(H_0\)，观测到这么极端的数据有多难？」

    「p 值是零假设为真的概率」是错的

    这是 p 值最严重的一处误读。两者的区别可以用一个表说清：

    说法 对错 实际含义
    在 \(H_0\) 为真时，观测到这么极端结果的概率 对 ✓ 这就是 p 值的定义：\(P(\text{数据这么极端} \mid H_0)\)
    零假设为真的概率 错 ✗ 那是 \(P(H_0 \mid \text{数据})\)，方向反了

    为什么方向反了很要紧：条件概率不可交换。 \(P(\text{检测阳性} \mid \text{没病})\) 和 \(P(\text{没病} \mid \text{检测阳性})\) 是两个完全不同的数。

    一个具体的数字例子：某种病在人群里只有 0.1% 的患病率， 检测的假阳性率是 5%。 那么「检测阳性的人里真的得病的比例」大约只有 2% 左右， 尽管「检测阳性」对应的 p 值（假阳性率）只有 0.05。 p 值小，完全不代表 \(H_0\) 为真的概率小。

    p 值到底能告诉你什么：它只回答「数据与 \(H_0\) 的相容程度」。 要谈「\(H_0\) 为真的概率」，需要先验信息， 那是贝叶斯方法（贝叶斯因子、后验概率）的任务

    一句话总结 p 值：

    p 值写什么 它的意思是 它的意思不是
    p = 0.03 若 \(H_0\) 为真，有 3% 的机会拿到这么极端的数据 不是「\(H_0\) 有 3% 概率为真」
    p = 0.03 数据与 \(H_0\) 不太相容 不是「效应很大」
    p = 0.03 一个关于数据的概率 不是关于假设的概率

    6.4 显著性水平与两类错误¶

    显著性水平 \(\alpha\) 是你事先选定的判定门槛，常用 0.05。规则是：

    • p < α → 拒绝 \(H_0\)，称结果「统计显著」；
    • p ≥ α → 不拒绝 \(H_0\)（注意：不是「接受 \(H_0\)」）。

    只要做了判定，就可能判错。错误分两类：

    \(H_0\) 实际为真 \(H_0\) 实际为假
    判定：拒绝 \(H_0\) 第一类错误（假阳性）⚠ 概率 = α 正确判定 ✓ 概率 = 功效
    判定：不拒绝 \(H_0\) 正确判定 ✓ 概率 = 1 − α 第二类错误（假阴性）⚠ 概率 = β

    两类错误的通俗说法：

    类型 俗称 现实后果举例
    第一类错误 误报、假阳性 把无效的药判成有效，推向市场
    第二类错误 漏报、假阴性 把有效的药判成无效，错失机会

    两类错误此消彼长，无法同时压到最低

    在样本量固定的前提下：

    你调整什么 第一类错误 α 第二类错误 β 功效
    把 α 调小（如 0.05 → 0.01） 下降 ✓ 上升 ⚠ 下降
    把 α 调大（如 0.05 → 0.10） 上升 ⚠ 下降 ✓ 上升
    加大样本量 不变 下降 ✓ 上升 ✓

    关键点：只有加大样本量才能同时改善两边。 单纯调 α 只是把一种错误换成另一种，总量不会变好。

    判断依据： - 后果严重的是「误报」（如药物安全）→ 把 α 设小； - 后果严重的是「漏报」（如早期筛查）→ 把 α 放大，或直接用更高的功效目标

    6.5 统计功效¶

    功效（power）的定义：

    \[\text{功效} = 1 - \beta = P(\text{正确地拒绝} H_0 \mid H_1 \text{为真})\]

    也就是「真实存在的效应，被检测出来的概率」。常用目标是 0.80。

    功效由四个因素决定：

    因素 变大时功效 解释
    效应量（真实差异） 上升 ✓ 差异越明显越好检
    样本量 n 上升 ✓ 信息越多越好检
    显著性水平 α 上升 ✓ 门槛越松越容易拒绝
    数据噪声 σ 下降 ⚠ 噪声越大越难分辨信号

    功效低的后果：你做了一个「阴性」的实验， 但你无法区分「真的没有效应」和「效应存在但没检出」。 这种阴性结果几乎没有信息量

    为什么非参数方法有时更强：偏态分布里的极端值会拉大标准差、稀释信号， 而秩检验把这些极端值只当成「最大的那一个」，不受其具体数值影响， 因此在厚尾数据上往往更敏感。

    代价是什么：

    参数检验 非参数检验
    前提要求 正态、方差齐 几乎没有 ✓
    数据利用 用具体数值 只用排序
    数据本来就正态时 更强（功效更高）✓ 损失一些功效 ⚠
    报的结论 均值之差 往往是「中位数/分布位置」之差
    有极端离群值时 容易被带偏 ⚠ 稳健 ✓

    判断依据：

    • 数据近似正态、无异常离群值 → 优先参数检验（功效高，结论更好解释）
    • 明显偏态、有极端值、或数据本身就是有序等级 → 优先非参数
    • 两种都做，结论一致 → 报告更有底气；结论不一致 → 必须报告并解释 ⚠

    7.4 陷阱四：只报 p 值，不报效应量与置信区间¶

    p 值只回答「有没有差异」，不回答「差异多大」。 所以完整报告至少要三样：

    该报什么 回答的问题 缺了会怎样
    效应量（如 Cohen's d） 差异有多大 读者无法判断实际重要性 ⚠
    置信区间 差异的可能范围 读者不知道精度
    p 值 差异是否不像巧合 读者不知道是否稳健

    更关键的：置信区间包含了 p 值的信息。 对于「差异为 0」这个 \(H_0\)，95% 区间不包含 0 ⟺ 双侧 p < 0.05。

    所以报区间比报 p 值信息量更大：

    输出 告诉读者的信息
    p = 0.03 有差异，不多不少
    p = 0.03，95% CI = [0.02, 0.40] 有差异，且小的效应也不能排除 ✓
    p = 0.03，95% CI = [0.30, 0.40] 有差异，而且效应稳定在中等水平 ✓

    后两行的 p 值完全一样，结论的实用价值天差地别。 这就是要报区间的原因。

    7.5 陷阱五：先看数据再决定怎么检验¶

    一套「看着数据选检验」的流程会让 p 值彻底失效：

    步骤 表面上做了什么 实际上做了什么
    1 先算一下描述统计 相当于看了数据
    2 发现偏态，改用非参数 又是一次尝试
    3 还不显著，去掉两个离群值 第三次尝试
    4 换个单侧方向 第四次尝试
    5 正好 p < 0.05，报出来 把「至少一次成功」报成了「一次检验」 ⚠

    后果：这种流程的实际假阳性率远高于 0.05 —— 和上一节「做 20 次检验」是同一个问题， 只是「检验次数」被隐藏在了分析步骤里，更难察觉。

    判断依据（可操作的规矩）：

    规矩 说明
    先写分析方案，再看数据 包括用哪个检验、怎么处理异常值、方向是单侧还是双侧 ✓
    异常值的剔除规则要事先定 例如「按预先定义的技术性异常剔除」，而不是「看起来不对就删」
    探索性分析要明确标为探索性 探索得到的假设需要新数据验证 ✓
    报告所有做过的检验 包括没达到显著的那些 ⚠

    一句话：检验是「验证假设」的工具，不是「发明假设」的工具。 两者都是正经工作，但必须分清楚，用不同的数据 ✓

    7.6 误用速查表¶

    误用 为什么错 正确做法
    「p 值是 \(H_0\) 为真的概率」 条件概率方向反了 它是 \(P(\text{数据} \mid H_0)\) ✓
    「p < 0.05 所以效应很大」 p 受样本量强烈影响 同时报效应量 ✓
    「不显著所以没有差异」 可能是样本量不够 报告区间，看它是否排除了重要效应 ✓
    「多次比较没用校正」 假阳性率累积 Bonferroni 或 FDR ✓
    「只报 p，不报区间」 丢失精度信息 两者都报 ✓
    「事后改单侧」 p 值被减半 事先定方向 ✓
    「按结果挑检验方法」 相当于多次尝试 事先登记方案 ✓

    8.2 相关系数 r 也能当效应量¶

    当两个变量都是连续变量时，Pearson 相关系数 \(r\) 本身就是效应量。

    对于「两组比较」这种情形，把组别编码成 0 / 1， 算出的相关系数叫点二列相关，它和 d 之间有确定的换算关系：

    \[r = \frac{d}{\sqrt{d^2 + 4}}\]

    核验上面输出：\(d = 0.6095\) 时， \(0.6095 / \sqrt{0.6095^2 + 4} = 0.2915\)，与直接算出的 \(r = 0.2949\) 基本一致

    小结量之间的换算：

    已知 求 公式
    d r \(r = d/\sqrt{d^2+4}\)
    r d \(d = 2r/\sqrt{1-r^2}\)
    t（两组等样本量 n） r \(r = \sqrt{t^2/(t^2 + 2n - 2)}\)

    8.3 效应量的经验判据¶

    Cohen 的经验判据（注意：这些是粗糙的参考值，不是硬标准）：

    小 中 大
    Cohen's d 0.2 0.5 0.8
    相关系数 r 0.1 0.3 0.5
    比例差（如转化率） 1 个百分点量级 数个千分点 显著百分点差

    效应量的判据必须结合具体领域看

    「d = 0.2 算小」这句话只在一般社会科学的语境下成立：

    场景 d = 0.2 意味着什么
    教育干预对成绩的影响 可能算不小了
    药物降低死亡率 可能意义重大
    网页按钮颜色对点击率 可能是很值钱的改进
    某种噪声对听力的长期影响 可能需要 d 很小 也值得干预 ⚠

    判断依据： - 报 d 时附上原始尺度的差异（例如「平均快了 0.15 秒」）， 让读者自己能判断重要性 - 领域内有公认基准时，用领域基准而不是通用判据 - 更要紧的是问「这个差异会不会改变一个决策」

    十、常见统计陷阱速查¶

    陷阱 具体表现 后果 正确做法
    把统计显著当实际重要 只报 p < 0.05，不报效应量 微小差异被当成重大发现 ⚠ 同时报效应量与区间 ✓
    忽略前提假设 直接对偏态小样本用 t 检验 p 值不可信 先查正态性与方差齐性 ✓
    只报 p 值 报告里没有 d、没有 CI 读者无法判断精度和重要性 三样都报 ✓
    样本量过小 n = 8 就下结论 检不出真实差异，假阴性 ⚠ 事前算功效；阴性结果要注明功效
    混淆 SD 与 SE 「均值 ± 数字」不写清 精度被夸大成好几倍 明确标注，或直接给区间 ✓
    多重比较不校正 反复切分数据找显著 假阳性率可达 60% 以上 ⚠ Bonferroni 或 FDR ✓
    误读置信区间 「真值有 95% 概率在区间内」 概念性错误 理解为长期覆盖率 ✓
    误读 p 值 「p 是 \(H_0\) 为真的概率」 概念性错误 它是 \(P(\text{数据}\mid H_0)\) ✓
    过度解读「不显著」 「不显著 = 没有差异」 漏掉真实效应 ⚠ 「没有足够证据」≠「证明没有」 ✓
    HARKing 看到结果后编一个假设 p 值失去意义 ⚠ 事先登记假设，探索需新数据验证 ✓

    三条最该记住的：

    记住这个 因为
    统计显著 ≠ 实际重要 样本量足够大时，任何微小差异都会显著
    不显著 ≠ 没有效应 也可能只是样本量不够、噪声太大
    报数字要成组报 点估计 + 区间 + 效应量 + n，缺一个都会误导读者

    做法 说明
    事先登记分析方案 最好的做法：把要做的检验、次数、阈值写进方案 ✓
    报告所有检验和全部 p 值 而不是只挑显著的报 ✓
    做多重比较校正 Bonferroni 阈值 = 0.05 / 5 = 0.01 ✓
    或者用 FDR 类方法 检验之间有相关时更合适

    如果其中一次 p = 0.03：

    判定方式 结果
    不校正，用 α = 0.05 p = 0.03 < 0.05 → 显著
    Bonferroni，用 α/k = 0.01 0.03 > 0.01 → 不再显著 ⚠

    这两种判定都是「对」的，取决于你的目标：

    目标 选哪种
    只想单看这一项，不关心其他四次 用 α = 0.05（但要在报告里说明进行了多次检验）
    想控制「五次里至少错一次」的整体风险 Bonferroni，用 0.01 ✓

    判断依据：关键不是选哪种校正，而是「说清楚做了多少次检验」。 读者只要知道 k = 5，就能自己判断该怎么看这个 0.03 —— 隐瞒检验次数才是最严重的问题

    最后提醒 Bonferroni 的代价：把阈值压到 0.01， 意味着真实的效应也更难被检出。如果这 5 个检验里 确实有真实效应，功效就下降了。所以校正不是免费的， 它是在「少犯错报」和「少漏报」之间做取舍

    小结¶

    要记住的 为什么
    总体拿不到，只能用样本推断 成本、可行性、破坏性，三重限制
    同一总体抽两次必然不同 抽样误差无法消除，只能量化
    抽样分布是「统计量的分布」 它量化了「样本均值本身有多不稳」
    中心极限定理说的是「样本均值」趋近正态 不是「原始数据」趋近正态
    「n ≥ 30」不是铁律 重度偏态需要更大的 n，要看偏度和离群值
    \(\text{SD}(\bar{x}) = \sigma/\sqrt{n}\) 样本量越大越稳，但收益是平方根级
    SD 描述个体，SE 描述估计量 \(\text{SD}/\text{SE}=\sqrt{n}\)，n = 100 时差 10 倍
    置信区间是「程序的覆盖率」 重复抽样时约 95% 的区间含真值
    不能说「真值有 95% 概率在区间内」 参数是固定常数，随机的是区间
    置信区间宽度由三个因素定 置信水平、样本量、标准差，要指明是哪一个
    p 值是「\(H_0\) 为真时观测到这么极端的概率」 是 \(P(\text{数据}\mid H_0)\)，方向不能反
    p 值不是 \(H_0\) 为真的概率 条件概率不可交换
    \(H_0\) 为真时 p 值近似均匀分布 所以「p < 0.05」本来就有 5% 概率发生
    两类错误此消彼长 只有加样本量能同时改善两边
    equal_var=False（Welch）更保险 方差不齐 + 样本量不等时，Student 假阳性率失控
    配对数据必须用 ttest_rel 独立检验会把个体差异当噪声，功效大跌
    提前算正态性与方差齐性 前提不成立时 p 值没有意义
    偏态数据用秩检验更稳 mannwhitneyu / wilcoxon 不依赖分布形状
    检验次数少时用 Bonferroni 阈值 \(\alpha/k\) 不校正时「至少一次假阳性」概率可达 60% 以上
    p 小 ≠ 效应大 样本量足够大时，0.05 的差异也能「显著」
    效应量不随样本量膨胀 所以它是判断实际重要性的关键
    要成组报告：点估计 + 区间 + 效应量 + n 缺一个都会误导读者
    「不显著」不等于「没有差异」 也可能是功效不足，是漏报
