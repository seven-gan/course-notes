    Python 编程基础¶

    目标：从「没写过代码」到「能独立写出、跑通、调试自己的脚本」。

    这一模块把 Python 语言本身拆成 14 个知识点，每个小概念都单独成页讲透。 学完它，你才具备读第二模块（科学计算）代码的能力。

    为什么编程要「拆开慢慢讲」，而不是一篇长文

    因为编程的困难不在「知道」，而在「准确」。

    数学 编程
    理解了概念就能推下去 差一个冒号、差一个缩进级别就报错
    记错公式可以现推 记错语法只能查，或看报错
    边界条件可以事后补 边界条件必须一开始就想对

    所以这一模块的每一页都力求：

    • 讲清一个概念，不含糊带过
    • 给出对比（对写法 vs 错写法，以及为什么）
    • 每段代码都能跑，输出与页面所写一致
    • 列出易错点，因为那些地方真的会踩

    知识点总览¶

    01 环境与工具
    解释器与编辑器、装库、第一个程序、三种运行方式、报错怎么读
    基础 · 万事开头难，环境是第一关
    02 变量与类型
    变量是「名字」不是「盒子」、动态类型、赋值机制、可变与不可变
    核心 · 理解这些才不会踩「共享引用」的坑
    03 数字与运算
    int/float/complex、整除与取余、浮点精度、大整数、数值比较
    基础 · 数值计算的前提
    04 字符串
    索引切片、不可变性、常用方法、f-string 格式化、编码与中文
    核心 · 处理文本的基本功
    05 列表与元组
    增删改查、排序、切片、解包、浅拷贝与深拷贝、列表vs元组
    核心 · 最常用的容器
    06 字典与集合
    键值对、遍历、默认值、计数、去重、集合运算、哈希原理
    核心 · 按名字取值的利器
    07 条件与循环
    if/elif/else、while、for、range、enumerate、zip、break/continue/else
    核心 · 程序逻辑的骨架
    08 函数
    定义与调用、参数类型、返回值、作用域、闭包、装饰器入门
    核心 · 复用与封装的基础
    09 推导式与生成器
    列表/字典/集合推导式、条件筛选、生成器表达式、惰性求值
    重要 · Python 最有特色的语法
    10 异常与调试
    异常类型、try/except/else/finally、raise、assert、三种调试方法
    核心 · 决定你能不能独立解决问题
    11 文件与路径
    open 与 with、文本/二进制模式、编码、pathlib、目录遍历、CSV
    核心 · 读写真实数据
    12 模块与包
    import 机制、标准库速查、自建模块、`__name__`、虚拟环境、pip
    重要 · 组织代码与使用生态
    13 类与对象
    类与实例、属性与方法、继承、特殊方法、dataclass
    重要 · 大型程序的组织方式
    14 工程习惯
    命名规范、注释与文档字符串、类型标注、代码格式、单元测试入门
    参考 · 让代码可维护

    与「科学计算」模块的关系¶

    两个模块的分工

    本模块（编程基础） 科学计算模块
    讲什么 Python 语言本身 用 Python 做计算
    例子 列表、字典、函数 数组、数据表、画图
    学完能做 写通用脚本、处理文本与小数据 做数据分析、数值实验、科研绘图

    顺序不能颠倒：科学计算模块的代码里会用到函数、推导式、 异常处理、文件读写 —— 这些都在本模块 ✓

    怎么用这一模块¶

    三条建议

    1. 每段代码都要亲手敲一遍

    读代码时大脑会产生「我懂了」的错觉。 真正的检验是：关掉页面自己写一遍，能不能跑通。

    2. 报错不要跳过

    每一页的易错点都是真实高频错误。 看到报错先别改，想一想它想告诉你什么。

    3. 每页末尾的例题和自测要做

    例题有「思路」折叠，先自己想，想不出来再看思路， 最后才看解答。这样效果最好。
