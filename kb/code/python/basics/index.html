    Python 编程基础¶

    这一页的目标只有一个：让你能独立写出并跑通自己的 Python 脚本。

    和其他模块不同，编程必须动手——看懂代码和写出代码是两件事。

    怎么用这一页（读法和其他模块不同）

    做法 原因
    边读边敲 看懂 ≠ 会写，肌肉记忆不可省
    看报错不要慌 报错是信息，不是失败（本页专门讲）
    先跑通再改 从能跑的代码改起，比从零写快 10 倍
    遇到不懂就 print 最有效的调试手段，没有之一

    每一段代码你都可以直接复制到 VSCode 里按 Ctrl+F5 运行 ✓

    四者怎么选（决策表）

    需求 选
    有序、需要增删改 list ✓
    有序、不允许改（如坐标） tuple
    按名字取值（如配置、记录） dict ✓
    去重、集合运算（交并差） set

    注意 lst[::-1] 是「反转」，不是原地改 —— 它会返回新列表。原地反转是 lst.reverse()：

    strip() 与 replace() 的执行顺序会影响结果

    上面第 5 行输出是 Hi, Python（两端没有空格）—— 因为 .strip() 先去掉了空格，.replace() 再去替换文字 ✓

    如果调换顺序：

    1
2
3
    s = "  Hello, Python  "
print(repr(s.replace("Hello", "Hi").strip()))   # 先替换再 strip
print(repr(s.strip().replace("Hello", "Hi")))   # 先 strip 再替换

    'Hi, Python'
'Hi, Python'

    这个例子里两者结果相同（因为替换的 Hello 在中间，不影响两端空格）。

    但下面这个就不一样了 —— 替换目标含空格时：

    1
2
3
    s = "  Hello, Python  "
print(repr(s.replace("  Hello", "Hi").strip()))  # 先替换两端内容
print(repr(s.strip().replace("  Hello", "Hi")))  # strip 后已无 "  Hello"

    'Hi, Python'
'Hello, Python'

    规律：方法调用是「从左到右」依次作用的， 链式调用时顺序不同、结果可能不同 ⚠

    实用建议：链式调用超过 2 个方法时， 拆成多行更清楚，也便于调试：

    1
2
3
4
    text = "  Hello, Python  "
text = text.strip()               # 第 1 步
text = text.replace("Hello", "Hi")  # 第 2 步
print(repr(text))

    'Hi, Python'

    为什么推荐 f-string（不是 % 也不是 .format）

    写法 例子 评价
    % 格式化 "%s: %.2f" % (n, v) 老，易错
    .format() "{}: {:.2f}".format(n, v) 冗长
    f-string f"{n}: {v:.2f}" 最直观 ✓

    f-string 的三个好处：

    1. 表达式直接写在里面：f"{a+b}"、f"{x**2}"
    2. 格式说明符和 .format 相同：{v:.2f}、{v:>10}
    3. 可读性最好 —— 变量名紧贴它的位置 ✓

    Python 3.6+ 起支持，本项目用 3.12 完全没问题。

    补充：repr() 与 print() 的区别 —— repr() 会显示引号与转义符，排查「看不见的字符」时必备：

print(repr(s))       # 'abc\n'  —— 一眼看出末尾有换行

    为什么是 33 字节（一个跨平台的坑）

    UTF-8 下 1 个汉字占 3 字节，所以： 第一行 + 第二行 + 第三行 = 9 个汉字 = 27 字节

    加上 3 个换行符，理论上是 30 字节 —— 但实际是 33 ⚠

    多出的 3 字节来自 Windows 的换行转换：

    平台 换行符 3 个换行占
    Linux / macOS \n（1 字节） 3 字节 → 共 30
    Windows（文本模式） \r\n（2 字节） 6 字节 → 共 33

    p.write_text(...) 默认以文本模式打开， Windows 会把 \n 自动转成 \r\n ✓

def is_prime(n):
    """判断质数。"""
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return False
    return True

    """学生成绩分析：一个完整的小脚本。"""
from pathlib import Path
from statistics import mean, median, stdev

# ---------- 1. 准备数据（实际项目里从文件读） ----------
records = [
    {"name": "小明", "cls": "一班", "scores": {"语文": 88, "数学": 95, "英语": 78}},
    {"name": "小红", "cls": "一班", "scores": {"语文": 92, "数学": 88, "英语": 96}},
    {"name": "小刚", "cls": "二班", "scores": {"语文": 79, "数学": 82, "英语": 85}},
    {"name": "小丽", "cls": "二班", "scores": {"语文": 95, "数学": 91, "英语": 89}},
    {"name": "小强", "cls": "一班", "scores": {"语文": 67, "数学": 73, "英语": 80}},
]

# ---------- 2. 加派生字段 ----------
for r in records:
    r["总分"] = sum(r["scores"].values())
    r["平均分"] = round(r["总分"] / len(r["scores"]), 2)

# ---------- 3. 按平均分排序 ----------
ranked = sorted(records, key=lambda r: r["平均分"], reverse=True)

print(f"{'排名':<4}{'姓名':<6}{'班级':<6}{'总分':<6}{'平均分':<8}")
print("-" * 32)
for i, r in enumerate(ranked, 1):
    print(f"{i:<6}{r['name']:<8}{r['cls']:<8}{r['总分']:<8}{r['平均分']:<10}")

# ---------- 4. 统计量 ----------
avgs = [r["平均分"] for r in records]
print()
print(f"平均分: 均值 {mean(avgs):.2f}  中位数 {median(avgs):.2f}  标准差 {stdev(avgs):.2f}")

# ---------- 5. 按班级分组统计 ----------
print()
for cls in sorted({r["cls"] for r in records}):
    group = [r["平均分"] for r in records if r["cls"] == cls]
    print(f"{cls}: {len(group)} 人, 平均 {mean(group):.2f}")

# ---------- 6. 写报告 ----------
out = Path("report.txt")
with open(out, "w", encoding="utf-8") as f:
    f.write("成绩报告\n")
    f.write("=" * 32 + "\n")
    for i, r in enumerate(ranked, 1):
        f.write(f"{i}. {r['name']}（{r['cls']}） 平均 {r['平均分']}\n")
print(f"\n报告已写入 {out}")

    a = [1, 2, 3]

    提示

    想想 b = a 是复制还是「指向同一个对象」。

    解答

    输出 [1, 2, 3, 4]。

    原因：b = a 不复制，而是让 b 和 a 指向同一个列表对象。

    示意图：

    a ──┐
    ├──> [1, 2, 3]
b ──┘

    所以通过 b 修改，a 也「变了」（其实是同一个对象）。

    要真正复制：

    1

    a = [1, 2, 3]
b = a.copy()        # 或 b = a[:] 或 b = list(a)
b.append(4)
print("a =", a)
print("b =", b)

    a = [1, 2, 3]
b = [1, 2, 3, 4]

    这个陷阱对 dict、set 同样适用 ✓

    注意「浅拷贝」的局限：

    方法 层次
    a.copy() / a[:] 浅拷贝（嵌套对象仍共享）

    import copy

# 浅拷贝：内层列表仍共享
a = [[1, 2], [3, 4]]
b = a.copy()
b[0].append(99)
print("浅拷贝后 a =", a)

# 深拷贝：完全独立
x = [[1, 2], [3, 4]]
y = copy.deepcopy(x)
y[0].append(99)
print("深拷贝后 x =", x)
print("深拷贝后 y =", y)

    对比很清楚：浅拷贝时 a 被连带改了， 深拷贝时 x 完全不受影响 ✓

    from collections import Counter


def most_common_items(items):
    """返回出现次数最多的元素列表（可能多个并列）。"""
    if not items:
        return []
    counts = Counter(items)
    top = max(counts.values())
    return [k for k, v in counts.items() if v == top]


# 测试
print(most_common_items([1, 2, 2, 3, 3, 4]))
print(most_common_items(["a", "b", "a", "c", "b"]))
print(most_common_items([1, 1, 1]))
print(most_common_items([]))

    [2, 3]
['a', 'b']
[1]
[]

    关键点：

    步骤 说明
    先处理空列表 否则 max() 对空序列报 ValueError ✗
    Counter 一行得词频 不用手写循环 ✓
    max(counts.values()) 找出最高频次
    列表推导筛选并列项 这就是「并列都返回」的实现 ✓

    若不要并列（只返回一个）：

    1
    counts.most_common(1)[0][0]

    边界情况必须测：空列表、全相同、全部不同 —— 这三个测过，函数基本可靠 ✓

    import csv
from pathlib import Path

# 先造一个测试文件
p = Path("scores.csv")
p.write_text("name,score\n小明,88\n小红,95\n小刚,73\n",
             encoding="utf-8")

# 读取
with open(p, encoding="utf-8", newline="") as f:
    rows = list(csv.DictReader(f))

# 转换类型（CSV 读出来都是字符串！）
data = [(r["name"], float(r["score"])) for r in rows]

avg = sum(s for _, s in data) / len(data)
top_name, top_score = max(data, key=lambda t: t[1])

print(f"人数: {len(data)}")
print(f"平均分: {avg:.2f}")
print(f"最高分: {top_name} ({top_score:.0f})")

    1. CSV 读出来全是字符串 —— 必须自己转 float / int ✗

    1
    print(type(rows[0]["score"]))   # <class 'str'>

    2. 打开文件要加 newline="" —— 否则 Windows 上可能出现空行 ⚠

    3. 用 DictReader 而不是 reader —— 按列名取值（r["name"]）比按下标（r[0]）可读且不易错 ✓
