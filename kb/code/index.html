    编程基础¶

    看懂公式 ≠ 会写代码。 这一层专门训练「动手做出来」的能力。

    和数学层、专业课程层有什么不同

    数学基础 / 专业课程 编程基础
    核心目标 理解概念与推导 写出能跑的代码 ✓
    主要形式 公式、图示、例题 代码块 + 运行输出 + 实操步骤 ✓
    学习方式 读 + 想 读 + 敲 + 跑 ✓
    检验方式 自测题 输出是否与讲解一致（可亲自跑一遍核对）

    所以这一层的每一段代码，你都可以直接复制到编辑器里运行， 输出与页面所写完全一致 —— 这不是「大概是这样」， 而是出版前逐段实跑核对过的

    为什么编程单独成层¶

    你可能会问：为什么不把 Python 放进「专业课程」里？

    因为编程是「横跨所有课程的共同工具」，不是某一门课的内容。

    你学的 用 Python / NumPy 做什么
    线性代数 矩阵运算、特征值、SVD
    概率论 随机数、分布拟合、统计检验
    数学优化 梯度下降、凸优化求解
    信号与系统 卷积、傅里叶变换、滤波器设计
    机器学习 / 模式识别 数据预处理、训练、评估
    无人系统 仿真、最优控制、强化学习

    放成独立一层的好处：

    好处 说明
    一份权威讲解 不用在每门课里重复讲「怎么读 CSV」✓
    按需查阅 做优化实验时遇到 pandas 问题，直接跳过来
    可持续补充 加新库（如 PyTorch）不影响课程层结构

    学习方法建议¶

    编程学习的三个反直觉之处

    1. 看懂 ≠ 会写 —— 必须动手

    读代码时大脑会产生「我懂了」的错觉。 真正的检验是：关掉页面，自己写一遍，能不能跑通。

    做法 效果
    只读 半天后忘光 ✗
    边读边敲 形成肌肉记忆 ✓
    敲完故意改错看报错 理解最深 ✓

    2. 报错是信息，不是失败

    新手看到红色报错就慌。 实际上 Python 的报错写得很好 —— 它告诉你 哪一行、什么类型、为什么。

    读报错顺序：先看最后一行，再看行号 （basics 页有专门一节讲这个）

    1. 不要从零写，要从「能跑的」改起

      错误做法 正确做法
      盯空白文件硬想 先跑通一个最小例子 ✓
      一次写 200 行再运行 写 5 行跑一次 ✓
      报错就推翻重写 先读懂报错再改 ✓

      「小步快跑」在编程里比在任何领域都更适用

    环境说明¶

    本层所有代码都在 Python 3.12 上实测通过， 用到的库版本如下（版本略新略旧都不影响，差异会另作说明）：

    库 本层实测版本
    Python 3.12
    NumPy 1.26
    pandas 2.2
    Matplotlib 3.9

    你需要准备什么环境

    只要满足两点，本层所有代码都能跑：

    要求 说明
    Python 3.9 或更高 本层用了 f-string、dict.fromkeys 保持顺序等特性
    装有 NumPy / pandas / Matplotlib 第二页的核心内容

    最省事的做法：装 Anaconda 发行版 —— 它把 Python 与科学计算生态打包在一起， 上述库开箱即用，不用逐个安装

    若已装官方 Python，一条命令补齐：

    pip install numpy pandas matplotlib scipy sympy scikit-learn

    务必确认编辑器用的是那个装了库的 Python —— 机器上存在多个 Python 是新手最常踩的坑， 症状是「代码没错却报 No module named 'numpy'」✗

    具体排查步骤见 环境与工具 一节
