    导数与微分¶

    微积分回答一个核心问题：

    当一个量变了一点点，另一个量跟着变多少？

    这个「变化率」就是导数。它是整门学科的起点，也是梯度下降（机器学习训练的 唯一算法）的数学基础。

    为什么工程专业必须掌握导数

    领域 导数的角色
    机器学习训练 损失函数对参数的导数 = 梯度，决定往哪走
    机器人运动学 位置对时间的导数 = 速度；速度的导数 = 加速度
    传感器标定 灵敏度 = 输出对输入的导数
    优化 一阶必要条件：最优点处导数为零

    可以说，「会不会求导」决定了能否进入这些领域。

    一、导数的定义¶

    定义：函数 \(f\) 在点 \(x_0\) 处的导数为

    \[ f'(x_0) = \lim_{\Delta x \to 0}\frac{f(x_0+\Delta x)-f(x_0)}{\Delta x} \]

    若该极限存在，称 \(f\) 在 \(x_0\) 处可导。

    几何意义：导数是曲线在 \(x_0\) 处切线的斜率。

    一个亲手算的例子¶

    用定义求 \(f(x) = x^2\) 在 \(x_0 = 3\) 处的导数。

    按定义逐步计算：

    \[ \frac{f(3+\Delta x) - f(3)}{\Delta x} = \frac{(3+\Delta x)^2 - 3^2}{\Delta x} \]

    展开分子：

    \[ = \frac{9 + 6\Delta x + (\Delta x)^2 - 9}{\Delta x} = \frac{6\Delta x + (\Delta x)^2}{\Delta x} \]

    约去 \(\Delta x\)（注意 \(\Delta x \neq 0\) 才能约）：

    \[ = 6 + \Delta x \]

    取极限 \(\Delta x \to 0\)：

    \[ f'(3) = \lim_{\Delta x\to 0}(6+\Delta x) = 6 \]

    验证：\(f'(x) = 2x\)，代入 \(x=3\) 得 \(6\)

    为什么可以约去 Δx（这一步常被质疑）

    导数的定义里 \(\Delta x \to 0\) 但不等于 0（否则分母为零，无意义）。

    所以只要 \(\Delta x \neq 0\)，就可以把它约掉。约掉之后再取极限， 得到的是一个良定义的有限值。

    这个「先约、后取极限」的顺序是关键：若先取极限再约，就会遇到 \(\frac{0}{0}\) 的不定型。

    二、基本求导公式¶

    以下公式必须熟练掌握（它们是所有计算的基础）。

    函数 导数
    \(C\)（常数） \(0\)
    \(x^n\) \(nx^{n-1}\)
    \(e^x\) \(e^x\)
    \(a^x\) \(a^x\ln a\)
    \(\ln x\) \(\dfrac{1}{x}\)
    \(\log_a x\) \(\dfrac{1}{x\ln a}\)
    \(\sin x\) \(\cos x\)
    \(\cos x\) \(-\sin x\)
    \(\tan x\) \(\sec^2 x = \dfrac{1}{\cos^2 x}\)
    \(\arcsin x\) \(\dfrac{1}{\sqrt{1-x^2}}\)
    \(\arctan x\) \(\dfrac{1}{1+x^2}\)

    只要记三个，其余都能推出来

    核心是这三个：

    公式 为什么核心
    \((e^x)' = e^x\) 唯一「导数等于自己」的函数
    \((\ln x)' = 1/x\) 与 \(e^x\) 互为反函数
    \((x^n)' = nx^{n-1}\) 幂法则，多项式求导全靠它

    其余可以推出：

    • \(\sin\) 与 \(\cos\) 的导数由和角公式＋定义可得
    • \(a^x = e^{x\ln a}\)，用链式法则得 \(a^x\ln a\)
    • \(\log_a x = \frac{\ln x}{\ln a}\)，得 \(\frac{1}{x\ln a}\)
    • 反函数导数：\((f^{-1})'(y) = \frac{1}{f'(x)}\)， 由此从 \(e^x\) 得 \(\ln x\)、从 \(\sin\) 得 \(\arcsin\)

    「导数等于自己」这一点很特殊：它是 \(e^x\) 在工程中无处不在的根本原因 （微分方程的解、信号衰减、复利、放射性衰变都是它）。

    三、求导法则¶

    四则运算¶

    \[ (af + bg)' = af' + bg' \qquad\text{（线性）} \]
    \[ (fg)' = f'g + fg' \qquad\text{（乘积法则）} \]
    \[ \left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2} \qquad\text{（商法则）} \]

    乘积法则最容易记错

    常见错误：写成 \((fg)' = f'g'\) ✗

    反例检验：取 \(f = x\)，\(g = x\)，则 \(fg = x^2\)。

    • 正确：\((x^2)' = 2x\)
    • 错误写法给出 \(1 \times 1 = 1\) ✗

    记忆方法：「前导后不导，加，前不导后导」。

    验证一下：\(f = x\)，\(g = x\) 时

    \[ f'g + fg' = 1\cdot x + x\cdot 1 = 2x \;\checkmark \]

    复合函数（链式法则）¶

    \[ \big(f(g(x))\big)' = f'(g(x))\cdot g'(x) \]

    这是最重要的一条——反向传播算法的全部数学依据。

    链式法则的直觉

    「变化率的传递」：

    设 \(y = f(u)\)，\(u = g(x)\)。当 \(x\) 变化 \(\Delta x\) 时：

    1. \(u\) 变化约 \(g'(x)\Delta x\)
    2. \(y\) 随之变化约 \(f'(u)\times\)（\(u\) 的变化量）

    合起来：

    \[ \Delta y \approx f'(u)\cdot g'(x)\cdot \Delta x \]

    所以 \(\frac{\mathrm{d}y}{\mathrm{d}x} = f'(u)g'(x)\)。

    这就是「变化率的链式传递」，也是多层网络能逐层回传梯度的原因。

    详见链式法则与反向传播。

    四、微分：导数的「增量版本」¶

    定义：函数 \(f\) 在 \(x\) 处的微分为

    \[ \mathrm{d}y = f'(x)\,\mathrm{d}x \]

    含义：当自变量变化 \(\mathrm{d}x\) 时，函数变化的线性主部。

    微分与导数的区别¶

    概念 含义 形式
    导数 变化率（一个数，或函数） \(f'(x)\)
    微分 变化的线性近似（一个量） \(\mathrm{d}y = f'(x)\mathrm{d}x\)

    关系：导数乘上自变量的增量，就是微分的值。

    线性近似¶

    由微分立即得到线性近似公式：

    \[ f(x_0 + \Delta x) \approx f(x_0) + f'(x_0)\Delta x \]

    这个近似在工程中的两条重要用途

    1. 误差传播分析

    若测量 \(x\) 有误差 \(\Delta x\)，则 \(f(x)\) 的误差约为

    \[ \Delta f \approx \lvert f'(x)\rvert\lvert\Delta x\rvert \]

    导数的绝对值就是「误差放大倍数」。

    例：用 \(r\) 算面积 \(A = \pi r^2\)，则 \(\frac{\mathrm{d}A}{\mathrm{d}r} = 2\pi r\)。 半径 \(r = 10\) cm 时，若测量误差 0.1 cm，面积误差约

    \[ 2\pi\times10\times0.1 \approx 6.28\ \text{cm}^2 \]

    2. 迭代法的依据

    牛顿法求解 \(f(x)=0\)：

    \[ x_{k+1} = x_k - \frac{f(x_k)}{f'(x_k)} \]

    它就是「用切线代替曲线求根」——在 \(x_k\) 处作切线， 切线零点就是下一次迭代值。

    五、典型例题¶

    例题 1：用定义求导¶

    用定义求 \(f(x) = \sqrt{x}\) 在 \(x_0 = 4\) 处的导数。

    思路

    关键技巧：把分子有理化，消去分母的 \(\Delta x\)。

    解答

    按定义写：

    \[ f'(4) = \lim_{\Delta x\to0}\frac{\sqrt{4+\Delta x}-\sqrt4}{\Delta x} = \lim_{\Delta x\to0}\frac{\sqrt{4+\Delta x}-2}{\Delta x} \]

    分子有理化（分子分母同乘共轭）：

    \[ = \lim_{\Delta x\to0}\frac{\left(\sqrt{4+\Delta x}-2\right)\left(\sqrt{4+\Delta x}+2\right)}{\Delta x\left(\sqrt{4+\Delta x}+2\right)} \]

    分子用平方差：

    \[ = \lim_{\Delta x\to0}\frac{(4+\Delta x)-4}{\Delta x\left(\sqrt{4+\Delta x}+2\right)} = \lim_{\Delta x\to0}\frac{\Delta x}{\Delta x\left(\sqrt{4+\Delta x}+2\right)} \]

    约去 \(\Delta x\)：

    \[ = \lim_{\Delta x\to0}\frac{1}{\sqrt{4+\Delta x}+2} \]

    取极限（此时分母不再趋于零）：

    \[ = \frac{1}{\sqrt4+2} = \frac{1}{4} \]

    验证：\(f'(x) = \frac{1}{2\sqrt x}\)，代入 \(x=4\)：

    \[ f'(4) = \frac{1}{2\times2} = \frac14 \;\checkmark \]

    有理化是「消去分母 Δx」的常用技巧

    遇到含根式的极限，若分子分母都趋于零， 常用有理化制造可约因子。

    形式 乘什么
    \(\sqrt{a}-\sqrt{b}\) \(\sqrt{a}+\sqrt{b}\)
    \(\sqrt[3]{a}-\sqrt[3]{b}\) \(a^{2/3}+a^{1/3}b^{1/3}+b^{2/3}\)

    例题 2：乘积法则与商法则¶

    求 \(f(x) = \dfrac{x^2 e^x}{x+1}\) 的导数。

    思路

    先用商法则，其中分子的求导要用乘积法则。

    解答

    先对分子用乘积法则。设 \(u = x^2 e^x\)，则

    \[ u' = (x^2)'e^x + x^2(e^x)' = 2xe^x + x^2e^x = e^x(2x+x^2) = xe^x(x+2) \]

    再对整个分式用商法则（\(f = u/v\)，\(v = x+1\)）：

    \[ f'(x) = \frac{u'v - uv'}{v^2} = \frac{xe^x(x+2)(x+1) - x^2e^x\cdot1}{(x+1)^2} \]

    提取公因子 \(xe^x\)：

    \[ = \frac{xe^x\left[(x+2)(x+1) - x\right]}{(x+1)^2} \]

    展开括号：

    \[ (x+2)(x+1) - x = x^2+3x+2-x = x^2+2x+2 \]

    最终结果：

    \[ f'(x) = \frac{xe^x(x^2+2x+2)}{(x+1)^2} \]

    快速验证 \(x=0\)：

    • 直接算 \(f'(0)\)：由上式得 \(\frac{0\times1\times2}{1} = 0\)
    • 另一种方法：\(f(x) \approx \frac{x^2\cdot1}{1+0}\) 在 \(x \approx 0\) 处， 故 \(f'(0) \approx 0\)

    计算顺序建议

    先算分子导数、再套商法则，可以避免在商法则内部嵌入乘积法则时漏项。

    若直接写，很容易漏掉「分子求导时还要用乘积法则」这一步。

    自查手段：把结果代入几个具体点，与数值差商对比：

    \[ f'(x) \approx \frac{f(x+h)-f(x-h)}{2h} \quad (h \text{ 很小}) \]

    例题 3：链式法则（多层复合）¶

    求 \(f(x) = e^{2x}\sin(3x)\) 的导数。

    思路

    用乘积法则，其中每一部分都要用链式法则。

    解答

    分别求两部分的导数：

    第一部分 \(e^{2x}\)（外层指数，内层 \(2x\)）：

    \[ \left(e^{2x}\right)' = e^{2x}\cdot(2x)' = 2e^{2x} \]

    第二部分 \(\sin(3x)\)（外层正弦，内层 \(3x\)）：

    \[ \left(\sin 3x\right)' = \cos(3x)\cdot(3x)' = 3\cos 3x \]

    用乘积法则组合：

    \[ f'(x) = 2e^{2x}\sin 3x + e^{2x}\cdot3\cos 3x \]

    化简（提取 \(e^{2x}\)）：

    \[ f'(x) = e^{2x}\left(2\sin 3x + 3\cos 3x\right) \]

    验证 \(x=0\)：

    • 由结果：\(e^0(2\cdot0 + 3\cdot1) = 3\)
    • 数值差商（\(h = 10^{-5}\)）：
    \[ \frac{f(h)-f(-h)}{2h} \approx 3 \]

    两者一致

    链式法则的「剥洋葱」记法

    由外向内逐层求导并相乘：

    \[ f(x) = e^{\,2x} \;\longrightarrow\; \left(e^{\square}\right)' = e^{\square}\cdot\square' \]

    写成「剥洋葱」的形式：

    \[ \frac{\mathrm{d}}{\mathrm{d}x}e^{\,g(x)} = e^{\,g(x)}\cdot g'(x) \]

    越外层越先写。多层复合时依次剥下去，最后乘上最内层的导数。

    例题 4：误差传播（微分的应用）¶

    某圆柱体半径 \(r = 5\) cm，高 \(h = 10\) cm。 若 \(r\) 的测量误差为 \(\pm 0.05\) cm，估计体积的最大相对误差。

    思路

    体积 \(V = \pi r^2h\)，用微分估计 \(\Delta V \approx \frac{\partial V}{\partial r}\Delta r\)。

    解答

    体积公式：

    \[ V = \pi r^2 h \]

    对 \(r\) 求偏导（\(h\) 视为常数）：

    \[ \frac{\partial V}{\partial r} = 2\pi r h \]

    代入数值：

    \[ \frac{\partial V}{\partial r}\bigg|_{r=5,h=10} = 2\pi\times5\times10 = 100\pi \approx 314.16\ \text{cm}^2 \]

    体积误差估计：

    \[ \Delta V \approx 314.16 \times 0.05 \approx 15.71\ \text{cm}^3 \]

    体积本身：

    \[ V = \pi\times25\times10 = 250\pi \approx 785.4\ \text{cm}^3 \]

    相对误差：

    \[ \frac{\lvert\Delta V\rvert}{V} \approx \frac{15.71}{785.4} \approx 0.02 = 2\% \]

    也可以用对数微分更快算相对误差：

    \[ \ln V = \ln\pi + 2\ln r + \ln h \]

    两边微分：

    \[ \frac{\mathrm{d}V}{V} = 2\frac{\mathrm{d}r}{r} \]

    代入 \(\frac{\mathrm{d}r}{r} = \frac{0.05}{5} = 1\%\)：

    \[ \frac{\Delta V}{V} \approx 2\times1\% = 2\% \;\checkmark \]

    与前面一致，但计算量小得多。

    对数微分：算相对误差的利器

    原理：\(\mathrm{d}(\ln y) = \frac{\mathrm{d}y}{y}\)， 所以取对数再微分就得到相对变化率。

    规则（幂次直接变成系数）：

    \[ y = Cx_1^{a_1}x_2^{a_2}\cdots \Longrightarrow \frac{\mathrm{d}y}{y} = a_1\frac{\mathrm{d}x_1}{x_1} + a_2\frac{\mathrm{d}x_2}{x_2}+\cdots \]

    用途：

    场景 例子
    误差传播 上例（幂次 2 → 误差放大 2 倍）
    灵敏度分析 各输入对输出的相对贡献
    量纲分析 幂次即量纲指数

    注意：相对误差被幂次放大。若要控制输出误差在 1% 内， 平方项对应的输入误差必须控制在 0.5% 内。

    六、用在哪些课程里¶

    机器人学 · 运动学与动力学¶

    • 位置对时间求导得速度，速度求导得加速度——这是运动学的基本关系
    • 雅可比矩阵就是把「关节角速度 → 末端速度」的线性映射写成矩阵形式 （本质是多元函数的导数）
    • 动力学方程 \(M(\boldsymbol{q})\ddot{\boldsymbol{q}} + C(\boldsymbol{q},\dot{\boldsymbol{q}})\dot{\boldsymbol{q}} + \boldsymbol{g}(\boldsymbol{q}) = \boldsymbol{\tau}\) 来自拉格朗日方程，而拉格朗日函数要对时间求导

    机器人机构学 · 速度运动学¶

    • 位姿对关节变量的导数给出雅可比
    • 奇异位形判据 \(\det J = 0\) 本质上来自「导数矩阵不满秩」

    模式识别 · 梯度下降¶

    • 训练就是不断求损失函数对参数的导数（梯度），沿负梯度方向更新
    • 学习率的选取与二阶导数（曲率）有关

    无人系统自主决策与优化 · 轨迹优化¶

    • 最优控制里代价函数包含 \(\int \lvert \dot{\boldsymbol{q}}\rvert^2 \mathrm{d}t\)， 求导得到欧拉-拉格朗日方程
    • 数值优化中梯度与 Hessian 都要计算

    现代数字信号处理 · 连续信号分析¶

    • 信号的微分性质：\(\mathcal{F}\{f'\} = j\omega F(\omega)\) （时域微分 = 频域乘 \(j\omega\)）
    • 这解释了「微分放大高频噪声」（本知识库「傅里叶」一节有详述）

    七、自测¶

    Q1 用定义求 \(f(x) = \frac{1}{x}\) 在 \(x = 2\) 处的导数。

    提示

    通分后分子会出现 \(\Delta x\)，可以约掉。

    解答

    按定义：

    \[ f'(2) = \lim_{\Delta x\to0}\frac{\dfrac{1}{2+\Delta x}-\dfrac12}{\Delta x} \]

    通分分子：

    \[ \frac{1}{2+\Delta x}-\frac12 = \frac{2-(2+\Delta x)}{2(2+\Delta x)} = \frac{-\Delta x}{2(2+\Delta x)} \]

    代入并约去 \(\Delta x\)：

    \[ f'(2) = \lim_{\Delta x\to0}\frac{-\Delta x}{2(2+\Delta x)\Delta x} = \lim_{\Delta x\to0}\frac{-1}{2(2+\Delta x)} \]

    取极限：

    \[ = \frac{-1}{2\times2} = -\frac14 \]

    验证：\(f'(x) = -\frac{1}{x^2}\)，\(x=2\) 时得 \(-\frac14\)

    注意符号：\(f(x)=1/x\) 是递减函数，导数为负，符合直觉。

    Q2 求 \(f(x) = \ln(\cos x)\) 的导数。

    提示

    外层是对数，内层是余弦。

    解答

    用链式法则（外层 \(\ln\)，内层 \(\cos\)）：

    \[ f'(x) = \frac{1}{\cos x}\cdot(\cos x)' = \frac{1}{\cos x}\cdot(-\sin x) \]

    化简：

    \[ f'(x) = -\frac{\sin x}{\cos x} = -\tan x \]

    验证 \(x=0\)：

    • 由结果：\(-\tan 0 = 0\)
    • 数值差商：\(f(h)-f(-h) \approx 0\)（因为 \(\ln\cos\) 在 0 附近是偶函数）

    另一条思路：\(\ln\cos x = \frac12\ln(\cos^2x) = \frac12\ln(1-\sin^2x)\)， 也能求出同样结果（但计算更繁）。

    Q3 设 \(y = f(u)\)，\(u = g(x)\)，且 \(f(2) = 5\)、\(f'(2) = 3\)、\(g(1) = 2\)、\(g'(1) = 4\)。 求 \(\frac{\mathrm{d}y}{\mathrm{d}x}\) 在 \(x=1\) 处的值。

    提示

    链式法则：\(\frac{\mathrm{d}y}{\mathrm{d}x} = f'(g(x))\cdot g'(x)\)。

    解答

    用链式法则：

    \[ \frac{\mathrm{d}y}{\mathrm{d}x} = f'(g(x))\cdot g'(x) \]

    代入 \(x=1\)：

    • \(g(1) = 2\)，所以 \(f'(g(1)) = f'(2) = 3\)
    • \(g'(1) = 4\)
    \[ \left.\frac{\mathrm{d}y}{\mathrm{d}x}\right|_{x=1} = 3\times4 = 12 \]

    注意 \(f(2)=5\) 这个信息没用上 —— 它出现在计算 \(y\) 的值时 （\(y = f(2) = 5\)），但求导只需要导数值。

    这类题的关键：看清题目给的是函数值还是导数值， 链式法则只用导数值。

    Q4 用微分估计 \(\sqrt{4.02}\) 的近似值。

    提示

    取 \(f(x) = \sqrt x\)，在 \(x_0 = 4\) 处做线性近似。

    解答

    取基准点与增量：

    \[ f(x) = \sqrt x, \qquad x_0 = 4, \qquad \Delta x = 0.02 \]

    基准值：

    \[ f(4) = 2 \]

    导数：

    \[ f'(x) = \frac{1}{2\sqrt x} \implies f'(4) = \frac{1}{2\times2} = \frac14 \]

    线性近似：

    \[ f(4.02) \approx f(4) + f'(4)\Delta x = 2 + \frac14\times0.02 = 2 + 0.005 = 2.005 \]

    验证（精确值）：\(\sqrt{4.02} \approx 2.004993\)…

    误差约 \(7\times10^{-6}\)，相对误差约 \(3.5\times10^{-6}\) —— 相当精确。

    为什么这么准：线性近似的误差是 \(O((\Delta x)^2)\)， 这里 \(\Delta x = 0.02\)，所以误差量级约 \(4\times10^{-4}\) （再乘以函数的二阶导数系数）。\(\Delta x\) 越小，近似越好。
