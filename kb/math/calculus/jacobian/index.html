    雅可比矩阵¶

    上一页把雅可比矩阵定义成「向量函数的导数」。这一页专门讲它——

    因为雅可比矩阵是把「数学」变成「工程」的那座桥。

    在机器人学里，雅可比直接决定：关节怎么动，末端就怎么动。

    为什么机器人学必须掌握雅可比

    工程问题 雅可比的作用
    给定期望的末端速度，关节该转多快？ 解 \(J\dot{\boldsymbol{q}} = \dot{\boldsymbol{x}}\)
    末端能施加多大力？ \(\boldsymbol{\tau} = J^\top\boldsymbol{F}\)
    什么姿态下机器人「卡住」？ \(\det J = 0\)（奇异）
    冗余机器人的最优解？ 用伪逆 \(J^+\)

    没有雅可比，这些都没法算。

    一、定义：从关节空间到任务空间的线性化¶

    设机器人有 \(n\) 个关节、末端有 \(m\) 个自由度（任务空间维数）。

    正运动学给出末端位姿与关节变量的关系：

    \[ \boldsymbol{x} = \boldsymbol{f}(\boldsymbol{q}) \]

    其中 \(\boldsymbol{q}\in\mathbb{R}^n\) 是关节变量，\(\boldsymbol{x}\in\mathbb{R}^m\) 是末端位姿。

    对时间求导（用链式法则）：

    \[ \dot{\boldsymbol{x}} = \frac{\partial\boldsymbol{f}}{\partial\boldsymbol{q}}\,\dot{\boldsymbol{q}} = J(\boldsymbol{q})\,\dot{\boldsymbol{q}} \]

    雅可比矩阵即

    \[ J(\boldsymbol{q}) = \frac{\partial\boldsymbol{f}}{\partial\boldsymbol{q}} = \begin{bmatrix} \dfrac{\partial f_1}{\partial q_1} & \cdots & \dfrac{\partial f_1}{\partial q_n}\\[6pt] \vdots & \ddots & \vdots\\[4pt] \dfrac{\partial f_m}{\partial q_1} & \cdots & \dfrac{\partial f_m}{\partial q_n} \end{bmatrix} \]

    形状是 \(m\times n\)（行 = 任务维度，列 = 关节数）。

    三个关键认识

    1. 雅可比是「局部的」

    它依赖当前位形 \(\boldsymbol{q}\)。同一个机器人， 不同姿态下的雅可比不同。

    工程含义：控制律必须在每个控制周期重新计算雅可比 （通常是实时计算，这是机器人控制器的计算负担之一）。

    2. 它是「速度层面」的线性映射

    位姿关系 \(\boldsymbol{x} = \boldsymbol{f}(\boldsymbol{q})\) 是非线性的， 但速度关系是线性的：

    \[ \dot{\boldsymbol{x}} = J\dot{\boldsymbol{q}} \]

    这就是「在工作点线性化」（回到泰勒展开那一页的思想）。

    3. 行数可以少于/多于列数

    情形 \(m\) 与 \(n\) 含义 求解
    非冗余 \(m = n\) 方阵 直接求逆（若可逆）
    冗余 \(m < n\) 关节多于自由度 无穷多解（用伪逆取最小范数）
    欠驱动 \(m > n\) 自由度多于关节 一般无解（只能最小二乘）

    冗余机器人的「无穷多解」是优点——可以在完成任务的同时 用多余自由度避障、避奇异、优化姿态。

    二、二连杆机器人的雅可比（亲手推导）¶

    这是最经典的例子，值得完整算一遍。

    几何设定¶

    两根连杆长度 \(l_1\)、\(l_2\)，关节角 \(q_1\)、\(q_2\)（都在平面内）。

    末端位置：

    \[ x = l_1\cos q_1 + l_2\cos(q_1+q_2) \]
    \[ y = l_1\sin q_1 + l_2\sin(q_1+q_2) \]

    求雅可比¶

    对两个关节角分别求偏导：

    \[ J = \begin{bmatrix} \dfrac{\partial x}{\partial q_1} & \dfrac{\partial x}{\partial q_2}\\[6pt] \dfrac{\partial y}{\partial q_1} & \dfrac{\partial y}{\partial q_2} \end{bmatrix} \]

    逐项计算：

    \[ \frac{\partial x}{\partial q_1} = -l_1\sin q_1 - l_2\sin(q_1+q_2) \]
    \[ \frac{\partial x}{\partial q_2} = -l_2\sin(q_1+q_2) \]
    \[ \frac{\partial y}{\partial q_1} = l_1\cos q_1 + l_2\cos(q_1+q_2) \]
    \[ \frac{\partial y}{\partial q_2} = l_2\cos(q_1+q_2) \]

    所以

    \[ J = \begin{bmatrix} -l_1\sin q_1 - l_2\sin(q_1+q_2) & -l_2\sin(q_1+q_2)\\ l_1\cos q_1 + l_2\cos(q_1+q_2) & l_2\cos(q_1+q_2) \end{bmatrix} \]

    求行列式（判断奇异）¶

    \[ \det J = \left(-l_1\sin q_1 - l_2\sin(q_1{+}q_2)\right)\cdot l_2\cos(q_1{+}q_2) - \left(-l_2\sin(q_1{+}q_2)\right)\cdot\left(l_1\cos q_1 + l_2\cos(q_1{+}q_2)\right) \]

    展开并整理：

    \[ = -l_1l_2\sin q_1\cos(q_1{+}q_2) - l_2^2\sin(q_1{+}q_2)\cos(q_1{+}q_2) + l_1l_2\sin(q_1{+}q_2)\cos q_1 + l_2^2\sin(q_1{+}q_2)\cos(q_1{+}q_2) \]

    中间两项相消（\(+l_2^2\) 与 \(-l_2^2\) 抵消）：

    \[ = l_1l_2\left[\sin(q_1{+}q_2)\cos q_1 - \sin q_1\cos(q_1{+}q_2)\right] \]

    用和角公式 \(\sin A\cos B - \sin B\cos A = \sin(A-B)\)，取 \(A = q_1+q_2\)，\(B = q_1\)：

    \[ \boxed{\ \det J = l_1l_2\sin q_2\ } \]

    这个简洁结果有明确的物理含义

    \[ \det J = l_1l_2\sin q_2 \]

    奇异条件：\(\det J = 0 \iff \sin q_2 = 0 \iff q_2 = 0°\) 或 \(180°\)

    姿态 物理含义
    \(q_2 = 0°\) 两连杆完全伸直（共线向外）
    \(q_2 = 180°\) 两连杆完全折叠（共线向内）

    为什么这两个姿态是奇异的：

    • 完全伸直时，末端只能沿垂直方向运动—— 沿连杆方向的自由度丢失了
    • 完全折叠时，末端位置与 \(q_1\) 无关的变化被 \(q_2\) 抵消

    直观理解：伸直时，转动 \(q_2\) 与转动 \(q_1\) 在末端产生的 速度方向重合（线性相关），雅可比的列不满秩。

    工程后果：

    问题 说明
    无法沿某方向运动 该方向的速度要求无解
    求逆发散 \(J^{-1}\) 不存在（或接近奇异时数值爆炸）
    关节速度爆炸 微小的末端速度要求对应极大的关节速度

    对策：阻尼最小二乘（DLS）——用 \(J^\top(JJ^\top + \lambda^2I)^{-1}\) 替代 \(J^{-1}\)， 在接近奇异时自动降低增益。

    三、雅可比的三类应用¶

    应用 1：速度映射（正问题）¶

    已知关节速度 \(\dot{\boldsymbol{q}}\)，求末端速度：

    \[ \dot{\boldsymbol{x}} = J\dot{\boldsymbol{q}} \]

    总是可算（一次矩阵乘法）。

    应用 2：逆速度映射（逆问题）¶

    已知期望的末端速度 \(\dot{\boldsymbol{x}}\)，求关节速度：

    \[ \dot{\boldsymbol{q}} = J^{-1}\dot{\boldsymbol{x}} \quad (m = n) \]

    冗余情形（\(m < n\)）用伪逆取最小范数解：

    \[ \dot{\boldsymbol{q}} = J^{+}\dot{\boldsymbol{x}}, \qquad J^{+} = J^\top(JJ^\top)^{-1} \]

    （这里 \(JJ^\top\) 是 \(m\times m\)，可逆性更好。）

    应用 3：静力对偶（力传递）¶

    这是最容易被忽略却很重要的一点。

    虚功原理：末端做的功 = 关节做的功

    \[ \boldsymbol{F}^\top\dot{\boldsymbol{x}} = \boldsymbol{\tau}^\top\dot{\boldsymbol{q}} \]

    代入 \(\dot{\boldsymbol{x}} = J\dot{\boldsymbol{q}}\)：

    \[ \boldsymbol{F}^\top J\dot{\boldsymbol{q}} = \boldsymbol{\tau}^\top\dot{\boldsymbol{q}} \]

    对任意 \(\dot{\boldsymbol{q}}\) 成立，所以

    \[ \boxed{\ \boldsymbol{\tau} = J^\top\boldsymbol{F}\ } \]

    为什么力映射用转置（而不是逆）

    速度用 \(J\)，力用 \(J^\top\)——这个「对偶」关系来自 虚功原理（能量守恒）。

    量 映射 理由
    速度 \(\dot{\boldsymbol{x}} = J\dot{\boldsymbol{q}}\) 运动学定义
    力 \(\boldsymbol{\tau} = J^\top\boldsymbol{F}\) 能量守恒

    验证量纲：\(\boldsymbol{F}\) 是力（\(m\) 维），\(J^\top\) 是 \(n\times m\)， 乘起来是 \(n\) 维的力矩

    工程含义：

    • 想让末端施加某个力，可由 \(\boldsymbol{\tau} = J^\top\boldsymbol{F}\) 算关节力矩
    • 奇异位形下，某些方向的力需要无穷大力矩 （因为 \(J\) 降秩，\(J^\top\) 也降秩，无法产生某些方向的力）

    这个对偶关系在「力控」「阻抗控制」中到处出现， 也是为什么机器人控制里 \(J\) 与 \(J^\top\) 总是成对出现。

    四、奇异值分解与雅可比¶

    雅可比的奇异值有直接的物理含义。

    \[ J = U\Sigma V^\top \]

    奇异值 \(\sigma_i\) 的含义：

    奇异值 含义
    最大奇异值 \(\sigma_{\max}\) 末端在某方向的最大速度放大倍数
    最小奇异值 \(\sigma_{\min}\) 最弱方向的放大倍数
    \(\sigma_{\min} = 0\) 奇异（该方向动不了）

    可操作度（manipulability）：

    \[ w = \sqrt{\det(JJ^\top)} = \prod_i\sigma_i \]

    衡量机器人「离奇异有多远」：\(w\) 大表示灵活，\(w\to0\) 表示接近奇异。

    条件数：

    \[ \kappa(J) = \frac{\sigma_{\max}}{\sigma_{\min}} \]

    \(\kappa\) 大表示各向异性强（某些方向容易动、某些方向难动）。

    这就是「奇异值和可操作度」在机器人学中的用法

    用途 方法
    避奇异路径规划 最大化 \(w\) 或最小化 \(\kappa\)
    奇异检测 监控 \(\sigma_{\min}\)，低于阈值就报警
    力/速度权衡 由奇异值分布决定

    这回到了线性代数模块的 SVD——那里讲的数学工具， 在这里变成了机器人设计的定量指标。

    五、典型例题¶

    例题 1：二连杆雅可比的计算¶

    设 \(l_1 = l_2 = 1\)，\(q_1 = 0°\)，\(q_2 = 90°\)。 求雅可比矩阵，并判断是否奇异。

    思路

    代入前面的公式，先算角度和，再代三角函数值。

    解答

    准备三角函数值：

    \[ q_1 = 0, \qquad q_2 = \frac{\pi}{2}, \qquad q_1+q_2 = \frac{\pi}{2} \]
    \[ \sin q_1 = 0,\quad \cos q_1 = 1,\quad \sin(q_1+q_2) = 1,\quad \cos(q_1+q_2) = 0 \]

    代入雅可比公式（\(l_1 = l_2 = 1\)）：

    \[ J = \begin{bmatrix} -1\cdot0 - 1\cdot1 & -1\cdot1\\ 1\cdot1 + 1\cdot0 & 1\cdot0 \end{bmatrix} = \begin{bmatrix} -1 & -1\\ 1 & 0 \end{bmatrix} \]

    求行列式：

    \[ \det J = (-1)(0) - (-1)(1) = 1 \]

    交叉验证（用公式 \(\det J = l_1l_2\sin q_2\)）：

    \[ \det J = 1\cdot1\cdot\sin\frac{\pi}{2} = 1 \;\checkmark \]

    结论：\(\det J = 1 \neq 0\) → 非奇异，姿态可操作。

    物理验证：\(q_2 = 90°\) 是「垂直」，离奇异的 \(q_2 = 0°\) 与 \(180°\) 都最远（\(90°\) 处的 \(\lvert\sin q_2\rvert\) 最大）。 所以这是可操作度最大的姿态

    可操作度随第二关节角的变化

    \[ \lvert\det J\rvert = l_1l_2\lvert\sin q_2\rvert \]
    \(q_2\) \(\lvert\det J\rvert\) 状态
    \(0°\) \(0\) 奇异
    \(30°\) \(0.5l_1l_2\) 较差
    \(60°\) \(0.866l_1l_2\) 较好
    \(90°\) \(l_1l_2\) 最优
    \(120°\) \(0.866l_1l_2\) 较好
    \(180°\) \(0\) 奇异

    所以二连杆的最佳工作区间是 \(q_2\) 在 \(60°\)–\(120°\)。

    与 \(q_1\) 无关（因为 \(\det J\) 不含 \(q_1\)）—— 这是二连杆平面臂的特殊性质（整个工作空间内径向对称）。

    例题 2：由末端速度求关节速度¶

    承上例（\(J = \begin{bmatrix}-1&-1\\1&0\end{bmatrix}\)）。 要求末端速度为 \(\dot{\boldsymbol{x}} = (0, 1)^\top\)，求关节速度。

    思路

    解线性方程组 \(J\dot{\boldsymbol{q}} = \dot{\boldsymbol{x}}\)。

    解答

    列方程：

    \[ \begin{bmatrix}-1&-1\\1&0\end{bmatrix} \begin{bmatrix}\dot q_1\\ \dot q_2\end{bmatrix} = \begin{bmatrix}0\\1\end{bmatrix} \]

    展开：

    \[ \begin{cases} -\dot q_1 - \dot q_2 = 0\\ \dot q_1 = 1 \end{cases} \]

    求解：由第二式 \(\dot q_1 = 1\)，代入第一式：

    \[ -1 - \dot q_2 = 0 \implies \dot q_2 = -1 \]

    结果：

    \[ \dot{\boldsymbol{q}} = (1,\ -1)^\top \]

    验证：

    \[ J\dot{\boldsymbol{q}} = \begin{bmatrix}-1&-1\\1&0\end{bmatrix}\begin{bmatrix}1\\-1\end{bmatrix} = \begin{bmatrix}-1+1\\1\end{bmatrix} = \begin{bmatrix}0\\1\end{bmatrix} \;\checkmark \]

    物理含义：关节 1 正向转、关节 2 反向转， 两者配合使末端纯向上运动（水平分量恰好抵消）。

    也可用逆矩阵直接算：

    \[ J^{-1} = \frac{1}{\det J}\begin{bmatrix}0&1\\-1&-1\end{bmatrix} = \begin{bmatrix}0&1\\-1&-1\end{bmatrix} \]

    （因为 \(\det J = 1\)，逆矩阵就是伴随矩阵。）

    验证：

    \[ J^{-1}\dot{\boldsymbol{x}} = \begin{bmatrix}0&1\\-1&-1\end{bmatrix}\begin{bmatrix}0\\1\end{bmatrix} = \begin{bmatrix}1\\-1\end{bmatrix} \;\checkmark \]

    注意逆矩阵的推导顺序

    \(2\times2\) 矩阵的逆公式：

    \[ \begin{bmatrix}a&b\\c&d\end{bmatrix}^{-1} = \frac{1}{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix} \]

    注意对角元互换、非对角元变号——这个符号容易记错。

    验证方法：算 \(J\cdot J^{-1}\) 看是否得单位阵。

    在本例中：

    \[ J\cdot J^{-1} = \begin{bmatrix}-1&-1\\1&0\end{bmatrix}\begin{bmatrix}0&1\\-1&-1\end{bmatrix} = \begin{bmatrix}0+1 & -1+1\\ 0+0 & 1+0\end{bmatrix} = \begin{bmatrix}1&0\\0&1\end{bmatrix} \;\checkmark \]

    例题 3：奇异位形的检测¶

    设 \(l_1 = 2\)、\(l_2 = 1\)。判断 \(q_2 = 5°\) 时的可操作度， 并说明为什么此时控制会出问题。

    思路

    用 \(\det J = l_1l_2\sin q_2\) 算可操作度。

    解答

    计算行列式：

    \[ \det J = l_1l_2\sin q_2 = 2\times1\times\sin 5° = 2\times0.0872 = 0.174 \]

    与最优姿态（\(q_2 = 90°\)）对比：

    姿态 \(\det J\) 相对最优
    \(q_2 = 90°\) \(2.0\) \(100\%\)
    \(q_2 = 5°\) \(0.174\) \(8.7\%\)

    可操作度只有最优时的 8.7% —— 接近奇异。

    为什么控制会出问题：

    1. 逆运动学的增益爆炸

    \[ J^{-1} = \frac{1}{\det J}\begin{bmatrix}\cdots\end{bmatrix} \]

    \(\det J = 0.174\) 时，逆矩阵的元素被放大 \(1/0.174 \approx 5.7\) 倍。 若 \(q_2 = 1°\)（\(\det J = 0.035\)），放大 29 倍； \(q_2 = 0.1°\) 时放大 287 倍。

    后果：末端要求一个微小的速度，关节就要转动极快—— 超出电机能力，或引起剧烈振动。

    2. 微小误差被放大

    控制中总有测量/计算误差。接近奇异时，

    \[ \dot{\boldsymbol{q}} = J^{-1}\dot{\boldsymbol{x}} \]

    会把 \(\dot{\boldsymbol{x}}\) 的小误差放大 \(1/\sigma_{\min}\) 倍。 当 \(\sigma_{\min}\to0\)，误差被放大到无穷。

    3. 某些方向完全动不了

    奇异时 \(\det J = 0\)，\(J\) 降秩， 存在非零向量 \(\boldsymbol{v}\) 使 \(J\boldsymbol{v} = \boldsymbol{0}\)。

    物理含义：沿 \(\boldsymbol{v}\) 方向转关节，末端不动—— 这部分「关节运动」被浪费了。

    在本例（完全伸直）中，这个方向就是「沿连杆轴向」的末端运动能力。

    工程对策一览

    方法 做法 代价
    阻尼最小二乘 用 \(J^\top(JJ^\top+\lambda^2I)^{-1}\) 引入位置误差
    关节限位 限制 \(q_2\) 不小于某个角度 缩小工作空间
    任务空间缩放 接近奇异时降低末端速度指令 变慢
    避奇异路径规划 规划时就绕开奇异区 需要路径优化
    冗余机器人 用多余自由度主动避开 结构复杂

    阻尼最小二乘的公式：

    \[ \dot{\boldsymbol{q}} = J^\top\big(JJ^\top + \lambda^2I\big)^{-1}\dot{\boldsymbol{x}} \]

    原理：加上 \(\lambda^2I\) 使矩阵一定可逆（正定）， 在奇异附近自动「软化」——牺牲一些精度换取数值稳定。

    \(\lambda\) 的选取：离奇异远时取小（精度优先）， 接近奇异时取大（稳定优先）。这就是变阻尼策略。

    例题 4：力映射与对偶¶

    承例 1（\(J = \begin{bmatrix}-1&-1\\1&0\end{bmatrix}\)）。 若末端要施加 \(\boldsymbol{F} = (0, 10)^\top\)（向上 10 N）， 求需要的关节力矩，并验证能量守恒。

    思路

    用 \(\boldsymbol{\tau} = J^\top\boldsymbol{F}\)。

    解答

    求 \(J^\top\)（转置即行列互换）：

    \[ J^\top = \begin{bmatrix}-1&1\\-1&0\end{bmatrix} \]

    计算关节力矩：

    \[ \boldsymbol{\tau} = J^\top\boldsymbol{F} = \begin{bmatrix}-1&1\\-1&0\end{bmatrix}\begin{bmatrix}0\\10\end{bmatrix} = \begin{bmatrix}0+10\\0+0\end{bmatrix} = \begin{bmatrix}10\\0\end{bmatrix} \]

    结果：\(\boldsymbol{\tau} = (10,\ 0)^\top\)

    物理解读：

    关节 力矩 含义
    关节 1 \(10\) N·m 需要驱动
    关节 2 \(0\) 不需要力矩

    为什么关节 2 不需要力矩：当前姿态（\(q_1 = 0\)，\(q_2 = 90°\)）下， 关节 2 的轴线与所需的力方向「对齐」， 或者更准确地说：\(\boldsymbol{F}\) 在关节 2 「能产生的力」方向上的 投影为零。

    验证能量守恒（虚功）：

    设关节速度为 \(\dot{\boldsymbol{q}} = (1,-1)^\top\)（例 2 的结果）， 则末端速度为 \(\dot{\boldsymbol{x}} = (0,1)^\top\)。

    末端功率：

    \[ P_{\text{末端}} = \boldsymbol{F}^\top\dot{\boldsymbol{x}} = (0,10)\cdot(0,1) = 10 \]

    关节功率：

    \[ P_{\text{关节}} = \boldsymbol{\tau}^\top\dot{\boldsymbol{q}} = (10,0)\cdot(1,-1) = 10 \]

    两者相等 ✓ 能量守恒成立。

    这个「对偶」在控制中的核心地位

    控制类型 主控量 用到的关系
    位置/速度控制 关节速度 \(\dot{\boldsymbol{x}} = J\dot{\boldsymbol{q}}\)
    力/阻抗控制 末端力 \(\boldsymbol{\tau} = J^\top\boldsymbol{F}\)
    混合控制 两者 按方向分解

    为什么这个对偶必然成立：来自虚功原理（能量守恒）， 是物理定律，不是数学巧合。

    这也解释了「奇异位形下不能施加某些方向的力」： \(J\) 降秩 → \(J^\top\) 也降秩 → \(\boldsymbol{\tau}\) 张成的空间变小， 有些 \(\boldsymbol{F}\) 无法实现（无论给多大关节力矩）。

    六、用在哪些课程里¶

    机器人学 · 运动学与力控¶

    • 速度运动学：\(\dot{\boldsymbol{x}} = J\dot{\boldsymbol{q}}\)（核心方程）
    • 静力分析：\(\boldsymbol{\tau} = J^\top\boldsymbol{F}\)
    • 奇异位形：\(\det J = 0\)，用 \(\sigma_{\min}\) 或可操作度检测
    • 逆运动学数值解：\(\Delta\boldsymbol{q} = J^{+}\Delta\boldsymbol{x}\)（雅可比迭代）
    • 阻抗/导纳控制：全建立在 \(J\) 与 \(J^\top\) 之上

    机器人机构学 · 机构的自由度与性能¶

    • 自由度分析：雅可比的秩给出瞬时自由度数
    • 可操作度 \(w = \sqrt{\det(JJ^\top)}\) 作为机构设计指标
    • 条件数 \(\kappa(J)\) 衡量灵活性
    • 并联机构的雅可比分析与串联不同（含约束）

    模式识别 · 反向传播与梯度流¶

    • 雅可比矩阵就是链式法则里的偏导矩阵
    • 逐元素激活函数的雅可比是对角阵 → 高效计算
    • 梯度消失的定量分析就是雅可比连乘的谱分析

    无人系统自主决策与优化 · 轨迹跟踪¶

    • 微分平坦/反馈线性化：用雅可比的逆做精确线性化
    • 轨迹跟踪控制：\(\dot{\boldsymbol{q}}_d = J^{+}\dot{\boldsymbol{x}}_d\)
    • 模型预测控制：预测模型对状态/控制的雅可比

    七、自测¶

    Q1 三连杆平面机械臂（\(n = 3\)，末端位置 \(m = 2\)）的雅可比是什么形状？ 如何求逆运动学解？

    提示

    考虑 \(m\) 与 \(n\) 的关系。

    解答

    雅可比形状：\(m\times n = 2\times3\)

    \[ J \in \mathbb{R}^{2\times3} \]

    行列式不存在（非方阵）→ 不能直接求逆 ✗

    这是冗余机器人（\(n > m\)：关节数多于任务维数）。

    求逆解用伪逆（最小范数解）：

    \[ \dot{\boldsymbol{q}} = J^{+}\dot{\boldsymbol{x}}, \qquad J^{+} = J^\top\big(JJ^\top\big)^{-1} \]

    这时 \(JJ^\top\) 是 \(2\times2\)，可逆性较好

    冗余的价值：

    优势 说明
    无穷多解 \(3-2 = 1\) 维的零空间
    可避障 用零空间运动规避障碍
    可避奇异 主动调整姿态远离奇异
    可优化次要目标 如能耗最小、力矩最小

    零空间投影（利用冗余做次要任务）：

    \[ \dot{\boldsymbol{q}} = J^{+}\dot{\boldsymbol{x}} + \big(I - J^{+}J\big)\boldsymbol{z} \]

    第二项在零空间内（不影响末端），可用来优化次要目标 \(\boldsymbol{z}\)。

    验证：\(J(I - J^+J) = J - JJ^+J = J - J = 0\) （因为 \(JJ^+J = J\) 是伪逆的定义性质之一。）

    Q2 为什么 \(\boldsymbol{\tau} = J^\top\boldsymbol{F}\) 而不是 \(\boldsymbol{\tau} = J^{-1}\boldsymbol{F}\)？

    提示

    从能量/虚功角度考虑，并检查量纲。

    解答

    因为来自虚功原理（能量守恒），不是运动学关系。

    推导：

    末端做功 = 关节做功

    \[ \boldsymbol{F}^\top\dot{\boldsymbol{x}} = \boldsymbol{\tau}^\top\dot{\boldsymbol{q}} \]

    代入 \(\dot{\boldsymbol{x}} = J\dot{\boldsymbol{q}}\)：

    \[ \boldsymbol{F}^\top J\dot{\boldsymbol{q}} = \boldsymbol{\tau}^\top\dot{\boldsymbol{q}} \]

    对任意 \(\dot{\boldsymbol{q}}\) 成立 →

    \[ \boldsymbol{\tau} = J^\top\boldsymbol{F} \]

    为什么不能用 \(J^{-1}\)：

    问题 说明
    形状不对 \(J^{-1}\) 是 \(n\times n\)，\(\boldsymbol{F}\) 是 \(m\) 维；\(m \neq n\) 时无法相乘
    量纲不对 \(\boldsymbol{F}\)（力）乘 \(J^{-1}\)（1/长度）得「力/长度」，不是力矩
    物理含义不对 力映射是「对偶」，不是「逆」

    量纲验证（\(J^\top\) 正确）：

    • \(\boldsymbol{F}\) 各分量：力（N）
    • \(J\) 各元素：长度（m）
    • \(J^\top\boldsymbol{F}\)：N·m = 力矩

    核心认识：速度用逆、力用转置， 这与「线性代数的对偶空间」是同一件事—— 力是速度的对偶向量（属于对偶空间）， 所以变换用转置而非逆。

    Q3 判断：\(\det J = 0\) 时，机器人完全不能运动。

    提示

    考虑零空间的含义。

    解答

    不对。不是「完全不能动」，而是「某个方向不能动」。

    准确表述：

    \(\det J = 0\) 表示 \(J\) 降秩——存在非零向量 \(\boldsymbol{v}\) 使 \(J\boldsymbol{v} = \boldsymbol{0}\)。

    含义分解：

    方向 能否运动
    值域方向（\(J\) 的列空间） 可以运动 ✓
    零空间方向 关节动但末端不动（该运动被浪费）

    二连杆例子的具体情况（完全伸直，\(q_2 = 0°\)）：

    • 末端可以沿垂直于连杆的方向运动（转 \(q_1\)）
    • 末端不能沿连杆轴向运动（这个自由度丢失）

    所以是「丢失一个自由度」，不是「完全不能动」。

    工程含义：

    现象 说明
    某些任务仍可完成 只要不需要那个缺失的方向
    逆解不可靠 需要该方向速度时无解或发散
    力控受限 无法在该方向施加力

    判据的精细程度：

    判据 能看出什么
    \(\det J = 0\) 是否恰好奇异
    \(\sigma_{\min}\)（最小奇异值） 离奇异多近（更实用！）

    实践建议：不要只看 \(\det J\) 是否为零，而要看 \(\sigma_{\min}\) 或 \(\kappa(J)\) —— 因为接近奇异（数值上）就已经有问题了。
