    矩阵微积分¶

    前面讲的是标量函数的导数。但机器学习里的函数几乎都是向量到标量或 向量到向量的——参数的个数是百万量级。

    矩阵微积分把「对每个参数求导」这件事写成矩阵运算。

    它的价值不只是记号简洁：写成矩阵形式后可以直接高效实现 （一次矩阵乘法代替百万次循环）。

    为什么必须用矩阵形式

    问题 逐元素写法 矩阵写法
    记号 \(10^6\) 个偏导 1 个梯度向量
    实现 百万次循环 一次矩阵乘法
    硬件利用 无法并行 GPU 天然适配

    这不是「为了好看」——矩阵运算才能用上 BLAS、cuBLAS 等优化库， 把计算速度提高几百倍。

    一、三种导数类型¶

    按「输入」与「输出」的维度分类：

    类型 输入 输出 导数形式 记号
    标量对向量 \(\boldsymbol{x}\in\mathbb{R}^n\) \(y\in\mathbb{R}\) 梯度（\(n\) 维向量） \(\nabla_{\boldsymbol{x}}y\) 或 \(\frac{\partial y}{\partial\boldsymbol{x}}\)
    向量对标量 \(t\in\mathbb{R}\) \(\boldsymbol{y}\in\mathbb{R}^m\) 切向量（\(m\) 维向量） \(\frac{\partial\boldsymbol{y}}{\partial t}\)
    向量对向量 \(\boldsymbol{x}\in\mathbb{R}^n\) \(\boldsymbol{y}\in\mathbb{R}^m\) 雅可比矩阵（\(m\times n\)） \(\frac{\partial\boldsymbol{y}}{\partial\boldsymbol{x}}\)

    「布局约定」不统一，是查资料时最大的坑

    向量对向量求导得到矩阵时，列/行的排列顺序有两种约定：

    约定 分子布局（numerator layout） 分母布局（denominator layout）
    \(\frac{\partial\boldsymbol{y}}{\partial\boldsymbol{x}}\) 的形状 \(m\times n\) \(n\times m\)
    常见于 数学教材、MML 部分工程教材
    梯度 \(\nabla f\) 列为向量 也为向量（通常一致）

    本文采用分子布局（结果的行数与输出维度一致）， 这也是 MML 与主流深度学习框架的约定。

    实际影响：看别的资料时先确认它用哪种约定， 否则转置关系会弄错。对 \(\frac{\partial y}{\partial\boldsymbol{x}}\) （标量对向量）两种约定结果相同，所以最常见的梯度计算不受影响。

    二、标量对向量：梯度¶

    设 \(f : \mathbb{R}^n \to \mathbb{R}\)，则梯度是

    \[ \nabla_{\boldsymbol{x}}f = \frac{\partial f}{\partial\boldsymbol{x}} = \begin{bmatrix} \dfrac{\partial f}{\partial x_1}\\[6pt] \vdots\\[2pt] \dfrac{\partial f}{\partial x_n} \end{bmatrix} \]

    每个分量是对应变量的偏导数。

    三个最基本的公式¶

    这三个必须背下来——几乎所有梯度计算都由它们组合而成。

    \[ \boxed{\ \frac{\partial}{\partial\boldsymbol{x}}\big(\boldsymbol{a}^\top\boldsymbol{x}\big) = \boldsymbol{a}\ } \]
    \[ \boxed{\ \frac{\partial}{\partial\boldsymbol{x}}\big(\boldsymbol{x}^\top\boldsymbol{x}\big) = 2\boldsymbol{x}\ } \]
    \[ \boxed{\ \frac{\partial}{\partial\boldsymbol{x}}\big(\boldsymbol{x}^\top A\boldsymbol{x}\big) = 2A\boldsymbol{x} \quad (A \text{ 对称})\ } \]

    验证方法：逐分量展开

    验证第二个（\(\boldsymbol{x}^\top\boldsymbol{x} = \sum_i x_i^2\)）：

    \[ \frac{\partial}{\partial x_j}\sum_i x_i^2 = 2x_j \]

    所以整个梯度是 \(2\boldsymbol{x}\) ✓ —— 与标量情况 \((\boldsymbol{x}^2)' = 2x\) 完全平行。

    验证第三个（设 \(A\) 对称）：

    \[ \boldsymbol{x}^\top A\boldsymbol{x} = \sum_{i,j}A_{ij}x_ix_j \]

    对 \(x_k\) 求偏导。含 \(x_k\) 的项来自两处：

    • \(i=k\)：\(\sum_j A_{kj}x_kx_j\)
    • \(j=k\)：\(\sum_i A_{ik}x_ix_k\)

    两者相加（注意 \(A\) 对称，\(A_{kj} = A_{jk}\)）：

    \[ \frac{\partial}{\partial x_k} = 2\sum_j A_{kj}x_j = 2(A\boldsymbol{x})_k \]

    所以梯度是 \(2A\boldsymbol{x}\)

    注意：\(A\) 不对称时公式变成

    \[ \frac{\partial}{\partial\boldsymbol{x}}\big(\boldsymbol{x}^\top A\boldsymbol{x}\big) = (A + A^\top)\boldsymbol{x} \]

    当 \(A\) 对称时 \(A + A^\top = 2A\)，回到上面的形式。 机器学习中出现的二次型矩阵（如 Hessian、协方差）通常是对称的。

    复合运算的常用结果¶

    函数 梯度
    \(\boldsymbol{a}^\top\boldsymbol{x}\) \(\boldsymbol{a}\)
    \(\boldsymbol{x}^\top\boldsymbol{a}\) \(\boldsymbol{a}\)
    \(\boldsymbol{x}^\top\boldsymbol{x}\) \(2\boldsymbol{x}\)
    \(\boldsymbol{x}^\top A\boldsymbol{x}\)（\(A\) 对称） \(2A\boldsymbol{x}\)
    \(A\boldsymbol{x}\) 的某个分量 对应的行向量

    三、向量对向量：雅可比矩阵¶

    设 \(\boldsymbol{f}: \mathbb{R}^n \to \mathbb{R}^m\)，则雅可比矩阵是

    \[ J = \frac{\partial\boldsymbol{f}}{\partial\boldsymbol{x}} = \begin{bmatrix} \dfrac{\partial f_1}{\partial x_1} & \cdots & \dfrac{\partial f_1}{\partial x_n}\\[6pt] \vdots & \ddots & \vdots\\[4pt] \dfrac{\partial f_m}{\partial x_1} & \cdots & \dfrac{\partial f_m}{\partial x_n} \end{bmatrix} \]

    第 \(i\) 行是第 \(i\) 个输出对各输入的偏导。

    最重要的一个：线性映射¶

    若 \(\boldsymbol{f}(\boldsymbol{x}) = A\boldsymbol{x}\)，则

    \[ \boxed{\ \frac{\partial(A\boldsymbol{x})}{\partial\boldsymbol{x}} = A\ } \]

    线性映射的导数就是它自己的矩阵——这与标量情形 \((ax)' = a\) 完全平行。

    雅可比矩阵的完整含义

    1. 它是「局部线性化」的系数矩阵

    由泰勒一阶展开：

    \[ \boldsymbol{f}(\boldsymbol{x}+\Delta\boldsymbol{x}) \approx \boldsymbol{f}(\boldsymbol{x}) + J\Delta\boldsymbol{x} \]

    这就是机器人学里「关节速度 → 末端速度」的映射。

    2. 它给出体积缩放因子

    \[ \lvert\det J\rvert = \text{局部体积缩放倍数} \]

    在多变量积分的换元公式中出现。\(\det J = 0\) 表示映射降维。

    3. 链式法则就是矩阵乘法

    若 \(\boldsymbol{z} = \boldsymbol{g}(\boldsymbol{y})\)，\(\boldsymbol{y} = \boldsymbol{f}(\boldsymbol{x})\)，则

    \[ \frac{\partial\boldsymbol{z}}{\partial\boldsymbol{x}} = \frac{\partial\boldsymbol{z}}{\partial\boldsymbol{y}}\cdot\frac{\partial\boldsymbol{y}}{\partial\boldsymbol{x}} \qquad\text{（矩阵相乘）} \]

    这解释了为什么深度学习框架用矩阵乘法实现反向传播。

    常用结果表¶

    函数 雅可比
    \(A\boldsymbol{x}\) \(A\)
    \(\boldsymbol{a}^\top\boldsymbol{x}\) \(\boldsymbol{a}^\top\)
    \(\sigma(\boldsymbol{x})\)（逐元素作用） \(\operatorname{diag}(\sigma'(\boldsymbol{x}))\)
    \(\boldsymbol{x}\) 的某个线性组合 对应的行/列向量

    四、逐元素函数的雅可比：对角矩阵¶

    若 \(f\) 逐元素作用于向量（如 sigmoid、ReLU）：

    \[ \boldsymbol{y} = \begin{bmatrix}\sigma(x_1)\\ \vdots\\ \sigma(x_n)\end{bmatrix} \]

    则每个 \(y_i\) 只依赖 \(x_i\)，所以

    \[ J = \operatorname{diag}\big(\sigma'(x_1),\dots,\sigma'(x_n)\big) \]

    雅可比是对角矩阵——这意味着各分量互不影响。

    为什么这个结构很关键

    1. 计算极快

    对角矩阵与向量相乘只需 \(O(n)\)（而非 \(O(n^2)\)）， 而且实践中根本不用构造矩阵，直接用逐元素乘法：

    \[ J\boldsymbol{v} = \sigma'(\boldsymbol{x})\odot\boldsymbol{v} \]

    （\(\odot\) 是逐元素乘。）这正是深度学习框架的做法。

    1. 解释了「激活函数影响梯度传播」

    反向传播中要连乘各层的雅可比。逐元素函数的雅可比是对角的， 所以连乘退化为逐元素连乘：

    \[ \prod_{\ell}\sigma'(\boldsymbol{z}^{(\ell)}) \]
    激活函数 \(\sigma'\) 的范围 后果
    sigmoid \((0,\ 0.25]\) 连乘衰减快 → 梯度消失
    tanh \((0,\ 1]\) 稍好，但仍会衰减
    ReLU \(\{0,\ 1\}\) 正区间不衰减 ✓

    这就是「为什么 ReLU 成为默认选择」的矩阵视角解释。

    Softmax 的雅可比（非对角）¶

    Softmax 是例外——每个输出依赖所有输入：

    \[ \sigma(\boldsymbol{z})_i = \frac{e^{z_i}}{\sum_j e^{z_j}} \]

    它的雅可比是

    \[ J = \operatorname{diag}(\boldsymbol{s}) - \boldsymbol{s}\boldsymbol{s}^\top, \qquad \boldsymbol{s} = \sigma(\boldsymbol{z}) \]

    注意有非对角项 \(\boldsymbol{s}\boldsymbol{s}^\top\)，所以不是对角的。

    这个公式的推导要点

    记 \(s_i = \frac{e^{z_i}}{S}\)，其中 \(S = \sum_j e^{z_j}\)。

    当 \(i = j\)：

    \[ \frac{\partial s_i}{\partial z_i} = \frac{e^{z_i}S - e^{z_i}e^{z_i}}{S^2} = \frac{e^{z_i}}{S} - \left(\frac{e^{z_i}}{S}\right)^2 = s_i - s_i^2 = s_i(1-s_i) \]

    当 \(i \neq j\)：

    \[ \frac{\partial s_i}{\partial z_j} = \frac{0\cdot S - e^{z_i}e^{z_j}}{S^2} = -s_is_j \]

    合并成矩阵：对角线上是 \(s_i - s_i^2\)，非对角线是 \(-s_is_j\)， 正好就是 \(\operatorname{diag}(\boldsymbol{s}) - \boldsymbol{s}\boldsymbol{s}^\top\)

    与交叉熵配合时的简化：softmax + 交叉熵的联合梯度是 \(\boldsymbol{s} - \boldsymbol{y}\)（极其简洁）， 因为这个复杂雅可比被交叉熵的梯度「抵消」了。 这是 softmax 与交叉熵总是配对使用的原因之一。

    五、典型例题¶

    例题 1：求梯度¶

    设 \(f(\boldsymbol{x}) = \boldsymbol{x}^\top A\boldsymbol{x} + \boldsymbol{b}^\top\boldsymbol{x}\)， 其中 \(A\) 对称。求 \(\nabla f\)。

    思路

    拆成两项，分别用前面两个基本公式。

    解答

    拆成两项：

    \[ f(\boldsymbol{x}) = \underbrace{\boldsymbol{x}^\top A\boldsymbol{x}}_{\text{二次项}} + \underbrace{\boldsymbol{b}^\top\boldsymbol{x}}_{\text{一次项}} \]

    第一项（\(A\) 对称，用 \(\nabla(\boldsymbol{x}^\top A\boldsymbol{x}) = 2A\boldsymbol{x}\)）：

    \[ \nabla(\boldsymbol{x}^\top A\boldsymbol{x}) = 2A\boldsymbol{x} \]

    第二项（用 \(\nabla(\boldsymbol{b}^\top\boldsymbol{x}) = \boldsymbol{b}\)）：

    \[ \nabla(\boldsymbol{b}^\top\boldsymbol{x}) = \boldsymbol{b} \]

    相加：

    \[ \boxed{\ \nabla f = 2A\boldsymbol{x} + \boldsymbol{b}\ } \]

    这就是「二次型目标函数」的梯度， 令它为零得到正规方程的解

    \[ 2A\boldsymbol{x} + \boldsymbol{b} = \boldsymbol{0} \implies \boldsymbol{x} = -\frac12 A^{-1}\boldsymbol{b} \]

    （当 \(A\) 正定时这是极小点。）

    与标量情形对照

    标量 向量
    \(f = ax^2 + bx\) \(f = \boldsymbol{x}^\top A\boldsymbol{x} + \boldsymbol{b}^\top\boldsymbol{x}\)
    \(f' = 2ax + b\) \(\nabla f = 2A\boldsymbol{x} + \boldsymbol{b}\)
    \(f' = 0 \Rightarrow x = -\frac{b}{2a}\) \(\nabla f = 0 \Rightarrow \boldsymbol{x} = -\frac12A^{-1}\boldsymbol{b}\)

    结构完全一样（只是除法变成逆矩阵）。

    注意：标量时若 \(a > 0\) 是极小；向量时需 \(A\) 正定才是极小。 这就是「二阶条件」从「符号」推广到「正定性」的过程。

    例题 2：最小二乘的梯度推导¶

    给定数据矩阵 \(X\)（\(m\times n\)）、目标 \(\boldsymbol{y}\)（\(m\) 维）， 最小二乘损失为

    \[ L(\boldsymbol{w}) = \lVert X\boldsymbol{w} - \boldsymbol{y}\rVert^2 \]

    求 \(\nabla_{\boldsymbol{w}}L\)，并求最优解。

    思路

    先把范数平方写成 \(\boldsymbol{z}^\top\boldsymbol{z}\) 的形式，再求导。

    解答

    第一步：展开成二次型

    记残差 \(\boldsymbol{r} = X\boldsymbol{w} - \boldsymbol{y}\)，则 \(L = \boldsymbol{r}^\top\boldsymbol{r}\)。

    \[ L = (X\boldsymbol{w}-\boldsymbol{y})^\top(X\boldsymbol{w}-\boldsymbol{y}) \]

    展开（注意 \((A\boldsymbol{w})^\top = \boldsymbol{w}^\top A^\top\)）：

    \[ = \boldsymbol{w}^\top X^\top X\boldsymbol{w} - \boldsymbol{w}^\top X^\top\boldsymbol{y} - \boldsymbol{y}^\top X\boldsymbol{w} + \boldsymbol{y}^\top\boldsymbol{y} \]

    中间两项相等（都是标量，转置后不变）：

    \[ \boldsymbol{y}^\top X\boldsymbol{w} = (\boldsymbol{y}^\top X\boldsymbol{w})^\top = \boldsymbol{w}^\top X^\top\boldsymbol{y} \]

    所以

    \[ L = \boldsymbol{w}^\top X^\top X\boldsymbol{w} - 2\boldsymbol{w}^\top X^\top\boldsymbol{y} + \boldsymbol{y}^\top\boldsymbol{y} \]

    第二步：求梯度

    注意 \(X^\top X\) 是对称矩阵，用例题 1 的公式（其中 \(A = X^\top X\)，\(\boldsymbol{b} = -2X^\top\boldsymbol{y}\)）：

    \[ \nabla L = 2X^\top X\boldsymbol{w} - 2X^\top\boldsymbol{y} \]

    提取公因子：

    \[ \boxed{\ \nabla L = 2X^\top(X\boldsymbol{w} - \boldsymbol{y})\ } \]

    第三步：令梯度为零

    \[ X^\top X\boldsymbol{w} = X^\top\boldsymbol{y} \]

    这就是「正规方程」（normal equation）。

    若 \(X^\top X\) 可逆，解为

    \[ \boldsymbol{w}^\star = (X^\top X)^{-1}X^\top\boldsymbol{y} \]

    第四步：确认是最小值

    Hessian 是

    \[ H = \nabla^2 L = 2X^\top X \]

    它总是半正定（因为 \(\boldsymbol{v}^\top X^\top X\boldsymbol{v} = \lVert X\boldsymbol{v}\rVert^2 \geq 0\)）。 当 \(X\) 列满秩时正定 → 严格极小

    这里能用正规方程，但实践中常常不用

    原因：计算 \((X^\top X)^{-1}\) 的数值稳定性差，且代价高。

    方法 复杂度 数值稳定性
    正规方程 \(O(n^3)\) 差（条件数被平方）
    QR 分解 \(O(mn^2)\) 好
    SVD \(O(mn^2)\) 最好（可处理秩亏）
    梯度下降 迭代 适合大规模

    关键：\(\kappa(X^\top X) = \kappa(X)^2\)， 所以条件数被平方（本知识库「矩阵分解」一节的例题量化过这一点）。 条件数 \(10^4\) 的 \(X\) 会让 \(X^\top X\) 变成 \(10^8\)，求逆时精度损失严重。

    实践建议：小规模用 QR 或 SVD；大规模用迭代法（共轭梯度、随机梯度）。

    例题 3：sigmoid 的导数¶

    设 \(\sigma(x) = \frac{1}{1+e^{-x}}\)（逐元素作用）。 求它的导数，并说明为什么这对梯度传播不利。

    思路

    用商法则求导，结果可以用 \(\sigma\) 本身表示。

    解答

    第一步：求导

    用商法则（分子 1，分母 \(1+e^{-x}\)）：

    \[ \sigma'(x) = \frac{0\cdot(1+e^{-x}) - 1\cdot(-e^{-x})}{(1+e^{-x})^2} = \frac{e^{-x}}{(1+e^{-x})^2} \]

    第二步：用 \(\sigma\) 表示

    注意

    \[ \sigma(x) = \frac{1}{1+e^{-x}}, \qquad 1 - \sigma(x) = \frac{e^{-x}}{1+e^{-x}} \]

    两者相乘：

    \[ \sigma(x)\big(1-\sigma(x)\big) = \frac{1}{1+e^{-x}}\cdot\frac{e^{-x}}{1+e^{-x}} = \frac{e^{-x}}{(1+e^{-x})^2} \]

    与上面一致 ✓ 所以

    \[ \boxed{\ \sigma'(x) = \sigma(x)\big(1-\sigma(x)\big)\ } \]

    第三步：求最大值

    设 \(s = \sigma(x) \in (0,1)\)，则 \(\sigma' = s(1-s)\)。

    这是开口向下的抛物线，最大值在 \(s = 1/2\)：

    \[ \sigma'_{\max} = \frac12\times\frac12 = \frac14 = 0.25 \]

    边界情况：

    \(x\) \(\sigma(x)\) \(\sigma'(x)\)
    \(-\infty\) \(0\) \(0\)
    \(0\) \(0.5\) \(0.25\)
    \(+\infty\) \(1\) \(0\)

    第四步：为什么对梯度传播不利

    反向传播中，梯度要连乘各层的雅可比（对角阵），即连乘 \(\sigma'\)。

    \[ \sigma'(x) \leq 0.25 \]

    \(L\) 层连乘的上界是

    \[ 0.25^L \]
    层数 \(0.25^L\)
    5 \(9.8\times10^{-4}\)
    10 \(9.5\times10^{-7}\)
    20 \(9.1\times10^{-13}\)
    50 \(7.9\times10^{-31}\)

    梯度会指数衰减到零 → 梯度消失。

    相比之下 ReLU 在正区间 \(\sigma' = 1\)，连乘不衰减。

    sigmoid 的适用场景（不该完全弃用）

    场景 是否合适 原因
    深层网络的隐藏层 ✗ 梯度消失
    二分类输出层 ✓ 需要 \((0,1)\) 概率，且只有一层
    LSTM 的门控 ✓ 门需要 \((0,1)\) 的「开关」语义
    需要概率解释时 ✓ 输出天然是概率

    关键区分：问题出在「多层堆叠」而不是 sigmoid 本身。 输出层用一次没问题——因为只有一层，不存在连乘。

    例题 4：softmax + 交叉熵的梯度¶

    设 \(\boldsymbol{s} = \operatorname{softmax}(\boldsymbol{z})\)， 交叉熵损失为

    \[ L = -\sum_i y_i\log s_i \]

    （\(\boldsymbol{y}\) 是 one-hot 标签。）求 \(\frac{\partial L}{\partial\boldsymbol{z}}\)。

    思路

    用链式法则：先对 \(\boldsymbol{s}\) 求导，再乘 softmax 的雅可比。 结果会非常简洁。

    解答

    第一步：对 \(\boldsymbol{s}\) 求导

    \[ \frac{\partial L}{\partial s_i} = -\frac{y_i}{s_i} \]

    所以

    \[ \frac{\partial L}{\partial\boldsymbol{s}} = -\frac{\boldsymbol{y}}{\boldsymbol{s}} \qquad\text{（逐元素相除）} \]

    第二步：用链式法则乘雅可比

    \[ \frac{\partial L}{\partial z_k} = \sum_i \frac{\partial L}{\partial s_i}\cdot\frac{\partial s_i}{\partial z_k} \]

    其中（上一节推出的 softmax 雅可比）

    \[ \frac{\partial s_i}{\partial z_k} = s_i(\delta_{ik} - s_k) \]

    （\(\delta_{ik}\) 是 Kronecker 记号：\(i=k\) 时为 1，否则为 0。）

    第三步：代入求和

    \[ \frac{\partial L}{\partial z_k} = \sum_i \left(-\frac{y_i}{s_i}\right)\cdot s_i(\delta_{ik}-s_k) = -\sum_i y_i(\delta_{ik}-s_k) \]

    展开求和：

    \[ = -\sum_i y_i\delta_{ik} + s_k\sum_i y_i \]

    第一项：\(\sum_i y_i\delta_{ik} = y_k\)

    第二项：因为 \(\boldsymbol{y}\) 是 one-hot（或概率分布），\(\sum_i y_i = 1\)

    所以

    \[ \frac{\partial L}{\partial z_k} = -y_k + s_k \]

    写成向量形式：

    \[ \boxed{\ \frac{\partial L}{\partial\boldsymbol{z}} = \boldsymbol{s} - \boldsymbol{y}\ } \]

    这个「极简结果」是 softmax + 交叉熵配对的原因

    对比：

    组合 梯度
    softmax + 交叉熵 \(\boldsymbol{s}-\boldsymbol{y}\)（极简）
    softmax + 平方误差 含完整雅可比，复杂且梯度小

    为什么平方误差不好：当输出接近错误标签时 （\(s_i\) 很小但 \(y_i = 1\)），平方误差的梯度会包含 \(s_i\) 因子， 反而更小——学习更慢。

    交叉熵则给出 \(s_i - y_i\)，误差大时梯度也大，收敛更快。

    数值上的好处：

    • 结果只需逐元素相减，不需要构造 \(n\times n\) 的雅可比矩阵
    • 数值稳定（避免 \(\log 0\)，实现时用 log-sum-exp 技巧）

    这就是「分类任务用 softmax + 交叉熵」的数学理由—— 不只是习惯，而是梯度形式最优。

    六、用在哪些课程里¶

    模式识别 · 神经网络的理论基础¶

    • 所有层的梯度都是矩阵形式，反向传播实现为矩阵乘法
    • softmax + 交叉熵是分类任务的标准组合
    • 批归一化的梯度涉及对均值/方差的求导
    • 注意力机制的梯度需要处理 softmax 雅可比

    无人系统自主决策与优化 · 最优控制与学习¶

    • 线性二次调节器（LQR）：代价是二次型，梯度 \(2A\boldsymbol{x}+\boldsymbol{b}\) 形式
    • 模型预测控制：每步解一个二次规划
    • 策略梯度：对策略参数求导，全用矩阵形式
    • Hessian 近似（高斯-牛顿法）用于快速收敛

    机器人学 · 雅可比矩阵的应用¶

    • 速度运动学：\(\dot{\boldsymbol{x}} = J(\boldsymbol{q})\dot{\boldsymbol{q}}\)
    • 静力分析：\(\boldsymbol{\tau} = J^\top\boldsymbol{F}\)（转置关系）
    • 奇异位形：\(\det J = 0\)
    • 冗余逆运动学：用伪逆 \(J^+\)（本知识库「奇异值分解」一节的例题）

    智能传感与信息处理 · 状态估计¶

    • 卡尔曼滤波的增益矩阵来自最小化协方差的矩阵求导
    • 最小二乘标定：正规方程的解
    • 信息滤波器：用精度矩阵（协方差之逆）的矩阵运算

    七、自测¶

    Q1 求 \(f(\boldsymbol{x}) = \lVert A\boldsymbol{x}-\boldsymbol{b}\rVert^2\) 的梯度。

    提示

    与例题 2 结构相同。

    解答

    展开（记 \(\boldsymbol{r} = A\boldsymbol{x}-\boldsymbol{b}\)）：

    \[ f = \boldsymbol{r}^\top\boldsymbol{r} = \boldsymbol{x}^\top A^\top A\boldsymbol{x} - 2\boldsymbol{b}^\top A\boldsymbol{x} + \boldsymbol{b}^\top\boldsymbol{b} \]

    （中间两项相等，因为都是标量。）

    求梯度（\(A^\top A\) 对称）：

    \[ \nabla f = 2A^\top A\boldsymbol{x} - 2A^\top\boldsymbol{b} \]

    整理：

    \[ \boxed{\ \nabla f = 2A^\top(A\boldsymbol{x}-\boldsymbol{b})\ } \]

    结构：\(2\times\)(转置矩阵)\(\times\)(残差) —— 与例题 2 完全一致 （那里 \(X\) 替代了 \(A\)）。

    记忆方法：

    \[ \nabla_{\boldsymbol{x}}\lVert A\boldsymbol{x}-\boldsymbol{b}\rVert^2 = 2A^\top(A\boldsymbol{x}-\boldsymbol{b}) \]

    与标量 \((ax-b)^2\) 的导数 \(2a(ax-b)\) 平行——只是 \(a\) 变成 \(A^\top\)。

    Q2 求 \(\boldsymbol{y} = A\boldsymbol{x}\) 对 \(\boldsymbol{x}\) 的雅可比矩阵。

    提示

    逐个分量看 \(y_i\) 依赖哪些 \(x_j\)。

    解答

    逐分量展开：

    \[ y_i = \sum_{j=1}^{n}A_{ij}x_j \]

    求偏导：

    \[ \frac{\partial y_i}{\partial x_j} = A_{ij} \]

    所以雅可比就是 \(A\) 本身：

    \[ \boxed{\ \frac{\partial(A\boldsymbol{x})}{\partial\boldsymbol{x}} = A\ } \]

    含义：

    视角 结论
    线性映射 它的导数就是它自己
    与标量对照 \((ax)' = a\) ✓

    推论：线性映射在所有点处的雅可比都相同 （没有「局部」的差异）——这正是「线性」的定义性特征。

    Q3 判断：\(\frac{\partial(\boldsymbol{x}^\top A\boldsymbol{x})}{\partial\boldsymbol{x}} = 2A\boldsymbol{x}\) 对任意方阵 \(A\) 都成立。

    提示

    回顾推导中对 \(A\) 对称性的使用。

    解答

    不对，只在 \(A\) 对称时成立。

    正确的一般公式：

    \[ \frac{\partial(\boldsymbol{x}^\top A\boldsymbol{x})}{\partial\boldsymbol{x}} = (A + A^\top)\boldsymbol{x} \]

    验证：展开成求和

    \[ \boldsymbol{x}^\top A\boldsymbol{x} = \sum_{i,j}A_{ij}x_ix_j \]

    对 \(x_k\) 求偏导，含 \(x_k\) 的项来自 \(i=k\) 与 \(j=k\) 两处：

    \[ \frac{\partial}{\partial x_k} = \sum_j A_{kj}x_j + \sum_i A_{ik}x_i = (A\boldsymbol{x})_k + (A^\top\boldsymbol{x})_k \]

    即 \(\big((A+A^\top)\boldsymbol{x}\big)_k\)

    当 \(A\) 对称时 \(A^\top = A\)，得 \(2A\boldsymbol{x}\)

    为什么实践中通常写 \(2A\boldsymbol{x}\)： 机器学习中的二次型矩阵（Hessian、协方差、\(X^\top X\)） 都是对称的，所以简写形式足够。

    但要注意：若代码里传入非对称矩阵而得错误结果， 检查这一点能快速定位问题。

    Q4 设 \(\boldsymbol{s} = \operatorname{softmax}(\boldsymbol{z})\)，且 \(\boldsymbol{z}\in\mathbb{R}^3\)。 若 \(\boldsymbol{s} = (0.2,\ 0.3,\ 0.5)^\top\)，求 softmax 雅可比矩阵的对角线元素。

    提示

    对角线元素是 \(s_i(1-s_i)\)。

    解答

    用公式 \(J_{ii} = s_i(1-s_i)\)：

    \[ J_{11} = 0.2\times0.8 = 0.16 \]
    \[ J_{22} = 0.3\times0.7 = 0.21 \]
    \[ J_{33} = 0.5\times0.5 = 0.25 \]

    非对角线元素 \(J_{ij} = -s_is_j\)（\(i\neq j\)）：

    \[ J_{12} = J_{21} = -0.2\times0.3 = -0.06 \]
    \[ J_{13} = J_{31} = -0.2\times0.5 = -0.10 \]
    \[ J_{23} = J_{32} = -0.3\times0.5 = -0.15 \]

    完整矩阵：

    \[ J = \begin{bmatrix} 0.16 & -0.06 & -0.10\\ -0.06 & 0.21 & -0.15\\ -0.10 & -0.15 & 0.25 \end{bmatrix} \]

    验证两个性质：

    1. 每行之和为 0（因为 \(\sum_i s_i = 1\) 恒成立，对 \(z_k\) 求导得 0）：

    第一行：\(0.16 - 0.06 - 0.10 = 0\)

    第二行：\(-0.06+0.21-0.15 = 0\)

    第三行：\(-0.10-0.15+0.25 = 0\)

    2. 各行元素符号：对角线为正，非对角线为负 （提高某个 \(z_i\) 会降低其它 \(s_j\)）。

    意义：softmax 的输出是「竞争」关系—— 一类概率上升，其它必然下降。这与 sigmoid（各元素独立） 形成鲜明对比。
