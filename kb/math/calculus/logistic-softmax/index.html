    Logistic 与 Softmax 导数¶

    分类任务的输出层几乎总是这两个函数之一：

    任务 输出层 输出含义
    二分类 Logistic（sigmoid） 一个概率值
    多分类 Softmax 各类的概率（和为 1）

    这一页把它们的导数完整推导一遍——因为导数的形式 直接决定了训练能否收敛。

    为什么值得专门用一页讲它们的导数

    问题 与本页的关系
    为什么 sigmoid 会导致梯度消失？ 导数上限只有 0.25
    为什么分类用「softmax + 交叉熵」？ 联合梯度极简（\(\boldsymbol{s}-\boldsymbol{y}\)）
    为什么不用平方误差配 softmax？ 梯度会「消失」
    计算复杂度如何？ 一个是对角阵，一个是满矩阵

    结论先行：这两个函数的导数形式直接解释了深度学习的 若干设计选择。

    一、Logistic（Sigmoid）函数¶

    定义¶

    \[ \sigma(x) = \frac{1}{1+e^{-x}} \]

    值域：\((0, 1)\) —— 所以可解释为概率。

    形状：S 形曲线，在 \(x = 0\) 处取 \(0.5\)。

    导数推导¶

    用商的求导法则（分子为常数 1）：

    \[ \frac{\mathrm{d}}{\mathrm{d}x}\left[\frac{1}{1+e^{-x}}\right] = \frac{0\cdot(1+e^{-x}) - 1\cdot(-e^{-x})}{(1+e^{-x})^2} = \frac{e^{-x}}{(1+e^{-x})^2} \]

    关键技巧：用 \(\sigma\) 自身表示。

    注意到

    \[ \sigma(x) = \frac{1}{1+e^{-x}}, \qquad 1 - \sigma(x) = \frac{e^{-x}}{1+e^{-x}} \]

    两者相乘：

    \[ \sigma(x)\big(1-\sigma(x)\big) = \frac{1}{1+e^{-x}}\cdot\frac{e^{-x}}{1+e^{-x}} = \frac{e^{-x}}{(1+e^{-x})^2} \]

    与上面完全相同 ✓ 所以

    \[ \boxed{\ \sigma'(x) = \sigma(x)\big(1-\sigma(x)\big)\ } \]

    这个结果为什么漂亮

    1. 求导结果只用函数值本身

    前向传播时已经算出 \(\sigma(x)\)，所以反向传播不需要额外计算—— 直接复用。这让 sigmoid 的反向传播几乎没有额外成本。

    2. 最大值只有 ¼

    设 \(s = \sigma(x)\in(0,1)\)，则 \(\sigma' = s(1-s)\)。

    这是开口向下的抛物线，顶点在 \(s = 1/2\)：

    \[ \sigma'_{\max} = \frac12\cdot\frac12 = \frac14 = 0.25 \]

    上界 0.25 是后面「梯度消失」分析的出发点。

    导数的取值¶

    \(x\) \(\sigma(x)\) \(\sigma'(x)\)
    \(-6\) \(0.0025\) \(\approx 0.0025\)
    \(-2\) \(0.119\) \(0.105\)
    \(-1\) \(0.269\) \(0.197\)
    \(0\) \(0.5\) \(0.25\)（最大）
    \(1\) \(0.731\) \(0.197\)
    \(2\) \(0.881\) \(0.105\)
    \(6\) \(0.9975\) \(\approx 0.0025\)

    观察：两端（\(\lvert x\rvert\) 大）导数趋零—— 这意味着当输入饱和时，梯度消失。

    「饱和」是梯度消失的直接原因

    什么叫饱和：\(\lvert x\rvert\) 很大时 \(\sigma(x)\) 接近 0 或 1， 此时输入怎么变，输出几乎不变 → 导数趋于零。

    后果：

    情形 现象
    神经元输出接近 0 或 1 该神经元几乎不再学习
    多层连乘 梯度指数衰减

    这就是「为什么深层网络用 sigmoid 学不动」。

    实践中的缓解方法：

    方法 原理
    输入归一化 让 \(x\) 落在导数较大的区间
    批归一化 每层重新标准化，避免饱和
    换 ReLU 正区间导数恒为 1
    合适的权重初始化 避免初始就饱和

    二、Softmax 函数¶

    定义¶

    对向量 \(\boldsymbol{z}\in\mathbb{R}^K\)（称为 logits）：

    \[ s_i = \frac{e^{z_i}}{\sum_{j=1}^{K}e^{z_j}}, \qquad i = 1,\dots,K \]

    性质：

    性质 说明
    \(s_i\in(0,1)\) 每个都是正概率
    \(\sum_i s_i = 1\) 归一化
    保序 \(z_i > z_j \Rightarrow s_i > s_j\)
    平移不变 \(z_i \to z_i + c\) 不改变输出

    为什么需要 softmax¶

    问题：分类需要「各类的概率，且和为 1」。直接归一化不行：

    \[ \frac{z_i}{\sum_j z_j} \quad\text{（当 } z_i \text{ 为负时会出错）} \]

    softmax 的做法：先指数（保证正），再归一化。

    指数还带来一个好处：放大差异。

    \(z\) \(e^z\) softmax（与 0、2 一起）
    \(-1\) \(0.368\) \(0.019\)
    \(0\) \(1\) \(0.052\)
    \(2\) \(7.389\) \(0.386\)

    注意：\(z\) 只差 2，概率却差 20 倍——softmax 是「赢者通吃」的。

    平移不变性的实际价值（数值稳定）

    证明平移不变：

    \[ \frac{e^{z_i+c}}{\sum_j e^{z_j+c}} = \frac{e^{z_i}e^{c}}{\sum_j e^{z_j}e^{c}} = \frac{e^{z_i}}{\sum_j e^{z_j}} = s_i \]

    工程用途：防止溢出。

    若 \(z_i = 1000\)，则 \(e^{1000}\) 溢出（浮点数上限约 \(e^{709}\)）。

    解决办法：减去最大值

    \[ s_i = \frac{e^{z_i - \max_j z_j}}{\sum_j e^{z_j - \max_j z_j}} \]

    这样指数的自变量最大为 0，\(e^0 = 1\)，绝不会溢出， 而结果完全不变（由平移不变性保证）。

    这是所有深度学习框架内部的做法（log_softmax 同理）。

    三、Softmax 的雅可比矩阵¶

    推导¶

    \[ \frac{\partial s_i}{\partial z_j} = ? \]

    分两种情形。

    情形 1：\(i = j\)

    记 \(S = \sum_k e^{z_k}\)（分母，与 \(i\) 无关），则 \(s_i = e^{z_i}/S\)。

    用商法则（注意 \(S\) 也依赖 \(z_i\)）：

    \[ \frac{\partial s_i}{\partial z_i} = \frac{e^{z_i}\cdot S - e^{z_i}\cdot e^{z_i}}{S^2} = \frac{e^{z_i}}{S} - \left(\frac{e^{z_i}}{S}\right)^2 = s_i - s_i^2 \]
    \[ \boxed{\ \frac{\partial s_i}{\partial z_i} = s_i(1 - s_i)\ } \]

    形式与 sigmoid 相同（这并非巧合——二分类时二者一致）。

    情形 2：\(i \neq j\)

    此时分子 \(e^{z_i}\) 与分母中只有 \(e^{z_j}\) 那项依赖 \(z_j\)：

    \[ \frac{\partial s_i}{\partial z_j} = \frac{0\cdot S - e^{z_i}\cdot e^{z_j}}{S^2} = -\frac{e^{z_i}}{S}\cdot\frac{e^{z_j}}{S} = -s_is_j \]
    \[ \boxed{\ \frac{\partial s_i}{\partial z_j} = -s_is_j \quad (i\neq j)\ } \]

    合成矩阵形式¶

    \[ J = \frac{\partial\boldsymbol{s}}{\partial\boldsymbol{z}} = \operatorname{diag}(\boldsymbol{s}) - \boldsymbol{s}\boldsymbol{s}^\top \]

    验证：对角元是 \(s_i - s_i^2\)，非对角元是 \(-s_is_j\)

    softmax 的矩阵是满的 —— 这是实现上的关键点

    函数 雅可比 存储 乘法代价
    sigmoid 对角阵 \(O(K)\) \(O(K)\)
    softmax 满矩阵 \(O(K^2)\) \(O(K^2)\)

    但实践中有更好的写法：不要显式构造矩阵， 而用向量化运算：

    \[ J\boldsymbol{v} = \boldsymbol{s}\odot\boldsymbol{v} - \boldsymbol{s}\big(\boldsymbol{s}^\top\boldsymbol{v}\big) \]

    （\(\odot\) 是逐元素乘。）右边只需 \(O(K)\) 次运算

    推导：由 \(J = \operatorname{diag}(\boldsymbol{s}) - \boldsymbol{s}\boldsymbol{s}^\top\)：

    \[ J\boldsymbol{v} = \operatorname{diag}(\boldsymbol{s})\boldsymbol{v} - \boldsymbol{s}(\boldsymbol{s}^\top\boldsymbol{v}) = \boldsymbol{s}\odot\boldsymbol{v} - \boldsymbol{s}(\boldsymbol{s}^\top\boldsymbol{v}) \]

    这是「矩阵-向量积」的隐式实现，避免了 \(O(K^2)\) 的存储和运算。 深度学习框架正是这么做的。

    一个重要性质：每行之和为零¶

    \[ \sum_j \frac{\partial s_i}{\partial z_j} = 0 \]

    验证：因为 \(\sum_i s_i = 1\) 恒成立（与 \(\boldsymbol{z}\) 无关）， 对 \(z_j\) 求导得零。

    逐项验证（\(K = 3\)）：

    \[ s_i(1-s_i) + (-s_is_k) + (-s_is_l) = s_i - s_i^2 - s_i(s_k+s_l) \]

    由 \(s_i + s_k + s_l = 1\) 得 \(s_k + s_l = 1-s_i\)，所以

    \[ = s_i - s_i^2 - s_i(1-s_i) = s_i - s_i^2 - s_i + s_i^2 = 0 \;\checkmark \]

    物理含义：提高某一类概率必然降低其它类——这是「竞争」关系。

    四、与交叉熵配合：梯度极简¶

    这是「softmax + 交叉熵」成为分类标准配置的原因。

    设定¶

    \[ \boldsymbol{s} = \operatorname{softmax}(\boldsymbol{z}), \qquad L = -\sum_i y_i\log s_i \]

    其中 \(\boldsymbol{y}\) 是 one-hot 标签。

    推导¶

    第一步：对 \(\boldsymbol{s}\) 求导

    \[ \frac{\partial L}{\partial s_i} = -\frac{y_i}{s_i} \]

    第二步：链式法则

    \[ \frac{\partial L}{\partial z_j} = \sum_i\frac{\partial L}{\partial s_i}\cdot\frac{\partial s_i}{\partial z_j} \]

    代入 softmax 雅可比（统一写成 \(s_i(\delta_{ij} - s_j)\)）：

    \[ = \sum_i\left(-\frac{y_i}{s_i}\right)\cdot s_i\big(\delta_{ij}-s_j\big) = -\sum_i y_i\big(\delta_{ij}-s_j\big) \]

    展开：

    \[ = -\sum_i y_i\delta_{ij} + s_j\sum_i y_i \]

    第一项 \(= y_j\)（Kronecker 记号只留下 \(i = j\)）

    第二项：\(\sum_i y_i = 1\)（概率分布归一）

    所以

    \[ \boxed{\ \frac{\partial L}{\partial z_j} = s_j - y_j\ } \qquad\Longrightarrow\qquad \frac{\partial L}{\partial\boldsymbol{z}} = \boldsymbol{s} - \boldsymbol{y} \]

    这个结果为什么是「设计出来的最优」

    对比两种组合：

    组合 梯度 训练表现
    softmax + 交叉熵 \(\boldsymbol{s}-\boldsymbol{y}\) 收敛快 ✓
    softmax + 平方误差 含 \(s_i(1-s_i)\) 等因子 收敛慢 ✗

    为什么平方误差差：当预测严重错误时 （例如真值是类别 2，但 \(s_2 \approx 0\)），

    \[ \frac{\partial}{\partial s_2}(s_2 - 1)^2 = 2(s_2-1) \approx -2 \]

    这个梯度看起来不小，但要传到 \(\boldsymbol{z}\) 还要乘 softmax 的雅可比，其中含 \(s_2(1-s_2)\approx 0\) 的因子——

    结果：梯度被「掐灭」，学习停滞。

    而交叉熵给出的 \(s_2 - y_2 = s_2 - 1 \approx -1\)， 经过雅可比后仍然是 \(s_j - y_j\)，不含消失因子。

    这正是「交叉熵是为分类任务设计的损失函数」的含义。

    二分类的特例¶

    当 \(K = 2\) 时，softmax 退化为 sigmoid：

    \[ s_1 = \frac{e^{z_1}}{e^{z_1}+e^{z_2}} = \frac{1}{1+e^{-(z_1-z_2)}} = \sigma(z_1-z_2) \]

    梯度形式也一致：交叉熵 + sigmoid 的梯度是 \(\sigma - y\)。

    任务 输出层 损失 梯度
    二分类 1 个 sigmoid 二元交叉熵 \(\hat y - y\)
    多分类 \(K\) 个 softmax 分类交叉熵 \(\boldsymbol{s}-\boldsymbol{y}\)
    多标签 \(K\) 个 sigmoid 各类二元交叉熵 逐元素 \(\hat y_i - y_i\)

    注意「多标签」用多个 sigmoid（不是 softmax）—— 因为多标签的类别不互斥（可以同时属于多类）， 不需要「和为 1」的约束。

    五、典型例题¶

    例题 1：求 sigmoid 的导数¶

    设 \(\sigma(x) = \dfrac{1}{1+e^{-x}}\)，求 \(\sigma'(x)\) 并求最大值。

    思路

    用商法则，再设法用 \(\sigma\) 自身表示。

    解答

    第一步：商法则

    \[ \sigma'(x) = \frac{0\cdot(1+e^{-x}) - 1\cdot\frac{\mathrm{d}}{\mathrm{d}x}(1+e^{-x})}{(1+e^{-x})^2} \]

    注意 \(\frac{\mathrm{d}}{\mathrm{d}x}(1+e^{-x}) = -e^{-x}\)：

    \[ = \frac{-(-e^{-x})}{(1+e^{-x})^2} = \frac{e^{-x}}{(1+e^{-x})^2} \]

    第二步：用 \(\sigma\) 表示

    \[ \sigma(x) = \frac{1}{1+e^{-x}} \]

    计算 \(1-\sigma(x)\)：

    \[ 1-\sigma(x) = \frac{1+e^{-x}-1}{1+e^{-x}} = \frac{e^{-x}}{1+e^{-x}} \]

    相乘：

    \[ \sigma(x)\big(1-\sigma(x)\big) = \frac{1}{1+e^{-x}}\cdot\frac{e^{-x}}{1+e^{-x}} = \frac{e^{-x}}{(1+e^{-x})^2} \]

    与第一步一致

    \[ \boxed{\ \sigma'(x) = \sigma(x)\big(1-\sigma(x)\big)\ } \]

    第三步：求最大值

    设 \(s = \sigma(x)\)，则 \(\sigma' = s(1-s) = s - s^2\)。

    这是关于 \(s\) 的抛物线，顶点在

    \[ s = \frac{1}{2}, \qquad \sigma'_{\max} = \frac12\cdot\frac12 = \frac14 \]

    最大值：\(\dfrac14 = 0.25\)

    数值验证（\(x = 0\)）：

    \[ \sigma(0) = \frac{1}{1+1} = 0.5, \qquad \sigma'(0) = 0.5\times0.5 = 0.25 \;\checkmark \]

    导数的上界 0.25 是「梯度消失」分析的起点。

    例题 2：求 softmax 的雅可比矩阵¶

    设 \(\boldsymbol{z} = (1, 2, 3)^\top\)，求 \(\boldsymbol{s} = \operatorname{softmax}(\boldsymbol{z})\) 及雅可比矩阵。

    思路

    先算 softmax，再用 \(J_{ii} = s_i(1-s_i)\)、\(J_{ij} = -s_is_j\)。

    解答

    第一步：计算 softmax

    \[ e^1 = 2.71828, \qquad e^2 = 7.38906, \qquad e^3 = 20.0855 \]

    分母：

    \[ S = 2.71828 + 7.38906 + 20.0855 = 30.19284 \]

    各分量：

    \[ s_1 = \frac{2.71828}{30.19284} = 0.09003 \]
    \[ s_2 = \frac{7.38906}{30.19284} = 0.24473 \]
    \[ s_3 = \frac{20.0855}{30.19284} = 0.66524 \]

    验证归一化：

    \[ 0.09003 + 0.24473 + 0.66524 = 1.00000 \;\checkmark \]

    第二步：对角线元素 \(J_{ii} = s_i(1-s_i)\)

    \[ J_{11} = 0.09003\times0.90997 = 0.08192 \]
    \[ J_{22} = 0.24473\times0.75527 = 0.18484 \]
    \[ J_{33} = 0.66524\times0.33476 = 0.22270 \]

    第三步：非对角线元素 \(J_{ij} = -s_is_j\)

    \[ J_{12} = J_{21} = -0.09003\times0.24473 = -0.02203 \]
    \[ J_{13} = J_{31} = -0.09003\times0.66524 = -0.05989 \]
    \[ J_{23} = J_{32} = -0.24473\times0.66524 = -0.16281 \]

    完整矩阵：

    \[ J = \begin{bmatrix} 0.08192 & -0.02203 & -0.05989\\ -0.02203 & 0.18484 & -0.16281\\ -0.05989 & -0.16281 & 0.22270 \end{bmatrix} \]

    第四步：验证每行之和为零

    第一行：\(0.08192 - 0.02203 - 0.05989 = 0.00000\)

    第二行：\(-0.02203 + 0.18484 - 0.16281 = 0.00000\)

    第三行：\(-0.05989 - 0.16281 + 0.22270 = 0.00000\)

    全部为零 ✓ 与理论一致。

    观察：熵越大，对角线元素越小

    分布 熵 对角线元素
    均匀 \((1/3,1/3,1/3)\) 最大 \(1/3\times2/3 = 0.222\)（全相等）
    尖锐（本例） 较小 \(0.082, 0.185, 0.223\)（不等）

    规律：分布越尖锐（某类概率接近 1）， 该类对应的对角线元素 \(s_i(1-s_i)\) 越小。

    含义：当模型已经很有信心时（\(s_i \approx 1\)）， 梯度变小——这是「学习放缓」的数学表现。

    与 sigmoid 饱和的情形本质相同。

    例题 3：softmax + 交叉熵的梯度¶

    承例 2（\(\boldsymbol{z} = (1,2,3)^\top\)，\(\boldsymbol{s} = (0.090, 0.245, 0.665)^\top\)）。 若真实标签是第 3 类（\(\boldsymbol{y} = (0,0,1)^\top\)），求梯度。

    思路

    直接用 \(\boldsymbol{s} - \boldsymbol{y}\)。

    解答

    用极简公式：

    \[ \frac{\partial L}{\partial\boldsymbol{z}} = \boldsymbol{s} - \boldsymbol{y} \]

    逐分量：

    \[ \frac{\partial L}{\partial z_1} = 0.09003 - 0 = 0.09003 \]
    \[ \frac{\partial L}{\partial z_2} = 0.24473 - 0 = 0.24473 \]
    \[ \frac{\partial L}{\partial z_3} = 0.66524 - 1 = -0.33476 \]

    梯度：

    \[ \nabla_{\boldsymbol{z}}L = (0.090,\ 0.245,\ -0.335)^\top \]

    解读：

    分量 符号 梯度下降的方向
    \(z_1\) \(+0.09\) 减小 \(z_1\)（预测概率偏高了）
    \(z_2\) \(+0.245\) 减小 \(z_2\)（偏高更多）
    \(z_3\) \(-0.335\) 增大 \(z_3\)（真类概率要提升）

    验证梯度之和为零（这个性质由雅可比每行和为零推出）：

    \[ 0.09003 + 0.24473 - 0.33476 = 0.00000 \;\checkmark \]

    物理含义：softmax 参数有一个冗余自由度—— 所有 \(z_i\) 同加一个常数，输出不变。

    所以梯度必然「零和」（对平移方向无梯度）， 这解释了为什么必须有权重衰减或正则化来定住这个自由度。

    梯度之和为零带来的实践问题

    问题：\(\sum_j\partial L/\partial z_j = 0\) 意味着 梯度的方向总与向量 \((1,1,\dots,1)\) 正交。

    后果：

    现象 说明
    参数漂移 所有 \(z_i\) 可以同时增大而不改变输出
    数值膨胀 长期训练后 logits 越来越大

    缓解方法：

    方法 作用
    权重衰减（L2） 抑制权重无界增长
    批归一化 稳定中间层分布
    早停 在漂移造成问题前停止

    这是「为什么分类网络需要正则化」的一个具体原因—— 不只是防过拟合，也是为了控制这个固有自由度。

    例题 4：求导链的完整验证¶

    用两层网络验证「softmax + 交叉熵」的梯度确实等于 \(\boldsymbol{s}-\boldsymbol{y}\)。

    网络：

    \[ \boldsymbol{z} = W\boldsymbol{h} + \boldsymbol{b}, \qquad \boldsymbol{s} = \operatorname{softmax}(\boldsymbol{z}) \]

    其中 \(\boldsymbol{h}\) 是隐藏层输出，\(W\) 是输出层权重矩阵。

    思路

    先对 \(W\)（间接）求导，验证链式法则在各环节都成立。

    解答

    第一步：对 \(\boldsymbol{z}\) 的梯度（已知）

    \[ \frac{\partial L}{\partial\boldsymbol{z}} = \boldsymbol{s} - \boldsymbol{y} \]

    第二步：对 \(\boldsymbol{b}\) 的梯度

    由 \(\boldsymbol{z} = W\boldsymbol{h}+\boldsymbol{b}\)，得 \(\frac{\partial\boldsymbol{z}}{\partial\boldsymbol{b}} = I\)，所以

    \[ \frac{\partial L}{\partial\boldsymbol{b}} = \boldsymbol{s} - \boldsymbol{y} \]

    第三步：对 \(W\) 的梯度

    用链式法则（\(\boldsymbol{z}\) 通过 \(W\) 依赖）：

    \[ \frac{\partial L}{\partial W} = \frac{\partial L}{\partial\boldsymbol{z}}\cdot\frac{\partial\boldsymbol{z}}{\partial W} \]

    其中 \(\boldsymbol{z} = W\boldsymbol{h}\) 对 \(W\) 的导数是

    \[ \frac{\partial(W\boldsymbol{h})}{\partial W} \longrightarrow \text{结果为 } (\boldsymbol{s}-\boldsymbol{y})\boldsymbol{h}^\top \]

    所以

    \[ \boxed{\ \frac{\partial L}{\partial W} = (\boldsymbol{s} - \boldsymbol{y})\boldsymbol{h}^\top\ } \]

    量纲/形状检查：

    量 形状 说明
    \(\boldsymbol{s}-\boldsymbol{y}\) \(K\times1\) 输出层误差
    \(\boldsymbol{h}^\top\) \(1\times d\) 隐藏层输出的转置
    乘积 \(K\times d\) 与 \(W\) 形状一致 ✓

    这就是「输出层误差 × 输入」的经典形式—— 与前面「反向传播」一节的 \(\frac{\partial\mathcal{L}}{\partial W^{(\ell)}} = \boldsymbol{\delta}^{(\ell)}\boldsymbol{a}^{(\ell-1)\top}\) 完全相同。

    验证一个具体数值（简化：\(K = 2\)，\(d = 3\)）：

    设 \(\boldsymbol{s}-\boldsymbol{y} = (0.1, -0.1)^\top\)、 \(\boldsymbol{h} = (1, 2, 3)^\top\)，则

    \[ \frac{\partial L}{\partial W} = \begin{bmatrix}0.1\\-0.1\end{bmatrix}\begin{bmatrix}1&2&3\end{bmatrix} = \begin{bmatrix}0.1&0.2&0.3\\-0.1&-0.2&-0.3\end{bmatrix} \]

    观察：两行成比例（第二行 = 第一行 × \((-1)\)）。

    这不是巧合——它反映了 softmax 的「零和」结构： 所有输出权重的梯度沿 \((1,\dots,1)\) 方向的分量为零。

    完整的训练步骤（把这一页用起来）

    一次迭代：

    步骤 计算
    1. 前向 \(\boldsymbol{z} = W\boldsymbol{h}+\boldsymbol{b}\)，\(\boldsymbol{s} = \operatorname{softmax}(\boldsymbol{z})\)
    2. 损失 \(L = -\sum_i y_i\log s_i\)
    3. 输出层误差 \(\boldsymbol{\delta} = \boldsymbol{s}-\boldsymbol{y}\)
    4. 权重梯度 \(\partial L/\partial W = \boldsymbol{\delta}\boldsymbol{h}^\top\)
    5. 偏置梯度 \(\partial L/\partial\boldsymbol{b} = \boldsymbol{\delta}\)
    6. 回传到隐藏层 \(\partial L/\partial\boldsymbol{h} = W^\top\boldsymbol{\delta}\)
    7. 更新 \(W \leftarrow W - \eta\,\partial L/\partial W\)

    注意第 3 步：整个输出层的反向传播只需要一次减法—— 这是 softmax + 交叉熵组合的核心优势。

    六、用在哪些课程里¶

    模式识别 · 分类器的输出层¶

    • 二分类：sigmoid + 二元交叉熵
    • 多分类：softmax + 分类交叉熵
    • 多标签：多个 sigmoid（各标签独立）
    • 梯度形式统一为「预测 − 真值」，便于实现

    智能传感与信息处理 · 软判决与置信度¶

    • 传感器融合的软判决：用 softmax 给出各假设的置信度
    • 注意力的权重：softmax 用于归一化注意力分数
    • 温度参数：softmax 前除以 \(T\) 可调节「软硬程度」 （\(T\to0\) 变硬，\(T\) 大则更均匀）

    无人系统自主决策与优化 · 策略网络¶

    • 强化学习的策略输出：softmax 给出各动作的概率
    • 策略梯度中要对 log 概率求导（用到本页的链式结构）
    • 动作选择：按 softmax 概率采样（探索与利用的平衡）

    七、自测¶

    Q1 求 \(\sigma(2)\) 与 \(\sigma'(2)\) 的数值。

    提示

    先算 \(\sigma(2)\)，再用 \(\sigma(1-\sigma)\)。

    解答

    计算 \(\sigma(2)\)：

    \[ e^{-2} = 0.135335 \]
    \[ \sigma(2) = \frac{1}{1+0.135335} = \frac{1}{1.135335} = 0.880797 \]

    计算 \(\sigma'(2)\)（用 \(\sigma(1-\sigma)\)）：

    \[ \sigma'(2) = 0.880797\times(1-0.880797) = 0.880797\times0.119203 = 0.104994 \]

    结果：

    \[ \sigma(2) \approx 0.8808, \qquad \sigma'(2) \approx 0.1050 \]

    用另一方法验证（直接算 \(\frac{e^{-2}}{(1+e^{-2})^2}\)）：

    \[ \frac{0.135335}{(1.135335)^2} = \frac{0.135335}{1.288990} = 0.104994 \;\checkmark \]

    注意：\(x = 2\) 时导数只有 \(0.105\)， 不到最大值 \(0.25\) 的一半——已经进入「部分饱和」区间。

    这提醒我们：即使 \(x\) 不算很大（\(x=2\)），sigmoid 也开始饱和了。 这是 sigmoid 在深层网络中不受欢迎的定量原因之一。

    Q2 验证 softmax 的平移不变性：\(\boldsymbol{z} = (1,2,3)\) 与 \(\boldsymbol{z}' = (0,1,2)\)（都减 1）的 softmax 相同。

    提示

    分别算，或直接用平移不变性的证明。

    解答

    算第一个（已在例 2 中算过）：

    \[ \boldsymbol{s} = (0.09003,\ 0.24473,\ 0.66524) \]

    算第二个：

    \[ e^0 = 1, \qquad e^1 = 2.71828, \qquad e^2 = 7.38906 \]

    分母：

    \[ S' = 1 + 2.71828 + 7.38906 = 11.10734 \]

    各分量：

    \[ s_1' = \frac{1}{11.10734} = 0.09003 \]
    \[ s_2' = \frac{2.71828}{11.10734} = 0.24473 \]
    \[ s_3' = \frac{7.38906}{11.10734} = 0.66524 \]

    完全一致

    验证关系：\(S' = S/e = 30.19284/2.71828 = 11.10734\)

    （因为每个 \(e^{z_i}\) 都除以了 \(e\)，分母也除以 \(e\)，比值不变。）

    工程价值：数值稳定。

    若 \(\boldsymbol{z} = (1000, 1001, 1002)\)，直接算 \(e^{1000}\) 溢出。 减去最大值后变成 \((0,1,2)\) 附近的相对值，安全计算。

    实现要点：

    1
2
    z_shift = z - max(z)          # 平移（防止溢出）
s = exp(z_shift) / sum(exp(z_shift))

    所有深度学习框架的内部实现都这么做。

    Q3 二分类任务中，用 1 个 sigmoid 与用 2 个 softmax 等价吗？

    提示

    考虑自由度和梯度形式。

    解答

    在数学上等价，但实践中有差异。

    等价性：softmax 输出 \((s_1, s_2)\) 且 \(s_1+s_2 = 1\)， 所以只有 1 个自由度，与单个 sigmoid 相同：

    \[ s_2 = \frac{e^{z_2}}{e^{z_1}+e^{z_2}} = \frac{1}{1+e^{z_1-z_2}} = \sigma(z_2-z_1) \]

    差异对比：

    方面 1 个 sigmoid 2 个 softmax
    参数量 \(d+1\)（一组权重+偏置） \(2d+2\)（两组）
    自由度 恰好 多 1 个（平移冗余）
    梯度形式 \(\hat y - y\) \(\boldsymbol{s}-\boldsymbol{y}\)
    数值稳定性 好 需做平移处理
    实用性 推荐 ✓ 不必要

    结论：二分类应该用 1 个 sigmoid。

    原因：

    1. 参数更少（少一半输出层参数）
    2. 无冗余自由度（不需要额外正则化来定住平移）
    3. 实现简单（一次 sigmoid vs 带 max 减法的 softmax）

    什么情况用 2 类 softmax：当代码框架统一处理多分类时 （\(K=2\) 也走 softmax 路径），便于代码复用。 这在小 \(K\) 时代价可忽略。

    Q4 为什么「多标签分类」要用多个 sigmoid 而不是 softmax？

    提示

    考虑标签之间是否互斥。

    解答

    因为多标签任务的类别不互斥。

    核心区别：

    任务 标签关系 输出层 输出和
    多分类 互斥（只能属于一类） softmax \(=1\)
    多标签 不互斥（可同时属于多类） 多个 sigmoid 各自独立

    具体例子（图像标签）：

    一张图片可能同时是「沙滩」「日落」「有人」—— 这三个标签可以同时为真。

    若用 softmax，则三者的概率之和必须为 1， 强行让它们互相排斥——这不符合实际情况。

    正确做法：每个标签独立过一个 sigmoid

    \[ \hat y_i = \sigma(w_i^\top\boldsymbol{h}), \qquad i = 1,\dots,K \]

    用各类各自的二元交叉熵求和作为总损失：

    \[ L = -\sum_{i=1}^{K}\Big[y_i\log\hat y_i + (1-y_i)\log(1-\hat y_i)\Big] \]

    梯度：逐元素 \(\hat y_i - y_i\)（因为各支路独立， 雅可比是对角的）。

    判断方法：

    问题 用
    「这张图是猫、狗、还是鸟？」 softmax（三选一）
    「这张图里有猫吗？有狗吗？有鸟吗？」 3 个 sigmoid（各自判断）

    这是初学最容易搞错的地方之一——用错会导致模型 无法同时预测多个标签。
