    点估计¶

    概率论那一层讲「已知分布求概率」；统计这一层反过来：

    已知数据，反推分布（或分布的参数）。

    这个「反推」叫估计。这一页讲最基础的一类：点估计 —— 用一个数值（或向量）去估计未知参数。

    从概率到统计：问题的方向反了

    层次 已知 求
    概率论 分布（参数已知） 事件概率、期望、方差
    数理统计 数据（样本） 分布或参数

    这个方向反转是统计学的全部内容： 它带来了「估计好不好」的问题 —— 因为没有唯一的正确答案， 只有「哪个估计量更好」的比较。

    所以统计学的核心是「评价标准」：

    标准 回答的问题
    无偏性 平均而言是否准确？
    一致性 数据多了是否收敛到真值？
    有效性 波动是否最小？
    充分性 是否用尽了数据中的信息？

    这一页围绕这四个标准展开。

    一、估计量与估计值¶

    术语区分（容易混，但要分清）：

    术语 记号 含义
    参数 \(\theta\) 未知的真值（固定但不知道）
    估计量 \(\hat\theta = g(X_1,\dots,X_n)\) 随机变量（因为样本随机）
    估计值 \(\hat\theta_{\text{obs}}\) 代入观测数据后的具体数值

    关键观念：估计量是随机变量 —— 换个样本就得到不同的值。

    所以「估计量的好坏」要用分布来描述：

    • 它的期望（是否无偏）
    • 它的方差（是否稳定）
    • 它随 \(n\) 增大的行为（是否一致）

    「样本」的两层含义（一个常见的语言混淆）

    说法 含义
    「样本」 一次抽样得到的观测值 \(x_1,\dots,x_n\)
    「样本」 还没抽时的随机变量 \(X_1,\dots,X_n\)

    习惯上：

    • 写 \(X_i\) 时指随机变量（大写）
    • 写 \(x_i\) 时指观测值（小写）

    这个区别很重要：说「\(\bar X\) 的期望是 \(\mu\)」时用的是随机变量视角； 说「算得 \(\bar x = 3.2\)」时用的是观测值视角

    独立性假设：本章默认 \(X_1,\dots,X_n\) 独立同分布（i.i.d.）， 即每一样本来自同一分布且互不影响。

    二、三种常用点估计方法¶

    方法 1：矩估计¶

    思想：用样本矩等于理论矩，解出参数。

    \[ \underbrace{\frac1n\sum_i X_i^k}_{\text{样本 }k\text{ 阶矩}} = \underbrace{E[X^k]}_{\text{理论 }k\text{ 阶矩}} \]

    例：估计均值与方差 —— 用一阶矩：

    \[ \bar X = \mu \implies \hat\mu = \bar X \]

    优点：简单、总有解（一般情形）；缺点：效率可能较低。

    方法 2：最大似然估计（MLE）¶

    思想：选使观测数据「最可能发生」的参数。

    \[ \hat\theta_{\text{MLE}} = \arg\max_\theta\ \ell(\theta) = \arg\max_\theta\sum_i\log f(X_i;\theta) \]

    本知识库已在「最大似然估计」一页详细讲过，这里只强调它的地位：

    优点 说明
    一致 \(n\to\infty\) 时收敛到真值 ✓
    渐近有效 达到 Cramér-Rao 下界 ✓
    渐近正态 便于构造区间估计与检验 ✓
    有不变性 若 \(\hat\theta\) 是 MLE，则 \(g(\hat\theta)\) 也是 \(g(\theta)\) 的 MLE ✓

    「不变性」很实用：估计了方差 \(\sigma^2\) 后， 标准差 \(\sigma\) 的 MLE 直接开方即可

    方法 3：贝叶斯估计¶

    思想：把 \(\theta\) 视为随机变量，用数据更新先验：

    \[ p(\theta\mid\boldsymbol{x}) = \frac{p(\boldsymbol{x}\mid\theta)p(\theta)}{p(\boldsymbol{x})} \]

    给出的是整个后验分布（而非单个点）→ 信息更完整

    点估计时常用：

    准则 估计
    后验均值 \(E[\theta\mid\boldsymbol{x}]\)（最小化平方误差）
    后验中位数 最小化绝对误差
    后验众数（MAP） \(\arg\max p(\theta\mid\boldsymbol{x})\)

    与 MLE 的关系：

    \[ \text{MAP} = \arg\max\big[\ell(\theta)+\log p(\theta)\big] \]

    即「MLE + 先验惩罚」 —— 这就是正则化的贝叶斯解释

    三种方法的对应关系（与「最大似然估计」一页呼应）

    方法 目标 与正则化的关系
    矩估计 匹配矩 无
    MLE 最大化似然 无（等价于无正则）
    MAP 最大化后验 等价于加正则 ✓
    后验均值 最小化平方误差 等价于某种正则

    具体对应（已在前面讲过，这里汇总）：

    先验 等价的正则
    高斯先验 \(N(0,\sigma^2)\) L2 正则（Ridge） ✓
    拉普拉斯先验 L1 正则（Lasso） ✓
    均匀先验 无正则（退化为 MLE）

    一句话：「加正则」在贝叶斯视角下就是「加先验」 —— 两条路通向同一个公式。

    三、评价估计量的四个标准¶

    标准 1：无偏性¶

    定义：

    \[ E[\hat\theta] = \theta \quad\forall\theta \]

    含义：平均而言估计正确（不系统偏高或偏低）。

    偏差：\(\operatorname{Bias}(\hat\theta) = E[\hat\theta]-\theta\)。

    无偏的意义与局限（重要）

    无偏 ≠ 好。要结合方差一起看。

    经典反例：估计正态方差 \(\sigma^2\) 时

    估计量 期望 评价
    \(\frac1n\sum(X_i-\bar X)^2\) \(\frac{n-1}{n}\sigma^2\) 有偏 ✗
    \(\frac{1}{n-1}\sum(X_i-\bar X)^2\) \(\sigma^2\) 无偏 ✓

    所以样本方差用 \(n-1\) 而不是 \(n\) —— 这正是「为什么要除以 \(n-1\)」的答案

    为什么 \(n\) 会偏低（直观）：因为用了 \(\bar X\) 代替未知的 \(\mu\) —— 拟合过的中心比真中心更「贴合」数据，所以离差平方和偏小 ✗

    但注意：有偏的估计量有时更好（若其均方误差更小）。

    估计量类型 特点
    无偏 平均正确，但可能方差大
    最小均方误差（MSE） 可能引入偏差换取更小方差 ✓

    这就是「偏差-方差权衡」的来源（与「模式识别」中的概念完全一致）：

    \[ \text{MSE}(\hat\theta) = \operatorname{Bias}^2+\operatorname{Var} \]

    标准 2：有效性¶

    定义：在两个无偏估计量中，方差更小的更有效。

    相对效率：\(\dfrac{\operatorname{Var}(\hat\theta_1)}{\operatorname{Var}(\hat\theta_2)}\)。

    核心结论（Cramér-Rao 下界）：

    \[ \operatorname{Var}(\hat\theta)\geq\frac{1}{n\,I(\theta)} \]

    其中 \(I(\theta) = E\left[\left(\frac{\partial\log f(X;\theta)}{\partial\theta}\right)^2\right]\) 是单个样本的 Fisher 信息量。

    Fisher 信息量的三层理解（这是统计学的核心概念之一）

    理解 1：曲率（最直观）

    \[ I(\theta) = -E\left[\frac{\partial^2\log f}{\partial\theta^2}\right] \]

    似然函数的「尖峰程度」：

    似然形状 Fisher 信息 估计精度
    尖（曲率大） 大 高 ✓
    平（曲率小） 小 低 ✗

    为什么：尖的似然意味着「稍微偏离就明显变差」 → 数据对 \(\theta\) 的约束强 → 估计准

    理解 2：方差（估计的精度上限）

    \[ \operatorname{Var}(\hat\theta)\geq\frac{1}{nI(\theta)} \]

    含义：即使最聪明的估计量，精度也不能超过这个界 ✓

    \(n\) 增大 → 界下降（\(\propto 1/n\)） —— 这就是「多测几次能提高精度」的定量形式。

    理解 3：信息（与信息论的联系）

    Fisher 信息度量「数据中含有多少关于 \(\theta\) 的信息」 —— 与「信息论」模块的熵/互信息是同一主题的不同侧面

    实用价值：

    用途 说明
    评估估计量的效率 与下界比较
    实验设计 选使 \(I(\theta)\) 最大的测量方案 ✓
    置信区间宽度 与 \(1/\sqrt{nI}\) 成正比

    MLE 的渐近性质（重要）：

    \[ \hat\theta_{\text{MLE}} \xrightarrow{d} N\left(\theta,\ \frac{1}{nI(\theta)}\right) \]

    即 MLE 渐近达到 Cramér-Rao 下界 → 渐近有效 （这是「为什么实践中普遍用 MLE」的理论依据。）

    标准 3：一致性¶

    定义：\(n\to\infty\) 时 \(\hat\theta_n\xrightarrow{P}\theta\)。

    含义：数据足够多就收敛到真值。

    常用判据（由 MSE 分解）：

    \[ \text{MSE}\to0 \implies \text{一致} \]

    所以「偏差与方差都趋于 0」即可保证一致性

    为什么一致性是「最低要求」：不满足一致性的估计量 再多数据也没用 ✗

    标准 4：充分性¶

    定义：若统计量 \(T\) 包含了样本中关于 \(\theta\) 的全部信息， 则称 \(T\) 为充分统计量。

    判据（因子分解定理）：

    \[ f(x_1,\dots,x_n;\theta) = g(T(\boldsymbol{x});\theta)\cdot h(\boldsymbol{x}) \]

    含义：联合密度能被分解为「只通过 \(T\) 依赖 \(\theta\)」的形式

    充分性的实用价值

    核心意义：若 \(T\) 充分，则可以只保留 \(T\) 而不损失信息 ✓

    场景 好处
    数据压缩 存 \(T\) 而不是全部数据
    计算效率 只需处理 \(T\)
    理论分析 把 \(n\) 维问题化为 1 维

    例子：

    分布 充分统计量
    伯努利 \(B(1,p)\) \(\sum X_i\)（成功次数）
    正态（\(\mu\) 未知、\(\sigma\) 已知） \(\bar X\)
    正态（\(\mu,\sigma\) 都未知） \((\bar X,\ S^2)\)
    泊松 \(\text{Poisson}(\lambda)\) \(\sum X_i\)

    直觉：对伯努利来说，具体顺序无关紧要 —— 只有「成功几次」包含关于 \(p\) 的信息

    这就回答了「为什么可以扔掉原始数据」 —— 因为 \(T\) 已经包含全部信息。

    与「信息论」的联系： \(T\) 充分 ⟺ \(I(T;\theta) = I(\boldsymbol{X};\theta)\) （即 \(T\) 保留了对 \(\theta\) 的全部互信息。）

    这给了「充分性」一个信息论定义，也说明 「充分」就是「不舍弃任何信息」

    四、典型例题¶

    例题 1：矩估计与 MLE 的比较¶

    设 \(X_1,\dots,X_n\) 来自均匀分布 \(U(0,\theta)\)，\(\theta>0\) 未知。 求 (a) 矩估计；(b) MLE；© 比较两者的性质。

    思路

    矩估计用 \(E[X] = \theta/2\)；MLE 用「样本最大值」。

    解答

    (a) 矩估计

    \[ E[X] = \frac{\theta}{2} \]

    令 \(\bar X = \theta/2\)：

    \[ \hat\theta_{\text{矩}} = 2\bar X \]

    性质：

    \[ E[2\bar X] = 2\cdot\frac{\theta}{2} = \theta \;\checkmark \]

    无偏

    (b) 最大似然估计

    似然函数：对 \(x_i\in[0,\theta]\) 全部成立，即 \(\theta\geq\max_i x_i\)：

    \[ L(\theta) = \prod_i\frac{1}{\theta}\mathbf{1}\{0\leq x_i\leq\theta\} = \frac{1}{\theta^n}\mathbf{1}\{\theta\geq x_{(n)}\} \]

    其中 \(x_{(n)} = \max_i x_i\)。

    观察：\(L(\theta) = \theta^{-n}\) 关于 \(\theta\) 单调递减 → 越小越好；但受约束 \(\theta\geq x_{(n)}\)。

    所以最优在边界：

    \[ \hat\theta_{\text{MLE}} = x_{(n)} = \max_i X_i \]

    注意：MLE 不是无偏的 ✗

    \[ E[X_{(n)}] = \frac{n}{n+1}\theta \neq \theta \]

    有偏（偏低） —— 因为样本最大值总小于真上界

    © 比较

    估计量 无偏 一致 方差
    \(2\bar X\) ✓ ✓ \(\propto\frac{\theta^2}{n}\)
    \(X_{(n)}\) ✗（偏低） ✓ \(\propto\frac{\theta^2}{n^2}\)

    这道题是「MLE 不一定无偏」的经典例子

    关键对比：

    方面 \(2\bar X\) \(X_{(n)}\)
    无偏性 ✓ ✗
    方差量级 \(O(1/n)\) \(O(1/n^2)\) ✓
    极限性质 收敛 收敛更快 ✓

    方差推导（\(X_{(n)}\) 的惊人效率）：

    \(X_{(n)}\) 的分布是 \(F_{X_{(n)}}(x) = (x/\theta)^n\)，可算出

    \[ \operatorname{Var}(X_{(n)}) = \frac{n\theta^2}{(n+1)^2(n+2)} \approx \frac{\theta^2}{n^2} \]

    对比 \(2\bar X\)：

    \[ \operatorname{Var}(2\bar X) = 4\cdot\frac{\theta^2}{12n} = \frac{\theta^2}{3n} \]

    比值（精确）：

    \[ \frac{\operatorname{Var}(2\bar X)}{\operatorname{Var}(X_{(n)})} = \frac{1/(3n)}{n/[(n+1)^2(n+2)]} = \frac{(n+1)^2(n+2)}{3n^2} \]

    当 \(n\) 较大时（把分子展开）：

    \[ \frac{(n+1)^2(n+2)}{3n^2} = \frac{n^3+4n^2+5n+2}{3n^2} = \frac{n}{3}+\frac43+O\!\left(\frac1n\right) \]

    所以渐近地 \(\approx n/3\)，但在小 \(n\) 时偏差明显：

    \(n\) 精确比值 \(n/3\) 差异
    \(2\) \(3.00\) \(0.67\) 很大
    \(10\) \(4.84\) \(3.33\) \(45\%\)
    \(100\) \(34.68\) \(33.33\) \(4\%\)
    \(1000\) \(334.67\) \(333.33\) \(0.4\%\)

    注意「渐近」的适用范围 —— 小样本时不能用 \(n/3\) 近似 ✗

    \(X_{(n)}\) 的方差随 \(n\) 减小得快得多（\(1/n^2\) vs \(1/n\)）

    所以尽管有偏，它的 MSE 更小（当 \(n\) 较大）：

    \[ \text{MSE}(X_{(n)}) = \underbrace{\frac{\theta^2}{(n+1)^2}}_{\text{偏差}^2}+\underbrace{\frac{n\theta^2}{(n+1)^2(n+2)}}_{\text{方差}} \approx \frac{2\theta^2}{n^2} \]

    远小于：

    \[ \text{MSE}(2\bar X) = \frac{\theta^2}{3n} \]

    结论：有偏但更精确 ✓ —— 这就是「偏差-方差权衡」的实例。

    工程含义：估计「上界/最大值」类参数时， 「样本最大値」通常比「矩估计」更准（虽然略偏低）。

    常见修正（无偏化）：

    \[ \hat\theta_{\text{无偏}} = \frac{n+1}{n}X_{(n)} \]

    这个估计量无偏，但方差稍大 —— 又一个权衡

    例题 2：验证无偏性与计算 MSE¶

    设 \(X_1,\dots,X_n\) 来自 \(N(\mu,\sigma^2)\)，两者都未知。 比较两个方差估计量：\(S^2 = \frac{1}{n-1}\sum(X_i-\bar X)^2\) 与 \(\hat\sigma^2 = \frac1n\sum(X_i-\bar X)^2\)。

    思路

    用「\(E[\sum(X_i-\bar X)^2] = (n-1)\sigma^2\)」这个已知结论。

    解答

    第一步：\(S^2\) 的无偏性

    已知（可由 \(\chi^2\) 分布推出）：

    \[ \sum_i(X_i-\bar X)^2 \sim \sigma^2\chi^2_{n-1} \implies E\left[\sum_i(X_i-\bar X)^2\right] = (n-1)\sigma^2 \]

    所以：

    \[ E[S^2] = \frac{(n-1)\sigma^2}{n-1} = \sigma^2 \;\checkmark \]

    \(S^2\) 无偏

    第二步：\(\hat\sigma^2\) 的偏差

    \[ E[\hat\sigma^2] = \frac{(n-1)\sigma^2}{n} = \frac{n-1}{n}\sigma^2 \]

    偏差：

    \[ \operatorname{Bias} = \frac{n-1}{n}\sigma^2-\sigma^2 = -\frac{\sigma^2}{n} \]

    偏低 ✗ （偏差随 \(n\) 减小）

    第三步：比较 MSE

    \(S^2\) 的方差（用 \(\chi^2\) 分布的方差 \(2(n-1)\)）：

    \[ \operatorname{Var}(S^2) = \frac{\sigma^4}{(n-1)^2}\cdot2(n-1) = \frac{2\sigma^4}{n-1} \]
    \[ \text{MSE}(S^2) = \frac{2\sigma^4}{n-1} \]

    \(\hat\sigma^2\) 的 MSE：

    \[ \operatorname{Var}(\hat\sigma^2) = 2\sigma^4\frac{n-1}{n^2} \]
    \[ \text{MSE}(\hat\sigma^2) = \frac{2\sigma^4(n-1)}{n^2}+\frac{\sigma^4}{n^2} = \frac{\sigma^4(2n-1)}{n^2} \]

    比较（以 \(\sigma^4\) 为单位）：

    \(n\) \(\text{MSE}(S^2) = \frac{2}{n-1}\) \(\text{MSE}(\hat\sigma^2) = \frac{2n-1}{n^2}\) 谁更小
    \(2\) \(2.000\) \(0.750\) \(\hat\sigma^2\) ✓
    \(5\) \(0.500\) \(0.360\) \(\hat\sigma^2\) ✓
    \(10\) \(0.222\) \(0.190\) \(\hat\sigma^2\) ✓
    \(20\) \(0.105\) \(0.0975\) \(\hat\sigma^2\) ✓
    \(100\) \(0.0202\) \(0.0199\) \(\hat\sigma^2\) ✓

    这个结果很反直觉：有偏的估计量 MSE 更小！

    结论：\(\hat\sigma^2\)（除以 \(n\)）的均方误差始终小于 \(S^2\)（除以 \(n-1\)） ✓

    为什么：

    估计量 偏差² 方差 总 MSE
    \(\hat\sigma^2\) \(\frac{\sigma^4}{n^2}\)（小） \(\frac{2\sigma^4}{n}\cdot\frac{n-1}{n}\)（略小） 略小 ✓
    \(S^2\) \(0\) \(\frac{2\sigma^4}{n-1}\)（略大） 略大

    用 \(\hat\sigma^2\) 换来的偏差很小（\(O(1/n^2)\)）， 但方差的节省是 \(O(1/n^2)\) 量级 —— 净收益为正

    那为什么实践中还用 \(S^2\)？

    理由 说明
    无偏性便于理论分析 无偏估计量可直接叠加（如 ANOVA 分解）
    小样本时差异微小 \(n=2\) 时差别最大但也只有 \(2\) vs \(0.75\)
    约定俗成 教科书与软件的统一做法
    一致估计量 两者渐近等价

    注意「MSE 更小」不等于「更好」：

    使用场景 推荐
    需要无偏（如方差分解） \(S^2\)（除以 \(n-1\)） ✓
    纯预测/估计精度 任选（差别很小）
    需要最小 MSE \(\hat\sigma^2\) 或专门的收缩估计

    这与机器学习中的「正则化」是同一逻辑： 故意引入小偏差换取方差下降

    例题 3：Fisher 信息量与 Cramér-Rao 下界¶

    设 \(X_1,\dots,X_n\sim\text{Poisson}(\lambda)\)。 求 Fisher 信息量与 \(\lambda\) 的无偏估计的方差下界。

    思路

    先算单样本的对数似然二阶导，再代入 \(E[X] = \lambda\)。

    解答

    第一步：单样本的对数似然

    \[ \log f(x;\lambda) = x\log\lambda-\lambda-\log(x!) \]

    第二步：一阶与二阶导

    \[ \frac{\partial\log f}{\partial\lambda} = \frac{x}{\lambda}-1 \]
    \[ \frac{\partial^2\log f}{\partial\lambda^2} = -\frac{x}{\lambda^2} \]

    第三步：Fisher 信息

    \[ I(\lambda) = -E\left[\frac{\partial^2\log f}{\partial\lambda^2}\right] = \frac{E[X]}{\lambda^2} = \frac{\lambda}{\lambda^2} = \frac{1}{\lambda} \]

    结果：\(I(\lambda) = \dfrac{1}{\lambda}\)

    第四步：Cramér-Rao 下界（\(n\) 个样本）

    \[ \operatorname{Var}(\hat\lambda)\geq\frac{1}{nI(\lambda)} = \frac{\lambda}{n} \]

    结果：下界为 \(\dfrac{\lambda}{n}\)

    第五步：验证 \(\bar X\) 达到下界

    \[ \operatorname{Var}(\bar X) = \frac{\operatorname{Var}(X)}{n} = \frac{\lambda}{n} \;\checkmark \]

    恰好取到下界 → \(\bar X\) 是有效估计量

    Fisher 信息随参数变化的「非等方差性」（实用要点）

    注意 \(I(\lambda) = 1/\lambda\)：信息量依赖 \(\lambda\) 本身。

    \(\lambda\) \(I(\lambda)\) 下界 \(\lambda/n\)
    \(0.1\) \(10\) \(0.1/n\)
    \(1\) \(1\) \(1/n\)
    \(100\) \(0.01\) \(100/n\)

    含义：\(\lambda\) 大时信息量小（因为泊松分布的方差 \(\propto\lambda\)， 相对波动小但绝对波动大）。

    这与「方差与均值相等」的泊松特性一致

    工程含义（敏感度的相对性）：

    任务 说明
    估计小计数率（如罕见事件） 每次观测信息量大，少量数据即可
    估计大计数率 需要更多数据达到同样绝对精度

    但要注意「相对精度」：

    \[ \frac{\sqrt{\operatorname{Var}(\bar X)}}{\lambda} = \frac{\sqrt{\lambda/n}}{\lambda} = \frac{1}{\sqrt{n\lambda}} \]

    相对误差反而随 \(\lambda\) 增大而减小

    所以「绝对精度」与「相对精度」给出的结论相反 —— 实际评价时要说清用哪个指标。

    这就是「参数化方式影响信息量」的例子：

    若改参数化为 \(\eta = \sqrt{\lambda}\)，则 \(I(\eta)\) 会不同 （因为 Fisher 信息在参数变换下按雅可比变化， 这与「KL 散度在变换下不变但 Fisher 信息会变」是相关的性质。）

    例题 4：充分统计量的判定¶

    设 \(X_1,\dots,X_n\sim B(1,p)\)（伯努利）。 证明 \(T = \sum_i X_i\) 是 \(p\) 的充分统计量。

    思路

    用因子分解定理，把联合密度分成「依赖 \(T\)」和「不依赖 \(p\)」两部分。

    解答

    第一步：写出联合概率

    对观测 \(\boldsymbol{x} = (x_1,\dots,x_n)\)（每个 \(x_i\in\{0,1\}\)）：

    \[ P(\boldsymbol{X} = \boldsymbol{x};p) = \prod_{i=1}^{n}p^{x_i}(1-p)^{1-x_i} \]

    第二步：整理指数

    令 \(t = \sum_i x_i\)：

    \[ = p^{\sum x_i}(1-p)^{n-\sum x_i} = p^t(1-p)^{n-t} \]

    第三步：识别因子分解

    \[ P(\boldsymbol{X}=\boldsymbol{x};p) = \underbrace{p^t(1-p)^{n-t}}_{g(t;p)}\cdot\underbrace{1}_{h(\boldsymbol{x})} \]
    因子 依赖
    \(g(t;p)\) \(t\)（通过 \(\sum x_i\)）与 \(p\) ✓
    \(h(\boldsymbol{x}) = 1\) 不依赖 \(p\) ✓

    符合因子分解定理 → \(T = \sum_i X_i\) 是充分统计量

    充分性的直觉：顺序不含信息

    \(T\) 只用了「成功次数」，扔掉了「顺序」 —— 而这是无损的

    验证「顺序确实不含信息」：

    两个不同的观测序列，若成功次数相同：

    \[ (1,0,1) \quad\text{与}\quad (0,1,1) \]

    它们的似然完全相同：

    \[ p^2(1-p) \quad\text{（都等于）} \]

    所以对 \(p\) 的推断完全一样 —— 顺序无关

    这就是充分性的实用含义：可以把 \(n\) 个 0/1 压缩成 1 个数。

    工程含义（数据压缩与计算）：

    场景 好处
    存储 只存成功次数与总次数 ✓
    计算 无需遍历全部样本
    在线更新 只需维护 \(T\) 的累加 ✓

    注意「充分」是相对于「哪个参数」而言的：

    参数 充分统计量
    \(p\) \(T = \sum X_i\) ✓
    若要检验「数据是否独立」 \(T\) 不充分 ✗

    即：\(T\) 保留了关于 \(p\) 的全部信息， 但不保留关于「模型假设是否成立」的信息

    这提醒我们：充分性是「对特定参数」的性质 —— 做模型诊断时不能只依赖 \(T\)。

    五、用在哪些课程里¶

    模式识别 · 参数估计与分类器训练¶

    • MLE / MAP 是所有参数化分类器的训练基础
    • 无偏性与方差 决定分类器输出的校准质量
    • Fisher 信息 用于特征选择（选信息量大的特征）
    • 偏差-方差权衡 直接对应过拟合与欠拟合

    智能传感与信息处理 · 传感器标定与融合¶

    • 点估计 是标定问题的核心（从含噪数据估参数）
    • Cramér-Rao 下界 给出「标定精度」的理论极限
    • 充分统计量 支持边缘计算（只上传统计量而非原始数据）
    • Fisher 信息 用于传感器布局优化（选最敏感的配置）

    无人系统自主决策与优化 · 参数辨识¶

    • 系统辨识就是从输入输出数据估动态模型参数
    • 一致估计保证「数据多了模型会变准」
    • MSE 准则用于模型阶数选择
    • 信息矩阵（Fisher 信息的矩阵形式）决定可辨识性

    六、自测¶

    Q1 设 \(X_1,\dots,X_n\sim\text{Exp}(\lambda)\)（密度 \(\lambda e^{-\lambda x}\)，\(x>0\)）。 求 \(\lambda\) 的矩估计与 MLE。

    提示

    \(E[X] = 1/\lambda\)；MLE 只需对 \(-\log\lambda+\lambda\bar x\) 求极值。

    解答

    矩估计

    由 \(E[X] = 1/\lambda\)，令 \(\bar X = 1/\lambda\)：

    \[ \hat\lambda_{\text{矩}} = \frac{1}{\bar X} \]

    MLE

    对数似然：

    \[ \ell(\lambda) = \sum_i(\log\lambda-\lambda x_i) = n\log\lambda-\lambda n\bar x \]

    求导令零：

    \[ \frac{n}{\lambda}-n\bar x = 0 \implies \hat\lambda_{\text{MLE}} = \frac{1}{\bar X} \]

    结果：两者相同

    \[ \hat\lambda = \frac{1}{\bar X} \]

    性质检查：

    性质 结论
    无偏？ ✗（\(E[1/\bar X]\neq1/E[\bar X]\)，由 Jensen 不等式 \(E[1/\bar X]>1/E[\bar X]=\lambda\)）
    一致？ ✓（\(\bar X\xrightarrow{P}1/\lambda\)，连续映射保收敛）
    有效？ ✓（指数族，MLE 渐近达到 CRB）

    注意「无偏性一般不能通过函数传递」：

    \[ E[g(\hat\theta)]\neq g(E[\hat\theta]) \quad\text{（除非 }g\text{ 仿射）} \]

    这是常见错误来源 ✗

    无偏修正（小样本修正，\(n>1\)）：

    \[ \hat\lambda_{\text{无偏}} = \frac{n-1}{n\bar X} = \frac{n-1}{\sum_i X_i} \]

    （因为 \(\sum X_i\sim\text{Gamma}(n,\lambda)\)，其倒数的期望可算得。）

    Q2 判断：MLE 一定无偏。

    提示

    回想上一页 \(U(0,\theta)\) 的例子。

    解答

    不对。MLE 一般有偏，只是「渐近无偏」。

    反例（上一页例 1）：

    \[ X_i\sim U(0,\theta) \implies \hat\theta_{\text{MLE}} = X_{(n)} \]
    \[ E[X_{(n)}] = \frac{n}{n+1}\theta \neq \theta \]

    偏低 ✗

    另一个反例（正态方差）：

    \[ \hat\sigma^2_{\text{MLE}} = \frac1n\sum(X_i-\bar X)^2 \implies E = \frac{n-1}{n}\sigma^2 \]

    偏低 ✗

    为什么 MLE 会有偏：

    原因 说明
    不变性 MLE 在参数变换下保持（但不保持无偏性）
    边界效应 参数有界时最优常在边界（如 \(U(0,\theta)\)）
    非线性 似然函数的最大点未必是「平均正确的点」

    MLE 真正的保证是渐近性质：

    性质 结论
    渐近无偏 \(E[\hat\theta_n]\to\theta\) ✓
    一致 \(\hat\theta_n\xrightarrow{P}\theta\) ✓
    渐近有效 方差 → Cramér-Rao 下界 ✓
    渐近正态 \(\sqrt n(\hat\theta_n-\theta)\xrightarrow{d}N(0,1/I(\theta))\) ✓

    工程含义：大样本时 MLE 无偏问题可以忽略； 小样本时需要修正（或直接用无偏估计量）。

    Q3 某正态总体 \(\sigma\) 已知为 2。为把 \(\mu\) 的估计标准差控制在 0.1 以内， 至少需要多少样本？

    提示

    \(\operatorname{Var}(\bar X) = \sigma^2/n\)，令其平方根 ≤ 0.1。

    解答

    设样本量 \(n\)：

    \[ \operatorname{std}(\bar X) = \frac{\sigma}{\sqrt n} = \frac{2}{\sqrt n} \]

    要求：

    \[ \frac{2}{\sqrt n}\leq0.1 \implies \sqrt n\geq20 \implies n\geq400 \]

    结果：至少 400 个样本

    验证：

    \[ \frac{2}{\sqrt{400}} = \frac{2}{20} = 0.1 \;\checkmark \]

    一般公式：

    \[ n\geq\left(\frac{\sigma}{\text{目标精度}}\right)^2 \]

    几个常用数值：

    目标 \(\sigma/\sqrt n\) 需要的 \(n\)（\(\sigma=2\)）
    \(1.0\) \(4\)
    \(0.5\) \(16\)
    \(0.2\) \(100\)
    \(0.1\) \(400\)
    \(0.01\) \(40000\)

    注意「精度提高 10 倍，样本量要增 100 倍」 ✗

    这就是「\(\sqrt n\) 律」的代价 —— 这在实验设计中是最重要的定量约束之一。

    与 Fisher 信息的联系：因为 CRB \(= 1/(nI)\)，精度 \(\propto 1/\sqrt n\)

    Q4 为什么说「充分统计量」支持边缘计算？

    提示

    想想「传输什么」能既不丢信息又最省带宽。

    解答

    因为充分统计量包含了关于目标参数的全部信息，可以只上传它。

    对比两种做法：

    做法 上传内容 带宽
    朴素 原始数据 \(x_1,\dots,x_n\) \(O(n)\) ✗
    充分统计量 \(T(\boldsymbol{x})\)（常是 1 个数） \(O(1)\) ✓

    举例（伯努利）：

    若要估计成功概率 \(p\)，\(T = \sum_i X_i\) 是充分的。

    上传 数据量
    全部比特 \(n\) 位
    成功次数 + 总数 \(O(\log n)\) 位 ✓

    \(n = 10^6\) 时：从 \(10^6\) 位降到约 20 位 —— 压缩比约 50000 倍

    这不是「有损压缩」 —— 因为对估计 \(p\) 而言没有信息损失

    但必须注意前提：

    前提 说明
    已知分布族 如「已知是伯努利」✓
    参数固定 假设 \(p\) 在采集期间不变
    只需估计该参数 若要检测「分布是否变了」，\(T\) 不充分 ✗

    工程应用：

    场景 充分统计量
    传感器网络 各节点上传「求和/计数」
    联邦学习的简单情形 上传梯度/充分量
    在线监控 只维护累加统计量

    危险提醒：若分布族假设错误，此做法会丢掉发现错误的机会 ✗ 所以实践中常同时上传一些诊断量（如极值、方差）。
