    区间估计与假设检验¶

    上一页的点估计给出一个数值。但它没回答一个关键问题：

    这个估计有多准？

    这一页给出两种回答方式，它们本质上是同一件事的两个视角：

    视角 问题 形式
    区间估计 「真值大概在什么范围？」 给出区间 \([\hat\theta_L,\hat\theta_U]\)
    假设检验 「这个说法能被数据推翻吗？」 接受/拒绝某个假设

    两者的对偶关系（核心结论）

    一个置信水平 \(1-\alpha\) 的置信区间， 恰好对应「所有不被水平 \(\alpha\) 的检验拒绝的参数值」 ✓

    \[ \theta_0\in\text{CI}_{1-\alpha} \iff \text{检验不拒绝 }H_0:\theta = \theta_0 \]

    所以两者是同一套数学的两种表述：

    语言 说法
    区间估计 「\(\theta\) 落在 \([a,b]\) 内（置信度 \(95\%\)）」
    假设检验 「\(\theta = 0\) 这个假设不能被拒绝」

    实践中按方便选一种表述 —— 但理解它们的等价性能避免很多混淆。

    一、置信区间¶

    基本概念¶

    置信水平 \(1-\alpha\) 的含义（这是最容易误解的地方）：

    重复抽样很多次，每次构造一个区间， 约 \(1-\alpha\) 比例的区间会包含真值 \(\theta\)。

    置信区间的常见误解（必须澄清）

    错误说法：「\(\theta\) 有 \(95\%\) 的概率落在 \([1.2, 3.4]\) 内」

    为什么错：\(\theta\) 是固定常数（不是随机变量）， 所以「它落在某区间内」的概率只能是 0 或 1 ✗

    正确说法：「区间 \([1.2,3.4]\) 是用一个「\(95\%\) 成功率的方法」构造出来的」 ✓

    主语 谁在变化
    区间是随机的（随样本变化） \(\theta\) 固定 ✓
    ~真值~不随机 ✗

    为什么这个区别重要：

    误解的后果 说明
    以为「有 95% 概率在区间内」 会把置信度当成后验概率 ✗
    想表达「后验概率」 应改用贝叶斯可信区间 ✓

    两者的区别：

    概念 定义 解释
    置信区间（频率派） \(\theta\) 固定、区间随机 长期覆盖率
    可信区间（贝叶斯） \(\theta\) 随机、区间固定 「\(\theta\) 有 95% 概率在此区间内」 ✓

    这也解释了「为什么贝叶斯方法有时更受欢迎」 —— 可信区间的表述符合直觉。

    正态均值区间的构造¶

    情形 1：\(\sigma\) 已知（用 Z 分布）

    \[ \bar X\pm z_{1-\alpha/2}\cdot\frac{\sigma}{\sqrt n} \]

    情形 2：\(\sigma\) 未知（用 t 分布）

    \[ \bar X\pm t_{1-\alpha/2,\,n-1}\cdot\frac{S}{\sqrt n} \]

    为什么用 \(t\) 分布：

    \[ \frac{\bar X-\mu}{S/\sqrt n}\sim t_{n-1} \]

    多了一个「用 \(S\) 代替 \(\sigma\)」的不确定性 → 尾部更厚 → \(t\) 分位数比 \(z\) 大 → 区间更宽 ✓ 更保守。

    常用临界值表（务必记住 z 的几个值）

    正态（Z）临界值：

    置信水平 \(\alpha\) \(z_{1-\alpha/2}\)
    \(90\%\) \(0.10\) \(1.645\)
    \(95\%\) \(0.05\) \(1.960\)
    \(99\%\) \(0.01\) \(2.576\)
    \(99.9\%\) \(0.001\) \(3.291\)

    记忆要点：「95% 用 1.96」 是最常用的 ✓ （这也印证了「约 2 倍标准差」的经验法则。）

    \(t\) 分布临界值（\(1-\alpha/2 = 0.975\)）：

    自由度 \(n-1\) \(t_{0.975}\) 与 \(z\) 的比值
    \(1\) \(12.706\) \(6.5\) 倍
    \(5\) \(2.571\) \(1.31\) 倍
    \(10\) \(2.228\) \(1.14\) 倍
    \(30\) \(2.042\) \(1.04\) 倍
    \(\infty\) \(1.960\) \(1.00\)

    规律：\(n\) 大时 \(t\to z\) —— 所以大样本时用哪个都行 ✓

    \(n\geq30\) 时两者差异 <5% —— 这就是「大样本用 Z 近似」的依据。

    区间宽度的影响因素¶

    \[ \text{宽度} = 2\times\text{临界值}\times\frac{\text{标准差}}{\sqrt n} \]
    因素 变化 宽度
    置信水平 \(1-\alpha\) ↑ 更保险 变宽 ✗
    样本量 \(n\) ↑ 数据更多 变窄 ✓
    总体方差 \(\sigma^2\) ↑ 数据更散 变宽 ✗

    「n 要多大」的定量公式（实验设计必备）

    要求区间半宽 \(\leq d\)，则

    \[ n\geq\left(\frac{z_{1-\alpha/2}\cdot\sigma}{d}\right)^2 \]

    代入常用数值（\(z = 1.96\)）：

    目标半宽（以 \(\sigma\) 为单位） 需要的 \(n\)
    \(1.0\sigma\) \(4\)
    \(0.5\sigma\) \(16\)
    \(0.2\sigma\) \(97\)
    \(0.1\sigma\) \(385\)
    \(0.01\sigma\) \(38416\)

    注意「精度提高 10 倍，样本量要增 100 倍」 ✗

    这个「\(\sqrt n\) 律」是实验设计的硬约束 —— 它解释了为什么「想要非常精确的估计」代价极高。

    工程含义（几类典型场景）：

    场景 目标 大致样本量
    粗略评估 半宽 \(0.3\sigma\) \(\approx44\)
    一般精度 半宽 \(0.1\sigma\) \(\approx385\)
    高精度 半宽 \(0.02\sigma\) \(\approx9600\)

    实践建议：先想清楚「多准算够」 —— 否则容易做大量无效采样 ✗

    二、假设检验¶

    基本框架¶

    两个假设：

    假设 记号 地位
    原假设 \(H_0\) 默认成立（要「保护」的）
    备择假设 \(H_1\) 要「证明」的

    检验逻辑（与反证法类比）：

    假设 \(H_0\) 成立，看观测数据是否「太不寻常」； 若太不寻常，则拒绝 \(H_0\)。

    两类错误：

    \(H_0\) 为真 \(H_0\) 为假
    不拒绝 \(H_0\) ✓ 正确 第二类错误（\(\beta\)）
    拒绝 \(H_0\) 第一类错误（\(\alpha\)） ✓ 正确

    两类错误的权衡（这是假设检验的核心张力）

    错误 名称 严重性
    第一类（\(\alpha\)） 弃真（假阳性） 通常更严重 ✗
    第二类（\(\beta\)） 取伪（假阴性） 取决于场景

    检验的标准做法：先固定 \(\alpha\)（如 0.05）， 然后在所有满足该 \(\alpha\) 的检验中最小化 \(\beta\) ✓

    为什么先固定 \(\alpha\)：

    原因 说明
    两类错误不能同时最小 减少 \(\alpha\) 必然增大 \(\beta\)（在 \(n\) 固定时）
    需要明确的判据 否则无法决断
    惯例 \(\alpha = 0.05\) 是长期形成的平衡点

    检验功效（power）：

    \[ \text{power} = 1-\beta \]

    含义：当 \(H_0\) 确实为假时，能正确检测出来的概率 ✓

    功效的三个影响因素：

    因素 变化 功效
    样本量 \(n\) ↑ 数据更多 ↑ ✓
    效应量（真实差异）↑ 差异更明显 ↑ ✓
    显著性水平 \(\alpha\) ↑ 判据更宽松 ↑（但牺牲第一类错误）✗
    噪声 \(\sigma\) ↑ 数据更散 ↓ ✗

    工程含义：「检验不显著」不等于「没有效应」 —— 可能是样本量不足导致功效太低 ✗

    这就是「为什么做实验前要算样本量」： 要保证功效足够（通常要求 \(80\%\) 以上），否则白做 ✓

    p 值¶

    定义：在 \(H_0\) 成立下，观测到「至少与当前数据一样极端」的概率。

    \[ p = P(\text{比观测更极端的数据}\mid H_0) \]

    判据：\(p<\alpha\) 则拒绝 \(H_0\)。

    p 值的常见误用（这一条必须记住）

    p 值不是：

    错误理解 为什么错
    「\(H_0\) 为真的概率」 p 值是在 \(H_0\) 下算的数据概率，方向反了 ✗
    「效应的大小」 p 小不代表效应大（\(n\) 大时小效应也能显著）✗
    「结果的可靠性」 它只反映「与 \(H_0\) 的一致性」

    正确理解：p 值衡量「数据与 \(H_0\) 的相容程度」 ✓

    具体对比（重要）：

    情形 p 值 效应量
    \(n = 10\)，差异 \(=1.0\) \(0.20\) 大但不显著
    \(n = 10^6\)，差异 \(=0.001\) \(0.001\) 极小但显著

    所以「统计显著」不等于「实际重要」 ✗

    工程实践建议：

    做法 理由
    同时报告效应量与置信区间 p 值信息不完整 ✓
    明确 \(\alpha\) 与样本量 便于判断功效
    避免「p 值钓鱼」 反复换假设直到显著 ✗

    「p 值钓鱼」（p-hacking）的危险：

    若做 20 次独立检验，即使全部 \(H_0\) 为真， 也约有 \(1-0.95^{20} \approx 64\%\) 的概率至少出现一个 \(p<0.05\) ✗

    这就是「多重比较问题」 —— 需要校正（如 Bonferroni）。

    常用检验¶

    检验 用途 统计量
    单样本 Z 检验 均值（\(\sigma\) 已知） \(z = \frac{\bar X-\mu_0}{\sigma/\sqrt n}\)
    单样本 t 检验 均值（\(\sigma\) 未知） \(t = \frac{\bar X-\mu_0}{S/\sqrt n}\)
    配对 t 检验 前后对比 对差值做单样本 t
    双样本 t 检验 两组均值比较 \(t = \frac{\bar X_1-\bar X_2}{S_p\sqrt{1/n_1+1/n_2}}\)
    \(\chi^2\) 检验 方差、拟合优度、独立性 \(\sum\frac{(O-E)^2}{E}\)
    F 检验 方差比、ANOVA \(S_1^2/S_2^2\)

    「什么时候用哪个」：

    问题 检验
    一个均值是否等于某值 单样本 t
    两组均值是否相等 双样本 t
    同一组前后是否变化 配对 t ✓
    方差是否等于某值 \(\chi^2\)
    两组方差是否相等 F
    多组均值是否全相等 ANOVA（F）

    三、与区间估计的对偶关系¶

    这是本页最重要的结构结论。

    对偶关系的具体形式

    陈述：对同一个 \(\alpha\)，

    \[ \theta_0\in\text{CI}_{1-\alpha} \iff \text{水平 }\alpha\text{ 的检验不拒绝 }H_0:\theta = \theta_0 \]

    推导（以均值检验为例）：

    置信区间（\(\sigma\) 已知）：

    \[ \bar X-z_{1-\alpha/2}\frac{\sigma}{\sqrt n} < \mu < \bar X+z_{1-\alpha/2}\frac{\sigma}{\sqrt n} \]

    检验的接受域：解 \(H_0:\mu = \mu_0\) 不被拒绝的条件

    \[ \left\lvert\frac{\bar X-\mu_0}{\sigma/\sqrt n}\right\rvert < z_{1-\alpha/2} \]

    两者是同一个不等式 ✓

    实用价值：

    场景 用哪个
    想知道「大概范围」 区间估计
    想知道「是否等于 0」 假设检验
    报告结果 区间更完整 ✓（含方向与大小）
    多重比较 检验（有成熟的校正方法）

    一个重要的推论：「区间包含 0」等价于「不显著」 ✓

    所以报告置信区间比只报告 p 值更有信息量：

    报告内容 信息
    \(p = 0.03\) 只知道「显著」
    \(95\%\) CI \(= [0.2,\ 1.8]\) 知道效应方向与大小范围 ✓

    这就是现代统计报告规范推荐「报区间」的原因。

    四、典型例题¶

    例题 1：构造置信区间¶

    某零件长度测量 16 次，得 \(\bar x = 12.05\) mm、\(s = 0.20\) mm。 设长度服从正态分布。求平均长度的 \(95\%\) 置信区间。

    思路

    \(\sigma\) 未知 → 用 \(t\) 分布；自由度 \(n-1 = 15\)。

    解答

    第一步：确定临界值

    自由度 \(df = 16-1 = 15\)，\(\alpha = 0.05\)：

    \[ t_{0.975,\,15} = 2.131 \]

    第二步：计算标准误

    \[ SE = \frac{s}{\sqrt n} = \frac{0.20}{\sqrt{16}} = \frac{0.20}{4} = 0.05 \]

    第三步：构造区间

    \[ \bar x\pm t_{0.975,\,15}\cdot SE = 12.05\pm2.131\times0.05 \]
    \[ = 12.05\pm0.10655 \]

    结果：

    \[ [11.943,\ 12.157]\ \text{mm} \]

    完整解读：

    表述 是否正确
    「\(\mu\) 有 95% 概率在 \([11.94,12.16]\) 内」 ✗（\(\mu\) 固定）
    「用此方法构造的区间有 95% 概率覆盖 \(\mu\)」 ✓

    进一步的问题：若要半宽 \(\leq0.05\) mm，需要多少样本？

    估算（用 \(s\) 作为 \(\sigma\) 的估计）：

    \[ n\geq\left(\frac{z_{0.975}\cdot s}{d}\right)^2 = \left(\frac{1.96\times0.20}{0.05}\right)^2 = 7.84^2 \approx 62 \]

    需要 \(n\geq62\) 个样本（\(7.84^2 = 61.47\) 向上取整；比现在的 16 个多近 4 倍）✓

    注意「需要重新估计临界值」： 实际计算时应用 \(t\)，而 \(t\) 依赖 \(n\) —— 所以通常先用 \(z\) 估算，得到 \(n\) 后再迭代一次 ✓

    标准误（SE）与标准差（SD）的区别（高频混淆点）

    量 公式 含义
    标准差（SD） \(s\) 单个观测的离散程度
    标准误（SE） \(s/\sqrt n\) 均值估计的精度

    关键差别：

    特性 SD SE
    随 \(n\) 变化 不随（描述数据本身） 随 \(n\) 减小 ✓
    \(n\to\infty\) 趋于 \(\sigma\) 趋于 0
    用途 描述数据分散度 推断均值的精度

    常见错误：在论文中「用 SD 冒充 SE」以显得更精确 ✗

    判读原则：

    想说明 用
    「个体差异多大」 SD
    「均值估得多准」 SE ✓
    「置信区间」 SE（乘临界值）

    本例题中：SD \(=0.20\)、SE \(=0.05\) —— 差 4 倍（\(=\sqrt{16}\)）✓

    例题 2：单样本 t 检验¶

    某工艺标称厚度为 5.00 mm。抽检 9 件，得 \(\bar x = 5.08\)、\(s = 0.09\)。 在 \(\alpha = 0.05\) 下检验厚度是否偏离标称值（双侧）。

    思路

    双侧检验，\(H_0:\mu = 5.00\)；算 \(t\) 统计量后与临界值比较。

    解答

    第一步：建立假设

    \[ H_0:\mu = 5.00 \quad\text{vs}\quad H_1:\mu\neq5.00 \]

    （双侧检验。）

    第二步：计算检验统计量

    \[ SE = \frac{0.09}{\sqrt9} = 0.03 \]
    \[ t = \frac{\bar x-5.00}{SE} = \frac{5.08-5.00}{0.03} = \frac{0.08}{0.03} = 2.667 \]

    第三步：确定临界值

    \(df = 8\)，双侧 \(\alpha = 0.05\)：

    \[ t_{0.975,\,8} = 2.306 \]

    第四步：比较

    \[ \lvert t\rvert = 2.667 > 2.306 \implies \text{拒绝 } H_0 \;\checkmark \]

    结论：在 \(\alpha = 0.05\) 下，厚度显著偏离标称值 ✓

    补充：p 值

    \(df = 8\) 时，\(P(\lvert t\rvert>2.667) \approx 0.029\)

    \[ p\approx0.029 < 0.05 \;\checkmark \]

    与置信区间的一致性验证：

    \(95\%\) CI：

    \[ 5.08\pm2.306\times0.03 = 5.08\pm0.069 = [5.011,\ 5.149] \]

    区间不包含 5.00 ✓ → 与「拒绝 \(H_0\)」一致 ✓

    （这正是对偶关系的直接体现。）

    这个例子的工程解读

    统计显著 ≠ 实际重要：

    视角 判断
    统计：\(p = 0.029 < 0.05\) 显著偏离 ✓
    工程：偏移 \(0.08\) mm，公差若为 \(\pm0.20\) mm 仍在公差内，可接受 ✓

    两者不矛盾 —— 它们回答不同的问题：

    问题 工具
    「能否确信存在系统性偏移？」 假设检验
    「这个偏移是否影响使用？」 工程公差判断 ✓

    实践建议：

    做法 理由
    报告 \(p\) 值 + 效应量（偏移量） 两者都说清
    结合工艺公差判断 才是工程决策依据
    记录测量系统误差 避免把仪器偏差当工艺偏移

    进一步分析：若偏移被确认，应查系统性原因：

    可能原因 检查方向
    仪器未校准 用标准件核验
    刀具磨损 观察随时间趋势
    温度漂移 记录环境温度
    材料批次差异 分批检验

    例题 3：检验功效与样本量¶

    承例题 2。若真实偏移为 \(0.08\) mm（即 \(\mu = 5.08\)）、\(\sigma = 0.09\)， 样本量 \(n = 9\) 时的检验功效是多少？要把功效提到 \(0.90\)，需要多少样本？

    思路

    功效 = \(P(\text{拒绝}H_0\mid H_1\text{为真})\)。用非中心 t 或正态近似。

    解答

    第一步：功效的定义

    \[ \text{power} = P(\lvert T\rvert>t_{\text{crit}}\mid \mu = 5.08) \]

    第二步：用正态近似计算（便于手算）

    临界值（用 \(z\)）：

    \[ z_{0.975} = 1.96 \]

    非中心参数（效应量）：

    \[ \delta = \frac{\mu-\mu_0}{\sigma/\sqrt n} = \frac{0.08}{0.09/3} = \frac{0.08}{0.03} = 2.667 \]

    功效（双侧）：

    \[ \text{power} = P(\lvert Z+\delta\rvert>1.96) = P(Z>1.96-\delta)+P(Z<-1.96-\delta) \]
    \[ = P(Z>-0.707)+P(Z<-4.627) \]
    \[ \approx 0.760+0.000 = 0.760 \]

    结果：功效约 \(76\%\)

    第三步：求达到 \(90\%\) 功效的样本量

    对双侧检验，忽略极小项，需要

    \[ \delta-z_{1-\alpha/2}\geq z_{1-\beta} \]
    \[ \delta\geq1.96+1.282 = 3.242 \]

    而 \(\delta = \frac{\lvert\Delta\rvert}{\sigma/\sqrt n} = \frac{\lvert\Delta\rvert\sqrt n}{\sigma}\)：

    \[ \frac{0.08\sqrt n}{0.09}\geq3.242 \implies \sqrt n\geq3.647 \implies n\geq13.3 \]

    结果：需要 \(n\geq14\)

    验证：\(n = 14\) 时

    \[ \delta = \frac{0.08\sqrt{14}}{0.09} = \frac{0.08\times3.742}{0.09} = 3.326 \]
    \[ \text{power} = P(Z>1.96-3.326) = P(Z>-1.366) = 0.914 \;\checkmark \]

    确实超过 \(90\%\) ✓

    样本量公式（记住这个通用形式）

    \[ n\geq\frac{(z_{1-\alpha/2}+z_{1-\beta})^2\sigma^2}{\Delta^2} \]

    注意「\(\alpha\) 与 \(\beta\) 都要进公式」 —— 这与「只考虑置信区间」时只用 \(z_{1-\alpha/2}\) 不同 ✓

    常用数值（\(\alpha = 0.05\)、功效 \(80\%\) / \(90\%\)）：

    功效 \(z_{1-\alpha/2}+z_{1-\beta}\) 平方
    \(80\%\) \(1.96+0.842 = 2.802\) \(7.85\)
    \(90\%\) \(1.96+1.282 = 3.242\) \(10.51\)
    \(95\%\) \(1.96+1.645 = 3.605\) \(13.00\)

    对比「只做区间估计」的样本量公式：

    目的 系数（\(\alpha=0.05\)）
    区间半宽 \(\leq\Delta\) \(1.96^2 = 3.84\)
    检验功效 \(80\%\) \(2.802^2 = 7.85\)
    检验功效 \(90\%\) \(3.242^2 = 10.51\)

    结论：为「检测出效应」所需的样本量约是「估计区间」的 2-3 倍 ✓

    工程含义：

    目的 样本规划
    想知道「大概多少」 用区间公式
    想知道「是否有差异」 用功效公式（要求更多样本） ✓

    这也是为什么「检验不显著」常常是样本不足 —— 很多人按区间公式算样本量，却想做检验，功效自然不够 ✗

    例题 4：配对检验与独立检验的区别¶

    某方法改进前后各测 8 个样本（同一批样品）：

    样品 1 2 3 4 5 6 7 8
    改进前 10.2 11.5 9.8 12.1 10.9 11.8 10.4 12.3
    改进后 10.0 11.2 9.6 11.8 10.6 11.6 10.2 12.0

    检验改进是否有效（\(\alpha = 0.05\)）。

    思路

    同一批样品 → 配对检验（对差值做单样本 t 检验）。

    解答

    第一步：判断用哪种检验

    情形 检验
    两组的样本一一对应（同一批样品） 配对 t 检验 ✓
    两组独立取样（不同样品） 独立双样本 t 检验

    本例题是同一批样品 → 配对检验 ✓

    为什么重要：配对能消除「样品间差异」这个干扰因素 —— 检验更敏感 ✓

    第二步：计算差值

    样品 前 后 差值 \(d\)
    1 \(10.2\) \(10.0\) \(0.2\)
    2 \(11.5\) \(11.2\) \(0.3\)
    3 \(9.8\) \(9.6\) \(0.2\)
    4 \(12.1\) \(11.8\) \(0.3\)
    5 \(10.9\) \(10.6\) \(0.3\)
    6 \(11.8\) \(11.6\) \(0.2\)
    7 \(10.4\) \(10.2\) \(0.2\)
    8 \(12.3\) \(12.0\) \(0.3\)

    第三步：算差值的均值与标准差

    \[ \bar d = \frac{0.2+0.3+0.2+0.3+0.3+0.2+0.2+0.3}{8} = \frac{2.0}{8} = 0.250 \]

    差值平方和：

    \[ \sum(d_i-\bar d)^2 = 4\times(0.2-0.25)^2+4\times(0.3-0.25)^2 \]
    \[ = 4\times0.0025+4\times0.0025 = 0.02 \]
    \[ s_d = \sqrt{\frac{0.02}{7}} = \sqrt{0.002857} \approx 0.05345 \]

    第四步：检验统计量

    \[ t = \frac{\bar d}{s_d/\sqrt n} = \frac{0.25}{0.05345/2.828} = \frac{0.25}{0.01890} \approx 13.23 \]

    第五步：临界值

    \(df = 7\)，\(t_{0.975,7} = 2.365\)

    \[ 13.23\gg2.365 \implies \text{拒绝 } H_0 \;\checkmark \]

    结论：改进显著有效（\(p\ll0.001\)）

    对比：若误用「独立双样本 t 检验」会怎样

    独立检验的公式：

    \[ t = \frac{\bar x_1-\bar x_2}{s_p\sqrt{\frac{1}{n_1}+\frac{1}{n_2}}} \]

    两组的标准差：

    改进前：\(\bar x_1 = 11.125\)，\(s_1\approx0.935\) 改进后：\(\bar x_2 = 10.875\)，\(s_2\approx0.900\)

    合并标准差：

    \[ s_p = \sqrt{\frac{(8-1)s_1^2+(8-1)s_2^2}{14}} \approx 0.918 \]

    统计量：

    \[ t = \frac{11.125-10.875}{0.918\times\sqrt{1/8+1/8}} = \frac{0.25}{0.918\times0.5} = \frac{0.25}{0.459} \approx 0.545 \]

    比较：

    检验 \(t\) 值 临界值 结论
    配对（\(df=7\)） \(13.23\) \(2.365\) 显著 ✓
    独立（\(df=14\)） \(0.545\) \(2.145\) 不显著 ✗

    结论完全相反！ 为什么：

    原因 说明
    样品间差异很大（10.2 到 12.3） 独立检验把这个变异算进误差 ✗
    改进效果一致（都是 \(0.2-0.3\)） 配对检验把样品差异消除了 ✓

    这就是「配对设计」的价值：

    \[ \text{配对} \implies \text{消除个体差异} \implies \text{检验更敏感} \]

    工程实践教训：

    情形 应选设计
    可配对（同一样品/同一受试者前后） 配对 ✓
    不可配对（不同批次） 独立
    能配对却用独立 浪费了信息（可能漏掉真实效应）✗

    这就是「实验设计」的重要性 —— 错误的检验方法可能导致完全相反的结论 ✓

    七、自测¶

    Q1 某测量 \(n = 25\)、\(\bar x = 50.4\)、\(s = 2.0\)。求 \(\mu\) 的 \(95\%\) 置信区间。

    提示

    \(\sigma\) 未知用 \(t\)；\(df = 24\)，\(t_{0.975,24} = 2.064\)。

    解答

    第一步：标准误

    \[ SE = \frac{s}{\sqrt n} = \frac{2.0}{\sqrt{25}} = \frac{2.0}{5} = 0.4 \]

    第二步：临界值

    \(df = 24\)，\(\alpha = 0.05\)（双侧）：

    \[ t_{0.975,\,24} = 2.064 \]

    第三步：区间

    \[ 50.4\pm2.064\times0.4 = 50.4\pm0.8256 \]

    结果：

    \[ [49.574,\ 51.226] \]

    对比 \(z\) 的近似：

    \[ 50.4\pm1.96\times0.4 = [49.616,\ 51.184] \]
    方法 区间宽度
    \(t\)（正确） \(1.651\)
    \(z\)（近似） \(1.568\)

    \(t\) 的区间更宽约 \(5.3\%\) —— 这是「用 \(s\) 代替 \(\sigma\)」的代价 ✓

    何时可以用 \(z\)：\(n\geq30\) 时差别小于 5% —— 本例题 \(n = 25\)，用 \(t\) 更稳妥 ✓

    解读提醒：不能说「\(\mu\) 有 \(95\%\) 概率落在该区间内」 —— \(\mu\) 是固定常数，正确说法是「用此方法构造的区间有 95% 概率覆盖 \(\mu\)」✓

    Q2 判断：\(p = 0.04\) 表示「\(H_0\) 为真的概率是 \(4\%\)」。

    提示

    回顾 p 值的定义方向。

    解答

    不对。方向反了。

    正确含义：在 \(H_0\) 成立的条件下，观测到「至少与当前数据一样极端」的概率是 \(4\%\) ✓

    符号化对比：

    说法 数学形式 是否正确
    「\(H_0\) 为真的概率」 \(P(H_0\mid\text{data})\) ✗ 错
    p 值 \(P(\text{更极端数据}\mid H_0)\) ✓ 对

    这两个概率可能相差极大 （贝叶斯视角下）

    具体说明：

    设某罕见病的先验患病率 \(P(H_0) = 0.001\)（\(H_0\) = 患病）。 即便检测在患病时阳性率 99%，且假阳性率 5%：

    \[ P(H_0\mid+) = \frac{0.99\times0.001}{0.99\times0.001+0.05\times0.999} \approx 0.019 \]

    约 \(1.9\%\)，而「\(p\) 值」是 \(5\%\)（假阳性率）—— 相差 2.6 倍 ✗

    （这与「概率论」模块「贝叶斯定理」一页的疾病检测例子完全一致。）

    工程含义：

    想知道 用什么
    「数据与 \(H_0\) 有多不相容」 p 值（频率派）
    「\(H_0\) 有多大可能」 后验概率（贝叶斯） ✓
    「效应的大小与范围」 置信区间

    实践建议：报告结果时同时给出效应量与区间 —— 单看 p 值容易误读 ✓

    Q3 某检验 \(\alpha = 0.05\)、功效 \(80\%\)。若真实效应确实存在， 大约多少次实验能检测出来？

    提示

    功效就是「有效应时检出的概率」。

    解答

    直接由功效定义：

    \[ \text{power} = 1-\beta = 0.80 \]

    含义：每次实验有 \(80\%\) 概率检出（检出 = 拒绝 \(H_0\)）。

    所以：

    量 值
    单次检出概率 \(0.80\)
    单次漏检概率 \(0.20\)

    「做 \(k\) 次至少检出一次」的概率：

    \[ P(\text{至少一次}) = 1-0.20^k \]

    具体数值：

    \(k\) 至少检出一次
    \(1\) \(0.80\)
    \(2\) \(0.96\)
    \(3\) \(0.992\)
    \(5\) \(0.99968\)

    结果：做 3 次几乎必然检出（99.2%）

    但要小心「重复实验」的统计陷阱

    若每次都检验并取「显著的那次」 —— 这会严重抬高假阳性 ✗

    原因：每次独立检验的假阳性率是 \(\alpha = 0.05\)， 做 \(k\) 次的至少一次假阳性率：

    \[ 1-(1-0.05)^k = 1-0.95^k \]
    \(k\) 假阳性率
    \(1\) \(5.0\%\)
    \(3\) \(14.3\%\)
    \(10\) \(40.1\%\)
    \(20\) \(64.2\%\) ✗

    所以「反复做直到显著」是无效的做法 —— 它把 \(\alpha = 0.05\) 实际变成了 \(0.64\) ✗

    正确处理方式：

    场景 做法
    确实要重复 \(k\) 次 预先做多重比较校正（Bonferroni：\(\alpha/k\)）✓
    想提高检出率 增加单次样本量（提高功效）✓
    已做多次后挑出显著的 结果不可用 ✗

    Bonferroni 校正示例（\(k = 10\)）：

    \[ \alpha_{\text{校正}} = \frac{0.05}{10} = 0.005 \]

    每个检验的判据收紧到 \(0.005\)，则总体假阳性率回到约 \(5\%\) ✓

    代价：判据变严 → 功效下降 —— 这就是「多重比较的代价」，需要在设计阶段就考虑 ✓

    Q4 为什么说「置信区间比只报 p 值更有信息量」？

    提示

    想想 p 值能告诉你什么、不能告诉你什么。

    解答

    因为置信区间同时包含「方向、大小、精度」三类信息，而 p 值只有「是否显著」。

    两类报告的对比：

    报告 能回答的问题
    \(p = 0.03\) 「有统计显著差异」
    \(95\%\) CI \(= [0.2,\ 1.8]\) 「效应为正、大约 \(0.2\)–\(1.8\)、精度如何」✓

    用一个例子说明 p 值的不足：

    三种情形都是 \(p = 0.03\)：

    情形 \(n\) 效应量 \(95\%\) CI
    A \(10\) 大 \([0.5,\ 5.0]\)（很宽）
    B \(1000\) 中 \([0.15,\ 0.45]\)
    C \(10^6\) 极小 \([0.0002,\ 0.0004]\)

    同样的 p 值，实际意义完全不同 ✗

    情形 实际解读
    A 效应可能很大，但精度差（需更多数据）
    B 效应中等且可信 ✓
    C 效应虽显著但可能毫无实际意义 ✗

    与对偶关系的一致性：

    \[ \text{区间包含 }\theta_0 \iff \text{不拒绝 } H_0:\theta = \theta_0 \]

    所以区间本身就包含了检验的全部结论 —— 而且多了「范围」信息 ✓

    现代报告规范的建议：

    应报告 原因
    效应量 + 置信区间 核心信息 ✓
    \(p\) 值 辅助（说明是否显著）
    样本量、检验方法、前提检验 可重复性
    多重比较校正（若适用） 避免假阳性

    一句话：「显著」是二元判断，而「多大、多准」才是决策依据 ✓
