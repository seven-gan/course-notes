    模型选择与泛化¶

    前面几页都在解决「给定模型，怎么估参数」。

    这一页解决一个更靠前的问题：

    模型本身该选哪个？ 复杂度怎么定？

    为什么这个问题绕不开：模型太简单学不到规律（欠拟合）， 太复杂会把噪声也学进去（过拟合）。 而「太简单」和「太复杂」之间没有免费的分界线 —— 必须用数据之外的原则来选。

    一、泛化误差与经验误差¶

    1.1 两个误差不是一回事¶

    名称 定义 能不能算出来
    经验误差（训练误差） 在训练集上的平均损失 能（直接用训练数据算）
    泛化误差（测试误差） 在总体上的期望损失 不能（总体未知）⚠

    这一页的全部困难都来自第二行： 我们真正关心的量算不出来，能算出来的量不是我们关心的

    1.2 训练误差的欺骗性¶

    关键事实：训练误差随模型复杂度单调下降。

    极端情形：一个足够复杂的模型可以把训练集背下来， 训练误差降到零 —— 但它对没见过的样本毫无用处。

    所以「训练误差小」不能作为选模型的依据 ⚠

    用图看这件事：下图把「偏差平方」与「方差」分开画出来， 两者方向相反，它们的和（总误差）在中间某个复杂度处最小。

    1.3 偏差-方差分解¶

    对平方损失，可以精确地分解：

    \[ \mathbb{E}\left[(\hat f(x) - f(x))^2\right] = \underbrace{\left(\mathbb{E}[\hat f(x)] - f(x)\right)^2}_{ \text{偏差}^2} + \underbrace{\operatorname{Var}\left(\hat f(x)\right)}_{ \text{方差}} + \underbrace{\sigma^2}_{\text{噪声}} \]

    三项的读法：

    项 含义 模型变复杂时
    偏差平方 模型平均偏离真值的程度 减小（更能拟合）
    方差 模型对不同训练集的敏感度 增大（更不稳定）
    噪声 数据本身的不可约误差 不变（与模型无关）

    两个立即有用的推论：

    • 第三项永远消不掉 —— 它给出误差的理论下界 ✓
    • 偏差与方差反向变化 → 存在一个最优复杂度

    「训练误差小」不等于「模型好」

    这是初学者最常犯的判断错误。

    具体表现：

    · 用训练误差选模型 → 必然选出最复杂的那个 · 看到「训练准确率 99.9%」就以为模型很好 · 加了更多特征/更多层，训练误差降了，就以为改进有效

    正确做法：任何模型比较都必须基于没参与训练的数据。 这就引出下一节的交叉验证。

    二、交叉验证：把数据切成两块¶

    2.1 留出法¶

    最简单：把数据分成训练集与验证集。

    问题：切一次的话，结果对怎么切很敏感 （数据少时尤其严重）

    2.2 K 折交叉验证¶

    做法：把数据分成 \(K\) 份，轮流留一份做验证，其余训练：

    最终误差是 \(K\) 次的平均：

    \[ \text{CV}_K = \frac{1}{K}\sum_{k=1}^{K}\text{Err}_k \]

    K 的常见取值与权衡：

    \(K\) 优点 缺点
    5 计算量适中，偏差-方差较平衡 —
    10 更稳，最常用 计算量是 5 折的两倍
    \(n\)（留一法） 几乎无偏 计算量最大，方差反而可能大 ⚠

    为什么留一法方差可能更大：\(n\) 个训练集彼此高度重叠， 所以 \(n\) 次结果不独立，平均不能按 \(1/n\) 的方式降方差 ⚠

    2.3 一个必须避免的错误¶

    特征选择 / 标准化 / 降维都必须放在每一折里面做 ⚠

    为什么：如果先在全量数据上选特征、再交叉验证， 那么验证折的信息已经泄露进训练过程了 —— 这会把验证误差低估，让你误以为模型很好。

    这个错误叫「信息泄露」（data leakage）：

    做法 是否泄露
    折内做标准化 正确 ✓
    全量数据先标准化再分折 泄露 ⚠
    折内做特征选择 正确 ✓
    全量数据先选特征再分折 泄露 ⚠

    判据一句话：任何用到"全体数据"的步骤，都必须包在折内 ✓

    三、信息准则：不用切数据的办法¶

    交叉验证要反复训练。另一条路是在训练误差上加一个惩罚项。

    3.1 AIC¶

    \[ \text{AIC} = 2k - 2\ln\hat L \]

    符号：\(k\) 是参数个数，\(\hat L\) 是最大化的似然值。

    要点：第一项惩罚复杂度，第二项奖励拟合好（似然大 → 该项小）

    3.2 BIC¶

    \[ \text{BIC} = k\ln n - 2\ln\hat L \]

    与 AIC 的唯一差别：参数个数的权重从 \(2\) 变成 \(\ln n\)。

    这带来一个重要后果：

    \(n\) \(\ln n\) 与 AIC 的 \(2\) 相比
    7 1.95 略小
    100 4.61 明显更大
    \(10^5\) 11.5 远大于 2

    所以样本量大时，BIC 的惩罚远比 AIC 重 → 选出的模型更简单。下图能看到两条准则的最优点位置不同：

    3.3 三个准则的适用场景¶

    准则 倾向 理论依据 适合
    AIC 选稍复杂的 估计预测误差 目的是预测
    BIC 选更简单的 估计真实模型（一致性） 目的是识别真模型
    交叉验证 中性 直接估泛化误差 通用，计算贵

    一句话选择建议：关心预测用 AIC，关心解释/变量筛选用 BIC， 算力充足时优先交叉验证

    AIC / BIC 有自己的失效条件

    ① 参数量 \(k\) 要能数清。 对神经网络、随机森林这类模型，\(k\) 不是显式给出的 —— 硬套信息准则会得到错误结论

    ② 要求 \(\hat L\) 是真正的全局最大似然。 若 EM 收敛到局部最优，\(\ln\hat L\) 偏小， 惩罚项的相对影响就被扭曲

    ③ BIC 的一致性假设「真模型在候选集里」。 若真模型不在候选集里，BIC 的一致性和它的"选简单模型"倾向 都可能误导

    这三条意味着：信息准则不能替代交叉验证， 它只是"算得便宜"的近似手段。

    四、其他选择策略¶

    4.1 正则化：把选择"藏"进优化¶

    不显式选复杂度，而是在损失里加一项惩罚：

    \[ \hat\theta = \arg\min_\theta \left[\text{损失}(\theta) + \lambda\,\Omega(\theta)\right] \]

    两种最常用的惩罚：

    惩罚 形式 效果
    L2 岭回归 \(\lambda\sum_j\theta_j^2\) 权重统一变小，但不为零
    L1 Lasso \(\lambda\sum_j\|\theta_j\|\) 部分权重恰好为零 → 自动选特征 ✓

    L1 为什么能产生零：在原点处它不可导 （有尖角），所以最优解容易正好落在尖点上

    \(\lambda\) 怎么定：它本身就是个超参数，还是要用交叉验证选 所以正则化不是"免费"的，只是把"选结构"换成了"选一个数"。

    4.2 早停¶

    在验证误差开始上升时停止训练。

    为什么有效：它隐式地限制了模型的有效复杂度 代价：需要一份验证集（不能用于训练）。

    4.3 集成：不做选择而是取平均¶

    思路：与其挑一个最好的，不如把多个模型平均。

    为什么能降误差：若各模型误差不相关， 平均后的方差按 \(1/M\) 降低

    \[ \operatorname{Var}\left(\frac{1}{M}\sum_{m=1}^{M}\hat f_m\right) = \frac{1}{M^2}\sum_m \operatorname{Var}(\hat f_m) \quad(\text{各模型独立时}) \]

    注意前提是"独立"：若各模型高度相关（误差同向）， 平均的收益就很小 这正是"随机"森林比"普通"装袋更有效的原因（见下）。

    随机森林的两层随机：

    1. 对样本自助抽样（bootstrap）
    2. 对特征每次分裂只从随机子集里挑

    第二层是关键 —— 它让各棵树用的特征不同， 从而降低树之间的相关性，平均才真正有效

    五、例题¶

    例题 1：偏差-方差分解的数值验证¶

    题目：某模型在 100 组不同训练集上训练，得到的预测在 \(x_0\) 处的 均值是 \(4.2\)，标准差是 \(0.8\)；真实值是 \(5.0\)，数据噪声标准差 \(0.5\)。 求该点期望误差的偏差-方差分解。

    思路

    直接代入三项分解式。

    解答

    第一步：偏差平方。

    \[ (\mathbb{E}[\hat f] - f)^2 = (4.2 - 5.0)^2 = 0.64 \]

    第二步：方差。

    \[ \operatorname{Var} = 0.8^2 = 0.64 \]

    第三步：噪声。

    \[ \sigma^2 = 0.5^2 = 0.25 \]

    第四步：求和。

    \[ 0.64 + 0.64 + 0.25 = 1.53 \]

    答案：期望误差约 \(1.53\)，其中偏差占 \(0.64\)、方差占 \(0.64\)、 噪声占 \(0.25\)

    偏差和方差正好相等， 说明这个模型处在"偏差-方差平衡点"。 若想再降误差，两边都要动 —— 而噪声那 \(0.25\) 是动不了的

    例题 2：K 折交叉验证的误差估计¶

    题目：5 折交叉验证得到的 5 个误差分别是 \(0.21, 0.18, 0.25, 0.19, 0.22\)。给出误差估计与其标准误。

    思路

    平均值给出误差估计；标准误用样本标准差除以 \(\sqrt K\)。

    解答

    第一步：算平均。

    \[ \bar e = \frac{0.21+0.18+0.25+0.19+0.22}{5} = 0.210 \]

    第二步：算样本标准差。

    偏离量：\(0.000, -0.030, 0.040, -0.020, 0.010\)。

    \[ s^2 = \frac{0+9\times10^{-4}+16\times10^{-4}+4\times10^{-4}+1\times10^{-4}}{4} = \frac{30\times10^{-4}}{4} = 7.5\times10^{-4} \]
    \[ s \approx 0.0274 \]

    第三步：算标准误。

    \[ \text{SE} = \frac{s}{\sqrt{5}} \approx \frac{0.0274}{2.236} \approx 0.0123 \]

    答案：误差估计 \(0.210\)，标准误约 \(0.012\)

    必须报标准误。 \(0.210 \pm 0.012\) 与 \(0.210 \pm 0.10\) 的含义完全不同 —— 后者说明折间差异大（数据少或分布不均）， 这时比较两个模型需要更谨慎

    例题 3：AIC 与 BIC 选出的模型不同¶

    题目：\(n=1000\) 个样本，两个模型的最大化对数似然与参数个数如下。 分别用 AIC 与 BIC 选择。

    模型 \(\ln\hat L\) \(k\)
    甲 \(-500\) \(5\)
    乙 \(-480\) \(12\)
    思路

    分别代入两个准则，取值小者胜（注意这是准则值， 不是似然值 —— 曲解方向是常见错误）。

    解答

    第一步：AIC。

    \[ \text{AIC}_\text{甲} = 2\times5 - 2\times(-500) = 10 + 1000 = 1010 \]
    \[ \text{AIC}_\text{乙} = 2\times12 - 2\times(-480) = 24 + 960 = 984 \]

    AIC 选 乙（984 更小）

    第二步：BIC。 这里 \(\ln 1000 \approx 6.908\)：

    \[ \text{BIC}_\text{甲} = 5\times6.908 + 1000 = 34.5 + 1000 = 1034.5 \]
    \[ \text{BIC}_\text{乙} = 12\times6.908 + 960 = 82.9 + 960 = 1042.9 \]

    BIC 选 甲（1034.5 更小）

    答案：AIC 选乙，BIC 选甲 —— 两个准则结论相反。

    这个例子恰好展示了两种倾向的差别。

    乙的似然更好（多 20），但多用了 7 个参数：

    · AIC 认为这 20 的收益值得（惩罚只有 \(2\times7=14\)） · BIC 认为不值得（惩罚有 \(6.908\times7\approx48\)）

    报告结果时应该同时给出两个准则，而不是只报一个。

    例题 4：识别信息泄露¶

    题目：某人这样做了流程： ① 用全部 1000 个样本标准化特征； ② 用全部样本做单变量筛选，留下前 20 个特征； ③ 做 10 折交叉验证评估模型。 报告说"交叉验证准确率 96%"。 这个数字可信吗？错在哪？

    思路

    逐步检查哪一步用了"全体数据"，且这个信息是否会被验证折"看到"。

    解答

    第一步：找出泄露的步骤。

    ① 与 ② 都用了全部数据：

    步骤 用全体数据？ 泄露？
    ① 标准化 是（全体均值方差） 是 ⚠
    ② 特征筛选 是（全体相关性） 是 ⚠
    ③ 交叉验证 — 受影响

    第二步：泄露的机制。

    第 ② 步选特征时，每一折的验证样本都参与了"哪些特征重要"的决定 —— 于是这些特征天然偏向于在验证折上也表现好。

    第 ① 步的泄露较轻（只用了均值方差两个数）， 但在小样本时也不可忽视。

    第三步：结论。

    96% 这个数字是乐观偏高的，不可信 正确做法是把 ①② 放进每一折内部重新执行。

    答案：不可信；泄露在步骤 ①②，因为都用了全体数据。

    判据就一句话 —— 任何用到"全体数据"的步骤，都必须包在折内 ✓

    这个错误在特征筛选 + 交叉验证的组合里极其常见， 而且会让结果看起来好得多，所以特别危险。
