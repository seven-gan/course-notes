    回归分析¶

    统计的前两页讲「估计一个参数」。这一页讲一个更实用的问题：

    给定若干自变量，怎样预测一个因变量？

    这就是回归。它是工程数据分析中使用频率最高的工具。

    一句话抓住回归的全部内容

    回归 = 最小二乘 + 一系列诊断。

    环节 内容
    估计 最小二乘（OLS）有闭式解
    推断 系数的置信区间与显著性检验
    评估 \(R^2\)、残差分析
    诊断 线性性、同方差、独立性、正态性、多重共线性
    选择 变量选择与正则化

    只做第一步就报告结果，是实践中最大的错误来源 ✗ —— 因为「\(R^2\) 很高」不代表模型正确。

    一、一元线性回归¶

    1.1 模型¶

    \[ y_i = \beta_0+\beta_1x_i+\varepsilon_i, \qquad \varepsilon_i\sim N(0,\sigma^2)\ \text{i.i.d.} \]

    两个部分：

    部分 含义
    \(\beta_0+\beta_1x_i\) 系统性（可解释、要估计）
    \(\varepsilon_i\) 随机误差（不可解释）

    1.2 最小二乘估计¶

    目标：最小化残差平方和

    \[ \text{RSS} = \sum_i(y_i-\hat\beta_0-\hat\beta_1x_i)^2 \]

    对 \(\beta_0\)、\(\beta_1\) 求偏导令零（回顾「矩阵微积分」一页的方法）：

    \[ \frac{\partial\text{RSS}}{\partial\beta_0} = -2\sum_i(y_i-\beta_0-\beta_1x_i) = 0 \]
    \[ \frac{\partial\text{RSS}}{\partial\beta_1} = -2\sum_ix_i(y_i-\beta_0-\beta_1x_i) = 0 \]

    解得：

    \[ \boxed{\ \hat\beta_1 = \frac{\sum_i(x_i-\bar x)(y_i-\bar y)}{\sum_i(x_i-\bar x)^2},\qquad \hat\beta_0 = \bar y-\hat\beta_1\bar x\ } \]

    一个「必须经过样本均值点」的性质（很实用）

    由第一个正规方程：

    \[ \sum_i(y_i-\hat\beta_0-\hat\beta_1x_i) = 0 \implies \sum_i\hat\varepsilon_i = 0 \]

    残差之和为零

    由此可得：

    \[ \bar y = \hat\beta_0+\hat\beta_1\bar x \]

    即回归直线必过 \((\bar x,\bar y)\)

    这个性质有两个用途：

    用途 说明
    快速检查计算 算完必验证直线过均值点
    提高数值稳定性 可用中心化数据拟合（避免 \(\bar x\) 很大时的舍入误差）

    另一个必验证的性质：

    \[ \sum_i x_i\hat\varepsilon_i = 0 \]

    即残差与 \(x\) 正交

    这两个正交性是最小二乘的「几何本质」：

    向量 含义
    \(\hat{\boldsymbol{y}}\) \(y\) 在 \(x\) 张成空间上的投影
    \(\hat{\boldsymbol\varepsilon}\) 垂直于该空间的分量

    这正是「正交性与投影」一页的投影公式 —— 最小二乘就是投影。

    1.3 拟合优度：\(R^2\)¶

    定义：

    \[ R^2 = 1-\frac{\text{RSS}}{\text{TSS}},\qquad \text{TSS} = \sum_i(y_i-\bar y)^2 \]

    含义：模型解释了因变量总变异的比例。

    值 含义
    \(R^2 = 1\) 完美拟合
    \(R^2 = 0.8\) 解释了 \(80\%\) 的变异
    \(R^2 = 0\) 与「只用均值预测」一样差

    R2 的四个陷阱（务必要知道）

    陷阱 1：\(R^2\) 高 ≠ 模型正确

    例如用 \(x\) 和 \(x^2\) 拟合两个点的数据，\(R^2\) 必然 = 1 ✗ 但模型可能毫无意义（过拟合）。

    陷阱 2：\(R^2\) 只适用于「同一数据集上的比较」

    比较 是否可行
    同一数据上不同模型 ✓
    不同数据集上的 \(R^2\) ✗ 不可比

    陷阱 3：加变量必然使 \(R^2\) 不下降

    \[ R^2_{\text{加变量}}\geq R^2_{\text{原模型}} \quad\text{（恒成立）} \]

    所以用 \(R^2\) 选变量会永远偏向最复杂的模型 ✗

    修正：用调整 \(R^2\)（对变量个数惩罚）：

    \[ \bar R^2 = 1-(1-R^2)\frac{n-1}{n-p-1} \]

    陷阱 4：\(R^2\) 高但预测差

    为什么：\(R^2\) 是样本内指标。 若模型过拟合，样本内 \(R^2\) 高但样本外预测很差 ✗

    正确做法：用交叉验证评估预测能力

    \(R^2\) 与「相关系数」的关系（一元回归时）：

    \[ R^2 = r^2 \]

    即「相关系数的平方」✓ —— 这解释了这个名字。

    但多元回归时：\(R^2\) 是「多个相关性的综合」， 不再是任何单一相关系数的平方

    二、多元线性回归（矩阵形式）¶

    2.1 模型与解¶

    \[ \boldsymbol{y} = X\boldsymbol{\beta}+\boldsymbol{\varepsilon} \]

    其中 \(X\) 是 \(n\times p\) 的设计矩阵（第一列通常全为 1，对应截距）。

    最小二乘解（正规方程）：

    \[ \boxed{\ \hat{\boldsymbol{\beta}} = (X^\top X)^{-1}X^\top\boldsymbol{y}\ } \]

    这与「矩阵微积分」一页的结论完全一致

    这个公式在数值计算中的严重问题（必须知道）

    公式在数学上正确，但直接计算会有数值问题。

    问题 说明
    \(X^\top X\) 使条件数平方 \(\kappa(X^\top X) = \kappa(X)^2\) ✗
    求逆不稳定 病态时误差被放大
    数值精度损失 双精度可能不够

    回顾「梯度下降与收敛」一页的结论： 条件数直接决定数值方法的精度与步数

    实践中应改用：

    方法 说明
    QR 分解 解 \(R\boldsymbol{\beta} = Q^\top\boldsymbol{y}\)，条件数不平方 ✓
    SVD 最稳健，可处理秩亏
    Cholesky 快但需 \(X^\top X\) 正定
    迭代法（CG/LSQR） 大规模稀疏时用 ✓

    对比：

    方法 复杂度 稳定性
    正规方程 + 求逆 \(O(np^2+p^3)\) 差 ✗
    QR \(O(np^2)\) 好 ✓
    SVD \(O(np^2)\) 最好 ✓

    工程建议：除非 \(p\) 很小且条件数良好，否则用 QR 或 SVD （numpy.linalg.lstsq 内部用的是 SVD。）

    2.2 系数推断¶

    \(\hat{\boldsymbol{\beta}}\) 的分布：

    \[ \hat{\boldsymbol{\beta}}\sim N\left(\boldsymbol{\beta},\ \sigma^2(X^\top X)^{-1}\right) \]

    所以第 \(j\) 个系数的标准误：

    \[ SE(\hat\beta_j) = \hat\sigma\sqrt{[(X^\top X)^{-1}]_{jj}} \]

    检验 \(H_0:\beta_j = 0\)：

    \[ t_j = \frac{\hat\beta_j}{SE(\hat\beta_j)}\sim t_{n-p} \]

    这与上一页的假设检验框架完全一致

    「系数不显著」的两种可能原因（要分清）

    原因 判断方法
    该变量确实无关 看系数大小与置信区间
    与其他变量高度相关（共线性） 看 VIF ✓

    共线性的后果：

    现象 说明
    系数标准误很大 \(SE\) 被放大 → 不显著 ✗
    系数符号反常 与单变量回归相反
    系数值剧烈变化 增删一个样本就大变

    诊断指标：方差膨胀因子（VIF）：

    \[ \text{VIF}_j = \frac{1}{1-R_j^2} \]

    其中 \(R_j^2\) 是把 \(x_j\) 对其余变量回归得到的 \(R^2\)。

    判据（经验）：

    VIF 判断
    \(<5\) 可接受 ✓
    \(5\)–\(10\) 需注意
    \(>10\) 严重共线性 ✗

    注意「VIF 的含义」：

    \[ \text{VIF} = 10 \implies SE\text{ 被放大 }\sqrt{10}\approx3.2\text{ 倍} \]

    处理方式：

    方法 说明
    删除冗余变量 最简单
    主成分回归 用正交组合
    岭回归 L2 正则，专门处理共线性 ✓
    收集更多数据 可降低相关性

    三、回归诊断（最容易被忽略、却最重要）¶

    核心原则：模型假设不成立时，所有推断都不可靠 ✗

    3.1 五个假设与对应的诊断¶

    假设 违反的后果 诊断方法
    线性 系数有偏、预测差 残差 vs 拟合值图（应有随机散布）
    同方差 标准误不准、检验失效 残差 vs 拟合值（喇叭形？）
    独立性 标准误严重低估 残差序列图、Durbin-Watson 检验
    正态性 小样本检验不准 QQ 图
    无严重共线性 系数不稳 VIF

    「残差图」是回归分析最重要的工具

    为什么：残差图直接暴露模型没抓住的结构

    各类异常残差图的含义：

    图形 问题 对策
    弯曲（U 形） 漏了非线性项 加 \(x^2\)、取对数
    喇叭形（发散） 异方差 加权最小二乘、变换 \(y\)
    周期性波动 残留的时间/空间结构 加时间变量、用时间序列模型
    单点远离 强影响点 检查数据、稳健回归
    随机散布 ✓ 无问题 ——

    工程含义：先画图，再报告数字

    异方差的一个实用修法：

    情形 变换
    \(y>0\)、方差 \(\propto y^2\) \(\log y\)
    计数数据、方差 \(\propto\) 均值 \(\sqrt{y}\)
    比例数据 logit 变换

    注意「变换改变了模型含义」：

    \[ \log y = \beta_0+\beta_1x \]

    含义是「\(y\) 相对变化」而非「绝对变化」：

    \[ x\text{ 增 }1 \implies y\text{ 乘 }e^{\beta_1} \]

    这与「对数线性化」在「指数拟合」中的应用是同一件事

    3.2 异常点的三种类型（要区分）¶

    类型 定义 判断指标
    离群点（outlier） \(y\) 方向偏离 标准化残差 \(>3\)
    高杠杆点（leverage） \(x\) 方向极端 杠杆值 \(h_{ii}>2p/n\)
    强影响点（influential） 删掉它会显著改变系数 Cook 距离 ✓

    「杠杆点」为什么危险（一个关键洞察）

    杠杆点可能把回归线「拉过去」 —— 即使它的残差很小 ✗

    原因：最小二乘最小化平方误差， 而杠杆点对直线的位置影响很大。

    经典例子：

    数据 拟合斜率
    大部分点集中在 \(x\in[0,10]\)，\(y\) 随机散布 \(\approx0\)
    加一个点 \((100, 5)\) 被拉成明显正斜率 ✗

    即使那个点的残差很小，它也会改变整条直线

    判据（杠杆值）：

    \[ h_{ii} = [X(X^\top X)^{-1}X^\top]_{ii} \]

    阈值：\(h_{ii}>2\bar h = 2p/n\) 需注意。

    Cook 距离（综合杠杆与残差）：

    \[ D_i = \frac{\hat\varepsilon_i^2}{p\hat\sigma^2}\cdot\frac{h_{ii}}{(1-h_{ii})^2} \]

    判据：\(D_i>1\) 时该点影响显著。

    工程实践建议：

    做法 理由
    先看图 数值判据可能漏掉
    报告时说明是否删除异常点 透明度 ✓
    不要盲目删点 可能是真实信息 ✗
    用稳健回归（Huber） 自动降权 ✓

    四、典型例题¶

    例题 1：手算一元回归¶

    给定数据：

    \(x\) 1 2 3 4 5
    \(y\) 2.1 3.9 6.2 7.8 10.1

    求最小二乘回归线、\(R^2\)，并验证「过均值点」。

    思路

    用中心化公式算 \(\hat\beta_1\)，再求截距。

    解答

    第一步：求均值

    \[ \bar x = \frac{1+2+3+4+5}{5} = 3 \]
    \[ \bar y = \frac{2.1+3.9+6.2+7.8+10.1}{5} = \frac{30.1}{5} = 6.02 \]

    第二步：算离差

    \(x_i\) \(y_i\) \(x_i-\bar x\) \(y_i-\bar y\) \((x_i-\bar x)^2\) \((x_i-\bar x)(y_i-\bar y)\)
    \(1\) \(2.1\) \(-2\) \(-3.92\) \(4\) \(7.84\)
    \(2\) \(3.9\) \(-1\) \(-2.12\) \(1\) \(2.12\)
    \(3\) \(6.2\) \(0\) \(0.18\) \(0\) \(0\)
    \(4\) \(7.8\) \(1\) \(1.78\) \(1\) \(1.78\)
    \(5\) \(10.1\) \(2\) \(4.08\) \(4\) \(8.16\)
    求和 \(0\) \(0\) \(10\) \(19.90\)

    第三步：斜率

    \[ \hat\beta_1 = \frac{19.90}{10} = 1.99 \]

    第四步：截距

    \[ \hat\beta_0 = \bar y-\hat\beta_1\bar x = 6.02-1.99\times3 = 6.02-5.97 = 0.05 \]

    结果：

    \[ \hat y = 0.05+1.99x \]

    第五步：验证「过均值点」

    \[ \hat y(\bar x = 3) = 0.05+1.99\times3 = 0.05+5.97 = 6.02 = \bar y \;\checkmark \]

    第六步：计算 \(R^2\)

    TSS（总平方和）：

    \[ \text{TSS} = 4^2+1^2+0^2+1^2+4^2 = 3.92^2+2.12^2+0.18^2+1.78^2+4.08^2 \]
    \[ = 15.3664+4.4944+0.0324+3.1684+16.6464 = 39.708 \]

    RSS（残差平方和）：

    \(x\) \(y\) \(\hat y\) \(\hat\varepsilon\) \(\hat\varepsilon^2\)
    \(1\) \(2.1\) \(2.04\) \(0.06\) \(0.0036\)
    \(2\) \(3.9\) \(4.03\) \(-0.13\) \(0.0169\)
    \(3\) \(6.2\) \(6.02\) \(0.18\) \(0.0324\)
    \(4\) \(7.8\) \(8.01\) \(-0.21\) \(0.0441\)
    \(5\) \(10.1\) \(10.00\) \(0.10\) \(0.0100\)
    和 \(0.00\) ✓ \(0.1070\)

    注意「残差之和为零」 ✓ 与理论一致。

    \[ R^2 = 1-\frac{0.1070}{39.708} = 1-0.002695 = 0.9973 \]

    结果：\(R^2\approx0.9973\)（极高）

    这道题的两个验证点

    验证点 1：残差之和为零

    \[ \sum_i\hat\varepsilon_i = 0.06-0.13+0.18-0.21+0.10 = 0.00 \;\checkmark \]

    这是最小二乘的必然性质（有截距时）

    若算出来不是零，说明计算有误 —— 这是最好的自检

    验证点 2：残差与 \(x\) 正交

    \[ \sum_ix_i\hat\varepsilon_i = 1(0.06)+2(-0.13)+3(0.18)+4(-0.21)+5(0.10) \]
    \[ = 0.06-0.26+0.54-0.84+0.50 = 0.00 \;\checkmark \]

    同样为零

    工程含义：这两个正交性是最小二乘的「指纹」 —— 任何实现出这两个结果，就说明算法正确

    但 \(R^2 = 0.997\) 不意味着「模型完美」：

    需要进一步检查 说明
    残差图 是否有结构
    样本量 \(n=5\) 太少，\(R^2\) 容易高
    外推风险 \(x\) 超出 \([1,5]\) 时不可靠

    特别是「\(n\) 小时 \(R^2\) 天然偏高」：

    一元回归的自由度修正：

    \[ \bar R^2 = 1-(1-0.9973)\frac{5-1}{5-2} = 1-0.0027\times\frac43 = 0.9964 \]

    调整后的值略低（但本例仍很高）

    例题 2：多元回归与共线性诊断¶

    某数据有 \(n = 20\)，三个自变量。回归得：

    变量 系数 标准误 \(t\) 值 VIF
    截距 \(2.5\) \(1.2\) \(2.08\) ——
    \(x_1\) \(0.80\) \(0.25\) \(3.20\) \(1.4\)
    \(x_2\) \(0.15\) \(0.42\) \(0.36\) \(12.5\)
    \(x_3\) \(0.05\) \(0.40\) \(0.13\) \(11.8\)

    判断哪些变量应保留。

    思路

    看 \(t\) 值（显著性）与 VIF（共线性）两方面。

    解答

    第一步：判断显著性

    自由度 \(df = n-p-1 = 20-3-1 = 16\)，\(t_{0.975,16} = 2.120\)。

    变量 \(\lvert t\rvert\) 与临界值比较 结论
    截距 \(2.08\) \(<2.120\) 不显著
    \(x_1\) \(3.20\) \(>2.120\) 显著 ✓
    \(x_2\) \(0.36\) \(\ll\) 不显著
    \(x_3\) \(0.13\) \(\ll\) 不显著

    第二步：判断共线性

    变量 VIF 判断
    \(x_1\) \(1.4\) 无问题 ✓
    \(x_2\) \(12.5\) 严重 ✗
    \(x_3\) \(11.8\) 严重 ✗

    第三步：综合分析

    \(x_2\) 与 \(x_3\) 的 VIF 都很高 → 说明它们彼此高度相关：

    \[ \text{VIF} = 12.5 \implies R_j^2 = 1-\frac{1}{12.5} = 1-0.08 = 0.92 \]

    即 \(x_2\) 有 \(92\%\) 的变异能被 \(x_3\) 解释 —— 两者几乎是同一个变量 ✗

    第四步：结论建议

    变量 建议 理由
    \(x_1\) 保留 ✓ 显著且 VIF 低
    \(x_2\) 删除（或与 \(x_3\) 二选一） 不显著 + 高 VIF
    \(x_3\) 删除 不显著 + 高 VIF

    处理步骤：

    步骤 操作
    1 删除其中一个（如 \(x_3\)），重新拟合
    2 再看剩下的 \(x_2\) 是否变显著
    3 若仍不显著 → 删除
    4 每步都检查 VIF

    为什么不能只看 t 值（关键教训）

    若只看 \(t\) 值：会删掉 \(x_2\)、\(x_3\) —— 但可能误删真实重要的变量 ✗

    为什么：共线性使标准误膨胀， 从而掩盖真实效应：

    \[ SE(\hat\beta_j) \propto \sqrt{\text{VIF}_j} \]

    数值对比（VIF 的影响）：

    VIF \(\sqrt{\text{VIF}}\) 标准误放大 原本显著的效应是否还显著
    \(1\) \(1.0\) \(1\) 倍 ✓ 显著
    \(4\) \(2.0\) \(2\) 倍 边界
    \(16\) \(4.0\) \(4\) 倍 可能变不显著 ✗

    所以「不显著」可能是假象 —— 真实效应被共线性「藏」起来了。

    判别方法：

    方法 说明
    逐个单独回归 若单独显著但联合不显著 → 共线性 ✓
    看 VIF 直接定量
    主成分分析 检查 \(x\) 的列空间结构

    处理共线性的三个方案：

    方案 优点 缺点
    删变量 简单 可能丢信息
    岭回归（L2） 稳定，不删变量 ✓ 系数有偏
    主成分回归 用正交组合 ✓ 解释性下降
    偏最小二乘（PLS） 兼顾预测与解释 需要调参

    工程建议：若目的是预测 → 用岭回归；若目的是解释 → 删冗余变量

    例题 3：异方差的影响与处理¶

    某实验数据 \(y\) 随 \(x\) 增大，且波动幅度也增大。 用普通最小二乘得 \(\hat\beta_1 = 2.0\)，\(SE = 0.3\)。 用加权最小二乘后 \(SE\) 变为 \(0.55\)。说明差异的意义。

    思路

    异方差使标准误被低估，从而「虚假显著」。

    解答

    第一步：认识异方差的机制

    普通最小二乘的假设：

    \[ \operatorname{Var}(\varepsilon_i) = \sigma^2 \quad\text{（对所有 }i\text{ 相同）} \]

    实际情形：方差随 \(x\) 增大

    \[ \operatorname{Var}(\varepsilon_i) = \sigma^2 w_i^2,\quad w_i\text{ 随 }i\text{ 变} \]

    第二步：后果（关键）

    普通最小二乘仍然无偏，但标准误的估计有偏（偏低） ✗

    \[ SE_{\text{OLS}} < SE_{\text{真实}} \]

    这导致：

    后果 说明
    \(t\) 值被高估 虚假显著 ✗
    置信区间过窄 覆盖不足
    检验功效虚高 假阳性增多

    第三步：定量对比

    方法 \(SE\) \(t = 2.0/SE\) 结论（\(df\) 足够大时）
    OLS（异方差下） \(0.30\) \(6.67\) 「高度显著」
    WLS（正确） \(0.55\) \(3.64\) 仍显著但弱得多

    比值：

    \[ \frac{SE_{\text{WLS}}}{SE_{\text{OLS}}} = \frac{0.55}{0.30} \approx 1.83 \]

    OLS 的标准误被低估了约 45% ✗

    第四步：结论

    \(\hat\beta_1 = 2.0\) 仍然显著（\(t = 3.64\)）， 但显著程度远不如 OLS 所报告的那样

    若换一组数据使 WLS 的 \(SE = 0.95\)：

    \[ t = \frac{2.0}{0.95} = 2.11 \]

    接近临界值 1.96 —— 此时结论就会从「显著」变为「边界」 ✗

    异方差的两个处理方案（对比）

    方案 1：加权最小二乘（WLS）

    思路：给方差小的观测更大权重：

    \[ \min\sum_i\frac{1}{w_i^2}(y_i-\beta_0-\beta_1x_i)^2 \]

    \(w_i\) 怎么定：通常需要建模方差与 \(x\) 的关系，如假设

    \[ \operatorname{Var}(\varepsilon_i)\propto x_i^2 \implies w_i = x_i \]

    优点：若 \(w_i\) 正确，达到有效（最小方差） 缺点：\(w_i\) 猜错可能更糟 ✗

    方案 2：稳健标准误（推荐）

    思路：不改变系数估计，只修正标准误：

    \[ \text{Var}_{\text{HC}}(\hat{\boldsymbol{\beta}}) = (X^\top X)^{-1}\left(\sum_i\hat\varepsilon_i^2\boldsymbol{x}_i\boldsymbol{x}_i^\top\right)(X^\top X)^{-1} \]

    （这是「异方差一致」或「三明治」估计量。）

    优点：

    优点 说明
    不需要建模方差结构 免猜测 ✓
    系数不变 便于比较
    大样本下可靠 理论保证 ✓

    缺点：小样本时略保守。

    两种方案的对比：

    方面 WLS 稳健标准误
    系数估计 改变（更有效） 不变
    需要知道 \(w_i\) 需要 ✗ 不需要 ✓
    小样本表现 依赖 \(w_i\) 正确性 略保守
    推荐场景 方差结构已知 一般情形 ✓

    工程建议：不确定方差结构时，用稳健标准误 （现代统计软件都有这个选项，如 R 的 sandwich 包、 Python 的 statsmodels 的 cov_type="HC3"。）

    同时要记住：先画残差图检验异方差 —— 不要盲目使用稳健方法（若假设成立，普通方法更有效）。

    例题 4：模型选择与过拟合¶

    某数据 \(n = 30\)，比较三个模型：

    模型 变量数 \(p\) \(R^2\) 调整 \(R^2\) 10 折交叉验证 \(\text{RMSE}\)
    A \(1\) \(0.72\) \(0.71\) \(2.15\)
    B \(3\) \(0.85\) \(0.83\) \(1.92\)
    C \(8\) \(0.91\) \(0.88\) \(2.08\)

    选哪个？

    思路

    比较「样本内指标」与「交叉验证」的差异。

    解答

    第一步：看样本内指标（\(R^2\)）

    \[ R^2_C = 0.91 > R^2_B = 0.85 > R^2_A = 0.72 \]

    按 \(R^2\) 会选 C —— 但这会永远选最复杂的模型 ✗

    第二步：看调整 \(R^2\)

    调整公式中加入了变量数的惩罚：

    \[ \bar R^2 = 1-(1-R^2)\frac{n-1}{n-p-1} \]

    验证（\(n = 30\)）：

    模型 \(p\) \((n-1)/(n-p-1)\) \(1-(1-R^2)\times\)该值
    A \(1\) \(29/28 = 1.0357\) \(1-0.28\times1.0357 = 0.710\) ✓
    B \(3\) \(29/26 = 1.1154\) \(1-0.15\times1.1154 = 0.833\) ✓
    C \(8\) \(29/21 = 1.3810\) \(1-0.09\times1.3810 = 0.876\)

    注意「调整 \(R^2\) 的惩罚强度有限」：

    \(p\) 从 \(1\) 增到 \(8\) 时，惩罚因子 \((n-1)/(n-p-1)\) 只从 \(1.036\) 升到 \(1.381\) —— 对 \(R^2\) 的削减约 \(3\) 个百分点（\(0.91\to0.876\)）， 不足以抵消「加变量」带来的 \(R^2\) 上升。

    所以调整 \(R^2\) 仍会选 C（\(0.84\) 最大）—— 这正是它的局限：它只能纠正「变量个数」的膨胀， 不能纠正「变量个数 + 过拟合」的复合效应 ✗

    第三步：看交叉验证（样本外）

    模型 CV RMSE
    A \(2.15\)
    B \(1.92\)（最小） ✓
    C \(2.08\)

    按样本外误差，B 最好

    第四步：分析差异的原因

    指标 选出的模型 依据
    \(R^2\) C 样本内（会过拟合）
    调整 \(R^2\) C 惩罚不足
    CV B 样本外 ✓

    为什么 C 差：

    原因 说明
    \(n = 30\)、\(p = 8\) 每个变量只有约 \(30/8\approx4\) 个样本
    自由度不足 \(n-p-1 = 21\)（尚可，但变量太多）
    过拟合 \(R^2\) 高但样本外变差 ✗

    第五步：结论

    选模型 B

    理由：

    方面 说明
    交叉验证最优 样本外预测最好
    变量数适中 可解释性好
    调整 \(R^2\) 接近 C 差异不大（\(0.83\) vs \(0.88\)）
    简洁性 奥卡姆剃刀 ✓

    模型选择的三个准则（各有适用场景）

    准则 公式/方法 适用
    AIC \(-2\log L+2k\) 预测（渐近）
    BIC \(-2\log L+k\log n\) 识别真模型（惩罚更重）
    交叉验证 样本外误差 最通用 ✓
    调整 \(R^2\) 见上 线性回归的快速判断

    AIC 与 BIC 的差别（重要）：

    准则 惩罚项 倾向
    AIC \(2k\) 选较大模型（预测优先）
    BIC \(k\log n\) 选较小模型（真相优先）✓

    \(n\) 大时 BIC 的惩罚远大于 AIC：

    \(n\) AIC 惩罚 BIC 惩罚 比值
    \(10\) \(2\) \(2.30\) \(1.15\)
    \(100\) \(2\) \(4.61\) \(2.30\)
    \(1000\) \(2\) \(6.91\) \(3.45\)

    这就是「BIC 更保守」的定量原因

    实践建议：

    目的 推荐
    预测（工程最关心） 交叉验证 ✓
    理论分析 AIC / BIC
    快速筛选 调整 \(R^2\)
    需要「稀疏解」 Lasso + CV ✓

    注意「交叉验证的代价」：需要训练多次（\(k\) 折就是 \(k\) 次）—— 计算量是单次拟合的 \(k\) 倍 ✗

    折数 \(k\) 的选择：

    \(k\) 特点
    \(5\) 快，偏差略大
    \(10\) 最常用（偏差-方差平衡） ✓
    \(n\)（留一法 LOO） 无偏但方差大、慢

    工程建议：默认用 10 折；数据极少时用 LOO

    五、自测¶

    Q1 给定 \(n = 4\) 的数据：

    \(x\) 1 2 4 5
    \(y\) 3 5 9 11

    求最小二乘斜率与截距，并验证残差之和为零。

    提示

    用中心化公式 \(\hat\beta_1 = \frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sum(x_i-\bar x)^2}\)。

    解答

    第一步：均值

    \[ \bar x = \frac{1+2+4+5}{4} = 3,\qquad \bar y = \frac{3+5+9+11}{4} = 7 \]

    第二步：离差表

    \(x_i\) \(y_i\) \(x_i-\bar x\) \(y_i-\bar y\) \((x_i-\bar x)^2\) 乘积
    \(1\) \(3\) \(-2\) \(-4\) \(4\) \(8\)
    \(2\) \(5\) \(-1\) \(-2\) \(1\) \(2\)
    \(4\) \(9\) \(1\) \(2\) \(1\) \(2\)
    \(5\) \(11\) \(2\) \(4\) \(4\) \(8\)
    和 \(0\) \(0\) \(10\) \(20\)

    第三步：系数

    \[ \hat\beta_1 = \frac{20}{10} = 2.0 \]
    \[ \hat\beta_0 = \bar y-\hat\beta_1\bar x = 7-2.0\times3 = 1.0 \]

    结果：\(\hat y = 1.0+2.0x\)

    第四步：验证残差

    \(x\) \(y\) \(\hat y\) \(\hat\varepsilon\)
    \(1\) \(3\) \(3.0\) \(0.00\)
    \(2\) \(5\) \(5.0\) \(0.00\)
    \(4\) \(9\) \(9.0\) \(0.00\)
    \(5\) \(11\) \(11.0\) \(0.00\)
    \[ \sum\hat\varepsilon_i = 0 \;\checkmark \]

    发现：所有残差恰好为零 → \(R^2 = 1\)

    为什么：本例数据恰好落在一条直线上 （\(y = 1+2x\)）—— 这是构造的完美线性数据

    工程提醒：真实的测量数据不可能有 \(R^2 = 1\) —— 若出现，应检查：

    可能原因 说明
    数据是构造的 如本例
    变量泄漏 自变量里含了因变量的信息 ✗
    数据重复计算 同一数据用了两次
    舍入掩盖 精度太低

    「\(R^2 = 1\)」在真实数据中通常意味着有 bug ✗

    Q2 判断：\(R^2\) 越大说明模型越好。

    提示

    回顾 \(R^2\) 的四个陷阱。

    解答

    不对。\(R^2\) 大不说明模型好。

    三个理由：

    理由 1：加变量必使 \(R^2\) 不降

    \[ R^2_{\text{加变量}}\geq R^2_{\text{原模型}} \]

    所以用 \(R^2\) 选模型会永远偏向最复杂的 ✗

    具体例子：10 个数据点、9 个自变量 → 必然 \(R^2 = 1\) （因为可以完美插值），但模型完全无意义 ✗

    理由 2：\(R^2\) 是样本内指标

    情形 样本内 \(R^2\) 样本外表现
    简单模型 \(0.75\) \(0.73\) ✓
    过拟合模型 \(0.95\) \(0.40\) ✗

    样本内高不代表预测好 —— 必须用交叉验证 ✓

    理由 3：\(R^2\) 与「因果关系」无关

    经典例子：用「冰淇淋销量」预测「溺水人数」→ \(R^2\) 很高， 但真正原因是第三个变量（气温）

    这就是「相关不等于因果」 —— 高 \(R^2\) 只说明相关性。

    正确的模型评估方式：

    方法 看什么
    交叉验证 样本外预测误差 ✓
    调整 \(R^2\) / AIC / BIC 带惩罚的拟合优度
    残差诊断 假设是否成立 ✓
    领域知识 系数符号与大小是否合理

    一句话：\(R^2\) 是「描述性」指标，不能作为「模型正确性」的证据 ✓

    Q3 某回归中 \(VIF = 16\)。解释其含义与后果。

    提示

    \(\text{VIF} = 1/(1-R_j^2)\)，且标准误被放大 \(\sqrt{\text{VIF}}\) 倍。

    解答

    含义拆解：

    \[ \text{VIF} = \frac{1}{1-R_j^2} = 16 \implies R_j^2 = 1-\frac{1}{16} = 0.9375 \]

    解读：该变量有 \(93.75\%\) 的变异能被其他自变量解释

    即：它几乎是其他变量的线性组合 —— 冗余 ✗

    后果 1：标准误被放大 4 倍

    \[ SE(\hat\beta_j)_{\text{共线下}} = \sqrt{16}\times SE(\hat\beta_j)_{\text{无共线}} \]

    数值示例：

    情形 真实 \(SE\) \(\lvert\hat\beta\rvert = 1\) 时的 \(t\) 结论
    无共线（VIF=1） \(0.25\) \(4.00\) 显著 ✓
    VIF=16 \(1.00\) \(1.00\) 不显著 ✗

    同一个真实效应，因共线性而「消失」 —— 这就是「虚假不显著」

    后果 2：系数符号可能反常

    当共线严重时，系数估计的方差极大 → 符号可能变成反的 ✗

    经典例子：用「身高」和「体重」同时预测健康指标 —— 可能出现「体重系数为负」的反常结果。

    后果 3：系数对数据极敏感

    操作 后果
    增删一个样本 系数可能大变
    换一个变量集 系数不稳定

    处理方案（按推荐顺序）：

    方案 优点 缺点
    删冗余变量 简单、可解释 ✓ 可能丢信息
    岭回归（L2） 稳定、不删变量 ✓ 系数有偏
    主成分回归 用正交组合 ✓ 解释性下降
    收集更多数据 根本解决 成本高

    为什么「岭回归能治共线性」：

    在 \(X^\top X\) 上加 \(\lambda I\) 使最小特征值变大：

    \[ \hat{\boldsymbol{\beta}}_{\text{岭}} = (X^\top X+\lambda I)^{-1}X^\top\boldsymbol{y} \]
    \[ \kappa(X^\top X+\lambda I) < \kappa(X^\top X) \;\checkmark \]

    条件数下降 → 估计稳定 （这与「梯度下降与收敛」一页「岭回归改善条件数」的结论一致。）

    Q4 残差图呈「喇叭形」（随拟合值增大而发散）。说明问题与对策。

    提示

    这是异方差；考虑变换或加权。

    解答

    问题：异方差（heteroscedasticity）

    违反的假设：

    \[ \operatorname{Var}(\varepsilon_i) = \sigma^2 \quad\text{（对所有 }i\text{ 相同）} \]

    实际：方差随 \(x\)（或 \(\hat y\)）递增。

    后果：

    后果 说明
    系数仍然无偏 ✓（这点重要：OLS 的系数不受影响）
    标准误被低估 ✗ 检验与区间都不可靠
    \(t\) 值虚高 假阳性增多
    置信区间过窄 覆盖不足

    注意「系数无偏但推断失效」这个区别：

    方面 是否受影响
    \(\hat\beta\) 的点估计 ✗ 不受影响
    \(SE(\hat\beta)\) ✓ 受影响（低估）
    显著性检验 ✓ 失效
    预测区间 ✓ 不准

    对策 1：变量变换（首选，若适用）

    情形 变换 原理
    \(y>0\)、\(\sigma\propto y\) \(\log y\) 相对误差变常数 ✓
    计数数据 \(\sqrt{y}\) 方差稳定化
    比例数据（\(0\lt y<1\)） \(\log\frac{y}{1-y}\) logit

    变换后要重新检查残差图

    注意变换的代价：模型含义改变

    \[ \log y = \beta_0+\beta_1x \implies x\text{ 增 }1 \implies y\text{ 乘 }e^{\beta_1} \]

    解释从「加性」变为「乘性」

    对策 2：加权最小二乘（WLS）

    给方差小的观测更大权重：

    \[ \min\sum_i\frac{(y_i-\hat y_i)^2}{w_i^2},\qquad w_i^2\propto\operatorname{Var}(\varepsilon_i) \]

    优点：若 \(w_i\) 正确则有效（最小方差） 缺点：需要猜方差结构 ✗

    对策 3：稳健标准误（最省事，推荐）

    不改系数，只修正标准误：

    \[ \text{Var}_{\text{HC}} = (X^\top X)^{-1}\Big(\sum_i\hat\varepsilon_i^2\boldsymbol{x}_i\boldsymbol{x}_i^\top\Big)(X^\top X)^{-1} \]

    优点：

    优点 说明
    不需知道方差结构 免猜测 ✓
    系数不变 便于比较
    大样本可靠 有理论保证 ✓

    软件中的名字：HC0–HC3（HC3 最适合小样本）。

    三种方案的选择：

    情形 推荐
    有理论依据的变换 变换 ✓
    方差结构已知 WLS
    不确定 稳健标准误 ✓

    最后提醒：先看残差图再选方案 —— 不要在不检验的情况下盲目用稳健方法（假设成立时普通方法更有效）。
