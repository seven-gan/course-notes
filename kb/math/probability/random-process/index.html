    随机过程¶

    前面讲的随机变量是「一个数」。这一页把它扩展到时间轴：

    随机过程是随时间演化的随机变量族。

    \[ \{X(t),\ t\in T\} \]

    它是本知识库信号与系统模块「随机信号基础」一页的概率论侧 ——两页配合看，才能完整理解「噪声分析」与「最优滤波」。

    为什么工程专业必须懂随机过程

    领域 应用
    信号处理 噪声建模、功率谱密度、最优滤波
    状态估计 马尔可夫过程、卡尔曼滤波
    可靠性 失效过程、泊松到达
    通信 排队模型、马尔可夫链
    强化学习 马尔可夫决策过程（MDP）

    注意最后一行：强化学习的状态转移就是随机过程， 这是两个看似无关的领域之间的一座桥。

    一、两种等价视角¶

    理解随机过程的关键是同时把握两个视角。

    固定什么 看到什么 名称
    固定时间 \(t\) 一个随机变量 \(X(t)\) 截面
    固定实验（样本） 一条确定性函数 \(x(t)\) 样本函数（实现）

    类比：把随机过程想成「一叠波形图」

    • 抽出一张 → 看到一条具体波形（样本函数）
    • 把所有图的同一时刻纵向切一刀 → 得到一批数（随机变量）

    工程现实：我们通常只能观测到一条样本函数（一次实验的完整记录）。 所以必须引入下面的假设。

    二、平稳性与遍历性¶

    2.1 严格平稳¶

    对所有 \(n\) 与所有时间平移 \(\tau\)，联合分布不变：

    \[ F(x_1,\dots,x_n; t_1,\dots,t_n) = F(x_1,\dots,x_n; t_1+\tau,\dots,t_n+\tau) \]

    含义：统计规律不随时间变化。

    2.2 宽平稳（WSS）¶

    实用中只要求前两阶矩满足（回到信号模块的定义）：

    \[ E[X(t)] = \mu \quad\text{（常数）} \]
    \[ R_{XX}(t_1,t_2) = E[X(t_1)X(t_2)] = R_{XX}(\tau), \quad \tau = t_1-t_2 \]

    关键收益：自相关从二元函数降为一元函数 \(R(\tau)\)。

    2.3 遍历性¶

    定义：若时间平均等于统计平均，则称过程是遍历的：

    \[ \lim_{T\to\infty}\frac{1}{2T}\int_{-T}^{T}x(t)\,\mathrm{d}t = E[X(t)] \]

    遍历性是「能用一条样本估计统计量」的前提

    问题：期望的定义需要对无穷多条样本平均， 但实际只有一条记录。

    解答：若过程遍历，则时间足够长的单一记录 就能代表整个样本集合。

    假设 作用
    宽平稳 统计量不随时间变
    遍历 长时间平均 = 集合平均

    这就是所有实际信号分析的理论基础： 我们测到的是一段信号，而不是无穷多条。

    注意：遍历性比平稳性更强（遍历 ⟹ 平稳，反之不然）。

    反例（平稳但不遍历）：\(X(t) = A\)（常数）， 其中 \(A\) 是随机变量（每次实验取不同值，但一次实验内不变）。

    • 平稳 ✓（分布不随时间变）
    • 不遍历 ✗（时间平均恒为 \(A\)，不等于 \(E[A]\)）

    工程含义：这类过程「太慢」，在有限观测时间内看不到变化， 无法用时间平均估计集合平均。

    三、自相关与功率谱¶

    自相关函数（已熟悉）：

    \[ R_{XX}(\tau) = E[X(t)X(t+\tau)] \]

    性质：

    性质 表达式
    偶函数（实过程） \(R(\tau) = R(-\tau)\)
    原点最大 \(\lvert R(\tau)\rvert \leq R(0)\)
    原点值 = 均方 \(R(0) = E[X^2]\)

    功率谱密度（维纳-辛钦定理）：

    \[ S_{XX}(\omega) = \int_{-\infty}^{\infty}R_{XX}(\tau)e^{-j\omega\tau}\,\mathrm{d}\tau \]

    总功率：

    \[ \frac{1}{2\pi}\int S_{XX}(\omega)\,\mathrm{d}\omega = R(0) \]

    自相关与功率谱的完整对接（三个层次）

    层次 内容
    定义 \(R(\tau)\) 的描述能力（相关性）
    变换 \(S(\omega)\) 是 \(R\) 的傅里叶变换
    物理 \(R(0)\) = 总功率 = 谱的积分

    三个实用推论：

    1. 相关时间 \(\tau_c\)：\(R(\tau)\) 衰减到 \(R(0)/e\) 所需时间

    \(\tau_c\) 谱宽度 信号特征
    小 宽 变化快（宽带）
    大 窄 变化慢（窄带）

    这就是「时宽-带宽不确定性」在随机信号上的体现—— 与傅里叶变换的不确定性原理是同一件事。

    2. 白噪声的极限情形：

    \[ R(\tau) = \sigma^2\delta(\tau) \iff S(\omega) = \sigma^2 \ (\text{常数}) \]

    相关时间为零（任何非零延迟都不相关）↔ 谱无限宽。

    3. 周期性成分检测：

    若 \(R(\tau)\) 含周期成分，则信号含周期性分量 （即使被噪声掩盖）。这是自相关检测弱周期信号的原理。

    四、马尔可夫过程与马尔可夫链¶

    这是随机过程中最重要的一类。

    4.1 马尔可夫性（无后效性）¶

    定义：给定当前状态，未来与过去条件独立：

    \[ P(X_{n+1}\mid X_n, X_{n-1},\dots,X_0) = P(X_{n+1}\mid X_n) \]

    含义：「未来只取决于现在」——过去的信息已被现在完全包含。

    马尔可夫性为什么是「强大的简化」

    一般过程的困难：\(P(X_{n+1}\mid X_n,\dots,X_0)\) 需要 \(n+1\) 阶联合分布 → 维数爆炸。

    马尔可夫性的威力：只需 \(P(X_{n+1}\mid X_n)\) → 一个转移概率矩阵就够了。

    模型 需要的历史长度
    一般随机过程 全部历史
    马尔可夫过程 只看当前

    马尔可夫链（离散状态 + 离散时间）：状态转移由矩阵 \(P\) 描述，

    \[ P_{ij} = P(X_{n+1} = j\mid X_n = i) \]

    性质：每行之和为 1（从状态 \(i\) 出发必然到某个状态）：

    \[ \sum_j P_{ij} = 1 \]

    工程应用：

    领域 应用
    语音识别 HMM（隐马尔可夫模型）
    导航定位 位置转移模型
    排队论 顾客到达与服务
    可靠性 设备状态转移
    强化学习 MDP 的状态转移

    4.2 平稳分布¶

    若存在分布 \(\boldsymbol{\pi}\) 满足

    \[ \boldsymbol{\pi} = \boldsymbol{\pi}P \]

    则称 \(\boldsymbol{\pi}\) 是平稳分布（长期状态下各状态的比例）。

    含义：达到平稳后，分布不再变化：

    \[ \boldsymbol{\pi}^\top P = \boldsymbol{\pi}^\top \]

    这是「特征值 1 对应的左特征向量」问题 ——回到线性代数模块的「特征值」一页（马尔可夫链那条课程联系）。

    平稳分布的求法与两个条件

    求法：解 \(\boldsymbol{\pi}^\top P = \boldsymbol{\pi}^\top\) 且 \(\sum_i\pi_i = 1\)。

    注意：\((\boldsymbol{\pi}^\top P = \boldsymbol{\pi}^\top)\) 等价于 \(P^\top\boldsymbol{\pi} = \boldsymbol{\pi}\)， 即 \(\boldsymbol{\pi}\) 是 \(P^\top\) 的特征值 1 的特征向量。

    存在性与唯一性的条件：

    条件 作用
    不可约（任意两状态可互达） 保证唯一性
    非周期 保证收敛
    有限状态 保证存在

    收敛速率由第二大特征值决定：

    \[ \text{收敛速率} \approx \lvert\lambda_2\rvert \]

    \(\lvert\lambda_2\rvert\) 越接近 0，收敛越快； 接近 1 则收敛很慢（混合时间长）。

    这解释了 MCMC（马尔可夫链蒙特卡洛）为什么要关注 \(\lambda_2\)—— 它决定采样效率。

    五、泊松过程¶

    这是「计数型」随机过程的基准模型。

    定义：计数过程 \(N(t)\) 满足

    条件 内容
    \(N(0) = 0\) 从零开始
    独立增量 不重叠区间的增量独立
    平稳增量 增量分布只依赖区间长度
    稀有事件 短时间 \(\Delta t\) 内发生一次的概率为 \(\lambda\Delta t + o(\Delta t)\)

    计数分布：

    \[ P(N(t) = k) = \frac{(\lambda t)^k e^{-\lambda t}}{k!} \]

    即 \(N(t)\sim\text{Poisson}(\lambda t)\)。

    到达间隔：独立同分布于 \(\text{Exp}(\lambda)\)（回到随机变量那一页）。

    泊松过程的三个等价刻画（考试常考）

    刻画 内容
    计数 \(N(t)\sim\text{Poisson}(\lambda t)\)
    间隔 间隔 i.i.d. \(\sim\text{Exp}(\lambda)\)
    到达时刻 第 \(n\) 个到达服从 \(\text{Gamma}(n,\lambda)\)

    三者互相等价 —— 知道一个就能推出另两个。

    工程应用：

    现象 建模
    电话呼叫到达 泊松
    放射性衰变 泊松
    光子计数（光学传感器） 泊松
    网络包到达 泊松（近似）
    声纳的虚假报警 泊松

    重要性质：泊松过程的叠加仍是泊松过程， 速率相加（\(\lambda = \lambda_1+\lambda_2\)）。

    所以多个独立噪声源的到达可以合成一个泊松过程 —— 这是噪声建模的便利之处。

    但要注意「非平稳」情形：真实系统的到达率常随时间变化 （如一天中不同时段的呼叫量）。此时用非齐次泊松过程 \(\lambda(t)\) 建模。

    六、典型例题¶

    例题 1：判断宽平稳¶

    设 \(X(t) = A\cos(\omega_0 t + \Theta)\)，其中 \(A\) 是常数， \(\Theta\sim U(0,2\pi)\)。判断是否为宽平稳过程。

    思路

    分别检查均值是否常数、自相关是否只依赖时间差。

    解答

    第一步：均值

    \[ E[X(t)] = A\,E[\cos(\omega_0t+\Theta)] \]

    计算期望：

    \[ E[\cos(\omega_0t+\Theta)] = \frac{1}{2\pi}\int_0^{2\pi}\cos(\omega_0t+\theta)\,\mathrm{d}\theta \]

    令 \(u = \omega_0t+\theta\)，积分一个完整周期：

    \[ \frac{1}{2\pi}\int_{\omega_0t}^{\omega_0t+2\pi}\cos u\,\mathrm{d}u = 0 \]

    （因为 \(\cos\) 在一个完整周期上积分为零。）

    所以

    \[ E[X(t)] = 0 \quad\text{（常数 ✓）} \]

    第二步：自相关

    \[ R(t_1,t_2) = A^2E\left[\cos(\omega_0t_1+\Theta)\cos(\omega_0t_2+\Theta)\right] \]

    用积化和差公式 \(\cos A\cos B = \frac12[\cos(A-B)+\cos(A+B)]\)：

    \[ = \frac{A^2}{2}E\left[\cos(\omega_0(t_1-t_2)) + \cos(\omega_0(t_1+t_2)+2\Theta)\right] \]

    第一项不含 \(\Theta\)，直接提出。

    第二项含 \(2\Theta\)，其期望：

    \[ E[\cos(\omega_0(t_1+t_2)+2\Theta)] = 0 \]

    （对 \(\Theta\) 均匀分布，\(2\Theta\) 覆盖两个完整周期，积分为零。）

    所以

    \[ R(t_1,t_2) = \frac{A^2}{2}\cos\big(\omega_0(t_1-t_2)\big) \]

    只依赖 \(\tau = t_1-t_2\)

    结论：是宽平稳过程

    结果：

    \[ E[X(t)] = 0, \qquad R_{XX}(\tau) = \frac{A^2}{2}\cos(\omega_0\tau) \]

    这个例子的工程意义（「随机相位」假设的用处）

    为什么假设相位随机：实际振荡器的初相位无法精确已知， 用均匀随机相位建模更符合实际。

    带来的好处：

    项 有随机相位 无随机相位（相位固定）
    均值 \(0\)（常数） \(A\cos(\omega_0t+\theta_0)\)（随时间变）
    平稳性 宽平稳 ✓ 不平稳 ✗

    所以「随机相位」是让过程平稳的关键假设。

    功率谱（对自相关做傅里叶变换）：

    \[ S_{XX}(\omega) = \frac{\pi A^2}{2}\big[\delta(\omega-\omega_0) + \delta(\omega+\omega_0)\big] \]

    这是两条谱线 —— 功率完全集中在 \(\pm\omega_0\)， 总功率 \(R(0) = A^2/2\) ✓（正弦波的均方值就是 \(A^2/2\)）。

    这与「正弦信号是功率信号」一致（回到积分那一页的讨论）。

    例题 2：马尔可夫链的平稳分布¶

    某设备的每日状态：正常（N）或故障（F）。转移矩阵

    \[ P = \begin{bmatrix}0.9&0.1\\0.5&0.5\end{bmatrix} \]

    （行 = 当前状态，列 = 下一状态。）

    (a) 求平稳分布。(b) 若今天正常，求 2 天后的状态分布。

    思路

    (a) 解 \(\boldsymbol{\pi}^\top P = \boldsymbol{\pi}^\top\)；(b) 直接做矩阵乘法。

    解答

    (a) 平稳分布

    设 \(\boldsymbol{\pi} = (\pi_N, \pi_F)\)。方程为

    \[ \begin{cases} 0.9\pi_N + 0.5\pi_F = \pi_N &\text{（N 的平稳性）}\\ 0.1\pi_N + 0.5\pi_F = \pi_F &\text{（F 的平稳性）}\\ \pi_N + \pi_F = 1 &\text{（归一化）} \end{cases} \]

    由第一个方程：

    \[ 0.5\pi_F = 0.1\pi_N \implies \pi_N = 5\pi_F \]

    代入归一化：

    \[ 5\pi_F + \pi_F = 1 \implies \pi_F = \frac16, \quad \pi_N = \frac56 \]

    结果：

    \[ \boldsymbol{\pi} = \left(\frac56,\ \frac16\right) \approx (0.833,\ 0.167) \]

    验证（用第二个方程）：

    \[ 0.1\times\frac56 + 0.5\times\frac16 = \frac{0.5}{6} + \frac{0.5}{6} = \frac{1}{6} \;\checkmark \]

    长期含义：设备约 83.3% 的时间正常，16.7% 故障。

    计算平均可用度：\(0.833\) —— 这就是可靠性的常用指标。

    (b) 2 天后的分布

    先算 \(P^2\)：

    \[ P^2 = \begin{bmatrix}0.9&0.1\\0.5&0.5\end{bmatrix}\begin{bmatrix}0.9&0.1\\0.5&0.5\end{bmatrix} \]

    逐项计算：

    \[ P^2_{11} = 0.9\times0.9 + 0.1\times0.5 = 0.81+0.05 = 0.86 \]
    \[ P^2_{12} = 0.9\times0.1 + 0.1\times0.5 = 0.09+0.05 = 0.14 \]

    （第一行和为 \(0.86+0.14 = 1\)）

    \[ P^2_{21} = 0.5\times0.9 + 0.5\times0.5 = 0.45+0.25 = 0.70 \]
    \[ P^2_{22} = 0.5\times0.1 + 0.5\times0.5 = 0.05+0.25 = 0.30 \]

    （第二行和为 \(0.70+0.30 = 1\)）

    所以

    \[ P^2 = \begin{bmatrix}0.86&0.14\\0.70&0.30\end{bmatrix} \]

    今天正常的初态 \(\boldsymbol{\pi}_0 = (1,0)\)：

    \[ \boldsymbol{\pi}_2 = \boldsymbol{\pi}_0 P^2 = (0.86,\ 0.14) \]

    结果：2 天后 86% 正常、14% 故障

    观察：从 1 天到 2 天，已经接近平稳

    时刻 \(P(\text{正常})\)
    0（今天） \(1.000\)
    1 \(0.900\)
    2 \(0.860\)
    平稳 \(0.833\)

    收敛很快（因为第二特征值较小）。

    计算特征值验证：\(P\) 的特征值是 \(1\) 与 \(0.4\)：

    \[ \det\begin{bmatrix}0.9-\lambda&0.1\\0.5&0.5-\lambda\end{bmatrix} = (0.9-\lambda)(0.5-\lambda) - 0.05 \]
    \[ = \lambda^2 - 1.4\lambda + 0.45 - 0.05 = \lambda^2-1.4\lambda+0.4 = (\lambda-1)(\lambda-0.4) \]

    第二大特征值 \(\lambda_2 = 0.4\) → 每步衰减约 \(0.4\)：

    步数 偏离平稳的程度
    1 \(0.4\)
    2 \(0.16\)
    3 \(0.064\)

    验证第 2 步的偏离：\(0.860 - 0.833 = 0.027\)， 而初态偏离是 \(1 - 0.833 = 0.167\)，比值 \(0.16 = 0.4^2\)

    这就是「收敛速率由第二大特征值决定」的具体验证。

    例题 3：泊松过程的计算¶

    某光学传感器接收到的光子到达服从泊松过程，平均每秒 4 个。 求 (a) 1 秒内恰好 4 个的概率；(b) 相邻两个光子的平均间隔。

    思路

    计数分布是 \(\text{Poisson}(\lambda t)\)；间隔是 \(\text{Exp}(\lambda)\)。

    解答

    (a) 计数概率

    参数为 \(\lambda t = 4\times1 = 4\)：

    \[ P(N(1) = 4) = \frac{4^4 e^{-4}}{4!} \]

    计算：

    \[ 4^4 = 256, \qquad 4! = 24, \qquad e^{-4} \approx 0.018316 \]
    \[ = \frac{256}{24}\times0.018316 = 10.667\times0.018316 \approx 0.1954 \]

    结果：约 \(19.5\%\)

    (b) 平均间隔

    间隔服从 \(\text{Exp}(\lambda)\)，均值为 \(1/\lambda\)：

    \[ E[\text{间隔}] = \frac{1}{4} = 0.25\ \text{秒} \]

    结果：250 毫秒

    一致性验证：平均每秒 4 个 → 平均间隔 0.25 秒

    泊松过程的两个反直觉之处

    1. 平均间隔是 0.25 秒，但间隔的「众数」是 0

    \(\text{Exp}(4)\) 的密度是 \(f(x) = 4e^{-4x}\)，在 \(x=0\) 处最大。

    含义：最短的间隔最常见（密度峰值在 0）， 但少数很长的间隔把平均值拉高到 0.25 秒。

    统计量 值
    众数 \(0\)
    中位数 \(\frac{\ln2}{4} \approx 0.173\) 秒
    均值 \(0.25\) 秒

    中位数 < 均值（右偏）✓ 与随机变量那一页的结论一致。

    2. 「等待时间悖论」

    若你在随机时刻开始观测，则你等到的第一个间隔 平均比 \(1/\lambda\) 长（期望为 \(2/\lambda\)）。

    原因：更长的间隔占据更多时间轴，所以随机时刻更可能落在长间隔内 ——这叫长度偏倚抽样（length-biased sampling）。

    工程含义：凭印象估计「平均间隔」会系统性偏大； 必须通过计数（在固定时间窗内数事件数）来估计，而不是测量间隔。

    例题 4：由自相关求相关时间与带宽¶

    设某随机过程的自相关为

    \[ R(\tau) = 100e^{-5\lvert\tau\rvert} \]

    (a) 求总功率。(b) 求相关时间。© 求功率谱与带宽。

    思路

    总功率是 \(R(0)\)；相关时间由衰减到 \(1/e\) 给出；谱用傅里叶变换。

    解答

    (a) 总功率

    \[ P = R(0) = 100e^0 = 100 \]

    结果：\(100\)（单位取决于 \(X\) 的物理量纲）

    (b) 相关时间

    定义 \(R(\tau_c) = R(0)/e\)：

    \[ 100e^{-5\tau_c} = \frac{100}{e} \]
    \[ e^{-5\tau_c} = e^{-1} \implies 5\tau_c = 1 \implies \tau_c = 0.2 \]

    结果：\(\tau_c = 0.2\)（时间单位）

    © 功率谱与带宽

    谱（用本知识库信号模块已算过的结果）：

    \[ S(\omega) = \frac{2a\sigma^2}{a^2+\omega^2}\bigg|_{a=5,\ \sigma^2=100} = \frac{1000}{25+\omega^2} \]

    验证总功率（对谱积分）：

    \[ \frac{1}{2\pi}\int_{-\infty}^{\infty}\frac{1000}{25+\omega^2}\mathrm{d}\omega = \frac{1000}{2\pi}\cdot\frac{\pi}{5} = 100 \;\checkmark \]

    （用到 \(\int_{-\infty}^{\infty}\frac{\mathrm{d}\omega}{a^2+\omega^2} = \frac{\pi}{a}\)。）

    带宽（\(S\) 降到最大值一半处的频率，即 \(-3\) dB 带宽）：

    \(S(0) = 1000/25 = 40\)，令 \(S(\omega_c) = 20\)：

    \[ \frac{1000}{25+\omega_c^2} = 20 \implies 25+\omega_c^2 = 50 \]
    \[ \omega_c = 5 \ \text{rad/s} \]

    结果：带宽 \(\omega_c = 5\) rad/s

    关键关系：相关时间 × 带宽 ≈ 常数

    本例中

    \[ \tau_c\times\omega_c = 0.2\times5 = 1 \]

    这不是巧合——它是不确定性原理在这类过程上的表现：

    \[ \tau_c\cdot\omega_c \approx 1 \]

    一般规律：

    时域 频域 例子
    相关时间短（变化快） 带宽宽 白噪声（\(\tau_c\to0\)，带宽 \(\to\infty\)）
    相关时间长（变化慢） 带宽窄 慢漂移（\(\tau_c\) 大，带宽小）

    工程应用：

    问题 用法
    估计噪声带宽 测自相关衰减时间再取倒数
    估计相关时间 由谱宽的倒数估计
    判断是否可当白噪声 若系统带宽 \(\ll\) 噪声带宽，可近似

    最后一条很实用：若噪声的带宽远大于系统带宽， 则在系统看来噪声「足够白」，可用白噪声模型简化分析 —— 这正是工程中大量使用白噪声假设的原因。

    七、自测¶

    Q1 设 \(X(t) = A\)（常数），其中 \(A\sim N(0,1)\)。 判断是否为宽平稳、是否遍历。

    提示

    均值与自相关是否依赖于时间；再看时间平均能否代表集合平均。

    解答

    宽平稳性：

    均值：

    \[ E[X(t)] = E[A] = 0 \quad\text{（常数 ✓）} \]

    自相关：

    \[ R(t_1,t_2) = E[A\cdot A] = E[A^2] = 1 \quad\text{（只依赖 }\tau\text{ 为常数 ✓）} \]

    是宽平稳过程

    遍历性：

    时间平均（对任一实现，\(A\) 固定）：

    \[ \lim_{T\to\infty}\frac{1}{2T}\int_{-T}^{T}A\,\mathrm{d}t = A \]

    集合平均：

    \[ E[A] = 0 \]

    比较：\(A\neq 0\)（概率为 1），所以

    \[ \text{时间平均} = A \neq 0 = \text{集合平均} \;\times \]

    不遍历 ✗

    结论：

    性质 结果
    宽平稳 ✓
    遍历 ✗

    这就是「平稳但不遍历」的标准反例

    直觉理解：这个过程变化得太慢（根本不变）—— 在一次实验的有限观测时间内，看不到任何「统计涨落」， 所以时间平均无法代表集合平均 ✗

    遍历性的本质要求：过程要在观测时间内「充分游历」各种状态。

    过程 游历程度 遍历
    常数 \(A\) 完全不游历 ✗
    高斯的白噪声 充分游历 ✓
    慢漂移（相关时间很长） 观测期内未充分游历 ✗（实际中）

    工程含义（很重要）：

    场景 后果
    传感器零偏（视为常数） 不能*用时间平均估计其期望 ✗
    需要多次上电测量 每次是一个「新样本」

    这解释了为什么「零偏估计」需要多次开机 —— 单次开机内的平均只能给出该次的零偏值（时间平均 = 该次的值）， 而不会趋向总体期望。

    实践建议：

    目的 做法
    估计随机涨落 单次记录内部的时间平均（若遍历）✓
    估计系统性偏差 需要多次独立实验 ✓

    Q2 某设备的转移矩阵

    \[ P = \begin{bmatrix}0.8&0.2\\0.4&0.6\end{bmatrix} \]

    求平稳分布。

    提示

    解 \(\boldsymbol{\pi}^\top P = \boldsymbol{\pi}^\top\) 与 \(\sum\pi_i = 1\)。

    解答

    设 \(\boldsymbol{\pi} = (\pi_1,\pi_2)\)，方程为

    \[ \begin{cases}0.8\pi_1+0.4\pi_2 = \pi_1\\ 0.2\pi_1+0.6\pi_2 = \pi_2\\ \pi_1+\pi_2 = 1\end{cases} \]

    由第一式：

    \[ 0.4\pi_2 = 0.2\pi_1 \implies \pi_1 = 2\pi_2 \]

    代入归一化：

    \[ 2\pi_2+\pi_2 = 1 \implies \pi_2 = \frac13,\quad \pi_1 = \frac23 \]

    结果：

    \[ \boldsymbol{\pi} = \left(\frac23,\ \frac13\right) \approx (0.667,\ 0.333) \]

    验证（用第二式）：

    \[ 0.2\times\frac23+0.6\times\frac13 = \frac{0.4}{3}+\frac{0.6}{3} = \frac13 \;\checkmark \]

    长期含义：系统约 \(66.7\%\) 的时间处于状态 1、\(33.3\%\) 处于状态 2。

    计算特征值（判断收敛速率）：

    \[ \operatorname{tr}(P) = 1.4,\qquad \det(P) = 0.8\times0.6-0.2\times0.4 = 0.48-0.08 = 0.40 \]
    \[ \lambda^2-1.4\lambda+0.40 = 0 \implies (\lambda-1)(\lambda-0.4) = 0 \]

    第二大特征值 \(\lambda_2 = 0.4\) → 收敛较快 （每步偏离平稳的幅度衰减到 \(0.4\) 倍。）

    Q3 某呼叫中心的来话服从泊松过程，平均每分钟 3 次。 求 (a) 1 分钟内恰好 2 次的概率；(b) 相邻两次来话的平均间隔。

    提示

    计数服从 Poisson(λt)，间隔服从 Exp(λ)。

    解答

    (a) 计数概率

    参数 \(\lambda t = 3\times1 = 3\)：

    \[ P(N(1) = 2) = \frac{3^2e^{-3}}{2!} = \frac{9\times0.049787}{2} = 0.224 \]

    结果：约 \(22.4\%\)

    (b) 平均间隔

    间隔服从 \(\text{Exp}(3)\)，均值为 \(1/\lambda\)：

    \[ E[\text{间隔}] = \frac13\ \text{分钟} = 20\ \text{秒} \]

    结果：20 秒

    一致性验证：每分钟 3 次 → 平均间隔 ⅓ 分钟

    注意「间隔的分布是右偏的」：

    统计量 值
    众数 \(0\)（最短间隔最常见）
    中位数 \(\frac{\ln2}{3} \approx 0.231\) 分钟 ≈ 13.9 秒
    均值 \(0.333\) 分钟 = 20 秒

    中位数 < 均值 ✓ 符合指数分布的右偏特性。

    工程含义（人员排班）：

    若按「平均间隔 20 秒」安排接线员， 则有约 \(50\%\) 的间隔短于 13.9 秒 —— 需要用「排队论」而非「平均值」来做容量规划

    Q4 已知某随机过程的 \(R(\tau) = 25e^{-10\lvert\tau\rvert}\)。 求 (a) 总功率；(b) 相关时间；© 带宽。

    提示

    总功率是 \(R(0)\)；相关时间由衰减到 \(1/e\) 给出；带宽由谱降到一半给出。

    解答

    (a) 总功率

    \[ P = R(0) = 25e^0 = 25 \]

    结果：\(25\)

    (b) 相关时间

    定义 \(R(\tau_c) = R(0)/e\)：

    \[ 25e^{-10\tau_c} = \frac{25}{e} \implies 10\tau_c = 1 \implies \tau_c = 0.1 \]

    结果：\(\tau_c = 0.1\)

    © 带宽

    谱（用 \(R = \sigma^2e^{-a\lvert\tau\rvert}\) 的变换结果，\(a = 10\)、\(\sigma^2 = 25\)）：

    \[ S(\omega) = \frac{2a\sigma^2}{a^2+\omega^2} = \frac{2\times10\times25}{100+\omega^2} = \frac{500}{100+\omega^2} \]

    \(S(0) = 500/100 = 5\)。

    令 \(S(\omega_c) = S(0)/2 = 2.5\)：

    \[ \frac{500}{100+\omega_c^2} = 2.5 \implies 100+\omega_c^2 = 200 \implies \omega_c = 10 \]

    结果：带宽 \(\omega_c = 10\) rad/s

    验证「时宽-带宽关系」：

    \[ \tau_c\cdot\omega_c = 0.1\times10 = 1 \;\checkmark \]

    这正是不确定性原理的体现

    验证总功率（对谱积分）：

    \[ \frac{1}{2\pi}\int_{-\infty}^{\infty}\frac{500}{100+\omega^2}\mathrm{d}\omega = \frac{500}{2\pi}\cdot\frac{\pi}{10} = 25 \;\checkmark \]

    结果汇总：

    量 值
    总功率 \(25\)
    相关时间 \(0.1\)
    带宽 \(10\) rad/s

    工程解读：相关时间短（0.1）↔ 带宽宽（10） —— 这个噪声「变化快」（宽带噪声）。

    实用判据：若系统带宽 \(\ll\) 噪声带宽，可把噪声当白噪声处理 （此处噪声带宽 10 rad/s，若系统带宽只有 0.1 rad/s， 则在系统看来噪声足够「白」。）

    最大似然估计
