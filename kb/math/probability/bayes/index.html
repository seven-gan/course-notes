    贝叶斯定理¶

    上一页把贝叶斯定理作为条件概率的推论给出了。这一页把它当成一种思维方式来讲。

    贝叶斯定理：新证据如何改变我们的判断。

    它不是一条计算技巧，而是在不确定下做推理的通用框架—— 模式识别、状态估计、故障诊断、机器学习，全都建立在它之上。

    贝叶斯思维的一句话概括

    \[ \text{后验} \propto \text{似然}\times\text{先验} \]
    成分 含义 来源
    先验 看到数据前相信什么 经验、历史数据
    似然 若假设成立，数据有多可能 物理模型、传感器特性
    后验 看到数据后应相信什么 两者相乘并归一化

    核心洞察：判断不只取决于证据，还取决于先验。 这正是本知识库「样本空间」一页里假阳性问题的教训。

    一、连续情形的贝叶斯定理¶

    对连续随机变量，把概率换成密度：

    \[ \boxed{\ f(\theta\mid \boldsymbol{x}) = \frac{f(\boldsymbol{x}\mid\theta)f(\theta)}{f(\boldsymbol{x})}\ } \]

    其中

    \[ f(\boldsymbol{x}) = \int f(\boldsymbol{x}\mid\theta)f(\theta)\,\mathrm{d}\theta \]

    这是参数估计的起点：\(\theta\) 是待估参数，\(\boldsymbol{x}\) 是观测数据。

    项 名称 含义
    \(f(\theta)\) 先验密度 对参数的事前信念
    \(f(\boldsymbol{x}\mid\theta)\) 似然 参数为 \(\theta\) 时观测到 \(\boldsymbol{x}\) 的可能
    \(f(\theta\mid\boldsymbol{x})\) 后验密度 观测后对参数的信念
    \(f(\boldsymbol{x})\) 证据 归一化常数（与 \(\theta\) 无关）

    为什么分母常常可以不管

    因为 \(f(\boldsymbol{x})\) 不含 \(\theta\)（它是对 \(\theta\) 积分后得到的常数）， 所以在求「与 \(\theta\) 有关的量」时常可忽略：

    \[ f(\theta\mid\boldsymbol{x}) \propto f(\boldsymbol{x}\mid\theta)f(\theta) \]

    典型用法：

    目的 是否需要分母
    求最大后验估计（MAP） 不需要（只比较大小）
    求后验的期望 需要（归一化）
    求后验的完整分布 需要

    MAP 估计就是

    \[ \hat\theta_{\text{MAP}} = \arg\max_\theta\big[f(\boldsymbol{x}\mid\theta)f(\theta)\big] \]

    这与「最大似然估计（MLE）」的关系是：

    方法 目标
    MLE \(\arg\max f(\boldsymbol{x}\mid\theta)\)
    MAP \(\arg\max f(\boldsymbol{x}\mid\theta)f(\theta)\)

    MLE 是 MAP 在「先验均匀」时的特例（因为均匀先验是常数，不影响极值位置）。

    二、共轭先验¶

    问题：贝叶斯更新的分母 \(f(\boldsymbol{x}) = \int f(\boldsymbol{x}\mid\theta)f(\theta)\mathrm{d}\theta\) 常常积不出来。

    解决：选择共轭先验——使后验与先验属于同一分布族， 从而更新只改变参数，不需要做积分。

    定义：若先验 \(f(\theta)\) 与后验 \(f(\theta\mid\boldsymbol{x})\) 属于同一分布族， 则称该先验是似然的共轭先验。

    常用共轭对：

    似然 共轭先验 后验
    伯努利 / 二项 Beta Beta（参数累加）
    泊松 Gamma Gamma
    正态（已知方差） 正态 正态
    正态（已知均值） 逆 Gamma 逆 Gamma
    多项 Dirichlet Dirichlet

    正态 + 正态 = 正态：这是最常用的一对

    设先验 \(\theta\sim N(\mu_0,\sigma_0^2)\)， 观测 \(x\mid\theta\sim N(\theta,\sigma^2)\)（一次观测），则后验

    \[ \theta\mid x \sim N(\mu_1,\ \sigma_1^2) \]

    其中

    \[ \frac{1}{\sigma_1^2} = \frac{1}{\sigma_0^2} + \frac{1}{\sigma^2}, \qquad \mu_1 = \sigma_1^2\left(\frac{\mu_0}{\sigma_0^2} + \frac{x}{\sigma^2}\right) \]

    关键在于「精度的可加性」：定义精度（方差的倒数）

    \[ \tau = \frac{1}{\sigma^2} \]

    则

    \[ \tau_1 = \tau_0 + \tau_x \]

    精度直接相加 —— 这极其简洁。

    量 含义
    \(\tau_0\) 先验提供的「信息量」
    \(\tau_x\) 数据提供的「信息量」
    \(\tau_1\) 总的「信息量」

    后验均值是「加权平均」：

    \[ \mu_1 = \frac{\tau_0\mu_0 + \tau_x x}{\tau_0 + \tau_x} \]

    谁的精度高，谁的话语权就大 —— 这就是贝叶斯更新的直觉。

    多次观测：\(n\) 次独立观测的精度是 \(n\tau_x\)（精度可加）， 所以

    \[ \tau_n = \tau_0 + n\tau_x \]

    \(n\) 很大时 \(\tau_0\) 可忽略，后验完全由数据决定 （回到「数据说话」）

    三、三种估计的对比¶

    方法 估计值 使用先验
    MLE（最大似然） \(\arg\max f(\boldsymbol{x}\mid\theta)\) ✗
    MAP（最大后验） \(\arg\max f(\boldsymbol{x}\mid\theta)f(\theta)\) ✓
    贝叶斯估计 后验的某个泛函（如均值 \(E[\theta\mid \boldsymbol{x}]\)） ✓

    MLE 与 MAP 的关系（以及正则化的解释）

    取对数后：

    \[ \hat\theta_{\text{MAP}} = \arg\max_\theta\big[\log f(\boldsymbol{x}\mid\theta) + \log f(\theta)\big] \]

    对比机器学习的损失函数：

    贝叶斯项 机器学习对应
    \(-\log f(\boldsymbol{x}\mid\theta)\) 损失函数（如交叉熵）
    \(-\log f(\theta)\) 正则项

    这解释了一件重要的事：

    先验 对应的正则化
    高斯先验 \(N(0,\sigma^2)\) L2 正则（权重衰减）
    拉普拉斯先验 L1 正则（产生稀疏解）

    推导（高斯先验 → L2）：

    \[ -\log f(\theta) = -\log\left[\frac{1}{\sqrt{2\pi}\sigma}e^{-\theta^2/(2\sigma^2)}\right] = \frac{\theta^2}{2\sigma^2} + \text{常数} \]

    这正是 L2 正则项 \(\frac{\lambda}{2}\lVert\theta\rVert^2\)（取 \(\lambda = 1/\sigma^2\)）

    工程含义：正则化不是「技巧」，而是有概率意义的—— 它等价于对参数施加了先验信念。

    这也解释了为什么正则强度要与数据量匹配： 数据越多，先验的相对影响越小。

    四、朴素贝叶斯分类器¶

    这是贝叶斯定理在模式识别中最直接的应用。

    问题¶

    给定特征 \(\boldsymbol{x} = (x_1,\dots,x_d)\)，判断类别 \(c\)：

    \[ P(c\mid\boldsymbol{x}) = \frac{P(\boldsymbol{x}\mid c)P(c)}{P(\boldsymbol{x})} \]

    困难：\(P(\boldsymbol{x}\mid c)\) 是 \(d\) 维联合分布，需要估计的参数太多 （\(d\) 大时指数爆炸）。

    朴素贝叶斯的假设¶

    假设特征在类别内条件独立：

    \[ P(\boldsymbol{x}\mid c) = \prod_{i=1}^{d}P(x_i\mid c) \]

    于是：

    \[ P(c\mid\boldsymbol{x}) \propto P(c)\prod_{i=1}^{d}P(x_i\mid c) \]

    分类决策：

    \[ \hat c = \arg\max_c\Big[P(c)\prod_{i=1}^{d}P(x_i\mid c)\Big] \]

    「朴素」二字的含义与代价

    「朴素」指的就是那个条件独立假设—— 它通常不成立（特征往往相关），所以叫「朴素」（naive）。

    参数数量对比（\(d\) 个特征、每个取 \(k\) 个值）：

    方法 参数数量
    完整联合分布 \(O(k^d)\)
    朴素贝叶斯 \(O(kd)\)

    指数级降到线性级 —— 这就是它实用的原因。

    为什么假设不成立却仍然有效：

    原因 说明
    分类只需要排序正确 概率值不准也能选出最大者
    相关性会同时影响各候选类别 部分抵消
    小样本下偏差-方差权衡有利 参数少 → 方差小

    已知的失效情形：特征高度相关且各类别的相关性模式不同时， 朴素贝叶斯会明显出错。

    经典陷阱：若两个特征完全重复 （\(x_2 = x_1\)），则那个特征被计了两次， 使后验过度自信——这是「双重计数」问题。

    平滑（拉普拉斯平滑）¶

    问题：若某特征值在某类别下从未出现，则

    \[ P(x_i\mid c) = 0 \implies \text{整个连乘} = 0 \]

    一个零概率抹掉了所有其它证据 —— 这显然是错的。

    解决（拉普拉斯平滑）：

    \[ P(x_i = v\mid c) = \frac{N_{i,v,c} + \alpha}{N_c + \alpha k} \]

    其中 \(N_{i,v,c}\) 是计数，\(k\) 是取值个数，\(\alpha\) 通常取 1。

    效果：从不出现的事件给一个很小的正概率，而非零。

    五、典型例题¶

    例题 1：连续情形的贝叶斯更新¶

    设参数 \(\theta\) 的先验为 \(N(0, 4)\)。 观测到一次 \(x = 3\)，观测模型为 \(x\mid\theta\sim N(\theta, 1)\)。

    (a) 求后验分布。(b) 求 MAP 估计。

    思路

    用「精度可加」公式。

    解答

    (a) 后验

    精度：

    \[ \tau_0 = \frac{1}{\sigma_0^2} = \frac14 = 0.25 \]
    \[ \tau_x = \frac{1}{\sigma^2} = \frac11 = 1 \]

    后验精度（可加）：

    \[ \tau_1 = \tau_0 + \tau_x = 0.25 + 1 = 1.25 \]

    所以

    \[ \sigma_1^2 = \frac{1}{1.25} = 0.8 \]

    后验均值（加权平均）：

    \[ \mu_1 = \frac{\tau_0\mu_0 + \tau_x x}{\tau_1} = \frac{0.25\times0 + 1\times3}{1.25} = \frac{3}{1.25} = 2.4 \]

    结果：

    \[ \theta\mid x \sim N(2.4,\ 0.8) \]

    (b) MAP 估计

    正态分布的众数就是均值，所以

    \[ \hat\theta_{\text{MAP}} = 2.4 \]

    对比 MLE：若忽略先验，MLE 就是 \(x = 3\)。

    贝叶斯估计把 3 向先验均值 0 拉近了 → \(2.4\)

    这个「拉近」效应的定量理解

    \[ \mu_1 = \frac{\tau_0\mu_0 + \tau_x x}{\tau_0+\tau_x} \]

    代入 \(\mu_0 = 0\)、\(x = 3\)、\(\tau_0 = 0.25\)、\(\tau_x = 1\)：

    \[ \mu_1 = \frac{1}{1.25}\times3 = 0.8\times3 = 2.4 \]

    比例 \(0.8\) 的含义：数据占 \(80\%\) 权重，先验占 \(20\%\)。

    \[ \frac{\tau_x}{\tau_0+\tau_x} = \frac{1}{1.25} = 0.8 \]

    数据越多，这个比例越接近 1：

    观测数 \(n\) 后验精度 数据权重
    1 \(0.25+1 = 1.25\) \(80\%\)
    4 \(0.25+4 = 4.25\) \(94\%\)
    100 \(0.25+100\) \(99.75\%\)

    这就是「贝叶斯更新会逐渐遗忘先验」的定量表现。

    例题 2：Beta-伯努利共轭¶

    某部件合格率 \(\theta\) 未知。先验取 \(\text{Beta}(2,2)\)。 检验 10 件，其中 7 件合格。

    (a) 求后验分布。(b) 求后验均值。

    思路

    Beta-伯努利共轭：后验参数 = 先验参数 + 成功/失败计数。

    解答

    (a) 后验

    共轭规则：若先验为 \(\text{Beta}(\alpha,\beta)\)， 观测到 \(s\) 次成功、\(f\) 次失败，则后验为

    \[ \text{Beta}(\alpha + s,\ \beta + f) \]

    代入 \(\alpha = 2\)、\(\beta = 2\)、\(s = 7\)、\(f = 3\)：

    \[ \theta\mid \text{data} \sim \text{Beta}(2+7,\ 2+3) = \text{Beta}(9,\ 5) \]

    (b) 后验均值

    Beta 分布的均值是 \(\frac{\alpha}{\alpha+\beta}\)：

    \[ E[\theta\mid\text{data}] = \frac{9}{9+5} = \frac{9}{14} \approx 0.643 \]

    对比 MLE：\(\frac{7}{10} = 0.7\)。

    对比先验均值：\(\frac{2}{2+2} = 0.5\)。

    后验均值介于两者之间（0.643），且更靠近数据（0.7）

    Beta 先验的「虚拟样本」解释

    \(\text{Beta}(\alpha,\beta)\) 可以理解为已经看过 \(\alpha-1\) 次成功、 \(\beta-1\) 次失败（或近似理解为 \(\alpha\) 次成功、\(\beta\) 次失败）。

    于是后验均值就是「加了虚拟样本后的频率」：

    \[ E[\theta\mid\text{data}] = \frac{\alpha + s}{(\alpha+s)+(\beta+f)} = \frac{2+7}{(2+7)+(2+3)} = \frac{9}{14} \]

    本例如同「先验贡献 2 成功 2 失败，再加 7 成功 3 失败」。

    先验强度的含义：

    先验 \(\alpha+\beta\) 相当于「先验样本数」
    \(\text{Beta}(1,1)\)（均匀） 2 几乎没有先验信息
    \(\text{Beta}(2,2)\) 4 弱先验
    \(\text{Beta}(50,50)\) 100 强先验（很难被数据改变）

    工程用途：想表达「我对这个参数有很强的历史经验」， 就用大 \(\alpha+\beta\)；想「让数据说话」，就用 \(\text{Beta}(1,1)\)。

    实践建议：一般先用弱先验，数据积累后再逐步调整。

    例题 3：朴素贝叶斯分类¶

    用朴素贝叶斯判断一封邮件是否为垃圾邮件。

    训练数据：

    邮件 含「免费」 含「会议」 类别
    1 是 否 垃圾
    2 是 是 垃圾
    3 否 是 正常
    4 否 是 正常
    5 否 否 正常

    待分类邮件：含「免费」、不含「会议」。

    用拉普拉斯平滑（\(\alpha = 1\)），判断类别。

    思路

    先算先验与各特征的类条件概率（含平滑），再用朴素贝叶斯的乘积公式。

    解答

    第一步：先验

    垃圾 2 封、正常 3 封，共 5 封：

    \[ P(\text{垃圾}) = \frac25 = 0.4, \qquad P(\text{正常}) = \frac35 = 0.6 \]

    第二步：类条件概率（含拉普拉斯平滑 \(\alpha=1\)）

    每个特征有 2 个取值（是/否），所以 \(k = 2\)， 平滑公式：\(P = \frac{\text{计数}+1}{\text{该类总数}+2}\)。

    垃圾类（2 封）：

    特征 计数 平滑后
    「免费」= 是 2 \(\frac{2+1}{2+2} = 0.75\)
    「免费」= 否 0 \(\frac{0+1}{2+2} = 0.25\)
    「会议」= 是 1 \(\frac{1+1}{2+2} = 0.5\)
    「会议」= 否 1 \(\frac{1+1}{2+2} = 0.5\)

    正常类（3 封）：

    特征 计数 平滑后
    「免费」= 是 0 \(\frac{0+1}{3+2} = 0.2\)
    「免费」= 否 3 \(\frac{3+1}{3+2} = 0.8\)
    「会议」= 是 2 \(\frac{2+1}{3+2} = 0.6\)
    「会议」= 否 1 \(\frac{1+1}{3+2} = 0.4\)

    第三步：计算后验（未归一化）

    待分类邮件：「免费」= 是、「会议」= 否。

    垃圾：

    \[ P(\text{垃圾})\cdot P(\text{免费}\mid\text{垃圾})\cdot P(\text{无会议}\mid\text{垃圾}) = 0.4\times0.75\times0.5 = 0.15 \]

    正常：

    \[ P(\text{正常})\cdot P(\text{免费}\mid\text{正常})\cdot P(\text{无会议}\mid\text{正常}) = 0.6\times0.2\times0.4 = 0.048 \]

    第四步：比较并归一化

    \[ 0.15 > 0.048 \implies \textbf{判为垃圾邮件} \]

    归一化后的后验概率：

    \[ P(\text{垃圾}\mid \boldsymbol{x}) = \frac{0.15}{0.15+0.048} = \frac{0.15}{0.198} \approx 0.758 \]

    即约 \(75.8\%\)

    没有平滑会怎样（关键检验）

    若不做平滑，看看「正常」类的「免费 = 是」：

    训练数据中正常邮件从未含「免费」→ 计数为 0 →

    \[ P(\text{免费}\mid\text{正常}) = 0 \]

    于是

    \[ P(\text{正常})\cdot 0\cdot P(\text{无会议}\mid\text{正常}) = 0 \]

    整个乘积变成 0 —— 无论其它特征提供多少证据， 正常类的得分都会被这一个零彻底抹掉。

    后果：只要邮件含「免费」就必然判为垃圾—— 即使它是「会议免费」这类正常内容。

    这就是「零概率问题」，拉普拉斯平滑正是为解决它而设计的。

    对比：

    方法 垃圾得分 正常得分 判定
    无平滑 0.15 0 垃圾（但理由不充分）
    平滑后 0.15 0.048 垃圾（79% 置信）

    平滑后正常类有了「非零的发言机会」，判定才基于证据比较 而不是「一票否决」。

    例题 4：贝叶斯 vs 频率派——一个直观对比¶

    某试验做了 5 次，全部成功。估计成功率 \(\theta\)。

    (a) MLE 给出的估计是多少？有什么问题？

    (b) 用 \(\text{Beta}(1,1)\) 先验，后验均值是多少？

    思路

    (a) 想想「5 次全成功」时的频率估计；(b) 用共轭规则。

    解答

    (a) MLE

    \[ \hat\theta_{\text{MLE}} = \frac{5}{5} = 1 \]

    问题：它断言成功率恰好是 100%，即「不可能失败」。

    为什么这是问题：

    问题 说明
    过于绝对 5 次样本不足以支持「绝无失败」的结论
    预测失效 说下一次必然成功，但若失败则模型完全错误
    零概率灾难 若用于下游计算，出现 \(P(\text{失败}) = 0\) 会导致 \(\log 0\) 等

    本质：MLE 只看数据，不考虑样本量的说服力。

    (b) 贝叶斯（Beta(1,1) 先验）

    \(\text{Beta}(1,1)\) 是 \([0,1]\) 上的均匀分布（最弱的先验）。

    后验：

    \[ \text{Beta}(1 + 5,\ 1 + 0) = \text{Beta}(6,\ 1) \]

    后验均值：

    \[ E[\theta\mid\text{data}] = \frac{6}{6+1} = \frac67 \approx 0.857 \]

    结果：\(0.857\) —— 比 MLE 的 \(1\) 更保守、更合理

    为什么更合理：它保留了「可能失败」的一丝可能 （后验分布 \(\text{Beta}(6,1)\) 在 \(\theta = 1\) 附近有密度但非全部）。

    注意这里先验极弱（\(\text{Beta}(1,1)\) 几乎不含信息）， 可见「加一点点先验」就能避免极端的 \(1\)。

    两种学派的差异与工程取向

    方面 频率派 贝叶斯派
    \(\theta\) 的性质 固定未知常数 随机变量（有分布）
    概率的含义 长期频率 信念程度
    小样本 容易给出极端估计 有先验「托底」
    计算 通常更快 常需积分/MCMC
    先验 不使用 需要指定（争议点）

    工程实践的常见做法：

    情形 倾向
    数据量大 两者结果趋同（先验影响消失）
    数据量小 贝叶斯更稳（有先验正则）
    需要「不确定性量化」 贝叶斯（直接给出分布）
    实时嵌入式 频率派/简单方法（贝叶斯可能太慢）

    本知识库的信号与系统模块中， 卡尔曼滤波正是贝叶斯方法：它维护状态的完整分布（均值+协方差）， 每次观测做一次「贝叶斯更新」。这就是它优于简单滤波器的原因。

    模式识别 · 分类与决策¶

    • 贝叶斯分类器：最小错误率决策的理论最优解

    • 粒子滤波：非高斯/非线性的贝叶斯近似

    • 目标跟踪：状态的贝叶斯递推（预测 + 更新）

    • 贝叶斯优化：用于超参数搜索（用高斯过程建模目标函数）
    • 贝叶斯神经网络：对权重加先验，输出不确定性

    七、自测¶

    Q1 先验 \(N(10, 1)\)，观测 \(x = 13\)，似然 \(x\mid\theta\sim N(\theta, 4)\)。 求后验均值。

    提示

    用精度可加与加权平均。

    解答

    精度：

    \[ \tau_0 = \frac{1}{1} = 1, \qquad \tau_x = \frac14 = 0.25 \]

    后验精度：

    \[ \tau_1 = 1 + 0.25 = 1.25 \]

    后验均值：

    \[ \mu_1 = \frac{1\times10 + 0.25\times13}{1.25} = \frac{10 + 3.25}{1.25} = \frac{13.25}{1.25} = 10.6 \]

    结果：\(10.6\)

    解读：先验（精度 1）比数据（精度 0.25）更「可信」， 所以后验（10.6）更靠近先验（10）而不是数据（13）。

    验证权重：

    来源 权重
    先验 \(\frac{1}{1.25} = 0.8\)
    数据 \(\frac{0.25}{1.25} = 0.2\)
    \[ 0.8\times10 + 0.2\times13 = 8 + 2.6 = 10.6 \;\checkmark \]

    这提醒我们：若先验很强（方差小），少量数据难以改变判断。 实践中若怀疑先验有偏，应选弱先验（大方差）。

    Q2 判断：MAP 估计总是比 MLE 更准确。

    提示

    想想先验本身可能是错的。

    解答

    不对。取决于先验是否正确。

    关键：贝叶斯方法把先验的假设引入了结果。

    先验情形 MAP 相对 MLE
    先验接近真值 MAP 更准 ✓
    先验严重偏离 MAP 可能更差 ✗
    数据充分 两者接近（先验影响消失）
    数据稀少 + 好先验 MAP 明显更准
    数据稀少 + 坏先验 MAP 明显更差

    具体例子：设真值 \(\theta = 5\)，数据倾向 \(\hat\theta_{\text{MLE}} = 5.2\)。

    • 若先验 \(N(5, 1)\)（对的）→ MAP 会拉向 5，更准
    • 若先验 \(N(0, 1)\)（错的）→ MAP 被拉向 0，更差 ✗

    工程启示：

    实践建议 理由
    先验要有依据 来自历史数据或物理约束，别凭空设
    数据不足时用弱先验 避免坏先验主导
    数据充分时可放心用先验 影响会被数据冲淡
    做敏感性分析 换不同先验看结论是否稳定

    「坏先验」在工程中的实际表现：系统在某环境下标定的参数， 换到另一环境后可能失效——这本质上就是「先验不再适用」。

    Q3 朴素贝叶斯为什么能用于特征相关的数据？

    提示

    想想分类只需要什么。

    解答

    因为它只需要预测的「排序」正确，不需要概率值准确。

    详细解释：

    1. 分类只比较大小

    \[ \hat c = \arg\max_c P(c)\prod_i P(x_i\mid c) \]

    只需要选出最大者，不要求概率值本身是准确的。

    特征相关性会使概率值偏大或偏小（通常偏「自信」）， 但如果所有类别都同样受影响，排序可能仍然正确。

    2. 偏差-方差权衡

    方法 参数数 偏差 方差
    完整贝叶斯 \(O(k^d)\) 低 极高（数据不足）
    朴素贝叶斯 \(O(kd)\) 高 低

    小样本时，低方差的收益常超过高偏差的损失。

    3. 什么时候会失效

    情形 后果
    特征高度冗余（如完全重复） 双重计数 → 过度自信
    各类别的相关模式不同 排序出错
    特征间有强负相关 概率严重失真

    缓解方法：

    方法 说明
    特征选择 去掉冗余特征
    降维（PCA） 先去相关
    校准（calibration） 后处理让概率变准
    改用半朴素贝叶斯 允许部分依赖（如 TAN）

    实践结论：朴素贝叶斯是极好的基线—— 快、稳定、参数量小。文本分类上常与复杂模型打平。 但若要用它的概率值（如做风险决策），必须先做校准。

    Q4 为什么「正则化」可以理解为贝叶斯先验？

    提示

    对 MAP 取对数，看剩余两项。

    解答

    因为 MAP 的对数形式正好是「负损失 + 负对数先验」。

    推导：

    \[ \hat\theta_{\text{MAP}} = \arg\max_\theta\big[f(\boldsymbol{x}\mid\theta)f(\theta)\big] \]

    取对数（\(\log\) 单调，不改变极值位置）：

    \[ = \arg\max_\theta\big[\log f(\boldsymbol{x}\mid\theta) + \log f(\theta)\big] \]

    改为最小化（加负号）：

    \[ = \arg\min_\theta\underbrace{\big[-\log f(\boldsymbol{x}\mid\theta)\big]}_{\text{损失函数}} + \underbrace{\big[-\log f(\theta)\big]}_{\text{正则项}} \]

    这就是「损失 + 正则」的形式

    两种常见对应的完整推导：

    先验 \(-\log f(\theta)\) 正则
    高斯 \(N(0,\sigma^2)\) \(\frac{\lVert\theta\rVert^2}{2\sigma^2} + C\) L2（权重衰减）
    拉普拉斯 \(\frac{\lVert\theta\rVert_1}{b} + C\) L1（稀疏）

    拉普拉斯先验的推导：

    \[ f(\theta) = \frac{1}{2b}e^{-\lvert\theta\rvert/b} \implies -\log f(\theta) = \frac{\lvert\theta\rvert}{b} + C \]

    正是 L1 正则

    为什么 L1 产生稀疏解（这个解释很漂亮）：

    先验 在 0 附近的密度形状 效果
    高斯 光滑（顶点处导数为 0） 参数靠近 0 但不为 0
    拉普拉斯 尖峰（0 处导数不为 0） 参数容易被压到恰好 0

    直观理解：拉普拉斯分布在 0 处有个「尖锐的峰」， 意味着它强烈相信「很多参数应该恰好为 0」—— 这正是稀疏性的来源。

    工程含义：正则化强度 \(\lambda\) 就对应先验方差：

    \[ \lambda = \frac{1}{\sigma^2} \]

    强正则 ⟺ 小方差先验 ⟺ 对参数「更有主见」。
