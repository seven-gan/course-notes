    样本空间与条件概率¶

    概率论的起点是一个很朴素的想法：

    有些事情无法确定，但可以用「可能性的大小」来描述。

    这一页建立这门语言的基本词汇：样本空间、事件、概率、条件概率。

    为什么工程专业要从这里开始

    后面的所有内容——随机变量、分布、贝叶斯、估计——都建立在这几个概念上。

    后续内容 依赖这里的概念
    随机变量 事件 → 实数映射
    条件分布 条件概率
    贝叶斯定理 条件概率的定义
    全概率公式 划分与条件概率
    独立性 条件概率的特例

    跳过这一节，后面就只能是「背公式」。

    一、样本空间与事件¶

    样本空间 \(\Omega\)：一次试验所有可能结果的集合。

    样本点 \(\omega\)：\(\Omega\) 中的一个元素（一个可能结果）。

    事件 \(A\)：\(\Omega\) 的一个子集（满足某条件的那些结果）。

    一个具体的例子¶

    投掷一颗骰子：

    概念 内容
    样本空间 \(\Omega = \{1,2,3,4,5,6\}\)
    样本点 \(3\)（表示掷出 3 点）
    事件 \(A\) = 「掷出偶数」 \(\{2,4,6\}\)
    事件 \(B\) = 「掷出大于 4」 \(\{5,6\}\)

    事件运算（就是集合运算）：

    记号 含义 例（上表）
    \(A\cup B\) 至少发生一个 \(\{2,4,5,6\}\)
    \(A\cap B\) 同时发生 \(\{6\}\)
    \(A^c\)（或 \(\bar A\)） 不发生 \(\{1,3,5\}\)
    \(A\cap B = \varnothing\) 互斥（不能同时发生） ——

    「互斥」与「独立」是完全不同的概念

    这两个词极易混淆，但含义毫无关系。

    概念 定义 直觉
    互斥 \(A\cap B = \varnothing\) 二者不能同时发生
    独立 \(P(A\cap B) = P(A)P(B)\) 一方的发生不影响另一方

    关键点：互斥事件通常不独立（而是「负相关」）。

    举例（掷骰子）：

    • \(A\) = 「掷出 6」，\(B\) = 「掷出奇数」→ 互斥（不能同时） 但不独立：知道 \(A\) 发生，\(B\) 必然不发生。

    • \(A\) = 「掷出 6」，\(C\) = 「第一次掷出 6」（另一次独立投掷） → 独立（不相干），也不互斥。

    工程含义：传感器故障可能「互斥」（同时只坏一个）却 不独立（共同原因导致）——这正是「共因失效」分析要处理的问题。

    二、概率的公理化定义¶

    柯尔莫哥洛夫公理（1933）：概率 \(P\) 是定义在事件上的函数，满足

    公理 内容
    非负性 \(P(A) \geq 0\)
    规范性 \(P(\Omega) = 1\)
    可加性 若 \(A_i\) 两两互斥，则 \(P\left(\bigcup_i A_i\right) = \sum_i P(A_i)\)

    这三条是全部概率论的基础——所有结论都由它们推出。

    由此得出的常用性质：

    性质 公式
    补事件 \(P(A^c) = 1 - P(A)\)
    空集 \(P(\varnothing) = 0\)
    容斥原理 \(P(A\cup B) = P(A) + P(B) - P(A\cap B)\)
    单调性 \(A\subseteq B \Rightarrow P(A) \leq P(B)\)

    补事件技巧：算「至少一个」

    直接算「至少发生一个」很难（要枚举所有情况）。 但它的补事件是「一个都不发生」——于是

    \[ P(\text{至少一个}) = 1 - P(\text{一个都不}) \]

    例：掷 3 次骰子，至少出现一次 6 的概率：

    \[ 1 - P(\text{都没 6}) = 1 - \left(\frac56\right)^3 = 1 - \frac{125}{216} \approx 0.421 \]

    对比直接算：要算「恰好 1 个 6」+「恰好 2 个」+「恰好 3 个」—— 三项求和，繁琐得多。

    这是概率计算中最实用的技巧之一。

    古典概型¶

    若 \(\Omega\) 有限且每个样本点等可能：

    \[ P(A) = \frac{\lvert A\rvert}{\lvert\Omega\rvert} = \frac{\text{有利结果数}}{\text{总结果数}} \]

    注意前提是「等可能」——这个前提不成立时不能这样算 （例如「中奖」与「不中奖」不是等可能的）。

    三、条件概率¶

    定义：在事件 \(B\) 已发生的条件下，\(A\) 发生的条件概率为

    \[ \boxed{\ P(A\mid B) = \frac{P(A\cap B)}{P(B)}, \qquad P(B) > 0\ } \]

    直观理解：\(B\) 的发生把样本空间缩小到 \(B\)， 我们在新的（更小的）空间里重新算概率。

    乘法公式¶

    由定义直接得

    \[ P(A\cap B) = P(A\mid B)P(B) = P(B\mid A)P(A) \]

    这也是贝叶斯定理的来源（把两个表达式相等并整理）。

    不要混淆 P(A|B) 与 P(B|A)

    这是最常见的错误，而且后果可能很严重。

    经典例子（假阳性问题）：

    某疾病患病率 0.1%，检测灵敏度 99%（患病者 99% 检出）， 特异度 99%（健康者 99% 判为阴性）。

    问：检测阳性的人，真正患病的概率是多少？

    很多人答「99%」。实际答案约 9%。

    计算（设 \(D\) = 患病，\(+\) = 阳性）：

    \[ P(D\mid +) = \frac{P(+\mid D)P(D)}{P(+)} \]

    先算分母（全概率）：

    \[ P(+) = P(+\mid D)P(D) + P(+\mid D^c)P(D^c) = 0.99\times0.001 + 0.01\times0.999 = 0.00099 + 0.00999 = 0.01098 \]

    于是

    \[ P(D\mid +) = \frac{0.00099}{0.01098} \approx 0.090 = 9.0\% \]

    为什么这么低：虽然检测很准，但健康人基数极大（999 人）， 其中 1% 的误报（约 10 人）远多于真患者（约 1 人）。

    工程教训：

    直觉 实际
    「检测准确率 99%，阳性就基本确诊」 ✗ 还要看基础患病率

    这解释了：为什么罕见故障的检测需要极高特异度， 以及为什么医疗筛查要做复查。

    四、全概率公式与贝叶斯定理¶

    划分¶

    若 \(B_1,\dots,B_n\) 满足：

    1. 两两互斥：\(B_i\cap B_j = \varnothing\)（\(i\neq j\)）
    2. 完备：\(\bigcup_i B_i = \Omega\)

    则称它们是 \(\Omega\) 的一个划分（把一个整体切成互不重叠的若干块）。

    全概率公式¶

    \[ \boxed{\ P(A) = \sum_{i=1}^{n}P(A\mid B_i)P(B_i)\ } \]

    用途：当直接算 \(P(A)\) 困难，但「按原因分类」后每类都容易算时使用。

    直觉：

    步骤 含义
    按 \(B_i\) 分情况 枚举所有可能的「来源」
    每类算 \(P(A\mid B_i)P(B_i)\) 该类发生且导致 \(A\) 的概率
    求和 所有来源的总概率

    贝叶斯定理¶

    由乘法公式的两种写法相等，立即得到

    \[ \boxed{\ P(B_i\mid A) = \frac{P(A\mid B_i)P(B_i)}{\sum_j P(A\mid B_j)P(B_j)}\ } \]
    术语 名称 含义
    \(P(B_i)\) 先验（prior） 观测前对 \(B_i\) 的信念
    \(P(A\mid B_i)\) 似然（likelihood） 若 \(B_i\) 成立，观测到 \(A\) 的可能
    \(P(B_i\mid A)\) 后验（posterior） 观测到 \(A\) 后对 \(B_i\) 的信念
    分母 \(P(A)\) 证据（evidence） 归一化常数

    「先验 → 似然 → 后验」是工程推理的骨架

    一句话概括：

    \[ \text{后验} \propto \text{似然}\times\text{先验} \]

    工程含义：

    场景 先验 似然 后验
    故障诊断 各故障的发生率 症状在各故障下的出现率 诊断结论
    目标识别 各类目标出现频率 特征在各目标下的分布 识别结果
    状态估计 状态的预测分布 观测模型 修正后的状态
    参数学习 参数的先验分布 数据似然 参数后验

    注意：若先验很「偏」（如患病率极低），即使似然很强， 后验仍可能很小——上文的假阳性例子正是如此。

    五、独立性¶

    定义：若

    \[ P(A\cap B) = P(A)P(B) \]

    则称 \(A\) 与 \(B\) 相互独立。

    等价形式（当 \(P(B) > 0\)）：

    \[ P(A\mid B) = P(A) \]

    含义：知道 \(B\) 发生不改变 \(A\) 的概率。

    多个事件独立：任意子集都满足乘积关系（不只是两两）。

    「两两独立」不蕴含「相互独立」

    这是容易忽略的细节。

    反例（掷两枚硬币，考虑三个事件）：

    • \(A\) = 第一枚正面
    • \(B\) = 第二枚正面
    • \(C\) = 两枚结果相同

    可以验证 \(P(A\cap B) = P(A)P(B)\)、\(P(A\cap C) = P(A)P(C)\)、 \(P(B\cap C) = P(B)P(C)\) —— 两两独立 ✓

    但

    \[ P(A\cap B\cap C) = \frac14 \neq P(A)P(B)P(C) = \frac18 \]

    三者不相互独立 ✗

    原因：一旦知道 \(A\) 与 \(B\) 都发生，\(C\) 必然发生 ——于是 \(C\) 携带了「冗余」信息。

    工程含义：多传感器融合时，若传感器误差两两不相关， 仍可能存在共同的失效模式（导致联合分布偏离独立假设）。

    六、典型例题¶

    例题 1：容斥原理¶

    从 1 到 100 的整数中随机取一个。求它是 2 的倍数或 3 的倍数的概率。

    思路

    用容斥原理，注意 6 的倍数被重复计算了。

    解答

    定义事件：

    • \(A\) = 2 的倍数
    • \(B\) = 3 的倍数

    各自的数量：

    \[ \lvert A\rvert = \left\lfloor\frac{100}{2}\right\rfloor = 50 \]
    \[ \lvert B\rvert = \left\lfloor\frac{100}{3}\right\rfloor = 33 \]

    交集（6 的倍数，需要减去重复计数的部分）：

    \[ \lvert A\cap B\rvert = \left\lfloor\frac{100}{6}\right\rfloor = 16 \]

    容斥原理：

    \[ P(A\cup B) = P(A) + P(B) - P(A\cap B) \]
    \[ = \frac{50}{100} + \frac{33}{100} - \frac{16}{100} = \frac{67}{100} = 0.67 \]

    结果：\(67\%\)

    验证（用补事件）：既不是 2 的倍数也不是 3 的倍数 → 是 \(6k\pm1\) 型的数。

    在 1–100 中，与 6 互质的数（模 6 余 1 或 5）共有

    \[ \left\lfloor\frac{100}{6}\right\rfloor\times2 + 1 = 16\times2+1 = 33 \]

    （每个完整周期 6 贡献 2 个，余下的 97–100 中还有 97 一个。）

    所以

    \[ P = 1 - \frac{33}{100} = \frac{67}{100} \;\checkmark \]

    两者一致。

    例题 2：条件概率的计算¶

    一箱产品中，甲厂生产 60%，乙厂 40%。甲厂次品率 2%，乙厂 3%。

    (a) 随机取一件是次品的概率？

    (b) 若已知取到次品，它来自甲厂的概率？

    思路

    (a) 用全概率公式；(b) 用贝叶斯定理。

    解答

    记号：\(A\) = 甲厂，\(B\) = 乙厂，\(D\) = 次品。

    已知：

    \[ P(A) = 0.6, \quad P(B) = 0.4, \quad P(D\mid A) = 0.02, \quad P(D\mid B) = 0.03 \]

    (a) 全概率公式

    \[ P(D) = P(D\mid A)P(A) + P(D\mid B)P(B) \]
    \[ = 0.02\times0.6 + 0.03\times0.4 = 0.012 + 0.012 = 0.024 \]

    结果：\(2.4\%\)

    (b) 贝叶斯定理

    \[ P(A\mid D) = \frac{P(D\mid A)P(A)}{P(D)} = \frac{0.012}{0.024} = 0.5 \]

    结果：\(50\%\)

    解读：虽然甲厂的次品率更低（2% vs 3%）， 但因为甲厂产量大（60%），所以次品中来自甲厂的比例仍是一半。

    这个结果与直觉不符：容易以为「次品率低的厂占次品比例也低」。 实际上

    \[ \text{贡献} = \text{产量比例}\times\text{次品率} \]

    两个厂恰好相等（\(0.012 = 0.012\)），所以各占一半。

    这类题的通用做法

    画一张表可以避免混乱：

    厂 产量比例 次品率 次品贡献
    甲 0.6 0.02 0.012
    乙 0.4 0.03 0.012
    合计 1.0 —— 0.024

    那么：

    • (a) 的答案 = 合计列 = 0.024
    • (b) 的答案 = 甲的贡献 / 合计 = 0.012 / 0.024 = 0.5

    「贡献 = 比例 × 条件概率」这一列是关键—— 全概率公式就是这一列的求和，贝叶斯定理就是取其中一项再归一化。

    例题 3：假阳性问题（条件概率的方向）¶

    某雷达检测系统：目标存在时检测到信号的概率 0.95； 无目标时误报概率 0.05。目标的先验出现概率为 0.01。

    (a) 检测到信号时，真有目标的概率？

    (b) 若要求后验概率 ≥ 0.5，先验至少需要多大？

    思路

    用贝叶斯定理；(b) 是把先验当未知数解不等式。

    解答

    记号：\(T\) = 有目标，\(S\) = 检测到信号。

    已知：

    \[ P(T) = 0.01, \quad P(S\mid T) = 0.95, \quad P(S\mid T^c) = 0.05 \]

    (a) 贝叶斯定理

    先算证据：

    \[ P(S) = 0.95\times0.01 + 0.05\times0.99 = 0.0095 + 0.0495 = 0.059 \]

    于是

    \[ P(T\mid S) = \frac{0.0095}{0.059} \approx 0.161 = 16.1\% \]

    结果：只有 \(16.1\%\)

    为什么这么低：虽然检测很灵敏（95%）， 但无目标的情形基数极大（99%），其中 5% 的误报 （占总体 \(0.0495\)）远大于真目标的检测（\(0.0095\)）。

    (b) 求所需先验

    设先验 \(P(T) = p\)，则

    \[ P(T\mid S) = \frac{0.95p}{0.95p + 0.05(1-p)} \geq 0.5 \]

    分子分母同乘 20：

    \[ \frac{19p}{19p + (1-p)} \geq 0.5 \]

    即

    \[ \frac{19p}{18p+1} \geq \frac12 \]
    \[ 38p \geq 18p + 1 \implies 20p \geq 1 \implies p \geq 0.05 \]

    结果：先验至少 5%

    解读：先验从 1% 提到 5%（5 倍），后验才达到 50%。

    工程含义：

    手段 作用
    提高检测灵敏度 有限（已 95%，提升空间小）
    降低误报率 有效（但受物理限制）
    提高先验 靠多传感器确认、连续性检验（上一时刻有目标）

    这正是雷达/声纳采用「检测跟踪一体化」的原因： 用历史信息提高先验，而不是只依赖单帧检测。

    这个例子说明了「基础率谬误」

    基础率谬误（base rate fallacy）：忽略先验，只看似然。

    只看似然 加上先验
    「95% 灵敏，所以阳性就是目标」 实际 \(P(T\mid S) = 16\%\)

    在工程中的表现：

    领域 谬误形式
    医疗诊断 罕见病筛查的假阳性泛滥
    缺陷检测 高精度检测但缺陷率极低 → 大量误报
    入侵检测 正常流量基数大 → 告警淹没
    故障诊断 罕见故障的误报

    正确做法：必须把先验纳入计算（贝叶斯思维）。

    例题 4：系统可靠性（独立性应用）¶

    某系统由 3 个独立部件串联组成，各部件可靠度分别为 0.9、0.8、0.95。

    (a) 系统可靠度（需要全部正常）？

    (b) 若改为并联（任一正常即可），可靠度是多少？

    思路

    串联用乘积；并联用补事件。

    解答

    (a) 串联

    系统正常当且仅当三个都正常。由独立性：

    \[ R_{\text{串}} = 0.9\times0.8\times0.95 = 0.684 \]

    结果：\(68.4\%\)

    注意：串联可靠度低于任何一个部件——这是「串联的代价」。

    (b) 并联

    系统正常 = 至少一个正常。用补事件（全部故障）：

    \[ R_{\text{并}} = 1 - (1-0.9)(1-0.8)(1-0.95) \]
    \[ = 1 - 0.1\times0.2\times0.05 = 1 - 0.001 = 0.999 \]

    结果：\(99.9\%\)

    对比：

    结构 可靠度 特点
    串联 \(68.4\%\) 低于最差部件
    并联 \(\mathbf{99.9\%}\) 高于最好部件

    冗余设计的价值与代价

    并联（冗余）能大幅提高可靠度，但代价是：

    代价 说明
    成本 部件数量倍增
    重量/体积 对无人机、卫星很敏感
    复杂度 需要故障切换逻辑
    共因失效 独立假设可能不成立

    关键警告：独立性假设。

    若三个部件是同一批次、同一厂家，它们的失效可能相关：

    情形 实际可靠度
    独立失效 \(99.9\%\)
    完全相关（一起坏） \(90\%\)（等于单部件）

    工程实践：真正的冗余要用不同原理（如惯导 + 卫星 + 视觉）， 而不是同款三份——这就是「多样性冗余」。

    本知识库的信号与系统模块中，「随机信号基础」一节 讲到的「不相关 ≠ 独立」在这里有直接的工程后果。

    八、自测¶

    Q1 掷一颗公平骰子。求掷出偶数或大于 4 的概率。

    提示

    用容斥原理，注意 6 被重复计算。

    解答

    定义事件：

    • \(A\) = 偶数 = \(\{2,4,6\}\)
    • \(B\) = 大于 4 = \(\{5,6\}\)

    各自的概率：

    \[ P(A) = \frac36,\qquad P(B) = \frac26 \]

    交集：

    \[ A\cap B = \{6\} \implies P(A\cap B) = \frac16 \]

    容斥原理：

    \[ P(A\cup B) = \frac36+\frac26-\frac16 = \frac46 = \frac23 \]

    结果：\(\dfrac23 \approx 66.7\%\)

    直接枚举验证：\(A\cup B = \{2,4,5,6\}\) —— 共 4 个 ✓

    \[ P = \frac46 = \frac23 \;\checkmark \]

    注意「互斥」与「独立」的区别：

    \(A\) 与 \(B\) 不互斥（都含 6）✓ 也不独立：

    \[ P(A\cap B) = \frac16 \neq P(A)P(B) = \frac36\times\frac26 = \frac16 \]

    等一下 —— 这里恰好相等！ 验证：

    \[ \frac36\times\frac26 = \frac{6}{36} = \frac16 \;\checkmark \]

    所以本例中 \(A\) 与 \(B\) 恰好独立（尽管看起来不显然）。

    这是巧合（骰子结构造成的），不是普遍规律 ✓

    Q2 某疾病患病率 0.5%，检测灵敏度 98%，特异度 97%。 求检测阳性者真正患病的概率。

    提示

    用贝叶斯定理；注意健康人基数极大。

    解答

    记号：\(D\) = 患病，\(+\) = 阳性。

    已知：

    \[ P(D) = 0.005,\qquad P(+\mid D) = 0.98,\qquad P(+\mid D^c) = 0.03 \]

    第一步：证据（全概率公式）

    \[ P(+) = 0.98\times0.005+0.03\times0.995 = 0.0049+0.02985 = 0.03475 \]

    第二步：贝叶斯定理

    \[ P(D\mid +) = \frac{0.0049}{0.03475} \approx 0.141 = 14.1\% \]

    结果：约 \(14.1\%\)

    解读：即使检测灵敏度高达 98%，阳性者真正患病的概率只有 14% —— 因为健康人基数太大（99.5%），其中 3% 的误报 （占总体 \(0.02985\)）远多于真患者的检出（\(0.0049\)）✓

    对比：

    项 值 占比
    真患者被检出 \(0.0049\) \(14.1\%\)
    健康人误报 \(0.02985\) \(85.9\%\)

    工程含义：筛查罕见问题必须用高特异度 —— 灵敏度再高也抵不过基数效应 ✗

    若想提高后验：

    手段 说明
    提高特异度 最有效（减少误报）
    复查 第二次检测 → 用第一次的结果作先验
    提高先验 先筛查高风险人群（提高 \(P(D)\)）

    Q3 三个独立部件，可靠度分别为 0.95、0.9、0.99。 求「串联」与「并联」两种结构的系统可靠度。

    提示

    串联用乘积，并联用补事件。

    解答

    串联（需全部正常）：

    \[ R_{\text{串}} = 0.95\times0.9\times0.99 = 0.84645 \]

    结果：约 \(84.6\%\)

    并联（任一正常即可）：

    \[ R_{\text{并}} = 1-(1-0.95)(1-0.9)(1-0.99) \]
    \[ = 1-0.05\times0.1\times0.01 = 1-0.00005 = 0.99995 \]

    结果：约 \(99.995\%\)

    对比：

    结构 可靠度
    串联 \(84.6\%\)
    并联 \(99.995\%\)

    并联大幅提升可靠度（从 \(84.6\%\) 到 \(99.995\%\)）✓

    但必须检查独立性假设：

    情形 实际可靠度
    独立失效 \(99.995\%\)
    共因失效（一起坏） \(95\%\)（等于最差部件）✗

    工程实践：真正的冗余要用不同原理（如惯导 + 卫星 + 视觉）， 而不是同款三份 ✓

    这也解释了为什么「三余度」设计在航空中常用： 若独立性成立，可靠度极高；但设计要求故障模式不同。

    Q4 判断：若 \(P(A\cap B) = 0\)，则 \(A\) 与 \(B\) 独立。

    提示

    想想「互斥」与「独立」的定义差别。

    解答

    不对。\(P(A\cap B) = 0\) 意味着互斥，而互斥通常不独立。

    定义对比：

    概念 定义
    互斥 \(A\cap B = \varnothing\)（即 \(P(A\cap B) = 0\)）
    独立 \(P(A\cap B) = P(A)P(B)\)

    反例：掷骰子，\(A\) = 偶数、\(B\) = 奇数。

    \[ P(A\cap B) = 0 \quad\text{（互斥）} \]

    但：

    \[ P(A)P(B) = \frac12\times\frac12 = \frac14 \neq 0 \]

    所以不独立 ✗

    直觉理解：互斥是「负相关」的极端 —— 知道 \(A\) 发生就确定 \(B\) 不发生，信息量极大 ✓

    关系总结：

    关系 是否成立
    独立 \(\Rightarrow\) 互斥 ✗
    互斥 \(\Rightarrow\) 独立 ✗
    仅有特例：\(P(A) = 0\) 或 \(P(B) = 0\) 此时两者都成立（平凡情形）

    工程含义：

    场景 该用哪个概念
    「同一时刻只能坏一个」 互斥
    「一个坏了不影响另一个的失效概率」 独立
    冗余设计 希望独立（但物理上常是「共因」相关）✗

    危险情形：把「互斥」误当成「独立」→ 会严重低估联合事件的概率 ✗
