    最大似然估计¶

    前面几页都假设「分布已知」。这一页回答：

    给定数据，怎么反过来求分布的参数？

    最常用的答案是最大似然估计（MLE）——而且它与你熟悉的 交叉熵损失是同一件事。

    为什么这一页对机器学习特别重要

    你以为的 实际上的
    「交叉熵损失是设计出来的」 它就是负对数似然
    「为什么用 MSE 回归」 高斯噪声下的 MLE
    「为什么用交叉熵分类」 伯努利/多项分布的 MLE

    理解了 MLE，损失函数就都有来源了。

    一、似然函数¶

    设定：数据 \(\boldsymbol{x} = (x_1,\dots,x_n)\) 独立同分布， 来自分布 \(f(x;\theta)\)，其中 \(\theta\) 是未知参数。

    似然函数：

    \[ L(\theta) = \prod_{i=1}^{n}f(x_i;\theta) \]

    关键的概念转变：

    视角 固定什么 变化什么 名称
    概率 \(\theta\) \(x\) \(f(x;\theta)\)
    似然 \(\boldsymbol{x}\) \(\theta\) \(L(\theta)\)

    MLE：找使似然最大的参数

    \[ \hat\theta_{\text{MLE}} = \arg\max_\theta L(\theta) \]

    似然的直观含义

    「哪个参数值最可能产生我看到的这组数据？」

    举例：抛硬币 10 次得到 7 次正面。

    • 若 \(\theta = 0.7\) → 出现这个结果的概率较高
    • 若 \(\theta = 0.1\) → 出现这个结果的概率极低
    • 所以 \(\theta = 0.7\) 更「像」真值

    MLE 就是在所有可能的 \(\theta\) 中挑「最像」的那个。

    注意因果方向是反的：

    方向 问题
    概率（正向） 已知 \(\theta\)，数据多可能？
    似然（反向） 已知数据，哪个 \(\theta\) 更可能？

    为什么取对数¶

    \[ \ell(\theta) = \log L(\theta) = \sum_{i=1}^{n}\log f(x_i;\theta) \]

    好处：

    好处 说明
    乘积变求和 便于求导
    数值稳定 避免 \(n\) 个小概率连乘下溢为 0
    不改变极值位置 \(\log\) 单调递增

    下溢问题很实际：若每个 \(f \approx 0.01\)，\(n = 100\) 时 \(L \approx 10^{-200}\) ——已超出浮点数下限。取对数后变成 \(-460\)，完全安全。

    二、求解步骤¶

    标准流程：

    步骤 操作
    1 写出似然 \(L(\theta) = \prod_i f(x_i;\theta)\)
    2 取对数得 \(\ell(\theta)\)
    3 对 \(\theta\) 求导，令导数为零
    4 解方程得 \(\hat\theta\)
    5 验证是最大值（二阶导数为负，或边界检查）

    第 5 步不能省

    令导数为零只给出驻点，可能是极大、极小或鞍点。

    检查方法：

    方法 操作
    二阶导 \(\ell''(\hat\theta) < 0\)（单参数）
    Hessian 负定 多参数
    边界检查 参数有范围限制时（如 \(0<p<1\)）单独查端点
    实际代入 比较几个点的似然值

    边界情形很常见：例如伯努利参数的 MLE 可能是 \(\hat p = 0\) 或 \(1\) （当数据全为失败或全为成功）——这是边界解，不是驻点。

    三、三个经典结果¶

    这三个结果是机器学习损失函数的来源。

    结果 1：伯努利 → 频率估计¶

    若 \(x_i\in\{0,1\}\) 且 \(P(x_i = 1) = p\)，则

    \[ \hat p_{\text{MLE}} = \frac{1}{n}\sum_{i=1}^{n}x_i = \frac{\text{成功次数}}{n} \]

    就是「频率」 —— 这符合直觉。

    结果 2：高斯 → 样本均值与方差¶

    若 \(x_i\sim N(\mu,\sigma^2)\)，则

    \[ \hat\mu_{\text{MLE}} = \frac1n\sum_i x_i \qquad\text{（样本均值）} \]
    \[ \hat\sigma^2_{\text{MLE}} = \frac1n\sum_i(x_i-\hat\mu)^2 \qquad\text{（注意除以 }n\text{）} \]

    MLE 的方差估计是有偏的

    \[ E\left[\hat\sigma^2_{\text{MLE}}\right] = \frac{n-1}{n}\sigma^2 < \sigma^2 \]

    它系统性偏小。

    修正（无偏估计）：除以 \(n-1\) 而非 \(n\)：

    \[ s^2 = \frac{1}{n-1}\sum_i(x_i-\bar x)^2 \]

    为什么除以 \(n-1\)：因为 \(\bar x\) 本身是从数据估计的， 消耗了「一个自由度」。用 \(\bar x\) 代替真值 \(\mu\) 会让 \(\sum(x_i-\bar x)^2\) 偏小。

    直观理解：用样本均值代替真均值时， 数据「更靠近」样本均值（它就是为此而选的），所以平方和偏小。

    样本量 偏差比例
    \(n=10\) 偏小 \(10\%\)
    \(n=100\) 偏小 \(1\%\)
    \(n\to\infty\) 偏差消失

    实践建议：小样本时用 \(n-1\)；大样本时区别可忽略。 （但软件库的行为要确认——有些默认 \(n\)。）

    结果 3：多元高斯 → 样本均值与协方差¶

    \[ \hat{\boldsymbol{\mu}} = \frac1n\sum_i\boldsymbol{x}_i, \qquad \hat\Sigma = \frac1n\sum_i(\boldsymbol{x}_i-\hat{\boldsymbol{\mu}})(\boldsymbol{x}_i-\hat{\boldsymbol{\mu}})^\top \]

    这就是模式识别中「用数据估计高斯模型」的做法。

    四、MLE = 最小化负对数似然¶

    这是与机器学习对接的关键。

    \[ \hat\theta_{\text{MLE}} = \arg\max_\theta\ell(\theta) = \arg\min_\theta\big[-\ell(\theta)\big] \]

    所以「最大化似然」等价于「最小化负对数似然（NLL）」。

    常见损失函数都是 NLL（这是本节最重要的认识）

    情形 1：回归 → MSE

    假设 \(y_i = f(\boldsymbol{x}_i) + \epsilon_i\)，\(\epsilon_i\sim N(0,\sigma^2)\)， 则 \(y_i\sim N(f(\boldsymbol{x}_i),\sigma^2)\)。

    负对数似然（忽略常数）：

    \[ -\ell = \frac{1}{2\sigma^2}\sum_i\big(y_i - f(\boldsymbol{x}_i)\big)^2 \]

    这就是均方误差（MSE） ✓

    含义：用 MSE 做回归 = 假设噪声是高斯。

    情形 2：二分类 → 二元交叉熵

    \(y_i\in\{0,1\}\)，\(P(y_i = 1) = \hat p_i\)，负对数似然：

    \[ -\ell = -\sum_i\Big[y_i\log\hat p_i + (1-y_i)\log(1-\hat p_i)\Big] \]

    这就是二元交叉熵 ✓

    情形 3：多分类 → 交叉熵

    \(y_i\) 是 one-hot，\(\hat{\boldsymbol{p}}_i\) 是 softmax 输出：

    \[ -\ell = -\sum_i\sum_{c}y_{ic}\log\hat p_{ic} \]

    这就是交叉熵 ✓

    总表：

    任务 噪声/分布假设 损失函数
    回归 高斯噪声 MSE
    二分类 伯努利 二元交叉熵
    多分类 多项分布 交叉熵
    计数回归 泊松 泊松损失
    鲁棒回归 拉普拉斯噪声 MAE（L1 损失）

    最后一行值得注意：拉普拉斯噪声 → 负对数似然是 \(-\ell \propto \sum\lvert y_i-\hat y_i\rvert\) = MAE。

    所以「用 MAE 而非 MSE」等价于「假设噪声是拉普拉斯而非高斯」 ——而拉普拉斯分布尾部更厚，所以 MAE 对离群点更鲁棒 ✓

    五、MLE 的性质¶

    性质 说明
    一致性 \(n\to\infty\) 时 \(\hat\theta\to\theta_{\text{真}}\)（概率收敛）
    渐近正态 \(\hat\theta\) 近似服从正态分布
    渐近有效 达到克拉美-罗下界（方差最小）
    不变性 若 \(\hat\theta\) 是 \(\theta\) 的 MLE，则 \(g(\hat\theta)\) 是 \(g(\theta)\) 的 MLE
    可能有偏 有限样本下有偏（如方差估计）

    「渐近有效」的含义与克拉美-罗下界

    克拉美-罗下界（CRLB）：任何无偏估计的方差都不能低于

    \[ \operatorname{Var}[\hat\theta] \geq \frac{1}{I(\theta)} \]

    其中 \(I(\theta)\) 是费舍尔信息量：

    \[ I(\theta) = -E\left[\frac{\partial^2\ell}{\partial\theta^2}\right] \]

    直觉：对数似然的曲率越大（峰越尖），信息越多，估计越准。

    这与图 1 的直观一致：峰越尖 → 参数越确定。

    MLE 在 \(n\to\infty\) 时达到该下界 —— 所以它「渐近最优」。

    工程意义：

    用途 说明
    评估估计器性能 与 CRLB 比较看离最优还有多远
    设计实验 提高 \(I(\theta)\)（如增加样本、改善条件）可提升精度
    理论下界 任何算法都不可能更好（无偏前提下）

    六、典型例题¶

    例题 1：伯努利参数的 MLE¶

    抛硬币 \(n\) 次，\(k\) 次正面。求 \(p\) 的 MLE。

    思路

    写出似然，取对数，求导令零。

    解答

    第一步：写出似然

    每次结果 \(x_i\in\{0,1\}\)，概率为 \(p^{x_i}(1-p)^{1-x_i}\)。

    独立同分布 → 似然为

    \[ L(p) = \prod_{i=1}^{n}p^{x_i}(1-p)^{1-x_i} = p^{k}(1-p)^{n-k} \]

    （因为乘积中 \(p\) 的指数累加为正面次数 \(k\)。）

    第二步：取对数

    \[ \ell(p) = k\log p + (n-k)\log(1-p) \]

    第三步：求导令零

    \[ \frac{\mathrm{d}\ell}{\mathrm{d}p} = \frac{k}{p} - \frac{n-k}{1-p} = 0 \]

    整理：

    \[ k(1-p) = (n-k)p \]
    \[ k - kp = np - kp \]
    \[ k = np \implies p = \frac{k}{n} \]

    第四步：验证是最大值

    二阶导数：

    \[ \ell''(p) = -\frac{k}{p^2} - \frac{n-k}{(1-p)^2} < 0 \]

    恒为负 ✓ 所以是最大值。

    结果：

    \[ \boxed{\ \hat p_{\text{MLE}} = \frac{k}{n}\ } \]

    就是频率 ✓ 例如 \(k=7\)、\(n=10\) 时 \(\hat p = 0.7\)。

    注意边界情形（这一步很容易漏）

    二阶导为负只在 \(0 < p < 1\) 内部成立。 若 \(k = 0\) 或 \(k = n\)，驻点可能在边界上：

    情形 \(\hat p_{\text{MLE}}\) 说明
    \(k = 0\)（全失败） \(0\) 导数为 \(-\frac{n}{1-p} < 0\)，\(\ell\) 单调递减 → 最大在 \(p\to0^+\)
    \(k = n\)（全成功） \(1\) 导数为 \(\frac{n}{p} > 0\)，\(\ell\) 单调递增 → 最大在 \(p\to1^-\)

    这两个边界解在工程中很危险：

    问题 后果
    \(\hat p = 0\) 断言「不可能成功」
    \(\hat p = 1\) 断言「必然成功」
    用于对数似然 \(\log 0 = -\infty\) → 数值崩溃

    这正是「贝叶斯定理」一页讲的零概率问题的第二个例子—— 解决办法也一样：加先验（贝叶斯平滑）或拉普拉斯平滑。

    例：\(k=0\)、\(n=5\) 时用 \(\text{Beta}(1,1)\) 先验， 后验均值 \(\frac{1}{7} \approx 0.143\)，而不是 \(0\)。

    例题 2：高斯参数的 MLE¶

    设 \(x_1,\dots,x_n\) 独立同分布，来自 \(N(\mu,\sigma^2)\)。 求 \(\mu\) 与 \(\sigma^2\) 的 MLE。

    思路

    对数似然含 \(n\) 项求和；对两个参数分别求偏导。

    解答

    第一步：写出对数似然

    单个样本的对数密度：

    \[ \log f(x_i) = -\frac12\log(2\pi) - \frac12\log\sigma^2 - \frac{(x_i-\mu)^2}{2\sigma^2} \]

    求和：

    \[ \ell(\mu,\sigma^2) = -\frac{n}{2}\log(2\pi) - \frac{n}{2}\log\sigma^2 - \frac{1}{2\sigma^2}\sum_{i=1}^{n}(x_i-\mu)^2 \]

    第二步：对 \(\mu\) 求偏导

    只有最后一项依赖 \(\mu\)：

    \[ \frac{\partial\ell}{\partial\mu} = -\frac{1}{2\sigma^2}\cdot2\sum_i(x_i-\mu)(-1) = \frac{1}{\sigma^2}\sum_i(x_i-\mu) \]

    令其为零（\(\sigma^2 > 0\) 时可约去）：

    \[ \sum_i(x_i-\mu) = 0 \implies \sum_i x_i = n\mu \]
    \[ \boxed{\ \hat\mu = \frac1n\sum_{i=1}^{n}x_i = \bar x\ } \]

    就是样本均值 ✓

    第三步：对 \(\sigma^2\) 求偏导

    记 \(S = \sum_i(x_i-\hat\mu)^2\)（在 \(\hat\mu\) 处取值），则

    \[ \frac{\partial\ell}{\partial\sigma^2} = -\frac{n}{2\sigma^2} + \frac{S}{2\sigma^4} \]

    令其为零，两边乘 \(2\sigma^4\)：

    \[ -n\sigma^2 + S = 0 \]
    \[ \boxed{\ \hat\sigma^2 = \frac{1}{n}\sum_{i=1}^{n}(x_i-\bar x)^2\ } \]

    注意是除以 \(n\)，不是 \(n-1\) ✓

    第四步：验证是最大值

    Hessian 的对角元：

    \[ \frac{\partial^2\ell}{\partial\mu^2} = -\frac{n}{\sigma^2} < 0 \;\checkmark \]
    \[ \frac{\partial^2\ell}{\partial(\sigma^2)^2} = \frac{n}{2\sigma^4} - \frac{S}{\sigma^6} = \frac{n}{2\sigma^4} - \frac{n\sigma^2}{\sigma^6}\bigg|_{\hat\sigma^2} = \frac{n}{2\sigma^4} - \frac{n}{\sigma^4} = -\frac{n}{2\sigma^4} < 0 \;\checkmark \]

    （代入了 \(S = n\hat\sigma^2\)。）

    所以是局部极大 ✓

    MLE 的方差是有偏的（这是 MLE 的著名缺陷）

    偏差计算：

    \[ E\left[\sum_i(x_i-\bar x)^2\right] = (n-1)\sigma^2 \]

    （这是统计学的基本结果：样本方差的「未修正」形式期望为 \((n-1)\sigma^2\)。）

    所以

    \[ E[\hat\sigma^2_{\text{MLE}}] = \frac{n-1}{n}\sigma^2 < \sigma^2 \]

    系统性地偏小 ✓

    修正（无偏估计）：

    \[ s^2 = \frac{1}{n-1}\sum_i(x_i-\bar x)^2 \]

    偏差的比例 \(\frac{1}{n}\)：

    \(n\) 偏差
    \(2\) \(50\%\)（严重！）
    \(5\) \(20\%\)
    \(10\) \(10\%\)
    \(100\) \(1\%\)
    \(10000\) \(0.01\%\)

    为什么会有偏差：因为 \(\bar x\) 是在同一批数据上算的， 数据「更靠近」自己的均值，导致平方和偏小。

    工程取向：

    场合 用哪个
    小样本 \(n-1\)（无偏）
    大样本 差别可忽略
    需要 MLE 的理论性质 \(n\)（保持一致）

    注意：MLE 有偏但一致（\(n\to\infty\) 时偏差消失）， 且具备渐近有效性——所以在机器学习中通常直接用 \(n\)。

    例题 3：从 MLE 推出 MSE 损失¶

    证明：在高斯噪声假设下，最大化似然等价于最小化均方误差。

    思路

    写出 \(y_i\) 的分布，取负对数似然，看剩下什么。

    解答

    第一步：设定模型

    设目标与预测的关系为

    \[ y_i = f(\boldsymbol{x}_i;\theta) + \epsilon_i, \qquad \epsilon_i\sim N(0,\sigma^2) \]

    独立同分布。

    第二步：写出 \(y_i\) 的分布

    加高斯噪声不改变均值、只平移方差：

    \[ y_i\sim N\big(f(\boldsymbol{x}_i;\theta),\ \sigma^2\big) \]

    密度：

    \[ f(y_i) = \frac{1}{\sqrt{2\pi}\sigma}\exp\left(-\frac{(y_i-f(\boldsymbol{x}_i;\theta))^2}{2\sigma^2}\right) \]

    第三步：对数似然

    \[ \ell(\theta) = \sum_i\left[-\frac12\log(2\pi) - \log\sigma - \frac{(y_i-f(\boldsymbol{x}_i;\theta))^2}{2\sigma^2}\right] \]

    第四步：分离出与 \(\theta\) 无关的部分

    \[ \ell(\theta) = -\frac{n}{2}\log(2\pi) - n\log\sigma - \frac{1}{2\sigma^2}\sum_i\big(y_i-f(\boldsymbol{x}_i;\theta)\big)^2 \]

    前两项不含 \(\theta\) → 最大化 \(\ell\) 只需

    \[ \max_\theta\left[-\frac{1}{2\sigma^2}\sum_i\big(y_i-f(\boldsymbol{x}_i;\theta)\big)^2\right] \]

    即

    \[ \min_\theta\sum_i\big(y_i-f(\boldsymbol{x}_i;\theta)\big)^2 \]

    这就是 MSE ✓

    这个推导的三个重要推论

    推论 1：为什么回归用平方误差

    \[ \text{高斯噪声假设} \iff \text{MSE 损失} \]

    不是随意选的，而是有概率依据的。

    推论 2：\(\sigma^2\) 不影响最优参数

    注意 \(\frac{1}{2\sigma^2}\) 是正的比例常数—— 它不改变极值位置。

    含义：噪声大小不影响最优模型（只影响我们对估计的置信度）。

    这一点很实用：训练时不必知道噪声方差。

    推论 3：\(\sigma^2\) 可以事后估计

    在最优 \(\theta\) 处，令 \(\partial\ell/\partial\sigma = 0\) 可得

    \[ \hat\sigma^2 = \frac1n\sum_i\big(y_i-f(\boldsymbol{x}_i;\hat\theta)\big)^2 \]

    就是残差的均方 —— 这正是「训练完后看残差估计噪声水平」的依据。

    工程用途：用残差方差评估模型质量、构造预测区间。

    MSE 的隐含代价：对离群点敏感

    因为高斯噪声的尾部薄（\(e^{-z^2/2}\) 衰减极快）， MSE 隐含假设「大误差极少见」。

    若实际有大离群点：

    后果 说明
    离群点产生平方级的巨大惩罚 主导整个损失
    模型被「拉偏」 为拟合离群点牺牲正常样本

    对策（换个噪声假设）：

    假设 损失 特点
    高斯 MSE（平方） 对离群点敏感
    拉普拉斯 MAE（绝对值） 鲁棒 ✓
    Huber 小误差平方 + 大误差线性 折中

    Huber 损失的思路：小误差时像 MSE（光滑可导）， 大误差时像 MAE（不被离群点主导）——综合两者优点。

    例题 4：指数分布的 MLE（含参数变换）¶

    设 \(x_1,\dots,x_n\) 独立同分布，来自 \(\text{Exp}(\lambda)\)。 求 \(\lambda\) 的 MLE，并检验 MLE 的不变性。

    思路

    写出似然（指数密度是 \(\lambda e^{-\lambda x}\)），求导；再用不变性求 \(1/\lambda\) 的 MLE。

    解答

    第一步：对数似然

    \[ \ell(\lambda) = \sum_{i=1}^{n}\log\left(\lambda e^{-\lambda x_i}\right) = n\log\lambda - \lambda\sum_{i=1}^{n}x_i \]

    第二步：求导令零

    \[ \frac{\mathrm{d}\ell}{\mathrm{d}\lambda} = \frac{n}{\lambda} - \sum_i x_i = 0 \]
    \[ \boxed{\ \hat\lambda_{\text{MLE}} = \frac{n}{\sum_i x_i} = \frac{1}{\bar x}\ } \]

    就是样本均值的倒数 ✓

    第三步：验证是最大值

    \[ \ell''(\lambda) = -\frac{n}{\lambda^2} < 0 \;\checkmark \]

    恒为负 ✓

    第四步：检验不变性

    指数分布的均值是 \(1/\lambda\)。由 MLE 的不变性：

    \[ \widehat{(1/\lambda)}_{\text{MLE}} = \frac{1}{\hat\lambda} = \bar x \]

    即均值的 MLE 就是样本均值 ✓ 与直觉一致。

    MLE 不变性的实用价值

    定理：若 \(\hat\theta\) 是 \(\theta\) 的 MLE， 则对任意函数 \(g\)（不必是单调的！），\(g(\hat\theta)\) 是 \(g(\theta)\) 的 MLE。

    用途：

    想估计 做法
    \(\lambda\) 直接求 MLE
    \(1/\lambda\)（均值） 直接取倒数（不需重新求导）
    \(\lambda^2\) 取平方
    \(\log\lambda\) 取对数

    这省掉了大量重复推导——不必每换一个量就重做一遍优化。

    注意：不变性对 MLE 成立，但对无偏性不成立：

    \[ E[g(\hat\theta)] \neq g(E[\hat\theta]) \]

    （除非 \(g\) 是线性的。）

    例：\(1/\hat\lambda\) 是 \(1/\lambda\) 的 MLE， 但不是无偏估计（因为倒数是非线性运算）：

    \[ E\left[\frac{1}{\hat\lambda}\right] \neq \frac{1}{\lambda} \]

    工程含义：优化目标和评价指标可以是同一个量（都用 MLE）， 但若要求「无偏」，需要额外修正。

    七、用在哪些课程里¶

    模式识别 · 训练目标的理论依据¶

    • 所有监督学习的损失函数都是某种分布假设下的 NLL
    • 高斯判别分析：用 MLE 估计各类的均值与协方差
    • GMM：用 EM 算法做 MLE（有隐变量时的推广）
    • 逻辑回归：伯努利 NLL（即交叉熵）

    智能传感与信息处理 · 参数标定¶

    • 传感器标定：由测量数据估计模型参数（MLE）
    • 噪声参数估计：从残差估计噪声方差
    • 可靠性分析：由故障数据估计寿命分布参数

    现代数字信号处理 · 信号参数估计¶

    • 频率/相位估计：MLE 是理论最优（渐近有效）
    • 阵列处理：DOA 估计的 ML 方法
    • 与 CRLB 比较：判断估计算法是否接近最优

    海洋声学 · 声源参数估计¶

    • 声源定位：由阵列数据估计方向（MLE/MAP）
    • 信道参数估计：多径时延与幅度
    • 模型选择：用似然比较不同模型（AIC/BIC 基于似然）

    八、自测¶

    Q1 某试验做了 20 次，成功 15 次。求成功率的 MLE。

    提示

    伯努利的 MLE 就是频率。

    解答
    \[ \hat p_{\text{MLE}} = \frac{k}{n} = \frac{15}{20} = 0.75 \]

    结果：\(0.75\)

    验证（用对数似然比较几个候选值）：

    \(p\) 对数似然 \(15\log p + 5\log(1-p)\)
    \(0.60\) \(-12.24\)
    \(0.70\) \(-11.37\)
    \(0.75\) \(-11.25\)（最大）
    \(0.80\) \(-11.39\)
    \(0.90\) \(-13.09\)

    \(0.75\) 处最大 ✓ 与 \(0.8\) 很接近，但确实更优。

    注意曲率（这是判断估计精度的关键）：

    \(0.7\) 与 \(0.8\) 处的对数似然只差

    \[ \lvert-11.37 - (-11.39)\rvert = 0.02 \]

    非常平坦 —— 说明 20 个样本信息量有限， \(\hat p\) 的不确定性较大。

    这与费舍尔信息直接相关：曲率越大（峰越尖），估计越精确。 伯努利的费舍尔信息是

    \[ I(p) = \frac{n}{p(1-p)} \]

    在 \(p = 0.75\) 处：\(I = \frac{20}{0.75\times0.25} \approx 106.7\)， 对应的克拉美-罗下界（最小可能方差）是

    \[ \frac{1}{I} = \frac{1}{106.7} \approx 0.0094 \]

    即 \(\hat p\) 的标准差约 \(\sqrt{0.0094} \approx 0.097\) —— 接近 0.1，说明 20 个样本给出的估计精度有限。

    Q2 设数据 \(\{2, 4, 6, 8\}\)，假设来自 \(N(\mu,\sigma^2)\)。 求 \(\mu\) 与 \(\sigma^2\) 的 MLE 与无偏估计。

    提示

    MLE 除以 \(n\)，无偏除以 \(n-1\)。

    解答

    样本均值：

    \[ \bar x = \frac{2+4+6+8}{4} = \frac{20}{4} = 5 \]
    \[ \hat\mu = 5 \]

    偏差平方和：

    \(x_i\) \(x_i-5\) 平方
    2 \(-3\) 9
    4 \(-1\) 1
    6 \(1\) 1
    8 \(3\) 9
    \[ \sum(x_i-\bar x)^2 = 9+1+1+9 = 20 \]

    MLE（除以 \(n=4\)）：

    \[ \hat\sigma^2_{\text{MLE}} = \frac{20}{4} = 5 \]

    无偏估计（除以 \(n-1=3\)）：

    \[ s^2 = \frac{20}{3} \approx 6.667 \]

    结果：\(\hat\sigma^2_{\text{MLE}} = 5\)，\(s^2 \approx 6.67\)

    对比：

    估计 值 偏差
    MLE \(5\) 系统性偏小
    无偏 \(6.67\) 无偏

    偏差比例：\(\frac{1}{n} = 25\%\) —— 小样本时偏差很显著 ✓

    这提醒我们：\(n=4\) 时用 MLE 的方差会低估 25%， 做置信区间或风险评估时会过于自信。

    Q3 为什么 MLE 里要取对数，而不直接最大化似然？

    提示

    考虑数值范围与求导难度。

    解答

    两个原因：数值稳定与求导方便。

    原因 1：避免数值下溢（工程上最关键）

    似然是乘积：

    \[ L = \prod_{i=1}^{n}f(x_i) \]

    取 \(f \approx 0.01\)、\(n = 200\)：

    \[ L \approx 10^{-400} \]

    这已超出双精度浮点数的下限（约 \(10^{-308}\)）→ 变为 0。

    取对数后：

    \[ \ell = \sum_i\log f(x_i) = 200\times(-4.6) = -920 \]

    完全在浮点范围内 ✓

    原因 2：乘积的导数很麻烦

    形式 求导
    \(L = \prod_i f_i\) 要用乘积法则 \(n\) 次，产生 \(n\) 项
    \(\ell = \sum_i\log f_i\) 逐项求导再相加，简单 ✓

    原因 3：与优化算法兼容

    梯度下降、牛顿法等需要可加的损失函数：

    \[ \text{损失} = \sum_i\text{（单样本损失）} \]

    这正是「小批量（mini-batch）」训练的基础—— 可以用一部分样本估计整个数据集的梯度。

    正确性保证：\(\log\) 是严格单调递增函数，所以

    \[ \arg\max L = \arg\max\log L \]

    极值位置完全不变 ✓

    Q4 若假设噪声服从拉普拉斯分布（而非高斯），MLE 对应什么损失函数？

    提示

    拉普拉斯密度含 \(\exp(-|x-\mu|/b)\)。

    解答

    对应 MAE（平均绝对误差）。

    推导：

    拉普拉斯分布的密度：

    \[ f(y) = \frac{1}{2b}\exp\left(-\frac{\lvert y-\mu\rvert}{b}\right) \]

    负对数似然（单个样本）：

    \[ -\log f(y) = \log(2b) + \frac{\lvert y-\mu\rvert}{b} \]

    对所有样本求和，去掉与 \(\theta\) 无关的常数：

    \[ \text{NLL} \propto \sum_i\lvert y_i - f(\boldsymbol{x}_i;\theta)\rvert \]

    这就是 MAE ✓

    为什么 MAE 更鲁棒（关键洞察）：

    损失 梯度 对离群点的反应
    MSE \(\propto\lvert e\rvert\) 误差越大，梯度线性增长 → 离群点主导
    MAE \(\propto\text{sign}(e)\) 梯度恒定（±1）→ 离群点影响有限

    定量对比：一个误差为 10 的离群点

    损失 贡献
    MSE \(100\)（相对误差=1 的样本大 100 倍）
    MAE \(10\)（只大 10 倍）

    所以 MAE 不会被少数极端点带偏 ✓

    概率上的解释（一句话总结）：

    \[ \text{MAE 鲁棒} \iff \text{拉普拉斯噪声尾部更厚} \iff \text{大误差更常见} \]

    因为拉普拉斯假设「大误差本来就常见」，所以它不会把大误差 当成异常而过度反应 —— 这就是鲁棒性的来源。

    实践建议：

    数据情况 选择
    干净、噪声近似高斯 MSE（更高效）
    含离群点 MAE 或 Huber（更鲁棒）
    不确定 Huber（折中）

    高斯分布
    下一页
