    高斯分布¶

    工程中几乎所有「噪声」都被建模为高斯分布。这不是巧合，而是中心极限定理的后果。

    大量独立小因素的叠加，结果趋于高斯分布。

    这一页讲清楚三件事：为什么它无处不在、多维情形怎么算、 为什么卡尔曼滤波建立在它之上。

    为什么必须彻底搞懂高斯分布

    领域 高斯的角色
    测量误差 建模为标准高斯
    卡尔曼滤波 假设状态与噪声都是高斯
    模式识别 高斯判别分析、GMM
    信号处理 高斯白噪声、匹配滤波
    海洋声学 环境噪声近似高斯

    高斯是「默认假设」——理解它的性质（尤其多维情形） 是读懂后续大部分算法的前提。

    一、一维高斯分布¶

    密度函数：

    \[ f(x) = \frac{1}{\sqrt{2\pi}\sigma}\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right) \]

    记作 \(X\sim N(\mu,\sigma^2)\)。

    两个参数就是全部信息：

    参数 含义 作用
    \(\mu\) 均值 决定位置（峰在哪）
    \(\sigma^2\) 方差 决定宽度（多分散）

    为什么密度函数里有那个奇怪的系数

    \[ \frac{1}{\sqrt{2\pi}\sigma} \]

    它是为了归一化：让

    \[ \int_{-\infty}^{\infty}f(x)\mathrm{d}x = 1 \]

    这个积分是高斯积分：

    \[ \int_{-\infty}^{\infty}e^{-x^2/2}\mathrm{d}x = \sqrt{2\pi} \]

    这个 \(\sqrt{2\pi}\) 无法用初等函数求出， 必须用二重积分技巧（极坐标）或数值方法。

    工程含义：正态的 CDF 没有初等表达式—— 这就是需要查表或用 \(\operatorname{erf}\) 函数的原因 （也让「逆变换采样」不可行，回到随机变量那一页的结论）。

    标准正态分布¶

    \[ Z = \frac{X-\mu}{\sigma} \sim N(0,1) \]

    标准化把任何高斯变到标准形式，于是只需一张表。

    3σ 法则（用在工程判断）¶

    区间 概率
    \(\mu\pm\sigma\) \(68.27\%\)
    \(\mu\pm2\sigma\) \(95.45\%\)
    \(\mu\pm3\sigma\) \(99.73\%\)
    \(\mu\pm6\sigma\) \(99.9999998\%\)

    工程经验：

    场景 用法
    异常检测 超出 \(3\sigma\) 判为异常
    质量控制 \(6\sigma\) 标准（每百万件约 0.002 个缺陷）
    检测门限 由虚警率反推（\(P_{fa} = 10^{-6}\) 对应约 \(4.75\sigma\)）

    二、中心极限定理¶

    定理：设 \(X_1,\dots,X_n\) 独立同分布，\(E[X_i] = \mu\)、 \(\operatorname{Var}[X_i] = \sigma^2\)（有限），则

    \[ \frac{\sum_{i=1}^{n}X_i - n\mu}{\sqrt{n}\sigma} \xrightarrow{d} N(0,1) \quad (n\to\infty) \]

    关键点：\(X_i\) 本身的分布可以是任意的。

    为什么这解释了「高斯无处不在」

    任何由大量独立小因素叠加产生的量，都趋于高斯。

    现象 叠加来源
    测量误差 无数微小扰动（热噪声、读数偏差）
    电子噪声 大量载流子的独立运动
    人的身高 大量基因与环境因素
    雨滴落点偏差 风向、初速的微小差异

    高斯分布在 \(n\) 不大时就已相当接近： 通常 \(n \gtrsim 30\) 就够（这是「大样本」的经验阈值）。

    工程上的实际意义：

    做法 依据
    假设噪声是高斯 中心极限定理
    多个误差源合成用一个高斯描述 同上
    用 \(\sigma\) 描述总误差 方差可加

    但要注意反例：

    情形 结果分布
    极少数的大跳动主导（如脉冲干扰） 重尾（不适用高斯）
    单个主导因素（不是「大量小因素」） 不一定高斯
    因素是乘性叠加 趋于对数正态

    「乘性叠加 → 对数正态」：若 \(Y = \prod X_i\)，则

    \[ \ln Y = \sum\ln X_i \]

    由中心极限定理，\(\ln Y\) 趋于正态 → \(Y\) 趋于对数正态。

    这是通信中「阴影衰落」用对数正态建模的原因 （多个障碍物的衰减是乘性的）。

    三、多维高斯分布¶

    这是工程中真正用到的形式。

    密度函数：

    \[ f(\boldsymbol{x}) = \frac{1}{(2\pi)^{d/2}\lvert\Sigma\rvert^{1/2}} \exp\left(-\frac12(\boldsymbol{x}-\boldsymbol{\mu})^\top\Sigma^{-1}(\boldsymbol{x}-\boldsymbol{\mu})\right) \]

    记作 \(\boldsymbol{x}\sim N(\boldsymbol{\mu},\Sigma)\)。

    参数 形状 含义
    \(\boldsymbol{\mu}\) \(d\) 维向量 中心位置
    \(\Sigma\) \(d\times d\) 对称正定矩阵 协方差矩阵（形状与方向）

    指数中的二次型：

    \[ (\boldsymbol{x}-\boldsymbol{\mu})^\top\Sigma^{-1}(\boldsymbol{x}-\boldsymbol{\mu}) \]

    这是马氏距离的平方 —— 用 \(\Sigma^{-1}\) 加权的距离。

    为什么是 Σ⁻¹ 而不是 Σ

    直观解释：

    方向 \(\Sigma\) 的特征值 含义
    数据分散的方向 特征值大 该方向「不稀奇」→ 距离应算小
    数据集中的方向 特征值小 该方向偏离很稀奇 → 距离应算大

    取逆正好实现这个加权：\(\Sigma^{-1}\) 在方差小的方向上给出大的权重。

    这就是马氏距离比欧氏距离合理的原因：

    距离 是否考虑数据分布
    欧氏 \(\lVert\boldsymbol{x}-\boldsymbol{\mu}\rVert\) ✗ 各方向同等对待
    马氏 ✓ 按数据分布的「稀奇程度」加权

    工程用途：

    场景 为什么用马氏
    异常检测 考虑各方向正常波动幅度
    分类（高斯判别） 比较「哪个类的马氏距离更小」
    卡尔曼滤波 新息用 \(S^{-1}\) 加权

    退化情形：若 \(\Sigma = \sigma^2I\)（各方向独立同方差）， 则马氏距离就退化为欧氏距离除以 \(\sigma\) ✓

    等高线是椭圆¶

    密度等高线由二次型为常数给出：

    \[ (\boldsymbol{x}-\boldsymbol{\mu})^\top\Sigma^{-1}(\boldsymbol{x}-\boldsymbol{\mu}) = c \]

    这是椭圆（或椭球），其形状由 \(\Sigma\) 的特征分解决定：

    \(\Sigma\) 的性质 等高线形状
    \(\Sigma = \sigma^2I\) 圆（各向同性）
    \(\Sigma\) 对角但不等 轴对齐的椭圆
    \(\Sigma\) 有非对角项 倾斜的椭圆

    主轴方向就是 \(\Sigma\) 的特征向量， 各轴长度与 \(\sqrt{\text{特征值}}\) 成正比。

    这与线性代数模块的「谱定理」完全对接： 对称正定矩阵总可以正交对角化

    \[ \Sigma = Q\Lambda Q^\top \]

    于是

    \[ \Sigma^{-1} = Q\Lambda^{-1}Q^\top \]

    这解释了为什么协方差矩阵一定是对称正定的 （回到「矩阵分解」一页的结论）。

    四、高斯的优良性质¶

    这几条性质是高斯「好用」的根本原因。

    性质 1：线性变换仍是高斯¶

    \[ \boldsymbol{x}\sim N(\boldsymbol{\mu},\Sigma) \implies A\boldsymbol{x}+\boldsymbol{b}\sim N(A\boldsymbol{\mu}+\boldsymbol{b},\ A\Sigma A^\top) \]

    注意协方差的变换是 \(A\Sigma A^\top\)（对称，正好符合要求）。

    性质 2：线性组合仍是高斯¶

    若 \(\boldsymbol{x},\boldsymbol{y}\) 联合高斯，则任意线性组合

    \[ a\boldsymbol{x} + b\boldsymbol{y} \]

    仍是高斯。

    推论：高斯性在线性运算下封闭 —— 这是卡尔曼滤波可行的关键。

    性质 3：不相关 ⟺ 独立¶

    对联合高斯分布：

    \[ \text{不相关} \iff \text{独立} \]

    这是高斯独有的性质（回到「期望与方差」一页的反例： 一般分布下不相关不蕴含独立）。

    推论：若 \(\Sigma\) 是对角矩阵，则各分量独立。

    性质 4：边缘化与条件化都保持高斯¶

    设

    \[ \begin{bmatrix}\boldsymbol{x}\\\boldsymbol{y}\end{bmatrix} \sim N\left(\begin{bmatrix}\boldsymbol{\mu}_x\\\boldsymbol{\mu}_y\end{bmatrix}, \begin{bmatrix}\Sigma_{xx}&\Sigma_{xy}\\\Sigma_{yx}&\Sigma_{yy}\end{bmatrix}\right) \]

    边缘分布：

    \[ \boldsymbol{x}\sim N(\boldsymbol{\mu}_x,\ \Sigma_{xx}) \]

    条件分布：

    \[ \boldsymbol{x}\mid\boldsymbol{y}\sim N\left(\boldsymbol{\mu}_{x\mid y},\ \Sigma_{x\mid y}\right) \]

    其中

    \[ \boldsymbol{\mu}_{x\mid y} = \boldsymbol{\mu}_x + \Sigma_{xy}\Sigma_{yy}^{-1}(\boldsymbol{y}-\boldsymbol{\mu}_y) \]
    \[ \Sigma_{x\mid y} = \Sigma_{xx} - \Sigma_{xy}\Sigma_{yy}^{-1}\Sigma_{yx} \]

    条件分布公式就是卡尔曼滤波的核心

    这两个公式值得仔细看：

    均值更新：

    \[ \boldsymbol{\mu}_{x\mid y} = \underbrace{\boldsymbol{\mu}_x}_{\text{先验预测}} + \underbrace{\Sigma_{xy}\Sigma_{yy}^{-1}}_{\text{卡尔曼增益 }K}(\underbrace{\boldsymbol{y}-\boldsymbol{\mu}_y}_{\text{新息}}) \]
    项 卡尔曼滤波里的名字
    \(\boldsymbol{\mu}_x\) 状态的预测均值
    \(\boldsymbol{y}-\boldsymbol{\mu}_y\) 新息（测量减去预测）
    \(\Sigma_{xy}\Sigma_{yy}^{-1}\) 卡尔曼增益 \(K\)

    协方差更新：

    \[ \Sigma_{x\mid y} = \underbrace{\Sigma_{xx}}_{\text{预测协方差}} - \underbrace{\Sigma_{xy}\Sigma_{yy}^{-1}\Sigma_{yx}}_{\text{信息增益（恒为非负定）}} \]

    注意是「减号」 —— 观测总是减少不确定性 ✓ 这符合直觉：获得信息不会让不确定性变大。

    这说明：卡尔曼滤波不是「凑出来的算法」， 而是高斯条件分布公式的直接实现。

    验证「不确定性一定减少」：因为

    \[ \Sigma_{x\mid y} = \Sigma_{xx} - \Sigma_{xy}\Sigma_{yy}^{-1}\Sigma_{yx} \preceq \Sigma_{xx} \]

    （\(\Sigma_{xy}\Sigma_{yy}^{-1}\Sigma_{yx}\) 半正定，见矩阵分解一页的结论）。

    五、典型例题¶

    例题 1：标准化与查表¶

    设 \(X\sim N(3, 4)\)（即 \(\mu = 3\)、\(\sigma = 2\)）。 求 \(P(1 < X < 5)\)。

    思路

    标准化后查标准正态表；注意这个区间恰好是 \(\mu\pm\sigma\)。

    解答

    标准化：

    \[ P(1 < X < 5) = P\left(\frac{1-3}{2} < Z < \frac{5-3}{2}\right) = P(-1 < Z < 1) \]

    查表（或记住 3σ 法则）：

    \[ P(-1 < Z < 1) = \Phi(1) - \Phi(-1) \]

    由标准正态的对称性 \(\Phi(-1) = 1-\Phi(1)\)：

    \[ = \Phi(1) - (1-\Phi(1)) = 2\Phi(1) - 1 \]

    查表得 \(\Phi(1) = 0.8413\)，所以

    \[ = 2\times0.8413 - 1 = 0.6827 \]

    结果：约 \(68.27\%\) ✓ （这正是 3σ 法则中的第一行）

    观察：区间 \([1,5]\) 恰好是 \([\mu-\sigma,\ \mu+\sigma]\)， 所以直接可用 \(68.27\%\)。

    常见区间概率（值得记住的速查表）

    区间 概率 尾概率（单侧）
    \(\pm1\sigma\) \(68.27\%\) \(15.87\%\)
    \(\pm1.645\sigma\) \(90\%\) \(5\%\)
    \(\pm1.96\sigma\) \(95\%\) \(2.5\%\)
    \(\pm2\sigma\) \(95.45\%\) \(2.28\%\)
    \(\pm2.576\sigma\) \(99\%\) \(0.5\%\)
    \(\pm3\sigma\) \(99.73\%\) \(0.135\%\)

    工程用途（由虚警率反推门限）：

    要求的虚警率 门限
    \(5\%\) \(1.645\sigma\)
    \(1\%\) \(2.326\sigma\)
    \(0.1\%\) \(3.09\sigma\)
    \(10^{-6}\) \(4.75\sigma\)

    这就是雷达/声纳检测门限的确定方式： 先定可接受的虚警率，再查表得门限。

    例题 2：线性变换¶

    设 \(\boldsymbol{x}\sim N\left(\begin{bmatrix}1\\2\end{bmatrix}, \begin{bmatrix}4&2\\2&3\end{bmatrix}\right)\)， 求 \(\boldsymbol{y} = \begin{bmatrix}1&1\\0&2\end{bmatrix}\boldsymbol{x}\) 的分布。

    思路

    用线性变换公式：\(\boldsymbol{\mu}_y = A\boldsymbol{\mu}\)， \(\Sigma_y = A\Sigma A^\top\)。

    解答

    第一步：均值

    \[ \boldsymbol{\mu}_y = A\boldsymbol{\mu}_x = \begin{bmatrix}1&1\\0&2\end{bmatrix}\begin{bmatrix}1\\2\end{bmatrix} = \begin{bmatrix}1+2\\0+4\end{bmatrix} = \begin{bmatrix}3\\4\end{bmatrix} \]

    第二步：协方差（\(A\Sigma A^\top\)）

    先算 \(A\Sigma\)：

    \[ A\Sigma = \begin{bmatrix}1&1\\0&2\end{bmatrix}\begin{bmatrix}4&2\\2&3\end{bmatrix} = \begin{bmatrix}4+2 & 2+3\\ 0+4 & 0+6\end{bmatrix} = \begin{bmatrix}6&5\\4&6\end{bmatrix} \]

    再乘 \(A^\top = \begin{bmatrix}1&0\\1&2\end{bmatrix}\)：

    \[ A\Sigma A^\top = \begin{bmatrix}6&5\\4&6\end{bmatrix}\begin{bmatrix}1&0\\1&2\end{bmatrix} = \begin{bmatrix}6+5 & 0+10\\ 4+6 & 0+12\end{bmatrix} = \begin{bmatrix}11&10\\10&12\end{bmatrix} \]

    结果：

    \[ \boldsymbol{y}\sim N\left(\begin{bmatrix}3\\4\end{bmatrix}, \begin{bmatrix}11&10\\10&12\end{bmatrix}\right) \]

    检查协方差矩阵的对称性：\(\Sigma_y = \begin{bmatrix}11&10\\10&12\end{bmatrix}\) 确实对称 ✓（这是必要条件——任何协方差矩阵都必须对称）

    检查正定性（必要）：

    • 主对角元：\(11 > 0\)、\(12 > 0\) ✓
    • 行列式：\(11\times12 - 100 = 132-100 = 32 > 0\) ✓

    所以是正定的 ✓

    两个必须记住的形状技巧

    1. \(A\Sigma A^\top\) 而不是 \(A\Sigma\)

    写法 问题
    \(A\Sigma\) 一般不对称 → 不是合法协方差
    \(A\Sigma A^\top\) 对称 ✓（\((A\Sigma A^\top)^\top = A\Sigma^\top A^\top = A\Sigma A^\top\)）

    2. 为什么是 \(A\) 和 \(A^\top\) 在两侧

    维度检查（\(A\) 是 \(m\times d\)、\(\Sigma\) 是 \(d\times d\)）：

    \[ \underbrace{A}_{m\times d}\underbrace{\Sigma}_{d\times d}\underbrace{A^\top}_{d\times m} = m\times m \;\checkmark \]

    正好是输出维数 \(m\) 的协方差矩阵 ✓

    与「方差缩放」的对照（一维时）：

    一维 多维
    \(\operatorname{Var}[aX] = a^2\sigma^2\) \(\Sigma_y = A\Sigma A^\top\)

    \(a^2\) 对应 \(A\Sigma A^\top\)（系数出现两次）✓

    例题 3：条件分布（卡尔曼滤波的形式）¶

    设

    \[ \begin{bmatrix}x\\y\end{bmatrix} \sim N\left(\begin{bmatrix}0\\0\end{bmatrix}, \begin{bmatrix}4&2\\2&5\end{bmatrix}\right) \]

    求 \(x\mid y\) 的分布，并解释「观测带来的信息增益」。

    思路

    用条件分布的公式；注意协方差是「先验方差减去增益项」。

    解答

    第一步：识别分块

    块 值
    \(\mu_x\) \(0\)
    \(\mu_y\) \(0\)
    \(\Sigma_{xx}\) \(4\)
    \(\Sigma_{xy} = \Sigma_{yx}\) \(2\)
    \(\Sigma_{yy}\) \(5\)

    第二步：条件均值公式

    \[ \mu_{x\mid y} = \mu_x + \Sigma_{xy}\Sigma_{yy}^{-1}(y-\mu_y) = 0 + \frac{2}{5}(y-0) = 0.4y \]

    第三步：条件方差公式

    \[ \Sigma_{x\mid y} = \Sigma_{xx} - \Sigma_{xy}\Sigma_{yy}^{-1}\Sigma_{yx} = 4 - \frac{2\times2}{5} = 4 - 0.8 = 3.2 \]

    结果：

    \[ x\mid y \sim N\left(0.4y,\ 3.2\right) \]

    观察这个结果（正是卡尔曼滤波的形式）：

    项 值 含义
    卡尔曼增益 \(K\) \(0.4\) \(\Sigma_{xy}/\Sigma_{yy}\)
    条件均值 \(K\cdot y\) 先验 + 增益×新息
    先验方差 \(4\) 观测前的不确定性
    后验方差 \(3.2\) 观测后降低 ✓

    信息增益的定量：

    \[ \text{方差降低} = 4 - 3.2 = 0.8 = \text{即 }20\% \]

    为什么是 \(20\%\)：由 \(\Sigma_{xy}^2/(\Sigma_{xx}\Sigma_{yy})\) 决定：

    \[ \frac{4}{4\times5} = 0.2 \]

    这就是相关系数的平方：

    \[ \rho_{xy}^2 = \frac{\Sigma_{xy}^2}{\Sigma_{xx}\Sigma_{yy}} = \frac{4}{20} = 0.2 \]

    所以：

    \[ \Sigma_{x\mid y} = \Sigma_{xx}(1-\rho^2) \]

    这条公式很通用：观测能把方差降低的比例恰好是 \(\rho^2\)。

    推论：

    \(\rho\) 观测的价值
    \(0\)（不相关） 无用（方差完全不降，\(1-0 = 1\)）
    \(0.5\) 降低 \(25\%\)
    \(0.9\) 降低 \(81\%\)（很有价值）
    \(1\)（完全相关） 方差降为 \(0\)（完全确定）

    工程含义：传感器的有效性取决于它与被测量的相关性。 若相关性低，再贵的传感器也带不来信息——这是传感器选型的核心判据。

    例题 4：不相关即独立（高斯特例）¶

    设 \(\boldsymbol{x}\sim N(\boldsymbol{0},\Sigma)\)，其中

    \[ \Sigma = \begin{bmatrix}4&0\\0&9\end{bmatrix} \]

    说明两个分量独立，并写出联合密度。

    思路

    对角协方差 → 二次型可分离 → 密度可分解为乘积。

    解答

    第一步：\(\Sigma\) 是对角阵，所以分量不相关

    \[ \operatorname{Cov}[x_1,x_2] = \Sigma_{12} = 0 \]

    第二步：高斯情形下不相关即独立

    （性质 3，高斯独有。）

    第三步：验证密度可分解

    先算 \(\Sigma^{-1}\)（对角阵求逆就是取倒数）：

    \[ \Sigma^{-1} = \begin{bmatrix}1/4&0\\0&1/9\end{bmatrix} \]

    二次型：

    \[ \boldsymbol{x}^\top\Sigma^{-1}\boldsymbol{x} = \frac{x_1^2}{4} + \frac{x_2^2}{9} \]

    这是两项之和 → 指数可分成两个因子的乘积：

    \[ e^{-\frac12\left(\frac{x_1^2}{4}+\frac{x_2^2}{9}\right)} = e^{-\frac{x_1^2}{8}}\cdot e^{-\frac{x_2^2}{18}} \]

    归一化常数也可分解：

    \[ \frac{1}{2\pi\sqrt{\lvert\Sigma\rvert}} = \frac{1}{2\pi\sqrt{36}} = \frac{1}{12\pi} \]

    而两个一维密度的常数之积：

    \[ \frac{1}{\sqrt{2\pi}\cdot2}\cdot\frac{1}{\sqrt{2\pi}\cdot3} = \frac{1}{2\pi\cdot6} = \frac{1}{12\pi} \;\checkmark \]

    所以联合密度分解为：

    \[ f(x_1,x_2) = \underbrace{\frac{1}{\sqrt{2\pi}\cdot2}e^{-x_1^2/8}}_{N(0,4)} \cdot\underbrace{\frac{1}{\sqrt{2\pi}\cdot3}e^{-x_2^2/18}}_{N(0,9)} \]

    即 \(x_1\sim N(0,4)\) 与 \(x_2\sim N(0,9)\) 独立 ✓

    这个结论只在「联合高斯」时成立

    必须区分两种情形：

    情形 不相关 ⟹ 独立？
    已知联合高斯 ✓ 成立
    只知道各自的边缘分布 ✗ 不成立

    反例（回到期望与方差一页）：\(x\sim U(-1,1)\)、\(y = x^2\)。

    • 协方差为 0（不相关）
    • 但 \(y\) 完全由 \(x\) 决定（不独立）

    关键在于：这里 \((x,y)\) 不是联合高斯 （因为 \(y = x^2\) 不是 \(x\) 的线性函数）。

    工程上的实用判据：

    检查 结论
    二维散点图呈椭圆云 近似联合高斯 → 可用此性质
    散点呈抛物线/弯曲形状 非高斯 → 不可用
    单变量都是高斯但联合不是 仍不能用

    实践建议：卡尔曼滤波依赖「联合高斯」假设。 若实际数据有强非线性结构，应改用粒子滤波 或先做非线性变换。

    八、自测¶

    Q1 设 \(X\sim N(2, 9)\)（即 \(\mu = 2\)、\(\sigma = 3\)）。 求 \(P(-1 < X < 5)\)。

    提示

    标准化后看区间是否为 \(\mu\pm\sigma\)。

    解答

    标准化：

    \[ P(-1 < X < 5) = P\left(\frac{-1-2}{3} < Z < \frac{5-2}{3}\right) = P(-1 < Z < 1) \]

    区间恰好是 \(\mu\pm\sigma\) ✓

    用 3σ 法则：

    \[ P(-1 < Z < 1) = 0.6827 \]

    结果：约 \(68.27\%\)

    验证（用对称性）：

    \[ P(-1<Z<1) = 2\Phi(1)-1 = 2\times0.8413-1 = 0.6827 \;\checkmark \]

    注意区间的端点计算：

    端点 标准化
    \(-1\) \(\frac{-1-2}{3} = -1\)
    \(5\) \(\frac{5-2}{3} = 1\)

    正好是 \(\pm1\) —— 因为 \(\mu = 2\)、\(\sigma = 3\)， 所以 \(\mu-\sigma = -1\)、\(\mu+\sigma = 5\) ✓

    工程含义：若已知噪声是高斯且标准差为 3， 则「观测值落在 \([\mu-3,\mu+3]\) 之外」的概率约 \(31.7\%\) —— 这可以作为异常检测的初步判据。

    Q2 设二维高斯

    \[ \boldsymbol{x}\sim N\left(\begin{bmatrix}0\\0\end{bmatrix},\begin{bmatrix}4&0\\0&1\end{bmatrix}\right) \]
    提示

    对角协方差在高斯下意味着独立。

    解答

    判断独立性：

    \(\Sigma\) 是对角矩阵 → 分量不相关：

    \[ \operatorname{Cov}[x_1,x_2] = \Sigma_{12} = 0 \]

    联合高斯下不相关 ⟹ 独立 ✓

    所以 \(x_1\) 与 \(x_2\) 独立

    写出联合密度：

    行列式 \(\lvert\Sigma\rvert = 4\times1 = 4\)，所以 \(\lvert\Sigma\rvert^{1/2} = 2\)。

    二次型（\(\Sigma^{-1} = \operatorname{diag}(1/4, 1)\)）：

    \[ \boldsymbol{x}^\top\Sigma^{-1}\boldsymbol{x} = \frac{x_1^2}{4}+x_2^2 \]

    联合密度：

    \[ f(\boldsymbol{x}) = \frac{1}{2\pi\cdot2}\exp\left(-\frac12\left(\frac{x_1^2}{4}+x_2^2\right)\right) = \frac{1}{4\pi}e^{-x_1^2/8}e^{-x_2^2/2} \]

    验证分解：

    \[ \underbrace{\frac{1}{\sqrt{2\pi}\cdot2}e^{-x_1^2/8}}_{N(0,4)} \cdot\underbrace{\frac{1}{\sqrt{2\pi}\cdot1}e^{-x_2^2/2}}_{N(0,1)} \]

    两者相乘的常数部分：

    \[ \frac{1}{2\sqrt{2\pi}}\cdot\frac{1}{\sqrt{2\pi}} = \frac{1}{4\pi} \;\checkmark \]

    与上面的归一化常数一致 ✓ 所以密度确实分解为乘积形式 —— 这正是独立的等价条件 ✓

    等高线形状：\(\Sigma\) 对角但特征值不同（4 与 1）→ 轴对齐的椭圆（半轴长比 \(2:1\)，因为 \(\sqrt4:\sqrt1 = 2:1\)）。

    Q3 判断：若 \(X\) 与 \(Y\) 的边缘分布都是高斯，则 \((X,Y)\) 联合高斯。

    提示

    想想 \(Y = X^2\) 这类非线性关系。

    解答

    不对。边缘高斯不能保证联合高斯。

    反例构造：

    设联合密度为「两个不同高斯的混合」：

    \[ f(x,y) = \frac12 f_1(x,y)+\frac12 f_2(x,y) \]

    其中 \(f_1 = N(\boldsymbol{0}, I)\)、\(f_2 = N(\boldsymbol{0},\ \operatorname{diag}(1,2))\)。

    边缘分布：混合的两项边缘都是高斯，混合后仍是高斯 ✓

    但联合分布不是高斯 ✗（它是双峰的混合）

    另一个直观反例：

    设 \(X\sim N(0,1)\)，\(Y = X\cdot S\)，其中 \(S\) 独立且取 \(\pm1\) 各半。

    变量 分布
    \(X\) \(N(0,1)\) ✓ 高斯
    \(Y\) \(N(0,1)\) ✓ 高斯（对称化）
    \((X,Y)\) 不是联合高斯 ✗

    为什么：\(Y\) 依赖 \(X\) 的符号（非线性）， 而 \(X\) 与 \(Y\) 的符号完全相同（\(Y\) 与 \(X\) 同号）—— 这产生了「取值限制在两个象限」的结构，不是椭圆等高线 ✗

    验证协方差：

    \[ \operatorname{Cov}(X,Y) = E[XY]-E[X]E[Y] = E[X^2S]-0 = E[X^2]E[S] = 1\times0 = 0 \]

    协方差为零（不相关），但显然不独立（\(Y\) 与 \(X\) 同号）✗

    这就是「不相关 ≠ 独立」在高斯情形下的一个陷阱：

    前提 结论
    联合高斯 + 不相关 ⟹ 独立 ✓
    仅边缘高斯 + 不相关 ⟹ 不能推出独立 ✗

    实践判据：

    检查 方法
    联合是否高斯 画二维散点（应呈椭圆云）
    有弯曲/双峰结构 不是联合高斯 ✗
    只用了边缘直方图 不足以判断 ✗

    工程含义：卡尔曼滤波依赖「联合高斯」假设 —— 不能只验证各个变量的边缘分布，必须检查联合结构 ✓

    Q4 设 \(x\sim N(0,1)\)、\(y\sim N(1,1)\)，且 \(\operatorname{Cov}(x,y) = 0.5\)。 求 \(x\mid y\) 的均值与方差。

    提示

    用条件分布的公式（卡尔曼滤波的形式）。

    解答

    识别参数：

    量 值
    \(\mu_x\) \(0\)
    \(\mu_y\) \(1\)
    \(\Sigma_{xx}\) \(1\)
    \(\Sigma_{xy}\) \(0.5\)
    \(\Sigma_{yy}\) \(1\)

    条件均值：

    \[ \mu_{x\mid y} = \mu_x+\Sigma_{xy}\Sigma_{yy}^{-1}(y-\mu_y) = 0+\frac{0.5}{1}(y-1) = 0.5(y-1) \]

    条件方差：

    \[ \Sigma_{x\mid y} = \Sigma_{xx}-\Sigma_{xy}\Sigma_{yy}^{-1}\Sigma_{yx} = 1-\frac{0.5\times0.5}{1} = 1-0.25 = 0.75 \]

    结果：

    \[ x\mid y \sim N\big(0.5(y-1),\ 0.75\big) \]

    验证「不确定性减少」：

    量 观测前 观测后
    方差 \(1\) \(0.75\) ✓ 减少

    减少比例 = 相关系数的平方：

    \[ \rho_{xy}^2 = \frac{\Sigma_{xy}^2}{\Sigma_{xx}\Sigma_{yy}} = \frac{0.25}{1} = 0.25 \]

    验证：

    \[ \Sigma_{x\mid y} = \Sigma_{xx}(1-\rho^2) = 1\times(1-0.25) = 0.75 \;\checkmark \]

    这就是卡尔曼滤波的核心公式：

    项 卡尔曼滤波中的名字
    \(\Sigma_{xy}\Sigma_{yy}^{-1} = 0.5\) 卡尔曼增益 \(K\)
    \(y-\mu_y\) 新息
    \(\mu_x+K\cdot\text{新息}\) 状态更新
    \(\Sigma_{xx}-K\Sigma_{yx}\) 协方差更新

    工程含义：相关性越强（\(\rho\) 越大），观测的价值越高 —— 若 \(\rho = 1\)（完全相关），则条件方差降为 \(0\)（完全确定）✓

    这也解释了传感器选型的原则： 优先选与被测量相关性高的传感器 ✓
