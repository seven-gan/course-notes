    期望与方差¶

    分布函数完整描述了随机变量，但常常太多信息。工程上我们更关心两个数：

    量 回答的问题
    期望 「平均而言是多少？」
    方差 「波动有多大？」

    为什么只要这两个数

    场景 需求
    传感器标定 只要均值（系统偏差）与方差（随机误差）
    误差传播 用均值和方差做线性近似（回到微积分那一页）
    卡尔曼滤波 状态只需均值和协方差
    质量控制 均值（是否偏）与标准差（是否稳定）

    对高斯分布，均值和方差就是全部信息—— 这是它在工程中被广泛使用的重要原因。

    一、期望¶

    定义（离散）：

    \[ E[X] = \sum_x x\,p_X(x) \]

    定义（连续）：

    \[ E[X] = \int_{-\infty}^{\infty}x\,f_X(x)\,\mathrm{d}x \]

    直观：期望是「以概率为权重的加权平均」，也物理上对应 质心（把概率当成质量分布）。

    期望不一定是「可能取到的值」

    例子 期望 是否可能取到
    掷骰子 \(3.5\) ✗（骰子没有 3.5 点）
    掷硬币（正面=1） \(0.5\) ✗
    连续均匀 \(U(0,1)\) \(0.5\) 概率为零

    期望是「长期平均值」，不必是某次实现的取值。

    工程含义：说「平均故障间隔 500 小时」， 不代表任何一次都会在第 500 小时出故障。

    期望的性质¶

    性质 表达式 条件
    线性 \(E[aX+bY] = aE[X]+bE[Y]\) 总是成立（不需要独立）
    常数 \(E[c] = c\) ——
    独立时的乘积 \(E[XY] = E[X]E[Y]\) 需要独立（或至少不相关）
    函数 \(E[g(X)] = \int g(x)f_X(x)\mathrm{d}x\) ——

    期望的线性性是「最重要的性质」

    \[ E[aX + bY] = aE[X] + bE[Y] \]

    关键：不需要 X 与 Y 独立 —— 这是它极其好用的原因。

    典型应用：期望可加，所以「求和的期望 = 期望的和」。

    例（指示变量技巧）：求 \(n\) 个人中「生日在同一个月」的期望对数。

    直接枚举很麻烦。但设指示变量

    \[ I_{ij} = \begin{cases}1, & \text{第 }i,j\text{ 人同月}\\ 0, & \text{否则}\end{cases} \]

    则总对数是 \(\sum_{i\lt j}I_{ij}\)，由线性性：

    \[ E\left[\sum_{i<j}I_{ij}\right] = \sum_{i<j}E[I_{ij}] = \binom{n}{2}\cdot\frac{1}{12} \]

    （因为任意两人同月的概率是 \(1/12\)。）

    不需要处理复杂的相关性 —— 这就是线性性的威力。

    二、方差与标准差¶

    定义：

    \[ \operatorname{Var}[X] = E\left[(X - E[X])^2\right] \]

    常用计算式（更方便）：

    \[ \boxed{\ \operatorname{Var}[X] = E[X^2] - (E[X])^2\ } \]

    标准差：

    \[ \sigma_X = \sqrt{\operatorname{Var}[X]} \]

    为什么工程上更常用标准差

    量 量纲 用途
    方差 平方量纲 理论推导方便（可加、可微）
    标准差 与 \(X\) 相同 直观解释、报告误差

    例：测量长度得到 \(X = 10 \pm 0.5\) cm。

    • 若 \(0.5\) 是标准差 → 单位一致 ✓ 直观
    • 若 \(0.5\) 是方差 → 意味着标准差 \(0.71\) cm，读起来别扭

    两者都要会：

    场合 用
    推导公式（如卡尔曼滤波） 方差/协方差
    报告测量结果 标准差
    误差传播的乘法组合 相对标准差

    方差的性质¶

    性质 表达式 说明
    平移不变 \(\operatorname{Var}[X+b] = \operatorname{Var}[X]\) 加常数不改变波动
    缩放平方 \(\operatorname{Var}[aX] = a^2\operatorname{Var}[X]\) 注意是 \(a^2\)
    独立可加 \(\operatorname{Var}[X+Y] = \operatorname{Var}[X]+\operatorname{Var}[Y]\) 需要独立
    一般情形 \(\operatorname{Var}[X+Y] = \operatorname{Var}[X]+\operatorname{Var}[Y]+2\operatorname{Cov}[X,Y]\) ——

    方差的可加性需要独立（或至少不相关）

    对比期望：

    运算 是否需要独立
    \(E[X+Y]\) 不需要 ✓
    \(\operatorname{Var}[X+Y]\) 需要（否则要加协方差项）

    为什么：期望是一阶量（线性），方差是二阶量（含乘积）。

    不独立时的后果：

    \[ \operatorname{Var}[X+Y] = \operatorname{Var}[X]+\operatorname{Var}[Y]+2\operatorname{Cov}[X,Y] \]
    相关性 后果
    正相关 方差比相加更大（风险叠加）
    负相关 方差比相加更小（风险对冲！）

    工程含义（这就是「分散投资」与「多传感器互补」的数学原理）：

    若两个误差源负相关，合并后的方差会小于各自之和—— 这是「互补滤波」能比单个传感器更准的原因。

    三、协方差与相关系数¶

    协方差：

    \[ \operatorname{Cov}[X,Y] = E\big[(X-E[X])(Y-E[Y])\big] = E[XY] - E[X]E[Y] \]

    含义：衡量两个变量的线性共同变化趋势。

    \(\operatorname{Cov}\) 含义
    \(> 0\) 正相关（同增同减）
    \(< 0\) 负相关（一增一减）
    \(= 0\) 不相关（无线性关系）

    相关系数（归一化到 \([-1,1]\)）：

    \[ \rho_{XY} = \frac{\operatorname{Cov}[X,Y]}{\sigma_X\sigma_Y} \]

    相关系数的性质与含义

    \(\lvert\rho\rvert\) 的取值 含义
    \(1\) 完全正线性相关（\(Y = aX+b\)，\(a>0\)）
    \(-1\) 完全负线性相关
    \(0\) 无线性相关（但不代表独立）
    \(0.7\)–\(0.9\) 强线性关系

    重要提醒（回到信号模块的结论）：

    \[ \rho = 0 \iff \text{不相关} \neq \text{独立} \]

    只有对高斯分布，不相关才等价于独立。

    反例：\(X\sim N(0,1)\)，\(Y = X^2\)，则 \(\rho_{XY} = 0\) 但 \(Y\) 完全由 \(X\) 决定。

    工程用途：\(\rho\) 是无量纲的，可以直接比较不同量纲变量之间的 相关强度——这是它比协方差更常用的原因。

    四、常见分布的期望与方差¶

    分布 期望 方差
    伯努利 \(B(p)\) \(p\) \(p(1-p)\)
    二项 \(B(n,p)\) \(np\) \(np(1-p)\)
    泊松 \(P(\lambda)\) \(\lambda\) \(\lambda\)
    几何 \(\dfrac{1}{p}\) \(\dfrac{1-p}{p^2}\)
    均匀 \(U(a,b)\) \(\dfrac{a+b}{2}\) \(\dfrac{(b-a)^2}{12}\)
    指数 \(\text{Exp}(\lambda)\) \(\dfrac{1}{\lambda}\) \(\dfrac{1}{\lambda^2}\)
    正态 \(N(\mu,\sigma^2)\) \(\mu\) \(\sigma^2\)

    两个值得记住的特殊之处

    1. 泊松：期望等于方差

    \[ E[X] = \operatorname{Var}[X] = \lambda \]

    实用价值：这是一个检验方法。若实测数据中样本均值与 样本方差差异很大，说明数据不服从泊松分布。

    这类「均值-方差关系」是判断分布类型的重要线索：

    分布 均值与方差的关系
    泊松 相等
    二项 方差 \(<\) 均值（\(\operatorname{Var} = np(1-p) < np\)）
    负二项 方差 \(>\) 均值（过度离散）

    2. 均匀分布：方差与区间长度的平方成正比

    \[ \operatorname{Var} = \frac{(b-a)^2}{12} \]

    工程用途：量化误差建模。

    若量化步长为 \(\Delta\)，则误差近似服从 \(U(-\Delta/2, \Delta/2)\)：

    \[ \operatorname{Var} = \frac{\Delta^2}{12} \]

    这就是本知识库「量化与信噪比」一页中 \(\sigma_e^2 = \Delta^2/12\) 的来源 ✓

    那个 \(1/12\) 不是凭空来的，而是均匀分布的方差公式。

    五、期望与方差的计算技巧¶

    技巧 1：用定义算（连续情形要积分）¶

    \[ E[X] = \int x f(x)\mathrm{d}x, \qquad E[X^2] = \int x^2 f(x)\mathrm{d}x \]

    技巧 2：用 \(E[X^2]-(E[X])^2\) 优于直接用定义¶

    直接算 \(E[(X-\mu)^2]\) 需要先求 \(\mu\)，再积分，步骤多。 用 \(E[X^2]-\mu^2\) 只需两个积分。

    技巧 3：对称性¶

    若分布关于 \(c\) 对称，则

    \[ E[X] = c \]

    证明思路：\(X-c\) 与 \(-(X-c)\) 同分布，所以 \(E[X-c] = -E[X-c] = 0\)。

    例：

    分布 对称中心 期望
    \(U(a,b)\) \(\frac{a+b}{2}\) \(\frac{a+b}{2}\)
    \(N(\mu,\sigma^2)\) \(\mu\) \(\mu\)
    对称三角分布 顶点位置 顶点位置

    这能省掉积分 —— 看到对称分布先想这条。

    技巧 4：指示变量分解¶

    把「计数」拆成若干个 0/1 变量之和，再用期望的线性性。

    这是概率论中最有用的技巧之一（前面生日例子已经用过）。

    六、典型例题¶

    例题 1：离散分布¶

    设 \(X\) 的 PMF 为 \(p(0) = 0.2\)、\(p(1) = 0.5\)、\(p(2) = 0.3\)。 求 \(E[X]\)、\(\operatorname{Var}[X]\)、\(\sigma_X\)。

    思路

    先算 \(E[X]\) 与 \(E[X^2]\)，再用 \(E[X^2]-\mu^2\)。

    解答

    期望：

    \[ E[X] = 0\times0.2 + 1\times0.5 + 2\times0.3 = 0 + 0.5 + 0.6 = 1.1 \]

    二阶矩：

    \[ E[X^2] = 0^2\times0.2 + 1^2\times0.5 + 2^2\times0.3 = 0 + 0.5 + 1.2 = 1.7 \]

    方差：

    \[ \operatorname{Var}[X] = E[X^2] - (E[X])^2 = 1.7 - 1.21 = 0.49 \]

    标准差：

    \[ \sigma_X = \sqrt{0.49} = 0.7 \]

    结果：\(E = 1.1\)，\(\operatorname{Var} = 0.49\)，\(\sigma = 0.7\)

    用定义直接验证方差（对比方法）：

    \(x\) \(x-\mu\) \((x-\mu)^2\) 加权
    0 \(-1.1\) 1.21 0.242
    1 \(-0.1\) 0.01 0.005
    2 \(0.9\) 0.81 0.243

    求和：\(0.242 + 0.005 + 0.243 = 0.49\) ✓

    两种方法一致，但 \(E[X^2]-\mu^2\) 的计算量更小 （只需两个和，不必先算偏差）。

    标准差的「经验法则」（值得记住）

    对近似正态的数据（或任何分布），有

    区间 包含的概率（正态）
    \(\mu\pm\sigma\) 约 68%
    \(\mu\pm2\sigma\) 约 95%
    \(\mu\pm3\sigma\) 约 99.7%

    工程应用：

    场景 用法
    质量控制 超出 \(\pm3\sigma\) 判为异常
    传感器精度 「\(3\sigma\) 误差」= 最坏情况估计
    检测门限 由虚警率要求反推门限

    注意：这个法则严格只对正态分布成立。 对重尾分布（如柯西），\(\pm3\sigma\) 可能只覆盖很小概率。

    例题 2：指数分布的期望与方差¶

    设 \(X\sim\text{Exp}(\lambda)\)，\(f(x) = \lambda e^{-\lambda x}\)（\(x\geq0\)）。 求 \(E[X]\) 与 \(\operatorname{Var}[X]\)。

    思路

    用分部积分；记住 LIATE 顺序（多项式优先当 \(u\)）。

    解答

    期望：

    \[ E[X] = \int_0^{\infty}x\lambda e^{-\lambda x}\mathrm{d}x \]

    分部积分（\(u = x\)，\(\mathrm{d}v = \lambda e^{-\lambda x}\mathrm{d}x\)， 所以 \(\mathrm{d}u = \mathrm{d}x\)、\(v = -e^{-\lambda x}\)）：

    \[ = \left[-xe^{-\lambda x}\right]_0^{\infty} + \int_0^{\infty}e^{-\lambda x}\mathrm{d}x \]

    边界项在 \(\lambda>0\) 时为零（指数衰减比 \(x\) 增长快）：

    \[ = 0 + \left[\frac{-e^{-\lambda x}}{\lambda}\right]_0^{\infty} = \frac{1}{\lambda} \]

    结果：

    \[ E[X] = \frac{1}{\lambda} \]

    二阶矩（同样用分部积分两次）：

    \[ E[X^2] = \int_0^{\infty}x^2\lambda e^{-\lambda x}\mathrm{d}x = \frac{2}{\lambda^2} \]

    方差：

    \[ \operatorname{Var}[X] = \frac{2}{\lambda^2} - \left(\frac{1}{\lambda}\right)^2 = \frac{2}{\lambda^2} - \frac{1}{\lambda^2} = \frac{1}{\lambda^2} \]

    结果：

    \[ \operatorname{Var}[X] = \frac{1}{\lambda^2}, \qquad \sigma_X = \frac{1}{\lambda} \]

    指数分布的一个特殊性质：标准差 = 均值

    \[ E[X] = \sigma_X = \frac{1}{\lambda} \]

    这意味着：

    \[ \frac{\sigma_X}{E[X]} = 1 \]

    即变异系数恒为 1。

    对比：

    分布 变异系数 \(\sigma/\mu\)
    指数 1（固定）
    正态 可任意
    泊松 \(1/\sqrt{\lambda}\)

    实用价值（分布识别）：

    若实测数据的样本标准差与样本均值接近相等（比值约 1）， 则指数分布是一个合理的候选模型。

    工程含义：「寿命的不确定性与其平均水平相当」—— 这解释了为什么用指数分布描述寿命时预测很难精确 （波动与均值一样大）。

    例题 3：期望的线性性（指示变量技巧）¶

    \(n\) 封信随机装入 \(n\) 个写好地址的信封（全随机排列）。 求装对的信封数的期望。

    思路

    不要试图求分布的完整形式！用指示变量 + 期望线性性。

    解答

    设指示变量：

    \[ I_i = \begin{cases}1, & \text{第 }i\text{ 封信装对}\\ 0, & \text{否则}\end{cases} \]

    装对的封数：

    \[ X = \sum_{i=1}^{n}I_i \]

    求 \(E[I_i]\)：由对称性，第 \(i\) 封信装进正确信封的概率是 \(1/n\)：

    \[ E[I_i] = P(\text{装对}) = \frac1n \]

    用线性性求和：

    \[ E[X] = \sum_{i=1}^{n}E[I_i] = n\cdot\frac1n = 1 \]

    结果：期望恰好是 1（与 \(n\) 无关！）

    这个结果令人惊讶：无论 5 封信还是 1000 封信， 平均都恰好装对 1 封。

    注意：这里不需要任何独立性假设 ✓ 指示变量之间是强相关的（如第 1 封装对会影响其它）， 但期望的线性性不管相关性。

    这题如果去求分布会非常困难

    完整分布是什么（错排问题）：

    \[ P(X = k) = \frac{\binom{n}{k}\cdot D_{n-k}}{n!} \]

    其中 \(D_m\) 是错排数（derangement）：

    \[ D_m = m!\sum_{j=0}^{m}\frac{(-1)^j}{j!} \]

    计算量远大于用线性性（后者只需两行）。

    极限行为（\(n\to\infty\)）：\(X\) 趋于泊松分布 \(P(1)\)：

    \[ P(X = k) \to \frac{e^{-1}}{k!} \]

    所以

    \(k\) 极限概率
    0 \(e^{-1} \approx 0.368\)
    1 \(e^{-1} \approx 0.368\)
    2 \(e^{-1}/2 \approx 0.184\)
    3 \(e^{-1}/6 \approx 0.061\)

    「恰好装对 0 封」的概率约 36.8% —— 有趣的是， 这与「恰好装对 1 封」的概率几乎相同。

    例题 4：协方差与不相关¶

    设 \(X\sim U(-1,1)\)，\(Y = X^2\)。求 \(\operatorname{Cov}[X,Y]\) 与 \(\rho_{XY}\)。

    思路

    算 \(E[XY]\) 与 \(E[X]E[Y]\)，注意对称性。

    解答

    第一步：\(E[X]\)

    \(X\sim U(-1,1)\) 关于 0 对称，所以

    \[ E[X] = 0 \]

    (也可直接积分验证：\(\int_{-1}^1 x\cdot\frac12\mathrm{d}x = 0\)。)**

    第二步：\(E[XY]\)

    \[ E[XY] = E[X\cdot X^2] = E[X^3] \]

    \(X^3\) 是奇函数，在对称区间 \([-1,1]\) 上的积分为零：

    \[ E[X^3] = \int_{-1}^{1}x^3\cdot\frac12\,\mathrm{d}x = 0 \]

    第三步：协方差

    \[ \operatorname{Cov}[X,Y] = E[XY] - E[X]E[Y] = 0 - 0\times E[Y] = 0 \]

    所以 \(\rho_{XY} = 0\) —— \(X\) 与 \(Y\) 不相关。

    第四步：但它们显然不独立！

    \(Y = X^2\) 完全由 \(X\) 决定（知道 \(X\) 就知道 \(Y\)）。

    验证：取 \(X = 0.5\) 与 \(X = -0.5\)，两者都有 \(Y = 0.25\)， 但 \(X\) 的取值不同 → 不是函数依赖的反向。

    若独立，则应有 \(E[XY] = E[X]E[Y] = 0\)（这个成立）， 但还应对任意函数成立，例如

    \[ E[X^2Y] = E[X^4] = \frac15 \neq E[X^2]E[Y] = \frac13\cdot\frac13 = \frac19 \]

    （因为 \(X^4\) 在 \([-1,1]\) 上的均值是 \(\frac15\)，\(X^2\) 的是 \(\frac13\)。）

    \[ \frac15 = 0.2 \neq \frac19 \approx 0.111 \;\times \]

    所以不独立 ✓

    「不相关只测线性关系」的完整含义

    协方差/相关系数捕捉的是：

    \[ Y \approx aX + b \quad\text{（线性关系的强度）} \]

    上例中 \(Y = X^2\) 是纯二次关系，线性部分为零 → 协方差为零。

    工程后果：

    如果只看协方差 会漏掉
    线性依赖 非线性依赖（如平方、相位）
    一阶/二阶信息 高阶结构

    这就是为什么需要「高阶统计量」：

    工具 能捕捉
    协方差 线性相关
    三阶累积量 非对称性、二次相位耦合
    四阶累积量 峰度、非线性结构

    具体应用（本知识库信号模块提到过）：某些通信信号 （如 BPSK）在二阶统计上「像白噪声」（协方差为零）， 必须用高阶累积量才能检测。

    这也是课程大纲中「高阶谱估计」的存在理由。

    七、用在哪些课程里¶

    模式识别 · 特征与损失¶

    • 特征标准化：减去均值除以标准差（消除量纲影响）
    • PCA：协方差矩阵的特征分解（用协方差衡量特征相关性）
    • 均方误差（MSE）损失：正是 \(E[(Y-\hat Y)^2]\)
    • 偏差-方差分解：\(\text{误差} = \text{偏差}^2 + \text{方差} + \text{噪声}\)

    智能传感与信息处理 · 误差分析与标定¶

    • 系统误差 vs 随机误差：均值偏移 vs 方差
    • 误差传播：用微分的线性近似（\(Y = g(X)\) 时 \(\sigma_Y\approx\lvert g'\rvert\sigma_X\)）
    • 多传感器融合：按方差（精度）加权平均
    • 标定：用均值估计系统偏差并补偿

    现代数字信号处理 · 统计量¶

    • 均值与方差是随机信号的基本统计量
    • 自相关函数就是 \(E[X(t)X(t+\tau)]\)（二阶矩）
    • 功率= 均方值 = \(E[X^2]\) = 方差 + 均值平方
    • 克拉美-罗下界：用方差的倒数表示估计精度上限

    无人系统自主决策与优化 · 风险与估计¶

    • 卡尔曼滤波：维护状态的均值与协方差
    • 风险度量：方差作为风险的代理
    • 蒙特卡洛传播：用样本估计输出的均值与方差
    • 策略评估：回报的期望（价值函数）

    八、自测¶

    Q1 设 \(X\) 的 PDF 为 \(f(x) = 2x\)（\(0\leq x\leq1\)）。 求 \(E[X]\)、\(\operatorname{Var}[X]\)。

    提示

    分别积分求 \(E[X]\) 与 \(E[X^2]\)。

    解答

    期望：

    \[ E[X] = \int_0^1 x\cdot2x\,\mathrm{d}x = 2\int_0^1 x^2\mathrm{d}x = 2\cdot\frac13 = \frac23 \]

    二阶矩：

    \[ E[X^2] = \int_0^1 x^2\cdot2x\,\mathrm{d}x = 2\int_0^1 x^3\mathrm{d}x = 2\cdot\frac14 = \frac12 \]

    方差：

    \[ \operatorname{Var}[X] = \frac12 - \left(\frac23\right)^2 = \frac12 - \frac49 = \frac{9-8}{18} = \frac{1}{18} \approx 0.0556 \]

    标准差：

    \[ \sigma_X = \frac{1}{\sqrt{18}} = \frac{1}{3\sqrt2} \approx 0.236 \]

    结果：\(E[X] = 2/3\)，\(\operatorname{Var}[X] = 1/18\)

    合理性检查：\(f(x) = 2x\) 是递增的， 所以 \(X\) 更偏向 1，\(E[X] = 2/3 > 0.5\)（均匀分布的值）✓

    Q2 设 \(X\) 与 \(Y\) 独立，\(E[X] = 2\)、\(\operatorname{Var}[X] = 3\)、 \(E[Y] = -1\)、\(\operatorname{Var}[Y] = 4\)。 求 \(E[2X-3Y+5]\) 与 \(\operatorname{Var}[2X-3Y+5]\)。

    提示

    期望用线性性（不需要独立）；方差用 \(a^2\operatorname{Var}\) 与独立可加。

    解答

    期望（线性性，不需要独立）：

    \[ E[2X-3Y+5] = 2E[X] - 3E[Y] + 5 = 2\times2 - 3\times(-1) + 5 = 4+3+5 = 12 \]

    方差（注意常数项不影响方差，系数要平方）：

    \[ \operatorname{Var}[2X-3Y+5] = 2^2\operatorname{Var}[X] + (-3)^2\operatorname{Var}[Y] \]
    \[ = 4\times3 + 9\times4 = 12 + 36 = 48 \]

    结果：\(E = 12\)，\(\operatorname{Var} = 48\)

    两个关键点：

    操作 正确处理
    常数 \(+5\) 方差不变
    系数 \(-3\) 方差乘 \((-3)^2 = 9\)（符号无关）
    独立求和 方差相加

    常见错误：把 \(\operatorname{Var}[2X-3Y]\) 写成 \(4\operatorname{Var}[X] - 9\operatorname{Var}[Y]\)（错！是相加）✗

    方差永远非负，所以「差的方差」也是各项方差之和 （在独立前提下）——这是一个重要的直觉修正。

    Q3 某元件的寿命（小时）服从指数分布，平均寿命 1000 小时。 求寿命超过 1000 小时的概率，以及寿命的标准差。

    提示

    指数分布：\(E = 1/\lambda\)，\(\sigma = 1/\lambda\)。

    解答

    求参数：

    \[ E[X] = \frac{1}{\lambda} = 1000 \implies \lambda = 10^{-3} \]

    超过 1000 小时的概率：

    \[ P(X > 1000) = e^{-\lambda\times1000} = e^{-1} \approx 0.3679 \]

    标准差（指数分布的特殊性质 \(\sigma = 1/\lambda\)）：

    \[ \sigma_X = \frac{1}{\lambda} = 1000\ \text{小时} \]

    结果：概率 \(36.8\%\)，标准差 \(1000\) 小时

    两个反直觉的事实：

    1. 「超过平均值」的概率是 36.8%，不是 50%

    这是因为指数分布右偏（长尾）， 中位数（\(693\) 小时）小于均值（\(1000\) 小时）。

    2. 标准差等于均值（变异系数为 1）

    含义：寿命的不确定性极大——波动与均值同样大小。

    工程含义：

    问题 影响
    无法可靠预测单个元件寿命 波动太大了
    只能用概率描述 说「平均 1000 小时」意义有限
    备件策略依赖分布尾部 需要按分位数备货

    对比：若寿命的标准差只有均值的 10%（如正态分布）， 预测就可靠得多。这就是为什么工程上更希望元件 磨损型失效（方差小）而非随机失效（指数分布，方差大）。

    Q4 判断：若 \(\operatorname{Cov}[X,Y] = 0\)，则 \(X\) 与 \(Y\) 相互独立。

    提示

    回顾例题 4 的反例。

    解答

    不对。不相关（协方差为 0）不蕴含独立。

    反例（例题 4）：\(X\sim U(-1,1)\)，\(Y = X^2\)。

    • \(\operatorname{Cov}[X,Y] = E[X^3] - E[X]E[Y] = 0 - 0 = 0\) → 不相关 ✓
    • 但 \(Y\) 完全由 \(X\) 决定 → 不独立 ✗

    正确的逻辑关系：

    关系 是否成立
    独立 \(\Rightarrow\) 不相关 ✓ 一定
    不相关 \(\Rightarrow\) 独立 ✗ 一般不成立
    联合高斯下两者等价 ✓ 特例

    记忆：「独立更强，高斯下才等价」。

    工程检查清单：

    情形 能否用「不相关即独立」
    已知联合高斯（如卡尔曼滤波的假设） ✓ 可以
    非高斯（通信调制、脉冲干扰） ✗ 不可以
    未知分布 ✗ 保守处理

    实际风险：若错误假设独立而实际存在非线性依赖， 会导致：

    • 检测器性能估计错误（虚警率不符）
    • 融合算法失效
    • 置信区间过窄（过度自信）
