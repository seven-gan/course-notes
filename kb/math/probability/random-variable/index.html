    随机变量与分布¶

    上一页用集合（事件）描述随机性，但集合不好算。这一页做一次关键的转换：

    把随机结果映射成数，于是可以用函数工具分析。

    这个映射就是随机变量。

    为什么要做这个转换

    用事件描述 用随机变量描述
    「掷出偶数」是一个集合 \(X = 1\) 如果偶数，否则 \(0\)
    无法直接算平均值 \(E[X]\) 可以算
    无法画图 可以画 PDF、CDF
    没有微积分可用 可以用积分

    转换之后就进入了微积分的地盘——这正是概率论与微积分相邻的原因。

    一、随机变量的定义¶

    定义：随机变量是从样本空间到实数的函数

    \[ X : \Omega \to \mathbb{R} \]

    注意：它是函数，不是「变量」——这个名字有历史误导性。

    例（掷两枚硬币）：

    结果 \(X\)（正面个数）
    (H,H) 2
    (H,T) 1
    (T,H) 1
    (T,T) 0

    于是 \(X\) 取值为 \(0,1,2\)，各自概率待算。

    离散与连续¶

    类型 取值 描述工具 例子
    离散 可数（有限或可数无限） 概率质量函数 PMF 掷骰子、计数
    连续 不可数（区间） 概率密度函数 PDF 时间、电压、位置

    二、离散情形：概率质量函数（PMF）¶

    \[ p_X(x) = P(X = x) \]

    要求：

    条件 说明
    \(p_X(x) \geq 0\) 非负
    \(\sum_x p_X(x) = 1\) 归一化

    常见离散分布：

    分布 PMF 场景
    伯努利 \(p^x(1-p)^{1-x}\)，\(x\in\{0,1\}\) 单次成功/失败
    二项 \(\binom{n}{x}p^x(1-p)^{n-x}\) \(n\) 次独立试验的成功数
    泊松 \(\dfrac{\lambda^x e^{-\lambda}}{x!}\) 单位时间内事件数
    几何 \((1-p)^{x-1}p\) 首次成功前的失败次数

    三、连续情形：概率密度函数（PDF）¶

    \[ f_X(x) \geq 0, \qquad \int_{-\infty}^{\infty}f_X(x)\,\mathrm{d}x = 1 \]

    关键：连续随机变量取单个值的概率为零。

    \[ P(X = x) = 0 \quad\text{（对连续分布）} \]

    概率由积分给出：

    \[ P(a \leq X \leq b) = \int_a^b f_X(x)\,\mathrm{d}x \]

    f(x) 不是概率

    这是最常被误解的一点。

    概念 范围 含义
    PMF \(p(x)\) \([0,1]\) 就是概率
    PDF \(f(x)\) 可以 \(> 1\) 密度，需要乘「宽度」才是概率

    为什么 PDF 可以大于 1：

    例如均匀分布 \(U(0, 0.5)\)：

    \[ f(x) = \frac{1}{0.5} = 2 > 1 \]

    但

    \[ \int_0^{0.5}2\,\mathrm{d}x = 1 \;\checkmark \]

    类比：概率密度就像物理密度（kg/m³）。 密度可以是 \(1000\) 而总质量很小（如果体积很小）。

    工程含义：看到 \(f(x) > 1\) 不要惊慌——它不是概率。

    四、累积分布函数（CDF）¶

    \[ F_X(x) = P(X \leq x) \]

    对离散：\(F_X(x) = \sum_{t\leq x}p_X(t)\)（阶梯函数）

    对连续：

    \[ F_X(x) = \int_{-\infty}^{x}f_X(t)\,\mathrm{d}t \]

    性质：

    性质 说明
    单调不减 \(x_1 < x_2 \Rightarrow F(x_1)\leq F(x_2)\)
    极限 \(F(-\infty)=0\)，\(F(\infty)=1\)
    右连续 \(F(x^+) = F(x)\)
    连续情形的导数 \(f_X(x) = F_X'(x)\)

    CDF 是「最通用」的描述工具

    优势：

    优点 说明
    对离散与连续都适用 不需要区分
    求区间概率方便 \(P(a\lt X\leq b) = F(b)-F(a)\)
    总是单调不减 便于比较与分析

    用法对照：

    要求 用 CDF 用 PDF
    \(P(X\leq a)\) \(F(a)\) ✓ \(\int_{-\infty}^a f\)
    \(P(a\lt X\leq b)\) \(F(b)-F(a)\) ✓ \(\int_a^b f\)
    \(P(X > a)\) \(1-F(a)\) ✓ \(\int_a^{\infty}f\)

    CDF 只需一次「累积」，PDF 每次都要积分——这是 CDF 的实用优势。

    五、常见连续分布¶

    分布 PDF 场景
    均匀 \(U(a,b)\) \(\dfrac{1}{b-a}\)，\(x\in[a,b]\) 完全无偏的随机
    指数 \(\text{Exp}(\lambda)\) \(\lambda e^{-\lambda x}\)，\(x\geq0\) 等待时间、寿命
    正态 \(N(\mu,\sigma^2)\) \(\dfrac{1}{\sqrt{2\pi}\sigma}e^{-\frac{(x-\mu)^2}{2\sigma^2}}\) 几乎一切

    为什么这三个最重要

    分布 关键性质 工程用途
    均匀 等可能 随机数生成、量化误差模型
    指数 无记忆性 泊松过程的事件间隔、可靠性
    正态 中心极限定理 测量误差、噪声

    指数的无记忆性：

    \[ P(X > s+t \mid X > s) = P(X > t) \]

    含义：已经等了 \(s\) 时间，还要等的分布与「从一开始等」相同—— 不记得过去了多久。

    这解释了为什么泊松过程的间隔是指数分布， 也解释了为什么「元件已用 1000 小时」不影响它的剩余寿命 （仅当失效率恒定，即指数分布时成立）。

    验证（用生存函数 \(P(X>t) = e^{-\lambda t}\)）：

    \[ \frac{P(X>s+t)}{P(X>s)} = \frac{e^{-\lambda(s+t)}}{e^{-\lambda s}} = e^{-\lambda t} = P(X>t) \;\checkmark \]

    六、随机变量的函数¶

    若 \(Y = g(X)\)，如何求 \(Y\) 的分布？

    方法一：用 CDF 定义（最稳妥）¶

    \[ F_Y(y) = P(Y\leq y) = P(g(X)\leq y) \]

    然后求导得 PDF。

    方法二：变量变换公式（\(g\) 单调时）¶

    若 \(g\) 严格单调且可导，则

    \[ f_Y(y) = f_X\big(g^{-1}(y)\big)\left\lvert\frac{\mathrm{d}}{\mathrm{d}y}g^{-1}(y)\right\rvert \]

    别忘了那个绝对值（雅可比因子）

    \[ f_Y(y) = f_X(g^{-1}(y))\cdot\left\lvert\frac{\mathrm{d}x}{\mathrm{d}y}\right\rvert \]

    为什么需要它：概率必须守恒。当 \(g\) 把区间「拉长」时， 密度要相应「变小」以保持总概率为 1。

    类比：把一维变量换成新坐标时，长度元素要换算：

    \[ \lvert\mathrm{d}x\rvert = \left\lvert\frac{\mathrm{d}x}{\mathrm{d}y}\right\rvert\lvert\mathrm{d}y\rvert \]

    这与多元情形的雅可比行列式是同一件事 （\(\lvert\det J\rvert\) 给出体积缩放因子， 见本知识库「雅可比矩阵」一页）。

    例（线性变换）：\(Y = aX+b\)，则

    \[ f_Y(y) = \frac{1}{\lvert a\rvert}f_X\left(\frac{y-b}{a}\right) \]

    验证：\(a = 2\)（把分布拉宽一倍）时，密度高度变为一半， 以保证面积仍为 1 ✓

    七、典型例题¶

    例题 1：由 PMF 求 CDF 与概率¶

    设离散随机变量 \(X\) 的 PMF 为

    \[ p_X(0) = 0.2,\quad p_X(1) = 0.5,\quad p_X(2) = 0.3 \]

    (a) 验证归一化。(b) 求 \(F_X(x)\)。© 求 \(P(0.5 < X \leq 2)\)。

    思路

    CDF 是累积求和；区间概率用 CDF 相减。

    解答

    (a) 归一化验证

    \[ 0.2 + 0.5 + 0.3 = 1.0 \;\checkmark \]

    (b) CDF

    \[ F_X(x) = \begin{cases} 0, & x < 0\\ 0.2, & 0 \leq x < 1\\ 0.7, & 1 \leq x < 2\\ 1.0, & x \geq 2 \end{cases} \]

    逐段说明：

    区间 累积了哪些
    \(x<0\) 无
    \([0,1)\) 只含 \(X=0\)：\(0.2\)
    \([1,2)\) 含 \(X=0,1\)：\(0.2+0.5 = 0.7\)
    \(x\geq2\) 全部：\(1.0\)

    © 区间概率

    \[ P(0.5 < X \leq 2) = F_X(2) - F_X(0.5) = 1.0 - 0.2 = 0.8 \]

    直接验证（枚举满足条件的取值）：

    \[ P(X=1) + P(X=2) = 0.5 + 0.3 = 0.8 \;\checkmark \]

    注意开闭端点

    \(P(0.5 < X \leq 2)\) 中： - \(X=0\) 不满足 \(X > 0.5\)，所以不包含 → 要减去 \(F(0.5) = P(X\leq 0.5) = 0.2\) - \(X=2\) 满足 \(X\leq2\)，包含

    对连续分布，端点开闭不影响结果（单点概率为零）。

    例题 2：指数分布的分布函数与应用¶

    设 \(X\sim\text{Exp}(\lambda)\)，\(f(x) = \lambda e^{-\lambda x}\)（\(x\geq0\)）。

    (a) 求 \(F(x)\)。(b) 验证无记忆性。© 若 \(\lambda = 0.01\)/小时，求 \(X > 100\) 的概率。

    思路

    用积分求 CDF；无记忆性用条件概率定义验证。

    解答

    (a) CDF

    \[ F(x) = \int_0^x\lambda e^{-\lambda t}\,\mathrm{d}t = \left[-e^{-\lambda t}\right]_0^x = 1 - e^{-\lambda x}, \quad x\geq0 \]

    （\(x<0\) 时 \(F(x) = 0\)。）

    验证极限：\(F(\infty) = 1-0 = 1\) ✓，\(F(0) = 1-1 = 0\) ✓

    (b) 无记忆性验证

    条件概率定义：

    \[ P(X>s+t\mid X>s) = \frac{P(X>s+t)}{P(X>s)} \]

    （因为 \(\{X>s+t\}\subseteq\{X>s\}\)，交集就是前者。）

    用生存函数 \(P(X>x) = 1-F(x) = e^{-\lambda x}\)：

    \[ = \frac{e^{-\lambda(s+t)}}{e^{-\lambda s}} = e^{-\lambda t} = P(X>t) \;\checkmark \]

    与 \(s\) 无关 ✓ 这就是「忘记已过去多久」。

    © 具体数值

    \[ P(X>100) = e^{-0.01\times100} = e^{-1} \approx 0.3679 \]

    结果：约 \(36.8\%\)

    工程含义（平均寿命 \(1/\lambda = 100\) 小时）：

    问题 答案
    寿命超过平均值的概率 \(e^{-1}\approx36.8\%\)

    这与直觉不符：容易以为「超过平均值」的概率约 50%。

    实际上指数分布右偏（长尾），所以中位数小于均值：

    \[ \text{中位数} = \frac{\ln 2}{\lambda} \approx \frac{0.693}{0.01} = 69.3\ \text{小时} \]

    中位数（69.3）< 均值（100）✓

    指数分布的「到期概率」与工程保养决策

    无记忆性有个反直觉推论：

    若元件寿命服从指数分布，则

    情形 剩余寿命分布
    全新元件 \(\text{Exp}(\lambda)\)
    已用 1000 小时的元件 \(\text{Exp}(\lambda)\)（完全相同）

    工程含义：

    • 对指数寿命的元件，「预防性更换」没有收益 （旧的和新的剩余寿命分布一样）
    • 但这只在失效率恒定时成立

    现实中很多元件不服从指数分布（有磨损期、老化期）：

    阶段 失效率 分布
    早期（磨合） 递减 威布尔（\(k<1\)）
    有用期 恒定 指数
    磨损期 递增 威布尔（\(k>1\)）

    这就是「浴盆曲线」——在磨损期，预防性更换才有意义。

    例题 3：变量变换¶

    设 \(X\sim U(0,1)\)，求 \(Y = -2\ln X\) 的分布。

    思路

    用 CDF 法：先求 \(F_Y(y) = P(Y\leq y)\)，再求导。

    解答

    第一步：确定 \(Y\) 的取值范围

    \(X\in(0,1)\) 时 \(\ln X\in(-\infty,0)\)，所以 \(Y = -2\ln X\in(0,\infty)\)。

    第二步：用 CDF 法

    \[ F_Y(y) = P(Y\leq y) = P(-2\ln X\leq y) \]

    解不等式（注意 \(\ln\) 是增函数，除以负数要变号）：

    \[ -2\ln X \leq y \iff \ln X \geq -\frac{y}{2} \iff X \geq e^{-y/2} \]

    所以

    \[ F_Y(y) = P(X\geq e^{-y/2}) = 1 - P(X < e^{-y/2}) \]

    \(X\sim U(0,1)\) 的 CDF 是 \(F_X(x) = x\)（\(x\in[0,1]\)），于是

    \[ F_Y(y) = 1 - e^{-y/2}, \quad y > 0 \]

    第三步：求导得 PDF

    \[ f_Y(y) = \frac{\mathrm{d}}{\mathrm{d}y}\left(1-e^{-y/2}\right) = \frac12 e^{-y/2} \]

    这是指数分布 \(\text{Exp}(\lambda = 1/2)\) ✓

    这个变换为什么重要（逆变换采样法）

    上面的结果说明：

    \[ X\sim U(0,1) \implies -\frac{1}{\lambda}\ln X \sim \text{Exp}(\lambda) \]

    这就是「逆变换采样」：

    步骤 操作
    1 生成均匀随机数 \(u\sim U(0,1)\)
    2 计算 \(x = F^{-1}(u)\)
    3 则 \(x\) 服从目标分布

    原理：若 \(U\sim U(0,1)\)，则 \(F^{-1}(U)\) 的 CDF 恰好是 \(F\)：

    \[ P(F^{-1}(U)\leq x) = P(U\leq F(x)) = F(x) \;\checkmark \]

    应用：

    用途 说明
    生成任意分布的随机数 计算机只能生成均匀随机数
    蒙特卡洛仿真 按给定分布采样
    本知识库的信号仿真 生成特定分布噪声

    局限：需要 \(F^{-1}\) 有闭式表达。正态分布就没有—— 所以正态随机数用 Box-Muller 变换或其它算法。

    例题 4：正态分布的线性变换¶

    设 \(X\sim N(\mu,\sigma^2)\)，求 \(Y = aX+b\) 的分布（\(a\neq0\)）。

    思路

    用变量变换公式（线性变换是单调的）。

    解答

    用变量变换公式：

    \[ f_Y(y) = f_X\left(\frac{y-b}{a}\right)\cdot\frac{1}{\lvert a\rvert} \]

    （因为 \(x = g^{-1}(y) = \frac{y-b}{a}\)，\(\left\lvert\frac{\mathrm{d}x}{\mathrm{d}y}\right\rvert = \frac{1}{\lvert a\rvert}\)。）

    代入正态 PDF：

    \[ f_Y(y) = \frac{1}{\sqrt{2\pi}\sigma\lvert a\rvert} \exp\left(-\frac{\left(\frac{y-b}{a}-\mu\right)^2}{2\sigma^2}\right) \]

    整理指数部分：

    \[ \frac{y-b}{a}-\mu = \frac{y-b-a\mu}{a} = \frac{y-(a\mu+b)}{a} \]

    所以

    \[ \left(\frac{y-b}{a}-\mu\right)^2 = \frac{(y-(a\mu+b))^2}{a^2} \]

    代入：

    \[ f_Y(y) = \frac{1}{\sqrt{2\pi}\sigma\lvert a\rvert} \exp\left(-\frac{(y-(a\mu+b))^2}{2a^2\sigma^2}\right) \]

    这正是 \(N(a\mu+b,\ a^2\sigma^2)\) 的密度函数 ✓

    结论：

    \[ \boxed{\ X\sim N(\mu,\sigma^2) \implies aX+b\sim N(a\mu+b,\ a^2\sigma^2)\ } \]

    「正态的线性变换仍是正态」的工程价值

    这条性质使正态分布在工程中极其方便：

    操作 结果
    加常数（标定偏移） 均值平移
    乘常数（放大） 均值与标准差同比例缩放
    多个线性组合 仍是正态（见「随机向量」一页）

    为什么必须用 \(a^2\) 而不是 \(a\)：

    方差是平方量纲。\(a = 2\) 时：

    \[ \text{标准差} \times 2, \qquad \text{方差} \times 4 \]

    标准差随 \(a\) 线性变化，方差随 \(a^2\) 变化——

    这是「方差」与「标准差」在写法上必须分清的原因。

    验证：\(a=-1\)（取负）时，方差不变（\((-1)^2 = 1\)）， 但均值变为 \(-\mu\)。所以「取负」只翻转均值，不改变离散程度 ✓

    八、用在哪些课程里¶

    模式识别 · 概率模型的基础¶

    • 贝叶斯分类器需要类条件分布 \(p(\boldsymbol{x}\mid \omega_i)\)
    • 高斯判别分析假设各类服从多维正态
    • 混合高斯模型（GMM）：多个正态的加权和
    • 密度估计（Parzen 窗、KDE）：从数据估计 PDF

    智能传感与信息处理 · 噪声建模¶

    • 测量噪声通常建模为高斯
    • 量化误差可建模为均匀分布（量化步长内）
    • 传感器寿命用指数或威布尔分布
    • 泊松计数（光子、粒子计数）用泊松分布

    现代数字信号处理 · 随机信号¶

    • 噪声的分布决定检测性能（高斯噪声下匹配滤波最优）
    • 泊松过程描述脉冲型干扰
    • 功率谱密度与分布的对应（高斯白噪声的特殊性）

    无人系统自主决策与优化 · 不确定性建模¶

    • 卡尔曼滤波假设状态与噪声都是高斯
    • 粒子滤波用样本表示任意分布
    • 风险评估用分布的分位数（VaR）

    九、自测¶

    Q1 设 \(X\) 的 PDF 为 \(f(x) = cx\)（\(0\leq x\leq 2\)）。求常数 \(c\) 与 \(P(X>1)\)。

    提示

    先用归一化条件定 \(c\)。

    解答

    第一步：归一化定 \(c\)

    \[ \int_0^2 cx\,\mathrm{d}x = c\cdot\frac{x^2}{2}\bigg|_0^2 = c\cdot2 = 1 \]

    所以

    \[ c = \frac12 \]

    验证 PDF 非负：\(f(x) = \frac{x}{2}\geq0\) 在 \([0,2]\) 上 ✓

    第二步：求 \(P(X>1)\)

    \[ P(X>1) = \int_1^2\frac{x}{2}\,\mathrm{d}x = \frac{1}{2}\cdot\frac{x^2}{2}\bigg|_1^2 = \frac14(4-1) = \frac34 \]

    结果：\(P(X>1) = 0.75\)

    交叉验证（用 CDF）：

    \[ F(x) = \int_0^x\frac{t}{2}\mathrm{d}t = \frac{x^2}{4} \]
    \[ P(X>1) = 1 - F(1) = 1 - \frac14 = \frac34 \;\checkmark \]

    注意这个 PDF 的形状：\(f(x) = x/2\) 在 \([0,2]\) 上递增—— 说明 \(X\) 更可能取靠近 2 的值。这与 \(P(X>1) = 0.75\)（大于一半）一致 ✓

    Q2 判断：连续随机变量满足 \(P(X=x) = 0\)，所以 \(P(a\leq X\leq b) = P(a\lt X\lt b)\)。

    提示

    想想端点处的概率是多少。

    解答

    正确。

    推导：

    \[ P(a\leq X\leq b) = P(a<X<b) + P(X=a) + P(X=b) \]

    而连续分布的单点概率为零：

    \[ P(X=a) = \int_a^a f(x)\mathrm{d}x = 0 \]

    所以

    \[ P(a\leq X\leq b) = P(a<X<b) \;\checkmark \]

    这个性质在计算中很实用：算连续分布区间概率时 不必纠结端点的开闭。

    但是：对离散分布必须区分端点！

    对比：

    分布类型 端点开闭
    连续 无影响
    离散 有影响（\(P(X=a)\) 可以大于 0）

    例（离散）：\(X\) 取 \(\{0,1,2\}\) 等可能，则

    \[ P(0\leq X\leq 1) = P(0)+P(1) = \frac23 \]
    \[ P(0<X<1) = 0 \quad\text{（没有取值在中间）} \]

    差别巨大 ✓

    Q3 设 \(X\sim U(0,1)\)，求 \(Y = X^2\) 的 PDF。

    提示

    \(Y = X^2\) 在 \([0,1]\) 上单调，可用变量变换公式；也可用 CDF 法。

    解答

    方法一：CDF 法

    \[ F_Y(y) = P(Y\leq y) = P(X^2\leq y) = P(X\leq\sqrt y) = \sqrt y, \quad 0\leq y\leq 1 \]

    （最后一步用了 \(F_X(x) = x\)。）

    求导：

    \[ f_Y(y) = \frac{\mathrm{d}}{\mathrm{d}y}\sqrt y = \frac{1}{2\sqrt y} \]

    方法二：变量变换公式验证

    \(g(x) = x^2\)，\(g^{-1}(y) = \sqrt y\)，\(\left\lvert\frac{\mathrm{d}x}{\mathrm{d}y}\right\rvert = \frac{1}{2\sqrt y}\)。

    \[ f_Y(y) = f_X(\sqrt y)\cdot\frac{1}{2\sqrt y} = 1\cdot\frac{1}{2\sqrt y} \;\checkmark \]

    两者一致。

    结果：

    \[ f_Y(y) = \frac{1}{2\sqrt y}, \quad 0 < y < 1 \]

    检查归一化：

    \[ \int_0^1\frac{1}{2\sqrt y}\mathrm{d}y = \left[\sqrt y\right]_0^1 = 1 \;\checkmark \]

    注意这一点：\(y\to0^+\) 时 \(f_Y(y)\to\infty\)（无界）！

    但积分仍为 1——这再次说明 PDF 可以无界， 只要「密度 × 宽度」的整体积分为 1。

    直观理解：\(x\) 接近 0 的一小段会被映射到非常窄的 \(y\) 区间， 所以那里的密度必须很大才能「装下」相应的概率质量。

    Q4 为什么正态分布不能用「逆变换采样」生成随机数？

    提示

    想想 \(F^{-1}\) 是否有闭式表达。

    解答

    因为正态的 CDF 没有初等函数的闭式表达。

    正态 CDF：

    \[ \Phi(x) = \int_{-\infty}^{x}\frac{1}{\sqrt{2\pi}}e^{-t^2/2}\,\mathrm{d}t \]

    这个积分没有初等原函数（不能用有限个多项式、 指数、三角函数的组合表示）——

    它只能用误差函数 \(\operatorname{erf}\) 或数值方法表示。

    所以 \(F^{-1}\) 也无法写成闭式，逆变换采样法用不了。

    替代方案：

    方法 原理
    Box-Muller 变换 用两个均匀随机数生成一对正态数
    Ziggurat 算法 查表 + 拒绝采样（最快）
    中心极限定理近似 多个均匀数求和（精度有限）

    Box-Muller 的核心公式：

    \[ Z_1 = \sqrt{-2\ln U_1}\cos(2\pi U_2), \qquad Z_2 = \sqrt{-2\ln U_1}\sin(2\pi U_2) \]

    其中 \(U_1, U_2\) 是独立的 \(U(0,1)\)，则 \(Z_1, Z_2\) 独立且都服从 \(N(0,1)\)。

    注意这里用到了例 3 的结果：\(-\ln U\) 与指数分布有关， 而 \(\sqrt{\cdot}\) 与 \(\chi^2\) 分布（正态的平方和）有关—— 两者组合就得到正态。

    工程意义：所有需要高斯噪声的仿真（雷达、通信、传感器） 都依赖这些算法。理解它们有助于判断仿真结果的可靠性。
