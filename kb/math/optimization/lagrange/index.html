    拉格朗日乘数法¶

    前面讲的都是无约束优化。实际工程问题几乎都有约束：

    「在满足这些条件的前提下，让目标最小。」

    拉格朗日乘数法把带约束问题转化成无约束问题。

    核心思想：把约束「折进」目标函数

    问题 目标
    原始 \(\min f(\boldsymbol{x})\)，s.t. \(h_i(\boldsymbol{x}) = 0\)
    转化后 \(\min\ \mathcal{L}(\boldsymbol{x},\boldsymbol{\lambda}) = f(\boldsymbol{x}) + \sum_i\lambda_i h_i(\boldsymbol{x})\)

    新变量 \(\lambda_i\) 称为拉格朗日乘数， 它们是要「求解」的——不是事先给定的。

    得到的方程数与未知数个数正好匹配：

    未知数 个数
    \(\boldsymbol{x}\) \(n\)
    \(\lambda\) \(m\)（约束个数）
    合计 \(n+m\)
    方程 个数
    \(\nabla_{\boldsymbol{x}}\mathcal{L} = 0\) \(n\)
    \(h_i = 0\) \(m\)
    合计 \(n+m\)

    方程数 = 未知数个数 ✓ 所以一般有唯一解（或有限个解）。

    一、等式约束：几何推导¶

    问题：

    \[ \min_{\boldsymbol{x}}f(\boldsymbol{x}) \quad\text{s.t.}\quad h(\boldsymbol{x}) = 0 \]

    几何直觉（最关键的部分）¶

    在最优解处，两者的梯度必须平行：

    \[ \nabla f(\boldsymbol{x}^*) = \lambda\nabla h(\boldsymbol{x}^*) \]

    为什么：

    情形 说明
    若 \(\nabla f\) 不平行于 \(\nabla h\) 则 \(\nabla f\) 有沿约束曲面的分量 → 沿该方向移动既降低 \(f\) 又保持约束 → 不是最优 ✗
    若两者平行 沿曲面移动无法降低 \(f\) → 可能是最优 ✓

    这就是「拉格朗日乘数」的几何含义： \(\lambda\) 是让两个梯度对齐的缩放因子。

    拉格朗日函数¶

    把上述条件写成方程，引入辅助变量 \(\lambda\)：

    \[ \mathcal{L}(\boldsymbol{x},\lambda) = f(\boldsymbol{x}) + \lambda\,h(\boldsymbol{x}) \]

    必要条件（对 \(\boldsymbol{x}\) 和 \(\lambda\) 分别求偏导令零）：

    \[ \nabla_{\boldsymbol{x}}\mathcal{L} = \nabla f(\boldsymbol{x}) + \lambda\nabla h(\boldsymbol{x}) = \boldsymbol{0} \]
    \[ \frac{\partial\mathcal{L}}{\partial\lambda} = h(\boldsymbol{x}) = 0 \]

    第二个方程正好就是原约束 ✓ —— 这就是「约束被自动满足」的机制。

    多个等式约束¶

    \[ \min f(\boldsymbol{x})\quad\text{s.t.}\quad h_i(\boldsymbol{x}) = 0,\ i=1,\dots,m \]
    \[ \mathcal{L} = f(\boldsymbol{x}) + \sum_{i=1}^{m}\lambda_ih_i(\boldsymbol{x}) \]

    几何含义：\(\nabla f\) 必须落在 \(\{\nabla h_i\}\) 张成的空间里 （即 \(\nabla f\) 是各约束梯度的线性组合）。

    二、乘数的实际含义（工程解释）¶

    这是最容易被忽略、却最有工程价值的一点。

    \(\lambda^*\) 的含义：约束放松一点，目标能改善多少。

    \[ \frac{\partial f^*}{\partial c} = -\lambda^* \]

    （对约束 \(h(\boldsymbol{x}) = c\) 的情形。）

    「影子价格」的工程解读

    结论：\(\lvert\lambda^*\rvert\) 是约束的边际价值。

    具体含义举例：

    场景 约束 \(\lambda\) 的含义
    预算约束 花费 ≤ 100 万 多给 1 万预算能降低多少成本
    功率约束 功率 ≤ 10 W 多给 1 W 能提升多少性能
    时间约束 历时 ≤ 5 s 多给 1 s 能省多少能耗
    材料约束 用钢 ≤ 1 t 多 1 kg 钢能减轻多少重量

    \(\lambda = 0\) 的含义：约束不起作用（不「活跃」）—— 此时最优解与无约束最优相同，放松约束没有收益。

    \(\lvert\lambda\rvert\) 大的含义：约束很「紧」—— 稍微放松就能显著改善目标。

    工程用途：

    决策 依据
    是否值得花成本放松约束 比较 \(\lvert\lambda\rvert\) 与放松的成本
    资源该投在哪里 投入 \(\lvert\lambda\rvert\) 最大的约束
    为什么系统「卡」在某指标上 找出 \(\lvert\lambda\rvert\) 最大的约束

    这就是经济学中的「影子价格」， 也是工程优化里最有实用价值的输出之一 （通常优化求解器都会同时给出最优乘数）。

    三、不等式约束：从等式到 KKT¶

    若约束是 \(g(\boldsymbol{x})\leq0\)，处理方式不同：

    \[ \mathcal{L}(\boldsymbol{x},\mu) = f(\boldsymbol{x}) + \mu\,g(\boldsymbol{x}) \]

    关键区别：符号条件。

    约束类型 条件 原因
    等式 \(h=0\) \(\lambda\) 任意符号 两个方向都能走
    不等式 \(g\leq0\) \(\mu\geq0\) 约束「单侧限制」，乘数必须非负

    为什么不等式约束的乘数必须 ≥ 0（直觉）

    设定：约束 \(g(\boldsymbol{x})\leq0\)，即 \(g\) 越小越「安全」。

    若 \(\mu < 0\)：拉格朗日函数 \(\mathcal{L} = f + \mu g\) 中， 减小 \(g\)（更满足约束）反而使 \(\mathcal{L}\) 增大 —— 这与「约束应该惩罚违反」的直觉矛盾 ✗

    因此必须 \(\mu\geq0\) ✓

    另一个角度（等价于「梯度方向必须一致」）：

    最优处需要「目标想往哪里走」与「约束不允许往哪里走」对抗：

    \[ -\nabla f = \mu\nabla g, \quad \mu\geq0 \]

    含义：要降低 \(f\) 就必须违反约束（两者方向相反）—— 这才说明约束真正起作用。

    若约束不起作用：则 \(\mu = 0\)，退化为无约束问题

    互补松弛条件¶

    最关键的一条：

    \[ \mu_i\,g_i(\boldsymbol{x}) = 0 \]

    含义：每个不等式约束只有两种状态：

    状态 条件 说明
    活跃（起作用） \(g_i = 0\) 且 \(\mu_i > 0\) 正好卡在边界上
    不活跃 \(g_i < 0\) 且 \(\mu_i = 0\) 有富余，不影响最优解

    两者不能同时非零 —— 这就是「互补」。

    互补松弛条件的实用价值（大幅简化问题）

    它告诉我们：不需要考虑所有约束—— 可以先猜哪些约束活跃，只处理那几个。

    在支持向量机（SVM）中的经典应用：

    样本类型 约束状态 \(\mu_i\)
    在间隔边界上（支持向量） 活跃 \(>0\)
    远离边界且分类正确 不活跃 \(=0\)

    结论：只有支持向量贡献于决策边界

    这解释了两件事：

    现象 原因
    移动非支持向量的样本不改变模型 它们的 \(\mu_i = 0\)
    稀疏性 大部分样本 \(\mu_i = 0\)

    工程意义：稀疏性使存储与预测只需保留支持向量 —— 这是 SVM 高效的原因。

    一般的工作流程：

    步骤 操作
    1 猜一个活跃集（哪些约束 \(g_i = 0\)）
    2 只对这些约束用拉格朗日法求解
    3 检查得到的 \(\mu_i\) 是否都 \(\geq0\)
    4 若不满足，调整活跃集，重复

    这就是「活跃集方法」，也是很多 QP 求解器的核心。

    四、典型例题¶

    例题 1：基础等式约束¶

    求 \(f(x,y) = x^2+y^2\) 在约束 \(x+y = 1\) 下的最小值。

    思路

    写拉格朗日函数，对三个变量求偏导令零。

    解答

    第一步：写拉格朗日函数

    \[ \mathcal{L}(x,y,\lambda) = x^2+y^2+\lambda(x+y-1) \]

    第二步：求偏导并令零

    \[ \frac{\partial\mathcal{L}}{\partial x} = 2x+\lambda = 0 \implies x = -\frac{\lambda}{2} \]
    \[ \frac{\partial\mathcal{L}}{\partial y} = 2y+\lambda = 0 \implies y = -\frac{\lambda}{2} \]
    \[ \frac{\partial\mathcal{L}}{\partial\lambda} = x+y-1 = 0 \]

    第三步：解方程组

    由前两式得 \(x = y\)，代入约束：

    \[ 2x = 1 \implies x = y = \frac12 \]

    （可回代得 \(\lambda = -1\)。）

    结果：

    \[ f_{\min} = \left(\frac12\right)^2+\left(\frac12\right)^2 = \frac12 \]

    几何验证：这是「原点 \((0,0)\) 到直线 \(x+y=1\) 的距离平方的最小值」——

    距离：

    \[ d = \frac{\lvert0+0-1\rvert}{\sqrt{1^2+1^2}} = \frac{1}{\sqrt2} \]

    所以 \(d^2 = \frac12\) ✓ 与上面一致。

    验证梯度平行：

    \[ \nabla f = (2x,2y)\bigg|_{(1/2,1/2)} = (1,1) \]
    \[ \nabla h = (1,1) \]

    确实平行（\(\lambda = -1\)）

    这道题也是「最小范数解」的原型

    \[ \min\lVert\boldsymbol{x}\rVert^2 \quad\text{s.t.}\quad \boldsymbol{a}^\top\boldsymbol{x} = b \]

    由拉格朗日法可得

    \[ \boldsymbol{x}^* = \frac{b}{\lVert\boldsymbol{a}\rVert^2}\boldsymbol{a} \]

    即最优解沿约束法向（\(\boldsymbol{a}\) 的方向）。

    本知识库「正交性与投影」一页的投影公式与此同源 —— 「投影」就是这类最小范数问题的解。

    工程应用：

    场景 含义
    冗余机器人的最小关节运动 满足末端位移前提下关节移动最少
    神经网络的最小范数解 满足拟合前提下权重最小（隐含正则化）
    最小能量控制 达到目标所需能量最小

    例题 2：乘数的经济含义¶

    某工厂生产两种产品，产量为 \(x,y\)（单位：件）。 成本函数

    \[ f(x,y) = x^2+2y^2 \]

    产能约束：\(x+y = 100\)。求最优产量与乘数，并解释乘数的含义。

    思路

    用拉格朗日法求解，然后用「乘数 = 边际价值」解释。

    解答

    第一步：拉格朗日函数

    \[ \mathcal{L} = x^2+2y^2+\lambda(x+y-100) \]

    第二步：求偏导

    \[ \frac{\partial\mathcal{L}}{\partial x} = 2x+\lambda = 0 \implies x = -\frac{\lambda}{2} \]
    \[ \frac{\partial\mathcal{L}}{\partial y} = 4y+\lambda = 0 \implies y = -\frac{\lambda}{4} \]
    \[ x + y = 100 \]

    第三步：求解

    由前两式：

    \[ x = 2y \]

    代入约束：

    \[ 2y + y = 100 \implies y = \frac{100}{3},\quad x = \frac{200}{3} \]

    乘数（回代）：

    \[ \lambda = -2x = -\frac{400}{3} \approx -133.33 \]

    最优成本：

    \[ f_{\min} = \left(\frac{200}{3}\right)^2 + 2\left(\frac{100}{3}\right)^2 = \frac{40000}{9} + \frac{20000}{9} = \frac{60000}{9} \approx 6666.67 \]

    结果：

    量 值
    \(x^*\) \(66.67\)
    \(y^*\) \(33.33\)
    \(\lambda^*\) \(-133.33\)

    乘数的含义（关键）：

    \[ \frac{\partial f^*}{\partial c} = -\lambda^* = 133.33 \]

    解读：产能每增加 1 件，成本可降低约 133.3。

    为什么 \(x\) 的产量是 \(y\) 的两倍（\(x = 2y\)）：

    产品 成本系数 说明
    \(x\) \(x^2\)（系数 1） 边际成本 \(2x\)
    \(y\) \(2y^2\)（系数 2） 边际成本 \(4y\)

    最优时两者边际成本相等（这正是次节要讲的原理）：

    \[ 2x = 4y \implies x = 2y \;\checkmark \]

    所以「成本系数小的多生产」 ✓ 符合直觉。

    「边际成本相等」是最优分配的通则

    在最优解处，所有被约束耦合的资源，其边际收益（或边际成本）必须相等：

    \[ \frac{\partial f}{\partial x_1} = \frac{\partial f}{\partial x_2} = \cdots = -\lambda \]

    为什么：若某个方向的边际成本更低，则把资源从高成本方向 移过来就能降低成本 → 还没到最优

    这个原理的应用：

    场景 最优条件
    生产分配 各线边际成本相等
    功率分配 各支路边际效率相等（等微增率准则）
    数据采样 各点边际信息量相等（最优实验设计）
    投资组合 各资产边际风险贡献相等（风险平价）

    工程价值：这给出了分配资源的定量判据， 而不只是「凭经验分配」。

    例题 3：多约束情形¶

    求 \(f(x,y,z) = xyz\) 在约束 \(x+y+z = 6\)（\(x,y,z>0\)）下的最大值。

    思路

    这是「固定和求最大乘积」的经典问题，用拉格朗日法。

    解答

    第一步：拉格朗日函数

    \[ \mathcal{L} = xyz + \lambda(x+y+z-6) \]

    第二步：三个偏导方程

    \[ \frac{\partial\mathcal{L}}{\partial x} = yz + \lambda = 0 \implies yz = -\lambda \]
    \[ \frac{\partial\mathcal{L}}{\partial y} = xz + \lambda = 0 \implies xz = -\lambda \]
    \[ \frac{\partial\mathcal{L}}{\partial z} = xy + \lambda = 0 \implies xy = -\lambda \]

    第三步：比较三式

    由 \(yz = xz\)（两者都等于 \(-\lambda\)）得

    \[ z(y-x) = 0 \implies x = y \]

    （因为 \(z > 0\)。）

    同样由 \(xz = xy\) 得

    \[ x(z-y) = 0 \implies y = z \]

    所以

    \[ x = y = z \]

    第四步：代入约束

    \[ 3x = 6 \implies x = y = z = 2 \]

    最大值：

    \[ f_{\max} = 2\times2\times2 = 8 \]

    结果：在 \(x=y=z=2\) 处取得最大值 \(8\)

    这是「算术-几何平均不等式」的一个特例

    AM-GM 不等式：

    \[ \sqrt[3]{xyz} \leq \frac{x+y+z}{3} \]

    在 \(x+y+z = 6\) 时：

    \[ \sqrt[3]{xyz} \leq \frac63 = 2 \implies xyz \leq 8 \;\checkmark \]

    等号条件正是 \(x=y=z\) —— 与拉格朗日法得到的结果一致

    这说明拉格朗日乘数法能「顺便证明」许多经典不等式：

    问题 对应不等式
    求和固定、求积最大 AM-GM
    平方和固定、求积最大 柯西-施瓦茨
    约束下求熵最大 均匀分布最优

    工程用途（等分原则）：

    场景 最优解
    给定总功率下的容量最大化 各通道等功率（注水算法的简化情形）
    给定总比特下的失真最小 各源等失真
    给定材料下的结构强度 对称设计往往最优

    注意「往往最优」的例外：若各通道特性不同 （信噪比不同），最优分配不再是等分， 而是「注水算法」——好通道多分配资源。

    这是约束条件相同但系数不同的情形， 与本节「系数相同所以等分」形成对比。

    例题 4：不等式约束与互补松弛¶

    求 \(\min f(x,y) = (x-2)^2 + (y-2)^2\)，约束 \(x + y \leq 2\)。

    思路

    先看无约束最优是否满足约束；若不满足，则约束活跃。

    解答

    第一步：先看无约束最优

    \(f\) 的无约束极小在 \((2,2)\)。

    检查约束：

    \[ x+y = 4 > 2 \quad\text{违反约束 ✗} \]

    结论：无约束最优不可行 → 约束必然活跃。

    第二步：建立 KKT 条件

    拉格朗日函数（注意形式 \(g(\boldsymbol{x}) = x+y-2\leq0\)）：

    \[ \mathcal{L} = (x-2)^2+(y-2)^2+\mu(x+y-2) \]

    条件：

    \[ \frac{\partial\mathcal{L}}{\partial x} = 2(x-2)+\mu = 0 \]
    \[ \frac{\partial\mathcal{L}}{\partial y} = 2(y-2)+\mu = 0 \]
    \[ x+y = 2 \quad\text{（因为约束活跃）} \]
    \[ \mu \geq 0 \quad\text{（乘数非负）} \]

    第三步：求解

    由前两式：

    \[ x = 2-\frac{\mu}{2}, \qquad y = 2-\frac{\mu}{2} \]

    所以 \(x = y\)。代入约束：

    \[ 2x = 2 \implies x = y = 1 \]

    求 \(\mu\)：由 \(2(x-2)+\mu = 0\)：

    \[ 2(1-2)+\mu = 0 \implies -2+\mu = 0 \implies \mu = 2 \]

    检查符号：\(\mu = 2 \geq 0\) ✓ 满足

    第四步：验证互补松弛

    \[ \mu\,g(\boldsymbol{x}) = 2\times(1+1-2) = 2\times0 = 0 \;\checkmark \]

    结果：

    量 值
    最优点 \((1,1)\)
    \(f_{\min}\) \((1-2)^2+(1-2)^2 = 2\)
    \(\mu^*\) \(2\)

    几何验证：\((2,2)\) 到直线 \(x+y=2\) 的距离是

    \[ \frac{\lvert2+2-2\rvert}{\sqrt2} = \frac{2}{\sqrt2} = \sqrt2 \]

    所以距离平方 \(= 2\) ✓ 与最优值一致。

    乘数含义：约束 \(x+y\leq2\) 的右端每增加 1， 最优值下降约 \(\mu^* = 2\)（更准确地，一阶近似）。

    验证：若约束变为 \(x+y\leq3\)，则最优在 \((1.5,1.5)\)， \(f = 2\times(0.5)^2 = 0.5\)。从 2 降到 0.5，变化 \(-1.5\)， 与「\(\mu\times1 = 2\)」量级相符（差值来自非线性， 因为原来约束不够松，二阶效应显著）。

    注意这个例子揭示的「两种情况」

    两种情形的处理完全不同：

    情形 判据 处理
    约束活跃 无约束最优违反约束 \(g = 0\)，\(\mu > 0\)
    约束不活跃 无约束最优满足约束 \(\mu = 0\)，忽略约束

    在本题中：无约束最优 \((2,2)\) 违反约束 → 活跃情形

    若改成约束 \(x+y\leq5\)：无约束最优 \((2,2)\) 满足 \(2+2=4\leq5\) → 不活跃 → 最优仍是 \((2,2)\)， 且 \(\mu = 0\)

    实用检查流程：

    步骤 操作
    1 求无约束最优
    2 检查是否满足所有约束
    3 若全部满足 → 完成（\(\mu=0\)）
    4 若违反某个 → 把该约束设为活跃，重新求解
    5 检查求得的 \(\mu\geq0\)；若不满足，说明猜错了活跃集

    第 5 步很关键：若算出 \(\mu<0\)，说明该约束不应该活跃 ——需要重新调整。这就是下一节「KKT 条件」要系统化的内容。

    五、自测¶

    Q1 求 \(f(x,y) = xy\) 在约束 \(x+y = 4\)（\(x,y>0\)）下的最大值。

    提示

    用拉格朗日法；这是「固定和求最大积」的二维版本。

    解答

    第一步：拉格朗日函数

    \[ \mathcal{L} = xy+\lambda(x+y-4) \]

    第二步：偏导令零

    \[ \frac{\partial\mathcal{L}}{\partial x} = y+\lambda = 0 \implies y = -\lambda \]
    \[ \frac{\partial\mathcal{L}}{\partial y} = x+\lambda = 0 \implies x = -\lambda \]
    \[ x+y = 4 \]

    第三步：求解

    由前两式 \(x = y\)，代入约束：

    \[ 2x = 4 \implies x = y = 2 \]

    最大值：

    \[ f_{\max} = 2\times2 = 4 \]

    验证（用 AM-GM）：对 \(x,y>0\)，

    \[ \sqrt{xy}\leq\frac{x+y}{2} = 2 \implies xy\leq4 \;\checkmark \]

    等号当且仅当 \(x = y = 2\)

    验证梯度平行：

    \[ \nabla f = (y,x)\bigg|_{(2,2)} = (2,2),\qquad \nabla h = (1,1) \]

    平行 ✓（\(\lambda = -2\)）

    顺带得到乘数的含义：\(-\lambda = 2\)， 表示「和增加 1，乘积最多增加约 2」。 验证：若约束改为 \(x+y = 4.1\)，最优在 \((2.05,2.05)\)， \(f = 4.2025\) —— 增加约 \(0.2025\)， 与一阶估计 \(2\times0.1 = 0.2\) 吻合

    Q2 用拉格朗日法证明：固定周长下正方形面积最大。

    提示

    设矩形边长 \(x,y\)，周长固定为 \(2(x+y) = P\)。

    解答

    第一步：建立问题

    固定周长 \(P\)，即约束

    \[ x+y = \frac{P}{2} \]

    目标：最大化面积

    \[ A = xy \]

    第二步：拉格朗日函数

    \[ \mathcal{L} = xy+\lambda\left(x+y-\frac{P}{2}\right) \]

    第三步：求偏导

    \[ \frac{\partial\mathcal{L}}{\partial x} = y+\lambda = 0 \]
    \[ \frac{\partial\mathcal{L}}{\partial y} = x+\lambda = 0 \]

    由两式相减：

    \[ y - x = 0 \implies x = y \]

    第四步：代入约束

    \[ 2x = \frac{P}{2} \implies x = \frac{P}{4} \]

    所以

    \[ x = y = \frac{P}{4} \]

    即正方形

    最大面积：

    \[ A_{\max} = \left(\frac{P}{4}\right)^2 = \frac{P^2}{16} \]

    验证（对比长方形）：

    设 \(x = \frac{P}{4}+d\)、\(y = \frac{P}{4}-d\)（保持周长）：

    \[ A = \left(\frac{P}{4}\right)^2-d^2 < \frac{P^2}{16} \]

    确实变小，且随 \(\lvert d\rvert\) 增大而减小

    这个结论的推广（值得记住）

    「对称性最优」的模式：

    问题 最优解
    固定周长、最大面积 正方形（二维）、圆（连续自由形状）
    固定和、最大积 各量相等（AM-GM 等号条件）
    固定面积、最小周长 正方形
    固定体积、最小表面积 立方体

    共同点：在对称性不被打破时，最优解也对称。

    但要注意「系数不同」的情况：若目标改为 \(A = 2xy\) （给 \(x\) 加权），则最优不再是正方形 —— 此时应按「边际量相等」求解：

    \[ \frac{\partial A}{\partial x} = \frac{\partial A}{\partial y} = -\lambda \]

    即 \(2y = 2x\) 仍给出 \(x = y\)（因为 \(2xy\) 对 \(x,y\) 对称）。

    若目标改为 \(A = x^2y\)，则

    \[ 2xy = x^2 \implies 2y = x \]

    不再是正方形 ✓ —— 这提醒我们「对称性来自目标的对称性」。

    Q3 求 \(\min f(x,y) = x^2+y^2\) 在约束 \(x+2y = 5\) 下的解。

    提示

    与例题 1 结构相同，只是约束系数不同。

    解答

    第一步：拉格朗日函数

    \[ \mathcal{L} = x^2+y^2+\lambda(x+2y-5) \]

    第二步：偏导令零

    \[ 2x+\lambda = 0 \implies x = -\frac{\lambda}{2} \]
    \[ 2y+2\lambda = 0 \implies y = -\lambda \]
    \[ x+2y = 5 \]

    第三步：代入约束

    \[ -\frac{\lambda}{2}+2(-\lambda) = 5 \]
    \[ -\frac{\lambda}{2}-2\lambda = -\frac{5\lambda}{2} = 5 \]
    \[ \lambda = -2 \]

    回代：

    \[ x = -\frac{-2}{2} = 1, \qquad y = -(-2) = 2 \]

    结果：\((x^*,y^*) = (1,2)\)，\(f_{\min} = 1+4 = 5\)

    几何验证：原点到直线 \(x+2y=5\) 的距离：

    \[ d = \frac{\lvert0+0-5\rvert}{\sqrt{1^2+2^2}} = \frac{5}{\sqrt5} = \sqrt5 \]

    距离平方 \(= 5\) ✓ 与 \(f_{\min}\) 一致。

    从这两道题看出的一般公式

    \[ \min\lVert\boldsymbol{x}\rVert^2\quad\text{s.t.}\quad\boldsymbol{a}^\top\boldsymbol{x} = b \]

    最优解：

    \[ \boldsymbol{x}^* = \frac{b}{\lVert\boldsymbol{a}\rVert^2}\boldsymbol{a} \]

    验证本题：\(\boldsymbol{a} = (1,2)\)、\(b = 5\)

    \[ \boldsymbol{x}^* = \frac{5}{5}(1,2) = (1,2) \;\checkmark \]

    物理含义：最优解沿约束的法向（即 \(\boldsymbol{a}\) 方向）。

    这与「投影」完全一致——投影就是「最短距离对应的点」， 也就是这个最小范数问题的解。

    Q4 设约束 \(g(x) = x-3\leq0\)，目标 \(f(x) = x^2\)。 求最优解与乘数，并说明约束是否活跃。

    提示

    先看无约束最优是否满足约束。

    解答

    第一步：无约束最优

    \[ f'(x) = 2x = 0 \implies x = 0 \]

    检查约束：

    \[ g(0) = 0-3 = -3 \leq0 \;\checkmark \]

    满足 → 约束不活跃

    第二步：结论

    量 值
    最优解 \(x^* = 0\)
    \(f_{\min}\) \(0\)
    \(\mu^*\) \(0\)（不活跃）

    验证 KKT：

    条件 检验
    平稳性 \(2(0)+\mu\cdot1 = 0 \Rightarrow \mu = 0\) ✓
    原始可行 \(-3\leq0\) ✓
    对偶可行 \(\mu = 0\geq0\) ✓
    互补松弛 \(\mu\cdot g = 0\times(-3) = 0\) ✓

    全部满足

    对比：若约束改为 \(x+2\leq0\)（即要求 \(x\leq-2\)）：

    • 无约束最优 \(x = 0\) 违反约束（\(0 > -2\)）✗
    • 约束活跃：\(x^* = -2\)
    • \(f_{\min} = 4\)
    • 求 \(\mu\)：平稳性 \(2(-2)+\mu = 0 \Rightarrow \mu = 4\geq0\)

    两种情况的核心区别：

    情形 \(\mu\) 约束状态
    无约束最优可行 \(0\) 不活跃
    无约束最优不可行 \(>0\) 活跃

    这就是「互补松弛」的两种情形， 也是实际求解时先检查无约束最优的依据 （能省掉大量计算）。
