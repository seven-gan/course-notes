    牛顿法与二阶优化¶

    上一页的梯度下降只用一阶信息（梯度）。这一页加进二阶信息 （Hessian）——收敛速度从「∝ 条件数」变成「与条件数无关」。

    牛顿法：用二次函数局部近似目标，直接跳到二次模型的极小点。

    代价是每步要算（或近似）Hessian，这在高维时很贵。

    一阶 vs 二阶：一个核心权衡

    梯度下降 牛顿法
    用的信息 梯度 梯度 + Hessian
    每步成本 \(O(n)\) \(O(n^3)\)（求逆）
    迭代次数 \(\propto\kappa\) \(\approx\) 常数
    对尺度敏感 强 不敏感
    适用维度 任意（\(10^9\)） 中小（\(10^4\) 以内）

    结论：牛顿法「每一步很贵，但只需很少步」。 所以它在中小规模、高精度需求下最优。

    一、从泰勒展开到牛顿法¶

    思路：在 \(\boldsymbol{x}_k\) 处做二阶泰勒展开：

    \[ f(\boldsymbol{x}) \approx f(\boldsymbol{x}_k) + \nabla f(\boldsymbol{x}_k)^\top(\boldsymbol{x}-\boldsymbol{x}_k) + \frac12(\boldsymbol{x}-\boldsymbol{x}_k)^\top\nabla^2f(\boldsymbol{x}_k)(\boldsymbol{x}-\boldsymbol{x}_k) \]

    直接跳到这个二次模型的极小点。

    对右边求梯度并令为零：

    \[ \nabla f(\boldsymbol{x}_k) + \nabla^2f(\boldsymbol{x}_k)(\boldsymbol{x}-\boldsymbol{x}_k) = \boldsymbol{0} \]

    解出：

    \[ \boldsymbol{x} = \boldsymbol{x}_k - \big[\nabla^2f(\boldsymbol{x}_k)\big]^{-1}\nabla f(\boldsymbol{x}_k) \]

    这就是牛顿迭代：

    \[ \boxed{\ \boldsymbol{x}_{k+1} = \boldsymbol{x}_k - H_k^{-1}\boldsymbol{g}_k\ } \]

    其中 \(H_k = \nabla^2f(\boldsymbol{x}_k)\)、\(\boldsymbol{g}_k = \nabla f(\boldsymbol{x}_k)\)。

    与梯度下降的对照：牛顿法「自带学习率」

    方法 更新式
    梯度下降 \(\boldsymbol{x}_{k+1} = \boldsymbol{x}_k - \eta\boldsymbol{g}_k\)
    牛顿法 \(\boldsymbol{x}_{k+1} = \boldsymbol{x}_k - H_k^{-1}\boldsymbol{g}_k\)

    对比可见：牛顿法相当于取

    \[ \eta_k = H_k^{-1} \]

    即「学习率」是一个矩阵，而且每步自动调整。

    这解释了为什么牛顿法对尺度不敏感：

    若把某个变量放大 \(c\) 倍（尺度变化），则

    量 变化
    梯度分量 \(\times c\)
    Hessian 对应行列 \(\times c^2\)
    \(H^{-1}g\) \(\times c^{-2}\times c = \times c^{-1}\)

    正好抵消尺度的变化 ✓ 所以牛顿法天然「尺度不变」。

    对比梯度下降：尺度变化直接改变梯度大小 → 需要重新调学习率 → 这就是它对条件数敏感的原因。

    二次函数的特殊情形：一步到位¶

    若 \(f\) 本身就是二次函数 \(f(\boldsymbol{x}) = \frac12\boldsymbol{x}^\top A\boldsymbol{x} + \boldsymbol{b}^\top\boldsymbol{x} + c\)， 则

    \[ \nabla f = A\boldsymbol{x}+\boldsymbol{b}, \qquad \nabla^2f = A \]

    牛顿迭代：

    \[ \boldsymbol{x}_1 = \boldsymbol{x}_0 - A^{-1}(A\boldsymbol{x}_0+\boldsymbol{b}) = -A^{-1}\boldsymbol{b} \]

    这正是精确最优解 ✓ 一步到位（与初值无关）。

    这解释了两件事：

    现象 解释
    牛顿法在二次函数上 1 步收敛 二阶模型就是函数本身
    牛顿法接近最优点时极快 任何光滑函数在极小点附近近似二次

    二、收敛速度：二次收敛¶

    定义：若误差满足

    \[ \lVert\boldsymbol{x}_{k+1}-\boldsymbol{x}^*\rVert \leq C\lVert\boldsymbol{x}_k-\boldsymbol{x}^*\rVert^2 \]

    则称二次收敛（\(C\) 为常数）。

    含义：每步有效数字翻倍。

    当前误差 下一步误差（\(C=1\)）
    \(10^{-1}\) \(10^{-2}\)
    \(10^{-2}\) \(10^{-4}\)
    \(10^{-4}\) \(10^{-8}\)
    \(10^{-8}\) \(10^{-16}\)（已达机器精度）

    只需 4 步就到达双精度极限

    对比：

    方法 收敛阶 达到 \(10^{-10}\) 的步数（估算）
    梯度下降（线性收敛） \(O(\rho^k)\) 取决于 \(\kappa\)，可能上千
    牛顿法（二次收敛） \(O(\varepsilon^{2})\) 约 4–6 步

    二次收敛是「局部」性质（这个前提很重要）

    定理的条件：

    条件 说明
    初值足够接近最优解 关键前提
    Hessian 在该邻域正定 保证方向正确
    \(f\) 二阶连续可微 保证导数存在

    若初值太远会怎样：

    现象 原因
    可能发散 Hessian 在远处可能负定/不定，方向变成「上升方向」
    可能震荡 二次模型与真实函数差异大
    可能跳到更远 模型极小点跑出可行区域

    反例（经典）：\(f(x) = \sqrt{x^2+1}\)（光滑凸函数）， 若初值 \(x_0\) 过大，牛顿法会震荡发散。

    这就是「牛顿法需要保护」的原因。

    带保护的牛顿法¶

    实践中的三种保护：

    策略 做法 作用
    线搜索 只在方向为下降方向时用，并选步长保证 \(f\) 下降 保证单调下降
    信赖域 限制步长 \(\lVert\Delta\boldsymbol{x}\rVert\leq\Delta_k\) 防止跳太远
    修正 Hessian 用 \(H+\lambda I\)（\(\lambda>0\) 保证正定） 修正不定情形

    方向是否为下降方向（\(H\) 正定时）：

    \[ \boldsymbol{g}^\top(-H^{-1}\boldsymbol{g}) = -\boldsymbol{g}^\top H^{-1}\boldsymbol{g} < 0 \;\checkmark \]

    （因为 \(H\succ0 \Rightarrow H^{-1}\succ0\)。）

    但 \(H\) 不定时可能为「上升方向」 ✗ → 这就是需要修正的原因。

    三、计算代价与拟牛顿法¶

    牛顿法的瓶颈¶

    操作 复杂度
    计算 Hessian \(O(n^2)\) 存储，\(O(n^2)\) 次二阶导计算
    解线性方程组 \(H\Delta = -\boldsymbol{g}\) \(O(n^3)\)

    \(n = 10^6\) 时：\(O(n^3) = 10^{18}\) —— 完全不可行 ✗

    这是牛顿法在高维深度学习中被弃用的原因。

    拟牛顿法：用梯度差近似 Hessian¶

    核心思想：不显式算 Hessian，而是用它满足的性质来迭代更新近似。

    割线条件（secant condition）：

    \[ H_{k+1}\boldsymbol{s}_k = \boldsymbol{y}_k \]

    其中

    \[ \boldsymbol{s}_k = \boldsymbol{x}_{k+1}-\boldsymbol{x}_k, \qquad \boldsymbol{y}_k = \boldsymbol{g}_{k+1}-\boldsymbol{g}_k \]

    含义：近似的 Hessian 应该把「位移」映成「梯度差」。

    理由：由泰勒展开

    \[ \boldsymbol{g}_{k+1}-\boldsymbol{g}_k \approx H(\boldsymbol{x}_{k+1}-\boldsymbol{x}_k) \]

    即 \(\boldsymbol{y}_k \approx H\boldsymbol{s}_k\)

    BFGS 更新公式¶

    \[ H_{k+1} = H_k + \frac{\boldsymbol{y}_k\boldsymbol{y}_k^\top}{\boldsymbol{y}_k^\top\boldsymbol{s}_k} - \frac{H_k\boldsymbol{s}_k\boldsymbol{s}_k^\top H_k}{\boldsymbol{s}_k^\top H_k\boldsymbol{s}_k} \]

    （这是 Hessian 逆的更新，即直接近似 \(H^{-1}\)。）

    BFGS 的两个优点

    1. 每步只 \(O(n^2)\)

    方法 每步
    牛顿法 \(O(n^3)\)
    BFGS \(O(n^2)\)

    2. 保持对称正定

    若 \(H_k\succ0\) 且 \(\boldsymbol{y}_k^\top\boldsymbol{s}_k>0\)，则 \(H_{k+1}\succ0\)

    第 2 点很重要：它保证每步方向都是下降方向， 不需要额外检查。

    保证 \(\boldsymbol{y}_k^\top\boldsymbol{s}_k>0\) 的条件：\(f\) 严格凸。

    所以 BFGS 在凸问题上非常可靠；非凸时可能需要修正 （如用 \(\boldsymbol{y}_k + \gamma\boldsymbol{s}_k\) 替代，即「阻尼 BFGS」）。

    L-BFGS：有限内存版本¶

    问题：\(O(n^2)\) 存储对 \(n = 10^6\) 仍是 \(10^{12}\) 个数 ✗

    L-BFGS 的思路：不存矩阵，只存最近 \(m\) 步的 \((\boldsymbol{s}_k,\boldsymbol{y}_k)\) 对（\(m\) 通常 5–20）， 需要矩阵-向量积时按公式重构。

    方法 存储 每步
    BFGS \(O(n^2)\) \(O(n^2)\)
    L-BFGS \(O(mn)\) \(O(mn)\)

    \(n = 10^6\)、\(m = 10\) 时：存储 \(10^7\) 个数（可行）

    为什么深度学习不用 L-BFGS

    理论上 L-BFGS 更省，但深度学习仍普遍用 SGD/Adam，原因有四：

    原因 说明
    随机性 L-BFGS 需要一致的目标函数；SGD 的损失每批都不同，割线条件失真
    小批量噪声 梯度差 \(\boldsymbol{y}_k\) 被噪声主导，Hessian 近似失效
    非凸性 曲率可能变化剧烈，历史信息过时
    超参数敏感 学习率、批大小、\(m\) 需要配合

    有效场景（L-BFGS 表现好）：

    场景 说明
    全批次训练 目标函数确定
    参数适中（\(10^4\)–\(10^6\)） 存储可行
    需要高精度 如科学计算、标定
    凸问题（如逻辑回归） 理论保证

    一句话：SGD 系列靠「噪声+多次迭代」；L-BFGS 靠「精确曲率」。 深度学习的损失曲面 + 大数据规模使前者更合适。

    四、高斯-牛顿与 Levenberg-Marquardt¶

    这是一类专门针对最小二乘的二阶方法。

    问题形式¶

    \[ \min_{\boldsymbol{x}}\ \frac12\lVert\boldsymbol{r}(\boldsymbol{x})\rVert^2 = \frac12\sum_i r_i(\boldsymbol{x})^2 \]

    这在曲线拟合、标定、SLAM、位姿估计中极其常见。

    高斯-牛顿法¶

    梯度与 Hessian（用链式法则，\(J\) 是残差的雅可比）：

    \[ \nabla f = J^\top\boldsymbol{r} \]
    \[ \nabla^2 f = J^\top J + \sum_i r_i\nabla^2r_i \]

    关键近似：忽略二阶项 \(\sum_i r_i\nabla^2r_i\)（因为它在残差小时可忽略）：

    \[ H \approx J^\top J \]

    迭代：

    \[ \boldsymbol{x}_{k+1} = \boldsymbol{x}_k - (J^\top J)^{-1}J^\top\boldsymbol{r} \]

    高斯-牛顿法的三个实用优点

    1. 不需要真正的 Hessian

    只需残差的雅可比 \(J\)（一阶导数）！ 二阶项被结构性消掉了。

    这大幅降低了实现难度。

    2. \(J^\top J\) 总是半正定

    \[ \boldsymbol{v}^\top(J^\top J)\boldsymbol{v} = \lVert J\boldsymbol{v}\rVert^2 \geq 0 \;\checkmark \]

    所以方向总是下降方向（\(J\) 列满秩时正定）。

    3. 小残差时接近牛顿法

    残差 \(\boldsymbol{r}\to\boldsymbol{0}\) 时，忽略的二阶项也 \(\to0\) → 收敛速度接近二次

    这正是最小二乘问题的「天然结构优势」。

    与最小二乘的闭环：\(J^\top J\) 与 \(J^\top\boldsymbol{r}\) 就是 正规方程的两边（回到「矩阵微积分」一页）—— 高斯-牛顿本质上是在每次迭代重新线性化并解正规方程。

    Levenberg-Marquardt（LM）¶

    问题：\(J^\top J\) 可能奇异或病态（尤其参数冗余时）。

    解决：加阻尼项

    \[ \boldsymbol{x}_{k+1} = \boldsymbol{x}_k - (J^\top J + \lambda I)^{-1}J^\top\boldsymbol{r} \]

    LM 是「梯度下降」与「高斯-牛顿」的平滑插值

    看 \(\lambda\) 的两个极端：

    \(\lambda\) 有效方法 特点
    \(\lambda\to0\) 高斯-牛顿 收敛快（接近二次）
    \(\lambda\to\infty\) 梯度下降（步长 \(1/\lambda\)） 稳定但慢

    推导（\(\lambda\) 大的情形）：

    \[ (J^\top J+\lambda I)^{-1} \approx \frac1\lambda I \]

    所以

    \[ \Delta\boldsymbol{x} \approx -\frac1\lambda J^\top\boldsymbol{r} = -\frac1\lambda\nabla f \]

    正是梯度下降（步长 \(1/\lambda\)）

    自适应调整策略（LM 的核心）：

    情形 调整
    这一步让损失下降 减小 \(\lambda\)（更信任二次模型，走牛顿步）
    这一步让损失上升/不变 增大 \(\lambda\)（更保守，退回梯度下降）

    这使它既有牛顿法的速度、又有梯度下降的稳健性。

    工程地位：LM 是非线性最小二乘的事实标准—— 从相机标定到机器人 SLAM，几乎所有需要拟合几何模型的地方都用它。

    五、典型例题¶

    例题 1：用牛顿法求平方根¶

    用牛顿法计算 \(\sqrt{2}\)。写出迭代式并计算前 3 步（从 \(x_0=1\) 出发）。

    思路

    把求平方根写成解方程 \(f(x) = x^2-2=0\)，用牛顿法求根。

    解答

    第一步：化为求根问题

    求 \(\sqrt2\) 等价于解 \(f(x) = x^2-2 = 0\)。

    第二步：推导迭代式

    牛顿法求根的一般形式（\(x_{k+1} = x_k - f(x_k)/f'(x_k)\)）：

    \[ x_{k+1} = x_k - \frac{x_k^2-2}{2x_k} \]

    化简（这是著名的「巴比伦算法」）：

    \[ x_{k+1} = \frac{2x_k^2 - x_k^2 + 2}{2x_k} = \frac{x_k^2+2}{2x_k} = \frac12\left(x_k + \frac{2}{x_k}\right) \]

    第三步：迭代

    从 \(x_0 = 1\) 出发：

    \(k\) 计算 \(x_k\) 误差
    0 —— \(1\) \(4.1\times10^{-1}\)
    1 \(\frac12(1+2) = 1.5\) \(1.5\) \(8.6\times10^{-2}\)
    2 \(\frac12(1.5+1.3333) = 1.41667\) \(1.416667\) \(2.5\times10^{-3}\)
    3 \(\frac12(1.41667+1.41176) = 1.414216\) \(1.414216\) \(2.1\times10^{-6}\)

    验证：\(\sqrt2 = 1.41421356\ldots\)

    第 3 步已精确到小数点后 6 位

    观察「有效数字翻倍」

    把误差写出来看：

    \(k\) 误差
    0 \(4.1\times10^{-1}\)
    1 \(8.6\times10^{-2}\)
    2 \(2.5\times10^{-3}\)
    3 \(2.1\times10^{-6}\)

    每步误差约「平方」：

    \[ (8.6\times10^{-2})^2 \approx 7.4\times10^{-3} \]

    （与实际 \(2.5\times10^{-3}\) 量级一致）

    这就是二次收敛：有效数字位数每步翻倍 （\(1\to2\to3\to6\to12\to\cdots\)）。

    工程意义：牛顿法是一种「极快的开方算法」—— 现代 CPU 的除法/开方指令内部就用类似迭代。

    另一个著名例子：快速平方根倒数 用「魔数 + 一次牛顿迭代」，精度已足够游戏图形学使用。

    例题 2：牛顿法的发散（为什么需要保护）¶

    设 \(f(x) = \sqrt{x^2+1}\)。从 \(x_0 = 0.5\) 出发用纯牛顿法，观察行为。

    思路

    先算出梯度与 Hessian 的表达式，再迭代。

    解答

    第一步：求梯度和二阶导

    \[ f'(x) = \frac{x}{\sqrt{x^2+1}} \]
    \[ f''(x) = \frac{1\cdot\sqrt{x^2+1} - x\cdot\frac{x}{\sqrt{x^2+1}}}{x^2+1} = \frac{(x^2+1)-x^2}{(x^2+1)^{3/2}} = \frac{1}{(x^2+1)^{3/2}} \]

    注意 \(f''(x) > 0\) 恒成立 —— 函数是严格凸的 ✓

    第二步：牛顿迭代式

    \[ x_{k+1} = x_k - \frac{f'(x_k)}{f''(x_k)} = x_k - \frac{x_k/\sqrt{x_k^2+1}}{1/(x_k^2+1)^{3/2}} \]

    化简（注意 \((x^2+1)^{3/2}/\sqrt{x^2+1} = x^2+1\)）：

    \[ x_{k+1} = x_k - x_k(x_k^2+1) = -x_k^3 \]

    第三步：迭代（\(x_0 = 0.5\)）

    \(k\) \(x_k\) \(\lvert x_k\rvert\)
    0 \(0.5\) \(0.5\)
    1 \(-0.125\) \(0.125\)
    2 \(0.001953\) \(\approx0.002\)
    3 \(-7.5\times10^{-9}\) 极小

    这次收敛了 ✓（因为初值已足够接近）

    第四步：换成较大初值 \(x_0 = 2\)

    \(k\) \(x_k\) \(\lvert x_k\rvert\)
    0 \(2\) \(2\)
    1 \(-8\) \(8\)
    2 \(512\) \(512\)
    3 \(-1.34\times10^{8}\) 爆炸

    发散 ✗ ——\(\lvert x_k\rvert\) 增长极快（三次方）。

    这个反例的教训（关键）

    函数是凸的、光滑的、甚至有唯一全局最小—— 但纯牛顿法仍然会发散。

    原因：

    观察 说明
    迭代式 \(x_{k+1}=-x_k^3\) 当 \(\lvert x_k\rvert>1\) 时，\(\lvert x_{k+1}\rvert = \lvert x_k\rvert^3\) 爆炸
    收敛区域是 \(\lvert x_0\rvert<1\) 只有这个范围内才收敛
    走出范围就永不回头 因为映射是三次方增长

    这说明了什么：

    \[ \text{凸性} \not\Rightarrow \text{牛顿法收敛} \]

    凸性只保证「局部最优 = 全局最优」， 不保证牛顿法的迭代稳定。

    这就是为什么实践中必须加保护：

    保护手段 作用
    线搜索 若新点使 \(f\) 增大，就缩短步长
    信赖域 限制 \(\lvert\Delta x\rvert\) 不超过信任半径
    混合策略 远离最优时用梯度下降，接近时切牛顿

    在这道题里：若加线搜索（要求 \(f\) 下降）， 从 \(x_0=2\) 出发时，第 1 步的 \(-8\) 会让 \(f\) 增大 （\(f(2)=\sqrt5\approx2.236\)，\(f(-8)=\sqrt{65}\approx8.06\)） → 线搜索会自动缩短步长，避免发散

    例题 3：二次收敛速度的验证¶

    用牛顿法解 \(f(x) = x^3 - 2 = 0\)（即求 \(\sqrt[3]{2}\)）， 从 \(x_0 = 1\) 出发，验证误差的平方关系。

    思路

    推导迭代式，算出误差序列，检验 \(\varepsilon_{k+1}\approx C\varepsilon_k^2\)。

    解答

    第一步：迭代式

    \(f = x^3-2\)，\(f' = 3x^2\)：

    \[ x_{k+1} = x_k - \frac{x_k^3-2}{3x_k^2} = \frac{3x_k^3 - x_k^3 + 2}{3x_k^2} = \frac{2x_k^3+2}{3x_k^2} \]

    第二步：迭代

    \(\sqrt[3]{2} = 1.2599210499\ldots\)

    \(k\) \(x_k\) 误差 \(\varepsilon_k\)
    0 \(1.0000000\) \(2.60\times10^{-1}\)
    1 \(\frac{2+2}{3} = 1.3333333\) \(7.34\times10^{-2}\)
    2 \(\frac{2(2.37037)+2}{3(1.77778)} = 1.2638889\) \(3.97\times10^{-3}\)
    3 \(\approx 1.2599335\) \(1.24\times10^{-5}\)
    4 \(\approx 1.2599211\) \(1.2\times10^{-10}\)

    第三步：验证平方关系

    步 \(\varepsilon_k\) \(\varepsilon_k^2\) \(\varepsilon_{k+1}\)
    0→1 \(2.60\times10^{-1}\) \(6.8\times10^{-2}\) \(7.34\times10^{-2}\)
    1→2 \(7.34\times10^{-2}\) \(5.4\times10^{-3}\) \(3.97\times10^{-3}\)
    2→3 \(3.97\times10^{-3}\) \(1.6\times10^{-5}\) \(1.24\times10^{-5}\)
    3→4 \(1.24\times10^{-5}\) \(1.5\times10^{-10}\) \(1.2\times10^{-10}\)

    每步的 \(\varepsilon_{k+1}\) 与 \(\varepsilon_k^2\) 同量级

    比例常数约 \(C\approx0.5\)（随步数趋于稳定）。

    结论：二次收敛得到数值验证

    为什么是「有效数字翻倍」

    若 \(\varepsilon_k = 10^{-m}\)，则

    \[ \varepsilon_{k+1} \approx 10^{-2m} \]

    指数从 \(m\) 变成 \(2m\) —— 这就是「位数翻倍」。

    步 有效数字位数
    0 \(1\)
    1 \(1\)
    2 \(2\)
    3 \(4\)–\(5\)
    4 \(9\)–\(10\)

    达到双精度（约 16 位）只需约 5–6 步

    对比二分法：每次误差减半 → 需要 \(\log_2(10^{16}) \approx 53\) 步。

    牛顿法比二分法快约 10 倍（在光滑问题上前提下）。

    但代价：需要导数，且需要好的初值。

    例题 4：高斯-牛顿法拟合¶

    用高斯-牛顿法推导拟合模型 \(y = a e^{bx}\) 的迭代式。

    思路

    先线性化（取对数）或直接对残差求雅可比。

    解答

    第一步：定义残差

    给定数据 \((t_i, y_i)\)，\(i=1,\dots,N\)，残差为

    \[ r_i(a,b) = y_i - a e^{bt_i} \]

    目标：\(\min\frac12\sum_i r_i^2\)。

    第二步：求雅可比

    \[ \frac{\partial r_i}{\partial a} = -e^{bt_i} \]
    \[ \frac{\partial r_i}{\partial b} = -a t_i e^{bt_i} \]

    所以（第 \(i\) 行）

    \[ J_{i,\cdot} = \begin{bmatrix}-e^{bt_i} & -a t_i e^{bt_i}\end{bmatrix} \]

    第三步：高斯-牛顿迭代

    \[ \begin{bmatrix}a\\b\end{bmatrix}_{k+1} = \begin{bmatrix}a\\b\end{bmatrix}_k - (J^\top J)^{-1}J^\top\boldsymbol{r} \]

    其中 \(J\)、\(\boldsymbol{r}\) 在 \((\hat a_k,\hat b_k)\) 处取值。

    具体形式（\(J^\top J\) 的四个元素）：

    \[ (J^\top J)_{11} = \sum_i e^{2bt_i} \]
    \[ (J^\top J)_{12} = (J^\top J)_{21} = \sum_i a t_i e^{2bt_i} \]
    \[ (J^\top J)_{22} = \sum_i a^2t_i^2e^{2bt_i} \]

    右端：

    \[ (J^\top\boldsymbol{r})_1 = -\sum_i e^{bt_i}r_i \]
    \[ (J^\top\boldsymbol{r})_2 = -\sum_i at_ie^{bt_i}r_i \]

    这就是可直接编程实现的迭代式。

    一个更简单的做法（线性化）

    对指数模型可以先取对数：

    \[ \ln y = \ln a + bx \]

    令 \(A = \ln a\)，则变成线性最小二乘：

    变量 线性形式
    新目标 \(\ln y_i\)
    参数 \(A, b\)
    模型 \(\ln y_i \approx A + bx_i\)

    一次求解即可（无需迭代）

    但要注意这个「取对数」的代价：

    方面 说明
    改变了误差结构 对数变换使小 \(y\) 的误差被放大、大 \(y\) 的被压缩
    结果不同 对数域的最优 ≠ 原域的最小二乘最优
    权重偏移 等价于给不同数据点不同权重（\(\propto y_i^{-2}\)）

    何时可以用：

    情形 选择
    相对误差大致相同（乘性噪声） 取对数 ✓（甚至更合理）
    绝对误差大致相同（加性噪声） 不要取对数，用高斯-牛顿/数值优化
    不确定 用非线性方法

    工程建议：先试对数线性化（快、稳、有全局解）， 若拟合效果不满意，再改用迭代的非线性最小二乘。

    这个「误差结构决定方法」的原则与「最大似然估计」一页的 结论一致——不同的噪声假设对应不同的目标函数。

    六、用在哪些课程里¶

    无人系统自主决策与优化 · 轨迹优化与最优控制¶

    • 轨迹优化常用 L-BFGS（参数规模中等、需要高精度）
    • 直接配点法把最优控制离散成大规模非线性规划（NLP）
    • SQP（序列二次规划）：每步解一个 QP 子问题，用二阶信息

    机器人学 · SLAM 与位姿估计¶

    • 图优化 SLAM：主要用高斯-牛顿或 LM（残差是重投影误差）
    • Bundle Adjustment（视觉重建）：大规模最小二乘，用 LM
    • 手眼标定：非线性最小二乘拟合参数
    • 逆运动学数值解：用雅可比迭代（高斯-牛顿的特例）

    模式识别 · 二阶优化与二阶近似¶

    • 牛顿法在中小规模问题上（如逻辑回归）比 SGD 快
    • K-FAC、Hessian-free 用二阶信息加速神经网络训练
    • 二阶方法的近似（对角、块对角）是 Adam 等方法的理论基础

    智能传感与信息处理 · 参数标定¶

    • 传感器标定是典型的非线性最小二乘问题 → LM 标准解法
    • 误差模型拟合：用高斯-牛顿迭代
    • 状态估计的迭代扩展卡尔曼滤波（IEKF）用高斯-牛顿的迭代形式

    七、自测¶

    Q1 写出用牛顿法求 \(\sqrt[3]{5}\) 的迭代式。

    提示

    解 \(x^3-5=0\)。

    解答

    化为求根：\(f(x) = x^3-5\)，\(f'(x) = 3x^2\)。

    迭代式：

    \[ x_{k+1} = x_k - \frac{x_k^3-5}{3x_k^2} \]

    化简：

    \[ = \frac{3x_k^3 - x_k^3 + 5}{3x_k^2} = \frac{2x_k^3+5}{3x_k^2} \]

    优雅形式：

    \[ \boxed{\ x_{k+1} = \frac{1}{3}\left(2x_k + \frac{5}{x_k^2}\right)\ } \]

    验证（从 \(x_0 = 2\)）：

    \(k\) \(x_k\)
    0 \(2\)
    1 \(\frac13(4+1.25) = 1.75\)
    2 \(\frac13(3.5+1.6327) = 1.7109\)
    3 \(\approx1.709976\)

    真值 \(\sqrt[3]{5} = 1.709976\)… ✓ 3 步就精确

    与「加权平均」类比（第 \(n\) 次根的牛顿迭代）：

    \[ x_{k+1} = \frac{1}{n}\left((n-1)x_k + \frac{a}{x_k^{n-1}}\right) \]

    \(n=2\) 时就是例题 1 的巴比伦算法

    这个结构说明：牛顿迭代常写成「旧值与新估计的加权平均」， 权重由 \(n\) 决定——直观上就是从两侧夹逼。

    Q2 判断：牛顿法一定比梯度下降收敛快。

    提示

    比较两者的代价与适用条件。

    解答

    不对。要分情形讨论。

    牛顿法快的情形：

    条件 原因
    参数规模小（\(<10^4\)） \(O(n^3)\) 可接受
    接近最优解 二次收敛发挥作用
    需要高精度 步数少
    条件数大 对尺度不敏感

    牛顿法慢/不可用的情形：

    条件 原因
    高维（\(>10^6\)） \(O(n^3)\) 完全不可行
    目标函数有噪声（随机梯度） 割线条件失真
    初值远离最优 可能发散（例题 2）
    Hessian 难以计算 实现成本高
    非凸且曲率变化剧烈 历史信息过时

    关键对比（要用「总代价」而非「每步代价」）：

    方法 每步 步数 总代价（\(n=10^6\)）
    梯度下降 \(O(n)\) \(10^5\) \(10^{11}\) ✓
    牛顿法 \(O(n^3) = 10^{18}\) \(\approx10\) \(10^{19}\) ✗
    L-BFGS \(O(mn) = 10^7\) \(10^3\) \(10^{10}\) ✓

    结论：

    规模 推荐
    \(n\lesssim10^4\) 牛顿法/BFGS
    \(n\sim10^5\)–\(10^7\) L-BFGS
    \(n\gtrsim10^7\) 且随机 SGD/Adam

    「最快的算法」取决于问题的规模与结构—— 这是优化实践的核心判断。

    Q3 为什么高斯-牛顿法不需要二阶导数？

    提示

    看 Hessian 的分解，以及最小二乘的特殊结构。

    解答

    因为最小二乘的 Hessian 可分解，且二阶项在小残差时可忽略。

    第一步：Hessian 的分解

    对 \(f = \frac12\sum_i r_i^2\) 求梯度：

    \[ \frac{\partial f}{\partial x_j} = \sum_i r_i\frac{\partial r_i}{\partial x_j} \]

    再求一次导（用乘积法则）：

    \[ \frac{\partial^2 f}{\partial x_j\partial x_k} = \sum_i\left(\frac{\partial r_i}{\partial x_j}\frac{\partial r_i}{\partial x_k} + r_i\frac{\partial^2 r_i}{\partial x_j\partial x_k}\right) \]

    写成矩阵形式：

    \[ \nabla^2f = \underbrace{J^\top J}_{\text{一阶导！}} + \underbrace{\sum_i r_i\nabla^2r_i}_{\text{二阶导}} \]

    第二步：关键观察

    项 需要什么导数
    \(J^\top J\) 只需一阶导（雅可比 \(J\)）✓
    \(\sum_i r_i\nabla^2 r_i\) 需要二阶导 ✗

    第三步：忽略第二项

    理由：

    情形 第二项的大小
    残差 \(\boldsymbol{r}\to\boldsymbol0\)（拟合良好） \(\to0\)，可忽略 ✓
    残差较大但模型接近线性 二阶导小，可忽略
    残差大且强非线性 不可忽略（高斯-牛顿可能失效）✗

    这就是「结构化」带来的好处： 问题的特殊形式让二阶信息变得可用一阶信息构造。

    工程价值：

    方面 好处
    实现 只需写残差与雅可比（一阶）
    计算 省掉二阶导的计算与存储
    性质 \(J^\top J\) 自动半正定 ✓

    对比一般的牛顿法：需要完整 Hessian， 且需要额外处理「Hessian 可能不定」的问题。

    一句话：最小二乘问题的结构，使得「近似二阶信息」 可以免费获得——这是它成为工程标准方法的原因。

    Q4 为什么 LM 方法要比纯高斯-牛顿法更常用？

    提示

    考虑 \(J^\top J\) 奇异或病态的情形。

    解答

    因为 LM 用阻尼项换来了稳健性。

    高斯-牛顿的三个失效情形：

    情形 后果
    \(J^\top J\) 奇异（参数冗余/不可辨识） 无法求逆 ✗
    \(J^\top J\) 病态（条件数大） 步长巨大、震荡 ✗
    初值远离最优 可能发散 ✗

    LM 的修正：

    \[ (J^\top J + \lambda I)^{-1}J^\top\boldsymbol{r} \]

    三个好处：

    1. 一定可逆：\(J^\top J\succeq0\)，加 \(\lambda I\)（\(\lambda>0\)）后 正定 ✓ → 必有逆。

    2. 改善条件数：

    \[ \kappa(J^\top J+\lambda I) < \kappa(J^\top J) \]

    （因为加 \(\lambda\) 到所有特征值上，小特征值的相对提升更多。）

    3. 自适应地在两种方法间切换：

    \(\lambda\) 变化 行为
    损失下降 减小 \(\lambda\) → 更像牛顿（快）
    损失上升 增大 \(\lambda\) → 更像梯度下降（稳）

    这就是「信任域」思想的实现： \(\lambda\) 反映「我有多信任当前的二次模型」。

    对比总结：

    方法 稳健性 速度 实现
    纯高斯-牛顿 差 快 简单
    梯度下降 好 慢 最简单
    LM 好 ✓ 快 ✓ 中等

    实践结论：

    \[ \text{非线性最小二乘} \Rightarrow \text{首选 LM} \]

    唯一的代价：\(\lambda\) 需要调整策略（通常用「下降就减半、 上升就加倍」的简单规则）。
