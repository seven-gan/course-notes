    优化问题与凸性¶

    整门机器学习的训练过程，都可以写成一句话：

    找一个让损失最小的参数。

    这句话的数学形式就是优化问题：

    \[ \min_{\boldsymbol{x}} f(\boldsymbol{x}) \quad\text{s.t.}\quad \boldsymbol{x}\in\mathcal{X} \]

    这一页讲清楚问题的分类与凸性——后者决定了「局部最优是否等于全局最优」， 这是优化理论中最关键的分水岭。

    为什么「凸性」是优化的分水岭

    性质 凸优化 非凸优化
    局部最优 一定是全局最优 ✓ 可能只是局部
    求解难度 多项式时间（可靠） NP 难（一般情形）
    算法保证 有收敛证明 通常只能给「不错的解」
    例子 线性回归、SVM、逻辑回归 神经网络、聚类

    一句话：凸 ⇒ 梯度下降一定收敛到全局最优；非凸 ⇒ 只能寄希望于好运。

    这就是为什么深度学习「能work」需要额外解释（非凸却常常效果好）。

    一、问题的分类¶

    按变量类型¶

    类型 变量取值 求解方法 例子
    连续优化 \(\boldsymbol{x}\in\mathbb{R}^n\) 梯度类方法 神经网络训练
    离散优化 \(\boldsymbol{x}\in\mathbb{Z}^n\) 组合方法 旅行商、调度

    关键差别：离散优化不能用梯度（不可导），难度通常高得多。

    工程含义：

    情形 做法
    本来离散 用整数规划、动态规划、启发式
    想让连续方法可用 松弛为连续问题

    松弛的例子：把「必须选 0 或 1」放松为「可以取 \([0,1]\) 内任意值」， 求出解后再取整到最近的整数。这常给出「近似最优」的解。

    按约束¶

    类型 形式 求解
    无约束 \(\min f(\boldsymbol{x})\) 令梯度为零
    约束 \(\min f\)，s.t. \(g_i(\boldsymbol{x})\leq0\) 拉格朗日乘数法、KKT

    按函数性质¶

    类型 条件 难度
    线性规划（LP） \(f\) 与约束都线性 简单（单纯形法）
    二次规划（QP） \(f\) 二次，约束线性 中等
    凸优化 \(f\) 凸，可行集凸 可靠可解
    非线性非凸 —— 困难

    二、全局最优与局部最优¶

    局部最优：存在邻域，使得

    \[ f(\boldsymbol{x}^*) \leq f(\boldsymbol{x}), \quad \forall \boldsymbol{x}\in N(\boldsymbol{x}^*)\cap\mathcal{X} \]

    全局最优：在整个可行集上最小。

    局部最优 ≠ 全局最优（非凸情形）

    典型陷阱：\(f(x) = x^4 - 3x^2 + x\) 有多个极值点。

    概念 含义
    局部最优 在附近最小
    全局最优 在所有点中最小

    梯度下降的行为：

    初值位置 收敛到
    靠近某个局部极小 那个局部极小（可能不是全局）
    靠近全局极小 全局极小（运气好）

    工程含义：初值很重要。

    深度学习中为什么还能用：

    观察 解释
    高维空间中「坏的」局部极小很少 维度越高，鞍点比局部极小更常见
    过参数化 参数多于数据时，损失曲面变得「平缓」
    随机梯度噪声 有助于跳出浅的局部极小
    实践验证 不同初值常收敛到相近的损失值

    注意：这一条是「经验观察 + 部分理论」，不是完全的定理。

    驻点、极值点、鞍点¶

    驻点：\(\nabla f(\boldsymbol{x}) = \boldsymbol{0}\)。

    判据（用 Hessian，回到泰勒展开那一页）：

    Hessian 性质 结论
    正定 局部极小
    负定 局部极大
    不定 鞍点
    半定 需更高阶信息

    鞍点在优化中的重要性（高维特有）

    鞍点：某些方向是极小、另一些方向是极大的点。

    为什么高维中鞍点特别多：

    \(n\) 维空间中，Hessian 有 \(n\) 个特征值。 「恰好全部同号」的概率随 \(n\) 增大而指数下降 （若特征值符号随机，概率约 \(2^{-(n-1)}\)）。

    维度 「全部同号」的概率（粗略）
    \(1\) \(1\)
    \(3\) \(1/4\)
    \(10\) \(\approx 1/512\)
    \(1000\) 极小

    结论：高维优化中，绝大多数驻点是鞍点，而非局部极小。

    梯度下降会停在鞍点吗：理论上会（梯度为零）， 但实际上：

    原因 说明
    精确到达鞍点概率为零 浮点运算几乎不可能精确落在鞍点
    鞍点附近梯度很小但非零 会缓慢「滑过」鞍点向极小方向
    随机梯度噪声 帮助逃离
    负曲率方向 有些算法（如 Newton 类）主动利用

    这就是「高维非凸优化在实践中不难」的核心原因之一。

    三、凸集与凸函数¶

    凸集¶

    定义：集合 \(C\) 是凸的，若对任意 \(\boldsymbol{x},\boldsymbol{y}\in C\) 与任意 \(\theta\in[0,1]\)：

    \[ \theta\boldsymbol{x} + (1-\theta)\boldsymbol{y} \in C \]

    直观：集合内任意两点的连线都在集合内（没有「凹进去」的部分）。

    凸集例子：

    集合 是否凸 说明
    超平面 \(\{\boldsymbol{x}:\boldsymbol{a}^\top\boldsymbol{x}=b\}\) ✓ 平面本身
    半空间 \(\{\boldsymbol{x}:\boldsymbol{a}^\top\boldsymbol{x}\leq b\}\) ✓
    球/椭球 ✓
    多面体（线性不等式定义） ✓
    圆环（挖掉中间的圆） ✗ 连心线不在集合内
    两个分离的球之并 ✗ 连接线穿过外面

    凸函数¶

    定义：\(f\) 是凸函数，若其定义域为凸集，且对任意 \(\boldsymbol{x},\boldsymbol{y}\) 与 \(\theta\in[0,1]\)：

    \[ f(\theta\boldsymbol{x}+(1-\theta)\boldsymbol{y}) \leq \theta f(\boldsymbol{x})+(1-\theta)f(\boldsymbol{y}) \]

    几何含义：函数图像上任意两点连线，都在函数图像的上方 （或：弦在弧之上）。

    等价判据：

    判据 形式 适用
    一阶 \(f(\boldsymbol{y}) \geq f(\boldsymbol{x}) + \nabla f(\boldsymbol{x})^\top(\boldsymbol{y}-\boldsymbol{x})\) 可微
    二阶 \(\nabla^2f(\boldsymbol{x}) \succeq 0\)（Hessian 半正定） 二阶可微

    一阶条件的几何意义（「切线在下方」）

    \[ f(\boldsymbol{y}) \geq f(\boldsymbol{x}) + \nabla f(\boldsymbol{x})^\top(\boldsymbol{y}-\boldsymbol{x}) \]

    右边是 \(f\) 在 \(\boldsymbol{x}\) 处的切线（或切平面）。

    含义：切线永远在函数下方 —— 这是凸函数最直观的特征。

    重要推论（一阶最优性条件）：

    \[ \nabla f(\boldsymbol{x}^*) = \boldsymbol{0} \implies \boldsymbol{x}^* \text{ 是全局最优} \]

    推导：把 \(\boldsymbol{x}=\boldsymbol{x}^*\) 代入一阶条件（\(\nabla f = 0\)）：

    \[ f(\boldsymbol{y}) \geq f(\boldsymbol{x}^*) \quad \forall \boldsymbol{y} \]

    对所有 \(\boldsymbol{y}\) 成立 → 全局最小 ✓

    这就是「凸函数只需令梯度为零」的严格依据—— 而对非凸函数，梯度为零只给出局部信息。

    保持凸性的运算¶

    这些规则让「判断一个函数是否凸」变得容易。

    运算 结果
    \(f,g\) 凸，\(a,b\geq0\) \(af+bg\) 凸
    \(f\) 凸，\(A\) 矩阵 \(f(A\boldsymbol{x}+\boldsymbol{b})\) 凸
    \(f,g\) 凸且都 \(\geq0\) \(fg\) 不一定凸 ✗
    \(\max(f_1,\dots,f_m)\)（都凸） 凸 ✓
    \(\sup\) of 凸函数族 凸 ✓
    \(f\) 凸，\(g\) 凸且非减 \(g(f(\boldsymbol{x}))\) 凸 ✓
    \(h\) 凸 \(\{\boldsymbol{x}:h(\boldsymbol{x})\leq c\}\) 是凸集 ✓

    最值得记的两条：max 与 sup 保持凸性

    1. \(\max\) 保持凸性

    \[ f(\boldsymbol{x}) = \max_i f_i(\boldsymbol{x}) \quad\text{（}f_i\text{ 均凸）} \Rightarrow f \text{ 凸} \]

    用途：最小最大问题、鲁棒优化中的「最坏情况」目标 都是 max 形式。

    例：鲁棒优化要求「在所有可能情形下都满足约束」 → 把每个情形的约束写成不等式，取最大值 ≤ 0 → 仍是凸问题。

    2. \(\sup\)（写法的上确界）也保持凸性

    这一条更强的版本：任何凸函数的逐点上确界仍是凸的。

    用途：构造凸函数（如「支撑函数」），以及证明某些复杂函数的凸性。

    反面：\(\min\) 不一定保持凸性 —— 这解释了为什么「取最小值」的操作会把凸问题变成非凸问题。

    四、常见凸/非凸函数一览¶

    这张表在判断问题时极其有用。

    函数 凸性 备注
    \(f(\boldsymbol{x}) = \boldsymbol{a}^\top\boldsymbol{x}+b\) 凸（也是凹） 仿射函数
    \(f = \boldsymbol{x}^\top A\boldsymbol{x}\)（\(A\succeq0\)） 凸 二次型
    \(f = \lVert\boldsymbol{x}\rVert_p\)（\(p\geq1\)） 凸 任何范数都凸
    \(f = \lVert\boldsymbol{x}\rVert_0\) 非凸 计数 = 非凸
    \(f = -\log x\)（\(x>0\)） 凸
    \(f = e^x\) 凸
    \(f = x\log x\) 凸 负熵
    \(f = \log(1+e^x)\) 凸 softplus
    log-sum-exp \(\log\sum_i e^{x_i}\) 凸 ✓ 重要
    \(\max_i x_i\) 凸
    \(\lvert x\rvert\) 凸
    \(\sin x\) 非凸 振荡

    log-sum-exp 为什么重要

    \[ f(\boldsymbol{x}) = \log\sum_{i=1}^{n}e^{x_i} \]

    两个用途：

    1. 它是 \(\max\) 的光滑近似

    性质 说明
    下界 \(f(\boldsymbol{x}) \geq \max_i x_i\)
    上界 \(f(\boldsymbol{x}) \leq \max_i x_i + \log n\)
    极限 \(f(\boldsymbol{x})\to\max_i x_i\)（当 \(\max\) 明显大于其它）

    所以「用 log-sum-exp 近似 max」既保持可微性又不改变最优解的本质。

    2. 它是 softmax 与交叉熵的数值稳定实现核心

    \[ \log\operatorname{softmax}(\boldsymbol{z})_i = z_i - \underbrace{\log\sum_j e^{z_j}}_{\text{log-sum-exp}} \]

    计算时先减去最大值（平移不变性，回到「Logistic 与 Softmax 导数」一页） 就得到数值稳定的实现。

    一般规律：「指数 + 求和 + 取对数」的组合保持凸性 —— 这类函数在机器学习中到处都是（softmax、交叉熵、摊薄损失）。

    五、典型例题¶

    例题 1：判断凸性¶

    判断下列函数的凸性：

    (a) \(f(x) = x^4\)。(b) \(f(x) = x^3\)。© \(f(\boldsymbol{x}) = \lVert A\boldsymbol{x}-\boldsymbol{b}\rVert^2\)。

    思路

    用二阶条件（求二阶导或 Hessian）。

    解答

    (a) \(f(x) = x^4\)

    \[ f'(x) = 4x^3, \qquad f''(x) = 12x^2 \geq 0 \;\checkmark \]

    二阶导非负（仅 \(x=0\) 处为零，其它严格正）

    结论：凸函数（严格凸，除 0 点）

    (b) \(f(x) = x^3\)

    \[ f'(x) = 3x^2, \qquad f''(x) = 6x \]

    \(f''(x) < 0\) 当 \(x<0\)，\(>0\) 当 \(x>0\) → 符号变化 ✗

    结论：非凸函数

    验证（用定义找反例）：取 \(x = -1\)、\(y = 1\)、\(\theta = 0.5\)。

    左边：

    \[ f(0) = 0 \]

    右边：

    \[ 0.5f(-1)+0.5f(1) = 0.5(-1)+0.5(1) = 0 \]

    两者相等（不构成反例）。需要另取点。试 \(x=-2\)、\(y=1\)、\(\theta=0.5\)：

    左边：\(f(-0.5) = -0.125\)

    右边：\(0.5(-8)+0.5(1) = -3.5\)

    左边 \((-0.125) >\) 右边 \((-3.5)\) → 违反凸性定义 ✗

    结论确认：非凸 ✓

    © \(f(\boldsymbol{x}) = \lVert A\boldsymbol{x}-\boldsymbol{b}\rVert^2\)

    展开（回到矩阵微积分一页）：

    \[ f(\boldsymbol{x}) = \boldsymbol{x}^\top A^\top A\boldsymbol{x} - 2\boldsymbol{b}^\top A\boldsymbol{x} + \boldsymbol{b}^\top\boldsymbol{b} \]

    求梯度与 Hessian：

    \[ \nabla f = 2A^\top(A\boldsymbol{x}-\boldsymbol{b}), \qquad \nabla^2 f = 2A^\top A \]

    判断 \(2A^\top A\) 的正定性：对任意 \(\boldsymbol{v}\)：

    \[ \boldsymbol{v}^\top(2A^\top A)\boldsymbol{v} = 2\lVert A\boldsymbol{v}\rVert^2 \geq 0 \;\checkmark \]

    半正定 → 凸函数 ✓

    并且：

    条件 结论
    \(A\) 列满秩 \(A^\top A\) 正定 → 严格凸（唯一最优解）
    \(A\) 秩亏 半正定 → 凸但不严格（最优解不唯一）

    工程含义：最小二乘问题总是凸的 ✓ 这是它可靠的原因。

    这类判断的通用流程

    步骤 操作
    1 求 Hessian
    2 检查是否半正定（所有特征值 \(\geq0\)，或所有顺序主子式 \(\geq0\)）
    3 若半正定 → 凸；若正定 → 严格凸

    常用工具：

    判据 适用
    特征值全 \(\geq0\) 通用
    顺序主子式全 \(\geq0\) 对称矩阵（Sylvester 判据的推广）
    \(\boldsymbol{v}^\top H\boldsymbol{v}\geq0\) 对任意 \(\boldsymbol{v}\) 有时更容易验证

    例题 2：凸集判定¶

    判断下列集合是否凸：

    (a) \(C_1 = \{(x_1,x_2): x_1^2+x_2^2\leq1\}\)（单位圆盘）

    (b) \(C_2 = \{(x_1,x_2): x_1^2+x_2^2=1\}\)（单位圆周）

    © \(C_3 = \{(x_1,x_2): x_1x_2\geq1,\ x_1>0\}\)

    思路

    (a) 是「凸函数的子水平集」；(b) 只在边界；© 取两点看连线。

    解答

    (a) 单位圆盘

    \(C_1\) 是凸函数 \(f(\boldsymbol{x}) = x_1^2+x_2^2\) 的子水平集：

    \[ C_1 = \{\boldsymbol{x}: f(\boldsymbol{x})\leq1\} \]

    凸函数的子水平集一定是凸集 ✓（前面「保持凸性的运算」表中的最后一条）

    结论：凸集 ✓

    (b) 单位圆周

    取两点 \(\boldsymbol{x} = (1,0)\) 与 \(\boldsymbol{y} = (-1,0)\)，它们在 \(C_2\) 上。

    中点：

    \[ \frac{\boldsymbol{x}+\boldsymbol{y}}{2} = (0,0) \]

    但 \((0,0)\) 不在 \(C_2\) 上（\(\lVert(0,0)\rVert = 0\neq1\)）✗

    结论：非凸集 ✗

    关键区别：「\(\leq\)」给出凸集，「\(=\)」一般不凸 （等式约束定义的是「低维曲面」，通常不凸）。

    这一条在优化中很实用：

    约束类型 可行集
    线性不等式 \(\boldsymbol{a}^\top\boldsymbol{x}\leq b\) 凸 ✓
    线性等式 \(\boldsymbol{a}^\top\boldsymbol{x}= b\) 凸 ✓（超平面是凸的）
    非线性等式 \(g(\boldsymbol{x})=0\) 一般非凸 ✗

    所以 一般只把等式约束限制在线性形式 —— 这是「凸优化标准形式」的由来。

    © \(C_3 = \{x_1x_2\geq1,\ x_1>0\}\)

    等价改写：\(x_1>0\) 时 \(x_1x_2\geq1 \iff x_2\geq\frac{1}{x_1}\)。

    关键观察：\(\frac1{x_1}\) 在 \(x_1>0\) 上是凸函数 （因为 \(\frac{1}{x}\) 的二阶导 \(\frac{2}{x^3}>0\)）。

    所以 \(C_3\) 是凸函数的上镜图（epigraph）：

    \[ C_3 = \{(x_1,x_2): x_2 \geq g(x_1)\}, \quad g = \frac{1}{x_1} \]

    凸函数的上镜图一定是凸集 ✓

    结论：凸集 ✓

    几何直观：画 \(x_2 = 1/x_1\) 的图像，集合是它上方的区域 ——这个区域没有「凹陷」，确实是凸的。

    三类「凸性保证」的集合（记住这三个）

    形式 是否凸 原因
    子水平集 \(\{f\leq c\}\)（\(f\) 凸） ✓ 凸函数性质
    上镜图 \(\{(x,t): t\geq f(x)\}\)（\(f\) 凸） ✓ 凸函数定义
    等式 \(\{f = c\}\)（非线性） 一般 ✗ 只是边界

    实用口诀：

    \[ \text{凸函数} + \text{「}\leq\text{」} \Rightarrow \text{凸集} \]
    \[ \text{凸函数} + \text{「}= \text{」} \Rightarrow \text{一般非凸（除非是线性）} \]

    例题 3：验证凸性的一阶条件¶

    用一阶条件验证 \(f(x) = e^x\) 是凸函数。

    思路

    一阶条件：\(f(y)\geq f(x)+f'(x)(y-x)\)。

    解答

    写出不等式的两边：

    \[ e^y \geq e^x + e^x(y-x) \]

    两边除以 \(e^x\)（正数，不变号）：

    \[ e^{y-x} \geq 1 + (y-x) \]

    令 \(t = y-x\)，需证明：

    \[ e^{t} \geq 1+t \quad \forall t\in\mathbb{R} \]

    这就是 \(e^t\) 在 \(t=0\) 处的切线是它的下界 ✓

    证明：定义

    \[ g(t) = e^t - 1 - t \]

    求导找最小值：

    \[ g'(t) = e^t - 1 \]

    \(g'(t) = 0\) 当 \(t = 0\)。且

    区间 \(g'\) \(g\)
    \(t<0\) \(<0\) 递减
    \(t>0\) \(>0\) 递增

    所以 \(t=0\) 是全局最小点：

    \[ g(0) = e^0-1-0 = 0 \]

    因此 \(g(t)\geq0\)，即 \(e^t\geq1+t\) ✓

    结论：\(f(x)=e^x\) 满足一阶条件 → 凸函数 ✓

    这个不等式值得记住（工程中反复出现）

    \[ \boxed{\ e^t \geq 1+t\ } \]

    等号仅在 \(t=0\) 成立。

    工程用途：

    场景 用法
    证明不等式 把 \(e^t\) 换成 \(1+t\) 做下界估计
    指数增长的保守估计 增长率至少是线性的
    信息论 用于证明 KL 散度非负
    数值分析 相对误差界

    推广形式（对凸函数的一般性质）：

    \[ e^t \geq 1+t \quad\text{（这是 }e^t\text{ 在 0 处一阶泰勒的下界）} \]

    对比其它函数的线性下界：

    函数 切线不等式
    \(e^t\) \(e^t\geq1+t\)
    \(-\ln t\) \(-\ln t \geq 1-t\)（即 \(\ln t\leq t-1\)）
    \(t\ln t\) \(t\ln t\geq t-1\)

    这些都可以由「凸函数的切线在下方」统一解释。

    例题 4：判断问题是否为凸优化¶

    判断下列问题是否凸：

    (a) \(\min\ \lVert A\boldsymbol{x}-\boldsymbol{b}\rVert^2 + \lambda\lVert\boldsymbol{x}\rVert_2^2\)

    (b) \(\min\ \lVert A\boldsymbol{x}-\boldsymbol{b}\rVert^2\)，s.t. \(\lVert\boldsymbol{x}\rVert_2\leq1\)

    © \(\min\ \lVert A\boldsymbol{x}-\boldsymbol{b}\rVert^2\)，s.t. \(\lVert\boldsymbol{x}\rVert_0\leq k\)

    思路

    检查目标函数与可行集各自的凸性。

    解答

    (a) 岭回归（Ridge）

    目标函数是两项之和：

    项 凸性
    \(\lVert A\boldsymbol{x}-\boldsymbol{b}\rVert^2\) 凸（例题 1c）
    \(\lambda\lVert\boldsymbol{x}\rVert_2^2\) 凸（\(\lambda>0\)，二次型）

    凸 + 凸 = 凸 ✓

    结论：凸优化问题 ✓（无约束）

    进一步：Hessian 是

    \[ 2A^\top A + 2\lambda I \]

    因为 \(2\lambda I\) 正定，所以 Hessian 恒正定 → 严格凸 → 唯一最优解 ✓

    这就是岭回归比普通最小二乘更「稳」的原因： 加正则项后 Hessian 一定可逆，最优解唯一。

    (b) 带球约束的最小二乘

    目标：凸 ✓

    约束 \(\lVert\boldsymbol{x}\rVert_2\leq1\)： 这是凸函数（范数）的子水平集 → 凸集 ✓

    结论：凸优化问题 ✓

    求解：可用投影梯度法（每步把点投影回球内）。

    © 带基数约束的最小二乘

    目标：凸 ✓

    约束 \(\lVert\boldsymbol{x}\rVert_0\leq k\)： 基数约束要求「非零元素的个数 ≤ k」。

    \(\lVert\cdot\rVert_0\) 不是范数，且非凸 ✗

    为什么非凸：考虑 \(\boldsymbol{x} = (1,0)\)、\(\boldsymbol{y} = (0,1)\)， 两者基数都是 1（满足 \(\leq k\)）。但中点

    \[ \frac{\boldsymbol{x}+\boldsymbol{y}}{2} = (0.5,\ 0.5) \]

    基数仍为 2？不，这里两个分量都非零 → 基数为 2。

    当 \(k=1\) 时，中点基数 \(= 2 > 1\) → 不在可行集内 ✗ 违反凸集定义。

    结论：非凸优化问题 ✗（实际上是 NP 难的）

    工程上的处理（这是重点）：

    方法 说明
    L1 松弛 用 \(\lVert\boldsymbol{x}\rVert_1\leq c\) 替代（凸！）
    贪心算法 逐步选择（如 OMP）
    启发式搜索 模拟退火、遗传算法

    为什么 L1 是好替代：

    范数 形状 效果
    \(\lVert\cdot\rVert_0\) 非凸（计数） 精确稀疏
    \(\lVert\cdot\rVert_1\) 凸（菱形） 诱导稀疏 ✓
    \(\lVert\cdot\rVert_2\) 凸（圆形） 不稀疏

    几何直观：L1 球的「尖角」正好在坐标轴上， 所以最优解容易恰好落在坐标轴上 → 该分量为零 → 稀疏 ✓

    这就是 Lasso 的原理，也是压缩感知的核心思想。

    「L0 难、L1 松」是稀疏优化的基本套路

    层级 问题 可解性
    原始 \(\lVert\boldsymbol{x}\rVert_0\leq k\) NP 难
    松弛 \(\lVert\boldsymbol{x}\rVert_1\leq c\) 凸，多项式可解 ✓
    理论保证 满足条件时两者解相同 压缩感知的核心定理

    工程含义：遇到非凸的「计数」约束，先想 L1 松弛。

    这与「正则化的概率解释」一页的结论呼应： L1 正则等价于拉普拉斯先验，天然倾向于产生稀疏解。

    七、自测¶

    Q1 判断 \(f(x) = \lvert x\rvert\) 是否凸函数。

    提示

    可以直接用定义，或注意它可写成两个仿射函数的最大值。

    解答

    方法一：用定义

    对任意 \(x,y\) 与 \(\theta\in[0,1]\)，需验证

    \[ \lvert\theta x+(1-\theta)y\rvert \leq \theta\lvert x\rvert+(1-\theta)\lvert y\rvert \]

    由三角不等式（注意 \(\theta\geq0\)、\(1-\theta\geq0\)）：

    \[ \lvert\theta x+(1-\theta)y\rvert \leq \lvert\theta x\rvert+\lvert(1-\theta)y\rvert = \theta\lvert x\rvert+(1-\theta)\lvert y\rvert \;\checkmark \]

    方法二：写成 max 形式

    \[ \lvert x\rvert = \max\{x,\ -x\} \]

    而 \(x\) 与 \(-x\) 都是仿射函数（既凸又凹），

    max 保持凸性（前面「保持凸性的运算」表） → 凸 ✓

    结论：\(\lvert x\rvert\) 是凸函数。

    工程意义：这解释了为什么 L1 正则（\(\sum\lvert w_j\rvert\)） 是凸的 → Lasso 问题可可靠求解 ✓

    Q2 判断集合 \(\{(x_1,x_2): x_1^2+x_2^2\geq1\}\)（单位圆盘外部）是否凸。

    提示

    取两个离得很远的点看中点。

    解答

    不是凸集。

    反例：取 \(\boldsymbol{x} = (1,0)\) 与 \(\boldsymbol{y} = (-1,0)\)。

    两者都满足 \(x_1^2+x_2^2 = 1\geq1\) ✓ 都在集合内。

    中点：

    \[ \frac{\boldsymbol{x}+\boldsymbol{y}}{2} = (0,0) \]

    检查：\(0^2+0^2 = 0 < 1\) → 中点不在集合内 ✗

    违反凸集定义 → 非凸 ✗

    关键对比：

    集合 形式 是否凸
    圆盘内部 \(x_1^2+x_2^2\leq1\) ✓ 凸（子水平集）
    圆盘外部 \(x_1^2+x_2^2\geq1\) ✗ 非凸

    规律：「\(\leq\)」（凸函数的子水平集）给出凸集， 「\(\geq\)」一般不给 —— 因为 \(\geq\) 对应「凸函数的上水平集」， 而凸函数的上水平集不保证凸。

    对应到滤波设计：若要求「某些频率的增益 \(\geq\) 某值」（带通要求）， 可行集可能是非凸的 → 需要专门处理（如凸松弛）。

    Q3 设 \(f(\boldsymbol{x}) = \max\{2x_1+x_2,\ x_1-x_2+3,\ -x_1+1\}\)。 说明 \(f\) 是凸函数，并求 \(f\) 在 \(\boldsymbol{x} = (1,1)\) 处的值。

    提示

    max 保持凸性；直接代入三个仿射函数取最大。

    解答

    凸性：三项都是仿射函数

    \[ g_1 = 2x_1+x_2,\qquad g_2 = x_1-x_2+3,\qquad g_3 = -x_1+1 \]

    仿射函数既凸又凹 → max 保持凸性 → \(f\) 凸 ✓

    求值（\(\boldsymbol{x} = (1,1)\)）：

    项 计算 值
    \(g_1\) \(2(1)+1\) \(3\)
    \(g_2\) \(1-1+3\) \(3\)
    \(g_3\) \(-1+1\) \(0\)
    \[ f(1,1) = \max\{3,\ 3,\ 0\} = 3 \]

    结果：\(f(1,1) = 3\)

    注意：两项同时取到最大值（\(g_1 = g_2 = 3\)）—— 这对应「活跃约束不止一个」的情形 （与 KKT 那一页的「角点」情形同源）。

    工程含义：max 形式在鲁棒优化中很常见 —— 「在所有可能情形下满足要求」就是让每个情形的约束都成立， 即取最大值 ≤ 0。而 max 保持凸性，所以鲁棒优化常常仍是凸问题 ✓

    Q4 为什么 \(\min\) 不一定保持凸性？举反例。

    提示

    考虑两个凸函数的逐点最小值。

    解答

    因为「取最小值」是「取上确界」的对偶操作，方向相反。

    运算 是否保持
    \(\max\)（或 \(\sup\)） 保持凸性 ✓
    \(\min\)（或 \(\inf\)） 不保持 ✗

    反例：取两个凸函数

    \[ f_1(x) = x^2, \qquad f_2(x) = (x-2)^2 \]

    逐点最小值：

    \[ g(x) = \min\{f_1(x),\ f_2(x)\} \]

    这个 \(g\) 的形状是「两个抛物线各自的下半部分」—— 在 \(x = 1\) 附近（两抛物线交点，\(f_1 = f_2 = 1\)） 出现一个「向上凸的尖峰」（严格说是非凸的转折）。

    验证非凸性：取 \(x_1 = 0\)、\(x_2 = 2\)：

    \[ g(0) = \min\{0,\ 4\} = 0,\qquad g(2) = \min\{4,\ 0\} = 0 \]

    中点：

    \[ g(1) = \min\{1,\ 1\} = 1 \]

    凸性要求 \(g(1)\leq\frac{g(0)+g(2)}{2} = 0\)，但实际 \(g(1) = 1 > 0\) ✗

    违反凸性 ✗

    工程含义：

    操作 后果
    引入 max（最坏情况） 通常仍凸 ✓
    引入 min（选择最好的） 可能破坏凸性 ✗

    这解释了一件重要的事：「混合模型」常是非凸的。

    例如高斯混合模型（GMM）的似然：

    \[ p(x) = \sum_k\pi_k\mathcal{N}(x;\mu_k,\sigma_k) \]

    涉及「哪个分量更好」的选择，导致非凸 → 所以 GMM 用 EM 算法（只能到局部最优）。
