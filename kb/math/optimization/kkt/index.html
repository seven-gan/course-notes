    KKT 条件¶

    前面三页分别讲了等式约束（拉格朗日）、不等式约束的思路、以及对偶。 这一页把它们合成约束优化最优性的统一判据。

    KKT 条件：约束优化「最优」的完整刻画。

    对凸问题，KKT 是充要条件；对一般问题，它是必要条件。 这是整个约束优化理论的核心。

    KKT 四个条件的记忆框架

    条件 名称 内容
    ① 平稳性 \(\nabla f + \sum\mu_i\nabla g_i + \sum\lambda_j\nabla h_j = \boldsymbol{0}\)
    ② 原始可行 \(g_i\leq0\)，\(h_j = 0\)
    ③ 对偶可行 \(\mu_i\geq0\)
    ④ 互补松弛 \(\mu_ig_i = 0\)

    记忆口诀：「梯度为零、约束满足、乘数非负、松紧互补」

    每一条的必要性都很直观：

    条件 为什么必要
    ① 否则还能沿某方向下降
    ② 解必须可行
    ③ 否则拉格朗日函数无下界（回到对偶那一页）
    ④ 约束要么起作用要么不起作用，不能「半起作用」

    一、KKT 条件与三个已有结论的关系¶

    KKT 不是新东西，而是前面三页的统一：

    前面讲的 KKT 中的对应
    拉格朗日法（等式约束） 条件 ①（含 \(\lambda_j\) 项）
    不等式乘数非负 条件 ③
    互补松弛 条件 ④
    对偶的「约束自动满足」 条件 ②

    所以 KKT 可以理解为：

    「拉格朗日平稳性 + 可行性 + 符号条件 + 互补松弛」的合集。

    KKT 的严格陈述（含约束品性）

    考虑问题：

    \[ \min f(\boldsymbol{x})\quad\text{s.t.}\quad g_i(\boldsymbol{x})\leq0,\ h_j(\boldsymbol{x})=0 \]

    若 \(\boldsymbol{x}^*\) 是局部最优解，且满足某个「约束品性」 （constraint qualification），则存在乘数 \(\boldsymbol{\mu}^*,\boldsymbol{\lambda}^*\) 使以下条件成立：

    \[ \nabla f(\boldsymbol{x}^*) + \sum_i\mu_i^*\nabla g_i(\boldsymbol{x}^*) + \sum_j\lambda_j^*\nabla h_j(\boldsymbol{x}^*) = \boldsymbol{0} \]
    \[ g_i(\boldsymbol{x}^*)\leq0,\qquad h_j(\boldsymbol{x}^*) = 0 \]
    \[ \mu_i^*\geq0 \]
    \[ \mu_i^*g_i(\boldsymbol{x}^*) = 0 \]

    「约束品性」是什么：保证约束的梯度「不退化」的条件。

    常见约束品性 内容 说明
    LICQ 活跃约束的梯度线性无关 最常用、最直观
    Slater 存在严格可行点 凸问题专用
    MFCQ 更弱的版本 允许多个活跃约束

    为什么需要它（一个经典反例）：

    \[ \min x\quad\text{s.t.}\quad -x^3\leq0 \]

    （约束即 \(x^3\geq0\)，等价于 \(x\geq0\)。）

    分析：

    项 内容
    可行域 \(x\geq0\)
    最优解 \(x^* = 0\)（\(x\) 越小越好，但必须 \(\geq0\)）
    目标梯度 \(f'(x) = 1\)，在 \(x=0\) 处为 \(1\)
    约束梯度 \(g(x) = -x^3\)，\(g'(x) = -3x^2\)，在 \(x=0\) 处 \(g'(0) = 0\)

    KKT 条件 ①要求：

    \[ 1 + \mu\cdot0 = 0 \implies 1 = 0 \;\text{矛盾} ✗ \]

    找不到 \(\mu\) → KKT 在 \(x^*=0\) 处不成立！

    原因：约束 \(-x^3\leq0\) 在 \(x=0\) 处梯度为零 → 约束「退化」→ 违反 LICQ ✗

    注意反例的选择要点：

    要求 说明
    最优解存在 否则谈不上「必要条件」
    活跃约束的梯度为零 违反 LICQ
    目标梯度不为零 否则 \(\mu\) 可以是任意值，不会矛盾

    我最初写的 \(\min x\) s.t. \(x^3\leq0\) 是错的—— 那个问题的可行域是 \(x\leq0\)，而 \(x\) 可以无限减小 → 无下界，最优解不存在，不能作为反例。 正确写法应让可行域是 \(x\geq0\)（如上）。

    教训：KKT 不是「无条件」的必要条件。 但工程中的约束通常不会这么退化， 所以实践中一般直接用 KKT（若发现问题再检查约束品性）。

    二、凸问题：KKT 是充分必要的¶

    这是 KKT 最有用的部分。

    定理：若问题是凸的（\(f\) 与所有 \(g_i\) 凸，\(h_j\) 仿射）， 且 \(\boldsymbol{x}^*\) 满足 KKT 条件，则 \(\boldsymbol{x}^*\) 是全局最优解。

    凸情形下的「充要」意味着什么（实用价值极高）

    情形 KKT 的地位
    凸问题 充要条件：满足 KKT ⟺ 全局最优 ✓
    非凸问题 只是必要条件：全局最优 ⟹ 满足 KKT（但不保证反向）

    实际意义：

    \[ \text{验证一个解是否最优} \rightarrow \text{只需检查 KKT（无需遍历所有点）} \]

    这就是为什么凸优化「可靠」：

    步骤 说明
    1 求解（任何达到 KKT 点的算法）
    2 检查 KKT 是否满足
    3 若满足 → 保证是全局最优，可以停止

    对比非凸问题：满足 KKT 的可能只是局部最优或鞍点。

    工程上的「停止准则」：

    残差 含义
    \(\lVert\nabla\mathcal{L}\rVert\) 平稳性违反程度
    \(\max_i(g_i)^+\) 可行性违反程度
    \(\lvert\mu_ig_i\rvert\) 互补松弛违反程度

    三者都小于容差 → 认为已收敛 ✓ （所有实用求解器都这么做。）

    三、用 KKT 解问题的完整流程¶

    这是本页最实用的部分 —— 一套可照做的流程。

    流程¶

    步骤 操作
    1 写出目标与约束（统一成 \(g_i\leq0\)、\(h_j=0\)）
    2 判断问题是否凸（是则 KKT 充要）
    3 写拉格朗日函数
    4 列出 KKT 的四个条件
    5 枚举「活跃集」（哪些 \(g_i = 0\)），逐个求解
    6 检验每个解：可行性、\(\mu\geq0\)、互补松弛
    7 比较所有可行解的目标值，取最优

    第 5、6 步是「猜活跃集」——这很容易出错

    为什么需要枚举：\(\mu_ig_i = 0\) 意味着 「\(g_i = 0\) 或 \(\mu_i = 0\)」——两者之一成立。

    \(m\) 个不等式约束就有 \(2^m\) 种组合，所以要逐个试。

    实用简化（不必真的枚举 \(2^m\)）：

    技巧 说明
    先求无约束最优 若满足所有约束 → 全部不活跃，完成 ✓
    物理判断 根据问题含义猜哪些约束「应该是紧的」
    逐步加约束 先处理最可能活跃的，求解后检查
    用求解器 现代求解器会自动找活跃集

    检验时最容易犯的两个错：

    错误 后果
    忘了检查 \(\mu\geq0\) 得到「假最优」（实际不是最优）
    忘了验证可行性 解可能违反某些约束

    必须两样都查，否则结果不可信。

    四、典型例题¶

    例题 1：完整 KKT 流程¶

    求解

    \[ \min f(x,y) = x^2+y^2 \quad\text{s.t.}\quad x+y\geq2 \]
    思路

    先看无约束最优是否可行，再按活跃集方式处理。

    解答

    第一步：统一约束形式

    \(x+y\geq2 \Rightarrow g(x,y) = 2-x-y\leq0\)

    第二步：检查凸性

    项 凸性
    \(f = x^2+y^2\) 凸 ✓
    \(g = 2-x-y\) 仿射（既凸又凹） ✓

    是凸问题 → KKT 是充要条件 ✓

    第三步：先试无约束最优

    \[ \nabla f = (2x,2y) = \boldsymbol{0} \implies (x,y) = (0,0) \]

    检查约束：

    \[ g(0,0) = 2-0-0 = 2 > 0 \quad\text{违反 ✗} \]

    → 无约束最优不可行 → 约束必须活跃。

    第四步：设约束活跃（\(g = 0\)），列 KKT

    \[ \mathcal{L} = x^2+y^2+\mu(2-x-y) \]

    条件 ①（平稳性）：

    \[ \frac{\partial\mathcal{L}}{\partial x} = 2x-\mu = 0 \implies x = \frac{\mu}{2} \]
    \[ \frac{\partial\mathcal{L}}{\partial y} = 2y-\mu = 0 \implies y = \frac{\mu}{2} \]

    条件 ②（原始可行，且约束活跃）：

    \[ 2-x-y = 0 \implies x+y = 2 \]

    第五步：求解

    由 \(x = y\) 与 \(x+y = 2\)：

    \[ x = y = 1 \]

    求 \(\mu\)：

    \[ 2(1)-\mu = 0 \implies \mu = 2 \]

    第六步：检验

    检查 结果
    平稳性 ✓ \(2(1)-2 = 0\) ✓
    原始可行 ✓ \(g = 2-1-1 = 0\leq0\) ✓
    对偶可行 ✓ \(\mu = 2\geq0\) ✓
    互补松弛 ✓ \(2\times0 = 0\) ✓

    四项全部满足 ✓

    第七步：结论

    由于是凸问题且满足 KKT：

    \[ (x^*,y^*) = (1,1),\qquad f_{\min} = 2 \]

    是全局最优解 ✓

    几何验证：原点到直线 \(x+y=2\) 的距离平方：

    \[ d^2 = \frac{\lvert0+0-2\rvert^2}{1^2+1^2} = \frac42 = 2 \;\checkmark \]

    KKT 组合使用的两个「刹车点」

    刹车点 1：先试无约束最优（省大量工作）

    结果 后续
    可行 直接完成，\(\mu=0\)，无需解 KKT 方程组 ✓
    不可行 才需要处理约束

    这在多约束问题中尤其重要——能省掉大量枚举。

    刹车点 2：必须查 \(\mu\geq0\)

    若算出 \(\mu<0\) 说明什么：

    \[ \mu<0 \implies \text{猜测的活跃集错了} ✗ \]

    为什么：\(\mu<0\) 违反对偶可行（条件 ③）。 物理上意味着「约束方向与目标下降方向一致」—— 即约束本该阻止下降，却实际上帮助了下降 → 说明该约束不应该是活跃的。

    正确做法：去掉这个约束（设为不活跃，\(\mu=0\)）重新求解。

    例题 2：两个不等式约束¶

    求解

    \[ \min f(x,y) = x^2+y^2 \quad\text{s.t.}\quad x\geq1,\ y\geq1 \]
    思路

    两个约束可能都活跃，或只有一个活跃。

    解答

    第一步：统一形式

    \[ g_1 = 1-x\leq0,\qquad g_2 = 1-y\leq0 \]

    是凸问题 ✓（目标凸、约束仿射）

    第二步：无约束最优 \((0,0)\)——违反两个约束 ✗

    第三步：枚举活跃集（三种可能）

    情形 活跃约束 说明
    A 只有 \(g_1\) \(x=1\)，\(y\) 自由
    B 只有 \(g_2\) \(y=1\)，\(x\) 自由
    C 两个都活跃 \(x=1\) 且 \(y=1\)

    情形 A（只 \(g_1\) 活跃）

    \[ \mathcal{L} = x^2+y^2+\mu_1(1-x) \]

    条件：

    \[ 2x-\mu_1 = 0,\qquad 2y = 0 \]

    得 \(y = 0\)。但违反 \(y\geq1\) ✗

    该情形不可行 ✗

    情形 B（只 \(g_2\) 活跃）

    对称地得 \(x = 0\)，违反 \(x\geq1\) ✗

    情形 C（两个都活跃）

    \[ \mathcal{L} = x^2+y^2+\mu_1(1-x)+\mu_2(1-y) \]

    条件 ①：

    \[ 2x-\mu_1 = 0 \implies \mu_1 = 2x \]
    \[ 2y-\mu_2 = 0 \implies \mu_2 = 2y \]

    约束活跃：\(x = 1\)、\(y = 1\)。

    所以

    \[ \mu_1 = 2,\qquad \mu_2 = 2 \]

    第四步：检验情形 C

    检查 结果
    平稳性 ✓
    原始可行 \(x=1\geq1\) ✓，\(y=1\geq1\) ✓
    对偶可行 \(\mu_1 = 2\geq0\) ✓，\(\mu_2 = 2\geq0\) ✓
    互补松弛 \(\mu_1g_1 = 2\times0 = 0\) ✓，\(\mu_2g_2 = 0\) ✓

    全部满足 ✓

    第五步：结论

    \[ (x^*,y^*) = (1,1),\qquad f_{\min} = 1+1 = 2 \]

    注意：此处的答案是可行域的「角点」（两个约束的交点）—— 这是两个约束同时活跃的典型情形。

    这个例子揭示的几何规律（值得记住）

    最优解出现在哪里：

    情形 最优解位置
    无约束最优在可行域内部 内部点（\(\nabla f = 0\)）
    无约束最优在边界外 边界上（1 个约束活跃）
    无约束最优在角点外 角点（多个约束活跃）

    这与「线性规划的顶点最优性」同源：

    问题类型 最优解所在
    线性规划 可行域的顶点
    凸二次（本例） 边界或角点
    一般凸问题 边界（KKT 点）

    实用含义：

    方法 适用
    枚举顶点（单纯形法） 线性规划，顶点有限
    KKT + 活跃集 一般凸问题
    内点法 大规模问题（不显式枚举顶点）

    为什么内点法更适合大规模：

    顶点数随约束数指数增长（\(2^m\)）， 而内点法每步只需解一个线性方程组，复杂度多项式 ✓

    例题 3：非凸情形 KKT 只是必要条件¶

    考察 \(f(x) = x^3 - 3x\)，约束 \(-2\leq x\leq2\)。 用 KKT 找出所有 KKT 点，并识别哪些是局部最优、哪些不是。

    思路

    KKT 会给出多个候选点；需要逐个判断（因为非凸，KKT 不充分）。

    解答

    第一步：统一约束

    \[ g_1 = -2-x\leq0, \qquad g_2 = x-2\leq0 \]

    注意：这个问题非凸（\(f\) 的三阶导为 6，\(f'' = 6x\) 变号）。

    所以 KKT 只是必要条件 —— KKT 点可能不是最优。

    第二步：分情形

    情形 条件 求解
    内部 \(\mu_1 = \mu_2 = 0\) \(f'(x) = 0\)
    左边界 \(g_1\) 活跃 \(x = -2\)
    右边界 \(g_2\) 活跃 \(x = 2\)

    情形 1：内部（无约束驻点）

    \[ f'(x) = 3x^2-3 = 0 \implies x = \pm1 \]

    两个驻点都在 \([-2,2]\) 内 ✓ → 都是 KKT 点。

    情形 2：左边界 \(x = -2\)

    检验 \(\mu_1\geq0\)。\(f'(-2) = 3\times4-3 = 9\)。

    对 \(g_1 = -2-x\)：\(\nabla g_1 = -1\)。

    平稳性：\(f'(x)+\mu_1(-1) = 0 \Rightarrow \mu_1 = f'(-2) = 9\geq0\) ✓

    可行 KKT 点 ✓

    情形 3：右边界 \(x = 2\)

    \(f'(2) = 3\times4-3 = 9\)。

    对 \(g_2 = x-2\)：\(\nabla g_2 = +1\)。

    平稳性：\(f'(2)+\mu_2(1) = 0 \Rightarrow \mu_2 = -9 < 0\) ✗

    不可行 → \(x=2\) 不是 KKT 点 ✗

    第三步：汇总 KKT 点

    点 类型 \(f\) 值
    \(x = -2\) 边界 \(-8+6 = -2\)
    \(x = -1\) 内部驻点 \(-1+3 = 2\)
    \(x = 1\) 内部驻点 \(1-3 = -2\)
    \(x = 2\) 非 KKT 点 \(8-6 = 2\)

    第四步：判断各点的性质

    \(f''(x) = 6x\)：

    点 \(f''\) 性质
    \(x = -2\) \(-12 < 0\) 边界点（左端点）
    \(x = -1\) \(-6 < 0\) 局部极大
    \(x = 1\) \(6 > 0\) 局部极小
    \(x = 2\) \(12 > 0\) 非 KKT（但仍是端点可行点）

    第五步：确定全局最优

    比较所有候选点的函数值：

    \(x\) \(f(x)\)
    \(-2\) \(-2\)
    \(1\) \(-2\)
    \(2\) \(2\)
    \(-1\) \(2\)

    存在两个全局最小点：\(x = -2\) 与 \(x = 1\)，都有 \(f = -2\) ✓

    这个例子的三个关键教训

    教训 1：KKT 点是「候选」，不都是最优

    \(x = -1\) 满足 KKT，但它是局部极大（不是极小）✗

    原因：\(\mu_1g_1 = 0\) 只排除了「约束违反」， 不保证「二阶条件」（曲率方向）满足。

    完整判据还需要二阶条件：

    条件 内容
    KKT（一阶） 必要条件
    二阶充分条件 在「临界锥」上，Hessian 正定 → 严格局部最小

    对非凸问题：

    \[ \text{满足 KKT} \xrightarrow{\text{不保证}} \text{局部最小} \]

    所以必须额外检查（二阶条件或直接比较邻域值）。

    教训 2：\(x=2\) 不是 KKT 点，但仍是端点

    它不满足 \(\mu_2\geq0\)。物理上： 在 \(x=2\) 处 \(f' = 9>0\)，说明减小 \(x\) 能降低 \(f\) → 右边界不是阻挡下降的约束 → 所以它不该活跃 ✓

    这印证了「\(\mu<0\) 说明约束猜错了」。

    教训 3：全局最优可能有两个（甚至更多）

    \(x=-2\) 与 \(x=1\) 都有 \(f=-2\)。

    工程含义：

    情形 处理
    多个全局最优 按次要准则选择（能耗、鲁棒性…）
    需要唯一解 加正则项（如 \(\varepsilon x^2\)）打破对称

    注意：非凸问题没有「找全局最优」的多项式算法（NP 难）， 所以实践中的策略是：

    策略 说明
    多起点 从多个初值分别优化，取最好
    凸松弛 转化为凸问题求近似（如 L1 松弛）
    局部搜索 + 启发式 模拟退火、遗传算法
    实际接受局部最优 深度学习中常见的做法

    例题 4：KKT 在机器学习中的应用（正则化）¶

    从 KKT 的角度解释 Lasso（L1 正则）为什么产生稀疏解。

    思路

    写出 Lasso 的 KKT 条件，看 \(\mu\)（或次梯度）为零的条件。

    解答

    第一步：问题形式

    \[ \min_{\boldsymbol{w}}\ \frac12\lVert X\boldsymbol{w}-\boldsymbol{y}\rVert^2+\lambda\lVert\boldsymbol{w}\rVert_1 \]

    注意：\(\lVert\boldsymbol{w}\rVert_1 = \sum_j\lvert w_j\rvert\) 在 \(w_j = 0\) 处不可微，所以用次梯度（subgradient）。

    \(\lvert w\rvert\) 的次梯度：

    \[ \partial\lvert w\rvert = \begin{cases}\{+1\}, & w>0\\ \{-1\}, & w<0\\ [-1,1], & w=0\end{cases} \]

    第二步：写 KKT（用次梯度替代梯度）

    记残差 \(\boldsymbol{r} = X\boldsymbol{w}-\boldsymbol{y}\)，则

    \[ \boldsymbol{0}\in -X^\top\boldsymbol{r} + \lambda\,\partial\lVert\boldsymbol{w}\rVert_1 \]

    逐分量：

    \[ X_j^\top\boldsymbol{r} \in \lambda\,\partial\lvert w_j\rvert \]

    第三步：分三种情形

    情形 KKT 条件 结论
    \(w_j > 0\) \(X_j^\top\boldsymbol{r} = \lambda\) 相关性与阈值恰好相等
    \(w_j < 0\) \(X_j^\top\boldsymbol{r} = -\lambda\) 同理（取负）
    \(w_j = 0\) \(\lvert X_j^\top\boldsymbol{r}\rvert\leq\lambda\) 相关性不足阈值 → 该特征被「忽略」

    第四步：稀疏性的来源（关键洞察）

    只要某个特征与残差的相关性「不够大」（\(<\lambda\)）， 它的权重就恰好为零** ✓

    这就是稀疏性：

    \[ w_j = 0 \iff \lvert X_j^\top\boldsymbol{r}\rvert \leq \lambda \]

    对比 L2 正则（Ridge）：

    方法 正则 次梯度/梯度 \(w_j=0\) 的条件
    Lasso \(\lVert\boldsymbol{w}\rVert_1\) 在 0 处是一个区间 \([-1,1]\) 容易满足 → 稀疏 ✓
    Ridge \(\lVert\boldsymbol{w}\rVert_2^2\) 处处可微，梯度 \(2\lambda w_j\) \(X_j^\top\boldsymbol{r} = -2\lambda w_j\) → 只有 \(w_j\) 恰为 0 才行（几乎不可能）

    核心机制：

    范数 在 \(w_j=0\) 处的性质 稀疏
    L1 不可微（次梯度是区间） ✓
    L2 可微（梯度是单点） ✗

    「不可微」反而带来好处——这是 L1 能产生稀疏解的数学根源。

    这个 KKT 分析给出的两个实用结论

    1. \(\lambda\) 的作用是可以定量理解的

    \(\lambda\) 效果
    越大 阈值越高 → 更多 \(w_j\) 被压到 0 → 更稀疏
    \(\lambda = 0\) 无正则 → 最小二乘
    \(\lambda\) 极大 全部 \(w_j = 0\)（只有截距保留）

    这解释了两件事：

    现象 原因
    调大 \(\lambda\) 特征变少 阈值升高
    不存在「自动最优 \(\lambda\)」 需要交叉验证选择

    2. 特征标准化为什么必要

    观察条件 \(\lvert X_j^\top\boldsymbol{r}\rvert\leq\lambda\)： 比较的是「相关性」与「阈值 \(\lambda\)」。

    若某特征 \(X_j\) 的尺度很大（如未归一化）：

    后果 说明
    \(X_j^\top\boldsymbol{r}\) 天然很大 容易被选中（即使实际不重要）
    尺度小的特征 天然接近 0 → 容易被误剔除

    结论：用 L1 正则前必须标准化特征 —— 否则惩罚是「不公平的」（尺度大的特征被系统性优待）。

    这与「梯度下降与收敛」一页的结论呼应： 标准化既改善条件数，又保证正则化的公平性。

    对比 Ridge：它也有尺度问题（惩罚 \(\lambda w_j^2\)）， 同样需要标准化 —— 所以这条对两者都适用。

    五、自测¶

    Q1 写出问题 \(\min x^2+y^2\) s.t. \(x+y = 4\) 的 KKT 条件并求解。

    提示

    只有等式约束，所以是对称的 KKT（拉格朗日乘数法）。

    解答

    第一步：拉格朗日函数

    \[ \mathcal{L} = x^2+y^2+\lambda(x+y-4) \]

    第二步：KKT 条件

    条件 内容
    ① 平稳性 \(2x+\lambda = 0\)，\(2y+\lambda = 0\)
    ② 原始可行 \(x+y = 4\)
    ③ 对偶可行 \(\lambda\) 无符号限制（等式约束）
    ④ 互补松弛 不适用（没有不等式约束）

    第三步：求解

    由 ① 得 \(x = y = -\lambda/2\)，代入 ②：

    \[ 2\left(-\frac{\lambda}{2}\right) = 4 \implies \lambda = -4 \]

    回代：

    \[ x = y = 2 \]

    结果：

    \[ (x^*,y^*) = (2,2),\qquad f_{\min} = 4+4 = 8 \]

    几何验证：原点到直线 \(x+y=4\) 的距离平方：

    \[ d^2 = \frac{(0+0-4)^2}{2} = \frac{16}{2} = 8 \;\checkmark \]

    只有等式约束时 KKT 退化为拉格朗日乘数法

    约束类型 KKT 额外要求
    只有等式 只需 ①②（无符号条件、无互补松弛）
    含不等式 需要 ③④

    注意 \(\lambda\) 的符号没有限制：这是因为等式约束 「两侧都能走」，乘数可正可负。 本题得 \(\lambda = -4\)，这是合法的 ✓

    对比：若把约束改成 \(x+y\geq4\)（不等式），则要求 \(\mu\geq0\)：

    \[ \mathcal{L} = x^2+y^2+\mu(4-x-y) \]

    得 \(\mu = 4\geq0\) ✓ 合法

    两次得到的 \(f_{\min}\) 相同（都是 8） —— 因为在这两道题里，约束都恰好活跃， 且「≥」与「=」在原最优点处等价。

    Q2 判断：满足 KKT 条件的点一定是全局最优解。

    提示

    考虑凸性与非凸性的区别。

    解答

    不对。取决于问题是否凸。

    正确的结论：

    问题类型 KKT 的地位
    凸问题 充要条件：满足 KKT ⟺ 全局最优 ✓
    非凸问题 只是必要条件：全局最优 ⟹ 满足 KKT（反向不成立）

    非凸情形的反例（KKT 那一页的例题 3）：

    \[ \min\ x^3-3x\quad\text{s.t.}\quad-2\leq x\leq2 \]
    点 是否 KKT 实际性质
    \(x = -2\) ✓ 全局最小（边界）
    \(x = -1\) ✓ 局部极大 ✗
    \(x = 1\) ✓ 全局最小
    \(x = 2\) ✗ （\(\mu<0\)）

    \(x=-1\) 满足 KKT 但是局部极大 ✗

    原因：KKT 是一阶条件， 只看「梯度为零 + 约束满足」， 不检查曲率方向。

    完整判据还需要二阶条件：

    条件 内容
    一阶（KKT） 必要
    二阶充分条件 在「临界锥」上 Hessian 正定 → 严格局部最小

    工程实践中的处理：

    情形 做法
    已知凸 直接用 KKT，放心 ✓
    非凸 多起点求解 + 比较目标值
    需要保证 用凸松弛，或全局优化算法（分支定界）

    关键判断：先确认问题是否凸 —— 这决定 KKT 能否作为充分条件。这是优化的第一步。

    Q3 求解 \(\min f(x) = (x-3)^2\) s.t. \(1\leq x\leq2\)。

    提示

    两个不等式约束；先看无约束最优。

    解答

    第一步：统一约束

    \[ g_1 = 1-x\leq0,\qquad g_2 = x-2\leq0 \]

    凸问题 ✓（目标凸、约束仿射）

    第二步：无约束最优

    \[ f'(x) = 2(x-3) = 0 \implies x = 3 \]

    检查约束：\(x=3\) 违反 \(x\leq2\) ✗

    第三步：枚举活跃集

    情形 活跃约束 求解
    A 只 \(g_1\)（\(x = 1\)） \(f'(1) = -4\)
    B 只 \(g_2\)（\(x = 2\)） \(f'(2) = -2\)
    C 两个都活跃 不可能（\(1\neq2\)）

    情形 A（\(x = 1\)）：

    平稳性：\(f'(1)+\mu_1(-1) = 0 \Rightarrow -4-\mu_1 = 0 \Rightarrow \mu_1 = -4 < 0\) ✗

    不可行（\(\mu_1<0\) 违反对偶可行）

    情形 B（\(x = 2\)）：

    平稳性：\(f'(2)+\mu_2(1) = 0 \Rightarrow -2+\mu_2 = 0 \Rightarrow \mu_2 = 2\geq0\) ✓

    可行 KKT 点 ✓

    第四步：检验情形 B

    检查 结果
    平稳性 \(-2+2 = 0\) ✓
    原始可行 \(1\leq2\leq2\) ✓
    对偶可行 \(\mu_2 = 2\geq0\) ✓
    互补松弛 \(\mu_2g_2 = 2\times(2-2) = 0\) ✓

    全部满足 ✓

    第五步：结论

    \[ x^* = 2,\qquad f_{\min} = (2-3)^2 = 1 \]

    直观验证：\(f\) 在 \(x=3\) 处最小， 但可行域是 \([1,2]\)，最靠近 3 的可行点是 \(x=2\) ✓ 所以最优在右端点。

    为什么情形 A 的乘数为负说明它不该活跃

    物理含义：在 \(x=1\) 处，\(f'(1) = -4 < 0\)，说明 增大 \(x\) 能降低 \(f\)（目标想往右走）。

    而约束 \(g_1: x\geq1\) 的作用是阻止 \(x\) 变得更小 —— 它没有阻挡目标想去的方向（右边）。

    所以它不该是活跃约束 → \(\mu_1\) 必须为 0 → 但平稳性又要求 \(\mu_1 = -4\) → 矛盾 ✗

    这说明：\(\mu<0\) 是「猜错活跃集」的明确信号。 遇到时应把该约束从活跃集中去掉，重新求解 ✓

    Q4 从 KKT 的角度解释：为什么 L2 正则（Ridge）不产生稀疏解， 而 L1 正则（Lasso）会？

    提示

    比较 \(\lvert w\rvert\) 与 \(w^2\) 在 \(w=0\) 附近的可微性。

    解答

    关键在于「在 \(w=0\) 处是否可微」。

    第一步：写出两种正则的 KKT

    Ridge：

    \[ \min\ \frac12\lVert X\boldsymbol{w}-\boldsymbol{y}\rVert^2+\frac\lambda2\lVert\boldsymbol{w}\rVert^2 \]

    梯度（处处可微）：

    \[ -X^\top\boldsymbol{r}+\lambda\boldsymbol{w} = \boldsymbol{0} \]

    逐分量：

    \[ X_j^\top\boldsymbol{r} = \lambda w_j \]

    要 \(w_j = 0\)，需要

    \[ X_j^\top\boldsymbol{r} = 0 \]

    即残差与该特征恰好正交 —— 这在一般情况下 几乎不可能精确成立（\(\boldsymbol{r}\) 由所有特征共同决定）✗

    Lasso：

    \[ \min\ \frac12\lVert X\boldsymbol{w}-\boldsymbol{y}\rVert^2+\lambda\lVert\boldsymbol{w}\rVert_1 \]

    用次梯度（\(\lvert w_j\rvert\) 在 0 处不可微）：

    \[ X_j^\top\boldsymbol{r}\in\lambda\,\partial\lvert w_j\rvert \]

    当 \(w_j = 0\) 时，\(\partial\lvert w_j\rvert = [-1,1]\)，所以条件为

    \[ \lvert X_j^\top\boldsymbol{r}\rvert\leq\lambda \]

    这是一个「区间」条件（而不是等式）：

    条件 类型
    Ridge 等式 \(X_j^\top\boldsymbol{r} = 0\)
    Lasso 不等式 \(\lvert X_j^\top\boldsymbol{r}\rvert\leq\lambda\)

    第二步：为什么「不等式条件」容易满足

    条件 满足的难易
    等式（Ridge） 需精确命中一个点 很难
    不等式（Lasso） 只需落在一个区间内 容易 ✓

    这解释了稀疏性：只要特征的相关性「不够大」，权重就恰好为 0。

    第三步：几何直观（「尖角」vs「圆滑」）

    范数 等高线形状 与损失等高线相切的位置
    L1 菱形（有尖角） 容易切在尖角上（坐标轴上）→ 稀疏 ✓
    L2 圆形（光滑） 切点一般不在坐标轴上 → 不稀疏 ✗

    根本原因：

    \[ \text{不可微（次梯度是区间）} \iff \text{等高线有尖角} \iff \text{稀疏} \]

    「不可微」这个「缺点」反而是稀疏性的来源 —— 这是 L1 正则最反直觉、也最重要的性质。
