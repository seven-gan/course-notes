    梯度下降与收敛¶

    上一页讲了「什么是优化问题」和「凸性的意义」。这一页讲怎么解。

    梯度下降：沿最陡下降方向，走一小步，重复。

    公式只有一行：

    \[ \boldsymbol{x}_{k+1} = \boldsymbol{x}_k - \eta\nabla f(\boldsymbol{x}_k) \]

    但步长 \(\eta\) 怎么选、「为什么能收敛」、「收敛多快」 ——这些决定了它能否真正work。

    为什么这一页比公式本身重要

    公式人人会写，但以下问题决定成败：

    问题 影响
    学习率取多大？ 太大发散，太小极慢
    为什么需要归一化？ 影响条件数 → 影响收敛
    为什么用随机梯度？ 大规模数据下唯一可行
    为什么需要动量？ 加速 + 抑制震荡
    收敛有多快？ 决定训练时间

    这一页把这些问题都量化回答。

    一、算法与几何直觉¶

    梯度下降（GD）：

    \[ \boldsymbol{x}_{k+1} = \boldsymbol{x}_k - \eta\nabla f(\boldsymbol{x}_k) \]

    为什么用负梯度方向：由泰勒一阶展开

    \[ f(\boldsymbol{x}+\Delta\boldsymbol{x}) \approx f(\boldsymbol{x}) + \nabla f(\boldsymbol{x})^\top\Delta\boldsymbol{x} \]

    要让 \(f\) 下降，需要 \(\nabla f^\top\Delta\boldsymbol{x} < 0\)。

    在所有单位方向中，\(\Delta\boldsymbol{x} = -\frac{\nabla f}{\lVert\nabla f\rVert}\) 给出最负的内积（由柯西-施瓦茨不等式，回到内积那一页）：

    \[ \nabla f^\top\left(-\frac{\nabla f}{\lVert\nabla f\rVert}\right) = -\lVert\nabla f\rVert \]

    这是最小值 ✓ 所以负梯度方向是局部最陡下降方向。

    二、学习率的影响¶

    这是实践中最关键的参数。

    \(\eta\) 取值 现象
    太小 收敛极慢（步长不够）
    合适 稳定收敛
    太大 震荡、发散
    极大 数值溢出（NaN）

    2.1 定量分析（二次函数情形）¶

    设 \(f(\boldsymbol{x}) = \frac12\boldsymbol{x}^\top A\boldsymbol{x}\)（\(A\) 正定）。 梯度下降：

    \[ \boldsymbol{x}_{k+1} = \boldsymbol{x}_k - \eta A\boldsymbol{x}_k = (I-\eta A)\boldsymbol{x}_k \]

    在 \(A\) 的特征基下解耦（回到线性代数「矩阵分解」一页）：

    \[ x_{k+1}^{(i)} = (1-\eta\lambda_i)x_k^{(i)} \]

    收敛条件：所有 \(|1-\eta\lambda_i| < 1\)，即

    \[ 0 < \eta < \frac{2}{\lambda_{\max}} \]

    这条公式解释了学习率的一切

    \[ 0 < \eta < \frac{2}{\lambda_{\max}} \]

    关键含义：

    观察 解释
    上界由最大特征值决定 大曲率方向先「爆」
    与最小特征值无关 小曲率方向决定收敛速度
    特征值差异大 → 难选 \(\eta\) 病态问题

    收敛速率由最慢的分量决定：

    \[ \text{误差衰减因子} = \max_i\lvert1-\eta\lambda_i\rvert \]

    最优学习率（使最大衰减因子最小）：

    \[ \eta^* = \frac{2}{\lambda_{\max}+\lambda_{\min}} \]

    此时收敛速率：

    \[ \rho = \frac{\lambda_{\max}-\lambda_{\min}}{\lambda_{\max}+\lambda_{\min}} = \frac{\kappa-1}{\kappa+1} \]

    其中 \(\kappa = \lambda_{\max}/\lambda_{\min}\) 是条件数。

    条件数如何拖慢收敛（这是核心结论）

    \[ \rho = \frac{\kappa-1}{\kappa+1} \]
    条件数 \(\kappa\) 收敛速率 \(\rho\) 达到 \(10^{-3}\) 所需迭代（约）
    \(1\) \(0\) 1 步（一步到位）
    \(10\) \(0.82\) \(\approx 35\)
    \(100\) \(0.98\) \(\approx 340\)
    \(1000\) \(0.998\) \(\approx 3450\)
    \(10^4\) \(0.9998\) \(\approx 34500\)

    规律：迭代次数大致正比于条件数 \(\kappa\)。

    工程含义（这直接指导实践）：

    问题 对策
    条件数大 归一化/标准化输入（把各维缩放到相近尺度）
    特征尺度差异大 用 Adam/RMSprop（自适应学习率）
    需要精确解 牛顿法（收敛速率与 \(\kappa\) 无关）

    这就是「为什么深度学习必须做数据标准化」的定量理由—— 不是「习惯」，而是它能直接减少条件数、加速收敛。

    2.2 学习率调度¶

    实践中常用「先大后小」的策略：

    策略 形式 特点
    步进衰减 每 \(k\) 轮减半 简单
    指数衰减 \(\eta_k = \eta_0\gamma^k\) 平滑
    余弦退火 \(\eta_k = \frac{\eta_0}{2}(1+\cos\frac{k\pi}{K})\) 现代常用
    预热+衰减 先线性升后降 Transformer 常用
    ReduceLROnPlateau 损失不降就减半 自适应

    为什么先大后小：

    阶段 大学习率的作用 小学习率的作用
    早期 快速穿过平坦区域 ——
    后期 —— 精细调整，避免在最优点附近震荡

    三、收敛性分析¶

    3.1 凸函数的收敛保证¶

    定理（\(L\)-光滑 + 凸）：设 \(\nabla f\) 是 \(L\)-Lipschitz 连续的 （即 \(\lVert\nabla f(\boldsymbol{x})-\nabla f(\boldsymbol{y})\rVert \leq L\lVert\boldsymbol{x}-\boldsymbol{y}\rVert\)）， 取 \(\eta \leq 1/L\)，则

    \[ f(\boldsymbol{x}_k) - f^* \leq \frac{\lVert\boldsymbol{x}_0-\boldsymbol{x}^*\rVert^2}{2\eta k} \]

    即 \(O(1/k)\) 收敛。

    若进一步是 \(\mu\)-强凸（\(\nabla^2f\succeq\mu I\)），则线性收敛：

    \[ f(\boldsymbol{x}_k) - f^* \leq \left(1-\frac{\mu}{L}\right)^k\big(f(\boldsymbol{x}_0)-f^*\big) \]

    「L-光滑」与「mu-强凸」的物理含义

    概念 数学 物理含义
    \(L\)-光滑 \(\nabla^2f\preceq LI\) 曲率有上界（不会太陡）
    \(\mu\)-强凸 \(\nabla^2f\succeq\mu I\) 曲率有下界（不会太平）

    两者的比值 \(L/\mu\) 就是条件数的推广 → 决定收敛速率。

    情形 收敛阶
    凸 + \(L\)-光滑 \(O(1/k)\)
    强凸 + \(L\)-光滑 线性收敛 \(O(\rho^k)\)
    仅非凸 \(O(1/\sqrt{k})\)（只能到梯度 \(\approx0\)）

    重要提醒：非凸情形下只能说「梯度趋于零」， 不能保证到达全局最优（因为它可能收敛到鞍点或局部极小）。

    \(L\) 的实用估计：\(L\approx\lambda_{\max}(\nabla^2 f)\)， 所以「\(\eta\leq1/L\)」与前面的「\(\eta<2/\lambda_{\max}\)」一致

    四、随机梯度下降（SGD）¶

    问题：\(n\) 个样本时，目标函数是可加形式

    \[ f(\boldsymbol{x}) = \frac1n\sum_{i=1}^{n}f_i(\boldsymbol{x}) \]

    每次算完整梯度需要遍历全部数据（\(n\) 很大时不可行）。

    SGD：每次用一个样本（或一小批）估计梯度：

    \[ \boldsymbol{x}_{k+1} = \boldsymbol{x}_k - \eta_k\nabla f_{i_k}(\boldsymbol{x}_k) \]

    其中 \(i_k\) 随机选取。

    期望意义下梯度无偏：

    \[ E_{i_k}[\nabla f_{i_k}(\boldsymbol{x})] = \nabla f(\boldsymbol{x}) \]

    但方差非零 → 引入噪声。

    SGD 的三个关键影响

    1. 计算成本

    方法 每步成本 \(n = 10^6\) 时
    批量 GD \(O(n)\) 每步算 \(10^6\) 个样本
    SGD \(O(1)\) 每步算 1 个样本

    每步快 \(10^6\) 倍 —— 这是大规模训练可行的关键。

    2. 噪声的双重作用

    影响 说明
    坏处 梯度有噪声 → 在最优点附近不收敛（震荡）
    好处 噪声帮助逃离浅的局部极小与鞍点

    这解释了「为什么 SGD 在非凸优化中表现好」—— 它不追求精确收敛，而是「在好的区域内游走」。

    3. 学习率必须衰减

    因为噪声导致的震荡幅度正比于 \(\eta\)，要收敛必须逐步减小：

    \[ \sum_k\eta_k = \infty, \qquad \sum_k\eta_k^2 < \infty \]

    这两个条件（Robbins-Monro）保证收敛：

    条件 作用
    \(\sum\eta_k = \infty\) 能走任意远（不会半路停住）
    \(\sum\eta_k^2 < \infty\) 噪声累积可控（最终能收敛）

    典型选择：\(\eta_k = \frac{\eta_0}{1+k\tau}\)（\(O(1/k)\) 衰减）✓ 满足两条件。

    4.1 小批量（Mini-batch）¶

    实践中最常用：每步用 \(B\) 个样本（如 32、128、256）。

    梯度方差随批大小减小：

    \[ \operatorname{Var}\left[\frac1B\sum_{i=1}^{B}\nabla f_i\right] = \frac{\sigma^2}{B} \]

    所以梯度噪声的标准差 \(\propto 1/\sqrt{B}\)。

    为什么批大小不能无脑增大

    理论收益：方差 \(\propto 1/B\) → 越大越准。

    但收益递减：

    批大小 \(B\) 梯度噪声（相对） 计算成本
    \(1\) \(1.000\) \(1\)
    \(16\) \(0.250\) \(16\)
    \(64\) \(0.125\) \(64\)
    \(256\) \(0.063\) \(256\)
    \(1024\) \(0.031\) \(1024\)

    噪声按 \(1/\sqrt{B}\) 降，成本按 \(B\) 涨 → 收益递减。

    新的模型：\(\eta\) 与 \(B\) 有联合效应—— 「批大小的信息」与「学习率」可以互补：

    \[ \text{有效学习率} \propto \eta\sqrt{B} \]

    这解释了「线性缩放规则」：批大小增大 \(k\) 倍时， 学习率也应增大 \(k\) 倍（保持有效学习率不变）。

    实践建议：

    场合 批大小
    显存充足、追求速度 大（256–4096）+ 相应增大 \(\eta\)
    需要正则化效果 小（32–128） —— 噪声有正则作用
    泛化优先 中等 + 恰当调度

    五、动量与自适应方法¶

    5.1 动量（Momentum）¶

    问题：SGD 在「峡谷」形状（某一维曲率大）中会来回震荡。

    解决：累积历史梯度方向，平滑更新：

    \[ \boldsymbol{v}_{k+1} = \beta\boldsymbol{v}_k + \nabla f(\boldsymbol{x}_k) \]
    \[ \boldsymbol{x}_{k+1} = \boldsymbol{x}_k - \eta\boldsymbol{v}_{k+1} \]

    \(\beta\) 通常取 0.9。

    动量的两个作用机理

    1. 抑制震荡

    若某方向梯度来回变号 → 累积后相互抵消 → 震荡减弱

    2. 加速一致方向

    若某方向梯度持续同号 → 累积后变大 → 加速前进

    等效学习率的放大倍数：

    \[ \text{稳定状态下的累积} = \frac{1}{1-\beta} \]

    \(\beta = 0.9\) 时约 10 倍

    这解释了两件事：

    现象 解释
    动量能让收敛快很多 有效步长放大 10 倍
    用动量后学习率要调小 否则实际步长太大

    5.2 Nesterov 动量¶

    改进：在「预测的下一点」处算梯度，而非当前点：

    \[ \boldsymbol{v}_{k+1} = \beta\boldsymbol{v}_k + \nabla f\big(\boldsymbol{x}_k - \eta\beta\boldsymbol{v}_k\big) \]

    直观：先按动量「探一步」，在探到的位置看梯度—— 如果那一步走过头了，梯度会「拉回来」。

    收敛速率：凸情形下从 \(O(1/k)\) 改善到 \(O(1/k^2)\)

    5.3 Adam（最常用）¶

    思路：对每个参数自适应调整学习率（用梯度的一阶与二阶矩估计）。

    \[ m_k = \beta_1 m_{k-1} + (1-\beta_1)g_k \quad\text{（一阶矩）} \]
    \[ v_k = \beta_2 v_{k-1} + (1-\beta_2)g_k^2 \quad\text{（二阶矩）} \]

    偏差修正（防止初期偏向零）：

    \[ \hat m_k = \frac{m_k}{1-\beta_1^k}, \qquad \hat v_k = \frac{v_k}{1-\beta_2^k} \]

    更新：

    \[ \boldsymbol{x}_{k+1} = \boldsymbol{x}_k - \eta\frac{\hat m_k}{\sqrt{\hat v_k}+\epsilon} \]

    默认超参数：\(\beta_1 = 0.9\)、\(\beta_2 = 0.999\)、\(\epsilon = 10^{-8}\)。

    Adam 为什么对特征尺度差异鲁棒

    关键：分母 \(\sqrt{\hat v_k}\) 是该参数梯度的典型幅度。

    效果：更新量被归一化为

    \[ \frac{\hat m_k}{\sqrt{\hat v_k}} \approx \text{常数（约 1）} \]

    于是各参数的「有效学习率」被拉平 —— 梯度大的参数（大尺度特征）自动被除以大分母。

    这就是 Adam 对条件数不敏感的原因：

    方法 对条件数的依赖
    原始 GD 强（迭代数 \(\propto\kappa\)）
    Adam 弱（自动缩放）

    所以实践中的常见组合：

    场景 推荐
    快速原型、小数据 Adam
    精调（追求最优精度） SGD + 动量 + 学习率调度
    大规模视觉任务 LARS/LAMB（Adam 的大批量变体）

    Adam 的代价：内存开销是 SGD 的 3 倍 （要存 \(m_k\)、\(v_k\) 与梯度）。

    六、典型例题¶

    例题 1：学习率上界¶

    设 \(f(x_1,x_2) = \frac12(4x_1^2 + 100x_2^2)\)。 求梯度下降的稳定学习率上界与最优学习率。

    思路

    Hessian 是对角阵，特征值就是对角元。

    解答

    写出 Hessian

    \(f\) 是二次型 \(\frac12\boldsymbol{x}^\top A\boldsymbol{x}\) 形式，其中

    \[ A = \begin{bmatrix}4&0\\0&100\end{bmatrix} \]

    特征值（对角阵，直接读出）：

    \[ \lambda_{\max} = 100, \qquad \lambda_{\min} = 4 \]

    稳定条件：\(0 < \eta < \frac{2}{\lambda_{\max}}\)

    \[ \eta_{\text{上界}} = \frac{2}{100} = 0.02 \]

    最优学习率：

    \[ \eta^* = \frac{2}{\lambda_{\max}+\lambda_{\min}} = \frac{2}{100+4} = \frac{2}{104} \approx 0.01923 \]

    条件数：

    \[ \kappa = \frac{100}{4} = 25 \]

    收敛速率：

    \[ \rho = \frac{\kappa-1}{\kappa+1} = \frac{25-1}{25+1} = \frac{24}{26} \approx 0.923 \]

    达到 \(10^{-3}\) 误差所需迭代数：

    \[ \rho^k \leq 10^{-3} \implies k \geq \frac{\ln(10^{-3})}{\ln(0.923)} = \frac{-6.908}{-0.0801} \approx 86 \]

    结果：约 86 次迭代

    注意「特征尺度差异」造成的困难

    若把 \(x_2\) 除以 5（即「标准化」该维），则新的问题：

    \[ f = \frac12(4x_1^2 + 100(x_2/5)^2\cdot?) \cdots \]

    更直接的做法：标准化后 \(A = \text{diag}(4,4)\)（假设都归一到相近尺度），则

    量 标准化前 标准化后
    \(\lambda_{\max}\) \(100\) \(4\)
    \(\kappa\) \(25\) \(1\)
    \(\rho\) \(0.923\) \(0\)
    迭代数 \(\approx 86\) \(1\)

    迭代数从 86 降到 1 —— 这就是「为什么必须标准化」的定量证明。

    一般规律：

    \[ \text{迭代数} \propto \kappa \propto \frac{\text{最大特征尺度}^2}{\text{最小特征尺度}^2} \]

    （注意是平方，因为 Hessian 涉及二阶导。）

    推论：若某特征的尺度是另一维的 10 倍， 则贡献到条件数的因子是 \(10^2 = 100\) —— 影响非常显著。

    例题 2：手算几次梯度下降¶

    设 \(f(x) = x^2\)（即 \(\lambda_1 = 2\)，因为 \(f'' = 2\)）。 从 \(x_0 = 1\) 出发，用 \(\eta = 0.4\)，算前 3 次迭代，并验证收敛。

    思路

    直接代入公式；用 \(x_{k+1} = (1-\eta\lambda)x_k\) 形式更快。

    解答

    确定参数：\(f'(x) = 2x\)，所以

    \[ \eta\lambda = 0.4\times2 = 0.8 \]

    迭代公式：

    \[ x_{k+1} = x_k - 0.4\times(2x_k) = x_k(1-0.8) = 0.2x_k \]

    逐次计算：

    \(k\) \(x_k\)
    0 \(1\)
    1 \(0.2\times1 = 0.2\)
    2 \(0.2\times0.2 = 0.04\)
    3 \(0.2\times0.04 = 0.008\)

    验证收敛条件：

    \[ \lvert1-\eta\lambda\rvert = \lvert0.2\rvert = 0.2 < 1 \;\checkmark \]

    收敛

    收敛速率：每步误差变为 \(0.2\) 倍 —— 非常快（因为这是一个 一维问题，条件数为 1）。

    一般解：\(x_k = 0.2^k\)。

    验证「稳定条件」的边界（一个值得做的实验）

    取 \(\eta = 1\)（即 \(\eta\lambda = 2\)）：

    \[ x_{k+1} = (1-2)x_k = -x_k \]

    结果：\(\lvert x_k\rvert\) 恒为 1，但符号交替：

    \(k\) \(x_k\)
    0 \(1\)
    1 \(-1\)
    2 \(1\)
    3 \(-1\)

    这是「临界振荡」：\(\lvert1-\eta\lambda\rvert = 1\)， 处于收敛与发散的边界，不会收敛到 0 ✗

    取 \(\eta = 1.1\)（即 \(\eta\lambda = 2.2\)）：

    \[ x_{k+1} = (1-2.2)x_k = -1.2x_k \]
    \[ \lvert x_k\rvert = 1.2^k \to \infty \]

    发散 ✗

    这三组对比说明了什么：

    \(\eta\lambda\) \(\lvert1-\eta\lambda\rvert\) 行为
    \(0.8\) \(0.2\) 收敛 ✓
    \(2.0\) \(1.0\) 临界振荡（不收敛）
    \(2.2\) \(1.2\) 发散 ✗

    实践启示：学习率接近上界时会出现「损失上下跳动」—— 这是需要减小学习率的明确信号。

    例题 3：条件数对收敛速度的影响¶

    设 \(f(x_1,x_2) = \frac12(x_1^2 + 1000x_2^2)\)。 求最优学习率下的收敛速率，以及要达到 \(10^{-6}\) 精度需多少步。

    思路

    特征值是 1 与 1000；用 \(\rho = (\kappa-1)/(\kappa+1)\)。

    解答

    特征值：

    \[ \lambda_{\max} = 1000, \qquad \lambda_{\min} = 1 \]

    条件数：

    \[ \kappa = 1000 \]

    最优学习率：

    \[ \eta^* = \frac{2}{1000+1} = \frac{2}{1001} \approx 0.001998 \]

    收敛速率：

    \[ \rho = \frac{1000-1}{1000+1} = \frac{999}{1001} \approx 0.998 \]

    所需步数（误差从 1 降到 \(10^{-6}\)）：

    \[ \rho^k \leq 10^{-6} \]
    \[ k \geq \frac{\ln(10^{-6})}{\ln(0.998)} = \frac{-13.816}{-0.002002} \approx 6900 \]

    结果：约 6900 步

    对比：

    条件数 步数（到 \(10^{-6}\)）
    \(1\) \(1\)
    \(10\) \(\approx 70\)
    \(100\) \(\approx 690\)
    \(1000\) \(\approx 6900\)

    规律（很重要）：

    \[ \text{步数} \approx \frac{\kappa}{2}\ln\frac{1}{\epsilon} \]

    步数与条件数成正比

    （推导：\(\rho = \frac{\kappa-1}{\kappa+1} \approx 1-\frac{2}{\kappa}\)， 所以 \(\ln\rho \approx -\frac2\kappa\)，于是 \(k \approx -\frac{\kappa}{2}\ln\epsilon\)。）

    这个例子解释了「为什么深度学习需要几十万步训练」

    真实的深度学习问题：

    因素 影响
    参数多（\(10^6\)–\(10^9\)） 特征值谱宽
    特征尺度差异大 条件数可能 \(10^4\)–\(10^6\)
    目标是 \(10^{-2}\) 级精度（不需 \(10^{-6}\)） 缓解但有限

    按上面的公式估算：\(\kappa = 10^5\) 时

    \[ k \approx \frac{10^5}{2}\times\ln(10^2) \approx 2.3\times10^5 \]

    几十万步 —— 与实际情况相符。

    三项加速手段（对应三个时间尺度）：

    手段 作用机理 效果
    标准化/归一化 直接降低 \(\kappa\) 最根本
    Adam / 自适应 抵消尺度差异 对 \(\kappa\) 不敏感
    二阶方法（牛顿） 消除 \(\kappa\) 依赖 收敛步数与 \(\kappa\) 无关

    牛顿法的代价：需要 Hessian（\(n^2\) 存储、\(n^3\) 求逆）—— 对 \(10^6\) 参数不可行，所以实践中用拟牛顿法（L-BFGS） 或对角近似（Adam 就是对角二阶近似）。

    例题 4：SGD 的方差与批大小¶

    某任务的单样本梯度方差 \(\sigma^2 = 4\)。用批大小 \(B\) 时，梯度噪声的标准差是多少？若 \(B\) 从 64 增到 256，噪声降到多少？

    思路

    梯度方差 ∝ \(1/B\)，标准差 ∝ \(1/\sqrt{B}\)。

    解答

    批梯度方差：

    \[ \operatorname{Var}\left[\frac1B\sum_{i=1}^{B}g_i\right] = \frac{\sigma^2}{B} \]

    标准差：

    \[ \text{std} = \frac{\sigma}{\sqrt B} \]

    对 \(B = 64\)：

    \[ \text{std} = \frac{2}{\sqrt{64}} = \frac{2}{8} = 0.25 \]

    对 \(B = 256\)：

    \[ \text{std} = \frac{2}{\sqrt{256}} = \frac{2}{16} = 0.125 \]

    结果：\(B\) 从 64 增到 256（4 倍），噪声降到 \(1/2\)

    一般关系：

    \[ \frac{\text{std}_{256}}{\text{std}_{64}} = \sqrt{\frac{64}{256}} = \frac12 \]

    批大小增 4 倍 → 标准差降为一半

    「线性缩放规则」的推导与实用价值

    问题：批大小增大后，梯度更准（噪声小）， 此时若保持 \(\eta\) 不变，会发生什么？

    分析：噪声减小 → 更新方向更可靠 → 可以走更大步而不震荡。

    经验规则（线性缩放）：

    \[ B\to kB \implies \eta \to k\eta \]

    理论依据：有效学习率正比于 \(\eta\sqrt B\)（近似不变）， 所以 \(B\) 增 \(k\) 倍时 \(\eta\) 应增 \(k\) 倍。

    两条规则的对比：

    规则 形式 适用
    线性缩放 \(\eta\propto B\) 保持「有效学习率」
    平方根缩放 \(\eta\propto\sqrt B\) 更保守（防不稳定）

    实用建议：

    情形 做法
    想加快训练 增大 \(B\) 同时按比例增大 \(\eta\)
    出现发散 用较保守的 \(\sqrt B\) 缩放，或先预热
    显存受限 用梯度累积模拟大批量

    梯度累积技巧（省显存的大批量）：

    累加 \(k\) 次小批梯度后再更新一次 → 等效于 \(k\) 倍批大小， 但只需一份小批的显存

    注意：大批量训练的泛化能力有时较差（即使训练损失相同）。 这是「大批量训练的泛化差距」问题，通常用学习率预热缓解。

    七、自测¶

    Q1 设 \(f(x) = 5x^2\)。用梯度下降（\(\eta = 0.05\)）从 \(x_0 = 2\) 出发， 写出迭代式并算前两步。

    提示

    \(f'(x) = 10x\)，所以 \(x_{k+1} = x_k(1-\eta\cdot10)\)。

    解答

    确定系数：

    \[ f'(x) = 10x \implies \eta\lambda = 0.05\times10 = 0.5 \]

    迭代式：

    \[ x_{k+1} = x_k - 0.05\times(10x_k) = x_k(1-0.5) = 0.5x_k \]

    计算：

    \(k\) \(x_k\)
    0 \(2\)
    1 \(1\)
    2 \(0.5\)

    验证收敛条件：

    \[ \lvert1-\eta\lambda\rvert = 0.5 < 1 \;\checkmark \]

    收敛，每步误差减半（收敛速率 \(\rho = 0.5\)）。

    最优学习率（这里 \(\lambda_{\max} = \lambda_{\min} = 10\)，\(\kappa = 1\)）：

    \[ \eta^* = \frac{2}{\lambda_{\max}+\lambda_{\min}} = \frac{2}{20} = 0.1 \]

    取 \(0.1\) 时 \(\lvert1-\eta\lambda\rvert = 0\) → 一步到位

    注意：一维问题条件数恒为 1，所以可以一步收敛。 多维问题中只有「各方向曲率相同」（\(\kappa=1\)）才能一步到位。

    Q2 某问题的 Hessian 特征值为 \(\{1, 9, 100\}\)。 求稳定学习率上界与最优学习率，并估计收敛速率。

    提示

    上界由最大特征值决定；最优值用公式 \(2/(\lambda_{\max}+\lambda_{\min})\)。

    解答

    特征值：

    \[ \lambda_{\max} = 100, \qquad \lambda_{\min} = 1 \]

    稳定上界：

    \[ \eta < \frac{2}{\lambda_{\max}} = \frac{2}{100} = 0.02 \]

    最优学习率：

    \[ \eta^* = \frac{2}{100+1} = \frac{2}{101} \approx 0.0198 \]

    条件数：

    \[ \kappa = \frac{100}{1} = 100 \]

    收敛速率：

    \[ \rho = \frac{\kappa-1}{\kappa+1} = \frac{99}{101} \approx 0.980 \]

    达到 \(10^{-3}\) 的步数：

    \[ k \geq \frac{\ln(10^{-3})}{\ln(0.980)} = \frac{-6.908}{-0.0202} \approx 345 \]

    结果：

    量 值
    \(\eta\) 上界 \(0.02\)
    \(\eta^*\) \(0.0198\)
    \(\rho\) \(0.980\)
    迭代数 \(\approx 345\)

    注意中间那个特征值 9 不起作用：

    特征值 角色
    \(100\)（最大） 决定学习率上界
    \(1\)（最小） 决定收敛速度
    \(9\)（中间） 不影响这两者

    工程启示：改善条件数的重点是「拉近最大与最小」—— 中间的特征值怎么分布关系不大。

    所以数据标准化（把各维尺度拉近）直接命中要害

    Q3 判断：SGD 的学习率可以保持不变（不衰减）。

    提示

    考虑噪声的影响以及 Robbins-Monro 条件。

    解答

    不对。SGD 的学习率必须衰减（至少在实际要达到精确解时）。

    原因：SGD 的梯度有噪声：

    \[ \boldsymbol{x}_{k+1} = \boldsymbol{x}_k - \eta\nabla f_{i_k}(\boldsymbol{x}_k) \]

    在最优解附近：真实梯度趋于零，但噪声不趋于零：

    \[ \nabla f_{i_k}(\boldsymbol{x}^*) \neq \boldsymbol{0}\quad\text{（单样本梯度非零）} \]

    后果：更新量的方差 \(\approx\eta^2\sigma^2\)。

    学习率 行为
    固定 \(\eta\) 在最优点附近永久震荡，无法精确收敛 ✗
    衰减 \(\eta_k\to0\) 震荡幅度减小 → 可以收敛 ✓

    Robbins-Monro 条件（收敛的充分条件）：

    \[ \sum_{k=1}^{\infty}\eta_k = \infty, \qquad \sum_{k=1}^{\infty}\eta_k^2 < \infty \]
    条件 作用 若违反
    \(\sum\eta_k = \infty\) 能走任意远 永远到不了最优点
    \(\sum\eta_k^2 < \infty\) 噪声累积有限 无法收敛到精确解

    典型衰减：\(\eta_k = \frac{\eta_0}{1+k\tau}\)（\(O(1/k)\)）满足两条件

    实践中的折中：

    场合 做法
    追求最高精度 严格衰减（如每若干轮减半）
    深度学习常规训练 阶梯/余弦衰减（不追求精确最优）
    大批量 + 好初始化 可以较长时间保持大学习率
    需要「永远在线学习」 保持小常数学习率（容忍震荡）

    深度学习中的常见做法：余弦退火到很小的值（不是严格 0）， 最后阶段近似「收敛」。

    Q4 为什么动量的等效学习率放大倍数约为 \(1/(1-\beta)\)？

    提示

    考虑梯度恒定不变时动量的累积效果。

    解答

    因为动量把历史梯度累积起来，稳定状态下累积的倍数是几何级数之和。

    设定：假设梯度恒定 \(\boldsymbol{g}_k = \boldsymbol{g}\)（用于估计稳态）。

    动量递推：

    \[ \boldsymbol{v}_{k+1} = \beta\boldsymbol{v}_k+\boldsymbol{g} \]

    展开（从 \(\boldsymbol{v}_0 = \boldsymbol{0}\) 出发）：

    \[ \boldsymbol{v}_1 = \boldsymbol{g} \]
    \[ \boldsymbol{v}_2 = \beta\boldsymbol{g}+\boldsymbol{g} = (1+\beta)\boldsymbol{g} \]
    \[ \boldsymbol{v}_3 = \beta(1+\beta)\boldsymbol{g}+\boldsymbol{g} = (1+\beta+\beta^2)\boldsymbol{g} \]

    一般形式：

    \[ \boldsymbol{v}_k = \left(\sum_{j=0}^{k-1}\beta^j\right)\boldsymbol{g} \]

    稳态（\(k\to\infty\)，\(\lvert\beta\rvert<1\)）：

    \[ \boldsymbol{v}_\infty = \frac{1}{1-\beta}\boldsymbol{g} \]

    这就是放大倍数

    代入 \(\beta = 0.9\)：

    \[ \frac{1}{1-0.9} = 10 \;\checkmark \]

    含义：动量让有效步长变成原来的 10 倍。

    实践推论：

    情形 调整
    从无动量改为 \(\beta=0.9\) 学习率应减到约 1/10
    否则 有效步长过大 → 震荡或发散

    注意这是「稳态」估计：初期（\(k\) 小）放大倍数还没达到 10：

    \(k\) 累积倍数（\(\beta=0.9\)）
    1 \(1\)
    2 \(1.9\)
    5 \(4.10\)
    10 \(6.51\)
    20 \(8.78\)
    \(\infty\) \(10\)

    这解释了两件事：

    现象 原因
