    对偶问题¶

    上一页的拉格朗日函数带来了一个「副作用」：每个原始问题都伴随一个对偶问题。

    对偶：从「下界」的角度重新看约束优化。

    它的价值不只是理论优美——SVM、通信资源分配、网络流等许多 问题的实用算法都是在对偶域求解的。

    为什么需要「对偶」

    动机 说明
    给出下界 对偶问题的最优值 ≤ 原始最优值，可评估解的质量
    换约束形式 原始约束多/复杂 → 对偶约束可能简单
    降维 对偶变量个数 = 约束个数（常远小于变量数）
    结构化算法 SVM、ADMM 等在对偶域有高效解法
    理论工具 证明强对偶、KKT 条件的必经之路

    一、拉格朗日对偶函数¶

    定义¶

    考虑原始问题：

    \[ \min_{\boldsymbol{x}}f(\boldsymbol{x}) \quad\text{s.t.}\quad g_i(\boldsymbol{x})\leq0,\ h_j(\boldsymbol{x})=0 \]

    拉格朗日函数：

    \[ \mathcal{L}(\boldsymbol{x},\boldsymbol{\mu},\boldsymbol{\lambda}) = f(\boldsymbol{x}) + \sum_i\mu_ig_i(\boldsymbol{x}) + \sum_j\lambda_jh_j(\boldsymbol{x}) \]

    对偶函数：对 \(\boldsymbol{x}\) 取下确界

    \[ \boxed{\ \theta(\boldsymbol{\mu},\boldsymbol{\lambda}) = \inf_{\boldsymbol{x}}\mathcal{L}(\boldsymbol{x},\boldsymbol{\mu},\boldsymbol{\lambda})\ } \]

    对偶函数为什么「总是凹函数」（这一点很重要）

    关键观察：\(\mathcal{L}\) 对 \((\boldsymbol{\mu},\boldsymbol{\lambda})\) 是仿射函数 （线性加常数）。

    仿射函数既凸又凹

    逐点下确界保持凹性（前面「保持凸性的运算」一页：sup 保持凸、inf 保持凹）

    所以 \(\theta\) 一定是凹函数 —— 无论原问题是否凸 ✓

    因此对偶问题在形式上总是「好问题」（最大化凹函数）， 无论原问题是否凸。

    但要注意：对偶函数可能取 \(-\infty\)（当原始问题不可行时）， 此时相应的 \((\boldsymbol{\mu},\boldsymbol{\lambda})\) 不可用。

    对偶函数是原始最优值的下界¶

    核心性质：对任意 \(\boldsymbol{\mu}\geq0\) 与任意 \(\boldsymbol{\lambda}\)：

    \[ \theta(\boldsymbol{\mu},\boldsymbol{\lambda}) \leq p^* \]

    其中 \(p^*\) 是原始最优值。

    证明：设 \(\tilde{\boldsymbol{x}}\) 是任一可行点（即满足所有约束）。

    由于 \(\boldsymbol{\mu}\geq0\)、\(g_i(\tilde{\boldsymbol{x}})\leq0\)、\(h_j(\tilde{\boldsymbol{x}}) = 0\)：

    \[ \mathcal{L}(\tilde{\boldsymbol{x}},\boldsymbol{\mu},\boldsymbol{\lambda}) = f(\tilde{\boldsymbol{x}}) + \underbrace{\sum_i\mu_ig_i(\tilde{\boldsymbol{x}})}_{\leq0} + \underbrace{\sum_j\lambda_jh_j(\tilde{\boldsymbol{x}})}_{=0} \leq f(\tilde{\boldsymbol{x}}) \]

    所以：

    \[ \theta(\boldsymbol{\mu},\boldsymbol{\lambda}) = \inf_{\boldsymbol{x}}\mathcal{L} \leq \mathcal{L}(\tilde{\boldsymbol{x}},\boldsymbol{\mu},\boldsymbol{\lambda}) \leq f(\tilde{\boldsymbol{x}}) \]

    对任意可行点成立（特别地，对最优解 \(\boldsymbol{x}^*\)）：

    \[ \theta(\boldsymbol{\mu},\boldsymbol{\lambda}) \leq f(\boldsymbol{x}^*) = p^* \;\checkmark \]

    这个下界的重要工程含义

    它给出「最优解不可能比这个更好」的证明：

    用途 说明
    评估解的质量 已知下界，就能算「当前解离最优有多远」
    终止准则 原始-对偶间隙 \(f(\boldsymbol{x})-\theta(\boldsymbol{\mu})\to0\) 时停止
    算法可靠性 提供严格保证（不是启发式）

    数值例：

    设某问题的对偶给出下界 \(\theta = 98.0\)，而某个可行解给出 \(f = 100.3\)。

    则间隙：

    \[ f-\theta = 2.3 \]

    结论：当前解最多比最优差 2.3（相对差 \(\leq 2.3\%\)）

    这比「跑一万次看看」可靠得多——是严格的界。

    实践中的应用：分支定界法（整数规划）就靠对偶界剪枝； ADMM 用对偶变量做分布式协调。

    二、对偶问题与对偶间隙¶

    对偶问题：最大化下界

    \[ \max_{\boldsymbol{\mu},\boldsymbol{\lambda}}\ \theta(\boldsymbol{\mu},\boldsymbol{\lambda}) \quad\text{s.t.}\quad \boldsymbol{\mu}\geq0 \]

    记其最优值为 \(d^*\)。

    弱对偶（总是成立）：

    \[ d^* \leq p^* \]

    对偶间隙：

    \[ \text{gap} = p^* - d^* \geq 0 \]

    强对偶：\(d^* = p^*\)（间隙为零）。

    强对偶何时成立（这是最关键的问题）

    条件 结论
    一般情形 只有弱对偶（\(d^*\leq p^*\)）
    凸问题 + Slater 条件 强对偶（\(d^* = p^*\)）✓
    线性规划 总是强对偶（不需要额外条件）
    二次凸规划（QCQP，凸） Slater 条件下强对偶

    Slater 条件：存在严格可行点 \(\boldsymbol{x}\)，使得

    \[ g_i(\boldsymbol{x}) < 0 \quad\text{（对所有非仿射的不等式约束）} \]

    直观含义：可行域有「内部」（不是退化成一条线或一个点）。

    线性规划为什么无条件成立：总能找到「严格内点」 （若可行域非空且有界），故 Slater 条件自动满足。

    对机器学习的意义：

    问题 是否强对偶 说明
    SVM（软间隔） ✓ 强对偶 目标二次、约束线性 → 凸 + Slater
    Lasso ✓ 强对偶 凸问题
    逻辑回归 ✓ 强对偶 凸问题
    神经网络训练 ✗ 一般无强对偶 非凸

    三、对偶问题的求解（线性规划的例子）¶

    对偶最漂亮的应用是线性规划。

    原始问题（标准形式）¶

    \[ \min_{\boldsymbol{x}}\ \boldsymbol{c}^\top\boldsymbol{x} \quad\text{s.t.}\quad A\boldsymbol{x}\geq\boldsymbol{b},\ \boldsymbol{x}\geq\boldsymbol{0} \]

    对偶问题¶

    推导思路：写拉格朗日函数并对 \(\boldsymbol{x}\) 取下确界。

    \[ \mathcal{L}(\boldsymbol{x},\boldsymbol{y}) = \boldsymbol{c}^\top\boldsymbol{x} + \boldsymbol{y}^\top(\boldsymbol{b}-A\boldsymbol{x}) = (\boldsymbol{c}-A^\top\boldsymbol{y})^\top\boldsymbol{x} + \boldsymbol{b}^\top\boldsymbol{y} \]

    关于 \(\boldsymbol{x}\geq0\) 取下确界：

    情形 \(\inf\)
    \(\boldsymbol{c}-A^\top\boldsymbol{y} \geq \boldsymbol{0}\) \(\boldsymbol{b}^\top\boldsymbol{y}\)（取 \(\boldsymbol{x}=\boldsymbol{0}\)）
    否则（某分量 \(<0\)） \(-\infty\)（沿该方向让 \(x\to+\infty\)）

    所以：

    \[ \theta(\boldsymbol{y}) = \begin{cases}\boldsymbol{b}^\top\boldsymbol{y}, & A^\top\boldsymbol{y}\leq\boldsymbol{c}\\ -\infty, & \text{否则}\end{cases} \]

    对偶问题：

    \[ \max_{\boldsymbol{y}}\ \boldsymbol{b}^\top\boldsymbol{y} \quad\text{s.t.}\quad A^\top\boldsymbol{y}\leq\boldsymbol{c},\ \boldsymbol{y}\geq\boldsymbol{0} \]

    LP 原始与对偶的「对称美」

    把两者并排看：

    原始（primal） 对偶（dual）
    目标 \(\min\ \boldsymbol{c}^\top\boldsymbol{x}\) \(\max\ \boldsymbol{b}^\top\boldsymbol{y}\)
    约束 \(A\boldsymbol{x}\geq\boldsymbol{b}\) \(A^\top\boldsymbol{y}\leq\boldsymbol{c}\)
    变量符号 \(\boldsymbol{x}\geq0\) \(\boldsymbol{y}\geq0\)

    规律（记忆要点）：

    变换 效果
    目标 \(\min\to\max\)
    系数 \(\boldsymbol{c}\leftrightarrow\boldsymbol{b}\) 互换
    矩阵 \(A\to A^\top\)
    不等号 \(\geq\to\leq\)

    「转置 + 对角互换」 —— 这就是 LP 对偶的完整规则。

    对偶的实用性（变量数目的变化）：

    问题 原始变量 对偶变量
    网络流 边数（可 \(10^6\)） 节点数（可 \(10^3\)）
    投资组合 资产数 约束数
    SVM 样本数（可 \(10^5\)） 样本数（相同）

    当约束数远小于变量数时，对偶问题规模小得多 → 更好解

    互补松弛（LP 情形）：

    \[ y_i(b_i - (A\boldsymbol{x})_i) = 0, \qquad x_j(c_j - (A^\top\boldsymbol{y})_j) = 0 \]
    含义 说明
    约束有余量 → 对偶变量为 0 该约束不影响最优
    变量 \(>0\) → 对偶约束「紧」 该约束恰好取等号

    这是「松紧互补」的经济学解释： 「有富余的资源不值钱（\(\lambda=0\)）； 值钱的资源一定被用光（约束取等号）」。

    四、SVM：对偶的经典应用¶

    原始问题（软间隔 SVM）¶

    \[ \min_{\boldsymbol{w},b,\boldsymbol{\xi}}\ \frac12\lVert\boldsymbol{w}\rVert^2 + C\sum_i\xi_i \]
    \[ \text{s.t.}\quad y_i(\boldsymbol{w}^\top\boldsymbol{x}_i+b)\geq1-\xi_i,\quad \xi_i\geq0 \]

    对偶问题¶

    引入乘数 \(\alpha_i\geq0\)（对应间隔约束）与 \(\beta_i\geq0\)（对应 \(\xi_i\geq0\)）， 推导后得到

    \[ \max_{\boldsymbol{\alpha}}\ \sum_i\alpha_i - \frac12\sum_{i,j}\alpha_i\alpha_jy_iy_j\boldsymbol{x}_i^\top\boldsymbol{x}_j \]
    \[ \text{s.t.}\quad 0\leq\alpha_i\leq C,\qquad \sum_i\alpha_iy_i = 0 \]

    最优权重：

    \[ \boldsymbol{w}^* = \sum_i\alpha_i^*y_i\boldsymbol{x}_i \]

    对偶形式带来的三个关键好处

    1. 数据只以「内积」形式出现

    看对偶目标里的 \(\boldsymbol{x}_i^\top\boldsymbol{x}_j\) —— 只有内积！

    这直接引出「核方法」：把内积替换成核函数

    \[ \boldsymbol{x}_i^\top\boldsymbol{x}_j \longrightarrow k(\boldsymbol{x}_i,\boldsymbol{x}_j) \]

    就得到非线性 SVM，而无需显式计算高维映射

    核 形式 效果
    线性 \(\boldsymbol{x}^\top\boldsymbol{z}\) 线性分割
    多项式 \((\boldsymbol{x}^\top\boldsymbol{z}+1)^d\) 多项式曲面
    RBF/高斯 \(e^{-\gamma\lVert\boldsymbol{x}-\boldsymbol{z}\rVert^2}\) 无穷维映射

    注意最后一行：RBF 核对应无穷维特征空间， 根本无法显式构造——但核技巧只需算内积， 因此完全可行

    1. 约束从「每个样本一条」变成「简单箱约束」

      形式 约束
      原始 \(y_i(\boldsymbol{w}^\top\boldsymbol{x}_i+b)\geq1-\xi_i\)（每个样本一条）
      对偶 \(0\leq\alpha_i\leq C\)（箱约束）+ 一个等式

      箱约束是二次规划求解器最擅长的形式

      3. 稀疏性（互补松弛的后果）

      互补松弛条件给出

      \[ \alpha_i\big[y_i(\boldsymbol{w}^\top\boldsymbol{x}_i+b)-1+\xi_i\big] = 0 \]

      只有「活跃」的样本（支持向量）有 \(\alpha_i > 0\)

      样本 \(\alpha_i\) 对 \(\boldsymbol{w}\) 的贡献
      在边界上或违反间隔 \(>0\) 有贡献
      分类正确且在间隔外 \(=0\) 无贡献

      所以：

      \[ \boldsymbol{w}^* = \sum_{i\in\text{支持向量}}\alpha_i^*y_i\boldsymbol{x}_i \]

      只需保留支持向量 → 预测阶段的计算量与存储都很小

      这也解释了一个著名的现象：移动远离边界的样本， SVM 的解完全不变——因为它们的 \(\alpha_i = 0\)。

    五、典型例题¶

    例题 1：求对偶函数¶

    设 \(f(x) = x^2\)，约束 \(g(x) = x-1\leq0\)。求对偶函数。

    思路

    写拉格朗日函数，对 \(x\) 求下确界（注意 \(\mu\geq0\) 的要求在后面用到）。

    解答

    第一步：拉格朗日函数

    \[ \mathcal{L}(x,\mu) = x^2+\mu(x-1) \]

    第二步：对 \(x\) 求下确界

    \(\mathcal{L}\) 关于 \(x\) 是二次函数，开口向上，极小点在导数为零处：

    \[ \frac{\partial\mathcal{L}}{\partial x} = 2x+\mu = 0 \implies x = -\frac{\mu}{2} \]

    代入：

    \[ \mathcal{L}\left(-\frac{\mu}{2},\mu\right) = \frac{\mu^2}{4}+\mu\left(-\frac{\mu}{2}-1\right) = \frac{\mu^2}{4}-\frac{\mu^2}{2}-\mu = -\frac{\mu^2}{4}-\mu \]

    所以对偶函数：

    \[ \boxed{\ \theta(\mu) = -\frac{\mu^2}{4}-\mu,\qquad \mu\geq0\ } \]

    第三步：验证是凹函数

    \[ \theta''(\mu) = -\frac12 < 0 \;\checkmark \]

    凹 ✓ 与理论一致。

    第四步：求对偶最优

    令 \(\theta'(\mu) = -\frac{\mu}{2}-1 = 0\)：

    \[ \mu = -2 \]

    但约束 \(\mu\geq0\) → 最优在边界 \(\mu = 0\)：

    \[ d^* = \theta(0) = 0 \]

    第五步：与原始最优比较

    原始问题：\(\min x^2\) s.t. \(x\leq1\)。

    无约束最优 \(x=0\) 满足 \(0\leq1\) → 约束不活跃。

    \[ p^* = f(0) = 0 \]

    所以 \(d^* = p^* = 0\) ✓ 强对偶成立（间隙为 0）

    从这道题看对偶函数的两类形状

    本例（约束不活跃）：

    量 值
    无约束最优 \(x=0\)
    是否满足约束 ✓ 满足
    \(\mu^*\) \(0\)
    对偶最优位置 边界

    若约束改为 \(g(x) = x+1\leq0\)（要求 \(x\leq-1\)）：

    无约束最优 \(x=0\) 违反约束 → 约束活跃。

    量 值
    原始最优 \(x=-1\)，\(p^*=1\)
    \(\mu^*\) \(+2\)
    对偶最优 内部点

    若沿用上面的形式：\(\theta(\mu) = -\frac{\mu^2}{4}-\mu\)，令导数为零得 \(\mu=-2<0\) 不可行 → 最优只能取边界 \(\mu=0\)，得 \(d^* = 0 < p^* = 1\) ✗。

    但原问题（目标凸、约束线性）是凸问题，按定理本应强对偶 —— 症结在于拉格朗日函数里约束的写法：必须写成 \(g(x) = x+1\leq0\)，即

    \[ \mathcal{L} = x^2+\mu(x+1) \]

    重新求下确界：\(\frac{\partial\mathcal{L}}{\partial x} = 2x+\mu = 0 \Rightarrow x = -\mu/2\)。

    \[ \theta(\mu) = \frac{\mu^2}{4}+\mu\left(-\frac{\mu}{2}+1\right) = \frac{\mu^2}{4}-\frac{\mu^2}{2}+\mu = -\frac{\mu^2}{4}+\mu \]

    令 \(\theta' = -\frac{\mu}{2}+1 = 0\) 得 \(\mu = 2\geq0\) ✓ 可行

    \[ d^* = \theta(2) = -1+2 = 1 = p^* \;\checkmark \]

    强对偶成立

    结论：拉格朗日函数里约束的符号必须正确 （\(g\leq0\) 的形式），否则对偶函数会算错。

    例题 2：LP 的对偶¶

    写出下列 LP 的对偶：

    \[ \min\ 3x_1+2x_2 \quad\text{s.t.}\quad x_1+x_2\geq4,\quad x_1\geq0,\ x_2\geq0 \]

    并验证强对偶。

    思路

    用 LP 对偶规则（转置 + 对角互换），或直接推导。

    解答

    第一步：写成标准形式

    目标 \(\boldsymbol{c} = (3,2)^\top\)，约束 \(A\boldsymbol{x}\geq\boldsymbol{b}\) 中

    \[ A = \begin{bmatrix}1&1\end{bmatrix},\qquad \boldsymbol{b} = 4 \]

    第二步：写出对偶

    按规则（\(\max\boldsymbol{b}^\top\boldsymbol{y}\) s.t. \(A^\top\boldsymbol{y}\leq\boldsymbol{c}\)，\(\boldsymbol{y}\geq0\)）：

    \[ \max\ 4y_1 \quad\text{s.t.}\quad y_1\leq3,\quad y_1\leq2,\quad y_1\geq0 \]

    化简（两个约束取更紧的）：

    \[ \max\ 4y_1\quad\text{s.t.}\quad 0\leq y_1\leq2 \]

    第三步：解对偶

    显然取 \(y_1 = 2\)：

    \[ d^* = 4\times2 = 8 \]

    第四步：解原始

    目标 \(3x_1+2x_2\) 中 \(x_2\) 的系数更小，但两者都受同一个约束 \(x_1+x_2\geq4\)。

    最优点：尽量用系数小的变量。

    方案 目标值
    \((4,0)\) \(12\)
    \((0,4)\) \(8\) ✓
    \[ p^* = 8 \]

    第五步：验证强对偶

    \[ d^* = 8 = p^* = 8 \;\checkmark \]

    强对偶成立 ✓（LP 必然强对偶）

    验证互补松弛：

    检查 结果
    \(y_1^* = 2 > 0\) → 对应约束应活跃 \(x_1+x_2 = 0+4 = 4\) ✓ 活跃
    \(x_1^* = 0\) → 对偶约束 \(y_1\leq3\) 应不紧 \(y_1 = 2 < 3\) ✓ 不紧
    \(x_2^* = 4 > 0\) → 对偶约束 \(y_1\leq2\) 应紧 \(y_1 = 2 = 2\) ✓ 紧

    全部成立

    互补松弛给出的「产品组合」直觉

    原始变量 \(x_j > 0\) 的含义：产品 \(j\) 值得生产。

    互补松弛说：若 \(x_j^* > 0\)，则对应的对偶约束必须是紧的：

    \[ (A^\top\boldsymbol{y}^*)_j = c_j \]

    解读：只有当「资源的影子价格恰好等于生产成本」时， 才值得生产该产品。

    情形 决策
    影子价格 \(=\) 成本 产销平衡（生产）
    影子价格 \(<\) 成本 不生产（\(x_j = 0\)）

    这就是「生产决策」的经济学判据， 也是 LP 在生产计划、运输调度中应用广泛的原因。

    例题 3：对偶给出下界的实用价值¶

    某优化问题（非凸）的原始最优值 \(p^*\) 未知。 用对偶求得 \(d^* = 12.5\)；某启发式算法给出可行解 \(f = 13.2\)。 评估该解的质量。

    思路

    用下界估计最大可能的改进幅度。

    解答

    第一步：建立不等式

    由弱对偶：

    \[ 12.5 = d^* \leq p^* \leq f = 13.2 \]

    第二步：估计间隙

    当前解与对偶界的差距：

    \[ f - d^* = 13.2 - 12.5 = 0.7 \]

    第三步：相对质量

    \[ \frac{f - d^*}{d^*} = \frac{0.7}{12.5} = 5.6\% \]

    结论：该解最多比最优值差 5.6%

    （因为 \(p^*\) 在 \([12.5, 13.2]\) 内，所以 \(f\) 相对 \(p^*\) 的差 不超过 \(5.6\%\)。）

    这个「质量保证」的工程价值

    对比两种评估方式：

    方式 能给出的结论
    多次运行取最好 「没找到更好的」← 无保证
    对偶下界 「不可能更好超过 5.6%」← 严格保证 ✓

    第二类结论的用途：

    场景 决策
    间隙 \(<1\%\) 接受该解（继续优化收益太小）
    间隙较大 继续改进，或投入更多算力
    需要严格最优 用分支定界（靠对偶界剪枝）

    在整数规划中的核心作用（分支定界）：

    步骤 操作
    1 放松整数约束 → 得到 LP 松弛（给上界，因为最小化问题放松后更松）
    2 用 LP 的对偶给下界
    3 若某分支的下界 > 当前最好可行解 → 剪枝 ✓
    4 重复直到间隙为零

    「剪枝」是整数规划能解大规模问题的关键—— 而剪枝的依据就是这里的对偶界。

    六、自测¶

    Q1 写出 \(\min\ 2x_1+3x_2\) s.t. \(x_1+x_2\geq3\)，\(x_1,x_2\geq0\) 的对偶。

    提示

    用 LP 对偶规则：\(\min\leftrightarrow\max\)、\(\boldsymbol{b}\leftrightarrow\boldsymbol{c}\)、\(A\to A^\top\)、\(\geq\to\leq\)。

    解答

    第一步：识别参数

    \[ \boldsymbol{c} = (2,3)^\top,\qquad A = \begin{bmatrix}1&1\end{bmatrix},\qquad \boldsymbol{b} = 3 \]

    第二步：写对偶

    按规则：

    \[ \max\ 3y_1\quad\text{s.t.}\quad \begin{bmatrix}1\\1\end{bmatrix}y_1\leq\begin{bmatrix}2\\3\end{bmatrix},\quad y_1\geq0 \]

    展开：

    \[ y_1\leq2,\qquad y_1\leq3,\qquad y_1\geq0 \]

    取更紧的约束：

    \[ \max\ 3y_1\quad\text{s.t.}\quad 0\leq y_1\leq2 \]

    第三步：求对偶最优

    \[ d^* = 3\times2 = 6 \]

    第四步：验证原始最优

    \(2x_1+3x_2\) 中 \(x_1\) 系数更小 → 尽量用 \(x_1\)：

    \[ (x_1,x_2) = (3,0) \implies 2\times3 = 6 \]

    对比 \((0,3)\)：\(3\times3 = 9\)（更差）。

    \[ p^* = 6 \;\checkmark \]

    强对偶成立：\(d^* = p^* = 6\)

    互补松弛检验：

    检验 结果
    \(y_1^* = 2>0\) → 原始约束活跃 \(x_1+x_2 = 3\) ✓
    \(x_2^* = 0\) → 对偶约束 \(y_1\leq3\) 不紧 \(2 < 3\) ✓
    \(x_1^* = 3>0\) → 对偶约束 \(y_1\leq2\) 紧 \(2 = 2\) ✓

    全部成立

    Q2 判断：对任意优化问题，对偶间隙都为零。

    提示

    想想非凸的情形。

    解答

    不对。只有凸问题在满足适当条件时间隙才为零。

    一般结论：

    问题类型 对偶间隙
    一般（含非凸） 可能 > 0（弱对偶只给 \(d^*\leq p^*\)）
    凸 + Slater 条件 = 0（强对偶）✓
    线性规划 = 0（无条件成立）
    凸二次规划（QCQP） Slater 下为 0

    对偶间隙 > 0 的后果：

    后果 说明
    无法用对偶精确求解 对偶最优 ≠ 原始最优
    但下界仍有效 可用于评估解质量
    可能「不可达」 对偶最优可能取不到（只在极限）

    非凸问题的实用价值：

    虽然间隙可能非零，但对偶仍能给出下界 —— 这足以用于：

    用途 说明
    分支定界的剪枝 整数规划的核心
    解质量评估 「不可能更好超过 X%」
    松弛求解 得到近似解

    Q3 对偶函数为什么一定是凹函数（无论原问题是否凸）？

    提示

    对偶函数是「拉格朗日函数对 \(x\) 的下确界」。

    解答

    因为「对仿射函数取下确界」保持凹性。

    证明思路（分两步）：

    第一步：拉格朗日函数对乘数是仿射的

    \[ \mathcal{L}(\boldsymbol{x},\boldsymbol{\mu},\boldsymbol{\lambda}) = f(\boldsymbol{x})+\sum_i\mu_ig_i(\boldsymbol{x})+\sum_j\lambda_jh_j(\boldsymbol{x}) \]

    固定 \(\boldsymbol{x}\)，把 \((\boldsymbol{\mu},\boldsymbol{\lambda})\) 当自变量： \(\mathcal{L}\) 是它们的一次函数（加常数）

    → 仿射函数 → 既凸又凹

    第二步：逐点下确界保持凹性

    \[ \theta(\boldsymbol{\mu},\boldsymbol{\lambda}) = \inf_{\boldsymbol{x}}\mathcal{L}(\boldsymbol{x},\boldsymbol{\mu},\boldsymbol{\lambda}) \]

    一般事实：

    运算 保持
    逐点上确界（\(\sup\)） 凸性 ✓
    逐点下确界（\(\inf\)） 凹性 ✓

    （这是「保持凸性的运算」一页的对偶版本。）

    所以 \(\theta\) 是凹函数 —— 不需要原问题凸

    这个性质为什么重要：

    意义 说明
    对偶问题总是「最大化凹函数」 形式上总是「好问题」
    即使原问题非凸，对偶也结构良好 便于求解
    但对偶可行域可能复杂 仍需处理约束

    注意：对偶问题还要求 \(\boldsymbol{\mu}\geq0\)， 以及对 \(\theta = -\infty\) 的点要排除。

    但「凹」这一点已经很值钱了： 例如次梯度法可以直接用于最大化凹函数， 无需原问题凸性

    Q4 举例说明「对偶给下界」在整数规划中的用途。

    提示

    考虑分支定界法的剪枝逻辑。

    解答

    用途：分支定界法中的「剪枝」——这是整数规划能解大规模问题的关键。

    问题形式（最小化）：

    \[ \min\ \boldsymbol{c}^\top\boldsymbol{x}\quad\text{s.t.}\quad A\boldsymbol{x}\geq\boldsymbol{b},\ \boldsymbol{x}\in\mathbb{Z}^n \]

    难点：整数约束使问题NP 难。

    松弛策略：把 \(\boldsymbol{x}\in\mathbb{Z}^n\) 放松为 \(\boldsymbol{x}\geq0\) → 得到线性规划松弛，此时 \(p^*_{\text{LP}}\leq p^*_{\text{IP}}\)。

    用对偶给出「下界」的具体流程：

    步骤 操作
    1 解 LP 松弛，得 \(p^*_{\text{LP}}\)（这是 IP 的下界）
    2 若 LP 解恰好是整数 → 完成（它就是 IP 最优）
    3 否则选一个非整数分量分支（如 \(x_j\leq\lfloor\cdot\rfloor\) 与 \(x_j\geq\lceil\cdot\rceil\)）
    4 对每个分支重复 1–3
    5 剪枝：若某分支的下界 \(\geq\) 当前最好可行解 → 丢弃该分支 ✓

    为什么第 5 步能剪枝：

    该分支的所有解都 \(\geq\) 下界 \(\geq\) 当前最好解 → 不可能更好 → 无需继续探索

    数值例子：

    分支 LP 下界 决策
    分支 A \(12.5\) 探索（当前最好解 \(13.2\)）
    分支 B \(13.5\) 剪枝（\(\geq13.2\)）✓
    分支 C 不可行 剪枝 ✓

    效率提升的来源：

    手段 效果
    好下界（紧的） 剪枝更多
    LP 对偶恰给出紧下界 所以 LP 是标准松弛
    好可行解（上界） 剪枝阈值更高

    实用提醒：现代整数规划求解器都会同时维护 「最好的可行解」与「对偶界」， 当两者相等（间隙为零）时证明已找到最优解，可以停止

    这就是「对偶」在工程中最直接的价值 —— 它把「无法判断是否最优」变成「可以严格证明最优」。
