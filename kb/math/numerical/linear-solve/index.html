    线性方程组求解¶

    线性方程组 \(A\boldsymbol{x} = \boldsymbol{b}\) 是数值计算中出现最频繁的问题：

    来源 规模
    有限元 / 有限差分 \(10^{6}\)–\(10^{9}\)
    电路仿真 \(10^{3}\)–\(10^{5}\)
    最小二乘拟合 \(10^{2}\)–\(10^{4}\)
    机器人逆运动学 \(6\)–\(30\)

    求解方法分两大类：

    类型 方法 适用
    直接法 高斯消元、LU、Cholesky 中小规模、稠密 ✓
    迭代法 Jacobi、GS、SOR、CG 大规模、稀疏 ✓

    一句话抓住核心：选方法看矩阵的两个特征

    特征 决定
    规模与稀疏性 直接法 vs 迭代法
    条件数 需要多少位精度、是否要正则化

    决策表：

    矩阵 推荐
    \(n<10^{3}\)、稠密 LU（带选主元） ✓
    对称正定 Cholesky（快一倍）✓
    带状/稀疏 迭代法或稀疏 LU
    对称正定、超大 共轭梯度（CG） ✓
    非对称、超大 GMRES 等 Krylov 方法
    病态 加正则或用 QR/SVD

    本页按「直接法 → 迭代法 → CG 与最小二乘」的顺序展开。

    一、高斯消元与 LU 分解¶

    1.1 高斯消元¶

    基本操作（第 \(k\) 步）：

    \[ \text{第 }i\text{ 行}\leftarrow\text{第 }i\text{ 行}-m_{ik}\times\text{第 }k\text{ 行},\qquad m_{ik} = \frac{a_{ik}}{a_{kk}} \]

    \(m_{ik}\) 称为「乘数」。

    消元完成后得到上三角矩阵 \(U\)，再用回代求解。

    「乘数的绝对值应 ≤1」——这是选主元的理由

    先看一个反例（不选主元）：

    \[ \begin{bmatrix}10^{-8} & 1\\ 1 & 1\end{bmatrix}\begin{bmatrix}x_1\\ x_2\end{bmatrix} = \begin{bmatrix}1\\ 2\end{bmatrix} \]

    真解：\(x_1\approx1\)、\(x_2\approx1\)

    乘数：

    \[ m_{21} = \frac{1}{10^{-8}} = 10^{8} \]

    消元后：

    \[ \begin{bmatrix}10^{-8} & 1\\ 0 & 1-10^{8}\end{bmatrix}\begin{bmatrix}x_1\\ x_2\end{bmatrix} = \begin{bmatrix}1\\ 2-10^{8}\end{bmatrix} \]

    问题：\(10^{-8}\) 在浮点中被 \(10^{8}\) 完全淹没 ✗

    回代得到 \(x_2\approx1\)，但 \(x_1\) 会完全错误（因为 \(10^{-8}x_1+1\approx1\)， 无法从中解出 \(x_1\)）✗

    若交换两行（选主元）：

    \[ \begin{bmatrix}1 & 1\\ 10^{-8} & 1\end{bmatrix}\begin{bmatrix}x_1\\ x_2\end{bmatrix} = \begin{bmatrix}2\\ 1\end{bmatrix} \]

    乘数 \(m_{21} = 10^{-8}\)（小）

    消元后：

    \[ \begin{bmatrix}1 & 1\\ 0 & 1-10^{-8}\end{bmatrix} \]

    这个矩阵良态，解准确

    结论：选主元是为了让乘数 ≤1，避免放大误差

    判据（部分选主元）：

    \[ \text{在第 }k\text{ 列，把 }|a_{ik}|\text{ 最大的行换到第 }k\text{ 行} \]

    1.2 LU 分解¶

    若不做行交换，消元过程可写成

    \[ A = LU \]

    其中 \(L\) 是单位下三角（对角元为 1，下三角是乘数）。

    若做了行交换：

    \[ PA = LU \]

    \(P\) 是置换矩阵。

    LU 分解的实用价值：一次分解，多次求解

    优点：分解只做一次，之后每个新右端只需 \(O(n^{2})\)（回代）。

    对比：

    做法 每解一次的成本
    重新高斯消元 \(O(n^{3})\) ✗
    LU 分解 + 两次回代 \(O(n^{2})\) ✓

    典型场景（需要多次求解同一个 \(A\)）：

    场景 右端个数
    瞬态仿真的每步 \(10^{3}\)–\(10^{6}\)
    灵敏度分析 \(n\) 个
    单位脉冲响应 \(n\) 个（即求 \(A^{-1}\)）

    \(n = 1000\) 时的对比：

    做法 总运算量
    每次重新消元（\(1000\) 个右端） \(10^{3}\times10^{9} = 10^{12}\) ✗
    LU 一次 + 回代 \(10^{9}+10^{3}\times10^{6} = 2\times10^{9}\) ✓

    快了 500 倍

    工程含义：求解器接口的设计应该支持「先分解、后多次求解」

    （这就是为什么 LAPACK 把 getrf（分解）和 getrs（求解） 分成两个函数。）

    1.3 复杂度与 Cholesky¶

    方法 复杂度 适用
    高斯消元 / LU \(\frac{2}{3}n^{3}+O(n^{2})\) 一般方阵
    Cholesky \(\frac{1}{3}n^{3}+O(n^{2})\) 对称正定 ✓
    追赶法（三对角） \(O(n)\) 三对角 ✓

    Cholesky 分解（\(A\) 对称正定）：

    \[ A = LL^{T} \]

    其中 \(L\) 是下三角（对角元为正）。

    计算格式：

    \[ l_{jj} = \sqrt{a_{jj}-\sum_{k<j}l_{jk}^{2}} \]
    \[ l_{ij} = \frac{1}{l_{jj}}\left(a_{ij}-\sum_{k<j}l_{ik}l_{jk}\right)\quad(i>j) \]

    Cholesky 相对 LU 的三个优势

    优势 说明
    快一倍 \(\frac13n^{3}\) vs \(\frac23n^{3}\) ✓
    存储减半 只需存一个三角 ✓
    不需要选主元 正定性保证数值稳定 ✓

    第三个优势最实用：省掉了选主元的逻辑与数据移动

    但有一个前提：\(A\) 必须对称正定。

    「对称正定」在实践中能否保证：

    场景 是否 SPD
    有限元的刚度矩阵（无约束） ✓
    最小二乘的 \(A^{T}A\) ✓（但条件数已平方 ✗）
    协方差矩阵 ✓
    图拉普拉斯矩阵 ✓（半正定）
    一般的雅可比矩阵 ✗

    判断方法：

    方法 说明
    理论分析 如「能量正定」⟹ SPD
    试做 Cholesky 若开根号遇到负数，则不是 SPD ✓
    检查特征值 最可靠但昂贵

    实用技巧：直接尝试 Cholesky 分解 —— 它是最快的 SPD 检测器

    若分解失败（根号内为负）：

    原因 处理
    矩阵确实非正定 换用 LU ✓
    数值上失去正定性（条件数差） 加小对角项（\(A+\lambda I\)）✓
    数据错误 检查输入

    「加小对角项」的数学含义：这是岭正则化

    \[ A+\lambda I\ \text{（SPD，条件数改善）} \]

    这与「线性代数」模块的矩阵分解一页的结论一致

    二、经典迭代法¶

    2.1 为什么需要迭代法¶

    直接法的瓶颈：

    问题 说明
    复杂度 \(O(n^{3})\) \(n = 10^{6}\) 时 \(10^{18}\)，不可行 ✗
    存储 \(O(n^{2})\) \(10^{6}\) 阶稠密阵要 \(10^{12}\) 个数 ✗
    填充（fill-in） 稀疏矩阵消元后变稠密 ⚠

    迭代法的优势：

    优势 说明
    每步只需矩阵-向量乘 \(O(\text{nnz})\) ✓
    存储只需非零元 稀疏友好 ✓
    可以「提前停止」 得到近似解就够时省时 ✓

    2.2 三种经典迭代格式¶

    把 \(A\) 分解为：

    \[ A = D+L+U \]

    （对角、严格下三角、严格上三角。）

    方法 迭代式 特点
    Jacobi \(\boldsymbol{x}^{(k+1)} = D^{-1}(\boldsymbol{b}-(L+U)\boldsymbol{x}^{(k)})\) 完全并行 ✓
    Gauss-Seidel \(\boldsymbol{x}^{(k+1)} = (D+L)^{-1}(\boldsymbol{b}-U\boldsymbol{x}^{(k)})\) 串行，但收敛快一倍
    SOR 在 GS 上加松弛因子 \(\omega\) 可调优 ✓

    Jacobi 的分量形式（最直观）：

    \[ x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i-\sum_{j\neq i}a_{ij}x_j^{(k)}\right) \]

    含义：用「其他分量的旧值」更新第 \(i\) 个分量

    Gauss-Seidel 的区别：立即使用刚算出的新值 ✓

    \[ x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i-\sum_{j<i}a_{ij}x_j^{(k+1)}-\sum_{j>i}a_{ij}x_j^{(k)}\right) \]

    为什么 Gauss-Seidel 比 Jacobi 快一倍

    对「相容次序」的矩阵（如三对角），有精确关系：

    \[ \rho_{\text{GS}} = \rho_{\text{Jacobi}}^{2} \]

    含义：误差衰减速率是 Jacobi 的平方

    具体数值（\(\rho_J = 0.5\) 时）：

    方法 收敛因子 每步误差
    Jacobi \(0.5\) 减半
    Gauss-Seidel \(0.25\) 降到 ¼ ✓

    所以迭代次数约减半

    为什么更快（直观）：

    GS 用「更新的信息」 —— 计算 \(x_2\) 时已经用上了新的 \(x_1\) 而 Jacobi 还在用旧的 \(x_1\)。

    代价：GS 是串行的（必须按顺序算）， 并行性差 ✗

    所以并行计算中 Jacobi 反而更受欢迎（如 GPU 上的多重网格）

    SOR 的引入：

    \[ x_i^{(k+1)} = (1-\omega)x_i^{(k)}+\omega x_i^{\text{GS}} \]
    \(\omega\) 名称 效果
    \(\omega = 1\) 就是 GS ——
    \(0<\omega<1\) 欠松弛 更稳但更慢
    \(1<\omega<2\) 超松弛 可以显著加速 ✓
    \(\omega\geq2\) 发散 ✗

    最优 \(\omega\)（对三对角矩阵，已知 \(\rho_J\)）：

    \[ \omega_{\text{opt}} = \frac{2}{1+\sqrt{1-\rho_J^{2}}} \]

    此时：

    \[ \rho_{\text{SOR}} = \omega_{\text{opt}}-1 \]

    这个公式的威力（\(n\) 很大时）：

    \(n\) \(\rho_J\) \(\rho_{\text{GS}}\) \(\rho_{\text{SOR}}\)
    \(10\) \(0.9595\) \(0.9206\) \(0.5604\)
    \(20\) \(0.9888\) \(0.9778\) \(0.7406\)
    \(100\) \(0.9995163\) \(0.9990328\) \(0.9396763\)

    迭代次数（要把误差降 \(10^{-6}\)）：

    \(n\) Jacobi Gauss-Seidel SOR
    \(10\) \(334\) \(167\) \(24\)
    \(20\) \(1230\) \(615\) \(46\)
    \(100\) \(28554\) \(14277\) \(222\)

    结论（重要）：

    方法 迭代次数随 \(n\) 的增长
    Jacobi \(O(n^{2})\) ✗
    Gauss-Seidel \(O(n^{2})\) ✗
    SOR（最优 \(\omega\)） \(O(n)\) ✓

    这就是「SOR 在高分辨率问题上有巨大优势」的原因

    注意「最优 \(\omega\) 需要知道 \(\rho_J\)」：

    实践中常用自适应估计（用迭代过程中的信息估计）， 或试几个 \(\omega\) 看哪个收敛快

    2.3 收敛条件¶

    迭代法收敛的三个充分条件（必须知道）

    条件 1：严格对角占优 ⟹ 收敛

    \[ \lvert a_{ii}\rvert>\sum_{j\neq i}\lvert a_{ij}\rvert\quad\forall i \]

    这是最容易检验的条件

    条件 2：对称正定 ⟹ Gauss-Seidel 收敛 （Jacobi 不一定。）

    条件 3：\(\rho(\text{迭代矩阵})<1\)（充要条件）

    数值经验（工程实用判据）：

    观察 结论
    残差单调下降 大概收敛 ✓
    残差震荡或上升 发散，必须换方法 ✗
    收敛极慢 条件数差，考虑预处理 ✓

    对角占优的直观理解：

    若对角线元素占主导，则「以对角线解出的新值」接近真解 ✓ （因为方程主要由 \(a_{ii}x_i\) 决定。）

    反例（不收敛的情形）：

    \[ A = \begin{bmatrix}1 & 2\\ 2 & 1\end{bmatrix} \]

    对角不占优（\(1<2\)）✗

    Jacobi 迭代矩阵：

    \[ B_J = D^{-1}(L+U) = \begin{bmatrix}0 & -2\\ -2 & 0\end{bmatrix} \]

    特征值 \(\pm2\) → \(\rho = 2>1\) → 发散 ✗

    工程含义：求解前应检查（或至少观察）对角占优性

    若不占优怎么办：

    手段 说明
    重新排序未知量 可让对角占优 ✓
    预处理 乘一个「近似逆」 ✓
    换直接法 若规模允许 ✓

    三、共轭梯度与最小二乘¶

    3.1 共轭梯度（CG）¶

    适用：\(A\) 对称正定。

    核心思想：在「\(A\)-共轭」的方向上依次求极小，\(n\) 步内精确收敛 ✓

    算法（最简洁的形式）：

    步骤 公式
    初始化 \(\boldsymbol{r}_0 = \boldsymbol{b}-A\boldsymbol{x}_0\)，\(\boldsymbol{p}_0 = \boldsymbol{r}_0\)
    步长 \(\alpha_k = \dfrac{\boldsymbol{r}_k^{T}\boldsymbol{r}_k}{\boldsymbol{p}_k^{T}A\boldsymbol{p}_k}\)
    更新解 \(\boldsymbol{x}_{k+1} = \boldsymbol{x}_k+\alpha_k\boldsymbol{p}_k\)
    更新残差 \(\boldsymbol{r}_{k+1} = \boldsymbol{r}_k-\alpha_kA\boldsymbol{p}_k\)
    更新方向 \(\beta_k = \dfrac{\boldsymbol{r}_{k+1}^{T}\boldsymbol{r}_{k+1}}{\boldsymbol{r}_k^{T}\boldsymbol{r}_k}\)，\(\boldsymbol{p}_{k+1} = \boldsymbol{r}_{k+1}+\beta_k\boldsymbol{p}_k\)

    CG 相比「最速下降」的关键改进

    方法 每步的方向 收敛
    最速下降 沿残差（当前最陡） 可能反复震荡 ✗
    CG 沿「\(A\)-共轭」方向 不重复走同一方向 ✓

    「\(A\)-共轭」的定义：

    \[ \boldsymbol{p}_i^{T}A\boldsymbol{p}_j = 0\quad(i\neq j) \]

    含义：在一个方向上求极小时，不影响之前方向的极小性

    这带来两个理论结论：

    结论 说明
    \(n\) 步内精确收敛 （在精确算术下）✓
    误差按 \(\left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^{k}\) 衰减 与梯度下降同形

    注意「\(n\) 步精确收敛」在实际中不成立 —— 因为舍入误差破坏了共轭性 ✗

    但 CG 的实用价值在于「远小于 \(n\) 步就足够准」

    与「梯度下降」页的联系：CG 的收敛因子形式与上一层的 「梯度下降在二次函数上的收敛速率」完全一致

    3.2 预处理：改善条件数¶

    问题：若 \(\kappa(A)\) 很大，CG 仍需要很多步 ✗

    解决：用「预处理矩阵」\(M\approx A\) 把问题变成 \(M^{-1}A\)。

    效果：

    \[ \kappa(M^{-1}A)\ll\kappa(A)\implies\text{迭代次数大幅下降} \]

    常见的预处理：

    预处理 说明
    对角（Jacobi） \(M = \operatorname{diag}(A)\)，最便宜 ✓
    不完全 Cholesky（IC） 稀疏近似
    多重网格 最优（\(O(n)\)）但复杂
    块预处理 分块对角

    「预处理」的本质就是「改善条件数」

    这与本知识库反复出现的主题一致：

    层次 手段 效果
    梯度下降 数据标准化 降低 \(\kappa\) ✓
    岭回归 加 \(\lambda I\) 降低 \(\kappa\) ✓
    CG 预处理 降低 \(\kappa\) ✓
    迭代法 重新排序 让对角占优 ✓

    统一的认识：数值方法的收敛速度由条件数控制

    这解释了三件事：

    现象 原因
    深度学习为何需要归一化 降低条件数
    为何病态矩阵难解 条件数大
    为何预处理值得投入 直接降低迭代次数

    实用建议：对角预处理几乎「免费」（只需存储对角元）， 应作为默认选择

    3.3 最小二乘与 QR¶

    问题（超定方程组 \(A\boldsymbol{x}\approx\boldsymbol{b}\)，\(A\) 是 \(m\times n\)、\(m>n\)）：

    \[ \min_{\boldsymbol{x}}\lVert A\boldsymbol{x}-\boldsymbol{b}\rVert_2 \]

    正规方程解：

    \[ A^{T}A\boldsymbol{x} = A^{T}\boldsymbol{b} \]

    但条件数被平方（回顾「浮点数与误差」一页的警告）✗

    「用 QR 而不是正规方程」的量化理由

    方法 需要解的系统 条件数
    正规方程 \(A^{T}A\boldsymbol{x} = A^{T}\boldsymbol{b}\) \(\kappa(A)^{2}\) ✗
    QR \(R\boldsymbol{x} = Q^{T}\boldsymbol{b}\) \(\kappa(A)\) ✓

    QR 的做法：把 \(A\) 分解为

    \[ A = Q\begin{bmatrix}R\\ 0\end{bmatrix} \]

    （\(Q\) 是 \(m\times m\) 正交矩阵，\(R\) 是 \(n\times n\) 上三角。）

    最小二乘解满足：

    \[ R\boldsymbol{x} = (Q^{T}\boldsymbol{b})_{1:n} \]

    只需回代

    为什么条件数不平方：

    正交变换保持 2-范数（\(\lVert Q\boldsymbol{v}\rVert = \lVert\boldsymbol{v}\rVert\)）

    所以 \(\kappa(A) = \kappa(R)\) —— 不放大

    QR 的两种实现：

    方法 稳定性 成本
    Gram-Schmidt（经典） 差（正交性会丢失）✗ 低
    改进 Gram-Schmidt（MGS） 较好 ✓ 低
    Householder 最好 ✓ 约 2 倍

    工程建议：用 Householder 或改进 GS； 绝不手工实现经典 GS

    （numpy.linalg.qr 与 LAPACK 用的都是 Householder。）

    三种最小二乘方法的完整对比：

    方法 条件数 成本 秩亏 推荐
    正规方程 \(\kappa^{2}\) ✗ 最低 ✗ 仅当 \(\kappa\) 很小
    QR \(\kappa\) ✓ 中 ⚠ 一般首选 ✓
    SVD \(\kappa\) ✓ 高 ✓ 可处理 病态/秩亏 ✓

    「秩亏」的含义：\(A\) 的列线性相关 → 解不唯一 ✗

    SVD 的优势：

    \[ A = U\Sigma V^{T}\implies\boldsymbol{x} = V\Sigma^{+}U^{T}\boldsymbol{b} \]

    其中 \(\Sigma^{+}\) 是「把小的奇异值置零后的倒数」——

    这给出「最小范数解」，且可以显式控制截断

    思路

    逐列用公式 \(l_{jj} = \sqrt{a_{jj}-\sum_{k\lt j}l_{jk}^{2}}\)、 \(l_{ij} = \frac{1}{l_{jj}}\left(a_{ij}-\sum_{k\lt j}l_{ik}l_{jk}\right)\)。

    \[ l_{32} = \frac{a_{32}-l_{31}l_{21}}{l_{22}} = \frac{-43-(-8)(6)}{1} = \frac{-43+48}{1} = 5 \]

    第三步：第 3 列

    \[ l_{33} = \sqrt{a_{33}-l_{31}^{2}-l_{32}^{2}} = \sqrt{98-64-25} = \sqrt9 = 3 \]

    第四步：结果

    \[ L = \begin{bmatrix}2 & 0 & 0\\ 6 & 1 & 0\\ -8 & 5 & 3\end{bmatrix} \]

    第五步：验证 \(LL^{T} = A\)

    位置 计算 结果
    \((1,1)\) \(2^{2}\) \(4\) ✓
    \((1,2)\) \(2\times6\) \(12\) ✓
    \((1,3)\) \(2\times(-8)\) \(-16\) ✓
    \((2,2)\) \(6^{2}+1^{2}\) \(37\) ✓
    \((2,3)\) \(6(-8)+1\cdot5\) \(-48+5 = -43\) ✓
    \((3,3)\) \((-8)^{2}+5^{2}+3^{2}\) \(64+25+9 = 98\) ✓

    全部吻合

    顺带得到行列式：

    \[ \det(A) = \det(L)^{2} = (2\times1\times3)^{2} = 36 \]

    例题 3：Jacobi 与 Gauss-Seidel 的收敛速率¶

    对三对角矩阵

    \[ A = \begin{bmatrix}4 & -1 & 0\\ -1 & 4 & -1\\ 0 & -1 & 4\end{bmatrix} \]

    求两种迭代法的谱半径、收敛速度与所需迭代数。

    思路

    先求 Jacobi 迭代矩阵的特征值，再用 \(\rho_{\text{GS}} = \rho_J^{2}\)。

    解答

    第一步：Jacobi 迭代矩阵

    \[ B_J = D^{-1}(L+U) = \frac14\begin{bmatrix}0 & 1 & 0\\ 1 & 0 & 1\\ 0 & 1 & 0\end{bmatrix} \]

    第二步：求特征值

    令 \(\lambda\) 是 \(\frac14M\) 的特征值（\(M\) 是上面那个矩阵）， 即 \(M\) 的特征值除以 4。

    \(M\) 的特征多项式：

    \[ \det(M-\mu I) = \det\begin{bmatrix}-\mu & 1 & 0\\ 1 & -\mu & 1\\ 0 & 1 & -\mu\end{bmatrix} = -\mu^{3}+2\mu \]

    （按第一行展开可得。）

    解 \(-\mu^{3}+2\mu = 0\)：

    \[ \mu(\mu^{2}-2) = 0\implies\mu = 0,\ \pm\sqrt2 \]

    所以：

    \[ \rho(B_J) = \frac{\sqrt2}{4}\approx0.353553 \]

    第三步：Gauss-Seidel 的谱半径

    对相容次序矩阵（三对角满足）：

    \[ \rho_{\text{GS}} = \rho_J^{2} = \frac{2}{16} = 0.125 \]

    第四步：收敛速度对比

    要把误差降低 \(10^{-6}\)，所需迭代数：

    \[ k\approx\frac{\ln(10^{-6})}{\ln\rho} = \frac{-13.8155}{\ln\rho} \]
    方法 \(\rho\) \(\ln\rho\) \(k\)
    Jacobi \(0.353553\) \(-1.0397\) \(13.3\to14\)
    Gauss-Seidel \(0.125\) \(-2.0794\) \(6.64\to7\)

    Gauss-Seidel 只需约一半的迭代次数

    第五步：SOR 的进一步提升

    最优松弛因子：

    \[ \omega_{\text{opt}} = \frac{2}{1+\sqrt{1-\rho_J^{2}}} = \frac{2}{1+\sqrt{1-0.125}} = \frac{2}{1+0.935414} = 1.0333705 \]
    \[ \rho_{\text{SOR}} = \omega_{\text{opt}}-1 = 0.0333705 \]

    所需迭代数：

    \[ k = \frac{13.8155}{3.3998}\approx4.06\to5 \]

    结果汇总：

    方法 \(\rho\) 迭代数
    Jacobi \(0.353553\) \(14\)
    Gauss-Seidel \(0.125000\) \(7\)
    SOR（\(\omega_{\text{opt}}\)） \(0.033370\) \(5\)

    「n 小的时候 SOR 的优势不明显」——但 n 大时是决定性的

    \(n = 3\) 时：Z 从 14 降到 5（约 3 倍），不算惊人。

    但把 \(n\) 增大（对 \(n\times n\) 的三对角矩阵，\(\rho_J = \cos\frac{\pi}{n+1}\)）：

    \(n\) Jacobi GS SOR SOR 的加速比
    \(10\) \(334\) \(167\) \(24\) \(14\times\)
    \(20\) \(1230\) \(615\) \(46\) \(27\times\)
    \(50\) \(7918\) \(3959\) \(105\) \(75\times\)
    \(100\) \(28554\) \(14277\) \(222\) \(129\times\) ✓

    加速比随 \(n\) 增长

    原因是三种方法的「复杂度阶」不同：

    方法 迭代次数随 \(n\)
    Jacobi \(O(n^{2})\) ✗
    Gauss-Seidel \(O(n^{2})\) ✗
    SOR \(O(n)\) ✓

    所以 \(n\) 越大，SOR 越相对有优势

    工程选择的实际建议：

    场景 方法
    \(n\) 小（\(<10^{2}\)） 直接用直接法（LU） ✓
    稀疏、\(n\) 中（\(10^{2}\)–\(10^{4}\)） SOR 或 CG
    稀疏、\(n\) 大（\(>10^{4}\)） 预处理 CG 或多重网格 ✓
    需要极高精度 迭代法改善后转直接法

    最后一行值得说明：实践中常用「迭代法热身 + 直接法收尾」 —— 迭代法快速降低误差，直接法处理剩余的小规模问题 （这就是「混合方法」的思想。）

    例题 4：共轭梯度的手算与 QR 最小二乘¶

    (a) 用 CG 解 \(A\boldsymbol{x} = \boldsymbol{b}\)，其中 \(A = \begin{bmatrix}4 & 1\\ 1 & 3\end{bmatrix}\)、\(\boldsymbol{b} = (1,2)^{\top}\)。

    (b) 用 QR 对数据 \((1,6),(2,5),(3,7),(4,10)\) 做最小二乘直线拟合。

    思路

    (a) 按 CG 的五步公式逐步算（\(n=2\) 应两步收敛）。 (b) 用改进 Gram-Schmidt 求 \(Q\)、\(R\)。

    解答

    (a) 共轭梯度

    真解（用于验证）：\(\det A = 12-1 = 11\)，

    \[ A^{-1} = \frac{1}{11}\begin{bmatrix}3 & -1\\ -1 & 4\end{bmatrix} \implies \boldsymbol{x}^{*} = \frac{1}{11}\begin{bmatrix}3\times1-1\times2\\ -1\times1+4\times2\end{bmatrix} = \frac{1}{11}\begin{bmatrix}1\\ 7\end{bmatrix} = (0.0909,\ 0.6364)^{\top} \]

    初始化：

    \[ \boldsymbol{x}_0 = (0,0)^{\top},\quad \boldsymbol{r}_0 = \boldsymbol{b} = (1,2)^{\top},\quad \boldsymbol{p}_0 = \boldsymbol{r}_0 \]

    第一次迭代：

    \[ A\boldsymbol{p}_0 = \begin{bmatrix}4\times1+1\times2\\ 1\times1+3\times2\end{bmatrix} = (6,7)^{\top} \]
    \[ \alpha_0 = \frac{\boldsymbol{r}_0^{T}\boldsymbol{r}_0}{\boldsymbol{p}_0^{T}A\boldsymbol{p}_0} = \frac{1+4}{6+14} = \frac{5}{20} = 0.25 \]
    \[ \boldsymbol{x}_1 = 0+0.25(1,2)^{\top} = (0.25,\ 0.5)^{\top} \]
    \[ \boldsymbol{r}_1 = (1,2)^{\top}-0.25(6,7)^{\top} = (1-1.5,\ 2-1.75)^{\top} = (-0.5,\ 0.25)^{\top} \]

    第二次迭代：

    \[ \beta_0 = \frac{\boldsymbol{r}_1^{T}\boldsymbol{r}_1}{\boldsymbol{r}_0^{T}\boldsymbol{r}_0} = \frac{0.25+0.0625}{5} = \frac{0.3125}{5} = 0.0625 \]
    \[ \boldsymbol{p}_1 = (-0.5,0.25)^{\top}+0.0625(1,2)^{\top} = (-0.4375,\ 0.375)^{\top} \]
    \[ A\boldsymbol{p}_1 = \begin{bmatrix}4(-0.4375)+0.375\\ -0.4375+3(0.375)\end{bmatrix} = (-1.375,\ 0.6875)^{\top} \]
    \[ \alpha_1 = \frac{0.3125}{(-0.4375)(-1.375)+(0.375)(0.6875)} = \frac{0.3125}{0.601563+0.257813} = \frac{0.3125}{0.859375} = \frac{4}{11} \]
    \[ \boldsymbol{x}_2 = (0.25,0.5)^{\top}+\frac{4}{11}(-0.4375,0.375)^{\top} = (0.25-0.159091,\ 0.5+0.136364)^{\top} \]
    \[ = (0.090909,\ 0.636364)^{\top} \;\checkmark \]

    与真解完全一致

    第二步就收敛（因为 \(n = 2\)）

    (b) QR 最小二乘

    设计矩阵与右端：

    \[ A = \begin{bmatrix}1 & 1\\ 1 & 2\\ 1 & 3\\ 1 & 4\end{bmatrix},\qquad \boldsymbol{b} = (6,5,7,10)^{\top} \]

    第 1 列的正交化：

    \[ \boldsymbol{a}_1 = (1,1,1,1)^{\top},\qquad\lVert\boldsymbol{a}_1\rVert = 2 \]
    \[ \boldsymbol{q}_1 = (0.5,0.5,0.5,0.5)^{\top},\qquad r_{11} = 2 \]

    第 2 列：

    \[ \boldsymbol{a}_2 = (1,2,3,4)^{\top},\qquad r_{12} = \boldsymbol{q}_1^{T}\boldsymbol{a}_2 = 0.5(1+2+3+4) = 5 \]
    \[ \boldsymbol{v} = \boldsymbol{a}_2-r_{12}\boldsymbol{q}_1 = (1,2,3,4)^{\top}-5(0.5,\ldots)^{\top} = (-1.5,-0.5,0.5,1.5)^{\top} \]
    \[ r_{22} = \lVert\boldsymbol{v}\rVert = \sqrt{2.25+0.25+0.25+2.25} = \sqrt5 \]
    \[ \boldsymbol{q}_2 = \frac{1}{\sqrt5}(-1.5,-0.5,0.5,1.5)^{\top} \]

    投影右端：

    \[ \boldsymbol{q}_1^{T}\boldsymbol{b} = 0.5(6+5+7+10) = 14 \]
    \[ \boldsymbol{q}_2^{T}\boldsymbol{b} = \frac{-1.5(6)-0.5(5)+0.5(7)+1.5(10)}{\sqrt5} = \frac{-9-2.5+3.5+15}{\sqrt5} = \frac{7}{\sqrt5} \]

    解 \(R\boldsymbol{x} = Q^{T}\boldsymbol{b}\)：

    \[ \begin{bmatrix}2 & 5\\ 0 & \sqrt5\end{bmatrix}\begin{bmatrix}a_0\\ a_1\end{bmatrix} = \begin{bmatrix}14\\ 7/\sqrt5\end{bmatrix} \]

    回代：

    \[ \sqrt5\,a_1 = \frac{7}{\sqrt5}\implies a_1 = \frac75 = 1.4 \]
    \[ 2a_0+5(1.4) = 14\implies2a_0 = 7\implies a_0 = 3.5 \]

    结果：

    \[ \hat y = 3.5+1.4x \]

    验证残差：

    \(x\) \(y\) \(\hat y\) 残差 残差²
    \(1\) \(6\) \(4.9\) \(1.1\) \(1.21\)
    \(2\) \(5\) \(6.3\) \(-1.3\) \(1.69\)
    \(3\) \(7\) \(7.7\) \(-0.7\) \(0.49\)
    \(4\) \(10\) \(9.1\) \(0.9\) \(0.81\)
    和 \(4.20\)

    残差之和：\(1.1-1.3-0.7+0.9 = 0\) ✓（有截距时的必然性质。）

    残差平方和 RSS \(= 4.20\)

    用 \(Q\) 验证：

    \[ \lVert\boldsymbol{b}\rVert^{2} = 36+25+49+100 = 210 \]
    \[ \lVert Q^{T}\boldsymbol{b}\rVert^{2} = 14^{2}+\frac{49}{5} = 196+9.8 = 205.8 \]
    \[ \text{RSS} = 210-205.8 = 4.2 \;\checkmark \]

    从 (b) 看「为什么 QR 比正规方程好」

    正规方程的条件数：

    \[ A^{T}A = \begin{bmatrix}4 & 10\\ 10 & 30\end{bmatrix} \]

    其特征值：

    \[ \lambda = \frac{34\pm\sqrt{1156-80}}{2} = \frac{34\pm32.8024}{2}\implies33.401,\ 0.599 \]
    \[ \kappa(A^{T}A) = \frac{33.401}{0.599}\approx55.8 \]

    而 \(\kappa(A) = \sqrt{55.8}\approx7.5\)

    所以正规方程把条件数从 \(7.5\) 放大到 \(55.8\) ✗

    本例中 \(55.8\) 仍然很小（远小于 \(10^{16}\)）， 所以正规方程也能给出正确结果

    但若数据更病态：

    \(\kappa(A)\) \(\kappa(A^{T}A)\) 正规方程是否可用
    \(7.5\) \(56\) ✓ 可用
    \(10^{4}\) \(10^{8}\) ✓ 勉强
    \(10^{8}\) \(10^{16}\) ✗ 完全不可用

    工程结论：

    「用正规方程还是 QR」不应靠猜 —— 算一下 \(\kappa(A)\)（或直接用 lstsq）

    实际操作建议：

    场景 做法
    快速原型 np.linalg.lstsq（内部 SVD）✓
    需要速度且已知良态 正规方程
    需要显式控制 QR（Householder）
    秩亏 SVD + 截断

    注意「numpy.linalg.lstsq 默认用 gelsd（SVD）」 —— 它是最稳健的，代价是速度稍慢

    五、用在哪些课程里¶

    5.1 无人系统自主决策与优化 · 大规模稀疏求解¶

    • 轨迹优化的 KKT 系统是稀疏的 → 用稀疏 LU 或迭代法
    • 内点法的每步都要解一个大规模 KKT 系统
    • 模型预测控制（MPC）在线求解 QP → 分解可离线预计算
    • 条件数检查是判断「解是否可信」的第一手段

    5.2 机器人学 · 雅可比与逆运动学¶

    • 逆运动学的雅可比求解常在奇异位形附近病态
    • 阻尼最小二乘（DLS）用 \((J^{T}J+\lambda I)\) 改善条件数
    • SLAM 的图优化是超大稀疏最小二乘 → 用稀疏 Cholesky 或 CG
    • 刚体动力学的惯性矩阵对称正定 → Cholesky 最快

    5.3 智能传感与信息处理 · 滤波与标定¶

    • 卡尔曼滤波的协方差更新需要「保持正定性」→ 平方根滤波
    • 传感器标定是最小二乘问题 → 用 QR
    • 阵列信号处理的协方差矩阵是 SPD → Cholesky
    • 病态标定问题需正则化或增加激励

    六、自测¶

    Q1 判断：解 \(A\boldsymbol{x} = \boldsymbol{b}\) 时，只要用「选主元的高斯消元」， 结果就一定准确。

    提示

    条件数属于问题还是算法？

    解答

    不对。选主元只保证算法稳定，不能改善问题的条件数。

    两个层面的区分（回顾「浮点数与误差」一页）：

    层面 选主元的作用
    算法稳定性 ✓ 改善（不让误差被放大）
    问题的条件数 ✗ 完全不改变

    最终的误差界：

    \[ \text{相对误差}\lesssim\kappa(A)\times\epsilon_{\text{mach}} \]

    即使算法完美稳定（稳定性因子 \(=1\)）：

    \(\kappa(A)\) 最坏相对误差
    \(10^{4}\) \(10^{-12}\) ✓
    \(10^{8}\) \(10^{-8}\) ✓
    \(10^{12}\) \(10^{-4}\) ⚠
    \(10^{16}\) \(10^{0}\)（全错） ✗

    所以正确的做法是「先估条件数」：

    条件数 结论
    小（\(<10^{8}\)） 放心求解 ✓
    中（\(10^{8}\)–\(10^{12}\)） 知道有多少位可信 ⚠
    大（\(>10^{12}\)） 改问题（正则化/重新标定/改模型）✗

    「改问题」的具体手段：

    手段 效果
    岭正则化（\(A+\lambda I\)） 直接降低 \(\kappa\) ✓
    变量重新标定（相当于对角预处理） 降低 \(\kappa\) ✓
    换用更稳定的公式化 避免显式形成病态矩阵
    提高精度（四倍精度） 昂贵但有效 ⚠

    一个实用的自检流程：

    步骤 操作
    1 求解
    2 算残差 \(\lVert A\boldsymbol{x}-\boldsymbol{b}\rVert\)
    3 残差大 → 可能是条件数问题 ⚠
    4 算条件数估计
    5 若 \(\kappa\epsilon\gtrsim\) 需求精度 → 改问题 ✓

    注意「残差小不等于解准」（一个反直觉的事实）：

    因为 \(\boldsymbol{x}\) 的误差与残差的关系是

    \[ \frac{\lVert\Delta\boldsymbol{x}\rVert}{\lVert\boldsymbol{x}\rVert} \lesssim\kappa(A)\frac{\lVert\boldsymbol{r}\rVert}{\lVert\boldsymbol{b}\rVert} \]

    所以 \(\kappa\) 大时，「残差很小」也可能对应「解很错」 ✗

    这就是「必须看条件数，不能只看残差」的原因 ✓

    Q2 为什么 Cholesky 比 LU 快一倍，而且不需要选主元？

    提示

    对称性省了什么？正定性保证了什么？

    解答

    对称性省掉一半计算，正定性保证稳定性。

    快一倍的原因：对称性

    LU 要算两个三角因子（\(L\) 与 \(U\)，各约 \(n^{2}/2\) 个元素）； Cholesky 只算一个 \(L\)（因为 \(U = L^{T}\)）

    分解 运算量
    LU \(\frac23n^{3}\)
    Cholesky \(\frac13n^{3}\) ✓

    存储也减半

    不需要选主元的原因：正定性

    关键事实：对称正定矩阵的 Cholesky 分解一定存在， 且对角线元素 \(l_{jj}>0\)

    为什么稳定：

    正定性保证了「主元不会变小」 —— 即每一步的 \(l_{jj}^{2} = a_{jj}-\sum l_{jk}^{2}>0\) 且量级可控

    对比 LU 的情形：

    矩阵 是否需要选主元
    一般方阵 必需 ✗
    对称正定 不需要 ✓
    对称但不定 需要

    这在实际中的价值：

    方面 收益
    代码 无选主元逻辑，简单 ✓
    数据移动 无行交换 → 缓存友好 ✓
    并行 更容易并行化 ✓
    稀疏结构 选主元会破坏稀疏性 → 不选主元反而保持 ✓

    最后一行在稀疏情形特别重要：

    选主元会引入「填充」（fill-in），破坏稀疏性 ✗

    所以对稀疏 SPD 矩阵，Cholesky 是首选 （这就是为什么有限元的结构刚度矩阵都用 Cholesky。）

    判断 SPD 的实用方法：

    方法 说明
    试做 Cholesky 最快 ✓（根号内为负即失败）
    检查特征值 最可靠但最贵
    理论分析 如「能量泛函正定」✓

    若矩阵只是「半正定」（有零特征值，如图拉普拉斯）：

    情形 处理
    完全半正定 加 \(\lambda I\) 或用带主元的 LDL\(^{T}\)
    数值上接近奇异 加 jitter（\(\lambda\approx\epsilon\lVert A\rVert\)）✓
    有明确零空间（如约束） 分离出约束方向

    Q3 某三对角矩阵 \(n = 100\)，用 Jacobi 需要约 \(28500\) 次迭代才能 把误差降到 \(10^{-6}\)。用 SOR 呢？

    提示

    用 \(\rho_J = \cos\frac{\pi}{n+1}\) 和 SOR 的最优松弛公式。

    解答

    第一步：Jacobi 的谱半径

    对三对角矩阵（\(n\times n\)）：

    \[ \rho_J = \cos\frac{\pi}{n+1} \]
    \[ n = 100\implies\rho_J = \cos\frac{\pi}{101} = \cos(0.0311106)\approx0.99951628 \]

    第二步：SOR 的最优松弛因子

    \[ \omega_{\text{opt}} = \frac{2}{1+\sqrt{1-\rho_J^{2}}} \]

    计算：

    \[ \rho_J^{2}\approx0.99903280,\qquad1-\rho_J^{2}\approx0.00096720 \]
    \[ \sqrt{0.00096720}\approx0.0310995 \]
    \[ \omega_{\text{opt}} = \frac{2}{1.0310995}\approx1.9396763 \]

    第三步：SOR 的谱半径

    \[ \rho_{\text{SOR}} = \omega_{\text{opt}}-1\approx0.9396763 \]

    第四步：所需迭代数

    \[ k_{\text{SOR}} = \frac{\ln(10^{-6})}{\ln(0.93967)} = \frac{-13.8155}{-0.062227}\approx222 \]

    结果：约 \(222\) 次（Jacobi 是 \(28500\) 次）

    对比总结：

    方法 \(\rho\) 迭代数 相对 Jacobi
    Jacobi \(0.99951628\) \(28554\) \(1\times\)
    Gauss-Seidel \(0.99903280\) \(14277\) \(2\times\)
    SOR（最优 \(\omega\)） \(0.9396763\) \(222\) \(129\times\) ✓

    SOR 快了约 128 倍

    「这个数字背后的物理含义」

    为什么 SOR 的加速比这么大：

    方法 误差衰减模式
    Jacobi / GS 「低频」误差分量衰减极慢 ✗
    SOR 最优 \(\omega\) 同时压制高低频 ✓

    更具体地：Jacobi 的误差可分解为不同频率的本征模式， 最慢的模式就是最低频的（波长 \(\sim n\)）—— 它的衰减因子 \(\cos\frac{\pi}{n+1}\approx1-\frac{\pi^{2}}{2n^{2}}\)， 所以需要 \(O(n^{2})\) 步 ✗

    SOR 最优 \(\omega\) 把最慢的因子压到 \(1-\frac{2\pi}{n}\) → 需要 \(O(n)\) 步

    注意「迭代次数的阶」：

    方法 迭代次数 每步成本 总成本
    Jacobi \(O(n^{2})\) \(O(n)\) \(O(n^{3})\) ✗
    GS \(O(n^{2})\) \(O(n)\) \(O(n^{3})\) ✗
    SOR \(O(n)\) \(O(n)\) \(O(n^{2})\) ✓

    所以 SOR 的总成本与「三对角直接法（追赶法）」同阶

    但两者有本质区别：

    方法 稀疏性 三维扩展
    追赶法（直接） 仅三对角 填充严重 ✗
    SOR 任意稀疏 可用 ✓

    这就是「为什么实际中大量用迭代法」 —— 在三维/高阶稀疏问题时，直接法的填充会摧毁优势

    进一步的武器：

    方法 复杂度
    SOR \(O(n^{2})\)
    预处理 CG 通常 \(O(n^{1.5})\) 或更好 ✓
    多重网格 \(O(n)\)（最优） ✓

    「多重网格是最优的」 —— 它的收敛率与网格尺寸无关，这是目前最好的结果

    Q4 为什么最小二乘不要用正规方程？

    提示

    \(\kappa(A^{T}A) = \kappa(A)^{2}\)。

    解答

    因为正规方程把条件数平方，使本来可解的问题变得不可解。

    正规方程：

    \[ A^{T}A\boldsymbol{x} = A^{T}\boldsymbol{b} \]

    条件数关系：

    \[ \kappa(A^{T}A) = \kappa(A)^{2} \]

    量化后果：

    \(\kappa(A)\) \(\kappa(A^{T}A)\) 双精度下可信位数
    \(10^{3}\) \(10^{6}\) \(10\) ✓
    \(10^{6}\) \(10^{12}\) \(4\) ⚠
    \(10^{8}\) \(10^{16}\) \(0\)（全错） ✗

    具体例子（希尔伯特矩阵）：

    \(n\) \(\kappa(H_n)\) \(\kappa(H_n^{T}H_n)\)
    \(4\) \(1.5\times10^{4}\) \(2.3\times10^{8}\)
    \(8\) \(1.5\times10^{10}\) \(2.3\times10^{20}\) ✗
    \(12\) \(1.8\times10^{16}\) 溢出 ✗

    \(n = 8\) 时正规方程已完全失效，而 \(\kappa(H_8) = 10^{10}\) 本身 在双精度下勉强还能用（约 6 位有效数字）

    替代方案：

    方法 条件数 成本 秩亏处理
    正规方程 \(\kappa^{2}\) ✗ 最低 ✗
    QR \(\kappa\) ✓ 约 2 倍 ⚠
    SVD \(\kappa\) ✓ 约 5–10 倍 ✓ 最佳

    为什么 QR/SVD 不平方：

    它们用正交变换，而正交变换保持 2-范数

    \[ \lVert Q\boldsymbol{v}\rVert_2 = \lVert\boldsymbol{v}\rVert_2\implies\kappa(A) = \kappa(R) \]

    所以 QR 保持了原问题的条件数

    实际建议（可直接照做）：

    场景 做法
    不确定 np.linalg.lstsq（默认 SVD）✓
    已知良态、追求速度 正规方程（但要检查 \(\kappa\)）
    大规模稀疏 LSQR 或正则化 ✓
    需要 Tikhonov 正则 增广矩阵 \(\begin{bmatrix}A\\ \sqrt\lambda I\end{bmatrix}\) ✓

    最后一行值得展开：

    Tikhonov 正则化可以转化为一个「更大的、但良态的最小二乘问题」

    \[ \min\lVert A\boldsymbol{x}-\boldsymbol{b}\rVert^{2}+\lambda\lVert\boldsymbol{x}\rVert^{2} \iff \min\left\lVert\begin{bmatrix}A\\ \sqrt\lambda I\end{bmatrix}\boldsymbol{x}-\begin{bmatrix}\boldsymbol{b}\\ \boldsymbol{0}\end{bmatrix}\right\rVert^{2} \]

    这样就能用标准的 QR/SVD 求解器 而且正则化降低了条件数

    工程实践提醒：

    检查 说明
    始终检查条件数 它是「可信位数」的判据 ✓
    残差小不代表解准 \(\kappa\) 大时两者无关 ✗
    优先用库函数 它们已处理这些陷阱 ✓

    「优先用库函数」的理由：

    LAPACK/NumPy 的实现考虑了选主元、缩放、迭代改善等细节 —— 自己实现很容易漏掉关键步骤 ✗
