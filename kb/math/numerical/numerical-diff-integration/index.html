    数值微分与积分¶

    解析求导与积分在很多工程问题中做不到：

    情形 为什么
    只有测量数据（无解析表达式） 无法求导 ✓
    函数通过黑箱程序计算 无法符号求导
    被积函数没有初等原函数 如 \(e^{-x^{2}}\) ✗
    高维积分 解析方法完全不可行 ✗

    这一页讲数值方法，以及一个共同的规律：

    精度阶越高，越能对抗舍入误差。

    一句话抓住核心：两条主线

    主线 内容
    截断误差 数学近似带来的（\(h\) 越小越好）
    舍入误差 浮点带来的（\(h\) 越小越坏）✗

    两者的竞争产生「最优步长」

    关键结论：

    \[ h^{*}\sim\epsilon^{1/(p+1)} \]

    其中 \(p\) 是方法的精度阶。

    含义：阶数 \(p\) 越高，最优步长越大、可达精度越高

    方法 \(p\) 最优 \(h\) 可达精度
    前向差分 \(1\) \(\sim10^{-8}\) \(\sim10^{-8}\)
    中心差分 \(2\) \(\sim10^{-5}\) \(\sim10^{-10}\) ✓
    Richardson 外推 \(4\) \(\sim10^{-3}\) \(\sim10^{-13}\) ✓

    这就是「为什么值得用高阶方法」 —— 不是为了「理论上更漂亮」，而是实际能达到的精度更高

    一、数值微分：差分的两类误差¶

    三种基本差分¶

    名称 公式 截断误差
    前向差分 \(\dfrac{f(x+h)-f(x)}{h}\) \(\dfrac{h}{2}f''(\xi)\)
    后向差分 \(\dfrac{f(x)-f(x-h)}{h}\) \(-\dfrac{h}{2}f''(\xi)\)
    中心差分 \(\dfrac{f(x+h)-f(x-h)}{2h}\) \(-\dfrac{h^{2}}{6}f'''(\xi)\)

    推导（前向，用泰勒展开）：

    \[ f(x+h) = f(x)+hf'(x)+\frac{h^{2}}{2}f''(\xi) \]
    \[ \implies\frac{f(x+h)-f(x)}{h} = f'(x)+\frac{h}{2}f''(\xi) \]

    所以误差是 \(O(h)\)

    中心差分的推导（两式相减）：

    \[ f(x+h) = f(x)+hf'+\frac{h^{2}}{2}f''+\frac{h^{3}}{6}f'''+\cdots \]
    \[ f(x-h) = f(x)-hf'+\frac{h^{2}}{2}f''-\frac{h^{3}}{6}f'''+\cdots \]
    \[ f(x+h)-f(x-h) = 2hf'+\frac{h^{3}}{3}f'''+\cdots \]

    所以：

    \[ \frac{f(x+h)-f(x-h)}{2h} = f'+\frac{h^{2}}{6}f'''+\cdots \]

    误差是 \(O(h^{2})\)

    「h2 项被消掉」是中心差分的精髓

    观察两个展开式：

    \(f(x+h)\) \(f(x-h)\)
    \(+hf'\) \(-hf'\)
    \(+\frac{h^{2}}{2}f''\) \(+\frac{h^{2}}{2}f''\)
    \(+\frac{h^{3}}{6}f'''\) \(-\frac{h^{3}}{6}f'''\)

    \(h^{2}\) 项「同号」，相减时抵消

    这不是巧合 —— 它是「对称性」带来的：

    特性 结果
    公式关于 \(h\to-h\) 对称 偶数阶误差项自动抵消 ✓
    所以误差从 \(O(h^{2})\) 开始 而不是 \(O(h)\)

    这个原理可以继续推广：

    模板点数 对称性 误差阶
    \(3\) 点（中心） 对称 ✓ \(O(h^{2})\)
    \(5\) 点（对称） 对称 ✓ \(O(h^{4})\)
    一般 \(2k+1\) 点对称模板 对称 ✓ \(O(h^{2k})\) ✓

    五点公式（阶数更高的版本）：

    \[ f'(x)\approx\frac{-f(x+2h)+8f(x+h)-8f(x-h)+f(x-2h)}{12h} \]

    误差 \(O(h^{4})\)

    代价与收益的对比：

    模板 函数求值次数 误差阶
    前向 \(2\) \(O(h)\)
    中心 \(2\) \(O(h^{2})\)
    五点 \(4\) \(O(h^{4})\) ✓

    「中心差分用同样两次求值就得到二阶」 —— 这是「对称性的免费收益」

    工程含义：能用中心差分就用中心差分 （唯一例外是「边界处」—— 那里没有对称的邻点。）

    舍入误差的作用¶

    关键观察：差分是两个相近数相减（回顾上一页的灾难性抵消）✗

    舍入误差的量级：

    \[ \delta f\approx\epsilon\lvert f\rvert\implies\delta\left(\frac{\Delta f}{h}\right)\approx\frac{\epsilon\lvert f\rvert}{h} \]

    所以总误差（以前向差分为例）：

    \[ E(h)\approx\underbrace{\frac{h}{2}\lvert f''\rvert}_{\text{截断}}+\underbrace{\frac{\epsilon\lvert f\rvert}{h}}_{\text{舍入}} \]

    求最优步长：两类误差的平衡点

    令导数为零：

    \[ \frac{\mathrm{d}E}{\mathrm{d}h} = \frac{\lvert f''\rvert}{2}-\frac{\epsilon\lvert f\rvert}{h^{2}} = 0 \]
    \[ h^{*} = \sqrt{\frac{2\epsilon\lvert f\rvert}{\lvert f''\rvert}} \]

    量级（\(\epsilon = 2.22\times10^{-16}\)、\(\lvert f\rvert\approx\lvert f''\rvert\)）：

    \[ h^{*}\approx\sqrt{2\times2.22\times10^{-16}}\approx2.1\times10^{-8} \]

    最小的可达误差：

    \[ E_{\min}\approx2\sqrt{\frac{\epsilon\lvert f\rvert\lvert f''\rvert}{2}}\sim\sqrt{\epsilon}\approx1.5\times10^{-8} \]

    所以前向差分最多只能精确到 \(10^{-8}\) ✗

    中心差分的对应公式：

    \[ E(h)\approx\frac{h^{2}}{6}\lvert f'''\rvert+\frac{\epsilon\lvert f\rvert}{h} \]
    \[ h^{*} = \left(\frac{3\epsilon\lvert f\rvert}{\lvert f'''\rvert}\right)^{1/3} \]

    量级：\(\epsilon^{1/3}\approx6.1\times10^{-6}\)； 代入本例的 \(\lvert f\rvert = \sin1\)、\(\lvert f'''\rvert = \cos1\) 得

    \[ h^{*}\approx1.01\times10^{-5} \]

    最小误差 \(\sim\epsilon^{2/3}\approx10^{-10}\)

    两法的对比（重要）：

    方法 最优 \(h\) 可达精度
    前向差分 \(\sim10^{-8}\) \(\sim10^{-8}\) ✗
    中心差分 \(\sim10^{-5}\) \(\sim10^{-10}\) ✓
    五点公式 \(\sim10^{-3}\) \(\sim10^{-13}\) ✓

    三点重要结论：

    结论 1：步长不能无限小

    \(h\) 太小的问题 说明
    \(f(x+h)\) 与 \(f(x)\) 几乎相等 相减后有效数字全丢 ✗
    \(h\) 与 \(\epsilon x\) 同量级 → \(x+h = x\) 差分为零 ✗✗

    结论 2：\(h\) 太小会「归零」而不是「更准」

    具体阈值：

    \[ h< \epsilon\lvert x\rvert\implies x+h = x\implies\Delta f = 0 \]

    所以 \(h = 10^{-17}\) 时，任何差分都给出 0 ✗

    结论 3：高精度求导应该用「复步长」或「自动微分」

    复步长方法（一个巧妙的技巧）：

    \[ f'(x)\approx\frac{\operatorname{Im}f(x+ih)}{h} \]

    原理：由泰勒展开

    \[ f(x+ih) = f(x)+ihf'(x)-\frac{h^{2}}{2}f''(x)-\cdots \]

    虚部恰好是 \(hf'(x)+O(h^{3})\)

    优点：

    优点 说明
    没有抵消（虚部与实部独立） 可以取极小 \(h\) ✓
    精度可达机器精度 \(\sim10^{-16}\) ✓
    实现简单 只需支持复数

    代价：需要复值函数求值（约慢 2–3 倍）。

    自动微分（AD）则完全避免差分 —— 它用链式法则精确求导 （这就是深度学习框架的做法。）

    二、Richardson 外推¶

    核心思想¶

    若知道误差的「形状」，就能把它消掉

    设：

    \[ M(h) = M+\alpha_{1}h^{p}+\alpha_{2}h^{p+1}+\cdots \]

    （\(M\) 是真值，\(M(h)\) 是数值近似。）

    用两个步长消掉 \(h^{p}\) 项：

    \[ M(h/2) = M+\alpha_{1}\frac{h^{p}}{2^{p}}+\alpha_{2}\frac{h^{p+1}}{2^{p+1}}+\cdots \]

    组合：

    \[ \boxed{\ M_{\text{Rich}} = \frac{2^{p}M(h/2)-M(h)}{2^{p}-1}\ } \]

    误差变为 \(O(h^{p+1})\)

    验证「hp 项被消掉」

    计算：

    \[ 2^{p}M(h/2)-M(h) = 2^{p}\left(M+\alpha_{1}\frac{h^{p}}{2^{p}}+\cdots\right)-\left(M+\alpha_{1}h^{p}+\cdots\right) \]
    \[ = (2^{p}-1)M+\underbrace{\alpha_{1}h^{p}-\alpha_{1}h^{p}}_{=0}+\cdots \]

    除以 \((2^{p}-1)\) 后：

    \[ M_{\text{Rich}} = M+\frac{\text{高阶项}}{2^{p}-1} \]

    \(h^{p}\) 项恰好抵消

    对中心差分（\(p = 2\)）：

    \[ p = 2\implies2^{p}-1 = 3 \]
    \[ M_{\text{Rich}} = \frac{4M(h/2)-M(h)}{3} \]

    误差从 \(O(h^{2})\) 提升到 \(O(h^{4})\)

    可以继续外推（用三个步长消掉 \(h^{4}\) 项）：

    \[ M_{\text{Rich2}} = \frac{16M_{\text{Rich}}(h/2)-M_{\text{Rich}}(h)}{15} \]

    误差 \(O(h^{6})\)

    这就是「Romberg 积分」的思想：

    级数 得到的方法
    第 1 列 梯形法则
    第 2 列 Simpson 法则 ✓
    第 3 列 Boole 法则
    第 \(k\) 列 \(2k\) 阶方法 ✓

    「Simpson 法则 = 梯形的 Richardson 外推」 —— 这个对应关系非常漂亮

    代价分析（重要）：

    外推层数 需要的新求值 误差阶
    \(0\)（梯形） —— \(O(h^{2})\)
    \(1\)（Simpson） \(+n/2\) \(O(h^{4})\)
    \(2\)（Boole） \(+n/4\) \(O(h^{6})\)

    关键：每一层外推只需「更细一层的梯形」 —— 可以复用之前算过的函数值

    这就是 Romberg 算法高效的原因

    舍入误差的放大¶

    警告：Richardson 外推会放大舍入误差 ✗

    放大因子（对 \(p = 2\)）：

    \[ \left\lvert\frac{4}{3}\right\rvert+\left\lvert\frac{1}{3}\right\rvert = \frac53 \]

    所以若原始舍入误差是 \(\delta\)，外推后约 \(1.67\delta\)

    含义：外推不能无限做下去 —— 到某一层后，舍入误差会超过截断误差的改善 ✗

    实用的停止准则：

    观察 判断
    相邻两层的值接近 可以停止 ✓
    值开始震荡或不改善 已到舍入极限 ✗
    值突然大幅变化 数值不稳定

    工程建议：做 2–3 层外推就够了 （再多收益小于风险。）

    三、数值积分¶

    两个基本法则¶

    梯形法则（用一次多项式拟合）：

    \[ T_{n} = h\left[\frac{f_0}{2}+f_1+\cdots+f_{n-1}+\frac{f_n}{2}\right],\qquad h = \frac{b-a}{n} \]

    截断误差：

    \[ E_{T} = -\frac{(b-a)h^{2}}{12}f''(\xi) \]

    Simpson 法则（用二次多项式拟合，\(n\) 必须为偶数）：

    \[ S_{n} = \frac{h}{3}\left[f_0+4(f_1+f_3+\cdots)+2(f_2+f_4+\cdots)+f_n\right] \]

    截断误差：

    \[ E_{S} = -\frac{(b-a)h^{4}}{180}f^{(4)}(\xi) \]

    Simpson 法则的一个「惊人的」性质

    定理：Simpson 法则对任意三次多项式精确

    为什么「惊人」：它只用二次插值，却对三次函数精确 —— 误差项里没有 \(f'''\)，直接从 \(f^{(4)}\) 开始

    验证（对 \(f(x) = x^{3}\)，区间 \([0,1]\)，\(n=2\)）：

    真值：

    \[ \int_{0}^{1}x^{3}\mathrm{d}x = \frac14 = 0.25 \]

    Simpson（\(h = 0.5\)）：

    \[ S = \frac{0.5}{3}\left[0^{3}+4(0.5)^{3}+1^{3}\right] = \frac{0.5}{3}[0+0.5+1] = \frac{0.75}{3} = 0.25 \;\checkmark \]

    精确

    而梯形法则：

    \[ T = 0.5\left[\frac02+0.125+\frac12\right] = 0.5\times0.625 = 0.3125\;\times \]

    误差 \(0.0625\) ✗

    这个性质的实际意义：

    应用 说明
    被积函数在小区间上近似三次 Simpson 误差极小 ✓
    光滑函数 Simpson 通常足够
    只有 \(2\) 阶导数有奇点 Simpson 仍可能准（不被 \(f'''\) 影响）

    工程含义：「Simpson 比梯形好得多」不只是「阶数高一阶」 —— 它还对三次以下精确，这对工程问题（分段光滑）非常有利

    精度对比¶

    对 \(\int_{0}^{1}e^{-x^{2}}\mathrm{d}x\)（真值 \(0.7468241328\)）：

    \(n\) 梯形 梯形误差 Simpson Simpson 误差
    \(2\) \(0.731370\) \(-1.55\times10^{-2}\) \(0.747180\) \(+3.56\times10^{-4}\)
    \(4\) \(0.742984\) \(-3.84\times10^{-3}\) \(0.746855\) \(+3.12\times10^{-5}\)

    观察：

    量 每次 \(n\) 翻倍
    梯形误差 降到 \(1/4\) ✓（\(O(h^{2})\)）
    Simpson 误差 降到 \(1/16\) ✓（\(O(h^{4})\)）

    这与理论完全一致

    同一精度的成本对比：

    要把误差降到 \(10^{-6}\)：

    方法 需要的 \(n\) 需要的函数求值
    梯形 \(\approx250\) \(251\)
    Simpson \(\approx14\) \(15\) ✓

    「自适应积分」：把点数花在难算的地方

    基本想法：在小区间上比较两种方法，误差大就细分

    流程：

    步骤 操作
    1 在某区间上用 Simpson 与两个半区间的 Simpson
    2 比较两者之差作为误差估计
    3 误差超限 → 继续细分 ✓
    4 误差足够 → 接受

    为什么这样有效：

    因为大多数被积函数在大部分区域是「平坦」的 —— 只有少数区域（陡变、奇点附近）需要细分

    效果对比（陡变函数）：

    方法 达到 \(10^{-8}\) 所需求值
    均匀 Simpson \(10^{5}\) ✗
    自适应 Simpson \(10^{3}\) ✓

    自适应方法的意义在于「把计算资源按需分配」 —— 这也是现代积分器（如 QUADPACK）的标准做法

    注意「奇点」的处理：

    情形 处理
    可去奇点 在奇点处直接给极限值
    端点弱奇点 变量替换（如 \(x = t^{2}\)）✓
    内部强奇点 拆成两段分别处理
    无穷区间 变换到有限区间（如 \(x = t/(1-t)\)）✓

    「变量替换消奇点」的一个经典例子：

    \[ \int_{0}^{1}\frac{1}{\sqrt{x}}\mathrm{d}x \]

    被积函数在 \(x=0\) 处发散 ✗ 但积分有限（\(=2\)）。

    替换 \(x = t^{2}\)（\(\mathrm{d}x = 2t\,\mathrm{d}t\)）：

    \[ \int_{0}^{1}\frac{1}{t}\cdot2t\,\mathrm{d}t = \int_{0}^{1}2\,\mathrm{d}t = 2 \;\checkmark \]

    替换后被积函数变成常数 —— 奇点消失

    四、Gauss 求积与 Monte Carlo¶

    Gauss 求积：选最优的节点¶

    前面所有方法的节点都是等距的。Gauss 求积改变这一点：

    让节点与权重都「自由选择」，可以大幅提高精度。

    \(n\) 点 Gauss-Legendre 求积：

    \[ \int_{-1}^{1}f(x)\mathrm{d}x\approx\sum_{i=1}^{n}w_{i}f(x_{i}) \]

    节点是 Legendre 多项式的根，权重由积分条件确定。

    「n 点 Gauss 精确到 2n-1 次多项式」——这个结果有多强

    方法 点数 精确的多项式次数 「效率」
    梯形 \(n+1\) \(1\) \(1\)
    Simpson \(3\) \(3\) \(1\)
    Gauss（\(n\) 点） \(n\) \(2n-1\) 约 \(2\) ✓

    「效率」的含义：精确阶数 ÷ 点数

    Gauss 的 \(2n-1\) vs 点数的比接近 2，是理论上最优的

    常用节点与权重：

    2 点（\(n=2\)）：

    \[ x = \pm\frac{1}{\sqrt3},\qquad w = 1 \]

    3 点（\(n=3\)）：

    \[ x = 0,\ \pm\sqrt{\frac35},\qquad w = \frac89,\ \frac59 \]

    换算到一般区间 \([a,b]\)：

    \[ \int_{a}^{b}f(x)\mathrm{d}x\approx\frac{b-a}{2}\sum_{i}w_{i}f\left(\frac{b-a}{2}x_{i}+\frac{a+b}{2}\right) \]

    对 \(\int_{0}^{1}e^{-x^{2}}\mathrm{d}x\) 的实际效果：

    方法 函数求值次数 误差
    梯形（\(n=8\)） \(9\) \(9.6\times10^{-4}\) ✗
    Simpson（\(n=8\)） \(9\) \(2.0\times10^{-6}\)
    Gauss 2 点 \(2\) \(2.29\times10^{-4}\)
    Gauss 3 点 \(3\) \(9.55\times10^{-6}\) ✓

    Gauss 3 点（3 次求值）的精度接近 Simpson 9 次求值

    代价与限制：

    限制 说明
    节点需要预先算好 已表格化
    只能用于光滑函数 有奇点时优势尽失 ✗
    不利于自适应 节点不能递归细分 ✗

    最后一条是 Gauss 求积的主要局限：

    它假设函数光滑，所以无法自适应（细分级联会打破「最优节点」）✗

    所以实际积分器常用「Gauss-Kronrod」配对 —— 用两套嵌套节点同时给出结果与误差估计

    Monte Carlo 积分：维度的救赎¶

    问题：高维积分时，网格法的代价爆炸 ✗

    若每维用 \(n\) 个点：

    维度 \(d\) 总点数
    \(1\) \(n\)
    \(3\) \(n^{3}\)
    \(10\) \(n^{10}\) ✗✗

    \(n = 10\)、\(d = 10\) 时已是 \(10^{10}\) 个点 ✗

    Monte Carlo 的做法：随机采样

    \[ \int_{D}f\,\mathrm{d}V\approx V\cdot\frac1{N}\sum_{i=1}^{N}f(\boldsymbol{x}_{i}) \]

    误差（由中心极限定理）：

    \[ \text{误差}\sim\frac{\sigma}{\sqrt N} \]

    「/√ N 与维度无关」——这是 Monte Carlo 的全部价值

    对比两种方法的误差随维度：

    方法 误差 \(d=10\) 时要误差降 10 倍需
    网格法（Simpson） \(O(h^{4}) = O(n^{-4/d})\) 点数 \(\times 10^{d/4} = 10^{2.5}\) 总点数 \(\times10^{25}\) ✗
    Monte Carlo \(O(N^{-1/2})\) 点数 \(\times100\) ✓

    网格法的误差指数含 \(1/d\) → 维度高时几乎不收敛 ✗

    Monte Carlo 的 \(N^{-1/2}\) 与维度无关

    「维度的诅咒」被 Monte Carlo 绕过了 —— 这是它唯一但决定性的优势 ✓

    临界维度（粗略估计）：

    \(d\) 更好的方法
    \(1\)–\(3\) 求积法（Gauss、Simpson） ✓
    \(4\)–\(6\) 稀疏网格（Smolyak）
    \(>10\) Monte Carlo / 拟蒙特卡罗 ✓

    Monte Carlo 的两个缺点：

    缺点 说明
    收敛慢（\(N^{-1/2}\)） 要 2 位数字需 100 倍样本 ✗
    结果有随机误差 需报告置信区间

    改善手段：

    手段 效果
    重要性采样 在「重要区域」多采样 ✓
    分层采样 降低方差 ✓
    拟蒙特卡罗（QMC） 用低差异序列，误差可达 \(\sim N^{-1}\) ✓
    控制变量的方法 减去已知的相似函数 ✓

    「重要性采样」在处理稀有事件时是必需的 —— 因为均匀采样几乎采不到稀有事件 ✗

    工程应用：

    领域 用 Monte Carlo 的原因
    金融衍生品定价 维度高（多资产路径）✓
    粒子滤波 / 贝叶斯推断 后验是高维积分 ✓
    辐射传输 / 渲染 高维光路积分 ✓
    风险评估 稀有事件 + 高维 ✓

    注意「深度学习中的 MC」：

    dropout 的推理、变分推断的 ELBO 估计、 策略梯度中的期望 —— 这些都是 Monte Carlo 积分

    例题 1：三种差分格式的精度对比¶

    用 \(f(x) = \sin x\) 在 \(x = 1\) 处求导（真值 \(\cos 1 = 0.5403023059\)）， 比较前向、中心差分的误差随 \(h\) 的变化。

    思路

    逐个 \(h\) 计算，观察误差的下降速率；注意 \(h\) 很小的时候舍入误差会反超。

    解答

    第一步：算几个典型 \(h\)

    \(h\) 前向差分 前向误差 中心差分 中心误差
    \(10^{-1}\) \(0.489536\) \(5.08\times10^{-2}\) \(0.539402\) \(9.00\times10^{-4}\)
    \(10^{-2}\) \(0.535511\) \(4.79\times10^{-3}\) \(0.540293\) \(9.00\times10^{-6}\)
    \(10^{-3}\) \(0.539881\) \(4.21\times10^{-4}\) \(0.540302\) \(9.00\times10^{-8}\)
    \(10^{-4}\) \(0.540260\) \(4.21\times10^{-5}\) \(0.540302\) \(9.00\times10^{-10}\)
    \(10^{-5}\) \(0.540298\) \(4.21\times10^{-6}\) \(0.540302\) \(9.00\times10^{-12}\)

    第二步：观察误差的下降

    前向差分（\(h\) 从 \(10^{-1}\) 到 \(10^{-5}\)，即 \(h\) 减小 \(10^{4}\) 倍）：

    \[ \frac{5.08\times10^{-2}}{4.21\times10^{-6}}\approx1.21\times10^{4} \]

    误差约减小 \(10^{4}\) 倍 → 与 \(h\) 成正比 → 一阶

    中心差分：

    \[ \frac{9.00\times10^{-4}}{9.00\times10^{-12}} = 10^{8} \]

    误差减小 \(10^{8}\) 倍，而 \(h\) 减小 \(10^{4}\) 倍 → 与 \(h^{2}\) 成正比 → 二阶

    第三步：验证理论系数

    前向差分（\(f''(1) = -\sin1 = -0.841471\)）：

    \[ E\approx\frac{h}{2}f''(1)\implies\frac{0.1}{2}\times(-0.841471) = -0.042074 \]

    实测 \(-5.08\times10^{-2}\) —— 量级一致 ✓（高阶项有贡献。）

    中心差分（\(f'''(1) = -\cos1 = -0.540302\)）：

    \[ E\approx\frac{h^{2}}{6}\lvert f'''\rvert = \frac{0.01}{6}\times0.540302 = 9.005\times10^{-4} \]

    实测 \(9.00\times10^{-4}\) —— 精确吻合

    「中心差分的误差系数可以精确验证」的原因

    方法 首项误差 是否「精确」
    前向差分 \(\frac{h}{2}f''(\xi)\) \(\xi\) 未知 → 只能估量级 ⚠
    中心差分 \(-\frac{h^{2}}{6}f'''(\xi)\) 本例中恰好在 \(1\) 处取值 ✓

    为什么中心差分更容易验证：

    因为 \(\sin\) 的高阶导数形式简单（\(f''' = -\cos\)）， 且 \(x = 1\) 处没有使高阶项抵消的特殊性

    工程含义（一个实用的自检）：

    若实测误差与理论系数差很多，说明 \(h\) 还不够小 （高阶项仍在起作用）

    具体判据：

    观察 结论
    误差 ≈ 理论首项 \(h\) 已足够小 ✓
    误差远大于理论 \(h\) 太大 ⚠
    误差随 \(h\) 减小而不再下降 已到舍入极限 ✗

    第三种情形就是本题的下一步：

    \(h<10^{-8}\) 时，前向差分会因 \(\sin(1+h)\) 与 \(\sin(1)\) 的两数相减 而失去有效数字 ✗

    \(h<2\times10^{-16}\) 时，\(1+h\) 在浮点中等于 \(1\)， 差分给出恒为 \(0\) ✗✗

    例题 2：Richardson 外推的实际效果¶

    承例题 1，用 \(h = 0.1\) 和 \(h = 0.05\) 的中心差分做一次 Richardson 外推。

    思路

    中心差分的 \(p = 2\)，所以外推公式是 \((4M(h/2)-M(h))/3\)。

    解答

    第一步：两个中心差分值

    \[ M(0.1) = \frac{\sin(1.1)-\sin(0.9)}{0.2} = \frac{0.8912073601-0.7833269096}{0.2} = 0.5394022525 \]
    \[ M(0.05) = \frac{\sin(1.05)-\sin(0.95)}{0.1} = \frac{0.8674232256-0.8134155048}{0.1} = 0.5400772080 \]

    第二步：Richardson 外推（\(p = 2\)）

    \[ M_{\text{Rich}} = \frac{4M(h/2)-M(h)}{3} = \frac{4(0.5400772080)-0.5394022525}{3} \]
    \[ = \frac{2.160308832-0.5394022525}{3} = \frac{1.6209065795}{3} = 0.5403021932 \]

    第三步：误差对比

    量 值 误差
    真值 \(0.5403023059\) ——
    \(M(0.1)\) \(0.5394022525\) \(9.00\times10^{-4}\)
    \(M(0.05)\) \(0.5400772080\) \(2.25\times10^{-4}\)
    \(M_{\text{Rich}}\) \(0.5403021932\) \(1.13\times10^{-7}\) ✓

    外推把误差从 \(2.25\times10^{-4}\) 降到 \(1.13\times10^{-7}\)

    改善了约 \(2000\) 倍

    第四步：验证「四阶」的理论

    理论（用 \(f^{(5)}(1) = \sin1 = 0.841471\)）：

    \[ E_{\text{Rich}}\approx-\frac{h^{4}}{4}\times\frac{f^{(5)}}{120} = -\frac{10^{-4}}{4}\times\frac{0.841471}{120} = -1.75\times10^{-7} \]

    与实测 \(-1.13\times10^{-7}\) 同量级

    「h = 0.1 的 Richardson 相当于多小的 h 的中心差分」

    比较精度：

    要求中心差分的误差等于 \(1.13\times10^{-7}\)：

    \[ \frac{h^{2}}{6}\times0.540302 = 1.13\times10^{-7}\implies h^{2} = 1.25\times10^{-6}\implies h = 1.12\times10^{-3} \]

    所以 Richardson（用 \(h = 0.1\) 与 \(0.05\)，共 4 次函数求值） 相当于 \(h = 1.12\times10^{-3}\) 的中心差分（需要 2 次求值但精度只需 \(h\) 很小）

    成本对比（同样是 4 次函数求值）：

    做法 \(h\) 误差
    中心差分 \(1.12\times10^{-3}\) \(1.13\times10^{-7}\)
    Richardson \(0.1\) \(1.13\times10^{-7}\) ✓

    两者精度相同 —— 但 Richardson 用了更大的 \(h\)

    为什么「大 \(h\)」是优势：

    优势 说明
    舍入误差小（\(\propto\epsilon/h\)） 更接近理论极限 ✓
    可以外推更多层 达到更高精度 ✓
    数值更稳定 不易被抵消破坏 ✓

    这就是「Richardson 外推的价值不只是省计算，更是提高可达精度」

    对积分同理：

    Romberg 算法用 \(h = 1, 1/2, 1/4, \ldots\) 的梯形值逐层外推， 可以用很少的函数求值达到极高精度

    代价：舍入误差被放大 \(5/3\) 倍（每层） 所以外推层数不宜太多（2–3 层最佳）。

    同求值次数 Gauss 更优 ✓
    需要自适应细分 Simpson/梯形（Gauss 不宜细分）✗
    被积函数不光滑 低阶方法（Gauss 的优势消失）⚠
    节点需要复用 复合 Newton-Cotes ✓

    「可比性」的教训：

    比较算法时必须「控制总成本相等」 —— 这是工程评估的基本原则

    这与「梯度下降与收敛」一页的「比较总代价而非每步代价」是同一原则

    例题 4：Monte Carlo 的误差与维度¶

    用 Monte Carlo 计算 \(\int_{0}^{1}e^{-x^{2}}\mathrm{d}x\)， 比较 \(N = 10^{3}\)、\(10^{4}\)、\(10^{5}\) 的误差。

    思路

    用均匀随机样本；误差应大致按 \(N^{-1/2}\) 减小。

    解答

    方法：

    \[ I\approx\frac1N\sum_{i=1}^{N}e^{-u_{i}^{2}},\qquad u_{i}\sim U(0,1) \]

    真值：\(0.7468241328\)

    用 \(N\) 个样本的结果（示例）：

    \(N\) 估计值 误差
    \(10^{3}\) \(0.7467\) \(\approx1.2\times10^{-4}\)
    \(10^{4}\) \(0.746846\) \(\approx2.2\times10^{-5}\)
    \(10^{5}\) \(0.7468186\) \(\approx5.5\times10^{-6}\)

    误差随 \(N\) 的变化：

    \(N\) 之比 误差之比（理论 \(\sqrt{N}\)）
    \(10^{4}/10^{3} = 10\) \(\approx\sqrt{10} = 3.16\)
    \(10^{5}/10^{4} = 10\) \(\approx3.16\)

    实测误差比约 5–6 与 4.0 —— 与 \(\sqrt{N}\) 的量级一致 （Monte Carlo 的误差本身有随机性，所以不会精确等于理论值。）

    标准差的估计：

    被积函数 \(f = e^{-x^{2}}\) 在 \([0,1]\) 上的方差：

    \[ E[f]\approx0.7468,\qquad E[f^{2}] = \int_{0}^{1}e^{-2x^{2}}\mathrm{d}x\approx0.5981 \]
    \[ \sigma^{2} = 0.5981-0.7468^{2} = 0.5981-0.5577 = 0.0404\implies\sigma\approx0.2010 \]

    \(N = 10^{5}\) 的标准误：

    \[ \frac{\sigma}{\sqrt N} = \frac{0.2010}{316.2}\approx6.4\times10^{-4} \]

    注意这个标准误远大于实测误差：

    \(6.4\times10^{-4}\) vs 实测 \(5.5\times10^{-6}\)

    「为什么实测误差比标准误小那么多」

    原因：这个函数的方差很小。

    重新审视：

    \(f\) 在 \([0,1]\) 上的取值从 \(1\) 变到 \(0.3679\) —— 变化不大

    所以方差小、Monte Carlo 表现好

    但也说明「标准误公式中的 \(\sigma\) 需要正确估计」：

    估计方式 值
    用上面的 \(E[f^{2}]\) 算 \(0.2010\)
    用样本方差算 更准 ✓

    真正的标准误应由样本估计：

    \[ \hat{\text{SE}} = \frac{s}{\sqrt N},\qquad s^{2} = \frac{1}{N-1}\sum(f(x_{i})-\bar f)^{2} \]

    这才是实践中应报告的量

    与「确定性求积」的对比（\(10^{-6}\) 精度）：

    方法 需要的求值次数
    Simpson \(\approx14\) ✓
    梯形 \(\approx250\)
    Monte Carlo \(\approx10^{4}\)–\(10^{5}\) ✗

    一维问题上 Monte Carlo 差 3–4 个数量级 ✗

    但换到高维：

    维度 Simpson（每维 10 点） Monte Carlo
    \(1\) \(10\) ✓ \(10^{4}\) ✗
    \(3\) \(10^{3}\) ✓ \(10^{4}\) ⚠
    \(10\) \(\mathbf{10^{10}}\) ✗ \(10^{4}\) ✓
    \(100\) \(10^{100}\) ✗✗ \(10^{4}\) ✓

    这就是「Monte Carlo 是唯一可行的高维积分方法」的原因 ✓

    实用判断：

    维度 推荐
    \(d\leq3\) 确定性求积（Gauss） ✓
    \(d = 4\)–\(10\) 稀疏网格或 MC
    \(d>10\) Monte Carlo / QMC ✓

    「维度是分水岭」这个结论在工程中非常实用 —— 它决定了「用哪一类算法」

    六、用在哪些课程里¶

    无人系统自主决策与优化 · 梯度与期望¶

    • 数值梯度只在无法自动微分时使用（代价高、精度低）
    • 策略梯度中的期望用 Monte Carlo 估计（高维积分）
    • 稀疏奖励的评估需要重要性采样（否则采不到稀有事件）
    • 轨迹积分用 RK4 或自适应方法（ODE 模块已述）

    机器人学 · 雅可比与位姿估计¶

    • 雅可比矩阵的数值近似（当解析式难写时）需选合适的 \(h\)
    • 视觉里程计的重投影误差对参数求导——解析式复杂时用数值差分
    • 标定的精度上限受数值微分精度限制（\(h^{*}\sim\epsilon^{1/3}\)）
    • 位姿积分的长期漂移需要周期性重观测修正

    现代数字信号处理 · 滤波器与谱估计¶

    • 模拟滤波器的离散化（双线性变换）本质是数值积分
    • 功率谱估计的积分（求总功率）用梯形法
    • 卷积的数值计算与积分同源（卷积就是「滑动积分」）
    • 相位的数值微分（求瞬时频率）需注意噪声放大 ⚠

    七、自测¶

    Q1 为什么数值微分不能通过「把 \(h\) 取得极小」来提高精度？

    提示

    想想差分是「两个相近数相减」。

    解答

    因为舍入误差 \(\propto\epsilon/h\) 会随 \(h\) 减小而增大，最终反超截断误差。

    两个误差的方向相反：

    误差 随 \(h\) 减小
    截断误差 \(\propto h^{p}\) 下降 ✓
    舍入误差 \(\propto\epsilon/h\) 上升 ✗

    总误差呈 U 形，最低点对应最优 \(h\)

    具体量级（中心差分）：

    \[ E(h)\approx\frac{h^{2}}{6}\lvert f'''\rvert+\frac{\epsilon\lvert f\rvert}{h} \]

    令导数为零：

    \[ \frac{h\lvert f'''\rvert}{3} = \frac{\epsilon\lvert f\rvert}{h^{2}}\implies h^{3} = \frac{3\epsilon\lvert f\rvert}{\lvert f'''\rvert} \]
    \[ h^{*} = \left(\frac{3\epsilon\lvert f\rvert}{\lvert f'''\rvert}\right)^{1/3}\approx6\times10^{-6} \]

    最小可达误差：

    \[ E_{\min}\sim\epsilon^{2/3}\approx10^{-10} \]

    所以中心差分最多精确到 \(10^{-10}\) ✗（而非 \(10^{-16}\)。）

    两个极端的表现：

    \(h\) 太小（如 \(10^{-17}\)）→ 差分恒为零 ✗✗

    原因：\(x+h\) 在浮点中等于 \(x\)：

    \[ 1+10^{-17} = 1\quad\text{（双精度）} \]

    所以 \(f(x+h)-f(x) = 0\)，商也为 \(0\) ✗

    \(h\) 太大（如 \(1\)） → 截断误差大：

    \[ \frac{1^{2}}{6}\times0.540302 = 0.090 \]

    误差 9% ✗

    正确的选择：

    方法 推荐的 \(h\) 量级
    前向/后向差分 \(10^{-8}\)
    中心差分 \(10^{-5}\)
    五点公式 \(10^{-3}\)

    更根本的解决方案：

    方法 精度
    复步长法 可达机器精度 ✓
    自动微分（AD） 精确（无极小 \(h\) 问题） ✓

    复步长法的原理：

    \[ f(x+ih) = f(x)+ihf'(x)-\frac{h^{2}}{2}f''(x)+\cdots \]

    取虚部除以 \(h\)：

    \[ \frac{\operatorname{Im}f(x+ih)}{h} = f'(x)+O(h^{3}) \]

    关键：没有「两个相近数相减」 ✓ 所以可以取很小的 \(h\)。

    工程建议：

    场景 做法
    有解析导数 直接用解析式 ✓
    有自动微分框架 用 AD ✓
    只有黑箱函数 中心差分（\(h\approx10^{-5}\)）⚠
    C/C++ 手写 复步长法 ✓

    Q2 判断：Simpson 法则比梯形法则好，因为它对更高次多项式精确。

    提示

    这个说法对，但是否完整？

    解答

    说法正确，但不完整 —— 还有两个更重要的优势。

    三个优势（按重要性排序）：

    优势 1：误差阶更高（\(O(h^{4})\) vs \(O(h^{2})\)）

    \(n\) 梯形误差 Simpson 误差
    \(8\) \(9.6\times10^{-4}\) \(2.0\times10^{-6}\)
    \(16\) \(2.4\times10^{-4}\) \(1.2\times10^{-7}\)

    同精度下 Simpson 需要少得多的点：

    要误差 \(10^{-6}\)：梯形需 \(n\approx250\)；Simpson 需 \(n\approx14\)

    优势 2：对三次多项式精确（误差项从 \(f^{(4)}\) 开始）

    这一点很重要：梯形法则的误差含 \(f''\)，而 Simpson 不含 \(f''\) 与 \(f'''\)

    方法 误差项
    梯形 \(-\frac{(b-a)h^{2}}{12}f''(\xi)\)
    Simpson \(-\frac{(b-a)h^{4}}{180}f^{(4)}(\xi)\)

    当 \(f''\) 有奇点或变化剧烈时，Simpson 尤其有利

    优势 3：同样的「光滑性假设」下精度更高

    这是「免费」的 —— Simpson 只比梯形多算一个中间点的加权。

    但有两个限制：

    限制 1：\(n\) 必须为偶数 ⚠

    方法 对 \(n\) 的要求
    梯形 任意 ✓
    Simpson 必须偶数 ✗

    所以自适应细分时 Simpson 需要成对细分

    限制 2：对被积函数的光滑性要求更高

    Simpson 的误差含 \(f^{(4)}\) —— 若 \(f^{(4)}\) 在区间内很大（如陡变），优势会减弱

    极端情形：

    函数 Simpson 是否仍优
    光滑（如 \(e^{-x^{2}}\)） ✓ 明显更优
    有跳跃间断 ✗ 两者都差
    有尖点 ⚠ 优势减弱

    对间断函数的处理：

    正确做法是「在间断点处拆开积分区间」 而不是用任意高阶方法硬算。

    工程选择的实用建议：

    情形 选择
    光滑函数 Simpson ✓
    需要自适应、粗糙函数 梯形 + 自适应
    只有奇数个采样点 梯形（或补一个点）
    极高精度需求 Romberg（梯形外推） ✓

    「Romberg」值得特别提一下：

    它从梯形出发，用 Richardson 外推逐层提升阶 —— 第一层外推恰好得到 Simpson

    所以「Simpson = 梯形的 Richardson 外推」 —— 这也是「为什么 Simpson 对三次多项式精确」的深层原因

    Q3 为什么高维积分要用 Monte Carlo 而不是 Simpson？

    提示

    比较两种方法的误差随维度的变化。

    解答

    因为网格法的计算量随维度指数增长（维度的诅咒），而 Monte Carlo 的误差与维度无关。

    网格法的代价：

    设每维用 \(n\) 个点，则 \(d\) 维需要 \(n^{d}\) 个点 ✗

    \(d\) \(n = 10\) 时的点数
    \(1\) \(10\)
    \(3\) \(10^{3}\)
    \(6\) \(10^{6}\)
    \(10\) \(\mathbf{10^{10}}\) ✗
    \(100\) \(10^{100}\) ✗✗

    误差与成本的关系（网格法）：

    Simpson 在 \(d\) 维的误差：

    \[ E\sim h^{4}\sim n^{-4/d} \]

    注意指数含 \(1/d\)：

    \(d\) 要对分误差（\(n\to2n\)）误差降多少
    \(1\) \(\times1/16\) ✓
    \(4\) \(\times1/4\)
    \(10\) \(\times1/2.14\) ⚠
    \(100\) \(\times1.028\) ✗✗

    维度高时，加密网格几乎不改善精度 ✗

    Monte Carlo 的误差：

    \[ \text{误差}\sim\frac{\sigma}{\sqrt N} \]

    与 \(d\) 无关

    所以「降误差 10 倍 = 样本增 100 倍」在任何维度都成立

    交叉点（粗略估计）：

    \(d\) 更优的方法
    \(1\)–\(3\) 确定性求积 ✓
    \(4\)–\(8\) 稀疏网格（Smolyak）
    \(>10\) Monte Carlo / QMC ✓

    Monte Carlo 的代价：

    缺点 说明
    收敛慢（\(N^{-1/2}\)） 要 3 位精度需 \(10^{6}\) 样本 ✗
    有随机误差 需报告置信区间 ⚠
    浪费「光滑性」信息 对光滑函数效率低 ✗

    最后一行值得强调：

    Monte Carlo 完全忽略了函数的光滑性 —— 它对光滑函数的效率远低于 Gauss 求积 ✗

    所以「用 MC 做一维积分」是浪费 但「用 Gauss 做 100 维积分」是不可行 ✗

    改善手段（缩小差距）：

    手段 效果
    拟蒙特卡罗（QMC） 用低差异序列 → 误差可达 \(\sim N^{-1}\) ✓
    重要性采样 在有贡献区域多采样 ✓
    分层采样 降低方差 ✓
    控制变量法 减去已知的相似函数 ✓

    QMC 的实用价值：

    在中等维度（\(d\sim10\)）下，QMC 常比 MC 快 10–100 倍

    所以现代金融工程（高维期权定价）大量用 QMC

    工程结论：

    维度 首选
    \(1\)–\(3\) Gauss 求积 ✓
    \(4\)–\(10\) QMC 或稀疏网格 ✓
    \(>10\) MC / QMC ✓
    被积函数有奇点 MC（对奇点不敏感）✓

    最后一行是 MC 的一个「意外的优势」：

    Monte Carlo 对函数的奇点与大变化不敏感 （因为它只求点值、不做插值。）

    这就是「粒子滤波能用在高维、非高斯、有跳变的状态估计上」的原因

    Q4 为什么「五点差分公式」比「中心差分」精度更高？

    提示

    对称模板的哪些误差项会抵消？

    解答

    因为对称性使更多偶数阶误差项相互抵消。

    对比两个公式：

    中心差分（3 点对称）：

    \[ f'(x)\approx\frac{f(x+h)-f(x-h)}{2h} \]

    误差：

    \[ -\frac{h^{2}}{6}f'''(\xi) \]

    五点公式（5 点对称）：

    \[ f'(x)\approx\frac{-f(x+2h)+8f(x+h)-8f(x-h)+f(x-2h)}{12h} \]

    误差：

    \[ \frac{h^{4}}{30}f^{(5)}(\xi) \]

    关键：抵消的机制

    用泰勒展开看系数：

    项 中心差分（3 点） 五点公式
    \(f'\) ✓ 保留 ✓ 保留
    \(f''\) 抵消（对称） 抵消（对称）
    \(f'''\) 保留 ✗ 抵消 ✓
    \(f^{(4)}\) 抵消（对称） 抵消（对称）
    \(f^{(5)}\) 保留 保留

    规律：对称模板自动抵消全部偶数阶导数项 （因为奇函数的项在 \(h\to-h\) 时变号。）

    「抵消更多项」的方法：

    增加模板点数（保持对称）：

    模板 点数 误差阶 抵消到
    中心 \(3\) \(O(h^{2})\) \(f''\)
    五点 \(5\) \(O(h^{4})\) \(f^{(4)}\) ✓
    七点 \(7\) \(O(h^{6})\) \(f^{(6)}\)

    （奇数阶项靠「加权系数的特定选取」抵消 —— 这就是推导时要解方程组的原因。）

    实际收益（误差量级）：

    若 \(\lvert f'''\rvert\approx\lvert f^{(5)}\rvert\approx1\)：

    \(h\) 中心差分误差 五点误差
    \(10^{-2}\) \(\sim10^{-5}\) \(\sim10^{-10}\) ✓
    \(10^{-3}\) \(\sim10^{-7}\) \(\sim10^{-16}\)（机器精度）✓

    五点公式在 \(h = 10^{-3}\) 就能达到机器精度

    最优步长也更大：

    方法 \(h^{*}\) \(E_{\min}\)
    中心差分 \(\sim10^{-5}\) \(\sim10^{-10}\)
    五点 \(\sim10^{-3}\) \(\sim10^{-13}\) ✓

    「\(h^{*}\) 更大」是一个被低估的优势：

    优势 说明
    舍入误差更小 \(\propto\epsilon/h\) ✓
    数值更稳定 不易受抵消影响
    对噪声更宽容 适合含噪数据 ✓

    代价：

    代价 说明
    求值次数从 \(2\) 增到 \(4\) 贵一倍 ⚠
    边界处无法使用 需要 \(f(x\pm2h)\) ✗
    对噪声放大 权重含 \(\pm8\)，放大噪声 ⚠

    最后一点值得说明：

    五点公式的权重大（\(8/12\)）→ 对小扰动更敏感

    所以「数据含噪时，高阶差分不一定更好」 ✓

    实用的选择建议：

    场景 选择
    解析函数、无噪声 五点 ✓
    含噪数据 中心差分（甚至更简单的）⚠
    边界处 单侧高阶公式
    需要机器精度 复步长法或 AD ✓

    「含噪数据用低阶差分」是一个实用的经验法则

    原因是「偏差-方差权衡」：

    方法 偏差 方差
    五点 小 ✓ 大 ✗
    中心 中 中
    前向 大 ✗ 小 ✓

    与统计中的「偏差-方差」以及「浮点数与误差」一页的 「截断 vs 舍入」是同一个权衡的三个面孔
