    向量与向量空间¶

    线性代数研究的对象有两类：向量和线性映射。 这一页讲第一类。

    可能你会觉得「向量就是一组数」——这在计算时够用，但会挡住后面所有的理解。 真正的定义要抽象一层：向量是「能做加法和数乘」的东西。 这个定义之下，多项式是向量，函数是向量，连你熟悉的矩阵也是向量。

    先建立这个抽象视角，后面的特征值、线性映射才讲得通。

    一、从熟悉的地方开始¶

    中学里学的向量是平面或空间中的「箭头」：

    \[ \boldsymbol{u} = (3,\,4) \]

    它可以相加：

    \[ (3,4) + (1,2) = (4,6) \]

    也可以乘以一个数（称为标量）：

    \[ 2 \cdot (3,4) = (6,8) \]

    就这两件事。没有减法，没有除法，也没有「点乘」—— 点乘是后来才引进的额外结构，不是向量空间本身的一部分。

    关键认识

    向量空间的全部内容就是加法与数乘两种运算。 后面所有概念（线性无关、基、维数、线性映射）都从这两个运算生长出来。

    加法为什么这样定义¶

    向量加法有个很直观的几何解释：首尾相接。

    从图里能读出两件事：

    1. 加法有几何意义：「首尾相接」的位移合成
    2. 加法可交换（公理 1）：虚线补出的平行四边形说明， 先走 \(\boldsymbol{u}\) 还是先走 \(\boldsymbol{v}\)，终点相同

    数乘的几何意义也很清楚：\(\lambda \boldsymbol{u}\) 把 \(\boldsymbol{u}\) 拉长到 \(|\lambda|\) 倍。 \(\lambda < 0\) 时方向反转，\(\lambda = 0\) 时缩成一个点（零向量）。

    二、推广到 \(\mathbb{R}^n\)¶

    把「两个数一组」推广到「\(n\) 个数一组」：

    \[ \mathbb{R}^n = \{(x_1, x_2, \dots, x_n) : x_i \in \mathbb{R}\} \]

    加法与数乘按分量进行：

    \[ (x_1,\dots,x_n) + (y_1,\dots,y_n) = (x_1+y_1,\ \dots,\ x_n+y_n) \]
    \[ \lambda (x_1,\dots,x_n) = (\lambda x_1,\ \dots,\ \lambda x_n) \]

    \(n=2\) 是平面，\(n=3\) 是空间，\(n\) 更大就画不出来了——但代数规则完全一样。

    为什么 \(n\) 可以很大¶

    在工程里 \(n\) 常常很大：

    场景 \(n\) 是什么
    一张 \(28\times28\) 的灰度图 \(n = 784\)（每个像素一个分量）
    机器人的关节角度 \(n\) = 关节数（6 或 7）
    传感器一次采样 \(n\) = 传感器通道数

    画不出来不代表不能算——这正是抽象定义的价值。

    三、真正的定义：向量空间¶

    现在把「可以做加法和数乘」这件事本身抽出来，作为定义。

    定义：设 \(V\) 是一个集合，在它上面定义了加法与数乘两种运算。 若对任意 \(\boldsymbol{u},\boldsymbol{v},\boldsymbol{w} \in V\) 和任意 \(\lambda,\mu \in \mathbb{R}\)（或 \(\mathbb{C}\)）， 下列 8 条都成立，则称 \(V\) 是向量空间，其中的元素称为向量：

    # 公理 含义
    1 \(\boldsymbol{u}+\boldsymbol{v} = \boldsymbol{v}+\boldsymbol{u}\) 加法交换律
    2 \((\boldsymbol{u}+\boldsymbol{v})+\boldsymbol{w} = \boldsymbol{u}+(\boldsymbol{v}+\boldsymbol{w})\) 加法结合律
    3 存在 \(\boldsymbol{0}\) 使 \(\boldsymbol{v}+\boldsymbol{0}=\boldsymbol{v}\) 零向量存在
    4 对每个 \(\boldsymbol{v}\) 存在 \(-\boldsymbol{v}\) 使 \(\boldsymbol{v}+(-\boldsymbol{v})=\boldsymbol{0}\) 负向量存在
    5 \(\lambda(\boldsymbol{u}+\boldsymbol{v}) = \lambda\boldsymbol{u}+\lambda\boldsymbol{v}\) 数乘对向量加法分配
    6 \((\lambda+\mu)\boldsymbol{v} = \lambda\boldsymbol{v}+\mu\boldsymbol{v}\) 数乘对标量加法分配
    7 \((\lambda\mu)\boldsymbol{v} = \lambda(\mu\boldsymbol{v})\) 数乘结合律
    8 \(1\cdot\boldsymbol{v} = \boldsymbol{v}\) 数乘单位元

    这 8 条不用背

    它们只是把「加法和数乘应该有的正常性质」列全。 你只需要记住一句话：能做加法与数乘、且性质正常的东西，就是向量空间。

    后面的所有定理都从这 8 条推出。这也是为什么结论对多项式、函数同样成立—— 因为证明里只用到了这 8 条，没用到「向量长得像箭头」。

    四、向量不只是箭头¶

    这是抽象定义带来的最大好处。

    例 1：多项式也是向量¶

    设 \(P_2\) 是所有次数不超过 2 的实系数多项式：

    \[ p(x) = a_0 + a_1 x + a_2 x^2 \]

    定义加法与数乘就是通常的多项式运算：

    \[ (a_0 + a_1 x + a_2 x^2) + (b_0 + b_1 x + b_2 x^2) = (a_0+b_0) + (a_1+b_1)x + (a_2+b_2)x^2 \]
    \[ \lambda(a_0 + a_1 x + a_2 x^2) = \lambda a_0 + \lambda a_1 x + \lambda a_2 x^2 \]

    8 条公理全部成立，所以 \(P_2\) 是向量空间。

    它和 \(\mathbb{R}^3\) 有什么关系？注意系数：\(a_0 + a_1 x + a_2 x^2\) 与 \((a_0, a_1, a_2)\) 是一一对应的，而且运算规则完全一致。这就是后面要讲的同构。

    例 2：函数也是向量¶

    设 \(V\) 是区间 \([0,1]\) 上所有连续函数构成的集合。定义

    \[ (f+g)(x) = f(x) + g(x), \qquad (\lambda f)(x) = \lambda f(x) \]

    （即「逐点相加、逐点数乘」。）

    同样是向量空间。验证一下第 3 条：零向量就是恒为 0 的函数 \(f(x)\equiv 0\)。

    这个例子的重要性

    函数空间是信号处理的基础。 一个信号 \(x(t)\) 就是一个「向量」，只不过分量是连续统而不是 \(n\) 个。 傅里叶变换之所以能理解为「换一组基」，根源就在这里。

    例 3：不是向量空间的例子¶

    设 \(V = \{(x, y) : x, y \in \mathbb{R},\ x \geq 0\}\)（右半平面）， 用通常的加法与数乘。它不是向量空间。

    为什么？取 \(\boldsymbol{v} = (1, 0) \in V\)，标量 \(\lambda = -1\)，则

    \[ \lambda \boldsymbol{v} = (-1, 0) \notin V \]

    数乘不封闭，所以不满足定义。

    这个例子说明：一个集合能不能成为向量空间，取决于运算的定义域是否封闭。

    五、子空间¶

    定义：设 \(U \subseteq V\) 是向量空间 \(V\) 的子集。若 \(U\) 在 \(V\) 的运算下本身也是向量空间， 则称 \(U\) 是 \(V\) 的子空间。

    判定：只需检查两条¶

    不用把 8 条公理全验一遍。因为 \(V\) 中的运算已经满足公理， \(U\) 作为子集自动继承了交换律、结合律等—— 唯一可能出问题的是「封闭性」（也就是上面例 3 失败的地方）。

    于是有：

    子空间判定法

    非空子集 \(U \subseteq V\) 是子空间，当且仅当：

    1. 对加法封闭：\(\boldsymbol{u}, \boldsymbol{v} \in U \Longrightarrow \boldsymbol{u}+\boldsymbol{v} \in U\)
    2. 对数乘封闭：\(\boldsymbol{u} \in U,\ \lambda \in \mathbb{R} \Longrightarrow \lambda\boldsymbol{u} \in U\)

    两条合起来等价于一条：\(\lambda\boldsymbol{u} + \boldsymbol{v} \in U\)。

    注意：「非空」这个条件不能省。空集对加法封闭（因为没有元素可加），但它不是子空间（没有零向量）。

    三个典型子空间¶

    子空间 定义 几何图像（\(n=3\)）
    \(\{\boldsymbol{0}\}\) 只有零向量 原点
    过原点的直线 \(\{\lambda \boldsymbol{v} : \lambda \in \mathbb{R}\}\) 一条直线
    过原点的平面 \(\{\lambda\boldsymbol{u} + \mu\boldsymbol{v}\}\) 一个平面

    「过原点」不能少

    平面 \(z = 1\)（不过原点的平面）不是子空间：它不含零向量。

    这是最常见的错误。记住：任何子空间必含零向量—— 取 \(\lambda = 0\) 即可，\(0\cdot\boldsymbol{u} = \boldsymbol{0}\)。

    六、和与直和¶

    两个子空间的和¶

    定义：\(U_1 + U_2 = \{\boldsymbol{u}_1 + \boldsymbol{u}_2 : \boldsymbol{u}_1 \in U_1,\ \boldsymbol{u}_2 \in U_2\}\)

    例如在 \(\mathbb{R}^3\) 中，取

    • \(U_1 = \{(x, 0, 0)\}\)：\(x\) 轴
    • \(U_2 = \{(0, y, 0)\}\)：\(y\) 轴

    则 \(U_1 + U_2 = \{(x, y, 0)\}\)：\(xy\) 平面。

    和为子空间的证明：设 \(\boldsymbol{u}_1+\boldsymbol{u}_2\) 和 \(\boldsymbol{v}_1+\boldsymbol{v}_2\) 是 \(U_1+U_2\) 中的两个元素，则

    \[ \lambda(\boldsymbol{u}_1+\boldsymbol{u}_2) + (\boldsymbol{v}_1+\boldsymbol{v}_2) = \underbrace{(\lambda\boldsymbol{u}_1 + \boldsymbol{v}_1)}_{\in U_1} + \underbrace{(\lambda\boldsymbol{u}_2 + \boldsymbol{v}_2)}_{\in U_2} \in U_1+U_2 \]

    （第一个因为 \(U_1\) 是子空间，第二个因为 \(U_2\) 是子空间。）故 \(U_1+U_2\) 是子空间。\(\blacksquare\)

    直和¶

    定义：若 \(U_1 + U_2\) 中的每个元素表示方式唯一，则称这个和为直和，记作

    \[ U_1 \oplus U_2 \]

    判定条件（很漂亮）：\(U_1 + U_2\) 是直和 当且仅当

    \[ U_1 \cap U_2 = \{\boldsymbol{0}\} \]

    证明思路：

    （\(\Rightarrow\)）设 \(U_1\cap U_2\) 中有非零元素 \(\boldsymbol{w}\)。那么零向量有两种表示：

    \[ \boldsymbol{0} = \boldsymbol{0} + \boldsymbol{0} = \boldsymbol{w} + (-\boldsymbol{w}) \]

    前者两个分量都在各自的子空间，后者也是（\(\boldsymbol{w}\in U_1\)，\(-\boldsymbol{w}\in U_2\)）。 表示不唯一，与直和定义矛盾。

    （\(\Leftarrow\)）设 \(\boldsymbol{u}_1+\boldsymbol{u}_2 = \boldsymbol{v}_1+\boldsymbol{v}_2\)，则

    \[ \boldsymbol{u}_1 - \boldsymbol{v}_1 = \boldsymbol{v}_2 - \boldsymbol{u}_2 \]

    左边在 \(U_1\)，右边在 \(U_2\)，所以两边都等于交集中的某个元素。 由 \(U_1\cap U_2 = \{\boldsymbol{0}\}\) 得 \(\boldsymbol{u}_1 = \boldsymbol{v}_1\)，\(\boldsymbol{u}_2 = \boldsymbol{v}_2\)，表示唯一。\(\blacksquare\)

    直和的直觉

    直和 = 「两块拼起来，不重叠」。

    想象 \(\mathbb{R}^2\) 中 \(x\) 轴与 \(y\) 轴：它们只交于原点，所以 \(\mathbb{R}^2 = \{(x,0)\} \oplus \{(0,y)\}\)，每个点 \((x,y)\) 的分解唯一。

    若换成 \(x\) 轴与直线 \(y = x\)：它们的交只有原点，也是直和。 但若换成 \(x\) 轴与 \(x\) 轴：交是整个 \(x\) 轴，不是直和。

    为什么「交不等于 \(\{\boldsymbol{0}\}\)」就意味着分解不唯一？

    以下图为例：\(\boldsymbol{w} \in U_1 \cap U_2\) 且 \(\boldsymbol{w} \neq \boldsymbol{0}\)，则零向量有两种写法：

    \[ \boldsymbol{0} = \underbrace{\boldsymbol{0}}_{\in U_1} + \underbrace{\boldsymbol{0}}_{\in U_2} \qquad\text{和}\qquad \boldsymbol{0} = \underbrace{\boldsymbol{w}}_{\in U_1} + \underbrace{(-\boldsymbol{w})}_{\in U_2} \]

    同一个零向量，两种分解——这就是「不唯一」。

    七、典型例题¶

    下面三道题覆盖了本节最常见的题型。建议先自己想，再看解答。

    例题 1：判断子空间（并找出几何图像）¶

    判断下列集合是否为 \(\mathbb{R}^3\) 的子空间：

    (a) \(U_a = \{(x,y,z) : x + 2y - z = 0\}\)

    (b) \(U_b = \{(x,y,z) : x + 2y - z = 1\}\)

    © \(U_c = \{(x,y,z) : x^2 + y^2 = z^2\}\)

    思路

    子空间判定只需两条：对加法封闭、对数乘封闭（并注意非空）。 实用技巧：先看是否含零向量——不含的立刻判否。

    解答

    (a) 是子空间。

    先验零向量：\(0 + 0 - 0 = 0\) ✓ 含零向量。

    设 \(\boldsymbol{u} = (x_1,y_1,z_1)\)、\(\boldsymbol{v} = (x_2,y_2,z_2)\) 都满足方程。

    加法：\(\boldsymbol{u}+\boldsymbol{v}\) 代入左边

    \[ (x_1+x_2) + 2(y_1+y_2) - (z_1+z_2) = \underbrace{(x_1+2y_1-z_1)}_{=0} + \underbrace{(x_2+2y_2-z_2)}_{=0} = 0 \;\checkmark \]

    数乘：对 \(\lambda\)，

    \[ \lambda x_1 + 2\lambda y_1 - \lambda z_1 = \lambda\underbrace{(x_1+2y_1-z_1)}_{=0} = 0 \;\checkmark \]

    因此是子空间。几何图像：过原点、法向量为 \((1,2,-1)\) 的平面，是一个 2 维子空间。

    (b) 不是子空间。

    代入零向量：\(0 + 0 - 0 = 0 \neq 1\)。不含零向量，立刻判否。

    这是「不过原点的平面」，它和 (a) 中的平面平行，但整体平移了。

    © 不是子空间。

    含零向量（\(0^2+0^2=0^2\) ✓），所以不能靠零向量判否，要验封闭性。

    取 \(\boldsymbol{u} = (0,1,1)\)（满足 \(0+1=1\) ✓）和 \(\boldsymbol{v} = (0,1,-1)\)（满足 \(0+1=1\) ✓）。则

    \[ \boldsymbol{u}+\boldsymbol{v} = (0,\,2,\,0) \]

    验证：\(0^2 + 2^2 = 4\)，但 \(z^2 = 0^2 = 0\)，\(4 \neq 0\) ✗

    所以加法不封闭，不是子空间。

    几何图像：\(x^2+y^2=z^2\) 是圆锥面（双锥），它明显不是「平坦」的，当然不是子空间。

    从这道题学到的

    集合形式 判断方式
    线性方程 \(= 0\) ✅ 通常是子空间（过原点）
    线性方程 \(= c \neq 0\) ❌ 不是（不含零向量）
    平方、乘积等非线性 ❌ 通常不是（用两个向量之和验证）

    第一行动：先代零向量。零向量不在，直接判否，省下一半时间。

    例题 2：求子空间的交与和¶

    设 \(U_1 = \{(x,y,z) : x = 0\}\)（即 \(yz\) 平面），\(U_2 = \{(x,y,z) : y = 0\}\)（即 \(xz\) 平面）。求 \(U_1 \cap U_2\) 与 \(U_1 + U_2\)，并判断和是否为直和。

    思路

    交 = 同时满足两个条件；和 = 把两个子空间的向量相加。 判断直和：看交是否为 \(\{\boldsymbol{0}\}\)。

    解答

    求交：同时满足 \(x = 0\) 与 \(y = 0\)，故

    \[ U_1 \cap U_2 = \{(0,0,z) : z \in \mathbb{R}\} = z\text{ 轴} \]

    这是一个 1 维子空间（不是 \(\{\boldsymbol{0}\}\)）。

    求和：

    \[ U_1 + U_2 = \{(0,y_1,z_1) + (x_2,0,z_2)\} = \{(x_2,\ y_1,\ z_1+z_2)\} \]

    由于 \(x_2, y_1\) 可取任意实数、\(z_1+z_2\) 也可取任意实数，所以

    \[ U_1 + U_2 = \mathbb{R}^3 \]

    判断直和：因为 \(U_1 \cap U_2 = z\) 轴 \(\neq \{\boldsymbol{0}\}\)，所以不是直和。

    验证「分解不唯一」：考察向量 \((0,0,5)\)，它有两种分解

    \[ (0,0,5) = \underbrace{(0,0,5)}_{\in U_1} + \underbrace{(0,0,0)}_{\in U_2} = \underbrace{(0,0,2)}_{\in U_1} + \underbrace{(0,0,3)}_{\in U_2} \]

    确实不唯一 ✓ 与「交不为 \(\{\boldsymbol{0}\}\)」的结论一致。

    注意维数关系

    本例中 \(\dim U_1 = \dim U_2 = 2\)，\(\dim(U_1+U_2) = 3\)，但 \(2+2 = 4 > 3\)。

    这不是矛盾——只有当和为直和时才有

    \[ \dim(U_1 \oplus U_2) = \dim U_1 + \dim U_2 \]

    一般情况正确的公式是

    \[ \dim(U_1 + U_2) = \dim U_1 + \dim U_2 - \dim(U_1 \cap U_2) \]

    本例验证：\(2 + 2 - 1 = 3\) ✓

    例题 3：证明题（抽象向量空间）¶

    设 \(U\) 与 \(W\) 都是向量空间 \(V\) 的子空间。证明 \(U \cap W\) 也是 \(V\) 的子空间。

    思路

    直接用判定法两条：非空 + 对线性组合封闭。

    解答

    非空：\(U\) 与 \(W\) 都是子空间，所以都含零向量。于是 \(\boldsymbol{0} \in U\) 且 \(\boldsymbol{0} \in W\)，故 \(\boldsymbol{0} \in U \cap W\)，交集非空 ✓

    对线性组合封闭：取任意 \(\boldsymbol{u}, \boldsymbol{v} \in U \cap W\) 和标量 \(\lambda\)。

    因为 \(\boldsymbol{u}, \boldsymbol{v} \in U\) 且 \(U\) 是子空间，所以

    \[ \lambda\boldsymbol{u} + \boldsymbol{v} \in U \]

    同理，因为 \(\boldsymbol{u}, \boldsymbol{v} \in W\) 且 \(W\) 是子空间，所以

    \[ \lambda\boldsymbol{u} + \boldsymbol{v} \in W \]

    两边都成立，因此

    \[ \lambda\boldsymbol{u} + \boldsymbol{v} \in U \cap W \]

    由判定法，\(U \cap W\) 是子空间。\(\blacksquare\)

    结论的适用范围

    这个证明没有用到任何关于「向量长什么样」的信息—— 只用到了 \(U\)、\(W\) 是子空间这一事实。

    所以结论对任意向量空间都成立：多项式空间的子空间之交、函数空间的子空间之交，同样是子空间。

    这正是第一节「抽象定义」的价值：证明一次，到处可用。

    并集不是子空间

    对比一下：\(U \cup W\) 一般不是子空间。

    反例：取 \(U = x\) 轴、\(W = y\) 轴。则 \((1,0) \in U \cup W\)，\((0,1) \in U \cup W\)， 但

    \[ (1,0) + (0,1) = (1,1) \notin U \cup W \]

    加法不封闭。

    记忆：交是子空间，并不是。

    九、用在哪些课程里¶

    机器人学 · 位姿与速度¶

    • 关节角向量 \(\boldsymbol{q} \in \mathbb{R}^n\) 是向量空间的元素
    • 末端位姿在任务空间中描述，与关节空间之间通过雅可比映射
    • 雅可比的零空间（\(J\dot{\boldsymbol{q}} = \boldsymbol{0}\)）对应奇异位形——机械臂失去某些方向的运动能力

    模式识别 · 特征空间¶

    • 一个样本是特征空间 \(\mathbb{R}^d\) 中的一个点，\(d\) 是特征维数
    • 降维就是找一个低维子空间来近似数据（PCA 的核心）
    • 特征提取的本质：选择用哪个子空间坐标来表示数据

    现代数字信号处理 · 信号空间¶

    • 离散信号 \(\{x[n]\}\) 是向量空间 \(\mathbb{R}^N\)（或 \(\mathbb{C}^N\)）的元素
    • 傅里叶变换 = 换一组基（用复指数作为基向量）
    • 子空间方法（MUSIC 等）把观测空间分为信号子空间与噪声子空间，二者是直和

    智能传感与信息处理 · 状态空间¶

    • 系统状态 \(\boldsymbol{x} \in \mathbb{R}^n\) 是状态空间的元素
    • 可观性 = 能否从输出重构整个状态空间
    • 可控性 = 能否用输入到达状态空间中任意一点

    十、自测¶

    Q1 判断：\(U = \{(x, y, z) : x + y + z = 0\}\) 是不是 \(\mathbb{R}^3\) 的子空间？

    提示

    检查两条：对加法封闭？对数乘封闭？

    解答

    是。

    设 \(\boldsymbol{u} = (x_1,y_1,z_1)\) 与 \(\boldsymbol{v} = (x_2,y_2,z_2)\) 都满足坐标和为 0。

    加法：\(\boldsymbol{u}+\boldsymbol{v} = (x_1+x_2,\ y_1+y_2,\ z_1+z_2)\)，坐标和为 \((x_1+y_1+z_1) + (x_2+y_2+z_2) = 0 + 0 = 0\) ✓

    数乘：\(\lambda\boldsymbol{u}\) 的坐标和为 \(\lambda(x_1+y_1+z_1) = 0\) ✓

    非空（含零向量），故是子空间。

    几何图像：这是过原点、法向量为 \((1,1,1)\) 的平面。 它正是下面 Q2 中两个子空间的直和。

    Q2 设 \(U_1 = \{(x,0,0)\}\)，\(U_2 = \{(0,y,z)\}\)。\(U_1 + U_2\) 是直和吗？

    提示

    先求交，再看是否为 \(\{\boldsymbol{0}\}\)。

    解答

    是直和。

    求交：若 \(\boldsymbol{w} \in U_1 \cap U_2\)，则 \(\boldsymbol{w}\) 形如 \((x,0,0)\) 又形如 \((0,y,z)\)。 比较分量得 \(x = 0\)、\(y = z = 0\)，所以

    \[ U_1 \cap U_2 = \{\boldsymbol{0}\} \]

    由判定条件，\(U_1 + U_2 = U_1 \oplus U_2\)。

    验证和是什么：\(U_1+U_2 = \{(x,y,z)\} = \mathbb{R}^3\)。 即 \(\mathbb{R}^3 = x\text{轴} \oplus yz\text{平面}\)，每个向量的分解唯一（就是分量的重新组合）。

    Q3 判断：\(P_n\)（所有次数恰好为 \(n\) 的多项式，\(n \geq 1\)，加上零多项式）是不是向量空间？

    提示

    试试两个 \(n\) 次多项式相加。再试数乘。

    解答

    不是。

    关键反例：取 \(p(x) = x^n\)，\(q(x) = -x^n\)。二者都是 \(n\) 次多项式，但

    \[ p(x) + q(x) = 0 \]

    得到的是零多项式。虽然我把零多项式也加进了集合，但加法不封闭还不够—— 换个例子：\(p(x)=x^n+1\)，\(q(x)=-x^n\)，则

    \[ p(x)+q(x) = 1 \]

    这是 0 次多项式，不在集合中（当 \(n\geq1\) 时）。故加法不封闭，不是向量空间。

    对比：次数不超过 \(n\) 的多项式 \(P_n = \{a_0 + a_1x + \cdots + a_nx^n\}\) 是向量空间—— 因为相加后次数不会超过 \(n\)。

    教训：「恰好」与「不超过」的区别，就是封闭与否的区别。

    Q4 证明：子空间必含零向量。

    提示

    用数乘封闭性，取标量 0。

    解答

    设 \(U\) 是非空子空间，取任意 \(\boldsymbol{u} \in U\)（非空保证存在这样的元素）。

    由数乘封闭性，对任意标量 \(\lambda\) 都有 \(\lambda\boldsymbol{u} \in U\)。取 \(\lambda = 0\)：

    \[ 0 \cdot \boldsymbol{u} = \boldsymbol{0} \in U \]

    所以零向量属于 \(U\)。\(\blacksquare\)

    用途：这是一个快速判否的工具。 看到「不过原点的平面」「不含零向量的集合」，立刻能断定它不是子空间，不用再验封闭性。
