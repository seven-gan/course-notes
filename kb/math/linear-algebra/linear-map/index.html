    线性映射与矩阵¶

    前三页建立了「向量空间」这套语言。但线性代数真正的主角不是向量，而是映射：

    向量空间之间的「保持线性结构」的映射，以及它们的矩阵表示。

    这里有一个关键认识，值得先把话说透：

    矩阵不是数字表格，而是线性映射的坐标表示

    这是本节最重要的一句话。

    线性映射是客观对象（一个几何/物理作用，比如旋转、投影、求导）； 矩阵是它在一组基下的「记账方式」。

    换了基，矩阵就变了，但映射本身没变。

    明白这一点，才能理解为什么「相似矩阵有相同特征值」， 以及为什么傅里叶变换、Z 变换可以看成「换一组基看同一个系统」。

    一、线性映射的定义¶

    定义：设 \(T: V \to W\) 是向量空间之间的映射。若对任意 \(\boldsymbol{u},\boldsymbol{v} \in V\) 与标量 \(\lambda\)，都有

    \[ T(\boldsymbol{u}+\boldsymbol{v}) = T\boldsymbol{u} + T\boldsymbol{v} \qquad\text{（可加性）} \]
    \[ T(\lambda\boldsymbol{u}) = \lambda\, T\boldsymbol{u} \qquad\text{（齐次性）} \]

    则称 \(T\) 是线性映射。

    两条合起来等价于一条：

    \[ T(\lambda\boldsymbol{u}+\boldsymbol{v}) = \lambda T\boldsymbol{u} + T\boldsymbol{v} \]

    立即得到的推论¶

    性质 说明
    \(T\boldsymbol{0} = \boldsymbol{0}\) 取 \(\lambda=0\) 于 \(T(\lambda\boldsymbol{0}) = \lambda T\boldsymbol{0}\)
    \(T(-\boldsymbol{u}) = -T\boldsymbol{u}\) 取 \(\lambda=-1\)
    保持线性组合 \(T\big(\sum c_k\boldsymbol{v}_k\big) = \sum c_k T\boldsymbol{v}_k\)

    「线性」与「正比」是两回事

    中学说的「正比」（\(y = kx\)）是一类特殊线性映射。 但也有不是线性的映射看起来像正比：

    \[ T(x) = 2x + 1 \]

    它不能「过零」——\(T(0) = 1 \neq 0\)。用第一条推论即可判否。

    这就是为什么神经网络里的「仿射层」\(\boldsymbol{y} = W\boldsymbol{x} + \boldsymbol{b}\) 严格说不是线性的（除非 \(\boldsymbol{b}=\boldsymbol{0}\)）， 它是仿射（线性 + 平移）。

    三个典型例子¶

    例 1：旋转（\(\mathbb{R}^2 \to \mathbb{R}^2\)）

    \[ T\begin{bmatrix} x \\ y\end{bmatrix} = \begin{bmatrix} x\cos\theta - y\sin\theta \\ x\sin\theta + y\cos\theta \end{bmatrix} \]

    例 2：求导（多项式空间 \(P_n \to P_{n-1}\)）

    \[ T(p) = p' \]

    线性性来自求导的运算法则：\((p+q)' = p'+q'\) 与 \((\lambda p)' = \lambda p'\)。

    这个例子说明什么

    求导是线性映射！ 这一点在信号处理里极为重要—— 微分方程可以写成线性算子方程，于是能用「线性系统」的整套工具分析。

    例 3：内积（固定一个变量）

    固定 \(\boldsymbol{u} \in V\)，定义 \(\varphi(\boldsymbol{x}) = \langle\boldsymbol{x},\boldsymbol{u}\rangle\)。 这是 \(V \to \mathbb{R}\)（或 \(\mathbb{C}\)）的线性映射，称为线性泛函。

    二、矩阵：线性映射的坐标表示¶

    现在把抽象定义「落地」。

    设 \(V\) 的基为 \(\{\boldsymbol{v}_1,\dots,\boldsymbol{v}_n\}\)，\(W\) 的基为 \(\{\boldsymbol{w}_1,\dots,\boldsymbol{w}_m\}\)。

    关键：只要知道 \(T\) 把基向量映到哪里，就完全确定了 \(T\)—— 因为任意 \(\boldsymbol{v}\) 都是基的线性组合，而 \(T\) 保持线性组合：

    \[ \boldsymbol{v} = \sum_k c_k \boldsymbol{v}_k \quad\Longrightarrow\quad T\boldsymbol{v} = \sum_k c_k\, T\boldsymbol{v}_k \]

    做法：把每个 \(T\boldsymbol{v}_k\) 用 \(W\) 的基表示出来

    \[ T\boldsymbol{v}_k = \sum_{j=1}^m a_{jk}\,\boldsymbol{w}_j \]

    把系数 \(a_{jk}\) 按列排列，得到矩阵 \(A = (a_{jk})\)。于是

    \[ T\boldsymbol{v} = \sum_k c_k \sum_j a_{jk}\boldsymbol{w}_j = \sum_j \left(\sum_k a_{jk} c_k\right)\boldsymbol{w}_j \]

    括号里正是矩阵乘法的第 \(j\) 个分量：

    \[ \boxed{\ \text{坐标}(T\boldsymbol{v}) = A\,\text{坐标}(\boldsymbol{v})\ } \]

    矩阵乘法的定义从哪来

    很多人觉得矩阵乘法规则（「行乘列」）很突兀。现在清楚了：

    它就是「线性映射的复合」在坐标下的表现。

    设 \(T: V\to W\)，\(S: W\to U\)，矩阵分别为 \(A\)、\(B\)。 则复合 \(S\circ T\) 的矩阵是 \(BA\)。

    验证一下维度：\(\boldsymbol{x} \in V\) 的坐标是 \(n\) 维。 \(T\) 先作用得 \(A\boldsymbol{x}\)（\(m\) 维），再作用 \(S\) 得 \(B(A\boldsymbol{x})\)。 所以「先 \(A\) 后 \(B\)」写成矩阵就是 \(BA\) —— 注意顺序是反的， 因为作用顺序是从右往左读。

    「矩阵表示」依赖于基的选择¶

    这是最容易忽视的一点。同一个线性映射，换一组基，矩阵就变。

    关系式：设旧基下矩阵为 \(A\)，新基下为 \(B\)，两组基之间的过渡矩阵为 \(P\)（旧坐标 \(= P\cdot\) 新坐标）。则

    \[ \boxed{\ B = P^{-1} A P\ } \]

    这样的 \(A\) 与 \(B\) 称为相似。

    相似矩阵有相同的特征值——这一点在特征值那一页会用到， 而它的根本原因就是：它们描述的是同一个映射。

    三、零空间与值域¶

    这两个子空间刻画映射的「信息行为」。

    定义：

    \[ \operatorname{null} T = \{\boldsymbol{v} : T\boldsymbol{v} = \boldsymbol{0}\} \qquad\text{（零空间，又称核）} \]
    \[ \operatorname{range} T = \{T\boldsymbol{v} : \boldsymbol{v} \in V\} \qquad\text{（值域，又称象）} \]

    两者都是子空间（留作自测）。

    直观理解¶

    三个基本判据¶

    性质 等价条件
    单射（一一对应） \(\operatorname{null}T = \{\boldsymbol{0}\}\)
    满射（能覆盖 \(W\)） \(\operatorname{range}T = W\)
    可逆（同构） 单射且满射，此时 \(\dim V = \dim W\)

    「单射 \(\iff\) 零空间只有零向量」的证明：

    （\(\Leftarrow\)）设 \(T\boldsymbol{u} = T\boldsymbol{v}\)，则 \(T(\boldsymbol{u}-\boldsymbol{v}) = \boldsymbol{0}\)， 所以 \(\boldsymbol{u}-\boldsymbol{v} \in \operatorname{null}T = \{\boldsymbol{0}\}\)，即 \(\boldsymbol{u}=\boldsymbol{v}\) ✓

    （\(\Rightarrow\)）设 \(T\) 单射，取 \(\boldsymbol{v} \in \operatorname{null}T\)，则 \(T\boldsymbol{v} = \boldsymbol{0} = T\boldsymbol{0}\)， 由单射性得 \(\boldsymbol{v} = \boldsymbol{0}\) ✓

    为什么这个判据很实用

    判断「映射是否单射」要比较「不同输入是否给出不同输出」， 这需要检查无穷多对输入。

    但上面的判据把它化成了一个齐次方程是否有非零解： 只需看 \(\operatorname{null}T\) 里有没有非零向量。从无穷检查变成一次代数判定。

    四、秩-零化度定理（重述与矩阵版本）¶

    上一页（线性无关与基）给过这个定理，这里补充它的矩阵形式与实际意义。

    \[ \dim V = \dim(\operatorname{null}T) + \dim(\operatorname{range}T) \]

    矩阵版本：设 \(A\) 是 \(m\times n\) 矩阵，看作映射 \(\mathbb{R}^n \to \mathbb{R}^m\)，则

    \[ n = \dim(\operatorname{null}A) + \operatorname{rank}(A) \]

    即

    \[ \boxed{\ \operatorname{rank}(A) = n - \dim(\operatorname{null}A)\ } \]

    两种常见情形¶

    情形 结论 工程含义
    \(m > n\)（高瘦，方程多于未知数） 零空间非平凡，不可能单射 超定方程组一般无解 → 用最小二乘
    \(n > m\)（矮胖，未知数多于方程） 值域维数 \(\leq m < n\)，不可能满射 欠定方程组有无穷多解 → 取最小范数解
    \(m = n\)（方阵） 可能可逆 可逆 \(\iff\) \(\operatorname{rank} = n\) \(\iff\) \(\det \neq 0\)

    这解释了为什么工程问题总要用「最小二乘」或「伪逆」

    只要不是恰好可逆的方阵，就必然要面对「无解」或「多解」。

    • 无解（高瘦）→ 投影到列空间，求最小二乘解（上一页的内容）
    • 多解（矮胖）→ 在所有解中取范数最小的（这需要伪逆）

    这两条路都通向伪逆 \(A^+\)，是机器人逆运动学、稀疏传感、 病态反问题的共同基础。

    五、典型例题¶

    例题 1：写出线性映射的矩阵¶

    定义 \(T: \mathbb{R}^2 \to \mathbb{R}^3\) 为

    \[ T\begin{bmatrix} x \\ y \end{bmatrix} = \begin{bmatrix} x + y \\ 2x \\ y - x \end{bmatrix} \]

    (a) 验证 \(T\) 是线性的。

    (b) 写出 \(T\) 在标准基下的矩阵。

    思路

    线性性按定义验证；矩阵的列就是「基向量的像」。

    解答

    (a) 验证线性性

    设 \(\boldsymbol{u} = (x_1,y_1)\)、\(\boldsymbol{v} = (x_2,y_2)\)，标量 \(\lambda\)。

    \[ T(\lambda\boldsymbol{u}+\boldsymbol{v}) = T(\lambda x_1+x_2,\ \lambda y_1+y_2) \]

    代入定义（各分量分别计算）：

    \[ = \begin{bmatrix} (\lambda x_1+x_2)+(\lambda y_1+y_2) \\ 2(\lambda x_1+x_2) \\ (\lambda y_1+y_2)-(\lambda x_1+x_2)\end{bmatrix} \]

    而

    \[ \lambda T\boldsymbol{u} + T\boldsymbol{v} = \lambda\begin{bmatrix} x_1+y_1\\2x_1\\y_1-x_1\end{bmatrix} + \begin{bmatrix}x_2+y_2\\2x_2\\y_2-x_2\end{bmatrix} \]
    \[ = \begin{bmatrix} \lambda x_1+\lambda y_1 + x_2+y_2 \\ 2\lambda x_1 + 2x_2 \\ \lambda y_1-\lambda x_1 + y_2-x_2\end{bmatrix} \]

    两式逐分量相等 ✓ 所以 \(T\) 线性。

    （更简洁的做法）：注意到每个输出分量都是输入的一次齐次表达式 （没有常数项、没有乘积项），这直接保证线性。

    (b) 求矩阵

    矩阵的第 \(k\) 列 = 第 \(k\) 个基向量的像。

    \[ T\boldsymbol{e}_1 = T(1,0) = \begin{bmatrix}1\\2\\-1\end{bmatrix}, \qquad T\boldsymbol{e}_2 = T(0,1) = \begin{bmatrix}1\\0\\1\end{bmatrix} \]

    所以

    \[ A = \begin{bmatrix} 1 & 1 \\ 2 & 0 \\ -1 & 1 \end{bmatrix} \]

    验证：用矩阵算 \((x,y) = (3,2)\)：

    \[ A\begin{bmatrix}3\\2\end{bmatrix} = \begin{bmatrix}1\cdot3+1\cdot2\\2\cdot3+0\cdot2\\-1\cdot3+1\cdot2\end{bmatrix} = \begin{bmatrix}5\\6\\-1\end{bmatrix} \]

    直接代入定义：\((x+y, 2x, y-x) = (5, 6, -1)\) ✓ 一致。

    求矩阵的通用方法

    矩阵的每一列，就是对应基向量的像。

    所以求矩阵只需做 \(n\) 次计算（\(n\) 是定义域维数）， 不必背公式。

    例题 2：求零空间与值域¶

    设 \(A = \begin{bmatrix} 1 & 2 & 3 \\ 2 & 4 & 6 \end{bmatrix}\)，看作 \(\mathbb{R}^3 \to \mathbb{R}^2\) 的映射。

    (a) 求 \(\operatorname{rank}(A)\)。

    (b) 求零空间的维数。

    © 这个映射可能单射吗？

    思路

    注意第二行是第一行的 2 倍，两行线性相关。

    解答

    (a) 求秩

    观察：第二行 \(= 2 \times\) 第一行。所以

    \[ \operatorname{rank}(A) = 1 \]

    几何图像：值域是 \(\mathbb{R}^2\) 中由 \((1,2)\) 张成的一条直线。

    (b) 零空间维数

    由秩-零化度定理（\(n = 3\)）：

    \[ \dim(\operatorname{null}A) = 3 - \operatorname{rank}(A) = 3 - 1 = 2 \]

    具体求出来验证：解 \(A\boldsymbol{x}=\boldsymbol{0}\)，即

    \[ x + 2y + 3z = 0 \]

    （第二行是它的 2 倍，冗余。）

    这是一张过原点的平面。取两个线性无关的解：

    \[ \boldsymbol{v}_1 = (-2,1,0), \qquad \boldsymbol{v}_2 = (-3,0,1) \]

    验证 \(A\boldsymbol{v}_1 = (-2+2, -4+4) = (0,0)\) ✓， \(A\boldsymbol{v}_2 = (-3+3, -6+6) = (0,0)\) ✓。 二者线性无关，故零空间维数 \(=2\) ✓ 与定理一致。

    © 可能单射吗

    不可能。因为 \(\operatorname{null}A \neq \{\boldsymbol{0}\}\) （维数 2，含大量非零向量）。

    物理上：3 维输入被压到 1 维，必然丢失 2 维信息。 具体地，\(\boldsymbol{v}_1\) 与 \(\boldsymbol{v}_2\) 是「看不见的输入」—— 它们不产生任何输出，所以从输出无法区分「\(\boldsymbol{x}\)」与「\(\boldsymbol{x}+\boldsymbol{v}_1\)」。

    注意：两行真的不成比例吗？

    它们成比例（后者是前者的 2 倍），所以两行线性相关，秩为 1。

    判断矩阵的秩，先看行（或列）之间有没有倍数/线性组合关系， 这比机械地做行变换快得多。

    例题 3：相似变换¶

    设 \(A = \begin{bmatrix} 4 & 2 \\ 1 & 3\end{bmatrix}\)，取 \(P = \begin{bmatrix} 2 & 1 \\ 1 & 1\end{bmatrix}\)。

    (a) 求 \(P^{-1}\)。

    (b) 计算 \(B = P^{-1}AP\)。

    © 验证 \(A\) 与 \(B\) 的迹相等。

    思路

    \(2\times2\) 矩阵求逆用公式 \(\frac{1}{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}\)。

    解答

    (a) 求逆

    \[ \det P = 2\cdot1 - 1\cdot1 = 1 \]
    \[ P^{-1} = \frac{1}{1}\begin{bmatrix} 1 & -1 \\ -1 & 2\end{bmatrix} = \begin{bmatrix} 1 & -1 \\ -1 & 2\end{bmatrix} \]

    (b) 计算 \(B = P^{-1}AP\)

    先算 \(AP\)：

    \[ AP = \begin{bmatrix}4&2\\1&3\end{bmatrix}\begin{bmatrix}2&1\\1&1\end{bmatrix} = \begin{bmatrix}4\cdot2+2\cdot1 & 4\cdot1+2\cdot1\\ 1\cdot2+3\cdot1 & 1\cdot1+3\cdot1\end{bmatrix} = \begin{bmatrix}10&6\\5&4\end{bmatrix} \]

    再左乘 \(P^{-1}\)：

    \[ B = \begin{bmatrix}1&-1\\-1&2\end{bmatrix}\begin{bmatrix}10&6\\5&4\end{bmatrix} = \begin{bmatrix}10-5 & 6-4\\ -10+10 & -6+8\end{bmatrix} = \begin{bmatrix}5&2\\0&2\end{bmatrix} \]

    © 验证迹相等

    \[ \operatorname{tr}(A) = 4+3 = 7, \qquad \operatorname{tr}(B) = 5+2 = 7 \;\checkmark \]

    更进一步，两者的行列式也相等（迹与行列式都是相似不变量）：

    \[ \det A = 12-2 = 10, \qquad \det B = 5\cdot2 - 2\cdot0 = 10 \;\checkmark \]

    从这道题看到的

    \(B\) 是上三角矩阵，比 \(A\) 更容易分析 （对角元直接就是特征值：\(5\) 与 \(2\)）。

    这正是「找一组好基把矩阵变简单」的动机—— 如果能让 \(B\) 变成对角矩阵，问题就彻底简化了， 这叫可对角化，是下一节（特征值）的主题。

    例题 4：证明秩的对称性¶

    证明：对任意 \(m\times n\) 矩阵 \(A\)，有 \(\operatorname{rank}(A) = \operatorname{rank}(A^\top)\)。

    「行秩 = 列秩」。

    思路

    可以用「矩阵乘法不增加秩」这一事实： \(\operatorname{rank}(XY) \leq \min(\operatorname{rank}X, \operatorname{rank}Y)\)。 或者用线性映射论证。

    解答

    思路一（用线性映射的像与核）

    考虑 \(A\) 的列空间 \(\operatorname{col}(A) = \operatorname{range}A \subseteq \mathbb{R}^m\)。 按定义

    \[ \operatorname{rank}(A) = \dim\operatorname{col}(A) \]

    而 \(A^\top\) 的列空间是 \(\mathbb{R}^n\) 的子空间。关键观察是：

    \[ \operatorname{col}(A)^\perp = \operatorname{null}(A^\top) \]

    验证：\(\boldsymbol{y} \in \operatorname{col}(A)^\perp\) \(\iff\) \(\boldsymbol{y}\) 与 \(A\) 的每一列正交 \(\iff\) \(A^\top\boldsymbol{y} = \boldsymbol{0}\) \(\iff\) \(\boldsymbol{y} \in \operatorname{null}(A^\top)\) ✓

    于是用上一节的正交补维数公式（\(A^\top: \mathbb{R}^m \to \mathbb{R}^n\)）：

    \[ \dim\operatorname{col}(A)^\perp = m - \operatorname{rank}(A) \]

    另一方面

    \[ \dim\operatorname{null}(A^\top) = m - \operatorname{rank}(A^\top) \]

    （此处用秩-零化度定理，输入维数是 \(m\)。）

    两式相等，得

    \[ m - \operatorname{rank}(A) = m - \operatorname{rank}(A^\top) \]

    故 \(\operatorname{rank}(A) = \operatorname{rank}(A^\top)\)。\(\blacksquare\)

    这个结论的实用价值

    「行秩 = 列秩」让我们可以选好算的那一边。

    • 求秩时，行变换（高斯消元）比列变换方便 → 用行秩
    • 但从几何意义看，\(\operatorname{rank}(A) = \dim\)（值域）， 是列张成的空间维数

    两者相等这件事本身不是显然的，它保证了「秩」这个概念是良定义的。

    推论：\(\operatorname{rank}(A) \leq \min(m,n)\) —— 秩不会超过行数，也不会超过列数。这与图 4 的形状分析一致。

    六、用在哪些课程里¶

    机器人学 · 雅可比矩阵与奇异位形¶

    • 末端速度与关节速度的关系 \(\boldsymbol{v} = J(\boldsymbol{q})\dot{\boldsymbol{q}}\) 就是一个线性映射（在某位形下），\(J\) 是它的矩阵
    • 奇异位形：\(\operatorname{rank}J < \min(6,n)\)，此时
    • 零空间非平凡 → 存在关节运动而末端不动（失去某些方向的控制）
    • 值域不能覆盖全部方向 → 某些末端运动无法实现
    • 冗余机械臂（\(n > 6\)）的零空间被用来避障、避开关节极限

    模式识别 · 特征降维的线性映射视角¶

    • 线性降维就是一个线性映射 \(T: \mathbb{R}^d \to \mathbb{R}^k\)（\(k < d\)）
    • 由秩-零化度定理，必然有 \(d - k\) 维信息被丢弃（零空间）
    • PCA 选择让「丢弃的信息尽可能少」的那个映射—— 具体说，让投影后的方差最大
    • 线性判别分析（LDA）则是希望类间散度大、类内散度小

    现代数字信号处理 · LTI 系统是线性映射（而且是时不变的）¶

    • 一个 LTI 系统的输入输出关系就是从输入信号空间到输出信号空间的一个线性映射
    • 卷积正是这个映射的显式形式：\(y = h * x\)
    • 换到频域后，这个线性映射变成逐点相乘—— 这就是「换一组基（复指数基）让映射变简单」的典型例子
    • 与矩阵的相似变换完全同构：同一个系统的不同表示

    智能传感与信息处理 · 可观性与可控性¶

    概念 判据 含义
    可控性 可控性矩阵列满秩 能否用输入把状态送到任意目标
    可观性 可观性矩阵列满秩 能否从输出推断出全部状态
    不可观方向 可观性矩阵的零空间 那些状态不产生任何输出

    不可观 = 零空间非平凡，这与例题 2 的逻辑完全一样： 「看不见的输入」对应「看不见的状态」。

    七、自测¶

    Q1 判断 \(T(x,y) = (x^2,\ y)\) 是否线性。

    提示

    取 \(\lambda = 2\) 检验齐次性。

    解答

    不是线性的。

    检验齐次性：取 \((x,y)=(1,1)\)，\(\lambda = 2\)。

    左边：

    \[ T(2(1,1)) = T(2,2) = (2^2,\ 2) = (4, 2) \]

    右边：

    \[ 2T(1,1) = 2(1^2, 1) = (2, 2) \]

    \((4,2) \neq (2,2)\) ✗ 齐次性不成立。

    快速判据：输出分量里出现了输入的二次项 \(x^2\)， 不可能是线性的。（线性映射的每个输出分量必须是输入的一次齐次组合。）

    Q2 设 \(A\) 是 \(4\times 3\) 矩阵，\(\operatorname{rank}(A) = 3\)。求 \(\dim\operatorname{null}A\)，并判断映射是否单射。

    提示

    用 \(n = \dim\operatorname{null} + \operatorname{rank}\)，其中 \(n\) 是输入维数。

    解答

    零空间维数：

    \[ \dim\operatorname{null}A = n - \operatorname{rank}(A) = 3 - 3 = 0 \]

    所以 \(\operatorname{null}A = \{\boldsymbol{0}\}\)。

    单射：是。因为零空间只有零向量。

    几何含义：3 维输入被完整地嵌入 4 维输出空间（没有信息损失）。 值域是 \(\mathbb{R}^4\) 中的一个 3 维子空间（超平面）。

    注意：它是单射但不是满射（值域只有 3 维，填不满 4 维空间）。 这说明「单射」与「满射」是独立的条件——只有方阵才可能两者兼得。

    从工程角度：这类映射对应超定方程组有唯一最小二乘解的情形 （列满秩，\(A^\top A\) 可逆）。

    Q3 设 \(T: \mathbb{R}^5 \to \mathbb{R}^5\) 线性，且 \(\operatorname{null}T\) 的维数是 2。\(T\) 是否可逆？

    提示

    可逆要求单射且满射。

    解答

    不可逆。

    \(\dim\operatorname{null}T = 2 > 0\)，说明零空间含非零向量， 所以 \(T\) 不是单射，因而不可逆。

    补充：值域维数

    \[ \dim\operatorname{range}T = 5 - 2 = 3 \]

    值域只有 3 维（填不满 5 维空间），所以 \(T\) 也不是满射。

    一般结论：对方阵（\(\dim V = \dim W\)）， 「单射」「满射」「可逆」三者等价。所以检查任一条即可。

    但注意：这个等价性只对方阵成立。对非方阵， 单射与满射可能一个成立一个不成立（见 Q2）。

    Q4 设 \(A\) 与 \(B\) 是相似矩阵（\(B = P^{-1}AP\)）。证明它们的迹相等。

    提示

    用迹的循环性质 \(\operatorname{tr}(XY) = \operatorname{tr}(YX)\)。

    解答

    直接计算：

    \[ \operatorname{tr}(B) = \operatorname{tr}(P^{-1}AP) \]

    把 \(P^{-1}A\) 看成一个整体 \(X\)，\(P\) 看成 \(Y\)，用循环性质 \(\operatorname{tr}(XY) = \operatorname{tr}(YX)\)：

    \[ \operatorname{tr}(P^{-1}AP) = \operatorname{tr}\big((P^{-1}A)P\big) = \operatorname{tr}\big(P(P^{-1}A)\big) \]

    而

    \[ P(P^{-1}A) = (PP^{-1})A = A \]

    所以

    \[ \operatorname{tr}(B) = \operatorname{tr}(A) \qquad\blacksquare \]

    同样的方法可证：\(\det(A) = \det(B)\)（用 \(\det(XY) = \det X\det Y\)）。

    为什么这些都相等：因为迹与行列式都是相似不变量—— 它们只依赖线性映射本身，不依赖基的选择。 特征值也如此（下一节会证），这正是「相似矩阵特征值相同」的根源。
