    范数与内积¶

    前面讲的向量空间只有加法和数乘两种运算。但你可能已经注意到一个问题：

    在这样的空间里，说不出「两个向量有多接近」，也说不出「一个向量有多长」。

    「长度」「角度」「垂直」这些概念，需要额外的结构才能定义。这个结构就是内积。

    内积一旦引入，整个几何就长出来了：

    引入的概念 依赖
    长度（范数） 内积 \(\lVert\boldsymbol{v}\rVert = \sqrt{\langle\boldsymbol{v},\boldsymbol{v}\rangle}\)
    垂直（正交） 内积 \(\langle\boldsymbol{u},\boldsymbol{v}\rangle = 0\)
    投影 用内积把向量分解
    最佳逼近 投影的推论

    对工科来说，这一页是最小二乘、PCA、相关分析、匹配滤波的共同基础。

    一、内积：给向量空间加上「角度」¶

    定义：向量空间 \(V\) 上的内积是一个函数，把每对向量 \(\boldsymbol{u},\boldsymbol{v}\) 映射为一个数 \(\langle \boldsymbol{u},\boldsymbol{v}\rangle\)，满足三条内积公理：

    # 公理 名称 含义
    1 \(\langle \boldsymbol{u},\boldsymbol{v}\rangle = \overline{\langle \boldsymbol{v},\boldsymbol{u}\rangle}\) 共轭对称 交换后取共轭（实数为相等）
    2 \(\langle \lambda\boldsymbol{u}+\mu\boldsymbol{w},\boldsymbol{v}\rangle = \lambda\langle \boldsymbol{u},\boldsymbol{v}\rangle + \mu\langle \boldsymbol{w},\boldsymbol{v}\rangle\) 对第一元线性 分配与齐次
    3 \(\langle \boldsymbol{v},\boldsymbol{v}\rangle \geq 0\)，且 \(=0\) 当且仅当 \(\boldsymbol{v}=\boldsymbol{0}\) 正定性 自己和自己内积非负

    第 1 条为什么要取共轭

    因为在复向量空间上，如果不取共轭，第 3 条就无法成立。

    试想复数向量 \(\boldsymbol{v} = (i)\)（1 维复向量）。若定义 \(\langle\boldsymbol{u},\boldsymbol{v}\rangle = \sum u_k v_k\)（不取共轭），则

    \[ \langle \boldsymbol{v},\boldsymbol{v}\rangle = i \cdot i = -1 < 0 \]

    出现了负的「长度平方」，与第 3 条矛盾。

    所以复内积约定第 2 个分量取共轭：

    \[ \langle \boldsymbol{u},\boldsymbol{v}\rangle = \sum_k u_k \overline{v_k} \]

    此时 \(\langle\boldsymbol{v},\boldsymbol{v}\rangle = i \cdot \overline{i} = i \cdot (-i) = 1 > 0\)

    在实数域上 \(\overline{v_k} = v_k\)，共轭无影响——因此本节所有结论对实向量空间都更简洁。

    两个标准例子¶

    例 1：\(\mathbb{R}^n\) 上的点积

    \[ \langle \boldsymbol{u},\boldsymbol{v}\rangle = \sum_{k=1}^n u_k v_k \]

    例 2：函数空间上的积分内积

    在 \(C[0,1]\)（区间 \([0,1]\) 上的连续函数）上定义

    \[ \langle f,g\rangle = \int_0^1 f(x)g(x)\,\mathrm{d}x \]

    验证第 3 条：\(\langle f,f\rangle = \int_0^1 f(x)^2\,\mathrm{d}x \geq 0\)， 且等号只在 \(f \equiv 0\) 时成立（因为非负连续函数的积分为零必然是恒零函数）

    这个积分内积为什么重要

    它让函数也能谈「角度」和「垂直」。

    傅里叶分析的核心就是这个内积：不同频率的正弦波满足

    \[ \int_0^{T} \sin(2\pi m t/T)\sin(2\pi n t/T)\,\mathrm{d}t = 0 \quad (m \neq n) \]

    即不同频率互相正交。这正是傅里叶级数能「分解」信号的根源—— 在一组正交基上求坐标，就是投影。

    二、范数：内积给出的「长度」¶

    定义：由内积诱导的范数为

    \[ \lVert \boldsymbol{v}\rVert = \sqrt{\langle \boldsymbol{v},\boldsymbol{v}\rangle} \]

    直观：这就是中学「长度」概念在一般向量空间上的推广。

    为什么用平方根¶

    因为内积是双线性的，而长度应当是线性缩放的：

    \[ \langle \lambda\boldsymbol{v}, \lambda\boldsymbol{v}\rangle = \lambda\overline{\lambda}\langle \boldsymbol{v},\boldsymbol{v}\rangle = |\lambda|^2 \lVert\boldsymbol{v}\rVert^2 \]

    两边开方得 \(\lVert\lambda\boldsymbol{v}\rVert = |\lambda|\,\lVert\boldsymbol{v}\rVert\)—— 数乘 \(|\lambda|\) 倍，长度就变为 \(|\lambda|\) 倍 ✓ 这符合直觉。 若不取平方根，缩放规律就变成 \(|\lambda|^2\)，不再与几何一致。

    常用范数（不限于内积诱导）¶

    在 \(\mathbb{R}^n\) 里还有几种常用范数，它们不由内积产生，但工程中同样重要：

    名称 定义 特点
    1-范数 \(\lVert\boldsymbol{v}\rVert_1 = \sum_i \lvert v_i\rvert\) 稀疏性（lasso 正则）
    2-范数 \(\lVert\boldsymbol{v}\rVert_2 = \sqrt{\sum_i v_i^2}\) 内积诱导，欧氏长度
    \(\infty\)-范数 \(\lVert\boldsymbol{v}\rVert_\infty = \max_i \lvert v_i\rvert\) 最坏情况

    为什么只有 2-范数能由内积诱导

    内积范数必须满足平行四边形法则：

    \[ \lVert\boldsymbol{u}+\boldsymbol{v}\rVert^2 + \lVert\boldsymbol{u}-\boldsymbol{v}\rVert^2 = 2\lVert\boldsymbol{u}\rVert^2 + 2\lVert\boldsymbol{v}\rVert^2 \]

    验证方式：取 \(\boldsymbol{u}=(1,0)\)，\(\boldsymbol{v}=(0,1)\)。

    • 1-范数：左边 \(= \lVert(1,1)\rVert_1^2 + \lVert(1,-1)\rVert_1^2 = 4+4 = 8\)， 右边 \(= 2\cdot 1 + 2 \cdot 1 = 4\)。\(8 \neq 4\) ✗
    • 2-范数：左边 \(= 2 + 2 = 4\)，右边 \(= 2+2 = 4\)

    所以 1-范数不能写成 \(\sqrt{\langle\cdot,\cdot\rangle}\) 的形式。

    这在优化里很关键：只有 2-范数对应的目标函数能化为简单的二次型。

    三、两个基本不等式¶

    内积空间里有两个几乎所有证明都会用到的不等式。

    柯西-施瓦茨不等式¶

    \[ \lvert \langle \boldsymbol{u},\boldsymbol{v}\rangle \rvert \leq \lVert\boldsymbol{u}\rVert\,\lVert\boldsymbol{v}\rVert \]

    等号成立当且仅当 \(\boldsymbol{u}\) 与 \(\boldsymbol{v}\) 线性相关。

    证明（实向量空间，思路是「构造一个非负的二次函数」）：

    若 \(\boldsymbol{v}=\boldsymbol{0}\)，两边都是 0，平凡成立。设 \(\boldsymbol{v}\neq\boldsymbol{0}\)。

    对任意实数 \(t\)，由正定性

    \[ 0 \leq \lVert \boldsymbol{u} - t\boldsymbol{v}\rVert^2 = \langle \boldsymbol{u}-t\boldsymbol{v},\boldsymbol{u}-t\boldsymbol{v}\rangle \]

    展开（实数情形内积对称）：

    \[ = \lVert\boldsymbol{u}\rVert^2 - 2t\langle \boldsymbol{u},\boldsymbol{v}\rangle + t^2\lVert\boldsymbol{v}\rVert^2 \]

    这是关于 \(t\) 的二次函数，开口向上（\(\lVert\boldsymbol{v}\rVert^2 > 0\)）且恒非负， 所以判别式必须 \(\leq 0\)：

    \[ \Delta = \left(2\langle\boldsymbol{u},\boldsymbol{v}\rangle\right)^2 - 4\lVert\boldsymbol{v}\rVert^2\lVert\boldsymbol{u}\rVert^2 \leq 0 \]

    整理得 \(\langle\boldsymbol{u},\boldsymbol{v}\rangle^2 \leq \lVert\boldsymbol{u}\rVert^2\lVert\boldsymbol{v}\rVert^2\)，开方即得结论。\(\blacksquare\)

    这个不等式在工程里的用途

    相关系数的绝对值不超过 1，这就是柯西-施瓦茨不等式的直接推论：

    \[ \rho = \frac{\langle\boldsymbol{u},\boldsymbol{v}\rangle}{\lVert\boldsymbol{u}\rVert\lVert\boldsymbol{v}\rVert} \in [-1, 1] \]

    它还给出匹配滤波的上界：给定接收信号与模板， 内积（相关值）的最大可能值就是两者范数之积。

    三角不等式¶

    \[ \lVert\boldsymbol{u}+\boldsymbol{v}\rVert \leq \lVert\boldsymbol{u}\rVert + \lVert\boldsymbol{v}\rVert \]

    几何意义：三角形两边之和大于第三边（走直线最短）。

    证明：

    \[ \lVert\boldsymbol{u}+\boldsymbol{v}\rVert^2 = \lVert\boldsymbol{u}\rVert^2 + 2\langle\boldsymbol{u},\boldsymbol{v}\rangle + \lVert\boldsymbol{v}\rVert^2 \]

    由柯西-施瓦茨，\(\langle\boldsymbol{u},\boldsymbol{v}\rangle \leq \lvert\langle\boldsymbol{u},\boldsymbol{v}\rangle\rvert \leq \lVert\boldsymbol{u}\rVert\lVert\boldsymbol{v}\rVert\)，所以

    \[ \leq \lVert\boldsymbol{u}\rVert^2 + 2\lVert\boldsymbol{u}\rVert\lVert\boldsymbol{v}\rVert + \lVert\boldsymbol{v}\rVert^2 = \left(\lVert\boldsymbol{u}\rVert+\lVert\boldsymbol{v}\rVert\right)^2 \]

    开方即得。\(\blacksquare\)

    四、正交：内积给出的「垂直」¶

    定义：\(\boldsymbol{u} \perp \boldsymbol{v}\) 当且仅当 \(\langle \boldsymbol{u},\boldsymbol{v}\rangle = 0\)。

    从内积还原「余弦」：为什么内积能定义角度¶

    中学的余弦定理给出

    \[ \lVert\boldsymbol{u}-\boldsymbol{v}\rVert^2 = \lVert\boldsymbol{u}\rVert^2 + \lVert\boldsymbol{v}\rVert^2 - 2\lVert\boldsymbol{u}\rVert\lVert\boldsymbol{v}\rVert\cos\theta \]

    而在内积空间里，把左边展开：

    \[ \lVert\boldsymbol{u}-\boldsymbol{v}\rVert^2 = \lVert\boldsymbol{u}\rVert^2 - 2\langle\boldsymbol{u},\boldsymbol{v}\rangle + \lVert\boldsymbol{v}\rVert^2 \]

    两式对比，立即看出

    \[ \langle \boldsymbol{u},\boldsymbol{v}\rangle = \lVert\boldsymbol{u}\rVert\lVert\boldsymbol{v}\rVert\cos\theta \]

    这就是内积的几何本质

    内积 = 长度之积 × 夹角余弦。

    由柯西-施瓦茨知 \(\lvert\cos\theta\rvert \leq 1\)，所以这个定义是自洽的—— 不等式的几何含义正是「余弦不能超过 1」。

    工程上的相关系数就是 \(\cos\theta\)： \(\rho = 1\) 表示两向量同向（完全正相关），\(\rho = 0\) 表示正交（不相关）， \(\rho = -1\) 表示反向（完全负相关）。

    正交的性质¶

    性质 说明
    \(\boldsymbol{0} \perp \boldsymbol{v}\) 对一切 \(\boldsymbol{v}\) 因 \(\langle\boldsymbol{0},\boldsymbol{v}\rangle = 0\)
    非零向量与自身不正交 \(\langle\boldsymbol{v},\boldsymbol{v}\rangle > 0\)
    正交组必线性无关 见下方证明
    勾股定理 \(\boldsymbol{u}\perp\boldsymbol{v} \Longrightarrow \lVert\boldsymbol{u}+\boldsymbol{v}\rVert^2 = \lVert\boldsymbol{u}\rVert^2+\lVert\boldsymbol{v}\rVert^2\)

    「正交组必线性无关」的证明：

    设 \(\{\boldsymbol{v}_1,\dots,\boldsymbol{v}_m\}\) 两两正交且都非零，并设

    \[ \lambda_1\boldsymbol{v}_1 + \cdots + \lambda_m\boldsymbol{v}_m = \boldsymbol{0} \]

    两边与 \(\boldsymbol{v}_k\) 作内积。由正交性，除第 \(k\) 项外全为零：

    \[ \lambda_k \langle\boldsymbol{v}_k,\boldsymbol{v}_k\rangle = 0 \]

    而 \(\langle\boldsymbol{v}_k,\boldsymbol{v}_k\rangle = \lVert\boldsymbol{v}_k\rVert^2 > 0\)（非零向量），故 \(\lambda_k = 0\)。 对每个 \(k\) 都成立，所以线性无关。\(\blacksquare\)

    反过来不成立

    线性无关不蕴含正交。

    例如 \(\mathbb{R}^2\) 中 \(\boldsymbol{v}_1 = (1,0)\)、\(\boldsymbol{v}_2 = (1,1)\)： 线性无关（不成比例），但

    \[ \langle\boldsymbol{v}_1,\boldsymbol{v}_2\rangle = 1\cdot1 + 0\cdot1 = 1 \neq 0 \]

    不正交。这正是格拉姆-施密特正交化的用途—— 把线性无关组改造成正交组。

    五、规范正交基：最好的坐标系¶

    定义：若 \(\{\boldsymbol{e}_1,\dots,\boldsymbol{e}_n\}\) 满足

    \[ \langle \boldsymbol{e}_j,\boldsymbol{e}_k\rangle = \begin{cases} 1, & j = k \\ 0, & j \neq k \end{cases} \]

    即每个向量长度为 1，且两两正交，则称为规范正交基。

    核心优势：坐标无需解方程¶

    一般基求坐标，要解线性方程组 \(P\boldsymbol{c} = \boldsymbol{x}\)。

    规范正交基求坐标，只需一个内积：

    \[ \boldsymbol{x} = \sum_{k=1}^n \langle \boldsymbol{x},\boldsymbol{e}_k\rangle\,\boldsymbol{e}_k \]

    即第 \(k\) 个坐标就是 \(\langle\boldsymbol{x},\boldsymbol{e}_k\rangle\)。

    证明：设 \(\boldsymbol{x} = \sum_j c_j \boldsymbol{e}_j\)，两边与 \(\boldsymbol{e}_k\) 作内积：

    \[ \langle\boldsymbol{x},\boldsymbol{e}_k\rangle = \sum_j c_j \langle\boldsymbol{e}_j,\boldsymbol{e}_k\rangle = c_k \cdot 1 = c_k \]

    （用到了正交性：\(j \neq k\) 的项全为零。）\(\blacksquare\)

    这就是傅里叶变换的公式来源

    傅里叶级数

    \[ f(t) = \sum_n c_n e^{j2\pi n t/T}, \qquad c_n = \frac{1}{T}\int_0^T f(t) e^{-j2\pi n t/T}\,\mathrm{d}t \]

    正是在规范正交基下求坐标的公式。\(c_n\) 就是内积 \(\langle f, e^{j2\pi n t/T}\rangle\) （乘以归一化常数 \(1/T\)）。

    「傅里叶变换把信号分解成频率分量」这句话的严格含义是： 把信号投影到一组正交的复指数基上。

    勾股定理的推广¶

    若 \(\{\boldsymbol{v}_1,\dots,\boldsymbol{v}_m\}\) 两两正交，则

    \[ \lVert \boldsymbol{v}_1+\cdots+\boldsymbol{v}_m\rVert^2 = \lVert\boldsymbol{v}_1\rVert^2 + \cdots + \lVert\boldsymbol{v}_m\rVert^2 \]

    证明：设 \(S = \sum_k \boldsymbol{v}_k\)，则

    \[ \lVert S\rVert^2 = \sum_j\sum_k \langle\boldsymbol{v}_j,\boldsymbol{v}_k\rangle \]

    交叉项 \(j\neq k\) 全为零（正交），只剩对角项 \(\langle\boldsymbol{v}_k,\boldsymbol{v}_k\rangle = \lVert\boldsymbol{v}_k\rVert^2\)。\(\blacksquare\)

    能量分解：工程解释

    在信号处理里，\(\lVert f\rVert^2 = \int \lvert f(t)\rvert^2\mathrm{d}t\) 常解释为能量。

    勾股定理的推广说：正交分解后，总能量等于各分量能量之和（帕塞瓦尔定理）。

    这就解释了为什么傅里叶分析「不丢信息」—— 能量可以分配到各个频率上，加起来仍等于原信号能量。

    六、典型例题¶

    例题 1：计算范数与夹角¶

    设 \(\boldsymbol{u} = (1,2,2)\)，\(\boldsymbol{v} = (2,1,-2)\)（\(\mathbb{R}^3\)，标准内积）。

    (a) 求 \(\lVert\boldsymbol{u}\rVert\)、\(\lVert\boldsymbol{v}\rVert\)。

    (b) 求 \(\boldsymbol{u}\) 与 \(\boldsymbol{v}\) 的夹角。

    © 验证柯西-施瓦茨不等式。

    思路

    范数是各分量平方和开方；夹角用 \(\cos\theta = \frac{\langle u,v\rangle}{\|u\|\|v\|}\)。

    解答

    (a) 范数

    \[ \lVert\boldsymbol{u}\rVert = \sqrt{1^2+2^2+2^2} = \sqrt{9} = 3 \]
    \[ \lVert\boldsymbol{v}\rVert = \sqrt{2^2+1^2+(-2)^2} = \sqrt{9} = 3 \]

    注意：两个向量长度相同，但方向完全不同。

    (b) 夹角

    先算内积：

    \[ \langle\boldsymbol{u},\boldsymbol{v}\rangle = 1\cdot2 + 2\cdot1 + 2\cdot(-2) = 2+2-4 = 0 \]

    内积为零，所以两向量正交，夹角

    \[ \theta = 90^\circ \]

    © 验证柯西-施瓦茨

    \[ \lvert\langle\boldsymbol{u},\boldsymbol{v}\rangle\rvert = 0, \qquad \lVert\boldsymbol{u}\rVert\lVert\boldsymbol{v}\rVert = 3\times3 = 9 \]

    故 \(0 \leq 9\) ✓ 不等式成立（此处是严格小于，因为两向量不相关）。

    从这道题学到的

    内积为零是判断正交的充分必要条件，不需要算角度。

    实用技巧：先算内积，若为零就不用继续算范数了—— 正交是最强的「无关」信号。

    例题 2：柯西-施瓦茨取等号的时机¶

    (a) 求 \(\boldsymbol{u}=(1,0)\)、\(\boldsymbol{v}=(2,0)\) 的内积与范数积，比较大小。

    (b) 说明等号成立的条件。

    思路

    两个向量线性相关时（成比例）应当取等号。

    解答

    (a) 计算

    \[ \langle\boldsymbol{u},\boldsymbol{v}\rangle = 1\cdot2+0\cdot0 = 2 \]
    \[ \lVert\boldsymbol{u}\rVert = 1, \qquad \lVert\boldsymbol{v}\rVert = 2 \]
    \[ \lvert\langle\boldsymbol{u},\boldsymbol{v}\rangle\rvert = 2 = 1\times2 = \lVert\boldsymbol{u}\rVert\lVert\boldsymbol{v}\rVert \]

    取到等号

    (b) 条件

    这里 \(\boldsymbol{v} = 2\boldsymbol{u}\)，两向量线性相关（一个是另一个的倍数）。

    一般结论：柯西-施瓦茨取等号 \(\iff\) 两向量线性相关。

    几何解释：线性相关意味着夹角为 \(0^\circ\) 或 \(180^\circ\)， 此时 \(|\cos\theta| = 1\)，代入 \(\langle\boldsymbol{u},\boldsymbol{v}\rangle = \lVert\boldsymbol{u}\rVert\lVert\boldsymbol{v}\rVert\cos\theta\) 即取等号。

    工程含义：相关系数 \(|\rho| = 1\) 表示完全线性相关（可以互相预测）。

    例题 3：用正交性求坐标¶

    在 \(\mathbb{R}^3\) 中，取规范正交基

    \[ \boldsymbol{e}_1 = \frac{1}{\sqrt{2}}(1,1,0), \quad \boldsymbol{e}_2 = \frac{1}{\sqrt{2}}(1,-1,0), \quad \boldsymbol{e}_3 = (0,0,1) \]

    求 \(\boldsymbol{x} = (3,1,5)\) 在这组基下的坐标。

    思路

    规范正交基下，坐标就是内积 \(\langle\boldsymbol{x},\boldsymbol{e}_k\rangle\)，不用解方程组。

    解答

    直接算三个内积。

    \[ c_1 = \langle\boldsymbol{x},\boldsymbol{e}_1\rangle = \frac{1}{\sqrt{2}}(3\cdot1 + 1\cdot1 + 5\cdot0) = \frac{4}{\sqrt{2}} = 2\sqrt{2} \]
    \[ c_2 = \langle\boldsymbol{x},\boldsymbol{e}_2\rangle = \frac{1}{\sqrt{2}}(3\cdot1 + 1\cdot(-1) + 0) = \frac{2}{\sqrt{2}} = \sqrt{2} \]
    \[ c_3 = \langle\boldsymbol{x},\boldsymbol{e}_3\rangle = 3\cdot0 + 1\cdot0 + 5\cdot1 = 5 \]

    所以坐标为

    \[ \boldsymbol{x} = 2\sqrt{2}\,\boldsymbol{e}_1 + \sqrt{2}\,\boldsymbol{e}_2 + 5\,\boldsymbol{e}_3 \]

    验证（把基向量展开还原）：

    \[ 2\sqrt{2}\cdot\frac{1}{\sqrt{2}}(1,1,0) + \sqrt{2}\cdot\frac{1}{\sqrt{2}}(1,-1,0) + 5(0,0,1) \]
    \[ = (2,2,0) + (1,-1,0) + (0,0,5) = (3,1,5) \;\checkmark \]

    对比：如果用一般基会怎样

    若基不正交（比如 \(\boldsymbol{b}_1=(1,1,0),\boldsymbol{b}_2=(2,0,0),\boldsymbol{b}_3=(0,0,1)\)）， 直接算内积得到的不是坐标。

    例如 \(\langle\boldsymbol{x},\boldsymbol{b}_1\rangle = 4\)，但坐标并不等于 4 （因为 \(\boldsymbol{b}_1\) 不是单位长，且与 \(\boldsymbol{b}_2\) 不正交）。

    此时必须解方程组。规范正交基的全部价值就在于省掉这一步。

    例题 4：证明平行四边形法则（内积范数的特征）¶

    证明内积诱导的范数满足

    \[ \lVert\boldsymbol{u}+\boldsymbol{v}\rVert^2 + \lVert\boldsymbol{u}-\boldsymbol{v}\rVert^2 = 2\lVert\boldsymbol{u}\rVert^2 + 2\lVert\boldsymbol{v}\rVert^2 \]
    思路

    把两个范数都用内积展开，交叉项会相互抵消或加倍。

    解答

    分别展开。

    \[ \lVert\boldsymbol{u}+\boldsymbol{v}\rVert^2 = \langle\boldsymbol{u}+\boldsymbol{v},\boldsymbol{u}+\boldsymbol{v}\rangle = \lVert\boldsymbol{u}\rVert^2 + 2\langle\boldsymbol{u},\boldsymbol{v}\rangle + \lVert\boldsymbol{v}\rVert^2 \]
    \[ \lVert\boldsymbol{u}-\boldsymbol{v}\rVert^2 = \langle\boldsymbol{u}-\boldsymbol{v},\boldsymbol{u}-\boldsymbol{v}\rangle = \lVert\boldsymbol{u}\rVert^2 - 2\langle\boldsymbol{u},\boldsymbol{v}\rangle + \lVert\boldsymbol{v}\rVert^2 \]

    两式相加，交叉项 \(+2\langle\boldsymbol{u},\boldsymbol{v}\rangle\) 与 \(-2\langle\boldsymbol{u},\boldsymbol{v}\rangle\) 正好抵消：

    \[ \lVert\boldsymbol{u}+\boldsymbol{v}\rVert^2 + \lVert\boldsymbol{u}-\boldsymbol{v}\rVert^2 = 2\lVert\boldsymbol{u}\rVert^2 + 2\lVert\boldsymbol{v}\rVert^2 \qquad\blacksquare \]

    几何意义：平行四边形的两条对角线平方和 = 四条边的平方和。

    用途：这是判定范数能否由内积诱导的标准工具。 第一节里用它对 1-范数做出了否定判断（\(8 \neq 4\)）。

    七、用在哪些课程里¶

    现代数字信号处理 · 相关与匹配滤波¶

    • 互相关就是内积：\(R_{xy}(\tau) = \int x(t)y(t-\tau)\mathrm{d}t\) 是 \(x\) 与「平移后的 \(y\)」的内积
    • 匹配滤波：在白噪声中检测已知波形 \(s(t)\)，最优滤波器是 \(h(t) = s(T-t)\)。 其原理正是让输出信噪比最大，而最大值由柯西-施瓦茨给出—— 在 \(h\) 与 \(s\) 成比例时取到
    • 正交频分复用（OFDM）：各子载波频率设计成互相正交，因此可以用内积直接分离

    模式识别 · 距离与相似度¶

    • 欧氏距离 \(d(\boldsymbol{x},\boldsymbol{y}) = \lVert\boldsymbol{x}-\boldsymbol{y}\rVert\) 由内积定义
    • 余弦相似度 \(\cos\theta = \frac{\langle\boldsymbol{x},\boldsymbol{y}\rangle}{\lVert\boldsymbol{x}\rVert\lVert\boldsymbol{y}\rVert}\) 常用于文本与高维特征（对长度不敏感，只看方向）
    • PCA 的第一步就是求协方差矩阵的主特征向量—— 而协方差本身是中心化后的内积

    智能传感与信息处理 · 状态估计¶

    • 量测方程 \(y = H\boldsymbol{x} + \boldsymbol{v}\) 中的投影关系由内积刻画
    • 卡尔曼滤波的更新步本质是把观测投影到状态空间上
    • 多传感器融合：各传感器提供「方向」，加权融合是最小方差意义下的投影

    机器人学 · 运动学与优化¶

    • 雅可比矩阵的行给出末端速度对关节速度的敏感方向
    • 最小二乘逆运动学：在冗余机械臂上，用伪逆求模长最小的解， 而这个「最小」由范数定义
    • 轨迹优化的代价函数通常是加速度的 2-范数平方

    八、自测¶

    Q1 判断：若 \(\langle\boldsymbol{u},\boldsymbol{v}\rangle = 0\)，是否必有 \(\boldsymbol{u}=\boldsymbol{0}\) 或 \(\boldsymbol{v}=\boldsymbol{0}\)？

    提示

    找一个具体的反例，两个非零向量内积为零。

    解答

    不一定。 反例：\(\boldsymbol{u}=(1,0)\)，\(\boldsymbol{v}=(0,1)\)，二者都非零，但

    \[ \langle\boldsymbol{u},\boldsymbol{v}\rangle = 1\cdot0 + 0\cdot1 = 0 \]

    这正说明正交与「至少有一个是零向量」是两回事。

    注意区分：\(\langle\boldsymbol{v},\boldsymbol{v}\rangle = 0\) 才必然推出 \(\boldsymbol{v}=\boldsymbol{0}\) （正定性公理）。这里讨论的是两个不同向量的内积。

    Q2 设 \(\lVert\boldsymbol{u}\rVert = 3\)，\(\lVert\boldsymbol{v}\rVert = 4\)，\(\langle\boldsymbol{u},\boldsymbol{v}\rangle = 6\)。求 \(\lVert 2\boldsymbol{u} - \boldsymbol{v}\rVert\)。

    提示

    先算 \(\lVert 2\boldsymbol{u}-\boldsymbol{v}\rVert^2\)，用内积展开。

    解答

    展开：

    \[ \lVert 2\boldsymbol{u}-\boldsymbol{v}\rVert^2 = 4\lVert\boldsymbol{u}\rVert^2 - 4\langle\boldsymbol{u},\boldsymbol{v}\rangle + \lVert\boldsymbol{v}\rVert^2 \]

    代入数值：

    \[ = 4\cdot 9 - 4\cdot 6 + 16 = 36 - 24 + 16 = 28 \]

    所以

    \[ \lVert 2\boldsymbol{u}-\boldsymbol{v}\rVert = \sqrt{28} = 2\sqrt{7} \]

    注意第一项系数：\(\lVert 2\boldsymbol{u}\rVert^2 = 4\lVert\boldsymbol{u}\rVert^2\)（数乘提出要平方）； 交叉项系数是 \(2\times2 = 4\)（来自 \((a-b)^2\) 展开的 \(-2ab\)，其中 \(a\) 带系数 2）。

    这是这类计算最容易出错的地方。

    Q3 证明：若 \(\lVert\boldsymbol{u}\rVert = \lVert\boldsymbol{v}\rVert\)，则 \(\boldsymbol{u}+\boldsymbol{v}\) 与 \(\boldsymbol{u}-\boldsymbol{v}\) 正交。

    提示

    算内积 \(\langle\boldsymbol{u}+\boldsymbol{v}, \boldsymbol{u}-\boldsymbol{v}\rangle\)。

    解答
    \[ \langle \boldsymbol{u}+\boldsymbol{v},\ \boldsymbol{u}-\boldsymbol{v}\rangle = \lVert\boldsymbol{u}\rVert^2 - \langle\boldsymbol{u},\boldsymbol{v}\rangle + \langle\boldsymbol{v},\boldsymbol{u}\rangle - \lVert\boldsymbol{v}\rVert^2 \]

    （实数情形 \(\langle\boldsymbol{u},\boldsymbol{v}\rangle = \langle\boldsymbol{v},\boldsymbol{u}\rangle\)，中间两项抵消。）

    \[ = \lVert\boldsymbol{u}\rVert^2 - \lVert\boldsymbol{v}\rVert^2 = 0 \]

    （末步用了范数相等的条件。）故两者正交。\(\blacksquare\)

    几何意义：菱形的对角线互相垂直—— 因为 \(\boldsymbol{u}+\boldsymbol{v}\) 与 \(\boldsymbol{u}-\boldsymbol{v}\) 正好是菱形两条对角线方向。

    Q4 1-范数是否满足三角不等式？是否满足平行四边形法则？

    提示

    三角不等式代入 \(\boldsymbol{u}=(1,0)\)、\(\boldsymbol{v}=(0,1)\) 验证； 平行四边形法则用同一组数验证。

    解答

    三角不等式：满足。

    \[ \lVert\boldsymbol{u}\rVert_1 = 1, \quad \lVert\boldsymbol{v}\rVert_1 = 1, \quad \lVert\boldsymbol{u}+\boldsymbol{v}\rVert_1 = \lvert1\rvert+\lvert1\rvert = 2 \]

    有 \(2 \leq 1+1 = 2\)，取等号 ✓（1-范数确实满足三角不等式，更一般的证明用逐分量三角不等式求和。）

    平行四边形法则：不满足。

    左边

    \[ \lVert\boldsymbol{u}+\boldsymbol{v}\rVert_1^2 + \lVert\boldsymbol{u}-\boldsymbol{v}\rVert_1^2 = 2^2 + 2^2 = 8 \]

    右边

    \[ 2\lVert\boldsymbol{u}\rVert_1^2 + 2\lVert\boldsymbol{v}\rVert_1^2 = 2\cdot1 + 2\cdot1 = 4 \]

    \(8 \neq 4\) ✗

    结论：1-范数满足三角不等式（所以它是合法的范数）， 但不满足平行四边形法则，因此不能由内积诱导。

    这解释了为什么 lasso 回归（\(\ell_1\) 正则）的最优解没有闭式公式， 而岭回归（\(\ell_2\) 正则）有。
