    线性无关、张成与基¶

    上一页说向量空间是「能做加法与数乘的集合」。这一页回答一个自然的问题：

    最少需要几个向量，才能「拼出」整个空间？

    答案的三个关键词：张成（能不能拼出来）、线性无关（有没有多余的）、基（刚好够用的一组）。 这三个概念合起来给出 维数——空间最本质的不变量。

    对工程来说，这一节的价值在于：「基」就是坐标系，「坐标」就是换基后的表示。 信号处理里的傅里叶变换、模式识别里的 PCA，本质上都是「换一组基」。

    一、线性组合：能拼出什么¶

    定义：设 \(\boldsymbol{v}_1,\dots,\boldsymbol{v}_m \in V\)。形如

    \[ \lambda_1\boldsymbol{v}_1 + \lambda_2\boldsymbol{v}_2 + \cdots + \lambda_m\boldsymbol{v}_m \]

    的向量（\(\lambda_i\) 是标量）称为这些向量的线性组合。

    直观理解：线性组合就是「把每个向量按不同倍数放大，再叠加」。

    从两个向量看¶

    在 \(\mathbb{R}^2\) 中取 \(\boldsymbol{v}_1 = (1,0)\)，\(\boldsymbol{v}_2 = (0,1)\)。它们的线性组合是

    \[ \lambda_1(1,0) + \lambda_2(0,1) = (\lambda_1, \lambda_2) \]

    能取到平面上任意一点——这就是「\(xy\) 坐标系」。

    现在换一组：\(\boldsymbol{v}_1 = (1,0)\)，\(\boldsymbol{v}_2 = (2,0)\)。线性组合是

    \[ \lambda_1(1,0) + \lambda_2(2,0) = (\lambda_1 + 2\lambda_2,\ 0) \]

    只能取到 \(x\) 轴上的点。两个向量「方向重复」了，白白多了一个却没能多覆盖任何方向。

    这个对比直接引出下一个概念。

    二、张成：能拼出的全部¶

    定义：所有线性组合的集合称为这些向量的张成：

    \[ \operatorname{span}(\boldsymbol{v}_1,\dots,\boldsymbol{v}_m) = \left\{\sum_{i=1}^m \lambda_i \boldsymbol{v}_i : \lambda_i \in \mathbb{R}\right\} \]

    性质：张成一定是子空间（含零向量，对加法与数乘封闭）。

    验证一下数乘封闭：若 \(\boldsymbol{u} = \sum \lambda_i\boldsymbol{v}_i\)，则

    \[ \mu\boldsymbol{u} = \sum (\mu\lambda_i)\boldsymbol{v}_i \]

    仍是线性组合 ✓

    几个例子¶

    向量组 张成
    \(\{(1,0)\}\) \(x\) 轴
    \(\{(1,0),(0,1)\}\) 整个 \(\mathbb{R}^2\)
    \(\{(1,0),(2,0)\}\) \(x\) 轴（仍是 1 维）
    \(\{(1,0),(0,1),(1,1)\}\) 整个 \(\mathbb{R}^2\)（2 维，但有 3 个向量）

    最后一行很重要：3 个向量张成 2 维空间，说明有冗余。

    三、线性无关：没有冗余¶

    定义：称 \(\boldsymbol{v}_1,\dots,\boldsymbol{v}_m\) 线性无关，若

    \[ \sum_{i=1}^m \lambda_i \boldsymbol{v}_i = \boldsymbol{0} \]

    只有 \(\lambda_1 = \cdots = \lambda_m = 0\) 这一组解。

    若存在不全为零的系数使上式成立，则称这些向量线性相关。

    怎么理解¶

    线性相关意味着：某一个向量可以被其它向量线性表示。

    推导：设存在不全为零的 \(\lambda_i\) 使 \(\sum \lambda_i\boldsymbol{v}_i = \boldsymbol{0}\)。 取一个非零的 \(\lambda_k\)，则

    \[ \boldsymbol{v}_k = -\frac{1}{\lambda_k}\sum_{i \neq k} \lambda_i \boldsymbol{v}_i \]

    即 \(\boldsymbol{v}_k\) 是其余向量的线性组合——它是多余的。

    一句话记住

    • 线性无关 = 「每一个都不可替代」
    • 线性相关 = 「至少有一个是多余的」

    判断方法¶

    把向量按列排成矩阵 \(A = [\boldsymbol{v}_1\ \cdots\ \boldsymbol{v}_m]\)，则

    \[ \sum \lambda_i \boldsymbol{v}_i = A\boldsymbol{\lambda} \]

    所以线性无关 \(\iff\) 方程组 \(A\boldsymbol{\lambda} = \boldsymbol{0}\) 只有零解 \(\iff\) \(A\) 的列满秩。

    这就把线性无关问题化归为秩的计算。

    两个快速判据¶

    实用判据

    判据 1（数量）：\(\mathbb{R}^n\) 中，超过 \(n\) 个向量必线性相关。

    原因：\(A\) 是 \(n \times m\) 矩阵且 \(m > n\)，方程个数少于未知数个数，必有非零解。

    判据 2（含零向量）：含零向量的组必线性相关。

    原因：给零向量配系数 1、其余配 0，就得到 \(\sum \lambda_i \boldsymbol{v}_i = \boldsymbol{0}\) 且系数不全为零。

    四、基：刚好够用¶

    现在把两个条件合起来。

    定义：向量组 \(\boldsymbol{v}_1,\dots,\boldsymbol{v}_n\) 是 \(V\) 的基，若

    1. 它张成 \(V\)（能拼出全部）
    2. 它线性无关（没有多余）

    基的核心性质：表示唯一¶

    这是基最重要的性质，值得单独推一遍。

    命题：若 \(\{\boldsymbol{v}_1,\dots,\boldsymbol{v}_n\}\) 是 \(V\) 的基，则 \(V\) 中每个向量都能唯一地写成线性组合。

    证明：

    存在性由「张成」直接得到。

    唯一性：设 \(\boldsymbol{v}\) 有两种表示

    \[ \boldsymbol{v} = \sum_{i=1}^n \lambda_i \boldsymbol{v}_i = \sum_{i=1}^n \mu_i \boldsymbol{v}_i \]

    两式相减：

    \[ \sum_{i=1}^n (\lambda_i - \mu_i)\boldsymbol{v}_i = \boldsymbol{0} \]

    由线性无关，只能有 \(\lambda_i - \mu_i = 0\)，即 \(\lambda_i = \mu_i\)。故表示唯一。\(\blacksquare\)

    这组唯一的系数 \((\lambda_1,\dots,\lambda_n)\) 就称为 \(\boldsymbol{v}\) 在这组基下的坐标。

    为什么坐标需要先定基

    说「这个点的坐标是 \((3,4)\)」，其实隐含了「相对于标准基 \(\{(1,0),(0,1)\}\)」。

    换一组基，同一个向量的坐标就变了。向量本身没变，变的是描述它的数字。

    这正是「坐标是相对的，向量是绝对的」这句话的含义。

    从图到公式：坐标变换¶

    设旧基为 \(\{\boldsymbol{e}_1,\boldsymbol{e}_2\}\)，新基为 \(\{\boldsymbol{b}_1,\boldsymbol{b}_2\}\)， 且新基可以用旧基表示：

    \[ \boldsymbol{b}_1 = p_{11}\boldsymbol{e}_1 + p_{21}\boldsymbol{e}_2, \qquad \boldsymbol{b}_2 = p_{12}\boldsymbol{e}_1 + p_{22}\boldsymbol{e}_2 \]

    若某向量在新基下的坐标是 \((c_1, c_2)\)，即 \(\boldsymbol{v} = c_1\boldsymbol{b}_1 + c_2\boldsymbol{b}_2\)，代入上式：

    \[ \boldsymbol{v} = c_1(p_{11}\boldsymbol{e}_1 + p_{21}\boldsymbol{e}_2) + c_2(p_{12}\boldsymbol{e}_1 + p_{22}\boldsymbol{e}_2) \]

    按 \(\boldsymbol{e}_1, \boldsymbol{e}_2\) 整理：

    \[ \boldsymbol{v} = (p_{11}c_1 + p_{12}c_2)\boldsymbol{e}_1 + (p_{21}c_1 + p_{22}c_2)\boldsymbol{e}_2 \]

    写成矩阵形式：

    \[ \underbrace{\begin{bmatrix} x_1 \\ x_2 \end{bmatrix}}_{\text{旧坐标}} = \underbrace{\begin{bmatrix} p_{11} & p_{12} \\ p_{21} & p_{22} \end{bmatrix}}_{\text{过渡矩阵 } P} \underbrace{\begin{bmatrix} c_1 \\ c_2 \end{bmatrix}}_{\text{新坐标}} \]

    这就是坐标变换公式 \(\boldsymbol{x} = P\boldsymbol{c}\)，其中 \(P\) 的列就是新基向量在旧基下的坐标。

    记住这个「反直觉」的方向

    很多人第一次会写错方向。注意上式：旧坐标 = 过渡矩阵 × 新坐标， 也就是从新坐标到旧坐标要左乘 \(P\)；反过来从旧坐标求新坐标要左乘 \(P^{-1}\)。

    理解方式：\(P\) 的每一列是「新基向量长什么样（用旧基描述）」。 所以新基的坐标 1（第一个基向量）对应的旧坐标就是 \(P\) 的第一列——方向自然就对了。

    五、维数：空间的本质不变量¶

    定义：\(V\) 的维数 \(\dim V\) 是它任意一组基中向量的个数。

    这个定义能成立，需要一件事：不同基的向量个数相同。这是个定理（基的个数不变量）：

    定理：任何两组基的向量个数相等

    证明思路（用「线性无关组长度 ≤ 张成组长度」这个引理）：

    设 \(\{\boldsymbol{u}_1,\dots,\boldsymbol{u}_m\}\) 和 \(\{\boldsymbol{v}_1,\dots,\boldsymbol{v}_n\}\) 都是 \(V\) 的基。

    因为 \(\{\boldsymbol{u}_i\}\) 张成 \(V\)，而 \(\{\boldsymbol{v}_j\}\) 线性无关， 由引理得 \(n \leq m\)。

    同理，交换两者角色得 \(m \leq n\)。

    故 \(m = n\)。\(\blacksquare\)

    引理本身（\(\mathbb{R}^n\) 中任何线性无关组的长度 ≤ 张成组的长度）的证明用的是「替换论证」， 这里不展开，但结论很重要：维数是良定义的。

    常见空间的维数¶

    空间 维数 一组基
    \(\mathbb{R}^n\) \(n\) 标准基 \(\boldsymbol{e}_1,\dots,\boldsymbol{e}_n\)
    \(P_n\)（次数 ≤ \(n\) 的多项式） \(n+1\) \(1, x, x^2, \dots, x^n\)
    \(m\times n\) 矩阵 \(mn\) \(E_{ij}\)（只有一个位置为 1）

    注意 \(P_n\) 的维数是 \(n+1\) 而不是 \(n\)——因为从 \(x^0\) 到 \(x^n\) 共 \(n+1\) 个。

    六、秩-零化度定理¶

    这是线性代数最有用的定理之一，它把维数关系说清楚了。

    先定义两个空间。设 \(T: V \to W\) 是线性映射：

    零空间（kernel / null space）：

    \[ \operatorname{null} T = \{\boldsymbol{v} \in V : T\boldsymbol{v} = \boldsymbol{0}\} \]

    值域（range）：

    \[ \operatorname{range} T = \{T\boldsymbol{v} : \boldsymbol{v} \in V\} \]

    秩-零化度定理

    \[ \dim V = \dim(\operatorname{null} T) + \dim(\operatorname{range} T) \]

    也就是说：输入空间的维数 = 「被压掉的维数」+ 「保留的维数」。

    证明思路：

    取 \(\operatorname{null}T\) 的一组基 \(\{\boldsymbol{u}_1,\dots,\boldsymbol{u}_k\}\)， 把它扩充成 \(V\) 的基 \(\{\boldsymbol{u}_1,\dots,\boldsymbol{u}_k,\boldsymbol{w}_1,\dots,\boldsymbol{w}_m\}\)。

    关键是要证明 \(\{T\boldsymbol{w}_1,\dots,T\boldsymbol{w}_m\}\) 是 \(\operatorname{range}T\) 的基：

    （1）张成 range：任取 \(T\boldsymbol{v}\)，把 \(\boldsymbol{v}\) 用基展开：

    \[ \boldsymbol{v} = \sum a_i\boldsymbol{u}_i + \sum b_j\boldsymbol{w}_j \]

    作用 \(T\)：

    \[ T\boldsymbol{v} = \sum a_i \underbrace{T\boldsymbol{u}_i}_{= \boldsymbol{0}} + \sum b_j T\boldsymbol{w}_j = \sum b_j T\boldsymbol{w}_j \]

    所以 \(\{T\boldsymbol{w}_j\}\) 张成 \(\operatorname{range}T\) ✓

    （2）线性无关：设 \(\sum c_j T\boldsymbol{w}_j = \boldsymbol{0}\)，则

    \[ T\left(\sum c_j\boldsymbol{w}_j\right) = \boldsymbol{0} \]

    所以 \(\sum c_j\boldsymbol{w}_j \in \operatorname{null}T\)，可写成 \(\sum a_i\boldsymbol{u}_i\)。即

    \[ \sum c_j\boldsymbol{w}_j + \sum(-a_i)\boldsymbol{u}_i = \boldsymbol{0} \]

    但 \(\{\boldsymbol{u}_i,\boldsymbol{w}_j\}\) 是基（线性无关），所以所有系数为零，特别地 \(c_j = 0\) ✓

    于是 \(\operatorname{range}T\) 的维数是 \(m\)，而 \(\dim V = k + m\)。定理成立。\(\blacksquare\)

    这个定理在工程里的意义

    它告诉你「信息损失了多少」。

    场景 解读
    降维（PCA） range 维数 < 输入维数，损失的是 null 空间方向的信息
    传感器融合 若 \(T\) 的 null 空间非平凡，说明有状态观测不到（不可观）
    机器人奇异位形 雅可比 \(J\) 的 null 空间 → 末端无法运动的方向

    七、典型例题¶

    例题 1：判断线性相关性¶

    判断向量组 \(\{(1,0,1),\ (0,1,1),\ (1,1,2)\}\) 是否线性无关。

    思路

    先观察第三个向量是否等于前两个之和。

    解答

    观察：

    \[ (1,0,1) + (0,1,1) = (1,1,2) \]

    即 \(\boldsymbol{v}_3 = \boldsymbol{v}_1 + \boldsymbol{v}_2\)。

    于是得到非平凡线性组合

    \[ \boldsymbol{v}_1 + \boldsymbol{v}_2 - \boldsymbol{v}_3 = \boldsymbol{0} \]

    系数 \((1,1,-1)\) 不全为零，所以线性相关 ✓

    行列式验证（把向量按列排）：

    \[ \det\begin{bmatrix}1&0&1\\0&1&1\\1&1&2\end{bmatrix} = 1\begin{vmatrix}1&1\\1&2\end{vmatrix} - 0 + 1\begin{vmatrix}0&1\\1&1\end{vmatrix} \]
    \[ = 1\cdot(2-1) + 1\cdot(0-1) = 1 - 1 = 0 \;\checkmark \]

    行列式为零，与「线性相关」一致。

    秩：前两个向量不成比例（线性无关），故

    \[ \operatorname{rank} = 2 \]

    例题 2：补全成一组基¶

    在 \(\mathbb{R}^3\) 中，把线性无关组 \(\{(1,0,0),\ (0,1,0)\}\) 补全为一组基。

    思路

    \(\mathbb{R}^3\) 的基需要 3 个线性无关向量， 找一个不由前两个线性表示的向量即可。

    解答

    分析：前两个向量张成 \(xy\) 平面

    \[ \operatorname{span}\{(1,0,0),(0,1,0)\} = \{(x,y,0) : x,y \in \mathbb{R}\} \]

    所以第三分量非零的向量都不能由它们线性表示。

    取第三分量为一的向量 \(\boldsymbol{v}_3 = (0,0,1)\)。

    验证线性无关：设

    \[ c_1(1,0,0) + c_2(0,1,0) + c_3(0,0,1) = (c_1,\ c_2,\ c_3) = \boldsymbol{0} \]

    比较分量得 \(c_1 = c_2 = c_3 = 0\) ✓

    3 个线性无关向量在 3 维空间中必然构成一组基。

    这组基正是标准基 \(\{\boldsymbol{e}_1,\boldsymbol{e}_2,\boldsymbol{e}_3\}\)。

    补全成基的一般方法

    步骤：

    1. 把已知向量排成矩阵，求行最简形，找出主元列
    2. 看哪些标准基向量不能由已知向量线性表示
    3. 逐个补充，并验证秩随之增加

    判据：若原向量组的个数等于其秩（即线性无关）， 就一定可以补全到 \(n\) 个。

    若原向量组线性相关，则要先筛掉冗余的向量， 否则补全时怎么加都凑不齐 \(n\) 个线性无关向量。

    例题 3：用秩-零化度定理求零空间维数¶

    设 \(T: \mathbb{R}^4 \to \mathbb{R}^3\) 是线性映射，且 \(\operatorname{rank}(T) = 2\)。 求 \(\dim(\operatorname{null}T)\)。

    思路

    直接用秩-零化度定理：输入维数 = 零空间维数 + 值域维数。

    解答

    秩-零化度定理：

    \[ \dim V = \dim(\operatorname{null}T) + \dim(\operatorname{range}T) \]

    已知：

    • 输入空间维数 \(\dim V = 4\)（因为 \(V = \mathbb{R}^4\)）
    • 值域维数 \(\dim(\operatorname{range}T) = \operatorname{rank}(T) = 2\)

    代入求解：

    \[ 4 = \dim(\operatorname{null}T) + 2 \implies \dim(\operatorname{null}T) = 2 \]

    验证维度关系：

    空间 维数
    输入 \(\mathbb{R}^4\) 4
    零空间（被压成零） 2
    值域（保留下来） 2
    合计 \(2+2=4\) ✓

    几何含义：4 维输入被压到 2 维输出， 所以有 2 个方向的信息被完全丢失。

    这意味着 \(T\) 不是单射（零空间非平凡）： 若 \(T\boldsymbol{x}_1 = T\boldsymbol{x}_2\)，则 \(\boldsymbol{x}_1 - \boldsymbol{x}_2 \in \operatorname{null}T\)， 而零空间是 2 维的，所以有无穷多组输入映射到同一输出。

    这类题的通用解法

    秩-零化度定理只要知道其中两个量，就能求第三个：

    已知 求 公式
    输入维数、秩 零空间维数 \(n - r\)
    输入维数、零空间维数 秩 \(n - k\)
    秩、零空间维数 输入维数 \(r + k\)

    工程判据：

    • 若 \(\dim(\operatorname{null}T) > 0\)，映射不可逆（有信息丢失）
    • 对矩阵 \(A\)：\(\dim(\operatorname{null}A) = n - \operatorname{rank}(A)\) 就是「有多少个方向解不出来」

    例题 4：求向量在新基下的坐标¶

    在 \(\mathbb{R}^2\) 中，取新基

    \[ \boldsymbol{b}_1 = (1,1), \qquad \boldsymbol{b}_2 = (1,-1) \]

    求向量 \(\boldsymbol{v} = (3,5)\) 在这组基下的坐标。

    思路

    设 \(\boldsymbol{v} = c_1\boldsymbol{b}_1 + c_2\boldsymbol{b}_2\)， 展开成方程组求解。

    解答

    设坐标形式：

    \[ \boldsymbol{v} = c_1\boldsymbol{b}_1 + c_2\boldsymbol{b}_2 \]

    代入具体向量：

    \[ (3,5) = c_1(1,1) + c_2(1,-1) \]

    按分量列出方程组：

    \[ \begin{cases} c_1 + c_2 = 3 &\text{（第一个分量）}\\ c_1 - c_2 = 5 &\text{（第二个分量）} \end{cases} \]

    求解（两式相加、相减）：

    相加：\(2c_1 = 8 \implies c_1 = 4\)

    相减：\(2c_2 = -2 \implies c_2 = -1\)

    结果：

    \[ \boldsymbol{v} = 4\boldsymbol{b}_1 - \boldsymbol{b}_2 \]

    验证：

    \[ 4(1,1) - 1(1,-1) = (4,4) - (1,-1) = (3,5) \;\checkmark \]

    坐标：在基 \(\{\boldsymbol{b}_1,\boldsymbol{b}_2\}\) 下， \(\boldsymbol{v}\) 的坐标是 \((4, -1)\)。

    注意：坐标随基而变，向量本身不变

    同一个向量 \(\boldsymbol{v} = (3,5)\)：

    基 坐标
    标准基 \(\{(1,0),(0,1)\}\) \((3, 5)\)
    新基 \(\{(1,1),(1,-1)\}\) \((4, -1)\)

    向量是客观对象，坐标只是它在某组基下的「记账方式」。

    这也是为什么求坐标前必须先明确用哪组基—— 单说「坐标是 (3,5)」是不完整的表述。

    为什么这组基特别方便

    这组基 \(\boldsymbol{b}_1=(1,1)\)、\(\boldsymbol{b}_2=(1,-1)\) 有两个好性质：

    性质 验证
    正交 \((1,1)\cdot(1,-1) = 0\) ✓
    长度相同（都是 \(\sqrt2\)） \(\lvert(1,1)\rvert = \lvert(1,-1)\rvert = \sqrt2\) ✓

    正交基下求坐标可以用内积直接算（不必解方程组）：

    \[ c_1 = \frac{\langle\boldsymbol{v},\boldsymbol{b}_1\rangle}{\lVert\boldsymbol{b}_1\rVert^2} = \frac{3+5}{2} = 4 \;\checkmark \]
    \[ c_2 = \frac{\langle\boldsymbol{v},\boldsymbol{b}_2\rangle}{\lVert\boldsymbol{b}_2\rVert^2} = \frac{3-5}{2} = -1 \;\checkmark \]

    结果与解方程组一致，但快得多—— 这就是规范正交基的核心优势（详见「范数与内积」一节）。

    八、用在哪些课程里¶

    现代数字信号处理 · 傅里叶变换就是换基¶

    离散信号空间 \(\mathbb{C}^N\) 的标准基是 \(\{\boldsymbol{e}_0,\dots,\boldsymbol{e}_{N-1}\}\)， \(\boldsymbol{e}_k\) 表示「第 \(k\) 个时刻有冲激」。

    傅里叶变换换了一组新基——复指数序列：

    \[ \boldsymbol{w}_k = \left(1,\ e^{j2\pi k/N},\ e^{j4\pi k/N},\ \dots,\ e^{j2\pi k(N-1)/N}\right) \]

    原来信号的坐标是「各时刻的采样值」，换基后的坐标是「各频率的强度」。

    这就是为什么频谱分析有意义：同一信号，换一组基看，能看出原本看不出的结构。

    模式识别 · 降维就是找低维子空间¶

    \(N\) 个样本、每个 \(d\) 维，数据张成一个不超过 \(d\) 维的子空间。若数据实际接近一个低维子空间（比如 \(k\) 维，\(k \ll d\)），则

    • 用这 \(k\) 个基向量表示数据，信息损失很小
    • 这就是 PCA 的思路：找「最好的」\(k\) 维子空间

    秩-零化度定理在这里告诉你：投影到 \(k\) 维子空间，损失掉的是 \(d-k\) 维的信息。

    机器人学 · 奇异位形¶

    机械臂的雅可比 \(J(\boldsymbol{q}) \in \mathbb{R}^{6\times n}\) 给出关节速度到末端速度的映射：

    \[ \boldsymbol{v}_{\text{末端}} = J(\boldsymbol{q})\,\dot{\boldsymbol{q}} \]

    奇异位形定义为 \(J\) 的秩下降的位形。此时

    \[ \dim(\operatorname{null} J) > 0 \]

    意味着存在非零的关节速度使末端不动——某些方向失去了运动能力。

    对 \(n = 6\) 的机械臂：正常时 \(\operatorname{rank}J = 6\)（可任意运动）；奇异时秩 < 6，无法沿某些方向运动。

    智能传感与信息处理 · 可观性¶

    状态方程 \(y = C\boldsymbol{x}\)（只看输出）。若 \(C\) 的零空间非平凡， 则零空间中的状态不产生任何输出——这些状态不可观测。

    可观性判据就是要求 \(C\) 及其幂次的零空间交集只有 \(\{\boldsymbol{0}\}\)。

    九、自测¶

    Q1 判断 \(\{(1,2,3),\ (4,5,6),\ (7,8,9)\}\) 是否线性无关。

    提示

    排成矩阵求行列式，或看第三行是否为前两行的组合。

    解答

    线性相关。

    观察：\(\boldsymbol{v}_3 = 2\boldsymbol{v}_2 - \boldsymbol{v}_1\)？

    \[ 2(4,5,6) - (1,2,3) = (8-1,\ 10-2,\ 12-3) = (7,8,9) \checkmark \]

    确实成立。所以存在非零系数（\(-1, 2, -1\)）使组合为零：

    \[ -\boldsymbol{v}_1 + 2\boldsymbol{v}_2 - \boldsymbol{v}_3 = \boldsymbol{0} \]

    故线性相关。

    行列式验证：

    \[ \det\begin{bmatrix} 1&4&7\\2&5&8\\3&6&9\end{bmatrix} = 0 \]

    原因：第一个向量 \(+\) 第三个向量 \(= (8,10,12) = 2\times\) 第二个向量。 三个点共线（都在直线 \(y = x+1\) 上）。

    Q2 求 \(\operatorname{span}\{(1,1,0),\ (0,1,1)\}\) 的维数与一组基。

    提示

    先看这两个向量是否线性无关。

    解答

    维数为 2，一组基就是这两个向量本身。

    验证线性无关：设 \(\lambda_1(1,1,0) + \lambda_2(0,1,1) = \boldsymbol{0}\)，即

    \[ (\lambda_1,\ \lambda_1+\lambda_2,\ \lambda_2) = (0,0,0) \]

    由第一个分量 \(\lambda_1 = 0\)；由第三个分量 \(\lambda_2 = 0\)。故只有零解，线性无关。

    所以这组向量张成一个 2 维子空间，它们本身就是基。

    几何图像：这是 \(\mathbb{R}^3\) 中过原点的一个平面，法向量为

    \[ (1,1,0) \times (0,1,1) = (1\cdot1 - 0\cdot1,\ 0\cdot0 - 1\cdot1,\ 1\cdot1 - 1\cdot0) = (1,-1,1) \]

    即平面 \(x - y + z = 0\)。

    Q3 设 \(T:\mathbb{R}^4 \to \mathbb{R}^3\) 是满射（onto）。求 \(\dim(\operatorname{null}T)\)。

    提示

    用秩-零化度定理。满射说明 range 维数是多少？

    解答
    \[\dim(\operatorname{null}T) = 1\]

    推导：

    \(T\) 满射意味着 \(\operatorname{range}T = \mathbb{R}^3\)，所以

    \[ \dim(\operatorname{range}T) = 3 \]

    由秩-零化度定理：

    \[ \dim(\operatorname{null}T) = \dim(\mathbb{R}^4) - \dim(\operatorname{range}T) = 4 - 3 = 1 \]

    解读：从 4 维压到 3 维，必然有 1 维被「压掉」了。 这意味着至少有一个非零方向被映射到零——不可能做到「单射」。

    推论：从低维空间到高维空间的线性映射永远不可能是满射（维数就不够）。

    Q4 证明：\(\{\boldsymbol{v}_1, \boldsymbol{v}_2, \boldsymbol{v}_3\}\) 线性无关 \(\Longrightarrow\) \(\{\boldsymbol{v}_1+\boldsymbol{v}_2,\ \boldsymbol{v}_2+\boldsymbol{v}_3,\ \boldsymbol{v}_3\}\) 线性无关。

    提示

    设新组合为零，展开后利用原组的线性无关性。

    解答

    设存在标量 \(a,b,c\) 使得

    \[ a(\boldsymbol{v}_1+\boldsymbol{v}_2) + b(\boldsymbol{v}_2+\boldsymbol{v}_3) + c\boldsymbol{v}_3 = \boldsymbol{0} \]

    按原向量整理：

    \[ a\boldsymbol{v}_1 + (a+b)\boldsymbol{v}_2 + (b+c)\boldsymbol{v}_3 = \boldsymbol{0} \]

    由 \(\{\boldsymbol{v}_1,\boldsymbol{v}_2,\boldsymbol{v}_3\}\) 线性无关，各系数必须为零：

    \[ \begin{cases} a = 0 \\ a+b = 0 \\ b+c = 0 \end{cases} \]

    由 \(a=0\) 代入第二式得 \(b=0\)，再代入第三式得 \(c=0\)。

    所以只有平凡解，新向量组线性无关。\(\blacksquare\)

    思路总结：把「新组的线性组合」翻译成「原组的线性组合」， 再用原组的无关性推出系数全为零。这是这类题的通用解法。
