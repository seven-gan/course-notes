    正交性与投影¶

    上一页引入了内积，于是有了「长度」和「垂直」。这一页回答一个非常实用的问题：

    如果目标不在我能够到的范围里，我该选哪个「最接近」的？

    比如：想用两个方向的组合去逼近某个向量，但无论怎么组合都到不了它—— 该怎么办？

    答案的美妙之处在于：选那个「误差与我的所有可用方向都垂直」的点。 这个「垂直」条件不只是几何直觉，它给出一个可解的方程， 而且可以证明它就是最优的。

    这一页的内容直接通向最小二乘拟合、PCA、卡尔曼滤波的更新步。

    一、正交补：所有「与它垂直」的向量¶

    定义：设 \(U \subseteq V\) 是子空间，定义 \(U\) 的正交补为

    \[ U^{\perp} = \{\boldsymbol{v} \in V : \langle \boldsymbol{v},\boldsymbol{u}\rangle = 0 \ \text{对一切}\ \boldsymbol{u} \in U\} \]

    即：与 \(U\) 中每个向量都正交的那些向量。

    正交补是子空间

    证明：取 \(\boldsymbol{v}_1,\boldsymbol{v}_2 \in U^{\perp}\)，任取 \(\boldsymbol{u} \in U\)。

    \[ \langle \lambda\boldsymbol{v}_1+\boldsymbol{v}_2,\ \boldsymbol{u}\rangle = \lambda\langle\boldsymbol{v}_1,\boldsymbol{u}\rangle + \langle\boldsymbol{v}_2,\boldsymbol{u}\rangle = \lambda\cdot 0 + 0 = 0 \]

    所以 \(\lambda\boldsymbol{v}_1+\boldsymbol{v}_2 \in U^\perp\)，对线性组合封闭； 又 \(\boldsymbol{0} \in U^\perp\)（零向量与一切正交），非空。故 \(U^\perp\) 是子空间 ✓

    一个关键的直和分解¶

    定理：若 \(U\) 是 \(V\) 的有限维子空间，则

    \[ V = U \oplus U^{\perp} \]

    也就是说：\(V\) 中每个向量都能唯一地写成一个「\(U\) 中的部分」加上一个「与 \(U\) 垂直的部分」。

    这两个部分有自己的名字：

    • \(U\) 中的部分称为 \(\boldsymbol{v}\) 在 \(U\) 上的投影，记 \(\operatorname{proj}_U \boldsymbol{v}\)
    • \(U^\perp\) 中的部分为正交余项（或误差项）

    二、一个向量的投影：先看最简单的情形¶

    先设 \(U\) 是一维的，由单个非零向量 \(\boldsymbol{u}\) 张成。求 \(\boldsymbol{v}\) 在 \(U\) 上的投影。

    直观：投影应当形如 \(\lambda \boldsymbol{u}\)，我们要定出 \(\lambda\)。

    关键条件：误差 \(\boldsymbol{v} - \lambda\boldsymbol{u}\) 必须与 \(U\) 正交，即与 \(\boldsymbol{u}\) 正交：

    \[ \langle \boldsymbol{v}-\lambda\boldsymbol{u},\ \boldsymbol{u}\rangle = 0 \]

    展开：

    \[ \langle \boldsymbol{v},\boldsymbol{u}\rangle - \lambda\langle \boldsymbol{u},\boldsymbol{u}\rangle = 0 \]

    解出

    \[ \lambda = \frac{\langle \boldsymbol{v},\boldsymbol{u}\rangle}{\langle \boldsymbol{u},\boldsymbol{u}\rangle} = \frac{\langle \boldsymbol{v},\boldsymbol{u}\rangle}{\lVert\boldsymbol{u}\rVert^2} \]

    于是投影公式：

    \[ \boxed{\ \operatorname{proj}_U \boldsymbol{v} = \frac{\langle \boldsymbol{v},\boldsymbol{u}\rangle}{\lVert\boldsymbol{u}\rVert^2}\,\boldsymbol{u}\ } \]

    若 \(\boldsymbol{u}\) 是单位向量（\(\lVert\boldsymbol{u}\rVert=1\)），公式简化为

    \[ \operatorname{proj}_U \boldsymbol{v} = \langle \boldsymbol{v},\boldsymbol{u}\rangle\,\boldsymbol{u} \]

    为什么它是「最优」的¶

    上面的推导只用了「误差垂直」这一个条件，但没有证明它就使距离最小。 补上这一步（这是投影被称为「最佳逼近」的原因）：

    设 \(\boldsymbol{w} = \lambda\boldsymbol{u}\) 是 \(U\) 中任意向量。则

    \[ \lVert \boldsymbol{v}-\boldsymbol{w}\rVert^2 = \lVert \boldsymbol{v}-\operatorname{proj}_U\boldsymbol{v} + \operatorname{proj}_U\boldsymbol{v}-\boldsymbol{w}\rVert^2 \]

    后面那一项 \(\operatorname{proj}_U\boldsymbol{v}-\boldsymbol{w}\) 仍在 \(U\) 中，而误差 \(\boldsymbol{v}-\operatorname{proj}_U\boldsymbol{v}\) 与 \(U\) 正交， 所以两者正交。由勾股定理：

    \[ \lVert \boldsymbol{v}-\boldsymbol{w}\rVert^2 = \underbrace{\lVert \boldsymbol{v}-\operatorname{proj}_U\boldsymbol{v}\rVert^2}_{\text{固定}} + \underbrace{\lVert \operatorname{proj}_U\boldsymbol{v}-\boldsymbol{w}\rVert^2}_{\geq 0} \]

    右边第一项与 \(\boldsymbol{w}\) 无关，第二项非负。所以当且仅当 \(\boldsymbol{w} = \operatorname{proj}_U\boldsymbol{v}\) 时取到最小值。\(\blacksquare\)

    这个证明的结构值得记住

    「把总误差拆成「垂直部分 + 水平部分」，垂直部分与选择无关， 水平部分非负」——这是最小二乘、最优估计里反复出现的论证方式。

    它说明：最佳逼近 = 让误差落在正交补里。

    三、推广到多维：规范正交基下的投影¶

    若 \(U\) 有一组规范正交基 \(\{\boldsymbol{e}_1,\dots,\boldsymbol{e}_m\}\)，那么投影就是各方向投影之和：

    \[ \operatorname{proj}_U \boldsymbol{v} = \sum_{k=1}^m \langle \boldsymbol{v},\boldsymbol{e}_k\rangle\,\boldsymbol{e}_k \]

    为什么是「求和」而不是「解方程组」：

    一般基下求投影需要解正规方程（下面第五节）。但规范正交基下， 各方向互不干扰——沿着 \(\boldsymbol{e}_1\) 的坐标不受 \(\boldsymbol{e}_2\) 影响， 所以可以直接算内积再相加。

    这解释了正交性的价值

    正交 = 分量之间不串扰。

    工程上「正交码」「正交子载波」都是为了这个性质： 接收端可以用一个内积就把某个分量单独取出来，不受其它分量影响。

    四、格拉姆-施密特正交化：造出规范正交基¶

    给定线性无关组 \(\{\boldsymbol{v}_1,\dots,\boldsymbol{v}_m\}\)，怎样得到规范正交组？

    思路：逐个处理，每一步都减去已在前面方向上的投影，剩下的就是正交的部分。

    算法：

    \[ \boldsymbol{u}_1 = \boldsymbol{v}_1, \qquad \boldsymbol{e}_1 = \frac{\boldsymbol{u}_1}{\lVert\boldsymbol{u}_1\rVert} \]

    对 \(k = 2,\dots,m\)：

    \[ \boldsymbol{u}_k = \boldsymbol{v}_k - \sum_{j=1}^{k-1}\langle \boldsymbol{v}_k,\boldsymbol{e}_j\rangle\,\boldsymbol{e}_j, \qquad \boldsymbol{e}_k = \frac{\boldsymbol{u}_k}{\lVert\boldsymbol{u}_k\rVert} \]

    为什么要求线性无关

    若 \(\boldsymbol{v}_k\) 落在前面向量张成的子空间里，减去投影后剩零向量， 无法单位化（除零）。这正是线性相关的表现。

    所以在算法中若遇到 \(\boldsymbol{u}_k = \boldsymbol{0}\)，说明原向量组线性相关， 应当剔除该向量再继续。

    一个手算例子¶

    取 \(\boldsymbol{v}_1 = (1,1)\)，\(\boldsymbol{v}_2 = (2,0)\)（\(\mathbb{R}^2\) 标准内积）。

    第一步：

    \[ \boldsymbol{e}_1 = \frac{(1,1)}{\sqrt{2}} = \left(\frac{1}{\sqrt2},\frac{1}{\sqrt2}\right) \]

    第二步：先算投影系数

    \[ \langle \boldsymbol{v}_2,\boldsymbol{e}_1\rangle = 2\cdot\frac{1}{\sqrt2} + 0\cdot\frac{1}{\sqrt2} = \frac{2}{\sqrt2} = \sqrt{2} \]

    减去投影：

    \[ \boldsymbol{u}_2 = (2,0) - \sqrt2\left(\frac{1}{\sqrt2},\frac{1}{\sqrt2}\right) = (2,0)-(1,1) = (1,-1) \]

    单位化：

    \[ \boldsymbol{e}_2 = \frac{(1,-1)}{\sqrt2} = \left(\frac{1}{\sqrt2},-\frac{1}{\sqrt2}\right) \]

    验证正交性：

    \[ \langle \boldsymbol{e}_1,\boldsymbol{e}_2\rangle = \frac{1}{\sqrt2}\cdot\frac{1}{\sqrt2} + \frac{1}{\sqrt2}\cdot\left(-\frac{1}{\sqrt2}\right) = \frac12 - \frac12 = 0 \;\checkmark \]

    五、最小二乘：投影最重要的应用¶

    现在看这一页最实用的部分。

    问题：方程组无解时怎么办¶

    设 \(A\) 是 \(m\times n\) 矩阵，\(\boldsymbol{b} \in \mathbb{R}^m\)。 方程

    \[ A\boldsymbol{x} = \boldsymbol{b} \]

    可能无解（当 \(\boldsymbol{b}\) 不在 \(A\) 的列空间里时）。

    从几何角度看「无解」

    把 \(A\) 的列看成 \(\mathbb{R}^m\) 中的向量，它们的张成是列空间 \(\operatorname{range}A\)。

    \(A\boldsymbol{x} = \boldsymbol{b}\) 有解 \(\iff\) \(\boldsymbol{b} \in \operatorname{range}A\)。

    若 \(\boldsymbol{b}\) 不在这个子空间里（比如 \(m > n\) 时通常如此）， 方程无解——这在几何上是「目标点不在可到达的平面上」。

    但我们常常还是想要一个「最接近」的解。于是定义

    \[ \hat{\boldsymbol{x}} = \argmin_{\boldsymbol{x}} \lVert A\boldsymbol{x} - \boldsymbol{b}\rVert^2 \]

    这就是最小二乘解。

    用投影求解¶

    关键观察：\(A\boldsymbol{x}\) 的所有可能取值构成子空间 \(\operatorname{range}A\)。 所以问题就是：

    在 \(\operatorname{range}A\) 里找一个与 \(\boldsymbol{b}\) 最接近的点。

    而这正是投影！由第二节的结论，最优解满足：

    \[ \boldsymbol{b} - A\hat{\boldsymbol{x}} \perp \operatorname{range}A \]

    「与列空间正交」等价于与 \(A\) 的每一列都正交，写成矩阵形式就是

    \[ A^{\top}(\boldsymbol{b} - A\hat{\boldsymbol{x}}) = \boldsymbol{0} \]

    整理得正规方程：

    \[ \boxed{\ A^{\top}A\,\hat{\boldsymbol{x}} = A^{\top}\boldsymbol{b}\ } \]

    若 \(A^{\top}A\) 可逆（即 \(A\) 的列线性无关），则

    \[ \hat{\boldsymbol{x}} = (A^{\top}A)^{-1}A^{\top}\boldsymbol{b} \]

    为什么叫「最小二乘」

    「二乘」指平方。因为最小化的是误差平方和：

    \[ \lVert A\boldsymbol{x}-\boldsymbol{b}\rVert^2 = \sum_i (A\boldsymbol{x}-\boldsymbol{b})_i^2 \]

    用平方而非绝对值，好处是可导，能求解析解（绝对值在零点不可导， 所以 \(\ell_1\) 问题没有闭式解——这正是上一节提到的对比）。

    六、典型例题¶

    例题 1：求一个向量在直线上的投影¶

    在 \(\mathbb{R}^3\) 中，取 \(\boldsymbol{u} = (1,1,0)\)，\(\boldsymbol{v} = (3,1,2)\)。 求 \(\boldsymbol{v}\) 在 \(\operatorname{span}\{\boldsymbol{u}\}\) 上的投影，以及最短距离。

    思路

    用一维投影公式 \(\frac{\langle v,u\rangle}{\|u\|^2}u\)，误差范数就是最短距离。

    解答

    算内积与范数平方：

    \[ \langle \boldsymbol{v},\boldsymbol{u}\rangle = 3\cdot1 + 1\cdot1 + 2\cdot0 = 4 \]
    \[ \lVert\boldsymbol{u}\rVert^2 = 1^2+1^2+0^2 = 2 \]

    投影（系数 \(= 4/2 = 2\)）：

    \[ \operatorname{proj}_U \boldsymbol{v} = 2(1,1,0) = (2,2,0) \]

    误差向量：

    \[ \boldsymbol{v} - \operatorname{proj}_U\boldsymbol{v} = (3,1,2) - (2,2,0) = (1,-1,2) \]

    验证正交（这是投影的关键性质）：

    \[ \langle (1,-1,2),\ (1,1,0)\rangle = 1\cdot1 + (-1)\cdot1 + 2\cdot0 = 0 \;\checkmark \]

    最短距离：

    \[ \lVert(1,-1,2)\rVert = \sqrt{1+1+4} = \sqrt{6} \]

    结论：最佳逼近点是 \((2,2,0)\)，最短距离 \(\sqrt6\)。

    实用技巧

    永远验证误差与子空间正交。这既是投影的定义性质，也是快速自查手段—— 如果算出的误差不与基向量正交，说明计算有误。

    例题 2：最小二乘拟合直线¶

    用一条过原点的直线 \(y = kx\) 拟合三个数据点 \((1,2)\)、\((2,3)\)、\((3,5)\)。 求最佳 \(k\)。

    思路

    写成 \(A k = \boldsymbol{b}\) 的形式，其中 \(A\) 由 \(x\) 坐标组成，然后解正规方程 \(A^\top A k = A^\top\boldsymbol{b}\)。

    解答

    建立方程（想找 \(k\) 使 \(y_i \approx k x_i\)）：

    \[ \begin{bmatrix} 1 \\ 2 \\ 3 \end{bmatrix} k = \begin{bmatrix} 2 \\ 3 \\ 5 \end{bmatrix} \]

    这个方程组无解（不存在一条过原点的直线同时穿过三个点）。

    列正规方程：

    \[ A^\top A = \begin{bmatrix} 1 & 2 & 3\end{bmatrix}\begin{bmatrix} 1\\2\\3\end{bmatrix} = 1+4+9 = 14 \]
    \[ A^\top\boldsymbol{b} = \begin{bmatrix} 1 & 2 & 3\end{bmatrix}\begin{bmatrix} 2\\3\\5\end{bmatrix} = 2+6+15 = 23 \]

    解出：

    \[ \hat{k} = \frac{23}{14} \approx 1.643 \]

    验证（误差与列空间正交，即与 \(A\) 的列内积为零）：

    拟合值 \(\hat{y} = \frac{23}{14}(1,2,3) = (1.643,\ 3.286,\ 4.929)\)

    误差 \(\boldsymbol{r} = (2,3,5) - (1.643,3.286,4.929) = (0.357,\ -0.286,\ 0.071)\)

    \[ \langle \boldsymbol{r}, A\text{的列}\rangle = 0.357\cdot1 + (-0.286)\cdot2 + 0.071\cdot3 = 0.357 - 0.571 + 0.214 \approx 0 \;\checkmark \]

    （舍入误差范围内为 0，验证成立。）

    常见误解：为什么不是取平均斜率

    若不假思索，可能算三个点的斜率 \(2, 1.5, 1.667\) 再取平均得 \(1.722\)。

    这是错的。最小二乘最小化的是竖直方向的误差平方和 \(\sum(y_i - kx_i)^2\)，不是斜率误差。

    直观看：\(x=3\) 的点误差权重更大（因为 \(kx\) 在那里变化更快）， 所以最小二乘解 \(\frac{23}{14} \approx 1.643\) 会比简单平均更靠近小斜率的解。

    例题 3：格拉姆-施密特正交化¶

    把 \(\boldsymbol{v}_1 = (1,1,0)\)，\(\boldsymbol{v}_2 = (1,0,1)\) 化为规范正交组。

    思路

    先单位化 \(\boldsymbol{v}_1\)，再把 \(\boldsymbol{v}_2\) 减去它在 \(\boldsymbol{e}_1\) 上的投影，最后单位化。

    解答

    第一步：

    \[ \lVert\boldsymbol{v}_1\rVert = \sqrt{1+1+0} = \sqrt2 \]
    \[ \boldsymbol{e}_1 = \frac{1}{\sqrt2}(1,1,0) = \left(\tfrac{1}{\sqrt2},\ \tfrac{1}{\sqrt2},\ 0\right) \]

    第二步：算投影系数

    \[ \langle \boldsymbol{v}_2,\boldsymbol{e}_1\rangle = 1\cdot\tfrac{1}{\sqrt2} + 0\cdot\tfrac{1}{\sqrt2} + 1\cdot0 = \tfrac{1}{\sqrt2} \]

    减去投影：

    \[ \boldsymbol{u}_2 = (1,0,1) - \tfrac{1}{\sqrt2}\left(\tfrac{1}{\sqrt2},\tfrac{1}{\sqrt2},0\right) = (1,0,1) - \left(\tfrac12,\tfrac12,0\right) = \left(\tfrac12,-\tfrac12,1\right) \]

    单位化：

    \[ \lVert\boldsymbol{u}_2\rVert = \sqrt{\tfrac14+\tfrac14+1} = \sqrt{\tfrac32} = \sqrt{\tfrac{3}{2}} \]
    \[ \boldsymbol{e}_2 = \frac{1}{\sqrt{3/2}}\left(\tfrac12,-\tfrac12,1\right) = \sqrt{\tfrac23}\left(\tfrac12,-\tfrac12,1\right) = \left(\tfrac{1}{\sqrt6},\ -\tfrac{1}{\sqrt6},\ \tfrac{2}{\sqrt6}\right) \]

    验证：

    长度

    \[ \lVert\boldsymbol{e}_2\rVert^2 = \tfrac16+\tfrac16+\tfrac46 = 1 \;\checkmark \]

    正交

    \[ \langle\boldsymbol{e}_1,\boldsymbol{e}_2\rangle = \tfrac{1}{\sqrt2}\cdot\tfrac{1}{\sqrt6} + \tfrac{1}{\sqrt2}\cdot\left(-\tfrac{1}{\sqrt6}\right) + 0 = 0 \;\checkmark \]

    例题 4：证明正交补的维数关系¶

    设 \(U\) 是 \(n\) 维内积空间 \(V\) 的 \(m\) 维子空间。证明

    \[ \dim U^{\perp} = n - m \]
    思路

    用 \(V = U \oplus U^\perp\)，再由直和的维数关系推出。

    解答

    第一步：证明 \(U \cap U^\perp = \{\boldsymbol{0}\}\)。

    设 \(\boldsymbol{w} \in U \cap U^\perp\)。由 \(\boldsymbol{w} \in U^\perp\) 得 \(\boldsymbol{w}\) 与 \(U\) 中一切向量正交， 特别地（因 \(\boldsymbol{w} \in U\)）

    \[ \langle \boldsymbol{w},\boldsymbol{w}\rangle = 0 \]

    由内积正定性公理，\(\boldsymbol{w} = \boldsymbol{0}\)。所以交只有零向量， 和 \(U + U^\perp\) 是直和。

    第二步：证明 \(U + U^\perp = V\)。

    任取 \(\boldsymbol{v} \in V\)。取 \(U\) 的一组规范正交基 \(\{\boldsymbol{e}_1,\dots,\boldsymbol{e}_m\}\)（可由格拉姆-施密特得到）， 令

    \[ \boldsymbol{p} = \sum_{k=1}^m \langle\boldsymbol{v},\boldsymbol{e}_k\rangle\boldsymbol{e}_k \in U, \qquad \boldsymbol{q} = \boldsymbol{v} - \boldsymbol{p} \]

    对任意 \(j\) 计算内积（利用 \(\boldsymbol{e}\) 的规范正交性）：

    \[ \langle \boldsymbol{q},\boldsymbol{e}_j\rangle = \langle \boldsymbol{v},\boldsymbol{e}_j\rangle - \sum_{k=1}^m\langle\boldsymbol{v},\boldsymbol{e}_k\rangle\langle\boldsymbol{e}_k,\boldsymbol{e}_j\rangle = \langle \boldsymbol{v},\boldsymbol{e}_j\rangle - \langle \boldsymbol{v},\boldsymbol{e}_j\rangle = 0 \]

    所以 \(\boldsymbol{q}\) 与 \(U\) 的基中每个向量正交，因而 \(\boldsymbol{q} \in U^\perp\)。

    于是 \(\boldsymbol{v} = \boldsymbol{p} + \boldsymbol{q}\) 具有「\(U\) 中元素 + \(U^\perp\) 中元素」的形式， 故 \(V \subseteq U + U^\perp\)；反向包含显然。得 \(V = U + U^\perp\)。

    第三步：用直和维数公式。

    综合两步，\(V = U \oplus U^\perp\)，所以

    \[ n = \dim V = \dim U + \dim U^\perp = m + \dim U^\perp \]

    移项即得

    \[ \dim U^\perp = n - m \qquad\blacksquare \]

    这个结果的用途

    它给出了「自由度」的计数方式。

    场景 解释
    最小二乘 \(A\) 是 \(m\times n\)，\(n > m\) 时零空间维数 \(\geq n-m\)，说明解不唯一
    PCA 降维 从 \(n\) 维投影到 \(m\) 维，被丢弃的是 \(n-m\) 维（正交补方向）
    约束优化 每个等式约束减少一个自由度，正是这个公式

    七、用在哪些课程里¶

    机器人学 · 冗余逆运动学与约束¶

    • 冗余机械臂（关节数 > 任务维数）的最小范数解由伪逆 \(J^+ = J^\top(JJ^\top)^{-1}\) 给出—— 它正是「在满足任务约束的所有解中取范数最小者」，本质是投影
    • 零空间投影：\(I - J^+J\) 把任意关节速度投影到零空间， 实现在不影响末端的前提下调整姿态（避关节极限、避障）

    模式识别 · 最小二乘与 PCA¶

    • 线性回归的解析解 \(\hat{\boldsymbol{w}} = (X^\top X)^{-1}X^\top\boldsymbol{y}\) 就是正规方程
    • PCA：把数据中心化后投影到主特征向量张成的子空间， 被丢弃的部分正是正交补方向上的分量
    • 岭回归：在正规方程上加 \(\lambda I\)，即 \((\lambda I + X^\top X)^{-1}X^\top\boldsymbol{y}\)， 用来处理 \(X^\top X\) 接近奇异的情形

    现代数字信号处理 · 投影与子空间方法¶

    • 投影定理：信号在带限子空间上的最佳逼近就是投影
    • 子空间方法（MUSIC 等）把观测空间分成信号子空间与其正交补（噪声子空间）， 通过正交性来估计频率/到达角
    • 自适应滤波（LMS、RLS）：每一步都在做「误差与输入正交」的更新

    智能传感与信息处理 · 卡尔曼滤波¶

    • 量测更新可写成投影的代数形式： \(\hat{\boldsymbol{x}}_{k|k} = \hat{\boldsymbol{x}}_{k|k-1} + K(\boldsymbol{y} - H\hat{\boldsymbol{x}}_{k|k-1})\)
    • 新息 \(\boldsymbol{y} - H\hat{\boldsymbol{x}}\) 必须与已有估计正交（新息白化条件）， 这正是「误差垂直」在随机情形下的推广

    八、自测¶

    Q1 求 \(\boldsymbol{v} = (1,2,3)\) 在 \(\boldsymbol{u} = (1,1,1)\) 方向上的投影。

    提示

    直接用公式，注意分母是 \(\lVert u\rVert^2\) 而非 \(\lVert u\rVert\)。

    解答
    \[ \langle\boldsymbol{v},\boldsymbol{u}\rangle = 1+2+3 = 6, \qquad \lVert\boldsymbol{u}\rVert^2 = 3 \]

    所以

    \[ \operatorname{proj} = \frac{6}{3}(1,1,1) = (2,2,2) \]

    验证：误差 \((1,2,3)-(2,2,2) = (-1,0,1)\)，与 \(\boldsymbol{u}\) 的内积

    \[ -1+0+1 = 0 \;\checkmark \]

    Q2 判断：若 \(\boldsymbol{u} \perp \boldsymbol{v}\)，则 \(\lVert\boldsymbol{u}+\boldsymbol{v}\rVert^2 = \lVert\boldsymbol{u}\rVert^2+\lVert\boldsymbol{v}\rVert^2\)。反之是否成立？

    提示

    反之要验证「平行四边形对角线相等 \(\Rightarrow\) 正交」，可用内积展开比较。

    解答

    正向成立（勾股定理）。

    展开：

    \[ \lVert\boldsymbol{u}+\boldsymbol{v}\rVert^2 = \lVert\boldsymbol{u}\rVert^2 + 2\langle\boldsymbol{u},\boldsymbol{v}\rangle + \lVert\boldsymbol{v}\rVert^2 \]

    若 \(\boldsymbol{u}\perp\boldsymbol{v}\) 则 \(\langle\boldsymbol{u},\boldsymbol{v}\rangle = 0\)，得等式 ✓

    反向也成立。因为上式右侧与 \(\lVert\boldsymbol{u}\rVert^2+\lVert\boldsymbol{v}\rVert^2\) 相等， 就必须有 \(2\langle\boldsymbol{u},\boldsymbol{v}\rangle = 0\)，即 \(\langle\boldsymbol{u},\boldsymbol{v}\rangle = 0\)， 也就是 \(\boldsymbol{u}\perp\boldsymbol{v}\) ✓

    所以勾股定理是正交的等价刻画（在实内积空间里）。

    推论：可以用勾股定理来检验正交，不必直接算内积。

    Q3 设 \(A\) 是 \(3\times2\) 矩阵，\(\boldsymbol{b}\in\mathbb{R}^3\)。若 \(A^\top A\) 可逆，最小二乘解的几何意义是什么？

    提示

    想想 \(A\boldsymbol{x}\) 能取到哪些点、最佳近似点是什么。

    解答

    \(A\boldsymbol{x}\) 当 \(\boldsymbol{x}\) 取遍 \(\mathbb{R}^2\) 时，取到的是 \(\mathbb{R}^3\) 中由 \(A\) 的两列张成的二维子空间（一个过原点的平面）。

    最小二乘解 \(\hat{\boldsymbol{x}}\) 使 \(A\hat{\boldsymbol{x}}\) 成为 \(\boldsymbol{b}\) 在这个平面上的正交投影。

    几个要点：

    • \(\boldsymbol{b}\) 一般不在平面内（三维里二维子空间装不下所有点），所以原方程无解
    • 误差向量 \(\boldsymbol{b} - A\hat{\boldsymbol{x}}\) 与整个列空间正交， 也就是与 \(A\) 的两列都正交：\(A^\top(\boldsymbol{b}-A\hat{\boldsymbol{x}}) = 0\)
    • 误差落在正交补里，而正交补是 \(3-2=1\) 维的（一条直线）
    • 由于平面过原点，投影不会强制过任何非零点——所以最小二乘拟合一般不含截距项， 要含截距需在 \(A\) 里加一列全 1

    这正是「拟合直线时要加常数项 1」的几何解释。

    Q4 判断：\(U^\perp\) 中的向量与 \(U\) 中每个向量都正交，那么 \(U\) 中向量是否也与 \(U^\perp\) 中每个向量正交？

    提示

    看内积的定义里是否对称。

    解答

    成立。

    内积满足共轭对称：\(\langle\boldsymbol{u},\boldsymbol{v}\rangle = \overline{\langle\boldsymbol{v},\boldsymbol{u}\rangle}\)。 所以 \(\langle\boldsymbol{v},\boldsymbol{u}\rangle = 0 \iff \langle\boldsymbol{u},\boldsymbol{v}\rangle = 0\)， 正交关系是相互的。

    因此 \(U^\perp\) 与 \(U\) 的关系是对称的，也可以写 \((U^\perp)^\perp \supseteq U\)。

    补充：在有限维空间里，进一步有 \((U^\perp)^\perp = U\)（因为两者的维数互补且包含关系成立）。 但在无穷维空间里这个等式一般不成立（只保证 \(\supseteq\)）， 这是泛函分析里的一个经典差别。
