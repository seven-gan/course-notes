    Wasserstein 距离¶

    上一页看到 JS 散度的致命问题：分布不重叠时梯度消失。这一页讲一个 从根本上解决该问题的度量。

    Wasserstein 距离：把一个分布「搬运」成另一个所需的最小代价。

    它也叫「推土机距离」（Earth Mover's Distance, EMD） —— 这个名字很好地说明了它的直观含义。

    Wasserstein 距离相对于 KL/JS 的两个关键优势

    性质 KL JS Wasserstein
    对称 ✗ ✓ ✓
    有界 ✗ ✓ ✗（可无限大）
    分布不重叠时有梯度 ✓（但可能爆炸） ✗ 梯度为零 ✓ 梯度正常
    反映「距离」的几何意义 ✗ ✗ ✓（度量空间中的距离）

    最关键的一行是第三行：Wasserstein 距离即使两个分布 完全不重叠，也仍然给出「它们相距多远」的有意义数值

    这正是 WGAN 稳定的根本原因。

    一、直观定义：搬运土堆的成本¶

    设想：\(p\) 是一堆土（形状由概率密度描述），\(q\) 是另一堆土。

    问题：把 \(p\) 这堆土搬到 \(q\) 的形状，最少需要做多少功？

    定义：

    \[ W(p,q) = \inf_{\gamma\in\Pi(p,q)}\ \int\lvert x-y\rvert\,\mathrm{d}\gamma(x,y) \]

    其中 \(\Pi(p,q)\) 是所有「以 \(p\) 为边缘分布、以 \(q\) 为另一边缘分布」的联合分布 （称为传输方案或耦合）。

    每项的含义：

    量 含义
    \(\gamma(x,y)\) 「把 \(x\) 处的土搬到 \(y\) 处」的方案
    \(\lvert x-y\rvert\) 搬运距离
    \(\int\lvert x-y\rvert\mathrm{d}\gamma\) 总搬运成本
    \(\inf\) 取最省成本的方案

    「最优传输」这个名字的来源

    这个 \(\inf\) 是在所有可行的搬运方案中取最小 —— 所以叫「最优传输」（Optimal Transport）。

    工程类比：

    场景 \(p\) 的含义 \(q\) 的含义 \(W\) 的含义
    土方工程 一堆土 目标地形 最小运输功
    物流 仓库供货 门店需求 最小运费
    生成模型 数据分布 生成分布 最小「改造代价」

    关键在于「距离」被赋予了物理意义： 它不只是「差异多大」，而是「要花多少代价才能变成对方」。

    这就是为什么它能反映「几何结构」 —— 而 KL/JS 只关心「概率值的差异」，不关心「分布之间的空间关系」✗

    二、最简单的情形：一维「点分布」¶

    先看最简例子，它揭示了核心特性。

    设定：\(p = \delta_0\)（质量全在 0）、\(q = \delta_\theta\)（质量全在 \(\theta\)）。

    Wasserstein 距离：

    \[ W(\delta_0,\delta_\theta) = \lvert\theta\rvert \]

    只有一个搬运方案（把 0 处的土全搬到 \(\theta\)），成本就是距离

    三个量的对比（关键表）：

    \(\theta\) \(W = \lvert\theta\rvert\) \(D_{KL}\) \(JSD\)
    \(0\) \(0\) \(0\) \(0\)
    \(0.1\) \(0.1\) \(\infty\) \(\log2\)（饱和）
    \(1\) \(1\) \(\infty\) \(\log2\)（饱和）
    \(100\) \(100\) \(\infty\) \(\log2\)（饱和）

    这张表说明了「为什么 WGAN 稳定」（核心洞察）

    观察三个量的行为：

    量 随 \(\theta\) 增大
    \(D_{KL}\) 立刻 \(\to\infty\)（完全无梯度信息）✗
    \(JSD\) 立刻饱和到 \(\log2\)（梯度为零）✗
    \(W\) 线性增长 ✓

    为什么会这样：

    量 依据什么
    KL/JS 概率值的重叠程度（不重叠就是「无穷大差异」）
    \(W\) 空间中的距离（能算「隔多远」）✓

    梯度行为：

    \[ \frac{\partial W}{\partial\theta} = \operatorname{sign}(\theta) = \pm1 \]

    梯度恒为 \(\pm1\) —— 无论相隔多远，都有稳定的梯度指引方向

    这正是 WGAN 训练稳定的根本原因：

    目标 分布不重叠时的梯度
    JS（原始 GAN） \(0\) → 学不动 ✗
    Wasserstein（WGAN） \(\pm1\) → 持续改进 ✓

    一句话：Wasserstein 距离把「概率差异」换成了「空间距离」， 从而在分布不重叠时仍保留有效信息。

    一维一般情形（有闭式解）¶

    对一维分布，Wasserstein 距离有简洁的闭式表达。

    \(p\) 和 \(q\) 的 \(W_1\) 距离：

    \[ W_1(p,q) = \int_0^1\lvert F_p^{-1}(u)-F_q^{-1}(u)\rvert\,\mathrm{d}u \]

    其中 \(F^{-1}\) 是分位数函数（CDF 的逆）。

    含义：把两个分布的「分位数」逐点相减再积分

    这个公式的实用价值

    它把「两个分布的差异」化为「分位数的差异」 —— 计算上只需排序（对样本）或求逆 CDF。

    对比三个量的计算难度：

    量 从样本估计
    KL / JS 需要密度估计（难，对分箱敏感）✗
    \(W_1\)（一维） 只需排序（\(O(n\log n)\)）✓

    这就是「Wasserstein 距离在实证中好用」的原因之一： 它对样本就能直接估计，不需先估密度。

    高维情形：没有简单闭式解（要用 Kantorovich-Rubinstein 对偶或 Sinkhorn 算法），但一维的结果给了我们关于其性质的可靠理解。

    三、Kantorovich-Rubinstein 对偶（WGAN 的理论基础）¶

    高维 Wasserstein 距离的计算很困难。对偶形式给出了一个可用的替代：

    \[ \boxed{\ W_1(p,q) = \sup_{\lVert f\rVert_L\leq1}\ \Big[E_{x\sim p}[f(x)]-E_{x\sim q}[f(x)]\Big]\ } \]

    其中 \(\lVert f\rVert_L\leq1\) 表示 \(f\) 是 1-Lipschitz 函数：

    \[ \lvert f(x)-f(y)\rvert\leq\lvert x-y\rvert \quad\forall x,y \]

    这个对偶形式是 WGAN 的全部理论基础

    含义：在「斜率不超过 1」的所有函数中， 找使「两个期望之差」最大的那个

    直观理解：

    步骤 说明
    1 选一个「测尺」\(f\)（斜率受限）
    2 算 \(f\) 在 \(p\) 与 \(q\) 上的期望之差
    3 取最大 —— 这就是最「敏感」的测尺

    与 GAN 的对应（这是关键）：

    数学对象 GAN 中的角色
    \(f\) 判别器（critic）
    约束 \(\lVert f\rVert_L\leq1\) 判别器的Lipschitz 约束
    \(E_p[f]-E_q[f]\) 判别器的目标（要最大化）
    \(W_1\) 判别器能达到的最大值（就是 Wasserstein 距离）

    所以 WGAN 的做法：

    步骤 操作
    1 训练一个「critic」\(f\) 来最大化 \(E_p[f]-E_q[f]\)
    2 它给出的值近似就是 \(W_1\)（有实际含义的数值）
    3 生成器最小化这个值（= 最小化 \(W_1\)）

    对比原始 GAN：

    方面 GAN（JS） WGAN（Wasserstein）
    判别器输出 概率 \(\in[0,1]\)（sigmoid） 实数（无 sigmoid）
    损失的含义 JS 的估计 Wasserstein 距离的估计
    损失值可解释 ✗（只是对抗信号） ✓（就是距离，可监控训练）
    不重叠时梯度 \(0\) ✗ 正常 ✓

    WGAN 的一个额外好处：损失值有实际意义 —— 可以直接监控它是否下降来判断训练质量（原始 GAN 的损失没有这个性质）。

    关键实现问题：如何保证 Lipschitz 约束¶

    这是 WGAN 最棘手的工程细节。

    方法 做法 问题
    权重裁剪（原始 WGAN） 每次更新后把权重裁到 \([-c,c]\) 会导致梯度消失或爆炸；\(c\) 难调 ✗
    梯度惩罚（WGAN-GP） 加惩罚项 \(\lambda(E_{\hat x}[\lVert\nabla f(\hat x)\rVert-1]^2)\) 效果好 ✓ 但需算二阶梯度（慢）
    谱归一化（SNGAN） 对每层权重做谱范数归一化 高效 ✓ 计算便宜
    一致性项（CT-GAN） 用有限差分近似 Lipschitz 约束 折中

    「权重裁剪」为什么会导致问题（值得理解）

    做法：每步把所有权重限制在 \([-c,c]\) 内。

    问题 1：\(c\) 很难选

    \(c\) 取值 后果
    太小 大部分权重被裁到边界 → 梯度消失 ✗
    太大 Lipschitz 约束太松 → 训练不稳定 ✗

    问题 2：权重集中在边界

    若 \(c = 0.01\)，许多权重会被反复裁到 \(\pm0.01\) —— 这使网络表达能力受限，且梯度也会被裁剪（梯度消失）✗

    问题 3：与「保证 Lipschitz」的关系不直接

    裁剪确实能给出 Lipschitz 上界（因为每层的 Lipschitz 常数有界）， 但上界很松，且牺牲了太多容量。

    改进方案的核心思想：直接约束「梯度范数 ≈ 1」 —— 这正是 WGAN-GP 的梯度惩罚做的：

    \[ \mathcal{L}_{\text{GP}} = \lambda\,E_{\hat x}\big[(\lVert\nabla_{\hat x}f(\hat x)\rVert_2-1)^2\big] \]

    其中 \(\hat x\) 是在 \(p\) 与 \(q\) 的连线上采样的点。

    为什么用「连线上的点」：

    最优的 \(f\) 在 \(p\) 与 \(q\) 之间的「传输路径」上梯度范数恰为 1 （这是最优传输理论的结果）—— 所以只需在这条带上施加约束

    代价：需要计算二阶导（对 \(\nabla f\) 再求导），计算成本高。

    所以实践中：

    场合 推荐
    追求效果 WGAN-GP
    追求效率（大模型） 谱归一化（SNGAN）
    简单实验 权重裁剪（但注意调 \(c\)）

    四、典型例题¶

    例题 1：点分布的 Wasserstein 距离¶

    设 \(p = \delta_0\)、\(q = \delta_3\)。求 \(W_1(p,q)\)，并说明梯度性质。

    思路

    点分布只有一种搬运方案。

    解答

    唯一的搬运方案：把 0 处的全部质量搬到 3。

    \[ W_1(\delta_0,\delta_3) = 1\times\lvert0-3\rvert = 3 \]

    结果：\(W_1 = 3\)

    梯度性质（把 \(q\) 的参数化为 \(\theta\)）：

    \[ W(\theta) = \lvert\theta\rvert \]
    \[ \frac{\partial W}{\partial\theta} = \operatorname{sign}(\theta) = \begin{cases}+1, & \theta>0\\ -1, & \theta<0\end{cases} \]

    梯度恒为 \(\pm1\) ✓ 不饱和、不消失

    对比 JS 散度：

    量 值 梯度
    \(W_1\) \(3\) \(\pm1\) ✓
    \(JSD\) \(\log2\)（饱和） \(0\) ✗

    这个对比是「WGAN 优于 GAN」的最小说明

    场景：初始时生成分布离数据分布很远（\(\theta = 3\)）。

    用 JS 训练：

    \[ \frac{\partial JSD}{\partial\theta} = 0 \]

    梯度为零 → 生成器得不到任何指引 ✗ （理论上它会「随机游走」直到碰巧重叠 —— 所以早期 GAN 训练极不稳定。）

    用 Wasserstein 训练：

    \[ \frac{\partial W}{\partial\theta} = -1 \]

    梯度清晰指向「减小距离」的方向 而且距离越远，改进的绝对量越大（线性关系）。

    这就是「WGAN 训练稳定、不需要精心平衡生成器与判别器」的原因

    实践观察：

    现象 原始 GAN WGAN
    早期生成质量 随机/崩溃 逐步改善
    损失曲线 无意义（震荡） 单调下降（可监控）
    超参数敏感性 高 较低

    例题 2：一维高斯分布的 \(W_1\)¶

    设 \(p = N(\mu_1,\sigma^2)\)、\(q = N(\mu_2,\sigma^2)\)（方差相同）。 用分位数公式求 \(W_1\)。

    思路

    同方差正态的分位数函数形状相同（只差平移），所以逐点差是常数。

    解答

    第一步：分位数函数

    正态 \(N(\mu,\sigma^2)\) 的分位数函数：

    \[ F^{-1}(u) = \mu+\sigma\Phi^{-1}(u) \]

    其中 \(\Phi^{-1}\) 是标准正态的分位数函数。

    第二步：两点相减

    \[ F_p^{-1}(u)-F_q^{-1}(u) = (\mu_1+\sigma\Phi^{-1}(u))-(\mu_2+\sigma\Phi^{-1}(u)) = \mu_1-\mu_2 \]

    \(\Phi^{-1}(u)\) 项完全抵消 ✓（因为方差相同）

    第三步：代入公式

    \[ W_1 = \int_0^1\lvert\mu_1-\mu_2\rvert\,\mathrm{d}u = \lvert\mu_1-\mu_2\rvert \]

    结果：

    \[ \boxed{\ W_1 = \lvert\mu_1-\mu_2\rvert\ } \]

    含义：同方差下，\(W_1\) 就等于均值之差的绝对值 —— 完全符合直觉

    回到例题 1 的饱和对比：

    \(\lvert\mu_1-\mu_2\rvert\) \(W_1\) \(JSD\)
    \(1\) \(1\) \(0.161\)
    \(5\) \(5\) \(0.975\)
    \(10\) \(10\) \(1.000\)（已饱和）
    \(100\) \(100\) \(1.000\)（不变！）

    对比鲜明：

    量 \(\mu\) 差从 5 增到 100（×20）
    \(W_1\) \(5\to100\)（×20） ✓
    \(JSD\) \(0.975\to1.000\)（仅 +2.6%）✗

    \(W_1\) 忠实反映距离，而 \(JSD\) 早已饱和

    注意「方差相同」这个前提：

    若方差不同，则分位数之差不再是常数 —— 公式变为：

    \[ W_1 = \int_0^1\lvert(\mu_1-\mu_2)+(\sigma_1-\sigma_2)\Phi^{-1}(u)\rvert\,\mathrm{d}u \]

    需要数值积分（没有简单的闭式解）。

    两个高斯的一般 \(W_2\)（二次型）：

    \[ W_2^2 = (\mu_1-\mu_2)^2+(\sigma_1-\sigma_2)^2 \]

    这个形式很漂亮：均值差 + 标准差差的平方和 （注意是 \(W_2\) 的平方，\(W_2\) 是其平方根。）

    例题 3：为什么 KL 在点分布上无穷大¶

    设 \(p = \delta_0\)、\(q = \delta_1\)。求 \(D_{KL}(p\|q)\) 并解释。

    思路

    两个分布的支撑完全不重叠。

    解答

    计算：

    \[ D_{KL}(p\|q) = \sum_x p(x)\log\frac{p(x)}{q(x)} \]
    \(x\) \(p(x)\) \(q(x)\) 项
    \(0\) \(1\) \(0\) \(1\times\log\frac{1}{0} = \mathbf{+\infty}\)
    \(1\) \(0\) \(1\) \(0\)
    \[ D_{KL}(p\|q) = +\infty \]

    结果：\(D_{KL} = +\infty\)

    为什么会无穷大（关键理解）

    原因：\(p\) 在 \(x=0\) 处有全部质量，但 \(q(0) = 0\) —— 即「\(q\) 认为这件事不可能，但 \(p\) 说它是必然的」。

    信息论解读：若用 \(q\) 去编码由 \(p\) 产生的数据点 \(x=0\)， 则 \(-\log q(0) = +\infty\) —— 需要无限多比特 ✗

    这个「无穷大」在优化中的后果：

    后果 说明
    无法计算梯度 无穷大处不可导
    无法比较不同距离 都是 \(\infty\)，分不出「近一点」和「远得多」
    训练完全停滞 无信息可用

    而 \(W_1 = 1\)（例题 1 的方法）✓ —— 有限、有意义、有梯度

    三个量在「完全不重叠」时的表现（总结）：

    量 值 可用性
    \(D_{KL}\) \(+\infty\) 完全不可用 ✗
    \(JSD\) \(\log2\)（常数） 无梯度 ✗
    \(W_1\) 有限且反映距离 ✓ 可用

    这就是「Wasserstein 是三者中唯一在分布不重叠时仍然有效的 优化目标」的完整说明

    实践中的缓解手段（若坚持用 KL）：

    方法 做法
    加噪声 对数据加小噪声，使支撑重叠
    标签平滑 避免预测概率为 0 或 1
    用 \(\varepsilon\) 平滑 \(q\to(1-\varepsilon)q+\varepsilon\cdot\text{uniform}\)

    注意「加噪声」的现实依据：真实数据本身总是有噪声的 —— 所以「完全不重叠」在实践中更多是高维稀疏性造成的数值问题， 而不是物理事实。

    例题 4：WGAN 的判别器与 GAN 的对比¶

    说明 WGAN 与传统 GAN 在判别器设计上的三个关键差别。

    思路

    对照 Kantorovich-Rubinstein 对偶，看 \(f\) 需要满足什么。

    解答

    差别 1：输出层去掉 sigmoid

    网络 输出 含义
    GAN 的判别器 \(D\) \(\in[0,1]\)（概率） 「这张图多真」
    WGAN 的 critic \(f\) 实数（无激活） 万一个「分数」

    为什么：对偶形式中的 \(f\) 是任意实值函数（只受 Lipschitz 约束）， 不需要是概率 ✗

    差别 2：目标函数不同

    网络 目标
    GAN 判别器 最大化 \(\log D(x)+\log(1-D(G(z)))\)
    WGAN critic 最大化 \(E_{p}[f]-E_{q}[f]\)

    注意 WGAN 的目标里没有 log ✓ —— 这就是它能给出「距离」的原因。

    差别 3：需要 Lipschitz 约束

    网络 约束
    GAN 无特别约束（sigmoid 天然有界）
    WGAN 必须加 Lipschitz 约束（否则 \(E_p[f]-E_q[f]\) 可以无限大）✗

    若不加约束会发生什么：

    \[ \sup_f\big[E_p[f]-E_q[f]\big] = +\infty \]

    （取 \(f\) 斜率为任意大的线性函数即可。）

    所以约束是必需的，这也是 WGAN 实现上的主要难点。

    三个差别的「逻辑链」（这是理解 WGAN 的关键）

    从「想要什么」推到「怎么做」：

    步骤 内容
    1. 想要 一个「分布不重叠时也有梯度」的度量
    2. 选择 Wasserstein 距离 \(W_1\)（因为它反映几何距离）
    3. 问题 \(W_1\) 的定义（最优化搬运方案）难以直接计算
    4. 转机 Kantorovich-Rubinstein 对偶把它变成「求函数的最大期望差」
    5. 实现 用一个神经网络 \(f\) 来近似那个「最优函数」
    6. 代价 必须保证 \(f\) 是 1-Lipschitz（否则上确界无穷）
    7. 方案 权重裁剪 / 梯度惩罚 / 谱归一化

    这条链说明了：WGAN 不是「随便改改」，而是从数学目标出发的严格设计

    与「对抗训练」的关系：

    视角 说明
    GAN 的叙事 「生成器与判别器对抗」
    WGAN 的叙事 「估计并用 Wasserstein 距离作为损失」

    后者更清晰 —— 因为 \(f\) 的角色是「距离的估计器」， 而不是「真假的裁判」

    这也解释了 WGAN 的两个实践优势：

    优势 原因
    损失值可监控 它就是距离的估计（有物理意义）
    不需要平衡两个网络 目标清晰、梯度不饱和

    工程建议：

    目标 选择
    追求图像质量（有大量算力） 原始 GAN + 各种技巧（StyleGAN 系列）
    训练稳定性优先 WGAN-GP ✓
    大模型、效率优先 谱归一化 + Hinge 损失
    从零开始调试 WGAN 最容易调通 ✓

    五、三个量的完整对比（总结表）¶

    这张表把信息论这一系列的核心结论汇总起来。

    量 定义 对称 有界 三角不等式 不重叠时
    KL 散度 \(\sum p\log\frac{p}{q}\) ✗ ✗ ✗ \(+\infty\) ✗
    JS 散度 到中点的 KL 平均 ✓ ✓（\(\log2\)） ✗ \(\log2\)（饱和，梯度为零）✗
    \(\sqrt{JSD}\) JS 开平方 ✓ ✓ ✓ 常数 ✗
    总变差 \(\frac12\sum\lvert p-q\rvert\) ✓ ✓（\(1\)） ✓ \(1\)（饱和）✗
    \(W_1\) 最优搬运成本 ✓ ✗ ✓ 有限且反映距离 ✓

    选择指南（实用总结）

    任务 推荐 理由
    分类/回归训练 交叉熵（= 前向 KL） 与 MLE 等价，梯度简洁
    生成模型（求稳定） Wasserstein 不重叠时有梯度
    需要严格度量 \(\sqrt{JSD}\) 或 \(W_1\) 满足三角不等式
    需要「覆盖所有模式」 前向 KL 零避免性质
    需要「精确锁定模式」 反向 KL 零强迫性质
    聚类/近邻搜索 \(\sqrt{JSD}\) 或 \(W_1\) 度量空间算法适用
    分布不重叠 \(W_1\) 唯一有效的

    一条实用的判断规则：

    \[ \text{若两个分布可能不重叠} \Rightarrow \text{优先考虑 Wasserstein} \]

    这在实践中包括：

    场景 为何容易不重叠
    高维生成模型 低维流形在高维空间中几乎不相交
    稀疏/离散数据 支撑是离散点集
    小样本 经验分布支撑有限

    而在「分类」这类任务中，交叉熵仍是首选 —— 因为模型输出与标签都是同维概率向量，天然重叠 （softmax 输出永远不会恰好为零，除非数值下溢。）

    六、自测¶

    Q1 设 \(p = \delta_0\)、\(q = \delta_5\)。求 \(W_1\)，并与 \(JSD\) 比较梯度性质。

    提示

    点分布只有一种搬运方案；梯度是 sign 函数。

    解答

    Wasserstein 距离：

    \[ W_1(\delta_0,\delta_5) = 1\times\lvert0-5\rvert = 5 \]

    梯度（把 \(q\) 参数化为 \(\delta_\theta\)）：

    \[ W(\theta) = \lvert\theta\rvert \implies \frac{\partial W}{\partial\theta} = \operatorname{sign}(\theta) \]

    在 \(\theta = 5\) 处：

    \[ \frac{\partial W}{\partial\theta} = -1 \]

    （负号表示「减小 \(\theta\) 能减小 \(W\)」——这正是优化方向。）

    结果对比：

    量 值 梯度
    \(W_1\) \(5\) \(1\)（恒定）✓
    \(JSD\) \(\log2 = 1\)（饱和） \(0\) ✗

    关键解读：

    \(W_1\) 的数值随距离线性增长：

    \(\theta\) \(W_1\) \(JSD\)
    \(1\) \(1\) \(0.161\)
    \(5\) \(5\) \(0.975\)
    \(100\) \(100\) \(1.000\)

    即「\(W_1\) 能区分 5 与 100，而 JSD 不能」 ✓

    工程含义：用 \(W_1\) 训练时，即使生成分布离数据分布很远， 梯度仍然清晰地指向「靠近」的方向 —— 这是 WGAN 训练稳定的根本原因。

    Q2 求两个同方差正态分布 \(N(0,1)\) 与 \(N(3,1)\) 的 \(W_1\)。

    提示

    用分位数公式，注意同方差。

    解答

    分位数函数：

    \[ F_p^{-1}(u) = \mu_p+\sigma\Phi^{-1}(u) \]

    逐点相减：

    \[ F_p^{-1}(u)-F_q^{-1}(u) = (0+\sigma\Phi^{-1}(u))-(3+\sigma\Phi^{-1}(u)) = -3 \]

    \(\Phi^{-1}(u)\) 项抵消（因为方差相同）

    代入 \(W_1\) 公式：

    \[ W_1 = \int_0^1\lvert-3\rvert\,\mathrm{d}u = 3 \]

    结果：

    \[ W_1 = \lvert\mu_1-\mu_2\rvert = 3 \]

    一般结论（同方差）：

    \[ W_1\big(N(\mu_1,\sigma^2),\ N(\mu_2,\sigma^2)\big) = \lvert\mu_1-\mu_2\rvert \]

    为什么这么简单：

    原因 说明
    两个正态形状相同 只差一个平移
    所以分位数只差常数 \(\Phi^{-1}(u)\) 项抵消
    常数差积分就是它本身 \(W_1 = \lvert\Delta\mu\rvert\)

    对比 \(W_2\)（二次型）：

    \[ W_2^2 = (\mu_1-\mu_2)^2+(\sigma_1-\sigma_2)^2 \]

    同方差时 \(\sigma_1 = \sigma_2\)，所以 \(W_2 = \lvert\mu_1-\mu_2\rvert\) ✓ —— 与 \(W_1\) 相同（对这个特殊情形）。

    一般情形（方差不同） 需要数值积分，因为 \((\sigma_1-\sigma_2)\Phi^{-1}(u)\) 项不再抵消。

    Q3 为什么 Wasserstein 距离在分布「完全不重叠」时仍然有效？

    提示

    想想它依据的是「概率重叠」还是「空间距离」。

    解答

    因为它度量的是「搬运成本」（空间距离），而不是「概率重叠程度」。

    根本区别：

    量 依据什么 不重叠时的表现
    KL 概率值的比值 \(+\infty\)
    JS 概率值的重叠 \(\log2\)（饱和）
    \(W_1\) 空间中的搬运距离 有限，且反映距离 ✓

    具体说明（\(p = \delta_0\)、\(q = \delta_\theta\)）：

    量 计算 结果
    KL \(q(0) = 0\) 而 \(p(0) = 1\) → 除零 \(+\infty\)
    JS 两分布「完全不重叠」→ 上界 \(\log2\)（与 \(\theta\) 无关）
    \(W_1\) 把 0 处的质量搬到 \(\theta\) \(\lvert\theta\rvert\)

    \(W_1\) 完全不关心「概率值是否重合」 —— 它只关心「这些质量需要搬多远」

    这个差异的深层含义：

    视角 说明
    KL/JS 「点对点」比较概率密度
    \(W_1\) 「整体搬移」的几何代价

    所以 \(W_1\) 能感知「分布之间的空间关系」 —— 而 KL/JS 不能 ✓

    工程后果（这就是 WGAN 的动机）：

    场景 KL/JS \(W_1\)
    生成分布在数据分布旁边（很近但不重叠） 梯度为零/无穷 ✗ 距离很小，梯度正常 ✓
    生成分布离得很远 无法区分远近 ✗ 距离大，梯度大 ✓

    一句话：\(W_1\) 把「概率差异」换成了「空间距离」， 从而在最有挑战的场景（高维不重叠）中仍保留有效信息。

    Q4 为什么 WGAN 必须对判别器加 Lipschitz 约束？

    提示

    看对偶形式 \(\sup_f[E_p[f]-E_q[f]]\)，想想 \(f\) 无约束会怎样。

    解答

    因为不加约束时，那个上确界是无穷大 —— 目标函数没有意义。

    对偶形式：

    \[ W_1(p,q) = \sup_{\lVert f\rVert_L\leq1}\big[E_{x\sim p}[f(x)]-E_{x\sim q}[f(x)]\big] \]

    若去掉「\(\lVert f\rVert_L\leq1\)」这个约束：

    取 \(f(x) = cx\)（斜率 \(c\) 任意大），则

    \[ E_p[f]-E_q[f] = c\,(\mu_p-\mu_q) \]

    随 \(c\to\infty\)，这个值 \(\to\infty\) ✗

    具体数值（\(\mu_p = 1\)、\(\mu_q = 0\)）：

    \(c\) \(E_p[f]-E_q[f]\)
    \(1\) \(1\)
    \(10\) \(10\)
    \(1000\) \(1000\)
    \(\to\infty\) \(\to\infty\) ✗

    所以约束是「数学上必需的」（不是调参选择）

    但约束的「紧度」也很关键：

    约束 问题
    太松（\(L\) 很大） 上确界很大，训练不稳
    恰好 \(L = 1\) 上确界 = \(W_1\)（正是我们要的） ✓
    太紧（\(L\) 很小） 表达能力受限，低估距离 ✗

    三种实现方式的比较：

    方法 做法 优点 缺点
    权重裁剪 裁到 \([-c,c]\) 简单 \(c\) 难调，易梯度消失
    梯度惩罚 加 \((\lVert\nabla f\rVert-1)^2\) 项 效果好 ✓ 需二阶导（慢）✗
    谱归一化 归一化每层谱范数 高效 ✓ 稍弱于 GP

    梯度惩罚为什么用「连线上的点」：

    由最优传输理论，最优的 \(f\) 在 \(p\) 与 \(q\) 之间的传输路径上 梯度范数恰为 1 —— 所以只需在这条带上施加约束

    实践建议：

    目标 选择
    效果优先 WGAN-GP
    效率优先（大模型） 谱归一化
    快速原型 权重裁剪（注意调 \(c\)）
    上一页
    JS 散度
    下一页
    总览
