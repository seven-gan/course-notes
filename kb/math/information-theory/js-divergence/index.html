    JS 散度¶

    上一页的 KL 散度有个实用缺陷：它不对称。这一页讲一个简单的修正 —— JS 散度：

    JS 散度 = 「到两分布中点的 KL」的对称平均。

    它同时解决了 KL 的另一个问题：无界。

    JS 散度修正了 KL 的两个缺陷

    缺陷 KL 散度 JS 散度
    不对称 \(D_{KL}(p\;\lvert\;q)\neq D_{KL}(q\;\lvert\;p)\) ✓ 对称
    可能无界 \(q(x)\to0\) 而 \(p(x)>0\) 时 \(\to\infty\) ✓ 有界（\(\leq\log2\)）

    有界这一点很重要：它让 JS 散度更适合作为优化目标（迭代更稳定）

    这就是 GAN 原始论文用 JS 散度的原因 —— 但同时也埋下了它后来被 Wasserstein 距离取代的伏笔（下一节讲）。

    一、JS 散度的定义¶

    定义：先取两个分布的平均分布

    \[ m = \frac{p+q}{2} \]

    则 JS 散度为

    \[ \boxed{\ JSD(p\|q) = \frac12D_{KL}(p\|m)+\frac12D_{KL}(q\|m)\ } \]

    要点：「\(p\) 和 \(q\) 各自到它们的中间点的 KL 的平均」。

    这个定义的两点精心设计

    设计 1：为什么取「到中点」而不是「互相之间」

    若直接对称化（如 \(D_{KL}(p\|q)+D_{KL}(q\|p)\)）：

    问题 说明
    仍然可能无界 任一方向发散则整体发散
    值可能很大 不利于优化

    而用「到中点」：

    优点 说明
    有界 因为 \(p\) 与 \(m\) 总是「互相有覆盖」
    数值稳定 不会出现除以零

    设计 2：为什么前面有 \(\frac12\)

    这是归一化：使 JS 的上界恰好是 \(\log 2\)（而非 \(2\log2\)）。

    物理含义：\(\log2\) 比特正是「两个完全不同的分布之间」的距离 —— 这与「1 比特 = 一个二值判断」的直觉一致

    有界性的证明¶

    \[ JSD(p\|q)\leq\log 2 \]

    证明：

    每个 KL 项 \(\leq\log2\)（因为两个分布在中点处总有共同支撑）：

    \[ D_{KL}(p\|m) = \sum_x p(x)\log\frac{p(x)}{m(x)} \]

    注意 \(m(x) = \frac{p(x)+q(x)}{2}\geq\frac{p(x)}{2}\)，所以

    \[ \frac{p(x)}{m(x)} = \frac{p(x)}{(p(x)+q(x))/2}\leq\frac{p(x)}{p(x)/2} = 2 \]

    因此

    \[ D_{KL}(p\|m)\leq\sum_x p(x)\log 2 = \log 2 \]

    两项目各 \(\leq\log2\)，取平均后

    \[ JSD\leq\frac12\log2+\frac12\log2 = \log2 \;\checkmark \]

    等号条件：\(p\) 与 \(q\) 的支撑完全不重叠（完全不同的分布）。

    其他性质¶

    性质 内容
    对称 \(JSD(p\;\lvert\;q) = JSD(q\;\lvert\;p)\) ✓
    非负 \(JSD\geq0\)
    为零 \(= 0\iff p = q\)
    有界 \(\leq\log2\)
    开了平方后是距离 \(\sqrt{JSD}\) 满足三角不等式 ✓

    「√JSD 是真正的距离」这个性质很有价值

    JSD 本身仍不满足三角不等式（它不是度量）。

    但它的平方根满足 —— 这被称为「JS 距离」：

    \[ d_{JS}(p,q) = \sqrt{JSD(p\|q)} \]

    这意味着：

    用途 说明
    可以用于度量空间中的算法 如聚类（k-means 变体）、近邻搜索
    满足「三角形不等式」 便于界估计与剪枝
    理论保证 可以套用度量空间的理论结果

    对比其它散度：

    量 对称 有界 三角不等式
    KL ✗ ✗ ✗
    JSD ✓ ✓ ✗
    \(\sqrt{JSD}\) ✓ ✓ ✓
    总变差距离 ✓ ✓ ✓

    二、JS 散度与交叉熵/熵的关系¶

    JS 散度可以用熵表示：

    \[ JSD(p\|q) = H(m)-\frac{H(p)+H(q)}{2} \]

    推导：

    \[ D_{KL}(p\|m) = \sum p\log\frac{p}{m} = -H(p)-\sum p\log m \]
    \[ D_{KL}(q\|m) = -H(q)-\sum q\log m \]

    取平均：

    \[ \frac12[D_{KL}(p\|m)+D_{KL}(q\|m)] = -\frac{H(p)+H(q)}{2}-\sum\frac{p+q}{2}\log m \]

    注意最后一项

    \[ \sum\frac{p(x)+q(x)}{2}\log m(x) = \sum m(x)\log m(x) = -H(m) \]

    所以

    \[ JSD = -\frac{H(p)+H(q)}{2}+H(m) \;\checkmark \]

    这个熵形式的实用价值

    含义：

    \[ JSD = \underbrace{H(m)}_{\text{中点的熵}}-\underbrace{\frac{H(p)+H(q)}{2}}_{\text{两分布熵的平均}} \]

    解读：「混合」使熵增加的部分 —— 两个分布混合后，如果不确定性增大了，说明它们有差异

    情形 \(H(m)\) 与平均熵的关系 JSD
    \(p = q\) 相等（混合无影响） \(0\)
    \(p\) 与 \(q\) 完全不同 \(H(m)\) 大得多 大（接近 \(\log2\)）

    工程用法：只需三个熵就能算 JS —— 与「互信息 = 三个熵的组合」结构类似

    这也说明了 JS 与互信息的平行关系：

    量 形式 度量什么
    互信息 \(H(X)+H(Y)-H(X,Y)\) 变量间的依赖
    JS 散度 \(H(m)-\frac{H(p)+H(q)}{2}\) 两个分布的距离

    两者都是「混合/联合后熵的变化量」的度量

    三、JS 散度在 GAN 中的角色（以及它的问题）¶

    GAN 的原始目标¶

    生成对抗网络（GAN）的原始论文把问题写成：

    \[ \min_G\max_D\ \underbrace{E_{x\sim p_{\text{data}}}[\log D(x)]+E_{z}[\log(1-D(G(z)))]}_{\text{判别器的目标}} \]

    关键结论（论文证明）：对固定的生成器 \(G\)，最优判别器为

    \[ D^*(x) = \frac{p_{\text{data}}(x)}{p_{\text{data}}(x)+p_g(x)} \]

    此时生成器的目标等价于

    \[ \min_G\ 2\,JSD(p_{\text{data}}\|p_g)-\log 4 \]

    即「最小化数据分布与生成分布的 JS 散度」

    这个等价性揭示了 GAN 训练困难的根源（关键洞察）

    问题：当两个分布「不重叠」时，JS 散度为常数 \(\log2\) —— 梯度为零 ✗

    具体分析：

    情形 \(JSD\) 梯度
    两分布有重叠 \(<\log2\) 非零 ✓
    完全不重叠 \(=\log2\)（饱和） 零 ✗

    为什么会不重叠（在训练早期很常见）：

    原因 说明
    数据分布往往集中在低维流形上 高维空间中两个低维流形几乎必然不交
    生成分布初始时随机 与数据分布几乎不重叠
    高维空间的「体积集中」 随机分布之间距离远

    后果：

    \[ \text{梯度消失} \implies \text{生成器学不到东西} ✗ \]

    这就是「GAN 难训练」的信息论解释

    原始 GAN 论文的补救：把生成器目标从 \(\log(1-D)\) 改为 \(-\log D\)（「非饱和损失」）：

    目标 梯度行为（\(D\) 很小时）
    \(\log(1-D)\)（饱和） 梯度 \(\to0\) ✗
    \(-\log D\)（非饱和） 梯度大 ✓

    但注意：这改变了优化的目标（不再严格等价于最小化 JS）—— 只是一个更实用的启发式。

    更根本的解决：换一个「即使在完全不重叠时也有梯度」的度量 —— 这就是Wasserstein 距离（下一节）。

    补充：「JS 散度饱和」的一个简单例子¶

    一维情形：设真实分布是 \(\delta_0\)（集中在 0）， 生成分布是 \(\delta_\theta\)（集中在 \(\theta\)）。

    \(\theta\) 支撑重叠？ \(JSD\) 梯度
    \(0\) 完全重叠 \(0\) —
    \(\theta\neq0\) 完全不重叠 \(\log2\) \(0\) ✗

    结论：只要 \(\theta\neq0\)，梯度都是零 —— 生成器无法通过梯度「逐步靠近」✗

    而如果用 Wasserstein 距离：

    \[ W(\delta_0,\delta_\theta) = \lvert\theta\rvert \]

    梯度恒为 \(\pm1\) ✓ —— 可以持续改进！

    这就是「WGAN 更稳定」的核心原因 ✓

    四、典型例题¶

    例题 1：计算 JS 散度¶

    设 \(p = (0.5, 0.5)\)、\(q = (0.9, 0.1)\)。求 \(JSD(p\|q)\) 与 \(\sqrt{JSD}\)。

    思路

    先算中点 \(m\)，再算两个 KL 散度。

    解答

    第一步：中点分布

    \[ m = \frac{p+q}{2} = \left(\frac{0.5+0.9}{2},\ \frac{0.5+0.1}{2}\right) = (0.7,\ 0.3) \]

    第二步：两个 KL 散度

    \[ D_{KL}(p\|m) = 0.5\log_2\frac{0.5}{0.7}+0.5\log_2\frac{0.5}{0.3} \]

    （\(\log_2(5/7) = -0.485\)、\(\log_2(5/3) = 0.737\)）

    \[ = 0.5\times(-0.485)+0.5\times0.737 = -0.243+0.369 = 0.126\ \text{比特} \]
    \[ D_{KL}(q\|m) = 0.9\log_2\frac{0.9}{0.7}+0.1\log_2\frac{0.1}{0.3} \]

    （\(\log_2(9/7) = 0.363\)、\(\log_2(1/3) = -1.585\)）

    \[ = 0.9\times0.363+0.1\times(-1.585) = 0.327-0.159 = 0.168\ \text{比特} \]

    第三步：JS 散度

    \[ JSD = \frac{0.126+0.168}{2} = 0.147\ \text{比特} \]

    第四步：JS 距离

    \[ \sqrt{JSD} = \sqrt{0.147} \approx 0.383 \]

    结果：

    量 值
    \(D_{KL}(p\;\lvert\;m)\) \(0.126\)
    \(D_{KL}(q\;\lvert\;m)\) \(0.168\)
    \(JSD\) \(0.147\)
    \(\sqrt{JSD}\) \(0.383\)

    验证有界性：\(0.147 < \log_2 2 = 1\)

    对比 KL 散度的值（上一页算过）：

    量 值
    \(D_{KL}(p\;\lvert\;q)\) \(0.737\)
    \(D_{KL}(q\;\lvert\;p)\) \(0.531\)
    \(JSD\) \(0.147\)

    注意 JS 比两者都小得多 —— 这是因为它度量的是「到中点的距离」， 而中点比任一端都更接近两者

    这也说明：JS 与 KL 的数值不可直接比较（含义不同）。

    用熵形式交叉验证

    \[ JSD = H(m)-\frac{H(p)+H(q)}{2} \]
    \[ H(m) = -0.7\log_2 0.7-0.3\log_2 0.3 = 0.7\times0.515+0.3\times1.737 = 0.361+0.521 = 0.881 \]
    \[ H(p) = 1.0,\qquad H(q) = -0.9\log_2 0.9-0.1\log_2 0.1 = 0.137+0.332 = 0.469 \]
    \[ JSD = 0.881-\frac{1.0+0.469}{2} = 0.881-0.735 = 0.146 \;\checkmark \]

    与前面的 \(0.147\) 一致（差异来自舍入）

    这验证了两种算法等价 —— 实践中用熵形式更方便（只需三个熵）。

    例题 2：完全不同的分布¶

    设 \(p = (1, 0)\)、\(q = (0, 1)\)（支撑完全不重叠）。求 \(JSD\) 与其梯度性质。

    思路

    中点分布是 \((0.5, 0.5)\)，然后算两个 KL。

    解答

    第一步：中点分布

    \[ m = \left(\frac{1+0}{2},\ \frac{0+1}{2}\right) = (0.5,\ 0.5) \]

    第二步：两个 KL 散度

    \[ D_{KL}(p\|m) = 1\times\log_2\frac{1}{0.5}+0 = \log_2 2 = 1\ \text{比特} \]
    \[ D_{KL}(q\|m) = 0+1\times\log_2\frac{1}{0.5} = 1\ \text{比特} \]

    第三步：JS 散度

    \[ JSD = \frac{1+1}{2} = 1\ \text{比特} = \log_2 2 \;\checkmark \]

    结果：\(JSD = \log2 = 1\) 比特 —— 恰好取到上界

    验证上界：\(JSD\leq\log2\)，此处取等号

    这个例子正是 GAN 训练困难的「教科书情形」

    关键观察：只要两分布完全不重叠，\(JSD\) 就恒为 \(\log2\) —— 与「不重叠的程度」无关 ✗

    举一个连续的参数化例子（一维高斯）：

    设 \(p = N(0,1)\)、\(q = N(\mu,1)\)（均值不同，方差相同）。

    \(\mu\) 支撑重叠 \(JSD\)
    \(0\) 完全 \(0\)
    \(1\) 大部分重叠 小
    \(5\) 极少重叠 接近 \(\log2\)
    \(100\) 几乎毫不重叠 \(\approx\log2\)（饱和）

    随着 \(\mu\) 增大，\(JSD\) 迅速饱和到 \(\log2\) —— \(\mu\) 从 5 增到 100，\(JSD\) 几乎不变 ✗

    后果：

    \[ \frac{\partial JSD}{\partial \mu}\to0 \]

    梯度消失 → 无法用梯度下降把 \(q\) 拉向 \(p\) ✗

    这就是「JS 散度不适合作为远距离分布的优化目标」的原因

    Wasserstein 距离的对比（下一节）：

    对两个一维高斯 \(N(\mu_1,\sigma^2)\) 与 \(N(\mu_2,\sigma^2)\)：

    \[ W = \lvert\mu_1-\mu_2\rvert \]

    无论距离多远，梯度都是常数 \(\pm1\) 所以能持续改进 —— 这就是 WGAN 的动机。

    例题 3：JS 与 KL 的数值对比¶

    设 \(p = (0.5, 0.5)\)、\(q = (0.99, 0.01)\)。计算 \(D_{KL}(p\|q)\) 与 \(JSD(p\|q)\)， 说明哪个更「温和」。

    思路

    注意 \(q\) 的第二项很小（0.01），这会让 \(D_{KL}(p\|q)\) 很大。

    解答

    第一步：\(D_{KL}(p\|q)\)

    \[ D_{KL}(p\|q) = 0.5\log_2\frac{0.5}{0.99}+0.5\log_2\frac{0.5}{0.01} \]

    （\(\log_2(50/99) = -0.985\)、\(\log_2 50 = 5.644\)）

    \[ = 0.5\times(-0.985)+0.5\times5.644 = -0.492+2.822 = 2.330\ \text{比特} \]

    第二步：\(JSD\)

    中点：

    \[ m = \left(\frac{0.5+0.99}{2},\ \frac{0.5+0.01}{2}\right) = (0.745,\ 0.255) \]
    \[ D_{KL}(p\|m) = 0.5\log_2\frac{0.5}{0.745}+0.5\log_2\frac{0.5}{0.255} \]

    （\(\log_2 0.671 = -0.576\)、\(\log_2 1.961 = 0.971\)）

    \[ = 0.5\times(-0.576)+0.5\times0.971 = -0.288+0.486 = 0.198 \]
    \[ D_{KL}(q\|m) = 0.99\log_2\frac{0.99}{0.745}+0.01\log_2\frac{0.01}{0.255} \]

    （\(\log_2 1.329 = 0.410\)、\(\log_2 0.0392 = -4.673\)）

    \[ = 0.99\times0.410+0.01\times(-4.673) = 0.406-0.047 = 0.359 \]
    \[ JSD = \frac{0.198+0.359}{2} = 0.279\ \text{比特} \]

    结果对比：

    量 值 是否超上界
    \(D_{KL}(p\;\lvert\;q)\) \(2.330\) ✗ 超出 \(\log2 = 1\)
    \(JSD(p\;\lvert\;q)\) \(0.279\) ✓ 在界内

    关键差别：

    \[ \frac{D_{KL}}{JSD} = \frac{2.330}{0.279} \approx 8.4\ \text{倍} \]

    为什么 KL 这么大：

    因为 \(p\) 在第二项上有 \(0.5\) 的质量，而 \(q\) 只给 \(0.01\) —— 这个「质量错配」导致 \(\log_2\frac{0.5}{0.01} = 5.644\) 的大惩罚， 乘以权重 \(0.5\) 后贡献 \(2.822\)

    而 JS 的「中点」机制把它「拉平」了：

    项 \(p\) vs \(q\) \(p\) vs \(m\)（中点）
    第二项概率 \(0.5\) vs \(0.01\) \(0.5\) vs \(0.255\)
    比值 \(50\)（很大） \(1.96\)（温和）

    中点提供了「共同的参照」 → 惩罚不再爆炸

    这个对比说明了「有界性」的实用价值

    为什么有界对优化很重要：

    问题 无界（KL） 有界（JS）
    个别样本的极端值 可能主导整个损失 被限制在 \(\log2\) 内
    梯度尺度 变化剧烈 稳定
    学习率选择 难调 容易

    具体场景（生成模型）：

    训练早期，生成分布与真实分布差异巨大 → \(D_{KL}\) 会是很大的值 → 梯度爆炸（需要很小的学习率）✗

    而 \(JSD\) 始终 \(\leq1\) → 梯度尺度可控 ✓

    这就是「JS 比 KL 更适合做优化目标」的原因 —— 但它仍有「不重叠时梯度为零」的问题（例题 2）， 所以最终还要靠 Wasserstein 距离解决。

    三者的定位：

    量 对称 有界 远距离有梯度 适用
    KL ✗ ✗ ✓（且很大） MLE 训练
    JS ✓ ✓ ✗（梯度消失） GAN（早期方案）
    Wasserstein ✓ ✗ ✓ WGAN ✓

    五、自测¶

    Q1 设 \(p = (0.5, 0.5)\)、\(q = (0.6, 0.4)\)。求 \(JSD(p\|q)\)。

    提示

    先取中点，再算两个 KL。

    解答

    第一步：中点

    \[ m = \left(\frac{0.5+0.6}{2},\ \frac{0.5+0.4}{2}\right) = (0.55,\ 0.45) \]

    第二步：两个 KL 散度

    \[ D_{KL}(p\|m) = 0.5\log_2\frac{0.5}{0.55}+0.5\log_2\frac{0.5}{0.45} \]

    计算（\(\log_2 0.909 = -0.138\)、\(\log_2 1.111 = 0.152\)）：

    \[ = 0.5\times(-0.138)+0.5\times0.152 = -0.069+0.076 = 0.007\ \text{比特} \]
    \[ D_{KL}(q\|m) = 0.6\log_2\frac{0.6}{0.55}+0.4\log_2\frac{0.4}{0.45} \]

    （\(\log_2 1.091 = 0.126\)、\(\log_2 0.889 = -0.170\)）：

    \[ = 0.6\times0.126+0.4\times(-0.170) = 0.076-0.068 = 0.008\ \text{比特} \]

    第三步：JS 散度

    \[ JSD = \frac{0.007+0.008}{2} \approx 0.0075\ \text{比特} \]

    结果：\(JSD \approx 0.0075\) 比特（很小）

    解读：\(p\) 与 \(q\) 很接近（只差 0.1），所以 JS 很小

    对比：上一页算过的 \(p=(0.5,0.5)\) 与 \(q=(0.9,0.1)\)：

    对比 \(JSD\)
    \((0.5,0.5)\) vs \((0.6,0.4)\) \(0.0075\)
    \((0.5,0.5)\) vs \((0.9,0.1)\) \(0.147\)

    差距约 20 倍 —— JS 忠实反映了「分布差异的程度」

    这也说明 JS 的数值有直观意义：越接近零说明分布越相似。

    Q2 求 \(JSD\) 的上界，并说明何时取到。

    提示

    回忆有界性证明中用到的 \(p(x)/m(x)\leq2\)。

    解答

    上界：

    \[ JSD(p\|q)\leq\log 2 \]

    （若对数底为 2，则上界为 1 比特。）

    取到的条件：\(p\) 与 \(q\) 的支撑完全不重叠

    证明要点：

    由中点 \(m(x) = \frac{p(x)+q(x)}{2}\geq\frac{p(x)}{2}\)，得

    \[ \frac{p(x)}{m(x)}\leq2 \implies \log\frac{p(x)}{m(x)}\leq\log2 \]

    因此

    \[ D_{KL}(p\|m)\leq\sum_x p(x)\log2 = \log2 \]

    两项目各 \(\leq\log2\)，平均后仍 \(\leq\log2\) ∎

    取等号的例子：\(p = (1,0)\)、\(q = (0,1)\)

    量 值
    \(m\) \((0.5,0.5)\)
    \(D_{KL}(p\;\lvert\;m)\) \(1\)
    \(D_{KL}(q\;\lvert\;m)\) \(1\)
    \(JSD\) \(1 = \log2\) ✓

    工程意义（有界性的价值）：

    好处 说明
    梯度尺度稳定 不会因分布差异大而爆炸
    学习率易调 损失范围已知（\([0,1]\)）
    可比性 不同数据集之间的 JS 可比较

    但有界也带来副作用：差异「饱和」后无法区分 —— 这正是它被 Wasserstein 取代的原因 ✗

    Q3 为什么 GAN 的原始目标等价于最小化 JS 散度？

    提示

    最优判别器是 \(D^*(x) = p_{\text{data}}/(p_{\text{data}}+p_g)\)。

    解答

    因为把最优判别器代入目标后，剩下的恰好是 JS 散度的形式。

    第一步：GAN 的目标

    \[ \min_G\max_D\ E_{p_{\text{data}}}[\log D(x)]+E_{p_g}[\log(1-D(x))] \]

    第二步：对固定的 \(G\)，求最优 \(D\)

    这是「在 \(D(x)\in[0,1]\) 上最大化 \(p_{\text{data}}\log D+p_g\log(1-D)\)」（逐点）。

    求导令零：

    \[ \frac{p_{\text{data}}}{D}-\frac{p_g}{1-D} = 0 \]

    解出：

    \[ D^*(x) = \frac{p_{\text{data}}(x)}{p_{\text{data}}(x)+p_g(x)} \]

    第三步：代回目标

    记 \(a = p_{\text{data}}\)、\(b = p_g\)，则

    \[ a\log\frac{a}{a+b}+b\log\frac{b}{a+b} \]

    与 JS 的定义比较（\(m = \frac{a+b}{2}\)）：

    \[ D_{KL}(a\|m) = a\log\frac{2a}{a+b}, \qquad D_{KL}(b\|m) = b\log\frac{2b}{a+b} \]
    \[ \frac12\left[D_{KL}(a\|m)+D_{KL}(b\|m)\right] + \log2 = -\left[a\log\frac{a}{a+b}+b\log\frac{b}{a+b}\right] \]

    所以

    \[ \max_D V(D,G) = 2\,JSD(p_{\text{data}}\|p_g)-\log4 \]

    因此生成器的目标等价于

    \[ \min_G JSD(p_{\text{data}}\|p_g) \;\checkmark \]

    这个等价性的两个重要推论：

    推论 说明
    原始 GAN 在理论上「最优」 因为 JS 是合法度量
    但 JS 有饱和问题 分布不重叠时梯度为零 ✗

    实践中的补救：把 \(\log(1-D)\) 改为 \(-\log D\)（非饱和损失） —— 但这不再等价于 JS，只是启发式

    根本的解决：换成 Wasserstein 距离（下一节）。

    Q4 判断：\(JSD(p\|q) = 0\) 意味着 \(p\) 和 \(q\) 完全相同。

    提示

    想想「几乎处处相等」的情形。

    解答

    基本正确，但需注意「几乎处处」的细节。

    严格陈述：

    \[ JSD(p\|q) = 0 \iff p(x) = q(x) \text{ 对几乎所有的 }x \]

    (「几乎处处」= 除测度为零的集合外)

    证明：

    由 \(JSD = \frac12D_{KL}(p\|m)+\frac12D_{KL}(q\|m)\)，且 \(D_{KL}\geq0\)：

    \[ JSD = 0 \implies D_{KL}(p\|m) = 0 \implies p = m \text{（几乎处处）} \]

    而 \(m = \frac{p+q}{2}\)，所以 \(p = m\) 意味着

    \[ p = \frac{p+q}{2} \implies 2p = p+q \implies p = q \;\checkmark \]

    注意与 KL 的对比：

    量 条件
    \(D_{KL}(p\;\lvert\;q) = 0\) \(p = q\)（几乎处处）
    \(D_{KL}(p\;\lvert\;q) < \infty\) 需要 \(p\) 的支撑包含于 \(q\) 的支撑
    \(JSD(p\;\lvert\;q) < \infty\) 总是成立（有界）✓

    关键差别：JS 的有限性是「无条件」的 —— 这正是它相对于 KL 的第一个改进

    实践意义：

    场景 用 JS
    支撑不重叠 ✓ 仍有限
    需要对称 ✓
    需要「区分远距离」 ✗ 会饱和
    需要「判断是否相同」 ✓ 可以（零即相同）
    上一页
    交叉熵与 KL 散度
    下一页
    Wasserstein 距离
