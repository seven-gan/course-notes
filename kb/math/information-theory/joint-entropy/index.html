    联合熵与条件熵¶

    上一页讲了单个随机变量的熵。这一页处理两个变量：

    量 回答的问题
    联合熵 \(H(X,Y)\) 同时观察 \(X\) 和 \(Y\)，总不确定性多少？
    条件熵 \(H(Y\mid X)\) 已知 \(X\) 后，\(Y\) 还剩多少不确定性？

    这两个量是互信息的基础（下一节的主题）。

    一句话抓住核心关系

    \[ H(X,Y) = H(X) + H(Y\mid X) \]

    「总不确定性 = \(X\) 的不确定性 + 已知 \(X\) 后 \(Y\) 剩下的不确定性」

    这是链式法则。它的直观含义：

    想知道 \((X,Y)\) 需要的信息 = 先知道 \(X\)（花 \(H(X)\)）， 再在知道 \(X\) 的基础上知道 \(Y\)（花 \(H(Y\mid X)\)）。

    这个「分两步获取信息」的视角是整节的关键。

    一、联合熵¶

    定义：

    \[ \boxed{\ H(X,Y) = -\sum_{x,y}p(x,y)\log p(x,y)\ } \]

    含义：把 \((X,Y)\) 当成一个联合随机变量，套用熵的定义。

    性质（直接来自熵的性质）：

    性质 内容
    非负 \(H(X,Y)\geq0\)
    上界 \(H(X,Y)\leq\log(\lvert\mathcal{X}\rvert\lvert\mathcal{Y}\rvert)\)
    独立时最大 \(H(X,Y) = H(X)+H(Y)\)（当且仅当独立）

    「独立时联合熵最大」是常见的直觉误区

    容易误以为：联合熵总是 \(\geq H(X)\)（因为多了个变量）。

    实际上：\(H(X,Y)\) 可以小于 \(H(X)\) 吗？——不能 ✓

    但关键在于「独立 ⇒ 联合熵最大」这句话需要限定条件：

    陈述 是否正确
    \(H(X,Y)\geq H(X)\) ✓ 总是成立
    \(H(X,Y)\geq H(Y)\) ✓ 总是成立
    \(H(X,Y)\leq H(X)+H(Y)\) ✓ 总是成立（次可加性）
    \(H(X,Y) = H(X)+H(Y) \iff\) 独立 ✓ 成立
    「独立时 \(H(X,Y)\) 达到最大」 ⚠ 需限定：在边缘分布固定的前提下才是最大

    「边缘分布固定时，独立使联合熵最大」的含义：

    设 \(X\)、\(Y\) 的边缘分布已经给定（即 \(p(x)\)、\(p(y)\) 固定）， 那么在所有可能的联合分布中：

    \[ H(X,Y)\leq H(X)+H(Y) \]

    等号（即独立）给出最大联合熵 ✓

    为什么：独立 = 「最不相关」= 假设最少 —— 这与「最大熵原理」的精神一致（回到上一页）。

    工程含义：若两个变量相关，则联合熵小于各自熵之和 —— 「一起看」比「分开看」需要更少的信息来刻画。

    这个「减少量」就是互信息（下一节）。

    二、条件熵¶

    定义：

    \[ \boxed{\ H(Y\mid X) = -\sum_{x,y}p(x,y)\log p(y\mid x) = E_{X}\left[H(Y\mid X = x)\right]\ } \]

    含义：「知道 \(X\) 之后，\(Y\) 平均还剩多少不确定性」。

    注意两点：

    细节 说明
    对 \(p(x,y)\) 加权（不是 \(p(x)p(y)\)） 用联合分布加权
    是 \(H(Y\mid X=x)\) 的期望 对 \(X\) 的所有取值求期望

    条件熵为什么是「期望」而不是「条件熵的直接替换」

    容易搞错的地方：\(H(Y\mid X)\) 不是把 \(H(Y)\) 中的 \(p(y)\) 换成 \(p(y\mid x)\)。

    正确理解：

    \[ H(Y\mid X) = E_X\big[H(Y\mid X=x)\big] = \sum_x p(x)H(Y\mid X=x) \]

    两步走：

    步骤 操作
    1 对每个具体的 \(x\)，算条件分布的熵 \(H(Y\mid X=x)\)
    2 按 \(p(x)\) 加权平均

    为什么需要期望：因为 \(X\) 是随机的 —— 在观测前我们不知道会看到哪个 \(x\)， 所以只能用期望描述「平均会剩多少不确定性」。

    这与「熵是自信息的期望」是同一模式的推广：

    量 形式
    自信息 \(I(x)\) 单个事件的量
    熵 \(H(X)\) 自信息的期望
    条件熵 \(H(Y\mid X=x)\) 给定具体 \(x\) 后的熵
    条件熵 \(H(Y\mid X)\) 对 \(X\) 求期望

    三个重要性质¶

    性质 内容 说明
    非负 \(H(Y\mid X)\geq0\) 不确定性不为负
    上界 \(H(Y\mid X)\leq H(Y)\) 「条件作用不增加不确定性」
    等式条件 \(H(Y\mid X) = H(Y) \iff\) 独立 独立时观测 \(X\) 无用

    「条件作用不增加不确定性」是最重要的性质

    \[ H(Y\mid X)\leq H(Y) \]

    含义：「知道得更多，不确定性不会变大」 —— 这符合直觉，但需要证明（不是平凡的）。

    证明思路（用下一节的互信息，这里先给直观）：

    \[ H(Y)-H(Y\mid X) = I(X;Y)\geq0 \]

    而 \(I(X;Y)\geq0\) 来自「KL 散度非负」 ✓

    等号成立的条件：\(X\) 与 \(Y\) 独立 —— 此时 \(p(y\mid x) = p(y)\)，观测 \(X\) 完全不提供关于 \(Y\) 的信息。

    工程含义（这是「条件熵为什么有用」的核心）：

    场景 \(H(Y\mid X)\) 的含义
    \(X\) = 传感器读数，\(Y\) = 真实状态 读数能减少多少状态的不确定性
    \(X\) = 特征，\(Y\) = 类别 特征对分类的帮助
    \(X\) = 历史，\(Y\) = 未来 历史的预测能力

    若 \(H(Y\mid X) = H(Y)\)：该传感器/特征/历史毫无用处 ✗

    若 \(H(Y\mid X) = 0\)：完全确定（\(X\) 已包含 \(Y\) 的全部信息）✓

    三、链式法则¶

    联合熵的链式法则：

    \[ \boxed{\ H(X,Y) = H(X) + H(Y\mid X) = H(Y) + H(X\mid Y)\ } \]

    对称性：两种分解顺序给出同一个结果 ✓

    推广到 \(n\) 个变量：

    \[ H(X_1,\dots,X_n) = H(X_1)+H(X_2\mid X_1)+\cdots+H(X_n\mid X_1,\dots,X_{n-1}) \]

    链式法则的证明（很短，值得看）

    从条件概率的乘法法则出发：

    \[ p(x,y) = p(x)p(y\mid x) \]

    取对数：

    \[ \log p(x,y) = \log p(x)+\log p(y\mid x) \]

    两边乘 \(-p(x,y)\) 并对所有 \(x,y\) 求和：

    \[ -\sum_{x,y}p(x,y)\log p(x,y) = -\sum_{x,y}p(x,y)\log p(x)-\sum_{x,y}p(x,y)\log p(y\mid x) \]

    第一项：注意 \(\sum_y p(x,y) = p(x)\)，所以

    \[ -\sum_x p(x)\log p(x) = H(X) \]

    第二项：正是 \(H(Y\mid X)\) 的定义 ✓

    合并即得 \(H(X,Y) = H(X)+H(Y\mid X)\) ∎

    关键步骤：「对数把乘积变成加法」 —— 这与自信息的可加性是同一个机制。

    这也是为什么信息论里到处是「加法」 —— 因为对数把概率的乘积结构变成了加法结构。

    链式法则的应用：联合熵的上界¶

    由 \(H(Y\mid X)\leq H(Y)\)（条件不增加不确定性）：

    \[ H(X,Y)\leq H(X)+H(Y) \;\checkmark \]

    这就是「次可加性」，等号仅在独立时成立。

    推广（\(n\) 个变量）：

    \[ H(X_1,\dots,X_n)\leq\sum_i H(X_i) \]

    含义：「一起看」的信息量不超过「分开看」之和 ✓

    这个不等式的工程价值

    应用 说明
    数据压缩 联合编码优于分开编码（相关数据可压缩更多）
    存储估计 相关数据的联合熵更小 → 存得更少
    特征冗余检测 若 \(H(X,Y)\ll H(X)+H(Y)\)，则两特征高度冗余

    具体例子：设 \(X\) 与 \(Y\) 是同一张图片的相邻像素。 若分别编码，各需 \(H(X)\)、\(H(Y)\) 比特； 联合编码只需 \(H(X,Y) < H(X)+H(Y)\) ✓

    这就是「图像/视频压缩为什么有效」的信息论解释 —— 利用像素间的相关性（冗余）。

    四、典型例题¶

    例题 1：计算联合熵与条件熵¶

    设 \(X,Y\) 的联合分布为

    \(Y=0\) \(Y=1\)
    \(X=0\) \(1/8\) \(1/4\)
    \(X=1\) \(1/8\) \(1/2\)

    求 (a) \(H(X)\)；(b) \(H(Y)\)；© \(H(X,Y)\)； (d) \(H(Y\mid X)\)；(e) 验证链式法则。

    思路

    先求边缘分布，再逐个算。

    解答

    (a) 边缘分布 \(p(x)\)

    对 \(y\) 求和：

    \[ p(X=0) = \frac18+\frac14 = \frac38 \]
    \[ p(X=1) = \frac18+\frac12 = \frac58 \]

    熵：

    \[ H(X) = -\frac38\log_2\frac38-\frac58\log_2\frac58 \]

    计算（\(\log_2 3 = 1.585\)、\(\log_2 5 = 2.322\)）：

    \[ = 0.375\times(3-1.585)+0.625\times(3-2.322) = 0.375\times1.415+0.625\times0.678 \]
    \[ = 0.5306+0.4238 = 0.9544\ \text{比特} \]

    (b) 边缘分布 \(p(y)\)

    对 \(x\) 求和：

    \[ p(Y=0) = \frac18+\frac18 = \frac14 \]
    \[ p(Y=1) = \frac14+\frac12 = \frac34 \]

    熵：

    \[ H(Y) = -\frac14\log_2\frac14-\frac34\log_2\frac34 = 0.25\times2+0.75\times0.415 = 0.5+0.3113 = 0.8113\ \text{比特} \]

    © 联合熵

    逐项计算 \(-p\log p\)：

    \((x,y)\) \(p\) \(-\log_2 p\) 贡献
    \((0,0)\) \(1/8\) \(3\) \(0.375\)
    \((0,1)\) \(1/4\) \(2\) \(0.5\)
    \((1,0)\) \(1/8\) \(3\) \(0.375\)
    \((1,1)\) \(1/2\) \(1\) \(0.5\)

    求和：

    \[ H(X,Y) = 0.375+0.5+0.375+0.5 = 1.75\ \text{比特} \]

    (d) 条件熵 \(H(Y\mid X)\)

    先算两个条件分布：

    \(X=0\) 时（边缘概率 \(3/8\)）：

    \[ p(Y=0\mid X=0) = \frac{1/8}{3/8} = \frac13, \qquad p(Y=1\mid X=0) = \frac{1/4}{3/8} = \frac23 \]
    \[ H(Y\mid X=0) = -\frac13\log_2\frac13-\frac23\log_2\frac23 = 0.3333\times1.585+0.6667\times0.585 = 0.5283+0.3900 = 0.9183\ \text{比特} \]

    \(X=1\) 时（边缘概率 \(5/8\)）：

    \[ p(Y=0\mid X=1) = \frac{1/8}{5/8} = \frac15, \qquad p(Y=1\mid X=1) = \frac{1/2}{5/8} = \frac45 \]
    \[ H(Y\mid X=1) = -\frac15\log_2\frac15-\frac45\log_2\frac45 = 0.2\times2.322+0.8\times0.322 = 0.4644+0.2575 = 0.7219\ \text{比特} \]

    加权平均：

    \[ H(Y\mid X) = \frac38\times0.9183+\frac58\times0.7219 = 0.375\times0.9183+0.625\times0.7219 \]
    \[ = 0.3444+0.4512 = 0.7956\ \text{比特} \]

    (e) 验证链式法则

    \[ H(X)+H(Y\mid X) = 0.9544+0.7956 = 1.7500 \]

    而 \(H(X,Y) = 1.75\) ✓ 完全吻合

    同时验证另一个方向：

    \[ H(X\mid Y) = H(X,Y)-H(Y) = 1.75-0.8113 = 0.9387 \]
    \[ H(Y)+H(X\mid Y) = 0.8113+0.9387 = 1.75 \;\checkmark \]

    注意「条件熵小于无条件熵」在本例中成立但不多

    \[ H(Y\mid X) = 0.7956 < H(Y) = 0.8113 \;\checkmark \]

    减少量（即互信息）：

    \[ I(X;Y) = H(Y)-H(Y\mid X) = 0.8113-0.7956 = 0.0157\ \text{比特} \]

    这个互信息很小！ ——说明 \(X\) 与 \(Y\) 几乎独立。

    如何看出「几乎独立」：比较 \(p(x,y)\) 与 \(p(x)p(y)\)：

    \((x,y)\) 实际 \(p(x,y)\) \(p(x)p(y)\) 差异
    \((0,0)\) \(0.125\) \(0.375\times0.25 = 0.094\) 小
    \((0,1)\) \(0.250\) \(0.375\times0.75 = 0.281\) 小
    \((1,0)\) \(0.125\) \(0.625\times0.25 = 0.156\) 小
    \((1,1)\) \(0.500\) \(0.625\times0.75 = 0.469\) 小

    差异都很小 → 接近独立 ✓

    工程含义：这种情形下，知道 \(X\) 几乎不能帮助预测 \(Y\) —— 该特征几乎没有价值。

    这提示了一个实用判据：用互信息衡量特征的相关性 （下一节详述）。

    例题 2：独立与相关的极端情形¶

    (a) 若 \(X\) 与 \(Y\) 独立，\(H(X) = 1\)、\(H(Y) = 2\) 比特。 求 \(H(X,Y)\) 与 \(H(Y\mid X)\)。

    (b) 若 \(Y = X\)（完全相关），\(H(X) = 1\) 比特。 求 \(H(X,Y)\) 与 \(H(Y\mid X)\)。

    思路

    独立用 \(H(X,Y) = H(X)+H(Y)\)；完全相关用 \(H(X,Y) = H(X)\)。

    解答

    (a) 独立情形

    \[ H(X,Y) = H(X)+H(Y) = 1+2 = 3\ \text{比特} \]
    \[ H(Y\mid X) = H(Y) = 2\ \text{比特} \]

    解读：观测 \(X\) 对 \(Y\) 完全没有帮助 —— 不确定性仍是完整的 2 比特。

    互信息：\(I(X;Y) = 2-2 = 0\) ✓

    (b) 完全相关（\(Y = X\)）

    此时 \((X,Y)\) 与 \(X\) 一样「不确定」：

    \[ H(X,Y) = H(X) = 1\ \text{比特} \]
    \[ H(Y\mid X) = 0\ \text{比特} \]

    解读：知道 \(X\) 就完全知道了 \(Y\) —— 没有剩余不确定性 ✓

    互信息：\(I(X;Y) = H(Y)-0 = 1\) 比特 = \(H(X)\) ✓

    验证链式法则：

    \[ H(X)+H(Y\mid X) = 1+0 = 1 = H(X,Y) \;\checkmark \]

    把两个极端与一般情形放在一起看

    情形 \(H(X,Y)\) \(H(Y\mid X)\) \(I(X;Y)\)
    (a) 独立 \(H(X)+H(Y)\)（最大） \(H(Y)\)（最大） \(0\)（最小）
    (b) 完全相关 \(H(X)=H(Y)\)（最小） \(0\)（最小） \(H(X)\)（最大）
    一般 介于之间 介于之间 介于之间

    两个关键规律：

    规律 1：独立性使 \(H(X,Y)\) 最大、使 \(I(X;Y)\) 最小

    规律 2：相关性越强，\(H(X,Y)\) 与 \(I(X;Y)\) 的变化方向相反

    这解释了两件工程事实：

    事实 信息论解释
    相关数据更易压缩 \(H(X,Y)\) 更小（低于 \(H(X)+H(Y)\)）
    相关特征提供更多信息 \(I(X;Y)\) 更大

    注意「压缩」与「信息」不矛盾： - 压缩利用冗余（\(H(X,Y)\) 小 → 可少花比特） - 信息指的是关于对方的知识（\(I(X;Y)\) 大）

    同一个「相关性」既带来压缩性，也带来信息量 —— 这两个视角说的是同一件事的两面 ✓

    例题 3：链式法则与多变量¶

    设 \(X_1,X_2,X_3\) 独立同分布（i.i.d.）且每个的熵为 \(h\)。 求 \(H(X_1,X_2,X_3)\)。若 \(X_2 = X_1\)、\(X_3 = X_1\)（完全相关），结果如何？

    思路

    独立时链式法则的各项都退化为无条件熵；完全相关时各项为 0。

    解答

    第一步：独立同分布情形

    链式法则：

    \[ H(X_1,X_2,X_3) = H(X_1)+H(X_2\mid X_1)+H(X_3\mid X_1,X_2) \]

    逐项计算：

    项 值 理由
    \(H(X_1)\) \(h\) ——
    \(H(X_2\mid X_1)\) \(H(X_2) = h\) 独立 → 条件不减少不确定性
    \(H(X_3\mid X_1,X_2)\) \(H(X_3) = h\) 同上

    结果：

    \[ H(X_1,X_2,X_3) = 3h \]

    对比次可加性上界：\(\sum_i H(X_i) = 3h\) —— 取到等号 ✓ 与「独立 ⇒ 联合熵最大」一致。

    第二步：完全相关情形（\(X_2 = X_3 = X_1\)）

    逐项计算：

    项 值 理由
    \(H(X_1)\) \(h\) ——
    \(H(X_2\mid X_1)\) \(0\) 知道 \(X_1\) 就完全知道 \(X_2\)
    \(H(X_3\mid X_1,X_2)\) \(0\) 同上

    结果：

    \[ H(X_1,X_2,X_3) = h \]

    这个对比揭示了「冗余」的定量含义

    情形 联合熵 冗余度
    独立 \(3h\) 无冗余（需要完整存 3 份信息）
    完全相关 \(h\) 冗余 \(2h\)（只需存 1 份）

    压缩比：\(3h/h = 3\) 倍 ✓

    推广到 \(n\) 个完全相关变量：

    \[ H = h \quad\text{（与 } n \text{ 无关）} \]

    这就是「重复数据可无限压缩」的信息论解释 ✓

    实际数据的中间情形：

    设相邻样本的相关系数为 \(\rho\)，则联合熵介于 \(h\) 与 \(nh\) 之间：

    \[ H(\text{全部}) \approx n\cdot h\quad\text{（}\rho = 0\text{）} \]
    \[ H(\text{全部}) \to h\quad\text{（}\rho\to1\text{）} \]

    这解释了「压缩率取决于数据的相关性」 —— 这也是为什么图像（强相关）比随机数（无相关）容易压缩得多。

    DCT/小波变换的作用（从信息论角度看）：

    把空间相关性转成「稀疏表示」 → 大部分系数接近零 → 可以用更少比特编码（熵编码）。

    例题 4：条件熵的实用计算（信道模型）¶

    某二进制对称信道（BSC）：输入 \(X\in\{0,1\}\) 等概， 输出 \(Y\) 有 \(\varepsilon\) 的概率翻转。求 \(H(Y\mid X)\) 与 \(H(Y)\)。

    思路

    \(H(Y\mid X=x)\) 与 \(x\) 无关（对称），所以条件熵就是单次翻转的熵。

    解答

    第一步：\(H(Y\mid X)\)

    对任意 \(x\)，输出分布都是

    \[ p(Y = x\mid X=x) = 1-\varepsilon, \qquad p(Y\neq x\mid X=x) = \varepsilon \]

    所以：

    \[ H(Y\mid X=x) = H_b(\varepsilon) = -\varepsilon\log_2\varepsilon-(1-\varepsilon)\log_2(1-\varepsilon) \]

    与 \(x\) 无关 → 期望也是同一个值：

    \[ \boxed{\ H(Y\mid X) = H_b(\varepsilon)\ } \]

    第二步：\(H(Y)\)

    由于 \(X\) 等概且信道对称，输出也是等概的：

    \[ p(Y=0) = (1-\varepsilon)\frac12+\varepsilon\frac12 = \frac12 \]
    \[ p(Y=1) = \frac12 \]

    所以：

    \[ H(Y) = 1\ \text{比特} \]

    第三步：看具体数值

    \(\varepsilon\) \(H(Y\mid X)\) \(H(Y)\) 互信息
    \(0\)（无噪声） \(0\) \(1\) \(1\)
    \(0.1\) \(0.469\) \(1\) \(0.531\)
    \(0.5\)（完全噪声） \(1.0\) \(1\) \(0\)
    \(1\)（完全翻转） \(0\) \(1\) \(1\)

    注意翻转概率为 0.5 与 1 的反差

    \(\varepsilon\) 情况 \(H(Y\mid X)\) 互信息
    \(0.5\) 输出完全随机 \(1\)（最大） \(0\) ✗
    \(1\) 输出必然翻转 \(0\)（最小） \(1\) ✓

    \(\varepsilon = 1\) 时互信息最大！为什么？

    因为「必然翻转」也是确定性的规律 —— 只要把接收到的比特取反，就能完全恢复原信息 ✓

    启示：「信息」不在于「值相等」，而在于「有确定的映射关系」。

    条件熵度量的是「可预测性」，不是「相似性」：

    关系 \(H(Y\mid X)\) 可预测性
    \(Y = X\) \(0\) 完全可预测 ✓
    \(Y = 1-X\) \(0\) 也是完全可预测 ✓
    \(Y\) 与 \(X\) 无关 \(H(Y)\) 完全不可预测 ✗

    这就是「互信息」的定义为什么用 \(H(Y)-H(Y\mid X)\) —— 它捕捉的是「观测后不确定性减少多少」， 而不是「两个变量的值有多像」。

    这解释了一个重要的工程事实：互信息能识别非线性的确定性关系， 而相关系数（Pearson）不能。

    关系 Pearson 相关系数 互信息
    \(Y = X\) \(\pm1\) 大 ✓
    \(Y = X^2\)（\(X\) 对称） \(\approx0\) ✗ 大 ✓
    \(Y = 1-X\) \(-1\) 大 ✓
    独立 \(0\) \(0\)

    所以做特征选择时，互信息比相关系数更可靠 ✓ （这一点在「随机信号基础」一页已从「不相关 ≠ 独立」的角度提过。）

    五、用在哪些课程里¶

    模式识别 · 特征选择与决策树¶

    • 互信息是最常用的特征选择准则（比相关系数更通用）
    • 信息增益（决策树 ID3）就是互信息
    • 条件互信息用于分析特征间的冗余
    • 最大相关最小冗余（mRMR）：用互信息做特征筛选

    现代数字信号处理 · 信道容量¶

    • 信道容量 \(C = \max_{p(x)}I(X;Y)\) 依赖互信息
    • 条件熵 \(H(Y\mid X)\) 是「信道噪声的熵」
    • BSC 的容量 \(C = 1-H_b(\varepsilon)\)：

    \(\varepsilon = 0\) 时 \(C = 1\)；\(\varepsilon = 0.5\) 时 \(C = 0\)。

    智能传感与信息处理 · 传感器有效性¶

    • \(H(Y\mid X)\) 衡量传感器价值：读数 \(X\) 对状态 \(Y\) 的不确定性减少量
    • 多传感器融合：用条件互信息评估各传感器的边际贡献
    • 冗余检测：若 \(I(X_1;X_2)\) 大，两个传感器冗余（可省一个）

    无人系统自主决策与优化 · 信息收集¶

    • 主动感知：选择信息增益最大的观测动作
    • 信念状态的熵：POMDP 中用它衡量「对环境的确定程度」
    • 探索与利用：熵降低 = 探索获得的信息
