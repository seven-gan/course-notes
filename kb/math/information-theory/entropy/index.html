    自信息与熵¶

    信息论要回答一个看似哲学的问题：

    「一条消息含有多少信息？」

    香农（Shannon, 1948）给出了可计算的答案。这一页建立整门学科的两个基本量： 自信息（单个事件的信息量）与熵（平均信息量）。

    为什么工程专业必须掌握熵

    领域 熵的角色
    机器学习 交叉熵损失、决策树的信息增益
    数据压缩 熵是压缩率的理论下界
    通信 信道容量公式含熵
    决策 最大熵原理给出「最不偏」的分布
    统计物理 熵与热力学第二定律

    一句话：熵度量「不确定性」，而「消除不确定性」就是获得信息。

    一、自信息：单个事件的信息量¶

    定义：事件 \(x\) 发生时携带的信息量为

    \[ \boxed{\ I(x) = -\log P(x)\ } \]

    单位：若 \(\log\) 以 2 为底，单位是比特（bit）； 以 \(e\) 为底是奈特（nat）；以 10 为底是哈特利（hartley）。

    为什么是「负对数」（四个要求推出唯一形式）

    设信息量 \(I(p)\) 是概率 \(p\) 的函数。合理的四条要求：

    要求 含义 数学表达
    1. 非负 信息量不能是负的 \(I(p)\geq0\)
    2. 单调递减 越不可能的事件，信息越多 \(p_1\lt p_2 \Rightarrow I(p_1)>I(p_2)\)
    3. 确定性事件无信息 必然发生的事不提供信息 \(I(1) = 0\)
    4. 可加性 独立事件的信息量相加 \(I(p_1p_2) = I(p_1)+I(p_2)\)

    第 4 条是最关键的设计：独立 ⇒ 联合概率是乘积 ⇒ 信息量应当是加和。

    唯一满足这四条的函数（连续情形）：

    \[ I(p) = -\log_b p \]

    验证第 4 条：

    \[ -\log(p_1p_2) = -(\log p_1+\log p_2) = I(p_1)+I(p_2) \;\checkmark \]

    这就是「对数」出现的原因 —— 它把「概率的乘积」变成「信息的加和」， 与「对数把乘除变加减」是同一件事。

    注意「底」的选择只改变单位，不改变本质：

    底 单位 使用场合
    2 比特 信息论、数字通信（最常用）
    \(e\) 奈特 机器学习（与对数似然自然衔接）
    10 哈特利 较少用

    换算：\(1\ \text{nat} = 1/\ln 2 \approx 1.4427\ \text{bit}\)。

    1.1 几个具体数值（建立直觉）¶

    事件 概率 自信息
    掷公平硬币出正面 \(1/2\) 1 比特
    掷公平骰子出 3 \(1/6\) \(\log_2 6 \approx 2.585\) 比特
    抛硬币连续 10 次都是正面 \(1/1024\) 10 比特
    必然事件 \(1\) \(0\) 比特
    概率 \(10^{-6}\) 的故障 \(10^{-6}\) \(\approx 19.93\) 比特

    「1 比特」的含义：恰好等于「一次公平二选一」所提供的信息量。

    「比特」这个名字的来源与工程含义

    来源：来自 binary digit（二进制数字）。

    工程含义：1 比特的信息量恰好可以用 1 个二进制位表示 —— 这是「信息量」与「存储/传输成本」的直接对应。

    推广（这与数据压缩直接相关）：

    事件信息量 所需二进制位（下界）
    1 比特 1 位
    2.585 比特（骰子） 至少 3 位（但不能简单地用 3 位一一映射！）
    10 比特 10 位

    骰子那行的微妙之处：掷骰子有 6 种结果， 用 3 位可以表示 8 种，看似「够用但浪费」。 这就是变长编码（如霍夫曼编码）的用武之地 —— 常用结果用短码，罕见结果用长码，平均长度趋近于熵。

    所以「信息量」是「压缩能力的理论下界」， 这是香农第一定理（无失真信源编码定理）的核心内容。

    二、熵：自信息的期望¶

    定义（离散）：

    \[ \boxed{\ H(X) = -\sum_x p(x)\log p(x) = E\left[-\log p(X)\right] } \]

    含义：随机变量 \(X\) 的「平均不确定性」。

    这就是「自信息的期望」 —— 所以熵也称为平均自信息。

    两个必须知道的约定与细节

    1. \(0\log 0 = 0\) 的约定

    当 \(p(x) = 0\) 时，该项的解释是：

    \[ \lim_{p\to0^+}p\log p = 0 \]

    含义：不可能发生的事件不贡献不确定性 ✓ 符合直觉。

    证明（用洛必达）：令 \(p\to0^+\)，

    \[ \lim_{p\to0^+}p\ln p = \lim_{p\to0^+}\frac{\ln p}{1/p} \overset{\text{L'H}}{=}\lim_{p\to0^+}\frac{1/p}{-1/p^2} = \lim_{p\to0^+}(-p) = 0 \;\checkmark \]

    所以求和时 \(p(x) = 0\) 的项直接跳过。

    2. 熵的单位取决于对数的底

    底 单位
    2 比特
    \(e\) 奈特

    机器学习中常用奈特（因为与 \(\ln\) 似然衔接）， 信息论/通信中常用比特。

    2.1 熵的基本性质¶

    性质 内容 说明
    非负 \(H(X)\geq0\) 不确定性不能为负
    上界 \(H(X)\leq\log n\)（\(n\) 为取值个数） 均匀分布时取等
    确定性 \(H = 0 \iff\) 某个 \(p(x) = 1\) 完全确定则无不确定性
    凹性 \(H\) 是 \(p\) 的凹函数 所以「混合分布」的熵 ≥ 平均熵

    「熵的最大值在均匀分布」——这是最大熵原理的核心

    对 \(n\) 个取值的离散随机变量：

    \[ H(X)\leq\log n \]

    等号当且仅当 \(p(x) = 1/n\)（均匀分布）

    直觉：均匀分布是「最不确定」的 —— 没有任何结果比其他结果更可能。

    验证（\(n=2\) 的伯努利情形）：

    设 \(P(X=1) = p\)，则

    \[ H(p) = -p\log_2 p-(1-p)\log_2(1-p) \]
    \(p\) \(H\)（比特）
    \(0\) \(0\)
    \(0.1\) \(0.469\)
    \(0.5\) \(1.0\)（最大）
    \(0.9\) \(0.469\)
    \(1\) \(0\)

    这正是「二元熵函数」，关于 \(p = 0.5\) 对称

    工程意义（最大熵原理）：

    在已知约束下，应选择熵最大的分布。

    理由：熵最大 = 假设最少 = 最不偏（不引入未知的偏好）。

    已知信息 最大熵分布
    只有取值范围（有限） 均匀分布
    已知均值与方差 高斯分布
    已知均值（正值） 指数分布
    已知取值范围 \([0,\infty)\) 与均值 指数分布

    这解释了一个重要事实：「高斯分布是最不偏的选择」 —— 在只知道一、二阶矩时，假设高斯是信息上最保守的做法。

    这与「高斯分布」那一页的「中心极限定理」是两条独立的理由： - 中心极限定理：「多数叠加趋于高斯」 - 最大熵：「只知一二阶矩时高斯最不偏」

    两者都支持在工程中用高斯假设

    三、熵的意义：三个视角¶

    理解熵可以从三个角度看，各有用途。

    3.1 视角 1：不确定性¶

    熵大 = 难猜。

    分布 熵 猜中难度
    某结果概率 1 \(0\) 必定猜中
    \((0.9,0.1)\) \(0.469\) 较易猜中
    \((0.5,0.5)\) \(1.0\) 最难猜

    3.2 视角 2：平均编码长度（压缩下界）¶

    香农第一定理：无损压缩的平均码长不能小于熵。

    \[ \bar L \geq H(X) \]

    这就是「熵是压缩极限」的含义

    具体例子：设某信源有 4 个符号，概率为

    \[ (0.5,\ 0.25,\ 0.125,\ 0.125) \]

    熵：

    \[ H = -\left(0.5\log_2 0.5+0.25\log_2 0.25+0.125\log_2 0.125\times2\right) = 0.5+0.5+0.375+0.375 = 1.75\ \text{比特} \]

    对比「定长编码」（每个符号 2 比特）：\(\bar L = 2\) 比特 —— 有浪费 ✗

    霍夫曼编码（变长）：

    符号 概率 码字 长度
    A \(0.5\) 0 1
    B \(0.25\) 10 2
    C \(0.125\) 110 3
    D \(0.125\) 111 3

    平均码长：

    \[ \bar L = 0.5\times1+0.25\times2+0.125\times3+0.125\times3 = 1.75\ \text{比特} \]

    恰好等于熵 ✓（本例是「可完美达到」的情形。）

    一般结论：

    \[ H(X) \leq \bar L < H(X)+1 \]

    含义：霍夫曼编码与熵的差距小于 1 比特

    工程含义：熵告诉你「还能压缩多少」—— 若当前压缩率远高于熵，说明某些信息被丢弃了（有损压缩）； 若低于熵，说明还有压缩空间。

    3.3 视角 3：信息量（消除不确定性所需的信息）¶

    「获得 \(H(X)\) 比特的信息，就能完全确定 \(X\)。」

    具体例子：

    情形 需要多少信息
    猜一个 32 比特的随机数 32 比特
    猜一个 1–100 的数（均匀） \(\log_2 100 \approx 6.64\) 比特
    确定一次公平硬币的结果 1 比特

    这解释了「20 问游戏」的优化策略：

    每问一次应把可能性减半（获得 1 比特）， 这样 \(\lceil\log_2 n\rceil\) 次就能确定答案

    四、典型例题¶

    例题 1：计算熵¶

    设 \(X\) 的分布为 \(p(1) = 0.5\)、\(p(2) = 0.25\)、\(p(3) = 0.25\)。 求 \(H(X)\)（比特）。

    思路

    直接代入定义，逐项计算。

    解答

    逐项计算：

    \(x\) \(p\) \(-\log_2 p\) 贡献 \(p\cdot(-\log_2 p)\)
    1 \(0.5\) \(1\) \(0.5\)
    2 \(0.25\) \(2\) \(0.5\)
    3 \(0.25\) \(2\) \(0.5\)

    求和：

    \[ H(X) = 0.5+0.5+0.5 = 1.5\ \text{比特} \]

    结果：\(H(X) = 1.5\) 比特

    验证上界（\(n = 3\)）：

    \[ \log_2 3 \approx 1.585 > 1.5 \;\checkmark \]

    上界未被取到，说明分布不均匀（最大熵要求均匀）

    若改为均匀分布 \((1/3,1/3,1/3)\)：

    \[ H = \log_2 3 \approx 1.585\ \text{比特} \]

    确实更大

    编码验证：用变长码

    符号 码字
    1 0
    2 10
    3 11

    平均码长 \(= 0.5\times1+0.25\times2+0.25\times2 = 1.5\) ✓ 恰好等于熵

    「负对数概率」这一对应关系

    观察上表：概率是 \(2^{-k}\) 的符号，自信息恰好是 \(k\) 比特。

    概率 自信息 码长
    \(1/2\) \(1\) \(1\)
    \(1/4\) \(2\) \(2\)
    \(1/8\) \(3\) \(3\)

    这就是「算术编码」和「前缀码」能达到熵下界的原因： 让码长与自信息匹配，平均就趋近熵

    反过来解释熵为什么是下界：

    若某个符号被赋予更短的码，则必有别的符号码更长 （因为前缀码要求总码字空间有限）。 平均长度的加权和在最优点恰好等于熵。

    这就是「香农第一定理」的直观证明思路。

    例题 2：熵的对称性与极值¶

    设 \(X\) 是伯努利随机变量，\(P(X=1) = p\)。 求 \(H(X)\) 的表达式与最大值，并说明何时熵为零。

    思路

    写出二元熵函数，求导找极值。

    解答

    第一步：写出熵

    \[ H(p) = -p\log_2 p-(1-p)\log_2(1-p) \]

    第二步：求导

    用 \((\ln x)' = 1/x\) 与换底 \(\log_2 x = \frac{\ln x}{\ln2}\)：

    \[ \frac{\mathrm{d}H}{\mathrm{d}p} = -\frac{1}{\ln2}\left[\ln p+1-\ln(1-p)-1\right] = -\frac{1}{\ln2}\ln\frac{p}{1-p} \]

    第三步：令导数为零

    \[ \ln\frac{p}{1-p} = 0 \implies \frac{p}{1-p} = 1 \implies p = \frac12 \]

    第四步：验证是最大值

    \[ H''(p) = -\frac{1}{\ln2}\left(\frac1p+\frac{1}{1-p}\right) < 0 \]

    恒为负 → 最大值

    最大值：

    \[ H(0.5) = -0.5\log_2 0.5-0.5\log_2 0.5 = 0.5+0.5 = 1\ \text{比特} \]

    第五步：何时为零

    由 \(0\log0 = 0\) 的约定：

    \(p\) \(H\)
    \(0\) \(0\)
    \(1\) \(0\)

    结果：

    量 值
    最大值 \(1\) 比特（\(p = 0.5\)）
    零值 \(p = 0\) 或 \(p = 1\)

    解读：

    \(p\) 含义 熵
    \(0\) 必然是 0 \(0\)（无不确定性）
    \(0.5\) 完全公平 \(1\)（最不确定）
    \(1\) 必然是 1 \(0\)（无不确定性）

    对称性：\(H(p) = H(1-p)\) —— 因为「几乎必然发生」与 「几乎必然不发生」的不确定性相同

    这个例子的工程意义：二元信道的容量

    「公平硬币 = 1 比特」不是巧合，而是联系到通信容量的关键：

    情形 每符号信息量
    公平二进制（\(p=0.5\)） 1 比特
    有偏二进制（\(p=0.9\)） \(0.469\) 比特

    含义：有偏信源可压缩（可以用变长码少花比特）。

    这正是压缩算法（如 Huffman、LZ、算术编码）利用的性质： 数据中「常见的模式」概率高 → 熵低 → 可压缩。

    极端情形：若数据完全可预测（\(p=1\)），熵为 0 → 理论上可压缩到零（这就是「全零文件压缩到几字节」的原理）。

    例题 3：最大熵原理的应用¶

    已知某离散随机变量取值范围是 \(\{1,2,3,4\}\)，除此之外无任何信息。 按最大熵原理，应假设什么分布？如果额外已知 \(E[X] = 2.5\) 呢？

    思路

    只有取值范围时，均匀分布熵最大；已知均值时要用拉格朗日乘数法求最大熵分布。

    解答

    情形 1：只有取值范围

    由「最大熵 = 均匀分布」：

    \[ p(1) = p(2) = p(3) = p(4) = \frac14 \]

    熵：

    \[ H = \log_2 4 = 2\ \text{比特} \]

    理由：无信息时，假设等可能是最保守的（不作任何额外假设）

    情形 2：额外已知 \(E[X] = 2.5\)

    现在要在约束

    \[ \sum_i p_i = 1, \qquad \sum_i i\,p_i = 2.5 \]

    下最大化 \(H\)。

    用拉格朗日乘数法（回顾优化那一页）：

    \[ \mathcal{L} = -\sum_i p_i\log p_i + \lambda_1\left(\sum_i p_i-1\right)+\lambda_2\left(\sum_i ip_i-2.5\right) \]
    \[ \frac{\partial\mathcal{L}}{\partial p_i} = -\log_2 p_i-\frac{1}{\ln2}+\lambda_1+\lambda_2 i = 0 \]

    解出：

    \[ p_i \propto 2^{\lambda_2 i} \]

    即「指数族」形式！设 \(p_i = C\theta^i\)（\(\theta = 2^{\lambda_2}\)）， 由两个约束确定 \(C\) 与 \(\theta\)。

    用对称性快速求解：\(E[X] = 2.5\) 恰好是 \(1,2,3,4\) 的中点， 所以分布应关于中点对称：

    \[ p(1) = p(4),\qquad p(2) = p(3) \]

    设 \(p(1) = p(4) = a\)、\(p(2) = p(3) = b\)，则

    \[ 2a+2b = 1 \implies a+b = \frac12 \]
    \[ E[X] = 1a+2b+3b+4a = 5a+5b = 5(a+b) = 2.5 \;\checkmark \]

    第二个约束自动满足（只要对称）→ 无法唯一确定 \(a,b\) ✗

    说明：这个约束没有提供额外信息（它被对称性蕴含了）。

    所以最大熵解仍是均匀分布：

    \[ p_i = \frac14 \]

    结论：\(E[X] = 2.5\) 这个约束不减少不确定性（因为均匀分布已满足它）。

    最大熵原理的实用价值

    它给出了「在信息不足时如何选择分布」的客观答案：

    已知信息 最大熵分布 工程用途
    取值范围 均匀 随机数生成、量化误差建模
    一阶矩 指数族 排队论、可靠性
    一、二阶矩 高斯 噪声建模、卡尔曼滤波
    均值 + 上界 截断指数 排队长度的近似

    「信息不足时用什么分布」这个问题在工程中极常见， 最大熵给出了有原则的答案

    同时也说明了「为什么不能随便假设分布」： 额外假设 = 引入额外信息 = 可能错误。 例如，若真实分布在 \(\{1,2,3,4\}\) 上均匀， 而你假设了高斯（因为「大概是钟形」）， 就人为引入了不存在的信息 ✗

    这是贝叶斯思维在分布选择上的体现 —— 与「贝叶斯定理」那一页的「弱先验」原则一致。

    例题 4：熵与决策树的信息增益¶

    某数据集有 8 个样本，标签为「是/否」。划分前的标签分布是 \((6,2)\)（6 个「是」、2 个「否」）。 用某特征划分后得到两组：组 A 有 \((5,1)\)，组 B 有 \((1,1)\)。 计算划分前后的熵与信息增益。

    思路

    算划分前的熵、划分后两组的加权熵，两者之差就是信息增益。

    解答

    第一步：划分前的熵

    概率 \((6/8, 2/8) = (0.75, 0.25)\)：

    \[ H(\text{前}) = -0.75\log_2 0.75-0.25\log_2 0.25 \]
    \[ = 0.75\times0.415+0.25\times2 = 0.3113+0.5 = 0.8113\ \text{比特} \]

    第二步：划分后各组的熵

    组 A（\((5,1)\)，共 6 个）：

    \[ H_A = -\frac56\log_2\frac56-\frac16\log_2\frac16 = 0.8333\times0.2630+0.1667\times2.585 \]
    \[ = 0.2192+0.4308 = 0.6500\ \text{比特} \]

    组 B（\((1,1)\)，共 2 个）：

    \[ H_B = -0.5\log_2 0.5-0.5\log_2 0.5 = 1.0\ \text{比特} \]

    第三步：加权平均（条件熵）

    \[ H(\text{后}) = \frac68H_A+\frac28H_B = 0.75\times0.65+0.25\times1.0 \]
    \[ = 0.4875+0.25 = 0.7375\ \text{比特} \]

    第四步：信息增益

    \[ \text{IG} = H(\text{前})-H(\text{后}) = 0.8113-0.7375 = 0.0738\ \text{比特} \]

    结果：信息增益约 \(0.074\) 比特

    这个增益很小 —— 说明这个特征「不太好」

    信息增益的含义：

    增益 含义
    大 划分后纯度明显提高 → 好特征 ✓
    小（本例） 划分后几乎没变纯 → 差特征 ✗

    为什么本例增益小：

    组 熵 问题
    A \(0.65\) 仍不够纯（\(6\) 个里还有 \(1\) 个「否」）
    B \(1.0\) 完全没分开（一半一半，熵取最大值）✗

    组 B 是「最坏情况」：划分后它的熵是最大值 1.0， 说明这个特征在该组内毫无区分能力。

    决策树的特征选择准则对比：

    准则 公式 特点
    信息增益（ID3） \(H(\text{前})-H(\text{后})\) 偏向取值多的特征 ✗
    信息增益率（C4.5） \(\frac{\text{IG}}{H(\text{特征})}\) 修正上述偏向 ✓
    基尼指数（CART） \(1-\sum p_i^2\) 计算更快（无对数）

    「偏向多取值特征」的问题：

    若某特征取值很多（如「样本编号」，每个值对应一个样本）， 则划分后每组都纯（熵为 0）→ 信息增益最大 ✗

    但这样的划分毫无泛化意义（只是把样本逐个分开）。

    信息增益率通过除以「特征自身的熵」来惩罚：

    \[ \text{增益率} = \frac{\text{IG}}{H(\text{特征})} \]

    取值多的特征 \(H(\text{特征})\) 大 → 增益率被压低

    这与「过拟合」是同一个问题的两种表现： 用过于细分的特征 = 记住了训练数据的噪声。

    五、自测¶

    Q1 某随机变量取三个值，概率为 \((0.5, 0.25, 0.25)\)。 求它的熵（比特），并验证不超过 \(\log_2 3\)。

    提示

    逐项算 \(p\cdot(-\log_2 p)\) 再求和。

    解答

    逐项计算：

    \(p\) \(-\log_2 p\) 贡献
    \(0.5\) \(1\) \(0.5\)
    \(0.25\) \(2\) \(0.5\)
    \(0.25\) \(2\) \(0.5\)
    \[ H = 0.5+0.5+0.5 = 1.5\ \text{比特} \]

    验证上界：

    \[ \log_2 3 \approx 1.585 > 1.5 \;\checkmark \]

    结果：\(H = 1.5\) 比特

    能否用更短的码：注意到每个概率都是 \(2^{-k}\) 形式， 所以可以设计码长恰等于自信息的前缀码：

    符号 码字 长度
    1 0 1
    2 10 2
    3 11 2

    平均码长：\(0.5+0.5+0.5 = 1.5\) = 熵

    这说明：当所有概率都是 \(2\) 的负整数次幂时， 霍夫曼编码能恰好达到熵下界（无「不足 1 比特」的浪费）。

    Q2 判断：若某随机变量的熵为 0，则它一定是常数。

    提示

    回顾 \(H = 0\) 与分布形状的关系。

    解答

    正确（在有限取值集合上）。

    推导：由 \(H(X) = -\sum_x p(x)\log p(x) = 0\)。

    每一项 \(p\log p\leq0\)（因为 \(p\in[0,1]\)，\(\log p\leq0\)）， 所以各项之和为 0 要求每一项都为 0：

    \[ p(x)\log p(x) = 0 \quad\forall x \]

    由约定 \(0\log0 = 0\)，以及 \(\log p = 0\) 当且仅当 \(p = 1\)：

    所以存在某个 \(x^*\) 使 \(p(x^*) = 1\)，其余为 0 —— 即 \(X\) 几乎必然取 \(x^*\)

    结论：熵为零 ⟺ 完全确定 ⟺ 退化分布（单点分布）

    注意「几乎必然」的用词：严格来说，若某取值概率为 0， 那个取值仍是可能的取值（只是不发生）。 在工程中视为「确定」即可。

    工程含义：熵为零的数据不需要传输任何信息 （接收方已经知道内容 —— 这就是「可压到零」的情形。）

    Q3 已知某离散随机变量取值范围是 \(\{0,1,2,3\}\)，且 \(E[X] = 1.5\)。 按最大熵原理应假设什么分布？

    提示

    \(E[X] = 1.5\) 恰好是范围的中点，想想均匀分布是否满足。

    解答

    假设均匀分布：\(p(0) = p(1) = p(2) = p(3) = \frac14\)。

    验证均值：

    \[ E[X] = \frac{0+1+2+3}{4} = \frac64 = 1.5 \;\checkmark \]

    满足约束

    结论：该约束不排除均匀分布，所以最大熵解仍是均匀分布。

    熵：

    \[ H = \log_2 4 = 2\ \text{比特} \]

    一般原理：只有「额外信息」才能改变最大熵解。

    额外信息 是否改变解
    均值 = 1.5（恰在中点） 不改（均匀已满足）
    均值 = 1.0（≠1.5） 改（需要用指数族）
    方差已知 改（趋于高斯）

    实践中要小心：如果你以为某个约束提供了信息， 但实际没有（如本例），那么「用拉格朗日乘数法」会得到 一个不确定的解（方程不足以确定参数）—— 这就是本例的表现。

    判断方法：先检查均匀分布是否满足约束。若满足， 则约束没有信息量

    Q4 为什么压缩算法的极限是熵？

    提示

    考虑「编码长度」与「概率」的关系，以及可辨认编码的空间限制。

    解答

    核心：编码长度与概率的对应关系由「码字空间有限」决定。

    第一步：编码长度与自信息的关系

    在最优编码中，概率为 \(p\) 的符号，其码长约等于自信息：

    \[ L(x)\approx -\log_2 p(x) \]

    理由：若某个符号的码更短，则必然有别的符号的码更长 （因为前缀码要求码字之间不能有前缀关系， 这限制了「短码」的总数量：长度为 \(k\) 的码字最多 \(2^k\) 个）。

    第二步：前缀码的「Kraft 不等式」

    对任何前缀码，码长必须满足

    \[ \sum_x 2^{-L(x)}\leq1 \]

    含义：所有码字在「二进制树」上占据的「概率质量」之和不超过 1。

    第三步：求最小平均长度

    问题化为：

    \[ \min\sum_x p(x)L(x)\quad\text{s.t.}\quad\sum_x2^{-L(x)}\leq1 \]

    用拉格朗日乘数法（回到优化那一页）可得最优解：

    \[ L(x) = -\log_2 p(x) \]

    此时平均长度：

    \[ \bar L = \sum_x p(x)\left(-\log_2 p(x)\right) = H(X) \;\checkmark \]

    结论：熵是平均码长的下界，且可达到（当 \(p(x)\) 都是 \(2\) 的负整数次幂时恰好达到；一般情况下与熵的差小于 1 比特）。

    实用提醒：「达到熵」需要理想编码。 实际算法（Huffman、算术编码、LZ 系列）与熵的差距：

    算法 与熵的差距
    Huffman \(<1\) 比特/符号
    算术编码 可达任意近 ✓
    LZ 系列（通用） 取决于数据冗余度

    工程含义：熵给出了「还能压多少」的可靠标尺 —— 若某压缩算法比熵还小，说明它是有损的（丢了信息）。
