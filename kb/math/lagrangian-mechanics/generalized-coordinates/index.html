    广义坐标与 Euler-Lagrange 方程¶

    牛顿力学用「力」描述运动。这一页换一条路：

    用能量描述运动 —— 只需一个标量函数（拉格朗日量），就能推出全部运动方程。

    这就是拉格朗日力学。它的好处在于坐标选取自由：

    力学体系 描述方式 坐标选取
    牛顿力学 矢量（力、动量） 受约束限制（需引入约束力）✗
    拉格朗日力学 标量（动能、势能） 任意广义坐标 ✓

    一句话抓住核心：一个标量代替一组矢量方程

    拉格朗日量：

    \[ L = T-V \quad\text{（动能减势能）} \]

    Euler-Lagrange 方程：

    \[ \frac{\mathrm{d}}{\mathrm{d}t}\left(\frac{\partial L}{\partial\dot q_i}\right)-\frac{\partial L}{\partial q_i} = 0 \]

    两个关键优势：

    优势 说明
    标量替代矢量 动能与势能都是标量，无需分解方向 ✓
    坐标自由 用广义坐标 \(q_i\)，约束自动被吸收 ✓

    「约束自动被吸收」是最实用的优势： 牛顿法中要算「约束力」（如绳子张力、斜面支持力）， 而拉格朗日法完全不需要

    代价：方程是二阶微分方程，有时求解比牛顿法更繁琐。

    但对于复杂机械系统（如多关节机器人），拉格朗日法的优势压倒性

    一、广义坐标¶

    定义¶

    广义坐标：能完全确定系统位形的任意一组独立变量 \(q_1,\dots,q_n\)。

    关键点：\(n\) 是系统的自由度数（不是质点数、也不是坐标数）。

    系统 自由度 可选的广义坐标
    平面单摆 \(1\) 摆角 \(\theta\)
    双摆 \(2\) 两个摆角 \(\theta_1,\theta_2\)
    平面自由质点 \(2\) \((x,y)\) 或 \((r,\phi)\)
    空间自由刚体 \(6\) 质心三位移 \(+\) 三姿态角
    平面两连杆机械臂 \(2\) 两个关节角

    「自由度」的界定：n = 3N-约束数

    一般公式（\(N\) 个质点，\(m\) 个完整约束）：

    \[ n = 3N-m \]

    举例：

    系统 \(N\) 约束 \(n\)
    空间自由质点 \(1\) \(0\) \(3\)
    平面单摆（杆长固定） \(1\) \(1\)（距离固定） \(1\) ✓
    平面双摆 \(2\) \(2\) \(2\)
    空间刚体 \(N\to\infty\) 刚性 \(6\)

    「平面单摆只有 1 个自由度」这件事很重要：

    质心位置 \((x,y)\) 是 \(2\) 个坐标，但受约束

    \[ x^2+y^2 = l^2 \]

    只剩下一个独立变量（角度）

    用角度而非 \((x,y)\) 的好处：

    坐标 是否满足约束
    \((x,y)\) 需要显式处理约束 ✗
    \(\theta\) 自动满足（因为 \(x = l\sin\theta\)、\(y = -l\cos\theta\)）✓

    这就是「广义坐标自动吸收约束」的含义

    广义速度与动能¶

    广义速度：\(\dot q_i = \dfrac{\mathrm{d}q_i}{\mathrm{d}t}\)。

    动能的一般形式：

    \[ T = \frac12\sum_{i,j}m_{ij}(q)\dot q_i\dot q_j \]

    注意 \(m_{ij}\) 可能依赖 \(q\) —— 这是与质点系（\(T = \frac12m v^2\)）的关键区别 ✓

    为什么依赖 \(q\)：因为位置对广义坐标的导数随 \(q\) 变化。

    例子（平面单摆）：

    位置 \(\boldsymbol{r} = (l\sin\theta,\ -l\cos\theta)\)，所以

    \[ \dot{\boldsymbol{r}} = (l\cos\theta\dot\theta,\ l\sin\theta\dot\theta) \]
    \[ T = \frac12m\lvert\dot{\boldsymbol{r}}\rvert^2 = \frac12ml^2\dot\theta^2 \]

    这里 \(m_{11} = ml^2\) 是常数（因为单摆的转动惯量不随角度变）。

    若换成「弹簧摆」（杆长可变）：\(l\) 也是广义坐标，此时

    \[ T = \frac12m(\dot l^2+l^2\dot\theta^2) \]

    \(m_{22} = ml^2\) 依赖 \(l\) ✓ —— 这就是「\(m_{ij}\) 依赖 \(q\)」的例子。

    这一项会产生「离心力」等惯性效应（几何耦合项）。

    二、从变分原理推导 Euler-Lagrange 方程¶

    作用量与 Hamilton 原理¶

    作用量：

    \[ S = \int_{t_1}^{t_2}L(q,\dot q,t)\,\mathrm{d}t \]

    Hamilton 原理（最小作用量原理）：

    真实运动使作用量取极值（通常是极小）。

    \[ \delta S = 0 \]

    从 S = 0 推导 Euler-Lagrange 方程（核心推导）

    第一步：对 \(q(t)\) 施加变分

    设真实轨迹 \(q(t)\)，考虑邻近轨迹 \(q(t)+\epsilon\eta(t)\)， 其中 \(\eta(t_1) = \eta(t_2) = 0\)（端点固定）

    这个「端点固定」条件是关键 —— 它使边界项消失。

    第二步：作用量的变分

    \[ \frac{\mathrm{d}S}{\mathrm{d}\epsilon}\bigg|_{\epsilon=0} = \int_{t_1}^{t_2}\left[\frac{\partial L}{\partial q}\eta+\frac{\partial L}{\partial\dot q}\dot\eta\right]\mathrm{d}t \]

    第三步：对第二项分部积分

    \[ \int_{t_1}^{t_2}\frac{\partial L}{\partial\dot q}\dot\eta\,\mathrm{d}t = \left[\frac{\partial L}{\partial\dot q}\eta\right]_{t_1}^{t_2}-\int_{t_1}^{t_2}\frac{\mathrm{d}}{\mathrm{d}t}\left(\frac{\partial L}{\partial\dot q}\right)\eta\,\mathrm{d}t \]

    边界项为零（因为 \(\eta(t_1) = \eta(t_2) = 0\)）

    第四步：合并

    \[ \frac{\mathrm{d}S}{\mathrm{d}\epsilon}\bigg|_{\epsilon=0} = \int_{t_1}^{t_2}\left[\frac{\partial L}{\partial q}-\frac{\mathrm{d}}{\mathrm{d}t}\left(\frac{\partial L}{\partial\dot q}\right)\right]\eta\,\mathrm{d}t = 0 \]

    第五步：用「基本引理」

    因为 \(\eta(t)\) 是任意的（只要求端点为零）， 方括号内的量必须恒为零 ✓ （若某处不为零，可取 \(\eta\) 在该处非零而其余为零，使积分不为零。）

    所以：

    \[ \boxed{\ \frac{\mathrm{d}}{\mathrm{d}t}\left(\frac{\partial L}{\partial\dot q_i}\right)-\frac{\partial L}{\partial q_i} = 0\ } \]

    这是 \(n\) 个二阶微分方程（每个自由度一个）

    推导中的三个关键点：

    点 作用
    端点固定 消掉边界项
    分部积分 把 \(\dot\eta\) 转成 \(\eta\)
    \(\eta\) 任意 推出方括号恒为零

    注意「作用量极值」而非「最小」： 一般是极小，但在某些情况下可以是极大或鞍点 —— 统称「驻值」（stationary）

    「动能减势能」为什么是对的¶

    一个常见困惑：为什么是 \(T-V\)（相减）而不是 \(T+V\)？

    答：由变分原理反推出来的。看简单例子：

    自由质点（\(T = \frac12m\dot x^2\)、\(V = 0\)）：

    \[ L = \frac12m\dot x^2 \implies \frac{\partial L}{\partial\dot x} = m\dot x,\quad \frac{\partial L}{\partial x} = 0 \]

    EL 方程：

    \[ \frac{\mathrm{d}}{\mathrm{d}t}(m\dot x)-0 = 0 \implies m\ddot x = 0 \;\checkmark \]

    得到「无外力则匀速」

    重力场中的质点（\(V = mgz\)）：

    \[ L = \frac12m\dot z^2-mgz \]

    EL 方程：

    \[ \frac{\partial L}{\partial\dot z} = m\dot z \implies \frac{\mathrm{d}}{\mathrm{d}t}(m\dot z) = m\ddot z \]
    \[ \frac{\partial L}{\partial z} = -mg \]
    \[ m\ddot z-(-mg) = 0 \implies m\ddot z = -mg \;\checkmark \]

    正确给出重力加速度

    「T-V 而不是 T+V」的检验

    若用 \(T+V\) 会怎样：\(L = \frac12m\dot z^2+mgz\)

    \[ m\ddot z-mg = 0 \implies \ddot z = +g \;\text{（方向反了）}✗ \]

    错误

    所以「相减」不是任意选择，而是被物理决定的

    直观理解（一个有用的类比）：

    量 角色
    \(V\) 位置的「代价」
    \(T\) 运动的「代价」
    \(L = T-V\) 两者之差（对真实运动取驻值）

    另一种理解：EL 方程给出的正是牛顿第二定律

    \[ \frac{\mathrm{d}}{\mathrm{d}t}(m\dot q) = -\frac{\partial V}{\partial q} \]

    其中左边是动量的时间导数、右边是力的负梯度。 \(L\) 只是把这两个角色分配给了 \(T\) 与 \(-V\)

    三、EL 方程的应用模板¶

    标准流程：

    步骤 操作
    1 选广义坐标 \(q_i\)（个数 = 自由度数）
    2 用 \(q,\dot q\) 表示动能 \(T\)
    3 用 \(q\) 表示势能 \(V\)
    4 写出 \(L = T-V\)
    5 对每个 \(q_i\) 算 EL 方程
    6 整理成运动方程（可能非线性）

    第 2、3 步是主要工作量，第 5 步只是机械求导

    为什么「V 只依赖 q、不依赖 q」在多数情形成立

    常见势能：

    势能 表达式 依赖
    重力 \(mgz\) 只依赖位置 ✓
    弹性 \(\frac12k(x-x_0)^2\) 只依赖位置 ✓
    电磁（含速度项） \(q\phi-q\boldsymbol{A}\cdot\boldsymbol{v}\) 依赖速度 ✗

    对于「依赖速度的势」，标准处理是改用「广义势」：

    \[ L = T-V_{\text{广义}} \]

    其中 \(V_{\text{广义}}\) 可以依赖 \(\dot q\)（如电磁场情形）

    这一页只处理「\(V\) 只依赖 \(q\)」的情形（覆盖绝大多数机械系统）。

    一个重要的检验：若 \(L\) 不显含某个 \(q_k\)（即 \(\partial L/\partial q_k = 0\)）， 则

    \[ \frac{\mathrm{d}}{\mathrm{d}t}\left(\frac{\partial L}{\partial\dot q_k}\right) = 0 \implies p_k\equiv\frac{\partial L}{\partial\dot q_k} = \text{const} \]

    这就是「循环坐标 ⟹ 动量守恒」 —— 详见下一页（约束与守恒量）。

    四、典型例题¶

    例题 1：平面单摆¶

    质量 \(m\) 的质点用长 \(l\) 的轻杆悬挂，在竖直平面内摆动。 用拉格朗日法求运动方程。

    思路

    广义坐标取摆角 \(\theta\)；先写位置再求速度。

    解答

    第一步：选广义坐标

    自由度 \(n = 1\)（因为杆长固定），取摆角 \(\theta\)（从竖直向下量起）。

    第二步：位置与速度

    以悬挂点为原点、\(y\) 向下为正：

    \[ x = l\sin\theta,\qquad y = l\cos\theta \]

    速度：

    \[ \dot x = l\cos\theta\,\dot\theta,\qquad \dot y = -l\sin\theta\,\dot\theta \]

    速率平方：

    \[ \dot x^2+\dot y^2 = l^2\dot\theta^2(\cos^2\theta+\sin^2\theta) = l^2\dot\theta^2 \]

    第三步：动能与势能

    \[ T = \frac12ml^2\dot\theta^2 \]

    势能（取最低点为势能零点，则高度为 \(l(1-\cos\theta)\)）：

    \[ V = mgl(1-\cos\theta) \]

    第四步：拉格朗日量

    \[ L = \frac12ml^2\dot\theta^2-mgl(1-\cos\theta) \]

    第五步：算 EL 方程的两项

    \[ \frac{\partial L}{\partial\dot\theta} = ml^2\dot\theta \quad\implies\quad \frac{\mathrm{d}}{\mathrm{d}t}\left(\frac{\partial L}{\partial\dot\theta}\right) = ml^2\ddot\theta \]
    \[ \frac{\partial L}{\partial\theta} = -mgl\sin\theta \]

    （注意：对 \(\theta\) 求导时 \(V\) 的项给出 \(-mgl\sin\theta\)。）

    第六步：代回 EL 方程

    \[ ml^2\ddot\theta-(-mgl\sin\theta) = 0 \]
    \[ \boxed{\ ml^2\ddot\theta+mgl\sin\theta = 0 \quad\Longleftrightarrow\quad \ddot\theta+\frac{g}{l}\sin\theta = 0\ } \]

    结果：\(\ddot\theta+\dfrac{g}{l}\sin\theta = 0\)

    验证：小角度近似

    当 \(\theta\ll1\) 时 \(\sin\theta\approx\theta\)：

    \[ \ddot\theta+\frac{g}{l}\theta = 0 \]

    简谐振动，角频率

    \[ \omega = \sqrt{\frac{g}{l}},\qquad T_{\text{周期}} = 2\pi\sqrt{\frac{l}{g}} \;\checkmark \]

    与教科书结果一致

    对比：牛顿法要处理约束力，拉格朗日法不用

    牛顿法的做法：

    需要分解重力为「沿杆方向」与「切向」两个分量， 其中沿杆分量的张力与向心加速度平衡：

    方向 方程
    沿杆 \(T-mg\cos\theta = ml\dot\theta^2\)（用于求张力）
    切向 \(ml\ddot\theta = -mg\sin\theta\) ✓

    要额外算张力 \(T\) —— 而我们根本不关心它 ✗

    拉格朗日法：

    完全不需要张力 —— 因为 \(\theta\) 已经自动满足杆长约束

    这就是「广义坐标吸收约束」的实际价值

    工程含义（机器人学）：

    多关节机械臂的拉格朗日方程中，关节处的约束力（结构内力）不出现在方程里 —— 我们只关心关节力矩 这使得推导可以完全用能量方法系统化地进行。

    例题 2：弹簧振子与阻尼¶

    质量 \(m\) 的物体连在刚度 \(k\) 的弹簧上，受与速度成正比的阻尼力 \(-c\dot x\)。 用拉格朗日法求运动方程。

    思路

    阻尼是非保守力，需要用「广义力」处理。

    解答

    第一步：无阻尼部分

    广义坐标 \(x\)（相对平衡位置的位移）：

    \[ T = \frac12m\dot x^2,\qquad V = \frac12kx^2 \]
    \[ L = \frac12m\dot x^2-\frac12kx^2 \]

    第二步：处理非保守力（关键）

    阻尼力不能写进 \(V\)（因为它是耗散力，不做势力）✗

    正确做法：把非保守力作为广义力 \(Q_x\) 加到 EL 方程右边：

    \[ \frac{\mathrm{d}}{\mathrm{d}t}\left(\frac{\partial L}{\partial\dot x}\right)-\frac{\partial L}{\partial x} = Q_x \]

    第三步：算广义力

    虚功原理：\(\delta W = -c\dot x\,\delta x\)，所以

    \[ Q_x = -c\dot x \]

    （因为力 \(F = -c\dot x\)，而 \(Q_x = F\frac{\partial x}{\partial x} = F\)。）

    第四步：代入

    \[ m\ddot x-(-kx) = -c\dot x \]
    \[ \boxed{\ m\ddot x+c\dot x+kx = 0\ } \]

    结果：标准的阻尼振子方程

    第五步：分析（用特征方程）

    设 \(x = e^{\lambda t}\)：

    \[ m\lambda^2+c\lambda+k = 0 \implies \lambda = \frac{-c\pm\sqrt{c^2-4mk}}{2m} \]

    三种情形：

    判别式 名称 行为
    \(c^2>4mk\) 过阻尼 两个负实根，无振荡
    \(c^2 = 4mk\) 临界阻尼 重根，最快无振荡回复 ✓
    \(c^2<4mk\) 欠阻尼 复根，衰减振荡

    临界阻尼条件：

    \[ c_{\text{crit}} = 2\sqrt{mk} \]

    「非保守力」的处理方式（这是常见的难点）

    三种力的分类：

    类型 例子 处理
    保守力 重力、弹簧 放进 \(V\) ✓
    耗散力 阻尼、摩擦 用广义力 \(Q\)（或 Rayleigh 耗散函数）
    速度相关力 电磁场洛伦兹力 用广义势

    Rayleigh 耗散函数（更优雅的做法）：

    \[ \mathcal{F} = \frac12c\dot x^2 \]

    则方程变为：

    \[ \frac{\mathrm{d}}{\mathrm{d}t}\left(\frac{\partial L}{\partial\dot x}\right)-\frac{\partial L}{\partial x}+\frac{\partial\mathcal{F}}{\partial\dot x} = 0 \]

    验证：\(\frac{\partial\mathcal{F}}{\partial\dot x} = c\dot x\)，代入得

    \[ m\ddot x+kx+c\dot x = 0 \;\checkmark \]

    与直接加广义力等价

    Rayleigh 函数的物理含义：它的一半是耗散功率：

    \[ P_{\text{耗散}} = c\dot x^2 = 2\mathcal{F} \]

    工程价值（能量法分析阻尼系统）：

    用途 说明
    能量平衡 输入能量 = 存储能量 + 耗散能量
    稳定性判断 耗散使能量单调减少 → 稳定 ✓
    Lyapunov 函数构造 用「总能量」作为 Lyapunov 函数

    这与「梯度下降与收敛」一页的「Lyapunov 方法」是同一思想 ✓ —— 用能量单调下降证明稳定性。

    注意阻尼的本质：它使相空间体积收缩（耗散系统）， 所以轨迹最终趋向吸引子

    例题 3：双摆（耦合系统的拉格朗日方程）¶

    两个相同质量 \(m\) 的质点用两根长 \(l\) 的轻杆串联， 在同一竖直平面内摆动。写出拉格朗日量与运动方程。

    思路

    两个广义坐标 \(\theta_1,\theta_2\)；先写两个质点的位置。

    解答

    第一步：广义坐标

    \(n = 2\)，取 \(\theta_1\)（第一杆与竖直方向夹角）、 \(\theta_2\)（第二杆与竖直方向夹角）

    第二步：两个质点的位置

    质点 1：

    \[ x_1 = l\sin\theta_1,\qquad y_1 = l\cos\theta_1 \]

    质点 2（在第一质点的基础上再加一段）：

    \[ x_2 = l\sin\theta_1+l\sin\theta_2,\qquad y_2 = l\cos\theta_1+l\cos\theta_2 \]

    第三步：速度

    \[ \dot x_1 = l\cos\theta_1\dot\theta_1,\qquad \dot y_1 = -l\sin\theta_1\dot\theta_1 \]
    \[ \dot x_2 = l\cos\theta_1\dot\theta_1+l\cos\theta_2\dot\theta_2 \]
    \[ \dot y_2 = -l\sin\theta_1\dot\theta_1-l\sin\theta_2\dot\theta_2 \]

    第四步：速率平方（关键是交叉项）

    \[ \lvert\dot{\boldsymbol{r}}_1\rvert^2 = l^2\dot\theta_1^2 \]
    \[ \lvert\dot{\boldsymbol{r}}_2\rvert^2 = l^2\dot\theta_1^2+l^2\dot\theta_2^2+2l^2\dot\theta_1\dot\theta_2(\cos\theta_1\cos\theta_2+\sin\theta_1\sin\theta_2) \]

    用和角公式 \(\cos(\theta_1-\theta_2) = \cos\theta_1\cos\theta_2+\sin\theta_1\sin\theta_2\)：

    \[ \lvert\dot{\boldsymbol{r}}_2\rvert^2 = l^2\left[\dot\theta_1^2+\dot\theta_2^2+2\dot\theta_1\dot\theta_2\cos(\theta_1-\theta_2)\right] \]

    第五步：动能

    \[ T = \frac12m\left[\lvert\dot{\boldsymbol{r}}_1\rvert^2+\lvert\dot{\boldsymbol{r}}_2\rvert^2\right] \]
    \[ = \frac12ml^2\left[2\dot\theta_1^2+\dot\theta_2^2+2\dot\theta_1\dot\theta_2\cos(\theta_1-\theta_2)\right] \]

    第六步：势能（取悬挂点为参考）

    \[ V = -mg(y_1+y_2) = -mgl(2\cos\theta_1+\cos\theta_2) \]

    第七步：拉格朗日量

    \[ \boxed{\ L = \frac{ml^2}{2}\left[2\dot\theta_1^2+\dot\theta_2^2+2\dot\theta_1\dot\theta_2\cos(\theta_1-\theta_2)\right]+mgl(2\cos\theta_1+\cos\theta_2)\ } \]

    第八步：运动方程（不展开全部求导，给出结构）

    对 \(\theta_1\) 应用 EL 方程，会得到：

    \[ 2ml^2\ddot\theta_1+ml^2\ddot\theta_2\cos(\theta_1-\theta_2)-ml^2\dot\theta_2^2\sin(\theta_1-\theta_2)+2mgl\sin\theta_1 = 0 \]

    对 \(\theta_2\)：

    \[ ml^2\ddot\theta_2+ml^2\ddot\theta_1\cos(\theta_1-\theta_2)+ml^2\dot\theta_1^2\sin(\theta_1-\theta_2)+mgl\sin\theta_2 = 0 \]

    双摆的三个重要特征（这就是「混沌」的来源）

    特征 1：动能里有交叉项

    \[ 2\dot\theta_1\dot\theta_2\cos(\theta_1-\theta_2) \]

    这一项使两个自由度「耦合」 —— 不能像单摆那样各自独立 ✓

    特征 2：方程里有 \(\dot\theta^2\) 项（非线性）

    \[ \dot\theta_2^2\sin(\theta_1-\theta_2),\qquad \dot\theta_1^2\sin(\theta_1-\theta_2) \]

    这是「离心型」的非线性项 —— 来自动能中 \(m_{ij}(q)\) 对 \(q\) 的依赖

    特征 3：没有解析解

    双摆的运动方程是非线性耦合常微分方程 —— 一般没有闭式解 ✗

    后果：

    现象 说明
    混沌 初始条件的微小差异被指数放大
    长期不可预测 无法用解析式预测
    能量守恒但仍混沌 「保守系统也能混沌」✓

    工程含义（机器人学）：

    启示 说明
    多关节系统本质非线性 不能简单线性化就完事 ✗
    需要数值积分 用 RK4 等（详见 ODE 模块）
    控制必须考虑耦合 关节间的惯性耦合不能忽略
    混沌系统的控制困难 长期预测不可行

    这解释了「为什么机械臂动力学建模与数值仿真不可或缺」 —— 即使只有两个连杆，也没有解析解

    与非线性控制的联系：

    反馈线性化就是「通过精心设计的控制律， 把这个非线性系统变换为线性系统」—— 而它的第一步就是写出拉格朗日方程

    例题 4：用 EL 方程验证动量守恒¶

    质量为 \(m\) 的质点在无势场中自由运动（无外力）。 用拉格朗日量说明动量守恒。

    思路

    看 \(L\) 是否显含坐标 → 循环坐标 ⟹ 共轭动量守恒。

    解答

    第一步：写拉格朗日量

    自由质点（无势能，\(V = 0\)）：

    \[ L = T = \frac12m(\dot x^2+\dot y^2+\dot z^2) \]

    第二步：观察「不显含坐标」

    \[ \frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} = \frac{\partial L}{\partial z} = 0 \]

    即 \(x,y,z\) 都是循环坐标

    第三步：用 EL 方程

    对 \(x\)：

    \[ \frac{\mathrm{d}}{\mathrm{d}t}\left(\frac{\partial L}{\partial\dot x}\right)-\underbrace{\frac{\partial L}{\partial x}}_{=0} = 0 \]
    \[ \frac{\mathrm{d}}{\mathrm{d}t}(m\dot x) = 0 \implies m\dot x = \text{const} \]

    同理 \(m\dot y\)、\(m\dot z\) 都是常数

    结果：三个方向的动量分量全部守恒

    第四步：一般结论

    若 \(L\) 不显含某个 \(q_k\)（循环坐标），则

    \[ p_k\equiv\frac{\partial L}{\partial\dot q_k} = \text{const} \]

    这就是「共轭动量守恒」

    「对称性 ⟺ 守恒律」—— Noether 定理的雏形

    对应表：

    \(L\) 不依赖什么 守恒量 对称性
    空间平移 动量 ✓ 空间均匀
    时间（\(L\) 不显含 \(t\)） 能量 ✓ 时间均匀
    空间旋转 角动量 ✓ 空间各向同性

    这就是 Noether 定理的核心思想：

    \[ \text{每一个连续对称性} \Longleftrightarrow \text{一个守恒量} \]

    验证「时间平移 ⟹ 能量守恒」：

    若 \(L\) 不显含 \(t\)，则能量

    \[ E = \sum_i\dot q_i\frac{\partial L}{\partial\dot q_i}-L \]

    守恒 ✓（可对时间求导验证为零。）

    对本例题：

    \[ E = m\dot x\cdot\dot x+m\dot y\cdot\dot y+m\dot z\cdot\dot z-\frac12m(\dot x^2+\dot y^2+\dot z^2) = \frac12m\lvert\dot{\boldsymbol{r}}\rvert^2 = T \;\checkmark \]

    即动能守恒（因为 \(V = 0\)，总能量就是动能）

    工程含义（机器人学）：

    对称性 机器人中的表现
    重力方向固定 动量不守恒（但有其他结构）
    关节无摩擦、无重力 能量守恒 → 可用能量作为 Lyapunov 函数 ✓
    旋转对称（如自由漂浮航天器） 角动量守恒 → 姿态控制的重要约束 ✓

    实践价值：守恒量可以作为数值积分的检验

    例如：用 RK4 仿真无阻尼摆时， 应检查「总能量是否近似守恒」—— 若能量单调漂移，说明步长太大或算法不当 ✗

    这是「仿真结果是否可信」的最基本的自检

    五、自测¶

    Q1 一个质量为 \(m\) 的珠子可沿光滑的竖直圆环（半径 \(R\)）滑动。 用拉格朗日法求运动方程。

    提示

    自由度 1，取珠子与最低点的夹角 \(\theta\) 为广义坐标。

    解答

    第一步：选广义坐标

    珠子被约束在圆环上，自由度 \(n = 1\)，取偏角 \(\theta\)

    第二步：位置与速度

    以圆心为原点、竖直向下为 \(y\) 轴正向：

    \[ x = R\sin\theta,\qquad y = R\cos\theta \]
    \[ \dot x = R\cos\theta\,\dot\theta,\qquad \dot y = -R\sin\theta\,\dot\theta \]
    \[ \lvert\dot{\boldsymbol{r}}\rvert^2 = R^2\dot\theta^2(\cos^2\theta+\sin^2\theta) = R^2\dot\theta^2 \]

    第三步：动能与势能

    \[ T = \frac12mR^2\dot\theta^2 \]
    \[ V = -mgR\cos\theta \]

    （取圆心为零势能点时，位置高度为 \(-R\cos\theta\)，即最低点势能最低。）

    第四步：拉格朗日量

    \[ L = \frac12mR^2\dot\theta^2+mgR\cos\theta \]

    第五步：EL 方程

    \[ \frac{\partial L}{\partial\dot\theta} = mR^2\dot\theta \implies \frac{\mathrm{d}}{\mathrm{d}t}\left(\frac{\partial L}{\partial\dot\theta}\right) = mR^2\ddot\theta \]
    \[ \frac{\partial L}{\partial\theta} = -mgR\sin\theta \]
    \[ mR^2\ddot\theta-(-mgR\sin\theta) = 0 \]

    结果：

    \[ \boxed{\ \ddot\theta+\frac{g}{R}\sin\theta = 0\ } \]

    与单摆方程形式相同，只是 \(l\to R\) ✓ —— 因为「圆环上的珠子」与「绳摆」的几何约束本质相同。

    两个平衡点：

    \(\theta\) 位置 稳定性
    \(0\) 最低点 稳定 ✓
    \(\pi\) 最高点 不稳定 ✗

    用「拐点判据」验证（\(V = -mgR\cos\theta\)）：

    \[ V'(\theta) = mgR\sin\theta = 0 \implies \theta = 0,\ \pi \]
    \[ V''(\theta) = mgR\cos\theta \]
    \(\theta\) \(V''\) 结论
    \(0\) \(mgR>0\) 势能极小 → 稳定 ✓
    \(\pi\) \(-mgR<0\) 势能极大 → 不稳定 ✗

    这就是「势能极小 ⟺ 稳定平衡」的判据

    Q2 判断：用拉格朗日法必须选「自然的」坐标（如角度、长度）。

    提示

    \(\theta\) 与 \(\ln r\) 都能描述同一系统吗？

    解答

    不对。广义坐标可以是任意能唯一确定位形的独立变量。

    允许的例子（同一个系统）：

    系统 可用的广义坐标
    平面单摆 \(\theta\)；或 \(\cos\theta\)；或 \(\tan(\theta/2)\)
    平面质点 \((x,y)\)；\((r,\phi)\)；或 \((u,v)\) 的任意可逆变换
    一维振子 \(x\)；或 \(\ln x\)（\(x>0\) 时）；或 \(x^3\)

    为什么可以任意选：

    因为 EL 方程的形式在任意可逆坐标变换下保持（协变性）

    但要注意两点：

    注意 1：变换必须是可逆的（一一对应）

    变换 是否合格
    \(\theta\in(-\pi,\pi)\) ✓
    \(\cos\theta\in(-1,1)\) ✓（可逆）
    \(\theta^2\) ✗ 不可逆（\(\pm\theta\) 混淆）

    注意 2：坐标选取影响方程形式（但不影响物理）

    以单摆为例，用 \(\theta\) 得

    \[ \ddot\theta+\frac{g}{l}\sin\theta = 0 \]

    若用 \(u = \cos\theta\)：

    \[ \dot u = -\sin\theta\,\dot\theta \]

    方程会变得更复杂（含根号）——

    物理完全一样，但方程难解 ✗

    所以「坐标可以任意选，但要选得聪明」

    工程选择原则：

    原则 理由
    选使约束自动满足的 减少变量 ✓
    选使动能/势能简单的 方程更简洁
    选有物理意义的 便于解释结果
    避开奇点 如 \(\theta = \pi\) 处 \(\tan(\theta/2)\) 发散

    一个重要的反例（球坐标在极点）：

    用 \((\theta,\phi)\) 描述球面时，极点处 \(\phi\) 无定义 —— 方程在那里有奇点 ✗

    工程含义：卫星/机器人的姿态参数化必须避免奇异点 —— 这就是为什么用四元数（无奇点）而非欧拉角

    Q3 求竖直平面内「弹簧摆」（质量为 \(m\) 的质点，用刚度 \(k\) 的弹簧悬挂， 弹簧原长 \(l_0\)）的拉格朗日量与自由度数。

    提示

    弹簧长度 \(l\) 与摆角 \(\theta\) 都是变量 → 自由度 2。

    解答

    第一步：确定自由度

    约束 是否完整
    质点被限制在竖直平面内 ✓（减少一个坐标）
    弹簧长度可变 无额外约束 ✓

    所以自由度 \(n = 2\)，取广义坐标 \((l,\theta)\)： \(l\) 是弹簧即时长度，\(\theta\) 是与竖直方向的夹角

    第二步：位置

    \[ x = l\sin\theta,\qquad y = l\cos\theta \]

    注意「位置显含 \(l\)」（与普通单摆的关键区别）✓

    第三步：速度（要用乘积法则）

    \[ \dot x = \dot l\sin\theta+l\cos\theta\,\dot\theta \]
    \[ \dot y = \dot l\cos\theta-l\sin\theta\,\dot\theta \]

    第四步：速率平方（这一步最容易算错）

    \[ \lvert\dot{\boldsymbol{r}}\rvert^2 = \dot x^2+\dot y^2 \]

    展开：

    \[ \dot x^2 = \dot l^2\sin^2\theta+2\dot ll\dot\theta\sin\theta\cos\theta+l^2\dot\theta^2\cos^2\theta \]
    \[ \dot y^2 = \dot l^2\cos^2\theta-2\dot ll\dot\theta\sin\theta\cos\theta+l^2\dot\theta^2\sin^2\theta \]

    相加，注意交叉项抵消 ✓：

    \[ \lvert\dot{\boldsymbol{r}}\rvert^2 = \dot l^2+l^2\dot\theta^2 \]

    第五步：动能与势能

    \[ T = \frac12m\left(\dot l^2+l^2\dot\theta^2\right) \]

    势能 = 重力势能 + 弹性势能：

    \[ V = -mgl\cos\theta+\frac12k(l-l_0)^2 \]

    第六步：拉格朗日量

    \[ \boxed{\ L = \frac12m\left(\dot l^2+l^2\dot\theta^2\right)+mgl\cos\theta-\frac12k(l-l_0)^2\ } \]

    对比普通单摆（\(l\) 固定）：

    项 单摆 弹簧摆
    自由度 \(1\) \(2\)
    动能 \(\frac12ml^2\dot\theta^2\) 多出 \(\frac12m\dot l^2\)
    耦合 无 \(l^2\dot\theta^2\) 项

    「l22 项」带来的重要物理效应

    关键观察：动能中 \(m_{22} = ml^2\) 依赖 \(l\) ✓

    对 \(\theta\) 的 EL 方程会因此产生额外项：

    \[ \frac{\partial T}{\partial\theta}\text{ 项给出 } ml\dot l\dot\theta \]

    对 \(l\) 的方程：

    \[ m\ddot l = ml\dot\theta^2+mg\cos\theta-k(l-l_0) \]

    注意 \(ml\dot\theta^2\) 这一项 —— 离心力 ✓

    含义：摆得越快，弹簧被拉得越长

    这就是「两个自由度耦合」的物理表现：

    现象 说明
    摆动加快 离心力增大 → 弹簧伸长
    弹簧伸长 转动惯量 \(ml^2\) 增大 → 摆动变慢
    两者相互影响 不能独立分析 ✗

    工程意义（离心调速器、旋转机械）：

    场景 现象
    转动带可动质量块 转速升高 → 质量块外移（离心调速器原理）✓
    旋转的柔性臂 转速升高 → 臂伸长（离心刚化）
    直升机旋翼 转速影响桨叶的摆振频率

    这就是「单摆」与「弹簧摆」的本质区别： 后者是耦合的非线性系统，可能出现能量在两个自由度间传递（拍频）

    Q4 为什么「作用量取极值」能推出运动方程？给出推导的关键三步。

    提示

    变分、分部积分、基本引理。

    解答

    前提：设真实轨迹 \(q(t)\)，考虑邻近轨迹 \(q(t)+\epsilon\eta(t)\)， 其中 \(\eta(t_1) = \eta(t_2) = 0\)（端点固定）

    第一步：写出变分

    \[ \frac{\mathrm{d}S}{\mathrm{d}\epsilon}\bigg|_{\epsilon=0} = 0 \]

    代入 \(S = \int_{t_1}^{t_2}L(q,\dot q,t)\mathrm{d}t\)：

    \[ = \int_{t_1}^{t_2}\left[\frac{\partial L}{\partial q}\eta+\frac{\partial L}{\partial\dot q}\dot\eta\right]\mathrm{d}t \]

    第二步：对 \(\dot\eta\) 项分部积分

    \[ \int_{t_1}^{t_2}\frac{\partial L}{\partial\dot q}\dot\eta\,\mathrm{d}t = \left[\frac{\partial L}{\partial\dot q}\eta\right]_{t_1}^{t_2}-\int_{t_1}^{t_2}\frac{\mathrm{d}}{\mathrm{d}t}\left(\frac{\partial L}{\partial\dot q}\right)\eta\,\mathrm{d}t \]

    因为 \(\eta(t_1) = \eta(t_2) = 0\)，边界项为零

    第三步：用基本引理

    \[ \int_{t_1}^{t_2}\left[\frac{\partial L}{\partial q}-\frac{\mathrm{d}}{\mathrm{d}t}\left(\frac{\partial L}{\partial\dot q}\right)\right]\eta\,\mathrm{d}t = 0 \]

    因为 \(\eta\) 任意（只要求端点为零），方括号必须恒为零：

    \[ \frac{\mathrm{d}}{\mathrm{d}t}\left(\frac{\partial L}{\partial\dot q}\right)-\frac{\partial L}{\partial q} = 0 \;\checkmark \]

    结果：Euler-Lagrange 方程

    三个关键点的作用：

    步骤 关键点 作用
    一 变分 \(q\to q+\epsilon\eta\) 把「函数」的极值问题变成「参数」的极值
    二 端点固定 消掉边界项 ✓
    三 \(\eta\) 任意 推出被积函数恒为零 ✓

    「端点固定」为什么合理：

    因为我们要求的是「给定起点与终点的轨迹」 —— 变分不能改变端点 ✓

    「\(\eta\) 任意」为什么合法：

    基本引理：若 \(\int f(t)\eta(t)\mathrm{d}t = 0\) 对一切满足 \(\eta(t_1) = \eta(t_2) = 0\) 的连续 \(\eta\) 成立，则 \(f\equiv0\)

    证明思路（反证）：若某点 \(t_0\) 处 \(f(t_0)\neq0\)， 取 \(\eta\) 为在 \(t_0\) 附近为正、其余为零的「尖峰函数」， 则由连续性，积分不为零 —— 矛盾

    这个「基本引理」是变分法的基石 它在有限元、最优控制、变分推断中都反复出现。

    工程联系：

    领域 类似结构
    最优控制 Pontryagin 极小值原理也从变分导出
    有限元 弱形式来自「虚功原理」（同为变分）
    变分推断 用变分逼近后验（同源于变分原理）
    深度学习 「变分自编码器」（VAE）用变分下界

    共同点：都是「把极值问题转化为可求解的微分/代数方程」
