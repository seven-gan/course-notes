    信号与系统基础¶

    这是信号处理模块的第一页。在给出定义之前，先把整个学科的核心问题说清楚：

    一个系统对输入做了什么？

    这句话看起来简单，但它决定了这门课的整个结构：

    问题 对应的工具
    输入是什么？ 信号（连续 / 离散、周期 / 非周期）
    系统怎么描述？ 冲激响应、系统函数
    「做了什么」怎么算？ 卷积
    有没有更简单的看法？ 傅里叶变换（换到频域）
    能不能算得快？ FFT、滤波器设计

    两条主线贯穿全课

    主线 1（时域）：系统对输入逐点作用 → 卷积

    主线 2（频域）：把信号拆成不同频率 → 傅里叶变换

    两条线由卷积定理连接：

    \[ \text{时域卷积} \quad\Longleftrightarrow\quad \text{频域相乘} \]

    理解这一点，这门课就通了一半。

    一、信号：什么是信号¶

    定义：信号是携带信息的物理量的表示，数学上就是一个函数。

    类型 数学形式 例子
    连续时间信号 \(x(t)\)，\(t \in \mathbb{R}\) 麦克风电压、温度曲线
    离散时间信号 \(x[n]\)，\(n \in \mathbb{Z}\) 每秒采样的数字、每日股价

    方括号与圆括号的约定（很重要）

    本课程（以及绝大多数教材）用符号区分两类信号：

    记号 含义 自变量
    \(x(t)\) 连续时间信号 实数 \(t\)
    \(x[n]\) 离散时间信号 整数 \(n\)

    这个区分不是随意的：连续信号的运算（求导、积分）与离散信号的运算 （差分、求和）本质不同，用不同括号能避免混淆。

    另外注意：\(x[n]\) 中的 \(n\) 只是序号，不是「时间的第 n 秒」。 采样周期 \(T_s\) 才联系两者：\(x[n] = x(nT_s)\)。

    基本信号¶

    1. 单位冲激（连续） \(\delta(t)\)

    它不是普通函数，而是由筛选性质定义的广义函数：

    \[ \int_{-\infty}^{\infty} x(t)\delta(t-t_0)\,\mathrm{d}t = x(t_0) \]

    直观理解：一个「无穷窄、无穷高、面积为 1」的尖峰。它的作用是从 \(x(t)\) 中 「挑出」\(t_0\) 时刻的值。

    2. 单位阶跃 \(u(t)\)

    \[ u(t) = \begin{cases} 1, & t \geq 0 \\ 0, & t < 0\end{cases} \]

    3. 单位脉冲（离散） \(\delta[n]\)

    \[ \delta[n] = \begin{cases} 1, & n = 0 \\ 0, & n \neq 0\end{cases} \]

    与连续情形不同，离散冲激是普通函数（一个值为 1、其余为 0 的序列）， 不需要广义函数理论。

    4. 复指数信号 \(e^{j\omega t}\)

    这是最重要的信号，因为它穿过任何 LTI 系统后形状不变（只是被乘一个复数）。 这个性质称为「复指数是 LTI 系统的特征函数」。

    为什么复指数这么重要

    回忆线性代数：特征向量是「被矩阵作用后方向不变」的向量。

    对 LTI 系统，「方向不变」的含义是「波形不变，只改变幅度与相位」。 满足这个条件的信号正是复指数 \(e^{j\omega t}\)：

    \[ \text{LTI 系统}\{e^{j\omega t}\} = H(\omega)\,e^{j\omega t} \]

    其中 \(H(\omega)\) 是「特征值」（在频域里叫频率响应）。

    所以傅里叶变换的本质是「把信号表示为 LTI 特征信号的组合」。 这与「把向量表示为特征向量的组合」是同一件事。

    二、系统：什么是系统¶

    定义：系统是把输入信号映射为输出信号的变换

    \[ y = T\{x\} \]

    按性质分类，最重要的两类是线性与时不变。

    线性¶

    \[ T\{a x_1 + b x_2\} = a\,T\{x_1\} + b\,T\{x_2\} \]

    即上一模块讲的线性映射，包含：

    • 可加性：\(T\{x_1+x_2\} = T\{x_1\}+T\{x_2\}\)
    • 齐次性：\(T\{ax\} = aT\{x\}\)

    时不变¶

    若 \(y(t) = T\{x(t)\}\)，则对任意时移 \(t_0\)

    \[ T\{x(t-t_0)\} = y(t-t_0) \]

    含义：系统的行为不随时间改变。今天输入一个信号，和明天输入同样的信号， 输出波形一样（只是时间上整体平移）。

    为什么 LTI 这么重要¶

    LTI = 线性 + 时不变，这是本课程只讨论 LTI 系统的原因：

    性质 带来的好处
    线性 可以叠加：把复杂输入拆成简单输入，分别算再相加
    时不变 系统的「指纹」不随时间变化，可以完整刻画
    两者结合 系统完全由冲激响应 \(h(t)\) 决定

    LTI 系统的完整刻画

    一个重要结论：只要知道 LTI 系统对单位冲激的响应 \(h(t)\)， 就知道它对任何输入的响应。

    推导思路：

    1. 任何信号可写成冲激的叠加（连续是积分，离散是求和）
    2. 由线性，响应 = 各冲激响应的叠加
    3. 由时不变，冲激延迟 \(t_0\) 的响应就是 \(h\) 延迟 \(t_0\)

    合起来就得到卷积：

    \[ y(t) = \int_{-\infty}^{\infty} h(\tau)x(t-\tau)\,\mathrm{d}\tau \]

    这就是下一页的主题。

    三、系统的几个重要性质¶

    因果性¶

    定义：系统因果（causal）当且仅当输出不依赖未来的输入。

    对 LTI 系统，等价条件是

    \[ h(t) = 0 \quad \text{for } t < 0 \]

    物理意义：现实系统都是因果的（不能预知未来）。但离线处理可以「非因果」—— 比如对已录好的音频做处理，可以用到未来的样本。

    稳定性（BIBO 稳定）¶

    定义：有界输入产生有界输出（Bounded-Input Bounded-Output）。

    对 LTI 系统的判据：

    \[ \int_{-\infty}^{\infty}\lvert h(t)\rvert\,\mathrm{d}t < \infty \qquad\left(\text{离散：}\sum_n \lvert h[n]\rvert < \infty\right) \]

    即冲激响应绝对可积（可和）。

    记忆性¶

    类型 定义 例子
    无记忆 输出只依赖当前输入 \(y(t) = 2x(t)\)
    有记忆 输出依赖过去（或未来）输入 \(y(t) = x(t) + x(t-1)\)、积分器

    四、典型例题¶

    例题 1：判断系统的性质¶

    判断下列系统是否线性、时不变：

    (a) \(y(t) = 3x(t) + 2\)

    (b) \(y(t) = t\,x(t)\)

    © \(y[n] = x[2n]\)

    思路

    线性：分别检验可加性与齐次性（或找一个反例）。 时不变：把 \(x(t-t_0)\) 代入，看输出是否等于 \(y(t-t_0)\)。

    解答

    (a) \(y(t) = 3x(t)+2\)：不是线性，是时不变

    线性：取 \(x_1 = x_2 = 0\)，则 \(y = 2 \neq 0\)。线性系统必须有 \(T\{0\} = 0\)， 而这个系统在零输入时输出 2。不是线性。

    （它是仿射的，即「线性 + 常数偏置」，与神经网络的层同类。）

    时不变：把 \(x(t-t_0)\) 代入得 \(3x(t-t_0)+2 = y(t-t_0)\) ✓ 是时不变。

    (b) \(y(t) = t\,x(t)\)：是线性，不是时不变

    线性：

    \[ T\{ax_1+bx_2\} = t(ax_1+bx_2) = a(tx_1) + b(tx_2) = aT\{x_1\}+bT\{x_2\} \;\checkmark \]

    时不变：代入 \(x(t-t_0)\)：

    \[ T\{x(t-t_0)\} = t\,x(t-t_0) \]

    而

    \[ y(t-t_0) = (t-t_0)x(t-t_0) \]

    两者不等（差 \(t_0x(t-t_0)\)）。不是时不变。

    物理意义：\(t\) 这个系数随时间变化，说明系统的增益在变， 「今天」和「明天」对同一输入的反应不同 —— 正是时变的定义。

    © \(y[n] = x[2n]\)：是线性，不是时不变

    线性：显然（只是抽取样本）

    时不变：代入 \(x[n-n_0]\)：

    \[ T\{x[n-n_0]\} = x[2n-n_0] \]

    而

    \[ y[n-n_0] = x[2(n-n_0)] = x[2n-2n_0] \]

    两者不等（除非 \(n_0 = 0\)）。不是时不变。

    物理意义：\(y[n]=x[2n]\) 是降采样（抽掉一半样本）。 先延迟再抽取，与先抽取再延迟，结果不同 —— 相当于「抽取的时刻」随 \(n_0\) 偏移了。

    两道失时不变的题，原因不同

    系统 失败原因
    \(t\,x(t)\) 增益显式依赖时间
    \(x[2n]\) 时间轴被压缩（抽取会改变时间尺度）

    判据：如果系统对时间轴做了非线性缩放（如 \(t \to 2t\)）或 显式依赖 \(t\)，就很可能不是时不变。

    例题 2：判断因果性与稳定性¶

    已知 LTI 系统的冲激响应如下，判断因果性与 BIBO 稳定性：

    (a) \(h(t) = e^{-2t}u(t)\)

    (b) \(h(t) = e^{2t}u(t)\)

    © \(h[n] = (0.5)^n u[n]\)

    (d) \(h[n] = 2^n u[n]\)

    思路

    因果看 \(h\) 在负时间是否为零；稳定看绝对可积/可和。

    解答

    (a) \(h(t) = e^{-2t}u(t)\)：因果且稳定

    因果：有 \(u(t)\) 因子，所以 \(t<0\) 时 \(h(t)=0\)

    稳定：

    \[ \int_0^{\infty} e^{-2t}\,\mathrm{d}t = \left[-\frac12 e^{-2t}\right]_0^{\infty} = \frac12 < \infty \;\checkmark \]

    (b) \(h(t) = e^{2t}u(t)\)：因果但不稳定

    因果 ✓（同样有 \(u(t)\)）

    稳定：

    \[ \int_0^{\infty} e^{2t}\,\mathrm{d}t = \left[\frac12 e^{2t}\right]_0^{\infty} = \infty \;\times \]

    不稳定（指数增长，积分发散）。

    © \(h[n] = (0.5)^n u[n]\)：因果且稳定

    因果

    稳定（几何级数，公比 0.5 < 1）：

    \[ \sum_{n=0}^{\infty}(0.5)^n = \frac{1}{1-0.5} = 2 < \infty \;\checkmark \]

    (d) \(h[n] = 2^n u[n]\)：因果但不稳定

    因果

    稳定：

    \[ \sum_{n=0}^{\infty}2^n = \infty \;\times \]

    不稳定。

    规律总结

    形式 稳定条件
    \(e^{at}u(t)\) \(a < 0\)（衰减）
    \(a^n u[n]\) \(\lvert a\rvert < 1\)（衰减）

    「极点是否在单位圆（或左半平面）内」 就是从这个绝对可积条件来的—— 这一点在 Z 变换与滤波器部分会重新遇到。 现在的判断很直观：冲激响应衰减 → 稳定；不衰减 → 不稳定。

    例题 3：用线性性质求输出¶

    设 LTI 系统满足 \(T\{\delta(t)\} = h(t) = e^{-t}u(t)\)。 利用线性和时不变性，求输入 \(x(t) = 2\delta(t) + 3\delta(t-1)\) 时的输出。

    思路

    把输入拆成冲激的线性组合，用线性逐项处理，每项用「时不变 + 冲激响应」。

    解答

    输入是两个冲激的线性组合。按 LTI 性质逐项处理：

    第一项 \(2\delta(t)\)：

    由线性（齐次性），

    \[ T\{2\delta(t)\} = 2T\{\delta(t)\} = 2h(t) = 2e^{-t}u(t) \]

    第二项 \(3\delta(t-1)\)：

    先由时不变，\(T\{\delta(t-1)\} = h(t-1)\)；再由齐次性，

    \[ T\{3\delta(t-1)\} = 3h(t-1) = 3e^{-(t-1)}u(t-1) \]

    由可加性，总输出：

    \[ y(t) = 2e^{-t}u(t) + 3e^{-(t-1)}u(t-1) \]

    验证思路：这就是卷积的具体体现。一般地

    \[ x(t) = \sum_k c_k\delta(t-t_k) \implies y(t) = \sum_k c_k h(t-t_k) \]

    把任意输入写成冲激叠加，就得到卷积公式的雏形。

    从离散叠加到连续积分

    注意：本例的输出可以视为「输入是离散冲激和」时的卷积结果。 下一页会把「连续叠加」推广为积分，得到完整的卷积定义。

    例题 4：判断系统的线性与时不变性（含积分器）¶

    判断系统 \(y(t) = \int_{-\infty}^{t} x(\tau)\,\mathrm{d}\tau\)（积分器）的性质。

    思路

    积分是线性运算（回顾微积分模块）；时不变性需验证「先积分后平移」是否等于「先平移后积分」。

    解答

    线性：是。

    由积分的线性性：

    \[ \int_{-\infty}^{t}(ax_1+bx_2)\,\mathrm{d}\tau = a\int_{-\infty}^{t}x_1\,\mathrm{d}\tau + b\int_{-\infty}^{t}x_2\,\mathrm{d}\tau \;\checkmark \]

    （这与「求导是线性映射」是同一件事——积分是求导的逆运算。）

    时不变：是。

    设 \(y(t) = \int_{-\infty}^{t}x(\tau)\mathrm{d}\tau\)。对输入 \(x(t-t_0)\)：

    \[ T\{x(\cdot-t_0)\}(t) = \int_{-\infty}^{t}x(\tau-t_0)\,\mathrm{d}\tau \]

    做变量替换 \(\sigma = \tau - t_0\)（则 \(\tau = \sigma+t_0\)， 上限 \(t\) 对应 \(\sigma = t-t_0\)）：

    \[ = \int_{-\infty}^{t-t_0}x(\sigma)\,\mathrm{d}\sigma = y(t-t_0) \;\checkmark \]

    所以积分器是 LTI 系统。

    冲激响应：取 \(x = \delta\)：

    \[ h(t) = \int_{-\infty}^{t}\delta(\tau)\,\mathrm{d}\tau = u(t) \]

    （因为 \(\delta\) 在 \(t=0\) 处集中，积分到 \(t\) 时，若 \(t \geq 0\) 则面积为 1，否则为 0。）

    因果且不稳定：

    • 因果：\(h(t) = u(t)\) 在 \(t<0\) 为 0
    • 稳定性：
    \[ \int_{-\infty}^{\infty}\lvert u(t)\rvert\,\mathrm{d}t = \int_0^\infty \mathrm{d}t = \infty \;\times \]

    不稳定。

    物理意义：积分器一旦输入有非零直流分量，输出会线性增长到无穷。 这与「阶跃响应是斜坡」一致。

    积分器与微分器的对照

    系统 冲激响应 因果 稳定
    积分器 \(u(t)\) 是 否（面积无限）
    微分器 \(\delta'(t)\)（冲激的导数） 是 否

    两者都是 LTI，都不稳定。这在滤波器设计中很重要： 理想积分器/微分器物理上不可实现，只能用近似。

    六、自测¶

    Q1 判断：\(y[n] = x[n] + x[n-1]\) 是否线性、时不变、因果。

    提示

    逐项检验；因果性看输出是否用到未来的 \(x\)。

    解答

    线性：是。

    容易验证（加减法保持线性）。

    时不变：是。

    对输入 \(x[n-n_0]\)：

    \[ T\{x[\cdot-n_0]\}[n] = x[n-n_0] + x[n-1-n_0] \]

    而

    \[ y[n-n_0] = x[n-n_0] + x[(n-n_0)-1] = x[n-n_0]+x[n-n_0-1] \]

    两者相同

    因果：是。 输出只用到 \(x[n]\)（当前）与 \(x[n-1]\)（过去），不涉及未来。

    冲激响应：\(h[n] = \delta[n]+\delta[n-1] = \{1, 1\}\)。

    稳定性：

    \[ \sum_n \lvert h[n]\rvert = 1+1 = 2 < \infty \;\checkmark \]

    稳定。这是一个最简单的两抽头滤波器（一阶 FIR）。

    Q2 判断：\(y[n] = x[n+2]\) 是否因果？

    提示

    输出是否用到了「未来」的输入？

    解答

    不因果。

    输出 \(y[n]\) 依赖 \(x[n+2]\) —— 即将来 2 步之后的输入。

    在实时系统中这无法实现（还没有采集到那个样本）。

    用途：在离线处理中这种「非因果」操作是允许且有用的， 比如音频后期的「前瞻压缩」（look-ahead compression） 需要提前知道后续样本才能决定当前增益。

    注意：\(y[n]=x[n+2]\) 仍然线性且时不变， 只是不因果。三个性质是独立的。

    Q3 设 LTI 系统冲激响应 \(h[n] = \delta[n] - \delta[n-1]\)。判断稳定性并解释其功能。

    提示

    算绝对和；再想想这个系统对信号做了什么。

    解答

    稳定性：

    \[ \sum_n\lvert h[n]\rvert = \lvert1\rvert + \lvert-1\rvert = 2 < \infty \;\checkmark \]

    稳定。

    功能：一阶差分（高通效果）

    求输出（直接用卷积，或注意冲激响应就是系统对 \(\delta\) 的响应）：

    \[ y[n] = x[n] - x[n-1] \]

    这是离散一阶差分，近似求导。

    为什么有高通效果：对低频（变化缓慢）的信号， \(x[n] \approx x[n-1]\)，差分接近 0； 对高频（变化剧烈）的信号，差分较大。

    所以它保留快速变化、抑制缓慢变化 —— 高通滤波。

    验证：输入常数 \(x[n]=1\)，输出 \(y[n] = 1-1 = 0\) ✓ （直流被完全抑制。）

    Q4 举一个「线性但时变」和「非线性但时不变」的系统各一个。

    提示

    前者可用时间显式出现在表达式中；后者可用常数偏置。

    解答

    线性但时变：

    \[ y(t) = t\,x(t) \]
    • 线性：已验证
    • 时变：不同时刻增益不同（已验证 ✗）

    另一个例子：\(y[n] = x[2n]\)（降采样，也是时变）。

    非线性但时不变：

    \[ y(t) = x(t)^2 \]
    • 非线性：检验齐次性，取 \(a = 2\)：
    \[ T\{2x\} = (2x)^2 = 4x^2 \neq 2x^2 = 2T\{x\} \;\times \]
    • 时不变：\(T\{x(t-t_0)\} = x(t-t_0)^2 = y(t-t_0)\)

    另一类常见例子：\(y(t) = \lvert x(t)\rvert\)（整流器）、 \(y(t) = \max(x(t), 0)\)（半波整流）都是非线性但时不变。

    重要启示：线性与时不变是两个独立的性质， 共有 4 种组合，只有同时具备两者的系统（LTI）才有卷积表示。
