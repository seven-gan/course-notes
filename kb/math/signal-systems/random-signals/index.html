    随机信号基础¶

    前面处理的信号都是确定的：给一个时刻，能算出确切的值。

    但工程中的信号大多含随机成分：噪声、干扰、目标回波。

    随机信号不能用「某个时刻的值」描述，只能用「统计特性」描述。

    这一页建立描述随机信号的工具：均值、自相关、功率谱密度。 它们是维纳滤波、卡尔曼滤波、谱估计的直接基础。

    为什么必须学这个

    现代数字信号处理的课程大纲里，「随机过程和统计估计」紧跟在 「信号分析基础」之后。原因很简单：

    后续内容 依赖这里的工具
    维纳滤波 自相关函数、功率谱密度
    卡尔曼滤波 随机过程的状态空间模型
    谱估计 功率谱的定义与估计方法
    自适应滤波 相关矩阵、均方误差
    检测与估计 统计假设检验

    跳过这一节，后面的「最优滤波」就只能背公式。

    一、随机过程：从一个随机变量到一族随机变量¶

    定义：随机过程是随时间变化的随机变量族 \(\{X(t), t \in T\}\)。

    理解的关键是两个视角：

    视角 固定什么 看到什么
    一个样本 固定「实验结果」 一条具体的波形（样本函数）
    一个时刻 固定 \(t\) 一个随机变量 \(X(t)\)

    用抛硬币的类比

    投掷一枚硬币 1000 次，每次记录正反（1 或 -1），得到一个序列。

    • 固定「第 5 次实验」 → 看第 5 次投掷的结果 → 是一个随机变量
    • 固定「第 300 次抛掷」 → 看第 300 个数据点 → 也是一个随机变量

    随机过程 = 无穷多个这样的函数「捆在一起」。

    实际工作中我们通常只观测到一条样本函数（一次实验的完整记录）， 但用集合平均（对无穷多条样本求平均）来定义统计量。

    关键假设（遍历性，ergodicity）：如果过程遍历， 则「时间平均 = 集合平均」。 这才使得「从单次观测估计统计量」成为可能—— 这是所有实际信号处理的立足点。

    二、一阶与二阶统计量¶

    均值（一阶矩）¶

    \[ \mu_X(t) = E[X(t)] = \int x\,f_X(x;t)\,\mathrm{d}x \]

    含义：随机过程的「平均趋势」（直流分量）。

    自相关函数（二阶矩，核心工具）¶

    \[ \boxed{\ R_{XX}(t_1,t_2) = E\left[X(t_1)X(t_2)\right]\ } \]

    含义：描述「不同时刻的取值有多相关」。

    性质：

    性质 表达式 说明
    对称 \(R_{XX}(t_1,t_2) = R_{XX}(t_2,t_1)\) 交换无关
    原点最大 \(\lvert R_{XX}(t_1,t_2)\rvert \leq \sqrt{R_{XX}(t_1,t_1)R_{XX}(t_2,t_2)}\) 柯西-施瓦茨
    对角即功率 \(R_{XX}(t,t) = E[X^2(t)]\) 均方值

    自协方差¶

    \[ C_{XX}(t_1,t_2) = R_{XX}(t_1,t_2) - \mu_X(t_1)\mu_X(t_2) \]

    作用：去掉均值影响后的「纯波动相关性」。

    \[ C_{XX}(t,t) = \operatorname{Var}[X(t)] \qquad\text{（方差）} \]

    三、平稳性：让分析可行的关键假设¶

    严格平稳：所有阶统计量都不随时间平移改变。

    宽平稳（WSS，weakly stationary）——实用中只要求这个：

    \[ \begin{aligned} \mu_X(t) &= \mu_X \quad&\text{（均值恒定）}\\ R_{XX}(t_1,t_2) &= R_{XX}(\tau), \quad \tau = t_1-t_2 \quad&\text{（只依赖时间差）} \end{aligned} \]

    宽平稳为什么这么有用

    因为它把「二元函数 \(R(t_1,t_2)\)」降成一元函数 \(R(\tau)\)。

    性质 宽平稳下的形式
    自相关 \(R_{XX}(\tau)\)（只与时间差有关）
    均方值 \(R_{XX}(0) = E[X^2]\)
    对称 \(R_{XX}(-\tau) = R_{XX}(\tau)\)（实过程）

    物理含义：过程的「统计规律」不随时间变化—— 今天测和明天测，相关特性一样。

    这是能从一次观测估计统计量的前提（配合遍历性）。

    自相关函数的典型形状¶

    四、功率谱密度：频域的随机信号描述¶

    随机信号没有明确的傅里叶变换（它是随机的）， 所以用功率谱密度（PSD）描述其频域分布。

    定义（维纳-辛钦定理）：

    \[ \boxed{\ S_{XX}(\omega) = \int_{-\infty}^{\infty} R_{XX}(\tau)e^{-j\omega\tau}\,\mathrm{d}\tau\ } \]

    即：功率谱密度是自相关函数的傅里叶变换。

    逆变换：

    \[ R_{XX}(\tau) = \frac{1}{2\pi}\int_{-\infty}^{\infty}S_{XX}(\omega)e^{j\omega\tau}\,\mathrm{d}\omega \]

    为什么「自相关的变换」就是功率谱

    物理理解：

    时域 频域
    自相关是「信号与自身延迟后的相似度」 相似度谱 → 能量/功率分布

    对确定性信号的能量谱：\(S = \lvert X(\omega)\rvert^2\)（由卷积定理可得）。 对随机信号，\(\lvert X\rvert^2\) 是随机量，需要取期望， 于是变成「自相关的傅里叶变换」。

    这个定理是谱估计的理论基础——它告诉我们 「估计功率谱」等价于「估计自相关再变换」。

    重要性质¶

    性质 表达式 说明
    非负 \(S_{XX}(\omega) \geq 0\) 功率不能为负
    偶函数 \(S_{XX}(-\omega) = S_{XX}(\omega)\) 实过程
    总功率 \(\dfrac{1}{2\pi}\displaystyle\int S_{XX}\mathrm{d}\omega = R_{XX}(0)\) 积分即均方值
    白噪声 \(S_{XX}(\omega) = \sigma^2\)（常数） 全频段等功率

    「白噪声」名字的由来

    白光含所有可见光频率且强度均匀。 白噪声的功率谱在所有频率上平坦 —— 名字由此而来。

    但有一点必须注意：真正的白噪声有无限功率：

    \[ \frac{1}{2\pi}\int_{-\infty}^{\infty}\sigma^2\,\mathrm{d}\omega = \infty \]

    所以白噪声是数学理想化，物理上不存在。 实际信号总在某个频率之上衰减（物理系统有带宽限制）。

    工程上常用的近似：

    术语 含义
    白噪声 在关注频带内平坦
    带限白噪声 在 \(\pm B\) 内平坦，之外为零
    有色噪声 谱不平坦（如 \(1/f\) 噪声）

    为什么还要用白噪声：它数学上最简单， 而且对窄带系统，只要噪声带宽远大于系统带宽，模型就足够准确。

    通过 LTI 系统的功率谱¶

    重要结论：若输入 \(X\) 的功率谱为 \(S_{XX}(\omega)\)，通过频率响应 \(H(\omega)\) 的 LTI 系统，则输出功率谱

    \[ \boxed{\ S_{YY}(\omega) = \lvert H(\omega)\rvert^2\,S_{XX}(\omega)\ } \]

    注意是「幅度的平方」（因为功率谱是功率量，不是幅度量）。

    五、典型例题¶

    例题 1：由自相关求功率谱¶

    设宽平稳随机过程的自相关函数为

    \[ R_{XX}(\tau) = \sigma^2 e^{-a\lvert\tau\rvert}, \qquad a > 0 \]

    求功率谱密度。

    思路

    做傅里叶变换。由于 \(R\) 是偶函数，可以只算 \(\tau \geq 0\) 再乘 2。

    解答
    \[ S_{XX}(\omega) = \int_{-\infty}^{\infty}\sigma^2 e^{-a\lvert\tau\rvert}e^{-j\omega\tau}\,\mathrm{d}\tau \]

    利用偶函数性质，把积分拆成两半（\(\tau<0\) 与 \(\tau>0\)）：

    \[ = \sigma^2\left[\int_{-\infty}^{0}e^{a\tau}e^{-j\omega\tau}\,\mathrm{d}\tau + \int_{0}^{\infty}e^{-a\tau}e^{-j\omega\tau}\,\mathrm{d}\tau\right] \]

    第一项：

    \[ \int_{-\infty}^{0}e^{(a-j\omega)\tau}\,\mathrm{d}\tau = \frac{1}{a-j\omega} \]

    第二项：

    \[ \int_{0}^{\infty}e^{-(a+j\omega)\tau}\,\mathrm{d}\tau = \frac{1}{a+j\omega} \]

    相加：

    \[ S_{XX}(\omega) = \sigma^2\left[\frac{1}{a-j\omega}+\frac{1}{a+j\omega}\right] = \sigma^2\cdot\frac{2a}{a^2+\omega^2} \]

    结果：

    \[ \boxed{\ S_{XX}(\omega) = \frac{2a\sigma^2}{a^2+\omega^2}\ } \]

    特征分析：

    \(\omega\) \(S_{XX}\) 说明
    \(0\) \(2\sigma^2/a\) 最大（低频占主导）
    \(\pm a\) \(\sigma^2/a\) 降到一半（\(-\)3 dB 点）
    \(\to\infty\) \(\to 0\) 高频快速衰减

    物理含义：这是一个低通型随机过程（一阶马尔可夫过程）， 常见于：

    • 热噪声经 RC 电路后的输出
    • 随机游走的增量（Ornstein-Uhlenbeck 过程）
    • 慢变随机漂移（陀螺仪零偏、传感器漂移）

    相关时间：\(\tau_c = 1/a\)。\(a\) 越小，相关时间越长，谱越窄。 这与「时间-带宽不确定性」一致。

    例题 2：白噪声通过低通滤波器¶

    白噪声 \(S_{XX}(\omega) = N_0/2\)（双边谱）通过理想低通滤波器

    \[ H(\omega) = \begin{cases}1, & \lvert\omega\rvert \leq \omega_c\\ 0, & \text{其它}\end{cases} \]

    (a) 求输出功率谱。

    (b) 求输出总功率。

    © 输出自相关函数是什么形状？

    提示

    \(S_{YY} = \lvert H\rvert^2 S_{XX}\)；总功率对 \(S_{YY}\) 积分。

    解答

    (a) 输出功率谱

    \[ S_{YY}(\omega) = \lvert H(\omega)\rvert^2\cdot\frac{N_0}{2} = \begin{cases}\dfrac{N_0}{2}, & \lvert\omega\rvert \leq \omega_c\\[4pt] 0, & \text{其它}\end{cases} \]

    白噪声被「切」成带限白噪声（矩形谱）。

    (b) 输出总功率

    \[ P = \frac{1}{2\pi}\int_{-\omega_c}^{\omega_c}\frac{N_0}{2}\,\mathrm{d}\omega = \frac{1}{2\pi}\cdot\frac{N_0}{2}\cdot2\omega_c = \frac{N_0\omega_c}{2\pi} \]

    关键观察：输出功率正比于带宽 \(\omega_c\)。

    这解释了「滤波器越宽，噪声越大」： 带宽加倍，噪声功率加倍（+3 dB）。

    © 输出自相关

    对矩形谱做逆变换，得到 sinc 函数：

    \[ R_{YY}(\tau) = \frac{N_0\omega_c}{2\pi}\cdot\frac{\sin(\omega_c\tau)}{\omega_c\tau} \]

    （这正是「矩形 ↔ sinc」变换对的又一次应用。）

    零点位置：\(\tau = k\pi/\omega_c\)（\(k\) 为非零整数）。 即相隔 \(\pi/\omega_c\) 的采样点不相关。

    实用推论：按奈奎斯特率采样带限白噪声，得到「离散白噪声」

    推导：带限白噪声的自相关零点在

    \[ \tau = \frac{\pi}{\omega_c} = \frac{1}{2f_c} \]

    若以奈奎斯特率 \(T_s = 1/(2f_c)\) 采样，则相邻采样点恰好落在零点上：

    \[ R_{YY}(kT_s) = 0 \quad (k \neq 0) \]

    所以采样后的序列是不相关的 —— 这是「离散白噪声」的来源。

    工程含义：

    结论 用途
    带限白噪声按奈奎斯特采样 → 不相关 理论分析的简化假设
    不相关 ≠ 独立 只有高斯过程才等价

    注意：不相关只是「二阶不相关」，对非高斯过程， 不相关不蕴含独立。这在检测理论里是个陷阱。

    例题 3：信噪比的改善¶

    信号带宽 \(B_s = 1\) kHz，白噪声功率谱 \(S_{XX} = N_0/2\)。 用一个带宽 \(B_n\) 的理想低通滤波器滤除噪声。

    (a) 若信号功率为 \(P_s\)，求滤波后的信噪比。

    (b) 若滤波器带宽刚好 \(B_n = B_s\)，SNR 是多少？

    © 若带宽变为 \(2B_s\)，SNR 变化多少？

    思路

    滤波后信号功率不变（信号在带内），噪声功率正比于带宽。

    解答

    (a) 滤波后 SNR

    信号（在带内，不受影响）：

    \[ P_s \quad\text{（不变）} \]

    噪声（正比于带宽）：

    \[ P_n = \frac{N_0}{2}\cdot2B_n\cdot\frac{1}{2\pi}\cdot 2\pi = N_0 B_n \]

    （用频率 \(f\) 表示更直接：噪声功率 \(= N_0B_n\)，其中 \(N_0\) 是单边谱密度。）

    \[ \text{SNR} = \frac{P_s}{N_0B_n} \]

    结论：SNR 与滤波器带宽成反比。

    (b) 取 \(B_n = B_s\) 时

    \[ \text{SNR}_{\text{opt}} = \frac{P_s}{N_0B_s} \]

    这是「匹配信号带宽」时的最优 SNR（对白噪声而言）。

    © 带宽加倍时

    \[ \text{SNR}_{\text{new}} = \frac{P_s}{2N_0B_s} = \frac{\text{SNR}_{\text{opt}}}{2} \]

    下降 3 dB。

    「滤波器带宽越窄越好」——但有个前提

    前提：信号必须完整落在滤波器通带内。

    若带宽窄到切掉信号本身的成分，则信号功率也下降：

    带宽 信号 噪声 SNR
    \(B_n \gg B_s\) 完整 大 差
    \(B_n = B_s\) 完整 中 最优
    \(B_n < B_s\) 被削 小 反而变差

    所以存在最优点：滤波器带宽应匹配信号带宽。

    这就是「匹配滤波」思想的第一步（严格的最优匹配滤波还要考虑 加权形状，使输出 SNR 最大）。

    实践含义：滤波器带宽设为信号带宽的 1–1.5 倍通常较好 （略微留余量以避免削掉信号边缘）。

    例题 4：相关与独立的区别¶

    设 \(X\) 是零均值随机变量，\(Y = X^2\)。

    (a) 求 \(X\) 与 \(Y\) 的相关系数。

    (b) \(X\) 与 \(Y\) 相关吗？独立吗？

    提示

    算协方差 \(E[XY] - E[X]E[Y]\)，注意 \(E[X]=0\)。

    解答

    (a) 求协方差

    \[ E[XY] = E[X\cdot X^2] = E[X^3] \]

    对对称分布（如均匀分布 \([-1,1]\) 或高斯）的零均值随机变量， \(E[X^3] = 0\)（三阶矩为零，因为奇函数在对称分布下积分为零）。

    所以

    \[ \operatorname{Cov}(X,Y) = E[XY] - E[X]E[Y] = 0 - 0 = 0 \]

    相关系数为 0（不相关）。

    (b) 相关性与独立性

    不相关，但显然不独立 —— 因为 \(Y\) 完全由 \(X\) 决定 （知道 \(X\) 就知道了 \(Y\)）。

    结论：

    关系 是否成立
    不相关 ✓（协方差为 0）
    独立 ✗（\(Y\) 是 \(X\) 的函数）

    这与「\(X\) 的符号被丢失」是一致的： \(X\) 与 \(-X\) 给出同一个 \(Y\)，所以 \(Y\) 对 \(X\) 的线性信息为零， 但非线性信息（幅度）完整保留。

    这是信号处理里最重要的警示之一

    「不相关」≠「独立」。

    只有高斯过程是例外：

    情形 结论
    联合高斯 不相关 ⟺ 独立 ✓
    一般分布 不相关 ⇏ 独立 ✗

    工程后果：

    场景 风险
    用「不相关」假设替代「独立」 对非高斯信号（如通信调制信号）可能出错
    二阶统计量（相关、功率谱） 只能刻画线性关系，看不到非线性相关
    需要非线性分析时 要用高阶累积量（高阶谱）

    具体例子：某些通信信号（如 BPSK）在二阶统计上是「白的」， 需要用高阶累积量才能检测出来。 这正是课程大纲里「高阶谱估计方法」的存在理由。

    六、用在哪些课程里¶

    现代数字信号处理 · 后续全部内容的基础¶

    后续内容 用到的工具
    维纳滤波 自相关函数、互相关、功率谱（频域最优解）
    卡尔曼滤波 随机过程的状态空间模型、白噪声驱动
    谱估计 功率谱的定义与估计（周期图、AR 模型、子空间）
    自适应滤波 相关矩阵 \(R = E[\boldsymbol{x}\boldsymbol{x}^H]\)、均方误差
    检测与估计 统计假设检验、似然比
    高阶谱 累积量（针对非高斯、非线性）

    为什么相关矩阵这么重要

    自适应滤波与阵列处理的核心数学对象是相关矩阵

    \[ R = E\left[\boldsymbol{x}\boldsymbol{x}^H\right] \]

    它是一个埃尔米特（共轭对称）矩阵，因此：

    性质 后果
    共轭对称 特征值全为实数
    半正定 可做特征分解（回到线性代数模块的谱定理）
    结构特殊 可用快速算法求解（如 Levinson-Durbin）

    所以「随机信号分析」与「线性代数」在这里汇合：

    线性代数概念 随机信号中的对应
    内积 相关 \(E[xy^*]\)
    正交 不相关
    正交投影 最优线性估计（维纳滤波）
    特征分解 子空间方法（MUSIC）

    这就是为什么本知识库把线性代数放在基础层： DSP 的进阶内容几乎全建立在特征分解与投影之上。

    智能传感与信息处理 · 状态估计与降噪¶

    • 卡尔曼滤波：以白噪声驱动的状态空间模型，最优贝叶斯估计
    • 噪声建模：区分白噪声、\(1/f\) 噪声、量化噪声
    • 信号检测：判断「有没有目标」需要统计检验
    • 传感器漂移：用随机游走模型（自相关为 \(e^{-a\lvert\tau\rvert}\)）描述
    • 多传感器融合：用互相关分析确定各传感器的相关性

    海洋声学 · 噪声环境下的信号检测¶

    • 海洋环境噪声：宽带但非白（低频更强），需谱建模
    • 匹配场处理：在噪声背景下检测目标，依赖噪声的空间相关特性
    • 声纳方程：其中的「噪声级」就是噪声功率谱的积分
    • 线谱检测：用自相关/功率谱从噪声中提取周期性成分（舰船特征）

    七、自测¶

    Q1 判断：若两个随机变量的相关系数为 0，它们一定独立。

    提示

    回忆例题 4 的 \(Y = X^2\) 反例。

    解答

    不一定。

    反例：\(X\) 是零均值对称分布（如均匀分布 \([-1,1]\)），\(Y = X^2\)。

    • \(\operatorname{Cov}(X,Y) = E[X^3] = 0\) → 不相关
    • 但 \(Y\) 完全由 \(X\) 决定 → 不独立 ✗

    正确的说法：

    条件 结论
    独立 ⟹ 不相关（一定）
    不相关 ⇏ 独立（一般）
    联合高斯 不相关 ⟺ 独立

    记忆口诀：「独立更强，高斯下等价」。

    工程影响：许多算法（如卡尔曼滤波在某些推导中）依赖高斯假设， 此时「不相关即独立」才成立。对非高斯信号要谨慎。

    Q2 设 \(R_{XX}(\tau) = 10e^{-3\lvert\tau\rvert}\)。求均方值与总功率。

    提示

    均方值 \(= R_{XX}(0)\)；总功率等于均方值（零均值时即方差）。

    解答

    均方值：

    \[ E[X^2] = R_{XX}(0) = 10e^{0} = 10 \]

    总功率：对零均值过程，\(E[X^2]\) 就是总功率（方差）。

    \[ P = 10 \]

    验证（用频域）：先求功率谱，再积分。

    由例题 1 的公式（\(a = 3\)，\(\sigma^2 = 10\)）：

    \[ S_{XX}(\omega) = \frac{2\cdot3\cdot10}{9+\omega^2} = \frac{60}{9+\omega^2} \]

    积分：

    \[ P = \frac{1}{2\pi}\int_{-\infty}^{\infty}\frac{60}{9+\omega^2}\mathrm{d}\omega = \frac{60}{2\pi}\cdot\frac{\pi}{3} = 10 \;\checkmark \]

    （用到标准积分）

    \[ \int_{-\infty}^{\infty}\frac{\mathrm{d}\omega}{a^2+\omega^2} = \frac{\pi}{a} \]

    两种方法一致 ✓ 这验证了「\(R(0)\) = 总功率 = 谱的积分」。

    Q3 白噪声通过一个增益为 2、带宽为 100 Hz 的理想低通滤波器。 若白噪声双边谱密度为 \(N_0/2 = 10^{-6}\) W/Hz，求输出功率。

    提示

    \(S_{YY} = \lvert H\rvert^2 S_{XX}\)，注意增益要平方。

    解答

    输出谱密度：

    \[ S_{YY} = \lvert H(\omega)\rvert^2\cdot S_{XX} = 2^2\times10^{-6} = 4\times10^{-6}\ \text{W/Hz} \]

    输出功率（对单边频带 \(B = 100\) Hz 积分）：

    \[ P = S_{YY}\times B = 4\times10^{-6}\times100 = 4\times10^{-4}\ \text{W} \]

    注意两个关键点：

    要点 说明
    增益要平方 \(S_{YY} = \lvert H\rvert^2S_{XX}\)，不是 \(\lvert H\rvert S_{XX}\)
    功率与带宽成正比 带宽 10 倍 → 功率 10 倍

    常见错误：把增益直接乘（\(2\times10^{-6}\times100 = 2\times10^{-4}\)）—— 这是把功率谱当成了幅度谱，错了 4 倍。

    为什么必须平方：功率谱描述的是功率量， 而 \(H\) 描述的是幅度变换。功率正比于幅度的平方。

    Q4 为什么说「二阶统计量只能刻画线性关系」？

    提示

    想想自相关函数用的是什么运算。

    解答

    自相关的定义只用到二阶乘积：

    \[ R_{XX}(\tau) = E[X(t)X(t+\tau)] \]

    它是 \(X\) 的二次函数（乘积），所以：

    能捕捉 不能捕捉
    线性相关（乘性关系） 非线性相关（如平方、相位、符号）
    幅度信息的均方特性 相位耦合（如二次相位耦合）
    高斯过程的全部信息 非高斯过程的完整结构

    具体例子（相位信息丢失）：

    对 \(X(t) = \cos(\omega_0t+\Theta)\)（\(\Theta\) 均匀随机相位）， 其自相关为

    \[ R_{XX}(\tau) = \frac12\cos(\omega_0\tau) \]

    相位 \(\Theta\) 完全消失了 —— 自相关（从而功率谱）不含相位信息。

    这解释了两个重要事实：

    事实 说明
    功率谱不含相位 只有幅度信息（相位在下页「谱估计」里很关键）
    BPSK 等信号「谱上是白的」 因为其非线性结构在二阶统计中不可见

    需要非线性分析时用什么：

    工具 用途
    三阶累积量 / 双谱 检测二次相位耦合、高斯噪声抑制
    四阶累积量 / 三谱 检测更高阶耦合
    优点 高斯噪声的高阶累积量为零 → 天然抗高斯噪声

    这正是课程大纲中「高阶谱估计方法在非高斯信号检测和非线性系统辨识 等方面的应用」的理论基础。
