    采样定理与混叠¶

    前面几页都在处理连续信号。但实际系统（计算机、DSP 芯片）只能处理离散数据。

    这一页回答一个关键问题：

    以多快的速度采样，才能不丢失信息？

    答案是奈奎斯特采样定理：

    \[ \boxed{\ f_s > 2f_{\max}\ } \]

    即采样频率必须大于信号最高频率的 2 倍。

    这句话看起来简单，但它背后有两个必须理解的机制：频谱周期延拓与混叠。 不理解它们，就无法理解为什么「采样率不够会出错」，以及为什么必须加抗混叠滤波器。

    一、采样的数学模型¶

    理想采样：用周期冲激串乘上连续信号。

    \[ x_s(t) = x(t)\cdot p(t), \qquad p(t) = \sum_{n=-\infty}^{\infty}\delta(t-nT_s) \]

    其中 \(T_s\) 是采样周期，\(f_s = 1/T_s\) 是采样频率。

    采样得到的序列：

    \[ x[n] = x(nT_s) \]

    关键：采样在频域做什么¶

    冲激串 \(p(t)\) 的傅里叶变换还是冲激串（这是一个漂亮的对称性）：

    \[ P(\omega) = \frac{2\pi}{T_s}\sum_{k=-\infty}^{\infty}\delta(\omega - k\omega_s), \qquad \omega_s = \frac{2\pi}{T_s} = 2\pi f_s \]

    时域相乘 = 频域卷积（卷积定理的对偶形式）：

    \[ X_s(\omega) = \frac{1}{2\pi}X(\omega)*P(\omega) \]

    与冲激串卷积的效果是把频谱搬移并叠加：

    \[ \boxed{\ X_s(\omega) = \frac{1}{T_s}\sum_{k=-\infty}^{\infty}X(\omega - k\omega_s)\ } \]

    这个式子是本节的核心

    采样的频域效果：把原频谱以 \(\omega_s\) 为周期复制无穷多份。

    这就是频谱周期延拓。

    为什么这会导致问题：如果原来的频谱「太宽」（超过 \(\omega_s/2\)）， 相邻的副本就会互相重叠——重叠的部分无法再区分， 这就叫混叠。

    二、奈奎斯特定理¶

    定理（奈奎斯特-香农采样定理）：

    若信号 \(x(t)\) 是带限的，即

    \[ X(\omega) = 0 \quad \text{当 } \lvert\omega\rvert > \omega_{\max} = 2\pi f_{\max} \]

    则当采样频率满足

    \[ \boxed{\ f_s > 2f_{\max}\ } \]

    （严格说 \(\geq\)，但等于时要求临界条件，实用上取严格大于）

    时，\(x(t)\) 可以由采样序列 \(x[n]\) 完全恢复。

    恢复方法：理想低通滤波（截止频率 \(f_s/2\)）。

    奈奎斯特频率：\(f_N = f_s/2\)，即可无混叠表示的最高频率。

    奈奎斯特频率是临界情形，实用上要留余量

    理论上 \(f_s = 2f_{\max}\) 就够，但实际中：

    原因 说明
    抗混叠滤波器不理想 实际低通有过渡带，必须留出余量
    信号不是严格带限 真实信号总有噪声与高频成分
    需要保留裕度 通常取 \(f_s = 2.5 \sim 5\) 倍 \(f_{\max}\)

    工程惯例：音频取 44.1 kHz（人耳上限约 20 kHz，约 2.2 倍）； 某些精密测量取 10 倍以上。

    三、混叠：为什么不可恢复¶

    混叠的机制¶

    考虑两个频率：\(f_0\)（真实）与 \(f_s - f_0\)（看起来像的频率）。

    采样后：

    \[ \cos(2\pi f_0 nT_s) \quad\text{与}\quad \cos(2\pi (f_s-f_0)nT_s) \]

    在 \(t = nT_s\) 处取值完全相同（因为 \(\cos(2\pi(f_s-f_0)nT_s) = \cos(2\pi n - 2\pi f_0 nT_s) = \cos(2\pi f_0nT_s)\)）。

    所以采样数据无法区分它们——这就是混叠。

    混叠频率的计算

    若真实频率 \(f_0\) 超过奈奎斯特频率 \(f_N = f_s/2\)，采样后会「折叠」到

    \[ f_{\text{alias}} = \left\lvert f_0 - k f_s\right\rvert \quad\text{取使结果落在 }[0, f_s/2]\text{ 的整数 }k \]

    例：\(f_s = 1000\) Hz，真实频率 \(f_0 = 1300\) Hz。

    \(f_0 > f_N = 500\) Hz，所以混叠。取 \(k=1\)：

    \[ f_{\text{alias}} = \lvert 1300 - 1000\rvert = 300 \text{ Hz} \]

    结果：一个 1300 Hz 的信号，采样后看起来像 300 Hz。

    这是真实工程事故的常见来源：比如旋转机械的振动监测中， 高频振动可能混叠成低频，让人误判故障频率。

    混叠的严重后果

    现象 说明
    不可恢复 混叠后两个频率无法区分，任何后处理都救不回来
    虚假低频 高频信号伪装成低频，误导分析
    拍频 多个混叠分量干涉，产生虚假的缓慢波动

    唯一正确的对策：采样前先滤波（抗混叠滤波器）。 采样之后再处理已经晚了。

    四、抗混叠滤波器¶

    做法：在采样器前面加一个模拟低通滤波器，截止频率设为 \(f_s/2\)。

    \[ x(t) \xrightarrow{\ \text{抗混叠低通}\ } \tilde{x}(t) \xrightarrow{\ \text{采样}\ } x[n] \]

    这样做的理由：

    1. 把高于 \(f_s/2\) 的成分在采样前去掉，避免它们混叠到低频
    2. 代价是损失了高频信息——但这是必须接受的
    3. 比「让高频混叠进来干扰低频」要好得多

    一个实用的类比：转动的车轮

    电影里车轮看起来倒转，就是时间采样（每秒 24 帧）引起的混叠：

    • 真实转速很高（超过「帧率的一半」对应的转速）
    • 采样后看起来转速变慢，甚至反向

    这解释了：

    现象 原因
    车轮正转看起来反转 频率折叠（\(f_0 > f_s/2\)）
    桨叶「停住」 恰好混叠到 0（\(f_0 = f_s\) 的整数倍）

    人眼无法「抗混叠」——因为我们无法在视网膜前加滤波器。 这是采样理论在日常生活中的直观体现。

    五、恢复：为什么低通能重建信号¶

    采样后频谱是周期延拓的（图 1 情形②）。若没有混叠， 则原频谱完整地保留在 \([-\omega_s/2, \omega_s/2]\) 内。

    所以用一个理想低通滤波器（截止 \(\omega_s/2\)）就能取出原频谱：

    \[ X(\omega) = T_s\,X_s(\omega)\cdot \operatorname{rect}\!\left(\frac{\omega}{\omega_s}\right) \]

    对应的时域恢复公式（惠特克-香农插值）：

    \[ x(t) = \sum_{n=-\infty}^{\infty} x[n]\,\operatorname{sinc}\!\left(\frac{t-nT_s}{T_s}\right) \]

    这个公式告诉我们什么

    恢复不是「连线」，而是用 sinc 函数加权叠加：

    做法 是否正确
    线性插值（连线） ✗ 只是近似，不是精确恢复
    零阶保持（阶梯） ✗ 有高频失真
    sinc 插值 ✓ 理论精确恢复

    实用含义：

    • 数字示波器上的「平滑」不是插值，只是视觉美化
    • 音频 DAC 需要重建滤波器（接近 sinc 特性的低通）
    • 高质量重采样（如 44.1k → 48k）需要正确的插值算法

    理想 sinc 插值不可实现

    sinc 函数在时间上无限延伸，且非因果。所以精确恢复需要： - 无限长的数据 - 未来的样本

    实际做法：用有限长、近似 sinc 的滤波器（如升余弦、窗函数法设计）。

    六、典型例题¶

    例题 1：判断是否发生混叠¶

    信号含频率成分 100 Hz、300 Hz、900 Hz。问：

    (a) 采样率 1000 Hz 时是否混叠？混叠频率是多少？

    (b) 采样率 2000 Hz 时呢？

    思路

    奈奎斯特频率 \(f_N = f_s/2\)；超过 \(f_N\) 的成分会折叠。

    解答

    (a) \(f_s = 1000\) Hz

    \(f_N = 500\) Hz。

    真实频率 是否超限 混叠后频率
    100 Hz 否 100 Hz ✓
    300 Hz 否 300 Hz ✓
    900 Hz 是 \(\lvert900-1000\rvert = 100\) Hz ✗

    发生混叠：900 Hz 折叠到 100 Hz。

    严重后果：原本 100 Hz 与 900 Hz 是两个不同成分， 混叠后都显示为 100 Hz，幅度叠加 —— 无法区分。

    (b) \(f_s = 2000\) Hz

    \(f_N = 1000\) Hz。

    三个成分（100、300、900 Hz）都低于 1000 Hz，所以无混叠

    结论：\(f_s = 2000\) Hz 可以无失真表示这三个成分。

    对比：\(f_s\) 从 1000 提高到 2000，混叠问题消失。 这也说明提高采样率可以解决混叠（前提是硬件允许）。

    混叠的「对称」规律

    混叠后的频率关于 \(f_s/2\) 镜像折叠：

    \[ f_{\text{alias}} = \left\lvert f_0 - f_s\right\rvert \quad (\text{当 } f_s/2 < f_0 < f_s) \]

    记忆方法：把频率想象成一张纸，在 \(f_s/2\) 处折一下， 超过的部分就「印」到低频区。

    若 \(f_0 > f_s\)，则反复折叠（取模）。

    例题 2：设计采样系统¶

    要测量频率上限为 5 kHz 的振动信号，要求：

    • 无混叠
    • 抗混叠滤波器是非理想的，过渡带宽度为 1 kHz（即截止后还需要 1 kHz 才衰减到可忽略）

    求最小采样率。

    思路

    关键：抗混叠滤波器的「过渡带」意味着必须在截止频率之上再留余量， 否则过渡带内的频率会混叠。

    解答

    分析：

    信号最高频率 \(f_{\max} = 5\) kHz。

    滤波器在 5 kHz 处开始衰减，但在 6 kHz 之前还未完全衰减 （过渡带宽度 1 kHz）。

    关键约束：采样后，频率 \(f\) 会与 \(\lvert f - f_s\rvert\) 混叠。 要求不低于 5 kHz 的任何频率都不能混叠到 5 kHz 以下。

    最危险的是滤波器过渡带上边缘 \(f = 6\) kHz。要求它的混叠位置仍高于 5 kHz：

    \[ f_s - 6\text{ kHz} \geq 5\text{ kHz} \]

    即

    \[ f_s \geq 11 \text{ kHz} \]

    所以最小采样率约 11 kHz（取 12 kHz 留余量）。

    对比：若滤波器理想（过渡带为零），只需 \(f_s > 10\) kHz。

    结论：

    滤波器 所需 \(f_s\)
    理想（过渡带 0） \(> 2f_{\max} = 10\) kHz
    实际（过渡带 1 kHz） \(> 2f_{\max}+\text{过渡带} = 11\) kHz

    实用的设计公式

    \[ f_s \geq 2\left(f_{\max} + \Delta f_{\text{过渡带}}\right) \]

    或者说：采样率必须高于「滤波器完全衰减点」的 2 倍。

    场景 典型选择
    音频（20 kHz 上限） 44.1 kHz（过渡带约 2 kHz）
    振动监测 常取 \(2.5 \sim 5\) 倍
    精密测量 常取 10 倍以上

    代价权衡：提高 \(f_s\) 会增加数据量与功耗。 所以实际设计要在「采样率」与「滤波器阶数」之间权衡： 滤波器更陡（阶数高）→ 可以降低采样率。

    例题 3：混叠的定量计算¶

    \(f_s = 100\) Hz。真实频率 30 Hz、70 Hz、130 Hz、230 Hz 采样后各显示为多少？

    提示

    对每个频率，反复加/减 \(f_s\) 直到落在 \([0, f_s/2] = [0,50]\) Hz。

    解答

    逐一计算（目标区间 \([0, 50]\) Hz）：

    30 Hz：已在区间内 → 30 Hz

    70 Hz：超过 50 Hz。\(\lvert70-100\rvert = 30\) Hz → 30 Hz（混叠 ✗）

    130 Hz：超过。先减 \(f_s\) 得 30 Hz，在区间内 → 30 Hz（混叠 ✗）

    230 Hz：减 \(2f_s\) 得 \(230-200 = 30\) Hz → 30 Hz（混叠 ✗）

    结果汇总：

    真实频率 混叠后
    30 Hz 30 Hz
    70 Hz 30 Hz
    130 Hz 30 Hz
    230 Hz 30 Hz

    四个完全不同的频率，采样后全部显示为 30 Hz！

    这是混叠最危险的形态：多个频率成分叠加到同一个频点， 幅度相加，频谱上看起来只是一个强峰 —— 完全无法知道真实有几个成分、分别在什么频率。

    规律：混叠频率满足

    \[ f_{\text{alias}} = \left\lvert f_0 \bmod f_s \right\rvert,\quad \text{再折叠到 }[0, f_s/2] \]

    本例中 \(70-100 = -30 \to 30\)；\(130 \bmod 100 = 30\)；\(230 \bmod 100 = 30\)。

    工程教训

    看到频谱上的强峰时，不能断定它就是真实的振动频率。

    正确做法：

    1. 检查采样率与信号带宽
    2. 改变采样率重测：若峰值位置随 \(f_s\) 变化而移动，说明是混叠
    3. 加抗混叠滤波器后重测

    这就是为什么振动监测设备的技术指标里， 抗混叠滤波器的性能与采样率同等重要。

    例题 4：采样定理的边界情形¶

    信号 \(x(t) = \cos(2\pi f_0 t)\)，\(f_0 = 100\) Hz。 用 \(f_s = 200\) Hz 采样（恰好 \(f_s = 2f_0\)）。问采样序列是什么？

    提示

    代入 \(t = nT_s = n/200\)，算 \(\cos(2\pi\cdot100\cdot n/200)\)。

    解答
    \[ x[n] = \cos\left(2\pi\cdot100\cdot\frac{n}{200}\right) = \cos(\pi n) \]

    取值：

    \[ x[n] = \cos(\pi n) = (-1)^n = \{1, -1, 1, -1, \dots\} \]

    结果：采样序列是 \((-1)^n\)，即「最高频」的离散序列。

    这意味着什么：在离散域里，\((-1)^n\) 对应归一化频率 0.5 （即 \(f = f_s/2\)，奈奎斯特频率）。

    问题：\((-1)^n\) 也可以解释为 \(f = -f_s/2\) 的正弦， 两者在采样点上无法区分。

    而且更进一步：若真实频率是 \(\pm100\) Hz， 采样结果都是 \((-1)^n\) —— 符号/相位信息丢失。

    为什么实际要「严格大于」

    临界情形（\(f_s = 2f_{\max}\)）有三个麻烦：

    问题 说明
    相位不确定 \(\cos\) 与 \(-\cos\) 采样结果可能相同
    幅度不确定 采样点可能恰好落在零点上，读出全零
    抗混叠滤波器做不到理想 需要无限陡的截止

    第三种最实际：若滤波器不是理想的矩形， \(f_0\) 附近的成分会部分漏过并混叠，直接污染结果。

    所以工程上取 \(f_s > 2f_{\max}\)，且留出余量。 音频的 44.1 kHz（对 20 kHz 上限留了 2.2 倍）就是例证。

    顺便说明：44.1 kHz 这个「奇怪」的数字来自早期数字录音设备 （PAL 制式的 44.1 = 588 × 75 行扫描频率），是历史沿革而非理论最优。

    七、用在哪些课程里¶

    现代数字信号处理 · 数字化的第一步¶

    采样定理是「模拟到数字」的理论基础，也是后续所有数字处理的前提：

    后续内容 与采样的关系
    DFT / FFT \(N\) 个采样点的频域表示
    频谱分析 频率分辨率 \(= f_s/N\)
    多速率处理 降采样必须重新考虑混叠
    重采样 需插值 + 抗混叠

    数字频率的两种常用记法

    记法 范围 说明
    归一化频率（\(\times\pi\)） \([-\pi, \pi]\) DSP 算法标准
    归一化频率（\(\times f_s\)） \([-0.5, 0.5]\) 工程文档常用
    实际频率 \([-f_s/2, f_s/2]\) 测量报告常用

    换算：\(\omega = 2\pi f/f_s\)。所以 \(\omega = \pi\) 对应 \(f = f_s/2\)（奈奎斯特）。

    智能传感与信息处理 · 传感器与数据采集¶

    • ADC 选型：采样率与位宽共同决定性能
    • 抗混叠滤波是硬件必需：不能靠软件补救
    • 传感器的带宽必须与采样率匹配：
    • 传感器带宽 > 采样率一半 → 必然混叠
    • 若传感器本身是低通的（且截止合适），可省掉抗混叠滤波器
    • 过采样：用远高于需求的采样率，可降低对抗混叠滤波器陡度的要求， 同时通过平均提升有效位数（\(\sigma\)-\(\delta\) ADC 的原理）

    海洋声学 · 声信号的采集¶

    • 水下声信号带宽：常见工作频段几 Hz 到几百 kHz
    • 采样率选择：需覆盖最高工作频率的 2 倍以上
    • 混叠的特殊风险：海洋噪声宽带且强， 若不滤除，高频噪声会混叠进低频信号频段，严重降低检测性能

    八、自测¶

    Q1 判断：若信号带宽为 4 kHz，用 8 kHz 采样能否无失真恢复？

    提示

    注意「等于」是临界情形。

    解答

    理论上可以，实践上不建议。

    \(f_s = 8\) kHz，\(f_N = 4\) kHz，恰好等于信号带宽上限。

    理论：临界采样定理要求 \(f_s \geq 2f_{\max}\)，所以理论上满足。

    实践问题：

    问题 后果
    抗混叠滤波器非理想 4 kHz 附近的成分泄露，混叠进来
    4 kHz 处的分量 相位/幅度不确定
    没有余量 任何偏差都会导致混叠

    建议：取 \(f_s = 10 \sim 20\) kHz，留出余量。 工程上通常取 \(2.5 \sim 5\) 倍。

    Q2 某信号以 500 Hz 采样，在频谱上看到 50 Hz 处有一个峰。 真实频率可能是多少？（列举三种）

    提示

    用混叠公式反推：真实频率可能是 \(f_s\) 的整数倍加减 50。

    解答

    混叠到 50 Hz 的真实频率满足

    \[ \lvert f_0 - kf_s\rvert = 50 \quad\text{或}\quad f_0 = kf_s \pm 50 \]

    取不同的 \(k\)（\(f_s = 500\) Hz）：

    \(k\) 可能真实频率
    0 50 Hz
    1 500 − 50 = 450 Hz（500 + 50 = 550 折叠为 50）
    2 1000 − 50 = 950 Hz
    3 1500 − 50 = 1450 Hz

    所以至少三种可能：50 Hz、450 Hz、950 Hz（以及更高）

    如何确定真实值：

    1. 改变采样率：若峰位置随之变化，是混叠；真实频率位置不变
    2. 加抗混叠滤波器：滤掉高频后再测
    3. 提高采样率：直接消除混叠

    这就是「频谱上的峰不一定可信」的原因。

    Q3 为什么不先采样、之后再数字滤波，来去除混叠？

    提示

    想想混叠发生在哪一步。

    解答

    因为混叠发生在「采样那一刻」，之后无法区分。

    具体分析：

    步骤 发生了什么
    真实信号 含 100 Hz 与 900 Hz 两个成分
    以 1000 Hz 采样 900 Hz 折叠到 100 Hz
    采样后的数据 只有一个「100 Hz + 幅度更大的成分」
    数字滤波 无法区分原来的两个成分 —— 它们已经合并了

    关键：混叠是信息丢失，不是「加上噪声」。 丢失的信息不可能通过后处理恢复。

    正确顺序：

    \[ \text{模拟信号} \xrightarrow{\ \text{抗混叠低通}\ } \text{带限信号} \xrightarrow{\ \text{采样}\ } \text{数字序列} \xrightarrow{\ \text{数字滤波}\ } \text{结果} \]

    类比：这就像照片失焦（模拟域混叠）后无法用软件恢复清晰 —— 信息已经在成像时丢失了。

    Q4 什么是「过采样」？它有什么好处？

    提示

    采样率远高于奈奎斯特要求的 2 倍。

    解答

    过采样：取 \(f_s \gg 2f_{\max}\)（远大于奈奎斯特要求）。

    好处一：降低对抗混叠滤波器的要求

    过渡带可以更宽（从 \(f_{\max}\) 到 \(f_s/2\) 之间的空间变大）， 滤波器可以用更低阶实现 —— 成本更低、相位失真更小。

    好处二：提高有效位数（信噪比）

    过采样 + 平均（或低通数字滤波）可以降低量化噪声。 理论上每提高 4 倍采样率可增加 1 位有效位数（6 dB 信噪比）。

    好处三：简化重建滤波器

    DAC 输出端的重建滤波器同样可以用更简单的设计。

    代价：

    代价 说明
    数据量大 需要更快的处理与更多存储
    功耗高 ADC 采样电路功耗随速率上升

    \(\Sigma\)-\(\Delta\)（sigma-delta）ADC 就是过采样的极致应用： 用极低位数（甚至 1 位）配合极高采样率，实现高分辨率。 这是现代音频 ADC 的主流方案。
