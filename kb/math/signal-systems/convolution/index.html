    卷积¶

    上一页留下一个结论：LTI 系统完全由冲激响应 \(h\) 决定。这一页把它写成公式。

    先给结论：

    \[ y(t) = \int_{-\infty}^{\infty} h(\tau)\,x(t-\tau)\,\mathrm{d}\tau \quad\text{（连续）} \]
    \[ y[n] = \sum_{k=-\infty}^{\infty} h[k]\,x[n-k] \quad\text{（离散）} \]

    这就是卷积，记作 \(y = h * x\)。

    卷积为什么长这样（一句话版本的推导）

    任意输入都是冲激的叠加，把这件事写出来就有了卷积：

    第一步：把 \(x(t)\) 写成「无数个冲激的加权和」

    \[ x(t) = \int_{-\infty}^{\infty} x(\tau)\,\delta(t-\tau)\,\mathrm{d}\tau \]

    第二步：由时不变，\(\delta(t-\tau)\) 的响应是 \(h(t-\tau)\)

    第三步：由线性（叠加），加权和输入产生的输出也是加权和

    \[ y(t) = \int_{-\infty}^{\infty} x(\tau)\,h(t-\tau)\,\mathrm{d}\tau \]

    就这三步。 卷积不是需要死记的公式，而是「分解为冲激 + 叠加」的必然结果。

    一、怎么理解卷积¶

    卷积的数学形式容易让人困惑：为什么是 \(x(t-\tau)\) 而不是 \(x(\tau)\)？

    三个操作：翻转、平移、加权求和¶

    固定 \(t\)，看卷积积分在做什么：

    步骤 操作
    1 把 \(h(\tau)\) 翻转成 \(h(-\tau)\)
    2 平移 \(t\)，得到 \(h(t-\tau)\)
    3 与 \(x(\tau)\) 相乘，对 \(\tau\) 求和（积分）

    用一个比喻记住「翻转」的作用

    想象 \(x\) 是一条横放的尺子，\(h\) 是一张透明的模板（已翻转）。

    把模板沿着尺子从左到右滑动，每滑到一个位置，就计算「模板挡住的部分的面积」， 这个面积就是该位置的输出值。

    滑动过程 = 卷积。 所以卷积也叫「滑动加权和」。

    一个关键性质：卷积可交换¶

    \[ h * x = x * h \]

    验证（连续情形）：做变量替换 \(\sigma = t - \tau\)（则 \(\tau = t-\sigma\)，\(\mathrm{d}\tau = -\mathrm{d}\sigma\)）：

    \[ \int_{-\infty}^{\infty} h(\tau)x(t-\tau)\,\mathrm{d}\tau = \int_{\infty}^{-\infty} h(t-\sigma)x(\sigma)(-\mathrm{d}\sigma) = \int_{-\infty}^{\infty} x(\sigma)h(t-\sigma)\,\mathrm{d}\sigma \]

    含义：谁「翻转平移」都行。所以「输入通过滤波器」也可以看成 「滤波器通过输入」。

    二、离散卷积：手算更容易¶

    离散卷积

    \[ y[n] = \sum_{k=-\infty}^{\infty} h[k]\,x[n-k] \]

    手算方法（列表法）：

    1. 列出 \(h[k]\) 与 \(x[k]\) 的取值表
    2. 把 \(x\) 翻转（\(x[-k]\)）
    3. 逐个 \(n\) 平移并计算乘积和

    一个完整的手算例子¶

    设 \(x[n] = \{1, 2, 3\}\)（\(n = 0,1,2\)），\(h[n] = \{1, 1\}\)（\(n=0,1\)）。 求 \(y[n] = x[n]*h[n]\)。

    用列表法：

    \(n\) 计算 \(y[n]\)
    0 \(h[0]x[0] = 1\times1\) 1
    1 \(h[0]x[1] + h[1]x[0] = 1\times2 + 1\times1\) 3
    2 \(h[0]x[2] + h[1]x[1] = 1\times3 + 1\times2\) 5
    3 \(h[1]x[2] = 1\times3\) 3

    结果：\(y[n] = \{1, 3, 5, 3\}\)（\(n=0,1,2,3\)）。

    长度公式（很实用）

    若 \(x\) 的长度为 \(M\)，\(h\) 的长度为 \(N\)，则

    \[ \text{卷积结果长度} = M + N - 1 \]

    这常用于检查卷积结果是否正确。

    三、卷积的性质¶

    性质 表达式 含义
    交换律 \(x*h = h*x\) 谁翻转平移都一样
    结合律 \((x*h_1)*h_2 = x*(h_1*h_2)\) 级联系统可合并
    分配律 \(x*(h_1+h_2) = x*h_1 + x*h_2\) 并联系统可分解
    与冲激卷积 \(x*\delta = x\) 冲激是卷积的「单位元」
    时移 \(x(t)*\delta(t-t_0) = x(t-t_0)\) 与移位冲激卷积 = 平移

    结合律的实际意义：级联系统

    两个 LTI 系统串联，总冲激响应是两者卷积：

    \[ h_{\text{总}} = h_1 * h_2 \]

    这解释了为什么可以把多级滤波器合并成一个。

    同时注意交换律的作用：级联的顺序可以交换（对 LTI 系统而言）。

    卷积与多项式乘法¶

    一个漂亮的对应关系：离散卷积就是多项式乘法。

    设

    \[ X(z) = x[0] + x[1]z + x[2]z^2, \qquad H(z) = h[0] + h[1]z \]

    则乘积的系数正是卷积结果：

    \[ X(z)H(z) = x[0]h[0] + (x[0]h[1]+x[1]h[0])z + (x[1]h[1]+x[2]h[0])z^2 + x[2]h[1]z^3 \]

    对比前面的手算结果 \(\{1,3,5,3\}\) —— 完全一致。

    这个对应关系是 Z 变换的入口

    把 \(z\) 换成 \(z^{-1}\) 并解释为「延迟算子」，就得到 Z 变换。

    于是「时域卷积」变成「变换域乘法」：

    \[ y = x * h \quad\Longleftrightarrow\quad Y(z) = X(z)H(z) \]

    这是信号处理中最重要的一个转换：把麻烦的卷积换成简单的乘法。

    四、典型例题¶

    例题 1：手算离散卷积¶

    设 \(x[n] = \{2, 1\}\)（\(n=0,1\)），\(h[n] = \{1, 3, 2\}\)（\(n=0,1,2\)）。 求 \(y[n] = x[n]*h[n]\)。

    思路

    逐项计算；长度应为 \(2+3-1 = 4\)。

    解答

    逐项计算（\(y[n] = \sum_k h[k]x[n-k]\)）：

    \(n=0\)：

    \[ y[0] = h[0]x[0] = 1\times2 = 2 \]

    \(n=1\)：

    \[ y[1] = h[0]x[1] + h[1]x[0] = 1\times1 + 3\times2 = 1+6 = 7 \]

    \(n=2\)：

    \[ y[2] = h[1]x[1] + h[2]x[0] = 3\times1 + 2\times2 = 3+4 = 7 \]

    \(n=3\)：

    \[ y[3] = h[2]x[1] = 2\times1 = 2 \]

    结果：

    \[ y[n] = \{2,\ 7,\ 7,\ 2\} \]

    用多项式乘法验证：

    \[ (2+z)(1+3z+2z^2) = 2 + 6z + 4z^2 + z + 3z^2 + 2z^3 \]
    \[ = 2 + 7z + 7z^2 + 2z^3 \;\checkmark \]

    系数 \(\{2,7,7,2\}\) 与手算一致。

    长度检验：\(2+3-1 = 4\) ✓

    例题 2：连续卷积（矩形与矩形）¶

    设

    \[ x(t) = \begin{cases}1, & 0 \leq t \leq 2 \\ 0, & \text{其他}\end{cases}, \qquad h(t) = \begin{cases}1, & 0 \leq t \leq 1 \\ 0, & \text{其他}\end{cases} \]

    求 \(y(t) = x(t)*h(t)\)。

    思路

    用「重叠面积」的几何观点分段讨论。

    解答

    由卷积公式

    \[ y(t) = \int_{-\infty}^{\infty} h(\tau)x(t-\tau)\,\mathrm{d}\tau \]

    两个矩形都是宽度有限、高度 1 的方波，所以重叠长度就是积分值。

    分四段讨论：

    ① \(t < 0\)：无重叠，\(y = 0\)。

    ② \(0 \leq t \leq 1\)：\(h(\tau)\) 在 \([0,1]\) 为 1，\(x(t-\tau)\) 在 \(\tau \in [t-2, t]\) 为 1。交集 \([0, t]\)，长度 \(t\)：

    \[ y(t) = t \]

    ③ \(1 < t \leq 2\)：交集 \([t-2, 1]\)？需仔细算：

    \(h\) 支撑在 \([0,1]\)，\(x(t-\tau)\) 支撑在 \(\tau \in [t-2,t]\)。

    对 \(1 < t \leq 2\)：交集为 \([t-2, t] \cap [0,1] = [t-2, 1]\)（因为 \(t-2 \leq 0\) 且 \(t \geq 1\)）。 长度 \(= 1 - (t-2) = 3-t\)？这不对，长度应该先增后减。

    让我重新分析。对 \(1 < t \leq 2\)，交集是 \([0,1]\)（因为 \([t-2,t] \supseteq [0,1]\) 需要 \(t-2 \leq 0\) 即 \(t \leq 2\)，且 \(t \geq 1\)）。

    所以长度 \(= 1\)：

    \[ y(t) = 1 \quad (1 < t \leq 2) \]

    ④ \(2 < t \leq 3\)：交集 \([t-2, 1]\)，长度 \(1-(t-2) = 3-t\)：

    \[ y(t) = 3-t \]

    ⑤ \(t > 3\)：无重叠，\(y = 0\)。

    汇总（这就是梯形）：

    \[ y(t) = \begin{cases} 0, & t<0 \\ t, & 0 \leq t \leq 1 \\ 1, & 1 < t \leq 2 \\ 3-t, & 2 < t \leq 3 \\ 0, & t > 3 \end{cases} \]

    长度检验：宽度 \(2\) 与宽度 \(1\) 的矩形卷积，结果宽度应为 \(2+1 = 3\) （从 \(t=0\) 到 \(t=3\)）✓

    矩形卷积的通式

    两个矩形卷积 = 梯形（若宽度相等则退化为三角形）。

    具体地：宽度 \(a\) 与 \(b\) 的矩形卷积，得到 - 上升段长度 \(\min(a,b)\) - 平顶段长度 \(\lvert a-b\rvert\) - 下降段长度 \(\min(a,b)\)

    这解释了「为什么窗函数卷积会平滑」：矩形是最锐利的窗， 卷积后变成梯形（边角被抹圆）。卷积总会让信号变平滑。

    例题 3：卷积的时移性质¶

    证明 \(x(t)*\delta(t-t_0) = x(t-t_0)\)。

    提示

    用冲激的筛选性质直接代入卷积积分。

    解答

    代入卷积定义：

    \[ x(t)*\delta(t-t_0) = \int_{-\infty}^{\infty} x(\tau)\,\delta(t-\tau-t_0)\,\mathrm{d}\tau \]

    冲激 \(\delta(t-\tau-t_0)\) 在 \(\tau = t-t_0\) 处非零。由筛选性质：

    \[ \int_{-\infty}^{\infty} x(\tau)\,\delta(\tau-(t-t_0))\,\mathrm{d}\tau = x(t-t_0) \qquad\blacksquare \]

    含义：与延迟冲激卷积 = 把信号延迟。

    推论（结合律的应用）：

    \[ x(t)*\left[\delta(t) + \delta(t-t_0)\right] = x(t) + x(t-t_0) \]

    这是一个两径信道模型（直射波 + 反射波）， 也解释了混响为什么是「原信号与一串衰减冲激的卷积」。

    冲激是卷积的单位元

    这个性质让 \(\delta\) 在卷积运算中扮演「1」的角色： \(x*\delta = x\)。

    所以常把 \(\delta\) 称为卷积恒等元。这也是判断一个序列是否为冲激的依据： 若 \(x*h = h\) 对所有 \(h\) 成立，则 \(x = \delta\)。

    例题 4：用卷积判断系统级联的效果¶

    两个 LTI 系统级联：

    • 系统 1：\(h_1[n] = \delta[n] - \delta[n-1]\)（差分，高通）
    • 系统 2：\(h_2[n] = \delta[n] + \delta[n-1]\)（平滑，低通）

    (a) 求级联系统的等效冲激响应。

    (b) 说明级联效果。

    思路

    由结合律，级联的冲激响应是两者卷积。

    解答

    (a) 等效冲激响应

    \[ h[n] = h_1[n]*h_2[n] = (\delta[n]-\delta[n-1])*(\delta[n]+\delta[n-1]) \]

    展开（用分配律）：

    \[ = \delta[n]*\delta[n] + \delta[n]*\delta[n-1] - \delta[n-1]*\delta[n] - \delta[n-1]*\delta[n-1] \]

    用 \(x*\delta[n-k] = x[n-k]\)：

    \[ = \delta[n] + \delta[n-1] - \delta[n-1] - \delta[n-2] \]
    \[ = \delta[n] - \delta[n-2] \]

    (b) 效果说明

    等效系统是

    \[ y[n] = x[n] - x[n-2] \]

    效果分析：

    频率成分 响应
    直流（\(x[n]=\) 常数） \(1-1 = 0\) → 完全抑制
    最高频（\(x[n]=(-1)^n\)） \(1-(-1)^2\cdot(-1)^n\)… 需具体算，见下
    中等频率 部分通过

    检验直流：\(x[n] = C\)（常数），则

    \[ y[n] = C - C = 0 \;\checkmark \]

    检验最高频：\(x[n] = (-1)^n\)，

    \[ y[n] = (-1)^n - (-1)^{n-2} = (-1)^n - (-1)^n = 0 \]

    （因为 \((-1)^{n-2} = (-1)^n\)。）最高频也被抑制。

    结论：这是带通滤波器（低频和高频都被抑制，中间通过）。

    为什么「高通 + 低通」不等于「全通」

    直觉上可能以为「高通 + 低通 = 全通」，但本例说明串联会叠加两者的衰减。

    具体说：

    • 差分（高通）在低频处增益 ≈ 0 → 抑制低频
    • 平滑（低通）在高频处增益 ≈ 0 → 抑制高频
    • 串联后：低频被第一个抑制，高频被第二个抑制 → 两头都被砍掉

    这解释了工程上级联滤波器要小心：每一级都会引入衰减， 总响应是各级之积（不是之和）。

    并联才是「相加」（由图 3 的分配律）。

    五、用在哪些课程里¶

    现代数字信号处理 · 滤波的数学本质¶

    • 滤波就是卷积：\(y = h * x\)，\(h\) 是滤波器的冲激响应
    • FIR 滤波器直接实现卷积（有限长冲激响应）
    • IIR 滤波器的冲激响应无限长，实现用递推形式
    • 计算卷积的两条路：
    • 时域直接算：\(O(NM)\)（\(N,M\) 为长度）
    • 频域算：\(O(N\log N)\)（用 FFT，快得多）

    FFT 为什么能加速卷积

    由卷积定理（下一页详述）：

    \[ y = x * h \quad\Longleftrightarrow\quad Y = X\cdot H \]

    所以流程是：

    FFT → 相乘 → IFFT

    复杂度从 \(O(N^2)\) 降到 \(O(N\log N)\)。

    \(N = 10^6\) 时：\(O(N^2) = 10^{12}\)（不可行）； \(O(N\log N) \approx 2\times10^7\)（瞬间完成）。

    这就是「快速卷积」的全部秘密。

    智能传感与信息处理 · 传感器动态响应¶

    • 传感器的冲激响应 \(h\) 刻画其动态特性
    • 实测输出 \(y = h * x\)（\(x\) 为真实被测量）
    • 反卷积：从 \(y\) 与 \(h\) 恢复 \(x\) —— 这是病态问题， 需要正则化（回忆 SVD 那一页的条件数分析）
    • 多传感器时间对齐：不同传感器的延迟差异就是冲激响应的时移

    通信与图像处理（延伸）¶

    应用 卷积的作用
    图像模糊 与高斯核卷积
    图像锐化 与拉普拉斯核卷积（近似二阶导）
    边缘检测 Sobel / Canny 算子都是小卷积核
    卷积神经网络 每层就是一组可学习的卷积核
    信道均衡 用逆滤波器抵消信道卷积

    卷积神经网络（CNN）名字的由来

    CNN 的每层确实在做卷积（严格说是互相关，差一个翻转）。

    「卷积核」就是 \(h\)，「特征图」就是 \(y = h*x\) 的结果。

    所以理解卷积，也就理解了 CNN 的数学骨架。

    六、自测¶

    Q1 设 \(x[n] = \{1,1,1\}\)（\(n=0,1,2\)），\(h[n] = \{1,1\}\)。求 \(y[n] = x*h\)。

    提示

    长度应为 \(3+2-1 = 4\)；这是「移动平均」。

    解答
    \[ \begin{aligned} y[0] &= 1\times1 = 1 \\ y[1] &= 1\times1 + 1\times1 = 2 \\ y[2] &= 1\times1 + 1\times1 = 2 \\ y[3] &= 1\times1 = 1 \end{aligned} \]

    结果：\(y[n] = \{1,2,2,1\}\)

    物理意义：\(h[n] = \{1,1\}\) 是一个两点滑动平均（未归一化）。 输出是「相邻两点之和」，所以数值变大、边缘出现斜坡。

    归一化版本：若 \(h[n] = \{0.5, 0.5\}\)，则 \(y = \{0.5,1,1,0.5\}\)， 这是真正的「移动平均滤波」，能平滑噪声。

    Q2 判断：\(x[n]*\delta[n-3] = x[n-3]\) 是否成立？

    提示

    用筛选性质（离散版）。

    解答

    成立。

    离散卷积：

    \[ (x*\delta[\cdot-3])[n] = \sum_k x[k]\,\delta[n-k-3] \]

    当 \(n-k-3 = 0\)，即 \(k = n-3\) 时，\(\delta\) 为 1，其余为 0。所以

    \[ = x[n-3] \;\checkmark \]

    含义：与移位冲激卷积 = 时移。

    推论：任何序列都可以写成冲激的叠加

    \[ x[n] = \sum_k x[k]\,\delta[n-k] \]

    这正是卷积推导的起点（回到本页开头的「三步推导」第一步）。

    Q3 两个系统 \(h_1[n] = \{1, 2\}\) 与 \(h_2[n] = \{1, -1\}\) 并联。求等效冲激响应。

    提示

    并联是相加（分配律），不是卷积。

    解答

    由分配律，并联的等效冲激响应是相加：

    \[ h[n] = h_1[n]+h_2[n] = \{1,2\} + \{1,-1\} = \{2, 1\} \]

    对比串联（若题目是串联）：则为卷积

    \[ h_1*h_2 = \{1\cdot1,\ 1\cdot(-1)+2\cdot1,\ 2\cdot(-1)\} = \{1,\ 1,\ -2\} \]

    务必区分：

    连接方式 等效冲激响应
    串联（级联） 卷积 \(h_1*h_2\)
    并联 相加 \(h_1+h_2\)

    这个区别在实际系统设计中很重要。

    Q4 卷积结果的长度与输入长度有何关系？为什么？

    提示

    考虑两个序列的支撑区间（非零范围）。

    解答

    若 \(x\) 的非零范围是 \([0, M-1]\)（长度 \(M\)）， \(h\) 的是 \([0, N-1]\)（长度 \(N\)），则

    \[ y[n] = \sum_k h[k]x[n-k] \]

    要 \(h[k]\) 非零，需 \(0 \leq k \leq N-1\)； 要 \(x[n-k]\) 非零，需 \(0 \leq n-k \leq M-1\)，即 \(n-M+1 \leq k \leq n\)。

    两者同时成立要求交集非空，于是 \(n\) 的范围是

    \[ 0 \leq n \leq (M-1)+(N-1) = M+N-2 \]

    长度 = \(M+N-2+1 = M+N-1\) ✓

    理解：最「早」的非零输出出现在 \(h\) 的第一点与 \(x\) 的第一点对齐时（\(n=0\)）； 最「晚」出现在 \(h\) 的最后点与 \(x\) 的最后点对齐时（\(n = M+N-2\)）。

    用途：这是检查卷积计算是否遗漏项的快速方法。
