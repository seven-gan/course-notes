    拉普拉斯变换¶

    傅里叶变换有一个限制：它只处理「稳定」信号（要求积分收敛）。

    例如 \(x(t) = e^{2t}u(t)\) 增长到无穷，其傅里叶变换不存在。 但电路里不稳定系统确实存在，我们也需要分析它们。

    解决办法：给信号乘一个衰减因子 \(e^{-\sigma t}\)，让它收敛。

    这就是拉普拉斯变换：

    \[ X(s) = \int_{-\infty}^{\infty} x(t)\,e^{-st}\,\mathrm{d}t, \qquad s = \sigma + j\omega \]

    拉普拉斯变换 = 带衰减因子的傅里叶变换

    把 \(s = \sigma+j\omega\) 代入：

    \[ X(s) = \int x(t)e^{-\sigma t}e^{-j\omega t}\,\mathrm{d}t = \mathcal{F}\{x(t)e^{-\sigma t}\} \]

    先乘 \(e^{-\sigma t}\)（让信号衰减），再求傅里叶变换。

    \(\sigma\) 效果
    \(0\) 退化为傅里叶变换（\(s = j\omega\)）
    \(>0\) 增强衰减 → 可分析增长信号
    \(<0\) 反而不利于收敛

    这就解释了为什么拉普拉斯变换能处理傅里叶变换处理不了的信号。 代价是：\(s\) 是复变量，画图需要二维平面（\(s\) 平面）而不是一条频率轴。

    一、与傅里叶变换、Z 变换的关系¶

    这三个变换是同一个思想在不同场景下的形态：

    变换 变量 适用 判据区域
    傅里叶变换 \(j\omega\)（\(s\) 平面虚轴） 稳定信号 —
    拉普拉斯变换 \(s = \sigma+j\omega\) 连续系统 左半平面
    Z 变换 \(z = re^{j\omega}\) 离散系统 单位圆内

    三者的对应关系：

    \[ \boxed{\ z = e^{sT_s}\ } \]

    其中 \(T_s\) 是采样周期。

    这个映射把连续域的判据搬到离散域：

    连续域（\(s\) 平面） → 离散域（\(z\) 平面）
    虚轴（\(j\omega\)） → 单位圆
    左半平面（稳定） → 单位圆内（稳定）
    虚轴上的极点 → 单位圆上的极点
    右半平面（不稳定） → 单位圆外

    记住这一条，两个学科就通了

    连续系统看左半平面，离散系统看单位圆内——本质是同一件事。

    这也解释了为什么「离散化」时要用特殊方法（如双线性变换）： 必须保证这个映射把左半平面映到单位圆内， 否则稳定的连续系统会变成不稳定的离散系统。

    离散化方法 是否保稳
    前向差分 ✗ 可能失真
    后向差分 ✓ 保稳
    双线性变换 ✓ 保稳（且频率无混叠）
    冲激响应不变法 ✗ 有混叠（高频折叠）

    二、收敛域与极点¶

    收敛域（ROC）：使积分收敛的 \(s\) 的集合。

    对单边拉普拉斯变换（\(t \geq 0\)），ROC 总是某个右半平面：

    \[ \operatorname{Re}(s) > \sigma_0 \]

    其中 \(\sigma_0\) 是最右极点的实部。

    关键性质：

    性质 说明
    ROC 内不含极点 极点上积分发散
    ROC 形状 由极点位置划分的带状/半平面
    因果系统的 ROC 最右极点右侧的半平面
    ROC 含虚轴 ⟺ 稳定 因为虚轴就是傅里叶变换存在的条件

    稳定性的完整判据

    因果系统稳定 ⟺ 所有极点在左半平面（\(\operatorname{Re}(p_i) < 0\)）。

    为什么：因果系统的 ROC 是「最右极点右侧」。 若所有极点在左半平面，则最右极点实部 \(< 0\)， ROC 包含虚轴 → 傅里叶变换存在 → 稳定

    这对应 Z 变换里的「极点在单位圆内」，通过 \(z = e^{sT}\) 完全对应。

    三、常用变换对¶

    \(x(t)\)（\(t \geq 0\)） \(X(s)\) 极点
    \(\delta(t)\) \(1\) 无
    \(u(t)\)（阶跃） \(\dfrac{1}{s}\) \(s=0\)
    \(t\,u(t)\)（斜坡） \(\dfrac{1}{s^2}\) \(s=0\)（二阶）
    \(e^{-at}u(t)\) \(\dfrac{1}{s+a}\) \(s=-a\)
    \(t e^{-at}u(t)\) \(\dfrac{1}{(s+a)^2}\) \(s=-a\)（二阶）
    \(\cos(\omega_0t)u(t)\) \(\dfrac{s}{s^2+\omega_0^2}\) \(s=\pm j\omega_0\)
    \(\sin(\omega_0t)u(t)\) \(\dfrac{\omega_0}{s^2+\omega_0^2}\) \(s=\pm j\omega_0\)
    \(e^{-at}\cos(\omega_0t)u(t)\) \(\dfrac{s+a}{(s+a)^2+\omega_0^2}\) \(s=-a\pm j\omega_0\)

    从极点位置读出时域行为（很重要的技能）

    极点位置 时域表现
    负实轴（\(s=-a\)） 指数衰减 \(e^{-at}\)
    原点（\(s=0\)） 常量（阶跃）
    正实轴 指数增长（不稳定）
    纯虚轴（\(\pm j\omega_0\)） 等幅振荡（临界）
    左半平面复数（\(-a\pm j\omega_0\)） 衰减振荡 ← 最常见的工程情形
    右半平面复数 增幅振荡（不稳定）

    虚部给出振荡频率，实部给出衰减速率。

    这是「极点决定动态特性」的具体含义。

    四、重要性质¶

    性质 时域 \(s\) 域
    线性 \(ax_1+bx_2\) \(aX_1+bX_2\)
    时移 \(x(t-t_0)u(t-t_0)\) \(e^{-st_0}X(s)\)
    \(s\) 域平移 \(e^{-at}x(t)\) \(X(s+a)\)
    尺度 \(x(at)\) \(\dfrac{1}{a}X\!\left(\dfrac{s}{a}\right)\)
    卷积 \(x*h\) \(X(s)H(s)\)
    微分 \(\dfrac{\mathrm{d}x}{\mathrm{d}t}\) \(sX(s)-x(0^-)\)
    积分 \(\displaystyle\int_0^t x\,\mathrm{d}\tau\) \(\dfrac{X(s)}{s}\)
    初值 \(x(0^+)\) \(\lim_{s\to\infty}sX(s)\)
    终值 \(x(\infty)\) \(\lim_{s\to0}sX(s)\)

    微分性质里的初值项不能漏

    \[ \mathcal{L}\left\{\frac{\mathrm{d}x}{\mathrm{d}t}\right\} = sX(s) - x(0^-) \]

    这一项 \(x(0^-)\) 是「初始条件」的来源，也是拉普拉斯变换能解 微分方程的关键：它把初始条件自动带入代数方程。

    对比傅里叶变换：傅里叶变换的微分性质是 \(j\omega X(\omega)\)， 没有初值项——因为它不处理初始条件（只处理稳态）。

    这就是「解带初始条件的微分方程要用拉普拉斯变换，不用傅里叶变换」的原因。

    用拉普拉斯变换解微分方程¶

    流程（把微分方程变成代数方程）：

    步骤 操作
    1 对微分方程两边取拉普拉斯变换
    2 初值自动进入方程
    3 解出 \(Y(s)\)（代数运算）
    4 部分分式分解
    5 查表逆变换得 \(y(t)\)

    与 Z 变换解差分方程完全平行（那一页讲过）。

    这一步的价值：微积分 → 代数

    原问题 变换后
    微分方程 代数方程
    积分/微分 乘/除 \(s\)
    卷积 乘法
    初始条件 常数项

    所以「变换方法」的核心价值是把难的问题变成容易的问题， 解完再换回来。

    五、系统函数与频率响应¶

    对 LTI 系统，冲激响应 \(h(t)\) 的拉普拉斯变换 \(H(s)\) 称为系统函数：

    \[ H(s) = \frac{Y(s)}{X(s)} \]

    频率响应：令 \(s = j\omega\)（在虚轴上取值）：

    \[ H(j\omega) = H(s)\Big|_{s=j\omega} \]

    为什么取 s = jω 就是频率响应

    因为 \(s = \sigma+j\omega\)，取 \(\sigma = 0\) 得 \(s = j\omega\)， 这正是傅里叶变换（前面已说明：\(\sigma=0\) 时拉普拉斯退化为傅里叶）。

    前提：系统必须稳定（ROC 包含虚轴），否则 \(s=j\omega\) 不在收敛域内， 频率响应没有意义。

    工程含义：不稳定系统谈不上「频率响应」—— 因为它对正弦输入的响应会发散，不是等幅的正弦。

    六、典型例题¶

    例题 1：求拉普拉斯变换¶

    求 \(x(t) = e^{-3t}u(t)\) 的拉普拉斯变换与收敛域。

    思路

    代入定义做积分，注意收敛条件。

    解答
    \[ X(s) = \int_0^{\infty}e^{-3t}e^{-st}\,\mathrm{d}t = \int_0^{\infty}e^{-(s+3)t}\,\mathrm{d}t \]

    计算：

    \[ = \left[\frac{e^{-(s+3)t}}{-(s+3)}\right]_0^{\infty} \]

    当 \(\operatorname{Re}(s+3) > 0\)（即 \(\operatorname{Re}(s) > -3\)）时， 上界处 \(e^{-(s+3)\cdot\infty} \to 0\)：

    \[ = 0 - \frac{1}{-(s+3)} = \frac{1}{s+3} \]

    结果：

    \[ \boxed{\ X(s) = \frac{1}{s+3},\qquad \operatorname{Re}(s) > -3\ } \]

    极点：\(s = -3\)（在负实轴，左半平面）→ 稳定

    对照傅里叶变换：把 \(s = j\omega\) 代入，得 \(1/(j\omega+3)\)， 与前面傅里叶那一页的结果一致

    ROC 的含义：\(\operatorname{Re}(s) > -3\) 是最右极点 \(-3\) 右侧的半平面， 且包含虚轴（因为 \(-3 < 0\)）→ 傅里叶变换存在 → 稳定

    例题 2：用拉普拉斯变换解微分方程¶

    求解

    \[ \frac{\mathrm{d}y}{\mathrm{d}t} + 2y = 1, \qquad y(0^-) = 0 \]
    思路

    两边取拉普拉斯变换，用微分性质（注意初值项），解出 \(Y(s)\) 再逆变换。

    解答

    第一步：取变换

    输入是阶跃 \(1 = u(t)\)，其变换为 \(1/s\)。

    左边变换（用微分性质）：

    \[ \mathcal{L}\left\{\frac{\mathrm{d}y}{\mathrm{d}t}\right\} + 2Y(s) = \left[sY(s) - y(0^-)\right] + 2Y(s) \]

    由 \(y(0^-) = 0\)：

    \[ = sY(s) + 2Y(s) = (s+2)Y(s) \]

    右边：

    \[ \frac{1}{s} \]

    第二步：解代数方程

    \[ (s+2)Y(s) = \frac{1}{s} \implies Y(s) = \frac{1}{s(s+2)} \]

    第三步：部分分式分解

    \[ \frac{1}{s(s+2)} = \frac{A}{s} + \frac{B}{s+2} \]

    求系数：

    \[ A = \left.\frac{1}{s+2}\right|_{s=0} = \frac12, \qquad B = \left.\frac{1}{s}\right|_{s=-2} = -\frac12 \]

    所以

    \[ Y(s) = \frac{1/2}{s} - \frac{1/2}{s+2} \]

    第四步：逆变换（查表：\(1/s \leftrightarrow u(t)\)，\(1/(s+a) \leftrightarrow e^{-at}u(t)\)）

    \[ \boxed{\ y(t) = \frac12\left(1 - e^{-2t}\right)u(t)\ } \]

    验证：

    • \(y(0^+) = \frac12(1-1) = 0\) ✓ 符合初值
    • \(t \to \infty\)：\(y \to \frac12\)（稳态）
    • 代回原方程：\(y' = e^{-2t}\)，而 \(y'+2y = e^{-2t} + (1-e^{-2t}) = 1\)

    物理解读：这是一阶低通系统对阶跃输入的响应—— 从 0 开始按指数规律趋近稳态值 \(1/2\)（时间常数 \(\tau = 1/2\) s）。

    对比：用傅里叶变换解不了这道题

    原因：傅里叶变换的微分性质是 \(j\omega Y(\omega)\)，没有初值项， 所以无法处理 \(y(0^-) = 0\) 这个初始条件。

    更严格地说：单边拉普拉斯变换处理的是「\(t \geq 0\) 且给定初值」的问题 （瞬态 + 稳态），而傅里叶变换处理的是「双边、稳态」问题。

    目的 工具
    求瞬态响应（含初值） 拉普拉斯（或 Z）变换
    求稳态频率响应 傅里叶变换
    分析稳定性 极点位置（拉普拉斯/Z）

    例题 3：从极点判断动态行为¶

    系统 \(H(s) = \dfrac{10}{s^2+6s+25}\)。判断稳定性并描述阶跃响应特征。

    思路

    求分母的根，看实部符号；由实部判衰减速率，虚部判振荡频率。

    解答

    求极点（解 \(s^2+6s+25=0\)）：

    \[ s = \frac{-6\pm\sqrt{36-100}}{2} = \frac{-6\pm j8}{2} = -3\pm j4 \]

    判断稳定性：实部 \(-3 < 0\)，两个极点都在左半平面 → 稳定

    动态特征：

    参数 值 含义
    实部 \(\sigma = -3\) 衰减速率 时间常数 \(\tau = 1/3\) s
    虚部 \(\omega_d = 4\) 阻尼振荡频率 \(f_d = 4/(2\pi) \approx 0.64\) Hz
    自然频率 \(\omega_n = \sqrt{25} = 5\) 无阻尼固有频率 —
    阻尼比 \(\zeta = 3/5 = 0.6\) 欠阻尼 有超调

    （计算关系：\(s = -\zeta\omega_n \pm j\omega_n\sqrt{1-\zeta^2}\)， 所以 \(\zeta\omega_n = 3\)、\(\omega_n\sqrt{1-\zeta^2} = 4\)， 得 \(\omega_n = 5\)、\(\zeta = 0.6\)。）

    阶跃响应特征：

    • 欠阻尼（\(0 < \zeta < 1\)）：振荡衰减，有超调
    • 超调量约
    \[ M_p = e^{-\pi\zeta/\sqrt{1-\zeta^2}} = e^{-3\pi/4} \approx 9.5\% \]
    • 振荡 4 个周期后衰减到初值的
    \[ e^{-3\cdot 4\cdot 2\pi/4} = e^{-6\pi} \approx 6\times10^{-9} \]

    （基本消失）

    时域形式（供对照）：

    \[ y(t) = 2\left[1 - e^{-3t}\left(\cos 4t + \frac34\sin 4t\right)\right]u(t) \]

    （分母 \(s^2+6s+25 = (s+3)^2+16\)，对应衰减振荡的标准形式。）

    极点的「虚部-实部」读法

    位置 时域
    实部绝对值大（远离虚轴） 衰减快（响应迅速稳定）
    实部接近 0（靠近虚轴） 衰减慢（振荡持续久，易不稳定）
    虚部大 振荡频率高

    工程经验：极点离虚轴太近（\(\lvert\sigma\rvert\) 小）是危险的—— 参数稍有变化就可能跑到右半平面。所以设计时通常要求一定的稳定裕度。

    例题 4：由微分方程求系统函数与稳定性¶

    系统满足 \(\ddot{y} + 3\dot{y} + 2y = \dot{x} + x\)。求 \(H(s)\) 并判断稳定性。

    提示

    两边取拉普拉斯变换（零初值），用 \(d/dt \leftrightarrow s\)。

    解答

    取零初值下的拉普拉斯变换：

    用 \(d^n/dt^n \leftrightarrow s^n\)（零初值时初值项为零）：

    \[ s^2Y(s) + 3sY(s) + 2Y(s) = sX(s) + X(s) \]

    提取公因子：

    \[ (s^2+3s+2)Y(s) = (s+1)X(s) \]

    系统函数：

    \[ H(s) = \frac{Y(s)}{X(s)} = \frac{s+1}{s^2+3s+2} \]

    因式分解：

    \[ s^2+3s+2 = (s+1)(s+2) \]
    \[ H(s) = \frac{s+1}{(s+1)(s+2)} \]

    零点与极点：

    类型 位置
    零点 \(s = -1\)
    极点 \(s = -1,\ -2\)

    注意：\(s = -1\) 既是零点又是极点——可以约掉！

    \[ H(s) = \frac{1}{s+2} \qquad (s \neq -1) \]

    极零相消（pole-zero cancellation）：分子分母的公因子相消， 系统实际是一阶的。

    稳定性：剩下的极点在 \(s=-2\)（左半平面）→ 稳定

    阶跃响应：\(H(s)/s = 1/[s(s+2)]\)，与例题 2 同形式 → \(y(t) = \frac12(1-e^{-2t})u(t)\)

    极零相消要小心两件事

    1. 数学上可约，物理上不一定

    若那个被约掉的极点是不稳定的（在右半平面）， 系统内部仍有发散模态（虽然输入输出关系看起来稳定）。

    这叫内部不稳定（或「不可观/不可控模态」）。 实际系统中这可能导致内部信号饱和甚至损坏设备。

    2. 数值上不要真的去约

    实际的传递函数是通过测量或辨识得到的， 分子分母的系数有误差。所谓「公因子」可能只是接近相等。

    直接约掉会带来严重的数值误差。正确做法是用最小实现理论 （基于可控可观分解）来判断。

    实践建议：看到接近的极零点对，先检查它是否真的可约 （看留数与可控可观性），不要想当然。

    七、用在哪些课程里¶

    现代数字信号处理 · 模拟部分与离散化的桥梁¶

    用途 说明
    模拟滤波器设计 在 \(s\) 域设计（巴特沃斯、切比雪夫等）
    离散化 通过 \(z = e^{sT}\) 或双线性变换转到 \(z\) 域
    稳定性判据 连续系统看左半平面
    系统辨识 由输入输出数据拟合 \(H(s)\)

    双线性变换：为什么它比「直接代换」好

    一种朴素的离散化是直接代 \(s = (1-z^{-1})/T\)（前向差分）， 但它不保证稳定性。

    双线性变换用

    \[ s = \frac{2}{T}\cdot\frac{z-1}{z+1} \]

    它的好处：

    优点 说明
    保稳 左半平面 → 单位圆内（严格）
    无混叠 频率轴映射到单位圆上一一对应
    缺点 频率有非线性畸变（需预畸变校正）

    所以工程上离散化模拟滤波器几乎都用双线性变换。

    智能传感与信息处理 · 传感器动态建模¶

    • 传感器传递函数 \(H(s)\) 刻画其动态特性（带宽、阻尼、谐振）
    • 二阶模型（\(\omega_n\)、\(\zeta\)）是振动传感器、加速度计的常用模型
    • 动态补偿：用一个 \(1/H(s)\) 的补偿环节提升带宽 （但要检查补偿后的稳定性与噪声放大）
    • 状态观测器设计依赖系统极点配置

    海洋声学 · 换能器与信道建模¶

    • 换能器电声转换用二阶系统建模（谐振频率附近）
    • 信道传递函数 \(H(s)\) 描述多径与频率选择性衰落
    • 阻抗匹配网络的设计在 \(s\) 域进行

    八、自测¶

    Q1 求 \(x(t) = tu(t)\) 的拉普拉斯变换。

    提示

    可以直接积分，或用「\(t\) 倍乘」性质：\(\mathcal{L}\{tx(t)\} = -\frac{dX}{ds}\)。

    解答

    方法一：直接积分（分部积分）

    \[ X(s) = \int_0^{\infty}te^{-st}\,\mathrm{d}t \]

    设 \(u = t\)，\(\mathrm{d}v = e^{-st}\mathrm{d}t\)，则 \(\mathrm{d}u = \mathrm{d}t\)， \(v = -e^{-st}/s\)：

    \[ = \left[-t\frac{e^{-st}}{s}\right]_0^{\infty} + \frac{1}{s}\int_0^{\infty}e^{-st}\,\mathrm{d}t \]

    第一项在 \(\operatorname{Re}(s)>0\) 时为 0，第二项 \(= \frac{1}{s}\cdot\frac1s\)：

    \[ \boxed{\ X(s) = \frac{1}{s^2},\qquad \operatorname{Re}(s) > 0\ } \]

    方法二：用性质

    由 \(u(t) \leftrightarrow 1/s\) 与 \(\mathcal{L}\{tx(t)\} = -\frac{\mathrm{d}}{\mathrm{d}s}X(s)\)：

    \[ \mathcal{L}\{tu(t)\} = -\frac{\mathrm{d}}{\mathrm{d}s}\left(\frac1s\right) = \frac{1}{s^2} \;\checkmark \]

    极点：\(s=0\) 处的二阶极点。

    为什么是二阶：因为 \(t\) 线性增长，比阶跃「更不稳定」， 需要更强的衰减因子。极点阶数反映了增长的幂次。

    工程含义：输入斜坡信号时，一阶系统（\(H = 1/(s+a)\)）的输出 会长成二次函数形式——这就是「积分器串联」的效果。

    Q2 判断：\(H(s) = \frac{1}{s-2}\) 的系统稳定吗？

    提示

    看极点位置。

    解答

    不稳定。

    极点在 \(s = 2\)（右半平面）✗

    对应的冲激响应：

    \[ h(t) = e^{2t}u(t) \]

    这是指数增长，显然不稳定 ✓ 与判据一致。

    补充说明：

    问题 回答
    有频率响应吗？ 没有（虚轴不在 ROC 内）
    ROC 是什么？ \(\operatorname{Re}(s) > 2\)
    为什么会不稳定？ 极点实部为正 → 符号使 \(e^{-(s-2)t}\) 指数增长

    物理例子：正反馈过强的放大器、倒立摆（无控制时）、 热失控系统。

    怎样才能稳定：把极点移到左半平面，例如加负反馈 （\(H = 1/(s+2)\)）。

    Q3 已知 \(H(s) = \frac{1}{(s+1)(s+100)}\)。求系统带宽的近似值。

    提示

    看极点的分布，主极点决定低频段的带宽。

    解答

    极点：\(s = -1\) 与 \(s = -100\)。

    主极点（离虚轴最近的）：\(s = -1\)，时间常数 \(\tau = 1\) s。

    带宽近似：一阶系统 \(-3\) dB 带宽为

    \[ \omega_c \approx \frac{1}{\tau} = 1 \text{ rad/s} \]

    即 \(f_c \approx 0.16\) Hz。

    为什么可以忽略 \(-100\) 的极点：

    它离原点远 100 倍 → 转折频率高 100 倍。 在 \(\omega \approx 1\) 附近，它的贡献（分母中的 \(\lvert j\omega+100\rvert\)） 几乎是常数 100，只影响增益不影响形状。

    主导极点近似：对多极点系统，离虚轴最近的极点决定动态特性 （前提是它比其它极点近足够多，通常 5 倍以上）。

    误差估计：忽略高频极点会带来约 \(1/100\) 的增益误差 （约 \(0.04\) dB），在工程上可忽略。

    反面例子：若极点是 \(-1\) 与 \(-3\)，两者只差 3 倍， 不能用主导极点近似，必须完整分析（这时是双时间常数过程）。

    Q4 为什么拉普拉斯变换能处理傅里叶变换处理不了的信号？举例说明。

    提示

    想 \(\sigma\) 因子的作用。

    解答

    核心原因：多了衰减因子 \(e^{-\sigma t}\)。

    例子：\(x(t) = e^{2t}u(t)\)（指数增长）。

    傅里叶变换：

    \[ X(\omega) = \int_0^{\infty}e^{2t}e^{-j\omega t}\,\mathrm{d}t = \int_0^{\infty}e^{(2-j\omega)t}\,\mathrm{d}t \]

    被积函数的模是 \(e^{2t}\)，随 \(t\) 增长，积分发散 → 不存在 ✗

    拉普拉斯变换：

    \[ X(s) = \int_0^{\infty}e^{2t}e^{-st}\,\mathrm{d}t = \int_0^{\infty}e^{-(s-2)t}\,\mathrm{d}t \]

    只要 \(\operatorname{Re}(s) > 2\)，被积函数就衰减，积分收敛：

    \[ X(s) = \frac{1}{s-2}, \qquad \operatorname{Re}(s) > 2 \]

    收敛域存在

    对比总结：

    傅里叶变换 拉普拉斯变换
    可处理 稳定信号（\(\sigma=0\) 就够） 增长信号（需 \(\sigma>0\)）
    变量 \(j\omega\)（一维） \(s\)（二维）
    稳定性判断 无法判断（不存在就没得谈） 极点位置直接给出判据
    初始条件 无法处理 自动带入

    代价：

    代价 说明
    需要二维平面 画图比频谱麻烦
    需要给收敛域 否则变换不唯一
    逆变换更难 需要复平面积分（实用中用部分分式 + 查表）

    工程取向：分析稳定性与瞬态用拉普拉斯，分析稳态频率特性用傅里叶 （实际中 \(s=j\omega\) 代入即可）。
