    离散傅里叶变换与 FFT¶

    傅里叶变换处理的是连续信号，但计算机只能处理有限长离散数据。

    这一页回答：给定 \(N\) 个采样点，怎么算出它的频谱？

    答案就是离散傅里叶变换（DFT）：

    \[ X[k] = \sum_{n=0}^{N-1} x[n]\,e^{-j2\pi kn/N}, \qquad k = 0,1,\dots,N-1 \]

    它是频谱分析与数字滤波的实际工具——也是 FFT 要加速的那个运算。

    三种傅里叶变换的关系（先理清楚）

    这是最容易混淆的地方：

    变换 信号类型 频谱类型 计算方式
    CTFT（连续时间傅里叶变换） 连续、非周期 连续、非周期 积分
    DTFT 离散、非周期 连续、周期 无穷求和
    DFT 离散、有限长 离散、周期 有限求和

    两条规律（记这两条就够了）：

    时域 → 频域
    离散（采样） 频谱周期重复
    有限长（截断） 频谱离散化

    所以：时域离散且有限 → 频域周期且离散，这正是 DFT。

    一、DFT 的定义与来源¶

    定义¶

    对长度 \(N\) 的序列 \(x[0],\dots,x[N-1]\)，DFT 为

    \[ X[k] = \sum_{n=0}^{N-1} x[n]\,e^{-j2\pi kn/N}, \qquad k = 0,1,\dots,N-1 \]

    逆变换（IDFT）：

    \[ x[n] = \frac{1}{N}\sum_{k=0}^{N-1} X[k]\,e^{j2\pi kn/N} \]

    两者形式对称，只差指数符号与前面的 \(1/N\)。

    为什么是这个形式¶

    回忆「规范正交基下求坐标 = 内积」（线性代数模块）。

    基向量取

    \[ \boldsymbol{w}_k = \left(1,\ e^{j2\pi k/N},\ e^{j4\pi k/N},\ \dots,\ e^{j2\pi k(N-1)/N}\right) \]

    这 \(N\) 个向量互相正交：

    \[ \sum_{n=0}^{N-1} e^{j2\pi (k-m)n/N} = \begin{cases} N, & k = m \\ 0, & k \neq m\end{cases} \]

    （这是几何级数求和的结果：公比 \(e^{j2\pi(k-m)/N} \neq 1\) 时，\(N\) 项之和为 0。）

    所以 \(X[k]\) 就是 \(x\) 在这组正交基上的投影系数——与傅里叶级数系数公式同源。

    与 DTFT 的关系：DFT 是 DTFT 的采样

    若把有限长序列补零成无限长（或视为一个周期的采样），则

    \[ X[k] = X(e^{j\omega})\Big|_{\omega = 2\pi k/N} \]

    即 DFT 就是 DTFT 在 \(N\) 个等间隔频点上的采样值。

    这解释了两件事：

    1. DFT 的频域是周期的（周期 \(N\)，因为 \(X[k+N] = X[k]\)）
    2. 频率分辨率：相邻频点间隔 \(\Delta f = f_s/N\)

    二、频率分辨率与物理频率¶

    DFT 的第 \(k\) 个点对应物理频率

    \[ f_k = \frac{k}{N}f_s, \qquad k = 0,1,\dots,N-1 \]

    频率分辨率（能区分的最小频率间隔）：

    \[ \boxed{\ \Delta f = \frac{f_s}{N} = \frac{1}{NT_s} = \frac{1}{T_{\text{总}}}\ } \]

    其中 \(T_{\text{总}} = NT_s\) 是总观测时长。

    关键认识：分辨率只取决于观测时长

    \[ \Delta f = \frac{1}{T_{\text{总}}} \]

    与采样率无关（在 \(N\) 固定时提高 \(f_s\) 只会扩大频率范围，不会细化分辨率）。

    想要的效果 该怎么做
    看更高的频率 提高采样率 \(f_s\)
    分辨更近的两个频率 增加观测时长 \(T_{\text{总}}\)

    常见误解：「补零能提高分辨率」。

    实际上：补零只是让频点更密（曲线更光滑）， 不能区分原本分辨不出的两个频率——因为补零没有增加真实信息。

    操作 频点间隔 真实分辨率
    补零（\(N\) 增大，\(T\) 不变） 变密 不变
    延长观测（\(T\) 增大） 变密 提高

    验证方法：观察补零后的频谱，峰仍然「胖」（主瓣宽度由 \(T\) 决定）。

    三、频谱泄漏与窗函数¶

    问题的来源¶

    DFT 隐含假设：所取的那 \(N\) 个点正好是一个周期（即信号在观测窗口内周期性延拓）。

    若信号频率不是 \(\Delta f\) 的整数倍，这个假设不成立 → 观测窗口的首尾接不上 → 频谱出现虚假的旁瓣。这叫频谱泄漏。

    从频域看：截断相当于乘以矩形窗，而矩形窗的频谱是 sinc（主瓣 + 无限旁瓣）。 频域相乘 = 卷积，所以真实谱线被「抹开」成 sinc 形状。

    常用窗函数¶

    窗 主瓣宽度 最高旁瓣 适用
    矩形 最窄（最高分辨率） \(-13\) dB 整周期截断、瞬态信号
    汉宁（Hann） 2 倍 \(-31\) dB 通用频谱分析
    汉明（Hamming） 2 倍 \(-43\) dB 需要低旁瓣
    布莱克曼 3 倍 \(-58\) dB 大动态范围（弱信号检测）
    平顶 最宽 极低 幅度精度优先（校准）

    窗函数的选择原则

    权衡关系：主瓣越窄（分辨率好）↔ 旁瓣越低（泄漏小），二者不可兼得。

    需求 选择
    区分靠得很近的两个频率 矩形 / 汉宁（主瓣窄）
    检测一个弱信号旁边有强信号 布莱克曼（旁瓣低）
    准确测量幅度 平顶窗
    分析瞬态/冲击 矩形窗（不加窗）

    为什么汉宁窗是「默认选择」：它在分辨率与泄漏之间取得较好的平衡， 且首尾都趋零（天然缓解不连续）。

    加窗的代价¶

    加窗会改变信号的幅度与能量。修正方法：

    • 幅度修正：除以窗函数的相干增益（\(\frac{1}{N}\sum_{n}w[n]\)）
    • 能量修正：除以窗的均方根增益（用它算功率谱时）

    忽略修正会导致幅度系统性偏小（例如汉宁窗约 \(-6\) dB）。

    这是实际频谱分析最容易犯的错误

    用示波器/频谱仪测出的谱线高度偏低，常见原因就是没做窗增益修正。

    此外还有「重叠处理」（overlap）：加窗会削弱窗口边缘的数据权重， 所以实践中把相邻段重叠 50%，再用「重叠相加」保持总权重恒定。

    这就是 Welch 法的做法（工程上最常用的功率谱估计方法）。

    四、FFT：把 \(O(N^2)\) 降到 \(O(N\log N)\)¶

    DFT 的计算量¶

    直接计算：\(N\) 个频点，每个需 \(N\) 次复数乘加 →

    \[ O(N^2) \]

    \(N = 10^6\) 时需要约 \(10^{12}\) 次运算——不可行。

    FFT 的核心思想：分治¶

    FFT（快速傅里叶变换）不是新的变换，而是计算 DFT 的快速算法。

    关键观察：\(e^{-j2\pi kn/N}\) 具有周期性与对称性：

    \[ W_N^{k(n+N)} = W_N^{kn}, \qquad W_N^{k(n+N/2)} = -W_N^{kn} \]

    （记 \(W_N = e^{-j2\pi/N}\)。）

    利用这两条，可以把长度 \(N\) 的 DFT 拆成两个长度 \(N/2\) 的 DFT：

    \[ X[k] = \underbrace{E[k]}_{\text{偶数项 DFT}} + W_N^k\underbrace{O[k]}_{\text{奇数项 DFT}}, \qquad k = 0,\dots,\frac N2-1 \]
    \[ X\left[k+\frac N2\right] = E[k] - W_N^k\,O[k] \]

    第二个式子里的负号正是对称性带来的——所以算出一半的 \(E[k]\) 与 \(O[k]\) 后， 另一半只需加减法。

    递归下去，总计算量变为

    \[ O(N\log N) \]

    \(N = 10^6\) 时约 \(2\times10^7\) 次——快 5 万倍。

    FFT 的意义超出算法本身

    FFT 让「频域方法」在工程上变得可用：

    应用 说明
    快速卷积 FFT → 相乘 → IFFT，\(O(N\log N)\) 替代 \(O(N^2)\)
    实时频谱分析 音频、振动、雷达
    OFDM 通信 用 IFFT/FFT 实现多载波调制解调
    图像处理 二维 FFT 做滤波与压缩
    快速大数乘法 把乘法化为卷积

    没有 FFT，现代数字通信与信号处理都不可能实现。

    五、DFT 的重要性质¶

    性质 时域 频域
    线性 \(ax_1+bx_2\) \(aX_1+bX_2\)
    循环移位 \(x[(n-m)\bmod N]\) \(X[k]e^{-j2\pi km/N}\)
    循环卷积 \(x\circledast h\) \(X[k]H[k]\)
    对偶 \(X[n]\) \(Nx[(-k)\bmod N]\)
    帕塞瓦尔 \(\sum_n\lvert x[n]\rvert^2\) \(\frac1N\sum_k\lvert X[k]\rvert^2\)

    注意「循环」卷积 —— 这是最容易出错的地方

    DFT 的卷积定理给出的是循环卷积（下标模 \(N\)）， 而不是我们在线性系统里用的线性卷积。

    区别：

    类型 结果长度 含义
    线性卷积 \(M+N-1\) 实际的系统响应（卷积那一页）
    循环卷积 \(\max(M,N)\) 下标环绕，会产生混叠

    后果：若直接用 FFT 做线性卷积而不处理，结果会首尾混叠（时域混叠）。

    解决办法：补零

    把两个序列都补零到长度 \(\geq M+N-1\)，再做 DFT。 此时循环卷积与线性卷积一致（因为不会有下标环绕）。

    \[ L \geq M+N-1 \]

    这也是「用 FFT 做快速卷积」必须注意的第一个细节。

    六、典型例题¶

    例题 1：手算 4 点 DFT¶

    求 \(x = \{1, 1, 0, 0\}\) 的 4 点 DFT。

    思路

    直接代入定义，用 \(W_4 = e^{-j2\pi/4} = -j\) 化简。

    解答

    记 \(W_4 = e^{-j2\pi/4} = e^{-j\pi/2} = -j\)。则 \(W_4^{kn}\) 只有 \(1, -j, -1, j\) 四种取值。

    代入 \(X[k] = \sum_{n=0}^{3}x[n]W_4^{kn}\)（只有 \(n=0,1\) 非零）：

    \[ X[k] = 1\cdot W_4^0 + 1\cdot W_4^{k} = 1 + (-j)^k \]

    逐个计算：

    \(k\) \((-j)^k\) \(X[k]\)
    0 \(1\) \(1+1 = 2\)
    1 \(-j\) \(1-j\)
    2 \(-1\) \(1-1 = 0\)
    3 \(j\) \(1+j\)

    结果：

    \[ X = \{2,\ 1-j,\ 0,\ 1+j\} \]

    验证共轭对称：\(X[1] = 1-j\) 与 \(X[3] = 1+j\) 互为共轭 ✓ （因为 \(x\) 是实序列，这正是前面讲的共轭对称性。）

    验证帕塞瓦尔定理：

    时域能量：\(\lvert1\rvert^2+\lvert1\rvert^2 = 2\)

    频域能量：

    \[ \frac14\left(\lvert2\rvert^2+\lvert1-j\rvert^2+\lvert0\rvert^2+\lvert1+j\rvert^2\right) = \frac14(4+2+0+2) = \frac84 = 2 \;\checkmark \]

    例题 2：确定频率分辨率¶

    某振动信号以 \(f_s = 1000\) Hz 采样，采集 4096 点。

    (a) 频率分辨率是多少？

    (b) 能分析的最高频率？

    © 若信号含 100 Hz 与 103 Hz 两个成分，能区分吗？

    思路

    分辨率 \(\Delta f = f_s/N\)；最高可分析频率由奈奎斯特定理给出。

    解答

    (a) 频率分辨率

    \[ \Delta f = \frac{f_s}{N} = \frac{1000}{4096} \approx 0.244 \text{ Hz} \]

    验证：观测时长 \(T = N/f_s = 4.096\) s，所以 \(\Delta f = 1/T \approx 0.244\) Hz ✓

    (b) 最高频率

    由奈奎斯特定理：

    \[ f_{\max} = \frac{f_s}{2} = 500 \text{ Hz} \]

    © 能否区分 100 与 103 Hz

    两频率间隔 \(3\) Hz，而分辨率 \(0.244\) Hz。

    \[ 3 \gg 0.244 \;\checkmark \]

    可以区分 ✓ 它们之间约有 \(3/0.244 \approx 12\) 个频点， 在频谱上会显示为两个独立的峰。

    反过来的问题：若分辨不出怎么办

    假设要分辨间隔 \(0.1\) Hz 的两个成分。需要

    \[ \Delta f \leq 0.1 \implies T \geq 10 \text{ s} \]

    即至少观测 10 秒。

    注意：提高采样率没用！

    若把 \(f_s\) 提到 10000 Hz 而 \(N\) 仍取 4096，则

    \[ \Delta f = \frac{10000}{4096} \approx 2.44 \text{ Hz} \]

    分辨率反而变差了（因为观测时长缩短到 0.41 s）。

    正确做法：保持采样率，增加点数 \(N\)（即延长观测时间）。

    例题 3：循环卷积与线性卷积的区别¶

    \(x = \{1,2,3\}\)，\(h = \{1,1\}\)。

    (a) 求补零到 \(N=4\) 后的循环卷积。

    (b) 与线性卷积比较。

    思路

    循环卷积要对下标取模 \(N\)；线性卷积不取模。

    解答

    已知线性卷积（前面算过）：

    \[ y_{\text{lin}} = \{1,\ 3,\ 5,\ 3\} \]

    长度 \(M+N-1 = 3+2-1 = 4\)。

    (a) \(N=4\) 的循环卷积

    把 \(x\) 补零到 4 点：\(x = \{1,2,3,0\}\)，\(h = \{1,1,0,0\}\)。

    循环卷积定义：

    \[ y_c[n] = \sum_{k=0}^{3} h[k]\,x[(n-k)\bmod 4] \]
    \(n\) 计算 \(y_c[n]\)
    0 \(h[0]x[0]+h[1]x[3] = 1\cdot1+1\cdot0\) 1
    1 \(h[0]x[1]+h[1]x[0] = 2+1\) 3
    2 \(h[0]x[2]+h[1]x[1] = 3+2\) 5
    3 \(h[0]x[3]+h[1]x[2] = 0+3\) 3
    \[ y_c = \{1,\ 3,\ 5,\ 3\} \]

    (b) 比较

    \[ y_c = \{1,3,5,3\} = y_{\text{lin}} \;\checkmark \]

    完全一致！

    原因：我们选的 \(N = 4\) 恰好等于 \(M+N-1 = 4\)， 满足「\(N \geq M+N_{\text{len}}-1\)」的条件，所以没有下标环绕。

    若 N 选得太小会怎样

    取 \(N = 3\)（小于 4）。此时下标要模 3，第 3 个输出会环绕回第 0 个位置：

    \[ y_c[0] = h[0]x[0]+h[1]x[2] = 1+3 = 4 \neq 1 \]

    结果：\(y_c = \{4, 3, 5\}\)——第 0 项被污染了（多了原本属于第 3 项的贡献）。

    这就是时域混叠。

    结论（用 FFT 做线性卷积的规则）：

    \[ L \geq M + N - 1 \]

    其中 \(L\) 是 FFT 长度。补零到 \(L\) 后再做 FFT，结果才正确。

    例题 4：加窗的效果¶

    信号含一个强分量（幅度 1）与一个弱分量（幅度 0.001，即 \(-60\) dB）。 用矩形窗与布莱克曼窗分别分析，说明为什么必须用后者。

    提示

    矩形窗旁瓣约 \(-13\) dB，布莱克曼约 \(-58\) dB。强信号的旁瓣会掩盖弱信号。

    解答

    用矩形窗

    强信号的旁瓣最高约 \(-13\) dB（相对主瓣）。

    强信号幅度 1 的旁瓣泄漏到弱信号频点附近时，其幅度约为

    \[ 10^{-13/20} \approx 0.22 \]

    而弱信号本身只有 \(0.001\)。

    \[ 0.22 \gg 0.001 \;\times \]

    弱信号完全被强信号的旁瓣掩盖 —— 检测不到。

    用布莱克曼窗

    旁瓣约 \(-58\) dB：

    \[ 10^{-58/20} \approx 0.00126 \]

    与弱信号幅度 0.001 同量级，仍然勉强。若用平顶窗或进一步降低旁瓣 （如 Kaiser 窗调参数），可以让旁瓣低于 \(-80\) dB，此时泄漏约 \(10^{-4}\)， 弱信号可以显现 ✓

    但代价是什么：

    窗 主瓣宽度（相对矩形）
    矩形 1 倍（最好分辨率）
    汉宁 / 汉明 2 倍
    布莱克曼 3 倍
    平顶 约 4–5 倍

    布莱克曼的主瓣宽 3 倍，意味着频率分辨率降低 3 倍。

    这就是「频谱分析」的核心权衡

    想检测 该怎么做
    靠得很近的两个强信号 用窄主瓣窗（矩形/汉宁）
    强信号旁的弱信号 用低旁瓣窗（布莱克曼/平顶）
    相位/频率精度优先 汉宁
    幅度精度优先 平顶

    没有一种窗能同时做到「高分辨率」与「低泄漏」—— 这是不确定性原理在频谱分析中的体现。

    实际工作中通常同时用两种窗试算，对比结果来避免误判。

    七、用在哪些课程里¶

    现代数字信号处理 · 数字频谱分析的核心工具¶

    任务 做法
    频谱分析 加窗 + FFT + 取模
    功率谱估计 Welch 法（分段、重叠 50%、平均）
    快速卷积 补零 + FFT + 相乘 + IFFT
    频域滤波 FFT → 乘 \(H[k]\) → IFFT
    系统辨识 用 \(H[k] = Y[k]/X[k]\) 估计频率响应

    关于频率分辨率的工程直觉

    「能分辨多近的两个频率」= 「看了多久」。

    这与傅里叶变换的时频不确定性是同一件事：

    \[ \Delta t\cdot\Delta f \gtrsim 1 \]
    场景 观测时长 分辨率
    语音一帧 20 ms 50 Hz
    音乐分析 0.5 s 2 Hz
    机械振动诊断 10 s 0.1 Hz
    精密频率计量 1000 s 1 mHz

    想分辨更精细的频率结构，只能测更久。

    智能传感与信息处理 · 传感器信号分析¶

    • FFT 频谱分析是振动、声音、电流等传感信号的常规手段
    • 加窗与重叠是工程实现的必备步骤（否则幅度出错）
    • 实时 FFT（滑动窗）用于在线监测
    • 分辨率选择取决于被测量的性质 （轴承故障特征频率间隔窄 → 需要长观测）

    海洋声学 · 声信号处理链¶

    • LOFAR 谱图：短时傅里叶变换得到的时频图，用于检测舰船线谱
    • 宽带 vs 窄带处理：窄带需要长观测以分辨线谱
    • DEMON 分析：包络谱，用 FFT 提取螺旋桨调制特征

    八、自测¶

    Q1 求 \(x = \{1, 0, 1, 0\}\) 的 4 点 DFT。

    提示

    只有 \(n = 0, 2\) 非零，\(W_4^{2k} = (-1)^k\)。

    解答
    \[ X[k] = 1\cdot W_4^0 + 1\cdot W_4^{2k} = 1 + (-1)^k \]
    \(k\) \((-1)^k\) \(X[k]\)
    0 1 2
    1 \(-1\) 0
    2 1 2
    3 \(-1\) 0
    \[ X = \{2,\ 0,\ 2,\ 0\} \]

    解读：频谱只有 \(k=0\)（直流）与 \(k=2\)（奈奎斯特频率）两个非零分量—— 因为 \(x = \{1,0,1,0\}\) 正是最高频序列 \((1,0)\) 的重复， 其频谱集中在 0 与 \(f_s/2\) ✓ 这与直觉一致。

    验证共轭对称：\(X[k]\) 全为实数（虚部为 0），符合实偶序列的频谱为实偶函数 ✓

    Q2 判断：把 \(N\) 点数据补零到 \(2N\) 点做 FFT，频率分辨率提高一倍。对吗？

    提示

    分辨率公式 \(\Delta f = 1/T\)，想想补零是否改变了 \(T\)。

    解答

    不对。

    分辨率由观测时长决定：

    \[ \Delta f = \frac{1}{T}, \qquad T = N T_s \]

    补零不改变实际观测时长（补的是零，不是新数据）， 所以 \(T\) 不变，真实分辨率不变。

    补零的效果：

    变化 是否发生
    频点数变多（曲线更光滑） ✓
    频点间隔 \(\Delta f_{\text{grid}}\) 变小 ✓
    真实分辨能力 ✗ 不变

    如何验证：观察两个邻近频率的峰。补零后峰的形状（主瓣宽度） 没有变化，只是采样点更密。若原本分辨不出，补零后仍分辨不出。

    正确提高分辨率的方法：延长观测时间（采集更多点）。

    Q3 为什么 FFT 能加速 DFT？它改变了变换的结果吗？

    提示

    想想分治利用了频谱的什么性质。

    解答

    为什么能加速：

    利用旋转因子的周期性与对称性：

    \[ W_N^{k(n+N/2)} = -W_N^{kn} \]

    这条对称性让「后半段频谱」可以用「前半段」加减得到， 不需要重新计算。于是每次把问题规模减半，递归下去得到 \(O(N\log N)\)。

    它不改变结果：

    FFT 与原 DFT 的数学定义完全相同，输出逐点一致（浮点误差范围内）。

    验证方法：

    import numpy as np
x = np.random.randn(8)
X1 = np.array([sum(x[n]*np.exp(-2j*np.pi*k*n/8) for n in range(8))
               for k in range(8)])   # 直接 DFT
X2 = np.fft.fft(x)                  # FFT
print(np.allclose(X1, X2))          # True

    两者的区别只在计算速度：

    复杂度 \(N = 10^6\) 的运算量
    直接 DFT \(O(N^2)\) \(\approx 10^{12}\)
    FFT \(O(N\log N)\) \(\approx 2\times10^7\)

    所以 FFT 是算法，不是新的变换。

    Q4 用 FFT 计算两个长度 100 的序列的线性卷积，FFT 长度至少取多少？为什么？

    提示

    回忆线性卷积的长度公式，以及循环卷积产生混叠的条件。

    解答

    至少取 \(L = 100+100-1 = 199\)。

    通常取 2 的整数次幂（FFT 效率最高），所以实际取

    \[ L = 256 \]

    为什么必须满足 \(L \geq M+N-1\)：

    长度 后果
    \(L < M+N-1\) 循环卷积的下标环绕 → 时域混叠，结果错误
    \(L \geq M+N-1\) 无环绕，循环卷积 = 线性卷积 ✓

    具体做法：

    1. 把 \(x\) 与 \(h\) 都补零到长度 256
    2. 分别做 256 点 FFT
    3. 频域相乘
    4. IFFT 得到 199 个有效结果（后 57 个是零，因补零产生）

    为什么值得这样做：

    方法 复杂度（\(M=N=100\)）
    直接卷积 \(100\times100 = 10^4\)
    FFT 法 \(\approx 3\times256\log_2 256 \approx 6\times10^3\)

    本例优势不大（序列太短），但序列越长优势越明显：

    \(N\) 直接 \(O(N^2)\) FFT \(O(N\log N)\) 加速比
    100 \(10^4\) \(6\times10^3\) 1.7×
    1000 \(10^6\) \(10^4\) 100×
    \(10^6\) \(10^{12}\) \(2\times10^7\) 5 万×

    工程实践：超过约 50–100 点就改用 FFT 法（可用「重叠相加/重叠保留」 处理超长序列的分段卷积）。
