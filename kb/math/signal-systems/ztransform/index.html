    Z 变换与滤波器¶

    前面处理的是连续信号，用拉普拉斯变换与傅里叶变换。

    这一页引入离散信号对应的工具：Z 变换。它的地位与拉普拉斯变换相当， 但更适合数字系统。

    先给对照表，建立整体认识：

    连续时间 离散时间 作用
    拉普拉斯变换 \(s\) Z 变换 \(z\) 复频域分析、稳定性判据
    傅里叶变换 \(\omega\) DTFT \(e^{j\omega}\) 频域响应
    微分方程 差分方程 系统描述
    极点（左半平面） 极点（单位圆内） 稳定性

    为什么需要 Z 变换（而不只用傅里叶变换）

    傅里叶变换只处理「稳定」信号（要求积分/求和收敛）。

    例如 \(x[n] = 2^n u[n]\) 增长，其傅里叶变换不收敛。 但 Z 变换引入一个收敛因子 \(r^{-n}\) 后仍可分析：

    \[ \mathcal{Z}\{x[n]\} = \sum_n x[n]z^{-n}, \qquad z = re^{j\omega} \]

    这扩大了可分析的范围，也让「稳定性」有了清晰的几何判据（极点位置）。

    一、Z 变换的定义¶

    双边 Z 变换：

    \[ X(z) = \sum_{n=-\infty}^{\infty} x[n]\,z^{-n} \]

    单边 Z 变换（工程常用，从 \(n=0\) 开始）：

    \[ X(z) = \sum_{n=0}^{\infty} x[n]\,z^{-n} \]

    其中 \(z\) 是复变量。

    关键理解：\(z^{-1}\) 是「延迟算子」¶

    看一个简单情形：\(x[n] = \delta[n-k]\)（在 \(n=k\) 处为 1），则

    \[ X(z) = \sum_n \delta[n-k]z^{-n} = z^{-k} \]

    所以「延迟 \(k\) 个采样」对应「乘 \(z^{-k}\)」。

    这解释了为什么差分方程能变成代数方程：

    \[ y[n] - 0.5y[n-1] = x[n] \quad\Longrightarrow\quad Y(z) - 0.5z^{-1}Y(z) = X(z) \]
    \[ \Longrightarrow\quad H(z) = \frac{Y(z)}{X(z)} = \frac{1}{1-0.5z^{-1}} \]

    这是 Z 变换最大的实用价值

    差分方程（时域，递归）→ 代数方程（z 域，多项式）

    时域 z 域
    卷积 \(y = h*x\) 相乘 \(Y = HX\)
    差分方程 有理函数 \(H(z)\)
    稳定性 极点位置

    系统分析从「解递归方程」变成「分析多项式的根」——容易得多。

    收敛域（ROC）¶

    Z 变换是无穷级数，只在某些 \(z\) 上收敛。这个集合叫收敛域。

    同一个 X(z) 可能对应不同的 x[n]

    Z 变换必须连同收敛域一起给出，否则不唯一。

    例：\(x_1[n] = a^nu[n]\)（右边序列）与 \(x_2[n] = -a^nu[-n-1]\)（左边序列） 给出同一个代数表达式

    \[ X(z) = \frac{1}{1-az^{-1}} \]

    但收敛域不同：\(x_1\) 的 ROC 是 \(\lvert z\rvert > \lvert a\rvert\)， \(x_2\) 的是 \(\lvert z\rvert < \lvert a\rvert\)。

    序列类型 收敛域形状
    有限长 整个 z 平面（可能除 0 或 ∞）
    右边（因果） \(\lvert z\rvert > r_0\)（半径外的区域）
    左边（反因果） \(\lvert z\rvert < r_0\)（半径内的区域）
    双边 环形 \(r_1 < \lvert z\rvert < r_2\)

    二、常用变换对¶

    \(x[n]\) \(X(z)\) 收敛域
    \(\delta[n]\) \(1\) 全平面
    \(\delta[n-k]\) \(z^{-k}\) 全平面（除 0/∞）
    \(u[n]\) \(\dfrac{1}{1-z^{-1}}\) \(\lvert z\rvert > 1\)
    \(a^nu[n]\) \(\dfrac{1}{1-az^{-1}}\) \(\lvert z\rvert > \lvert a\rvert\)
    \(na^nu[n]\) \(\dfrac{az^{-1}}{(1-az^{-1})^2}\) \(\lvert z\rvert > \lvert a\rvert\)
    \(\cos(\omega_0n)u[n]\) \(\dfrac{1-z^{-1}\cos\omega_0}{1-2z^{-1}\cos\omega_0+z^{-2}}\) \(\lvert z\rvert > 1\)

    常用性质¶

    性质 时域 z 域
    线性 \(ax_1+bx_2\) \(aX_1+bX_2\)
    时移 \(x[n-k]\) \(z^{-k}X(z)\)
    卷积 \(x*h\) \(X(z)H(z)\)
    z 域微分 \(nx[n]\) \(-z\dfrac{\mathrm{d}X}{\mathrm{d}z}\)
    初值 \(x[0]\) \(\lim_{z\to\infty}X(z)\)

    由常用对得到「极点决定衰减速度」

    看 \(a^nu[n]\) 的变换 \(1/(1-az^{-1})\)：

    • 极点在 \(z = a\)
    • 序列衰减速度由 \(\lvert a\rvert\) 决定

    两者的对比如下：

    \(\lvert a\rvert\) 序列行为
    \(< 1\) 衰减 → 稳定
    \(= 1\) 不衰减（等幅）→ 临界
    \(> 1\) 增长 → 不稳定

    所以「极点是否在单位圆内」就是稳定性判据（下面第四节详述）。

    三、由差分方程求系统函数¶

    一般形式（线性常系数差分方程）：

    \[ \sum_{k=0}^{N} a_k\,y[n-k] = \sum_{m=0}^{M} b_m\,x[n-m] \]

    两边取 Z 变换（用时移性质 \(x[n-k]\leftrightarrow z^{-k}X(z)\)）：

    \[ \sum_k a_k z^{-k}Y(z) = \sum_m b_m z^{-m}X(z) \]

    于是系统函数：

    \[ \boxed{\ H(z) = \frac{Y(z)}{X(z)} = \frac{\sum_{m=0}^{M}b_mz^{-m}}{\sum_{k=0}^{N}a_kz^{-k}}\ } \]

    这是两个多项式之比，所以：

    \[ H(z) = \frac{B(z)}{A(z)} \]
    • 零点：\(B(z) = 0\) 的根 → 该频率被抑制
    • 极点：\(A(z) = 0\) 的根 → 该频率被放大（可能不稳定）

    四、稳定性的几何判据（重点）¶

    定理：因果 LTI 系统稳定 当且仅当所有极点在单位圆内：

    \[ \lvert p_i\rvert < 1 \quad \text{对每个极点 } p_i \]

    直觉：由第二节，\(a^nu[n]\) 的极点在 \(z=a\)。 所以「极点 \(a\) 对应衰减 \(a^n\)」——\(a\) 在单位圆内就意味着衰减。

    对照连续时间：为什么是「左半平面」vs「单位圆内」

    连续 离散
    基本衰减 \(e^{-\alpha t}\)（\(\alpha > 0\)） \(a^n\)（\(\lvert a\rvert<1\)）
    映射 \(s = -\alpha\)（左半平面） \(z = a\)（单位圆内）
    判据 \(\operatorname{Re}(s) < 0\) \(\lvert z\rvert < 1\)

    两者的关系：\(z = e^{sT_s}\)。

    左半平面 \(s\) 映射到单位圆内 \(z\)（关键的保稳性映射）。

    这也解释了傅里叶变换的地位： 令 \(z = e^{j\omega}\)（即 \(z\) 在单位圆上），Z 变换就退化为 DTFT：

    \[ X(e^{j\omega}) = \sum_n x[n]e^{-j\omega n} \]

    单位圆就是「频率轴」。

    频率响应的几何求法¶

    在单位圆上取 \(z = e^{j\omega}\)，则

    \[ H(e^{j\omega}) = \frac{\prod_{m}(e^{j\omega}-z_m)}{\prod_{k}(e^{j\omega}-p_k)} \]

    （\(z_m\) 为零点，\(p_k\) 为极点。）

    几何意义：\(\lvert H\rvert\) 是「到各零点的距离之积」除以「到各极点的距离之积」。

    频率点靠近… 效果
    极点 分母小 → 幅度大（峰）
    零点 分子小 → 幅度小（谷）

    这给出了「凭图读频率响应」的技能

    看到极点零点图就能大致判断频率响应：

    • 极点在单位圆内靠近圆 → 该频率附近共振峰
    • 零点在单位圆上 → 该频率完全阻断
    • 极点在圆上 → 临界振荡（不稳定）

    这是滤波器设计的基本直觉。

    五、两类滤波器：FIR 与 IIR¶

    类型 全称 \(H(z)\) 形式 冲激响应
    FIR 有限冲激响应 只有分子（\(A(z)=1\)） 有限长
    IIR 无限冲激响应 有分母（极点） 无限长

    FIR 滤波器¶

    \[ H(z) = \sum_{m=0}^{M}b_mz^{-m} \]

    时域实现（就是卷积）：

    \[ y[n] = \sum_{m=0}^{M}b_m\,x[n-m] \]

    两类滤波器的权衡¶

    维度 FIR IIR
    冲激响应 有限长 无限长
    稳定性 总是稳定（无极点，除 \(z=0\)） 需要检查极点位置
    实现 直接卷积，需 \(M\) 次乘法 递归，乘法次数少
    线性相位 容易做到（系数对称即可） 很难精确做到
    实现同性能的阶数 较高 较低（更省算力）
    设计难度 简单直观 需要映射（如双线性变换）

    选型建议

    需求 选择
    要求波形保真（线性相位） FIR
    算力/延迟受限（同等指标） IIR
    要求绝对稳定 FIR
    需要极窄过渡带 IIR（阶数低得多）

    音频通常用 FIR（相位失真可以听出来）； 成本敏感的嵌入式常用 IIR。

    六、典型例题¶

    例题 1：由差分方程求系统函数与稳定性¶

    系统满足

    \[ y[n] = 0.8\,y[n-1] + x[n] \]

    (a) 求 \(H(z)\)。

    (b) 求极点，判断稳定性。

    © 求 \(h[n]\)。

    思路

    两边取 Z 变换（用 \(y[n-1]\leftrightarrow z^{-1}Y(z)\)），解出 \(H = Y/X\)。

    解答

    (a) 求系统函数

    取 Z 变换：

    \[ Y(z) = 0.8z^{-1}Y(z) + X(z) \]

    移项：

    \[ Y(z)(1-0.8z^{-1}) = X(z) \]
    \[ H(z) = \frac{Y(z)}{X(z)} = \frac{1}{1-0.8z^{-1}} \]

    还可以写成（分子分母乘 \(z\)）：

    \[ H(z) = \frac{z}{z-0.8} \]

    (b) 极点与稳定性

    令分母为零：\(z - 0.8 = 0\)，得极点 \(z = 0.8\)。

    因为 \(\lvert 0.8\rvert < 1\)，极点在单位圆内，所以稳定

    © 冲激响应

    对照常用变换对 \(a^nu[n]\leftrightarrow\frac{1}{1-az^{-1}}\)，

    \[ \boxed{\ h[n] = (0.8)^n u[n]\ } \]

    验证衰减：\(h[0]=1\)，\(h[1]=0.8\)，\(h[2]=0.64\)… 确实衰减 与稳定性结论一致。

    这个系统的实际意义

    \(y[n] = 0.8y[n-1] + x[n]\) 是一阶 IIR 低通滤波器（指数平滑）。

    用途： - 传感器数据平滑（抑制噪声） - 指数移动平均（EMA）（金融、监控指标） - 一阶动态系统的离散化

    \(\lvert a\rvert\) 越接近 1，平滑越强（但响应越慢）： - \(a = 0.8\)：响应较快 - \(a = 0.99\)：很平滑但滞后明显

    这就是平滑度与响应延迟的权衡。

    例题 2：判断极点位置与稳定性¶

    系统函数

    \[ H(z) = \frac{z+1}{z^2 - 0.9z + 0.2} \]

    判断稳定性。

    提示

    求分母的根，看模是否都小于 1。

    解答

    求极点（解 \(z^2-0.9z+0.2=0\)）：

    \[ z = \frac{0.9 \pm \sqrt{0.81-0.8}}{2} = \frac{0.9\pm\sqrt{0.01}}{2} = \frac{0.9\pm0.1}{2} \]
    \[ p_1 = 0.5, \qquad p_2 = 0.4 \]

    判断：

    \[ \lvert p_1\rvert = 0.5 < 1, \qquad \lvert p_2\rvert = 0.4 < 1 \]

    两个极点都在单位圆内 → 稳定

    零点：\(z+1=0\)，得 \(z = -1\)（在单位圆上）。

    频率响应特征：

    频率 分析
    直流（\(z=1\)） \(\lvert H\rvert = \frac{2}{1-0.9+0.2} = \frac{2}{0.3} \approx 6.67\)（大）
    奈奎斯特（\(z=-1\)） 分子为 0 → \(\lvert H\rvert = 0\)（完全阻断）

    所以这是一个低通滤波器，且在高频处完全阻断。

    极点靠近单位圆的程度决定峰的高度： 这里极点在 0.5、0.4（离圆较远），所以峰值不尖锐。 若极点移到 0.95，直流附近会有很尖的共振峰。

    判断二阶系统稳定性的快速方法

    对 \(z^2 + a_1z + a_0 = 0\)，稳定的充要条件（Jury 判据的 \(n=2\) 情形）：

    \[ \lvert a_0\rvert < 1, \qquad 1 + a_1 + a_0 > 0, \qquad 1 - a_1 + a_0 > 0 \]

    本例中 \(a_1 = -0.9\)，\(a_0 = 0.2\)：

    • \(\lvert 0.2\rvert < 1\)
    • \(1 + (-0.9) + 0.2 = 0.3 > 0\)
    • \(1 - (-0.9) + 0.2 = 2.1 > 0\)

    三条都满足 → 稳定 ✓ 与直接求根一致。

    不用求根就能判断，这对高阶系统很有价值（求根可能数值不稳）。

    例题 3：FIR 滤波器的频率响应¶

    设 \(h[n] = \{0.5,\ 0.5\}\)（两点滑动平均）。求 \(H(z)\) 与频率响应，并说明其功能。

    思路

    求 Z 变换，代入 \(z=e^{j\omega}\)，分析幅度响应。

    解答

    求 \(H(z)\)：

    \[ H(z) = 0.5 + 0.5z^{-1} = 0.5\frac{z+1}{z} \]

    零点：\(z = -1\)（单位圆上，对应奈奎斯特频率）。

    极点在 \(z=0\)（由 \(1/z\) 产生），在单位圆内 → 稳定。

    频率响应（令 \(z = e^{j\omega}\)）：

    \[ H(e^{j\omega}) = 0.5 + 0.5e^{-j\omega} \]

    提取相位因子：

    \[ = 0.5e^{-j\omega/2}\left(e^{j\omega/2}+e^{-j\omega/2}\right) = e^{-j\omega/2}\cos\!\left(\frac{\omega}{2}\right) \]

    所以

    \[ \boxed{\ \lvert H(e^{j\omega})\rvert = \left\lvert\cos\frac{\omega}{2}\right\rvert\ } \]

    频率响应分析：

    频率 \(\omega\) \(\lvert H\rvert\) 效果
    \(0\)（直流） \(\lvert\cos 0\rvert = 1\) 完全通过 ✓
    \(\pi/2\) \(\lvert\cos(\pi/4)\rvert = 0.707\) 通过约 70%
    \(\pi\)（奈奎斯特） \(\lvert\cos(\pi/2)\rvert = 0\) 完全阻断 ✓

    结论：低通滤波器（通过低频，阻断高频）。

    物理验证：

    • 输入常数 \(x[n]=C\)：\(y[n] = 0.5C+0.5C = C\) → 不变 ✓（直流通过）
    • 输入 \(x[n]=(-1)^n\)：\(y[n] = 0.5(-1)^n + 0.5(-1)^{n-1} = 0.5(-1)^n - 0.5(-1)^n = 0\) → 被消除

    这是最简单的平滑滤波器，但有相位延迟

    输出可以写成

    \[ y[n] = 0.5x[n]+0.5x[n-1] \]

    注意相位：\(H = e^{-j\omega/2}\cos(\omega/2)\) 中的 \(e^{-j\omega/2}\) 表示半个采样的延迟。所以输出相对输入滞后 0.5 个采样。

    这是 FIR 的通病：对称 FIR 的延迟为 \((N-1)/2\) 个采样 （\(N\) 为系数个数）。本例 \(N=2\)，延迟 0.5

    好处是线性相位：延迟对所有频率都一样，所以波形不失真 （只是整体平移）。这正是一个采样、音频处理中重视的性质。

    改进方向：为减少振铃，可以用加权平均（如高斯窗）代替等权平均。

    例题 4：从 \(H(z)\) 读频率响应¶

    系统 \(H(z) = 1 - z^{-1}\)（一阶差分）。求幅度响应，判断滤波器类型。

    提示

    代入 \(z = e^{j\omega}\)，用三角函数化简。

    解答
    \[ H(e^{j\omega}) = 1 - e^{-j\omega} \]

    提取因子：

    \[ = e^{-j\omega/2}\left(e^{j\omega/2}-e^{-j\omega/2}\right) = e^{-j\omega/2}\cdot 2j\sin\!\left(\frac{\omega}{2}\right) \]

    所以

    \[ \lvert H(e^{j\omega})\rvert = 2\left\lvert\sin\frac{\omega}{2}\right\rvert \]

    频率响应分析：

    频率 \(\lvert H\rvert\) 效果
    \(0\)（直流） \(2\lvert\sin 0\rvert = 0\) 完全阻断 ✓
    \(\pi/2\) \(2\sin(\pi/4) \approx 1.41\) 通过
    \(\pi\)（奈奎斯特） \(2\sin(\pi/2) = 2\) 最大增益 ✓

    结论：高通滤波器（阻断低频，通过高频）。

    零点在 \(z = 1\)（单位圆上）—— 对应 \(\omega = 0\)， 所以直流被完全阻断 ✓（零点位置与阻断频率对应。）

    与上一题对照：

    滤波器 \(h[n]\) 零点 类型
    滑动平均 \(\{0.5, 0.5\}\) \(z=-1\) 低通
    差分 \(\{1, -1\}\) \(z=1\) 高通

    两者恰好互补：一个阻断高频、一个阻断低频。

    组合起来：把两者级联（卷积），得

    \[ H_{\text{总}} = (0.5+0.5z^{-1})(1-z^{-1}) = 0.5 - 0.5z^{-2} \]

    即 \(h = \{0.5, 0, -0.5\}\)，这是带通（回忆卷积那一页的例题 4， 那里用的是未归一化的 \(\{1,1\}\)，结论相同）。

    差分对噪声的影响

    差分是高通，所以它对高频噪声有放大作用：

    \[ \text{高频处增益} \to 2 \]

    而噪声通常富含高频成分。这解释了前一页（傅里叶）提到的 「数值微分对噪声敏感」。

    实践做法：先低通（平滑）再差分，形成带通 + 平滑的组合。

    现代数字信号处理 · 系统分析与设计的核心工具¶

    任务 Z 变换的作用
    系统分析 由差分方程得 \(H(z)\)，读极点零点
    稳定性判断 极点是否都在单位圆内
    频率响应 令 \(z=e^{j\omega}\)
    滤波器设计 指定 \(H(z)\) 的极点零点布局
    逆系统 \(1/H(z)\)（注意零点变极点，可能不稳定）

    智能传感与信息处理 · 实时滤波与状态估计¶

    • 嵌入式滤波器：传感器数据流上的一阶/二阶 IIR（计算量极小）
    • 互补滤波：加速度计与陀螺仪的融合， 本质是「一个高通 + 一个低通」组合，与例题 4 同源
    • 卡尔曼滤波的稳态形式：稳态时退化为一个固定的 IIR 滤波器
    • 信号的动态补偿：传感器带宽不足时用逆系统部分补偿 （但要小心 \(1/H\) 可能不稳定）

    海洋声学 · 声信号处理链¶

    • 带通滤波：水声信号通常在特定频段，需滤除海洋环境噪声
    • 匹配滤波器：与发射波形匹配，其 \(H(z)\) 为时间反转共轭
    • 混响抑制：利用信号的动态特性设计自适应滤波器

    八、自测¶

    Q1 求 \(x[n] = 0.5^nu[n]\) 的 Z 变换与收敛域。

    提示

    这是几何级数，公比 \(0.5z^{-1}\)。

    解答
    \[ X(z) = \sum_{n=0}^{\infty}0.5^nz^{-n} = \sum_{n=0}^{\infty}\left(0.5z^{-1}\right)^n \]

    这是几何级数，公比 \(q = 0.5z^{-1}\)，收敛条件 \(\lvert q\rvert < 1\)：

    \[ \lvert 0.5z^{-1}\rvert < 1 \iff \lvert z\rvert > 0.5 \]

    求和：

    \[ \boxed{\ X(z) = \frac{1}{1-0.5z^{-1}}, \qquad \lvert z\rvert > 0.5\ } \]

    收敛域是半径 0.5 的圆外区域

    为什么 ROC 是这样的：序列是「右边序列」（\(n \geq 0\)）， 所以 ROC 是「最外极点之外的区域」。

    极点在 \(z = 0.5\)（分母为零处），ROC 的边界正是这个极点 —— ROC 从不包含极点（这是 Z 变换的一条基本性质）。

    Q2 系统 \(H(z) = \frac{1}{1-1.5z^{-1}}\) 是否稳定？

    提示

    看极点模长。

    解答

    不稳定。

    极点在 \(z = 1.5\)，\(\lvert 1.5\rvert > 1\)，在单位圆外 ✗

    对应的冲激响应：

    \[ h[n] = (1.5)^n u[n] \]

    这是指数增长，显然不稳定 ✓ 与判据一致。

    注意：这个系统的 \(H(z)\) 代数表达式与 \(H(z) = \frac{1}{1-0.5z^{-1}}\) 形式相同（只是 \(a\) 不同）， 但稳定性完全不同 —— 所以判断稳定必须看极点的具体位置。

    如果一定要用这个系统，可以： 1. 减小增益（把极点移进单位圆） 2. 加反馈补偿 3. 用 FIR 近似期望特性

    Q3 判断：FIR 滤波器一定稳定吗？为什么？

    提示

    FIR 的 \(H(z)\) 有没有非零极点？

    解答

    一定稳定。

    FIR 的 \(H(z)\) 形如

    \[ H(z) = \sum_{m=0}^{M}b_mz^{-m} = \frac{b_0z^M + b_1z^{M-1}+\cdots+b_M}{z^M} \]

    极点全在 \(z = 0\)（分母 \(z^M = 0\)）。

    而 \(\lvert 0\rvert = 0 < 1\)，所以所有极点都在单位圆内 → 必然稳定

    直观理由：FIR 的冲激响应有限长（只有 \(M+1\) 个非零值）， 所以

    \[ \sum_n\lvert h[n]\rvert = \sum_{m=0}^{M}\lvert b_m\rvert < \infty \]

    （有限项之和必然有限）→ 满足 BIBO 稳定条件

    这是 FIR 的一大优势：无需担心稳定性问题， 调试时可以放心（不会因为参数不小心而发散）。

    IIR 则相反：参数稍有偏差就可能让极点跑出单位圆。

    Q4 一个滤波器的极点在 \(z = 0.98\)，零点在 \(z = -1\)。 预测它的频率响应特征。

    提示

    极点在单位圆内但很靠近圆（\(0.98\)）；零点在单位圆上。

    解答

    极点靠近 \(z=0.98\)（正实轴，对应低频 \(\omega \approx 0\)）：

    → 低频处增益很大，形成尖锐的共振峰

    零点在 \(z = -1\)（对应奈奎斯特频率 \(\omega = \pi\)）：

    → 高频处完全阻断

    所以这是一个「窄带低通」滤波器（截止很陡，通带很窄）。

    定量估计峰高：在 \(\omega=0\) 处（\(z=1\)）：

    \[ \lvert H(1)\rvert = \frac{\lvert 1+1\rvert}{\lvert 1-0.98\rvert} = \frac{2}{0.02} = 100 \]

    增益 100 倍（40 dB）—— 这是一个很强的共振。

    实际影响：

    方面 说明
    优点 能强效提取低频信号
    风险 对低频噪声同样放大 100 倍
    副作用 响应很慢（时间常数 \(\approx 1/(1-0.98) = 50\) 个采样）
    数值风险 系数量化误差可能让极点移出单位圆

    设计经验：极点越靠近单位圆，选择性越好但越危险。 工程上通常限制 \(\lvert p\rvert \leq 0.99\)， 并检查定点实现下的精度影响。
