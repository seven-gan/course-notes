    常微分方程的数值解法¶

    前四页讲的都是「能求出解析解」的情形。但实践中：

    绝大多数 ODE 没有解析解，必须数值求解。

    这一页讲数值解法，以及为什么它们会失败（这是更重要的部分）。

    一句话抓住核心：精度与稳定性的双重约束

    数值解法的两大要求：

    要求 含义 违反的后果
    精度（精度阶） 步长 \(h\to0\) 时误差如何减小 结果不准
    稳定性 步长过大时是否发散 结果爆炸 ✗

    关键洞察：稳定性比精度更致命 ✓

    情形 后果
    精度不足 结果有小误差（可接受）
    不稳定 结果完全无意义（甚至溢出） ✗

    本页的主线：从 Euler 到 RK4 再到隐式方法， 每一步都在解决「精度」或「稳定性」的某个问题。

    一、初值问题与 Euler 法¶

    问题形式¶

    \[ y' = f(t,y),\qquad y(t_0) = y_0 \]

    目标：求 \(y(t)\) 在离散时刻 \(t_0,t_1,\dots\) 的近似值。

    显式 Euler 法¶

    用一阶泰勒展开（回顾「泰勒展开」一页）：

    \[ y(t+h) = y(t)+hy'(t)+O(h^2) \]

    代入 \(y' = f(t,y)\)：

    \[ \boxed{\ y_{n+1} = y_n+h\,f(t_n,y_n)\ } \]

    Euler 法的几何含义与两个误差来源

    几何含义：沿当前点的切线方向前进一步

    特点 说明
    单步法 只需 \(y_n\)
    显式 可直接算出 \(y_{n+1}\) ✓
    一阶精度 局部误差 \(O(h^2)\)，全局 \(O(h)\)

    两个误差来源（都要知道）：

    来源 1：截断误差（方法本身的）

    \[ \text{局部截断误差} = \frac{h^2}{2}y''(\xi) = O(h^2) \]

    全局误差（累积 \(n = T/h\) 步）：

    \[ O(h^2)\times\frac{T}{h} = O(h) \]

    所以 Euler 是「一阶方法」 —— \(h\) 减半，误差也减半

    来源 2：舍入误差（浮点导致的）

    \(h\) 截断误差 舍入误差 总误差
    大 大 ✗ 小 大
    小 小 大（步数多，累积多）✗ 大
    最优 —— —— 存在最优 \(h\)

    舍入误差的量级：

    \[ \text{舍入误差}\sim\frac{\epsilon_{\text{mach}}}{h} \]

    （步数 \(\propto1/h\)，每步舍入 \(\sim\epsilon_{\text{mach}}\)。）

    最优步长的估算（令两者平衡）。

    写成一阶方法（\(p = 1\)）的完整形式：

    \[ \text{总误差} \approx \underbrace{Ch}_{\text{截断}} + \underbrace{\frac{\epsilon_{\text{mach}}}{h}}_{\text{舍入}} \]

    令两项相等 \(Ch = \epsilon_{\text{mach}}/h\)，得

    \[ h^* = \sqrt{\frac{\epsilon_{\text{mach}}}{C}} \]

    注意这里有个常数 \(C\) —— 它由方程与方法共同决定， 不能一概而论。取 \(C = 1\) 时 \(h^* \approx 1.49\times10^{-8}\)； 取 \(C = 10^{-2}\) 时 \(h^* \approx 1.49\times10^{-7}\)。

    \(C\) \(h^* = \sqrt{\epsilon/C}\) 最小总误差 \(\approx 2\sqrt{\epsilon C}\)
    \(1\) \(1.49\times10^{-8}\) \(2.98\times10^{-8}\)
    \(10^{-2}\) \(1.49\times10^{-7}\) \(2.98\times10^{-9}\)
    \(10^{-4}\) \(1.49\times10^{-6}\) \(2.98\times10^{-10}\)

    含义：\(h\) 小到 \(10^{-7}\) 量级后，舍入误差开始与截断误差相当； 再小到 \(10^{-11}\) 以下就被舍入完全主导 ✗

    具体分解（取 \(C = 10^{-2}\)）：

    \(h\) 截断 \(\approx Ch\) 舍入 \(\approx \epsilon/h\) 主导项
    \(10^{-4}\) \(1.0\times10^{-6}\) \(2.2\times10^{-12}\) 截断
    \(10^{-7}\) \(1.0\times10^{-9}\) \(2.2\times10^{-9}\) 相当（接近最优）
    \(10^{-11}\) \(1.0\times10^{-13}\) \(2.2\times10^{-5}\) 舍入（误差反而变大）

    它与「数值计算」模块的「数值微分」一页是同一个权衡 —— 都是「截断误差随 \(h\) 下降、舍入误差随 \(h\) 上升」， 最优点都出现在 \(h \sim \sqrt{\epsilon}\) 附近。

    改进 Euler 法（Heun 法）¶

    问题：Euler 法只用起点斜率，忽略了这步中斜率的变化。

    改进：用起点与终点斜率的平均：

    \[ \tilde y_{n+1} = y_n+hf(t_n,y_n)\quad\text{（预测）} \]
    \[ y_{n+1} = y_n+\frac h2\left[f(t_n,y_n)+f(t_{n+1},\tilde y_{n+1})\right]\quad\text{（校正）} \]

    「预测-校正」结构的价值

    两步的含义：

    步骤 作用
    预测 用 Euler 估一个终点
    校正 用两点的斜率平均重新算

    改进的效果：

    方法 精度阶
    Euler \(O(h)\)
    改进 Euler \(O(h^2)\) ✓

    为什么精度提高：梯形公式（对 \(y'\) 的积分用梯形近似）

    \[ y(t+h)-y(t) = \int_t^{t+h}f\,\mathrm{d}s\approx\frac h2[f(t)+f(t+h)] \]

    梯形公式的误差是 \(O(h^3)\)（局部）→ 全局 \(O(h^2)\)

    代价：每步要算两次 \(f\)（起点与预测终点）。

    一个重要的实用性质：改进 Euler 可以估计误差

    \[ \text{误差估计}\approx\lvert y_{n+1}-\tilde y_{n+1}\rvert \]

    但必须说清它估计的是「谁的」误差 —— 这个差值估计的是预测值（即 Euler 一步）的误差， 不是校正值的误差。

    定量验证（\(y' = -2y\)、\(y(0)=1\)、\(h = 0.1\)，真解 \(e^{-0.2} = 0.81873075\)）：

    量 数值 与真实局部误差的比
    预测值 \(\tilde y_1\) \(0.800000\) —
    校正值 \(y_1\) \(0.820000\) —
    \(\lvert y_1 - \tilde y_1\rvert\) \(0.020000\) —
    预测值的真实误差 \(\lvert\tilde y_1 - y(t_1)\rvert\) \(0.018731\) \(1.068\) ✓
    校正值的真实误差 \(\lvert y_1 - y(t_1)\rvert\) \(0.001269\) \(15.76\) ✗

    差值 \(0.02\) 与预测值的误差 \(0.018731\) 几乎相等（比值 \(1.068\)）， 但比校正值的误差大 \(15.76\) 倍。

    为什么：设校正值为精确解的近似，则 \(\lvert y_1 - \tilde y_1\rvert \approx\) （预测值误差 \(-\) 校正值误差），而预测值的误差大一个 \(h\) 阶， 所以差值主要由预测值误差决定。

    随 \(h\) 变化也能看出这一点：

    \(h\) \(\lvert y_1-\tilde y_1\rvert\) / 预测值误差 \(\lvert y_1-\tilde y_1\rvert\) / 校正值误差
    \(0.20\) \(1.138\) \(8.26\)
    \(0.10\) \(1.068\) \(15.76\)
    \(0.05\) \(1.034\) \(30.75\)
    \(0.01\) \(1.007\) \(150.75\)

    第一列随 \(h \to 0\) 趋近于 1，第二列却发散 —— 这确证了「差值估计的是预测值的误差」。

    工程含义：这个性质仍然很有用，因为

    用法 说明
    作为相对指标 \(\lvert y_{n+1}-\tilde y_{n+1}\rvert\) 与误差同阶（都是 \(O(h^{2})\) 局部）
    控制步长 只要它超过容差就减小 \(h\) ✓
    估计绝对误差 需要除以 \((2^{p}-1)\) 等因子（见下）

    要得到校正值的误差估计，应使用 Richardson 型的修正（对 \(p\) 阶方法）：

    \[ \text{误差估计} \approx \frac{\lvert y_{n+1}-\tilde y_{n+1}\rvert}{2^{p}-1} \]

    二、Runge-Kutta 方法¶

    RK4：经典的四阶方法¶

    \[ \boxed{\ y_{n+1} = y_n+\frac h6(k_1+2k_2+2k_3+k_4)\ } \]

    其中：

    \[ k_1 = f(t_n,\ y_n) \]
    \[ k_2 = f\left(t_n+\frac h2,\ y_n+\frac h2k_1\right) \]
    \[ k_3 = f\left(t_n+\frac h2,\ y_n+\frac h2k_2\right) \]
    \[ k_4 = f(t_n+h,\ y_n+hk_3) \]

    RK4 的「加权平均」结构（Simpson 法则的类比）

    权重是 \(1:2:2:1\)（除以 6）——这正是 Simpson 法则的权重

    方法 权重模式
    梯形（改进 Euler） \(1:1\)（两点）
    Simpson / RK4 \(1:4:1\) 或 \(1:2:2:1\)

    含义：RK4 与 Simpson 法则同源 —— 都在用「更多采样点 + 合适的权重」逼近积分

    四个 \(k\) 的含义：

    \(k\) 在何处算斜率
    \(k_1\) 起点
    \(k_2\) 中点（用 \(k_1\) 预测）
    \(k_3\) 中点（用 \(k_2\) 预测）
    \(k_4\) 终点（用 \(k_3\) 预测）

    精度：

    方法 每步 \(f\) 求值次数 全局精度
    Euler \(1\) \(O(h)\)
    改进 Euler \(2\) \(O(h^2)\)
    RK4 \(4\) \(O(h^4)\) ✓

    「性价比」的对比（重要）：

    要把误差降到 \(10^{-6}\)：

    方法 需要 \(h\) 需要步数（\(T=1\)） 需要 \(f\) 求值次数
    Euler \(10^{-6}\) \(10^6\) \(10^6\) ✗
    改进 Euler \(10^{-3}\) \(10^3\) \(2\times10^3\)
    RK4 \(10^{-1.5}\approx0.032\) \(\approx31\) \(4\times31 = 124\) ✓

    RK4 只需 124 次求值，Euler 要 \(10^6\) 次 —— 效率差约 \(8000\) 倍

    这就是「RK4 是工程标准选择」的原因： 它在「每步成本」与「所需步数」之间取得很好的平衡。

    自适应步长（RK45）¶

    思路：同时用 4 阶和 5 阶方法，用两者之差估计误差， 据此调整 \(h\)。

    \[ \text{误差}\approx\lvert y^{(5)}-y^{(4)}\rvert \]
    情形 调整
    误差 < 容差 增大 \(h\)（可以更大步）✓
    误差 > 容差 减小 \(h\) 并重做本步 ✗

    工程价值：

    情形 自适应步长的优势
    解变化平缓 用大步长（省时间）✓
    解变化剧烈（如刚性问题、突跳） 自动用小步长（保精度）✓

    这就是「为什么现代 ODE 求解器都默认自适应」

    三、稳定性与刚性方程¶

    稳定性的概念¶

    用最简单的测试方程（这是标准做法）：

    \[ y' = \lambda y,\qquad \operatorname{Re}(\lambda)<0 \]

    真解：\(y(t) = y_0e^{\lambda t}\) → 单调衰减到零

    数值解应该也衰减。若不衰减反而增长 → 不稳定 ✗

    对 Euler 法：

    \[ y_{n+1} = y_n+h\lambda y_n = (1+h\lambda)y_n \]

    稳定条件：

    \[ \lvert1+h\lambda\rvert<1 \]

    Euler 法的稳定区域很小（这是关键限制）

    设 \(\lambda\) 为负实数（\(\lambda = -a\)，\(a>0\)）：

    \[ \lvert1-ha\rvert<1 \implies 0<ha<2 \implies h<\frac{2}{a} \]

    所以步长受限于 \(2/\lvert\lambda\rvert\) ✗

    若 \(\lambda\) 很大（快速衰减的过程）：

    \(\lvert\lambda\rvert\) 允许的 \(h\)
    \(1\) \(<2\)
    \(100\) \(<0.02\)
    \(10^6\) \(<2\times10^{-6}\) ✗

    后果：必须用极小步长，即使解本身变化很慢 ✗

    这就引出了「刚性」问题（下面详述）。

    复平面的稳定区域：

    Euler 的稳定区域是以 \((-1,0)\) 为圆心、半径 1 的圆：

    \[ \lvert1+z\rvert<1,\qquad z = h\lambda \]

    它只覆盖左半平面的一小部分 ✗

    对比：

    方法 稳定区域 性质
    显式 Euler 单位圆（小）✗ 条件稳定
    隐式 Euler \(z\) 平面中圆心 \((1,0)\) 半径 1 的圆外（含整个左半平面）✓ A 稳定
    RK4 稍大（含 \([-2.78,0]\)） 条件稳定
    梯形法 整个左半平面 ✓ A 稳定

    刚性方程（Stiff）¶

    定义（实用版）：系统的特征值实部跨度极大（比值 \(\gg1\)）。

    经典例子：

    \[ y' = -1000(y-\cos t)-\sin t \]

    真解：\(y(t) = \cos t + Ce^{-1000t}\) —— 快速瞬态（\(e^{-1000t}\)）很快消失，之后只剩平滑的 \(\cos t\)

    问题：

    阶段 解的行为 需要的 \(h\)
    初始瞬态（\(t\lesssim0.01\)） 剧烈变化 需要小 \(h\)
    之后（平滑段） 平滑 按理可以用大 \(h\) ✓

    但显式方法不允许：

    \[ h<\frac{2}{1000} = 0.002 \]

    即使解已经平滑，也必须用小步长 ✗

    刚性的「反直觉」之处（这是本页最重要的洞察）

    刚性问题中，步长限制来自「稳定性」而非「精度」

    约束 来源 是否可放松
    精度要求 解的局部变化 解平滑时可放松 ✓
    稳定性要求 最快的时间尺度 始终存在，不可放松 ✗

    关键：最快的时间尺度即使已经衰减掉， 仍然限制着显式方法的步长 ✗

    为什么：显式方法每步都要求 \(\lvert1+h\lambda\rvert<1\) —— 这个条件必须对全部特征值成立， 包括那些已经「无关紧要」的快速衰减模式

    后果（定量）：

    若 \(\operatorname{Re}\lambda_{\max} = -10^6\)、\(\operatorname{Re}\lambda_{\min} = -1\)， 而想积分到 \(t = 100\)：

    方法 需要的步数
    显式（受 \(h<2/10^6\)） \(\approx5\times10^7\) ✗
    隐式（可用 \(h\approx0.1\)） \(\approx10^3\) ✓

    差了 5 万倍 ✗

    这就是「处理刚性问题必须用隐式方法」的原因 ✓

    隐式方法¶

    隐式 Euler：

    \[ y_{n+1} = y_n+h\,f(t_{n+1},y_{n+1}) \]

    注意右边含 \(y_{n+1}\) —— 需要解方程（可能是非线性的）✗

    稳定条件：

    \[ \left\lvert\frac{1}{1-h\lambda}\right\rvert<1 \quad\text{对任意 }\operatorname{Re}\lambda<0\text{ 都成立} ✓ \]

    这就是「A 稳定」 ✓ —— 步长不受稳定性限制。

    A 稳定还不够：还要看「快速模态会不会被衰减掉」

    A 稳定的定义是：稳定区域包含整个左半平面，即 \(\lvert R(z)\rvert < 1\) 对一切 \(\operatorname{Re}z < 0\) 成立。

    但对刚性问题，A 稳定只是必要条件。真正的关键问题是： 当 \(z \to -\infty\)（极快衰减的模态）时，\(\lvert R(z)\rvert\) 趋于多少？

    若 \(\lvert R(z)\rvert \to 1\)，则快速模态被保留为等幅振荡而不是被衰减掉， 这会给缓慢变化的真实解叠加不衰减的伪振荡。

    因此需要更强的条件 —— L 稳定：

    \[ \text{L 稳定} \quad:\quad \text{A 稳定} \ \wedge\ \lim_{z\to-\infty}\lvert R(z)\rvert = 0 \]

    三种方法的定量对比：

    方法 \(R(z)\) \(\lim_{z\to-\infty}\lvert R(z)\rvert\) A 稳定 L 稳定
    显式 Euler \(1+z\) \(\infty\) ✗ ✗
    隐式 Euler \(\dfrac{1}{1-z}\) \(0\) ✓ ✓
    梯形法 \(\dfrac{1+z/2}{1-z/2}\) \(\lvert -1\rvert = 1\) ✓ ✗
    2 阶 BDF 见下行 \(0\) ✓ ✓

    具体数值（\(\lvert R\rvert\) 随 \(z\) 变负）：

    \(z\) \(\lvert R_{\text{隐式 Euler}}\rvert\) \(\lvert R_{\text{梯形}}\rvert\)
    \(-1\) \(0.5000\) \(0.3333\)
    \(-5\) \(0.1667\) \(0.4286\)
    \(-10\) \(0.0909\) \(0.6667\)
    \(-50\) \(0.0196\) \(0.9231\)
    \(-100\) \(0.0099\) \(0.9608\)
    \(-1000\) \(0.0010\) \(0.9960\)

    隐式 Euler 迅速趋零（\(z=-1000\) 时 \(0.001\)） 梯形法却趋近于 1（\(z=-1000\) 时 \(0.996\)）✗ —— 它把快速模态完整地保留成 \((-1)^{n}\) 的符号交替振荡。

    这就是「梯形法虽然 A 稳定，却不适合强刚性问题」的原因

    工程含义：选刚性求解器时不能只看「A 稳定」这个标签。 实践中应优先选 L 稳定 的方法（隐式 Euler、BDF、TR-BDF2）， 因为刚性问题的本质就是「存在极快衰减的模态」， 而这些模态必须被数值方法彻底压掉，而不是留作伪振荡。

    隐式方法的代价与收益

    收益：

    收益 说明
    A 稳定 步长不受 \(\lambda_{\max}\) 限制 ✓
    L 稳定（隐式 Euler、BDF） 快速模态被彻底压掉 ✓
    大步长可行 刚性问题必需 ✓

    代价：

    代价 说明
    每步要解方程 非线性时用牛顿法（回顾优化那页）✗
    实现复杂 需要 Jacobian
    每步更贵 但总步数可能少几个数量级 ✓

    权衡：

    \[ \text{隐式：每步贵} \times \text{步数少} \quad\text{vs}\quad \text{显式：每步便宜} \times \text{步数极多} \]

    对刚性问题，隐式完胜

    工程建议（选型指南）：

    问题类型 推荐方法
    非刚性 RK45（自适应显式） ✓
    中等刚性 隐式 RK、Rosenbrock
    强刚性 BDF（如 MATLAB 的 ode15s） ✓
    守恒系统（长期积分） 辛方法（保持能量的结构） ✓

    一个能自查的判据：

    若显式求解器需要极小步长（远小于解的变化尺度）， 问题大概是刚性的

    具体表现：

    现象 诊断
    步长被压到极小 刚性
    略微放大 \(h\) 就发散 刚性 ✓
    求解时间远超预期 刚性

    四、典型例题¶

    例题 1：Euler 法与改进 Euler 法的精度对比¶

    用两种方法解 \(y' = -2y\)、\(y(0) = 1\)（真解 \(y = e^{-2t}\)）， 取 \(h = 0.1\)，算到 \(t = 0.2\)，比较误差。

    思路

    逐步计算；注意改进 Euler 需要预测再校正。

    解答

    真解：

    \(t\) \(y = e^{-2t}\)
    \(0.1\) \(0.81873075\)
    \(0.2\) \(0.67032005\)

    Euler 法（\(f = -2y\)）

    第一步：\(t=0\)，\(y_0 = 1\)

    \[ y_1 = 1+0.1\times(-2\times1) = 1-0.2 = 0.8 \]

    第二步：

    \[ y_2 = 0.8+0.1\times(-2\times0.8) = 0.8-0.16 = 0.64 \]

    误差：

    \(t\) Euler 真解 误差
    \(0.1\) \(0.800000\) \(0.818731\) \(1.873\times10^{-2}\)
    \(0.2\) \(0.640000\) \(0.670320\) \(3.032\times10^{-2}\)

    改进 Euler 法

    第一步：\(t=0\)、\(y_0 = 1\)

    预测：

    \[ \tilde y_1 = 1+0.1\times(-2) = 0.8 \]

    校正（斜率平均）：

    \[ k_1 = -2\times1 = -2,\qquad k_2 = -2\times0.8 = -1.6 \]
    \[ y_1 = 1+\frac{0.1}{2}(-2-1.6) = 1-0.18 = 0.82 \]

    第二步：

    \[ \tilde y_2 = 0.82+0.1\times(-2\times0.82) = 0.82-0.164 = 0.656 \]
    \[ k_1 = -2\times0.82 = -1.64,\qquad k_2 = -2\times0.656 = -1.312 \]
    \[ y_2 = 0.82+\frac{0.1}{2}(-1.64-1.312) = 0.82-0.1476 = 0.6724 \]

    误差：

    \(t\) 改进 Euler 真解 误差
    \(0.1\) \(0.820000\) \(0.818731\) \(1.269\times10^{-3}\)
    \(0.2\) \(0.672400\) \(0.670320\) \(2.080\times10^{-3}\)

    对比总结：

    \(t\) Euler 误差 改进 Euler 误差 比值
    \(0.1\) \(1.873\times10^{-2}\) \(1.269\times10^{-3}\) \(14.8\)
    \(0.2\) \(3.032\times10^{-2}\) \(2.080\times10^{-3}\) \(14.6\)

    改进 Euler 的误差约小 15 倍

    验证「二阶方法」的预期：误差应 h2

    理论预期（\(h=0.1\)）：

    方法 阶 预期误差量级
    Euler \(O(h)\) \(\sim h\times C = 0.1C\)
    改进 Euler \(O(h^2)\) \(\sim h^2\times C = 0.01C\)

    比值应约为 \(1/h = 10\)。

    实际比值约 15 —— 与理论量级相符 （常数因子不同，所以不是精确的 10。）

    验证「阶」的方法（\(h\) 减半）：

    方法 \(h\to h/2\) 时误差
    Euler（一阶） 减半
    改进 Euler（二阶） 降到 ¼ ✓

    这是数值方法中的一个基本自检手段： 把 \(h\) 减半，看误差降到多少 —— 由此反推阶数

    工程实践：这个技巧可以用来验证求解器是否按预期收敛 （若误差不按预期下降，可能是实现有错或步长已进入舍入误差主导区。）

    例题 2：Euler 法的稳定性边界¶

    用显式 Euler 解 \(y' = -20y\)、\(y(0)=1\)。 分别取 \(h = 0.05\)、\(0.1\)、\(0.11\)、\(0.2\)，判断稳定性。

    思路

    稳定条件 \(\lvert1+h\lambda\rvert<1\)，这里 \(\lambda = -20\)。

    解答

    稳定条件

    \[ \lvert1-20h\rvert<1 \implies 0<20h<2 \implies h<0.1 \]

    逐情形分析

    \(h\) \(1-20h\) \(\lvert\cdot\rvert\) 稳定性
    \(0.05\) \(0\) \(0<1\) 稳定（一步归零） ✓
    \(0.09\) \(-0.8\) \(0.8<1\) 稳定 ✓
    \(0.1\) \(-1\) \(1\) 临界（振荡不衰减） ✗
    \(0.11\) \(-1.2\) \(1.2>1\) 发散 ✗
    \(0.2\) \(-3\) \(3>1\) 严重发散 ✗

    具体数值验证

    \(h = 0.05\)：

    \[ y_1 = (1-1)\times1 = 0,\qquad y_2 = 0 \]

    一步归零 ✓ —— 这是 \(h\lambda = -1\) 的特殊情形。

    注意「不发散」不等于「准确」：

    量 值
    数值解 \(y_1\) \(0\)
    真解 \(e^{-1}\) \(0.368\)
    误差 \(0.368\)（很大！） ✗

    所以 \(h=0.05\) 虽然稳定，精度却很差 （要精度需更小 \(h\)，但那样又容易进入舍入误差区。）

    \(h = 0.1\)：

    \[ y_n = (-1)^n \]

    符号交替、幅度不变 —— 不收敛也不发散（临界）✗

    \(h = 0.11\)：

    \[ y_n = (-1.2)^n \]

    幅度指数增长 —— 发散 ✗

    \(h = 0.2\)：

    \[ y_n = (-3)^n \implies \lvert y_5\rvert = 243 \]

    剧烈发散 ✗

    这个例子说明了「稳定性限制步长」的严重性

    真解是 \(e^{-20t}\)，衰减极快 —— 它其实很容易数值求解

    但显式 Euler 要求 \(h<0.1\) —— 即使解在 \(t>0.5\) 后已经几乎为零，仍不能用大 \(h\) ✗

    为什么：

    \[ \lvert1+h\lambda\rvert<1 \quad\text{必须对 }\lambda = -20\text{ 成立} \]

    这个条件与「解的大小」无关 —— 它是方法本身的要求

    这就是「刚性」的微观机制。

    三种处理的对比：

    方法 \(h=0.1\) 时
    显式 Euler 临界振荡 ✗
    隐式 Euler \(y_{n+1} = \dfrac{y_n}{1+20h} = \dfrac{y_n}{3}\)，稳定衰减 ✓
    RK4 稳定区域含 \([-2.78,0]\)，\(h\lambda = -2\) 稳定 ✓

    隐式 Euler 的稳定性验证：

    \[ y_{n+1} = y_n+h\lambda y_{n+1} \implies y_{n+1} = \frac{y_n}{1-h\lambda} \]

    对任意 \(\operatorname{Re}\lambda<0\) 与任意 \(h>0\)：

    \[ \left\lvert\frac{1}{1-h\lambda}\right\rvert = \frac{1}{\lvert1+h\lvert\lambda\rvert\rvert}<1 \;\checkmark \]

    永远稳定 ✓ —— 这就是 A 稳定的含义。

    工程含义：

    场景 方法选择
    快速衰减的瞬态 显式需要小 \(h\) ✗
    含快速瞬态的长时间仿真 隐式 ✓
    刚性化学反应、电路 隐式（BDF、隐式 RK）
    平滑的机械系统 显式（RK45）✓

    例题 3：RK4 的精度¶

    用 RK4 解 \(y' = -2y\)、\(y(0) = 1\)，\(h = 0.1\)，算到 \(t=0.2\)， 与真解比较。

    思路

    只用一步算到 \(t=0.1\)（\(h=0.1\)），看四阶方法的威力。

    解答

    第一步：\(k\) 值（\(t=0\)，\(y=1\)，\(f=-2y\)）

    \[ k_1 = -2\times1 = -2 \]
    \[ k_2 = -2\times(1+0.05\times(-2)) = -2\times0.9 = -1.8 \]
    \[ k_3 = -2\times(1+0.05\times(-1.8)) = -2\times0.91 = -1.82 \]
    \[ k_4 = -2\times(1+0.1\times(-1.82)) = -2\times0.818 = -1.636 \]

    第二步：加权求和

    \[ y_1 = 1+\frac{0.1}{6}(-2+2\times(-1.8)+2\times(-1.82)+(-1.636)) \]

    逐项：

    项 值
    \(k_1\) \(-2.000\)
    \(2k_2\) \(-3.600\)
    \(2k_3\) \(-3.640\)
    \(k_4\) \(-1.636\)
    和 \(-10.876\)
    \[ y_1 = 1+\frac{0.1}{6}\times(-10.876) = 1-0.181267 = 0.818733 \]

    第三步：比较

    量 值
    RK4 的 \(y(0.1)\) \(0.818733\)
    真解 \(e^{-0.2}\) \(0.818731\)
    误差 \(2\times10^{-6}\) ✓

    第四步：与前一例题对比

    方法 \(h=0.1\) 时 \(y(0.1)\) 的误差
    Euler \(1.87\times10^{-2}\)
    改进 Euler \(1.27\times10^{-3}\)
    RK4 \(2\times10^{-6}\) ✓

    RK4 的误差比 Euler 小约 \(10^4\) 倍

    验证「四阶」：h 减半时误差应降到约 1/16

    理论：四阶方法的全局误差 \(\propto h^4\)：

    \[ h\to\frac h2 \implies \text{误差}\to\frac{\text{误差}}{2^4} = \frac{\text{误差}}{16} \]

    本例题的验证思路（用 \(h = 0.05\) 重算）：

    \(h\) 预期误差 实际
    \(0.1\) —— \(2\times10^{-6}\)
    \(0.05\) \(1.25\times10^{-7}\) 约 \(1.3\times10^{-7}\) ✓

    吻合 ✓ —— 确认为四阶方法。

    工程价值（为什么 RK4 成为默认选择）：

    方面 RK4 的表现
    每步成本 4 次 \(f\) 求值
    精度 \(O(h^4)\)（极高）✓
    稳定性 比 Euler 好得多
    实现难度 中等（无需解方程）✓

    RK4 的「性价比」几乎是最优的 —— 更高阶的方法（如 RK8）每步要更多求值， 而精度提升的收益有限

    注意「精度」不解决「刚性」：

    RK4 也是显式方法 → 仍有稳定性限制 ✗

    问题 RK4 是否解决
    精度不足 是（\(O(h^4)\)）✓
    刚性的稳定性限制 否（稳定区域仍有限）✗

    本例题中 RK4 在 \(h=0.1\) 稳定（因为 \(h\lambda = -2\) 在其稳定区域内）， 但若 \(\lambda = -10^6\)，RK4 也不得不取极小 \(h\) ✗

    所以「精度」与「稳定性」是两个独立的问题 RK4 解决了前者，隐式方法解决后者。

    例题 4：刚性问题的诊断¶

    某系统有两个特征值 \(\lambda_1 = -1\)、\(\lambda_2 = -10^4\)， 需要积分到 \(t = 10\)。用显式 RK4 需要多少步？用隐式方法呢？

    思路

    显式的步长由 \(\lvert\lambda_{\max}\rvert\) 限制；隐式只受精度限制。

    解答

    第一步：判断刚性

    \[ \frac{\lvert\lambda_2\rvert}{\lvert\lambda_1\rvert} = \frac{10^4}{1} = 10^4 \]

    比值达 \(10^4\) → 强刚性

    第二步：显式 RK4 的步长限制

    RK4 的稳定区间（实轴部分）大约是

    \[ h\lambda\in[-2.78,\ 0] \]

    由最快的模态 \(\lambda_2 = -10^4\) 决定：

    \[ h_{\max} = \frac{2.78}{10^4} = 2.78\times10^{-4} \]

    所需步数：

    \[ N = \frac{10}{2.78\times10^{-4}} \approx 36000 \]

    结果：约 \(3.6\times10^4\) 步

    第三步：各模态的时间尺度对比

    模态 时间常数 \(1/\lvert\lambda\rvert\) 在 \(t=10\) 内的变化
    \(\lambda_1 = -1\) \(1\) 显著（衰减到 \(e^{-10}\)）
    \(\lambda_2 = -10^4\) \(10^{-4}\) 在 \(t>0.001\) 后已完全消失

    关键观察：\(t>0.001\) 之后，解完全由 \(\lambda_1\) 主导，非常平滑 ✓

    但显式方法仍必须用 \(h\approx2.8\times10^{-4}\) ✗ —— 因为它还要「稳住」那个已经不存在的快模态。

    第四步：隐式方法的步长

    隐式方法（A 稳定）只受精度限制。

    解的特征时间是 \(1/\lvert\lambda_1\rvert = 1\)， 所以用 \(h\approx0.01\)–\(0.1\) 就能保证精度：

    \[ N = \frac{10}{0.05} = 200 \]

    结果：约 \(200\) 步

    第五步：对比

    方法 步数 每步成本 总成本
    显式 RK4 \(36000\) \(4\) 次 \(f\) \(\approx1.4\times10^5\)
    隐式（每步解一次线性方程组） \(200\) 稍高 \(\approx O(10^2)\) ✓

    效率差约三个数量级

    这个例子揭示的「刚性问题」的核心

    刚性 = 「最快模态限制了显式方法的步长，但它在解中已无关紧要」

    诊断步骤（实用流程）：

    步骤 操作 判读
    1 尝试显式求解器（如 RK45） 观察步长与耗时
    2 若它把步长压得极小但仍满足容差 → 可能刚性
    3 若略微放大 \(h\) 就发散 → 确诊刚性 ✓
    4 算出 Jacobian 的特征值，看实部跨度 定量确认
    5 换隐式求解器（BDF、隐式 RK） 解决 ✓

    实践中的表现（一个很实用的判据）：

    若求解器报告的实际步长远小于解的变化尺度， 那基本就是刚性问题

    具体例子：解看起来是「平滑的慢变化」， 但求解器却需要 \(10^5\) 步 —— 矛盾就是线索

    工程建议（选型决策表）：

    诊断 选择
    特征值跨度小、解平滑 RK45（自适应显式）✓
    特征值跨度大 BDF / 隐式 RK ✓
    不确定 先用 RK45 试，观察步长 ✓
    长期守恒系统 辛方法（保能量）

    注意「隐式方法也需要 Jacobian」：

    对 \(y' = f(t,y)\)，隐式步需要解

    \[ y_{n+1}-y_n-hf(t_{n+1},y_{n+1}) = 0 \]

    用牛顿法（回顾优化那页）→ 需要 \(\partial f/\partial y\)

    若 Jacobian 难算（如黑箱仿真）：

    替代 说明
    数值差分 每步多算 \(n\) 次 \(f\)
    无 Jacobian 的隐式方法 如 Jacobian-free Newton-Krylov ✓
    半隐式（IMEX） 把刚性部分隐式、其余显式 ✓

    IMEX 值得特别一提：它把系统拆成「刚性部分 + 非刚性部分」， 前者用隐式、后者用显式 —— 兼顾稳定性与效率

    典型应用：流体力学、等离子体、带快速化学反应的燃烧问题。

    五、用在哪些课程里¶

    机器人学 · 动力学仿真¶

    • 机械臂、腿式机器人的动力学是刚性 ODE（关节刚度差异大）→ 用隐式方法
    • 实时仿真要求每步极快，常在精度与速度间折中
    • 接触/碰撞引入不连续的力 → 需要事件检测与步长重启
    • 能量守恒检查：无阻尼系统的仿真必须验证能量漂移（长期积分的自检）

    无人系统自主决策与优化 · 轨迹积分与最优控制¶

    • 轨迹预测（如卡尔曼滤波的预测步）本质是积分运动方程
    • 直接配点法把最优控制离散为非线性规划，ODE 求解器是内层核心
    • 长期任务（如轨道、巡航）用辛方法保持能量/动量守恒
    • 刚性问题：无人机电机动态比机身动态快得多 → 需要隐式方法

    现代数字信号处理 · 连续系统的离散化¶

    • 连续时间滤波器到数字滤波器的变换（双线性变换）与 ODE 数值方法同源
    • 锁相环、自适应滤波器的连续模型离散化
    • 模拟电路的仿真（SPICE）是刚性 ODE 的经典应用
    • 状态空间模型的离散化用矩阵指数（回顾 ODE 模块第三页）

    Q1 用 Euler 法解 \(y' = y\)、\(y(0)=1\)、\(h=0.1\)，算 \(y(0.3)\)，与真解比较。

    提示

    \(f = y\)，所以 \(y_{n+1} = y_n(1+h)\)。

    解答

    迭代公式

    \[ y_{n+1} = y_n+0.1y_n = 1.1y_n \]

    逐步计算

    \(n\) \(t\) \(y_n\)
    \(0\) \(0.0\) \(1.000000\)
    \(1\) \(0.1\) \(1.100000\)
    \(2\) \(0.2\) \(1.210000\)
    \(3\) \(0.3\) \(1.331000\)

    真解

    \[ y(0.3) = e^{0.3} = 1.349859 \]

    误差

    \[ \lvert1.331000-1.349859\rvert = 0.018859 \]

    结果：Euler 给 \(1.331\)，真解 \(1.3499\)，误差约 \(1.89\times10^{-2}\)

    注意「误差随 \(t\) 增大而增大」：

    \(t\) Euler 真解 误差
    \(0.1\) \(1.1000\) \(1.1052\) \(5.2\times10^{-3}\)
    \(0.2\) \(1.2100\) \(1.2214\) \(1.14\times10^{-2}\)
    \(0.3\) \(1.3310\) \(1.3499\) \(1.89\times10^{-2}\)

    误差近似线性增长 ✓ —— 这是全局误差 \(O(h)\) 的表现。

    验证「一阶」：若 \(h\) 减半，误差应减半：

    \(h\) \(y(0.3)\) 误差
    \(0.1\) \(1.331\) \(1.89\times10^{-2}\)
    \(0.05\) \(1.3401\) \(9.8\times10^{-3}\)
    \(0.025\) \(1.3450\) \(4.9\times10^{-3}\)

    误差确实大致减半 ✓ —— 确认是一阶方法。

    另一个观察：Euler 系统性偏低 （因为 \(1.1^3 = 1.331 < e^{0.3} = 1.3499\)。） 这是 Euler 法在「增长型」问题上的典型偏差方向。

    Q2 判断：RK4 是四阶方法，所以它也能解决刚性问题。

    提示

    想想「精度阶」与「稳定性」是不是同一件事。

    解答

    不对。RK4 精度高，但仍是显式方法，仍有稳定性限制。

    两个独立的问题：

    问题 关注点 RK4 是否解决
    精度 \(h\to0\) 时误差如何减小 ✓ 解决（\(O(h^4)\)）
    稳定性 步长较大时是否发散 ✗ 未解决

    RK4 的稳定区间也是有限的：

    实轴上约

    \[ h\lambda\in[-2.78,\ 0] \]

    对比各类方法：

    方法 实轴稳定区间 刚性可用？
    Euler \([-2,0]\) ✗
    RK4 \([-2.78,0]\) ✗
    隐式 Euler \((-\infty,0]\) ✓
    梯形法 \((-\infty,0]\) ✓
    BDF 大部分左半平面 ✓

    注意「RK4 的稳定区间（2.78）只比 Euler（2）大一点」 ✓

    含义：RK4 的稳定性优势不大 —— 它的价值主要在精度，而非稳定性 ✗

    具体后果（刚性问题）：

    若 \(\lambda = -10^6\)：

    方法 允许的 \(h\)
    Euler \(2\times10^{-6}\)
    RK4 \(2.78\times10^{-6}\)

    两者几乎一样小 ✗ —— RK4 完全没帮上忙。

    正确的做法：

    需求 方法
    高精度 + 非刚性 RK45 ✓
    刚性问题 隐式（BDF、隐式 RK） ✓
    既刚又需要精度 高阶隐式方法

    一句话：「高阶」与「稳定」是两回事 —— RK4 是前者，隐式方法是后者

    实践判据：若 RK45 求解器报告步长被压得极小， 换高阶显式方法也无济于事 —— 必须换隐式 ✓

    Q3 某刚性问题的特征值为 \(\lambda_1 = -1\)、\(\lambda_2 = -5000\)。 用显式 Euler 求解需要多小的步长？若用隐式方法呢？

    提示

    显式 Euler 要求 \(h<2/\lvert\lambda_{\max}\rvert\)。

    解答

    第一步：显式 Euler 的步长限制

    \[ h<\frac{2}{\lvert\lambda_{\max}\rvert} = \frac{2}{5000} = 4\times10^{-4} \]

    结果：\(h<4\times10^{-4}\)

    第二步：隐式方法的步长

    隐式 Euler 是 A 稳定的 → 不受稳定性限制， 只受精度限制。

    解的变化由慢模态 \(\lambda_1 = -1\) 主导（时间常数 \(1\)）， 所以 \(h\) 可与 \(1\) 同量级（如 \(h = 0.05\)）

    第三步：对比

    方法 \(h\) 若积分到 \(t = 5\)，需要步数
    显式 Euler \(4\times10^{-4}\) \(\approx12500\) ✗
    隐式 Euler \(0.05\) \(100\) ✓

    效率差约 125 倍

    但从「精度」角度看，两者都不够

    显式 Euler 是一阶 → 即使 \(h = 4\times10^{-4}\)，精度仍然一般 ✗

    隐式 Euler 也是一阶 ✗

    所以更实用的组合：

    需求 方案
    非刚性 + 高精度 RK45
    刚性 + 高精度 BDF（变阶变步长） ✓
    刚性 + 中等精度 隐式 RK、TR-BDF2

    BDF 的核心优势：

    优势 说明
    A 稳定（低阶）/ A(α) 稳定（高阶） 刚性可用 ✓
    可变阶（1–5 阶） 自动适应难度 ✓
    可变步长 兼顾精度与效率 ✓

    这就是「MATLAB ode15s、Python scipy.integrate.solve_ivp(method='BDF') 是刚性问题的标准工具」的原因

    工程建议：先用 RK45，若它「卡住」（步长被压得极小、耗时远超预期）， 换 BDF —— 这是最实用的诊断流程

    Q4 为什么数值方法存在「最优步长」而不能无限减小 \(h\)？

    提示

    考虑截断误差与舍入误差的相反趋势。

    解答

    因为截断误差与舍入误差随 \(h\) 的变化方向相反，两者之和存在最小值。

    两种误差的行为：

    误差 量级 随 \(h\) 减小
    截断误差 \(\sim Ch^p\)（\(p\) 是阶数） 减小 ✓
    舍入误差 \(\sim\dfrac{\epsilon_{\text{mach}}}{h}\) 增大 ✗

    为什么舍入误差随 \(h\) 减小而增大：

    步数 \(\propto 1/h\)，每步的舍入误差 \(\sim\epsilon_{\text{mach}}\) → 累积舍入误差 \(\propto\epsilon_{\text{mach}}/h\)

    总误差：

    \[ E(h)\approx Ch^p+\frac{\epsilon_{\text{mach}}}{h} \]

    求最优 \(h\)（令导数为零）：

    \[ Cp\,h^{p-1} = \frac{\epsilon_{\text{mach}}}{h^2} \implies h^{*}\sim\left(\frac{\epsilon_{\text{mach}}}{C}\right)^{1/(p+1)} \]

    对一阶方法（\(p=1\)）：

    \[ h^*\sim\sqrt{\epsilon_{\text{mach}}}\approx\sqrt{2.2\times10^{-16}}\approx1.5\times10^{-8} \]

    对四阶方法（\(p=4\)）：

    \[ h^*\sim\epsilon_{\text{mach}}^{1/5}\approx(2.2\times10^{-16})^{0.2}\approx7\times10^{-4} \]

    重要的对比：

    方法阶数 最优 \(h\) 最优 \(h\) 处的误差
    \(p=1\) \(\sim10^{-8}\) \(\sim10^{-8}\)
    \(p=4\) \(\sim10^{-3}\) \(\sim10^{-13}\) ✓

    高阶方法能达到更高的最终精度

    因为 \(p\) 大时最优 \(h\) 也更大（\(h^*\) 随 \(p\) 增大）：

    \(p\) \(h^*\) 的指数 \(1/(p+1)\) \(h^*\)
    \(1\) \(1/2\) \(10^{-8}\)
    \(2\) \(1/3\) \(10^{-5.3}\)
    \(4\) \(1/5\) \(10^{-3.2}\) ✓

    这就是「为什么高阶方法能同时更准更稳」的原因

    工程含义：

    实践建议 理由
    不要盲目用极小 \(h\) 舍入误差会反超 ✗
    用自适应步长 自动找到平衡点 ✓
    观察误差是否随 \(h\) 下降 若不再下降，已进入舍入主导区 ✓
    高精度需求用高阶方法 而不是用极小 \(h\) ✗

    一个实用的自检：若把 \(h\) 减半而误差不变或变大， 说明已经到达舍入误差主导区 —— 再减小 \(h\) 是徒劳的 ✓
