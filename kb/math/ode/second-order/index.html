    二阶线性微分方程¶

    上一页的一阶方程只有一个任意常数，解是一条曲线族。 这一页的方程多了一个导数，所以通解里会有两个任意常数， 需要两个初始条件（通常是初始位置与初始速度）才能定解。

    多这一阶，物理含义就完全不同了：

    • 一阶系统只能「趋近」或「发散」，不会振荡；
    • 二阶系统可以振荡——这是振动的来源， 也是机械臂关节弹跳、无人机姿态摆动、\(LC\) 电路起振的数学基础。

    二阶方程在工程中的地位无可替代，因为牛顿第二定律本身就是一个二阶方程：

    \[ m\ddot{x} = F \]

    加速度是位置的二阶导数。所以只要涉及「质量 + 力」的模型，二阶方程必然出现。 而本页要处理的常系数线性情形（\(a y'' + b y' + c y = f(x)\)） 恰好又能完整求出解析解，因此成为所有这些模型的「标准参考解」。

    一句话抓住核心

    二阶常系数线性方程的全部信息都藏在特征方程 \(ar^{2} + br + c = 0\) 的两个根里。

    根的情形 判别式 通解形式 运动表现
    两个相异实根 \(r_1 \neq r_2\) \(b^{2} - 4ac > 0\) \(C_1e^{r_1x} + C_2e^{r_2x}\) 单调趋近 / 单调发散
    二重实根 \(r\) \(b^{2} - 4ac = 0\) \((C_1 + C_2x)e^{rx}\) 临界情形，最快回到平衡
    共轭复根 \(\alpha \pm \beta i\) \(b^{2} - 4ac < 0\) \(e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)\) 振荡（\(\alpha<0\) 时衰减）

    非齐次方程的解 = 齐次通解 + 一个特解：

    \[ y = y_h + y_p \]

    \(y_h\) 由特征根决定（系统的固有响应），\(y_p\) 由右端 \(f(x)\) 决定（强迫响应）。

    一句话判据：先解特征方程定 \(y_h\)，再看右端定 \(y_p\)，最后用两个初值定常数。

    一、二阶线性方程的结构¶

    标准形与两个概念¶

    二阶线性方程的一般形式是

    \[ y'' + p(x)\,y' + q(x)\,y = f(x) \]
    • 若 \(f(x) \equiv 0\)，称为齐次方程，即 \(y'' + p(x)y' + q(x)y = 0\)
    • 若 \(f(x) \not\equiv 0\)，称为非齐次方程

    注意：「齐次」在这里指右端为零，与一阶方程里「齐次 = 可写成 \(y/x\) 的函数」 是两个不同的用法。判断前先看方程阶数，别混用。

    本页主要处理常系数情形（\(p\)、\(q\) 都是常数）， 因为只有此时才有统一的求根解法。

    线性方程的两个基本定理¶

    叠加原理（齐次）：若 \(y_1\)、\(y_2\) 都是齐次方程的解， 则任意线性组合 \(C_1y_1 + C_2y_2\) 也是解。

    验证：把 \(C_1y_1 + C_2y_2\) 代入左端，

    \[ (C_1y_1 + C_2y_2)'' + p(C_1y_1 + C_2y_2)' + q(C_1y_1 + C_2y_2) \]
    \[ = C_1\underbrace{(y_1'' + py_1' + qy_1)}_{=0} + C_2\underbrace{(y_2'' + py_2' + qy_2)}_{=0} = 0 \]

    关键：这一步之所以能「提出来」，正是因为方程对 \(y\) 是线性的。 非线性方程不具有这个性质——这也是线性理论能建立的原因。

    非齐次解的结构：若 \(y_p\) 是非齐次方程的一个特解， \(y_h\) 是齐次方程的通解，则非齐次方程的通解为

    \[ y = y_h + y_p \]

    证明：设 \(y\) 为任一解，令 \(u = y - y_p\)。则

    \[ u'' + pu' + qu = (y'' + py' + qy) - (y_p'' + py_p' + qy_p) = f(x) - f(x) = 0 \]

    所以 \(u\) 是齐次解，即 \(u = y_h\)

    工程含义：这条定理把问题拆成两半—— \(y_h\) 只看系统本身（\(p\)、\(q\)），\(y_p\) 只看外部输入（\(f\)）。 调参改善 \(y_h\)，改输入改善 \(y_p\)，两者互不干扰。

    线性相关与朗斯基行列式¶

    要把「两个解」写成通解，这两个解必须线性无关。 判定工具是朗斯基行列式（Wronskian）：

    \[ W(y_1, y_2) = \begin{vmatrix} y_1 & y_2 \\ y_1' & y_2' \end{vmatrix} = y_1y_2' - y_1'y_2 \]
    情形 \(W\) 结论
    \(y_1 = e^{x}\)，\(y_2 = e^{-x}\) \(e^{x}(-e^{-x}) - e^{x}e^{-x} = -1 - 1 = -2 \neq 0\) 线性无关 ✓
    \(y_1 = x\)，\(y_2 = 2x\) \(x \cdot 2 - 1 \cdot 2x = 0\) 线性相关 ✗
    \(y_1 = e^{2x}\)，\(y_2 = e^{3x}\) \(e^{2x}\cdot 3e^{3x} - 2e^{2x}\cdot e^{3x} = e^{5x} > 0\) 线性无关 ✓

    为什么只查一个点就够：由 Abel 公式，

    \[ W(x) = W(x_0)\exp\left(-\int_{x_0}^{x} p(t)\,\mathrm{d}t\right) \]

    指数因子永不为零，所以 \(W\) 要么恒为零，要么处处不为零。 判断线性无关只需在任意一点算一次。

    工程含义：\(W \neq 0\) 保证「两个初值条件可以唯一确定两个常数」。 如果 \(W = 0\)，就会出现「两个不同的初值给出同一组常数」或「无解」的尴尬， 系统在数学上是不可辨识的。

    为什么二阶需要两个条件¶

    方程阶数 通解中的常数个数 需要的初始条件 物理含义
    一阶 1 \(y(x_0) = y_0\) 初始状态（位置、电压、液位）
    二阶 2 \(y(x_0) = y_0\)，\(y'(x_0) = v_0\) 初始位置 + 初始速度
    \(n\) 阶 \(n\) \(n\) 个 初始状态向量

    为什么二阶要速度：因为二阶方程描述的是「加速度由位置和速度决定」的过程。 给定同一初始位置，速度不同则后续轨迹完全不同。 这就是「振子从同一个位置出发，可以向上走也可以向下走」的数学表达。

    二、常系数齐次方程与特征方程¶

    特征方程的来源¶

    设 \(y = e^{rx}\)（指数函数的导数还是指数函数，是最「自然」的猜测形式）。则

    \[ y' = re^{rx}, \qquad y'' = r^{2}e^{rx} \]

    代入 \(ay'' + by' + cy = 0\)：

    \[ ar^{2}e^{rx} + bre^{rx} + ce^{rx} = 0 \]

    因为 \(e^{rx} \neq 0\)，可以约掉，得到特征方程：

    \[ ar^{2} + br + c = 0 \]

    这是本页最重要的一个式子：它把「解微分方程」转化成了「解一元二次方程」。 微分方程的所有振荡、衰减、发散性质，全部由这两个根决定。

    一般解的形式由判别式 \(\Delta = b^{2} - 4ac\) 的符号分三类。 下面逐一说明，并在每类里给出「为什么会是这个形式」的理由。

    情形一：两个相异实根¶

    \(\Delta > 0\) 时，\(r_1 \neq r_2\) 都是实数，\(e^{r_1x}\) 与 \(e^{r_2x}\) 线性无关，直接叠加：

    \[ y = C_1e^{r_1x} + C_2e^{r_2x} \]

    运动特点：两个指数项各自单调变化，没有振荡。 若两根都负，则都衰减，\(y \to 0\)；若有一根为正，则该项发散。

    典型例：\(y'' - 5y' + 6y = 0\)、\(y(0) = 1\)、\(y'(0) = 0\)。

    特征方程 \(r^{2} - 5r + 6 = 0\)，因式分解得

    \[ (r - 2)(r - 3) = 0 \implies r_1 = 2,\ r_2 = 3 \]

    通解 \(y = C_1e^{2x} + C_2e^{3x}\)。

    由 \(y(0) = C_1 + C_2 = 1\)；由 \(y' = 2C_1e^{2x} + 3C_2e^{3x}\) 得 \(y'(0) = 2C_1 + 3C_2 = 0\)。

    联立求解：由第一式 \(C_1 = 1 - C_2\)，代入第二式

    \[ 2(1 - C_2) + 3C_2 = 0 \implies 2 + C_2 = 0 \implies C_2 = -2,\quad C_1 = 3 \]
    \[ y = 3e^{2x} - 2e^{3x} \]

    数值验证：

    \(x\) \(3e^{2x}\) \(2e^{3x}\) \(y\) 说明
    0.0 3.000000 2.000000 1.000000 初值 ✓
    0.5 8.154845 8.963378 \(-0.808533\) 已变为负
    1.0 22.167168 40.171074 \(-18.003906\) 快速发散

    注意 \(x=0\) 处速度为零：\(y'(0) = 3\cdot 2 - 2\cdot 3 = 0\) ✓。 解先是「被压下去」再反转发散——因为 \(e^{3x}\) 项的增长最终压过了 \(e^{2x}\) 项。

    两个必须看清的细节：

    1. \(x=0.5\) 处发生变号：\(3e^{1} = 8.154845\) 与 \(2e^{1.5} = 8.963378\) 几乎相等， 两者相减得 \(-0.808533\)。相减放大误差是这个解的特点，与散度无关。
    2. 比值高达 22.3 倍：\(x\) 从 0.5 到 1.0，\(\lvert y\rvert\) 从 0.808533 增到 18.003906， \(\dfrac{18.003906}{0.808533} \approx 22.27\)。 这个 22.27 倍远大于 \(e^{1.5} \approx 4.48\)， 原因正是上面的「近抵消」：\(x=0.5\) 处两个大数几乎抵消成小量， 所以从这个小量出发的相对增长被人为放大了。 当两个指数项符号相反、大小相近时，解对参数极其敏感 —— 工程上这是「病态初值问题」的典型来源。

    工程含义：只要有一个正根，解就发散，而且发散速度由最大的正根主导 （这里 \(r = 3\)，因为 \(e^{3x}\) 最终压过 \(e^{2x}\)）。 这就是为什么稳定性判据只看「最大实部特征值」。

    情形二：二重实根¶

    \(\Delta = 0\) 时只有一个根 \(r = -\dfrac{b}{2a}\)。 只写 \(C_1e^{rx}\) 是不够的——那只有一个常数，无法匹配两个初值。 第二个线性无关解取为 \(y_2 = xe^{rx}\)（这正是重复根的标准处理）。

    \[ y = (C_1 + C_2x)e^{rx} \]

    要记住的结论：重根时必须在单个解前乘 \(x\)。

    典型例：\(y'' + 4y' + 4y = 0\)、\(y(0) = 1\)、\(y'(0) = 3\)。

    特征方程 \(r^{2} + 4r + 4 = 0\)，即 \((r+2)^{2} = 0\)，得 \(r = -2\)（二重）。

    \[ y = (C_1 + C_2x)e^{-2x} \]

    由 \(y(0) = C_1 = 1\)。求导：

    \[ y' = C_2e^{-2x} - 2(C_1 + C_2x)e^{-2x} = e^{-2x}\left[C_2 - 2C_1 - 2C_2x\right] \]

    \(y'(0) = C_2 - 2C_1 = 3\)，代入 \(C_1 = 1\) 得 \(C_2 = 5\)。

    \[ y = (1 + 5x)e^{-2x} \]

    数值验证：

    \(x\) \(1 + 5x\) \(e^{-2x}\) \(y\) \(y'\)
    0.0 1.000 1.000000 1.000000 3.000000
    0.2 2.000 0.670320 1.340640 0.670320
    0.3 2.500 0.548812 1.372030 0.000000
    0.5 3.500 0.367879 1.287578 \(-0.735759\)
    1.0 6.000 0.135335 0.812012 \(-0.947347\)
    2.0 11.000 0.018316 0.201472 \(-0.311366\)

    特点：解先上升（从 1 升到约 1.372）再衰减—— 因为 \(x\) 的增长暂时压过了 \(e^{-2x}\) 的衰减， 但指数衰减最终获胜。拐点出现在 \(x = 0.3\)（此处 \(y' = 0\)，\(y\) 达到最大 \(1.372030\)）。

    注意 \(x=1\) 与 \(x=2\) 处的导数绝对值变小：\(y'(1) = -0.947347\)、 \(y'(2) = -0.311366\)。导数先负向增大（在 \(x = 0.4\) 附近取极值，那里 \(y''=0\)，即拐点）， 随后指数衰减使导数趋近于零。所以 \(y\) 是「先快速下降、后缓慢拖尾」， 这正是临界阻尼响应的典型尾部形态。

    临界阻尼的工程意义：\(x\) 因子让解在上升一次后不产生任何过冲， 这正好是「最快回到平衡且不振荡」的条件。 汽车的悬挂减振器、伺服系统都是按临界阻尼附近设计的。

    为什么乘 \(x\) 有效：设 \(r\) 是二重根，直接用降阶公式可以验证。 对 \(y'' + py' + qy = 0\)，已知一个解 \(y_1\)，则

    \[ y_2 = y_1\int \frac{e^{-\int p\,\mathrm{d}x}}{y_1^{2}}\,\mathrm{d}x \]

    取 \(y_1 = e^{rx}\)、\(p = -2r\)（因为重根 \(r_1 + r_2 = -p\)）， 则 \(e^{-\int p\,\mathrm{d}x} = e^{2rx}\)，于是

    \[ y_2 = e^{rx}\int \frac{e^{2rx}}{e^{2rx}}\,\mathrm{d}x = e^{rx}\int 1\,\mathrm{d}x = xe^{rx} \]

    乘 \(x\) 不是凑出来的，而是降阶公式的必然结果。

    情形三：共轭复根¶

    \(\Delta < 0\) 时两根为

    \[ r = \alpha \pm \beta i, \qquad \alpha = -\frac{b}{2a},\quad \beta = \frac{\sqrt{4ac - b^{2}}}{2a} \]

    \(e^{(\alpha + \beta i)x}\) 是复数形式的解，但它和它的共轭组合可以写成实形式。 用欧拉公式 \(e^{i\theta} = \cos\theta + i\sin\theta\)：

    \[ e^{(\alpha + \beta i)x} = e^{\alpha x}(\cos\beta x + i\sin\beta x) \]

    取实部与虚部，得到两个实解，通解为

    \[ y = e^{\alpha x}\left(C_1\cos\beta x + C_2\sin\beta x\right) \]

    这是本页最需要记住的形式：

    参数 名称 作用
    \(\alpha\) 衰减率（决定包络 \(e^{\alpha x}\)） \(\alpha < 0\) 衰减，\(\alpha > 0\) 发散，\(\alpha = 0\) 等幅振荡
    \(\beta\) 角频率（决定振荡快慢） 周期 \(T = \dfrac{2\pi}{\lvert\beta\rvert}\)
    \(\lvert r\rvert = \sqrt{\alpha^{2} + \beta^{2}}\) 固有频率 与阻尼无关的「无阻尼频率」

    归一化形式：上式也可写成单一余弦（幅度 + 相位）：

    \[ y = A e^{\alpha x}\cos\left(\beta x - \varphi\right) \]

    其中 \(A = \sqrt{C_1^{2} + C_2^{2}}\) 是振幅，\(\tan\varphi = \dfrac{C_2}{C_1}\) 是初相。 工程上习惯用这个形式，因为「振幅」和「相位」才是可直接测量的量。

    典型例：\(y'' + 2y' + 5y = 0\)、\(y(0) = 1\)、\(y'(0) = 0\)。

    特征方程 \(r^{2} + 2r + 5 = 0\)：

    \[ r = \frac{-2 \pm \sqrt{4 - 20}}{2} = -1 \pm 2i \]

    所以 \(\alpha = -1\)、\(\beta = 2\)，

    \[ y = e^{-x}\left(C_1\cos 2x + C_2\sin 2x\right) \]

    由 \(y(0) = C_1 = 1\)。求导：

    \[ y' = -e^{-x}(C_1\cos2x + C_2\sin2x) + e^{-x}(-2C_1\sin2x + 2C_2\cos2x) \]

    \(y'(0) = -C_1 + 2C_2 = 0\)，代入 \(C_1 = 1\) 得 \(C_2 = \frac12\)。

    \[ y = e^{-x}\left(\cos 2x + \frac12\sin 2x\right) \]

    振幅与相位：\(A = \sqrt{1 + \frac14} = \frac{\sqrt{5}}{2} \approx 1.118034\)， \(\tan\varphi = \frac12 \implies \varphi \approx 0.463648\) rad \(\approx 26.57^{\circ}\)。

    数值验证（注意 \(x = 1\) 附近 \(\cos2x + \frac12\sin2x\) 接近零，解析振荡因子在 \(2x \approx 3.02\) 处过零）：

    \(x\) \(e^{-x}\) \(\cos2x + \frac12\sin2x\) \(y\) 包络 \(Ae^{-x}\)
    0.0 1.000000 1.000000 1.000000 1.118034
    0.5 0.606531 0.961038 0.582899 0.678122
    1.0 0.367879 0.038502 0.014164 0.411302
    2.0 0.135335 \(-1.032045\) \(-0.139672\) 0.151309

    关键观察：

    1. \(y\) 在每个点都不超过包络 \(\lvert y\rvert \le Ae^{-x}\) （\(x=0\)：\(1.000 \le 1.118\)；\(x=1\)：\(0.014 \le 0.411\)）；
    2. \(x = 1\) 附近出现准零点：解析因子从正变负，\(y(1) = 0.014164\) 很接近零， 随后在 \(x=2\) 处变成 \(-0.139672\)。 注意 \(y\) 经过零点是正常的振荡行为，但幅度已很小；
    3. 包络衰减很稳定：包络从 1.118034 降到 0.151309， 比值 \(1.118034 / 0.151309 \approx 7.39\)，而 \(e^{2} \approx 7.389\) 包络严格按 \(e^{-x}\) 变化，与振荡因子无关。

    常见的误判：看到 \(y\) 在 \(x=1\) 处几乎为零，可能误以为「解已经衰减完了」； 但 \(x=2\) 处 \(\lvert y\rvert = 0.139672\) 反而更大。 这是振荡因子在起作用，必须用包络判断衰减，不能用瞬时值。

    工程含义：这是欠阻尼振荡的标准形态。 \(\alpha = -1\) 给出时间常数 \(\tau = 1\)（衰减到 \(1/e\) 需要 1 个时间单位）， \(\beta = 2\) 给出周期 \(T = \pi \approx 3.141593\)。 两个参数独立可调：改 \(\alpha\) 只影响衰减快慢，改 \(\beta\) 只影响振荡频率。 这正是「阻尼」与「刚度」在物理上可以独立设计的原因。

    三种情形的完整对比¶

    特征根 判别式条件 通解 是否振荡 稳定性（实部符号）
    \(r_1, r_2\) 相异实根 \(b^{2} - 4ac > 0\) \(C_1e^{r_1x} + C_2e^{r_2x}\) 否 都负才稳定

    三、非齐次方程与待定系数法¶

    求解总流程¶

    解非齐次方程 \(ay'' + by' + cy = f(x)\) 只需三步：

    1. 解齐次部分：求特征方程的根，写出 \(y_h\)（两个任意常数）；
    2. 找特解：由 \(f(x)\) 的形式猜 \(y_p\)，代入定系数；
    3. 定常数：把 \(y = y_h + y_p\) 代入两个初始条件解出 \(C_1\)、\(C_2\)。

    第 2 步是唯一需要技巧的地方，而技巧可以完全表格化。

    待定系数法的试解表¶

    右端 \(f(x)\) 的形式 试解 \(y_p\) 的形式 备注
    \(P_m(x)\)（\(m\) 次多项式） \(x^{k}Q_m(x)\) \(k\) = 0 或 1 或 2（见下）
    \(ae^{\lambda x}\) \(x^{k}Ae^{\lambda x}\) 若 \(\lambda\) 是特征根则升幂
    \(a\cos\omega x + b\sin\omega x\) \(x^{k}(A\cos\omega x + B\sin\omega x)\) 若 \(\pm\omega i\) 是特征根则升幂
    \(e^{\lambda x}\left[P_m(x)\cos\omega x + P_n(x)\sin\omega x\right]\) \(x^{k}e^{\lambda x}\left[Q_l(x)\cos\omega x + R_l(x)\sin\omega x\right]\) \(l = \max(m,n)\)

    关于 \(k\) 的规则（这是最容易出错的地方）：

    \(\lambda\) 与特征根的关系 \(k\) 取值
    \(\lambda\) 不是特征根 \(k = 0\)
    \(\lambda\) 是单特征根 \(k = 1\)（乘一次 \(x\)）
    \(\lambda\) 是二重特征根 \(k = 2\)（乘两次 \(x\)）

    为什么必须升幂：若右端函数本身已经是齐次解， 直接把同样形式代入会得到 \(0 = f(x)\) 的矛盾—— 必须乘 \(x\) 才能找到线性无关的新解。 本质上和「重根要乘 \(x\)」是同一个道理。

    典型例：多项式右端¶

    解 \(y'' - 3y' + 2y = 4x + 1\)、\(y(0) = 1\)、\(y'(0) = 0\)。

    第一步：齐次解。 \(r^{2} - 3r + 2 = 0\)，\((r-1)(r-2) = 0\)，\(r = 1, 2\)。

    \[ y_h = C_1e^{x} + C_2e^{2x} \]

    第二步：特解。 \(f(x) = 4x + 1\) 是一次多项式，且 \(0\) 不是特征根，取 \(k=0\)。设

    \[ y_p = Ax + B \]

    代入：\(y_p' = A\)，\(y_p'' = 0\)，

    \[ 0 - 3A + 2(Ax + B) = 2Ax + (2B - 3A) = 4x + 1 \]

    比较系数：

    \[ 2A = 4 \implies A = 2, \qquad 2B - 6 = 1 \implies B = 3.5 \]
    \[ y_p = 2x + 3.5 \]

    验算：\(y_p'' - 3y_p' + 2y_p = 0 - 6 + (4x + 7) = 4x + 1\)

    为什么不能取 \(y_p = A\)：那样 \(y_p' = y_p'' = 0\)， 左端变成 \(2A\)（常数），永远匹配不上 \(4x\) 项。

    第三步：定常数。

    \[ y = C_1e^{x} + C_2e^{2x} + 2x + 3.5 \]

    \(y(0) = C_1 + C_2 + 3.5 = 1 \implies C_1 + C_2 = -2.5\)。

    \[ y' = C_1e^{x} + 2C_2e^{2x} + 2, \qquad y'(0) = C_1 + 2C_2 + 2 = 0 \implies C_1 + 2C_2 = -2 \]

    两式相减：\(C_2 = 0.5\)，\(C_1 = -3\)。

    \[ y = -3e^{x} + 0.5e^{2x} + 2x + 3.5 \]

    数值验证：

    \(x\) \(-3e^{x}\) \(0.5e^{2x}\) \(2x + 3.5\) \(y\)
    0.0 \(-3.000000\) 0.500000 3.500000 1.000000
    0.5 \(-4.946164\) 1.359141 4.500000 0.912977
    1.0 \(-8.154845\) 3.694528 5.500000 1.039683
    2.0 \(-22.167168\) 27.299075 7.500000 12.631907

    观察：\(x = 0.5\) 处 \(y \approx 0.912977\) 略低于初值 1， 之后回升并最终发散。这是「衰减模式先起作用、增长模式后主导」的典型形态。

    工程含义：右端是多项式意味着外部输入是缓变的（如恒定推力、恒速输入）。 此时解的长期行为由 \(y_p = 2x + 3.5\) 决定 —— 输出跟随输入的线性增长。 但系统本身有一个不稳定模式 \(e^{2x}\)， 所以只要初值给得不好，输出最终会离开这条「理想跟踪轨迹」。 这就是「输入-输出跟踪」与「内部稳定性」是两回事的根源。

    典型例：指数右端与共振¶

    解 \(y'' + y = 4e^{2x}\)、\(y(0) = 0\)、\(y'(0) = 0\)。

    第一步：齐次解。 \(r^{2} + 1 = 0 \implies r = \pm i\)，即 \(\alpha = 0\)、\(\beta = 1\)。

    \[ y_h = C_1\cos x + C_2\sin x \]

    第二步：特解。 右端 \(4e^{2x}\)，\(\lambda = 2\) 不是特征根（特征根是 \(\pm i\)），取 \(k = 0\)。设

    \[ y_p = Ae^{2x} \implies y_p'' = 4Ae^{2x} \]

    代入：

    \[ 4Ae^{2x} + Ae^{2x} = 5Ae^{2x} = 4e^{2x} \implies A = \frac45 \]
    \[ y_p = \frac45 e^{2x} \]

    第三步：定常数。

    \[ y = C_1\cos x + C_2\sin x + \frac45 e^{2x} \]

    \(y(0) = C_1 + \frac45 = 0 \implies C_1 = -\frac45\)。

    \[ y' = -C_1\sin x + C_2\cos x + \frac85 e^{2x}, \qquad y'(0) = C_2 + \frac85 = 0 \implies C_2 = -\frac85 \]
    \[ y = \frac45 e^{2x} - \frac45\cos x - \frac85\sin x \]

    数值验证：

    \(x\) \(\frac45 e^{2x}\) \(-\frac45\cos x\) \(-\frac85\sin x\) \(y\)
    0.0 0.800000 \(-0.800000\) 0.000000 0.000000
    0.5 2.174625 \(-0.702066\) \(-0.767081\) 0.705479
    1.0 5.911245 \(-0.432242\) \(-1.346354\) 4.132649
    2.0 43.678520 \(+0.332917\) \(-1.454876\) 42.556562

    关键：\(x = 2\) 时 \(y \approx 42.556562\)，其中 \(43.678520\) 来自强迫项， 振荡项合计只有 \(0.332917 - 1.454876 = -1.121959\)。 强迫响应完全压倒了固有响应。

    这里的 \(\lambda = 2\) 与特征根 \(\pm i\) 不相等，所以没有共振， 指数项直接进入特解。下一节专门处理「相等」的情形。

    四、共振：当右端撞上固有频率¶

    共振的数学标志¶

    若右端的指数参数 \(\lambda\) 恰好等于某个特征根， 或右端的振荡频率 \(\omega\) 恰等于 \(\lvert\beta\rvert\)， 则试解必须升幂（乘 \(x\) 或 \(x^{2}\)），解里就会冒出 \(x\) 的因子。

    \(x\) 因子就是共振的数学签名：振幅随时间无界增长。

    典型例：与固有频率相同的正弦驱动¶

    解 \(y'' + 4y = 8\sin 2x\)、\(y(0) = 0\)、\(y'(0) = 0\)。

    第一步：齐次解。 \(r^{2} + 4 = 0 \implies r = \pm 2i\)，\(\alpha = 0\)、\(\beta = 2\)。

    \[ y_h = C_1\cos 2x + C_2\sin 2x \]

    第二步：特解。 右端 \(\sin 2x\) 的频率与 \(\beta = 2\) 完全相同， 即 \(\pm 2i\) 就是特征根。所以必须乘 \(x\)（\(k = 1\)）：

    \[ y_p = x(A\cos 2x + B\sin 2x) \]

    求导：

    \[ y_p' = A\cos2x + B\sin2x + x(-2A\sin2x + 2B\cos2x) \]
    \[ y_p'' = (-4A\sin2x + 4B\cos2x) + x(-4A\cos2x - 4B\sin2x) \]

    代入 \(y_p'' + 4y_p\)，含 \(x\) 的项恰好抵消：

    \[ y_p'' + 4y_p = -4A\sin2x + 4B\cos2x \]

    要等于 \(8\sin 2x\)：

    \[ -4A = 8 \implies A = -2, \qquad 4B = 0 \implies B = 0 \]
    \[ y_p = -2x\cos 2x \]

    第三步：定常数。

    \[ y = C_1\cos2x + C_2\sin2x - 2x\cos2x \]

    \(y(0) = C_1 = 0\)。

    \[ y' = -2C_1\sin2x + 2C_2\cos2x - 2\cos2x + 4x\sin2x \]

    \(y'(0) = 2C_2 - 2 = 0 \implies C_2 = 1\)。

    \[ y = \sin 2x - 2x\cos 2x \]

    数值验证：

    \(x\) \(\sin2x\) \(\cos2x\) \(-2x\cos2x\) \(y\) 包络 \(2x\)
    0.0 0.000000 1.000000 0.000000 0.000000 0.0
    0.5 0.841471 0.540302 \(-0.540302\) 0.301169 1.0
    1.0 0.909297 \(-0.416147\) 0.832294 1.741591 2.0
    \(\pi/2 \approx 1.5708\) 0.000000 \(-1.000000\) 3.141593 3.141593 3.141593
    \(\pi \approx 3.1416\) 0.000000 1.000000 \(-6.283185\) \(-6.283185\) 6.283185

    关键观察：

    • 在 \(x = \pi/2\) 处 \(y = \pi \approx 3.141593\)，恰好等于包络值；
    • 在 \(x = \pi\) 处 \(y = -2\pi \approx -6.283185\)；
    • 每经过半个周期，幅值就增加 \(2\pi \approx 6.28\)，永不饱和。

    这就是共振：输入频率与系统固有频率一致时， 能量持续注入且没有任何衰减机制，振幅线性无限增长。

    工程含义：塔科马海峡大桥（1940）在风载下垮塌、 洗衣机在特定转速剧烈抖动、无人机在特定频率输入下姿态失控， 数学本质都是「驱动频率撞上 \(\lvert\beta\rvert\)」。 工程防范手段有三条：

    手段 做法 数学对应
    避开频率 让工作频率远离固有频率 使 \(\omega \neq \lvert\beta\rvert\)
    加阻尼 让 \(\alpha < 0\) 引入 \(b y'\) 项，使包络变 \(e^{\alpha x}\)
    加非线性/限幅 振幅大时改变参数 使方程不再线性

    加阻尼为什么有效：若方程改为 \(y'' + 2y' + 4y = 8\sin2x\)， 特征根为 \(-1 \pm \sqrt{3}i\)，\(\beta = \sqrt{3} \approx 1.732 \neq 2\)， 共振被消除，解变成有界振荡（幅度有限）。 这也是为什么阻尼是「最保险」的手段——它不需要知道驱动频率。

    阻尼比与工程指标¶

    实际工程中把二阶方程写成标准形式

    \[ \ddot{y} + 2\zeta\omega_n\dot{y} + \omega_n^{2}y = 0 \]

    其中 \(\omega_n\) 是无阻尼固有频率，\(\zeta\) 是阻尼比。特征根为

    \[ r = -\zeta\omega_n \pm \omega_n\sqrt{\zeta^{2} - 1} \]
    \(\zeta\) 类型 特征根 响应形态
    \(0 < \zeta < 1\) 欠阻尼 \(-\zeta\omega_n \pm i\omega_n\sqrt{1-\zeta^{2}}\) 衰减振荡
    \(\zeta = 1\) 临界阻尼 \(-\omega_n\)（二重） 最快无过冲回归
    \(\zeta > 1\) 过阻尼 两个负实根 缓慢单调回归
    \(\zeta = 0\) 无阻尼 \(\pm i\omega_n\) 等幅振荡
    \(\zeta < 0\) 负阻尼 实部为正 发散（不稳定）

    关键工程指标（欠阻尼情形的标准公式）：

    \[ \text{超调量 } M_p = \exp\left(-\frac{\pi\zeta}{\sqrt{1-\zeta^{2}}}\right), \qquad \text{峰值时间 } t_p = \frac{\pi}{\omega_n\sqrt{1-\zeta^{2}}}, \qquad \text{调节时间 } t_s \approx \frac{3}{\zeta\omega_n} \]

    具体数值：

    \(\zeta\) \(\omega_n\sqrt{1-\zeta^{2}}\)（阻尼频率） 超调量 \(M_p\) 说明
    0.1 0.994987 72.92 % 严重振荡，不可用
    0.2 1.959592 52.66 % 振荡明显
    0.4 0.916515 25.38 % 常见设计目标
    0.5 1.732051 16.30 % 平衡选择
    \(1/\sqrt{2} \approx 0.707\) 0.707107 4.33 % 巴特沃斯，无谐振峰
    1.0 0（无振荡） 0 % 临界阻尼

    为什么要选 \(\zeta \approx 0.707\)：这是巴特沃斯（Butterworth）响应， 幅频特性最平坦、无谐振峰，且超调只有 4.33 %，工程上很好接受。 滤波器设计与控制器设计都大量采用这个值。

    具体算一个：取 \(\zeta = 0.5\)、\(\omega_n = 2\) rad/s，

    \[ \omega_d = 2\sqrt{1 - 0.25} = 2 \times 0.866025 = 1.732051 \ \text{rad/s} \implies T = \frac{2\pi}{1.732051} \approx 3.627599 \ \text{s} \]
    \[ M_p = \exp\left(-\frac{\pi \times 0.5}{0.866025}\right) = e^{-1.813799} \approx 16.30\ \% \]
    \[ t_s \approx \frac{3}{0.5 \times 2} = 3 \ \text{s} \]

    这三个数一起描述了系统的全部动态性能：多久开始稳定（\(t_s\)）、 摆动多快（\(T\)）、冲过头多少（\(M_p\)）。

    五、典型例题¶

    例题 1：两个相异实根¶

    求解 \(y'' - y' - 6y = 0\)、\(y(0) = 1\)、\(y'(0) = 2\)，并求 \(y(1)\)。

    思路

    写特征方程、求根、写通解、用两个初值定常数。 注意 \(y'(0)\) 要用通解求导后再代入。

    解答

    特征方程：

    \[ r^{2} - r - 6 = 0 \implies (r - 3)(r + 2) = 0 \implies r_1 = 3,\ r_2 = -2 \]

    通解：

    \[ y = C_1e^{3x} + C_2e^{-2x} \]

    定常数：\(y(0) = C_1 + C_2 = 1\)。

    \[ y' = 3C_1e^{3x} - 2C_2e^{-2x}, \qquad y'(0) = 3C_1 - 2C_2 = 2 \]

    由第一式 \(C_1 = 1 - C_2\)，代入：

    \[ 3(1 - C_2) - 2C_2 = 2 \implies 3 - 5C_2 = 2 \implies C_2 = 0.2,\quad C_1 = 0.8 \]
    \[ y = \frac{4}{5}e^{3x} + \frac{1}{5}e^{-2x} = \frac{4e^{3x} + e^{-2x}}{5} \]

    数值验证：

    \(x\) \(\frac45 e^{3x}\) \(\frac15 e^{-2x}\) \(y\)
    0.0 0.800000 0.200000 1.000000
    0.5 3.585351 0.073576 3.658927
    1.0 16.068430 0.027067 16.095497
    2.0 322.743035 0.003663 322.746698

    \(y(1) \approx 16.095497\)。

    观察：\(x = 2\) 时 \(e^{-2x}\) 项已衰减到 \(0.0037\)， 解几乎完全由 \(e^{3x}\) 主导。这就是「主导特征根」的实际含义 —— 只要有足够长的时间，\(r\) 最大的那个根决定一切。

    工程含义：系统有一个不稳定模式（\(r=3\)）和一个衰减模式（\(r=-2\)）。 两个初始条件决定了往每个模式里注入多少能量。 这里 \(C_1 = 0.8 > 0\)，所以不稳定模式被激发了，解必然发散。 如果设计目标是稳定，就必须让 \(r\) 的实部都为负—— 这一判断将在第四页系统化为 Lyapunov 稳定性理论。

    例题 2：二重根与临界阻尼¶

    求解 \(y'' + 4y' + 4y = 0\)、\(y(0) = 1\)、\(y'(0) = 3\)， 求 \(y\) 的最大值及取得位置。

    思路

    判别式为 \(16 - 16 = 0\)，是二重根。 重根时通解是 \((C_1 + C_2x)e^{rx}\)。 最大值处令 \(y' = 0\)。

    解答

    特征方程：\(r^{2} + 4r + 4 = 0\)，即 \((r+2)^{2} = 0\)，\(r = -2\)（二重）。

    通解：

    \[ y = (C_1 + C_2x)e^{-2x} \]

    定常数：\(y(0) = C_1 = 1\)。

    \[ y' = \left[C_2 - 2(C_1 + C_2x)\right]e^{-2x} = \left[C_2 - 2C_1 - 2C_2x\right]e^{-2x} \]

    \(y'(0) = C_2 - 2C_1 = 3 \implies C_2 = 5\)。

    \[ y = (1 + 5x)e^{-2x} \]

    求最大值：令 \(y' = 0\)，

    \[ 5 - 2(1 + 5x) = 0 \implies 5 - 2 - 10x = 0 \implies x = 0.3 \]

    （纠正：\(5 - 2 - 10x = 0\) 得 \(x = 0.3\)。）

    \[ y_{\max} = (1 + 5 \times 0.3)e^{-0.6} = 2.5 \times 0.548812 = 1.372030 \]

    数值验证：

    \(x\) \(1 + 5x\) \(e^{-2x}\) \(y\) \(y'\)
    0.0 1.000 1.000000 1.000000 3.000000
    0.2 2.000 0.670320 1.340640 0.670320
    0.3 2.500 0.548812 1.372030 0.000000
    0.5 3.500 0.367879 1.287578 \(-0.735759\)
    1.0 6.000 0.135335 0.812012 \(-0.947347\)

    在 \(x = 0.3\) 处 \(y' = 0\)，\(y_{\max} \approx 1.372030\)。

    与无阻尼情形的对比：若没有阻尼项，\(y(0)=1\)、\(y'(0)=3\) 会给出 无界振荡；这里因为有二重负根，解先升一次再单调衰减到零。

    工程含义：临界阻尼下只允许一次越过目标值，然后单调回归—— 没有第二次振荡，也没有过冲。这是「快速定位」类应用的理想选择： 磁盘磁头定位、精密平台的快速就位都追求临界阻尼。 代价：响应速度不是最快的（过阻尼更慢但更稳，欠阻尼更快但有振荡）。

    例题 3：非齐次（多项式右端）¶

    求解 \(y'' - 3y' + 2y = 4x + 1\)、\(y(0) = 1\)、\(y'(0) = 0\)，并讨论输出跟踪。

    思路

    先求齐次解，再按右端是「一次多项式」设 \(y_p = Ax + B\)，比较系数。 最后用初值定常数。

    解答

    齐次解：

    \[ r^{2} - 3r + 2 = 0 \implies r = 1,\ 2 \implies y_h = C_1e^{x} + C_2e^{2x} \]

    特解：\(f(x) = 4x + 1\) 为一次多项式，\(0\) 不是特征根，取 \(k=0\)，设 \(y_p = Ax + B\)。

    \[ y_p' = A,\quad y_p'' = 0 \implies 0 - 3A + 2Ax + 2B = 4x + 1 \]

    比较系数：

    \[ 2A = 4 \implies A = 2, \qquad 2B - 3A = 1 \implies 2B - 6 = 1 \implies B = 3.5 \]
    \[ y_p = 2x + 3.5 \]

    定常数：

    \[ y = C_1e^{x} + C_2e^{2x} + 2x + 3.5 \]
    \[ y(0) = C_1 + C_2 + 3.5 = 1 \implies C_1 + C_2 = -2.5 \]
    \[ y' = C_1e^{x} + 2C_2e^{2x} + 2, \qquad y'(0) = C_1 + 2C_2 + 2 = 0 \implies C_1 + 2C_2 = -2 \]

    相减得 \(C_2 = 0.5\)，\(C_1 = -3\)：

    \[ y = -3e^{x} + 0.5e^{2x} + 2x + 3.5 \]

    数值验证：

    \(x\) \(y\) \(y_p = 2x + 3.5\) \(y - y_p\)（偏离跟踪轨迹）
    0.0 1.000000 3.500000 \(-2.500000\)
    0.5 0.912977 4.500000 \(-3.587023\)
    1.0 1.039683 5.500000 \(-4.460317\)
    2.0 12.631907 7.500000 5.131907

    讨论：\(y_p = 2x + 3.5\) 是「理想跟踪轨迹」。 但 \(y - y_p = -3e^{x} + 0.5e^{2x}\) 会增长： 令它为零，得 \(0.5e^{2x} = 3e^{x}\)，即 \(e^{x} = 6\)， 所以偏离发生在 \(x = \ln 6 \approx 1.791759\) 附近。

    现象 数学原因
    输出能跟踪线性输入 右端多项式次数有限，特解也是同次多项式
    跟踪只能维持一段 齐次解含正根 \(e^{2x}\)，会盖过 \(y_p\)
    想长期跟踪需保证稳定 必须使齐次解的所有根实部为负

    工程含义：这是「跟踪性能」与「稳定性」必须同时满足的例子。 只保证 \(y_p\) 存在（跟踪）远远不够，必须让 \(y_h\) 衰减 （即所有特征根实部为负），跟踪才有意义。 这是控制理论中「内部稳定性先于外部跟踪」的具体体现。

    例题 4：共振¶

    求解 \(y'' + 4y = 8\sin 2x\)、\(y(0) = 0\)、\(y'(0) = 0\)， 求 \(y\) 在 \(x = \pi/2\) 与 \(x = \pi\) 处的值，并说明如何消除共振。

    思路

    右端频率 \(\omega = 2\) 与特征频率 \(\beta = 2\) 相同，属共振。 特解要乘 \(x\)：\(y_p = x(A\cos2x + B\sin2x)\)。

    解答

    齐次解：\(r^{2} + 4 = 0 \implies r = \pm 2i\)，\(\beta = 2\)。

    \[ y_h = C_1\cos2x + C_2\sin2x \]

    特解（升幂）：因为 \(\omega = \beta = 2\)，取 \(k = 1\)，设

    \[ y_p = x(A\cos2x + B\sin2x) \]

    计算后含 \(x\) 的项抵消，得到

    \[ y_p'' + 4y_p = -4A\sin2x + 4B\cos2x = 8\sin2x \]
    \[ A = -2, \qquad B = 0 \implies y_p = -2x\cos2x \]

    定常数：\(y = C_1\cos2x + C_2\sin2x - 2x\cos2x\)。

    \(y(0) = C_1 = 0\)；

    \[ y' = -2C_1\sin2x + 2C_2\cos2x - 2\cos2x + 4x\sin2x \]

    \(y'(0) = 2C_2 - 2 = 0 \implies C_2 = 1\)。

    \[ y = \sin 2x - 2x\cos 2x \]

    数值计算：

    \(x\) \(\sin2x\) \(\cos2x\) \(y\)
    0.0 0.000000 1.000000 0.000000
    \(\pi/4 \approx 0.7854\) 1.000000 0.000000 1.000000
    \(0.5\) 0.841471 \(-0.416147\) 0.301169
    \(1.0\) 0.909297 \(-0.416147\) 1.741591
    \(\pi/2 \approx 1.5708\) 0.000000 \(-1.000000\) \(\pi \approx 3.141593\)
    \(\pi \approx 3.1416\) 0.000000 1.000000 \(-2\pi \approx -6.283185\)

    结论：\(y(\pi/2) = \pi \approx 3.141593\)，\(y(\pi) = -2\pi \approx -6.283185\)。

    振幅增长的规律：在 \(x = (2k+1)\pi/2\) 处幅值为 \((2k+1)\pi\)， 即每半周期增加 \(2\pi \approx 6.28\)。线性增长，没有上限。

    如何消除共振：

    手段 改法 效果
    加阻尼 改为 \(y'' + 2y' + 4y = 8\sin2x\) 特征根 \(-1 \pm \sqrt{3}i\)，\(\beta = 1.732 \neq 2\)，解有界
    改固有频率 改为 \(y'' + 9y = 8\sin2x\) 特征根 \(\pm 3i\)，\(\beta = 3 \neq 2\)，解为拍频
    改驱动频率 改为 \(8\sin 3x\) 远离 \(\beta = 2\)

    验证第一种改法：\(y'' + 2y' + 4y = 8\sin2x\)， 齐次根 \(-1 \pm \sqrt{3}i\)，右端频率 2 不等于 \(\sqrt{3}\)， 特解为 \(y_p = A\cos2x + B\sin2x\)（不升幂），解有界。 这是最省事也最可靠的方案 —— 不需要精确知道驱动频率就能防共振。

    工程含义：共振是「输入与系统同频」的必然结果， 而现实中驱动频率往往无法精确控制（风力、路面激励、流体涡脱）， 所以加阻尼永远是第一选择。

    六、用在哪些课程里¶

    机器人学 · 关节柔性、阻抗控制与抑振¶

    • 关节柔性模型：把关节看作「转动惯量 + 弹簧 + 阻尼」， 方程为 \(J\ddot{q} + b\dot{q} + kq = \tau\)， 本页的特征方程分析直接给出固有频率 \(\omega_n = \sqrt{k/J}\) 与阻尼比 \(\zeta = \frac{b}{2\sqrt{kJ}}\)；
    • 抑振设计：想让机械臂快速定位不过冲，就要把 \(\zeta\) 调到 \(0.7\) 附近；\(\zeta < 0.3\) 时末端会出现明显抖动（超调 \(> 37\%\)）；
    • 共振规避：机器人本体的一阶固有频率必须远高于控制带宽， 否则指令激励会引发结构共振（本页第四节）。

    现代数字信号处理 · 二阶滤波器的原型¶

    • 二阶连续时间滤波器（低通、带通、陷波）的传递函数分母就是 \(s^{2} + 2\zeta\omega_n s + \omega_n^{2}\)， 其极点在 \(s\) 平面上的位置完全由本页的特征根给出；
    • 超调与频率响应峰：\(\zeta = 0.707\) 的无谐振峰特性 正是巴特沃斯滤波器的设计依据（\(M_p = 4.33\%\)）；
    • IIR 滤波器设计：从连续原型（本页讨论的微分方程） 经双线性变换得到离散递推式， 所以理解二阶连续方程是理解二阶 IIR 的前提。

    无人系统自主决策与优化 · 姿态动力学与控制带宽¶

    • 无人机姿态模型：俯仰通道在悬停点线性化后就是 \(I_y\ddot{\theta} + b\dot{\theta} = \tau\)， 是二阶方程，本页给出了它的完整响应形态；
    • 控制带宽与超调：PID 参数整定本质上是在设定闭环的 \(\zeta\) 与 \(\omega_n\)。 若把 \(\zeta\) 配到 0.5，超调就是 16.3 %， 这个数字可以直接从本页表格读出，不必仿真；
    • 共振风险：旋翼转速的周期性激励若与机身固有频率接近， 会引起姿态共振。这就是「转速限制区」的由来。

    七、自测¶

    Q1 求解 \(y'' - y' - 6y = 0\)、\(y(0) = 1\)、\(y'(0) = 2\) 形式的题目时， 若特征根改为 \(r = -1\) 与 \(r = -3\)，初值仍为 \(y(0)=1\)、\(y'(0)=0\)， 写出解并说明与例题 1 的本质差别。

    提示

    先解 \(C_1 + C_2 = 1\)、\(-C_1 - 3C_2 = 0\)。 重点比较「根的正负」如何决定长期行为。

    解答

    特征方程：\(r^{2} + 4r + 3 = 0 \implies (r+1)(r+3) = 0\)，\(r_1 = -1\)、\(r_2 = -3\)。

    通解：

    \[ y = C_1e^{-x} + C_2e^{-3x} \]

    定常数：\(y(0) = C_1 + C_2 = 1\)；\(y' = -C_1e^{-x} - 3C_2e^{-3x}\)， \(y'(0) = -C_1 - 3C_2 = 0\)。

    由第一式 \(C_1 = 1 - C_2\)，代入第二式：\(-(1-C_2) - 3C_2 = 0 \implies -1 - 2C_2 = 0\)， \(C_2 = -0.5\)，\(C_1 = 1.5\)。

    \[ y = 1.5e^{-x} - 0.5e^{-3x} \]

    数值验证：

    \(x\) \(1.5e^{-x}\) \(-0.5e^{-3x}\) \(y\)
    0.0 1.500000 \(-0.500000\) 1.000000
    0.5 0.909796 \(-0.111565\) 0.798231
    1.0 0.551819 \(-0.024894\) 0.526926
    2.0 0.203003 \(-0.001239\) 0.201764
    3.0 0.074681 \(-0.000062\) 0.074619

    本质差别：

    对比项 例题 1（\(r = 3, -2\)） 本题（\(r = -1, -3\)）
    根的正负 一正一负 全负
    长期行为 \(e^{3x}\) 主导，发散 \(e^{-x}\) 主导，衰减到零
    \(x=2\) 处 \(y\) 322.746698 0.201764
    稳定性 不稳定 稳定

    结论：决定系统是否稳定的是「所有特征根的实部是否都为负」， 而不是根的个数或大小。两个例子方程形式几乎一样， 只把系数从 \(-5\)、\(6\) 改成 \(4\)、\(3\)，稳定性就完全反转了。

    工程含义：这解释了为什么控制器设计里要仔细检查特征根位置。 「系数差一点」听起来无害，但可能正好把根从负半平面推到了正半平面。

    Q2 求解 \(y'' + 2y' + 5y = 0\)、\(y(0) = 2\)、\(y'(0) = -1\)， 写出振幅-相位形式，并给出包络与周期。

    提示

    特征根为 \(-1 \pm 2i\)。通解 \(e^{-x}(C_1\cos2x + C_2\sin2x)\)。 振幅 \(A = \sqrt{C_1^{2} + C_2^{2}}\)，周期 \(T = 2\pi/\beta\)。

    解答

    特征方程：\(r^{2} + 2r + 5 = 0\)，

    \[ r = \frac{-2 \pm \sqrt{4 - 20}}{2} = -1 \pm 2i \implies \alpha = -1,\ \beta = 2 \]

    通解：

    \[ y = e^{-x}(C_1\cos2x + C_2\sin2x) \]

    定常数：\(y(0) = C_1 = 2\)。

    逐项求导：

    \[ y' = -e^{-x}(C_1\cos2x + C_2\sin2x) + e^{-x}(-2C_1\sin2x + 2C_2\cos2x) \]

    整理成「\(\cos\) 项 + \(\sin\) 项」：

    \[ y' = e^{-x}\left[(2C_2 - C_1)\cos2x - (2C_1 + C_2)\sin2x\right] \]

    在 \(x=0\) 处：\(y'(0) = 2C_2 - C_1\)。

    \[ y'(0) = 2C_2 - 2 = -1 \implies C_2 = 0.5 \]
    \[ y = e^{-x}\left(2\cos 2x + \frac12\sin 2x\right) \]

    振幅与相位：

    \[ A = \sqrt{4 + 0.25} = \sqrt{4.25} \approx 2.061553 \]
    \[ \tan\varphi = \frac{C_2}{C_1} = \frac{0.5}{2} = 0.25 \implies \varphi \approx 0.244979 \ \text{rad} \approx 14.036^{\circ} \]
    \[ y = 2.061553\, e^{-x}\cos(2x - 0.244979) \]

    核对：\(x=0\) 时 \(2.061553\cos(-0.244979) = 2.061553 \times 0.970143 = 2.000000\) 与 \(y(0)=2\) 一致。

    包络与周期：包络为 \(A e^{-x} = 2.061553e^{-x}\)； 周期 \(T = \dfrac{2\pi}{2} = \pi \approx 3.141593\)； 时间常数 \(\tau = 1/\lvert\alpha\rvert = 1\)。

    数值验证：

    \(x\) \(e^{-x}\) \(2\cos2x + 0.5\sin2x\) \(y\) 包络 \(2.061553e^{-x}\)
    0.0 1.000000 2.000000 2.000000 2.061553
    0.5 0.606531 1.501340 0.910609 1.250395
    1.0 0.367879 \(-0.377645\) \(-0.138928\) 0.758403
    2.0 0.135335 \(-1.685688\) \(-0.228133\) 0.279001

    衰减速度：包络从 \(x=1\) 到 \(x=2\) 减小 \(e \approx 2.718\) 倍 （\(0.758403 / 0.279001 \approx 2.718\)）。 \(y\) 本身从 \(-0.138928\) 到 \(-0.228133\) 反而变大， 这再次说明振荡系统必须用包络判断衰减趋势。

    工程含义：这个系统的阻尼比可由 \(\zeta = \lvert\alpha\rvert/\omega_n\) 读出， 其中 \(\omega_n = \sqrt{\alpha^{2} + \beta^{2}} = \sqrt{1 + 4} = \sqrt{5} \approx 2.236068\)， 所以 \(\zeta = 1/2.236068 \approx 0.447214\) （这也等于 \(b/(2\sqrt{ac}) = 2/(2\sqrt{5}) = 1/\sqrt{5}\)）。 超调量 \(M_p = \exp\left(-\pi\zeta/\sqrt{1-\zeta^{2}}\right)\)： \(\sqrt{1 - 0.2} = 0.894427\)，\(M_p = e^{-1.570796} \approx 20.79\ \%\)。 这个 20.79 % 就是该系统的设计超调，可以从方程系数一步算出， 不需要任何仿真。

    Q3 求解 \(y'' + y = 4e^{2x}\)、\(y(0) = 0\)、\(y'(0) = 0\)，求 \(y(1)\)。

    提示

    特征根为 \(\pm i\)，右端参数 \(\lambda = 2\) 不是特征根， 所以特解取 \(Ae^{2x}\) 而不需要乘 \(x\)。

    解答

    齐次解：\(r^{2} + 1 = 0 \implies r = \pm i\)，

    \[ y_h = C_1\cos x + C_2\sin x \]

    特解：设 \(y_p = Ae^{2x}\)，则 \(y_p'' = 4Ae^{2x}\)，

    \[ 4Ae^{2x} + Ae^{2x} = 5Ae^{2x} = 4e^{2x} \implies A = \frac45 \]

    定常数：

    \[ y = C_1\cos x + C_2\sin x + \frac45 e^{2x} \]

    \(y(0) = C_1 + \frac45 = 0 \implies C_1 = -\frac45\)。

    \[ y' = -C_1\sin x + C_2\cos x + \frac85 e^{2x} \implies y'(0) = C_2 + \frac85 = 0 \implies C_2 = -\frac85 \]
    \[ y = \frac45 e^{2x} - \frac45\cos x - \frac85\sin x \]

    数值计算：\(x = 1\) 时

    项 数值
    \(\frac45 e^{2}\) \(0.8 \times 7.389056 = 5.911245\)
    \(-\frac45\cos 1\) \(-0.8 \times 0.540302 = -0.432242\)
    \(-\frac85\sin 1\) \(-1.6 \times 0.841471 = -1.346354\)
    \(y(1)\) 4.132649

    \(y(1) \approx 4.132649\)。

    代入验证：\(y'' = \frac{16}{5}e^{2x} + \frac45\cos x + \frac85\sin x\)，

    \[ y'' + y = \frac{16}{5}e^{2x} + \frac45\cos x + \frac85\sin x + \frac45 e^{2x} - \frac45\cos x - \frac85\sin x \]
    \[ = \frac{20}{5}e^{2x} = 4e^{2x} \ \checkmark \]

    齐次部分与三角函数项恰好全部抵消 —— 这正是「\(y_h\) 是齐次解」的必然结果，也是最快的校验方式。

    与共振例题的对比：

    对比项 本题（\(\lambda = 2 \neq \pm i\)） 共振例（\(\omega = 2 = \beta\)）
    是否升幂 否 是（乘 \(x\)）
    特解 \(\frac45 e^{2x}\)（有界） \(-2x\cos2x\)（无界）
    长期行为 指数增长但不振荡 振荡且幅值线性增长

    注意：\(e^{2x}\) 也会增长，但它是指数增长且不振荡， 与共振的「线性增长且振荡」在形态上完全不同。 工程上「指数增长」意味着模型参数错了（系统本身不稳定）， 而「线性增长」意味着工作频率选错了（输入与系统同频）。

    Q4 求解 \(y'' - 2y' + y = e^{x}\)、\(y(0) = 0\)、\(y'(0) = 0\)。 本题的右端 \(\lambda = 1\) 是二重特征根，说明为什么必须乘 \(x^{2}\)。

    提示

    特征方程 \((r-1)^{2} = 0\)，\(r=1\) 是二重根。 试解应设为 \(y_p = Ax^{2}e^{x}\)（\(k=2\)）。

    解答

    齐次解：\(r^{2} - 2r + 1 = 0 \implies (r-1)^{2} = 0\)，\(r = 1\)（二重）。

    \[ y_h = (C_1 + C_2x)e^{x} \]

    为什么必须乘 \(x^{2}\)：右端 \(e^{x}\) 对应的参数 \(\lambda = 1\)， 而 \(1\) 是二重特征根。若只乘以 \(x\)（即设 \(y_p = Axe^{x}\)）， 那么 \(Axe^{x}\) 本身就是齐次解（取 \(C_1 = 0\)、\(C_2 = A\)）， 代入左端必然得到 0，无法匹配 \(e^{x}\)。 所以必须再升一幂：

    \[ y_p = Ax^{2}e^{x} \]

    计算：

    \[ y_p' = A(2xe^{x} + x^{2}e^{x}) = Ae^{x}(x^{2} + 2x) \]
    \[ y_p'' = Ae^{x}(x^{2} + 2x) + Ae^{x}(2x + 2) = Ae^{x}(x^{2} + 4x + 2) \]

    代入 \(y_p'' - 2y_p' + y_p\)：

    \[ Ae^{x}\left[(x^{2} + 4x + 2) - 2(x^{2} + 2x) + x^{2}\right] = Ae^{x}\left[x^{2} + 4x + 2 - 2x^{2} - 4x + x^{2}\right] = 2Ae^{x} \]

    令 \(2Ae^{x} = e^{x}\)，得 \(A = \frac12\)。

    \[ y_p = \frac12 x^{2}e^{x} \]

    数值验证：

    \(x\) \(\frac12 x^{2}\) \(e^{x}\) \(y_p\)
    0.5 0.125 1.648721 0.206090
    1.0 0.500 2.718282 1.359141
    2.0 2.000 7.389056 14.778112

    定常数：

    \[ y = (C_1 + C_2x)e^{x} + \frac12x^{2}e^{x} \]

    \(y(0) = C_1 = 0\)。

    \[ y' = e^{x}\left[C_2 + C_2x + x + \frac12x^{2}\right] \implies y'(0) = C_2 = 0 \]
    \[ y = \frac12 x^{2}e^{x} \]

    结论：解的常数全为零，只剩特解。

    升幂规律总结：

    \(\lambda\) 与特征根的关系 试解形式 本例
    非特征根 \(Ae^{x}\) 会得到 0 = 1 的矛盾
    单特征根 \(Axe^{x}\) 代入左端仍得 0，仍矛盾
    二重特征根 \(Ax^{2}e^{x}\) ✓ 得 \(2A = 1\)

    工程含义：极点重合（重根）时，系统对同频激励的响应会多一个 \(x\) 幂次因子—— 响应幅度以多项式速度增长（这里是 \(x^{2}\)）。 在控制与滤波中，二重极点出现在临界阻尼边界上， 参数稍有偏差就会变成复根（振荡）或实根（过阻尼）， 所以重根是数值上最敏感的位置，实际设计应主动避开。
