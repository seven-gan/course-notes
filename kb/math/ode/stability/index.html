    稳定性分析¶

    前三页解决的是「怎么解」——求出微分方程的解。 这一页换个问题：不解方程，能不能判断解会不会跑掉？

    这个问题极为实际。工程上绝大多数的判断都只需要「会收敛吗」 「会振荡吗」「扰动能压住吗」，而不需要解的解析表达式。 Lyapunov 理论给出的正是这样一套不需要求解的判据， 它是整个非线性系统与控制理论的基石。

    本页要讲清楚四件事：

    1. 稳定性的严格定义——为什么需要区分「稳定」「渐近稳定」「指数稳定」， 以及为什么「有界」与「收敛」是两回事；
    2. 线性化判据（Lyapunov 第一法）——用雅可比矩阵的特征值判断平衡点， 这是最常用的工具，但有失效的情形；
    3. Lyapunov 直接法（第二法）——构造一个「能量函数」， 看它是否单调递减。这招不需要解方程、不需要线性化；
    4. LaSalle 不变原理与极限环——当能量函数只是「不增」而非「递减」时， 如何仍然得出收敛结论，以及「自激振荡」是怎么产生的。

    一句话抓住核心

    对 \(\dot{\boldsymbol{x}} = \boldsymbol{f}(\boldsymbol{x})\)，设 \(\boldsymbol{x}_e\) 是平衡点。

    概念 定义要点 判据（线性化）
    Lyapunov 稳定 初值足够近时，轨迹始终留在给定邻域内 \(\operatorname{Re}\lambda_i \le 0\)
    渐近稳定 稳定且 \(t \to \infty\) 时轨迹趋于 \(\boldsymbol{x}_e\) \(\operatorname{Re}\lambda_i < 0\)（严格）
    指数稳定 偏差按 \(e^{-\alpha t}\) 衰减 \(\operatorname{Re}\lambda_i \le -\alpha < 0\)
    不稳定 存在任意近的初值使轨迹跑出邻域 某个 \(\operatorname{Re}\lambda_i > 0\)

    三条必须记住的要点：

    1. 只有双曲平衡点（无零实部特征值）才能用线性化判定。有零实部时线性化失效；
    2. Lyapunov 直接法只要求找到一个正定函数 \(V\) 使 \(\dot{V} \le 0\)（半负定）， 配合 LaSalle 不变原理即可得渐近稳定；
    3. 极限环是「孤立的闭合轨道」，不是平衡点，必须用别的方法（如 Poincaré–Bendixson 定理）。

    一、稳定性的严格定义¶

    为什么需要「定义」¶

    日常语言里说「系统是稳定的」，往往指「扰动后能回到原位」。 但数学上这两件事必须分开：

    • 扰动后不跑远，但也不回来（如无阻尼摆）—— 这是稳定；
    • 扰动后能回来—— 这是渐近稳定。

    混淆两者会造成工程事故：设计者以为「稳定」就够了， 结果系统在等幅振荡里长期工作，累积磨损或疲劳。

    三个定义¶

    设 \(\dot{\boldsymbol{x}} = \boldsymbol{f}(\boldsymbol{x})\)，\(\boldsymbol{f}(\boldsymbol{x}_e) = 0\)， \(\boldsymbol{x}(t)\) 是初值为 \(\boldsymbol{x}_0\) 的解。

    定义 1（Lyapunov 稳定，简称稳定）

    \[ \forall \varepsilon > 0, \ \exists \delta > 0: \quad \lVert\boldsymbol{x}_0 - \boldsymbol{x}_e\rVert < \delta \implies \lVert\boldsymbol{x}(t) - \boldsymbol{x}_e\rVert < \varepsilon, \quad \forall t \ge 0 \]

    要点：「初值足够近，轨迹就永远留在管子里」。 关键：\(\delta\) 可以依赖 \(\varepsilon\)，但不能依赖初值或时间。

    定义 2（渐近稳定）

    \[ \text{稳定} \ \wedge \ \exists \delta > 0: \lVert\boldsymbol{x}_0 - \boldsymbol{x}_e\rVert < \delta \implies \lim_{t\to\infty}\lVert\boldsymbol{x}(t) - \boldsymbol{x}_e\rVert = 0 \]

    要点：「稳定 + 最终回到平衡点」。

    定义 3（指数稳定）

    \[ \exists \alpha, \beta > 0: \quad \lVert\boldsymbol{x}(t) - \boldsymbol{x}_e\rVert \le \beta e^{-\alpha t}\lVert\boldsymbol{x}_0 - \boldsymbol{x}_e\rVert \]

    要点：「收敛速度不低于某个指数」。 这是最强的稳定性，也是工程上唯一能给出明确时间指标的定义。

    三者的关系¶

    关系 是否成立 反例
    指数稳定 \(\implies\) 渐近稳定 ✓ —
    渐近稳定 \(\implies\) 稳定 ✓ —
    稳定 \(\implies\) 渐近稳定 ✗ \(\dot{x} = 0\)（任意位置都停留）
    稳定 \(\implies\) 指数稳定 ✗ 中心型系统（无阻尼振子）
    渐近稳定 \(\implies\) 指数稳定 ✗ \(\dot{x} = -x^{3}\)（多项式收敛，非指数）

    最后一行值得说明：\(\dot{x} = -x^{3}\)、\(x(0) = x_0\) 的解是

    \[ x(t) = \frac{x_0}{\sqrt{1 + 2x_0^{2}t}} \]

    它趋于零，但按 \(t^{-1/2}\) 衰减，比任何 \(e^{-\alpha t}\) 都慢。 所以它渐近稳定但不是指数稳定。

    工程含义：任何「收敛速度保证了具体指标」的结论都要求指数稳定。 若只知道渐近稳定，收敛时间可能是无穷长。

    具体数值对比（\(\lvert x\rvert\) 从 1 衰减到给定水平所需时间）：

    衰减规律 到 \(10^{-1}\) 到 \(10^{-3}\) 到 \(10^{-6}\)
    指数 \(e^{-t}\)（\(\alpha = 1\)） 2.302585 6.907755 13.815511
    指数 \(e^{-5t}\)（\(\alpha = 5\)） 0.460517 1.381551 2.763102
    多项式 \(t^{-1/2}\)（即 \(-x^{3}\)） 49.500000 499950.0 \(5.0 \times 10^{11}\)

    结论：多项式收敛在工程上等于「不收敛」—— 到 \(10^{-6}\) 需要 \(5 \times 10^{11}\) 个时间单位。 这就是为什么控制器设计必须检查「指数衰减率 \(\alpha\)」而不仅仅是「是否会收敛」。

    平衡点与轨道稳定性¶

    概念 对象 含义
    平衡点稳定 一个点 \(\boldsymbol{x}_e\) 扰动后不跑远
    轨道稳定 一条闭合轨道（极限环） 扰动后不跑离这条轨道
    渐近轨道稳定 极限环 扰动后趋于这条轨道（吸引）

    注意两者的差别：极限环上的运动永不停止， 但可以「稳定」——因为这里的「稳定」是相对轨道而言，不是相对某个点。 这正是自激振荡的本质（下一节详述）。

    二、线性化判据（Lyapunov 第一法）¶

    雅可比矩阵¶

    设 \(\boldsymbol{f}\) 在 \(\boldsymbol{x}_e\) 处可微。令 \(\boldsymbol{\xi} = \boldsymbol{x} - \boldsymbol{x}_e\) 是小扰动，作一阶泰勒展开：

    \[ \dot{\boldsymbol{\xi}} = \boldsymbol{f}(\boldsymbol{x}_e + \boldsymbol{\xi}) \approx \boldsymbol{f}(\boldsymbol{x}_e) + J\boldsymbol{\xi} = J\boldsymbol{\xi} \]

    其中

    \[ J = \frac{\partial \boldsymbol{f}}{\partial \boldsymbol{x}}\bigg|_{\boldsymbol{x}_e}, \qquad J_{ij} = \frac{\partial f_i}{\partial x_j}\bigg|_{\boldsymbol{x}_e} \]

    \(J\) 就是雅可比矩阵（微积分模块里的 jacobian）。 注意 \(\boldsymbol{f}(\boldsymbol{x}_e) = 0\)，所以线性化后没有常数项。

    三个判定定理¶

    设 \(J\) 的特征值为 \(\lambda_1, \ldots, \lambda_n\)。

    条件 名称 结论
    全部 \(\operatorname{Re}\lambda_i < 0\) 双曲稳定 \(\boldsymbol{x}_e\) 渐近稳定（指数稳定）
    存在 \(\operatorname{Re}\lambda_i > 0\) 双曲不稳定 \(\boldsymbol{x}_e\) 不稳定
    存在 \(\operatorname{Re}\lambda_i = 0\)，其余 \(< 0\) 非双曲（临界） 线性化失效，需非线性分析

    「双曲」的含义：没有任何特征值落在虚轴上。 只有双曲平衡点，线性化才能给出确定结论。

    为什么非双曲时失效：看两个例子，线性化后的矩阵完全相同：

    系统 线性化矩阵 特征值 真实行为
    \(\dot{x} = -x^{3}\) \(J = 0\) \(0\) 渐近稳定
    \(\dot{x} = +x^{3}\) \(J = 0\) \(0\) 不稳定

    两者在原点线性化都得到零矩阵，特征值都是 \(0\)， 但真实稳定性完全相反。所以线性化在非双曲情形无法提供任何信息。

    另一个例子：\(\dot{x}_1 = x_2\)、\(\dot{x}_2 = -x_1^{3}\)（非线性弹簧）的线性化 也是 \(\begin{bmatrix}0&1\\0&0\end{bmatrix}\)（特征值 \(0\)，非双曲）， 但实际是中心型（稳定非渐近）。必须用 Lyapunov 方法分析。

    典型例：阻尼摆¶

    无穷阶模型（\(\theta\) 从竖直向下量起）：

    \[ \ddot{\theta} + k\dot{\theta} + \frac{g}{L}\sin\theta = 0 \]

    取 \(x_1 = \theta\)、\(x_2 = \dot{\theta}\)，写成状态方程：

    \[ \begin{cases} \dot{x}_1 = x_2 \\ \dot{x}_2 = -\dfrac{g}{L}\sin x_1 - kx_2 \end{cases} \]

    雅可比矩阵：

    \[ J = \begin{bmatrix} 0 & 1 \\ -\dfrac{g}{L}\cos x_1 & -k \end{bmatrix} \]

    平衡点一：\((0, 0)\)（竖直向下）。\(\cos 0 = 1\)，

    \[ J = \begin{bmatrix} 0 & 1 \\ -\dfrac{g}{L} & -k \end{bmatrix}, \qquad \det(\lambda I - J) = \lambda^{2} + k\lambda + \frac{g}{L} \]

    取 \(g/L = 9.81\ \text{s}^{-2}\)、\(k = 0.5\ \text{s}^{-1}\)：

    \[ \lambda = \frac{-0.5 \pm \sqrt{0.25 - 39.24}}{2} = -0.25 \pm 3.122099\,i \]
    量 值 含义
    \(\operatorname{Re}\lambda\) \(-0.25\) 负 → 渐近稳定 ✓
    \(\omega_d\) \(3.122099\ \text{rad/s}\) 阻尼振荡频率
    周期 \(T\) \(\dfrac{2\pi}{3.122099} \approx 2.012488\ \text{s}\) 摆动周期
    时间常数 \(\tau\) \(\dfrac{1}{0.25} = 4\ \text{s}\) 包络衰减常数
    \(\omega_n\) \(\sqrt{9.81} = 3.132092\ \text{rad/s}\) 无阻尼固有频率
    \(\zeta\) \(\dfrac{k}{2\omega_n} = \dfrac{0.5}{2\times 3.132092} \approx 0.079819\) 阻尼比

    注意 \(\zeta \approx 0.08\) 极小：这是一个严重欠阻尼系统。 按第二页的超调公式 \(M_p = \exp\left(-\dfrac{\pi\zeta}{\sqrt{1-\zeta^{2}}}\right)\)：

    \[ \sqrt{1 - 0.079819^{2}} = 0.996810, \qquad M_p = \exp\left(-\frac{\pi \times 0.079819}{0.996810}\right) = e^{-0.251637} \approx 77.75\ \% \]

    超调将近 78 %——摆会大幅越过最低点后才慢慢收敛。

    收敛时间的定量估算：包络按 \(e^{-0.25t}\) 衰减，

    目标 需要时间
    衰减到 10 % \(\dfrac{\ln 10}{0.25} \approx 9.2103\ \text{s}\)
    衰减到 1 % \(\dfrac{\ln 100}{0.25} \approx 18.4207\ \text{s}\)

    约 18.4 秒才能衰减到 1 % —— 这是「阻尼不足」的直接后果。

    工程含义：这条计算说明了「\(\operatorname{Re}\lambda\) 决定收敛快慢」。 若希望 5 秒内衰减到 1 %，需要 \(\lvert\operatorname{Re}\lambda\rvert \ge \dfrac{\ln 100}{5} = 0.921034\)， 而 \(\lvert\operatorname{Re}\lambda\rvert = \dfrac{k}{2}\)，所以

    \[ k \ge 2 \times 0.921034 = 1.842068 \]

    即阻尼系数要从 \(0.5\) 增大到约 \(1.84\)（约 3.7 倍）。

    这是「从稳定性要求反推设计参数」的完整链条。 把新参数代回去看副作用：

    \(k\) \(\lvert\operatorname{Re}\lambda\rvert\) \(\omega_d\) 周期 \(T\) \(\zeta\) 超调 \(M_p\) 到 1 %
    0.5 0.25 3.122099 2.012488 s 0.079819 77.75 % 18.4207 s
    1.842068 0.921034 2.993609 2.098866 s 0.294064 38.04 % 5.0000 s

    注意副作用：阻尼增大近 4 倍，但

    • \(\lvert\operatorname{Re}\lambda\rvert\) 只增大 3.68 倍（\(0.921034/0.25 = 3.684136\)）， 收敛时间正好降到 \(1/3.68\)；
    • \(\omega_d\) 只从 \(3.122099\) 降到 \(2.993609\)（约 4 %）， 周期几乎不变；
    • \(\zeta\) 从 \(0.0798\) 增到 \(0.2941\)，超调从 77.75 % 降到 38.04 %， 改善明显但仍不理想（38 % 的超调在精密定位中仍不可接受）。

    关键工程结论：增大阻尼能有效缩短收敛时间，但代价是响应变「迟钝」。

    把极限情形算出来看：

    \(k\) \(\zeta\) 特征值 超调 到 1 % 形态
    0.5 0.079819 \(-0.25 \pm 3.122099i\) 77.75 % 18.4207 s 严重振荡

    注意临界阻尼那一行：\(k = 2\omega_n = 2\sqrt{9.81} = 6.264184\) 给出 \(\zeta = 1\)， 特征值变成二重实根 \(-3.132092\)，没有虚部，所以不存在周期（不再振荡）。 此时 \(t\) 因子的作用（第二页讲过）使收敛变慢（\(\lvert\operatorname{Re}\lambda\rvert = 3.132092\) 但含 \(te^{-3.132092t}\) 因子）。

    所以实际设计必须在「快」与「稳」之间折中： \(\zeta\) 太小则振荡剧烈（本例 \(\zeta = 0.08\) 时超调 77.75 %）， \(\zeta\) 接近 1 则响应迟钝（二阶系统的调节时间 \(t_s \approx \dfrac{3}{\zeta\omega_n}\cdot\dfrac{1}{\zeta}\) 会随 \(\zeta\) 增大而变长）。 工程上常见的折中是取 \(\zeta\) 约 \(0.5 \sim 0.7\)， 这正好是「超调 16.3 % 到 4.3 %」的范围，既有明确的收敛速度，又不过冲太多。

    平衡点二：\((\pi, 0)\)（竖直向上）。\(\cos\pi = -1\)，

    \[ J = \begin{bmatrix} 0 & 1 \\ \dfrac{g}{L} & -k \end{bmatrix}, \qquad \lambda^{2} + k\lambda - \frac{g}{L} = 0 \]
    \[ \lambda = \frac{-0.5 \pm \sqrt{0.25 + 39.24}}{2} \implies \lambda_1 = 2.892053, \quad \lambda_2 = -3.392053 \]

    有一个正实根 \(2.892053 > 0\) → 不稳定

    工程含义：倒立摆（\((\pi, 0)\)）本质上不稳定， 这就是为什么机器人要「主动平衡」—— 必须靠控制器持续施加力矩（相当于改变 \(k\) 的符号与大小） 才能把正实根移到左半平面。这条判据是平衡控制的存在理由。

    判定流程与注意事项¶

    步骤 操作 注意
    1 求平衡点：解 \(\boldsymbol{f}(\boldsymbol{x}) = 0\) 可能有多个，必须逐个分析
    2 求雅可比矩阵 \(J\) 在每个平衡点处代入
    3 求 \(J\) 的特征值 或用 \(\operatorname{tr}\)、\(\det\) 的二维判据
    4 检查实部符号 严格小于零才渐近稳定
    5 检查是否双曲 有零实部就必须用非线性方法

    易错点：

    • 线性化只对「该平衡点的小邻域」有效。远离平衡点时线性近似失效；
    • 渐近稳定是局部性质。即使线性化给出渐近稳定， 也只知道「存在某个邻域」，不知道邻域多大（这需要吸引域分析）；
    • 多平衡点情形下「系统是否稳定」这个说法不严谨， 必须问「哪个平衡点稳定」。

    三、Lyapunov 直接法¶

    核心思想¶

    想象一个碗里的球：球总会滚向碗底。 判断这个性质不需要知道球的轨迹方程， 只需要知道「能量在减少」——这就是 Lyapunov 方法。

    设 \(V(\boldsymbol{x})\) 是一个标量函数，满足

    条件 数学表述 物理含义
    正定 \(V(\boldsymbol{x}_e) = 0\)，\(V(\boldsymbol{x}) > 0\) 对 \(\boldsymbol{x} \neq \boldsymbol{x}_e\) 「能量」非负，仅平衡点处为零
    连续可微 \(V \in C^{1}\) 可以求导
    递减 \(\dot{V}(\boldsymbol{x}) \le 0\) 能量不增加

    三个结论：

    条件 结论
    \(\dot{V} \le 0\)（半负定） \(\boldsymbol{x}_e\) Lyapunov 稳定
    \(\dot{V} < 0\)（负定） \(\boldsymbol{x}_e\) 渐近稳定
    \(\dot{V} \le -cV\)（\(c > 0\)） \(\boldsymbol{x}_e\) 指数稳定
    \(\dot{V} > 0\)（在任意小邻域内可取到正值） 不稳定

    关键：\(\dot{V}\) 是沿轨迹的导数（全导数）：

    \[ \dot{V} = \frac{\partial V}{\partial \boldsymbol{x}}\cdot\dot{\boldsymbol{x}} = \nabla V^{\mathsf{T}}\boldsymbol{f}(\boldsymbol{x}) \]

    注意这里用的是链式法则——\(\dot{V}\) 不显含时间， 因为 \(V\) 只依赖于状态，而状态的演化由方程给出。

    三种「能量」的常见取法¶

    系统类型 推荐的 \(V\) 理由
    线性 \(\dot{\boldsymbol{x}} = A\boldsymbol{x}\) \(V = \boldsymbol{x}^{\mathsf{T}}P\boldsymbol{x}\)（\(P\) 正定） 求导得 \(\boldsymbol{x}^{\mathsf{T}}(A^{\mathsf{T}}P + PA)\boldsymbol{x}\)
    机械系统 动能 + 势能 物理能量天然正定
    一般非线性 二次型 + 高阶项 试错，靠经验

    线性系统的 Lyapunov 方程¶

    对 \(\dot{\boldsymbol{x}} = A\boldsymbol{x}\) 取 \(V = \boldsymbol{x}^{\mathsf{T}}P\boldsymbol{x}\)（\(P\) 对称正定）：

    \[ \dot{V} = \dot{\boldsymbol{x}}^{\mathsf{T}}P\boldsymbol{x} + \boldsymbol{x}^{\mathsf{T}}P\dot{\boldsymbol{x}} = \boldsymbol{x}^{\mathsf{T}}A^{\mathsf{T}}P\boldsymbol{x} + \boldsymbol{x}^{\mathsf{T}}PA\boldsymbol{x} = \boldsymbol{x}^{\mathsf{T}}\left(A^{\mathsf{T}}P + PA\right)\boldsymbol{x} \]

    令 \(A^{\mathsf{T}}P + PA = -Q\)（\(Q\) 正定），则 \(\dot{V} = -\boldsymbol{x}^{\mathsf{T}}Q\boldsymbol{x} < 0\)， 立即得到渐近稳定。这就是Lyapunov 方程：

    \[ \boxed{A^{\mathsf{T}}P + PA = -Q} \]

    定理（Lyapunov）：对给定的正定 \(Q\)，

    \[ A \ \text{的所有特征值实部为负} \iff \text{方程 } A^{\mathsf{T}}P + PA = -Q \text{ 有唯一正定解 } P \]

    这条定理的价值：它把「求特征值」换成了「解线性方程组」。 在数值上，解 \(n^{2}\) 个线性方程通常比求特征值更稳定、更快， 尤其是 \(A\) 是稀疏矩阵时。

    具体例：解 Lyapunov 方程¶

    取

    \[ A = \begin{bmatrix} -3 & 1 \\ 1 & -3 \end{bmatrix}, \qquad Q = I \]

    设 \(P = \begin{bmatrix} p_{11} & p_{12} \\ p_{12} & p_{22} \end{bmatrix}\)（对称）。 \(A\) 是对称矩阵，\(A^{\mathsf{T}} = A\)，所以方程变为

    \[ 2AP = -I \implies AP = -\frac12 I \]
    \[ P = -\frac12 A^{-1} \]

    \(\det A = 9 - 1 = 8\)，

    \[ A^{-1} = \frac{1}{8}\begin{bmatrix} -3 & -1 \\ -1 & -3 \end{bmatrix} \]
    \[ P = -\frac{1}{16}\begin{bmatrix} -3 & -1 \\ -1 & -3 \end{bmatrix} = \begin{bmatrix} \dfrac{3}{16} & \dfrac{1}{16} \\[3pt] \dfrac{1}{16} & \dfrac{3}{16} \end{bmatrix} \]

    验证 \(A^{\mathsf{T}}P + PA = -I\)：

    \[ AP = \begin{bmatrix} -3 & 1 \\ 1 & -3 \end{bmatrix}\begin{bmatrix} 3/16 & 1/16 \\ 1/16 & 3/16 \end{bmatrix} = \begin{bmatrix} -9/16 + 1/16 & -3/16 + 3/16 \\ 3/16 - 3/16 & 1/16 - 9/16 \end{bmatrix} = \begin{bmatrix} -1/2 & 0 \\ 0 & -1/2 \end{bmatrix} \]
    \[ A^{\mathsf{T}}P + PA = 2AP = \begin{bmatrix} -1 & 0 \\ 0 & -1 \end{bmatrix} = -I \ \checkmark \]

    验证 \(P\) 正定（Sylvester 判据）：\(p_{11} = 3/16 \approx 0.187500 > 0\)， \(\det P = \dfrac{9}{256} - \dfrac{1}{256} = \dfrac{8}{256} = 0.031250 > 0\)

    \(P\) 的两个特征值是 \(\dfrac{3 \pm 1}{16}\)，即 \(0.25\) 与 \(0.125\)，均正

    于是 \(V = \boldsymbol{x}^{\mathsf{T}}P\boldsymbol{x}\) 的具体值：

    \(\boldsymbol{x}\) \(V = \boldsymbol{x}^{\mathsf{T}}P\boldsymbol{x}\) 计算 值
    \((1, 0)\) \(3/16\) 0.187500
    \((0, 1)\) \(3/16\) 0.187500
    \((1, 1)\) \(\dfrac{3+2+3}{16} = \dfrac{8}{16}\) 0.500000
    \((2, 0)\) \(4 \times \dfrac{3}{16}\) 0.750000

    而 \(\dot{V} = -\lVert\boldsymbol{x}\rVert^{2}\)， 所以 \(\lVert\boldsymbol{x}\rVert = 1\) 时 \(\dot{V} = -1\)： 「能量」每单位时间至少减少 1（在单位圆上）。

    更多 Lyapunov 方程的解：

    \(A\) \(\lambda(A)\) \(Q\) \(P\) \(P\) 的特征值
    \(\begin{bmatrix}-3&1\\1&-3\end{bmatrix}\) \(-2,\ -4\) \(I\) \(\begin{bmatrix}3/16&1/16\\1/16&3/16\end{bmatrix}\) \(0.25,\ 0.125\)
    \(\begin{bmatrix}-1&0\\0&-2\end{bmatrix}\) \(-1,\ -2\) \(I\) \(\begin{bmatrix}1/2&0\\0&1/4\end{bmatrix}\) \(0.5,\ 0.25\)
    \(\begin{bmatrix}-2&0\\0&-2\end{bmatrix}\) \(-2,\ -2\) \(I\) \(\begin{bmatrix}1/4&0\\0&1/4\end{bmatrix}\) \(0.25,\ 0.25\)
    \(\begin{bmatrix}0&1\\-4&-2\end{bmatrix}\) \(-1 \pm \sqrt{3}i\) \(I\) \(\begin{bmatrix}1.5&0.125\\0.125&0.3125\end{bmatrix}\) \(1.513015,\ 0.299485\)

    注意第四行的规律：特征值越靠近虚轴（实部绝对值越小）， \(P\) 的最大特征值越大（\(1.513015\)）。 这反映了一个重要事实：\(P\) 的大小衡量「能量衰减的难度」—— 越接近临界稳定，需要越大的 \(V\) 才能「证明」衰减。

    这也解释了为什么临界情形（中心）根本没有正定解 \(P\)： 对 \(A = \begin{bmatrix}0&1\\-1&0\end{bmatrix}\)（中心）， Lyapunov 方程无正定解，因为特征值实部为零，不满足定理前提。

    非线性例：\(V\) 是物理能量¶

    回到阻尼摆，取机械能作为 \(V\)：

    \[ V(x_1, x_2) = \underbrace{\frac12 x_2^{2}}_{\text{动能}} + \underbrace{\frac{g}{L}(1 - \cos x_1)}_{\text{势能}} \]

    （势能以最低点为零，所以 \(x_1 = 0\) 时 \(V = 0\)，\(x_1 \neq 0\) 时 \(V > 0\)）

    求沿轨迹的导数：

    \[ \dot{V} = x_2\dot{x}_2 + \frac{g}{L}\sin x_1 \cdot \dot{x}_1 = x_2\left(-\frac{g}{L}\sin x_1 - kx_2\right) + \frac{g}{L}\sin x_1 \cdot x_2 \]

    两项 \(\dfrac{g}{L}\sin x_1 \cdot x_2\) 恰好抵消：

    \[ \dot{V} = -kx_2^{2} \le 0 \ \checkmark \]

    这是一个漂亮的结论：能量耗散的速率只由阻尼项决定， 与势能无关 —— 这正是「阻尼消耗能量」的数学表述。

    数值验证（\(g/L = 9.81\)、\(k = 0.5\)）：

    \((x_1, x_2)\) \(V\) \(\dot{V} = -0.5x_2^{2}\)
    \((0.1, 0.0)\) 0.049009 0.000000
    \((0.5, 0.5)\) 1.325915 \(-0.125000\)
    \((1.0, 1.0)\) 5.009634 \(-0.500000\)
    \((\pi, 0)\) 19.620000 0.000000

    关键问题：\(\dot{V} \le 0\) 只是半负定（\(\dot{V} = 0\) 在整条 \(x_2 = 0\) 上都成立）， 所以不能直接推出渐近稳定。为什么？

    因为 \(\dot{V} = 0\) 的集合（\(x_2 = 0\)，即整条水平轴） 包含非平衡点。比如状态 \((1.0, 0)\)：这里 \(\dot{V} = 0\)， 但 \(x_2 = 0\)、\(\dot{x}_2 = -\dfrac{g}{L}\sin 1 = -8.25 \neq 0\)， 状态会立刻离开这条线，能量随后继续下降。

    要排除这种「暂时停在高能量状态」的可能，就需要 LaSalle 不变原理。

    四、LaSalle 不变原理与极限环¶

    不变原理的陈述¶

    LaSalle 不变原理：设 \(\Omega\) 是紧集（有界闭集）且在系统作用下正不变 （从 \(\Omega\) 出发的轨迹永不离开 \(\Omega\)）。设 \(V \in C^{1}\) 且 \(\dot{V} \le 0\) 在 \(\Omega\) 上成立。令

    \[ E = \left\{\boldsymbol{x} \in \Omega : \dot{V}(\boldsymbol{x}) = 0\right\} \]

    \(M\) 是 \(E\) 中最大的不变集（即包含在 \(E\) 中、 且在系统作用下不变的集合），则每条轨迹都趋于 \(M\)。

    关键：不需要 \(\dot{V}\) 负定，只需要「\(\dot{V} = 0\) 的地方没有非平凡的不变集」。 这个放宽极其重要，因为很多物理系统的能量导数天然是半负定的。

    「不变集」的含义：若 \(\boldsymbol{x}(0) \in M\)，则 \(\boldsymbol{x}(t) \in M\) 对所有 \(t\) 成立。 在 \(E\) 里检查不变性：取 \(E\) 中的点，代入方程看状态是否留在 \(E\) 内。

    用它证明阻尼摆的渐近稳定¶

    \(E\) 是 \(x_2 = 0\)（整条水平轴）。检查 \(E\) 中的不变集：

    在 \(E\) 上，\(x_2 = 0\)。由方程，\(\dot{x}_1 = x_2 = 0\)，而

    \[ \dot{x}_2 = -\frac{g}{L}\sin x_1 - k \cdot 0 = -\frac{g}{L}\sin x_1 \]

    要轨迹留在 \(E\) 内，必须 \(\dot{x}_2 = 0\)（否则 \(x_2\) 会变非零，离开 \(E\)）：

    \[ -\frac{g}{L}\sin x_1 = 0 \implies x_1 = n\pi, \quad n \in \mathbb{Z} \]

    所以在 \(E\) 内的不变集是平衡点的集合 \(\{(n\pi, 0)\}\)。

    结论：

    起点所在区域 轨迹收敛到
    \(\lvert x_1\rvert < \pi\)（能量小于 \(19.62\)） \((0, 0)\) —— 竖直向下，渐近稳定 ✓
    \(\pi < \lvert x_1\rvert < 3\pi\) \((\pm 2\pi, 0)\) —— 又转到下一个最低点

    这就完成了证明：Lyapunov 函数只给到「稳定」， 加上 LaSalle 才得到「渐近稳定」。

    吸引域的能量估算：取 \(V < 2g/L = 19.62\)。 为什么是这个界？因为 \(V(\pi, 0) = \dfrac{g}{L}(1 - \cos\pi) = 2\dfrac{g}{L} = 19.62\)， 而 \(V\) 沿轨迹不增，所以能量小于势垒高度的轨迹永远爬不过倒立位置 ✓

    \[ \Omega = \left\{(x_1, x_2): \frac12x_2^{2} + \frac{g}{L}(1-\cos x_1) < 2\frac{g}{L}\right\} \]
    \(x_1\)（\(x_2=0\)） \(V\) 是否在吸引域内
    0.5 1.200915 ✓
    1.0 4.509634 ✓
    \(\pi\) 19.620000 边界（临界）
    \(2\pi\) 之外 — 会翻转过去

    工程含义：吸引域就是「系统能承受多大扰动的容许范围」。 它用能量给出：初始能量只要低于势垒，就能回到最低点。 这个结论不需要解方程，也不依赖阻尼大小 —— 只要阻尼为正（\(k > 0\)），就有 \(\dot{V} \le 0\)。

    极限环：稳定的自激振荡¶

    定义：极限环是一条孤立的闭合轨道， 其周期与幅值由系统本身决定，与初始条件无关。

    与中心的关键区别：

    对比项 中心（无阻尼振子） 极限环
    闭合轨道数量 无穷多条（每个初值一条） 有限条（孤立）
    周期与幅值 依赖初始条件 不依赖初始条件
    能否被扰动破坏 会变成螺旋（加阻尼即破坏） 不会（被扰动后仍回到环上）
    数学名称 保守系统 结构稳定的自激振荡

    典型例：van der Pol 振子

    \[ \ddot{x} - \mu(1 - x^{2})\dot{x} + x = 0, \qquad \mu > 0 \]

    写成状态方程：

    \[ \dot{x} = y, \qquad \dot{y} = \mu(1 - x^{2})y - x \]

    关键的物理机制：看 \(\mu(1-x^{2})\) 这一项，

    \(\lvert x\rvert\) 系数符号 作用
    \(\lvert x\rvert < 1\) 正 阻尼为负 → 能量注入，振幅增大
    \(\lvert x\rvert > 1\) 负 阻尼为正 → 能量耗散，振幅减小

    这两种作用在 \(\lvert x\rvert = 1\) 处切换， 所以振幅既不会无限增大也不会衰减到零 —— 必然稳定在某个中间幅度，这就是极限环。

    数值结果（四阶 Runge–Kutta，步长 \(2\times 10^{-4}\)）：

    \(\mu\) 幅值 \(x_{\max}\) 周期 \(T\) \(T/2\pi\)
    0.1 2.000104 6.287106 1.00062
    0.2 2.000414 6.298872 1.00250
    0.5 2.002488 6.380678 1.01552
    1.0 2.008620 6.663303 1.06050
    2.0 2.019891 7.629862 1.21433
    5.0 2.021508 11.612215 1.84814

    两个重要观察：

    1. 幅值几乎不随 \(\mu\) 变化：从 \(\mu = 0.1\) 到 \(\mu = 5.0\)， \(x_{\max}\) 只从 \(2.000104\) 变到 \(2.021508\)（变化约 1 %）。 这与「极限环幅值由系统决定」完全一致 —— 幅值几乎是一个几何常数，而不是可调参数。
    2. 周期随 \(\mu\) 显著增大：从 \(6.287\) 增到 \(11.612\)， 约 \(1.85\) 倍。大 \(\mu\) 时振荡变慢（因为能量交换过程更剧烈、更「松弛」）。

    平均法（小 \(\mu\) 近似）：

    \[ T \approx 2\pi\left(1 + \frac{\mu^{2}}{16} - \frac{5\mu^{4}}{3072} + \cdots\right) \]
    \(\mu\) 平均法 \(T\) 数值 \(T\) 相对误差
    0.2 6.298877 6.298872 约 \(10^{-6}\) ✓
    1.0 6.665658 6.663303 约 \(0.035\ \%\)
    2.0 7.690357 7.629862 约 \(0.79\ \%\)

    结论：平均法在小 \(\mu\) 时极其精确（\(\mu = 0.2\) 时误差百万分之一）， 但 \(\mu\) 增大后误差迅速增长（\(\mu = 2\) 时接近 1 %）。 这符合「平均法是 \(\mu\) 的渐近展开」的定位。

    工程含义：van der Pol 方程是自激振荡的标准模型：

    工程现象 对应的 \(\mu\) 意义
    电子管/晶体管振荡器起振 非线性增益限制振幅
    心脏起搏细胞的节律 极限环 = 稳定心率
    航空发动机喘振 极限环 = 危险的自持振荡
    机械摩擦引起的爬行 负阻尼效应

    关键区别：共振（第二页）是外部驱动频率撞上系统固有频率， 去掉驱动就消失了；而极限环是自激的， 没有外部驱动也会持续振荡。这是两类完全不同的振荡。

    极限环的判定工具：

    方法 适用条件 结论
    Poincaré–Bendixson 定理 二维自治系统；存在有界闭集无平衡点，且轨迹不能离开 必有闭合轨道
    Bendixson 判据 二维；\(\nabla\cdot\boldsymbol{f} = \dfrac{\partial f_1}{\partial x} + \dfrac{\partial f_2}{\partial y}\) 不变号 无闭合轨道
    数值搜索 通用 找穿越相截线（Poincaré 截面）的周期点

    用 Bendixson 判据排除极限环：对 van der Pol，

    \[ \nabla\cdot\boldsymbol{f} = \frac{\partial y}{\partial x} + \frac{\partial}{\partial y}\left[\mu(1-x^{2})y - x\right] = 0 + \mu(1-x^{2}) \]

    这个量在 \(\lvert x\rvert > 1\) 时为负、\(\lvert x\rvert < 1\) 时为正，会变号， 所以 Bendixson 判据不适用（判据要求不变号）， 极限环不被排除 —— 这与数值结果（确实有极限环）一致

    显式可解的极限环例子¶

    考虑

    \[ \dot{x} = -y + x(1 - x^{2} - y^{2}), \qquad \dot{y} = x + y(1 - x^{2} - y^{2}) \]

    转到极坐标 \(r^{2} = x^{2} + y^{2}\)。先算 \(r\dot{r} = x\dot{x} + y\dot{y}\)：

    \[ x\dot{x} + y\dot{y} = x\left[-y + x(1-r^{2})\right] + y\left[x + y(1-r^{2})\right] = -xy + x^{2}(1-r^{2}) + xy + y^{2}(1-r^{2}) = r^{2}(1-r^{2}) \]

    所以

    \[ \dot{r} = r(1 - r^{2}) \]

    再算 \(\dot{\theta}\)。由

    \[ x\dot{y} - y\dot{x} = x\left[x + y(1-r^{2})\right] - y\left[-y + x(1-r^{2})\right] = x^{2} + y^{2} = r^{2} \]

    而 \(x\dot{y} - y\dot{x} = r^{2}\dot{\theta}\)，得

    \[ \dot{\theta} = 1 \]

    这是最干净的极限环例子：

    半径 \(\dot{r} = r(1-r^{2})\) 行为
    \(r = 0.5\) \(0.375000\) 向外扩大
    \(r = 0.9\) \(0.171000\) 向外扩大
    \(r = 1.0\) \(0.000000\) 不动 —— 极限环
    \(r = 1.1\) \(-0.231000\) 向内收缩
    \(r = 2.0\) \(-6.000000\) 向内收缩

    \(r = 1\) 是稳定极限环：内侧向外、外侧向内，两侧都被吸引过来。

    \(\dot{r} = r(1-r^{2})\) 可以精确求解（伯努利方程，与第一页一致）。 令 \(u = r^{2}\)，则 \(\dot{u} = 2r\dot{r} = 2u(1-u)\)，分离变量得

    \[ r^{2}(t) = \frac{1}{1 + \left(\dfrac{1}{r_0^{2}} - 1\right)e^{-2t}} \]

    数值验证：

    初值 \(r_0\) \(t = 0.5\) \(t = 1.0\) \(t = 2.0\) \(t = 5.0\) \(t \to \infty\)
    0.5 0.689469 0.843347 0.973609 0.999932 1.000000
    2.0 1.175178 1.054973 1.006940 1.000017 1.000000

    两个方向的初值都收敛到 \(r = 1\) 而且周期 \(T = \dfrac{2\pi}{\dot{\theta}} = 2\pi\)，与初值完全无关。

    \(t = 5\) 时误差已到 \(10^{-4}\) 量级（\(r_0 = 0.5\) 时 \(0.999932\)）， 说明收敛到极限环是相当快的—— 因为 \(\dot{r}\) 在 \(r\) 接近 1 时近似为 \(-2(r-1)\)，即指数收敛。

    工程含义：这个例子的价值在于它可解， 所以能精确验证「极限环的吸引性」。 实际系统（如 van der Pol）通常不可解， 只能靠数值方法画相图或 Poincaré 截面， 但结论模式完全相同：内侧外扩、外侧内收、中间稳定。

    例题 1：Lyapunov 方程求解与验证¶

    对 \(A = \begin{bmatrix} -3 & 1 \\ 1 & -3 \end{bmatrix}\)、\(Q = I\)， 解 Lyapunov 方程 \(A^{\mathsf{T}}P + PA = -Q\)， 验证 \(P\) 正定，并求 \(V = \boldsymbol{x}^{\mathsf{T}}P\boldsymbol{x}\) 在 \((1,1)\) 处的值。

    思路

    先看 \(A\) 是否对称。若 \(A^{\mathsf{T}} = A\)，则方程化为 \(2AP = -I\)， 可以直接求逆得到 \(P\)。

    解答

    特征值（用于确认前提）：\(\operatorname{tr} = -6\)、\(\det = 8\)，

    \[ \lambda^{2} + 6\lambda + 8 = 0 \implies \lambda = -2,\ -4 \]

    两者都负 ✓，所以 Lyapunov 方程必有唯一正定解。 化简方程：\(A^{\mathsf{T}} = A\)（因为 \(A\) 对称），所以

    \[ A^{\mathsf{T}}P + PA = AP + PA = 2AP = -I \]
    \[ AP = -\frac12 I \implies P = -\frac12 A^{-1} \]

    求逆：\(\det A = (-3)(-3) - 1 \cdot 1 = 9 - 1 = 8\)，

    \[ A^{-1} = \frac{1}{8}\begin{bmatrix} -3 & -1 \\ -1 & -3\end{bmatrix} \]
    \[ P = -\frac{1}{16}\begin{bmatrix} -3 & -1 \\ -1 & -3\end{bmatrix} = \begin{bmatrix} \dfrac{3}{16} & \dfrac{1}{16} \\[3pt] \dfrac{1}{16} & \dfrac{3}{16} \end{bmatrix} = \begin{bmatrix} 0.187500 & 0.062500 \\ 0.062500 & 0.187500 \end{bmatrix} \]

    验证方程：

    \[ AP = \begin{bmatrix} -3 & 1 \\ 1 & -3 \end{bmatrix}\begin{bmatrix} 3/16 & 1/16 \\ 1/16 & 3/16 \end{bmatrix} = \begin{bmatrix} (-9+1)/16 & (-3+3)/16 \\ (3-3)/16 & (1-9)/16 \end{bmatrix} = \begin{bmatrix} -1/2 & 0 \\ 0 & -1/2 \end{bmatrix} \]
    \[ 2AP = \begin{bmatrix} -1 & 0 \\ 0 & -1 \end{bmatrix} = -I \ \checkmark \]

    验证 \(P\) 正定（Sylvester 判据：\(p_{11} > 0\) 且 \(\det P > 0\)）：

    \[ p_{11} = 0.187500 > 0 \ \checkmark \]
    \[ \det P = \frac{3}{16}\cdot\frac{3}{16} - \frac{1}{16}\cdot\frac{1}{16} = \frac{9 - 1}{256} = \frac{8}{256} = 0.031250 > 0 \ \checkmark \]

    \(P\) 的特征值：\(\operatorname{tr} = 0.375000\)、\(\det = 0.031250\)， \(\lambda = \dfrac{0.375 \pm \sqrt{0.140625 - 0.125}}{2} = \dfrac{0.375 \pm 0.125}{2}\)，

    \[ \lambda_1 = 0.25, \qquad \lambda_2 = 0.125 \]

    都为正

    求 \(V(1,1)\)：

    \[ V = \begin{bmatrix}1&1\end{bmatrix}\begin{bmatrix} 3/16 & 1/16 \\ 1/16 & 3/16 \end{bmatrix}\begin{bmatrix}1\\1\end{bmatrix} = \frac{3}{16} + \frac{1}{16} + \frac{1}{16} + \frac{3}{16} = \frac{8}{16} = 0.500000 \]

    \(V(1,1) = 0.5\)。

    其他点的值：

    \(\boldsymbol{x}\) \(V\)
    \((1,0)\) 0.187500
    \((0,1)\) 0.187500
    \((1,1)\) 0.500000
    \((2,0)\) 0.750000

    结论：\(\dot{V} = -\boldsymbol{x}^{\mathsf{T}}\boldsymbol{x} = -\lVert\boldsymbol{x}\rVert^{2}\)， 所以 \(V\) 沿轨迹严格递减， \(\boldsymbol{x} = (1,1)\) 处 \(\dot{V} = -2\)。

    工程含义：\(\dot{V} = -\lVert\boldsymbol{x}\rVert^{2}\) 说明 「能量」\(V\) 的衰减率等于状态模长的平方。 所以状态越远离原点，能量衰减越快 —— 这是一种「自动加速收敛」的机制， 与 \(\dot{x} = -x^{3}\)（距离越远衰减越快）的定性行为一致。

    例题 2：非双曲情形与线性化的失效¶

    用 \(\dot{x} = -x^{3}\) 说明线性化判据为何失效， 并用 Lyapunov 方法证明原点是渐近稳定的，同时求收敛时间。

    思路

    线性化矩阵在原点为零矩阵，特征值全为 0（非双曲）。 取 \(V = x^{2}\)，算 \(\dot{V}\)。

    解答

    线性化：\(f(x) = -x^{3}\)，\(f'(x) = -3x^{2}\)，

    \[ J = f'(0) = 0 \]

    特征值为 \(0\)，属于非双曲情形 → 按第二节的定理，线性化无法给出任何结论。

    为什么失效：对比 \(\dot{x} = +x^{3}\)，

    系统 \(J\) 在原点 特征值 真实稳定性 线性化能判断吗
    \(\dot{x} = -x^{3}\) \(0\) \(0\) 渐近稳定 ✗
    \(\dot{x} = +x^{3}\) \(0\) \(0\) 不稳定 ✗

    两个系统的线性化完全相同，稳定性却相反 —— 这说明线性化在非双曲情形丢掉了全部有效信息。

    用 Lyapunov 方法：取

    \[ V(x) = x^{2} \]

    \(V > 0\) 对 \(x \neq 0\)，\(V(0) = 0\) ✓ 正定。

    \[ \dot{V} = 2x\dot{x} = 2x(-x^{3}) = -2x^{4} < 0 \quad (x \neq 0) \]

    负定 → 原点是渐近稳定的

    精确解：\(\dot{x} = -x^{3}\) 是可分离变量方程（第一页！），

    \[ \frac{\mathrm{d}x}{x^{3}} = -\mathrm{d}t \implies -\frac{1}{2x^{2}} = -t + C \]

    由 \(x(0) = x_0\) 得 \(C = -\dfrac{1}{2x_0^{2}}\)，所以

    \[ \frac{1}{2x^{2}} = t + \frac{1}{2x_0^{2}} \implies x(t) = \frac{x_0}{\sqrt{1 + 2x_0^{2}t}} \]

    收敛时间（\(x_0 = 1\)）：

    \[ x(t) = \frac{1}{\sqrt{1 + 2t}} \]
    目标 \(\lvert x\rvert\) 需要 \(t\)
    \(10^{-1}\) \(\dfrac{1}{2}\left(\dfrac{1}{0.01} - 1\right) = 49.5\)
    \(10^{-3}\) \(\dfrac{1}{2}\left(10^{6} - 1\right) = 499999.5\)
    \(10^{-6}\) \(\dfrac{1}{2}\left(10^{12} - 1\right) \approx 5 \times 10^{11}\)

    到 \(10^{-6}\) 需要 \(5 \times 10^{11}\) 个时间单位

    与指数衰减的对比（同样从 1 出发）：

    衰减规律 到 \(10^{-1}\) 到 \(10^{-3}\) 到 \(10^{-6}\)
    \(-x^{3}\)（多项式） 49.5 \(5.0 \times 10^{5}\) \(5.0 \times 10^{11}\)
    \(-x\)（指数 \(e^{-t}\)） 2.302585 6.907755 13.815511
    \(-5x\)（指数 \(e^{-5t}\)） 0.460517 1.381551 2.763102

    结论：\(\dot{x} = -x^{3}\) 渐近稳定但不是指数稳定， 而且在实际工程时间尺度上等于不收敛。

    注意 \(\dot{V} = -2x^{4}\) 与 \(V = x^{2}\) 的关系： \(\dot{V} = -2V^{2}\)，这是关于 \(V\) 的非线性方程，不是 \(\dot{V} \le -cV\) 的形式， 所以只能得到渐近稳定（多项式速率），得不到指数稳定。 若要有 \(\dot{V} \le -cV\)，需要 \(f(x)\) 在原点附近至少线性（\(f(x) \approx -\alpha x\)）。

    工程含义：这解释了一个常见困惑 —— 「理论上证明收敛了，为什么实测还是不收敛？」 因为「渐近稳定」不给出任何收敛速度保证。 设计时必须额外确认指数稳定（即线性化后 \(\operatorname{Re}\lambda < 0\) 且留有余量）。

    例题 3：相图分类与阻尼比反推¶

    给定 \(A = \begin{bmatrix} 0 & 1 \\ -4 & -2 \end{bmatrix}\)， 判断平衡点类型、求 Lyapunov 方程的 \(P\)、 计算阻尼比与超调量，并求「衰减到 1 % 需要多久」。

    思路

    先算 \(\operatorname{tr}\)、\(\det\)、判别式确定类型。 然后解 Lyapunov 方程（\(A\) 不对称，需要解三个方程）。 最后用 \(\zeta = \lvert\operatorname{Re}\lambda\rvert/\omega_n\)。

    解答

    第一步：相图分类

    \[ \operatorname{tr}(A) = 0 + (-2) = -2, \qquad \det(A) = 0\cdot(-2) - 1\cdot(-4) = 4 \]
    \[ \Delta = \operatorname{tr}^{2} - 4\det = 4 - 16 = -12 < 0 \]
    判据 值 结论
    \(\det\) \(+4 > 0\) 非鞍点
    \(\Delta\) \(-12 < 0\) 焦点
    \(\operatorname{tr}\) \(-2 < 0\) 稳定

    稳定焦点。特征值：

    \[ \lambda = \frac{-2 \pm \sqrt{-12}}{2} = -1 \pm 1.732051\,i \]

    第二步：解 Lyapunov 方程。设 \(P = \begin{bmatrix} p_{11} & p_{12} \\ p_{12} & p_{22}\end{bmatrix}\)， 代入 \(A^{\mathsf{T}}P + PA = -I\)：

    \[ \begin{cases} 2(0 \cdot p_{11} + (-4)p_{12}) = -1 & \text{（(1,1) 元）} \\ 1\cdot p_{11} + (-2 + 0)p_{12} + (-4)p_{22} = 0 & \text{（(1,2) 元）} \\ 2(1 \cdot p_{12} + (-2)p_{22}) = -1 & \text{（(2,2) 元）} \end{cases} \]

    由第一式：\(-8p_{12} = -1 \implies p_{12} = 0.125\)。

    由第三式：\(2p_{12} - 4p_{22} = -1 \implies 0.25 - 4p_{22} = -1 \implies p_{22} = 0.3125\)。

    由第二式：\(p_{11} - 2(0.125) - 4(0.3125) = 0 \implies p_{11} = 0.25 + 1.25 = 1.5\)。

    \[ P = \begin{bmatrix} 1.500000 & 0.125000 \\ 0.125000 & 0.312500 \end{bmatrix} \]

    验证正定：\(p_{11} = 1.5 > 0\)， \(\det P = 1.5 \times 0.3125 - 0.125^{2} = 0.468750 - 0.015625 = 0.453125 > 0\)

    \(P\) 的特征值：\(\operatorname{tr} = 1.812500\)、\(\det = 0.453125\)， \(\operatorname{tr}^{2} - 4\det = 3.285156 - 1.812500 = 1.472656\)，\(\sqrt{1.472656} = 1.213530\)，所以

    \[ \lambda = \frac{1.812500 \pm 1.213530}{2} \implies \lambda_1 = 1.513015, \quad \lambda_2 = 0.299485 \]

    都为正

    第三步：阻尼比与超调

    \[ \omega_n = \sqrt{\operatorname{Re}\lambda^{2} + \operatorname{Im}\lambda^{2}} = \sqrt{1 + 3} = 2 \]
    \[ \zeta = \frac{\lvert\operatorname{Re}\lambda\rvert}{\omega_n} = \frac{1}{2} = 0.5 \]

    （也可用 \(\zeta = \dfrac{b}{2\sqrt{ac}} = \dfrac{2}{2\sqrt{4}} = 0.5\)）

    \[ M_p = \exp\left(-\frac{\pi\zeta}{\sqrt{1-\zeta^{2}}}\right) = \exp\left(-\frac{\pi \times 0.5}{\sqrt{0.75}}\right) = \exp\left(-\frac{1.570796}{0.866025}\right) = e^{-1.813799} \approx 16.3034\ \% \]

    超调约 16.30 %。

    阻尼振荡周期：

    \[ T = \frac{2\pi}{\lvert\operatorname{Im}\lambda\rvert} = \frac{2\pi}{1.732051} \approx 3.627599\ \text{s} \]

    第四步：衰减到 1 % 所需时间

    \[ t = \frac{\ln 100}{\lvert\operatorname{Re}\lambda\rvert} = \frac{4.605170}{1} = 4.605170\ \text{s} \]

    小结：

    指标 值 来源
    平衡点类型 稳定焦点 \(\det>0\)、\(\Delta<0\)、\(\operatorname{tr}<0\)
    特征值 \(-1 \pm 1.732051\,i\) 特征方程
    \(\omega_n\) \(2\ \text{rad/s}\) 特征值模长
    \(\zeta\) \(0.5\) \(\lvert\operatorname{Re}\lambda\rvert/\omega_n\)
    超调 \(M_p\) \(16.30\ \%\) \(\exp(-\pi\zeta/\sqrt{1-\zeta^{2}})\)
    振荡周期 \(3.627599\ \text{s}\) \(2\pi/\lvert\operatorname{Im}\lambda\rvert\)
    衰减到 1 % \(4.605170\ \text{s}\) \(\ln 100/\lvert\operatorname{Re}\lambda\rvert\)
    \(P\) 最大特征值 \(1.513015\) Lyapunov 方程

    注意 \(P\) 与 \(\lvert\operatorname{Re}\lambda\rvert\) 的关系：

    矩阵 \(A\) 特征值 \(P\) 的最大特征值
    \(\begin{bmatrix}-3&1\\1&-3\end{bmatrix}\) \(-2,\ -4\)（纯实） \(0.25\)
    \(\begin{bmatrix}-1&0\\0&-2\end{bmatrix}\) \(-1,\ -2\) \(0.5\)
    \(\begin{bmatrix}0&1\\-4&-2\end{bmatrix}\) \(-1 \pm 1.732051\,i\) \(1.513015\)

    规律：特征值的实部越接近虚轴（\(\lvert\operatorname{Re}\lambda\rvert\) 越小）、 虚部越大（振荡越强），\(P\) 的最大特征值就越大。 因为「振荡型」和「接近临界」的能量最难被快速耗尽， 需要更大的 \(V\) 才能「证明」衰减。

    更进一步：\(\lambda_{\max}(P)\) 大致反比于「到虚轴的距离」。 这正是工程上「留出稳定裕量」的定量依据 —— 若 \(\lvert\operatorname{Re}\lambda\rvert\) 很小，\(P\) 会很大， 意味着很小的扰动就会引起很大的能量变化， 系统对参数误差极为敏感。

    工程含义：这张表就是一套完整的性能评估模板。 只要给定了 \(A\)，全部指标都能从特征值算出， 不需要任何仿真。反过来，若设计要求「超调 < 20 %、5 秒收敛」， 就可以直接反推所需的 \(\zeta\) 与 \(\lvert\operatorname{Re}\lambda\rvert\)， 再据此设计控制器增益。

    例题 4：用 LaSalle 不变原理证明渐近稳定¶

    对系统 \(\dot{x} = y\)、\(\dot{y} = -x - y^{3}\)， 用 \(V = \dfrac{x^{2} + y^{2}}{2}\) 分析原点的稳定性， 并说明为什么必须用 LaSalle 不变原理而不能直接下结论。

    思路

    先算 \(\dot{V}\)，会发现它只是半负定（在 \(y = 0\) 上为零）。 然后检查 \(\dot{V} = 0\) 集合内是否存在非平凡不变集。

    解答

    第一步：算 \(\dot{V}\)

    \[ V = \frac{x^{2} + y^{2}}{2} \]

    \(V > 0\) 对 \((x,y) \neq (0,0)\)，\(V(0,0) = 0\) ✓ 正定。

    \[ \dot{V} = x\dot{x} + y\dot{y} = x \cdot y + y \cdot (-x - y^{3}) \]

    第一项与第二项中的 \(-xy\) 恰好抵消：

    \[ \dot{V} = xy - xy - y^{4} = -y^{4} \le 0 \]

    \(\dot{V} \le 0\) 是半负定的（在整条 \(y = 0\) 上都为零）， 所以只能得到 Lyapunov 稳定，不能直接得到渐近稳定。

    数值检查：

    \((x,y)\) \(V\) \(\dot{V} = -y^{4}\)
    \((1, 0)\) 0.500000 0.000000
    \((1, 1)\) 1.000000 \(-1.000000\)
    \((0, 2)\) 2.000000 \(-16.000000\)

    注意 \((1,0)\) 处 \(\dot{V} = 0\)，但这时系统并不平衡： \(\dot{x} = y = 0\)、\(\dot{y} = -x - y^{3} = -1 \neq 0\)。 状态会立刻离开 \(y = 0\) 这条线。

    第二步：检查 \(\dot{V} = 0\) 集合内的不变集

    \[ E = \left\{(x, y) : \dot{V} = 0\right\} = \left\{(x, y) : y = 0\right\} \]

    在 \(E\) 上（即 \(y = 0\)），看方程：

    \[ \dot{x} = y = 0, \qquad \dot{y} = -x - y^{3} = -x \]

    若轨迹要留在 \(E\) 内，必须有 \(\dot{y} = 0\)（否则 \(y\) 会变成非零，离开 \(E\)）：

    \[ -x = 0 \implies x = 0 \]

    所以 \(E\) 内唯一的不变集是原点 \(M = \{(0,0)\}\)。

    第三步：应用 LaSalle 不变原理

    取

    \[ \Omega = \left\{(x,y) : \frac{x^{2}+y^{2}}{2} \le \rho\right\} \]

    对任意 \(\rho > 0\)，\(\Omega\) 是有界闭集（紧集）。 因为 \(\dot{V} \le 0\)，从 \(\Omega\) 出发的轨迹满足 \(V \le \rho\)， 所以保持在 \(\Omega\) 内（正不变）

    由 LaSalle 不变原理，每条轨迹趋向 \(M = \{(0,0)\}\)，所以原点是

    \[ \textbf{渐近稳定} \]

    的

    第四步：能否得到指数稳定？

    \(\dot{V} = -y^{4}\)。当 \(y\) 很小时 \(y^{4}\) 比 \(\lVert(x,y)\rVert^{2} = 2V\) 小得多， 所以不存在常数 \(c > 0\) 使 \(\dot{V} \le -cV\)。

    用线性化验证：\(f_1 = y\)、\(f_2 = -x - y^{3}\)，

    \[ J = \begin{bmatrix} \dfrac{\partial f_1}{\partial x} & \dfrac{\partial f_1}{\partial y} \\[4pt] \dfrac{\partial f_2}{\partial x} & \dfrac{\partial f_2}{\partial y} \end{bmatrix}_{(0,0)} = \begin{bmatrix} 0 & 1 \\ -1 & -3y^{2} \end{bmatrix}_{(0,0)} = \begin{bmatrix} 0 & 1 \\ -1 & 0 \end{bmatrix} \]

    特征值 \(\lambda^{2} + 1 = 0 \implies \lambda = \pm i\)， 零实部 → 非双曲！ 线性化不能判定。

    但 Lyapunov + LaSalle 给出了明确结论：渐近稳定。

    注意：虽然渐近稳定，但收敛是多项式速率而不是指数速率 （因为 \(y^{4}\) 在原点附近太小）。 这一点只要对比 \(\dot{y} = -x - y\)（线性阻尼）就看得清楚：

    系统 \(\dot{V}\) 线性化特征值 稳定性类型
    \(\dot{y} = -x - y\) \(-y^{2}\) \(-0.5 \pm 0.866025\,i\) 指数稳定
    \(\dot{y} = -x - y^{3}\) \(-y^{4}\) \(\pm i\)（非双曲） 渐近但非指数

    结论汇总：

    问题 答案
    \(V\) 是否正定 ✓
    \(\dot{V}\) 是否负定 ✗（半负定）
    能否直接得渐近稳定 ✗
    LaSalle 后能否得渐近稳定 ✓
    线性化能否判定 ✗（非双曲）
    是否指数稳定 ✗（多项式速率）

    工程含义：这个例题说明了 Lyapunov 方法的不可替代性—— 在非双曲情形（线性化完全失效）， Lyapunov 直接法是唯一能给出结论的工具。 同时它提醒：「渐近稳定」离「工程可用」还有一段距离， 必须进一步确认收敛速率。

    六、用在哪些课程里¶

    机器人学 · 平衡控制与安全判定¶

    • 倒立摆/双足平衡：\(( \pi, 0)\)（竖直向上）是不稳定平衡点 （本页算出的 \(\lambda_1 = 2.892053 > 0\)）， 所以必须靠状态反馈主动把特征值移到左半平面 —— 这是平衡控制的根本理由；
    • 吸引域决定安全边界：机器人推挤恢复、外力扰动的容许范围， 就是「平衡点的吸引域」；
    • Lyapunov 函数即能量：机械臂的「动能 + 势能」天然是 \(V\)， \(\dot{V} = -\text{耗散}\) 正好对应阻尼器的功耗；
    • 接触力与安全：把「安全约束」写成 \(V \le V_{\max}\)， 一旦接近边界就减速，这是 Lyapunov 型安全控制器的基本思路。

    现代数字信号处理 · 滤波器稳定性与自适应算法¶

    • IIR 滤波器稳定性：极点必须在单位圆内（离散系统的 \(\lvert z \rvert < 1\) 对应连续系统的 \(\operatorname{Re}\lambda < 0\)）， 这是本页判据的离散版本；
    • 自适应滤波的收敛：LMS 算法的权重误差动态是 \(\boldsymbol{w}_{k+1} = (I - \mu R)\boldsymbol{w}_k\)， 收敛要求步长 \(\mu < \dfrac{2}{\lambda_{\max}(R)}\) —— 这正是本页「特征值决定稳定性」的直接应用；
    • 数值实现中的极限环：定点 IIR 滤波器会因舍入出现 「零输入振荡」，本质是量化误差制造的伪极限环， 其幅度分析要用本页的极限环理论；
    • 锁相环的捕获与失锁：捕获范围就是「平衡点的吸引域」， 超出范围会跳到另一个平衡点（cycle slip）。

    无人系统自主决策与优化 · 收敛性与安全约束¶

    • 轨迹跟踪的误差动态：在参考轨迹上线性化得到 \(\dot{e} = A(t)e\)， 稳定性由瞬时特征值（或用 Lyapunov 函数族）判定；
    • 多智能体一致性：\(A = -\mathcal{L}\)， 收敛性由 Laplacian 的特征值给出， \(\lambda_2 > 0\) 保证一致（对应双曲稳定判据）；
    • 安全控制的 CBF 方法：控制障碍函数（Control Barrier Function） 就是 Lyapunov 函数的对偶形式 —— Lyapunov 要求 \(V\) 递减（趋向目标）， CBF 要求 \(h\) 不递减（远离禁区）；
    • 优化算法的收敛性证明：梯度流 \(\dot{x} = -\nabla f(x)\) 取 \(V = f(x) - f^{*}\)，则 \(\dot{V} = -\lVert\nabla f\rVert^{2} \le 0\)， LaSalle 给出收敛到驻点集合 —— 这就是「梯度下降收敛」的标准证明，与本节证明完全同构；
    • 决策的鲁棒性：影响函数给出「扰动使代价变化多少」， 但稳定性（扰动是否会让状态发散）是更基本的问题， 必须先解决。

    七、自测¶

    Q1 判断 \(A = \begin{bmatrix} 0 & 1 \\ -4 & -2 \end{bmatrix}\) 的平衡点类型， 求阻尼比与振荡周期。

    提示

    \(\operatorname{tr} = -2\)、\(\det = 4\)、\(\Delta = -12\)。 特征值 \(-1 \pm \sqrt{3}i\)，\(\omega_n = 2\)。

    解答

    类型判定：

    \[ \operatorname{tr} = -2, \qquad \det = 4, \qquad \Delta = 4 - 16 = -12 < 0 \]
    判据 值 结论
    \(\det > 0\) 4 不是鞍点
    \(\Delta < 0\) \(-12\) 焦点
    \(\operatorname{tr} < 0\) \(-2\) 稳定

    稳定焦点

    特征值：

    \[ \lambda = \frac{-2 \pm \sqrt{-12}}{2} = -1 \pm \sqrt{3}\,i \approx -1 \pm 1.732051\,i \]

    阻尼比与周期：

    \[ \omega_n = \sqrt{(-1)^{2} + (\sqrt{3})^{2}} = \sqrt{1 + 3} = 2 \]
    \[ \zeta = \frac{\lvert\operatorname{Re}\lambda\rvert}{\omega_n} = \frac{1}{2} = 0.5 \]
    \[ T = \frac{2\pi}{\sqrt{3}} = \frac{6.283185}{1.732051} \approx 3.627599\ \text{s} \]

    超调量：

    \[ M_p = \exp\left(-\frac{\pi \times 0.5}{\sqrt{1 - 0.25}}\right) = e^{-1.813799} \approx 16.3034\ \% \]

    结果汇总：

    指标 值
    类型 稳定焦点
    特征值 \(-1 \pm 1.732051\,i\)
    \(\omega_n\) \(2\ \text{rad/s}\)
    \(\zeta\) \(0.5\)
    周期 \(T\) \(3.627599\ \text{s}\)
    超调 \(M_p\) \(16.3034\ \%\)

    与例题 1 的对照：例题 1 的 \(A = \begin{bmatrix}-3&1\\1&-3\end{bmatrix}\) 是稳定结点（特征值 \(-1\)、\(-3\)，全为实数）， 不会振荡；而本题是稳定焦点，会振荡。 两者的 \(\operatorname{Re}\lambda\) 都是 \(-1\)， 所以包络衰减速率相同（时间常数都是 1）， 区别只在有没有虚部。

    工程含义：这组对照直接说明了 「虚部管振荡、实部管稳定」这一条判据的实用价值。 在控制器设计中，虚部（振荡频率）与实部（衰减速率） 可以通过不同的反馈通道相对独立地调节， 这正是 PID 中 P/I/D 各项分工的数学基础。

    Q2 判断系统 \(\dot{x} = -x^{3}\)、\(\dot{y} = -y^{3}\) 的原点稳定性， 求 \((1,1)\) 处的 \(\dot{V}\)（取 \(V = \dfrac{x^{2}+y^{2}}{2}\)）， 并说明线性化能否判定。

    提示

    算 \(\dot{V} = x\dot{x} + y\dot{y}\)，注意符号。 线性化矩阵在原点是什么？

    解答

    取 \(V = \dfrac{x^{2}+y^{2}}{2}\)：\(V > 0\) 对 \((x,y) \neq (0,0)\) ✓ 正定。

    计算 \(\dot{V}\)：

    \[ \dot{V} = x\dot{x} + y\dot{y} = x(-x^{3}) + y(-y^{3}) = -x^{4} - y^{4} \]

    \(-(x^{4}+y^{4}) < 0\) 对 \((x,y) \neq (0,0)\) 成立（负定）

    所以原点是渐近稳定的。

    \((1,1)\) 处的值：

    \[ V(1,1) = \frac{1 + 1}{2} = 1.000000, \qquad \dot{V}(1,1) = -(1 + 1) = -2.000000 \]

    另一个点 \((0.5, 2)\)：

    \[ V = \frac{0.25 + 4}{2} = 2.125000, \qquad \dot{V} = -(0.0625 + 16) = -16.062500 \]

    线性化：

    \[ f_1 = -x^{3} \implies \frac{\partial f_1}{\partial x} = -3x^{2}, \quad \frac{\partial f_1}{\partial y} = 0 \]
    \[ f_2 = -y^{3} \implies \frac{\partial f_2}{\partial x} = 0, \quad \frac{\partial f_2}{\partial y} = -3y^{2} \]
    \[ J = \begin{bmatrix} -3x^{2} & 0 \\ 0 & -3y^{2} \end{bmatrix}_{(0,0)} = \begin{bmatrix} 0 & 0 \\ 0 & 0 \end{bmatrix} \]

    零矩阵，特征值全为 0 → 非双曲 → 线性化完全失效

    对比表：

    方法 结论
    线性化 失效（\(J = 0\)，非双曲）
    Lyapunov（\(V = \lVert\boldsymbol{x}\rVert^{2}/2\)） 渐近稳定 ✓

    为什么 \(\dot{V}\) 是四次方：因为方程右端是三次的， 而 \(V\) 是二次的，相乘就得到四次。 这直接导致多项式收敛速率（不是指数速率）， 与本页例题 2 的 \(\dot{x} = -x^{3}\) 完全同类。

    与线性情形的对照：

    系统 \(\dot{V}\) 收敛类型
    \(\dot{x} = -x\)（线性） \(-x^{2} = -2V\) 指数（\(\dot{V} \le -2V\)）
    \(\dot{x} = -x^{3}\)（立方） \(-x^{4} = -4V^{2}\) 多项式

    工程含义：三次非线性阻尼在实际工程中几乎不可用， 因为它在小偏差时提供的「恢复力」过于微弱。 若发现系统响应有极长的拖尾（如机器人关节最后 几毫弧度总是迟迟不到位），首先怀疑阻尼特性是非线性的， 并考虑改用线性 + 饱和的混合策略。

    Q3 判断 \(A = \begin{bmatrix} -2 & 3 \\ -3 & -2 \end{bmatrix}\) 的平衡点类型， 求阻尼比、周期与衰减到 1 % 的时间。

    提示

    \(\operatorname{tr} = -4\)、\(\det = 13\)。 判别式 = \(16 - 52 = -36\)。

    解答

    类型判定：

    \[ \operatorname{tr} = -2 + (-2) = -4, \qquad \det = (-2)(-2) - 3(-3) = 4 + 9 = 13 \]
    \[ \Delta = \operatorname{tr}^{2} - 4\det = 16 - 52 = -36 < 0 \]

    稳定焦点

    特征值：

    \[ \lambda = \frac{-4 \pm \sqrt{-36}}{2} = \frac{-4 \pm 6i}{2} = -2 \pm 3i \]

    阻尼比与周期：

    \[ \omega_n = \sqrt{2^{2} + 3^{2}} = \sqrt{4 + 9} = \sqrt{13} \approx 3.605551 \]
    \[ \zeta = \frac{2}{\sqrt{13}} \approx 0.554700 \]
    \[ T = \frac{2\pi}{3} = \frac{6.283185}{3} \approx 2.094395\ \text{s} \]

    超调量：

    \[ \sqrt{1 - 0.554700^{2}} = \sqrt{1 - 0.307692} = \sqrt{0.692308} \approx 0.832050 \]
    \[ M_p = \exp\left(-\frac{\pi \times 0.554700}{0.832050}\right) = e^{-2.094395} \approx 12.31\ \% \]

    衰减到 1 % 的时间：

    \[ t = \frac{\ln 100}{2} = \frac{4.605170}{2} \approx 2.302585\ \text{s} \]

    结果汇总：

    指标 值
    类型 稳定焦点
    特征值 \(-2 \pm 3i\)
    \(\omega_n\) \(\sqrt{13} \approx 3.605551\ \text{rad/s}\)
    \(\zeta\) \(2/\sqrt{13} \approx 0.554700\)
    周期 \(T\) \(2.094395\ \text{s}\)
    超调 \(M_p\) \(12.31\ \%\)
    到 1 % 时间 \(2.302585\ \text{s}\)

    与 Q1 的对比：

    对比项 Q1（\(-1 \pm \sqrt{3}i\)） 本题（\(-2 \pm 3i\)）
    \(\lvert\operatorname{Re}\lambda\rvert\) 1 2
    \(\omega_n\) 2 3.605551
    \(\zeta\) 0.5 0.554700
    \(T\) 3.627599 s 2.094395 s
    \(M_p\) 16.30 % 12.31 %
    到 1 % 时间 4.605170 s 2.302585 s

    本题整体更快且超调更小，因为 \(\lvert\operatorname{Re}\lambda\rvert\) 是 Q1 的两倍（衰减快一倍），\(\zeta\) 也更大（振荡更小）。

    有意思的巧合：本题的 \(M_p = 12.30\ \%\) 与 衰减到 1 % 的时间 \(2.302585\ \text{s}\) 都来自 \(\ln 100\) 与 \(e^{-2.094395}\) 的计算，而 \(\pi \times 0.554700 / 0.832050\) 恰好等于 \(2\pi/3 = T\)。 这不是巧合：\(\zeta/\sqrt{1-\zeta^{2}} = \dfrac{\lvert\operatorname{Re}\lambda\rvert}{\lvert\operatorname{Im}\lambda\rvert}\)， 所以

    \[ M_p = e^{-\pi\lvert\operatorname{Re}\lambda\rvert/\lvert\operatorname{Im}\lambda\rvert} = e^{-2\pi/T} \]

    —— 超调量只由「衰减时间与周期的比」决定。 这是二阶系统一个非常实用的化简。

    Q4 对 \(A = \begin{bmatrix} -1 & 0 \\ 0 & -2 \end{bmatrix}\)， 解 Lyapunov 方程 \(A^{\mathsf{T}}P + PA = -I\)， 验证 \(P\) 正定，并求 \(V = \boldsymbol{x}^{\mathsf{T}}P\boldsymbol{x}\) 在 \((0,1)\) 与 \((1,1)\) 处的值。

    提示

    对角矩阵情形最简单：\(A^{\mathsf{T}}P + PA\) 的对角元就是 \(2a_{ii}p_{ii}\)。

    解答

    化简方程：设 \(P = \begin{bmatrix} p_{11} & p_{12} \\ p_{12} & p_{22}\end{bmatrix}\)。 因为 \(A\) 是对角矩阵，

    \[ A^{\mathsf{T}}P + PA = \begin{bmatrix} -1 & 0 \\ 0 & -2\end{bmatrix}\begin{bmatrix} p_{11} & p_{12} \\ p_{12} & p_{22}\end{bmatrix} + \begin{bmatrix} p_{11} & p_{12} \\ p_{12} & p_{22}\end{bmatrix}\begin{bmatrix} -1 & 0 \\ 0 & -2\end{bmatrix} \]
    \[ = \begin{bmatrix} -2p_{11} & -3p_{12} \\ -3p_{12} & -4p_{22} \end{bmatrix} \]

    令它等于 \(-I\)：

    \[ -2p_{11} = -1 \implies p_{11} = \frac12 = 0.500000 \]
    \[ -3p_{12} = 0 \implies p_{12} = 0 \]
    \[ -4p_{22} = -1 \implies p_{22} = \frac14 = 0.250000 \]
    \[ P = \begin{bmatrix} 0.500000 & 0 \\ 0 & 0.250000 \end{bmatrix} \]

    验证方程：

    \[ A^{\mathsf{T}}P + PA = \begin{bmatrix} -1 & 0 \\ 0 & -1 \end{bmatrix} = -I \ \checkmark \]

    验证 \(P\) 正定：

    判据 值 结论
    \(p_{11} > 0\) \(0.5\) ✓
    \(\det P = 0.5 \times 0.25 - 0 = 0.125\) \(> 0\) ✓
    \(P\) 的特征值（就是对角元） \(0.5\)、\(0.25\) 都正 ✓

    求 \(V\) 的值：

    \[ V(\boldsymbol{x}) = \boldsymbol{x}^{\mathsf{T}}P\boldsymbol{x} = 0.5x_1^{2} + 0.25x_2^{2} \]
    \(\boldsymbol{x}\) 计算 \(V\)
    \((0, 1)\) \(0 + 0.25\) 0.250000
    \((1, 0)\) \(0.5 + 0\) 0.500000
    \((1, 1)\) \(0.5 + 0.25\) 0.750000
    \((2, 2)\) \(2.0 + 1.0\) 3.000000

    \(\dot{V}\) 与衰减率：

    \[ \dot{V} = -\boldsymbol{x}^{\mathsf{T}}\boldsymbol{x} = -(x_1^{2} + x_2^{2}) \]
    \(\boldsymbol{x}\) \(\dot{V}\) \(V\) \(\dot{V}/V\)
    \((1,0)\) \(-1\) 0.500000 \(-2.000000\)
    \((0,1)\) \(-1\) 0.250000 \(-4.000000\)
    \((1,1)\) \(-2\) 0.750000 \(-2.666667\)

    注意 \(\dot{V}/V\) 不是常数，取值在 \([-4, -2]\) 之间。 所以不能直接写出 \(\dot{V} \le -cV\) 的形式（用 \(c = 2\) 不成立， 因为 \((0,1)\) 处 \(\dot{V}/V = -4\)；用 \(c = 4\) 也不成立）。 正确的结论要用特征值：

    \[ \dot{V} \le -2\lambda_{\min}(P)\lVert\boldsymbol{x}\rVert^{2} \quad \text{且} \quad \lVert\boldsymbol{x}\rVert^{2} \ge \frac{V}{\lambda_{\max}(P)} \]

    所以（\(\lambda_{\min} = 0.25\)、\(\lambda_{\max} = 0.5\)）

    \[ \dot{V} \le -\frac{2 \times 0.25}{0.5}V = -V \]

    所以 \(\dot{V} \le -V\)，即 \(V(t) \le V(0)e^{-t}\)，指数稳定

    经验公式：对 Lyapunov 方程，衰减速率的下界是

    \[ \alpha = \frac{\lambda_{\min}(Q)}{\lambda_{\max}(P)} \]

    本例 \(\alpha = \dfrac{1}{0.5} = 2\)。这给出「至少以 \(e^{-2t}\) 衰减」的保证， 而实际的衰减速率介于 \(\lvert\lambda_1\rvert = 1\) 与 \(\lvert\lambda_2\rvert = 2\) 之间。

    工程含义：\(\alpha = \dfrac{\lambda_{\min}(Q)}{\lambda_{\max}(P)}\) 是从 Lyapunov 函数反推收敛速度的标准公式。 它通常比真实的最慢衰减率更保守 （这里给出 2，而真实最慢是 1）， 所以用于保守估计收敛时间是安全的 —— 工程上宁可保守也不要乐观。

    本页小结

    你的问题 该用什么方法 关键公式
    平衡点是哪种类型 迹-行列式判据 \(\Delta = \operatorname{tr}^{2} - 4\det\)
    小扰动后会不会跑远 线性化（雅可比矩阵） 特征值实部符号
    线性化失效怎么办 Lyapunov 直接法 构造 \(V\)，看 \(\dot{V}\) 符号
    \(\dot{V}\) 只是半负定 LaSalle 不变原理 检查 \(E\) 内最大不变集
    怎么算衰减速度 时间常数 \(t = \dfrac{\ln(1/\varepsilon)}{\lvert\operatorname{Re}\lambda\rvert}\)
    怎么求「能量」函数 解 Lyapunov 方程 \(A^{\mathsf{T}}P + PA = -Q\)
    有没有自激振荡 Poincaré–Bendixson / 数值 极限环

    最后一句话：稳定性分析的全部价值在于「不解方程也能下结论」。 线性化给出最快的判据（但要求双曲）， Lyapunov 方法给出最一般的方法（但需要构造 \(V\) 的技巧）， LaSalle 原理填补了「半负定」这一最常见情形。 这三者的组合覆盖了工程上绝大多数的稳定性判定需求， 而它们对「\(\operatorname{Re}\lambda\) 符号」的依赖， 将直接决定下一页数值方法能取多大的步长。
