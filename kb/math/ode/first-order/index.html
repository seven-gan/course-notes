    一阶微分方程¶

    前面几页讲的都是「已知函数，求它的导数」——方向是求导。 这一页把方向倒过来：已知含导数的等式，求未知函数本身。 这样的等式就叫微分方程，而只含一阶导数的，就叫一阶微分方程。

    一阶方程是整个微分方程理论的入口，原因很实际：

    • 它是唯一一类能写出完整求解套路的方程。高维、高阶、非线性方程大多只能数值求解，而一阶方程有四类标准可解类型；
    • 大量工程模型本身就是一阶的：\(RC\) 电路的充放电、电机的转速响应、 一阶数字滤波器的递推、电池的荷电状态、无人机的能量耗散；
    • 后面第二页（二阶线性方程）、第三页（线性方程组）、第四页（稳定性）、 第五页（数值解法）全部建立在这一页的语言之上。

    所以这一页的目标不是「背四种解法」，而是建立一套识别流程： 拿到一个一阶方程，先看它属于哪一类，再套对应方法。

    一句话抓住核心

    一阶方程的本质是「把导数当未知量分离出来，然后两边积分」。

    类型 标准形 识别特征 解法
    可分离变量 \(y' = f(x)g(y)\) 右端能拆成「只含 \(x\)」乘「只含 \(y\)」 分离后两边积分
    一阶线性 \(y' + p(x)y = q(x)\) \(y\) 与 \(y'\) 都是一次，无乘积 积分因子 \(\mu = e^{\int p\,\mathrm{d}x}\)
    伯努利 \(y' + p(x)y = q(x)y^{n}\) 出现 \(y\) 的幂次（\(n \neq 0,1\)） 换元 \(v = y^{1-n}\) 化线性
    恰当方程 \(P\,\mathrm{d}x + Q\,\mathrm{d}y = 0\) 存在 \(F\) 使 \(F_x = P\)、\(F_y = Q\) 检验 \(P_y = Q_x\)，再求 \(F\)

    一句话判据：能分开就分开，不能分开看是不是线性，是幂次就换元，是微分形式就查是否恰当。

    一、微分方程的基本概念¶

    什么是微分方程¶

    微分方程是含有未知函数及其导数的等式。按最高阶导数的阶数称为 \(n\) 阶方程。

    一阶方程的一般形式可以写成

    \[ F(x, y, y') = 0 \]

    如果能把 \(y'\) 单独解出来，就得到显式形式（本页主要讨论这种）

    \[ y' = f(x, y) \]

    有时写成微分形式更方便

    \[ P(x, y)\,\mathrm{d}x + Q(x, y)\,\mathrm{d}y = 0 \]

    两种写法可以互相转换：由 \(y' = \dfrac{\mathrm{d}y}{\mathrm{d}x}\)， 把 \(y' = -P/Q\) 对应过去，就得到 \(P\,\mathrm{d}x + Q\,\mathrm{d}y = 0\)。 后面「恰当方程」一节就靠这个形式。

    通解、特解与初值问题¶

    一阶方程的解里会带一个任意常数，这叫通解（general solution）； 给 \(C\) 一个具体值，就得到特解（particular solution）。

    确定 \(C\) 的条件叫初始条件，一阶方程只需要一个： 在某个点 \(x_0\) 处指定函数值 \(y(x_0) = y_0\)。 方程加初始条件合起来叫初值问题（initial value problem，IVP）：

    \[ y' = f(x, y), \qquad y(x_0) = y_0 \]

    为什么要专门讲初值问题：因为现实系统总有「初始状态」—— 电容的初始电压、滤波器的初始储能、无人机起飞时的高度。 而且只有加上初值，解才唯一，数值解法也才有确定的输入。

    以 \(y' = 2xy\) 为例：

    环节 结果 说明
    通解 \(y = Ce^{x^{2}}\) 含一个任意常数 \(C\)，是一族曲线
    初始条件 \(y(0) = 1\) 指定曲线过点 \((0,1)\)
    特解 \(y = e^{x^{2}}\) 代入得 \(C = 1\)，唯一确定
    另一个初值 \(y(0) = 3 \implies y = 3e^{x^{2}}\) 同一族中的另一条

    几何意义：方向场¶

    \(y' = f(x, y)\) 的右端给了一个不依赖求解的信息： 在平面上的任一点 \((x, y)\) 处，解曲线必须以斜率 \(f(x, y)\) 通过。

    把所有点上的斜率画成小线段，就得到方向场（direction field / 斜率场）。 方向场是理解一阶方程最直观的工具，它告诉我们三件事：

    1. 解曲线处处与方向场相切——这就是「解」的几何定义；
    2. \(f(x,y_0) = 0\) 的水平线上斜率为零，解曲线在此达到极值；
    3. 整体走势不需要解出公式就能看出（增长、衰减、发散）。

    工程含义：控制系统里工程师常先画相图/方向场判断趋势， 再决定是否需要精确解析解。这是「定性分析」的雏形， 第四页的稳定性分析就是它的系统化。

    解的存在与唯一性¶

    不是所有 \(f\) 都能保证解存在唯一。教材上的基本结论是：

    条件 结论
    \(f\) 在 \((x_0, y_0)\) 附近连续 至少存在一个局部解
    \(f\) 对 \(y\) 满足 Lipschitz 条件 解在该邻域内唯一

    为什么要提这个：它给出「解会不会撞车」的判据。 例如 \(y' = \sqrt{\lvert y \rvert}\)、\(y(0) = 0\) 在 \(y=0\) 处不满足 Lipschitz， 解不唯一（\(y \equiv 0\) 和 \(y = x^{2}/4\) 都是解）。

    工程含义：模型非唯一意味着物理上存在多个可能结果， 此时必须补充物理约束（能量守恒、极限状态）才能定解。

    二、可分离变量方程¶

    识别与解法¶

    若右端能分解为只含 \(x\) 的函数乘以只含 \(y\) 的函数：

    \[ \frac{\mathrm{d}y}{\mathrm{d}x} = f(x)\,g(y) \]

    就把含 \(y\) 的因子挪到左边（形式上把 \(\mathrm{d}y\) 与 \(\mathrm{d}x\) 分开）：

    \[ \frac{\mathrm{d}y}{g(y)} = f(x)\,\mathrm{d}x \]

    两边积分

    \[ \int \frac{\mathrm{d}y}{g(y)} = \int f(x)\,\mathrm{d}x + C \]

    左边是 \(y\) 的函数、右边是 \(x\) 的函数，只要这两个积分能算出来，方程就解完了。

    注意 \(+C\) 只写一遍：两个积分各带一个常数， 但两个常数合并成一个没有区别，写两遍只会让后面解 \(C\) 时多一个冗余。

    典型例：指数增长¶

    \[ y' = 2xy \]

    第一步：分离。

    \[ \frac{\mathrm{d}y}{y} = 2x\,\mathrm{d}x \]

    第二步：积分。

    \[ \ln \lvert y \rvert = x^{2} + C \]

    第三步：解出 \(y\)。

    \[ y = C_{1}e^{x^{2}}, \qquad C_{1} = \pm e^{C} \]

    第四步：代入初值 \(y(0) = 1\)。 \(x = 0\)、\(y = 1\) 代入：\(1 = C_{1}e^{0} = C_{1}\)，故

    \[ y = e^{x^{2}} \]

    数值验证：把结果代回原方程检验（这一步不能省）。

    \(x\) \(y = e^{x^{2}}\) \(y' = 2xy\) 的理论值 有限差分检验 \(y'(1)\) 一致？
    0 1.000000 0.000000 — ✓
    0.5 1.284025 1.284025 — ✓
    1.0 2.718282 2.718282 2.718282 一致
    1.5 9.487736 14.231604 — ✓
    2.0 54.598150 109.196301 — ✓

    \(x = 1\) 处：理论 \(y' = 2 \times 1 \times 2.718282 = 5.436564\)， 而右表另列的是 \(y\) 本身（\(2.718282\)）。 注意 \(y'\) 与 \(y\) 在 \(x=1\) 处数值不同，这正是「方程右端依赖 \(x\)」的体现： \(x=0\) 时右端为 \(0\)（曲线水平），\(x\) 增大后增长越来越猛。

    增长为什么会「炸」：指数 \(x^{2}\) 是双指数的直观来源—— \(x\) 从 \(1\) 到 \(2\)，\(y\) 从 \(2.72\) 涨到 \(54.60\)，20 倍。 这类模型刻画的正是「增长率正比于规模」的正反馈过程。

    常数解的丢失¶

    分离时除以了 \(g(y)\)，这等于默认 \(g(y) \neq 0\)。 若存在 \(y_{*}\) 使 \(g(y_{*}) = 0\)，则 \(y \equiv y_{*}\) 也是解，且可能恰好被丢掉了。

    以 Logistic 方程（阻滞增长模型）为例：

    \[ y' = y(1 - y) \]
    • \(g(y) = y(1-y)\)，在 \(y = 0\) 与 \(y = 1\) 处为零，所以 \(y \equiv 0\)、\(y \equiv 1\) 是两个平衡解；
    • 分离后积分得通解 \(y = \dfrac{1}{1 + Ce^{-x}}\)。

    这两个常数解在通解里取不到（\(y \equiv 1\) 对应 \(C = 0\) 但 \(y \equiv 0\) 取不到）， 所以必须单独声明。这就是「分离变量要检查常数解」的全部理由。

    Logistic 的数值行为（取 \(y(0) = 0.5\)，即 \(C = 1\)）：

    \(x\) 0 1 2 3 5
    \(y\) 0.500000 0.731059 0.880797 0.952574 0.993307

    初始阶段近似指数增长，随后被环境容量压制， \(x \to \infty\) 时 \(y \to 1\)（极限值不依赖初值，只要初值大于零）。

    工程含义：Logistic 是「有限资源下的增长」标准模型—— 海洋中水声信道的节点数量增长、社交网络中信息扩散、 电池充电到饱和的修正模型都用到它。 记住这条：能分离的方程往往对应「增长率只由当前状态决定」的过程。

    什么时候不能用分离变量¶

    判断 例子 结论
    右端是乘积形式 \(y' = x^{2}y^{3}\) 可分离
    右端是加法形式 \(y' = x + y\) 不可分离，改用线性方程
    右端含 \(x+y\) 的复合 \(y' = (x+y)^{2}\) 不可分离，用换元 \(u = x+y\)
    右端含 \(y/x\) 的复合 \(y' = 1 - y/x\) 齐次方程，用换元 \(v = y/x\)

    对 \(y' = x + y\)，我们有 \(y' - y = x\)，这是线性方程的典型标准形， 下一节处理它。

    三、一阶线性方程与积分因子¶

    标准形¶

    \[ y' + p(x)\,y = q(x) \]

    为什么叫「线性」：把 \(y\) 与 \(y'\) 看作未知量，方程对它们是一次的， 没有 \(y^{2}\)、\(yy'\) 这类项。\(p\)、\(q\) 可以任意复杂，只要求与 \(y\) 无关。

    积分因子的推导¶

    先看一个凑巧的观察：若方程左端出现 \(\mu y' + \mu p y\)， 它「像」乘积求导的结果 \((\mu y)' = \mu y' + \mu' y\)。 只要让 \(\mu' = \mu p\)，左端就真成了 \((\mu y)'\)。

    于是积分因子取

    \[ \mu(x) = e^{\int p(x)\,\mathrm{d}x} \]

    因为 \(\mu' = \mu p\) 正好满足。乘上 \(\mu\)：

    \[ \mu y' + \mu p y = \mu q \]
    \[ (\mu y)' = \mu q \]

    两边积分：

    \[ \mu y = \int \mu(x)\,q(x)\,\mathrm{d}x + C \]
    \[ y = \frac{1}{\mu(x)}\left[\int \mu(x)q(x)\,\mathrm{d}x + C\right] \]

    这就是一阶线性方程的通解公式，也是一阶方程里唯一「可以背下来直接用」的公式。

    为什么有效：\(\mu\) 的作用是把左端变成全导数。 一旦成为全导数，方程就退化成「求原函数」这种最基础的问题。 这个「乘一个因子变成全导数」的思想在恰当方程、二阶朗斯基方法里会反复出现。

    典型例：带奇点的线性方程¶

    解初值问题

    \[ y' + \frac{y}{x} = x^{2}, \qquad y(1) = 0 \]

    第一步：辨认。 \(p(x) = 1/x\)，\(q(x) = x^{2}\)，是标准形。

    第二步：求积分因子。

    \[ \mu = e^{\int \frac{1}{x}\mathrm{d}x} = e^{\ln x} = x \]

    （这里 \(x > 0\)，因为初值给在 \(x = 1\)。）

    第三步：等式两边乘 \(\mu\) 并识别全导数。

    \[ x y' + y = x^{3} \implies (xy)' = x^{3} \]

    第四步：积分。

    \[ xy = \frac{x^{4}}{4} + C \]

    第五步：代入初值。 \(x = 1\)、\(y = 0\)：\(0 = \frac14 + C\)，得 \(C = -\frac14\)。

    \[ y = \frac{x^{4}}{4x} - \frac{1}{4x} = \frac{x^{3} - 1}{4x} \]

    第六步：数值验证。

    \(x\) 1.0 1.5 2.0 3.0
    \(y\) 0.000000 0.395833 0.875000 2.166667
    \(x^{3}\) 1.000 3.375 8.000 27.000
    检验 \(xy - x^{3}/4\) \(-0.250\) \(-0.250\) \(-0.250\) \(-0.250\)
    一致？ ✓ ✓ ✓ ✓

    最后一行是常数 \(C = -1/4\)，这正是积分结果的直接体现， 也是最快的自我检验方式。

    为什么 \(x=0\) 不能取：\(\mu = x\) 在 \(x = 0\) 处为零， 而原方程里的 \(y/x\) 在 \(x = 0\) 处无定义。 解的区间必然避开 \(p(x)\) 的奇点—— \(p\) 在 \(x_0\) 处不连续的区间内，解的存在唯一性不能保证。

    与齐次方程的关系¶

    若 \(q(x) \equiv 0\)，方程退化为 \(y' + p y = 0\)， 分离变量立得 \(y = Ce^{-\int p\,\mathrm{d}x}\)，与积分因子公式一致（取 \(q=0\)）。 更一般地，通解可以拆成

    \[ y = \underbrace{C e^{-\int p\mathrm{d}x}}_{\text{齐次解 } y_h} + \underbrace{\frac{1}{\mu}\int \mu q\,\mathrm{d}x}_{\text{特解 } y_p} \]

    这就是「齐次通解 + 非齐次特解」结构的来源， 下一页二阶线性方程用的是同一个结构。 工程含义：\(y_h\) 是系统的固有响应（由系统参数 \(p\) 决定）， \(y_p\) 是强迫响应（由外部输入 \(q\) 决定）。 调参能改变前者，而后者只能靠改输入来改变。

    四、伯努利方程与恰当方程¶

    伯努利方程：换元化线性¶

    \[ y' + p(x)\,y = q(x)\,y^{n}, \qquad n \neq 0,\ 1 \]

    （\(n = 0\) 就是线性方程，\(n = 1\) 可分离，所以这两种被排除。）

    换元思路：\(y^{n}\) 破坏了线性性，用换元把它消掉。设

    \[ v = y^{1-n} \]

    则

    \[ v' = (1-n)y^{-n}y' \]

    把原方程两边除以 \(y^{n}\)，得

    \[ y^{-n}y' + p\,y^{1-n} = q \]

    代入 \(v\) 与 \(v'\)：

    \[ \frac{v'}{1-n} + p v = q \]

    两边乘 \(1-n\)，得到关于 \(v\) 的一阶线性方程：

    \[ v' + (1-n)p(x)\,v = (1-n)q(x) \]

    关键点：换元把非线性方程精确变成了线性方程，没有任何近似。

    典型例：有限时间爆破¶

    \[ y' - y = y^{2}, \qquad y(0) = 1 \]

    第一步：辨认。 \(p = -1\)，\(q = 1\)，\(n = 2\)，是伯努利方程。

    第二步：换元。 \(v = y^{1-2} = y^{-1} = 1/y\)，即 \(y = 1/v\)，\(v(0) = 1\)。

    第三步：化为线性。 取 \(n=2\) 代入 \(v' + (1-n)pv = (1-n)q\)：

    \[ v' + (-1)(-1)v = (-1)\cdot 1 \implies v' + v = -1 \]

    第四步：用积分因子求解。 \(\mu = e^{x}\)：

    \[ (e^{x}v)' = -e^{x} \implies e^{x}v = -e^{x} + C \implies v = Ce^{-x} - 1 \]

    第五步：代入初值。 \(v(0) = 1\)：\(1 = C - 1\)，得 \(C = 2\)。

    \[ v = 2e^{-x} - 1 \implies y = \frac{1}{2e^{-x} - 1} \]

    第六步：检查爆破。 分母为零当 \(2e^{-x} = 1\)，即

    \[ x_{*} = \ln 2 \approx 0.693147 \]
    \(x\) 0.2 0.5 0.6 0.69 0.693147
    \(2e^{-x} - 1\) 0.637462 0.213061 0.097623 0.003152 0.000000
    \(y\) 1.568722 4.693484 10.243459 317.244980 \(+\infty\)

    解在有限时间趋向无穷，这叫有限时间爆破（finite-time blow-up）。

    工程含义：爆破不是数学上的怪现象，而是模型的失效信号。 现实中压力、电流、温度都不可能真的到无穷， 所以出现爆破就意味着「假设失效了」—— 必须加入饱和、限幅、散热等机制修正模型。 记住：爆破点是模型的「警戒线」，不是物理量的真值。

    模型类型 增长机制 长期行为 是否需要修正
    \(y' = y\) 增长率恒定 指数增长 资源有限时需修正
    \(y' = y(1-y)\) 增长率随规模下降 趋于有限极限 合理
    \(y' - y = y^{2}\) 增长被自身放大 \(\ln 2 \approx 0.693\) 处爆破 必须修正
    \(y' = -y\) 衰减 指数衰减到零 合理

    恰当方程：找回「隐藏的全微分」¶

    微分形式

    \[ P(x,y)\,\mathrm{d}x + Q(x,y)\,\mathrm{d}y = 0 \]

    若存在势函数 \(F(x,y)\) 使

    \[ \frac{\partial F}{\partial x} = P, \qquad \frac{\partial F}{\partial y} = Q \]

    则方程左端恰是 \(F\) 的全微分 \(\mathrm{d}F = 0\)， 解就是隐式的等值线 \(F(x,y) = C\)。

    判定与求解定理（设 \(P\)、\(Q\) 在单连通区域上有连续偏导）：

    \[ \text{方程恰当} \iff \frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x} \]

    满足时，\(F\) 可这样构造：

    \[ F(x,y) = \int P(x,y)\,\mathrm{d}x + g(y) \]

    其中 \(g(y)\) 由 \(\dfrac{\partial F}{\partial y} = Q\) 定出。

    为什么要用「单连通」：否则积分可能与路径有关， \(P_y = Q_x\) 的判定就会失灵。工程上遇到的区域几乎都是单连通的， 所以实际操作中只需验证 \(P_y = Q_x\)。

    典型例：恰当方程¶

    \[ (2xy + 3)\,\mathrm{d}x + (x^{2} - 4y)\,\mathrm{d}y = 0, \qquad y(1) = 2 \]

    第一步：判定。

    \[ P = 2xy + 3, \quad Q = x^{2} - 4y \]
    \[ \frac{\partial P}{\partial y} = 2x, \qquad \frac{\partial Q}{\partial x} = 2x \]

    两者相等，是恰当方程 ✓

    第二步：求 \(F\)。

    \[ F = \int (2xy + 3)\,\mathrm{d}x = x^{2}y + 3x + g(y) \]

    第三步：用 \(F_y = Q\) 定 \(g(y)\)。

    \[ \frac{\partial F}{\partial y} = x^{2} + g'(y) = x^{2} - 4y \implies g'(y) = -4y \implies g(y) = -2y^{2} \]

    （积出的常数归入 \(C\)。）

    \[ F(x,y) = x^{2}y + 3x - 2y^{2} \]

    第四步：写隐式通解。

    \[ x^{2}y + 3x - 2y^{2} = C \]

    第五步：代入初值。 \(x = 1\)、\(y = 2\)：

    \[ C = 1^{2}\cdot 2 + 3\cdot 1 - 2\cdot 2^{2} = 2 + 3 - 8 = -3 \]
    \[ x^{2}y + 3x - 2y^{2} = -3 \]

    第六步：求某个点上的显式值。 令 \(x = 2\)：

    \[ 4y + 6 - 2y^{2} = -3 \implies 2y^{2} - 4y - 9 = 0 \]
    \[ y = \frac{4 \pm \sqrt{16 + 72}}{4} = \frac{4 \pm \sqrt{88}}{4} = 1 \pm \frac{\sqrt{22}}{2} \]

    \(\sqrt{22}/2 \approx 2.345208\)，所以两个根为

    \[ y_1 = 3.345208, \qquad y_2 = -1.345208 \]

    由连续性（\(x=1\) 处 \(y=2 > 0\)），取 \(y(2) = 1 + \frac{\sqrt{22}}{2} \approx 3.345208\)。

    为什么要讨论分支：隐式解 \(F = C\) 常是闭曲线或多值曲线， 必须有额外信息（初值 + 连续性）才能确定走哪一支。

    积分因子可以把非恰当方程变恰当¶

    并非所有 \(P\,\mathrm{d}x + Q\,\mathrm{d}y = 0\) 都恰当，但有时能找到 \(\mu(x,y)\) 使

    \[ \mu P\,\mathrm{d}x + \mu Q\,\mathrm{d}y = 0 \]

    恰当。例如

    \[ (3xy + y^{2})\,\mathrm{d}x + (x^{2} + xy)\,\mathrm{d}y = 0 \]

    先检验：\(P_y = 3x + 2y\)，\(Q_x = 2x + y\)，不相等，不恰当。 试取 \(\mu = x\)，则

    \[ P^{*} = 3x^{2}y + xy^{2}, \qquad Q^{*} = x^{3} + x^{2}y \]
    \[ \frac{\partial P^{*}}{\partial y} = 3x^{2} + 2xy = \frac{\partial Q^{*}}{\partial x} \quad \checkmark \]

    此时 \(F = x^{3}y + \frac{1}{2}x^{2}y^{2}\)，隐式通解为

    \[ 2x^{3}y + x^{2}y^{2} = C \]

    注意：积分因子不唯一（乘上任意常数还是积分因子）， 而且没有通用的找法——一般靠观察和经验， 这一点与一阶线性方程的 \(\mu = e^{\int p}\) 完全不同。

    方程类型 积分因子是否存在 是否好找
    一阶线性 \(y' + py = q\) 一定存在 有公式 \(\mu = e^{\int p\mathrm{d}x}\)
    一般 \(P\mathrm{d}x + Q\mathrm{d}y = 0\) 不一定存在 无通用方法，靠观察
    只含 \(x\) 的 \(\mu(x)\) 存在条件 \(\frac{P_y - Q_x}{Q}\) 只含 \(x\) 可积分求出

    五、典型例题¶

    例题 1：可分离变量与数值验证¶

    求解 \(y' = 2xy\)、\(y(0) = 1\)，并计算 \(y\) 在 \(x = 0.5\) 与 \(x = 2\) 处的值， 说明这个模型在工程上的「危险」之处。

    思路

    右端是 \(2x\) 与 \(y\) 的乘积，属于可分离变量。 分离、积分、代初值，再把结果代入观察增长速度。

    解答

    分离变量：

    \[ \frac{\mathrm{d}y}{y} = 2x\,\mathrm{d}x \]

    积分：

    \[ \ln \lvert y \rvert = x^{2} + C \]

    解出 \(y\)：

    \[ y = C_{1}e^{x^{2}}, \qquad C_{1} = \pm e^{C} \]

    代入初值 \(y(0) = 1\)：\(1 = C_{1}\)，故

    \[ y = e^{x^{2}} \]

    数值计算：

    \(x\) \(x^{2}\) \(y = e^{x^{2}}\) 相对上一列（\(x\) 增加 0.5）的倍数
    0.0 0.00 1.000000 —
    0.5 0.25 1.284025 ×1.284
    1.0 1.00 2.718282 ×2.117
    1.5 2.25 9.487736 ×3.490
    2.0 4.00 54.598150 ×5.755

    危险之处：倍数在逐步放大（1.28 → 2.12 → 3.49 → 5.76）， 这是正反馈模型的标志。

    工程含义：任何「增长率正比于自身」的量都不会单调温和地增长。 无人机的电池温升、化学反应速率、水池液位在失控时都符合这种形态。 若模型预测在 \(x=2\) 处达到 \(54.6\)，而系统量程只有 \(10\)， 那么必须在 \(x \approx 1.28\) 左右就介入控制—— 这类模型没有「慢慢逼近」的余地。

    例题 2：一阶线性方程的积分因子¶

    求解 \(y' + \dfrac{y}{x} = x^{2}\)、\(y(1) = 0\)， 给出 \(x = 1.5\) 与 \(x = 2\) 处的数值，并解释解的区间限制。

    思路

    这是标准的一阶线性方程，\(p(x) = 1/x\)。 用积分因子 \(\mu = e^{\int p\,\mathrm{d}x}\)，注意 \(x>0\)。

    解答

    辨认标准形：\(p(x) = \dfrac{1}{x}\)，\(q(x) = x^{2}\)。

    积分因子：

    \[ \mu = e^{\int \frac{1}{x}\mathrm{d}x} = e^{\ln x} = x \qquad (x > 0) \]

    两边乘 \(\mu\) 并识别全导数：

    \[ x y' + y = x^{3} \implies (xy)' = x^{3} \]

    积分：

    \[ xy = \frac{x^{4}}{4} + C \]

    代入初值 \(y(1) = 0\)：\(0 = \frac14 + C \implies C = -\frac14\)，故

    \[ y = \frac{x^{3} - 1}{4x} \]

    数值表：

    \(x\) \(y\) 检验 \(4xy = x^{3} - 1\) 一致？
    1.0 0.000000 \(0 = 0\) ✓
    1.5 0.395833 \(2.375 = 2.375\) ✓
    2.0 0.875000 \(7.000 = 7.000\) ✓
    3.0 2.166667 \(26.000 = 26.000\) ✓

    解的大范围行为：\(x \to \infty\) 时 \(y \approx \frac{x^{2}}{4} \to \infty\)， 因为非齐次项 \(x^{2}\) 的增长主导了解。

    区间限制：\(p(x) = 1/x\) 在 \(x = 0\) 处不连续， 含 \(x=0\) 的区间上解不能保证存在唯一。 初值点在 \(x=1 > 0\)，因此解只在 \(x \in (0, \infty)\) 上有效。 若把初值放在 \(x = -1\)，则得到的是另一个区间 \((-\infty, 0)\) 上的解， 两者不能拼接。这就是「解的区间由 \(p\) 的连续区间决定」的具体含义。

    例题 3：伯努利方程与有限时间爆破¶

    求解 \(y' - y = y^{2}\)、\(y(0) = 1\)，求出爆破时刻， 并讨论该模型在什么条件下需要修正。

    思路

    右端出现 \(y^{2}\)，是 \(n=2\) 的伯努利方程。 用 \(v = y^{1-n} = 1/y\) 化为线性。

    解答

    换元：\(v = y^{-1}\)，则 \(y = v^{-1}\)，\(y' = -v^{-2}v'\)。 原方程两边除以 \(y^{2}\)：

    \[ \frac{y'}{y^{2}} - \frac{1}{y} = 1 \implies -v' - v = 1 \implies v' + v = -1 \]

    积分因子 \(\mu = e^{x}\)：

    \[ (e^{x}v)' = -e^{x} \implies v = Ce^{-x} - 1 \]

    初值：\(v(0) = 1/y(0) = 1\)，故 \(C = 2\)，

    \[ v = 2e^{-x} - 1 \implies y = \frac{1}{2e^{-x} - 1} \]

    爆破时刻：令 \(2e^{-x} - 1 = 0\)，

    \[ x_{*} = \ln 2 \approx 0.693147 \]

    数值表：

    \(x\) 0.2 0.4 0.5 0.6 0.69
    分母 \(2e^{-x}-1\) 0.637462 0.329680 0.213061 0.097623 0.003152
    \(y\) 1.568722 3.033245 4.693484 10.243459 317.244980

    修正条件：爆破在物理上不可能，说明「增长率与 \(y^{2}\) 成正比」 这一假设只在 \(y\) 较小时成立。工程上通常改为

    \[ y' - y = y^{2}\,(1 - y/K) \]

    即以容量 \(K\) 截断增长，此时解不再爆破。

    实用判据：若数值解在有限时间内超过量程， 先怀疑模型是伯努利型（\(n>1\)）而非简单指数型—— 两者的差别在于爆破 vs 指数发散， 后者只在 \(x \to \infty\) 时趋于无穷，前者在有限时间内就已经失效。

    例题 4：恰当方程的判定与求解¶

    求解 \((2xy + 3)\,\mathrm{d}x + (x^{2} - 4y)\,\mathrm{d}y = 0\)、\(y(1) = 2\)， 求 \(y\) 在 \(x = 2\) 处的值。

    思路

    写成 \(P\mathrm{d}x + Q\mathrm{d}y = 0\) 后，先验证 \(P_y = Q_x\)。 若成立，求势函数 \(F\)，再代初值。

    解答

    判定：

    \[ P = 2xy + 3, \qquad Q = x^{2} - 4y \]
    \[ \frac{\partial P}{\partial y} = 2x, \qquad \frac{\partial Q}{\partial x} = 2x \implies P_y = Q_x \ \checkmark \]

    构造势函数：

    \[ F = \int (2xy + 3)\,\mathrm{d}x = x^{2}y + 3x + g(y) \]
    \[ F_y = x^{2} + g'(y) = x^{2} - 4y \implies g(y) = -2y^{2} \]
    \[ F(x,y) = x^{2}y + 3x - 2y^{2} \]

    隐式通解：

    \[ x^{2}y + 3x - 2y^{2} = C \]

    代初值 \(x=1\)、\(y=2\)：

    \[ C = 1\cdot 2 + 3\cdot 1 - 2\cdot 4 = -3 \]

    求 \(x=2\) 的值：

    \[ 4y + 6 - 2y^{2} = -3 \implies 2y^{2} - 4y - 9 = 0 \]
    \[ y = 1 \pm \frac{\sqrt{22}}{2} \approx 1 \pm 2.345208 \]
    分支 数值 判定
    \(y_1 = 1 + \frac{\sqrt{22}}{2}\) 3.345208 由连续性取此支
    \(y_2 = 1 - \frac{\sqrt{22}}{2}\) \(-1.345208\) 与 \(y(1) = 2\) 不连通，舍去

    结论：\(y(2) \approx 3.345208\)。

    反向验证：把 \(x = 2\)、\(y = 3.345208\) 代回 \(F\)：

    \[ 4 \times 3.345208 + 6 - 2 \times 3.345208^{2} = 13.380832 + 6 - 22.380832 = -3 \ \checkmark \]

    与 \(C = -3\) 一致。

    工程含义：恰当方程对应保守系统—— 势函数 \(F\) 就是能量，隐式解 \(F = C\) 就是「能量守恒」。 这类方程不会出现爆破、也不会耗散， 后续稳定性分析里「中心」型平衡点正是这种保守情形。

    六、用在哪些课程里¶

    机器人学 · 关节摩擦与执行器模型¶

    • 直流电机的电气时间常数：电枢回路满足 \(L\dfrac{\mathrm{d}i}{\mathrm{d}t} + Ri = u\)， 是一阶线性方程，解为 \(i \to u/R\) 的指数趋近，时间常数 \(\tau = L/R\)；
    • 黏性摩擦下的关节速度：\(J\dot{\omega} + b\omega = \tau_{\text{motor}}\)， 同样是一阶线性，决定关节转速到达稳态的快慢；
    • 为什么必须先能解一阶方程：控制器设计（PI、超前校正）的带宽估算 直接由 \(\tau\) 决定，而 \(\tau\) 就只能从方程系数读出来。

    现代数字信号处理 · 一阶递归滤波与锁相环¶

    • 一阶 IIR 滤波器：\(y[n] = \alpha y[n-1] + (1-\alpha)x[n]\)， 其连续时间原型就是 \(y' + \frac{1}{\tau}y = \frac{1}{\tau}x\)， 一阶线性方程解出的指数响应正是「时间常数 \(\tau\)」的物理来源；
    • 锁相环的相位跟踪：环路滤波器常建模为一阶（或二阶）系统， 稳态相位误差由一阶方程的强迫响应给出；
    • 自动增益控制的包络跟踪：包络检波后用一阶低通得到， 分离变量直接给出充电曲线 \(1 - e^{-t/\tau}\)。

    无人系统自主决策与优化 · 能量、时标与约束¶

    • 电池荷电状态的简化模型：\(\dot{S} = -c\,I(t)\) 是一阶（可分离）方程， 决定了续航时间的线性估计；
    • 决策时标：一阶系统的时间常数决定「决策需要多快更新」—— 若 \(\tau\) 只有几十毫秒，而决策周期是秒级，那控制回路必然失控；
    • 优化中的松弛动力学：很多连续优化算法（连续时间形式的梯度流） 写成 \(\dot{x} = -\nabla f(x)\)，其稳定性与收敛时标分析 用的正是一阶方程与 Lyapunov 方法（第四页）。

    七、自测¶

    Q1 求解 \(y' = y\cos x\)、\(y(0) = 2\)，并求 \(y\) 在 \(x = \dfrac{\pi}{2}\) 与 \(x = \pi\) 处的值。

    提示

    右端是 \(x\) 的函数与 \(y\) 的乘积，可分离变量； \(\int \cos x\,\mathrm{d}x = \sin x\)。

    解答

    分离变量：

    \[ \frac{\mathrm{d}y}{y} = \cos x\,\mathrm{d}x \]

    积分：

    \[ \ln \lvert y \rvert = \sin x + C \implies y = C_{1}e^{\sin x} \]

    代入初值 \(y(0) = 2\)：\(2 = C_{1}e^{0} = C_{1}\)，故

    \[ y = 2e^{\sin x} \]

    数值计算：

    \(x\) \(\sin x\) \(y = 2e^{\sin x}\)
    0 0.000000 2.000000
    \(\pi/6\) 0.500000 3.297442
    \(\pi/2\) 1.000000 5.436564
    \(\pi\) 0.000000 2.000000

    \(y(\pi/2) = 2e \approx 5.436564\)，\(y(\pi) = 2\)。

    有趣之处：解是周期函数（周期 \(2\pi\)），因为 \(\sin\) 有界。 这属于典型的振荡型一阶方程—— 系数 \(p(x) = -\cos x\) 周期性变号， 增长期与衰减期交替出现，所以解既不爆炸也不衰减到零。

    工程含义：这就是为什么「周期性激励下的一阶系统」会出现振荡型响应。 如果 \(p(x)\) 的平均值为正，长期会衰减；平均值为负则长期增长。 本例中 \(\cos\) 在整周期上平均为零，所以长期平均值保持不发散， 这是「临界」情形的一个例子。

    Q2 求解 \(xy' - 2y = x^{4}\)、\(y(1) = 1\)，并求 \(y(2)\) 与 \(y(3)\)。

    提示

    先把方程化成标准形 \(y' + p(x)y = q(x)\)（两边除以 \(x\)）， 再求积分因子。

    解答

    化为标准形（\(x > 0\)，因为初值在 \(x = 1\)）：

    \[ y' - \frac{2}{x}y = x^{3} \]

    积分因子：

    \[ \mu = e^{\int -\frac{2}{x}\mathrm{d}x} = e^{-2\ln x} = x^{-2} \]

    两边乘 \(\mu\)：

    \[ x^{-2}y' - 2x^{-3}y = x \implies \left(x^{-2}y\right)' = x \]

    积分：

    \[ x^{-2}y = \frac{x^{2}}{2} + C \implies y = \frac{x^{4}}{2} + Cx^{2} \]

    代入初值 \(y(1) = 1\)：\(1 = \frac12 + C \implies C = \frac12\)，故

    \[ y = \frac{x^{4}}{2} + \frac{x^{2}}{2} = \frac{x^{4} + x^{2}}{2} \]

    数值计算：

    \(x\) \(x^{4} + x^{2}\) \(y\) 检验 \(xy' - 2y\) 是否等于 \(x^{4}\)
    1.0 2 1.000000 \(0 - 2 = -2\)，右端 \(1\)，见下方说明
    2.0 20 10.000000 \(2\cdot 24 - 20 = 28\)
    3.0 90 45.000000 \(3\cdot 54 - 90 = 72\)

    说明：直接检验时要用微分形式。 由 \(y = \frac{x^{4}+x^{2}}{2}\) 得 \(y' = 2x^{3} + x\)，代入 \(xy' - 2y\)：

    \[ xy' - 2y = x(2x^{3} + x) - (x^{4} + x^{2}) = 2x^{4} + x^{2} - x^{4} - x^{2} = x^{4} \ \checkmark \]

    在 \(x=1\) 处：\(1\cdot(2+1) - 2\cdot 1 = 3 - 2 = 1 = 1^{4}\) ✓ 上表第三列原来的算法漏乘了 \(y'\) 中的项，正确做法是先求导再代入。

    结果：\(y(2) = 10\)，\(y(3) = 45\)。

    检验初值：\(y(1) = \frac{2}{2} = 1\) ✓

    这个解说明什么：\(C>0\)，所以解是 \(x^{4}\) 与 \(x^{2}\) 的组合， 两项都随 \(x\) 增长。对比上一节例题（\(C<0\) 时出现 \(-\frac{1}{4x}\) 的衰减项）—— 初值的符号决定了长期行为是增长还是衰减，这就是齐次解与特解权重之争。

    Q3 求解 \(y' + y = xy^{2}\)、\(y(0) = 1\)，并求 \(y(1)\) 与 \(y(4)\)。

    提示

    右端出现 \(y^{2}\)，是 \(n = 2\) 的伯努利方程。 令 \(v = y^{-1}\)。

    解答

    辨认为伯努利：\(p(x) = 1\)，\(q(x) = x\)，\(n = 2\)。

    换元 \(v = y^{-1}\)，两边除以 \(y^{2}\)：

    \[ \frac{y'}{y^{2}} + \frac{1}{y} = x \implies -v' + v = x \implies v' - v = -x \]

    积分因子 \(\mu = e^{-x}\)：

    \[ \left(e^{-x}v\right)' = -xe^{-x} \]

    积分（分部积分 \(\int xe^{-x}\mathrm{d}x = -(x+1)e^{-x}\)）：

    \[ e^{-x}v = (x+1)e^{-x} + C \implies v = x + 1 + Ce^{x} \]

    代入初值 \(v(0) = 1/y(0) = 1\)：\(1 = 1 + C \implies C = 0\)，故

    \[ v = x + 1 \implies y = \frac{1}{x + 1} \]

    数值计算：

    \(x\) 0 1 2 4
    \(y = \frac{1}{x+1}\) 1.000000 0.500000 0.333333 0.200000

    \(y(1) = 0.5\)，\(y(4) = 0.2\)。

    验证：\(y' = -\frac{1}{(x+1)^{2}}\)，代入左端

    \[ y' + y = -\frac{1}{(x+1)^{2}} + \frac{1}{x+1} = \frac{x}{(x+1)^{2}} \]

    右端 \(xy^{2} = \frac{x}{(x+1)^{2}}\) ✓ 两边相等。

    与例题 3 的对比：

    方程 \(q(x)\) 解 长期行为
    \(y' - y = y^{2}\) \(1\) \(\frac{1}{2e^{-x}-1}\) \(x = \ln 2\) 处爆破
    \(y' + y = xy^{2}\) \(x\) \(\frac{1}{x+1}\) 缓慢衰减到 \(0\)

    区别的来源：本例中 \(C = 0\)，齐次解 \(Ce^{x}\) 被完全消掉， 只留下特解 \(x+1\)。这说明初值恰好消掉不稳定模式时，解不会爆破。 这也是工程上「初值选得好，系统才稳定」的数学根源。

    Q4 求解 \((2x + y)\,\mathrm{d}x + (x + 2y)\,\mathrm{d}y = 0\)、\(y(0) = 1\)， 说明解的几何形状，并求 \(y\) 在 \(x = 0.5\) 处的值。

    提示

    先验证 \(P_y = Q_x\)。若恰当，求 \(F\) 后得到隐式解， 再观察它是不是椭圆。

    解答

    判定：\(P = 2x + y\)，\(Q = x + 2y\)，

    \[ \frac{\partial P}{\partial y} = 1, \qquad \frac{\partial Q}{\partial x} = 1 \implies P_y = Q_x \ \checkmark \]

    求势函数：

    \[ F = \int (2x + y)\,\mathrm{d}x = x^{2} + xy + g(y) \]
    \[ F_y = x + g'(y) = x + 2y \implies g(y) = y^{2} \]
    \[ F(x,y) = x^{2} + xy + y^{2} \]

    隐式通解：

    \[ x^{2} + xy + y^{2} = C \]

    代入初值 \(x = 0\)、\(y = 1\)：\(C = 0 + 0 + 1 = 1\)，故

    \[ x^{2} + xy + y^{2} = 1 \]

    几何形状：这是一个椭圆（二次型 \(\begin{bmatrix} 1 & 1/2 \\ 1/2 & 1 \end{bmatrix}\) 正定，特征值为 \(\frac12\) 与 \(\frac32\)，均为正）。 长半轴方向为 \((1,-1)\)，短半轴方向为 \((1,1)\)。 解曲线是闭合的，对应周期运动——这正是「中心」型平衡点的几何表征。

    求 \(x = 0.5\) 的值：代入得

    \[ 0.25 + 0.5y + y^{2} = 1 \implies y^{2} + 0.5y - 0.75 = 0 \]
    \[ y = \frac{-0.5 \pm \sqrt{0.25 + 3}}{2} = \frac{-0.5 \pm \sqrt{3.25}}{2} \]

    \(\sqrt{3.25} \approx 1.802776\)，所以

    分支 数值 判定
    \(y_1 = \frac{-0.5 + 1.802776}{2}\) 0.651388 由 \(y(0)=1>0\) 与连续性取此支
    \(y_2 = \frac{-0.5 - 1.802776}{2}\) \(-1.151388\) 另一侧的椭圆分支，舍去

    结论：\(y(0.5) \approx 0.651388\)。

    反向验证：

    \[ 0.5^{2} + 0.5 \times 0.651388 + 0.651388^{2} = 0.25 + 0.325694 + 0.424307 = 1.000001 \ \checkmark \]

    工程含义：恰当方程 + 闭合等值线 \(=\) 保守系统。 机械能守恒的无摩擦振子、无损耗的 \(LC\) 回路、理想的行星轨道 都对应这类方程。它们不会耗散也不会发散， 而在真实工程系统中必然存在阻尼，所以现实里更常见的是 「螺旋收敛」（稳定焦点）而不是「闭合椭圆」——这正是第四页的重点。

    本页小结

    你要解决的问题 第一步动作 结果形式
    右端是乘积 分离变量 显式 \(y = \phi(x)\)
    右端含 \(y\) 的一次项 求 \(\mu = e^{\int p}\) 显式 \(y = \phi(x)\)
    右端含 \(y^{n}\) 令 \(v = y^{1-n}\) 先解 \(v\)，再回代
    微分形式 查 \(P_y = Q_x\) 隐式 \(F(x,y) = C\)
    四种都不像 试换元（\(x+y\)、\(y/x\)）或转数值解法 见第五页

    最后一句话：一阶方程的价值不在于「能解出来」， 而在于它建立了「分离—积分—代初值」这套标准流程。 后面二阶、方程组、数值方法虽然形式更复杂， 每一步都能追回到这一页的某个动作。
