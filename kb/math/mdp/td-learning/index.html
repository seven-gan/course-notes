    时序差分学习¶

    上一页的动态规划要求两样我们通常没有的东西：完整的环境模型 \(p(s'\mid s,a)\)， 以及遍历所有状态的能力。这一页把它们都丢掉——只保留「能与环境交互」这一条。

    能交互就意味着能采样：做一次动作，观察下一个状态与奖励。 时序差分（Temporal-Difference, TD）学习的全部思想就是：

    用一个采样到的 \((s,a,r,s')\) 四元组，代替 Bellman 方程里那个算不出来的期望。

    这一页要解决的问题是：把「解方程」变成「边跑边学」。 它带来的好处是巨大的——不需要模型、不需要遍历全状态、可以在线增量更新。 代价是引入了随机性，于是所有结论都从「等式」变成「期望意义下的逼近」， 收敛性需要额外的条件（学习率、探索充分性）。

    这一页的位置：它是整个强化学习最核心的一页。 Q-learning 是应用最广的算法，SARSA 是安全性最相关的算法， 资格迹 TD(\(\lambda\)) 是它们的统一框架。

    一句话抓住核心

    三个更新式，一句话记住它们的区别。

    TD(0)（评估固定策略）：

    \[ V(S_t) \leftarrow V(S_t) + \alpha\left[R_{t+1} + \gamma V(S_{t+1}) - V(S_t)\right] \]

    SARSA（on-policy 控制，用实际采取的下一个动作）：

    \[ Q(S_t,A_t) \leftarrow Q(S_t,A_t) + \alpha\left[R_{t+1} + \gamma Q(S_{t+1},A_{t+1}) - Q(S_t,A_t)\right] \]

    Q-learning（off-policy 控制，用贪心的下一个动作）：

    \[ Q(S_t,A_t) \leftarrow Q(S_t,A_t) + \alpha\left[R_{t+1} + \gamma\max_a Q(S_{t+1},a) - Q(S_t,A_t)\right] \]

    唯一的差别就是目标值里那一项：

    算法 目标值里的下一动作项 策略类型 学到的是
    TD(0) \(\gamma V(S_{t+1})\) 评估给定 \(\pi\) \(V^{\pi}\)
    SARSA \(\gamma Q(S_{t+1},A_{t+1})\)，\(A_{t+1}\sim\pi\) on-policy \(Q^{\pi}\)（当前策略）
    Q-learning \(\gamma\max_a Q(S_{t+1},a)\) off-policy \(Q^{*}\)（最优策略）

    方括号里的东西叫 TD 误差：

    \[ \delta_t := R_{t+1} + \gamma V(S_{t+1}) - V(S_t) \]

    TD 误差就是「惊喜」：实际得到的比预期多还是少。 它是本模块后面所有算法的通用信号——Actor-Critic 里用它更新策略， 资格迹里用它加权历史状态，连神经科学都把它当作多巴胺信号的模型。

    一、从动态规划到时序差分¶

    1.1 动态规划的三个做不到¶

    DP 的要求 工程现实 后果
    已知精确模型 \(p(s'\mid s,a)\) 真实系统模型往往未知或不准 无法做期望
    需要遍历所有 \(s\in S\) 连续状态空间无法枚举 无法全扫描
    每次扫描 \(O(\lvert S\rvert^2\lvert A\rvert)\) 状态数大时不可承受 算力不够

    但要看清一件重要的事：DP 真正依赖模型的地方只有一个—— 计算 \(\sum_{s'}p(s'\mid s,a)V(s')\) 这个期望。 如果能把期望换成别的东西，模型就不再需要。

    1.2 核心思想：用采样代替期望¶

    关键观察（本页的全部起点）：Bellman 期望方程

    \[ V^{\pi}(s) = \sum_a\pi(a\mid s)\sum_{s'}p(s'\mid s,a)\left[r(s,a)+\gamma V^{\pi}(s')\right] \]

    右端是一个期望：对 \(A_t\sim\pi(\cdot\mid s)\) 与 \(S_{t+1}\sim p(\cdot\mid s,a)\) 取期望。 既然它是一个期望，就可以用一次采样来估计它：

    \[ \mathbb{E}\left[R_{t+1}+\gamma V(S_{t+1})\ \Big|\ S_t=s\right] \approx R_{t+1}+\gamma V(S_{t+1}) \]

    右边这个采样量就是 TD 目标（TD target）。它是一个无偏估计： 由全期望公式

    \[ \mathbb{E}\left[R_{t+1}+\gamma V(S_{t+1})\ \Big|\ S_t=s\right] = \sum_a\pi(a\mid s)\sum_{s'}p(s'\mid s,a)\left[r(s,a)+\gamma V(s')\right] \]

    即采样量的期望恰好等于 Bellman 方程的右端 \(\checkmark\)。

    1.3 TD 误差与随机逼近¶

    TD 误差定义为

    \[ \delta_t := R_{t+1} + \gamma V(S_{t+1}) - V(S_t) \]

    它是无偏的当且仅当 \(V=V^{\pi}\)：若 \(V=V^{\pi}\)，则由 Bellman 方程

    \[ \mathbb{E}[\delta_t\mid S_t=s] = \mathbb{E}[R_{t+1}+\gamma V^{\pi}(S_{t+1})\mid S_t=s]-V^{\pi}(s) = V^{\pi}(s)-V^{\pi}(s)=0 \]

    反过来，若 \(\mathbb{E}[\delta_t\mid S_t=s]=0\) 对所有 \(s\) 成立，则 \(V\) 满足 Bellman 方程， 从而 \(V=V^{\pi}\)（由不动点唯一性）。

    这就是 TD 学习的收敛判据：让 TD 误差的期望处处为零。 于是自然地得到随机逼近（stochastic approximation）式的更新：

    \[ V(S_t)\leftarrow V(S_t)+\alpha_t\,\delta_t \]

    这个更新式的含义：若实际拿到的比预期多（\(\delta_t>0\)），就把 \(V\) 往上调一点； 反之往下调。\(\alpha_t\) 是学习率，控制「调多少」。

    TD 学习是「用采样解方程」的一般套路

    把 DP 与他合并排，结构完全一样，只有一步不同：

    环节 DP TD
    写出不动点方程 \(V=\mathcal{T}^{\pi}V\) 同
    每次迭代做什么 全状态应用 \(\mathcal{T}^{\pi}\) 只对访问到的 \(s\) 做一次更新
    期望怎么算 精确求和 \(\sum_a\pi\sum_{s'}p\) 单次采样 \(r+\gamma V(s')\)
    更新幅度 完全替换 按 \(\alpha\) 部分修正
    是否需模型 需要 不需要

    「完全替换」与「部分修正」的区别值得说明： DP 里写 \(V(s)\leftarrow\mathbb{E}[\cdots]\) 是赋值（\(\alpha=1\)）； TD 里必须写成 \(V(s)\leftarrow V(s)+\alpha\delta\)（\(\alpha<1\)）， 否则单次采样的噪声会直接把 \(V\) 冲垮，无法收敛。

    1.4 TD 学习是「对 DP 的猜谜」¶

    用 Sutton 与 Barto 在《强化学习导论》里的经典说法：

    TD 学习可以被看作是对 DP 的一种「猜谜」—— 它用量化的、基于经验的猜测，去逼近 DP 所要求的精确期望。

    这个比喻抓住了三件事：

    1. 有猜测成分：用 \(V(S_{t+1})\) 当作「未来有多好」的估计， 而它本身也是学出来的——用估计去更新估计（bootstrapping）。
    2. 猜测逐步变准：每次交互给一点修正，长期看收敛到真值。
    3. 不需要模型的精确知识：猜的是「值」，不是「模型」。

    「bootstrapping」这个术语要特别注意：它指 更新一个估计量时用了另一个估计量（而不是真实结果）。 这是 TD 与 MC 的分水岭：

    方法 更新目标 是否 bootstrapping
    动态规划 \(r+\gamma\sum_{s'}p(s'\mid s,a)V(s')\) 是（需要模型）
    TD 学习 \(r+\gamma V(S_{t+1})\) 是（用采样，不需模型）
    蒙特卡洛 \(G_t\)（真实回报） 否

    用估计更新估计会带来偏差，这是 TD 的核心弱点， 也是下一节「偏差–方差权衡」要处理的问题。

    二、蒙特卡洛与时序差分¶

    2.1 蒙特卡洛方法¶

    蒙特卡洛（Monte Carlo, MC）方法完全不猜： 跑完整个回合，得到真实的折扣回报 \(G_t\)，然后用它更新：

    \[ V(S_t)\leftarrow V(S_t) + \alpha\left[G_t - V(S_t)\right] \]

    其中 \(G_t = R_{t+1}+\gamma R_{t+2}+\cdots+\gamma^{T-1}R_T\)（\(T\) 为终止时刻）。

    MC 的三个硬性要求：

    要求 原因
    回合必须终止 \(G_t\) 是有限的有限项和
    必须等到回合结束才能更新 \(G_t\) 要等所有奖励到手
    只能用完整轨迹 不能从中间某点开始

    第三条正是 MC 的根本缺陷：在持续性任务（永不终止）中无法使用， 在长回合任务中即时性极差（要等几千步才能更新一次）。

    MC 的优点：它是无偏的（\(G_t\) 是真实回报，期望正好等于 \(V^{\pi}(s)\)）， 而且不需要马尔可夫性（不需要 bootstrap，也就不依赖状态是否携带完整历史信息）。

    2.2 两者的完整对比¶

    对比维度 蒙特卡洛（MC） 时序差分（TD(0)）
    更新目标 真实回报 \(G_t\) 估计值 \(R_{t+1}+\gamma V(S_{t+1})\)
    是否 bootstrapping 否 是
    偏差 无偏 有偏（初始 \(V\) 错则偏差）
    方差 高（累加全部 \(T\) 步随机性） 低（只含一步随机性）
    何时能更新 回合结束 每一步
    能否用于持续任务 不能 能
    是否依赖马尔可夫性 不依赖 依赖
    对初始值的敏感性 低 高（初始偏差会传播）
    收敛速度（样本效率） 较慢 通常更快
    对稀疏奖励 需等很久才见到非零回报 也能较快传播信息

    方差对比的直观解释：\(G_t\) 是 \(T\) 步随机变量的和，方差随 \(T\) 线性增长； 而 \(R_{t+1}+\gamma V(S_{t+1})\) 只含一步随机性（在 \(V\) 已知的假设下方差有界）。 所以 TD 的方差远小于 MC，这是它样本效率更高的根本原因。

    偏差对比的直观解释：\(V(S_{t+1})\) 是学出来的，若它错了， TD 目标就系统性偏移。而且初始偏差会顺着迭代向回传播—— 这是 TD 的固有代价。

    2.3 偏差–方差权衡的统一视角：\(n\) 步回报¶

    这两者不是对立的两极，而是一条连续谱上的两个端点。定义 \(n\) 步回报：

    \[ G_t^{(n)} := R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{n-1}R_{t+n} + \gamma^{n}V(S_{t+n}) \]
    \(n\) 得到的算法 偏差 方差
    \(n=1\) TD(0) 高 低
    \(n=2,4,8,\dots\) \(n\) 步 TD 中等 中等
    \(n\to\infty\)（到达终止） MC 无偏 高

    这个表就是「偏差–方差权衡」在强化学习里的精确形式， \(n\) 是那个调节旋钮。

    \(n\) 步 TD 的更新式：

    \[ V(S_t)\leftarrow V(S_t)+\alpha\left[G_t^{(n)}-V(S_t)\right] \]

    「无偏」要看是对谁无偏

    MC 的无偏是真无偏：\(\mathbb{E}[G_t\mid S_t=s]=V^{\pi}(s)\) 严格成立。

    \(n\) 步 TD 的「偏差」有两层含义，容易混淆：

    1. 相对于 \(V^{\pi}\) 的偏差：当 \(n\) 有限时， \(\mathbb{E}[G_t^{(n)}\mid S_t=s]\neq V^{\pi}(s)\)—— 这是因为插入了 \(V(S_{t+n})\)，它是估计值。即使 \(V\) 正确， \(n\) 步回报的期望也只在 \(n\to\infty\) 时精确等于 \(V^{\pi}\)。
    2. 收敛后的偏差：若算法收敛到某个 \(\tilde{V}\)， 则 \(n\) 步 TD 与 TD(0) 一样都收敛到真值 \(V^{\pi}\)， 不留下固定偏差。有限 \(n\) 只影响收敛路径，不影响极限。

    结论：有限 \(n\) 带来的偏差是可消除的（随学习过程消失）， 不是不可消除的模型偏差。 这一点与函数逼近带来的不可消除偏差完全不同， 后者是本页末尾要提醒的严重问题。

    2.4 「TD 比 MC 更有效」的一个经典例子¶

    考虑一个随机游走环境：5 个非终止状态排成一行，两端是终止状态， 最右端终止奖励为 \(1\)，其余奖励为 \(0\)。真实价值为 \(V(s)=i/6\) （\(i\) 是位置编号，即「到达右端的概率」）。

    理论结果（Sutton & Barto 的经典实验）：在同样的数据量下， TD(0) 学到的价值明显更接近真值，而 MC 需要更多回合才能赶上来。

    为什么：MC 必须等到达右端才能知道回报， 且回报的方差很大（因为要经过多次随机选择）； TD 每步都能更新，且它利用了「相邻状态的价值相近」这一马尔可夫结构。

    但必须注意：这个优势建立在一个前提上——马尔可夫性成立。 若状态表示不完整（例如随机游走被改造成「每步有概率跳回随机位置」的非马尔可夫过程）， MC 反而更准。这是 TD 的马尔可夫假设在实际中失效时的典型表现。

    工程教训：TD 更好还是 MC 更好，取决于马尔可夫性的成立程度。 状态设计得好，TD 优势明显；状态设计得差，TD 的系统性偏差会比 MC 的方差更致命。

    三、TD(0) 与 SARSA：on-policy 控制¶

    3.1 从评估到控制¶

    前面讲的 TD(0) 只解决评估问题（给定 \(\pi\)，求 \(V^{\pi}\)）。 要做控制（找最优策略），需要引入动作维度：学 \(Q\) 而不是 \(V\)。

    SARSA 的做法是把 TD(0) 式中的 \(V\) 换成 \(Q\)：

    \[ Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\left[R_{t+1}+\gamma Q(S_{t+1},A_{t+1})-Q(S_t,A_t)\right] \]

    名字的来源：更新用到了五元组 \((S_t,\ A_t,\ R_{t+1},\ S_{t+1},\ A_{t+1})\)—— 用中文说就是「状态–动作–奖励–状态–动作」（State-Action-Reward-State-Action）， 各取首字母就是 SARSA。

    \(A_{t+1}\) 是怎么来的：由当前策略 \(\pi\) 在实际交互中真的选出来。 这一点至关重要，直接决定了 SARSA 是 on-policy 算法。

    3.2 on-policy 的含义与 \(\varepsilon\)-greedy 探索¶

    关键问题：如果策略总是选当前认为最好的动作（纯贪心）， 那没被试过的动作永远不会被改进，可能卡在次优解。必须探索。

    \(\varepsilon\)-greedy 策略是最常用的探索方法：

    \[ \pi(a\mid s) = \begin{cases} 1-\varepsilon+\dfrac{\varepsilon}{\lvert A(s)\rvert}, & a = \arg\max_{a'}Q(s,a') \\[6pt] \dfrac{\varepsilon}{\lvert A(s)\rvert}, & \text{否则} \end{cases} \]

    它保证两件事：

    性质 数学形式 作用
    保持探索 \(\pi(a\mid s)\geq\frac{\varepsilon}{\lvert A\rvert}>0\) 对所有 \(a\) 每个动作都会被无限次尝试
    趋近贪心 \(\varepsilon\to0\) 时退化为贪心 最终能收敛到最优

    第一个性质是收敛性的必要条件：若某动作永不被尝试， \(Q(s,a)\) 永远不会更新，就无法保证收敛到 \(Q^{*}\)。 这就是「GLIE 条件」（Greedy in the Limit with Infinite Exploration，无限探索下的极限贪心） 的实际含义。

    on-policy 的定义：行为策略（用于产生数据的策略）与目标策略（被评估/改进的策略）是同一个。 SARSA 就是这种情况——它评估的就是当前正在执行的那个 \(\varepsilon\)-greedy 策略。

    SARSA 学到的是「带探索策略」的价值，不是最优价值

    设 \(\varepsilon>0\)，SARSA 收敛到的是 \(Q^{\pi_\varepsilon}\)—— 在「有一定概率乱走」的策略下的价值。

    后果：SARSA 学出的 \(Q\) 会正确反映探索的风险。 例如在悬崖边行走：因为 \(\varepsilon\) 概率会随机走一步， 靠悬崖的路线真的有可能掉下去，所以它在该路线上的 \(Q\) 值会偏低， 于是 SARSA 倾向于选择更安全但更绕的路线。

    这不是缺陷，而是一个重要的安全特性——见例题 3 的定量分析。

    3.3 SARSA 的收敛性¶

    定理（收敛性）：若满足以下条件，SARSA 以概率 1 收敛到 \(Q^{*}\)：

    \[ \sum_{t=1}^{\infty}\alpha_t = \infty, \qquad \sum_{t=1}^{\infty}\alpha_t^2 < \infty \]

    并且策略满足 GLIE，状态–动作对无限次被访问，奖励有界。

    这两个学习率条件称为 Robbins–Monro 条件，含义值得解释清楚：

    条件 含义 反例
    \(\sum\alpha_t=\infty\) 学习率衰减得足够慢 \(\alpha_t=1/2^t\)：衰减太快，\(V\) 停在初始值附近
    \(\sum\alpha_t^2<\infty\) 学习率衰减得足够快 \(\alpha_t=\text{const}\)：噪声永不消除，\(V\) 一直抖动
    两者同时 \(\alpha_t=1/t\) 型最优 \(\sum 1/t=\infty\)，\(\sum 1/t^2=\pi^{2}/6\approx1.6449<\infty\) \(\checkmark\)

    \(\alpha_t=1/t\) 满足两个条件，这是最经典的选择。 实践中常取 \(\alpha_t = 1/(1+\text{访问次数}(s,a))\) 的变体。

    注意：条件 \(\sum\alpha_t^2<\infty\) 对表格式 SARSA / Q-learning 是必需的； 但在函数逼近（如神经网络）下通常只用常数学习率， 此时只能保证收敛到某个邻域而不是精确最优—— 这是深度强化学习的理论困难之一。

    四、Q-learning：off-policy 控制¶

    4.1 更新式与它的巧妙之处¶

    Q-learning 的更新式只有一处与 SARSA 不同：

    \[ Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\left[R_{t+1}+\gamma\max_{a}Q(S_{t+1},a)-Q(S_t,A_t)\right] \]

    把 \(\gamma Q(S_{t+1},A_{t+1})\) 换成 \(\gamma\max_a Q(S_{t+1},a)\)。

    这个替换为什么能学到最优值：核对 Bellman 最优方程

    \[ Q^{*}(s,a) = r(s,a) + \gamma\sum_{s'}p(s'\mid s,a)\max_{a'}Q^{*}(s',a') \]

    Q-learning 的更新目标 \(R_{t+1}+\gamma\max_a Q(S_{t+1},a)\) 正是右端期望里面的那个量的采样。所以：

    \[ \mathbb{E}\left[R_{t+1}+\gamma\max_a Q(S_{t+1},a)\ \Big|\ S_t=s,A_t=a\right] = r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\max_{a'}Q(s',a') \]

    采样量的期望恰好是 Bellman 最优方程的右端—— 于是和 1.3 节一样的论证表明：让 TD 误差期望为零的 \(Q\) 就是 \(Q^{*}\)。

    4.2 为什么是 off-policy¶

    关键观察：更新式里的 \(\max_a Q(S_{t+1},a)\) 只依赖 \(Q\) 表，不依赖实际采到的 \(A_{t+1}\)。

    这意味着：无论数据由哪个策略产生，这个更新都在朝 \(Q^{*}\) 推进。 产生数据的策略（行为策略）与被学习的目标策略（贪心策略）可以不同—— 这就是 off-policy。

    off-policy 的巨大优势：

    优势 说明
    可用旧数据 数据由过时策略产生也能学（经验回放的基础）
    可学别人的数据 人类演示、其他机器人、仿真数据都能用
    可学多策略混合数据 大幅提升样本利用率
    目标策略可以纯贪心 不受探索策略的干扰

    代价：off-policy 的收敛更脆弱，且（在 MC 形式下）需要重要性采样修正。 Q-learning 之所以这么受欢迎，正是因为它用「取 max」这个技巧 绕开了重要性采样——这是它最漂亮的数学贡献。

    4.3 on-policy 与 off-policy 的完整对照¶

    对比项 SARSA（on-policy） Q-learning（off-policy）
    目标值 \(R+\gamma Q(S',A')\)，\(A'\sim\pi\) \(R+\gamma\max_a Q(S',a)\)
    行为策略 = 目标策略 是 否（目标为贪心）
    收敛到 \(Q^{\pi}\)（当前探索策略） \(Q^{*}\)（最优）
    是否需重要性采样 不需要 不需要（取 max 绕开了）
    能否用经验回放 一般不 可以
    安全性（探索风险） 考虑（更保守） 不考虑（更激进）
    典型失败模式 过于保守，收敛到次优 靠近悬崖时高风险
    实现难度 简单 同样简单
    收敛条件 Robbins–Monro + GLIE Robbins–Monro + 充分探索

    怎么选：SARSA 还是 Q-learning

    判断标准是「训练过程中的错误能不能容忍」：

    场景 推荐 理由
    仿真环境，试错免费 Q-learning 学得快，直接逼近最优
    真实机器人，撞了要修 SARSA 考虑探索风险，更保守
    需要复用历史数据 Q-learning 支持经验回放
    有安全约束 SARSA 或更保守的变体 on-policy 天然含风险
    需要在线学习、不可重放 SARSA 与在线策略一致

    一句话：Q-learning 学的是「如果以后都走最优会怎样」， SARSA 学的是「按现在这个爱乱走的策略实际会怎样」。 训练期间存在危险时，后者的估计更贴近现实。

    4.4 最大化偏差与 Double Q-learning¶

    Q-learning 有一个系统性缺陷，来源正是那个 \(\max\)。

    问题：设 \(Q\) 表带有估计噪声。取 \(\max_a Q(s,a)\) 时， 噪声为正的估值更容易被选中，于是

    \[ \mathbb{E}\left[\max_a Q(s,a)\right] > \max_a \mathbb{E}\left[Q(s,a)\right] \]

    这个不等式的右边才是我们想估的量。 左边系统性偏大—— 称为最大化偏差（maximization bias）。

    数值示例（本页例题 4 会详细算）：两个动作的真值都是 \(0\)， \(Q\) 的估计带独立标准正态噪声，则

    \[ \mathbb{E}\left[\max(Q_1,Q_2)\right] = \frac{1}{\sqrt{\pi}} \approx 0.5642 > 0 \]

    偏大了 0.56——完全来自噪声。若奖励尺度是 1， 这个偏差足以让智能体一直选一个实际没有优势的动作。

    Double Q-learning 的解法：把估计和选动作分开，用两套独立的 \(Q\) 表：

    \[ Q_1(S_t,A_t)\leftarrow Q_1(S_t,A_t)+\alpha\left[R_{t+1}+\gamma\,Q_2\!\left(S_{t+1},\ \arg\max_a Q_1(S_{t+1},a)\right)-Q_1(S_t,A_t)\right] \]

    （每次随机选择更新 \(Q_1\) 或 \(Q_2\)，并相应交换两者的角色。）

    为什么有效：\(\arg\max\) 由 \(Q_1\) 决定，但取值的 \(Q_2\) 是独立估计的。 「选中最大」这件事用了一个噪声源，「评估它多大」用了另一个独立的噪声源， 两者不相关，故偏差被消除：

    \[ \mathbb{E}\left[Q_2\left(s',\ \arg\max_a Q_1(s',a)\right)\right] = \max_a \mathbb{E}\left[Q_2(s',a)\right] \]

    （在 \(Q_1,Q_2\) 独立且都无偏的假设下）。

    为什么这是个重要的问题

    最大化偏差在奖励稀疏、噪声大的环境中特别严重， 因为它让算法系统性地高估未充分探索的动作。

    这在实践中表现为：智能体反复尝试一个其实不好的动作， 因为它「看起来有潜力」（实际是噪声抬高了估值）。

    凡是更新式里有 \(\max\) 的算法都有这个问题： Q-learning、值迭代（在有噪声估计时）、DQN、DDPG—— 这也是为什么深度强化学习里 DQN 用了两个网络 （在线网络选动作、目标网络评估值）， 它的动机与 Double Q-learning 完全相同。

    4.5 收敛性证明思路¶

    Q-learning 的收敛性证明比 SARSA 更微妙，因为它是 off-policy、 且更新里含 \(\max\)（非线性）。证明的核心是一个两个时间尺度的论证：

    思路（把随机逼近写成「压缩算子 + 噪声」）：

    第一步：把更新写成算子形式。 定义

    \[ (\mathcal{T}Q)(s,a) = r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\max_{a'}Q(s',a') \]

    则 Q-learning 的更新是 \(Q_{t+1}=Q_t+\alpha_t\left[(\mathcal{T}Q_t)(s,a)-Q_t(s,a)+\text{噪声}\right]\)， 其中「噪声」来自单次采样代替期望：

    \[ \text{噪声} = R_{t+1}+\gamma\max_a Q_t(S_{t+1},a) - \mathbb{E}\left[\cdots\right] \]

    第二步：噪声在条件期望下为零。

    \[ \mathbb{E}\left[\text{噪声}\ \Big|\ \mathcal{F}_t\right] = 0 \]

    这是 4.1 节算出的无偏性。故更新是一个鞅差分（martingale difference）驱动的随机逼近。

    第三步：\(\mathcal{T}\) 是 \(\gamma\)-压缩的（下一页与上一页都证明了）。

    第四步：用随机逼近定理。 由 Robbins–Monro 条件 （\(\sum\alpha_t=\infty\)、\(\sum\alpha_t^2<\infty\)） 与「充分探索」（每个 \((s,a)\) 被访问无限次）， 可以证明 \(Q_t\to Q^{*}\) 几乎必然。

    证明的关键难点：第三步的压缩性是在无穷范数下成立的， 但随机逼近的收敛定理通常需要加权范数—— 因为不同 \((s,a)\) 的访问频率不同。引入权重 \(w(s,a)\) 与范数

    \[ \lVert Q\rVert_w = \max_{s,a}\frac{\lvert Q(s,a)\rvert}{w(s,a)} \]

    可证 \(\mathcal{T}\) 在此范数下仍是压缩的，从而完成证明。

    「充分探索」这个条件为什么不可省：若某个 \((s,a)\) 从不被访问， 它的 \(Q\) 值永远是初始值，永远不收敛。这就是 5.2 节强调 \(\varepsilon\)-greedy 必须保证 \(\pi(a\mid s)\geq\varepsilon/\lvert A\rvert>0\) 的原因。

    五、资格迹与 TD(\(\lambda\))¶

    5.1 前向视角：\(\lambda\)-回报¶

    \(n\) 步回报给了一个离散的旋钮。能不能把所有 \(n\) 加权平均起来？ 可以：

    \[ G_t^{\lambda} := (1-\lambda)\sum_{n=1}^{\infty}\lambda^{n-1}G_t^{(n)} \]

    其中 \(\lambda\in[0,1]\)。

    权重 \((1-\lambda)\lambda^{n-1}\) 的和为 1（几何分布归一化）：

    \[ (1-\lambda)\sum_{n=1}^{\infty}\lambda^{n-1} = (1-\lambda)\cdot\frac{1}{1-\lambda} = 1 \quad \checkmark \]

    所以 \(\lambda\)-回报是各 \(n\) 步回报的凸组合，\(n\) 越大权重越小（按 \(\lambda\) 指数衰减）。

    两个极端情形：

    \(\lambda\) \(\lambda\)-回报 等价于
    \(0\) \((1-0)\cdot 1\cdot G_t^{(1)}=G_t^{(1)}\) TD(0)
    \(1\) \(\sum_{n=1}^{\infty}0^{n-1}G_t^{(n)}\)（只剩 \(n=1\)？不对） 见下

    \(\lambda=1\) 要小心处理：此时 \((1-\lambda)\lambda^{n-1}\) 在 \(n=1\) 处是 \(1\cdot1=1\)， 在 \(n\geq2\) 处是 \(0\cdot1=0\)，形式上只剩 \(G_t^{(1)}\)。

    这说明上述定义在 \(\lambda=1\) 处不连续—— 它是一个折扣和的定义方式问题。标准做法是定义

    \[ G_t^{\lambda} = (1-\lambda)\sum_{n=1}^{T-t-1}\lambda^{n-1}G_t^{(n)} + \lambda^{T-t-1}G_t \]

    即在最后一个完整回报 \(G_t\) 上额外加一个 \(\lambda^{T-t-1}\) 权重。 这样 \(\lambda=1\) 时恰好退化为 \(G_t\)（纯 MC），且权重总和仍为 1。务必用这个定义。

    用这个定义检查权重和（设回合长 \(T-t\) 步）：

    \[ (1-\lambda)\sum_{n=1}^{T-t-1}\lambda^{n-1}+\lambda^{T-t-1} = (1-\lambda)\cdot\frac{1-\lambda^{T-t-1}}{1-\lambda}+\lambda^{T-t-1} = 1-\lambda^{T-t-1}+\lambda^{T-t-1} = 1 \quad \checkmark \]

    于是完整对照：

    \(\lambda\) \(\lambda\)-回报 等价算法 偏差 方差
    \(0\) \(G_t^{(1)}\) TD(0) 高 低
    \(0<\lambda<1\) 混合 TD(\(\lambda\)) 中 中
    \(1\) \(G_t\) MC 无偏 高

    5.2 反向视角：资格迹¶

    前向视角有个致命问题：它需要等到回合结束才能算 \(G_t^{(n)}\)—— 这样 TD 的「每步更新」优势就丢了。

    反向视角用资格迹（eligibility trace）解决了这个问题：

    \[ E_t(s) = \begin{cases} \gamma\lambda E_{t-1}(s)+1, & s = S_t \\ \gamma\lambda E_{t-1}(s), & s \neq S_t \end{cases} \]
    \[ V(s)\leftarrow V(s)+\alpha\,\delta_t\,E_t(s) \quad \text{对所有 } s \]

    资格迹的含义（名字的来源）：\(E_t(s)\) 衡量状态 \(s\) 「有多少资格为当前的 TD 误差负责」。 「eligibility trace」借用的是信用分配（credit assignment）的比喻—— 哪些过去的状态有资格分享当前的惊喜。

    三个关键性质：

    性质 数学形式 含义
    每步衰减 \(E_t(s)=\gamma\lambda E_{t-1}(s)\) 越久远的状态「资格」越低
    访问时加一 \(E_t(S_t)\mathrel{+}=1\) 刚访问的状态获得全额资格
    用迹加权更新 \(\Delta V(s)=\alpha\delta_t E_t(s)\) 一次 TD 误差更新所有状态

    「一次误差更新所有状态」是反向视角最实用的一点： 不需要等回合结束，每步都能对全部状态做一次更新， 而且更新量自动按「该状态与当前的相关程度」加权。

    5.3 两者等价：TD(\(\lambda\)) 的核心定理¶

    定理（前向–反向等价）：在线性函数逼近与表格式情形下， 在回合结束时，反向视角（资格迹）对 \(V\) 的累积更新量， 等于前向视角（\(\lambda\)-回报）的更新量。

    证明要点（这个推导很值得看一遍）： 设回合为 \(S_t,S_{t+1},\dots,S_T\)，各步 TD 误差为 \(\delta_t,\dots,\delta_{T-1}\)。 反向视角下 \(V(S_t)\) 累积收到的更新量是

    \[ \Delta V(S_t)=\alpha\sum_{k=t}^{T-1}\delta_k\,E_k(S_t) \]

    而状态 \(S_t\) 在第 \(k\) 步的资格迹可以精确算出。注意 \(S_t\) 在 \(t\) 步被访问后， 若无再次访问，其迹为

    \[ E_k(S_t) = (\gamma\lambda)^{k-t} \]

    （每步乘一次 \(\gamma\lambda\)）。代入即得

    \[ \Delta V(S_t)=\alpha\sum_{k=t}^{T-1}(\gamma\lambda)^{k-t}\delta_k \]

    这正是「前向视角」的另一种写法（可以证明 \(G_t^{\lambda}-V(S_t)=\sum_{k=t}^{T-1}(\gamma\lambda)^{k-t}\delta_k\)），即

    \[ \mathbb{E}\left[G_t^{\lambda}\right] = V(S_t) + \mathbb{E}\left[\sum_{k=t}^{T-1}(\gamma\lambda)^{k-t}\delta_k\right] \]

    这个等式是本页最漂亮的结果：它说明 「用加权历史误差之和」与「用 \(\lambda\)-回报的误差」是同一件事的两种算法实现。

    视角 何时更新 需存什么 实现复杂度
    前向（\(\lambda\)-回报） 回合结束后 整条轨迹 需存轨迹，\(O(T)\) 内存
    反向（资格迹） 每一步 一个迹向量 \(E(s)\) \(O(\lvert S\rvert)\) 内存

    反向视角是实际可用的那个——它的内存与状态数同阶，与回合长度无关。 前向视角只用于理论分析。 这个「同一算法两种视角」的模式 在后面讲 GAE（广义优势估计）时会再次出现。

    资格迹的一个实践要点：lambda 与 alpha 的配合

    资格迹会放大有效学习率：因为一次 TD 误差同时更新了多个状态， 等价于学习率被乘了一个因子。

    经验规律：用 TD(\(\lambda\)) 时， 学习率 \(\alpha\) 应当大致按 \(\dfrac{1}{1+\lambda L}\) 缩小， 其中 \(L\approx\dfrac{1}{1-\gamma\lambda}\) 是平均迹长度。

    否则容易出现数值发散——这是 TD(\(\lambda\)) 实现中最常见的坑， 表现为 \(V\) 值迅速变成极大或 NaN。

    六、典型例题¶

    例题 1：同一轨迹上 TD(0) 与 MC 的数值对比¶

    环境：三状态序列 \(A\to B\to C\to T\)（\(T\) 终止）， 奖励依次为 \(0,0,1\)；折扣 \(\gamma=0.9\)，学习率 \(\alpha=0.1\)； 初始估计 \(V(A)=1,\ V(B)=2,\ V(C)=3,\ V(T)=0\)。

    (a) 用 TD(0) 逐步更新，求每一步后的 \(V\)； (b) 用首次访问 MC 更新，求更新后的 \(V\)； © 对比两者并解释差异的来源。

    思路

    TD(0) 每步立刻更新，注意第二个 TD 误差要用已经更新过的 \(V(B)\) 还是更新前的 \(V(B)\)？——按在线 TD(0) 的标准做法， 第二个 TD 误差用更新前的 \(V(B)=2\)（因为该误差在本步之前就已算出）。 为了对比清晰，本题采用「先算全部 TD 误差、再统一更新」的方式， 这样与 MC 的对比更公平。 MC 要先算出 \(G(A)=0.9^2\times1\)、\(G(B)=0.9\times1\)、\(G(C)=1\)。

    解答

    (a) TD(0) 逐步更新。

    第 1 步：从 \(A\) 到 \(B\)，奖励 \(0\)。

    \[ \delta_1 = 0 + 0.9\times V(B) - V(A) = 0 + 0.9\times2 - 1 = 0.8 \]
    \[ V(A) \leftarrow 1 + 0.1\times0.8 = 1.08 \]

    第 2 步：从 \(B\) 到 \(C\)，奖励 \(0\)。

    \[ \delta_2 = 0 + 0.9\times V(C) - V(B) = 0 + 0.9\times3 - 2 = 0.7 \]
    \[ V(B) \leftarrow 2 + 0.1\times0.7 = 2.07 \]

    第 3 步：从 \(C\) 到 \(T\)，奖励 \(1\)。

    \[ \delta_3 = 1 + 0.9\times V(T) - V(C) = 1 + 0 - 3 = -2.0 \]
    \[ V(C) \leftarrow 3 + 0.1\times(-2.0) = 2.8 \]

    TD(0) 更新后的估计：

    \[ V_{\text{TD}} = \left(1.08,\ 2.07,\ 2.80\right) \]

    (b) 首次访问 MC 更新。

    先算三个真实回报：

    \[ G(C) = R_{C\to T} = 1 \]
    \[ G(B) = R_{B\to C} + \gamma G(C) = 0 + 0.9\times1 = 0.9 \]
    \[ G(A) = R_{A\to B} + \gamma G(B) = 0 + 0.9\times0.9 = 0.81 \]

    再对每个状态各更新一次：

    \[ V(A)\leftarrow 1 + 0.1(0.81-1) = 1 - 0.019 = 0.981 \]
    \[ V(B)\leftarrow 2 + 0.1(0.90-2) = 2 - 0.11 = 1.89 \]
    \[ V(C)\leftarrow 3 + 0.1(1.00-3) = 3 - 0.2 = 2.8 \]

    MC 更新后的估计：

    \[ V_{\text{MC}} = \left(0.981,\ 1.89,\ 2.80\right) \]

    © 对比与解释。

    状态 初始 \(V\) TD(0) 更新后 MC 更新后 真实值（该策略下）
    \(A\) \(1.000\) \(1.080\) \(0.981\) \(0.810\)
    \(B\) \(2.000\) \(2.070\) \(1.890\) \(0.900\)
    \(C\) \(3.000\) \(2.800\) \(2.800\) \(1.000\)

    三个关键观察：

    (1) \(C\) 的更新完全相同。 因为 \(C\) 是最后一站， TD 目标 \(1+\gamma V(T) = 1\) 恰好等于 MC 回报 \(G(C)=1\)。 当误差不需要 bootstrap 时（终止前一步），TD 与 MC 等价—— 这印证了「MC 是 \(n\to\infty\) 的 TD、TD(0) 是 \(n=1\) 的 TD」， 而在最后一站两者重合。

    (2) TD 把值「往高处拉」，MC 把值「往低处拉」。 原因很清楚：

    状态 TD 目标 MC 目标 谁更接近真值
    \(A\) \(0.9\times2 = 1.8\) \(0.81\) MC（真值 \(0.81\)）
    \(B\) \(0.9\times3 = 2.7\) \(0.90\) MC（真值 \(0.90\)）
    \(C\) \(1.0\) \(1.00\) 相同

    TD 的目标被 \(V(B)=2\)、\(V(C)=3\) 这两个偏高的初始估计污染了—— 这正是 bootstrapping 带来的偏差。因为初始值 \(V\) 远高于真值 （\(2\) 对 \(0.9\)、\(3\) 对 \(1.0\)），TD 目标也跟着偏高。

    (3) 一次更新后 MC 更准，但这不是定论。 本题只更新一次， 且初始值恰好严重偏高，所以 MC 占优。若多跑几轮：

    更新轮数 TD(0) 的 \(V(A)\) MC 的 \(V(A)\) 真值
    0 \(1.000\) \(1.000\) \(0.810\)
    1 \(1.080\) \(0.981\) \(0.810\)
    2 \(1.008\) \(0.966\) \(0.810\)
    3 \(0.952\) \(0.954\) \(0.810\)

    （每轮都用同一轨迹；TD 每轮做 3 次更新，MC 每轮做 3 次更新。）

    TD 在第 3 轮就已经接近真值（\(0.952\) 与真值 \(0.810\) 的差距来自 只用了 \(\alpha=0.1\) 的步长），而 MC 的收敛节奏受同一轨迹重复的制约。 这就是「样本效率」的体现：TD 用一条轨迹的信息做了 3 次传播， MC 只做了一次「终点回传」。

    (d) 结论汇总。

    维度 本题中的表现
    TD 的偏差 明显（被 bootstrap 的偏差估值污染）
    MC 的偏差 无（\(G_t\) 是真实回报）
    TD 的方差 低（每步只含一步随机性）
    本题的胜负 单次更新 MC 更准；多轮 TD 追得更快
    关键教训 TD 的初始值不能随便设；MC 无所谓

    最重要的工程结论：TD 学习对初始值敏感。 本题中若把初始值设为 \(V\equiv0\)（而非偏高）， TD 的首步目标就会是 \(0.9\times0=0<0.81\)，方向立刻变得正确。 实践中 TD 的初始值常取 \(0\) 或很小的值，就是一个朴素的防偏手段。

    例题 2：TD(\(\lambda\)) 的资格迹逐步计算¶

    环境：与例题 1 相同的轨迹 \(A\to B\to C\to T\)，奖励 \(0,0,1\)； \(\gamma=0.9\)，\(\alpha=0.1\)，\(\lambda=0.5\)； 初始 \(V=(1,2,3,0)\)。 用反向视角（资格迹）逐步更新，列出每一步的资格迹与 \(V\)， 并用前向视角的加权误差和验证结果。

    思路

    资格迹的更新顺序很重要：先把所有迹乘上 \(\gamma\lambda\)，再给当前状态加一。 算量 \(\gamma\lambda = 0.45\)。 最后用 \(\sum_{k=t}^{T-1}(\gamma\lambda)^{k-t}\delta_k\) 核对。

    例题 3：Q-learning 与 SARSA 的差异（含悬崖问题定量分析）¶

    (a) 某步的数据为：\(Q(s,a)=2.0\)，\(r=1.0\)，\(S'=s'\)， 行为策略在 \(s'\) 处实际选择了动作 \(a'\) 且 \(Q(s',a')=3.0\)， 而 \(\max_{a}Q(s',a)=4.5\)。取 \(\gamma=0.9\)、\(\alpha=0.1\)， 分别用 Q-learning 与 SARSA 更新 \(Q(s,a)\)。

    (b) 悬崖行走问题：沿悬崖边缘走需要 \(9\) 步到达目标， 每步奖励 \(-1\)，但每步有概率 \(q\) 失足掉下悬崖（奖励 \(-100\)，回合结束）； 绕远路需要 \(11\) 步，完全安全。行为策略是 \(\varepsilon\)-greedy（4 个动作）， 故失足概率 \(q\approx\varepsilon/4\)。 求 \(\varepsilon\) 的临界值， 并解释为什么这解释了 SARSA 更保守的现象。

    思路

    (a) 两个算法唯一区别是目标值里用 \(\max\) 还是用实际采样的 \(Q(s',a')\)。 (b) 沿悬崖路线价值 \(V_A\) 满足 \(V_{\text{step}} = q(-100)+(1-q)(-1+\gamma V_{\text{next}})\)， 从终点倒推 9 步。绕路的价值是确定性的 \(-\frac{1-\gamma^{11}}{1-\gamma}\)。令两者相等解 \(q\)。

    解答

    (a) 单步更新对比。

    Q-learning（用 \(\max\)）：

    \[ \text{target} = r + \gamma\max_a Q(s',a) = 1.0 + 0.9\times4.5 = 1.0+4.05 = 5.05 \]
    \[ Q(s,a)\leftarrow 2.0 + 0.1\times(5.05-2.0) = 2.0+0.305 = 2.305 \]

    SARSA（用实际采取的 \(a'\)）：

    \[ \text{target} = r + \gamma Q(s',a') = 1.0 + 0.9\times3.0 = 1.0+2.7 = 3.70 \]
    \[ Q(s,a)\leftarrow 2.0 + 0.1\times(3.70-2.0) = 2.0+0.17 = 2.17 \]

    对比：

    算法 目标值 增量 更新后 \(Q(s,a)\)
    Q-learning \(5.05\) \(+0.305\) \(2.305\)
    SARSA \(3.70\) \(+0.17\) \(2.17\)

    Q-learning 把 \(Q(s,a)\) 抬得更高（\(2.305>2.17\)），差距 \(0.135\)。 这反映了两种算法的根本差别： Q-learning 假设今后都走最优（\(4.5\)）， SARSA 假设今后按当前行为策略走（\(3.0\)）。 行为策略带探索时，后者的估计更贴近现实。

    (b) 悬崖问题：临界探索率。

    绕远路的价值（确定性，11 步）。 每步 \(-1\)，折扣后

    \[ V_B = -\left(1+\gamma+\gamma^2+\cdots+\gamma^{10}\right) = -\frac{1-\gamma^{11}}{1-\gamma} = -\frac{1-0.9^{11}}{0.1} \]

    \(0.9^{11} = 0.313810596\)，故

    \[ V_B = -\frac{1-0.313810596}{0.1} = -\frac{0.686189404}{0.1} = -6.861894 \]

    沿悬崖路线的价值（随机）。 记从「距离终点还剩 \(k\) 步」处出发的价值为 \(v_k\)， 边界 \(v_0=0\)（已到达）。每步：

    \[ v_{k} = q\times(-100) + (1-q)\left(-1+\gamma v_{k-1}\right) \]

    逐步倒推 9 次得到 \(v_9\)（起点）。数值结果：

    每步失足概率 \(q\) \(V_A\) 与 \(V_B=-6.8619\) 比较
    \(0.0000\) \(-6.125795\) 悬崖路线更好
    \(0.0005\) \(-6.418400\) 悬崖路线更好
    \(0.0010\) \(-6.710025\) 悬崖路线更好
    \(0.0013\) \(-6.884533\) 绕路更好（已越过临界点）
    \(0.0050\) \(-9.008180\) 绕路更好
    \(0.0100\) \(-11.795491\) 绕路更好
    \(0.0200\) \(-17.096842\) 绕路更好
    \(0.0500\) \(-31.015030\) 绕路更好

    临界值 \(q^{*}\)： 用二分法求解 \(v_9(q)=V_B\)：

    \[ q^{*} \approx 0.001261 \]

    换算成探索率（4 个动作，\(\varepsilon\)-greedy 下的失足概率 \(q\approx\varepsilon/4\)）：

    \[ \varepsilon^{*} = 4q^{*} \approx 0.005 \]

    结论：只要探索率超过约 \(0.5\%\)，走悬崖边缘在价值上就不再划算。

    这个数字小得惊人，正是悬崖问题的要害：

    观察 含义
    \(\varepsilon^{*}\approx0.5\%\) 极小的探索就足以让冒险路线变差
    失足代价 \(100\) vs 绕路多花 \(2\) 步 代价比是 \(50:1\)，风险被极度放大
    9 步中有 9 次失足机会 机会多，累积风险高

    为什么 SARSA 更保守——现在有了定量解释：

    SARSA 学的是 \(Q^{\pi_\varepsilon}\)，即在含 \(\varepsilon\) 探索的策略下的真实价值。 由于 \(\varepsilon=0.1\)（常用值）\(\gg\varepsilon^{*}=0.005\)， SARSA 会算出悬崖路线的价值远低于绕路，因而选择绕路。

    Q-learning 学的是 \(Q^{*}\)，它假装探索不存在， 于是认为悬崖路线（9 步）优于绕路（11 步），因而选择贴边冒险。

    实测表现（这是强化学习最著名的实验之一）：

    算法 学到的路径 训练期间的平均回报 训练结束后（\(\varepsilon\to0\)）的回报
    Q-learning 贴边（最优） 差（常掉下去） 好（最优）
    SARSA 绕路（安全） 好（很少掉） 略差（多走 2 步）

    工程决策：

    • 仿真训练、之后关掉探索上线：用 Q-learning（最终性能更好）。
    • 真机训练、不允许撞坏：用 SARSA（训练过程更安全）。
    • 安全关键系统：用 SARSA，或显式加入风险约束 （如把 \(-100\) 改成更极端的惩罚，或直接用 CVaR 等风险度量）。

    补充说明（为什么 \(\varepsilon\) 不该一味调小）： 既然 \(\varepsilon\) 小就安全，为什么不直接取 \(\varepsilon=0.001\)？ 因为由 3.2 节的 GLIE 条件，探索不足会导致某些 \((s,a)\) 永不被访问， \(Q\) 值不收敛。过小的 \(\varepsilon\) 会带来两个问题： 收敛到次优解（局部最优），以及收敛速度极慢。 \(\varepsilon\) 的调参本质上是「安全性」与「最优性」的权衡， 这个权衡在悬崖问题上表现得最尖锐。

    例题 4：最大化偏差与 Double Q-learning¶

    (a) 设两个动作的真实价值都是 \(0\)，但 \(Q\) 的估计带独立同分布的标准正态噪声 \(Q_1,Q_2\sim N(0,1)\)。求 \(\mathbb{E}[\max(Q_1,Q_2)]\) 并指出偏差大小。

    (b) 用一个具体的数值表格场景说明这个偏差如何误导决策。

    © 说明 Double Q-learning 如何消除这个偏差。

    思路

    (a) 用 \(\max(x,y)=\frac{x+y+\lvert x-y\rvert}{2}\)， 再注意 \(Q_1-Q_2\sim N(0,2)\)，故 \(\mathbb{E}\lvert Q_1-Q_2\rvert=\sqrt{2}\cdot\sqrt{2/\pi}=\frac{2}{\sqrt{\pi}}\)。 © 关键是「选动作」与「估值」用两套独立估计。

    解答

    (a) 计算期望偏差。

    用恒等式拆开最大值：

    \[ \max(Q_1,Q_2) = \frac{Q_1+Q_2+\lvert Q_1-Q_2\rvert}{2} \]

    取期望。由于 \(Q_1,Q_2\) 独立同分布 \(N(0,1)\)，故 \(\mathbb{E}[Q_1]=\mathbb{E}[Q_2]=0\)，于是

    \[ \mathbb{E}\left[\max(Q_1,Q_2)\right] = \frac{0+0+\mathbb{E}\lvert Q_1-Q_2\rvert}{2} = \frac{\mathbb{E}\lvert Q_1-Q_2\rvert}{2} \]

    求 \(\mathbb{E}\lvert Q_1-Q_2\rvert\)。 令 \(D=Q_1-Q_2\)。 独立正态变量之差仍正态，方差相加：

    \[ D \sim N\left(0,\ 1+1\right) = N(0,2), \qquad \sigma_D = \sqrt{2} \]

    对 \(D\sim N(0,\sigma^2)\)，已知 \(\mathbb{E}\lvert D\rvert = \sigma\sqrt{\dfrac{2}{\pi}}\)，故

    \[ \mathbb{E}\lvert Q_1-Q_2\rvert = \sqrt{2}\cdot\sqrt{\frac{2}{\pi}} = \frac{2}{\sqrt{\pi}} \]

    代入：

    \[ \mathbb{E}\left[\max(Q_1,Q_2)\right] = \frac{1}{2}\cdot\frac{2}{\sqrt{\pi}} = \frac{1}{\sqrt{\pi}} \approx 0.564190 \]

    结论：真实价值都是 \(0\)，但 \(\max\) 的期望是 \(0.5642\)—— 系统性地高估了约 \(0.56\)。

    蒙特卡洛验证（\(4\times10^{5}\) 次独立抽样）： 得到 \(\mathbb{E}[\max]\approx0.563446\)，与理论值 \(0.564190\) 相符 \(\checkmark\) （差异来自抽样误差）。

    偏差的严重程度对照：

    噪声标准差 \(\sigma\) \(\mathbb{E}[\max(Q_1,Q_2)]\) 偏差
    \(0\) \(0\) \(0\)
    \(0.5\) \(\dfrac{0.5}{\sqrt{\pi}}\approx0.2821\) \(0.2821\)
    \(1.0\) \(\approx0.5642\) \(0.5642\)
    \(2.0\) \(\approx1.1284\) \(1.1284\)

    偏差与噪声标准差成正比：\(\mathbb{E}[\max]=\frac{\sigma}{\sqrt{\pi}}\)。 噪声越大，高估越严重——这就是「奖励噪声大、采样少」的环境里 Q-learning 特别容易失效的原因。

    更一般的结论（动作数为 \(k\)）：偏差随 \(k\) 增大而增大。 可以证明当 \(k\to\infty\) 时 \(\mathbb{E}[\max]\approx\sigma\sqrt{2\ln k}\)， 对数增长——这意味着动作维度大时偏差会显著恶化。

    (b) 具体的误导场景。 考虑三个动作的一个状态 \(s\)， 真实价值完全相同（都是 \(0\)），但 \(Q\) 表带噪声：

    动作 真实 \(Q^{*}\) 当前估计 \(\hat{Q}\)（带噪声）
    \(a_1\) \(0\) \(+0.9\)
    \(a_2\) \(0\) \(-0.4\)
    \(a_3\) \(0\) \(+0.2\)

    \(\max_a\hat{Q}(s,a) = 0.9\)，而真实的最大值是 \(0\)—— 高估了 \(0.9\)。

    后果链条：

    步骤 发生什么 问题
    1 贪心选择 \(a_1\)（因为 \(\hat{Q}\) 最高） 其实三个动作一样好
    2 用 \(R+\gamma\max\hat{Q}\) 更新，目标含 \(0.9\) 的高估 高估被写入 \(Q\)
    3 下次还选 \(a_1\)，因为它的估值被抬高了 自我强化
    4 其他动作得不到更新，其噪声永远不被平均掉 偏差累积

    最终表现：智能体反复执行一个没有优势的动作， 而真正有优势的动作（如果存在）可能被噪声淹没而永远不被探索充分。

    这个现象在稀疏奖励任务中尤其致命： 大部分 \((s,a)\) 的奖励都是 \(0\)， 真实 \(Q\) 值几乎相同，\(Q\) 值的差异几乎全部来自噪声， 于是 \(\max\) 的高估直接主导了决策。

    © Double Q-learning 的解法。

    核心思想：把「选动作」和「给它估值」这两件事用两套独立估计完成。

    维护两个 \(Q\) 表 \(Q_1,Q_2\)。每次更新时（以更新 \(Q_1\) 为例）：

    \[ Q_1(S_t,A_t)\leftarrow Q_1(S_t,A_t)+\alpha\left[R_{t+1}+\gamma\,Q_2\!\left(S_{t+1},\ \arg\max_a Q_1(S_{t+1},a)\right)-Q_1(S_t,A_t)\right] \]

    关键结构：

    \[ \underbrace{\arg\max_a Q_1(S_{t+1},a)}_{\text{用 } Q_1 \text{ 选动作}} \quad\text{与}\quad \underbrace{Q_2(S_{t+1},\ \cdot\,)}_{\text{用 } Q_2 \text{ 估值}} \]

    两个环节用了不同的噪声源。

    为什么偏差被消除（关键的期望计算）： 设 \(a^{\dagger}=\arg\max_a Q_1(s',a)\)。由于 \(Q_2\) 独立于 \(Q_1\)， 条件在 \(a^{\dagger}\) 上时 \(Q_2(s',a^{\dagger})\) 仍是 \(Q_2(s',\cdot)\) 的无偏估计：

    \[ \mathbb{E}\left[Q_2\left(s',a^{\dagger}\right)\ \Big|\ a^{\dagger}\right] = \mathbb{E}\left[Q_2(s',a)\right]\Big|_{a=a^{\dagger}} = Q^{*}(s',a^{\dagger}) \]

    （第二步用了「\(Q_2\) 关于每个动作都无偏」。） 再对 \(a^{\dagger}\) 取期望，并用 \(\mathbb{E}[Q^{*}(s',a^{\dagger})]=\max_a Q^{*}(s',a)\) （因为真实价值在最优动作处取最大，而噪声已被排除在估值环节之外），即得

    \[ \mathbb{E}\left[Q_2\left(S_{t+1},\ \arg\max_a Q_1(S_{t+1},a)\right)\right] = \max_a Q^{*}(s',a) \]

    无偏。

    对比 Q-learning 错在哪：它用同一套带噪声的 \(Q\) 既选动作又估值，于是

    \[ \mathbb{E}\left[\max_a Q(s',a)\right] > \max_a \mathbb{E}\left[Q(s',a)\right] \]

    「先取最大再取期望」\(\neq\)「先取期望再取最大」—— 这是 Jensen 不等式方向问题，\(\max\) 是凸函数， 故 \(\mathbb{E}[\max]\geq\max[\mathbb{E}]\)。

    (d) 三种算法的对照。

    算法 更新目标 是否 off-policy 最大化偏差
    Q-learning \(r+\gamma\max_a Q(s',a)\) 是 有
    Double Q-learning \(r+\gamma Q_2(s',\arg\max_a Q_1(s',a))\) 是 基本消除
    SARSA \(r+\gamma Q(s',A')\) 否（on-policy） 无（没有 \(\max\)）

    注意 SARSA 天然没有这个偏差——因为它的更新式里不含 \(\max\)， 也就没有「先取最大再取期望」的问题。 这是 on-policy 方法的一个隐性优势。

    在深度强化学习中的对应：DQN 用两个网络 （在线网络选动作、目标网络提供数值）， 其动机与 Double Q-learning 完全一致。 这个「双估计」思想已经成为深度强化学习的标准组件， 广泛应用于 DQN、DDPG、TD3 等算法。

    实践建议：

    场景 是否需要 Double 技巧
    奖励密集、噪声小 可不加
    奖励稀疏、噪声大 强烈建议加
    动作空间大（\(k>10\)） 建议加（偏差随 \(\ln k\) 增长）
    用神经网络近似 建议加（函数逼近本身带来噪声）

    七、用在哪些课程里¶

    无人系统自主决策与优化 · 在线学习与自主决策¶

    • 不需要模型的巨大价值：无人机在未知风场中的悬停控制， 动力学模型往往不准；TD 类方法直接从交互数据学习价值， 绕开了建模环节。这是强化学习能用于真实无人系统的最主要原因。
    • Q-learning 用于离线训练 + 在线查表： 训练阶段用仿真大量试错（off-policy 支持经验回放，样本效率高）， 学到 \(Q^{*}\) 后部署为查找表。 在线决策复杂度 \(O(\lvert A\rvert)\)，满足机载实时性要求。
    • SARSA 用于真机安全训练： 例题 3(b) 的悬崖分析直接适用—— 无人机的「贴边飞行」在仿真中最优， 但探索期间的真实坠机代价不可接受。 用 SARSA 会让智能体主动选择保守策略。
    • 经验回放与 off-policy：把历史 \((s,a,r,s')\) 存入缓冲区反复采样， 样本效率可提升一个数量级。这是 DQN 成功的关键组件之一， 其合法性完全来自 Q-learning 的 off-policy 性质。
    • TD 误差作为「异常检测信号」： \(\delta_t\) 大意味着「实际与预期严重不符」， 可以直接用作故障检测（模型与实际偏离）或 好奇心驱动的探索奖励（新颖状态处 \(\delta\) 大）。

    模式识别 · 序列决策与信用分配¶

    • 信用分配问题是共性：在序列标注中， 误差发生在最后一步，但错误可能来自前面任何一步—— 这与强化学习「奖励稀疏时如何把信用分给早期动作」是同一个问题。 资格迹（5.2 节）就是解决信用分配的机制。

    • TD 误差与预测编码：\(\delta_t=R_{t+1}+\gamma V(S_{t+1})-V(S_t)\) 的结构是「预测–修正」—— 这与卡尔曼滤波的创新项（innovation）、 以及神经网络里的残差学习在形式上是同构的。

      场景 预测 观测 误差信号
      TD 学习 \(V(S_t)\) \(R_{t+1}+\gamma V(S_{t+1})\) \(\delta_t\)
      卡尔曼滤波 \(\hat{x}_{t\lvert t-1}\) \(y_t\) 创新项 \(y_t-H\hat{x}\)
      梯度下降 \(f(x_t)\) 目标值 残差
      预测编码（神经科学） 期望输入 实际输入 预测误差

    这张表说明「用预测误差驱动的增量学习」是一个跨领域的统一范式。 把它作为一条主线，能把模式识别、控制、优化三门课的知识串起来。

    • 时序模式识别中的衰减因子： 资格迹的衰减 \(\gamma\lambda\) 与模式识别里的 「记忆衰减窗口」是同一个设计—— 既要考虑久远的历史，又不能让历史无限累积。\(\lambda\) 就是这个权衡参数。

    机器人学 · 在线学习与安全性¶

    • TD 学习对初始值敏感，实机部署要小心： 例题 1 显示 TD 的更新目标会被初始 \(V\) 污染。 真机上若初始 \(Q\) 表设置不当， 早期动作会基于错误的价值估计执行，可能造成危险。 实践做法：先在有安全约束的仿真里训练到接近收敛，再迁移到真机微调。
    • 资格迹的计算成本：\(E(s)\) 的维度与状态数同阶。 若用神经网络近似，资格迹会变成与参数量同阶的向量， 内存与更新成本大幅上升。 这是 TD(\(\lambda\)) 在深度强化学习中不如在表格方法中流行的实际原因 （GAE 是一种更实用的近似替代）。
    • 收敛判据要用 Robbins–Monro： 学习率若取常数，\(Q\) 值会持续抖动，机械臂的末端执行器会肉眼可见地抖动。 工程上常用「学习率随访问次数衰减」\(\alpha_t=1/(1+n(s,a))\)， 既能满足收敛条件，又能在后期稳定下来。
    • 奖励设计与 TD 的交互：稀疏奖励会让 TD 误差长期为 \(0\)， 梯度信号消失、学习停滞。这是机器人任务中最常见的失败模式， 常用的补救是奖励塑形（上一页的势函数准则） 或课程学习（从简单任务逐步加难）。

    八、自测¶

    Q1 判断对错并说明理由： (a) TD 学习不需要环境模型，因为它用采样代替了期望。 (b) MC 方法是无偏的，所以总是优于 TD。 © SARSA 与 Q-learning 的差别在于前者不能收敛到最优。 (d) \(\lambda=0\) 的 TD(\(\lambda\)) 就是 TD(0)，\(\lambda=1\) 的 TD(\(\lambda\)) 就是 MC。

    提示

    (a) 想清楚「不需要模型」和「不需要马尔可夫性」是两件事。 (b) 无偏 \(\neq\) 方差小。 © 再读一遍 SARSA 的收敛定理。 (d) 注意 \(\lambda=1\) 时的定义要加上末尾那一项 \(\lambda^{T-t-1}G_t\)。

    解答

    (a) 正确，但要补一句。 TD 用单次采样代替了 Bellman 方程里的期望 \(\sum_a\pi\sum_{s'}p\)， 因此确实不需要 \(p(s'\mid s,a)\)。

    但必须补充：TD 仍然需要马尔可夫性成立 （因为它用 \(V(S_{t+1})\) 概括「未来的所有信息」）。 「不需要模型」与「不需要马尔可夫性」是两件独立的事：

    方法 需要模型 需要马尔可夫性
    动态规划 需要 需要
    TD 学习 不需要 需要
    蒙特卡洛 不需要 不需要

    这张表是本页最该记住的对照表。 注意 MC 是唯一两者都不需要的 （代价是必须等回合结束、方差大）。

    (b) 错误。 无偏只说明「平均意义上正确」，不说明方差小。 MC 的 \(G_t\) 是 \(T\) 步随机的和，方差随 \(T\) 线性增长； TD 的目标只含一步随机性，方差小得多。

    在同样的数据量下，TD 通常收敛更快（Sutton & Barto 的随机游走实验 是最经典的证据）。偏差与方差要一起看：

    方法 偏差 方差 综合样本效率
    MC 无偏 高 通常较低
    TD(0) 有偏 低 通常较高

    而且「无偏」在工程上未必是优点： 若 MC 的方差大到单次估计完全不可用， 「无偏但方差巨大」反而不如「有偏但稳定」。 这是统计学里最古老的教训。

    © 错误。 SARSA 也能收敛到最优，条件是 GLIE （策略在极限处趋于贪心 + 每个 \((s,a)\) 被无限次访问）。 只要 \(\varepsilon\to0\)，SARSA 收敛到 \(Q^{*}\)。

    两者的真实差别是「收敛到哪个量」在 \(\varepsilon>0\) 时的表现：

    情形 SARSA 收敛到 Q-learning 收敛到
    \(\varepsilon\) 固定（\(>0\)） \(Q^{\pi_\varepsilon}\)（含探索的价值） \(Q^{*}\)
    \(\varepsilon\to0\)（GLIE） \(Q^{*}\) \(Q^{*}\)

    所以「SARSA 更保守」只在 \(\varepsilon\) 固定时成立。 这也说明：如果最终要让 \(\varepsilon\to0\)， 两种算法都会收敛到最优策略，差别只在训练过程中的风险偏好。

    (d) 正确（用正确的定义）。 但要提醒一个细节：

    \(\lambda=0\)：\((1-0)\cdot1\cdot G_t^{(1)}=G_t^{(1)}\)， 这是 TD(0) 的目标 \(\checkmark\)。

    \(\lambda=1\)：由正确的定义 \(G_t^{\lambda}=(1-\lambda)\sum_{n=1}^{T-t-1}\lambda^{n-1}G_t^{(n)}+\lambda^{T-t-1}G_t\)， 取 \(\lambda=1\) 得 \((1-1)\times(\cdots)+1^{T-t-1}G_t = G_t\)—— 恰好是 MC 的回报 \(\checkmark\)。

    若用错误定义 \(G_t^{\lambda}=(1-\lambda)\sum_{n=1}^{\infty}\lambda^{n-1}G_t^{(n)}\) 在 \(\lambda=1\) 处会出现 \(0\times\infty\) 的不定式， 形式上会得到 \(G_t^{(1)}\) 而误判为 TD(0)。 这个坑必须避开——定义里末尾那一项 \(+\lambda^{T-t-1}G_t\) 不是装饰，是必需的。

    补充：\(0<\lambda<1\) 时权重是 \((1-\lambda)\lambda^{n-1}\)， 几何衰减，越远的未来权重越低。\(\lambda\) 就是「看多远」的第二个旋钮 （第一个是 \(\gamma\)）。

    Q2 环境为 \(3\) 步确定性轨迹 \(S_1\to S_2\to S_3\to T\)（\(T\) 终止）， 奖励 \(1,2,0\)；\(\gamma=0.9\)，初始 \(V=(0,0,0,0)\)。 (a) 写出 \(n=1,2,3\) 的 \(n\) 步回报 \(G_1^{(n)}\)； (b) 用 \(\lambda=0.5\) 计算 \(G_1^{\lambda}\)（用正确的定义）。

    思路

    \(n\) 步回报的前 \(n\) 项是真实奖励，最后一项是 \(\gamma^n V(S_{t+n})\)。 由于初始 \(V\equiv0\)，\(V(S_{t+n})\) 项在前几轮不影响。 \(\lambda\)-回报的定义中，\(n=1,2\) 是普通的 \(n\) 步回报， 最后一项（完整回报）要额外乘 \(\lambda^{T-t-1}\)。

    解答

    (a) \(n\) 步回报。 轨迹为 \(S_1(r=1)\to S_2(r=2)\to S_3(r=0)\to T\)， 回合长度 \(T-t=3\) 步（从 \(S_1\) 到终止共 3 步）。

    \[ G_1^{(1)} = R_2 + \gamma V(S_2) = 1 + 0.9\times0 = 1 \]
    \[ G_1^{(2)} = R_2 + \gamma R_3 + \gamma^2 V(S_3) = 1 + 0.9\times2 + 0 = 1+1.8 = 2.8 \]
    \[ G_1^{(3)} = R_2 + \gamma R_3 + \gamma^2 R_4 + \gamma^3 V(T) = 1 + 0.9\times2 + 0.81\times0 + 0 = 2.8 \]

    注意 \(G_1^{(2)}=G_1^{(3)}=2.8\)——因为第 3 步奖励是 \(0\)， 而初始 \(V\equiv0\)，故第 3 步不带来任何增量。 更完整地说，完整回报 \(G_1 = 1+0.9\times2+0.81\times0 = 2.8\)， 与 \(G_1^{(3)}\) 相同（因为 \(V(T)=0\) 是精确的）。

    (b) \(\lambda\)-回报。 用定义（\(T-t=3\)，故需 \(n=1,2\) 的 \(n\) 步回报， 再加末尾完整回报项，系数为 \(\lambda^{3-1}=\lambda^{2}\)）：

    \[ G_1^{\lambda} = (1-\lambda)\sum_{n=1}^{2}\lambda^{n-1}G_1^{(n)} + \lambda^{2}G_1 \]

    取 \(\lambda=0.5\)，\(G_1=2.8\)：

    \[ G_1^{0.5} = (1-0.5)\left[0.5^{0}\times1 + 0.5^{1}\times2.8\right] + 0.5^{2}\times2.8 \]
    \[ = 0.5\left[1 + 1.4\right] + 0.25\times2.8 \]
    \[ = 0.5\times2.4 + 0.7 = 1.2+0.7 = 1.9 \]

    验算权重和：\((1-\lambda)(1+\lambda)+\lambda^{2} = 0.5\times1.5+0.25 = 0.75+0.25 = 1\ \checkmark\)。

    © 各 \(\lambda\) 的对照。

    \(\lambda\) \(G_1^{\lambda}\) 说明
    \(0\) \(1.000\) 只用 \(G_1^{(1)}\)（TD(0) 目标）
    \(0.5\) \(1.900\) 混合
    \(0.9\) \(2.543\) 接近完整回报
    \(1\) \(2.800\) 完整回报（MC）

    验算 \(\lambda=0\)：\((1-0)[1\times G_1^{(1)}]=1.0\ \checkmark\)。 验算 \(\lambda=1\)：\((1-1)[\cdots]+1^{2}\times2.8 = 2.8\ \checkmark\)。

    单调性：\(G_1^{\lambda}\) 随 \(\lambda\) 从 \(1.0\) 单调升到 \(2.8\)， 因为本例的真实回报（\(2.8\)）大于 TD(0) 目标（\(1.0\)）—— \(\lambda\) 越大越「相信真实回报」。

    (d) 两点工程含义。

    (1) \(\lambda\) 是「信 bootstrap 还是信真实回报」的程度旋钮： \(\lambda\) 小则相信 \(V\) 的估计（低方差、有偏）， \(\lambda\) 大则相信真实回报（无偏、高方差）。

    (2) 本例中 \(G_1^{(2)}=G_1^{(3)}\) 有一个意外好处： 当后续奖励为 \(0\) 且 \(V\) 精确时， 增加 \(n\) 不再带来新信息，因此小幅调整 \(\lambda\) 影响有限。 这提示我们：当环境有大量零奖励时，\(\lambda\) 的调节作用会被削弱—— 此时更值得调整的是 \(\gamma\)。

    Q3 on-policy 与 off-policy 的区别。 (a) 对以下算法判断是 on-policy 还是 off-policy：SARSA、Q-learning、 蒙特卡洛控制（带 \(\varepsilon\)-greedy 行为策略）、 以及「用旧的经验回放数据训练 Deep Q-Network」。 (b) 某轨迹有 3 步，目标策略与行为策略的动作概率比依次为 \(2.0,\ 0.5,\ 1.5\)。求重要性采样权重，并说明为什么它会导致高方差。 © 为什么 Q-learning 不需要重要性采样修正？

    提示

    (a) 判断标准：行为策略与目标策略是否相同。 (b) 权重是各步比值的连乘。 © 回到 Q-learning 的更新式，看它有没有用到行为策略的概率。

    解答

    (a) 判断结果。

    算法 类型 理由
    SARSA on-policy 用实际采到的 \(A_{t+1}\) 更新，评估的就是正在执行的 \(\pi\)
    Q-learning off-policy 用 \(\max_a Q\) 更新，与行为策略无关
    MC 控制（\(\varepsilon\)-greedy） on-policy 评估与执行是同一个 \(\varepsilon\)-greedy 策略
    DQN + 经验回放 off-policy 回放数据来自旧策略，目标是贪心策略

    关于最后一项要特别注意：把 SARSA 改成用经验回放会破坏它的理论基础， 因为回放的数据来自旧策略，而 SARSA 的目标更新用了 「当前策略下会选的动作」——两者不一致就破坏了 on-policy 的前提。 这是实现中一个真实的错误来源。

    (b) 重要性采样权重。

    完整轨迹的权重是各步比值连乘：

    \[ \rho = \frac{\mu(A_0\mid S_0)}{b(A_0\mid S_0)}\cdot\frac{\mu(A_1\mid S_1)}{b(A_1\mid S_1)}\cdot\frac{\mu(A_2\mid S_2)}{b(A_2\mid S_2)} = 2.0\times0.5\times1.5 = 1.5 \]

    如果只看前两步：\(\rho=2.0\times0.5=1.0\)。 如果三步都是 \(1.5\)：\(\rho=1.5^3=3.375\)。

    为什么导致高方差：连乘的期望是 1（可以严格证明）， 但连乘的方差随步数指数增长：

    步数 \(T\) 各步比值都取 \(1.5\) 时的 \(\rho\) 各步都取 \(0.5\) 时的 \(\rho\)
    \(1\) \(1.5\) \(0.5\)
    \(3\) \(3.375\) \(0.125\)
    \(5\) \(7.594\) \(0.03125\)
    \(10\) \(57.665\) \(0.000977\)

    两个方向的极端都很糟糕：\(\rho\) 极大导致估计被单个样本主导， \(\rho\) 极小导致该样本几乎不被使用。 这就是「重要性采样在高维长轨迹上不可用」的根本原因。 即使期望无偏，方差也会让估计毫无实用性—— 这是 (b) 与 Q1(b) 相通的教训。

    © Q-learning 为什么不需要重要性采样。

    看更新式：

    \[ Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\left[R_{t+1}+\gamma\max_a Q(S_{t+1},a)-Q(S_t,A_t)\right] \]

    右端只出现 \(S_t,A_t,R_{t+1},S_{t+1}\) 以及 \(Q\) 表。 特别注意：它完全没有用到 \(A_{t+1}\)，也没有用到行为策略的 \(\pi(A\mid S)\)。

    这意味着什么：更新式本身不含任何「行为策略」的信息， 所以它不需要「修正」，因为压根没有要修正的东西。 \(\max_a Q(S_{t+1},a)\) 无论数据从哪来都朝同一个目标推进。

    严格地说，这个 max 技巧让 Q-learning 的目标是 \(\mathbb{E}\left[R_{t+1}+\gamma\max_a Q(S_{t+1},a)\ \middle|\ S_t=s,A_t=a\right]\)， 这个期望只在 \((s,a)\) 上取，不需要对「行为策略选了什么」取期望—— 所以求期望时没有 \(b(a\mid s)\) 出现，也就无需除以它。

    对比 MC 的 off-policy：MC 用 \(G_t\) 估计 \(V^{\pi}(s)\)， 而 \(G_t\) 的分布依赖行为策略（因为轨迹是行为策略生成的）， 所以必须用 \(\rho=\prod\frac{\pi}{b}\) 把分布「掰回来」。

    一句话总结：

    方法 目标量依赖行为策略吗 需不需 \(\rho\)
    MC off-policy 依赖（整条轨迹的分布） 需要
    Q-learning 不依赖（只看 \((s,a)\) 的即时转移） 不需要
    TD(0) 评估 off-policy 依赖（一步） 需要（一步比值）

    正是「TD 只用一步转移」这一点，让 Q-learning 的 重要性采样退化为「无需修正」—— 这是 Q-learning 成为最实用算法之一的数学根源。

    Q4 本题讨论收敛性条件。 (a) 说明 Robbins–Monro 条件 \(\sum\alpha_t=\infty\)、\(\sum\alpha_t^2<\infty\) 的必要性， 各举一个违反条件的反例。 (b) 验证 \(\alpha_t=1/t\) 满足两个条件（给出 \(\sum 1/t^2\) 的值）。 © 为什么在函数逼近（如神经网络）下通常只用常数学习率？ 这时还能保证收敛到 \(V^{*}\) 吗？

    提示

    (a) 分别想「衰减太快」「衰减太慢（不衰减）」两种情形。 (b) \(\sum_{t=1}^{\infty}1/t^2=\pi^2/6\)。 © 想「用函数逼近时值函数能否精确表示 \(V^{*}\)」这个问题。

    解答

    (a) 两个条件的必要性。

    条件一：\(\sum\alpha_t=\infty\)（衰减得够慢）。

    反例：取 \(\alpha_t=2^{-t}\)，则 \(\sum_{t=1}^{\infty}2^{-t}=1<\infty\)。 此时总的更新步长是有限的。若初始值离真值很远， 学习过程走不了那么远就停了——

    \[ \lvert V_{\infty}-V^{*}\rvert \geq \lvert V_0-V^{*}\rvert\left(1-\alpha_{\text{总}}\right)^{?} \]

    更直观地：设真值 \(V^{*}=10\)、初始 \(V_0=0\)、每步奖励给一个「指向 10」的信号。 若 \(\sum\alpha_t=1\)，则最多只能把 \(V\) 从 \(0\) 移到约 \(10\times1\) 就够了—— 但在有噪声与 bootstrap 的情况下，总步长必须足够大才能消除初始误差。 只要总步长有限，初始误差就一定会留下残留。

    条件二：\(\sum\alpha_t^2<\infty\)（衰减得够快）。

    反例：取 \(\alpha_t=\alpha\)（常数，例如 \(0.1\)）。 此时 \(\sum\alpha_t^2=\sum0.01=\infty\)，条件违反。

    后果：每次更新都引入一次采样噪声，更新量 \(\alpha\delta_t\) 的方差 是 \(\alpha^2\text{Var}(\delta)\)。常数步长意味着噪声永远不衰减， \(V\) 会在真值附近持续抖动，永远不收敛（只能收敛到某个邻域）。

    工程上的表现：机械臂的 \(Q\) 值表持续小幅波动， 末端执行器出现肉眼可见的抖动。这是「学习率不衰减」的直接可见后果。

    条件 违反的后果 典型现象
    \(\sum\alpha_t=\infty\) 衰减太快，走不到位 收敛到远离真值的值
    \(\sum\alpha_t^2<\infty\) 衰减太慢，噪声不消 \(V\) 持续抖动，不收敛

    两个条件的方向是相反的，必须同时满足—— 这就是为什么 \(\alpha_t=1/t\) 这种「缓慢衰减」是唯一合适的形状。

    (b) 验证 \(\alpha_t=1/t\)。

    第一条件（调和级数发散）：

    \[ \sum_{t=1}^{\infty}\frac{1}{t} = \infty \]

    这是经典的调和级数，发散（虽然增长速度极慢， 前 \(10^4\) 项之和只有约 \(9.7876\)）。条件满足 \(\checkmark\)。

    第二条件（巴塞尔问题）：

    \[ \sum_{t=1}^{\infty}\frac{1}{t^2} = \frac{\pi^2}{6} \approx 1.644934 \]

    收敛，条件满足 \(\checkmark\)。

    数值核对（部分和向 \(\pi^2/6\) 收敛）：

    项数 \(n\) \(\sum_{t=1}^{n}1/t\) \(\sum_{t=1}^{n}1/t^2\)
    \(10\) \(2.9290\) \(1.549768\)
    \(100\) \(5.1874\) \(1.634984\)
    \(1000\) \(7.4855\) \(1.643935\)
    \(10000\) \(9.7876\) \(1.644834\)
    \(\infty\) \(\infty\) \(1.644934\)

    注意两个级数的对比：第一列缓慢增长（\(n\) 增大 \(100\) 倍只增加约 \(2.3\)）， 第二列迅速逼近 \(1.6449\)。这正是两个条件所要求的「一慢一快」。

    实践中的常用形式： \(\alpha_t=\dfrac{1}{1+n(s,a)}\)（\(n\) 为该 \((s,a)\) 的访问次数）， 这是 \(1/t\) 的变体，避免 \(t=0\) 时除零，行为上与 \(1/t\) 一致。

    © 函数逼近下为什么用常数学习率。

    核心原因：函数逼近会引入「不可消除的逼近误差」。

    用参数化函数 \(V_{\theta}(s)\)（例如神经网络）近似价值时， 如果 \(V^{*}\) 不在函数族 \(\{V_{\theta}\}\) 中，那么无论 \(\theta\) 怎么调， 都无法精确表示 \(V^{*}\)。 此时让 \(\alpha_t\to0\) 会让算法停在这个不精确的表示上——

    \[ \lim_{t\to\infty}V_{\theta_t} = V_{\theta^{\text{proj}}}(\text{投影解}) \neq V^{*} \]

    这里 \(V_{\theta^{\text{proj}}}\) 是 \(V^{*}\) 在函数族上的投影。 严格的收敛定理（Robbins–Monro 型）在这种情形下失去了意义， 因为它保证的是「收敛到某个点」，而这个点本身就有系统偏差。

    所以深度强化学习改用常数学习率，目标从 「收敛到精确最优」改为「在最优解附近保持稳定」：

    学习率 理论保证 实践效果
    衰减型（\(1/t\)） 表格式下有收敛保证 函数逼近下会过早停滞
    常数型 只保证在邻域内 持续探索、适应非平稳性

    常数学习率还带来一个额外好处：它能适应非平稳环境 （比如对手策略在变、目标分布在变）。 衰减学习率会「锁死」，无法跟踪变化。

    但也引入两个新问题：

    问题 表现 常见对策
    持续抖动 性能曲线不平稳 学习率调度、目标网络
    可能发散 \(Q\) 值爆炸（「致命三要素」） 目标网络、经验回放、梯度裁剪

    「致命三要素（deadly triad）」 是这里必须提的一个结论： 函数逼近 + bootstrapping + off-policy 三者同时出现时，收敛性没有保证， 可能发散。 三者的组合正是 DQN 的配置， 所以 DQN 必须靠目标网络（target network）冻结目标值、 经验回放等工程手段来稳定训练。

    本页的结论汇总：

    情形 收敛保证 收敛到哪
    表格 + on-policy（SARSA） 有（Robbins–Monro + GLIE） \(Q^{*}\)
    表格 + off-policy（Q-learning） 有（充分探索） \(Q^{*}\)
    函数逼近 + on-policy 有（带逼近误差） 投影解附近
    函数逼近 + off-policy（致命三要素） 无 可能发散

    最后一行是深度强化学习所有稳定化技巧（目标网络、双估计、 经验回放、梯度裁剪、信任域）的存在理由—— 它们不是在优化性能，而是在补救一个失效的理论。
