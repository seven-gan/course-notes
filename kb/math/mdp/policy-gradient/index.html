    策略梯度¶

    前面几页的强化学习方法都基于价值函数：先学 \(Q\) 或 \(V\)，再据此选动作。 这一页走另一条路：

    直接对策略参数求梯度，用梯度上升改进策略。

    这就是策略梯度。它比价值方法更适合连续动作与随机策略。

    两条技术路线的对比（这是理解本页的框架）

    方面 价值方法（Q-learning 等） 策略梯度
    学什么 \(Q(s,a)\) 或 \(V(s)\) 直接学 \(\pi_\theta(a\mid s)\)
    怎么选动作 \(\arg\max_a Q(s,a)\) 从 \(\pi_\theta\) 采样
    连续动作 困难（要搜索/近似优化）✗ 自然支持 ✓
    随机策略 间接（如 \(\varepsilon\)-贪心） 直接参数化 ✓
    收敛性 可能震荡（\(\arg\max\) 不连续） 梯度上升，平滑 ✓
    样本效率 通常更高 通常更低
    方差 —— 高（本页核心难题）✗

    两个最关键的优势：

    优势 为什么
    连续动作空间 不需要在连续空间上做 \(\arg\max\) ✓
    随机策略 可以直接参数化概率分布 ✓

    本页的主线：如何求梯度 → 如何降低方差 → Actor-Critic 与 PPO。

    一、目标函数与策略梯度定理¶

    目标函数¶

    策略用参数化分布表示（如 softmax、高斯）：

    \[ \pi_\theta(a\mid s) \]

    目标：最大化期望回报

    \[ J(\theta) = E_{\tau\sim\pi_\theta}[R(\tau)] \]

    其中 \(\tau = (s_0,a_0,s_1,a_1,\dots)\) 是一条轨迹， \(R(\tau)\) 是它的累积回报。

    梯度上升：

    \[ \theta\leftarrow\theta+\alpha\nabla_\theta J(\theta) \]

    策略梯度定理¶

    问题：\(J\) 的期望依赖 \(\theta\)（因为轨迹分布依赖 \(\theta\)）， 而轨迹是离散采样的 —— 怎么求导？

    关键技巧：对数导数技巧（log-derivative trick）

    「对数导数技巧」的完整推导（这是本页的数学核心）

    恒等式：

    \[ \nabla_\theta p_\theta(\tau) = p_\theta(\tau)\nabla_\theta\log p_\theta(\tau) \]

    验证：由 \(\nabla\log f = \frac{\nabla f}{f}\) 得

    \[ p_\theta(\tau)\nabla_\theta\log p_\theta(\tau) = p_\theta(\tau)\cdot\frac{\nabla_\theta p_\theta(\tau)}{p_\theta(\tau)} = \nabla_\theta p_\theta(\tau) \;\checkmark \]

    作用：把「对概率求导」变成「对对数求导再乘概率」 —— 这样就能写成期望形式，从而用采样估计 ✓

    代入目标函数：

    \[ \nabla_\theta J = \nabla_\theta\sum_\tau p_\theta(\tau)R(\tau) = \sum_\tau\nabla_\theta p_\theta(\tau)R(\tau) \]

    用恒等式：

    \[ = \sum_\tau p_\theta(\tau)\nabla_\theta\log p_\theta(\tau)R(\tau) = E_{\tau}\big[R(\tau)\nabla_\theta\log p_\theta(\tau)\big] \]

    这就是：

    \[ \boxed{\ \nabla_\theta J = E_{\tau\sim\pi_\theta}\Big[R(\tau)\sum_{t}\nabla_\theta\log\pi_\theta(a_t\mid s_t)\Big]\ } \]

    两个关键点：

    点 说明
    期望可以用采样估计 跑若干条轨迹求平均 ✓
    不需要知道环境模型 梯度里没有转移概率 ✓

    第二点极其重要：这就是「无模型」（model-free）的来源 ✓

    进一步的化简：可以证明（利用马尔可夫性） 只有动作之后的回报才影响该动作的梯度：

    \[ \nabla_\theta J = E\Big[\sum_t\nabla_\theta\log\pi_\theta(a_t\mid s_t)\cdot G_t\Big] \]

    其中 \(G_t\) 是从 \(t\) 开始的折扣累积回报：

    \[ G_t = \sum_{k=0}^{T-t-1}\gamma^k r_{t+k} \]

    为什么可以只用 \(G_t\)：

    原因 说明
    因果关系 过去的动作不能影响过去的奖励 ✓
    马尔可夫性 给定当前状态后，未来与更早的历史条件独立

    这个化简既正确又降低方差 ✓

    二、REINFORCE 算法¶

    把梯度定理写成算法：

    \[ \nabla_\theta J\approx\frac1N\sum_{i=1}^{N}\sum_t\nabla_\theta\log\pi_\theta(a_{i,t}\mid s_{i,t})G_{i,t} \]

    算法流程：

    步骤 操作
    1 用当前 \(\pi_\theta\) 跑 \(N\) 条完整轨迹
    2 算每条轨迹的 \(G_t\)
    3 算梯度估计
    4 梯度上升更新 \(\theta\)
    5 重复

    REINFORCE 的核心问题：方差极高

    为什么方差高：

    原因 说明
    \(G_t\) 本身是随机变量 轨迹随机 → 回报波动大
    只用一条轨迹估计期望 采样噪声大
    奖励的尺度 若奖励 \(100\) 量级，梯度也大

    后果：

    后果 说明
    收敛极慢 需要海量采样 ✗
    学习率难调 太大学不收敛
    不同任务的梯度尺度差异大 不能通用

    这就是「策略梯度样本效率低」的根源 ✓

    本页后续内容全部围绕「降低方差」展开：

    手段 效果
    基线（baseline）减方差 最基础、最有效 ✓
    优势函数 \(A_t\) 比 \(G_t\) 更准
    资格迹 / GAE 偏差-方差折中
    Actor-Critic 用 \(V\) 估计基线
    PPO 的裁剪 限制更新幅度

    三、基线与优势函数（降方差的核心）¶

    为什么可以减去基线¶

    关键结论：对任何只依赖状态 \(s_t\) 的函数 \(b(s_t)\)：

    \[ E\big[\nabla_\theta\log\pi_\theta(a_t\mid s_t)\cdot b(s_t)\big] = 0 \]

    所以减去它不改变期望，但能降低方差 ✓

    「减去基线不改变期望」的证明（很短，值得看）

    关键：\(b(s_t)\) 只依赖 \(s_t\)，而动作 \(a_t\) 由 \(\pi_\theta\) 采样。

    计算期望（对 \(a_t\) 求期望，\(s_t\) 固定）：

    \[ E_{a_t\sim\pi_\theta}\big[\nabla_\theta\log\pi_\theta(a_t\mid s_t)b(s_t)\big] = b(s_t)\sum_{a}\pi_\theta(a\mid s_t)\frac{\nabla_\theta\pi_\theta(a\mid s_t)}{\pi_\theta(a\mid s_t)} \]

    （用了 \(\nabla\log\pi = \frac{\nabla\pi}{\pi}\)。）

    化简：

    \[ = b(s_t)\sum_a\nabla_\theta\pi_\theta(a\mid s_t) = b(s_t)\nabla_\theta\underbrace{\sum_a\pi_\theta(a\mid s_t)}_{=1} = b(s_t)\nabla_\theta 1 = 0 \;\checkmark \]

    关键一步：概率之和恒为 1，其梯度为零 ✓

    这说明：减去基线是「免费的降方差手段」 —— 期望不变，方差变小 ✓

    最优基线的直观选择：\(b(s_t)\approx E[G_t\mid s_t] = V^{\pi}(s_t)\) —— 即「该状态下预期的回报」。

    为什么它最优（直观）：

    情形 \(G_t-b(s_t)\) 该动作的梯度贡献
    回报高于平均 正 增强该动作 ✓
    回报低于平均 负 削弱该动作 ✓

    这正是我们想要的信号：比平均好就加强，比平均差就削弱 ✓

    优势函数¶

    定义：

    \[ A^{\pi}(s,a) = Q^{\pi}(s,a)-V^{\pi}(s) \]

    含义：在状态 \(s\) 下，选动作 \(a\) 比「平均水平」好多少 ✓

    用优势替换 \(G_t\)：

    \[ \nabla_\theta J = E\big[\nabla_\theta\log\pi_\theta(a_t\mid s_t)\cdot A^{\pi}(s_t,a_t)\big] \]

    为什么优势比 \(G_t\) 好：

    量 含义 方差
    \(G_t\) 实际回报 含「状态本身的难度」→ 高 ✗
    \(A_t = G_t-V(s_t)\) 相对优势 去掉了状态难度 → 低 ✓

    具体例子说明：

    情形 \(G_t\) \(V(s_t)\) \(A_t\)
    简单状态下拿 \(10\) 分（平均也是 \(10\)） \(10\) \(10\) \(0\)（无优劣）
    困难状态下拿 \(5\) 分（平均是 \(2\)） \(5\) \(2\) \(+3\)（很好）✓
    简单状态下拿 \(8\) 分（平均是 \(10\)） \(8\) \(10\) \(-2\)（较差）✗

    用 \(G_t\) 会怎么错：

    • 「困难状态拿 5 分」和「简单状态拿 5 分」的 \(G_t\) 相同， 但前者是很棒的决策，后者是很差的决策 ✗

    用优势函数就能区分 ✓

    四、Actor-Critic¶

    核心思想：用 critic 估计 \(V(s)\) 作为基线，减少方差。

    \[ A_t\approx r_t+\gamma V_\phi(s_{t+1})-V_\phi(s_t) \]

    为什么这个形式好用：

    优势 说明
    只需一步 不需要等整条轨迹结束 ✓
    用 \(V_\phi\) 引导 用估计的「未来」代替真实未来
    偏差-方差折中 有偏但方差小

    两个网络的分工：

    网络 角色 目标
    Actor \(\pi_\theta\) 决策 最大化 \(J\)
    Critic \(V_\phi\) 评估 最小化 \(\delta_t^2\)（TD 误差平方）

    这与「价值方法」的关系：

    Actor-Critic 是两者的结合 —— 用价值方法（critic）来降低策略梯度的方差 ✓

    「TD 误差」的多重身份（一个重要洞察）

    \[ \delta_t = r_t+\gamma V_\phi(s_{t+1})-V_\phi(s_t) \]

    它可以有三种解读：

    身份 说明
    优势的估计 \(A_t\approx\delta_t\) ✓
    TD 误差 critic 的预测误差 ✓
    更新的「意外程度」 实际比预期好多少

    三种解读都指向同一件事：

    \[ \delta_t = \underbrace{\text{实际得到的}}_{\text{现在}+\\text{折现的未来}} - \underbrace{\text{预期的}}_{\text{critic 的估计}} \]

    所以「advantage ≈ TD 误差」是自然的 —— 两者都在度量「比预期好多少」。

    这也解释了「为什么 Actor-Critic 比 REINFORCE 方差小」：

    方法 基线的来源 方差
    REINFORCE 无（或用 \(G_t\) 的均值） 高 ✗
    Actor-Critic \(V_\phi(s_t)\)（学习得到） 低 ✓

    代价：引入偏差（因为 \(V_\phi\) 是估计的，不完美）✗

    这就是「偏差-方差权衡」在强化学习中的体现 ✓

    GAE：偏差-方差的连续调节¶

    问题：用一步 TD（偏差大）还是用完整 \(G_t\)（方差大）？

    GAE（广义优势估计）：

    \[ A^{\text{GAE}(\gamma,\lambda)}_t = \sum_{l=0}^{\infty}(\gamma\lambda)^l\delta_{t+l} \]
    \(\lambda\) 行为 偏差 方差
    \(\lambda = 0\) 只用一步 TD 大 小 ✓
    \(\lambda = 1\) 退化为 \(G_t-V(s_t)\) 小 ✓ 大
    \(0<\lambda<1\) 折中（通常 \(0.95\)）✓ 中 中

    这就是「用 \(\lambda\) 平滑地调节偏差-方差」 ✓

    与资格迹的关系：

    \[ \text{GAE 是「优势函数的资格迹形式」} \]

    两者都在做「多步信息的指数加权」。

    PPO：限制更新幅度¶

    问题：策略梯度更新可能步长过大 → 策略突然变差 → 训练崩溃 ✗

    PPO 的解决：限制新策略与旧策略的比率：

    \[ r_t(\theta) = \frac{\pi_\theta(a_t\mid s_t)}{\pi_{\theta_{\text{old}}}(a_t\mid s_t)} \]

    裁剪目标：

    \[ L^{\text{CLIP}} = E\Big[\min\big(r_t(\theta)A_t,\ \operatorname{clip}(r_t(\theta),1-\epsilon,1+\epsilon)A_t\big)\Big] \]

    含义（关键）：

    情形 处理
    更新让好动作的概率增大（\(A_t>0\)，\(r>1\)） 只允许到 \(1+\epsilon\) ✗
    更新让坏动作的概率减小（\(A_t<0\)，\(r<1\)） 只允许到 \(1-\epsilon\) ✗
    更新在范围内 正常梯度 ✓

    「取 min」的作用：确保裁剪总是「悲观」的 —— 即使用户想更新更多，目标函数也不会奖励它 ✓

    为什么 PPO 变得非常流行：

    优点 说明
    简单 比 TRPO 简单得多（无需二阶优化）✓
    有效 在实践中表现稳定
    可复用数据 同一批数据可以更新多次（重要！）

    「可复用数据」的含义：

    方法 每批数据的利用
    朴素策略梯度 用一次就丢 ✗
    PPO 多次更新（因为裁剪限制了分布偏移）✓

    这是 PPO 样本效率较高的关键原因之一 ✓

    五、典型例题¶

    例题 1：验证基线不改变期望¶

    设两动作问题，状态固定，\(\pi_\theta(a_1) = p\)、\(\pi_\theta(a_2) = 1-p\)。 验证 \(E[\nabla_\theta\log\pi\cdot b] = 0\)（\(b\) 为常数）。

    思路

    直接算求和，注意 \(p+(1-p) = 1\)。

    解答

    第一步：写出对数梯度

    记 \(\theta\) 是 \(\log\frac{p}{1-p}\) 形式的参数。用更直接的方式： 设策略由 \(p\) 参数化（\(\theta\) 通过 \(p\) 依赖它）。

    \[ \log\pi(a_1) = \log p,\qquad \log\pi(a_2) = \log(1-p) \]

    第二步：对 \(p\) 求导

    \[ \frac{\partial}{\partial p}\log p = \frac1p,\qquad \frac{\partial}{\partial p}\log(1-p) = \frac{-1}{1-p} \]

    第三步：算加权和

    \[ E\left[\frac{\partial}{\partial p}\log\pi\cdot b\right] = b\left[p\cdot\frac1p+(1-p)\cdot\frac{-1}{1-p}\right] \]
    \[ = b\,[1-1] = 0 \;\checkmark \]

    结果：期望恰为零 ✓

    关键步骤：\(p\cdot\frac1p = 1\) 与 \((1-p)\cdot\frac{-1}{1-p} = -1\) 恰好抵消 —— 这正是「概率之和为 1」的体现 ✓

    更一般的形式（用 \(\theta\) 而非 \(p\)）：

    \[ \sum_a\pi_\theta(a)\nabla_\theta\log\pi_\theta(a) = \nabla_\theta\sum_a\pi_\theta(a) = \nabla_\theta 1 = 0 \]

    「概率之和恒为 1，其梯度为零」 ✓

    这个「零期望」的两个重要推论

    推论 1：基线是免费的降方差工具

    \[ E[\nabla\log\pi\cdot(G_t-b(s_t))] = E[\nabla\log\pi\cdot G_t]-0 \]

    期望不变，但方差可以显著降低 ✓

    推论 2：可以「加」任意与动作无关的量

    这不只是「减法」——加上任何 \(b(s_t)\) 也允许 ✓

    工程含义：

    做法的自由度 说明
    基线可以任意选 只要不依赖动作
    可以选使方差最小的 即 \(V(s_t)\) ✓
    可以用任何估计器 神经网络、蒙特卡洛均值、手工设计

    这也解释了「为什么可以用 critic 估计的 \(V_\phi\) 作基线」 —— 即使 \(V_\phi\) 不准确，期望仍是无偏的 ✓ （不准确只影响方差降低的效果，不影响正确性。）

    这是 Actor-Critic 理论上的「安全网」 —— critic 学得不好，actor 仍然不会系统性地学错 ✓

    例题 2：优势函数比 \(G_t\) 更好的数值例子¶

    两个状态，各有两动作。数据如下：

    状态 动作 \(G_t\)（实际回报） \(V(s)\)
    \(s_1\)（简单） \(a_1\) \(10\) \(10\)
    \(s_1\)（简单） \(a_2\) \(9\) \(10\)
    \(s_2\)（困难） \(a_1\) \(5\) \(2\)
    \(s_2\)（困难） \(a_2\) \(1\) \(2\)

    用 \(G_t\) 与用 \(A_t\) 分别会怎样更新？

    思路

    比较两个「都拿 5 分」但状态难度不同的情形。

    解答

    第一步：算优势

    状态 动作 \(G_t\) \(V(s)\) \(A_t = G_t-V\)
    \(s_1\) \(a_1\) \(10\) \(10\) \(0\)
    \(s_1\) \(a_2\) \(9\) \(10\) \(-1\)
    \(s_2\) \(a_1\) \(5\) \(2\) \(+3\)
    \(s_2\) \(a_2\) \(1\) \(2\) \(-1\)

    第二步：用 \(G_t\) 的更新信号

    情形 梯度权重 \(G_t\) 效果
    \(s_1,a_1\)（回报 \(10\)） \(+10\) 强增强
    \(s_2,a_1\)（回报 \(5\)） \(+5\) 增强（弱）
    \(s_1,a_2\)（回报 \(9\)） \(+9\) 也增强 ✗

    问题 1：\(s_1,a_2\) 明明比 \(a_1\) 差（\(9<10\)），但 \(G_t=9>0\) 仍然增强了它 ✗

    问题 2：\(s_2,a_1\) 是很好的决策（\(5\) 远高于平均 \(2\)）， 但权重 \(5\) 小于 \(s_1,a_1\) 的 \(10\) —— 强化学习会「更偏好简单的状态」而非「更好的决策」 ✗

    第三步：用 \(A_t\) 的更新信号

    情形 \(A_t\) 效果
    \(s_1,a_1\)（=平均） \(0\) 不更新（既不好也不坏）✓
    \(s_1,a_2\)（低于平均） \(-1\) 削弱 ✓
    \(s_2,a_1\)（远高于平均） \(+3\) 强增强 ✓
    \(s_2,a_2\)（低于平均） \(-1\) 削弱 ✓

    完美区分了「好坏」 ✓

    这个例子说明了「优势函数为什么必要」

    核心区别：

    量 度量什么
    \(G_t\) 绝对回报（混入了「状态本身有多容易」）
    \(A_t\) 相对优势（纯化了「这个决策有多好」）✓

    用 \(G_t\) 的两个具体问题：

    问题 后果
    好决策在易状态下的 \(G_t\) 可能更大 学错优先级 ✗
    差决策在易状态下 \(G_t\) 仍为正 错误地增强 ✗

    用 \(A_t\) 的好处：

    好处 说明
    只关注决策质量 与状态难度解耦 ✓
    方差更小 去掉了「状态难度」这个大变动源 ✓
    学习更稳 信号更干净

    这也解释了「为什么 Actor-Critic 效果好」 —— 它提供了一个学习得到的基线 \(V_\phi\)， 从而得到接近优势函数的信号 ✓

    工程含义（奖励设计）：

    做法 问题
    只用绝对回报作为奖励 学习信号被「状态难度」干扰
    做奖励归一化 / 用优势 信号更纯粹 ✓
    奖励尺度不当（如全是 \(1000\) 量级） 梯度爆炸 ✗

    例题 3：GAE 的 \(\lambda\) 取值¶

    某轨迹的 TD 误差为 \(\delta_0 = 1.0\)、\(\delta_1 = 0.5\)、\(\delta_2 = 0.2\)， \(\gamma = 0.9\)。求 \(\lambda = 0\)、\(0.95\)、\(1\) 时的 \(A_0^{\text{GAE}}\)。

    思路

    \(A_0 = \sum_l(\gamma\lambda)^l\delta_l\)。

    解答

    第一步：\(\lambda = 0\)

    \[ A_0 = (\gamma\cdot0)^0\delta_0 = \delta_0 = 1.0 \]

    结果：\(A_0 = 1.0\)（只用第一步）

    第二步：\(\lambda = 0.95\)

    权重系数 \(\gamma\lambda = 0.9\times0.95 = 0.855\)。

    \(l\) 系数 \((0.855)^l\) \(\delta_l\) 贡献
    \(0\) \(1.000\) \(1.0\) \(1.000\)
    \(1\) \(0.855\) \(0.5\) \(0.4275\)
    \(2\) \(0.731\) \(0.2\) \(0.1462\)
    和 \(1.5737\)

    结果：\(A_0\approx1.574\)

    第三步：\(\lambda = 1\)

    系数 \(\gamma\lambda = 0.9\)：

    \(l\) 系数 \((0.9)^l\) \(\delta_l\) 贡献
    \(0\) \(1.000\) \(1.0\) \(1.000\)
    \(1\) \(0.900\) \(0.5\) \(0.450\)
    \(2\) \(0.810\) \(0.2\) \(0.162\)
    和 \(1.612\)

    结果：\(A_0\approx1.612\)

    汇总对比：

    \(\lambda\) \(A_0\) 特点
    \(0\) \(1.000\) 偏差大、方差小
    \(0.95\) \(1.574\) 常用折中 ✓
    \(1\) \(1.612\) 偏差小、方差大

    从这个计算看 的作用

    观察：

    \(\lambda\) 用到的 \(\delta\) 个数（有效）
    \(0\) \(1\) 个
    \(0.95\) 约 \(1/(1-0.855)\approx7\) 个
    \(1\) 约 \(1/(1-0.9) = 10\) 个

    「有效视野」的公式：

    \[ \text{有效步数}\approx\frac{1}{1-\gamma\lambda} \]

    验证：

    \(\gamma\lambda\) 有效步数
    \(0\) \(1\)
    \(0.855\) \(6.9\)
    \(0.9\) \(10\)
    \(0.99\) \(100\)

    这解释了「为什么 \(\lambda\) 越小方差越小」：

    用的 \(\delta\) 越少 → 累积的随机性越少 → 方差越小 ✓

    工程建议：

    场景 \(\lambda\)
    快速实验 \(0.95\)（通用默认值）✓
    长程依赖任务 \(0.99\)
    短程/信号强 \(0\)–\(0.9\)
    理论分析 \(1\)（无偏）

    一个重要提醒：\(\lambda\) 与 \(\gamma\) 是耦合的 —— 关键是乘积 \(\gamma\lambda\)。

    所以若 \(\gamma = 0.99\)，则 \(\lambda = 0.95\) 给的有效步数：

    \[ \frac{1}{1-0.99\times0.95} = \frac{1}{1-0.9405} = 16.8 \]

    比 \(\gamma=0.9\) 时的 \(6.9\) 长得多 ✓

    所以调参时要看「\(\gamma\lambda\)」而非单独看 \(\lambda\) ✓

    例题 4：PPO 裁剪的实际效果¶

    设 \(\epsilon = 0.2\)、\(A_t = 1.0\)（好动作）。 分别计算 \(r_t = 0.5\)、\(1.0\)、\(1.5\)、\(3.0\) 时的 PPO 目标值。

    思路

    \(L = \min(rA,\ \operatorname{clip}(r,1-\epsilon,1+\epsilon)A)\)。

    解答

    参数：\(\epsilon = 0.2\)，所以裁剪区间是 \([0.8,\ 1.2]\)。

    逐个计算（\(A = 1.0>0\)）：

    情形 1：\(r = 0.5\)

    \[ \operatorname{clip}(0.5,\ 0.8,\ 1.2) = 0.8 \]
    \[ \min(0.5\times1,\ 0.8\times1) = \min(0.5,\ 0.8) = 0.5 \]

    情形 2：\(r = 1.0\)（未变）

    \[ \operatorname{clip}(1.0) = 1.0 \]
    \[ \min(1.0,\ 1.0) = 1.0 \]

    情形 3：\(r = 1.5\)

    \[ \operatorname{clip}(1.5,\ 0.8,\ 1.2) = 1.2 \]
    \[ \min(1.5,\ 1.2) = 1.2 \;\checkmark \]

    被裁剪限制了 ✓（否则会是 \(1.5\)，鼓励过大的更新。）

    情形 4：\(r = 3.0\)

    \[ \operatorname{clip}(3.0) = 1.2 \]
    \[ \min(3.0,\ 1.2) = 1.2 \;\checkmark \]

    完全被限制住 ✓

    汇总表：

    \(r_t\) \(\operatorname{clip}\) \(\min\) 是否被裁剪
    \(0.5\) \(0.8\) \(0.5\) 否（min 取了 \(rA\)）
    \(1.0\) \(1.0\) \(1.0\) 否
    \(1.5\) \(1.2\) \(1.2\) 是 ✓
    \(3.0\) \(1.2\) \(1.2\) 是 ✓

    「取 min」的巧妙之处（这是 PPO 的核心设计）

    关键观察：对 \(r>1.2\) 的情形，目标值恒为 \(1.2\)（不再增长） ✓

    含义：进一步增大 \(r\) 不会增加目标函数 → 梯度为零 → 不会鼓励「走得更远」 ✓

    为什么用 \(\min\) 而不用 \(\operatorname{clip}\) 单独：

    考虑 \(A<0\)（坏动作）的情形：

    目的 想要的
    减小坏动作的概率 \(r\) 应该变小（\(r<1\)）✓

    若只用 clip：当 \(r<0.8\) 时，\(\operatorname{clip}(r) = 0.8\)， 则目标是 \(0.8\times A\)（\(A<0\) → 负值较小）—— 这会阻止 \(r\) 继续减小 ✓ 正确。

    但若 \(r\) 变得很大（\(r>1.2\)，即坏动作概率反而增加了）：

    计算 值（\(A = -1\)）
    \(rA\) \(1.5\times(-1) = -1.5\)
    \(\operatorname{clip}(r)A\) \(1.2\times(-1) = -1.2\)
    \(\min\) \(-1.5\) ✓

    取 min 得到 \(-1.5\) —— 保留了「惩罚」 ✓

    若只用 clip 会得到 \(-1.2\) —— 削弱了惩罚 ✗

    所以「取 min」保证了「总是采取悲观（保守）的估计」 ✓

    「悲观」的含义：

    情形 悲观选择
    好动作（\(A>0\)）被过度增强 取较小的目标（限制收益）✓
    坏动作（\(A<0\)）被过度增强 取更负的目标（保留惩罚） ✓

    两种情形都「不鼓励偏离旧策略太远」 ✓

    这就是「信赖域」思想的可实现形式：

    方法 实现方式
    TRPO 硬约束 KL 散度（需二阶优化）✗
    PPO 裁剪比率（一阶，简单） ✓

    PPO 的成功很大程度来自这个「简单而有效」的设计 ✓

    """

    • 四旋翼姿态控制、机械臂轨迹跟踪都用连续动作空间的策略梯度
    • PPO 是机器人强化学习最常用的基线算法
    • 从仿真到实物（sim-to-real）：策略梯度的随机策略天然支持域随机化 ✓
    • 多智能体：MAPPO 等算法是 PPO 的多智能体扩展

    模式识别 · 序列决策与生成¶

    • 序列生成（文本、语音）可视为 MDP，用策略梯度优化不可微指标
    • RLHF（人类反馈强化学习）用 PPO 微调大模型
    • 不可微指标的优化：BLEU、WER 等无法反向传播， 用策略梯度的「对数导数技巧」可以得到无偏梯度 ✓
    • 注意力/路由的随机性：Gumbel-Softmax 等与策略梯度同源

    机器人学 · 运动与操作¶

    • 连续动作是机器人控制的常态 → 策略梯度比 DQN 更自然 ✓
    • 模仿学习 + 策略梯度（GAIL）：用对抗方式学策略
    • PPO / SAC 是机械臂抓取、足式机器人行走的主流算法
    • 安全约束：用约束策略梯度（CPO）保证不违反安全条件

    七、自测¶

    Q1 为什么策略梯度可以直接处理连续动作空间，而 Q-learning 不行？

    提示

    想想 Q-learning 需要做什么运算。

    解答

    因为 Q-learning 需要 \(\arg\max_a Q(s,a)\)，而策略梯度不需要。

    Q-learning 的困难：

    \[ \pi(s) = \arg\max_a Q(s,a) \]
    动作空间 求 \(\arg\max\) 的难度
    离散、小 枚举，可行 ✓
    连续 需要解一个优化问题 ✗
    高维（如 \(7\) 自由度机械臂的力矩） 每步都要优化，代价极高 ✗

    策略梯度的做法：

    直接输出一个分布（如高斯）：

    \[ \pi_\theta(a\mid s) = N\big(\mu_\theta(s),\ \sigma_\theta^2(s)\big) \]

    选动作就是采样：

    \[ a\sim N\big(\mu_\theta(s),\ \sigma_\theta^2(s)\big) \]

    完全不需要 \(\arg\max\) ✓

    对比总结：

    方面 Q-learning 策略梯度
    选动作 \(\arg\max\)（需搜索）✗ 采样（\(O(1)\)）✓
    连续动作 困难 自然支持 ✓
    动作维度 维数灾难（枚举） 不敏感 ✓
    随机性 需外部加（\(\varepsilon\)-贪心） 内建 ✓

    额外好处：动作维度增加时，策略梯度的难度增长平缓 —— 因为网络输出的维度增加是线性的，不需要指数级的枚举 ✓

    代价：策略梯度样本效率更低（需要更多交互）✗ —— 这就是「连续控制常用 PPO/SAC 而非 DQN」的原因。

    Q2 证明：减去只依赖状态 \(s_t\) 的基线 \(b(s_t)\) 不改变策略梯度的期望。

    提示

    对 \(a_t\) 求期望，利用「概率之和为 1」。

    解答

    要证的命题：

    \[ E\big[\nabla_\theta\log\pi_\theta(a_t\mid s_t)\cdot b(s_t)\big] = 0 \]

    第一步：写出期望形式

    固定 \(s_t\)，对 \(a_t\) 求期望（\(a_t\sim\pi_\theta\)）：

    \[ = \sum_a\pi_\theta(a\mid s_t)\cdot\nabla_\theta\log\pi_\theta(a\mid s_t)\cdot b(s_t) \]

    第二步：用对数导数的逆恒等式

    \[ \pi_\theta(a\mid s_t)\nabla_\theta\log\pi_\theta(a\mid s_t) = \nabla_\theta\pi_\theta(a\mid s_t) \]

    代入：

    \[ = b(s_t)\sum_a\nabla_\theta\pi_\theta(a\mid s_t) \]

    第三步：交换求和与求导

    \[ = b(s_t)\nabla_\theta\sum_a\pi_\theta(a\mid s_t) = b(s_t)\nabla_\theta(1) = 0 \;\checkmark \]

    证明完成 ✓

    关键一步的含义：

    \[ \sum_a\pi_\theta(a\mid s_t) = 1 \quad\text{对任意 }\theta\text{ 都成立} \]

    所以它的梯度恒为零 ✓ （「常数函数的梯度为零」。）

    推论：可以自由选择基线 ✓

    若要用 \(b(s_t)\)，则梯度估计变为：

    \[ \nabla_\theta J\approx\frac1N\sum_i\sum_t\nabla_\theta\log\pi_\theta(a_{i,t}\mid s_{i,t})\big(G_{i,t}-b(s_{i,t})\big) \]

    期望无偏、方差更小 ✓

    工程含义（很重要）：

    含义 说明
    critic 估计不准也无害 期望仍无偏 ✓
    只影响方差降低的效果 不影响正确性
    所以 Actor-Critic 是「安全」的 有理论保证 ✓

    这也是「Actor-Critic 中的 critic 可以很粗糙」的原因 —— 它只是一个「降方差工具」，不参与决定学习目标 ✓

    Q3 某任务奖励量级为 \(1000\)。直接用策略梯度会有什么问题？如何处理？

    提示

    梯度尺度与奖励尺度成正比。

    解答

    问题：梯度尺度过大

    \[ \nabla_\theta J = E\big[\nabla_\theta\log\pi\cdot G_t\big] \]

    \(G_t\) 是 \(1000\) 量级 → 梯度也是 \(1000\) 量级 ✗

    具体后果：

    后果 说明
    学习率必须极小 \(10^{-6}\) 量级，敏感难调 ✗
    更新步长剧烈波动 不同轨迹的 \(G_t\) 差异大
    可能数值溢出 累积梯度可能很大
    不同任务不能共用超参 奖励尺度一变就要重调 ✗

    对比：若奖励是 \(1\) 量级

    奖励尺度 合适的学习率
    \(1\) \(10^{-3}\)
    \(1000\) \(10^{-6}\)（小 1000 倍）✗

    两种处理方式：

    方式 1：奖励缩放（reward scaling）

    把奖励除以一个尺度因子（如 \(1000\)）：

    \[ r' = \frac{r}{1000} \]

    注意「不改变问题的最优解」： 因为乘正常数不改变 \(\arg\max\) ✓

    方式 2：优势归一化（推荐）

    对每个 batch 的优势做标准化：

    \[ \hat A_t = \frac{A_t-\overline{A}}{\operatorname{std}(A)} \]

    好处：

    好处 说明
    自动适应不同尺度 无需人工设常数 ✓
    与基线减方差协同 双重降方差
    通用于不同任务 超参可复用 ✓

    注意优势归一化不改变期望（在 batch 内近似）—— 这与「减去基线」的论证类似：标准化的平移部分期望为零 ✓

    工程实践要点：

    做法 说明
    奖励缩放 + 优势归一化 两者都可做 ✓
    检查梯度范数 若 \(>10\) 应裁剪
    梯度裁剪 限制 \(\lVert g\rVert\leq c\)（如 \(0.5\)）
    学习率与奖励尺度解耦 归一化后学习率可通用

    梯度裁剪的公式：

    \[ g\leftarrow g\cdot\min\left(1,\ \frac{c}{\lVert g\rVert}\right) \]

    这是实现中的标准做法 ✓

    Q4 PPO 的裁剪为什么用 \(\min\) 而不是只对 \(r\) 做 clip？

    提示

    分别考虑 \(A>0\) 与 \(A<0\)，看 \(r\) 很大时两种做法有什么不同。

    解答

    因为「取 min」保证对两种符号的优势都采取「悲观」估计， 而只用 clip 会在 \(A<0\) 时削弱惩罚。

    情形 1：\(A>0\)（好动作），\(r\) 很大（如 \(r=3\)）

    计算 值
    \(rA\) \(3A\)
    \(\operatorname{clip}(r)A\) \(1.2A\)
    \(\min\) \(1.2A\) ✓

    两种做法结果相同 —— 都限制在 \(1.2A\) ✓

    情形 2：\(A<0\)（坏动作），\(r\) 很大（如 \(r=3\)，即坏动作概率反而增大了）

    设 \(A = -1\)：

    计算 值
    \(rA\) \(3\times(-1) = -3\)
    \(\operatorname{clip}(r)A\) \(1.2\times(-1) = -1.2\)
    \(\min\) \(-3\) ✓

    差别出现了：

    做法 目标值 效果
    只用 clip \(-1.2\) 惩罚被削弱 ✗
    \(\min\) \(-3\) 保留完整惩罚 ✓

    为什么「保留惩罚」是对的：

    我们要最大化目标。\(-3 < -1.2\)， 所以 \(\min\) 取了更负的值 → 目标更小 → 优化会避开它 ✓

    含义：「坏动作概率增大」这件事必须被惩罚 —— 而 \(\min\) 保住了这个惩罚 ✓

    总结「取 min」在两个方向上的行为：

    情形 \(\min\) 的作用
    好动作被增强太多 限制收益上限（防止过度乐观）✓
    坏动作被增强（\(A<0\), \(r>1\)） 保留惩罚（防止漏罚）✓
    好动作被削弱（\(A>0\), \(r<1\)） 取 \(rA\)（不额外惩罚）✓

    「悲观」的统一含义：

    \[ L^{\text{CLIP}}\leq \text{（未裁剪的目标）} \]

    即「目标函数总是取较小的那个」 —— 绝不会因为裁剪而「奖励」偏离旧策略的行为 ✓

    这就是 PPO「信赖域」性质的实现机制 —— 它用「取 min」代替了 TRPO 的硬约束 ✓
