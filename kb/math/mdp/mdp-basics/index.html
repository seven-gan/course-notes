    马尔可夫决策过程基础¶

    上一页的马尔可夫链只有一个「被动」的主角：状态自己会跳。这一页给它加上「动作」—— 于是从「描述世界怎么变」升级成「决定世界怎么变」。这就是马尔可夫决策过程（MDP）。

    多出来的那个东西叫动作 \(a\)：转移概率从 \(p(s'\mid s)\) 变成 \(p(s'\mid s,a)\)， 而动作由我们自己挑。一旦有了「挑选」，就必然有「好坏」之分， 于是需要一个新的数学对象来量化「某个状态有多好」——价值函数。

    这一页要解决的问题是：把「长期收益最大化」这个模糊目标， 翻译成一个自洽的、可求解的方程组。这个方程组就是 Bellman 方程， 它是后面动态规划、时序差分、策略梯度的共同地基。

    一句话抓住核心

    MDP 的全部内容是五个量、两个函数、一个方程：

    记号 名称 谁来定 角色
    \(S\) 状态集合 建模者设计 「现在的处境」
    \(A\) 动作集合 建模者设计 「能做的事」
    \(p(s'\mid s,a)\) 转移概率 环境 「做了会怎样」
    \(r(s,a)\) 即时奖励 建模者设计 「做得好不好」
    \(\gamma\) 折扣因子 建模者设计 「眼光有多远」
    \(V^{\pi}(s)\) 状态价值 由上面五项算出 在 \(s\) 处按 \(\pi\) 走有多好
    \(Q^{\pi}(s,a)\) 动作价值 由上面五项算出 在 \(s\) 处先做 \(a\) 再按 \(\pi\) 走有多好

    两个 Bellman 期望方程（策略 \(\pi\) 固定）：

    \[ V^{\pi}(s) = \sum_{a}\pi(a\mid s)\sum_{s'}p(s'\mid s,a)\left[r(s,a)+\gamma V^{\pi}(s')\right] \]
    \[ Q^{\pi}(s,a) = r(s,a) + \gamma\sum_{s'}p(s'\mid s,a)\sum_{a'}\pi(a'\mid s')Q^{\pi}(s',a') \]

    一个 Bellman 最优方程（把期望换成取最大）：

    \[ V^{*}(s) = \max_{a}\left[r(s,a) + \gamma\sum_{s'}p(s'\mid s,a)V^{*}(s')\right] \]

    记住最核心的一句：Bellman 方程不是「定义」，而是自洽性条件—— 它说「现在的价值 = 眼前奖励 + 打折后的未来价值」。

    一、MDP 的五个要素与折扣回报¶

    1.1 形式定义¶

    马尔可夫决策过程是一个五元组 \((S,\ A,\ p,\ r,\ \gamma)\)：

    要素 数学形式 典型工程取值方式
    状态空间 \(S\) 可数集合或连续空间 位置网格、关节角离散化、特征向量
    动作空间 \(A(s)\) 可数集合或连续空间 上/下/左/右、力矩、连续控制量
    转移核 \(p(s'\mid s,a)\) \(S\times A\times S\to[0,1]\) 由动力学模型或经验统计得到
    奖励函数 \(r(s,a)\) \(S\times A\to\mathbb{R}\) 人工设计，最影响成败的一步
    折扣因子 \(\gamma\) \([0,1)\) 常取 \(0.9\)、\(0.99\)、\(0.999\)

    转移核满足行随机，与马尔可夫链完全一致：

    \[ p(s'\mid s,a)\geq 0, \qquad \sum_{s'\in S}p(s'\mid s,a) = 1 \quad \text{对一切} \ s,a \]

    奖励函数只依赖 (s,a) 是不是限制太强

    标准形式是 \(r(s,a)\)，但工程中常见的写法还有 \(r(s,a,s')\)、 甚至 \(r(s,a,s',a')\)。它们都能化归成 \(r(s,a)\)，方法是取条件期望：

    \[ r(s,a) := \sum_{s'} p(s'\mid s,a)\, r(s,a,s') \]

    这一步之所以成立，是因为在给定 \((s,a)\) 之后，\(s'\) 的分布已知。 后续所有公式里的 \(r(s,a)\) 都默认采用这个期望化定义， 因此不必为不同教材的记号差异烦恼。

    1.2 马尔可夫性在 MDP 中的形式¶

    \[ P(S_{t+1}=s' \mid S_t=s,\ A_t=a,\ \text{历史}) = p(s'\mid s,a) \]

    与马尔可夫链的唯一区别：条件里多了当前时刻的动作 \(A_t\)。 一旦把动作看作「由策略决定的外部输入」，MDP 就退化为一条 非时齐（由策略决定）的马尔可夫链——这就是上一页与本页的接口：

    \[ \text{给定策略} \ \pi, \quad P^{\pi}_{ss'} := \sum_{a}\pi(a\mid s)\,p(s'\mid s,a) \ \Longrightarrow\ \text{一条普通马尔可夫链} \]

    这条式子是整个模块最重要的「翻译」： 固定策略后，MDP 就是马尔可夫链，上一页讲的全部结论（平稳分布、收敛速度、谱隙） 原封不动地适用于评估这个策略。后面的策略评估算法正是靠这一点成立的。

    1.3 折扣回报¶

    从时刻 \(t\) 出发，之后收到的奖励序列为 \(R_{t+1},R_{t+2},R_{t+3},\dots\) （注意下标习惯：在 \(t\) 执行 \(A_t\) 后收到 \(R_{t+1}\)）。定义折扣回报

    \[ G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty}\gamma^{k}R_{t+k+1} \]

    相邻两步回报之间有一个漂亮的递推关系，这是全模块反复使用的核心恒等式：

    \[ G_t = R_{t+1} + \gamma\left(R_{t+2}+\gamma R_{t+3}+\cdots\right) = R_{t+1} + \gamma G_{t+1} \]

    把这个式子记牢：Bellman 方程就是它在期望意义下的版本。 所谓「动态规划」，本质就是对这条递推关系做迭代。

    1.4 为什么必须折扣¶

    折扣因子 \(\gamma\) 有三重作用，缺一不可：

    (1) 保证无穷级数收敛。 若奖励有界 \(\lvert R\rvert\leq R_{\max}\)，则

    \[ \lvert G_t\rvert \leq \sum_{k=0}^{\infty}\gamma^{k}R_{\max} = \frac{R_{\max}}{1-\gamma} < \infty \]

    这个界是后续所有收敛性证明的基础，务必记住这个形式 \(R_{\max}/(1-\gamma)\)。

    (2) 体现「延迟的不确定性」。 同样的奖励，越晚拿到越不可靠 （系统可能故障、模型可能失效）。折扣是不确定性的代理。

    (3) 作为数学工具（本征参数）。 取 \(\gamma<1\)，则 \(\gamma\) 同时充当压缩映射的压缩系数—— Bellman 算子是 \(\gamma\)-压缩的，这是压缩映射原理能用的前提。 若 \(\gamma=1\)，收敛性需要额外假设，算法稳定性大幅下降。

    折扣因子的工程含义：它决定「眼光有多远」

    有效视野长度可以取为 \(\dfrac{1}{1-\gamma}\)：

    \(\gamma\) 有效视野 \(1/(1-\gamma)\) \(\gamma^{k}\) 衰减到 \(1/e\) 的 \(k\) 典型用途
    \(0.5\) \(2\) 步 \(1.4\) 只看眼前（贪心）
    \(0.9\) \(10\) 步 \(9.5\) 短程任务、机械臂抓取
    \(0.99\) \(100\) 步 \(99.5\) 标准强化学习默认值
    \(0.999\) \(1000\) 步 \(995\) 长程任务、导航
    \(1\) \(\infty\) — 回合制任务，需额外假设

    判断依据：\(\gamma^{k}\) 就是「第 \(k\) 步奖励的现值相对权重」。 取 \(\gamma=0.9\) 时 \(0.9^{10}=0.3487\)，即第 10 步的奖励只值第 1 步的三成半； 取 \(\gamma=0.99\) 时 \(0.99^{10}=0.9044\)，差别不大。

    一个具体的取值方法：设你希望「第 \(k\) 步之后的奖励基本可以忽略」， 就解 \(\gamma^{k} \approx 0.1\)，得 \(\gamma \approx 0.1^{1/k}\)。 例如任务长度 \(k=100\) 步，则 \(\gamma\approx0.977\)， 工程上取 \(0.98\) 或 \(0.99\) 即可。

    \(\gamma\) 第 1 步现值 第 5 步现值 第 10 步现值 第 25 步现值
    \(0.50\) \(50.00\) \(3.13\) \(0.10\) \(0.00\)
    \(0.90\) \(90.00\) \(59.05\) \(34.87\) \(7.18\)
    \(0.99\) \(99.00\) \(95.10\) \(90.44\) \(77.78\)

    （表内为「第 \(k\) 步收到 100 分奖励」折算到当下的价值 \(100\gamma^{k}\)。）

    要点：\(\gamma=0.5\) 时第 10 步的 100 分只值 0.10 分，几乎等于放弃； \(\gamma=0.99\) 时还值 90.44 分。调 \(\gamma\) 就是在调「机器的耐心」。

    关于「平均奖励」准则

    还有一类 MDP 用平均奖励准则（\(\lim_{N\to\infty}\frac{1}{N}\mathbb{E}[\sum R_t]\)）替代折扣。 它适合「长期在线运行、没有终止」的场景（如排队系统、持续导航）， 但数学工具完全不同（需要对马尔可夫链的平稳分布求期望）， 本模块统一采用折扣准则。看到别人论文里的公式时务必先确认是哪种准则。

    二、策略与值函数¶

    2.1 策略¶

    策略 \(\pi\) 是从状态到动作的决策规则。

    随机策略（stochastic）：

    \[ \pi(a\mid s) = P(A_t = a \mid S_t = s), \qquad \sum_{a\in A(s)}\pi(a\mid s) = 1 \]

    确定性策略（deterministic）：\(a = \mu(s)\)。

    两者的关系：确定性策略是随机策略的退化情形—— 把全部概率质量放在一个动作上即可，即 \(\pi(a\mid s)=\mathbf{1}\{a=\mu(s)\}\)。 因此后面讨论最优性时，只需在随机策略集合上取最大，这更省事。

    时齐性假设：本模块只考虑与时间无关的策略 \(\pi(a\mid s)\) （不写成 \(\pi(a\mid s,t)\)）。理由：MDP 本身时齐， 可以证明最优策略也可以取时齐的。这个假设让值函数只需以 \(s\) 为自变量，是全模块简化的关键。

    2.2 状态价值函数¶

    给定策略 \(\pi\)，状态价值函数定义为从状态 \(s\) 出发、此后一直按 \(\pi\) 行动的期望折扣回报：

    \[ V^{\pi}(s) := \mathbb{E}_{\pi}\left[G_t \mid S_t = s\right] = \mathbb{E}_{\pi}\left[\sum_{k=0}^{\infty}\gamma^{k}R_{t+k+1}\ \Big|\ S_t=s\right] \]

    这个定义里的三个要素必须分清：

    要素 含义 关键点
    「从 \(s\) 出发」 条件 \(S_t=s\) 自变量是状态，不是时间步
    「按 \(\pi\) 行动」 期望下标 \(\pi\) 期望同时对动作与状态转移取
    「此后一直」 无穷求和 不是只看一步，是全部未来

    时齐性带来的好处：定义中的 \(t\) 已经完全消失。 正是这一点，让 \(V^{\pi}\) 成为一个只依赖 \(s\) 的函数， 从而可以写成自洽方程——如果 \(V\) 还依赖 \(t\)，就无法迭代求解。

    2.3 动作价值函数¶

    \[ Q^{\pi}(s,a) := \mathbb{E}_{\pi}\left[G_t \mid S_t=s,\ A_t=a\right] \]

    与 \(V^{\pi}\) 的唯一区别：第一个动作被钉死为 \(a\)，之后的动作才按 \(\pi\) 走。

    这个区别带来了巨大的实用价值：

    • \(V^{\pi}(s)\) 只告诉你「在 \(s\) 处按 \(\pi\) 走有多好」，不能告诉你换一个动作会怎样；
    • \(Q^{\pi}(s,a)\) 明确按动作分列，可以直接比较不同动作的优劣—— 这正是「策略改进」和「Q-learning」能工作的原因。

    2.4 \(V\) 与 \(Q\) 的互相换算¶

    由全概率公式（对第一个动作取条件期望）立得：

    \[ V^{\pi}(s) = \sum_{a\in A(s)}\pi(a\mid s)\,Q^{\pi}(s,a) \]

    反过来，把第一个动作固定后，回报为「即时奖励 + 打折后的后续」：

    \[ Q^{\pi}(s,a) = r(s,a) + \gamma\sum_{s'}p(s'\mid s,a)\,V^{\pi}(s') \]

    对照这两个式子：

    关系式 方向 直观说法
    \(V^{\pi}(s)=\sum_a \pi(a\lvert s)Q^{\pi}(s,a)\) \(Q\to V\) 在 \(s\) 处按策略平均
    \(Q^{\pi}(s,a)=r(s,a)+\gamma\sum_{s'}p(s'\lvert s,a)V^{\pi}(s')\) \(V\to Q\) 先拿走即时奖励再贴现未来

    把第一个式子代入第二个的对称形式，立即得到 \(V\) 的 Bellman 期望方程——这正是下一节的内容。

    三、Bellman 方程：自动求和的技巧¶

    Bellman 方程的全部技巧，就是把「无穷维的求和」压缩成「一个方程」。

    这些方程被称为 Bellman 方程，即通过一个递归式来刻画无穷多个未来回报之和。 它的价值在于：把「无穷求和」的计算问题，变成了「解方程组」的代数问题。

    3.1 策略下的 Bellman 期望方程¶

    由 \(G_t = R_{t+1}+\gamma G_{t+1}\) 两边取期望 \(\mathbb{E}_{\pi}[\cdot\mid S_t=s]\)：

    \[ V^{\pi}(s) = \sum_{a}\pi(a\mid s)\sum_{s'}p(s'\mid s,a)\left[r(s,a)+\gamma V^{\pi}(s')\right] \]

    同理，对 \(Q\)：

    \[ Q^{\pi}(s,a) = r(s,a) + \gamma\sum_{s'}p(s'\mid s,a)\sum_{a'}\pi(a'\mid s')Q^{\pi}(s',a') \]

    推导只需三步，值得完整走一遍：

    第一步：拆出即时奖励。

    \[ V^{\pi}(s) = \mathbb{E}_{\pi}\left[R_{t+1}+\gamma G_{t+1}\mid S_t=s\right] = \mathbb{E}_{\pi}[R_{t+1}\mid S_t=s] + \gamma\,\mathbb{E}_{\pi}[G_{t+1}\mid S_t=s] \]

    第二步：算第一项。 由 \(A_t\sim\pi(\cdot\mid s)\)、\(S_{t+1}\sim p(\cdot\mid s,a)\)：

    \[ \mathbb{E}_{\pi}[R_{t+1}\mid S_t=s] = \sum_{a}\pi(a\mid s)\sum_{s'}p(s'\mid s,a)\,r(s,a) \]

    第三步：把第二项用 \(V^{\pi}\) 表示——这一步是全推导的灵魂。

    \[ \mathbb{E}_{\pi}[G_{t+1}\mid S_t=s] = \sum_{a}\pi(a\mid s)\sum_{s'}p(s'\mid s,a)\,\mathbb{E}_{\pi}[G_{t+1}\mid S_{t+1}=s'] \]

    而由时齐性，\(\mathbb{E}_{\pi}[G_{t+1}\mid S_{t+1}=s'] = V^{\pi}(s')\)—— 下标 \(t+1\) 被消掉了！这就是时齐假设的全部价值。

    把三步合起来，即得方程。\(\blacksquare\)

    注意 \(V^{\pi}\) 同时出现在等式两边——所以这不是「算出 \(V\)」的显式公式， 而是「\(V\) 必须满足的条件」。求解它需要解线性方程组（下一节）或迭代（下一页）。

    3.2 矩阵形式：\(V\) 到底怎么解¶

    对有限状态 MDP，把所有 \(V^{\pi}(s)\) 排成列向量 \(\boldsymbol{v}\in\mathbb{R}^{\lvert S\rvert}\)。 对上式两边同时加上 \(r^{\pi}(s)-\sum_{s'}P^{\pi}_{ss'}V^{\pi}(s)\)，重新整理：

    \[ V^{\pi}(s) - \gamma\sum_{s'}P^{\pi}_{ss'}V^{\pi}(s') = r^{\pi}(s) \]

    其中

    \[ r^{\pi}(s) := \sum_{a}\pi(a\mid s)\,r(s,a), \qquad P^{\pi}_{ss'} := \sum_{a}\pi(a\mid s)\,p(s'\mid s,a) \]

    写成矩阵形式：

    \[ \left(I - \gamma P^{\pi}\right)\boldsymbol{v}^{\pi} = \boldsymbol{r}^{\pi} \quad\Longrightarrow\quad \boxed{\ \boldsymbol{v}^{\pi} = \left(I-\gamma P^{\pi}\right)^{-1}\boldsymbol{r}^{\pi}\ } \]

    这个闭式解非常重要，它一次给出了三件事：

    1. 存在唯一性：\(I-\gamma P^{\pi}\) 一定可逆（因为 \(P^{\pi}\) 是随机矩阵， 谱半径 \(\leq1\)，而 \(\gamma<1\)，故 \(\gamma P^{\pi}\) 的特征值模严格小于 1）。
    2. 与平稳分布的联系：这正是上一页马尔可夫链在一阶矩上的推广 （把「平稳分布」换成「折扣期望」）。
    3. 算法的基础：迭代法 \(\boldsymbol{v}_{k+1}=\boldsymbol{r}^{\pi}+\gamma P^{\pi}\boldsymbol{v}_{k}\) 收敛到 \(\boldsymbol{v}^{\pi}\)，收敛速率由 \(\gamma\) 决定——这就是策略评估。

    Neumann 级数展开给出另一个视角，物理意义一目了然：

    \[ \left(I-\gamma P^{\pi}\right)^{-1} = \sum_{k=0}^{\infty}\gamma^{k}\left(P^{\pi}\right)^{k} \quad\Longrightarrow\quad \boldsymbol{v}^{\pi} = \sum_{k=0}^{\infty}\gamma^{k}\left(P^{\pi}\right)^{k}\boldsymbol{r}^{\pi} \]

    逐项解释：\(\left(P^{\pi}\right)^{k}\boldsymbol{r}^{\pi}\) 是「第 \(k\) 步的期望奖励」， \(\gamma^{k}\) 是它的折扣——这与 \(G_t\) 的定义逐字对应。 所以矩阵求逆公式只是「无穷折扣求和」的代数包装。

    收敛速度就是折扣因子

    上一页我们算出「误差按 \(\lvert\lambda_2\rvert^n\) 衰减」。 在 MDP 里，迭代算子 \(\boldsymbol{v}\mapsto\boldsymbol{r}^{\pi}+\gamma P^{\pi}\boldsymbol{v}\) 的误差衰减率是 \(\gamma\)（因为 \(P^{\pi}\) 是随机矩阵，\(\lVert P^{\pi}\rVert_{\infty}=1\)）。

    所以：\(\gamma\) 既控制「眼光多远」，又控制「收敛多快」，一个参数两个作用。

    \(\gamma\) 误差减半步数 \(\log 0.5/\log\gamma\) 达到 \(10^{-6}\) 精度步数
    \(0.5\) \(1.00\) \(20\)
    \(0.9\) \(6.58\) \(132\)
    \(0.99\) \(69.0\) \(1379\)
    \(0.999\) \(692.8\) \(13811\)

    这是强化学习里最重要的算力权衡： 想让智能体「看得很远」，就必须接受「算得很慢」。

    3.3 Bellman 最优方程¶

    定义最优状态价值函数

    \[ V^{*}(s) := \max_{\pi}V^{\pi}(s), \qquad Q^{*}(s,a) := \max_{\pi}Q^{\pi}(s,a) \]

    \(V^{*}\) 满足 Bellman 最优方程（注意「期望」变成「取最大」）：

    \[ V^{*}(s) = \max_{a\in A(s)}\left[r(s,a) + \gamma\sum_{s'}p(s'\mid s,a)\,V^{*}(s')\right] = \max_{a}Q^{*}(s,a) \]

    以及 \(Q^{*}\) 的版本：

    \[ Q^{*}(s,a) = r(s,a) + \gamma\sum_{s'}p(s'\mid s,a)\max_{a'}Q^{*}(s',a') \]

    最优方程与期望方程的三处差别，务必分清：

    对比项 Bellman 期望方程 Bellman 最优方程
    对动作的处理 按 \(\pi(a\lvert s)\) 加权平均 直接取 \(\max_a\)
    \(V\) 与 \(Q\) 的关系 \(V^{\pi}=\sum_a\pi(a\lvert s)Q^{\pi}\) \(V^{*}=\max_a Q^{*}\)
    方程类型 线性方程 非线性方程（含 max）
    求解方法 矩阵求逆 / 迭代 值迭代 / 策略迭代 / Q-learning
    是否有闭式解 有：\((I-\gamma P^{\pi})^{-1}r^{\pi}\) 一般没有，只能迭代

    「非线性」这一条是分水岭：期望方程是线性的，所以能一步解出； 最优方程因为有 \(\max\)，一般没有闭式解，只能用迭代法—— 这就是下一页动态规划的全部内容。

    3.4 关于最优性的两个重要提醒¶

    提醒一：\(V^{*}(s)=\max_{\pi}V^{\pi}(s)\) 是「逐状态」取最大， 但保证存在一个策略同时对所有状态取到最大。

    不能想当然地认为「每个状态各挑一个最优策略」能拼成一个合法策略—— 好在有一个定理（4.1 节）保证确实存在统一的 \(\pi^{*}\)。

    提醒二：在状态 \(s\) 处最优的动作，不需要事先知道 \(V^{*}\) 以外的信息。

    \[ \pi^{*}(s) = \arg\max_{a}Q^{*}(s,a) \]

    如果 \(Q^{*}\) 已知，MDP 就彻底解决了——剩下的只是查表。 这条式子把「求策略」化归为「求 \(Q^{*}\)」， 而 \(Q^{*}\) 满足一个自洽方程，这就是所有强化学习算法的出发点： 它们都在用不同的方式估计 \(Q^{*}\)。

    四、最优性的结构¶

    4.1 最优策略的存在性¶

    定理：对有限 MDP（\(S,A\) 有限、\(\lvert r\rvert\) 有界、\(\gamma<1\)）， 存在确定性、时齐的最优策略 \(\pi^{*}\)，使得对一切 \(s\in S\)、一切 \(\pi\)，

    \[ V^{\pi^{*}}(s) \geq V^{\pi}(s) \]

    证明思路（三步）：

    (1) 有界性。 由 1.4 节，\(\lvert V^{\pi}(s)\rvert\leq R_{\max}/(1-\gamma)\)， 故 \(V^{*}(s)=\sup_{\pi}V^{\pi}(s)\) 有限。

    (2) 取极限完成。 取一列策略 \(\pi_n\) 使 \(V^{\pi_n}(s)\uparrow V^{*}(s)\)。 由于确定性策略只有 \(\lvert A\rvert^{\lvert S\rvert}\) 个（有限）， 必存在某个 \(\pi^{*}\) 被无穷多次取到，从而 \(V^{\pi^{*}}=V^{*}\)。

    (3) 存在性推广到所有状态。 用 4.2 节的策略改进论证， 说明这个逐状态的极限策略可以统一。

    有限性在这里是本质的：状态与动作有限 \(\Rightarrow\) 策略空间有限 \(\Rightarrow\) 上确界可达。 对连续动作空间，\(\arg\max\) 未必存在（可能需要 \(\sup\) 而非 \(\max\)）， 这是连续控制问题的技术难点之一。

    4.2 确定性与随机：随机策略到底有没有用¶

    由 4.1，最优策略总可以取确定性的。但这不等于随机策略没有意义。 必须把两种情形分开：

    情形 是否需要随机策略 原因
    单个 MDP、完全可观测、\(S,A\) 有限 不需要 存在确定性最优策略
    部分可观测（POMDP） 需要 状态不确定，随机化可提升期望收益
    博弈 / 多智能体 需要 确定性策略会被对手针对
    策略梯度方法 主动使用 随机策略保证可微、保证探索
    函数逼近下的局部最优 常用 随机性帮助逃离鞍点

    结论：「最优策略可以确定」是数学事实，「随机策略在实践中仍然必要」是工程事实。 本模块后面讲策略梯度时，随机性是必备条件—— 因为 \(\nabla_{\theta}\pi_{\theta}(a\mid s)\) 只有在 \(\pi\) 关于 \(\theta\) 光滑时才存在， 而确定性策略的 \(\arg\max\) 不可微。

    4.3 折扣因子 \(\gamma\) 的四重身份¶

    把前面散落的结论集中起来，\(\gamma\) 在 MDP 中有四个完全不同的角色：

    身份 具体形式 影响
    目标参数 \(G_t\) 里的权重 眼光多远、多重视未来
    压缩系数 算子 \(\mathcal{T}\) 的 Lipschitz 常数 值迭代/策略评估的收敛速率
    误差放大上限 \(\lVert V\rVert\leq R_{\max}/(1-\gamma)\) 数值范围与精度要求
    有效样本需求 视野 \(\approx 1/(1-\gamma)\) 需要多长的轨迹才能「看全」

    最后一行是实践中最痛的：\(\gamma=0.99\) 时有效视野 100 步， 意味着要准确估计 \(V(s)\)，样本轨迹必须长到能覆盖这 100 步的所有分支。 若轨迹太短，估计出的 \(V\) 系统性偏低（截断了远处的奖励）， 这个偏差在实践中比方差更危险，因为它不会随样本增多而消失。

    调参经验：能从任务本身推出一个自然的 \(\gamma\) 就用它—— 例如「30 步内必须到达目标」，则取 \(\gamma\) 使 \(\gamma^{30}\approx0.1\)， 即 \(\gamma\approx0.926\)，取 \(0.93\)。不要盲目用默认的 \(0.99\)。

    4.4 四个核心对象的完整对照¶

    本页到此已经把四个核心对象都介绍完了。把它们排在一张表里， 是避免混淆的最有效办法——尤其是 \(Q^{\pi}\) 与 \(Q^{*}\) 的区别， 在实践中出错最多。

    对象 定义 满足的方程 由谁决定 主要用途
    \(V^{\pi}(s)\) 按 \(\pi\) 走的期望回报 \(V^{\pi}(s)=\sum_a\pi(a\lvert s)\left[r(s,a)+\gamma\sum_{s'}pV^{\pi}(s')\right]\) 策略 \(\pi\) 评估一个给定策略
    \(Q^{\pi}(s,a)\) 先做 \(a\) 再按 \(\pi\) 走 \(Q^{\pi}(s,a)=r(s,a)+\gamma\sum_{s'}p\sum_{a'}\pi Q^{\pi}\) 策略 \(\pi\) 比较动作，做策略改进
    \(V^{*}(s)\) 最优期望回报 \(V^{*}(s)=\max_a\left[r(s,a)+\gamma\sum_{s'}pV^{*}(s')\right]\) 无（最优） 反映任务天花板
    \(Q^{*}(s,a)\) 最优动作价值 \(Q^{*}(s,a)=r(s,a)+\gamma\sum_{s'}p\max_{a'}Q^{*}(s',a')\) 无（最优） 直接给出最优策略

    四条互相换算的关系式（全部由定义直接推出，值得背下来）：

    \[ Q^{\pi}(s,a) = r(s,a) + \gamma\sum_{s'}p(s'\mid s,a)\,V^{\pi}(s') \]
    \[ V^{\pi}(s) = \sum_{a}\pi(a\mid s)\,Q^{\pi}(s,a) \]
    \[ V^{*}(s) = \max_{a}Q^{*}(s,a) \]
    \[ \pi^{*}(s) = \arg\max_{a}Q^{*}(s,a) \]

    一个反复出现的判断技巧：

    问题 该看哪个对象 理由
    「这个策略好不好」 \(V^{\pi}\) 评估只需要标量比较
    「在 \(s\) 处换个动作会更好吗」 \(Q^{\pi}\) \(V^{\pi}\) 不含动作维度，答不了
    「这个任务最好能到多少」 \(V^{*}\) 上界参考值
    「现在该做什么」 \(Q^{*}\) 直接 \(\arg\max\) 即可

    注意 \(Q^{\pi}(s,\pi(s)) = V^{\pi}(s)\) 与 \(Q^{*}(s,\pi^{*}(s))=V^{*}(s)\)： 策略在状态 \(s\) 处实际选择的那个动作对应的 \(Q\) 值，恰好等于 \(V\)。 这是检验 \(V\) 与 \(Q\) 是否算对的一条快速自检准则。

    4.5 奖励设计：势函数准则¶

    奖励设计是 MDP 建模中唯一没有标准答案的环节，但有一个严格有用的准则。 问题是：为了加速学习，我们想加入「引导性奖励」 （例如「离目标越近给得越多」），但加错了会把最优策略改掉。

    势函数准则（potential-based shaping）：把奖励改为

    \[ r'(s,a,s') = r(s,a,s') + \gamma\Phi(s') - \Phi(s) \]

    其中 \(\Phi:S\to\mathbb{R}\) 是任意势函数。则新 MDP 的最优策略集合与原 MDP 完全相同。

    为什么成立（关键一步）：先算有限 \(T\) 步内加进来的奖励的折扣和：

    \[ \sum_{k=0}^{T-1}\gamma^{k}\left[\gamma\Phi(s_{k+1})-\Phi(s_k)\right] = \sum_{k=0}^{T-1}\gamma^{k+1}\Phi(s_{k+1}) - \sum_{k=0}^{T-1}\gamma^{k}\Phi(s_k) \]

    把第一个和的下标平移（令 \(j=k+1\)，则 \(j\) 从 \(1\) 到 \(T\)）：

    \[ = \sum_{j=1}^{T}\gamma^{j}\Phi(s_j) - \sum_{k=0}^{T-1}\gamma^{k}\Phi(s_k) \]

    两个和里 \(j=1,\dots,T-1\) 的项逐项相同，全部相消，只剩首尾两项：

    \[ = \gamma^{T}\Phi(s_T) - \Phi(s_0) \]

    令 \(T\to\infty\)。由 \(\gamma<1\) 且 \(\Phi\) 有界（\(S\) 有限），\(\gamma^{T}\Phi(s_T)\to0\)，故

    \[ \sum_{k=0}^{\infty}\gamma^{k}\left[\gamma\Phi(s_{k+1})-\Phi(s_k)\right] = -\Phi(s_0) \]

    这就是全部论证：加进来的奖励总量恰为 \(-\Phi(s_0)\)， 只依赖初始状态，与策略无关。 于是

    \[ G'(\text{轨迹}) = G(\text{轨迹}) - \Phi(s_0) \]

    任意两条从同一 \(s_0\) 出发的轨迹，好坏排序完全不变，故最优策略集合不变 \(\blacksquare\)。

    注意这个「错位相减」的技巧本身：它和 3.2 节 \(\left(I-\gamma P^{\pi}\right)^{-1}=\sum_k\gamma^k\left(P^{\pi}\right)^k\) 是同一个套路的两种外观—— 折扣求和的核心操作永远是「平移下标后相消」。把这个技巧练熟， 后面讲资格迹（TD(\(\lambda\))）时会再次用到，而且形式完全一样。

    这个准则的实用价值：想加引导奖励时，不要直接写「离目标越近加分」， 而要写成差分形式 \(\gamma\Phi(s')-\Phi(s)\)，取 \(\Phi(s)=-\text{dist}(s,\text{目标})\)。 这样既加速了学习，又保证学出的最优行为没有被篡改。

    反例：若直接写 \(r'=r+\Phi(s')\)（缺少 \(-\Phi(s)\) 项）， 则总奖励变成 \(\sum\gamma^k\Phi(s_{k+1})\)，这个和依赖策略， 很可能让智能体「绕圈刷分」——这就是奖励黑客（reward hacking）的数学根源。

    五、典型例题¶

    例题 1：两状态 MDP 的最优值函数¶

    考虑两状态 MDP，\(S=\{s_1,s_2\}\)，\(A=\{a,b\}\)，\(\gamma=0.5\)，转移与奖励为

    状态 动作 下一状态 即时奖励
    \(s_1\) \(a\) \(s_1\) \(0\)
    \(s_1\) \(b\) \(s_2\) \(2\)
    \(s_2\) \(a\) \(s_1\) \(1\)
    \(s_2\) \(b\) \(s_2\) \(0\)

    求 \(V^{*}(s_1)\) 与 \(V^{*}(s_2)\)，以及 \(Q^{*}\) 的全部四个值。

    思路

    转移是确定性的，所以 Bellman 最优方程里的 \(\sum_{s'}\) 只剩一项。 写出两个方程，每个都是「两个候选值取最大」。 关键观察：在 \(s_2\) 处动作 \(b\) 给出 \(V^{*}(s_2)=0.5V^{*}(s_2)\)， 即 \(V^{*}(s_2)=0\)，所以这个候选一定不优——可以据此先化简。

    解答

    第一步：写出 Bellman 最优方程。 由于转移确定性，\(\sum_{s'}p(s'\mid s,a)V^{*}(s')\) 就等于唯一的下一状态的 \(V^{*}\)：

    \[ V^{*}(s_1) = \max\Big\{\underbrace{0 + 0.5\,V^{*}(s_1)}_{\text{动作 }a},\ \underbrace{2 + 0.5\,V^{*}(s_2)}_{\text{动作 }b}\Big\} \]
    \[ V^{*}(s_2) = \max\Big\{\underbrace{1 + 0.5\,V^{*}(s_1)}_{\text{动作 }a},\ \underbrace{0 + 0.5\,V^{*}(s_2)}_{\text{动作 }b}\Big\} \]

    第二步：先看 \(s_2\) 处的动作 \(b\)。 它给出的方程是 \(V^{*}(s_2)=0.5V^{*}(s_2)\)， 唯一解 \(V^{*}(s_2)=0\)。而 \(s_2\) 处动作 \(a\) 给出 \(1+0.5V^{*}(s_1)>0\) （因为 \(V^{*}(s_1)\geq0\)，由奖励非负可知）。 故 \(s_2\) 处一定选动作 \(a\)，于是

    \[ V^{*}(s_2) = 1 + 0.5\,V^{*}(s_1) \qquad (\star) \]

    第三步：判断 \(s_1\) 处选哪个。 设选 \(b\)，把 \((\star)\) 代入：

    \[ V^{*}(s_1) = 2 + 0.5\left(1+0.5V^{*}(s_1)\right) = 2.5 + 0.25V^{*}(s_1) \]
    \[ 0.75\,V^{*}(s_1) = 2.5 \quad \Longrightarrow \quad V^{*}(s_1) = \frac{2.5}{0.75} = \frac{10}{3} \]

    检查另一个候选（选 \(a\)）：\(0.5\cdot\frac{10}{3} = \frac{5}{3}\)。 比较：\(\frac{10}{3} > \frac{5}{3}\ \checkmark\)，选 \(b\) 确实最优。

    所以

    \[ V^{*}(s_1) = \frac{10}{3} \approx 3.333333, \qquad V^{*}(s_2) = 1 + 0.5\cdot\frac{10}{3} = \frac{8}{3} \approx 2.666667 \]

    第四步：回代验证 Bellman 最优方程（这是必做的一步）：

    \[ \max\left\{0.5\cdot\frac{10}{3},\ 2 + 0.5\cdot\frac{8}{3}\right\} = \max\left\{\frac{5}{3},\ \frac{10}{3}\right\} = \frac{10}{3} = V^{*}(s_1)\ \checkmark \]
    \[ \max\left\{1 + 0.5\cdot\frac{10}{3},\ 0.5\cdot\frac{8}{3}\right\} = \max\left\{\frac{8}{3},\ \frac{4}{3}\right\} = \frac{8}{3} = V^{*}(s_2)\ \checkmark \]

    两个方程都成立，答案正确。

    第五步：算 \(Q^{*}\)。 用 \(Q^{*}(s,a) = r(s,a)+\gamma V^{*}(s')\)：

    \[ Q^{*}(s_1,a) = 0 + 0.5\cdot\frac{10}{3} = \frac{5}{3} \approx 1.666667 \]
    \[ Q^{*}(s_1,b) = 2 + 0.5\cdot\frac{8}{3} = \frac{10}{3} \approx 3.333333 \]
    \[ Q^{*}(s_2,a) = 1 + 0.5\cdot\frac{10}{3} = \frac{8}{3} \approx 2.666667 \]
    \[ Q^{*}(s_2,b) = 0 + 0.5\cdot\frac{8}{3} = \frac{4}{3} \approx 1.333333 \]

    核对 \(V^{*}(s)=\max_a Q^{*}(s,a)\)： \(\max(5/3,\,10/3) = 10/3\ \checkmark\)，\(\max(8/3,\,4/3) = 8/3\ \checkmark\)。

    最优策略：\(\pi^{*}(s_1)=b\)，\(\pi^{*}(s_2)=a\)。 注意这是一个「循环」策略：\(s_1\to s_2\to s_1\to\cdots\)， 每两步收 \(2+1=3\) 的奖励，折扣后恰好是 \(\frac{2+1\cdot0.5}{1-0.5^2} = \frac{2.5}{0.75} = \frac{10}{3}\)。 这个「无终止循环」的特点是本例可用手算的原因。

    例题 2：策略评估——用矩阵求逆与迭代两种方法¶

    在例题 1 的 MDP 上，取策略 \(\pi\) 为「\(s_1\) 选 \(b\)，\(s_2\) 选 \(a\)」， 求 \(V^{\pi}(s_1)\) 与 \(V^{\pi}(s_2)\)，并分别用矩阵求逆与迭代法验证。

    思路

    先写出该策略诱导的马尔可夫链：\(r^{\pi}=(2,1)^{\top}\)， \(P^{\pi}=\begin{pmatrix}0&1\\1&0\end{pmatrix}\)。 代入闭式解 \(\boldsymbol{v}^{\pi}=(I-\gamma P^{\pi})^{-1}\boldsymbol{r}^{\pi}\)。 迭代法则从零向量出发反复应用 \(\boldsymbol{v}\leftarrow\boldsymbol{r}^{\pi}+\gamma P^{\pi}\boldsymbol{v}\)。

    解答

    第一步：写出 \(r^{\pi}\) 与 \(P^{\pi}\)。

    策略 \(\pi\) 是确定性的：\(\pi(b\mid s_1)=1\)，\(\pi(a\mid s_2)=1\)。故

    \[ r^{\pi}(s_1) = r(s_1,b) = 2, \qquad r^{\pi}(s_2) = r(s_2,a) = 1 \]
    \[ P^{\pi} = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix} \]

    第二步：构造 \(I-\gamma P^{\pi}\)。 \(\gamma=0.5\)，故

    \[ I - 0.5\,P^{\pi} = \begin{pmatrix} 1 & -0.5 \\ -0.5 & 1 \end{pmatrix} \]

    第三步：求逆。 行列式

    \[ \det = 1\times1 - (-0.5)(-0.5) = 1 - 0.25 = 0.75 = \frac{3}{4} \]
    \[ \left(I-0.5P^{\pi}\right)^{-1} = \frac{1}{0.75}\begin{pmatrix} 1 & 0.5 \\ 0.5 & 1 \end{pmatrix} = \frac{4}{3}\begin{pmatrix} 1 & 0.5 \\ 0.5 & 1 \end{pmatrix} \]

    第四步：代入求 \(\boldsymbol{v}^{\pi}\)。

    \[ \boldsymbol{v}^{\pi} = \frac{4}{3}\begin{pmatrix} 1 & 0.5 \\ 0.5 & 1 \end{pmatrix}\begin{pmatrix} 2 \\ 1 \end{pmatrix} = \frac{4}{3}\begin{pmatrix} 2 + 0.5 \\ 1 + 1 \end{pmatrix} = \frac{4}{3}\begin{pmatrix} 2.5 \\ 2 \end{pmatrix} = \begin{pmatrix} \frac{10}{3} \\[4pt] \frac{8}{3} \end{pmatrix} \]

    即

    \[ V^{\pi}(s_1) = \frac{10}{3} \approx 3.333333, \qquad V^{\pi}(s_2) = \frac{8}{3} \approx 2.666667 \]

    与例题 1 的 \(V^{*}\) 完全相同——说明这个策略确实是最优的， 因为达到 \(V^{\pi}=V^{*}\) 的策略就是最优策略。

    第五步：回代验证 Bellman 期望方程。

    \[ V^{\pi}(s_1) = r(s_1,b) + 0.5\,V^{\pi}(s_2) = 2 + 0.5\cdot\frac{8}{3} = 2+\frac{4}{3} = \frac{10}{3}\ \checkmark \]
    \[ V^{\pi}(s_2) = r(s_2,a) + 0.5\,V^{\pi}(s_1) = 1 + 0.5\cdot\frac{10}{3} = 1+\frac{5}{3} = \frac{8}{3}\ \checkmark \]

    第六步：迭代法验证。 从 \(\boldsymbol{v}_0=(0,0)^{\top}\) 出发， 反复做 \(\boldsymbol{v}_{k+1} = \boldsymbol{r}^{\pi} + 0.5P^{\pi}\boldsymbol{v}_k\)， 即 \(v_{k+1}(s_1) = 2+0.5v_k(s_2)\)，\(v_{k+1}(s_2) = 1+0.5v_k(s_1)\)：

    \(k\) \(v_k(s_1)\) \(v_k(s_2)\) 与极限的偏差
    0 0.000000 0.000000 3.333333
    1 2.000000 1.000000 1.666667
    2 2.500000 2.000000 0.833333
    3 3.000000 2.250000 0.416667
    4 3.125000 2.500000 0.208333
    5 3.250000 2.562500 0.104167
    6 3.281250 2.625000 0.052083
    \(\infty\) 3.333333 2.666667 0

    每步误差精确减半——因为 \(\gamma=0.5\)，误差按 \(\gamma^k\) 衰减。 第 6 步误差 0.0521，与理论值 \(3.3333\times0.5^6 = 0.0521\) 完全一致 \(\checkmark\)。

    两法结论一致，验证通过。

    例题 3：折扣因子如何改变最优决策¶

    某智能体有两个动作： FAST 立即获得奖励 \(5\) 然后回合结束； SLOW 本步奖励 \(0\)，但此后每步持续获得奖励 \(5\)（永不终止）。 问：\(\gamma\) 取何值时 SLOW 优于 FAST？

    思路

    比较两者的 \(Q\) 值。FAST 是 \(Q=5\)。 SLOW 的回报是 \(0+\gamma\cdot5+\gamma^2\cdot5+\cdots\)， 用几何级数求和得 \(\gamma\cdot\frac{5}{1-\gamma}\)。 令它大于 5 解出 \(\gamma\) 的阈值。

    解答

    第一步：算 FAST 的价值。 立即拿 \(5\)，游戏结束，故

    \[ Q_{\text{FAST}} = 5 \]

    第二步：算 SLOW 的价值。 本步奖励为 \(0\)，之后每一步奖励 \(5\)。故

    \[ Q_{\text{SLOW}} = 0 + \gamma\cdot5 + \gamma^2\cdot5 + \gamma^3\cdot5 + \cdots = \gamma\cdot5\left(1+\gamma+\gamma^2+\cdots\right) = \frac{5\gamma}{1-\gamma} \]

    第三步：比较。 令 \(Q_{\text{SLOW}} > Q_{\text{FAST}}\)：

    \[ \frac{5\gamma}{1-\gamma} > 5 \quad \Longrightarrow \quad \frac{\gamma}{1-\gamma} > 1 \quad \Longrightarrow \quad \gamma > 1-\gamma \quad \Longrightarrow \quad \gamma > \frac{1}{2} \]

    所以阈值是 \(\gamma = 1/2\)。 \(\gamma<1/2\) 时选 FAST，\(\gamma>1/2\) 时选 SLOW。

    第四步：数值验证。

    \(\gamma\) \(Q_{\text{SLOW}}=\dfrac{5\gamma}{1-\gamma}\) \(Q_{\text{FAST}}\) 最优动作
    \(0.3\) \(2.1429\) \(5.0000\) FAST
    \(0.4\) \(3.3333\) \(5.0000\) FAST
    \(0.5\) \(5.0000\) \(5.0000\) 平手
    \(0.6\) \(7.5000\) \(5.0000\) SLOW
    \(0.8\) \(20.0000\) \(5.0000\) SLOW
    \(0.9\) \(45.0000\) \(5.0000\) SLOW
    \(0.99\) \(495.0000\) \(5.0000\) SLOW

    第五步：分步累加验证 \(\gamma=0.9\) 的情形（确认几何级数没算错）：

    \[ Q_{\text{SLOW}}^{(n)} = 5\sum_{k=1}^{n}0.9^{k} \]
    累加步数 \(n\) \(Q_{\text{SLOW}}^{(n)}\)
    1 4.5000
    2 8.5500
    3 12.1950
    5 18.4280
    10 29.3095
    50 44.7681
    \(\infty\) 45.0000

    逐步逼近 45，与公式 \(\frac{5\times0.9}{0.1}=45\ \checkmark\)。

    工程含义（这一题最重要的收获）：

    现象 数学原因 实践后果
    \(\gamma\) 小 → 短视 未来奖励被强烈折价 只想立刻拿分，不愿等待
    \(\gamma\) 大 → 长视 未来几乎不打折 愿意「前期吃亏、后期大赚」
    \(\gamma\to1\) \(1/(1-\gamma)\to\infty\) 值函数发散，算法不稳

    这就是「机器人的耐心旋钮」。 训练机械臂做「先后退再冲刺」这类需要前期牺牲的动作时， \(\gamma\) 太小会永远学不会——它看不到冲刺阶段的大奖励。 这是机器人强化学习中最常见的失败模式之一。

    例题 4：动作价值函数与最优策略的多种形式¶

    沿用例题 1 的 MDP 与 \(V^{*}=\left(\frac{10}{3},\frac{8}{3}\right)\)， 现在为 \(s_1\) 增加一个与动作 \(b\) 完全等效的动作 \(c\) （即 \(c\) 也从 \(s_1\) 转到 \(s_2\) 并得奖励 \(2\)）。 (a) 求全部 \(Q^{*}\)；(b) 说明最优策略有多少个； © 若在 \(s_1\) 处以概率 \(p\) 选 \(b\)、以概率 \(1-p\) 选 \(c\) 的混合策略， 求 \(V^{\pi}(s_1)\)，并判断 \(p\) 是否影响结果。

    思路

    加了动作 \(c\) 之后 \(V^{*}\) 不变（因为它不改变可达集合）。 注意 \(Q^{*}(s_1,b)=Q^{*}(s_1,c)\)，出现并列最优。 混合策略下 \(b\) 与 \(c\) 的下一状态与奖励完全相同，所以 \(V\) 与 \(p\) 无关。

    解答

    (a) 计算 \(Q^{*}\)。 动作 \(c\) 的转移与奖励和 \(b\) 完全相同，故

    \[ Q^{*}(s_1,a) = 0 + 0.5\cdot\frac{10}{3} = \frac{5}{3} \approx 1.666667 \]
    \[ Q^{*}(s_1,b) = Q^{*}(s_1,c) = 2 + 0.5\cdot\frac{8}{3} = \frac{10}{3} \approx 3.333333 \]
    \[ Q^{*}(s_2,a) = 1 + 0.5\cdot\frac{10}{3} = \frac{8}{3} \approx 2.666667 \]
    \[ Q^{*}(s_2,b) = 0 + 0.5\cdot\frac{8}{3} = \frac{4}{3} \approx 1.333333 \]

    核对：\(V^{*}(s_1)=\max\left(\frac53,\frac{10}3,\frac{10}3\right)=\frac{10}{3}\ \checkmark\)， \(V^{*}(s_2)=\max\left(\frac83,\frac43\right)=\frac83\ \checkmark\)。 \(V^{*}\) 与例题 1 完全一致——增加一个等效动作不改变最优值。

    (b) 最优策略的个数。 由 \(\pi^{*}(s)=\arg\max_a Q^{*}(s,a)\)：

    • 在 \(s_2\) 处唯一：只有动作 \(a\) 达到 \(\frac{8}{3}\)，故 \(\pi^{*}(s_2)=a\)；
    • 在 \(s_1\) 处有并列：\(b\) 与 \(c\) 都达到 \(\frac{10}{3}\)。

    故在 \(s_1\) 处任何以概率 1 落在 \(\{b,c\}\) 上的随机策略都是最优的—— 即 \(s_1\) 处的选择有无穷多个（\(0\leq p\leq1\) 的连续族）。 整个 MDP 的最优策略共有无穷多个。

    重要结论：最优策略一般不唯一。 这解释了为什么不同的强化学习算法（Q-learning、SARSA、策略梯度） 在同一任务上会收敛到行为不同的策略——它们都对，只是选了并列解中的不同那个。

    © 混合策略的值。 设 \(s_1\) 处选 \(b\) 的概率为 \(p\)，选 \(c\) 的概率为 \(1-p\)。 由于两个动作都「转到 \(s_2\) 并得奖励 \(2\)」，按定义算 \(Q^{\pi}(s_1,\cdot)\)：

    \[ Q^{\pi}(s_1,b) = 2 + 0.5\,V^{\pi}(s_2), \qquad Q^{\pi}(s_1,c) = 2 + 0.5\,V^{\pi}(s_2) \]

    两者相同，故按 \(\pi\) 加权平均仍然是同一个值：

    \[ V^{\pi}(s_1) = p\cdot Q^{\pi}(s_1,b) + (1-p)\cdot Q^{\pi}(s_1,c) = 2 + 0.5\,V^{\pi}(s_2) \]

    \(p\) 完全不出现！继续求 \(V^{\pi}(s_2)\)（在 \(s_2\) 处仍选 \(a\)）：

    \[ V^{\pi}(s_2) = 1 + 0.5\,V^{\pi}(s_1) \]

    联立：\(V^{\pi}(s_1) = 2 + 0.5\left(1+0.5V^{\pi}(s_1)\right) = 2.5 + 0.25V^{\pi}(s_1)\)，故

    \[ V^{\pi}(s_1) = \frac{2.5}{0.75} = \frac{10}{3}\ \checkmark, \qquad V^{\pi}(s_2) = \frac{8}{3} \]

    与 \(V^{*}\) 完全相同，且与 \(p\) 无关（取 \(p=3/7\) 代入同样得到 \(\frac{10}{3}\)）。

    三条结论集中起来：

    问题 结论 原因
    \(V^{*}\) 会变吗 不会 增加等效动作不改变可达收益集合
    最优策略唯一吗 不唯一（无穷多个） 存在并列的 \(\arg\max\)
    混合后值会变吗 不变 被混合的动作完全等效

    工程含义：如果在两个等效动作上随机化， 策略的期望表现不会变差——这一点在探索中非常有用。 但反过来说，如果两个动作不等效，随机化就会损失收益 （因为 \(\sum_a\pi(a)Q(a)\leq\max_aQ(a)\) 严格不等）。 这正是「最优策略可以确定性」这句话的实际意义。

    六、用在哪些课程里¶

    无人系统自主决策与优化 · 问题建模的统一语言¶

    • 把控制问题说成 MDP：这是本课程最核心的建模动作。 状态 = 系统观测量（位置、姿态、剩余电量、任务进度）， 动作 = 控制输入或离散决策（左转/右转/加速）， 奖励 = 任务完成度减去能耗与风险。 一旦写成 MDP，就可以直接调用整套求解算法——不用每次重新发明。
    • 奖励设计（reward shaping）是工程成败的关键。 奖励写错了，算法再先进也学不出想要的行为。 常见的坑：只用稀疏的终端奖励（成功给 1，其余给 0）会让学习极慢， 因为绝大多数轨迹上 \(G_t\) 都是 0，梯度信号为零。 补救办法是加入引导性奖励（potential-based shaping）， 但必须保证它不改变最优策略——这是一个有严格定理支撑的设计准则。
    • \(\gamma\) 与任务时限的对应：本页例题 3 给出的阈值分析可直接用于选 \(\gamma\)。 例如「30 步内到达目标」，取 \(\gamma\approx0.93\)； 「需要长时间省电巡航」则取 \(\gamma\to1\) 附近的 \(0.999\)。
    • \(Q^{*}\) 就是「决策表」：机载实时决策时， 离线算好 \(Q^{*}\) 存成查找表，在线只需 \(\arg\max_a Q^{*}(s,a)\)， 单次查询复杂度是 \(O(\lvert A\rvert)\)，完全满足实时性要求。 这是「强化学习能上机」的关键工程路径。

    模式识别 · 序列决策与概率推断¶

    • 贝叶斯滤波是 MDP 的「无动作」特例。 把 MDP 的动作去掉（或固定为「观测」），Bellman 期望方程退化为 贝叶斯递推 \(p(x_t\mid y_{1:t})\propto p(y_t\mid x_t)\int p(x_t\mid x_{t-1})p(x_{t-1}\mid y_{1:t-1})\mathrm{d}x_{t-1}\)。 两者的结构完全相同：都是「当前信念 → 转移 → 修正」。

    • HMM 与 MDP 的对照：

      HMM（模式识别） MDP（决策）
      转移 \(p(x_{t+1}\lvert x_t)\) \(p(s'\lvert s,a)\)

    机器人学 · 从规划到学习¶

    • 机械臂抓取：状态 = 关节角 + 末端位姿 + 物体位姿估计； 动作 = 关节力矩增量；奖励 = 接近目标 + 抓稳 + 减去力矩消耗。 奖励中必须包含「安全项」，否则学出的策略会撞坏设备。
    • 移动机器人导航：\(\gamma\) 取 \(0.99\) 是常见选择， 对应「约 100 步的规划视野」，与局部避障 + 全局路径的层次结构吻合。
    • 部分可观测性（POMDP）：真实机器人的状态（如地面摩擦、负载质量） 不可直接观测，严格来说应是 POMDP。 工程解法：把「信念状态」或短的观测历史当作状态， 从而近似满足马尔可夫性——这正是本页 1.2 节「状态设计」的实际应用。
    • 多机器人协作：每个机器人的奖励依赖他人的动作， 严格来说不是单智能体 MDP 而是 Markov 博弈。 但工程上常忽略这一层（独立学习），代价是收敛性没有保证。 知道这个近似在哪里失效，比记住算法更重要。

    七、自测¶

    Q1 判断对错并说明理由： (a) 在 MDP 中，最优策略一定存在，且可以是确定性的。 (b) 若 \(\gamma=1\)，只要奖励有界，\(G_t\) 就一定收敛。 © 状态价值函数 \(V^{\pi}(s)\) 依赖时刻 \(t\)，所以不能迭代求解。 (d) \(V^{*}(s)=\max_{\pi}V^{\pi}(s)\) 中，不同的状态可以取不同的 \(\pi\)。

    提示

    (a) 回想有限性在存在性证明中的作用。 (b) 举一个常数奖励的例子，算一算无穷和。 © 时齐性假设的作用是什么？ (d) 关键在「是否存在一个统一的最优策略」这个定理。

    解答

    (a) 正确（但需要有限性条件）。 对有限 MDP（\(S,A\) 有限、奖励有界、\(\gamma<1\)）， 存在确定性时齐最优策略。论证要点：\(V^{*}(s)=\sup_{\pi}V^{\pi}(s)\) 有界； 确定性策略总数 \(\lvert A\rvert^{\lvert S\rvert}\) 有限，故上确界可达。 注意：若动作空间是连续的，\(\arg\max\) 可能不存在， 此时只能保证存在近似最优策略——这是连续控制的真实困难。

    (b) 错误。 \(\gamma=1\) 时 \(G_t = \sum_{k=0}^{\infty}R_{t+k+1}\)， 取 \(R\equiv1\) 则 \(G_t = \infty\)，发散。 有界不足以保证收敛——必须 \(\gamma<1\) 才能由 \(\lvert G_t\rvert\leq R_{\max}/(1-\gamma)\) 得到有限界。 （对回合制任务，\(\gamma=1\) 可以用，因为求和只在有限步内进行， 但此时需要额外假设每个回合必然终止。）

    © 错误。 正因为引入了时齐假设（转移与奖励都不依赖时间）， 定义中的 \(t\) 被完全消掉，\(V^{\pi}\) 成为只依赖 \(s\) 的函数。 推导中关键的一步是 \(\mathbb{E}_{\pi}[G_{t+1}\mid S_{t+1}=s'] = V^{\pi}(s')\)——下标被消掉了。 若 \(V\) 依赖 \(t\)，就无法写成自洽方程，迭代法也失去依据。

    (d) 表述有陷阱。 记号 \(\max_{\pi}V^{\pi}(s)\) 中确实有 \(\pi\)， 看上去「每个状态各取一个 \(\pi\)」；但定理保证存在一个统一的 \(\pi^{*}\) 使 \(V^{\pi^{*}}(s)=V^{*}(s)\) 对所有 \(s\) 同时成立。 所以这个担心是多余的：逐状态取最大与整体取最优是一致的。 证明思路是 4.1 节的「有限策略空间中取极限」。

    Q2 两状态 MDP，\(S=\{s_1,s_2\}\)，\(A=\{L,R\}\)， 给定策略 \(\pi\)（\(s_1\) 处选 \(L\)、\(s_2\) 处选 \(R\)），参数如下： \(r(s_1,L)=1\)，\(r(s_2,R)=2\)； \(p(s_1\mid s_1,L)=0.5\)，\(p(s_2\mid s_1,L)=0.5\)； \(p(s_2\mid s_2,R)=1\)；\(\gamma=0.9\)。 求 \(V^{\pi}(s_1)\) 与 \(V^{\pi}(s_2)\)。

    提示

    先写 \(P^{\pi}\) 与 \(r^{\pi}\)，注意 \(s_2\) 处动作 \(R\) 是自环。 用闭式解列二元线性方程组，或者直接用 \(V^{\pi}(s)=r^{\pi}(s)+\gamma\sum_{s'}P^{\pi}_{ss'}V^{\pi}(s')\) 逐个写。

    解答

    第一步：写出 \(r^{\pi}\) 与 \(P^{\pi}\)。

    \[ r^{\pi}(s_1) = r(s_1,L) = 1, \qquad r^{\pi}(s_2) = r(s_2,R) = 2 \]
    \[ P^{\pi} = \begin{pmatrix} 0.5 & 0.5 \\ 0 & 1 \end{pmatrix} \]

    （第二行 \(s_2\to s_2\) 概率为 1，是自环，故第二个分量 \(P^{\pi}_{22}=1\)。）

    第二步：写 Bellman 期望方程。

    \[ V^{\pi}(s_1) = 1 + 0.9\left(0.5\,V^{\pi}(s_1) + 0.5\,V^{\pi}(s_2)\right) \]
    \[ V^{\pi}(s_2) = 2 + 0.9\,V^{\pi}(s_2) \]

    第三步：先解 \(s_2\)。 第二个方程只含 \(V^{\pi}(s_2)\)：

    \[ V^{\pi}(s_2)(1-0.9) = 2 \quad \Longrightarrow \quad V^{\pi}(s_2) = \frac{2}{0.1} = 20 \]

    这符合直觉：在 \(s_2\) 处每步拿奖励 \(2\) 永不终止， 折扣后总价值为 \(\frac{2}{1-0.9}=20\ \checkmark\)。

    第四步：解 \(s_1\)。 代入 \(V^{\pi}(s_2)=20\)：

    \[ V^{\pi}(s_1) = 1 + 0.9\left(0.5\,V^{\pi}(s_1) + 0.5\times20\right) = 1 + 0.45\,V^{\pi}(s_1) + 9 \]
    \[ V^{\pi}(s_1)(1-0.45) = 10 \quad \Longrightarrow \quad V^{\pi}(s_1) = \frac{10}{0.55} = \frac{200}{11} \approx 18.181818 \]

    第五步：回代验证。

    \[ 1 + 0.9\left(0.5\times\frac{200}{11} + 0.5\times20\right) = 1 + 0.9\left(\frac{100}{11} + 10\right) = 1 + 0.9\cdot\frac{210}{11} = 1 + \frac{189}{11} = \frac{200}{11}\ \checkmark \]
    \[ 2 + 0.9\times20 = 2+18 = 20 = V^{\pi}(s_2)\ \checkmark \]

    两个方程全部成立。答案：\(V^{\pi}(s_1)=\dfrac{200}{11}\approx18.1818\)，\(V^{\pi}(s_2)=20\)。

    用矩阵求逆复核。 \(I-0.9P^{\pi} = \begin{pmatrix} 0.55 & -0.45 \\ 0 & 0.10 \end{pmatrix}\)， 行列式 \(=0.055\)。逆矩阵为

    \[ \left(I-0.9P^{\pi}\right)^{-1} = \frac{1}{0.055}\begin{pmatrix} 0.10 & 0.45 \\ 0 & 0.55 \end{pmatrix} \]

    乘以 \(\boldsymbol{r}^{\pi}=(1,2)^{\top}\)：

    \[ \boldsymbol{v}^{\pi} = \frac{1}{0.055}\begin{pmatrix} 0.10\times1 + 0.45\times2 \\ 0.55\times2 \end{pmatrix} = \frac{1}{0.055}\begin{pmatrix} 1.00 \\ 1.10 \end{pmatrix} = \begin{pmatrix} 18.1818 \\ 20.0000 \end{pmatrix}\ \checkmark \]

    两种方法一致。（\(\frac{1}{0.055}=\frac{200}{11}\)，故第一分量为 \(\frac{200}{11}\times1=\frac{200}{11}\)。）

    工程含义：\(s_1\) 处有一半概率掉进「更好的」\(s_2\)， 但代价是要等一步才能到，所以 \(V^{\pi}(s_1)=18.18 < V^{\pi}(s_2)=20\)。 差值 \(20-18.18=1.82\) 就是「\(s_1\) 处的处境劣势」—— 这个差值可以用来判断「要不要花力气避免进入某个状态」。

    Q3 设奖励 \(R\equiv1\)、\(\gamma=0.9\)。 (a) 求 \(G_t\) 的期望值（即常数奖励下的无穷折扣和）。 (b) 求「第 \(k\) 步奖励的现值权重」\(\gamma^{k}\) 衰减到 0.1 以下所需的 \(k\)。 © 若把「有效视野」定义为 \(\gamma^{k}\) 的衰减时间常数 \(1/(1-\gamma)\)， 说明为什么这个定义合理。

    提示

    (a) 用几何级数 \(\sum_{k=0}^{\infty}\gamma^{k} = 1/(1-\gamma)\)。 (b) 解 \(0.9^{k}=0.1\)，取对数。 © 想一想「\(\gamma\) 与 \(1-\gamma\) 的连续近似关系」， 即 \(\gamma^{k} = (1-(1-\gamma))^{k}\approx\mathrm{e}^{-k(1-\gamma)}\)。

    解答

    (a) 无穷折扣和。

    \[ G_t = \sum_{k=0}^{\infty}\gamma^{k}\cdot1 = \frac{1}{1-\gamma} = \frac{1}{0.1} = 10 \]

    这也是 \(V^{\pi}(s)\) 的上界形式 \(R_{\max}/(1-\gamma)\) 在 \(R_{\max}=1\) 时的取值。

    (b) 衰减到 0.1 所需步数。

    \[ 0.9^{k} = 0.1 \quad \Longrightarrow \quad k = \frac{\log 0.1}{\log 0.9} = \frac{-2.302585}{-0.105361} \approx 21.85 \]

    约 22 步。 也就是说第 23 步之后的奖励，权重已低于 \(10\%\)。

    © 为什么 \(1/(1-\gamma)\) 是合理的视野定义。

    令 \(\varepsilon = 1-\gamma\)（小量），则 \(\gamma = 1-\varepsilon\)，于是

    \[ \gamma^{k} = (1-\varepsilon)^{k} \approx \mathrm{e}^{-\varepsilon k} = \mathrm{e}^{-k/(1/(1-\gamma))} \]

    最后一步用到了 \(\varepsilon = 1-\gamma\)。这说明 \(\gamma^{k}\) 近似是一个指数衰减， 其特征时间（衰减到 \(1/\mathrm{e}\approx0.3679\) 的步数）正是 \(\dfrac{1}{1-\gamma}\)。

    对 \(\gamma=0.9\)：\(1/(1-\gamma)=10\) 步，与直接算 \(0.9^{k}=0.3679\) 得到的 \(k = \log 0.3679/\log 0.9 = 9.49\) 步非常接近。

    所以「有效视野约 \(1/(1-\gamma)\) 步」是一个有依据的近似， 它的精确含义是「折扣权重的 e 折时间」。

    (d) 视野长度的对照表。

    \(\gamma\) \(1/(1-\gamma)\) \(0.1\) 权重步数 \(\log0.1/\log\gamma\) 误差减半步数 \(\log0.5/\log\gamma\)
    \(0.5\) \(2\) \(3.32\) \(1.00\)
    \(0.9\) \(10\) \(21.85\) \(6.58\)
    \(0.99\) \(100\) \(229.1\) \(69.0\)
    \(0.999\) \(1000\) \(2301\) \(692.8\)

    注意第三列（有效视野）与第四列（算法收敛步数）是两个完全不同的量： - 有效视野 \(\approx\frac{1}{1-\gamma}\) 说的是问题本身需要看多远； - 收敛步数 \(\approx\frac{\log 10^{-6}}{\log\gamma}\) 说的是算法要算多久。

    两者的比值稳定在 13～14 倍左右（因为 \(\log 10^{-6}\approx-13.8\)， 而 \(\log\gamma\approx-(1-\gamma)\)，故比值 \(\approx\frac{13.8}{1-\gamma}\) 除以 \(\frac{1}{1-\gamma}\) 正好是 13.8）。 这个比例在选算法时有直接意义： 若任务需要 100 步的视野（\(\gamma=0.99\)）， 则求解到 \(10^{-6}\) 精度大约需要 1379 步迭代—— 如果每次迭代都要扫一遍状态空间，机载实时求解难以承受， 所以工程上普遍采用「离线训练、在线查表」的两段式方案。

    Q4 本题讨论 Bellman 期望方程与 Bellman 最优方程的区别。 (a) 若某 MDP 只有 1 个动作（\(\lvert A\rvert=1\)），两个方程有什么关系？ (b) 严格说明为什么期望方程是线性的、最优方程是非线性的。 © 若某个 \(V\) 满足 Bellman 最优方程，能否断定它就是 \(V^{*}\)？

    提示

    (a) \(\max_a\) 在单元素集合上等于唯一元素。 (b) 看 \(V\) 出现在方程右边时的「次数」——一次还是多次、是否被 max 包裹。 © 需要用到「Bellman 算子是 \(\gamma\)-压缩」这一性质。

    解答

    (a) 只有一个动作时两者相同。 若 \(A=\{a_0\}\)， 则 \(\max_{a}\) 在单元素集合上就是取该元素，而 \(\pi(a_0\mid s)=1\)， 期望求和也退化为单项。两个方程都变成

    \[ V(s) = r(s,a_0) + \gamma\sum_{s'}p(s'\mid s,a_0)V(s') \]

    完全一致。 此时 MDP 退化成一个普通马尔可夫链—— 正好印证 1.2 节「固定策略后 MDP 就是马尔可夫链」的说法。

    (b) 线性 vs 非线性。

    期望方程中，把 \(V\) 看作未知量，方程右边是

    \[ \sum_{a}\pi(a\mid s)\sum_{s'}p(s'\mid s,a)\left[r(s,a)+\gamma V(s')\right] = \underbrace{\sum_{a}\pi(a\mid s)\sum_{s'}p(s'\mid s,a)r(s,a)}_{b_s,\ \text{与}\ V\ \text{无关}} + \gamma\sum_{s'}\underbrace{\left(\sum_a\pi(a\mid s)p(s'\mid s,a)\right)}_{P^{\pi}_{ss'}}V(s') \]

    \(V\) 只以一次幂出现，且系数 \(P^{\pi}_{ss'}\) 不依赖 \(V\)。 写成矩阵形式就是 \((I-\gamma P^{\pi})\boldsymbol{v}=\boldsymbol{r}^{\pi}\)—— 标准的线性方程组。

    最优方程中，右边是 \(\max_a\left[r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)V(s')\right]\)。 \(\max\) 是分段线性凸函数，不是线性函数：

    \[ \max_a(f_a+g_a) \neq \max_a f_a + \max_a g_a \quad\text{一般情形} \]

    具体地，取 \(A=\{a_1,a_2\}\)、两个动作的表达式分别为 \(V(s_1)\) 与 \(V(s_2)\)， 则 \(\max\{V(s_1),V(s_2)\}\) 关于 \((V(s_1),V(s_2))\) 明显非线性 （它是一阶齐次的凸函数，而线性函数必须同时满足可加性）。

    后果：期望方程可以一步求逆解出，最优方程必须迭代求解。

    © 能，但需要论证。 设 \(\mathcal{T}\) 为 Bellman 最优算子：

    \[ (\mathcal{T}V)(s) = \max_a\left[r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)V(s')\right] \]

    关键性质：\(\mathcal{T}\) 在最大范数下是 \(\gamma\)-压缩的（证明见下一页）。 由压缩映射原理，\(\mathcal{T}\) 有唯一不动点。

    一方面 \(V^{*}\) 满足 Bellman 最优方程，即 \(\mathcal{T}V^{*}=V^{*}\)， 故 \(V^{*}\) 是不动点。 另一方面由不动点唯一性，任何满足 \(\mathcal{T}V=V\) 的 \(V\) 都等于 \(V^{*}\)。

    所以只要验证了 Bellman 最优方程，就能断定是 \(V^{*}\)。 这正是所有强化学习算法「收敛性验证」的统一套路： 算法收敛 ⟹ 极限点满足方程 ⟹ 唯一 ⟹ 就是 \(V^{*}\)。

    因此「回代验证 Bellman 方程」是解 MDP 后的标准收尾动作， 它的合法性就来自这个定理——这是本页最有用的一条方法论。
